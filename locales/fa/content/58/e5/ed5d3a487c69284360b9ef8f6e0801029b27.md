آنها راهنمای ابزار مرتبط با بافت کاربر هم دارند، مانند این:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

شاید دوست داشته باشید این ویجت‌ها را خودتان در اسناد Markdown رندر کنید، مثلاً در پایان یک سند برای پیشنهاد مطالعه‌ی بیشتر یا تمرین‌های خوبی که می‌توان از آن‌ها چیزی یاد گرفت.

**توجه:** همچنین می‌توانید برای متن‌های درون‌خطی از پیوندهای معمولی استفاده کنید که راهنمای ابزار به آن‌ها اضافه می‌شود. برای جزئیات بیشتر، [مستندات پیونددهی داخلی](/docs/building/markdown/internal-linking) را ببینید.

## کاربرد

ویجت‌ها هر جایی که بتوانید از Markdown استفاده کنید به کار می‌روند، مانند مستندسازی، رویکردها و بحث‌های دانشجو و مربی.

آنها با قالب زیر رندر می‌شوند:

```md
[<type>:<id>]()
```

بخش‌های `<type>` و `<id>` متغیر هستند و به ویجت واقعی مورد استفاده بستگی دارند.

مرجع پیوند، یعنی محتوای `()`، توسط وب‌سایت نادیده گرفته می‌شود. برای اهداف نگهداری می‌توانید آن‌ها را به هر جایی که می‌خواهید اشاره دهید.

## ویجت تمرین

قالب پیوند: `[exercise:<track-slug>/<exercise-slug>]()`

### مثال

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## ویجت مفهوم

قالب پیوند: `[concept:<track-slug>/<concept-slug>]()`

### مثال

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## ویجت رویکرد

قالب پیوند: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### مثال

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## ویجت مقاله

قالب پیوند: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### مثال

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
