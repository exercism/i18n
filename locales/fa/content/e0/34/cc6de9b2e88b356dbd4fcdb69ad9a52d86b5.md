# پیوست دستورالعمل

## ساختار پروژه

* پوشه‌ی `src` شامل راه‌حل شما برای این تمرین است
* پوشه‌ی `spec` شامل testهایی است که برای این تمرین اجرا می‌شوند

## اجرای testها

اگر در پوشه‌ی درستی باشید (یعنی همان پوشه‌ای که `src` و `spec` در آن قرار دارند)، می‌توانید testهای آن تمرین را با اجرای `crystal spec` اجرا کنید:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

این دستور همه‌ی فایل‌های test را در پوشه‌ی `spec` اجرا می‌کند.

در هر فایل test، همه‌ی testها به‌جز test اول نادیده گرفته شده‌اند.

وقتی یک test را با موفقیت پاس کنید، می‌توانید با تغییر `pending` به `it`، test بعدی را از حالت نادیده خارج کنید.

## ارسال راه‌حل شما

هنگام ارسال راه‌حل، حتماً فایل منبع را در پوشه‌ی `src` هم ارسال کنید:

```bash
$ exercism submit src/hello_world.cr
```
