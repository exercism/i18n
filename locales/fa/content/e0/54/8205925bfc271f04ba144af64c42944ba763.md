# نکاتی درباره‌ی براکت‌ها

Tcl یک [زبان بسیار ساده](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm) است، اما شیوه‌ای که مفسر code را تجزیه می‌کند چند حالت مرزی مشکل‌ساز دارد.

## آکولاد

آکولاد در Tcl صرفاً روشی برای نقل‌قول کردن یک بلوک متن است؛ این متن ممکن است به‌عنوان code یا داده تفسیر شود. درون آکولادها، آکولادهای تودرتو می‌توانند ظاهر شوند، اما این آکولادهای تودرتو باید متوازن باشند. صفحه‌ی راهنمای Tcl این را می‌گوید:

> آکولادها درون کلمه تودرتو می‌شوند: برای هر آکولاد باز اضافی باید یک آکولاد بسته‌ی اضافی وجود داشته باشد (البته اگر آکولاد باز یا بسته‌ای درون کلمه _با بک‌اسلش نقل‌قول شده باشد_، در یافتن آکولاد بسته‌ی متناظر شمرده نمی‌شود).

عبارت‌بندی آنجا کاملاً دقیق است: اگر می‌خواهید کاراکتر آکولاد باز یا بسته‌ی بدون متناظر داشته باشید، باید با بک‌اسلش نقل‌قول شود. پس این کار را نکنید:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
باید این کار را بکنید
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

این می‌تواند مشکل‌ساز باشد، چون Tcl کامنت‌ها را به شیوه‌ای متفاوت از بیشتر زبان‌ها تجزیه می‌کند. بحث بیشتری در [ویکی Tcl](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments) هست.

## کروشه

به‌طور مشابه، چون Tcl از کروشه‌ها برای [جانشینی دستور.](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11)، حتی درون رشته‌های داخل گیومه‌ی دوگانه، استفاده می‌کند، باید در فرار دادن کروشه‌های باز احتیاط کنید.

## پرانتز

به‌جز [متغیرهای آرایه‌ی انجمنی](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12)، پرانتزها صرفاً کاراکترهای معمولی هستند.
