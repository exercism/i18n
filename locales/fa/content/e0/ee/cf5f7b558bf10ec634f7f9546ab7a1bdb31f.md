# مقدمه

## رابط به‌عنوان مجموعه‌ای از متدها

در ساده‌ترین شکل خود، **«نوع رابط»** مجموعه‌ای از امضاهای متد است.
در ادامه نمونه‌ای از تعریف یک رابط را می‌بینید که دو متد `Add` و `Value` دارد:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

نام پارامترهایی مانند `increment` را می‌توان از تعریف رابط حذف کرد، اما معمولاً خوانایی را بیشتر می‌کنند.

نام رابط‌ها در Go شامل واژه‌ی `Interface` یا `I` نیست.
به‌جای آن، معمولاً به `er` ختم می‌شوند، مانند `Reader` و `Stringer`.

## پیاده‌سازی یک رابط

هر نوعی که متدهای رابط را تعریف کند، به‌طور خودکار و ضمنی رابط را «پیاده‌سازی» می‌کند.
در Go کلیدواژه‌ی `implements` وجود ندارد.

نوع زیر رابط `Counter` را که در بالا دیدیم، پیاده‌سازی می‌کند.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

برای پیاده‌سازی رابط، فرقی نمی‌کند که متد گیرنده‌ی مقداری داشته باشد یا گیرنده‌ی اشاره‌گر.
(اگر درباره‌ی آن‌ها مطمئن نیستید، [مفاهیم متدها][concept-methods] را دوباره ببینید.)

> یک مقدار از نوع رابط می‌تواند هر مقداری را که آن متدها را پیاده‌سازی می‌کند، نگه دارد. [^1]

یعنی اکنون می‌توان از `Stats` در همه‌ی جاهایی استفاده کرد که انتظار رابط `Counter` را دارند.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

چون رابط‌ها به‌صورت ضمنی پیاده‌سازی می‌شوند، یک نوع به‌راحتی می‌تواند چندین رابط را پیاده‌سازی کند.
فقط کافی است همه‌ی متدهای لازم را تعریف کرده باشد.

## رابط خالی

یک نوع رابط بسیار خاص در Go وجود دارد: **«رابط خالی»** که هیچ متدی ندارد.
رابط خالی به این شکل نوشته می‌شود: `interface{}`.
`any` معادلی برای `interface{}` است و کاربردش رایج‌تر است.

چون رابط خالی هیچ متدی ندارد، هر نوعی آن را به‌صورت ضمنی پیاده‌سازی می‌کند.
این موضوع برای تعریف تابعی مفید است که بتواند به‌شکل عمومی هر مقداری را بپذیرد.
در این حالت، پارامتر تابع از نوع رابط خالی استفاده می‌کند.
