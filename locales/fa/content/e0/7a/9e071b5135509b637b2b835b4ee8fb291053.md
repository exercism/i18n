# دستورالعمل‌ها

در این تمرین، مجوزهای حساب‌های کاربری یک انجمن اینترنتی را بررسی می‌کنید. این انجمن از سه مجوز متفاوت پشتیبانی می‌کند:

- Read
- Write
- Delete

سه نوع حساب وجود دارد که هر کدام مجوزهای پیش‌فرض متفاوتی دارند:

- مهمان‌ها: می‌توانند پست‌ها را بخوانند.
- کاربران: می‌توانند پست‌ها را بخوانند و بنویسند.
- ناظران: می‌توانند پست‌ها را بخوانند، بنویسند و حذف کنند؛ همه‌ی مجوزها را دارند.

گاهی می‌توان مجوزهای تکی را تغییر داد؛ برای مثال می‌توان به یک حساب مهمان اجازه داد که پست بنویسد، یا لغو همه‌ی مجوزهای یک حساب باعث می‌شود هیچ مجوزی نداشته باشد.

## 1. گرفتن مجوزهای پیش‌فرض برای یک نوع حساب

ابتدا یک `enum` به اسم `AccountType` تعریف کنید که سه نوع حساب را نشان دهد: `Guest`، `User` و `Moderator`.

سپس یک `enum` به اسم `Permission` تعریف کنید که سه نوع مجوز را نشان دهد: `Read`، `Write`، `Delete` و دو مورد دیگر: `All` برای داشتن همه‌ی مجوزها و `None` برای نداشتن هیچ مجوزی.

سپس متد `Permissions.Default()` را (که `static` است) پیاده‌سازی کنید تا مجوزهای پیش‌فرض یک نوع حساب مشخص را برگرداند:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. اعطای یک مجوز

متد `Permissions.Grant()` را (که `static` است) پیاده‌سازی کنید که یک مجوز را اعطا (اضافه) می‌کند:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. لغو یک مجوز

متد `Permissions.Revoke()` را (که `static` است) پیاده‌سازی کنید که یک مجوز را لغو (حذف) می‌کند:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. بررسی یک مجوز

متد `Permissions.Check()` را (که `static` است) پیاده‌سازی کنید که مجوزهای فعلی حساب را می‌گیرد و بررسی می‌کند که آیا حساب برای یک مجوز مشخص مجاز است:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
