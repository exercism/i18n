# مقدمه

در Java، از «لیترال» `null` برای نشان دادن نبود یک مقدار استفاده می‌شود.

انواع داده‌ی اولیه در Java همه مقدار پیش‌فرض دارند و بنابراین هرگز نمی‌توانند `null` باشند. طبق قرارداد، این نوع‌ها با حرف کوچک شروع می‌شوند، مثلاً `int`.

انواع ارجاعی آدرس حافظه‌ی یک شیء را در خود نگه می‌دارند و می‌توانند مقدار `null` داشته باشند. آن‌ها معمولاً با حرف بزرگ شروع می‌شوند، مثلاً `String`.

اگر بخواهید به متغیری از نوع داده‌ی اولیه مقدار `null` بدهید، خطای زمان کامپایل رخ می‌دهد، چون متغیر همیشه مقداری اولیه از همان نوعی را نگه می‌دارد که به آن نسبت داده شده است.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

اختصاص دادن مقدار `null` به یک متغیر ارجاعی به خطای زمان کامپایل منجر نمی‌شود، چون متغیرهای ارجاعی `null` را می‌پذیرند.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
