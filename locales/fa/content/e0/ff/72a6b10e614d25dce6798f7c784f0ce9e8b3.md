# مقدمه

حلقه‌ی `for` به شما امکان می‌دهد کدی را بارها درون یک حلقه اجرا کنید تا زمانی که شرطی برآورده شود.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

حلقه‌ی `for` از چهار بخش تشکیل شده است:

1. مقداردهی اولیه: یک بار پیش از ورود به حلقه اجرا می‌شود. معمولاً برای تعریف متغیرهایی به کار می‌رود که درون حلقه استفاده می‌شوند.
2. شرط: پیش از هر بار تکرار حلقه اجرا می‌شود. تا زمانی که مقدار آن `true` باشد، حلقه به اجرا ادامه می‌دهد.
3. شمارنده: پس از هر بار تکرار حلقه اجرا می‌شود. معمولاً برای تغییر (اغلب افزایش یا کاهش) متغیرهای حلقه به کار می‌رود.
4. بدنه: کدی که در هر بار تکرار حلقه اجرا می‌شود.
