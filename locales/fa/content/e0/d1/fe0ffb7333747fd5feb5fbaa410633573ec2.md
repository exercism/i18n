# راهنمایی‌ها

## کلی

- مستندات Python درباره‌ی [ابزارهای کنترل جریان][control flow tools] و آموزش Real Python درباره‌ی [شرط‌ها][real python conditionals] جای خوبی برای شروع هستند.
- مستندات Python درباره‌ی [عملیات منطقی][boolean operations] می‌تواند مرور خوبی بر `bools` باشد؛ آموزش Real Python درباره‌ی [مقادیر منطقی][python booleans] هم همین‌طور.
- مستندات Python درباره‌ی [مقایسه‌ها][comparisons] و [نمونه‌های مقایسه][python comparisons examples] می‌تواند مرور خوبی برای مقایسه‌ها باشد.

## 1. بررسی وضعیت بحرانی

- عملگرهای مقایسه ([مرور مقایسه‌ها][comparisons review]) و عملیات منطقی ([concept:python/bools]()) را می‌توان با هم ترکیب کرد و همراه با شرط‌ها به کار برد.
- عبارت‌های شرطی باید به `True` یا `False` ارزیابی شوند.
- از `else` می‌توان برای «بلوک کد»ی استفاده کرد که وقتی همه‌ی آزمون‌های شرطی `False` برگردانند اجرا می‌شود.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. تعیین بازه‌ی توان خروجی

- عملگرهای مقایسه را می‌توان با هم ترکیب کرد و همراه با شرط‌ها به کار برد.
- می‌توان از هر تعداد دستور `elif` به عنوان «شاخه»های تصمیم‌گیری استفاده کرد.
- هر «شاخه» می‌تواند `return` جداگانه داشته باشد، هرچند ممکن است ابزارهای lint آن را «بدسبک» بدانند.
- اگر linter ایراد گرفت، می‌توانید خروجی یک شاخه را به یک متغیر مشترک نسبت دهید و سپس همان متغیر را `return` کنید.

## 3. سازوکار ایمن در برابر خرابی

- عملگرهای مقایسه را می‌توان با هم ترکیب کرد و همراه با شرط‌ها به کار برد.
- می‌توان از هر تعداد دستور `elif` به عنوان «شاخه»های تصمیم‌گیری استفاده کرد.
- هر «شاخه» می‌تواند `return` جداگانه داشته باشد، هرچند ممکن است ابزارهای lint آن را «بدسبک» بدانند.
- اگر linter ایراد گرفت، می‌توانید خروجی یک شاخه را به یک متغیر مشترک نسبت دهید و سپس همان متغیر را `return` کنید.
