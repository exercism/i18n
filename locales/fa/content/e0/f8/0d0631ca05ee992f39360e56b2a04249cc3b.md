# مثال

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

خطوطی که با نقطه شروع می‌شوند «دستورالعمل» هستند: دستوراتی برای اسمبلر، نه برای پردازنده.
`.equ` اسم `FRAME_SIZE` را به عدد ۱۶ می‌دهد.
`.text` می‌گوید که آنچه در ادامه می‌آید کد است.
`.global` برچسب `is_triple` را برای بیرون از این فایل قابل مشاهده می‌کند، تا کدهای دیگر بتوانند آن را فراخوانی کنند.
ممکن است `.globl` را هم ببینید، که همین معنی را می‌دهد.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` بررسی می‌کند که آیا `a² + b² = c²`، اگر چنین باشد ۱ برمی‌گرداند و در غیر این صورت ۰.
برای مثال، `(6, 8, 10)` مقدار ۱ را می‌دهد، چون `36 + 64 = 100`.
برچسب `is_triple` مشخص می‌کند که تابع از کجا شروع می‌شود.
این تابع با `a`، `b` و `c` در ثبات‌های `a0`، `a1` و `a2` فراخوانی می‌شود.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

ثبات `ra` «نشانی بازگشت» را نگه می‌دارد، جایی در فراخوانی‌کننده که پس از پایان کار باید به آنجا برگردیم.
هر `call` مقدار `ra` را بازنویسی می‌کند، بنابراین ابتدا آن را روی «پشته» ذخیره می‌کنیم.
پشته به سمت پایین رشد می‌کند، به سمت نشانی‌های کوچک‌تر، بنابراین کم کردن ۱۶ از اشاره‌گر پشته `sp` برای ما ۱۶ بایت رزرو می‌کند.
(`sp` باید همیشه مضربی از ۱۶ باشد.)
همچنین `b` و `c` را ذخیره می‌کنیم، چون تابعی که فراخوانی می‌کنیم مجاز است ثبات‌های `a` را تغییر دهد.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` از قبل در `a0` قرار دارد، جایی که `square` ورودی خود را انتظار دارد.
`call` مقدار `ra` را روی دستور بعدی تنظیم می‌کند و به `square` می‌پرد، که نتیجه‌اش را در `a0` برمی‌گرداند.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

`b` را از پشته بارگذاری می‌کنیم، آن را به توان دو می‌رسانیم و به `a * a` اضافه می‌کنیم.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

تفاضل دقیقاً وقتی صفر است که `a² + b² = c²`.
`seqz` («تنظیم اگر برابر صفر باشد») آن را به ۱ یا ۰ تبدیل می‌کند.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

`ra` را بازیابی می‌کنیم و ۱۶ بایت پشته را برمی‌گردانیم.
سپس `ret` به نشانی موجود در `ra` می‌پرد، و به فراخوانی‌کننده برمی‌گردد.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` هیچ تابع دیگری را فراخوانی نمی‌کند، بنابراین `ra` دست‌نخورده می‌ماند و چیزی برای ذخیره کردن وجود ندارد.
با `.global` علامت‌گذاری نشده است، چون فقط `is_triple` از آن استفاده می‌کند.
