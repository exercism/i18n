# مقدمه

`vector` در Clojure یک مجموعه‌ی ترتیبی، ایندکس‌شده و تغییرناپذیر از صفر یا چند مقدار است. یعنی وقتی وکتوری ساخته شد، دیگر نمی‌توان آن را تغییر داد. توابعی که روی وکتورها کار می‌کنند یک وکتور جدید برمی‌گردانند و وکتور اصلی بدون تغییر می‌ماند. مقادیر داخل یک وکتور می‌توانند از انواع متفاوت باشند. وکتورها را می‌توان به این شکل تعریف کرد:

```clojure
(def empty [])
(def single-value [5])
```

می‌توان با استفاده از یک اندیس، عناصر را از وکتور بازیابی کرد. وکتورهای Clojure صفرمبنا هستند، یعنی اندیس اولین عنصر همیشه صفر است:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

وکتور اصلی بدون تغییر می‌ماند:

```clojure
numbers
;;=> [2 3 5]
```

برای اینکه مقدار به‌روزرسانی‌شده را به خاطر بسپاریم، باید آن را همراه ببریم یا در یک «var» نگه داریم:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
