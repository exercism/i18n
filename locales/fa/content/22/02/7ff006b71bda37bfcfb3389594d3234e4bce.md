# درباره

«لیست» در Gleam مجموعه‌ای تغییرناپذیر از صفر یا چند مقدار است. تمام مقادیر یک لیست باید نوع یکسانی داشته باشند. چون لیست‌ها تغییرناپذیرند، پس از ساخته‌شدن یک لیست، مقدارش هرگز تغییر نمی‌کند. هر تابع یا عملگری که به نظر می‌رسد لیست را تغییر می‌دهد (مثلاً با افزودن یک عنصر)، در واقع لیست جدیدی برمی‌گرداند.

لیست‌ها را می‌توان به این شکل تعریف کرد:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

رایج‌ترین راه برای افزودن یک عنصر به یک لیست، اضافه‌کردن آن به ابتدای لیست با نحوه‌ی نگارش گسترش است:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

ماژول [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) در کتابخانه‌ی استاندارد Gleam توابع مفید زیادی برای کار با لیست‌ها در خود دارد. این ماژول در کدهای Gleam بسیار پرکاربرد است، پس خوب است که با آن آشنا باشید.

می‌توان از «الگوهای لیست» در عبارت‌های `case` استفاده کرد تا با لیست‌ها تطبیق داده شود و مقادیر موجود در آن‌ها به متغیرها نسبت داده شود:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

علاوه بر تطبیق با لیست‌هایی با طول دقیق مشخص، می‌توان از نحوه‌ی نگارش گسترش برای تطبیق با لیست‌هایی با حداقل طول مشخص استفاده کرد:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

همچنین می‌توان از نحوه‌ی نگارش گسترش برای نسبت دادن بقیه‌ی لیست به یک متغیر استفاده کرد:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

عبارت‌های `case` باید برای هر مقدار ممکن از نوعی که با آن تطبیق داده می‌شوند یک الگو داشته باشند، بنابراین اغلب از یک الگوی نادیده‌گرفتن (`_`) در انتها استفاده می‌شود تا هر مقدار باقی‌مانده را پوشش دهد.
