# درباره

انواع عددی داخلی در C++ را می‌توان به اعداد صحیح و اعداد اعشاری تقسیم کرد.
اعداد صحیح، اعداد کامل هستند؛ مانند `0`، `691` یا `-2`.
اعداد اعشاری، اعدادی هستند که ممیز اعشاری دارند؛ مانند `6.02214076`، `0.1` یا `-1.616`.

## اعداد صحیح

مثال زیر اعلان و مقداردهی اولیه‌ی چهار متغیر متفاوت را نشان می‌دهد

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

وقتی مقداری را به یک متغیر `int` نسبت می‌دهید، می‌توانید این کار را مستقیماً با یک مقدار ثابت انجام دهید.
مقدار ثابت، عددی است که مستقیماً در کد نوشته شده است؛ مانند `9241`.
برای مبنّاهای مختلف نمایش، مقدارهای ثابت صحیح متفاوتی وجود دارد.
مقدارهای ثابت صحیح دهدهی رایج‌ترین هستند و از ارقام `0` تا `9` استفاده می‌کنند.
با افزودن یک پیشوند ویژه، مانند `0x`، می‌توان از مبناهای دیگر استفاده کرد.
مثال بالا عدد `9421` را در چهار نمایش و پیشوندش نشان می‌دهد.
همه‌ی متغیرها به مقدار یکسان مقداردهی اولیه می‌شوند.

برای جزئیات بیشتر درباره‌ی سیستم‌های نمایش مختلف، نگاهی به [آموزش کوچکی][cpp_numerical_bases] بیندازید.

می‌توانید برای خوانایی بهتر از یک آپاستروف برای جدا کردن ارقام استفاده کنید.
`9'241` با `0b0100'100'0001'1001` یا `92'4'1` یکسان است.

## اعداد اعشاری

مقدارهای ثابت اعشاری به دو شکل وجود دارند.
علاوه بر شکل شهودی `0.0024`، می‌توان از نماد علمی آن، `2.4e-3`، نیز استفاده کرد.
رایج‌ترین نوع اعشاری `double` است.

## حساب

C++ از `+`، `-`، `*`، `/`، `(` و `)` و `%` برای ساختن عبارت‌ها پشتیبانی می‌کند.
نتیجه‌ی عملیات بین دو عدد صحیح نیز یک عدد صحیح است.
`5 / 2` مقدار `2` را برمی‌گرداند.
وقتی یکی از انواع درگیر یک نوع اعشاری باشد، نتیجه نیز اعشاری خواهد بود.
`5.0 / 2` و `5 / 2.0` مقدار `2.5` را برمی‌گردانند.
`%` عملگر باقیمانده است و باقیمانده‌ی تقسیم صحیح را برمی‌گرداند: `5%3` برابر `2` است.

## عملگر انتساب

عملگر انتساب، یک مقدار ثابت را به یک متغیر نسبت می‌دهد.
این کار همیشه از راست به چپ انجام می‌شود، نه برعکس.

```cpp
int length = 5;
int width = 2;
length = width;
```

اینجا مقدار صحیح `5` به متغیر `length` نسبت داده می‌شود.
سپس مقدار صحیح `2` به متغیر `width` نسبت داده می‌شود.
در نهایت، مقدار `width` در متغیر `length` کپی می‌شود و مقدار پیشین `5` از دست می‌رود.
همچنین در نظر بگیرید که ما فقط در لحظه‌ی عملیات انتساب، مقدار `width` را به `length` نسبت می‌دهیم.
بنابراین، اگر مقدار `width` در زمانی بعدتر تغییر کند، بر مقداری که `length` گرفته است تأثیری نخواهد داشت.

عملگر انتساب را می‌توان با عملگرهای دیگر (حسابی و بیتی) ترکیب کرد که به آن‌ها عملگرهای `compound assignment` می‌گویند: `+=`، `-=`، `*=`، `/=`، `%=`.
این عملگرها با انجام یک عملیات روی مقدار فعلی یک متغیر، آن را تغییر می‌دهند.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

متغیرهای `people` و `eggs` به `0` مقداردهی اولیه می‌شوند.
سپس، مقدار صحیح `2` را به مقدار موجود `0` متغیر `people` اضافه می‌کنیم و نتیجه را دوباره به `people` نسبت می‌دهیم.
اکنون `people` برابر `2` می‌شود.
بعد، برای هر نفر `3` تخم‌مرغ اضافه می‌کنیم که در مجموع `6` تخم‌مرغ می‌شود.
حالا این `6` را به مقدار موجود `0` متغیر `eggs` اضافه می‌کنیم و نتیجه را دوباره به `eggs` نسبت می‌دهیم.
اکنون `eggs` برابر `6` خواهد بود.
عبارت معادل آن `people = people + 2` و `eggs = eggs + (3 * people)` خواهد بود.

## تبدیل نوع

تبدیل نوع، تبدیل یک نوع به نوعی دیگر است.
اگر به یک `double` نیاز باشد، می‌توان از یک `int` به‌جای آن استفاده کرد.
مثال `5.0 / 2` از بالا با تبدیل ضمنی `2` به `2.0` انجام می‌شود.
یک `double` که به `int` تبدیل شود، ممکن است اطلاعات از دست بدهد.
روش خوبی است که این تبدیل‌ها به نوع دیگر T را به‌صورت صریح و با `static_cast<T>` انجام دهید.
تبدیل قدیمی به سبک C با `(T)` در C++ مدرن توصیه نمی‌شود، اما بهتر است با آن آشنا باشید.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## دقت و نمایش

اعداد در C++ نمی‌توانند به‌طور دلخواه بزرگ باشند.
برای مثال، `int` با ۳۲ بیت نمایش داده می‌شود.
این مقدار برای مجموعه‌ای از `2^32` عدد کافی است، یعنی حدود ۴ میلیارد.
با احتساب `0`، این مقدار بزرگ‌ترین و کوچک‌ترین اعداد `int` را به‌صورت `-2^31` و `2^31 - 1` تعیین می‌کند.

اعداد اعشاری معمولاً با دقت ۱۵ رقم اعشاری پیاده‌سازی می‌شوند، اما نمایش آن‌ها بسته به سیستم میزبان متفاوت است.
