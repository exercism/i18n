# درباره

[Reason](https://reasonml.github.io/) یک روش نگارش و زنجیره‌ی ابزار است که برای برنامه‌نویسان JavaScript طراحی شده و بر پایه‌ی زبان تابعی [OCaml](https://ocaml.org/) است.

از آنجا که به‌صورت ایستا نوع‌دهی شده است، احتمالاً از JavaScript ایمن‌تر است، اما استنتاج نوع قدرتمندی دارد؛ یعنی حاشیه‌نویسی‌های نوع مانع شما نمی‌شوند.

تمرین‌های Exercism مستقیماً به JS کامپایل می‌شوند، اما Reason را می‌توان از طریق زنجیره‌ی ابزار OCaml به کد بومی، iOS، Android و حتی [ریزکنترل‌گرها](http://www.algo-prog.info/ocapic/web/index.php?id=ocapic) کامپایل کرد.
