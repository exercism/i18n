# تست‌ها

## فایل‌های تمرین

تمرینی که دانلود می‌کنید شامل این فایل‌ها برای ساخت و تست راه‌حل‌تان است:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

اسم فایل‌ها از تمرینی به تمرین دیگر فرق می‌کند.
راه‌حل خود را در فایل `.vb`ی بنویسید که اسمش به `Tests` ختم نمی‌شود.
فایلی که به `Tests.vb` ختم می‌شود، مجموعه‌ی تست xUnit است؛ معمولاً فقط برای حذف آرگومان‌های `Skip` باید آن را ویرایش کنید.
معمولاً نیازی نیست فایل پروژه یا فایل قفل را ویرایش کنید.

## اجرای تست‌ها

یک ترمینال در پوشه‌ی تمرین باز کنید و اجرا کنید:

```bash
dotnet test
```

این دستور وابستگی‌های پروژه را بازیابی می‌کند، پروژه را می‌سازد و تست‌هایش را اجرا می‌کند.
همچنین می‌توانید از `dotnet watch test` استفاده کنید تا هر بار که یک فایل منبع تغییر کرد، تست‌ها را دوباره اجرا کنید.

## تست‌های نادیده‌گرفته‌شده

تمرین‌ها در ابتدا فقط اولین تست را فعال می‌کنند تا بتوانید بقیه را گام‌به‌گام حل کنید.
برای پیدا کردن تست‌ها، فایلی را باز کنید که به `Tests.vb` ختم می‌شود.
هر تست یک زیرروال `Sub` است که با ویژگی `<Fact>` در xUnit مشخص شده است.
تا وقتی ویژگی `<Fact>` یک تست آرگومان `Skip` داشته باشد، آن تست نادیده گرفته می‌شود:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

برای فعال کردن تست، کافی است آرگومان `Skip` را حذف کنید:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

پس از اینکه تستی که تازه فعال کرده‌اید با موفقیت پاس شد، همین کار را با تست نادیده‌گرفته‌شده‌ی بعدی تکرار کنید.
وقتی همه‌ی تست‌ها فعال و پاس شده باشند، کارتان تمام است.
