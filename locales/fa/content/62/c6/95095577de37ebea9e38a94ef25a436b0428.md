# مقدمه

## تنظیم‌کننده‌های زمانی

وقتی با اشیایی از نوع `java.time` مانند `LocalDate` کار می‌کنید، اغلب لازم است تنظیم‌های پیچیده‌ای روی تاریخ انجام دهید، مثل پیدا کردن «دومین سه‌شنبه‌ی ماه».
به‌جای اینکه این کار را دستی حساب کنید، می‌توانید از **`TemporalAdjusters`** استفاده کنید.

کلاس کمکی `java.time.temporal.TemporalAdjusters` (به حرف جمع «s» در انتهای اسم دقت کنید) متدهای ایستایی برای بسیاری از تنظیم‌های رایج تاریخ در اختیارتان می‌گذارد.
این تنظیم‌ها را با متد `.with()` روی یک شیء زمانی (مانند `LocalDate`) اعمال می‌کنید.

```exercism/note
استفاده از `with(TemporalAdjuster)` یک نمونه‌ی _تازه_ برمی‌گرداند و نمونه‌ی موجود را به‌روزرسانی نمی‌کند، چون اشیای `java.time` تغییرناپذیرند.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

در ادامه چند تنظیم‌کننده‌ی کلیدی را می‌بینید که برای محاسبات زمان‌بندی مفیدند:

### یافتن روز مشخص هفته در ماه

از `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` استفاده کنید تا nاُمین بار تکرار یک روز هفته را در ماه پیدا کنید.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### یافتن اولین/آخرین روز هفته در ماه

از `firstInMonth(DayOfWeek dayOfWeek)` یا `lastInMonth(DayOfWeek dayOfWeek)` استفاده کنید.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### تنظیم‌های نسبی (بعدی/قبلی)

تنظیم‌کننده‌هایی مثل `next()`، `previous()`، `nextOrSame()` و `previousOrSame()` نزدیک‌ترین وقوع بعدی یا قبلی یک روز مشخص از هفته را نسبت به تاریخ جاری پیدا می‌کنند.

- `next()`/`previous()`: اگر تاریخ جاری با آن روز مطابقت داشته باشد، آن را در نظر نمی‌گیرد.
- `nextOrSame()`/`previousOrSame()`: اگر تاریخ جاری با آن روز مطابقت داشته باشد، آن را هم در نظر می‌گیرد.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### تنظیم‌کننده‌های سفارشی

`TemporalAdjuster` یک رابط تابعی است، پس می‌توانید تنظیم‌کننده‌ی خودتان را به‌صورت یک لامبدا بنویسید که شیء زمانی موردنظر برای تنظیم را می‌گیرد و نمونه‌ی تنظیم‌شده را برمی‌گرداند.
دقیقاً مانند تنظیم‌کننده‌های از پیش تعریف‌شده با `.with()` اعمال می‌شود و می‌تواند در داخل خودش از آن‌ها استفاده کند.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

استفاده از این تنظیم‌کننده‌های کلاس `TemporalAdjusters` می‌تواند کارهای دستکاری تاریخ را بسیار ساده‌تر کند.
