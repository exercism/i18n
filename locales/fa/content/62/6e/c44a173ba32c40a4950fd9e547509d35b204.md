# دستورالعمل‌ها

در این تمرین، شما با یک دوست مشغول بازی حدس عدد هستید. قواعد ساده است: شما به‌طور مخفیانه عددی بین `1` و `100` انتخاب می‌کنید و دوستتان تلاش می‌کند حدس بزند چه عددی را انتخاب کرده‌اید. برای اینکه به دوستتان کمک کنید، بسته به اینکه حدس چقدر به عددی که انتخاب کرده‌اید (`42`) نزدیک بوده، پاسخ متفاوتی می‌دهید. این‌ها قواعد پاسخ‌های مختلف هستند:

- اگر حدس `42` باشد: «Correct»
- اگر حدس `41` یا `43` باشد: «So close»
- اگر حدس کمتر از `41` باشد: «Too low»
- اگر حدس بیشتر از `43` باشد: «Too high»

شما چهار وظیفه دارید که پاسخ حدس‌ها را کدنویسی کنید.

## 1. پاسخ به یک حدس درست

تابع `reply` را پیاده‌سازی کنید تا به یک حدس درست پاسخ دهد:

```fsharp
reply 42
// => "Correct"
```

## 2. پاسخ به یک حدس نزدیک

تابع `reply` را تغییر دهید تا به حدس‌های نزدیک پاسخ دهد:

```fsharp
reply 41
// => "So close"
```

## 3. پاسخ به حدس‌های خیلی پایین

تابع `reply` را تغییر دهید تا به حدس‌های خیلی پایین پاسخ دهد:

```fsharp
reply 25
// => "Too low"
```

## 4. پاسخ به حدس‌های خیلی بالا

تابع `reply` را تغییر دهید تا به حدس‌های خیلی بالا پاسخ دهد:

```fsharp
reply 88
// => "Too high"
```
