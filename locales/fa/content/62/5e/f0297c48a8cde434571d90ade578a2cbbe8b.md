# راهنمایی‌ها

## 1. بررسی کنید که غذا درست است

- می‌توانید از دستور شرطی [`if`][if] استفاده کنید تا بررسی کنید که غذا درست است.

## 2. بررسی کنید که نوشیدنی مسموم است

- [متدی][downcase] برای تبدیل یک رشته به حروف کوچک وجود دارد.
- می‌توانید با استفاده از [`String#includes?`][includes?] بررسی کنید که یک رشته کاراکتر مشخصی دارد یا نه.

## 3. نوشیدنی را عوض کنید

- می‌توانید از متدهایی که از قبل پیاده‌سازی شده‌اند استفاده کنید تا بررسی کنید که نوشیدنی مسموم است یا نه.
- [عملگری][or] وجود دارد که می‌توان از آن برای برگرداندن اولین مقدار درست استفاده کرد.
