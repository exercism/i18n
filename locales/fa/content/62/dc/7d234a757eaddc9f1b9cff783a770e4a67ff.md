# مقدمه

## تصادفی بودن

می‌توان از یک نمونه از کلاس `java.util.Random` برای تولید اعداد تصادفی در Java استفاده کرد.

### اعداد صحیح تصادفی

می‌توان با استفاده از متد `nextInt()` یک عدد صحیح تصادفی تولید کرد.
این کار مقداری در بازه‌ی `Integer.MIN_VALUE` تا `Integer.MAX_VALUE` تولید می‌کند.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

برای محدود کردن بازه‌ی مقادیر تولیدشده، از `nextInt(int)` استفاده کنید.
این کار مقداری در بازه‌ی `0` (شامل) تا کران بالای مشخص‌شده (غیرشامل) تولید می‌کند.

برای مثال، این کد عددی تصادفی از `0` تا `9` تولید می‌کند.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

و این کد عددی تصادفی از `10` تا `19` تولید می‌کند.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### اعداد اعشاری تصادفی

می‌توان با استفاده از متد `nextDouble()` یک عدد اعشاری تصادفی تولید کرد.
این کار مقداری در بازه‌ی `0.0` تا `1.0` تولید می‌کند.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

و این کد عددی تصادفی از `100.0` تا `200.0` تولید می‌کند.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
