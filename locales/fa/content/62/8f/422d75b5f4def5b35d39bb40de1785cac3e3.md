# دستورالعمل‌ها

در این تمرین، مجموعه‌ای ناقص از روال‌های کمکی را پیاده‌سازی می‌کنید تا به یک برنامه‌نویس در تمیز کردن اسم‌های شناسه کمک کنید.
در این ۵ تمرین، روال `Clean` را به‌تدریج کامل می‌کنید.
یک شناسه‌ی معتبر از صفر یا چند حرف و زیرخط تشکیل شده است.
در همه‌ی حالت‌ها، تضمین شده است که رشته‌ی ورودی هرگز `null` نیست.
اگر رشته‌ی خالی به تابع `Clean` داده شود، باید رشته‌ی خالی برگردانده شود.
توجه کنید که فراخوان‌کننده باید از فراخوانی روال `Clean` با یک شناسه‌ی خالی پرهیز کند، چون چنین شناسه‌هایی بی‌اثرند.

## 1. هر فاصله‌ای را با زیرخط جایگزین کنید

متد (_static_) `Identifier.Clean()` را طوری پیاده‌سازی کنید که هر فاصله را با زیرخط جایگزین کند.
این موضوع برای فاصله‌های ابتدا و انتهای رشته هم صدق می‌کند.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. نویسه‌های کنترلی را با رشته‌ی «CTRL» با حروف بزرگ جایگزین کنید

متد (_static_) `Identifier.Clean()` را طوری تغییر دهید که نویسه‌های کنترلی را با رشته‌ی `"CTRL"` با حروف بزرگ جایگزین کند.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. kebab-case را به camelCase تبدیل کنید

متد (_static_) `Identifier.Clean()` را طوری تغییر دهید که kebab-case را به camelCase تبدیل کند.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. نویسه‌هایی را که حرف نیستند حذف کنید

متد (_static_) `Identifier.Clean()` را طوری تغییر دهید که هر نویسه‌ای را که حرف نیست حذف کند.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. حروف کوچک یونانی را حذف کنید

متد (_static_) `Identifier.Clean()` را طوری تغییر دهید که هر حرف یونانی در بازه‌ی 'α' تا 'ω' را حذف کند.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
