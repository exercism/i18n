# مقدمه

## With

شکل خاص [`with`][with] راهی فراهم می‌کند تا روی «مسیر موفق» مجموعه‌ای از گام‌های بالقوه ناموفق تمرکز کنید و بعداً به شکست‌ها رسیدگی کنید.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

در هر گام، اگر بندی مطابقت کند، زنجیره ادامه می‌یابد تا اینکه بلوک `do` اجرا شود. اگر یک مطابقت شکست بخورد، زنجیره متوقف می‌شود و بند نامطابق برگردانده می‌شود. این امکان را دارید که از یک بلوک `else` استفاده کنید تا مطابقت‌های ناموفق را بگیرید و مقدار بازگشتی را تغییر دهید.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
