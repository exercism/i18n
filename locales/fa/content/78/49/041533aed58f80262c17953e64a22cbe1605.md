# نصب

برای کار روی تمرین‌ها به این نرم‌افزارها نیاز دارید:

1. [`OPAM`، مدیر بسته‌ی OCaml](https://opam.ocaml.org/)

   برای این که بدانید چطور `OPAM` را روی سیستم‌عامل خودتان نصب و پیکربندی کنید، [راهنمای نصب Real World OCaml، ویرایش دوم](https://dev.realworldocaml.org/install.html) را ببینید.

2. کامپایلر OCaml

   فهرست نسخه‌های موجود را ببینید:

   ```bash
   opam switch
   ```

   اگر از قبل یک «سوییچ» برای OCaml ۵.۱ دارید، یا آن را با اجرای `opam switch <switch-name>` بارگذاری کنید، یا با اجرای دستور زیر سوییچ تازه‌ای بسازید:

   ```bash
   opam switch create exercism 5.4.0
   ```

   اسم `exercism` در اینجا اختیاری است، اما این که به سوییچ‌هایتان اسم بدهید، کار خوبی است.

3. نصب کتابخانه‌های استاندارد گسترده و کتابخانه‌های تست

   برای نصب وابستگی‌هایی که این مسیر نیاز دارد، دستور زیر را اجرا کنید:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   بعضی تمرین‌ها فقط از کتابخانه‌ی استاندارد OCaml استفاده می‌کنند و بعضی از کتابخانه‌های گسترده‌ی شرکت Jane Street به اسم Base و Core_kernel.
   کتابخانه‌ی تست OUnit نام دارد و بعضی تمرین‌ها به‌علاوه از کتابخانه‌ی QCheck برای تست‌های مبتنی بر ویژگی استفاده می‌کنند.
   با اجرای دستور بالا این کتابخانه‌ها نصب می‌شوند.

4. نصب و استفاده از شل تعاملی (اختیاری)

   خلاصه‌ای از [راه‌اندازی و استفاده از `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   فایل تازه‌ای به اسم `.ocamlinit` در پوشه‌ی خانه‌ی خودتان بسازید و این خط‌ها را به آن اضافه کنید:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. نصب ابزارها در VS Code (اختیاری)

   اگر از VS Code استفاده می‌کنید:
   - سرور زبان OCaml را از [اینجا](https://github.com/ocaml/ocaml-lsp) نصب کنید.
   - افزونه‌ی OCaml برای VS Code را از [اینجا](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform) نصب کنید، یا `OCaml Platform` را از Ocaml Labs جست‌وجو کنید.
