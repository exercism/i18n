# مقدمه

بسیاری از برنامه‌ها برای شبیه‌سازی رویدادهای دنیای واقعی به مقادیر (شبه)تصادفی نیاز دارند.

مثال‌های رایج و آشنا عبارت‌اند از:

- انداختن سکه: مقداری تصادفی از میان ('H', 'T').
- انداختن تاس: یک عدد صحیح تصادفی از ۱ تا ۶.
- بُر زدن یک دسته کارت: ترتیبی تصادفی از فهرست کارت‌ها.
- ساخت درخت‌ها و بوته‌ها در یک شبیه‌سازی گرافیکی سه‌بعدی.

تولید مقادیر واقعاً تصادفی با رایانه [چالشی فنی و به‌طرز شگفت‌آوری دشوار][why-randomness-is-hard] است و به همین دلیل، مولدهای «شبه‌تصادفی» هم وجود دارند.

~~~exercism/advanced
[مشخصات زبان][spec] جاوااسکریپت، پیاده‌سازی تولید اعداد تصادفی را الزامی نمی‌کند.
همه‌ی مرورگرهای اصلی و محیط‌های اجرایی جاوااسکریپت یک PRNG (مولد اعداد شبه‌تصادفی) پیاده‌سازی می‌کنند.
چون این اعداد از نظر رمزنگاری امن نیستند، هرگز نباید برای کارهایی به کار روند که به اعداد تصادفی واقعی یا دست‌کم از نظر رمزنگاری امن نیاز دارند؛ مانند تولید گواهی یا رمز عبور، یا عملیاتی از این دست.

استانداردی به نام [Web Cryptography][rfc] وجود دارد که رابطی برای انجام رمزنگاری در جاوااسکریپت استانداردسازی می‌کند.
این استاندارد هم [توسط مرورگرها][crypto-web] پیاده‌سازی شده است و هم توسط محیط‌های اجرایی‌ای مانند [Node.JS][crypto-node] و [Deno][crypto-deno].

این مفهوم درباره‌ی Web Crypto نیست و خود را به تولید اعداد شبه‌تصادفی محدود می‌کند.

## تولید اعداد تصادفی

در جاوااسکریپت می‌توانید با استفاده از تابع [`Math.random()`][Math.random] اعداد شبه‌تصادفی تولید کنید.
این تابع یک عدد اعشاری شبه‌تصادفی بین ۰ (شامل) و ۱ (غیرشامل) برمی‌گرداند.

برای گرفتن عددی تصادفی بین _min_ (شامل) و _max_ (غیرشامل)، می‌توانید از تابعی تقریباً مانند این استفاده کنید:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## تولید اعداد صحیح تصادفی

برای تولید یک عدد صحیح تصادفی، می‌توانید از `Math.floor()` یا `Math.ceil()` استفاده کنید تا عدد تولیدشده‌ی تصادفی را به عدد صحیح تبدیل کنید.

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
