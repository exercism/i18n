# مقدمه

با توجه به اینکه اسم زبانی که داریم استفاده می‌کنیم، یعنی Lisp، مخفف _LIST Processing_ است، ممکن است فکر کنید این زبان امکاناتی برای کار با لیست‌هایی از عناصر دارد و حق با شماست!

هرچند Common Lisp ساختارهای داده‌ای غیر از لیست هم دارد، لیست‌ها هنوز بسیار پرکاربردند.

یک لیست در Common Lisp دنباله‌ای از عناصر است. به آن **cons** هم می‌گویند (بیشتر به دلایل تاریخی).
خود عناصر لازم نیست از یک نوع باشند.
برای مثال می‌توانید لیستی از `1`، `two` و `"III"` داشته باشید.

## ساختن لیست‌ها

می‌توانید به‌سادگی یک لیست نقل‌قول‌شده به این شکل تایپ کنید: `'(1 two "III")` و این کار باعث می‌شود یک لیست ساخته و ارزیابی شود (نتیجه‌ی ارزیابی آن `(1 two "III")` است).

همچنین دو تابع اصلی برای ساختن لیست وجود دارد: `list` و `cons`.

`list` صفر یا چند آرگومان می‌گیرد و به لیستی ارزیابی می‌شود که با آن مقادیر ساخته شده است:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` دو عنصر می‌گیرد و لیستی می‌سازد که عنصر اولش `car` آن (سر لیست) و عنصر دومش `cdr` آن (بقیه‌ی لیست) است:

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

از توابع `car` و `cdr` می‌توان برای دسترسی به `car` و `cdr` یک لیست استفاده کرد.

(`first` و `rest` مترادف‌های `car` و `cdr` هستند و دقیقاً یکسان کار می‌کنند.)

## طول و دسترسی تصادفی

طول یک لیست را می‌توان با استفاده از `length` مشخص کرد.
طول یک لیست خالی صفر است.

به یک عنصر دلخواه می‌توان با `nth` دسترسی داشت (توجه کنید که اندیس‌گذاری لیست‌ها از صفر شروع می‌شود).

درخواست اندیسی که از طول لیست بزرگ‌تر باشد _خطا نیست_.
در عوض، به `nil` ارزیابی می‌شود:

```lisp
(nth 23 '(short list)) ; => nil
```

## ترکیب لیست‌ها

دو یا چند لیست را می‌توان با `append` ترکیب کرد: 

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

هر آرگومانی که به `append` داده می‌شود باید یک لیست باشد.
