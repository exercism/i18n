# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که فهرستی از زبان‌های برنامه‌نویسی را که می‌خواهید در Exercism یاد بگیرید، پیگیری کند.

شش کار دارید که همگی به کار با فهرست‌ها مربوط می‌شوند.

## 1. یک فهرست تازه بسازید

برای پیگیری زبان‌هایی که می‌خواهید یاد بگیرید، باید یک فهرست تازه بسازید. پیوند `newList` را تعریف کنید که دربردارنده‌ی یک فهرست تازه و خالی است.

```fsharp
newList
// => []
```

## 2. یک فهرست موجود را تعریف کنید

در حال حاضر، کاغذی دارید که زبان‌هایی را که می‌خواهید یاد بگیرید روی آن نوشته شده‌اند: F#، Clojure و Haskell. پیوند `existingList` را تعریف کنید تا این فهرست را نشان دهد.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. یک زبان تازه به فهرست اضافه کنید

همان‌طور که Exercism را کاوش می‌کنید و زبان‌های جالب‌تری پیدا می‌کنید، می‌خواهید آن‌ها را به فهرستتان اضافه کنید. تابع `addLanguage` را پیاده‌سازی کنید که یک زبان تازه را به ابتدای فهرست شما اضافه می‌کند.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. زبان‌های فهرست را بشمارید

شمردن زبان‌ها یکی‌یکی کار راحتی نیست. تابع `countLanguages` را پیاده‌سازی کنید تا تعداد زبان‌های فهرست شما را بشمارد.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. فهرست را برعکس کنید

یک جایی متوجه می‌شوید که فهرستتان در واقع برعکس مرتب شده است! تابع `reverseList` را پیاده‌سازی کنید تا فهرستتان را برعکس کند.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. بررسی کنید که آیا فهرست هیجان‌انگیز است

هرچند همه‌ی زبان‌ها را دوست دارید، F# جایگاه ویژه‌ای در دل شما دارد. به همین دلیل، اگر شرایط زیر برقرار باشد، از یک فهرست زبان واقعاً هیجان‌زده می‌شوید:

- اولین عنصر فهرست F# باشد.
- دومین عنصر فهرست F# باشد و فهرست یا دو زبان داشته باشد یا سه زبان.

تابع `excitingList` را پیاده‌سازی کنید تا بررسی کند آیا یک فهرست زبان هیجان‌انگیز است:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
