# مقدمه

## عدد

در C# دو نوع مختلف عدد وجود دارد:

- «عدد صحیح»: اعدادی بدون رقم پس از جداکننده‌ی اعشار (اعداد کامل). مثال‌ها: `-6`، `0`، `1`، `25`، `976` و `500000`.
- «عدد اعشاری»: اعدادی با صفر یا چند رقم پس از جداکننده‌ی اعشار. مثال‌ها: `-2.4`، `0.1`، `3.14`، `16.984025` و `1024.0`.

دو نوع عددی رایج در C#، `int` و `double` هستند. `int` یک عدد صحیح ۳۲ بیتی است و `double` یک عدد اعشاری ۶۴ بیتی.

محاسبات با عملگرهای حسابی استاندارد انجام می‌شوند. می‌توان اعداد را با عملگرهای مقایسه‌ی عددی استاندارد و همچنین عملگرهای تساوی (`==`) و نامساوی (`!=`) مقایسه کرد.

C# دو نوع تبدیل عددی دارد:

1. «تبدیل ضمنی»: هیچ داده‌ای از دست نمی‌رود و به نگارش اضافی نیازی نیست.
2. «تبدیل صریح»: ممکن است داده از دست برود و به نگارش اضافی به شکل _cast_ نیاز است.

از آنجا که دقت `int` از `double` کمتر است، تبدیل `int` به `double` ایمن است و بنابراین یک تبدیل ضمنی به حساب می‌آید. اما تبدیل `double` به `int` می‌تواند به از دست رفتن داده منجر شود، پس به یک تبدیل صریح نیاز دارد.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## دستور شرطی

در این تمرین باید منطقی را به‌صورت شرطی اجرا کنید. رایج‌ترین راه برای این کار در C# استفاده از دستور `if/else` است:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

شرط یک دستور `if` باید از نوع `bool` باشد. C# هیچ مفهومی از مقادیر _truthy_ ندارد.
