# کمک

اگر به مشکل خوردید، برای دریافت کمک می‌توانید از یکی از منابع زیر استفاده کنید:

- [The Emacs Wiki](http://emacswiki.org/) بسیار ارزشمند است. زمان زیادی را اینجا بگذرانید.
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) راهنمای رسمی GNU Emacs است.
- IRC: کانال‌هایی در [Libera.Chat](https://libera.chat/) برای `#emacs`، `#org-mode` و بسیاری از بسته‌های Emacs وجود دارد و افراد کمک‌کننده‌ی زیادی هم آنجا هستند. و با emacs، فاصله‌ی شما تا IRC تنها یک `M-x erc` است.
- Matrix: در [Matrix](https://matrix.org/) اتاق‌هایی برای [emacs](https://matrix.to/#/#emacs:matrix.org)، [org-mode](https://matrix.to/#/#org-mode:matrix.org) و بسته‌های دیگر Emacs وجود دارد.
  می‌توانید [به فضای Matrix مربوط به Emacs بپیوندید](https://matrix.to/#/#emacs-space:matrix.org) تا نمای کلی کانال‌های موجود را ببینید.
  برای پیوستن به Matrix از داخل Emacs می‌توانید از بسته‌ی [Ement.el](https://github.com/alphapapa/ement.el) استفاده کنید.
- [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) و [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) را می‌توانید برای جستجوی مشکلتان و دیدن اینکه آیا پیش‌تر پاسخ داده شده است یا نه به کار ببرید. همچنین می‌توانید سؤال بپرسید و به آن‌ها پاسخ دهید.
