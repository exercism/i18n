# ضمیمه‌ی دستورالعمل‌ها

## قابل فراخوانی

در PHP مفهومی به اسم [«قابل فراخوانی»](https://www.php.net/manual/en/language.types.callable.php) وجود دارد.

این‌ها می‌توانند شکل‌های گوناگونی داشته باشند، اما ما روی [«توابع ناشناس»](https://www.php.net/manual/en/functions.anonymous.php) تمرکز می‌کنیم.

می‌توان یک تابع ناشناس را درون یک متغیر ساخت و آن را با پارامترها فراخوانی کرد:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
