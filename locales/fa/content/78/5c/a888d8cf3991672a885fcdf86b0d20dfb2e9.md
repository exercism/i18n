# مقدمه

## AST

درخت نحوه‌ی نگارش انتزاعی (AST)، که به آن _عبارت نقل‌قول‌شده_ هم می‌گویند، روشی برای نمایش کد به‌صورت داده است.

هر گره در AST یک تاپل سه‌عنصری است.

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

عنصر اول، یک اتم، عملیات است. عنصر دوم، یک لیست کلیدواژه، متادیتا است. عنصر سوم لیستی از آرگومان‌هاست که گره‌های دیگر را در خود دارد. مقادیر لیترال مانند اعداد صحیح، اتم‌ها و رشته‌ها در AST به‌جای تاپل‌های سه‌عنصری، خودشان نمایش داده می‌شوند.

### تبدیل کد به AST

تبدیل کد Elixir به AST و تبدیل AST به کد بخشی از کتابخانه‌ی استاندارد است. توابع کار با AST را می‌توانید در ماژول‌های `Code` (مثلاً برای تبدیل رشته‌ای حاوی کد به AST) و `Macro` (مثلاً برای پیمایش AST یا تبدیل آن به رشته) پیدا کنید.

توجه داشته باشید که همه‌ی توابع کتابخانه‌ی استاندارد از اسم `quoted` برای اشاره به AST استفاده می‌کنند (کوته‌نوشتِ _عبارت نقل‌قول‌شده_).

فرم ویژه‌ای که کد را به AST تبدیل می‌کند `quote` نام دارد. این فرم یک بلوک کد می‌گیرد و AST آن را برمی‌گرداند.

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

### موارد استفاده

توانایی نمایش کد به‌صورت AST در قلب فرابرنامه‌نویسی در Elixir قرار دارد. _ماکروها_ که روشی برای نوشتن کد Elixir هستند که خودشان کد Elixir تولید می‌کنند، با برگرداندن AST به‌عنوان خروجی کار می‌کنند.

کاربرد دیگر AST، تحلیل ایستای کد است؛ مانند ابزار خود Exercism، یعنی Analyzer، که ممکن است آن را به‌عنوان ربات کوچکی بشناسید که روی راه‌حل‌های شما کامنت می‌گذارد.
