# پیوست دستورالعمل

## پیاده‌سازی

اقلام با [رکوردها](https://lfe.gitbooks.io/reference-guide/content/16.html)، که در `item.lfe` تعریف شده‌اند، نمایش داده می‌شوند.
برای گرفتن وزن از `item-weight` و برای گرفتن ارزش از `item-value` استفاده کنید.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
