# مقدمه

ABAP چندین نوع عددی دارد. در این تمرین، از دو مورد از آن‌ها استفاده می‌کنید:

- `i` برای مقادیر صحیح، مانند تعداد روزها.
- `p` برای مقادیر اعشاری بسته، مانند نرخ ساعتی یا تخفیف.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

اعداد اعشاری بسته، بیشترین طول و تعداد رقم اعشار خود را تعریف می‌کنند. مقادیر ثابت اعشاری معمولاً به‌صورت مقادیر متنی نوشته می‌شوند و توسط کامپایلر یا با `CONV` به نوع اعشاری مقصد تبدیل می‌شوند.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP توابع عددی توکار برای گرد کردن ارائه می‌دهد. تابع `floor` به سمت پایین تا نزدیک‌ترین عدد صحیح گرد می‌کند و `ceil` به سمت بالا تا نزدیک‌ترین عدد صحیح.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
