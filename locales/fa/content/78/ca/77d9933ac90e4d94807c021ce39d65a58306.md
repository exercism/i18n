# معرفی

## رشته

در Gleam، «رشته» متنی تغییرناپذیر است که بین دو علامت نقل‌قول دوگانه قرار می‌گیرد. رشته‌ها از نویسه‌های یونیکد پشتیبانی می‌کنند و می‌توانند چندخطی باشند.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

می‌توان رشته‌ها را با عملگر `<>` به هم چسباند:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

ماژول [`gleam/string`][stdlib] در کتابخانه‌ی استاندارد، توابعی برای کار با رشته‌ها ارائه می‌دهد.

می‌توان رشته‌ها را در عبارت‌های `case` تطبیق داد:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

اگر می‌خواهید روی ابتدای یک رشته تطبیق دهید و بقیه را به یک متغیر نسبت دهید، می‌توانید از الگوی عملگر `<>` استفاده کنید:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
