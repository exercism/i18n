# دستورالعمل‌ها

دو نوازنده‌ی ویولن در حال تمرین یک دوئت هستند. هر بخش یک آرایه است که تعداد نت‌های هر میزان را در خود نگه می‌دارد و طول بخش‌ها همیشه یکسان نیست.

هر چهار کار در کلاس `DUET_PRACTICE` قرار می‌گیرند.

## 1. چند میزان را با هم می‌نوازند؟

تا زمانی که هر دو بخش میزانی باقی داشته باشند، با هم می‌نوازند.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. چند میزان مطابقت دارند؟

میزان‌هایی را بشمارید که در آن‌ها هر دو بخش تعداد نت یکسانی دارند. فقط میزان‌هایی که هر دو بخش دارند می‌توانند مطابقت داشته باشند.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. کدام‌یک شلوغ‌تر است؟

میزان‌هایی را بشمارید که در آن‌ها بخش اول نت‌های بیشتری از بخش دوم دارد.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. میزان‌ها را وزن‌دهی کنید

میزان‌های بعدی سخت‌ترند، بنابراین هر میزان به اندازه‌ی جایگاهش به حساب می‌آید: میزان اول یک بار شمرده می‌شود، میزان دوم دو بار و میزان سوم سه بار. تعداد نت‌های هر میزان را در شماره‌ی آن ضرب کنید و همه را با هم جمع بزنید.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

یعنی ۱×۴ + ۲×۴ + ۳×۸. شماره‌گذاری میزان‌ها از یک شروع می‌شود، نه از صفر.
