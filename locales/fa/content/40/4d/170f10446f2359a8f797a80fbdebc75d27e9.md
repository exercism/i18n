# نصب

## کدام نسخه را انتخاب کنیم؟

توصیه می‌کنیم از یک نسخه‌ی پایدار PHP با پشتیبانی فعال استفاده کنید.
در حال حاضر این نسخه‌ها **PHP 8.2، 8.3 و 8.4** هستند.
جزئیات مربوط به نسخه‌های کنونی و زمان‌بندی آن‌ها را می‌توانید در [مستندات رسمی PHP](https://www.php.net/supported-versions.php) پیدا کنید.

## نصب PHP

بیشتر مدیرهای بسته برای Linux و macOS بسته‌های از پیش ساخته‌شده را ارائه می‌دهند.
می‌توان PHP را دانلود کرد و از سورس ساخت؛ این موارد در [php.net/downloads.php](https://php.net/downloads.php) یا [windows.php.net/download](https://windows.php.net/download) در دسترس هستند.

~~~~exercism/note
برای تکمیل تمرین‌ها نیازی به وب‌سروری مانند nginx یا Apache HTTP server نیست.
~~~~

### Linux

توزیع‌های مختلف روش‌های متفاوتی دارند.
باید بتوانید

```shell
yum install php
```

یا

```shell
apt-get install php
```

را بسته به مدیر بسته‌ی خودتان اجرا کنید.

برای دستورالعمل‌های بیشتر، بخش [نصب روی سیستم‌های Unix](https://www.php.net/manual/en/install.unix.php) را در دفترچه‌ی PHP بخوانید.

### macOS

هرچند PHP اغلب همراه macOS عرضه می‌شود، ولی معمولاً قدیمی است.
توصیه می‌کنیم PHP را از طریق [Homebrew](https://brew.sh/) نصب کنید.
می‌توانید Homebrew را با دنبال کردن دستورالعمل‌های [صفحه‌ی اصلی‌شان](https://brew.sh/#install) نصب کنید.

برای تأیید نصب، دستور زیر را امتحان کنید؛ در زمان نگارش این متن، باید نسخه‌ی `4.5.x` از Homebrew را نمایش دهد.

```shell
brew --version 
```

نصب PHP با Homebrew

```shell
brew install php@8.4
```

این دستور باید نسخه‌ی نصب‌شده‌ی PHP را نمایش دهد، حداقل نسخه‌ی `8.2.0`.

```shell
php -v
```

برای دستورالعمل‌های بیشتر، بخش [نصب روی macOS](https://www.php.net/manual/en/install.macosx.php) را در دفترچه بخوانید.

### Windows

فایل‌های باینری رسمی PHP برای Windows را می‌توانید از [windows.php.net/download](https://windows.php.net/download) دانلود کنید.

بسته‌های از پیش ساخته‌شده‌ای هم وجود دارد، از جمله [WAMP](https://www.wampserver.com/en/) - (Windows, Apache, MySQL, PHP) و [XAMPP](https://www.apachefriends.org/de/index.html).

برای دستورالعمل‌های بیشتر، بخش [نصب روی سیستم‌های Windows](https://www.php.net/manual/en/install.windows.php) را در دفترچه بخوانید.

### Docker

اگر راه‌حل‌های کانتینری را ترجیح می‌دهید، می‌توانید [ایمیج رسمی PHP را از Docker Hub](https://hub.docker.com/_/php) دانلود کنید.
به [Docker](https://docs.docker.com/engine/install/) هم نیاز خواهید داشت.

### موارد دیگر

اگر می‌خواهید از سیستم‌عامل دیگری استفاده کنید، دستورالعمل‌های [php.net/manual/en/install](https://www.php.net/manual/en/install.php) را ببینید.

### از طریق PHP Archive (PHAR)

ساده‌ترین راه برای استفاده از PHPUnit در تمرین‌های Exercism، دانلود توزیعی است که به‌صورت یک PHP Archive (PHAR) بسته‌بندی شده است؛ این روش، روش توصیه‌شده برای استفاده از PHPUnit هم هست.
فایل PHAR را همان جایی قرار دهید که CLI مربوط به `exercism` را قرار داده‌اید تا بتوانید PHPUnit را از هر جایی اجرا کنید.

می‌توانید یک نسخه از بسته‌های PHPUnit را به‌صورت یک PHP Archive دانلود کنید:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

سپس فایل دانلودشده را اجرایی کنید:

```shell
chmod +x phpunit.phar
```

و آن را به همان جایی منتقل کنید که CLI مربوط به `exercism` را منتقل کرده‌اید و نام دستور را `phpunit` بگذارید:

```shell
mv phpunit.phar ~/bin/phpunit
```

حالا می‌توانید `phpunit` را از هر جایی اجرا کنید، همان‌طور که در [مستندات تستِ مسیر PHP](https://exercism.org/docs/tracks/php/tests) نشان داده شده است:

```shell
phpunit --version
```

خروجی باید چیزی شبیه این باشد:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

همچنین می‌توانید برای نصب PHPUnit، [دستورالعمل‌های رسمی نصب PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) را دنبال کنید.

### از طریق Composer

نسخه‌ی 11 PHPUnit را می‌توان از طریق [Composer](https://getcomposer.org) هم نصب کرد.

#### نصب Composer

[Composer](https://getcomposer.org) را با دنبال کردن [دستورالعمل‌های نصب](https://getcomposer.org/doc/00-intro.md) سیستم‌عامل دستگاه‌تان نصب کنید. برای راحتی استفاده، توصیه می‌کنیم آن را به‌صورت سراسری نصب کنید.

#### افزودن PHPUnit به‌عنوان ابزار سراسری

با استفاده از دستور زیر:

```shell
composer global require phpunit/phpunit ^11.5
```

لطفاً مطمئن شوید نسخه‌ی 11.5 یا جدیدتر را نصب می‌کنید.
