# Tests

قبل از اینکه testها را اجرا کنید، مطمئن شوید که پوشه‌ی تمرین درست راه‌اندازی شده است؛ برای این کار مراحل نصب را دنبال کنید: `corepack yarn install` و راه‌اندازی Editor SDK.

testها را با این دستور اجرا کنید:

```bash
$ corepack yarn test
```

## testهای skipشده

در مجموعه‌ی testها همه‌ی testها به‌جز اولین مورد skip شده‌اند.

وقتی یک test را با موفقیت پاس کردید، می‌توانید با تغییر `xit` به `it`، test بعدی را فعال کنید.
علاوه بر این، ممکن است testها با `xdescribe` گروه‌بندی شده باشند.
با تغییر آن به `describe`، آن گروه را فعال کنید.
در نهایت، ممکن است برخی تمرین‌ها testهای اختیاری `it.skip` داشته باشند.
برای اجرای test اختیاری، `.skip` را حذف کنید.
