# درباره

نوع `Option` یک enum است که کتابخانه استاندارد ارائه می‌دهد. برای بیان مقداری که ممکن است وجود نداشته باشد مفید است.
گرچه ممکن است این شبیه `null` یا `nil` به نظر برسد، اما کاملاً متفاوت و خاص است.

`Option<T>` انواع دیگر را در خود نگه می‌دارد و دو گونه دارد: `Some(T)` و `None`.

برای مثال، `Option<u32>` نوع `u32` را در خود نگه می‌دارد.

## کاربرد

### استفاده از `T` درون `Option<T>`

چندین الگوی رایج برای استفاده از مقداری که ممکن است در یک `Option` حضور داشته باشد وجود دارد:

- `if let Some(t) = optional { ... }`.

    الگوی `if let` مقدار را از `Option<T>` استخراج می‌کند و آن را به متغیر `t` مقید می‌کند. این به شما اجازه می‌دهد که مستقیماً در دامنه‌ی همان بلوک از آن استفاده کنید.

- `match optional { Some(t) => {...}, None => {...}}`

    عملگر `match` نیز به شما اجازه می‌دهد که حالت‌های `None` را در یک دستور یا عبارت باز کنید و مدیریت کنید. این جایگزینی برای زنجیره‌ای از دستورهای if و else است. استفاده از `match` می‌تواند خوانایی برخی بخش‌های کد را افزایش دهد.
- `optional.map(|t| ...)`
   `Option::map` یک `Option` را با تابع ارائه‌شده، در جای خود و به‌طور بالقوه با یک نوع جدید، به‌روزرسانی می‌کند.

   **توجه**: اگر مقدار درون آن موجود باشد، روی آن عمل می‌کند. مقدار مقیدشده به یک `Option<U>` تبدیل می‌شود، که در آن بستار داده‌شده `FnOnce(T) -> U` است.
- `optional.unwrap()`.
   `unwrap` کردن یک `Option<T>` مقدار `T` را استخراج می‌کند، اما اگر `T` وجود نداشته باشد، panic می‌کند. در برخی موارد راهگشا است.

   **مهم**: `unwrap` کردن می‌تواند در کوتاه‌مدت یا در کد تست، توسعه را آسان‌تر کند، اما احتمال بروز panic در زمان اجرا را به وجود می‌آورد. تا حد امکان باید از آن اجتناب شود.

- `optional.expect("Unexpected None found! Aborting program.)`.
   متد `expect` روی `Option<T>` بسیار شبیه `unwrap()` است، اما اگر مقدار `None` باشد، با استفاده از پیام ارائه‌شده panic می‌کند.

## مثال‌ها

وقتی مقداری در یک `Option<u32>` وجود دارد:

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

وقتی مقداری در یک `Option<u32>` وجود *ندارد*:

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
