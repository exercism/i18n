# مقدمه

از آنجا که همه‌ی نوع‌های داده‌ی استاندارد Clojure تغییرناپذیرند، Clojure *«نوع‌های ارجاعی»* را ارائه می‌دهد که امکان تغییر کنترل‌شده را فراهم می‌کنند. ساده‌ترین و پرکاربردترین این‌ها را «اتم» می‌نامند.

اتم‌ها با تابع `atom` ساخته می‌شوند، تابعی که یک مقدار اولیه می‌گیرد:

```clojure
(def players (atom ()))
```

برای خواندن مقدار فعلی اتم از `deref` یا شکل کوتاه `@` استفاده می‌شود:

```clojure
@players
;;=> ()
```

مقدار فعلی اتم `players` را می‌توان با `swap!` تغییر داد؛ این تابع مقدار را با اعمال یک تابع به‌روز می‌کند:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

تابع `reset!` مقدار یک اتم را بدون توجه به مقدار فعلی آن جایگزین می‌کند:

```clojure
(reset! players ())
```
