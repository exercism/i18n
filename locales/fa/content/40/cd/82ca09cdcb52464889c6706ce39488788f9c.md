# درباره

به انواعی که رابط [`IEnumerable<T>`][IEnumerable] را پیاده‌سازی می‌کنند، «قابل شمارش» می‌گویند.
همه‌ی انواع مجموعه‌ی توکار این رابط را پیاده‌سازی می‌کنند.

می‌توان یک نوع قابل شمارش را با یک حلقه‌ی `foreach` پیمایش کرد:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

برای پیاده‌سازی `IEnumerable<T>`، یک نوع باید یک متد را پیاده‌سازی کند: `IEnumerator<T> GetEnumerator()`.
همان‌طور که دیدید، یک نوع قابل شمارش، پیمایش واقعی روی یک مجموعه را به یک نوع `IEnumerator<T>` واگذار می‌کند.
این رابط یک خصوصیت و سه متد برای پیاده‌سازی دارد:

- `public T Current { get; }`: گرفتن عنصر جاری.
- `public bool MoveNext ();`: به عنصر بعدی می‌رود. اگر این جابه‌جایی موفق باشد `true` و در غیر این صورت (وقتی عنصر دیگری وجود ندارد) `false` را برمی‌گرداند.
- `public void Reset ();`: «شمارشگر» را به حالت اولیه‌اش بازنشانی می‌کند (پیش از نخستین عنصر).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
