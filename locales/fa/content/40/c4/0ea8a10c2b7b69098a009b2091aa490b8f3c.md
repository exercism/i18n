# مقدمه

یک [عملگر مقایسه][comparisons] در Python (_که به آن عملگر رابطه‌ای Python هم می‌گویند_)، به _مقدارهای_ دو [عملوند][operand] نگاه می‌کند و اگر شرط `comparison` برقرار باشد یا نباشد، یک مقدار «منطقی» `True` یا `False` برمی‌گرداند.

جدول زیر رایج‌ترین عملگرهای مقایسه در Python را نشان می‌دهد:

| عملگر | عملیات | توضیحات |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>` | «بزرگ‌تر از» | `a > b` زمانی `True` است که `a` از نظر مقدار **اکیداً** بزرگ‌تر از `b` باشد. |
| `<` | «کوچک‌تر از» | `a < b` زمانی `True` است که `a` از نظر مقدار **اکیداً** کوچک‌تر از `b` باشد. |
| `==` | «برابر با» | `a == b` زمانی `True` است که `a` از نظر مقدار **دقیقاً** با `b` برابر باشد. |
| `>=` | «بزرگ‌تر از یا برابر با» | `a >= b` زمانی `True` است که `a > b` یا `a == b` باشد (از نظر مقدار). |
| `<=` | «کوچک‌تر از یا برابر با» | `a <= b` زمانی `True` است که `a < b` یا `a == b` باشد (از نظر مقدار). |
| `!=` | «نابرابر با» | `a != b` زمانی `True` است که `a == b` برابر `False` باشد. |
| `is` | «هویت» | `a is b` زمانی `True` است که **_و تنها اگر_** `a` و `b` همان _شیء_ باشند. |
| `is not` | «نفی هویت» | `a is not b` زمانی `True` است که **_و تنها اگر_** `a` و `b` همان _شیء_ **نباشند**. |
| `in` | «آزمون دربرگیری» | `a in b` زمانی `True` است که `a` عضو، زیرمجموعه یا عنصری از `b` باشد. |
| `not in` | «آزمون نفی دربرگیری» | `a not in b` زمانی `True` است که `a` عضو، زیرمجموعه یا عنصری از `b` نباشد. |

همه‌ی آن‌ها اولویت یکسانی دارند (_که از اولویت [عملیات منطقی][boolean operations] بالاتر، اما از اولویت عملیات حسابی یا بیتی پایین‌تر است_).

## مقایسه بین انواع داده‌ی مختلف

اشیائی که انواع مختلف دارند (_به‌جز انواع عددی_) به‌طور پیش‌فرض هرگز برابر مقایسه نمی‌شوند.
نمونه‌های غیریکسان از یک `class` نیز _**برابر مقایسه نمی‌شوند**_، مگر اینکه `class` متدهای ویژه‌ای تعریف کند که رفتار مقایسه‌ی پیش‌فرض `object` را سفارشی‌سازی می‌کنند.

انواع عددی (اکثراً) استثنایی بر این قاعده‌ی تطبیق نوع هستند.
یک `integer` **می‌تواند** برابر با یک `float` در نظر گرفته شود (_یا یک [`octal`][octal] برابر یک [`hexadecimal`][hex]_)، تا زمانی که انواع بتوانند به‌طور ضمنی برای مقایسه تبدیل شوند.

برای سایر انواع عددی ([اعداد مختلط][complex numbers]، [اعداد اعشاری][decimal numbers]، [کسرها][rational numbers])، عملگرهای مقایسه در جایی تعریف می‌شوند که «معنی پیدا می‌کنند» (_جایی که تبدیل ضمنی نتیجه را تغییر نمی‌دهد_)، اما اگر اشیاء زیرین نتوانند به‌طور دقیق برای مقایسه تبدیل شوند، یک `TypeError` پرتاب می‌کنند.

## مقایسه‌ی هویت شیء

عملگرهای `is` و `is not` [_هویت_][object identity] شیء را می‌سنجند، نه _مقدار_ شیء را.
هویت یک شیء پس از ساخت هرگز تغییر نمی‌کند و با استفاده از تابع [`id()`][id function] قابل یافتن است.

`<apple> is <orange>` اگر _**و تنها اگر**_ `id(<apple>)` == `id(<orange>)` باشد، به `True` ارزیابی می‌شود.
`<apple> is not <orange>` عکس آن را برمی‌گرداند.

## مقایسه‌ی عضویت

عملگرهای `in` و `not in` _عضویت_ را می‌سنجند.
`<fish> in <soup>` اگر `<fish>` عضوی از `<soup>` باشد (_اگر `<fish>` زیرمجموعه‌ی `<soup>` باشد یا در آن قرار گرفته باشد_)، به `True` ارزیابی می‌شود و در غیر این صورت `False` ارزیابی می‌شود.
`<fish> not in <soup>` نقیض، یا _عکسِ_ `<fish> in <soup>` را برمی‌گرداند.

برای انواع رشته و بایت، `<name> in <fullname>` _**اگر و تنها اگر**_ `<name>` زیررشته‌ای از `<fullname>` باشد، `True` است.
