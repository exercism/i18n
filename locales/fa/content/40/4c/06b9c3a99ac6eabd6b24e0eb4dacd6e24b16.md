# مقدمه

## بیشتر درباره‌ی الگوها

یادتان باشد که در مفهوم Fundamentals گفتیم یک برنامه‌ی AWK از **جفت‌های «الگو-کنش»** تشکیل شده است.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### منظور از «الگو» چیست؟

«الگو» هر عبارت AWK است.
درست‌بودن نتیجه‌ی عبارت تعیین می‌کند که کنش اجرا شود یا نه.

### الگوی خالی

می‌توان الگو را حذف کرد.
در این صورت، کنش برای هر رکورد اجرا می‌شود.

می‌توانیم همه‌ی نام‌های کاربری را در فایل passwd چاپ کنیم.

```sh
awk -F: '{print $1}' /etc/passwd
```

### عبارت‌های باقاعده

AWK می‌تواند رشته‌ها را با عبارت‌های باقاعده مقایسه کند و به یک نتیجه‌ی منطقی برسد.

از عملگر تطبیق عبارت باقاعده‌ی `~` استفاده کنید تا یک فیلد مشخص را تطبیق دهید.
این عملگر یک رشته را به عنوان عملوند چپ و یک عبارت باقاعده را به عنوان عملوند راست می‌گیرد.
یک عبارت باقاعده‌ی تحت‌اللفظی بین دو اسلش `/` قرار می‌گیرد.

برای پیدا کردن کاربرانی در فایل passwd که با bash وارد می‌شوند:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` عملگر «تطبیق **نشدن** عبارت باقاعده» است.

برای تطبیق یک عبارت باقاعده با رکورد جاری، می‌توانید بنویسید `$0 ~ /regex/`.
این کار آن‌قدر رایج است که شکل کوتاه‌تری هم دارد: می‌توانید `$0` و `~` را حذف کنید و به‌سادگی `/regex/` بنویسید.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
آن دستور یک‌خطی AWK را با فرمان grep معادلش مقایسه کنید

```sh
grep 'regex' data.txt
```

AWK بدون اینکه از ایجاز و کوتاهی چشم بپوشد، یک زبان برنامه‌نویسی کامل در اختیارتان می‌گذارد.
~~~~

در مفهوم دیگری به گونه‌ی عبارت‌های باقاعده‌ی GNU AWK بیشتر می‌پردازیم.

### عبارت‌ها

عبارت‌های AWK (حسابی، منطقی یا از هر نوع دیگر) را می‌توان به عنوان الگو به کار برد.

برای استخراج همه‌ی کاربرانی که UID آن‌ها ۱۰۰۰ یا بیشتر است:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

یادتان باشد که مقادیر «غلط» در AWK عدد صفر و رشته‌ی خالی هستند و همه‌ی اعداد و رشته‌های دیگر «درست»اند.
هر عبارتی که به یک عدد یا یک رشته ارزیابی شود، می‌تواند به عنوان الگو به کار رود.

### توابع

هر تابع [توکار][builtins] یا [تعریف‌شده توسط کاربر][user-defined] را می‌توان در یک عبارت، و در نتیجه در الگو، به کار برد.
چند مثال:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### الگوهای ثابت

یک اصطلاح رایج در AWK این است:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` یک الگویی است که مقدارش درست است و کنشی به آن وابسته نیست.
یعنی «رکورد جاری را چاپ کن».
