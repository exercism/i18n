# مقدمه

بیشتر داده‌ها در Factor در «دنباله‌ها» قرار دارند. آرایه‌ها (`{ … }`)، بردارها (`V{ … }`) و رشته‌ها همه یک [پروتکل][sequence-protocol] یکسان از [`sequences`][sequences] را به اشتراک می‌گذارند.

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

توابع تجمیعی، مانند `sum`، `count`، `any?` و `all?`، و همچنین محمول‌هایی مانند `empty?` و `member?`، به‌طور یکسان روی همه‌ی انواع دنباله کار می‌کنند. ساختن دنباله‌های جدید بدون تغییر داده‌ها: `prefix`، `suffix`، `append`، `unclip` و `unclip-last`.

`>array`، `>vector` و `>string` (در [`arrays`][arrays] و واژگان متناظر) وقتی لازم است از یک عملیات عمومی یک نمونه‌ی مشخص و عینی به دست آورید، میان انواع دنباله تبدیل انجام می‌دهند.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
