# راهنمایی‌ها

## کلی

- باید [ماژول `Dict`][dict-module] را `import` کنید.

## 1. شمارش گل‌های هر گلزن

- احتمالاً ساده‌ترین راه این است که یک تابع به‌روزرسانی تعریف کنید و در `updateGoalCountForPlayer` از `Dict.update` استفاده کنید.

## 2. حذف بازیکنان کم‌اهمیت

- `Dict.filter` ساده‌ترین راه برای این کار است.

## 3. بازنشانی تعداد گل‌های بازیکن

- `Dict.insert` ساده‌ترین راه برای این کار است.

## 4. قالب‌بندی تعداد گل برای یک بازیکن

- `Dict.get`، `Maybe.map` و `Maybe.withDefault` برای این کار مفید هستند.

## 5. قالب‌بندی تعداد گل برای همه‌ی بازیکنان

- `Dict.toList`، `List.map` و `String.join` برای این کار مفید هستند. نیازی به `sort` نیست.

## 6. ترکیب بازی‌ها

- `Dict.merge` ساده‌ترین راه برای این کار است.

[dict-module]: https://package.elm-lang.org/packages/elm/core/latest/Dict
