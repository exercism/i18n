# عملگر تفکیک دامنه

عملگر تفکیک دامنه (`::`) به ما امکان می‌دهد به یک کلاس ارجاع دهیم تا به ثابت‌های نام، ویژگی‌های ایستا یا متدهای ایستای آن دسترسی پیدا کنیم.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## استفاده از `self` و `static` همراه با عملگر تفکیک دامنه

گاهی لازم است یک شیء به دامنه‌ی خودش ارجاع دهد. برای این کار، کلیدواژه‌ی `self` به یک کلاس اجازه می‌دهد به دامنه‌ی خودش ارجاع دهد. استفاده از کلیدواژه‌ی `self` کلاس را از نام خودش جدا می‌کند، و همین نگهداری کد را در طول زمان آسان‌تر می‌سازد.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

از کلیدواژه‌ی `static` همراه با عملگر تفکیک دامنه استفاده کنید تا ارجاع به کلاس فرزند جاری به‌صورت «دیرهنگام» مقید شود.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## استفاده از `parent` همراه با عملگر تفکیک دامنه

کلیدواژه‌ی `parent` برای ارجاع به ثابت‌ها، ویژگی‌ها یا متدهای کلاس والد به کار می‌رود. معمولاً از آن برای فراخوانی سازنده‌ی والد هنگام نمونه‌سازی از یک شیء استفاده می‌شود:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## نکات قابل توجه

### سطح دسترسی ثابت‌ها، ویژگی‌ها و متدها

عملگر تفکیک دامنه همچنان از قواعدی پیروی می‌کند که اصلاح‌کننده‌های دسترسی `public`، `private` و `protected` تعیین می‌کنند.
