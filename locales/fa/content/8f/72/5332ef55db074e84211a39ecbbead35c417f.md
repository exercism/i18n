## دستورالعمل‌ها

وظیفه‌ی شما تولید مازهای بی‌نقص برای Mickey و Minerva است؛ مازهایی که تنها یک راه‌حل دارند و هیچ بخش جدایی در آن‌ها نیست.
آنچه باید بدانید:

- شکل ماز مستطیلی است و در ابتدا و انتهای آن یک بازشدگی وجود دارد.
- ماز اتاق‌ها و راهروهایی دارد که با زاویه‌ی قائمه یکدیگر را قطع می‌کنند.
- برنامه باید دو پارامتر بپذیرد: تعداد سطرها و ستون‌ها. اندازه‌ی ماز باید بین ۵ تا ۱۰۰ خانه باشد.
- مازی که `x` ستون عرض و `y` سطر ارتفاع دارد، باید `2x + 1` کاراکتر عرض و `2y + 1` کاراکتر ارتفاع داشته باشد.
- اگر بذری داده نشود، یک ماز تصادفی تولید کنید. اگر یک بذر چند بار داده شود، ماز حاصل هر بار یکسان خواهد بود.
- از کاراکترهای [جعبه‌کشی][Box-drawing] برای رسم دیوارها و از نماد فلش (⇨) برای ورودی در سمت چپ و خروجی در سمت راست استفاده کنید.

وقت آن رسیده که برای این موش‌های ماجراجو چند ماز بی‌نقص بسازید!

### نمونه‌ها

1. ماز کوچک مربعی ۵×۵ خانه (یا ۱۱×۱۱ کاراکتر)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. ماز مستطیلی ۶×۱۸ خانه
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
