# دستورالعمل‌ها

روز ولنتاین است. شریک زندگی‌تان چند ایده برای فعالیت دارد و از شما می‌خواهد به هر کدام امتیاز بدهید: `yes`، `no` یا `maybe`.

فعالیت‌ها به‌صورت آرایه‌های ۲ عنصری `{ tag value }` نمایش داده می‌شوند که در آن‌ها `tag` یکی از این‌هاست: `board-game`، `chill`، `movie`، `restaurant` یا `walk`.

| فعالیت                     | شکل                        |
| ------------------------- | --------------------------- |
| یک بازی رومیزی انجام دادن | `{ board-game f }`          |
| استراحت کردن              | `{ chill f }`               |
| تماشای فیلمی با ژانر `genre` | `{ movie genre }`        |
| غذا خوردن در جایی با نوع غذای `cuisine` | `{ restaurant cuisine }` |
| پیاده‌روی `km` کیلومتری   | `{ walk km }`               |

ژانر یکی از این‌هاست: `crime`، `horror`، `romance`، `thriller`. نوع غذا هم `korean` یا `turkish` است.

## 1. به نوع غذا امتیاز بدهید

`rate-restaurant` را طوری تعریف کنید که یک نوع غذا را از پشته بردارد و تأیید شما را برگرداند:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. به ژانر فیلم امتیاز بدهید

`rate-movie` را طوری تعریف کنید که یک ژانر بگیرد و برگرداند:

- `romance` → `yes`
- هر ژانر دیگری → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. به پیاده‌روی امتیاز بدهید

`rate-walk` را طوری تعریف کنید که یک تعداد کیلومتر بگیرد و برگرداند:

- بیشتر از `11` → `yes`
- بیشتر از `6` و حداکثر تا `11` → `maybe`
- در غیر این صورت → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. به فعالیت امتیاز بدهید

`rate-activity` را طوری تعریف کنید که یک فعالیت `{ tag value }` را از پشته بردارد و تأیید شما را برگرداند. از توابع کمکی بالا دوباره استفاده کنید:

- `board-game`، `chill` → همیشه `no`
- `movie` → واگذار به `rate-movie`
- `restaurant` → واگذار به `rate-restaurant`
- `walk` → واگذار به `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. شمارش تأییدها

`approval-counts` را طوری تعریف کنید که یک فهرست از فعالیت‌ها بگیرد و یک آرایه‌ی ۳ عنصری `{ yes-count maybe-count no-count }` را برگرداند که نشان می‌دهد چند فعالیت با هر امتیاز ارزیابی شده‌اند.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
