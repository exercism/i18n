همه‌ی مقادیر ثابت غیرضروری را حذف کنید.

در JavaScript لازم نیست برای برگرداندن یک «مقدار منطقی»، مقدار ثابت `true` یا `false` را `return` کنید. نتیجه‌ی یک عبارت را می‌توان مستقیماً برگرداند.

```javascript
// instead of
if (some_expression) {
  return true;
} else {
  return false;
}

// ...in JavaScript, these can be returned directly
return some_expression;
```
