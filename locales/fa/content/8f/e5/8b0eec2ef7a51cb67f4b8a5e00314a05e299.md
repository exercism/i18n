# شروع به کار کارمندان در پایگاه داده

## صورت مسئله

شرکت ABC Corp قصد دارد همه‌ی اطلاعات پرداخت‌های تنخواه به کارمندان را در یک پایگاه داده نگهداری کند. شما به بخش مالی شرکت ABC Corp در پیاده‌سازی آن کمک می‌کنید. چون شرکت ABC Corp در حال گسترش فعالیت‌های خود است، با استخدام کارمندان تازه، افزودن کارمند جدید به سامانه یک نیاز رایج است.

وظیفه‌ی شما این است که اطلاعات کارمند جدید را به جدول `Employee` در پایگاه داده اضافه کنید و مقدار ستون `employee_id` را که به‌صورت خودکار تولید می‌شود، بدون فرستادن پرس‌وجوی دیگری به پایگاه داده برگردانید. اگر هنگام اجرا خطایی رخ دهد، باید `-1` برگردانده شود.

## جزئیات پایگاه داده

برای این مسئله از پایگاه داده‌ی H2 ارائه‌شده استفاده کنید.

> فایل پایگاه داده‌ی نمونه `gofigure.mv.db` است و اسم پایگاه داده `gofigure` است. این فایل در پوشه‌ی `db` قرار دارد.

جدول‌های زیر از قبل همراه با چند داده‌ی نمونه در پایگاه داده‌ی نمونه‌ی H2 وجود دارند. اسم ستون‌ها و نوع داده‌ها در ادامه آمده است.

**اسم جدول** : `Employee`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحیح، کلید اصلی خودافزا       |
| `name`            | رشته        |
| `city`            | رشته        |
| `department`      | رشته        |
| `age`             | عدد صحیح        |

**اسم جدول**: `Payment`

| **ستون‌ها:**      | نوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحیح، کلید اصلی خودافزا       |
| `date`            | تاریخ        |
| `amount`          | اعشاری        |
| `employee_id`     | عدد صحیح        |
| `reason`          | رشته        |

* فایل پایگاه داده `gofigure.mv.db` است. از JDBC URL به شکل `jdbc:h2:file:/path/to/db/file` استفاده کنید
* اسم کاربری: `root`
* گذرواژه: `root`

## محدودیت‌ها

* برای اعتبارسنجی پرس‌وجوها و نمونه‌ی Ballerina از فایل پایگاه داده‌ی H2 که در پوشه‌ی `db` ارائه شده است استفاده کنید
* برای افزودن درایور پایگاه داده‌ی H2 به عنوان یک وابستگی پلتفرمی در Ballerina.toml خود، از روش maven dependency params استفاده کنید
* برای یافتن شناسه‌ای که به‌صورت خودکار تولید می‌شود، پرس‌وجوی دیگری به پایگاه داده نفرستید


## محیط Test

* می‌توانید Test را با `bal test` اجرا کنید؛ این Test روی پایگاه داده‌ی نمونه‌ی ارائه‌شده اجرا می‌شود.

## راهنمایی‌ها

* برای کار با پایگاه داده از ماژول [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) استفاده کنید
* برای مراحل افزودن درایور JDBC به عنوان وابستگی، به بخش [Prerequisite](https://lib.ballerina.io/ballerinax/java.jdbc/latest) مراجعه کنید
* برای درج داده از متد ریموت [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute) استفاده کنید
* به مثال‌های [DML and DDL operations](https://ballerina.io/learn/by-example/mysql-execute-operation/) مراجعه کنید
