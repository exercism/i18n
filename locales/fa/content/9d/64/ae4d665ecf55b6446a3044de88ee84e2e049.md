# پیوست دستورالعمل‌ها

## پیاده‌سازی

برای تکمیل این تمرین باید «struct» را پیاده‌سازی کنید: نوع داده‌ی `school` را تعریف کنید و توابع زیر را بنویسید:

- newSchool
- add
- roster
- grade

فصل ۳ از [Notes on Programming SML/NJ][notes] به کاربرد signatureها و structها می‌پردازد.

[notes]: https://www.cs.cornell.edu/riccardo/prog-smlnj/notes-011001.pdf
