# پیوست دستورالعمل‌ها

## تعریف یک نوع استقرایی

این تمرین انتظار دارد که مقدار بازگشتی یک [نوع استقرایی][inductive] به اسم `Classification` باشد که باید خودتان آن را تعریف کنید.

این نوع باید یک نمونه از [BEq][beq] داشته باشد، یعنی آزمون برابری منطقی را می‌پذیرد، و یک نمونه از [Repr][repr]، یعنی مقادیر این نوع می‌توانند برای نمایش قالب‌بندی شوند.

می‌توانید به [این صفحه][instance] درباره‌ی اعلان نمونه‌ها مراجعه کنید.
Lean می‌تواند به‌طور خودکار برای بسیاری از کلاس‌ها [نمونه بسازد][deriving].

## زیرنوع‌ها

آرگومان تابع `classify` یک [زیرنوع][subtype] به اسم `Positive` است:

```
def Positive := { x : Nat // x > 0 }
```

زیرنوع‌ها عنصرهایی از یک نوع خاص را نمایش می‌دهند که یک محمول را برآورده می‌کنند.
`Positive` عنصرهای `Nat` را نمایش می‌دهد که بزرگ‌تر از `0` هستند.

هر عنصر از یک زیرنوع را می‌توان به‌صورت یک جفت در نظر گرفت که از یک مقدار از نوع زیرین و یک اثبات، به معنای ریاضی، تشکیل شده است که آن مقدار محمول متناظر را برآورده می‌کند.

زیرنوع‌ها ناورداها را در سطح نوع اعمال می‌کنند و تضمین می‌کنند که مقادیر بدشکل ساخته نشوند.
