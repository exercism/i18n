# درباره

[رشته‌های تحت‌اللفظی][verbatim-strings] امکان نوشتن رشته‌های چندخطی را فراهم می‌کنند. این رشته‌ها با یک `@` آغاز می‌شوند. می‌توان از آن‌ها همراه با درج مقدار در رشته استفاده کرد. فقط کافی است پیش از گیومه‌ی آغازیِ رشته یک `"\$"` اضافه کنید.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
