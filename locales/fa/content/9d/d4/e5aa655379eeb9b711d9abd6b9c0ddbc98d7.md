# دستورالعمل‌ها

در این تمرین، روشی برای پیگیری امتیازهای بالای محبوب‌ترین بازی سالن بازی‌های آرکید محله‌تان پیاده‌سازی می‌کنید.

## 1. افزودن بازیکن به تخته‌ی امتیازات

برای افزودن بازیکن به تخته‌ی امتیازات، دو متد `add_player!` تعریف کنید که آرگومان‌های زیر را می‌گیرند:

- آرگومان اول، دیکشنری امتیازهاست.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است.
- آرگومان سوم، امتیاز به‌صورت عدد صحیح است.
  این آرگومان اختیاری است؛ اگر مقداری داده نشود، امتیاز باید ۰ در نظر گرفته شود.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. حذف بازیکن از تخته‌ی امتیازات

برای حذف بازیکن از تخته‌ی امتیازات، `remove_player!` را تعریف کنید که ۲ آرگومان می‌گیرد:

- آرگومان اول، دیکشنری امتیازهاست.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. به‌روزرسانی امتیاز بازیکن

برای به‌روزرسانی امتیاز بازیکن با جایگزین کردن امتیاز قبلی، `update_score!` را تعریف کنید که ۳ آرگومان می‌گیرد:

- آرگومان اول، دیکشنری امتیازهاست.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است که می‌خواهید امتیازش را به‌روزرسانی کنید.
- آرگومان سوم، امتیازی است که می‌خواهید امتیاز ذخیره‌شده را به آن تغییر دهید.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. بازنشانی امتیاز بازیکن

برای بازنشانی امتیاز بازیکن، `reset_score!` را تعریف کنید که ۲ آرگومان می‌گیرد:

- آرگومان اول، دیکشنری امتیازهاست.
- آرگومان دوم، اسم بازیکن به‌صورت رشته است که می‌خواهید امتیازش را بازنشانی کنید.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. دریافت فهرست بازیکنان

برای دریافت فهرست بازیکنان، `players` را تعریف کنید که ۱ آرگومان می‌گیرد:

- آرگومان اول، دیکشنری امتیازهاست.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
