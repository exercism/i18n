# مقدمه

## عبارت‌های باقاعده در JavaScript

یک [عبارت باقاعده][mdn-regular-expressions] (یا به اختصار Regex) دنباله‌ای از کاراکترهاست که می‌توانیم با آن عناصر خاصی از رشته‌ها را هدف بگیریم و دستکاری کنیم. از این رو می‌توانیم:

- یک متن را در یک رشته **جست‌وجو** کنیم
- زیررشته‌ها را در یک رشته **جایگزین** کنیم
- اطلاعاتی را از یک رشته **استخراج** کنیم

> 💡 گونه‌ی عبارت‌های باقاعده در JavaScript بخشی از استاندارد ECMA-262 این زبان است. یعنی لازم نیست نگران سازگاری مخصوص هر مرورگر باشید.

## چگونه عبارت‌های باقاعده بسازیم

در JavaScript، عبارت باقاعده بیشتر در قالب `/pattern/modifiers` نوشته می‌شود.

برای ساختن یک عبارت باقاعده دو راه داریم:

1. **لیترال عبارت باقاعده**:

```javascript
const regex = /[a-z]/;
```

2. سازنده‌ی **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

در هر دو حالت، JavaScript از این عبارت باقاعده یک شیء می‌سازد. توصیه می‌شود الگوهای تغییرناپذیر را به کار ببرید و به‌صورت پیش‌فرض از لیترال استفاده کنید.

از سازنده‌ی `RegExp` می‌توان در مواردی استفاده کرد که عبارت باقاعده تغییر می‌کند یا هنوز آن را نمی‌دانیم (مثل ورودی).

## 🏴‍☠️ پرچم‌ها

عبارت‌های باقاعده قابلیت‌های اختیاری ویژه‌ای به نام [`flags`][mdn-flags] دارند که امکانات بیشتری در اختیارمان می‌گذارند.

برخی از پرکاربردترین آن‌ها عبارت‌اند از:

- `/g` - جست‌وجوی سراسری
- `/i` - بدون حساسیت به بزرگی و کوچکی حروف
- `/m` - جست‌وجوی چندخطی

در ادامه یک مثال ساده می‌آوریم:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

کاراکتر `g` به ما امکان می‌دهد همه‌ی تطبیق‌های ممکن را در یک رشته پیدا کنیم. بدون این ویژگی، JavaScript فقط نخستین تطبیق `Home` را استخراج می‌کرد.

پرچم `/i` که حساسیت به بزرگی و کوچکی حروف را نادیده می‌گیرد، هنگام یافتن یک الگو به ما انعطاف می‌دهد. به این ترتیب مهم نیست آنچه می‌جوییم با `UPPERCASE` نوشته شده باشد یا با `lowercase`.

وقتی از سازنده‌ی `RegExp` استفاده می‌کنید، نحوه‌ی نگارش افزودن پرچم‌ها متفاوت است.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## پرکاربردترین توابع

وقتی عبارت‌های باقاعده با توابع درون‌ساز موجود در JavaScript ترکیب می‌شوند، ابزارهای قدرتمندی برای دستکاری رشته‌ها و گرفتن داده از آن‌ها در اختیار داریم.

این‌ها چند مورد از پرکاربردترین توابعی هستند که در کنار عبارت‌های باقاعده به کار می‌روند.

### تست

متد [test()][mdn-regex-test] جست‌وجویی برای یافتن تطبیق میان یک عبارت باقاعده و یک رشته‌ی مشخص انجام می‌دهد. «درست» یا «غلط» را برمی‌گرداند.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### تطبیق

با متد [match()][mdn-regex-match] آرایه‌ای مفید به دست می‌آوریم که محتوای آن به وجود یا نبود تطبیق‌های یافته‌شده بستگی دارد.

به این ترتیب می‌توانیم هم در هر رشته‌ای **جست‌وجو** کنیم و هم اطلاعات را **استخراج** کنیم. برای نمونه:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

وقتی پرچم جست‌وجوی سراسری `/g` وجود داشته باشد، متد به‌جای گرفتن تنها تطبیق همراه با اطلاعات مفیدی مثل اندیس یا ورودی، همه‌ی موارد یافته‌شده را در قالب آرایه برمی‌گرداند:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### جایگزینی

متد [replace()][mdn-regex-replace] در JavaScript به ما امکان می‌دهد مقداری را در یک رشته‌ی مشخص جست‌وجو کنیم و آن را با مقدار تازه‌ی دلخواه جایگزین کنیم.

```javascript
string.replace(searchValue, newValue);
```

الگویی که برای جست‌وجوی جایگزینی به کار می‌رود می‌تواند یک رشته‌ی ساده یا یک عبارت باقاعده باشد.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

علاوه بر این، می‌توانیم در جایگاه مقدار جایگزین یک تابع به کار ببریم تا تغییرات بیشتری روی هر مقدار اعمال شود.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### تقسیم

متد [split()][mdn-regex-split] در JavaScript روش دیگری برای استفاده از عبارت‌های باقاعده و دستکاری رشته‌هاست.

به این ترتیب، از عبارت باقاعده استفاده می‌کنیم تا یک رشته‌ی مشخص را بر اساس تشخیص یک الگو تقسیم کنیم، برای نمونه `str.split(/[,.\s]/)`. این الگو به‌عنوان `separator` به کار می‌رود.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
