# مقدمه

## کست کردن

«کست کردن» و «تبدیل نوع» دو روش متفاوت برای تغییر یک عبارت از یک نوع داده به نوعی دیگر هستند.

یک عبارت را می‌توان با عملگر کست `(<type>)` به نوع دیگری کست کرد.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

اگر نوع‌ها با هم سازگار نباشند، نمونه‌ای از `InvalidCastException` پرتاب می‌شود. در مورد اعداد، این یعنی نوع گیرنده نمی‌تواند مقدار کست‌شده را نمایش دهد. در مورد کلاس‌ها، یکی از دو نوع باید از دیگری مشتق شده باشد (این موضوع برای انواع `struct` هم به‌شکلی بدیهی صادق است).

جایگزینی برای «کست کردن»، «تبدیل نوع» با استفاده از عملگر `is` است. این کار معمولاً برای انواع ارجاعی و انواع تهی‌پذیر به کار می‌رود.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

اگر لازم است نوع دقیق یک شیء را تشخیص دهید، `is` ممکن است کمی بیش از حد سهل‌گیرانه باشد، چون برای یک کلاس و هر کلاس و رابطی که به‌طور مستقیم یا غیرمستقیم از آن مشتق شده‌اند مقدار «درست» را برمی‌گرداند. در این حالت، `typeof` و `Object.GetType()` راه‌حل هستند.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
