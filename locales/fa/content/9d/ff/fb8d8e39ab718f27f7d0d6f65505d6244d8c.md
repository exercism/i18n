# پیوست دستورالعمل

خروجی باید به [ترتیب سطری](https://en.wikipedia.org/wiki/Row-_and_column-major_order) چیده شود: ابتدا همه‌ی واژه‌های سطر اول، سپس واژه‌های سطر دوم و به همین ترتیب.

## ثبات‌ها

| ثبات    | کاربرد        | نوع      | توضیح                                |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | ورودی        | عدد صحیح | اندازه                              |
| `$a1`    | ورودی/خروجی  | نشانی    | ماتریس واژه‌ها، به ترتیب سطری        |
| `$v0`    | خروجی        | عدد صحیح | تعداد واژه‌های ماتریس                |
| `$t0-9`  | موقت         | هر نوع   | برای ذخیره‌سازی موقت                 |
