# Tests

یک REPL کلوجراسکریپت به شما امکان می‌دهد کد را به‌راحتی اجرا کنید و بازخورد فوری بگیرید؛ همچنین می‌توان از آن برای اجرای تست‌ها استفاده کرد.

## Leiningen

برای باز کردن یک REPL با استفاده از Clojure CLI، به پوشه‌ای که تمرین در آن قرار دارد بروید و این دستور را اجرا کنید:
``` bash
$ clojure -m cljs.main -re node
```

توجه کنید که Node باید روی سیستم شما نصب باشد.

وقتی آماده‌ی کار روی یک تمرین شدید و فایلی برای نگهداری راه‌حل خود ساختید (مثل `bob.cljs`)، می‌توانید تست‌ها را در ترمینال خود با `$ clojure -A:test` اجرا کنید.

اول، فضای‌نام تست را `require` کنید:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

فضای‌نام را به فضای‌نام تست تغییر دهید:
```clojure
=> (ns bob-test)
nil
```

سپس `run-tests` را روی `bob-test` فراخوانی کنید:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

برای اجرای تست‌های یک تمرین با Clojure CLI، کافی است این را فراخوانی کنید:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
