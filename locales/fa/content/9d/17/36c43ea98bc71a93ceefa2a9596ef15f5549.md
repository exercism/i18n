# مقدمه

وقتی می‌خواهید داده‌ای را مدل‌سازی کنید که فقط می‌تواند مجموعه‌ی مشخصی از حالت‌های ممکن را بپذیرد، مثل روزهای هفته، جهت‌های قطب‌نما یا دکمه‌های یک دسته‌بازی، انواع پایه‌ای مثل `Int` یا `String` اشکالات بزرگی دارند.
با عددهای صحیح یا رشته‌ها، کد شما باید مدام مقادیر نامعتبر را بررسی کند (مثلاً کد وضعیتی برابر با `999` یا غلط تایپی مثل `"leftt"`)، و خوانندگان انسانی هم به‌سختی می‌توانند بفهمند این اعداد چه چیزی را نشان می‌دهند.

Swift این مشکل را با [_شمارشی_][enumerations] حل می‌کند (که اغلب به `enum` کوتاه می‌شود).
شمارشی یک نوع مشترک برای گروهی از مقادیر نام‌دار و مرتبط تعریف می‌کند. چون کامپایلر از پیش همه‌ی حالت‌های ممکن را می‌داند، می‌تواند کد شما را در زمان کامپایل از نظر درستی و کامل بودن بررسی کند.
شمارشی‌ها می‌توانند متد، سازنده و ویژگی‌های محاسبه‌شده هم داشته باشند.

## تعریف شمارشی

برای تعریف یک شمارشی از کلیدواژه‌ی `enum` و بعد از آن اسم نوع استفاده کنید و حالت‌هایش را داخل آکولاد فهرست کنید.
طبق قرارداد Swift، اسم نوع با `UpperCamelCase` نوشته می‌شود و هر حالت با `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

می‌توانید چندین حالت را هم در یک خط و جدا‌شده با کاما تعریف کنید:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

برای اشاره به یک حالت شمارشی، اسم نوع شمارشی را بنویسید و بعد از آن یک نقطه (`.`) و سپس اسم حالت را بیاورید. وقتی نوع معلوم باشد یا کامپایلر بتواند آن را استنتاج کند، می‌توانید اسم نوع را حذف کنید و از روش نوشتن کوتاه‌تر با نقطه استفاده کنید:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## متد و سازنده

شمارشی‌ها می‌توانند درست مثل کلاس‌ها و ساختارها متد و سازنده‌ی سفارشی تعریف کنند. داخل یک متد شمارشی، `self` به مقدار حالت جاری اشاره می‌کند:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## مقادیر خام

حالت‌های یک شمارشی می‌توانند با مقادیر پیش‌فرضی به نام [_مقادیر خام_][raw-values] از پیش پر شوند.
همه‌ی مقادیر خام در یک شمارشی باید از یک نوع باشند (مثل `Int`، `String` یا `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

می‌توانید یک شمارشی را با `init(rawValue:)` از یک مقدار خام بسازید. چون ممکن است مقدار خامی نامعتبر داده شود، این سازنده یک مقدار اختیاری برمی‌گرداند:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift می‌تواند برای شمارشی‌های `String` و `Int` به‌طور خودکار مقادیر خام تعیین کند:

- در شمارشی‌های `String`، مقدار خام هر حالت به‌طور پیش‌فرض اسم همان حالت است.
- در شمارشی‌های `Int`، مقادیر خام از `0` شروع می‌شوند و تا وقتی خلاف آن مشخص نشده باشد، هر بار یک واحد زیاد می‌شوند.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```
