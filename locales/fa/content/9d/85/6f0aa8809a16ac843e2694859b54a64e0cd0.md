# دستورالعمل‌ها

در این تمرین شما کدی می‌نویسید که به یک شرکت تابلو‌سازی کمک می‌کند پیام‌های سفارشی برای تابلوهایشان بسازد.

## 1. مجموعه‌ای از رشته‌های مفید بسازید

ثابت‌های رشته‌ای زیر را تعریف کنید که برای ساختن تابلوها به کار می‌روند:

- `birthday`: مقدار "Birthday" را نگه می‌دارد
- `valentine`: مقدار "Valentine's Day" را نگه می‌دارد
- `anniversary`: رشته‌ی "Anniversary" را نگه می‌دارد

## 2. مجموعه‌ای از کاراکترهای مفید بسازید

کاراکترهای ثابت زیر را تعریف کنید که برای ساختن تابلوها به کار می‌روند:

- `space`: مقدار " " را نگه می‌دارد (یک فاصله‌ی تک)
- `exclamation`: مقدار "!" را نگه می‌دارد

## 3. عبارت‌ها را برای ساختن پیام‌ها به هم بچسبانید

تابع `buildSign(for:name:)` را پیاده‌سازی کنید؛ این تابع آرگومان `for` را می‌گیرد که یکی از سه رشته‌ای را نگه می‌دارد که در تمرین اول تعریف کردید، و آرگومان `name` را می‌گیرد که رشته‌ای است و اسم شخصی را نگه می‌دارد که تابلو برای اوست.
برای ساختن پیام تابلو باید از الحاق استفاده کنید و یادتان باشد که ثابت‌های تعریف‌شده را دوباره به کار ببرید.
تابع باید پیام تابلو را به‌صورت یک رشته برگرداند.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. تابلوی فارغ‌التحصیلی بسازید

تابع `graduationFor(name:year:)` را پیاده‌سازی کنید؛ این تابع آرگومان `name` را می‌گیرد که رشته‌ای است و اسم شخصی را نگه می‌دارد که تابلو برای اوست، و آرگومان `year` را می‌گیرد که یک عدد صحیح است و سالی را نگه می‌دارد که شخص در آن فارغ‌التحصیل می‌شود.
برای ساختن پیام تابلو باید از رشته‌های قالبی استفاده کنید.
تابع باید پیام تابلو را به‌صورت یک رشته برگرداند.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. هزینه‌ی یک تابلو را محاسبه کنید

تابع `costOf(sign:)` را پیاده‌سازی کنید؛ این تابع آرگومان `sign` را می‌گیرد که رشته‌ای است و پیام تابلو را نگه می‌دارد.
تابلو یک قیمت پایه‌ی ۲۰ در واحد پول داده‌شده دارد. به‌علاوه، هر حرف ۲ هزینه دارد (فاصله‌های خالی هم در محاسبه لحاظ می‌شوند).
تابع باید هزینه‌ی تابلو را به‌صورت یک عدد صحیح برگرداند.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
