# درباره

در Haxe از «تکرارگر» برای پیمایش یک مقدار با حلقه‌ی `for` استفاده می‌شود. تکرارگرها دو نوع دارند:

- `Iterator` که روی یک مقدار پیمایش انجام می‌دهد.
- داده‌ی `Iterable` که امکان پیمایش روی یک نوع داده را فراهم می‌کند.

هر دوی این مفاهیم با `Iterator<T>` و `Iterable<T>` نمایش داده می‌شوند:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

روی هر کلاسی که با یکی از این نوع‌ها منطبق شود، می‌توان با حلقه‌ی `for` پیمایش کرد. اگر کلاسی متدهای `hasNext` و `next` را تعریف کند، یک تکرارگر به حساب می‌آید؛ در غیر این صورت، اگر متد `iterator` را تعریف کند، یک نوع «تکرارپذیر» به حساب می‌آید:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

در مثال بالا، کلاس `MyStringIterator` یک تکرارگر به حساب می‌آید، چون هر دو متد `hasNext` و `next` را پیاده‌سازی می‌کند و همین باعث می‌شود با `Iterator<String>` سازگار باشد.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

در اینجا، کلاس `MyArrayWrap` یک نوع داده‌ی تکرارپذیر به حساب می‌آید، چون با `Iterable<Array<T>>` سازگار است.
