# درباره

Elm زبانی لذت‌بخش برای ساخت برنامه‌های وب قابل‌اعتماد است. پیام‌های خطای دوستانه، کارایی عالی و خروجی سبک دارد و در زمان اجرا هیچ استثنایی رخ نمی‌دهد.

احتمالاً مشهورترین و پرکپی‌شده‌ترین بخش Elm، «The Elm Architecture» است؛ الگویی ساده برای ساختاربندی برنامه‌های وب که همه‌ی برنامه‌های وب Elm با آن نوشته می‌شوند.

ایده‌ی اصلی این است که کد شما حول یک `Model` از وضعیت برنامه ساخته می‌شود، راهی برای `update` کردن مدل و راهی برای `view` کردن مدل.

`Model` وضعیت برنامه را در خود دارد: همه‌ی داده‌ای که برنامه به آن نیاز دارد.
اگر یک برنامه‌ی ساده را در نظر بگیرید که یک جعبه‌ی متن دارد و متنی که معکوس آن متن را نشان می‌دهد، مدل مانند زیر خواهد بود.
این مثال را می‌توانید در [راهنمای Elm][elm-guide-text-fields] هم ببینید.

```elm
type alias Model =
  { text : String
  }
```

‏`update` تابعی است که وقتی تغییری رخ می‌دهد (مثل کلیک کردن کاربر روی یک دکمه) با یک `Msg` فراخوانی می‌شود.
این تابع `Msg` و `Model` فعلی را می‌گیرد و یک `Model` جدید برمی‌گرداند.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

‏`view` تابعی است که HTML را برای نمایش به کاربر در مرورگر برمی‌گرداند.
این تابع `Model` فعلی را می‌گیرد و یک `Html Msg` برمی‌گرداند (نوعی که Elm برای نمایش HTML از آن استفاده می‌کند).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
