# مقدمه

در Gleam، «دیکشنری» ساختار داده‌ای برای ذخیره‌ی اطلاعات در قالب جفت‌های کلید-مقدار است. در زبان‌های دیگر ممکن است این ساختار با نام‌های آرایه‌ی انجمنی، هش یا دیکشنری هم شناخته شود.

می‌توان از هر نوعی برای کلیدها و مقدارهای یک دیکشنری استفاده کرد و دیکشنری ترتیب مدخل‌های خود را هنگام دسترسی یا بازگرداندن تضمین نمی‌کند.

## کار با دیکشنری‌ها

دیکشنری‌ها با استفاده از توابع ماژول `gleam/dict` ساخته و دستکاری می‌شوند.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
