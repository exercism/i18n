# دستورالعمل‌ها

در حالی که کار خود را در _Instruments of Texas_ ادامه می‌دهید، پیشرفتی در پیاده‌سازی ماشین‌حساب RPN با Elixir در حال انجام است. تیم شما می‌خواهد بتواند خطاهایی اختصاصی‌تر از خطاهای عمومی کتابخانه‌ی استاندارد ایجاد کند. شما در حال تحقیق هستید، اما تصمیم گرفته‌اید دو خطای جدید بنویسید که _Exception Behaviour_ را پیاده‌سازی می‌کنند.

## 1. خطا برای تقسیم بر صفر

تقسیم یک عدد بر صفر نتیجه‌ی تعریف‌نشده‌ای تولید می‌کند که به نظر تیم بهتر است با یک خطا نشان داده شود.

ماژول `DivisionByZeroError` را طوری پیاده‌سازی کنید که پیام خطایش `"division by zero occurred"` باشد.

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. خطا هنگام برخورد با کمبود پشته

ماشین‌حساب‌های RPN از یک «پشته» استفاده می‌کنند تا اعداد را پیش از انجام محاسبات روی آن‌ها نگه دارند. تیم این «پشته» را با فهرستی از اعداد (صحیح و اعشاری) نمایش می‌دهد، مثلاً: `[3, 4.0]`. هر عملیات برای انجام محاسبه‌اش به تعداد مشخصی عدد روی پشته نیاز دارد. وقتی اعداد کافی روی پشته نباشد، به این حالت خطای «کمبود پشته» می‌گویند. استثنای `StackUnderflowError` را پیاده‌سازی کنید که یک پیام پیش‌فرض و زمینه‌ی اضافی اختیاری فراهم می‌کند.

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. یک تابع تقسیم بنویسید

تابع `divide/1` را پیاده‌سازی کنید که یک پشته _(فهرستی از دو عدد)_ می‌گیرد و:

- وقتی پشته اعداد کافی ندارد، خطای _کمبود پشته_ را ایجاد می‌کند
- وقتی مقسوم‌علیه ۰ است، خطای _تقسیم بر صفر_ را ایجاد می‌کند (توجه کنید که فهرست اعداد به ترتیب معکوس ذخیره می‌شود)
- وقتی خطایی ایجاد نمی‌شود، تقسیم را انجام می‌دهد

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```
