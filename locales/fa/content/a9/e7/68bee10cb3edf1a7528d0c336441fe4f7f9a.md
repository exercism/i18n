# درباره

[ساختارها][structs-and-classes] (که معمولاً «struct» نامیده می‌شوند) یکی از بلوک‌های اصلی سازنده‌ی برنامه‌های Swift هستند.
ساختارها به شما امکان می‌دهند نوع‌های سفارشی بسازید که ویژگی‌های مرتبط (داده) و متدها (رفتار) را کنار هم گروه‌بندی می‌کنند.
در واقع، نوع‌های استاندارد Swift، از جمله `Int`، `Double`، `Bool`، `String`، `Array` و `Dictionary`، همگی به صورت ساختار پیاده‌سازی شده‌اند.

## تعریف ساختارها

برای تعریف یک ساختار، از کلیدواژه‌ی `struct` استفاده کنید؛ بعد از آن اسم نوع و آکولادهایی می‌آید که تعریف آن را در بر می‌گیرند.
طبق قرارداد Swift، اسم ساختارها با `UpperCamelCase` نوشته می‌شود:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## ساختن نمونه‌ها

تعریف یک ساختار یک نقشه‌ی اولیه است.
برای ساختن «نمونه» از یک ساختار، مقداردهی‌کننده‌ی آن را با نوشتن اسم نوع و سپس پرانتزها فراخوانی کنید:

```swift
var someStats = CharacterStats()
```

این کار نمونه‌ای می‌سازد که با مقادیر پیش‌فرض ویژگی‌های تعریف پر شده است.

Swift همچنین یک **«مقداردهی‌کننده‌ی عضو‌به‌عضو»** خودکار برای ساختارها تولید می‌کند که به شما امکان می‌دهد ویژگی‌ها را با اسم مقداردهی اولیه کنید:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## دسترسی به ویژگی‌ها و تغییر آن‌ها

شما با «نقطه‌گذاری» به ویژگی‌های یک نمونه دسترسی پیدا می‌کنید و آن‌ها را تغییر می‌دهید:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

چون ساختارها از نوع‌های مقداری هستند، تغییر دادن ویژگی‌های یک نمونه نیازمند آن است که خود نمونه با `var` اعلام شود.
اگر نمونه با `let` اعلام شود، همه‌ی ویژگی‌های آن تغییرناپذیر می‌شوند.
