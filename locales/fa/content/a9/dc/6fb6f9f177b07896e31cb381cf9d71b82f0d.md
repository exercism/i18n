# پیوست دستورالعمل‌ها

## ساختار پروژه

تمرین‌های Clojure در Exercism از [leiningen](http://leiningen.org/) برای پیکربندی و اجرای کد شما استفاده می‌کنند و از [ساختار دایرکتوری استاندارد leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout) بهره می‌برند.

یک فایل تست به اسم `hello_world_test.clj` درون دایرکتوری `test` پیدا می‌کنید.
کد خود را در `src/hello_world.clj` بنویسید. باید از فضای نام `hello-world` استفاده کند تا تست‌ها بتوانند آن را پیدا کنند.

## اجرای تست‌ها

تست‌ها را با فرمان `lein test` اجرا کنید و کاری کنید که همگی قبول شوند:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

سپس تمرین را با این فرمان ارسال کنید:

```
$ exercism submit src/hello_world.clj
```

برای دستورالعمل‌های دقیق‌تر و منابع یادگیری، به [صفحه‌ی زبان Clojure در Exercism](http://exercism.io/languages/clojure) مراجعه کنید.
