# نصب

از [موتور Godot][godot-engine] برای اجرای کد GDScript استفاده می‌شود.
موتور Godot روی Windows، Linux، macOS و Android اجرا می‌شود.



## نصب موتور Godot

موتور Godot را می‌توان مستقیماً از [وب‌سایت موتور Godot][godot-engine] دانلود کرد.
این دانلود شامل یک فایل اجرایی است که نسخه‌ی موتور Godot در نامش آمده است.
نام این فایل باید به `godot` تغییر کند و در یکی از پوشه‌های `$PATH` قرار بگیرد.
پس از کامل کردن نصب، می‌توانید با اجرای این دستور در یک ترمینال بررسی کنید که CLI با موفقیت نصب شده است یا نه:

```bash
godot --version
```

این مسیر از Godot نسخه‌ی ۴.۷.۲ استفاده می‌کند.
