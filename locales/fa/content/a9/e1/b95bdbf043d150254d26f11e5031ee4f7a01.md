# درباره

«ماکرو»ی `use` به ما امکان می‌دهد که ماژول خود را به‌سرعت با قابلیت‌هایی که ماژول دیگری فراهم می‌کند، گسترش دهیم. وقتی ماژولی را `use` می‌کنیم، آن ماژول می‌تواند کدی را به ماژول ما تزریق کند، برای مثال می‌تواند توابعی را تعریف کند، ماژول‌های دیگر را `import` یا `alias` کند یا ویژگی‌های ماژول را تنظیم کند.

اگر تا به حال به فایل‌های test برخی از تمرین‌های Elixir در Exercism نگاه کرده باشید، به احتمال زیاد متوجه شده‌اید که همه‌ی آن‌ها با `use ExUnit.Case` شروع می‌شوند. همین یک خط کد است که ماکروهای `test` و `assert` را در ماژول test در دسترس قرار می‌دهد.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## ماکروی `__using__/1`

اینکه دقیقاً چه اتفاقی می‌افتد وقتی ماژولی را `use` می‌کنید، توسط ماکروی `__using__/1` آن ماژول تعیین می‌شود. این ماکرو یک آرگومان می‌گیرد، یک «لیست کلیدواژه» با گزینه‌ها، و یک [«عبارت نقل‌شده»][concept-ast] برمی‌گرداند. کد موجود در این عبارت نقل‌شده، هنگام فراخوانی `use` به ماژول ما درج می‌شود.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

گزینه‌ها را می‌توان به عنوان آرگومان دوم هنگام فراخوانی `use` ارائه داد، برای مثال `use ExUnit.Case, async: true`. اگر به صراحت داده نشوند، مقدار پیش‌فرض‌شان یک لیست خالی است.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
