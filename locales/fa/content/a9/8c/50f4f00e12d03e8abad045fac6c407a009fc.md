# درباره

«حلقه» روشی است برای اجرای مکرر یک مجموعه از یک یا چند دستور. به هر بار اجرای یک مجموعه دستور، «تکرار» می‌گویند.

## حلقه‌ی While

حلقه‌ی `while` یک مجموعه دستور را تا زمانی اجرا می‌کند که یک عبارت «منطقی» در بالای حلقه «درست» باشد. وقتی عبارت منطقی «غلط» باشد، حلقه از اجرا باز می‌ایستد و اجرا به خط بعدی کد پس از حلقه می‌رود.

اگر عبارت منطقی از همان ابتدا به «غلط» ارزیابی شود، حلقه‌ی `while` اصلاً اجرا نمی‌شود و اجرا به خط بعدی کد پس از حلقه می‌رود.

وجود شرطی برای پایان دادن به حلقه اهمیت دارد؛ در غیر این صورت حلقه بی‌پایان می‌شود و جلوی هرگونه پیشرفت کد را می‌گیرد. اگر `++` از `i` در کد بالا حذف شده بود، یک حلقه‌ی بی‌پایان می‌شد.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

## حلقه‌ی Do

در حلقه‌ی `do` عبارت منطقی در پایین حلقه بررسی می‌شود. حلقه‌ی `do` همیشه حداقل یک بار اجرا می‌شود، مانند مثال زیر

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

انجام همین کار با حلقه‌ی `while` به کد بیشتری نیاز داشت

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## حلقه‌ی For

اغلب یک حلقه متغیری را به‌روزرسانی می‌کند و زمانی که متغیر به مقدار مشخصی برسد، پایان می‌یابد. حلقه‌ی `for` روشی است برای مقداردهی اولیه، به‌روزرسانی و بررسی یک یا چند متغیر در یک سطر و داخل پرانتز. بخش اول برای مقداردهی اولیه به متغیر، بخش دوم برای بررسی متغیر و بخش سوم برای به‌روزرسانی مقدار متغیر است.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

این کد از معادلش با حلقه‌ی `while` کوتاه‌تر است و در عین حال همچنان خواناست.

بخش‌های مقداردهی اولیه و به‌روزرسانی حلقه‌ی `for` می‌توانند با استفاده از عملگر کاما برای جدا کردن عبارت‌های داخل شرط‌ها، بیش از یک متغیر را مدیریت کنند.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

این کد چنین چیزی چاپ می‌کند

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

لازم نیست هیچ‌یک از بخش‌های حلقه‌ی `for` تعریف شود. عبارت بررسی خالی به «درست» ارزیابی می‌شود، بنابراین می‌توان از حلقه‌ی `for` برای ساختن یک حلقه‌ی بی‌پایان به این شکل استفاده کرد

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

این کد از این نظر شبیه حلقه‌ی `while` است که `i` پیش از حلقه مقداردهی اولیه می‌شود و داخل حلقه افزایش می‌یابد. همچنین `i` داخل حلقه بررسی می‌شود و حلقه با دستور `break` پایان می‌یابد.

## دستور `break`

گاهی ممکن است یک حلقه لازم باشد بر اساس شرط خاصی که در عبارت منطقی‌اش بررسی نمی‌شود، پایان یابد. دستور `break` حلقه را پایان می‌دهد و اجرا به خط بعدی کد پس از حلقه می‌رود.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

این کد چنین چیزی چاپ می‌کند

```
i is 0
j is 5
After the loop
```

## دستور `continue`

گاهی لازم است حلقه تکرار بعدی خود را بدون به پایان رساندن تکرار جاری آغاز کند. دستور `continue` اجرای تکرار جاری را متوقف می‌کند و اجرا را از ابتدای تکرار بعدی ادامه می‌دهد.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

این کد چنین چیزی چاپ می‌کند

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

وقتی `i` و `j` هر دو `2` باشند، این کد مقادیر آن‌ها را چاپ نمی‌کند.
