# مقدمه

تابع `switch()` می‌تواند جایگزینی موجز برای زنجیره‌ی طولانی‌ای از آزمون‌های `if` ... `else if` باشد.
متغیری که `switch` روی آن انجام می‌شود معمولاً یک رشته است و در این صورت می‌توان کوتیشن‌ها را از «انتخاب‌گر» حذف کرد.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

توجه کنید که گزینه تنها در صورتی به گزینه‌ی بعدی می‌رسد که مقدارش خالی گذاشته شود، همان‌طور که در مثال بالا برای `M` چنین است.
نیازی نیست مثل برخی زبان‌های دیگر دستورهای `break` را بنویسید.

وقتی `switch` روی نوع‌های `character` انجام می‌شود، مقدار آخر به‌عنوان پیش‌فرض در نظر گرفته می‌شود، همان‌طور که اینجا می‌بینید.
اما در نوع‌های عدد صحیح، نمی‌توان پیش‌فرض تعیین کرد.

## توابع در `dplyr`

`switch` در R پایه بسیار محدود است: فقط می‌تواند با یک ورودی واحد تطابق دقیق برقرار کند.
این کار وقتی R نخستین بار در ۱۹۹۳ منتشر شد منطقی به نظر می‌رسید، اما برای استفاده‌های امروزی به بهبود نیاز دارد.

~~~~exercism/note
همان‌طور که در مفهوم [`Conditionals`][concept-conditionals] هم اشاره شد، مجموعه بسته‌های `tidyverse` طوری طراحی شده است که کارکردهای R پایه را تکمیل کند (و گاهی جایگزین آن شود) بدون آنکه سازگاری با نسخه‌های قبلی را از بین ببرد.

می‌توانید بسته‌ی `dplyr` را با افزودن `library(dplyr)` (برای همان یک بسته) یا `library(tidyverse)` (برای کل مجموعه) به بالای کدتان در دسترس قرار دهید.

کتابخانه‌ی `dplyr` دو تابع اضافی مرتبط با `switch` ارائه می‌دهد.

### توابع `recode_values` و `replace_values`

این دو تابع مرتبط به هم، امکان نگاشت بردارمحور و شبیه به `switch` را از مقادیر قدیمی به مقادیر جدید فراهم می‌کنند.

تفاوت اصلی‌شان این است که `recode_values()` یک بردار کاملاً جدید می‌سازد، در حالی که `replace_values()` به‌روزرسانی جزئی یک بردار موجود را ممکن می‌کند.

تطبیق همچنان دقیق است، اما:

- گزینه‌های سمت چپ می‌توانند بردار باشند و اگر هر یک از عنصرها تطبیق پیدا کند، ورودی تطبیق‌یافته در نظر گرفته می‌شود.
- گزینه‌های سمت چپ و نتیجه‌های سمت راست با یک تیلدا `~` به‌جای `=` به هم پیوند می‌خورند.
- در همه‌ی حالت‌ها می‌توان یک مقدار پیش‌فرض تعیین کرد.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### تابع `case_when`

`case_when` نحوه‌ی نگارش `case_match` را یک گام جلوتر می‌برد: اجازه می‌دهد در سمت چپ `~` هر عبارت منطقی بنویسید.

بردار ورودی (در مثال زیر `x`) به‌عنوان آرگومان داده نمی‌شود؛ فقط باید از قبل تعریف شده باشد.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```
