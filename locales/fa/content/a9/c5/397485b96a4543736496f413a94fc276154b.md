# درباره

عملگرهای اصلی حسابی و مقایسه را می‌توان برای استفاده در کلاس‌ها و ساختارهای خودتان سازگار کرد. به این کار _سربارگذاری عملگر_ می‌گویند.

این [مقاله][operator-overloading] بحثی مفصل درباره‌ی نحوه‌ی نگارش و همچنین این است که کدام عملگرها را می‌توان سربارگذاری کرد و کدام‌ها را نه.

بیشتر عملگرها این شکل را دارند:

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

[عملگرهای تبدیل نوع][ud-conversion-operators] این شکل را دارند:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

عملگرها همانند متدهای ایستا رفتار می‌کنند.

- یک نماد عملگر جای شناسه‌ی متد را می‌گیرد و آن‌ها پارامتر و نوع بازگشتی دارند. قواعد نوع برای پارامترها و نوع بازگشتی با شهود شما همخوان است و می‌توانید به کامپایلر تکیه کنید تا راهنمایی دقیقی ارائه دهد.
- در عملیات دودویی، پارامتر اول آرگومان سمت چپ عملیات را می‌گیرد.
- عملگرها امضایی دارند که در حالت عملیات دودویی شامل دو پارامتر و یک نوع بازگشتی است، و در حالت عملگرهای یکانی شامل یک پارامتر و یک نوع بازگشتی.
- برای عملگرهای دودویی، یکی از نوع‌های پارامتر باید نوع کلاس تعریف‌کننده باشد.
- در مورد تبدیل‌های نوع، یا پارامتر یا نوع بازگشتی باید نوع کلاس تعریف‌کننده باشد.
- برای عملگرهای افزایش و کاهش، پارامتر و نوع بازگشتی باید نوع کلاس تعریف‌کننده باشند.

نمونه‌های نحوه‌ی نگارش:

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

اغلب کارساز است که متد [`Equals()`][equals] را پیاده‌سازی کنید و آن را از عملگر `==` فراخوانی کنید. به همین ترتیب، برای مقایسه‌ها می‌توانید رابط [`IComparable`][icomparable] را پیاده‌سازی کنید. در هر دو حالت، با کمی بیشتر از یک تیر، دو نشان می‌زنید.

باید توجه داشته باشید که نمی‌توانید از نمادهایی که بخشی از مجموعه‌ی استاندارد عملگرها نیستند، عملگر بسازید. فقط می‌توانید از نمادهای موجود برای آن عملیاتی استفاده کنید که مستندات مشخص کرده قابل سربارگذاری هستند. عملگرهایی که می‌توان سربارگذاری کرد [اینجا][overloadable-operators] فهرست شده‌اند.

توجه کنید که ترتیب پارامترها در جایی که نوعشان متفاوت است مهم است. در کد نمونه‌ی بالا، `pt * 10m` عبارتی مجاز است، در حالی که `10m * pt` کامپایل نمی‌شود.
