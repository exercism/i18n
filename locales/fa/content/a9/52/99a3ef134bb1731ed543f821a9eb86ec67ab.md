# مقدمه

عملگر `|>` را «عملگر pipe» می‌نامند. می‌توان از آن برای زنجیره‌کردن فراخوانی توابع استفاده کرد، به این ترتیب که مقدار برگردانده‌شده از فراخوانی تابع قبلی به فراخوانی تابع بعدی داده می‌شود.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

کد بالا معادل کد زیر است:

```gleam
string.append(string.uppercase("hello"), "?!")
```

عملگر pipe مقدار را یا به‌عنوان «آرگومان» اول به فراخوانی تابع می‌دهد، یا به‌عنوان تنها آرگومان به یک فراخوانی جدید، بسته به اینکه کدام‌یک نوع درست را داشته باشد.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

گاهی می‌خواهیم مقدار را در جایگاه دیگری بگذاریم؛ در این حالت می‌توان از «جای‌نگهدار» `_` استفاده کرد تا نشان دهد مقدار باید کجا درج شود.

```gleam
100
|> some_function(1, _, 2)
```
