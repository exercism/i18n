# مقدمه

رشته در Factor دنباله‌ای از نویسه‌ها است. بیشتر واژه‌های واژگان [`sequences`][sequences] روی رشته‌ها هم کار می‌کنند، علاوه بر واژه‌های اختصاصی کار با رشته در [`splitting`][splitting]، [`ascii`][ascii] و هم‌خانواده‌هایشان.

## لیترال رشته

رشته‌ها داخل گیومه‌ی دوتایی نوشته می‌شوند. «دنباله‌های فرار» معمول پشتیبانی می‌شوند: `\n`، `\t`، `\r`، `\\`، `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## طول و اندیس‌گذاری

چون رشته یک دنباله است، واژه‌های `length` و `nth` از [`sequences`][sequences] مستقیم روی آن کار می‌کنند.

`length` تعداد نویسه‌ها را برمی‌گرداند:

```factor
"hello" length .    ! => 5
```

`nth` یک اندیس صفرمبنا و دنباله را می‌گیرد و عنصر آن موقعیت را برمی‌گرداند. برای یک رشته، آن عنصر یک *نویسه* است؛ یعنی یک «کدپوینت» (یک عدد صحیح)، نه یک زیررشته‌ی تک‌نویسه:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## برگشت از نویسه به رشته

برای تبدیل یک کدپوینت تکی به رشته‌ای تک‌نویسه، از `1string ( char -- str )` در [`strings`][strings] استفاده کنید. `CHAR:` شکل زمان تجزیه‌ی یک کدپوینت لیترال است:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## تقسیم

واژگان [`splitting`][splitting] رشته را به قطعه‌هایی تقسیم می‌کند.

`split1` روی *اولین* وقوع یک جداکننده می‌بُرد و هر دو نیمه را برمی‌گرداند:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` روی *هر کدام* از نویسه‌های یک مجموعه‌ی جداکننده می‌بُرد و ممکن است قطعه‌های خالی تولید کند:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (در [`sequences`][sequences]) قطعه‌های خالی را حذف می‌کند:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## برداشتن یک قطعه

وقتی رشته به آرایه‌ای از قطعه‌ها تقسیم شد، `first`، `second`، `third` و `fourth` (در [`sequences`][sequences]) قطعه‌ی آن موقعیت را برمی‌گردانند:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

وقتی می‌خواهید همه‌ی قطعه‌های ابتدایی را یک‌جا روی پشته داشته باشید، `first2` و `first3` دو یا سه‌تا از آن‌ها را در یک مرحله باز می‌کنند:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

روی خود یک رشته، `first` اولین **نویسه** را برمی‌گرداند، یعنی یک کدپوینت، نه یک زیررشته:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## پیراستن

`[ blank? ] trim` (از [`sequences`][sequences]، با `blank?` از واژگان [`ascii`][ascii]) فاصله‌های ابتدا و انتهای رشته را حذف می‌کند:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## تبدیل حالت حروف

`>lower` و `>upper` (از [`ascii`][ascii]) رشته‌ای تازه با حالت حروف تغییر یافته برمی‌گردانند:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## به هم پیوستن

دو واژه از [`sequences`][sequences] رشته را سر هم می‌کنند:

`surround` یک رشته را با یک پیشوند و یک پسوند می‌پیچد:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` دو رشته را با یک جداکننده میانشان به هم می‌چسباند:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
