# دستورالعمل‌ها

دستگاه ساده‌ی نوبت‌دهی خیلی خوب فروش می‌رفت، اما بعضی کاربران از کمبود قابلیت‌های پیشرفته‌اش در مقایسه با مدل‌های دیگری که در بازار موجود بود شکایت داشتند.

سازنده به بازخورد کاربران گوش داد و تصمیم گرفت مدل دلوکسی با قابلیت‌های بیشتر منتشر کند و یک بار دیگر وظیفه‌ی نوشتن نرم‌افزار این دستگاه به شما سپرده شد.

قابلیت‌های جدیدی که به مدل دلوکس اضافه شده‌اند عبارت‌اند از:
- پیگیری شماره‌هایی که هم‌اکنون در صف هستند.
- تعیین حداقل و حداکثر شماره. این ویژگی امکان استفاده از چند دستگاه دلوکس نوبت‌دهی را فراهم می‌کند تا مشتریان را برای بخش‌های مختلف یک مرکز در صف قرار دهید و بخش‌ها را از روی بازه‌ی شماره‌ها از هم تشخیص دهید.
- اجازه دادن به بعضی شماره‌ها برای رد کردن صف، به‌منظور ارائه‌ی خدمات اولویت‌دار به زنان باردار و سالمندان.
- خاموش‌شدن خودکار برای جلوگیری از جا گذاشتن تصادفی دستگاه به مدت کل آخر هفته و هدر رفتن انرژی.

منطق کسب‌وکار دستگاه را پیش‌تر همکارتان پیاده‌سازی کرده و در ماژول `TakeANumberDeluxe.State` قابل مشاهده است. اکنون وظیفه‌ی شما این است که آن را درون یک `GenServer` بگنجانید.

## 1. راه‌اندازی دستگاه

از رفتار `GenServer` در ماژول `TakeANumberDeluxe` استفاده کنید.

تابع `start_link/1` و کالبک لازمِ `GenServer` را پیاده‌سازی کنید.

آرگومانی که به `start_link/1` داده می‌شود یک لیست کلیدواژه است. این لیست شامل کلیدهای `:min_number` و `:max_number` است. مقادیر این کلیدها باید به تابع `TakeANumberDeluxe.State.new/2` داده شوند.

اگر `TakeANumberDeluxe.State.new/2` یک تاپل `{:ok, state}` برگرداند، دستگاه باید راه‌اندازی شود و حالت بازگشتی را به‌عنوان حالت خود در نظر بگیرد. اما اگر در عوض یک تاپل `{:error, error}` برگرداند، دستگاه باید متوقف شود و خطای بازگشتی را دلیل توقف قرار دهد.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

شاید متوجه شده باشید که تابع `TakeANumberDeluxe.State.new/2` یک آرگومان اختیاری سوم هم به اسم `auto_shutdown_timeout` می‌گیرد. ما در آخرین مرحله‌ی این تمرین از آن استفاده خواهیم کرد.

## 2. گزارش حالت دستگاه

تابع `report_state/1` و کالبک لازمِ `GenServer` را پیاده‌سازی کنید. دستگاه باید حالت فعلی خود را به فراخواننده پاسخ دهد.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. قرار دادن شماره‌های جدید در صف

تابع `queue_new_number/1` و کالبک لازمِ `GenServer` را پیاده‌سازی کنید.

باید تابع `TakeANumberDeluxe.State.queue_new_number/1` را با حالت فعلی دستگاه فراخوانی کند.

اگر `TakeANumberDeluxe.State.queue_new_number/1` یک تاپل `{:ok, new_number, new_state}` برگرداند، دستگاه باید با شماره‌ی جدید به فراخواننده پاسخ دهد و حالت جدید را به‌عنوان حالت خود تنظیم کند. اما اگر در عوض یک تاپل `{:error, error}` برگرداند، دستگاه باید با خطا به فراخواننده پاسخ دهد و حالتش را تغییر ندهد.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. ارائه‌ی شماره‌ی بعدی صف

تابع `serve_next_queued_number/2` و کالبک لازمِ `GenServer` را پیاده‌سازی کنید.

باید تابع `TakeANumberDeluxe.State.serve_next_queued_number/2` را با حالت فعلی دستگاه و آرگومان اختیاری دومش، `priority_number`، فراخوانی کند.

اگر `TakeANumberDeluxe.State.serve_next_queued_number/2` یک تاپل `{:ok, next_number, new_state}` برگرداند، دستگاه باید با شماره‌ی بعدی به فراخواننده پاسخ دهد و حالت جدید را به‌عنوان حالت خود تنظیم کند. اما اگر در عوض یک تاپل `{:error, error}` برگرداند، دستگاه باید با خطا به فراخواننده پاسخ دهد و حالتش را تغییر ندهد.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. بازنشانی حالت

تابع `reset_state/1` و کالبک لازمِ `GenServer` را پیاده‌سازی کنید.

باید تابع `TakeANumberDeluxe.State.new/2` را فراخوانی کند تا با استفاده از `min_number` و `max_number` حالت فعلی، حالت جدیدی بسازد. دستگاه باید حالت جدید را به‌عنوان حالت خود تنظیم کند. نباید به فراخواننده پاسخی بدهد.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. پیاده‌سازی خاموش‌شدن خودکار

راه‌اندازی دستگاه را تغییر دهید. باید مقدار کلید `:auto_shutdown_timeout` را در لیست کلیدواژه‌ای که به‌عنوان `init_arg` داده می‌شود بخواند و آن را به‌عنوان آرگومان سوم به `TakeANumberDeluxe.State.new/3` بدهد. اگر `:auto_shutdown_timeout` داده نشده باشد، از مقدار پیش‌فرض `:infinity` استفاده کنید.

بازنشانی حالت دستگاه را طوری تغییر دهید که `auto_shutdown_timeout` را هم به `TakeANumberDeluxe.State.new/3` بدهد.

مقادیر بازگشتی همه‌ی کالبک‌های پیاده‌سازی‌شده (`init/1` و همه‌ی کالبک‌های `handle_*`) را طوری تغییر دهید که یک مهلت زمانی تعیین کنند. از مقدار کلید `:auto_shutdown_timeout` در حالت فعلی دستگاه استفاده کنید. مهلت زمانی را به مقدار بازگشتی `{:stop, reason}` مربوط به `init/1` اضافه نکنید؛ مهلت‌های زمانی فقط پس از آن اعمال می‌شوند که سرور حلقه‌ی دریافت خود را آغاز کرده باشد.

یک کالبک `GenServer` پیاده‌سازی کنید تا پیام `:timeout` را مدیریت کند؛ این پیام اگر دستگاه در بازه‌ی مهلت داده‌شده هیچ پیام دیگری دریافت نکند، برایش فرستاده می‌شود. باید فرایند را با دلیل `:normal` پایان دهد.

مطمئن شوید که پیام‌های غیرمنتظره را هم با نادیده گرفتنشان مدیریت می‌کنید.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
