# معرفی

تابع در Cairo به شما اجازه می‌دهد کد را در یک واحد قابل استفاده‌ی مجدد گروه‌بندی کنید و برنامه‌هایتان را ماژولارتر و خواناتر کنید.
توابع در Cairo از کلیدواژه‌ی `fn` تشکیل شده‌اند که بعد از آن اسم تابع، فهرستی از پارامترها داخل پرانتز و یک بلوک کد می‌آید که مشخص می‌کند تابع چه کاری انجام می‌دهد.

## پارامترهای تابع

در Cairo، نوع همه‌ی پارامترهای تابع باید صریحاً مشخص شود.
برخلاف بعضی زبان‌ها، Cairo نوع‌ها را استنتاج نمی‌کند و مقدار پیش‌فرضی هم برای پارامترها وجود ندارد، پس همه‌ی پارامترها الزامی هستند.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## پارامترها در برابر آرگومان‌ها

تفاوت گذاشتن بین `parameters` و `arguments` مهم است:

- **پارامترها** اسم متغیرهایی هستند که در تعریف تابع به کار می‌روند، مثل `greeting` و `name` در تابع `print_greeting_name`.
- **آرگومان‌ها** مقادیر واقعی‌ای هستند که هنگام فراخوانی تابع به آن پاس داده می‌شوند.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## دستورها و عبارت‌ها

بدنه‌ی تابع از مجموعه‌ای از دستورها ساخته می‌شود که به‌صورت اختیاری با یک عبارت پایان می‌یابند.

- دستورها کارهایی هستند که عملی را انجام می‌دهند و مقداری برنمی‌گردانند.
- عبارت‌ها به یک مقدار حاصل ارزیابی می‌شوند.

ساختن یک متغیر و نسبت‌دادن مقداری به آن با کلیدواژه‌ی `let` یک دستور است.

```rust
let y = 6;
```

اما `6` در دستور بالا یک عبارت است که به مقدار `6` ارزیابی می‌شود.

فراخوانی یک تابع خودش یک عبارت است، چون همیشه به یک مقدار ارزیابی می‌شود: مقدار بازگشتی صریح تابع، اگر مشخص شده باشد، یا در غیر این صورت نوع «unit» که با `()` نشان داده می‌شود.

## مقادیر بازگشتی

توابع Cairo می‌توانند مقادیری را به کدی که آن‌ها را فراخوانی کرده برگردانند.
مقادیر بازگشتی بعد از پارامترها می‌آیند و با یک پیکان `->` از آن‌ها جدا می‌شوند.
در Cairo، مقدار بازگشتی تابع همان مقدار آخرین عبارت در بلوک بدنه‌ی تابع است.
می‌توانید با استفاده از کلیدواژه‌ی `return` و مشخص‌کردن یک مقدار، زودتر از تابع بازگردید.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## فراخوانی توابع

برای فراخوانی یک تابع در Cairo، کافی است اسم تابع را بنویسید و بعد از آن آرگومان‌ها را داخل پرانتز قرار دهید.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
