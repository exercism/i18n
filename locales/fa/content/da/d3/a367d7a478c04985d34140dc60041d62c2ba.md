# دستورالعمل‌ها

در این تمرین قرار است کد بیشتری بنویسید که به آماده کردن و پختن لازانیای فوق‌العاده‌تان از کتاب آشپزی محبوبتان مربوط می‌شود.

چهار کار پیش رو دارید.
کار اول به خود پختن مربوط است و سه کار دیگر به آماده‌سازی بی‌نقص.

## 1. زمان آماده‌سازی را تخمین بزنید

برای لازانیای بعدی که می‌خواهید درست کنید، می‌خواهید مطمئن شوید که زمان کافی کنار گذاشته‌اید تا از پختن لذت ببرید.
قبلاً برنامه‌ریزی کرده‌اید که لازانیایتان چه لایه‌هایی داشته باشد.
حالا می‌خواهید بر این اساس تخمین بزنید که آماده‌سازی چقدر طول می‌کشد.

تابعی به نام `PreparationTime` پیاده‌سازی کنید که یک برش از لایه‌ها را به‌صورت `[]string` و میانگین زمان آماده‌سازی هر لایه را بر حسب دقیقه به‌صورت `int` می‌پذیرد.
تابع باید تخمین کل زمان آماده‌سازی را بر اساس تعداد لایه‌ها به‌صورت یک `int` برگرداند.
زبان Go برای توابع مقدار پیش‌فرض ندارد.
اگر میانگین زمان آماده‌سازی به‌صورت `0` پاس داده شود (مقدار اولیه‌ی پیش‌فرض یک `int`)، باید از مقدار پیش‌فرض `2` استفاده کرد.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. مقدار رشته‌فرنگی و سس لازم را محاسبه کنید

علاوه بر کنار گذاشتن زمان، می‌خواهید مطمئن شوید که سس و رشته‌فرنگی کافی برای پختن لازانیای رویاهایتان دارید.
برای هر لایه‌ی رشته‌فرنگی در لازانیایتان به ۵۰ گرم رشته‌فرنگی نیاز دارید.
برای هر لایه‌ی سس در لازانیایتان به ۰٫۲ لیتر سس نیاز دارید.

تابع `Quantities` را تعریف کنید که یک برش از لایه‌ها را به‌عنوان پارامتر از نوع `[]string` می‌گیرد.
سپس تابع مقدار رشته‌فرنگی و سس لازم برای درست کردن غذایتان را تعیین می‌کند.
نتیجه باید به‌صورت دو مقدار برگردانده شود: `noodles` به‌صورت یک `int` و `sauce` به‌صورت یک `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. ماده‌ی مخفی را اضافه کنید

مدتی پیش به دیدن دوستی رفتید و آنجا لازانیا خوردید.
فوق‌العاده بود و یک ویژگی خاص داشت.
آن دوست فهرست مواد اولیه را برایتان فرستاد و گفت که آخرین مورد در فهرست همان «ماده‌ی مخفی» است که غذا را این‌قدر خاص کرده بود.
حالا می‌خواهید آن ماده‌ی مخفی را به دستور پخت خودتان هم اضافه کنید.

تابعی به نام `AddSecretIngredient` بنویسید که دو برش از مواد اولیه از نوع `[]string` را به‌عنوان پارامتر می‌پذیرد.
پارامتر اول فهرستی است که دوستتان برایتان فرستاده و پارامتر دوم فهرست مواد اولیه‌ی دستور پخت خودتان است.
آخرین عنصر در فهرست مواد اولیه‌یتان همیشه `"?"` است.
تابع باید آن را با آخرین مورد از فهرست دوستتان جایگزین کند.
**توجه:** تابع `AddSecretIngredient` چیزی برنمی‌گرداند؛ باید فهرست مواد اولیه‌ی خودتان را مستقیماً تغییر دهید.
فهرست مواد اولیه‌ی دوستتان **نباید** تغییر کند.
همچنین، چون `slice` به‌صورت اشاره‌گر به تابع پاس داده می‌شود، تغییرات روی دو آرگومان `[]string` که به `AddSecretIngredient` پاس داده می‌شوند، مستقیماً اعمال می‌شود.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. دستور پخت را متناسب‌سازی کنید

مقادیری که در کتاب آشپزی شما آمده فقط برای دو پرس لازانیا کافی است.
چون می‌خواهید دفعه‌ی بعد برای افراد بیشتری آشپزی کنید، می‌خواهید مقدار مواد را برای تعداد پرس‌های مختلف حساب کنید.

تابعی به نام `ScaleRecipe` پیاده‌سازی کنید که دو پارامتر می‌گیرد.

- یک برش از مقادیر `float64` که برای ۲ پرس لازم است.
- تعداد پرس‌هایی که می‌خواهید بپزید.

تابع باید یک برش از مقادیر `float64` را برگرداند که برای تعداد پرس‌های مورد نظر لازم است.
با این حال می‌خواهید دستور پخت اصلی را حفظ کنید.
یعنی آرگومان `quantities` نباید در این تابع تغییر کند.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
