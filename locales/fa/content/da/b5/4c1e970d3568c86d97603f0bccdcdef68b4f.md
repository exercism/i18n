# Break، Continue

وقتی از یک ساختار کنترلی حلقه یا تکرار استفاده می‌کنید، کلیدواژه‌های `break` و `continue` می‌توانند به کنترل جریان برنامه کمک کنند.
کلیدواژه‌ی `break` از حلقه به محدوده‌ی بیرونی خارج می‌شود و در نتیجه حلقه را خاتمه می‌دهد.
کلیدواژه‌ی `continue` باقی‌مانده‌ی تکرار جاری را رد می‌کند و حلقه را از ابتدای تکرار بعدی از سر می‌گیرد.
هرچند کم پیش می‌آید، می‌توان عددی را همراه با کلیدواژه آورد تا مشخص کند از چند بستر باید خارج شد یا به تکرار بعدی رفت.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

در مثال قبلی، `continue` پنج (۵) بار اجرا می‌شود، اما در تکرار ششم (۶)، `break` اجرا می‌شود و همین باعث می‌شود کد از حلقه خارج شود.
