# دستورالعمل‌ها

فصل نت‌بال به پایان رسیده است و جدول رده‌بندی تعیین می‌کند چه کسانی در فینال بازی می‌کنند.

قالب اولیه یک کلاس `TEAM` در اختیارتان می‌گذارد. `FINALS_LADDER` را زیر آن بنویسید.

## 1. چه کسی بالای کیست؟

`higher` دو تیم می‌گیرد و برمی‌گرداند که آیا تیم اول بالاتر از تیم دوم قرار می‌گیرد یا نه. تیمی که امتیاز بیشتری دارد بالاتر می‌آید. تیم‌هایی که امتیازشان برابر است با تفاضل گل از هم جدا می‌شوند و تیمی که تفاضل گل بیشتری دارد بالاتر می‌آید.

```sather
FINALS_LADDER::higher(#TEAM("Vixens", 24, 40), #TEAM("Magpies", 20, 90))
-- => true
```

## 2. جدول رده‌بندی

`ladder` تیم‌ها را در هر ترتیبی می‌گیرد و آن‌ها را رتبه‌بندی‌شده برمی‌گرداند. آرایه‌ای که تحویل داده می‌شود باید دست‌نخورده بماند.

```sather
FINALS_LADDER::ladder(teams)
-- => the same teams, best first
```

## 3. جدول را بخوانید

`names` آرایه‌ای از تیم‌ها می‌گیرد و اسم آن‌ها را که با `", "` به هم پیوسته‌اند برمی‌گرداند.

```sather
FINALS_LADDER::names(FINALS_LADDER::ladder(teams))
-- => "Vixens, Magpies, Swifts"
```

## 4. قهرمانان

`premiers` تیم‌ها را در هر ترتیبی می‌گیرد و اسم تیمی را که در صدر است برمی‌گرداند. اگر هیچ تیمی وجود نداشته باشد، پاسخ `""` است.

```sather
FINALS_LADDER::premiers(teams)
-- => "Vixens"
```

## 5. یک ترتیب کاملاً متفاوت

`shortest_first` آرایه‌ای از رشته‌ها می‌گیرد و آن‌ها را بر اساس طول، از کوتاه‌ترین، مرتب‌شده برمی‌گرداند. رشته‌هایی که طول یکسان دارند به ترتیب الفبا می‌آیند.

```sather
FINALS_LADDER::shortest_first(|"Magpies", "Vixens", "Swifts"|)
-- => "Swifts", "Vixens", "Magpies"
```

این قاعده‌ی شکستن تساوی تزئینی نیست. مرتب‌سازی پایدار نیست، پس بدون آن، دو اسم با طول یکسان ممکن است به هر ترتیبی بیرون بیایند.

این همان روال مرتب‌سازی کار ۲ است که قاعده‌ی متفاوتی به آن داده شده است. نکته‌ی تمرین همین است.
