# مقدمه

[فرم خاص `with`][with] راهی فراهم می‌کند تا روی «مسیر موفق» در یک زنجیره از گام‌هایی که ممکن است شکست بخورند تمرکز کنید و رسیدگی به شکست‌ها را به بعد موکول کنید.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

در هر گام، اگر یک شاخه مطابقت داشته باشد، زنجیره ادامه می‌یابد تا اینکه بلوک `do` اجرا شود. اگر یکی از مطابقت‌ها شکست بخورد، زنجیره متوقف می‌شود و شاخه‌ی نامطابق برگردانده می‌شود. شما می‌توانید از یک بلوک `else` برای گرفتن مطابقت‌های ناموفق و تغییر مقدار بازگشتی استفاده کنید.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
