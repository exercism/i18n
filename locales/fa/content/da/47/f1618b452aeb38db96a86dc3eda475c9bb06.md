# نصب

## پیشگفتار

اگرچه Regina Rexx به‌طور گسترده‌ای پورت شده است، دستورالعمل‌های نصب بر پلتفرم‌های دسکتاپ ۶۴ بیتی که Windows، Linux یا MacOS اجرا می‌کنند تمرکز خواهند داشت.

## مراحل نصب

لطفاً توجه داشته باشید که این مسیر انتظار دارد آخرین نسخه‌ی [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) نصب شده باشد (نسخه‌ی 3.9.5، در زمان نگارش این متن). پیوند ارائه‌شده شما را مستقیم به بخش «Files» می‌برد که از آنجا یک فایل را برای دانلود انتخاب می‌کنید.

### Windows

نصب برای اجرا به‌صورت بومی زیر Windows (از طریق پنجره‌ی CMD یا Powershell) به‌سادگی در مرورگر و با دکمه‌ی [`Download Latest Version`](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/Regina395w64.exe/download) انجام می‌شود. کافی است کلیک کنید، دانلود کنید و نصب کنید.

اگر محیط‌های شبیه‌سازی Linux مانند موارد زیر را دارید یا می‌خواهید از آن‌ها استفاده کنید:

* [Git for Windows](https://gitforwindows.org/)
* [Cygwin](https://cygwin.com/)
* [MinGW](http://mingw.org/)

فایل‌های باینری بومی Windows مربوط به Regina باید قابل دسترس باشند، پس می‌توانید به‌سادگی آن‌ها را در این محیط‌ها اجرا کنید و برای بیشتر کاربردها این کافی است.

با این حال، یک نکته‌ی احتیاطی این است که دستور ADDRESS درست کار نمی‌کند (چون به سیستم‌عامل میزبان متصل می‌شود). برای بهترین نتیجه در این محیط‌ها، بسته‌ی مخصوص آن محیط را دریافت کنید و نصبش کنید. برای نمونه، وب‌سایت Regina یک نسخه‌ی [مخصوص Cygwin](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-pc-cygwin.tgz/download) را میزبانی می‌کند که می‌توان آن را نصب کرد.

در غیر این صورت، اگر توزیع _واقعی_ Linux زیر Windows مانند [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) یا [Virtual Box](https://www.virtualbox.org/) را دارید یا می‌خواهید استفاده کنید، کافی است دستورالعمل‌های بخش Linux را برای توزیع مربوطه دنبال کنید.

### Linux

نصب روی Linux معمولاً وقتی از مدیر بسته‌ی سیستم استفاده می‌کنید کاملاً سرراست است. اما وقتی بسته‌های موجود _آخرین_ نسخه‌ی در دسترس نباشند مشکل پیش می‌آید. متأسفانه وضعیت Regina همین است.

نصب مبتنی بر بسته هنوز ممکن است، به شرط آنکه آخرین بسته را به‌صورت دستی دریافت کنید. وب‌سایت [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) بسته‌هایی برای توزیع‌های خانواده‌ی Debian (شامل Ubuntu) و خانواده‌ی RHEL (شامل Fedora، CentOS، Rocky و Alma) و دیگران میزبانی می‌کند.

برای توزیع انتخابی، باید دو بسته دانلود کنید، یک بسته‌ی کتابخانه و یک بسته‌ی باینری. مثلاً برای نصب روی Debian یا Ubuntu این‌گونه عمل کنید:

```plain
sudo apt update && sudo apt -y install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx_3.9.5-2_amd64-Debian-11.deb > regina-rexx_3.9.5-2_amd64-Debian-11.deb
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3_3.9.5-2_amd64-Debian-11.deb > libregina3_3.9.5-2_amd64-Debian-11.deb
sudo apt -y install libregina3_3.9.5-2_amd64-Debian-11.deb regina-rexx_3.9.5-2_amd64-Debian-11.deb
```

و روی CentOS و RHEL 7، این را امتحان کنید:
```plain
sudo yum update && sudo yum install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
sudo yum localinstall libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
```

و روی Fedora، Rocky و Alma امتحان کنید:
```plain
sudo dnf update && sudo dnf install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
sudo dnf localinstall libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
```

هرجا نصب مبتنی بر بسته ممکن نباشد، یا به هر دلیل مشکل‌دار از آب دربیاید، همیشه می‌توان از کد منبع ساخت؛ آرشیو را این‌گونه می‌توان دریافت کرد:

```plain
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5.tar.gz > regina-rexx-3.9.5.tar.gz
```

با فرض اینکه ابزارهای استاندارد ساخت (gcc، make) نصب هستند (اگر نیستند، دستورالعمل‌های اینجا را دنبال کنید: [Install Development Tools](https://ostechnix.com/install-development-tools-linux/))، این مراحل را انجام دهید:

```plain
tar -xzvf regina-rexx-3.9.5.tar.gz && cd regina-rexx-3.9.5
./configure
sudo make
sudo make install
```

کتابخانه (`libregina.so`) و دو مجموعه فایل باینری (`rexx` و `regina`) نصب می‌شوند (مکان پیش‌فرض `/usr/local/bin` است).

فایل باینری `rexx` به‌صورت ایستا پیوند داده شده است، پس خودکفا و آماده‌ی استفاده است.

فایل باینری `regina` به‌صورت پویا پیوند داده شده است، بنابراین کمی پیکربندی لازم دارد تا بتواند کتابخانه‌ی اشتراکی `libregina.so` را در زمان اجرا پیدا کند. برای این کار این مراحل را دنبال کنید:

```plain
# Configure shared library location
sudo su
echo /usr/local/lib64/ > /etc/ld.so.conf.d/regina-rexx-3.9.5-x86_64.conf
echo /usr/local/lib64/regina-rexx/addons > /etc/ld.so.conf.d/regina-rexx-addons-x86_64.conf
cd /usr/local/lib64
rm -f libregina.so libregina.so.3
ln -s libregina.so.3.9 libregina.so
ln -s libregina.so.3.9 libregina.so.3
ldconfig
exit

# Check symbolic link creation
ls -l /usr/local/lib64/

# Output should be similar. Note symbolic links.
-rw-r--r--. 1 root root 3887554 Dec  1 18:22 libregina.a
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so -> libregina.so.3.9
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so.3 -> libregina.so.3.9
-rwxr-xr-x. 1 root root  574104 Dec  1 18:22 libregina.so.3.9
drwxr-xr-x. 2 root root      26 Dec  1 18:22 pkgconfig
drwxr-xr-x. 4 root root      33 Dec  1 18:22 regina-rexx

# Check library path, and executable using that path
ldconfig -p | grep regina
ldd /usr/local/bin/regina

# Alternate for local user
export LD_LIBRARY_PATH=${LD_LIBRARY_PATH}:/usr/local/lib64:/usr/local/lib64/regina-rexx/addons
```

لطفاً توجه داشته باشید که ساخت از کد منبع و پیکربندی سیستمی همراه آن، کاری است که بهتر است کاربران باتجربه انجام دهند.

### MacOS

نصب فرایندی سه مرحله‌ای است:

* مدیر بسته‌ی [Homebrew](https://brew.sh) را نصب کنید
* برنامه‌ی `Terminal` را پیدا کنید و اجرا کنید
* از خط فرمان `Terminal`، این را وارد کنید:

   `brew install regina-rexx`

این کار _باید_ آخرین نسخه را نصب کند.

اگر این اتفاق نیفتاد، می‌توانید بسته‌ی [Regina for MacOS](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-apple-darwin21.6.0.tgz/download) را دانلود و به‌صورت دستی نصب کنید.

## پس از نصب

### بررسی نصب

پس از کامل کردن نصب، می‌توانید با اجرای این دستور در ترمینال بررسی کنید که [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) با موفقیت نصب شده است یا نه:

```plain
rexx --version=v
```

روی هر دو پلتفرم Windows و Linux، خروجی زیر در ترمینال ظاهر می‌شود:

```plain
3.9.5
```

که شماره‌ی نسخه‌ی مفسر است.

یک باینری دوم به اسم `regina` هم نصب می‌شود. این فایل از هر جهت با `rexx` یکسان است، جز اینکه به یک کتابخانه‌ی اشتراکی پیوند می‌خورد، و اگر بخواهید به توابع کمکی بیرونی دسترسی داشته باشید، مفسری است که باید به‌جای آن استفاده کنید. بخش [دسترسی به روال‌های بیرونی](###accessing-external-routines) را ببینید.

برای شروع استفاده از این مسیر نیازی به نصب هیچ نرم‌افزار دیگری نیست (با فرض اینکه Exercism CLI نصب شده باشد).

یادداشت‌های استفاده‌ی زیر، مقدمات پایه‌ای برای کار با مفسر از خط فرمان فراهم می‌کند.

### نحوه‌ی استفاده

یک اسکریپت Rexx معمولاً پسوند _`.rexx`_ دارد، هرچند این اجباری نیست، چون مفسر تلاش می‌کند هر نام فایلی را که به‌عنوان آرگومان پاس داده شود اجرا کند و اگر کد Rexx معتبری داشته باشد، با موفقیت اجرا می‌شود.

دستور زیر تلاش می‌کند فایلی به اسم `hello.rexx` را اجرا کند:

```plain
rexx hello.rexx
```

با فرض اینکه فایل حاوی کد زیر باشد:

```rexx
say "Hello, world!"
exit 0
```

آن‌گاه خروجی ترمینال این خواهد بود:

```plain
Hello, world!
```

همین خروجی ترمینال ظاهر می‌شد اگر نام فایل به `hello.txt` تغییر می‌کرد و این‌گونه اجرا می‌شد:

```plain
rexx hello.txt
```

خوب است بدانید که کد اسکریپت را می‌توان به‌جای قرار گرفتن در یک فایل، از طریق pipe به مفسر فرستاد. کد قبلی را می‌توان این‌گونه با pipe اجرا کرد:

```plain
echo "say 'Hello, world' ; exit 0" | rexx
```

و روی ترمینال Linux یا Powershell در Windows به یک اندازه کار می‌کند.

### استفاده‌ی پیشرفته

به فایل‌های اسکریپت می‌توان یک یا چند آرگومان خط فرمان پاس داد، و آن‌ها می‌توانند کدهای بازگشت عدد صحیح دلخواه برگردانند. اما مفسر باید بداند که چند آرگومان به اسکریپت پاس داده می‌شود، و این کار با گزینه‌ی `-a` انجام می‌شود.

برای نمونه، فرض کنید فایل `multiarg.rexx` حاوی کد زیر باشد:

```rexx
say "My name is" ARG(1) || ", your name is" ARG(2) || ", and the script return code will be" ARG(3) || "."
exit ABS(ARG(3))
```

برای اینکه چند آرگومان اسکریپت درست تفسیر شوند، اسکریپت این‌گونه اجرا می‌شود:

```plain
rexx -a multiarg.rexx "John" "Jill" 5
```

که خروجی زیر را در ترمینال به دنبال دارد:

```plain
My name is John, your name is Jill, and the script return code will be 5.
```

و کد بازگشت برنامه (که در Linux با `$?` و در Windows با `%errorlevel%` قابل دسترسی است) روی مقدار ۵ تنظیم می‌شود.

### دسترسی به روال‌های بیرونی

Regina از روال‌هایی که در کتابخانه‌های اشتراکی بیرونی قرار دارند پشتیبانی می‌کند. چند مورد از آن‌ها در وب‌سایت Regina موجود است. اما نصب این کتابخانه‌ها در اینجا بحث نمی‌شود.

Regina یکی از این کتابخانه‌ها، یعنی _regutil_ را همراه خود دارد. این کتابخانه چند روال همه‌کاره دارد، از جمله برای ریاضیات، دستکاری فایل و سیستم فایل، و کارهای دسترسی به سیستم.

هیچ مرحله‌ی نصب دیگری لازم نیست. اما برای استفاده از این روال‌ها در یک اسکریپت، باید هنگام بارگذاری مفسر ثبت شوند. این کار به بیش از دو فراخوانی تابع نیاز ندارد و فرایند در ادامه نشان داده شده است.

فایل `access-external.rexx` حاوی کد زیر است:

```rexx
/* Register external library and functions */
call RxFuncAdd 'SysLoadFuncs', 'regutil', 'SysLoadFuncs'
call SysLoadFuncs

say "Value of pi is" SysPi()
say "Square root of 25 is" SysSqrt(25)
say "Square root of 2 is" SysSqrt(2)

/* Deregister */
call SysDropFuncs

exit 0
```

برای بارگذاری و استفاده از این روال‌ها باید از فایل باینری `regina` استفاده کرد، پس اسکریپت این‌گونه اجرا می‌شود:

```plain
regina access-external.rexx
```

و خروجی زیر در ترمینال ظاهر می‌شود:

```plain
Value of pi is 3.141592654
Square root of 25 is 5.000000000
Square root of 2 is 1.414213562
```

اگر به‌جای آن از فایل باینری `rexx` استفاده شده بود، خروجی ترمینال روی پلتفرم Windows این می‌شد:

```plain
'SYSLOADFUNCS' is not recognized as an internal or external command,
operable program or batch file.
'SYSPI' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSDROPFUNCS' is not recognized as an internal or external command,
operable program or batch file.
```

و روی پلتفرم Linux، خروجی ترمینال این می‌شد:

```plain
sh: SYSLOADFUNCS: command not found
sh: SYSPI: command not found
sh: SYSSQRT: command not found
sh: SYSSQRT: command not found
sh: SYSDROPFUNCS: command not found
```
