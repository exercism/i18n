# درباره

`<iota>` در Factor یک دنباله‌ی *مجازی* از اعداد صحیح `0, 1, …, n-1` تولید می‌کند. پیمایش آن با `map` دنباله‌ی جدول‌ی‌شده‌ای به دست می‌دهد که هر عنصرش تابعی از موقعیت خودش است:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

دو مورد به شما امکان می‌دهند یک دنباله از کدهای عدد صحیح را به رشته تبدیل کنید:

| word      | نقش                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | لیترال زمان تجزیه که کدپوینت یک نویسه را روی پشته می‌گذارد |
| `>string` | تبدیل یک دنباله از کدپوینت‌ها به یک رشته                |

این دو با هم، روش استاندارد ساختن ردیفی از نویسه‌ها را می‌سازند که بر اساس موقعیت نمایه شده‌اند:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

انتخاب نویسه با `if` (یا `?`) درون کوتیشن باعث می‌شود تصمیم‌گیری برای هر موقعیت نزدیک به همان نمایه‌ای بماند که به آن وابسته است.
