# از جایگذاری رشته استفاده کنید

برای ساختن پویای یک رشته، به‌جای به‌هم‌چسباندن رشته یا استفاده از `StringBuilder`، از [«جایگذاری رشته»](https://docs.scala-lang.org/overviews/core/string-interpolation.html) استفاده کنید.

مزیت اصلی این است که کد جایگذاری رشته معمولاً از به‌هم‌چسباندن رشته یا `StringBuilder` خواناتر است.
