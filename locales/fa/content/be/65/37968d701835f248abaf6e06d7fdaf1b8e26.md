# مقدمه

در Haxe، یک «نوع انتزاعی» نوعی است که در زمان اجرا نوع متفاوتی است. این یک قابلیت زمان کامپایل است که انواعی را «روی» انواع مشخص تعریف می‌کند تا رفتارشان را تغییر دهد یا گسترش دهد:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

در اینجا نوع `AbstractInt` را با استفاده از کلیدواژه‌ی `abstract` اعلان می‌کنیم. نحوه‌ی نگارش آن بسیار شبیه به `class` است. و درست مثل کلاس‌ها، انواع انتزاعی می‌توانند متد داشته باشند. همچنین می‌توان آن‌ها را نمونه‌سازی کرد و درست مثل کلاس‌ها به کار برد:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
