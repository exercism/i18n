# درباره

`List` بسیار شبیه به [`Array`][array] است. اما تفاوت‌های مهمی وجود دارد که نمی‌خواهید از آن‌ها بگذرید:

1. یک لیست را نمی‌توان با کروشه ایندکس کرد، یعنی `[0]`.
2. یک لیست را نمی‌توان مقداردهی اولیه کرد.
3. comprehension برای لیست‌ها وجود ندارد.
4. یک لیست می‌تواند در حین پیمایش، عناصر خود را آزادانه تغییر دهد.

`List` عضوی از پکیج `haxe.ds` است، پس هر بار که بخواهید از لیست‌ها استفاده کنید، باید پکیج آن را `import` کنید:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
