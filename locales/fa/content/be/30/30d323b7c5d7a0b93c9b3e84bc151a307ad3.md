# درباره

از `PHP 8.0.0` به بعد در دسترس است؛ **اعلان نوع اجتماع** مقادیری از چند نوع متفاوت را می‌پذیرد، نه فقط یک نوع. نوع اجتماع با استفاده از خط عمودی (`|`) برای جدا کردن نوع‌ها تعریف می‌شود.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## نکات ظریف

- نوع‌های `null` را می‌توان با `?Type` یا `Type1|Type2|null` به‌صورت _nullable_ اعلام کرد.
- اگر نوع‌های تکراری یا زائد اعلام شوند، خطای زمان کامپایل رخ می‌دهد.
- `void` را نمی‌توان به‌عنوان بخشی از اعلان نوع اجتماع به کار برد.
