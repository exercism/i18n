# https://www.php.net/manual/en/language.basic-syntax.phptags.php"عملگر تفکیک محدوده

عملگر تفکیک محدوده (`::`) به ما امکان می‌دهد تا به یک کلاس ارجاع دهیم و به ثابت‌ها، ویژگی‌های ایستا یا متدهای ایستای آن دسترسی پیدا کنیم.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## استفاده از `self` و `static` همراه با عملگر تفکیک محدوده

گاهی ممکن است لازم باشد که یک شیء به محدوده‌ی خودش ارجاع دهد. برای همین، «کلیدواژه»ی `self` به یک کلاس اجازه می‌دهد تا به محدوده‌ی خودش ارجاع دهد. استفاده از کلیدواژه‌ی `self` کلاس را از اسم خودش جدا می‌کند و به این ترتیب نگهداری کد در طول زمان آسان‌تر می‌شود.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

اما `self` از نظر واژگانی به کلاسی که در آن ظاهر می‌شود مقید است.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

ارزیابی `MyOtherClass::getMyValue` همچنان به `1` می‌انجامد، نه به `99`. برای حل این مشکل، از کلیدواژه‌ی `static` همراه با عملگر تفکیک محدوده استفاده کنید تا ارجاع را به‌صورت «پیوند دیرهنگام» به کلاس نواده‌ی جاری متصل کنید.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## استفاده از `parent` همراه با عملگر تفکیک محدوده

ممکن است نیاز باشد به‌طور مشخص به ثابتی، ویژگی‌ای یا متدی که در محدوده‌ی والد در دسترس است ارجاع دهید:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

بیشتر اوقات در برنامه‌نویسی شیءگرا، از `parent` برای فراخوانی سازنده‌ی والد هنگام نمونه‌سازی یک شیء استفاده می‌شود:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## نکات احتیاطی

### سطح دسترسی ثابت، ویژگی و متد

عملگر تفکیک محدوده همچنان از قواعدی پیروی می‌کند که اصلاح‌کننده‌های دسترسی `public`، `private` و `protected` تعیین کرده‌اند.
