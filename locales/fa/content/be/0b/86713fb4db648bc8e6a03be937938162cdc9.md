# مقدمه

در Go، `for range` یک بلوک کد را برای مقدارهای حاصل از یک «عبارت بازه» تکرار می‌کند.
عبارت بازه تعیین می‌کند که هر تکرار یک مقدار تولید می‌کند یا دو مقدار.

## عبارت‌های بازه

### پیمایش روی یک برش

`range` روی یک «برش»، اندیس و مقدار هر «عنصر» را به ترتیب تولید می‌کند:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### پیمایش روی یک نگاشت

`range` روی یک «نگاشت»، هر «کلید» و مقدار را تولید می‌کند، اما ترتیب تکرار تضمین نمی‌شود.
Go عمداً ترتیب تکرار نگاشت را تصادفی می‌کند، بنابراین ممکن است یک برنامه‌ی یکسان در هر اجرا خروجی متفاوتی تولید کند.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### پیمایش روی یک رشته

`range` روی یک «رشته»، اندیس بایت و هر «رون» (نقطه‌ی کد یونیکد) را تولید می‌کند.
در مثال زیر، `子` سه بایت را اشغال می‌کند، بنابراین `猫` از اندیس بایت `3` شروع می‌شود، نه `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

اگر به اندیس‌های رون نیاز دارید، رشته را به یک برش از رون‌ها تبدیل کنید:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### پیمایش روی یک عدد صحیح

`range` می‌تواند مستقیماً روی یک «عدد صحیح» تکرار کند و مقدارهایی از `0` تا قبل از آن عدد، بدون اینکه خود آن عدد را شامل شود، تولید کند.
مقادیر صفر و منفی معتبرند اما هیچ تکراری تولید نمی‌کنند.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### پیمایش روی یک تکرارگر

`range` یک «تکرارگر» از نوع `iter.Seq[V]` یا `iter.Seq2[K, V]` را می‌پذیرد.
یک تکرارگر تابعی است که دنباله‌ای از مقدارها را یکی‌یکی تولید می‌کند.
سپس `range` می‌تواند آن مقدارها را یکی‌یکی طی کند.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### پیمایش روی یک کانال

در پایان، `range` می‌تواند مقدارهایی را دریافت کند که از طریق یک «کانال» فرستاده می‌شوند تا زمانی که آن کانال جای دیگری بسته شود.
کانال‌ها بعداً در برنامه‌ی درسی مسیر با جزئیات بیشتری بررسی می‌شوند.

## حذف اندیس یا مقدار

اگر متغیری اعلام شود اما هرگز استفاده نشود، Go کامپایل نمی‌شود.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

اگر فقط مقدار لازم است، اندیس یا کلید را به `_` اختصاص دهید تا آن را نادیده بگیرید.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

اگر فقط اندیس لازم است، آن را کاملاً حذف کنید:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

اگر به هیچ‌کدام از اندیس و مقدار نیازی نیست، هر دو را می‌توان حذف کرد:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
