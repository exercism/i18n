# درباره

«عبارت باقاعده» که به آن «regex» هم می‌گویند، الگوی کوچکی است که شکل یک متن را توصیف می‌کند. ابزارهای عبارت باقاعده‌ی Factor در واژگان [`regexp`][regexp] قرار دارند و الگو به‌صورت یک مقدار ثابت میان `R/ ` و `/` نوشته می‌شود.

بیشتر نویسه‌ها در یک الگو با خودشان تطبیق پیدا می‌کنند. قدرت بیان از کلاس‌های نویسه و تکرارکننده‌ها می‌آید:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

پس `R/ [A-Z]{2}-\d{4}/` با «دو حرف بزرگ، یک خط تیره، چهار رقم» تطبیق پیدا می‌کند.

## تطبیق با کل رشته در برابر جست‌وجو

`matches?` فقط زمانی موفق می‌شود که *کل* رشته با الگو تطبیق پیدا کند. بقیه‌ی واژه‌ها *درون* یک رشته جست‌وجو می‌کنند:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## برش‌ها

`first-match` و `re-split` اشیای `slice` را برمی‌گردانند که نماهایی سبک به رشته‌ی اصلی هستند، نه رشته‌های تازه. هرگاه به یک رشته‌ی مستقل نیاز داشته باشید (مثلاً برای مقایسه با یک رشته‌ی ثابت)، برش را با `>string` به رشته تبدیل کنید. `all-matching-subseqs` از پیش رشته برمی‌گرداند.

## جایگزینی

`re-replace` هر تطبیق را با یک رشته‌ی جایگزین عوض می‌کند و نتیجه را برمی‌گرداند:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## ساختن الگو در زمان اجرا

`R/ /` هنگام بارگذاری فایل تجزیه می‌شود. برای ساختن یک الگو از رشته‌ای که در زمان اجرا محاسبه می‌شود، از `<regexp>` استفاده کنید:

```
<regexp> ( string -- regexp )
```
