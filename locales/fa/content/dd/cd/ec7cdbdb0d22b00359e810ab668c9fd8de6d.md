# دستورالعمل‌ها

در این تمرین باید چند تابع پیاده‌سازی کنید تا فهرستی از زبان‌های برنامه‌نویسی را دستکاری کنید.

## 1. تابعی تعریف کنید که یک فهرست زبان خالی را برگرداند

تابع `new` را تعریف کنید که هیچ آرگومانی نمی‌گیرد و یک فهرست خالی برمی‌گرداند.

```haskell
new
-- -> []
```

## 2. تابعی تعریف کنید که زبانی را به فهرست اضافه کند

تابع `add/2` را تعریف کنید که ۲ آرگومان می‌گیرد (یک _فهرست زبان_ و یک رشته‌ی متنی که یک _زبان_ است).
باید فهرست حاصل را برگرداند که زبان جدید به ابتدای فهرست داده‌شده اضافه شده باشد.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. تابعی تعریف کنید که زبانی را از فهرست حذف کند

تابع `remove` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_).
باید فهرست را بدون اولین عنصر برگرداند. فرض کنید فهرست همیشه حداقل یک عنصر دارد.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. تابعی تعریف کنید که اولین عنصر فهرست را برگرداند

تابع `first` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_).
باید اولین زبان فهرست را برگرداند.
فرض کنید فهرست همیشه حداقل یک عنصر دارد.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. تابعی تعریف کنید که تعداد زبان‌های فهرست را برگرداند

تابع `count` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_). 
باید تعداد زبان‌های فهرست را برگرداند.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. تابعی تعریف کنید که مشخص کند فهرست یک زبان تابعی دارد یا نه

تابع `isFunctionalList` را تعریف کنید که ۱ آرگومان می‌گیرد (یک _فهرست زبان_). 
باید یک مقدار «منطقی» برگرداند. 
اگر _"Haskell"_ یکی از زبان‌های فهرست باشد، باید `True` را برگرداند.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
