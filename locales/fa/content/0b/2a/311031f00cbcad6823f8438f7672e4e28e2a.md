# پیوست دستورالعمل‌ها

## دستورالعمل‌های مخصوص این مسیر

برای این تمرین باید یک **locale** به اسم `robot` تعریف کنید که **اسم‌های** `position` و `direction` و **فعل** `move` را تعریف می‌کند.

- **فعل** `create` در `robot`، موقعیت و جهت اولیه را به‌صورت آرایه‌ای از جعبه‌ها می‌گیرد.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` مقادیر `position` و `direction` را در **نمونه**ی ساخته‌شده به‌روزرسانی می‌کند.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
