# اعداد صحیح

اعداد صحیح اعداد کاملی هستند که به مجموعه‌ی `{..., -2, -1, 0, 1, 2, ...}` تعلق دارند.
بیشینه و کمینه‌ی مقدار یک عدد صحیح را سیستمی تعیین می‌کند که PHP در آن اجرا می‌شود.
معمولاً در بیشتر سیستم‌های مدرن، عدد صحیح یک مقدار ۶۴ بیتی است، یعنی می‌تواند بازه‌ای از `-9_223_372_036_854_775_808` تا `9_223_372_036_854_775_807` را (با احتساب دو سر بازه) نمایش دهد.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

می‌توانید اعداد صحیح را با یک پیشوند مبنا، در مبنایی غیر از ۱۰ بنویسید:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
