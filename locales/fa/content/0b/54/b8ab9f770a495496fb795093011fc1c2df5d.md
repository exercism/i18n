## گزینه‌های اضافی خط فرمان jq

در تست‌ها گزینه‌های اضافی‌ای برای `jq` می‌بینید.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

این‌ها چه هستند؟

- `-s`

  این حالت «slurp» نام دارد.
  به‌جای اینکه ورودی به‌صورت جریانی از اشیای JSON پردازش شود،
  همه‌ی ورودی در یک آرایه جمع می‌شود.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  ممکن است `-r` را پیش‌تر دیده باشید که رشته‌های «خام» را بدون علامت نقل‌قول چاپ می‌کند.
  این گزینه برعکس آن است.
  هر خط از ورودی به‌صورت یک رشته در نظر گرفته می‌شود.

  دو مثال:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

وقتی این دو گزینه را با هم به کار می‌برید، _آرایه‌ای از رشته‌ها به دست نمی‌آورید_:
بلکه کل ورودی را به‌صورت یک رشته‌ی واحد به دست می‌آورید، همراه با نویسه‌های سطر جدید در پایان هر خط.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

پرداختن به این موضوع بخشی از چالش این تمرین است.
