# تابع `main` دارد

تابع `Main` را حذف کنید، چون test‌ها به آن نیازی ندارند و خواندن code را کمی سخت‌تر می‌کند.

معمولاً تابع `Main` برای کمک به debug کردن code اضافه می‌شود. با این حال، روش بهتر این است که هنگام اجرای یک یا چند unit test، code را debug کنید. این مزیت دیگری هم دارد: می‌توان روی debug کردن یک test case مشخص تمرکز کرد. در ادامه چند پیوند آورده شده که توضیح می‌دهند چگونه code Scala را هنگام اجرای unit test‌ها در محیط‌های توسعه‌ی مختلف debug کنید:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
