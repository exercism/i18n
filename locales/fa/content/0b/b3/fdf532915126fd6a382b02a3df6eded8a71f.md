# مقدمه

در Common Lisp، مانند بسیاری از زبان‌ها، اعداد چند نوع دارند. دو مورد از ابتدایی‌ترین آن‌ها عبارت‌اند از:

## اعداد صحیح

مانند بسیاری از زبان‌ها، Common Lisp اعداد صحیح دارد.
این‌ها اعداد کامل و بدون ممیز اعشاری‌اند (مانند `-6`، `0`، `25`، `1234` و غیره).

Common Lisp هیچ محدودیتی برای بزرگی اعداد صحیح تعریف نکرده است.
اعداد صحیح می‌توانند هر قدر بزرگ باشند (یا اگر منفی باشند، هر قدر کوچک).

در کل، اگر فقط با اعداد کامل کار می‌کنید، بهتر است اعداد صحیح را ترجیح دهید، چون برخلاف اعداد اعشاری، در محاسبات زیاد دچار همان از دست رفتن دقت نمی‌شوند.

## اعداد اعشاری

مانند بسیاری از زبان‌ها، Common Lisp اعداد اعشاری دارد.
این‌ها اعداد کسری یا کامل هستند که یک ممیز اعشاری دارند (مانند `3.14`، `-1.7`، `99.99`، `2048.0`).

## حساب

Common Lisp برای بیشتر عملیات از عملگرهای حسابی استاندارد استفاده می‌کند، اما تا حدی منحصربه‌فرد است، چون از «نماد پیشوندی» استفاده می‌کند، نه از «نماد میان‌وندی» آشناتر.

به‌طور واضح‌تر:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

هرچند نماد پیشوندی بعضی عملیات مانند `2 + 2` را به شکل تا حدی ناآشنای `(+ 2 2)` درمی‌آورد، کار کردن با بیش از یک عدد را بسیار آسان‌تر می‌کند.

### ریاضیات پایه

Common Lisp همه‌ی توابع معمول را دارد: `+`، `-`، `*`، `/` برای جمع، تفریق، ضرب و تقسیم.

وقتی به تقسیم می‌پردازید، ممکن است بخواهید باقی‌مانده‌ی تقسیم را بدانید؛ این کار با تابع `mod` (برای باقی‌مانده) انجام می‌شود که یک عدد و یک مقسوم‌علیه را به عنوان آرگومان می‌گیرد:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

### مقایسه‌ی اعداد

در نهایت، ممکن است مقایسه‌ی اعداد مختلف با توابعی مانند `=` (برابر)، `/=` (نابرابر) و `>=` (بزرگ‌تر یا مساوی) برایتان مفید باشد.
وقتی این مقایسه‌ها درست باشند (مانند `(= 1 1)`)، `T` را برمی‌گردانند و وقتی درست نباشند (مانند `(> 0 1)`)، `NIL` را برمی‌گردانند.
