# مقدمه

Swift یک نوع داده‌ای داخلی به نام [`Bool`][bools] ارائه می‌دهد که برای نمایش مقادیر درستی به کار می‌رود: `true` و `false`.

## عملگرهای منطقی

Swift سه [عملگر منطقی][logical-operators] (`!`، `&&` و `||`) ارائه می‌دهد که عبارت‌های منطقی را با هم ترکیب و ارزیابی می‌کنند.

### AND منطقی (`&&`)

[عملگر _and_][and] (`&&`) تنها زمانی `true` را برمی‌گرداند که هر دو عملوند `true` باشند.
اگر یکی از عملوندها `false` باشد، مقدار `false` را برمی‌گرداند.
یک عبارت یا مقدار منطقی را در هر طرف نماد `&&` قرار دهید:

```swift
true && true  // true
true && false // false
```

### OR منطقی (`||`)

[عملگر _or_][or] (`||`) اگر **حداقل یکی** از عملوندها `true` باشد، `true` را برمی‌گرداند.
تنها زمانی `false` را برمی‌گرداند که هر دو عملوند `false` باشند.
یک عبارت یا مقدار منطقی را در هر طرف نماد `||` قرار دهید:

```swift
true || true   // true
true || false  // true
false || false // false
```

### NOT منطقی (`!`)

[عملگر _not_][not] (`!`) یک مقدار منطقی را معکوس می‌کند.
اگر مقدار `false` باشد `true` را برمی‌گرداند و اگر مقدار `true` باشد `false` را برمی‌گرداند.
عملگر `!` را بلافاصله قبل از مقدار یا عبارت قرار دهید:

```swift
!true  // false
!false // true
```

## استفاده از پرانتز (`()`)

می‌توانید از [پرانتز][explicit-parentheses] برای گروه‌بندی عبارت‌ها و کنترل ترتیب ارزیابی استفاده کنید.
در Swift، عبارت‌های داخل پرانتز اول ارزیابی می‌شوند:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

گروه‌بندی با پرانتز همچنین تعیین می‌کند که عملگر NOT چگونه روی عبارت‌های پیچیده اعمال می‌شود:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

هر جا لازم است ترتیب ارزیابی را روشن کنید یا خواندن شرط‌های پیچیده را آسان‌تر کنید، از پرانتز استفاده کنید.
وقتی اولویت پیش‌فرض از پیش روشن است، از افزودن پرانتزهای بی‌مورد بپرهیزید.
