# پیوست دستورالعمل‌ها

## دستورالعمل‌های مخصوص این ترک

در گذشته، Elm از «برنامه‌نویسی واکنشی تابعی» استفاده می‌کرد، تا اینکه به استفاده از «معماری Elm» روی آورد.

این تمرین را طوری حل کنید که گویی در حال نوشتن یک برنامه‌ی وب با معماری Elm هستید.
خروجی برنامه باید HTML با ساختار زیر باشد

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

که در آن `<dl>` عنصر فهرست توصیفی، `<dt>` عنصر اصطلاح توصیفی و `<dd>` عنصر جزئیات توصیفی است؛ این‌ها همه عناصر استاندارد HTML هستند.

اگر خطایی رخ دهد، خروجی باید ساختار زیر را داشته باشد

```html
<div>
  <p>error message</p>
</div>
```
