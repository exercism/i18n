# درباره

عملگر `|>` را «عملگر پایپ» می‌نامند. می‌توان از آن برای زنجیره‌کردن فراخوانی‌های تابع استفاده کرد، به این شکل که مقدار برگردانده‌شده از فراخوانی تابع قبلی به فراخوانی تابع بعدی داده می‌شود.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

کد بالا معادل کد زیر است:

```gleam
string.append(string.uppercase("hello"), "?!")
```

عملگر پایپ مقدار را یا به‌عنوان آرگومان اول به فراخوانی تابع می‌دهد، یا به‌عنوان تنها آرگومان به یک فراخوانی جدید، بسته به این‌که در کدام حالت نوع درست باشد.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

گاهی می‌خواهیم مقدار را در جایگاه دیگری بدهیم. در این حالت می‌توان از «جای‌نگهدار» `_` استفاده کرد تا نشان دهیم مقدار باید کجا درج شود.

```gleam
100
|> some_function(1, _, 2)
```
