# مقدمه

## `Base.@kwdef`

ماکروی `Base.@kwdef` را می‌توان به کار برد تا به‌طور خودکار سازنده‌هایی تعریف کند که برای تعریف یک [`struct`][struct] آرگومان‌های کلیدواژه‌ای می‌گیرند. همچنین امکان تعیین مقدارهای پیش‌فرض برای فیلدها را فراهم می‌کند.

برای مثال، تعریف زیر

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

سه سازنده را به‌طور هم‌زمان تعریف می‌کند

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

از جمله سازنده‌ای که بر پایه‌ی آرگومان‌های کلیدواژه‌ای است

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

در حالی که تعریف استاندارد

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

تنها دو مورد زیر را تعریف می‌کند

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

و نیازمند تعریف دستی یک سازنده‌ی کلیدواژه‌ای خواهد بود.

### چه زمانی از `Base.@kwdef` استفاده کنیم؟

سازنده‌های کلیدواژه‌ای به‌ویژه برای ساختن `struct`هایی مفیدند که تعداد زیادی آرگومان می‌گیرند؛ به‌خصوص وقتی نوع یا مقدار آرگومان‌ها ارتباط مستقیمی با معنای آن‌ها ندارد.

تعریف زیر را در نظر بگیرید:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

بدون دانستن تعریف این نوع، روشن نیست که هر مقدار چه معنایی دارد. و حتی اگر تعریف را بدانید، احتمالاً باید ترتیب را بارها و بارها جست‌وجو کنید.

اما وقتی از یک سازنده‌ی کلیدواژه‌ای استفاده می‌کنید، معنای آن‌ها بی‌درنگ روشن است:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` نه صادر شده است و نه در راهنما مستند شده. بنابراین بخشی از [API عمومی Julia][public-api] نیست.
این یعنی از نظر فنی تضمینی برای پایدار بودن رابط آن وجود ندارد و ممکن است بین به‌روزرسانی‌های جزئی Julia تغییر کند.

با این حال، این ماکرو به‌طور گسترده در سراسر اکوسیستم استفاده می‌شود و بعید است به شکلی ناسازگار تغییر کند.
