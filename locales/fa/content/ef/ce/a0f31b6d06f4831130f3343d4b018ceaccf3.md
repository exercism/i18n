# «منطقی»

Crystal نوعی به اسم [`Bool`][bools] دارد.
این نوع مقادیر `true` و `false` را نشان می‌دهد.

## عملگرهای منطقی

Crystal سه عملگر منطقی دارد (`!`، `||`، `&&`) که مقادیر منطقی را با هم ترکیب می‌کنند و عبارت‌هایی می‌سازند که مقادیر متفاوتی تولید می‌کنند.

### و (`&&`)

عملگر «و» در Crystal با `&&` نشان داده می‌شود و اگر هر دو مقدار `true` باشند، `true` برمی‌گرداند؛ در غیر این صورت `false` برمی‌گرداند.
هنگام استفاده از عملگر و، یک مقدار منطقی در سمت راست `&&` و دیگری در سمت چپ قرار می‌گیرد.

```crystal
true && true
# => true

true && false
# => false
```

### یا (`||`)

عملگر «یا» در Crystal با `||` نشان داده می‌شود و اگر **حداقل یکی** از مقادیر داده‌شده `true` باشد، `true` برمی‌گرداند.
اگر هر دو مقدار `false` باشند، `false` برمی‌گرداند.
هنگام استفاده از عملگر یا، یک مقدار منطقی باید در سمت راست `||` و دیگری در سمت چپ قرار گیرد.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### نقیض (`!`)

عملگر «نقیض» در Crystal با `!` نشان داده می‌شود و اگر مقدار منطقی داده‌شده `false` باشد، `true` برمی‌گرداند و اگر `true` داده شود، `false` برمی‌گرداند.
هنگام استفاده از عملگر نقیض، یک مقدار منطقی باید بعد از عملگر (`!`) قرار گیرد.

```crystal
!true
# => false

!false
# => true
```

## استفاده از پرانتز (`()`)

هنگام کار با مقادیر منطقی، می‌توانید از پرانتز استفاده کنید تا تعیین کنید کدام مقادیر منطقی ابتدا ارزیابی شوند.
نتیجه بسته به نحوه‌ی استفاده از پرانتز می‌تواند متفاوت باشد.
در Crystal، آنچه داخل پرانتز است ابتدا ارزیابی می‌شود.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

از آنجا که آنچه داخل پرانتز است ابتدا ارزیابی می‌شود، عملگر نقیض در مثال زیر روی عبارت داخل پرانتز اعمال می‌شود.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
فقط زمانی باید از پرانتز استفاده کنید که بر نتیجه تأثیر بگذارد؛ در غیر این صورت، باید حذف شوند.
~~~~

## درست‌نما و غلط‌نما

در Crystal، مقادیر «غلط‌نما» عبارت‌اند از: `false`، `nil` و اشاره‌گرهای null؛ **هر مقدار دیگری** «درست‌نما» است.
این مقادیر را می‌توان با عملگرهای منطقی نام‌برده‌شده در بالا استفاده کرد.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## قواعد اسم‌گذاری متدها با مقادیر منطقی

در Crystal، رایج است که متدی را که مقدار درست‌نما یا غلط‌نما برمی‌گرداند، با علامت سؤال (`?`) اسم‌گذاری کنند.
در بیشتر موارد، این متد یک مقدار منطقی برمی‌گرداند، اما نه لزوماً.
این یعنی می‌توان از متد در جاهایی استفاده کرد که مقدار درست‌نما یا غلط‌نما انتظار می‌رود، برای مثال به عنوان شرط یک دستور `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

متدهایی که در انتهای اسمشان علامت سؤال دارند و مقدار منطقی برنمی‌گردانند، اغلب به جای آن `nil` برمی‌گردانند. `nil` _مشابه `None` یا `null` در زبان‌های دیگر است_.
