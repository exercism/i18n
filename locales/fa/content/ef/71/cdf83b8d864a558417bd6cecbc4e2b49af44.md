# Debug

از آنجا که «test-runner» کنونی از [PonyTest](https://stdlib.ponylang.io/pony_test--index/) استفاده می‌کند، اکتور Main در test.pony قرار دارد و نباید آن را به‌عنوان بخشی از راه‌حل خود ویرایش کنید.

همان‌طور که در برنامه‌های Pony بهترین شیوه است، ما تا زمانی که نیازی نباشد دسترسی به `Env` را در اختیار نمی‌گذاریم. این یعنی در تقریباً همه‌ی موارد نمی‌توانید برای debug به سبک printf از `env.out.print()` استفاده کنید.

اما Pony ماژولی به نام [debug](https://stdlib.ponylang.io/debug--index/) دارد که به برنامه‌هایی که با پرچم `-d` کامپایل شده‌اند امکان می‌دهد بدون دسترسی به `Env` به STDOUT و STDERR دسترسی ویژه داشته باشند.

اگر به debug به سبک printf نیاز دارید، باید از همین قابلیت استفاده کنید.

مثال Debug:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```


همین کد، یک بار با پرچم `-d` و یک بار بدون آن کامپایل شده است:
