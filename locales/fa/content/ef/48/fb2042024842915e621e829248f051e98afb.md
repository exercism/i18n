## جفت

`Pair` یک ساختار داده است که دقیقاً دو عنصر را در خود جای می‌دهد و این دو عنصر از طریق فیلدهای `first` و `second` قابل دسترسی‌اند.

می‌توان آن‌ها را با `x => y` ساخت:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

عناصر یک `Pair` می‌توانند از نوع متفاوتی باشند:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

`Pair`ها در Julia دو کاربرد رایج دارند: دیکشنری و جایگزینی.

### جایگزینی

بسیاری از متدهای جایگزینی یک `Pair` را به عنوان آرگومان می‌گیرند تا روشن شود کدام عنصر جایگزین می‌شود.
این امکان را می‌دهد که چیزی شبیه به این بنویسیم

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

که در آن هر `4` در مجموعه با `0` جایگزین می‌شود، به‌جای نگارش کم‌واضح‌ترِ

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
