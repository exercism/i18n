# راهنمایی‌ها

## کلی

- برای کار با [کدپوینت‌های][codepoint] نویسه از `?` استفاده کنید.
- از `\s` می‌توان برای نمایش یک فاصله استفاده کرد.
- برای کار با کدها از نشانه‌گذاری کوتاه [عدد صحیح دودویی][integer-literal] استفاده کنید.
- سعی کنید از راهبرد بازگشت دنباله‌دار استفاده کنید.

## 1. کدگذاری اسید نوکلئیک به مقدار دودویی

- این تابع باید یک عدد صحیح را به عدد صحیح دیگری نگاشت کند.
- این تابع نیازی به بازگشت ندارد.
- استفاده از توابع چندبندی ممکن است با تقسیم آن به بخش‌های کوچک‌تر، این کار را آسان‌تر کند.

## 2. کدگشایی مقدار دودویی به اسید نوکلئیک

- این تابع معکوس تابع بخش ۱ است.
- این تابع نیازی به بازگشت ندارد.
- استفاده از توابع چندبندی ممکن است با تقسیم آن به بخش‌های کوچک‌تر، این کار را آسان‌تر کند.

## 3. کدگذاری یک فهرست نویسه‌ی DNA

- یک تابع بازگشتی دنباله‌دار بسازید که یک کدپوینت را از فهرست نویسه می‌گیرد و نتیجه‌ی رشته‌ی بیت را به‌صورت بازگشتی می‌سازد.
- توابع بازگشتی دنباله‌دار به یک انباشتگر نیاز دارند.
- به یاد داشته باشید که یک [فهرست نویسه][charlist] فهرستی از [کدپوینت‌های عدد صحیح][codepoint] است.
- می‌توانید اولین عنصر و باقی عناصر را از یک فهرست با استفاده از یک تابع داخلی از [ماژول `Kernel`][kernel] بگیرید.
- همچنین می‌توانید با استفاده از نشانه‌گذاری [`[head | tail]`][list] روی یک فهرست تطبیق الگو انجام دهید.
- از توابع چندبندی برای جدا کردن حالت پایه از حالت‌های بازگشتی استفاده کنید.
- فراموش نکنید که نوع بخش‌های رشته‌ی بیت را با استفاده از عملگر `::` مشخص کنید.

## 4. کدگشایی یک رشته‌ی بیت DNA

- یک تابع بازگشتی دنباله‌دار بسازید که [۴ بیت اول را از][bitstring-matching] [رشته‌ی بیت][bitstring] تطبیق می‌دهد و نتیجه‌ی [فهرست نویسه][charlist] را به‌صورت بازگشتی می‌سازد.
- توابع بازگشتی دنباله‌دار به یک انباشتگر نیاز دارند.
- به یاد داشته باشید که از [شکل ویژه‌ی رشته‌ی بیت][bitstring-form] می‌توان برای تطبیق روی رشته‌های بیت استفاده کرد.
- فراموش نکنید که نوع بخش‌های رشته‌ی بیت را با استفاده از عملگر `::` مشخص کنید.
- در انتها باید انباشتگر را برعکس کنید. یک تابع بازگشتی دنباله‌دار خصوصی به اسم `reverse` بنویسید که این کار را انجام دهد و از آن در حالت پایه‌ی تابع `decode` استفاده کنید.
