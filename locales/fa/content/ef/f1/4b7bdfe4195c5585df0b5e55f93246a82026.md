# درباره

در Common Lisp همه‌چیز یک عبارت است.
هر عبارت یا یک جزء تک است (که به آن «اتم» می‌گویند) یا لیستی از اجزا (که با پرانتز مشخص می‌شود: `()`).

## نقل قول

همه‌ی S-Expressionها، مانند نمادها، قابل نقل قول هستند:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

این نقل قول جلوی ارزیابی یک S-expression را می‌گیرد و به‌جای آن با آن مانند داده رفتار می‌کند.
این [پاسخ عالی Stack Overflow][so-quoting] نقل قول را کمی با جزئیات بیشتری بررسی می‌کند.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
