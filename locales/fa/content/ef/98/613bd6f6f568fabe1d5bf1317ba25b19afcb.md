# مقدمه

## مقایسه

در C++ می‌توانید مقادیر را با استفاده از عملگرهای مقایسه، مقایسه کنید.

| مقایسه        | عملگر  |
| ------------------| --------- |
| برابر             | `==`      |
| نابرابر         | `!=`      |
| کوچک‌تر              | `<`       |
| کوچک‌تر یا برابر     | `<=`      |
| بزرگ‌تر           | `>`       |
| بزرگ‌تر یا برابر  | `>=`      |

نتیجه‌ی این مقایسه‌ها همیشه یک مقدار «منطقی» است:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

عملگرهای `==` و `!=` به ترتیب بررسی می‌کنند که آیا یک مقدار با مقدار دیگری برابر است یا نه. در ادامه چند مثال رایج را می‌بینید:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

بقیه‌ی عملگرها بررسی می‌کنند که یک مقدار از مقدار دیگری بزرگ‌تر است (`>`)، بزرگ‌تر یا برابر با آن است (`>=`)، کوچک‌تر است (`<`) یا کوچک‌تر یا برابر با آن است (`<=`).
این نوع مقایسه برای اعداد و رشته‌ها در دسترس است.
هنگام مقایسه‌ی رشته‌ها، ترتیب فرهنگ لغت (که به آن ترتیب واژه‌نگاری هم می‌گویند) رعایت می‌شود.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## دستورهای شرطی

دستورهای شرطی در C++ مشابه دستورهای شرطی در زبان‌های دیگر هستند.
نوع زیربنایی هر عملیات شرطی، نوع `bool` است که می‌تواند مقدار `true` یا `false` را داشته باشد.
از دستورهای شرطی اغلب به عنوان سازوکارهای کنترل جریان برای بررسی شرط‌های مختلف استفاده می‌شود.

می‌توان از یک دستور `if` استفاده کرد که اگر شرط زیربنایی `true` باشد، کدش را به این شکل اجرا می‌کند:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

در سناریوهایی که بیش از یک حالت وجود دارد، می‌توان چندین دستور `if` را با استفاده از دستورهای `else if` و `else` به هم زنجیر کرد.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

از C++17 به بعد، دستورهای شرطی می‌توانند یک دستور مقداردهی اولیه‌ی کوتاه هم داشته باشند که می‌توان از آن برای مقداردهی اولیه‌ی یک یا چند متغیر برای دستور شرطی استفاده کرد.
برای مثال:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> نکته: به هیچ‌کدام از متغیرهایی که در مقداردهی اولیه ساخته می‌شوند، پس از پایان دستور شرطی نمی‌توان دسترسی داشت.
