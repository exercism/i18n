# درباره

به‌طور پیش‌فرض، متغیرها به حوزه‌ای که در آن تعریف می‌شوند محدودند. اگر خارج از یک تابع یا کلاس و در یک فایل تعریف شوند، به حوزه‌ی همان فایل محدود می‌شوند. اگر در یک تابع یا کلاس تعریف شوند، به حوزه‌ی همان تابع یا کلاس محدود می‌شوند.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## حوزه‌ی سراسری

استفاده از کلیدواژه‌ی `global` پیش از تخصیص یک متغیر، متغیری با حوزه‌ی سراسری می‌سازد. این الگو اغلب توصیه نمی‌شود، چون [کد به‌شدت جفت‌شده](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>) ایجاد می‌کند.

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## حوزه‌ی ایستا

استفاده از کلیدواژه‌ی `static` پیش از تخصیص یا اعلان یک متغیر، حوزه‌ی آن متغیر را حفظ می‌کند، اما مقدارش میان حوزه‌های اجرا باقی می‌ماند.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

در این مثال، متغیر `$count` _فقط در اولین فراخوانی تابع_ با مقدار ۰ مقداردهی اولیه می‌شود. در هر فراخوانی بعدی، مقدار آن به فراخوانی بعد منتقل می‌شود. بنابراین هر بار که تابع فراخوانی می‌شود، یک عدد صحیح بزرگ‌تر برمی‌گرداند.
