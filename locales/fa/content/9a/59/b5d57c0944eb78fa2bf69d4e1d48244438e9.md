# دستورالعمل‌ها

شما پرنده‌شناسی پرشور هستید که پیگیری می‌کنید در هفت روز گذشته چند پرنده به باغتان آمده است.

شش کار در پیش دارید که همه‌شان به شمار پرنده‌هایی مربوط می‌شوند که به باغتان آمده‌اند.

## 1. بررسی کنید شمارش‌های هفته‌ی گذشته چه بوده‌اند

برای مقایسه، همیشه نسخه‌ای از شمارش‌های هفته‌ی گذشته را کنار خود نگه می‌دارید که عبارت بودند از: 0، 2، 5، 3، 7، 8 و 4. پیوند `lastWeek` را تعریف کنید که شمارش‌های هفته‌ی گذشته را در خود دارد:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. بررسی کنید دیروز چند پرنده آمده است

تابع `yesterday` را پیاده‌سازی کنید تا برگرداند که دیروز چند پرنده به باغتان آمده‌اند. شمارش پرنده‌ها بر اساس روز مرتب شده است؛ اولین عنصر مربوط به شمارش قدیمی‌ترین روز است و آخرین عنصر شمارش امروز.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. محاسبه‌ی شمار کل پرنده‌هایی که به باغ آمده‌اند

تابع `total` را پیاده‌سازی کنید تا شمار کل پرنده‌هایی را برگرداند که به باغتان آمده‌اند:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. بررسی کنید آیا روزی بدون پرنده بوده است

تابع `dayWithoutBirds` را پیاده‌سازی کنید که اگر روزی وجود داشته باشد که هیچ پرنده‌ای در آن به باغ نیامده است، `true` را برمی‌گرداند؛ در غیر این صورت `false` را برمی‌گرداند:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. افزایش شمارش امروز

تابع `incrementTodaysCount` را پیاده‌سازی کنید تا شمارش امروز را یک واحد افزایش دهد و شمارش‌های به‌روزشده را برگرداند:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. بررسی یک هفته‌ی غیرعادی

در طول یک سال گذشته دریافته‌اید که برخی هفته‌ها الگوهای غیرعادی یکسانی دارند:
- در هر روز زوج هفته، هیچ پرنده‌ای نبود
- در هر روز زوج هفته، دقیقاً ۱۰ پرنده دیده می‌شد
- در هر روز فرد هفته، دقیقاً ۵ پرنده دیده می‌شد

تابع `unusualWeek` را پیاده‌سازی کنید که اگر الگوی شمارش پرنده‌های این هفته با یکی از الگوهای غیرعادی مطابقت داشته باشد، `true` را برمی‌گرداند:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(توجه کنید که زوج یا فرد بودن روزها بر پایه‌ی شماره‌گذاری از ۱ است، نه از ۰؛ اولین عنصر آرایه مربوط به یک روز فرد است)
