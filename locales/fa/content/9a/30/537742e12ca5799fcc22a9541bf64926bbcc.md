# پیوست دستورالعمل‌ها

## حافظه‌ی رزروشده

بافر مربوط به رشته‌ی ورودی از بایت‌های 64 تا 191 حافظه‌ی خطی استفاده می‌کند.


## قالب خروجی

انتظار می‌رود مجموعه‌ی اعداد به‌صورت یک آرایه‌ی پیوسته از اعداد `u8` ارائه شود؛ این آرایه هنگام تبدیل داده‌های سریال‌شده به ساختار اصلی، بر اساس طول تقسیم می‌شود:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
