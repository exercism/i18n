# دستورالعمل‌ها

یک مدرسه‌ی محلی نزدیک شما انجمن دانش‌آموزی بسیار فعالی دارد.
انجمن دانش‌آموزی توسط یک رئیس اداره می‌شود و هر ۲ سال یک‌بار، برای انتخاب رئیس جدید انتخابات برگزار می‌شود.

در انتخابات امسال تصمیم گرفته شد که به یک سامانه‌ی دیجیتال جدید برای شمارش آرا نیاز است. مدرسه برای ساختن این سامانه‌ی جدید به کمک شما نیاز دارد.

## 1. دریافت تعداد آرا از یک `ElectionResult`

سامانه‌ی جدید به راهی نیاز خواهد داشت که تعداد آرا را از یک شمارنده به دست آورد.

`struct` نتیجه‌ی انتخابات از قبل برای شما ساخته شده است و به این شکل تعریف می‌شود:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

چون همه‌ی اعضای `struct` عمومی هستند، نیازی نیست برای مقداردهی اولیه به یک شیء `ElectionResult` یک `constructor` بنویسید.
به‌جای آن می‌توانید از `initializer list` استفاده کنید:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

تابعی به نام `vote_count` بسازید که یک ارجاع به `ElectionResult` را به عنوان آرگومان می‌گیرد و تعداد آرا در `ElectionResult` را برمی‌گرداند.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. افزایش آرای یک `ElectionResult`

بالاخره وقت پردازش آرا رسیده است!
حالا به راهی نیاز دارید که آرا در یک `ElectionResult` را افزایش دهد.

تابعی `void` به نام `increment_vote_count` بسازید که یک ارجاع به `ElectionResult` و یک تعداد آرا را به عنوان آرگومان می‌گیرد و `ElectionResult` را به اندازه‌ی آن تعداد آرا افزایش می‌دهد.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. شمارش آرا و ریاست

مدرسه آرا را تحویل داد و حالا وقت بررسی نتایج برای یافتن برنده است.

تابعی به نام `determine_result` بسازید که یک ارجاع به شمارش نهایی می‌گیرد و یک ارجاع به `ElectionResult` رئیس جدید را برمی‌گرداند.
همچنین باید اسم برنده را با افزودن پیشوند «President» به آن تغییر دهد.
شمارش نهایی در قالب یک `reference` به `std::vector<ElectionResult>` داده می‌شود؛ برداری که `ElectionResults` همه‌ی نامزدهای شرکت‌کننده را در خود دارد.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

برای ساده نگه داشتن کار، می‌توانید موارد زیر را فرض کنید:
- `vector` حداقل یک عنصر دارد.
- هیچ تساوی‌ای برای مقام اول وجود نخواهد داشت.
