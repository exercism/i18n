# درباره

یک پارامتر متد را می‌توان با دادن یک مقدار پیش‌فرض به آن اختیاری کرد. وقتی یک پارامتر اختیاری باشد، فراخوان لازم نیست برای آن پارامتر آرگومانی بدهد؛ در این صورت از مقدار پیش‌فرض استفاده می‌شود. [پارامترهای اختیاری][optional-arguments] _باید_ در انتهای فهرست پارامترها باشند؛ پارامترهای غیراختیاری نمی‌توانند بعد از آن‌ها بیایند. اگر یک متد چند پارامتر اختیاری داشته باشد، می‌توانید فقط برخی از آن‌ها را با استفاده از [آرگومان‌های نامدار][named-arguments] مشخص کنید.

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

مقدار یک پارامتر اختیاری باید یکی از این موارد باشد:

- یک عبارت ثابت (مثلاً `"hi"`، `2`، `DayOfWeek.Friday`، `null` و غیره)
- یک عبارت `new` از یک نوع مقدار
- یک عبارت `default` از یک نوع مقدار

[named-arguments]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#named-arguments
