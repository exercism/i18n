# درباره

## حلقه‌ی For

دستور `for` یک بلوک کد را تکرار می‌کند.
خط اول آن کنترل می‌کند که این بلوک چند بار تکرار شود:

```go
for init; condition; post {
    // loop body
}
```

- دستور **`init`** یک بار پیش از نخستین تکرار اجرا می‌شود. معمولاً در آن یک متغیر شمارنده اعلام و مقداردهی می‌شود که حلقه از آن استفاده می‌کند.
- **`condition`** یک عبارت منطقی است که پیش از هر تکرار ارزیابی می‌شود. حلقه زمانی متوقف می‌شود که این عبارت به `false` ارزیابی شود.
- دستور **`post`** پس از هر تکرار کامل‌شده اجرا می‌شود. می‌توان از آن برای به‌روزرسانی شمارنده استفاده کرد.

دور `init; condition; post` پرانتز نگذارید.
اما آکولادهای `{ }` که بدنه‌ی حلقه را در بر می‌گیرند همیشه الزامی‌اند.

این حلقه `i` را از `1` شروع می‌کند، مقدار جاری `i` را چاپ می‌کند، آن را برای تکرار بعدی افزایش می‌دهد و زمانی که `i` به `10` برسد متوقف می‌شود:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## شکل‌های دیگر حلقه

### حلقه‌ای فقط با شرط

می‌توان دستورهای `init` و `post` را حذف کرد.
دستور `for` که فقط یک شرط دارد، همان کاری را می‌کند که حلقه‌ی while در زبان‌های دیگر انجام می‌دهد.
Go کلیدواژه‌ی `while` ندارد.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### حلقه‌ی بی‌نهایت

می‌توان دستور `for` را بدون شرط نوشت:

```go
for {
    // loop body
}
```

این حلقه به‌تنهایی پایان نمی‌یابد.
اجرا باید به‌طور صریح از حلقه خارج شود، مثلاً با `break` یا `return`.

## کنترل حلقه‌ها

### `break` و `continue`

در این حلقه، `break` از حلقه خارج می‌شود:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` بقیه‌ی بدنه‌ی حلقه‌ی جاری را نادیده می‌گیرد و تکرار بعدی را آغاز می‌کند:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### `break` و `continue` برچسب‌دار

در حلقه‌های تودرتو، `break` یا `continue` بدون برچسب به درونی‌ترین حلقه اعمال می‌شود.
برای برچسب‌زدن به یک حلقه‌ی دربرگیرنده، یک شناسه و بعد از آن یک دونقطه را در خطی دقیقاً بالای آن قرار دهید.
سپس نام برچسب حلقه را بعد از `break` یا `continue` بنویسید تا عمل به آن حلقه هدایت شود:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
