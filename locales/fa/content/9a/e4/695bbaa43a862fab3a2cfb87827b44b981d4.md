# مقدمه

نوع `Option` سازوکار زبان F# برای برخورد با مقادیری است که ممکن است وجود داشته باشند یا نداشته باشند. این نوع جایگزینی ایمن از نظر نوع برای استفاده از `null` فراهم می‌کند که در زبان‌های دیگر برای برخورد با چنین مقادیری رایج است. از این نوع در بسیاری از توابع کتابخانه‌ی استاندارد F# استفاده می‌شود، بنابراین درک آن برای استفاده‌ی مؤثر از کتابخانه‌ی استاندارد F# ضروری است.

## کاربرد

نوع `Option` یک نوع جنریک است (که یک نوع پایه دارد).  
مقدارهای `Option` یا `Some value` هستند، یعنی نماینده‌ی یک مقدار مشخص، یا `None` هستند، یعنی نماینده‌ی نبودِ مقدار.

تابع زیر نشان می‌دهد که چگونه یک مقدار `Option` بسازیم:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` شکل نگارش پسوندیِ معادلِ `Option<T>` است؛ می‌توان این دو شکل نگارش را به‌جای یکدیگر به کار برد.
با این حال، بر اساس راهنمای سبک F#، برای نوع‌های Option نگارش پسوندی ترجیح داده می‌شود (به بخش [قالب‌بندی نوع‌ها و حاشیه‌نویسی‌های نوع در راهنمای سبک F#](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions) مراجعه کنید). 
~~~~

## خواندن محتوای یک مقدار Option

روش اصطلاحی خواندن یک مقدار `Option` از طریق «تطبیق الگو» است، همان‌طور که در مثال زیر نشان داده شده است:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## باز کردن Option با مقدارهای پیش‌فرض

با دادن مقدارهای پیش‌فرض به کمک تابع `Option.defaultValue` می‌توان `Option` را «باز کرد» (یعنی آن را به نوعی که در خود دارد تبدیل کرد). این کار به‌ویژه زمانی مفید است که بخواهید مطمئن شوید مقدار `None` نیست.
برای مثال:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
