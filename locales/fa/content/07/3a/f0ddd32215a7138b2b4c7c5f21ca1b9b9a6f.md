# درباره

به‌طور کلی دو نوع حلقه وجود دارد:

1. حلقه زدن تا زمانی که یک شرط برآورده شود.
2. حلقه زدن روی عناصر یک مجموعه.

هر دو [در R ممکن هستند][web-loops]، هرچند ممکن است اولی رایج‌تر باشد.

## `while` و `repeat`

R برای مسائل بدون پایان مشخص که تعداد دفعات گردش در حلقه از قبل معلوم نیست، حلقه‌ی [`while`][ref-control] را با یک شرط و حلقه‌ی [`repeat`][ref-control] را بدون شرط (معادل `while (TRUE)`) دارد.

شکل پایه کاملاً ساده است:

```R
while (condition) {
  do_something()
}
```

در این حالت، برنامه به گردش در حلقه ادامه می‌دهد تا زمانی که `condition` دیگر `TRUE` نباشد.

دو راه برای خروج زودهنگام از حلقه وجود دارد:

- یک `break` باعث خروج از حلقه می‌شود و اجرا از خط بعدی پس از آکولاد بسته‌ی حلقه `}` ادامه می‌یابد.
- یک `return(x)` اجرای تابع جاری را متوقف می‌کند و مقدار بازگشتی `x` را به فراخوان‌کننده بازمی‌گرداند.

با وجود این گزینه‌ها، گاهی اوقات راحت است که یک حلقه‌ی «بی‌پایان» با `repeat { ... }` ایجاد کنید. سپس با یافتن یک شرط توقف در بدنه‌ی حلقه، یک `break` یا `return` را فعال کنید.

این سه گونه معادل هستند و همه با `x == 0.4444...` پایان می‌یابند.

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## پیمایش یک بردار (یا مجموعه‌ی دیگر)

این کار اغلب در R غیرضروری است.
همان‌طور که در مفاهیم دیگر بحث شد، بسیاری از توابع روی کل بردارها عمل می‌کنند.

با این حال، حلقه‌های صریح گاهی اجتناب‌ناپذیر هستند.
این موضوع به‌ویژه زمانی درست است که:

- بدنه‌ی حلقه دارای عوارض جانبی مانند چاپ کردن یا ورودی/خروجی فایل است.
- حلقه زدن تا رسیدن به یک معیار خاص، پس از تعداد نامشخصی از تکرارها، ادامه می‌یابد.

شرط حلقه باید در پرانتز باشد.
مانند بدنه‌ی توابع، برای بدنه‌های حلقه‌ی یک‌خطی، آکولادها اختیاری هستند (اما اغلب شامل می‌شوند).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

اگر تکرار جاری شرطی را برآورده نکند، می‌توان با یک `next` بلافاصله به تکرار بعدی پرش کرد:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

اگر به اندیس عددی نیاز است، از [`seq_along()`][ref-seq_along] استفاده کنید.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

استفاده از `i in 1:length(v)` توصیه _نمی‌شود_، زیرا می‌تواند وقتی `length(v)` صفر است مشکل ایجاد کند.
محدوده‌ی `1:0` معادل `c(1, 0)` است، بنابراین بدنه‌ی حلقه اجرا می‌شود و احتمالاً شکست می‌خورد.
تابع `seq_along()` طوری طراحی شده است که این مورد را به‌درستی مدیریت کند.
