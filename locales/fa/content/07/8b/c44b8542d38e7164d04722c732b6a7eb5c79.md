# test کردن تمرین

برای اینکه برای یک تمرین راه‌حل بنویسید و آن را به‌صورت محلی test کنید، مراحل زیر را دنبال کنید.

## دانلود تمرین

یک Command Prompt باز کنید و دستور زیر را با اسم تمرین موردنظرتان اجرا کنید تا آن را دانلود کنید.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## توسعه‌ی راه‌حل

1. دستور زیر را اجرا کنید تا به پوشه‌ی تمرینی که تازه دانلود کرده‌اید بروید.

     >**نکته:** محل پوشه در دستور زیر به سیستم‌عامل شما و فضای کاری Exercism که تنظیم کرده‌اید بستگی دارد. می‌توانید با اجرای دستور `exercism configure` محل فضای کاری خود را پیدا کنید.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. دستورالعمل‌های ارائه‌شده را دنبال کنید و برای تمرین راه‌حل بنویسید.

## راه‌حل خود را test کنید

بعضی از تمرین‌های Ballerina یک test دارند و بعضی دیگر چندین test. این testها را می‌توانید در فایل test مربوطه در پوشه‌ی `/tests` داخل پوشه‌ی ریشه‌ی تمرین پیدا کنید.

### test کردن تمرینی با یک test

دستور زیر را اجرا کنید تا test تمرین اجرا شود.

به‌طور پیش‌فرض فقط اولین test فعال است. این کار عمدی است، چون به شما اجازه می‌دهد فقط روی پاس کردن همان یک test تمرکز کنید.

```sh
bal test
```

### test کردن تمرینی با چند test

برای test کردن تمرینی که چند test دارد، مراحل زیر را دنبال کنید.

1. وقتی اولین test پاس شد، با حذف ویژگی `enable: false` از حاشیه‌نویسی `@test:Config`، test بعدی را فعال کنید.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2. دستور زیر را اجرا کنید تا test فعال‌شده اجرا شود.

   ```sh
     bal test
   ```

3. دو مرحله‌ی بالا را تکرار کنید تا بقیه‌ی testها را فعال کنید.

با فعال کردن همه‌ی testها و مطمئن شدن از اینکه پیاده‌سازی‌تان همه‌ی آن‌ها را پاس می‌کند، تمرین را با موفقیت به پایان رسانده‌اید.
