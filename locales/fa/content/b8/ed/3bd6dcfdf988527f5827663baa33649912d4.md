# درباره

گاهی اوقات نیازی به سربارِ ساختن یک «شیء» دارای «وضعیت» ندارید.
در این موارد، می‌توان از یک `module` استفاده کرد.

یک «ماژول» بسیار شبیه یک «کلاس» است (در واقع، `Module` والد `Classes` در سلسله‌مراتب شیء است). تفاوت اصلی این است که به جای استفاده از متدهای نمونه‌ای، از متدهای کلاسی استفاده می‌کنیم.
متدهای کلاسی با `self.` شروع می‌شوند و مستقیماً روی یک ماژول فراخوانی می‌شوند.

برای مثال:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
