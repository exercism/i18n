# مقدمه‌ای بر آرایه

در Java، آرایه‌ها راهی برای ذخیره‌ی چند مقدار از یک نوع در یک ساختار واحد هستند.
برخلاف سایر ساختارهای داده، آرایه‌ها پس از ایجاد، اندازه‌ی ثابتی دارند.
می‌توان با استفاده از اندیس، مقداری را در آرایه قرار داد یا آن را از آن بازیابی کرد.
آرایه‌های Java از اندیس‌گذاری صفرمبنا استفاده می‌کنند: اندیس اولین عنصر ۰ است، اندیس دومین عنصر ۱ است و به همین ترتیب.

نحوه‌ی نگارش استاندارد برای مقداردهی اولیه به یک آرایه چنین است:

```java
type[] variableName = new type[size];
```

`type` نوع عناصر آرایه است که می‌تواند یک نوع اولیه (مثلاً `int`) یا یک کلاس (مثلاً `String`) باشد.

`size` تعداد عناصری است که این آرایه در خود نگه می‌دارد (و بعداً قابل تغییر نیست).
پس از ایجاد آرایه، عناصر آن به مقادیر پیش‌فرض خود مقداردهی اولیه می‌شوند (معمولاً `0`، `false` یا `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

همچنین می‌توان آرایه‌ها را با یک نگارش میان‌بر تعریف کرد که به شما امکان می‌دهد هم آرایه را ایجاد کنید و هم مقدار آن را تعیین کنید:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

از آنجا که کامپایلر حالا می‌تواند تشخیص دهد آرایه چند عنصر خواهد داشت، می‌توان طول را حذف کرد.

می‌توان با استفاده از نگارش اندیس درون براکت، به عناصر آرایه مقدار داد و به آن‌ها دسترسی داشت:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

دسترسی به اندیسی که خارج از اندیس‌های معتبر آرایه باشد، منجر به یک `IndexOutOfBoundsException` می‌شود.

می‌توان آرایه‌ها را با فراخوانی متدها یا ویژگی‌های یک نمونه‌ی آرایه، یا با استفاده از متدهای ایستای تعریف‌شده در کلاس `Arrays` دست‌کاری کرد (که معمولاً فقط در کدهای جنریک استفاده می‌شوند).
ویژگی `length` طول یک آرایه را نگه می‌دارد.
می‌توان به این صورت به آن دسترسی داشت:

```java
int arrayLength = someArray.length;
```

Java همچنین یک کلاس ابزاری مفید به نام [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) ارائه می‌دهد که متدهای مفید زیادی مرتبط با آرایه دارد (مثلاً `Arrays.equals`).

Java همچنین از [آرایه‌های چندبعدی](https://www.programiz.com/java-programming/multidimensional-array) مانند `int[][] arr = new int[3][4];` پشتیبانی می‌کند که می‌توانند بسیار مفید باشند.

این واقعیت که آرایه یک _مجموعه_ هم هست یعنی علاوه بر دسترسی به مقادیر با اندیس، می‌توانید با یک حلقه‌ی `for-each` روی _همه‌ی_ مقادیر آن پیمایش کنید:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

اگر می‌خواهید کنترل بیشتری بر این داشته باشید که روی کدام مقادیر پیمایش کنید، می‌توان از یک حلقه‌ی `for` استفاده کرد:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
