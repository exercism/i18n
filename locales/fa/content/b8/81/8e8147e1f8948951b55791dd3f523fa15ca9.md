# مقدمه

## مقادیر منطقی در Julia

مقدارهای درست یا غلط با نوع `Bool` نمایش داده می‌شوند.
این نوع فقط دو مقدار دارد: `true` و `false`.

```julia-repl
julia> true
true

julia> false
false
```

## عملگرهای منطقی

در Julia سه عملگر منطقی وجود دارد.

`&&` همان عملگر منطقی «و» است.
اگر عبارت‌های *هر دو* طرف `&&` برابر `true` باشند، نتیجه `true` می‌شود.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` همان عملگر منطقی «یا» است.
اگر عبارت *هر یک از* دو طرف `||` برابر `true` باشد، نتیجه `true` می‌شود.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` همان عملگر منطقی «نه» است.
مقدارهای `true` و `false` را جابه‌جا می‌کند.

```julia-repl
julia> !true
false

julia> !false
true
```

برای عبارت‌های طولانی‌تر و پیچیده‌تر، بهتر است از پرانتز استفاده کنید تا منظورتان روشن‌تر باشد.

```julia-repl
julia> (true || false) && (false && true)
false
```
