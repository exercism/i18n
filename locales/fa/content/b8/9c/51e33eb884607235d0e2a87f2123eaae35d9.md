# راهنمایی‌ها

- برای این تمرین به تابع `format` نیاز خواهید داشت.

## 1. قالب‌بندی مقادیر فصلی

- تابع `format` همیشه `nil` برمی‌گرداند، مگر این که پارامتر جریان `nil` باشد.
- از `~A` می‌توان برای قالب‌بندی یک مقدار استفاده کرد.

## 2. گزارش دوفصلی

- تابع قبلی شما برای ساختن دو خط موردنیاز عالی است.
- از `~%` و `~&` می‌توان برای ساختن خط جدید استفاده کرد.

## 3. خوانایی برای انسان در مقابل موجود فضایی Lisp

- تابع قالب‌بندی فصلی قبلی شما برای ساختن رشته‌های موردنیاز عالی است.
- از `~S` می‌توان برای قالب‌بندی مقادیر به شکلی خوانا استفاده کرد.
