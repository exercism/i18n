# کلاس‌های دارای وضعیت

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## `attr`، `readonly attr`، `private attr`

| نحوه‌ی نوشتن | خواندن از بیرون | تغییر از بیرون |
| --- | --- | --- |
| `attr x : INT` | بله | بله |
| `readonly attr x : INT` | بله | خیر |
| `private attr x : INT` | خیر | خیر |

`readonly` همان گزینه‌ای است که به‌طور پیش‌فرض باید سراغش بروید. اجازه می‌دهد هرکسی امتیاز را ببیند و تأکید می‌کند که تغییرش از `home_goal` بگذرد؛ همان‌جایی که قواعد امتیازدهی در آن قرار دارند.

## `create` و `new`

`new` یک شیء از این کلاس می‌سازد که همه‌ی ویژگی‌هایش خالی‌اند. فقط می‌توان آن را درون کلاس به کار برد.

`create` یک روال معمولی با اسمی توافق‌شده است: `#C(args)` دقیقاً همان `C::create(args)` است. یک کلاس می‌تواند چند تا از این‌ها داشته باشد که با آرگومان‌هایشان از هم تشخیص داده می‌شوند، و کلاسی که هیچ‌کدام را ندارد به‌سادگی نمی‌تواند با `#` ساخته شود.

## `SAME`

`SAME` به کلاسی اشاره دارد که در آن نوشته شده است. در `create` نوع بازگشتی است؛ در آرگومان هم به کار می‌آید و همین است که باعث می‌شود یک روال ارث‌بری‌شده درباره‌ی کلاس ارث‌برنده حرف بزند، نه درباره‌ی کلاسی که از آن آمده است.

## روال‌هایی بدون نوع بازگشتی

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

نه `:` دارد و نه نوع. چنین روالی به‌صورت دستور فراخوانی می‌شود و نمی‌تواند در یک عبارت ظاهر شود. نشانه‌ی آن است که هدف فراخوانی، تغییری است که ایجاد می‌کند.

## `self`

درون یک روال، `self` همان شیئی است که روال روی آن فراخوانی شده است. به‌ندرت نوشته می‌شود، چون نام بردن از یک ویژگی یا روال به‌تنهایی یعنی همان ویژگی یا روالِ `self`. جایی لازم می‌شود که شیء باید به جای دیگری سپرده یا بازگردانده شود:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`، `new`، `void`، `result`، `value` و `out` همه واژه‌هایی هستند که Sather آن‌ها را برای خود برداشته است و هیچ‌یک را نمی‌توان به‌عنوان اسم دلخواه خودتان به کار برد.

## ارجاع، نه مقدار

به یک شیء از طریق یک ارجاع دسترسی پیدا می‌کنید. دو اسم برای یک تخته‌ی امتیاز، امتیاز یکسانی را می‌بینند:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`، که بعداً می‌آید، راه رسیدن به رفتار دیگر است.
