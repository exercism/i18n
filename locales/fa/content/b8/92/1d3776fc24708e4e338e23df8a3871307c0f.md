# مقدمه

## «درست» و «غلط»

در Ruby، «درست» و «غلط» حالت‌های «منطقی» هستند که با `true` و `false` نشان داده می‌شوند. این دو می‌توانند به‌تنهایی به‌عنوان مقدار ثابت به کار روند، یا نتیجه‌ی متدهای منطقی یا مقایسه‌ای باشند.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ و _falsey_

وقتی اشیاء در دستورهای `if` یا دیگر بافت‌های منطقی ارزیابی می‌شوند، همه‌ی اشیاء _truthy_ ارزیابی می‌شوند، **به‌جز** `false` و `nil`.

## جریان کنترل

ارزیابی‌های _truthy_ و _falsey_ در بافت جریان کنترل مفید هستند. Ruby نیز مانند زبان‌های رویه‌ای ساختار `if`...`else` دارد، اما شاید رایج‌تر باشد که از `if` به‌عنوان دستوری «محافظ» برای تغییر ارزیابی یک عبارت استفاده شود.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby دستور `unless` را فراهم می‌کند تا کد خواناتر شود.
برای نمونه) به‌جای `eat_desert if not too_full` می‌توانیم `eat_desert unless too_full` را هم بنویسیم.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
