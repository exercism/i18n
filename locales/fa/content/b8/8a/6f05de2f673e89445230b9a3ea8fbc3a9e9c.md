# درباره

[بازه][range] فاصله‌ای بین دو مقدار را نشان می‌دهد.
از بازه معمولاً با انواعی مانند `Int`، `String` و `Character` برای پیمایش دنباله‌ها، برش مجموعه‌ها، یا بررسی اینکه آیا مقداری در محدوده قرار می‌گیرد استفاده می‌شود.

Swift دو عملگر اصلی بازه ارائه می‌دهد:

- **عملگر بازه‌ی بسته (`...`)**: شامل هر دو مقدار شروع و پایان می‌شود (`1...5` شامل ۱، ۲، ۳، ۴ و ۵ است).
- **عملگر بازه‌ی نیمه‌باز (`..<`)**: مقدار شروع را شامل می‌شود اما مقدار پایان را شامل نمی‌شود (`1..<5` شامل ۱، ۲، ۳ و ۴ است).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
وقتی متدی را مستقیماً روی یک لیترال بازه فراخوانی می‌کنید، عبارت بازه را داخل پرانتز بگذارید تا کامپایلر ابتدا بازه را ارزیابی کند:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## تبدیل بازه به آرایه

می‌توانید یک بازه از اعداد را با استفاده از سازنده‌ی `Array(_:)` به `Array` تبدیل کنید:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## برش آرایه با بازه‌ها

می‌توانید از بازه‌ها برای برش زیربخش‌هایی از یک آرایه استفاده کنید:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## ویژگی‌ها و متدهای بازه

عملیات رایج روی بازه‌ها عبارت‌اند از:

| عضو | توضیح | مثال |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count` | تعداد عناصر بازه را برمی‌گرداند | `(1...5).count` مقدار `5` را برمی‌گرداند |
| [`contains(_:)`][contains] | اگر بازه مقدار مشخص‌شده را شامل شود، `true` را برمی‌گرداند | `(1...5).contains(3)` مقدار `true` را برمی‌گرداند |

## بازه‌های یک‌طرفه

Swift از بازه‌های یک‌طرفه (جزئی) نیز پشتیبانی می‌کند، که در آن‌ها مقدار شروع یا پایان را حذف می‌کنید:

- `array[2...]`: از اندیس ۲ تا پایان مجموعه.
- `array[...2]`: از ابتدای مجموعه تا اندیس ۲، با احتساب آن.
- `array[..<2]`: از ابتدای مجموعه تا (اما بدون احتساب) اندیس ۲.

## بازه‌های رشته و کاراکتر

همچنین می‌توان بازه‌هایی بین کاراکترها یا رشته‌هایی ایجاد کرد که با `Comparable` منطبق هستند:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
