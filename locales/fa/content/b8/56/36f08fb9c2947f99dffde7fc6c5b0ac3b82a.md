# مقدمه

C#، مانند بسیاری از زبان‌های دارای نوع‌دهی ایستا، تعدادی نوع ارائه می‌دهد که اعداد صحیح را نمایش می‌دهند و هر یک محدوده‌ی مقادیر خاص خود را دارد. در انتهای کوچک، نوع `sbyte` کمینه‌ای برابر با -۱۲۸ و بیشینه‌ای برابر با ۱۲۷ دارد. مانند همه‌ی انواع اعداد صحیح، این مقادیر به‌صورت `<type>.MinValue` و `<type>.MaxValue` در دسترس هستند. در انتهای بزرگ، نوع `long` کمینه‌ای برابر با -۹,۲۲۳,۳۷۲,۰۳۶,۸۵۴,۷۷۵,۸۰۸ و بیشینه‌ای برابر با ۹,۲۲۳,۳۷۲,۰۳۶,۸۵۴,۷۷۵,۸۰۷ دارد. در فاصله‌ی میان این دو، انواع `short` و `int` قرار دارند.

محدوده‌ها بر اساس پهنای ذخیره‌سازی که سیستم به هر نوع اختصاص می‌دهد تعیین می‌شوند. برای مثال، یک `byte` از ۸ بیت و یک `long` از ۶۴ بیت استفاده می‌کند.

هر یک از انواع بالا با یک معادل بدون علامت جفت می‌شود: `sbyte`/`byte`، `short`/`ushort`، `int`/`uint` و `long`/`ulong`. در همه‌ی موارد، محدوده‌ی مقادیر از ۰ تا منفیِ بیشینه‌ی علامت‌دار ضربدر ۲ به‌علاوه‌ی ۱ است.

| نوع   | پهنا  | کمینه                    | بیشینه                     |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | ۸ بیت  | -۱۲۸                       | +۱۲۷                        |
| short  | ۱۶ بیت | -۳۲_۷۶۸                    | +۳۲_۷۶۷                     |
| int    | ۳۲ بیت | -۲_۱۴۷_۴۸۳_۶۴۸             | +۲_۱۴۷_۴۸۳_۶۴۷              |
| long   | ۶۴ بیت | -۹_۲۲۳_۳۷۲_۰۳۶_۸۵۴_۷۷۵_۸۰۸ | +۹_۲۲۳_۳۷۲_۰۳۶_۸۵۴_۷۷۵_۸۰۷  |
| byte   | ۸ بیت  | ۰                          | +۲۵۵                        |
| ushort | ۱۶ بیت | ۰                          | +۶۵_۵۳۵                     |
| uint   | ۳۲ بیت | ۰                          | +۴_۲۹۴_۹۶۷_۲۹۵              |
| ulong  | ۶۴ بیت | ۰                          | +۱۸_۴۴۶_۷۴۴_۰۷۳_۷۰۹_۵۵۱_۶۱۵ |

یک متغیر (یا عبارت) از یک نوع را می‌توان به‌راحتی به نوع دیگری تبدیل کرد. برای نمونه، در یک عملیات انتساب، اگر نوع مقداری که انتساب داده می‌شود (سمت چپ) تضمین کند که مقدار در محدوده‌ی نوع مقصد (سمت راست) قرار می‌گیرد، یک انتساب ساده کافی است:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

از طرف دیگر، اگر محدوده‌ی نوعی که از آن انتساب داده می‌شود زیرمجموعه‌ای از محدوده‌ی مقادیر نوع مقصد نباشد، آنگاه حتی اگر مقدار خاص در محدوده‌ی مقصد قرار داشته باشد، به یک عملیات «تبدیل نوع»، یعنی `()`، نیاز است:

```csharp
short s = 42;
uint ui = (uint)s;
```

## تبدیل بیت

کلاس `BitConverter` روش راحتی برای تبدیل انواع صحیح به آرایه‌های بایت و برعکس فراهم می‌کند.
