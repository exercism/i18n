# راهنمایی‌ها

## 1. یافتن کارت در دسته

- یک [متد داخلی][index] وجود دارد که می‌تواند اولین عنصر مجموعه را که شرط مشخص‌شده در بلوک را برآورده می‌کند پیدا کند و اندیس آن را برگرداند، و اگر هیچ عنصری پیدا نشد `nil` را برگرداند.

## 2. بزرگ‌کردن همه‌ی نویسه‌ها

- یک [متد داخلی][map] برای تبدیل همه‌ی عنصرهای مجموعه وجود دارد.
- یک [متد داخلی][capitalize] برای بزرگ‌کردن کلمه‌ها روی `String` وجود دارد.

## 3. محاسبه‌ی سطح قدرت همه‌ی کارت‌ها

- می‌توانید از [متد `sum`] برای محاسبه‌ی سطح قدرت کل همه‌ی کارت‌ها استفاده کنید.
- متد `sum` می‌تواند یک بلوک هم بپذیرد تا عنصرها را پیش از جمع‌کردنشان تبدیل کند.

## 4. رمزگشایی یک کارت

- یک [متد داخلی][each_char_with_index] برای پیمایش نویسه‌های یک `String` همراه با اندیس وجود دارد.
