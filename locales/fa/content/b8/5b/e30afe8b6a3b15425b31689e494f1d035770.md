# بازه

[بازه][range] فاصله‌ای بین دو مقدار را نشان می‌دهد.
رایج‌ترین نوع‌هایی که از بازه پشتیبانی می‌کنند `Int`، `Char` و `String` هستند.
از بازه‌ها می‌توان برای کارهای زیادی استفاده کرد؛ مثل ساختن سریع یک مجموعه، برش دادن رشته‌ها، بررسی اینکه یک مقدار درون یک بازه قرار دارد یا نه، و پیمایش.
بازه‌ها با عملگر بازه `..` یا `...` ساخته می‌شوند (به‌ترتیب شامل و غیرشامل).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

دلیل وجود دو عملگر بازه این است که بتوان بازه‌هایی ساخت که مقدار پایانی را شامل شوند یا نه، که مثلاً هنگام کار با ایندکس‌های صفرمبنا به کار می‌آید.

بازه‌ها را می‌توان با سازنده‌ی `Range` هم ساخت.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
وقتی در Crystal با عملگرهای بازه‌ی `..` یا `...` یک بازه می‌سازید و می‌خواهید متدی را روی آن فراخوانی کنید، باید بازه را داخل پرانتز بگذارید.
چون در غیر این صورت، متد روی آرگومان دومِ عملگر بازه فراخوانی می‌شود.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## گرفتن زیررشته‌ها

وقتی می‌خواهید رشته‌ای را برش دهید، می‌توانید از عملگر بازه برای گرفتن زیررشته استفاده کنید.
یعنی با ساختن بازه‌ای که ایندکس شروع و پایان زیررشته را مشخص می‌کند.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

همچنین می‌توانید از ایندکس‌های منفی استفاده کنید تا زیررشته را از انتهای رشته بگیرید.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## متدهای بازه

بازه‌ها مجموعه‌ای از متدها دارند که می‌توان برای کار با آن‌ها از آن‌ها استفاده کرد.
برای مثال، با این متدها می‌توان مجموع همه‌ی مقادیر بازه را به دست آورد یا بررسی کرد که آیا بازه مقدار مشخصی را شامل می‌شود یا نه.

| متد | توضیح | مثال |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum] | مجموع همه‌ی مقادیر بازه را برمی‌گرداند | `(1..5).sum # => 15` |
| [`size`][size] | اندازه‌ی بازه را برمی‌گرداند | `(1..5).size # => 5` |
| [`includes?`][indludes] | اگر بازه مقدار داده‌شده را شامل شود `true` و در غیر این صورت `false` را برمی‌گرداند | `(1..5).includes?(3) # => true` |

## بازه‌های بی‌پایان و بی‌آغاز

یک بازه می‌تواند بی‌پایان یا بی‌آغاز باشد.
در بازه‌ی بی‌پایان یا بی‌آغاز، مقدار شروع یا پایانش `nil` است، اما هنگام تعریف بازه می‌توان `nil` را حذف کرد.

استفاده از بازه‌های بی‌آغاز و بی‌پایان وقتی مفید است که مثلاً بخواهید رشته‌ای را از ابتدا یا تا انتها برش دهید.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
اگر بازه‌ی بی‌پایان روی یک مجموعه استفاده نشود، در صورت بی‌احتیاطی می‌تواند به یک دنباله‌ی بی‌پایان منجر شود.
~~~~

## بازه‌های `Char`

می‌توان از کاراکترها در بازه‌ها استفاده کرد و این امکان را دارد که فاصله‌ای از کاراکترها بین دو کاراکتر به دست آورید.
برای مثال، وقتی بخواهید الفبا را به دست آورید، این کار به کار می‌آید.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## بازه‌های `String`

از رشته‌ها هم می‌توان در بازه‌ها استفاده کرد و به این ترتیب فاصله‌ای از رشته‌ها بین دو رشته به دست می‌آید.
اما رفتارش وقتی در یک بازه‌ی رشته‌ای چند کاراکتر به کار می‌رود، کمی با رفتار `Char` فرق دارد.
رفتارش در بازه‌های رشته‌ای پیچیده‌تر می‌تواند گیج‌کننده شود، پس احتیاط کنید.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
