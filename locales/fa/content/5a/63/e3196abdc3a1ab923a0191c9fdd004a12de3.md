# مقدمه

## سازنده

برای ساختن یک نمونه از یک _کلاس_، _سازنده‌ی_ آن را با عملگر `new` فراخوانی می‌کنید.
سازنده نوع ویژه‌ای از متد است که هدفش مقداردهی اولیه به نمونه‌ای است که تازه ساخته شده.
سازنده‌ها شبیه متدهای معمولی هستند، اما نوع بازگشتی ندارند و اسمشان با اسم کلاس یکسان است.

```java
class Library {
    private int books;

    public Library() {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

سازنده‌ها هم مانند متدهای معمولی می‌توانند پارامتر داشته باشند.
پارامترهای سازنده معمولاً به‌صورت فیلدهای (خصوصی) نگه داشته می‌شوند تا بعداً به آن‌ها دسترسی داشته باشیم، یا در یک محاسبه‌ی یک‌بارمصرف به کار می‌روند.
آرگومان‌ها را هم می‌توان به سازنده‌ها پاس داد، درست همان‌طور که آرگومان‌ها را به متدهای معمولی پاس می‌دهید.

```java
class Building {
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight) {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```
