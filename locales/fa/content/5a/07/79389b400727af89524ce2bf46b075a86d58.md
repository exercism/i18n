# درباره

علاوه بر دستور `if`، یک دستور `switch` هم وجود دارد که منطق را به‌صورت شرطی اجرا می‌کند. از آن زمانی استفاده می‌شود که یک متغیر واحد باید با چندین مقدار متفاوت مقایسه شود. برای متغیری مانند `x`، دستور `switch` در Haxe نحوه‌ی نگارش زیر را دارد.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

حالت `default` زمانی اجرا می‌شود که هیچ حالت دیگری مطابقت نداشته باشد.
