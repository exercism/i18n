# دستورالعمل‌ها

وظیفه‌ی شما این است که بهترین چیدمان صندلی‌ها دور میز را پیدا کنید.
این کار را با تعریف _«واقعیت‌ها»_ (مواردی که همیشه «درست» هستند) و _«قاعده‌ها»_ (مواردی که به‌شرطی «درست» هستند) انجام می‌دهید.

## 1. آدم‌های پرحرف را فهرست کنید

واقعیت `chatty` را تعریف کنید تا نماینده‌ی آدم‌های پرحرف باشد.
واقعیت `chatty` یک آرگومان می‌گیرد: اسم شخص پرحرف با حروف کوچک.

```prolog
chatty(gustavo).
true.
```

## 2. فهرست کنید چه کسی چه کسی را دوست دارد

واقعیت `likes` را تعریف کنید تا نشان دهد چه کسی چه کسی را دوست دارد.
واقعیت `likes` دو آرگومان می‌گیرد:

1. اسم شخصی که دیگری را دوست دارد، با حروف کوچک
2. اسم شخصی که دوستش دارند، با حروف کوچک

```prolog
likes(esteban, malena).
true.
```

## 3. افرادی که همدیگر را دوست دارند، جفت خوبی می‌سازند

قاعده‌ی `pairing` را طوری تعریف کنید که وقتی هر دو نفر همدیگر را دوست دارند، «درست» باشد.
قاعده‌ی `pairing` دو آرگومان می‌گیرد:

1. اسم نفر اول، با حروف کوچک
2. اسم نفر دوم، با حروف کوچک

```prolog
pairing(malena, esteban).
true.
```

## 4. آدم‌های پرحرف با هر کسی جفت می‌شوند

قاعده‌ی `pairing` را طوری تعریف کنید که وقتی (حداقل) یکی از دو نفری که جفت می‌شوند پرحرف است، «درست» باشد.

```prolog
pairing(valeria, jaime).
true.
```

## 5. چیدمان صندلی‌ها را بررسی کنید

قاعده‌ی `seating` را طوری تعریف کنید که وقتی همه‌ی پنج جفت، جفت‌های خوبی هستند، «درست» باشد.

قاعده‌ی `pairing` پنج آرگومان می‌گیرد:

1. اسم نفر اول، با حروف کوچک
2. اسم نفر دوم، با حروف کوچک
3. اسم نفر سوم، با حروف کوچک
4. اسم نفر چهارم، با حروف کوچک
5. اسم نفر پنجم، با حروف کوچک

از واقعیت‌ها و قاعده‌هایی که همین حالا تعریف کردید برای بررسی چیدمان صندلی‌ها استفاده کنید.

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
