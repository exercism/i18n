# مقدمه

Elixir از توابع زیادی برای کار با بیت‌ها پشتیبانی می‌کند که در ماژول `Bitwise` قرار دارند.

- `band/2`: AND بیتی
- `bsl/2`: شیفت به چپ بیتی
- `bsr/2`: شیفت به راست بیتی
- `bxor/2`: XOR بیتی
- `bor/2`: OR بیتی
- `bnot/1`: NOT بیتی

در ادامه مثالی از نحوه‌ی استفاده از یک تابع بیتی را می‌بینید:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

همه‌ی توابع بیتی فقط روی اعداد صحیح کار می‌کنند.

اگر از Elixir نسخه‌ی ۱.۹ یا پایین‌تر استفاده می‌کنید، برای استفاده از ماژول `Bitwise` باید در ابتدای تعریف ماژول `require Bitwise` را فراخوانی کنید.
