# دستورالعمل‌ها

مری طرفدار پروپاقرص سریال تلویزیونی _Star Trek: The Next Generation_ است. او اغلب بازی‌های نقش‌آفرینی قلم و کاغذی بازی می‌کند، بازی‌هایی که در آن‌ها خودش و دوستانش خود را خدمه‌ی _Starship Enterprise_ جا می‌زنند. شخصیت مری، کاپیتان پیکارد است و این یعنی باید دفتر وقایع کاپیتان را نگه دارد. او بخش خلاقانه‌ی بازی را دوست دارد، اما دوست ندارد داده‌های تصادفی را همان‌جا و در لحظه تولید کند.

به مری کمک کنید و برای داده‌هایی که معمولاً در دفتر وقایع کاپیتان ظاهر می‌شوند، تولیدکننده‌های تصادفی بسازید.

## 1. تولید یک سیاره‌ی تصادفی

_Starship Enterprise_ در سفرهایش با سیاره‌های بسیاری روبه‌رو می‌شود. سیاره‌های جهان Star Trek بر اساس ویژگی‌هایشان به دسته‌هایی تقسیم می‌شوند. برای مثال، زمین یک سیاره‌ی کلاس M است. همه‌ی کلاس‌های ممکن سیاره عبارت‌اند از: D، H، J، K، L، M، N، R، T و Y.

تابع `random_planet_class/0` را پیاده‌سازی کنید. این تابع باید یکی از کلاس‌های سیاره را به‌صورت تصادفی برگرداند.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. تولید یک شماره‌ی ثبت سفینه‌ی تصادفی

Enterprise (شماره‌ی ثبت NCC-1701) تنها سفینه‌ای نیست که در فضا پرواز می‌کند! وقتی با سفینه‌ی دیگری ملاقات می‌کند، مری باید شماره‌ی ثبت آن سفینه را یادداشت کند.

شماره‌های ثبت با پیشوند «NCC-» شروع می‌شوند و بعد از آن عددی از ۱۰۰۰ تا ۹۹۹۹ (شامل هر دو سر) می‌آید.

تابع `random_ship_registry_number/0` را پیاده‌سازی کنید که یک شماره‌ی ثبت سفینه‌ی تصادفی برمی‌گرداند.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. تولید یک تاریخ ستاره‌ای تصادفی

دفتر وقایعی که تاریخ نداشته باشد، به چه کار می‌آید؟

«تاریخ ستاره‌ای» یک عدد اعشاری است. ماجراهای _Starship Enterprise_ در فصل اول _The Next Generation_ بین تاریخ‌های ستاره‌ای ۴۱۰۰۰٫۰ و ۴۲۰۰۰٫۰ رخ می‌دهد. «۴» به معنای قرن بیست‌وچهارم است و «۱» به معنای فصل اول.

تابع `random_stardate/0` را پیاده‌سازی کنید که یک عدد اعشاری بین ۴۱۰۰۰٫۰ (شامل خودش) و ۴۲۰۰۰٫۰ (بدون خودش) برمی‌گرداند.

پیاده‌سازی باید از یک تابع Erlang استفاده کند.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. قالب‌بندی تاریخ ستاره‌ای

در دفتر وقایع کاپیتان، تاریخ‌های ستاره‌ای معمولاً تا یک رقم اعشار گرد می‌شوند.

تابع `format_stardate/1` را پیاده‌سازی کنید که یک عدد اعشاری می‌گیرد و رشته‌ای برمی‌گرداند که در آن عدد تا یک رقم اعشار گرد شده است.

پیاده‌سازی باید از یک تابع Erlang استفاده کند.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
