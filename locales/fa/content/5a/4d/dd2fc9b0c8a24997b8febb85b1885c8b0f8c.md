# مقدمه

«بلوک» مجموعه‌ای از دستورها و اعلان‌هاست که به‌صورت یک واحد کنار هم گروه‌بندی می‌شوند.
بلوک‌ها اغلب، اما نه همیشه، درون آکولادها تعریف می‌شوند.
بلوک‌ها می‌توانند درون توابع و درون بلوک‌های دیگر تودرتو شوند.

یک تابع تا حدی شبیه یک بلوک عمل می‌کند.
شناسه‌ی متغیری که در یک تابع تعریف می‌شود از بیرون آن تابع دیده نمی‌شود، همان‌طور که شناسه‌ی متغیری که در یک بلوک تعریف می‌شود از بیرون آن بلوک دیده نمی‌شود.
دو متغیر در دو تابع می‌توانند اسم یکسانی داشته باشند، چون آن دو تابع درون یکدیگر را نمی‌بینند؛ همان‌طور که دو متغیر در دو بلوک می‌توانند اسم یکسانی داشته باشند، چون آن دو بلوک درون یکدیگر را نمی‌بینند.
اما توابع و بلوک‌ها یکسان نیستند.
یک تابع را نمی‌توان درون تابع دیگری تودرتو کرد، اما یک بلوک را می‌توان درون بلوک دیگری تودرتو کرد.

در مثال زیر، `number` درون تابع `main` تعریف شده است.
`flag` درون بلوک `if` تعریف شده است که خودش درون تابع `main` تودرتو شده است.
متغیرهایی که درون یک بلوک تعریف می‌شوند فقط درون همان بلوک معتبرند.
بنابراین، تلاش برای کامپایل کردن کد به خطای کامپایل منجر می‌شود.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

ممکن است پیام خطا گیج‌کننده باشد، چون `flag` _واقعاً_ پیش‌تر در تابع استفاده شده است.
با این حال، `flag` درون یک بلوک داخل تابع تعریف شده است.
بلوک داخلی می‌تواند متغیر `number` را در تابع بیرونی‌اش «ببیند»، اما تابع بیرونی نمی‌تواند متغیر `flag` را که درون بلوک داخلی‌اش تعریف شده «ببیند».
به‌محض اینکه اجرا از بلوک خارج شود، متغیر `flag` به‌طور خودکار نابود می‌شود و دیگر در اختیار برنامه نیست.
خود تابع `main` اولین بار شناسه‌ی `flag` را در آخرین دستور `printf` می‌بیند.
اگر آخرین دستور `printf` حذف شود، برنامه کامپایل می‌شود و هنگام اجرا `1` را چاپ می‌کند.
دلیلش این است که متغیر `flag` در بلوکی که اولین دستور `printf` را در بر دارد معتبر است.

از `C99` به بعد، دستورهای تک‌خطی `if`، `for`، `while` و `do` هم بلوک به حساب می‌آیند.
در مثال زیر، با اینکه `i` درون آکولادها تعریف نشده است، فقط در بلوکی وجود دارد که دستور `for` تعریف کرده است و برای تابع بیرونی `main` قابل دیدن نیست.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

اگر آخرین دستور `printf` حذف شود، برنامه کامپایل می‌شود و هنگام اجرا `0 2 4 6 8 10 ` را چاپ می‌کند.
بعضی زبان‌ها، مثل Go و Rust، صراحتاً بیان می‌کنند که دستورهای شرطی و حلقه‌ای تک‌خطی یک بلوک تشکیل می‌دهند.
آن‌ها لازم می‌دانند که چنین دستورهای تک‌خطی همچنان درون آکولادها قرار بگیرند.
