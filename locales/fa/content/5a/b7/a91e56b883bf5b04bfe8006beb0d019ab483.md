# مقدمه

## مقادیر منطقی در R

مقادیر «درست» یا «غلط»، که گاهی مقادیر «بولی» هم نامیده می‌شوند، با نوع `logical` نمایش داده می‌شوند.
این نوع فقط دو مقدار دارد: `TRUE` و `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## عملگرهای منطقی

در R پنج عملگر منطقی وجود دارد، اما در این مرحله از برنامه‌ی درسی فقط سه مورد از آن‌ها مرتبط است.
دو عملگر دیگر هنگام کار با بردارها مهم خواهند بود، که در چند مفهوم بعدی به آن‌ها پرداخته می‌شود.

`&&` عملگر «و» منطقی است.
اگر عبارت‌های *هر دو* طرف `&&` مقدار `TRUE` باشند، به `TRUE` ارزیابی می‌شود.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` عملگر «یا» منطقی است.
اگر یک عبارت در *هر کدام* از طرفین `||` مقدار `TRUE` باشد، به `TRUE` ارزیابی می‌شود.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` عملگر «نه» منطقی است.
مقادیر `TRUE` و `FALSE` را با هم عوض می‌کند.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

برای عبارت‌های طولانی‌تر و پیچیده‌تر، بهتر است برای روشن شدن منظورتان از پرانتز استفاده کنید.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
