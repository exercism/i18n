# Char

`Char` یک نوع داده در Crystal است که یک نقطه‌ی کد یونیکد ۳۲ بیتی را نمایش می‌دهد.
اندازه‌ی آن باعث می‌شود از نظر حافظه بهینه باشد و ویژگی‌های خاصی به آن بدهد که `String` ندارد.
`Char` با کوتیشن تک (`'`) ساخته می‌شود و فقط یک نقطه‌ی کد یونیکد می‌تواند درون آن قرار بگیرد.

```crystal
'a' # => 'a'
'a'.class # => Char
```

در Crystal کار کردن با `Char` هنگام کار با `String` بسیار رایج است، چون تعداد قابل توجهی از متدهای کلاس `String` یک `Char` برمی‌گردانند یا یک `Char` را به عنوان آرگومان می‌گیرند.
برای مثال، متد [`String#[]`][index] یک `Char` برمی‌گرداند، و متد [`String#chars`][chars] مجموعه‌ای از `Char`ها را برمی‌گرداند.

## افزایش و کاهش

چون `Char` یک نقطه‌ی کد ۳۲ بیتی یونیکد است، از افزایش و کاهش پشتیبانی می‌کند؛ به همین دلیل اگر `'a'` را داشته باشید، با اضافه کردن یک به آن به `'b'` می‌رسید.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

همچنین متدی به اسم [`Char#succ`][succ] وجود دارد که `Char` بعدی را در جدول یونیکد برمی‌گرداند، و [`Char#pred`][pred] که `Char` قبلی را در جدول یونیکد برمی‌گرداند.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## الحاق

چون `Char` فقط برای نمایش یک یونیکد ۳۲ بیتی در نظر گرفته شده است، دو `Char` را نمی‌توان به هم الحاق کرد.
بنابراین `Char` را فقط می‌توان با `String` الحاق کرد.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## متدهای ویژگی

Crystal چند متد برای گرفتن اطلاعات درباره‌ی یک کاراکتر دارد، مثلاً اینکه عدد است یا حرف، یا بزرگ است یا کوچک.
در ادامه فهرستی از چند مورد از این متدها آمده است؛ برای مشاهده‌ی فهرست کامل، [API مربوط به `Char`][char-api] را ببینید:

| متد                           | توضیحات                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | اگر `Char` یک عدد باشد، `true` را برمی‌گرداند               |
| [`Char#letter?`][letter]         | اگر `Char` یک حرف باشد، `true` را برمی‌گرداند               |
| [`Char#lowercase?`][lowercase]   | اگر `Char` حرف کوچک باشد، `true` را برمی‌گرداند              |
| [`Char#uppercase?`][uppercase]   | اگر `Char` حرف بزرگ باشد، `true` را برمی‌گرداند              |
| [`Char#ascii?`][ascii]           | اگر `Char` یک کاراکتر ASCII باشد، `true` را برمی‌گرداند     |
| [`Char#whitespace?`][whitespace] | اگر `Char` یک کاراکتر فضای خالی باشد، `true` را برمی‌گرداند |

## تبدیل

### تبدیل بین نقطه‌های کد و `Char`

چون `Char` یک نقطه‌ی کد ۳۲ بیتی یونیکد است، می‌توانید بین `Char` و نقطه‌های کد (`Int`) تبدیل انجام دهید.
این کار با متد [`Char#ord`][ord] امکان‌پذیر است که نقطه‌ی کد مربوط به `Char` را برمی‌گرداند، یا با متد [`Int#chr`][chr] که `Char` مربوط به نقطه‌ی کد را برمی‌گرداند.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### تبدیل بین نوع‌ها

مانند سایر نوع‌های داده، `Char` چند متد برای تبدیل بین نوع‌ها دارد.
رایج‌ترین آن‌ها متد `Char#to_s` است که `Char` را به `String` تبدیل می‌کند. همچنین متد `Char#to_i` وجود دارد که `Char` را به `Int` تبدیل می‌کند، و متد `Char#to_f` که `Char` را به `Float` تبدیل می‌کند.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## فرار

مانند `String`ها، برخی کاراکترها را نمی‌توان مستقیم نوشت و برای نوشتنشان باید آن‌ها را فرار دهید.
می‌توانید از کاراکتر `\` برای نوشتن یک دنباله‌ی فرار و سپس کاراکتری که می‌خواهید فرار دهید استفاده کنید.

این‌ها کاراکترهای خاص در Crystal هستند:

| مقدار    | توضیحات                   |
| -------- | ----------------------------- |
| `\a`     | هشدار                         |
| `\b`     | پاک‌کردن به عقب                     |
| `\e`     | فرار                        |
| `\f`     | فید فرم                     |
| `\n`     | فید خط یا خط جدید          |
| `\r`     | بازگشت به ابتدای خط               |
| `\t`     | تب افقی                |
| `\v`     | تب عمودی                  |
| `\\`     | بک‌اسلش                     |
| `\'`     | کوتیشن تک                  |
| `\"`     | کوتیشن دوگانه                  |
| `\377`   | کاراکتر ASCII در مبنای هشت         |
| `\xFF`   | کاراکتر ASCII در مبنای شانزده   |
| `\uFFFF` | کاراکتر یونیکد در مبنای شانزده |
