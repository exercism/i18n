# دستورالعمل‌های مخصوص SQLite

* ستون **digits** شامل فهرستی از اعداد صحیح است که با JSON کدگذاری شده است.
  مثال:
  ```json
  [1,0,1,0,1,0]
  ```
* ستون **result** باید شامل داده‌های کدگذاری‌شده با JSON باشد: یک شیء که ارقام در آن به‌صورت اعداد صحیح آمده‌اند، یا توضیحی از هر خطایی.
  مثال‌ها:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  یا
  ```json
  {"error":"some error description"}
  ```

## شِمای جدول

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
