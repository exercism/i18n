# مقدمه

بیشتر داده‌ها در Factor در *دنباله‌ها* قرار دارند. آرایه‌ها، بردارها و رشته‌ها همگی دنباله‌اند و مجموعه‌ای مشترک از واژه‌ها را از واژگان [`sequences`][sequences] به اشتراک می‌گذارند.

## لیترال آرایه

آرایه‌ی «لیترال» با `{ }` و با فضای خالی بین عنصرها نوشته می‌شود:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

آرایه‌ها طول ثابت دارند، بنابراین واژه‌هایی مثل `suffix` و `remove-nth` که تعداد عنصرها را تغییر می‌دهند، به‌جای بزرگ کردن دنباله‌ی اصلی، یک دنباله‌ی *جدید* برمی‌گردانند.

## طول و اندیس‌گذاری

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` نسخه‌ی ایمن نسبت به محدوده است: می‌توانید یک موقعیت را بدون بررسی اولیه‌ی طول، بررسی کنید.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## برش

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

هر دو اگر `n` بزرگ‌تر از دنباله باشد خطا می‌دهند. اگر `n` بیش از حد بزرگ باشد، `index-or-length` آن را تا طول دنباله کوچک می‌کند تا برشی که پس از آن می‌آید از انتهای دنباله بیرون نزند:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

گونه‌های ستاره‌دار `head*` و `tail*` از انتها می‌شمارند: `head*` آخرین `n` عنصر را حذف می‌کند و `tail*` آخرین `n` عنصر را نگه می‌دارد:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

برای یک برش دلخواه بین دو اندیس، `subseq` *شروع* (شامل) و *پایان* (غیرشامل) را می‌گیرد:

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

وقتی یک *شروع و طول* دارید، آن‌ها را جمع کنید تا پایان به دست آید:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(این محدوده‌ی اندیس `[2, 5)` است؛ سه نویسه که از موقعیت ۲ شروع می‌شوند.)

پرسش معکوس، یعنی *کجا* یک زیردنباله رخ می‌دهد، با `subseq-index` پاسخ داده می‌شود؛ این واژه اندیس شروع اولین تطابق را برمی‌گرداند، یا اگر تطابقی نباشد `f` را:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## پر کردن

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

هر دو `seq` را گسترش می‌دهند تا طولش حداقل `n` شود. اگر `seq` از قبل به آن اندازه باشد، بدون تغییر برگردانده می‌شود.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## همان واژه‌ها روی رشته‌ها هم کار می‌کنند

رشته دنباله‌ای از نویسه‌هاست، بنابراین همه‌ی موارد بالا روی رشته‌ها هم کار می‌کنند؛ فقط نتیجه به‌جای آرایه، یک رشته‌ی دیگر است:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## تجمیع

`sum` و `product` (در [`sequences`][sequences]) عنصرهای یک دنباله‌ی عددی را جمع یا ضرب می‌کنند:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` یک گزاره را روی دنباله اجرا می‌کند و برمی‌گرداند که این گزاره برای چند عنصر درست است:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## گزاره‌ها روی کل دنباله

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## ساختن یک دنباله‌ی جدید

`suffix` یک عنصر به انتهای دنباله اضافه می‌کند؛ `prefix` یکی به ابتدا. `unclip` اولین عنصر را جدا می‌کند و `unclip-last` آخرین عنصر را:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

ترکیب `unclip-last` و `suffix` یک به‌روزرسانی غیرمخرب از آخرین عنصر به دست می‌دهد (و `unclip` به همراه `prefix` همین کار را برای اولین عنصر انجام می‌دهد):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## تبدیل میان نوع‌های دنباله

`>array`، `>vector` و `>string` (در [`arrays`][arrays] و واژگان متناظر) یک دنباله را به یک نوع مشخص تبدیل می‌کنند. وقتی یک عملیات برش یا دنباله‌ی عمومی برگردانده باشد و شما به آرایه (یا رشته) نیاز داشته باشید، مفید است.

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
