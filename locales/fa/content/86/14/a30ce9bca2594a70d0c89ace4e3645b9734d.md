# پیوست دستورالعمل‌ها

## نکته‌ها

باید تابع `rotate` را پیاده‌سازی کنید که یک `Int` و یک `String` می‌گیرد و سپس آن را با یک رمز چرخشی کدگذاری می‌کند.
اگر درباره‌ی نوع‌ها مطمئن نیستید می‌توانید از امضای ارائه‌شده استفاده کنید، اما نگذارید خلاقیت‌تان را محدود کند.

این تمرین با داده‌های متنی کار می‌کند. به دلایل تاریخی، نوع `String` در Haskell هم‌معنی `[Char]` است، یعنی لیستی از کاراکترها. برای پردازش کارآمدتر داده‌های متنی می‌توان از نوع `Text` استفاده کرد.

به عنوان یک گسترش اختیاری برای این تمرین، می‌توانید

- درباره‌ی [انواع رشته](https://haskell-lang.org/tutorial/string-types) در Haskell بخوانید.
- `- text` را به لیست وابستگی‌هایتان در package.yaml اضافه کنید.
- `Data.Text` را [به این شکل](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) وارد کنید:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- از نوع `Text` استفاده کنید، مثلاً `rotate :: Int -> Text -> Text`، و ترکیب‌کننده‌های `Data.Text` را مثلاً به شکل `T.pack` به کار ببرید.
- به مستندات [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) نگاهی بیندازید.
- همه‌ی رخدادهای `String` را در RotationalCipher.hs با `Text` جایگزین کنید، یعنی:

```haskell
rotate :: Int -> Text -> Text
```

این بخش کاملاً اختیاری است.
