# دستورالعمل‌ها

سالن زیبایی‌ای در نیویورک که در تمرین «Booking Up For Beauty» به آن کمک کردید، کارش گرفته و بسیاری از مشتریانش به مشتری ثابت تبدیل شده‌اند.
مشتری ثابت به جای اینکه هر بار جداگانه نوبت بگیرد، یک قرار همیشگی دارد: «یک سه‌شنبه در میان»، «آخرین جمعه‌ی ماه» و از این قبیل.
صاحب سالن از شما ابزاری کمکی خواسته که تاریخ‌های پشت این قرارها و همچنین تاریخ‌های برنامه‌ی ماهانه‌ی خود سالن را حساب کند.

## 1. قرار ثابت یک مشتری ثابت را پیدا کنید

متد `SalonCalendar.standingAppointment()` را پیاده‌سازی کنید که یک سال، یک ماه، یک تکرار (`1` برای اولین، `2` برای دوم و به همین ترتیب) و یک روز از هفته می‌گیرد.
این متد تاریخ آن تکرار از آن روز هفته را در آن ماه برمی‌گرداند:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. قرار آخر ماه یک مشتری ثابت را پیدا کنید

بعضی از مشتری‌های ثابت آخرین تکرار روز مورد نظرشان در ماه را ترجیح می‌دهند.
متد `SalonCalendar.lastAppointment()` را پیاده‌سازی کنید که یک سال، یک ماه و یک روز از هفته می‌گیرد و تاریخ آخرین تکرار آن روز هفته را در آن ماه برمی‌گرداند:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. نزدیک‌ترین روز آزاد را برای مشتری بدون نوبت پیدا کنید

مشتری‌ای پشت پذیرش می‌پرسد «شنبه‌ی بعد».
اگر روزی که مشتری پرسشش را مطرح می‌کند خودش شنبه باشد، منظورش همان روز است.
متد `SalonCalendar.nextAvailable()` را پیاده‌سازی کنید که یک تاریخ و یک روز از هفته می‌گیرد و اولین تاریخی را برمی‌گرداند که در آن روز یا بعد از آن قرار دارد و به آن روز هفته می‌افتد:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. روز بستن حساب‌ها را پیدا کنید

سالن حساب‌هایش را در آخرین روز هر ماه می‌بندد.
اما سالن در آخر هفته تعطیل است، پس وقتی آخرین روز ماه به شنبه یا یکشنبه بیفتد، حساب‌ها در جمعه‌ی پیش از آن بسته می‌شوند.
متد `SalonCalendar.bookkeepingDay()` را پیاده‌سازی کنید که یک سال و یک ماه می‌گیرد و روز بستن حساب‌های آن ماه را برمی‌گرداند:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. قاعده‌ی آخر هفته را برای روز پرداخت حقوق دوباره به کار ببرید

حقوق کارکنان پانزدهم هر ماه پرداخت می‌شود، با همان قاعده‌ی آخر هفته: وقتی پانزدهم به شنبه یا یکشنبه بیفتد، روز پرداخت جمعه‌ی پیش از آن است.
به جای اینکه این قاعده را بار دوم بنویسید، آن را به یک تنظیم‌کننده‌ی قابل استفاده‌ی مجدد تبدیل کنید.

متد `SalonCalendar.precedingWorkday()` را پیاده‌سازی کنید که یک `TemporalAdjuster` برمی‌گرداند؛ این تنظیم‌کننده روزهای هفته را بدون تغییر می‌گذارد و شنبه یا یکشنبه را به جمعه‌ی پیش از آن برمی‌گرداند.
سپس متد `SalonCalendar.payday()` را پیاده‌سازی کنید که یک سال و یک ماه می‌گیرد و از همان تنظیم‌کننده استفاده می‌کند:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

اگر خواستید، می‌توانید برگردید و از این تنظیم‌کننده در `bookkeepingDay()` هم استفاده کنید.
