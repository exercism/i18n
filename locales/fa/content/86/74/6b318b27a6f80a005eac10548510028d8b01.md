# Instructions

در این تمرین روی یک زمان‌بند قرار ملاقات برای یک سالن زیبایی در نیویورک کار می‌کنید؛ سالنی که در ۱۵ سپتامبر ۲۰۱۲ افتتاح شد.

چهار کار پیش رو دارید که همه به تاریخ‌های قرار ملاقات مربوط می‌شوند. تاریخ‌ها و زمان‌ها از یکی از این سه قالب زیر استفاده می‌کنند:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

تست‌ها به‌طور خودکار «فرهنگ» را روی `en-US` تنظیم می‌کنند؛ لازم نیست خودتان فرهنگ را تنظیم یا مشخص کنید.

## 1. تجزیه‌ی تاریخ قرار ملاقات

متد (_static_) `Appointment.Schedule()` را پیاده‌سازی کنید تا نمایش متنی یک تاریخ قرار ملاقات را به قالب متناظر `DateTime` تجزیه کنید:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. بررسی این که آیا قرار ملاقات گذشته است

متد (_static_) `Appointment.HasPassed()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و بررسی می‌کند آیا قرار در گذشته بوده است یا نه:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. بررسی این که آیا قرار ملاقات بعدازظهر است

متد (_static_) `Appointment.IsAfternoonAppointment()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و بررسی می‌کند آیا قرار ملاقات بعدازظهر است یا نه (بزرگ‌تر یا مساوی ۱۲:۰۰ و کوچک‌تر از ۱۸:۰۰):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. توصیف زمان و تاریخ قرار ملاقات

متد (_static_) `Appointment.Description()` را پیاده‌سازی کنید که یک تاریخ قرار ملاقات می‌گیرد و توصیفی از آن تاریخ و زمان را برمی‌گرداند:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. برگرداندن تاریخ سالگرد

متد (_static_) `Appointment.AnniversaryDate()` را پیاده‌سازی کنید که تاریخ سالگرد امسال را برمی‌گرداند؛ تاریخ سالگرد ۱۵ سپتامبر است:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
