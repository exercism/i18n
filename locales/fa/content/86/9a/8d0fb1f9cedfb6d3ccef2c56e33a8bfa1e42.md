# مقدمه

«پروتکل‌ها» سازوکاری برای دستیابی به «چندریختی» در Elixir هستند، زمانی که می‌خواهید رفتار بسته به نوع داده تغییر کند.

«پروتکل‌ها» با استفاده از `defprotocol` تعریف می‌شوند و شامل یک یا چند سرآیند تابع هستند.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

«پروتکل‌ها» را می‌توان با استفاده از `defimpl` پیاده‌سازی کرد.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

یک پروتکل را می‌توان برای هر نوع داده‌ی موجود در Elixir یا برای یک «ساختار» پیاده‌سازی کرد.

وقتی یک تابع پروتکل فراخوانی می‌شود، پیاده‌سازی مناسب به‌طور خودکار بر اساس نوع آرگومان اول انتخاب می‌شود.
