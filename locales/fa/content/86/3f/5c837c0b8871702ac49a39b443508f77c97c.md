# مقدمه

## عملگرهای مقایسه

[عملگرهای مقایسه][comparison-operators] دو مقدار از یک نوع را با هم مقایسه می‌کنند و یک مقدار `Bool` برمی‌گردانند (`true` یا `false`).
اگر مقادیری از نوع‌های متفاوت را با هم مقایسه کنید، کامپایلر خطا می‌دهد.

عملگرهای مقایسه‌ی استاندارد در Swift عبارت‌اند از:

| عملگر | توضیح              | مثال            |
| ------ | ------------------ | --------------- |
| `==`   | برابر است با        | `1 == 1` («درست») |
| `!=`   | برابر نیست با       | `1 != 2` («درست») |
| `<`    | کوچک‌تر از          | `4 < 5` («درست»)  |
| `<=`   | کوچک‌تر یا مساوی    | `4 <= 4` («درست») |
| `>`    | بزرگ‌تر از           | `3 > 1` («درست»)  |
| `>=`   | بزرگ‌تر یا مساوی     | `2 >= 2` («درست») |

## دستورهای `if` و `else`

یک [دستور شرطی][conditional-statement] بر اساس اینکه نتیجه‌ی یک شرط `true` باشد یا `false`، کد را اجرا می‌کند.
رایج‌ترین دستور شرطی، [دستور `if`][if] است که یک بلوک کد را فقط زمانی اجرا می‌کند که شرطش `true` باشد.
یک دستور `if` را با کلیدواژه‌ی `if` می‌نویسید؛ بعد از آن شرط و بلوکی از کد می‌آید که داخل آکولاد قرار گرفته است:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

می‌توانید `if` را با یک بند `else` همراه کنید تا وقتی شرط `false` است، کد جایگزینی اجرا شود:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

برای آزمودن چند شرط پشت سر هم، دستورها را با `else if` به هم زنجیر کنید.
یک دستور `if` به شاخه‌ی `else` نیازی ندارد، اما می‌توانید یکی را بگنجانید تا حالت‌هایی را پوشش دهید که هیچ‌کدام از شرط‌ها برقرار نیستند:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## عبارت‌های `if`

در Swift مدرن، از دستورهای `if` می‌توان به‌عنوان عبارت‌هایی که یک مقدار تولید می‌کنند هم استفاده کرد.
هر شاخه به یک مقدار ارزیابی می‌شود و همین، تخصیص نتیجه به‌صورت شرطی را آسان می‌کند:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## عملگر سه‌تایی

[عملگر شرطی سه‌تایی][ternary-operator] کوتاه‌نویسی فشرده‌ای برای یک عبارت `if-else` است.
این عملگر یک شرط را ارزیابی می‌کند و بسته به اینکه آن شرط `true` باشد یا `false`، یکی از دو مقدار را برمی‌گرداند.

این عملگر سه بخش دارد: `condition ? trueExpression : falseExpression`.
اگر `condition` به `true` ارزیابی شود، `trueExpression` ارزیابی و برگردانده می‌شود؛ در غیر این صورت `falseExpression` ارزیابی و برگردانده می‌شود.

عملگر سه‌تایی برای انتخاب‌های ساده و یک‌خطی ایده‌آل است:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

مثال بالا معادل فشرده‌ای است از:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
