# مقدمه

## مقایسه‌ی اعداد

در `jq` می‌توان اعداد را با عملگرهای رابطه‌ای و برابری زیر مقایسه کرد.

| مقایسه                 | عملگر    |
| ---------------------- | -------- |
| بزرگ‌تر از              | `a > b`  |
| بزرگ‌تر یا مساوی        | `a >= b` |
| کوچک‌تر از              | `a < b`  |
| کوچک‌تر یا مساوی        | `a <= b` |
| برابری                 | `a == b` |
| نابرابری               | `a != b` |

نتیجه‌ی مقایسه همیشه یک «مقدار منطقی» است، یعنی یا `true` یا `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## مقایسه‌ی رشته‌ها

از عملگرهای مقایسه‌ی بالا می‌توان برای مقایسه‌ی رشته‌ها هم استفاده کرد.
در این حالت، یک ترتیب واژه‌نامه‌ای (لکسیکوگرافیک) اعمال می‌شود.
این ترتیب _بر اساس مقدار کدپوینت یونیکد_ است.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

وقتی دو متغیری را مقایسه می‌کنید که ظاهراً مقدار عددی دارند اما از نوع رشته هستند، باید دقت کنید.
به دلیل ترتیب واژه‌نامه‌ای، نتیجه با مقایسه‌ی مقادیر از نوع عدد یکسان نخواهد بود.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## برابری «سخت‌گیرانه»

عملگر `==` در `jq` از این نظر مانند `===` در Javascript است که مقادیری که به نظر یکسان می‌آیند اما از نوع متفاوتی هستند، با هم برابر نیستند.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## مقایسه‌ی آرایه‌ها

دو آرایه زمانی برابرند که همه‌ی عناصر متناظرشان برابر باشند.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## مقایسه‌ی اشیاء

دو شیء زمانی برابرند که جفت‌های کلید-مقدار یکسانی داشته باشند.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
