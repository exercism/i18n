# مقدمه

## عملگر سه‌گانه

یک «شرط سه‌گانه» روشی کوتاه‌تر برای نوشتن دستورهای ساده‌ی `if/else` است.
اگر یک دستور `if/else` فقط دو شاخه داشته باشد، یکی برای وقتی که شرط «درست» است و یکی برای وقتی که «غلط» است، می‌توان آن را به‌صورت یک شرط سه‌گانه بازنویسی کرد.

شرط‌های سه‌گانه از ترکیب نمادهای `?` و `:` برای جدا کردن اجزای یک شرط استفاده می‌کنند:

```ruby
condition ? true_branch : false_branch
```

کدی که در سمت چپ `?` قرار دارد، شرط است و کد سمت راست شامل دو شاخه‌ی ممکن است که با `:` از هم جدا شده‌اند.
اگر شرط _«درست»_ باشد، کدی که در سمت _چپ_ `:` قرار دارد اجرا می‌شود.
اگر شرط _«غلط»_ باشد، آنگاه کدی که در سمت _راست_ `:` قرار دارد اجرا می‌شود.

برای مثال:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

را می‌توان به این صورت بازنویسی کرد:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
