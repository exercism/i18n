# درباره

[structها][getting-started] [mapهای][maps] ویژهای با مجموعهای مشخص از کلیدها هستند.

- structها بررسیهای زمان کامپایل و مقادیر پیش‌فرض را فراهم می‌کنند.
- نام یک struct از ماژولی گرفته می‌شود که در آن تعریف شده است.
- برای تعریف یک struct از [`defstruct`][docs-defstruct] استفاده کنید.
  - معمولاً این ساختار بلافاصله پس از تعریف ماژول می‌آید.
- `defstruct` یا فهرستی از [اتم‌ها][atom] را می‌پذیرد (برای مقادیر پیش‌فرض `nil`) یا فهرست‌های کلیدواژه را (برای مقادیر پیش‌فرض مشخص‌شده).
  - فیلدهای بدون مقدار پیش‌فرض باید پیش از فیلدهای دارای مقدار پیش‌فرض بیایند.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## دسترسی به فیلدها و به‌روزرسانی

- بیشتر توابعی که با [mapها][maps] کار می‌کنند، با structها هم کار می‌کنند.
  - [_Access Behaviour_][access-behaviour] یک استثناست و برای structها پیاده‌سازی **نشده** است.
- توصیه می‌شود برای دسترسی به فیلدهای struct از _عملگر دسترسی ایستا_ `.` استفاده کنید.

- گرفتن/واکشی مقادیر فیلد:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- به‌روزرسانی مقادیر فیلد

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## الزام به مقداردهی اولیه‌ی فیلدها

- [ویژگی ماژول `@enforce_keys`][enforcing-keys] یک بررسی در زمان اجرا ایجاد می‌کند که فیلدهای مشخص‌شده باید هنگام ساخت struct به مقداری **غیر** از `nil` مقداردهی شوند.
- پس از `@enforce_keys` فهرستی از کلیدهای فیلد می‌آید (که [اتم][atom] هستند).
- اگر کلیدی که الزام شده مقداردهی نشود، خطایی بالا می‌آید.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
