# مقدمه

مقادیر منطقی در C++ با نوع `bool` نمایش داده می‌شوند.
یک `bool` یا `true` است یا `false`.

## عملگرهای منطقی

C++ از سه عملگر منطقی پشتیبانی می‌کند: `!` (نه)، `&&` (و) و `||` (یا).
همچنین می‌توانید از نسخه‌های جایگزین `not`، `and` و `or` استفاده کنید.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## تقدم

هر یک از این سه عملگر منطقی _تقدم عملگر_ متفاوتی دارند.
در نتیجه، به این ترتیب ارزیابی می‌شوند: ابتدا `!`، سپس `&&` و در نهایت `||`.
اگر می‌خواهید ترتیب متفاوتی را اعمال کنید، می‌توانید یک عبارت منطقی را در پرانتز (یعنی `()`) قرار دهید، زیرا پرانتزها تقدم عملگر بالاتری دارند.

```cpp
!true && false   // => false
!(true and false) // => true
```

## تبدیل

اگر از `true` یا `false` در جایی که انتظار یک عدد می‌رود استفاده کنید، به‌ترتیب به `1` و `0` تبدیل می‌شوند.
اگر از یک عدد در یک عملیات منطقی استفاده کنید، هر مقدار دیگری به جز `0` به عنوان `true` در نظر گرفته می‌شود، حتی مقادیر منفی.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
