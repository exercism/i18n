# راهنما

## عمومی

- نگران این نباشید که آرگومان‌ها چطور به دست می‌آیند؛ فقط روی ترکیب آرگومان‌ها تمرکز کنید تا نتیجه‌ی موردنظر را برگردانید.

## 1. تعریف کنید که آیا pac-man می‌تواند یک شبح را بخورد

- تابع باید یک مقدار [«منطقی»][bool] برگرداند.
- می‌توانید از عملگر [منطقی][bool] `&&` برای ترکیب آرگومان‌ها و به دست آوردن نتیجه استفاده کنید.

## 2. تعریف کنید که آیا pac-man امتیاز می‌گیرد

- تابع باید یک مقدار [منطقی][bool] برگرداند.
- می‌توانید از عملگر [منطقی][bool] `||` برای ترکیب آرگومان‌ها و به دست آوردن نتیجه استفاده کنید.

## 3. تعریف کنید که آیا pac-man می‌بازد

- تابع باید یک مقدار [منطقی][bool] برگرداند.
- می‌توانید از عملگرهای [منطقی][bool] `&&` و `!` برای ترکیب آرگومان‌ها و به دست آوردن نتیجه استفاده کنید.

## 4. تعریف کنید که آیا pac-man برنده می‌شود

- تابع باید یک مقدار [منطقی][bool] برگرداند.
- می‌توانید از عملگرهای [منطقی][bool] `&&` و `!` برای ترکیب آرگومان‌ها و نتایج یکی از توابعی که قبلاً پیاده‌سازی کرده‌اید استفاده کنید.

[bool]: https://gleam.run/book/tour/bools.html
