# درباره

jq با عبور دادن داده‌ی ورودی JSON از یک _عبارت واحد_ (که به‌شکل _خط لوله‌ای از فیلترها_ نوشته می‌شود) کار می‌کند تا به داده‌ی تبدیل‌شده‌ی موردنظر برسد.

## آشنایی سریع با گزینه‌های خط فرمان `jq`

زبان `jq` به‌وسیله‌ی _برنامه‌ی_ `jq` پیاده‌سازی شده است.
این برنامه چندین گزینه‌ی کاربردی خط فرمان در اختیار می‌گذارد که نحوه‌ی مصرف ورودی و نحوه‌ی ارائه‌ی خروجی را کنترل می‌کنند.

در مثال‌های زیر با این‌ها روبه‌رو می‌شوید:

- `-n` یا `--null-input`

  معمولاً به برنامه‌ی `jq` یک فایل برای خواندن داده می‌شود، یا شما داده را به ورودی‌اش می‌فرستید.
  گزینه‌ی `--null-input` به شما اجازه می‌دهد بدون هیچ ورودی‌ای داده‌ی JSON تولید کنید.

- `-c` یا `--compact-output`

  `jq` به‌طور پیش‌فرض خروجی‌اش را مرتب و خوانا چاپ می‌کند.
  وقتی داده مرتب قالب‌بندی شده باشد، دیدنش برای انسان‌ها بسیار مفید است.
  اما برای ماشین‌ها این کار لازم نیست: گزینه‌ی `--compact-output` فاصله‌های قالب‌بندی را حذف می‌کند تا اندازه‌ی JSON حاصل کمینه شود.

- `-f filename` یا `--from-file filename`

  برنامه‌ی `jq` را از `filename` بخوانید، به‌جای اینکه آن را روی خط فرمان بنویسید.
  هم `sed` و هم `awk` برای همین منظور از گزینه‌ی `-f` استفاده می‌کنند.
  این را در اسکریپت‌های تست تمرین‌های عملی خواهید دید.

برای جزئیات همه‌ی گزینه‌ها، [راهنما][man-cli] را ببینید.

## فیلتر و لوله

**فیلترها** با نام **عبارت‌ها** هم شناخته می‌شوند.

یک _فیلتر_ ورودی می‌گیرد و خروجی تولید می‌کند.
مثل همان روشی که در یک پوسته‌ی یونیکس کار می‌کنید، می‌توانید _فیلترها_ را با لوله‌ی `|` به هم بپیوندید تا خروجی یک _فیلتر_ به ورودی فیلتر دیگر وصل شود.

## فیلتر همانی: `.`

این ساده‌ترین _فیلتر_ است.
ورودی‌اش را همان‌طور که هست به خروجی می‌فرستد.
برای نمونه، `jq` به‌طور پیش‌فرض خروجی را مرتب چاپ می‌کند، پس اگر JSON را به فیلتر `.` بدهید، خروجی مرتب و قالب‌بندی‌شده را مجانی به‌دست می‌آورید!

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## آرایه

این آشنایی سریعی است با کار کردن با **آرایه‌ها**.
بعداً این موضوع را با جزئیات بیشتری بررسی خواهیم کرد.

به عناصر _آرایه_ با کروشه دسترسی پیدا می‌کنید و اندیس‌گذاری از صفر شروع می‌شود.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

یک _فیلتر_ می‌تواند با قرار دادن یک عبارت میان `[` و `]` یک _آرایه_ بسازد

- با فهرستی معلوم از عناصر:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- برای گرد آوردن جریانی از عناصر: برای نمونه،
  [`range`][man-range] تابعی است که جریانی از اعداد تولید می‌کند

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  استفاده از `[]` نتایج عبارت را در یک آرایه گرد می‌آورد

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## کاما یک عملگر است

_کاما_ فقط نحوی نیست که عناصر _آرایه_ را از هم جدا می‌کند.
**کاما** یک **عملگر** است که جریان‌ها را به هم می‌پیوندد.

برای نمونه `[1, 2, 3]` یک _فیلتر_ است که با سازنده‌ی _آرایه_ یعنی `[]`، نتیجه‌ی به‌هم‌پیوستن سه عبارت `1`، `2` و `3` را گرد می‌آورد.

آیا نقطه‌ویرگول‌های `range(10; 70; 15)` را در بالا دیدید؟
چون _کاماها_ در زبان `jq` کاربرد مشخصی دارند، توابعی که چند آرگومان می‌گیرند، آرگومان‌ها را با نقطه‌ویرگول از هم جدا می‌کنند.

## شیء

آشنایی سریع با **شیءها**.

مانند بسیاری از زبان‌های برنامه‌نویسی، برای دسترسی به ویژگی‌های _شیء_ از نقطه استفاده کنید

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

از کروشه‌ها هم می‌توان برای _شیءها_ استفاده کرد، اما در آن صورت برای رشته‌های ثابت به گیومه نیاز دارید.
این یکی از روش‌های کار با کلیدهایی است که فاصله دارند.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```

می‌توانید با `{}` و جفت‌های `key: value` یک _شیء_ بسازید.
دور _کلیدهایی_ که رشته‌های «ساده» هستند به گیومه نیازی نیست.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

خروجی این است

```none
{
  "question": 54,
  "answer": 42
}
```

برای اینکه با _کلید_ مانند یک _عبارت_ رفتار شود، باید آن را داخل پرانتز بگذارید (مورد زیر هم همان خروجی بالا را می‌دهد).

```sh
echo '[["question", "answer"], [54, 42]]' \
| jq '{(.[0][0]): .[1][0], (.[0][1]): .[1][1]}'
```

برای نمونه، برای بیرون کشیدن `id` و `name` از

## خط لوله

برای نمونه، فرض کنید `file.json` این را در خود دارد

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

بیایید طول _آرایه‌ی_ key2 را حساب کنیم:

```sh
$ jq '.key2 | length' file.json
3
```

اینجا خروجی عبارت `.key2` را به‌عنوان ورودی به [`length`][man-length] _لوله می‌کنیم_، که همان‌طور که انتظار می‌رود تعداد عناصر آرایه را خروجی می‌دهد.

<!-- prettier-ignore -->
~~~~exercism/caution
این یکی از جنبه‌های `jq` است که کمی باید به آن عادت کرد:
بیشتر توابع (اما نه همه‌شان) مثل _فیلتر_ عمل می‌کنند؛ یعنی داده را به ورودی فیلتر می‌دهید، نه به‌عنوان آرگومان.
~~~~

## فیلترها می‌توانند ورودی خود را نادیده بگیرند

در این مثال، داده‌ی JSON ورودی نادیده گرفته می‌شود و هیچ تأثیری بر خروجی ندارد:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## فیلترها می‌توانند جریان‌هایی از داده تولید کنند

یک _فیلتر_ می‌تواند بیش از یک مقدار خروجی بدهد.
برای نمونه، _فیلتر_ `.[]` هر عنصر یک _آرایه_ را به‌صورت مقداری جداگانه خروجی می‌دهد:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

اگر چنین _فیلتری_ را به فیلتر دیگری لوله کنید، _فیلتر_ دوم **_برای هر مقدار_** اجرا می‌شود:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

این شبیه پیمایش ضمنی است.
وقتی این تکنیک را بفهمید، می‌بینید که _فیلترهای_ بسیار قدرتمند `jq` می‌توانند خیلی مختصر باشند.

## پرانتز

از **پرانتز** برای گروه‌بندی زیرعبارت‌ها و تعیین ترتیب عملیات استفاده می‌شود، درست مانند زبان‌های دیگر.
در `jq`، ممکن است نیاز به آن‌ها تا حدودی غیرمنتظره به نظر برسد.

برای نمونه، فرض کنید می‌خواهیم _آرایه‌ای_ با ۲ عنصر بسازیم: جذر ۹؛ و _e_ به توان ۱.
دو عبارت جداگانه این‌ها هستند: `9 | sqrt` و `1 | exp`.
انتظار داریم خروجی _آرایه‌ی_ `[3, 2.7...]` باشد.

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

چرا چیزی را که انتظار داشتیم به‌دست نیاوردیم؟ `jq` آن را این‌طور تفسیر می‌کند:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` جریانی از دو عنصر (`3` و `1`) می‌سازد که هر کدام به `exp` داده می‌شوند.

باید مطمئن شویم که `exp` فقط یک عدد را به‌عنوان ورودی می‌گیرد.
به بیان دیگر، باید تضمین کنیم که لوله پیش از کاما ارزیابی می‌شود.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## نوع

از [راهنما][man-types]

> jq از همان مجموعه‌ی انواع داده پشتیبانی می‌کند که JSON پشتیبانی می‌کند: اعداد، رشته‌ها، مقادیر منطقی، آرایه‌ها، شیءها (که در زبان JSON همان هش‌هایی با کلیدهای صرفاً رشته‌ای هستند) و «null».

در تمرین‌های بعدی درباره‌ی این‌ها بیشتر یاد خواهید گرفت.

## فضای سفید

فضای سفید در `jq` معنادار نیست.
از فاصله، تب و خط جدید هرطور که مناسب می‌دانید برای قالب‌بندی کدتان استفاده کنید.
ما از هیچ راهنمای سبکی که برای `jq` وجود داشته باشد آگاه نیستیم.

## مقادیر تغییرناپذیر

مقدارها در `jq` _تغییرناپذیر_ هستند.
فیلترهایی که یک مقدار را تغییر می‌دهند، مقدار جدیدی تولید می‌کنند.
این یعنی `jq` متغیر سراسری ندارد؛ باید عادت کنید که حالت را از یک فیلتر به فیلتر دیگر بفرستید.

## «درستی»

مقدارهای `false` و `null` به‌عنوان «غلط» در نظر گرفته می‌شوند. هر مقدار دیگری
(از جمله عدد صفر و رشته/آرایه/شیء خالی) «درست» است.

## تابع و عملگر

بدون اینکه خیلی عمیق شویم (توابع موضوع تمرینی دیگر خواهند بود)، در ادامه چند تابع درونی مفید را می‌بینید:

- [`length`][man-length]

  با گرفتن یک آرایه به‌عنوان ورودی، تعداد عناصر آرایه را خروجی می‌دهد.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- [`+`][man-plus]

  این عملگر بسته به نوع عملوندهایش کارهای متفاوتی انجام می‌دهد:
  اعداد را جمع می‌کند،
  رشته‌ها را به هم می‌چسباند،
  آرایه‌ها را به هم می‌پیوندد،
  و شیءها را ادغام می‌کند.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  [`add`][man-add] تابعی است که یک آرایه می‌گیرد و موردی را برمی‌گرداند که همه‌ی عناصرش با قواعد `+` به هم جمع شده‌اند.
  `[1, 2, 3] | add` خروجی `6` را می‌دهد.

- [`map`][man-map]

  با گرفتن یک آرایه به‌عنوان ورودی و یک فیلتر به‌عنوان آرگومان، آرایه‌ای را خروجی می‌دهد که فیلتر روی هر عنصرش اعمال شده است

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- [`select`][man-select]

  با گرفتن _مقداری_ ورودی و یک فیلتر به‌عنوان آرگومان:
  - اگر فیلتر اعمال‌شده بر آرگومان به یک مقدار _«درست»_ برسد، ورودی را بدون تغییر خروجی می‌دهد
  - در غیر این صورت، _هیچ چیز_ خروجی نمی‌دهد (نه مقدار `null`، بلکه واقعاً هیچ خروجی‌ای)

  برای نمونه، با گرفتن چند عدد، آن‌هایی که بر ۳ بخش‌پذیرند را انتخاب کنید

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  به یاد بیاورید که `range` یک _جریان_ از اعداد خروجی می‌دهد.
  `select` برای هر عدد یک بار فراخوانی می‌شود.
  فقط اعدادی که از عبارت «عبور می‌کنند» خروجی داده می‌شوند.

  اغلب لازم است عناصری از یک آرایه را انتخاب کنید.
  برای این کار چند روش وجود دارد.

  با ورودی `["Anne", "Bob", "Cathy", "Dave"]`، نام‌هایی با طول ۴ را انتخاب کنید.
  - از `map` و `select` با هم استفاده کنید

    ```jq
    map(select(length == 4))
    ```

  - آرایه را به عناصر جدا از هم بشکنید، روی آن جریان `select` بزنید و نتایج را گرد آورید

    ```jq
    [ .[] | select(length == 4) ]
    ```
