# پیوست دستورالعمل

## ثبات

| ثبات    | کاربرد    | نوع      | توضیح                                              |
| ------- | --------- | -------- | -------------------------------------------------- |
| `$a0`   | ورودی     | عدد صحیح | عدد                                                |
| `$v0`   | خروجی     | «منطقی»  | عدد آرمسترانگ است (`0` = `false`، `1` = `true`)     |
| `$t0-9` | موقت      | هر نوع   | برای ذخیره‌سازی موقت استفاده می‌شود                  |
