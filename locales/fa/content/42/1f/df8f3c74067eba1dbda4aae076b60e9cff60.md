# تکرارگر

پیمایش یک آرایه با شمارنده، پیش از آنکه کار اصلی آغاز شود، چهار خط مقدمه‌چینی لازم دارد:

```sather
   i ::= 0;
   loop
      until!(i >= counts.size);
      total := total + counts[i];
      i := i + 1;
   end;
```

شمارنده، شرط پایان و گام، هیچ‌کدام ربطی به جمع‌زدن عددها ندارند. یک **«تکرارگر»** هر سه‌ی این کارها را انجام می‌دهد.

```sather
   loop
      total := total + counts.elt!;
   end;
```

`elt!` هر بار یک عنصر تحویل می‌دهد و وقتی عنصری باقی نماند، حلقه را پایان می‌دهد. بدون شمارنده، بدون هیچ جای اشتباهی، و بدون هیچ راهی برای بیرون‌زدن از انتهای آرایه.

## علامت تعجب

`!` یک تکرارگر را مشخص می‌کند. تا حالا با سه مورد از آن‌ها روبه‌رو شده‌اید، یعنی `until!`، `while!` و `break!`، و همه‌شان از یک قاعده پیروی می‌کنند: **یک تکرارگر را فقط می‌توان داخل یک حلقه فراخوانی کرد.** نوشتن `counts.elt!` بیرون از حلقه خطاست.

از تکرارگری که داخل حلقه فراخوانی می‌شود، هر بار یک مقدار خواسته می‌شود. وقتی مقداری برایش باقی نمانده باشد، حلقه بی‌درنگ پایان می‌یابد، در هر جایی از بدنه که فراخوانی رخ داده باشد.

## دو مورد برای شروع

`elt!` عنصرهای یک آرایه یا یک رشته را به ترتیب می‌دهد.

```sather
   loop
      #OUT + names.elt! + "\n";
   end;
```

`upto!` می‌شمارد. `1.upto!(5)` اعداد ۱، ۲، ۳، ۴، ۵ را می‌دهد و بعد حلقه را پایان می‌دهد.

```sather
   loop
      total := total + 1.upto!(5);
   end;
```

هر دو روال‌های معمولی‌ای هستند که فقط اتفاقی به `!` ختم می‌شوند، بنابراین هر دو را با یک نقطه فراخوانی می‌کنید، روی یک آرایه یا روی یک عدد.

## نگه‌داشتن پاسخ

حلقه خودبه‌خود پایان می‌یابد، بنابراین هر نتیجه‌ای که داخل آن به دست می‌آید باید در متغیری نگه داشته شود که **بیرون** اعلان شده باشد؛ وگرنه با پایان یافتن حلقه، آن نتیجه هم از بین می‌رود.

```sather
   total ::= 0;             -- outside
   loop
      total := total + counts.elt!;
   end;
   return total;
```
