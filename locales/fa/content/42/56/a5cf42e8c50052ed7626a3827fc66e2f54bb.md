# مقدمه

## مقادیر پیش‌فرض پارامتر

[«مقادیر پیش‌فرض پارامتر»][default-parameter-values] را می‌توان برای هر یک از پارامترهای یک تابع تعیین کرد؛ به این صورت که در فهرست پارامترها، بعد از حاشیه‌نویسی نوع پارامتر، مقداری به آن پارامتر نسبت می‌دهید. وقتی مقدار پیش‌فرضی برای یک پارامتر مشخص شده باشد، هر کس تابع را فراخوانی می‌کند می‌تواند آن پارامتر را هنگام فراخوانی حذف کند و به‌جای آن، مقدار پیش‌فرض به کار می‌رود.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## پارامترهای چندمقداری

[«پارامترهای چندمقداری»][variadic-parameters] به یک تابع اجازه می‌دهند برای یک پارامتر واحد، صفر یا چند مقدار از یک نوع مشخص را بپذیرد.
برای تعریف یک پارامتر چندمقداری، سه نقطه (`...`) را به انتهای حاشیه‌نویسی نوع آن پارامتر اضافه می‌کنید.

در بدنه‌ی تابع، Swift این مقادیر را به‌صورت یک آرایه از نوع مشخص‌شده در دسترس قرار می‌دهد:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
اگر تابعی بعد از یک پارامتر چندمقداری، پارامترهای دیگری هم داشته باشد، نخستین پارامتری که پس از پارامتر چندمقداری می‌آید **باید** برچسب آرگومان صریح داشته باشد تا Swift بداند فهرست آرگومان‌های چندمقداری کجا تمام می‌شود.
~~~~


## پارامترهای ورودی-خروجی

در بدنه‌ی یک تابع، پارامترها ثابت در نظر گرفته می‌شوند، نه متغیر؛ تلاش برای تغییر مقدار یک پارامتر، خطای زمان کامپایل ایجاد می‌کند.
اگر تابعی بخواهد مقدار یک پارامتر را تغییر دهد، باید از [«_پارامتر ورودی-خروجی_»][in-out-parameters] استفاده کند تا این تغییرپذیری را صریح کند.

برای استفاده از پارامترهای ورودی-خروجی، برنامه‌نویس باید به سه نکته توجه کند:

1. تعریف تابع باید پارامترهای ورودی-خروجی را به‌صراحت مشخص کند؛ به این صورت که کلیدواژه‌ی `inout` را بین `:` و نام نوع، در حاشیه‌نویسی نوع پارامتر بنویسید.
2. مقداری که به پارامتر ورودی-خروجی فرستاده می‌شود باید به‌صورت متغیر تعریف شده باشد، نه ثابت. به همین ترتیب، نمی‌تواند یک لیترال باشد.
3. در فراخوانی تابع باید پیش از نام متغیر یک `&` بیاید تا به‌صراحت به‌عنوان قابل‌تغییر علامت‌گذاری شود.

وقتی این کار انجام شود، تابع یک رونوشت داخلی از پارامتر ورودی-خروجی می‌سازد، آن را طبق دستورهای بدنه‌ی تابع تغییر می‌دهد و سپس هنگام بازگشت تابع، مقدار تغییر‌یافته را دوباره در متغیری که فرستاده شده بود می‌نویسد.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
چند قاعده‌ی اضافی هم هست که باید درباره‌ی پارامترهای ورودی-خروجی بدانید.

۱  داخل تابعی که پارامتر ورودی-خروجی دارد، اجازه ندارید به متغیری که به‌عنوان پارامتر ورودی-خروجی فرستاده شده ارجاع دهید.
2. همان متغیر را نمی‌توان در یک تابع، به‌عنوان چند پارامتر ورودی-خروجی مختلف فرستاد.
   برای مثال، `inoutFunc(&mutVar, &mutVar)` خطای کامپایلر ایجاد می‌کند.
~~~~

## توابع تودرتو

در Swift می‌توانید [توابعی را داخل توابع دیگر][nested-functions] تعریف کنید.
به این‌ها **توابع تودرتو** می‌گویند.

معمولاً از توابع تودرتو به‌عنوان توابع کمکی خصوصی استفاده می‌شود که کارهای مشخصی را برای تابع دربرگیرنده انجام می‌دهند، بدون آنکه فضای نام بیرونی را شلوغ کنند:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

توابع تودرتو مثل توابع عادی رفتار می‌کنند، اما فقط در بدنه‌ی تابع دربرگیرنده قابل مشاهده هستند.
