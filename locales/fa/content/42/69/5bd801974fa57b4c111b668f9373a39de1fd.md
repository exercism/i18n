# Tests

هر تمرین testهای واحد و یک دستور ساخت با Make را در اختیار شما می‌گذارد.
پیاده‌سازی به عهده‌ی شماست.

هر فایل test قرار است به پیاده‌سازی شما لینک شود و یک فایل اجرایی کنسولی بسازد که testها را اجرا می‌کند.
اجرای فایل اجرایی test برای هر test شکست‌خورده پیام‌هایی چاپ می‌کند و وقتی testها شکست بخورند، یک کد خروجی ناصفر گزارش می‌دهد.

برای انجام یک تمرین:
* ساخت اولیه را با Make ایجاد کنید
* برای هر test واحد:
  * خط `TEST_IGNORE()` را حذف کنید.
  * خطاهای کامپایل را برطرف کنید تا test شکست بخورد.
  * فقط به‌اندازه‌ی لازم پیاده‌سازی کنید تا test موفق شود.
  * پیاده‌سازی خود را بازآرایی کنید تا خوانایی را بالا ببرید، تکرار را کم کنید و موارد دیگر را بهبود بخشید.
