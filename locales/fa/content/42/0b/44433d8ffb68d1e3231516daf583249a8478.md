# درباره

«لیترال‌ها» مقادیر ثابتی هستند که مستقیماً در کد به کار می‌روند.
این مقادیر در زمان اجرا به هیچ محاسبه‌ای نیاز ندارند.
آن‌ها به شکل‌های گوناگونی وجود دارند تا انواع مختلف داده را به‌شکل کارآمد نمایش دهند.
رایج‌ترین لیترال‌ها ماهیت عددی دارند، اما عملگرهای لیترالی هم برای انواع تاریخ، زمان و رشته وجود دارد.
مفهومی بعدی نشان می‌دهد که چگونه می‌توان از عملگرهای لیترال تعریف‌شده توسط کاربر استفاده کرد.

## لیترال‌های عددی

لیترال‌های عددی شامل نمایش‌های ده‌دهی، هشت‌هشتی، شانزده‌شانزدهی و دودویی هستند.
این مبانی پیش‌تر در [مفهوم اعداد][numbers-concept] بررسی شده است.

کامپایلر همه‌ی نمایش‌هایی مانند `23`، `0x50f7ba11` و `0xba5eba11` را به‌عنوان `int` درک می‌کند.
نوع کلی `int` علامت‌دار است و ([بسته به کامپایلر و سیستم][in-depth-integers]) اغلب بازه‌ای از `-2'147'483'648` تا `2'147'483'647` دارد.
این بازه در بیشتر مواقع کافی است و لازم نیست نگران نوع مشخص آن باشید.

برخی موارد کاربرد به بازه‌های بزرگ‌تر یا مصرف حافظه‌ی بسیار کمِ برنامه‌ها نیاز دارند.
برای اینکه صریح باشید، می‌توانید نوع عدد صحیح مشخص را مستقیماً همراه با لیترال عددی بنویسید.

وقتی به اعداد منفی نیازی نیست، اما بازه‌ی بیشتر مورد نظر است، از پسوند `u` یا `U` برای اعداد صحیح _بدون علامت_ استفاده می‌شود.
برای بازه‌های بزرگ‌تر می‌توان از `L` یا حتی `LL` برای نوع‌های `long` و `long long` استفاده کرد.

~~~~exercism/caution
استفاده از `l` کوچک مجاز است، اما به‌راحتی با عدد `1` اشتباه گرفته می‌شود و به همین دلیل توصیه نمی‌شود.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

اعداد ممیز شناور معمولاً هنگام کامپایل به‌صورت `double` در نظر گرفته می‌شوند.
این حالت پیش‌فرض خوبی است و موارد کاربرد با نوع محدودتر `float` کمتر از مثال بدون علامت بالا پیش می‌آید.

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## لیترال‌های کاراکتر و رشته

مفاهیم دیگر پیش‌تر از لیترال‌های کاراکتر با گیومه‌ی تک مانند `'}'` یا `'@'` استفاده کرده‌اند.

در C++ نوع `char` به ۱۲۸ [کد کاراکتر ASCII][ascii-code] اول محدود است.
برای استفاده از چند کاراکتر ASCII یا کاراکترهای ASCII توسعه‌یافته مانند `‰` یا حتی کاراکترهای یونیکد مانند `麗` و `ẞ`، به نوع‌های دیگری نیاز است.
در مفهوم پیشین، لیترال‌های رشته با _گیومه‌ی دوتایی_ معرفی شدند: `"一体どういう意味ですか。C++です"`.
نوع واقعی این عبارت ژاپنی `const char (&)[46]` است، یعنی یک رشته‌ی سبک C.

استفاده از لیترال‌های رشته به‌طور پیش‌فرض فعال نیست.
برای استفاده از لیترال _string_ یعنی `""s` یا لیترال _string-view_ یعنی `""sv`، کاربر باید با استفاده از فضای‌نام مربوطه، استفاده از آن‌ها را مشخص کند:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

می‌توان _string_view_ را مرجعی به یک رشته‌ی ثابت در نظر گرفت.
