# درباره

یک [دستور `switch`][switch] به شما امکان می‌دهد یک مقدار را با چندین مقدار ممکن مقایسه کنید.
با آن می‌توانید کدی مختصرتر از زمانی بنویسید که از چندین دستور `else-if` استفاده می‌کنید.
یک دستور `switch` با کلیدواژه‌ی `switch` شروع می‌شود و پس از آن مقداری می‌آید که باید مقایسه شود.
سپس می‌توانید با کلیدواژه‌ی `case` حالت‌ها را تعریف کنید و پس از آن مقداری می‌آید که باید با آن مقایسه شود.
از کلیدواژه‌ی `default` برای تعریف حالت پیش‌فرض استفاده می‌شود، یعنی زمانی که هیچ‌یک از حالت‌ها مطابقت نداشته باشند.
دستورهای `switch` هم مانند دستورهای `else-if` فقط بلوک کدی را اجرا می‌کنند که به اولین حالت مطابق وابسته است.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

مثال زیر را در نظر بگیرید:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

در عوض، می‌توان این را این‌طور نوشت:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
