# درباره

وقتی در Gleam روی یک مقدار «تطبیق الگو» انجام می‌دهیم، باید مطمئن شویم که الگوها با همه‌ی مقادیر ممکن آن نوع مطابقت می‌کنند، در غیر این صورت code کامپایل نمی‌شود.

این تابع باید رد شود، چون حالتی را که در آن لیست خالی است مدیریت نکرده است:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

بیشتر اوقات در برنامه‌های Gleam می‌خواهیم همه‌ی حالت‌های ممکن را مدیریت کنیم، اما در بعضی برنامه‌ها مثل نمونه‌های اولیه و اسکریپت‌های سریع شاید بخواهیم فقط روی مسیر موفقیت تمرکز کنیم و برای حالت‌های دیگر code ننویسیم. اینجاست که `let assert` در Gleam به کار می‌آید.

با `let assert` یک الگو می‌تواند فقط با برخی از مقادیر ممکن یک نوع مطابقت داشته باشد و اگر الگو با مقداری مطابقت نکند، برنامه کرش می‌کند. با `let assert` می‌توانیم تابع بالا را این‌گونه بنویسیم:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

کتابخانه‌های Gleam هرگز نباید از `let assert` استفاده کنند، چون می‌توانند باعث کرش برنامه شوند؛ در عوض باید از نوع `Result` استفاده کنند و بگذارند توسعه‌دهنده‌ی برنامه خودش تصمیم بگیرد که خطاها را چگونه مدیریت کند.
