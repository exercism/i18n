# دستورالعمل‌ها

در این تمرین می‌خواهید یک `TreasureChest` عمومی (جادویی!) بنویسید تا مقداری گنج در آن ذخیره کنید.

## 1. نوع `TreasureChest` را تعریف کنید

یک نوع پارامتری `TreasureChest{T}` با دو فیلد تعریف کنید.

- یک فیلد `password` از نوع `String` که برای ذخیره‌ی رمز صندوق گنج استفاده می‌شود.
- یک فیلد `treasure` از نوع `T` که برای ذخیره‌ی گنج استفاده می‌شود.
این مقدار عمومی است تا گنج بتواند هر نوعی باشد.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. تابع `get_treasure()` را تعریف کنید

این تابع باید دو آرگومان بگیرد.

- یک `String` (برای امتحان کردن رمز)
- یک نوع `TreasureChest`

این تابع باید رمز واردشده را با `password` موجود در `TreasureChest` بررسی کند.

- اگر رمزها مطابقت داشتند، گنج را برگردانید.
- اگر رمزها مطابقت نداشتند، `nothing` را برگردانید.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. تابع `multiply_treasure()` را تعریف کنید

این تابع باید دو آرگومان بگیرد.

- یک ضریب عدد صحیح `n`.
- یک نوع `TreasureChest{T}`.

این تابع باید یک `TreasureChest{Vector{T}}` جدید برگرداند، با:
- همان رمز اصلی
- گنج ضرب‌شده به صورت یک `Vector{T}` با طول `n`، و گنج اصلی که `n` بار تکرار شده است.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
