# مقدمه

تمام کدهای Common Lisp از S-Expression (عبارت نمادین، Symbolic Expression) ساخته شده‌اند. به آن‌ها برای کوتاهی sexpr می‌گویند. هر sexpr یا یک atom است یا یک cons. وقتی S-Expression‌ها ارزیابی می‌شوند، به‌طور خودکار مقداری را برمی‌گردانند که جای آن عبارت را می‌گیرد. وقتی توابع خودتان را می‌نویسید (با استفاده از `defun`)، آخرین مقدار در بدنه‌ی `defun` به‌طور خودکار برگردانده می‌شود:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
