# دستورالعمل‌ها

گروه زهی شما یک اجرای موسیقی دارد و کسی باید برنامه‌ی کنسرت را بنویسد.

هر پنج کار در کلاس `PROGRAMME_NOTES` قرار می‌گیرند.

## 1. نام قطعه و آهنگسازش را بنویسید

اول نام قطعه را بنویسید، بعد ` by ` و بعد نام آهنگساز را.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. اندازه‌گیری یک خط

چاپگر باید بداند طول یک خط چقدر است.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. چند حرف اول

با گرفتن یک عنوان و یک عدد، همان تعداد حرف را از ابتدای عنوان برگردانید.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. چند حرف آخر

همین کار، ولی این بار از انتها بشمارید.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. کوتاه کردن یک عنوان بلند

عنوان‌هایی که جا نمی‌شوند تا شش حرف اولشان کوتاه می‌شوند و بعد از آن‌ها سه نقطه می‌آید.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
