# دستورالعمل‌ها

شما در مرکز هنرهای محلی داوطلب هستید، جایی که قرار است یک موزاییک بلند از کاشی‌های سرامیکی بالای ورودی اصلی نصب شود. تیم طراحی کار را **ردیف به ردیف** چیده است: هر ردیف آرایه‌ای از رنگ کاشی‌ها است و کل موزاییک آرایه‌ای از ردیف‌ها.

همان‌طور که داوطلبان کاشی‌ها را می‌برند، جای می‌گذارند و جابه‌جا می‌کنند، شما «واژه»های کوچک و بازاستفاده‌پذیری می‌نویسید تا بخش‌هایی از طرح را بسازید، با هم ترکیب کنید و جست‌وجو کنید.

## 1. نوار تک‌کاشی

`tile-strip` را طوری تعریف کنید که یک رنگ بگیرد و ردیفی تک‌عنصری برگرداند که فقط همان رنگ را در خود دارد.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. ردیفی از سه کاشی

`row-of-three` را طوری تعریف کنید که سه رنگ را از پشته بردارد و ردیفی سه‌عنصری برگرداند.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. ترکیب ردیف‌ها در یک فهرست مسطح از کاشی‌ها

تیم طراحی باید جمع رنگ‌ها را در همه‌ی ردیف‌های موزاییک بررسی کند. `combine-rows` را طوری تعریف کنید که آرایه‌ای از ردیف‌ها بگیرد و یک دنباله‌ی واحد شامل همه‌ی کاشی‌ها به ترتیب برگرداند.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. آینه‌ای کردن یک ردیف

برای پنل‌های متقارن، تیم ردیف را آینه‌ای می‌کند و بعد نسخه‌ی آن را در سمت مقابل قرار می‌دهد. `mirror-row` را طوری تعریف کنید که ردیف را با ترتیب معکوس برگرداند.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. این رنگ کجای ردیف است؟

`tile-position` را طوری تعریف کنید که یک ردیف و یک رنگ بگیرد و اندیس (از ۰ شروع می‌شود) نخستین کاشی با آن رنگ در ردیف را برگرداند. اگر رنگ وجود نداشته باشد، `f` را برگردانید.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. آیا این ردیف آن رنگ را دارد؟

`has-colour?` را طوری تعریف کنید که یک ردیف و یک رنگ بگیرد و اگر آن رنگ جایی در ردیف ظاهر شود `t` و در غیر این صورت `f` را برگرداند.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
