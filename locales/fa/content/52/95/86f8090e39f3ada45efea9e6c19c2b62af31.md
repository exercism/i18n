# شرط‌ها

روبی چیزی به نام عبارت‌های کنترل جریان دارد. این عبارت‌ها نحوه‌ی اجرای برنامه را کنترل می‌کنند و مقداری «درست‌نما» یا «غلط‌نما» می‌گیرند.
عملگرهایی هم وجود دارند که با آن‌ها می‌توان مقدارهای درست‌نما یا غلط‌نما ساخت؛ به این‌ها [عملگرهای مقایسه][comparison-operators] می‌گویند.

دو عبارت کنترلی اصلی وجود دارد که تعیین می‌کنند کدام کد اجرا شود و کدام اجرا نشود؛ به بیان دیگر، مشخص می‌کنند کدام شاخه اجرا می‌شود.

این دو عبارتند از: `if` و عبارت `unless`.

## عملگرهای مقایسه

[عملگرهای مقایسه][comparison-operators] برای مقایسه‌ی مقدارها به کار می‌روند و مقدار `true` یا `false` برمی‌گردانند.
عملگرهای زیر برای مقایسه به دو مقدار هم‌نوع نیاز دارند.
اگر مقدارها هم‌نوع نباشند، مفسر خطا می‌دهد.
در ادامه فهرستی از این عملگرها و مثالی از زمانی که مقدار `true` می‌دهند آمده است:

| عملگر | توضیح | مثال |
| ------ | --------------------- | ------- |
| <      | کوچک‌تر از             | 4 < 5   |
| <=     | کوچک‌تر یا مساوی       | 4 <= 4  |
| >      | بزرگ‌تر از             | 3 > 1   |
| >=     | بزرگ‌تر یا مساوی       | 2 >= 2  |

برخلاف عملگرهایی که گفتیم، عملگرهای تساوی و نابرابری می‌توانند هر نوع مقداری را با هم مقایسه کنند.
عملگر `==` بررسی می‌کند که آیا دو مقدار با هم برابرند یا نه و نوع مقدار را هم در نظر می‌گیرد.
عملگر `!=` هم به همین شکل کار می‌کند، اما اگر مقدارها برابر نباشند `true` و اگر برابر باشند `false` برمی‌گرداند.
در ادامه فهرستی از عملگرهای تساوی و نابرابری و مثالی از زمانی که مقدار `true` می‌دهند آمده است:

| عملگر | توضیح | مثال |
| ------ | ------------ | ------- |
| ==     | برابر        | 4 == 4  |
| !=     | نابرابر      | 5 != 4  |

## دستور `if`

دستور [`if`][if] بررسی می‌کند که آیا یک شرط مشخص «درست‌نما» است یا «غلط‌نما».
اگر شرط درست‌نما باشد، کد داخل دستور `if` اجرا می‌شود.
دستور `if` با کلیدواژه‌ی `end` پایان می‌یابد.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## دستور `unless`

دستور `unless` بسیار شبیه دستور `if` کار می‌کند، با این تفاوت که اگر شرط غلط‌نما باشد، کد داخل دستور `unless` را اجرا می‌کند.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## دستور `else`

دستور `else` می‌تواند همراه با دستور `if` به کار رود.
دستور `else` زمانی اجرا می‌شود که شاخه‌ی `if` اجرا نشده باشد.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## دستورهای `if` آبشاری

دستور `elsif` می‌تواند همراه با دستور `if` به کار رود.
دستور `elsif` زمانی اجرا می‌شود که شاخه‌ی `if` اجرا نشده باشد و شرط دستور `elsif` درست‌نما باشد.
دستورهای `elsif` را می‌توان پشت سر هم زنجیره کرد و اولین شرط درست‌نما اجرا می‌شود.
همچنین می‌توان در پایان دستور `if` یک دستور `else` آورد که در صورتی اجرا می‌شود که هیچ‌یک از دستورهای پیشین درست نبوده باشند.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
