# مقدمه

حلقه‌ها برای اجرای مکرر یک منطق به کار می‌روند.
دو نوع رایج‌تر آن `while loop` (حلقه‌ی نامعین) و `for loop` (حلقه‌ی معین یا شمارشی) هستند.
حلقه‌ی `for each` هم هست که در یکی از مفاهیم بعدی مطرح می‌شود.


## نگارش کلی

`for loop` از یک سرآیند و یک «بلوک کد» تشکیل شده است که بدنه‌ی حلقه را در بر می‌گیرد و داخل آکولاد قرار دارد.
سرآیند از ۳ جزء تشکیل شده است که با نقطه‌ویرگول `;` از هم جدا می‌شوند: دستور آغازین، شرط و عبارتی دیگر.
هر یک از این‌ها می‌تواند خالی باشد.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- جزء **مقداردهی اولیه** کدی است که فقط یک‌بار پیش از شروع حلقه اجرا می‌شود.
- جزء **شرط** باید عبارتی باشد که نتیجه‌ی آن یک «مقدار منطقی» است و تعیین می‌کند حلقه چه زمانی باید متوقف شود.
تا زمانی که نتیجه‌ی این شرط «درست» باشد، کد داخل حلقه اجرا می‌شود.
به محض این‌که نتیجه‌ی این عبارت «غلط» شود، دیگر هیچ تکرار دیگری از حلقه اجرا نمی‌شود.
- جزء **عبارت** کدی است که در پایان هر تکرار اجرا می‌شود.


`while loop` بدنه‌اش را تا زمانی اجرا می‌کند که بررسی شرط آن «درست» باشد.
قطعه‌کد زیر نشان می‌دهد چطور یک حلقه‌ی `for` را به یک حلقه‌ی `while` تبدیل کنیم.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## میان‌پرده: افزایش و کاهش

هنگام کار با حلقه‌ها، اغلب لازم است ۱ واحد به یک متغیر شمارنده اضافه یا از آن کم کنیم.
این کار آن‌قدر رایج است که عملگرهای ویژه‌ای برایش وجود دارد: `++` و `--`.

این عملگرها دو شکل پیشوندی و پسوندی دارند.
شکل پیشوندی متغیر را پیش از استفاده در دستور تغییر می‌دهد و شکل پسوندی پس از آن.
احتمالاً بیشتر اوقات شکل پیشوندی را می‌خواهید.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## حلقه‌های For: یک مثال

جزء init معمولاً یک متغیر شمارنده را آماده می‌کند، شرط بررسی می‌کند که حلقه باید ادامه یابد یا متوقف شود، و جزء post معمولاً شمارنده را در پایان هر تکرار افزایش می‌دهد.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

این حلقه اعداد `1` تا `9` را (با احتساب `9`) با هم جمع می‌کند.

## دستورهای `break` و `continue`

در داخل بدنه‌ی حلقه می‌توانید از «کلیدواژه»ی `break` استفاده کنید تا اجرای حلقه به‌طور کامل متوقف شود:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

در مقابل، کلیدواژه‌ی `continue` فقط اجرای تکرار جاری را متوقف می‌کند و با تکرار بعدی ادامه می‌دهد:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> نکته: معمولاً درک منطق حلقه آسان‌تر است وقتی استفاده از `break` و `continue` به کمترین حد برسد یا کاملاً کنار گذاشته شود.
