# ورودی

ورودی این تمرین عبارت است از:

- `target`: یک رشته (مثلاً `'stone'`) که _آرگومان چپ_ خواهد بود.
- `candidates`: فهرستی از رشته‌های جعبه‌ای (مثلاً `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) که _آرگومان راست_ خواهد بود.

«فعل» شما به این صورت فراخوانی می‌شود:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## خروجی

فعل شما باید _فهرستی_ از جعبه‌ها را برگرداند که رشته‌های آناگرامِ `target` را در خود دارند. اگر هیچ آناگرامی وجود نداشت، نتیجه باید `empty` باشد.
