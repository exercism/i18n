# مقدمه

## حلقه

از حلقه‌ها برای اجرای مکرر بخشی از منطق استفاده می‌شود.
دو نوع رایج‌ترین آن‌ها `while loop` (تکرار نامعین) و `for loop` (تکرار معین یا شمارشی) هستند.
حلقه‌ی `for each` هم وجود دارد که در مفهوم بعدی به آن می‌پردازیم.

### نحوه‌ی نگارش کلی

`for loop` از یک سرآیند و یک بلوک کد تشکیل می‌شود که بدنه‌ی حلقه را در آکولادها در بر می‌گیرد.
سرآیند از ۳ بخش تشکیل می‌شود که با نقطه‌ویرگول `;` از هم جدا می‌شوند: دستور اولیه، شرط و یک عبارت دیگر.
هر کدام از این‌ها می‌تواند خالی باشد.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- بخش **init_statement** کدی است که فقط یک بار، پیش از شروع حلقه، اجرا می‌شود.
- بخش **condition** باید عبارتی باشد که به یک `boolean` ارزیابی می‌شود و تعیین می‌کند حلقه چه زمانی باید متوقف شود.
  کد داخل حلقه تا زمانی که این شرط به `true` ارزیابی شود، اجرا خواهد شد.
  به‌محض اینکه این عبارت به `false` ارزیابی شود، دیگر هیچ تکرار دیگری از حلقه اجرا نمی‌شود.
- بخش **expression** کدی است که در پایان هر تکرار اجرا می‌شود.

`while loop` تا زمانی بدنه‌اش را اجرا می‌کند که بررسی **condition** آن `true` باشد.
قطعه‌کد زیر نشان می‌دهد چگونه یک `for` را به یک `while loop` تبدیل کنید.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### میان‌پرده: افزایش و کاهش

هنگام کار با حلقه‌ها، اغلب لازم است به یک متغیر شمارنده که تعداد تکرارها را دنبال می‌کند، ۱ افزوده یا از آن ۱ کم شود.
این کار آن‌قدر رایج است که برای عمل‌های افزایش/کاهش، عملگرهای ویژه‌ای وجود دارد: `++` و `--`.

این عملگرها دو شکل **prefix** و **postfix** دارند.
شکل prefix متغیر را پیش از استفاده در دستور تغییر می‌دهد و شکل postfix آن را پس از آن.
احتمالاً در بیشتر مواقع شکل prefix را می‌خواهید.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### حلقه‌های For: یک مثال

معمولاً _init component_ یک متغیر شمارنده را مقداردهی می‌کند، _condition_ بررسی می‌کند که حلقه باید ادامه یابد یا متوقف شود، و _post component_ معمولاً شمارنده را در پایان هر تکرار افزایش می‌دهد.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

این حلقه اعداد از `1` تا `9` را با هم جمع می‌کند (شامل خود `9`).

### break و continue

داخل بدنه‌ی حلقه، می‌توانید از کلیدواژه‌ی `break` استفاده کنید تا اجرای حلقه را کاملاً متوقف کنید:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

در مقابل، کلیدواژه‌ی `continue` فقط اجرای تکرار جاری را متوقف می‌کند و با تکرار بعدی ادامه می‌دهد:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
وقتی استفاده از `break` و `continue` به کمترین حد رسیده باشد یا کاملاً کنار گذاشته شود، معمولاً درک منطق حلقه آسان‌تر است.
هر دو کلیدواژه بخش‌هایی از کد را رد می‌کنند و اغلب دنبال کردن کد را دشوارتر می‌کنند.
~~~~
