# دستورالعمل‌ها

در این تمرین کدی می‌نویسید که برای کارکنان کارخانه برچسب اسم چاپ می‌کند.
هر کارمند یک شناسه، یک اسم و یک اسم بخش دارد.
برچسب کارکنان به این شکل قالب‌بندی می‌شود: `"[id] - name - DEPARTMENT"`.

## 1. چاپ برچسب برای یک کارمند

تابع `print_name_badge` را پیاده‌سازی کنید. این تابع یک شناسه، یک اسم و یک بخش می‌گیرد.
باید برچسب را برگرداند، با اسم بخش به‌صورت حروف بزرگ.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. چاپ برچسب برای کارمند جدید

به دلیل یک ایراد در سیستم کامپیوتری، کارکنان جدید گاهی وقتی کار در کارخانه را شروع می‌کنند هنوز شناسه ندارند.
چون برچسب الزامی است، یک برچسب موقت بدون پیشوند شناسه دریافت می‌کنند.

تابع `print_name_badge` را گسترش دهید. وقتی شناسه وجود ندارد، باید برچسبی بدون آن چاپ کند.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. چاپ برچسب برای صاحب کارخانه

حتی صاحب کارخانه هم باید همیشه برچسب داشته باشد.
اما صاحب کارخانه بخش ندارد و هرگز هم نخواهد داشت: او برتر از همه‌ی بخش‌هاست.
در این حالت، برچسب باید به‌جای اسم بخش، `"OWNER"` را چاپ کند.

تابع `print_name_badge` را گسترش دهید. وقتی بخش `NULL` است، فرض کنید برچسب به صاحب شرکت تعلق دارد.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

در نظر بگیرید که ممکن است صاحب کارخانه خودش کارمند جدید هم باشد.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. محاسبه‌ی مجموع حقوق کارکنانی که شناسه ندارند

برای یک سنجش تقریبی از اینکه شناسه‌ها چقدر خوب صادر می‌شوند، می‌خواهید مجموع حقوق کارکنانی را ببینید که شناسه ندارند.
مقدار بالا یعنی تعداد زیادی در انتظارند، یا مشکل گریبان افراد ارشد را هم گرفته است: هر دو بد است.

تابع `salaries_no_id` را پیاده‌سازی کنید که یک بردار از شناسه‌ها و یک بردار متناظر از حقوق می‌گیرد و مجموع حقوق افرادی را برمی‌گرداند که هنوز شناسه ندارند.
هر دو بردار هم‌طول هستند.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_به‌عنوان یک نکته‌ی آموزشی اضافه که آزمون نمی‌شود:_ اگر هیچ کارمندی بدون شناسه نباشد، آن «بردار خالی» که جمع می‌زنید چیست؟
