## نحوه‌ی استفاده

### ساخت

`npx blueprint build` یا `yarn blueprint build`

### تست

`npx blueprint test` یا `yarn blueprint test`

### استقرار یا اجرای اسکریپت دیگری

`npx blueprint run` یا `yarn blueprint run`

### افزودن قرارداد جدید

`npx blueprint create ContractName` یا `yarn blueprint create ContractName`
