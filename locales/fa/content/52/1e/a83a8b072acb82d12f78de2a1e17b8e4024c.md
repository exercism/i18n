# تست‌ها

تست‌ها را با `exercism test` یا `eutest` اجرا کنید. به‌صورت پیش‌فرض همه‌ی تست‌ها اجرا می‌شوند.

## نادیده گرفتن تست‌ها

یک روش خوب برای شروع این است که همه‌ی تست‌ها را به‌جز اولین تست در `t_<exercise>.e` به‌صورت کامنت دربیاورید.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

یکی‌یکی پیش بروید و هر وقت تست فعلی موفق شد، تست بعدی را از کامنت دربیاورید. وقتی همه‌ی تست‌ها موفق شدند، تمرین را کامل کرده‌اید.
