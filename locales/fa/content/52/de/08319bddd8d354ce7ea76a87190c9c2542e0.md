# درباره

JavaScript از `true` و `false` برای نمایش دو مقدار درستیِ منطق استفاده می‌کند.

در JavaScript، برای هر یک از سه عملیات منطقی (AND، OR و NOT) یک عملگر متناظر وجود دارد: `&&`، `||` و `!`.
به‌طور کلی، قواعدی درباره‌ی ترتیب این عملیات وجود دارد. در این مورد، ابتدا `!` (نقیض) اعمال می‌شود، سپس `&&` (عطف) و بعد `||` (فصل).

می‌توان این ترتیب عملیات میان عملگرها را با استفاده از عملگری با اولویت بالاتر تغییر داد: `( )` که «عملگر گروه‌بندی» نامیده می‌شود یا به‌سادگی «پرانتز».
در واقع، عملگر `( )` بالاترین اولویت را میان همه‌ی عملگرهای JavaScript دارد.
اطلاعات بیشتر درباره‌ی اولویت عملگرها را [اینجا][here] می‌توانید پیدا کنید.
