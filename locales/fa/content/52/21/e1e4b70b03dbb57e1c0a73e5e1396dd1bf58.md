# درباره

نوع `Option` سازوکار زبان F# برای برخورد با مقادیری است که ممکن است وجود داشته باشند یا نداشته باشند.
این نوع جایگزینی امن از نظر نوع برای استفاده از `null` فراهم می‌کند؛ همان کاری که در زبان‌های دیگر برای برخورد با چنین مقادیری رایج است.
از این نوع در بسیاری از توابع کتابخانه‌ی استاندارد F# استفاده می‌شود، بنابراین درک آن برای استفاده‌ی مؤثر از کتابخانه‌ی استاندارد F# ضروری است.

## مزایای استفاده از نوع `Option`

* __امنیت در زمان کامپایل__: با صریح کردن وجود یا نبود یک مقدار در سیستم نوع، کامپایلر می‌تواند مطمئن شود که حالت «بدون مقدار» را مدیریت می‌کنید و این‌گونه از دسته‌ی بزرگی از باگ‌ها که ممکن است با مقادیر `null` رخ دهد جلوگیری می‌کند.

* __امنیت در زمان اجرا__: F# به جای استفاده از `null`، از `None` برای نشان دادن نبود مقدار استفاده می‌کند و همین امکان بروز `NullReferenceException` را غیرممکن می‌سازد.

* __الزام به مدیریت صریح__: سیستم نوع ایجاب می‌کند که کد هر دو حالت `Some value` و `None` را به‌صراحت مدیریت کند و همین کد شما را مقاوم‌تر و قابل‌پیش‌بینی‌تر می‌کند.

* __سازگاری با تطبیق الگو__: مقادیر `Option` به‌شکل یکپارچه با اصطلاح تطبیق الگو در F# کار می‌کنند و راهی تمیز و امن فراهم می‌کنند تا در صورت وجود مقدار آن را تجزیه و مدیریت کنید، یا در غیر این صورت کار دیگری انجام دهید.

## نحوه‌ی استفاده

نوع `Option` یک نوع ژنریک است (یعنی نوعی زیرین دارد).  
مقادیر `Option` یا `Some value` هستند که نماینده‌ی یک مقدار مشخص‌اند، یا `None` که نماینده‌ی نبود مقدار است.

تابع زیر نشان می‌دهد که چگونه یک مقدار `Option` بسازید:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` صورت نحوی پسوندی معادل `Option<T>` است؛ این دو شکل نگارش را می‌توان به‌جای هم به کار برد.
اما بر اساس راهنمای سبک F#، برای نوع‌های `Option` نگارش پسوندی ترجیح داده می‌شود (به [بخش قالب‌بندی نوع‌ها و حاشیه‌نویسی‌های نوع در راهنمای سبک F#](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions) نگاه کنید). 
~~~~

یک کاربرد معمول `Option` توابع جست‌وجو هستند. 
برای مثال، تابع `List.tryFind` وقتی عنصر در فهرست باشد `Some index` را برمی‌گرداند (که در آن `index` موقعیت مقدار موردنظر در فهرست است)، و وقتی عنصر در فهرست نباشد `None` را برمی‌گرداند.

## خواندن محتوای یک مقدار Option

روش اصطلاحی خواندن یک مقدار `Option` استفاده از تطبیق الگو است، همان‌طور که در مثال زیر نشان داده شده است:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## باز کردن مقادیر `Option` با مقادیر پیش‌فرض

مقادیر `Option` را می‌توان با ارائه‌ی مقادیر پیش‌فرض به کمک تابع `Option.defaultValue` «باز کرد» (به نوع درون خود تبدیل کرد). 
این کار به‌ویژه زمانی مفید است که بخواهید مطمئن شوید مقدار `None` نیست.
برای مثال:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## توابع بیشتر در ماژول `Option`

ماژول `Option` همچنین توابعی دارد که متناظر توابع موجود برای فهرست‌ها، آرایه‌ها، دنباله‌ها و دیگر نوع‌های مجموعه‌اند، مانند `Option.map`، `Option.iter`، `Option.forall` و `Option.count`. 
این توابع امکان می‌دهند با مقادیر `Option` مانند مجموعه‌ای با صفر یا یک عنصر رفتار شود.
