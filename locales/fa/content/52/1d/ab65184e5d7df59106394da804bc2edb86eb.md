# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به یک فریلنسر کمک می‌کند با یک مدیر پروژه صحبت کند.
وظیفه‌ی شما ارائه‌ی چند ابزار کمکی است تا نرخ‌های روزانه و ماهانه را سریع محاسبه کنید، به‌صورت اختیاری با تخفیف مشخصی که داده می‌شود.

ابتدا چند قاعده بین فریلنسر و مدیر پروژه تعیین می‌کنیم:

- نرخ روزانه ۸ برابر نرخ ساعتی است.
- یک ماه ۲۲ روز قابل صورت‌حساب دارد.

گاهی فریلنسر پیشنهاد می‌دهد روی نرخ روزانه‌اش تخفیف اعمال کند (برای مثال برای وفادارترین مشتریان یا مشتریان غیرانتفاعی).

تخفیف‌ها به صورت اعداد اعشاری مدل‌سازی می‌شوند که درصد را نشان می‌دهند، برای مثال `25.0` (۲۵٪).

## 1. محاسبه‌ی نرخ روزانه بر اساس نرخ ساعتی

تابعی به نام `dailyRateFrom` پیاده‌سازی کنید تا نرخ روزانه را بر اساس نرخ ساعتی که به عنوان پارامتر داده می‌شود محاسبه کند.
قرارداد تعیین می‌کند که یک روز ۸ ساعت قابل صورت‌حساب دارد.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

نرخ روزانه‌ی برگردانده‌شده باید از نوع `Double` باشد.

## 2. محاسبه‌ی نرخ ماهانه بر اساس نرخ ساعتی و تخفیف

تابع `monthlyRateFrom` را پیاده‌سازی کنید تا نرخ ماهانه‌ی تخفیف‌خورده را محاسبه کند.
این تابع دو پارامتر می‌گیرد: نرخ ساعتی و تخفیف به درصد.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

نرخ ماهانه‌ی برگردانده‌شده باید به نزدیک‌ترین عدد صحیح به بالا گرد شود (سقف گرفته شود).

## 3. محاسبه‌ی تعداد روزهای کاری کامل بر اساس بودجه، نرخ ساعتی و تخفیف

تابع `workdaysIn` را پیاده‌سازی کنید که بودجه، نرخ ساعتی و تخفیف را می‌گیرد و محاسبه می‌کند که این مبلغ چند روز کاری کامل را پوشش می‌دهد.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
تعداد روزهای برگردانده‌شده باید به پایین (با گرفتن کف) تا نزدیک‌ترین عدد صحیح گرد شود.
