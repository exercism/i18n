# افزوده‌ی دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | ورودی     | آدرس | عناصر آرایه‌ی یک |
| `$a1`    | ورودی     | عدد صحیح | اندازه‌ی آرایه‌ی یک، بر حسب کلمه |
| `$a2`    | ورودی     | آدرس | عناصر آرایه‌ی دو |
| `$a3`    | ورودی     | عدد صحیح | اندازه‌ی آرایه‌ی دو، بر حسب کلمه |
| `$v0`    | خروجی     | عدد صحیح | `0` = برابر، `1` = نابرابر، `2` = زیرلیست، `3` = فوق‌لیست |
| `$t0-9`  | موقت | هر نوع | برای ذخیره‌سازی موقت استفاده می‌شود |
