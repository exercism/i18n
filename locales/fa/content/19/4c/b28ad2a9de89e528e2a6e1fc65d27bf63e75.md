# Test Runner

Test Runner نرم‌افزاری است که تست‌های یک تمرین را روی کد دانش‌آموز اجرا می‌کند.

Test Runnerها دو مزیت برای ما دارند:

1. کدنویسی در مرورگر را ممکن می‌کنند تا دانش‌آموز بتواند روی یک راه‌حل بارها کار کند و ببیند آیا تست‌ها موفق می‌شوند یا شکست می‌خورند.
2. به ما امکان می‌دهند به منتورها اطلاعاتی بدهیم که کد دانش‌آموز «کار می‌کند» یا نه.

## ساخت Test Runner

اگر علاقه‌مند به ساخت Test Runner هستید، برای اطلاعات بیشتر [مستندات Test Runner](/docs/building/tooling/test-runners) را ببینید.
