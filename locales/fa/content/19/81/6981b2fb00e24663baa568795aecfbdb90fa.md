# مقدمه

«وراثت» روشی است برای ایجاد رابطه‌ی والد-فرزند بین کلاس‌ها.
کلاس فرزند (که گاهی _زیرکلاس_ نامیده می‌شود) به رفتار و داده‌های تعریف‌شده در کلاس والد (که گاهی _ابرکلاس_ نامیده می‌شود) دسترسی دارد.

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

کلیدواژه‌ی `extends` در اعلان کلاس فرزند، از طریق [زنجیره‌ی پروتوتایپ][prototype-chain] رابطه‌ای با کلاس والد برقرار می‌کند.

اشیایی که سازنده‌ی فرزند می‌سازد، پروتوتایپ کلاس والد را در زنجیره‌ی پروتوتایپ خود دارند و از این طریق به هر متد یا داده‌ای که کلاس والد تعریف کرده است دسترسی پیدا می‌کنند.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
