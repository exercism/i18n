# دستورالعمل‌ها

در این تمرین، خط‌های لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با این قالب: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ مختلف وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه وظیفه دارید که هرکدام یک خط لاگ می‌گیرند و از شما می‌خواهند کاری با آن انجام دهید. راه‌های زیادی برای حل این وظیفه‌ها وجود دارد؛ از میان مثال‌های بالا روش‌های دلخواهتان را انتخاب کنید و ببینید به چه نتیجه‌ای می‌رسید.

## 1. استخراج پیام از یک خط لاگ

متد `LogLineParser#message` را طوری پیاده‌سازی کنید که پیام یک خط لاگ را برگرداند:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

هر فاصله‌ی سفید ابتدایی یا انتهایی باید حذف شود:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. استخراج سطح لاگ از یک خط لاگ

متد `LogLineParser#log_level` را طوری پیاده‌سازی کنید که سطح لاگ یک خط لاگ را برگرداند؛ این سطح باید با حروف کوچک برگردانده شود:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. قالب‌بندی مجدد یک خط لاگ

متد `LogLineParser#reformat` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند، به این صورت که اول پیام و بعد از آن سطح لاگ را داخل پرانتز قرار می‌دهد:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
