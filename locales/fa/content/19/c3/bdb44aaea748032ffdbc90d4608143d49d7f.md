# درباره

در Swift، یک `String` مجموعه‌ای مرتب از مقادیر `Character` است که متنی خوانا برای انسان را نشان می‌دهد. رشته‌های Swift به‌طور کامل از نویسه‌های یونیکد و ایموجی پشتیبانی می‌کنند.

برای ساختن یک رشته، از یک لیترال رشته‌ای استفاده می‌کنید و متن را داخل علامت نقل‌قول دوگانه (`"`) قرار می‌دهید.
نویسه‌های ویژه با دنباله‌های فرار نوشته می‌شوند. برای مثال، `\n` یک خط جدید را نشان می‌دهد و `\"` نشان‌دهنده‌ی علامت نقل‌قول دوگانه‌ی فرار درون یک لیترال رشته‌ای است.

یک رشته‌ی خالی به‌صورت یک جفت علامت نقل‌قول دوگانه نوشته می‌شود که هیچ محتوایی بین آن‌ها نیست (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
