# مقدمه

[Zen of Python][zen-of-python] معتقد است باید «یک روش _واضح_» برای انجام هر کار در Python وجود داشته باشد.
برای Python ۳.۶+، [**درونیابی رشته‌ای تحت‌اللفظی**][string-interpolation] ([**`f-string`ها**][f-string]) معمولاً همان روش واضح و ترجیحی برای قالب‌بندی رشته‌ها است:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

با این حال، با توجه به تاریخچه‌ی طولانی Python و کاربردهای گوناگونش، تعجب‌آور نیست که **سه** روش رایج دیگر هم برای قالب‌بندی رشته‌ها در Python وجود دارد:

1. [`str.format()`][str-format] چندمنظوره، بسیار قدرتمند و با هر دو [`gnu gettext`][gettext] و بیشتر نسخه‌های Python سازگار است.
2. اگر سادگی، ایمنی یا بین‌المللی‌سازی سنگین چیزی است که به آن نیاز دارید، می‌توان از [`string.Template()`][string-template] برای کاهش خطرها هنگام کار با ورودی‌ها و برای بسته‌بندی رشته‌های ترجمه استفاده کرد.
3. عملگر `%` برای کدهای جدید عموماً منسوخ به شمار می‌رود، هرچند همچنان در Python مدرن کار می‌کند.
  عمدتاً باید برای سازگاری با کدبیس‌های قدیمی‌تر به کار برود.
  قالب‌بندی با `%` می‌تواند به مشکل‌هایی در نمایش نویسه‌های غیر ASCII و Unicode منجر شود و در مقایسه با روش‌های دیگر خطاهای بیشتری دارد و کارکرد کمتری ارائه می‌دهد.
  اگر قصد استفاده از آن را دارید، برای جزئیات پشتیبانی، توزیع Python خاص خودتان را بررسی کنید.
