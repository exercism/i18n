# مقدمه

## آرایه‌ی بیتی

کار کردن با داده‌های دودویی می‌تواند دشوار باشد، بنابراین Gleam یک نوع `BitArray` و نحوه‌ی نگارشی همراه آن فراهم می‌کند تا داده‌های دودویی را بسازید و الگو را روی آن‌ها تطبیق دهید.

«لیترال»های آرایه‌ی بیتی با نحوه‌ی نگارش `<<>>` تعریف می‌شوند. وقتی یک لیترال آرایه‌ی بیتی تعریف می‌کنید، آن را به‌صورت بخش‌هایی می‌سازید. هر «بخش» یک مقدار و یک «مشخصه» دارد که با `:` از هم جدا می‌شوند. مشخصه تعیین می‌کند که برای رمزگذاری مقدار از چند بیت استفاده می‌شود و می‌توان آن را کاملاً حذف کرد؛ در این صورت به‌طور پیش‌فرض یک عدد صحیح ۸ بیتی در نظر گرفته می‌شود.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

نوشتن نوع به‌صورت `:1` شکل کوتاه‌شده‌ی `:size(1)` است. اگر اندازه‌ی بیت از یک متغیر بیاید، باید شکل بلندتر را بنویسید.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### دودویی

وقتی لیترال‌های عدد صحیح دودویی می‌نویسیم، می‌توانیم آن‌ها را مستقیماً با مبنای ۲ بنویسیم، به این صورت که `0b` را به ابتدای لیترال اضافه کنیم. توجه کنید که هنگام چاپ در تست‌ها یا در برنامه‌تان، به‌صورت اعداد دهدهی نمایش داده می‌شوند.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### بریدن

اگر مقدار یک بخش از ظرفیت نوع آن بخش فراتر رود، از سمت چپ بریده می‌شود.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### افزودن به ابتدا و انتها

می‌توانید با استفاده از نحوه‌ی نگارش آرایه‌ی بیتی، هم به ابتدای یک آرایه‌ی بیتی موجود چیزی بیفزایید و هم به انتهای آن. برای آرایه‌ی بیتی موجود باید از مشخصه‌ی `:bits` استفاده کنید.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### به هم چسباندن

می‌توانیم آرایه‌های بیتی ذخیره‌شده در متغیرها را با نحوه‌ی نگارش آرایه‌ی بیتی به هم بچسبانیم. هنگام چسباندن دو آرایه‌ی بیتی با اندازه‌های متغیر باید از مشخصه‌ی `:bits` استفاده کنید.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### تطبیق الگو

می‌توان الگو را طوری تطبیق داد که مقادیری از آرایه‌ی بیتی به دست آید. باید تعداد بیت‌های هر بخشی را که می‌خواهید بگیرید بدانید، با یک استثنا: مشخصه‌ی `:bits` را می‌توان برای تطبیق الگو روی آرایه‌ی بیتی با اندازه‌ی نامعلوم به کار برد، اما این کار فقط برای آخرین بخش امکان‌پذیر است.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### بررسی آرایه‌ی بیتی

~~~~exercism/note
ممکن است آرایه‌های بیتی در قالبی متفاوت از قالبی که برای ساختن‌شان به کار رفته چاپ شوند. این موضوع هنگام یادگیری آرایه‌های بیتی اغلب باعث سردرگمی می‌شود.
~~~~

به‌طور پیش‌فرض، آرایه‌های بیتی در بخش‌های ۸ بیتی (یک بایت) نمایش داده می‌شوند، حتی اگر آن‌ها را با بخش‌هایی با اندازه‌ی متفاوت ساخته باشید.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

اگر آرایه‌ی بیتی‌ای بسازید که نماینده‌ی یک رشته‌ی رمزگذاری‌شده‌ی UTF-8 قابل چاپ باشد، ممکن است توسط توابعی مانند `io.debug` به‌صورت یک رشته نمایش داده شود. این موضوع به یک جزئیات پیاده‌سازی مربوط می‌شود: اینکه Gleam رشته‌ها را در درون خود چگونه نمایش می‌دهد.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
