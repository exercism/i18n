# مقدمه

توابع بازگشتی توابعی هستند که خودشان را فراخوانی می‌کنند.

یک تابع بازگشتی باید حداقل یک _حالت پایه_ و حداقل یک _حالت بازگشتی_ داشته باشد.

_حالت پایه_ بدون این‌که تابع را دوباره فراخوانی کند، مقداری را برمی‌گرداند. _حالت بازگشتی_ تابع را دوباره فراخوانی می‌کند و ورودی را طوری تغییر می‌دهد که در جایی با حالت پایه مطابقت کند.

بسیار پیش می‌آید که هر حالت در بند تابع خودش نوشته شود.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
