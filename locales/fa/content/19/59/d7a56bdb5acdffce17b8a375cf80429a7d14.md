# مقدمه

اصلاح‌کننده‌ی `const` را می‌توان روی هر فیلدی به کار برد (و عموماً هم باید به کار رود) که مقدارش در زمان کامپایل معلوم است و در طول عمر برنامه تغییر نمی‌کند.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

اصلاح‌کننده‌ی `readonly` را می‌توان روی هر فیلدی به کار برد (و عموماً هم باید به کار رود) که نمی‌توان آن را `const` کرد، به شرطی که مقدارش در طول عمر برنامه تغییر نکند و یا با یک مقداردهی اولیه‌ی درون‌خطی تعیین شود یا هنگام نمونه‌سازی (توسط سازنده یا متدی که سازنده فراخوانی می‌کند).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
