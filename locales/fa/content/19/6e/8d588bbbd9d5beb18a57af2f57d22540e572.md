# پیوست دستورالعمل‌ها

## ثبات‌ها

| ثبات | کاربرد | نوع | توضیح |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | ورودی     | آدرس | رشته‌ی اول که با `null` پایان می‌یابد  |
| `$a1`    | ورودی     | آدرس | رشته‌ی دوم که با `null` پایان می‌یابد |
| `$v0`    | خروجی     | عدد صحیح | فاصله‌ی همینگ                |
| `$t0-9`  | موقت | هر نوع     | برای ذخیره‌سازی موقت           |
