# تست‌ها

برای اجرای تست‌ها از داخل پوشه‌ی تمرین، این دستور را اجرا کنید:

```sh
odin test .
```

وقتی در حال تست هستید، Odin می‌تواند کد شما را «vet» کند: می‌تواند مواردی مانند `import`ها و متغیرهای استفاده‌نشده را پیدا کند. تست‌هایتان را با این دستور اجرا کنید:

```sh
odin test . -vet
```

برای گزینه‌های بیشتر، `odin test -help` را ببینید.
