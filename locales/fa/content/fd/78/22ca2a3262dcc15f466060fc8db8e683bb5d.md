# مقدمه

Swift مجموعه‌ای از دستورها دارد که می‌توان با آن‌ها جریان عادی کنترل حلقه‌ها را تغییر داد.
به این دستورها «دستورهای انتقال کنترل» می‌گویند.
شما `return` را قبلاً دیده‌اید؛ در این مفهوم با موارد دیگری آشنا می‌شوید که شامل `continue`، `break` و «برچسب‌ها» هستند.
در این مفهوم به `fallthrough` نمی‌پردازیم، اما می‌توانید درباره‌ی آن در [کتاب Swift][fallthrough] بخوانید.

## Continue

گاهی لازم است زودتر به تکرار بعدی حلقه بپرید، بدون این‌که بقیه‌ی دستورهای تکرار جاری حلقه را کامل کنید.
برای این کار می‌توان از کلیدواژه‌ی `continue` استفاده کرد.
وقتی `continue` اجرا می‌شود، حلقه به بررسی بعدی می‌رود تا ببیند آیا می‌توان تکرار بعدی حلقه را اجرا کرد؛ یعنی `while` در حلقه‌های While و Repeat-While، یا بررسی این‌که آیا در حلقه‌های For-In عنصر دیگری در دنباله هست یا نه.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

از `break` برای خروج زودهنگام از یک حلقه استفاده می‌شود.
وقتی `break` اجرا می‌شود، حلقه بی‌درنگ پایان می‌یابد و برنامه با اولین دستور پس از حلقه ادامه می‌دهد.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## برچسب

وقتی حلقه‌ها تودرتو هستند، گاهی ممکن است بخواهید با `break` یا `continue` از حلقه‌های بیرونی خارج شوید یا آن‌ها را از نو شروع کنید؛ منظور حلقه‌های بیرونی‌ای است که حلقه‌ی دربردارنده‌ی `break` یا `continue` را در خود دارند.
در چنین مواردی می‌توان از برچسب‌ها استفاده کرد تا مشخص شود کدام حلقه باید پایان یابد یا دوباره شروع شود.
می‌توان یک حلقه را با قرار دادن اسمی که پس از آن دو نقطه می‌آید، پیش از `while`، `repeat` یا `for`ی که حلقه را آغاز می‌کند، برچسب‌گذاری کرد.

برای دیدن تأثیر استفاده از برچسب‌ها به این شکل، به حلقه‌ی زیر توجه کنید.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
