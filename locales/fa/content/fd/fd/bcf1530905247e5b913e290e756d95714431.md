# مقدمه

«هیپ» مجموعه‌ای است که همیشه کوچک‌ترین عنصرش را می‌داند و به شما امکان می‌دهد آن را به‌سرعت حذف کنید. این ساختار، پیاده‌سازی طبیعی یک «صف اولویت» است. هیپ در واژگان [`heaps`][heaps] قرار دارد.

`<min-heap>` یک هیپ خالی می‌سازد که کوچک‌ترین کلیدش اول بیرون می‌آید؛
`<max-heap>` تصویر آینه‌ای آن است. هر عنصر یک «مقدار» است که زیر یک «کلید» ذخیره می‌شود و کلید همان اولویت است:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

هیپ «تغییرپذیر» است. `heap-push` آن را در جای خود تغییر می‌دهد. `heap-peek`
مقدار و کلید جلویی را بدون حذف آن برمی‌گرداند، `heap-pop` آن را حذف می‌کند و
برمی‌گرداند و `heap-pop-all` هیپ را به یک «لیست انجمنی» از جفت‌های `{ key value }`
به ترتیب اولویت تخلیه می‌کند:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
