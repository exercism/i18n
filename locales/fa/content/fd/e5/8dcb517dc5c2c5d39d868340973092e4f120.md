# مقدمه

در Go، یک «ثابت» مقدار ساده و تغییرناپذیری است که با «کلیدواژه‌ی» `const` به یک اسم اختصاص داده می‌شود:

```go
const myWebsite = "Exercism"
```

این ثابت‌ها بدون نوع هستند، اما وقتی نوعی لازم باشد، بر اساس نحوه‌ی نگارششان یک نوع پیش‌فرض به آن‌ها داده می‌شود؛ مثلاً وقتی به یک متد پاس داده می‌شوند.
می‌توان با اضافه کردن صریح یک نوع، ثابت‌های نوع‌دار ساخت:

```go
const myWebsite string = "Exercism"
```

Go مثل بعضی زبان‌های دیگر «enum» ندارد، اما یک شناسه‌ی از پیش تعریف‌شده به اسم `iota` دارد که برای ساختن ثابت‌های شمارشی به کار می‌رود.
ثابت‌ها در یک بلوک به‌طور ضمنی تکرار می‌شوند:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
