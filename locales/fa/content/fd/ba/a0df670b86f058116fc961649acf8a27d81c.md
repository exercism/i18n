# دستورالعمل‌ها

در این تمرین، خطوط لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است با این قالب: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ متفاوت وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه کار دارید که هرکدام یک خط لاگ می‌گیرد و از شما می‌خواهد کاری با آن انجام دهید.

## 1. گرفتن پیام از یک خط لاگ

تابع `message()` را پیاده‌سازی کنید تا پیام یک خط لاگ را برگرداند:

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

فاصله‌های سفید ابتدایی و انتهایی باید حذف شوند:

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. گرفتن سطح لاگ از یک خط لاگ

تابع `logLevel()` را پیاده‌سازی کنید تا سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. قالب‌بندی دوباره‌ی یک خط لاگ

تابع `reformat()` را پیاده‌سازی کنید که خط لاگ را دوباره قالب‌بندی می‌کند: ابتدا پیام را می‌آورد و بعد از آن، سطح لاگ را داخل پرانتز قرار می‌دهد:

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
