# مقدمه

اگر می‌خواهید چیزی با Raspberry Pi بسازید، احتمالاً از _«مقاومت»_ استفاده می‌کنید.
مانند تمرین‌های پیشین `Resistor Color Duo` و `Resistor Color Trio`، نوارهای رنگی مقاومت را به برچسب‌هایی خوانا برای انسان ترجمه می‌کنید.

- هر مقاومت یک مقدار مقاومت دارد.
- مقاومت‌ها کوچک‌اند، آن‌قدر کوچک که اگر مقدار مقاومت را روی‌شان چاپ کنید، خواندنش دشوار خواهد بود.
  برای حل این مشکل، تولیدکنندگان نوارهایی با کد رنگی روی مقاومت‌ها چاپ می‌کنند تا مقدار مقاومتشان را نشان دهند.
- هر نوار به‌عنوان یک رقم از یک عدد عمل می‌کند.
  برای مثال، اگر نواری قهوه‌ای (با مقدار ۱) و پس از آن نواری سبز (با مقدار ۵) چاپ می‌کردند، به عدد ۱۵ ترجمه می‌شد.
