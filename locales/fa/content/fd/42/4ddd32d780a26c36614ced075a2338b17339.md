# دستورالعمل‌ها

شما طرفدار پروپاقرص [کانال یوتیوب Numberphile](https://www.youtube.com/watch?v=PeUbRXnbmms) هستید و تازه ویدیوی جالبی درباره‌ی _دنباله‌ی اعداد لوکاس_ دیده‌اید. می‌خواهید این دنباله را با Elixir بسازید.

هنگام طراحی تابع خود، می‌خواهید از _ارزیابی تنبل_ استفاده کنید تا بتوانید هر تعداد عدد که می‌خواهید تولید کنید، اما فقط اگر به آن‌ها نیاز داشته باشید. پس تصمیم می‌گیرید از یک استریم استفاده کنید.

## 1. گرفتن آرگومان‌های نامعتبر

یک guard clause اضافه کنید تا اگر برای تولید دنباله مقداری به کار رود که عدد صحیح نباشد یا عدد صحیحی کوچک‌تر از ۱ باشد، خطا ایجاد شود. انجام این کار در گام اول، از بروز bugهای بازگشت بی‌نهایت در گام‌های بعدی جلوگیری می‌کند.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. تولید حالت‌های پایه

می‌دانید که این دنباله دو عدد آغازین دارد که از قاعده‌ی یکسانی پیروی نمی‌کنند. دو بند حالت پایه بنویسید تا این اعداد را برگردانند:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. ساخت حالت تعمیم‌یافته

برای هر دنباله‌ای بلندتر از ۲، می‌دانید که باید دو عدد قبلی را جمع کنید تا عدد بعدی به دست بیاید و به همین ترتیب ادامه دهید. حالت تعمیم‌یافته را بنویسید.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
