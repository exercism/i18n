## سفارشی‌سازی و ایجاد استثناها

گاهی لازم است در کد خود استثناها را هم [سفارشی‌سازی](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) کنید و هم [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) کنید. وقتی این کار را می‌کنید، باید همیشه یک **پیام خطای معنادار** بنویسید تا نشان دهد منبع خطا چیست. این کار کد شما را خواناتر می‌کند و کمک زیادی به Debug می‌کند.

می‌توان استثناهای سفارشی را از طریق کلاس‌های استثنای جدیدی ساخت (برای جزئیات بیشتر [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) را ببینید) که معمولاً زیرکلاس‌های [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception) هستند.

در موقعیت‌هایی که می‌دانید منبع خطا مشتق از نوع خاصی از استثنا خواهد بود، می‌توانید انتخاب کنید که از یکی از [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) زیر کلاس _Exception_ ارث‌بری کنید. هنگام ایجاد خطا هم باید پیام معناداری بگنجانید.

این تمرین به‌طور خاص می‌خواهد که یک _استثنای سفارشی_ بسازید که هرگاه پشته به‌اندازه‌ی کافی پر نشده باشد، [ایجاد](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/«پرتاب» شود. تست‌ها تنها در صورتی قبول می‌شوند که استثنای مناسبی را سفارشی‌سازی کنید، آن استثنا را `raise` کنید و پیام‌های خطای مناسب را بگنجانید.


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

علاوه بر این، این تمرین می‌خواهد که چند `built-in exceptions` را همراه با پیام خطا ایجاد کنید.
برای ایجاد یک `built-in exception` همراه با پیام، پیام را به عنوان آرگومان نوع `exception` بنویسید:

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
