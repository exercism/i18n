# مقدمه

مفیدترین واژه‌های دنباله یک *quotation* را به عنوان یکی از ورودی‌های خود می‌گیرند و از آن برای هدایت عملیات استفاده می‌کنند:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (همچنین در `sequences`) یک quotation را روی دنباله نگاشت می‌کند و نتایج را در یک گذر جمع می‌کند. همین الگو `sort-by` (در [`sorting`][sorting]) و `minimum-by` / `maximum-by` (در `sequences`) را نیز پیش می‌برد.

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
