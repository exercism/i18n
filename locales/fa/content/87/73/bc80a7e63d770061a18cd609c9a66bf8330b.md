# پیوست دستورالعمل‌ها

## واژه‌ها

یک تاپل `rat` با اسلات‌های `numerator` و `denominator` تعریف کنید.
`<rat>` باید آرگومان‌هایش را به ساده‌ترین شکل کاهش دهد، به‌طوری که
علامت روی صورت باشد (یعنی مخرج همیشه مثبت است).

- `<rat> ( numerator denominator -- rat )`، یک عدد گویای
  ساده‌شده می‌سازد.
- `>rat ( pair -- rat )`، یک `rat` را از `{ numerator denominator }` می‌سازد.
- `rat>pair ( rat -- pair )`، `{ numerator denominator }` را برمی‌گرداند.
- `r+ ( a b -- c )`، `r- ( a b -- c )`، `r* ( a b -- c )`،
  `r/ ( a b -- c )`، محاسبات روی دو عدد گویا.
- `r-abs ( a -- |a| )`، قدر مطلق.
- `r^ ( a n -- a^n )`، یک عدد گویا را به توان یک عدد صحیح
  می‌رساند (نماهای منفی مجازند).
- `real^r ( x a -- y )`، یک عدد حقیقی را به توان یک نمای
  گویا می‌رساند و یک عدد اعشاری برمی‌گرداند.

جنریک‌های `MATH:` در Factor (یعنی `+`، `-`، `*` و `/`) فقط روی
سلسله‌مراتب ریاضی داخلی دیسپچ می‌کنند، بنابراین این تمرین به‌جای
متدهایی روی آن جنریک‌ها، از نام‌های اختصاصی برای واژه‌ها استفاده می‌کند.
