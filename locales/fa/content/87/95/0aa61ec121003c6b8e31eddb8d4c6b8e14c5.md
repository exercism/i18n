# مقدمه

## ارث‌بری

در C#، می‌توان یک سلسله‌مراتب «کلاس» را با «ارث‌بری» تعریف کرد؛ ارث‌بری به کلاس مشتق (`Car`) اجازه می‌دهد رفتار و داده‌ی کلاس والدش (`Vehicle`) را به ارث ببرد. اگر کلاس والدی مشخص نشود، کلاس از کلاس `object` ارث می‌برد.

کلاس‌های والد به سه روش می‌توانند قابلیت‌هایی در اختیار کلاس‌های مشتق بگذارند:

- تعریف یک متد معمولی.
- تعریف یک متد `virtual` که مانند یک متد معمولی است، با این تفاوت که کلاس‌های مشتق می‌توانند آن را تغییر دهند.
- تعریف یک متد `abstract` که متدی بدون پیاده‌سازی است و کلاس‌های مشتق باید آن را پیاده‌سازی کنند. کلاسی که متدهای `abstract` دارد باید خودش هم با `abstract` علامت‌گذاری شود. از کلاس‌های انتزاعی نمی‌توان نمونه ساخت.

اصلاح‌کننده‌ی دسترسی `protected` اجازه می‌دهد به عضوی از کلاس والد در یک کلاس مشتق دسترسی داشته باشیم، اما دسترسی از کلاس‌های دیگر را مسدود می‌کند.

کلاس‌های مشتق می‌توانند از طریق کلیدواژه‌ی `base` به اعضای کلاس والد دسترسی داشته باشند.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

سازنده‌ی یک کلاس مشتق به‌طور خودکار، پیش از اجرای منطق سازنده‌ی خودش، سازنده‌ی کلاس والد را فراخوانی می‌کند. می‌توان با کلیدواژه‌ی `base` آرگومان‌هایی به سازنده‌ی کلاس والد فرستاد:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

وقتی بیش از یک کلاس از یک کلاس والد مشتق شود، آن دو (یا چند) کلاس اغلب نسخه‌های متفاوتی از یک متد کلاس والد را پیاده‌سازی می‌کنند. این یک اصل بسیار مهم است که به آن «چندریختی» می‌گویند. برای نمونه، در گونه‌ای متفاوت از مثال بالا نشان می‌دهیم که کد استفاده‌کننده از `Vehicle` چگونه بسته به این‌که چه نوع وسیله‌ی نقلیه‌ای نمونه‌سازی شده است، رفتار خود را تغییر می‌دهد.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
