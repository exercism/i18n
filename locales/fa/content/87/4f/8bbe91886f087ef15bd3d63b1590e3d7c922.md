# درباره‌ی رشته

[`string`][ref-string] در Kotlin دنباله‌ای تغییرناپذیر از کاراکترهای Unicode است.

[`Immutable`][wiki-immutable] یعنی هر عملیاتی روی یک رشته باید رشته‌ی جدیدی برگرداند: رشته‌ی اصلی هرگز نمی‌تواند تغییر کند.

[`Unicode`][wiki-unicode] یعنی می‌توان بیشتر نظام‌های نوشتاری جهان را نمایش داد، اما (برخلاف زبان‌های قدیمی‌تری مثل C) هیچ تناظر یک‌به‌یک میان کاراکترها و بایت‌ها وجود ندارد.
در ادامه در مفهوم [کاراکتر][concept-chars] بیشتر به این موضوع می‌پردازیم.

رشته با علامت نقل‌قول دوتایی `" "` احاطه می‌شود.

برخی کاراکترها به فرار نیاز دارند: `\\`، به‌علاوه‌ی کاراکترهای چاپ‌نشدنی معمول مثل `\t` (تب) و `\n` (خط جدید).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

رشته‌های چندخطی با ۳ علامت نقل‌قول دوتایی احاطه می‌شوند و می‌توانند متن دلخواهی داشته باشند (بدون نیاز به فرار).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

برای حذف تورفتگی مشترک خطوط از [trimIndent][trimIndent-doc] استفاده کنید.
این برای قالب‌بندی رشته مفید است:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

در عوض، [trimMargin][trimMargin-doc] به شما اجازه می‌دهد یک جداکننده مشخص کنید.
در این صورت، هر خط در `String` بعد از جداکننده آغاز می‌شود.
جداکننده به‌طور پیش‌فرض `|` است، اما می‌توانید جداکننده‌ی دیگری را به‌عنوان پارامتر مشخص کنید.
برای مثال:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

رشته‌ها را می‌توان با `+` به هم چسباند، اما بهتر است این کار را به موارد کوتاه و ساده محدود کنید.
گزینه‌های دیگری هم هست که اغلب بهترند.

## قالب‌های رشته

[`Templates`][ref-templates] به چیزی اشاره دارد که بعضی زبان‌های دیگر به آن «interpolation» می‌گویند.

اگر رشته‌ای شامل علامت دلار `$` باشد که پس از آن یک شناسه بیاید، یا شامل آکولادهایی (`{expression}`) باشد که دور یک عبارت را بگیرند، این‌ها به‌ترتیب با مقدار یا نتیجه‌ی آن عبارت جایگزین می‌شوند.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## قالب‌بندی رشته

روی پلتفرم JVM (و فقط آن)، `String.format()` قالب‌بندی دقیق‌تری از قالب‌های رشته فراهم می‌کند، با [نحوه‌ی نگارشی][web-formats] مشابه توابع [`printf`][wiki-printf] (_خیلی قدیمی!_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

~~~~exercism/advanced
Kotlin را می‌توان به چند هدف مختلف کامپایل کرد: ماشین مجازی جاوا، JavaScript، باینری‌های بومی برای Linux، Windows، Android و Apple، به‌علاوه‌ی دو گونه از WebAssembly.

عملاً می‌توان از کد یکسانی برای هرکدام استفاده کرد، اما توانایی‌های متفاوت پلتفرم‌های هدف باعث می‌شود تفاوت‌هایی در پشتیبانی از توابع کتابخانه‌ی استاندارد وجود داشته باشد.

Exercism در حال حاضر برای آزمون‌ها از JVM استفاده می‌کند.
~~~~

## توابع رشته

Kotlin [`functions`][ref-string-functions] _زیادی_ برای دستکاری رشته‌ها در اختیار می‌گذارد.

بیشتر این‌ها [`extensions functions`][ref-extensions] هستند و نه اعضای کلاس `String`، هرچند این موضوع تأثیر کمی بر نحوه‌ی استفاده‌ی ما از آن‌ها دارد.

~~~~exercism/note
صفحه‌های [مستندات][ref-string-functions] نسبتاً پیچیده‌ی Kotlin توابع الحاقی را در نمای پیش‌فرض پنهان می‌کنند.
در زمان نوشتن این متن، باارزش‌ترین محتوا در زبانه‌ای با اسم `Members & Extensions` پنهان است.
روی آن کلیک کنید تا این بخش باز شود و همه‌ی اعضا و توابع الحاقی موجود در کلاس `String` را ببینید.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

مثال زیر فقط نمونه‌ی کوچکی از موارد در دسترس را نشان می‌دهد:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## ساختن رشته

گاهی لازم است رشته‌ی بلندی مرحله‌به‌مرحله ساخته شود، مثلاً درون یک حلقه.

چسباندن رشته‌ها با `+` خیلی زود نه زیبا می‌شود و نه کارآمد: تغییرناپذیری یعنی کپی‌برداری _بسیار زیادی_ لازم است.

Kotlin روش‌های کارآمدتری برای ترکیب چند رشته دارد:

- قالب‌های رشته، که بالاتر توضیح داده شد.
- [`Chars`][ref-jointostring]، که در مفهوم [لیست][concept-lists] بررسی می‌شود.
- [`StringBuilder`][ref-stringbuilder] جاوا، که چندان Kotlin اصطلاحی به حساب نمی‌آید.
- [`buildString()`][ref-buildstring] خود Kotlin، که `StringBuilder` را در نحوه‌ی نگارشی مختصرتر و اصطلاح‌تری می‌پیچد.
منطق ساخت رشته را به‌عنوان آرگومان لامبدا می‌گیرد، که در مفهوم بعدی بررسی می‌شود.

در اصل، `StringBuilder` ساختاری شبیه لیست است، با متدهای راحت زیادی.
این‌ها نمونه‌ی کوچکی از آن‌هاست:

- [`append()`][ref-sb-append] برای افزودن به انتها.
- [`insert()`][ref-sb-insert] برای افزودن در موقعیت مشخص.
- [`deleteAt()`][ref-sb-deleteat] و [`deleteRange()`][ref-sb-deleterange] برای حذف از موقعیت‌های مشخص.
- `toString()` برای تبدیل به یک رشته‌ی معمولی در انتها: چسباندن همه‌چیز در یک عملیات واحد و کارآمد.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

مثالی از `buildString()`، با استفاده از نحوه‌ی نگارشی مفاهیم بعدی:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
