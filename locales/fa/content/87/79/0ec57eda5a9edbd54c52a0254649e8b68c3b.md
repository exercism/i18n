# پیوست دستورالعمل

## مزایا و معایب `from_quote`
این تمرین تابعی به نام `from_quote` در نوع `Time` تعریف می‌کند. این کار امکان نوشتن کدی مانند این را فراهم می‌کند:

```roc
time : Time
time = "00:01:23"
```

این کد به‌طور ضمنی `Time.from_quote("00:01:23")` را در زمان کامپایل فراخوانی می‌کند. این کار می‌تواند به‌طور بالقوه سرعت برنامه را افزایش دهد، چون نیازی نیست تجزیه را در زمان اجرا مدیریت کند، و تضمین می‌کند که مقدارهای زمانی که `from_quote` رد می‌کند، در زمان کامپایل گرفته می‌شوند، نه در زمان اجرا. علاوه بر این، کد را زیبا و خوانا می‌کند. برای مثال، این یکی از Testهای این تمرین است:

```roc
## start initiates time tracking for current lap
expect {
	result = Stopwatch.create()
		.start()?
		.advance_time("00:00:05")
		|> expect_current_lap("00:00:05")

	result.is_ok()
}
```

با این حال، ممکن است کسی که این کد را می‌خواند تصور کند که تابع `advance_time` یک `Str` می‌گیرد، در حالی که در واقع یک `Time` می‌گیرد. این می‌تواند به سردرگمی و خطا منجر شود. به همین دلیل، ممکن است قالب کمی طولانی‌تر اما صریح‌تر را ترجیح دهید: `"00:00:05".Time` که آن هم `from_quote` را در زمان کامپایل فراخوانی می‌کند.

در برنامه‌های خودتان، ممکن است ترجیح دهید به جای آن از `from_str` استفاده کنید:

```roc
Time := { ... }.{
    from_str : time_str -> Try(Time, [InvalidTime])
    from_str = |time_str| ...
}
```

همچنین می‌توانید `from_str` (یا هر تابع خالص دیگری) را در زمان کامپایل فراخوانی کنید، مانند این:

```roc
Ok(time) = Time.from_str("00:01:23")
```

توجه: قرار دادن این تعریف در سطح بالا باعث می‌شود در زمان کامپایل اجرا شود (چون تابع خالص است و ورودی‌اش در زمان کامپایل مشخص است). در داخل یک تابع، می‌توانید در زمان اجرا از `from_str` استفاده کنید.
