# دستورالعمل‌ها

شب دیگری است و در محوطه‌ی رده‌بندی آنتورپ شلوغی برپاست. شما مسئول اعزام در این شیفت هستید: واگن‌های باری ورودی باید در قالب قطارهای خروجی بازآرایی شوند، جفت‌کننده‌ها بازرسی شوند، مسیرها در تقاطع‌ها تقسیم شوند و بارهای یکسان برای صورتحساب ادغام شوند.

هر *واگن* رشته‌ای است که مشخص می‌کند چه باری حمل می‌کند: `"coal"`، `"timber"`، `"crates"` و غیره.

## 1. جفت کردن واگن‌ها به قطار

`couple` را طوری تعریف کنید که یک آرایه از واگن‌ها و یک طول `n` بگیرد و قطارهایی بدون هم‌پوشانی برگرداند که هر کدام `n` واگن دارند. اگر تعداد به‌طور مساوی تقسیم نشود، قطار آخر می‌تواند کوتاه‌تر باشد.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. نگاهی به جفت‌کننده‌ها

`peek-couplings` را طوری تعریف کنید که یک آرایه از واگن‌ها بگیرد و هر جفت مجاور را برگرداند، تا بازرس بتواند هر جفت‌کننده را بررسی کند.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. شکستن زنجیره در تقاطع‌ها

`split-at-junctions` را طوری تعریف کنید که یک آرایه از واگن‌ها و یک آرایه از `junctions` (واگن‌هایی که نقطه‌ی شکست را نشان می‌دهند) بگیرد و بخش‌های میان واگن‌های تقاطع را برگرداند. خود واگن‌های تقاطع نگه داشته نمی‌شوند.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. ادغام بارهای یکسان

`coalesce-cargo` را طوری تعریف کنید که یک آرایه از واگن‌ها بگیرد و واگن‌های *پشت‌سرهم* با بار یکسان را به‌صورت رشته‌های پیوسته گروه‌بندی کند.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
