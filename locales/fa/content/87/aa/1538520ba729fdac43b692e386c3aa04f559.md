# مقدمه

«تجزیه» روشی است برای از هم جدا کردن مقادیر ترکیبی در Rust. از آن اغلب برای استخراج فیلدها از تاپل‌ها یا ساختارها استفاده می‌شود.

برای مثال، قطعه‌ی کد زیر دو مقدار را از یک تاپل استخراج می‌کند:

```rust
let (first, second) = (1, 2);
```

مقدار `1` به متغیر `first` مقید می‌شود.
مقدار `2` به متغیر `second` مقید می‌شود.
