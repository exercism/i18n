# دستورالعمل‌ها

در این تمرین، خط‌های لاگ را پردازش می‌کنید.

هر خط لاگ رشته‌ای است به شکل زیر: `"[<LEVEL>]: <MESSAGE>"`.

سه سطح لاگ مختلف وجود دارد:

- `INFO`
- `WARNING`
- `ERROR`

سه وظیفه دارید که هر کدام یک خط لاگ می‌گیرد و از شما می‌خواهد کاری با آن انجام دهید.

## 1. دریافت پیام از یک خط لاگ

متد (`static`) `LogLine.Message()` را طوری پیاده‌سازی کنید که پیام یک خط لاگ را برگرداند:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

هر فضای خالی ابتدایی یا انتهایی باید حذف شود:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. دریافت سطح لاگ از یک خط لاگ

متد (`static`) `LogLine.LogLevel()` را طوری پیاده‌سازی کنید که سطح لاگ یک خط لاگ را برگرداند؛ این مقدار باید با حروف کوچک برگردانده شود:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. بازقالب‌بندی یک خط لاگ

متد (`static`) `LogLine.Reformat()` را پیاده‌سازی کنید که خط لاگ را بازقالب‌بندی می‌کند، به این صورت که پیام را اول قرار می‌دهد و سطح لاگ را بعد از آن در پرانتز می‌آورد:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
