# راهنما

## کلی

- می‌توان یک تابع را طوری تعریف کرد که چندین آرگومان بسته‌بندی‌شده را دریافت کند؛ برای این کار در آرگومان‌های `list` و `tuple` از پارامتر `*args` و در آرگومان‌های مبتنی بر دیکشنری یا کلیدواژه از پارامتر `**kwargs` استفاده کنید.
- برای بسته‌بندی یا باز کردن بسته‌بندی از عملگر `*` یا `**` استفاده کنید.

## 1. ساختن فهرست همه‌ی واگن‌ها

- چندین آرگومان در پارامترهای تابع را می‌توان با عملگر `*args` بسته‌بندی کرد.

## 2. اصلاح فهرست واگن‌ها

- استفاده از باز کردن بسته‌بندی با عملگر `*` به شما امکان می‌دهد دو عنصر اول یک `list` را بیرون بکشید و بقیه را دست‌نخورده نگه دارید.
- برای افزودن یک `list` دیگر به یک `list` موجود، می‌توانید از عملگر `*` استفاده کنید تا `list` را «پخش» کنید.

## 3. افزودن ایستگاه‌های جاافتاده

- استفاده از `**kwargs` به‌عنوان پارامتر تابع این امکان را می‌دهد که هر تعداد آرگومان کلیدواژه‌ای دلخواه ارسال شود.
- استفاده از `**<dict>` به‌عنوان آرگومان، یک دیکشنری را به آرگومان‌های کلیدواژه‌ای باز می‌کند.
- می‌توانید آرگومان‌های کلیدواژه‌ای را در `{}` یا `dict()` قرار دهید.
- برای بیرون کشیدن مقدارها از یک دیکشنری، می‌توانید از متد `<dict>.values()` استفاده کنید.

## 4. گسترش اطلاعات مسیریابی

- استفاده از `**<dict>` به‌عنوان آرگومان، یک دیکشنری را به آرگومان‌های کلیدواژه‌ای باز می‌کند.
- می‌توانید آرگومان‌های کلیدواژه‌ای را در `{}` یا `dict()` قرار دهید.

## 5. درست کردن انبار واگن‌ها

- از `zip(*iterators)` می‌توان برای جابه‌جا کردن سطر و ستون‌های یک `list` تودرتو استفاده کرد.
- برای بیرون کشیدن داده از تکرارگرهای زیپ‌شده، می‌توانید از یک حلقه‌ی For استفاده کنید.
- همچنین می‌توانید تکرارگرهای زیپ‌شده را با `*` باز کنید.
  `[*content] = zip(iterator_1, iterator_2)` یک `tuple` تولیدشده توسط `zip()` را به یک `list` باز می‌کند.
