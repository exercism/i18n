# مقدمه

در Gleam معمول است که «توابع مرتبه بالاتر» بنویسیم و به کار ببریم؛ یعنی توابعی که توابع دیگر را به عنوان آرگومان می‌گیرند. گاهی وقتی چند تابع مرتبه بالاتر را هم‌زمان به کار می‌برید، کد می‌تواند با چندین لایه تورفتگی سخت‌خوان شود.

برای مثال، اینجا تابعی داریم که چند تابع را فراخوانی می‌کند که `Result(Int, Nil)` برمی‌گردانند و اگر هر چهار مورد موفق باشند مقادیر را جمع می‌کند.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

عبارت‌های `use` در Gleam به ما اجازه می‌دهند این کد را بدون تورفتگی بنویسیم و اغلب خواندن آن را آسان‌تر می‌کنند.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

یک عبارت `use` همه‌ی دستورهای بعدی در بلوک را جمع می‌کند و آن را به‌عنوان آخرین آرگومان، به‌صورت یک تابع callback، به فراخوانی تابع پاس می‌دهد. متغیرهای بین کلیدواژه‌ی `use` و نماد `<-`، اسم آرگومان‌هایی هستند که به تابع callback پاس داده می‌شوند.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

تابع callback می‌تواند هر تعداد آرگومان بگیرد، یا اصلاً هیچ آرگومانی نگیرد.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

برای ساختن تابعی که بتوان آن را با یک عبارت `use` فراخوانی کرد، هیچ الزام ویژه‌ای وجود ندارد، جز اینکه تابع callback را به‌عنوان آخرین آرگومان بگیرد.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

عبارت‌های `use` در Gleam قابلیت بسیار قدرتمندی هستند که می‌توان آن‌ها را برای مسائل زیادی به کار برد، اما وقتی بیش از حد استفاده شوند می‌توانند خواندن کد را دشوار کنند. معمولاً ترجیح داده می‌شود که از نحوه‌ی نگارش عادی فراخوانی تابع استفاده کنید و فقط وقتی سراغ عبارت‌های `use` بروید که خواندن کد را آسان‌تر می‌کنند.
