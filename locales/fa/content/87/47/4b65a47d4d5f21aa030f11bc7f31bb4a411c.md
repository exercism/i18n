# راهنمایی‌ها

## 1. نوع خارجی `GbTree` را تعریف کنید

- انواع خارجی را می‌توان با نحوه‌ی نگارش `pub type TypeName(a, b, c)` تعریف کرد.

## 2. تابع `new_gb_tree` را تعریف کنید

- توابع خارجی را می‌توان با نحوه‌ی نگارش `@external(erlang, "module", "function")` تعریف کرد.
- تابع باید از `gb_trees:empty/0` استفاده کند.

## 3. تابع `insert` را تعریف کنید

- مستندات `gb_trees:insert/3` را بررسی کنید تا ترتیب درست آرگومان‌ها را تأیید کنید.
- تابع خارجی می‌تواند یک تابع خصوصی باشد که تابع `insert` آن را فراخوانی می‌کند تا ترتیب آرگومان‌ها را تغییر دهد.
- تابع باید از `gb_trees:insert/3` استفاده کند.

## 4. تابع `delete` را تعریف کنید

- مستندات `gb_trees:delete_any/2` را بررسی کنید تا ترتیب درست آرگومان‌ها را تأیید کنید.
- تابع خارجی می‌تواند یک تابع خصوصی باشد که تابع `delete` آن را فراخوانی می‌کند تا ترتیب آرگومان‌ها را تغییر دهد.
- تابع باید از `gb_trees:delete_any/2` استفاده کند.
- تابع `gb_trees:delete/2` اگر کلید پیدا نشود کرش می‌کند، بنابراین نباید از آن استفاده کرد.
