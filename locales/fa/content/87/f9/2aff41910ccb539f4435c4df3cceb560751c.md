# مقدمه

`Integer`ها هر عددی را نگه می‌دارند، هر چقدر هم بزرگ، تا محدودیت حافظه‌ی دستگاه شما؛ در حالی که `Int` متناظر با مجموعه‌ی اعداد صحیح مثبت و منفی است که می‌توانند در ۳۲ یا ۶۴ بیت بیان شوند (که حداقل از -۲^۲۹ تا ۲^۲۹ تضمین شده است).

`Float` متناظر با مجموعه‌ی اعداد حقیقی است، با محدودیت دقت کامپیوتر.
عملیاتی که روی اعداد تعریف می‌شوند معمولاً روی یکی از این دو نوع کار می‌کنند، نه روی هر دو.

توابعی که بین `Float` و `Integer` تبدیل انجام می‌دهند، از جمله `toFloat` که `Int`/`Integer` را به `Float` تبدیل می‌کند و `ceiling` که یک `Float` را به `Int` تبدیل می‌کند.

تبدیل از یک نوع صحیح (`Int` یا `Integer`) به هر نوع عددی دیگر با تابع `fromIntegral` انجام می‌شود.
نوع مقصد به‌طور خودکار استنتاج می‌شود.
برای مثال:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
