# مقدمه

یک `List` بسیار شبیه به `Array` است. اما تفاوت‌های اساسی‌ای وجود دارد که نمی‌خواهید آن‌ها را نادیده بگیرید:

1. یک لیست را نمی‌توان با کروشه ایندکس کرد، یعنی `[0]`.
2. یک لیست را نمی‌توان مقداردهی اولیه کرد.
3. هیچ «list comprehension» وجود ندارد.
4. یک لیست می‌تواند هنگام پیمایش روی عناصر، آن‌ها را آزادانه تغییر دهد.

`List` عضوی از پکیج `haxe.ds` است، بنابراین هر بار که می‌خواهید از لیست‌ها استفاده کنید، باید پکیج آن را `import` کنید:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
