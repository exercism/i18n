# مقدمه

در Factor، یک «نقل‌قول»، که همان کد داخل کروشه‌های `[ ]` است، خودش یک مقدار به حساب می‌آید، درست مثل یک عدد یا یک رشته. می‌توانید آن را در یک متغیر ذخیره کنید، در یک آرایه بگذارید، به یک تابع دیگر بدهید و بعداً آن را `call` کنید.

## `call`

`call` (که در [`kernel`][kernel] قرار دارد) یک نقل‌قول را اجرا می‌کند:

```factor
3 4 [ + ] call .
! => 7
```

وقتی یک نقل‌قول را در بافتی `call` می‌کنید که Factor نمی‌تواند اثر پشته‌ای آن را استنباط کند، باید آن اثر را صریحاً اعلام کنید:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

این کار یک بررسی در زمان اجرا کامپایل می‌کند که تأیید کند نقل‌قول واقعاً همان اثر اعلام‌شده را دارد.

## نقل‌قول‌ها در دنباله‌ها

چون نقل‌قول‌ها خودشان مقدار هستند، یک آرایه می‌تواند ترکیبی از عددها و نقل‌قول‌ها را در خود جای دهد:

```factor
{ 3 4 [ + ] }
```

به این ترتیب «یک برنامه» به یک دنباله‌ی معمولی تبدیل می‌شود و `each` روشی طبیعی برای اجرای آن می‌شود:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## برش انتهای یک دنباله

`head*` همه‌ی عناصر را به‌جز `n` عنصر آخر برمی‌گرداند؛ `last2` دو عنصر آخر را برمی‌گرداند:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

همراه با `suffix`، همین‌ها برای نوشتن یک عملیات پشته‌ای از نوع «دو عنصر بالایی را مصرف کن، یک نتیجه را روی پشته بگذار» کافی است.
