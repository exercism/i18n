# تست‌ها

پیش از آنکه بخواهید تست‌ها را اجرا کنید، مطمئن شوید که پوشه‌ی تمرین درست آماده شده است؛ برای این کار مراحل نصب، یعنی `corepack yarn install` و راه‌اندازی Editor SDK را دنبال کنید.

تست‌ها را با این دستور اجرا کنید:

```bash
$ corepack yarn test
```

مطمئن شوید که کدتان، مثل سایر کاربران، با eslint از بهترین شیوه‌ها پیروی می‌کند؛ eslint ابزاری است که روی کد شما تحلیل ایستا انجام می‌دهد. ابزارهایی مثل این، در پیدا کردن غلط‌های تایپی یا اشتباهات ساده در کدتان به شما کمک می‌کنند و در وقت‌تان صرفه‌جویی می‌کنند:

```bash
$ corepack yarn lint
```

یا هر دو را همزمان انجام دهید:

```bash
$ corepack yarn test && corepack yarn lint
```

مسیر TypeScript در Exercism سبکِ نوشتن کد را اجباری نمی‌کند؛ بنابراین در انتخاب میان نقطه‌ویرگول، تب در برابر فاصله و هر چیزی که میان این دو قرار می‌گیرد آزاد هستید.

## ساخت اولین ماژول‌تان

معمولاً تست‌ها در این مسیر، پیاده‌سازی شما را به‌صورت یک ماژول import می‌کنند: `import Bob from './bob';`. برای اینکه این کار انجام شود، باید پیاده‌سازی خود را از فایلی که تست‌ها برای ماژول شما جست‌وجو می‌کنند، یعنی `bob.ts`، export کنید:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

ما در هر تمرین استاب‌هایی آماده کرده‌ایم و این `export` را برای‌تان داخل آن گذاشته‌ایم.
