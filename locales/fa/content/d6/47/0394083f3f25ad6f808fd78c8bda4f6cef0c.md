# درباره‌ی توابع بی‌نام و بستارها

PHP امکان تعریف توابع را درون توابع دیگر فراهم می‌کند. این توابع نیازی ندارند که اسم داشته باشند، اما می‌توان آن‌ها را به متغیرها نسبت داد یا حتی مستقیماً به تابع دیگری که یک پارامتر تابعی می‌خواهد پاس داد.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

تابعی که در بالا تعریف شد و به `array_filter` پاس داده شد، یک «تابع بی‌نام» است. تابع `array_filter` از آن استفاده می‌کند تا تعیین کند آیا یک مقدار مشخص در آرایه در نتیجه‌ی `array_filter` برگردانده می‌شود یا نه. اگر تابع برای یک مقدار `true` برگرداند، آن مقدار در آرایه‌ی نتیجه قرار می‌گیرد.

از توابع بی‌نام می‌توان استفاده کرد تا از درون تابع به متغیرهایی ارجاع داد که در محدوده‌ی بیرون از تابع قرار دارند. به این پدیده می‌گویند محدوده‌ی تابع روی متغیری که در تابع به کار می‌رود «بسته» می‌شود، و اسم «بستار» هم از همین‌جا می‌آید. در برخی زبان‌ها، همه‌ی متغیرهای در محدوده به‌طور خودکار می‌توانند درون بستار استفاده شوند. در PHP، `$this` که به شیء فعلی اشاره دارد، به‌طور خودکار درون بستار مجاز است. همه‌ی متغیرهای دیگر باید صریحاً با کلیدواژه‌ی `use` ارجاع داده شوند.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

در تابع `makeAdderFunction` بالا، مقدار `$number` که پاس داده می‌شود، درون تابع بی‌نام تعریف‌شده در داخل تابع «بسته» می‌شود، و بعد همان تابع برگردانده می‌شود. بعد از آن، هر بار که آن تابع اجرا شود، مقدار `$number` را که پاس داده شده بود می‌داند. اگر این تابع را دوباره با عدد دیگری فراخوانی کنید، یک تابع کاملاً متفاوت برمی‌گرداند. این کار مقادیر یا عملکردی را که نخستین فراخوانی تابع برگردانده بود تغییر نمی‌دهد.
اگر لازم است بیش از یک متغیر را ببندید، می‌توانید آن‌ها را با کاما از هم جدا کرده و به کلیدواژه‌ی `use` اضافه کنید.

PHP همچنین یک نحوه‌ی نگارش کوتاه‌تر برای توابع دارد: `arrow functions`. این توابع باید نسبتاً ساده باشند. شکل پایه‌ای آن‌ها این است:

```php
fn(arguments) => expression
```

در این سبک از تابع، نیازی نیست از `use` استفاده کنید. این سبک به‌طور خودکار هر مقداری را در محدوده‌ی والد بسته و ثبت می‌کند. عبارت در این توابع پیکانی به‌طور خودکار برگردانده می‌شود، بدون اینکه لازم باشد از کلیدواژه‌ی `return` استفاده کنید. این کار به ما اجازه می‌دهد تابع `onlyOdds` بالا را این‌طور بازنویسی کنیم:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

تابع `makeAdderFunction` بالا را می‌توان این‌طور بازنویسی کرد:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**توجه:** اگر تابع را نتوان به‌صورت یک عبارت نوشت، نمی‌توان از نحوه‌ی نگارش کوتاه‌تر توابع پیکانی استفاده کرد.

متغیرها به‌صورت مقدار به توابع بی‌نام و بستارها پاس داده می‌شوند و درون آن‌ها نیز به همان صورت به کار می‌روند. یعنی اگر مقدار متغیر را درون تابع تغییر دهید، روی مقدار متغیر بیرون از تابع اثری نمی‌گذارد. اگر لازم است مقدار تغییر کند، می‌توانید آن را به‌صورت ارجاع پاس دهید.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

در مثال بالا، `array_walk` روی هر عنصر آرایه پیمایش می‌کند و هر مقدار را به تابعی که در فراخوانی اعلام شده می‌فرستد. جمع جاری را در `$total` نگه می‌دارد که هر مقدار اضافه‌شده به آن، قدر مطلق عدد است. همچنین شمار اعداد را هم پیگیری می‌کند. هر دو مقدار در بستار به‌صورت ارجاع به کار می‌روند، که با `&` جلوی هر متغیر در بخش `use` نشان داده شده است. یعنی تغییراتی که روی متغیرها رخ می‌دهد، پس از پایان `array_walk` هم برجا می‌ماند، تا تابع بتواند میانگین قدر مطلق اعداد آرایه را برگرداند.

توابع بی‌نام و بستارها راهی راحت فراهم می‌کنند تا تابعی تعریف کنید که شاید فقط در یک بافت مشخص به آن نیاز باشد، یا تابعی تعریف کنید که بر پایه‌ی مجموعه‌ای از پارامترها یک تابع پویا برمی‌گرداند؛ پارامترهایی که در زمانی متفاوت از زمان استفاده‌ی واقعی از تابع معلوم می‌شوند.
