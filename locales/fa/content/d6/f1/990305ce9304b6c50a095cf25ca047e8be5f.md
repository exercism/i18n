# ضمیمه‌ی دستورالعمل

## دستورالعمل‌های تکمیلی

جدولی به اسم `isogram` در اختیار شما قرار می‌گیرد.
ستون اول، `phrase`، شامل متنی است.
شما باید تعیین کنید که آیا این عبارت یک «ایزوگرام» است یا نه.
ستون دوم، `is_isogram`، را با یک مقدار عددی به‌روزرسانی کنید:

* اگر عبارت ایزوگرام باشد، 1
* اگر نباشد، 0

~~~~exercism/note
عملیات مقایسه در SQLite مقادیر «منطقی» را به‌صورت اعداد 0/1 برمی‌گرداند

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
