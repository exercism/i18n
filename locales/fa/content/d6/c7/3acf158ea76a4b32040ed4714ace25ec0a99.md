# پیوست دستورالعمل

## واژه

یک چندتایی `linked-list-node` تعریف کنید.

یک چندتایی `linked-list` تعریف کنید و یک متد `M: linked-list length` (از `sequences`) فراهم کنید تا تست‌ها بتوانند `length` را مستقیماً روی لیست شما فراخوانی کنند.

- `<linked-list> ( -- linked-list )` یک لیست خالی می‌سازد.
- `>linked-list ( seq -- linked-list )` هر عنصر `seq` را به ترتیب روی یک لیست تازه اضافه می‌کند.
- `linked-list>array ( linked-list -- array )` مقدارها را برمی‌گرداند، با شروع از بالای لیست.
- `list-push ( linked-list value -- linked-list )` یک مقدار را روی بالای لیست اضافه می‌کند.
- `list-pop ( linked-list -- linked-list value )` مقدار بالای لیست را حذف می‌کند و آن را برمی‌گرداند.
- `list-peek ( linked-list -- value )` مقدار بالای لیست را بدون حذف کردن آن برمی‌گرداند.
- `list-reverse ( linked-list -- linked-list )` لیستی را برمی‌گرداند که عناصر آن در ترتیب معکوس قرار دارند.

وقتی لیست خالی است، از `list-pop` و `list-peek` یک کلاس خطای `list-empty` پرتاب کنید.
