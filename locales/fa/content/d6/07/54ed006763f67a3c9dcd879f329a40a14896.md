# منطقی

کریستال نوعی دارد به نام [`Bool`][bools].
این نوع مقادیر `true` و `false` را نمایش می‌دهد.

## عملگرهای منطقی

کریستال سه عملگر منطقی دارد (`!`، `||`، `&&`) که مقادیر منطقی را با هم ترکیب می‌کنند و عبارت‌هایی می‌سازند که مقادیر متفاوتی تولید می‌کنند.

### و(`&&`)

عملگر [_و_][and] در کریستال با `&&` نمایش داده می‌شود و اگر هر دو مقدار `true` باشند `true` برمی‌گرداند؛ در غیر این صورت `false` برمی‌گرداند.
هنگام استفاده از عملگر _و_، یک مقدار منطقی در سمت راست `&&` و دیگری در سمت چپ قرار می‌گیرد.

```crystal
true && true
# => true

true && false
# => false
```

### یا(`||`)

عملگر [_یا_][or] در کریستال با `||` نمایش داده می‌شود و اگر **حداقل یکی** از مقادیر داده‌شده `true` باشد `true` برمی‌گرداند.
اگر هر دو مقدار `false` باشند، `false` برمی‌گرداند.
هنگام استفاده از عملگر _یا_، یک مقدار منطقی باید در سمت راست `||` و دیگری در سمت چپ قرار گیرد.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### نه(`!`)

عملگر _نه_ در کریستال با `!` نمایش داده می‌شود و اگر مقدار منطقی داده‌شده `false` باشد `true` برمی‌گرداند و اگر `true` داده شود `false` برمی‌گرداند.
هنگام استفاده از عملگر _نه_، یک مقدار منطقی باید بعد از عملگر (`!`) قرار گیرد.

```crystal
!true
# => false

!false
# => true
```

## استفاده از پرانتز(`()`)

هنگام کار با مقادیر منطقی، می‌توانید از پرانتز استفاده کنید تا تعیین کنید کدام مقادیر منطقی اول ارزیابی شوند.
نتیجه بسته به نحوه‌ی استفاده از پرانتز می‌تواند متفاوت باشد.
در کریستال، آنچه داخل پرانتز است اول ارزیابی می‌شود.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

چون آنچه داخل پرانتز است اول ارزیابی می‌شود، در مثال زیر عملگر _نه_ روی عبارت داخل پرانتز اعمال می‌شود.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
فقط زمانی باید از پرانتز استفاده کنید که روی نتیجه تأثیر بگذارد؛ در غیر این صورت، باید حذف شوند.
~~~~
