# دستورالعمل‌ها

در این تمرین، کدی می‌نویسید که به یک فریلنسر کمک می‌کند با مدیر پروژه ارتباط برقرار کند.
وظیفه‌ی شما این است که چند ابزار فراهم کنید تا نرخ‌های روزانه و ماهانه را به‌سرعت محاسبه کنند، به‌صورت اختیاری همراه با تخفیف مشخص‌شده.

ابتدا چند قاعده را بین فریلنسر و مدیر پروژه تعیین می‌کنیم:

- نرخ روزانه ۸ برابر نرخ ساعتی است.
- یک ماه ۲۲ روز قابل صورتحساب دارد.

گاهی فریلنسر پیشنهاد می‌دهد که روی نرخ روزانه‌اش تخفیف اعمال کند (برای نمونه برای وفادارترین مشتریان یا مشتریان غیرانتفاعی).

تخفیف‌ها به‌صورت اعداد اعشاری مدل‌سازی می‌شوند که درصد را نشان می‌دهند، برای نمونه `25.0` (۲۵٪).

## 1. محاسبه‌ی نرخ روزانه با داشتن نرخ ساعتی

تابعی به اسم `daily_rate` پیاده‌سازی کنید که نرخ روزانه را با داشتن نرخ ساعتی به‌عنوان پارامتر محاسبه کند.
قرارداد تعیین می‌کند که یک روز ۸ ساعت قابل صورتحساب دارد.

```cpp
daily_rate(60)
// => 480.0
```

نرخ روزانه‌ی برگشتی باید از نوع `double` باشد.

## 2. محاسبه‌ی قیمت پس از تخفیف

تابعی به اسم `apply_discount` پیاده‌سازی کنید که قیمت پس از تخفیف را محاسبه کند.
این تابع باید دو پارامتر بگیرد: قیمت اولیه و نرخ تخفیف بر حسب درصد.

```cpp
apply_discount(150, 10)
// => 135.0
```

مقدار برگشتی همیشه باید از نوع `double` باشد و به هیچ شکلی گرد نشود.

## 3. محاسبه‌ی نرخ ماهانه با داشتن نرخ ساعتی و تخفیف

تابعی به اسم `monthly_rate` پیاده‌سازی کنید که نرخ ماهانه‌ی تخفیف‌خورده را محاسبه کند.
این تابع باید دو پارامتر داشته باشد: نرخ ساعتی و تخفیف بر حسب درصد.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

نرخ ماهانه‌ی برگشتی باید به نزدیکترین عدد صحیح به بالا گرد شود (سقف گرفته شود).

## 4. محاسبه‌ی تعداد روزهای کاری کامل با داشتن بودجه، نرخ ساعتی و تخفیف

تابعی به اسم `days_in_budget` پیاده‌سازی کنید که بودجه، نرخ ساعتی و تخفیف را می‌گیرد و محاسبه می‌کند که این مبلغ چند روز کاری کامل را پوشش می‌دهد.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

تعداد روزهای برگشتی باید به نزدیکترین عدد صحیح به پایین گرد شود (کف گرفته شود).
