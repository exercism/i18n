# مقدمه

یک [`function`][function] روشی است برای بخش‌بندی کد تا بتوان آن را با اسم از یک یا چند جای برنامه فراخوانی کرد.
از تابع برای انجام کارهای مشخص و تکراری استفاده می‌شود.

به شکلی رسمی‌تر: تابع هر شیء پایتونی است که بتوان عملیات [`function call`][calls] را روی آن اعمال کرد.
از تابع ممکن است برای [`return`][return] کردن یک یا چند مقدار در نتیجه‌ی برخی عملیات استفاده شود، یا ممکن است برای یک یا چند [`side effects`][side effects] به کار رود.
اگر تابع «مقدار بازگشتی» مشخص نکند، باز هم `None` را برمی‌گرداند.

در ادامه مثالی از تابعی با «اثر جانبی» می‌آید:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

در مثال بالا، از «کلیدواژه‌ی» [`def`][def] برای علامت دادن به آغاز تعریف تابع استفاده می‌شود.
`hello` اسم تابع است.
پرانتزهای خالی نشان می‌دهند که هیچ مقداری به تابع فرستاده نمی‌شود.
بدنه‌ی تابع همان تنها دستور `print("Hello")` است.
`print` هم یک تابع است.
`"Hello"` داخل پرانتزهای تابع `print` به عنوان یک [`argument`][arguments] شناخته می‌شود.
تابع `print` از این آرگومان استفاده می‌کند تا بداند چه چیزی را چاپ کند.
توجه کنید که بدنه‌ی تابع تورفته است.
«تورفتگی» مهم است، چون پایتون برای دانستن اینکه «بلوک کد» کجا تمام می‌شود به آن تکیه می‌کند.
بدنه‌ی تابع یا در پایان برنامه تمام می‌شود، یا درست پیش از خط بعدی کدی که _تورفته نیست_.
چون `hello()` مقدار `return` مشخص نمی‌کند، اثر جانبی‌اش را اجرا می‌کند، یعنی `print()` را فراخوانی می‌کند، و سپس `None` را برمی‌گرداند.
در نهایت، تابع را با استفاده از اسمش و پرانتزها فراخوانی می‌کنیم؛ این پرانتزها به «مفسر» پایتون علامت می‌دهند که این یک اسم _فراخوانی‌پذیر_ است.

در ادامه مثالی از تابعی با مقدار بازگشتی می‌آید:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

بدنه‌ی این تابع از _فراخوانی_ `print` به _برگرداندن_ `string` "Hello" تغییر کرده است.
در پایان، کد همچنان `"Hello"` را چاپ می‌کند، اما اثر جانبی در _کد فراخوان_ رخ می‌دهد، نه در تابع `hello`.
اگر پرانتزها هنگام فراخوانی تابع `hello` حذف شوند (مثلاً `print(hello)`)، آنگاه `print` چیزی شبیه این چاپ می‌کند:

```
<function hello at 0x0000026E18E93E20>
```

مهم است که حتی اگر یک تابع هیچ آرگومانی نپذیرد (_یعنی هیچ پارامتری نداشته باشد_)، برای _فراخوانی_ درست آن باید از پرانتزهای خالی استفاده کرد.
این با زبانی مثل Ruby متفاوت است؛ Ruby برای فراخوانی تابعی بدون هیچ آرگومان، پرانتزهای خالی لازم ندارد.

یک تابع می‌تواند صفر یا چند [`parameters`][parameters] تعریف کند. یک «پارامتر» تعیین می‌کند که تابع چه آرگومان(هایی) را می‌پذیرد.

در ادامه مثالی از تابعی می‌آید که یک «آرگومان» می‌پذیرد:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

پارامتر با `name` تعریف شده است. `"Bob"` آرگومانی است که برنامه به تابع `hello` می‌فرستد. تابع `string` "Hello, Bob" را _برمی‌گرداند_.

اگر کسی `hello` را بدون فرستادن آرگومان فراخوانی کند چه می‌شود؟ برنامه خطا می‌دهد:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

اگر نمی‌خواهیم برنامه با نبود آرگومان خطا بدهد (_اما می‌خواهیم کد فراخوان اجازه داشته باشد آرگومانی نفرستد_)، می‌توانیم یک [«آرگومان پیش‌فرض»][default arguments] تعریف کنیم. «آرگومان پیش‌فرض» تعیین می‌کند اگر هنگام فراخوانی تابع آرگومان غایب باشد، چه مقداری استفاده شود.

در ادامه مثالی از تابعی با آرگومان پیش‌فرض می‌آید:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

به پارامتر `name` آرگومان پیش‌فرض `"you"` داده شده است، بنابراین اگر آرگومان `name` فرستاده نشود، برنامه `Hello, you` را چاپ می‌کند.

برای اطلاعات بیشتر درباره‌ی آرگومان‌های تابع، لطفاً مفهوم [آرگومان‌های تابع][function arguments] را ببینید.
