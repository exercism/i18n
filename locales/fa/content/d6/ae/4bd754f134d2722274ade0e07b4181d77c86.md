# درباره

نوع اولیه‌ی `char` در Java نمایشی ۱۶ بیتی از یک نویسه‌ی یونیکد است.

~~~~exercism/note
نوع `char` بر پایه‌ی [مشخصات اصلی یونیکد][unicode-specification] است که از ۱۶ بیت برای نمایش نویسه‌ها استفاده می‌کرد.
این مقدار برای پوشش بیشتر حروف رایج کافی است و نویسه‌های بازه‌ی 0x0000 تا 0xFFFF را در بر می‌گیرد.
از آن زمان، این مشخصات بازه‌ی نویسه‌های ممکن را تا 0x01FFFF گسترش داده است.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

چندین `char` می‌توانند یک رشته را تشکیل دهند، مانند `"word"`، یا می‌توان `char`ها را مستقل از هم پردازش کرد.
مقدار ثابت `char` را با کوتیشن تک احاطه می‌کنند (مثلاً `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## به دست آوردن `char`های یک `String`

متد `String.toCharArray` نویسه‌های یک `String` را به‌صورت یک آرایه برمی‌گرداند.
همان‌طور که در [آرایه][concept-arrays] اشاره شد، می‌توانید با یک حلقه‌ی `for` روی آرایه پیمایش کنید.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## کلاس [Character][docs-character]

متدهای کتابخانه‌ای زیادی برای بررسی و دستکاری `char`ها وجود دارد.
این متدها را می‌توان به‌صورت متدهای استاتیک کلاس [`java.lang.Character`][docs-character] یافت.
چند نمونه:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
برخی از متدهای کلاس `Character` سربارگذاری شده‌اند تا بتوانند هم یک `char` بگیرند و هم یک `int`.
برای نمونه، `isDigit` یک نسخه دارد که یک [`char`][is-digit-char] می‌پذیرد و نسخه‌ی دیگر یک [`int`][is-digit-int].
همان‌طور که پیش‌تر اشاره شد، نوع `char` تنها می‌تواند نویسه‌های بازه‌ی 0x0000 تا 0xFFFF را نمایش دهد.
اما `int` می‌تواند همه‌ی نویسه‌ها را نمایش دهد؛ به همین دلیل هم نسخه‌های سربارگذاری‌شده‌ی `int` وجود دارند.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## افزودن یک `char` به یک `String`

از عملگر `+` می‌توان برای افزودن یک `char` به یک `String` استفاده کرد.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
مراقب باشید که _هرگز_ از `+` برای به هم چسباندن دو `char` و ساختن یک `String` استفاده نکنید!
جمع کردن دو `char` به این روش یک `int` به دست می‌دهد، _نه_ یک `String`!
برای نمونه:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

دلیلش این است که Java نوع `char` را به `int` ارتقا می‌دهد (به بخش [۴.۲ انواع و مقادیر اولیه ][jls-primitives] از [مشخصات زبان Java][jls-main] نگاه کنید).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

اما وقتی نویسه‌های زیادی برای افزودن وجود دارد، ممکن است استفاده از [`StringBuilder`][docs-stringBuilder] به‌جای آن کارآمدتر باشد:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
