# دستورالعمل‌ها

Azara و Rui هم‌تیمی‌هایی هستند که در یک شکار گنج با مضمون دزدان دریایی با هم رقابت می‌کنند.
یکی فهرستی از گنج‌ها همراه با مختصات نقشه دارد و دیگری فهرستی از نام مکان‌ها همراه با مختصات نقشه.
نقشه‌های خالی هم به آن‌ها داده شده که روی هرکدام محل شروع با عبارت «شما اینجا هستید» علامت خورده است.

اما همه‌چیز کمی نامرتب است: به نظر می‌رسد مختصات‌های Azara با مختصات‌های Rui متفاوت قالب‌بندی و مرتب شده‌اند و آن‌ها باید مدام از یک فهرست به فهرست دیگر نگاه کنند تا بفهمند کدام گنج‌ها به کدام مکان‌ها مربوط‌اند.
چون تازه‌کارهای F# هستند، پیش شما آمده‌اند تا برای نوشتن یک برنامه‌ی کوچک (در واقع مجموعه‌ای از توابع) که اطلاعات شکارشان را بهتر سازمان‌دهی کند، از شما کمک بخواهند.

## 1. استخراج مختصات

تابع `getCooordinate()` را پیاده‌سازی کنید که یک جفت `(treasure, coordinate)` را از فهرست Azara می‌گیرد و فقط مختصات نقشه‌ی استخراج‌شده را برمی‌گرداند.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. قالب‌بندی مختصات

تابع `convertCoordinate()` را پیاده‌سازی کنید که یک مختصات در قالب "2A" می‌گیرد و یک تاپل در قالب `(2, 'A')` برمی‌گرداند.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. تطبیق مختصات

تابع `compareRecords()` را پیاده‌سازی کنید که یک جفت `(treasure, coordinate)` و یک رکورد `(location, coordinate, quadrant)` می‌گیرد و مختصات‌های هر دو را با هم مقایسه می‌کند.
اگر مختصات‌ها «تطبیق» داشته باشند **`true`** را برگردانید و اگر نداشته باشند **`false`** را برگردانید.
برای مقایسه‌ی دقیق، مختصات‌ها را در صورت نیاز دوباره قالب‌بندی کنید.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. ترکیب رکوردهای منطبق

تابع `createrecord()` را پیاده‌سازی کنید که یک جفت `(treasure, coordinate)` را از فهرست Azara و یک رکورد `(location, coordinate, quadrant)` را از فهرست Rui می‌گیرد و **اگر مختصات‌ها منطبق باشند** `(coordinate, location, quadrant, treasure)` را برمی‌گرداند.
اگر مختصات‌ها _منطبق نباشند_، یک تاپل با همان شکل ولی پرشده با `""` را برمی‌گرداند.
برای مقایسه‌ی دقیق، مختصات‌ها را در صورت نیاز دوباره قالب‌بندی کنید.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
