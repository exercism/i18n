# دستورالعمل‌ها

تابعی بنویسید که اعداد عادی را به [اعداد ترتیبی](https://en.wikipedia.org/wiki/Ordinal_numeral) تبدیل کند. برای صفر (۰) فقط رشته‌ی "0" را برگردانید.

اعداد ترتیبی اعدادی هستند که جایگاه یک مورد را در یک فهرست توصیف می‌کنند. اعداد ترتیبی در همین بافت به کار می‌روند و نام هر عدد ترتیبی به شکل انگلیسی نوشته می‌شود.

اعداد ترتیبی این‌ها هستند (دست‌کم، یکی از شکل‌هایشان):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

پس وارد کردن یک عدد عادی، معادل ترتیبی آن را به دست می‌دهد:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
