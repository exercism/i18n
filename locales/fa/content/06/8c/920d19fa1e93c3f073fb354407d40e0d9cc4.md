# مقدمه

نوع‌هایی که رابط `IEnumerable<T>` را پیاده‌سازی می‌کنند، «پیمایش‌پذیر» نامیده می‌شوند. همه‌ی نوع‌های مجموعه‌ی توکار این رابط را پیاده‌سازی می‌کنند.

روی یک نوع پیمایش‌پذیر می‌توان با یک حلقه‌ی `foreach` پیمایش کرد:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

برای پیاده‌سازی `IEnumerable<T>`، یک نوع باید یک متد را پیاده‌سازی کند: `IEnumerator<T> GetEnumerator()`. همان‌طور که دیدید، یک نوع پیمایش‌پذیر، پیمایش واقعی روی یک مجموعه را به یک نوع `IEnumerator<T>` واگذار می‌کند. این رابط یک ویژگی و سه متد برای پیاده‌سازی دارد:

- `public T Current { get; }`: عنصر جاری را برمی‌گرداند.
- `public bool MoveNext ();`: به عنصر بعدی می‌رود؛ اگر رفتن به عنصر بعدی موفق باشد `true` و در غیر این صورت (وقتی عنصر دیگری نمانده باشد) `false` را برمی‌گرداند.
- `public void Reset ();`: پیمایشگر را به حالت اولیه‌اش (پیش از اولین عنصر) بازمی‌گرداند.
