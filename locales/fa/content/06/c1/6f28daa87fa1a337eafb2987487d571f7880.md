# مقدمه

«عبارت‌های شرطی» برای اجرای کد بر اساس **if** به کار می‌روند، به این معنا که آیا یک شرط **«درست»** است یا **«غلط»**. این عبارت‌ها به این شکل نوشته می‌شوند:

```haxe
if (condition) {
  expressions
};
```

خروجی شرط از نوع `Bool` است، بنابراین وقتی خروجی `true` باشد، عبارت‌ها اجرا می‌شوند.

گاهی اوقات، وقتی شرط در واقع `false` است، می‌خواهیم بخش دیگری از کد اجرا شود. اینجاست که عبارت `else` وارد می‌شود. عبارت `else` زمانی که شرط اولیه `false` باشد، عبارت‌ها را اجرا می‌کند. اما اگر بخواهیم شرط را برای چند حالت ممکن بررسی کنیم، چه باید کرد؟ در این صورت از `else if (condition)` استفاده می‌کنیم. در ادامه یک مثال کامل آورده شده است:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
