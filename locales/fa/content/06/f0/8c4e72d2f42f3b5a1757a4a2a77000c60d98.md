# مقدمه

**عبارت‌های باقاعده**، که به آن‌ها regex هم می‌گویند، دنباله‌هایی از نویسه‌ها هستند که یک الگوی جست‌وجو را در متن مشخص می‌کنند.

یادگیری نحوه‌ی نگارش عبارت‌های باقاعده فراتر از موضوع این مبحث است.
ما بر عبارت‌هایی تمرکز می‌کنیم که `jq` برای استفاده از عبارت‌های باقاعده ارائه می‌دهد.

## گونه‌ی عبارت‌های باقاعده

ابزارهای مختلف نسخه‌های متفاوتی از عبارت‌های باقاعده را پیاده‌سازی می‌کنند.
`jq` از کتابخانه‌ی عبارت باقاعده‌ی [Oniguruma][oniguruma] استفاده می‌کند که تا حد زیادی با عبارت‌های باقاعده‌ی Perl نسخه‌ی ۵.۸ سازگار است.

نحوه‌ی نگارش خاصی که `jq` استفاده می‌کند را می‌توانید [در مخزن GitHub مربوط به Oniguruma پیدا کنید][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` هیچ نحوه‌ی نگارش خاصی برای عبارت‌های باقاعده ندارد.
آن‌ها به‌سادگی به شکل رشته بیان می‌شوند.
یعنی هر بک‌اسلش در عبارت باقاعده باید در رشته escape شود.

برای مثال، کلاس نویسه‌ی رقم (`\d`) باید به شکل `"\\d"` نوشته شود.
~~~~

<!-- prettier-ignore-end -->

## توابع عبارت‌های باقاعده

عبارت‌های باقاعده در `jq` محدود به [مجموعه‌ای از فیلترها][jq-regex-funcs] هستند.

### تطبیق ساده

وقتی می‌خواهید بدانید آیا رشته‌ای با الگویی مطابقت دارد یا نه، از فیلتر `test` استفاده کنید.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

این فیلتر یک نتیجه‌ی _منطقی_ خروجی می‌دهد.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### اطلاعاتی درباره‌ی تطبیق

وقتی می‌خواهید زیررشته‌ای را استخراج کنید که واقعاً با الگو مطابقت داشته است، از فیلتر `match` استفاده کنید.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

این فیلتر خروجی می‌دهد:

- اگر تطبیقی وجود نداشته باشد، هیچ؛ یا
- اگر تطبیقی وجود داشته باشد، یک شیء شامل ویژگی‌های مختلف.

این مثال با استفاده از نحوه‌ی نگارش backref، یعنی `\1`، دو مصوت یکسان و پشت‌سرهم را جست‌وجو می‌کند.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

فیلتر `match` برای _هر_ تطبیق یک شیء برمی‌گرداند.
این مثال نشان می‌دهد که پرچم `"g"` چگونه همه‌ی مصوت‌ها را پیدا می‌کند.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### زیررشته‌های گرفته‌شده

مشابه فیلتر `match`، فیلتر `capture` در صورت وجود تطبیق یک شیء برمی‌گرداند.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

شیء برگردانده‌شده، نگاشتی از **گروهِ‌های نام‌دار** است.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### فقط زیررشته‌ها

فیلتر `scan` مشابه `match` همراه با پرچم `"g"` است.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` یک _جریان_ از زیررشته‌ها خروجی می‌دهد.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

برای گرفتن زیررشته‌ها از سازنده‌ی آرایه‌ی `[...]` استفاده کنید.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### تقسیم یک رشته

اگر می‌دانید کدام بخش‌های رشته را می‌خواهید **نگه دارید**، از `match` یا `scan` استفاده کنید.
اگر می‌دانید کدام بخش‌ها را می‌خواهید **دور بریزید**، از `split` استفاده کنید.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
فیلتر **تک‌آرگومانی** `split` با آرگومان خود مانند یک **رشته‌ی ثابت** رفتار می‌کند.

برای استفاده از یک عبارت باقاعده همراه با `split`، **باید** آرگومان دوم را ارائه کنید؛ استفاده از یک رشته‌ی خالی اشکالی ندارد.
~~~~

<!-- prettier-ignore-end -->

مثالی که یک رشته را بر اساس فضای سفید دلخواه تقسیم می‌کند.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### جایگزینی

فیلترهای `sub` و `gsub` می‌توانند رشته‌ی ورودی را تغییر دهند و بخش‌های منطبق با الگو از ورودی را با یک رشته‌ی جایگزین عوض کنند.

برای جایگزینی فقط اولین تطبیق، از `sub` استفاده کنید.
برای جایگزینی همه‌ی تطبیق‌ها، از `gsub` استفاده کنید.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

متن جایگزین می‌تواند به زیررشته‌های منطبق ارجاع دهد؛ از گروه‌های نام‌دار و [درج رشته‌ای][jq-interp] استفاده کنید.

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## پرچم‌ها

در همه‌ی فیلترهای بالا، FLAGS رشته‌ای است که از صفر یا چند مورد از پرچم‌های پشتیبانی‌شده تشکیل می‌شود.

- `g` - جست‌وجوی سراسری (همه‌ی تطبیق‌ها را پیدا می‌کند، نه فقط اولین تطبیق)
- `i` - جست‌وجو بدون توجه به بزرگی و کوچکی حروف
- `m` - حالت چندخطی ('.' با خطوط جدید مطابقت می‌کند)
- `n` - نادیده گرفتن تطبیق‌های خالی
- `p` - هر دو حالت s و m فعال می‌شوند
- `s` - حالت تک‌خطی ('^' -> '\A', '$' -> '\Z')
- `l` - پیدا کردن طولانی‌ترین تطبیق‌های ممکن
- `x` - قالب گسترده‌ی عبارت باقاعده (نادیده گرفتن فضای سفید و توضیحات)

برای مثال

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
