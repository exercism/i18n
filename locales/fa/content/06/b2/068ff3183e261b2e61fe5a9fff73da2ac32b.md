# ساختارهای شرطی: if، elseif و else

دستورهای شرطی که از `if`، `elseif` و `else` استفاده می‌کنند، بخشی بنیادی از جریان کنترل برنامه هستند.
دستور `if` یک عبارت را ارزیابی می‌کند و اگر `true` باشد، شاخه‌ی کد را اجرا می‌کند.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

اگر عبارت یک مقدار «منطقی» نباشد، ارزیابی مشخص می‌کند که مقدار آن «درست‌نما» است یا «غلط‌نما».
در PHP، مقادیر زیر برابر با «غلط» در نظر گرفته می‌شوند:

- مقدار منطقی `false`
- عدد صحیح `0`
- عدد اعشاری `0.0` و `-0.0`
- یک آرایه‌ی خالی `[]`
- یک رشته‌ی خالی `""` یا یک رشته‌ی عددی `"0"`
- `null`

همه‌ی مقادیر دیگر «درست» در نظر گرفته می‌شوند.

## واکنش به چندین شرط

پس از یک دستور `if`، می‌توانید چندین شرط را با `elseif` و `else` زنجیره کنید.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

فقط یک دستور شرطی که «درست» ارزیابی شود، اجرا می‌شود.
پس اگر چندین شرط بتوانند «درست» ارزیابی شوند، ترتیبی که نوشته می‌شوند مهم است.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
