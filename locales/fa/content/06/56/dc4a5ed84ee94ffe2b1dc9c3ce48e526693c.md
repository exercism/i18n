# مقدمه

PHP چندین عملگر برای انجام عملیات حسابی ارائه می‌دهد. PHP برای عملگرهای حسابی خود از ترتیب استاندارد عملیات ریاضی پیروی می‌کند. عملگرهایی که PHP در اختیار می‌گذارد عبارت‌اند از:

* «هویت» (+)
* «نفی» (-)
* «جمع» (+)
* «تفریق» (-)
* «ضرب» (*)
* «تقسیم» (/)
* «باقیمانده» (%)
* «توان» (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
