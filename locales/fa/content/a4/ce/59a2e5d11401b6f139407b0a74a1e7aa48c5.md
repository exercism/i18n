# camelCase

[comment]: # "این خطا زمانی صادر می‌شود که یک متغیر یا نوع از camelCase یا PascalCase استفاده نکند"
[comment]: # "به ۲ پارامتر نیاز دارد:"
[comment]: # "- نادرست: اسمی با حروف‌چینی نادرست"
[comment]: # "- درست: اسمی با حروف‌چینی درست"

جامعه‌ی Elm به‌شدت ترجیح می‌دهد که برای اسم متغیرها از camelCase و برای نوع‌ها از PascalCase استفاده شود.

اسم `%{wrong}` را پیدا کردیم که باید با `%{correct}` جایگزین شود.
