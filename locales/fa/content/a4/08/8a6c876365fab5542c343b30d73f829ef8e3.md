# enum

`enum` یک نوع داده در Cairo است که برای تعریف مجموعه‌ای از گونه‌های از پیش تعیین‌شده به کار می‌رود تا کد خواناتر و ایمن‌تر شود.
در Cairo می‌توان گونه‌های `enum` را طوری تعریف کرد که انواع داده‌ی متفاوتی را نگه دارند (اعداد صحیح، `struct`ها، تاپل‌ها، `enum`های دیگر و غیره).

قطعه‌کد زیر نشان می‌دهد که `enum` را چگونه می‌توان تعریف کرد:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

`enum` یعنی `Direction` که در بالا تعریف شد، یک `enum` ساده با چهار گونه است: `North`، `East`، `South` و `West`.
قرارداد نام‌گذاری این است که برای گونه‌های `enum` از PascalCase استفاده شود.
هر گونه نماینده‌ی یک مقدار متمایز از نوع `enum` یعنی `Direction` است.
هر گونه در این نمونه‌ی خاص مقدار همراهی ندارد و می‌توان آن را با این نحوه‌ی نگارش نمونه‌سازی کرد:

```rust
let direction = Direction::North;
```

در ادامه همان `enum` یعنی `Direction` آمده است، اما با گونه‌هایی که مقدار همراه دارند و درجه‌ی دقیق جهت را ذخیره می‌کنند:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

از این مثال پیداست که هر گونه در `enum` یعنی `Direction` یک مقدار همراه از نوع `u128` دارد.
این نوع `enum` را می‌توان به این صورت نمونه‌سازی کرد:

```rust
let direction = Direction::North(10);
```

## نمونه‌ی `enum` پیچیده با انواع سفارشی

می‌توان یک `enum` را با ترکیبی از انواع داده‌ی متفاوت به عنوان گونه‌هایش تعریف کرد.
در مثال زیر، `Action` یک `enum` پیچیده است که مجموعه‌ای از `Quit`، `Direction`، `SendMessage`، `ChangeAvatar` و `ProfileState` را به عنوان گونه در خود دارد.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## پیاده‌سازی `trait` برای `enum`

در Cairo می‌توان `trait` تعریف کرد و آن را برای `enum`های سفارشی پیاده‌سازی کرد.
این کار به شما امکان می‌دهد متدها و ویژگی‌های مرتبط با یک `enum` را تعریف کنید.
در ادامه نمونه‌ای از این کار آمده است؛ در آن یک `enum` به اسم `Message` تعریف می‌کنیم و یک `trait` به اسم `Processing` برایش پیاده‌سازی می‌کنیم:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

در ادامه می‌بینید که چگونه می‌توان از این `trait` برای پردازش یک پیام `Quit` استفاده کرد:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

`enum`ها در بسیاری از موقعیت‌ها به کار می‌آیند، به‌ویژه وقتی همراه با جریان `match` استفاده شوند، همان‌طور که در بالا در پیاده‌سازی `trait` دیدیم.
درباره‌ی جریان `match` در [The Cairo Book][match] بیشتر بخوانید.
