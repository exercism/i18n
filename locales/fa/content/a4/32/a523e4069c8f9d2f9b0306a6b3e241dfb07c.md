# درباره

## نام‌های مستعار نوع

در Gleam می‌توانید از «نام مستعار نوع» استفاده کنید تا برای یک نوع موجود که در غیر این صورت نوشتنش دشوار است، نامی راحت انتخاب کنید.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

وقتی با `pub type` نوشته شود، می‌توان از این نام مستعار بیرون از ماژولی که در آن تعریف شده هم استفاده کرد. اگر `pub` را حذف کنید، نام مستعار خصوصی می‌شود و نمی‌توان در ماژول‌های دیگر به آن ارجاع داد.
