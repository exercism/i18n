# مقدمه

فرم خاص `import` به شما امکان می‌دهد از توابع یک ماژول خارجی استفاده کنید، بدون آنکه اسم ماژول را بیاورید.

وارد کردن کل یک ماژول خارجی می‌تواند با توابع محلی موجود تعارض ایجاد کند. برای جلوگیری از این کار، دو گزینه در دسترس است: `:except` و `:only`. هر دو یک لیست کلیدواژه می‌گیرند که کلید در آن اسم تابع و مقدارش تعداد آرگومان‌های آن تابع است.

معمولاً دستورهای `import` در ابتدای تعریف ماژول نوشته می‌شوند.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
