# مقدمه

در Clojure، به اتصال یک مقدار به یک اسم، «var» می‌گویند. varهای سطح بالا (سراسری) شبیه ثابت‌ها در زبان‌های دیگر هستند، اما معمولاً بازتعریف می‌شوند تا توسعه‌ی پویا آسان‌تر شود.

varهای سطح بالا با `def` تعریف می‌شوند:

```clojure
(def fingers 10)
```

از ماکروی `defn` می‌توان برای تعریف تابعی استفاده کرد که صفر یا چند آرگومان می‌گیرد. یک تابع همیشه نتیجه‌ی آخرین عبارت در بدنه‌اش را برمی‌گرداند.

```clojure
(defn add [x y]
  (+ x y))
```

فراخوانی یک تابع با مشخص کردن اسم آن و پاس دادن آرگومان برای هر یک از پارامترهای تابع انجام می‌شود.

```clojure
(def five (add 2 3))
```

توابع و مقادیر در Clojure فقط _بعد_ از تعریف شدن قابل استفاده‌اند. استفاده از آن‌ها پیش از تعریف شدن، به خطای کامپایل منجر می‌شود.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

در Clojure، فضای سفید هیچ اهمیت دیگری جز قالب‌بندی ندارد.

توابع و varهای Clojure در فضاهای نام سازمان‌دهی می‌شوند. یک فضای نام، قابلیت‌های مرتبط را گروه‌بندی می‌کند و با ماکروی `ns` تعریف می‌شود:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure از دو نوع کامنت پشتیبانی می‌کند. کامنت‌های تک‌خطی با `;` شروع می‌شوند و فرم `comment` برای جلوگیری از ارزیابی هر آنچه بین `(comment` و `)` قرار دارد به کار می‌رود.
