# درباره

[«سربارگذاری متد»][method-overloading] یکی از مفاهیم کلیدی در Java است و به یک کلاس اجازه می‌دهد بیش از یک متد با اسم یکسان داشته باشد، به شرطی که فهرست پارامترهای هر متد متفاوت باشد.
این ویژگی یکی از جنبه‌های بنیادی برنامه‌نویسی شیءگرا در Java است و راهی فراهم می‌کند تا عملیات مشابه را با انواع یا تعداد متفاوتی از ورودی‌ها انجام دهید.
سربارگذاری متد با اجازه دادن به متدهایی که کارهای مشابهی انجام می‌دهند تا اسم یکسان داشته باشند، خوانایی و سازماندهی کد را بهبود می‌بخشد.
نکته‌ی مهم این است که سربارگذاری بر اساس امضای متد تعیین می‌شود، که شامل اسم متد و فهرست پارامترها است.

## نکات کلیدی

- **امضا مهم است**: نوع بازگشتی بخشی از امضای متد نیست، بنابراین فقط تغییر دادن نوع بازگشتی یک متد به معنای سربارگذاری نیست.
- **تفاوت پارامترها**: متدهای سربارگذاری‌شده باید در تعداد یا نوع پارامترها با هم تفاوت داشته باشند.
- **کاربرد**: از سربارگذاری اغلب استفاده می‌شود تا راه‌های شهودی‌تری برای به کار بردن یک متد با انواع مختلف ورودی‌ها فراهم شود.

## نمونه‌هایی از سربارگذاری متد

کلاس `Calculator` را در نظر بگیرید که می‌تواند عددها را جمع کند.
سربارگذاری امکان انواع مختلفی از عملیات جمع را فراهم می‌کند:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## بهترین شیوه‌ها

- **وضوح**: متدهای سربارگذاری‌شده باید طوری به کار بروند که کد را شهودی‌تر کنند.
  - رفتار متدهای سربارگذاری‌شده باید مرتبط و سازگار باشد.
- **از ابهام پرهیز کنید**: مطمئن شوید هر متد سربارگذاری‌شده هدف روشنی دارد و تفاوت‌های فهرست پارامترها به‌قدری چشمگیر هست که سردرگمی ایجاد نکند.
- **مستندسازی**: هر نسخه از متدهای سربارگذاری‌شده را به‌درستی مستند کنید.
  - مستندسازی روشن به سایر توسعه‌دهندگان کمک می‌کند هدف و کاربرد هر گونه از متد را بفهمند.
- **انواع بازگشتی سازگار**: هرچند نوع بازگشتی در متدهای سربارگذاری‌شده می‌تواند متفاوت باشد، معمولاً به‌عنوان یک شیوه‌ی خوب بهتر است تا حد امکان آن‌ها را سازگار نگه دارید تا سردرگمی پیش نیاید.
- **محدود کردن سربارگذاری**: از استفاده‌ی بیش از حد از سربارگذاری متد پرهیز کنید.
  - سربارگذاری افراطی می‌تواند خواندن و نگهداری کد را سخت‌تر کند.

## نتیجه‌گیری

سربارگذاری متد ویژگی قدرتمندی در Java است که اگر درست به کار برود، می‌تواند خوانایی و انعطاف‌پذیری کد شما را بسیار افزایش دهد.
این ویژگی به متدها اجازه می‌دهد متنوع‌تر و سازگارتر با بافت‌های مختلف باشند و برنامه‌های Java شما را ماژولارتر و قابل‌نگهداری‌تر می‌کند.
