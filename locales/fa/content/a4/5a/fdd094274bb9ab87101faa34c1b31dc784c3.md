# Null

Null یک نوع مقدار اولیه است که تنها یک مقدار دارد: `null`.
از Null اغلب برای نمایش هیچ‌بودن استفاده می‌شود.
این مقدار «غلط‌گونه» در نظر گرفته می‌شود، اما با `false` و دیگر مقادیر غلط‌گونه متفاوت است.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## کار با مقادیر null

در PHP، مقادیر null می‌توانند دلیل رایجی برای خطا باشند، چون اغلب به جای یک وضعیت خطا یا برای نمایش هیچ‌بودن برگردانده می‌شوند.
جلوگیری از بروز خطاها اغلب نیازمند «بررسی null» است تا پیش از کار کردن با مقدار، تأیید کنیم که null نیست.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

بررسی مکرر null می‌تواند خطاپذیر باشد، بنابراین PHP دو عملگر برای کار با مقادیر null ارائه می‌دهد: عملگر دسترسی امن در برابر null یعنی `?->` و عملگر ادغام null یعنی `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
