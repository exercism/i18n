# درباره

- Pony به‌صورت ایستا نوع‌بندی شده است. این یعنی *باید* نوع داده‌های برنامه‌تان را از پیش تعریف کنید. اگر به Pony بگویید که متغیر `x` یک عدد صحیح است، نمی‌توانید یک رشته به آن نسبت دهید.
- سیستم نوع Pony همان چیزی است که تضمین‌های Pony را ممکن می‌کند.
  - اگر برنامه‌تان کامپایل شود، از کار نمی‌افتد.
  - هیچ استثنای مدیریت‌نشده‌ای رخ نخواهد داد.
  - چیزی به اسم `null` وجود ندارد، پس برنامه‌تان هرگز تلاش نمی‌کند `null` را ارجاع‌گشایی کند.
  - هرگز رقابت داده‌ای پیش نخواهد آمد.
  - هرگز بن‌بست رخ نخواهد داد.
  - کد شما همیشه از نظر قابلیت‌ها ایمن خواهد بود (محافظت در برابر حملات زنجیره‌ی تأمین.
- Pony اجازه نمی‌دهد نوع‌ها را مستقیماً تبدیل کنید. هر تغییر نوعی باید از طریق تابعی انجام شود که نمونه‌ای جدید از نوع جدید می‌سازد.
- سیستم نوع Pony با تقریباً همه‌ی زبان‌های دیگر متفاوت است، پس آن را در بخش‌های کوچک و قابل‌هضم بررسی می‌کنیم.

## پریتیوها

- پریتیوها ساده‌ترین شکل سازمان‌دهی کد در Pony هستند.
  - می‌توانید آن را یک ظرف یا فضای نام برای توابع در نظر بگیرید.
  - فیلدی ندارد (برای این کار کلاس داریم).
  - با کلیدواژه‌ی `primitive` تعریف می‌شود.

## توابع

- توابع با کلیدواژه‌ی `fun` تعریف می‌شوند.
  - توابع باید داخل یک `primitive` باشند (یا یک `class` یا یک `actor` که بعداً به آن‌ها می‌رسیم).
  - توابع می‌توانند ورودی‌هایی بگیرند و یک مقدار بازگشتی داشته باشند. این‌ها باید نوع داشته باشند.
  - اگر نوع بازگشتی تعریف کنید، تابع‌تان *باید* مقداری از آن نوع برگرداند. Pony مفهوم Null را ندارد.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## کامنت‌ها

از کامنت‌ها می‌توان برای گذاشتن یادداشت و یادآوری، یا فقط حذف موقت کد از کد منبع استفاده کرد. همان‌طور که در بالا دیدید، کامنت‌های تک‌خطی از `//` استفاده می‌کنند. کامنت‌های چندخطی از سبک C یعنی `/*` و `*/` استفاده می‌کنند.

## متغیرها

- اسم متغیرها همیشه با حرف کوچک شروع می‌شود
  - آن‌ها را با `var` اعلان می‌کنیم. (`let` و `embed` بعداً می‌آیند).
  - اگر Pony بتواند نوع متغیر را تشخیص دهد، خودش این کار را برایتان انجام می‌دهد.
  - نوع متغیر در زمان کامپایل بررسی می‌شود و هرگز تغییر نمی‌کند.
  - وقتی تازه با Pony شروع می‌کنید، توصیه می‌کنیم نوع را صریح بنویسید.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
