# مقدمه

به یاد بیاورید که در مفهوم «مبانی»، یک برنامه‌ی AWK از **جفت‌های الگو و کنش** تشکیل شده است.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## منظور از «الگو» چیست؟

«الگو» هر عبارت AWK است.
درست‌بودن نتیجه‌ی عبارت تعیین می‌کند که آیا کنش اجرا می‌شود یا نه.

## الگوی خالی

می‌توان الگو را حذف کرد.
در این حالت، کنش برای هر رکورد اجرا می‌شود.

می‌توانیم همه‌ی اسم‌های کاربری را در فایل passwd چاپ کنیم.

```sh
awk -F: '{print $1}' /etc/passwd
```

## عبارت‌های باقاعده

AWK می‌تواند رشته‌ها را با عبارت‌های باقاعده مقایسه کند تا یک «مقدار منطقی» به دست آورد.

برای تطبیق یک فیلد خاص، از عملگر تطبیق عبارت باقاعده یعنی `~` استفاده کنید.
این عملگر یک رشته را به عنوان عملوند سمت چپ و یک عبارت باقاعده را به عنوان عملوند سمت راست می‌گیرد.
یک عبارت باقاعده‌ی تحت‌اللفظی بین دو اسلش `/` قرار می‌گیرد.

برای یافتن کاربرانی در فایل passwd که با bash وارد می‌شوند:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` عملگر «تطبیق **ندادن** عبارت باقاعده» است.

برای تطبیق یک عبارت باقاعده با رکورد جاری، می‌توانید از `$0 ~ /regex/` استفاده کنید.
این کار آن‌قدر رایج است که یک شکل کوتاه‌نویسی هم دارد: می‌توانید `$0` و `~` را حذف کنید و به‌سادگی `/regex/` بنویسید.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
این یک‌خطی AWK را با فرمان معادل grep مقایسه کنید

```sh
grep 'regex' data.txt
```

AWK بدون آنکه از اختصار آن کم شود، یک زبان برنامه‌نویسی کامل در اختیارتان می‌گذارد.
~~~~

در یکی از مفاهیم بعدی بیشتر به گونه‌ی عبارت باقاعده‌ی GNU AWK می‌پردازیم.

## عبارت‌ها

عبارت‌های AWK (حسابی، منطقی یا هر نوع دیگر) را می‌توان به عنوان الگو به کار برد.

برای استخراج همه‌ی کاربرانی که UID آن‌ها ۱۰۰۰ یا بیشتر است:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

به یاد بیاورید که مقادیر «غلط» در AWK عدد صفر و رشته‌ی خالی هستند و هر عدد یا رشته‌ی دیگری «درست» است.
هر عبارتی که به یک عدد یا یک رشته ارزیابی شود، می‌تواند به عنوان الگو استفاده شود.

## توابع

هر [تابع توکار][builtins] یا [تابع کاربرساخته][user-defined] را می‌توان در یک عبارت و در نتیجه در الگو به کار برد.
چند نمونه:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## الگوهای ثابت

یک اصطلاح رایج در AWK این است:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` الگویی است که «درست» ارزیابی می‌شود و کنشی به آن وابسته نیست.
یعنی: «رکورد جاری را چاپ کن».
