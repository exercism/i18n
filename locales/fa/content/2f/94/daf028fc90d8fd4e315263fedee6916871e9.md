# پیوست دستورالعمل‌ها

## قالب تخته

تخته به شکل رشته‌ای نمایش داده می‌شود که با null پایان می‌یابد و در پایان هر سطر یک نویسه‌ی خط جدید دارد.

یک نمونه می‌تواند `"X  \n XO\nOX \n"` باشد.

## ثبات‌ها

| ثبات    | کاربرد       | نوع     | توضیح                                                                   |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | ورودی        | آدرس    | رشته‌ی ورودی که با null پایان می‌یابد                                   |
| `$v0`    | خروجی        | عدد صحیح | وضعیت بازی (`1` = `ongoing`، `2` = `draw`، `3` = `win`، `-1` = `error`) |
| `$t0-9`  | موقت         | هر نوع  | برای ذخیره‌سازی موقت                                                    |
