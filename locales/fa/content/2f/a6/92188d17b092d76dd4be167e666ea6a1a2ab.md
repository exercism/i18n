# مقدمه

زبان C یک زبان با نوع‌بندی ایستا است، یعنی همه‌چیز در زمان کامپایل نوع دارد. انتخاب اسم برای یک متغیر و تعیین نوع آن، اعلان متغیر نام دارد.

متغیر با مشخص کردن صریح نوع آن اعلان می‌شود.
اسم متغیر باید با یک حرف یا یک زیرخط شروع شود.
بعضی اسم‌ها قابل استفاده نیستند، چون به عنوان [کلیدواژه‌ها][reserved-keywords] یا [شناسه‌های دیگر][reserved-identifiers] رزرو شده‌اند.

مقدار دادن یا به‌روزرسانی متغیر با انتساب متغیر انجام می‌شود.
با مقدار دادن، آن متغیر تعریف می‌شود.
تعریف متغیر را مقداردهی اولیه هم می‌نامند.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

مقدار یک متغیر را می‌توان با عملگر انتساب ساده‌ی `=` تعیین و به‌روزرسانی کرد.
پس از تعریف، نوع متغیر هرگز تغییر نمی‌کند.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C یک زبان دستوری و رویه‌ای است.
همه‌ی محاسبات در قالب مجموعه‌ای از دستورها انجام می‌شود که بخشی از یک تابع یا چند تابع هستند.

هر تابع می‌تواند صفر یا چند پارامتر داشته باشد.
هنگام تعریف یک تابع، همه‌ی پارامترها و مقدار بازگشتی باید صریحاً دارای نوع باشند.
مقادیر با استفاده از کلیدواژه‌ی `return` از تابع بازگردانده می‌شوند.
توابع به‌طور پیش‌فرض کلاس ذخیره‌سازی خارجی دارند، یعنی در طول عمر برنامه وجود دارند و می‌توانند از بیرون فایل قابل مشاهده باشند.
برای جلوگیری از این وضعیت، می‌توان کلیدواژه‌ی `static` را اضافه کرد تا قابلیت مشاهده‌ی داخلی تعیین شود.

```c
static int add(int x, int y) {
  return x + y;
}
```

در مثال بالا، متغیرهای `x` و `y` فقط درون تابع قابل استفاده‌اند، یعنی «محدوده‌ی تابع» را دارند.
«محدوده» به این ایده اشاره دارد که مقدار مرتبط با یک اسم (از یک عنصر برنامه) فقط درون «ناحیه‌ی» کدی که در آن تعریف شده است قابل دسترسی است.
ناحیه‌های اصلی کد در C عبارت‌اند از:

- فایل
- تابع
- «بلوک» (مانند درون حلقه‌ها و دیگر ساختارها)

توابع با مشخص کردن اسم تابع و فرستادن آرگومان برای هر یک از پارامترهای تابع فراخوانی می‌شوند.

```c
int sum = add(1, 2);
```

C از دو نوع توضیح پشتیبانی می‌کند.
توضیح‌های تک‌خطی با `//` شروع می‌شوند (از C99 به بعد) و توضیح‌های چندخطی بین `/*` و `*/` قرار می‌گیرند.
