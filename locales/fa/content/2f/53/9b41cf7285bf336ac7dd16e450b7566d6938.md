# پیوست دستورالعمل

## ثبات‌ها

| ثبات   | کاربرد     | نوع      | توضیح                                                    |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | ورودی     | آدرس | رشته‌ی ورودی پایان‌یافته با تهی                           |
| `$v0`    | خروجی     | منطقی | اعتبار رشته‌ی ورودی (`0` = `false`، `1` = `true`) |
| `$t0-9`  | موقت | هر نوعی     | برای ذخیره‌سازی موقت استفاده می‌شود                             |
