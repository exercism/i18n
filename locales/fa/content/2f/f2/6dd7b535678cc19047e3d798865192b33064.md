# مقدمه

«فهرست کلیدواژه» یک ساختار داده‌ی کلید-مقدار است.

```elixir
[month: "April", year: 2018]
```

فهرست کلیدواژه فهرستی از [تاپل‌های][exercism-tuples] `{key, value}` است و می‌توان آن را به همان شکل هم نوشت، اما نگارش کوتاه‌تر کاربرد بیشتری دارد.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

کلیدها در فهرست کلیدواژه باید [اتم][exercism-atoms] باشند، اما مقدارها می‌توانند هرچه باشند. هر کلید می‌تواند بیش از یک بار به کار رود. جفت‌های کلید-مقدار در فهرست کلیدواژه مرتب هستند.

می‌توانید با فهرست‌های کلیدواژه به همان روش‌های فهرست‌ها کار کنید، یا از ماژول `Keyword` استفاده کنید.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
