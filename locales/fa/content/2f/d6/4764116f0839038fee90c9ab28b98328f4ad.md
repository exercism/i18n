## آرگومان‌های اختیاری

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

معادل است با

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

در پاسخ REPL می‌توانید ببینید که اولین تعریف دو متد را همزمان تعریف می‌کند.
