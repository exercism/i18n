# مقدمه

## رشته

یک `string` در C# شیءای است که متن تغییرناپذیر را به‌صورت دنباله‌ای از نویسه‌های یونیکد (حروف، ارقام، نشانه‌های نگارشی و غیره) نمایش می‌دهد. برای تعریف یک نمونه از `string` از علامت نقل‌قول دوگانه استفاده می‌شود:

```csharp
string fruit = "Apple";
```

### متدها

رشته‌ها با فراخوانی [متدهای داخلی][docs-string-methods] رشته دستکاری می‌شوند.
برای مثال، برای حذف فاصله‌های خالی از یک رشته، می‌توانید مانند این از [متد Trim][tutorial-docs.microsoft.com-trim-white-space] استفاده کنید:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

وقتی رشته‌ای ساخته شد، مقدار آن هرگز تغییر نمی‌کند.
هر متدی که به نظر برسد رشته را تغییر می‌دهد، در واقع رشته‌ی جدیدی برمی‌گرداند.

### الحاق

چندین رشته را می‌توان به هم الحاق (اضافه) کرد. ساده‌ترین راه برای این کار استفاده از عملگر `+` است.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### قالب‌بندی

برای هر قالب‌بندی رشته که پیچیده‌تر از الحاق ساده باشد، درج در رشته ترجیح داده می‌شود. برای استفاده از درج در رشته، یک علامت دلار (`$`) به ابتدای رشته اضافه کنید. سپس می‌توانید با آکولاد (`{}`) به هر متغیری درون رشته دسترسی داشته باشید.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
