# دستورالعمل‌ها

در این تمرین، مجموعه‌ای جزئی از توابع کمکی را پیاده‌سازی می‌کنید تا به یک برنامه‌نویس در پاک‌سازی اسم شناسه‌ها کمک کنید.

در ۶ مرحله، به‌تدریج توابع `transform` را برای تبدیل تک‌کاراکترها و `clean` را برای تبدیل رشته‌ها می‌سازید.

یک شناسه‌ی معتبر از صفر یا چند حرف، زیرخط، خط تیره، علامت سؤال و ایموجی تشکیل می‌شود.

اگر رشته‌ی خالی به تابع `clean` داده شود، باید رشته‌ی خالی برگردانده شود.

## 1. هر خط تیره‌ای را که به آن برخوردید با زیرخط جایگزین کنید

تابع `transform` را پیاده‌سازی کنید تا هر خط تیره را با زیرخط جایگزین کند.

```fsharp
transform '-'  // => "_"
```

## 2. همه‌ی فضای خالی را حذف کنید

همه‌ی کاراکترهای فضای خالی را حذف کنید.
این شامل فضای خالی ابتدا و انتهای رشته هم می‌شود.

```fsharp
transform ' '  // => ""
```

## 3. camelCase را به kebab-case تبدیل کنید

تابع `transform` را تغییر دهید تا camelCase را به kebab-case تبدیل کند.

```fsharp
transform 'D'  // => "-d"
```

## 4. کاراکترهایی را که رقم هستند حذف کنید

تابع `transform` را تغییر دهید تا هر کاراکتری را که عددی است حذف کند.

```fsharp
transform '7'  // => ""
```

## 5. حروف کوچک یونانی را با علامت سؤال جایگزین کنید

تابع `transform` را تغییر دهید تا هر حرف یونانی در بازه‌ی 'α' تا 'ω' را با علامت سؤال جایگزین کند.

```fsharp
transform 'β' // => "?"
```

## 6. این عملیات را ترکیب کنید تا روی یک رشته کار کنند

تابع `clean` را پیاده‌سازی کنید تا این عملیات را روی کل رشته اعمال کند.

کاراکترهایی که خارج از این قواعد قرار می‌گیرند باید بدون تغییر عبور کنند.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## ساختن رشته از کاراکترها

این موضوع بعداً در برنامه‌ی درسی با جزئیات بررسی می‌شود.

اما فعلاً ممکن است دانستن این نکته مفید باشد که یک [تابع مرتبه بالا][higher-order-function] به اسم [`String.collect`][string-collect] وجود دارد که یک مجموعه از `char`ها را، با استفاده از تابعی که خودتان می‌دهید، به یک رشته تبدیل می‌کند.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
