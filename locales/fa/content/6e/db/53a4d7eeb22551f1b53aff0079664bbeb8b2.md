# درباره

Haskell نوعی به نام `Num` دارد که نوع پایه برای همه‌ی انواع عددی است.
این نوع چهار زیرنوع اصلی دارد: [`Int`][int]، [`Integer`][integer]، [`Double`][double] و [`Float`][float].

در Haskell دو نوع عدد صحیح وجود دارد که اعداد کامل را نمایش می‌دهند.
`Int` یک عدد صحیح با اندازه‌ی ثابت است، در حالی که `Integer` یک عدد صحیح با دقت دلخواه است.

`Integer` هر عددی را نگه می‌دارد، هر چقدر هم که بزرگ باشد، تا مرز حافظه‌ی ماشین شما؛ در حالی که `Int` متناظر با مجموعه‌ی اعداد صحیح مثبت و منفی است که می‌توانند در ۳۲ یا ۶۴ بیت بیان شوند (حداقل از -۲^۲۹ تا ۲^۲۹ - ۱ تضمین شده است).

توجه کنید که هنگام نوشتن اعداد منفی، برای جلوگیری از ابهام باید از پرانتز استفاده کنید.

```haskell
1

(-1)
```

`Float` متناظر با مجموعه‌ی اعداد حقیقی است که با دقت رایانه محدود می‌شود.
عملیات تعریف‌شده روی اعداد معمولاً روی یکی از این دو نوع کار می‌کنند، نه هر دو.

`Double` یک عدد اعشاری با دقت دوگانه است.

```haskell
10.5
```

## تبدیل میان اعداد صحیح و اعشاری

با استفاده از تابع `toFloat` می‌توانید یک `Int` یا `Integer` را به `Float` تبدیل کنید.

```haskell
toFloat 1
-- -> 1.0
```

همچنین `fromIntegral` وجود دارد که هر نوع عددی را به نوع عددی استنتاج‌شده‌ای که لازم است تبدیل می‌کند.

```haskell
fromIntegral 1
-- -> 1.0
```

برای تبدیل یک `Float` به `Int` می‌توانید از توابع [`round`][round]، [`floor`][floor] یا [`ceiling`][ceiling] استفاده کنید.
تابع `round` به نزدیک‌ترین عدد صحیح گرد می‌کند، `floor` به سمت پایین گرد می‌کند و `ceiling` به سمت بالا.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## عملگرهای حسابی

می‌توانید از [عملگرهای حسابی پایه][math] روی انواع عددی استفاده کنید.
این عملگرها عبارت‌اند از `+`، `-`، `*`، `/` و `%`.
هنگام استفاده از این عملگرها، نوع اعداد باید یکسان باشد.
تابع `fromIntegral` تبدیل را طوری انجام می‌دهد که نوع‌ها یکسان شوند.

### جمع، تفریق و ضرب

عملگر `+` برای جمع، عملگر `-` برای تفریق و عملگر `*` برای ضرب به کار می‌رود.

| عملگر | مثال |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### تقسیم

تقسیم برای تقسیم اعداد بر یکدیگر به کار می‌رود.
این کار با عملگر `/` انجام می‌شود.
نتیجه همیشه یک عدد اعشاری خواهد بود.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
در برخی زبان‌های برنامه‌نویسی، وقتی بر صفر تقسیم می‌کنید، نتیجه یک خطا خواهد بود.

در Haskell، وقتی بر صفر تقسیم می‌کنید، نتیجه `Infinity` یا `-Infinity` است.
تنها استثنا تقسیم صفر بر صفر است که نتیجه‌اش `NaN` (به معنای «عدد نیست») می‌شود.

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## تقسیم اعداد صحیح

تقسیم اعداد صحیح، بخش صحیح نتیجه‌ی تقسیم دو عدد صحیح را به دست می‌دهد.
Haskell دو تابع تقسیم اعداد صحیح دارد که در نحوه‌ی گرد کردن وقتی نتیجه منفی است با هم فرق می‌کنند:

- `div` به سمت پایین، یعنی به سمت منفی بی‌نهایت، گرد می‌کند.
- `quot` به سمت صفر گرد می‌کند.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
تقسیم بر صفر در تقسیم اعداد صحیح باعث ایجاد یک استثنا می‌شود.
این با تقسیم معمولی تفاوت دارد.
~~~~

### باقی‌مانده

باقی‌مانده‌ی تقسیم اعداد صحیح را می‌توان با `mod` یا `rem` به دست آورد.
این دو وقتی یکی از اعداد منفی است، در علامت نتیجه با هم فرق می‌کنند:

- `mod` همراه با `div` می‌آید و علامت نتیجه‌اش با علامت مقسوم‌علیه یکسان است.
- `rem` همراه با `quot` می‌آید و علامت نتیجه‌اش با علامت مقسوم یکسان است.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

برای هر `x` و `y` (که `y` صفر نباشد)، این قواعد برقرار است:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
وقتی هر دو عدد مثبت باشند، `div` و `quot` نتیجه‌ی یکسانی می‌دهند و `mod` و `rem` هم همین‌طور.
در این حالت `quot` و `rem` می‌توانند کمی کارآمدتر باشند، چون `div` و `mod` برای رسیدگی به اعداد منفی به گام‌های اضافی نیاز دارند.
~~~~

~~~~exercism/caution
تقسیم بر صفر هنگام استفاده از `mod` یا `rem` باعث ایجاد یک استثنا می‌شود.
این با تقسیم معمولی تفاوت دارد.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## توان‌رسانی

Haskell سه عملگر «به توان رساندن» دارد که هر کدام متفاوت کار می‌کنند و نوع آرگومان متفاوتی می‌گیرند.

- `**` دو **عدد اعشاری** می‌گیرد و برای محاسبه‌ی توان از لگاریتم استفاده می‌کند.
- `^^` یک **عدد اعشاری** می‌گیرد و آن را به توان یک **عدد صحیح** مثبت یا منفی می‌رساند.
- `^` **هر نوع عددی** را می‌گیرد و آن را به توان یک **عدد صحیح** مثبت می‌رساند.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## اولویت و پرانتز

Haskell پرانتز (`()`) را مجاز می‌داند که می‌توان از آن برای گروه‌بندی عبارت‌ها استفاده کرد.
این وقتی مفید است که بخواهید ترتیب عملیات را تغییر دهید.

وقتی از چند عملگر حسابی استفاده می‌کنید، ترتیب عملیات همانند ریاضیات است که به آن [PEMDAS][pemdas] هم می‌گویند.
این ترتیب چنین است: پرانتز (`()`) ، توان (`**`)، ضرب (`*`)، تقسیم (`/`)، جمع (`+`) و تفریق (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
