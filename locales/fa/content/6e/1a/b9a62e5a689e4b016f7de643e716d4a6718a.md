# مقدمه

## تهی‌پذیری

در C#، از `null` برای نشان دادن عدم وجود مقدار استفاده می‌شود. نوع _تهی‌پذیر_ نوعی است که مقادیر `null` را می‌پذیرد.

پیش از C# ۸.۰، نوع‌های ارجاعی همیشه تهی‌پذیر بودند و نوع‌های مقداری نبودند. یک نوع مقداری را می‌توان با افزودن یک علامت سؤال (`?`) به آن، تهی‌پذیر کرد.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

دسترسی به عضو متغیری که `null` است باعث خطای کامپایل نمی‌شود، اما باعث می‌شود که `NullReferenceException` در زمان اجرا پرتاب شود:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

برای مقابله با این اشتباه رایج، C# ۸ به شما این امکان را می‌دهد که ویژگی‌ای را انتخاب کنید که نوع‌های ارجاعی را به‌طور پیش‌فرض غیرتهی‌پذیر می‌کند:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

برای کار ایمن با مقادیر تهی‌پذیر، پیش از استفاده از آن‌ها بررسی کنید که `null` هستند یا نه:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }

    // Value is not null at this point, so no compile warning
    // and no runtime NullReferenceException being thrown
    return name.ToUpper();
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

عملگر `??` به شما امکان می‌دهد وقتی مقدار `null` است، یک مقدار پیش‌فرض برگردانید:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

عملگر `?.` به شما امکان می‌دهد اعضای یک مقدار را که ممکن است `null` باشد، به‌صورت ایمن فراخوانی کنید:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
