# پیوست دستورالعمل

## پیام‌های استثنا

گاهی لازم است [یک استثنا ایجاد کنید](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). وقتی این کار را می‌کنید، همیشه باید یک **پیام خطای معنادار** هم بگنجانید تا نشان دهید منبع خطا چیست. این کار خوانایی کد شما را بیشتر می‌کند و به‌طور چشمگیری به دیباگ کردن کمک می‌کند. در موقعیت‌هایی که می‌دانید منبع خطا از نوع مشخصی خواهد بود، می‌توانید یکی از [انواع خطای داخلی](https://docs.python.org/3/library/exceptions.html#base-classes) را ایجاد کنید، اما باز هم باید پیامی معنادار بگنجانید.

این تمرین به‌طور خاص لازم می‌داند که از [دستور `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) استفاده کنید و اگر به تابع `classify()` عددی داده شود که _عدد صحیح مثبت_ نیست، یک `ValueError` «پرتاب» کنید. تست‌ها فقط وقتی قبول می‌شوند که هم `exception` را `raise` کنید و هم پیامی همراه آن بگنجانید.

برای `raise` کردن یک `ValueError` همراه با پیام، پیام را به‌عنوان آرگومان به نوع `exception` بدهید:

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
