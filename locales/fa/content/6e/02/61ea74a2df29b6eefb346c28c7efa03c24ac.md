# مقدمه

در Common Lisp یک تابع می‌تواند چند آرگومان اختیاری داشته باشد.
این‌ها در «لیست لامبدا» با کلیدواژه‌ی `&optional` مشخص می‌شوند.
اگر پارامتری مشخص نشود، مقدار `nil` به آن نسبت داده می‌شود.
اگر چندین پارامتر اختیاری وجود داشته باشد، به ترتیب مقداردهی می‌شوند.
می‌توان مقادیر پیش‌فرضی برای پارامترهای اختیاری مشخص کرد.
در نهایت، می‌توان برای هر پارامتر اختیاری یک نماد مشخص کرد که بسته به اینکه آن پارامتر توسط فراخوانی‌کننده‌ی تابع ارائه شده باشد یا نه، به «درست» یا «غلط» مقید می‌شود (به این «پارامتر supplied-p» می‌گویند).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
