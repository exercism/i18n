# مقدمه

در JavaScript، مقادیر می‌توانند انواع مختلفی داشته باشند. تغییر نوع یک متغیر را می‌توان با «تبدیل نوع» صریح انجام داد. علاوه بر این، JavaScript هرگاه بافت ایجاب کند، «هم‌نوع‌سازی نوع» (تبدیل نوع ضمنی) را نیز انجام می‌دهد.

## تبدیل نوع

JavaScript مانند بسیاری از زبان‌های دیگر ساختاری برای تبدیل صریح به نوعی (متفاوت) ندارد، اما در عوض می‌توان از چند ابزار درون‌ساخت استفاده کرد.
به‌طور خاص، می‌توان از `Boolean`، `Number` و `String` به‌عنوان تابع برای تبدیل یک مقدار به نوع مربوطه استفاده کرد.

### تبدیل به مقدار منطقی (مقادیر صادق و کاذب)

با `Boolean(value)` می‌توانید هر مقداری را به یک مقدار منطقی تبدیل کنید.
مجموعه‌ی ثابتی از مقادیر وجود دارد، به نام مقادیر «کاذب»، که به `false` تبدیل می‌شوند.
مهم‌تر از همه، `false`، `0`، رشته‌ی خالی، `null`، `undefined` و `NaN` کاذب هستند.

برای همه‌ی مقادیر دیگر، `Boolean` مقدار `true` را برمی‌گرداند.
به این مقادیر «صادق» می‌گویند.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

توجه کنید که طبق قواعد توضیح‌داده‌شده، `'0'`، `'false'`، `[]` و `{}` در JavaScript **صادق** هستند.

### تبدیل به عدد

از `Number(value)` می‌توان برای تبدیل یک مقدار به عدد استفاده کرد.
فاصله‌های سفید در ابتدا و انتهای رشته نادیده گرفته می‌شوند و رشته‌ی خالی به `0` تبدیل می‌شود.
اگر بخواهید مقداری غیراولیه یا رشته‌ای را تبدیل کنید که نمایانگر یک عدد نیست، نتیجه `NaN` ([عدد نیست][mdn-nan]) خواهد بود.

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### تبدیل به رشته

با `String(value)` می‌توانید یک مقدار را به رشته تبدیل کنید.
برای مقادیر اولیه، نتیجه همان چیزی است که انتظار دارید.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

برای آرایه‌ها، تابع `String` تبدیل به رشته را روی هر عنصر اعمال می‌کند و نتیجه‌ها را با یک ویرگول به هم می‌چسباند.
می‌توانید خودتان هم [متد `join`][mdn-join] را به کار ببرید، مثلاً برای تغییر جداکننده.
توجه کنید که در این حالت‌ها `null` و `undefined` به رشته‌ی خالی تبدیل می‌شوند.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

برای اشیاء، `String` به‌طور پیش‌فرض متنی بی‌فایده برمی‌گرداند.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## هم‌نوع‌سازی نوع

در برخی بافت‌ها، JavaScript پیش از ارزیابی یک دستور، مقدار را به‌طور خودکار به نوع داده‌ی دیگری تبدیل می‌کند.
به این تبدیل ضمنی، هم‌نوع‌سازی نوع می‌گویند.

### بافت منطقی

وقتی مقداری که منطقی نیست در بافتی منطقی به کار می‌رود، JavaScript همان قواعد تابع `Boolean` را برای تبدیل ضمنی آن مقدار اعمال می‌کند.

هم‌نوع‌سازی به مقدار منطقی معمولاً در این موارد رخ می‌دهد:

- شرط یک [دستور شرطی][concept-conditionals]
- عملوند اول [عملگر سه‌تایی][mdn-ternary] `?`
- عملوند عملگر نقیض منطقی `!`
- عملوندهای عملگرهای AND منطقی `&&` و OR منطقی `||` (نتیجه‌ی عبارت یکی از عملوندهاست، نه لزوماً یک مقدار منطقی)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### بافت رشته‌ای

اگر عملگر جمع `+` روی مقادیر اولیه به کار رود و یکی از عملوندها رشته باشد، عملوند دیگر هم به رشته تبدیل می‌شود.
منطق تبدیل همانند زمانی است که از تابع `String` استفاده می‌کنید.
سپس دو رشته به هم می‌چسبند.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### بافت عددی

بسیاری از عملگرها، بر اساس منطق تابع `Number` که پیش‌تر توضیح داده شد، عملوندها را (در صورت نیاز) به عدد تبدیل می‌کنند.

- عملگرهای حسابی: `+` (اگر رشته‌ای در کار نباشد)، `-`، `*`، `/`، `%`، `**`
- عملگرهای جمع یکانی و منفی‌سازی یکانی: `+`، `-`
- عملگرهای رابطه‌ای (برای عملوندهای غیررشته‌ای): `>`، `>=`، `<`، `<=`
- عملگرهای بیتی: `|`، `&`، `^`، `~`

برای جزئیات بیشتر درباره‌ی هر یک از این عملگرها به [فهرست عملگرهای MDN][mdn-operators] مراجعه کنید.

برای پرهیز از اشتباه، بهتر است همیشه پیش از به کار بردن این عملگرها، `Number` را صریحاً فراخوانی کنید.
