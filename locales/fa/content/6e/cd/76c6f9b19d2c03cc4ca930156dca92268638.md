# مقدمه

اغلب می‌خواهیم کدی بنویسیم که بتواند بر اساس یک «شرط» شاخه‌بندی کند. در Elixir راه‌های زیادی برای انجام این کار وجود دارد، اما یکی از ساده‌ترین راه‌ها استفاده از `cond/1` است.

`cond` با یک یا چند شاخه، در ساده‌ترین شکل خود، اولین مسیر را دنبال می‌کند که به `true` ارزیابی می‌شود:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

اگر هیچ مسیری به `true` ارزیابی نشود، محیط اجرا یک خطا ایجاد می‌کند.
