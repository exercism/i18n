# مقدمه

یکی از اهداف اصلی Julia این است که بتواند محاسبات را روی داده‌های عددی، سریع و کارآمد انجام دهد.
_کلی_ داده‌ی عددی.

معمولاً این داده‌ها در آرایه‌ها (یا نوع مرتبط دیگری) ذخیره می‌شوند، بنابراین می‌توان گفت که آرایه‌ها در قلب زبان Julia قرار دارند.

آرایه‌ها می‌توانند اندازه‌ی دلخواه داشته باشند (فقط محدود به حافظه‌ی سخت‌افزار شما) و می‌توانند هر تعداد بُعد داشته باشند.

این مفهوم مقدماتی بر مبانی آرایه‌های یک‌بعدی تمرکز دارد، که به آن‌ها `Vector` می‌گویند.

## ساختن `Vector`

در Julia، یک `Vector` دنباله‌ی مرتبی از مقادیر است که می‌توان با شماره‌ی اندیس به آن‌ها دسترسی داشت.

ساده‌ترین راه برای ساختن یک `Vector` این است که مقادیر را داخل کروشه فهرست کنید:

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

نوع `Vector` با نوع هر عنصر مطابقت دارد.

_یعنی `Vector`ها باید همگن باشند (همه‌ی عناصر از یک نوع)؟_

تا حدی بله، و اگر بهترین کارایی را می‌خواهید توصیه می‌شود همین را هدف بگیرید.
با این حال، Julia می‌تواند (در صورت لزوم) با استفاده از نوع `Any` این محدودیت را دور بزند:

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

هنگام ساختن یک `Vector` خالی، Julia به‌طور پیش‌فرض نوع عنصر را `Any` در نظر می‌گیرد، اما می‌توان با حاشیه‌نویسی آرایه‌ی خالی با نوع عنصر موردنظر، آن را دقیق‌تر تعریف کرد.

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# اندیس‌گذاری

لطفاً این قاعده را بخوانید و به خاطر بسپارید:

- ***به‌طور پیش‌فرض، اندیس‌گذاری در Julia از ۱ شروع می‌شود، نه ۰***.

این برای هر کسی که از زبان‌های دیگر علم داده (R، Matlab، Fortran...) استفاده کرده باشد آشناست، اما ممکن است برای دانشمندان رایانه‌ای با پیشینه‌ی زبان‌های شبیه C تکان‌دهنده به نظر برسد.

در غیر این صورت، اندیس‌ها همان‌طور که حدس می‌زنید کار می‌کنند: کافی است آن‌ها را داخل کروشه بگذارید:

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

به سادگیِ اندیس‌گذاری با `end` (که بسیار مفید است) و `begin` (که احتمالاً نیست) توجه کنید.

برنامه‌نویسان Python ممکن است درباره‌ی اندیس‌های منفی کنجکاو باشند.
دنبالشان نگردید: این‌ها بخشی از Julia نیستند و باعث خطای `BoundsError` می‌شوند، همان‌طور که هر اندیسی کوچک‌تر از ۱ یا بزرگ‌تر از `length(squares)` چنین می‌کند.

## عملیات روی `Vector`

`Vector`ها در Julia _تغییرپذیر_ هستند: می‌توانیم محتویات خانه‌های تک‌تک را تغییر دهیم.

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

توابع زیادی برای دستکاری `Vector`ها در دسترس است، هرچند مستندات Julia آن‌ها را به‌جای بردار به «مجموعه‌ها» تعمیم می‌دهد.

توجه کنید که بنا بر قرارداد، توابعی که ورودی خود را تغییر می‌دهند در اسمشان `!` دارند.
کامپایلر این را اجبار نمی‌کند، اما در دنیای Julia یک قرارداد بسیار _قوی_ است.

این‌ها چند تا از توابع مفید هستند:

- برای افزودن مقادیر به انتهای `Vector`، از `push!()` استفاده کنید.
- برای حذف آخرین مقدار، از `pop!()` استفاده کنید.
- برای کار روی ابتدای `Vector`، توابع متناظر `pushfirst!()` و `popfirst!()` هستند.
- برای درج یا حذف یک عنصر در هر موقعیتی، `insert!()` و `deleteat!()` وجود دارند.

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
