# مقدمه

## توابع چندشاخه‌ای

Elixir با اجازه دادن به توابع برای داشتن چندین شاخه، به رعایت **Open-Closed Principle** کمک می‌کند؛ بنابراین به‌جای منطق کنترلی پراکنده و سخت‌کدشده، می‌توان توابعی هدفمند نوشت که افزودن یا حذف رفتار را آسان می‌کنند.

Elixir برای نوشتن این‌ها، «شاخه‌های متعدد تابع» و «گاردها» را در اختیار شما می‌گذارد:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

هنگام اجرا، Elixir از بالای فایل منبع به پایین بررسی می‌کند که کدام شاخه‌ی تابع را فراخوانی کند.

متغیرهای بلااستفاده باید با زیرخط شروع شوند.

## گاردها

گاردها جلوی این را می‌گیرند که Elixir بر اساس ارزیابی آرگومان‌ها توسط توابع گارد، تابع را فراخوانی کند. گاردها با کلیدواژه‌ی `when` شروع می‌شوند و پس از آن یک عبارت منطقی می‌آید. توابع گارد، توابعی ویژه هستند که:

- باید خالص باشند و هیچ حالت سراسری‌ای را تغییر ندهند.
- باید مقادیر دقیقاً `true` یا `false` برگردانند.

فهرستی از گاردهای رایج را می‌توانید در [مستندات Elixir][kernel-guards] پیدا کنید. این فهرست شامل بررسی نوع، حساب پایه، مقایسه‌ها و عملگرهای صرفاً منطقی است.

## آرگومان‌های پیش‌فرض

توابع می‌توانند برای یک یا چند آرگومان مقدار پیش‌فرض تعریف کنند. بیایید این تابع را در نظر بگیریم:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

هنگام کامپایل، Elixir برای `number/0` (بدون آرگومان) و `number/1` (یک آرگومان) تعریف تابع می‌سازد.

اگر بیش از یک آرگومان مقدار پیش‌فرض داشته باشد، مقادیر پیش‌فرض از چپ به راست روی تابع اعمال می‌شوند تا آرگومان‌های جاافتاده را پر کنند.

اگر تابع بیش از یک شاخه داشته باشد، آرگومان‌های پیش‌فرض باید در سرآیند تابع (تابعی بدون بدنه) و پیش از شاخه‌های تابع تعریف شوند:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
