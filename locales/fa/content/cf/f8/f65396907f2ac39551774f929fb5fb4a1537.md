# مقدمه

در این تمرین باید منطق را به‌صورت شرطی اجرا کنید. رایج‌ترین روش انجام این کار در C# استفاده از دستور `if/else` است:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

شرط یک دستور `if` باید از نوع `bool` باشد. در C# مفهومی به اسم مقادیر _truthy_ وجود ندارد.
