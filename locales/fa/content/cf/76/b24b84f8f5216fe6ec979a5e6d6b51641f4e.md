# نصب

## پیشنیازهای مسیر زبان PowerShell

مسیر زبان PowerShell در Exercism نیاز دارد که موارد زیر روی سیستم شما نصب باشند:

- PowerShell یا Windows PowerShell Core
- ماژول چارچوب test و mock به اسم Pester نصب شده باشد

(پینوشت: پشتیبانی از PowerShell محدود به اصلاحات حیاتی است. PowerShell Core به‌طور مستمر نگهداری می‌شود و پشتیبانی چندسکویی گسترده‌تری دارد.)

### نصب PowerShell

PowerShell روی همه‌ی سیستم‌عامل‌های Windows از Windows 7 SP1 به بعد از پیش نصب شده است.

آخرین نسخه‌ی PowerShell و دستورالعمل‌های نصب برای همه‌ی پلتفرم‌ها (Linux، macOS و Windows) را [اینجا][installation] پیدا می‌کنید.

Source code و نصب دستی [PowerShell][source-code] هم در دسترس است.

### نصب و به‌روزرسانی چارچوب Pester

[Pester][pester] چارچوب test زبان PowerShell است.
از نسخه‌ی 4.0.9 به بعد با PowerShell Core روی Windows، Linux و MacOS سازگار است (با برخی محدودیت‌ها)

روی Windows 10 از پیش نصب شده است، اما توصیه می‌شود با اجرای دستور PowerShell زیر آن را به‌روزرسانی کنید:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

برای به‌روزرسانی‌های بعدی، این دستور را اجرا کنید:

```PowerShell
Update-Module -Name Pester
```

در صورت نیاز، دستورالعمل‌های بیشتر برای نصب در این نشانی در دسترس است: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## استفاده از یک IDE

اگر می‌خواهید ویرایش با امکانات کامل‌تری داشته باشید، احتمالاً به یک IDE نیاز دارید.
این‌ها محبوب‌ترین IDEهایی هستند که از ساخت پروژه‌های PowerShell پشتیبانی می‌کنند:

### همه‌ی پلتفرم‌ها

- [PowerShell ISE (محیط اسکریپت‌نویسی یکپارچه)][ise]، IDE گرافیکی از پیش نصب‌شده‌ای که همراه PowerShell عرضه می‌شود (فقط Windows).
  برای اجرای PowerShell ISE، در کنسول PowerShell عبارت `powershell_ise.exe` را تایپ کنید.
- [Visual Studio Code][vsc] به همراه [افزونه‌ی PowerShell][vsc-extension].
  Visual Studio Code همچنین به شما امکان می‌دهد testها را اجرا کنید و code خودتان را debug کنید.
- [Sublime Text 3][sublime] به همراه [بسته‌ی PowerShell][sublime-package].
