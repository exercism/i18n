# متدهای `String`

`String` چندین متد دارد که می‌توان از آن‌ها برای دست‌کاری رشته‌ها استفاده کرد.  
این متدها روی خود رشته فراخوانی می‌شوند و اغلب به هم زنجیره می‌شوند تا چندین عملیات را روی یک رشته انجام دهند.

در ادامه فهرستی از رایج‌ترین متدها آمده است.
برای فهرست کامل متدها، به [مستندات API `String`][string-api] مراجعه کنید.

## `String#upcase` و `String#downcase`

متد [`upcase`][upcase] یک رشته‌ی جدید برمی‌گرداند که همه‌ی نویسه‌های آن به حروف بزرگ تبدیل شده‌اند.

```crystal
"hello".upcase
# => "HELLO"
```

متد [`downcase`][downcase] یک رشته‌ی جدید برمی‌گرداند که همه‌ی نویسه‌های آن به حروف کوچک تبدیل شده‌اند.

```crystal
"HELLO".downcase
# => "hello"
```

## `String#capitalize` و `String#camelcase` و `String#underscore` و `String#titleize`

چندین متد می‌توانند تبدیل حروف بزرگ و کوچک را به شکل خاص‌تری انجام دهند.
این می‌تواند هنگام تبدیل یک رشته به قالبی مشخص مفید باشد.
در ادامه فهرستی از رایج‌ترین متدها آمده است:

| متد                            | توضیحات                                                                                                        | مثال                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | اولین حرف را به حروف بزرگ و بقیه را به حروف کوچک تبدیل می‌کند                                                   | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | زیرخط را به نگارش camelcase تبدیل می‌کند                                                                                   | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | مثل `String#camelcase` است، اما نویسه‌ی اول را کوچک باقی می‌گذارد                                                 | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | همه‌ی نویسه‌ها را به حروف کوچک تبدیل می‌کند و بین یک حرف کوچک و یک حرف بزرگ، زیرخط می‌گذارد | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | حرف اول هر کلمه را بزرگ و بقیه را کوچک می‌کند                                                   | `"the great gatsBY" # => "The Great Gatsby"`         |

## `String#sub` و `String#gsub`

Crystal متدهایی برای جایگزین کردن بخش‌هایی از یک رشته دارد.
به این‌ها [`sub`][sub] (_جایگزینی_) و [`gsub`][gsub] (_جایگزینی سراسری_) می‌گویند.

این متدها می‌توانند یک رشته، یک نویسه یا یک عبارت باقاعده را به عنوان آرگومان اول و یک رشته یا یک نویسه را به عنوان آرگومان دوم بگیرند.
آرگومان اول بخشی از رشته است که جایگزین می‌شود و آرگومان دوم جایگزین است.
`Char` و عبارت باقاعده در مفاهیم بعدی توضیح داده می‌شوند.

متد `sub` اولین رخداد آرگومان اول را با آرگومان دوم جایگزین می‌کند.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

متد `gsub` مثل `sub` کار می‌کند، اما همه‌ی رخدادهای آرگومان اول را با آرگومان دوم جایگزین می‌کند.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## `String#chomp` و `String#strip`

از `chomp` و `strip` می‌توان برای حذف نویسه‌های ناخواسته از یک رشته استفاده کرد.

متد [`chomp`][chomp] به طور پیش‌فرض آخرین نویسه‌های `\r`، `\n` یا `\r\n` را از یک رشته حذف می‌کند.
اگر این متد با یک آرگومان فراخوانی شود، مقدار داده‌شده را از انتهای رشته حذف می‌کند، به شرط آن که در انتهای رشته وجود داشته باشد.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

متد [`strip`][strip] به طور پیش‌فرض همه‌ی فاصله‌های خالی را از ابتدا و انتهای یک رشته حذف می‌کند.
اگر این متد با یک آرگومان فراخوانی شود، آن آرگومان را از ابتدا و انتهای رشته حذف می‌کند، به شرط آن که در ابتدا یا انتهای رشته وجود داشته باشد.

```crystal
" hello ".strip
# => "hello"
```

## `String#reverse`

می‌توانید از متد [`reverse`][reverse] برای معکوس کردن یک رشته استفاده کنید.
این متد یک رشته‌ی جدید برمی‌گرداند که نویسه‌های آن به ترتیب معکوس هستند.

```crystal
"hello".reverse
# => "olleh"
```

## `String#index`

از متد [`index`][index] می‌توان برای یافتن اندیس یک نویسه در یک رشته استفاده کرد.
متد `index` یک `String`، یک `Char` یا یک عبارت باقاعده را به عنوان آرگومان می‌گیرد.
می‌تواند یک آرگومان دوم اختیاری هم بگیرد تا اندیسی را مشخص کند که جست‌وجو از آن آغاز می‌شود.
متد `index` اندیس اولین رخداد آرگومان را برمی‌گرداند.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## `String#delete_at`

می‌توانید از متد [`delete_at`][delete_at] برای حذف یک نویسه از یک رشته استفاده کنید.
متد `delete_at` یک اندیس را به عنوان آرگومان می‌گیرد و نویسه‌ی موجود در آن اندیس را حذف می‌کند.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## `String#insert`

از متد [`insert`][insert] می‌توان برای درج یک رشته در اندیسی مشخص استفاده کرد.
متد `insert` یک اندیس را به عنوان آرگومان اول و یک رشته را به عنوان آرگومان دوم می‌گیرد.
متد `insert` یک رشته‌ی جدید برمی‌گرداند که آرگومان دوم در آن اندیس درج شده است.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
