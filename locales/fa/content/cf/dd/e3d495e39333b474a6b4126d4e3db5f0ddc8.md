# مقدمه

## سازنده‌ها

ساختن یک نمونه از یک _کلاس_ با فراخوانی _سازنده_ی آن از طریق عملگر `new` انجام می‌شود. سازنده نوع خاصی از متد است که هدفش مقداردهی اولیه به نمونه‌ای است که تازه ساخته شده. سازنده‌ها شبیه متدهای معمولی هستند، اما نوع بازگشتی ندارند و اسمشان با اسم کلاس یکی است.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

سازنده‌ها هم مانند متدهای معمولی می‌توانند پارامتر داشته باشند. پارامترهای سازنده معمولاً به‌صورت فیلدهای (خصوصی) ذخیره می‌شوند تا بعداً به آن‌ها دسترسی داشته باشیم، یا در یک محاسبه‌ی یک‌باره به کار می‌روند. آرگومان‌ها را می‌توان به سازنده‌ها پاس داد، درست مثل پاس دادن آرگومان‌ها به متدهای معمولی.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
