# مقدمه

یک تابع به شما امکان می‌دهد کد را در قالب یک واحد قابل‌استفاده‌ی مجدد قرار دهید.
این واحد از کلیدواژه‌ی `func`، اسم تابع و فهرستی جداشده با کاما از صفر یا چند پارامتر و نوع آن‌ها که داخل پرانتز می‌آید، تشکیل شده است.

## پارامترهای تابع

نوع همه‌ی پارامترها باید صریحاً مشخص شود. برای پارامترها استنتاج نوع وجود ندارد.
پارامترها مقدار پیش‌فرض ندارند، بنابراین همه‌ی پارامترهای تابع الزامی‌اند.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

پارامترهای هم‌نوع را می‌توان با هم اعلام کرد و پس از آن‌ها تنها یک اعلان نوع نوشت.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## پارامترها در برابر آرگومان‌ها

بیایید به‌سرعت دو اصطلاح را که اغلب با هم اشتباه گرفته می‌شوند بررسی کنیم: `parameters` و `arguments`.
پارامترهای تابع، اسم‌هایی هستند که در امضای تابع تعریف می‌شوند، مانند `greeting` و `name` در تابع `PrintGreetingName` بالا.
آرگومان‌های تابع، مقادیر مشخصی هستند که هنگام فراخوانی تابع به پارامترهای آن فرستاده می‌شوند.
برای نمونه، در مثال زیر، `"Hello"` و `"Katrina"` آرگومان‌هایی هستند که به پارامترهای `greeting` و `name` فرستاده می‌شوند:

```go
PrintGreetingName("Hello", "Katrina")
```

## مقادیر بازگشتی

پس از پارامترهای تابع، صفر یا چند مقدار بازگشتی می‌آید که نوع آن‌ها هم باید صریحاً مشخص شود.
مقدار بازگشتی تکی بدون پرانتز نوشته می‌شود و مقادیر بازگشتی متعدد داخل پرانتز قرار می‌گیرند.
مقادیر با استفاده از کلیدواژه‌ی `return` از تابع به کدی که آن را فراخوانی کرده بازگردانده می‌شوند.
می‌تواند چندین دستور `return` در یک تابع وجود داشته باشد.
اجرای تابع به‌محض رسیدن به یکی از این دستورهای `return` پایان می‌یابد.
اگر قرار باشد چند مقدار از یک تابع بازگردانده شود، با کاما از هم جدا می‌شوند.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## فراخوانی توابع

فراخوانی یک تابع با مشخص کردن اسم تابع و فرستادن آرگومان برای هر یک از پارامترهای آن در پرانتز انجام می‌شود.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## مقادیر بازگشتی نام‌گذاری‌شده و بازگشت لخت

علاوه بر پارامترها، مقادیر بازگشتی را هم می‌توان به‌صورت اختیاری نام‌گذاری کرد.
اگر از مقادیر بازگشتی نام‌گذاری‌شده استفاده شود، یک دستور `return` بدون آرگومان همان مقادیر را بازمی‌گرداند.
به این کار «بازگشت لخت» می‌گویند.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
