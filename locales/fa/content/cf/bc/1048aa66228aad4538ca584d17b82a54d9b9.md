# دستورالعمل‌ها

شما در حال ساختن یک بازی آنلاین ساده هستید که در آن یک دوست می‌تواند یک عدد مخفی را حدس بزند. می‌خواهید کمی بازخورد بدهید، اما با یک حدس پاسخ را لو ندهید. باید تابعی طراحی کنید که بسته به این که حدس با عدد مخفی چه رابطه‌ای دارد، پاسخ‌های متفاوتی بدهد.

| شرط                                                           | پاسخ           |
| ------------------------------------------------------------- | -------------- |
| وقتی حدس با عدد مخفی مطابقت دارد                              | "Correct"      |
| وقتی حدس یکی بیشتر یا یکی کمتر از عدد مخفی است                | "So close"     |
| وقتی حدس بزرگ‌تر از عدد مخفی است                               | "Too high"     |
| وقتی حدس کوچک‌تر از عدد مخفی است                               | "Too low"      |
| وقتی حدسی زده نمی‌شود                                          | "Make a guess" |

همه‌ی حدس‌ها و عددهای مخفی، اعداد صحیح هستند.

## 1. پاسخ را برای زمانی بسازید که حدس با عدد مخفی مطابقت دارد

تابع `compare/2` را پیاده‌سازی کنید که دو آرگومان می‌گیرد، `secret_number` و `guess`، که هر دو عدد صحیح هستند.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. پاسخ را برای زمانی بسازید که حدس بزرگ‌تر از عدد مخفی است

تابع `compare` را تغییر دهید تا به حدس‌هایی که از عدد مخفی بزرگ‌ترند پاسخ دهد.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. پاسخ را برای زمانی بسازید که حدس کوچک‌تر از عدد مخفی است

تابع `compare` را تغییر دهید تا به حدس‌هایی که از عدد مخفی کوچک‌ترند پاسخ دهد.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. پاسخ‌ها را برای زمانی بسازید که حدس یکی بیشتر یا یکی کمتر از عدد مخفی است

تابع `compare` را تغییر دهید تا به حدس‌هایی که به عدد مخفی نزدیک‌اند پاسخ دهد.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. پاسخ را برای زمانی بسازید که حدسی وجود ندارد

تابع `compare` را تغییر دهید تا وقتی حدسی وجود ندارد پاسخ دهد.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
