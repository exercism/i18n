# مقدمه

برخلاف بسیاری از زبان‌های دیگر، در JavaScript دو موجودیت متفاوت وجود دارد که نشان‌دهنده‌ی نبود یک مقدار (معنادار) هستند.
یکی `null` و دیگری `undefined`.

## `null`

مقدار ابتدایی `null` به‌عنوان یک «مقدار خالی» تعمدی برای متغیرهایی از هر نوع به کار می‌رود.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

می‌توانید با استفاده از [عملگر برابری سخت‌گیرانه][mdn-strict-equality] `===` بررسی کنید که آیا یک متغیر `null` است یا نه.

```javascript
let name = null;

name === null;
// => true
```

## `undefined`

> متغیری که مقداری به آن نسبت داده نشده است، از نوع `undefined` است.[^1]

یعنی در حالی که `null` نشان‌دهنده‌ی یک مقدار خالی است (اما همچنان یک مقدار)، `undefined` نشان‌دهنده‌ی نبود کامل یک مقدار است. 🤯

`undefined` در موقعیت‌های مختلفی ظاهر می‌شود.

- اگر متغیری بدون مقدار اعلام شود (مقداردهی اولیه انجام نشود)، `undefined` است.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- اگر بخواهید به ازای کلیدی ناموجود در یک شیء به مقداری دسترسی پیدا کنید، `undefined` دریافت می‌کنید.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- اگر یک تابع مقداری برنگرداند، نتیجه `undefined` است.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- اگر آرگومانی به یک تابع پاس داده نشود، `undefined` است، مگر اینکه آن آرگومان مقدار پیش‌فرض داشته باشد.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

می‌توانید با استفاده از عملگر برابری سخت‌گیرانه `===` بررسی کنید که آیا یک متغیر `undefined` است یا نه.

```javascript
let name;

name === undefined;
// => true
```

## زنجیره‌سازی اختیاری

اگر بخواهید مقدار تودرتویی را در یک شیء بازیابی کنید اما کلید والد وجود نداشته باشد، JavaScript یک خطا پرتاب می‌کند.
برای پرهیز آسان از این کار، زنجیره‌سازی اختیاری در سال ۲۰۲۰ به مشخصات زبان افزوده شد.
با عملگر زنجیره‌سازی اختیاری `?.` می‌توانید مطمئن شوید که JavaScript فقط زمانی تلاش می‌کند به کلید تودرتو دسترسی پیدا کند که والد آن `null` یا `undefined` نباشد.
در غیر این صورت `undefined` برگردانده می‌شود.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## ادغام پوچی

موقعیت‌هایی هست که می‌خواهید در صورت `null` یا `undefined` بودن یک متغیر، یک مقدار پیش‌فرض اعمال کنید (اما فقط در همان صورت).
برای این کار، عملگر ادغام پوچی `??` در سال ۲۰۲۰ معرفی شد.
این عملگر عملوند سمت راست را فقط زمانی برمی‌گرداند که عملوند سمت چپ `null` یا `undefined` باشد.
در غیر این صورت، عملوند سمت چپ برگردانده می‌شود.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
