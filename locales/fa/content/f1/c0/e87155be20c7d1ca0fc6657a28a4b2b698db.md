# درباره

[Java](https://go.java/index.html) یکی از محبوب‌ترین زبان‌های برنامه‌نویسی موجود است و این محبوبیت را مدیون انعطاف‌پذیری و سازگاری‌اش است. از آن به‌طور گسترده برای توسعه‌ی نرم‌افزار، اپلیکیشن‌های موبایل و ساخت سیستم‌های بزرگ‌تر استفاده می‌شود.

Java در سال ۱۹۹۵ متولد شد و نگهداری آن بر عهده‌ی [Oracle](https://www.oracle.com/index.html) است. با اینکه Java به‌اندازه‌ی بعضی از زبان‌های تازه‌ی این روزها جوان نیست، هنوز واقعاً محبوب است. این زبان طوری طراحی شده که سریع، امن، قابل‌اعتماد، مناسب برای تازه‌کاران و بسیار قابل‌حمل باشد. دلیل این قابلیت حمل آن است که Java روی [ماشین مجازی Java - JVM](https://en.wikipedia.org/wiki/Java_virtual_machine) اجرا می‌شود که با چند سکوی مختلف سازگار است. اپلیکیشن‌های Android هم با Java توسعه داده می‌شوند، چون [سیستم‌عامل Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) در محیطی از زبان Java اجرا می‌شود.

جامعه‌ی Java بسیار بزرگ است! برای نمونه، GitHub بیش از ۱٫۵ میلیون پروژه‌ی Java دارد. همچنین گفتنی است که Java دومین جامعه‌ی بزرگ را در [StackOverflow](https://stackoverflow.com/questions/tagged/java) دارد! این موضوع مهم است، چون هرچه جامعه‌ی یک زبان برنامه‌نویسی بزرگ‌تر باشد، احتمال اینکه پشتیبانی بیشتری دریافت کنید هم بیشتر می‌شود.

Java همچنین مجموعه‌ای قدرتمند و خوش‌طراحی از [APIها - رابط‌های برنامه‌نویسی کاربردی](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) دارد که می‌توان از آن‌ها برای کارهای گوناگونی مانند اتصال به پایگاه داده، شبکه، ورودی/خروجی، تجزیه‌ی XML، ابزارهای کمکی و بسیار بیشتر استفاده کرد.

از لپ‌تاپ‌ها تا مراکز داده، از کنسول‌های بازی تا ابررایانه‌های علمی، از گوشی‌های همراه تا اینترنت، [Java همه‌جا هست](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
