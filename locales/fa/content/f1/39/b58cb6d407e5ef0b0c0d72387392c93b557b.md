# Instructions

تادگ کتابخانه‌ی Erlang عالی برای کمک به پروژه‌اش پیدا کرده است. چون این کتابخانه‌ی Erlang قدیمی‌تر است، برای ذخیره‌ی داده‌ها از ماژول `gb_trees` استفاده می‌کند نه از ماژول جدیدتر `maps`.

به تادگ کمک کنید و برای کار با `gb_trees` در Gleam، نوع خارجی و تابع بسازید.

## 1. تعریف «نوع خارجی» `GbTree`

نوع `GbTree` باید دو «پارامتر نوع» داشته باشد: یک نوع کلید و یک نوع مقدار. نباید هیچ «سازنده»ای داشته باشد و همین آن را به یک نوع خارجی تبدیل می‌کند.

## 2. تعریف تابع `new_gb_tree`

تابع `new_gb_tree` نباید هیچ «آرگومان»ی بگیرد و باید یک `GbTree` خالی برگرداند.

باید از [تابع `gb_trees:empty/0`][empty] از کتابخانه استاندارد Erlang استفاده کند.

## 3. تعریف تابع `insert`

تابع `insert` باید یک `GbTree`، یک کلید و یک مقدار را برای درج در «درخت» بگیرد. باید یک `GbTree` جدید با کلید و مقدار درج‌شده برگرداند.

این تابع باید سه آرگومان بگیرد:
1. `GbTree`ی که باید در آن درج شود.
2. کلیدی که باید درج شود.
3. مقداری که باید درج شود.

باید از [تابع `gb_trees:insert/3`][insert] از کتابخانه استاندارد Erlang استفاده کند.

## 4. تعریف تابع `delete`

تابع `delete` باید یک `GbTree` و یک کلید را برای حذف از درخت بگیرد. باید یک `GbTree` جدید با کلید و مقدار حذف‌شده برگرداند.

این تابع باید دو آرگومان بگیرد:
1. `GbTree`ی که باید از آن حذف شود.
2. کلیدی که باید حذف شود.

باید از [تابع `gb_trees:delete_any/2`][delete_any] از کتابخانه استاندارد Erlang استفاده کند.
