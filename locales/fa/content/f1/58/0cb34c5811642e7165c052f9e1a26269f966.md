### معرفی

به اولین تمرین مسیر Java خوش آمدید!

این سند راهنمایی گام‌به‌گام برای حل این تمرین است.
این دستورالعمل‌ها روی Windows، macOS و Linux به یک اندازه کار می‌کنند.

حتی اگر با مبانی Java آشنایی دارید، مرور این راهنما می‌تواند مفید باشد؛ چون به شما کمک می‌کند خروجی ابزاری به اسم Gradle را بفهمید، ابزاری که با آن کدمان را کامپایل و تست می‌کنیم. همچنین شما را با برخی الگوهای مشترک همه‌ی تمرین‌های این مسیر آشنا می‌کند.

### ساختار تمرین

وقتی یک تمرین جدید Java را دریافت می‌کنید، این موارد را به دست می‌آورید:

- __یک یا چند فایل تست__ (همیشه).
این فایل‌ها در پوشه‌ی `src/test/java` قرار دارند و مجموعه‌ای از تست‌ها را تعریف می‌کنند که راه‌حل ما باید آن‌ها را پاس کند تا بتوانیم با خیال راحت بگوییم که کار می‌کند.
- __یک یا چند فایل شروع__ (در ابتدا).
اگر ارائه شده باشند، در پوشه‌ی `src/main/java` قرار دارند و پوسته‌ی کلاس‌هایی را تعریف می‌کنند که برای حل مسئله‌ی فعلی به آن‌ها نیاز دارید.

### حل «Hello, World!»

می‌توانید از ویرایشگر آنلاین ما برای نوشتن راه‌حل و اجرای تست‌ها استفاده کنید، اما اگر می‌خواهید مسئله را حل کنید و تست‌ها را به‌صورت محلی اجرا کنید، پیوندهای زیر را ببینید:

- [نصب Java][Installing Java]
- [کار به‌صورت محلی][Working Locally]
- [تست به‌صورت محلی در مسیر Java][Testing locally on the java track]

### گام ۱: اصلاح راه‌حل

چه به‌صورت محلی کار کنید و چه از ویرایشگر آنلاین استفاده کنید، باید کد زیر را ببینید:

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

هدف این است که کد ارائه‌شده را طوری تغییر دهید که به جای `"Goodbye, Mars!"` متن `"Hello, World!"` را تولید کند.

### گام ۲: اجرای تست‌ها

پس از اعمال اصلاحات و پیاده‌سازی راه‌حل، دوباره تست‌ها را اجرا کنید.
می‌توانید تست‌ها را با ویرایشگر آنلاین یا به‌صورت محلی روی سیستم خودتان اجرا کنید:

- برای اجرای تست‌ها در ویرایشگر آنلاین، روی دکمه‌ی «Run Tests» کلیک کنید.
- برای اجرای تست‌ها به‌صورت محلی، [تست در مسیر Java][Testing locally on the java track] را ببینید. اگر تست‌ها شکست خوردند، اشکالی ندارد! ببینید پیام خطا چه می‌گوید، کدتان را تغییر دهید و دوباره تست کنید. وقتی تست‌ها پاس شدند، به گام بعدی بروید.

### گام ۳: ارسال اولین نسخه‌ی شما

وقتی راه‌حل کارآمدی داشته باشیم که آن را بررسی کرده‌ایم، آماده‌ایم آن را در exercism.org ارسال کنیم.
می‌توانید راه‌حل را با ویرایشگر آنلاین یا به‌صورت محلی با [Exercism CLI][Working Locally] ارسال کنید:

- برای ارسال تمرین به‌صورت محلی، ابتدا اگر قبلاً این کار را نکرده‌اید [Exercism CLI را نصب کنید][Working Locally] و سپس فایل‌های راه‌حل‌تان را ارسال کنید، مثلاً:

  ```sh
  exercism submit <file location>
  ```

- `<file location>` را با مسیر نسبی فایل `Greeter.java` خودتان جایگزین کنید؛ بنابراین اگر در `C:\exercism\java\hello-world` کار می‌کنید، دستور چنین خواهد بود:

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- اگر می‌خواهید از ویرایشگر آنلاین برای ارسال راه‌حل استفاده کنید، فقط روی دکمه‌ی «Submit» کلیک کنید!

برای نگاهی دقیق‌تر به ارسال راه‌حل به‌صورت محلی:

- [ارسال به‌صورت محلی][Working Locally]

### گام‌های بعدی

از اینجا به بعد، مسیرهای متعددی پیش روی شماست.

هر تصمیمی که برای ادامه بگیرید، صمیمانه امیدواریم که یاد بگیرید و از عضویت در این جامعه لذت ببرید.
اگر هر زمان به کمک نیاز داشتید، در کمک خواستن تردید نکنید.

موفق باشید!

### به تمرین بعدی بروید

تمرین‌های بیشتری هست که می‌توانید با آن‌ها تمرین کنید.
سراغ تمرین بعدی بروید! (مثالی برای `two-fer`)

```sh
exercism download --exercise=two-fer --track=java
```

### مربی شوید

قلب Exercism گفت‌وگوهایی است که درباره‌ی شیوه‌های کدنویسی شکل می‌گیرد.
تمرین کردن حتماً لذت‌بخش است، اما درگیر شدن با دیگران، هم در تلاش‌های آن‌ها و هم در تلاش‌های خودتان، همان چیزی است که به شما بازخورد می‌دهد.
این بازخورد می‌تواند نشان دهد کجاها خوب عمل می‌کنید و کجاها ممکن است به بهبود نیاز داشته باشید.

برخی از راه‌حل‌های ارسالی تقریباً با مال شما یکسان خواهند بود و برخی کاملاً متفاوت.
دیدن هر دو دسته می‌تواند آموزنده و جالب باشد.

مربی‌ها راه‌حل‌های ارسالی مربوط به مسیری را که برای مربیگری انتخاب کرده‌اند بررسی می‌کنند تا به کاربران کمک کنند تا حد امکان بیشتر یاد بگیرند.

برای مطالعه‌ی بیشتر درباره‌ی مربیگری، به [مستندات Exercism][Mentoring] بروید.
