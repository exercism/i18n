# دستورالعمل‌ها

یک بانک شلوغ به مشتریان منتظر بر اساس «اولویت» رسیدگی می‌کند، نه به ترتیبی که رسیده‌اند. به هر مشتری وقتی بلیت می‌گیرد یک شماره‌ی اولویت داده می‌شود و متصدی باجه همیشه اول به کم‌ترین شماره رسیدگی می‌کند (`1` فوری‌ترین است). یک «هیپ کمینه» صف انتظار ایده‌آل است.

## 1. صف را باز کنید

`new-queue` را تعریف کنید؛ این تابع چیزی نمی‌گیرد و یک صف اولویت‌دار تازه و خالی برمی‌گرداند.

```factor
new-queue
! => an empty priority queue
```

## 2. یک مشتری اضافه کنید

`join-queue` را تعریف کنید؛ این تابع اسم مشتری، یک شماره‌ی اولویت و یک صف می‌گیرد. مشتری را به صف اضافه می‌کند و صف را برمی‌گرداند، بنابراین می‌توان مشتری‌ها را یکی پس از دیگری اضافه کرد.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. نفر بعدی کیست؟

`next-name` را تعریف کنید؛ این تابع یک صف می‌گیرد و اسم مشتری‌ای را برمی‌گرداند که باید بعدی به او رسیدگی شود (کسی که کم‌ترین شماره‌ی اولویت را دارد)، بدون این که او را از صف حذف کند.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. به همه رسیدگی کنید

`serve-all` را تعریف کنید؛ این تابع یک صف می‌گیرد و اسم همه‌ی مشتریان منتظر را به همان ترتیبی برمی‌گرداند که به آن‌ها رسیدگی می‌شود.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
