# مقدمه

در C++ می‌توانید مقادیر را با عملگرهای مقایسه با هم مقایسه کنید.

| مقایسه            | عملگر     |
| ------------------| --------- |
| مساوی             | `==`      |
| نامساوی           | `!=`      |
| کوچک‌تر            | `<`       |
| کوچک‌تر یا مساوی   | `<=`      |
| بزرگ‌تر            | `>`       |
| بزرگ‌تر یا مساوی   | `>=`      |

نتیجه‌ی این مقایسه‌ها همیشه یک مقدار «منطقی» است:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

عملگرهای `==` و `!=` به‌ترتیب بررسی می‌کنند که یک مقدار با مقدار دیگری برابر است یا نه.
چند مثال رایج:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

سایر عملگرها بررسی می‌کنند که یک مقدار از مقدار دیگری بزرگ‌تر (`>`)، بزرگ‌تر یا مساوی (`>=`)، کوچک‌تر (`<`) یا کوچک‌تر یا مساوی (`<=`) است.
این نوع مقایسه برای اعداد و رشته‌ها در دسترس است.
هنگام مقایسه‌ی رشته‌ها، ترتیب واژه‌نامه‌ای (که به آن ترتیب لغت‌نامه‌ای هم می‌گویند) رعایت می‌شود.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
