# راهنمایی‌ها

## 1. بررسی اینکه آیا سینمارو مستحق تخفیف سالمندان است

- از [عملگر سه‌گانه][doc-ternary] برای بررسی سن سینمارو استفاده کنید.

## 2. بررسی اینکه آیا سینمارو اجازه دارد فیلم‌های ترسناک ببیند

- سن سینمارو را با حداقل سن مجاز برای دیدن فیلم‌های ترسناک [مقایسه کنید][doc-integer-gtoe]. در این کار حتی به عملگر سه‌گانه هم نیازی ندارید.

## 3. بررسی اینکه آیا سینمارو مستحق پاپ‌کورن رایگان است

- از یکی از دستورهای شرطی [`if`][doc-if] یا [`unless`][doc-unless] استفاده کنید تا بررسی کنید آیا سینمارو مستحق پاپ‌کورن رایگان است.
- از [`raise`][doc-raise] استفاده کنید.
