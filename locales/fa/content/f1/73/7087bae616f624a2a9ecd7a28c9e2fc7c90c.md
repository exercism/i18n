# دستورالعمل‌ها

روزی روزگاری، شهر پرجنب‌وجوشی به نام Cyberspace وجود داشت.
Cyberspace یک کلان‌شهر دیجیتال بود که هر روز میلیون‌ها ساکن به آن وارد و از آن خارج می‌شدند.
برای پیگیری همه‌ی این کاربران، Cyberspace فایل ویژه‌ای به نام `/etc/passwd` داشت.

فایل `/etc/passwd` مثل دفترچه تلفن شهر بود.
هر کاربری را که روی سیستم حساب داشت فهرست می‌کرد، همراه با اطلاعات مهمی درباره‌ی هر کاربر:

| n   | فیلد |
| --- | --- |
| ۱   | نام کاربری |
| ۲   | گذرواژه («x» نشان می‌دهد که گذرواژه‌ی واقعی برای امنیت جای دیگری ذخیره شده است) |
| ۳   | UID، شناسه‌ی عددی یکتای کاربر |
| ۴   | GID، شناسه‌ی عددی یکتای گروه (معمولاً همان UID) |
| ۵   | اطلاعات کاربر (معمولاً اسم کامل کاربر، اما می‌تواند اطلاعات دیگری هم دربر داشته باشد) |
| ۶   | پوشه‌ی خانه |
| ۷   | شل ورود |

فیلدها با کاراکتر دونقطه از هم جدا می‌شوند.
این یک ورودی معمولی است:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

فایل را تیمی از مدیران سیستم اداره می‌کردند که مسئول ساختن حساب‌های جدید، به‌روزرسانی حساب‌های موجود و حذف حساب‌های قدیمی بودند.
مدیران سیستم دروازه‌بانان Cyberspace بودند و مطمئن می‌شدند که فقط کاربران مجاز به سیستم دسترسی داشته باشند.

یک روز، مدیر سیستم تازه‌ای به نام Alex استخدام شد تا به تیم بپیوندد.
Alex از پذیرفتن این کار هیجان‌زده بود و خیلی زود همه‌ی ریزه‌کاری‌های فایل `/etc/passwd` را یاد گرفت.
یاد گرفت چطور کاربران جدید به سیستم اضافه کند، اطلاعات کاربران را به‌روزرسانی کند و کاربران قدیمی را حذف کند.

وقتی Alex داشت روی فایل `/etc/passwd` کار می‌کرد، به نکته‌ی عجیبی پی برد.
پوشه‌ی خانه‌ی بعضی کاربران عجیب یا غیرمعمول بود.
پوشه‌ی خانه‌ی بعضی کاربران روی `/dev/null` تنظیم شده بود و پوشه‌ی خانه‌ی بعضی دیگر روی مسیرهای عجیبی که اصلاً وجود نداشتند.

Alex فهمید که این کاربران افراد واقعی نیستند، بلکه حساب‌های جعلی‌ای هستند که هکرها ساخته‌اند.
هکرها راهی پیدا کرده بودند که از یک آسیب‌پذیری در سیستم سوءاستفاده کنند و این حساب‌های جعلی را ساخته بودند تا به Cyberspace دسترسی پیدا کنند.

Alex می‌دانست که باید دست به کار شود.
او از awk استفاده کرد تا فایل `/etc/passwd` را تحلیل کند و اسکریپتی نوشت که همه‌ی حساب‌های جعلی را شناسایی کند.
سپس با بقیه‌ی اعضای تیم همکاری کرد تا این حساب‌ها را حذف کنند و آسیب‌پذیری‌ای را که در وهله‌ی اول به هکرها امکان ساخت آن‌ها را داده بود، رفع کنند.

به لطف استفاده‌ی Alex از awk، تیم توانست حساب‌های جعلی را شناسایی و حذف کند و Cyberspace را به جای امن‌تری برای همه تبدیل کند.
مدیران سیستم همچنان فایل `/etc/passwd` را مدیریت می‌کردند، آن را به‌روز و امن نگه می‌داشتند و مطمئن می‌شدند که فقط کاربران مجاز به سیستم دسترسی داشته باشند.

حالا نوبت شماست که مثل Alex مدیر سیستم باشید.

* عملگرهای منطقی شبیه زبان‌های دیگر هستند:

    | عمل | مثال            |
    | --------- | ------------------ |
    | AND       | `expr1 && expr2`   |
    | OR        | `expr1 \|\| expr2` |
    | NOT       | `! expr`           |

* فراخوانی یک تابع نحوه‌ی نگارش آشنایی دارد:

    ```awk
    function greet(name) {
        print "Hello", name
    }
    BEGIN {
        greet("Mary")   # prints "Hello Mary"
    }
    ```

## 1. فهرست کردن نام‌های کاربری

یک برنامه‌ی awk بنویسید که اولین فیلد جداشده با دونقطه را برای هر خط در فایل `passwd` چاپ کند.

## 2. چاپ شماره‌ی خط‌ها

یک دستور awk بنویسید که شماره‌ی خط هر رکورد در فایل ورودی را چاپ کند.
فقط شماره‌ی خط را چاپ کنید، نه هیچ اطلاعات دیگری.

## 3. چاپ رکوردهای دارای پوشه‌ی خانه‌ی نامعتبر

در Cyberspace، پوشه‌ی خانه‌ی «معتبر» با `/home` یا `/root` شروع می‌شود.
رکوردهای فایل ورودی را که پوشه‌ی خانه‌ی **نامعتبر** دارند چاپ کنید.

## 4. چاپ کاربران معتبری که از bash استفاده می‌کنند

رکوردهایی را چاپ کنید که پوشه‌ی خانه‌شان معتبر است **و** شل ورودشان `bash` است.
