# مقدمه

## مقایسه

### مقایسه‌ی اعداد

در `jq` می‌توان اعداد را با عملگرهای رابطه‌ای و برابری زیر مقایسه کرد.

| مقایسه | عملگر |
| ---------------------- | -------- |
| بزرگ‌تر از | `a > b`  |
| بزرگ‌تر یا مساوی | `a >= b` |
| کوچک‌تر از | `a < b`  |
| کوچک‌تر یا مساوی | `a <= b` |
| مساوی | `a == b` |
| نامساوی | `a != b` |

نتیجه‌ی مقایسه همیشه یک مقدار منطقی است، یعنی یا `true` یا `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### مقایسه‌ی رشته‌ها

از عملگرهای مقایسه‌ی بالا می‌توان برای مقایسه‌ی رشته‌ها هم استفاده کرد.
در این حالت، ترتیبی واژه‌نامه‌ای (لغت‌نامه‌ای) اعمال می‌شود.
این ترتیب _بر اساس مقدار کدپوینت یونیکد_ است.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

وقتی دو متغیری را مقایسه می‌کنید که به نظر می‌رسد مقدار عددی دارند اما از نوع رشته‌اند، باید مراقب باشید.
به دلیل ترتیب واژه‌نامه‌ای، نتیجه با مقایسه‌ی مقادیر از نوع عدد یکسان نخواهد بود.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### برابری «سخت‌گیرانه»

عملگر `==` در `jq` شبیه `===` در JavaScript است، به این معنا که مقادیری که «شبیه» هم به نظر می‌رسند اما از نوع‌های متفاوتی هستند، برابر نیستند.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### مقایسه‌ی آرایه‌ها

دو آرایه زمانی برابرند که همه‌ی عناصر متناظرشان برابر باشند.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### مقایسه‌ی اشیا

دو شیء زمانی برابرند که جفت‌های کلید-مقدار یکسانی داشته باشند.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## شرط‌ها

### عبارت `if`

**عبارت شرطی** در `jq` به شکل `if A then B else C end` است.

`if-then-else` مانند همه‌ی توابع درونی `jq` یک «فیلتر» است: ورودی می‌گیرد و خروجی تولید می‌کند.

اگر عبارت `A` مقداری «درست‌نما» تولید کند، فیلتر `if` عبارت `B` را ارزیابی می‌کند.
در غیر این صورت `C` را ارزیابی می‌کند.
ورودی فیلتر `if` به `B` یا `C` داده می‌شود.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
بند `else` **اختیاری** است؛ دو دستور زیر معادل یکدیگرند.

```jq
if A then B else . end
if A then B end
```
~~~~

### دستورهای `if` تودرتو

با `elif` می‌توان شرط‌های بیشتری افزود.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

هر تعداد بند `elif` که لازم دارید استفاده کنید.

### درست‌نمایی

تنها مقادیر «غلط» در `jq` این‌ها هستند: `false` و `null`.
همه‌ی مقادیر دیگر «درست» هستند، حتی عدد صفر و رشته‌ی خالی، آرایه‌ی خالی و شیء خالی.

### عملگرهای منطقی

از **عملگرهای منطقی** `and` و `or` می‌توان برای ساختن کوئری‌های پیچیده استفاده کرد.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

برای نقیض کردن، از `not` استفاده کنید. این یک **فیلتر** است، نه یک عملگر.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### عملگر جایگزین

**عملگر جایگزین** به شما امکان می‌دهد در صورتی که یک عبارت `false` یا `null` باشد، یک مقدار «پیش‌فرض» تعیین کنید.

```jq
A // B

# This is identical to
if A then A else B end
```

برای نمونه:

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
