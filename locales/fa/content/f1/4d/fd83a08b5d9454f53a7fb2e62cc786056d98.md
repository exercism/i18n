# راهنمایی

## کلی

- چهار نماد جهت‌های اصلی و چهار نماد سمت نسبی را با یک خط `SYMBOLS:` تعریف کنید: `SYMBOLS: north east south west ahead starboard behind port ;`
- هر تاپل با `TUPLE: <class> <slot1> <slot2> ;` تعریف می‌شود.
- یک خط `GENERIC:` واژه را تعریف می‌کند؛ هر خط `M:` یک متد برای یک کلاس اضافه می‌کند. اگر متغیرهای محلی نام‌دار در بدنه‌ی متد می‌خواهید، از `M::` استفاده کنید.

## 1. `>cartesian` برای `cardinal`

- یک `case` کوچک روی چهار نماد جهت کافی است.
- `{ north [ 0 1 ] }`، بدنه فقط دو مقدار را روی پشته می‌گذارد؛ تست انتظار دارد `x` روی پشته زیر `y` باشد.

## 2. `>cartesian` برای `polar`

- درجه‌ها را به رادیان تبدیل کنید: `bearing pi * 180 /`.
- `sin` و `cos` در `math.functions` قرار دارند.
- ابتدا `magnitude * sin(rad)` و سپس `magnitude * cos(rad)` را روی پشته قرار دهید.

## 3. `>cartesian` برای `relative`

- یک متغیر پویا تعریف کنید: `SYMBOL: heading`.
- آن را در متد خودتان با `heading get` بخوانید.
- `ahead/starboard/behind/port` را با یک `case` به آفست `0/90/180/270` نگاشت کنید، سپس `heading` را اضافه کنید. از آنجا به بعد، همان تبدیل قطبی بخش ۲ است. می‌توانید یک تابع کمکی جدا کنید: `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` روی یک `cardinal` و `change-bearing` روی یک `polar` یا `relative`، یک تاپل تازه می‌سازد که یک اسلات آن تغییر کرده و بقیه دست‌نخورده مانده‌اند: `[ <transformation-quotation> ] change-bearing`.
- برای چرخش `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- `>cartesian` را روی هر ورودی فراخوانی کنید، سپس مؤلفه‌های x و مؤلفه‌های y را جمع کنید. متغیرهای محلی این را خواناتر می‌کنند:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
