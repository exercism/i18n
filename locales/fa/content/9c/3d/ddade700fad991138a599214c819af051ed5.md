# مقدمه

در Go، هر متغیری یک مقدار دارد.
اگر متغیری را بدون مقداردهی اعلام کنید، به مقدار صفر نوع خودش تنظیم می‌شود.

انواع پایه، از جمله `bool`، انواع عددی و `string`، هر کدام یک مقدار صفر ثابت دارند:

| نوع                       | مقدار صفر |
| ------------------------- | --------- |
| bool                      | `false`   |
| int، int8، int64 و غیره   | `0`       |
| float32، float64          | `0`       |
| complex64، complex128     | `0+0i`    |
| string                    | `""`      |

اشاره‌گرها، توابع، رابط‌ها، برش‌ها، کانال‌ها و نقشه‌ها هر کدام مقدار صفر `nil` دارند.

آرایه و ساختار هرگز `nil` نیستند، چون داده را مستقیماً نگه می‌دارند، نه ارجاعی به آن.
هر عنصر آرایه و هر فیلد ساختار با مقدار صفر نوع خودش مقداردهی اولیه می‌شود.
برای مثال، `var a [3]int` آرایه‌ی `[0, 0, 0]` را می‌سازد.

## اعلام مقدارهای صفر

برای اعلام یک متغیر از `var` استفاده کنید:

```go
var myBool bool   // false
var mySlice []int // nil
```

برای ساختارها از لیترال ترکیبی `T{}` استفاده کنید:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
