# مقدمه

آرایه نوع اصلی دنباله با طول ثابت در Factor است که به شکل `{ … }` نوشته می‌شود: می‌توانید عنصرها را تغییر دهید اما طول را نه. واژگان `arrays` و `sequences` با هم سازنده‌های کوچکی در اختیارتان می‌گذارند که مقدارها را از پشته برمی‌دارند، به‌علاوه‌ی عملیات روزمره‌ای برای به‌هم‌پیوستن، معکوس کردن و جست‌وجوی عنصرها.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
