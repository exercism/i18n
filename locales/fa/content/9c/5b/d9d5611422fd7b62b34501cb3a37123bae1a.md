# مقدمه

«تعریف نوع» یک نوع نام‌دار جدید می‌سازد که از هر نوع دیگری متمایز است، حتی از نوعی که همان نوع پایه را دارد.

## تعریف نوع

تعریف نوع با کلیدواژه‌ی `type` شروع می‌شود و بعد از آن اسم نوع جدید و نوع پایه‌ی آن می‌آید:

```go
type File []bool
```

`File` در اینجا به یک ستون عمودی روی صفحه‌ی شطرنج اشاره دارد که معمولاً با حروف A تا H برچسب‌گذاری می‌شود.
هر خانه در این ستون با یک «مقدار منطقی» نمایش داده می‌شود که نشان می‌دهد آن خانه اشغال شده است یا نه.
حالا که `File` تعریف شده است، می‌توانیم از آن درون تعریف‌های دیگر استفاده کنیم:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` شناسه‌های ستون را به مقادیر `File` نگاشت می‌کند.
هر `File` یک اسلایس از مقادیر منطقی است که خانه‌های یک ستون شطرنج را نمایش می‌دهد.
بدون این تعریف‌های نوع، `board` یک `map[string][]bool` می‌بود؛ این باعث می‌شد فهم اینکه چه چیزی را نمایش می‌دهیم سخت‌تر شود.
