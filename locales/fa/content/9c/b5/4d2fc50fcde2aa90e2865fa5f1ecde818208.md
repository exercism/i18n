# استفاده از مستندات ماژول

[comment]: # (این خطا وقتی رخ می‌دهد که پاسخ ارسالی برای ماژول فاقد @moduledoc باشد)

توصیه می‌شود برای توضیح هدف ماژول، یک ویژگی [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) داشته باشید.

- مستندات در Elixir یک «شهروند درجه یک» است؛ مستندات Elixir طوری طراحی شده که خواندن و نوشتنش آسان باشد.
- نحوه‌ی نگارش Markdown درون ویژگی‌های مستندات `@moduledoc` و `@doc` پشتیبانی می‌شود.
