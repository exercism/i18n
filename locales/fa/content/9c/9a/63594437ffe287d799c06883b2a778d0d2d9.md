# دستورالعمل‌ها

ایستگاه هواشناسی ولینگتون سیستم دستی ثبت دمای خود را با یک سیستم دیجیتال تازه جایگزین می‌کند.
در سیستم قدیمی، محاسبات به‌صورت دستی انجام می‌شد.
در سیستم تازه، این محاسبات خودکار خواهند شد.
این محاسبات شامل تبدیل دما از سلسیوس به فارنهایت و یافتن میانگین دما است.
سیستم تازه حسگرهایی برای ثبت داده‌های دما بر حسب سلسیوس دارد.

ایستگاه هواشناسی ولینگتون از شما می‌خواهد که در سیستم تازه به آن‌ها کمک کنید.

## 1. تبدیل دما از سلسیوس به کلوین

ایستگاه هواشناسی بخشی در وب‌سایت خود دارد که مخصوص پژوهشگران است.
پژوهشگران به دمای بر حسب کلوین علاقه دارند.

کلوین یکای اندازه‌گیری دما است.
مقیاس آن با سلسیوس یکی است، اما نقطه‌ی شروعش متفاوت است.
نقطه‌ی شروع آن صفر مطلق است، که برابر است با ۰K (کلوین) یا -۲۷۳٫۱۵°C (سلسیوس).

جدول زیر تبدیل میان سلسیوس و کلوین را نشان می‌دهد:

| سلسیوس (°C) | کلوین (K) |
| ----------- | --------- |
| -۲۷۳٫۱۵     | ۰         |
| -۱۰۰        | ۱۷۳٫۱۵    |
| ۰           | ۲۷۳٫۱۵    |
| ۱۰۰         | ۳۷۳٫۱۵    |

ایستگاه هواشناسی از شما می‌خواهد که متدی پیاده‌سازی کنید که دما را از سلسیوس به کلوین تبدیل می‌کند.

متد `Temperature#to_kelvin` را پیاده‌سازی کنید که آرگومانی به اسم `celsius` می‌گیرد و با افزودن ۲۷۳٫۱۵ به مقدار داده‌شده‌ی `celsius`، دما را بر حسب کلوین برمی‌گرداند.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. گرد کردن دما

حسگر دمای ایستگاه هواشناسی دقیق است.
می‌تواند دما را با دقت ۰٫۰۰۰۱°C اندازه بگیرد.
ایستگاه هواشناسی می‌خواهد دما را فقط با گرد شدن به یک رقم اعشار نمایش دهد، چون بیشتر کاربران به این سطح از دقت علاقه‌ای ندارند.

ایستگاه هواشناسی از شما می‌خواهد که متدی پیاده‌سازی کنید که دما را به یک رقم اعشار گرد می‌کند.

متد `Temperature#round` را پیاده‌سازی کنید که آرگومانی به اسم `celsius` می‌گیرد و دما را گرد شده به یک رقم اعشار برمی‌گرداند.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. تبدیل دما از سلسیوس به فارنهایت

ایستگاه هواشناسی بخشی در وب‌سایت خود دارد که مخصوص گردشگران است.
گردشگران به دمای بر حسب فارنهایت علاقه دارند.

فارنهایت یکای اندازه‌گیری دما است.
مقیاس آن با سلسیوس متفاوت است.
۰°C برابر ۳۲°F است و ۱ درجه‌ی سلسیوس با ۱٫۸ درجه‌ی فارنهایت برابر است.

جدول زیر تبدیل میان سلسیوس و فارنهایت را نشان می‌دهد:

| سلسیوس (°C) | فارنهایت (°F) |
| ----------- | -------------- |
| -۲۷۳٫۱۵     | -۴۵۹٫۸         |
| -۱۰۰        | -۱۴۸           |
| ۰           | ۳۲             |
| ۱۰۰         | ۲۱۲            |

ایستگاه هواشناسی از شما می‌خواهد که متدی پیاده‌سازی کنید که دما را از سلسیوس به فارنهایت تبدیل می‌کند.

متد `Temperature#to_fahrenheit` را پیاده‌سازی کنید که آرگومانی به اسم `celsius` می‌گیرد و دما را بر حسب فارنهایت به‌صورت یک عدد صحیح برمی‌گرداند.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. به دست آوردن تعداد حسگرهای گمشده

در هنگام نصب حسگرهای دما، کارگران تعمیرات متوجه شدند که چند حسگر گم شده است.
هر واحد اندازه‌گیری دما به چهار حسگر دما نیاز دارد.
تیم تعمیرات تعداد حسگرهای موجودشان را شمردند، اما لازم بود بدانند چند حسگر کم دارند.
آن‌ها کمک می‌خواهند تا بشمارند که برای ساختن یک واحد اندازه‌گیری دمای کامل دیگر، چند حسگر باید بخرند.

متد `Temperature#number_missing_sensors` را پیاده‌سازی کنید که آرگومانی به اسم `number_of_sensors` می‌گیرد و تعداد حسگرهای گمشده را برمی‌گرداند.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
