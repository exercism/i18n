# گنجاندن کد

`circus-acts` از `<` استفاده می‌کرد تا بگوید یک کلاس *می‌تواند* کاری را انجام دهد که یک کلاس انتزاعی توصیف می‌کند. اما درباره‌ی چگونگی انجام آن حرفی نمی‌زد.

`include` نیمه‌ی دیگر ماجراست: کد واقعی را از کلاس دیگری برمی‌دارد و رونوشتی از آن را در این کلاس می‌گذارد.

```sather
class WARM_UP is

   count : INT is return 8; end;

   describe : STR is return count + " counts"; end;

end; -- class WARM_UP

class JAZZ_ROUTINE is

   include WARM_UP;

   -- count and describe are now here too, as though written out.

end; -- class JAZZ_ROUTINE
```

مقدار `JAZZ_ROUTINE::count` برابر ۸ است، بدون اینکه `JAZZ_ROUTINE` به آن اشاره‌ای کرده باشد.

## این‌ها دو تصمیم جداگانه‌اند

بیشتر زبان‌ها این دو را یکی می‌کنند: یک `extends` هم کد را به ارث می‌دهد و هم زیرکلاس را هر جایی که ابرکلاس به کار می‌آید قابل استفاده می‌کند. Sather این دو را از هم جدا نگه می‌دارد.

| نوشته | معنا |
| --- | --- |
| `class A < $B` | هر جایی که `$B` لازم باشد، می‌توان از یک `A` استفاده کرد |
| `class A is include B` | `A` با یک رونوشت از کد `B` آغاز می‌شود |

می‌توان یکی را بدون دیگری داشت، یا هر دو را. گنجاندن یک کلاس آن را به زیرنوع تبدیل **نمی‌کند**: پس از `include WARM_UP`، هنوز نمی‌توان از `JAZZ_ROUTINE` جایی که `WARM_UP` لازم است استفاده کرد و هیچ چیز خلاف این را ادعا نمی‌کند.

## تغییر نام

می‌توان یک روال گنجانده‌شده را با نامی دیگر وارد کرد:

```sather
   include WARM_UP count -> warm_up_count;
```

چند روال را با ویرگول از هم جدا می‌کنند:

```sather
   include WARM_UP count -> warm_up_count, describe -> warm_up_describe;
```

## حذف یکی

تغییر نام به *هیچ* آن را حذف می‌کند و همین روش جایگزین کردن آن است:

```sather
class TAP_ROUTINE is

   include WARM_UP describe -> ;

   describe : STR is return "Tap: " + count + " counts"; end;

end; -- class TAP_ROUTINE
```

`count` مثل همیشه وارد می‌شود؛ اما `describe` وارد نمی‌شود، بنابراین نوشتن یک روال به این نام در اینجا تعارضی ایجاد نمی‌کند. بدون `describe -> ;` کامپایلر امتناع می‌کرد: داشتن دو روال با نام و آرگومان‌های یکسان در یک کلاس خطاست و Sather حدس نمی‌زند که منظورتان کدام بوده است.

تفاوت آن با بازنویسی در بیشتر زبان‌ها همین است: جایگزینی اعلام می‌شود، نه اینکه ضمنی باشد.
