# مقدمه

وقتی در Gleam روی یک مقدار «تطبیق الگو» انجام می‌دهیم، باید مطمئن شویم که الگوها با همه‌ی مقادیر ممکن آن نوع مطابقت دارند، در غیر این صورت کد کامپایل نمی‌شود.

این تابع باید رد شود، چون حالتی را که لیست خالی است پوشش نداده است:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

بیشتر اوقات در برنامه‌های Gleam می‌خواهیم به همه‌ی حالت‌های ممکن رسیدگی کنیم، اما در برخی برنامه‌ها مثل نمونه‌های اولیه و اسکریپت‌های سریع ممکن است بخواهیم فقط روی «مسیر موفق» تمرکز کنیم و برای حالت‌های دیگر کد ننویسیم. اینجاست که `let assert` در Gleam به کار می‌آید.

با `let assert` یک الگو می‌تواند فقط با بعضی از مقادیر ممکن یک نوع مطابقت کند. اگر الگو با مقداری مطابقت نکند، برنامه کرش می‌کند. با `let assert` می‌توانیم تابع بالا را این‌گونه بنویسیم:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

کتابخانه‌های Gleam هرگز نباید از `let assert` استفاده کنند، چون می‌تواند باعث کرش برنامه شود. در عوض، باید از نوع `Result` استفاده کنند و اجازه دهند توسعه‌دهنده‌ی برنامه تصمیم بگیرد که با خطاها چگونه برخورد کند.
