# قابلیت دید

وقتی از کلاس‌ها برای سازمان‌دهی کد استفاده می‌کنید، «قابلیت دید» ویژگی‌ها، متدها و ثابت‌ها می‌تواند به ایجاد انتزاع‌ها و مسئولیت‌های درست کمک کند.
قابلیت دید ویژگی‌ها، متدها و ثابت‌ها با استفاده از کلیدواژه‌های `public`، `private` یا `protected` در زمان تعریف‌شان مشخص می‌شود.
قابلیت دید همیشه در ارتباط با استفاده‌ی بیرونی از ویژگی، متد یا ثابت کلاس معنا پیدا می‌کند.
یعنی اگر ویژگی‌ای `public` تعریف شود، برای فراخوانی‌های بیرونی قابل مشاهده و قابل استفاده است.
ویژگی‌ها، متدها و ثابت‌های `private` برای فراخوانی‌های بیرونی نه قابل مشاهده هستند و نه قابل استفاده.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

ویژگی‌ها، متدها و ثابت‌های `protected` فقط برای خودِ کلاس و کلاس‌های فرزندش (از طریق ارث‌بری) قابل مشاهده هستند.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
