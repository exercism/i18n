# نصب

راه‌حل‌های این مسیر به زبان اسمبلی RISC-V ۳۲بیتی نوشته می‌شوند و زیر شبیه‌سازی اجرا می‌شوند، بنابراین به هیچ سخت‌افزار RISC-V نیازی نیست.
هر تمرین همراه با یک Makefile ارائه می‌شود که تست‌ها را می‌سازد و آن‌ها را اجرا می‌کند.
برای استفاده از آن، به سه ابزار نیاز دارید:

- [Zig][zig]، که اسمبلر، کامپایلر C و پیونددهنده‌ی RISC-V را از طریق `zig cc` فراهم می‌کند.
- [Make][make]، که ساخت را اجرا می‌کند.
- `qemu-riscv32` از [QEMU][qemu]، که برنامه‌ی حاصل را اجرا می‌کند.

## macOS

با هر راه‌حل مجازی‌سازی مناسب (مثلاً [Lima][lima]) یک ماشین مجازی لینوکس راه‌اندازی کنید و بخش یکی از توزیع‌های لینوکس را در ادامه دنبال کنید.

## Windows

از [Windows Subsystem for Linux][wsl] استفاده کنید و بخش یکی از توزیع‌های لینوکس را در ادامه دنبال کنید.
یا به‌جای آن، یک ماشین مجازی لینوکس راه‌اندازی کنید.

## Debian / Ubuntu

Make و شبیه‌سازهای حالت کاربر QEMU را نصب کنید:

```shell
sudo apt install make qemu-user
```

سپس Zig 0.15.2 یا جدیدتر را همان‌طور که در [Direct download][zig-install] توضیح داده شده نصب کنید.

## Fedora

هر سه ابزار را با این دستور نصب کنید:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

هر سه ابزار را با این دستور نصب کنید:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

هر سه ابزار را با این دستور نصب کنید:

```shell
sudo zypper install zig make qemu-linux-user
```

## بررسی نصب

تأیید کنید که هر سه ابزار پیدا می‌شوند:

```shell
zig version
make --version
qemu-riscv32 --version
```

سپس با Exercism CLI یک تمرین را دانلود کنید و تست‌های آن را اجرا کنید:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
