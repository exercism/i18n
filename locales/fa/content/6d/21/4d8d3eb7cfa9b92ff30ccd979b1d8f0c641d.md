# مقدمه

در Gleam دو نوع متفاوت عدد وجود دارد: عدد صحیح و عدد اعشاری.

عدد صحیح یک عدد کامل است.

```gleam
let integer = 3
// -> 3
```

Gleam چندین عملگر دارد که با اعداد صحیح کار می‌کنند.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
