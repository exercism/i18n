# منابع

* [The Rust Programming Language](https://doc.rust-lang.org/book/) منبعی عالی است برای شروع کار با Rust و همچنین برای عمیق‌تر شدن در ویژگی‌های خاص آن.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) نمونه‌هایی از رایج‌ترین کدهایی را که در Rust خواهید نوشت به شما نشان می‌دهد.
* از [Rust API Documentation](http://doc.rust-lang.org/std/) می‌توانید برای کشف متدهای تازه و نحوه‌ی کارشان استفاده کنید.
* از [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) می‌توانید برای جست‌وجوی مشکلتان استفاده کنید و ببینید آیا پیش‌تر به آن پاسخ داده شده است یا نه. همچنین می‌توانید پرسش بپرسید و به پرسش‌ها پاسخ دهید.
* [Rust User Forum](http://users.rust-lang.org) برای گفت‌وگوی عمومی درباره‌ی Rust است.
* [/r/rust](http://www.reddit.com/r/rust/) سابردیت رسمی Rust است.
* سرور رسمی [The Rust Programming Language](https://discord.gg/rust-lang) در [Discord](https://discordapp.com/) را می‌توانید برای پرس‌وجوهای سریع و گفت‌وگو درباره‌ی این زبان به کار ببرید.
