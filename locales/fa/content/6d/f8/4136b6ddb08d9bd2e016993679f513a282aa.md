# یادگیری

## شروع کار با Emacs

خب، Emacs را نصب کرده‌اید. حالا چه کار کنیم؟

خب، می‌توانید با فشردن `C-h t` آموزش را شروع کنید و این نقطه‌ی شروع بدی نیست. این آموزش اصول ویرایش، جست‌وجو و جابه‌جایی در Emacs را به شما می‌آموزد.

اگر کاملاً تازه‌کار هستید، برداشتن یک کیت شروع می‌تواند منطقی باشد؛ کیت‌های شروع مجموعه‌ای از پیکربندی‌ها و بسته‌های از پیش تنظیم‌شده را همراه دارند.

بسته‌ی [Emacs Prelude](http://batsov.com/prelude/) مجموعه‌ی خوبی از پیش‌فرض‌های معقول و بسته‌ها را ارائه می‌دهد.

برای نصب Emacs Prelude دستور زیر را در ترمینال اجرا کنید:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

و حتماً برای دستورهای بیشتر [راهنمای نصب](https://prelude.emacsredux.com/en/latest/installation/) را ببینید.


اگر با vim آشنا هستید، ممکن است به کیت شروع [Doom Emacs](https://github.com/doomemacs/doomemacs) علاقه‌مند باشید که شبیه‌سازی vim را با قدرت [evil-mode](https://github.com/emacs-evil/evil) یکپارچه می‌کند.

برای نصب Doom Emacs دستور زیر را در ترمینال اجرا کنید:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

و حتماً برای دستورهای بیشتر [راهنمای نصب](https://github.com/doomemacs/doomemacs#install) را ببینید.

## راه‌اندازی بررسی نحوه‌ی نگارش و لینت

توصیه می‌شود بررسی نحوه‌ی نگارش و لینت را با [Flycheck](https://www.flycheck.org/en/latest/) راه‌اندازی کنید.

اگر هنوز مخزن [MELPA](https://melpa.org/) را به Emacs خود اضافه نکرده‌اید، این کار را با افزودن موارد زیر به [فایل init](https://www.flycheck.org/en/latest/glossary.html#term-init-file) انجام دهید

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

نصب و راه‌اندازی Flycheck بدون [use-package](https://github.com/jwiegley/use-package) با افزودن موارد زیر به [فایل init](https://www.flycheck.org/en/latest/glossary.html#term-init-file) انجام می‌شود

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

نصب و راه‌اندازی Flycheck با [use-package](https://github.com/jwiegley/use-package) با افزودن موارد زیر به [فایل init](https://www.flycheck.org/en/latest/glossary.html#term-init-file) انجام می‌شود

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

برای اطلاعات بیشتر و رفع اشکال، [مستندات Flycheck](https://www.flycheck.org/en/latest/user/troubleshooting.html) را ببینید.

## یادگیری Emacs Lisp

بهترین مستندات Emacs Lisp... همراه خود Emacs ارائه می‌شود!
برای دسترسی به
[مرجع Emacs Lisp](https://www.gnu.org/software/emacs/manual/elisp.html)،
`C-h i` را تایپ کنید و مدخل Elisp را پیدا کنید، یا Help &rarr; More Manuals
&rarr; Emacs Lisp Reference را انتخاب کنید.  توجه داشته باشید که ممکن است این
راهنما در برخی توزیع‌ها وجود نداشته باشد؛ در این صورت می‌توانید آن را
[به‌صورت آنلاین](https://www.gnu.org/software/emacs/manual/elisp.html) پیدا کنید.

اگر کاملاً با Elisp تازه‌کار هستید، می‌توانید
[مقدمه‌ای بر Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro) را بخوانید
که به همان روش باز می‌شود.

## بهترین روش‌ها و قراردادهای Emacs Lisp

راهنمای Emacs بخشی درباره‌ی [قراردادهای نگارش کد](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) Emacs Lisp دارد.
همچنین یک [راهنمای سبک](https://github.com/bbatsov/emacs-lisp-style-guide) با مشارکت جامعه در GitHub نگهداری می‌شود.
