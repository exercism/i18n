# نصب

## نصب .NET

مسیر C# روی پلتفرم [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) ساخته شده است که روی Windows، Linux و macOS اجرا می‌شود.
برای ساخت پروژه‌های .NET می‌توانید از رابط خط فرمان .NET (CLI) استفاده کنید.
این CLI بخشی از .NET SDK است که می‌توانید آن را با دنبال کردن [دستورالعمل‌های نصب](https://dotnet.microsoft.com/download/dotnet/8.0) نصب کنید.
توجه: مسیر C# به SDK نسخه‌ی 9.0 یا بالاتر نیاز دارد.

پس از تکمیل نصب، می‌توانید با اجرای این دستور در ترمینال بررسی کنید که CLI با موفقیت نصب شده است:

```bash
dotnet --version
```

اگر خروجی نسخه‌ای بزرگ‌تر یا مساوی `9.0.100` باشد، .NET SDK با موفقیت نصب شده است.

## استفاده از یک IDE

اگر تجربه‌ی ویرایش کامل‌تری می‌خواهید، احتمالاً می‌خواهید از یک [IDE یا محیط توسعه‌ی یکپارچه](https://en.wikipedia.org/wiki/Integrated_development_environment) استفاده کنید.
این‌ها محبوب‌ترین IDEهایی هستند که از ساخت پروژه‌های .NET پشتیبانی می‌کنند:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) همراه با [افزونه‌ی C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

توجه: از آنجا که قالب پروژه‌ی .NET تفاوت چشمگیری با نسخه‌های پیشین دارد، IDEهای قدیمی‌تر (مانند Visual Studio 2015) پشتیبانی نمی‌شوند.
