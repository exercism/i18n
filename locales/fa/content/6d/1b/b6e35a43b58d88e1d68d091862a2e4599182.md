# از توابع لیست استفاده نکنید

لطفاً در پیاده‌سازی‌تان از هیچ ماژول خارجی (مثل `List`، `Enum` یا `Stream`) استفاده نکنید. هدف این تمرین این است که خودتان این توابع پایه را بسازید. می‌توانید از توابع پایه‌ی `Kernel` (مثل `Kernel.+/2` برای جمع کردن اعداد) استفاده کنید، اما لطفاً از توابع `Kernel` برای لیست‌ها، مثل `++`، `--`، `hd`، `tl`، `in`، `for` و `length` استفاده نکنید.
