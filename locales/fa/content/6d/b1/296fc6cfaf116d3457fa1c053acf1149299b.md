# مقدمه

مانند بسیاری از زبان‌های دیگر، C++ هم _اشاره‌گر_ دارد.
شما می‌دانید که _مرجع‌ها_ و _اشاره‌گرها_ شبیه هم هستند، اما آن‌ها را لایه‌ای نزدیک‌تر به نحوه‌ی کار درونی رایانه‌تان در نظر بگیرید.
_اشاره‌گرها_ متغیرهایی هستند که نشانی اشیاء را نگه می‌دارند.
از آن‌ها برای تعامل مستقیم با اشیاء استفاده می‌شود و تخصیص حافظه‌ی پویا و دست‌کاری کارآمد داده‌ها را در C++ ممکن می‌کنند.

اگر تازه با _اشاره‌گرها_ آشنا شده‌اید، ممکن است کمی رمزآلود به نظر برسند، اما وقتی به آن‌ها عادت کنید، کاملاً ساده و سرراست می‌شوند.

اشاره‌گرها بخش مهمی از C++ هستند، پس وقت بگذارید و آن‌ها را واقعاً خوب بفهمید.
نسخه‌ی خام و ساده‌ی آن که در این مفهوم معرفی می‌شود، _اشاره‌گر ساده_ یا _اشاره‌گر خام_ هم نامیده می‌شود.
در C++ مدرن _اشاره‌گرهای هوشمند_ هم وجود دارند؛ نوع پایه اصلاً هوشمند نیست و باید همه‌ی کارها را خودتان دستی انجام دهید.

پیش از پرداختن به جزئیات، بهتر است کاربرد _اشاره‌گرها_ را بفهمید.
_اشاره‌گرها_ راهی برای به اشتراک گذاشتن نشانی یک شیء با بخش‌های دیگر برنامه‌ی ما هستند و به دو دلیل عمده مفیدند:

1. مانند _مرجع‌ها_، اشاره‌گرها از کپی‌ها جلوگیری می‌کنند و به کاهش مصرف منابع برنامه‌ی شما کمک می‌کنند.
1. برخلاف _مرجع‌ها_، می‌توان اشاره‌گرها را به اشیاء دیگری نسبت داد.
1. اشاره‌گرها همچنین می‌توانند به مقدار تهی اشاره کنند تا نشان دهند که در حال حاضر به هیچ شیئی اشاره نمی‌کنند.

## نحوه‌ی نگارش کلی

اعلان یک اشاره‌گر در C++ شامل مشخص کردن نوع داده‌ای است که اشاره‌گر به آن اشاره می‌کند، سپس یک ستاره (`*`) و اسم اشاره‌گر می‌آید.
وقتی اشاره‌گرها اعلان می‌شوند، به‌طور خودکار مقداردهی اولیه نمی‌شوند.
بدون انتساب صریح، یک اشاره‌گر معمولاً مقداری نامعین نگه می‌دارد که اغلب «نشانی آشغال» نامیده می‌شود.
هرچند برخی کامپایلرها ممکن است اشاره‌گرها را با `nullptr` مقداردهی اولیه کنند، این رفتار در همه‌ی کامپایلرها تضمین نشده است، بنابراین مهم است که به آن تکیه نکنید.
بهترین کار این است که اشاره‌گرهای خام را به‌صراحت مقداردهی اولیه کنید و پیش از استفاده، تهی نبودن آن‌ها را بررسی کنید تا از بروز مشکلات احتمالی جلوگیری شود.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

برای نسبت دادن نشانی یک متغیر به یک اشاره‌گر، از عملگر آدرس‌گیری (`&`) استفاده می‌کنید.
ارجاع‌زدایی از یک اشاره‌گر با عملگر _غیرمستقیم‌سازی_ (`*`) انجام می‌شود.

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

توجه: ارجاع‌زدایی باید به‌صراحت انجام شود، در حالی که _مرجع‌ها_ مثل یک نام مستعار عمل می‌کردند.

## محاسبات اشاره‌گر

_محاسبات اشاره‌گر_ به شما امکان می‌دهد روی اشاره‌گرها عملیات ریاضی انجام دهید، که هنگام کار با آرایه‌ها بسیار مفید است.
افزودن یک عدد صحیح به یک اشاره‌گر باعث می‌شود به عنصر دیگری اشاره کند.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

## دسترسی به متغیرهای عضو

در C++، از عملگر `->` برای دسترسی به اعضای یک شیء از طریق اشاره‌گری به آن شیء استفاده می‌شود.
این یک شکل کوتاه‌نوشت است که دسترسی به اعضای اشیائی را که اشاره‌گرها به آن‌ها اشاره می‌کنند ساده می‌کند.
برای نمونه، اگر `ptr` اشاره‌گری به شیئی با متغیر عضو `x` باشد، به‌جای استفاده از `(*ptr).x` می‌توانید مستقیماً از `ptr->x` استفاده کنید.
این عملگر هنگام کار با اشاره‌گرها به اشیاء، خوانایی کد را افزایش می‌دهد و از پرگویی می‌کاهد.

این یک مثال کوتاه است، با یک _ساختار_ `Superhero` که یک متغیر عضو `superpower` دارد.
تابع `main` اشاره‌گری به نام `dianaPrince` به یک شیء `Superhero` می‌سازد (که نماینده‌ی واندر وومن است).
از عملگر `->` برای دسترسی به متغیر عضو `superpower` استفاده می‌شود که «کمند حقیقت» نمادین واندر وومن را به نمایش می‌گذارد.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## اشاره‌گرها در برابر مرجع‌ها

اشاره‌گرها و مرجع‌ها هر دو دسترسی غیرمستقیم به اشیاء را ممکن می‌کنند، اما در توانایی‌ها و ملاحظات ایمنی با هم تفاوت دارند.
اشاره‌گرها این انعطاف را می‌دهند که شیء هدفشان را تغییر دهید و می‌توان آن‌ها را تهی کرد.
با این حال، این انعطاف خطرهایی هم به همراه دارد، مانند ارجاع‌زدایی از اشاره‌گرهای تهی یا ساختن اشاره‌گرهای معلق.
در مقابل، مرجع‌ها نمی‌توانند تهی باشند و هنگام ساخته شدن به اشیاء معتبر گره می‌خورند و به این ترتیب از این خطرها دور می‌مانند.
با توجه به ماهیت ایمن‌ترشان، بهتر است مرجع‌ها را به اشاره‌گرها ترجیح دهید، مگر آنکه کارکردهای اضافه‌ای که اشاره‌گرها فراهم می‌کنند ضروری باشند.
