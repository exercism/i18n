# বিস্তারিত

Swift-এ [ক্লোজার][closures] হলো কোডের স্বয়ংসম্পূর্ণ ব্লক, যেগুলোতে প্যারামিটার পাস করে সেগুলোর গণনা চালু করা যায় এবং মান রিটার্ন করা যায়।
ক্লোজারগুলো তাদের পরিবেশ থেকে মান ক্যাপচার করে এবং সেই মানগুলো নিজেদের গণনায় ব্যবহার করে।
যেহেতু এগুলো স্বয়ংসম্পূর্ণ, তাই প্রোগ্রামের মধ্যে অন্য মানের মতোই এগুলো পাস করা যায় বা কনস্ট্যান্ট ও ভ্যারিয়েবলে অ্যাসাইন করা যায়।

ক্লোজার শুনতে অনেকটা Swift ফাংশনের মতোই লাগতে পারে; সত্যিই তাই, আর এর ভালো একটি কারণও আছে।
Swift-এ ফাংশন হলো ক্লোজারেরই বিশেষ রূপ, যেগুলোর একটি নাম থাকা আবশ্যক এবং যেগুলো একটু ভিন্ন সিনট্যাক্সে ডিফাইন করা হয়।

Swift-এ ফাংশন কারিগরি দিক থেকে ক্লোজার হলেও, মানুষ যখন Swift-এ "closures" বলে, তখন তারা বোঝায় [ক্লোজার এক্সপ্রেশন][closure-expressions]।
ক্লোজার এক্সপ্রেশন লেখা হয় এভাবে: প্রথমে একটি প্যারামিটার তালিকা, তারপর একটি রিটার্ন টাইপ, তারপর `in` কিওয়ার্ড এবং সবশেষে ক্লোজারের বডি, সবটুকু একটি জোড়া দ্বিতীয় বন্ধনীর ভেতরে:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

এটি `(Double, Double) -> Double` টাইপের একটি ক্লোজার এক্সপ্রেশন ডিফাইন করে, এবং এই টাইপের কোনো ফাংশনের মতোই উপযুক্ত টাইপের প্যারামিটারগুলোর উপর প্রয়োগ করে এটি চালানো যায়:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

ক্লোজার চালাতে চাইলেই প্রতিবার পুরো ক্লোজার এক্সপ্রেশন লিখে ফেলা খুব একটা সুবিধাজনক নয়, তাই Swift-এর অন্য যেকোনো মানের মতোই ক্লোজারকে নামে অ্যাসাইন করা যায়।
এরপর প্যারামিটারগুলোর উপর সেই নাম প্রয়োগ করে সেটি কল করা যায়:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

উপরের উদাহরণে দেখা যাচ্ছে, সাধারণ ফাংশনের মতোই ক্লোজারও `return` কিওয়ার্ড বাদ দিতে পারে, যদি ক্লোজারের বডি একটি মাত্র এক্সপ্রেশন হয়।

বেশিরভাগ ক্ষেত্রেই ক্লোজার ব্যবহার করা হয় হায়ার-অর্ডার ফাংশনের সাথে, হয় প্যারামিটার হিসেবে পাস করে, নয়তো রেজাল্ট হিসেবে রিটার্ন করে:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
