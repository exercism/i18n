# শর্ত সম্পর্কে

## তুলনা অপারেটর

[তুলনা অপারেটর][operators] অনেক ভাষার মতোই, শুধু কিছু বাড়তি বৈশিষ্ট্য নিয়ে।

সমতা যাচাইয়ের জন্য অপারেটর দুটি হলো `==` (সমান) আর `!=` (অসমান)।

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

এছাড়া `===` আর `!==` অপারেটর দুটি ["রেফারেন্সিয়াল ইকুয়ালিটি"][referential-equality] পরীক্ষা করে:
`a === b` হয় যদি ও কেবল যদি `a` আর `b` একই অবজেক্টকে নির্দেশ করে।
সিলেবাসে পরে এটা আরও ভালোভাবে বোঝা যাবে।

বড়/ছোট তুলনার অপারেটরগুলোও প্রচলিত।

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if` দিয়ে ব্রাঞ্চিং

একটি [`if` এক্সপ্রেশন][if-else] লেখার পূর্ণ রূপ এই রকম:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- প্রতিটি কন্ডিশনালের দুই পাশে প্রথম বন্ধনী `()` অবশ্যই লাগবে।
- একটি কন্ডিশনালের ফলাফল অবশ্যই বুলিয়ান `true` বা `false` হতে হবে।
  কিছু ভাষায় যেমন "truthy" আর "falsy" ধারণা থাকে, Kotlin-এ তেমন কিছু নেই।
- কেবল একটি এক্সপ্রেশন থাকলে দ্বিতীয় বন্ধনী `{}` ঐচ্ছিক।
- `else if` আর `else` দুটোই ঐচ্ছিক, আর একাধিক `else if` ব্লকও থাকতে পারে।

`if` এক্সপ্রেশনটি একটি মান "বেছে নেওয়ার" কাজেও লাগে:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## বিকল্প?

সচেতন সিদ্ধান্তেই Kotlin-এ Java-র টার্নারি অপারেটর `? :` _নেই_।
এর বদলে সংক্ষিপ্ত `if ... else` ফর্মই পছন্দ করা হয়:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

Ruby-র মতো নয়, সংক্ষিপ্ত `if ... else` ফর্মে *সবসময়ই* একটি `else` লাগে, তাই এটি গার্ড স্টেটমেন্ট হিসেবে ব্যবহার করা যায় না:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

মনে রাখবেন, Kotlin-এ `if` হলো একটি [_এক্সপ্রেশন_][expression], যা একটি মান রিটার্ন করে।
এটি Java-র মতো [_স্টেটমেন্ট_][statement] নয়।

পরের কোনো কনসেপ্টে আমরা দেখব, Kotlin-এ শক্তিশালী একটি [`when`][when] কনস্ট্রাক্ট আছে, যার উদ্দেশ্য হলো `else if` ধারার লম্বা শিকলকে প্যাটার্ন ম্যাচিং দিয়ে প্রতিস্থাপন করা।
