# নির্দেশনার সংযোজন

## Tcl-এর `apply` কমান্ড

টেস্ট কেসগুলো দেখতে বিভ্রান্তিকর মনে হতে পারে।
এখানে আপনার কাজ হলো এটি ইমপ্লিমেন্ট করা:

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

শেষ আর্গুমেন্টটিতে এতগুলো ব্রেস কেন?

মনে করুন, `proc` কমান্ডটি এভাবে ডিফাইন করা হয়েছে:

```tcl
proc procName argList body
```

Tcl-এ একটি `apply` কমান্ড আছে:

```tcl
apply func ?arg1 arg2 ...?
```

এই "func" হলো দুটি এলিমেন্টের একটি তালিকা `{argList body}`, যা আসলে একটি অ্যানোনিমাস proc (বা "ল্যাম্বডা")।
`apply` কমান্ডটি সেই অ্যানোনিমাস proc-কে কল করে এবং তার প্রয়োজনীয় আর্গুমেন্টগুলো পাঠিয়ে দেয়।

উদাহরণ হিসেবে, নিচের তিনটি সমতুল্য:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

`apply` ব্যবহার করলে কোডের ব্লকগুলো এক জায়গা থেকে আরেক জায়গায় পাঠানো সহজ হয়।

সূত্র: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm)।
