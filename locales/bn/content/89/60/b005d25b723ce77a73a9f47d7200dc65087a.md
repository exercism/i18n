# ভূমিকা

## মডিউল

এখন পর্যন্ত আপনার দেখা সব অনুশীলনীতেই ক্লাস ব্যবহার করা হয়েছে।
মাঝে মাঝে স্টেটসহ একটি অবজেক্ট তৈরির অতিরিক্ত বোঝাটুকু আমাদের দরকার হয় না, তাই তার বদলে আমরা `module` ব্যবহার করি।

একটি মডিউল ক্লাসের সাথে অনেকটাই মিল, আসলে অবজেক্ট হায়ারার্কিতে `Module` হলো `Class`-এর প্যারেন্ট। মূল পার্থক্যটি হলো, ইনস্ট্যান্স মেথডের বদলে আমরা ক্লাস মেথড ব্যবহার করি।
ক্লাস মেথড `self.` দিয়ে শুরু হয় এবং সরাসরি একটি মডিউলের উপর কল করা হয়।

উদাহরণস্বরূপ:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## লুপ

Ruby-তে লুপ লেখার বেশ কয়েকটি উপায় আছে, তবে সাধারণভাবে আমরা লুপ করার বদলে এনুমারেশন ব্যবহার করতে অভ্যস্ত, তাই সম্ভবত সবচেয়ে বেশি চোখে পড়া লুপটি হলো `while` লুপ:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

আপনি এর সমগোত্রীয় `until`-ও ব্যবহার করতে পারেন।

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
