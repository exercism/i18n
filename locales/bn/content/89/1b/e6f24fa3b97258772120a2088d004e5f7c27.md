# টেস্ট

যেহেতু OCaml একটি কম্পাইলড প্রোগ্রামিং ভাষা, তাই টেস্ট রান করার আগে আপনাকে আপনার সাবমিশন এবং টেস্ট কোড কম্পাইল করতে হবে।
বিল্ড করার জন্য আমরা [`dune`](https://dune.build/) ব্যবহার করি।
প্রতিটি ফোল্ডারে একটি dune ফাইল থাকে যেখানে বিল্ড করার নিয়ম লেখা থাকে, আর থাকে একটি Makefile, যেটি কাজটি করতে dune-কে নির্দেশ দেয়।

টেস্ট কম্পাইল ও রান করতে, অনুশীলনী ফোল্ডার থেকে শুধু লিখুন:

```bash
make
```
