# ভূমিকা

JavaScript-এ অ্যারে হলো একটি তালিকাসদৃশ গঠন, যার নির্দিষ্ট কোনো দৈর্ঘ্য নেই এবং যা যেকোনো ধরনের প্রিমিটিভ বা অবজেক্ট ধারণ করতে পারে, এমনকি মিশ্র টাইপেরও।

অ্যারে তৈরি করতে হলে তৃতীয় বন্ধনী `[]`-এর মাঝে এলিমেন্ট যোগ করুন।
অ্যারে থেকে কিছু পড়তে হলে আইডেন্টিফায়ারের পরে তৃতীয় বন্ধনী `[]`-এর ভেতরে ইনডেক্সটি বসান।
অ্যারের ইনডেক্সগুলো শূন্য থেকে শুরু হয়।

যেমন:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

অ্যারেতে কতগুলো এলিমেন্ট আছে তা জানতে `length` প্রপার্টি ব্যবহার করুন:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

অ্যারের কোনো এলিমেন্ট বদলাতে হলে সেই ইনডেক্সে একটি মান অ্যাসাইন করতে হয়:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## মেথড

প্রতিটি Array অবজেক্টে পাওয়া কিছু [মেথড][array_methods] ব্যবহার করে অ্যারেতে এলিমেন্ট যোগ করা বা সরানো যায়।

### push

> `push()` মেথড একটি অ্যারের শেষে এক বা একাধিক এলিমেন্ট যোগ করে এবং অ্যারের নতুন দৈর্ঘ্য রিটার্ন করে।[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> `pop()` মেথড একটি অ্যারের শেষ এলিমেন্টটি সরিয়ে ফেলে এবং সেই এলিমেন্টটি রিটার্ন করে।
> এই মেথডটি অ্যারের দৈর্ঘ্য বদলে দেয়।[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> `shift()` মেথড একটি অ্যারের প্রথম এলিমেন্টটি সরিয়ে ফেলে এবং সরানো সেই এলিমেন্টটি রিটার্ন করে।
> এই মেথডটি অ্যারের দৈর্ঘ্য বদলে দেয়।[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> unshift() মেথড একটি অ্যারের শুরুতে এক বা একাধিক এলিমেন্ট যোগ করে এবং অ্যারের নতুন দৈর্ঘ্য রিটার্ন করে।[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> splice() মেথড বিদ্যমান এলিমেন্ট সরিয়ে বা প্রতিস্থাপন করে এবং/অথবা নতুন এলিমেন্ট জায়গায় বসিয়ে একটি অ্যারের বিষয়বস্তু বদলে দেয়। এই মেথডটি মুছে ফেলা এলিমেন্টগুলো ধারণ করা একটি অ্যারে রিটার্ন করে।[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
