# সম্পর্কে

একটি *ডিসজয়েন্ট সেট* (ইউনিয়ন-ফাইন্ড স্ট্রাকচার) একগুচ্ছ মানকে এমন গ্রুপে ভাগ করে রাখে যেগুলোর মধ্যে কোনো ওভারল্যাপ নেই, আর দ্রুত একটি প্রশ্নের উত্তর দেয়: এই দুটি মান কি একই গ্রুপে আছে? এটি [`disjoint-sets`][disjoint-sets] ভোকাবুলারিতে আছে।

`<disjoint-set>` একটি খালি স্ট্রাকচার তৈরি করে। মান, অর্থাৎ *অ্যাটম*গুলো, `add-atom` দিয়ে যোগ করা হয়, অথবা `add-atoms` দিয়ে একবারে অনেকগুলো; প্রতিটিই শুরুতে একা একটি গ্রুপে থাকে:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` দুটি অ্যাটম যে গ্রুপ দুটিতে আছে সেগুলোকে একত্র করে। এই একত্রীকরণ ট্রানজিটিভ: একবার `a`-কে `b`-এর সঙ্গে এবং `b`-কে `c`-এর সঙ্গে equate করা হলে তিনটিই একই গ্রুপে চলে আসে।

```
equate ( atom1 atom2 disjoint-set -- )
```

প্রতিটি গ্রুপ চিহ্নিত হয় একটি একক ক্যানোনিকাল সদস্য দিয়ে, তার *রিপ্রেজেন্টেটিভ* দিয়ে। `representative` সেটিই ফিরিয়ে দেয়, আর দুটি অ্যাটম ঠিক তখনই একই গ্রুপের অন্তর্ভুক্ত হয় যখন তাদের রিপ্রেজেন্টেটিভ একই হয়। `equiv?` সরাসরি সেই পরীক্ষাটিই করে দেয়:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

গ্রুপের রিপ্রেজেন্টেটিভ হিসেবে কোন অ্যাটমটি বেছে নেওয়া হয়, সেটি অভ্যন্তরীণ একটি বিষয়: গ্রুপের যেকোনো সদস্যই তা হতে পারে, আর গ্রুপগুলো একত্র হওয়ার সঙ্গে সঙ্গে তা বদলেও যেতে পারে। নির্দিষ্ট কোনো অ্যাটমটিই রিপ্রেজেন্টেটিভ হবে, তার উপর কখনোই নির্ভর করবেন না; নির্ভর করবেন কেবল একই গ্রুপের দুটি অ্যাটম একমত হওয়ার উপর।

`disjoint-set-members` যোগ করা প্রতিটি অ্যাটম ফিরিয়ে দেয়।

স্ট্রাকচারটি *মিউটেবল*: `equate` আর `add-atom` নতুন একটি ডিসজয়েন্ট সেট ফিরিয়ে না দিয়ে বরং জায়গাতেই সেটিকে বদলে দেয়। ইমপ্লিমেন্টেশনে ইউনিয়ন বাই র্যাংকের সঙ্গে পাথ কম্প্রেশন ব্যবহার করা হয়েছে, তাই পরপর অনেকবার `equate` ও `representative` কল করলেও প্রতিটি কল কার্যত ধ্রুবক সময় নেয়।
