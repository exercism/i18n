# স্ট্রিং

স্ট্রিং হলো ক্যারেক্টারের একটি সিরিজ, যাকে কোট দিয়ে ঘেরা হয়।
সিঙ্গেল কোট আর ডাবল কোট, দুটিই ব্যবহার করা যায়।

```php
<?php

$where = "Spain";
$what = 'rain';
```

## স্ট্রিং ভ্যারিয়েবল এক্সপ্যানশন

ডাবল কোটে লেখা স্ট্রিংয়ের ক্ষেত্রে, স্কোপে থাকা কোনো ভ্যারিয়েবলের উল্লেখ করা হলে, সেই ভ্যারিয়েবলের মানটি স্ট্রিংয়ের ভেতরে বসে যায়।

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## ক্যারেক্টার এনকোডিং সাপোর্ট

ঐতিহাসিকভাবে PHP-এর স্ট্রিং ফাংশনগুলো শুধু ASCII ক্যারেক্টার সমর্থন করত, আধুনিক Unicode এনকোডিং সমর্থন করত না।
প্রতিটি ASCII ক্যারেক্টার ১ বাইট, অথচ Unicode ক্যারেক্টার ১ থেকে ৪ বাইট লম্বা হতে পারে।
Unicode স্ট্রিং নিরাপদে ম্যানিপুলেট করার দরকার হলে, পুরনো ফাংশনগুলোর [মাল্টিবাইট সংস্করণ][multi-byte-fns] দেখুন।

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
