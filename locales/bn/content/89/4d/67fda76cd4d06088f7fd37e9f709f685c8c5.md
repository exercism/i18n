# ইঙ্গিত

## সাধারণ

- Roc-এ লেন্স খুব একটা ব্যবহার করা হয় না, কারণ রেকর্ড আপডেট সিনট্যাক্স বেশিরভাগ ক্ষেত্রেই তা সুন্দরভাবে সামলে দেয়।
  উদাহরণ হিসেবে এই নেস্টেড রেকর্ডটি দেখুন:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  এবার চলুন ববের চুল কেটে দিই:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  কোনো লেন্সের দরকারই নেই!

- তা সত্ত্বেও, Roc-এ লেন্সের ব্যবহার বিরল হলেও Haskell আর Scala-র মতো অন্য ভাষায় এটি বেশ কমন, তাই Roc-এ এটি কীভাবে বাস্তবায়ন করা যায় তা জানতে আপনার কৌতূহল হতে পারে।
  এটি প্যারামিটারাইজড টাইপ কিংবা ফাংশন ধারণ করা রেকর্ডের মতো উন্নত Roc ফিচার অনুশীলন করারও একটি ভালো উপায়।
  প্রকৃতপক্ষে, Roc-এ একটি লেন্স উপস্থাপনের একটি উপায় হলো:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  এটি একটি প্যারামিটারাইজড টাইপ: `whole` ও `part` যেকোনো টাইপ হতে পারে।
  `whole` সাধারণত একটি রেকর্ড, আর `part` যেকোনো ফিল্ড টাইপ হতে পারে।
  `get` ফিল্ডে এমন একটি ফাংশন থাকে যা প্রদত্ত `whole`-এর নির্দিষ্ট একটি `part` রিটার্ন করে, আর `set` ফিল্ডে থাকে এমন একটি ফাংশন যা প্রদত্ত `whole`-এর একটি কপি রিটার্ন করে, তবে সেখানে নির্দিষ্ট `part`-এর জায়গায় প্রদত্ত `part` বসানো থাকে।

  উদাহরণস্বরূপ, একজন মানুষের চুল পাওয়া বা সেট করার একটি লেন্স এখানে:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  এই লেন্স ব্যবহার করে আমরা ববের চুলে ফোকাস করতে পারি, এভাবে:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  আর এভাবে তার চুল বদলাতে পারি:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- লক্ষ করুন: `hair_lens.set`-এর চারপাশের বন্ধনীগুলো জরুরি, এগুলো ছাড়া Roc `hair_lens`-এর টাইপের ভেতরে `set` নামের একটি ফাংশন খুঁজতে শুরু করবে।

- লেন্স সত্যিই বিশেষভাবে কাজে লাগে যখন আপনি সেগুলো কম্পোজ করতে শুরু করেন, যা আপনাকে গভীরভাবে নেস্টেড অংশ পেতে ও সেট করতে দেয়।
  এটি করা যায় এ রকম একটি ফাংশন বাস্তবায়ন করে:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  এই ফাংশনটি বাস্তবায়ন করা হয়ে গেলে, এটি দিয়ে এভাবে একটি চুলের দৈর্ঘ্যের লেন্স তৈরি করতে পারেন:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  এবার ববের চুল আরেকবার কেটে দিতে পারেন:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- আপনি চাইতে পারেন এমন একটি ফাংশনও বাস্তবায়ন করতে, যা দিয়ে নেস্টেড অংশে যেকোনো রূপান্তর প্রয়োগ করতে পারবেন:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  বাস্তবায়ন হয়ে গেলে, `over` এভাবে ব্যবহার করতে পারেন:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- আমাদের পরামর্শ হলো, প্রথমে Roc-এর রেকর্ড আপডেট সিনট্যাক্স দিয়ে টেস্টগুলো পাস করুন, তারপর বদলে লেন্স ব্যবহার করে দেখুন।
