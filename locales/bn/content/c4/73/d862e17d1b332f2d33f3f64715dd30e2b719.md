# সম্পর্কে

যেখানে টাইপগুলোকে ইমপ্লিসিটভাবে কাস্ট করা যায় না, সেখানে আপনাকে একটি এক্সপ্লিসিট কাস্ট [অপারেটর][cast-operator] ব্যবহার করতে হবে। কাস্ট অপারেটর আসলে আপনি যে মানটি কাস্ট করতে চান তার আগে বন্ধনীর ভেতরে বসানো টার্গেট টাইপ ছাড়া আর কিছুই নয়:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

এক্সপ্লিসিট কাস্ট ব্যবহার করা সম্ভাব্য বিপজ্জনক। সবচেয়ে কমন দুটি এরর হলো:

- সামঞ্জস্যপূর্ণ নয় এমন টাইপে কাস্ট করা। এটি রানটাইমে একটি এক্সসেপশন থ্রো করবে।
- যথেষ্ট "প্রশস্ত" নয় এমন একটি সংখ্যাসূচক মানে কাস্ট করা। ইন্টিজারের ক্ষেত্রে এর ফলে সাইন কনফ্লিক্ট হতে পারে, আবার ওভারফ্লো এক্সসেপশনও থ্রো হতে পারে।

লক্ষ্য করুন: `int` টাইপের একটি এক্সপ্রেশন এক্সপ্লিসিটভাবে `char` টাইপে কাস্ট করা যায়। এর ফলে একটি ইনভ্যালিড `char` তৈরি হতে পারে।
