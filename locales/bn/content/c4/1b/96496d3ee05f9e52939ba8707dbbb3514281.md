# নির্দেশনার সম্পূরক অংশ

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                                        |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | ইনপুট ডিজিটের সংখ্যা                          |
| `$a1`    | ইনপুট        | ইন্টিজার | ইনপুট ডিজিটের বেস                            |
| `$a2`    | ইনপুট        | ইন্টিজার | আউটপুট ডিজিটের বেস                           |
| `$a3`    | ইনপুট/আউটপুট | অ্যাড্রেস | ডিজিট শব্দের অ্যারে, যা ওভাররাইট করা যায়       |
| `$v0`    | আউটপুট       | ইন্টিজার | আউটপুট ডিজিটের সংখ্যা, ইনপুট অবৈধ হলে -1       |
| `$t0-9`  | টেম্পোরারি   | যেকোনো   | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত হয়           |
