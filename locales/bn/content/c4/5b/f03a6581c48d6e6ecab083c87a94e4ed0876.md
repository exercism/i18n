# টেস্ট

নিচের কমান্ড দিয়ে টেস্টগুলো চালান:

```shell
corepack pnpm test
```

নিশ্চিত করুন যে আপনার কোড অন্য ব্যবহারকারীদের মতোই বেস্ট প্র্যাকটিস ও কোডিং স্টাইল মেনে চলে, ESLint-এর সাহায্যে, যা আপনার কোডে স্ট্যাটিক অ্যানালাইসিস চালানোর একটি টুল।
কখনও কখনও এ ধরনের টুল আপনার JavaScript কোডে টাইপো বা বোকা বোকা ভুল ধরতে আপনার সময় বাঁচিয়ে দেয়:

```shell
corepack pnpm lint
```

আপনি Jest-কে "watch" মোডেও চালাতে পারেন, যা কোড বা টেস্ট মডিউলে পরিবর্তন সেভ করলেই আপনার টেস্টগুলো স্বয়ংক্রিয়ভাবে আবার চালাবে:

```shell
corepack pnpm watch
```

## Skip টেস্ট বোঝা

skip মেথড টেস্ট স্যুটকে একটি টেস্ট না চালানোর নির্দেশ দেয়; এই ফাংশনটি নিচের অ্যালিয়াসগুলো দিয়েও ব্যবহার করা যায়: `it.skip(name, fn)` অথবা `xit(name, fn)` অথবা `xtest(name, fn)`

- কেন এগুলো স্কিপ করা হয়?

ব্যবহারকারীরা যাতে একবারে একটি টেস্টে মনোযোগ দিতে পারেন এবং সমাধান এগিয়ে নেওয়ার সঙ্গে সঙ্গে একটি একটি করে সক্রিয় করতে পারেন।

- কীভাবে এগুলো সক্রিয় করবেন?

`xtest` এর জায়গায় `test` লিখুন।

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## আপনার প্রথম JavaScript 2015 মডিউল তৈরি

সাধারণত এই ট্র্যাকের টেস্টগুলো আপনার ইমপ্লিমেন্টেশনকে একটি JavaScript মডিউল হিসেবে ইমপোর্ট করে লোড করে: `import { Bob } from './bob.js';`।
আপনাকে শুধু রেফারেন্স করা ফাইল `bob.js` থেকে আপনার ইমপ্লিমেন্টেশন এক্সপোর্ট করতে হবে:

```javascript
export function hey(message) {}
```

মডিউল সম্পর্কে আরও জানতে [Babel ডকুমেন্টেশন](https://babeljs.io/docs/learn-es2015/#modules) দেখুন।
শুরু করা সহজ করতে ডিরেক্টরিতে একটি _স্কেলিটন_ JavaScript ফাইল আছে।
