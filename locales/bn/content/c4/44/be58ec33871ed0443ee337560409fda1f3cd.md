# ভূমিকা

## সংখ্যা

ABAP-এ বেশ কয়েকটি নিউমেরিক টাইপ রয়েছে। এই অনুশীলনীতে আপনি সেগুলোর দুটি ব্যবহার করবেন:

- `i` ইন্টিজার মানের জন্য, যেমন দিনের সংখ্যা।
- `p` প্যাকড ডেসিমাল মানের জন্য, যেমন প্রতি ঘণ্টার হার বা ডিসকাউন্ট।

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

প্যাকড সংখ্যাগুলো তাদের সর্বোচ্চ দৈর্ঘ্য এবং দশমিক স্থানের সংখ্যা নির্ধারণ করে।
দশমিক লিটারাল সাধারণত টেক্সট মান হিসেবে লেখা হয় এবং কম্পাইলার দ্বারা বা `CONV` দিয়ে লক্ষ্য দশমিক টাইপে রূপান্তরিত হয়।

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### রাউন্ডিং

ABAP রাউন্ডিংয়ের জন্য বিল্ট-ইন নিউমেরিক ফাংশন প্রদান করে।
`floor` ফাংশনটি নিচের দিকে নিকটতম পূর্ণ সংখ্যায় রাউন্ড করে, আর `ceil` উপরের দিকে নিকটতম পূর্ণ সংখ্যায় রাউন্ড করে।

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## পাটিগণিত অপারেটর

ABAP নিউমেরিক মানের সাথে গণনার জন্য পাটিগণিত অপারেটর সমর্থন করে।

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

মৌলিক অপারেটরগুলো হলো:

- `+` যোগের জন্য।
- `-` বিয়োগের জন্য।
- `*` গুণের জন্য।
- `/` ভাগের জন্য।
- `MOD` পূর্ণসংখ্যা ভাগের ভাগশেষের জন্য।

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP যোগ ও বিয়োগের আগে গুণ ও ভাগ মূল্যায়ন করে।
উদ্দিষ্ট ক্রম স্পষ্ট করতে প্রথম বন্ধনী ব্যবহার করা যায়।

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
