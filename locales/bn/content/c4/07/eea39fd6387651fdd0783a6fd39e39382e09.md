# ভূমিকা

## ম্যাপ

একটি **ম্যাপ** হলো কী (key)-ভ্যালু জোড়া সংরক্ষণ করার একটি ডেটা স্ট্রাকচার।
এটি অন্য প্রোগ্রামিং ভাষার ডিকশনারির মতোই।
[ম্যাপ][map-javadoc] ইন্টারফেসটি একটি ম্যাপের উপর অপারেশনগুলো সংজ্ঞায়িত করে।

Java-এ বিভিন্ন ধরনের ম্যাপ ইমপ্লিমেন্টেশন আছে।
[HashMap][hashmap-javadoc] হলো বহুল ব্যবহৃত একটি।

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

[put][map-put-javadoc] ব্যবহার করে ম্যাপে এন্ট্রি যোগ করুন।

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

প্রতিটি কী (key)-এর সাথে কেবল একটি মান যুক্ত থাকতে পারে।
একই কী (key) দিয়ে `put` কল করলে ওই কী (key)-এর মান আপডেট হয়ে যাবে।

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

একটি কী (key)-এর মান পেতে [get][map-get-javadoc] ব্যবহার করুন।

```java
fruitPrices.get("apple"); // => 100
```

ম্যাপে নির্দিষ্ট কোনো কী (key) আছে কি না দেখতে [containsKey][map-containskey-javadoc] ব্যবহার করুন।

```java
fruitPrices.containsKey("apple");  // => true
fruitPrices.containsKey("orange"); // => false
```

[remove][map-remove-javadoc] দিয়ে এন্ট্রি মুছে ফেলুন।

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc] মেথডটি এন্ট্রির সংখ্যা রিটার্ন করে।

```java
fruitPrices.size();  // Returns 2
```

ম্যাপের কীগুলো বা ভ্যালুগুলোকে যথাক্রমে একটি Set বা একটি কালেকশন হিসেবে পেতে আপনি [keySet][map-keyset-javadoc] বা [values][map-values-javadoc] মেথড ব্যবহার করতে পারেন।

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
