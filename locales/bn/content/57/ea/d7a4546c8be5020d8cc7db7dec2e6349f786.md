# পরিচিতি

`OpenStruct` দিয়ে আপনি সহজেই একটি `Hash` থেকে অবজেক্ট তৈরি করতে পারেন। `Hash` কী (key) দিয়ে অ্যাক্সেস করতে না গিয়ে, বরং `OpenStruct` আমাদের মেথড ব্যবহার করে মান অ্যাক্সেস ও সেট করার সুযোগ দেয়।


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

এই পদ্ধতির একটি বাড়তি সুবিধা হলো, ব্লক সিনট্যাক্স ব্যবহার করার সময় আমরা একটি শর্টকাট কাজে লাগাতে পারি। যেসব ক্ষেত্রে একটি ব্লক কেবল একটি মেথড কল করে, সেখানে আপনি ব্লকটির জায়গায় `&:` আর তারপর মেথডের নাম বসাতে পারেন। উদাহরণস্বরূপ, নিচের দুটি লাইন একই কথা বোঝায়:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## স্ট্যান্ডার্ড লাইব্রেরি

আগের অনুশীলনীগুলোতে আপনি যে ক্লাসগুলো দেখেছেন, সেগুলো সবই Ruby-এর কোর লাইব্রেরির অংশ ছিল।

OpenStruct হলো Ruby-এর স্ট্যান্ডার্ড লাইব্রেরির অংশ (যাকে প্রায়ই ছোট করে "stdlib" বলা হয়), যা তারিখ, json আর নেটওয়ার্কিংয়ের মতো বিষয় নিয়ে কাজ করার জন্য ক্লাসের একটি সংগ্রহ। এটি আপনার কোড নিয়ে কাজ করা সহজ করে তোলার জন্য কিছু দরকারি সুবিধাও দেয়।

Core Library থেকে আসে না এমন ক্লাস, অর্থাৎ ভিন্ন ফাইলে থাকা আপনার নিজের কোড, stdlib-এর ক্লাস বা এক্সটার্নাল ডিপেন্ডেন্সি ব্যবহার করার সময়, সেগুলো ব্যবহারের আগে আমাদের `require` মেথড দিয়ে ইমপোর্ট করে নিতে হয়। উদাহরণস্বরূপ:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
