# Java ইনস্টল করা

Exercism CLI আর আপনার পছন্দের টেক্সট এডিটর ছাড়াও, Java-তে Exercism-এর অনুশীলনীগুলো নিয়ে প্র্যাকটিস করতে **Java Development Kit** (JDK) দরকার। JDK-তে Java Runtime _আর_ ডেভেলপমেন্ট টুলস, দুটোই থাকে (সবচেয়ে উল্লেখযোগ্যভাবে, Java কম্পাইলার)।

আজকাল JDK-এর অনেক ধরন আছে, যার কিছু ওপেন সোর্স। এখানে Exercism-এ আমরা [Adoptium-এর Eclipse Temurin][adoptium] ব্যবহার করার পরামর্শ দিই।

## সমর্থিত Java ভার্সন

Exercism-এর Java ট্র্যাক Java 25 LTS আর তার আগের ভার্সনগুলো সমর্থন করে।

## Eclipse Temurin ইনস্টল করা

আপনার সিস্টেমে Eclipse Temurin ইনস্টল করতে, তাদের চমৎকার [ইনস্টলেশনের নির্দেশাবলি][adoptium-installation-guide] দেখুন। সেখানে আপনার পছন্দের প্যাকেজ ম্যানেজার দিয়ে JDK ইনস্টল করার নির্দেশনা পাবেন, আর এতে সব প্রধান অপারেটিং সিস্টেমের জন্য ডাউনলোডযোগ্য ইনস্টলারের লিংকও আছে।

## Java-এর IDE

Java-এর জন্য অনেক বিনামূল্যের IDE পাওয়া যায়। এখানে কিছু জনপ্রিয় পছন্দ দেওয়া হলো:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Java এক্সটেনশনসহ Visual Studio Code][vscode-java]
