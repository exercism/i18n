# ম্যাপ ও সেট

একটি অ্যারে মানগুলোকে সংখ্যাযুক্ত অবস্থানে রাখে। কখনও কখনও কাজের লেবেলটি কোনো সংখ্যা হয় না।

## ম্যাপ

একটি **ম্যাপ** প্রতিটি **কী (key)**-এর সাথে একটি **টার্গেট** জুড়ে দেয়। কোনো কিছুকে তার কী (key) দিয়ে খুঁজুন, ম্যাপ আপনাকে তাই দেবে যা তার নিচে জমা করা ছিল।

`FMAP{K,T}` হলো `K` টাইপের কী (key) থেকে `T` টাইপের টার্গেটে যাওয়া একটি ম্যাপ। একটি প্রাণীর নাম তার থাকার জায়গার সাথে জুড়ে দেওয়া guide হলো `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## উত্তরটি সবসময় আবার অ্যাসাইন করুন

ওই মাঝের লাইনটি আবার দেখুন। `insert` বাড়তি জোড়াটিসহ ম্যাপটি উত্তর হিসেবে ফিরিয়ে দেয়, আর সেই উত্তরটি রেখে দিতেই হয়:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

এটি `FSTR`-এর ক্ষেত্রে যে নিয়ম, ঠিক সেই নিয়মই, আর একই কারণে। সাধারণত উত্তরটি হলো ঠিক সেই ম্যাপটিই যা ভেতরে দেওয়া হয়েছিল, জায়গায় বসেই বদলে যাওয়া; মাঝেমধ্যে, ম্যাপের জায়গা ফুরিয়ে গেলে, সেটি হয় আরও বড় একটি ম্যাপ। কোনটি ঘটছে তা আপনি বলতে পারেন না, তাই **উত্তরটিই ব্যবহার করুন আর পুরনো নামটি আর ব্যবহার করবেন না।** একটি `insert`-এর আগে থেকে পড়ে থাকা নামটি হয়তো বাসি হয়ে গেছে, নয়তো কাজে লাগার মতো কোনো ম্যাপকেই বোঝাচ্ছে না।

এর মানে আরও হলো, কোনো রুটিনকে দেওয়া ম্যাপও ওই রুটিন থেকে নিরাপদ নয়। মূলটি যদি টিকে থাকা দরকার হয়, তবে কনসেপ্ট পেজের `copy` দেখুন।

## এটা কি ওখানে আছে?

`has_ind` জিজ্ঞেস করে ম্যাপে কোনো কী (key) আছে কি না। নামটি "has index"-এর সংক্ষিপ্ত রূপ; এই ম্যাপগুলো যা-কে কী (key) বলে, সেটিই একেকটি index.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

যে কী (key) সেখানে নেই তা চাইলে এটি অভিযোগ করে **না**। `get` ওই টাইপের খালি মানটিই ফিরিয়ে দেয়, অর্থাৎ `INT`-এর জন্য শূন্য, আর `STR`-এর জন্য void, যা পরে অন্য কোথাও গিয়ে গোলমাল বাধাবে। তাই আনতে যাওয়ার আগে খুঁটে দেখুন:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## সেট

একটি **সেট** এমন সব মান ধারণ করে যেগুলোর কোনো পুনরাবৃত্তি নেই আর কোনো ক্রমও নেই। `FSET{T}` হলো `T` টাইপের মানের একটি সেট।

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

একই কিছু দুবার ইনসার্ট করলে থাকে মাত্র একটি কপি। সেটের কাজই তাই: জিনিস জড়ো করা, আর প্রতিটি কতবার এল তা ভুলে যাওয়া।

সেটের উপর `insert` এরপর ব্যবহার করার জন্য সেটটিই ফিরিয়ে দেয়, ঠিক যেমনটি ম্যাপের বেলায় করে, তাই প্রতিবারই এটি ফিরে অ্যাসাইন করুন।

## কতটি

`.size` দুটোতেই কাজ করে: একটি ম্যাপে কত জোড়া থাকে, আর একটি সেটে কত মান থাকে।
