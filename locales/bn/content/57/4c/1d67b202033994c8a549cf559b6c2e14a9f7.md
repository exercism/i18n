# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | ইনপুট     | ঠিকানা | নাল-টার্মিনেটেড ইনপুট স্ট্রিং                      |
| `$v0`    | আউটপুট    | বুলিয়ান | ইনপুটটি একটি আইসোগ্রাম কি না (`0` = `false`, `1` = `true`) |
| `$t0-9`  | অস্থায়ী   | যেকোনো | সাময়িক সংরক্ষণের জন্য ব্যবহৃত হয়                 |
