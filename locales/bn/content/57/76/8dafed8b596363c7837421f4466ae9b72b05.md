# ভূমিকা

## তারিখ-সময়

Java 8-এ প্রবর্তিত `java.time` প্যাকেজে তারিখ ও সময় নিয়ে কাজ করার জন্য বেশ কয়েকটি ক্লাস রয়েছে।

### `LocalDate`

`java.time.LocalDate` ক্লাসটি [ISO-8601 ক্যালেন্ডার সিস্টেম][iso-8601] অনুসারে টাইম-জোন ছাড়া একটি তারিখ প্রকাশ করে, যেমন `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

তারিখ অন্য তারিখের সাথে তুলনা করা যায়:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

একটি `LocalDate` ইনস্ট্যান্সে সেখান থেকে সময়ের অংশগুলো বের করার জন্য গেটার থাকে:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

একটি `LocalDate` ইনস্ট্যান্সে এতে সময়ের একক যোগ করার মেথড থাকে:

```exercism/note
এই মেথডগুলো একটি _নতুন_ `LocalDate` ইনস্ট্যান্স রিটার্ন করে এবং বিদ্যমান ইনস্ট্যান্স পরিবর্তন করে না, কারণ `LocalDate` ক্লাসটি ইমিউটেবল।
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

`java.time.LocalDateTime` ক্লাসটি [ISO-8601 ক্যালেন্ডার সিস্টেম][iso-8601] অনুসারে টাইম-জোন ছাড়া একটি তারিখ-সময় প্রকাশ করে, যেমন `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

আপনি একটি `LocalDate` ইনস্ট্যান্সকে `LocalDateTime`-এ রূপান্তর করতে পারেন:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### তারিখ-সময় ফরম্যাট করা

`LocalDate` ও `LocalDateTime` দুটোই `String`-এ এবং `String` থেকে রূপান্তর করার সময় [ISO-8601][iso-8601] স্ট্যান্ডার্ড নোটেশন ব্যবহার করে।

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

এভাবে একটি ভিন্ন ফরম্যাট ব্যবহার করে `String` থেকে `LocalDate` বা `LocalDateTime` পার্স করার চেষ্টা করা সম্ভব নয়।
পরিবর্তে, কাস্টম ফরম্যাট ব্যবহার করে তারিখ ফরম্যাট করতে আপনার `java.time.format.DateTimeFormatter` ব্যবহার করা উচিত:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

বিভিন্ন অঞ্চলের জন্য ফরম্যাট ও পার্স করার উদ্দেশ্যে কাস্টম ফরম্যাট তৈরি করার সময় একটি লোকেলও নির্দিষ্ট করা যায়:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
