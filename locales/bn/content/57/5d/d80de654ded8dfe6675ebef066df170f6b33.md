# পরিচিতি

Rust-এ, যে কোনো টাইপ [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator) ট্রেইট ইমপ্লিমেন্ট করে, তাকে ইটারেটর হিসেবে ধরা যায়।
Rust-এর বিল্ট-ইন [`collections`](https://doc.rust-lang.org/std/collections/index.html) কে `iter`, `iter_mut`, এবং `into_iter` মেথডের মাধ্যমে ইটারেটরে রূপান্তর করা যায়।
ইটারেটরগুলোর কাছে রয়েছে [শক্তিশালী মেথডের](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods) এক বিশাল সম্ভার, যেমন `collect`, `map`, `filter`, এবং `fold`, যা দিয়ে আপনি আপনার ডেটার উপর বিভিন্ন কাজ করতে পারেন।

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
