# নির্দেশনা

জাদুকর হতে চলা Elyse তার প্রশিক্ষণ চালিয়ে যাচ্ছে।
তার কাছে তাসের একটি ডেক আছে, যেটি নিয়ে সে কারিকুরি করতে চায়।

ব্যাপারটা সহজ করতে সে সাধারণত ২ থেকে ১০ নম্বরের তাস দিয়েই শুরু করে, যদিও কিছু কারিকুরিতে অতিরিক্ত (ফেস) কার্ড লাগতে পারে।

অ্যারে অ্যাক্সেসর `array[index]` এবং অবজেক্ট অ্যাক্সেসর (`object[key]` ও `object.key`)ও কখনোই ব্যবহার করা যাবে না।

## 1. প্রথম কার্ডটি নিন

Elyse `array[index]`, `.at(index)` বা `.shift()` ব্যবহার না করেই ডেকের প্রথম কার্ডটি হাজির করবে।
একেবারে জাদুর মতো।

```javascript
const deck = [5, 9, 7, 1, 8];

getFirstCard(deck);
// => 5
```

## 2. দ্বিতীয় কার্ডটি নিন

Elyse হাতের কৌশল দেখিয়ে `array[index]` বা `.shift()` ব্যবহার না করেই ডেকের দ্বিতীয় কার্ডটি হাজির করে।

```javascript
const deck = [3, 2, 10, 6, 7];

getSecondCard(deck);
// => 2
```

## 3. দুটি কার্ড অদলবদল করুন

Elyse ডেকের দুটি কার্ডের জায়গা বদলে দেবে।
এজন্য তাকে একটি ফাংশনও কল করতে হবে না।

```javascript
const deck = [10, 7];

swapTwoCards(deck);
// => [7, 10]
```

## 4. তিনটি কার্ড ঘুরিয়ে সাজান

আরও কিছু হাতের কৌশল দেখানোর জন্য Elyse তিনটি কার্ড নিয়ে দ্রুত উপরের কার্ডটি পিছনে নিয়ে যায়, ফলে মাঝের কার্ডটি প্রথম কার্ড হয়ে যায় আর আগের নিচের কার্ডটি মাঝের কার্ড হয়ে যায়।
এজন্য তাকে একটি ফাংশনও কল করতে হবে না।

```javascript
const deck = [2, 6, 10];

shiftThreeCardsAround(deck);
// => [6, 10, 2]
```

## 5. নাম দেওয়া স্তূপটি বাছুন

Elyse ডেকটিকে দুটি স্তূপে ভাগ করবে।
এরপর সে দর্শককে দুটি স্তূপের একটি বাছতে বলে, যার নাম আমরা দেব `chosen`।
`disregarded` স্তূপটির আর কোনো প্রয়োজন নেই, তাই সে সেটি উধাও করে দেয়।
এজন্য তাকে একটি ফাংশনও কল করতে হবে না।

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

pickNamedPile({ chosen, disregarded });
// => [5, 4]
```

## 5. বাছাই করা স্তূপটি অদলবদল করুন

দুর্ভাগ্যবশত দর্শক বারবার "ভুল" স্তূপটিই বেছে নেয়, কিন্তু কিছু চটজলদি চতুর জাদু দিয়ে Elyse `chosen` স্তূপের নাম বদলে `disregarded` করে দেয় আর `disregarded` স্তূপের নাম করে দেয় `chosen`।
এজন্য তাকে একটি ফাংশনও কল করতে হবে না।

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

swapNamedPile({ chosen, disregarded });
// => { chosen: [7, 10], disregarded: [5, 4] }
```
