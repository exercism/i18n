# নির্দেশনা

Boris মডেল ট্রেনের এক বড় ভক্ত, আর নিজের এই ভালোবাসা সবার সঙ্গে ভাগ করে নিতে তিনি একটি নিউজলেটার শুরু করার সিদ্ধান্ত নিয়েছেন। শুরুতে তিনি এই শখের সঙ্গে যুক্ত বন্ধু ও পরিচিতদের কাছে নিউজলেটারের প্রথম সংখ্যাটি পাঠাবেন; তাদের ইমেইল একটি টেক্সট ফাইলে সংরক্ষিত আছে।

ইঙ্গিত: ফাইল সংক্রান্ত কাজের জন্য [simplifile](https://hexdocs.pm/simplifile/simplifile.html) মডিউলটি ব্যবহার করুন।

## 1. একটি ফাইল থেকে ইমেইল পড়ুন

`read_emails` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি এমন একটি টেক্সট ফাইলের পাথ স্ট্রিং নেয় যাতে নতুন লাইনে আলাদা করা ইমেইল থাকে, এবং ফাইল থেকে ইমেইলগুলোর একটি অ্যারে রিটার্ন করে।

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. লেখার জন্য একটি লগ ফাইল তৈরি করুন

ইমেইল পাঠানো এমন একটি কাজ যা অনেক অপ্রত্যাশিত কারণে ব্যর্থ হতে পারে, যেমন ইমেইলে টাইপো বা সাময়িক নেটওয়ার্ক সমস্যা। সব বন্ধুকে ডুপ্লিকেট না পাঠিয়ে আবার ইমেইল পাঠানোর চেষ্টা করতে পারবেন, তা নিশ্চিত করতে যারা ইতিমধ্যে ইমেইল পেয়েছেন তাদের লগ করে রাখতে হবে। এজন্য একটি লগ ফাইল দরকার।

`create_log_file` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি ফাইল পাথ নেয় এবং ওই জায়গায় একটি নতুন খালি ফাইল তৈরি করে।

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. পাঠানো ইমেইল লগ করুন

`log_sent_email` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি লগ ফাইলের পাথ এবং ইমেইল থাকা একটি স্ট্রিং নেয়। এটি ফাইলে ইমেইলটি লেখে, তারপর একটি নিউলাইন দেয়।

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. নিউজলেটার পাঠান

এখন যেহেতু ইমেইল পাঠানোর প্রক্রিয়ার সব মৌলিক অংশ আপনার কাছে আছে, এগুলোকে একটি মাত্র ফাংশনে একত্র করতে হবে।

`send_newsletter` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ইমেইল থাকা ফাইলের পাথ, একটি লগ ফাইলের পাথ, এবং একটি অ্যানোনিমাস ফাংশন নেয়, যেটি নির্দিষ্ট একটি ইমেইলে ইমেইল পাঠায়।

এটি প্রদত্ত ফাইল থেকে সব ইমেইল পড়বে এবং প্রত্যেকটিতে ইমেইল পাঠানোর চেষ্টা করবে। ইমেইল পাঠানো অ্যানোনিমাস ফাংশনটি যদি একটি `Ok` মান রিটার্ন করে, তবে ইমেইলটি লগ ফাইলে লিখে রাখবে। ইমেইল পাঠানোর সঙ্গে সঙ্গেই যেন এটি করা হয়, তা নিশ্চিত করুন।

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
