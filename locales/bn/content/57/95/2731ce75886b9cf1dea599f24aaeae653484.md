# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | বইয়ের ওয়ার্ডের অ্যারে         |
| `$a1`    | ইনপুট     | ইন্টিজার | বইয়ের সংখ্যা             |
| `$v0`    | আউটপুট    | ইন্টিজার | দাম, সেন্টে             |
| `$t0-9`  | টেম্পোরারি | যেকোনো   | সাময়িক স্টোরেজের জন্য ব্যবহৃত  |
