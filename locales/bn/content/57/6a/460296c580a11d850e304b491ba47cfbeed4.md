# নির্দেশনা

এই অনুশীলনীতে আপনি সেভিংস অ্যাকাউন্ট নিয়ে কাজ করবেন।
প্রতি বছর আপনার সেভিংস অ্যাকাউন্টের ব্যালেন্স তার সুদের হার অনুযায়ী হালনাগাদ হয়।
আপনার ব্যাঙ্ক আপনাকে যে সুদের হার দেয়, তা নির্ভর করে আপনার অ্যাকাউন্টে থাকা টাকার পরিমাণের উপর (অর্থাৎ তার ব্যালেন্স):

- `0` ডলারের কম ব্যালেন্সে সুদের হার 3.213% (ব্যালেন্স আরও ঋণাত্মক হয়ে যায়)।
- `0` ডলার বা তার বেশি এবং `1000` ডলারের কম ব্যালেন্সে সুদের হার 0.5%।
- `1000` ডলার বা তার বেশি এবং `5000` ডলারের কম ব্যালেন্সে সুদের হার 1.621%।
- `5000` ডলার বা তার বেশি ব্যালেন্সে সুদের হার 2.475%।

আপনার সামনে চারটি কাজ আছে, যার প্রতিটিতে ব্যালেন্স আর তার সুদের হার নিয়ে কাজ করতে হবে।

## 1. সুদের হার হিসাব করুন

নির্দিষ্ট ব্যালেন্স অনুযায়ী সুদের হার হিসাব করতে `interest_rate` ফাংশনটি ইমপ্লিমেন্ট করুন:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. সুদ হিসাব করুন

নির্দিষ্ট ব্যালেন্স অনুযায়ী সুদ হিসাব করতে `yearly_interest` ফাংশনটি ইমপ্লিমেন্ট করুন:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. বার্ষিক ব্যালেন্স হালনাগাদ হিসাব করুন

সুদের হার বিবেচনায় নিয়ে বার্ষিক ব্যালেন্স হালনাগাদ হিসাব করতে `annual_balance_update` ফাংশনটি ইমপ্লিমেন্ট করুন:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. কাঙ্ক্ষিত ব্যালেন্সে পৌঁছাতে কত বছর লাগবে তা হিসাব করুন

প্রতি বছর ব্যালেন্সের সাথে সুদ যোগ হয়, এটি বিবেচনায় রেখে কাঙ্ক্ষিত ব্যালেন্সে পৌঁছাতে সর্বনিম্ন কত বছর লাগবে তা হিসাব করতে `years_until_desired_balance` ফাংশনটি ইমপ্লিমেন্ট করুন।
এর মানে হলো, এক বছর পরের ব্যালেন্স: শুরুর ব্যালেন্স + শুরুর ব্যালেন্সের সুদ।
দ্বিতীয় বছর পরের ব্যালেন্স হলো এক বছর পরের ব্যালেন্স + এক বছর পরের ব্যালেন্সের সুদ।
এভাবে চলতে থাকবে, যতক্ষণ না চলতি বছরের ব্যালেন্স লক্ষ্য ব্যালেন্সের সমান বা তার বেশি হয়।

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `int`.
