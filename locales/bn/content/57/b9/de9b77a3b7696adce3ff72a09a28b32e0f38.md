# অতিরিক্ত নির্দেশনা

## আউটপুট ফরম্যাট

ডায়মন্ডটি একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে আউটপুট দিন, যেখানে প্রতিটি সারির শেষে একটি নিউলাইন ক্যারেক্টার থাকবে।

একটি উদাহরণ আউটপুট হবে `"  A  \n B B \nC   C\n B B \n  A  \n"`

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | বাইট    | অক্ষর                          |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড ফলাফল স্ট্রিং    |
| `$t0-9`  | সাময়িক      | যেকোনো  | সাময়িক সংরক্ষণের জন্য          |
