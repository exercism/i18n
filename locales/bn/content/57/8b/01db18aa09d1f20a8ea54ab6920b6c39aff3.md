# নির্দেশনা

Lamont একটি Lisp ভিনগ্রহী, যে নিজের একটি ভিডিও গেম লিখতে চায়। এর মধ্যে একটি কাজে সে আপনার সাহায্য চেয়েছে, তা হলো একটি হাই স্কোর তালিকার হিসাব রাখা।

## 1. হাই স্কোর টেবিল তৈরি করা

`make-high-score-table` নামের একটি ফাংশন ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং একটি নতুন খালি হ্যাশ টেবিলে ইভ্যালুয়েট হয়:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. টেবিলে একজন প্লেয়ার যোগ করা

টেবিলে একজন প্লেয়ার যোগ করতে `add-player` নামের একটি ফাংশন ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়:
- হাই স্কোর টেবিলটি
- কিওয়ার্ড হিসেবে প্লেয়ারের নাম

প্লেয়ারের প্রাথমিক স্কোর শূন্য সেট করুন।

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. একজন প্লেয়ারের স্কোর সেট করা

একজন প্লেয়ারের স্কোর সেট করতে `set-score` নামের একটি ফাংশন ডিফাইন করুন, যেটি তিনটি আর্গুমেন্ট নেয়:
- হাই স্কোর টেবিলটি
- কিওয়ার্ড হিসেবে প্লেয়ারের নাম
- ইন্টিজার হিসেবে প্লেয়ারের স্কোর

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. টেবিল থেকে একটি স্কোর পাওয়া

টেবিল থেকে একজন প্লেয়ারের স্কোর পেতে `get-score` নামের একটি ফাংশন ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়:
- হাই স্কোর টেবিলটি
- কিওয়ার্ড হিসেবে প্লেয়ারের নাম

এই ফাংশনটি প্লেয়ারের জন্য সংরক্ষিত স্কোরে ইভ্যালুয়েট হওয়া উচিত।
যদি সেই প্লেয়ারের জন্য কোনো স্কোর সংরক্ষিত না থাকে, অথবা সেই প্লেয়ার এখনো টেবিলে না থাকে, তাহলে `0` ইভ্যালুয়েট হবে।

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. টেবিল থেকে একজন প্লেয়ার সরানো

হাই স্কোর টেবিল থেকে একজন প্লেয়ার সরাতে `remove-player` নামের একটি ফাংশন ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়:
- হাই স্কোর টেবিলটি
- কিওয়ার্ড হিসেবে প্লেয়ারের নাম

এই ফাংশনটি এমন ক্ষেত্রগুলোও সুন্দরভাবে সামলাতে পারবে, যেখানে প্লেয়ারকে এখনো টেবিলে যোগ করা হয়নি।
স্বাভাবিকভাবেই, একজন প্লেয়ার সরিয়ে ফেলার পর টেবিল থেকে তার স্কোর নিলে সেটি শূন্য হবে।

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
