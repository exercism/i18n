# ইঙ্গিত

## সাধারণ

- [সমানতা][equality]: C#-এ সমতার তুলনা কীভাবে কাজ করে, রেফারেন্স টাইপ ও ভ্যালু টাইপের সমতাসহ।
- [HashCode][hash-code]: হ্যাশ কোড কীভাবে তৈরি ও একত্রিত করতে হয়
- [GetHashCode][get-hash-code]: API ডকুমেন্টেশন
- [HashSet][hash-set]: API ডকুমেন্টেশন

## 1. নিশ্চিত করুন যে মুখের বৈশিষ্ট্যগুলো মিলে যায়

রেফারেন্স টাইপগুলোকে মান হিসেবে তুলনা করা নিয়ে বিস্তারিত আলোচনা এই [নিবন্ধ][value-equality]-এ আছে।

## 2. সিস্টেম অ্যাডমিনিস্ট্রেটর অথেন্টিকেট করুন

এটি আসলে টাস্ক ১-এ শেখা বিষয়গুলোকে একেবারে সাধারণভাবে রিকার্সিভ উপায়ে কাজে লাগানোর বিষয় মাত্র।

## 3. নতুন পরিচয় রেজিস্টার করুন

অনন্য মানের একটি সংগ্রহ সামলানোর সবচেয়ে পারফরম্যান্ট এবং "স্বাভাবিক" উপায় হলো একটি [হ্যাশ সেট][hash-set] ব্যবহার করা। নিজের কম্পিউটারে টেস্ট পাস হয়ে কিন্তু ওয়েবসাইটে ফেল করলে, `Authenticator` ক্লাসে `static` মেম্বারের বদলে ইনস্ট্যান্স মেম্বার ব্যবহার করে দেখুন।

## 4. অবৈধ পরিচয় অথেন্টিকেট হওয়া ঠেকান

[`HashSet<T>.Contains()`][hash-set-contains] মেথডটি বিবেচনা করুন। নিজের কম্পিউটারে টেস্ট পাস হয়ে কিন্তু ওয়েবসাইটে ফেল করলে, `Authenticator` ক্লাসে `static` মেম্বারের বদলে ইনস্ট্যান্স মেম্বার ব্যবহার করে দেখুন।

## 5. অথেন্টিকেট করার একাধিক চেষ্টা শনাক্ত করতে ডায়াগনস্টিক যোগ করুন

এই [ডকুমেন্টেশন][reference-equality]-এ মানের বদলে ইনস্ট্যান্স তুলনা করার বিষয়টি নিয়ে আলোচনা করা হয়েছে।
