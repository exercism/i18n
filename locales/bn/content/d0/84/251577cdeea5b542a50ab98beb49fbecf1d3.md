# পরিচিতি

## একাধিক রিটার্ন ভ্যালু

Swift-এ ফাংশন একটি টাপল রিটার্ন করে একাধিক মান রিটার্ন করতে পারে:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## return কিওয়ার্ড বাদ দেওয়া

যখন কোনো ফাংশনের বডি কেবল একটি এক্সপ্রেশন দিয়ে গঠিত হয়, তখন আপনি `return` কিওয়ার্ডটি বাদ দিতে পারেন:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

এই ইমপ্লিসিট রিটার্ন সিনট্যাক্স কেবল টাপল রিটার্ন করা ফাংশনের ক্ষেত্রেই নয়, বরং মান রিটার্ন করে এমন সব ফাংশনের ক্ষেত্রেই প্রযোজ্য।
