# নির্দেশনা

আপনার পরিচিত Erin একাধিক ইভেন্টের জন্য হাজার হাজার হ্যান্ডবিল প্রিন্ট করবেন, আর এতে আপনার সাহায্য দরকার! তিনি আপনাকে একটি লিফলেটের লেআউট তৈরি করতে বলেছেন, যাতে থাকবে একটি হেডার, ঐচ্ছিক একটি তারিখ এবং শিল্পীদের একটি তালিকা, যেখানে প্রত্যেক শিল্পীর সঙ্গে যুক্ত থাকবে একটি _ইউনিকোড আইকন_। লক্ষ্য হলো আপনার এই নতুন দারুণ লিফলেট ডিজাইনটি `print` করা ও বিতরণ করা, আর সফল হতে আপনার Python স্ট্রিং ফরম্যাটিংয়ের সব দক্ষতা কাজে লাগাতে হবে।

## 1. বড় হাতের অক্ষরের হেডারসহ ক্লাস তৈরি করুন

`capitalize_header` ফাংশনটি একটি ইভেন্টের নাম নেবে এবং ইভেন্টের নামটির বড় হাতের অক্ষরের রূপটি রিটার্ন করবে।

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. তারিখটি ফরম্যাট করুন

নতুন একটি মেথড `format_date` তৈরি করুন, যা একটি তালিকা নেয়; তালিকাটিতে একটি তারিখ, একটি মাস ও একটি বছর থাকে। এটি ফরম্যাট করা তারিখটি `<month_name> <date>, <year>` ফরম্যাটে দেখায়।

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. ইউনিকোড কোড পয়েন্টগুলো আইকন হিসেবে রেন্ডার করুন

`display_icons` মেথডটি কল করা হলে, পাস করা ইউনিকোড কোড পয়েন্টের তালিকাটি _আইকন_-এর একটি `list` হিসেবে রেন্ডার হয়ে রিটার্ন হওয়া উচিত।

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. তৈরি হওয়া লিফলেটটি দেখান

এখন আপনি উপরের সব ফাংশন ব্যবহার করবেন এবং সেগুলোকে `print_leaflet` ফাংশনে একত্র করবেন।
এটি একটি `event_name`, একটি `icons` তালিকা, একটি `authors` তালিকা এবং একটি `event_date` তালিকা নেবে।

পোস্টারটি নিচের লেআউট অনুসরণ করবে।

লিফলেটটি আয়তক্ষেত্রের আকারে একটি নির্দিষ্ট লেআউট অনুসরণ করে:

- প্রথম ও শেষ সারিতে ২০টি অ্যাস্টেরিস্ক থাকে। `"*"`
- প্রতিটি সেকশনের উপরে ও নিচে একটি খালি সারি দিয়ে তা আলাদা করা হয়।
- একটি খালি সারিতে কেবল শুরুতে একটি এবং শেষে একটি অ্যাস্টেরিস্ক থাকে।
- প্রথম সেকশনটি লিফলেটের হেডার, এই শিরোনামটি বড় হাতের অক্ষরে লেখা।
- দ্বিতীয় সেকশনটি ঐচ্ছিক তারিখ; তারিখটি পাস না করা হলে এই সেকশনটি একটি খালি সারি হওয়া উচিত।
- তৃতীয় ও শেষ সেকশনটি শিল্পীদের তালিকা, যেখানে প্রত্যেক শিল্পীর সঙ্গে সংশ্লিষ্ট আইকনটি যুক্ত থাকে।

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
