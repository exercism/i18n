# ভূমিকা

Gleam-এ `Nil` হলো এমন একটি টাইপ, যার একটিমাত্র মান থাকে, যার নামও `Nil`। অন্য ভাষার `void`-এর মতোই এটি সেই ক্ষেত্রে ব্যবহার করা হয়, যখন কোনো ফাংশনের রিটার্ন করার মতো উপযুক্ত আর কোনো মান থাকে না।

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Gleam-এ মানগুলো অন্য কিছু ভাষার মতো "nil-able" বা "nullable" নয়। একটি মান কেবল তখনই `Nil` হতে পারে যদি তার টাইপ `Nil` হয়, আর অন্য যেকোনো টাইপের মান কখনোই `Nil` হতে পারে না।
