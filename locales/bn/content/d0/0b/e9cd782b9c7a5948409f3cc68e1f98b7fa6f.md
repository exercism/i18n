# ইনস্টলেশন

## Mac

homebrew দিয়ে ইনস্টল করতে `brew install swi-prolog` চালান।
অথবা, [SWI Prolog ওয়েবসাইট](http://www.swi-prolog.org/download/devel) থেকে আপনার মেশিনের জন্য সোর্স ডাউনলোড করুন।

## Windows

[SWI Prolog ওয়েবসাইট](http://www.swi-prolog.org/download/devel) থেকে আপনার মেশিনের জন্য সোর্স ডাউনলোড করুন।

## Linux

[এখানে](http://www.swi-prolog.org/build/unix.html) থেকে আপনার ডিস্ট্রোর জন্য নির্দেশাবলি অনুসরণ করুন।
