# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | ১..৬৪ রেঞ্জের ভেতরে থাকা বর্গসংখ্যা |
| `$v0`    | আউটপুট    | ইন্টিজার | আউটপুটের নিচের ৩২ বিট            |
| `$v1`    | আউটপুট    | ইন্টিজার | আউটপুটের উপরের ৩২ বিট           |
| `$t0-9`  | টেম্পোরারি | যেকোনো  | সাময়িক সংরক্ষণের জন্য           |
