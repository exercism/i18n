# প্লেসহোল্ডার

## bash দিয়ে কীভাবে সমাধান করবেন

`bash`-এ ডেটটাইম স্ট্রিং **পার্স** করার কোনো বিল্ট-ইন উপায় নেই।
এই অনুশীলনীতে আপনাকে একটি এক্সটার্নাল ইউটিলিটি ডাকতে হবে।

* GNU `date` কমান্ডের `-d` অপশন [নানা ধরনের ফরম্যাট][gnu-date] পার্স করতে পারে।
* Mac ব্যবহারকারীদের জন্য দেখুন [BSD `date` কমান্ড][bsd-date] এবং এর `-f` অপশন।
* Perl সহজেই পাওয়া যায়, আর এর [`Time::Piece` মডিউল][time-piece] দিয়ে টাইমস্ট্যাম্প পার্স করা যায়।

bash কোনো এক্সটার্নাল টুল ছাড়াই তারিখ **ফরম্যাট** করতে পারে।
একটি ইন্টিজার টাইম ভ্যালু (এপক থেকে সেকেন্ড) দেওয়া থাকলে, [`printf`-এর `%()T` ফরম্যাটার][bash-printf] "strftime"-ধাঁচের ফরম্যাটিং প্রয়োগ করতে পারে।

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```
