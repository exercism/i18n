# টেস্ট

টেস্ট চালানোর জন্য নিচের কমান্ডটি চালান:

```bash
make
```

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
ডিফল্টভাবে টেস্ট চালালে শুধু একটি টেস্ট (প্রথমটি) চালানো হয়।
এটি ইচ্ছাকৃতভাবেই করা হয়েছে, যাতে আপনি শুধু ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।
এটি পাস হয়ে গেলে `TEST_IGNORE()` লাইনটি মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন।
সব টেস্ট চালু হয়ে গেলে এবং আপনার ইমপ্লিমেন্টেশন সেগুলো সব পাস করালে, আপনি অনুশীলনীটি সমাধান করে ফেলেছেন!
