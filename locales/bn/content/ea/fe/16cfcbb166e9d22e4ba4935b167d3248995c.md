# নির্দেশনা

আপনি! হ্যাঁ, আপনি, সাহসী লিস্পার! [লেনি][alien] নামের Lisp এলিয়েনটির আপনার সাহায্য দরকার! লেনি বাকি সব Lisp এলিয়েনের সাথে আড্ডা দিতে যেতে চায়, কিন্তু তার বাবা-মা বলেছে ঘর পরিষ্কার না হলে সে কোথাও যাবে না।

সমস্যা হলো, লেনি মেঝেটা প্রায় দেখতেই পায় না! লেনি বুঝতেই পারে না কোনটা অ্যাটম আর কোনটা কনস, কোনটা সিম্বল আর কোনটা কিওয়ার্ড, কোনটা `car` আর কোনটা `cdr`!

এই জঞ্জাল গুছিয়ে ফেলতে লেনিকে সাহায্য করবেন? [আপনার বন্ধনীগুলো][xkcd] ভুলে যাবেন না, এগুলো আপনার লাগবেই!

## 1. সিম্বল সম্পর্কে লেনিকে মনে করিয়ে দিন

শুরু করার আগে সিম্বল আর কিওয়ার্ড দেখতে কেমন হয়, সেটা লেনির একবার মনে করা দরকার। অনেক দিন হয়ে গেছে, শেষবার সে কিছু গুছিয়েছিল... দুটি ফাংশন ডিফাইন করে লেনিকে সাহায্য করুন: `lennys-favorite-food`, যেটা ইভ্যালুয়েট করলে কিছু একটা সিম্বল পাওয়া যায়, আর `lennys-secret-keyword`, যেটা ইভ্যালুয়েট করলে কিছু একটা কিওয়ার্ড পাওয়া যায়। উদাহরণ:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

মনে রাখবেন, আপনি চাইলে যেকোনো সিম্বল বা কিওয়ার্ড রিটার্ন করতে পারেন (যদি লাসাগনা পছন্দ না হয় বা এলিয়েনে বিশ্বাস না থাকে)।

## 2. অ্যাটম আর কনসের পার্থক্য করতে লেনিকে সাহায্য করুন

সিম্বল আর কিওয়ার্ড নিয়ে একবার মনে করিয়ে নেওয়া হয়ে গেলে, এবার পরিষ্কারের পালা! ঘরে ছড়িয়ে থাকা সব S-এক্সপ্রেশন গুছিয়ে ফেলতে হলে কোনটা কনস আর কোনটা অ্যাটম, সেটা বের করতে লেনির সাহায্য দরকার। আপনি দুটি ফাংশন ইমপ্লিমেন্ট করে সাহায্য করতে পারেন, `is-an-atom-p` আর `is-a-cons-p`:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

এই অংশে লিস্পের বেশ কিছু বিল্ট-ইন ফাংশন আছে, যেগুলো আপনার কাজে লাগতে পারে। এছাড়া আপাতত `T`-কে ট্রু আর `NIL`-কে ফলস ধরে নিতে পারেন।

## 3. লেনির কনসগুলো ভাগ করতে সাহায্য করুন

শেষে, লেনির কনসগুলো এত ভারী যে পরিপাটি করে গুছিয়ে রাখা যায় না, তাই সেগুলোকে ছোট ছোট অংশে ভাগ করা দরকার। আরও দুটি ফাংশন ডিফাইন করে এই কনসগুলো ভাঙতে লেনিকে সাহায্য করবেন (`first-thing` আর `rest-of-it`)?

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

এখানেও Common Lisp-এর কিছু বিল্ট-ইন ফাংশন কাজে লাগতে পারে।
