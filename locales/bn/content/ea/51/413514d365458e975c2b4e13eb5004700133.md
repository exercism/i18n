# জেনেরিক ডেটা টাইপ

Cairo-তে জেনেরিকস দিয়ে আপনি পুনরায় ব্যবহারযোগ্য কোড লিখতে পারেন, যা বিভিন্ন টাইপের সাথে কাজ করে; এতে কোডের পুনরাবৃত্তি এড়ানো যায় এবং রক্ষণাবেক্ষণযোগ্যতাও বাড়ে।

আপনি ফাংশন, স্ট্রাক্ট, এনাম, ট্রেইট আর মেথডের সাথে জেনেরিকস ব্যবহার করতে পারেন।

## জেনেরিক ফাংশন

একটি জেনেরিক ফাংশন আলাদা আলাদা ইমপ্লিমেন্টেশন ছাড়াই বিভিন্ন টাইপের উপর কাজ করে।

যেমন:

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

এখানে `T` হলো যেকোনো টাইপের জন্য একটি প্লেসহোল্ডার।

তবে Cairo-তে জেনেরিক টাইপ যেন নির্দিষ্ট কিছু নিয়ম মেনে চলে, তা নিশ্চিত করতে ট্রেইট বাউন্ড দরকার।

যদি `T` ড্রপযোগ্য হওয়া দরকার হয়, তাহলে আমরা সিগনেচারটি এভাবে আপডেট করতে পারি:

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

`Drop` বা `PartialOrd`-এর মতো ট্রেইট বাউন্ড নির্দিষ্ট কিছু অপারেশনের জন্য জেনেরিকসে কনস্ট্রেইন্ট যোগ করে।

## অ্যানোনিমাস কনস্ট্রেইন্ট

কোনো ফাংশনে যদি সরাসরি কোনো ট্রেইট ইমপ্লিমেন্টেশন ব্যবহার না হয়, তাহলে `+` দিয়ে অ্যানোনিমাস কনস্ট্রেইন্ট লিখতে পারেন:

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

এতে `TPartialOrd`-এর মতো ট্রেইটের নাম দিতে হয় না, ফলে লেখা সংক্ষিপ্ত হয়।

## জেনেরিকসহ স্ট্রাক্ট

স্ট্রাক্টে জেনেরিকস ব্যবহার করলে ফিল্ডগুলো নমনীয় রাখা যায়।

যেমন:

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

কোনো স্ট্রাক্টে যদি একাধিক জেনেরিক টাইপ দরকার হয়, তাহলে শুধু আরও প্লেসহোল্ডার যোগ করুন:

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## জেনেরিকসহ এনাম

এনামও জেনেরিক ডেটা টাইপ ধারণ করতে পারে।

যেমন:

```rust
enum Option<T> {
    Some: T,
    None,
}
```

`Option<T>` এনামটি যেকোনো টাইপের ঐচ্ছিক মান প্রকাশ করতে পারে।

একইভাবে, `Result<T, E>` দিয়ে সফলতা ও ব্যর্থতার টাইপ নির্ধারণ করা যায়:

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## জেনেরিক মেথড

মেথডেও জেনেরিকস ব্যবহার করা যায়।

যেমন:

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

আপনি নির্দিষ্ট জেনেরিক টাইপের জন্যও মেথড ডিফাইন করতে পারেন, যেমন `Wallet<u128>`:

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## জেনেরিক টাইপ মেশানো

জেনেরিকস জটিল সমন্বয়ও সামলাতে পারে।

যেমন, ভিন্ন টাইপের দুটি `Wallet` ইনস্ট্যান্স একসাথে মেশানো:

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

`+Drop` কনস্ট্রেইন্ট যোগ করলে কম্পাইলার রিসোর্সগুলো সঠিকভাবে সামলানো নিশ্চিত করে।

জেনেরিকস শক্তিশালী, তবে এর কনস্ট্রেইন্টগুলো সাবধানে সামলাতে হয়।

পুনরায় ব্যবহারযোগ্য, টাইপ-অ্যাগনস্টিক ও সংক্ষিপ্ত কোড লিখতে এগুলো ব্যবহার করুন।
