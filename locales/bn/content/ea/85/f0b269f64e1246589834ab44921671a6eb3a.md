# ভূমিকা

ফাংশন ডিক্লারেশন ও ফাংশন এক্সপ্রেশন ছাড়াও JavaScript-এ ফাংশন ডিফাইন করার আরও একটি খুব সংক্ষিপ্ত সিনট্যাক্স আছে।
এই ফাংশনগুলোকে _অ্যারো ফাংশন_ বলা হয়।

এই কনসেপ্টে আমরা একটি অ্যারো ফাংশন লেখার জন্য ব্যবহৃত সিনট্যাক্সে মনোযোগ দেব।
অ্যারো ফাংশন কীভাবে কাজ করে তা নিয়ে কিছু পার্থক্য আছে, যেমন _this_ বাইন্ডিং, যা অন্য কনসেপ্টে আলোচনা করা হবে।

এখানে একটি ফাংশন ডিক্লারেশন ও একটি অ্যারো ফাংশনের মধ্যে তুলনা দেওয়া হলো।

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

উপরে আপনি দেখতে পাবেন যে অ্যারো ফাংশনের সিনট্যাক্স:

1. `function` কিওয়ার্ডটি সরিয়ে দেয়
2. `addUpTwoNumbers` আইডেন্টিফায়ারটিকে `const` হিসেবে ডিক্লেয়ার করে
3. একটি ফ্যাট অ্যারো `=>` যোগ করে

যদি ফাংশন বডিতে কেবল একটি রিটার্ন স্টেটমেন্ট থাকে, যেমন উপরের উদাহরণে, তাহলে `{}` এবং `return` কিওয়ার্ড বাদ দেওয়া যায়।

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

একটি অ্যারো ফাংশন থেকে কেবল একটি অবজেক্ট রিটার্ন করার বিশেষ ক্ষেত্রে, রিটার্ন স্টেটমেন্ট বাদ দিতে হলে অবজেক্টটির চারপাশে প্রথম বন্ধনী দিতে হয়।

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

প্যারামিটারের চারপাশে বন্ধনী ব্যবহার করা প্যারামিটারের সংখ্যার উপর নির্ভর করে।

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
