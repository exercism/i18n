# পরিচিতি

Common Lisp-এ নামযুক্ত প্যারামিটারকে কিওয়ার্ড প্যারামিটার বলা হয়।

কিওয়ার্ড প্যারামিটার ল্যাম্বডা লিস্টে `&key` ল্যাম্বডা লিস্ট কিওয়ার্ড দিয়ে চিহ্নিত করা হয়। কিওয়ার্ড প্যারামিটার আবশ্যক নয়, এদের একটি ডিফল্ট মান থাকতে পারে, এবং এরা একটি "supplied-p প্যারামিটার"-ও নির্দিষ্ট করতে পারে, যা প্যারামিটারটির জন্য কোনো আর্গুমেন্ট দেওয়া হয়েছে কি না তার উপর নির্ভর করে "ট্রু" বা "ফলস" হবে।

```lisp
(defun keyword-parameter (&key (arg -1) arg)
(keyword-parameter)         ; => -1
(keyword-parameter :arg 13) ; => 13
```

ফাংশনে আর্গুমেন্ট দেওয়ার সময় কিওয়ার্ড প্যারামিটারগুলো তাদের "কিওয়ার্ড নাম" দিয়ে নির্দিষ্ট করা হয়, যা ডিফল্টভাবে প্যারামিটার নামের কিওয়ার্ড সিম্বল সংস্করণ (_অর্থাৎ_ কিওয়ার্ড প্যারামিটার `name`-এর কিওয়ার্ড নাম `:name`)। শুধু প্যারামিটার নামের বদলে কিওয়ার্ড নাম ও প্যারামিটার নামের একটি লিস্ট ব্যবহার করে কিওয়ার্ড প্যারামিটারের জন্য অন্য একটি নাম নির্দিষ্ট করাও সম্ভব:

```lisp
(defun other-keyword-name (&key ((other-name arg))) (list arg))
(other-keyword-name 'other-name 5) ; => (5)
```

একাধিক ধরনের প্যারামিটার অন্য ধরনের প্যারামিটারের (অপশনাল ও কিওয়ার্ড প্যারামিটার) সঙ্গে মেলানো গেলেও এটি সমস্যার কারণ হতে পারে, তাই সাবধানে করা উচিত। Practical Common Lisp-এর ["Mixing Different Parameter Types"][pcl-function] অংশটি দেখুন।

[pcl-function]: http://www.gigamonkeys.com/book/functions.html
