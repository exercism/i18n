# ভূমিকা

## শর্তমূলক স্টেটমেন্ট

শর্তমূলক স্টেটমেন্ট হলো সিদ্ধান্ত গ্রহণের স্টেটমেন্ট, যা হয় সাইড এফেক্ট চালাতে পারে, নয়তো একটি প্রোগ্রামে এক্সিকিউশনের প্রবাহ নিয়ন্ত্রণ করতে পারে।
শর্তমূলক স্টেটমেন্টের মধ্যে রয়েছে `if`, `if/else`, `switch` এবং `ternary` স্টেটমেন্ট।

শর্তমূলক স্টেটমেন্ট দিয়ে কোনো মান বা মানগুলোর সম্পর্ক নিয়ে প্রশ্ন করা হয়।
প্রশ্নটির মূল্যায়ন হয় একটি বুলিয়ান উত্তরে, তবে `if` স্টেটমেন্ট নিজে যেকোনো মান রিটার্ন করতে পারে, আবার শুধু একটি সাইড এফেক্টও চালাতে পারে।

## if স্টেটমেন্ট

সবচেয়ে সরল `if` স্টেটমেন্ট একটি এক্সপ্রেশন মূল্যায়ন করে এবং একটি মাত্র লাইন এক্সিকিউট করে।
যে এক্সপ্রেশনটি পরীক্ষা করা হয় তা সবসময় প্রথম বন্ধনীর মধ্যে রাখা হয়।

এটি একটি সাইড এফেক্ট চালাতে পারে

```c
if (count > 10)
    printf("count is greater than 10");
```

অথবা এটি এক্সিকিউশনের প্রবাহ বদলে দিতে পারে

```c
if (count > 10)
    return sum;
```

কোনো `if` স্টেটমেন্ট যদি একাধিক লাইন এক্সিকিউট করে, তবে লাইনগুলোকে দ্বিতীয় বন্ধনীর ভেতরে রাখতেই হবে

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

কিছু কোডিং টিম মানসম্মত নিয়ম করে রাখতে পারে যে `if` স্টেটমেন্টে সবসময় দ্বিতীয় বন্ধনী ব্যবহার করা উচিত, এক লাইনের ক্ষেত্রেও।


## if else

`if` স্টেটমেন্টের সাথে একটি `else` যুক্ত করা যায়

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if else if


`else`-এর সাথে আরেকটি `if` যুক্ত করে যা তৈরি হয়, তাকে বলা হয় `if-else-if ladder`।

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


কখনো কখনো `if-else-if ladder`-এর বদলে `switch` দিয়ে বিষয়টি আরও ভালোভাবে প্রকাশ করা যায়।
`if`-এর মতোই, যে এক্সপ্রেশনটি পরীক্ষা করা হয় তা সবসময় প্রথম বন্ধনীর মধ্যে রাখা হয়।

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

পরীক্ষা করা মানটি আগের কোনো কেসের সাথে না মিললে `default` কেসটি এক্সিকিউট হয়।

কোনো `switch` কেস যদি রিটার্ন না করে, তবে সাধারণত প্রতিটি কেস শেষ করতে একটি `break` বসানো হয়, নইলে লজিক পরের কেসে "ফলথ্রু" হয়ে যায়।
কখনো কখনো ফলথ্রু ইচ্ছাকৃতভাবে ব্যবহার করা হয়

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

ফলথ্রু যখন অনিচ্ছাকৃতভাবে ঘটে, তখন সেটি একটি Bug।

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

মানের একটি পরিসরের বদলে নির্দিষ্ট কিছু মানের বিরুদ্ধে পরীক্ষা করার সময় একটি switch উপকারী হতে পারে।
এটি একটি `if-else-if ladder`-এর চেয়ে দ্রুত হতে পারে, কারণ কম্পাইলার এমনভাবে `switch` স্টেটমেন্ট অপটিমাইজ করতে পারে, যা ladder-এর ক্ষেত্রে সম্ভব নয়।
কখনো কখনো একটি `switch` `if-else-if ladder`-এর চেয়ে বেশি পাঠযোগ্য দেখাতে পারে।

## টার্নারি (অর্থাৎ শর্তমূলক) অপারেটর

টার্নারি অপারেটর হলো তিন অংশের একটি শর্তমূলক স্টেটমেন্ট, যা প্রায়ই একটি মান নির্ধারণ করতে ব্যবহৃত হয়।
যে এক্সপ্রেশনটি পরীক্ষা করতে হবে তা প্রশ্নচিহ্নের আগে থাকে এবং এটি প্রথম বন্ধনীর মধ্যে থাকতে হয় না।
ট্রু হলে যে মানটি রিটার্ন হয় তা কোলনের আগে, আর ফলস হলে যে মানটি রিটার্ন হয় তা কোলনের পরে।
একটি লিটারেল মান অথবা একটি ভ্যারিয়েবল, যেকোনোটিই রিটার্ন করা যায়।

```c
int i = j > 5 ? 5: j;
```

সিনট্যাক্সের জটলা কমাতে টার্নারি অপারেটর নেস্টেড করা যায়।

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
