# নির্দেশনা

এই অনুশীলনীতে আপনি কারখানার কর্মীদের জন্য নেম ব্যাজ প্রিন্ট করার কোড লিখবেন।

## 1. একজন কর্মীর জন্য একটি ব্যাজ প্রিন্ট করুন

কর্মীদের একটি ID, নাম এবং বিভাগের নাম থাকে। কর্মীদের ব্যাজ লেবেল নিচের মতো ফরম্যাট করা হয়: `"[id] - name - DEPARTMENT"`।
একজন কর্মীর ব্যাজ লেবেল রিটার্ন করার জন্য `Badge.print()` মেথডটি ইমপ্লিমেন্ট করুন:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

মনে রাখবেন, লেবেলে বিভাগটি বড় হাতের অক্ষরে লিখতে হবে।

## 2. নতুন কর্মীর জন্য একটি ব্যাজ প্রিন্ট করুন

কম্পিউটার সিস্টেমের একটি খুঁতের কারণে, নতুন কর্মীরা কারখানায় কাজ শুরু করার সময় মাঝে মাঝে এখনও একটি ID পান না।
যেহেতু ব্যাজ আবশ্যক, তাই তারা ID প্রিফিক্স ছাড়া একটি সাময়িক ব্যাজ পাবেন। যে নতুন কর্মীদের এখনও ID নেই তাদের সাপোর্ট করার জন্য `Badge.print()` মেথডটি পরিবর্তন করুন:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. মালিকের জন্য একটি ব্যাজ প্রিন্ট করুন

এমনকি কারখানার মালিককেও সব সময় একটি ব্যাজ পরে থাকতে হয়।
তবে মালিকের কোনো বিভাগ থাকে না। এই ক্ষেত্রে লেবেলে বিভাগের নামের বদলে `"OWNER"` প্রিন্ট হওয়া উচিত।
মালিকের জন্য একটি লেবেল প্রিন্ট করার জন্য `Badge.print()` মেথডটি পরিবর্তন করুন:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

মনে রাখবেন, মালিকও নতুন কর্মী হতে পারেন:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
