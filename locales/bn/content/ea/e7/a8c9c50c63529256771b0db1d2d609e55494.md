# পরিচিতি

কম্প্রিহেনশন হলো _এনুমারেবল_ সহজে ও ডিক্লারেটিভভাবে রূপান্তর করার একটি উপায়।

একটি খুব সাধারণ কম্প্রিহেনশন ডিক্লেয়ার করতে আমরা `for` কিওয়ার্ড ব্যবহার করতে পারি, যার পরে থাকে একটি _জেনারেটর_ আর একটি _ডো-ব্লক_, যা এনুমারেট করা মান থেকে নতুন মান তৈরি করে।

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

কম্প্রিহেনশনে _ফিল্টার_-ও থাকতে পারে। যে মানগুলো ফিল্টার পাস করে না, সেগুলো চূড়ান্ত অ্যারে থেকে বাদ পড়ে:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

আমরা আরও জটিল কম্প্রিহেনশন কয়েকটি লাইনে ডিক্লেয়ার করতে পারি:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

একাধিক জেনারেটর ব্যবহার করে একটি _কার্টেসিয়ান প্রোডাক্ট_ তৈরি করা যায়। এর মানে হলো, প্রথম জেনারেটরের তৈরি করা প্রতিটি মান দ্বিতীয় জেনারেটরের তৈরি করা প্রতিটি মানের সঙ্গে একবার করে জোড়া লাগবে:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
