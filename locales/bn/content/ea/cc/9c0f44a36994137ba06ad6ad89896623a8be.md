# নির্দেশনা

Mecha Munch™, একটি মুদি কেনাকাটার অটোমেশন কোম্পানি, সদ্য আপনাকে তাদের অর্ডারিং অ্যাপে কাজ করার জন্য নিয়োগ দিয়েছে।
আপনার দলের দায়িত্ব একটি MVP (_[ন্যূনতম কার্যকর পণ্য][mvp]_) বানানো, যা শপিং কার্টের সব মৌলিক কাজ সামলাবে এবং ব্যবহারকারীদের তাদের মুদি অর্ডার যোগ, বাদ দেওয়া আর সাজানোর সুবিধা দেবে।
ভাগ্যক্রমে, টাকা-পয়সা আর চেক-আউটের সব কাজ অন্য একটি দল দেখছে!

## 1. ব্যবহারকারীর শপিং কার্টে আইটেম যোগ করা

MVP-তে ব্যবহারকারীকে তার শপিং কার্টে আইটেম যোগ করার সুবিধা থাকা উচিত।
এটি একসাথে একটি আইটেম বা একাধিক আইটেম হতে পারে।
যেহেতু এটি একটি MVP, আইটেমের পরিমাণ বোঝানো হয় _পুনরাবৃত্তি_ দিয়ে।
কোনো ব্যবহারকারী ২টি Orange যোগ করতে চাইলে ইনপুট ইটারেবলে 'Oranges' দুবার থাকবে।
ব্যবহারকারীর কার্টে আইটেমটি আগে থেকেই থাকলে কার্টের পরিমাণ ১ বাড়িয়ে দিতে হবে।
আইটেমটি কার্টে _নতুন_ হলে সেটি ১ পরিমাণে যোগ করতে হবে।

`add_items!(<cart>, <items>)` ফাংশনটি তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি কার্ট ডিকশনারি এবং যোগ করার জন্য আইটেমের একটি ইটারেবল নেয়।
এটি ব্যবহারকারীর জন্য আপডেট করা শপিং কার্ট ডিকশনারি রিটার্ন করবে।

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. রেসিপি "আইডিয়া" সেকশন আপডেট করা

অ্যাপটিতে একটি "আইডিয়া" সেকশন আছে, যা নানা রকম রান্নার তৈরি রেসিপিতে ভরা।
ব্যবহারকারী এই রেসিপিগুলোর যেকোনো একটি বেছে নিলে তার সব উপকরণ স্বয়ংক্রিয়ভাবে শপিং কার্টে যোগ হয়ে যাবে।
প্রজেক্ট ম্যানেজার আপনাকে এই "আইডিয়া" রেসিপিগুলো সম্পাদনা করার একটি উপায় বানাতে বলেছেন, কারণ কনটেন্ট টিম উপকরণ আর পরিমাণ বদলাতেই থাকে।

`update_recipes!(<ideas>, <updates>)` ফাংশনটি তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি "আইডিয়া" ডিকশনারি এবং রেসিপি আপডেটের একটি ডিকশনারি নেয়।
ফাংশনটি আপডেট করা "আইডিয়া" ডিকশনারি রিটার্ন করবে।

## 3. ফুলফিলমেন্টের জন্য ব্যবহারকারীর শপিং কার্ট দোকানে পাঠানো

অ্যাপটিকে একটি নির্দিষ্ট ব্যবহারকারীর কার্ট ফুলফিলমেন্টের জন্য দোকানে পাঠাতে হবে।
তবে দোকানের শপারদের একটি ইউনিক আইল কোড দেখে জানতে হবে কোন আইটেম কোথায় পাওয়া যাবে।
"ফুলফিলমেন্ট কার্ট"-টি আইটেমগুলোর আইল কোডের ক্রম অনুযায়ী সাজানো দরকার, যাতে শপাররা আরও দক্ষভাবে কাজ করতে পারেন।

`send_to_store(<cart>, <aislecodes>)` ফাংশনটি তৈরি করুন, যা একটি ব্যবহারকারীর শপিং কার্ট এবং দোকানের আইল নম্বরসহ একটি ডিকশনারি নেয়।
ফাংশনটি একটি সম্মিলিত "ফুলফিলমেন্ট কার্ট" রিটার্ন করবে, যেখানে ক্রেতা যে প্রতিটি আইটেম অর্ডার করছেন তার জন্য `aislecode => quantity` জোড়া থাকবে।
আইটেমগুলো তাদের আইল কোডের ক্রম অনুযায়ী থাকবে।

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. ব্যবহারকারী কী অর্ডার করেছেন তা প্রতিফলিত করতে দোকানের ইনভেন্টরি আপডেট করা।

অ্যাপ শুধু অনবরত ক্রেতার অর্ডার পাঠিয়ে যেতে পারে না।
একসময় দোকানের নানা পণ্য ফুরিয়ে যাবে।
তাই ব্যবহারকারী যখনই তার অর্ডার দোকানে পাঠাবে, আপনার অ্যাপের MVP-কে দোকানের ইনভেন্টরি আপডেট করতে হবে।
নাহলে ক্রেতারা এমন পণ্য অর্ডার করবেন যা আসলে মজুত নেই।

`update_store_inventory!(<inventory>, <cart>)` ফাংশনটি তৈরি করুন, যা একটি `cart` এবং একটি `inventory` নেয়।
ফাংশনটি "কার্টে" যত সংখ্যায় অর্ডার করা আছে সেই পরিমাণ দোকানের ইনভেন্টরি থেকে কমাবে, তারপর স্টকে নেই এমন (অর্থাৎ যেগুলোর পরিমাণ `0` হয়ে গেছে) আইটেমের একটি ডিকশনারি রিটার্ন করবে।

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. স্টকে নেই এমন আইটেম আবার অর্ডার করা।

ইনভেন্টরি আপডেট করার পাশাপাশি, আপনার অ্যাপ সেটি আবার স্টক করতেও সাহায্য করতে পারে।
ক্রেতার অর্ডারের পর যে আইটেমগুলো স্টকে নেই, সেগুলোর একটি মিনি-অর্ডার তৈরি করার ক্ষমতা আপনার MVP-তে থাকা উচিত।
এতে একটি বড় অর্ডার শুরু করা সহজ হবে।
তার উপর, মাঝে মাঝে সীমিত সময়ের প্রোমোশনাল আইটেম থাকে, যা স্টক তালিকায় থাকে না।
প্রোমোশনের সময় শেষ হওয়ার আগেই এগুলো বিক্রি হয়ে গেলে বোঝা যায় এগুলো জনপ্রিয়, আর সেগুলো স্টক তালিকায় যোগ করা যায়।

`reorder!(<outofstock>, <stock>)` ফাংশনটি তৈরি করুন, যা `outofstock` এবং `stock` নেয়।
`stock` ডিকশনারিতে থাকে সাধারণ স্টক আইটেম এবং সেগুলো আবার অর্ডার করার পরিমাণ।
`outofstock` ডিকশনারি হলো `update_store_inventory!`-এর ফলাফল, অর্থাৎ শূন্য পরিমাণের আইটেমের একটি ডিকশনারি।
`outofstock`-এর পরিমাণগুলো `stock`-এ থাকা পরিমাণ অনুযায়ী আপডেট করে রিটার্ন করতে হবে।
এছাড়া `outofstock`-এ থাকা কিন্তু `stock`-এ নেই এমন আইটেম `stock`-এ ডিফল্ট পরিমাণ `100` দিয়ে যোগ করতে হবে।

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
