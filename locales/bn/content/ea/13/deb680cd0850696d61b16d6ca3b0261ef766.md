# পরিচিতি

[Go](https://golang.org) একটি স্ট্যাটিকালি টাইপড, কম্পাইলড প্রোগ্রামিং ভাষা।
এই অনুশীলনীতে ভাষার তিনটি প্রধান বৈশিষ্ট্য পরিচয় করিয়ে দেওয়া হয়েছে: প্যাকেজ, ফাংশন ও ভ্যারিয়েবল।

## প্যাকেজ

Go-এর অ্যাপ্লিকেশনগুলো প্যাকেজে সাজানো থাকে।
একটি প্যাকেজ হলো একই ডিরেক্টরিতে থাকা সোর্স ফাইলগুলোর একটি সংগ্রহ।
একটি ডিরেক্টরির সব সোর্স ফাইলের প্যাকেজ নাম একই হতে হবে।
কোনো প্যাকেজ ইমপোর্ট করা হলে, কেবল সেই এনটিটিগুলোই (ফাংশন, টাইপ, ভ্যারিয়েবল, কনস্ট্যান্ট) ব্যবহার বা অ্যাক্সেস করা যায় যাদের নাম বড় হাতের অক্ষর দিয়ে শুরু হয়।
Go-তে নামকরণের সুপারিশকৃত ধরন হলো শনাক্তকারীদের নাম `camelCase`-এ লেখা, তবে যেগুলো প্যাকেজের বাইরে থেকেও ব্যবহারযোগ্য হওয়ার কথা সেগুলো `PascalCase`-এ হওয়া উচিত।

```go
package lasagna
```

## ভ্যারিয়েবল

Go স্ট্যাটিকালি টাইপড, অর্থাৎ কম্পাইল করার সময় প্রতিটি ভ্যারিয়েবলের [একটি নির্দিষ্ট টাইপ থাকতেই হবে](https://en.wikipedia.org/wiki/Type_system)।

স্পষ্টভাবে একটি টাইপ উল্লেখ করে ভ্যারিয়েবল ডিফাইন করা যায়:

```go
var explicit int // Explicitly typed
```

আপনি একটি ইনিশিয়ালাইজারও ব্যবহার করতে পারেন, তখন কম্পাইলার ইনিশিয়ালাইজারের টাইপের সাথে মিলিয়ে ভ্যারিয়েবলের টাইপ নির্ধারণ করে দেবে।

```go
implicit := 10   // Implicitly typed as an int
```

একবার ডিক্লেয়ার করা হলে, `=` অপারেটর দিয়ে ভ্যারিয়েবলে মান অ্যাসাইন করা যায়।
আর একবার ডিক্লেয়ার করা হলে, ভ্যারিয়েবলের টাইপ আর কখনোই বদলানো যায় না।

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## কনস্ট্যান্ট

কনস্ট্যান্টও ভ্যারিয়েবলের মতোই একটি তথ্য ধারণ করে, কিন্তু প্রোগ্রাম চলার সময় তাদের মান বদলাতে পারে না।

কনস্ট্যান্ট `const` কিওয়ার্ড দিয়ে ডিফাইন করা হয় এবং এগুলো সংখ্যা, ক্যারেক্টার, স্ট্রিং বা বুলিয়ান হতে পারে:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## ফাংশন

Go-এর ফাংশন শূন্য বা তার বেশি প্যারামিটার নিতে পারে।
প্যারামিটার অবশ্যই স্পষ্টভাবে টাইপ করা থাকতে হবে, এখানে কোনো টাইপ ইনফারেন্স নেই।

`return` কিওয়ার্ড ব্যবহার করে ফাংশন থেকে মান রিটার্ন করা হয়।

ফাংশনের নাম উল্লেখ করে এবং তার প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে একটি ফাংশন কল করা হয়।

লক্ষ্য করুন, Go দুই ধরনের কমেন্ট সমর্থন করে।
এক লাইনের কমেন্টের আগে `//` বসে এবং বহু লাইনের কমেন্ট `/*` ও `*/`-এর মাঝে লেখা হয়।

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
