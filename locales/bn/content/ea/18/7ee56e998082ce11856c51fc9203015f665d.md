# Debug

Debug করতে সাহায্য করার জন্য, আপনি [`print` বা একই ধরনের ফাংশন][cl-print] ব্যবহার করে স্ট্যান্ডার্ড আউটপুটে লিখতে পারেন, যা টেস্টের আউটপুটে দেখা যাবে।

উদাহরণস্বরূপ, আপনি যে ফাংশনটি লিখছেন তার ভেতরে `(print "hello there")` যোগ করে দিলে টেস্ট রানের সময় সেটি দেখা যাবে (শর্ত থাকে যে টেস্টটি ওই ফাংশনটি চালায়)।

একটি কৌশল হলো: আপনার যদি একাধিক জিনিস প্রিন্ট করতে হয়, তাহলে সেগুলো একটি অ্যারেতে একসাথে জড়ো করে তারপর সেটি প্রিন্ট করুন: `(print (list :this "that" 'the-other))`.

[cl-print]: http://www.lispworks.com/documentation/HyperSpec/Body/f_wr_pr.htm
