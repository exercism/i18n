# নির্দেশনার সংযোজন

## প্রজেক্ট স্ট্রাকচার

Exercism-এর Clojure অনুশীলনীগুলো ডিপেন্ডেন্সি ম্যানেজমেন্ট ও টেস্টিংয়ের জন্য সবচেয়ে বেশি ব্যবহৃত দুটি টুল সমর্থন করে, [leiningen][leiningen] এবং [Clojure CLI][clojure-cli]।

`test` ডিরেক্টরির ভেতরে `hello_world_test.clj` নামের একটি টেস্ট ফাইল পাবেন।
`src/hello_world.clj` ফাইলে আপনার কোড লিখুন। এতে `hello-world` নেমস্পেসটি ব্যবহার করা উচিত, যাতে টেস্টগুলো এটি খুঁজে নিতে পারে।

### Clojure CLI দিয়ে টেস্ট রান করা

```
$ clj -X:test
```

### Leiningen দিয়ে টেস্ট রান করা

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

তারপর অনুশীলনীটি সাবমিট করুন এভাবে:

```
$ exercism submit src/hello_world.clj
```

আরও বিস্তারিত নির্দেশনা ও শেখার উপকরণের জন্য [Exercism-এর Clojure ভাষা পাতা][exercism-clojure] দেখুন।
