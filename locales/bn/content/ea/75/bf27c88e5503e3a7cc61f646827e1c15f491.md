# ফ্যাশন বুটিক

## কাহিনি

আপনি একটি অনলাইন ফ্যাশন বুটিক চালাচ্ছেন। ব্ল্যাক ফ্রাইডে আসছে, তাই আপনি প্রস্তুত কিনা তা নিশ্চিত করতে আপনার ইনভেন্টরির হিসাব নেওয়া দরকার।

ইনভেন্টরির একটি একক আইটেম একটি ম্যাপ/ডিকশনারি দ্বারা উপস্থাপিত হয়, এবং পুরো ইনভেন্টরি এমন ম্যাপ/ডিকশনারির একটি অ্যারে।

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## কাজ

- দাম অনুসারে আইটেম সাজান
- যেসব আইটেমের দাম অনুপস্থিত সেগুলি খুঁজুন
- আইটেমের পরিমাণ বাড়ান
- আইটেমের মোট পরিমাণ গণনা করুন
