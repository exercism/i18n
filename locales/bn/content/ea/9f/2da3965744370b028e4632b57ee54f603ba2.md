# পরিচিতি

## কনস্ট্যান্ট

`const` মডিফায়ারটি এমন যেকোনো ফিল্ডে প্রয়োগ করা যায় (এবং সাধারণত করা উচিত), যার মান কম্পাইল টাইমে জানা থাকে এবং প্রোগ্রামের জীবনকালে বদলায় না।

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly` মডিফায়ারটি এমন যেকোনো ফিল্ডে প্রয়োগ করা যায় (এবং সাধারণত করা উচিত) যাকে `const` করা যায় না, যার মান প্রোগ্রামের জীবনকালে বদলায় না, এবং যা হয় কোনো ইনলাইন ইনিশিয়ালাইজার দিয়ে, নয়তো ইনস্ট্যানশিয়েশনের সময় (কনস্ট্রাক্টর দিয়ে, কিংবা কনস্ট্রাক্টর যে মেথডটিকে কল করে তার মাধ্যমে) সেট করা হয়।

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## ডিফেন্সিভ কপিং

নিরাপত্তা-সংবেদনশীল পরিস্থিতিতে (বা এমনকি কেবল বড় কোনো কোডবেসে, যেখানে ডেভেলপারদের অগ্রাধিকার ও উদ্দেশ্য আলাদা) আপনার উচিত একটি ক্লাসের পাবলিক API এড়িয়ে যাওয়ার সুযোগ না দেওয়া। এই সুযোগ তৈরি হয় যখন আপনি কোনো মেথডের মিউটেবল প্যারামিটার গ্রহণ করে সংরক্ষণ করেন, কিংবা রিটার্ন ভ্যালুর মাধ্যমে বা `out` প্যারামিটার হিসেবে ক্লাসের কোনো মিউটেবল সদস্য প্রকাশ করেন।

## রিডঅনলি কালেকশন

`readonly` মডিফায়ার একটি ফিল্ডের মান বা রেফারেন্স ওভাররাইট হওয়া আটকায় ঠিকই, কিন্তু একটি রেফারেন্স টাইপের সদস্যদের জন্য কোনো সুরক্ষা দেয় না।

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

একটি রেফারেন্স টাইপের সব সদস্য সুরক্ষিত রাখতে ফিল্ডগুলো `readonly` করা যায় এবং `set` অ্যাকসেসর ছাড়াই অটোমেটিক প্রপার্টি ডিফাইন করা যায়।

Base Class Library (BCL) কিছু কালেকশনের রিডঅনলি সংস্করণ দেয়, যেখানে একটি কালেকশনের সদস্যদের আপডেট হওয়া বন্ধ করার প্রয়োজন থাকে। এগুলো আসে র‍্যাপার আকারে:

- `ReadOnlyDictionary<T>` একটি `Dictionary<T>`-কে রিডঅনলি হিসেবে প্রকাশ করে।
- `ReadOnlyCollection<T>` একটি `List<T>`-কে রিডঅনলি হিসেবে প্রকাশ করে।
