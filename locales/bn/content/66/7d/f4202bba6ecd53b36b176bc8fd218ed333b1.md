# নির্দেশনা

আপনি একটি নেটবল ম্যাচে স্কোরবোর্ড চালাচ্ছেন। এতদিনের সবকিছুর বিপরীতে, একটি স্কোরবোর্ডকে মনে রাখতে হয় কী ঘটেছে।

`SCOREBOARD` ক্লাসটির জন্য নিচের বিষয়গুলো দরকার। স্টাব আপনাকে ক্লাসটি আর তার দুটি অ্যাট্রিবিউট ডিক্লারেশন দিয়ে দিয়েছে; বাকিটা আপনি যোগ করুন।

## 1. বোর্ড সেট আপ করুন

`create` হোম টিমের নাম ও অ্যাওয়ে টিমের নাম নেয়, আর দুটি স্কোরই শূন্যে থাকা একটি স্কোরবোর্ড ফিরিয়ে দেয়।

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. একটি গোল করা

`home_goal` হোম স্কোরের সাথে এক যোগ করে, আর `away_goal` অ্যাওয়ে স্কোরের সাথে এক যোগ করে। কোনোটিই কিছু ফিরিয়ে দেয় না।

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. বোর্ড পড়ুন

`summary` বোর্ডটি যেমন লিখে রাখা হয় সেভাবে ফিরিয়ে দেয়: হোম টিম, তার স্কোর, একটি ড্যাশ, অ্যাওয়ে স্কোর, তারপর অ্যাওয়ে টিম।

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

স্পেসগুলো ঠিক যেমন দেখানো হয়েছে তেমনই, আর ড্যাশটি একটি মাত্র `-`।

## 4. কে এগিয়ে আছে?

`leader` এগিয়ে থাকা টিমের নাম ফিরিয়ে দেয়, বা স্কোর সমান হলে `"Draw"` ফিরিয়ে দেয়।

```sather
board.leader
-- => "Vixens"
```

## 5. কতটা এগিয়ে?

`margin` ফিরিয়ে দেয় কত গোলে টিম দুটি আলাদা। যে-ই এগিয়ে থাকুক, এটি কখনো ঋণাত্মক হয় না।

```sather
board.margin
-- => 1
```
