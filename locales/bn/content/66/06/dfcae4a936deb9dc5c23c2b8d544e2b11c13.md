# টাপল

একটি [টাপল][tuple] হলো এলিমেন্টের একটি সসীম ও ক্রমবদ্ধ তালিকা, যা অপরিবর্তনীয়।
টাপলে প্রতিটি অবস্থানের একটি নির্দিষ্ট টাইপ থাকা আবশ্যক।
এর ফলে কম্পাইলার জানে কোন অবস্থানে কোন টাইপ আছে।
টাপলে ব্যবহৃত টাইপ প্রতিটি অবস্থানে আলাদা হতে পারে, তবে টাইপগুলো কম্পাইল টাইমে জানা থাকতে হবে।

## টাপল তৈরি করা

টাপলের মানগুলোর টাইপ কম্পাইলের সময় নির্ণয় করা যায় কি না, তার উপর নির্ভর করে টাপল বিভিন্ন উপায়ে তৈরি করা যায়।
মানগুলো কম্পাইল টাইমে জানা থাকলে টাপল লিটারেল সিনট্যাক্স ব্যবহার করে টাপল তৈরি করা যায়, নাহলে সেগুলো স্পষ্টভাবে ডিক্লেয়ার করতে হবে।
এটাও গুরুত্বপূর্ণ যে মানগুলোর টাইপ টাপলে উল্লিখিত টাইপের সাথে মেলে এবং মানের সংখ্যা উল্লিখিত টাইপের সংখ্যার সাথে মেলে।
টাপল লিটারেল সিনট্যাক্স দিয়ে ডিফাইন করার একটি উদাহরণ দেখুন:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

`Tuple` ক্লাস ব্যবহার করেও টাপল তৈরি করা যায়।

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

বিকল্পভাবে, আপনি টাপলে অ্যাসাইন করা ভ্যারিয়েবলের টাইপ স্পষ্টভাবে উল্লেখ করতে পারেন।

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

টাপলের টাইপ স্পষ্টভাবে উল্লেখ করা কাজে লাগতে পারে, কারণ এতে কোনো অবস্থানে একটি ইউনিয়ন টাইপ থাকবে বলে নির্ধারণ করা যায়।
এর অর্থ হলো একটি অবস্থানে একাধিক টাইপ থাকতে পারে।

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## কনভার্সন

### অ্যারে থেকে টাপল তৈরি করা

`Tuple` ক্লাসের `from` মেথড ব্যবহার করে আপনি একটি অ্যারে থেকে টাপল তৈরি করতে পারেন।
এর জন্য টাপলের টাইপ উল্লেখ করা আবশ্যক।

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### অ্যারেতে রূপান্তর

`to_a` মেথড ব্যবহার করে আপনি একটি টাপলকে অ্যারেতে রূপান্তর করতে পারেন।
যে অ্যারেটি পাওয়া যায়, তার এলিমেন্ট টাইপ হয় টাপলের প্রতিটি ফিল্ডের টাইপের ইউনিয়ন।

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### টাপল ডিফাইনের সংক্ষিপ্ত রূপ

স্পষ্টভাবে টাপল টাইপ ডিফাইন করার একটি সংক্ষিপ্ত রূপ আছে।
সেটি হলো টাপল লিটারেলের ভেতরে টাইপগুলো লিখে দেওয়া।

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## এলিমেন্ট অ্যাক্সেস করা

অ্যারের মতোই টাপলও জিরো-ইনডেক্সড, অর্থাৎ প্রথম এলিমেন্টটি থাকে ইনডেক্স 0-এ।
তবে অ্যারের বিপরীতে প্রতিটি এলিমেন্টের টাইপ নির্দিষ্ট এবং কম্পাইল টাইমে জানা থাকে, তাই টাপলে ইনডেক্স করলে এলিমেন্টের টাইপ নির্ভর করে নির্দিষ্ট অবস্থানের উপর।
টাপলের একটি এলিমেন্ট অ্যাক্সেস করতে আপনি `[]` অপারেটর ব্যবহার করতে পারেন।

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

অ্যারে থেকে এলিমেন্ট অ্যাক্সেস করার তুলনায় আরেকটি পার্থক্য হলো, ইনডেক্স স্পষ্টভাবে উল্লেখ করা থাকলে কম্পাইলার যাচাই করে যে ইনডেক্সটি টাপলের সীমার মধ্যে আছে কি না।
এর অর্থ হলো রানটাইম এররের বদলে আপনি কম্পাইল টাইম এরর পাবেন।

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

তবে ইনডেক্সটি কোনো ভ্যারিয়েবলে রাখা থাকলে কম্পাইলার কম্পাইল টাইমে যাচাই করতে পারবে না যে ইনডেক্সটি টাপলের সীমার মধ্যে আছে কি না, বরং রানটাইম এরর দেবে।

## সাবটাপল

একটি রেঞ্জের সাথে `[]` অপারেটর ব্যবহার করে আপনি টাপলের একটি সাবটাপল পেতে পারেন।
যা রিটার্ন হয়, তা হলো উল্লিখিত রেঞ্জের এলিমেন্টগুলো নিয়ে গঠিত একটি নতুন টাপল।
রেঞ্জটি কম্পাইল টাইমে দিতে হবে, নাহলে কম্পাইলার সাবটাপলের এলিমেন্টগুলোর টাইপ জানতে পারবে না।
এর অর্থ হলো রেঞ্জটি একটি রেঞ্জ লিটারেল হতে হবে, কোনো ভ্যারিয়েবলে অ্যাসাইন করা যাবে না।

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## কখন টাপল ব্যবহার করবেন

মানগুলোর টাইপ কম্পাইল টাইমে জানা থাকলে, নির্দিষ্ট সংখ্যক মান একসাথে গুছিয়ে রাখতে চাইলে টাপল কাজে লাগে।
কারণ টাপলের অপরিবর্তনীয়তার জন্য এগুলো অ্যারের চেয়ে কম মেমরি নেয় এবং দ্রুততর।
আরেকটি ব্যবহারের ক্ষেত্র হলো একটি মেথড থেকে একাধিক মান রিটার্ন করা।
মানগুলোর টাইপ আলাদা হলে এটি বিশেষভাবে সহায়ক, কারণ টাপলের প্রতিটি অবস্থানে আলাদা টাইপ থাকতে পারে।

যে ডেটা স্ট্রাকচারের আকার বাড়তে বা কমতে পারে, বা যা প্রায়ই পরিবর্তন করতে হয়, এমন কিছু দরকার হলে টাপল ব্যবহার করা উচিত নয়।
