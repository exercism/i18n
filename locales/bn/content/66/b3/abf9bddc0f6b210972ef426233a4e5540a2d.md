# নির্দেশনা

হতে-চলো যাদুকর হিসেবে Elyse-কে কিছু বেসিক বিষয় অনুশীলন করতে হবে। তার কাছে একটি তাসের ডেক আছে, যা নিয়ে সে কাজ করতে চায়।

কাজটা একটু সহজ করার জন্য সে শুধু ১ থেকে ১০ নম্বরের তাস ব্যবহার করে।

## 1. ডেক থেকে একটি তাস বের করা

প্রদত্ত ডেক থেকে `index` অবস্থানের তাসটি রিটার্ন করে এমন `getCard` ফাংশনটি ইমপ্লিমেন্ট করুন। যদি `index` ডেকে না থাকে, তাহলে Nothing রিটার্ন করুন।

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. ডেকে একটি তাস পরিবর্তন করা

`index` অবস্থানের তাসটি প্রদত্ত নতুন তাসে পরিবর্তিত করে এমন একটি ডেক রিটার্ন করে `setCard` ফাংশনটি ইমপ্লিমেন্ট করুন।
যদি `index` ডেকে না থাকে, তাহলে মূল ডেকটিই রিটার্ন করুন।

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. ডেকে একটি তাস যোগ করা

নতুন তাসটি যোগ করা অবস্থায় একটি ডেক রিটার্ন করে `addCard` ফাংশনটি ইমপ্লিমেন্ট করুন।

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. ডেক থেকে একটি তাস সরানো

`index` অবস্থানের তাসটি সরিয়ে ফেলা একটি ডেক রিটার্ন করে `removeCard` ফাংশনটি ইমপ্লিমেন্ট করুন।
যদি প্রদত্ত `index` ডেকের কোনো বৈধ ইনডেক্স না হয়, তাহলে মূল ডেকটিই রিটার্ন করুন।

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. ডেকে জোড় তাসের সংখ্যা গণনা করা

ডেকে জোড় তাসের সংখ্যা গণনা করে এমন `evenCardCount` ফাংশনটি ইমপ্লিমেন্ট করুন।

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
