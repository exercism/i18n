# পরিচিতি

## মূল বিষয়

এই বিষয়গুলো সম্পর্কে আরও বিস্তারিত জানতে [কনসেপ্ট পেজ][exercism-concept] দেখুন।

### সাধারণ সিনট্যাক্স

PHP-এর ওপেনিং ট্যাগ `<?php` PHP কোডের শুরু বোঝায়।
নির্দেশনা আলাদা করতে সব স্টেটমেন্ট অবশ্যই `;` দিয়ে শেষ হতে হবে।

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

সহজে পড়ার সুবিধার জন্য সব কোড উদাহরণে PHP-এর ওপেনিং ট্যাগ `<?php` বাদ দেওয়া হয়েছে।

### কমেন্ট

এক লাইনের কমেন্ট শুরু হয় `//` দিয়ে।

```php
// Single line comment
```

### মান ও ভ্যারিয়েবল

অ্যাসাইনমেন্ট `=` অপারেটর ব্যবহার করে একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করা যায়।
ভ্যারিয়েবলের নাম অবশ্যই ডলার `$` চিহ্ন দিয়ে শুরু হতে হবে এবং [নেমিং কনভেনশন][exercism-concept-naming-conventions] অনুসরণ করতে হবে।

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### ফাংশন ও মেথড

ফাংশনে মান ও ভ্যারিয়েবল পাস করা যায়।
ফাংশনের আর্গুমেন্টগুলো নতুন ভ্যারিয়েবল হয়ে পাস করা মান ধরে রাখে।
ফাংশন `return` কিওয়ার্ড ব্যবহার করে যেকোনো মান রিটার্ন করতে পারে।

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

ক্লাসের ভেতরের ফাংশন এবং তাদের ইনস্ট্যান্সকে মেথড বলা হয়।
একটি মেথড কল করতে হলে নামের আগে ইনস্ট্যান্স ও `->` বসাতে হয়।
মেথডগুলোর কাছে `$this` নামের বিশেষ ভ্যারিয়েবলের অ্যাক্সেস থাকে, যা বর্তমান ইনস্ট্যান্সকে বোঝায়।

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
