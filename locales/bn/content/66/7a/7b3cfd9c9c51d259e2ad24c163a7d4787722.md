# নির্দেশনা

একজন হবু জাদুকর হিসেবে এলিসকে কিছু বেসিক অভ্যাস করতে হবে। তার কাছে কার্ডের একটি স্ট্যাক আছে, যা সে নাড়াচাড়া করতে চায়।

কাজটা একটু সহজ করতে সে শুধু ১ থেকে ১০ নম্বরের কার্ড ব্যবহার করে, যাতে তার কার্ডের স্ট্যাককে সংখ্যার একটি ভেক্টর দিয়ে প্রকাশ করা যায়। কোনো নির্দিষ্ট কার্ডের অবস্থান ভেক্টরের ইনডেক্সের সাথে মিলে যায়।

## 1. স্ট্যাক থেকে একটি কার্ড বের করা

একটি কার্ড তুলতে হলে প্রদত্ত স্ট্যাক থেকে `position` ইনডেক্সের কার্ডটি রিটার্ন করুন।

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. স্ট্যাকের একটি কার্ড বদলানো

একটু হাতের কারসাজি করে স্ট্যাকের `position` ইনডেক্সের কার্ডটি প্রদত্ত রিপ্লেসমেন্ট কার্ড দিয়ে বদলে দিন।
বদলানো স্ট্যাকটি রিটার্ন করুন।

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. স্ট্যাকের উপরে একটি কার্ড ঢোকানো

স্ট্যাকের উপরে একটি নতুন কার্ড ঢুকিয়ে একটি কার্ডকে হাজির করুন।
বদলানো স্ট্যাকটি রিটার্ন করুন।

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. স্ট্যাক থেকে একটি কার্ড সরানো

স্ট্যাক থেকে প্রদত্ত `position` ইনডেক্সের কার্ডটি সরিয়ে একটি কার্ডকে উধাও করুন।
বদলানো স্ট্যাকটি রিটার্ন করুন।

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. স্ট্যাকের আকার পরীক্ষা করা

স্ট্যাকের আকার `stack_size` মানের সমান কি না তা পরীক্ষা করুন।

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. স্ট্যাকের উপরের কার্ড সরানো

স্ট্যাকের উপরের কার্ডটি সরিয়ে একটি কার্ডকে উধাও করুন।
বদলানো স্ট্যাকটি রিটার্ন করুন।

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. স্ট্যাকের নিচে একটি কার্ড ঢোকানো

স্ট্যাকের নিচে একটি নতুন কার্ড ঢুকিয়ে একটি কার্ডকে হাজির করুন।
বদলানো স্ট্যাকটি রিটার্ন করুন।

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. স্ট্যাকের নিচ থেকে একটি কার্ড সরানো

স্ট্যাকের নিচ থেকে কার্ডটি সরিয়ে একটি কার্ডকে উধাও করুন।
বদলানো স্ট্যাকটি রিটার্ন করুন।

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
