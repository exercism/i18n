# নির্দেশনা

আপনার বন্ধু ফটো এডিটিং সফটওয়্যারের জন্য টাকা দিতে দিতে ক্লান্ত হয়ে পড়েছেন এবং নিজেই একটি লেখার সিদ্ধান্ত নিয়েছেন।
আপনার বন্ধু নতুন সফটওয়্যারটির নাম দিয়েছেন Foto Fusionist।

Foto Fusionist একটি ফটো এডিটিং সফটওয়্যার, যা অনেক কাজ করতে পারে। তবে আপনি এখন পর্যন্ত এর মাত্র কয়েকটি ফিচার ইমপ্লিমেন্ট করেছেন।
তবুও আপনার বন্ধু এই অগ্রগতিতে খুব খুশি এবং আপনাকে আরও কয়েকটি ফিচার ইমপ্লিমেন্ট করতে বলেছেন।

## 1. বাইনারি রিপ্রেজেন্টেশনকে ইন্টিজারে রূপান্তর করুন

প্রথম ফিচার হিসেবে আপনার বন্ধু চান একটি সংখ্যার বাইনারি রিপ্রেজেন্টেশনকে ইন্টিজারে রূপান্তর করা যাবে।
এটি দরকার, কারণ তাহলে সফটওয়্যারটি একটি কালার চ্যানেলের বাইনারি রিপ্রেজেন্টেশন পড়ে সেটিকে ইন্টিজারে রূপান্তর করতে পারবে।

`FotoFusionist.binary_to_int` মেথডটি ইমপ্লিমেন্ট করুন, যা `String` টাইপের একটি আর্গুমেন্ট `binary` নেয়।
মেথডটি বাইনারি সংখ্যাটির ইন্টিজার রিপ্রেজেন্টেশন রিটার্ন করবে।

```crystal
FotoFusionist.binary_to_int("10011")
# => 19
```

## 2. ইন্টিজার থেকে লিস্ট সিগনিফিক্যান্ট বিট বের করুন

আপনার বন্ধুর চাওয়া দ্বিতীয় ফিচারটি হলো একটি ইন্টিজার থেকে [লিস্ট সিগনিফিক্যান্ট বিট][least-significant-bit] বের করা।
লিস্ট সিগনিফিক্যান্ট বিট হলো একেবারে ডানদিকে থাকা বিট।
এর মান সবচেয়ে কম হওয়ার কারণেই একে লিস্ট সিগনিফিক্যান্ট বিট বলা হয়।

একটি ছবিকে কালার চ্যানেল প্রকাশ করতে ব্যবহৃত বিটের সংখ্যা কমিয়ে অপ্টিমাইজ করা যায় কি না, তা নির্ণয় করতে লিস্ট সিগনিফিক্যান্ট বিট দরকার।

`FotoFusionist.least_significant_bit` মেথডটি ইমপ্লিমেন্ট করুন, যা `Int32` টাইপের একটি আর্গুমেন্ট `number` নেয়।
মেথডটি সংখ্যাটির লিস্ট সিগনিফিক্যান্ট বিট রিটার্ন করবে।

```crystal
FotoFusionist.least_significant_bit(0b10011)
# => 1

FotoFusionist.least_significant_bit(0b10010)
# => 0
```

## 3. কালার চ্যানেল থেকে হেক্স ভ্যালু বের করুন

আপনার বন্ধুর চাওয়া তৃতীয় ফিচারটি হলো একটি কালার চ্যানেল থেকে হেক্স ভ্যালু বের করা।
কালার চ্যানেলটিকে একটি হেক্স রিপ্রেজেন্টেশনে রূপান্তর করতে হেক্স ভ্যালু দরকার, আর ওই হেক্স রিপ্রেজেন্টেশনটি দুই ডিজিটের হতে হবে।

`FotoFusionist.hex_value` মেথডটি ইমপ্লিমেন্ট করুন, যা `Int32` টাইপের একটি আর্গুমেন্ট `number` নেয়।
মেথডটি সংখ্যাটির হেক্স ভ্যালু একটি `String` হিসেবে রিটার্ন করবে।

```crystal
FotoFusionist.hex_value(19)
# => "13"
```

## 4. RGB থেকে হেক্স ভ্যালু বের করুন

আপনার বন্ধুর চাওয়া চতুর্থ ফিচারটি হলো একটি RGB রং থেকে হেক্স ভ্যালু বের করা।
এটি দরকার, যাতে একজন ইউজার একটি রঙের একক স্ট্রিং রিপ্রেজেন্টেশন পেতে পারেন।
একটি RGB রং হলো এমন একটি রং, যা তিনটি কালার চ্যানেল দিয়ে প্রকাশ করা হয়: লাল, সবুজ আর নীল।
প্রতিটি কালার চ্যানেল ০ থেকে ২৫৫-এর মধ্যে একটি সংখ্যা দিয়ে প্রকাশ করা হয়।

একটি RGB রঙের হেক্স ভ্যালু হলো হেক্সাডেসিমালে ওই রঙের স্ট্রিং রিপ্রেজেন্টেশন, যেখানে প্রথমে লাল কালার চ্যানেল, তারপর সবুজ কালার চ্যানেল এবং সবশেষে নীল কালার চ্যানেল থাকে।

`FotoFusionist.hex_value_from_rgb` মেথডটি ইমপ্লিমেন্ট করুন, যা `Int32` টাইপের তিনটি আর্গুমেন্ট নেয়: `red`, `green` এবং `blue`।
মেথডটি RGB রঙের হেক্স ভ্যালু একটি `String` হিসেবে রিটার্ন করবে।

```crystal
FotoFusionist.hex_value_from_rgb(255, 0, 0)
# => "ff0000"
```
