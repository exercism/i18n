# ভূমিকা

প্রতিবার একটি ফাংশন কল করা হলে মেমরিতে একটি নতুন স্ট্যাক ফ্রেম তৈরি হয়, যাতে ওই ফাংশনের আর্গুমেন্ট ও লোকাল ভ্যারিয়েবলগুলো জমা রাখা যায়, আর ফাংশনটি রিটার্ন করলে এই স্ট্যাক ফ্রেমটি মেমরি থেকে মুছে ফেলা হয়। Gleam লুপিং সিনট্যাক্সের বদলে রিকার্সিভ ফাংশন কল ব্যবহার করে, তাই এই স্ট্যাক ফ্রেমগুলো অনেক বেশি মেমরি দখল করে ফেলতে পারে।

এই সমস্যা এড়াতে Gleam টেইল কল অপটিমাইজেশন সমর্থন করে, যা কম্পাইলারকে সুবিধা দেয় যে ফাংশনটি যদি সবশেষে একটি ফাংশন কল করে, তাহলে বর্তমান ফাংশনের স্ট্যাক ফ্রেমটি আবার ব্যবহার করতে পারে। এর মানে হলো, কোনো ফাংশন বাড়তি মেমরি ব্যবহার না করেই নিজেকে অসীমবার কল করতে পারে।

অপটিমাইজ না করা রিকার্সিভ ফাংশনকে অনেক সময় একটি _অ্যাকুমুলেটর_ ব্যবহার করে টেইল কল অপটিমাইজড ফাংশনে লিখে ফেলা যায়।

অ্যাকুমুলেটর হলো এমন একটি ভ্যারিয়েবল, যা ডেটার সাথে বাড়তি হিসেবে পাস করা হয়। এটি ফাংশনের চলমান অবস্থাটি বেস কেসে পৌঁছানো পর্যন্ত বহন করে।

অ্যাকুমুলেটর ইনিশিয়ালাইজ করা উচিত ফাংশনের লেখকের, ফাংশনের ব্যবহারকারীর নয়। এটি করতে হলে দুটি ফাংশন ডিক্লেয়ার করুন: একটি পাবলিক ফাংশন, যা শুধু প্রয়োজনীয় ডেটা আর্গুমেন্ট হিসেবে নেয় এবং অ্যাকুমুলেটর ইনিশিয়ালাইজ করে, আর একটি প্রাইভেট ফাংশন, যা একটি অ্যাকুমুলেটরও নেয়।

```gleam
// Count the length of a list without tail call optimisation
pub fn count(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> {
      let amount = count(rest) // Non-tail recursive call
      amount + 1
    }
  }
}
```

```gleam
// Count the length of a list with tail call optimisation
pub fn count(list: List(String)) -> Int {
  count_elements(list, 0)
}

fn count_elements(list: List(String), accumulator: Int) -> Int {
  case list {
    [] -> accumulator
    [_, ..rest] -> {
      let accumulator = accumulator + 1
      count_elements(rest, accumulator) // Tail recursive call
    }
  }
}
```
