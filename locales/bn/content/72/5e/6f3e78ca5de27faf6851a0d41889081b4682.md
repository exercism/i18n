# Swift ইনস্টল করা

Swift macOS, Linux এবং Windows-এ পাওয়া যায়।
আপনি কোন অপারেটিং সিস্টেম ব্যবহার করছেন তার উপর নির্ভর করে ইনস্টলেশন প্রক্রিয়া ভিন্ন হয়।
Linux সাপোর্ট নিয়ে একটি গুরুত্বপূর্ণ বিষয় হলো, Swift কেবল (সরকারিভাবে) নিচের ডিস্ট্রিবিউশনগুলোতে সাপোর্ট করে:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

আপনি যদি Linux-এর অন্য কোনো ডিস্ট্রিবিউশন ব্যবহার করেন, তাহলে নিজেই Swift ইনস্টল করার একটি উপায় খুঁজে বের করতে হবে।

## Xcode (macOS)

Xcode-এর সাথে Swift অন্তর্ভুক্ত থাকে; Xcode হলো macOS ও iOS ডেভেলপমেন্টের জন্য Apple-এর IDE।
exercism ট্র্যাকের জন্য আপনার Xcode 16.0 বা তার পরের ভার্সন ইনস্টল থাকা দরকার।
Xcode বিনামূল্যে [Mac App Store][xcode] থেকে পাওয়া যায়।
[Apple-এর ডেভেলপার সেন্টার][apple-developer-center] থেকে Xcode-এর আরও ভার্সন (সর্বশেষ বিটা সহ) পাওয়া যায়।

## macOS & Linux

macOS ও Linux-এর জন্য [swiftly][swiftly] নামের একটি Swift ইনস্টলেশন ম্যানেজার আছে।
এটি একটি কমান্ড লাইন টুল, যা দিয়ে আপনার সিস্টেমে Swift-এর একাধিক ভার্সন ইনস্টল ও ম্যানেজ করতে পারবেন।
macOS-এ swiftly ইনস্টল করার কমান্ড [এখানে][swiftly-macos] পাবেন, আর Linux-এর জন্য [এখানে][swiftly-linux]।

macOS-এর জন্য আরেকটি ইনস্টলেশন পদ্ধতি হলো [Homebrew][homebrew]।
Linux-এর ক্ষেত্রে অফিশিয়াল [Swift ওয়েবসাইট][tarball] থেকে টারবল ব্যবহার করে ইনস্টল করতে পারেন।

## Windows

Windows-এ Swift ইনস্টল করার সুপারিশকৃত উপায় হলো [WinGet ইনস্টলার][winget-windows] ব্যবহার করা।
Scoop প্যাকেজ ম্যানেজার ব্যবহার করেও Swift ইনস্টল করা যায়, অথবা ম্যানুয়াল ইনস্টলেশনও করতে পারেন।
সব অপশনের জন্য [Windows-এর জন্য Swift ইনস্টল][swift-windows] পৃষ্ঠাটি দেখুন।
