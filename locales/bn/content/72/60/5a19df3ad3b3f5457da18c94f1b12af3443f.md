# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা একটি যানবাহন কেনার প্রস্তুতি নিতে আপনাকে সাহায্য করবে।

আপনার তিনটি কাজ রয়েছে: একটি হলো আসলে আপনার একটি যানবাহন দরকার হবে কি না তা নির্ধারণ করা এবং দুইটি যানবাহনের মধ্যে বেছে নিতে সাহায্য করা, আপনি কোন ধরনের ড্রাইভিং লাইসেন্স নিতে হবে তা নির্ধারণ করা, এবং একটি হলো একটি ব্যবহৃত যানবাহনের গ্রহণযোগ্য দাম অনুমান করা।

## 1. একটি নির্দিষ্ট গাড়ির মাসিক পেমেন্ট আপনি দিতে সক্ষম কি না তা গণনা করুন

আপনার শহরের গাড়ির ডিলাররা সবাই পাঁচ বছরের, ০% সুদের একটি প্রোমোশন চালাচ্ছে, যার সুযোগ আপনি নিতে চান।
কিন্তু আপনি যে গাড়িটি চান, তার মাসিক পেমেন্ট আপনি দিতে পারবেন কি না, তা নিয়ে আপনার নিশ্চয়তা নেই।

মাসিক পেমেন্ট হলো গাড়ির মোট দামকে পাঁচ বছরের সময়কালের মধ্যে পড়া মাসের সংখ্যা দিয়ে ভাগ করলে যা হয়।

নিচের আর্গুমেন্টগুলো নেয় এমন `canIBuy(vehicle:price:monthlyBudget:)` ফাংশনটি ইমপ্লিমেন্ট করুন:
- `vehicle` - আপনি যে যানবাহনটি কিনতে চান তার নাম।
- `price` - আপনি যে যানবাহনটি কিনতে চান তার দাম।
- `monthlyBudget` - প্রতি মাসে আপনি যে পরিমাণ টাকা দিতে সক্ষম।

ফাংশনটি নিচের শর্তগুলোর ভিত্তিতে নিচের বার্তাটি রিটার্ন করবে:
- যদি যানবাহনের মাসিক পেমেন্ট আপনার মাসিক বাজেটের চেয়ে কম বা সমান হয়, তাহলে `"Yes! I'm getting a <vehicle>"` বার্তাটি রিটার্ন করুন।
- যদি যানবাহনের মাসিক পেমেন্ট আপনার মাসিক বাজেটের চেয়ে সর্বোচ্চ ১০% বেশি হয় (সীমা ধরে), তাহলে `"I'll have to be frugal if I want a <vehicle>"` বার্তাটি রিটার্ন করুন।
- যদি যানবাহনের মাসিক পেমেন্ট আপনার মাসিক বাজেটের চেয়ে ১০%-এর বেশি হয়, তাহলে `"Darn! No <vehicle> for me"` বার্তাটি রিটার্ন করুন।

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. আপনার কোন ধরনের ড্রাইভিং লাইসেন্স লাগবে তা নির্ধারণ করুন

আপনি একটি ব্যবহৃত যানবাহন কেনার সিদ্ধান্ত নিয়েছেন, আর এটি চালাতে আপনার কোন ধরনের ড্রাইভিং লাইসেন্স লাগবে তা নির্ধারণ করতে হবে।

`numberOfWheels` আর্গুমেন্টটি নেয় এমন `licenseType(numberOfWheels:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যেখানে `numberOfWheels` হলো আপনি যে যানবাহনটি কিনতে চান তার চাকার সংখ্যা।

ফাংশনটি নিচের শর্তগুলোর ভিত্তিতে নিচের বার্তাটি রিটার্ন করবে:
- চাকার সংখ্যা ২ বা ৩ হলে, `"You will need a motorcycle license for your vehicle"` বার্তাটি রিটার্ন করুন।
- চাকার সংখ্যা ৪ বা ৬ হলে, `"You will need an automobile license for your vehicle"` বার্তাটি রিটার্ন করুন।
- চাকার সংখ্যা ১৮ হলে, `"You will need a commercial trucking license for your vehicle"` বার্তাটি রিটার্ন করুন।
- সংখ্যাটি অন্য যেকোনো সংখ্যা হলে, `"We do not issue licenses for those types of vehicles"` বার্তাটি রিটার্ন করুন।

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. একটি ব্যবহৃত যানবাহনের দামের আনুমানিক হিসাব করুন

এখন যেহেতু আপনি সিদ্ধান্ত নিয়ে ফেলেছেন, আপনি নিশ্চিত হতে চান যে ডিলারশিপে আপনি ন্যায্য দামই পাচ্ছেন।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, তাই দাম নির্ভর করে যানবাহনটির বয়সের উপর।
মোটামুটি একটি অনুমানের জন্য ধরে নিন, যানবাহনটির বয়স যদি ৩ বছরের কম হয়, তাহলে এর দাম একেবারে নতুন থাকা অবস্থায় তার মূল দামের ৮০%।
যদি এর বয়স কমপক্ষে ১০ বছর হয়, তাহলে দাম ৫০%।
আর যানবাহনটির বয়স কমপক্ষে ৩ বছর কিন্তু ১০ বছরের বেশি না হলে, দাম মূল দামের ৭০%।

`originalPrice` ও `yearsOld` আর্গুমেন্ট নেয় এমন `calculateResellPrice(originalPrice:yearsOld:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যেখানে `originalPrice` হলো যানবাহনের মূল দাম, আর `yearsOld` হলো বছরে যানবাহনটির বয়স।
ফাংশনটি যানবাহনটির পুনর্বিক্রয় মূল্য রিটার্ন করবে।

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
