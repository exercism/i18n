# ইনস্টলেশন

## ইনস্টলেশনের অপশনগুলো

Unison-এর বর্তমান রিলিজটি Mac OS X, ৬৪-বিট Linux এবং Windows ব্যবহারকারীদের জন্য পাওয়া যাচ্ছে! আমাদের আশা, আপনি যদি Unison চেষ্টা করে দেখেন, তাহলে Exercism ফোরামে বা [Unison Discord](https://unison-lang.org/discord)-এ আমাদের সঙ্গে কথা বলতে আসবেন। প্রশ্ন করতে আসুন, আর আপনার সামনে পড়া যেকোনো সমস্যার কথা জানান! শুরু করার সময় আপনার অভিজ্ঞতা যেন স্বাগতপূর্ণ ও ইতিবাচক হয়, সেটাই আমরা চাই! 😊

Unison ডাউনলোড করা যায় [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage) অথবা সরাসরি প্যাকেজ করা বাইনারি দিয়ে। এই সব ডাউনলোডের অপশনই বর্ণনা করা আছে [আমাদের ওয়েবসাইটের ইনস্টলেশন নির্দেশনার পেজে](https://www.unison-lang.org/learn/quickstart/#installation-options)। UCM ইনস্টল হয়ে গেলে আবার এখানে ফিরে আসুন!

### অপশন ১: Homebrew ব্যবহার করে

আগে না থাকলে [homebrew ইনস্টল করুন](https://brew.sh/)।

এরপর কমান্ড লাইন থেকে এই কমান্ডগুলো লিখুন:

```
brew tap unisonweb/unison
brew install unison-language
```

এটি Unison কোডবেস ম্যানেজার এক্সিকিউটেবল `ucm` ইনস্টল করবে। আপনি যদি আগের কোনো ভার্সন থেকে আপগ্রেড করছেন, তাহলে শুধু এটা করুন

```
brew upgrade unison-language.
```

নোট: এই সময়ে যদি GitHub ইউজারনেম ও পাসওয়ার্ড চাওয়া হয়, তাহলে নিশ্চিত হয়ে নিন যে আপনি unisonweb/unison ঠিকভাবে লিখেছেন।

### অপশন ২: Mac ও Linux ব্যবহারকারীদের জন্য ম্যানুয়ালি ইনস্টল

নিজ নিজ Linux ও Mac ম্যানুয়াল ডাউনলোড অংশে [Linux আর Mac-এর ম্যানুয়াল ইনস্টল লিঙ্ক এখানে দেওয়া আছে](https://www.unison-lang.org/learn/quickstart/#installation-options)।

আপনি আপনার শেলে এমন একটি কমান্ড চালাবেন যেটা দেখতে প্রায় এরকম, তবে সবচেয়ে হালনাগাদ বাইনারি থাকবে উপরের লিঙ্কে:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### অপশন ৩: Windows ব্যবহারকারীদের জন্য ম্যানুয়ালি ইনস্টল

1. সেরা ফল পেতে আপনার ডিফল্ট টার্মিনাল অ্যাপ্লিকেশন হিসেবে "Windows Terminal" সেট করুন। Settings-এ "Terminal" খুঁজুন, অথবা [এই নির্দেশনাটি অনুসরণ করুন।](https://bit.ly/3IXwdlY)
2. আপনার কাছে এটি আগে থেকেই আছে কি না নিশ্চিত না হলে Git ইনস্টল করুন:
  * winget দিয়ে: `winget install --id Git.Git -e --source winget`
  * আপনি যদি Windows 10-এ থাকেন আর winget না থাকে, তাহলে [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) থেকে এটি ইনস্টল করতে পারেন, তারপর উপরের কমান্ডটি চালান।
3. [এখানে দেওয়া লিঙ্ক দিয়ে UCM ডাউনলোড করুন](https://www.unison-lang.org/learn/quickstart/#installation-options) এবং আপনার পছন্দমতো জায়গায় এটি এক্সট্র্যাক্ট করুন।
4. `ucm.exe` রান করুন

### অপশন ৪: Nix ইনস্টলেশন
[https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) ঠিকানায় যান এবং সেখানে readme-তে দেওয়া নির্দেশনা অনুসরণ করুন।

## আপনার Unison কোডবেস তৈরি করুন

`$HOME/.unison`-এ একটি Unison কোডবেস চালু করতে `ucm` রান করুন। এখানেই Unison ফাংশন ডেফিনিশন, টাইপ, নেমস্পেস ইত্যাদি সংরক্ষণ করবে। ডিফল্টভাবে Unison কোডবেস ম্যানেজার (সংক্ষেপে "UCM") `base` নামের স্ট্যান্ডার্ড লাইব্রেরিটি ডাউনলোড করা শুরু করবে, যা দিয়ে আপনি Unison কোড লিখবেন। একটু সময় লাগতে পারে! 🕰

## Unison ওয়ার্কফ্লো

আপনি যখন Unison কোড লিখতে চাইবেন, তখন কোডবেস ম্যানেজার চালু করতে `ucm` কমান্ড দেবেন। এরপর UCM যে ডিরেক্টরি থেকে ডাকা হয়েছে, সেখানকার `.u` এক্সটেনশনের যেকোনো ফাইলের পরিবর্তন লক্ষ্য করবে। যেমন, ধরুন আপনি `~/exercism/unison/my-exercise/` নামের একটি ডিরেক্টরিতে `scratch.u` নামের ফাইলে ফাংশন লিখছেন। আপনার উচিত `~/exercism/unison/my-exercise/`-এ `cd` করা এবং `ucm` রান করা। এতে নিশ্চিত হবে যে UCM আপনার `scratch.u` ফাইলের পরিবর্তন লক্ষ্য করছে।

`ucm` কোন ডিরেক্টরিতে ফাইলের পরিবর্তন দেখছে তা নিয়ে কখনো বিভ্রান্ত হলে, CLI চালু করার সময় স্বাগত স্ক্রিনেই সেটি লেখা থাকে।

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[আরও ওয়ার্কফ্লো টিপস এখানে দেখুন!](https://exercism.org/docs/tracks/unison/workflow)

## এডিটর সাপোর্ট

আপনার `.u` ফাইল লিখতে যেকোনো টেক্সট এডিটর ব্যবহার করতে পারেন। Unison-এ [LSP সাপোর্ট](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown) আছে, তাই আপনার প্রিয় IDE হোভারে টাইপ দেখানো, অটো-কমপ্লিট ইত্যাদিতে সাহায্য করতে পারে। Unison সাপোর্ট আছে এমন কয়েকটি জনপ্রিয় এডিটর নিচে দেওয়া হলো:

### Vim

[vim-plug](https://github.com/junegunn/vim-plug) ব্যবহার করে:

1. আগে না থাকলে [`vim-plug`](https://github.com/junegunn/vim-plug) ইনস্টল করুন।
2. আপনার .vimrc-তে নিচেরটি যোগ করুন: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. vim কমান্ড `:PlugInstall` দিন।

আরও তথ্যের জন্য vim-এর ভেতর থেকে `:help unison`
রান করুন, অথবা [অনলাইন হেল্প ডক](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt) দেখুন।

### Atom
কনসোল থেকে রান করুন:

```
apm install unisonweb/atom-unison
```

### VS Code

1. VS Code-এর পাশে Activity Bar-এ Extensions আইকনে ক্লিক করে, অথবা ⇧⌘X চেপে Extensions ভিউ খুলুন।
2. "unison" খুঁজুন
3. [Unison VS Code এক্সটেনশন](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison) ইনস্টল করুন

### Emacs
[`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs) ইনস্টল করুন।
