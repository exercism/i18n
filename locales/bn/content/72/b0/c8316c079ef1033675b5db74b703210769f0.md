# নির্দেশাবলি

এই অনুশীলনীতে আপনি সেভিংস অ্যাকাউন্ট নিয়ে কাজ করবেন।
প্রতি বছর আপনার সেভিংস অ্যাকাউন্টের ব্যালেন্স সুদের হার অনুযায়ী হালনাগাদ করা হয়।
আপনার ব্যাংক আপনাকে যে সুদের হার দেয়, তা নির্ভর করে আপনার অ্যাকাউন্টে কত টাকা আছে (অর্থাৎ তার ব্যালেন্স) তার উপর:

- `0` ডলারের কম ব্যালেন্সে 3.213% (ব্যালেন্স আরও ঋণাত্মক হয়ে যায়)।
- `0` ডলার বা তার বেশি এবং `1000` ডলারের কম ব্যালেন্সে 0.5%।
- `1000` ডলার বা তার বেশি এবং `5000` ডলারের কম ব্যালেন্সে 1.621%।
- `5000` ডলার বা তার বেশি ব্যালেন্সে 2.475%।

আপনার সামনে চারটি কাজ আছে, যার প্রত্যেকটিতে আপনার ব্যালেন্স ও তার সুদের হার নিয়ে কাজ করতে হবে।

## 1. সুদের হার হিসাব করুন

`InterestRate()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা নির্দিষ্ট ব্যালেন্সের ভিত্তিতে সুদের হার হিসাব করবে:

```go
InterestRate(200.75)
// => 0.5
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `float32`।

## 2. সুদ হিসাব করুন

`Interest()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা নির্দিষ্ট ব্যালেন্সের ভিত্তিতে সুদ হিসাব করবে:

```go
Interest(200.75)
// => 1.003750
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `float64`।

## 3. বার্ষিক ব্যালেন্স হালনাগাদ হিসাব করুন

`AnnualBalanceUpdate()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা সুদের হার বিবেচনায় নিয়ে বার্ষিক ব্যালেন্স হালনাগাদ হিসাব করবে:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `float64`।

## 4. কাঙ্ক্ষিত ব্যালেন্সে পৌঁছাতে কত বছর লাগবে তা হিসাব করুন

`YearsBeforeDesiredBalance()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা কাঙ্ক্ষিত ব্যালেন্সে পৌঁছাতে ন্যূনতম কত বছর লাগবে তা হিসাব করবে; এখানে মনে রাখতে হবে যে প্রতি বছর ব্যালেন্সের সাথে সুদ যোগ হয়।
এর মানে হলো, এক বছর পরের ব্যালেন্স: শুরুর ব্যালেন্স + শুরুর ব্যালেন্সের সুদ।
দ্বিতীয় বছর পরের ব্যালেন্স: এক বছর পরের ব্যালেন্স + এক বছর পরের ব্যালেন্সের সুদ।
এভাবে চলবে, যতক্ষণ না চলতি বছরের ব্যালেন্স লক্ষ্য ব্যালেন্সের সমান বা তার বেশি হয়।

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `int`।
