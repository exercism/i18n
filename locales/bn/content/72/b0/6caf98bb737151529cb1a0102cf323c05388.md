# Tests

CLI দিয়ে অনুশীলনীর test চালাতে হলে, অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি রান করুন:

```bash
clojure -M:test
```

## REPL

REPL দিয়ে অনুশীলনীর test চালাতে হলে, অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি রান করুন:

```bash
$ clojure -m cljs.main -re node
```

তারপর অনুশীলনীর test নেমস্পেস এবং Clojure test নেমস্পেস) `require` করুন:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

ns-টি test নেমস্পেসে পরিবর্তন করুন:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

তারপর `run-tests` কল করুন:

```clojure
=> (cljs.test/run-tests)
```
