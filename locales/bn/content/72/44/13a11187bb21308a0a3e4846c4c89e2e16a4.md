# ভূমিকা

পাইথনে `None` প্রায়শই একটি মানের অনুপস্থিতি বোঝাতে ব্যবহৃত হয়, অর্থাৎ একটি `null` (খালি) ভ্যারিয়েবল, অবজেক্ট বা আর্গুমেন্ট ডিফাইন করার জন্য একটি প্লেসহোল্ডার হিসেবে।

আপনি যদি অন্য কোনো প্রোগ্রামিং ভাষায় `NULL` বা `nil` টাইপের কথা শুনে থাকেন বা সেটি ব্যবহার করে থাকেন, তাহলে পাইথনে `None`-এর এই ব্যবহার আপনার কাছে পরিচিত মনে হবে। এমন ভ্যারিয়েবল বা ফাংশন আর্গুমেন্ট ডিক্লেয়ার করতে `None` আপনার কাজে লাগে, যেগুলোর জন্য আপনার এখনো কোনো মান নেই। এগুলো পরে প্রয়োজন অনুযায়ী নির্দিষ্ট মানে পুনরায় অ্যাসাইন করা যায়।

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

কোনো শর্ত যাচাইয়ে ব্যবহার করলে `None`-এর মান `False` হিসেবে গণ্য হয়, তাই একটি মানের "উপস্থিতি" বা "অনুপস্থিতি", অর্থাৎ _যেকোনো_ মানের উপস্থিতি বা অনুপস্থিতি যাচাই করার জন্য এটি কাজে লাগে। এই প্যাটার্নটি প্রায়শই ব্যবহৃত হয় যখন কোনো ফাংশন বা প্রক্রিয়া একটি এরর অবজেক্ট বা মেসেজ ফেরত দিতে পারে।

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
