# টেস্ট চালানো

কোনো অনুশীলনীর টেস্ট চালাতে হলে, সেই অনুশীলনীর ডিরেক্টরিতে `<exercise>.test` স্ক্রিপ্টটি চালান:

```bash
tclsh <exercise>.test
```

বেশিরভাগ অনুশীলনীতে প্রথম টেস্টটি ছাড়া বাকি সবগুলো "skipped" থাকবে।
এতে আপনি, ডেভেলপার হিসেবে, টেস্ট-ড্রিভেন ডেভেলপমেন্ট করতে পারেন: একটি একটি করে প্রতিটি টেস্ট পাস করার জন্য যতটুকু দরকার, ততটুকুই কোড লেখা।
স্কিপ কমান্ডগুলো অগ্রাহ্য করতে, টেস্ট স্যুট চালানোর আগে `RUN_ALL` এনভায়রনমেন্ট ভ্যারিয়েবলটি Tcl-এর একটি বৈধ true মানে \[1\] সেট করুন:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Tcl-এর true/false মানগুলো C লাইব্রেরি ফাংশন [Tcl_GetBoolean][bool]-এর man পেজে নথিভুক্ত করা আছে।

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
