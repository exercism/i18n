# নির্দেশনা

আপনি সমুদ্রতীরের বোর্ডওয়াক আর্কেডে ভাগ্যের খেলাগুলো চালান। খেলোয়াড়েরা পাশা গড়ায়, ক্ল মেশিন একটি পুরস্কার তুলে নেয়, আর কার্ড টেবিলের ডেক শাফল করা ও হাত ভাগ করা দরকার। এসবের সবকিছুই চলে র‍্যান্ডমনেসের জোরে। রাতের শেষে আপনার একটি "রিপ্লে" ফিচারও দরকার, যাতে বিতর্কিত কোনো খেলা একই সিড থেকে আবার চালানো যায়।

## 1. একটি পাশা গড়ান

`roll-die` ডিফাইন করুন যাতে এটি বাহুর সংখ্যা নেয় এবং `1` থেকে `sides` রেঞ্জের (অন্তর্ভুক্ত) একটি রোল রিটার্ন করে।

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. একটি পুরস্কার তুলে নিন

`pick-prize` ডিফাইন করুন যাতে এটি পুরস্কারের একটি সিকোয়েন্স নেয় এবং সেখান থেকে যেকোনো একটি র‍্যান্ডমভাবে রিটার্ন করে।

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. ডেক শাফল করুন

`shuffle-deck` ডিফাইন করুন যাতে এটি একটি ডেক (একটি সিকোয়েন্স) নেয় এবং কার্ডগুলোকে র‍্যান্ডম ক্রমে সাজিয়ে সেটি রিটার্ন করে।

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. একটি হাত ভাগ করুন

`deal-hand` ডিফাইন করুন যাতে এটি একটি ডেক ও একটি সংখ্যা `n` নেয়, এবং ডেক থেকে `n`টি *আলাদা* কার্ড রিটার্ন করে।

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. একটি সিড থেকে রিপ্লে করুন

`play-seeded` ডিফাইন করুন যাতে এটি একটি সিড ও একটি কোয়োটেশন নেয়, এবং ওই ইন্টিজার থেকে সিড করা একটি জেনারেটর দিয়ে কোয়োটেশনটি রান করে, ফলে একই সিড সবসময় একই ফলাফল আবার তৈরি করে। কোয়োটেশনের ফলাফলটি কলকারীকে রিটার্ন করা উচিত।

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
