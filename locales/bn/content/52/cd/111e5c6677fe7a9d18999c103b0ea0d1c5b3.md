# পরিচিতি

## লুপ

কোনো লজিক বারবার চালানোর জন্য লুপ ব্যবহার করা হয়।
সবচেয়ে কমন দুটি ধরন হলো `while loop` (অনির্দিষ্টকাল চলা লুপ) আর `for loop` (নির্দিষ্ট, বা গণনাভিত্তিক লুপ)।
এছাড়া `for each` লুপও আছে, যেটি পরে কোনো কনসেপ্টে আসবে।

### সাধারণ সিনট্যাক্স

`for loop`-এ থাকে একটি হেডার আর একটি কোড ব্লক, যার ভেতরে দ্বিতীয় বন্ধনী দিয়ে মোড়ানো লুপের বডি থাকে।
হেডারটি সেমিকোলন `;` দিয়ে আলাদা করা ৩টি কম্পোনেন্ট নিয়ে গঠিত: ইনিশিয়ালাইজেশন স্টেটমেন্ট, শর্ত আর আরেকটি এক্সপ্রেশন।
এগুলোর যেকোনোটি খালি থাকতে পারে।

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- **init_statement** কম্পোনেন্টটি এমন কোড, যা লুপ শুরু হওয়ার আগে কেবল একবার চলে।
- **শর্ত** কম্পোনেন্টটি এমন একটি এক্সপ্রেশন হতে হবে, যা `boolean`-এ মূল্যায়িত হয় আর লুপ কখন থামা উচিত তা নিয়ন্ত্রণ করে।
  এই শর্তটি যতক্ষণ `true` হিসেবে মূল্যায়িত হয়, ততক্ষণ লুপের ভেতরের কোড চলবে।
  এই এক্সপ্রেশনটি `false` হিসেবে মূল্যায়িত হওয়ামাত্রই লুপের আর কোনো ইটারেশন চলবে না।
- **এক্সপ্রেশন** কম্পোনেন্টটি এমন কোড, যা প্রতিটি ইটারেশনের শেষে চলে।

`while loop` তার বডি চালায় যতক্ষণ তার **শর্ত** পরীক্ষা `true` হয়।
নিচের কোডটি দেখায় কীভাবে একটি `for`-কে `while loop`-এ রূপান্তর করা যায়।

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### একটু থেমে: ইনক্রিমেন্ট আর ডিক্রিমেন্ট

লুপ নিয়ে কাজ করার সময় প্রায়ই একটি কাউন্টার ভ্যারিয়েবলের সাথে ১ যোগ বা ১ বিয়োগ করতে হয়, যা ইটারেশনগুলো হিসাব রাখে।
এটা এতটাই কমন যে ইনক্রিমেন্ট/ডিক্রিমেন্ট করার জন্য আলাদা অপারেটর আছে: `++` আর `--`।

এগুলো **প্রিফিক্স** আর **পোস্টফিক্স** রূপে আসে।
প্রিফিক্স স্টেটমেন্টে ব্যবহারের আগে ভ্যারিয়েবলটি বদলায়, আর পোস্টফিক্স রূপটি ব্যবহারের পরে বদলায়।
বেশিরভাগ সময়েই আপনি সম্ভবত প্রিফিক্স রূপটিই চাইবেন।

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### for লুপ: একটি উদাহরণ

_init কম্পোনেন্ট_ সাধারণত একটি কাউন্টার ভ্যারিয়েবল তৈরি করে, _শর্ত_ পরীক্ষা করে লুপ চালিয়ে যাওয়া উচিত নাকি থামানো, আর _post কম্পোনেন্ট_ সাধারণত প্রতিটি পুনরাবৃত্তির শেষে কাউন্টারটি ইনক্রিমেন্ট করে।

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

এই লুপটি `1` থেকে `9` পর্যন্ত সংখ্যাগুলোর যোগফল বের করবে (`9` সহ)।

### break আর continue

লুপের বডির ভেতরে `break` কিওয়ার্ড ব্যবহার করে লুপের সম্পাদন পুরোপুরি থামাতে পারেন:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

এর বিপরীতে, `continue` কিওয়ার্ড কেবল বর্তমান ইটারেশনের সম্পাদন থামায় আর পরেরটি দিয়ে চালিয়ে যায়:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
সাধারণত লুপের লজিক বোঝা সহজ হয়, যখন `break` আর `continue`-এর ব্যবহার যতটা সম্ভব কমানো হয় বা পুরোপুরি এড়িয়ে চলা হয়।
দুটি কিওয়ার্ডই কোডের নির্দিষ্ট কিছু অংশ বাদ দিয়ে যায়, ফলে কোড অনুসরণ করা প্রায়ই আরও কঠিন হয়ে পড়ে।
~~~~
