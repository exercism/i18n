# টেস্ট

`exercism test` বা `eutest` দিয়ে টেস্টগুলো চালান। ডিফল্টভাবে সব টেস্ট চলে।

## টেস্ট বাদ দেওয়া

শুরু করার একটি ভালো উপায় হলো `t_<exercise>.e`-তে প্রথম টেস্টটি ছাড়া বাকি সব টেস্ট কমেন্ট আউট করা।

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

একটির পর একটি করে এগিয়ে যান, বর্তমান টেস্টটি পাস হয়ে গেলে পরের টেস্টটি আনকমেন্ট করুন। সব টেস্ট পাস হলে আপনি অনুশীলনীটি সম্পন্ন করেছেন।
