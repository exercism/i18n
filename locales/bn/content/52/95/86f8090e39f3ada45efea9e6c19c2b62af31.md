# কন্ডিশনাল

Ruby-তে ফ্লো কন্ট্রোল এক্সপ্রেশন নামে পরিচিত একধরনের এক্সপ্রেশন আছে। এগুলো দিয়ে প্রোগ্রাম কীভাবে চলবে তা নিয়ন্ত্রণ করা হয় এবং এগুলো একটি ট্রুথি বা ফলসি মান নেয়।
কিছু অপারেটর আছে যা দিয়ে ট্রুথি বা ফলসি মান তৈরি করা যায়, এগুলোকে [তুলনা অপারেটর][comparison-operators] বলা হয়।

দুটি প্রধান কন্ট্রোল এক্সপ্রেশন আছে যা দিয়ে নিয়ন্ত্রণ করা হয় কোন কোডটি চলবে আর কোনটি চলবে না।
অর্থাৎ, কোন নির্দিষ্ট শাখাটি চলবে তাও এটাই ঠিক করে।

এই দুটি হলো: `if` এবং `unless` এক্সপ্রেশন।

## তুলনা অপারেটর

[তুলনা অপারেটর][comparison-operators] দিয়ে মান তুলনা করা হয় এবং একটি `true` বা `false` মান রিটার্ন করা হয়।
নিচের অপারেটরগুলোর জন্য তুলনা করার দুটি মান একই টাইপের হতে হয়।
মান দুটি একই টাইপের না হলে কম্পাইলার একটি এরর দেবে।
এখানে অপারেটরগুলোর একটি তালিকা এবং কখন এগুলো `true` মান দেয় তার একটি উদাহরণ দেওয়া হলো:

| মেথড | বিবরণ           | উদাহরণ |
| ------ | --------------------- | ------- |
| <      | কম             | 4 < 5   |
| <=     | কম বা সমান    | 4 <= 4  |
| >      | বেশি          | 3 > 1   |
| >=     | বেশি বা সমান | 2 >= 2  |

আগে উল্লেখ করা অপারেটরগুলোর বিপরীতে, সমান ও অসমান অপারেটর দিয়ে যেকোনো টাইপের মান তুলনা করা যায়।
`==` অপারেটর দিয়ে দুটি মান সমান কি না তা পরীক্ষা করা হয়, আর এতে মানের টাইপও পরীক্ষা করা হয়।
`!=` একইভাবে কাজ করে, তবে মান দুটি অসমান হলে এটি `true` রিটার্ন করে আর সমান হলে `false` রিটার্ন করে।
এখানে সমান ও অসমান অপারেটরগুলোর একটি তালিকা এবং কখন এগুলো `true` মান দেয় তার একটি উদাহরণ দেওয়া হলো:

| মেথড | বিবরণ  | উদাহরণ |
| ------ | ------------ | ------- |
| ==     | সমান        | 4 == 4  |
| !=     | সমান নয়    | 5 != 4  |

## `if` স্টেটমেন্ট

[`if`][if] স্টেটমেন্ট দিয়ে পরীক্ষা করা হয় কোন একটি শর্ত "ট্রুথি" না "ফলসি"।
শর্তটি ট্রুথি হলে if স্টেটমেন্টের ভেতরের কোডটি চলবে।
একটি `if` স্টেটমেন্ট `end` কিওয়ার্ড দিয়ে শেষ হয়।

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless` স্টেটমেন্ট

`unless` স্টেটমেন্ট প্রায় `if` স্টেটমেন্টের মতোই কাজ করে, তবে শর্তটি ফলসি হলে এটি `unless` স্টেটমেন্টের ভেতরের কোডটি চালায়।

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else` স্টেটমেন্ট

`else` স্টেটমেন্ট `if` স্টেটমেন্টের সাথে মিলিয়ে ব্যবহার করা যায়।
`if` শাখাটি চালানো না হলে `else` স্টেটমেন্টটি চালানো হবে।

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## "ক্যাসকেডিং-if" স্টেটমেন্ট

`elsif` স্টেটমেন্ট if স্টেটমেন্টের সাথে মিলিয়ে ব্যবহার করা যায়।
`if` শাখাটি চালানো না হলে এবং elsif স্টেটমেন্টের শর্তটি ট্রুথি হলে `elsif` স্টেটমেন্টটি চালানো হবে।
একাধিক elsif স্টেটমেন্ট একসাথে জুড়ে দেওয়া যায়, আর প্রথম যে শর্তটি ট্রুথি হবে সেটিই চালানো হবে।
if স্টেটমেন্টের শেষে একটি else স্টেটমেন্টও থাকতে পারে, যা আগের কোনোটিই সত্য না হলে চলবে।

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
