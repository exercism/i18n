## কীভাবে ব্যবহার করবেন

### বিল্ড

`npx blueprint build` অথবা `yarn blueprint build`

### টেস্ট

`npx blueprint test` অথবা `yarn blueprint test`

### ডিপ্লয় করা বা অন্য একটি স্ক্রিপ্ট চালানো

`npx blueprint run` অথবা `yarn blueprint run`

### নতুন একটি কনট্রাক্ট যোগ করা

`npx blueprint create ContractName` অথবা `yarn blueprint create ContractName`
