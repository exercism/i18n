# ভূমিকা

কোনো লজিক বারবার এক্সিকিউট করার জন্য লুপ ব্যবহার করা হয়।
সবচেয়ে কমন দুটি ধরন হলো `while loop` (অনির্দিষ্ট লুপিং) এবং `for loop` (নির্দিষ্ট বা গণনাকৃত লুপিং)।
এছাড়াও `for each` লুপ আছে, যা পরের কোনো কনসেপ্টে আসবে।


## সাধারণ সিনট্যাক্স

`for loop` একটি হেডার এবং একটি কোড ব্লক নিয়ে গঠিত, যেখানে লুপের বডি দ্বিতীয় বন্ধনী `{}` দিয়ে মোড়ানো থাকে।
হেডারটি সেমিকোলন `;` দিয়ে আলাদা করা ৩টি উপাদান নিয়ে গঠিত: init-statement, শর্ত এবং আরেকটি এক্সপ্রেশন।
এদের প্রত্যেকটি খালি থাকতে পারে।

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- **init** উপাদানটি হলো এমন কিছু কোড যা লুপ শুরু হওয়ার আগে কেবল একবার রান করে।
- **শর্ত** উপাদানটি অবশ্যই এমন একটি এক্সপ্রেশন হতে হবে যা একটি বুলিয়ান মানে মূল্যায়িত হয় এবং লুপটি কখন থামা উচিত তা নিয়ন্ত্রণ করে।
এই শর্তটি যতক্ষণ ট্রু-তে মূল্যায়িত হয়, ততক্ষণ লুপের ভেতরের কোড রান করবে।
এই এক্সপ্রেশনটি ফলস-এ মূল্যায়িত হওয়ামাত্রই লুপের আর কোনো ইটারেশন রান করবে না।
- **এক্সপ্রেশন** উপাদানটি হলো এমন কিছু কোড যা প্রতিটি ইটারেশনের শেষে রান করবে।


`while loop` তার বডি এক্সিকিউট করে যতক্ষণ তার শর্ত পরীক্ষা ট্রু থাকে।
নিচের কোড স্নিপেটটি দেখায় কীভাবে একটি for-কে while লুপে রূপান্তর করা যায়।

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## অন্তর্বর্তী পর্ব: ইনক্রিমেন্ট ও ডিক্রিমেন্ট

লুপ নিয়ে কাজ করার সময় প্রায়ই একটি কাউন্টার ভ্যারিয়েবলে ১ যোগ বা ১ বিয়োগ করার প্রয়োজন হয়।
এটি এতটাই কমন যে এই কাজটির জন্য বিশেষ অপারেটর রয়েছে: `++` এবং `--`।

এগুলো প্রিফিক্স ও পোস্টফিক্স দুটি রূপে আসে।
প্রিফিক্স স্টেটমেন্টে ব্যবহারের আগে ভ্যারিয়েবলটি বদলায় এবং পোস্টফিক্স রূপটি পরে বদলায়।
বেশিরভাগ সময় আপনি সম্ভবত প্রিফিক্স রূপটিই চাইবেন।

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## for লুপ: একটি উদাহরণ

init উপাদানটি সাধারণত একটি কাউন্টার ভ্যারিয়েবল সেট আপ করে, শর্তটি পরীক্ষা করে লুপটি চালিয়ে যাওয়া উচিত কি থামানো উচিত, আর post উপাদানটি সাধারণত প্রতিটি পুনরাবৃত্তির শেষে কাউন্টারটি ইনক্রিমেন্ট করে।

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

এই লুপটি `1` থেকে `9` পর্যন্ত সংখ্যাগুলো যোগ করবে (`9` সহ)।

## break এবং continue

লুপের বডির ভেতরে আপনি `break` কিওয়ার্ড ব্যবহার করে লুপের এক্সিকিউশন সম্পূর্ণভাবে থামাতে পারেন:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

এর বিপরীতে, `continue` কিওয়ার্ডটি কেবল চলতি ইটারেশনের এক্সিকিউশন থামায় এবং পরেরটিতে চালিয়ে যায়:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> নোট: `break` ও `continue`-এর ব্যবহার কমিয়ে আনা হলে বা সম্পূর্ণ এড়িয়ে যাওয়া হলে লুপের লজিক বোঝা সাধারণত সহজ হয়।
