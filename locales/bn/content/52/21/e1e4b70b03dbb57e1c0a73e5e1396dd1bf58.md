# পরিচিতি

`Option` টাইপ হলো F# ভাষার এমন একটি ব্যবস্থা, যা দিয়ে এমন মান নিয়ে কাজ করা যায়, যেগুলো থাকতেও পারে, না-ও থাকতে পারে।
এটি `null` ব্যবহারের একটি টাইপ-সেফ বিকল্প দেয়, যা অন্য ভাষায় এ ধরনের মান নিয়ে কাজ করার জন্য কমন।
F#-এর স্ট্যান্ডার্ড লাইব্রেরির অনেক ফাংশনেই এটি ব্যবহৃত হয়, তাই স্ট্যান্ডার্ড F# লাইব্রেরি কার্যকরভাবে ব্যবহার করতে হলে এটি বোঝা জরুরি।

## `Option` টাইপ ব্যবহারের সুবিধা

* __কম্পাইল-টাইম সেফটি__: টাইপ সিস্টেমে একটি মানের উপস্থিতি বা অনুপস্থিতি স্পষ্টভাবে উল্লেখ করার ফলে কম্পাইলার নিশ্চিত করতে পারে যে আপনি "মান নেই" অবস্থাটি হ্যান্ডেল করেছেন, যা null-এর কারণে ঘটতে পারত এমন এক বিশাল শ্রেণির বাগ প্রতিরোধ করে।

* __রান-টাইম সেফটি__: `null` ব্যবহারের বদলে F# মানের অনুপস্থিতি বোঝাতে `None` ব্যবহার করে, ফলে `NullReferenceException` ঘটার কোনো সুযোগই থাকে না।

* __স্পষ্টভাবে হ্যান্ডেল করতে বাধ্য করে__: টাইপ সিস্টেম কোডকে `Some value` আর `None` দুটি ক্ষেত্রই স্পষ্টভাবে হ্যান্ডেল করতে বাধ্য করে, যা আপনার কোডকে আরও মজবুত ও পূর্বানুমেয় করে তোলে।

* __প্যাটার্ন ম্যাচিংয়ের সাথে কাজ করে__: `Option`-গুলো F#-এর প্যাটার্ন ম্যাচিং রীতির সাথে নির্বিঘ্নে কাজ করে, ফলে মানটি থাকলে তা ডিকনস্ট্রাক্ট করে হ্যান্ডেল করার, আর না থাকলে ভিন্ন কিছু করার একটি পরিচ্ছন্ন ও নিরাপদ উপায় পাওয়া যায়।

## ব্যবহার

`Option` টাইপটি একটি জেনেরিক টাইপ (যার একটি অন্তর্নিহিত টাইপ থাকে)।
`Option` মান হয় `Some value`, যা একটি নির্দিষ্ট মান বোঝায়, নয়তো `None`, যা মান নেই বোঝায়।

নিচের ফাংশনটি একটি `Option` মান তৈরি করার উপায় দেখায়:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` হলো `Option<T>`-এর পোস্টফিক্স সিনট্যাক্স রূপ; দুটি সিনট্যাক্স ফর্মই একে অপরের বদলে ব্যবহার করা যায়।
তবে F# Style Guide অনুযায়ী, Option টাইপের ক্ষেত্রে পোস্টফিক্স নোটেশনকেই অগ্রাধিকার দেওয়া হয় (দেখুন [F# স্টাইল গাইডের টাইপ ও টাইপ অ্যানোটেশন ফরম্যাটিং অংশ](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions))।
~~~~

`Option`-এর একটি সাধারণ ব্যবহারের জায়গা হলো সার্চ ফাংশন।
উদাহরণস্বরূপ, `List.tryFind` ফাংশনটি লিস্টে আইটেমটি থাকলে `Some index` রিটার্ন করে (এখানে `index` হলো লিস্টে অনুরোধ করা মানটির অবস্থান), আর আইটেমটি লিস্টে না থাকলে `None` রিটার্ন করে।

## একটি Option মানের ভেতরের কনটেন্ট পড়া

`Option` মান পড়ার প্রচলিত রীতি হলো প্যাটার্ন ম্যাচিং, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## ডিফল্ট মান দিয়ে Option আনর্যাপ করা

`Option.defaultValue` ফাংশনে ডিফল্ট মান দিয়ে `Option`-গুলোকে "আনর্যাপ" করা যায় (তাদের ভেতরে থাকা টাইপে রূপান্তর করা যায়)।
আপনি যখন নিশ্চিত করতে চান যে মানটি `None` নয়, তখন এটি বিশেষভাবে কাজে লাগে।
উদাহরণস্বরূপ:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## `Option` মডিউলের আরও ফাংশন

`Option` মডিউলে এমন ফাংশনও আছে যেগুলো লিস্ট, অ্যারে, সিকোয়েন্স আর অন্যান্য কালেকশন টাইপের জন্য থাকা ফাংশনের সাথে মিলে যায়, যেমন `Option.map`, `Option.iter`, `Option.forall`, `Option.count`.
এই ফাংশনগুলোর সাহায্যে `Option`-গুলোকে শূন্য বা এক এলিমেন্টের কালেকশনের মতোও ব্যবহার করা যায়।
