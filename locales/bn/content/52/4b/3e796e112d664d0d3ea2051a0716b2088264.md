# নির্দেশাবলির সংযোজন

# ইনপুট

এই অনুশীলনীর ইনপুট হলো:

- `target`: একটি স্ট্রিং (যেমন `'stone'`), যা হবে _বাম আর্গুমেন্ট_।
- `candidates`: বক্সে রাখা স্ট্রিংয়ের একটি অ্যারে (যেমন `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`), যা হবে _ডান আর্গুমেন্ট_।

আপনার ভার্ব এভাবে কল করা হবে:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## আউটপুট

আপনার ভার্বটি এমন বক্সের একটি অ্যারে রিটার্ন করবে, যেগুলোতে টার্গেটের অ্যানাগ্রাম হওয়া স্ট্রিংগুলো থাকে। কোনো অ্যানাগ্রাম না থাকলে ফলাফল হবে `empty`.
