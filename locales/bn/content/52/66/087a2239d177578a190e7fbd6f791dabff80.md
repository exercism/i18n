# নির্দেশাবলি

আপনি স্বেচ্ছাসেবক হিসেবে কাজ করছেন কমিউনিটি আর্টস সেন্টারে, যেখানে সামনের প্রবেশপথের উপরে একটি লম্বা সিরামিক-টাইলের মোজাইক বসানো হচ্ছে। ডিজাইন টিম কাজটি সাজিয়ে রেখেছে **সারি ধরে সারি**: প্রতিটি সারি টাইলের রঙের একটি অ্যারে, আর গোটা মোজাইকটি সারিগুলোর একটি অ্যারে।

স্বেচ্ছাসেবকরা যখন টাইল কাটছেন, বসাচ্ছেন আর সাজিয়ে নিচ্ছেন, তখন আপনি ছোট ছোট পুনর্ব্যবহারযোগ্য ওয়ার্ড লিখছেন, যা দিয়ে ডিজাইনের টুকরো তৈরি করা, একত্র করা আর খুঁজে বের করা যায়।

## 1. একটি টাইলের স্ট্রিপ

`tile-strip` ডিফাইন করুন, যা একটি রং নেবে এবং শুধু সেই রঙটি ধারণ করা ১টি এলিমেন্টের একটি সারি রিটার্ন করবে।

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. তিনটি টাইলের একটি সারি

`row-of-three` ডিফাইন করুন, যা স্ট্যাক থেকে তিনটি রং নেবে এবং ৩টি এলিমেন্টের একটি সারি রিটার্ন করবে।

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. সারিগুলোকে একত্র করে টাইলগুলোর একটি সমতল তালিকা তৈরি করা

মোজাইকের সব সারি মিলিয়ে রঙের মোট হিসাব ডিজাইন টিমকে একবার যাচাই করে দেখতে হবে। `combine-rows` ডিফাইন করুন, যা সারিগুলোর একটি অ্যারে নেবে এবং ক্রমানুসারে প্রতিটি টাইলের একটি একক সিকোয়েন্স রিটার্ন করবে।

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. একটি সারিকে মিরর করা

সিমেট্রিক প্যানেলের জন্য টিম একটি সারি মিরর করে, তারপর কপিটি বিপরীত পাশে বসায়। `mirror-row` ডিফাইন করুন, যা একটি সারি উল্টো ক্রমে রিটার্ন করবে।

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. সারিতে এই রংটি কোথায়?

`tile-position` ডিফাইন করুন, যা একটি সারি ও একটি রং নেবে এবং সারিতে ওই রঙের প্রথম টাইলের ইনডেক্স (০-ভিত্তিক) রিটার্ন করবে। রংটি যদি না থাকে, তাহলে `f` রিটার্ন করুন।

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. এই সারিতে কি রংটি আছে?

`has-colour?` ডিফাইন করুন, যা একটি সারি ও একটি রং নেবে এবং সারিতে রংটি কোথাও থাকলে `t` রিটার্ন করবে, নাহলে `f`।

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
