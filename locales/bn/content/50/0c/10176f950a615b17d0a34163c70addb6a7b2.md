# সম্পর্কে

অন্য ভাষাগুলোর মতো C++-ও একটি `switch` স্টেটমেন্ট দেয়।
লম্বা `if ... else if` স্টেটমেন্ট লেখার একটি ছোট উপায় হলো switch স্টেটমেন্ট।
একটি switch তৈরি করতে হলে আমরা প্রথমে `switch` কিওয়ার্ডটি ব্যবহার করি, তারপর একটি ইন্টিজার বসাই।
এরপর `case` কিওয়ার্ড দিয়ে প্রতিটি শর্ত ঘোষণা করি।
আমরা একটি `default` কেসও ঘোষণা করতে পারি, যা তখন চলে যখন আগের কোনো `case` শর্তই মেলে না।
প্রতিটি কেসের শেষে একটি `break` (বা `return`) স্টেটমেন্ট থাকা উচিত।

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## ফলথ্রু

switch গঠন সম্পর্কে একটি গুরুত্বপূর্ণ বিষয় হলো, কোডটি চলতেই থাকে যতক্ষণ না একটি `break` (বা `return`) স্টেটমেন্ট সেটিকে থামায়।
এর ফলে অনাকাঙ্ক্ষিত আচরণ হতে পারে।

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

এই ধারাবাহিকভাবে চলার বৈশিষ্ট্যটির মূল ব্যবহার হলো এমন একটি স্টেটমেন্ট, যার একাধিক লেবেল থাকে।
একই কোড চালানোর সঙ্গে একাধিক switch ফলাফল যুক্ত হতে পারে।
এইভাবে (উদাহরণস্বরূপ, একটি বুকিং অ্যাপে), ২ ও ৩ গ্রুপ সাইজের জন্য কল করা ফাংশনটি একই হতে পারে:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
আপনি যেমন দেখেছেন, অন্য ভাষার তুলনায় C++-এর switch স্টেটমেন্ট বেশ সীমিত।
অনেক ভাষা বুলিয়ান এক্সপ্রেশন বা এমনকি রেগুলার এক্সপ্রেশনের ভিত্তিতেও switch করতে পারে।
C++-এর এই রূপটিকে goto/switch গঠনের একটি বর্ধিত রূপ ভাবতে পারেন।
শুধু switch স্টেটমেন্টই একটি লেবেলে জাম্প করতে পারে।
এর পরে অন্য সব লেবেল উপেক্ষিত হয়, আর কোড ব্লক থেকে বেরিয়ে আসতে আপনাকে `break` স্টেটমেন্ট ব্যবহার করতে হবে।
