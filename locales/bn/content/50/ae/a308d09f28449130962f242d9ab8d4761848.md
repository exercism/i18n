# সম্পর্কে

লোকাল ভ্যারিয়েবলগুলো স্ট্যাক কোডের জায়গা নেয় না, বরং তার পাশাপাশি থাকে। কখন এগুলো ব্যবহার করবেন:

- একই ইনপুট একাধিকবার উল্লেখ করা হয়।
- কাজের স্বাভাবিক ক্রম স্ট্যাকের ক্রমের সাথে মেলে না।
- আপনি এমন একটি হায়ার-অর্ডার ওয়ার্ডের ভেতরে আছেন, যা ল্যাম্বডাকে একসাথে একাধিক মান দিয়ে দেয় (`assoc-map`-এর `( key value -- newkey newvalue )`)।

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` একটি কোয়োটেশনের ভেতরে বা লিসেনারে লোকাল বাইন্ডিং চালু করে, যেখানে অন্যথায় `:>`-এর বাইন্ড হওয়ার মতো কোনো লেক্সিকাল স্কোপ থাকত না:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

`:>` মিউটেশন সাফিক্স দিয়ে আপনি একটি লোকাল পুনরায় বাইন্ড করতে পারেন, যা ইম্পারেটিভ-ধাঁচের লুপে কাজে লাগে:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
