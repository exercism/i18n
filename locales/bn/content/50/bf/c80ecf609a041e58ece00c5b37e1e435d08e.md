# সম্পর্কে

যে ভ্যারিয়েবলগুলো `var`-এর বদলে `final` কিওয়ার্ড দিয়ে ডিক্লেয়ার করা হয়, সেগুলোতে কেবল একবারই মান অ্যাসাইন করা যায়।

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

এটা মনে রাখা গুরুত্বপূর্ণ যে যেসব টাইপ ইমিউটেবল নয়, সেগুলোর ক্ষেত্রে `final` কাঙ্ক্ষিত প্রভাব নাও ফেলতে পারে, যেমন অ্যারে বা অবজেক্ট:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
