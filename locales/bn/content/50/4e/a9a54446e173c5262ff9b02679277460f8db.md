# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় বন্ধুদের সাথে "উইজার্ড অ্যান্ড ওয়ারিয়রস" নামের একটি রোল-প্লেয়িং গেম খেলছেন। আপনি হলেন গেম মাস্টার, যাঁর দায়িত্ব খেলোয়াড়দের জন্য গেমের জগৎকে প্রাণবন্ত করে তোলা। এর একটি মূল দিক হলো খেলোয়াড়দের কাছে গেমটি বর্ণনা করা: কোনো ক্যারেক্টারের স্ট্যাটাস কী, তারা যে শহরে ঘুরতে যাচ্ছে সেটি কেমন দেখতে, ইত্যাদি।

আপনার পাঁচটি কাজ আছে, যেখানে খেলোয়াড়দের কাছে গেমের বিভিন্ন অংশ বর্ণনা করতে হবে।

## 1. একটি ক্যারেক্টার বর্ণনা করুন

প্রতিটি ক্যারেক্টারের একটি ক্লাস, লেভেল ও হিট পয়েন্টের সংখ্যা থাকে এবং তাকে এভাবে বর্ণনা করা হয়: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. (static) `GameMaster.Describe` মেথডটি ইমপ্লিমেন্ট করুন, যা একমাত্র প্যারামিটার হিসেবে একটি `Character` নেয় এবং তার বর্ণনা রিটার্ন করে।

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. একটি গন্তব্য বর্ণনা করুন

প্রতিটি গন্তব্যের একটি নাম ও একটি বাসিন্দার সংখ্যা থাকে এবং সেটি এভাবে বর্ণনা করা হয়: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. (static) `GameMaster.Describe` মেথডটি ইমপ্লিমেন্ট করুন, যা একমাত্র প্যারামিটার হিসেবে একটি `Destination` নেয় এবং তার বর্ণনা রিটার্ন করে।

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. ভ্রমণের পদ্ধতি বর্ণনা করুন

ক্যারেক্টাররা দুইটি উপায়ের একটি ব্যবহার করে গন্তব্যে ভ্রমণ করতে পারে:

- হেঁটে যাওয়া, যা এভাবে বর্ণনা করা হয়: `"You're traveling to your destination by walking."`
- ঘোড়ায় চড়ে যাওয়া, যা এভাবে বর্ণনা করা হয়: `"You're traveling to your destination on horseback."`

(static) `GameMaster.Describe` মেথডটি ইমপ্লিমেন্ট করুন, যা একমাত্র প্যারামিটার হিসেবে একটি `TravelMethod` নেয় এবং তার বর্ণনা রিটার্ন করে।

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. একটি ক্যারেক্টারের গন্তব্যে ভ্রমণ বর্ণনা করুন

যখন একটি ক্যারেক্টার কোনো গন্তব্যে ভ্রমণ করছে, তখন সেটি আলাদা আলাদা বর্ণনাগুলোর সমন্বয়ে এভাবে বর্ণনা করা হয়: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. (static) `GameMaster.Describe` মেথডটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে একটি `Character`, একটি `Destination` ও একটি `TravelMethod` নেয় এবং তার বর্ণনা রিটার্ন করে।

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. ভ্রমণের পদ্ধতি উল্লেখ না করে একটি ক্যারেক্টারের গন্তব্যে ভ্রমণ বর্ণনা করুন

বেশিরভাগ ক্ষেত্রেই ক্যারেক্টাররা হেঁটে গন্তব্যে ভ্রমণ করে। সুবিধার জন্য খেলোয়াড়দের নিজেদের ভ্রমণ পদ্ধতি উল্লেখ না করার সুযোগ দেওয়া হয়, সেক্ষেত্রে ভ্রমণ পদ্ধতি হিসেবে হেঁটে যাওয়াকেই ধরে নেওয়া হবে। (static) `GameMaster.Describe` মেথডটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে একটি `Character` ও একটি `Destination` নেয় এবং তার বর্ণনা রিটার্ন করে।

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
