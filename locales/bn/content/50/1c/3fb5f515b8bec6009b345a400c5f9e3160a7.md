# সম্পর্কে

ল্যামডা হলো নামহীন ফাংশন। এগুলো মূলত ফাংশনের একটি সংক্ষিপ্ত রূপ।

ল্যামডা [এক্সপ্রেশন ল্যামডা](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions) অথবা [স্টেটমেন্ট ল্যামডা](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions#statement-lambdas) হতে পারে:

```
(input_parameters) => expression
(input_parameters) => { <statements> }
```

## ল্যামডা ডিক্লেয়ার করা

যেসব ল্যামডা কোনো মান রিটার্ন করে না (`void`), সেগুলোকে `Action<T>` ডেলিগেট টাইপে রূপান্তর করা যায়।

```csharp
// Statement lambda
Action = () =>
{
    Console.WriteLine("No parameters");
    Console.WriteLine("Still nice, right?");
}

// Expression lambda
Action<int> = (x) => Console.WriteLine(x);
```

যেসব ল্যামডা void ছাড়া অন্য রিটার্ন ভ্যালু দেয়, সেগুলোকে `Func<T>` ডেলিগেট টাইপে রূপান্তর করা যায়।

```csharp
// Expression lambda
Func<int, int> = (x) => x * x;

// Statement lambda
Func<string, string, bool> = (left, right) =>
{
    var equal = left == right;
    return equal;
}
```

যদি কোনো ল্যামডার একটি মাত্র প্যারামিটার থাকে, তাহলে প্যারামিটারের চারপাশের বন্ধনীগুলো বাদ দেওয়া যায়:

```csharp
// Equivalent definitions
Action<int> = (x) => Console.WriteLine(x);
Action<int> = x => Console.WriteLine(x);
```

## ল্যামডা আর্গুমেন্ট

ল্যামডার মূল ব্যবহার হলো এগুলোকে অন্য মেথডে আর্গুমেন্ট হিসেবে পাস করা, যেমন LINQ-এর বেশিরভাগ মেথড:

```csharp
var numbers = new[] { 1, 2, 3, 4 };
var doubled = numbers.Select(n => n * 2);
foreach (var number in doubled)
{
    Console.Write(number)
}
// => 2468
```
