# টেস্ট

টেস্টগুলো রান করতে নিচের কমান্ডটি চালান:

```bash
make
```

## বাদ দেওয়া টেস্ট

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
ডিফল্টভাবে আপনি যখন টেস্টগুলো রান করেন, তখন কেবল একটি টেস্ট (প্রথমটি) চালানো হয়।
এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।
এটি পাস হয়ে গেলে, `TEST_IGNORE()` লাইনটি মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন।
সব টেস্ট চালু হয়ে গেলে এবং আপনার ইমপ্লিমেন্টেশন সেগুলো সব পাস করালে, আপনি অনুশীলনীটি সমাধান করে ফেলবেন!

## ডিবাগিং

ডিবাগিংয়ে সাহায্যের জন্য `debug.mac` ফাইলে নানা ধরনের ম্যাক্রো ডিফাইন করা আছে।
সঠিক আকারের এক বা একাধিক আর্গুমেন্ট দিয়ে এগুলো কল করা যায়।
উদাহরণস্বরূপ:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

ওই ম্যাক্রোগুলোর যেকোনো একটি ব্যবহার করতে হলে, সলিউশন ফাইলের শুরুতে `debug.mac` ইনক্লুড করতে হবে:

```x86asm
%include "debug.mac"
```
