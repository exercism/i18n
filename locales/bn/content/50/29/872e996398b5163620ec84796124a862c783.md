# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু ইউটিলিটি রুটিনের একটি অংশ বাস্তবায়ন করবেন, যা একজন ডেভেলপারকে আইডেন্টিফায়ার নাম পরিষ্কার করতে সাহায্য করবে।

৬টি টাস্কে আপনি ধীরে ধীরে ফাংশন দুটি তৈরি করবেন: `transform`, যা একক ক্যারেক্টার রূপান্তর করে, এবং `clean`, যা স্ট্রিং রূপান্তর করে।

একটি বৈধ আইডেন্টিফায়ারে শূন্য বা তার বেশি অক্ষর, আন্ডারস্কোর, হাইফেন, প্রশ্নচিহ্ন ও ইমোজি থাকতে পারে।

`clean` ফাংশনে যদি একটি খালি স্ট্রিং পাঠানো হয়, তাহলে একটি খালি স্ট্রিং রিটার্ন করা উচিত।

## 1. যেকোনো হাইফেন আন্ডারস্কোর দিয়ে প্রতিস্থাপন করুন

যেকোনো হাইফেনকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করতে `transform` ফাংশনটি বাস্তবায়ন করুন।

```julia
julia> transform('-')
"_"
```

## 2. সব হোয়াইটস্পেস মুছে ফেলুন

সব হোয়াইটস্পেস ক্যারেক্টার মুছে ফেলুন।
এর মধ্যে শুরু ও শেষের হোয়াইটস্পেসও থাকবে।

```julia
julia> transform(' ')
""
```

## 3. ক্যামেলকেসকে কেবাব-কেসে রূপান্তর করুন

camelCase-কে kebab-case-এ রূপান্তর করতে `transform` ফাংশনটি পরিবর্তন করুন

```julia
julia> transform('D')
"-d"
```

## 4. যেসব ক্যারেক্টার সংখ্যা, সেগুলো বাদ দিন

যেকোনো সংখ্যাসূচক ক্যারেক্টার বাদ দিতে `transform` ফাংশনটি পরিবর্তন করুন।

```julia
julia> transform('7')
""
```

## 5. গ্রিক ছোট হাতের অক্ষর প্রশ্নচিহ্ন দিয়ে প্রতিস্থাপন করুন

'α' থেকে 'ω' পর্যন্ত পরিসরের যেকোনো গ্রিক অক্ষর প্রতিস্থাপন করতে `transform` ফাংশনটি পরিবর্তন করুন।

```julia
julia> transform('β')
"?"
```

## 6. একটি স্ট্রিংয়ে কাজ করার জন্য এই অপারেশনগুলো একসাথে করুন

সম্পূর্ণ একটি স্ট্রিংয়ে এই অপারেশনগুলো প্রয়োগ করতে `clean` ফাংশনটি বাস্তবায়ন করুন।

যেসব ক্যারেক্টার নিয়মের বাইরে পড়ে, সেগুলো অপরিবর্তিত অবস্থায় পার হয়ে যাবে।

```julia
julia> clean("  a2b Cd-ω😀  ")
"ab-cd_?😀"
```
