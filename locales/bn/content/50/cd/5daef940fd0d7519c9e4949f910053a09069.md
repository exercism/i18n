# অভ্যন্তরীণ লিংকিং

Exercism-এর Markdown পার্সারের মাধ্যমে রেন্ডার করা লিংক অভ্যন্তরীণ কি না তা যাচাই করা হয়, আর অভ্যন্তরীণ হলে সেগুলোতে টুলটিপ যুক্ত করা হতে পারে।

একটি কনসেপ্টের টুলটিপ দেখতে এমন হতে পারে:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## ব্যবহার

এভাবে লিংক সাজানোর জন্য কোনো বিশেষ সিনট্যাক্স নেই।
এর বদলে আমরা যাচাই করি লিংকের href নিচের দুটি রূপের একটি অনুসরণ করে কি না:

- একটি URL। যেমন https://exercism.org/tracks/ruby/concepts/basics
- একটি অ্যাবসোলিউট পাথ। যেমন /tracks/ruby/concepts/basics

আমরা বর্তমানে রিলেটিভ URL সমর্থন করি না (`./` বা `../` দিয়ে শুরু হওয়া URL যেমন), কারণ Markdown পার্সার জানে না যে সে যে ডকুমেন্টটি রেন্ডার করে তার প্রসঙ্গ কী, সে কোন প্রসঙ্গে রেন্ডার করছে, বা একটি git রিপোজিটরির গঠন কেমন।

## বিকল্প

সাধারণ লিংকের বদলে আপনি Widgets রেন্ডার করতে চাইতে পারেন।
এগুলো সাধারণত কোনো ডকুমেন্টের শেষে অতিরিক্ত পড়ার সুপারিশ করতে বা শেখার জন্য ভালো অনুশীলনী দেখাতে ব্যবহার করা হয়।

আরও বিস্তারিত জানতে [Widgets-এর ডকুমেন্টেশন](/docs/building/markdown/widgets) দেখুন।
