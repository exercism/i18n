# ভূমিকা

[`Nothingness`][concept-nothingness] কনসেপ্টে যেমন আলোচনা করা হয়েছে, অনুপস্থিত (`NULL`), অজানা (`NA`) বা গাণিতিকভাবে অবৈধ (`NaN`, `Inf`) ডেটা প্রকাশ করার বিভিন্ন উপায় R-এ আছে।
সাধারণভাবে, R এই মানগুলো ব্যবহার করে জায়গাতেই সমস্যা চিহ্নিত করার চেষ্টা করে এবং কোনো এক্সসেপশন ছাড়াই চালিয়ে যায়।

## `stop()`

কিছু সমস্যা এতটাই মৌলিক যে প্রোগ্রাম আর চালিয়ে যাওয়া যায় না।
সেক্ষেত্রে `stop(msg)` ব্যবহার করে সঙ্গে সঙ্গে একটি `Error` নিয়ে প্রোগ্রাম থামিয়ে দিন এবং `msg` প্রিন্ট করুন।

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

অন্য ভাষার `assert`-এর মতো, এটি `stop()`-এর একটি সুবিধাজনক র্যাপার।
এর প্যারামিটার হলো কমা দিয়ে আলাদা করা যেকোনো সংখ্যক বুলিয়ান শর্ত, এবং সেগুলোর সবকটিই `TRUE` হলেই প্রোগ্রামটি চালিয়ে যাবে।

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()` এবং `message()`

এগুলো এমন অবস্থার প্রতিক্রিয়া যা প্রোগ্রাম বন্ধ করে না, যেমন:

- এমন কোনো সমস্যা সম্পর্কে সতর্ক করা, যা থেকে প্রোগ্রামটি অন্তত আংশিকভাবে সেরে উঠতে পারে।
- দীর্ঘ সময় ধরে চলা একটি প্রোগ্রামের অগ্রগতি সম্পর্কে ব্যবহারকারীকে জানানো।

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

`suppressWarnings()` ফাংশনটি মাঝে মাঝে Exercism-এর ভেতরে কাজে লাগতে পারে, যাতে অবাঞ্ছিত আউটপুট দিয়ে টেস্ট রানারকে বিভ্রান্ত না করা হয়।
