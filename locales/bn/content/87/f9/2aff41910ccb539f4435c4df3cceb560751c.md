# ভূমিকা

`Integer` যত বড় সংখ্যাই হোক না কেন, আপনার মেশিনের মেমোরির সীমা পর্যন্ত যেকোনো সংখ্যা ধরে রাখতে পারে; অন্যদিকে `Int` বলতে ৩২ বা ৬৪ বিটে প্রকাশ করা যায় এমন ধনাত্মক ও ঋণাত্মক ইন্টিজারের সেটকে বোঝায় (অন্তত -2^29 থেকে 2^29 পর্যন্ত নিশ্চিত)।

`Float` বাস্তব সংখ্যার সেটের সাথে মেলে, যা কম্পিউটারের নির্ভুলতার সীমার মধ্যে সীমাবদ্ধ।

সংখ্যার ওপর সংজ্ঞায়িত অপারেশনগুলো সাধারণত এক টাইপ বা অন্যটির ওপর কাজ করে, কিন্তু দুটিতেই নয়।

`Float` আর `Integer`-এর মধ্যে রূপান্তরের ফাংশনগুলোর মধ্যে আছে, অন্যদের মধ্যে, `toFloat` যা `Int`/`Integer`-কে `Float`-এ রূপান্তর করে, আর `ceiling` যা একটি `Float`-কে `Int`-এ রূপান্তর করে।

একটি ইন্টিজার টাইপ (`Int` বা `Integer`) থেকে অন্য যেকোনো সাংখ্যিক টাইপে রূপান্তর করা হয় `fromIntegral` ফাংশনটি ব্যবহার করে।
টার্গেট টাইপটি স্বয়ংক্রিয়ভাবে অনুমান করা হয়।
যেমন:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
