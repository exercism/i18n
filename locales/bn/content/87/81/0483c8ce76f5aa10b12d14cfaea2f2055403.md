# নির্দেশনা সংযোজন

## ওয়ার্ড

`find-fewest-coins ( coins target -- result )` কয়েন ডিনোমিনেশনের একটি অ্যারে রিটার্ন করে, যেগুলোর যোগফল `target`। `coins` হলো একটি হ্যাশ সেট (যেমন `HS{ 1 5 10 25 }`); এটি নিয়ে কাজ করতে `sets` ভোকাবুলারির ওয়ার্ডগুলো (`members`, `in?`, …) ব্যবহার করুন।

যখন `coins`-এর কোনও কম্বিনেশন দিয়ে `target` তৈরি করা যায় না, তখন একটি `cannot-make-change` এরর থ্রো করুন।
