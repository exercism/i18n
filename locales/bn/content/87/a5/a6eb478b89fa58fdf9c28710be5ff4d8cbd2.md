# পরিচিতি

একটি `List` আর একটি `Array`-এর মধ্যে বেশ মিল রয়েছে। তবে এমন কয়েকটি বড় পার্থক্য আছে যা এড়িয়ে যাওয়া একেবারেই উচিত নয়:

1. বর্গাকার বন্ধনী, অর্থাৎ `[0]`, দিয়ে `List`-কে ইনডেক্স করা যায় না।
2. `List` ইনিশিয়ালাইজ করা যায় না।
3. লিস্ট কম্প্রিহেনশন বলে কিছু নেই।
4. ইটারেশন করার সময় `List`-এর এলিমেন্টগুলো অবাধে পরিবর্তন করা যায়।

`List` হলো `haxe.ds` প্যাকেজের একটি সদস্য, তাই লিস্ট ব্যবহার করতে চাইলে প্রতিবারই এর প্যাকেজটি ইমপোর্ট করতে হবে:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
