# স্ট্রিং সম্পর্কে

Kotlin-এ একটি [`string`][ref-string] হলো ইউনিকোড ক্যারেক্টারের একটি ইমিউটেবল সিকোয়েন্স।

[`Immutable`][wiki-immutable] মানে হলো, একটি স্ট্রিংয়ের উপর যেকোনো অপারেশনকে অবশ্যই একটি নতুন স্ট্রিং রিটার্ন করতে হবে: আসল স্ট্রিং কখনোই বদলাতে পারে না।

[`Unicode`][wiki-unicode] মানে হলো, বিশ্বের বেশিরভাগ লিখন পদ্ধতি এতে প্রকাশ করা যায়, কিন্তু (C-এর মতো পুরনো ভাষার বিপরীতে) ক্যারেক্টার আর বাইটের মধ্যে ১:১ ম্যাপিং নেই।
এটি নিয়ে [`Chars`][concept-chars] কনসেপ্টে আরও আলোচনা করা হবে।

একটি স্ট্রিং ডাবল কোট `" "` দিয়ে ঘেরা থাকে।

কিছু ক্যারেক্টার এস্কেপ করা প্রয়োজন: `\\`, সাথে সাধারণ প্রিন্ট না হওয়া ক্যারেক্টার যেমন `\t` (ট্যাব) আর `\n` (নিউলাইন)।

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

মাল্টি-লাইন স্ট্রিং তিনটি ডাবল কোট দিয়ে ঘেরা থাকে এবং এতে যেকোনো লেখা থাকতে পারে (এস্কেপ করার দরকার নেই)।

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

লাইনগুলোর সাধারণ ইনডেন্টিং সরাতে [trimIndent][trimIndent-doc] ব্যবহার করুন।
স্ট্রিংটি ফরম্যাট করার জন্য এটি কাজে লাগে:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

বিকল্পভাবে, [trimMargin][trimMargin-doc] দিয়ে আপনি একটি ডেলিমিটার ঠিক করতে পারেন।
তখন `String`-এর প্রতিটি লাইন ডেলিমিটারের পরে শুরু হয়।
ডেলিমিটারের ডিফল্ট মান `|`, তবে আপনি প্যারামিটার হিসেবে ভিন্ন ডেলিমিটার দিতে পারেন।
যেমন:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

`+` দিয়ে স্ট্রিং কনক্যাটেনেট করা যায়, তবে এটি ছোট আর সহজ ক্ষেত্রে সীমাবদ্ধ রাখাই ভালো।
এর বাইরে আরও, এবং প্রায়ই আরও ভালো, কিছু উপায় আছে।

## স্ট্রিং টেমপ্লেট

[`Templates`][ref-templates] বলতে বোঝায়, অন্য কিছু ভাষায় যাকে "interpolation" বলা হয়।

যদি একটি স্ট্রিংয়ে ডলার চিহ্ন `$` থাকে, যার পরে একটি আইডেন্টিফায়ার থাকে, অথবা দ্বিতীয় বন্ধনী (`{expression}`) দিয়ে ঘেরা একটি এক্সপ্রেশন থাকে, তবে সেগুলোর জায়গায় যথাক্রমে ওই মানটি বা ওই এক্সপ্রেশনের ফলাফলটি বসে।

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## স্ট্রিং ফরম্যাটিং

JVM প্ল্যাটফর্মে (শুধু এখানেই), `String.format()` স্ট্রিং টেমপ্লেটের চেয়ে আরও নিখুঁত ফরম্যাটিং করতে দেয়, যার [সিনট্যাক্স][web-formats] (_খুব পুরনো!_) [`printf`][wiki-printf] ফাংশনের মতো।

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## স্ট্রিং ফাংশন

স্ট্রিং নিয়ে কাজ করার জন্য Kotlin _অনেক_ [`functions`][ref-string-functions] দেয়।

বেশিরভাগই এগুলো `String` ক্লাসের মেম্বার নয়, বরং [`extensions functions`][ref-extensions], যদিও আমরা কীভাবে এগুলো ব্যবহার করি তাতে এর খুব একটা প্রভাব নেই।

~~~~exercism/note
Kotlin-এর বরং জটিল [ডকুমেন্টেশন][ref-string-functions] পেজগুলো ডিফল্ট ভিউতে এক্সটেনশন ফাংশন লুকিয়ে রাখে।
এটি লেখার সময়ে, সবচেয়ে মূল্যবান কনটেন্ট লুকানো আছে `Members & Extensions` নামের একটি ট্যাবে।
এটিতে ক্লিক করে সেকশনটি খুলুন এবং `String` ক্লাসে উপলব্ধ সব মেম্বার ও এক্সটেনশন দেখুন।

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

নিচের উদাহরণটি শুধু উপলব্ধ জিনিসের একটি ছোট অংশ দেখায়:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## একটি স্ট্রিং তৈরি করা

কখনো কখনো একটি লম্বা স্ট্রিং ধাপে ধাপে গড়ে তুলতে হয়, যেমন কোনো লুপের ভেতরে।

`+` দিয়ে স্ট্রিং কনক্যাটেনেট করা শিগগিরই সুন্দরও লাগে না, দক্ষও হয় না: ইমিউটেবিলিটির কারণে _অনেক_ কপি করতে হয়।

একাধিক স্ট্রিং একত্র করার জন্য Kotlin-এ আরও দক্ষ বিভিন্ন উপায় আছে:

- স্ট্রিং টেমপ্লেট, যার কথা উপরে বলা হয়েছে।
- [`joinToString()][ref-jointostring], যার আলোচনা [অ্যারে][concept-lists] কনসেপ্টে আসবে।
- Java-র [`StringBuilder`][ref-stringbuilder], যা বিশেষ আইডিওম্যাটিক Kotlin হিসেবে বিবেচিত হয় না।
- Kotlin-এর [`buildString()`][ref-buildstring], যা `StringBuilder`-কে আরও সংক্ষিপ্ত ও আইডিওম্যাটিক সিনট্যাক্সে মুড়ে দেয়।
এটি স্ট্রিং তৈরির লজিককে ল্যাম্বডা আর্গুমেন্ট হিসেবে নেয়, যা পরে কোনো কনসেপ্টে আলোচনা করা হবে।

মূলত, একটি `StringBuilder` হলো একটা তালিকা-সদৃশ স্ট্রাকচার, যাতে অনেক সুবিধাজনক মেথড আছে।
এটি তার একটি ছোট অংশ:

- [`append()`][ref-sb-append] দিয়ে শেষে যোগ করা যায়।
- [`insert()`][ref-sb-insert] দিয়ে নির্দিষ্ট অবস্থানে যোগ করা যায়।
- [`deleteAt()`][ref-sb-deleteat] আর [`deleteRange()`][ref-sb-deleterange] দিয়ে নির্দিষ্ট অবস্থান থেকে মুছে ফেলা যায়।
- `toString()` দিয়ে শেষে একটি সাধারণ স্ট্রিংয়ে রূপান্তর করা যায়: সবকিছু একটিমাত্র দক্ষ অপারেশনে কনক্যাটেনেট করা হয়।

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

পরের কনসেপ্টগুলোর সিনট্যাক্স ব্যবহার করে একটি `buildString()` উদাহরণ:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
