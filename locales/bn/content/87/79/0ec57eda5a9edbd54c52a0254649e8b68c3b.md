# নির্দেশনার সংযোজন

## `from_quote`-এর সুবিধা ও অসুবিধা

এই অনুশীলনীতে `Time` টাইপে একটি `from_quote` ফাংশন ডিফাইন করা হয়েছে। এর ফলে এ রকম কোড লেখা সম্ভব হয়:

```roc
time : Time
time = "00:01:23"
```

এই কোডটি কম্পাইল টাইমে অন্তর্নিহিতভাবে `Time.from_quote("00:01:23")` কল করে। এতে সম্ভাব্য প্রোগ্রামের গতি বাড়তে পারে, কারণ রানটাইমে পার্সিং সামলানোর দরকার হয় না, আর এটা নিশ্চিত করে যে `from_quote` প্রত্যাখ্যান করা টাইমগুলো রানটাইমে নয়, কম্পাইল টাইমেই ধরা পড়ে। উপরন্তু, এটি কোডকে সুন্দর ও পড়ার উপযোগী করে তোলে। উদাহরণস্বরূপ, এই অনুশীলনীর একটি টেস্ট দেখুন:

```roc
## start initiates time tracking for current lap
expect {
	result = Stopwatch.create()
		.start()?
		.advance_time("00:00:05")
		|> expect_current_lap("00:00:05")

	result.is_ok()
}
```

তবে এই কোড পড়ে কেউ ধরে নিতে পারেন যে `advance_time` ফাংশনটি একটি `Str` নেয়, অথচ আসলে এটি `Time` নেয়। এতে বিভ্রান্তি ও ভুল হতে পারে। এ কারণে আপনি হয়তো একটু লম্বা কিন্তু আরও স্পষ্ট রূপটি পছন্দ করবেন: `"00:00:05".Time`, যেটিও কম্পাইল টাইমে `from_quote` কল করে।

আপনার নিজের প্রোগ্রামে আপনি বরং `from_str` ব্যবহার করতে চাইতে পারেন:

```roc
Time := { ... }.{
    from_str : time_str -> Try(Time, [InvalidTime])
    from_str = |time_str| ...
}
```

আপনি কম্পাইল টাইমে `from_str` (বা অন্য যেকোনো পিউর ফাংশন) কল করতে পারেন, এভাবে:

```roc
Ok(time) = Time.from_str("00:01:23")
```

লক্ষ্য করুন: এই ডেফিনিশনটি টপ লেভেলে রাখলে এটি কম্পাইল টাইমে চলে (যেহেতু ফাংশনটি পিউর এবং এর ইনপুট কম্পাইল টাইমেই জানা থাকে)। কোনো ফাংশনের ভিতরে আপনি রানটাইমে `from_str` ব্যবহার করতে পারেন।
