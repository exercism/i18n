# পরিচিতি

Gleam-এ হায়ার অর্ডার ফাংশন লেখা ও ব্যবহার করা কমন ব্যাপার, অর্থাৎ এমন ফাংশন যা অন্য ফাংশনকে আর্গুমেন্ট হিসেবে নেয়। অনেকগুলো হায়ার অর্ডার ফাংশন একসাথে ব্যবহার করলে কোডে অনেক স্তরের ইন্ডেন্টেশন জমে গিয়ে পড়া কঠিন হয়ে যেতে পারে।

উদাহরণস্বরূপ, এখানে এমন একটি ফাংশন আছে যা `Result(Int, Nil)` রিটার্ন করে এমন কয়েকটি ফাংশনকে কল করে, এবং চারটিই সফল হলে মানগুলো যোগ করে।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam-এর `use` এক্সপ্রেশন দিয়ে আমরা এই কোডটি ইন্ডেন্টেশন ছাড়াই লিখতে পারি, যা প্রায়ই কোড পড়া আরও সহজ করে তোলে।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

একটি `use` এক্সপ্রেশন ব্লকে থাকা পরবর্তী সব স্টেটমেন্ট একত্র করে সেটিকে একটি কলব্যাক ফাংশন হিসেবে ফাংশন কলে শেষ আর্গুমেন্ট হিসেবে পাঠায়। `use` কিওয়ার্ড এবং `<-` চিহ্নের মাঝের ভ্যারিয়েবলগুলো হলো সেই আর্গুমেন্টগুলোর নাম, যেগুলো কলব্যাক ফাংশনে পাঠানো হবে।

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

কলব্যাক ফাংশন যেকোনো সংখ্যক আর্গুমেন্ট নিতে পারে, আবার একটিও না নিয়ে থাকতে পারে।

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

`use` এক্সপ্রেশন দিয়ে কল করা যায় এমন একটি ফাংশন বানাতে শেষ আর্গুমেন্ট হিসেবে একটি কলব্যাক ফাংশন নেওয়া ছাড়া আর কোনো বিশেষ শর্ত নেই।

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam-এর `use` এক্সপ্রেশন অত্যন্ত শক্তিশালী একটি ফিচার, যা অনেক সমস্যায় কাজে লাগানো যায়, কিন্তু অতিরিক্ত ব্যবহার করলে কোড পড়া কঠিন করে তুলতে পারে। সাধারণভাবে স্বাভাবিক ফাংশন কল সিনট্যাক্স ব্যবহার করাই ভালো, আর `use` এক্সপ্রেশন তখনই ব্যবহার করা উচিত যখন তা কোড পড়া সহজ করে।
