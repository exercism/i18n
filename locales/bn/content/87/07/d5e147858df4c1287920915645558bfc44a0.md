# পরিচিতি

এটি হতে পারে একটি _বিশাল_ বিষয়!
এটি নিয়ে একটি লম্বা বই লেখা সম্ভব, আর বেশ কয়েকজন তা করেছেন (কয়েকটি উদাহরণ দেখতে Amazon-এ "unicode book" খুঁজুন)।

## এক অতি সংক্ষিপ্ত ইতিহাস

আগের দশকগুলোতে কম্পিউটারে ক্যারেক্টার নিয়ে কাজ করা অনেক সহজ ছিল, যখন প্রোগ্রামাররা ধরে নিতেন যে ইংরেজিই একমাত্র গুরুত্বপূর্ণ ভাষা।
তাই: ২৬টি অক্ষর, বড় ও ছোট হাতের অক্ষর, ১০টি ডিজিট, কয়েকটি বিরামচিহ্ন, সাথে বেল বাজানোর একটি কোড (0x07), আর এই সবকিছু ৭ বিটে ধরে যেত: [ASCII][wiki-ascii] ক্যারেক্টার সেট।

স্বাভাবিকভাবেই, মানুষ জিজ্ঞাসা করতে শুরু করল à, ä আর Ł-এর কী হবে, তারপর অন্যরা জিজ্ঞাসা করতে শুরু করল ऄ, ஹ আর ญ-এর কী হবে, আর তরুণরা চাইল ইমোজি 😱।
কী করা যায়?

লম্বা গল্প সংক্ষেপে, অনেক বুদ্ধিমান ও ধৈর্যশীল মানুষকে বছরের পর বছর কমিটিতে দায়িত্ব পালন করতে হয়েছে, [Unicode][web-unicode] ক্যারেক্টার সেট এবং [UTF-8][wiki-utf-8]-এর মতো এনকোডিংয়ের খুঁটিনাটি বের করতে, আর অনেক সফটওয়্যারকে _খুবই_ জটিলভাবে নতুন করে লিখতে হয়েছিল।
এছাড়াও, অনেক নতুন Bug তৈরি হয়েছিল।

_সবকিছু_ ভেঙে পড়া রোধ করতে, Unicode/UTF-8 ডিজাইনে নিশ্চিত করা হয়েছে যে প্রথম ১২৭টি কোড ASCII-এর সাথে হুবহু মিলে যায় _(এমনকি বেলটিও)_।

## Kotlin-এ ক্যারেক্টার

২০০৫ সালের দিকে বা তার পরে ডিজাইন করা ভাষাগুলোর বড় সুবিধা ছিল যে তখন একটি মোটামুটি স্থিতিশীল Unicode স্ট্যান্ডার্ড আগেই তৈরি হয়ে গিয়েছিল।

Kotlin (প্রথম প্রকাশিত হয় ২০১১ সালে) ধরে নিতে পেরেছিল যে ব্যবহারকারীরা নানা (মানব) ভাষা ব্যবহার করবেন, আর সেগুলো প্রকাশ করতে তাঁদের Unicode দরকার হবে।

ক্যারেক্টার লিটারাল একক উদ্ধৃতি চিহ্নের ভেতরে লেখা হয়, আর এটি দ্বৈত উদ্ধৃতি চিহ্নে লেখা স্ট্রিং থেকে আলাদা।
C/C++ জগতের মানুষের কাছে এটি সম্ভবত স্পষ্ট, কিন্তু Python আর JavaScript প্রোগ্রামারদের কাছে বিভ্রান্তিকর হতে পারে।

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

`Char` আর `Int`-এর মধ্যে রূপান্তর করা সহজ:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

কম্পাইলার `Char`-এর উপর ইন্টিজার অ্যারিথমেটিকের _কিছু_ রূপ অনুমোদন করে:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char`-এর জন্য কিছু ফাংশন

সবসময়ের মতোই, এখানে আলোচনা করার জন্য [অনেক বেশি ফাংশন][ref-char-lib] আছে, তাই এটি কেবল একটি নির্বাচিত তালিকা।

- উপযুক্ত বর্ণমালার জন্য, [`uppercase()`][ref-uppercase] আর [`lowercase()`][ref-lowercase] দিয়ে কেস বদলান।
- [`isUpperCase()`][ref-isuppercase] আর [`isLowerCase()`][ref-islowercase] দিয়ে কেস পরীক্ষা করুন।
- ক্যারেক্টারের ধরন পরীক্ষা করুন এগুলো দিয়ে:
    - [`isLetter()`][ref-isletter], অনেক বর্ণমালা কভার করে
    - [`isDigit()`][ref-isdigit], ০..৯ রেঞ্জে
    - `isLetterOrDigit()`, আগের দুটি একসাথে করে
    - [`isWhitespace()`][ref-iswhitespace], যেকোনো হোয়াইটস্পেস ক্যারেক্টার

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## ক্যারেক্টার লিস্ট ও স্ট্রিংয়ের পারস্পরিক রূপান্তর

স্ট্রিং থেকে ক্যারেক্টার লিস্টে যেতে আমরা `toList()` ব্যবহার করতে পারি।

ক্যারেক্টার লিস্ট থেকে স্ট্রিংয়ে যেতে আছে [`joinToString()`][ref-jointostring] ফাংশন, যা আর্গুমেন্ট হিসেবে একটি সেপারেটর (প্রায়শই খালি স্ট্রিং) নেয়।

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

খেয়াল করুন, `joinToString()` একটি লিস্ট বা অ্যারের উপর কাজ করে।
একটি `Char`-কে ১ ক্যারেক্টারের স্ট্রিংয়ে _কাস্ট_ করতে `toString()` ব্যবহার করুন।

```kotlin
'a'.toString() // => "a"
```

একটি ক্যারেক্টার কোনো `String`-এ, বা একটি `Char` লিস্ট বা অ্যারেতে আছে কি না তা দেখতে আমাদের আছে `in`, যা [`contains()`][ref-contains] ফাংশনের সাথে মেলে।

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
