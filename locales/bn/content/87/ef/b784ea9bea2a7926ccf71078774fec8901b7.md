# নির্দেশনা

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন নিচের মতো ফরম্যাট করা একটি স্ট্রিং: `"[<LEVEL>]: <MESSAGE>"`.

তিনটি আলাদা লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার তিনটি কাজ আছে; প্রতিটি কাজে একটি লগ লাইন পাবেন এবং সেটি দিয়ে কিছু করতে হবে।

## 1. লগ লাইন থেকে মেসেজ বের করুন

লগ লাইনের মেসেজ রিটার্ন করার জন্য (_static_) `LogLine.Message()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

শুরুতে বা শেষে থাকা যেকোনো হোয়াইট স্পেস মুছে ফেলতে হবে:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. লগ লাইন থেকে লগ লেভেল বের করুন

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য (_static_) `LogLine.LogLevel()` মেথডটি ইমপ্লিমেন্ট করুন; লগ লেভেলটি ছোট হাতের অক্ষরে রিটার্ন করতে হবে:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. লগ লাইন রিফরম্যাট করুন

লগ লাইনটি রিফরম্যাট করার জন্য (_static_) `LogLine.Reformat()` মেথডটি ইমপ্লিমেন্ট করুন, যেখানে মেসেজটি আগে থাকে এবং তার পরে বন্ধনীর মধ্যে লগ লেভেলটি থাকে:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
