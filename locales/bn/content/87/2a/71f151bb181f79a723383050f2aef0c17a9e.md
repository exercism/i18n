# নির্দেশনা

Blorkemon™️ কার্ডের প্রতি আপনার নস্টালজিয়া যেন কমার নামই নেই, আপনি তো আবার সেগুলো সংগ্রহ করাও শুরু করে দিয়েছেন, আর বন্ধুদেরও নিজের সঙ্গে যোগ দিতে উৎসাহ দিচ্ছেন।

এই অনুশীলনীতে একটি কার্ডের সংগ্রহ বোঝানো হয়েছে `Set(String)` দিয়ে, কারণ আপনার লক্ষ্য যখন বিদ্যমান সব কার্ড পাওয়া, তখন একই কার্ড একাধিকবার থাকা গুরুত্বপূর্ণ নয়।

## 1. একটি সংগ্রহ শুরু করুন

আপনি সত্যিই চান আপনার বন্ধুরাও আপনার Blorkemon™️-পাগলামিতে যোগ দিক, আর তার সবচেয়ে ভালো উপায় হলো তাদের একটি কার্ড দিয়ে তাদের সংগ্রহ শুরু করে দেওয়া।

`new_collection` ইমপ্লিমেন্ট করুন, যা একটি কার্ডকে একটি সংগ্রহে রূপান্তর করে।

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. সংগ্রহ বাড়ান

একবার আপনার হাতে একটি সংগ্রহ এলে তা নিজের একটা জীবন পেয়ে যায়, আর তাকে বাড়তেই হবে।

`add_card` ইমপ্লিমেন্ট করুন, যা একটি কার্ড আর একটি সংগ্রহ নেয়, এবং দুটি মানের একটি টিউপল রিটার্ন করে: একটি `Bool`, যা জানায় কার্ডটি আগেই সংগ্রহে ছিল কি না, এবং কার্ডটি যোগ করা সেই সংগ্রহটি।

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. বিনিময় শুরু করুন

এখন যেহেতু আপনার বন্ধুরা আবার Blorkemon™️ নিয়ে পাগল হয়ে উঠেছে, আপনি কার্ড বিনিময় করে নিজের সংগ্রহ বাড়িয়ে নিতে পারেন।

সব বিনিময়ই যে করা যায় বা লাভজনক, তা কিন্তু নয়।
আপনার কাছে নেই এমন কার্ড বিনিময় করা যায় না, আর যে কার্ড আপনার কাছে আগেই আছে, তার জন্য কোনো কার্ড বিনিময় করা উচিত নয়।

`trade_card` ইমপ্লিমেন্ট করুন, যা বিনিময়ের জন্য দুটি কার্ড (আপনার আর তাদের) এবং আপনার বর্তমান সংগ্রহ নেয়।
এর রিটার্ন ভ্যালু দুটি মানের একটি টিউপল: একটি `Bool`, যা জানায় বিনিময়টি সম্ভব এবং লাভজনক কি না, আর বিনিময়টি করলে শেষে আপনার হাতে যে সংগ্রহটি থাকত সেটি (যদিও সেটি আসলে সম্ভবই না হয়)।

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. সবার কাছে থাকা কার্ড

আপনি আর আপনার Blorkemon™️-অনুরাগী বন্ধুরা একসঙ্গে জড়ো হয়ে ভাবেন, সবচেয়ে কমন কার্ডগুলো কোনগুলো।

`boring_cards` ইমপ্লিমেন্ট করুন, যা সংগ্রাহের একটি অ্যারে নেয় আর এমন সাজানো কার্ডের একটি অ্যারে রিটার্ন করে, যেগুলো সব সংগ্রহেই আছে।

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. সব কার্ড

আপনি আর আপনার বন্ধুরা মিলে কি Blorkemon™️-এর সব কার্ডেরই মালিক?

`total_cards` ইমপ্লিমেন্ট করুন, যা সংগ্রাহের একটি অ্যারে নেয় আর সব সংগ্রহ মিলিয়ে ভিন্ন ভিন্ন কার্ডের মোট সংখ্যা রিটার্ন করে।

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. চকচকেই জয়

আপনার ভাগনে খুব শিগগিরই আপনার সঙ্গে দেখা করতে আসছে, আর আপনি তাকে মুগ্ধ করতে চান।
ছোটরা তো চকচকে জিনিস পছন্দ করে, তাই না?
Blorkemon™️ কার্ড তো চকচকেও হতে পারে!

`shiny_cards` ইমপ্লিমেন্ট করুন, যা একটি সংগ্রহ নেয় আর `"Shiny "` দিয়ে শুরু হওয়া সব কার্ড ধারণ করা একটি সেট রিটার্ন করে।

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
