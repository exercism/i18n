# পরিচিতি

## ইনহেরিটেন্স

C#-এ _ইনহেরিটেন্স_ ব্যবহার করে একটি _ক্লাস_-হায়ারার্কি ডিফাইন করা যায়, যা একটি ডেরাইভড ক্লাসকে (`Car`) তার প্যারেন্ট ক্লাসের (`Vehicle`) আচরণ ও ডেটা ইনহেরিট করার সুযোগ দেয়। কোনো প্যারেন্ট নির্দিষ্ট না থাকলে ক্লাসটি `object` ক্লাস থেকে ইনহেরিট করে।

প্যারেন্ট ক্লাস তিনভাবে ডেরাইভড ক্লাসকে ফাংশনালিটি দিতে পারে:

- একটি সাধারণ মেথড ডিফাইন করা।
- একটি `virtual` মেথড ডিফাইন করা, যা সাধারণ মেথডের মতোই, তবে ডেরাইভড ক্লাস এটিকে _বদলাতে পারে_।
- একটি `abstract` মেথড ডিফাইন করা, যা ইমপ্লিমেন্টেশন ছাড়া একটি মেথড এবং ডেরাইভড ক্লাসকে এটি _অবশ্যই_ ইমপ্লিমেন্ট করতে হবে। যে ক্লাসে `abstract` মেথড থাকে, সেই ক্লাসটিকেও `abstract` হিসেবে চিহ্নিত করতে হবে। অ্যাবস্ট্রাক্ট ক্লাস ইনস্ট্যান্টিয়েট করা যায় না।

`protected` অ্যাক্সেস মডিফায়ার একটি প্যারেন্ট ক্লাসের সদস্যকে ডেরাইভড ক্লাসে অ্যাক্সেস করার সুযোগ দেয়, কিন্তু অন্য ক্লাস থেকে অ্যাক্সেস আটকে দেয়।

ডেরাইভড ক্লাস `base` কিওয়ার্ডের মাধ্যমে প্যারেন্ট ক্লাসের সদস্যগুলো অ্যাক্সেস করতে পারে।

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

ডেরাইভড ক্লাসের কনস্ট্রাক্টর নিজের কনস্ট্রাক্টরের লজিক চালানোর _আগে_ স্বয়ংক্রিয়ভাবে তার প্যারেন্টের কনস্ট্রাক্টর কল করবে। `base` কিওয়ার্ড ব্যবহার করে প্যারেন্ট ক্লাসের কনস্ট্রাক্টরে আর্গুমেন্ট পাঠানো যায়:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

একটি বেস ক্লাস থেকে যখন একাধিক ক্লাস ডেরাইভ করা হয়, তখন ওই দুই (বা তার বেশি) ক্লাস প্রায়ই বেস ক্লাসের একটি মেথডের ভিন্ন ভিন্ন ভার্সন ইমপ্লিমেন্ট করে। এটিই পলিমরফিজম নামের অত্যন্ত গুরুত্বপূর্ণ একটি নীতি। যেমন উপরের উদাহরণের একটি ভিন্ন রূপে দেখানো হয়েছে, কী ধরনের ভেহিকেল ইনস্ট্যান্টিয়েট করা হয়েছে তার উপর নির্ভর করে `Vehicle` ব্যবহার করা কোড কীভাবে নিজের আচরণ বদলাতে পারে।

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
