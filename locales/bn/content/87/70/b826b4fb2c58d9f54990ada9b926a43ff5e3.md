# নির্দেশনা

অ্যান্টওয়ার্পের মার্শালিং ইয়ার্ডে আরেকটি ব্যস্ত রাত। আপনি ডিউটিতে থাকা ডিসপ্যাচার: আসা মালবাহী ওয়াগনগুলোকে বাইরে যাওয়া ট্রেনে নতুন করে সাজাতে হবে, কাপলিং পরীক্ষা করতে হবে, জংশনে রুট ভাগ করতে হবে, আর বিলের জন্য একই পণ্য একত্র করতে হবে।

প্রতিটি *ওয়াগন* আসলে একটি স্ট্রিং, যেটি বলে দেয় সেটি কী বহন করছে: `"coal"`, `"timber"`, `"crates"` ইত্যাদি।

## 1. ওয়াগন জোড়া লাগিয়ে ট্রেন তৈরি করা

`couple` ডিফাইন করুন: এটি ওয়াগনের একটি অ্যারে আর একটি দৈর্ঘ্য `n` ইনপুট হিসেবে নেবে এবং প্রতিটিতে `n` টি ওয়াগন থাকে এমন ট্রেনের অ্যারে রিটার্ন করবে, যেখানে ট্রেনগুলো পরস্পরকে ওভারল্যাপ করে না। সংখ্যাটি সমানভাগে না ভাগ হলে শেষ ট্রেনটি ছোট হতে পারে।

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. কাপলিংগুলোতে এক নজর

`peek-couplings` ডিফাইন করুন: এটি ওয়াগনের একটি অ্যারে নেবে এবং পরস্পর সংলগ্ন প্রতিটি জোড়া রিটার্ন করবে, যাতে পরিদর্শক প্রতিটি কাপলিং পরীক্ষা করে দেখতে পারেন।

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. জংশনে চেইন ভাগ করা

`split-at-junctions` ডিফাইন করুন: এটি ওয়াগনের একটি অ্যারে আর `junctions` (যে ওয়াগনগুলো বিরতির বিন্দু চিহ্নিত করে) এর একটি অ্যারে নেবে এবং জংশন ওয়াগনগুলোর মধ্যবর্তী অংশগুলো রিটার্ন করবে। জংশন ওয়াগনগুলো নিজে রিটার্ন করা হয় না।

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. একই পণ্য একত্র করা

`coalesce-cargo` ডিফাইন করুন: এটি ওয়াগনের একটি অ্যারে নেবে এবং একই পণ্য বহনকারী *পরপর* ওয়াগনগুলোকে দলে দলে গুছিয়ে নেবে।

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
