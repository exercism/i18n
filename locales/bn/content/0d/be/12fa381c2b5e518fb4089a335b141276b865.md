# পরিচিতি

ফাংশন এক বা একাধিক আর্গুমেন্টের জন্য ডিফল্ট মান ঘোষণা করতে পারে। চলুন এই ফাংশনটি দেখি:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

কম্পাইল করলে Elixir `number/0` (কোনো আর্গুমেন্ট নেই) এবং `number/1` (একটি আর্গুমেন্ট) এর জন্য একটি করে ফাংশন ডেফিনিশন তৈরি করে।

যদি একাধিক আর্গুমেন্টের ডিফল্ট মান থাকে, তাহলে অনুপস্থিত আর্গুমেন্ট পূরণ করতে বাম থেকে ডানে ডিফল্ট মানগুলো ফাংশনে প্রয়োগ করা হয়।

যদি ফাংশনের একাধিক ক্লজ থাকে, তাহলে ফাংশন ক্লজগুলোর আগে একটি ফাংশন হেডারে (বডি ছাড়া ফাংশন) ডিফল্ট আর্গুমেন্ট ডিফাইন করা উচিত:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
