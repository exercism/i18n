# পরিচিতি

## মূল বিষয়গুলো

আমরা ধরে নিচ্ছি আপনি JSON সিনট্যাক্স ও ডেটা টাইপের সাথে পরিচিত।

jq আগত JSON ডেটাকে একটি _একক এক্সপ্রেশন_-এর (যা _ফিল্টারগুলোর একটি পাইপলাইনে_ লেখা) মধ্য দিয়ে পাঠিয়ে কাঙ্ক্ষিত রূপান্তরিত ডেটা তৈরি করে।

<!-- prettier-ignore -->
~~~~exercism/note
`jq` ভাষাটি `jq` _প্রোগ্রাম_ দিয়ে বাস্তবায়িত হয়েছে।
এই প্রোগ্রামটি বেশ কিছু সুবিধাজনক কমান্ড-লাইন অপশন দেয়, যেগুলো দিয়ে ইনপুট কীভাবে পড়া হবে আর আউটপুট কীভাবে দেখানো হবে তা নিয়ন্ত্রণ করা যায়।

নিচের উদাহরণগুলোতে আপনি পাবেন:

- `-n` অথবা `--null-input`

    সাধারণত `jq` প্রোগ্রামকে পড়ার জন্য একটি ফাইল দেওয়া হয়, অথবা আপনি তার ইনপুটে ডেটা পাঠান।
    `--null-input` অপশনটি দিয়ে কোনো ইনপুট ছাড়াই JSON ডেটা তৈরি করা যায়।

- `-c` অথবা `--compact-output`

    `jq` ডিফল্টভাবে তার আউটপুট সুন্দরভাবে সাজিয়ে দেখায়।
    ডেটা সুন্দরভাবে সাজানো থাকলে মানুষ তার দিকে তাকাতে দারুণ সুবিধা পায়।
    কিন্তু মেশিনের জন্য তা দরকার নেই: `--compact-output` অপশনটি ফরম্যাটিংয়ের হোয়াইটস্পেস সরিয়ে দিয়ে ফলাফল JSON-এর আকার কমিয়ে আনে।

- `-f filename` অথবা `--from-file filename`

    কমান্ড লাইনে `jq` প্রোগ্রামটি না দিয়ে বরং `filename` থেকে তা পড়ুন।
    `sed` আর `awk` দুটোই একই উদ্দেশ্যে `-f` অপশন ব্যবহার করে।
    প্র্যাকটিস অনুশীলনীগুলোর টেস্ট স্ক্রিপ্টে এটি ব্যবহৃত হতে দেখবেন।

এই পাঠের বাকি অংশে আমরা `jq` _ভাষা_ নিয়েই আলোচনা করব।
~~~~

### ফিল্টার ও পাইপ

**ফিল্টার**কে **এক্সপ্রেশন**ও বলা হয়।

একটি _ফিল্টার_ একটি ইনপুট নেয় আর একটি আউটপুট তৈরি করে।
ইউনিক্স শেল-এ যেভাবে কাজ করেন, ঠিক সেভাবেই আপনি পাইপ `|` দিয়ে _ফিল্টার_গুলো জুড়ে দিতে পারেন, যাতে এক _ফিল্টারের_ আউটপুট আরেকটির ইনপুটে যুক্ত হয়।

### আইডেন্টিটি ফিল্টার: `.`

এটি সবচেয়ে সহজ _ফিল্টার_।
এটি কেবল তার ইনপুটকে আউটপুটে পাঠিয়ে দেয়।

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### অ্যারে

এটি **অ্যারে** নিয়ে কাজ করার একটি সংক্ষিপ্ত পরিচিতি হবে।
এই বিষয়ে বিস্তারিত আলোচনা পরে করব।

_অ্যারে_-র এলিমেন্ট অ্যাক্সেস করা হয় বন্ধনী দিয়ে, আর ইনডেক্স শুরু হয় শূন্য থেকে।

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

একটি _ফিল্টার_ একটি এক্সপ্রেশনকে `[` আর `]` দিয়ে মুড়ে _অ্যারে_ তৈরি করতে পারে

- এলিমেন্টের একটি জানা তালিকা দিয়ে:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- এলিমেন্টের একটি স্ট্রিম সংগ্রহ করতে: যেমন,
  `range` একটি ফাংশন, যা সংখ্যার একটি স্ট্রিম আউটপুট দেয়

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  `[]` ব্যবহার করলে এক্সপ্রেশনের ফলাফলগুলো একটি অ্যারেতে জমা হয়

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### কমা একটি অপারেটর

_কমা_ কেবল _অ্যারে_-র এলিমেন্ট আলাদা করার সিনট্যাক্স নয়।
**কমা** একটি **অপারেটর**, যা স্ট্রিমগুলো জুড়ে দেয়।

যেমন `[1, 2, 3]` হলো একটি _ফিল্টার_, যা `[]` _অ্যারে_ কনস্ট্রাক্টর দিয়ে `1`, `2` আর `3` এই তিনটি এক্সপ্রেশন জোড়া লাগানোর ফল একত্র করে।

উপরের `range(10; 70; 15)`-এ সেমিকোলনগুলো খেয়াল করেছেন?
`jq` ভাষায় _কমা_-র একটি নির্দিষ্ট কাজ থাকায়, একাধিক আর্গুমেন্ট নেওয়া ফাংশনগুলো আর্গুমেন্ট আলাদা করতে সেমিকোলন ব্যবহার করে।

### অবজেক্ট

**অবজেক্ট** নিয়ে একটি সংক্ষিপ্ত পরিচিতি।

অনেক প্রোগ্রামিং ভাষার মতোই, _অবজেক্ট_-এর প্রপার্টি অ্যাক্সেস করতে ডট ব্যবহার করুন

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
বন্ধনী _অবজেক্ট_-এর জন্যও ব্যবহার করা যায়, তবে তখন স্ট্রিং লিটারালের জন্য কোটেশন লাগবে।
স্পেস থাকা কী (key) নিয়ে কাজ করার এটি একটি উপায়।

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

`{}` আর `key: value` জোড়া দিয়ে আপনি একটি _অবজেক্ট_ তৈরি করতে পারেন।
কী (key) যদি "সহজ" স্ট্রিং হয়, তবে তার চারপাশে কোটেশন লাগে না।

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

এর আউটপুট

```none
{
  "question": 54,
  "answer": 42
}
```

_কী (key)_-কে একটি _এক্সপ্রেশন_ হিসেবে ধরতে হলে, এটিকে প্রথম বন্ধনী দিয়ে মুড়তে হবে (নিচেরটিও উপরের মতোই আউটপুট দেয়)।

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### পাইপলাইন

যেমন, `file.json`-এ আছে

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

চলুন key2 _অ্যারে_-র দৈর্ঘ্য বের করি:

```sh
$ jq '.key2 | length' file.json
3
```

আমরা `.key2` এক্সপ্রেশনের আউটপুটকে `length`-এর ইনপুট হিসেবে _পাইপ_ করছি, আর এটি _অ্যারে_-র এলিমেন্টের সংখ্যা আউটপুট দেয়, তাতে অবাক হওয়ার কিছু নেই।

### ফিল্টার তার ইনপুট উপেক্ষা করতে পারে

এই উদাহরণে ইনপুট JSON ডেটা উপেক্ষিত হয় এবং আউটপুটে কোনো প্রভাব ফেলে না:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### ফিল্টার ডেটার স্ট্রিম আউটপুট দিতে পারে

একটি _ফিল্টার_ একাধিক মান আউটপুট দিতে পারে।
যেমন, `.[]` _ফিল্টার_ একটি _অ্যারে_-র প্রতিটি এলিমেন্টকে আলাদা মান হিসেবে আউটপুট দেয়:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

এমন একটি _ফিল্টার_কে অন্যটিতে পাইপ করলে দ্বিতীয় _ফিল্টার_-টি **_প্রতিটি মানের জন্য_** চালিত হবে:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

এটি অনেকটা অন্তর্নিহিত ইটারেশনের মতো।
এই কৌশলটি একবার বুঝে গেলে দেখবেন, খুব শক্তিশালী `jq` _ফিল্টার_ও বেশ সংক্ষিপ্ত হতে পারে।

### প্রথম বন্ধনী

**প্রথম বন্ধনী** দিয়ে সাব-এক্সপ্রেশনগুলো একসাথে দলবদ্ধ করা হয়, যাতে অপারেশনের ক্রম নিশ্চিত হয়, ঠিক অন্য ভাষাগুলোর মতোই।
`jq`-তে এগুলোর প্রয়োজনীয়তা কিছুটা অপ্রত্যাশিত লাগতে পারে।

যেমন, ধরুন আমরা ২টি এলিমেন্টের একটি _অ্যারে_ বানাতে চাই: ৯-এর বর্গমূল; আর ১ ঘাতে উন্নীত _e_।
দুটি আলাদা এক্সপ্রেশন হলো `9 | sqrt` আর `1 | exp`।
আমরা আশা করব আউটপুট হবে _অ্যারে_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

আমরা যা আশা করেছিলাম তা পাইনি কেন?
`jq` এটাকে এভাবে ব্যাখ্যা করে:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` দুটি এলিমেন্টের (`3` আর `1`) একটি স্ট্রিম তৈরি করে, যেগুলোর প্রত্যেকটিকে `exp`-কে দেওয়া হয়।

আমাদের নিশ্চিত করতে হবে যে `exp` ইনপুট হিসেবে কেবল একটি সংখ্যা নেয়।
অর্থাৎ, কমার আগে পাইপটি মূল্যায়িত হয় তা নিশ্চিত করতে হবে।

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### ফাংশন ও অপারেটর

বেশ গভীরে না গিয়েই (ফাংশন নিয়ে বিস্তারিত আলোচনা আরেকটি অনুশীলনীতে হবে), এখানে কয়েকটি কাজের বিল্ট-ইন ফাংশন দেওয়া হলো:

- `length`

  ইনপুট হিসেবে একটি অ্যারে পেলে, অ্যারেটিতে থাকা এলিমেন্টের সংখ্যা আউটপুট দেয়।

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  এই অপারেটরটি তার অপারেন্ডের টাইপ অনুযায়ী ভিন্ন ভিন্ন কাজ করে:
  সংখ্যা যোগ করে,
  স্ট্রিং জোড়া লাগায়,
  অ্যারে যুক্ত করে,
  অবজেক্ট একত্র করে।

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` একটি ফাংশন, যা একটি অ্যারে নিয়ে `+`-এর নিয়মে সব এলিমেন্ট একসাথে যোগ করে একটি মান রিটার্ন করে।
  `[1, 2, 3] | add` আউটপুট দেয় `6`.

- `map`

  ইনপুট হিসেবে একটি অ্যারে আর আর্গুমেন্ট হিসেবে একটি ফিল্টার পেলে, এমন একটি অ্যারে আউটপুট দেয় যেখানে প্রতিটি এলিমেন্টে ফিল্টারটি প্রয়োগ করা হয়েছে

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  _কিছু_ ইনপুট আর আর্গুমেন্ট হিসেবে একটি ফিল্টার পেলে:
  - আর্গুমেন্টে প্রয়োগ করা ফিল্টারের ফল যদি _ট্রু_ হয়, তবে ইনপুট অপরিবর্তিত আউটপুট দেয়
  - নাহলে _কিছুই_ আউটপুট দেয় না (`null` মানটি নয়, সত্যিই কোনো আউটপুট নয়)

  যেমন, কিছু সংখ্যা দেওয়া থাকলে, ৩ দিয়ে বিভাজ্য সংখ্যাগুলো বেছে নিন

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  মনে রাখবেন, `range` সংখ্যার একটি _স্ট্রিম_ আউটপুট দেয়।
  প্রতিটি সংখ্যার জন্য `select` একবার করে কল করা হবে।
  কেবল যে সংখ্যাগুলো এক্সপ্রেশনটি "পাস" করে সেগুলোই আউটপুটে আসে।

  আপনাকে প্রায়ই একটি অ্যারের এলিমেন্ট বেছে নিতে হয়।
  এটি করার কয়েকটি উপায় আছে।

  `["Anne", "Bob", "Cathy", "Dave"]` ইনপুট দিলে, যে নামগুলোর দৈর্ঘ্য ৪ সেগুলো বেছে নিন।
  - `map` আর `select` একসাথে ব্যবহার করুন

    ```jq
    map(select(length == 4))
    ```

  - অ্যারেটিকে ভেঙে এলিমেন্টে পরিণত করুন, ওই স্ট্রিমে `select` করুন, তারপর ফলাফলগুলো একত্র করুন

    ```jq
    [ .[] | select(length == 4) ]
    ```

### মন্তব্য

মন্তব্য `#` অক্ষর দিয়ে শুরু হয় আর লাইনের শেষ পর্যন্ত চলতে থাকে।
