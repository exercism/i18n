# পরিচিতি

## অ্যারে

C#-এ, যে ডেটা স্ট্রাকচারগুলো শূন্য বা তার বেশি এলিমেন্ট ধারণ করতে পারে, সেগুলোকে _কালেকশন_ বলা হয়। একটি **অ্যারে** হলো এমন একটি কালেকশন, যার সাইজ/দৈর্ঘ্য নির্দিষ্ট এবং যার সব এলিমেন্টকে অবশ্যই একই টাইপের হতে হবে। ইনডেক্স ব্যবহার করে অ্যারেতে এলিমেন্ট অ্যাসাইন করা যায় বা তা থেকে এলিমেন্ট পাওয়া যায়। C# অ্যারে জিরো-বেজড, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

শর্টকাট নোটেশন ব্যবহার করেও অ্যারে ডিফাইন করা যায়, যা দিয়ে একসাথে অ্যারে তৈরি করা ও তার মান সেট করা যায়। এখন কম্পাইলার বলতে পারে অ্যারেতে কতগুলো এলিমেন্ট থাকবে, তাই দৈর্ঘ্য বাদ দেওয়া যায়:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

অ্যারে ইনস্ট্যান্সের মেথড বা প্রপার্টি কল করে, কিংবা `Array` ক্লাসে ডিফাইন করা স্ট্যাটিক মেথড ব্যবহার করে অ্যারে নিয়ে কাজ করা যায়।

## for লুপ

একটি `for` লুপ দিয়ে একটি শর্ত পূরণ হওয়া পর্যন্ত বারবার কোড চালানো যায়।

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

একটি `for` লুপ চারটি অংশে গঠিত:

1. ইনিশিয়ালাইজার: লুপে ঢোকার আগে একবার চালানো হয়। সাধারণত লুপের ভেতরে ব্যবহৃত ভ্যারিয়েবল ডিফাইন করতে ব্যবহার করা হয়।
2. শর্ত: প্রতিটি লুপ ইটারেশনের আগে চালানো হয়। এটি `true` হিসেবে মূল্যায়িত হওয়া পর্যন্ত লুপ চলতে থাকে।
3. ইটারেটর: প্রতিটি লুপ ইটারেশনের পরে চালানো হয়। সাধারণত লুপ ভ্যারিয়েবল পরিবর্তন করতে (প্রায়শই: ইনক্রিমেন্ট/ডিক্রিমেন্ট) ব্যবহার করা হয়।
4. বডি: যে কোডটি প্রতিটি লুপ ইটারেশনে চালানো হয়।

## foreach লুপ

অ্যারে যে একটি _কালেকশন_-ও, তার মানে হলো ইনডেক্স দিয়ে মান পাওয়ার পাশাপাশি একটি `foreach` লুপ ব্যবহার করে তার _সব_ মানের উপর ইটারেট করা যায়:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
