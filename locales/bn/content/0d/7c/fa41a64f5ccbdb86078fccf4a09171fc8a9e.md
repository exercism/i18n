# পরিচিতি

যেকোনো মানই একটি এরর হতে পারে। `throw` (`kernel`-এ) একটি সিগন্যাল পাঠায়; বর্তমান ওয়ার্ডের স্ট্যাক ইফেক্ট বাতিল হয়ে যায় এবং নিয়ন্ত্রণ নিকটতম ঘিরে থাকা `recover`-এর কাছে ফিরে যায়।

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` একটি পার্সিং ওয়ার্ড, যা একবারেই একটি এরর টিউপল ক্লাস *এবং* একটি কনস্ট্রাক্টর ওয়ার্ড ডিফাইন করে:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

এতে প্রতিটি কাস্টম এরর একটি অনন্য ক্লাস, একটি সুবিধাজনক থ্রোয়িং কনস্ট্রাক্টর, আর ধরা পড়া এরর যাচাই করার জন্য একটি ক্লাস প্রেডিকেট (`name?`) পায়:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

ফাইনালি-ধাঁচের পরিচ্ছন্নতার জন্য `continuations`-এর `cleanup` দেখুন। আবার শুরু করা যায় এমন শর্তের জন্য `condition` দেখুন।
