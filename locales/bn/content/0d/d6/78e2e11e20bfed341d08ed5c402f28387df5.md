# নির্দেশনা

মঞ্চ ব্যবস্থাপক রিহার্সাল স্ক্রিপ্টটি টাইপ করাতে চান, আর এর বেশ কয়েকটি অংশ তৈরি হয় কোনো কিছু পুনরাবৃত্তি করে বা জোড়া লাগিয়ে।

চারটি কাজই `REHEARSAL_SCRIPT` ক্লাসে থাকবে।

## 1. একটি কিউ পুনরাবৃত্তি করা

একটি কিউ আর একটি সংখ্যা দেওয়া হলে, সেই কিউটি ততবার রিটার্ন করুন, মাঝে কিছু না রেখে।

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

কোনো কিছু শূন্য বার পুনরাবৃত্তি করলে খালি স্ট্রিং পাওয়া যায়।

## 2. কুশীলবদের নামের আদ্যক্ষর

কুশীলবদের তালিকা দেওয়া হলে, প্রতিটি নামের প্রথম অক্ষর রিটার্ন করুন, একসাথে জোড়া লাগানো অবস্থায়।

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. লাইনগুলোতে নম্বর দেওয়া

একটি দৃশ্যের লাইনগুলো দেওয়া হলে, সেগুলো এক থেকে নম্বর দিন, প্রতিটি নিজের নিজের লাইনে।

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

লাইনগুলোর *মাঝে* একটি নতুন লাইন থাকে, আর শেষ লাইনের পরে কোনোটা থাকে না। যে দৃশ্যে কোনো লাইন নেই, সেটি খালি স্ট্রিং।

## 4. একটি লাইন চিৎকার করা

এমন একটি লাইন রিটার্ন করুন যার প্রতিটি অক্ষর বড় হাতের অক্ষরে বদলে দেওয়া হয়েছে।

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
