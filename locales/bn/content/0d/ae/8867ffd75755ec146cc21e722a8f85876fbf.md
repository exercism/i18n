# নির্দেশনা

নিকোম্যাকাসের (খ্রিস্টাব্দ ৬০ - ১২০) ধনাত্মক পূর্ণসংখ্যার শ্রেণিবিন্যাস পদ্ধতির ভিত্তিতে নির্ধারণ করুন একটি সংখ্যা perfect, abundant নাকি deficient।

গ্রিক গণিতবিদ [নিকোম্যাকাস][nicomachus] ধনাত্মক পূর্ণসংখ্যার জন্য একটি শ্রেণিবিন্যাস পদ্ধতি তৈরি করেছিলেন, যেখানে প্রতিটি সংখ্যাকে তার [অ্যালিকোট সাম][aliquot-sum]-এর ভিত্তিতে **perfect**, **abundant** বা **deficient** শ্রেণিগুলোর ঠিক একটিতে ফেলা হয়।
অ্যালিকোট সাম বলতে সংখ্যাটির নিজেকে বাদ দিয়ে তার গুণনীয়কগুলোর যোগফলকে বোঝায়।
উদাহরণস্বরূপ, ১৫-এর অ্যালিকোট সাম হলো (১ + ৩ + ৫) = ৯

- **Perfect**: অ্যালিকোট সাম = সংখ্যা
  - ৬ একটি perfect সংখ্যা, কারণ (১ + ২ + ৩) = ৬
  - ২৮ একটি perfect সংখ্যা, কারণ (১ + ২ + ৪ + ৭ + ১৪) = ২৮
- **Abundant**: অ্যালিকোট সাম > সংখ্যা
  - ১২ একটি abundant সংখ্যা, কারণ (১ + ২ + ৩ + ৪ + ৬) = ১৬
  - ২৪ একটি abundant সংখ্যা, কারণ (১ + ২ + ৩ + ৪ + ৬ + ৮ + ১২) = ৩৬
- **Deficient**: অ্যালিকোট সাম < সংখ্যা
  - ৮ একটি deficient সংখ্যা, কারণ (১ + ২ + ৪) = ৭
  - মৌলিক সংখ্যাগুলো deficient হয়

একটি প্রদত্ত সংখ্যা **perfect** কি না তা নির্ধারণ করার একটি উপায় ইমপ্লিমেন্ট করুন।
আপনার প্রোগ্রামিং ভাষার ট্র্যাকের উপর নির্ভর করে, একটি প্রদত্ত সংখ্যা **abundant** নাকি **deficient** তাও নির্ধারণ করার একটি উপায় আপনাকে ইমপ্লিমেন্ট করতে হতে পারে।
