# নির্দেশনা

আপনাকে একটি কোম্পানিতে রেগুলার এক্সপ্রেশন স্পেশালিস্ট হিসেবে নিয়োগ দেওয়া হয়েছে, যেখানে একটি চ্যাটবট তৈরি করা হচ্ছে।

এটি এখনও উন্নয়নের একেবারে প্রাথমিক পর্যায়ে আছে, তাই আপনার লক্ষ্য হলো রেগুলার এক্সপ্রেশন ব্যবহার করে প্রাকৃতিক ভাষা বোঝা ও তৈরি করার ক্ষেত্রে চ্যাটবটের দক্ষতা বাড়ানো।

## বৈধ কমান্ড যাচাই করুন

বুদ্ধিমান হওয়ার পাশাপাশি চ্যাটবট একজন বিশ্বস্ত সহকারীও।

চ্যাটবটকে কিছু জিজ্ঞাসা করার জন্য ব্যবহারকারীকে কমান্ডের প্রথমেই “**Chatbot**” শব্দটি বলতে হবে।

কিওয়ার্ডটি বড় হাতের অক্ষরে লেখা হবে নাকি ছোট হাতের অক্ষরে, তা গুরুত্বপূর্ণ নয়। এখানে গুরুত্বপূর্ণ হলো শব্দটির অবস্থান।

`isValidCommand()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা ব্যবহারকারী কখন কমান্ড দিচ্ছেন তা চ্যাটবটকে চিনতে সাহায্য করে।

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## এনক্রিপ্ট করা ইমোজি সরান

মানুষ কীভাবে তাদের অনুভূতি প্রকাশ করতে ইমোজি ব্যবহার করে, তা বুঝতে চ্যাটবটের বেশ অসুবিধা হয়।

চ্যাটবট যখন ব্যবহারকারীর মেসেজ পায়, তখন প্রতিটি ইমোজি “_emoji_” হিসেবে এবং তারপর তার _id_ নম্বর হিসেবে লেখা থাকে।

এমন একটি `removeEmoji()` মেথড ইমপ্লিমেন্ট করুন যা একটি স্ট্রিং নেয় এবং পুরো মেসেজ থেকে ইমোজির সব এনক্রিপশন সরিয়ে দেয়।

যেসব লাইনে ইমোজির লেখা নেই, সেগুলো অপরিবর্তিত অবস্থায় রিটার্ন করতে হবে।

শুধু ইমোজি স্ট্রিংটি সরিয়ে ফেলুন। হোয়াইটস্পেস ঠিক করার চেষ্টা করবেন না।

এই নির্দিষ্ট চ্যালেঞ্জের জন্য রেগুলার এক্সপ্রেশন তৈরি করতে কনস্ট্রাক্টর সিনট্যাক্স ব্যবহার করুন।

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## বৈধ ফোন নম্বর যাচাই করুন

চ্যাটবটের ফিচার মোবাইল অ্যাপে ডাউনলোড করার সুবিধার কথা মাথায় রেখে, কথোপকথনের সময় ব্যবহারকারী একটি ফোন নম্বর লিখবেন বলে ধরে নেওয়া হয়।

সমস্যা হলো, চ্যাটবট শুধু একটি নির্দিষ্ট ফরম্যাটের নম্বরই পড়তে ও যাচাই করতে পারে।

নম্বরটি বৈধ হলে (অর্থাৎ **রেগুলার এক্সপ্রেশন** দ্বারা নির্দিষ্ট করা ক্যারেক্টার সিকোয়েন্সের সাথে মিললে), চ্যাটবট ব্যবহারকারীকে ধন্যবাদ জানিয়ে এবং নম্বরটি নিশ্চিত করে একটি মেসেজ দেয়। আর নম্বরটি অবৈধ হলে ফাংশনটি ব্যবহারকারীকে জানায় যে ফোন নম্বরটি বৈধ নয়।

প্রত্যাশিত ফরম্যাট হলো: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## ওয়েবসাইটের লিংক বের করুন

চ্যাটবট সত্যিই একটি কৌতূহলী সফটওয়্যার। কোনো নির্দিষ্ট বিষয়ে সে ইন্টারনেটে সার্চ করতে পারলেও, প্রাসঙ্গিক তথ্য খুঁজে বের করার জন্য ব্যবহারকারীদের কাছে দারুণ সব ওয়েবসাইট বা URL-এর খোঁজ নিতে ভালোবাসে।

কথোপকথনের উদাহরণ:

- **চ্যাটবট**: হে username, আমি JavaScript-এ কোড করা শিখতে চাই, আপনি কি এমন কোনো দারুণ ওয়েবসাইট জানেন যেখান থেকে আমি শিখতে পারি?
- **ব্যবহারকারী**: আমি [exercism.org](http://exercism.org) থেকে অনেক কিছু শিখেছি।

`getURL()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা শুধু প্রতিটি ওয়েবসাইটের লিংক নিয়ে একটি অ্যারে রিটার্ন করতে পারে। যেকোনো URL চিনতে একটি রেজেক্স লেখা খুবই জটিল হবে, কিন্তু চ্যাটবটের শুধু সাধারণ URL পড়ার দরকার। এই অনুশীলনীর জন্য, URL হলো `"."` দিয়ে আলাদা করা শব্দের যেকোনো ক্রম।

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## ব্যবহারকারীকে শুভেচ্ছা জানান

যারা চ্যাটবটের সাথে কথোপকথন করেছে, তাদের সবার ডেটা সংরক্ষণ করার জন্য চ্যাটবট ব্যবহারকারীর প্রোফাইল থেকে পুরো নামটি এ ধাঁচে পেতে পারে: **“smith, john”**।

এভাবেই আমরা চাই আমাদের চ্যাটবট যেন সত্যিই ভদ্র হয় এবং ভালো ছাপ ফেলে।

`niceToMeetYou()` ফাংশনটি লিখুন, যা ব্যবহারকারীর পুরো নাম নিয়ে একটি স্ট্রিং নেয় এবং **“Nice to meet you, John Smith”** স্ট্রিংটি রিটার্ন করে।

শেখার উদ্দেশ্যে, রেগুলার এক্সপ্রেশনের একটি **রিপ্লেসমেন্ট মেথড** ব্যবহার করে ফাংশনটি ইমপ্লিমেন্ট করুন।

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
