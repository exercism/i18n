# নির্দেশনা

বন্ধুদের জন্য কুকি বেক করার প্রস্তুতি নেওয়ার সময় আপনি দেখলেন যে, রেসিপিতে ব্যবহৃত কিছু মাপ আপনাকে রূপান্তর করতে হবে।
যেহেতু আপনি কেবল মেট্রিক পদ্ধতির সাথে পরিচিত, তাই নিজের সুবিধার জন্য আমেরিকান বেকিংয়ের প্রচলিত মাপগুলোকে মিলিলিটার (mL)-এ রূপান্তর করার একটি উপায় আপনাকে বের করতে হবে।

আপনার সমাধানের জন্য এই রূপান্তর ছকটি ব্যবহার করুন:

| রূপান্তরের একক | ভলিউম | মিলিলিটার (mL)-এ |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| আমেরিকান কাপ          | 1      | 240                 |
| আমেরিকান ফ্লুইড আউন্স  | 1      | 30                  |
| আমেরিকান চা-চামচ      | 1      | 5                   |
| আমেরিকান টেবিল-চামচ   | 1      | 15                  |

প্রশিক্ষণরত একজন প্রতিভাবান প্রোগ্রামার হিসেবে আপনি সিদ্ধান্ত নিলেন যে, তালিকাভুক্ত যেকোনো একক থেকে অন্য যেকোনো এককে (এমনকি একই এককে) রূপান্তর সহজ করতে মিলিলিটারকে একটি মধ্যবর্তী একক হিসেবে ব্যবহার করবেন।

## 1. একটি ভলিউম-জোড়া থেকে সংখ্যাসূচক অংশটি বের করুন

`KitchenCalculator.get_volume` মেথডটি ইমপ্লিমেন্ট করুন।
একটি ভলিউম-জোড়া টিউপল দেওয়া হলে, এটির কেবল সংখ্যাসূচক অংশটি রিটার্ন করা উচিত।

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. ভলিউম-জোড়াটিকে মিলিলিটারে রূপান্তর করুন

`KitchenCalculator.to_milliliter` মেথডটি ইমপ্লিমেন্ট করুন।
একটি ভলিউম-জোড়া টিউপল দেওয়া হলে, রূপান্তর ছক ব্যবহার করে এটির ভলিউমকে মিলিলিটারে রূপান্তর করা উচিত।

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. মিলিলিটার ভলিউম-জোড়াটিকে অন্য এককে রূপান্তর করুন

`KitchenCalculator.from_milliliter` মেথডটি ইমপ্লিমেন্ট করুন।
একটি ভলিউম-জোড়া টিউপল ও কাঙ্ক্ষিত একক দেওয়া হলে, রূপান্তর ছক ব্যবহার করে ভলিউমটিকে কাঙ্ক্ষিত এককে রূপান্তর করা উচিত।

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. যেকোনো একক থেকে যেকোনো এককে রূপান্তর করুন

`KitchenCalculator.convert` মেথডটি ইমপ্লিমেন্ট করুন।
একটি ভলিউম-জোড়া টিউপল ও কাঙ্ক্ষিত একক দেওয়া হলে, প্রদত্ত ভলিউমটিকে কাঙ্ক্ষিত এককে রূপান্তর করা উচিত।

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
