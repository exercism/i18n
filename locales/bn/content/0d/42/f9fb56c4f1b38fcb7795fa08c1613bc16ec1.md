# পরিচিতি

ক্লাস হলো Swift প্রোগ্রামের একটি মৌলিক গঠনউপাদান।
এগুলো আপনাকে সম্পর্কিত প্রপার্টি (ডেটা) ও মেথড (ফাংশন) একসাথে নিয়ে স্বয়ংসম্পূর্ণ কার্যকারিতার একক তৈরি করতে দেয়।

### ক্লাস ডিফাইন করা

একটি ক্লাস ডিফাইন করতে `class` কিওয়ার্ডের পরে ক্লাসের নাম লিখুন, আর ক্লাসের সংজ্ঞাটি রাখুন দ্বিতীয় বন্ধনীর ভেতরে:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

একটি ক্লাসের বডিতে স্টোরড প্রপার্টি থাকতে পারে, যেগুলো সাধারণ কনস্ট্যান্ট (`let`) বা ভ্যারিয়েবলের (`var`) মতো ডিফাইন করা হয় ও আচরণ করে।

### ইনস্ট্যান্স

একটি ক্লাস ডেফিনিশন এক ধরনের ব্লুপ্রিন্ট হিসেবে কাজ করে: এটি একটি নতুন টাইপ ডিফাইন করে এবং তার মানগুলো কেমন দেখতে হয় তা বর্ণনা করে, কিন্তু নিজে থেকে কোনো ইনস্ট্যান্স তৈরি করে না।

একটি ক্লাসের *ইনস্ট্যান্স* তৈরি করতে, ক্লাসের নামের পরে প্রথম বন্ধনী লিখে তার ইনিশিয়ালাইজার কল করুন:

```swift
let someCharacter = GameCharacter()
```

এতে একটি নতুন ইনস্ট্যান্স তৈরি হয়, যার প্রপার্টিগুলো ক্লাস ডেফিনিশনে উল্লেখ করা ডিফল্ট মান দিয়ে ইনিশিয়ালাইজ করা হয়।
স্পষ্ট ডিফল্ট মান নেই এমন অপশনাল প্রপার্টির ক্ষেত্রে (যেমন `name`), Swift সেগুলোকে ডিফল্ট হিসেবে `nil` ধরে নেয়।

### প্রপার্টি অ্যাক্সেস করা

আপনি *ডট নোটেশন* ব্যবহার করে একটি ইনস্ট্যান্সের প্রপার্টি অ্যাক্সেস করেন: ইনস্ট্যান্সের নাম, একটি ডট (`.`), তারপর প্রপার্টির নাম লিখুন।
নেস্টেড প্রপার্টির ক্ষেত্রেও ডট নোটেশন কাজ করে।

ডট নোটেশন দিয়ে আপনি মান পড়তে পারেন এবং প্রপার্টিটি মিউটেবল (`var`) হলে নতুন মান অ্যাসাইন করতে পারেন:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### মেথড

প্রপার্টির পাশাপাশি ক্লাস *মেথড*ও ডিফাইন করতে পারে, অর্থাৎ ক্লাসের সাথে সম্পর্কিত ফাংশন।

স্ট্যান্ডার্ড `func` সিনট্যাক্স ব্যবহার করে ক্লাসের বডির ভেতরে মেথড ডিফাইন করুন।
কোনো মেথড যদি একটি প্রপার্টি পরিবর্তন করে, তবে সেই প্রপার্টি অবশ্যই `var` দিয়ে ডিক্লেয়ার করতে হবে:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

প্রপার্টির মতোই ডট নোটেশন ব্যবহার করে একটি ইনস্ট্যান্সের মেথড কল করুন:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

একটি ক্লাসের প্রতিটি ইনস্ট্যান্সের `self` নামে একটি অন্তর্নিহিত প্রপার্টি থাকে, যা ইনস্ট্যান্সটিকেই বোঝায়।
প্রপার্টি বা মেথড বোঝানোর সময় এটি প্রায়ই বাদ দেওয়া হয়, তবে প্রপার্টির নাম আর মেথডের প্যারামিটারের নাম একই হলে, দুটোর মধ্যে পার্থক্য করতে `self` সাধারণত ব্যবহার করা হয়।
