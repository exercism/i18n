# নির্দেশনা

আপনার কাছের একটি স্থানীয় স্কুলে খুব সক্রিয় একটি শিক্ষার্থী সংগঠন আছে।
শিক্ষার্থী সংগঠনটি একজন সভাপতি পরিচালনা করেন এবং প্রতি ২ বছরে একবার নতুন সভাপতি নির্বাচনের জন্য নির্বাচন অনুষ্ঠিত হয়।

এ বছরের নির্বাচনে সিদ্ধান্ত নেওয়া হয়েছিল যে ভোট গণনার জন্য একটি নতুন ডিজিটাল সিস্টেম প্রয়োজন।
এই নতুন সিস্টেমটি তৈরিতে স্কুলের আপনার সাহায্য দরকার।

## 1. একটি ভোট কাউন্টার তৈরি করুন

নতুন ভোটিং সিস্টেমের প্রথম যে জিনিসগুলো দরকার তার মধ্যে একটি হলো ভোট কাউন্টার।
এই কাউন্টার একটি নির্দিষ্ট প্রার্থীর প্রাপ্ত ভোটের হিসাব রাখার একটি উপায়।

একটি ফাংশন `NewVoteCounter` তৈরি করুন, যা একজন প্রার্থীর প্রাথমিক ভোটের সংখ্যা গ্রহণ করে এবং প্রদত্ত প্রাথমিক ভোটের সংখ্যা দিয়ে আরম্ভ করা একটি `int`-কে নির্দেশকারী পয়েন্টার রিটার্ন করে।

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. একটি কাউন্টার থেকে ভোটের সংখ্যা পাওয়া

এখন আপনার কাছে নতুন কাউন্টার তৈরির একটি উপায় আছে! কিন্তু এখন আপনি বুঝতে পারছেন যে নতুন সিস্টেমের একটি কাউন্টার থেকে ভোটের সংখ্যা পাওয়ার একটি উপায়ও দরকার হবে।

একটি ফাংশন `VoteCount` তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি কাউন্টার (`*int`) নেবে এবং কাউন্টারে থাকা ভোটের সংখ্যা রিটার্ন করবে।
যদি কাউন্টারটি `nil` হয়, তাহলে ধরে নেবেন কাউন্টারে কোনো ভোট নেই:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. একটি কাউন্টারের ভোট বাড়ান

অবশেষে ভোট গণনার সময় এসেছে! এখন আপনার একটি কাউন্টারের ভোট বাড়ানোর একটি উপায় দরকার।

একটি ফাংশন `IncrementVoteCount` তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি কাউন্টার (`*int`) এবং কতগুলো ভোট নেবে, এবং সেই সংখ্যক ভোট দিয়ে কাউন্টারটি বাড়াবে।
আপনি ধরে নিতে পারেন যে পাস করা পয়েন্টারটি কখনোই `nil` হবে না।

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. নির্বাচন ফলাফল তৈরি করুন

সব ভোট এখন গণনা হয়ে গেছে, এখন পুরো স্কুলের জন্য ফলাফল ঘোষণার প্রস্তুতি নেওয়ার সময়।
এর জন্য আপনি লক্ষ্য করলেন যে শুধু ভোটের কাউন্টার থাকাই যথেষ্ট নয়।
ভোটের সংখ্যাকে একটি নির্দিষ্ট প্রার্থীর সাথে যুক্ত করার একটি উপায় থাকা দরকার।

একটি ফাংশন `NewElectionResult` তৈরি করুন, যা একজন প্রার্থীর নাম এবং তাঁর ভোটের সংখ্যা গ্রহণ করে এবং একটি নতুন নির্বাচন ফলাফল রিটার্ন করে।

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

নির্বাচন ফলাফলের স্ট্রাক্টটি ইতিমধ্যেই আপনার জন্য তৈরি করা হয়েছে এবং এটি এভাবে সংজ্ঞায়িত:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. ফলাফল ঘোষণা করুন

স্কুলকে নতুন সভাপতি ঘোষণার সময় এসেছে!
স্কুলের ছোট ডিজিটাল মেসেজ বোর্ডগুলোতে সভাপতির নাম ঘোষণা করা হবে।
বার্তাটিতে নতুন সভাপতির নাম এবং তাঁর প্রাপ্ত ভোট নিচের ফরম্যাটে দেখানো উচিত: `<candidate_name> (<votes>)`।
এমন একটি বার্তার উদাহরণ: `"Peter (51)"`।

একটি ফাংশন `DisplayResult` তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি `*ElectionResult` গ্রহণ করবে এবং প্রদর্শনের জন্য বার্তাসহ একটি স্ট্রিং রিটার্ন করবে।

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. ভোট পুনর্গণনা

চূড়ান্ত ফলাফল সঠিক ছিল কিনা নিশ্চিত করার জন্য ভোট আবার গণনা করা হয়েছিল।
পুনর্গণনায় দেখা গেল যে কিছু প্রার্থীর ভোটের সংখ্যা এক কমবেশি ছিল।

একটি ফাংশন `DecrementVotesOfCandidate` তৈরি করুন, যা চূড়ান্ত ফলাফল এবং এমন একজন প্রার্থীর নাম গ্রহণ করে যাঁর ভোটের সংখ্যা আপনি কমাবেন।
চূড়ান্ত ফলাফল `map[string]int` আকারে দেওয়া হয়, যেখানে কী (key) হলো প্রার্থীদের নাম এবং মান হলো তাঁর মোট ভোট।

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
