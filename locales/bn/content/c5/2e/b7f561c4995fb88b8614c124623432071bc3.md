# নির্দেশাবলি

এই অনুশীলনীতে আপনি আধা-স্ট্রাকচার্ড লগ বার্তা তৈরি করবেন।

## আধা-স্ট্রাকচার্ড বার্তা তৈরি করুন

আপনি কিছু স্টাব করা ফাংশন আর নিচের enum দিয়ে শুরু করবেন:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

আপনার লক্ষ্য হলো এভাবে একটি লগ বার্তা তৈরি করা: `"[<LEVEL>]: <MESSAGE>"`।
আপনাকে এমন ফাংশন ইমপ্লিমেন্ট করতে হবে যেগুলো লগ লেভেলের সাথে মেলে।

উদাহরণস্বরূপ, নিচের স্নিপেটটি `log` ফাংশনের একটি প্রত্যাশিত আউটপুট দেখায়।

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

আর `info` ফাংশনের ক্ষেত্রে:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

শুভকামনা!
