# নির্দেশাবলির সংযোজন

## এক্সসেপশন বার্তা

কখনও কখনও [এক্সসেপশন রেইজ করা][raise-an-exception] প্রয়োজন হয়। এটি করার সময় আপনার সর্বদা একটি **অর্থপূর্ণ এরর বার্তা** যোগ করা উচিত, যাতে বোঝা যায় এররটির উৎস কী। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিংয়ে অনেকটাই সাহায্য করে। যে পরিস্থিতিতে আপনি জানেন এররটির উৎস নির্দিষ্ট একটি টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপগুলোর][built-in-errors] একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থপূর্ণ বার্তা যোগ করা উচিত।

এই অনুশীলনীতে নির্দিষ্টভাবে প্রয়োজন, আপনি [`raise` স্টেটমেন্ট][raise-statement] ব্যবহার করে `ValueError` "থ্রো" করবেন, যদি `answer()`-এ পাস করা প্রশ্নটি ভুল গঠনের/অবৈধ হয়, অথবা এতে কোনো অজানা অপারেশন থাকে। টেস্টগুলো তখনই পাস করবে, যদি আপনি `exception`-টি `raise` করেন এবং তার সাথে একটি বার্তাও যোগ করেন।
**লক্ষ্য করুন**: প্রতিটি পরিস্থিতিতে প্রয়োজনীয় বার্তা আলাদা, যদিও একই _এরর টাইপ_ রেইজ করা হচ্ছে।
টেস্টগুলো ভালোভাবে খেয়াল করুন।

বার্তাসহ একটি [`ValueError`][value-error] রেইজ করতে, বার্তাটি `exception` টাইপে একটি আর্গুমেন্ট হিসেবে লিখুন:


```python
# if the question contains an unknown operation.
raise ValueError("unknown operation")

# if the question is malformed or invalid.
raise ValueError("syntax error")
```

কোনো নির্দিষ্ট কোড ব্লকের ভেতরে রেইজ হওয়া একটি এরর _হ্যান্ডল_ করতে [try-except][handling-exceptions] ব্যবহার করা যায়।
`try-except` ব্লকগুলো সম্ভাব্য এরর সৃষ্টি করতে পারে এমন কোড "র্যাপ" করে, এবং সব এক্সসেপশনকে একটি এরর, একাধিক এরর, বা সমস্যা সামলানোর অন্য কোডে ম্যাপ করে:


```python
while len(equation) > 1:
        try:
           # The questionable/error-prone code goes here,in an indented block
           # It can contain statements, loops, if-else blocks, or other executable code.
           x_value, operation, y_value, *rest = equation
           ...
           ...

        except:
            # Code for what to do when an error gets thrown in the code above.
            # This could be one error, or more complicated logging, error checking and messaging.
            raise ValueError("syntax error")
```
