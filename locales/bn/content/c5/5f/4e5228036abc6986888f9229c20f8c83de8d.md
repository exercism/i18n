# পরিচিতি

Common Lisp-এ সমতা যাচাইয়ের অনেকগুলো ভিন্ন প্রেডিকেট আছে।
এটি অন্য প্রোগ্রামিং ভাষাগুলোর থেকে আলাদা, যেখানে হয়তো মাত্র একটি বা দুটি থাকে (যেমন `==` আর `===`)।
Common Lisp-এ এই প্রেডিকেটগুলোর কিছু কেবল নির্দিষ্ট ডেটা টাইপের জন্য, আর বাকিগুলো জেনেরিক।
এখানে আলোচনা করা হবে এই শেষেরগুলো নিয়েই।

জেনেরিক সমতা যাচাইয়ের প্রেডিকেট চারটি, আর কোনটাকে "সমান" ধরবে সেই কড়াকড়িতে এরা একে অপরের থেকে আলাদা।
সবচেয়ে কড়া থেকে সবচেয়ে শিথিল, এই ক্রমে সেগুলো হলো: `eq`, `eql`, `equal` আর `equalp`।

সংক্ষেপে কয়েকটি সংজ্ঞা (কিছু খুঁটিনাটি বাদ দিয়ে) এরকম:

- `eq`: সমতা মানে এখানে দুটি অবজেক্ট একেবারে অভিন্ন।
  যেমন:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: সমতা মানে এখানে একই টাইপ ও মানের দুটি সংখ্যা, একই দুটি ক্যারেক্টার,
  অথবা অন্য যেকোনো কিছুর ক্ষেত্রে সেগুলো `eq` হলে সেগুলো সমান।
  যেমন:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: সমতা মানে এখানে: দুটি লিস্ট `equal` হয় যদি প্রতিটি এলিমেন্টও `equal` হয়; দুটি স্ট্রিং `equal` হয় যদি প্রতিটি এলিমেন্ট `eql` হয়; দুটি অ্যারে `equal` হয় যদি সেগুলো `eq` হয়; আর বাকি সবকিছু `equal` হয় যদি সেগুলো `eql` হয়।
  যেমন:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: সমতা মানে এখানে: স্ট্রিং ও ক্যারেক্টার তুলনা করা হয় বড়-ছোট হাতের অক্ষরের পার্থক্য না ধরে; সংখ্যা তুলনা করা হয় কিছুটা টাইপ কনভার্সনসহ; লিস্ট ও অ্যারে `equalp` হয় যদি প্রতিটি এলিমেন্টও `equalp` হয়, স্ট্রাকচার হয় যদি সেগুলো একই টাইপের হয় এবং সব স্লট `equalp` হয়, আর হ্যাশ-টেবিল হয় যদি তার কী (key) ও মানগুলো `equalp` হয়
  যেমন:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
