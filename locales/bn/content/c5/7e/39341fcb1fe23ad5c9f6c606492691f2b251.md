# ভূমিকা

PHP-তে `for` লুপ হলো সবচেয়ে জটিল ধরনের লুপ। এগুলো `C`, `Java` এবং `JavaScript`-এর `for` লুপের মতো আচরণ করে। এর মূল রূপটি হলো:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

প্রথম এক্সপ্রেশনটি (_expr1_) লুপ শুরু হওয়ার আগে মূল্যায়ন করা হয়। দ্বিতীয় এক্সপ্রেশনটি (_expr2_) প্রতিটি ইটারেশনের আগে মূল্যায়ন করা হয়; এটি যদি _ট্রুথি_ কোনো মান দেয়, তাহলে স্টেটমেন্টগুলো চালানো হয়। স্টেটমেন্টগুলো চালানোর পর তৃতীয় এক্সপ্রেশনটি (_expr3_) মূল্যায়ন করা হয়।
