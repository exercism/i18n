# সম্পর্কে

Haxe-এ একটি **অ্যারে** হলো সাধারণত একই টাইপের এলিমেন্টের একটি সংগ্রহ। Haxe-এ অ্যারে তৈরির তিনটি উপায় আছে; হয় কনস্ট্রাক্টর দিয়ে, নয়তো ডিক্লারেশন সিনট্যাক্স দিয়ে। Haxe-এ অ্যারের প্রথম এলিমেন্টের ইনডেক্স শূন্য:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

কনস্ট্রাক্টর দিয়ে অ্যারে তৈরি করতে হলে, অ্যারেতে যেসব এলিমেন্ট থাকবে সেগুলোর টাইপ পাস করতে হবে:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Haxe-এ অ্যারে অ্যাক্সেস আনবাউন্ডেড, অর্থাৎ এটি কোনো এক্সেপশন থ্রো করবে না, এটা নিশ্চিত। তাই এ নিয়ে আরও আলোচনা দরকার:

- কোনও অস্তিত্বহীন ইনডেক্সে রিড অ্যাক্সেস করা হলে, টার্গেট-নির্ভর একটি মান রিটার্ন হয়।
- সীমার বাইরের কোনও ধনাত্মক ইনডেক্সে রাইট অ্যাক্সেস করা হলে, শেষ ডিফাইন করা ইনডেক্স আর নতুন লেখা ইনডেক্সের মধ্যবর্তী সব অবস্থানে `null` (বা স্ট্যাটিক টার্গেটে বেসিক টাইপগুলোর ডিফল্ট মান) বসানো হয়।
- ঋণাত্মক ইনডেক্সে রাইট অ্যাক্সেস করা হলে ফলাফল অনির্দিষ্ট।

আমরা যদি চাই একটি অ্যারেতে একাধিক টাইপের এলিমেন্ট থাকুক, তাহলে টাইপ ইন্ডিকেটরে `Dynamic` টাইপ যোগ করি:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## ইটারেশন

`for` লুপ ব্যবহার করে অ্যারে ইটারেট করা যায়:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
