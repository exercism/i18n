# পরিচিতি

## টাইপ কনভার্সন (ডেটা টাইপ রূপান্তর)

Go-তে ভিন্ন ভিন্ন টাইপের মধ্যে রূপান্তর সবসময় স্পষ্টভাবে লিখতে হয়।
টাইপের মধ্যে রূপান্তর (যা **টাইপ কাস্টিং** নামেও পরিচিত) করা হয় কোন টাইপে রূপান্তর করতে চান, সেই টাইপের নামে একটি ফাংশন দিয়ে।
যেমন, একটি `int`-কে `float64`-তে রূপান্তর করতে হলে আপনাকে নিচের কাজটি করতে হবে:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## প্রিমিটিভ টাইপ ও স্ট্রিং-এর মধ্যে রূপান্তর

প্রিমিটিভ টাইপ (যেমন `int`) আর `string`-এর মধ্যে রূপান্তরের জন্য একটি `strconv` প্যাকেজ আছে।

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## টাইপ অ্যাসারশন

Go-তে ইন্টারফেস ব্যবহার করলে অন্তর্নিহিত টাইপ নিয়ে অস্পষ্টতা তৈরি হতে পারে।
টাইপ অ্যাসারশনের সাহায্যে আমরা এই সিনট্যাক্স ব্যবহার করে ইন্টারফেস ভ্যালুর অন্তর্নিহিত কংক্রিট মান বের করতে পারি: `interfaceVariable.(concreteType)`।

যেমন:

```go
var input any = 12
number := input.(int)
```

লক্ষ্য করুন: ইন্টারফেস ভ্যারিয়েবলে যদি কংক্রিট টাইপের কোনো মান না থাকে, তাহলে এটি একটি প্যানিক তৈরি করবে।

টাইপ অ্যাসারশনের দুইটি রিটার্ন ভ্যালু কাজে লাগিয়ে আমরা পরীক্ষা করতে পারি একটি ইন্টারফেস ভ্যালুতে নির্দিষ্ট কোনো কংক্রিট টাইপ আছে কি না: অন্তর্নিহিত মান, আর একটি বুলিয়ান মান যা জানায় অ্যাসারশনটি সফল হয়েছে কি না।
যেমন:

```go
str, ok := input.(string) // no panic if input is not a string
```

যদি `input`-এ একটি `string` থাকে, তাহলে `str` হবে অন্তর্নিহিত মান এবং `ok` হবে ট্রু।
যদি `input`-এ `string` না থাকে, তাহলে `str` হবে `string` টাইপের জিরো মান (অর্থাৎ `""`, খালি স্ট্রিং) এবং `ok` হবে ফলস।
যেকোনো ক্ষেত্রেই কোনো প্যানিক হয় না।

## টাইপ সুইচ

একটি **টাইপ সুইচ** পরপর কয়েকটি টাইপ অ্যাসারশন করতে পারে।
এর সিনট্যাক্স টাইপ অ্যাসারশনের মতোই (`interfaceVariable.(concreteType)`), তবে `concreteType`-এর জায়গায় বসে `type` কিওয়ার্ডটি।
নিচে একটি উদাহরণ দেওয়া হলো:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
