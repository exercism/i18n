# নির্দেশনা

একটি কারখানায় কাজ করার সময় কর্মীদের ব্যাজে যে বার্তা ছাপা হবে, তা তৈরি করার প্রয়োজন দেখা দেয়। আপনি এই ফাংশনটি JavaScript-এ ইমপ্লিমেন্ট করার সিদ্ধান্ত নেন।

একটি ব্যাজের জন্য কর্মীর `id`, কর্মীর `name` এবং তিনি যে বিভাগে কাজ করেন সেই বিভাগের নাম প্রয়োজন।

## 1. ব্যাজের বার্তা তৈরি করুন

`printBadge` নামের একটি ফাংশন ইমপ্লিমেন্ট করুন, যা ব্যাজে ছাপার জন্য বার্তাটি রিটার্ন করে।

কর্মীর নাম সব সময়ই দেওয়া থাকে, কিন্তু কর্মীর `id` নম্বর এবং বিভাগের নাম `null` হতে পারে। কর্মীর `id` নম্বর দেওয়া থাকলে তা তৃতীয় বন্ধনীর (`[]`) মধ্যে থাকবে (যেমন `[20]`)।

মালিকের ব্যাজে কোনো `id` বা `department` থাকবে না।

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
