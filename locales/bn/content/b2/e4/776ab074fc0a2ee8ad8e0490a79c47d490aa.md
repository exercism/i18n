# পরিচিতি

_টার্নারি অপারেটর_ হলো সাধারণ _if/else_ স্টেটমেন্টের জন্য একটি হালকা ও সংক্ষিপ্ত বিকল্প। সাধারণত রিটার্ন স্টেটমেন্টে এটি ব্যবহৃত হয় (তবে কেবল সেখানেই নয়), আর সিদ্ধান্ত নিতে এর লাগে মাত্র একটি লাইন: এক্সপ্রেশনটি `true` হলে এটি বাম দিকের মানটি রিটার্ন করে, আর `false` হলে ডান দিকের মানটি, যেমনটি নিচে দেখানো হয়েছে:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

অনেক সাধারণ _if/else_ এক্সপ্রেশনই _টার্নারি অপারেটর_ দিয়ে সহজ করে লেখা যায়।
