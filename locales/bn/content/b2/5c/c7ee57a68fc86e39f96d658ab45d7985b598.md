# টেস্ট

সব অনুশীলনীতেই মকিং ও টেস্টিংয়ের জন্য [Pester][pester] ফ্রেমওয়ার্ক ব্যবহার করা হয়।
Pester ফ্রেমওয়ার্কের নিয়ম অনুযায়ী সব টেস্ট `[Exercise].tests.ps1` নামের একটি ফাইলে থাকবে।
আপনি যদি সঠিক ডিরেক্টরিতে থাকেন (অর্থাৎ যেটিতে `[Exercise].ps1` ও `[Exercise].tests.ps1` আছে), তাহলে PowerShell থেকে এভাবে টেস্ট রান করতে পারেন:

``` PowerShell
Invoke-Pester
```

এটি ডিরেক্টরিতে খুঁজে পাওয়া সব `.tests.ps1` ফাইল রান করবে।

PowerShell ছাড়া অন্য কোনো শেল ব্যবহার করলে, টেস্ট রান করতে পারেন এভাবে:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Visual Studio Code-এ টেস্ট রান করা

Visual Studio Code-এ [PowerShell এক্সটেনশন][extension] ইনস্টল করা আছে কি না, তা নিশ্চিত করতে হবে।

Visual Studio Code-এ কয়েকটি উপায়ে টেস্ট রান করতে পারেন:

- Debug মেনু থেকে `.Tests.ps1` স্ক্রিপ্ট রান করা। কীবোর্ড শর্টকাট: `F5` অথবা `Shift + F5`
- এডিটরের ভেতরেই টেস্ট কোডের `Describe` কিওয়ার্ডের উপরে থাকা "Run Tests" লিংকে ক্লিক করা
- Pester ফ্রেমওয়ার্ক রান করার জন্য একটি Task কনফিগার করা

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
