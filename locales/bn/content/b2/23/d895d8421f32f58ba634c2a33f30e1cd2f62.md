# নির্দেশনার পরিশিষ্ট

গ্রিডের প্রতিটি সারি একটি ওয়ার্ড দিয়ে প্রকাশ করা হয়।

উদাহরণস্বরূপ,

```
    0 1 0
    1 0 0
    1 1 0
```

এভাবে প্রকাশ করা হয়:

```
0x2
0x4
0x6
```

গ্রিডে সর্বোচ্চ ৩২টি কলাম থাকে।

## রেজিস্টার

| রেজিস্টার | ব্যবহার        | টাইপ    | বিবরণ                 |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | সারির সংখ্যা              |
| `$a1`    | ইনপুট        | ইন্টিজার | কলামের সংখ্যা           |
| `$a2`    | ইনপুট        | অ্যাড্রেস | বর্তমান জেনারেশনের গ্রিড |
| `$a3`    | ইনপুট/আউটপুট | অ্যাড্রেস | পরবর্তী জেনারেশনের গ্রিড    |
| `$t0-9`  | টেম্পোরারি    | যেকোনো     | সাময়িক স্টোরেজের জন্য ব্যবহৃত হয়  |
