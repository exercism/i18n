# পরিচিতি

Pairs and Dicts কনসেপ্টে Julia-র ডিকশনারি টাইপের মূল বিষয়গুলো নিয়ে আলোচনা করা হয়েছে।

`Dict` যেহেতু একটি গুরুত্বপূর্ণ ও বহুল ব্যবহৃত কালেকশন টাইপ, তাই এগুলো নিয়ে কাজ করার জন্য অনেক ফাংশনও রয়েছে।

## এন্ট্রি নেওয়া

কোনো এন্ট্রি বের করার সবচেয়ে সহজ উপায় হলো কী (key) দিয়ে খোঁজা (যেমনটা অনেক ভাষাতেই হয়)। তবে যে কী (key) নেই, সেটি চাইলে `KeyError` হয়।

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

এন্ট্রি বের করার আগে আমরা যাচাই করে নিতে পারি যে কী (key)-টি আছে কি না (`haskey(d, 4)` জাতীয় কিছু দিয়ে), তবে অনুপস্থিত কী (key)-গুলোর জন্য সরাসরি একটি ডিফল্ট মান পেয়ে যাওয়াটাও কাজে লাগতে পারে।

এর জন্যই আছে `get()` ফাংশন আর তার পরিবর্তনশীল রূপ `get!()`। এদের মধ্যে পার্থক্য হলো, একটি "অনুপস্থিত" কী (key) `Dict`-এ যোগ হয় কি না।

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

আগের কনসেপ্টে আমরা দেখেছি, `delete!()` কী (key) দিয়ে কোনো এন্ট্রি মুছে ফেলে। মানটি একসাথে বের করে আনার কাজে `pop!()` ফাংশনটি এর সঙ্গে মিলিয়ে ব্যবহার করা যায়।

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## ইটারেশন

একটি `Dict`-এর উপর ইটারেশন করলে ডিফল্টভাবে `key => value` জোড়া পাওয়া যায়। এই অংশগুলো স্বাভাবিক `.first` ও `.second` নাম দিয়ে পাওয়া যায়।

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

অনেক সময় আমরা শুধু কী (key)-গুলো বা শুধু ভ্যালুগুলো ব্যবহার করতে চাই, যা করা সহজ।

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## মার্জ করা

দুটি `Dict` একসাথে করা কাজে লাগতে পারে, তবে একাধিক ইনপুটে থাকা কী (key)-গুলোর ক্ষেত্রে আমরা কী করতে চাই সেটি স্পষ্ট থাকা দরকার।

`merge()` ও `merge!()` ফাংশন যত খুশি সংখ্যক `Dict` দিলেও সেগুলোকে বাম থেকে ডানে ক্রমানুসারে একসাথে করে।

আগে থেকে থাকা কী (key)-গুলোর মান কেবল ওভাররাইট হয়ে যায়, তাই সবচেয়ে ডানের `Dict`-টাই "জিতে যায়"।

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()` ও `mergewith!()` ফাংশনে প্রথম আর্গুমেন্ট হিসেবে একটি ফাংশন দিতে পারি, যেটি ঠিক করে দেয় একই কী (key) বারবার এলে সেগুলো কীভাবে মার্জ হবে। যোগ করা এর একটি সহজ উদাহরণ।

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

লক্ষ করুন, `mergewith` ফাংশনগুলো হায়ার অর্ডার ফাংশন কাজে লাগানোর একটি ভালো উদাহরণ।
