# নির্দেশনার সংযোজন

## আউটপুট ফরম্যাট

কমা ও স্পেস বিভাজক হিসেবে ব্যবহার করে শিক্ষার্থীর গাছগুলো একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে আউটপুট করুন।

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | বাগানের ডায়াগ্রাম             |
| `$a1`    | ইনপুট        | অ্যাড্রেস | শিক্ষার্থীর নাম                |
| `$a2`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং  |
| `$t0-9`  | টেম্পোরারি    | যেকোনো   | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত |
