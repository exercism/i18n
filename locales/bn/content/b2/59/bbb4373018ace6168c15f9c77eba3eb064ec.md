# পরিচিতি

## let assert অ্যাসারশন

Gleam-এ একটি মানের উপর প্যাটার্ন ম্যাচিং করার সময় আমাদের নিশ্চিত করতে হয় যে প্যাটার্নগুলো টাইপের প্রতিটি সম্ভাব্য মানের সাথে মেলে, অন্যথায় কোড কম্পাইল হবে না।

অ্যারেটি খালি থাকার ক্ষেত্রটি হ্যান্ডেল করেনি বলে এই ফাংশনটি প্রত্যাখ্যান করা উচিত:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

Gleam প্রোগ্রামে বেশিরভাগ সময়ে আমরা প্রতিটি সম্ভাব্য ক্ষেত্র হ্যান্ডেল করতে চাই, কিন্তু প্রোটোটাইপ বা দ্রুত লেখা স্ক্রিপ্টের মতো কিছু প্রোগ্রামে আমরা হয়তো শুধু হ্যাপি পাথের দিকেই মন দিতে চাইব এবং বাকি ক্ষেত্রগুলোর জন্য কোড লিখতে চাইব না। এখানেই Gleam-এর `let assert` কাজে আসে।

let assert দিয়ে একটি প্যাটার্ন টাইপের কেবল কিছু সম্ভাব্য মানের সাথে মিলতে পারে, আর প্যাটার্নটি কোনো মানের সাথে না মিললে প্রোগ্রামটি ক্র্যাশ করবে। `let assert` ব্যবহার করে উপরের ফাংশনটি এভাবে লেখা যায়:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleam লাইব্রেরিতে কখনোই let assert ব্যবহার করা উচিত নয়, কারণ এতে প্রোগ্রাম ক্র্যাশ করতে পারে। এর বদলে `Result` টাইপ ব্যবহার করা উচিত, আর এররগুলো কীভাবে হ্যান্ডেল হবে তা অ্যাপ্লিকেশন ডেভেলপারের উপর ছেড়ে দেওয়া উচিত।
