# নির্দেশাবলি

এই অনুশীলনীতে আপনাকে ফোন নম্বর বিশ্লেষণ করতে হবে।

আপনাকে দুটি ফিচার ইমপ্লিমেন্ট করতে বলা হয়েছে।

রুটিনগুলোতে যে ফোন নম্বরগুলো পাঠানো হয় সেগুলো NNN-NNN-NNNN ফরম্যাটে থাকবে, যেমন 212-515-9876, এবং সেগুলো null নয়, এটা নিশ্চিত।

## 1. একটি ফোন নম্বর বিশ্লেষণ করুন

আপনার বিশ্লেষণে তিনটি তথ্য রিটার্ন করা উচিত

1. নম্বরটির প্রথম ৩টি ডিজিট হিসেবে নিউ ইয়র্কের ডায়ালিং কোড, অর্থাৎ 212 আছে কি না, তার একটি ইঙ্গিত
2. ৫ থেকে ৭ নম্বর পজিশনে (গণনা ১ থেকে শুরু) প্রিফিক্স কোড হিসেবে 555 থাকায় নম্বরটি ফেক কি না, তার একটি ইঙ্গিত
3. নম্বরটির শেষ ৪টি ডিজিট।

ফোন নম্বরের তথ্য তৈরি করতে (স্ট্যাটিক) মেথড `PhoneNumber.Analyze()` ইমপ্লিমেন্ট করুন।

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. একটি ফোন নম্বরে ফেক প্রিফিক্স কোড (555) আছে কি না শনাক্ত করুন

১ নম্বর টাস্কে তৈরি করা ফোন নম্বরের তথ্য ব্যবহার করে ফোন নম্বরটি ফেক কি না শনাক্ত করতে (স্ট্যাটিক) মেথড `PhoneNumber.IsFake()` ইমপ্লিমেন্ট করুন।

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
