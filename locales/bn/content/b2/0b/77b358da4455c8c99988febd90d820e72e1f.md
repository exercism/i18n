# সম্পর্কে

Java-তে একটি মানের অনুপস্থিতি বোঝাতে [`null` লিটারেল][null-keyword] ব্যবহার করা হয়।

Java-র [প্রিমিটিভ ডেটা টাইপগুলো][primitive-data-types]-এর প্রত্যেকটিরই একটি ডিফল্ট মান থাকে, তাই এরা কখনোই `null` হতে পারে না।
প্রথা অনুযায়ী এগুলো ছোট হাতের অক্ষর দিয়ে শুরু হয়, যেমন `int`।

[রেফারেন্স টাইপগুলো][reference-data-types] একটি অবজেক্টের মেমোরি অ্যাড্রেস ধারণ করে এবং এদের মান `null` হতে পারে।
এগুলো সাধারণত বড় হাতের অক্ষর দিয়ে শুরু হয়, যেমন `String`।

একটি প্রিমিটিভ ভ্যারিয়েবলে `null` মান অ্যাসাইন করার চেষ্টা করলে কম্পাইল টাইম এরর হয়, কারণ ভ্যারিয়েবলটি সবসময় অ্যাসাইন করা টাইপের একটি ডিফল্ট মান ধারণ করে।

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

কোনো রেফারেন্স ভ্যারিয়েবলে `null` মান অ্যাসাইন করলে কম্পাইল টাইম এরর হয় না, কারণ রেফারেন্স ভ্যারিয়েবলগুলো নালেবল।

```java
//No error will occur as the String variable str is nullable
String str = null;
```

যে রেফারেন্স ভ্যারিয়েবলের মান `null`, সেটি অ্যাক্সেস করলে কম্পাইল ঠিকঠাকই হবে, কিন্তু রানটাইমে `NullPointerException` থ্রো হবে।

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

এমন কোনো রেফারেন্স ভ্যারিয়েবল অ্যাক্সেস করার চেষ্টা করলে, যার মান `null` অথচ সেখানে একটি অবজেক্ট দরকার, [`NullPointerException` থ্রো হয়][null-pointer-exception]।

নালেবল মান নিয়ে নিরাপদে কাজ করতে হলে, সেগুলো নিয়ে কাজ করার আগে সেগুলো `null` কি না তা যাচাই করা উচিত। এটি করা যায় `==` বা `!=`-এর মতো [ইকুয়ালিটি অপারেটর][equality-operators] দিয়ে:

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
