# নির্দেশাবলি


আপনি একটি হোটেল রেস্টুরেন্টের মেট্রে ডি।
আপনার কাজ হলো আজ ডাইনিং রুমে কতগুলো আসন খালি আছে, কতগুলো রিজার্ভেশন আছে আর কতজন "ওয়াক-ইন" অতিথি এখন বসার অপেক্ষায় আছেন, সেই অনুযায়ী ডাইনিং রুমের আসন ব্যবস্থাপনা সামলানো।
এই অনুশীলনীর উদ্দেশ্যে, আসন বরাদ্দ হয় প্রথমে পাওয়া খালি আসন অনুযায়ী।


এই অনুশীলনীতে ডাইনিং রুম গোছানোর ৬টি আলাদা চ্যালেঞ্জ আপনাকে সম্পূর্ণ করতে হবে।


## 1. আজকের সিটিং চার্ট তৈরি করুন

`new_seating_chart(<size=22>)` ফাংশনটি ডিফাইন করুন, যা একটি size আর্গুমেন্ট নেয় এবং বোঝায় আজ ডাইনিং রুমে কতগুলো আসন রাখা হবে।
যদি `size` না দেওয়া হয়, ফাংশনটি ২২টি আসনের একটি সিটিং চার্ট রিটার্ন করবে।
আসনের মানগুলোর জন্য `None` প্লেসহোল্ডার থাকবে, যা বোঝায় আসনগুলো কোনো অতিথিকে বরাদ্দ করার জন্য খালি আছে।


## 2. রিজার্ভেশন সাজান

`arrange_reservations(<guest_names>)` ফাংশনটি ডিফাইন করুন, যার ১টি প্যারামিটার আছে এবং তা অতিথিদের নামের একটি তালিকা নেয়।
এটি বোঝায় আজ ডাইনিং রুমে কতজনের আসন সংরক্ষিত আছে।


এই ফাংশনটি ডিফল্ট আকারের (২২টি আসন) একটি `dict` সিটিং চার্ট রিটার্ন করবে, যেখানে রিজার্ভেশন তালিকায় নাম যেভাবে আছে সেই ক্রমে অতিথিদের আসনে বসানো হবে।
বরাদ্দ হয়নি এমন সব আসনের মান `None` থাকবে।
কোনো অতিথি না থাকলে, সব `None` প্লেসহোল্ডারসহ একটি "খালি" সিটিং চার্ট রিটার্ন করতে হবে।


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. সব "খালি" আসন খুঁজে বের করুন

`find_all_available_seats(<seats>)` ফাংশনটি ডিফাইন করুন, যা ১টি প্যারামিটার (_একটি সিটিং চার্ট ডিকশনারি_) নেয় এবং এখন অপেক্ষায় থাকা অতিথিদের জন্য খালি আছে এমন সব আসন নম্বরের একটি `list` রিটার্ন করে।
কোনো আসন খালি থাকলে ডিকশনারিতে তার মান `None` হবে। দখলে থাকা আসনে অতিথির নাম থাকবে।


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. বর্তমানে খালি আসনের ধারণক্ষমতা

`current_empty_seat_capacity(<seats>)` ফাংশনটি ডিফাইন করুন, যা ১টি প্যারামিটার নেয়, অর্থাৎ বর্তমান আসন রিজার্ভেশনগুলোর `dict`।
ফাংশনটি খালি থাকা আসনের মোট সংখ্যা রিটার্ন করবে।

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. আমাদের কি অপেক্ষা করা উচিত?

`accommodate_waiting_guests(<seats>, <guests>)` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়।
প্রথম প্যারামিটারটি হবে একটি সিটিং চার্ট `dict`।
দ্বিতীয় প্যারামিটারটি হবে হঠাৎ "ওয়াক-ইন" করা অতিথিদের একটি `list`।
প্রথমে আপনাকে বের করতে হবে কতগুলো আসন খালি আছে এবং এখন এই অঘোষিত অতিথিদের আসন দেওয়া আদৌ সম্ভব কি না।

যদি পর্যাপ্ত আসন না থাকে, সিটিং চার্ট `dict`টি অপরিবর্তিত অবস্থায় রিটার্ন করুন।

আসন _থাকলে_, অতিথিদের সিটিং চার্টে জায়গা বরাদ্দ করুন এবং হালনাগাদ করা চার্টটি রিটার্ন করুন।
**টিপ:** হিসাবগুলো আপনার হয়ে করতে আগে ডিফাইন করা ফাংশনগুলো ব্যবহার করতে পারেন।


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. খালি আসন

`empty_seats(<seats>, <seat_numbers>)` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়।
প্রথম প্যারামিটারটি হবে একটি সিটিং চার্ট ডিকশনারি।
দ্বিতীয় প্যারামিটারটি এমন আসন নম্বরের তালিকা, যেগুলো আপনাকে "খালি" করতে হবে, অর্থাৎ সেই আসন নম্বরের মান `None` করে দিতে হবে।

"খালি করতে হবে" এমন আসনগুলোর মান হালনাগাদ করার পর আসনগুলোর `dict` রিটার্ন করুন।

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
