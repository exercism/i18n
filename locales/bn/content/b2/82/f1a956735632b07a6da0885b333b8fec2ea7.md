# সম্পর্কে

Swift-এ আপনি একটি ইন্টিজার (যেমন `string[3]`) দিয়ে স্ট্রিং-এ ইনডেক্স করতে পারেন না।
কারণ Swift স্ট্রিংগুলো পরিবর্তনশীল দৈর্ঘ্যের ইউনিকোড ক্যারেক্টার দিয়ে গঠিত, একটি ক্যারেক্টার খুঁজে পেতে হলে আগের ক্যারেক্টারগুলোর মধ্য দিয়ে একে একে যেতে হয়।

একটি নির্দিষ্ট অবস্থানে একটি ক্যারেক্টার অ্যাক্সেস করতে হলে আপনাকে `String.Index` টাইপের একটি ইনডেক্স হিসাব করতে হবে।
এই ইনডেক্সগুলোকে *অপাক ইনডেক্স* বলা হয়, কারণ এগুলোর অভ্যন্তরীণ গঠন Swift পরিচালনা করে, সরাসরি কাঁচা ইন্টিজার হিসেবে ম্যানিপুলেট করা হয় না:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
