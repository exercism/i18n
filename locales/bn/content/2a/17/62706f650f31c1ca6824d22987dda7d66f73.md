# ভূমিকা

## চারলিস্ট

চারলিস্ট তৈরি করা হয় `~c` সিগিল ব্যবহার করে।

```elixir
~c"hello"
```

~~~~exercism/note
মনে রাখবেন, Elixir-এর পুরনো ভার্সনে চারলিস্টকে একক উদ্ধৃতি চিহ্ন দিয়ে `'hello'` হিসেবে লেখা হয়।
~~~~

দেখতে এগুলো স্ট্রিংয়ের সাথে খুবই মিল হলেও, এই দুটি ডেটা টাইপ আসলে একে অপরের থেকে বেশ আলাদা। একটি চারলিস্ট হলো ইন্টিজারের একটি অ্যারে। এই ইন্টিজারগুলো একটি নির্দিষ্ট ক্যারেক্টারের Unicode মান প্রকাশ করে, যাকে কোড পয়েন্টও বলা হয়।

```elixir
[65, 66, 67]
# => ~c"ABC"
```

কোনো ক্যারেক্টারের আগে `?` বসালে তার কোড পয়েন্ট পাওয়া যায়।

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

যেহেতু চারলিস্ট অ্যারে, তাই অন্য যেকোনো অ্যারের মতোই রিকার্সন আর প্যাটার্ন ম্যাচিং ব্যবহার করে এগুলো নিয়ে কাজ করা যায়।

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

`++` ব্যবহার করে দুটি অ্যারে জোড়া লাগাতে পারেন।

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

প্রথম অ্যারেটি যত বড় হবে, জোড়া লাগানো তত ধীর হবে, তাই যেকোনো দৈর্ঘ্যের অ্যারের শেষে বারবার যোগ করা এড়িয়ে চলুন।

## Case

`case` হলো একটি কন্ট্রোল ফ্লো স্ট্রাকচার, যা দিয়ে একটি নির্দিষ্ট মানকে অনেকগুলো প্যাটার্নের সাথে তুলনা করা যায়। `case` এক্সপ্রেশনের ক্লজগুলো উপর থেকে নিচে যাচাই করা হয়, যতক্ষণ না কোনো মিল পাওয়া যায়।

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
