# পরিচিতি

## তুলনা

Python নিচের মৌলিক তুলনা অপারেটরগুলো সাপোর্ট করে:

| অপারেটর | অপারেশন | বিবরণ |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | "এর চেয়ে বড়"             | `a > b` হলো `True` যদি মানের দিক থেকে `a`, `b`-এর চেয়ে **কঠোরভাবে** বড় হয়        |
| `<`      | "এর চেয়ে ছোট"                | `a < b` হলো `True` যদি মানের দিক থেকে `a`, `b`-এর চেয়ে **কঠোরভাবে** ছোট হয়           |
| `==`     | "সমান"                 | `a == b` হলো `True` যদি মানের দিক থেকে `a`, `b`-এর **কঠোরভাবে** সমান হয়           |
| `>=`     | "এর চেয়ে বড় বা সমান" | `a >= b` হলো `True` যদি মানের দিক থেকে `a > b` অথবা `a == b` হয়                        |
| `<=`     | "এর চেয়ে ছোট বা সমান"    | `a <= b` হলো `True` যদি মানের দিক থেকে `a < b` অথবা `a == b` হয়                        |
| `!=`     | "সমান নয়"             | `a != b` হলো `True` যদি `a == b` হয় `False`                                 |
| `is`     | "আইডেন্টিটি"                 | `a is b` হলো `True` যদি **_এবং কেবল যদি_** `a` আর `b` একই _অবজেক্ট_ হয় |
| `is not` | "নেগেটেড আইডেন্টিটি"         | `a is not b` হলো `True` যদি `a` আর `b` একই _অবজেক্ট_ **না** হয়       |
| `in`     | "কন্টেইনমেন্ট টেস্ট"         | `a in b` হলো `True` যদি `a`, `b`-এর মেম্বার, সাবসেট বা এলিমেন্ট হয়            |
| `not in` | "নেগেটেড কন্টেইনমেন্ট টেস্ট" | `a not in b` হলো `True` যদি `a`, `b`-এর মেম্বার, সাবসেট বা এলিমেন্ট না হয়  |

এদের সবার প্রায়োরিটি একই (_যা [বুলিয়ান অপারেশন][boolean operations]-এর চেয়ে বেশি, কিন্তু অ্যারিথমেটিক বা বিটওয়াইজ অপারেশনের চেয়ে কম_)।

## বিভিন্ন ডেটা টাইপের মধ্যে তুলনা

ভিন্ন টাইপের অবজেক্ট (_সংখ্যাসূচক টাইপগুলো ছাড়া_) ডিফল্টভাবে কখনোই সমান হিসেবে গণ্য হয় না।
একটি `class`-এর অভিন্ন নয় এমন ইনস্ট্যান্সও সমান হিসেবে _**না**_-ই গণ্য হয়, যদি না `class`-টি এমন বিশেষ [রিচ কম্প্যারিজন][rich comparisons] মেথড ডিফাইন করে যা ডিফল্ট `object` তুলনার আচরণ কাস্টমাইজ করে।
`rich comparisons` দিয়ে কাস্টমাইজ করার বিষয়টি পরের একটি অনুশীলনীতে আলোচনা করা হবে।
এই বিষয়ে (অনেক) বেশি বিস্তারিত জানতে Python ডকুমেন্টেশনের [মানের তুলনা][value comparisons] দেখুন।

সংখ্যাসূচক টাইপগুলো এই টাইপ মেলানোর নিয়মের (বেশিরভাগ ক্ষেত্রেই) একটি ব্যতিক্রম।
একটি `integer`-কে একটি `float`-এর সমান ধরা **যেতে পারে** (_বা একটি [`octal`][octal]-কে একটি [`hexadecimal`][hex]-এর সমান_), যতক্ষণ টাইপগুলোকে তুলনার জন্য ইমপ্লিসিটভাবে কনভার্ট করা যায়।

Python স্ট্যান্ডার্ড লাইব্রেরির বাকি সংখ্যাসূচক টাইপগুলোর ([complex][complex numbers], [decimal][decimal numbers], [fractions][rational numbers]) জন্য তুলনা অপারেটরগুলো সেখানে ডিফাইন করা, যেখানে তারা "অর্থবহ" (_যেখানে ইমপ্লিসিট কনভার্সন ফলাফল বদলায় না_), কিন্তু তুলনার জন্য অন্তর্নিহিত অবজেক্টগুলোকে নির্ভুলভাবে কনভার্ট করা না গেলে একটি `TypeError` থ্রো করে।
Python _সংখ্যাসূচক কনভার্সনে_ যে নিয়মগুলো ব্যবহার করে সে সম্পর্কে আরও জানতে Python ডকুমেন্টেশনের [অ্যারিথমেটিক কনভার্সন][arithmetic conversions] দেখুন।

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

কোনো সংখ্যাকে `NaN` (_not a number_) টাইপের সাথে ক্রমভিত্তিক তুলনা করলে ফল সবসময় `False`।
Python-এর `NaN`-এর সংজ্ঞার একটি বিভ্রান্তিকর পার্শ্বপ্রতিক্রিয়া হলো, `NaN` কখনোই `NaN`-এর সমান হিসেবে তুলিত হয় না।

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## স্ট্রিং তুলনা

সংখ্যার বিপরীতে, স্ট্রিং (`str`) তুলনা করা হয় [_লেক্সিকোগ্রাফিকভাবে_][lexographic order], তাদের প্রতিটি ইউনিকোড কোড পয়েন্ট ব্যবহার করে (_`str`-এর প্রতিটি কোড পয়েন্ট বিল্ট-ইন ফাংশন [`ord()`][ord]-এ পাস করার ফল, যা একটি `int` রিটার্ন করে_)।
দুই স্ট্রিংয়ের সব কোড পয়েন্ট মিলে গেলে এবং সেগুলো _**একই ক্রমে**_ থাকলে, দুই স্ট্রিংকেই সমান ধরা হয়।
এই তুলনাটি 'জোড়ায় জোড়ায়' করা হয়, প্রথমটির সাথে প্রথমটি, দ্বিতীয়টির সাথে দ্বিতীয়টি, এভাবে।
Python 3.x-এ `str` আর `bytes`-কে সরাসরি রূপান্তর করে তুলনা করা যায় না।

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## তুলনার চেইনিং

তুলনা অপারেটরগুলো _ইচ্ছেমতো_ চেইন করা যায়, অর্থাৎ যেকোনো দৈর্ঘ্যের যেকোনো সমন্বয়ে সেগুলো ব্যবহার করা যায়।
মনে রাখবেন, একটি এক্সপ্রেশনের মূল্যায়ন `left` থেকে `right`-এ হয়।

উদাহরণস্বরূপ, `x < y <= z` আসলে `x < y` `and` `y <= z`-এর সমতুল্য, শুধু পার্থক্য হলো `y` **মাত্র একবার** মূল্যায়িত হয়।
দুই ক্ষেত্রেই, `x < y`-কে `False` হিসেবে পাওয়া গেলে `z`-কে **একেবারেই** মূল্যায়ন করা হয় _না_।
একে প্রায়ই `short-circuit evaluation` বলা হয়, অর্থাৎ এক্সপ্রেশনের সত্য মান আগেই নির্ধারিত হয়ে গেলে মূল্যায়ন থেমে যায়।

`Short circuiting` verschieden বুলিয়ান অপারেটর, ফাংশন এবং Python-এ তুলনার চেইনিংও সাপোর্ট করে।
`C`, `C++`, `C#` আর `Java`-সহ আরও অনেক প্রোগ্রামিং ভাষার বিপরীতে, Python-এ `a < b < c`-এর মতো চেইন করা এক্সপ্রেশনের একটি প্রচলিত [গাণিতিক ব্যাখ্যা][three way boolean comparison] ও প্রিসিডেন্স থাকে।

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## অবজেক্ট আইডেন্টিটি তুলনা

`is` আর `is not` অপারেটর অবজেক্টের _মান_-এর বিপরীতে অবজেক্টের [_আইডেন্টিটি_][object identity] পরীক্ষা করে।
একবার তৈরি হওয়ার পর অবজেক্টের আইডেন্টিটি কখনো বদলায় না, আর এটি [`id()`][id function] ফাংশন দিয়ে পাওয়া যায়।

`<apple> is <orange>` মূল্যায়িত হয় `True`-তে _**যদি এবং কেবল যদি**_ `id(<apple>)` == `id(<orange>)` হয়।
`<apple> is not <orange>` এর বিপরীত ফল দেয়।

সিঙ্গেলটন হওয়ার কারণে, `None` আর `NotImplemented`-কে সবসময় `is` আর `is not` দিয়ে আইটেমের সাথে তুলনা করা উচিত।
এই রীতির আরও বিস্তারিত জানতে [মানের তুলনা][value comparisons none] ও [PEP8][pep8 programming recommendations] নিয়ে Python-এর রেফারেন্স ডকুমেন্টেশন দেখুন।

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## মেম্বারশিপ তুলনা

`in` আর `not in` অপারেটর _মেম্বারশিপ_ পরীক্ষা করে।
`<fish> in <soup>` মূল্যায়িত হয় `True`-তে যদি `<fish>`, `<soup>`-এর একটি মেম্বার হয় (_যদি `<fish>`, `<soup>`-এর একটি সাবসেট হয় বা `<soup>`-এর ভেতরে থাকে_), অন্যথায় `False`-তে মূল্যায়িত হয়।
`<fish> not in <soup>` নেগেশনটি রিটার্ন করে, অর্থাৎ `<fish> in <soup>`-এর _বিপরীত_ ফল।

স্ট্রিং আর bytes টাইপের ক্ষেত্রে, `<name> in <fullname>` হলো `True` _**যদি এবং কেবল যদি**_ `<name>`, `<fullname>`-এর একটি সাবস্ট্রিং হয়।

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
