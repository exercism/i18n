# ভূমিকা

Python-এ লুপ করার দুইটি কনস্ট্রাক্ট রয়েছে।
`while` লুপ _অনির্দিষ্ট_ (গণনাহীন) ইটারেশনের জন্য, আর `for` লুপ _নির্দিষ্ট_ (গণনাযুক্ত) ইটারেশনের জন্য।
`break`, `continue` ও `else` কিওয়ার্ডগুলো লুপের আচরণ কাস্টমাইজ করতে সাহায্য করে।
`range()` ও `enumerate()` লুপ গণনা এবং ইনডেক্সিংয়ে সাহায্য করে।


## While

[`while`][while statement] লুপ ততক্ষণ চলতেই থাকবে, যতক্ষণ `loop expression` বা "test" একটি [`boolean context`][truth value testing]-এ `True` হিসেবে গণ্য হয়; আর সেটি `False` হিসেবে গণ্য হলে থেমে যায়:

```python

# Lists are considered "truthy" in a boolean context if they
# contain one or more values, and "falsy" if they are empty.

>>> placeholders = ["spam", "ham", "eggs", "green_spam", "green_ham", "green_eggs"]

>>> while placeholders:
...     print(placeholders.pop(0))
...
'spam'
'ham'
'eggs'
'green_spam'
'green_ham'
'green_eggs'
```


## For

Python-এ সাধারণ [`for`][for statement] `loop`-কে বরং একটি _`for each`_ বলা ভালো, যা যেকোনো [ইটারেবল অবজেক্ট][iterable]-এর মানগুলোর মধ্য দিয়ে ঘোরে, এবং [`next()`][next built-in] কল করে আর কোনো মান ফেরত না এলে থেমে যায়:

```python

>>> word_list = ["bird", "chicken", "barrel", "bongo"]

>>> for word in word_list:
...    if word.startswith("b"):
...        print(f"{word.title()} starts with a B.")
...    else:
...        print(f"{word.title()} doesn't start with a B.")
...
'Bird starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel starts with a B.'
'Bongo starts with a B.'
```


## সিকোয়েন্স অবজেক্ট range()

যখন নির্দিষ্ট কোনো `iterable` দেওয়া থাকে না, তখন লুপ কাউন্টার হিসেবে বিশেষ [`range()`][range] সিকোয়েন্সটি ব্যবহার করা হয়।
`range()`-এর সিকোয়েন্সটি কোথায় `stop` হবে তা নির্দেশ করার জন্য একটি `int` দরকার, আর এটি ঐচ্ছিকভাবে `start` ও `step` প্যারামিটারও নিতে পারে।
কোনো `start` সংখ্যা না দিলে, সিকোয়েন্সটি ০ দিয়ে শুরু হবে।
`range()` অবজেক্টগুলো **লেজি** (_চাহিদা অনুযায়ী মান তৈরি হয়_), সব [সাধারণ সিকোয়েন্স অপারেশন][common sequence operations] সমর্থন করে, এবং নির্দিষ্ট সিকোয়েন্স যত লম্বাই হোক না কেন, নির্দিষ্ট পরিমাণ মেমোরি নেয়।

```python
# Here we use range to produce some numbers, rather than creating a list of them in memory.
# The values will start with 1 and stop *before* 7

>>> for number in range(1, 7):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
'1 is odd.'
'2 is even.'
'3 is odd.'
'4 is even.'
'5 is odd.'
'6 is even.'

# range() can also take a *step* parameter.
# Here we use range to produce only the "odd" numbers, starting with 3 and stopping *before* 15.

>>> for number in range(3, 15, 2):
...    if number % 2 == 0:
...       print(f"{number} is even.")
...    else:
...       print(f"{number} is odd.")
...
'3 is odd.'
'5 is odd.'
'7 is odd.'
'9 is odd.'
'11 is odd.'
'13 is odd.'
```


## enumerate() দিয়ে মান ও ইনডেক্স

যদি মান এবং তাদের ইনডেক্স দুটোই দরকার হয়, তাহলে বিল্ট-ইন [`enumerate(<iterable>)`][enumerate] (`index`, `value`) জোড়া রিটার্ন করবে:

```python

>>> word_list = ["bird", "chicken", "barrel", "apple"]

# *index* and *word* are the loop variables.
# Loop variables can be any valid python name.

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    else:
...        print(f"{word.title()} (at index {index}) doesn't start with a B.")
...
'Bird (at index 0) starts with a B.'
'Chicken (at index 1) doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Apple (at index 3) doesn\'t start with a B.'


# The same method can be used as a "lookup" for pairing items between two lists.
# Of course, if the lengths or indexes don't line up, this doesn't work.

>>> word_list = ["cat", "chicken", "barrel", "apple", "spinach"]
>>> category_list = ["mammal", "bird", "thing", "fruit", "vegetable"]

>>> for index, word in enumerate(word_list):
...    print(f"{word.title()} is in category: {category_list[index]}.")
...
'Cat is in category: mammal.'
'Chicken is in category: bird.'
'Barrel is in category: thing.'
'Apple is in category: fruit.'
'Spinach is in category: vegetable.'
```


## লুপের আচরণ পরিবর্তন

[`continue`][continue statement] কিওয়ার্ডটি দিয়ে পরের ইটারেশন সাইকেলে এগিয়ে যাওয়া যায়:

```python
word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple", "bear"]

# This will skip *bird*, at index 0
for index, word in enumerate(word_list):
    if index == 0:
        continue
    if word.startswith("b"):
        print(f"{word.title()} (at index {index}) starts with a b.")

'Barrel (at index 2) starts with a b.'
'Bongo (at index 3) starts with a b.'
'Bear (at index 6) starts with a b.'
```


[`break`][break statement] (_অনেক C-সংক্রান্ত ভাষার মতো_) কিওয়ার্ডটি দিয়ে ইটারেশন থামানো যায় এবং সবচেয়ে ভেতরের `loop` থেকে "বেরিয়ে যাওয়া" যায়:

```python
>>>  word_list = ["bird", "chicken", "barrel", "bongo", "sliver", "apple"]

>>> for index, word in enumerate(word_list):
...    if word.startswith("b"):
...        print(f"{word.title()} (at index {index}) starts with a B.")
...    elif word == "sliver":
...       break
...    else:
...       print(f"{word.title()} doesn't start with a B.")
... print("loop broken.")
...
'Bird (at index 0) starts with a B.'
'Chicken doesn\'t start with a B.'
'Barrel (at index 2) starts with a B.'
'Bongo (at index 3) starts with a B.'
'loop broken.'
```
