# পরিচিতি

ফ্লোট হলো দশমিক বিভাজকের পরে এক বা একাধিক অঙ্কযুক্ত সংখ্যা। এগুলো ৬৪-বিট ডাবল প্রেসিশন ফ্লোটিং-পয়েন্ট ফরম্যাট ব্যবহার করে।

```elixir
float = 3.45
# => 3.45
```

## সংখ্যা নিয়ে কাজ করা

[`Integer`][integer-functions] ও [`Float`][float-functions] মডিউলে এই টাইপগুলো নিয়ে কাজ করার জন্য কিছু কাজের ফাংশন পাবেন। মৌলিক গাণিতিক অপারেটর [`Kernel`][kernel-arithmetic-operators] মডিউলে ডিফাইন করা আছে।

## রূপান্তর

ইন্টিজার ও ফ্লোট একই গাণিতিক এক্সপ্রেশনে একসাথে মেশানো যায়। একটি এক্সপ্রেশনে ফ্লোট ব্যবহার করলে ফলাফলও যে ফ্লোট হবে তা নিশ্চিত হয়।

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

তবে ভাগ করার সময় ফলাফল সবসময় ফ্লোট হয়, এমনকি শুধু ইন্টিজার ব্যবহার করলেও।

```elixir
6 / 2
# => 3.0
```

একটি ফ্লোটকে ইন্টিজারে রূপান্তর করতে, [`trunc/1`][trunc-1] দিয়ে দশমিক অংশটি বাদ দিতে পারেন।
