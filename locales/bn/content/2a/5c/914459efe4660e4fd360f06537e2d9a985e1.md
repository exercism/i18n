# পরিচিতি

JavaScript-এ একটি [সেট][mdn-sets] হলো লিস্টের মতো একটি স্ট্রাকচার, যাতে ইউনিক মান থাকে; সেই মানগুলো প্রিমিটিভ হতে পারে, আবার অবজেক্ট রেফারেন্সও হতে পারে। অ্যারের মতো নয়, সেটের এলিমেন্টগুলো ইনডেক্স দিয়ে অ্যাক্সেস করা যায় না।

সেটের যেকোনো এলিমেন্টের সাথে একটি মান [স্ট্রিক্টলি ইকুয়াল][mdn-strict-equality] হলে সেটিতে সেই মান যোগ করা যায় না।

```javascript
const set = new Set();
const object = { color: 'lime green' };
const functionallyIdenticalObject = { color: 'lime green' };

set.add(object);
set.add('wow');
set.add(77);

console.log(set.size);
//=> 3

set.add(functionallyIdenticalObject); // added because functionallyIdenticalObject is not strictly equal to object
console.log(set.size);
//=> 4

set.add(77); // not added because 77 is strictly equal to 77
console.log(set.size);
//=> 4
```

সেট তৈরি করার সময় আপনি আর্গুমেন্ট হিসেবে একটি অ্যারে দিতে পারেন; তখন অ্যারের মানগুলোই সেটের মান হয়ে যাবে, আর ডুপ্লিকেট মানগুলোও বাদ পড়বে।

```javascript
const array = [1, 5, 4, 1];
const set = new Set(array); // the set's values become [1, 5, 4]

console.log(set.size);
//=> 3
```

একটি সেটকে অ্যারেতে রূপান্তর করতে আপনি [Array.from()][mdn-array-from] ব্যবহার করতে পারেন, যা সেট বা ম্যাপের মতো ইটারেবলকে অ্যারেতে রূপান্তর করে।

```javascript
const set = new Set();

set.add(1);
set.add(2);
set.add(3);
set.add(4);

const array = Array.from(set);
console.log(array);
//=> [1, 2, 3, 4]
```
