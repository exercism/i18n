# ভিজিবিলিটি

ক্লাস দিয়ে কোড সংগঠিত করার সময়, প্রপার্টি, মেথড ও কনস্ট্যান্টের ভিজিবিলিটি সঠিক অ্যাবস্ট্রাকশন ও দায়িত্ব বজায় রাখতে সাহায্য করে।
প্রপার্টি, মেথড ও কনস্ট্যান্ট ডিক্লেয়ার করার সময় `public`, `private` বা `protected` কিওয়ার্ড ব্যবহারের মাধ্যমে তাদের ভিজিবিলিটি নির্ধারিত হয়।
ভিজিবিলিটি সবসময় ক্লাসের প্রপার্টি, মেথড বা কনস্ট্যান্টের বাইরের ব্যবহারের সাপেক্ষে বিবেচিত হয়।
অর্থাৎ, কোনো প্রপার্টি `public` হিসেবে ডিক্লেয়ার করা হলে সেটি বাইরের কল থেকে দেখা যায় এবং ব্যবহার করা যায়।
প্রাইভেট প্রপার্টি, মেথড ও কনস্ট্যান্ট বাইরের কল থেকে দেখা যায় না বা ব্যবহার করা যায় না।

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

প্রোটেক্টেড প্রপার্টি, মেথড ও কনস্ট্যান্ট কেবল নিজেদের এবং (ইনহেরিট্যান্সের মাধ্যমে) চাইল্ড ক্লাসগুলোর কাছেই দৃশ্যমান।

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
