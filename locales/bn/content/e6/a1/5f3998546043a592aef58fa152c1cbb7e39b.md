# নির্দেশনা

স্কুলের নাটকের অডিশন শেষ, এখন পরিচালককে সিদ্ধান্তগুলো লিখে রাখতে হবে।

এই চারটি কাজই `CASTING_CALL` ক্লাসে রাখতে হবে।

## 1. রায়

প্রত্যেক শিল্পীকে দশের মধ্যে নম্বর দেওয়া হয়। আট বা তার বেশি পেলে তারা নাটকে ভূমিকা পায়; পাঁচ থেকে সাত হলে তাদের আবার ডাকা হয়; পাঁচের কম হলে তাদের ধন্যবাদ জানানো হয়।

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. কোন গ্রুপ?

১৩ বছরের কম বয়সীরা Juniors. ১৩ থেকে ১৫ বছর বয়সীরা Middles. ষোল বা তার বেশি বয়সীরা Seniors.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. কখন ফিরে আসতে হবে

Juniors-দের চারটায় আবার ডাকা হয়, Middles-দের পাঁচটায়, আর বাকি সবাইকে ছয়টায়।

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

আর্গুমেন্টটি একটি গ্রুপের নাম, ঠিক যেভাবে 2 নম্বর কাজে বানান করা হয়েছে সেভাবেই বানান করতে হবে।

## 4. শিটে কী লিখতে হবে

যে কেউ আট বা তার বেশি নম্বর পেয়েছে এবং গান গাইতে পারে, সে `"Lead"`. গান গাইতে না পারলে আট বা তার বেশি নম্বর হলেও `"Speaking part"`. বাকি সবাই `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
