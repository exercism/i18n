# ইনস্টলেশন

## দ্রুত শুরু

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

ডিফল্টভাবে এটি `/usr/local/bin`-এ ইনস্টল হবে। এটি পরিবর্তন করতে ডিরেক্টরির নামটি দিন:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Linux ও macOS-এর বাইনারি brew-এর মাধ্যমে দেওয়া হয়।

ইনস্টল:

    brew install borkdude/brew/babashka

আপগ্রেড:

    brew upgrade babashka

## Arch (Linux)

`babashka` [Arch User Repository](https://aur.archlinux.org)-তে [পাওয়া যায়](https://aur.archlinux.org/packages/babashka-bin/)। আপনার পছন্দের [AUR](https://aur.archlinux.org) হেল্পার যেমন
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) এবং [pacaur](https://github.com/rmarquis/pacaur) দিয়ে এটি ইনস্টল করা যায়। নিচে `yay` ব্যবহারের একটি উদাহরণ:

    yay -S babashka-bin

## Windows

Windows-এ আপনি [scoop](https://scoop.sh/) এবং
[scoop-clojure](https://github.com/littleli/scoop-clojure) বাকেট ব্যবহার করে ইনস্টল করতে পারেন।

## ডাউনলোড

আপনি [Github](https://github.com/borkdude/babashka/releases) থেকেও একটি বাইনারি ডাউনলোড করতে পারেন। Linux-এর জন্য একটি স্ট্যাটিক বাইনারি পাওয়া যায়, যা Alpine-এ ব্যবহার করা যায়।
