# পরিচিতি

## বিটস্ট্রিং

যেকোনো ভাষাতেই বাইনারি ডেটা নিয়ে কাজ করা একটি গুরুত্বপূর্ণ ধারণা, আর Elixir বাইনারি ডেটা লেখা, মেলানো ও গঠন করার জন্য একটি সুন্দর সিনট্যাক্স দেয়।

Elixir-এ বাইনারি ডেটাকে বিটস্ট্রিং টাইপ বলা হয়। বাইনারি ডেটা _টাইপ_ (সাধারণ বাইনারি ডেটার সাথে গুলিয়ে ফেলা যাবে না) হলো বিটস্ট্রিংয়ের একটি নির্দিষ্ট রূপ, যা নিয়ে আমরা পরের একটি অনুশীলনীতে আলোচনা করব।

বিটস্ট্রিং লিটারাল বিটস্ট্রিং স্পেশাল ফর্ম `<<>>` ব্যবহার করে ডিফাইন করা হয়। একটি বিটস্ট্রিং লিটারাল ডিফাইন করার সময় সেটি সেগমেন্টে সেগমেন্টে ডিফাইন করা হয়। প্রতিটি সেগমেন্টের একটি মান ও একটি টাইপ থাকে, যেগুলো `::` অপারেটর দিয়ে আলাদা করা হয়। টাইপটি বলে দেয় মানটি এনকোড করতে কতগুলো বিট ব্যবহার হবে। টাইপটি সম্পূর্ণভাবে বাদ দেওয়াও যায়, সেক্ষেত্রে ডিফল্ট হিসেবে ৮-বিট ইন্টিজার মান ধরা হয়।

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

টাইপ `::1` হিসেবে লেখা হলো `::size(1)` লেখার একটি সংক্ষিপ্ত রূপ। বিট সাইজ যদি কোনো ভ্যারিয়েবল থেকে আসে, তাহলে আপনাকে বড় সিনট্যাক্সটি ব্যবহার করতে হবে।

### বাইনারি

বাইনারি ইন্টিজার লিটারাল লেখার সময় আমরা লিটারালের সামনে `0b` বসিয়ে সরাসরি বেস-২ নোটেশনে লিখতে পারি। মনে রাখবেন, টেস্টের ফলাফলে বা iex ব্যবহার করার সময় এগুলো যেভাবেই হোক দশমিক সংখ্যা হিসেবেই দেখানো হবে।

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

### ট্রাংকেট করা

যদি সেগমেন্টের মান সেগমেন্টের টাইপের ধারণক্ষমতার চেয়ে বেশি হয়ে যায়, তাহলে এটি বাম দিক থেকে ট্রাংকেট করা হবে।

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

### প্রিপেন্ড ও অ্যাপেন্ড করা

স্পেশাল ফর্ম ব্যবহার করে আপনি একটি বিদ্যমান বিটস্ট্রিংয়ের সামনে ও পেছনে দুটোই যোগ করতে পারেন। বিদ্যমান বিটস্ট্রিংটির সাইজ অজানা হলে সেটির জন্য `::bitstring` টাইপ ব্যবহার করতে হবে।

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

### কনক্যাটেনেট করা

স্পেশাল ফর্ম ব্যবহার করে আমরা ভ্যারিয়েবলে রাখা বিটস্ট্রিংগুলো কনক্যাটেনেট করতে পারি। অজানা সাইজের দুটি বিটস্ট্রিং কনক্যাটেনেট করার সময় `::bitstring` টাইপ ব্যবহার করতে হবে।

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

### প্যাটার্ন ম্যাচিং

স্পেশাল ফর্ম থেকে মান বের করতেও প্যাটার্ন ম্যাচিং করা যায়। যে ফ্র্যাগমেন্টটি আপনি ধরতে চান, তার জন্য কত বিট লাগবে সেটি আপনাকে জানতে হবে, তবে একটি ব্যতিক্রম আছে: অজানা সাইজের বিটস্ট্রিংয়ের উপর প্যাটার্ন ম্যাচ করার জন্য `::bitstring` টাইপ ব্যবহার করা যায়, কিন্তু এটি শুধু শেষ ফ্র্যাগমেন্টের জন্যই ব্যবহার করা যাবে।

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

### বিটস্ট্রিং দেখা

~~~~exercism/note
বিটস্ট্রিংগুলো হয়তো (টেস্ট রানার বা iex-এ) যে ফরম্যাটে তৈরি করা হয়েছিল তার চেয়ে ভিন্ন ফরম্যাটে প্রিন্ট হতে পারে। বিটস্ট্রিং শেখার সময় এটি প্রায়ই বিভ্রান্তির সৃষ্টি করে।
~~~~

ডিফল্টভাবে বিটস্ট্রিংগুলো ৮ বিটের (এক বাইট) ফ্র্যাগমেন্টে দেখানো হয়, এমনকি আপনি যদি সেগুলো ভিন্ন সাইজের ফ্র্যাগমেন্টে তৈরি করে থাকেন।

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

আপনি যদি এমন একটি বিটস্ট্রিং তৈরি করেন যা একটি প্রিন্টযোগ্য UTF-8 এনকোডেড স্ট্রিং প্রকাশ করে, তাহলে সেটি স্ট্রিং হিসেবে দেখানো হয়।

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
