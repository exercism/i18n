# পরিচিতি

কোনো কোয়োটেশন যখন তার আশপাশ থেকে মান *মনে রাখতে* চায়, তখন Factor দুটি হাতিয়ার দেয়: [`kernel`][kernel] থেকে `curry`/`compose`, আর [`fry`][fry] থেকে fry সিনট্যাক্স `'[ … ]`.

`curry` একটি মান কোয়োটেশনের সামনের অংশে বসিয়ে দেয়:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` দুটি কোয়োটেশনকে জোড়া লাগায়:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

এক বা দুটির বেশি ক্যাপচার ধরতে হলে fry বেশি পরিচ্ছন্ন। প্রতিটি `_` প্লেসহোল্ডার স্ট্যাক থেকে নেওয়া একটি মান দিয়ে ক্রমানুসারে পূরণ হয়:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry নেস্টেড কোয়োটেশনের ভেতরেও পৌঁছে যায়।

[fry]: https://docs.factorcode.org/content/vocab-fry.html
