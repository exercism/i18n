# পরিচিতি

C#-এ অ্যারে হলো প্রিমিটিভ মান, অথবা স্ট্রাক্ট বা ক্লাসের ইনস্ট্যান্সের কলেকশন। এগুলো বেস ক্লাস লাইব্রেরিতে `List<T>` হিসেবে ইমপ্লিমেন্ট করা হয়েছে, যেখানে `T` হলো অ্যারের এলিমেন্টের টাইপ। API অ্যারে তৈরি ও ম্যানিপুলেট করার জন্য বিস্তৃত এক সেট মেথড উপলব্ধ করায়।

অ্যারেতে এলিমেন্ট যোগ করা যায় আবার সরিয়ে ফেলা যায়। প্রয়োজন অনুসারে এগুলো বাড়ে ও কমে।

```csharp
var listOfStrings = new List<string>();
```
