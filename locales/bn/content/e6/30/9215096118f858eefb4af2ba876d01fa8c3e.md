# পরিচিতি

[রেঞ্জ][range] দুটি মানের মধ্যবর্তী একটি ব্যবধি নির্দেশ করে।
রেঞ্জ কমনভাবে `Int`, `String`, আর `Character` টাইপের সাথে ব্যবহার করা হয় সিকোয়েন্সের উপর ইটারেশন করতে, কলেকশনের অংশ কেটে নিতে, বা কোনো মান নির্দিষ্ট সীমার মধ্যে পড়ে কি না তা যাচাই করতে।

Swift দুটি প্রধান রেঞ্জ অপারেটর প্রদান করে:

- **ক্লোজড রেঞ্জ অপারেটর (`...`)**: শুরু ও শেষ, দুটি মানই অন্তর্ভুক্ত করে (`1...5`-এ ১, ২, ৩, ৪ আর ৫ অন্তর্ভুক্ত)।
- **হাফ-ওপেন রেঞ্জ অপারেটর (`..<`)**: শুরুর মান অন্তর্ভুক্ত করে কিন্তু শেষের মান বাদ দেয় (`1..<5`-এ ১, ২, ৩ আর ৪ অন্তর্ভুক্ত)।

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
কোনো রেঞ্জ লিটারেলের উপর সরাসরি মেথড কল করার সময় রেঞ্জ এক্সপ্রেশনটি বন্ধনীর ভেতরে মুড়ে দিন, যাতে কম্পাইলার আগে রেঞ্জটি হিসাব করে নেয়:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```

## একটি রেঞ্জকে অ্যারেতে রূপান্তর করা

`Array(_:)` ইনিশিয়ালাইজার ব্যবহার করে আপনি সংখ্যার একটি রেঞ্জকে `Array`-তে রূপান্তর করতে পারেন:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## রেঞ্জ দিয়ে অ্যারের অংশ কাটা

আপনি রেঞ্জ ব্যবহার করে একটি অ্যারের উপ-অংশগুলো কেটে নিতে পারেন:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## রেঞ্জের প্রপার্টি ও মেথড

রেঞ্জের কমন অপারেশনগুলোর মধ্যে আছে:

| মেম্বার                  | বিবরণ                                                | উদাহরণ                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | রেঞ্জে থাকা এলিমেন্টের সংখ্যা রিটার্ন করে                | `(1...5).count` রিটার্ন করে `5`          |
| [`contains(_:)`][contains] | রেঞ্জটি নির্দিষ্ট মানটি অন্তর্ভুক্ত করলে `true` রিটার্ন করে | `(1...5).contains(3)` রিটার্ন করে `true` |

## একপার্শ্বিক রেঞ্জ

Swift একপার্শ্বিক (আংশিক) রেঞ্জও সাপোর্ট করে, যেখানে আপনি শুরুর বা শেষের যেকোনো একটি মান বাদ দেন:

- `array[2...]`: ইনডেক্স ২ থেকে কলেকশনের শেষ পর্যন্ত।
- `array[...2]`: কলেকশনের শুরু থেকে ইনডেক্স ২ পর্যন্ত (২ সহ)।
- `array[..<2]`: কলেকশনের শুরু থেকে ইনডেক্স ২ পর্যন্ত (তবে ২ বাদ দিয়ে)।

## স্ট্রিং ও ক্যারেক্টার রেঞ্জ

`Comparable` মেনে চলে এমন ক্যারেক্টার বা স্ট্রিংয়ের মধ্যেও রেঞ্জ তৈরি করা যায়:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
