# অ্যারে

Cairo-তে একটি অ্যারে হলো এমন একটি ডেটা স্ট্রাকচার, যা দিয়ে আপনি একই টাইপের এলিমেন্টের একটি সংগ্রহ সংরক্ষণ করতে পারেন।
Cairo-তে অ্যারের পরিবর্তনের সুযোগ সীমিত।
আপনি কেবল অ্যারের শেষে আইটেম অ্যাপেন্ড করতে পারেন এবং সামনে থেকে আইটেম সরাতে পারেন।
অ্যারে আসলে এমন কিউ, যার মান পরিবর্তন করা যায় না।

## অ্যারে তৈরি

অ্যারে মূলত `ArrayTrait` ট্রেইট ব্যবহার করে তৈরি করা হয়। `[1, 2]` এলিমেন্টের একটি অ্যারে তৈরি করতে নিচের ৪টি উপায়ের যেকোনো একটি ব্যবহার করা যায়:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> প্রতিটি `append()` কল অ্যারের শেষে একটি নতুন সংখ্যা যুক্ত করে।

## অ্যারের এলিমেন্ট সরানো

Cairo-তে অ্যারে থেকে এলিমেন্ট সরানোর একমাত্র উপায় হলো সামনে থেকে সরানো।
এই কাজটি `pop_front()` মেথডের মাধ্যমে করা হয়, যা একটি `Option` রিটার্ন করে। এটি আনর্যাপ করা যায় এবং সরিয়ে ফেলা এলিমেন্টটি ধারণ করে, আর অ্যারেটি খালি হলে এটি `Option::None` হয়।

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## অ্যারের মান অ্যাক্সেস করা

অ্যারের এলিমেন্ট অ্যাক্সেস করতে আপনি `get()` বা `at()` অ্যারে মেথড ব্যবহার করতে পারেন, যেগুলো ভিন্ন ভিন্ন টাইপ রিটার্ন করে।
`arr[index]` সাবস্ক্রিপ্টিং অপারেটরটি `arr.at(index)`-এর সমতুল্য।

### get() মেথড ব্যবহার করা

`get()` মেথড হলো একটি অ্যারে থেকে তার নম্বর দিয়ে কোনো আইটেম খুঁজে বের করার মতো।
এটি যেভাবে কাজ করে:

- `arr.get(index)` দিয়ে আপনি অ্যারের একটি নির্দিষ্ট অবস্থানে (ইনডেক্সে) থাকা আইটেম আনতে পারেন।
- প্রদত্ত ইনডেক্সে আইটেমটি থাকলে এটি `Option::Some(value)` রিটার্ন করে, আর ইনডেক্সটি সীমার বাইরে হলে `Option::None` রিটার্ন করে।

ইনডেক্স অবৈধ হতে পারে এমন পরিস্থিতি সামলাতে চাইলে, আপনার প্রোগ্রাম ক্র্যাশ না করিয়ে, এই মেথডটি আদর্শ।

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### at() মেথড ব্যবহার করা

`at()` মেথড সরাসরি একটি নির্দিষ্ট ইনডেক্সে থাকা এলিমেন্টের একটি স্ন্যাপশট দেয়, যেখানে `unbox()` অপারেশন ব্যবহার করে বক্স থেকে সংরক্ষিত মানটি বের করা হয়।
এই মেথডের সংক্ষিপ্ত রূপ হলো সাবস্ক্রিপ্টিং অপারেটর `arr[index]` ব্যবহার করা।
যে ইনডেক্স নেই (সীমার বাইরে) সেটি অ্যাক্সেস করার চেষ্টা করলে প্রোগ্রামটি একটি এরর নিয়ে প্যানিক করবে।

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## আকার সম্পর্কিত মেথড

অ্যারেতে কতটি এলিমেন্ট আছে তা জানতে `len()` মেথড ব্যবহার করুন।
এর রিটার্ন ভ্যালুর টাইপ `usize`.

অ্যারে খালি কি না তা যাচাই করতে চাইলে আপনি `is_empty()` মেথড ব্যবহার করতে পারেন, যা অ্যারে খালি থাকলে `true` এবং অন্যথায় `false` রিটার্ন করে।

## `Span`

`Span` হলো একটি স্ট্রাক্ট, যা একটি `Array`-এর স্ন্যাপশট উপস্থাপন করে।
এটি মূল অ্যারে পরিবর্তন না করেই অ্যারের এলিমেন্টগুলোতে নিরাপদ ও নিয়ন্ত্রিত অ্যাক্সেস দেওয়ার জন্য তৈরি।
ফাংশনের মধ্যে অ্যারে পাস করার সময় বা শুধু পড়ার অপারেশন করার সময় ডেটার অখণ্ডতা নিশ্চিত করা ও বরো সংক্রান্ত সমস্যা এড়াতে `Span` বিশেষভাবে কাজে লাগে।

> `Array`-এর দেওয়া সব মেথড `Span`-এর সাথেও ব্যবহার করা যায়, শুধু `append()` মেথডটি ছাড়া।

একটি `Array`-এর `Span` তৈরি করতে `span()` মেথড কল করুন:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## নির্দিষ্ট আকারের `Array` টাইপ

নির্দিষ্ট আকারের অ্যারেতে মানগুলো আমরা তৃতীয় বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা একটি তালিকা হিসেবে লিখি।
অ্যারের টাইপ লেখা হয় তৃতীয় বন্ধনী দিয়ে, যার ভেতরে থাকে প্রতিটি এলিমেন্টের টাইপ, একটি সেমিকোলন এবং শেষে অ্যারেতে এলিমেন্টের সংখ্যা।

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> দ্রষ্টব্য: কেবল নির্দিষ্ট আকারের অ্যারে কনস্ট্যান্ট হিসেবে ব্যবহার করা যায়

নির্দিষ্ট আকারের অ্যারেতে এলিমেন্ট অ্যাক্সেস করা যায় হয় অ্যারেটি ডিকনস্ট্রাক্ট করে, নয়তো এটিকে একটি `Span`-এ রূপান্তর করে, যা ইনডেক্সিং সমর্থন করে।

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
