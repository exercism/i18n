# নির্দেশনা

জাদুকর হতে চলা Elyse তার প্রশিক্ষণ চালিয়ে যাচ্ছেন। তার ট্রিকগুলো দেখানোর জন্য তাকে কার্ডের বেশ কিছু স্তূপ দেওয়া হবে।
কাজটা একটু সহজ করতে তিনি শুধু ১ থেকে ১০ নম্বর কার্ড ব্যবহার করেন।

এই অনুশীলনীতে একটি ভেক্টরের বিষয়বস্তু বিশ্লেষণ করতে বিল্ট-ইন মেথড ব্যবহার করুন।

## 1. একটি কার্ড উপস্থিত আছে কি না তা নির্ধারণ করুন

Elyse নির্ধারণ করতে চান স্ট্যাকে একটি কার্ড উপস্থিত আছে কি না, অর্থাৎ স্ট্যাকে একটি নির্দিষ্ট সংখ্যা আছে কি না।

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. একটি কার্ডের অবস্থান খুঁজে বের করুন

Elyse স্ট্যাকে একটি কার্ডের অবস্থান (ইনডেক্স) জানতে চান।
কার্ডটি স্ট্যাকে না থাকলে `-1` রিটার্ন করুন।

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. প্রতিটি কার্ড জোড় কি না তা নির্ধারণ করুন

Elyse জানতে চান প্রতিটি কার্ড জোড় কি না, অর্থাৎ স্ট্যাকের প্রতিটি সংখ্যা জোড় সংখ্যা কি না।

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. স্ট্যাকে বিজোড় মানের একটি কার্ড আছে কি না যাচাই করুন

Elyse জানতে চান স্ট্যাকে কোনো বিজোড় সংখ্যা আছে কি না।

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. স্ট্যাক থেকে প্রথম বিজোড় কার্ডটি নিন

Elyse জানতে চান প্রথম বিজোড় কার্ডটির মান কত।  
স্ট্যাকে কোনো বিজোড় কার্ড না থাকলে `-1` রিটার্ন করুন।

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. প্রথম জোড় কার্ডটির অবস্থান নির্ধারণ করুন

Elyse জানতে চান প্রথম জোড় কার্ডটির অবস্থান।
স্ট্যাকে কোনো জোড় কার্ড না থাকলে `-1` রিটার্ন করুন।

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
