# পরিচিতি

R-এর আলাদা কোনো সেট ডেটা টাইপ নেই; বরং ভেক্টরের উপর একই ধরনের কাজ করতে এটি নানা ধরনের ফাংশন ব্যবহার করে।

`%in%` অপারেটরটি সেটের সদস্যতা পরীক্ষা করে।

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

প্রাসঙ্গিক ফাংশনগুলোর মধ্যে রয়েছে `unique` (ডুপ্লিকেট সরানোর জন্য), সঙ্গে `union()`, `intersect()`, `setdiff()` এবং `setequal()`, যা সেটের জোড়ার উপর কাজ করে।

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

প্রতিটি ক্ষেত্রেই `set_1` আর `set_2` অপরিবর্তিত থাকে।
