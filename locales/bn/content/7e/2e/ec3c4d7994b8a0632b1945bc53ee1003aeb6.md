# For-Each লুপের পরিচিতি

[for-each লুপ](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) একটি কলেকশনের প্রতিটি এলিমেন্টের জন্য একটি কোড ব্লক চালানোর ব্যবস্থা করে।
কিছু ডকুমেন্টেশন (যেমন Oracle-এর ডকুমেন্টেশন) এদের এনহ্যান্সড for লুপ বলে।

সাধারণ সিনট্যাক্সটি হলো:

```java
for(declaration: collection) {
    body;
}
```

`declaration` অংশটি সেই ভ্যারিয়েবল ডিক্লেয়ার করে, যেটি কলেকশন থেকে অ্যাসাইন হওয়া মানগুলো ধরে রাখে।

`collection` হলো একটি অ্যারে বা কলেকশন, যেটি লুপ ভ্যারিয়েবলে অ্যাসাইন হবে এমন মানগুলো ধরে রাখে।

`body` অংশে সেই স্টেটমেন্টগুলো থাকে, যেগুলো কলেকশনের প্রতিটি মানের জন্য একবার করে চালানো হয়।

উদাহরণস্বরূপ:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

যা আউটপুট দেয়:

```text
a
e
i
o
u
```

সাধারণত নিচের কারণগুলোর জন্য `for` লুপের চেয়ে `for-each` লুপকেই বেশি প্রাধান্য দেওয়া হয়:

- `for-each` লুপ _সব_ মানের উপর ইটারেট করার নিশ্চয়তা দেয়।
- `for-each` লুপ আরও _ডিক্লারেটিভ_; অর্থাৎ কোডটি _কী_ করছে সেটাই বোঝায়, _কীভাবে_ করছে সেটা নয়।
- `for-each` লুপে ভুল হওয়াটা প্রায় অসম্ভব, অথচ `for` লুপে অফ-বাই-ওয়ান এরর হওয়া সহজ ( `<` আর `<=` ব্যবহারের কথা ভাবুন)।
- `for-each` লুপ সব ধরনের কলেকশনে কাজ করে, ইনডেক্স দিয়ে এলিমেন্ট অ্যাক্সেস করা যায় না এমন কলেকশনসহ (যেমন একটি `Set`)।
