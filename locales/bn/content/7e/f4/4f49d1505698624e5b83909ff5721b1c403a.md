# পরিচিতি

Ruby-এর সাথে আসে একটি স্ট্যান্ডার্ড লাইব্রেরি (প্রায়ই সংক্ষেপে "stdlib" বলা হয়): তারিখ, json আর নেটওয়ার্কিংয়ের মতো বিষয় নিয়ে কাজ করার ক্লাসের একটি সংগ্রহ। এটি আপনার কোড নিয়ে কাজ করা সহজ করে তোলার জন্য কিছু দরকারি সুবিধাও দেয়।

`OpenStruct` স্ট্যান্ডার্ড লাইব্রেরির অংশ, আর এটি দিয়ে খুব সহজেই একটি `Hash` থেকে একটি অবজেক্ট তৈরি করা যায়। `Hash` কী (key) দিয়ে অ্যাক্সেস করতে না গিয়ে বরং `OpenStruct`-এ মেথড ব্যবহার করে মান অ্যাক্সেস ও সেট করা যায়।

স্ট্যান্ডার্ড লাইব্রেরি বা অন্য যেকোনো লাইব্রেরির ক্লাস ব্যবহার করতে হলে `require` মেথড দিয়ে সেই ক্লাসটি `require` করতে হয়।

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

এর একটি বোনাস সুবিধা হলো, ব্লক সিনট্যাক্স ব্যবহার করার সময় আপনি একটি শর্টকাটের সুবিধা নিতে পারেন। যেসব ক্ষেত্রে একটি ব্লক কেবল একটি মেথড কল করে, সেখানে ব্লকের বদলে `&:` আর তারপর মেথডের নাম লিখতে পারেন। যেমন, এই দুটি লাইন একই কথা বোঝায়:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
