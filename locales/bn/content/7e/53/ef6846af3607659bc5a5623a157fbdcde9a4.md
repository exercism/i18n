# টার্নারি অপারেটর

টার্নারি কন্ডিশনাল হলো সাধারণ `if/else` স্টেটমেন্ট লেখার একটি ছোট উপায়।
কোনো `if/else` স্টেটমেন্টে যদি কেবল দুটি শাখা থাকে, একটি শর্ত ট্রু হলে আর একটি শর্ত ফলস হলে, তাহলে সেটিকে টার্নারি কন্ডিশনাল হিসেবে আবার লেখা যায়।

টার্নারিগুলো একটি কন্ডিশনাল ভাগ করতে `?` আর `:` চিহ্নের সমন্বয় ব্যবহার করে:
```ruby
condition ? true_branch : false_branch
```

`?`-এর বাম দিকের কোডটি হলো শর্ত, আর ডান দিকের কোডে থাকে দুটি সম্ভাব্য শাখা, যেগুলো `:` দিয়ে আলাদা করা।
শর্তটি যদি _ট্রু_ হয়, তাহলে `:`-এর _বাম_ দিকের কোডটি চালানো হয়।
শর্তটি যদি _ফলস_ হয়, তাহলে `:`-এর _ডান_ দিকের কোডটি চালানো হয়।

যেমন:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

এভাবে আবার লেখা যায়:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
