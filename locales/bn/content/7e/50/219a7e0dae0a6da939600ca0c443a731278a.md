# নির্দেশনা

আপনি একজন উৎসাহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কত পাখি এসেছে তার হিসাব রাখেন।

আপনার সামনে ছয়টি কাজ, সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. আজ কত পাখি এসেছে তা যাচাই করুন

`today()` ফাংশনটি ইমপ্লিমেন্ট করুন, যাতে এটি রিটার্ন করে আজ আপনার বাগানে কত পাখি এসেছে। পাখির সংখ্যাগুলো দিন অনুযায়ী সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরোনো দিনের সংখ্যা আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. আজকের সংখ্যা এক বাড়ান

`increment_todays_count()` ফাংশনটি ইমপ্লিমেন্ট করুন, যাতে আজকের সংখ্যা এক বাড়ে:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. পাখি না আসার কোনো দিন ছিল কি না তা যাচাই করুন

`has_day_without_birds()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `TRUE` রিটার্ন করে যদি এমন কোনো দিন থাকে যেদিন বাগানে শূন্য পাখি এসেছে; অন্যথায় `FALSE` রিটার্ন করে:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. প্রথম নির্দিষ্ট সংখ্যক দিনের জন্য আসা পাখির সংখ্যা হিসাব করুন

`count_for_first_days()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা সপ্তাহের শুরু থেকে আপনার বাগানে আসা পাখির সংখ্যা রিটার্ন করে, তবে হিসাবটি সপ্তাহের শুরু থেকে নির্দিষ্ট সংখ্যক দিনের মধ্যে সীমাবদ্ধ রাখে।

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্য দিনের চেয়ে বেশি ব্যস্ত। ব্যস্ত দিন হলো সেই দিন, যেদিন পাঁচটি বা তার বেশি পাখি আপনার বাগানে এসেছে।
`busy_days()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা ব্যস্ত দিনের সংখ্যা রিটার্ন করে:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. গত সপ্তাহে পাখি আসার চলমান যোগফল হিসাব করুন

এই সপ্তাহে এতক্ষণে মোট কত পাখি এসেছে, তা নিয়ে আপনার কৌতূহল আছে।
প্রতিটি দিনের জন্য ক্রমপুঞ্জিত যোগফল হিসাব করুন।

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. ব্যস্ততার ভিত্তিতে দিনের নামগুলো সাজান

আপনার সন্দেহ, পাখি আসা কাছাকাছি সড়ক যানবাহনের ধরণ দ্বারা প্রভাবিত হয়, তাই ছুটির দিন আর কর্মদিবসে তা আলাদা।

কত পাখি এসেছে তার _অবরোহী_ ক্রমে দিনের সংক্ষিপ্ত রূপগুলো সাজান।

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
