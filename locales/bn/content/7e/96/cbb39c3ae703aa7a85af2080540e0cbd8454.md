# পরিচিতি

## অ্যারে ও ভেক্টর

C++ একই টাইপের এলিমেন্ট একটি নির্দিষ্ট ক্রমে সংরক্ষণ করার জন্য বিভিন্ন কন্টেইনার দেয়। নির্দিষ্ট সাইজের কন্টেইনারের জন্য আছে `std::array`, আর `std::vector` আসে ডাইনামিকভাবে সাইজ বদলানোর সুবিধা নিয়ে।

### কনস্ট্রাকশন

আপনি যখন একটি অ্যারে বা ভেক্টর ডিক্লেয়ার করেন, তখন ওই কন্টেইনারটি কোন টাইপের এলিমেন্ট ধারণ করবে তা উল্লেখ করতে হয়। অ্যারের ক্ষেত্রে সাইজও দিতে হয়।
দুটি কন্টেইনার টাইপ কীভাবে ইনিশিয়ালাইজ করতে হয়, নিচের উদাহরণগুলো দেখুন:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

ভেক্টর সাধারণত বেশি জায়গা নেয়, কারণ এটি আরও বাড়ার জন্য মেমরি অ্যালোকেট করে।
এখানে সাইজ উল্লেখ করার দরকার নেই:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> নোট: টেমপ্লেট কনসেপ্টের পেছনের সঠিক কার্যপ্রণালী এখনই জানার দরকার নেই, সিলেবাসের আরও নিচে এর জন্য আলাদা কনসেপ্ট থাকবে।

### এলিমেন্ট অ্যাক্সেস

এলিমেন্ট অ্যাক্সেস করার জন্য ভেক্টর আর অ্যারে একই ফাংশন ব্যবহার করে।
কন্টেইনারের প্রথম ও শেষ এলিমেন্ট পেতে আপনি মেম্বার ফাংশন `front` আর `back` ব্যবহার করতে পারেন।
নির্দিষ্ট এলিমেন্ট অ্যাক্সেস করার জন্য `at` আর `[]` অপারেটরও আছে।

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> নোট: কন্টেইনারের রেঞ্জের বাইরের কোনো পজিশন বেছে নিলে `[]` আনডিফাইনড বিহেভিয়ারে পৌঁছে দিতে পারে।
> আর `at` ফাংশনটি একটি এক্সেপশন রেইজ করবে, যা দীর্ঘমেয়াদে আপনার জীবন সহজ করে দিতে পারে।

### ভেক্টর মডিফায়ার

`vector`-এর সাইজ নির্দিষ্ট নয়, তাই এলিমেন্ট যোগ করা বা সরিয়ে ফেলা সম্ভব।
এ কাজে ব্যবহৃত দুটি কমন ফাংশন হলো `emplace_back` আর `pop_back`।

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### ক্যাপাসিটি

মেম্বার ফাংশন `empty` দিয়ে কন্টেইনার খালি আছে কিনা যাচাই করতে পারেন।
এলিমেন্টের সংখ্যা জানতে চাইলে `size` ব্যবহার করতে পারেন।
