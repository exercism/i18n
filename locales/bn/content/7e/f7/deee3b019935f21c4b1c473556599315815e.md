# `jq`-এ ফাংশন

আপনি `jq`-এ নিজের **কাস্টম ফাংশন** ডিফাইন করতে পারেন, যাতে আপনার প্রয়োজনীয় যেকোনো লজিক এক জায়গায় গুছিয়ে রাখা যায়।
_ফাংশনগুলো_ বিল্ট-ইনের মতোই কাজ করে: এরা একটি ইনপুট নেয় এবং শূন্য, এক বা একাধিক আউটপুট দেয়।

## একটি ফাংশন ডিফাইন করা

নিচের সিনট্যাক্স ব্যবহার করে আপনি একটি `jq` _ফাংশন_ ডিফাইন করতে পারেন:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- শুরু হয় `def` কিওয়ার্ড দিয়ে,
- ফাংশন বডির আগে একটি কোলন,
- বডিটি একটি একক এক্সপ্রেশন দিয়ে গঠিত,
- শেষ হয় একটি সেমিকোলন দিয়ে,
- `jq` সিনট্যাক্সের বাকি অংশের মতোই, পড়ার সুবিধার জন্য আপনি খুশিমতো হোয়াইটস্পেস ব্যবহার করতে পারেন।

## ফাংশন কোথায় রাখবেন

_ফাংশন_ ব্যবহারের আগে ডিফাইন করা আবশ্যক: নিচেরটি একটি এরর:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

এর মানে হলো, আপনার `jq` কোডের একদম শুরুতে, "মূল" এক্সপ্রেশনের আগে _ফাংশনগুলো_ রাখতে হবে।

### নেস্টেড ফাংশন

_ফাংশনগুলো_ নেস্টেড হতে পারে:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

এখানে `B` _ফাংশনটি_ কেবল `A`-এর বডিতেই দৃশ্যমান।

## স্কোপ

একটি _ফাংশন_ ভ্যারিয়েবল ও নেস্টেড ফাংশনের জন্য একটি নতুন **স্কোপ** তৈরি করে।

## আর্গুমেন্ট

_ফাংশনের_ **আর্গুমেন্টগুলো** আলাদা করা হয় _সেমিকোলন_ দিয়ে, কমা দিয়ে নয়।
যেমন, একটি _ফাংশন_ যা একটি সংখ্যা নেয়, তারপর একটি সংখ্যা যোগ করে এবং একটি সংখ্যা দিয়ে গুণ করে:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

### আর্গুমেন্ট হলো _এক্সপ্রেশন_

ফাংশনের _আর্গুমেন্ট_ মান নয়, ফিল্টার।
এই অর্থে, এরা ঠিক সেভাবেই কাজ করে যেভাবে অন্য ভাষায় কলব্যাককে বোঝানো হয়:

উদাহরণ হিসেবে `add_mul` ফাংশনটি নিন:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

এখানে কী ঘটছে?

- `adder` আর্গুমেন্টটি পায় _এক্সপ্রেশন_ `. + 5`
  - ফাংশন যখন `. + adder` করে, তখন সেটি হয়ে যায় `. + . + 5`
  - `. == 10` হওয়ায় এর মান দাঁড়ায় 25
- একইভাবে, `multiplier` আর্গুমেন্টটি হলো এক্সপ্রেশন `. - 2`
  - এর মান দাঁড়ায় 8
  - তারপর ফলাফল হয় `25 * 8 == 200`

### আর্গুমেন্ট হিসেবে মান

কখনো কখনো আপনি একটি _আর্গুমেন্ট_-কে ভ্যারিয়েবলে "ম্যাটেরিয়ালাইজ" করতে চাইবেন:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

এর একটি শর্টহ্যান্ড আছে:

```jq
def my_func($arg):
    other stuff ...
;
```

খেয়াল রাখবেন, এটি কেবল "সিনট্যাক্টিক সুগার": `$` ছাড়া `arg` নামটিও _ফাংশনের_ ভেতরে স্কোপে থেকেই যায়।

## আরিটি

_ফাংশনের_ একটি **আরিটি** থাকে, অর্থাৎ এরা যত সংখ্যক _আর্গুমেন্ট_ নেয় তার সংখ্যা।

_ফাংশনগুলো_ একই নাম বিভিন্ন _আরিটি_ দিয়ে ব্যবহার করতে পারে।
বিল্ট-ইন [`range`][man-range] ফাংশনটি এর উদাহরণ: `range/1`, `range/2` এবং `range/3` সবই একসাথে থাকতে পারে।

আর্গুমেন্টের মাধ্যমে স্টেট বহন করে এমন রিকার্সিভ ফাংশন ডিফাইনের সময় এটি কাজে লাগতে পারে।
যেমন `map`-কে এভাবে বাস্তবায়ন করা _যেতে পারে_:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## রিকার্সন

`jq` টেল কল অপটিমাইজেশন করে, তবে কেবল ০-আরিটির ফাংশনের জন্য।

## মডিউল

একটি `jq` মডিউল হলো কেবল ফাংশন ধারণ করা একটি ফাইল।
একটি jq প্রোগ্রামে মডিউল যুক্ত করা হয় [`include`][man-include] বা [`import`][man-import] কমান্ড দিয়ে।
