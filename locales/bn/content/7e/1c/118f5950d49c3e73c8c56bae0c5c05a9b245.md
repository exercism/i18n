# নির্দেশাবলি

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার বিন্যাস `"[<LEVEL>]: <MESSAGE>"`।

তিনটি লগ লেভেল আছে: `INFO`, `WARNING` এবং `ERROR`।

আপনার সামনে তিনটি কাজ আছে। প্রতিটি কাজ স্ট্যাক থেকে একটি করে লগ লাইন নেয়।

## 1. একটি লগ লাইন থেকে মেসেজ বের করুন

`message` ডিফাইন করুন যেন এটি লগ লাইনের মেসেজ রিটার্ন করে। শুরু বা শেষে থাকা যেকোনো হোয়াইটস্পেস সরিয়ে ফেলতে হবে।

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. একটি লগ লাইন থেকে লগ লেভেল বের করুন

`log-level` ডিফাইন করুন যেন এটি লগ লাইনের লেভেল ছোট হাতের অক্ষরে রিটার্ন করে।

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. একটি লগ লাইন নতুন করে সাজান

`reformat` ডিফাইন করুন যেন এটি আগে মেসেজ বসায়, আর তার পরে বন্ধনীর মধ্যে ছোট হাতের লগ লেভেল বসায়।

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***নোট:*** এই অনুশীলনীর সব স্ট্রিং ASCII। পরের অনুশীলনীগুলোতে ইউনিকোড-সচেতন স্ট্রিং হ্যান্ডলিং নিয়ে কাজ হবে।
