# সম্পর্কে

Common Lisp-এ সবকিছুই একটি এক্সপ্রেশন।
একটি এক্সপ্রেশন হয় একটি একক জিনিস (যাকে অ্যাটম বলা হয়), নয়তো অনেকগুলো জিনিসের একটি অ্যারে (বন্ধনী দিয়ে ঘেরা: `()`)।

## কোটিং

সব S-এক্সপ্রেশন, সিম্বলের মতো, কোট করা যায়:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

এই কোটিং একটি S-এক্সপ্রেশনের ইভ্যালুয়েশন প্রতিরোধ করে, বরং এটিকে ডেটা হিসেবে গণ্য করে।
এখানে কোটিং নিয়ে আরেকটু বিস্তারিত আলোচনা করা একটি চমৎকার [Stack Overflow-এর উত্তর][so-quoting] রয়েছে।

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
