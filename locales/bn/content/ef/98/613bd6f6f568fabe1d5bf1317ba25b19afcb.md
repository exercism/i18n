# ভূমিকা

## তুলনা

C++-এ আপনি তুলনা অপারেটর ব্যবহার করে মান তুলনা করতে পারেন।

| তুলনা             | অপারেটর   |
| ------------------| --------- |
| সমান              | `==`      |
| সমান নয়           | `!=`      |
| কম                | `<`       |
| কম বা সমান        | `<=`      |
| বেশি              | `>`       |
| বেশি বা সমান      | `>=`      |

এই তুলনাগুলোর ফলাফল সবসময় একটি বুলিয়ান মান:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

`==` এবং `!=` অপারেটর দুটি যথাক্রমে একটি মান অন্য একটি মানের সমান কি না তা যাচাই করে।
এখানে কিছু কমন উদাহরণ রয়েছে:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

অন্য অপারেটরগুলো যাচাই করে একটি মান অন্য একটি মানের চেয়ে বড় (`>`), বড় বা সমান (`>=`), ছোট (`<`), এবং ছোট বা সমান (`<=`) কি না।
এই ধরনের তুলনা সংখ্যা এবং স্ট্রিংয়ের জন্য উপলব্ধ।
স্ট্রিং তুলনা করার সময় অভিধানিক ক্রম (যা লেক্সিকোগ্রাফিক ক্রম নামেও পরিচিত) অনুসরণ করা হয়।

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## If স্টেটমেন্ট

C++-এ কন্ডিশনালগুলো অন্য ভাষার কন্ডিশনালের মতোই।
যেকোনো কন্ডিশনাল অপারেশনের অন্তর্নিহিত টাইপ হলো `bool` টাইপ, যার মান `true` বা `false` হতে পারে।
কন্ডিশনালগুলো প্রায়ই বিভিন্ন শর্ত পরীক্ষা করার জন্য ফ্লো কন্ট্রোলের মাধ্যম হিসেবে ব্যবহৃত হয়।

একটি `if` স্টেটমেন্ট ব্যবহার করা যায়, যা অন্তর্নিহিত শর্তটি `true` হলে তার কোড চালায়, এভাবে:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

একাধিক কেস জড়িত পরিস্থিতিতে অনেক `if` স্টেটমেন্ট `else if` এবং `else` স্টেটমেন্ট ব্যবহার করে একসাথে চেইন করা যায়।

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17 থেকে `if` স্টেটমেন্টে একটি ছোট ইনিশিয়ালাইজেশন স্টেটমেন্টও অন্তর্ভুক্ত করা যায়, যা `if` স্টেটমেন্টের জন্য এক বা একাধিক ভ্যারিয়েবল ইনিশিয়ালাইজ করতে ব্যবহার করা যায়।
উদাহরণস্বরূপ:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> দ্রষ্টব্য: ইনিশিয়ালাইজেশনে তৈরি করা কোনো ভ্যারিয়েবল if স্টেটমেন্টের শেষের পরে অ্যাক্সেস করা যায় না।
