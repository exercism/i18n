# সম্পর্কে

`|>` অপারেটরটিকে পাইপ অপারেটর বলা হয়। এটি দিয়ে একাধিক ফাংশন কল একসাথে জুড়ে দেওয়া যায়, যাতে আগের ফাংশন কল থেকে রিটার্ন করা মানটি পরের ফাংশন কলে পাস হয়।

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

উপরের কোডটি নিচের কোডের সমতুল্য:

```gleam
string.append(string.uppercase("hello"), "?!")
```

পাইপ অপারেটর মানটি হয় ফাংশন কলে প্রথম আর্গুমেন্ট হিসেবে পাস করে, নয়তো নতুন একটি কলে একমাত্র আর্গুমেন্ট হিসেবে পাস করে, যেটির ক্ষেত্রে সঠিক ডেটা টাইপ হবে সেটিই বেছে নেয়।

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

কখনও কখনও আমরা মানটি অন্য একটি অবস্থানে পাস করতে চাই। সেক্ষেত্রে `_` প্লেসহোল্ডার দিয়ে বোঝানো যায় মানটি কোথায় বসানো উচিত।

```gleam
100
|> some_function(1, _, 2)
```
