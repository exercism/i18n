# Debug

বর্তমান টেস্ট-রানার [PonyTest](https://stdlib.ponylang.io/pony_test--index/) ব্যবহার করে, তাই Main অ্যাক্টরটি test.pony ফাইলে থাকে এবং আপনার সমাধানের অংশ হিসেবে এটি এডিট করা উচিত নয়।

Pony অ্যাপ্লিকেশনগুলোতে যেভাবে করা হয় সেটাই অনুসরণ করে, প্রয়োজন না হলে আমরা `Env`-এর অ্যাক্সেস দিই না। এর মানে হলো, প্রায় সব ক্ষেত্রেই আপনি `env.out.print()` দিয়ে printf-স্টাইলের ডিবাগিং করতে পারবেন না।

তবে Pony-তে একটি [debug](https://stdlib.ponylang.io/debug--index/) মডিউল আছে, যা `-d` ফ্ল্যাগ দিয়ে কম্পাইল করা প্রোগ্রামকে `Env`-এর অ্যাক্সেস ছাড়াই STDOUT ও STDERR-এ বিশেষ অ্যাক্সেস দেয়।

আপনার যদি printf-স্টাইলের ডিবাগিং দরকার হয়, তাহলে এই সুবিধাটিই ব্যবহার করুন।

Debug উদাহরণ:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```


একই কোড `-d` ফ্ল্যাগ দিয়ে এবং ছাড়া কম্পাইল করলে:
