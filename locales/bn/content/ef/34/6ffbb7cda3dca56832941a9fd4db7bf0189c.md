# ভূমিকা

## `Base.@kwdef`

ম্যাক্রো `Base.@kwdef` দিয়ে স্বয়ংক্রিয়ভাবে এমন কনস্ট্রাক্টর ডিফাইন করা যায় যা একটি [struct][struct] ডিফাইনের জন্য কিওয়ার্ড আর্গুমেন্ট নেয়।
এটি দিয়ে ফিল্ডের জন্য ডিফল্ট মানও সেট করা যায়।

উদাহরণস্বরূপ, নিচের সংজ্ঞাটি

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

একসাথে তিনটি কনস্ট্রাক্টর ডিফাইন করে

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

যার মধ্যে কিওয়ার্ড আর্গুমেন্টভিত্তিক একটি কনস্ট্রাক্টরও আছে

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

অথচ সাধারণ সংজ্ঞাটি

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

শুধু নিচের দুটি ডিফাইন করে

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

আর এর জন্য হাতে করে কিওয়ার্ডভিত্তিক কনস্ট্রাক্টর ডিফাইন করতে হতো।

### `Base.@kwdef` কখন ব্যবহার করবেন?

কিওয়ার্ডভিত্তিক কনস্ট্রাক্টর বিশেষভাবে কাজে লাগে এমন struct তৈরি করতে যেগুলো অনেকগুলো আর্গুমেন্ট নেয়, বিশেষ করে যখন আর্গুমেন্টের টাইপ বা মান আর্গুমেন্টগুলোর অর্থের সাথে সরাসরি সম্পর্কিত নয়।

নিচের সংজ্ঞাটি দেখুন:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

টাইপের সংজ্ঞা না জেনে কোন মানের অর্থ কী তা বোঝা যায় না।
আর সংজ্ঞাটি জানা থাকলেও, ক্রমটি বারবার মিলিয়ে নিতে হতে পারে।

কিন্তু কিওয়ার্ডভিত্তিক কনস্ট্রাক্টর ব্যবহার করলে তাদের অর্থ সঙ্গে সঙ্গে স্পষ্ট হয়ে যায়:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` এক্সপোর্ট করা হয়নি এবং ম্যানুয়ালে ডকুমেন্ট করা নেই, তাই এটি [Julia-এর পাবলিক API][public-api]-এর অংশ নয়।
এর মানে হলো এর ইন্টারফেস কারিগরি দিক থেকে স্থিতিশীল থাকার নিশ্চয়তা নেই এবং Julia-এর মাইনর আপডেটগুলোর মধ্যে এটি বদলে যেতে পারে।

তবে ম্যাক্রোটি পুরো ইকোসিস্টেমে ব্যাপকভাবে ব্যবহৃত হয়, এবং ব্রেকিং পরিবর্তন করে এটিকে বদলে ফেলার সম্ভাবনা কম।
