# ভূমিকা

Swift-এ [`Bool`][bools] নামে একটি বিল্ট-ইন টাইপ আছে, যা দিয়ে সত্য মান বোঝানো হয়: `true` এবং `false`।

## লজিক্যাল অপারেটর

বুলিয়ান এক্সপ্রেশন একত্রে জুড়তে ও মূল্যায়ন করতে Swift তিনটি [লজিক্যাল অপারেটর][logical-operators] (`!`, `&&` এবং `||`) দেয়।

### লজিক্যাল AND (`&&`)

[_and_ অপারেটর][and] (`&&`) `true` রিটার্ন করে কেবল তখনই, যখন দুই অপারেন্ডই `true`।
যেকোনো একটি অপারেন্ড `false` হলে এটি `false` রিটার্ন করে।
`&&` চিহ্নের দুই পাশে একটি এক্সপ্রেশন বা বুলিয়ান মান বসান:

```swift
true && true  // true
true && false // false
```

### লজিক্যাল OR (`||`)

[_or_ অপারেটর][or] (`||`) `true` রিটার্ন করে যদি অপারেন্ডগুলোর **অন্তত একটি** `true` হয়।
দুই অপারেন্ডই `false` হলে এটি কেবল তখনই `false` রিটার্ন করে।
`||` চিহ্নের দুই পাশে একটি এক্সপ্রেশন বা বুলিয়ান মান বসান:

```swift
true || true   // true
true || false  // true
false || false // false
```

### লজিক্যাল NOT (`!`)

[_not_ অপারেটর][not] (`!`) একটি বুলিয়ান মান উল্টে দেয়।
মানটি `false` হলে এটি `true` রিটার্ন করে, আর মানটি `true` হলে `false`।
`!` অপারেটরটি মান বা এক্সপ্রেশনের ঠিক আগে বসান:

```swift
!true  // false
!false // true
```

## বন্ধনী (`()`) ব্যবহার

এক্সপ্রেশনগুলো গ্রুপ করতে এবং মূল্যায়নের ক্রম নিয়ন্ত্রণ করতে আপনি [বন্ধনী][explicit-parentheses] ব্যবহার করতে পারেন।
Swift-এ বন্ধনীর ভেতরের এক্সপ্রেশনগুলো আগে মূল্যায়ন করা হয়:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

বন্ধনী দিয়ে গ্রুপ করলে এটিও নির্ধারিত হয়, জটিল এক্সপ্রেশনে NOT অপারেটর কীভাবে প্রয়োগ হবে:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
মূল্যায়নের ক্রম স্পষ্ট করতে বা জটিল শর্তগুলো পড়তে সহজ করতে বন্ধনী ব্যবহার করুন।
ডিফল্ট অগ্রাধিকার আগে থেকেই স্পষ্ট হলে অপ্রয়োজনীয় বন্ধনী যোগ করা এড়িয়ে চলুন।
