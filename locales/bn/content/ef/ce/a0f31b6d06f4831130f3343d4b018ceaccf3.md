# বুল

Crystal-এ [`Bool`][bools] নামে একটি টাইপ আছে।
এটি `true` ও `false` মান প্রকাশ করে।

## লজিক্যাল অপারেটর

Crystal-এ তিনটি লজিক্যাল অপারেটর আছে (`!`, `||`, `&&`), যেগুলো বুলগুলোকে একসাথে মিলিয়ে এমন এক্সপ্রেশন তৈরি করে যেগুলো ভিন্ন ভিন্ন মান দেয়।

### এবং (`&&`)

Crystal-এ [_এবং_ অপারেটরটি][and] `&&` দিয়ে প্রকাশ করা হয় এবং দুটি মানই `true` হলে `true` রিটার্ন করে; অন্যথায় `false` রিটার্ন করে।
_এবং_ অপারেটর ব্যবহার করার সময় `&&`-এর ডান দিকে একটি বুল এবং বাম দিকে আরেকটি বসানো হয়।

```crystal
true && true
# => true

true && false
# => false
```

### অথবা (`||`)

Crystal-এ [_অথবা_ অপারেটরটি][or] `||` দিয়ে প্রকাশ করা হয় এবং দেওয়া মানগুলোর মধ্যে **অন্তত একটি** `true` হলে `true` রিটার্ন করে।
দুটি মানই `false` হলে এটি `false` রিটার্ন করে।
_অথবা_ অপারেটর ব্যবহার করার সময় `||`-এর ডান দিকে একটি বুল এবং বাম দিকে আরেকটি বসানো উচিত।

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### নয় (`!`)

Crystal-এ _নয়_ অপারেটরটি `!` দিয়ে প্রকাশ করা হয় এবং দেওয়া বুলটি `false` হলে `true` রিটার্ন করে, আর `true` দিলে `false` রিটার্ন করে।
_নয়_ অপারেটর ব্যবহার করার সময় অপারেটরের (`!`) পরে একটি বুল বসানো উচিত।

```crystal
!true
# => false

!false
# => true
```

## বন্ধনী (`()`) ব্যবহার করা

বুলিয়ান নিয়ে কাজ করার সময় কোন বুলগুলো আগে মূল্যায়ন করা হবে তা ঠিক করতে আপনি বন্ধনী ব্যবহার করতে পারেন।
বন্ধনী কীভাবে ব্যবহার করা হয়েছে তার উপর নির্ভর করে ফলাফল আলাদা হতে পারে।
Crystal-এ বন্ধনীর ভিতরের অংশ আগে মূল্যায়ন করা হয়।

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

যেহেতু বন্ধনীর ভিতরের অংশ আগে মূল্যায়ন করা হয়, তাই পরের উদাহরণে _নয়_ অপারেটর বন্ধনীর ভিতরের এক্সপ্রেশনের উপর প্রয়োগ হবে।

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
বন্ধনী শুধু তখনই ব্যবহার করা উচিত যখন সেগুলো ফলাফলকে প্রভাবিত করে; অন্যথায় সেগুলো বাদ দেওয়া উচিত।
~~~~

## ট্রুথি এবং ফলসি

Crystal-এ "ফলসি" মানগুলো হল: `false`, `nil` আর নাল পয়েন্টার; **বাকি সবকিছু** "ট্রুথি"।
এই মানগুলো উপরে উল্লেখ করা লজিক্যাল অপারেটরগুলোর সাথে ব্যবহার করা যায়।

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## বুলিয়ান নিয়ে মেথডের নামকরণের রীতি

Crystal-এ ট্রুথি বা ফলসি মান রিটার্ন করে এমন মেথডের নামের শেষে সাধারণত একটি প্রশ্নচিহ্ন (`?`) দেওয়া হয়।
বেশিরভাগ ক্ষেত্রেই এই মেথড একটি বুল মান রিটার্ন করে, তবে সবসময় তা করতে হয় না।
এর মানে হল, যেখানে ট্রুথি বা ফলসি মান প্রত্যাশিত সেখানে এই মেথড ব্যবহার করা যায়, যেমন একটি `if` স্টেটমেন্টের শর্ত হিসেবে:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

নামের শেষে প্রশ্নচিহ্ন আছে কিন্তু বুল মান রিটার্ন করে না এমন মেথডগুলো প্রায়ই বদলে `nil` রিটার্ন করে। `nil` _অন্য ভাষার `None` বা `null`-এর মতো_।
