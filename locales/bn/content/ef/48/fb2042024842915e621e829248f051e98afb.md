### পরিভাষা

`Vector{T}` হলো এক-মাত্রিক অ্যারে `Array{T, 1}`-এর একটি অ্যালিয়াস।

## পেয়ার

একটি `Pair` হলো এমন একটি ডেটা স্ট্রাকচার, যাতে ঠিক দুটি এলিমেন্ট থাকে, আর এগুলো `first` ও `second` ফিল্ডের মাধ্যমে অ্যাক্সেস করা যায়।

এগুলো `x => y` ব্যবহার করে তৈরি করা যায়:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

একটি `Pair`-এর এলিমেন্টগুলো ভিন্ন ভিন্ন টাইপের হতে পারে:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Julia-তে `Pair`-এর দুটি কমন ব্যবহার রয়েছে: ডিকশনারি আর রিপ্লেসমেন্ট।

### ডিকশনারি

পেয়ারগুলোর একটি কালেকশন থেকে ডিকশনারি তৈরি করা যায়।
এটি পরে আরেকটি অনুশীলনীতে আলোচনা করা হবে।

### রিপ্লেসমেন্ট

অনেক রিপ্লেসমেন্ট মেথড আর্গুমেন্ট হিসেবে একটি `Pair` নেয়, যাতে কোন এলিমেন্টটি রিপ্লেস করা হচ্ছে তা স্পষ্ট বোঝা যায়।
এর ফলে নিচের মতো সিনট্যাক্স লেখা যায়

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

যেখানে কালেকশনের প্রতিটি `4`-কে `0` দিয়ে রিপ্লেস করা হয়, নিচের কম স্পষ্ট সিনট্যাক্সটির বদলে

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
