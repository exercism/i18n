# ভূমিকা

C#-এ এক্সসেপশন রানটাইমে ঘটে যাওয়া এরর পরিস্থিতি সামলানোর একটি সুবিন্যস্ত, অভিন্ন ও টাইপ-সেফ উপায় দেয়। অ্যাপ্লিকেশন ক্র্যাশ আটকাতে চাইলে এক্সসেপশন ও এরর ঠিকভাবে সামলানো গুরুত্বপূর্ণ।

C#-এ সব এক্সসেপশনের বেস টাইপ হলো `System.Exception` ক্লাস। এতে `Message`-এর মতো গুরুত্বপূর্ণ প্রপার্টি থাকে, যেখানে এক্সসেপশনটি কেন থ্রো করা হয়েছে তার মানুষের পড়ার মতো বিবরণ থাকে।

কোডের নির্দিষ্ট কোনো অংশে একটি এরর আছে বোঝাতে হলে নতুন একটি এক্সসেপশন অবজেক্ট তৈরি করে `throw` কিওয়ার্ড দিয়ে থ্রো করতে হয়:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

কোনো এক্সসেপশন থ্রো হলে, সেই এক্সসেপশন সামলানোর দায়িত্বে থাকা কোড খুঁজে বের করা রানটাইমের কাজ। যদি উপযুক্ত কোনো হ্যান্ডলার না পাওয়া যায়, তাহলে প্রোগ্রামের এক্সিকিউশন বন্ধ করার পাশাপাশি রানটাইম আনহ্যান্ডেলড এক্সসেপশনের বার্তাটি দেখায়।

এক্সসেপশনের জন্য হ্যান্ডলার তৈরি করতে C# try-catch স্টেটমেন্ট ব্যবহার করে, যা একটি `try` ব্লক আর এক বা একাধিক `catch` ক্লজ নিয়ে গঠিত। `try` ব্লকে সেই কোড থাকা ও পাহারা দেওয়া উচিত, যা থেকে এক্সসেপশন থ্রো হতে পারে। `catch` ক্লজগুলোতে সেই কোড থাকা উচিত, যা এরর ঘটার পর প্রোগ্রামের আচরণ সামলায়। খেয়াল রাখা জরুরি যে `try` ব্লকের পর এক্সসেপশনগুলোর ক্রম গুরুত্বপূর্ণ, কারণ একাধিক এক্সসেপশন তালিকাভুক্ত থাকলে প্রথম মিলে যাওয়া `catch` ক্লজটি এক্সিকিউট হয়।

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
