# নির্দেশনার সংযোজন

## ট্র্যাক-নির্দিষ্ট নির্দেশনা

ঐতিহাসিকভাবে Elm ফাংশনাল রিঅ্যাকটিভ প্রোগ্রামিং ব্যবহার করত, পরে তা Elm Architecture ব্যবহারে বিশেষায়িত হয়।

এই অনুশীলনীটি এমনভাবে সমাধান করুন যেন আপনি Elm Architecture ব্যবহার করে একটি ওয়েব অ্যাপ লিখছেন।
প্রোগ্রামের আউটপুট হবে HTML, যার গঠন হবে নিম্নরূপ

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

যেখানে `<dl>` হলো description list এলিমেন্ট, `<dt>` হলো description term এলিমেন্ট এবং `<dd>` হলো description details এলিমেন্ট, সবই স্ট্যান্ডার্ড HTML এলিমেন্ট।

কোনো এরর হলে আউটপুটের গঠন হবে নিম্নরূপ

```html
<div>
  <p>error message</p>
</div>
```
