# বিবরণ

এই অনুশীলনীতে আপনি একটি সহায়ক প্রোগ্রাম তৈরি করবেন, যাতে ব্যান্ডগুলোর মান আপনাকে মনে রাখতে না হয়।
প্রোগ্রামটি ইনপুট হিসেবে ১, ৪ বা ৫টি রঙ নেবে এবং ohms এককে সঠিক মান আউটপুট দেবে।
রঙের ব্যান্ডগুলো এভাবে এনকোড করা হয়:

| রঙ  | মান |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

[`Resistor Color Trio`][resistor-color-trio-exercise] অনুশীলনীতে আপনি প্রথম তিনটি রঙের ব্যান্ড ডিকোড করেছিলেন।
যেমন: orange-orange-brown রূপান্তরিত হয় মূল মান `330`-এ।
এই অনুশীলনীতে আপনাকে এর সঙ্গে _টলারেন্স_ যোগ করতে হবে।
টলারেন্স মানে হলো, একটি মান মূল মান থেকে সর্বোচ্চ কতটা বেশি বা কম হতে পারে।
যেমন, শেষ ব্যান্ডটি যদি green হয়, তবে সর্বোচ্চ টলারেন্স হবে `±0.5%`।

টলারেন্স ব্যান্ডের মান নিচের যেকোনো একটি হবে:

| রঙ  | টলারেন্স |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

চার ব্যান্ডের রেজিস্টরটি এভাবে গঠিত হয়:

| ব্যান্ড_১  | ব্যান্ড_২  | ব্যান্ড_৩     | ব্যান্ড_৪    |
| ------- | ------- | ---------- | --------- |
| মান_১ | মান_২ | মাল্টিপ্লায়ার | টলারেন্স |

উদাহরণ:

- orange-orange-brown-green-এর মান হবে `330` ohms, টলারেন্স `±0.5%`।
- orange-orange-red-grey-এর মান হবে `3300` ohms, টলারেন্স `±0.05%`।

চার ব্যান্ড ও পাঁচ ব্যান্ডের রেজিস্টরের মধ্যে পার্থক্য হলো, পাঁচ ব্যান্ডের রেজিস্টরে আরও নির্ভুল মান বোঝানোর জন্য একটি বাড়তি ব্যান্ড থাকে।

| ব্যান্ড_১  | ব্যান্ড_২  | ব্যান্ড_৩  | ব্যান্ড_৪     | ব্যান্ড_৫    |
| ------- | ------- | ------- | ---------- | --------- |
| মান_১ | মান_২ | মান_৩ | মাল্টিপ্লায়ার | টলারেন্স |

উদাহরণ:

- orange-orange-orange-black-green-এর মান হবে `333` ohms, টলারেন্স `±0.5%`।
- orange-red-orange-blue-violet-এর মান হবে `323 million` ohms, টলারেন্স `±0.1%`।

এক ব্যান্ডের রেজিস্টরও আছে।
এক ব্যান্ডের রেজিস্টরে শুধু black রঙটিই থাকে, যার মান 0।

আপনার প্রোগ্রামটি রেজিস্টর ব্যান্ডের রঙগুলোর একটি ইনপুট `list`-কে একটি লেবেলে রূপান্তর করবে:

"... ohms ±...%"

তাই `["orange", "orange", "black", "green"]` ইনপুট `list`-এর জন্য রিটার্ন হবে:

"33 ohms ±0.5%"

মান হাজার হাজার ohms হলে আমরা বলি "kiloohms"।
এটা অনেকটা ১০০০ মিটারের জন্য "kilometer" আর ১০০০ গ্রামের জন্য "kilograms" বলার মতো।

তাই `["orange", "orange", "orange", "grey"]` ইনপুট `list`-এর জন্য রিটার্ন হবে:

"33 kiloohms ±0.05%"

মান মিলিয়ন মিলিয়ন ohms হলে আমরা বলি "megaohms"।

তাই `["orange", "orange", "blue", "red"]` ইনপুট `list`-এর জন্য রিটার্ন হবে:

"33 megaohms ±2%"

[resistor-color-trio-exercise]: https://exercism.org/tracks/python/exercises/resistor-color-trio
