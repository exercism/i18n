# অ্যাবস্ট্র্যাক্ট ক্লাস

একটি সার্কাস শো হলো অ্যাক্টের একটি তালিকা। জাগলিং, ট্র্যাপিজ আর টাম্বলিং আলাদা আলাদা জিনিস, ভেতরের গঠনও আলাদা, কিন্তু রানিং অর্ডার যিনি তৈরি করেন, তাঁর প্রত্যেকটি থেকে দরকার মাত্র দুটি জিনিস: এর নাম কী, আর এতে কত সময় লাগে।

একটি **অ্যাবস্ট্র্যাক্ট ক্লাস** ঠিক ততটুকুই বর্ণনা করে, এর বেশি নয়।

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

এর নাম শুরু হয় `$` দিয়ে। এটি বডি ছাড়া রুটিনের তালিকা দেয়: শুধু সিগনেচার, প্রতিটি সেমিকোলনে গিয়ে শেষ হয়। এটি দিয়ে কিছুই তৈরি করা যায় না, এতে `create` নেই, `new` নেই।

## কনফর্মিং

`<`-এর পরে `$ACT`-এর নাম লিখে একটি বাস্তব ক্লাস প্রতিশ্রুতি দেয় যে সেটি একটি `$ACT`।

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` পড়া হয় "হলো একটি"। অ্যাবস্ট্র্যাক্ট ক্লাস যে যে রুটিনের তালিকা দেয়, ক্লাসটিকে সেগুলোর সবগুলো দিতে হবে, একই আর্গুমেন্ট আর একই রিটার্ন টাইপ নিয়ে। এর একটি বাদ পড়লে সেটি কম্পাইল এরর, রান টাইমে হঠাৎ করা কোনো চমক নয়।

একটি ক্লাস তার ইচ্ছেমতো যা খুশি যোগ করতে পারে। `TRAPEZE` এমন একটি উচ্চতা ধরে রাখতে পারে যা অন্য কোনো অ্যাক্টের নেই; অ্যাবস্ট্র্যাক্ট ক্লাস সেটা জানে না, জানার দরকারও নেই।

## টাইপটি ব্যবহার করা

`$ACT` একটি টাইপ, তাই এটি দিয়ে যেকোনো কিছু ডিক্লেয়ার করা যায়:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

ওই অ্যারেতে একসাথে তিনটি ভিন্ন ক্লাসের অবজেক্ট থাকে, যা একটি `ARRAY{JUGGLING}`-এ সম্ভব নয়।

## ডিসপ্যাচ

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` একটি `$ACT`। কোন `minutes` চলবে, সেটি ঠিক হয় লাইনটি রান হওয়ার সময়, অবজেক্টটি আসলে কী তার ওপর নির্ভর করে: জাগলিংয়ের জন্য `JUGGLING::minutes`, ট্র্যাপিজের জন্য `TRAPEZE::minutes`। এই বেছে নেওয়ার নামই **ডিসপ্যাচ**।

যোগ করার কাজটি করা রুটিন কখনও জিজ্ঞেস করে না, তার হাতে কোন ধরনের অ্যাক্ট এসেছে। চতুর্থ ধরনের একটি অ্যাক্ট যোগ করতে হলে শুধু একটি নতুন ক্লাস লিখতে হয়, আর কিছুই বদলাতে হয় না। এই পদ্ধতিতে কাজ করার পুরো কারণটাই সেটাই।
