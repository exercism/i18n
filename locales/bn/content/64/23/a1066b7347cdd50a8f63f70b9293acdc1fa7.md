# নির্দেশনা

আপনার কাজ হলো মিটিং কখন শুরু হয়েছে তার ভিত্তিতে ডেলিভারি তারিখের বর্ণনাগুলোকে _আসল_ ডেলিভারি তারিখে রূপান্তর করা।

ডেলিভারি তারিখের বর্ণনা দুই ধরনের:

1. স্থির: আগে থেকে নির্ধারিত কিছু শব্দ।
2. পরিবর্তনশীল: যে শব্দগুলোর একটি পরিবর্তনশীল অংশ থাকে, কিন্তু আগে থেকে নির্ধারিত কিছু প্যাটার্ন অনুসরণ করে।

## স্থির ডেলিভারি তারিখের বর্ণনা

স্থির ডেলিভারি তারিখের বর্ণনা তিনটি:

- `"NOW"`
- `"ASAP"` (যত দ্রুত সম্ভব)
- `"EOW"` (সপ্তাহের শেষ)

নিচের টেবিলটি দেখায় সেগুলো কীভাবে রূপান্তর করতে হয়:

| বর্ণনা  | মিটিংয়ের শুরু              | ডেলিভারি তারিখ                        |
| ----------- | ----------------------------- | ----------------------------------- |
| `"NOW"`     | -                             | মিটিং শুরু হওয়ার দুই ঘণ্টা পর        |
| `"ASAP"`    | 13:00-এর আগে                  | আজ 17:00-এ                          |
| `"ASAP"`    | 13:00 বা তার পরে              | আগামীকাল 13:00-এ                     |
| `"EOW"`     | সোমবার, মঙ্গলবার বা বুধবার    | শুক্রবার 17:00-এ                     |
| `"EOW"`     | বৃহস্পতিবার বা শুক্রবার        | রবিবার 20:00-এ                       |

## পরিবর্তনশীল ডেলিভারি তারিখের বর্ণনা

পরিবর্তনশীল ডেলিভারি তারিখের বর্ণনার প্যাটার্ন দুইটি:

- `"<N>M"` (N-তম মাস)
- `"Q<N>"` (N-তম কোয়ার্টার)

| বর্ণনা   | মিটিংয়ের শুরু               | ডেলিভারি তারিখ                                                |
| ----------- | ------------------------- | --------------------------------------------------------- |
| `"<N>M"`    | N-তম মাসের আগে             | এই বছরের N-তম মাসের _প্রথম_ কর্মদিবসে 8:00-এ                 |
| `"<N>M"`    | N-তম মাসের পরে বা সেই মাসে | আগামী বছরের N-তম মাসের _প্রথম_ কর্মদিবসে 8:00-এ             |
| `"Q<N>"`    | N-তম কোয়ার্টারের আগে বা সেই কোয়ার্টারে | এই বছরের N-তম কোয়ার্টারের _শেষ_ কর্মদিবসে 8:00-এ |
| `"Q<N>"`    | N-তম কোয়ার্টারের পরে      | আগামী বছরের N-তম কোয়ার্টারের _শেষ_ কর্মদিবসে 8:00-এ         |

~~~~exercism/note
কর্মদিবস হলো সোমবার, মঙ্গলবার, বুধবার, বৃহস্পতিবার বা শুক্রবার।

এক বছরে চারটি কোয়ার্টার থাকে, প্রতিটিতে তিনটি মাস:
1. জানুয়ারি/ফেব্রুয়ারি/মার্চ
2. এপ্রিল/মে/জুন
3. জুলাই/আগস্ট/সেপ্টেম্বর
4. অক্টোবর/নভেম্বর/ডিসেম্বর।
~~~~
