# নির্দেশনার সংযোজন

## আউটপুট ফরম্যাট

প্রোটিন সিকোয়েন্সটি একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে আউটপুট করুন, যেখানে প্রতিটি প্রোটিনের পরে একটি নিউলাইন ক্যারেক্টার থাকবে।

একটি উদাহরণ আউটপুট হবে `"Methionine\nPhenylalanine\nSerine\n"`

ইনপুটটি অবৈধ হলে একটি খালি স্ট্রিং আউটপুট করুন।

## রেজিস্টার

| রেজিস্টার | ব্যবহার        | টাইপ    | বিবরণ                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং  |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং |
| `$t0-9`  | টেম্পোরারি    | যেকোনো   | সাময়িক স্টোরেজের জন্য ব্যবহৃত |
