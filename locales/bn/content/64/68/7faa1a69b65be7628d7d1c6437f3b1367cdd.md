# নির্দেশাবলির সংযোজন

## বাস্তবায়ন

Cost নামে একটি মাত্র Go func ডিফাইন করুন, যা নির্ধারিত ডিসকাউন্টের ভিত্তিতে দেওয়া বইয়ের তালিকার খরচ হিসাব করে।

func Cost-এর জন্য নিচের সিগনেচারটি ব্যবহার করুন:

```go
func Cost(books []int) int
```

Cost সেন্টে মোট খরচ (ডিসকাউন্টের পরে) রিটার্ন করবে।
উদাহরণস্বরূপ, একটি বইয়ের জন্য খরচ ৮০০ সেন্ট, যা $8.00-এর সমান।
এই অনুশীলনীর জন্য কেবল ইন্টিজার হিসাবই প্রয়োজন।
