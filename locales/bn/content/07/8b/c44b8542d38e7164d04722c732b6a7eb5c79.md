# অনুশীলনীর test

একটি অনুশীলনীর সমাধান তৈরি করতে এবং স্থানীয়ভাবে সেটি test করতে নিচের ধাপগুলো অনুসরণ করুন।

## অনুশীলনীটি ডাউনলোড করুন

একটি Command Prompt খুলুন এবং পছন্দের অনুশীলনীটির নাম দিয়ে নিচের কমান্ডটি চালিয়ে সেটি ডাউনলোড করুন।

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## নিজের সমাধান তৈরি করুন

1. সদ্য ডাউনলোড করা অনুশীলনীর ডিরেক্টরিতে যেতে নিচের কমান্ডটি চালান।

     >**টিপ:** নিচের কমান্ডে ডিরেক্টরির অবস্থান নির্ভর করে আপনার OS এবং আপনার কনফিগার করা Exercism ওয়ার্কস্পেসের উপর। `exercism configure` কমান্ডটি চালিয়ে আপনি আপনার ওয়ার্কস্পেসের অবস্থান জানতে পারবেন।

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. দেওয়া নির্দেশনা অনুসরণ করে অনুশীলনীটির একটি সমাধান তৈরি করুন।

## নিজের সমাধান test করুন

কিছু Ballerina অনুশীলনীতে একটি মাত্র test থাকে, আবার কিছুতে একাধিক test থাকে। test-গুলো অনুশীলনীর রুট ডিরেক্টরির ভেতরের `/tests` ডিরেক্টরির সংশ্লিষ্ট test ফাইলে পাওয়া যাবে।

### একটি test আছে এমন অনুশীলনী test করা

অনুশীলনীর test চালাতে নিচের কমান্ডটি দিন।

ডিফল্টভাবে শুধু প্রথম test-টি সক্রিয় থাকে। এটি ইচ্ছাকৃত, কারণ এতে আপনি শুধু ওই একটি test পাস করানোর দিকেই মনোযোগ দিতে পারেন। 
     
```sh
bal test
```

### একাধিক test আছে এমন অনুশীলনী test করা

একাধিক test আছে এমন একটি অনুশীলনী test করতে নিচের ধাপগুলো অনুসরণ করুন।

1. প্রথম test-টি পাস হয়ে গেলে `@test:Config` অ্যানোটেশন থেকে `enable: false` প্রপার্টিটি সরিয়ে পরের test-টি সক্রিয় করুন।

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  সক্রিয় করা test-টি চালাতে নিচের কমান্ডটি চালান।

   ```sh
     bal test
   ```

3. বাকি test-গুলো সক্রিয় করতে উপরের দুইটি ধাপ আবার করুন।

সব test সক্রিয় করে এবং আপনার ইমপ্লিমেন্টেশন যে প্রতিটি test পাস করে তা নিশ্চিত করার মাধ্যমে আপনি অনুশীলনীটি সফলভাবে সম্পন্ন করেছেন।
