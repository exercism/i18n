# পরিচিতি

মূলত দুই ধরনের লুপ আছে:

1. কোনো শর্ত পূরণ হওয়া পর্যন্ত লুপ চালানো।
2. কোনো কালেকশনের এলিমেন্টগুলোর উপর দিয়ে লুপ চালানো।

দুটোই [R-এ সম্ভব][web-loops], তবে প্রথমটি বেশি কমন হতে পারে।

## `while` ও `repeat`

যেসব খোলা-মাথা সমস্যায় লুপটি কতবার ঘুরবে তা আগে থেকে জানা থাকে না, সেগুলোর জন্য R-এ আছে শর্তযুক্ত [`while`][ref-control] লুপ, আর শর্তহীন [`repeat`][ref-control] লুপ (`while (TRUE)`-এর সমতুল্য)।

মূল রূপটি বেশ সহজ:

```R
while (condition) {
  do_something()
}
```

এক্ষেত্রে `condition` আর `TRUE` না থাকা পর্যন্ত প্রোগ্রামটি লুপে ঘুরতেই থাকবে।

লুপ থেকে আগেভাগে বেরিয়ে আসার দুটি উপায় আছে:

- একটি `break` লুপটি থেকে বেরিয়ে আসে, আর এক্সিকিউশন লুপের ক্লোজিং ব্রেস `}`-এর পরের লাইনে গিয়ে চলতে থাকে।
- একটি `return(x)` বর্তমান ফাংশনের এক্সিকিউশন থামিয়ে দেয়, আর রিটার্ন ভ্যালু `x` যে ফাংশনটি কল করেছে তার কাছে ফিরিয়ে দেয়।

এই সুবিধাগুলো থাকলে মাঝে মাঝে `repeat { ... }` দিয়ে একটি "অসীম" লুপ বানিয়ে, তারপর লুপ বডির ভেতরে থামার শর্ত খুঁজে পেয়ে `break` বা `return` চালু করা সুবিধাজনক হতে পারে।

এই তিনটি ভ্যারিয়েন্ট সমতুল্য এবং সবগুলোই `x == 0.4444...` দিয়ে শেষ হয়

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## একটি ভেক্টর (বা অন্য কোনো কালেকশন) এর উপর ইটারেশন

R-এ এটি প্রায়ই দরকার পড়ে না।
অন্য কনসেপ্টগুলোতে আলোচনা করা হয়েছে, অনেক ফাংশনই পুরো ভেক্টরের উপর কাজ করে।

তবে কখনো কখনো স্পষ্ট লুপ এড়ানোর উপায় থাকে না।
বিশেষত যখন:

- লুপ বডির সাইড এফেক্ট থাকে, যেমন প্রিন্ট করা বা ফাইল I/O।
- আগে থেকে অনুমান করা যায় না এমন সংখ্যক ইটারেশনের পর কোনো একটি মাপকাঠিতে পৌঁছানো পর্যন্ত লুপ চলতে থাকে।

লুপের শর্ত অবশ্যই বন্ধনীর ভেতরে থাকতে হবে।
ফাংশন বডির মতোই, এক লাইনের লুপ বডির ক্ষেত্রে ব্রেস ঐচ্ছিক (তবে প্রায়ই দেওয়া হয়)।

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

যদি বর্তমান ইটারেশন কোনো শর্ত পূরণ করতে না পারে, তবে `next` দিয়ে সঙ্গে সঙ্গে পরের ইটারেশনে চলে যাওয়া যায়:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

সংখ্যাগত ইনডেক্স দরকার হলে [`seq_along()`][ref-seq_along] ব্যবহার করুন।

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)` ব্যবহার করা _সুপারিশ করা হয় না_, কারণ `length(v)` শূন্য হলে এটি সমস্যা তৈরি করতে পারে।
`1:0` রেঞ্জটি `c(1, 0)`-এর সমতুল্য, তাই লুপ বডি এক্সিকিউট হবে এবং সম্ভবত ফেল করবে।
এই পরিস্থিতিটি সঠিকভাবে সামলানোর জন্যই `seq_along()` ফাংশনটি তৈরি।
