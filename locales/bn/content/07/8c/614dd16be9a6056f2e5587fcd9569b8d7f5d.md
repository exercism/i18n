# নির্দেশাবলি

নির্ধারণ করুন, তিনটি ডমিনোর একটি প্রদত্ত সেট এমনভাবে সাজানো সম্ভব কি না, যাতে সেগুলো একটি সঠিক ডমিনো চেইন তৈরি করে (একটি টাইলের এক অর্ধেকের বিন্দু প্রতিবেশী টাইলের সংলগ্ন অর্ধেকের বিন্দুর সাথে মেলে) এবং যে টাইলগুলোর কোনো প্রতিবেশী নেই (প্রথম ও শেষ টাইল), সেগুলোর অর্ধেকের বিন্দু পরস্পরের সাথে মেলে। কিছু টেস্ট কেসে চেইন সমাধানে একই টাইল পুনরাবৃত্ত হতে পারে। একটি সঠিক ডমিনো চেইন সাজানো গেলে `True` রিটার্ন করুন, অন্যথায় `False`.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
