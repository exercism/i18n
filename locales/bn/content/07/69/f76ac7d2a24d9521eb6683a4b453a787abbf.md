# ভালো একটি সহায়তার অনুরোধ কীভাবে লিখবেন

Exercism-এর কোনো ক্ষেত্রে সাহায্য দরকার?

ভালো একটি সহায়তার অনুরোধ কীভাবে লিখতে হয় তা শিখে, আর আমাদের কমিউনিটিকে আপনাকে সাহায্য করতে উৎসাহ দিয়ে, ভালো উত্তর পাওয়ার সম্ভাবনা বাড়াতে সাহায্য করুন।

এখানে কয়েকটি গুরুত্বপূর্ণ টিপস দেওয়া হলো।

## ছবি নয়, কোড ব্লক ব্যবহার করুন

আপনি যখন কোড শেয়ার করতে চান (সেটি আপনার নিজের লেখা কোড হোক বা কোনো নির্দেশনা), তখন ছবি নয়, কোড ব্লক ব্যবহার করুন।

ডেভেলপার হিসেবে আমরা কোড পড়েই অনেক দ্রুত বুঝে ফেলি, কিন্তু কিছু দেখতে হলে ছবিতে জুম করতে হয়।
আর আমাদের অনেক ব্যবহারকারী স্ক্রিন রিডার ব্যবহার করেন, যা ছবি পড়ে শোনাতে পারে না।
তাই আপনি যদি একজন ভালো কমিউনিটি সদস্য হতে চান, আমাদের স্বেচ্ছাসেবকদের আপনাকে সাহায্য করতে উৎসাহ দিতে চান, আর পেশাদার দেখাতে চান, তাহলে কোড ছবি হিসেবে নয়, টেক্সট হিসেবে শেয়ার করুন!

উদাহরণস্বরূপ, আপনি এভাবে লিখতে পারেন:

````
```
for number in range(10):
  total += number;
```
````

এটি তখন এভাবে রেন্ডার হবে:

```
for number in range(10):
  total += number;
```

কোড ব্লকের শুরুতে ভাষার নাম যোগ করলে আপনি সিনট্যাক্স হাইলাইটিংও পেতে পারেন:

````
```python
for number in range(10):
  total += number;
```
````

যা হয়ে যায়:

```python
for number in range(10):
  total += number;
```

## অন্তর্ভুক্তিমূলক ভাষা ব্যবহার করুন

Exercism গড়ে উঠেছে ভিন্ন ভিন্ন জেন্ডারের মানুষ নিয়ে।
আপনি যদি আমাদের Discord-এ এসে "Hey boys" জাতীয় কথা বলেন, তাহলে আপনি সঙ্গে সঙ্গে আমাদের কমিউনিটির অর্ধেককে বাদ দিয়ে দিচ্ছেন।
এতে ওই অর্ধেক মানুষ আপনার সাহায্য করার সম্ভাবনা কমে যায়, আর বাকি কমিউনিটিও আপনার সাহায্য করতে কম আগ্রহী হবে, কারণ Exercism-এ আমরা অন্তর্ভুক্তিকে মূল্য দিই।

তাই আপনি যদি সাহায্য পেতে চান, আর একজন ভালো মানুষ হতে চান, তাহলে লিঙ্গভিত্তিক ভাষা ব্যবহার করবেন না।
"Hey folks", "Hey everyone" বলে দেখুন, কিংবা আরও সাহস দেখিয়ে বেছে নিন "Hey fellow Exercists!"
