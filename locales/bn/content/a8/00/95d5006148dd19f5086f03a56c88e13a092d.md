# স্পষ্ট রিটার্ন

মেথডটি সরল করতে স্পষ্ট রিটার্নটি মুছে ফেলুন।

রুবিতে একটি মেথড সর্বশেষ এক্সিকিউট হওয়া স্টেটমেন্টের ফলাফল রিটার্ন করে। তাই মেথড থেকে আগেভাগে রিটার্ন করার দরকার না থাকলে `return` কিওয়ার্ড স্পষ্টভাবে ব্যবহার করার প্রয়োজন নেই।

উদাহরণস্বরূপ, এটি `16` প্রিন্ট করবে, কারণ `multiply` মেথডটি তার শেষ এক্সপ্রেশনের ফলাফল, অর্থাৎ `a * b`, রিটার্ন করে।

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
