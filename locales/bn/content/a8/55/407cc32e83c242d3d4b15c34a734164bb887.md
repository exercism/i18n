# সম্পর্কে

কনস্ট্যান্ট হলো এমন মান যা কম্পাইল টাইমে নির্ধারিত হয় এবং যা পুনরায় অ্যাসাইন করা যায় না।
একটি একক কনস্ট্যান্ট ডিক্লেয়ার করতে `const` কিওয়ার্ডটি ব্যবহার করুন:

```go
const greeting = "hello"
```

একাধিক কনস্ট্যান্ট একটি ব্লকে ডিক্লেয়ার করা যায়।
একটি ব্লকের ভেতরে, স্পষ্টভাবে মান না দেওয়া কোনো কনস্ট্যান্ট আগের এক্সপ্রেশনটিই পুনরাবৃত্তি করে:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

কনস্ট্যান্ট সাধারণত প্যাকেজ লেভেলে ডিক্লেয়ার করা হয়, তবে ফাংশনের ভেতরেও ডিক্লেয়ার করা যায়।

## টাইপড ও আনটাইপড কনস্ট্যান্ট

টাইপ উল্লেখ না করে কনস্ট্যান্ট ডিক্লেয়ার করলে সেটি আনটাইপড হয়ে যায়।
আনটাইপড কনস্ট্যান্টের কোনো নির্দিষ্ট টাইপ থাকে না; এর মানই ঠিক করে দেয় এটি কোন কোন টাইপের সাথে সামঞ্জস্যপূর্ণ।
যতক্ষণ অন্তর্নিহিত মানটি সামঞ্জস্যপূর্ণ থাকে, ততক্ষণ কম্পাইলার প্রতিটি ব্যবহারে এটিকে প্রয়োজনীয় টাইপে রূপান্তর করে দেবে:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

টাইপড কনস্ট্যান্ট ডিক্লারেশনের সময়ই টাইপ স্থির করে দেয়:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## কী কী কনস্ট্যান্ট হতে পারে

কনস্ট্যান্ট শুধু বুলিয়ান, সংখ্যা, স্ট্রিং আর রুন ধারণ করতে পারে।
যেহেতু মানগুলো কম্পাইল টাইমে নির্ধারিত হয়, তাই কোনো ফাংশন কলের ফলাফল কনস্ট্যান্ট হিসেবে ব্যবহার করা যায় না।

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

কনস্ট্যান্টের একটি ব্লকে, `iota` ব্লকের ভেতরে একটি কনস্ট্যান্টের অবস্থান বোঝায়:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

প্রথমটির পরের প্রতিটি কনস্ট্যান্ট একই এক্সপ্রেশন উত্তরাধিকারসূত্রে পায়, আর `iota` এক씩 বাড়ে।

`iota` এক্সপ্রেশনেও কাজ করে।

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
