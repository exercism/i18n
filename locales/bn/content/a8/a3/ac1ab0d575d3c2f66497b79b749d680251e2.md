# পরিচিতি

কোনো লজিক বারবার চালাতে সবচেয়ে বেশি ব্যবহৃত স্টেটমেন্টগুলোর মধ্যে একটি হলো for লুপ।
JavaScript-এ এটি গঠিত হয় `for` কিওয়ার্ড, প্রথম বন্ধনীর ভেতরে মোড়া একটি _হেডার_, আর দ্বিতীয় বন্ধনীর ভেতরে মোড়া একটি কোড ব্লক দিয়ে, যার ভেতরে থাকে লুপের _বডি_।

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

ইনিশিয়ালাইজেশন সাধারণত একটি কাউন্টার ভ্যারিয়েবল তৈরি করে, শর্ত যাচাই করে লুপটি চালিয়ে যাওয়া উচিত নাকি থামানো উচিত, আর স্টেপ প্রতিটি পুনরাবৃত্তির শেষে কাউন্টারটি বাড়ায়।
হেডারের প্রতিটি অংশ সেমিকোলন দিয়ে আলাদা করা হয়।

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

স্টেপ নির্ধারণ করা হয় সাধারণত JavaScript-এর ইনক্রিমেন্ট বা ডিক্রিমেন্ট অপারেটর দিয়ে, যেমনটি উপরের উদাহরণে দেখানো হয়েছে।
এই অপারেটরগুলো একটি ভ্যারিয়েবলকে জায়গাতেই বদলে দেয়।
`++` একটি সংখ্যার সঙ্গে এক যোগ করে, `--` একটি সংখ্যা থেকে এক বিয়োগ করে।

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
