# rescue ছাড়া

ফ্লো কন্ট্রোলের জন্য এক্সেপশন ব্যবহার করবেন না।
`rescue` ব্যবহার না করে এই অনুশীলনীটি সমাধান করার চেষ্টা করুন।

আপনি যদি স্ট্যান্ডার্ড লাইব্রেরির এমন একটি ফাংশন ব্যবহার করেন যার নামের শেষে `!` থাকে (যা এরর রেইজ করে), তাহলে `!` ছাড়া সমতুল্য একটি ফাংশন খুঁজে দেখুন (যা সাধারণত `{:ok, result}` বা `{:error, message}` রিটার্ন করে)।

দ্রষ্টব্য: আপনার সমাধানে এই অটোমেটেড কমেন্টটি দেখলে, অন্য অটোমেটেড কমেন্টগুলো সঠিক নাও হতে পারে।
আগে এই সমস্যাটি ঠিক করুন!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
