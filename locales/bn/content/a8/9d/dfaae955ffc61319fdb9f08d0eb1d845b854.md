# নির্দেশাবলি

আপনি এখন নতুন, অত্যন্ত সমাদৃত গেম **উইংস কোয়েস্ট** তৈরির কাজে নেমেছেন।
গেমটিতে আপনি একটি পাখি, যিনি এদিক-ওদিক ঘুরে বীজ সংগ্রহ করেন।
খেলোয়াড় সব বীজ কুড়িয়ে নিলে জিতে যায়।
খেলোয়াড় যদি কোনো ঈগলের সংস্পর্শে আসে, তাহলে সে তার সব বীজ হারাবে এবং খেলাটি হারবে।
এই নিয়মের একটি ব্যতিক্রম আছে: খেলোয়াড়ের একটি সক্রিয় পাওয়ার-আপ থাকতে পারে, যা তাকে অন্য পাখিদের চেয়ে উঁচুতে উড়তে দেয়।

আপনার লক্ষ্য হলো গেমটিতে ব্যবহার হবে এমন কিছু নিয়ম লেখা।

## 1. পাখি বোনাস পয়েন্ট পাবে কি না তা নির্ধারণ করুন

গেমটিতে পাখি যদি পাওয়ার-আপ থাকা অবস্থায় কোনো ঈগল স্পর্শ করে, তবে সে বোনাস পয়েন্ট পাবে।

`bonusPoints(powerUpActive:touchingEagle:)` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয়: `powerUpActive`, যেখানে থাকে পাখির একটি সক্রিয় পাওয়ার-আপ আছে কি না, এবং `touchingEagle`, যেখানে থাকে পাখিটি কোনো ঈগল স্পর্শ করছে কি না।
ফাংশনটি `true` রিটার্ন করবে কেবল তখনই, যখন পাখির একটি সক্রিয় পাওয়ার-আপ আছে এবং সে কোনো ঈগল স্পর্শ করছে; অন্যথায় `false` রিটার্ন করবে।

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. পাখি পয়েন্ট পাবে কি না তা নির্ধারণ করুন

গেমটিতে খেলোয়াড় একটি বীজ বা একটি পাওয়ার-আপ কুড়িয়ে নিলে পয়েন্ট পায়।

`score(touchingPowerUp:touchingSeed:)` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয়: `touchingPowerUp`, যেখানে থাকে পাখিটি একটি পাওয়ার-আপ স্পর্শ করছে কি না, এবং `touchingSeed`, যেখানে থাকে পাখিটি একটি বীজ স্পর্শ করছে কি না।
পাখি যদি একটি পাওয়ার-আপ বা একটি বীজ স্পর্শ করে, তবে ফাংশনটি `true` রিটার্ন করবে; অন্যথায় `false` রিটার্ন করবে।

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. পাখি হারবে কি না তা নির্ধারণ করুন

`lose(powerUpActive:touchingEagle:)` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয়: `powerUpActive`, যেখানে থাকে পাখির একটি সক্রিয় পাওয়ার-আপ আছে কি না, এবং `touchingEagle`, যেখানে থাকে পাখিটি কোনো ঈগল স্পর্শ করছে কি না।
ক্যারেক্টারটি যদি কোনো ঈগল স্পর্শ করে এবং তার কোনো সক্রিয় পাওয়ার-আপ না থাকে, তবে ফাংশনটি `true` রিটার্ন করবে; অন্যথায় `false` রিটার্ন করবে।

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. পাখি জিতবে কি না তা নির্ধারণ করুন

`win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` ফাংশনটি ডিফাইন করুন, যা এই আর্গুমেন্টগুলো নেয়:

- `hasPickedUpAllSeeds`, যদি পাখি সব বীজ কুড়িয়ে নিয়ে থাকে।
- `powerUpActive`, যদি পাখির একটি সক্রিয় পাওয়ার-আপ থাকে।
- `touchingEagle`, যদি পাখি কোনো ঈগল স্পর্শ করছে।

পাখি যদি সব বীজ সংগ্রহ করে থাকে এবং ৩ নম্বর অংশে নির্ধারিত আর্গুমেন্ট অনুযায়ী না হারে, তবে ফাংশনটি `true` রিটার্ন করবে; অন্যথায় `false` রিটার্ন করবে।

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
