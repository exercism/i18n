# পরিচিতি

বিহেভিয়ারের সাহায্যে আমরা একটি _বিহেভিয়ার মডিউলে_ ইন্টারফেস (ফাংশন ও ম্যাক্রোর সেট) ডিফাইন করতে পারি, যা পরে ভিন্ন ভিন্ন _কলব্যাক মডিউল_ বাস্তবায়ন করতে পারে। এই সাধারণ ইন্টারফেসের সুবাদে ওই কলব্যাক মডিউলগুলোকে একে অন্যের বদলে ব্যবহার করা যায়।

~~~~exercism/note
লক্ষ্য করুন, "behaviours"-এর বানানটি ব্রিটিশ রীতি অনুযায়ী লেখা।
~~~~

## বিহেভিয়ার ডিফাইন করা

একটি বিহেভিয়ার ডিফাইন করতে হলে আমাদের একটি নতুন মডিউল বানাতে হবে এবং কাঙ্ক্ষিত ইন্টারফেসের অন্তর্গত ফাংশনগুলোর একটি তালিকা নির্দিষ্ট করে দিতে হবে। প্রতিটি ফাংশন `@callback` মডিউল অ্যাট্রিবিউট দিয়ে ডিফাইন করতে হবে। এর সিনট্যাক্স [ফাংশন টাইপস্পেক][concept-typespecs] (`@spec`)-এর মতোই। আমাদের একটি ফাংশনের নাম, আর্গুমেন্ট টাইপের একটি তালিকা এবং সম্ভাব্য সব রিটার্ন টাইপ উল্লেখ করতে হবে।

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer
end
```

## বিহেভিয়ার বাস্তবায়ন

আমাদের মডিউলে একটি বিদ্যমান বিহেভিয়ার যোগ করতে (অর্থাৎ একটি কলব্যাক মডিউল বানাতে) আমরা `@behaviour` মডিউল অ্যাট্রিবিউট ব্যবহার করি। এর মান হবে যে বিহেভিয়ার মডিউলটি আমরা যোগ করছি, তার নাম।

এরপর ওই বিহেভিয়ার মডিউল যে ফাংশনগুলো (কলব্যাক) চায়, সেগুলো সব আমাদের ডিফাইন করতে হবে। আমরা যদি অন্য কারও লেখা বিহেভিয়ার বাস্তবায়ন করি, যেমন Elixir-এর বিল্ট-ইন `Access` বা `GenServer` বিহেভিয়ার, তাহলে ওই বিহেভিয়ারের সব কলব্যাকের তালিকা পাব [hexdocs.pm][hexdocs]-এর ডকুমেন্টেশনে।

একটি কলব্যাক মডিউল কেবল নিজের বিহেভিয়ারের অন্তর্গত ফাংশনগুলোই বাস্তবায়ন করতে বাধ্য নয়। একটি মডিউল একাধিক বিহেভিয়ারও বাস্তবায়ন করতে পারে।

কোন ফাংশন কোন বিহেভিয়ার থেকে এসেছে তা বোঝাতে প্রতিটি ফাংশনের আগে `@impl` মডিউল অ্যাট্রিবিউট ব্যবহার করা উচিত। এর মান হবে যে বিহেভিয়ার মডিউলটি এই কলব্যাকটি ডিফাইন করেছে, তার নাম।

```elixir
defmodule BookCollection do
  @behaviour Countable

  defstruct [:list, :owner]

  @impl Countable
  def count(collection) do
    Enum.count(collection.list)
  end

  def mark_as_read(collection, book) do
    # other function unrelated to the Countable behaviour
  end
end
```

## ডিফল্ট কলব্যাক বাস্তবায়ন

বিহেভিয়ার ডিফাইনের সময় একটি কলব্যাকের ডিফল্ট বাস্তবায়ন দেওয়া সম্ভব। এই বাস্তবায়নটি `__using__/1` ম্যাক্রোর quoted এক্সপ্রেশনে ডিফাইন করতে হবে। বিহেভিয়ার মডিউলের ব্যবহারকারীরা যাতে ডিফল্ট বাস্তবায়নটি ওভাররাইড করতে পারেন, সেজন্য ফাংশনের বাস্তবায়নের পরে `defoverridable/1` ম্যাক্রোটি কল করুন। এটি একটি কিওয়ার্ড লিস্ট নেয়, যেখানে কী (key) হিসেবে থাকে ফাংশনের নাম আর মান হিসেবে থাকে ফাংশনের অ্যারিটি।

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer

  defmacro __using__(_) do
    quote do
      @behaviour Countable
      def count(collection), do: Enum.count(collection)
      defoverridable count: 1
    end
  end
end
```

লক্ষ্য করুন, ডিফল্ট কলব্যাক বাস্তবায়ন ডিফাইনের বাইরে অন্য কোনো উদ্দেশ্যে `__using__/1`-এর ভেতরে ফাংশন ডিফাইন করা উৎসাহিত নয়, তবে আপনি সবসময়ই অন্য একটি মডিউলে ফাংশন ডিফাইন করে সেগুলো `__using__/1` ম্যাক্রোতে ইমপোর্ট করতে পারেন।
