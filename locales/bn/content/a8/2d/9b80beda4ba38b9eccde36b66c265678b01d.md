# ভূমিকা

## মেথডের সেট হিসেবে ইন্টারফেস

সবচেয়ে সহজ রূপে, একটি **ইন্টারফেস টাইপ** হলো কিছু মেথড সিগনেচারের সেট।
নিচে একটি ইন্টারফেস ডেফিনিশনের উদাহরণ দেওয়া হলো, যেখানে `Add` ও `Value` নামের দুটি মেথড আছে:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

`increment`-এর মতো প্যারামিটারের নাম ইন্টারফেস ডেফিনিশন থেকে বাদ দেওয়া যায়, তবে এগুলো থাকলে সাধারণত কোড পড়তে সুবিধা হয়।

Go-তে ইন্টারফেসের নামে `Interface` বা `I` থাকে না।
বরং এগুলো প্রায়ই `er` দিয়ে শেষ হয়, যেমন `Reader`, `Stringer`.

## ইন্টারফেস ইমপ্লিমেন্ট করা

যে কোনো টাইপ ইন্টারফেসের মেথডগুলো ডিফাইন করলে স্বয়ংক্রিয়ভাবেই এবং অন্তর্নিহিতভাবে ইন্টারফেসটি "ইমপ্লিমেন্ট" করে।
Go-তে `implements` নামের কোনো কিওয়ার্ড নেই।

নিচের টাইপটি উপরে দেখা `Counter` ইন্টারফেসটি ইমপ্লিমেন্ট করে।

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

ইন্টারফেসটি ইমপ্লিমেন্ট করার জন্য মেথডের রিসিভার ভ্যালু রিসিভার হোক বা পয়েন্টার রিসিভার, তাতে কিছু যায় আসে না।
(এগুলো নিয়ে সন্দেহ থাকলে [মেথড বিষয়ক ধারণা][concept-methods] আবার দেখে নিন।)

> ইন্টারফেস টাইপের একটি মান এমন যেকোনো মান ধরে রাখতে পারে, যেটি ওই মেথডগুলো ইমপ্লিমেন্ট করে। ((Go Tour: Interfaces)[go-tour-interfaces])

এর মানে হলো, যে সব জায়গায় `Counter` ইন্টারফেস আশা করা হয়, সেখানে এখন `Stats` ব্যবহার করা যায়।

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

ইন্টারফেস যেহেতু অন্তর্নিহিতভাবে ইমপ্লিমেন্ট হয়, তাই একটি টাইপ সহজেই একাধিক ইন্টারফেস ইমপ্লিমেন্ট করতে পারে।
এর জন্য শুধু প্রয়োজনীয় সব মেথড ডিফাইন করা থাকলেই চলে।

## খালি ইন্টারফেস

Go-তে একটি খুব বিশেষ ইন্টারফেস টাইপ আছে, যাকে বলে **খালি ইন্টারফেস**, যেখানে একটিও মেথড থাকে না।
খালি ইন্টারফেস এভাবে লেখা হয়: `interface{}`.
Go 1.18 বা তার পরের ভার্সনে `any`-ও ব্যবহার করা যায়।
এটি একটি অ্যালিয়াস হিসেবে ডিফাইন করা হয়েছে।

খালি ইন্টারফেসে কোনো মেথড না থাকায় প্রতিটি টাইপই এটি অন্তর্নিহিতভাবে ইমপ্লিমেন্ট করে।
এটি এমন একটি ফাংশন ডিফাইনের জন্য কাজে লাগে, যা সাধারণভাবে যেকোনো মান নিতে পারে।
সেক্ষেত্রে ফাংশনের প্যারামিটারটি খালি ইন্টারফেস টাইপ ব্যবহার করে।
