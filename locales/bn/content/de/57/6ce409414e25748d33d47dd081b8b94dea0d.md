# পরিচিতি

জেনেরিক (generics) দিয়ে আপনি একই কোড দিয়ে একাধিক টাইপের কাজ করতে পারেন, কোনো কিছু ডুপ্লিকেট না করেই। অ্যাঙ্গেল ব্র্যাকেট `<T>` ব্যবহার করে জেনেরিক টাইপ ডিফাইন করা যায়, যেখানে `T` যেকোনো টাইপের জন্য একটি প্লেসহোল্ডার।

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

জেনেরিক টাইপটি কোন কোন অপারেশন সমর্থন করবে তা নির্দিষ্ট করার জন্য Cairo-এ trait bound দিতে হয়। `+` সিনট্যাক্স ব্যবহার করে আপনি সীমাবদ্ধতা যোগ করতে পারেন:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

struct-ও জেনেরিক হতে পারে:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

trait-ও জেনেরিক হতে পারে, ফলে সেগুলো বিভিন্ন টাইপের সাথে কাজ করতে পারে:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

ফাংশন trait bound-সহ জেনেরিক প্যারামিটার নিতে পারে, ফলে প্রয়োজনীয় trait ইমপ্লিমেন্ট করে এমন যেকোনো টাইপের সাথে সেগুলো কাজ করে:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
