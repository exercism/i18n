# পরিচিতি

Cairo-তে প্রিন্টিং ব্যবহার করে আপনি প্রোগ্রাম চালানোর সময় মেসেজ বা ডিবাগ তথ্য দেখাতে পারেন।

## মূল বিষয়গুলো

Cairo প্রিন্টিংয়ের জন্য দুটি ম্যাক্রো দেয়:

- `println!`: একটি মেসেজ আউটপুট দেয়, তারপর একটি নিউলাইন দেয়।
- `print!`: একটি মেসেজ আউটপুট দেয়, কিন্তু নিউলাইন দেয় না।

```rust
println!("Hello, Cairo!"); 
println!("x = {}, y = {}", 10, 20); 
```

প্লেসহোল্ডার `{}` প্রদত্ত মান দিয়ে প্রতিস্থাপিত হয়।

## স্ট্রিং ফরম্যাট করা

সাথে সাথে প্রিন্ট না করে একটি `ByteArray` তৈরি করতে `format!` ব্যবহার করুন:

```rust
let result = format!("{}-{}-{}", "tic", "tac", "toe");
println!("{}", result); // Output: tic-tac-toe
```

## কাস্টম ডেটা টাইপ

কাস্টম টাইপের জন্য প্রিন্ট করার জন্য `Display` ইমপ্লিমেন্ট করুন বা `Debug` ডিরাইভ করুন:

```rust
#[derive(Debug)]
struct Point { x: u8, y: u8 }

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Debug output: Point { x: 3, y: 4 }
```

## হেক্সাডেসিমাল প্রিন্টিং

ইন্টিজারকে হেক্সাডেসিমাল হিসেবে প্রিন্ট করতে `{:x}` ব্যবহার করুন:

```rust
println!("{:x}", 255); // Output: ff
```
