# পরিচিতি

`bit` হলো কম্পিউটিংয়ের সবচেয়ে সূক্ষ্ম মান।
`bit` শব্দটির অর্থ "binary digit"।
এটি এক্সিকিউশন এনভায়রনমেন্টে ডেটা সংরক্ষণের একটি একক, যা এমন একটি অবজেক্ট ধরে রাখতে যথেষ্ট বড় যার দুটি মানের একটি থাকতে পারে।
তাই এর বাইনারি মান হয় `1` নয়তো `0`।
অন্য সব ডেটা টাইপ একাধিক `bits` নিয়ে গঠিত।
উদাহরণস্বরূপ, একটি `byte` সাধারণত আটটি `bits` নিয়ে গঠিত হয়।

## বিটের মান কীভাবে লিখবেন

`Bits` মিলে বেস ২ সংখ্যা পদ্ধতি তৈরি করে।
বেস ২-এ `2`-এর প্রতিটি গুণিতক আমরা সাধারণত যাকে দশের ঘর/শতের ঘর/হাজারের ঘর ইত্যাদি বলি, সেখানে বসে; শুধু পার্থক্য হলো "দশ"-এর জায়গায় হয় "দুই", "শত"-এর জায়গায় হয় "চার", "হাজার"-এর জায়গায় হয় "আট", এভাবে চলতে থাকে।
সুতরাং, দশমিক মান `2` হবে বাইনারি মান `10`, `4` হবে `100`, আর `8` হবে `1000`।
দশমিক সংখ্যার মতোই, ডান থেকে বামে গেলে মান বেড়ে যায়।
দশমিক মান `5`-কে বাইনারিতে `101` দিয়ে প্রকাশ করা হয়, যেখানে "এককের" ঘরে একটি `1` আর "চারের" ঘরে একটি `1` থাকে, এভাবে ভাবতে পারি।
তবে, বাইনারি লিটারেল C ভাষার স্ট্যান্ডার্ডের অংশ নয়।
C ভাষার স্ট্যান্ডার্ডে সমর্থিত একমাত্র বাইনারি মান হলো একটিমাত্র `1` বা `0`।
কিছু অ-স্ট্যান্ডার্ড কম্পাইলার এক্সটেনশন, যেমন gnu কম্পাইলার, লিটারেলের আগে `0b` বসিয়ে বাইনারি লিটারেল _সমর্থন করে_।

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

মনে রাখা জরুরি যে এমন নোটেশন সব কম্পাইলারে সমর্থিত নয় এবং এটি বিভিন্ন কম্পাইলারের মধ্যে কোডের পোর্টেবিলিটির ক্ষেত্রে বাধা হয়ে দাঁড়াতে পারে।

বাইনারি মান লেখার একটি কমন উপায় হলো হেক্সাডেসিমেল নোটেশন ব্যবহার করা, যা একটি বেস ১৬ সংখ্যা পদ্ধতি।
C ভাষার হেক্সাডেসিমেল নোটেশনে লিটারেলের আগে `0x` বা `0X` বসানো হয়।
যেহেতু দশমিক মান `16`-কে দশকের ঘরে `1` দিয়ে প্রকাশ করা হয়, তাই হেক্সাডেসিমেলে দশমিক মান `10`-কে প্রকাশ করা হয় `0xA` দিয়ে, `11`-কে `0xB` দিয়ে, `12`-কে `0xC` দিয়ে, `13`-কে `0xD` দিয়ে, `14`-কে `0xE` দিয়ে আর `15`-কে `0xF` দিয়ে।
সুতরাং, উদাহরণস্বরূপ, দশমিক মান `42` লেখা হবে `0x2A` হিসেবে: `2` গুণ `16` (= `32`) যোগ `10` (= `42`)।

বাইনারিতে আমরা `42`-কে `00101010` হিসেবে ভাবতে পারি: `32` যোগ `8` যোগ `2`।
আমরা বলব, ডান দিক থেকে দ্বিতীয়, চতুর্থ ও ষষ্ঠ বিট "সেট" হয়েছে, অর্থাৎ সেগুলো `0`-এর বদলে `1`।
দ্বিতীয় বিটটি `2`, চতুর্থ বিটটি `8`, আর ষষ্ঠ বিটটি `32`।
এই তিনটি বিট সেট করলে `42` মানটি তৈরি হয়।

## বিট মাস্ক

একটি বিট মাস্ক হলো এমন যেকোনো মান, যা আলাদা আলাদা বিট সেট করতে ব্যবহৃত হয়।
উদাহরণস্বরূপ, ইংরেজি বর্ণমালায় ছাব্বিশটি অক্ষর আছে।
কমপক্ষে ছাব্বিশটি বিটের একটি মান, যেমন একটি unsigned 32-bit ইন্টিজার, প্রতিটি ইংরেজি অক্ষরের জন্য `true` বা `false` শর্ত সেট করার বিট মাস্ক হিসেবে ব্যবহার করা যেতে পারে।
প্রয়োজনীয় সংখ্যক `true` বা `false` শর্ত সামলাতে যথেষ্ট বিট আছে এমন যেকোনো মানই বিট মাস্ক হিসেবে কাজ করতে পারে।
আলাদা আলাদা বিট সেট করা ও পড়া হয় বিটওয়াইজ অপারেটর ব্যবহার করে।

## বিটওয়াইজ অপারেটর

ধরা যাক, আমরা একটি `string`-এ কোন কোন অক্ষর আছে তা হিসাব রাখতে চাই।
আমাদের উদাহরণে আমরা ইংরেজি বর্ণমালার ছাব্বিশটি অক্ষরই ব্যবহার করব।
আমাদের বিট মাস্ক হবে একটি unsigned 32-bit ইন্টিজার।
একটি `0` বোঝাবে যে অক্ষরটি নেই।
একটি `1` বোঝাবে যে অক্ষরটি একবার বা তার বেশি আছে।
শুরুতে আমাদের বিট মাস্কের বিট রূপ হবে পরপর ৩২টি `0s`: `00000000000000000000000000000000`।
সবচেয়ে ডানদিকের অবস্থানটি হবে `A`-এর জন্য।
বাম দিক থেকে দ্বিতীয়টি হবে `B`-এর জন্য, এভাবে চলবে।
ধরুন, আমরা একটি লুপে স্ট্রিংয়ের সব অক্ষর প্রসেস করছি, তাই আমরা এমন এক লাইন কোড চাই যা যেকোনো অক্ষর সেট করার জন্য কাজ করবে।

### বিটওয়াইজ বাম শিফট অপারেটর: একটি বিটের অবস্থান নির্ধারণের উপায়

`<<` হলো বামে শিফট করার বিটওয়াইজ অপারেটর।

আমাদের অক্ষর যদি `A` হয়, আমরা বামে শিফট করতে চাই না; কিন্তু অক্ষর যদি `B` হয়, আমরা এক অবস্থান বামে শিফট করতে চাই; আর অক্ষর যদি `C` হয়, দুই অবস্থান বামে শিফট করতে চাই, এভাবে চলবে।
যদিও আমরা `chars`-কে `A` বা `B`-এর মতো অক্ষর হিসেবে দেখতে পারি, মেমোরিতে একটি `char` আসলে একটি ইন্টিজার টাইপ হিসেবে থাকে, তাই আমরা একটি `char` নিয়ে সহজ গণনা করতে পারি।
ধরুন, আমাদের কাছে `letter` নামের একটি ভ্যারিয়েবল আছে, যা আমরা যে `char` প্রসেস করছি তা বোঝায়; তাহলে `letter` আর `A` `char`-এর পার্থক্য অনুযায়ী `1`-কে বামে শিফট করে প্রয়োজনীয় সংখ্যক অবস্থান বামে শিফট করতে পারি, এভাবে: `1 << letter - 'A'`।
`A` - `A` = `0`, তাই `letter` `A` হলে এটি `0` অবস্থান বামে শিফট করবে।
`B` - `A` = `1`, তাই `letter` `B` হলে এটি `1` অবস্থান বামে শিফট করবে, এভাবে চলবে।

### বিটওয়াইজ ইনক্লুসিভ OR অপারেটর: একটি বিট সেট করার উপায়

আমরা _কোথায়_ একটি বিট সেট করতে চাই তা জানলে, বিটওয়াইজ ইনক্লুসিভ OR অপারেটর, অর্থাৎ `|`, ব্যবহার করে সেটি সত্যিকারভাবে সেট করতে পারি।
`|` অপারেটরের ফলাফল প্রতিটি সেই অবস্থানে `1` হবে, যেখানে বাম বা ডান অপারেন্ডের যেকোনো একটির বিট সেট আছে।
সুতরাং, `0010 | 0001`-এর ফলাফল হবে `0011`।
(মনে রাখা জরুরি যে মানটি বাইনারিতে `11`, কিন্তু দশমিকে `3`।)
ফলাফলটি একটি মানে অ্যাসাইন করতে, `|` অপারেটরকে অ্যাসাইনমেন্ট অপারেটরের সঙ্গে মিলিয়ে এভাবে বিট সেট করা যায়: `|=`।
সহজ রাখতে, নিচের উদাহরণে কোনো লুপ ব্যবহার করা হয়নি, তবে এটি দেখায় কীভাবে আমরা `ABA` অক্ষরগুলো একটি বিট মাস্কে প্রসেস করতে পারি।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

`A`-এর জন্য আমরা আমাদের মাস্কের সবচেয়ে ডানদিকের অংশ `0001` সেট করি, তারপর `B`-এর জন্য মাস্কটি `0011` সেট করি।
আরেকটি `A` সেট করলে বিদ্যমান মাস্কে কোনো পরিবর্তন হয় না।
`A` আগেই সেট হয়েছে কি না তা দেখে আমরা বিটটি আবার সেট করা এড়াতে পারতাম।

### বিটওয়াইজ AND অপারেটর: একটি বিট পড়ার উপায়

`&` হলো বিটওয়াইজ AND অপারেটর।
`&` অপারেটরের ফলাফল প্রতিটি সেই অবস্থানে `1` হবে, যেখানে বাম ও ডান দুই অপারেন্ডেরই বিট সেট আছে।
সুতরাং, `0011 & 0001`-এর ফলাফল হবে `0001`।
নিচের উদাহরণে এটি কাজ করতে দেখা যায়।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### বিটওয়াইজ এক্সক্লুসিভ OR অপারেটর: একটি বিট উল্টে দেওয়ার উপায়

`^` হলো বিটওয়াইজ এক্সক্লুসিভ OR অপারেটর।
একটি _ইনক্লুসিভ_ OR অপারেটর থাকলে বোঝা যায়, ভিন্ন আচরণের একটি _এক্সক্লুসিভ_ OR অপারেটরও আছে।
`^` অপারেটরের ফলাফল প্রতিটি সেই অবস্থানে `1` হবে, যেখানে বাম বা ডান অপারেন্ডের _শুধু একটির_ বিট সেট আছে।
সুতরাং, `0001 ^ 0011`-এর ফলাফল হবে `0010`।
সবচেয়ে ডানদিকের বিটটি সেট হবে না, কারণ _দুই_ অপারেন্ডেরই সবচেয়ে ডানদিকের অবস্থানে `1` আছে।
এক্সক্লুসিভ OR অপারেশনকে অনেক সময় XOR হিসেবে লেখা হয়।
কোনো মানকে XOR করার ফলাফলটিকে আবার XOR করলে মূল মানটিই ফিরে আসে।
এটি খুব সহজ একটি এনক্রিপশনে ব্যবহার করা যায়, যেখানে একই কী ডেটা এনক্রিপ্ট ও ডিক্রিপ্ট দুই কাজেই ব্যবহৃত হয়।
উদাহরণস্বরূপ

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### বিটওয়াইজ ডান শিফট অপারেটর: একটি মান অর্ধেক করার উপায়

`>>` হলো ডানে শিফট করার বিটওয়াইজ অপারেটর।
সাধারণত, একটি মানের বিট যত অবস্থান ডানে শিফট করা হয়, ফলাফল হয় সেই মানকে দুই দিয়ে ভাগ করার সমান।
উদাহরণস্বরূপ

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

ডান অপারেন্ডের মান ঋণাত্মক হলে, বা প্রমোটেড বাম অপারেন্ডের প্রস্থের সমান বা তার চেয়ে বড় হলে, আচরণটি অনির্ধারিত।
এটি বাম শিফট অপারেটরের ক্ষেত্রেও প্রযোজ্য।
unsigned ইন্টিজারের বদলে signed ইন্টিজার ব্যবহার করলে সংখ্যাটি signed কি না সেটিও ভূমিকা রাখতে পারে।
নিচের উদাহরণে একটি সিস্টেমে signed ইন্টিজারের জন্য খুব বেশি বামে বা ডানে শিফট করলে কী আচরণ হয় তা দেখানো হয়েছে।

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

যেহেতু আচরণটি অনির্ধারিত, অন্য একটি সিস্টেমে ভিন্ন ফলাফল আসতে পারে।
বিট শিফট করার সময় ব্যবহৃত ডেটা টাইপের সীমা বোঝা জরুরি।

## বিট ফিল্ড

আমরা দেখেছি, একটি সরল ডেটা টাইপে গাঁথা বিটগুলোকে তাদের অবস্থান দিয়ে চিহ্নিত করা যায়।
একটি `struct`-এ গাঁথা বিটগুলোকে নাম দিয়ে চিহ্নিত করা যায়।
এমন ডেটা টাইপকে বলা হয় `bit field`।
`bit fields`-এর একটি ব্যবহারের ক্ষেত্র হতে পারে যখন একগুচ্ছ ON/OFF ফ্ল্যাগ দরকার হয় এবং মেমোরি ব্যবহার যতটা সম্ভব কমাতে চাওয়া হয়।

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;` সিনট্যাক্সটি struct-এর ভেতরে বসানো একটি `unsigned int`-এর মধ্যে `1` বিটের একটি ফিল্ড তৈরি করে।
`unsigned int`-এর বদলে `signed int` ব্যবহার করা যায়, অথবা C99 বা তার পর থেকে `bool` টাইপ ব্যবহার করা যায়।
বিট ফিল্ড থাকা একটি struct-এ অন্য ডেটা টাইপের ফিল্ডও থাকতে পারে, যেমন উপরের উদাহরণে `number_of_lights`।
