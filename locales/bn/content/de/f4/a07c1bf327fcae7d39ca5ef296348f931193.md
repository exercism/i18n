# ভূমিকা

Haxe-এ সংখ্যার দুইটি টাইপ আছে - ইন্টিজার আর ফ্লোট:

- `Int`: একটি পূর্ণসংখ্যা বোঝায়।
- `Float`: একটি ডাবল-প্রিসিশন ৬৪-বিট ফ্লোটিং পয়েন্ট সংখ্যা বোঝায়।

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

যদিও প্রতিটি `Int` এমন জায়গায় ব্যবহার করা যায় যেখানে `Float` প্রত্যাশিত (অর্থাৎ, `Int` `Float`-এ **অ্যাসাইন করা যায়** বা `Float`-এর সাথে **ইউনিফাই করে**), বিপরীতটা সত্য নয়: একটি `Float`-কে একটি `Int`-এ অ্যাসাইন করলে নির্ভুলতা হারানোর সম্ভাবনা থাকে এবং তাই এটি অন্তর্নিহিতভাবে অনুমোদিত নয়।
