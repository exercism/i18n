# নির্দেশনা

f(x) = ax^3 + bx^2 + cx + d আকারের একটি বহুপদী ফাংশন ধরা যাক। লোকাল মিনিমার সংজ্ঞা হলো f(x) < f(x - delta) এবং f(x) < f(x + delta)। এই সংজ্ঞা ব্যবহার করে লোকাল মিনিমামের একটি এক্সপ্রেশন বের করুন, আর প্রদত্ত সহগ (a, b, c, d) দিয়ে একটি লোকাল মিনিমা সমাধান করুন। সহগগুলো এমন একটি ফাংশন নির্দেশ করবে, যার অন্তত একটি মিনিমা থাকবে। মিনিমা যেখানে ঘটে, সেই x স্থানাঙ্কটি রিটার্ন করুন।
