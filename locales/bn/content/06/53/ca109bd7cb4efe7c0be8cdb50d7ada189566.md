# নির্দেশনা

সাধারণ সংখ্যাকে [অর্ডিনাল সংখ্যায়](https://en.wikipedia.org/wiki/Ordinal_numeral) রূপান্তর করার জন্য একটি ফাংশন লিখুন। শূন্য (0)-এর জন্য স্ট্রিং হিসেবে শুধু "0" রিটার্ন করুন।

অর্ডিনাল সংখ্যা হলো এমন সংখ্যা যা একটি তালিকায় কোনো কিছুর অবস্থান বোঝায়। এই প্রসঙ্গেই অর্ডিনাল সংখ্যাগুলো ব্যবহার করা হবে, অর্থাৎ একটি অর্ডিনাল সংখ্যার ইংরেজি বানানের নাম ব্যবহার করে।

অর্ডিনাল সংখ্যাগুলো হলো (অন্তত, তাদের একটি রূপ):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

তাই একটি সাধারণ সংখ্যা ইনপুট করলে তার সমতুল্য অর্ডিনাল পাওয়া যায়:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
