আজারা আর রুই একই দলের সতীর্থ, তারা জলদস্যু-থিমের একটি ট্রেজার হান্ট প্রতিযোগিতায় লড়ছে।
একজনের কাছে ম্যাপের কোঅর্ডিনেটসহ ট্রেজারদের একটি তালিকা আছে, অন্যজনের কাছে ম্যাপের কোঅর্ডিনেটসহ লোকেশনের নামের একটি তালিকা।
তাদের দুজনকে ফাঁকা ম্যাপও দেওয়া হয়েছে, যেখানে শুরুর স্থানে লেখা আছে YOU ARE HERE।

তবে ব্যাপারটা একটু এলোমেলো: আজারার কোঅর্ডিনেটগুলো দেখে মনে হয় রুইয়ের থেকে আলাদাভাবে ফরম্যাট করা আর সাজানো হয়েছে, আর কোন ট্রেজার কোন লোকেশনের সাথে যায় সেটা বের করার জন্য তাদের বারবার এক তালিকা থেকে আরেক তালিকায় দেখতে হচ্ছে।
যেহেতু তারা সদ্য F# শিখতে শুরু করেছে, তাই হান্টের তথ্যগুলো আরও ভালোভাবে গুছিয়ে রাখার জন্য একটি ছোট প্রোগ্রাম (আসলে কিছু ফাংশন) লিখতে তারা আপনার কাছে সাহায্য চেয়ে এসেছে।

## 1. কোঅর্ডিনেট বের করা

`getCooordinate()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আজারার তালিকা থেকে একটি `(treasure, coordinate)` জোড়া নেয় এবং শুধু বের করা ম্যাপ কোঅর্ডিনেটটি রিটার্ন করে।

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. কোঅর্ডিনেট ফরম্যাট করা

`convertCoordinate()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা "2A" ফরম্যাটের একটি কোঅর্ডিনেট নেয় এবং `(2, 'A')` ফরম্যাটের একটি টাপল রিটার্ন করে।

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. কোঅর্ডিনেট মেলানো

`compareRecords()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি `(treasure, coordinate)` জোড়া এবং একটি `(location, coordinate, quadrant)` রেকর্ড নেয়, আর দুটির কোঅর্ডিনেট তুলনা করে।
কোঅর্ডিনেটগুলো যদি "মেলে" তবে **`true`** রিটার্ন করুন, আর না মিললে **`false`** রিটার্ন করুন।
সঠিকভাবে তুলনা করার জন্য প্রয়োজন অনুযায়ী কোঅর্ডিনেট আবার ফরম্যাট করুন।

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. মিলে যাওয়া রেকর্ড একত্র করা

`createrecord()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আজারার তালিকা থেকে একটি `(treasure, coordinate)` জোড়া এবং রুইয়ের তালিকা থেকে একটি `(location, coordinate, quadrant)` রেকর্ড নেয়, আর **কোঅর্ডিনেটগুলো মিলে গেলে** `(coordinate, location, quadrant, treasure)` রিটার্ন করে।
কোঅর্ডিনেটগুলো যদি _না_ মেলে, তবে একই আকারের একটি টাপল রিটার্ন করুন, তবে সেটি `""` দিয়ে ভরা থাকবে।
সঠিকভাবে তুলনা করার জন্য প্রয়োজন অনুযায়ী কোঅর্ডিনেট আবার ফরম্যাট করুন।

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
