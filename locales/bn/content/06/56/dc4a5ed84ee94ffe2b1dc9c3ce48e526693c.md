# পরিচিতি

পাটিগণিতের অপারেশন করার জন্য PHP-তে বেশ কিছু অপারেটর আছে। পাটিগণিতের অপারেটরগুলোর ক্ষেত্রে PHP গণিতে প্রচলিত নিয়ম অনুযায়ীই কাজ করে। PHP-তে যে অপারেটরগুলো পাওয়া যায় সেগুলো হলো:

* আইডেন্টিটি (+)
* নেগেশন (-)
* যোগ (+)
* বিয়োগ (-)
* গুণ (*)
* ভাগ (/)
* মডুলো (%)
* এক্সপোনেনশিয়েশন (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
