# ভূমিকা

ভাগ্যনির্ভর খেলার জন্য এলোমেলোতার একটি উৎস দরকার। Factor-এর [`random`][random] ভোকাবুলারিতে আছে একটি জেনেরিক ওয়ার্ড, `random`, যা আপনি যা-ই দেন না কেন তার সঙ্গে খাপ খায়; সঙ্গে আছে শাফলিং ও স্যাম্পলিংয়ের জন্য কিছু সহায়ক ওয়ার্ড, আর টেস্টের জন্য এলোমেলোতাকে *পুনরুৎপাদনযোগ্য* করার একটি উপায়।

## একটি ওয়ার্ডকে `inline` চিহ্নিত করা

এই অনুশীলনীর কিছু কাজে এমন একটি ওয়ার্ড ডিফাইন করতে হয়, যা আর্গুমেন্ট হিসেবে একটি *কোয়োটেশন* (একটি `[ … ]` ব্লক) নেয় আর সেটি রান করে। এ বিষয়ে Factor-এর একটি অনড় নিয়ম আছে: **আর্গুমেন্ট হিসেবে পাওয়া কোনো কোয়োটেশনকে যে ওয়ার্ড `call` করে, তাকে অবশ্যই `inline` ডিক্লেয়ার করতে হবে**, আর সেটি লেখা হয় শেষ `;`-এর ঠিক পরে `inline` বসিয়ে।

`inline` কম্পাইলারকে বলে, ওয়ার্ডটির বডি আলাদা করে একবার কম্পাইল না করে প্রতিটি কল সাইটে সেটি জুড়ে দিতে।

- কলারের কোয়োটেশন সরাসরি গেঁথে দেওয়া হয়, তাই **কোয়োটেশনটি স্ট্যাকে যা-ই রেখে যায়, তা ফিরে যায় কলারের কাছেই**, যদিও ওয়ার্ডটির নিজের স্ট্যাক ইফেক্ট কোনো আউটপুট ঘোষণা করে না।

এখানে একটি ছোট ওয়ার্ড আছে, যা `10` পুশ করে তারপর তার হাতে দেওয়া কোয়োটেশনটি রান করে:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

এর স্ট্যাক ইফেক্ট `( quot -- )` কোনো আউটপুটের নাম বলে না, তবু *ভিন্ন* ইফেক্টের দুটি কোয়োটেশন দিয়ে এটি কল করলে ভিন্ন ফল আসে, আর সেগুলো সবই ফিরে যায় কলারের কাছে:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`: একটি এলিমেন্ট

`random` ([`random`][random]-এ আছে) তার আর্গুমেন্টের ওপর জেনেরিক:

```
random ( obj -- elt )
```

- একটি **ইন্টিজার** `n` দিলে এটি `[0, n)` রেঞ্জের একটি এলোমেলো ইন্টিজার রিটার্ন করে:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- একটি **সিকোয়েন্স** দিলে এটি একটি এলোমেলো এলিমেন্ট রিটার্ন করে:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

সাধারণ ছক্কা গড়তে রেঞ্জটি এক ধাপ উপরে সরাতে হয়: `6`-এর `random` দেয় 0 থেকে 5, তাই `6 random 1 +` দেয় 1 থেকে 6।

## কয়েকটি মান ড্র করা

নির্দিষ্ট সংখ্যক এলোমেলো ড্র জড়ো করতে `replicate` ([`sequences`][sequences]-এ আছে) দিয়ে একটি কোয়োটেশন বারবার চালান:

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`: একই জায়গায় শাফল

`randomize` ([`random`][random]-এ আছে) সিকোয়েন্সটির এলিমেন্টগুলো এলোমেলো ক্রমে সাজিয়ে সেটিই রিটার্ন করে:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

এটি **একই জায়গাতেই** শাফল করে আর সেই একই সিকোয়েন্স রিটার্ন করে, তাই মূল ক্রমটা ধরে রাখতে চাইলে আগে `clone` করুন।

## `sample`: কয়েকটি আলাদা এলিমেন্ট

`sample` ([`random`][random]-এ আছে) একটি সিকোয়েন্স থেকে `n`টি *আলাদা* এলিমেন্ট ড্র করে, ঠিক তাসের হাত বিলি করার মতো, যেখানে একই তাস দুবার আসে না:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

সিকোয়েন্সে যত এলিমেন্ট আছে তার চেয়ে বেশি চাইলে সেটি এরর।

## পুনরুৎপাদনযোগ্য এলোমেলোতা

ডিফল্টভাবে `random` সিস্টেম ক্লক থেকে সিড নেওয়া একটি গ্লোবাল জেনারেটর থেকে ড্র করে, তাই প্রতিবার রান করলে ফল আলাদা আসে। টেস্টের জন্য, কিংবা যখনই *আবার খেলা যায়* এমন একটি গেম চান, তখন একটি নির্দিষ্ট **সিড** দিয়ে জেনারেটর বাইন্ড করুন।

`<mersenne-twister>` ([`random.mersenne-twister`][mt]-এ আছে) একটি ইন্টিজার সিড থেকে জেনারেটর তৈরি করে, আর `with-random` ([`random`][random]-এ আছে) সেই জেনারেটরটি বসিয়ে একটি কোয়োটেশন রান করে:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

কোয়োটেশনের ভেতরের সবকিছু, অর্থাৎ `random`, `randomize`, `sample`, সিড দেওয়া জেনারেটর থেকেই ড্র করে, তাই একই সিড সবসময় একই ফল দেয়।

যে ওয়ার্ড আর্গুমেন্ট হিসেবে একটি কোয়োটেশন নেয় আর সেটি `with-random` দিয়ে রান করে, সেটি [একটি ওয়ার্ডকে `inline` চিহ্নিত করা](#marking-a-word-inline) অংশের নিয়মের আওতায় পড়ে: শেষ পর্যন্ত `with-random`-ই ওই কোয়োটেশনটি `call` করে, তাই এমন র‍্যাপারকে অবশ্যই `inline` চিহ্নিত করতে হবে।
