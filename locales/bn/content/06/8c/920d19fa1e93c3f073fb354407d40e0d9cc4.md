# ভূমিকা

যেসব টাইপ `IEnumerable<T>` ইন্টারফেসটি ইমপ্লিমেন্ট করে, সেগুলোকে _এনিউমারেবল_ বলা হয়। সব বিল্ট-ইন কালেকশন টাইপ এই ইন্টারফেসটি ইমপ্লিমেন্ট করে।

`foreach` লুপ ব্যবহার করে একটি এনিউমারেবল টাইপের ওপর ইটারেশন করা যায়:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>` ইমপ্লিমেন্ট করতে একটি টাইপকে একটি মাত্র মেথড ইমপ্লিমেন্ট করতে হয়: `IEnumerator<T> GetEnumerator()`। যেমনটা দেখা যাচ্ছে, একটি এনিউমারেবল কালেকশনের ওপর প্রকৃত ইটারেশনের কাজটি একটি `IEnumerator<T>` টাইপের হাতে ছেড়ে দেয়। এই ইন্টারফেসে ইমপ্লিমেন্ট করার জন্য একটি প্রপার্টি আর তিনটি মেথড আছে:

- `public T Current { get; }`: বর্তমান এলিমেন্টটি পাওয়া যায়।
- `public bool MoveNext ();`: পরের এলিমেন্টে যাওয়া হয়, পরের এলিমেন্টে যাওয়াটি সফল হলে `true` রিটার্ন করে, আর সফল না হলে (আর কোনো এলিমেন্ট না থাকলে) `false` রিটার্ন করে।
- `public void Reset ();`: এনিউমারেটরটিকে তার শুরুর অবস্থায় (প্রথম এলিমেন্টের আগের অবস্থায়) রিসেট করে।
