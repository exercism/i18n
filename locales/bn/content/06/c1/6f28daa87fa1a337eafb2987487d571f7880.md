# পরিচিতি

**if** একটি শর্ত **ট্রু** না **ফলস**, এই ভিত্তিতে কোড চালাতে শর্তাধীন এক্সপ্রেশন ব্যবহার করা হয়। এই এক্সপ্রেশনগুলো এভাবে লেখা হয়:

```haxe
if (condition) {
  expressions
};
```

শর্তের আউটপুট `Bool` টাইপের হয়, তাই আউটপুট `true` হলে এক্সপ্রেশনগুলো চালানো হয়।

কখনও কখনও শর্তটি আসলে `false` হলে কোডের আরেকটি অংশ চালানোর দরকার পড়ে। এখানেই `else` এক্সপ্রেশন কাজে আসে। প্রথম শর্তটি `false` হলে `else` এক্সপ্রেশনগুলো চালায়। কিন্তু শর্তটি একাধিক সম্ভাবনার জন্য যাচাই করতে চাইলে কী হবে? তখন `else if (condition)` ব্যবহার করতে হয়। নিচে একটি সম্পূর্ণ উদাহরণ দেওয়া হলো:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
