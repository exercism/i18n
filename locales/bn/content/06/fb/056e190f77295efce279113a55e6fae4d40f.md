# নির্দেশাবলির সংযোজন

## Python ট্র্যাকে এই অনুশীলনীটি কীভাবে সাজানো হয়েছে

এই অনুশীলনীর টেস্টগুলো আশা করে যে আপনার প্রোগ্রামটি একটি Garden [`class`][classes in python] হিসেবে ইমপ্লিমেন্ট করা হবে (_আরও দেখুন [concept:python/classes]()_)।
Python-এ ক্লাস সম্পর্কে আপনি যদি না জানেন, তবে Real Python-এর এই টিউটোরিয়ালটি শুরু করার আরেকটি ভালো জায়গা হতে পারে।

আপনার `class`-এ `plants` নামের একটি [`method`][methods] থাকা উচিত, যা আর্গুমেন্ট হিসেবে একজন শিক্ষার্থীর নাম নেয় এবং সেই শিক্ষার্থীর গাছের নামের `list` রিটার্ন করে।


## কনস্ট্রাক্টর

উদাহরণের বাগানটি তৈরি করা:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

টেস্টে এটিকে এভাবে দেখানো হবে: `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

এই রূপটি কাজ করতে হলে আপনার `class`-এ একটি [`__init__()`][init] [স্পেশাল মেথড][special-methods] ইমপ্লিমেন্ট করতে হবে।
আপনি যদি `__init__()` বা [_কনস্ট্রাক্টর_][what-is-a-constructor] সম্পর্কে জানা না থাকেন, তাহলে Python ডকুমেন্টেশনের [ক্লাস ও ইনস্ট্যান্স অবজেক্ট][class vs instance objects in python] অংশটি আরও বিস্তারিত ব্যাখ্যা দেয়।


## ডিফল্ট প্যারামিটার

কিছু টেস্টে `__init__()`-এ আর্গুমেন্ট হিসেবে শিক্ষার্থীদের একটি `list` পাঠানো হয়।
এটি সমস্যা বিবৃতিতে দেওয়া বারোজন শিক্ষার্থীর তালিকাটি ওভাররাইড করা উচিত।
এই দুটি স্টেটমেন্টই আপনার `__init__()` মেথডের সাথে কাজ করা দরকার:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

একটি উপায় হলো শিক্ষার্থীদের `list`-টিকে [ডিফল্ট আর্গুমেন্ট][default argument values] বানানো; Python ডকুমেন্টেশনে [ফাংশন ডিফিনিশন][function definitions] ব্যাখ্যা করার সঙ্গে সঙ্গে `default parameters` নিয়েও বিস্তারিত আলোচনা করা হয়েছে।
