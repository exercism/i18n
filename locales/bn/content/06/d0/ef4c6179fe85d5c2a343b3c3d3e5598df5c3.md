# টেস্ট

Exercism-এর অনুশীলনী সমাধান করার একটি উপায় হলো ওয়েবসাইটে গিয়ে ব্রাউজারের ভেতরের এডিটরটি ব্যবহার করা, যেখানে আপনি আপনার সমাধান এডিট ও টেস্ট করতে পারেন।

অথবা অনুশীলনীগুলো আপনার নিজের কম্পিউটারে ডাউনলোড করে নিতে পারেন, যেখানে নিজের এডিটর আর কিছু টুল দিয়ে আপনি সমাধান তৈরি করবেন, টেস্ট করবেন, আর সবশেষে সাবমিট করবেন।

এর জন্য ব্যবহার করতে হয় Exercism কমান্ড-লাইন ইন্টারফেস, বা সংক্ষেপে CLI; এটি এমন একটি অ্যাপ্লিকেশন যা টার্মিনাল বা কমান্ড-লাইন উইন্ডোর ভেতরে চলে। ইনস্টল করার নির্দেশনা এখানে পাবেন: [Exercism CLI ডকুমেন্টেশন](https://exercism.org/docs/using/solving-exercises/working-locally)।

## টেস্ট করার পদ্ধতি
Exercism ধরে নেয় আপনার টেস্ট-ড্রাইভেন ডেভেলপমেন্টের কিছু অভিজ্ঞতা আছে। প্রতিটি অনুশীলনীতে থাকে একটি _`stub file`_, আগে থেকে লেখা কিছু টেস্ট সম্বলিত একটি _`test file`_, আর টেস্টগুলো চালানোর জন্য একটি _`test script`_।

একটি অনুশীলনী সমাধান করতে হলে _`stub file`_ ধীরে ধীরে গড়ে তুলতে হয়, যাতে শেষ পর্যন্ত তাতে এমন কোড থাকে যা সব টেস্ট পাস করবে।

ব্যবহারিকভাবে এর মানে হলো, _`stub file`_ আর _`test file`_ দুটোই সক্রিয়ভাবে এডিট করতে হবে। মনে রাখবেন, _`test file`_ এডিট করা হয় টেস্ট কোড বদলানোর জন্য নয়, বরং ফেল করা টেস্ট কমেন্ট আউট করার জন্য।

শুরুতে একটি ছাড়া বাকি সব টেস্ট কমেন্ট করা থাকে; এরপর _`stub file`_ যখন একটি কাজ করা সমাধানের দিকে এগোয়, তখন আরও টেস্ট আনকমেন্ট করা হয়, শেষে সব টেস্ট সফলভাবে চলে।

## টেস্টের অবকাঠামো
অতিরিক্ত কোনো সফটওয়্যার ইনস্টল করার দরকার নেই, কারণ টেস্ট ফ্রেমওয়ার্কের উপাদানগুলো অনুশীলনীর ডাউনলোডের সাথেই আসে।

টেস্ট ফ্রেমওয়ার্কে তিনটি Rexx ফাইল থাকে, যেগুলো টেস্টের সময় অনুশীলনীর সমাধানের সাথে মিলে টেস্ট কোড ইউনিট তৈরি করে; এরপর _`test script`_ সেটি চালায়, আর টেস্টের ফলাফল টার্মিনালে প্রিন্ট হয়।

অনুগ্রহ করে _`test script`_ বা টেস্ট ফ্রেমওয়ার্কের অন্য কোনো ফাইল এডিট বা ডিলিট করবেন না। কোনো অজানা গোলযোগে যদি তা হয়ে যায়, তবে Exercism CLI দিয়ে অনুশীলনীটি আবার ডাউনলোড করুন, আর সমাধানের কোড থাকলে তা যেন হারিয়ে না যায় সেদিকে খেয়াল রাখুন।

## টেস্ট চালানো
একটি অনুশীলনী সমাধান করার ধাপগুলো এমন:

1. একটি টার্মিনাল খুলুন
2. বেছে নেওয়া অনুশীলনীটি ডাউনলোড করুন
3. অনুশীলনীর ডিরেক্টরিতে ঢুকুন
4. stub file ও test file আপনার এডিটরে লোড করুন
5. ধাপে ধাপে পুনরাবৃত্তি করুন:

    1. test script চালান
    2. আপনার stub file-এ কোড লিখুন (ধীরে ধীরে সেটিকে একটি সমাধান ফাইলে পরিণত করুন), আর আপনার test file-এ টেস্ট কমেন্ট বা আনকমেন্ট করুন

6. সব টেস্ট পাস করলে Exercism-এ সমাধানটি সাবমিট করুন
7. টার্মিনাল বন্ধ করুন
8. আপনার সাফল্য উদযাপন করুন

লিনাক্স টার্মিনালে `acronym` অনুশীলনীটি দিয়ে একটি বাস্তব উদাহরণ (ধরে নিন exercism ওয়ার্কস্পেস হলো:`/home/exercism`)

অনুশীলনী ডাউনলোড করুন:

`exercism download --track=rexx --exercise=acronym`

অনুশীলনীর ডিরেক্টরিতে ঢুকুন:

`cd /home/exercism/rexx/acronym`

অন্য একটি উইন্ডো থেকে, সম্ভবত একটি GUI থেকে, আপনার এডিটরে যথাক্রমে `acronym.rexx` ও `acronym-check.rexx` লোড করুন, অর্থাৎ stub ফাইল ও test ফাইল।

test script চালান: `./test-acronym`

তাহলে সব টেস্ট ফেল করা উচিত:

```bash
1..9
not ok 1 - basic Abbreviate("Portable Network Graphics")
not ok 2 - lowercase words Abbreviate("Ruby on Rails")
not ok 3 - punctuation Abbreviate("First In, First Out")
not ok 4 - all caps word Abbreviate("GNU Image Manipulation Program")
not ok 5 - punctuation without whitespace Abbreviate("Complementary metal-oxide semiconductor")
not ok 6 - very long abbreviation Abbreviate("Rolling On The Floor Laughing So Hard That My Dogs Came Over And Licked Me")
not ok 7 - consecutive delimiters Abbreviate("Something - I made up from thin air")
not ok 8 - apostrophes Abbreviate("Halley's Comet")
not ok 9 - underscore emphasis Abbreviate("The Road __Not__ Taken")
```

`acronym-check.rexx` ফাইলে প্রথম টেস্টটি ছাড়া বাকি সব কমেন্ট করে ফেলুন, তারপর test script আবার চালান; তাহলে নিচের আউটপুটটি আসা উচিত:

```bash
1..1
not ok 1 - basic Abbreviate("Portable Network Graphics")
```

`acronym.rexx` নিয়ে আবার কাজ করুন, যতক্ষণ না তাতে কার্যকর কোড থাকে; শেষে test script চালালে আউটপুট এমন হওয়া উচিত:

```bash
1..1
ok 1 - basic Abbreviate("Portable Network Graphics")
```

এরপর বাকি টেস্টগুলো আনকমেন্ট করুন, test script আবার চালান, আর শেষে আউটপুট এমন হওয়া উচিত:

```bash
1..9
ok 1 - basic Abbreviate("Portable Network Graphics")
ok 2 - lowercase words Abbreviate("Ruby on Rails")
ok 3 - punctuation Abbreviate("First In, First Out")
ok 4 - all caps word Abbreviate("GNU Image Manipulation Program")
ok 5 - punctuation without whitespace Abbreviate("Complementary metal-oxide semiconductor")
ok 6 - very long abbreviation Abbreviate("Rolling On The Floor Laughing So Hard That My Dogs Came Over And Licked Me")
ok 7 - consecutive delimiters Abbreviate("Something - I made up from thin air")
ok 8 - apostrophes Abbreviate("Halley's Comet")
ok 9 - underscore emphasis Abbreviate("The Road __Not__ Taken")
```

এখন আপনি আপনার অনুশীলনীর সমাধান সাবমিট করতে পারেন:

`exercism submit acronym.rexx`

আরেকটি রেপুটেশন পয়েন্টও যোগ হবে। কাজ শেষে টার্মিনালটি বন্ধ করুন।

MacOS ব্যবহারকারীর ক্ষেত্রেও প্রক্রিয়াটি প্রায় একই রকম হবে, কারণ এটিও UNIX থেকে উদ্ভূত একটি অপারেটিং সিস্টেম।

Windows ব্যবহারকারীদের ক্ষেত্রে প্রক্রিয়াটি মূলত একই, তবে কিছু ছোটখাটো পার্থক্য আছে:

- _Command Prompt_ উইন্ডোটিই হলো টার্মিনাল
- পাথের ক্ষেত্রে ফরওয়ার্ড স্ল্যাশের বদলে ব্যাকস্ল্যাশ বসে, তাই ওয়ার্কিং ডিরেক্টরি হতে পারে:

  `cd C:\Users\MyName\exercism\rexx\acronym`

- test script চালানো হয় এভাবে:

  `test-acronym`  or  `test-acronym.bat`

টেস্টের আউটপুট একই থাকবে।
