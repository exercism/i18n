# If, Elseif, Else

`if`, `elseif` আর `else` দিয়ে লেখা শর্তাধীন স্টেটমেন্ট প্রোগ্রামের কন্ট্রোল ফ্লোর একটি মৌলিক অংশ।
`if` স্টেটমেন্ট একটি এক্সপ্রেশন মূল্যায়ন করে, আর সেটি `true` হলে কোডের সেই শাখাটি চালায়।

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

এক্সপ্রেশনটি যদি বুলিয়ান মান না হয়, তাহলে মূল্যায়নই ঠিক করে দেয় মানটি "ট্রুথি" কি "ফলসি নয়"।
PHP-তে নিচের মানগুলো ফলসের সমান ধরা হয়:

- বুলিয়ান `false`
- ইন্টিজার `0`
- ফ্লোট `0.0` আর `-0.0`
- একটি খালি অ্যারে `[]`
- একটি খালি স্ট্রিং `""` বা একটি সাংখ্যিক স্ট্রিং `"0"`
- `null`

বাকি সব মান ট্রু ধরা হয়।

## একাধিক শর্তে সাড়া দেওয়া

একটি `if` স্টেটমেন্টের পরে আপনি `elseif` আর `else` দিয়ে একাধিক শর্ত জুড়ে দিতে পারেন।

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

ট্রু হিসেবে মূল্যায়িত হওয়া একটি শর্তাধীন স্টেটমেন্টই কেবল চালানো হবে।
তাই একাধিক শর্ত যদি ট্রু হিসেবে মূল্যায়িত হতে পারে, তাহলে সেগুলো যে ক্রমে লেখা হয়েছে সেটি গুরুত্বপূর্ণ।

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
