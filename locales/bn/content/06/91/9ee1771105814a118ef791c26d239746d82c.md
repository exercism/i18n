# নির্দেশনা

এই অনুশীলনীতে আপনি একটি জেনেরিক (আর ম্যাজিক্যাল!) TreasureChest লিখবেন, যাতে কিছু গুপ্তধন জমা রাখা যায়।

## 1. TreasureChest টাইপটি ডিফাইন করুন

দুটি ফিল্ডসহ একটি `TreasureChest{T}` প্যারামেট্রিক টাইপ ডিফাইন করুন।

- `String` টাইপের একটি `password` ফিল্ড, যা ট্রেজার চেস্টের পাসওয়ার্ড জমা রাখতে ব্যবহৃত হবে।
- `T` টাইপের একটি `treasure` ফিল্ড, যা গুপ্তধন জমা রাখতে ব্যবহৃত হবে।
এই মানটি জেনেরিক, যাতে গুপ্তধন যেকোনো কিছু হতে পারে।

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. get_treasure() ফাংশনটি ডিফাইন করুন

এই ফাংশনটি দুটি আর্গুমেন্ট নেবে।

- একটি `String` (পাসওয়ার্ড চেষ্টা করার জন্য)
- একটি `TreasureChest` টাইপ

এই ফাংশনটি প্রদত্ত পাসওয়ার্ডের চেষ্টাটি `TreasureChest`-এর `password`-এর সাথে মিলিয়ে দেখবে।

- পাসওয়ার্ডগুলো মিলে গেলে গুপ্তধনটি রিটার্ন করুন।
- পাসওয়ার্ডগুলো না মিললে `nothing` রিটার্ন করুন।

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. multiply_treasure() ফাংশনটি ডিফাইন করুন

এই ফাংশনটি দুটি আর্গুমেন্ট নেবে।

- একটি ইন্টিজার গুণক `n`।
- একটি `TreasureChest{T}` টাইপ।

ফাংশনটি একটি নতুন `TreasureChest{Vector{T}}` রিটার্ন করবে, যেখানে থাকবে

- আগেরটির মতোই একই পাসওয়ার্ড
- `n` দৈর্ঘ্যের একটি `Vector{T}` আকারে গুণিত গুপ্তধন, অর্থাৎ মূল গুপ্তধনটি `n` বার পুনরাবৃত্ত।

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
