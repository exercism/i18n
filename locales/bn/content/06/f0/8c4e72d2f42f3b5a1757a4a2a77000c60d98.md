# পরিচিতি

**রেগুলার এক্সপ্রেশন** (রেজেক্স) হলো এমন কিছু অক্ষরের ক্রম যা টেক্সটে একটি সার্চ প্যাটার্ন নির্দিষ্ট করে।

রেগুলার এক্সপ্রেশনের সিনট্যাক্স শেখা এই টপিকের পরিধির বাইরে।
আমরা রেজেক্স ব্যবহারের জন্য `jq` যে এক্সপ্রেশনগুলো দেয় সেগুলোতে মনোযোগ দেব।

## রেজেক্সের ধরন

ভিন্ন ভিন্ন টুল রেগুলার এক্সপ্রেশনের ভিন্ন ভিন্ন সংস্করণ বাস্তবায়ন করে।
`jq` এমন একটি [Oniguruma][oniguruma] রেজেক্স লাইব্রেরি অন্তর্ভুক্ত করে, যা অনেকাংশে Perl v5.8 রেজেক্সের সাথে সামঞ্জস্যপূর্ণ।

`jq`-এর ব্যবহৃত নির্দিষ্ট সিনট্যাক্স [Oniguruma GitHub রেপোতে পাওয়া যাবে][onig-syntax]।

## রেজেক্স ফাংশন

`jq`-এ রেগুলার এক্সপ্রেশন [কিছু ফিল্টারে][jq-regex-funcs] সীমাবদ্ধ।

### সাধারণ ম্যাচিং

কোনো স্ট্রিং কোনো প্যাটার্নের সাথে মেলে কিনা জানতে চাইলে `test` ফিল্টারটি ব্যবহার করুন।

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

এই ফিল্টারটি একটি _বুলিয়ান_ ফলাফল আউটপুট দেয়।

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### ম্যাচ সম্পর্কে তথ্য

যে সাবস্ট্রিংটি আসলে প্যাটার্নের সাথে মিলেছে সেটি বের করতে চাইলে `match` ফিল্টারটি ব্যবহার করুন।

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

এই ফিল্টারটি আউটপুট দেয়:

- কোনো মিল না থাকলে কিছুই না, অথবা
- মিল থাকলে বিভিন্ন প্রপার্টি সম্বলিত একটি অবজেক্ট।

এই উদাহরণটি `\1` ব্যাকরেফ সিনট্যাক্স ব্যবহার করে পরপর দুটি অভিন্ন স্বরবর্ণ খুঁজে বের করে।

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match` ফিল্টারটি _প্রতিটি_ মিলের জন্য একটি অবজেক্ট রিটার্ন করে।
এই উদাহরণে সব স্বরবর্ণ খুঁজে বের করার জন্য `"g"` ফ্ল্যাগটি কাজ করতে দেখা যায়।

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### ক্যাপচার করা সাবস্ট্রিং

`match` ফিল্টারের মতোই, `capture` ফিল্টারটি মিল থাকলে একটি অবজেক্ট রিটার্ন করে।

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

রিটার্ন করা অবজেক্টটি **নামযুক্ত ক্যাপচার**গুলোর একটি ম্যাপিং।

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### শুধু সাবস্ট্রিং

`scan` ফিল্টারটি `"g"` ফ্ল্যাগসহ `match`-এর মতোই।

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` সাবস্ট্রিংয়ের একটি _স্ট্রিম_ আউটপুট দেবে।

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

সাবস্ট্রিংগুলো ক্যাপচার করতে `[...]` অ্যারে কনস্ট্রাক্টরটি ব্যবহার করুন।

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### একটি স্ট্রিং ভাগ করা

স্ট্রিংয়ের যে অংশগুলো আপনি **রাখতে** চান সেগুলো জানা থাকলে `match` বা `scan` ব্যবহার করুন।
যে অংশগুলো আপনি **বাদ দিতে** চান সেগুলো জানা থাকলে `split` ব্যবহার করুন।

```jq
STRING | split(REGEX; FLAGS)
```

~~~~exercism/caution
**1-arity** `split` ফিল্টারটি তার আর্গুমেন্টকে একটি **নির্দিষ্ট স্ট্রিং** হিসেবে বিবেচনা করে।

`split`-এর সাথে রেজেক্স ব্যবহার করতে হলে আপনাকে **অবশ্যই** দ্বিতীয় আর্গুমেন্টটি দিতে হবে; খালি স্ট্রিং ব্যবহার করলেও সমস্যা নেই।
~~~~

<!-- prettier-ignore-end -->

একটি স্ট্রিংকে যেকোনো হোয়াইটস্পেসে ভাগ করার একটি উদাহরণ।

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### প্রতিস্থাপন

`sub` এবং `gsub` ফিল্টার ইনপুট স্ট্রিংকে রূপান্তর করতে পারে, ইনপুটের মিলে যাওয়া অংশগুলো একটি রিপ্লেসমেন্ট স্ট্রিং দিয়ে প্রতিস্থাপন করে।

শুধু প্রথম মিলটি প্রতিস্থাপন করতে `sub` ব্যবহার করুন।
সব মিল প্রতিস্থাপন করতে `gsub` ব্যবহার করুন।

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

রিপ্লেসমেন্ট টেক্সট মিলে যাওয়া সাবস্ট্রিংগুলোকে নির্দেশ করতে পারে; নামযুক্ত ক্যাপচার এবং [স্ট্রিং ইন্টারপোলেশন][jq-interp] ব্যবহার করুন।

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## ফ্ল্যাগ

উপরের সব ফিল্টারে FLAGS হলো সমর্থিত ফ্ল্যাগগুলোর শূন্য বা তার বেশি নিয়ে গঠিত একটি স্ট্রিং।

- `g` - গ্লোবাল সার্চ (শুধু প্রথমটি নয়, সব মিল খুঁজে বের করে)
- `i` - কেস ইনসেনসিটিভ সার্চ
- `m` - মাল্টি লাইন মোড ('.' নিউলাইনেও মিলবে)
- `n` - খালি মিল উপেক্ষা করে
- `p` - s এবং m উভয় মোডই সক্রিয় থাকে
- `s` - সিঙ্গেল লাইন মোড ('^' -> '\A', '$' -> '\Z')
- `l` - সম্ভাব্য দীর্ঘতম মিল খুঁজে বের করে
- `x` - এক্সটেন্ডেড রেজেক্স ফরম্যাট (হোয়াইটস্পেস ও কমেন্ট উপেক্ষা করে)

উদাহরণস্বরূপ

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
