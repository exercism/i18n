# নির্দেশাবলি

হঠাৎই আপনার মন নস্টালজিয়ায় ভরে যায়, আর পুরোনো Blorkemon™️ কার্ডগুলো ধুলো ঝেড়ে বের করার প্রবল ইচ্ছা জাগে।
Blorkemon™️ কার্ড একটি দারুণ, পুরোনো ঘরানার কার্ড ট্রেডিং গেম।
প্রতিটি `Card`-এ একটি Blorkemon™️ মনস্টার আঁকা থাকে, সঙ্গে থাকে আক্রমণ শক্তির মাত্রা, আর ভাগ্য সহায় হলে কার্ডটি চকচকেও হতে পারে।

## 1. শক্তির মাত্রা তুলনা করুন

প্রতিটি Blorkemon™️ কার্ড পরেরটির চেয়ে বেশি শক্তিশালী মনে হয়, তবে ভালো করে যাচাই করে নেওয়াই ভালো।

`isMorePowerful` ফাংশনটি লিখুন। এর প্রথম আর্গুমেন্টের কার্ডটি যদি অন্যটির চেয়ে সত্যিকারভাবে বেশি শক্তিশালী হয়, তবে এটি `True` রিটার্ন করবে, নাহলে `False`.

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. সর্বোচ্চ শক্তি খুঁজুন

হাতে একগুচ্ছ Blorkemon™️ কার্ড থাকলে আপনি সবচেয়ে ভয়ংকর আক্রমণ তৈরি করতে পারবেন।

`maxPower` ফাংশনটি লিখুন, যা দুটি কার্ডের মধ্যে সর্বোচ্চ শক্তির মাত্রা রিটার্ন করে।

```elm
maxPower newthree scientuna
    --> 120
```

## 3. কার্ডগুলো সাজান

মনে হচ্ছে আপনার প্রতিটি Blorkemon™️-এর অন্তত একটি করে কার্ড ছিল, তবে শেষবার দেখার পর অনেকদিন পেরিয়ে গেছে। Pulpapedia-র অফিসিয়াল তালিকার সঙ্গে মিলিয়ে দেখতে আপনার কার্ডগুলো সাজিয়ে নেওয়া উচিত।

`sortByMonsterName` ফাংশনটি লিখুন, যা `Cards`-এর একটি অ্যারে নেবে এবং মনস্টারের নাম অনুসারে সাজানো একটি অ্যারে রিটার্ন করবে।

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. সবচেয়ে কুল কার্ডগুলো আগে

Blorkemon™️ হলো পৃথিবীর সবচেয়ে কুল জিনিস।
এই কথাটা আপনি হালকাভাবে বলছেন না, এটা প্রমাণ করার জন্য আপনার হাতে একটি বৈজ্ঞানিক পদ্ধতি আছে।

`sortByCoolness` ফাংশনটি লিখুন, যা কার্ডের একটি অ্যারে সাজায় এবং সবচেয়ে কুল কার্ডগুলোকে প্রথমে রাখে।
একটি কার্ড কতটা কুল, তা প্রথমে নির্ধারিত হয় তার চকচকেভাব দিয়ে: যেসব কার্ড চকচকে, সেগুলো বাকিগুলোর চেয়ে অনেক বেশি কুল।
দ্বিতীয় বিষয়টি শক্তির মাত্রা, যত বেশি তত ভালো।

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. চকচকে শক্তি

চকচকেভাব শুধু দেখানোর জন্য নয়, সমান শক্তির দুই Blorkemon™️-এর লড়াইয়ে চকচকে কার্ডটি সবসময় জিতে যাবে।
একেই বলা হয় চকচকে শক্তি।

`compareShinyPower` ফাংশনটি লিখুন, যা এই বৈশিষ্ট্যটিকে নিয়মে বেঁধে দেয়।
দুটি কার্ডের শক্তির মাত্রা আলাদা হলে সেই শক্তির মাত্রা দিয়েই `Order` নির্ধারিত হয়, কিন্তু দুটো সমান হলে চকচকে কার্ডটিই বড় হিসেবে বিবেচিত হবে।

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. বাজি ধরুন

Blorkemon™️ কার্ডের গেমে যা খুশি হতে পারে, তবুও বেশি শক্তিশালী কার্ডের জেতার প্রবণতা থাকে।

`expectedWinner` ফাংশনটি লিখুন, যা `compareShinyPower`-এর ক্রম অনুসারে জেতার সম্ভাবনা সবচেয়ে বেশি এমন মনস্টারের নাম রিটার্ন করে।
ফাংশনটি প্রত্যাশিত বিজয়ী মনস্টারের নাম রিটার্ন করবে, আর দুই প্রতিদ্বন্দ্বীর চকচকে শক্তি সমান হলে রিটার্ন করবে "too close to call".

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
