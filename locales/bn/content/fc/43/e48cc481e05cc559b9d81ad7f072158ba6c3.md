# ভূমিকা

Swift-এ `guard` স্টেটমেন্টটি Swift ফাংশন থেকে আগাম রিটার্নের জন্য ব্যবহৃত হয়, যখন আরও প্রসেসিং চালিয়ে যাওয়ার জন্য পূরণ করা প্রয়োজন এমন একটি প্রয়োজনীয় শর্ত পূরণ না হয়, উদাহরণস্বরূপ:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

এখানে `guard` পরীক্ষা করে যে `guard` কীওয়ার্ডের পরে থাকা বুলিয়ান এক্সপ্রেশনটি ট্রু হিসেবে মূল্যায়িত হয় কি না। যদি হয়, তাহলে guard স্টেটমেন্টের পরের কোড দিয়ে প্রসেসিং চলতে থাকে (এখানে `let root = myValue.squareRoot()`. অন্যথায় এটি else ক্লজের কোডটি রান করবে। একটি `if` স্টেটমেন্টের বিপরীতে, একটি `guard` স্টেটমেন্টে _অবশ্যই_ একটি else ক্লজ থাকতে হবে, এবং if-else-এর else ক্লজের বিপরীতে, একটি guard-এর else ক্লজ _অবশ্যই_ guard স্টেটমেন্টের স্কোপ থেকে বেরিয়ে যেতে হবে। অর্থাৎ এটিকে অবশ্যই `return`, `continue`, `break`-এর মতো একটি কন্ট্রোল ট্রান্সফার স্টেটমেন্ট ব্যবহার করতে হবে, অথবা এটিকে একটি এরর থ্রো করতে হবে বা প্রোগ্রাম থেকে বেরিয়ে যেতে হবে।
