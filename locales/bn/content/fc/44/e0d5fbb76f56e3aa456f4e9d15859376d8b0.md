# সম্পর্কে

[Groovy](http://www.groovy-lang.org/) হলো Apache Foundation-এর একটি শক্তিশালী, ঐচ্ছিকভাবে টাইপড, ডাইনামিক ভাষা, যেটিতে স্ট্যাটিক টাইপিং ও স্ট্যাটিক কম্পাইলেশনের সুবিধাও রয়েছে।

Groovy-এর লক্ষ্য হলো সংক্ষিপ্ত ও সহজে শেখা যায় এমন সিনট্যাক্সের মাধ্যমে ডেভেলপারদের উৎপাদনশীলতা বাড়ানো।
এটি স্ক্রিপ্টিং, ডোমেইন-স্পেসিফিক ভাষা লেখা, রানটাইম ও কম্পাইল-টাইম মেটা-প্রোগ্রামিং এবং ফাংশনাল প্রোগ্রামিং সহজ করে তোলে।

এটি Java লাইব্রেরির পুরো ইকোসিস্টেমে অ্যাক্সেস দেয় এবং Java অ্যাপ্লিকেশনগুলোর সাথে নির্বিঘ্নে মিলে যায়।

এটিকে সাধারণ স্ক্রিপ্টিং ভাষা হিসেবে ব্যবহার করা যায়, আবার জটিল Java ফ্রেমওয়ার্কেও যুক্ত করা যায়।
এটি যেসব প্রযুক্তিকে শক্তি দেয়:
* Gradle,
* Spock,
* Ratpack,
* Grails,
* এবং Jenkins-এ স্ক্রিপ্টিং।

আর মজার তো বটেই।
