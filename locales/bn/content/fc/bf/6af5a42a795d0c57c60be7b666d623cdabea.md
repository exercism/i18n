# Char

`Char` হলো Crystal-এর একটি ডেটা টাইপ, যা একটি ৩২-বিট [ইউনিকোড][unicode] কোড পয়েন্ট প্রকাশ করে। এদের আকার এদের মেমোরি-সাশ্রয়ী করে তোলে এবং স্ট্রিং-এর নেই এমন কিছু নির্দিষ্ট বৈশিষ্ট্য এদের দেয়। এগুলো একক কোট (`'`) দিয়ে তৈরি করা হয় এবং ভেতরে কেবল একটি ইউনিকোড কোড পয়েন্ট রাখার অনুমতি দেয়।

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystal-এ স্ট্রিং নিয়ে কাজ করার সময় Char নিয়ে কাজ করা বেশ সাধারণ ব্যাপার, কারণ String ক্লাসের বেশ কিছু মেথড Char রিটার্ন করে বা আর্গুমেন্ট হিসেবে Char নেয়। উদাহরণস্বরূপ, [`String#[]`][index] মেথডটি একটি Char রিটার্ন করে, আবার [`String#chars`][chars] মেথডটি Char-এর একটি সমাহার রিটার্ন করে।

## ইনক্রিমেন্ট / ডিক্রিমেন্ট

যেহেতু char একটি ৩২ ইউনিকোড পয়েন্ট, তাই এরা ইনক্রিমেন্ট ও ডিক্রিমেন্ট সমর্থন করে। এর ফলে আপনার কাছে `'a'` থাকলে এক যোগ করে আপনি `'b'` পেতে পারেন।

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

এছাড়া [`Char#succ`][succ] নামে একটি মেথডও আছে, যা ইউনিকোড টেবিলের পরবর্তী char রিটার্ন করে, এবং [`Char#pred`][pred], যা ইউনিকোড টেবিলের পূর্ববর্তী char রিটার্ন করে।

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## concatenation

যেহেতু Chars কেবল একটি ৩২-বিট ইউনিকোড প্রকাশের জন্য বোঝানো হয়েছে, তাই দুটি char concatenate করা যায় না। তাই Chars কেবল Strings-এর সাথে concatenate করা যায়।

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## বৈশিষ্ট্যের মেথড

একটি Character সম্পর্কে তথ্য পাওয়ার জন্য Crystal-এ কয়েকটি মেথড আছে, যেমন সেটি একটি সংখ্যা বা অক্ষর কি না, কিংবা সেটি uppercase বা lowercase কি না। এখানে এমন কিছু মেথডের তালিকা দেওয়া হলো, সম্পূর্ণ তালিকার জন্য [Char API][char-api] দেখুন:

| মেথড                             | বর্ণনা                                                |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Char একটি সংখ্যা হলে `true` রিটার্ন করে              |
| [`Char#letter?`][letter]         | Char একটি অক্ষর হলে `true` রিটার্ন করে               |
| [`Char#lowercase?`][lowercase]   | Char lowercase হলে `true` রিটার্ন করে                |
| [`Char#uppercase?`][uppercase]   | Char uppercase হলে `true` রিটার্ন করে                |
| [`Char#ascii?`][ascii]           | Char একটি ASCII অক্ষর হলে `true` রিটার্ন করে         |
| [`Char#whitespace?`][whitespace] | Char একটি হোয়াইটস্পেস অক্ষর হলে `true` রিটার্ন করে  |

## রূপান্তর

### কোড পয়েন্ট ও Chars-এর মধ্যে রূপান্তর

যেহেতু Chars একটি ৩২-বিট ইউনিকোড পয়েন্ট, তাই Chars ও কোড পয়েন্টের (Int) মধ্যে রূপান্তর করা যায়। এটি করা যায় [`Char#ord`][ord] মেথড দিয়ে, যা Char-এর কোড পয়েন্ট রিটার্ন করবে, অথবা [`Int#chr`][chr] মেথড দিয়ে, যা কোড পয়েন্টের Char রিটার্ন করবে।

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### টাইপের মধ্যে রূপান্তর

অন্য ডেটা টাইপের মতোই, char-এর মধ্যে টাইপের মধ্যে রূপান্তর করার কয়েকটি মেথড আছে। সবচেয়ে বেশি ব্যবহৃতটি হলো `Char#to_s` মেথড, যা Char-কে একটি String-এ রূপান্তর করে। তবে `Char#to_i` মেথডও আছে, যা Char-কে একটি Int-এ রূপান্তর করে, এবং `Char#to_f` মেথড, যা Char-কে একটি Float-এ রূপান্তর করে।

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
