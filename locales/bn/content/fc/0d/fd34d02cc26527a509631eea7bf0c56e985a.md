# ক্যারেক্টার

একটি **ক্যারেক্টার** হলো একটি একক অক্ষর, অঙ্ক, ফাঁকা জায়গা বা চিহ্ন। Sather-এ এটির টাইপ `CHAR`, আর একটি ক্যারেক্টার লেখা হয় একক কোটেশনের ভেতরে।

```sather
   initial : CHAR is
      return 'M';
   end;
```

একটি ক্যারেক্টারের জন্য একক কোটেশন, আর একটি স্ট্রিংয়ের জন্য দ্বৈত কোটেশন। `'M'` আর `"M"` আলাদা টাইপ, একটির জায়গায় আরেকটি ব্যবহার করা যায় না।

## স্ট্রিং থেকে ক্যারেক্টার

একটি স্ট্রিং হলো ক্যারেক্টারের সারি, আর তৃতীয় বন্ধনী `[]` দিয়ে অবস্থান ধরে ধরে একটি ক্যারেক্টার বের করা যায়, গণনা শুরু হয় শূন্য থেকে, ঠিক অ্যারের মতোই।

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## একটি ক্যারেক্টার সম্পর্কে জিজ্ঞাসা

| কল | উত্তর |
| --- | --- |
| `c.is_alpha` | এটি কি একটি অক্ষর? |
| `c.is_digit` | এটি কি `0`–`9`-এর একটি? |
| `c.is_upper` | এটি কি বড় হাতের অক্ষর? |
| `c.is_lower` | এটি কি ছোট হাতের অক্ষর? |

প্রতিটির উত্তর `true` বা `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## বড় হাতের ও ছোট হাতের অক্ষরে পরিবর্তন

`.upper` একটি অক্ষরের বড় হাতের রূপ দেয়, আর `.lower` দেয় ছোট হাতের রূপ। অক্ষর নয় এমন যেকোনো কিছু অপরিবর্তিত অবস্থায় ফিরিয়ে দেওয়া হয়।

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## সংখ্যা হিসেবে ক্যারেক্টার

প্রতিটি ক্যারেক্টারের একটি সংখ্যা থাকে। `.int` সেটি দেয়, আর `.char` একটি সংখ্যাকে আবার ক্যারেক্টারে রূপান্তর করে।

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

কোন সংখ্যাটি ঠিক কত, সেটি খুব একটা গুরুত্বপূর্ণ নয়। গুরুত্বপূর্ণ হলো `a` থেকে `z` পর্যন্ত অক্ষরগুলো ক্রমানুসারে এবং একটির পাশে আরেকটি থাকে, তাই `'c'.int - 'a'.int` হলো 2, অর্থাৎ বর্ণমালায় `c` কতটা এগিয়ে আছে। এই কারণেই একটি সাইফার হুইল কাজ করে।
