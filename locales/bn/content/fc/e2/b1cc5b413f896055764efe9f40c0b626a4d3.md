# ম্যাপ ও সেট

| ধরন | যা ধরে রাখে | যা দিয়ে খোঁজা হয় |
| --- | --- | --- |
| `ARRAY{T}` | ক্রমানুসারে সাজানো মান | অবস্থান |
| `FMAP{K,T}` | কী (key)-টার্গেট জোড়া | কী (key) |
| `FSET{T}` | মান, পুনরাবৃত্তি ছাড়া | সদস্যতা |

## FMAP

```sather
   m ::= #FMAP{STR,INT};
   m := m.insert("emu", 2);
   m.get("emu")          -- 2
   m.has_ind("emu")      -- true
   m.size                -- 1
   m := m.delete("emu");
```

`m["emu"]` দিয়ে ম্যাপ পড়া যায় **না**। `FMAP`-এ এমন কোনো রুটিন নেই, আর ওই লাইনটি কম্পাইলই হবে না। এর জন্য `get` ব্যবহার করতে হয়।

### অনুপস্থিত কী (key)

যে কী (key) নেই, সেখানে `get` চালালে অভিযোগ করার বদলে ওই টাইপের খালি মানটাই উত্তর আসে: `0`, `false` বা void। একটি void `STR` যে জায়গায় তৈরি হয় সেখানে ব্যর্থ হয় না; ব্যর্থ হয় পরে, যেখানে শেষ পর্যন্ত এটি ব্যবহার করা হয়। আগে `has_ind` চালানোর অভ্যাসটা গড়ে তোলাই ভালো।

## FSET

```sather
   s ::= #FSET{STR};
   s := s.insert("emu");
   s.has("emu")          -- true
   s.size                -- 1
   s := s.delete("emu");
```

সেট একত্র করা যায়:

```sather
   a.union(b)            -- in either
   a.intersect(b)        -- in both
   a.difference(b)       -- in a but not b
   a.is_subset(b)
```

## আবার অ্যাসাইন করা, আর কপি করা

`insert` আর `delete` ফেরত দেয় এখন থেকে কোন কন্টেইনারটি ব্যবহার করবেন তা। সাধারণত সেটি একই অবজেক্ট, জায়গাতেই বদলে যায়; যখন এটিকে বড় হতে হয়, তখন সেটি নতুন, আরও বড় একটি অবজেক্ট। তাই:

```sather
   m := m.insert(k, v);     -- always
```

আর এরপর বাঁ দিকের নামটিই একমাত্র ভরসার জায়গা। একই ম্যাপের অন্য একটা নাম, যা `insert`-এর আগে নেওয়া হয়েছিল, সেটি পুরোনো হয়ে যেতে পারে।

স্বাধীন একটি কপি রাখতে চাইলে আগে কপি নিয়ে নিন:

```sather
   n ::= m.copy.insert(k, v);      -- m is unchanged
```

তবে একটা ফাঁদ আছে: যে ম্যাপে কখনো কিছু ইনসার্ট করা হয়নি সেটি **void**, আর void ম্যাপে `copy` ব্যর্থ হয়। `insert`, `get`, `has_ind` আর `size` সবই void ম্যাপ সামলাতে পারে। `#FMAP{K,T}` তো void, আর তাতে ইনসার্ট করাই ম্যাপ প্রথম অস্তিত্বে আসার উপায়। কিন্তু `copy` তা পারে না।

`HMAP` আর `HSET` এমন সংস্করণ, যারা কেবল জায়গাতেই বদলায়। বড় কিছু গড়তে এরা দ্রুত, আর শেখার সময় এরা ভুল ডিফল্ট।

## ঘুরে ঘুরে দেখা

| ইটারেটর | যা দেয় |
| --- | --- |
| `m.ind!` | প্রতিটি কী (key) |
| `m.target!` | প্রতিটি টার্গেট |
| `m.pair!` | প্রতিটি কী (key) ও টার্গেট একসাথে |
| `s.elt!` | সেটের প্রতিটি মান |

ম্যাপ বা সেট, কোনওটারই কোনো ক্রম নেই। দুবার রান করলে এদের ঘোরার ক্রম আলাদা হতে পারে, তাই কোনটি আগে আসে তার উপর নির্ভর করে কিছু লিখবেন না।
