# নির্দেশনা

নৃত্য দলের প্রতিটি রুটিন একই ওয়ার্ম-আপের ওপর দাঁড়িয়ে তৈরি, এরপর প্রত্যেকে নিজের পথে এগিয়ে যায়।

স্টাব আপনাকে `WARM_UP` দিয়েছে। এর নিচে আরও তিনটি ক্লাস লিখুন।

## 1. জ্যাজ রুটিন

`JAZZ_ROUTINE` অপরিবর্তিত অবস্থায় `WARM_UP` থেকে সবকিছু নেয়, এবং নতুন কিছু যোগ করে না।

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. ট্যাপ রুটিন

`TAP_ROUTINE` `WARM_UP` থেকে `counts` নেয়, কিন্তু নিজেকে বর্ণনা করে নিজের মতো করে। include থেকে `describe` বাদ দিন এবং নতুন একটি লিখুন।

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. ফিনালে

`FINALE` `warm_up_counts` নামে `WARM_UP` থেকে `counts` নেয়, এবং `describe` বাদ দেয়। এরপর এর নিজস্ব `counts` থাকে, যা ওয়ার্ম-আপের দ্বিগুণ, এবং নিজস্ব `describe` থাকে।

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

লক্ষ করুন এটা কী দেখায়: `FINALE::counts` আর `WARM_UP::counts` এক নয়, এবং দুটোই একই ক্লাসে ভিন্ন নামে পাওয়া যায়।
