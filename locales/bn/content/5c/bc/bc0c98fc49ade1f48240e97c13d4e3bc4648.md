# পরিচিতি

## Result

Elm ভাষায় এরর রিপোর্ট করার সমাধান এবং এরর থেকে পুনরুদ্ধার সম্ভব করে তোলার একটি উপায় হলো `Result` টাইপ। এটি কিছুটা `Maybe` টাইপের মতো, তবে `Maybe` ব্যর্থ হতে পারে এমন ফাংশন থেকে রিটার্ন করা গেলেও কেন ব্যর্থ হলো সে সম্পর্কে কিছুই জানায় না। `Result` কেন কিছু ব্যর্থ হলো, সেই প্রসঙ্গটিও সঙ্গে রাখে।

`Result` টাইপটি এভাবে ডিফাইন করা হয়:

```elm
type Result error value
  = Ok value
  | Err error
```

Elm-এর পরিভাষায় এটিকে কাস্টম টাইপ ডেফিনিশন বলা হয়।
`OK value` আর `Error error`-এর `error` ও `value` একটি টাইপ ভ্যারিয়েবল বোঝায়, অর্থাৎ এটি যেকোনো টাইপ হতে পারে, যেমন `Int`, `Bool` বা `String`।
তাই `Result String Int` হলো এমন একটি ভ্যারিয়েবল, যেটিতে একটি `Int` থাকবে বলে আশা করা হয়, আর কোনো এরর থাকলে সেটি একটি `String` হিসেবে প্রকাশ পাবে।
Result-এর জন্য অনেক কাজের হেল্পার ফাংশন নিয়ে একটি [Result মডিউল](https://package.elm-lang.org/packages/elm/core/latest/Result) আছে।
