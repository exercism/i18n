# পরিচিতি

একটি অ্যারে একটি _কালেকশন_ও হওয়ার অর্থ হলো, ইনডেক্স দিয়ে মান অ্যাক্সেস করা ছাড়াও আপনি একটি `foreach` লুপ ব্যবহার করে এর _সব_ মানের উপর ইটারেট করতে পারেন:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
