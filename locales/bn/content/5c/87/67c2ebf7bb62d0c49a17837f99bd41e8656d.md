# ভূমিকা

## ফ্যান্টম টাইপ

ফ্যান্টম টাইপ হলো একটি কাস্টম টাইপের টাইপ প্যারামিটার, যা ওই টাইপের কোনো মান কনস্ট্রাক্টরে ব্যবহার করা হয় না।

এটা একটু বিমূর্ত শোনাচ্ছে, তাই চলুন একটি উদাহরণ দেখি:

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

এই উদাহরণে `unit` টাইপ প্যারামিটারটি `Length`-এর মান কনস্ট্রাক্টরে ব্যবহার করা হয়নি, তাই `unit` একটি ফ্যান্টম টাইপ।

ব্যবহার না করা এই টাইপ প্যারামিটারটি হয়তো অকাজো মনে হতে পারে, কিন্তু এটি দিয়ে `Length` মানগুলো কীভাবে ব্যবহার করা যাবে তার উপর আরও কিছু বিধিনিষেধ যোগ করা যায়।

উদাহরণস্বরূপ, আমাদের একটি `double` ফাংশন থাকতে পারে, যা দৈর্ঘ্যকে গুণ করে। এটি যেকোনো এককের দৈর্ঘ্যের সাথে কাজ করে, তাই টাইপ প্যারামিটারটি একটি জেনেরিক টাইপ ভ্যারিয়েবল।

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

আমাদের একটি `add_inch` ফাংশনও থাকতে পারে, যা কেবল তখনই কাজ করে যখন দৈর্ঘ্যটি ইঞ্চিতে থাকে।

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

`add_inch` ফাংশনটি অন্য কোনো একক প্যারামিটারের দৈর্ঘ্য গ্রহণ করবে না; সঠিক এককটিই যেন ব্যবহার হয়, তা নিশ্চিত করতে ফ্যান্টম টাইপটি কাজে লাগানো হয়েছে।

দুটি দৈর্ঘ্যের মান যেন একই এককের হয়, তা নিশ্চিত করেও একটি ফাংশন লেখা যায়, দুটির জন্যই একই টাইপ ভ্যারিয়েবল ব্যবহার করে।

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

ফ্যান্টম টাইপ ওপেক টাইপের সাথে বেশ ভালোভাবে কাজ করতে পারে। অন্য মডিউলগুলো যদি `Length` মান তৈরি করতে না পারে, তাহলে আমরা নিশ্চিত করতে পারি যে ভুল একক টাইপ দিয়ে সেগুলো তৈরি হচ্ছে না, এবং শুধু উপরে ডিফাইন করা ফাংশনগুলোই সেগুলোর সাথে ব্যবহার করা যাবে।
