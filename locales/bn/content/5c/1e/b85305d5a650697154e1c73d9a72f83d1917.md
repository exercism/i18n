# নির্দেশনা

এই অনুশীলনীতে আপনি একটি রিমোট কন্ট্রোলড কার নিয়ে খেলবেন, যেটি কেনার জন্য আপনি অবশেষে যথেষ্ট টাকা জমাতে পেরেছেন।

কারগুলো সম্পূর্ণ (100%) ব্যাটারি নিয়ে শুরু করে।
রিমোট কন্ট্রোল দিয়ে আপনি প্রতিবার কারটি চালালে এটি 20 মিটার পথ পাড়ি দেয় এবং ব্যাটারির এক শতাংশ কমিয়ে দেয়।
কারটি তৈরি হওয়ার আগে পর্যন্ত তার ডাকনাম জানা যায় না।

রিমোট কন্ট্রোলড কারটিতে একটি অভিনব LED ডিসপ্লে আছে, যা দুই ধরনের তথ্য দেখায়:

- এটি মোট যে দূরত্ব চালিয়েছে, যা এভাবে দেখানো হয়: `"<METERS> meters"`।
- ব্যাটারিতে বাকি চার্জ, যা এভাবে দেখানো হয়: `"Battery at <PERCENTAGE>%"`।

ব্যাটারি 0% হলে আপনি আর কারটি চালাতে পারবেন না, এবং ব্যাটারি ডিসপ্লেতে `"Battery empty"` দেখাবে।

## 1. একেবারে নতুন একটি রিমোট কন্ট্রোলড কার তৈরি করুন

একেবারে নতুন একটি রিমোট কন্ট্রোলড কার অবজেক্ট রিটার্ন করার জন্য `new_remote_control_car/0` ফাংশনটি ইমপ্লিমেন্ট করুন:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. ডাকনামসহ একেবারে নতুন একটি রিমোট কন্ট্রোলড কার তৈরি করুন

প্রদত্ত ডাকনামসহ একেবারে নতুন একটি রিমোট কন্ট্রোলড কার অবজেক্ট রিটার্ন করার জন্য `new_remote_control_car/1` ফাংশনটি ইমপ্লিমেন্ট করুন:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. দূরত্ব দেখান

এমন একটি `display_distance/0` ফাংশন ইমপ্লিমেন্ট করুন যা ইনপুট হিসেবে একটি কার অবজেক্ট নেয় এবং LED ডিসপ্লেতে যেমনটি দেখানো হয় সেই দূরত্বের স্ট্রিং আউটপুট দেয়:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. ব্যাটারির শতাংশ দেখান

এমন একটি `display_battery/0` ফাংশন ইমপ্লিমেন্ট করুন যা ইনপুট হিসেবে একটি কার অবজেক্ট নেয় এবং LED ডিসপ্লেতে যেমনটি দেখানো হয় সেই ব্যাটারি শতাংশের স্ট্রিং আউটপুট দেয়:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

ব্যাটারি 0% হলে ব্যাটারি ডিসপ্লেতে "Battery empty" দেখাবে।

## 5. চালালে ব্যাটারি ও অতিক্রান্ত দূরত্ব বদলে যায়

এমন একটি `drive/0` ফাংশন ইমপ্লিমেন্ট করুন যা:

- ইনপুট হিসেবে একটি কার অবজেক্ট নেয়
- অতিক্রান্ত মিটারের সংখ্যা 20 বাড়ায়
- ব্যাটারির 1% কমায়
- পরিবর্তিত কার অবজেক্ট আউটপুট দেয়

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. ব্যাটারি শেষ হয়ে গেলে চালানোর বিষয়টি বিবেচনায় নিন

ব্যাটারি শেষ হয়ে গেলে (0%-এ থাকলে) অতিক্রান্ত দূরত্ব যাতে না বাড়ে এবং ব্যাটারির শতাংশ যাতে না কমে, সেভাবে `drive/0` ফাংশনটি হালনাগাদ করুন:

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
