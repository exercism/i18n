# নির্দেশনা

আপনি একজন শিক্ষক।
বছরের শেষে, আপনি আপনার প্রতিটি শিক্ষার্থীর জন্য একটি সংখ্যাসূচক গ্রেড তৈরি করেছেন।
এখন আপনাকে সেটিকে একটি লেটার গ্রেডে রূপান্তর করতে হবে এবং কতজন শিক্ষার্থী কোন লেটার গ্রেড পেয়েছে তা গুনতে হবে।

## 1. একটি সংখ্যাসূচক গ্রেডকে লেটার গ্রেডে রূপান্তর করুন

`letter_grade` ফাংশনটি ইনপুট হিসেবে একটি সংখ্যাসূচক গ্রেড নেবে, এবং আউটপুট হিসেবে লেটারটি দেবে।
এই রেঞ্জগুলো ব্যবহার করুন:

| লেটার |      গ্রেড |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

উদাহরণ:

```jq
75 | letter_grade   # => "C"
```

## 2. প্রতিটি লেটার গ্রেডের জন্য শিক্ষার্থীর সংখ্যা গণনা করুন

`count_letter_grades` ফাংশনটি শিক্ষার্থীদের নাম থেকে তাদের গ্রেডে ম্যাপ করা একটি অবজেক্ট নেবে।
আউটপুট হবে প্রতিটি লেটার গ্রেড থেকে সেই গ্রেড পাওয়া শিক্ষার্থীর সংখ্যায় ম্যাপ করা একটি অবজেক্ট।

উদাহরণ:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

এটি সমাধান করার কয়েকটি ভিন্ন উপায় আছে।
অনুশীলনের জন্য `reduce` ফিল্টারটি ব্যবহার করুন।
