# ভূমিকা

Elm-এ টেক্সট উপস্থাপনার মূল ভিত্তি হলো ক্যারেক্টার আর স্ট্রিং।
স্ট্রিংকে ক্যারেক্টারের অ্যারে হিসেবে ভাবা যায়, আর `List`-এর বেশিরভাগ ফাংশনের সমতুল্য ফাংশন `String` মডিউলে আছে।

## ক্যারেক্টার

`Char` টাইপটি একক উদ্ধৃতি চিহ্ন দিয়ে লেখা একটি ইউনিকোড ক্যারেক্টার বোঝায়, যেমন `'a'`।
`Char` মডিউলটি একটি ক্যারেক্টারের গুণ যাচাই করার জন্য প্রেডিকেট ফাংশন (`Char -> Bool`) দেয়: `isUpper`, `isLower`, `isAlpha`, আর `isAlphaNum`।
মডিউলটি আবার একটি ক্যারেক্টারকে `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower` দিয়ে রূপান্তর করার ফাংশনও দেয়, এবং `toCode` ও `fromCode` দিয়ে তার সংখ্যাগত ইউনিকোড মানের (`Int`) সাথে যাওয়া-আসার ফাংশনও দেয়।

## স্ট্রিং

`String` টাইপটি দক্ষভাবে স্ট্রিং নিয়ে কাজ করার জন্য একটি বিল্ট-ইন উপস্থাপনা দেয় এবং যেকোনো ইউনিকোড ক্যারেক্টারের ক্রম উপস্থাপন করতে পারে।
স্ট্রিং দ্বৈত উদ্ধৃতি চিহ্ন দিয়ে লেখা হয়: `"this is a string"`.
বহু-লাইনের স্ট্রিং তিনটি দ্বৈত উদ্ধৃতি চিহ্ন দিয়ে লেখা হয় এবং এতে এস্কেপ না করা উদ্ধৃতি চিহ্ন ও নতুন লাইন থাকতে পারে।

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## স্ট্রিং নিয়ে কাজ করা

`reverse : String -> String` স্ট্রিংটি উল্টে দেয়।
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` একটি স্ট্রিং n বার পুনরাবৃত্তি করে।
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` প্রদত্ত একটি সাবস্ট্রিংয়ের সব উপস্থিতি বদলে দেয়।
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` দুটি স্ট্রিং জুড়ে দেয়।
এই কাজটি `++` অপারেটর দিয়েও করা যায়।
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` স্ট্রিংয়ের একটি অ্যারের সব স্ট্রিং জুড়ে দিয়ে একটি স্ট্রিং তৈরি করে।
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` প্রদত্ত সেপারেটরে একটি স্ট্রিংকে স্ট্রিংয়ের অ্যারেতে ভাগ করে।
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` প্রদত্ত একটি সেপারেটর দিয়ে স্ট্রিংয়ের একটি অ্যারের সব স্ট্রিং জুড়ে দেয়।
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` একটি স্ট্রিংকে স্ট্রিংয়ে ভাগ করে, হোয়াইটস্পেসের টুকরো ধরে ভাগ করে।
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` একটি স্ট্রিংকে লাইনে ভাগ করে, নতুন লাইন ধরে ভাগ করে।
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` একটি স্ট্রিংয়ের শুরুতে একটি ক্যারেক্টার যোগ করে।
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` খালি নয় এমন একটি স্ট্রিংকে তার মাথা আর লেজে ভাগ করে।
এটি দিয়ে আপনি ঠিক অ্যারের মতোই স্ট্রিংয়ের উপর প্যাটার্ন ম্যাচ করতে পারেন।
খালি স্ট্রিং `Nothing` রিটার্ন করে।
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## সাবস্ট্রিং বের করা

`slice : Int -> Int -> String -> String` শুরু আর শেষ ইনডেক্স দিয়ে একটি সাবস্ট্রিং নেয়।
ঋণাত্মক ইনডেক্স অ্যারের শেষ থেকে গোনা হয়।
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` আর `right : Int -> String -> String` যথাক্রমে স্ট্রিংয়ের বাম বা ডান দিক থেকে n টি ক্যারেক্টার নেয়।

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` আর `dropRight : Int -> String -> String` যথাক্রমে একটি স্ট্রিংয়ের বাম বা ডান দিক থেকে n টি ক্যারেক্টার বাদ দেয়।
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## স্ট্রিংয়ের বৈশিষ্ট্য যাচাই করা

`length : String -> Int` একটি স্ট্রিংয়ে কতগুলো ক্যারেক্টার আছে তা রিটার্ন করে।
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` একটি স্ট্রিং খালি কি না তা নির্ণয় করে।
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` দ্বিতীয় স্ট্রিংটিতে প্রথমটি আছে কি না তা যাচাই করে।
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` আর `endsWith : String -> String -> Bool` দ্বিতীয় স্ট্রিংটি প্রদত্ত একটি সাবস্ট্রিং দিয়ে শুরু হয় কি শেষ হয় তা যাচাই করে।
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` আরেকটি স্ট্রিংয়ে একটি সাবস্ট্রিংয়ের সব শুরুর ইনডেক্সের অ্যারে দেয়।
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## স্ট্রিং রূপান্তর করা
`toInt : String -> Maybe Int` একটি স্ট্রিংকে `Just Int`-এ রূপান্তর করার চেষ্টা করে, আর ভুল ফরম্যাটের স্ট্রিংয়ের জন্য `Nothing` রিটার্ন করে।
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` একটি ইন্টিজারকে স্ট্রিংয়ে রূপান্তর করে।
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` একটি স্ট্রিংকে ফ্লোটে রূপান্তরের চেষ্টা করে, আর ভুল ফরম্যাটের স্ট্রিং হলে ব্যর্থ হয়।
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` একটি ফ্লোটকে স্ট্রিংয়ে রূপান্তর করে।
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` আর `fromList : List Char -> String` যথাক্রমে একটি স্ট্রিংকে ক্যারেক্টারের অ্যারেতে এবং ক্যারেক্টারের অ্যারে থেকে স্ট্রিংয়ে রূপান্তর করে।
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` একটি ক্যারেক্টারকে স্ট্রিংয়ে রূপান্তর করে।
```elm
fromChar 'a' 
    --> "a"
```

## স্ট্রিং ফরম্যাট করা

`toUpper : String -> String` আর `toLower : String -> String` যথাক্রমে স্ট্রিংকে সব বড় হাতের বা সব ছোট হাতের অক্ষরে রূপান্তর করে।
কেস-নিরপেক্ষ তুলনার জন্য দরকারি।
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` প্রদত্ত `Char` দিয়ে স্ট্রিংয়ের দুই পাশে প্যাড করে, যতক্ষণ না তা প্রদত্ত দৈর্ঘ্যে পৌঁছায়।
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
একইভাবে, `padLeft` আর `padRight` স্ট্রিংয়ের এক পাশে প্যাড করে, যতক্ষণ না তা প্রদত্ত দৈর্ঘ্যে পৌঁছায়।

`trim : String -> String` একটি স্ট্রিংয়ের দুই পাশ থেকে হোয়াইটস্পেস সরিয়ে দেয়।
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` আর `trimRight` একটি স্ট্রিংয়ের এক পাশ থেকে হোয়াইটস্পেস সরিয়ে দেয়।

## উচ্চ ক্রমের ফাংশন

`map : (Char -> Char) -> String -> String` প্রদত্ত ফাংশন দিয়ে একটি স্ট্রিংয়ের প্রতিটি ক্যারেক্টার রূপান্তর করে।
মনে রাখবেন, যে ফাংশনটি দেওয়া হবে সেটি `Char` থেকে `Char`-এ ম্যাপিং হতে হবে।
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` শুধু যে ক্যারেক্টারগুলো পরীক্ষায় পাস করে সেগুলো রাখে।
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` বাম দিক থেকে শুরু করে একটি স্ট্রিং রিডিউস করে।
ফাংশনটি প্রথম ক্যারেক্টারকে তার প্রথম প্যারামিটার হিসেবে এবং প্রদত্ত একটি প্রাথমিক মানকে দ্বিতীয় প্যারামিটার হিসেবে নিয়ে প্রয়োগ করা হয়।
ফাংশনের ফলাফলটি প্রদত্ত প্রাথমিক মানের মতোই একই টাইপের হতে হবে, আর এটি ক্রমান্বয়ে প্রতিটি ক্যারেক্টারের উপর প্রয়োগ করা হয়।
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` একই কাজ করে, তবে স্ট্রিংয়ের ডান দিক থেকে শুরু করে।

`any : (Char -> Bool) -> String -> Bool` প্রদত্ত প্রেডিকেটে কোনো ক্যারেক্টার `True` রিটার্ন করে কি না তা নির্ণয় করে।
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` প্রদত্ত প্রেডিকেটে একটি স্ট্রিংয়ের সব ক্যারেক্টার `True` রিটার্ন করে কি না তা নির্ণয় করে।
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
