# পরিচিতি

## সংখ্যা

Python-এ বিল্ট-ইন সংখ্যা তিন ধরনের: `ints`, `floats`, এবং `complex`। তবে এই অনুশীলনীতে আপনি কেবল `ints` আর `floats` নিয়েই কাজ করবেন।

### ints

`ints` হলো পূর্ণসংখ্যা। যেমন `1234`, `-10`, `20201278`।

Python-এর ইন্টিজারগুলোর [আরবিট্রারি প্রিসিশন][arbitrary-precision] থাকে, অর্থাৎ অঙ্কের সংখ্যা কেবল হোস্ট সিস্টেমের উপলব্ধ মেমোরি দিয়েই সীমাবদ্ধ।

### floats

`floats` হলো দশমিক বিন্দুযুক্ত সংখ্যা। যেমন `0.0`, `3.14`, `-9.01`।

ফ্লোটিং পয়েন্ট সংখ্যা সাধারণত Python-এ C-এর একটি `double` দিয়ে বাস্তবায়িত হয় (_দশমিকের পর ১৫ ঘর নির্ভুলতা_), তবে হোস্ট সিস্টেম ও অন্যান্য বাস্তবায়নের খুঁটিনাটি অনুযায়ী এর রূপ বদলে যেতে পারে। ফ্লোট নিয়ে কাজ করার সময় এতে কিছু চমক তৈরি হতে পারে, তবে বেশিরভাগ ক্ষেত্রেই এটি "যথেষ্ট ভালো"।

আরও বিস্তারিত ও আলোচনা দেখতে পারেন এই রিসোর্সগুলোতে:

## পাটিগণিত

Python `ints` আর `floats`-এর মধ্যে পাটিগণিত সম্পূর্ণভাবে সমর্থন করে। বাইনারি পাটিগণিত অপারেটরগুলো (`+`, `-`, `*`, `/`, `//`, এবং `%`) ব্যবহার করলে এটি সংকীর্ণ সংখ্যাগুলোকে তাদের কম-সংকীর্ণ প্রতিরূপের সাথে মিলিয়ে রূপান্তর করে।

Python `ints`-কে `floats`-এর চেয়ে সংকীর্ণ মনে করে। তাই এক্সপ্রেশনে একটি ফ্লোট ব্যবহার করলে ফলাফলও যে ফ্লোট হবে, তা নিশ্চিত। তবে ভাগ করার সময়, শুধু ইন্টিজার ব্যবহার করলেও ফলাফল সবসময় ফ্লোট হবে।

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

ইন্টিজার ফলাফল দরকার হলে, ফলাফল ছেঁটে ফেলতে `//` ব্যবহার করতে পারেন।

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

একটি ফ্লোটকে ইন্টিজারে রূপান্তর করতে `int()` ব্যবহার করতে পারেন। আর একটি ইন্টিজারকে ফ্লোটে রূপান্তর করতে `float()`।

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
