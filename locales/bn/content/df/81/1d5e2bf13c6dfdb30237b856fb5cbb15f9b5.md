# সম্পর্কে

Common Lisp প্রিন্টার হলো স্ট্রিমে ডেটা আউটপুট করার ব্যবস্থা। এই ব্যবস্থার একটি কমন ফাংশন হলো `format`।

`format` দুটি আবশ্যক প্যারামিটার নেয়: যে স্ট্রিমে লিখতে হবে সেটি এবং একটি কন্ট্রোল স্ট্রিং। কন্ট্রোল স্ট্রিংয়ের বিষয়বস্তুই ঠিক করে দেয় পরের আর্গুমেন্টগুলো কীভাবে ব্যবহার হবে।

প্রথম প্যারামিটারটির দুটি বিশেষ মান আছে: `t` এবং `nil`। `t` বোঝায় `*standard-output*`-এর সাথে বাঁধা স্ট্রিমটি ব্যবহার করা উচিত, আর `nil` বোঝায় একটি স্ট্রিং তৈরি করে সেটি রিটার্ন করা উচিত। স্ট্রিম প্যারামিটারটি `nil` না হলে `format`-এর মান `nil` হয়।

কন্ট্রোল স্ট্রিংয়ে ফরম্যাট ডিরেক্টিভ থাকতে পারে, যেগুলো বোঝানো হয় একটি `~` এবং তার পরের একটি ক্যারেক্টার দিয়ে (ক্যারেক্টারটি বড় হাতের না ছোট হাতের, তা গুরুত্বপূর্ণ নয়)। ফরম্যাট ডিরেক্টিভই ঠিক করে দেয় কোনো আর্গুমেন্ট খরচ হবে কি না এবং স্ট্রিমে সেগুলো কীভাবে ফরম্যাট হবে।

গুরুত্বপূর্ণ মৌলিক ফরম্যাট ডিরেক্টিভগুলো হলো:

* `~A` - _"নান্দনিকভাবে"_ "মানুষের পড়ার উপযোগী" ভাবে ফরম্যাট করে।
* `~S` - _"স্ট্যান্ডার্ড"_ উপায়ে ফরম্যাট করে, যাতে তা "মেশিনের পড়ার উপযোগী" হয়।
* `~%` - একটি নতুন লাইন লেখে।
* `~&` - লাইনের শুরুতে না থাকলে একটি নতুন লাইন লেখে।
* `~~` - একটি টিল্ডা লেখে।

উদাহরণ:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
