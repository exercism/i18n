# পরিচিতি

প্রায় প্রতিটি Factor প্রোগ্রামই হলো ওয়ার্ডের একটি ক্রম যা ডেটা স্ট্যাকে মান গ্রহণ ও উৎপাদন করে। যখন ইনপুট ও আউটপুট সুন্দরভাবে মিলে যায়, তখন কোডটি বাম থেকে ডানে অনায়াসে পড়া যায়। যখন তারা মেলে না, তখন আপনাকে *শাফল ওয়ার্ডস*-এর দ্বারস্থ হতে হয়, এবং কোডটি দ্রুত অপরিষ্কার হয়ে যায়।

এই অনুশীলনী আপনাকে Factor-এর স্ট্যান্ডার্ড সমাধানের সাথে পরিচয় করিয়ে দেবে: কম্বিনেটরস।

## শাফল ওয়ার্ডস

সবচেয়ে কমন শাফল ওয়ার্ডস [`kernel`][kernel]-এ থাকে:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

আপনি ইতিমধ্যেই `dup` এবং `swap` ব্যবহার করেছেন। `over` উপরের থেকে *দ্বিতীয়* এলিমেন্টের একটি কপি তৈরি করে, যা সুবিধাজনক যখন একই ইনপুট দুটি গণনায় ব্যবহার করতে হয়:

```factor
! Sum a number with twice itself: x + 2*x
: triple ( x -- 3x ) dup 2 * + ;
```

একবার ব্যবহারের জন্য এটি ঠিক আছে। কিন্তু একসাথে জোড়া লাগালে, `dup`, `swap`, `over`, `rot`-এর ক্রমগুলি দ্রুত অপাঠ্য হয়ে যায়।

## `keep`: ইনপুট সংরক্ষণ

`keep` ([`kernel`][kernel]-এ) স্ট্যাকের উপরের অংশে একটি কোটেশন কল করে কিন্তু ফলাফলের উপরে মূল মানটি রেখে দেয়:

```
keep ( x quot: ( x -- y ) -- y x )
```

```factor
5 [ 2 * ] keep .s
! => 10
! => 5
```

এটি `dup`-এর পরে কিছু একটা এবং তারপর শাফল করার প্যাটার্নটি প্রতিস্থাপন করে: যেখানে আপনি `dup something swap` লিখতেন, সেখানে আপনি শুধু `[ something ] keep` বলতে পারেন।

## `bi`: এক ইনপুটের দুটি ফাংশন

`bi` ([`kernel`][kernel]-এ) একই মানের উপর *দুটি* কোটেশন প্রয়োগ করে, উভয় ফলাফল স্ট্যাকে রেখে দেয়:

```
bi ( x q1 q2 -- r1 r2 )
```

```factor
4 [ sq ] [ neg ] bi .s
! => 16
! => -4
```

`bi` ছাড়া আপনি লিখতেন `dup sq swap neg`, দুটি অপারেশনের জন্য যথেষ্ট পাঠযোগ্য, কিন্তু তিনটির জন্য জটিল।

## `tri` এবং `cleave`: এক ইনপুটের অনেক ফাংশন

`tri` `bi`-কে তিনটি কোটেশনে বর্ধিত করে:

```
tri ( x q1 q2 q3 -- r1 r2 r3 )
```

`cleave` ([`combinators`][combinators]-এ) একই ধারণা, তবে যেকোনো সংখ্যক কোটেশনের একটি *অ্যারে*-এর জন্য:

```factor
4 { [ ] [ sq ] [ neg ] } cleave .s
! => 4
! => 16
! => -4
```

খালি কোটেশন `[ ]` আইডেন্টিটি হিসেবে কাজ করে, যা উপযোগী যখন কাট কার্ডের একটি স্লটে ইনপুটটিই থাকা উচিত।

## `dip` এবং `2dip`: নিচে অপারেট করুন

`dip` ([`kernel`][kernel]-এ) স্ট্যাকের উপরের নিচে থাকা মানগুলির উপর একটি কোটেশন কল করে, উপরের অংশটি অপরিবর্তিত রেখে। `2dip` একই কাজ করে কিন্তু উপরের *দুটি* মান রক্ষা করে:

```
dip  ( x   quot -- x   )
2dip ( x y quot -- x y )
```

```factor
9 10 11 [ + ] dip .s
! => 19      (9 + 10)
! => 11      (the protected top, restored)

9 10 11 12 [ + ] 2dip .s
! => 19      (9 + 10)
! => 11      (the protected y, originally 11)
! => 12      (the protected x, originally 12)
```

এখানে `dip` `11`-কে লুকিয়েছিল, `9 10 +` চালিয়েছিল, এবং `11`-কে আবার উপরে রেখেছিল। `2dip` `11 12`-কে লুকিয়েছিল, নিচে `9 10 +` চালিয়েছিল, তারপর `11 12` পুনরুদ্ধার করেছিল।

`dip` সঠিক টুল যখন স্বাভাবিক আর্গুমেন্ট অর্ডার "পাস-থ্রু" মানটি স্ট্যাকের উপরে রেখে দেয়। `swap … swap` স্যান্ডউইচের বদলে এটি ব্যবহার করুন।

## `bi@`: দুটি মানের উপর একই অপারেশন

`bi@` ([`kernel`][kernel]-এ) দুটি স্ট্যাক মানের উপর একটি কোটেশন প্রয়োগ করে:

```
bi@ ( x y quot -- r1 r2 )
```

```factor
3 4 [ sq ] bi@ .s
! => 9
! => 16
```

## `bi*`: দুটি মানের উপর ভিন্ন অপারেশন

`bi*` ([`kernel`][kernel]-এ) দুটি স্ট্যাক মানের উপর *ভিন্ন* কোটেশন প্রয়োগ করে, প্রথম কোটেশনটি নিচের মানের উপর, দ্বিতীয়টি উপরের মানের উপর:

```
bi* ( x y q1 q2 -- r1 r2 )
```

```factor
3 4 [ sq ] [ neg ] bi* .s
! => 9
! => -4
```

`bi@` ব্যবহার করুন যখন উভয় মানের উপর একই রকম আচরণ করা হয়, এবং `bi*` যখন প্রত্যেকের নিজস্ব আচরণ প্রয়োজন।

## `tri*`: তিনটি মানের উপর ভিন্ন অপারেশন

`tri*` ([`combinators`][combinators]-এ) `bi*`-কে তিনটি মান এবং তিনটি কোটেশনে বর্ধিত করে, প্রতিটি কোটেশনকে একটি করে মানের উপর ক্রমানুসারে প্রয়োগ করে:

```
tri* ( x y z q1 q2 q3 -- r1 r2 r3 )
```

```factor
1 2 3 [ sq ] [ neg ] [ 10 * ] tri* .s
! => 1
! => -2
! => 30
```
