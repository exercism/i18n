# নির্দেশনা

আপনি একজন উৎসাহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কতগুলো পাখি এসেছে তার হিসাব রাখেন।

আপনার ছয়টি কাজ আছে, সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. গত সপ্তাহের সংখ্যাগুলো কী ছিল তা দেখুন

তুলনার প্রয়োজনে আপনি সবসময় গত সপ্তাহের সংখ্যাগুলোর একটি কপি কাছে রাখেন, যেগুলো ছিল: 0, 2, 5, 3, 7, 8 আর 4। `BirdWatcher.getLastWeek()` মেথডটি বাস্তবায়ন করুন, যা গত সপ্তাহের সংখ্যাগুলো রিটার্ন করে:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. আজ কত পাখি এসেছে তা দেখুন

`BirdWatcher.getToday()` মেথডটি বাস্তবায়ন করুন, যা রিটার্ন করে আজ আপনার বাগানে কত পাখি এসেছে। পাখির সংখ্যাগুলো দিন অনুযায়ী সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরনো দিনের সংখ্যা আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. আজকের সংখ্যা বাড়ান

`BirdWatcher.incrementTodaysCount()` মেথডটি বাস্তবায়ন করুন, যা আজকের সংখ্যা বাড়ায়:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. কোনো দিন পাখি না আসার ঘটনা ছিল কি না দেখুন

`BirdWatcher.hasDayWithoutBirds()` মেথডটি বাস্তবায়ন করুন, যা `true` রিটার্ন করে যদি এমন কোনো দিন থাকে যেদিন বাগানে শূন্য পাখি এসেছে; অন্যথায় `false` রিটার্ন করে:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. প্রথম কয়েক দিনে আসা পাখির সংখ্যা হিসাব করুন

`BirdWatcher.getCountForFirstDays()` মেথডটি বাস্তবায়ন করুন, যা সপ্তাহের শুরু থেকে আপনার বাগানে আসা পাখির সংখ্যা রিটার্ন করে, তবে হিসাবটি সপ্তাহের শুরুর নির্দিষ্ট সংখ্যক দিনের মধ্যে সীমাবদ্ধ রাখুন।

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্যদিনের চেয়ে ব্যস্ত থাকে। ব্যস্ত দিন হলো সেদিন, যেদিন পাঁচটি বা তার বেশি পাখি আপনার বাগানে এসেছে।
`BirdWatcher.getBusyDays()` মেথডটি বাস্তবায়ন করুন, যা ব্যস্ত দিনের সংখ্যা রিটার্ন করে:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
