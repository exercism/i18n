# নির্দেশাবলি

আপনার DNA গবেষণাগারে আপনি স্টোরেজ জায়গা বাঁচাতে গবেষণার ডেটা সংকুচিত করার নানা উপায় নিয়ে কাজ করছেন। আপনার একজন সহকর্মী প্রস্তাব দিলেন DNA ডেটাকে বাইনারি রূপে রূপান্তর করা হোক:

| নিউক্লিক অ্যাসিড | কোড   |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

আপনি এটি নিয়ে ভাবলেন: এতে ডেটা সংরক্ষণের খরচ সম্ভবত কমবে, কিন্তু বিনিময়ে মানুষের পড়ার সহজতা কমে যাবে। আপনি ঠিক করলেন, আপনার সাশ্রয়ের পরিমাণ মাপতে এমন একটি মডিউল লিখবেন যা আপনার ডেটা এনকোড ও ডিকোড করবে।

## 1. নিউক্লিক অ্যাসিডকে বাইনারি মানে এনকোড করুন

`encode_nucleotide` ইমপ্লিমেন্ট করুন যাতে এটি একটি নিউক্লিওটাইড নেয় এবং এনকোড করা কোডের int মান রিটার্ন করে।

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. বাইনারি মান থেকে নিউক্লিক অ্যাসিড ডিকোড করুন

`decode_nucleotide` ইমপ্লিমেন্ট করুন যাতে এটি এনকোড করা কোডের ইন্টিজার মান নেয় এবং নিউক্লিওটাইড রিটার্ন করে।

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. DNA-র একটি অ্যারে এনকোড করুন

`encode` ইমপ্লিমেন্ট করুন যাতে এটি নিউক্লিওটাইডের একটি অ্যারে নেয় এবং এনকোড করা ডেটার একটি বিট অ্যারে রিটার্ন করে।

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. DNA-র বিট অ্যারে ডিকোড করুন

`decode` ইমপ্লিমেন্ট করুন যাতে এটি নিউক্লিক অ্যাসিড বোঝায় এমন একটি বিট অ্যারে নেয় এবং ডিকোড করা ডেটা নিউক্লিওটাইডের অ্যারে হিসেবে রিটার্ন করে।

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
