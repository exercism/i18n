# সম্পর্কে

কম্বিনেটর স্ট্যাক-শাফলিং প্যাটার্নগুলোকে নামযুক্ত, কম্পোজেবল ওয়ার্ডে পরিণত করে। যথেষ্ট পরিমাণ Factor লিখে ফেললে আপনি আর ভাববেন না "আমাকে `dup` করতে হবে, তারপর F রান করতে হবে, তারপর আসলটি ধরে রাখতে হবে", বরং সোজা `[ F ] keep` লিখবেন।

| প্যাটার্ন                            | শাফল                      | কম্বিনেটর      |
|------------------------------------|-------------------------------|-----------------|
| F প্রয়োগ করুন, ইনপুট অক্ষত রাখুন            | `dup F swap`                  | `[ F ] keep`    |
| একটি ইনপুটের উপর দুটি ফাংশন         | `dup F swap G`                | `[ F ] [ G ] bi`|
| একটি ইনপুটের উপর তিনটি ফাংশন       | জটিল                         | `[ F ] [ G ] [ H ] tri` |
| একটি ইনপুটের উপর অনেক ফাংশন        | খুব জটিল                    | `{ Fs … } cleave`|
| টপের *নিচে* থাকা মানের উপর কাজ করা  | `swap F swap`                 | `[ F ] dip`     |
| দুটি মানের উপর একই অপারেশন              | `swap F swap F`               | `[ F ] bi@`     |
| দুটি মানের উপর ভিন্ন ভিন্ন অপারেশন        | `swap F swap G`               | `[ F ] [ G ] bi*`|

`2` দিয়ে শুরু হওয়া পরিবারটি (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) ঠিক একই কাজ করে যখন প্রতিটি অপারেশনের *দুটি* ইনপুট দরকার; আর `3dup` ও `4dup` ডুপ্লিকেট করার এই রীতিকে স্ট্যাকের উপরের তিন বা চারটি মান পর্যন্ত বাড়িয়ে দেয়।

cleave/dip/bi পরিবারের বাইরে [`kernel`][kernel] এমন কন্ট্রোল-ফ্লো ভ্যারিয়েন্টও দেয় যেগুলো `f` পরিষ্কারভাবে প্রোপাগেট করে:

| ওয়ার্ড        | প্রভাব                                              |
|-------------|-----------------------------------------------------|
| `if*`       | ট্রু শাখা মানটি দেখতে পায়; ফলস শাখা পায় না    |
| `?last`     | সিকোয়েন্সের শেষ এলিমেন্ট, খালি হলে `f`         |
| `pop*`      | `pop`-এর ফেলে দেওয়া ভ্যারিয়েন্ট (একটি ভেক্টর মিউটেট করে)      |
| `dupd`      | উপর থেকে *দ্বিতীয়টি* ডুপ্লিকেট করে                     |
| `pick`      | উপর থেকে *তৃতীয়টি* উপরে কপি করে                    |
| `swapd`     | উপর থেকে দ্বিতীয় ও তৃতীয়টি অদলবদল করে              |
| `rotd`      | চার-গভীর স্ট্যাকের নিচের তিনটি ঘোরায়        |
| `tuck`      | উপরের মানটি উপর থেকে দ্বিতীয়টির নিচে কপি করে              |
| `with`      | HOS-এর জন্য একটি কোয়োটেশনে নির্দিষ্ট মান গেঁথে দেয়         |
| `while`     | কোনো প্রিডিকেট সত্য থাকলে লুপ চালায়                        |
| `until`     | কোনো প্রিডিকেট সত্য হওয়া পর্যন্ত লুপ চালায়                        |

সঠিক কম্বিনেটর বেছে নেওয়াও নিজে এক দক্ষতা। সাধারণ নিয়মটি হলো: কোনো ডেফিনিশনের বডিতে পরপর একাধিক শাফল ওয়ার্ড থাকলে, সাধারণত এমন একটি কম্বিনেটর থাকে যা উদ্দেশ্যটিকে আরও ভালোভাবে ধরে রাখে।
