# নির্দেশাবলি

লুসিয়ানের বান্ধবী বাড়ির পথে, অথচ তিনি তাঁদের বিবাহবার্ষিকীর ডিনার এখনো রান্না করেননি!

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা লুসিয়ানকে তাঁর প্রিয় রান্নার বই থেকে একটি চমৎকার লাসানিয়া রান্না করতে সাহায্য করবে।

লাসানিয়া রান্নায় ব্যয় হওয়া সময় নিয়ে আপনার চারটি কাজ আছে।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

`expected_minutes_in_oven` কনস্ট্যান্টটি ডিফাইন করুন, যা বোঝায় লাসানিয়াকে কত মিনিট ওভেনে থাকতে হবে। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে `40`।

## 2. ওভেনে বাকি সময় মিনিটে হিসাব করুন

`remaining_minutes_in_oven` মেথডটি ইমপ্লিমেন্ট করুন, যা লাসানিয়া ওভেনে এখন পর্যন্ত কত মিনিট ছিল সেটি _প্যারামিটার_ হিসেবে নেয় এবং আগের কাজের **ওভেনে প্রত্যাশিত সময় মিনিটে** অনুযায়ী _রিটার্ন_ করে, লাসানিয়াকে আর কত মিনিট ওভেনে থাকতে হবে।

```abap
remaining_minutes_in_oven( 30 ).
// => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparation_time_in_minutes` মেথডটি ইমপ্লিমেন্ট করুন, যা লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যাটি _প্যারামিটার_ হিসেবে নেয় এবং _রিটার্ন_ করে লাসানিয়া প্রস্তুত করতে আপনার কত মিনিট লেগেছে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```abap
preparation_time_in_minutes( 2 ).
// => 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`total_time_in_minutes` মেথডটি ইমপ্লিমেন্ট করুন, যা _দুটি প্যারামিটার_ নেয়: `numbernumber_of_layers` প্যারামিটারটি হলো লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন তার সংখ্যা, আর `actual_minutes_in_oven` প্যারামিটারটি হলো লাসানিয়া কত মিনিট ধরে ওভেনে আছে তার সংখ্যা। মেথডটি _রিটার্ন_ করবে লাসানিয়া রান্না করতে আপনার মোট কত মিনিট লেগেছে, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```abap
total_time_in_minutes( 
  numbernumber_of_layers = 3
  actual_minutes_in_oven = 20 ).
// => 26
```
