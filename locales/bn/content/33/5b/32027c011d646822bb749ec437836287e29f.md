# Import

[বিশেষ ফর্ম `import`][import] ব্যবহার করে আপনি বাইরের কোনো মডিউলের ফাংশন ও ম্যাক্রো ব্যবহার করতে পারেন, মডিউলটির নাম ব্যবহার না করেই।

পুরো একটি বাইরের মডিউল ইমপোর্ট করলে বর্তমান লোকাল ফাংশনগুলোর সাথে দ্বন্দ্ব তৈরি হতে পারে। এটি এড়াতে দুটি উপায় আছে: `:except` এবং `:only`. দুটিই একটি কিওয়ার্ড লিস্ট আশা করে, যেখানে কী (key) হলো ফাংশনের নাম আর মান হলো ফাংশনের অ্যারিটি।

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

সাধারণত ইমপোর্ট মডিউল ডেফিনিশনের শুরুতে যোগ করা হয়, তবে যেকোনো জায়গাতেই যোগ করা যায়। এদের স্কোপ লেক্সিকাল, অর্থাৎ একটি ফাংশন ডেফিনিশনের ভেতরে যোগ করা ইমপোর্ট আরেকটি ফাংশনে পাওয়া যাবে না।

অব্যবহৃত ইমপোর্ট কম্পাইলার ওয়ার্নিং তৈরি করে।
