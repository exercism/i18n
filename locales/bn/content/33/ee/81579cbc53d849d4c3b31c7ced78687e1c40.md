# নির্দেশাবলি

এই অনুশীলনীতে আপনি Exercism-এ যে প্রোগ্রামিং ভাষাগুলো শিখতে চান, সেগুলোর একটি অ্যারের ট্র্যাক রাখার কোড লিখবেন।

আপনার সামনে নয়টি কাজ আছে, যার সবগুলোতেই অ্যারে নিয়ে কাজ করতে হবে।

## 1. একটি নতুন অ্যারে তৈরি করুন

আপনি যে প্রোগ্রামিং ভাষাগুলো শিখতে চান তার ট্র্যাক রাখতে হলে আপনাকে একটি নতুন অ্যারে তৈরি করতে হবে।

নতুন ও খালি একটি অ্যারে রিটার্ন করে এমন static `Languages.NewList()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.NewList()
// => empty list
```

## 2. একটি বিদ্যমান অ্যারে ডিফাইন করুন

এই মুহূর্তে আপনার হাতে একটি কাগজ আছে, যাতে আপনি শিখতে চাওয়া প্রোগ্রামিং ভাষাগুলোর নাম লেখা: C#, Clojure এবং Elm।

অ্যারেটি রিটার্ন করার জন্য static `Languages.GetExistingLanguages()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. অ্যারেতে একটি নতুন প্রোগ্রামিং ভাষা যোগ করুন

Exercism ঘুরে ঘুরে আপনি যখন আরও মজার প্রোগ্রামিং ভাষা খুঁজে পান, তখন সেগুলো আপনার অ্যারেতে যোগ করতে চান।

আপনার অ্যারের শেষে একটি নতুন প্রোগ্রামিং ভাষা যোগ করার জন্য static `Languages.AddLanguage()` ফাংশনটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. অ্যারেতে থাকা প্রোগ্রামিং ভাষা গণনা করুন

প্রোগ্রামিং ভাষাগুলো এক এক করে গণনা করা অসুবিধাজনক।

আপনার অ্যারেতে থাকা প্রোগ্রামিং ভাষার সংখ্যা গণনা করার জন্য static `Languages.CountLanguages()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. অ্যারেতে একটি প্রোগ্রামিং ভাষা আছে কি না দেখুন

একটি প্রোগ্রামিং ভাষা আছে কি না তা দেখার জন্য static `Languages.HasLanguage()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. অ্যারেটি উল্টে দিন

একপর্যায়ে আপনি বুঝতে পারবেন যে আপনার অ্যারেটি আসলে উল্টো ক্রমে সাজানো!

আপনার অ্যারেটি উল্টে দেওয়ার জন্য static `Languages.ReverseList()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. অ্যারেটি উত্তেজনাপূর্ণ কি না দেখুন

আপনি সব প্রোগ্রামিং ভাষাই ভালোবাসেন, তবে C#-এর জন্য আপনার হৃদয়ে বিশেষ একটি জায়গা আছে। তাই নিচের যেকোনো একটি শর্ত ট্রু হলে আপনি প্রোগ্রামিং ভাষার একটি অ্যারে নিয়ে সত্যিই উত্তেজিত হন:

- অ্যারের প্রথমটি C#।
- অ্যারের দ্বিতীয় আইটেমটি C# এবং অ্যারেতে দুটি বা তিনটি প্রোগ্রামিং ভাষা আছে।

প্রোগ্রামিং ভাষার একটি অ্যারে উত্তেজনাপূর্ণ কি না তা দেখার জন্য static `Languages.IsExciting()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8. প্রোগ্রামিং ভাষা সরান

অ্যারে থেকে একটি নির্দিষ্ট প্রোগ্রামিং ভাষা সরানোর জন্য static `Languages.RemoveLanguage()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. অ্যারেতে থাকা সব প্রোগ্রামিং ভাষা ইউনিক কি না দেখুন

অ্যারেতে কোনো প্রোগ্রামিং ভাষা একাধিকবার এসেছে কি না তা দেখার জন্য static `Languages.IsUnique()` মেথডটি ইমপ্লিমেন্ট করুন।

এই মেথডটি কল করার সময় প্রোগ্রামিং ভাষার অ্যারে (অর্থাৎ প্যারামিটার) খালি থাকবে না, এটি নিশ্চিত, আর অ্যারেটি পরিবর্তন হলেও কিছু আসে যায় না।

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
