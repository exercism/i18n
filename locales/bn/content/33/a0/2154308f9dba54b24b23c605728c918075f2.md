# পরিচিতি

## অ্যারে

Gleam-এ একটি অ্যারে হলো শূন্য বা তার বেশি মানের একটি অপরিবর্তনীয় সংগ্রহ। একটি অ্যারের সব মানের টাইপ একই হতে হবে। যেহেতু অ্যারে অপরিবর্তনীয়, তাই একবার একটি অ্যারে তৈরি হয়ে গেলে তার মান আর কখনোই বদলানো যায় না। যে ফাংশন বা অপারেটরগুলো একটি অ্যারে বদলে দিচ্ছে বলে মনে হয় (যেমন একটি এলিমেন্ট যোগ করা), তারা আসলে একটি নতুন অ্যারে রিটার্ন করে।

অ্যারে এভাবে ডিফাইন করা যায়:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

অ্যারেতে একটি এলিমেন্ট যোগ করার সবচেয়ে কমন উপায় হলো স্প্রেড সিনট্যাক্স:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam স্ট্যান্ডার্ড লাইব্রেরির [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) মডিউলটিতে অ্যারে নিয়ে কাজ করার জন্য অনেক কাজের ফাংশন আছে। এই মডিউলটি Gleam কোডে খুব কমনভাবে ব্যবহার করা হয়, তাই এর সাথে পরিচিত থাকা ভালো।

case এক্সপ্রেশনে অ্যারে প্যাটার্ন ব্যবহার করে অ্যারের সাথে ম্যাচ করা যায় এবং তার ভেতরের মানগুলো ভ্যারিয়েবলে অ্যাসাইন করা যায়:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

নির্দিষ্ট দৈর্ঘ্যের অ্যারের সাথে ম্যাচ করার পাশাপাশি, স্প্রেড সিনট্যাক্স দিয়ে কমপক্ষে একটি নির্দিষ্ট দৈর্ঘ্যের অ্যারের সাথে ম্যাচ করা যায়:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

স্প্রেড সিনট্যাক্স দিয়ে অ্যারের বাকি অংশটি একটি ভ্যারিয়েবলে অ্যাসাইন করাও যায়:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

যে টাইপের সাথে ম্যাচ করা হচ্ছে, তার প্রতিটি সম্ভাব্য মানের জন্যই case এক্সপ্রেশনে একটি প্যাটার্ন থাকা উচিত, তাই বাকি মানগুলো সামলাতে বেশিরভাগ সময় শেষে একটি ডিসকার্ড প্যাটার্ন (`_`) ব্যবহার করা হয়।
