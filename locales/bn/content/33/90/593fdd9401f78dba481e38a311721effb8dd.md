# নির্দেশাবলির সংযোজন

## ইমপ্লিমেন্টেশন

এই অনুশীলনীতে আপনি এমন একটি প্রসিডিউর ইমপ্লিমেন্ট করবেন, যার কাজ হলো এটি যে স্ট্রিংটি রিটার্ন করে সেটি অ্যালোকেট করা। স্ট্রিংটি ডি-অ্যালোকেট করার দায়িত্ব ওই প্রসিডিউরের কলারের।

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
