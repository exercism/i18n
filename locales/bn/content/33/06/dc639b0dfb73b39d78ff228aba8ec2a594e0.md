# পরিচিতি

F#-এ একটি [`list`][lists] হলো শূন্য বা তার বেশি মানের একটি অপরিবর্তনীয় সংগ্রহ। একটি অ্যারের সব মানের টাইপ একই হতে হবে। যেহেতু অ্যারে অপরিবর্তনীয়, তাই একবার অ্যারে তৈরি হয়ে গেলে তার মান আর কখনো বদলানো যায় না। F# অ্যারের একটি _হেড_ (প্রথম এলিমেন্ট) এবং একটি _টেইল_ (প্রথম এলিমেন্টের পরের সবকিছু) থাকে। একটি অ্যারের টেইল নিজেই একটি অ্যারে।

অ্যারে এভাবে ডিফাইন করা যায়:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

অ্যারেতে একটি এলিমেন্ট যোগ করার সবচেয়ে কমন উপায় হলো `::` (কনস) অপারেটর:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

`@` অপারেটর বা `List.append` দিয়ে অ্যারে যুক্ত করা যায়:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

অ্যারে নিয়ন্ত্রণ করা হয় [`List` মডিউল][list-module]-এ ডিফাইন করা ফাংশন ও অপারেটরের মাধ্যমে। এই ফাংশনগুলোর কয়েকটি একটি `list` ইনস্ট্যান্সের [প্রপার্টি][list-properties] হিসেবেও পাওয়া যায়:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

এখানে সঠিক বা ভুল বলে কিছু নেই। সাধারণভাবে, `List` মডিউলের ফাংশনগুলো টাইপ ইনফারেন্সের সাথে ভালোভাবে কাজ করে, অন্যদিকে প্রপার্টিগুলো আরও সংক্ষিপ্ত কোড লেখার সুযোগ দেয়।

যে ফাংশন বা অপারেটরগুলো অ্যারে পরিবর্তন করে বলে মনে হয় (যেমন একটি এলিমেন্ট যোগ করা), তারা আসলে একটি নতুন অ্যারে রিটার্ন করে। তবে সাধারণত পারফরম্যান্স কোনো সমস্যা হয় না, কারণ অ্যারের ইমপ্লিমেন্টেশন অপ্রয়োজনীয় অ্যালোকেশন/কপি আটকে দেয়।

যেহেতু অ্যারে সিঙ্গলি লিংকড লিস্ট হিসেবে ইমপ্লিমেন্ট করা হয়, তাই (`::` অপারেটর দিয়ে) সামনে একটি এলিমেন্ট যোগ করা খুব দ্রুত, আর ইনডেক্স দিয়ে কোনো এলিমেন্ট অ্যাক্সেস করা তুলনামূলকভাবে ধীর হতে পারে।

প্যাটার্ন ম্যাচিংয়ের মাধ্যমে [_list_][list-pattern] এবং [_cons_][cons-pattern] প্যাটার্ন ব্যবহার করেও অ্যারে প্রসেস করা যায়:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

প্যাটার্ন ম্যাচিংয়ের সময় আপনি একটি মান _বাদ_ও দিতে পারেন; কোনো নির্দিষ্ট কেসে যখন একটি মান নিয়ে আপনার _কোনো ভাবনা থাকে না_ (অর্থাৎ আপনি মানটি _ব্যবহার_ করতে যাচ্ছেন না), তখন সেটা বোঝাতে একটি আন্ডারস্কোর (`'_'`) ব্যবহার করতে পারেন:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

প্যাটার্ন ম্যাচিংয়ের সময় একক `'_'` সবসময় _শেষে_ আসা উচিত; যে মান অন্য কোনো কেসের সাথে _মেলে না_, সেটি এই কেসটি সামলে নেবে।
