# টেস্ট

একটি অনুশীলনী ডাউনলোড করতে, যেমন `hello-world`, একটি টার্মিনাল খুলে রান করুন:

```bash
exercism download --track roc --exercise hello-world
```

এরপর অনুশীলনীর ডিরেক্টরিতে গিয়ে অনুশীলনীটি সমাধান করার জন্য কোডটি এডিট করুন। যেমন:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

প্রতিটি অনুশীলনীর সাথে একটি টেস্ট স্যুট থাকে। আপনি `roc test` কমান্ডটি ব্যবহার করে টেস্টগুলো রান করতে পারেন, যেমন:

```
roc test hello-world-test.roc
```

আপনি যদি অনুশীলনীটি সমাধান করে ফেলেন, তাহলে কোনো ফেল করা টেস্ট দেখতে পাবেন না, যেমন:

```
All (5) tests passed in 123.4 ms.
```

তবে আপনার কোডে কোনো এরর থাকলে সেগুলো দেখতে এমন হবে:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

এটি আপনার কোড ঠিক করতে সাহায্য করবে। আপনার কোড কাজ করা শুরু করলে আপনি `exercism submit` কমান্ডটি ব্যবহার করে সেটি সাবমিট করতে পারেন (বিস্তারিত জানতে অনুশীলনীর ডিরেক্টরির `HELP.md` দেখুন)।
