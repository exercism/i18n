# নির্দেশনা

স্থানীয় ক্লাবে এটি সিজনের শেষ প্রতিযোগিতা। আপনি ফিনিশ লাইনে দাঁড়িয়ে লিডারবোর্ড চালাচ্ছেন: প্রতিযোগীরা ক্রম অনুসারে ফিনিশ লাইন পার হচ্ছে, লেনগুলোর লেবেল দরকার, আর পরের হিট শুরুর আগেই অফিসিয়াল লেজারে টীকা যোগ করতে হবে।

প্রতিযোগীদের নাম একটি অ্যারে হিসেবে আসে, ফিনিশের ক্রম অনুসারে: ০তম নামটি বিজয়ী, ১ম নামটি রানার-আপ, আর এভাবেই বাকিগুলো।

## 1. বিব অ্যাসাইন করুন

`assign-bibs` ডিফাইন করুন যেন এটি প্রতিযোগীদের নামের একটি অ্যারে নেয় এবং `{ position name }` জোড়ার একটি অ্যারে রিটার্ন করে, যেখানে position প্রথমে থাকে।

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. লেন লেবেল

`lane-labels` ডিফাইন করুন যেন এটি প্রতিযোগীদের নামের একটি অ্যারে নেয় এবং `"Lane 0: Bolt"` ধরনের স্ট্রিং রিটার্ন করে।

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. প্রতিযোগীদের ট্যাগ করুন

`tag-racers` ডিফাইন করুন যেন এটি প্রতিযোগীদের নামের একটি অ্যারে *এবং* একটি ট্যাগ স্ট্রিং নেয়, আর `"<tag>/<index>: <name>"` ধরনের লেবেল রিটার্ন করে। একই ট্যাগ প্রতিটি লেবেলেই বসানো থাকে।

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. ফিনিশ রেকর্ড করুন

`record-finishes` ডিফাইন করুন যেন এটি প্রতিযোগীদের নামের একটি অ্যারে এবং একটি লেজার (একটি ভেক্টর) নেয়। প্রতিটি প্রতিযোগীর জন্য লেজারটির ভেতরেই `"<index>: <name>"` ধরনের একটি স্ট্রিং যোগ করে। কিছুই রিটার্ন করে না।

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. ল্যাপ বেল

`lap-bells` ডিফাইন করুন যেন এটি `laps` নামের একটি সংখ্যা নেয় এবং `laps` বার পুনরাবৃত্ত `"ding "` দিয়ে তৈরি একটি স্ট্রিং রিটার্ন করে।

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
