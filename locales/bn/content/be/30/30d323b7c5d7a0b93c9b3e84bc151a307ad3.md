# সম্পর্কে

`PHP 8.0.0` থেকে **ইউনিয়ন টাইপ ডিক্লারেশন** পাওয়া যায়, যা একটি মাত্র টাইপের বদলে একাধিক ভিন্ন টাইপের মান গ্রহণ করে। পাইপ (`|`) দিয়ে টাইপগুলো আলাদা করে ইউনিয়ন টাইপের সংজ্ঞা তৈরি করা হয়।

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## সূক্ষ্ম বিষয়

- `null` টাইপকে `?Type` অথবা `Type1|Type2|null` ব্যবহার করে _nullable_ হিসেবে ডিক্লেয়ার করা যায়।
- ডিক্লেয়ার করা ডুপ্লিকেট বা রিডান্ড্যান্ট টাইপের ফলে কম্পাইল-টাইম এরর হয়।
- `void` ইউনিয়ন টাইপ ডিক্লারেশনের অংশ হিসেবে ব্যবহার করা যায় না।
