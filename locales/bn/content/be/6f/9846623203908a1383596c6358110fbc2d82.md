# স্ট্রিং ইন্টারপোলেশন ব্যবহার করুন

ডাইনামিকভাবে একটি স্ট্রিং তৈরি করতে স্ট্রিং কনক্যাটেনেশন বা `StringBuilder` ব্যবহার না করে [স্ট্রিং ইন্টারপোলেশন](https://docs.scala-lang.org/overviews/core/string-interpolation.html) ব্যবহার করুন।

এর মূল সুবিধা হলো, স্ট্রিং কনক্যাটেনেশনের বা `StringBuilder` ব্যবহারের চেয়ে স্ট্রিং ইন্টারপোলেশনের কোড সাধারণত পড়তে সহজ হয়।
