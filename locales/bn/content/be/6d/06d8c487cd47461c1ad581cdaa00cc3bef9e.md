# https://www.php.net/manual/en/language.basic-syntax.phptags.php"স্কোপ রেজল্যুশন অপারেটর

স্কোপ রেজল্যুশন অপারেটর (`::`) আমাদেরকে একটি ক্লাস রেফারেন্স করে তার নাম কনস্ট্যান্ট, স্ট্যাটিক প্রপার্টি বা স্ট্যাটিক মেথড অ্যাক্সেস করার সুযোগ দেয়।

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## স্কোপ রেজল্যুশন অপারেটরের সাথে `self` এবং `static` ব্যবহার

একটি অবজেক্টের নিজের স্কোপ রেফারেন্স করা প্রয়োজন হতে পারে। এটি সহজ করতে, `self` কিওয়ার্ড একটি ক্লাসকে তার নিজের স্কোপ রেফারেন্স করার সুযোগ দেয়। `self` কিওয়ার্ড ব্যবহার করলে ক্লাসটি তার নিজের নাম থেকে আলাদা হয়ে যায়, যা সময়ের সাথে কোড মেইনটেইন করা সহজ করে তোলে।

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

তবে, `self` যে ক্লাসে উপস্থিত হয়, তার সাথে লেক্সিক্যালি বাউন্ড।

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

`MyOtherClass::getMyValue` কল করলে এখনও `1` আসে, `99` নয়। এটি সমাধান করতে, স্কোপ রেজল্যুশন অপারেটরের সাথে `static` কিওয়ার্ড ব্যবহার করে বর্তমান ডিসেন্ডেন্ট ক্লাসে রেফারেন্সটি "লেট বাইন্ড" করুন।

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## স্কোপ রেজল্যুশন অপারেটরের সাথে `parent` ব্যবহার

কখনও কখনও প্যারেন্ট স্কোপ থেকে পাওয়া একটি কনস্ট্যান্ট, প্রপার্টি বা মেথড নির্দিষ্টভাবে রেফারেন্স করার প্রয়োজন হতে পারে:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিংয়ে সবচেয়ে সাধারণভাবে, যখন একটি অবজেক্ট ইনস্ট্যানশিয়েট করা হয়, তখন প্যারেন্ট কনস্ট্রাক্টর কল করতে `parent` ব্যবহার করা হয়:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## সতর্কতা

### কনস্ট্যান্ট, প্রপার্টি এবং মেথড ভিজিবিলিটি

স্কোপ রেজল্যুশন অপারেটর এখনও `public`, `private`, এবং `protected` ভিজিবিলিটি মডিফায়ার দ্বারা নির্ধারিত নিয়ম অনুসরণ করে।
