# ইনস্টলেশন

শুধু Scarb ডাউনলোড করেই Cairo ইনস্টল করা যায়। Scarb, Cairo কম্পাইলার ও Cairo ভাষার সার্ভার একসাথে একটি সহজে ইনস্টল করার মতো প্যাকেজে বেঁধে দেয়, যাতে আপনি সঙ্গে সঙ্গে Cairo কোড লেখা শুরু করতে পারেন। Scarb আবার Cairo-এর প্যাকেজ ম্যানেজারও।

আপনার প্ল্যাটফর্মের জন্য প্রস্তাবিত ইনস্টলেশন নির্দেশনা পেতে [Cairo-এর অফিসিয়াল ওয়েবসাইট](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/) দেখুন।

অপারেটিং সিস্টেম অনুযায়ী:

- Linux/MacOS
    1. [asdf](https://asdf-vm.com/guide/getting-started.html) ইনস্টল করুন
    2. [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf) ইনস্টল করুন
    3. নতুন একটি টার্মিনাল সেশনে ইনস্টলেশন যাচাই করুন `scarb --version`
- Windows
    1. [scarb](https://docs.swmansion.com/scarb/download#windows) ইনস্টল করুন
    2. নতুন একটি টার্মিনাল সেশনে ইনস্টলেশন যাচাই করুন `scarb --version`

টুলচেইন ইনস্টল করলেই সব হয়ে যায় না! IDE সাপোর্ট উৎপাদনশীলতা অনেক বাড়িয়ে দেয়, আর বেশিরভাগ ডেভেলপার এখন সেটাই আশা করেন।
আপনি যদি Visual Studio Code ব্যবহার করেন, তাহলে [Cairo এক্সটেনশন](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1) ইনস্টল করার পরামর্শ দিই, যা সিনট্যাক্স হাইলাইটিং, কোড কমপ্লিশন আর অন্যান্য কাজের সুবিধা দেয়!
