# বিস্তারিত

*রেগুলার এক্সপ্রেশন* (রেজেক্স) হলো একটি ছোট প্যাটার্ন, যা কিছু টেক্সটের গঠন বর্ণনা করে। Factor-এর রেজেক্স টুলগুলো থাকে [`regexp`][regexp] ভোকাবুলারিতে, আর একটি প্যাটার্ন লেখা হয় `R/ ` আর `/` এর মাঝে একটি লিটারাল হিসেবে।

প্যাটার্নের বেশিরভাগ ক্যারেক্টার নিজের সাথে মিলে যায়। এর প্রকাশক্ষমতা আসে ক্যারেক্টার ক্লাস আর কোয়ান্টিফায়ার থেকে:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

তাহলে `R/ [A-Z]{2}-\d{4}/` মেলে "দুটি বড় হাতের অক্ষর, একটি ড্যাশ, চারটি সংখ্যা"-এর সাথে।

## পুরো স্ট্রিং মেলানো বনাম খোঁজা

`matches?` সফল হয় কেবল তখনই, যখন *পুরো* স্ট্রিংটি প্যাটার্নের সাথে মেলে। বাকি ওয়ার্ডগুলো স্ট্রিংয়ের *ভেতরে* খোঁজে:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## স্লাইস

`first-match` আর `re-split` রিটার্ন করে `slice` অবজেক্ট, যা নতুন স্ট্রিং নয়, বরং আসল স্ট্রিংয়ের হালকা ভিউ। যখন আলাদা একটি স্ট্রিং দরকার (যেমন কোনো স্ট্রিং লিটারালের সাথে তুলনা করতে), তখন `>string` দিয়ে স্লাইসকে রূপান্তর করুন। `all-matching-subseqs` আগেই স্ট্রিং রিটার্ন করে।

## প্রতিস্থাপন

`re-replace` প্রতিটি ম্যাচকে একটি রিপ্লেসমেন্ট স্ট্রিং দিয়ে বদলে দেয় এবং ফলাফলটি রিটার্ন করে:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## রানটাইমে প্যাটার্ন তৈরি করা

`R/ /` পার্স করা হয় ফাইলটি লোড হওয়ার সময়। রানটাইমে গণনা করা কোনো স্ট্রিং থেকে প্যাটার্ন তৈরি করতে `<regexp>` ব্যবহার করুন:

```
<regexp> ( string -- regexp )
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
