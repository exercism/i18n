# সম্পর্কে

একটি `List` [`Array`][array]-এর সাথে অনেকটাই মিল। তবে এমন কিছু বড় পার্থক্য আছে যা আপনি এড়িয়ে যেতে চাইবেন না:

1. একটি লিস্ট বর্গাকার বন্ধনী দিয়ে ইনডেক্স করা যায় না, অর্থাৎ `[0]`।
2. একটি লিস্ট ইনিশিয়ালাইজ করা যায় না।
3. লিস্ট কম্প্রিহেনশন বলে কিছু নেই।
4. একটি লিস্ট আইটারেট করার সময় এলিমেন্টগুলো অবাধে পরিবর্তন করতে পারে।

`List` হলো `haxe.ds` প্যাকেজের একটি সদস্য, তাই যখনই আপনি লিস্ট ব্যবহার করতে চাইবেন, আপনাকে এর প্যাকেজটি ইমপোর্ট করতে হবে:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
