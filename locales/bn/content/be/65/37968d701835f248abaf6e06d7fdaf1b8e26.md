# পরিচিতি

Haxe-এ একটি অ্যাবস্ট্রাক্ট টাইপ হলো এমন একটি টাইপ, যা রানটাইমে ভিন্ন একটি টাইপ। এটি একটি কম্পাইল-টাইম সুবিধা, যা কংক্রিট টাইপের "ওপর" টাইপ ডিফাইন করে, যাতে সেগুলোর আচরণ পরিবর্তন বা বাড়ানো যায়:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

এখানে আমরা `abstract` কিওয়ার্ডটি ব্যবহার করে `AbstractInt` টাইপটি ডিক্লেয়ার করছি। এর সিনট্যাক্স `class`-এর সিনট্যাক্সের সাথে অনেকটাই মিল। আর ক্লাসের মতোই, অ্যাবস্ট্রাক্ট টাইপেও মেথড থাকতে পারে। ক্লাসের মতোই এগুলোকে ইনস্ট্যান্টিয়েট করা ও ব্যবহার করা যায়:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
