# নির্দেশাবলি

ভবিষ্যতের এক জাদুকর হিসেবে Elyse-কে কিছু মৌলিক বিষয় অনুশীলন করতে হবে।
তার কাছে কার্ডের একটি স্ট্যাক আছে, যেটি নিয়ে সে নানা রকম কারিকুরি করতে চায়।

কাজটি একটু সহজ করতে সে শুধু ১ থেকে ১০ নম্বরের কার্ডগুলোই ব্যবহার করে, তাই তার কার্ডের স্ট্যাককে সংখ্যার একটি ভেক্টর দিয়ে প্রকাশ করা যায়।
কোনো নির্দিষ্ট কার্ডের অবস্থান ভেক্টরের ইনডেক্সের সাথে মিলে যায়।

## 1. স্ট্যাক থেকে একটি কার্ড নিয়ে আসা

একটি কার্ড নিতে হলে প্রদত্ত স্ট্যাক থেকে `position` ইনডেক্সের কার্ডটি রিটার্ন করুন।

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. স্ট্যাকে একটি কার্ড বদল করা

একটু হাতের কৌশল দেখিয়ে `position` ইনডেক্সের কার্ডটি প্রদত্ত রিপ্লেসমেন্ট কার্ডের সাথে বদলে দিন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. স্ট্যাকের উপরে একটি কার্ড ঢোকানো

স্ট্যাকের একেবারে উপরে একটি নতুন কার্ড ঢুকিয়ে একটি কার্ড হাজির করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. স্ট্যাক থেকে একটি কার্ড সরানো

স্ট্যাক থেকে প্রদত্ত `position` ইনডেক্সের কার্ডটি সরিয়ে একটি কার্ড গায়েব করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. স্ট্যাকের উপরের কার্ডটি সরানো

স্ট্যাকের উপরের কার্ডটি সরিয়ে একটি কার্ড গায়েব করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. স্ট্যাকের নিচে একটি কার্ড ঢোকানো

স্ট্যাকের একেবারে নিচে একটি নতুন কার্ড ঢুকিয়ে একটি কার্ড হাজির করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. স্ট্যাকের নিচ থেকে একটি কার্ড সরানো

স্ট্যাকের একেবারে নিচের কার্ডটি সরিয়ে একটি কার্ড গায়েব করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. স্ট্যাকের আকার যাচাই করা

স্ট্যাকের আকার `stack_size`-এর সমান কি না, তা যাচাই করুন।

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
