# নির্দেশনা

হালের ঘাটে এখন রাতের শিফট। মালবাহী জাহাজ *Olwen* পাশে নোঙর করা, আর এক দল ঘাটশ্রমিক সমান্তরালে ম্যানিফেস্ট নিয়ে কাজ করছে। জাহাজে ওঠার আগে প্রতিটি ক্রেট ওজন করতে হবে, আর হারবার মাস্টার একটি একক চলমান **টনেজ হিসাব** রাখেন, যেটি প্রতিটি উত্তোলনে হালনাগাদ হয়। সমস্যা হলো: ঘাটে ক্রেন আছে মাত্র একটি, তাই একই সময়ে দুইজন ঘাটশ্রমিক হিসাবটি হালনাগাদ করলেও সেটি ছিঁড়ে যাওয়া চলবে না।

প্রতিটি ক্রেট হলো সামগ্রীর ওজনের একটি অ্যারে। ক্রেটের ওজন হলো সেই সামগ্রীগুলোর যোগফল।

## 1. একটি ক্রেট ওজন করুন

`weigh-crate` ডিফাইন করুন, যেটি একটি ক্রেট নেয় আর তার মোট ওজন রিটার্ন করে। এটি সাধারণ সিকোয়েন্সিয়াল কাজ: একটি ক্রেট, একটি সংখ্যা বেরিয়ে আসে।

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. পুরো ম্যানিফেস্ট সমান্তরালে ওজন করুন

`weigh-all` ডিফাইন করুন, যেটি ক্রেটের একটি অ্যারে নেয় আর একই ক্রমে তাদের ওজনের অ্যারে রিটার্ন করে। `parallel-map` ব্যবহার করুন, যাতে প্রতি ক্রেটের কাজ সমান্তরালে চলে।

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. একটি নতুন ক্রেন তৈরি করুন

`<crane>` ডিফাইন করুন একটি নতুন ক্রেন তৈরি করতে: একটি টাপল, যাতে থাকে একটি নতুন `<lock>` আর টনেজ `0`। ক্রেনটিই হলো সেই শেয়ার্ড রিসোর্স, যেটি পরের কাজগুলো সুরক্ষা করবে।

```factor
<crane> tonnage>> .
! => 0
```

## 4. চলমান টনেজ হিসাবে একটি ক্রেট তুলুন

`hoist-crate` ডিফাইন করুন, যেটি একটি `weight` আর একটি `crane` নেয় এবং **ক্রেনের লকের অধীনে** ক্রেনের টনেজে ওজনটি যোগ করে, যাতে একই সময়ে অন্য ঘাটশ্রমিকরা তোলা তুললেও পড়া-যোগ-লেখা অ্যাটমিক থাকে।

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. চলমান টনেজ পড়ুন

`crane-tonnage` ডিফাইন করুন, যেটি ক্রেনের বর্তমান টনেজ রিটার্ন করে, সেটিও লকের অধীনে, যাতে তোলার মাঝখানে পড়াটি ছিঁড়ে যাওয়া কোনো মান দেখতে না পায়।

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. মাল লোড করুন

`load-cargo` ডিফাইন করুন, যেটি ক্রেটের একটি অ্যারে আর একটি ক্রেন নেয়, এবং **প্রতিটি ক্রেটের জন্য একটি ঘাটশ্রমিক থ্রেড তৈরি করে**, যেটি ক্রেটটি ওজন করে আর ওজনটি ক্রেনে তোলে। প্রতিটি ঘাটশ্রমিক শেষ হওয়ার পরেই ওয়ার্ডটি রিটার্ন করে। জয়েন সমন্বয় করতে `<promise>` আর `?promise` ব্যবহার করুন।

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
