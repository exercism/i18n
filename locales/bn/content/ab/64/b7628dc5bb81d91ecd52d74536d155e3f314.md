# ভূমিকা

JavaScript-এ `Array` ক্লাসে অ্যারে ট্রান্সফর্ম করার জন্য অনেক শক্তিশালী বিল্ট-ইন মেথড আছে।
এই মেথডগুলোর কল্যাণে একটি অ্যারে থেকে আরেকটি অ্যারেতে রূপান্তর করা অনেক সহজ হয়ে যায়, যা সাধারণ একটি for লুপ বা আরও সরাসরি ম্যানিপুলেশন দিয়ে করতে হলে অনেক বেশি খাটতে হতো।

কিছু মেথড [_পিওর_][pure-function-definition], অর্থাৎ সেগুলো মূল অ্যারেটি পরিবর্তন করে না।
বদলে তারা একটি নতুন অ্যারে রিটার্ন করে।
আবার অন্য কিছু মেথড যে অ্যারেটির উপর কল করা হয় সেটিই ম্যানিপুলেট করে এবং পরিবর্তিত অ্যারেটি রিটার্ন করে **না**।

অ্যারে ট্রান্সফর্ম করার জন্য সবচেয়ে কমন মেথডগুলো নিচে তুলে ধরা হলো।
উপলব্ধ সব মেথডের পূর্ণ তালিকা [MDN ডকুমেন্টেশন][array-methods] থেকে পাওয়া যাবে।

### map (পিওর)

আর্গুমেন্ট হিসেবে পাঠানো একটি ফাংশন অনুযায়ী প্রতিটি এলিমেন্ট ট্রান্সফর্ম করে নতুন একটি অ্যারে তৈরি করুন।
এই কলব্যাক ফাংশনগুলো প্রায়ই [অ্যারো ফাংশন][concept-arrow-functions] হিসেবে লেখা হয়।

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

লক্ষণীয় যে, ফলে যে অ্যারেটি পাওয়া যায় তার দৈর্ঘ্য সবসময় মূল অ্যারেটির মতোই হয়।

### filter (পিওর)

একটি ফিল্টারিং ফাংশন দিয়ে বর্তমান অ্যারেটি ফিল্টার করে নতুন একটি অ্যারে তৈরি করে (এলিমেন্টটি রাখা উচিত হলে ফাংশনটি ট্রু রিটার্ন করে, আর বাদ দেওয়া উচিত হলে ফলস)।

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (পিওর)

এমন একটি ফাংশন ব্যবহার করে অ্যারেটিকে একটি একক মানে নামিয়ে আনে, যে ফাংশনটি প্যারামিটার হিসেবে একটি _অ্যাকুমুলেটর_ আর অ্যারেটির বর্তমান এলিমেন্ট নেয়।
এই ফাংশনটি ঠিক করে দেয় বর্তমান এলিমেন্টটিকে কীভাবে অ্যাকুমুলেটরে মিলিয়ে দিতে হবে, আর পরের ইটারেশনে যে অ্যাকুমুলেটরটি ব্যবহার হবে সেটিই রিটার্ন করে।

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

একটি অ্যারেটির এলিমেন্টগুলো উল্টে দেয়।

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

এই মেথডটি যে অ্যারেটির উপর কল করা হয় সেটিই পরিবর্তন করে।

### slice (পিওর)

একটি শুরুর ইনডেক্স আর একটি শেষের ইনডেক্স দিলে, যে অ্যারেটির উপর কল করা হয় সেটি থেকে একটি সাব-অ্যারে তৈরি করে।

শেষের ইনডেক্সে থাকা এলিমেন্টটি অন্তর্ভুক্ত হবে না।
এছাড়া সব প্যারামিটার ঐচ্ছিক:
শুরুর ইনডেক্সের ডিফল্ট মান `0`, আর শেষের ইনডেক্সের ডিফল্ট মান অ্যারেটির দৈর্ঘ্য।

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

একটি অ্যারের এলিমেন্ট মুছে ফেলে বা প্রতিস্থাপন করে এবং/অথবা নতুন এলিমেন্ট যোগ করে।

এটি নিচের প্যারামিটারগুলো নেয়:

- যে এলিমেন্টের ইনডেক্স থেকে অ্যারেটি পরিবর্তন শুরু করতে হবে
- মুছে ফেলার এলিমেন্টের সংখ্যা
- অ্যারেতে ঢোকানোর এলিমেন্টগুলো (ঐচ্ছিক)

`splice` যে এলিমেন্টগুলো মুছে ফেলা হয়েছে সেগুলো রিটার্ন করে।

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

ডিফল্টভাবে `sort` একটি অ্যারের এলিমেন্টগুলো সাজায়, প্রথমে সেগুলোকে স্ট্রিং-এ রূপান্তর করে তারপর স্ট্রিং তুলনা প্রয়োগ করে (দেখুন [তুলনা ধারণা][concept-comparison])।
সাজানো হয় _ইন-প্লেস_, অর্থাৎ মূল অ্যারেটিই পরিবর্তিত হয়।
`sort` পরিবর্তিত অ্যারেটিই রিটার্নও করে, যা সুবিধাজনক যদি আপনি এর সাথে অন্য মেথডগুলো চেইন করতে চান।

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

সাজানোর ধরন নিজের ইচ্ছেমতো সাজাতে চাইলে আপনি আর্গুমেন্ট হিসেবে একটি তুলনা ফাংশন পাঠাতে পারেন।
তুলনা ফাংশনটিকে দুটি আর্গুমেন্ট দিয়ে কল করা হয়, যেগুলো অ্যারেটির দুটি এলিমেন্ট।
এরপর এটিকে নিচের মানগুলো রিটার্ন করতে হবে:

- একটি ঋণাত্মক সংখ্যা, যদি প্রথম আর্গুমেন্টটি দ্বিতীয়টির আগে সাজানো উচিত হয়
- একটি ধনাত্মক সংখ্যা, যদি প্রথম আর্গুমেন্টটি দ্বিতীয়টির পরে সাজানো উচিত হয়
- `0`, যদি এলিমেন্টগুলোর ক্রম একই থাকা উচিত হয়

উদাহরণস্বরূপ, সংখ্যা সাজাতে নিচের তুলনা ফাংশনটি ব্যবহার করা যায়।

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
