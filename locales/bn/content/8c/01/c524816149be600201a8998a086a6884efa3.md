# টেস্ট

আমরা আমাদের ওয়েবসাইটের টেস্ট রানার হিসেবে [pytest][Getting Started Guide] ব্যবহার করি।
Python ট্র্যাকের অনুশীলনীর টেস্ট যদি আপনার নিজের কম্পিউটারে ডাউনলোড করে চালাতে চান, তাহলে আপনার ডেভেলপমেন্ট মেশিনে `pytest` ইনস্টল করা লাগবে।
এর সঙ্গে নিচের `pytest` প্লাগইনগুলোও ইনস্টল করা উচিত:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

আমরা কোড লিন্টিং প্রোগ্রাম [pylint][pylint] ব্যবহারেরও সুপারিশ করি, কারণ এটি আমাদের ওয়েবসাইটের স্বয়ংক্রিয় ফিডব্যাকের একটি অংশ এবং একটি খুবই দরকারি স্ট্যাটিক কোড অ্যানালাইসিস টুল হতে পারে।
ব্যবহারের সুবিধার জন্য `pytest`-এর [pytest-pylint][pytest-pylint] প্লাগইন আপনাকে কমান্ড লাইনে `pytest`-এর মাধ্যমে `pylint` রান করার সুযোগ দেবে।

Pylint-এর কনফিগারেশন কিছুটা বেশি মনে হতে পারে, তাই শুরু করার জন্য [pylint.readthedocs.io-এর এই টিউটোরিয়ালটি][tutorial from pylint.readthedocs.io] সহায়ক হতে পারে, আর Real Python-এর [Code Quality: Tools and Best Practices][Code Quality: Tools and Best Practices] ওভারভিউটিও তাই।

## pytest ইনস্টল করা

বিল্ট-ইন Python ইউটিলিটি [`pip`][pip] দিয়ে `pytest` ইনস্টল ও আপডেট করা যায়।

আরও টিপসের জন্য Brett Cannon-এর কাছে Python-এর জন্য প্যাকেজ ইনস্টল করার একটি চমৎকার [দ্রুত-সহজ গাইড][quick-and-dirty] আছে, সঙ্গে রয়েছে [কেন আপনার `python -m pip` ব্যবহার করা উচিত][python-m-pip] তার একটি দারুণ ব্যাখ্যা।
Python-এর কমান্ড লাইন আর্গুমেন্ট নিয়ে আরও জানতে Python ডকুমেন্টেশনে [কমান্ড লাইন ও এনভায়রনমেন্ট][python command line] দেখুন।

**নোট:** আপনার সিস্টেমে `Python3` আর `py` Python-এর অ্যালিয়াস হতে পারে, নাও হতে পারে।
নিচের ইনস্টল কমান্ডগুলো সেই অনুযায়ী সামঞ্জস্য করে নিন।
কোনো ভার্চুয়াল এনভায়রনমেন্টে `pytest` ইনস্টল করতে চাইলে কমান্ড চালানোর আগে এনভায়রনমেন্টটি **অ্যাক্টিভেট করা আছে** কিনা নিশ্চিত করুন।
অন্যথায় `pytest` ইনস্টলেশনটি গ্লোবাল হয়ে যাবে।

#### Windows

```powershell
PS C:\Users\foobar> py -m pip install pytest pytest-cache pytest-subtests pytest-pylint
Successfully installed pytest-8.3.3 ...
```

#### Linux / MacOS

```bash
$ python3 -m pip install pytest pytest-cache pytest-subtests pytest-pylint
Successfully installed pytest-8.3.3 ...

```

ইনস্টলেশন সফল হয়েছে কিনা দেখতে:

```bash
$ python3 -m pytest --version
pytest 8.3.3
```

## টেস্ট চালানো

টেস্ট চালাতে, টার্মিনালে `cd` দিয়ে যে ফোল্ডারটিতে অনুশীলনীটি রাখা আছে সেখানে যান (_নিচের `<exercise-folder-location>`-এর জায়গায় আপনার পাথ বসান_)।

```bash
$ cd <exercise-folder-location>
```

<br>

~~~~exercism/note
 `<exercise-folder-location>` বা অ্যাঙ্গেল ব্র্যাকেটের ভেতরের বেশিরভাগ জিনিস বোঝায় একটি **_প্লেসহোল্ডার মান_**।
একটি সাধারণ পাথ বা ফাইলের নাম লেখা উচিত _কোনো ব্র্যাকেট ছাড়াই_।


উদাহরণস্বরূপ: `/Users/janedoe/exercism/python/exercises/concept/chaitanas-colossal-coaster` (*nix সিস্টেমে), `C:\Users\janedoe\exercism\python\exercises\practice\hello-world\` (Windows-এ), `myFolder` বা `my_file.py`।
~~~~  

<br>


আপনি যে ফাইলটি চালাতে চাইবেন তার নাম সাধারণত `_test.py` দিয়ে শেষ হয়।
এই ফাইলে অনুশীলনীর সলিউশনের টেস্ট থাকে, এবং সলিউশন আপলোড করলে ওয়েবসাইটে যে টেস্টগুলো চলে সেগুলোই এগুলো।
এরপর টার্মিনালে নিচের কমান্ডটি চালান, `<exercise_test.py>`-এর জায়গায় টেস্ট ফাইলের অবস্থান/নাম বসিয়ে:

```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

### ওয়ার্নিং ঠিক করা

উপরের কমান্ডে যদি `pytest -o markers=task` ব্যবহার না করেন, তাহলে আমাদের _নতুন_ সিনট্যাক্স ব্যবহার করা কোনো টেস্ট চালালে "unknown markers" নিয়ে `warnings` আসতে পারে।

প্রতিবার টেস্ট চালানোর সময় `pytest -o markers=task` টাইপ করা এড়াতে আপনি একটি `pytest.ini` কনফিগারেশন ফাইল ব্যবহার করতে পারেন, যা Python ট্র্যাক ডিরেক্টরির টপ লেভেল থেকে ডাউনলোড করা যায়: [pytest.ini][pytest.ini]।

আপনি নিচের বিষয়বস্তু দিয়ে নিজের `pytest.ini` ফাইলও তৈরি করতে পারেন:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Exercism অনুশীলনীগুলোর _রুট_ বা _ওয়ার্কিং_ ডিরেক্টরিতে এই ফাইলটি রাখলে মার্কগুলো রেজিস্টার হবে এবং ওয়ার্নিংগুলো বন্ধ হবে।
pytest মার্ক সম্পর্কে আরও তথ্য পাবেন `pytest` ডকুমেন্টেশনে [অ্যাট্রিবিউট দিয়ে টেস্ট ফাংশন চিহ্নিত করা][marking test functions with attributes]-এ এবং `pytest` ডকুমেন্টেশনে [কাস্টম মার্কার নিয়ে কাজ করা][working with custom markers]-এ।

_pytest কনফিগারেশন কাস্টমাইজ করার আরও তথ্য পাবেন pytest ডকুমেন্টেশনে [কনফিগারেশন ফাইল ফরম্যাট][configuration file formats]-এ_

### টেস্ট ফেইলিউর

টেস্ট ফেইল করলে `pytest` প্রতিটি ফেইল করা টেস্টের টেক্সট, তার সঙ্গে প্রতিটির প্রত্যাশিত ও প্রকৃত `return` মান টার্মিনালে প্রিন্ট করে।
নিচে একটি ফেইল করা টেস্টের সাধারণ উদাহরণ:

```bash
$(my_venv) python3 -m pytest -o markers=task <exercise_test.py>

=================== FAILURES ====================
______________ name_of_failed_test ______________
# Test code inside of <exercise_test.py> that failed.
...

============ short test summary info ============
FAILED exercise_test.py::ExerciseTest::name_of_failed_test
========== 1 failed, 2 passed in 0.13s ==========
```

### অতিরিক্ত আর্গুমেন্ট

pytest আপনার স্ক্রিনে ঠিক কী ফেরত দেয় তা নিয়ে সত্যিই নির্দিষ্ট হতে চাইলে, এখানে কিছু কাজের কমান্ড-লাইন আর্গুমেন্ট আছে যা দিয়ে আপনি এর আচরণ কনফিগার করতে পারবেন।

#### প্রথম ফেইলিউরের পর থামা [`-x`]

`-x` ফ্ল্যাগ ব্যবহার করলে টেস্ট স্বাভাবিকভাবেই চলবে, কিন্তু প্রথম টেস্ট ফেইল হওয়ার সঙ্গে সঙ্গেই টেস্ট রান থেমে যাবে।
একবারে একটি টাস্ক বা টেস্ট ফেইলিউর ডিবাগ করতে চাইলে এটি সহায়ক:

```bash
$(my_venv) python3 -m pytest -o markers=task -x exercises/<exercise_name>/<test_file_test.py>

=================== FAILURES ====================
_______________ example_test_foo ________________
...
...
============ short test summary info ============
FAILED example_test.py::ExampleTest::example_test_foo
!!!!!!!!!!! stopping after 1 failures !!!!!!!!!!!
========== 1 failed, 5 passed in 0.28s ==========
```

#### আগে ফেইল করা টেস্ট [`--ff`]

`pytest-cache` প্লাগইন মনে রাখে গতবার `pytest` চালানোর সময় কোন টেস্টগুলো ফেইল করেছিল, তাই `--ff` ফ্ল্যাগ ব্যবহার করলে `pytest` আগে **পূর্বে ফেইল করা টেস্টগুলো** চালাবে, তারপর বাকি টেস্টগুলো চালিয়ে যাবে।
কোনো এক নির্দিষ্ট টাস্ক বা ইনপুটের সেট নিয়ে অনেকগুলো ছোটখাটো সংশোধন করলে এটি আপনার টেস্টিং দ্রুত করে তুলতে পারে।

```bash
$(my_venv) python3 -m pytest -o markers=task --ff <example_file_test.py>
==================== 7 passed in 503s ====================
```

### সুপারিশকৃত ওয়ার্কফ্লো

আপনার ডিবাগিং সহজ ও (সম্ভবত) দ্রুত করতে আমরা নিচের কমান্ডগুলো ব্যবহারের সুপারিশ করি:

প্রথমে আপনার ওয়ার্কিং ডিরেক্টরি বদলে যে অনুশীলনীটি টেস্ট করতে চান তার ডিরেক্টরিতে যান:

```bash
$(my_venv) cd path/to/exercise
```

এরপর, আগে ব্যাখ্যা করা `-x` ও `--ff` আর্গুমেন্টসহ টেস্টগুলো চালান:

```bash
$(my_venv) python3 -m pytest -o markers=task -x --ff <example_file_test.py>
```

এতে আপনার সলিউশন টেস্ট হবে।
`pytest` কোনো ফেইল করা টেস্টে পৌঁছালে প্রোগ্রামটি থেমে যাবে এবং কোন টেস্টটি ফেইল করেছে তা জানাবে।
আপনি সংশোধন করে আবার টেস্ট চালালে `pytest` প্রথমে আগের ফেইল করা টেস্টটি চালাবে, তারপর বাকি টেস্টগুলো চালিয়ে যাবে।

### pytest-এর সঙ্গে PDB, Python ডিবাগার ব্যবহার করা

"প্রফেশনালের মতো ডিবাগ" করতে চাইলে `pytest` কমান্ডের পরে `--pdb` আর্গুমেন্ট ব্যবহার করতে পারেন, আর তাতে আপনি ঢুকে পড়বেন বিল্ট-ইন [Python ডিবাগার][pdb] `PDB`-তে।

```bash
$(my_venv) python3 -m pytest -o markers=task -x --ff --pdb <example_file_test.py>
=============== 4 passed in 0.15s ===============
```

কোনো টেস্ট ফেইল করলে `PDB`-তে ঢুকে পড়লে আপনি বর্তমান স্কোপ দেখতে দেখতে আপনার কোড ধাপে ধাপে এগোতে পারবেন, সেই সঙ্গে ভ্যারিয়েবলের মান ও বিভিন্ন ফাংশনের সিগনেচারও যাচাই করতে পারবেন।
`PDB` মডিউল সম্পর্কে আরও বিস্তারিত পাবেন [PDB-এর Python ডকুমেন্টেশনে][pdb]।
এর বাইরে, [PDB নিয়ে pytest ডকুমেন্টেশন][pytest-pdb] এবং [Real Python-এর এই গাইড](https://realpython.com/python-debugging-pdb/) অত্যন্ত সহায়ক।

## অতিরিক্ত তথ্য

### Python-কে আপনার PATH-এ যোগ করা

**নোট:** Windows-এ যদি আপনি [PSF Installer][psf-installer] দিয়ে Python ইনস্টল করে থাকেন, তাহলে কমান্ডটি হবে `py`, `python3` নয়।

একটি মডিউল রান করতে প্রতিবার `python3 -m` টাইপ করা কিছুটা বিরক্তিকর লাগতে পারে।
এটি এড়াতে, আপনার Python ইনস্টলেশনের `Scripts` ফোল্ডারটি আপনার PATH-এ যোগ করতে পারেন।
Python কোথায় ইনস্টল করেছেন জানা না থাকলে টার্মিনালে নিচের কমান্ডটি চালান:

```bash
$ python3 -c "import os, sys; print(os.path.dirname(sys.executable))"
<python_directory>
```

_রিটার্ন করা_ ডিরেক্টরিটিই হলো যেখানে আপনার বর্তমানে সক্রিয় Python সংস্করণ ইনস্টল করা আছে; এই অংশে এটিকে `<python_directory>` বলা হয়েছে।

#### Windows

`Windows Start` বোতামে ক্লিক করুন এবং _Edit the system environment variables_ খুঁজে এন্টার চাপুন।
এরপর `Environment Variables...` চাপুন:

![নীল বোতামে চাপুন, হাহা](https://raw.githubusercontent.com/exercism/python/main/docs/img/Windows-SystemProperties.png)

এরপর আপনার _User variables_-এ `Path` ভ্যারিয়েবলটি খুঁজে বের করুন, সেটি সিলেক্ট করুন এবং `Edit...`-এ ক্লিক করুন:

![path ভ্যারিয়েবল সিলেক্ট করা](https://raw.githubusercontent.com/exercism/python/main/docs/img/Windows-EnvironmentVariables.png)

এরপর ছবিতে দেখানো মতো একটি নতুন লাইন যোগ করুন, `<python_directory>`-এর জায়গায় আপনার Python ইনস্টলেশনের ডিরেক্টরি বসিয়ে:

![python-কে path-এ যোগ করা](https://raw.githubusercontent.com/exercism/python/main/docs/img/Windows-AddPythonPath.png)

#### MacOS/Linux

নিচেরটি `bash` শেলসহ বেশিরভাগ Linux ও MacOS ফ্লেভারে কাজ করার কথা।
Linux ডিস্ট্রো অনুযায়ী, আর `fish` বা `zsh` শেল ব্যবহার হচ্ছে কিনা তার ভিত্তিতে কমান্ড আলাদা হতে পারে।
`python3 -c "import os, sys; print(os.path.dirname(sys.executable))"`-এর আউটপুট দিয়ে `<python_directory>`-এর জায়গা পূরণ করুন

```bash
export PATH="$PATH:<python_directory>"
```
