# নির্দেশনা

আপনি যদি Raspberry Pi দিয়ে কিছু বানাতে চান, তাহলে সম্ভবত আপনার _রেজিস্টর_ লাগবে।
এই অনুশীলনীর জন্য এদের সম্পর্কে দুটি বিষয় জানা দরকার:

- প্রতিটি রেজিস্টরের একটি রেজিস্ট্যান্স মান থাকে।
- রেজিস্টরগুলো ছোট, এতই ছোট যে সেগুলোর গায়ে রেজিস্ট্যান্স মান ছাপলে তা পড়া কঠিন হয়ে যেত।

এই সমস্যা এড়ানোর জন্য নির্মাতারা রেজিস্টরের গায়ে রঙের কোড দেওয়া ব্যান্ড ছাপেন, যা দিয়ে তার রেজিস্ট্যান্স মান বোঝানো হয়।
প্রতিটি ব্যান্ডের একটি অবস্থান আর একটি সংখ্যাসূচক মান থাকে।

রেজিস্টরের প্রথম ২টি ব্যান্ড অনুসরণ করে একটি সহজ এনকোডিং স্কিম: প্রতিটি রং একটি নির্দিষ্ট সংখ্যার সাথে মিলে যায়।

তৃতীয় ব্যান্ডটি একটি মাল্টিপ্লায়ার।

এই অনুশীলনীতে আপনি একটি সহায়ক প্রোগ্রাম বানাবেন, যাতে ব্যান্ডগুলোর মান আপনাকে মনে রাখতে না হয়।

রেজিস্টরের রঙের এনকোডিং সম্পর্কে আরও তথ্য [ইলেকট্রনিক কালার কোড নিয়ে উইকিপিডিয়া নিবন্ধে][e-color-code] পাওয়া যাবে।

## 1. একটি নেমড ভেক্টর ডিফাইন করুন

রংগুলো এভাবে এনকোড করা হয়েছে:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

নেমড ভেক্টর `resistor_bands` তৈরি করুন, যেখানে রংগুলো থাকবে নাম হিসেবে আর সংখ্যাগুলো থাকবে মান হিসেবে।

## 2. একটি ব্যান্ডের সাথে সম্পর্কিত মান রিটার্ন করুন

প্রথমে আপনাকে যেকোনো রঙের ব্যান্ডের একক মান বের করতে পারতে হবে।

একটি ফাংশন `band_value(band)` ডিফাইন করুন, যেটি ব্যান্ডের রঙের একটি `string` নেয়।
ফাংশনটি ওই রঙের সংশ্লিষ্ট মান রিটার্ন করে।

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. দুটি ব্যান্ডের সাথে সম্পর্কিত মান রিটার্ন করুন

রেজিস্টরের প্রথম দুটি ব্যান্ড মিলে একটি সংখ্যা তৈরি করে।
প্রথম দুটি ব্যান্ডের সংখ্যা যদি যথাক্রমে `m` ও `n` হয়, তবে তারা মিলে `mn` সংখ্যাটি তৈরি করে।

একটি ফাংশন `two_band_value(bands)` ডিফাইন করুন, যেটি দুটি ব্যান্ড রঙের `string`-এর একটি `vector` নেয়।
ফাংশনটি ওই দুটি রঙের সংমিশ্রণের সংশ্লিষ্ট মান রিটার্ন করে।

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. তিনটি ব্যান্ডের সাথে সম্পর্কিত ওহম রিটার্ন করুন

সবশেষে, প্রথম দুটি ব্যান্ড তৃতীয়টির সাথে মিলিয়ে আপনাকে পূর্ণ ওহম রেটিং বের করতে হবে।
এর জন্য দুটি ব্যান্ডের মান আর একটি মাল্টিপ্লায়ার বের করতে হবে।
মাল্টিপ্লায়ারকে এভাবে ভাবা যায়: দুটি ব্যান্ডের মানের শেষে কতগুলো শূন্য যোগ হবে।

একটি ফাংশন `ohms(bands)` ডিফাইন করুন, যেটি তিনটি ব্যান্ড রঙের `string`-এর একটি `vector` নেয়।
ফাংশনটি ওই তিনটি রঙের সংমিশ্রণের সংশ্লিষ্ট ওহম রেটিং রিটার্ন করে।

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
