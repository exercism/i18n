# অ্যারে মেথড

অ্যারে হলো একটি কমন ডেটা স্ট্রাকচার, যা নিয়ে কাজ করা হয়। তাই অ্যারে নিয়ে কাজ করার জন্য একগুচ্ছ মেথড রয়েছে। এর মধ্যে আছে সর্টিং, রিভার্সিং, ইনসার্টিং এবং আরও অনেক কিছু।

এই মেথডগুলোর কয়েকটি ডেস্ট্রাকটিভ, অর্থাৎ এগুলো মূল অ্যারেটিকে বদলে দেয়। আবার বাকিগুলো নন-ডেস্ট্রাকটিভ, অর্থাৎ এগুলো একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি বদলায় না।

অ্যারে নিয়ে কাজ করার সময় সবচেয়ে বেশি ব্যবহৃত কিছু মেথড এখানে দেওয়া হলো:

## insert

অ্যারেতে একটি এলিমেন্ট ইনসার্ট করতে চাইলে আপনি [`insert`][insert] মেথডটি ব্যবহার করতে পারেন, যা একটি ইনডেক্স আর একটি এলিমেন্ট আর্গুমেন্ট হিসেবে নেয়। নির্দিষ্ট ইনডেক্সে এলিমেন্টটি যোগ হবে, আর অ্যারের বাকি অংশ ডান দিকে সরে যাবে। ইনডেক্সটি সীমার বাইরে গেলে একটি `IndexError` উত্থাপিত হবে।

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

অ্যারে থেকে কোনো নির্দিষ্ট এলিমেন্ট মুছে ফেলতে চাইলে আপনি [`delete`][delete] মেথডটি ব্যবহার করতে পারেন, যা একটি এলিমেন্ট আর্গুমেন্ট হিসেবে নেয়। মেথডটি মুছে ফেলা এলিমেন্টটি রিটার্ন করে। এলিমেন্টটি অ্যারেতে না থাকলে `nil` রিটার্ন হবে।

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

অ্যারের প্রথম বা শেষ এলিমেন্টটি পেতে চাইলে আপনি [`first`][first] আর [`last`][last] মেথড ব্যবহার করতে পারেন। এই মেথডগুলো একটি ঐচ্ছিক আর্গুমেন্ট নেয়, যা দিয়ে বোঝানো যায় কতটি এলিমেন্ট রিটার্ন করতে হবে। ইনডেক্স `0` বা `-1` ব্যবহার করা, কিংবা একটি রেঞ্জ ব্যবহার করার চেয়ে এগুলো পড়তে বেশি সুবিধাজনক। অ্যারেটি খালি থাকলে একটি `Enumerable::EmptyError` উত্থাপিত হবে।

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

অ্যারেটি উল্টে দিতে চাইলে আপনি [`reverse`][reverse] মেথডটি ব্যবহার করতে পারেন, যা এলিমেন্টগুলো উল্টো ক্রমে সাজিয়ে একটি নতুন অ্যারে রিটার্ন করে। খেয়াল রাখা জরুরি যে `reverse` একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি বদলায় না। মূল অ্যারেটি বদলাতে চাইলে মেথডের নামের শেষে একটি `!` যোগ করুন।

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

অ্যারেতে অবজেক্ট যোগ করতে চাইলে অ্যাপেন্ড মেথড(`<<`) কাজে লাগে। তবে দুটি অ্যারে একসাথে মেলাতে চাইলে আপনি [`+`][concat] অপারেটরটি ব্যবহার করতে পারেন, যা দুটি অ্যারের এলিমেন্ট নিয়ে একটি নতুন অ্যারে রিটার্ন করে।

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

কোনো অ্যারের সাথে আরেকটি অ্যারে অ্যাপেন্ড করলে অ্যারেটি একটি একক এলিমেন্ট হিসেবে যোগ হবে।

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

অ্যারেটি খালি কি না পরীক্ষা করতে আপনি [`empty?`][empty?] মেথডটি ব্যবহার করতে পারেন, যা অ্যারেটি খালি হলে `true` এবং অন্যথায় `false` রিটার্ন করে। অ্যারের দৈর্ঘ্য `0`-এর সাথে মিলিয়ে দেখার চেয়ে এটি পড়তে বেশি সুবিধাজনক।

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

অ্যারেতে কোনো এলিমেন্টের ইনডেক্স পেতে চাইলে আপনি [`index`][index] মেথডটি ব্যবহার করতে পারেন, যা একটি এলিমেন্ট আর্গুমেন্ট হিসেবে নেয়। এলিমেন্টটি অ্যারেতে না থাকলে `nil` রিটার্ন হবে।

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

অ্যারেতে কতটি এলিমেন্ট আছে জানতে চাইলে আপনি [`size`][size] মেথডটি ব্যবহার করতে পারেন।

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

অ্যারেতে কোনো এলিমেন্ট কতবার আছে গুনতে চাইলে আপনি [`count`][count] মেথডটি ব্যবহার করতে পারেন।

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

অ্যারেটি সাজাতে চাইলে আপনি [`sort`][sort] মেথডটি ব্যবহার করতে পারেন, যা এলিমেন্টগুলো সাজিয়ে একটি নতুন অ্যারে রিটার্ন করে। `reverse`-এর মতোই, এই মেথডটিও একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি বদলায় না।

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
