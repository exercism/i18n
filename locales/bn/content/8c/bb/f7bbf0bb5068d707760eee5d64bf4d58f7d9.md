# ইনস্টলেশন

## R রানটাইম ইনস্টল করুন
[CRAN হোমপেজ](https://cran.r-project.org/) দেখুন। সেখানে আপনি Linux, Mac OSX আর Windows-এর ডাউনলোড লিংক পাবেন। আপনার অপারেটিং সিস্টেমের জন্য ইনস্টলারটি ডাউনলোড করে চালান।

## RStudio IDE ইনস্টল করুন (প্রস্তাবিত)
RStudio হলো R-এ প্রোগ্রামিং করার জন্য একটি জনপ্রিয় ক্রস-প্ল্যাটফর্ম ইন্টিগ্রেটেড ডেভেলপমেন্ট এনভায়রনমেন্ট (IDE), যা Python, JavaScript আর Markdown-এর মতো অন্য ভাষাগুলোও সমর্থন করে। RStudio ব্যবহার করলে আপনার কোডে সমাধান লেখা ও টেস্ট চালানো আরও সহজ হয়ে যাবে।

[RStudio-র বর্তমান স্থিতিশীল সংস্করণ](https://www.rstudio.com/products/rstudio/download/) ডাউনলোড করে ইনস্টল করুন। অথবা বিকল্প হিসেবে আসন্ন রিলিজের [প্রিভিউ সংস্করণ](https://www.rstudio.com/products/rstudio/download/preview/) নিতে পারেন।

## R-এর জন্য Visual Studio Code এক্সটেনশন ইনস্টল করুন (বিকল্প)
Visual Studio Code-এর R এক্সটেনশনটি বর্ধিত সিনট্যাক্স হাইলাইটিং, কোড কমপ্লিশন, লিন্টিং, ফরম্যাটিং, R টার্মিনালের সাথে কাজ করা, ডেটা, প্লট, ওয়ার্কস্পেস ভ্যারিয়েবল ও হেল্প পেজ দেখা, প্যাকেজ ম্যানেজ করা এবং R Markdown ডকুমেন্ট নিয়ে কাজ করা সমর্থন করে।

[R এক্সটেনশনের বর্তমান সংস্করণ](https://code.visualstudio.com/docs/languages/r) ডাউনলোড করে ইনস্টল করুন।

## টেস্ট চালানোর জন্য R প্যাকেজ ইনস্টল করুন
স্পেকগুলো চালানোর টেস্ট রানার হলো Hadley Wickham-এর [`testthat`](https://github.com/hadley/testthat) লাইব্রেরি, যা R প্যাকেজ লেখকদের কাছে একটি জনপ্রিয় পছন্দ।

এই লাইব্রেরিটি ইনস্টল করতে আপনার RStudio কনসোলে (বা যেখানেই আপনি R ব্যবহার করছেন) নিচের অংশটি টাইপ করুন।

```{R}
install.packages("testthat")
```

অনুশীলনীগুলো সমাধান করতে আপনার প্যাকেজ ইনস্টল করার _প্রয়োজন_ পড়ার সম্ভাবনা যদিও কম, তবুও আপনার প্রোগ্রামিং স্টাইলের সাথে মানানসই [`tidyverse`](https://github.com/tidyverse/tidyverse)-এর মতো সাধারণ কাজে লাগে এমন একটি ইউটিলিটি প্যাকেজ আপনি আনতে চাইতে পারেন। `tidyverse`-এর মতো একটি প্যাকেজ ইনস্টল ও লোড করতে:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
