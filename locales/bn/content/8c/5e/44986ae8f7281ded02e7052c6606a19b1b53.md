# পরিচিতি

## সংখ্যা

Haskell-এ `Num` নামে একটি টাইপ আছে, যা সব সংখ্যাসূচক টাইপের মূল টাইপ।
সংখ্যা টাইপের ভিতরে চারটি প্রধান উপ-টাইপ রয়েছে: [`Int`][int], [`Integer`][integer], [`Double`][double] ও [`Float`][float]।

Haskell-এ ইন্টিজারের দুটি টাইপ আছে, যেগুলো পূর্ণসংখ্যা বোঝায়।
`Int` হলো নির্দিষ্ট আকারের ইন্টিজার, আর `Integer` হলো যেকোনো নির্ভুলতার ইন্টিজার।
`Integer` আপনার মেশিনের মেমরির সীমা পর্যন্ত যত বড়ই হোক না কেন যেকোনো সংখ্যা ধরে রাখতে পারে, আর `Int` বলতে বোঝায় সেই সব ধনাত্মক ও ঋণাত্মক ইন্টিজারের সেট, যেগুলো ৩২ বা ৬৪ বিটে প্রকাশ করা যায় (কমপক্ষে -2^29 থেকে 2^29 - 1 পর্যন্ত নিশ্চিত)।

মনে রাখবেন, ঋণাত্মক সংখ্যা লেখার সময় অস্পষ্টতা এড়াতে বন্ধনী ব্যবহার করা উচিত।

```haskell
1

(-1)
```

`Float` বাস্তব সংখ্যার সেট বোঝায়, যা কম্পিউটারের নির্ভুলতার মধ্যে সীমিত।
সংখ্যার উপর সংজ্ঞায়িত অপারেশনগুলো সাধারণত এক টাইপ বা অন্য টাইপে কাজ করে, দুইটাতেই নয়।
`Double` হলো ডাবল প্রিসিশনের একটি ফ্লোটিং-পয়েন্ট সংখ্যা।

```haskell
10.5
```

### ইন্টিজার ও ফ্লোটের মধ্যে রূপান্তর

`toFloat` ফাংশন ব্যবহার করে আপনি একটি `Int` বা `Integer` থেকে `Float`-এ রূপান্তর করতে পারেন।

```haskell
toFloat 1
-- -> 1.0
```

এছাড়া `fromIntegral` আছে, যা যেকোনো সংখ্যা টাইপকে প্রয়োজন অনুযায়ী অনুমিত সংখ্যা টাইপে রূপান্তর করে।

```haskell
fromIntegral 1
-- -> 1.0
```

একটি `Float` থেকে `Int`-এ রূপান্তর করতে আপনি [`round`][round], [`floor`][floor] বা [`ceiling`][ceiling] ফাংশন ব্যবহার করতে পারেন।
`round` ফাংশন নিকটতম ইন্টিজারে নিয়ে যায়, `floor` নিচের দিকে নামায়, আর `ceiling` উপরের দিকে ওঠায়।

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### গাণিতিক অপারেটর

সংখ্যাসূচক টাইপগুলোর উপর আপনি [মৌলিক গাণিতিক অপারেটরগুলো][math] ব্যবহার করতে পারেন।
অপারেটরগুলো হলো `+`, `-`, `*`, `/` ও `%`।
এই অপারেটরগুলো ব্যবহার করার সময় সংখ্যাগুলোর টাইপ মিলতে হবে।
`fromIntegral` ফাংশনটি রূপান্তর করে টাইপগুলো মিলিয়ে দেবে।

#### যোগ, বিয়োগ ও গুণ

`+` অপারেটর যোগের জন্য, `-` অপারেটর বিয়োগের জন্য আর `*` অপারেটর গুণের জন্য ব্যবহৃত হয়।

| অপারেটর | উদাহরণ         |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### ভাগ

ভাগ সংখ্যাকে ভাগ করতে ব্যবহৃত হয়।
`/` অপারেটরটি ভাগের জন্য ব্যবহৃত হয়।
ফলাফল সবসময় একটি ফ্লোট হবে।

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
কিছু প্রোগ্রামিং ভাষায় শূন্য দিয়ে ভাগ করলে ফলাফল একটি এরর হয়।

Haskell-এ শূন্য দিয়ে ভাগ করলে ফলাফল হয় `Infinity` বা `-Infinity`।
একমাত্র ব্যতিক্রম শূন্যকে শূন্য দিয়ে ভাগ করা, যার ফলাফল `NaN` (Not a Number)।

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### ইন্টিজার ভাগ

ইন্টিজার ভাগ পূর্ণসংখ্যাকে ভাগ করে ফলাফলের পূর্ণ অংশ পাওয়ার জন্য ব্যবহৃত হয়।
Haskell-এ ইন্টিজার ভাগের দুটি ফাংশন আছে, যেগুলো ফলাফল ঋণাত্মক হলে রাউন্ড করার ধরনে আলাদা:

- `div` নিচের দিকে, ঋণাত্মক অসীমের দিকে রাউন্ড করে।
- `quot` শূন্যের দিকে রাউন্ড করে।

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
ইন্টিজার ভাগে শূন্য দিয়ে ভাগ করলে একটি Exception হয়।
এটি সাধারণ ভাগের থেকে আলাদা।
~~~~

#### ভাগশেষ

ইন্টিজার ভাগের ভাগশেষ `mod` বা `rem` দিয়ে পাওয়া যায়।
কোনো একটি সংখ্যা ঋণাত্মক হলে ফলাফলের চিহ্নে এরা আলাদা:

- `mod` `div`-এর সাথে যায়, আর এর ফলাফলের চিহ্ন ভাজকের চিহ্নের মতোই হয়।
- `rem` `quot`-এর সাথে যায়, আর এর ফলাফলের চিহ্ন ভাজ্যের চিহ্নের মতোই হয়।

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

যেকোনো `x` ও `y`-এর জন্য (যেখানে `y` শূন্য নয়) এই নিয়মগুলো প্রযোজ্য:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
দুই সংখ্যাই ধনাত্মক হলে `div` আর `quot` একই ফলাফল দেয়, `mod` আর `rem`-ও তাই।
সেক্ষেত্রে `quot` ও `rem` কিছুটা বেশি কার্যকর হতে পারে, কারণ ঋণাত্মক সংখ্যা সামলাতে `div` আর `mod`-এর বাড়তি ধাপ লাগে।
~~~~

~~~~exercism/caution
`mod` বা `rem` ব্যবহার করে শূন্য দিয়ে ভাগ করলে একটি Exception হয়।
এটি সাধারণ ভাগের থেকে আলাদা।

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### সূচক নির্ণয়

Haskell-এ "পাওয়ারে উন্নীত করার" তিনটি অপারেটর আছে, যেগুলো আলাদাভাবে কাজ করে এবং আলাদা ধরনের আর্গুমেন্ট নেয়।

- `**` দুটি **ফ্লোটিং-পয়েন্ট সংখ্যা** নেয় এবং লগারিদম ব্যবহার করে পাওয়ার হিসাব করে।
- `^^` একটি **ফ্লোটিং-পয়েন্ট** নেয় এবং সেটিকে ধনাত্মক বা ঋণাত্মক **ইন্টিজার** পাওয়ারে উন্নীত করে।
- `^` **যেকোনো সংখ্যাসূচক টাইপ** নেয় এবং সেটিকে **ধনাত্মক ইন্টিজার** পাওয়ারে উন্নীত করে।

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### অগ্রাধিকার ও বন্ধনী

Haskell বন্ধনী(`()`) ব্যবহারের সুযোগ দেয়, যা দিয়ে এক্সপ্রেশন দলবদ্ধ করা যায়।
অপারেশনের ক্রম বদলাতে চাইলে এটি কাজে লাগে।

একাধিক গাণিতিক অপারেটর ব্যবহার করলে অপারেশনের ক্রম গণিতের মতোই হয়, যাকে [PEMDAS][pemdas] বলা হয়।
এটি বন্ধনী(`()`), সূচক(`**`), গুণ(`*`) ও ভাগ(`/`), এবং যোগ(`+`) ও বিয়োগ(`-`) এই ক্রম অনুসরণ করে।

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
