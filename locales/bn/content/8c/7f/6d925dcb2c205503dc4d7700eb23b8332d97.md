# পরিচিতি

`call` ([`kernel`][kernel]-এ) একটি কোয়োটেশন রান করে। যখন কোয়োটেশনের স্ট্যাক ইফেক্ট অনুমান করা যায় না, সাধারণত তখনই যখন কোয়োটেশনটি অন্য কোথাও থেকে আসে, `call`-এর উপর ইফেক্টটি স্পষ্টভাবে ঘোষণা করতে হয়:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

কোয়োটেশন যেহেতু মান, তাই একটি অ্যারেতে সংখ্যা ও কোয়োটেশনের মিশ্রণ থাকতে পারে। ফলে "একটি প্রোগ্রাম" হয়ে দাঁড়ায় আরেকটি সিকোয়েন্স মাত্র:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
