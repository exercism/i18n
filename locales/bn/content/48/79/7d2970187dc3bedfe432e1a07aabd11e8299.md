# নির্দেশনা

এই অনুশীলনীতে আপনি হাই স্কুলের প্রেমিক-প্রেমিকাদের সোশ্যাল মিডিয়ায় তাদের ভালোবাসা প্রকাশ করতে সাহায্য করবেন, তাদের নামের আদ্যক্ষর দিয়ে একটি ASCII বক্স তৈরি করে:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. নামের প্রথম অক্ষর বের করুন

`HighSchoolSweetheart.first_letter/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি নাম নেবে এবং তার প্রথম অক্ষর রিটার্ন করবে। নাম থেকে অপ্রয়োজনীয় হোয়াইটস্পেস পরিষ্কার করবে।

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. প্রথম অক্ষরটিকে আদ্যক্ষর হিসেবে ফরম্যাট করুন

`HighSchoolSweetheart.initial/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি নাম নেবে এবং তার প্রথম অক্ষর বড় হাতের অক্ষরে, শেষে একটি বিন্দু দিয়ে রিটার্ন করবে। আগের ধাপে আপনি যে `HighSchoolSweetheart.first_letter/1` ডিফাইন করেছিলেন, সেটি আবার ব্যবহার করতে ভুলবেন না।

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. পূর্ণ নামকে প্রথম নাম ও শেষ নামে ভাগ করুন

`HighSchoolSweetheart.initials/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি পূর্ণ নাম নেবে, যেখানে প্রথম নাম ও শেষ নাম একটি স্পেস দিয়ে আলাদা করা, এবং আদ্যক্ষরগুলো রিটার্ন করবে। আগের ধাপে আপনি যে `HighSchoolSweetheart.initial/1` ডিফাইন করেছিলেন, সেটি আবার ব্যবহার করতে ভুলবেন না।

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. আদ্যক্ষরগুলো ASCII বক্সের ভেতরে বসান

`HighSchoolSweetheart.pair/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি পূর্ণ নাম নেবে এবং আদ্যক্ষরগুলো একটি ASCII বক্সের ভেতরে রিটার্ন করবে। বক্সটি আপনাকে নিজে আঁকতে হবে না, কোড কমেন্টে দেওয়া বক্সটি ব্যবহার করুন। আগের ধাপে আপনি যে `HighSchoolSweetheart.initials/1` ডিফাইন করেছিলেন, সেটি আবার ব্যবহার করতে ভুলবেন না।

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
