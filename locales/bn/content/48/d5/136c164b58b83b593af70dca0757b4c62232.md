# টেস্ট

ডিপেন্ডেন্সি ইনস্টল করুন।

```sh
dart pub get
```

টেস্ট চালান।

```sh
dart test
```

প্রতিটি টেস্টের আরও বিস্তারিত আউটপুটের জন্য expanded রিপোর্টার ব্যবহার করুন।

```sh
dart test -r expanded
```

বেশিরভাগ অনুশীলনীতে একাধিক টেস্ট থাকে, আর প্রথমটি ছাড়া বাকি সব ডিফল্টভাবে স্কিপ করা থাকে।
একটি একটি করে টেস্ট করার জন্য, প্রতিটি টেস্টে `skip: true`-এর জায়গায় `skip: false` করে নিন।

অথবা, ফাইলটি এডিট না করেই একসাথে সব টেস্ট চালান।

```sh
dart test --run-skipped
```

সাবমিট করার সময় অনলাইন টেস্ট রানার স্কিপ করা টেস্টগুলোসহ সব টেস্ট চালায়।
