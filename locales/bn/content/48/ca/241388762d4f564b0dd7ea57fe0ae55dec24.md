# ভূমিকা

ABAP সংখ্যা দিয়ে হিসাব করার জন্য অ্যারিথমেটিক অপারেটর সমর্থন করে।

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

মূল অপারেটরগুলো হলো:

- `+` যোগ করার জন্য।
- `-` বিয়োগ করার জন্য।
- `*` গুণ করার জন্য।
- `/` ভাগ করার জন্য।
- `MOD` পূর্ণসংখ্যা ভাগের ভাগশেষের জন্য।

```abap
DATA full_months TYPE i.
full_months = floor( num_days / 22 ).

DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP যোগ ও বিয়োগের আগে গুণ ও ভাগ হিসাব করে। কাঙ্ক্ষিত ক্রমটি স্পষ্ট করতে বন্ধনী ব্যবহার করা যায়।

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
