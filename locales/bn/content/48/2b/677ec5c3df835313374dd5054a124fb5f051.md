# বেসিকস

এই বিষয়গুলো সম্পর্কে আরও বিস্তারিত জানতে [কনসেপ্ট পেজ][exercism-concept] দেখুন।

## সাধারণ সিনট্যাক্স

PHP কোড শুরু হয় `<?php` ওপেনিং ট্যাগ দিয়ে।
নির্দেশ আলাদা করার জন্য প্রতিটি স্টেটমেন্ট অবশ্যই একটি `;` দিয়ে শেষ হতে হবে।

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

সহজে পড়ার জন্য সব কোড উদাহরণে PHP ওপেনিং ট্যাগ `<?php` বাদ দেওয়া হয়েছে।

## কমেন্ট

একক লাইনের কমেন্ট শুরু হয় `//` দিয়ে।

```php
// Single line comment
```

## মান ও ভ্যারিয়েবল

অ্যাসাইনমেন্ট `=` অপারেটর ব্যবহার করে একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করা যায়।
ভ্যারিয়েবলের নাম অবশ্যই ডলার `$` চিহ্ন দিয়ে শুরু হতে হবে এবং [নামকরণের নিয়মাবলি][exercism-concept-naming-conventions] অনুসরণ করতে হবে।

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## ফাংশন ও মেথড

ফাংশনে মান ও ভ্যারিয়েবল পাস করা যায়।
ফাংশনের আর্গুমেন্ট হলো নতুন ভ্যারিয়েবল, যেগুলোতে পাঠানো মান ধরে রাখা হয়।
`return` কিওয়ার্ড ব্যবহার করে ফাংশন যেকোনো মান রিটার্ন করতে পারে।

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

ক্লাসের ভেতরের ফাংশন এবং তাদের ইনস্ট্যান্সগুলোকে মেথড বলা হয়।
একটি মেথড কল করতে হলে নামের আগে ইনস্ট্যান্স ও `->` বসে।
মেথডগুলোর কাছে বিশেষ ভ্যারিয়েবল `$this`-এর অ্যাক্সেস থাকে, যা বর্তমান ইনস্ট্যান্সকে বোঝায়।

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
