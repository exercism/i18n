# পরিচিতি

[`Rational numbers`][rational] হলো এমন ভগ্নাংশ, যার লব একটি ইন্টিজার আর হরও একটি ইন্টিজার।

উদাহরণস্বরূপ, আনুমানিক `Float64` মান `0.6666...`-এর বদলে আমরা `2//3`-কে একটি নির্ভুল ভগ্নাংশ হিসেবে সংরক্ষণ করতে পারি।

এর সুবিধা হলো, (ইন্টিজার ওভারফ্লো-এর মতো চরম পরিস্থিতি ছাড়া) একটি র‍্যাশনাল সংখ্যা নির্ভুল থাকে, ফলে ফ্লোটিং-পয়েন্ট সংখ্যায় প্রায়ই অনিবার্য যে রাউন্ডিং এররগুলো হয়, তা এড়ানো যায়।

আরও কিছু বিস্তারিত তথ্য আছে Julia-র [ম্যানুয়াল পেজে][julia-rational]।

র‍্যাশনাল সংখ্যা হলো সংখ্যার একটি বেশ সরল টাইপ, আর এগুলো আপনার প্রত্যাশা অনুযায়ীই কাজ করে।
যেহেতু Julia-র শুরুর দিকের সংস্করণগুলো থেকেই এগুলো একটি স্ট্যান্ডার্ড টাইপ, তাই বেশিরভাগ ফাংশনই ইন্টিজার আর ফ্লোটের মতোই এগুলোকে ইনপুট হিসেবে গ্রহণ করে।

## র‍্যাশনাল সংখ্যা তৈরি করা

তৈরি করা তো দুইটি ইন্টিজারের মাঝে `//` ব্যবহার করার মতোই সহজ।

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

কমন গুণনীয়কগুলো স্বয়ংক্রিয়ভাবে বাদ পড়ে যায়, ফলে ভগ্নাংশটি তার ["লঘিষ্ঠ আকারে"][lowest-terms] রূপান্তরিত হয়: অর্থাৎ ক্ষুদ্রতম সেই ইন্টিজারগুলো, যেগুলো ভগ্নাংশটিকে নির্ভুলভাবে প্রকাশ করে এবং যার হর ঋণাত্মক নয়।

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

অসীম ফলাফল গ্রহণযোগ্য, তবে [`NaN`][NaN] নয়।

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## র‍্যাশনাল সংখ্যার পাটিগণিত

স্বাভাবিক [`arithmetic operators`][operators] `+ - * / ^ %` র‍্যাশনাল সংখ্যার সাথেও কাজ করে, মূলত অন্য সংখ্যার টাইপগুলোর মতোই।

ইন্টিজার আর অন্য `Rational`-গুলোও এতে যোগ করা যায়, আর ফলাফল হয় `Rational`।
এক্সপ্রেশনে একটি `float` থাকলে আউটপুটও `float` হয়, যার ফলে নির্ভুলতা (সম্ভবত) কমে যেতে পারে।

যদি `float` দরকার হয়, তবে র‍্যাশনাল সংখ্যাটিকে রূপান্তর করতে শুধু `float()` ফাংশনটি ব্যবহার করুন।
দীর্ঘ একটি গণনার পুরোটা জুড়ে নির্ভুলতা বজায় রাখতে র‍্যাশনাল সংখ্যা ব্যবহার করা, আর শেষে সেটিকে ফ্লোটে রূপান্তর করা খুবই স্বাভাবিক।

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

র‍্যাশনাল সংখ্যা আর [কমপ্লেক্স সংখ্যা][complex] একসাথেও ব্যবহার করা যায়।
কমপ্লেক্স সংখ্যা নিয়ে আলোচনা করা হয়েছে [আলাদা একটি ধারণায়][complex-concept]।

## অন্যান্য অপারেশন

Julia-তে র‍্যাশনাল সংখ্যা আসলে শুধুই সংখ্যা।
কম্পাইলার সাধারণত প্রয়োজন অনুযায়ী টাইপ রূপান্তর করে নেয়।

তবে মনে রাখবেন, তুলনা কাজ করে কেবল সেই ভগ্নাংশের জন্য যাদের একটি সসীম দশমিক রূপ আছে:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

কিন্তু অন্যথায়, তুলনার জন্য একটি `Rational`-কে `Float`-এ কাস্ট করতে হবে:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

গাণিতিক ফাংশন র‍্যাশনাল সংখ্যা ইনপুট হিসেবে নেয়, তবে ফলাফল হতে পারে ফ্লোটিং-পয়েন্ট:

```julia-repl
julia> sqrt(9//16)
0.75
```
