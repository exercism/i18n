# পরিচিতি

## অ্যারো ফাংশন

একটি ফাংশন ডিফাইন করার জন্য ফাংশন ডিক্লারেশন আর ফাংশন এক্সপ্রেশনের পাশাপাশি JavaScript-এ আরও একটি অত্যন্ত সংক্ষিপ্ত সিনট্যাক্স রয়েছে।
এই ফাংশনগুলোকে _অ্যারো ফাংশন_ বলা হয়।

এখানে একটি ফাংশন ডিক্লারেশন আর একটি অ্যারো ফাংশনের মধ্যে তুলনা দেওয়া হলো।

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

যদি ফাংশনের বডিতে শুধু একটি রিটার্ন স্টেটমেন্ট থাকে, যেমন উপরের উদাহরণে, তাহলে `{}` আর `return` কিওয়ার্ড বাদ দেওয়া যায়।
যদি শুধু একটি প্যারামিটার থাকে, তাহলে বন্ধনী `()`-ও বাদ দেওয়া যায়।

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

ফাংশন কলে সরাসরি ছোট কলব্যাক ফাংশন ডিফাইন করতে অ্যারো ফাংশন প্রায়ই ব্যবহৃত হয়।

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## অ্যারে বিশ্লেষণ

[অ্যারে][arrays-concept]-এ অ্যারেটির বিষয়বস্তু বিশ্লেষণ করার জন্য বিল্ট-ইন মেথড থাকে।
এই মেথডগুলোর বেশিরভাগই একটি ফাংশন আর্গুমেন্ট হিসেবে নেয়, যেটি ট্রু বা ফলস রিটার্ন করে।
এমন একটি ফাংশনকে [`predicate`][predicate_in_programming] বলা হয়।

বিল্ট-ইন মেথডগুলো _একটি `for` লুপ_ বা বিল্ট-ইন `forEach` মেথডের বদলে ব্যবহার করার জন্য বোঝানো হয়েছে:

`for` লুপ দিয়ে বিশ্লেষণের উদাহরণ:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

একটি বিল্ট-ইন মেথড দিয়ে বিশ্লেষণের উদাহরণ:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

অ্যারে বিশ্লেষণ করার জন্য উপলব্ধ আরও কিছু সহায়ক বিল্ট-ইন মেথড নিচে দেখানো হয়েছে।
অ্যারে মেথডের সম্পূর্ণ তালিকার জন্য [MDN][mdn-array-methods] দেখুন।

### `includes`

`includes(value)` মেথড নির্ধারণ করে অ্যারেতে কোনো নির্দিষ্ট মান আছে কি না।
মানটি থাকলে এটি `true` রিটার্ন করে, নাহলে `false`।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

`every(predicate)` মেথড একটি ফাংশন নেয়, যেটি _একটি প্রেডিকেট_।
এটি পরীক্ষা করে অ্যারের সব এলিমেন্ট প্রেডিকেটে পাঠানো হলে `true` রিটার্ন করে কি না।
অন্য কথায়: মেথডটি পরীক্ষা করে যে এর সব এলিমেন্ট ফাংশন কলে পাস করা পরীক্ষায় উত্তীর্ণ হয়।
প্রতিটি এলিমেন্ট প্রেডিকেট পরীক্ষায় উত্তীর্ণ হলে এটি `true` রিটার্ন করে, নাহলে `false`।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

`some(predicate)` মেথড `every` মেথডের মতোই, তবে অ্যারের অন্তত একটি আইটেম _প্রেডিকেট_ পরীক্ষায় উত্তীর্ণ হলে `true` রিটার্ন করে।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

`find(predicate)` মেথড অ্যারের যে এলিমেন্টটি `predicate` পরীক্ষায় উত্তীর্ণ হয়, তার প্রথমটির মান রিটার্ন করে।
যেখানে `some()` উত্তীর্ণ হলে `true` রিটার্ন করে, সেখানে `find()` অ্যারের প্রকৃত মানটি রিটার্ন করে।
অ্যারের কোনো এলিমেন্টই _প্রেডিকেট_ পরীক্ষায় উত্তীর্ণ না হলে মেথডটি `undefined` রিটার্ন করে।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

`findIndex(predicate)` মেথড `find()` মেথডের মতোই, তবে _প্রেডিকেট_ পরীক্ষায় উত্তীর্ণ এলিমেন্টের `value`-এর বদলে তার (প্রথম) _ইনডেক্স_ রিটার্ন করে।
অ্যারের কোনো এলিমেন্টই _প্রেডিকেট_ পরীক্ষায় উত্তীর্ণ না হলে মেথডটি `-1` রিটার্ন করে।

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
