# নির্দেশনা

আপনি কেপ ক্রোজিয়ার বাতিঘরের রক্ষক। লণ্ঠন কক্ষ থেকে আপনি পাশ দিয়ে যাওয়া প্রতিটি জাহাজ লিপিবদ্ধ করেন, যার প্রতিটির পরিচয় একটি অনন্য কলসাইন। এছাড়া উপকূলের এদিক-ওদিকের অন্য বাতিঘরগুলোর সাথে সিগন্যাল রিলেও সমন্বয় করেন।

## 1. একটি নতুন লগবুক

`empty-log` ডিফাইন করুন, যা একটি নতুন খালি হ্যাশ-সেট রিটার্ন করে, কলসাইন জমা করার জন্য প্রস্তুত।

```factor
empty-log .
! => HS{ }
```

## 2. একটি দেখা লিপিবদ্ধ করুন

`sight` ডিফাইন করুন, যা একটি লগবুক ও একটি কলসাইন নেয় এবং দেখাটি জায়গাতেই লিপিবদ্ধ করে। কিছুই রিটার্ন করে না।

```factor
empty-log dup "NS-1024" sight .
! => HS{ "NS-1024" }
```

## 3. এটিকে কি আগে দেখেছি?

`seen?` ডিফাইন করুন, যা একটি লগবুক ও একটি কলসাইন নেয় এবং কলসাইনটি লিপিবদ্ধ করা থাকলে `t`, অন্যথায় `f` রিটার্ন করে।

```factor
HS{ "NS-1024" "WB-203" } "NS-1024" seen? .   ! => t
HS{ "NS-1024" "WB-203" } "X-99"    seen? .   ! => f
```

## 4. একটি দেখা ভুলে যান

`forget-sighting` ডিফাইন করুন, যা একটি লগবুক ও একটি কলসাইন নেয় এবং লগ থেকে কলসাইনটি জায়গাতেই মুছে ফেলে। কিছুই রিটার্ন করে না। কলসাইনটি সেখানে না থাকলে কিছুই করবেন না।

```factor
HS{ "NS-1024" "WB-203" } clone dup "WB-203" forget-sighting .
! => HS{ "NS-1024" }
```

## 5. কতটি আলাদা জাহাজ?

`unique-count` ডিফাইন করুন, যা লগে থাকা আলাদা কলসাইনের সংখ্যা রিটার্ন করে।

```factor
HS{ "NS-1024" "WB-203" "AC-77" } unique-count .   ! => 3
empty-log unique-count .                          ! => 0
```

## 6. পৌঁছানোযোগ্য বাতিঘর

কোস্ট গার্ড একটি `relay-map` রক্ষণাবেক্ষণ করে: একটি হ্যাশটেবিল, যার কী (key) থাকে বাতিঘরের নাম, আর প্রতিটি মান হলো সেই বাতিঘরটি সরাসরি যে বাতিঘরগুলোতে রিলে পাঠাতে পারে তাদের একটি অ্যারে।

`reachable` ডিফাইন করুন, যা একটি `start` বাতিঘর ও একটি `relay-map` নেয়, এবং বারবার রিলের মাধ্যমে `start` থেকে যে প্রতিটি বাতিঘরে পৌঁছানো যায় তার একটি হ্যাশ-সেট রিটার্ন করে (`start` নিজেও ধরে)।

```factor
H{
    { "Crozier"  { "Beacon"  "Hadley"  } }
    { "Beacon"   { "Crozier" "Spiral"  } }
    { "Hadley"   { "Crozier"           } }
    { "Spiral"   { "Beacon"  "Outpost" } }
    { "Outpost"  { "Spiral"            } }
    { "Far-Isle" { "Lonely"            } }
    { "Lonely"   { "Far-Isle"          } }
}
"Crozier" swap reachable .
! => HS{ "Crozier" "Beacon" "Hadley" "Spiral" "Outpost" }
```

`Far-Isle`/`Lonely` জোড়াটি নিজেই একটি আলাদা কানেক্টেড কম্পোনেন্ট, তাই কোনোটিই ফলাফলে আসে না।
