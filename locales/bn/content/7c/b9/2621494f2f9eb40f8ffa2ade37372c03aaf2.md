# নির্দেশাবলি

Lisp এলিয়েন Leslie-র কিছু কেনাকাটা করতে হবে। একটি শপিং লিস্ট থাকা খুবই জরুরি। সেখানে জিনিস যোগ করতে হয়, আবার জিনিস বাদও দিতে হয়।

অবশ্যই একটি Lisp এলিয়েনের জন্য সাধারণ কলম-কাগজে চলবে না। "List" তো "Lisp" শব্দের প্রায় পুরোটাই জুড়ে আছে!

কেনাকাটার হিসাব রাখতে সাহায্য করার জন্য কিছু ফাংশন লিখতে হবে।

আপনি কি Leslie-কে শপিং লিস্টের হিসাব রাখতে সাহায্য করতে পারেন?

## 1. নতুন একটি লিস্ট তৈরি করা

প্রথমেই Leslie-কে একটি খালি লিস্ট তৈরি করতে হবে। সেজন্য `new-list` নামের একটি ফাংশন একেবারে মানানসই হবে।

```lisp
(new-list) ; => ()
```

ওরে বাবা... Leslie-র মাথায় আগে থেকেই কয়েকটা জিনিস আছে, তাই এমন একটি ফাংশন দরকার যা তিনটি জিনিস নেয় (ভাগ্যক্রমে Leslie শুধু তিনটি জিনিসেরই একটি লিস্ট বানায়। একটাও কম নয়, একটাও বেশি নয়!) এবং সেই জিনিসগুলো দিয়ে একটি নতুন শপিং লিস্ট তৈরি করে। একটি ফাংশন লিখুন, `list-of-things`, যা তিনটি জিনিস নেয় এবং সেগুলোর একটি লিস্ট রিটার্ন করে।

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. লিস্টে জিনিস যোগ করা।

দোকানে যাওয়ার আগে Leslie খাবার রাখার ঘরে দেখে নেয় কী কী দরকার। আপনি `add-to-list` ফাংশনটি লিখে Leslie-কে সাহায্য করুন, যা একটি লিস্টের শুরুতে একটি জিনিস যোগ করে।

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. লিস্টে এরপরের জিনিস কোনটি?

কেনাকাটার সময় Leslie জানতে চায় এরপর কী কী খুঁজতে হবে। Leslie আরও ভালোবাসে লিস্টে সামনের দিকে উঁকি দিয়ে দ্বিতীয়, তৃতীয়, এমনকি ২৩তম জিনিসটি (Leslie-র লাকি নম্বর) দেখে নিতে।

- `first-thing`-এর মান হবে লিস্টের প্রথম জিনিস
- `second-thing`-এর মান হবে দ্বিতীয় জিনিস
- `third-thing`-এর মান হবে তৃতীয় জিনিস
- `twenty-third-thing`-এর মান হবে তেইশতম জিনিস

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. লিস্ট থেকে একটি জিনিস সরিয়ে ফেলা

Leslie চায় লিস্টের প্রথম জিনিসটি খুঁজে বের করে তা তাক থেকে সরিয়ে ফেলতে। আপনি `remove-first-item` ফাংশনটি লিখে Leslie-কে সাহায্য করুন, যা ইনপুট লিস্টের প্রথম জিনিসটি ছাড়া বাকি সবকিছু নিয়ে একটি লিস্ট রিটার্ন করে।

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. ছোট লিস্ট থেকে বড় লিস্ট

Leslie বুঝতে পারল, ভুল করে একটি নয়, দুটি শপিং লিস্ট তৈরি হয়ে গেছে! একটি ফাংশন লিখুন, `list-append`, যা প্রথম লিস্টের এলিমেন্টগুলোর পর দ্বিতীয় লিস্টের এলিমেন্টগুলো নিয়ে একটি লিস্ট রিটার্ন করে।

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. আর কত লম্বা?

এই কেনাকাটার সফরটা বেশ সময় নেবে ভেবে Leslie চিন্তিত হয়ে পড়ছে। লিস্টে আসলে কতগুলো জিনিস আছে? `just-how-long` নামের একটি ফাংশন লিখুন, যা Leslie-কে জানাবে তার লিস্টটি কত লম্বা।

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
