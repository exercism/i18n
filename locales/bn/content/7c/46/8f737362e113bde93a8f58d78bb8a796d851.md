# পরিচিতি

`var`-এর পরিবর্তে `final` কিওয়ার্ড দিয়ে ডিক্লেয়ার করা ভ্যারিয়েবলে মান কেবল একবারই অ্যাসাইন করা যায়।

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
