# পরিচিতি

C# একটি স্ট্যাটিক-টাইপড ভাষা, অর্থাৎ কম্পাইল-টাইমে সবকিছুরই একটি টাইপ থাকে। একটি [ভ্যারিয়েবল][variable]-এর জন্য নাম বাছাই করাকে ভ্যারিয়েবল ডিফাইন করা বলা হয়। ভ্যারিয়েবল ডিফাইন হয়ে গেলে তার মান সেট বা আপডেট করাকে ভ্যারিয়েবল অ্যাসাইনমেন্ট বলা হয়। ভ্যারিয়েবল ডিফাইন করা যায় হয় সরাসরি তার টাইপ উল্লেখ করে, নয়তো [`var` কিওয়ার্ড][var] ব্যবহার করে, যাতে C# কম্পাইলার অ্যাসাইন করা মান দেখে তার টাইপ অনুমান করতে পারে। `var` ব্যবহার করাকে _টাইপ ইনফারেন্স_ বলা হয়।

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

ভ্যারিয়েবলের মান [`=` অপারেটর][assignment] দিয়ে অ্যাসাইন ও আপডেট করা যায়। একবার ডিফাইন হয়ে গেলে ভ্যারিয়েবলের টাইপ আর কখনোই বদলানো যায় না।

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# একটি অবজেক্ট-ওরিয়েন্টেড ভাষা এবং এতে সব [ফাংশন][function]-ই একটি _ক্লাস_-এর ভেতরে ডিফাইন করতে হয়, আর ক্লাস ডিফাইন করা হয় [`class` কিওয়ার্ড][classes] দিয়ে। অবজেক্ট (বা _ইনস্ট্যান্স_) তৈরি করা হয় `new` কিওয়ার্ড ব্যবহার করে।

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

ক্লাসের ভেতরের ফাংশনকে _মেথড_ বলা হয়। প্রতিটি [মেথড][methods]-এ শূন্য বা তার বেশি প্যারামিটার থাকতে পারে। সব প্যারামিটারেই টাইপ স্পষ্টভাবে লিখতে হয়; প্যারামিটারের জন্য কোনো টাইপ ইনফারেন্স নেই। একইভাবে রিটার্ন টাইপও স্পষ্ট করে দিতে হয়। মেথড থেকে মান রিটার্ন করা হয় [`return` কিওয়ার্ড][return] দিয়ে। অন্য ফাইলের কোড যাতে মেথডটি কল করতে পারে, সেজন্য `public` অ্যাক্সেস মডিফায়ার যোগ করতে হয়।

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

মেথড কল করা হয় ইনস্ট্যান্সের উপর ডট (`.`) সিনট্যাক্স ব্যবহার করে: কোন মেথডটি কল করতে হবে তার নাম দিতে হয় এবং মেথডের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করতে হয়। চাইলে আর্গুমেন্টে সংশ্লিষ্ট প্যারামিটারের নামও উল্লেখ করা যায়।

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

যে মেথড কল করছে তার ক্লাসেই যদি কল করার মেথডটি ডিফাইন করা থাকে, তাহলে ক্লাসের নাম বাদ দেওয়া যায়।

কোনো মেথড যদি অবজেক্টের কোনো _স্টেট_ ব্যবহার না করে, তাহলে `static` মডিফায়ার দিয়ে মেথডটিকে _স্ট্যাটিক_ করা যায়। স্ট্যাটিক মেথডও ডট (`.`) সিনট্যাক্স দিয়েই কল করা হয়, তবে ক্লাসের ইনস্ট্যান্সের বদলে ক্লাসের উপরই কল করা হয়।

কোনো ক্লাসে শুধু স্ট্যাটিক মেথড থাকলে সেটিকেও `static` মডিফায়ার দিয়ে স্ট্যাটিক করা যায়। এতে ক্লাসটির উদ্দেশ্য স্পষ্ট হয়।

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

C#-এ স্কোপ নির্ধারিত হয় `{` আর `}` অক্ষর দুটির মধ্যে।

C# দুই ধরনের [কমেন্ট][comments] সমর্থন করে। এক লাইনের কমেন্টের আগে `//` বসে, আর বহু লাইনের কমেন্ট `/*` ও `*/`-এর মধ্যে লেখা হয়।

ইন্টিজার মান লেখা হয় এক বা একাধিক (পরপর) অঙ্ক দিয়ে এবং এগুলো [ডিফল্ট গাণিতিক অপারেটর][operators] সমর্থন করে।

ভ্যারিয়েবলের নামের ক্ষেত্রে [কিছু নিয়ম মানতে হয়][identifier-names], যেমন নাম শুরু হতে হবে কোনো অক্ষর বা আন্ডারস্কোর দিয়ে, এবং [C#-এর নামকরণের রীতিও মেনে চলা উচিত][naming-guidelines]। ভ্যারিয়েবলের নাম কোনো সংরক্ষিত [C# কিওয়ার্ড][csharp-keywords]-এর সাথে সংঘর্ষ করলে `@` দিয়ে সেটি এস্কেপ করতে হয়। এই ধরনের নোটেশন ব্যবহার করা সুপারিশ করা হয় না, তবে ব্যতিক্রমী ক্ষেত্রে এটি দেখা যায়, যেমন: `var @this`, `var @class` বা `var @var`।

C#-এর মতো C-পরিবারের ভাষায় এমন কয়েকটি ধারণা এতটাই মৌলিক যে সেগুলো প্রায় যেকোনো গুরুত্বপূর্ণ কোডে স্বাভাবিকভাবেই দেখা যায়। এগুলো হলো [মিউটেশন][mutation] আর [স্কোপ][scope]। মিউটেশন হলো এই ধারণা যে প্রোগ্রাম চলার সময় ভ্যারিয়েবলের মান বদলাতে পারে। স্কোপ হলো এই ধারণা যে কোনো নামের (প্রোগ্রাম উপাদানের নামের) সাথে যুক্ত মান কেবল সেই কোড "এলাকার" মধ্যেই পাওয়া যায় যেখানে সেটি ডিফাইন করা হয়েছে। C#-এ প্রধান কোড এলাকা হলো _ক্লাস/স্ট্রাক্ট_ ও _ফাংশন_ (সাধারণত মেথড), তবে এর মধ্যে লুপ ও অন্যান্য কাঠামোর বডিও পড়তে পারে।
