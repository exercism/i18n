# রক্ষণাবেক্ষণকারীদের জন্য

## টেস্ট তৈরি: `bin/generate_tests.py`

প্রতিটি অনুশীলনীর `.meta/template.j2`-এ সংরক্ষিত একটি Jinja টেমপ্লেট ব্যবহার করে [exercism/problem-specifications](https://github.com/exercism/problem-specifications)-এর ক্যানোনিকাল ডেটা থেকে টেস্ট ফাইল তৈরি করা হয়।

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

স্ক্রিপ্টটি problem-specifications পড়ে configlet-এর ক্যাশ (`~/.cache/exercism/configlet/problem-specifications`, যা `bin/configlet sync` পূরণ করে) থেকে, অথবা `problem-specifications` নামের একটি প্যারেন্ট ডিরেক্টরি থেকে।
শুধু `.meta/tests.toml`-এ অন্তর্ভুক্ত কেসগুলোই জেনারেট হয়।

Fortran স্ট্রিং লিটারেলে `\n` আর `\t`-এর মতো এস্কেপ থাকতে পারে না।
`escape_quote_whitespace` টেমপ্লেট ফিল্টার এগুলোকে `" // NEWLINE // "`, `" // TAB // "` আর `" // CARRIAGE_RETURN // "` হিসেবে পুনর্লিখন করে, তাই টেমপ্লেটকে ওই কনস্ট্যান্টগুলো ডিক্লেয়ার করতে হয় (দেখুন `exercises/practice/bob/.meta/template.j2`)।

### পূর্বশর্ত

- কার্যকর CMake ও Fortran কম্পাইলার
- Python 3.12+ আর `jinja2` সহ
- git

### নতুন একটি অনুশীলনী যোগ করার কাজের ধারা

উদাহরণ হিসেবে `bob` ব্যবহার করে:

- নতুন একটি ব্রাঞ্চ তৈরি করুন, যেমন `git checkout -b exercise-bob`
- `bin/add-exercise bob` রান করুন (`jq` আর `curl` দরকার)। এটি:
  - configlet নামিয়ে আনে এবং `configlet create` রান করে, যা অনুশীলনীটি `config.json`-এ যোগ করে এবং problem-specifications থেকে এর ডকুমেন্টেশন, মেটাডেটা ও `tests.toml` সিংক করে
  - `bin/reorder-exercises` দিয়ে `config.json` সাজায়
  - `exercises/shared/CMakeLists.txt` অনুশীলনীর ডিরেক্টরিতে কপি করে
  - একটি স্টাব সমাধান, একটি স্টাব `.meta/example.f90` আর একটি শুরুর `.meta/template.j2` লিখে (যা `exercises/shared/template.j2` থেকে নেওয়া)

  আপনি `-a <username>` না দিলে এটি আপনার GitHub ইউজারনেম জানতে চায়, আর `-d <difficulty>` না দিলে ডিফিকাল্টি ১ সেট করে।

- `.meta/template.j2` সম্পাদনা করুন যাতে প্রতিটি কেস সঠিক ইনপুট দিয়ে সঠিক ফাংশন কল করে, তারপর টেস্ট জেনারেট করুন:

  ```bash
  bin/generate_tests.py bob
  ```

- `.meta/example.f90`-এ একটি কাজ করা সমাধান লিখুন। শিক্ষার্থীকে শুরু করতে সাহায্য করতে, টেস্টগুলো যে ফাংশন বা সাবরুটিনগুলো কল করে সেগুলোর একটি কাঠামো দিয়ে শিক্ষার্থীর ফাইলটি (যেমন `bob.f90`) প্রতিস্থাপন করুন
- রিপোজিটরির রুট থেকে সম্পূর্ণ বিল্ড রান করে নিশ্চিত করুন সব টেস্ট পাস করে:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- `bin/reorder-exercises` আর `bin/configlet lint` রান করুন
- সবকিছু পাস করলে আপনার পরিবর্তনগুলো নিয়ে একটি পুল রিকোয়েস্ট খুলুন

### `CMakeLists.txt` পরিবর্তন করা

cmake ফাইল পরিবর্তন করার সময় `exercises/shared/`-এর মাস্টার কপিটি আপডেট করুন এবং `bin/update-cmake-files` দিয়ে এটি সব অনুশীলনীর ডিরেক্টরিতে কপি করুন।
