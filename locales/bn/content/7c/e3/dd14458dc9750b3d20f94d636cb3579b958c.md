# পরিচিতি

স্ট্যাটিক এক্সটেনশন বিদ্যমান টাইপগুলোর সোর্স না বদলেই সেগুলোকে আপাতভাবে এক্সটেন্ড করার সুযোগ দেয়। এটি সম্ভব হয় `using` স্টেটমেন্টের মাধ্যমে। স্ট্যাটিক এক্সটেনশন একটি শক্তিশালী টুল, যা টাইপগুলোকে আসলে পরিবর্তন না করেই সেগুলোতে নতুন কিছু যোগ করতে দেয়।

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
