# নির্দেশনা

এই অনুশীলনীতে, আপনি আপনার প্রিয় রান্নার বই থেকে আপনার চমৎকার লাসানিয়া প্রস্তুত ও রান্নার সাথে সম্পর্কিত আরও কিছু কোড লিখবেন।

আপনার পাঁচটি কাজ আছে।
প্রথমটি রান্নার নিজের সাথে সম্পর্কিত, বাকি চারটি নিখুঁত প্রস্তুতি নিয়ে।

## 1. লাসানিয়া তৈরি হয়েছে কি না তা নির্ধারণ করুন

ওভেনে লাসানিয়া থাকলে, আপনি জানতে চান এটি এখনই বের করা যাবে কি না।
ওভেনে লাসানিয়া যাতে পুড়ে না যায় তা নিশ্চিত করতে আপনি সাধারণত একটি টাইমার সেট করেন।
কিন্তু মাঝে মাঝে আপনি সেটি ভুলে যান।

এমন একটি ফাংশন `cookingStatus` লিখুন যা প্যারামিটার হিসেবে টাইমারে বাকি থাকা সময়কে মিনিটে গ্রহণ করে।
ফাংশনটির তিনটি সম্ভাব্য ফলাফল আছে।

- টাইমার `0` দেখালে, এটি `'Lasagna is done.'` রিটার্ন করবে।
- টাইমার অন্য যেকোনো সংখ্যা দেখালে, ফলাফল হওয়া উচিত `'Not done, please wait.'`।
- টাইমার মান না দিয়ে ফাংশনটি কল করা হলে, ফলাফল হওয়া উচিত `'You forgot to set the timer.'`।

টাইমার কখনো ০-এর কম কোনো মান দেখাবে না।

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. প্রস্তুতির সময় অনুমান করুন

পরের যে লাসানিয়াটি আপনি প্রস্তুত করবেন, সেটির জন্য যথেষ্ট সময় বরাদ্দ আছে কি না আপনি নিশ্চিত করতে চান, যাতে রান্নাটা উপভোগ করতে পারেন।
আপনি ইতিমধ্যেই আপনার লাসানিয়ার সব স্তর নিয়ে একটি পরিকল্পনা করেছেন।
এখন সেটির ভিত্তিতে প্রস্তুতিতে কত সময় লাগবে তা আপনি অনুমান করতে চান।

এমন একটি ফাংশন `preparationTime` তৈরি করুন যা স্তরগুলোর একটি অ্যারে এবং প্রতি স্তরে গড় প্রস্তুতির সময় মিনিটে গ্রহণ করে।
ফাংশনটির উচিত স্তরের সংখ্যার ভিত্তিতে মোট প্রস্তুতির সময়ের অনুমান রিটার্ন করা।
গড় প্রস্তুতির সময় না দিয়ে ফাংশনটি কল করা হলে, পরিবর্তে `2` মিনিট ধরে নিতে হবে।

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. প্রয়োজনীয় নুডলস ও সসের পরিমাণ হিসাব করুন

সময় বরাদ্দ করার পাশাপাশি, আপনার স্বপ্নের লাসানিয়া রান্নার জন্য যথেষ্ট সস ও নুডলস আছে কি না তাও আপনি নিশ্চিত করতে চান।
আপনার লাসানিয়ার প্রতিটি নুডলস স্তরের জন্য ৫০ গ্রাম নুডলস লাগবে।
আপনার লাসানিয়ার প্রতিটি সস স্তরের জন্য ০.২ লিটার সস লাগবে।

এমন একটি ফাংশন `quantities` ডিফাইন করুন যা প্যারামিটার হিসেবে স্তরগুলোর একটি অ্যারে নেয়।
এরপর ফাংশনটি আপনার খাবার তৈরির জন্য প্রয়োজনীয় নুডলস ও সসের পরিমাণ নির্ধারণ করবে।
ফলাফলটি `noodles` ও `sauce` কী (key) সহ একটি অবজেক্ট হিসেবে রিটার্ন করতে হবে।

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. গোপন উপাদান যোগ করুন

কিছুদিন আগে আপনি এক বন্ধুর বাড়িতে গিয়ে সেখানে লাসানিয়া খেয়েছিলেন।
এটি অসাধারণ ছিল এবং এতে বিশেষ কিছু একটা ছিল।
বন্ধু আপনাকে উপাদানের তালিকাটি পাঠিয়েছিলেন এবং বলেছিলেন, তালিকার শেষ জিনিসটিই "গোপন উপাদান" যা খাবারটিকে এত বিশেষ করে তুলেছিল।
এখন আপনি সেই গোপন উপাদানটিও আপনার রেসিপিতে যোগ করতে চান।

এমন একটি ফাংশন `addSecretIngredient` লিখুন যা প্যারামিটার হিসেবে উপাদানের দুটি অ্যারে গ্রহণ করে।
প্রথম প্যারামিটার হলো আপনার বন্ধুর পাঠানো তালিকা এবং দ্বিতীয়টি আপনার নিজের রেসিপির উপাদানের তালিকা।
ফাংশনটির উচিত আপনার বন্ধুর তালিকার শেষ জিনিসটি আপনার তালিকার শেষে যোগ করা।
যে অ্যারেটি আপনার রেসিপির প্রতিনিধিত্ব করে সেটি সরাসরি পরিবর্তন করতে হবে এবং ফাংশনটির কিছুই রিটার্ন করা উচিত নয়।
তবে প্রথম আর্গুমেন্টটি পরিবর্তন করা উচিত নয়।

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. রেসিপি স্কেল করুন

আপনার রান্নার বইয়ে দেওয়া পরিমাণ দিয়ে কেবল দুটি পোরশনের জন্য যথেষ্ট লাসানিয়া হয়।
যেহেতু পরের বার আপনি আরও মানুষের জন্য রান্না করতে চান, তাই আপনি বিভিন্ন সংখ্যার পোরশনের জন্য পরিমাণ হিসাব করতে চান।

এমন একটি ফাংশন `scaleRecipe` তৈরি করুন যা দুটি প্যারামিটার নেয়।

- একটি রেসিপি অবজেক্ট যেখানে ২ পোরশনের জন্য প্রয়োজনীয় পরিমাণ থাকে।
  অবজেক্টটির গঠন নিচের উদাহরণে দেখা যাবে।
- আপনি যে সংখ্যার পোরশন রান্না করতে চান।

ফাংশনটির উচিত কাঙ্ক্ষিত সংখ্যার পোরশনের জন্য প্রয়োজনীয় পরিমাণসহ একটি রেসিপি অবজেক্ট রিটার্ন করা।
তবে আপনি মূল রেসিপিটি রাখতে চান।
এর মানে হলো, এই কাজে রেসিপি আর্গুমেন্টটি পরিবর্তন করা উচিত নয়।

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
