# পরিচিতি

## অপশনাল

Swift [_অপশনাল_][optionals] ব্যবহার করে প্রোগ্রামারদের একটি মানের সম্ভাব্য অনুপস্থিতি প্রকাশ করার সুযোগ দেয়।
অপশনাল হলো এমন একটি টাইপ, যা হয় একটি মান ধারণ করতে পারে, নয়তো [`nil`][nil] হতে পারে, যা একটি মানের অনুপস্থিতিকে বোঝায়।
একটি অপশনাল ব্যবহার করতে হলে প্রোগ্রামকে আগে যাচাই করতে হয় যে মানটি আসলেই আছে কি না, তারপর আনর‍্যাপ করে সেটি ব্যবহার করতে হয়।

যেকোনো টাইপের নামের শেষে একটি `?` যোগ করে সেটিকে অপশনাল বানানো যায়।
তাই একটি অপশনাল ইন্টিজারের টাইপ হবে `Int?` এবং একটি অপশনাল স্ট্রিংয়ের টাইপ হবে `String?`।
অপশনাল টাইপের কনস্ট্যান্ট বা ভ্যারিয়েবল ডিফাইন করা এবং সেগুলোতে মান অ্যাসাইন করা, নন-অপশনাল টাইপের মানের ক্ষেত্রে যেমন করা হয় ঠিক তেমনই করা হয়।

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

একটি অপশনাল টাইপের ভ্যারিয়েবলে বিশেষ মান `nil` অ্যাসাইন করে আপনি সেটিতে মানের অনুপস্থিতি অ্যাসাইন করতে পারেন।
`nil` সব অপশনাল টাইপের সাথেই ব্যবহার করা যায়, কিন্তু দুটি ভিন্ন অপশনাল টাইপে অ্যাসাইন করা `nil`-এর টাইপ এক নয়; সেগুলো একটির জায়গায় আরেকটি ব্যবহার করা যায় না, এমনকি তুলনাও করা যায় না।

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

এছাড়াও লক্ষণীয়, `nil` যেকোনো অপশনাল টাইপে অ্যাসাইন করা গেলেও নন-অপশনাল টাইপে অ্যাসাইন করা যায় না (এমনকি সেটিতে আসলে `nil` না থাকলেও)।
আর যে মেথড একটি নন-অপশনাল টাইপ প্রত্যাশা করে, সেটিতে আগে আনর‍্যাপ না করে কোনো অপশনাল টাইপ পাঠানো যায় না।

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## অপশনাল ব্যবহার করা

যেহেতু অপশনাল টাইপ তাদের বেস টাইপের মতো একই টাইপ নয়, তাই এই দুই টাইপ একইভাবে ব্যবহার করা যায় না।
উদাহরণস্বরূপ: `Int("123") + 1` লিখলে কম্পাইলার একটি এরর দেয়: "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'"।
এর কারণ হলো `Int("123")` একটি `Int` টাইপ নয়, বরং একটি অপশনাল `Int?` টাইপ রিটার্ন করে; কারণ স্ট্রিংটি যদি ইন্টিজারে রূপান্তর করা না যায়, তাহলে ফলাফল হবে `nil`।
রূপান্তরের ফলে যে `Int` পাওয়া যায় তা ব্যবহার করতে হলে প্রথমে সেটি "আনর‍্যাপ" করতে হয়।

Swift-এ এটি সাধারণত করা হয় `if-let` এবং `guard-let` কনস্ট্রাক্ট দিয়ে, যা [_অপশনাল বাইন্ডিং_][optional-binding]-এর জন্য ব্যবহৃত হয়; এগুলো `nil` আছে কি না তা যাচাই করে, আর কোনো মান থাকলে আনর‍্যাপ করা মানটি একটি দেওয়া নামের সাথে বেঁধে একটি কোড পথ নেয়, আর `nil` পাওয়া গেলে ভিন্ন আরেকটি কোড পথ নেয়।

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

লক্ষণীয়, `safeNum` ভ্যারিয়েবলটির টাইপ `Int`, `Int?` নয়।
নিচের উদাহরণে `num`-এর টাইপ `Int?` এবং `safeNum`-এর টাইপ `Int`।

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

এই _অপশনাল বাইন্ডিং_ গুরুত্বপূর্ণ, কারণ এটি মান থেকে অপশনাল টাইপটি আনর‍্যাপ করে (বা "সরিয়ে দেয়"), ফলে মানটিকে একটি নন-অপশনাল মান হিসেবে ব্যবহার করা যায়।
আপনি যদি কেবল একটি শর্ত যাচাই করে দেখেন যে মানটি `nil` কি না, তাহলেও মানটির টাইপ অপশনালই থেকে যায়:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

যেসব ক্ষেত্রে আগেভাগে রিটার্ন করা দরকার, সেখানে `guard-let`-ও ব্যবহার করা যায়:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## অপশনাল তুলনা করা

মনে রাখবেন, একজোড়া অপশনালের বেস টাইপ স্ট্যান্ডার্ড তুলনা অপারেটর দিয়ে তুলনা করা গেলেও, অপশনালগুলো নিজেদের তুলনা করা যায় না।
এগুলো কেবল সমান কি না তা যাচাই করা যায়।
দুটি অপশনাল সমান হয় যদি দুটিই `nil` হয়, অথবা তারা যে মানগুলো ধারণ করে সেগুলো তাদের বেস টাইপের মধ্যে সমান হয়।

তবে দুটি অপশনাল মানের একটি কাস্টম তুলনা চালানোর জন্য কোড লেখা যায়।
নিচে একটি `switch` স্টেটমেন্টের উদাহরণ দেওয়া হলো, যা কেবল তখনই `true` রিটার্ন করবে যদি দুটি অপশনাল মানই নন-নিল হয় এবং প্রথম মানটি দ্বিতীয়টির চেয়ে ছোট হয়।
এটি করতে এটি _অপশনাল প্যাটার্ন_ `varName?` ব্যবহার করে, যা কেবল নন-নিল অপশনালের সাথে মেলে এবং অপশনালের ভেতরের মানটি `varName` নামের সাথে বেঁধে দেয়।

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
