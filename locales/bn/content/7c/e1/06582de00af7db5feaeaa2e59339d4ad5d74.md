# পরিচিতি

`if/else` এক্সপ্রেশন দিয়ে কন্ডিশনাল লজিক চালানো গেলেও, কন্ডিশনাল লজিক চালানোর আরও একটি শক্তিশালী উপায় Haskell-এ আছে: [প্যাটার্ন ম্যাচিং][pattern-matching]।
প্যাটার্ন ম্যাচিংয়ের সাহায্যে একটি মানকে এক বা একাধিক _প্যাটার্ন_-এর সাথে মিলিয়ে পরীক্ষা করা যায়।
এমন একটি প্যাটার্নের উদাহরণ হলো _কনস্ট্যান্ট প্যাটার্ন_, যা একটি মানকে একটি কনস্ট্যান্টের সাথে মেলায় (যেমন `1` বা `"hello"`)।

ফাংশন ডিফাইন করার সময় আপনি ভিন্ন ভিন্ন প্যাটার্নের জন্য আলাদা ফাংশন বডি ডিফাইন করতে পারেন।
এতে কোড পরিষ্কার হয়, সহজ ও পড়ার উপযোগী হয়।
আপনি যেকোনো ডেটা টাইপে প্যাটার্ন ম্যাচ করতে পারেন: সংখ্যা, ক্যারেক্টার, অ্যারে, টুপল ইত্যাদি।

উদাহরণস্বরূপ, একটি সাধারণ ফাংশন যা একটি পূর্ণসংখ্যা (`Int`) নেয় এবং সেটিকে _0_-এর _1_ ধাপ কাছাকাছি নিয়ে আসে, তা এভাবে লেখা যায়:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

অন্য প্যাটার্নের সাথে একসাথে ব্যবহার করলে প্যাটার্ন ম্যাচিংয়ের আসল জৌলুস বেরিয়ে আসে, যেমন _ভ্যারিয়েবল প্যাটার্ন_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

উপরের উদাহরণে _0_ ছাড়া বাকি সব ইনপুটকে একইভাবে দেখা হয়, ফলে ঋণাত্মক সংখ্যার জন্য ভুল ফলাফল আসবে।
কন্ডিশনাল প্যাটার্ন ব্যবহার করে এটি সমাধান করা যায়, যাদের _গার্ড_ বলা হয় এবং যেগুলো `|` চিহ্ন দিয়ে লেখা হয়:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

উপরের উদাহরণগুলোতে সম্ভাব্য সব ইনপুটের জন্য মিলে যাওয়া প্যাটার্ন নেই।
কম্পাইলার এটি ধরতে পারবে এবং একটি ওয়ার্নিং দেবে।
এটি Haskell-এর খুবই কাজের একটি বৈশিষ্ট্য, যা রান-টাইম এরর এড়াতে সম্ভাব্য সব পথ কভার করা নিশ্চিত করতে সাহায্য করে।
এটিকে _এক্সহস্টিভ চেকিং_ বলা হয়।
ওয়ার্নিং দূর করতে হলে আপনাকে সব কেস হ্যান্ডেল করতে হবে।
_গার্ড_-এর ভিতরে বাকি সব প্যাটার্ন ধরার জন্য `otherwise` এক্সপ্রেশনটি `True`-এর সিনট্যাকটিক সুগার হিসেবে ব্যবহার করতে পারেন।

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

প্যাটার্ন ম্যাচিং উপরে থেকে নিচে প্রতিটি প্যাটার্নের সাথে একটি মান পরীক্ষা করে, যতক্ষণ না মিলে যাওয়া একটি প্যাটার্ন পায় এবং সেই প্যাটার্নের সাথে সম্পর্কিত লজিক চালায়।
**প্যাটার্নের ক্রম গুরুত্বপূর্ণ!**
