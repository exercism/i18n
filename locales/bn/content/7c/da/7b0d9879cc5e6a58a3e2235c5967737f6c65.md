# ভূমিকা

একটি মেথড প্যারামিটারকে একটি ডিফল্ট মান অ্যাসাইন করে ঐচ্ছিক করা যায়। ঐচ্ছিক প্যারামিটারসহ কোনো মেথড কল করার সময়, কলকারীকে সেগুলোর জন্য মান পাস করতে হয় না। ঐচ্ছিক প্যারামিটারের জন্য যদি কোনো মান পাস করা না হয়, তবে তার ডিফল্ট মান ব্যবহার করা হবে।

ঐচ্ছিক প্যারামিটারগুলো প্যারামিটার তালিকার শেষে থাকতে হবে; তাদের পরে অ-ঐচ্ছিক প্যারামিটার থাকতে পারে না।

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

ভ্যারিয়েবলের নামের আগে `?` অপারেটর ব্যবহার করে ঐচ্ছিক প্যারামিটারটিকে `null`-এ সেট করা যায়:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
