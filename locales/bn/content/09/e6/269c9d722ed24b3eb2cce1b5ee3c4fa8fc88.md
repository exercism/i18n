# ভূমিকা

## প্যাকেজ ও মডিউল

### ইমপোর্ট করা

সাধারণত `use` কিওয়ার্ড দিয়ে একটি মডিউল লোড করা হয়।
এটি মডিউলটি লোড করার সাথে সাথে তার `import` মেথডও কল করে, ফলে এক্সপোর্ট করা সব সিম্বল ইমপোর্ট হয়ে যায়।

প্যাকেজের `@EXPORT` অ্যারেতে থাকা সিম্বলগুলো ডিফল্টভাবে ইমপোর্ট হয়।
প্যাকেজের `@EXPORT_OK` অ্যারেতে থাকা সিম্বলগুলো স্পষ্টভাবে ইমপোর্ট করতে হয়।

### এক্সপোর্ট করা

কোনো সিম্বল ইমপোর্ট করার জন্য প্রথমে সেটি এক্সপোর্ট করতে হয়।
[Exporter][Exporter] মডিউলটি Perl-এর সাথেই দেওয়া থাকে এবং এক্সপোর্ট করার সবচেয়ে সুবিধাজনক উপায়গুলোর একটি।

মডিউলটি ডিফাইন করা:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

মডিউলটি ব্যবহার করা:
```perl
use Foo ('bar');

bar();
```

### কোর মডিউল

[Exporter][Exporter]-এর পাশাপাশি Perl-এ ব্যবহারের জন্য নানা ধরনের [কোর মডিউল][perl-core-modules] আছে।
এখানে আপনার সামনে আসতে পারে এমন অনুশীলনীর জন্য কাজে লাগতে পারে এমন কিছু উদাহরণ হলো [List::Util][List::Util], [Time::Piece][Time::Piece] এবং [Math::BigRat][Math::BigRat]।

### CPAN

কোর মডিউল ছাড়াও, [CPAN][metacpan]-এ Perl কমিউনিটির তৈরি হাজার হাজার অতিরিক্ত মডিউল ইনস্টল করার জন্য পাওয়া যায়।
Exercism-এর Perl টেস্ট রানারের সাথে ব্যবহার করা যায় এমন কিছু মডিউল ইনস্টল করতে Perl ট্র্যাক একটি [cpanfile][test-runner-cpanfile] ব্যবহার করে।
