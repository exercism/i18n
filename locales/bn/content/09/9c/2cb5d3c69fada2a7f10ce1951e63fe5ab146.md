কিন্তু সবকিছু একটু এলোমেলো: Aazra-এর কোঅর্ডিনেটগুলো দেখে মনে হচ্ছে Rui-এর থেকে আলাদা ভাবে ফরম্যাট করা ও সাজানো হয়েছে, আর কোন ট্রেজার কোন লোকেশনে যায় তা বের করার জন্য তাদের বারবার এক তালিকা থেকে অন্য তালিকায় চোখ বুলাতে হচ্ছে। নতুন গ্লিমলিন হিসেবে তারা নিজেদের হান্টের তথ্য আরও ভালোভাবে গুছিয়ে রাখার জন্য একটি ছোট প্রোগ্রাম (আসলে কয়েকটি ফাংশন) লিখতে আপনার কাছে সাহায্য চাইতে এসেছে।

## 1. লোকেশন কনভার্ট করুন

`place_location_to_treasure_location` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি স্থানের লোকেশন (যেমন `#("C", 1)`) নেয় এবং সেটিকে একটি ট্রেজারের লোকেশন (যেমন `#(1, "C")`)-এ কনভার্ট করে।

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. ট্রেজার ও স্থানের লোকেশন তুলনা করুন

`treasure_location_matches_place_location` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি স্থানের লোকেশন (যেমন `#("C", 1)`) নেয় এবং সেটি একটি ট্রেজারের লোকেশন (যেমন `#(1, "C")`)-এর সাথে মিলে গেলে `True` রিটার্ন করে।

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. ট্রেজারের লোকেশন গণনা করুন

`count_place_treasures` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি স্থান (যেমন `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) ও ট্রেজারগুলোর তালিকা নেয় এবং সেখানে যতগুলো ট্রেজার পাওয়া যায় তার সংখ্যা রিটার্ন করে।

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. বিশেষ স্থান

`special_case_swap_possible` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি ট্রেজার (যেমন `#("Amethyst Octopus", #(1, "F"))`), একটি স্থান (যেমন `#("Seaside Cottages", #("C", 1))`) এবং একটি কাঙ্ক্ষিত ট্রেজার (যেমন `#("Crystal Crab", #(6, "A"))`) নেয়, এবং নিচের কম্বিনেশনগুলোর জন্য `True` রিটার্ন করে:

- Abandoned Lighthouse-এ Brass Spyglass যেকোনো অন্য ট্রেজারের সাথে বদলানো যায়।
- Stormy Breakwater-এ Amethyst Octopus-কে Crystal Crab বা Glass Starfish-এর সাথে বদলানো যায়।
- Harbor Managers Office-এ Vintage Pirate Hat-কে Model Ship in Large Bottle বা Antique Glass Fishnet Float-এর সাথে বদলানো যায়।
