# পরিচিতি

Factor-এর [`random`][random] ভোকাবুলারি একটি জেনেরিক ওয়ার্ড `random` দেয়, যা তার আর্গুমেন্ট অনুযায়ী নিজেকে খাপ খাইয়ে নেয়, আর দেয় সিকোয়েন্স শাফল ও স্যাম্পল করার হেল্পার।

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

একটি ইন্টিজার `n`-এর উপর `random` প্রয়োগ করলে `[0, n)` রেঞ্জের একটি মান রিটার্ন হয়; আর একটি সিকোয়েন্সের উপর প্রয়োগ করলে একটি র‍্যান্ডম এলিমেন্ট রিটার্ন হয়। `randomize` জায়গাতেই শাফল করে, আর `sample` আলাদা আলাদা এলিমেন্ট নির্বাচন করে।

ডিফল্টভাবে এগুলো সিস্টেম ক্লক থেকে সিড নেওয়া একটি গ্লোবাল জেনারেটর থেকে মান টানে। ফলাফল যাতে প্রতিবার একই আসে, সেজন্য একটি সিডযুক্ত জেনারেটর বসাতে পারেন `<mersenne-twister>` (এটি [`random.mersenne-twister`][mt] থেকে) আর `with-random` দিয়ে:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
