# পরিচিতি

[Stringer][stringer-interface] হলো একটি ইন্টারফেস, যা দিয়ে ভ্যালুগুলোর স্ট্রিং ফরম্যাট নির্ধারণ করা যায়।

এই ইন্টারফেসে মাত্র একটি মেথড আছে, `String`:

```go
type Stringer interface {
    String() string
}
```

এই ইন্টারফেসটি ইমপ্লিমেন্ট করতে চাওয়া টাইপের অবশ্যই একটি `String()` মেথড থাকতে হবে, যা টাইপটির এমন একটি স্ট্রিং রিটার্ন করে যা মানুষ সহজে বুঝতে পারে।
ভ্যালু ফরম্যাট ও প্রিন্ট করার জন্য [fmt][fmt-package] প্যাকেজ (এবং আরও অনেক প্যাকেজ) এই মেথডটি খুঁজবে।

## উদাহরণ: দূরত্ব

ধরুন, আমরা এমন একটি অ্যাপ্লিকেশনে কাজ করছি যা ভিন্ন ভিন্ন এককে মাপা ভৌগোলিক দূরত্ব নিয়ে কাজ করে।
আমরা `DistanceUnit` ও `Distance` টাইপ নিচের মতো ডিফাইন করেছি:

```go
type DistanceUnit int

const (
	Kilometer    DistanceUnit = 0
	Mile         DistanceUnit = 1
)

type Distance struct {
	number float64
	unit   DistanceUnit
}
```

উপরের উদাহরণে `Kilometer` ও `Mile` হলো `DistanceUnit` টাইপের কনস্ট্যান্ট।

`String` মেথড না থাকায় এই টাইপগুলো `Stringer` ইন্টারফেসটি ইমপ্লিমেন্ট করে না।
তাই `fmt`-এর ফাংশনগুলো Go-এর "ডিফল্ট ফরম্যাট" ব্যবহার করে `Distance` ভ্যালু প্রিন্ট করবে:

```go
mileUnit := Mile
fmt.Sprint(mileUnit)
// => 1
// The result is '1' because that is the underlying value of the 'Mile' constant (see constant declarations above)

dist := Distance{number: 790.7, unit: Kilometer}
fmt.Sprint(dist)
// => {790.7 0}
// not a very useful output!
```

আউটপুটকে আরও তথ্যবহুল করতে আমরা `DistanceUnit` ও `Distance` টাইপের জন্য `Stringer` ইন্টারফেসটি ইমপ্লিমেন্ট করি, প্রতিটি টাইপে একটি `String` মেথড যোগ করে:

```go
func (sc DistanceUnit) String() string {
	units := []string{"km", "mi"}
	return units[sc]
}

func (d Distance) String() string {
	return fmt.Sprintf("%v %v", d.number, d.unit)
}
```

`Distance` ভ্যালু ফরম্যাট করার সময় `fmt` প্যাকেজের ফাংশনগুলো এই মেথডগুলো কল করবে:

```go
kmUnit := Kilometer
kmUnit.String()
// => km

mileUnit := Mile
mileUnit.String()
// => mi

dist := Distance{
	number: 790.7,
	unit: Kilometer,
}
dist.String()
// => 790.7 km
```
