# ইঙ্গিত

## সাধারণ

- `plot` টাপল, `registrations` ও `next-id` সিম্বল এবং `not-found` সিম্বল আগেই অনুশীলনীর ফাইলে ডিক্লেয়ার করা আছে।
- মডিউল-লেভেল স্টেটের জন্য `set-global`, `get-global` আর `change-global` ব্যবহার করুন।

## 1. বাগান খুলুন এবং তার রেজিস্ট্রেশনগুলো তালিকাভুক্ত করুন

- `registrations`-এর শুরুর মান হিসেবে `V{ } clone`-ই সঠিক (সবসময় `clone` করুন, যাতে লিটারালটি কলগুলোর মধ্যে শেয়ার না হয়)।
- `1 next-id set-global` কাউন্টারটি সেট করে।
- `list-registrations`-এর জন্য একটি `registrations get-global`-ই যথেষ্ট।

## 2. একটি প্লট রেজিস্টার করুন

- আগে `next-id` পড়ুন, তারপর `id` ও `name` থেকে প্লটটি তৈরি করতে `plot boa` ব্যবহার করুন।
- `next-id [ 1 + ] change-global` দিয়ে কাউন্টারটি বাড়ান।
- `push` ([`sequences`][sequences]-এ) ভেক্টরের শেষে সরাসরি যোগ করে, যা `registrations get-global`-এর জন্য একেবারে উপযুক্ত।

## 3. একটি প্লট রিলিজ করুন

- `:: release ( id -- )` ফিল্টার প্রেডিকেটের ভেতরে `id` ব্যবহারযোগ্য করে তোলে।
- `[ id>> id = ] reject` এমন প্রতিটি প্লট রেখে দেয় যার `id` স্লট লোকাল `id`-এর সাথে মেলে *না*। এটি একটি `change-global`-এর বডি হিসেবে ব্যবহার করুন।

## 4. রেজিস্টার করা একটি প্লট আনুন

- `find` রিটার্ন করে `( index elt/f )`. `nip` ইনডেক্সটি বাদ দেয়।
- কিছু না পাওয়া গেলে `[ not-found ] unless*` সিম্বলটি বসিয়ে দেয়।
