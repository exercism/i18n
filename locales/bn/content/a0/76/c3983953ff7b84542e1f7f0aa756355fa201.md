# বিস্তারিত

এক্সসেপশন ফিল্টার করার সময় `when` হলো কিওয়ার্ড। এটি `catch` স্টেটমেন্টের পরে বসে এবং ওই সময়ে স্কোপে থাকা যেকোনো মান ব্যবহার করা একটি বুলিয়ান এক্সপ্রেশন নিতে পারে। এগুলো কেবল এক্সসেপশনটির নিজের সদস্যই হতে হবে, তা নয়। এক্সসেপশনের টাইপ মিললে এবং এক্সপ্রেশনটি ট্রু হলে ওই `catch` স্টেটমেন্টের সাথে সম্পর্কিত ব্লকটি চালানো হয়, অন্যথায় পরের `catch` স্টেটমেন্টটি থাকলে সেটি পরীক্ষা করা হয়।

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- এই [এক্সসেপশন ফিল্টার][exception-filters] নিবন্ধে দেখানো হয়েছে কীভাবে এক্সসেপশন ফিল্টার করতে হয়।

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
