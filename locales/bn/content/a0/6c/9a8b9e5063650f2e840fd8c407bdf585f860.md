# সম্পর্কে

**ক্লোজার** হলো [Clojure-এ][clojure-guide-closures] একটি প্রোগ্রামিং প্যাটার্ন, যার মাধ্যমে কোনো ফাংশনের ভেতরে বাইরের [লেক্সিকাল স্কোপ][wiki-lexical-scope] থেকে ভ্যারিয়েবল ব্যবহার করা যায়। Clojure ক্লোজারকে স্বচ্ছভাবেই সাপোর্ট করে, আর এগুলো আসলে কী, সেটা না জেনেই প্রায়ই এগুলো ব্যবহার করা হয়।

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## স্টেট সংরক্ষণ ও মান পাঠানোর জন্য ক্লোজার

অ্যাটম ব্যবহার করলে কিছু স্টেট সংরক্ষণ করা যায়:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

`increment`-এ প্রতিবার কল করলেই তার কাউন্টার এক씩 বেড়ে যায়:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
