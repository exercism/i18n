# নির্দেশনা

কাছেই "Tech Palace" নামে একটি গৃহস্থালি যন্ত্রপাতির দোকান আছে।
দোকানের মালিক সম্প্রতি একটি বড় ডিসপ্লে বসিয়েছেন, যা মার্কেটিং বার্তা দেখাতে এবং গ্রাহকরা প্রবেশপথে তাদের লয়্যালটি কার্ড স্ক্যান করলে একটি বিশেষ স্বাগত বার্তা দেখানোর জন্য ব্যবহার করা হবে।
ডিসপ্লেটি অনেকগুলো ছোট LED লাইট দিয়ে তৈরি এবং এটি একাধিক লাইন টেক্সট দেখাতে পারে।

নতুন ডিসপ্লের জন্য টেক্সট তৈরি করতে যে কোড ব্যবহার করা হয়, সেখানে দোকানের মালিকের আপনার সাহায্য দরকার।

## 1. স্বাগত বার্তা তৈরি করুন

<!-- markdownlint-disable-next-line MD038 -->
তাদের লয়্যালটি কার্ড স্ক্যান করা বেশিরভাগ গ্রাহকের জন্য দোকানের মালিক ডিসপ্লেতে `Welcome to the Tech Palace, ` লেখাটির পরে গ্রাহকের নাম বড় হাতের অক্ষরে দেখতে চান।

`welcome_message` ফাংশনটি ইমপ্লিমেন্ট করুন, যা গ্রাহকের নাম একটি ছোট স্ট্রিং (`felt252`) আর্গুমেন্ট হিসেবে নেয় এবং কাঙ্ক্ষিত বার্তাটি একটি `ByteArray` হিসেবে রিটার্ন করে।

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. চটকদার একটি বর্ডার যোগ করুন

দোকান থেকে প্রচুর কেনাকাটা করা অনুগত গ্রাহকদের জন্য মালিক স্বাগত বার্তার আগে ও পরে স্টার দিয়ে একটি লাইন যোগ করে স্বাগত ডিসপ্লেটি আরও চটকদার করতে চান।
প্রতিটি লাইনে কতগুলো স্টার থাকবে তা নিয়ে তিনি এখনো নিশ্চিত নন, তাই এটা কনফিগারেবল রাখতে চান।

একটি `add_border` ফাংশন লিখুন, যা আর্গুমেন্ট হিসেবে একটি স্বাগত বার্তা (একটি `ByteArray`) এবং প্রতি লাইনে স্টারের সংখ্যা (`u32` টাইপ) নেয়।
এটি একটি `ByteArray` রিটার্ন করবে, যা ৩টি লাইন নিয়ে গঠিত: কাঙ্ক্ষিত সংখ্যক স্টার দিয়ে একটি লাইন, তারপর ঠিক যেভাবে পাস করা হয়েছিল সেভাবেই স্বাগত বার্তা, তারপর স্টারের আরেকটি লাইন।

```rust
add_border("Welcome!", 10)
```

এটি নিচের ফলাফলটি রিটার্ন করা উচিত:

```bash
**********
Welcome!
**********
```

## 3. পুরনো মার্কেটিং বার্তা পরিষ্কার করুন

এই নতুন ডিসপ্লে বসানোর আগে দোকানে একটি অনুরূপ ডিসপ্লে ছিল, যা শুধু কনফিগার করা যায় না এমন স্থির লাইন দেখাতে পারত।
মালিক নতুন ডিসপ্লেতে পুরনো মার্কেটিং বার্তাগুলোর কিছু আবার ব্যবহার করতে চান।
তবে ডেটাতে ইতিমধ্যে একটি স্টার বর্ডার এবং কিছু অনাকাঙ্ক্ষিত হোয়াইটস্পেস রয়েছে।
আপনার কাজ হলো বার্তাগুলো পরিষ্কার করা, যাতে সেগুলো আবার ব্যবহার করা যায়।

`clean_up_message` ফাংশনটি ইমপ্লিমেন্ট করুন, যা পুরনো মার্কেটিং বার্তাটি একটি `ByteArray` হিসেবে নেয়।
ফাংশনটি প্রথমে টেক্সট থেকে সব স্টার সরাবে, এরপর বাকি টেক্সটের শুরু ও শেষের হোয়াইটস্পেস সরাবে।
এরপর ফাংশনটি পরিষ্কার করা বার্তাটি রিটার্ন করবে।

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
