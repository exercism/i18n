# পরিচিতি

Haxe-এ, একটি **অ্যারে** হলো (সাধারণত) একই টাইপের এলিমেন্টের একটি সংগ্রহ। Haxe-এ অ্যারে তৈরি করার তিনটি উপায় আছে; হয় কনস্ট্রাক্টর দিয়ে, নয়তো ডিক্লারেশন সিনট্যাক্স দিয়ে। Haxe-এ অ্যারের প্রথম এলিমেন্টের ইনডেক্স হয় শূন্য:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

কনস্ট্রাক্টর দিয়ে একটি অ্যারে তৈরি করতে হলে, অ্যারেতে যেসব এলিমেন্ট থাকবে সেগুলোর টাইপ পাস করতে হবে:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

যদি আমরা চাই একটি অ্যারে একাধিক টাইপের এলিমেন্ট ধারণ করুক, তাহলে টাইপ ইন্ডিকেটরে `Dynamic` টাইপটি যোগ করি:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
