# নির্দেশনা সংযোজন

## Prolog-এ তারিখ নিয়ে কাজ করা

তারিখ নিয়ে কাজ করার জন্য Prolog-এর বিল্ট-ইন সাপোর্ট [বেশ প্রাথমিক ধরনের][built-in-dates-support]। তারিখ নিয়ে কাজ করার অনেক সুবিধাজনক উপায় হলো [date_time প্যাকেজ][date_time-package] ব্যবহার করা।

### date_time প্যাকেজ ইনস্টল করা

আপনার ইনস্টল করা Swipl ভার্সন যদি বেশ নতুন হয়, তাহলে নিচের কমান্ডটি চালিয়ে প্যাকেজটি ইনস্টল করতে পারেন:

```bash
swipl pack install date_time
```

এটা যদি কাজ না করে, তাহলে চালাতে পারেন:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
আপনি যদি অনলাইন এডিটর ব্যবহার করেন, তাহলে নিজে হাতে কিছু ইনস্টল করার দরকার নেই।
~~~~

### date_time প্যাকেজ ব্যবহার করা

`date_time` প্যাকেজ ব্যবহার করতে আপনার সলিউশন ফাইলের শুরুতে নিচের কোডটি যোগ করুন:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
টিপ: [date_time প্যাকেজের সোর্স][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] ভালোভাবে ডকুমেন্ট করা আছে এবং আপনার অনেক উপকারে আসবে!
~~~~
