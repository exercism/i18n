# ইঙ্গিতসমূহ

## 1. Split a string into individual lines

- একটি নির্দিষ্ট ডেলিমিটার ব্যবহার করে স্ট্রিংকে স্ট্রিংয়ের অ্যারেতে ভাগ করার জন্য Swift-এ একটি [মেথড][nsstring-components-docs] আছে।

## 2. Front door

- প্রহরী একটি কবিতা আবৃত্তি করবেন, আর আপনাকে সেই কবিতাটি আলাদা আলাদা লাইনে ভাগ করতে হবে; এটার জন্য আপনি আগে থেকেই থাকা একটি ফাংশন ব্যবহার করতে পারেন।
- কবিতার লাইনগুলোর উপর ইটারেট করতে আপনি একটি for লুপ ব্যবহার করতে পারেন।
- একটি স্ট্রিংয়ের প্রথম ক্যারেক্টার পেতে আপনি স্ট্রিংয়ের `first` প্রপার্টি ব্যবহার করতে পারেন।
- প্রতিটি লাইনের প্রথম ক্যারেক্টার সংরক্ষণ করতে আপনি ক্যারেক্টারের একটি অ্যারে বা একটি স্ট্রিং ব্যবহার করতে পারেন।

## 3. Back door

- প্রহরী একটি কবিতা আবৃত্তি করবেন, আর আপনাকে সেই কবিতাটি আলাদা আলাদা লাইনে ভাগ করতে হবে; এটার জন্য আপনি আগে থেকেই থাকা একটি ফাংশন ব্যবহার করতে পারেন।
- কবিতার লাইনগুলোর উপর ইটারেট করতে আপনি একটি for লুপ ব্যবহার করতে পারেন।
- একটি স্ট্রিংয়ের শেষ ক্যারেক্টার পেতে আপনি স্ট্রিংয়ের `last` প্রপার্টি ব্যবহার করতে পারেন।
- প্রতিটি লাইনের শেষ ক্যারেক্টার সংরক্ষণ করতে আপনি ক্যারেক্টারের একটি অ্যারে বা একটি স্ট্রিং ব্যবহার করতে পারেন।

## 4. Secret room

- প্রহরী একটি কবিতা আবৃত্তি করবেন, আর আপনাকে সেই কবিতাটি আলাদা আলাদা লাইনে ভাগ করতে হবে; এটার জন্য আপনি আগে থেকেই থাকা একটি ফাংশন ব্যবহার করতে পারেন।
- কবিতার লাইনগুলোর দৈর্ঘ্যের উপর ইটারেট করে এমন একটি for লুপ আপনি ব্যবহার করতে পারেন।
- একটি স্ট্রিংয়ের নির্দিষ্ট ইনডেক্সে থাকা ক্যারেক্টার পেতে Swift-এ একটি [মেথড][indexing] আছে।
- একটি স্ট্রিংকে আপারকেসে রূপান্তর করতে Swift-এ একটি [মেথড][uppercased] আছে।
