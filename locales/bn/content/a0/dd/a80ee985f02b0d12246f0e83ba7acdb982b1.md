# নির্দেশনা

আপনি একজন আগ্রহী পাখি-পর্যবেক্ষক, যিনি হিসাব রাখেন আপনার বাগানে কত পাখি এসেছে।
সাধারণত আপনি নোটবুকে ট্যালি করে পাখি গোনেন, কিন্তু আপনি আপনার ডেটা নিয়ে আরও ভালোভাবে কাজ করতে চান।
গত কয়েক সপ্তাহে প্রতিদিনের যে পাখি-সংখ্যা আপনি নোটবুকে রেখেছিলেন, তা আপনি ইতোমধ্যেই ডিজিটাল করে ফেলেছেন।

এখন আপনি আপনার গোনা মোট পাখির সংখ্যা নির্ণয় করতে চান, কোনো নির্দিষ্ট সপ্তাহের পাখি-সংখ্যা হিসাব করতে চান এবং একটি গণনার ভুল সংশোধন করতে চান।

## 1. এখন পর্যন্ত আপনি মোট কত পাখি গুনেছেন তা নির্ণয় করুন

চলুন, একটি সামগ্রিক চিত্র দেখে ডেটা বিশ্লেষণ শুরু করি।
আপনি লগ রাখা শুরু করার পর থেকে মোট কত পাখি গুনেছেন তা বের করুন।

এমন একটি ফাংশন `totalBirdCount` তৈরি করুন যা প্রতিদিনের পাখি-সংখ্যা ধারণ করা একটি অ্যারের মতো অবজেক্ট গ্রহণ করে।
এটি আপনার গোনা মোট পাখির সংখ্যা রিটার্ন করবে।

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. একটি নির্দিষ্ট সপ্তাহে আসা পাখির সংখ্যা হিসাব করুন

এখন যেহেতু আপনার পাখি-গণনার সংখ্যাগুলো সম্পর্কে একটি সাধারণ ধারণা তৈরি হয়েছে, আপনি আরও সূক্ষ্ম বিশ্লেষণ করতে চান।

এমন একটি ফাংশন `birdsInWeek` তৈরি করুন যা প্রতিদিনের পাখি-সংখ্যা ধারণ করা একটি অ্যারের মতো অবজেক্ট এবং একটি সপ্তাহ নম্বর গ্রহণ করে।
এটি ওই নির্দিষ্ট সপ্তাহে আপনার গোনা মোট পাখির সংখ্যা রিটার্ন করে।
আপনি ধরে নিতে পারেন যে সপ্তাহগুলো সবসময় সম্পূর্ণভাবে হিসাব করা হয়।

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. একটি গণনার ভুল সংশোধন করুন

আপনি বুঝতে পারলেন যে আপনি যখনই পাখির হিসাব রাখার চেষ্টা করছিলেন, তখনই একটি পাখি বাগানের এক দূরের কোণে লুকিয়ে ছিল।
আপনি বের করলেন যে এই পাখিটি সবসময় প্রতি দুই দিনে একদিন আপনার বাগানে কাটাত।
ওই দিনগুলোর মাঝে এটি ঠিক কোথায় ছিল তা আপনি জানেন না, তবে নিশ্চিতভাবে আপনার বাগানে নয়।
আপনার পাখি-পর্যবেক্ষকের অন্তর্দৃষ্টিও আপনাকে বলে যে আপনার তালিকায় হিসাব করা প্রথম দিনটিতে পাখিটি আপনার বাগানে ছিল।

এই নতুন তথ্য অনুযায়ী, এমন একটি ফাংশন `fixBirdCountLog` লিখুন যা আর্গুমেন্ট হিসেবে প্রতিদিন গোনা পাখির একটি অ্যারের মতো অবজেক্ট নেয়। এটি প্রদত্ত অ্যারেটি পরিবর্তন করে গণনার ভুল সংশোধন করবে।

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
