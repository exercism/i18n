# পরিচিতি

C#-এ দুই ধরনের সংখ্যা আছে:

- ইন্টিজার: দশমিক বিন্দুর পরে কোনো অঙ্ক নেই এমন সংখ্যা (পূর্ণসংখ্যা)। উদাহরণ: `-6`, `0`, `1`, `25`, `976` এবং `500000`।
- ফ্লোটিং-পয়েন্ট সংখ্যা: দশমিক বিন্দুর পরে শূন্য বা তার বেশি অঙ্ক আছে এমন সংখ্যা। উদাহরণ: `-2.4`, `0.1`, `3.14`, `16.984025` এবং `1024.0`।

C#-এ সবচেয়ে কমন সংখ্যার টাইপ দুইটি হলো `int` এবং `double`। একটি `int` হলো ৩২-বিটের ইন্টিজার, আর একটি `double` হলো ৬৪-বিটের ফ্লোটিং-পয়েন্ট সংখ্যা।

অ্যারিথমেটিকের কাজ করা হয় স্ট্যান্ডার্ড অ্যারিথমেটিক অপারেটর দিয়ে। সংখ্যা তুলনা করা যায় স্ট্যান্ডার্ড সংখ্যাতুলনার অপারেটর এবং সমতা (`==`) ও অসমতা (`!=`) অপারেটর দিয়ে।

C#-এ দুই ধরনের সংখ্যা কনভার্সন আছে:

1. ইমপ্লিসিট কনভার্সন: কোনো ডেটা হারাবে না এবং অতিরিক্ত সিনট্যাক্স লাগে না।
2. এক্সপ্লিসিট কনভার্সন: ডেটা হারাতে পারে, আর এর জন্য _কাস্ট_ আকারে অতিরিক্ত সিনট্যাক্স লাগে।

যেহেতু একটি `int`-এর নির্ভুলতা একটি `double`-এর চেয়ে কম, তাই `int` থেকে `double`-এ কনভার্ট করা নিরাপদ, আর তাই এটা একটি ইমপ্লিসিট কনভার্সন। কিন্তু `double` থেকে `int`-এ কনভার্ট করলে ডেটা হারাতে পারে, তাই এর জন্য এক্সপ্লিসিট কনভার্সন দরকার।

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
