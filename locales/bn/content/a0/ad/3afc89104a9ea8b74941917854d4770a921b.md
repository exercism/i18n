সব স্পষ্ট `Boolean(...)` কল সরিয়ে ফেলুন।

JavaScript-এ একটি এক্সপ্রেশনের ফলাফলকে নির্দিষ্ট কোনো টাইপে _কাস্ট_ করার দরকার হয় না।
উদাহরণস্বরূপ, একটি বাইনারি এক্সপ্রেশনের ফলাফল যেমন আছে তেমনই রিটার্ন করা যায়, এবং সেটিকে `boolean` বানানোর জন্য আরেকটি কলের প্রয়োজন নেই।

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
