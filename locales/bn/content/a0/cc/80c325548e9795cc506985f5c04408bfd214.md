# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা আপনার প্রিয় রান্নার বইয়ের একটি দুর্দান্ত লাসানিয়া রান্না করতে সাহায্য করবে।

আপনার চারটি কাজ আছে, যেগুলো সবই লাসানিয়া রান্না করতে ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে ওভেনের প্রত্যাশিত সময় নির্ধারণ করুন

`expectedMinutesInOven()` মেথডটি ডিফাইন করুন, যা কোনো প্যারামিটার নেয় না এবং লাসানিয়াটি ওভেনে কত মিনিট থাকা উচিত তা রিটার্ন করে। রান্নার বই অনুসারে, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. মিনিটে ওভেনে বাকি সময় গণনা করুন

`remainingMinutesInOven()` মেথডটি ডিফাইন করুন, যা লাসানিয়া ওভেনে যত মিনিট আছে তা একটি প্যারামিটার হিসেবে নেয় এবং আগের কাজের ওভেনে প্রত্যাশিত সময় মিনিটের ভিত্তিতে লাসানিয়াটিকে ওভেনে আরও কত মিনিট থাকতে হবে তা রিটার্ন করে।

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. মিনিটে প্রস্তুতির সময় গণনা করুন

`preparationTimeInMinutes()` মেথডটি ডিফাইন করুন, যা লাসানিয়ায় আপনি যত স্তর যোগ করেছেন তার সংখ্যা একটি প্যারামিটার হিসেবে নেয় এবং লাসানিয়া প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. মিনিটে মোট কাজের সময় গণনা করুন

`totalTimeInMinutes()` মেথডটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসানিয়ায় আপনি যত স্তর যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসানিয়া ওভেনে যত মিনিট আছে তার সংখ্যা। ফাংশনটি রিটার্ন করবে লাসানিয়া রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, যা প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট আছে তার যোগফল।

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
