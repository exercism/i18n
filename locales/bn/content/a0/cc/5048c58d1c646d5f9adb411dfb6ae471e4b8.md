# পরিচিতি

অনেক ভাষাতেই `null` বা `none`-এর মতো একটি উপায় থাকে, যা দিয়ে অস্তিত্বহীন কোনো মান বোঝানো হয়। R যেহেতু প্রচুর পরিমাণ (প্রায়ই অগোছালো) ডেটা সামলানোর জন্যই তৈরি, তাই এতে শূন্যতার একাধিক রূপ আছে।

সামগ্রিক লক্ষ্য হলো, অনুপস্থিত বা সন্দেহজনক মান চোখে পড়ামাত্র সেটি চিহ্নিত করা, তারপর কোনো এক্সেপশন ছাড়াই কাজ চালিয়ে যাওয়া।

## NULL

কোনো মান সত্যিই না থাকলে সেটিকে `NULL` দিয়ে প্রকাশ করা হয়। এটি সম্ভবত C বা Python যা করে, তার সবচেয়ে কাছাকাছি।

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

অনেক ক্ষেত্রেই `NULL` মানগুলোকে সহজভাবে উপেক্ষা করা হয়:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

যেসব ক্ষেত্রে মানটি আছে, কিন্তু সেটি কী তা আমরা জানি না, সেখানে `NA` ব্যবহার করা হয়। যেমন, রাস্তা দিয়ে যাওয়া গাড়ি গোনার সময় মানব পর্যবেক্ষক অসুস্থ হয়ে পড়তে পারেন বা স্বয়ংক্রিয় সেন্সর নষ্ট হয়ে যেতে পারে, কিন্তু যান চলাচল চলতেই থাকে।

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

তাই `NA` হলো একটি প্লেসহোল্ডার, যা মানুষকে সতর্ক করে দেয় যে এটি কীভাবে সামলাবে, সে বিষয়ে তাদের একটি সিদ্ধান্ত নিতে হবে।

## NaN

"Not a Number"-এর সংক্ষিপ্ত রূপ `NaN`, যেখানে একটি সংখ্যা প্রত্যাশিত ছিল, সেখানে একটি হিসাবের সমস্যা চিহ্নিত করে।

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

"অবৈধ" হিসাবের একমাত্র সম্ভাবনা এটি নয়।
শূন্য দিয়ে ভাগ করলে অশূন্য লবের ক্ষেত্রে কোনো এরর ছাড়াই `Inf` বা `-Inf` রিটার্ন হয়।

```R
1 / 0
#> [1] Inf
```

## খালি ভেক্টর

সম্ভবত আশ্চর্যজনকভাবে, R-এ খালি কি না তা যাচাই করার কোনো আদর্শ উপায় নেই।

এমনকি একটি খালি ভেক্টর তৈরি করাও পুরোপুরি স্পষ্ট নয়।
আগের একটি অংশে আমরা দেখেছি, কোনো আর্গুমেন্ট ছাড়া `c()` একটি ভেক্টর নয়, বরং `NULL` রিটার্ন করে।

```R
is.vector(c())
#> [1] FALSE
```

`logical()` বা `integer()`-এর মতো ফাংশন একটি আর্গুমেন্ট নেয়, যা দিয়ে কাঙ্ক্ষিত দৈর্ঘ্য নির্দিষ্ট করা হয়, আর তা শূন্যও হতে পারে।

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

আমরা একটি ভেক্টর তৈরি করে পরে তার প্রতিটি এলিমেন্ট মুছে ফেলতেও পারি, যেমনটি [ভেক্টর কনসেপ্ট][concept-vectors]-এ বর্ণনা করা হয়েছে।
এতে উপযুক্ত টাইপের একটি দৈর্ঘ্য-০ ভেক্টর পাওয়া যায়।

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
