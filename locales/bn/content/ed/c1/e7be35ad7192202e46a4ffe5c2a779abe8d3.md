# পরিচিতি

Common Lisp-এর সব কোড এস-এক্সপ্রেশন (সিম্বলিক এক্সপ্রেশন) দিয়ে তৈরি। সংক্ষেপে এদের সেক্সপ্র বলা হয়। প্রতিটি সেক্সপ্র হয় একটি অ্যাটম, নয়তো একটি কনস। এস-এক্সপ্রেশন ইভ্যালুয়েট করা হলে সেগুলো স্বয়ংক্রিয়ভাবে একটি মান রিটার্ন করে, যা ওই এক্সপ্রেশনের জায়গা নিয়ে নেয়। নিজের ফাংশন লেখার সময় (`defun` ব্যবহার করে), `defun`-এর বডির শেষ মানটি স্বয়ংক্রিয়ভাবে রিটার্ন হয়ে যায়:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
