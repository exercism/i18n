# নির্দেশাবলি

আপনার স্ট্রিং দল একটি সঙ্গীতানুষ্ঠানে বাজাচ্ছে, আর অনুষ্ঠানসূচিটা কাউকে লিখতে হবে।

পাঁচটি কাজই `PROGRAMME_NOTES` ক্লাসে যাবে।

## 1. সুরটির নাম আর কে লিখেছেন

প্রথমে সুরটি, তারপর ` by `, তারপর সুরকার।

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. একটি লাইন মাপা

প্রিন্টারের জানা দরকার একটি লাইন কত লম্বা।

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. শুরুর কয়েকটি অক্ষর

একটি শিরোনাম আর একটি সংখ্যা দেওয়া হলে, শুরু থেকে ঠিক ততগুলো অক্ষর রিটার্ন করুন।

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. শেষের কয়েকটি অক্ষর

একইভাবে, তবে শেষ থেকে গুনে।

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. লম্বা শিরোনাম ছোট করা

যে শিরোনামগুলো আঁটে না, সেগুলোকে প্রথম ছয়টি অক্ষরে কেটে ফেলা হয়, আর তার পরে বসে তিনটি পূর্ণচ্ছেদ।

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
