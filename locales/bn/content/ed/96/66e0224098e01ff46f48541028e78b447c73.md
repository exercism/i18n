# পরিচিতি

[Clojure](http://clojure.org) একটি ডাইনামিক প্রোগ্রামিং ভাষা, যা Java Virtual Machine (JVM)-কে টার্গেট করে।
সাধারণ উদ্দেশ্যে ব্যবহারের জন্য ডিজাইন করা Clojure স্ক্রিপ্টিং ভাষার সহজবোধ্যতার সঙ্গে মাল্টিথ্রেডেড প্রোগ্রামিংয়ের শক্তিশালী পরিকাঠামোর মেলবন্ধন ঘটায়।

Clojure মূলত একটি ফাংশনাল প্রোগ্রামিং ভাষা, আর এতে রয়েছে সমৃদ্ধ, অপরিবর্তনীয় ও স্থায়ী [ডেটা স্ট্রাকচার](http://clojure.org/data_structures)।

Clojure ওপেন সোর্স, আর ভাষাটিতে অবদান রাখার বিষয়ে তথ্য [এখানে পাওয়া যাবে](http://clojure.org/contributing)।

Clojure-এর স্রষ্টা Rich Hickey চেয়েছিলেন ফাংশনাল প্রোগ্রামিংয়ের জন্য একটি আধুনিক Lisp, যা প্রতিষ্ঠিত Java প্ল্যাটফর্মের সঙ্গে মিলেমিশে চলবে এবং কনকারেন্সির কথা মাথায় রেখে ডিজাইন করা হবে; এভাবেই Clojure-এর জন্ম হয়।

Clojure-এর লক্ষ্যগুলো যেসব উদ্ধৃতিতে ফুটে ওঠে, তার কয়েকটি এখানে:

* _ভালো ডিজাইন মানে বড় বড় পরিকল্পনা করা নয়, বরং জিনিসগুলোকে খুলে ভেঙে দেখা।_
* _প্রোগ্রামিং মানে টাইপ করা নয়... এটা ভাবনার ব্যাপার।_
