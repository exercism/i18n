# নির্দেশনা

এই অনুশীলনীতে আপনি একটি গাড়ি কারখানার অ্যাসেম্বলি লাইনের উৎপাদন বিশ্লেষণ করার কোড লিখবেন। অ্যাসেম্বলি লাইনের গতি `0` (বন্ধ) থেকে `10` (সর্বোচ্চ) পর্যন্ত হতে পারে।

সবচেয়ে কম গতিতে (`1`) প্রতি ঘণ্টায় `221`টি গাড়ি তৈরি হয়। গতি বাড়ার সাথে সাথে উৎপাদন সরলরৈখিকভাবে বাড়ে। তাই গতি `4` হলে প্রতি ঘণ্টায় `4 * 221 = 884`টি গাড়ি তৈরি হওয়া উচিত। তবে গতি বেশি হলে ত্রুটিপূর্ণ গাড়ি তৈরি হওয়ার সম্ভাবনাও বেড়ে যায়, আর সেগুলো পরে বাদ দিতে হয়। নিচের টেবিলে দেখানো হয়েছে গতি কীভাবে সফলতার হারকে প্রভাবিত করে:

- `1` থেকে `4`: ১০০% সফলতার হার।
- `5` থেকে `8`: ৯০% সফলতার হার।
- `9` এবং `10`: ৭৭% সফলতার হার।

আপনার হাতে দুটি কাজ।

## 1. প্রতি ঘণ্টায় উৎপাদনের হার গণনা করুন

প্রতি ঘণ্টায় অ্যাসেম্বলি লাইনের উৎপাদনের হার হিসাব করার একটি মেথড ইমপ্লিমেন্ট করুন, যেখানে সফলতার হারও বিবেচনায় নিতে হবে:

```rust
assembly_line::production_rate_per_hour(6)
// Returns: 1193.4
```

খেয়াল করুন, এখানে রিটার্ন করা মানটি একটি `f64`।

## 2. প্রতি মিনিটে উৎপাদিত সচল গাড়ির সংখ্যা গণনা করুন

প্রতি মিনিটে কতগুলো সচল গাড়ি তৈরি হয়, তা হিসাব করার একটি মেথড ইমপ্লিমেন্ট করুন:

```rust
assembly_line::working_items_per_minute(6)
// Returns: 19
```

খেয়াল করুন, এখানে রিটার্ন করা মানটি একটি `u32`।
