# ভূমিকা

Elixir-এ ফাংশনকে ফার্স্ট ক্লাস সিটিজেন হিসেবে বিবেচনা করা হয়। এর মানে হলো:

- নেমড এবং অ্যানোনিমাস ফাংশন ভ্যারিয়েবলে অ্যাসাইন করা যায়।
- নেমড এবং অ্যানোনিমাস ফাংশন ডেটার মতোই আর্গুমেন্ট ও রিটার্ন ভ্যালু হিসেবে পাস করা যায়।
- অ্যানোনিমাস ফাংশন ডাইনামিকভাবে তৈরি করা যায়।

নেমড ফাংশনের বিপরীতে অ্যানোনিমাস ফাংশনের জন্য কোনো স্ট্যাটিক রেফারেন্স পাওয়া যায় না; এগুলো কেবল তখনই পাওয়া যায় যখন সেগুলোকে কোনো ভ্যারিয়েবলে অ্যাসাইন করা হয় বা সাথে সাথেই কল করা হয়।

আমরা অ্যানোনিমাস ফাংশন ব্যবহার করতে পারি এভাবে:

- লেক্সিক্যাল স্কোপ ব্যবহার করে ডেটা লুকাতে (যাকে ক্লোজারও বলা হয়)।
- রানটাইমে ডাইনামিকভাবে ফাংশন তৈরি করতে।

অ্যানোনিমাস ফাংশন শুরু হয় `fn` রিজার্ভড ওয়ার্ড দিয়ে, ফাংশনের বডি থেকে আর্গুমেন্ট আলাদা করা হয় `->` টোকেন দিয়ে, আর শেষ হয় `end` দিয়ে। নেমড ফাংশনের মতোই, ফাংশনের শেষ এক্সপ্রেশনটি কল করা ফাংশনের কাছে _ইমপ্লিসিটলি রিটার্ন_ হয়।

কোনো ফাংশন রেফারেন্স কল করতে হলে রেফারেন্স ভ্যারিয়েবল আর আর্গুমেন্টের তালিকার মাঝে একটি `.` ব্যবহার করতে হবে:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

এটাকে আরও সংক্ষিপ্ত করতে আপনি শর্টহ্যান্ড ক্যাপচার নোটেশনও ব্যবহার করতে পারেন:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
