# নির্দেশনা

আপনি বনের ভেতর দিয়ে হাঁটার একটি পথ চিহ্নিত করছেন। দূরত্ব আর চোখে পড়া জিনিস, দুটোই সিকোয়েন্স হিসেবে আসে, তাই দুটোই ইটারেটর।

চারটিই `BUSH_WALK` ক্লাসে থাকবে। প্রত্যেকটিই একটি ইটারেটর, তাই প্রতিটি নামের শেষে `!` থাকে।

## 1. মার্কার

`markers!` মিটারে ব্যবধান আর একটি সংখ্যা নেয়, এবং শুরু থেকে প্রতিটি মার্কারের দূরত্ব দেয়।

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

সংখ্যাটি শূন্য হলে এটি কিছুই দেয় না।

## 2. যতক্ষণ না পথ শেষ হয়

`until_end!` পথের পাশে চোখে পড়া জিনিসগুলো নেয় এবং একবারে একটি করে দেয়, `"end"` পেলে থেমে যায়। `"end"` নিজে কিন্তু দেওয়া হয় না।

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

যদি `"end"` না থাকে, তবে এটি সবকিছুই দেয়।

## 3. শুধু পাখিরা

`birds!` চোখে পড়া জিনিসগুলো নেয় এবং কেবল সেগুলোই দেয় যেগুলো বড় হাতের অক্ষর দিয়ে শুরু হয়। এই জরিপে পাখি লেখা হয় এভাবেই।

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. নম্বরযুক্ত

`numbered!` চোখে পড়া জিনিসগুলো নেয় এবং এক থেকে গুনে প্রত্যেকটির সামনে তার অবস্থান বসিয়ে দেয়।

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
