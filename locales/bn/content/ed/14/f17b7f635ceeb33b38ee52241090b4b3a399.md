# সম্পর্কে

[`Box`][box] বুঝতে হলে [স্ট্যাক ও হিপ][stack and heap] আসলে কী, তা বোঝা সহায়ক।

স্ট্যাক হলো মেমরির একটি অংশ, যা লাস্ট-ইন-ফার্স্ট-আউট (LIFO) বাফারের মতো কাজ করে। স্ট্যাকে ডেটা পুশ করা খুব দ্রুত, আর তা পপ করাও দ্রুত। এই ডেটার মধ্যে ভ্যারিয়েবল বা ফাংশন অ্যাড্রেস থাকতে পারে, তবে কম্পাইলের সময় ডেটার সাইজ অবশ্যই জানা ও নির্দিষ্ট হতে হবে।

কম্পাইলের সময় ডেটার সাইজ জানা না থাকলে, বা সাইজ বদলে যেতে পারে এমন হলে, তা হিপে অ্যালোকেট করতে হয়। অ্যালোকেট করার সময় হিপে ডেটা রাখার মতো যথেষ্ট বড় জায়গা খুঁজতে হয়, ডেটা হিপে লিখতে হয়, আর সেই ডেটার মেমরি অ্যাড্রেস স্ট্যাকে পুশ করতে হয়। এসব করতে স্ট্যাকে সোজা ডেটা রেখে দেওয়ার চেয়ে অনেক বেশি সময় লাগে। হিপ থেকে ডেটা ফিরিয়ে আনতে একটু বেশি সময় লাগে, কারণ স্ট্যাকের অ্যাড্রেস ধরে হিপে ডেটার অবস্থান পর্যন্ত যেতে হয়।

`Box` একটি স্মার্ট পয়েন্টার, যা হিপে ডেটা অ্যালোকেট করে। অ্যাড্রেসটি থাকে স্ট্যাকে, আর সেটি হিপে থাকা ডেটার দিকে ইশারা করে। `Box` ব্যবহারের একটি [কারণ][reasons] হলো, যখন এমন কোনো টাইপ থাকে যার সাইজ কম্পাইলের সময় জানা যায় না, আর আপনি সেই টাইপের একটি মান এমন জায়গায় ব্যবহার করতে চান যেখানে নির্দিষ্ট সাইজ দরকার, তখন ডেটা হিপে রাখা। এর একটি বাস্তব ব্যবহার হলো, যখন আপনার কাছে একাধিক স্ট্রাক্ট থাকে, যেগুলোকে আপনি এমন একটি ট্রেইটের মাধ্যমে একইভাবে সামলাতে চান যা তারা সবাই ইমপ্লিমেন্ট করে, যেমনটি নিচে উদাহরণ দেওয়া হলো।

ধরুন আমাদের দুটি স্ট্রাক্ট আছে। প্রতিটি স্ট্রাক্ট এমন কিছুর, যা বিরক্তিকর হতে পারে। আমরা প্রতিটি স্ট্রাক্টকে এভাবে একটি Annoyance ট্রেইট ইমপ্লিমেন্ট করাতে পারি

```rust
struct WerewolfOfLondon;
struct Rooster;

trait Annoyance {
    fn annoy(&self) -> &'static str;
}

impl Annoyance for WerewolfOfLondon {
    fn annoy(&self) -> &'static str {
        "ahhh-OOOOOOO!"
    }
}

impl Annoyance for Rooster {
    fn annoy(&self) -> &'static str {
        "errr-errr-errr-errr-ERRRRRRRRR!"
    }
}
```

এখন ধরুন আমরা এমন একটি ফাংশন চাই, যা তাকে দেওয়া দিনের সময় অনুযায়ী আমাদের একটি Annoyance দেবে। প্রথমে এভাবে চেষ্টা করতে পারি, তবে দেখা যাবে এটি কম্পাইল হয় না

```rust
enum TimeOfDay {
    Midnight,
    Morning,
}

//return something that implements Annoyance
fn annoy_me(time_of_day: TimeOfDay) -> impl Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// `match` arms have incompatible types
// expected struct `WerewolfOfLondon`, found struct `Rooster`
// this is found to be of type `WerewolfOfLondon`
// `match` arms have incompatible types
// you could change the return type to be a boxed trait object
// if you change the return type to expect trait objects, box the returned expressions

```

কম্পাইলার তার সবটুকু সহায়তা দিয়ে আমাদের ঠিক কী করতে হবে তা বলে দেয়, আর তা হলো একটি বক্সড ট্রেইট অবজেক্ট রিটার্ন করা। ট্রেইট অবজেক্ট কী তা না জানলে সহজভাবে বলা যায়, এটি এমন একটি উপায় যেখানে কোনো ফাংশন [ডাইনামিক ডিসপ্যাচ][dynamic dispatch]-এর মাধ্যমে নির্দিষ্ট একটি অবজেক্ট রিটার্ন করে, অথচ ফাংশনটি নির্দিষ্ট কোনো ট্রেইট ইমপ্লিমেন্ট করা যেকোনো অবজেক্ট ফেরত দিতে পারত। যেহেতু আমাদের ডাইনামিক ডিসপ্যাচ দরকার, তাই ট্রেইটের নামের সামনে শুধু একটি `dyn` বসিয়ে দেখতে পারি, কাজ হয় কি না।

```rust
fn annoy_me(time_of_day: TimeOfDay) -> dyn Annoyance {
    match time_of_day {
        TimeOfDay::Midnight => WerewolfOfLondon,
        TimeOfDay::Morning => Rooster,
    }
}

// the size for values of type `dyn Annoyance` cannot be known at compilation time
// the trait `Sized` is not implemented for `dyn Annoyance`
// all local variables must have a statically known size
// unsized locals are gated as an unstable feature
```

এররগুলোর একটি হলো, `dyn Annoyance`-এর সাইজ কম্পাইলের সময় জানা যায় না। কারণ `annoy_me` আগে থেকেই জানে না, তাকে কল করা হলে সে কোন নির্দিষ্ট ট্রেইট অবজেক্ট রিটার্ন করবে। Annoyance ইমপ্লিমেন্ট করা স্ট্রাক্টগুলোর ফিল্ড আলাদা হতে পারে, সাইজও আলাদা হতে পারে। আর এখানে আমাদের মনে করিয়ে দেওয়া হয়, `Box`-এর একটি ব্যবহার হলো এমন টাইপের জন্য, যার সাইজ কম্পাইলের সময় জানা যায় না। তাই এবার আমরা একটি `Box`ed রিটার্ন ভ্যালু ব্যবহার করি, এবং match এক্সপ্রেশন থেকে ফেরত আসা মানগুলো `Box` করি, এভাবে

```rust
fn annoy_me(time_of_day: TimeOfDay) -> Box<dyn Annoyance> {
    match time_of_day {
        TimeOfDay::Midnight => Box::new(WerewolfOfLondon),
        TimeOfDay::Morning => Box::new(Rooster),
    }
}
```

`Box`-এর সিগনেচার হলো `Box<T>`, যেখানে `T` বলতে বোঝায় বক্স করা নির্দিষ্ট টাইপ, যা অ্যাঙ্গেল ব্র্যাকেটের ভেতরে বসানো হয়, যেমন উপরে `Box<dyn Annoyance>`-এ দেখা গেছে।

আমরা বক্সড ট্রেইট অবজেক্টটি এভাবে ব্যবহার করতে পারি

```rust
fn be_annoying(annoying_one: &dyn Annoyance) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(&*my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(&*my_annoyance);
}
```

যা প্রিন্ট করে

```rust
"ahhh-OOOOOOO!"
"errr-errr-errr-errr-ERRRRRRRRR!"
```

যেহেতু `my_annoyance`-এর টাইপ `Box<dyn Annoyance>`, তাই ডিরেফ অপারেটর `*` দিয়ে এটিকে `Box` থেকে ডিরেফারেন্স করতে হয়। এরপর `be_annoying` ফাংশন যাতে এটি ধার নিতে পারে, সেজন্য এটিকে একটি `dyn Annoyance` হিসেবে রেফারেন্স করা হয়।

এটি ইমপ্লিমেন্ট করার আরেকটি উপায় হলো, প্যারামিটারটির সাইজ নির্দিষ্ট থাকার শর্তটি তুলে দেওয়া। সেক্ষেত্রে কম্পাইলার Annoyance-এর প্রতিটি ভ্যারিয়েন্টের জন্য আলাদা ফাংশন তৈরি করবে, যাতে এটি স্ট্যাটিক ডিসপ্যাচ করতে পারে (এই প্রক্রিয়াটিকে বলা হয় [মনোমরফাইজেশন][monomorphization]), এভাবে

```rust
fn be_annoying<A: Annoyance + ?Sized>(annoying_one: &A) {
    println!("{:?}", annoying_one.annoy());
}
```

আরেকটি উপায় হলো, `be_annoying` ফাংশনটি যেন একটি `Box<dyn Annoyance>` গ্রহণ করে এবং [ডিরেফ কোয়ার্শন][deref coercion] ব্যবহার করে, যাতে `Box`-টি নিজে থেকে ডিরেফারেন্স করতে না হয়। এতে Annoyance ট্রেইট অবজেক্টের ওনারশিপ `be_annoying` ফাংশনের কাছে চলে যাবে। ফাংশন শেষে এটি স্কোপের বাইরে চলে যাবে এবং আর পাওয়া যাবে না।

```rust
fn be_annoying(annoying_one: Box<dyn Annoyance>) {
    println!("{:?}", annoying_one.annoy());
}

pub fn main() {
    let my_annoyance = annoy_me(TimeOfDay::Midnight);
    be_annoying(my_annoyance);
    let my_annoyance = annoy_me(TimeOfDay::Morning);
    be_annoying(my_annoyance);
}
```

The Rust Programming Language বইয়ে [এর অধ্যায়ে][using box] `Box` কীভাবে ব্যবহার করবেন সে সম্পর্কে আরও জানতে পারবেন।
