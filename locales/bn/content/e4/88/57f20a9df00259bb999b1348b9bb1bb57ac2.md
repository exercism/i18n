# ভূমিকা

Python-এ একটি [tuple][tuple] হলো _ক্রমে_ সাজানো আইটেমের একটি _অপরিবর্তনীয়_ কালেকশন।
বেশিরভাগ কালেকশনের মতোই `tuples` যেকোনো (বা একাধিক) ডেটা টাইপ ধারণ করতে পারে, এমনকি অন্য `tuples`-ও।
টিউপল সব [সাধারণ সিকোয়েন্স অপারেশন][common sequence operations] সমর্থন করে, কিন্তু [পরিবর্তনযোগ্য সিকোয়েন্স অপারেশন][mutable sequence operations] **সমর্থন করে না**।

`for item in <tuple>` গঠনটি ব্যবহার করে একটি টিউপলের এলিমেন্টগুলোর উপর ইটারেশন করা যায়।
এলিমেন্টের ইনডেক্স আর মান দুটোই দরকার হলে `for index, item in enumerate(<tuple>)` ব্যবহার করা যায়।
যেকোনো সিকোয়েন্সের মতোই, `tuples`-এর ভেতরের এলিমেন্টগুলো _ব্র্যাকেট নোটেশন_ দিয়ে অ্যাক্সেস করা যায়, বাম দিক থেকে `0-based index` সংখ্যা বা ডান দিক থেকে `-1-based index` সংখ্যা ব্যবহার করে।
এছাড়াও স্লাইস নোটেশন (_`<tuple>[<start>:<stop>:<step>]`_) ব্যবহার করে টিউপল সম্পূর্ণ বা আংশিক কপি করা যায়।


## টিউপল তৈরি করা

`tuple(<iterable>)` ক্লাস কনস্ট্রাক্টর অথবা `tuple` লিটারাল ডিক্লারেশন, দুই পদ্ধতিতেই টিউপল তৈরি করা যায়।

### `tuple()` কনস্ট্রাক্টর খালি অবস্থায় বা একটি _ইটারেবল_ দিয়ে ব্যবহার করা:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

স্ট্রিং ইটারেবল, তাই `tuple()` কনস্ট্রাক্টরে একটি একক `str` আর্গুমেন্ট হিসেবে দিলে চমকে দেওয়ার মতো ফলাফল আসতে পারে:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

একক ইটারেবলের এলিমেন্টগুলো একে একে যোগ হয়:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### একটি টিউপলকে _লিটারাল_ হিসেবে ডিক্লার করা:

যেহেতু `tuple(<iterable>)` কনস্ট্রাক্টর আর্গুমেন্ট হিসেবে শুধু _ইটারেবল_ (বা কিছুই না) নেয়, তাই লিটারাল পদ্ধতিতে এক-উপাদানের টিউপল তৈরি করা অনেক সহজ।

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

অন্য `tuples`-সহ নেস্টেড ডেটা স্ট্রাকচারও `tuple` এলিমেন্ট হিসেবে যোগ করা যায়:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## টিউপল কনক্যাটেনেশন

প্লাস `+` অপারেটর ব্যবহার করে টিউপল কনক্যাটেনেট করা যায়, যা প্রতিটি `tuple` আনপ্যাক করে একটি নতুন সম্মিলিত `tuple` তৈরি করে।

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## টিউপলের ভেতরের এলিমেন্ট অ্যাক্সেস করা

বাম দিক থেকে `0-based index` সংখ্যা বা ডান দিক থেকে `-1-based index` সংখ্যা ব্যবহার করে _ব্র্যাকেট নোটেশন_ দিয়ে একটি `tuple`-এর ভেতরের এলিমেন্টগুলো অ্যাক্সেস করা যায়।

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## টিউপলের এলিমেন্টগুলোর উপর ইটারেশন করা

`for item in <tuple>` সিনট্যাক্স ব্যবহার করে একটি লুপে `tuple`-এর ভেতরের এলিমেন্টগুলোর উপর _ইটারেশন_ করা যায়।
ইনডেক্স আর মান দুটোই দরকার হলে `for index, item in enumerate(<tuple>)` ব্যবহার করা যায়।

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## একটি টিউপলে সদস্যতা যাচাই করা

একটি `tuple`-এ সদস্যতা যাচাই করতে `in` অপারেটর ব্যবহার করা যায়।

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
