# For লুপ

লুপিং প্রোগ্রামিংয়ের একটি মৌলিক ধারণা, যা দিয়ে আপনি একই কোড ব্লক একাধিকবার চালাতে পারেন।
Swift-এ দুই ধরনের লুপ আছে: [`for-in` লুপ][for-loops] আর `while` লুপ।
এই অধ্যায়ে আপনি `for-in` লুপ সম্পর্কে শিখবেন।

For লুপ দিয়ে আপনি মানের একটি সিকোয়েন্সের উপর ইটারেশন করতে পারেন, একে একে প্রতিটি এলিমেন্ট নিয়ে আপনার পছন্দের একটি ভ্যারিয়েবলে বেঁধে দিতে পারেন।
Swift-এ আপনি নানা রকম সিকোয়েন্সের উপর ইটারেশন করতে পারেন, যেমন রেঞ্জ, অ্যারে আর স্ট্রিং (এবং আরও কিছু টাইপ, যা পরে আলোচনা করা হবে)।
সিকোয়েন্সের প্রতিটি এলিমেন্টের উপর ইটারেশন শেষ হয়ে গেলে লুপটি শেষ হয়।

`for` কিওয়ার্ড দিয়ে For লুপ ডিক্লেয়ার করা হয়, তারপর থাকে একটি ভ্যারিয়েবলের নাম, `in` কিওয়ার্ড, আর যে মানের সিকোয়েন্সের উপর ইটারেশন হবে সেটি।
`for-in` লুপে দেওয়া ভ্যারিয়েবলটি ইমিউটেবল, অর্থাৎ লুপের ভেতরে আপনি এর মান বদলাতে পারবেন না।
সংখ্যার একটি অ্যারের উপর ইটারেশন করা একটি `for-in` লুপের উদাহরণ এখানে:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` ভ্যারিয়েবলটি `for-in` লুপে ডিক্লেয়ার করা হয় এবং কেবল লুপের স্কোপের ভেতরেই ব্যবহার করা যায়।

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## একটি রেঞ্জের উপর ইটারেশন

`for-in` লুপ ব্যবহার করে আপনি সংখ্যার একটি রেঞ্জের উপরও ইটারেশন করতে পারেন।
এতে আপনি নির্দিষ্ট সংখ্যকবার একটি কোড ব্লক চালাতে পারেন, যেমন `1...5` রেঞ্জটি ১, ২, ৩, ৪ আর ৫ সংখ্যাগুলোর উপর ইটারেশন করবে, তাই লুপটি ৫ বার চলবে।
কখনও কখনও অ্যারের মতো একটি ডেটা স্ট্রাকচারে ইনডেক্সের উপর ইটারেশন করতে চাইতে পারেন, তখন `0..<array.count` রেঞ্জটি ব্যবহার করতে পারেন।

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## একটি স্ট্রিংয়ের উপর ইটারেশন

`for-in` লুপ ব্যবহার করে আপনি একটি স্ট্রিংয়ের উপরও ইটারেশন করতে পারেন।
এতে আপনি স্ট্রিংয়ের প্রতিটি ক্যারেক্টারের উপর ইটারেশন করতে পারেন, আর বিশেষভাবে খেয়াল করুন যে লুপে দেওয়া টাইপটি `Character`।

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift-এ `stride` নামের একটি ফাংশনও আছে, যা দিয়ে নির্দিষ্ট ধাপ মেনে একটি রেঞ্জের উপর সিকোয়েন্স তৈরি করা যায়।
এরপর `for-in` লুপ দিয়ে সেই সিকোয়েন্সের উপর ইটারেশন করা যায়।
`stride`-কে [`stride(from:to:by:)`][stride-to] অথবা [`stride(from:through:by:)`][stride-through] হিসেবে ডিফাইন করা হয়েছে; প্রথমটি এক্সক্লুসিভ আর দ্বিতীয়টি ইনক্লুসিভ।

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

খেয়াল করুন, `to` প্যারামিটারটি এক্সক্লুসিভ, তাই লুপটি `to` প্যারামিটারের ঠিক আগের সংখ্যা পর্যন্ত ইটারেশন করবে; অন্যদিকে `through` প্যারামিটারটি ইনক্লুসিভ, তাই এক্ষেত্রে এটি `10`-ও অন্তর্ভুক্ত করবে।

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
