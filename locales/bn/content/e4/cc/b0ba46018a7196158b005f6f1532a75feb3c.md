# নির্দেশনা

এই অনুশীলনীতে আপনি এমন কোড লিখবেন যা একটি সাইন কোম্পানিকে তাদের সাইনের জন্য কাস্টম বার্তা তৈরি করতে সাহায্য করবে।

## 1. একটি উপলক্ষের সাইন তৈরি করুন

`buildSign(occasion, name)` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি `occasion` প্যারামিটার হিসেবে একটি স্ট্রিং এবং `name` প্যারামিটার হিসেবে কারও নাম ধারণ করা একটি স্ট্রিং গ্রহণ করে।
দুটি প্যারামিটার একটি টেমপ্লেট স্ট্রিংয়ে এমবেড করা হবে, যাতে সাইনে বার্তাটি আউটপুট দেওয়া যায়।

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. একটি জন্মদিনের সাইন তৈরি করুন

`buildBirthdaySign(age)` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি বয়স গ্রহণ করে এবং বয়সের ভিত্তিতে সাইনের বার্তার একটি অংশ নির্ধারণ করবে।
বয়স ৫০ বা তার বেশি হলে সাইনটি ব্যবহারকারীকে _mature_ হিসেবে উল্লেখ করবে, নাহলে _young_ হিসেবে উল্লেখ করবে।
প্রত্যাশিত আউটপুট হুবহু নিচে দেখানো হয়েছে:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. একটি গ্র্যাজুয়েশন সাইন তৈরি করুন

`graduationFor(name, year)` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি নাম স্ট্রিং প্যারামিটার হিসেবে এবং একটি বছর সংখ্যা প্যারামিটার হিসেবে নেয় এবং স্ট্রিং ইন্টারপোলেশন ব্যবহার করে সাইনের জন্য একটি বাক্যাংশ তৈরি করে, যেখানে বার্তার দুটি লাইন আলাদা করতে একটি নিউলাইন ব্যবহার করা হয়।

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. একটি সাইনের খরচ হিসাব করুন

`costOf(sign, currency)` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি সাইনের বিষয়বস্তু ধারণ করা একটি স্ট্রিং এবং কারেন্সি নির্দেশ করে এমন একটি স্ট্রিং নেয়।
সাইনের মূল দাম প্রদত্ত কারেন্সিতে ২০। এছাড়া প্রতিটি অক্ষরের খরচ ২। (হোয়াইটস্পেসও হিসাবের মধ্যে ধরা হয়।)
যে বাক্যাংশটি রিটার্ন করা হয়, সেখানে সাইন তৈরির খরচ থাকে, যা দশমিক বিন্দুর পরে দুই অঙ্কে লেখা হয় এবং তার পরে কারেন্সি স্ট্রিংটি থাকে।

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
