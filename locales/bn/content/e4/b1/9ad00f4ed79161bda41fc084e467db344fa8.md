# রিসোর্স

## মডিউল

Perl-এর সাথে কোর মডিউলের একটি সেট আগে থেকেই আসে, যেগুলোর তালিকা [perldoc](https://perldoc.perl.org/modules)-এ পাবেন। সাধারণত এই মডিউলগুলো আপনি সঙ্গে সঙ্গে ব্যবহার করতে পারবেন। (কিছু ডিস্ট্রিবিউশনে কোর মডিউলগুলো আলাদাভাবে ইনস্টল করতে হতে পারে)।

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) হলো কাজের মডিউলের একটি বাছাই করা তালিকা, যেখানে আরও কিছু সুপারিশের তালিকার উল্লেখ আছে।

Perl-এর জন্য বেশ কিছু মডিউল ইনস্টলার পাওয়া যায়, যেগুলো দিয়ে [CPAN](https://metacpan.org/)-এ পাওয়া নানা ধরনের মডিউল ইনস্টল করতে পারবেন।

### App::cpm
খুব দ্রুত এবং সহজ একটি মডিউল ইনস্টলার।
এর একটি টিউটোরিয়াল [CPAN](https://metacpan.org/pod/App::cpm::Tutorial)-এ পাওয়া যায়।

[ইনস্টলেশন ডকুমেন্টেশন](https://exercism.org/tracks/perl5/installation)-এর `local::lib` নির্দেশনা অনুসরণ করে থাকলে এটি আপনার কাছে আগেই ইনস্টল করা থাকবে।

একটি `cpanfile` থেকে প্রয়োজনীয় মডিউল ইনস্টল করতে শুধু `cpm install` চালান, আর যথাক্রমে recommended বা suggested মডিউল ইনস্টল করতে `--with-recommends` বা `--with-suggested` ব্যবহার করুন।

একটি নির্দিষ্ট মডিউল লোকালি ইনস্টল করতে `cpm install Module::Name` চালান, আর গ্লোবালি ইনস্টল করতে `cpm install -g Module::Name` চালান।

### App::cpanminus
সবচেয়ে পরিচিত এবং বহুল ব্যবহৃত মডিউল ইনস্টলার।
ইনস্টলেশনের নির্দেশনা [CPAN](https://metacpan.org/pod/App::cpanminus)-এ পাওয়া যায়।

একটি `cpanfile` থেকে প্রয়োজনীয় মডিউল ইনস্টল করতে `cpanm -L local --installdeps .` চালান।
একটি নির্দিষ্ট মডিউল লোকালি ইনস্টল করতে `cpanm -L local Module::Name` চালান, আর গ্লোবালি ইনস্টল করতে `cpanm Module::Name` চালান।

## কোড স্টাইল এবং লিন্টিং

Perl কোডিং নিয়ে ভালো সাধারণ পরামর্শ খুঁজলে Damian Conway-এর [Perl Best Practices][PBP] একটি ভালো রেফারেন্স।

আপনার কোড সুন্দরভাবে সাজাতে [Perl::Tidy][PerlTidy] মডিউলটি ব্যবহার করতে পারেন।

এরপর আপনার কোড নতুন করে ফরম্যাট করতে দেওয়া `perltidy` ইউটিলিটি প্রোগ্রামটি ব্যবহার করতে পারেন।

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy`-তে সব রুচির কথা মাথায় রেখে *অনেক* কনফিগারেশন অপশন আছে। সেগুলোর ডকুমেন্টেশন [এখানে][perltidyDocs] আছে।

[tidyview]-ও আছে, একটি ভিজ্যুয়াল ইন্টারফেস যা দিয়ে বিভিন্ন অপশন বদলে সঙ্গে সঙ্গে ফলাফল দেখতে পারেন।

কোডিং প্র্যাকটিস বাধ্যতামূলক করতে চাইলে [Perl::Critic][perlcritic]-ও আছে। আগে উল্লেখ করা *Perl Best Practices* বইয়ে বর্ণিত নিয়মগুলো এর সাথে আসে, তবে এর অনেক প্লাগইনও আছে, আর যেকোনো প্রতিষ্ঠানের নিজস্ব কোডিং নিয়মের সাথে মিলিয়ে এটিকে কাস্টমাইজ করা যায়।

ব্যবহার করতে:

    $ perlcritic some_script.pl

টুলটিতে অনেক, অনেক কনফিগারেশন টুইক আছে, বিস্তারিত জানতে এর [ডকুমেন্টেশন][perlcriticdocs] দেখুন।
