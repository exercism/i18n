# ভূমিকা

## তুলনা

জাভাস্ক্রিপ্টে সংখ্যাগুলোকে নিচের সম্পর্কমূলক ও সমতামূলক অপারেটর দিয়ে তুলনা করা যায়।

| তুলনা                  | অপারেটর   |
| ---------------------- | --------- |
| বড়                     | `a > b`   |
| বড় বা সমান             | `a >= b`  |
| ছোট                     | `a < b`   |
| ছোট বা সমান             | `a <= b`  |
| (কঠোর) সমান            | `a === b` |
| (কঠোর) সমান নয়         | `a !== b` |

তুলনার ফলাফল সবসময় একটি বুলিয়ান মান: `true` বা `false`।

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

জাভাস্ক্রিপ্টে উপরের তুলনা অপারেটরগুলো দিয়ে স্ট্রিংও তুলনা করা যায়।
সেক্ষেত্রে অভিধানের ক্রম (লেক্সিকোগ্রাফিক্যাল ক্রম) প্রয়োগ করা হয়।
সব ক্যারেক্টারের সঠিক ক্রমের একটি তালিকা [এখানে][utf-16-list] পাবেন।

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## শর্তাধীন

জাভাস্ক্রিপ্টে শর্তসাপেক্ষে লজিক রান করার একটি কমন উপায় হলো `if` স্টেটমেন্ট।
এটি `if` কিওয়ার্ড, প্রথম বন্ধনীতে মোড়ানো একটি শর্ত এবং দ্বিতীয় বন্ধনীতে মোড়ানো একটি কোড ব্লক নিয়ে গঠিত।
শর্তটির ফলাফল `true` হলে কেবল তখনই কোড ব্লকটি রান করা হয়।

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

এটি একা ব্যবহার করা যায়, আবার `else` কিওয়ার্ডের সাথে মিলিয়েও ব্যবহার করা যায়।

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

`else` স্টেটমেন্টের ভিতরে আরেকটি শর্ত নেস্ট করতে আপনি `else if` ব্যবহার করতে পারেন।

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
