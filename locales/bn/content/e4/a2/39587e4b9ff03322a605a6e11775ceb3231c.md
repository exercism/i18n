# পরিচিতি

ধরুন, আপনার 1000 পর্যন্ত সব অ-ঋণাত্মক ইন্টিজার দরকার।
এগুলো একটি অ্যারেতে টাইপ করতে হলে সেটা হাস্যকরই হতো।

এর জন্যই আছে `range` টাইপ:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

রেঞ্জ খুবই কমন: কেবল আপনার টাইপিং বাঁচাতেই নয়, ফাংশনের রিটার্ন টাইপ হিসেবেও।

মনে রাখুন, রেঞ্জ কোনো ভেক্টর _নয়_।
এগুলো আসলে একটি সিকোয়েন্স তৈরির নির্দেশনার সমষ্টি মাত্র ("লেজি" ইভালুয়েশন, বা একটি "ইটারেটর")।

কোনো রেঞ্জকে ভেক্টর হিসেবে দরকার হলে রূপান্তরের জন্য `collect()` ফাংশনটি ব্যবহার করুন:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

স্টেপ সাইজ নির্দিষ্ট করা যায়, এখানে 0.3:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

তাহলে সিনট্যাক্স হলো `start:stepsize:stop`.
ইন্টিজারের উদাহরণে যেমন দেখা যায়, দুই প্রান্তের সীমাই _অন্তর্ভুক্ত_।
স্টেপ সাইজ যদি `stop - start`-কে নিঃশেষে ভাগ না করে, তাহলে শেষ এলিমেন্টটি `stop` ছাড়িয়ে যাওয়া এড়াবে।

## অক্ষরের রেঞ্জ

রেঞ্জে অ-সংখ্যাসূচক সিকোয়েন্সও ব্যবহার করা যায়।
সবচেয়ে সহজ উদাহরণ হলো ASCII অক্ষর:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

`Char` টাইপ নিয়ে আরও বিস্তারিত আলোচনা আসবে অন্য একটি কনসেপ্টে।
আপাতত এগুলোকে একক কোটের ভেতরের একক ক্যারেক্টার হিসেবে ধরুন।

## রেঞ্জের জন্য ফাংশন ও অপারেটর

`first()` এবং `last()` দিয়ে একটি রেঞ্জের সীমা যাচাই করুন।

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## ভেক্টর ইনডেক্সিং নিয়ে আরও কিছু

ইন্টিজার রেঞ্জ ও ভেক্টর, দুটোই ভেক্টর ইনডেক্সিংয়ে ব্যবহার করা যায়:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
