# সম্পর্কে

Haxe-এ সংখ্যার দুইটি টাইপ আছে: ইন্টিজার আর ফ্লোট।

- `Int`: একটি পূর্ণসংখ্যা বোঝায়।
- `Float`: একটি ডাবল-প্রিসিশন ৬৪-বিট ফ্লোটিং পয়েন্ট সংখ্যা বোঝায়।

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

যেখানে একটি `Float` প্রত্যাশিত সেখানে প্রতিটি `Int` ব্যবহার করা যায় (অর্থাৎ `Int` **`Float`-এ অ্যাসাইন করা যায়** বা **`Float`-এর সাথে একীভূত হয়**), কিন্তু উল্টোটা সত্য নয়: একটি `Float` কোনো `Int`-এ অ্যাসাইন করলে নির্ভুলতা হারানোর সম্ভাবনা থাকে, তাই এটি স্বয়ংক্রিয়ভাবে অনুমোদিত নয়।

## তুলনা

সংখ্যাগুলোর মান একই হলে সেগুলো সমান।

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```
