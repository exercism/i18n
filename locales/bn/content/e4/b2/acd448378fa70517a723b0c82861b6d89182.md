# ভূমিকা

Kotlin হলো JetBrains-এর তৈরি একটি **স্ট্যাটিক টাইপযুক্ত** প্রোগ্রামিং ভাষা। এর মানে হলো, ভ্যারিয়েবলগুলোর টাইপ কম্পাইলের সময়েই নির্ধারিত হয়ে যায়।

## ভ্যারিয়েবল

অন্য স্ট্যাটিক টাইপযুক্ত প্রোগ্রামিং ভাষার মতোই, প্রতিটি ভ্যারিয়েবলের টাইপ কম্পাইলের সময়ে নির্ধারণ করা লাগে। যেখানে কম্পাইলার প্রসঙ্গ থেকে টাইপ অনুমান করতে পারে, সেখানে আপনি স্পষ্ট টাইপ ঘোষণা করা এড়িয়ে যেতে পারেন।

Kotlin-এ অপরিবর্তনীয় (`val`) ও পরিবর্তনীয় (`var`) ভ্যারিয়েবল আছে। অপরিবর্তনীয় ভ্যারিয়েবলের প্রাথমিক মান অ্যাসাইন করার পর সেটি আর পরিবর্তন করা যায় না। বেশিরভাগ সময়েই আপনি এই ধরনের ভ্যারিয়েবল ব্যবহার করবেন।

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

পরিবর্তনীয় ভ্যারিয়েবলের মান একবার বা একাধিকবার পরিবর্তন করা যায়:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Kotlin-এ সেমিকোলন ঐচ্ছিক, তবে কিছু বিশেষ ক্ষেত্রে ব্যতিক্রম আছে, যা পরে আলোচনা করা হবে।

## ফাংশন

Kotlin-এ ফাংশন `fun` কিওয়ার্ড দিয়ে ডিফাইন করা হয়, এবং এগুলো _ফার্স্ট-ক্লাস সিটিজেন_ (OOP-এর সাথে এর কোনো সম্পর্ক নেই)। এর মানে হলো, আপনি এগুলো (তথাকথিত `top-level functions`) সরাসরি ফাইলের ভেতরে ঘোষণা করতে পারেন (যেমন Java-তে মেথড শুধু ক্লাসের ভেতরে ডিফাইন করা যায়, ফাইলে নয়):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

ফাংশন আর্গুমেন্ট নিতে পারে। প্রতিটি আর্গুমেন্টের একটি নাম ও একটি টাইপ থাকে। ভ্যারিয়েবলের বিপরীতে, আর্গুমেন্টের টাইপ অনুমান করা যায় না। ফাংশনে শূন্য বা একাধিক আর্গুমেন্ট থাকতে পারে:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Kotlin-এর ফাংশন একটি মান রিটার্ন করতে পারে, আবার নাও পারে:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

ফাংশন থেকে একটি মান রিটার্ন করার জন্য `return` কিওয়ার্ড ব্যবহার করা হয়:

```kotlin
fun getName(): String {
    return "Alice"
}
```

ফাংশনে ডিফল্ট মানযুক্ত প্যারামিটার থাকতে পারে। ফাংশন কল করার সময় এগুলো বাদ দিলে এই মানগুলো ব্যবহার করা হয়:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## কমেন্ট

এক লাইনের কমেন্ট লেখার জন্য `//` ব্যবহার করুন:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

আর বহু লাইনের কমেন্ট লেখার জন্য `/*` এবং `*/` ব্যবহার করুন:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
