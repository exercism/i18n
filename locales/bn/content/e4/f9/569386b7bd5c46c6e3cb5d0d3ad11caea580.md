# পরিচিতি

`case` হলো Factor-এর সমতার ভিত্তিতে কাজ করা বহুমুখী সুইচ। পছন্দটি যখন *একটি একক* মান কয়েকটি বিকল্পের একটির সমান হওয়ার উপর নির্ভর করে, তখন এটি সঠিক হাতিয়ার; আর যখন প্রতিটি শাখার জন্য আলাদা পরীক্ষা দরকার (সেজন্য `cond` ব্যবহার করুন), তখন নয়।

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

কয়েকটি বিষয় স্পষ্ট রাখা ভালো:

- সমতা হলো `=`। `=` দিয়ে যেকোনো কিছুকে কী (key) হিসেবে ব্যবহার করা যায়, যেমন সংখ্যা, স্ট্রিং, ক্যারেক্টার, সিম্বল, এমনকি টুপল।
- *মিলে যাওয়া* শাখাগুলো ইনপুট মানটি *ছাড়াই* স্ট্যাক দেখে। *ডিফল্ট* শাখাগুলো সেটিকে তখনও উপরে দেখে।
- ডিফল্ট ছাড়া এবং কোনো মিলে যাওয়া ক্লজ ছাড়া একটি `case` একটি এরর ছোড়ে।

`case` সম্ভব হলে একটি জাম্প টেবিলে কম্পাইল হয়, তাই এটি শুধু `if` চেইনের জন্য সুগার নয়, এটি দ্রুতও।
