# পরিচিতি

যখন আপনার `n` সংখ্যক মানের একটি সারি দরকার, যেখানে প্রত্যেকটি মান তার নিজের অবস্থানের উপর নির্ভর করে, তখন Factor-এর `<iota>` এবং `map` মিলেমিশে কাজটি সেরে ফেলে, লুপ কাউন্টার লেখার দরকারই পড়ে না।

## `<iota>` এবং `map`

`<iota>` ([`sequences`][sequences] ভোকাবুলারিতে আছে) একটি অঋণাত্মক পূর্ণসংখ্যা `n` নেয় এবং `0, 1, …, n-1` পূর্ণসংখ্যাগুলোর একটি *ভার্চুয়াল* সিকোয়েন্স রিটার্ন করে। এরপর `map` তার উপর দিয়ে হেঁটে প্রতিটি এলিমেন্টে আপনার কোয়োটেশন প্রয়োগ করে:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

কোয়োটেশনটি একটি পূর্ণসংখ্যা পায়, সেটিই ইনডেক্স, এবং ওই অবস্থানের মানটি স্ট্যাকে রেখে দেয়।

## সংখ্যা অনুসারে ইটারেশন এবং পুনরাবৃত্তি

আপনার যখন প্রতিটি ইনডেক্সে যাওয়ার শুধু *সাইড ইফেক্ট* দরকার, নতুন কোনো সিকোয়েন্স নয়, তখন `each-integer` ([`math`][math] ভোকাবুলারিতে আছে) `0, 1, …, n-1` রেঞ্জের উপর একটি কোয়োটেশন চালায়:

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate` ([`sequences`][sequences] ভোকাবুলারিতে আছে) একটি কোয়োটেশন `n` বার কল করে এবং ফলাফলগুলো সংগ্রহ করে, ইনডেক্স উপেক্ষা করে। `n` সংখ্যক স্বাধীন মান তৈরি করতে এটি দারুণ সুবিধাজনক:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## সীমাবদ্ধ রেঞ্জ

ইনডেক্স রেঞ্জ যখন `0` থেকে শুরু হয় না, বা আপনি চান সেটি দুই প্রান্তেই অন্তর্ভুক্ত থাকুক, তখন [`ranges`][ranges] ভোকাবুলারি ব্র্যাকেট-নোটেশনের লিটারেল দেয়। তৃতীয় বন্ধনী শেষ বিন্দুটি অন্তর্ভুক্ত করে; প্রথম বন্ধনী সেটি বাদ দেয়।

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

কয়েকটি কমন এক-আর্গুমেন্ট শর্টহ্যান্ড:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>` হলো সবচেয়ে কমন রূপ; রেঞ্জ যখন `0` ছাড়া অন্য কোথাও থেকে শুরু হয়, বা উপরের সীমাটি অন্তর্ভুক্ত করা দরকার হয়, তখন `[a..b]` এবং তার সঙ্গীরা সঠিক হাতিয়ার।

## খোলা নিম্নসীমা এবং খালি হতে পারে এমন রেঞ্জ

তৃতীয় বন্ধনী একটি শেষ বিন্দুকে *অন্তর্ভুক্ত* করে; প্রথম বন্ধনী সেটিকে *বাদ দেয়*। বাম দিকে একই কৌশল প্রয়োগ করলে পাওয়া যায় `(a..b]` এবং `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]` ফলাফল দেয় `{ 1 … n }` যখন `n > 0`, আর `{ }` যখন `n = 0`। অর্থাৎ "`n` পর্যন্ত প্রতিটি ধনাত্মক পূর্ণসংখ্যা, `n` সহ" ধরে ইটারেট করার সময় এটাই স্বাভাবিক রূপ।

## অবরোহী রেঞ্জ

চারটি বন্ধনী রূপই, `[a..b]`, `[a..b)`, `(a..b]`, `(a..b)`, যখন `a > b` তখন *নিচের দিকে* গোনে, খালি ফলাফলের দিকে এগোয় না:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## অবস্থান অনুযায়ী স্ট্রিং তৈরি

`map` তার কোয়োটেশন যে আকার ফেরত দেয়, সেই আকারেই ফল দেয়। কোয়োটেশন যদি স্ট্যাকে একটি ক্যারেক্টার কোড রেখে দেয়, তাহলে `>string` ([`strings`][strings] ভোকাবুলারিতে আছে) ফলাফলটিকে একটি স্ট্রিংয়ে পরিণত করে:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A` পার্স হয়ে পূর্ণসংখ্যা `65` হয়। এখানে কোয়োটেশনটি ইনডেক্সকে দ্বিগুণ করে এবং সেই বেস যোগ করে, ফলে প্রতি দ্বিতীয় বড় হাতের অক্ষরে গিয়ে পৌঁছায়। ইনডেক্সের উপরে আপনি যে-ই গণিত চাপান, সেটিই ঠিক করে দেয় ওই অবস্থানে শেষ পর্যন্ত কোন ক্যারেক্টারটি বসবে।

## অবস্থান অনুযায়ী বেছে নেওয়া

ক্যারেক্টারটি ইনডেক্স নিয়ে কোনো *শর্তের* উপর নির্ভর করলে, বেছে নেওয়ার কাজটি কোয়োটেশনের ভিতরে করুন:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

প্রথম তিনটি অবস্থান `i 3 <` পরীক্ষার ফল `t` পায়, তাই তারা `a` পায়; বাকিগুলো `b` পায়। একই রূপ, অর্থাৎ `[ <test> [ <yes> ] [ <no> ] if ]`, `even?` / `odd?` ([`math`][math] ভোকাবুলারিতে আছে) দিয়ে করা প্যারিটি পরীক্ষা এবং `mod` ও `zero?` দিয়ে করা "প্রতি k-তম অবস্থান" পরীক্ষা, এই দুটোই কভার করে।
