# অপ্রত্যাশিত বক্সড টাইপ

`${'boxed.type'}` বক্সড টাইপের বদলে `${'literal.type'}` ব্যবহার করুন। TypeScript-এ `Object`, `Number`, `Boolean` আর `String` হলো এমন টাইপ, যেগুলো নন-প্রিমিটিভ বক্সড অবজেক্ট বোঝায়। এই ধরনের অবজেক্ট TypeScript বা JavaScript কোডে প্রায় কখনোই সঠিকভাবে ব্যবহৃত হয় না। বক্সিং সম্পর্কে আরও জানতে [এখানে](https://en.wikipedia.org/wiki/Object_type_(object-oriented_programming)#Boxing) পড়ুন।
