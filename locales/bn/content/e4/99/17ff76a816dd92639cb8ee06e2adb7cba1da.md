# পরিচিতি

অ্যারে হলো Factor-এর নির্দিষ্ট দৈর্ঘ্যের সিকোয়েন্স: আপনি এলিমেন্ট বদলাতে পারেন, কিন্তু দৈর্ঘ্য বদলাতে পারেন না। আপনি ইতিমধ্যেই জানেন কীভাবে একটি লিটারাল অ্যারে (`{ … }`) লিখতে হয়, আর কীভাবে একটি স্লাইস বা অ্যাগ্রিগেট করতে হয়। স্ট্যাকের মান থেকে অ্যারে তৈরি করার পর সেগুলোর ভেতরের জিনিস খোঁজা বা সাজানোর সময় যে ছোট টুলকিটটি কাজে লাগে, এই অনুশীলনীতে সেটিই তুলে ধরা হয়েছে।

## স্ট্যাক থেকে তৈরি করা

`1array`, `2array`, `3array` আর `4array` ([`arrays`][arrays]-এ) স্ট্যাকের ওপর থেকে ১, ২, ৩ বা ৪টি মান তুলে নিয়ে সেগুলোকে একসাথে বেঁধে দেয়:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## জোড়া লাগানো

`concat` ([`sequences`][sequences]-এ) এমন একটি সিকোয়েন্স নেয় যার এলিমেন্টগুলো নিজেরাই সিকোয়েন্স, আর সেগুলোকে এক স্তর ফ্ল্যাট করে দেয়। `join` একই কাজ করে, তবে প্রতিটি জোড়ার মাঝে একটি সেপারেটর বসিয়ে দেয়:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## উল্টে দেওয়া

`reverse` এলিমেন্টগুলো উল্টো ক্রমে সাজিয়ে একটি নতুন সিকোয়েন্স রিটার্ন করে:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## এটি কি একটি অ্যারে?

`array?` ([`arrays`][arrays]-এ) হলো টাইপ প্রেডিকেট। `<array>`, `1array`/`2array`/..., বা অ্যারে লিটারাল `{ … }` দিয়ে তৈরি যেকোনো মানের জন্য এটি ট্রু, আর বাকি সবকিছুর জন্য (ভেক্টর, স্ট্রিং ও অন্যান্য সিকোয়েন্সসহ) ফলস:

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## খুঁজে বের করা

`index` ইনপুট মানের সমান প্রথম এলিমেন্টটির অবস্থান রিটার্ন করে, আর মানটি না থাকলে `f` রিটার্ন করে। `member?` শুধু একটি বুলিয়ান রিটার্ন করে। দুটোই **প্রথমে এলিমেন্ট** আর **পরে সিকোয়েন্স** নেয়। `members` ([`sets`][sets]-এ) একটি সিকোয়েন্সের *ইউনিক* এলিমেন্টগুলো রিটার্ন করে (এটাই ডিডুপ্লিকেশন অপারেশন), আর `all-unique?` (এটিও `sets`-এ) পরীক্ষা করে সিকোয়েন্সে আগে থেকেই কোনো ডুপ্লিকেট নেই কি না:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
