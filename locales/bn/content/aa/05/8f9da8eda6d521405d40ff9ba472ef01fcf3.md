# কমান্ড লাইনে টেস্টিং

টেস্টগুলো চালান এভাবে:

```bash
$ cargo test
```

প্রথম টেস্টটি ছাড়া বাকি সব ইগনোর করা আছে। আপনি প্রথম টেস্টটি পাস করানোর পর, `tests` ডিরেক্টরিতে থাকা টেস্টের সোর্স ফাইলটি খুলুন, পরের টেস্ট থেকে `#[ignore]` ফ্ল্যাগটি সরিয়ে ফেলুন এবং সেটিও পাস করান। প্রতিটি আলাদা টেস্ট হলো একটি ফাংশন, যার উপরে `#[test]` ফ্ল্যাগ থাকে। এভাবে চলতে থাকুন, যতক্ষণ না আপনি সব টেস্ট পাস করেন।

টেস্টের সোর্স ফাইল এডিট না করেই যদি _শুধু ইগনোর করা_ টেস্টগুলো চালাতে চান, তাহলে ব্যবহার করুন:

```bash
$ cargo test -- --ignored
```

আপনি যদি Rust 1.51 বা তার পরের কোনো ভার্সন ব্যবহার করেন, তাহলে _সব_ টেস্ট চালাতে পারেন এভাবে:

```bash
$ cargo test -- --include-ignored
```

নির্দিষ্ট কোনো টেস্ট, যেমন `some_test`, চালাতে চাইলে ব্যবহার করতে পারেন:

```bash
$ cargo test some_test
```

ঐ নির্দিষ্ট টেস্টটি যদি ইগনোর করা থাকে, তাহলে ব্যবহার করুন:

```bash
$ cargo test some_test -- --ignored
```

Rust টেস্ট সম্পর্কে আরও জানতে অনলাইনের [টেস্ট ডকুমেন্টেশন][rust-tests] দেখুন।

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
