# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | শুরুর সংখ্যা                                   |
| `$v0`    | আউটপুট    | ইন্টিজার | প্রত্যাশিত ধাপসংখ্যা, সংখ্যাটি অবৈধ হলে -1 |
| `$t0-9`  | সাময়িক | যেকোনো     | সাময়িক স্টোরেজের জন্য ব্যবহৃত                        |
