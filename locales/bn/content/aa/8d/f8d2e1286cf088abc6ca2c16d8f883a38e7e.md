# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | ইনপুট     | অ্যাড্রেস | নাল ক্যারেক্টার দিয়ে শেষ হওয়া ইনপুট স্ট্রিং                     |
| `$v0`    | আউটপুট    | বুলিয়ান | ইনপুটটি একটি প্যানগ্রাম (`0` = `false`, `1` = `true`) |
| `$t0-9`  | সাময়িক   | যেকোনো  | সাময়িক সংরক্ষণের জন্য ব্যবহৃত                       |
