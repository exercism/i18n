# সম্পর্কে

শর্তাধীন স্টেটমেন্ট হলো এমন স্টেটমেন্ট, যা একটি শর্ত `true` না `false` তার উপর নির্ভর করে ভিন্ন ভিন্ন কোড চালায়।

একটি [`if` স্টেটমেন্ট][if_statement] তার বডি চালায় কেবল তখনই, যখন তার শর্ত `true` হয়।
Go-তে ট্রুথি বা ফালসি মানের কোনো ধারণা নেই, তাই শর্তটি অবশ্যই `bool` টাইপের হতে হবে।
`if mySlice { ... }` বা `if 1 { ... }`-এর মতো এক্সপ্রেশন কম্পাইল এরর।

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

অতিরিক্ত শর্ত পরীক্ষা করতে `else if` এবং কোনোটিই না মিললে ফলব্যাক হিসেবে `else` ব্যবহার করুন।
শর্তগুলো উপর থেকে নিচে মূল্যায়ন করা হয়, এবং কেবল প্রথম যে শাখার শর্ত ট্রু হয় সেটিই চলবে।

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

সাধারণভাবে Go ব্যতিক্রমী কেস থেকে আগেভাগে রিটার্ন করা এবং `else` এড়িয়ে চলাকে প্রাধান্য দেয়।

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

একটি `if` স্টেটমেন্টে একটি ছোট ইনিশিয়ালাইজেশন স্টেটমেন্টও থাকতে পারে।
এটি সাধারণত কোনো কলের ঠিক পরেই এরর যাচাই করতে ব্যবহৃত হয়:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

ইনিশিয়ালাইজেশন স্টেটমেন্টে ঘোষণা করা ভ্যারিয়েবল কেবল পুরো `if`/`else` চেইনের ভেতরেই স্কোপে থাকে।
উল্লেখ্য, Go-তে কোনো টার্নারি অপারেটর নেই, যা কোড সহজে পড়া যায় রাখার জন্য একটি সচেতন ডিজাইন সিদ্ধান্ত।
