# অতিরিক্ত নির্দেশনা

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                               |
| -------- | --------- | ------- | --------------------------------------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং                              |
| `$v0`    | আউটপুট    | বুলিয়ান | ইনপুটে মিলে যাওয়া বন্ধনী আছে কি না (`0` = `false`, `1` = `true`) |
| `$t0-9`  | টেম্পোরারি | যেকোনো | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত হয়।                    |
