# পরিচিতি

C#-এ বুলিয়ান প্রকাশ করা হয় `bool` টাইপ দিয়ে, যার মান `true` বা `false` হতে পারে।

C# চারটি [বুলিয়ান অপারেটর][operators] সমর্থন করে: `!` (NOT), `&&` (AND), `||` (OR) এবং `^` (XOR)। `&&` ও `||` অপারেটর _শর্ট-সার্কিট ইভ্যালুয়েশন_ ব্যবহার করে, অর্থাৎ অপারেটরের ডান দিকটি কেবল প্রয়োজন হলেই মূল্যায়ন করা হয়।

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

তিনটি বুলিয়ান অপারেটরের প্রত্যেকটির [_অপারেটর অগ্রাধিকার_][precedence] আলাদা। ফলে এগুলো এই ক্রমে মূল্যায়িত হয়: প্রথমে `not`, তারপর `&&`, তৃতীয়ে `^` এবং সবশেষে `||`। আপনি যদি এই নিয়মগুলো 'এড়াতে' চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন প্রথম বন্ধনী (`()`) দিয়ে ঘিরে দিতে পারেন, কারণ প্রথম বন্ধনীর অপারেটর অগ্রাধিকার আরও বেশি।

```csharp
!true && false   // => false
!(true && false) // => true
```
