# পরিচিতি

Elixir-এ আমরা মডিউল অ্যাট্রিবিউট ডিফাইন করতে পারি, যেগুলো আমাদের ফাংশনে কনস্ট্যান্ট হিসেবে ব্যবহার করা যায়।

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

মডিউল কনস্ট্যান্ট ডিফাইন করতে ব্যবহার করা হলে অ্যাট্রিবিউট যেকোনো এক্সপ্রেশন হতে পারে, যা কম্পাইলের সময় ইভ্যালুয়েট করা যায়। কম্পাইলের পরে মডিউল অ্যাট্রিবিউট আর ব্যবহার করা যায় না, কারণ কম্পাইলের সময়ই সেগুলো এক্সপ্যান্ড হয়ে যায়, অনেকটা C-এর মতো ভাষায় ডিফাইন করা ম্যাক্রোর মতো।
