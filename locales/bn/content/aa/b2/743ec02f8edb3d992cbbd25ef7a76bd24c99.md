# ইঙ্গিত

## সাধারণ

- এনামের উপর ইটারেশন করার জন্য `enum-iterator` ক্রেটটি ব্যবহার করুন। এটি কীভাবে করবেন তা জানতে [ডকুমেন্টেশন](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) দেখুন।

- int থেকে এনামে রূপান্তর করার জন্য `int-enum` ক্রেটটি ব্যবহার করুন। বিস্তারিত জানতে [ডকুমেন্টেশন](https://docs.rs/int-enum/0.5.0/int_enum/) দেখুন।

- `Debug` ট্রেইটটি এখানে আছে কারণ আপনার সম্ভবত এটির দরকার হবে।

- আপনার কালার এনামের উপর `derive` করা ট্রেইটের তালিকা বাড়াতে হবে।
