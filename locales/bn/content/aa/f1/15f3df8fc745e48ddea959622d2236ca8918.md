# সম্পর্কে

ABAP সংখ্যাসূচক মানের জন্য প্রচলিত গাণিতিক অপারেটর সমর্থন করে:

- `+` মান যোগ করে।
- `-` মান বিয়োগ করে।
- `*` মান গুণ করে।
- `/` মান ভাগ করে।
- `MOD` ইন্টিজার ভাগের ভাগশেষ রিটার্ন করে।

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

যোগ ও বিয়োগের আগে গুণ ও ভাগ হিসাব করা হয়। কোনো হিসাব স্পষ্টভাবে দলবদ্ধ করতে চাইলে বন্ধনী ব্যবহার করুন।

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
