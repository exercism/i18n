# নির্দেশনা

Blorkemon™️ কার্ডের জন্য আপনার নস্টালজিয়া যেন একটুও কমার নামই নিচ্ছে না, আপনি আবার সেগুলো সংগ্রহ করা শুরুও করে ফেলেছেন, আর এখন বন্ধুদেরও নিজের সাথে যোগ দিতে বলছেন।

এই অনুশীলনীতে একটি কার্ড সংগ্রহ `MapSet` দিয়ে প্রকাশ করা হয়, কারণ আপনার লক্ষ্য যখন সব বিদ্যমান কার্ড পাওয়া, তখন ডুপ্লিকেট কার্ড গুরুত্বপূর্ণ নয়।

## 1. একটি সংগ্রহ শুরু করুন

আপনি সত্যিই চান আপনার বন্ধুরাও আপনার Blorkemon™️ উন্মাদনায় যোগ দিক, আর তার সবচেয়ে ভালো উপায় হলো তাদের একটি কার্ড দিয়ে তাদের সংগ্রহের সূচনা করে দেওয়া।

`GottaSnatchEmAll.new_collection` ইমপ্লিমেন্ট করুন, যা একটি কার্ডকে একটি সংগ্রহে রূপান্তর করে।

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. সংগ্রহ বাড়ান

একবার তৈরি হয়ে গেলে সংগ্রহটি নিজের একটা জীবন পেয়ে যায়, আর তাকে বাড়তেই হবে।

`GottaSnatchEmAll.add_card` ইমপ্লিমেন্ট করুন, যা একটি কার্ড ও একটি সংগ্রহ নেয় এবং দুটি মানের একটি টাপল রিটার্ন করে: একটি বুলিয়ান, যা বলে কার্ডটি আগেই সংগ্রহে ছিল কি না, আর কার্ডটি যোগ করা সংগ্রহটি।

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. বিনিময় শুরু করুন

এখন যেহেতু আপনার বন্ধুরা আবার Blorkemon™️ নিয়ে পাগল, আপনি কার্ড বিনিময় করে নিজের সংগ্রহ বাড়াতে এটাকে কাজে লাগাতে পারেন।

প্রতিটি বিনিময় করা সম্ভবও নয়, আবার প্রতিটি বিনিময় করার মতোও নয়।
আপনার কাছে নেই এমন কার্ড আপনি বিনিময় করতে পারেন না, আর আপনার কাছে আগেই আছে এমন কার্ডের বদলে কোনো কার্ড বিনিময় করা উচিত নয়।

`GottaSnatchEmAll.trade_card` ইমপ্লিমেন্ট করুন, যা বিনিময়ের জন্য দুটি কার্ড (আপনার আর তার) ও আপনার বর্তমান সংগ্রহ নেয়।
এর রিটার্ন ভ্যালু দুটি মানের একটি টাপল: একটি বুলিয়ান, যা বলে বিনিময়টি সম্ভব ও করার মতো কি না, আর বিনিময়টি করলে শেষে আপনার হাতে যে সংগ্রহ থাকত (যদিও সেটি আসলে সম্ভব না হয়)।

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. প্রতিটির একটিই থাকতে পারে

একটি ফ্লি মার্কেটে আপনি পুরোনো কার্ডের একটা ভাণ্ডার খুঁজে পেলেন।
তালিকাটি আপনার সংগ্রহের সাথে মেলাতে হলে আপনাকে কার্ডগুলো সাজিয়ে ডুপ্লিকেটগুলো সরাতে হবে।

`GottaSnatchEmAll.remove_duplicates` ইমপ্লিমেন্ট করুন, যা কার্ডের একটি অ্যারে সাজায় এবং সাজানো, অনন্য কার্ডের একটি অ্যারে রিটার্ন করে।

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. তাদের কাছে নেই এমন কার্ড

নিজের সংগ্রহ নিয়ে গর্ব করার সময় এসেছে।

`GottaSnatchEmAll.extra_cards` ইমপ্লিমেন্ট করুন, যা আপনার সংগ্রহ ও আরেকটি সংগ্রহ নেয়, এবং ওই অন্য সংগ্রহে নেই এমন কার্ডের সংখ্যা রিটার্ন করে।

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. সবার কাছে আছে এমন কার্ড

আপনি আর আপনার Blorkemon™️-প্রেমী বন্ধুরা একসাথে বসে ভাবেন, কোন কার্ডগুলো সবচেয়ে কমন।

`GottaSnatchEmAll.boring_cards` ইমপ্লিমেন্ট করুন, যা সংগ্রহের একটি অ্যারে নেয় এবং সব সংগ্রহে আছে এমন সাজানো কার্ডের একটি অ্যারে রিটার্ন করে।

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. সবগুলো কার্ড

আপনি আর আপনার বন্ধুরা মিলে কি সব Blorkemon™️ কার্ডেরই মালিক?

`GottaSnatchEmAll.total_cards` ইমপ্লিমেন্ট করুন, যা সংগ্রহের একটি অ্যারে নেয় এবং সব সংগ্রহ মিলিয়ে ভিন্ন ভিন্ন কার্ডের মোট সংখ্যা রিটার্ন করে।

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. শাইনিই জয় এনে দেয়

শিগগিরই আপনার ভাগ্নে আপনার সাথে দেখা করতে আসছে, আর আপনি তাকে মুগ্ধ করতে চান।
শিশুরা তো চকচকে জিনিস পছন্দ করে, তাই না?
Blorkemon™️ কার্ডও শাইনি হতে পারে!

`GottaSnatchEmAll.split_shiny_cards` ইমপ্লিমেন্ট করুন, যা একটি সংগ্রহ নেয় এবং সাজানো কার্ডের দুটি অ্যারে নিয়ে একটি টাপল রিটার্ন করে: একটিতে `"Shiny"` দিয়ে শুরু হওয়া সব কার্ড থাকে, আর অন্যটিতে থাকে বাকি কার্ডগুলো।

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
