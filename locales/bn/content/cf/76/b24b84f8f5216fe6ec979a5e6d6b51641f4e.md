# ইনস্টলেশন

## PowerShell ভাষা ট্র্যাকের প্রয়োজনীয়তা

Exercism-এর PowerShell ভাষা ট্র্যাকটি ব্যবহার করতে হলে আপনার সিস্টেমে নিচের জিনিসগুলো ইনস্টল থাকা দরকার:

- PowerShell বা Windows PowerShell Core
- Pester টেস্ট ও মক ফ্রেমওয়ার্ক মডিউল

(পুনশ্চ: PowerShell-এর সাপোর্ট শুধু জরুরি ফিক্স পর্যন্ত সীমাবদ্ধ। PowerShell Core নিয়মিত রক্ষণাবেক্ষণ করা হয় এবং এর ক্রস-প্ল্যাটফর্ম সাপোর্ট বেশি)

### PowerShell ইনস্টল করা

Windows 7 SP1 থেকে শুরু করে সব Windows অপারেটিং সিস্টেমে PowerShell আগে থেকেই ইনস্টল করা থাকে।

PowerShell-এর সর্বশেষ ভার্সন এবং সব প্ল্যাটফর্মের (Linux, macOS ও Windows) জন্য ইনস্টলেশনের নির্দেশনা [এখানে][installation] পাবেন।

[PowerShell][source-code]-এর সোর্স কোড ও ম্যানুয়াল ইনস্টলের ব্যবস্থাও আছে।

### Pester ফ্রেমওয়ার্ক ইনস্টল ও আপডেট করা

[Pester][pester] হলো PowerShell-এর টেস্টিং ফ্রেমওয়ার্ক।
4.0.9 ভার্সন থেকে এটি Windows, Linux ও MacOS-এ PowerShell Core-এর সাথে সামঞ্জস্যপূর্ণ (কিছু সীমাবদ্ধতা সহ)

এটি Windows 10-এ আগে থেকেই ইনস্টল করা থাকে, তবে নিচের PowerShell কমান্ডটি চালিয়ে আপডেট করে নেওয়ার পরামর্শ দেওয়া হচ্ছে:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

পরবর্তী আপডেটগুলোর জন্য চালান:

```PowerShell
Update-Module -Name Pester
```

প্রয়োজনে ইনস্টলেশনের আরও নির্দেশনা এখানে পাওয়া যাবে: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## একটি IDE ব্যবহার করা

আপনি যদি আরও পূর্ণাঙ্গ এডিটিং অভিজ্ঞতা চান, তাহলে সম্ভবত একটি IDE ব্যবহার করতে চাইবেন।
PowerShell প্রজেক্ট বিল্ড করতে পারে এমন সবচেয়ে জনপ্রিয় IDE-গুলো হলো:

### সব প্ল্যাটফর্মে

- [PowerShell ISE (Integrated Scripting Environment)][ise], PowerShell-এর সাথে আসা বিল্ট-ইন গ্রাফিক্যাল IDE (শুধু Windows)।
  PowerShell ISE চালু করতে একটি PowerShell কনসোলে `powershell_ise.exe` টাইপ করুন।
- [PowerShell এক্সটেনশন][vsc-extension] সহ [Visual Studio Code][vsc]।
  Visual Studio Code দিয়ে আপনি টেস্টও চালাতে পারবেন এবং নিজের কোড ডিবাগও করতে পারবেন।
- [PowerShell প্যাকেজ][sublime-package] সহ [Sublime Text 3][sublime]।
