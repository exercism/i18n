# পরিচিতি

জুলিয়ার একটি মূল লক্ষ্য হলো সংখ্যাগত ডেটার উপর দ্রুত ও দক্ষভাবে হিসাব করতে পারা। _প্রচুর_ সংখ্যাগত ডেটা।

সাধারণত ডেটা অ্যারেতে (বা সম্পর্কিত কোনো টাইপে) সংরক্ষণ করা হয়, তাই এটা বলা যায় যে অ্যারেগুলো জুলিয়া ভাষার একেবারে কেন্দ্রে রয়েছে।

অ্যারে যত বড় খুশি হতে পারে (একমাত্র সীমা হলো আপনার হার্ডওয়্যারের মেমোরি), আর এর ডাইমেনশনও যত খুশি হতে পারে।

এই পরিচিতিমূলক কনসেপ্টে মূলত এক-মাত্রিক অ্যারের মূল বিষয়গুলো নিয়ে আলোচনা করা হয়েছে, যাদের ভেক্টর বলা হয়।

## ভেক্টর তৈরি করা

জুলিয়ায় একটি ভেক্টর হলো মানের একটি সাজানো ক্রম, যার প্রতিটি মান ইনডেক্স নম্বর দিয়ে অ্যাক্সেস করা যায়।

ভেক্টর তৈরির সবচেয়ে সহজ উপায় হলো মানগুলো তৃতীয় বন্ধনীর মধ্যে তালিকা করে লেখা:

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

ভেক্টরের টাইপ প্রতিটি এলিমেন্টের টাইপের সাথে মেলে।

_তাহলে ভেক্টরগুলোকে হোমোজিনিয়াস হতে হবে (সব এলিমেন্ট একই টাইপের)?_

কোনো এক অর্থে হ্যাঁ, আর আপনি যদি সেরা পারফরম্যান্স চান, তবে এটাই লক্ষ্য রাখার পরামর্শ দেওয়া হয়।
তবে জুলিয়া প্রয়োজনে এই সীমাবদ্ধতা এড়িয়ে যেতে পারে `Any` টাইপ ব্যবহার করে:

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

খালি ভেক্টর তৈরি করার সময় জুলিয়া ডিফল্টভাবে এলিমেন্ট টাইপ হিসেবে `Any` নেয়, তবে পছন্দের এলিমেন্ট টাইপ দিয়ে খালি অ্যারেটি অ্যানোটেট করে এটিকে আরও নির্দিষ্টভাবে ঠিক করা যায়।

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# ইনডেক্সিং

অনুগ্রহ করে এই নিয়মটি পড়ুন এবং মনে রাখুন:

- ***ডিফল্টভাবে জুলিয়ায় ইনডেক্সিং শুরু হয় 1 থেকে, 0 থেকে নয়***।

যারা অন্য ডেটা সায়েন্স ভাষা (R, Matlab, Fortran...) ব্যবহার করেছেন তাদের কাছে এটি চেনা, তবে C-এর মতো ভাষার পটভূমি আছে এমন কম্পিউটার সায়েন্টিস্টদের কাছে এটি হতবাক করার মতো লাগতে পারে।

এছাড়া ইনডেক্স কাজ করে ঠিক যেভাবে আপনি ভাবতে পারেন: শুধু এগুলো তৃতীয় বন্ধনীর মধ্যে বসান:

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

লক্ষ্য করুন `end` দিয়ে ইনডেক্স করা কত সুবিধাজনক (যা খুবই কাজের) আর `begin` দিয়ে (যা সম্ভবত নয়)।

পাইথন প্রোগ্রামাররা হয়তো ঋণাত্মক ইনডেক্স নিয়ে ভাবছেন।
ভাববেন না: এগুলো জুলিয়ার অংশ নয়, আর এগুলো ব্যবহার করলে একটি `BoundsError` তৈরি হয়, ঠিক যেভাবে 1-এর চেয়ে ছোট বা `length(squares)`-এর চেয়ে বড় যেকোনো ইনডেক্স করলে হয়।

## ভেক্টরের অপারেশন

জুলিয়ায় ভেক্টরগুলো _মিউটেবল_: আমরা আলাদা আলাদা সেলের ভেতরের মান বদলে দিতে পারি।

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

ভেক্টর নিয়ে কাজ করার জন্য অনেক ফাংশন আছে, যদিও জুলিয়ার ডকুমেন্টেশনে এগুলোকে ভেক্টরের বদলে আরও সাধারণভাবে "কালেকশন" বলা হয়।

লক্ষ্য করুন, কনভেনশন অনুযায়ী যে ফাংশনগুলো নিজের ইনপুট মিউটেট করে তাদের নামে `!` থাকে।
কম্পাইলার এটি বাধ্যতামূলক করে না, তবে জুলিয়ার জগতে এটি একটি খুবই _জোরালো_ কনভেনশন।

এখানে এমন কয়েকটি কাজের ফাংশন দেওয়া হলো:

- ভেক্টরের শেষে মান যোগ করতে `push!()` ব্যবহার করুন।
- শেষের মানটি সরিয়ে ফেলতে `pop!()` ব্যবহার করুন।
- ভেক্টরের শুরুতে কাজ করতে সংশ্লিষ্ট ফাংশন দুটি হলো `pushfirst!()` আর `popfirst!()`।
- যেকোনো অবস্থানে একটি এলিমেন্ট যোগ বা মুছে ফেলতে আছে `insert!()` আর `deleteat!()`।

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
