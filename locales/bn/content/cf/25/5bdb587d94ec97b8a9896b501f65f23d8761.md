# স্ট্রিং মেথড

`String`-এ এমন বেশ কিছু মেথড আছে যেগুলো দিয়ে স্ট্রিং নিয়ে কাজ করা যায়।  
এই মেথডগুলো স্ট্রিংয়ের উপরেই কল করা হয় এবং একটি স্ট্রিংয়ের উপর একাধিক কাজ করার জন্য প্রায়ই এগুলো একসাথে চেইন করে ব্যবহার করা হয়।

নিচে সবচেয়ে কমন কিছু মেথডের তালিকা দেওয়া হলো।
সব মেথডের পূর্ণ তালিকার জন্য [`String` API ডকুমেন্টেশন][string-api] দেখুন।

## String#upcase ও String#downcase

[`upcase`][upcase] মেথডটি একটি নতুন স্ট্রিং রিটার্ন করে, যেখানে সব ক্যারেক্টার বড় হাতের অক্ষরে রূপান্তরিত থাকে।

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase] মেথডটি একটি নতুন স্ট্রিং রিটার্ন করে, যেখানে সব ক্যারেক্টার ছোট হাতের অক্ষরে রূপান্তরিত থাকে।

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize ও String#camelcase ও String#underscore ও String#titleize

কয়েকটি মেথড আরও নির্দিষ্ট কেস রূপান্তর করতে পারে।
কোনো স্ট্রিংকে নির্দিষ্ট একটি ফরম্যাটে রূপান্তর করার সময় এটা কাজে লাগতে পারে।
এখানে সবচেয়ে কমন কিছু মেথডের তালিকা দেওয়া হলো:

| মেথড                            | বিবরণ                                                                                                        | উদাহরণ                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | প্রথম অক্ষরটি বড় হাতের এবং বাকিগুলো ছোট হাতের করে                                                   | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | আন্ডারস্কোরকে ক্যামেলকেসে রূপান্তর করে                                                                                   | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | String#camelcase-এর মতোই, তবে প্রথম ক্যারেক্টারটি ছোট হাতের রাখে                                                 | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | সব ক্যারেক্টার ছোট হাতের করে এবং একটি ছোট হাতের অক্ষর ও একটি বড় হাতের অক্ষরের মাঝে আন্ডারস্কোর বসায় | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | প্রতিটি শব্দের প্রথম অক্ষর বড় হাতের এবং বাকিগুলো ছোট হাতের করে                                                   | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub ও String#gsub

স্ট্রিংয়ের অংশ প্রতিস্থাপন করার জন্য Crystal-এ মেথড আছে।
এগুলো হলো [`sub`][sub] (_substitution_) এবং [`gsub`][gsub] (_global substitution_)।

এই মেথডগুলো প্রথম আর্গুমেন্ট হিসেবে একটি স্ট্রিং, ক্যারেক্টার বা রেজেক্স নিতে পারে, আর দ্বিতীয় আর্গুমেন্ট হিসেবে একটি স্ট্রিং বা ক্যারেক্টার নিতে পারে।
প্রথম আর্গুমেন্টটি হলো স্ট্রিংয়ের যে অংশটি প্রতিস্থাপিত হবে, আর দ্বিতীয় আর্গুমেন্টটি হলো প্রতিস্থাপন।
`Char` ও রেজেক্স পরের কনসেপ্টগুলোতে ব্যাখ্যা করা হবে।

`sub` মেথডটি প্রথম আর্গুমেন্টটির প্রথম উপস্থিতিকে দ্বিতীয় আর্গুমেন্ট দিয়ে প্রতিস্থাপন করে।

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub` মেথডটি `sub`-এর মতোই কাজ করে, তবে প্রথম আর্গুমেন্টটির সব উপস্থিতিকে দ্বিতীয় আর্গুমেন্ট দিয়ে প্রতিস্থাপন করে।

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp ও String#strip

একটি স্ট্রিং থেকে অবাঞ্ছিত ক্যারেক্টার সরাতে Chomp ও strip ব্যবহার করা যায়।

[`chomp`][chomp] মেথডটি ডিফল্টভাবে একটি স্ট্রিং থেকে শেষের `\r`, `\n` বা `\r\n` ক্যারেক্টারগুলো সরিয়ে দেয়।
মেথডটি কোনো আর্গুমেন্ট দিয়ে কল করা হলে, সেটি স্ট্রিংয়ের শেষ থেকে প্রদত্ত মানটি সরিয়ে দেয়,
যদি সেটি স্ট্রিংয়ের শেষে থেকে থাকে।

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

ডিফল্টভাবে, [`strip`][strip] মেথডটি একটি স্ট্রিংয়ের শুরু ও শেষ থেকে সব হোয়াইটস্পেস সরিয়ে দেয়।
মেথডটি কোনো আর্গুমেন্ট দিয়ে কল করা হলে, সেটি স্ট্রিংয়ের শুরু ও শেষ থেকে ওই আর্গুমেন্টটি সরিয়ে দেয়,
যদি সেটি স্ট্রিংয়ের শুরুতে বা শেষে থেকে থাকে।

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

একটি স্ট্রিং উল্টো করতে আপনি [`reverse`][reverse] মেথডটি ব্যবহার করতে পারেন।
এই মেথডটি উল্টো ক্রমে সাজানো ক্যারেক্টারসহ একটি নতুন স্ট্রিং রিটার্ন করে।

```crystal
"hello".reverse
# => "olleh"
```

## String#index

স্ট্রিংয়ে একটি ক্যারেক্টারের ইনডেক্স খুঁজে বের করতে [`index`][index] মেথডটি ব্যবহার করা যায়।
`index` মেথডটি আর্গুমেন্ট হিসেবে একটি `String`, `Char` বা রেজেক্স নেয়।
কোন ইনডেক্স থেকে খোঁজা শুরু হবে তা নির্দিষ্ট করতে এটি ঐচ্ছিক একটি দ্বিতীয় আর্গুমেন্ট নিতে পারে।
`index` মেথডটি আর্গুমেন্টটির প্রথম উপস্থিতির ইনডেক্স রিটার্ন করে।

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

স্ট্রিং থেকে একটি ক্যারেক্টার সরাতে আপনি [`delete_at`][delete_at] মেথডটি ব্যবহার করতে পারেন।
`delete_at` মেথডটি আর্গুমেন্ট হিসেবে একটি ইনডেক্স নেয় এবং ওই ইনডেক্সের ক্যারেক্টারটি সরিয়ে দেয়।

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

নির্দিষ্ট কোনো ইনডেক্সে একটি স্ট্রিং ঢোকাতে [`insert`][insert] মেথডটি ব্যবহার করা যায়।
`insert` মেথডটি প্রথম আর্গুমেন্ট হিসেবে একটি ইনডেক্স এবং দ্বিতীয় আর্গুমেন্ট হিসেবে একটি স্ট্রিং নেয়।
`insert` মেথডটি ওই ইনডেক্সে দ্বিতীয় আর্গুমেন্টটি ঢুকিয়ে একটি নতুন স্ট্রিং রিটার্ন করে।

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
