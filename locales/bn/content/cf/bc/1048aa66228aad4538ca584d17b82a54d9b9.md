# নির্দেশনা

আপনি একটি সহজ অনলাইন গেম তৈরি করছেন, যেখানে একজন বন্ধু একটি গোপন সংখ্যা অনুমান করতে পারবে। আপনি কিছু প্রতিক্রিয়া দিতে চান, কিন্তু একটি অনুমানের মাধ্যমে উত্তরটি ফাঁস করতে চান না। অনুমানটি গোপন সংখ্যার সাথে কীভাবে সম্পর্কিত, তার উপর নির্ভর করে ভিন্ন ভিন্ন প্রতিক্রিয়া দেওয়ার জন্য আপনাকে একটি ফাংশন বানাতে হবে।

| শর্ত                                                          | প্রতিক্রিয়া   |
| ------------------------------------------------------------- | -------------- |
| যখন অনুমানটি গোপন সংখ্যার সাথে মিলে যায়                      | "Correct"      |
| যখন অনুমানটি গোপন সংখ্যার চেয়ে এক বেশি বা এক কম হয়          | "So close"     |
| যখন অনুমানটি গোপন সংখ্যার চেয়ে বড় হয়                        | "Too high"     |
| যখন অনুমানটি গোপন সংখ্যার চেয়ে ছোট হয়                        | "Too low"      |
| যখন কোনো অনুমান করা হয় না                                     | "Make a guess" |

সব অনুমান ও গোপন সংখ্যাই ইন্টিজার সংখ্যা।

## 1. অনুমানটি গোপন সংখ্যার সাথে মিললে প্রতিক্রিয়া তৈরি করুন

`compare/2` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: `secret_number` এবং `guess`, যেগুলো দুটোই ইন্টিজার।

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. অনুমানটি গোপন সংখ্যার চেয়ে বড় হলে প্রতিক্রিয়া তৈরি করুন

`compare` ফাংশনটি পরিবর্তন করুন, যাতে এটি গোপন সংখ্যার চেয়ে বড় অনুমানগুলোর প্রতিক্রিয়া দিতে পারে।

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. অনুমানটি গোপন সংখ্যার চেয়ে ছোট হলে প্রতিক্রিয়া তৈরি করুন

`compare` ফাংশনটি পরিবর্তন করুন, যাতে এটি গোপন সংখ্যার চেয়ে ছোট অনুমানগুলোর প্রতিক্রিয়া দিতে পারে।

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. অনুমানটি গোপন সংখ্যার চেয়ে এক বেশি বা এক কম হলে প্রতিক্রিয়া তৈরি করুন

`compare` ফাংশনটি পরিবর্তন করুন, যাতে এটি গোপন সংখ্যার কাছাকাছি অনুমানগুলোর প্রতিক্রিয়া দিতে পারে।

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. কোনো অনুমান না থাকলে প্রতিক্রিয়া তৈরি করুন

`compare` ফাংশনটি পরিবর্তন করুন, যাতে কোনো অনুমান না থাকলেও এটি প্রতিক্রিয়া দিতে পারে।

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
