# পরিচিতি

একটি ফাংশন আপনাকে কোডকে পুনর্ব্যবহারযোগ্য একটি এককে গুছিয়ে রাখার সুযোগ দেয়।
এটি গঠিত হয় `func` কিওয়ার্ড, ফাংশনের নাম, এবং প্রথম বন্ধনীর মধ্যে কমা দিয়ে আলাদা করা শূন্য বা তার বেশি প্যারামিটার ও টাইপের তালিকা নিয়ে।

## ফাংশন প্যারামিটার

সব প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হয়; প্যারামিটারের জন্য কোনো টাইপ ইনফারেন্স নেই।
প্যারামিটারের জন্য কোনো ডিফল্ট মান নেই, তাই ফাংশনের সব প্যারামিটারই আবশ্যক।

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

একই টাইপের প্যারামিটারগুলো একসাথে ডিক্লেয়ার করা যায়, যার পরে একটিমাত্র টাইপ ডিক্লারেশন থাকে।

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## প্যারামিটার বনাম আর্গুমেন্ট

চলুন সংক্ষেপে দুটি পরিভাষা জেনে নিই, যেগুলো প্রায়ই একসাথে গুলিয়ে ফেলা হয়: `parameters` এবং `arguments`।
ফাংশন প্যারামিটার হলো ফাংশনের সিগনেচারে ডিফাইন করা সেই নামগুলো, যেমন উপরের `PrintGreetingName` ফাংশনে `greeting` ও `name`।
ফাংশন আর্গুমেন্ট হলো সেই নির্দিষ্ট মানগুলো, যেগুলো আমরা ফাংশন কল করার সময় ফাংশন প্যারামিটারে পাঠাই।
যেমন, নিচের উদাহরণে `"Hello"` ও `"Katrina"` হলো `greeting` ও `name` প্যারামিটারে পাঠানো আর্গুমেন্ট:

```go
PrintGreetingName("Hello", "Katrina")
```

## রিটার্ন ভ্যালু

ফাংশন প্যারামিটারের পরে থাকে শূন্য বা তার বেশি রিটার্ন ভ্যালু, যেগুলোর টাইপও স্পষ্টভাবে উল্লেখ করতে হয়।
একটিমাত্র রিটার্ন ভ্যালু বন্ধনী ছাড়াই লেখা হয়, আর একাধিক রিটার্ন ভ্যালু বন্ধনীর মধ্যে রাখা হয়।
`return` কিওয়ার্ড ব্যবহার করে ফাংশন থেকে কল করা কোডে মান রিটার্ন করা হয়।
একটি ফাংশনে একাধিক `return` স্টেটমেন্ট থাকতে পারে।
ফাংশনের এক্সিকিউশন সেই `return` স্টেটমেন্টগুলোর যেকোনো একটিতে পৌঁছালেই শেষ হয়ে যায়।
যদি একটি ফাংশন থেকে একাধিক মান রিটার্ন করতে হয়, তাহলে সেগুলো কমা দিয়ে আলাদা করা হয়।

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## ফাংশন কল করা

ফাংশন কল করা হয় এভাবে: ফাংশনের নাম লিখে এবং প্রথম বন্ধনীর মধ্যে ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## নামযুক্ত রিটার্ন ভ্যালু ও নেকেড রিটার্ন

প্যারামিটারের মতো রিটার্ন ভ্যালুগুলোও চাইলে নামযুক্ত করা যায়।
যদি নামযুক্ত রিটার্ন ভ্যালু ব্যবহার করা হয়, তাহলে আর্গুমেন্ট ছাড়া একটি `return` স্টেটমেন্ট সেই মানগুলোই রিটার্ন করবে।
এটিকে 'নেকেড' রিটার্ন বলা হয়।

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
