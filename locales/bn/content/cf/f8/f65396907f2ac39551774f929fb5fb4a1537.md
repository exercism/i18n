# ভূমিকা

এই অনুশীলনীতে আপনাকে শর্তসাপেক্ষে লজিক রান করতে হবে। C#-এ এটি করার সবচেয়ে কমন উপায় হলো একটি `if/else` স্টেটমেন্ট ব্যবহার করা:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

একটি `if` স্টেটমেন্টের শর্ত অবশ্যই `bool` টাইপের হতে হবে। C#-এ _truthy_ মানের কোনো ধারণা নেই।
