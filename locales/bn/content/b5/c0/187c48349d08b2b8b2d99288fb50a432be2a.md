# নির্দেশনা

আপনার কাজ হলো একটি গেমের স্কোরারদের একটি তালিকা নিয়ে, প্রতিটি খেলোয়াড় কত গোল করেছে তা গুনে বের করা।

`PlayerName` হলো `String`-এর একটি টাইপ অ্যালিয়াস, যা কোডকে পড়তে সহজ করে তোলে এবং `String`-এর এই ব্যবহারটিকে `String`-এর অন্য ব্যবহারগুলো থেকে আলাদা করে।

## 1. স্কোরারদের একত্র করা

প্রথমে `updateGoalCountForPlayer` ইমপ্লিমেন্ট করুন, যা একজন খেলোয়াড়ের গোলের সংখ্যা ইনিশিয়ালাইজ করে বা ইনক্রিমেন্ট করে।
তারপর `aggregateScorers` ফাংশনটি ইমপ্লিমেন্ট করুন, যাতে `updateGoalCountForPlayer` ব্যবহার করে প্রতিটি খেলোয়াড় কত গোল করেছে তা গোনা যায়।
এই ফাংশনটি একটি `List PlayerName` নেয় (গোল করা খেলোয়াড়দের নাম, যেখানে একই খেলোয়াড়ের নাম একাধিকবার থাকতে পারে), এবং একটি `Dict PlayerName Int` রিটার্ন করে, যেখানে তালিকার সব খেলোয়াড় এবং তারা কত গোল করেছে তা থাকে।

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. নগণ্য খেলোয়াড়দের বাদ দেওয়া

`removeInsignificantPlayers` ফাংশনটি ইমপ্লিমেন্ট করুন, যাতে থ্রেশহোল্ডের চেয়ে কম গোল করা যেকোনো খেলোয়াড়কে ছেঁটে বাদ দেওয়া যায়।

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. খেলোয়াড়ের গোলের সংখ্যা রিসেট করা

`resetPlayerGoalCount` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একজন খেলোয়াড়ের করা গোলের সংখ্যা শূন্যে রিসেট করে।

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. একজন খেলোয়াড়ের গোলের সংখ্যা ফরম্যাট করা

একজন খেলোয়াড়ের গোলের সংখ্যাকে স্ট্রিং হিসেবে ফরম্যাট করার জন্য `formatPlayer` ফাংশনটি ইমপ্লিমেন্ট করুন। ডিক্টে খেলোয়াড়টি না থাকলে ধরে নিন তার গোলের সংখ্যা শূন্য।

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. সব খেলোয়াড়ের গোলের সংখ্যা ফরম্যাট করা

সব খেলোয়াড়ের গোলের সংখ্যাকে স্ট্রিং হিসেবে ফরম্যাট করার জন্য `formatPlayers` ফাংশনটি ইমপ্লিমেন্ট করুন। খেলোয়াড়দের নাম অনুযায়ী সাজানো থাকা উচিত।

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. গেমগুলো একত্র করা

`combineGames` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুই গেমে প্রতিটি খেলোয়াড় মোট কত গোল করেছে তা গুনে বের করে।

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
