# ভূমিকা

অবজেক্ট ইনিশিয়ালাইজার হলো কনস্ট্রাক্টরের একটি বিকল্প। নিচে সিনট্যাক্সটি দেখানো হয়েছে। আপনি দ্বিতীয় বন্ধনীর ভেতরে `=` দিয়ে আলাদা করা নাম-মান জোড়াগুলোর একটি কমা-বিভক্ত তালিকা দেন:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

কালেকশনও এই পদ্ধতিতে ইনিশিয়ালাইজ করা যায়। সাধারণত এটি কমা-বিভক্ত তালিকা দিয়ে করা হয়, যেমনটি এখানে দেখানো হয়েছে:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

ডিকশনারি নিম্নলিখিত সিনট্যাক্স ব্যবহার করে:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
