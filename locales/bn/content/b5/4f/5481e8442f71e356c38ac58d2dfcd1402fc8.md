# ভূমিকা

## অ্যারে

JSON একটি **অ্যারে**-কে এভাবে সংজ্ঞায়িত করে:

> অ্যারে হলো মানের একটি ক্রমবদ্ধ সংগ্রহ।
> অ্যারে শুরু হয় `[` বাম বন্ধনী দিয়ে এবং শেষ হয় `]` ডান বন্ধনী দিয়ে।
> মানগুলো `,` কমা দিয়ে আলাদা করা হয়।

অ্যারেতে _যেকোনো ধরনের_ JSON মান শূন্য বা তার বেশি থাকতে পারে।
অ্যারের এলিমেন্টগুলোর সবগুলো একই টাইপের হওয়া জরুরি নয়।

### অ্যারে তৈরি করা

এলিমেন্টগুলোকে একটি অ্যারেতে জড়ো করতে বন্ধনী ব্যবহার করুন।

```jq
[1, 2, 3]
```

কোনো _স্ট্রিম_-এর এলিমেন্টগুলোকে বন্ধনীতে ঘিরে একটি অ্যারেতে ধরে রাখা যায়।

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### আকার

`length` ফাংশনটি একটি অ্যারের এলিমেন্টের সংখ্যা রিটার্ন করে।

### ইনডেক্সিং ও স্লাইসিং

অ্যারের ইনডেক্সিং শূন্য থেকে শুরু হয়।

বন্ধনী এক্সপ্রেশন দিয়ে একটি অ্যারে থেকে এলিমেন্ট পাওয়া যায়:
`.[2]` তৃতীয় এলিমেন্টটি দেয়।

ঋণাত্মক ইনডেক্স অ্যারের শেষ থেকে পিছনের দিকে গোনে:
`.[-1]` শেষ এলিমেন্টটি দেয়; `.[-2]` হলো শেষ থেকে দ্বিতীয়টি।

একটি **স্লাইস** হলো অ্যারের একটি ধারাবাহিক অংশ।
`.[10:15]` ইনডেক্স 10 থেকে শুরু করে 5টি এলিমেন্ট রিটার্ন করে; শেষ ইনডেক্সটি _অন্তর্ভুক্ত নয়_।

কয়েকটি সুবিধাজনক ফাংশন আছে:

- `first` প্রথম এলিমেন্টটি দেয়।
- `last` শেষ এলিমেন্টটি দেয়।
- `nth(n)` ইনডেক্স `n`-এ থাকা এলিমেন্টটি দেয়।

### ইটারেশন করা

কমন ইটারেশনের কাজগুলো সামলানোর জন্য `jq` অনেক ফাংশন দেয়:

- `map(expr)` একটি নতুন অ্যারে রিটার্ন করে, যেখানে `expr` পালাক্রমে প্রতিটি এলিমেন্টে প্রয়োগ করা হয়।

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` হলো এমন একটি ফাংশন যা `expr`-কে একটি _একক মান_-এ প্রয়োগ করে;
  এক্সপ্রেশনের ফলাফল ট্রু হলে মানটি রিটার্ন করা হয়;
  ফলাফল ফলস হলে _কিছুই_ রিটার্ন করা হয় না, `null` নয়, সত্যিকার অর্থে কিছুই না।

  এটি একটি অ্যারেতে প্রয়োগ করতে `map`-এর সঙ্গে মিলিয়ে ব্যবহার করুন।

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  অন্যভাবে, `select`-কে একটি _স্ট্রিম_-এ প্রয়োগ করে ফলাফলগুলো সংগ্রহ করুন।

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` ও `all(condition)` একটি বুলিয়ান মান রিটার্ন করে, যা জানায় অ্যারের এলিমেন্টগুলোর যেকোনোটি/সবগুলো শর্তটি পাস করে কি না।

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
