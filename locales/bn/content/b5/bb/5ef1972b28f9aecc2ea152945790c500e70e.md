# নির্দেশাবলি

`classes` অনুশীলনীতে আপনি যে রিমোট কন্ট্রোল কার প্রকল্পটি শুরু করেছিলেন সেটি ভালোভাবেই এগিয়েছে (অভিনন্দন!), আর সম্প্রতি বেশ কিছু স্পনসরশিপ চুক্তির সুবাদে উন্নয়নের জন্য বাজেটে টাকা এসেছে।

বাজেটের একটি অংশ ব্যবহার করা হচ্ছে কিছু টেলিমেট্রি সরবরাহ করতে।

স্পনসরদের খুশি রাখতে গাড়িটিতে একটি প্যানেল বসানো হয়েছে, যা ট্র্যাকের চারপাশে ঘোরার সময় স্পনসরদের নাম দেখাবে।

আপনি খেয়াল করবেন, এই ফ্যান্সি নতুন প্রযুক্তিগুলো চালু হওয়ায় গাড়িটির ব্যাটারি লাইফ নাটকীয়ভাবে কমে গেছে।

## 1. রিমোট কন্ট্রোল কার যাতে স্পনসরদের নাম দেখাতে পারে সেই সুবিধা দিন

এক বা একাধিক স্পনসরের নাম নিয়ে সেগুলো গাড়িতে সংরক্ষণ করতে `SetSponsors()` ইমপ্লিমেন্ট করুন।

মনে রাখবেন, `SetSponsors()` মেথডের আর্গুমেন্ট কখনোই null হবে না।

নির্বাচিত স্পন্সরটি দেখাতে `DisplaySponsor()` ইমপ্লিমেন্ট করুন। প্রথম যে স্পন্সরটি পাস করা হয় তার `sponsorNum` হয় 0, দ্বিতীয়টির 1, এভাবে চলতে থাকে।

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. গাড়ির টেলিমেট্রি ডেটা নিন

`RemoteControlCar.GetTelemetryData()` মেথডটি ইমপ্লিমেন্ট করুন।

`GetTelemetryData()` যেন `out` প্যারামিটারের মাধ্যমে ব্যাটারি পার্সেন্টেজ এবং মিটারে অতিক্রান্ত দূরত্ব available করে, তা নিশ্চিত করবে।

serialNum আর্গুমেন্ট আগে পাওয়া মানের চেয়ে ছোট হলে `GetTelemetryData()` `false` রিটার্ন করবে। (এখানে একাধিক টেলিমেট্রি নোড জড়িত থাকার একটি সমস্যা আছে)। এক্ষেত্রে `serialNum`-এর মান আগের সবচেয়ে বড় `serialNum` হিসেবে সেট হবে, আর ব্যাটারি পার্সেন্টেজ ও অতিক্রান্ত মিটার দুটোই `-1` হিসেবে সেট হবে। কলটি সফল হলে `serialNum` অপরিবর্তিত থাকে।

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. টেলিমেট্রি সিস্টেম যাতে প্রতি মিটারে ব্যাটারি ব্যবহার জানতে পারে সেই সুবিধা যোগ করুন

`TelemetryClient.GetBatteryUsagePerMeter()` মেথডটি ইমপ্লিমেন্ট করুন।

এটি `RemoteControlCar.GetTelemetryData()` কল করবে। `GetTelemetryData()` `false` রিটার্ন করলে বা গাড়ি চালানো না হয়ে থাকলে, এই রুটিনটি "no data" রিটার্ন করবে। `GetTelemetryData()` `true` রিটার্ন করলে নিচের ধরনের একটি মেসেজ রিটার্ন করতে হবে: "usage-per-meter=BATTERY-USAGE-PER-METER"। এখানে হিসাবটি হলো, (100 - বর্তমান ব্যাটারি পার্সেন্টেজ) কে এখন পর্যন্ত অতিক্রান্ত দূরত্বের (মিটারে) দ্বারা ভাগ করা হয়।

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
