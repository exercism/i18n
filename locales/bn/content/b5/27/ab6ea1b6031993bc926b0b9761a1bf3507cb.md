# নির্দেশাবলী

যে দিনটির জন্য আপনি এতদিন অপেক্ষা করেছিলেন, সেটি অবশেষে এসে গেছে, আর এখন আপনি আল্পসের বুকে একটি সুন্দর খামারের গর্বিত মালিক।

তবুও সকালে খুব ভোরে উঠে গরুগুলোকে খাবার দেওয়া আপনার এখনও ভালো লাগে না।
যেহেতু আপনি একজন দুর্দান্ত ইঞ্জিনিয়ার, তাই আপনি একটি ফিড ডিসপেনসার বানালেন, `FEED-M-ALL`।

আপনার প্রজেক্ট শেষ করার জন্য শেষ যে জিনিসটির দরকার, সেটি হলো এমন এক টুকরো কোড, যা হিসাব করে প্রতিটি গরু কতটুকু ফিড পাবে।
প্রতিটি গরু যেন সমান পরিমাণ পায়, সেটি জরুরি, আর দ্বন্দ্ব এড়ানোও দরকার।
গরুগুলো খুবই সংবেদনশীল।

ভাগ্য ভালো, ফিডের পরিমাণ হিসাব করার সব ফর্মুলা আপনাকে নিজে বের করতে হবে না।
আপনি ইন্টারনেটে পাওয়া এক রহস্যময় এক্সটার্নাল লাইব্রেরি ব্যবহার করেন।
এটি নাকি সবচেয়ে সুখী গরু এনে দেবে।
লাইব্রেরিটি এমন একটি ক্লাস প্রকাশ করে, যা নিচের ইন্টারফেসটি পূরণ করে।
নিজে লেখা কোডে আপনি এটির উপরেই ভরসা করবেন।

```crystal
class FodderCalculator
  def fodder_amount! : Number 
  end

  def fattening_factor! : Number
  end
end
```

কোড নিয়ে কাজ করার সময় আপনি এরর হ্যান্ডলিং আরও উন্নত করবেন, যাতে এটি আরও মজবুত হয় এবং পরে খামারের দৈনন্দিন কাজে ব্যবহার করার সময় debug করা সহজ হয়।

## 1. খাদ্য সমানভাবে ভাগ করুন

সবার আগে আপনি এমন কোড লেখায় মন দেন, যা দিয়ে প্রতি গরুর ফিডের পরিমাণ হিসাব করা যায়।

এমন একটি মেথড `TheFarm.divide_food` লিখুন, যা আর্গুমেন্ট হিসেবে একটি `FodderCalculator` অবজেক্ট এবং ইন্টিজার হিসেবে গরুর সংখ্যা নেয়।
*এই কাজে ধরে নিন, পাঠানো গরুর সংখ্যা সবসময় শূন্যের চেয়ে বেশি।*
মেথডটি প্রতি গরুর খাদ্যের পরিমাণ রিটার্ন করবে।

হিসাব করতে হলে প্রথমে সব গরুর জন্য মোট ফিডের পরিমাণ বের করতে হবে।
এটি করা হয় `fodder_amount!` মেথডটি কল করে এবং গরুর সংখ্যাটি পাস করে।
এর সঙ্গে লাগবে একটি ফ্যাক্টর, যা দিয়ে এই পরিমাণ গুণ করতে হবে।
এই ফ্যাক্টরটি আপনি পান `fattening_factor!` মেথডটি কল করে।
এই দুটি মান আর গরুর সংখ্যা দিয়ে এখন আপনি প্রতি গরুর খাদ্যের পরিমাণ হিসাব করতে পারেন (`float64` হিসেবে)।

আপনি যে মেথডগুলো কল করেন, তাদের কোনোটি যদি একটি এরর রিটার্ন করে, তবে এক্সিকিউশন থেমে যাবে এবং `0` রিটার্ন করবে।

```crystal
fodder_calculator = FodderCalculator.new(50, 1.5)
TheFarm.divide_food(fodder_calculator, 5)
# => 15.0

fodder_calculator = FodderCalculator.new(50, nil)
TheFarm.divide_food(fodder_calculator, 5)
# => 0
```

## 2. গরুর সংখ্যা যাচাই করুন

উপরের প্রথম কাজটি করতে গিয়ে আপনি বুঝতে পারেন, যে এক্সটার্নাল লাইব্রেরিটি ব্যবহার করছেন, সেটি আপনার ভাবনার মতো ভালো মানের নয়।
যেমন, এটি ইনভ্যালিড ইনপুট ঠিকভাবে হ্যান্ডল করতে পারে না।
নিজের কোডে ইনপুট মানের একটি যাচাই যোগ করে আপনি এই সীমাবদ্ধতাটি পাশ কাটাতে চান।

এমন একটি ফাংশন লিখুন, `TheFarm.validate_input_and_divide_food`, যার সিগনেচার উপরের `TheFarm.divide_food`-এর মতোই।

- পাঠানো গরুর সংখ্যা 0-এর বেশি হলে ফাংশনটি `TheFarm.divide_food` কল করবে এবং সেই কলে যা রিটার্ন আসে তা ফেরত দেবে।
- গরুর সংখ্যা 0 বা তার কম হলে ফাংশনটি `"Number of cows must be greater than 0"` বার্তা দিয়ে একটি এরর রেইজ করবে।

```crystal
TheFarm.validate_input_and_divide_food(fodderCalculator, 5)
# => 15

TheFarm.validate_input_and_divide_food(fodderCalculator, -2)
# Error: Number of cows must be greater than 0
```

## 3. এরর হ্যান্ডলিং উন্নত করুন

পাঠানোর আগে গরুর সংখ্যা যাচাই করা ভালো পদক্ষেপ ছিল, তবে অস্পষ্ট এরর বার্তাটি নিয়ে আপনি পুরোপুরি সন্তুষ্ট নন।
আপনি ঠিক করেন আরও ভালো কিছু করবেন, আর সেজন্য `InvalidCowsError` নামে একটি কাস্টম এরর ক্লাস বানাবেন।

কাস্টম এররটিতে থাকবে গরুর সংখ্যা (`Int32`) এবং একটি কাস্টম বার্তা (`String`), আর `Expection` মেথডটি ডেটাটি নিচের ফরম্যাটে সিরিয়ালাইজ করবে:
```txt
{number of cows} cows are invalid: {custom message}
```

কাস্টম এররটি হাতে নিয়ে এখন এমন একটি ফাংশন লিখুন, `TheFarm.validate_number_of_cows`, যা ইন্টিজার হিসেবে গরুর সংখ্যা নেয় এবং একটি এরর (বা nil) রিটার্ন করে।

- গরুর সংখ্যা 0-এর কম হলে ফাংশনটি একটি `InvalidCowsError` রিটার্ন করে, যার কাস্টম বার্তা থাকে `"there are no negative cows"`।
- গরুর সংখ্যা 0 হলে ফাংশনটি একটি `InvalidCowsError` রিটার্ন করে, যার কাস্টম বার্তা থাকে `"no cows don't need food"`।
- অন্যথায় ফাংশনটি `nil` রিটার্ন করে, যা বোঝায় যাচাই সফল হয়েছে।

```crystal
TheFarm.validate_number_of_cows(5)
# => nil

TheFarm.validate_number_of_cows(-5)
# => InvalidCowsError: -5 cows are invalid: there are no negative cows
```

এই ভ্যালিডেশন ফাংশনটি দাঁড় করানোর কঠিন পরিশ্রমের পর আপনি খেয়াল করেন, সন্ধ্যা হয়ে গেছে; তাই ডেস্ক ছেড়ে পাহাড়ের উপরে সূর্যাস্ত উপভোগ করতে চলে যান।
নতুন ভ্যালিডেশন ফাংশনটি সত্যিই কোডে যোগ করার কাজটি আপনি অন্য এক দিনের জন্য তুলে রাখেন।
