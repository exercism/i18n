# ইঙ্গিত

## সাধারণ

- `accessors` স্বয়ংক্রিয়ভাবে তৈরি হওয়া `slot>>` গেটার, `>>slot` সেটার আর `change-slot` আপডেটার দেয়।
- সেটার আর `change-slot` টিউপলটি *মিউটেট* করে। আসল টিউপলটি অক্ষত রেখে আপডেট করতে চাইলে আগে `clone` করুন।

## 1. `player` টিউপল ডিফাইন করুন

- স্লট সিনট্যাক্স হলো `TUPLE: …  ;`-এর ভেতরে `{ name initial: value }`.
- `initial:` অংশ ছাড়া স্লটের ডিফল্ট মান `f`.

## 2. প্লেয়ারের সাথে পরিচয় করিয়ে দিন

- `name>>` পড়ে `name` স্লট।
- [`kernel`][kernel]-এর `unless*` হলো "`f` হলে ডিফল্ট" বোঝানোর কৌশল।

## 3. পতিত প্লেয়ারকে আবার জীবিত করুন

- `health>>` স্লট পড়ে; [`math`][math]-এর `zero?` শূন্য কিনা পরীক্ষা করে।
- `clone`-এর পর `100 >>health` আর `100 >>mana` দিয়ে নতুন প্লেয়ার তৈরি করুন।
- "এখনও জীবিত" ক্ষেত্রে `f` রিটার্ন করুন।

## 4. ড্যামেজ নিন

- `change-health` একটি কোশন `( old-health -- new-health )` গ্রহণ করে।
- একটি ফ্রাই কোশন `'[ _ - 0 max ]` ([`math.order`][math.order] থেকে পাওয়া `max` সহ) দিয়ে হয় "ধরা ড্যামেজ বিয়োগ করে মান শূন্যে সীমাবদ্ধ রাখা"।
- মিউটেট করার আগে `clone` করতে ভুলবেন না।
