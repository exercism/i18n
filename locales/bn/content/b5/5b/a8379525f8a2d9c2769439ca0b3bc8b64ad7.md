# বিস্তারিত

Haxe টাইপ ও ফিল্ডের রানটাইম রিফ্লেকশন সাপোর্ট করে। রিফ্লেকশন সঠিকভাবে ব্যবহার করতে হলে কোন ধরনের অপারেশন সাপোর্ট করে আর কোনটি করে না, সেটি বুঝে নেওয়া জরুরি। রিফ্লেকশনের ডাইনামিক প্রকৃতির কারণে এটি সবসময় কম্পাইল-টাইমে নির্ধারণ করা যায় না।

রিফ্লেকশন API-তে দুটি ক্লাস রয়েছে:

- `Reflect`: একটি হালকা API, যা অ্যানোনিমাস স্ট্রাকচারে সবচেয়ে ভালো কাজ করে, তবে ক্লাসের জন্য সাপোর্ট সীমিত।
- `Type`: ক্লাস ও এনাম নিয়ে কাজ করার জন্য আরও নির্ভরযোগ্য একটি API।

কোন কোন মেথড ব্যবহার করা যায়, তার বিস্তারিত বিবরণ রয়েছে [Reflect][reflect] ও [Type][type]-এর API-তে।

নিচের উদাহরণে আমরা JavaScript টার্গেট ব্যবহার করছি:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
