# পরিচিতি

## অবজেক্ট

একটি JSON **অবজেক্ট** হলো, অন্য ভাষার পরিভাষায় বললে, একটি "hash", "map" বা "dictionary"।

JSON একটি _অবজেক্ট_-কে এভাবে সংজ্ঞায়িত করে:

> একটি অবজেক্ট হলো **নাম**/**মান** জোড়ার একটি অবিন্যস্ত সেট।
> একটি অবজেক্ট `{` বাম ব্রেস দিয়ে শুরু হয় এবং `}` ডান ব্রেস দিয়ে শেষ হয়।
> প্রতিটি _নাম_-এর পরে `:` কোলন থাকে এবং _নাম/মান_ জোড়াগুলো `,` কমা দিয়ে আলাদা করা হয়।

_নাম_ **অবশ্যই একটি স্ট্রিং হতে হবে**।
_নাম_-এর আরেকটি প্রতিশব্দ হলো _কী_ (key)।

_মান_ যেকোনো JSON টাইপের হতে পারে।
একই অবজেক্টের ভিন্ন ভিন্ন _মান_ ভিন্ন ভিন্ন টাইপের হতে পারে, যেমন এই উদাহরণে।

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

মনে রাখবেন, _শেষ_ কী (key)-ভ্যালু জোড়ার পরে **কোনো কমা থাকা যাবে না**।

### অবজেক্ট তৈরি করা

নাম/মান জোড়াগুলো একত্র করতে ব্রেস ব্যবহার করুন।
নামগুলো স্ট্রিং হতে হলেও, নামগুলো **আইডেন্টিফায়ার-সদৃশ** (আলফানিউমেরিক ক্যারেক্টার আর আন্ডারস্কোর দিয়ে গঠিত, এবং কোনো ডিজিট দিয়ে শুরু হয়নি) হলে সেগুলো কোট করার দরকার নেই।

```jq
{name: "Jane", age: 42}
```

_আইডেন্টিফায়ার-সদৃশ_ নয় এমন কী (key) ব্যবহার করাও বৈধ।
শুধু সেগুলো কোট করে দিন।

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

নাম যদি কোনো এক্সপ্রেশনের ফলাফল হয়, তাহলে এক্সপ্রেশনটি **অবশ্যই** বন্ধনীর ভিতরে থাকতে হবে।

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### ইনডেক্সিং

**ডট নোটেশন** দিয়ে অবজেক্ট থেকে মান বের করা হয়।

```jq
{name: "Jane", age: 42} | .age    # => 42
```

কোনো কী (key)-কে আইডেন্টিফায়ার হিসেবে উল্লেখ করতে না পারলে **ব্র্যাকেট নোটেশন** ব্যবহার করুন।

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### কী (key)-ভ্যালু জোড়া যোগ করা বা পরিবর্তন করা

একটি অ্যারেতে নতুন একটি কী (key)-ভ্যালু জোড়া যোগ করতে, বা বিদ্যমান কোনো কী (key)-এর মান হালনাগাদ করতে, বাম দিকে একটি ইনডেক্স এক্সপ্রেশন দিয়ে `=` অ্যাসাইনমেন্ট অপারেটর ব্যবহার করুন।

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+` অপারেটর অবজেক্টগুলোকে _মার্জ_ করবে।

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### একটি কী (key) মুছে ফেলা

একটি কী (key) মুছে ফেলতে `del` ফাংশন ব্যবহার করুন।
এটি হালনাগাদ হওয়া অবজেক্টটি রিটার্ন করে।

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

`del`-এর প্যারামিটার হলো একটি **ইনডেক্স এক্সপ্রেশন** (ডট বা ব্র্যাকেট নোটেশন ব্যবহার করে) যা অবজেক্টের একটি কী (key) নির্দেশ করে।
`jq` এটাকে **পাথ এক্সপ্রেশন** বলে।
শুধু একটি স্ট্রিং দিলেই হয় না।

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### সদস্যপদ

- অবজেক্টে কোনো কী (key) আছে কি না পরীক্ষা করতে `has` ফাংশন ব্যবহার করুন।

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- `in` দিয়ে পরীক্ষা করুন, কোনো কী (key) অবজেক্টে আছে কি না।

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### সব কী (key) তালিকাভুক্ত করা

সব কী (key)-এর একটি তালিকা আউটপুট করতে `keys` ফাংশন ব্যবহার করুন।

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

লক্ষ্য করুন, `keys` কী (key)গুলোকে _সর্ট_ করে দেয়।
আসল ক্রমে কী (key)গুলো পেতে `keys_unsorted` ব্যবহার করুন।

সব _মান_ তালিকাভুক্ত করার মতো কোনো সমতুল্য ফাংশন নেই।
তবে `.[]` ফিল্টার অবজেক্টের মানগুলো একটি _স্ট্রিম_ হিসেবে আউটপুট করে, আর সেই স্ট্রিমকে `[...]` অ্যারে কনস্ট্রাক্টর দিয়ে ধরে রাখা যায়।

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### ইটারেশন

- `map_values(filter)` ফাংশনটি অবজেক্টের প্রতিটি _মান_-এ ফিল্টারটি প্রয়োগ করে।

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- একটি অবজেক্টের উপর ইটারেট করতে হলে প্রথমে সেটিকে কী (key)-ভ্যালু অবজেক্টের একটি অ্যারে-তে রূপান্তর করতে হবে।
  `to_entries` ফাংশন সেটাই করে।

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  এই মুহূর্তে আমরা `map`-এর মতো অ্যারে ইটারেশন ফাংশন ব্যবহার করতে পারি।

- `from_entries` ফাংশনটি এর বিপরীত: কী (key)-ভ্যালু অবজেক্টের একটি অ্যারেকে একটি অবজেক্টে রূপান্তর করা।

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- একটি অবজেক্টের _প্রতিটি_ কী (key)-ভ্যালু জোড়ায় একটি ফিল্টার প্রয়োগ করতে `with_entries(filter)` ফাংশন ব্যবহার করুন।

  উদাহরণস্বরূপ, একটি নামকে একটি বয়সের সাথে ম্যাপ করা একটি অবজেক্ট দেওয়া থাকলে, কী (key) আর মানগুলোকে এভাবে অদলবদল করা যায়।

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  আউটপুট:

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` হলো নিচেরটির সমান:

  ```jq
  to_entries | map(filter) | from_entries
  ```
