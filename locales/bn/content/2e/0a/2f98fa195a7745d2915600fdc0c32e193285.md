# সম্পর্কে

Rust-এ, ইটারেটার হলো এমন যেকোনো মান যা [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) ট্রেইট ইমপ্লিমেন্ট করে।
ইটারেটারের মানগুলো ইটারেটারের উপর `next` মেথড কল করে ম্যানুয়ালি এগিয়ে নেওয়া যায়।

```rust
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // many built-in methods implemented
}
```

Rust-এর অনেক [`collections`](https://doc.rust-lang.org/std/collections/index.html) [`IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html) ইমপ্লিমেন্ট করে, যা কালেকশনের মান থেকে একটি `Iterator` তৈরি করতে পারে।

```rust
trait IntoIterator where Self::IntoIter: Iterator<Item=Self::Item> {
    type Item;
    type IntoIter: Iterator;
    fn into_iter(self) -> Self::IntoIter;
}
```

লক্ষ্য করুন, `IntoIterator::into_iter` তার `self` টাইপ কনজিউম করলেও, সেই টাইপটি ওনড ভ্যালু হতে হবে এমন নয়।
তাই [`Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-2), [`&'a Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator) এবং [`&'a mut Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-1)-এর জন্য `IntoIterator` ইমপ্লিমেন্টেশন রয়েছে।
ওনারশিপের বিভিন্ন মাত্রার জন্য এই ইমপ্লিমেন্টেশনগুলো দরকারি নমনীয়তা দেয়।

এই ধারণার জন্য `traits` বোঝা জরুরি নয়, এবং `traits`-এ দক্ষ হওয়ার জন্য আপনার জন্য একটি পুরো অনুশীলনী থাকবে।
আপাতত শুধু মনে রাখুন যে:

- যেকোনো টাইপ যা `IntoIterator` ইমপ্লিমেন্ট করে তাকে _ইটারেবল_ বলা হয়, কারণ এটিকে একটি ইটারেটারে রূপান্তর করা যায়।
- যেকোনো টাইপ যা `Iterator` ইমপ্লিমেন্ট করে সেটি একটি ইটারেটার, যা মান _তৈরি করে_ এবং যার উপর _ইটারেশন করা যায়_।
- যেকোনো টাইপ যা `IntoIterator` ইমপ্লিমেন্ট করে, তার `into_iter` মেথড কল করে আপনি একটি ইটারেটার পেতে পারেন।
- প্রতিটি ইটারেটার [`IntoIterator` ইমপ্লিমেন্ট করে](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html#impl-IntoIterator-25) এবং নিজেই নিজেকে তৈরি করে।
- `for` লুপ সবসময় ইটারেটারের উপর কাজ করে এবং তাদের রেঞ্জ আর্গুমেন্টে `IntoIterator` ইমপ্লিসিটভাবে কল করে।

## `into_iter` এবং for লুপ

ভেক্টরের উপর for লুপের সাথে আপনি সম্ভবত পরিচিত:

```rust
// lor is a `Vec`, which implements `IntoIterator`
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
for people in &lor {
    println!("{people}");
}
```

মূলত, একটি `for` লুপ হলো তার আর্গুমেন্টের `into_iter` মেথড কল করা, আর তারপর আইটেম তৈরি করা বন্ধ না হওয়া পর্যন্ত `next()` কল করার শর্টহ্যান্ড। অন্য কথায়, আগের লুপটি ডিসুগার হয় এভাবে:

```rust
{
    let mut iterator = (&lor).into_iter();
    while let Some(people) = iterator.next() {
        println!("{people}");
    }
}
```

## `iter` ও `iter_mut` মেথড

বেশিরভাগ Rust কালেকশন টাইপ `iter` ও `iter_mut` মেথড দেয়।
`T` টাইপের একটি কালেকশনের জন্য, এই দুটি মেথড প্রচলিতভাবে নিচের কাজ করে:

- `iter` যে ইটারেটার রিটার্ন করে সেটি ইমিউটেবল বরো করা `&T` দেয়।
- `iter_mut` যে ইটারেটার রিটার্ন করে সেটি মিউটেবল বরো করা `&mut T` দেয়।

```rust
let mut v = vec![1, 2, 3];

// Using `iter` method
let mut iterator = v.iter();
assert_eq!(iterator.next(), Some(&1));
assert_eq!(iterator.next(), Some(&2));
assert_eq!(iterator.next(), Some(&3));
assert_eq!(iterator.next(), None);

// Using `iter_mut` method
for value in v.iter_mut() {
     *value *= *value;
}
println!("{v:?}");
// => [1, 4, 9]
```

## `iter`, `iter_mut` ও `into_iter`-এর মধ্যে পার্থক্য

যদি `iter`, `iter_mut` ও `into_iter` সবই ইটারেটার তৈরি করে, তাহলে পার্থক্যগুলো কী?

- `iter` যে ইটারেটার রিটার্ন করে সেটি প্রচলিতভাবে ইমিউটেবল বরো করা `&T` দেয়।
- `iter_mut` যে ইটারেটার রিটার্ন করে সেটি প্রচলিতভাবে মিউটেবল বরো করা `&mut T` দেয়।
- `into_iter` যে ইটারেটার রিটার্ন করে সেটি তার কনটেক্সট অনুযায়ী `T`, `&T` বা `&mut T` দিতে পারে।

একটি `into_iter` কলের কনটেক্সট কী?
তার `self` টাইপ।
মনে করুন, `Vec`, `&'a Vec` ও `&'a mut Vec`-এর জন্য `IntoIterator` ইমপ্লিমেন্টেশন রয়েছে।
তাই:

- `(&v).into_iter()` হলো `v.iter()`-এর সমান => `&T` রিটার্ন করে
- `(&mut v).into_iter()` হলো `v.iter_mut()`-এর সমান => `&mut T` রিটার্ন করে
- `v.into_iter()` => `T` রিটার্ন করে এবং মানগুলো মুভ করে

এটি for লুপে সবচেয়ে স্পষ্ট:

- `for num in &v {...}` => `&T` বাইন্ড করে
- `for num in &mut v {...}` => `&mut T` বাইন্ড করে
- `for num in v {...}` => `T` বাইন্ড করে এবং মানগুলো মুভ করে

`(&v).into_iter()`-এর বদলে `v.iter()` লেখা প্রায়ই বেশি স্পষ্ট।
তাই `into_iter`-এর চেয়ে `iter` ও `iter_mut` পছন্দ করার আর্গোনমিক কারণ রয়েছে।

## ইটারেটারের জন্য বিল্ট-ইন মেথড ব্যবহার

ইটারেটার অনেক বিল্ট-ইন মেথড দেয়, যেমন `map`, `filter`, `collect`।
এই মেথডগুলো কখনো কখনো ক্লোজারের সাথে ব্যবহার করা হয়।

`map` একটি ক্লোজার ব্যবহার করে ইটারেটারের মান রূপান্তর করে।
`take` একটি (সম্ভাব্য অসীম) ইটারেটারকে এমন একটিতে ছেঁটে আনে, যা নির্দিষ্ট সংখ্যক আইটেমের পর বড়জোর শেষ হয়।

```rust
for even_number in (0..).into_iter().map(|x| x * 2).take(4) {
    let odd_number = even_number + 1;
    println!("{even_number} => {odd_number}");
}
// 0 => 1
// 2 => 3
// 4 => 5
// 6 => 7
```

`filter` ইটারেটারকে এমন একটিতে রূপান্তর করে যা কেবল সেই মানগুলোই রিটার্ন করে, যেগুলোর জন্য ক্লোজারটি `true` হিসেবে মূল্যায়িত হয়।
`count` ইটারেটারটি কনজিউম করে, তৈরি হওয়া আইটেমের সংখ্যা রিটার্ন করে।

```rust
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
let short_people = ["Dwarves", "Hobbits"];
let num_tall_people = lor.iter().filter(|people| !short_people.contains(people)).count();
assert_eq!(num_tall_people, 5);
```

`flat_map` প্রদত্ত ক্লোজারের মাধ্যমে প্রতিটি আইটেমকে নতুন ইটারেটারে রূপান্তর করে ইটারেটারটিকে রূপান্তর করে, তারপর তৈরি হওয়া সব নতুন ইটারেটারকে একসাথে শৃঙ্খলাবদ্ধ করে ফ্ল্যাট করে দেয়।
`collect` একটি নতুন কালেকশন তৈরি করে, যদি কালেকশন টাইপটি [`FromIterator`](https://doc.rust-lang.org/std/iter/trait.FromIterator.html) ইমপ্লিমেন্ট করে।

```rust
let words = ["alpha", "beta", "gamma"];
// chars() returns an iterator
let merged: String = words.iter()
                          .flat_map(|s| s.chars())
                          .collect();
assert_eq!(merged, "alphabetagamma");
```

[`Iterator` ট্রেইট](https://doc.rust-lang.org/std/iter/trait.Iterator.html) এমন _অনেক_ দরকারি ইটারেটার ট্রান্সফর্ম দেয়; ডকুমেন্টেশন পড়ে সেগুলোর সাথে নিজেকে পরিচিত করা ভালো।

## লেজিনেস

জানা জরুরি যে Rust ইটারেটার লেজি: আমরা ইটারেটারটি কনজিউম না করা পর্যন্ত তারা কোনো মান তৈরি করে না।
আপনি যদি নিচের কোডটি লিখে রান করেন:

```rust
(0..5).map(|x| x * x);
```

আপনি নিচের কম্পাইলার এররটি পাবেন:

```rust
 --> src/main.rs:2:5
  |
2 |     (0..5).map(|x| x * x);
  |     ^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: `#[warn(unused_must_use)]` on by default
  = note: iterators are lazy and do nothing unless consumed
```

এর কারণ `map` একটি অ্যাডাপ্টার মেথড, যা আরেকটি ইটারেটার রিটার্ন করে।

একটি ইটারেটার কনজিউম করতে, হয় একটি `for` লুপ ব্যবহার করুন, নয়তো এমন একটি ইটারেটার মেথড ব্যবহার করুন যা এমন কিছু মান তৈরি করে যা নিজে ইটারেটার নয়।

উদাহরণস্বরূপ, `collect` একটি কনজিউমার মেথড (এর ফাংশন সিগনেচার ইটারেটার নয়, বরং একটি জেনেরিক টাইপ রিটার্ন করে):

```rust
//         Iterator   Adaptor        Consumer
//                |      |               |
let v: Vec<_> = (0..5).map(|x| x * x).collect();
```
