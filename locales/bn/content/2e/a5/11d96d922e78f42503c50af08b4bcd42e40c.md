# নির্দেশনা

এই অনুশীলনীতে আপনি Exercism-এ যে প্রোগ্রামিং ভাষাগুলো শিখতে চান, সেগুলোর একটি অ্যারের হিসাব রাখার কোড লিখবেন।

আপনার ছয়টি কাজ আছে, যার প্রতিটিতেই অ্যারে নিয়ে কাজ করতে হবে।

## 1. একটি নতুন অ্যারে তৈরি করুন

আপনি যে ভাষাগুলো শিখতে চান সেগুলোর হিসাব রাখতে হলে আপনাকে একটি নতুন অ্যারে তৈরি করতে হবে। `new_list` ফাংশনটি ডিফাইন করুন, যা একটি নতুন, খালি অ্যারে রিটার্ন করে।

```gleam
new_list()
// -> []
```

## 2. একটি বিদ্যমান অ্যারে ডিফাইন করুন

এই মুহূর্তে আপনার কাছে একটি কাগজ আছে, যেখানে আপনি যে ভাষাগুলো শিখতে চান সেগুলো লেখা আছে: Gleam, Go আর TypeScript। এই অ্যারেটি রিটার্ন করার জন্য `existing_list` ফাংশনটি ডিফাইন করুন।

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. অ্যারেতে একটি নতুন ভাষা যোগ করুন

Exercism ঘুরে ঘুরে যখন আরও মজার ভাষা খুঁজে পাবেন, তখন সেগুলো আপনার অ্যারেতে যোগ করতে চাইবেন। আপনার অ্যারের শুরুতে একটি নতুন ভাষা যোগ করার জন্য `add_language` ফাংশনটি ইমপ্লিমেন্ট করুন।

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. অ্যারেতে ভাষাগুলো গুনুন

একটি একটি করে ভাষা গোনা অসুবিধাজনক। আপনার অ্যারেতে কতগুলো ভাষা আছে তা গোনার জন্য `count_languages` ফাংশনটি ইমপ্লিমেন্ট করুন।

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. অ্যারেটি উল্টে দিন

একসময় আপনি বুঝতে পারবেন, আপনার অ্যারেটি আসলে উল্টো ক্রমে সাজানো! আপনার অ্যারে উল্টে দেওয়ার জন্য `reverse_list` ফাংশনটি ইমপ্লিমেন্ট করুন।

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. অ্যারেটি উত্তেজনাপূর্ণ কিনা যাচাই করুন

সব ভাষাই আপনার ভালো লাগে, তবে Gleam-এর জন্য আপনার মনে একটি বিশেষ জায়গা আছে। তাই ভাষার একটি অ্যারে আপনার কাছে সত্যিই উত্তেজনাপূর্ণ যদি:

- অ্যারেতে প্রথমটি Gleam হয়।
- অ্যারেতে দ্বিতীয়টি Gleam হয় এবং অ্যারেতে দুটি বা তিনটি ভাষা থাকে।

ভাষার একটি অ্যারে উত্তেজনাপূর্ণ কিনা তা যাচাই করতে `exciting_list` ফাংশনটি ইমপ্লিমেন্ট করুন:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
