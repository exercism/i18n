# পরিচিতি

## ব্যাখ্যা

`number` ও `string`-এর মতো প্রিমিটিভ ডেটা টাইপ ছাড়াও JavaScript-এ `object` নামে আরেকটি গুরুত্বপূর্ণ ডেটা টাইপ আছে।
অবজেক্ট হলো কী (key)-মান জোড়ার সংগ্রহ।
তাই অন্য ভাষায় যাকে সাধারণত ম্যাপ বা ডিকশনারি বলা হয়, সেভাবেই এগুলো ব্যবহার করা যায়।

অন্য ভাষায় ম্যাপের সব মান প্রায়ই একই ডেটা টাইপের হতে হয়।
JavaScript-এ শুধু কী (key)-এর টাইপটাই সীমাবদ্ধ: এটিকে স্ট্রিং হতে হবে।
একটি অবজেক্টের ভেতরের মানগুলো বিভিন্ন টাইপের হতে পারে।
এগুলো সংখ্যার মতো প্রিমিটিভ টাইপ হতে পারে, আবার অ্যারে, অন্য অবজেক্ট বা এমনকি ফাংশনও হতে পারে।
এ কারণে অবজেক্ট অনেক বহুমুখী, তাই JavaScript-এ [অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং][oop] (OOP)-এর গুরুত্বপূর্ণ অংশও এগুলোই।

নিচে আমরা সংগ্রহ বা ম্যাপ হিসেবে অবজেক্ট নিয়েই আলোচনা করব। অবজেক্টের অন্য ব্যবহারগুলো অন্য কনসেপ্টে আলোচনা করা হবে, যেমন দেখুন [ক্লাস][concept-classes]।

## একটি অবজেক্ট তৈরি করা

আপনি কোঁকড়ানো বন্ধনী দিয়ে একটি অবজেক্ট তৈরি করেন।
চাইলে সরাসরি কিছু এন্ট্রিও যোগ করতে পারেন।
এর জন্য প্রথমে কী (key) লিখুন, তারপর একটি কোলন এবং তারপর মান।

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

JavaScript-এ শেষ এন্ট্রির পরে দেওয়া কমাটি ঐচ্ছিক।

আপনার মনে হতে পারে, কী (key)গুলো তো স্ট্রিং হওয়ার কথা, তাহলে এগুলোর চারপাশে উদ্ধৃতি চিহ্ন দেওয়া হয়নি কেন।
এটি একটি শর্টহ্যান্ড নোটেশন।
যদি কী (key) JavaScript-এর [আইডেন্টিফায়ার][mdn-identifier] হিসেবে নামকরণের নিয়ম মেনে চলে, তাহলে উদ্ধৃতি চিহ্ন বাদ দেওয়া যায়।
নামে বিশেষ চিহ্নযুক্ত কী (key)-এর জন্য সাধারণ স্ট্রিং নোটেশন ব্যবহার করতে হবে।

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## একটি মান বের করা

নির্দিষ্ট কোনো কী (key)-এর মান বের করার দুটি উপায় আছে: ডট নোটেশন এবং বন্ধনী নোটেশন।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

শর্টহ্যান্ড হিসেবে ডট নোটেশন ব্যবহারের ক্ষেত্রেও উদ্ধৃতি চিহ্ন বাদ দেওয়ার মতো একই সীমাবদ্ধতা আছে।
এটি তখনই কাজ করে, যখন কী (key) আইডেন্টিফায়ারের নামকরণের নিয়ম মেনে চলে।
অন্য কথায়, আপনার কী (key) যদি শুধু অক্ষর দিয়ে গঠিত একক শব্দ না হয়, তাহলে আপনাকে বর্গাকার বন্ধনী নোটেশনই ব্যবহার করতে হবে।

## একটি মান যোগ করা বা পরিবর্তন করা

অ্যাসাইনমেন্ট অপারেটর `=` দিয়ে আপনি একটি মান যোগ বা পরিবর্তন করতে পারেন।
এখানেও ডট এবং বন্ধনী নোটেশন দুটোই আছে।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## একটি এন্ট্রি মুছে ফেলা

`delete` কিওয়ার্ড ব্যবহার করে একটি অবজেক্ট থেকে কী (key)-মান জোড়া মুছে ফেলতে পারেন।

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## কোনো কী (key) আছে কি না যাচাই করা

`hasOwnProperty` মেথড দিয়ে একটি অবজেক্টে নির্দিষ্ট কোনো কী (key) আছে কি না তা যাচাই করতে পারেন।

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## একটি অবজেক্টের মধ্য দিয়ে লুপ করা

একটি অবজেক্টের সব কী (key)-এর উপর ইটারেট করার জন্য একটি বিশেষ `for...in` লুপ আছে।

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

সূক্ষ্ম এরর এড়াতে আপনার সর্বদা ধরে নেওয়া উচিত যে `for...in` লুপটি কী (key)গুলোকে কোনো নির্দিষ্ট ক্রম ছাড়াই ভিজিট করে।
এছাড়াও মনে রাখবেন, `for...in`-এর ইটারেশনে [উত্তরাধিকারসূত্রে পাওয়া কী (key)][concept-inheritance] অন্তর্ভুক্ত থাকে।
