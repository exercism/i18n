# ভূমিকা

প্যাটার্ন ম্যাচিংয়ের ব্যবহার অ্যাসার্টিভ, ইডিওম্যাটিক এলিক্সির কোডে প্রধান। আপনি হয়তো মনে করতে পারেন যে `=/2`-কে অ্যাসাইনমেন্ট অপারেটর হিসেবে নয়, বরং ম্যাচ অপারেটর হিসেবে বর্ণনা করা হয়। ম্যাচ অপারেটর ব্যবহার করার সময়, যদি বাম দিকের প্যাটার্নটি ডান দিকের সাথে ম্যাচ করে, তাহলে বাম দিকের যেকোনো ভ্যারিয়েবল বাইন্ড হয়, এবং ডান দিকের মানটি রিটার্ন করা হয়। কোনো ম্যাচ না থাকলে `MatchError` রেইজ করা হয়।

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

মনে রাখবেন, ম্যাচ ডান দিক থেকে বাম দিকে ঘটে।

শেষ উদাহরণে, যদি প্যাটার্ন ম্যাচে আমাদের কোনো ভ্যারিয়েবলের প্রয়োজন না হয়, তাহলে `_` উল্লেখ করে সেটি বাদ দিতে পারি।
`_` দিয়ে শুরু হওয়া যেকোনো ভ্যারিয়েবল রানটাইম দ্বারা ট্র্যাক করা হয় না।

## নেমড ফাংশনে প্যাটার্ন ম্যাচিং

একাধিক ফাংশন ক্লজ তৈরি করার সময় প্যাটার্ন ম্যাচিং একটি উপকারী টুল। ফাংশনের আর্গুমেন্টে প্যাটার্ন ম্যাচিং ব্যবহার করা যেতে পারে, যা নির্ধারণ করে কোন ফাংশন ক্লজটি ইনভোক করতে হবে। এটি ফাইলের উপরে থেকে নিচের দিকে প্রথম ম্যাচ পর্যন্ত চলে। ফাংশন হেডে ভ্যারিয়েবল বাইন্ড করা যেতে পারে এবং ফাংশন বডিতে ব্যবহার করা যেতে পারে।

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
