# নির্দেশনার পরিশিষ্ট

## ইঙ্গিত

আপনাকে `decode` ও `encode` ফাংশন দুটি ইমপ্লিমেন্ট করতে হবে, যেগুলো Atbash সাইফার ব্যবহার করে একটি `String` ডিকোড ও এনকোড করে।
টাইপগুলো নিয়ে নিশ্চিত না থাকলে দেওয়া সিগনেচারটি ব্যবহার করতে পারেন, তবে সেটি যেন আপনার সৃজনশীলতাকে বাধা না দেয়।

এই অনুশীলনীটি টেক্সট ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর
`String` টাইপ `[Char]`-এরই সমার্থক, যা ক্যারেক্টারগুলোর একটি অ্যারে। টেক্সট
ডেটা আরও দক্ষভাবে সামলাতে `Text` টাইপটি ব্যবহার করা যায়।

এই অনুশীলনীর ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি চাইলে:

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়তে পারেন।
- package.yaml ফাইলে আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করতে পারেন।
- `Data.Text` ইমপোর্ট করতে পারেন [নিচের পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` টাইপ ব্যবহার করতে পারেন, যেমন `decode :: Text -> Text`, আর
  `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.pack` নামে ডাকতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর
  ডকুমেন্টেশন দেখে নিতে পারেন।
- Atbash.hs ফাইলে `String`-এর সব জায়গায় `Text` বসাতে পারেন, অর্থাৎ:

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
