# পরিচিতি

`readonly` মডিফায়ার একটি ফিল্ডের মান বা রেফারেন্স ওভাররাইট হওয়া আটকালেও, রেফারেন্স টাইপের সদস্যদের কোনো সুরক্ষা দেয় না।

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

রেফারেন্স টাইপের সব সদস্য যাতে সুরক্ষিত থাকে তা নিশ্চিত করতে ফিল্ডগুলোকে `readonly` করা যায় এবং `set` অ্যাকসেসর ছাড়াই অটোমেটিক প্রপার্টি ডিফাইন করা যায়।

যেখানে কালেকশনের সদস্যদের আপডেট হওয়া বন্ধ করার দরকার হয়, সেখানে Base Class Library (BCL) কালেকশনের কিছু রিড-অনলি ভার্সন দেয়। এগুলো আসে র্যাপার আকারে:

- `ReadOnlyDictionary<T>` একটি `Dictionary<T>`-কে রিড-অনলি হিসেবে এক্সপোজ করে।
- `ReadOnlyCollection<T>` একটি `List<T>`-কে রিড-অনলি হিসেবে এক্সপোজ করে।
