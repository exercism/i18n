# বিবরণ

## সংখ্যার তুলনা

`jq`-তে নিচের সম্পর্ক ও সমতা অপারেটরগুলো ব্যবহার করে সংখ্যা তুলনা করা যায়।

| তুলনা          | অপারেটর |
| ---------------------- | -------- |
| বড়           | `a > b`  |
| বড় বা সমান | `a >= b` |
| ছোট              | `a < b`  |
| ছোট বা সমান    | `a <= b` |
| সমান                 | `a == b` |
| সমান নয়             | `a != b` |

তুলনার ফলাফল সর্বদা একটি বুলিয়ান মান, অর্থাৎ `true` অথবা `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## স্ট্রিংয়ের তুলনা

উপরের তুলনা অপারেটরগুলো দিয়ে স্ট্রিংও তুলনা করা যায়।
সেক্ষেত্রে অভিধানভিত্তিক (লেক্সিকোগ্রাফিক) ক্রম প্রয়োগ করা হয়।
ক্রমটি [ইউনিকোড কোডপয়েন্ট মান অনুযায়ী][sort] নির্ধারিত হয়।

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

দুটি ভ্যারিয়েবল তুলনা করার সময় আপনাকে সাবধান থাকতে হবে, যেগুলো দেখতে সংখ্যাসূচক মান ধারণ করছে বলে মনে হয় কিন্তু আসলে স্ট্রিং টাইপের।
অভিধানভিত্তিক ক্রমের কারণে ফলাফল সংখ্যা টাইপের মান তুলনার মতো একই হবে না।

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## "কঠোর" সমতা

`jq`-এর `==` অপারেটরটি Javascript-এর `===`-এর মতো, এই অর্থে যে যেসব জিনিস দেখতে একই রকম কিন্তু টাইপ আলাদা, সেগুলো সমান নয়।

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## অ্যারের তুলনা

দুটি অ্যারে সমান হয় যদি তাদের সংশ্লিষ্ট সব এলিমেন্ট সমান হয়।

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## অবজেক্টের তুলনা

দুটি অবজেক্ট সমান হয় যদি তাদের একই কী (key)-ভ্যালু জোড়া থাকে।

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
