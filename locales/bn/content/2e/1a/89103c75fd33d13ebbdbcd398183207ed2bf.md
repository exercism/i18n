# configlet ওয়ার্কফ্লো

configlet, একটি ট্র্যাকের (কনফিগারেশন) ফাইলগুলো যথাযথভাবে গঠিত কি না, তা সিনট্যাকটিক ও সেমান্টিক দুই দিক থেকেই যাচাই করতে [configlet টুল](/docs/building/configlet) ব্যবহার করে। এটি করে [`configlet lint`](/docs/building/configlet/lint) চালিয়ে।

## ফাইল ফরম্যাটিং যাচাই চালু করা

ট্র্যাকগুলো তাদের বিভিন্ন কনফিগারেশন ফাইল ফরম্যাট করতে [`configlet fmt`](/docs/building/configlet/format) ব্যবহার করতে পারে। একই কমান্ড দিয়ে সব কনফিগারেশন ফাইল সঠিকভাবে ফরম্যাট করা হয়েছে কি না তাও যাচাই করা যায়।

`configlet` ওয়ার্কফ্লো কনফিগারেশন ফাইলগুলো সঠিকভাবে ফরম্যাট করা হয়েছে কি না তা যাচাই করতে সমর্থন করে, তবে এটি ঐচ্ছিক এবং ডিফল্টভাবে বন্ধ থাকে। কনফিগারেশন ফাইলের ফরম্যাটিং যাচাই চালু করতে এই ধাপগুলো অনুসরণ করুন:

1. নিচের বিষয়বস্তু দিয়ে একটি `.github/org-wide-files-config.toml` ফাইল তৈরি করুন

```toml
[configlet]
fmt = true
```

2. এই ফাইলটি `main`-এ মার্জ হওয়ার পর, স্বয়ংক্রিয়ভাবে একটি PR খোলা হবে, যা `configlet.yml` ওয়ার্কফ্লোকে এভাবে পরিবর্তন করবে:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. এই PR মার্জ হয়ে গেলে, `configlet` ওয়ার্কফ্লো ট্র্যাকের কনফিগারেশন ফাইলগুলোর ফরম্যাটিংও যাচাই করবে।

## সোর্স

ওয়ার্কফ্লোটি `.github/workflows/configlet.yml` ফাইলে সংজ্ঞায়িত করা আছে।
