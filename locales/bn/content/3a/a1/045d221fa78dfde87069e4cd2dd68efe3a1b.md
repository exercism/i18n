# ভূমিকা

## সংখ্যার তুলনা

`jq`-তে নিচের সম্পর্ক ও সমতা অপারেটরগুলো দিয়ে সংখ্যা তুলনা করা যায়।

| তুলনা                  | অপারেটর |
| ---------------------- | -------- |
| এর চেয়ে বড়            | `a > b`  |
| এর চেয়ে বড় বা সমান    | `a >= b` |
| এর চেয়ে ছোট            | `a < b`  |
| এর চেয়ে ছোট বা সমান    | `a <= b` |
| সমান                   | `a == b` |
| সমান নয়                | `a != b` |

তুলনার ফলাফল সবসময় একটি বুলিয়ান মান, অর্থাৎ হয় `true` নয়তো `false`।

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## স্ট্রিংয়ের তুলনা

উপরের তুলনা অপারেটরগুলো দিয়ে স্ট্রিংও তুলনা করা যায়।
সেক্ষেত্রে অভিধানিক (লেক্সিকোগ্রাফিক) ক্রম প্রয়োগ করা হয়।
ক্রমটি নির্ধারিত হয় _ইউনিকোড কোডপয়েন্ট মান অনুসারে_।

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

এমন দুটি ভ্যারিয়েবল তুলনা করার সময় আপনাকে সাবধান থাকতে হবে, যেগুলোতে সংখ্যার মান আছে বলে মনে হয় কিন্তু আসলে টাইপ স্ট্রিং।
অভিধানিক ক্রমের কারণে ফলাফল সংখ্যা টাইপের মান তুলনার মতো একই হবে না।

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## "কঠোর" সমতা

`jq`-এর `==` অপারেটর JavaScript-এর `===` অপারেটরের মতো, কারণ যেসব জিনিস দেখতে একই রকম কিন্তু টাইপ ভিন্ন, সেগুলো সমান নয়।

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## অ্যারের তুলনা

দুটি অ্যারে সমান হয় যদি তাদের সমস্ত সংশ্লিষ্ট এলিমেন্ট সমান হয়।

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## অবজেক্টের তুলনা

দুটি অবজেক্ট সমান হয় যদি তাদের একই কী (key)-মান জোড়া থাকে।

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
