# ভূমিকা

C++-এ বুলিয়ান প্রকাশ করা হয় `bool` টাইপ দিয়ে।
একটি `bool` হয় `true`, নয়তো `false`.

## লজিক্যাল অপারেটর

C++ তিনটি বুলিয়ান অপারেটর সমর্থন করে: `!` (NOT), `&&` (AND) এবং `||` (OR).
বিকল্প রূপ হিসেবেও আপনি `not`, `and` এবং `or` ব্যবহার করতে পারেন।

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## প্রিসিডেন্স

তিনটি বুলিয়ান অপারেটরের প্রতিটির _অপারেটর প্রিসিডেন্স_ আলাদা।
ফলে এগুলো এই ক্রমে মূল্যায়িত হয়: প্রথমে `!`, তারপর `&&` এবং সবশেষে `||`।
আপনি যদি ভিন্ন কোনো ক্রমে মূল্যায়ন করাতে চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন প্রথম বন্ধনীর (অর্থাৎ `()`) ভেতরে রাখতে পারেন, কারণ বন্ধনীর অপারেটর প্রিসিডেন্স আরও বেশি।

```cpp
!true && false   // => false
!(true and false) // => true
```

## কনভার্সন

যেখানে একটি সংখ্যা প্রত্যাশিত, সেখানে `true` বা `false` ব্যবহার করলে সেগুলো যথাক্রমে `1` ও `0` হয়ে যাবে।
বুলিয়ান অপারেশনে কোনো সংখ্যা ব্যবহার করলে `0` ছাড়া বাকি সবকিছুই `true` হিসেবে ধরা হয়, এমনকি ঋণাত্মক মানও।

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
