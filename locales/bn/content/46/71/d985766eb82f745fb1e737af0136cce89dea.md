# পরিচিতি

Python-এ একটি ডিকশনারি (`dict`) হলো এমন একটি ডেটা স্ট্রাকচার, যা [হ্যাশেবল][term-hashable] _কী (key)_-কে _মান_-এর সাথে যুক্ত করে এবং অন্য প্রোগ্রামিং ভাষায় এটি রিসাইজেবল [হ্যাশ টেবিল][hashtable-wikipedia], হ্যাশম্যাপ বা [অ্যাসোসিয়েটিভ অ্যারে][associative-array] নামে পরিচিত।
ডিকশনারি হলো Python-এর একমাত্র বিল্ট-ইন [ম্যাপিং টাইপ][mapping-types-dict]।


`Keys` অবশ্যই হ্যাশেবল হতে হবে এবং পুরো ডিকশনারিতে ইউনিক হতে হবে।
কী (key)-এর টাইপ হতে পারে `numbers`, `str` বা `tuples` (_ইমিউটেবল_ মানের)।
এগুলোতে `lists`, `dict`s বা `set`s-এর মতো _মিউটেবল_ ডেটা স্ট্রাকচার থাকতে পারবে না।
Python 3.7 থেকে, `dict`-এ কী (key)-এর ক্রম এন্ট্রি যেভাবে যোগ করা হয় সেভাবেই থাকার নিশ্চয়তা দেওয়া হয়।

`values` যেকোনো ডেটা টাইপ বা স্ট্রাকচারের হতে পারে।
 মান _ইচ্ছেমতো_ নেস্টও হতে পারে, তাই এতে অ্যারের ভেতরে অ্যারে, সাব-ডিকশনারি এবং অন্য যেকোনো কাস্টম বা যৌগিক ডেটা স্ট্রাকচার থাকতে পারে।

একটি `key` দেওয়া হলে, ডিকশনারি (গড়ে) কনস্ট্যান্ট টাইমে একটি `value` বের করতে পারে (_এন্ট্রির সংখ্যার উপর নির্ভর করে না_)।
একটি `list` বা `array`-এর ভেতরে মান খোঁজার তুলনায় (_`index` পজিশন না জেনে_), একটি `dict` অনেক বেশি মেমরি ব্যবহার করে, তবে মান বের করা খুব দ্রুত হয়।
যেসব পরিস্থিতিতে আইটেমের সংগ্রহ বড় এবং সেগুলো ঘন ঘন অ্যাক্সেস ও আপডেট করতে হয়, সেখানে ডিকশনারি বিশেষভাবে কাজে লাগে।


## ডিকশনারি তৈরি করা

ডিকশনারি অনেকভাবে তৈরি করা যায়।
সবচেয়ে সহজ দুটি উপায় হলো `dict()` কনস্ট্রাক্টর ব্যবহার করা বা একটি `dict` _লিটারাল_ ঘোষণা করা।

### `dict()` ক্লাস কনস্ট্রাক্টর

`dict()` (_ডিকশনারি ক্লাসের কনস্ট্রাক্টর_) ব্যবহার করা যায় যেকোনো `key`, `value` জোড়ার ইটারেবল দিয়ে, অথবা একগুচ্ছ `<name>=<value>` _আর্গুমেন্ট_ দিয়ে:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### ডিকশনারি লিটারাল

একটি `dict` সরাসরি একটি _ডিকশনারি লিটারাল_ হিসেবেও লেখা যায়, যেখানে দ্বিতীয় বন্ধনী (`{}`) দিয়ে `key : value` জোড়াগুলো ঘেরা থাকে:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## ডিকশনারিতে মান অ্যাক্সেস করা

তৃতীয় বন্ধনী (`[]`) দিয়ে একটি _কী (key)_ ব্যবহার করে আপনি ডিকশনারির একটি এন্ট্রি অ্যাক্সেস করতে পারেন।
`dict`-এ `key` না থাকলে একটি `KeyError` থ্রো হয়:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

`.get(<key>, <default value>)` মেথডের মাধ্যমে একটি এন্ট্রি অ্যাক্সেস করলে `KeyError` এড়ানো যায়:

```python
>>> bear.get("color", 'not found')
'not found'
```

## ডিকশনারির মান পরিবর্তন বা যোগ করা

কোনো এন্ট্রির _কী (key)_-তে অ্যাসাইন করে আপনি তার মান পরিবর্তন করতে পারেন:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

একইভাবে নতুন `key`:`value` জোড়া _যোগ_ করা যায়:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## ডিকশনারির এন্ট্রি মুছে ফেলা (পপ করা)

ডিকশনারির একটি এন্ট্রি মুছে ফেলতে আপনি `.pop(<key>)` মেথড ব্যবহার করতে পারেন।
`.pop()` (`key`, `value`) জোড়াটি মুছে ফেলে এবং ব্যবহারের জন্য `value` রিটার্ন করে।
`.get()`-এর মতোই, `.pop(<key>)` একটি দ্বিতীয় আর্গুমেন্ট (_`dict.pop(<key>, <default value>)`_) নিতে পারে, যা `key` খুঁজে না পেলে রিটার্ন করা হয়।
এতে `KeyError` থ্রো হওয়া আটকে যায়:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## ডিকশনারির মধ্য দিয়ে লুপ করা / ইটারেট করা

`for item in dict` বা `while item` ব্যবহার করে ডিকশনারির মধ্য দিয়ে লুপ করলে ডিফল্টভাবে শুধু _কী (key)_-গুলোর উপরেই ইটারেশন হয়।
একই লুপের ভেতরে _তৃতীয় বন্ধনী_ ব্যবহার করে _মান_-গুলো অ্যাক্সেস করতে পারেন:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

আপনি `.items()` মেথডও ব্যবহার করতে পারেন, যা স্বয়ংক্রিয়ভাবে (`key`, `value`) টাপল রিটার্ন করে:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

একইভাবে, `.keys()` মেথড `keys` রিটার্ন করবে এবং `.values()` মেথড `values` রিটার্ন করবে।
