# নির্দেশনা

আপনি একটি ছোট দ্বীপের ফেরির যাত্রাসূচি রেখে থাকেন। যাত্রার সময়গুলো তারিখ হিসেবে লিপিবদ্ধ করা হয়, আর সেগুলো নিয়ে কাজ করার জন্য আপনার কয়েকটি হেল্পার দরকার।

## 1. যাত্রার তারিখ লিপিবদ্ধ করুন

`make-date` ডিফাইন করুন, যা একটি বছর, মাস আর দিন নেবে এবং সংশ্লিষ্ট টাইমস্ট্যাম্প রিটার্ন করবে।

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. বার-এর নাম দিন

`weekday-name` ডিফাইন করুন, যা একটি যাত্রার টাইমস্ট্যাম্প নেবে এবং যাত্রাটি যে বারে পড়ে তার নাম রিটার্ন করবে।

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. অধিবর্ষ

`leap?` ডিফাইন করুন, যা একটি বছর নেবে এবং সেটি অধিবর্ষ কি না তা রিটার্ন করবে।

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. এক মাসে দিনের সংখ্যা

`month-length` ডিফাইন করুন, যা একটি বছর আর একটি মাস নেবে এবং ওই মাসে কত দিন আছে সেই সংখ্যা রিটার্ন করবে (ফেব্রুয়ারি মাসের কথা মনে রাখুন)।

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. কয়েক দিন পরে

`add-days` ডিফাইন করুন, যা একটি টাইমস্ট্যাম্প আর কতগুলো দিন নেবে, এবং তার ঠিক তত দিন পরের টাইমস্ট্যাম্প রিটার্ন করবে।

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
