# নির্দেশাবলির সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার    | টাইপ     | বর্ণনা                                                     |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | ক্যাটাগরি: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | ইনপুট     | অ্যাড্রেস | পাশা (ওয়ার্ডের অ্যারে)                                      |
| `$v0`    | আউটপুট    | ইন্টিজার | প্রাপ্ত স্কোর                                               |
| `$t0-9`  | টেম্পোরারি | যেকোনো   | সাময়িক স্টোরেজের জন্য ব্যবহৃত হয়                           |
