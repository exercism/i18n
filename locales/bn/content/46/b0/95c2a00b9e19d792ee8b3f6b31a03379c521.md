# নির্দেশনার সংযোজন

## C++ ইমপ্লিমেন্টেশনের জন্য অতিরিক্ত নোট

C++-এ প্যারালেলিজম অর্জনের বেশ কয়েকটি উপায় আছে।
Exercism-এর অনলাইন রানার C++17 সাপোর্ট করে, তাই আপনি [অ্যালগরিদম লাইব্রেরি][algorithm] থেকে এক্সিকিউশন পলিসি ব্যবহার করতে পারেন।
আরেকটি উপায় হলো [থ্রেড][thread] নিজে ম্যানেজ করা।
তবে মনে রাখবেন, একটি থ্রেড তৈরি করা বেশ ব্যয়বহুল (এখানে একটি [থ্রেড পুল][pool] ব্যবহার করলে সুবিধা হবে)।

নিজের কম্পিউটারে কাজ করার সময় আপনি অবশ্যই যা চান ব্যবহার করতে পারেন।
তবে নন-স্ট্যান্ডার্ড লাইব্রেরি ব্যবহার করা সমাধান Exercism-এর অনলাইন রানারে সম্ভবত কাজ করবে না।

### বেঞ্চমার্ক

নিজের কম্পিউটারে কাজ করার সময় আপনি চাইলে একটি বেঞ্চমার্ক চালিয়ে বিভিন্ন ইমপ্লিমেন্টেশনে গতি কতটা বাড়ে তার একটা ধারণা পেতে পারেন।
CMake ফ্ল্যাগ `EXERCISM_INCLUDE_BENCHMARK` চালু করলে বেঞ্চমার্কটি সক্রিয় হয়:
```
cmake -DEXERCISM_RUN_ALL_TESTS=1 -DEXERCISM_INCLUDE_BENCHMARK=1 .
```

### প্যারালেল অ্যালগরিদমে কম্পাইলারের সাপোর্ট

C++ স্ট্যান্ডার্ড লাইব্রেরির (`libstdc++`) GCC-এর ইমপ্লিমেন্টেশন [TBB][tbb]-এর উপর নির্ভর করে।
TBB না থাকলে সিকোয়েন্সিয়াল ভার্সনে ফলব্যাক করা হবে, এমনকি প্যারালেল এক্সিকিউশন চাইলেও।

Ubuntu-তে আপনাকে `libtbb-dev` প্যাকেজটি ইনস্টল করতে হবে:
```
apt-get install libtbb-dev
```

macOS-এ TBB ইনস্টল করতে আপনি [Homebrew][homebrew] ব্যবহার করতে পারেন:
```
brew install tbb
```

Clang `libc++`-এর 17 নম্বর ভার্সনে প্যারালেল অ্যালগরিদমের পরীক্ষামূলক, আংশিক সাপোর্ট আছে।
এটি চালু করতে `-fexperimental-library` কম্পাইলার ফ্ল্যাগটি দিতে হবে।

Apple Clang 15 ও তার আগের ভার্সনগুলো প্যারালেল অ্যালগরিদম _সাপোর্ট করে না_।

Linux ও macOS-এ এই অনুশীলনীর জন্য আমরা GCC (সাথে ডিফল্ট `libstdc++`) ব্যবহার করার পরামর্শ দিই।

Microsoft-এর MSVC কমপক্ষে VS 2017 15.7 থেকে কোনো অতিরিক্ত লাইব্রেরি ইনস্টল না করেই প্যারালেল অ্যালগরিদম সাপোর্ট করে।
