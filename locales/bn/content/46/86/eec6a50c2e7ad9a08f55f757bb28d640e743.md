# পরিচিতি

Swift একটি কম্পাইলড, মাল্টি-প্যারাডাইম প্রোগ্রামিং ভাষা, যা তিনটি প্রধান লক্ষ্য নিয়ে ডিজাইন করা হয়েছে:

- **নিরাপত্তা**: ভাষার বিল্ট-ইন ফিচারগুলো আপনার code প্রোডাকশনে চলার আগেই bug ধরতে ও প্রতিরোধ করতে সাহায্য করে।
- **গতি**: C-ভিত্তিক ভাষার সমতুল্য অপ্টিমাইজড পারফরম্যান্স।
- **প্রকাশক্ষমতা**: পরিচ্ছন্ন, আধুনিক সিনট্যাক্স, যা পড়তে ও লিখতে আনন্দদায়ক এবং সহজ।

Apple ২০১৪ সালে Swift উপস্থাপন করে, iOS ও macOS ডেভেলপমেন্টের আগের ভাষা Objective-C-এর একটি আধুনিক বিকল্প হিসেবে।
আজ Swift ওপেন সোর্স, এবং এটি Apple প্ল্যাটফর্ম, Linux ও Windows-এ চলে।

## শুরু করা যাক

### ভ্যারিয়েবল

[ভ্যারিয়েবল][constants-variables] ডিফাইন করে আপনি মান সংরক্ষণ করতে ও নাম দিতে পারেন।
ভ্যারিয়েবল ডিফাইন করার পর আপনি তার নাম ব্যবহার করে আপনার code জুড়ে সেই মানটি বোঝাতে পারেন।
ভ্যারিয়েবল _মিউটেবল_, অর্থাৎ ডিফাইন করার পরেও তাদের মান পরিবর্তন করা যায়।

`var` কিওয়ার্ড দিয়ে একটি ভ্যারিয়েবল ডিফাইন করুন:

```swift
var variableName = 10
```

Swift একটি স্ট্যাটিক টাইপড ভাষা, অর্থাৎ কম্পাইল টাইমেই প্রতিটি মানের টাইপ জানা থাকে।
আপনি [টাইপ অ্যানোটেশন][type annotations] দিয়ে স্পষ্টভাবে টাইপ ঘোষণা করতে পারেন, অথবা অ্যাসাইন করা মান থেকে Swift কম্পাইলারকে [টাইপ ইনফার করতে][type-inferring] দিতে পারেন:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

অ্যাসাইনমেন্ট অপারেটর (`=`) দিয়ে আপনি একটি ভ্যারিয়েবলের মান আপডেট করতে পারেন:

~~~~exercism/note
ঘোষণা করার পর একটি ভ্যারিয়েবলের টাইপ আর পরিবর্তন করা যায় না।

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

টাইপ উল্লেখ করে আপনি প্রাথমিক মান ছাড়াই একটি ভ্যারিয়েবল ঘোষণা করতে পারেন, তবে ব্যবহার করার আগে অবশ্যই একটি মান অ্যাসাইন করতে হবে:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### কনস্ট্যান্ট

[কনস্ট্যান্ট][constants-variables]ও একটি মানের সাথে একটি নাম যুক্ত করে, তবে অ্যাসাইন করার পর তাদের মান পরিবর্তন করা যায় না।
এগুলো _ইমিউটেবল_।
`let` কিওয়ার্ড দিয়ে একটি কনস্ট্যান্ট ডিফাইন করুন:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### পাটিগণিতের অপারেটর

সাধারণ গণনার জন্য Swift আদর্শ [পাটিগণিতের অপারেটর][arithmetical-operators] সরবরাহ করে:

- যোগ: `+`
- বিয়োগ: `-`
- গুণ: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### ফাংশন

Swift-এ [ফাংশন][functions] হলো স্বয়ংসম্পূর্ণ code ব্লক, যা একটি নির্দিষ্ট কাজ করে।
ফাংশন ইনপুট নিতে পারে, একটি মান রিটার্ন করতে পারে, এবং অন্য ফাংশনে মান হিসেবে পাঠানোও যায়।
`func` কিওয়ার্ড দিয়ে একটি ফাংশন ডিফাইন করুন, তারপর ফাংশনের নাম, বন্ধনীর মধ্যে প্যারামিটার তালিকা, এবং ঐচ্ছিক একটি রিটার্ন টাইপ লিখুন:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift ফাংশনে [আর্গুমেন্ট লেবেল][argument-labels] ব্যবহার করা হয়, যার ফলে code পড়তে স্বাভাবিক বাক্যের মতো লাগে:

- ফাংশন কল করার সময় **আর্গুমেন্ট লেবেল** ব্যবহার করা হয়।
- ফাংশন বডির ভেতরে মানটি ব্যবহার করতে **প্যারামিটার নাম** ব্যবহার করা হয়।

আপনি যদি কেবল একটি নাম উল্লেখ করেন, তবে Swift সেটিকে আর্গুমেন্ট লেবেল ও প্যারামিটার নাম দুটোই হিসেবে ব্যবহার করে:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

ফাংশন কল করার সময় আপনি যদি আর্গুমেন্ট লেবেল না চান, তবে প্যারামিটার নামের আগে একটি আন্ডারস্কোর (`_`) লিখুন:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

সব ফাংশন প্যারামিটার ডিফল্টভাবে কনস্ট্যান্ট (`let`), অর্থাৎ ফাংশন বডির ভেতরে তাদের মান পরিবর্তন করা যায় না।

ফাংশন থেকে একটি মান রিটার্ন করতে হলে `->` এর পরে রিটার্ন টাইপ উল্লেখ করুন এবং `return` কিওয়ার্ড ব্যবহার করুন:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

কোনো ফাংশন যখন কোনো মান রিটার্ন করে না, তখন তার রিটার্ন টাইপ `Void` (যা একটি খালি টাপল, `()`, এর সমতুল্য)।
এমন ফাংশনে আপনি `-> Void` রিটার্ন টাইপ এবং `return` স্টেটমেন্ট দুটোই বাদ দিতে পারেন।

### কমেন্ট

Swift দুই ধরনের [কমেন্ট][comments] সমর্থন করে:

- **একলাইনের কমেন্ট** `//` দিয়ে শুরু হয় এবং লাইনের শেষ পর্যন্ত চলতে থাকে।
- **মাল্টিলাইন কমেন্ট** `/*` ও `*/` এর মধ্যে রাখা হয়।

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
