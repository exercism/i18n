# পরিচিতি

Kotlin-এ একটি [`string`][ref-string] হলো Unicode ক্যারেক্টারের একটি অপরিবর্তনীয় ক্রম।

[`Immutable`][wiki-immutable] মানে হলো, স্ট্রিংয়ের উপর যেকোনো অপারেশনকে নতুন একটি স্ট্রিং রিটার্ন করতে হবে: মূল স্ট্রিংটি কখনোই বদলাতে পারে না।

[`Unicode`][wiki-unicode] মানে হলো, বিশ্বের বেশিরভাগ লিখন পদ্ধতিকে এতে প্রকাশ করা যায়, তবে (C-এর মতো পুরনো ভাষার বিপরীতে) ক্যারেক্টার ও বাইটের মধ্যে ১:১ সম্পর্ক নেই।

একটি স্ট্রিং দুই পাশে ডাবল কোট `" "` দিয়ে ঘেরা থাকে।

কিছু ক্যারেক্টার এস্কেপ করতে হয়: `\\`, সঙ্গে সাধারণ নন-প্রিন্টিং ক্যারেক্টার, যেমন `\t` (ট্যাব) আর `\n` (নিউলাইন)।

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

মাল্টি-লাইন স্ট্রিং তিনটি ডাবল কোট দিয়ে ঘেরা হয়, আর এতে যা খুশি লেখা যায় (এস্কেপ করার দরকার নেই)।

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

লাইনগুলোর সাধারণ ইনডেন্টেশন সরিয়ে ফেলতে [trimIndent][trimIndent-doc] ব্যবহার করুন।
স্ট্রিং ফরম্যাট করার জন্য এটি কাজে লাগে:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

এর বিকল্প হিসেবে, [trimMargin][trimMargin-doc] দিয়ে আপনি একটি ডেলিমিটার নির্দিষ্ট করতে পারেন।
তখন `String`-এর প্রতিটি লাইন ডেলিমিটারের পরে শুরু হয়।
ডেলিমিটারের ডিফল্ট মান `|`, তবে আপনি প্যারামিটার হিসেবে ভিন্ন একটি ডেলিমিটার দিতে পারেন।
যেমন:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

`+` দিয়ে স্ট্রিং জোড়া লাগানো যায়, তবে এটি কেবল ছোট আর সরল ক্ষেত্রে সীমাবদ্ধ রাখাই ভালো।
এর জন্য আরও কিছু, আর প্রায়ই আরও ভালো, উপায় আছে।

## স্ট্রিং টেমপ্লেট

অন্য কিছু ভাষায় এটিকেই "ইন্টারপোলেশন" বলা হয়।

কোনো স্ট্রিংয়ে ডলার চিহ্ন `$`-এর পরে একটি আইডেন্টিফায়ার থাকলে, বা একটি এক্সপ্রেশনকে ঘিরে দ্বিতীয় বন্ধনী (`{expression}`) থাকলে, সেগুলোর জায়গায় যথাক্রমে আইডেন্টিফায়ারের মান বা এক্সপ্রেশনের ফলাফল বসে যায়।

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

পার্সিং অন্যথায় দ্ব্যর্থক হয়ে যেত, এমন ক্ষেত্রে এক্সপ্রেশনের চারপাশে দ্বিতীয় বন্ধনী `{ }` লাগে।

সাধারণভাবে, স্ট্রিং জোড়া লাগানোর জন্য `+` ব্যবহার করার চেয়ে স্ট্রিং টেমপ্লেট ব্যবহার করা বেশি কার্যকর ও বেশি স্বাভাবিক।

## স্ট্রিং ফাংশন

Kotlin স্ট্রিং নিয়ে কাজ করার জন্য _অনেক_ [`functions`][ref-string-functions] সরবরাহ করে।

এগুলোর বেশিরভাগই `String` ক্লাসের মেম্বার নয়, বরং [`extensions functions`][ref-extensions], যদিও এগুলো আমরা কীভাবে ব্যবহার করি তাতে এর খুব একটা প্রভাব পড়ে না।

~~~~exercism/note
Kotlin-এর বরং জটিল [documentation][ref-string-functions] পেজগুলো ডিফল্ট ভিউতে এক্সটেনশন ফাংশন লুকিয়ে রাখে।
এই অংশটি খোলার জন্য অবশ্যই `Members & Extensions`-এ ক্লিক করুন।

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

নিচের উদাহরণগুলোতে কেবল যা যা পাওয়া যায় তার একটি ছোট অংশ দেখানো হয়েছে:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
