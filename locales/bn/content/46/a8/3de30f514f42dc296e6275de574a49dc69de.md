# Cairo-তে মডিউল ও পাথ

Cairo কোড সাজাতে **মডিউল** ব্যবহার করে।

মডিউল প্রজেক্টের কাঠামো তৈরি করতে এবং ফাংশন, স্ট্রাক্ট ও ট্রেইটের মতো আইটেমের ভিজিবিলিটি নিয়ন্ত্রণ করতে সাহায্য করে।

## মডিউল ডিফাইন করা

মডিউল `mod` দিয়ে ডিফাইন করা হয় এবং এগুলো নেস্টেড করা যায়:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

ফাংশন, স্ট্রাক্ট ও ট্রেইট **ডিফল্টভাবে প্রাইভেট** থাকে।

সেগুলোকে তাদের মডিউলের বাইরে থেকে অ্যাক্সেসযোগ্য করতে `pub` ব্যবহার করুন।

## পাথ: অ্যাবসোলিউট বনাম রিলেটিভ

অন্য মডিউলের কোনো আইটেম রেফার করতে আপনি ব্যবহার করতে পারেন:

- **অ্যাবসোলিউট পাথ** (`crate::` থেকে শুরু):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **রিলেটিভ পাথ** (বর্তমান মডিউল থেকে শুরু):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  এটি কাজ করে যদি `front_of_house` একই মডিউলে থাকে।

## `use` দিয়ে মডিউল স্কোপে আনা

বারবার পুরো পাথ লেখা অসুবিধাজনক।

`use` কিওয়ার্ডটি ছোট করে রেফার করার সুযোগ দেয়:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` **কেবল যে স্কোপে থাকে সেখানেই** প্রযোজ্য; অন্য কোথাও প্রয়োজন হলে আবার লিখতে হবে।

### `use`-এর ইডিয়ম্যাটিক ব্যবহার

- ফাংশন নয়, **মডিউল** স্কোপে আনুন:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  এর বদলে:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- **ট্রেইট, স্ট্রাক্ট ও এনামের** জন্য পুরো পাথ ব্যবহার করুন:

  ```rust
  use core::num::traits::BitSize;
  ```

### `as` দিয়ে অ্যালিয়াস

প্রয়োজনে ইমপোর্টের নাম বদলান:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### একাধিক আইটেম ইমপোর্ট করা

একাধিক `use` স্টেটমেন্টের বদলে ইমপোর্টগুলো একসাথে লিখুন:

```rust
use shapes::{Square, Circle, Triangle};
```

## `pub use` দিয়ে রি-এক্সপোর্ট করা

ভিন্ন স্ট্রাকচারে একটি মডিউল প্রকাশ করতে `pub use` ব্যবহার করুন:

```rust
pub use crate::front_of_house::hosting;
```

এখন এক্সটার্নাল কোড `restaurant::front_of_house::hosting::add_to_waitlist()`-এর বদলে `restaurant::hosting::add_to_waitlist()` ব্যবহার করতে পারে।

## Scarb দিয়ে এক্সটার্নাল প্যাকেজ ব্যবহার করা

একটি ডিপেন্ডেন্সি যোগ করতে `Scarb.toml` আপডেট করুন:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

ডিপেন্ডেন্সি যোগ করতে `scarb add <package>` এবং সেগুলো সরাতে `scarb rm <package>` ব্যবহার করুন।

## গ্লব অপারেটর (`*`)

একটি মডিউল থেকে সবকিছু ইমপোর্ট করতে:

```rust
use core::num::traits::*;
```

এটি সাবধানে ব্যবহার করা উচিত, কারণ এটি কোড পড়া কঠিন করে তুলতে পারে।
