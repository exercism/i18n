# নির্দেশাবলী

এই অনুশীলনীতে, আপনি হাই স্কুলের প্রেমিক-প্রেমিকাদের তাদের নামের আদ্যক্ষর দিয়ে একটি ASCII হার্ট তৈরি করে সোশ্যাল মিডিয়ায় তাদের ভালোবাসা প্রকাশ করতে সাহায্য করবেন:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. নামের প্রথম অক্ষরটি বের করুন

`first_letter` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি নাম নেবে এবং তার প্রথম অক্ষর রিটার্ন করবে। এটি নাম থেকে অপ্রয়োজনীয় যেকোনো হোয়াইটস্পেস পরিষ্কার করবে।

```gleam
first_letter("Jane")
// -> "J"
```

## 2. প্রথম অক্ষরটিকে আদ্যক্ষর হিসেবে ফরম্যাট করুন

`initial` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি নাম নেবে এবং তার প্রথম অক্ষরটি বড় হাতের অক্ষরে, তারপর একটি ডট দিয়ে রিটার্ন করবে। আগের ধাপে আপনি যে `first_letter` ডিফাইন করেছেন, সেটি পুনরায় ব্যবহার করতে ভুলবেন না।

```gleam
initial("Robert")
// -> "R."
```

## 3. পুরো নামটিকে প্রথম নাম ও শেষ নামে ভাগ করুন

`initials` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি পুরো নাম নেবে, যেখানে একটি প্রথম নাম ও একটি শেষ নাম একটি স্পেস দিয়ে আলাদা করা থাকে, এবং আদ্যক্ষরগুলো রিটার্ন করবে। আগের ধাপে আপনি যে `initial` ডিফাইন করেছেন, সেটি পুনরায় ব্যবহার করতে ভুলবেন না।

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. আদ্যক্ষরগুলো হার্টের ভিতরে বসান

`pair` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি পুরো নাম নেবে এবং একটি ASCII হার্টের ভিতরে আদ্যক্ষরগুলো রিটার্ন করবে। আগের ধাপে আপনি যে `initials` ডিফাইন করেছেন, সেটি পুনরায় ব্যবহার করতে ভুলবেন না।

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
