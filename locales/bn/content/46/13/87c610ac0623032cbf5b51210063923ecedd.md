# সম্পর্কে

**ইউজার-ডিফাইন্ড** ফাংশন তৈরি করা হয় `function` কিওয়ার্ড দিয়ে। এরপর দিতে হয় ফাংশনের একটি নাম এবং আর্গুমেন্টের একটি তালিকা।

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

ফাংশনগুলোকে তাদের স্কোপের একদম উপরে হোস্ট করা হয়, তাই ডিফাইন করার আগেই সেগুলো ফাইলে কল করা যায়।

## নামকরণ

PHP-তে ফাংশনের নাম অন্য লেবেলগুলোর নিয়মই অনুসরণ করে: নাম শুরু হতে হবে একটি আন্ডারস্কোর বা অক্ষর দিয়ে, এরপর যত খুশি অক্ষর, সংখ্যা বা আন্ডারস্কোর বসতে পারে।
