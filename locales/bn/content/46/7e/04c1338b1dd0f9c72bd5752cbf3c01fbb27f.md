# পরিচিতি

## কিওয়ার্ড লিস্ট

কিওয়ার্ড লিস্ট হলো এমন একটি ডেটা স্ট্রাকচার, যেখানে কী (key) আর ভ্যালুর জোড়া থাকে।

```elixir
[month: "April", year: 2018]
```

কিওয়ার্ড লিস্ট আসলে `{key, value}` [টাপল][exercism-tuples]-এর একটি অ্যারে, আর সেভাবেও লেখা যায়, তবে ছোট সিনট্যাক্সটিই বেশি ব্যবহৃত হয়।

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

কিওয়ার্ড লিস্টের প্রতিটি কী (key) অবশ্যই একটি [অ্যাটম][exercism-atoms] হতে হবে, তবে ভ্যালু যেকোনো কিছু হতে পারে। একই কী (key) একাধিকবার ব্যবহার করা যায়। আর কওয়ার্ড লিস্টের কী (key) আর ভ্যালুর জোড়াগুলো একটি নির্দিষ্ট ক্রমে সাজানো থাকে।

আপনি অ্যারে নিয়ে যেভাবে কাজ করেন, সেই একই পদ্ধতিতে কওয়ার্ড লিস্ট নিয়েও কাজ করতে পারেন, আবার `Keyword` মডিউলটিও ব্যবহার করতে পারেন।

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
