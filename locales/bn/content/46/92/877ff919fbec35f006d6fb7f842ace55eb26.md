# নির্দেশাবলি

কমিউনিটি আর্টস সেন্টারের মোজাইকটি গত মাসে বসানোর কাজ শেষ করেছে, আর এখন Magpie Marg সেটি আবিষ্কার করে ফেলেছে। প্রায় প্রতিদিনই সে কাছের **ভান্ডার** থেকে আরও চকচকে টাইল এনে এক-দুটি টাইলের সঙ্গে বদলে দেয়, কিংবা একটি টাইল খুঁটে বের করে নিয়ে এক ঘণ্টার জন্য উধাও হয়ে যায়।

আপনি সেই স্বেচ্ছাসেবক, যিনি প্রতিটি পরিবর্তনের হিসাব রাখেন। মোজাইকটি নিজেই একটি **নির্দিষ্ট আকারের অ্যারে**, যেখানে প্রতিটি টাইলের অবস্থানের জন্য একটি স্লট থাকে আর সেখানে একটি রঙের স্ট্রিং কিংবা "অনুপস্থিত" বোঝাতে `f` রাখা থাকে। Magpie Marg-এর ভান্ডার হলো সে চুরি করা আলগা টাইলগুলোর একটি **ভেক্টর**।

## 1. নতুন একটি সারি সাজান

`fresh-mosaic` ডিফাইন করুন, যা একটি দৈর্ঘ্য `n` নেবে এবং `n`টি খালি স্লটের (প্রতিটি `f`) একটি অ্যারে রিটার্ন করবে।

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. একটি টাইল বসান

`place-tile` ডিফাইন করুন, যা একটি সারি, একটি অবস্থান এবং একটি রং নেবে, এবং সারিটিকে ইন-প্লেস আপডেট করবে যাতে উল্লেখিত অবস্থানে ওই রংটি থাকে। ওয়ার্ডটি কিছুই রিটার্ন করে না।

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. একটি টাইল খুঁটে বাদ দিন

`chip-tile` ডিফাইন করুন, যা একটি সারি ও একটি অবস্থান নেবে, এবং সারিটিকে ইন-প্লেস আপডেট করবে যাতে উল্লেখিত অবস্থানটি আবার `f` হয়ে যায়।

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. একটি টাইলের রং বদলান

`recolour-tile` ডিফাইন করুন, যা একটি সারি, একটি অবস্থান এবং এক-আর্গুমেন্টের একটি কোয়োটেশন নেবে, এবং ওই অবস্থানের টাইলে কোয়োটেশনটি প্রয়োগ করে সারিটিকে ইন-প্লেস আপডেট করবে।

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Marg আসার আগে স্ন্যাপশট নিন

`snapshot-mosaic` ডিফাইন করুন, যা একটি সারি নেবে এবং এমন একটি স্বাধীন কপি রিটার্ন করবে, যা মূল সারির পরবর্তী মিউটেশনগুলোতে প্রভাবিত হবে না।

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg-এর পকেটে একটি টাইল

`stash-tile` ডিফাইন করুন, যা Marg-এর ভান্ডার (একটি ভেক্টর) ও একটি রং নেবে, এবং ভান্ডারে রংটি যোগ করবে। কিছুই রিটার্ন করে না।

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg একটি টাইল ফিরিয়ে দেয়

`return-tile` ডিফাইন করুন, যা Marg-এর ভান্ডার নেবে এবং সবচেয়ে সম্প্রতি জমা করা টাইলটি (উপরেরটি) সরিয়ে রিটার্ন করবে।

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
