# নির্দেশনা

আপনাকে নেটওয়ার্ক অথেন্টিকেশন সিস্টেম নিয়ে আরও কিছু কাজ করতে বলা হয়েছে।

ডেভেলপমেন্টের সময় সিস্টেমে অ্যাডমিন আইডেন্টিটি হার্ডকোড করা থাকার পাশাপাশি, কর্তৃপক্ষ চায় সিনিয়র ডেভেলপারদের ক্ষেত্রেও একই ব্যবস্থা রাখা হোক।

## 1. সিস্টেম অ্যাডমিনের তথ্য সিস্টেমে হার্ডকোড করে রাখুন এবং কলারদের জন্য তা উপলব্ধ করুন।

অ্যাডমিনের তথ্য নিম্নরূপ:

| ইমেইল       | চোখের রং  | ফিলট্রামের প্রস্থ | নাম      | ঠিকানা ১ | ঠিকানা ২ |
| ------------ | --------- | -------------- | -------- | --------- | --------- |
| admin@ex.ism | green     | 0.9            | Chanakya | Mumbai    | India     |

সিস্টেম অ্যাডমিনের আইডেন্টিটির তথ্য রিটার্ন করার জন্য `Authenticator.Admin` প্রপার্টি ইমপ্লিমেন্ট করুন। নাম এবং ঠিকানার প্রতিটি অংশ `NameAndAddress` অ্যারের আলাদা আলাদা এলিমেন্টে থাকা উচিত।

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. ডেভেলপারদের তথ্য সিস্টেমে হার্ডকোড করে রাখুন এবং ডিকশনারি আকারে তা উপলব্ধ করুন।

ডেভেলপারদের তথ্য নিম্নরূপ:

| ইমেইল        | চোখের রং  | ফিলট্রামের প্রস্থ | নাম      | ঠিকানা ১ | ঠিকানা ২ |
| ------------- | --------- | -------------- | -------- | --------- | --------- |
| bert@ex.ism   | blue      | 0.8            | Bertrand | Paris     | France    |
| anders@ex.ism | brown     | 0.85           | Anders   | Redmond   | USA       |

ডেভেলপারদের আইডেন্টিটির তথ্য রিটার্ন করার জন্য `Authenticator.Developers` প্রপার্টি ইমপ্লিমেন্ট করুন। ডিকশনারির কী (key) হলো ডেভেলপারের নাম।

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
