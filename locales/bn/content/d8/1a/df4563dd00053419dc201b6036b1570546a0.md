# পরিচিতি

Common lisp কয়েকটি ভিন্ন শর্তাধীন এক্সপ্রেশন প্রদান করে, যাদের মধ্যে মূল পার্থক্য হলো এরা কতটি শাখা সমর্থন করে।

- `when` ও `unless` কেবল একটি মাত্র শাখার সুযোগ দেয়:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

টেস্ট এক্সপ্রেশনের পরের অংশটি একাধিক এক্সপ্রেশনও হতে পারে।

- `if` ক্লাসিক if-then-else গঠনটি প্রদান করে:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

মনে রাখবেন, then ও else উভয় ধারাই কেবল একটি এক্সপ্রেশন হতে পারে।

- `cond` `if` এক্সপ্রেশন নেস্ট না করেই একাধিক শাখা রাখার একটি উপায় দেয়:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

মনে রাখবেন, টেস্ট এক্সপ্রেশনের পরের এক্সপ্রেশনের সংখ্যার কোনো সীমা নেই।

- `case` ক্লাসিক 'switch' ধাঁচের একটি গঠন দেয়: এটি একটি মানকে কয়েকটি শাখার সঙ্গে মিলিয়ে পরীক্ষা করে:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

মনে রাখবেন, `cond`-এর মতো এখানেও টেস্ট এক্সপ্রেশনের পরের এক্সপ্রেশনের সংখ্যার কোনো সীমা নেই।
