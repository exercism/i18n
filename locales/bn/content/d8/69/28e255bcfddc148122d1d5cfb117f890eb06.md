# নির্দেশনা

আপনি নিউজিল্যান্ডে পায়ে হেঁটে বেড়াচ্ছেন আর একটি কম্পাস থেকে বেয়ারিং নিচ্ছেন। বেয়ারিং হলো ডিগ্রির একটি পূর্ণসংখ্যা, এবং এটি একটি মান: ২০ ডিগ্রি ঘুরলে আপনি যে বেয়ারিং নিয়েছিলেন তা বদলায় না, বরং আপনি অন্য একটি বেয়ারিং পান।

একটি `immutable class BEARING` লিখুন। স্টাব আপনাকে ক্লাস হেডার আর তার অ্যাট্রিবিউট দিয়ে দেয়।

## 1. একটি বেয়ারিং নিন

`create` একটি ডিগ্রি-সংখ্যা নেয় এবং একটি বেয়ারিং দেয়। ডিগ্রি ০ থেকে ৩৫৯ পর্যন্ত চলে, তাই এর বাইরের যেকোনো কিছু ঘুরে ফিরে আসে: ৩৭০ মানে ১০, আর -১০ মানে ৩৫০।

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. ঘোরান

`turned` কত ডিগ্রি ঘুরতে হবে সেই সংখ্যাটি নেয় এবং নতুন বেয়ারিং জানায়। ঋণাত্মক সংখ্যায় ঘুরলে উল্টো দিকে ঘোরে। যে বেয়ারিংয়ের উপর এটি কল করা হয়েছিল সেটি অপরিবর্তিত থাকে।

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. তুলনা করুন

`is_eq` আরেকটি বেয়ারিং নেয় এবং দুটি একই কি না তা জানায়। এটি একবার থাকলে বেয়ারিংয়ের উপর `=` কাজ করে।

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. পয়েন্টের নাম দিন

`point` বেয়ারিংটি যে কম্পাস পয়েন্টের সবচেয়ে কাছে সেটি জানায়, `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"` এর একটি হিসেবে।

প্রতিটি পয়েন্ট ৪৫ ডিগ্রি জুড়ে থাকে, আর তার কেন্দ্র থাকে নিজের নির্দিষ্ট বেয়ারিংয়ে: উত্তর ৩৩৭.৫ থেকে ০ হয়ে ২২.৫ পর্যন্ত চলে, উত্তর-পূর্ব ২২.৫ থেকে ৬৭.৫ পর্যন্ত, এভাবে আরও। যেহেতু এখানে বেয়ারিংগুলো পূর্ণসংখ্যা, ২২ বেয়ারিং হলো `"N"` আর ২৩ হলো `"NE"`।

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. এটি লিখে ফেলুন

`str` ডিগ্রি আর পয়েন্ট জানায়, যেমন `"90 degrees (E)"`।

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
