# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি রোল-প্লেয়িং গেম খেলছেন, যেখানে বিভিন্ন ধরনের যোদ্ধা একে অপরের সাথে লড়াই করতে পারে।
এই গেমে প্রতিটি ধরনের যোদ্ধার জন্য আলাদা নিয়ম রয়েছে।
আমরা দুটি নির্দিষ্ট ধরনের দিকে মনোযোগ দেব: Wizard এবং Warrior।

Warrior-এর জন্য নিয়মগুলি হলো:

- একজন Warrior কখনোই ভালনারেবল নয়।
- Warrior যে যোদ্ধাকে আক্রমণ করছে সে ভালনারেবল না হলে Warrior `6` পয়েন্ট ড্যামেজ দেয়।
- Warrior যে যোদ্ধাকে আক্রমণ করছে সে ভালনারেবল হলে Warrior `10` পয়েন্ট ড্যামেজ দেয়।

Wizard-এর জন্য নিয়মগুলি হলো:

- একজন Wizard আগে থেকে একটি স্পেল প্রস্তুত করতে পারে।
- আগে থেকে স্পেল প্রস্তুত না থাকলে একজন Wizard ভালনারেবল থাকে।
- আগে থেকে স্পেল প্রস্তুত থাকলে একজন Wizard `12` পয়েন্ট ড্যামেজ দেয়।
- আগে থেকে স্পেল প্রস্তুত না থাকলে একজন Wizard `3` পয়েন্ট ড্যামেজ দেয়।

## 1. Warrior ক্লাস তৈরি করুন

`Warrior` নামে একটি নতুন ক্লাস তৈরি করুন।
এই ক্লাসটি বিদ্যমান `Fighter` ক্লাস থেকে ইনহেরিট করবে।

## 2. Warrior-এর বর্ণনা দিন

`Warrior` ক্লাসটি এমনভাবে আপডেট করুন যাতে এর `toString()` মেথডটি বর্ণনা করে এটি কী ধরনের যোদ্ধা।
মেথডটি `"Fighter is a Warrior"` স্ট্রিংটি রিটার্ন করবে।

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Warrior-দের ইনভালনারেবল করুন

`Warrior` ক্লাসটি এমনভাবে আপডেট করুন যাতে এর `isVulnerable()` মেথডটি সর্বদা `false` রিটার্ন করে।

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Warrior-এর ড্যামেজ পয়েন্ট হিসাব করুন

`Warrior` ক্লাসটি এমনভাবে আপডেট করুন যাতে এর `getDamagePoints(Fighter)` মেথডটি উপরের নিয়ম অনুযায়ী Warrior-এর দেওয়া ড্যামেজ হিসাব করে।

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Wizard ক্লাস তৈরি করুন

`Wizard` নামে আরেকটি নতুন ক্লাস তৈরি করুন।
এই ক্লাসটিও বিদ্যমান `Fighter` ক্লাস থেকে ইনহেরিট করবে।

## 6. Wizard-এর বর্ণনা দিন

`Wizard` ক্লাসটি এমনভাবে আপডেট করুন যাতে এর `toString()` মেথডটি বর্ণনা করে এটি কী ধরনের যোদ্ধা।
মেথডটি `"Fighter is a Wizard"` স্ট্রিংটি রিটার্ন করবে।

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Wizard-দের স্পেল প্রস্তুত করার সুযোগ দিন এবং স্পেল প্রস্তুত না থাকলে তাদের ভালনারেবল করে তুলুন

`Wizard` ক্লাসটি আপডেট করে `prepareSpell()` নামে একটি মেথড যোগ করুন।
ক্লাসটির মনে রাখা উচিত কখন এই মেথডটি কল করা হয়, এবং নিশ্চিত করা উচিত যে এর `isVulnerable()` মেথডটি `false` রিটার্ন করে কেবল তখনই, যখন একটি স্পেল প্রস্তুত থাকে।

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Wizard-এর ড্যামেজ পয়েন্ট হিসাব করুন

`Wizard` ক্লাসটি এমনভাবে আপডেট করুন যাতে এর `getDamagePoints(Fighter)` মেথডটি উপরের নিয়ম অনুযায়ী Wizard-এর দেওয়া ড্যামেজ হিসাব করে।

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
