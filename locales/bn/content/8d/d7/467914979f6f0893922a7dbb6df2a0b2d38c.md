# পরিচিতি

Haxe একটি স্ট্রংলি টাইপড ভাষা, তবে প্রয়োজনে টাইপিং সিস্টেমকে ভেঙে ফেলা যায়। একটি নামে একটি মান অ্যাসাইন করাকে ভ্যারিয়েবল ডিফাইন করা বলা হয়। একটি ভ্যারিয়েবল হয় স্পষ্টভাবে তার টাইপ উল্লেখ করে ডিফাইন করা যায়, অথবা `var` কিওয়ার্ড ব্যবহার করে Haxe কম্পাইলারকে টাইপ অনুমান করতে দিয়ে। তাই নিচের দুটি ভ্যারিয়েবল ডেফিনিশন সমান:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

`=` অপারেটর ব্যবহার করে একটি ভ্যারিয়েবল আপডেট করা যায়:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

ভ্যারিয়েবল থেকে ভিন্ন টাইপের কোনো মান অ্যাসাইন করার চেষ্টা করলে কম্পাইলার একটি এরর দেবে:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Haxe-এ কোড সাধারণত একটি _ফাংশনের_ ভেতরে লেখা হয়, যাকে [_মেথড_](method)-ও বলা হয়। এই ফাংশনগুলো প্যারামিটার (আর্গুমেন্ট) নিতে পারে এবং `return` কিওয়ার্ড ব্যবহার করে মান রিটার্ন করতে পারে। ফাংশন `()` সিনট্যাক্স দিয়ে কল করা হয়। সব ফাংশনেরই একটি রিটার্ন টাইপ থাকতে হবে।

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Haxe-এ স্কোপ নির্ধারিত হয় `{` ও `}` অক্ষরের মাঝে।

Haxe দুই ধরনের কমেন্ট সমর্থন করে। এক লাইনের কমেন্টের আগে `//` বসে, আর মাল্টিলাইন কমেন্ট `/*` ও `*/`-এর মধ্যে রাখা হয়।
