# নির্দেশনা

আপনার বন্ধু Linus একজন লোকোমোটিভ ইঞ্জিনিয়ার, যিনি শহরের মধ্যে মালবাহী ট্রেন চালান। ট্রেন সামলাতে তিনি যেমন অসাধারণ, তেমনি লজিস্টিকস বা কম্পিউটার সামলাতে ততটাই দুর্বল। ট্রেনের বিবরণ গুছিয়ে সাজাতে আর রুটের ডেটার ভুল সংশোধন করতে তিনি আপনার প্রোগ্রামিং সহায়তা নিতে চান।

~~~~exercism/note
এই অনুশীলনীটি স্লাইসিং, ইনডেক্সিং আর `Dict`-এর নানা মেথড দিয়ে সহজেই সমাধান করা যেত। তবে নিচের প্রতিটি কাজ সমাধান করতে আমরা চাই আপনি প্যাকিং (অর্থাৎ স্লার্পিং), আনপ্যাকিং (অর্থাৎ স্প্ল্যাটিং) আর মাল্টিপল অ্যাসাইনমেন্ট অনুশীলন করুন।
~~~~

## 1. সব ওয়াগনের একটি ভেক্টর তৈরি করুন

আপনার বন্ধু প্রতিটি ওয়াগনের আইডেন্টিফায়ার (ID) হিসাব রেখে চলেছেন, কিন্তু সিস্টেমকে যেকোনো সময়ে কতগুলো ওয়াগন প্রসেস করতে হবে, তা তিনি কখনোই নিশ্চিতভাবে জানেন না। এই ডেটা যদি একটি একক `Vector`-এ গুছিয়ে দেওয়া যায়, তবে বাকি লজিস্টিকস প্রোগ্রামের জন্য কাজটা অনেক সহজ হয়ে যাবে।

এমন একটি ফাংশন `get_vector_of_wagons(args...)` বাস্তবায়ন করুন, যা যেকোনো সংখ্যক ওয়াগন ID গ্রহণ করে। প্রতিটি ID একটি ধনাত্মক ইন্টিজার হবে। এরপর ফাংশনটি যেসব ID পেয়েছে, সেগুলো একটি একক `Vector` হিসেবে `return` করবে।

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. ওয়াগনের ভেক্টরটি ঠিক করুন

এখন আপনি ডেটা সম্পর্কে এবং লজিস্টিকস প্রোগ্রামে এটি কীভাবে ব্যবহৃত হয়, সে সম্পর্কে কিছুটা ধারণা পেতে শুরু করেছেন। ID সিস্টেম সবসময় লোকোমোটিভকে **1** আইডি দেয়, আর ট্রেনের বাকি ওয়াগনগুলোকে **1**-এর চেয়ে বড় কোনো এলোমেলোভাবে বাছাই করা ID দেয়।

আপনার বন্ধুকে ট্রেনে দুটি নতুন ওয়াগন জুড়তে হয়েছিল, কিন্তু সিস্টেম আপডেট করতে ভুলে গেছেন! এখন ট্রেনের `Vector`-এ প্রথম দুটি ওয়াগনকে শেষে সরিয়ে নিতে হবে, নইলে সবকিছু এলোমেলো হয়ে যাবে।

ব্যাপারটা আরও জটিল করে তুলতে, আপনার বন্ধু এইমাত্র একটি দ্বিতীয় `Vector` খুঁজে পেয়েছেন, যাতে হারিয়ে যাওয়া কিছু ওয়াগন ID আছে বলে মনে হচ্ছে। তিনি শুধু এটুকু মনে করতে পারছেন যে নতুন ওয়াগনগুলো সরানোর পর, এই দ্বিতীয় `Vector`-এর IDগুলো নির্ধারিত লোকোমোটিভের ঠিক পরেই বসাতে হবে।

তাঁর ভুলগুলো সংশোধন করে ডেটা একত্রিত করে দিলে Linus সত্যিই কৃতজ্ঞ থাকবেন।

এমন একটি ফাংশন `fix_vector_of_wagons(each_wagons_id, missing_wagons)` বাস্তবায়ন করুন, যা ওয়াগন ID ধারণকারী দুটি `Vector` নেয়। এটি প্রথম `Vector`-এর প্রথম দুটি আইটেমকে শেষে সরিয়ে নেবে এবং দ্বিতীয় `Vector`-এর মানগুলো লোকোমোটিভ ID (**1**)-এর পিছনে (_অর্থাৎ ডান দিকে_) বসাবে। এরপর ফাংশনটি পরিবর্তনগুলোসহ একটি `Vector` `return` করবে।

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. বাদ পড়া স্টপগুলো যোগ করুন

এখন যেহেতু সব ওয়াগন ডেটা ঠিক আছে, Linus চান আপনি সিস্টেমের রাউটিং তথ্য আপডেট করুন। একটি পরিবহন রুটে ট্রেন হয়তো মাল তোলা বা নামানোর জন্য কয়েকটি আলাদা স্টেশনে থামে। প্রতিটি যাত্রায় এই মাঝের ডেলিভারি পয়েন্টগুলোর সংখ্যা আলাদা হতে পারে। আপনার বন্ধু চান, বাদ পড়া বা অতিরিক্ত ডেলিভারি তথ্য দিয়ে আপনি সিস্টেমের রাউটিং `Dict` আপডেট করুন।

এমন একটি ফাংশন `add_missing_stops(route, stops...)` বাস্তবায়ন করুন, যা একটি রাউটিং `Dict`-এর পরে চলকসংখ্যক `stop_number => city` Pair গ্রহণ করে। এরপর আপনার ফাংশনটি রাউটিং `Dict`-টি এমনভাবে রিটার্ন করবে যে তাতে একটি অতিরিক্ত `key` যোগ হবে, যেটি ক্রমানুসারে যোগ করা সব স্টপের একটি `Vectors` ধারণ করে।

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. রাউটিং তথ্য সম্প্রসারিত করুন

Linus রাউটিং প্রোগ্রাম নিয়ে কাজ করছেন এবং লক্ষ্য করেছেন যে কিছু রুটে গুরুত্বপূর্ণ কিছু বিবরণ বাদ পড়েছে। প্রাথমিক রুট তথ্য একটি `Dict` হিসেবে তৈরি করা হয়েছে, আর আপনার বন্ধু চান আপনি যা যা বাদ পড়েছে তা দিয়ে ওই `Dict` আপডেট করুন। সিস্টেমের প্রতিটি রুটে সামান্য আলাদা বিবরণ লাগে, তাই Linus সত্যিই একটি জেনেরিক সমাধান চান।

এমন একটি ফাংশন `extend_route_information(route; more_route_information...)` বাস্তবায়ন করুন, যা একটি `Dict` নেয়, যাতে ট্রেন রুটের উৎস ও গন্তব্য শহর থাকে, এবং সেইসাথে চলকসংখ্যক কিওয়ার্ড আর্গুমেন্ট থাকে, যেগুলোতে ট্রেনের গতি, দৈর্ঘ্য বা তাপমাত্রার মতো রাউটিং বিবরণ থাকে। ফাংশনটি সব রাউটিং তথ্যসহ একটি সমন্বিত `Dict` রিটার্ন করবে।

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
