# নির্দেশনা

অঙ্কের একটি স্ট্রিং দেওয়া হলে, n দৈর্ঘ্যের একটি সংলগ্ন সাবস্ট্রিংয়ের বৃহত্তম গুণফল নির্ণয় করুন।

উদাহরণস্বরূপ, `'1027839564'` ইনপুটের জন্য ৩ অঙ্কের একটি সিরিজের বৃহত্তম গুণফল ২৭০ (৯ * ৫ * ৬), আর ৫ অঙ্কের একটি সিরিজের বৃহত্তম গুণফল ৭৫৬০ (৭ * ৮ * ৩ * ৯ * ৫)।

মনে রাখবেন, ইনপুটে এই সিরিজগুলোকে কেবল *পাশাপাশি অবস্থানে* থাকতে হয়; অঙ্কগুলো *সংখ্যাগতভাবে পরপর* হওয়ার দরকার নেই।

`'73167176531330624919225119674426574742355349194934'` ইনপুটের জন্য ৬ অঙ্কের একটি সিরিজের বৃহত্তম গুণফল ২৩৫২০।
