# নির্দেশনা

আপনি একজন উৎসাহী পাখি-পর্যবেক্ষক, যিনি যেকোনো দিনে আপনার বাগানে কত পাখি এসেছে তার হিসাব রাখেন।

আপনি পাখি-পর্যবেক্ষণকে নতুন এক উচ্চতায় নিয়ে যাওয়ার সিদ্ধান্ত নিয়েছেন এবং কয়েকটি টুল বানাতে চলেছেন, যা এই ডেটা ট্র্যাক করতে আর প্রক্রিয়া করতে সাহায্য করবে।

আপনি ডেটা ইন্টিজারের একটি অ্যারে হিসেবে রাখার সিদ্ধান্ত নিয়েছেন।
অ্যারেটির প্রথম সংখ্যাটি হলো আজ আপনার বাগানে আসা পাখির সংখ্যা, দ্বিতীয়টি গতকালের, আর এভাবেই বাকিগুলো।

```exercism/note
বাস্তব জগতের অ্যাপ্লিকেশনে যেখানে যেখানে প্রযোজ্য, সেখানে সবসময় কোর মডিউল ব্যবহার করা উচিত। তবে রিকার্সন সম্পর্কে শেখার উদ্দেশ্যে এই অনুশীলনীতে `List`-এর কোনো ফাংশন ব্যবহার করবেন না।
```

## 1. আজ কত পাখি এসেছে তা দেখুন

`today` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি প্রতিদিনের পাখি-গণনার একটি অ্যারে ইনপুট হিসেবে নেবে এবং আজকের গণনাটি রিটার্ন করবে।
অ্যারেটি খালি হলে এটি `Nothing` রিটার্ন করবে, অন্যথায় গণনাটি একটি `Just`-এ মোড়া থাকবে।

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. আজকের গণনা এক বাড়ান

`incrementDayCount` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি প্রতিদিনের পাখি-গণনার একটি অ্যারে নেবে এবং আজকের গণনাটি এক বাড়িয়ে দেবে।
অ্যারেটি খালি হলে `[1]` রিটার্ন করুন।

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. পাখি আসেনি এমন কোনো দিন ছিল কি না দেখুন

`hasDayWithoutBirds` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি প্রতিদিনের পাখি-গণনার একটি অ্যারে নেবে।
যদি অন্তত একটি দিন এমন থাকে যেদিন বাগানে কোনো পাখি আসেনি, তবে এটি `True` রিটার্ন করবে, অন্যথায় `False`।

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. আসা পাখির মোট সংখ্যা হিসাব করুন

`total` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি প্রতিদিনের পাখি-গণনার একটি অ্যারে নেবে এবং আপনি ডেটা সংগ্রহ শুরু করার পর থেকে আপনার বাগানে আসা পাখির মোট সংখ্যা রিটার্ন করবে।

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্যদিনের চেয়ে ব্যস্ত থাকে।
ব্যস্ত দিন হলো এমন দিন, যেদিন আপনার বাগানে পাঁচটি বা তার বেশি পাখি এসেছে।

`busyDays` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি প্রতিদিনের পাখি-গণনার একটি অ্যারে নেবে এবং ব্যস্ত দিনের সংখ্যা রিটার্ন করবে।

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
