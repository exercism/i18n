# নির্দেশনা

একটি বাইনারি সংখ্যা, যা একটি স্ট্রিং হিসেবে উপস্থাপিত হয় (যেমন '101010'), মৌলিক নীতির ভিত্তিতে তার দশমিক সমতুল্য মানে রূপান্তর করুন।

বাইনারি থেকে দশমিক রূপান্তর বাস্তবায়ন করুন। একটি বাইনারি ইনপুট স্ট্রিং দেওয়া হলে আপনার প্রোগ্রামের একটি দশমিক আউটপুট তৈরি করা উচিত। প্রোগ্রামটির অবৈধ ইনপুট সামলাতে পারা উচিত।

## লক্ষ্য করুন

- রূপান্তরটি নিজেই বাস্তবায়ন করুন।
  রূপান্তরটি আপনার হয়ে করার জন্য অন্য কিছু ব্যবহার করবেন না।

## বাইনারি সম্পর্কে (বেস-২)

দশমিক একটি বেস-১০ পদ্ধতি।

বেস ১০-এ লেখা ২৩ সংখ্যাটিকে ১০-এর ঘাতগুলোর একটি রৈখিক সমন্বয় হিসেবে বোঝা যায়:

- একেবারে ডানদিকের অঙ্কটি ১০^০ = ১ দিয়ে গুণ করা হয়
- পরের সংখ্যাটি ১০^১ = ১০ দিয়ে গুণ করা হয়
- ...
- *n*-তম সংখ্যাটি ১০^*(n-১)* দিয়ে গুণ করা হয়।
- এই সব মান যোগ করা হয়।

তাহলে: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

বাইনারি একই রকম, তবে ১০-এর ঘাতের বদলে ২-এর ঘাত ব্যবহার করে।

তাহলে: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
