# Instructions

আপনি আর আপনার বন্ধুরা কলম-কাগজে খেলা রোল-প্লেয়িং গেম খেলতে ভালোবাসেন, কিন্তু খেয়াল করলেন যে নতুন মানুষকে আপনার দলে যোগ করানো বেশ কঠিন। নতুনরা প্রায়ই চরিত্র তৈরি করতে গিয়ে হিমশিম খায়। শুরুটা কোথা থেকে করতে হবে, তারা জানে না। নতুন খেলোয়াড়দের সাহায্য করার জন্য আপনি ঠিক করলেন একটি ছোট প্রোগ্রাম লিখবেন, যা পুরো প্রক্রিয়াটি ধরে ধরে তাদের পথ দেখাবে।

## 1. নতুন খেলোয়াড়কে স্বাগত জানান

`RPG.CharacterSheet.welcome/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি স্বাগত বার্তা প্রিন্ট করবে, আর `:ok` রিটার্ন করবে।

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. চরিত্রের নাম জিজ্ঞাসা করুন

`RPG.CharacterSheet.ask_name/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি প্রশ্ন প্রিন্ট করবে, উত্তর পাওয়ার জন্য অপেক্ষা করবে, আর শুরুর ও শেষের ফাঁকা জায়গা বাদ দিয়ে সেই উত্তর রিটার্ন করবে।

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. চরিত্রের ক্লাস জিজ্ঞাসা করুন

`RPG.CharacterSheet.ask_class/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি প্রশ্ন প্রিন্ট করবে, উত্তর পাওয়ার জন্য অপেক্ষা করবে, আর শুরুর ও শেষের ফাঁকা জায়গা বাদ দিয়ে সেই উত্তর রিটার্ন করবে।

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. চরিত্রের লেভেল জিজ্ঞাসা করুন

`RPG.CharacterSheet.ask_level/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি প্রশ্ন প্রিন্ট করবে, উত্তর পাওয়ার জন্য অপেক্ষা করবে, আর সেই উত্তর একটি ইন্টিজার হিসেবে রিটার্ন করবে।

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. আগের ধাপগুলোকে একত্রিত করুন

`RPG.CharacterSheet.run/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি নতুন খেলোয়াড়কে স্বাগত জানাবে, চরিত্রের নাম, ক্লাস আর লেভেল জিজ্ঞাসা করবে, আর চরিত্রের শিটটি একটি ম্যাপ হিসেবে রিটার্ন করবে। এটি "Your character" লেবেল দিয়ে ম্যাপটিও প্রিন্ট করবে।

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
