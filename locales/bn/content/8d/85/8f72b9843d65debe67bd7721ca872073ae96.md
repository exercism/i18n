# পরিচিতি

ঠিক যেমন `int` বা অন্য কোনো মৌলিক ডেটা টাইপের জন্য পয়েন্টার তৈরি করা যায়, তেমনি একটি ফাংশনের জন্যও পয়েন্টার তৈরি করা যায়।
একটি ফাংশন পয়েন্টার দিয়ে একটি ফাংশনকে অন্য একটি ফাংশনে পাস করা যায়।
যে ফাংশনকে অন্য একটি ফাংশনে প্যারামিটার মান হিসেবে পাস করা হয়, তাকে ফার্স্ট ক্লাস ফাংশন বলা হয়।
যে ফাংশন এক বা একাধিক ফাংশনকে প্যারামিটার হিসেবে নেয়, অথবা একটি ফাংশন রিটার্ন করে, তাকে হায়ার অর্ডার ফাংশন বলা হয়।

নিচের উদাহরণে `is_even` ও `is_odd` হলো ফার্স্ট ক্লাস ফাংশন।
আর হায়ার অর্ডার ফাংশনটি হলো `test_number`।

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```

`test_number`-এর প্রথম আর্গুমেন্টের জন্য `bool (*func) (int)` ফাংশন সিগনেচারটি ভেতরে পাস করা ফাংশনগুলোর সিগনেচারের সাথে মেলে।
`is_even` ও `is_odd` দুটোই একটি `int` প্যারামিটার নেয় এবং একটি `bool` রিটার্ন করে।
`(*func)`-এ `func` বলতে যে ফাংশনটি ব্যবহার করা হবে তার নাম বোঝায়।
যদি `(*fn)` ব্যবহার করা হতো, তাহলে সেটি এভাবে কল করা হতো: `printf(text, number, fn(number)? "true": "false");`।
ফাংশন পয়েন্টার প্যারামিটারটি পূরণ করতে, `test_number` কল করার সময় প্রত্যাশিত সিগনেচারযুক্ত একটি ফাংশনের নাম পাস করি।
তাই দেখা যায়, একটি ফাংশনের নাম ওই নামের ফাংশনের অ্যাড্রেসের দিকে নির্দেশ করে।

ভুল সিগনেচার দিয়ে একটি ফাংশন পয়েন্টার কল করলে আনডিফাইন্ড বিহেভিয়ার (UB) হয়।
কম্পাইলারের ওপর নির্ভর করে এটি হয়তো কম্পাইলই হবে না, আবার সতর্কবার্তাসহ বা সতর্কবার্তা ছাড়াই কম্পাইল হতে পারে, কিন্তু পরে রানটাইমে ক্র্যাশ করে।
