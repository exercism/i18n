# নির্দেশনা

এই অনুশীলনীতে আপনি একটি রিমোট কন্ট্রোলড কার নিয়ে খেলবেন, যা কেনার জন্য অবশেষে যথেষ্ট টাকা জমিয়ে ফেলেছেন।

গাড়িগুলো সম্পূর্ণ (১০০%) চার্জের ব্যাটারি নিয়ে শুরু করে। প্রতিবার রিমোট কন্ট্রোল দিয়ে গাড়ি চালালে এটি ২০ মিটার যায় এবং ব্যাটারির এক শতাংশ কমে যায়। গাড়িটি তৈরি হওয়ার আগে তার ডাকনাম জানা যায় না।

এই রিমোট কন্ট্রোলড কারটিতে একটি দুর্দান্ত LED ডিসপ্লে আছে, যেখানে দুই ধরনের তথ্য দেখানো হয়:

- এটি এখন পর্যন্ত মোট যে দূরত্ব চালিয়েছে, তা এভাবে দেখানো হয়: `"<METERS> meters"`.
- ব্যাটারিতে বাকি চার্জ, যা এভাবে দেখানো হয়: `"Battery at <PERCENTAGE>%"`.

ব্যাটারি ০% হলে আপনি আর গাড়ি চালাতে পারবেন না এবং ব্যাটারি ডিসপ্লেতে `"Battery empty"` দেখাবে।

## 1. একেবারে নতুন একটি রিমোট কন্ট্রোলড কার তৈরি করুন

`RemoteControlCar.new/0` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি একেবারে নতুন একটি রিমোট কন্ট্রোলড কার স্ট্রাক্ট রিটার্ন করে:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

স্ট্রাক্টে ডাকনাম থাকা আবশ্যক, তাই নিশ্চিত করুন যে `new` ফাংশনে একটি মান ইনিশিয়ালাইজ করা হয়, স্ট্রাক্টে নয়।

## 2. ডাকনাম সহ একেবারে নতুন একটি রিমোট কন্ট্রোলড কার তৈরি করুন

`RemoteControlCar.new/1` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি প্রদত্ত একটি ডাকনাম সহ একেবারে নতুন একটি রিমোট কন্ট্রোলড কার স্ট্রাক্ট রিটার্ন করে:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. দূরত্ব দেখানো

`RemoteControlCar.display_distance/1` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি LED ডিসপ্লেতে যেভাবে দেখানো হয় সেই অনুযায়ী দূরত্ব রিটার্ন করে:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

নিশ্চিত করুন যে ফাংশনটি আর্গুমেন্ট হিসেবে শুধুমাত্র একটি `RemoteControlCar` স্ট্রাক্ট গ্রহণ করে।

## 4. ব্যাটারির শতাংশ দেখানো

`RemoteControlCar.display_battery/1` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি LED ডিসপ্লেতে যেভাবে দেখানো হয় সেই অনুযায়ী ব্যাটারির শতাংশ রিটার্ন করে:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

নিশ্চিত করুন যে ফাংশনটি আর্গুমেন্ট হিসেবে শুধুমাত্র একটি `RemoteControlCar` স্ট্রাক্ট গ্রহণ করে। ব্যাটারি ০% হলে ব্যাটারি ডিসপ্লেতে "Battery empty" দেখাবে।

## 5. চালালে ব্যাটারি ও চালিত দূরত্ব বদলায়

`RemoteControlCar.drive/1` ফাংশনটি ইমপ্লিমেন্ট করুন যা:

- চালিত মিটারের সংখ্যা ২০ বাড়ায়
- ব্যাটারির এক শতাংশ কমায়

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

নিশ্চিত করুন যে ফাংশনটি আর্গুমেন্ট হিসেবে শুধুমাত্র একটি `RemoteControlCar` স্ট্রাক্ট গ্রহণ করে।

## 6. ব্যাটারি শেষ হলে চালানোর বিষয়টি বিবেচনায় নিন

`RemoteControlCar.drive/1` ফাংশনটি এমনভাবে আপডেট করুন যাতে ব্যাটারি শেষ হয়ে গেলে (০% হলে) এটি চালিত দূরত্বও বাড়ায় না এবং ব্যাটারির শতাংশও কমায় না:

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
