# পরিচিতি

একটি সেট হলো অনন্য মানের একটি অপরিবর্তনীয় ও ক্রমহীন সংগ্রহ। একটি সেটের সব এলিমেন্ট একই টাইপের হতে হয়।

`gleam/set` মডিউলটি `Set` টাইপটি ডিফাইন করে এবং সেট নিয়ে কাজ করার ফাংশন সরবরাহ করে।

`set.to_list` ও `set.from_list` দিয়ে আপনি অ্যারে ও সেটকে পরস্পরে রূপান্তর করতে পারেন। সেটে এলিমেন্টের ক্রম নিশ্চিত নয়।

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

`set.new`, `set.insert` ও `set.delete` দিয়ে আপনি সেট তৈরি করতে ও সেগুলোতে মান যোগ করতে পারেন।

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

`set.contains` ও `set.size` ফাংশন দিয়ে আপনি একটি সেটের ভেতরের মান যাচাই করতে পারেন।

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

`set.union` ও `set.intersect` দিয়ে সেট জোড়া লাগানো যায়।

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

আপনি সেট ফিল্টারও করতে পারেন।

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
