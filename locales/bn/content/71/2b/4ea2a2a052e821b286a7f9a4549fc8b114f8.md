# নির্দেশনা

এই অনুশীলনীতে আপনি একটি রোল-প্লেয়িং গেমের মেকানিকগুলো তৈরি করবেন।
একজন খেলোয়াড়ের চরিত্রকে নিচের টাইপ দিয়ে প্রকাশ করা হয়:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

এই গেমের খেলোয়াড়দের স্পেল কাস্ট করা শুরু করার আগে লেভেল ১০-এ পৌঁছাতে হবে, তখনই তাদের ম্যানা পুল আনলক হয়।
আপনি এই গেমের দুটি ফিচার নিয়ে কাজ করছেন: রিভাইভ মেকানিক এবং স্পেল কাস্টিং মেকানিক।

## 1. নিজের পরিচয় দিন

`introduce` ফাংশনের কনটেন্ট লিখুন।
চুপিসারে খেলা প্লেয়াররা হয়তো তাদের নাম গোপন করে রেখেছেন, তাদের পরিচয় দেওয়া হবে `"Mighty Magician"` হিসেবে।
নাহলে নিজের নাম দিয়েই নিজের পরিচয় দিন।

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. রিভাইভ মেকানিক তৈরি করুন

`revive` ফাংশনটি যাচাই করবে যে প্লেয়ারের চরিত্রটি সত্যিই মৃত কি না (তার হেলথ ০-এ পৌঁছেছে কি না)।
মৃত হলে এটি ১০০ হেলথ-সহ একটি নতুন `Player` ইনস্ট্যান্স রিটার্ন করবে।
নাহলে, অর্থাৎ প্লেয়ারের চরিত্রটি যদি মৃত না হয়, `revive` ফাংশনটি `Nothing` রিটার্ন করে।

প্লেয়ারের লেভেল ১০ বা তার বেশি হলে তাকে ১০০ ম্যানা-সহও রিভাইভ করা হবে।
আর প্লেয়ারের লেভেল ১০-এর কম হলে তার ম্যানা হবে `Nothing`।
`revive` ফাংশনটি প্লেয়ারের লেভেল অপরিবর্তিত রাখবে।

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

যার হেলথ ১ বা তার বেশি, এমন প্লেয়ারের উপর `revive` মেথড কল করা হলে ফাংশনটি `Nothing` রিটার্ন করবে।

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. স্পেল কাস্টিং মেকানিক তৈরি করুন

`castSpell` ফাংশনটি আর্গুমেন্ট হিসেবে একটি `Int` নেয়, যা বলে দেয় স্পেলটির ম্যানা খরচ কত, এবং একটি `Player`-ও।
এটি আপডেট হওয়া প্লেয়ার, আর সাথে কাস্ট করা স্পেলটি যে পরিমাণ ড্যামেজ করে তা রিটার্ন করে।
সফলভাবে স্পেল কাস্ট হলে স্পেলটির ম্যানা খরচের দ্বিগুণ ড্যামেজ হয়।
তবে প্লেয়ারের কাছে পর্যাপ্ত ম্যানা না থাকলে কিছুই হয় না, প্লেয়ার অপরিবর্তিত থাকে এবং কোনো ড্যামেজও হয় না।
আর প্লেয়ারের যদি ম্যানা পুলই না থাকে, তবে স্পেল কাস্ট করার চেষ্টা করলে তার হেলথ স্পেলটির ম্যানা খরচের সমান কমে যায় এবং কোনো ড্যামেজ হয় না।

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
