# নির্দেশনা

আপনার কমিউনিটি অ্যাসোসিয়েশন আপনাকে কমিউনিটি গার্ডেনের রেজিস্ট্রেশন পরিচালনা করার জন্য একটি সহজ রেজিস্ট্রি অ্যাপ্লিকেশন তৈরি করতে বলেছে। `Plot` স্ট্রাক্টটি ইতিমধ্যেই আপনার জন্য সরবরাহ করা হয়েছে।

## 1. বাগান খুলুন

`CommunityGarden.start/1` ফাংশনটি ইমপ্লিমেন্ট করুন, এটি ঐচ্ছিক কিওয়ার্ড লিস্ট হিসেবে অপশন গ্রহণ করবে যা _এজেন্ট প্রসেসে_ পাঠানো হবে। বাগানের প্রাথমিক স্টেটটি খালি প্লট সংগ্রহের প্রতিনিধিত্ব করার জন্য ইনিশিয়ালাইজ করা উচিত। এটি বাগানের `pid` সহ একটি `:ok` টাপল রিটার্ন করবে।

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. রেজিস্ট্রেশনগুলোর তালিকা করুন

`CommunityGarden.list_registrations/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি কমিউনিটি গার্ডেনের `pid` গ্রহণ করবে। এটি রেজিস্টার্ড সংরক্ষিত প্লটগুলোর একটি অ্যারে রিটার্ন করবে।

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> এই মুহূর্তে, আমরা প্লট রেজিস্টার করার ক্ষমতা যোগ করিনি, তাই এই অ্যারেটি খালি থাকা উচিত।

## 3. একজন ব্যক্তির নামে প্লট রেজিস্টার করুন

`CommunityGarden.register/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি কমিউনিটি গার্ডেনের `pid` এবং প্লট রেজিস্টার করার জন্য একটি নাম গ্রহণ করবে। সফল হলে এটি প্লটের আইডি এবং যার নামে রেজিস্টার করা হয়েছে তা সহ `Plot` স্ট্রাক্ট রিটার্ন করবে।

আইডিগুলো ইনক্রিমেন্টাল এবং ইউনিক হওয়া উচিত। আপনি এজেন্টের স্টেটে একটি আইডি কাউন্টার রাখতে পারেন।

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. প্লট রিলিজ করুন

`CommunityGarden.release/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি রিলিজ করার জন্য প্লটের `pid` এবং `id` গ্রহণ করবে। সফল হলে এটি `:ok` রিটার্ন করবে। যখন একটি প্লট রিলিজ করা হয়, তখন আইডি পুনরায় ব্যবহার করা হয় না, এটি শুধুমাত্র একটি ইউনিক আইডেন্টিফায়ার হিসেবে ব্যবহৃত হয়।

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. একটি রেজিস্টার্ড প্লট পান

`CommunityGarden.get_registration/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি চেক করার জন্য প্লটের `pid` এবং `id` গ্রহণ করবে। যদি প্লটটি রেজিস্টার্ড থাকে তবে এটি প্লটটি রিটার্ন করবে, এবং যদি আনরেজিস্টার্ড থাকে তবে `:not_found` রিটার্ন করবে।

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
