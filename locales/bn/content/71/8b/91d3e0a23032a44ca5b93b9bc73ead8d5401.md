# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি ইনভেন্টরি সিস্টেম পরিচালনা করবেন।

ইনভেন্টরিটি আইটেমের নাম অনুযায়ী সাজানো থাকবে এবং কোন আইটেম কত সংখ্যায় আছে তার হিসাব রাখবে।

আপনাকে ইনভেন্টরিতে আইটেম যোগ করার কাজ সামলাতে হবে।
কোনো আইটেম একটি নির্দিষ্ট অ্যারেতে যতবার থাকবে, ইনভেন্টরিতে সেই আইটেমের পরিমাণ ঠিক ততবার `1` করে বাড়াতে হবে।
এছাড়া অনুরোধ করা হলে পরিমাণ `1` কমিয়ে ইনভেন্টরি থেকে আইটেম মুছে ফেলার কাজও আপনাকে সামলাতে হবে।

সবশেষে, আপনাকে এমন একটি ফাংশন লিখতে হবে যা একটি প্রদত্ত ইনভেন্টরির সব কী (key) ও মানের জোড়া `tuples`-এর একটি `list` হিসেবে রিটার্ন করবে।


## 1. একটি অ্যারের ভিত্তিতে ইনভেন্টরি তৈরি করুন

এমন একটি `create_inventory(<input list>)` ফাংশন লিখুন যা ইনপুট হিসেবে দেওয়া আইটেমের একটি অ্যারে থেকে একটি "ইনভেন্টরি" তৈরি করে।
এটি একটি `dict` রিটার্ন করবে, যেখানে প্রতিটি আইটেমের নামের সাথে তার নিজ নিজ পরিমাণ জোড়া থাকবে।

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. একটি অ্যারে থেকে বিদ্যমান ডিকশনারিতে আইটেম যোগ করুন

এমন একটি `add_items(<inventory dict>, <item list>)` ফাংশন লিখুন যা পাস করা ইনভেন্টরিতে আইটেমের একটি অ্যারে যোগ করে:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. ইনভেন্টরি থেকে আইটেম কমান

এমন একটি `decrement_items(<inventory dict>, <items list>)` ফাংশন লিখুন যা আইটেমের একটি `list` নেয়।
আপনার ফাংশনটি `list`-এ কোনো আইটেম যতবার থাকবে, প্রতিবার সেই আইটেমের সংখ্যা থেকে `1` কমাবে:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

ইনভেন্টরিতে কোনো আইটেমের সংখ্যা 0-এর নিচে নামা যাবে না।
 ইনপুট `list`-এ কোনো আইটেম যতবার আছে, তা যদি উপলব্ধ সংখ্যার চেয়ে বেশি হয়, তবে ওই আইটেমের জন্য লেখা পরিমাণ 0-ই থাকবে।
 সংখ্যা 0 হয়ে গেলে আরও কমানোর অনুরোধগুলো উপেক্ষা করতে হবে।

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. ইনভেন্টরি থেকে একটি এন্ট্রি সম্পূর্ণ মুছে ফেলুন

এমন একটি `remove_item(<inventory dict>, <item>)` ফাংশন লিখুন যা ইনভেন্টরি থেকে একটি আইটেম ও তার সংখ্যা সম্পূর্ণভাবে মুছে ফেলে:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

ইনভেন্টরিতে আইটেমটি না পাওয়া গেলে ফাংশনটি মূল ইনভেন্টরিটি অপরিবর্তিত অবস্থায় রিটার্ন করবে।

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. ইনভেন্টরির সম্পূর্ণ বিষয়বস্তু রিটার্ন করুন

এমন একটি `list_inventory(<inventory dict>)` ফাংশন লিখুন যা একটি ইনভেন্টরি নেয় এবং `(item, quantity)` টাপলের একটি অ্যারে রিটার্ন করে।
অ্যারেটিতে শুধু _উপলব্ধ_ আইটেমগুলোই (_যেগুলোর পরিমাণ শূন্যের চেয়ে বেশি_) থাকবে:

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
