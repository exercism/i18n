# পরিচিতি

## মূল বিষয়

Java একটি স্ট্যাটিক টাইপড ভাষা, অর্থাৎ কম্পাইলের সময়েই একটি ভ্যারিয়েবলের টাইপ জানা থাকে।
কোনো নামে একটি মান অ্যাসাইন করাকে ভ্যারিয়েবল ডিফাইন করা বলা হয়।
ভ্যারিয়েবল ডিফাইন করতে তার টাইপ স্পষ্টভাবে উল্লেখ করতে হয়।

```java
int explicitVar = 10;
```

ভ্যারিয়েবলের মান আপডেট করা হয় `=` অপারেটরের মাধ্যমে।
এখানে `=` গাণিতিক সমতা বোঝায় না।
এটি কেবল একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করে।
একবার ডিফাইন হয়ে গেলে ভ্যারিয়েবলের টাইপ আর কখনো পরিবর্তন করা যায় না।

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java একটি [অবজেক্ট-ওরিয়েন্টেড ভাষা][object-oriented-programming] এবং এতে সব ফাংশন একটি _ক্লাসে_ ডিফাইন করা আবশ্যক।
ক্লাস ডিফাইন করতে `class` কিওয়ার্ডটি ব্যবহার করা হয়।

```java
class Calculator {
    // ...
}
```

ক্লাসের ভেতরের ফাংশনকে _মেথড_ বলা হয়।
প্রতিটি মেথডে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে।
সব প্যারামিটারের টাইপ স্পষ্টভাবে লিখতে হয়, প্যারামিটারের জন্য কোনো টাইপ ইনফারেন্স নেই।
একইভাবে, রিটার্ন টাইপও স্পষ্টভাবে উল্লেখ করতে হয়।
`return` কিওয়ার্ড দিয়ে মেথড থেকে মান রিটার্ন করা হয়।
অন্য ক্লাস থেকে একটি মেথড কল করার সুযোগ দিতে `public` অ্যাক্সেস মডিফায়ার যোগ করতে হয়।

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

একটি মেথড ইনভোক করা বা কল করা হয় এভাবে: তার ক্লাস ও মেথডের নাম উল্লেখ করে এবং মেথডের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Java-তে স্কোপ নির্ধারিত হয় `{` আর `}` অক্ষর দুটির মধ্যে।

Java দুই ধরনের কমেন্ট সমর্থন করে।
একলাইনের কমেন্টের আগে `//` বসে আর বহুলাইনের কমেন্ট লেখা হয় `/*` ও `*/`-এর মধ্যে।

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
