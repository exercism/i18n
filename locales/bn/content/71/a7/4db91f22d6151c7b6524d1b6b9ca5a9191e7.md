# ভূমিকা

Gleam-এ স্ট্রিং হলো ডাবল কোটেশন দিয়ে ঘেরা অপরিবর্তনীয় টেক্সট। এগুলো ইউনিকোড ক্যারেক্টার সমর্থন করে এবং মাল্টি-লাইন হতে পারে।

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

`<>` অপারেটর ব্যবহার করে স্ট্রিংগুলোকে একসাথে জোড়া লাগানো যায়:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

স্ট্যান্ডার্ড লাইব্রেরির [`gleam/string`][stdlib] মডিউলটি স্ট্রিং নিয়ে কাজ করার ফাংশন প্রদান করে।

কেস এক্সপ্রেশনে স্ট্রিং ম্যাচ করা যায়:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

আপনি যদি একটি স্ট্রিংয়ের শুরুর অংশের সাথে ম্যাচ করতে চান এবং বাকি অংশটি একটি ভ্যারিয়েবলে অ্যাসাইন করতে চান, তাহলে `<>` অপারেটর প্যাটার্ন ব্যবহার করতে পারেন:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
