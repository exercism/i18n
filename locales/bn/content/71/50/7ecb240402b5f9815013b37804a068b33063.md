# টেস্ট

## টেস্ট চালানো

কোনো অনুশীলনীর ডিরেক্টরিতে থাকলে আপনি দুটি সাবডাইরেক্টরি দেখতে পাবেন:

* `Sources/<Exercise>` ডিরেক্টরিতে আপনার অনুশীলনীর সমাধান থাকে
* `Tests/<Exercise>Tests` ডিরেক্টরিতে অনুশীলনীটির জন্য চালানোর টেস্টগুলো থাকে

আপনি যদি সঠিক ডিরেক্টরিতে থাকেন (অর্থাৎ যে ডিরেক্টরিতে `Sources` আর `Tests` আছে), তাহলে `swift test` রান করে ওই অনুশীলনীর টেস্টগুলো চালাতে পারবেন:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

একটি টেস্ট পাস হয়ে গেলে পরের টেস্টটি চালু করতে `@Test` স্টেটমেন্ট থেকে `.enabled(if: RUNALL)` মুছে ফেলুন। বিকল্পভাবে, Linux বা macOS-এ `RUNALL` এনভায়রনমেন্ট ভ্যারিয়েবলটি `true` করে দিয়ে আপনি সব টেস্ট একসাথে চালাতে পারেন:

```bash
$ export RUNALL=true
```

আর যদি আপনি Windows-এ PowerShell ব্যবহার করেন:

```powershell
set RUNALL=true
```

## সমাধান জমা দেওয়া

Exercism-এ একটি সমাধান আপলোড করতে হলে আপনাকে এমন ডিরেক্টরিতে থাকতে হবে যেখানে `Sources` আর `Tests` ডিরেক্টরি দুটি আছে।

```bash
$ exercism submit 
```
