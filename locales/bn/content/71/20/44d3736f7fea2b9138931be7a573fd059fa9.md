# ভূমিকা

F#-এ `list` হলো শূন্য বা তার বেশি মানের একটি অপরিবর্তনীয় সংগ্রহ। অ্যারের সব মানের টাইপ একই হতে হবে। যেহেতু অ্যারে অপরিবর্তনীয়, একবার একটি অ্যারে তৈরি হলে তার মান কখনোই পরিবর্তন হতে পারে না। যে কোনো ফাংশন/অপারেটর যা একটি অ্যারে পরিবর্তন করে বলে মনে হয় (যেমন একটি এলিমেন্ট যোগ করা), আসলে একটি নতুন অ্যারে রিটার্ন করবে।

অ্যারে নিচের মতো করে ডিফাইন করা যায়:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

একটি অ্যারে একটি এলিমেন্ট যোগ করার সবচেয়ে কমন উপায় হলো `::` (কনস) অপারেটর:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

একটি F# অ্যারের একটি _হেড_ (প্রথম এলিমেন্ট) এবং একটি _টেল_ (প্রথম এলিমেন্টের পরের সবকিছু) থাকে। একটি অ্যারের টেল নিজেই একটি অ্যারে।

অ্যারে হয় `List` মডিউলে ডিফাইন করা ফাংশন ও অপারেটর দিয়ে পরিচালনা করা হয়, অথবা _অ্যারে_ ও _কনস_ প্যাটার্ন ব্যবহার করে প্যাটার্ন ম্যাচিংয়ের মাধ্যমে হাতে হাতে পরিচালনা করা হয়:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

প্যাটার্ন ম্যাচিংয়ের সময় আপনি একটি মান _বাতিল_ করতে পারেন; যখন আপনার একটি মানের _দরকার নেই_ (অর্থাৎ আপনি মানটি _ব্যবহার_ করতে যাচ্ছেন না) তখন এটি বোঝাতে আপনি একটি আন্ডারস্কোর (`'_'`) ব্যবহার করতে পারেন:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

একক `'_'` প্যাটার্ন ম্যাচিংয়ের সময় সর্বদা _শেষে_ আসা উচিত, যে কোনো মান যা অন্য কোনো কেসের সাথে _মেলে না_ তা এই কেস দ্বারা পরিচালিত হবে।
