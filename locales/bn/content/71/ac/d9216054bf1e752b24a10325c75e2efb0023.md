# পরিচিতি

Factor-এর বেশিরভাগ সিকোয়েন্স ওয়ার্ড *নতুন* সিকোয়েন্স রিটার্ন করে আর তাদের ইনপুট অপরিবর্তিত রাখে, কিন্তু সময়ের সাথে বদলে যাওয়া স্টেট সংরক্ষণ করতে চাইলে অ্যারে ও ভেক্টর দুটোই **ইন-প্লেস মিউটেশন** সমর্থন করে।

`set-nth` আর `change-nth` জায়গাতেই একটি স্লট বদলে দেয়, আর তা অ্যারে বা ভেক্টর দুইয়ের ওপরই কাজ করে। `<array>` নির্দিষ্ট দৈর্ঘ্যের একটি মিউটেবল অ্যারে তৈরি করে; `V{ }` লিটারাল, `<vector>`, `push` আর `pop` শুধু ভেক্টরের জন্যই প্রযোজ্য, কারণ অ্যারের দৈর্ঘ্য বদলানো যায় না। `clone` সিকোয়েন্সটির একটি অনুলিপি বানায়, যাতে পরের মিউটেশনগুলো মূলটিতে ছড়িয়ে না পড়ে।

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
