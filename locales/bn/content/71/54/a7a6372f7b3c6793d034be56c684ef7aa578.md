# নির্দেশাবলি

হাতে-কলমে জাদুকর হওয়ার পথে এলিসের কিছু মৌলিক বিষয় অনুশীলন করা দরকার।
তার কাছে কার্ডের একটি স্ট্যাক আছে, যেটি নিয়ে সে নানা কাজ করতে চায়।

কাজটা একটু সহজ করার জন্য সে শুধু ১ থেকে ১০ নম্বর কার্ডগুলোই ব্যবহার করে।

## 1. নির্দিষ্ট কিছু কার্ড দিয়ে একটি স্লাইস তৈরি করুন

কার্ড নিয়ে অনুশীলন করার সময় এলিস ডেকের তার পছন্দের তিনটি কার্ড দিয়ে শুরু করতে ভালোবাসে: ২, ৬ আর ৯।
এমন একটি ফাংশন `FavoriteCards` লিখুন যা ওই কার্ডগুলো একই ক্রমে নিয়ে একটি স্লাইস রিটার্ন করে।

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. স্ট্যাক থেকে একটি কার্ড বের করা

প্রদত্ত স্ট্যাক থেকে `index` অবস্থানের কার্ডটি রিটার্ন করুন।

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

ইনডেক্স যদি সীমার বাইরে চলে যায় (অর্থাৎ ঋণাত্মক হয় বা স্ট্যাকের শেষের পরে চলে যায়), তাহলে আমরা `-1` রিটার্ন করতে চাই:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
Go-এর প্রচলিত রীতি অনুযায়ী, "সীমার বাইরে" এমন একটি মান রিটার্ন করার বদলে একটি এরর রিটার্ন করা হয়।
এখানে ধনাত্মক ইন্টিজার প্রত্যাশিত হলে "সীমার বাইরে" বোঝাতে মানটি হয় `-1`।
এরর রিটার্ন করার সময় এররের সাথে [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) রিটার্ন করাটাই আদর্শ ধরা হয়।
সঠিক রিটার্ন ভ্যালু-সহ এরর রিটার্ন করা নিয়ে ভবিষ্যতের একটি অনুশীলনীতে আলোচনা করা হবে।
~~~~

## 3. স্ট্যাকে একটি কার্ড বদল করা

`index` অবস্থানের কার্ডটিকে প্রদত্ত নতুন কার্ডের সাথে বদলে দিন এবং সমন্বিত স্ট্যাকটি রিটার্ন করুন।
মনে রাখবেন, এটি ইনপুট স্লাইসটিকে পরিবর্তন করবে, আর এটাই প্রত্যাশিত আচরণ।

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

ইনডেক্স যদি সীমার বাইরে চলে যায় (অর্থাৎ ঋণাত্মক হয় বা স্ট্যাকের শেষের পরে চলে যায়), তাহলে আমরা নতুন কার্ডটি স্ট্যাকের শেষে যোগ করতে চাই:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. স্ট্যাকের উপরে কার্ড যোগ করা

`value` প্যারামিটারে উল্লেখ করা কার্ড বা কার্ডগুলো স্ট্যাকের উপরে যোগ করুন।

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

`value` প্যারামিটারের জন্য কোনো আর্গুমেন্ট না দিলে ফলাফলটি মূল স্লাইসের সমান হয়।

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. স্ট্যাক থেকে একটি কার্ড সরানো

স্ট্যাক থেকে `index` অবস্থানের কার্ডটি সরিয়ে স্ট্যাকটি রিটার্ন করুন।
মনে রাখবেন, এটি ইনপুট স্লাইসটি পরিবর্তন করতে পারে, আর তাতে কোনো সমস্যা নেই।

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

ইনডেক্স যদি সীমার বাইরে চলে যায় (অর্থাৎ ঋণাত্মক হয় বা স্ট্যাকের শেষের পরে চলে যায়), তাহলে আমরা স্ট্যাকটি অপরিবর্তিত রাখতে চাই:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
