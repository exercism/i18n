# সংখ্যা

ক্রিস্টালে `Number` নামে একটি টাইপ আছে, যেটি সব সংখ্যাগত টাইপের মূল টাইপ।
Number টাইপের ভেতরে দুটি প্রধান উপ-টাইপ আছে: [`Int`][int] ও [`Float`][float]।

`Int` হলো ইন্টিজার শব্দের সংক্ষিপ্ত রূপ, এটি পূর্ণসংখ্যা বোঝায়।
`Int` ঋণাত্মক ও ধনাত্মক দুটোই হতে পারে, এতে দশমিক বিন্দু থাকে না।

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` দশমিক বিন্দুযুক্ত সংখ্যা বোঝায়।
`Float`-ও ঋণাত্মক ও ধনাত্মক দুটোই হতে পারে।

```crystal
10.5.class
# => Float64
```

## `Int` ও `Float`-এর মধ্যে রূপান্তর

'to_i' ও 'to_f' মেথড ব্যবহার করে আপনি `Int` ও `Float`-এর মধ্যে রূপান্তর করতে পারেন।
`Float` থেকে `Int`-তে রূপান্তরের সময় সংখ্যাটি নিচের দিকে রাউন্ড করা হয়।

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## গাণিতিক অপারেটর

আপনি `Int` ও `Float`-এর উপর [মৌলিক গাণিতিক অপারেটরগুলো][math] ব্যবহার করতে পারেন।
অপারেটরগুলো হলো `+`, `-`, `*`, `/` এবং `%`।
এই অপারেটরগুলো ব্যবহারের সময় আপনি `Int` ও `Float` মিলিয়ে ব্যবহার করতে পারেন।

### যোগ, বিয়োগ ও গুণ

যোগের জন্য `+` অপারেটর, বিয়োগের জন্য `-` অপারেটর এবং গুণের জন্য `*` অপারেটর ব্যবহার করা হয়।

| অপারেটর | উদাহরণ         |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### ভাগ

সংখ্যাকে ভাগ করার জন্য ভাগ ব্যবহার করা হয়।
ভাগের জন্য `/` অপারেটরটি ব্যবহার করা হয়।
ফলাফল সবসময় Float হবে।

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
কিছু প্রোগ্রামিং ভাষায় শূন্য দিয়ে ভাগ করলে ফলাফল একটি এরর হয়।

ক্রিস্টালে শূন্য দিয়ে ভাগ করলে ফলাফল হয় `Infinity` বা `-Infinity`।
একমাত্র ব্যতিক্রম হলো শূন্যকে শূন্য দিয়ে ভাগ করা, যার ফলাফল `NaN` (Not a Number)।
`Infinity` ও `NaN` হলো `Float` টাইপের বিশেষ মান।

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## ইন্টিজার ভাগ

সংখ্যাকে ভাগ করে ফলাফলের পূর্ণ অংশ পেতে ইন্টিজার ভাগ ব্যবহার করা হয়।
ফলাফলটি সবসময় নিচের দিকে রাউন্ড হয়ে একটি Int-এ পরিণত হয়।

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
ইন্টিজার ভাগে শূন্য দিয়ে ভাগ করলে `DivisionByZeroError` হয়।
এটি সাধারণ ভাগের থেকে আলাদা।
~~~~

### মডুলাস

ভাগের ভাগশেষ পেতে মডুলাস ব্যবহার করা হয়।
মডুলাসের জন্য `%` অপারেটরটি ব্যবহার করা হয়।

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
মডুলো ব্যবহার করে শূন্য দিয়ে ভাগ করলে DivisionByZeroError হয়।
এটি সাধারণ ভাগের থেকে আলাদা।

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## সূচকীকরণ

সংখ্যাকে ঘাতে উন্নীত করতে সূচকীকরণ ব্যবহার করা হয়।
সূচকীকরণের জন্য `**` অপারেটরটি ব্যবহার করা হয়।
একটি `Float` ও একটি `Int` নিয়ে করা অপারেশনের ফলাফল একটি `Float` হবে।

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## রাউন্ডিং

`round` মেথডটি একটি ঐচ্ছিক আর্গুমেন্ট নেয়: কত দশমিক স্থান পর্যন্ত রাউন্ড করতে হবে তার সংখ্যা।
দশমিক স্থানের ডিফল্ট সংখ্যা 0।

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### উপরে ও নিচে রাউন্ডিং

`ceil` ও `floor` মেথড ব্যবহার করে আপনি উপরে বা নিচে রাউন্ড করে একটি `Int` পেতে পারেন।
`ceil` মেথড উপরে রাউন্ড করে, আর `floor` মেথড নিচে রাউন্ড করে।

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## অগ্রাধিকার ও বন্ধনী

ক্রিস্টাল বন্ধনী(`()`) ব্যবহারের সুযোগ দেয়, যা দিয়ে এক্সপ্রেশনগুলোকে দলবদ্ধ করা যায়।
অপারেশনের ক্রম বদলাতে চাইলে এটি কাজে লাগে।

একাধিক গাণিতিক অপারেটর ব্যবহার করার সময় অপারেশনের ক্রম গণিতের মতোই, যাকে [PEMDAS][pemdas] বলা হয়।
এটি এই ক্রম অনুসরণ করে: বন্ধনী(`()`), সূচক(`**`), গুণ(`*`) ও ভাগ(`/`), এবং যোগ(`+`) ও বিয়োগ(`-`)।

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
