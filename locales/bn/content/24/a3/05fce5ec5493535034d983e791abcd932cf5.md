# পরিচিতি

Clojure একটি ফাংশনাল ভাষা, তাই এখানে ফাংশনগুলো ফার্স্ট-ক্লাস সিটিজেন। এর মানে হলো, ডেটার মতোই ফাংশনগুলোকে অন্য ফাংশনে পাস করা যায় এবং অন্য ফাংশন দিয়েই সেগুলো তৈরি করা যায়। ক্লোজারে বিশেষ করে হায়ার-অর্ডার ফাংশনের একটি সমৃদ্ধ সংগ্রহ আছে, যেগুলো বিদ্যমান ফাংশনের ভিত্তিতে নতুন ফাংশন তৈরি করে। এখানে আমরা চারটি গুরুত্বপূর্ণ উদাহরণ দেখব: `partial`, `comp`, `memoize` এবং `juxt`. এই ফাংশন-উৎপাদক ফাংশনগুলো হায়ার-অর্ডার ফাংশনের আরও বড় একটি শ্রেণির অন্তর্ভুক্ত, যেমন `map`, `reduce`, `apply`, `complement`, ইত্যাদি, যেগুলো বিদ্যমান ফাংশনের উপর কাজ করে।

## partial

সাধারণভাবে, `my-function` নামের একটি বিদ্যমান ফাংশনের ক্ষেত্রে, যার প্যারামিটারগুলো `p1, p2, ..., pN`, আমরা এর কিছু প্যারামিটার `p1, p2, ..., pM`-কে `v1, v2, ..., vM` ধ্রুবক মান দিয়ে স্থির করে দিতে পারি। এটি করতে আমরা `partial` এভাবে প্রয়োগ করি: `(partial my-function v1 v2 ... vM)`.

ফলাফল হলো একটি নতুন ফাংশন, যা `p1=v1, p2=v2, ..., pM=vM` স্থির করে মূল `my-function`-কে প্রয়োগ করে। আমাদের নতুন ফাংশনটি ইনপুট হিসেবে বাকি প্যারামিটারগুলো `pM+1, pM+2, ..., pN` নেয়, যাদের মান `partial` প্রয়োগ করার সময় উল্লেখ করা হয়নি:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

একটি সহজ উদাহরণ হিসেবে, চলুন `inc-by-9` নামের একটি ফাংশন ডিফাইন করি, যা আমরা যা-ই পাস করি না কেন, একটি নির্দিষ্ট পরিমাণ ৯ দিয়ে বাড়িয়ে দেয়। আমরা এমন একটি ফাংশন এভাবে তৈরি করতে পারি:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

দ্বিতীয় উদাহরণ হিসেবে, আমাদের কাছে `generic-greetings` নামের একটি ফাংশন আছে, যা যাকে অভিবাদন জানাতে চাই তার নামের সাথে শুরুর ও শেষের টেক্সট বার্তা ব্যবহার করে:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

আর `partial` ব্যবহার করে সবসময় একটি নির্দিষ্ট অভিবাদন বার্তা ব্যবহার করা যায়:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` ব্যবহার করে আমরা যত খুশি ফাংশনের কম্পোজিশন তৈরি করতে পারি। সাধারণভাবে, `N` সংখ্যক ফাংশন `f1, f2, ..., fN` কম্পোজ করা মানে হলো সেগুলোকে ক্রমানুসারে প্রয়োগ করা, অর্থাৎ একটির আউটপুট পরেরটিতে পাস করা। গাণিতিক রূপে এটি এভাবে প্রকাশ করা হয়:

```
f1 (f2 (... fN(x)))
```

Clojure-তে এটি করা মানে এটিই:
```clojure
(f1 (f2 (... (fN x))))
```

comp ব্যবহার করে আমরা একটি নতুন ফাংশন তৈরি করতে পারি, যা আমাদের হয়ে এই কম্পোজিশনটি করে দেয়:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

উদাহরণ হিসেবে ধরা যাক, আমরা কিছু সংখ্যার যোগফল বের করতে চাই এবং তারপর ফলাফলটি ৬ দিয়ে গুণ করতে চাই। আমরা এভাবে তা করতে পারি:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` একটি নির্দিষ্ট ইনপুটের সাথে সম্পর্কিত আগে গণনা করা ফলাফল পুনরায় ব্যবহার করার সুযোগ দেয়। একই ইনপুট পেলে *মেমোাইজ করা* ফাংশনটি আবার নতুন করে গণনা না করেই একই ফলাফল রিটার্ন করে। এটি এই বিষয়টির সুবিধা নেয় যে `clojure` ফাংশনগুলো ডিফল্টভাবে *রেফারেনশিয়ালি ট্রান্সপারেন্ট*: একই ইনপুট পেলে তারা সবসময় একই আউটপুট দেয়, ফলে আগের গণনাগুলো সহজেই পুনরায় ব্যবহার করা সম্ভব হয়।

এটি কীভাবে কাজ করে দেখার জন্য, চলুন একটি কৃত্রিম উদাহরণ নিই, যেখানে ফাংশনটি আউটপুট দেওয়ার আগে দুই সেকেন্ড ঘুমায়, যাতে আমরা `memoize` ব্যবহারের আগে ও পরে *গণনার সময়* সহজে তুলনা করতে পারি।

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` এমন একটি ফাংশন তৈরি করে, যা তাকে পাস করা ফাংশনগুলোকে বাম থেকে ডান ক্রমে প্রয়োগ করে। ফলাফল হলো একটি ভেক্টর, যার উপাদান হিসেবে থাকে প্রতিটি ফাংশনের আলাদা আলাদা ফলাফল:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

সহজ উদাহরণ হিসেবে, আমরা এমন একটি ফাংশন তৈরি করি, যা x-কে ২ থেকে ৫ পর্যন্ত ধারাবাহিক গুণনীয়ক দিয়ে গুণ করে গুণফল নির্ণয় করে:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
