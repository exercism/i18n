# ভূমিকা

ডাইনামিক মেমরি লাইব্রেরি ফাংশনের মাধ্যমে বাস্তবায়িত হয়, যা প্রোগ্রামার রানটাইমে মেমরি অ্যালোকেট ও ডি-অ্যালোকেট করতে ব্যবহার করেন।
যেহেতু মেমরি অ্যালোকেট ও ডি-অ্যালোকেট করার নিয়ন্ত্রণ প্রোগ্রামারের হাতেই থাকে, তাই ডাইনামিক মেমরির নিরাপত্তা নির্ভর করে প্রোগ্রামার কতটা মানবিক ভুল থেকে মুক্ত, তার উপর।
এই কারণেই ডাইনামিক মেমরি প্রোগ্রামিং বাগের বড় একটি উৎস, আর হ্যাকিং আক্রমণের একটি বড় লক্ষ্যও।

## malloc

`malloc` হলো `stdlib.h`-তে ঘোষিত একটি ফাংশন, যা ডাইনামিক মেমরি অ্যালোকেট করতে ব্যবহৃত হয়।
অ্যালোকেশন সফল হলে এমন একটি পয়েন্টার রিটার্ন হয়, যা অ্যালোকেট করা মেমরির প্রথম বাইটের অ্যাড্রেসের দিকে ইশারা করে।
অ্যালোকেশন সফল না হলে `NULL` রিটার্ন হয়।
`malloc`-এর ফলাফল `NULL` কি না তা যাচাই করে নেওয়া এবং ব্যর্থ হলে সুন্দরভাবে সামলে নেওয়া বিচক্ষণতার পরিচয়।
রিটার্ন হওয়া পয়েন্টারটি `pointer-to-void` টাইপের, যাকে মোটামুটি একটি "জেনেরিক" পয়েন্টার হিসেবে ধরা যায়, যা মেমরিতে ব্যবহৃত নির্দিষ্ট টাইপে রূপান্তর করা যায়।
`malloc`-এর একটি প্যারামিটার আছে, যা হলো প্রয়োজনীয় মেমরির আকার, বাইটে।
একটি অ্যারে অ্যালোকেট করতে হলে মোট আকার = প্রতিটি এলিমেন্টের ডেটা টাইপের আকার × এলিমেন্টের সংখ্যা।
প্রতিটি এলিমেন্টের ডেটা টাইপের আকার বের করতে সাধারণত `sizeof` অপারেটর ব্যবহার করা হয়।
নিচের উদাহরণটি এটি দেখায়

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

মনে রাখা জরুরি, `malloc` দিয়ে নতুন অ্যালোকেট করা মেমরি ইনিশিয়ালাইজ করা থাকে না, বরং সেখানে গার্বেজ ভ্যালু থাকতে পারে।
খেয়াল করুন, `numbers` পয়েন্টারের `sizeof` কিন্তু অ্যারের এলিমেন্টের সংখ্যা নয়, আবার অ্যালোকেট করা মোট মেমরির পরিমাণও নয়।
`malloc` যে পয়েন্টার রিটার্ন করে তার আকার ওই নির্দিষ্ট সিস্টেমে যেকোনো পয়েন্টারের আকারের সমান।
উদাহরণের কোডটি একটি ৬৪-বিট সিস্টেমে চালানো হয়েছিল, তাই পয়েন্টারের আকার ছিল ৮ বাইট (প্রতি বাইটে ৮ বিট দিয়ে গুণ করলে = ৬৪ বিট)।
পয়েন্টারের টাইপটি নিজে থেকেই pointer-to-void থেকে pointer-to-int-এ রূপান্তরিত হয়েছিল।
এটি স্পষ্টভাবেও রূপান্তর করা যেত, এভাবে: `int * numbers = (int *) malloc(sizeof(int) * count);`.
যদি মানগুলো পড়ার আগেই নিশ্চিতভাবে লেখা হবে, তাহলে মেমরি অ্যালোকেট করার একটি দক্ষ উপায় হতে পারে `malloc` ব্যবহার করা।
কিন্তু যদি সম্ভাবনা থাকে যে মানগুলো ইনিশিয়ালাইজ হওয়ার আগেই পড়া হতে পারে, তাহলে `malloc` ব্যবহার করা ঝুঁকিপূর্ণ।
মেমরি অ্যালোকেট করার আরও নিরাপদ উপায় হলো `calloc` ব্যবহার করা, যা নতুন অ্যালোকেট করা মেমরিকে শূন্য দিয়ে ইনিশিয়ালাইজ করে।

উপরের উদাহরণগুলোতে খেয়াল করুন, `free(numbers)` ব্যবহার করা হয়েছে।

## free

`free` হলো `stdlib.h`-তে ঘোষিত একটি ফাংশন, যা ডাইনামিকভাবে অ্যালোকেট করা মেমরি ডি-অ্যালোকেট করতে ব্যবহৃত হয়।
ডাইনামিকভাবে অ্যালোকেট করা মেমরি `free` দিয়ে ছেড়ে দেওয়া পর্যন্ত মেমরিতে দখল হয়ে থাকে।
কিছু অপারেটিং সিস্টেম প্রোগ্রাম শেষ হয়ে গেলে ডাইনামিকভাবে অ্যালোকেট করা মেমরি নিজে থেকেই ফ্রি করে দেয়, তবে তার উপর নির্ভর না করাই বেস্ট প্র্যাকটিস।
`free`-এর একটি প্যারামিটার আছে, যা হলো ডাইনামিকভাবে অ্যালোকেট করা মেমরির দিকে ইশারা করা একটি পয়েন্টার।
যে পয়েন্টার ফ্রি করার পর `NULL` সেট করা হয় না, তাকে ড্যাঙ্গলিং পয়েন্টার বলা হয়।
একটি ড্যাঙ্গলিং পয়েন্টার তার উদ্দিষ্ট মেমরির বদলে অন্য মেমরির দিকে ইশারা করতে পারে।
তাই একটি ড্যাঙ্গলিং পয়েন্টার ডেটা করাপশন এবং ইচ্ছেমতো কোড বসিয়ে তা চালিয়ে দেওয়ার দিকে নিয়ে যেতে পারে।
`NULL` সেট করে পরিষ্কার করা হয়নি এমন অ্যালোকেট করা মেমরির পয়েন্টার দিয়ে প্রোগ্রাম হ্যাক করা যেতে পারে।
`free`-কে পয়েন্টার পাস করার পর সেটিকে `NULL` সেট করে দেওয়া বেস্ট প্র্যাকটিস।

## calloc

`calloc` হলো `stdlib.h`-তে ঘোষিত একটি ফাংশন, যা ডাইনামিক মেমরি অ্যালোকেট করা এবং নতুন অ্যালোকেট করা মেমরিকে শূন্য দিয়ে ইনিশিয়ালাইজ করা, দুটো কাজেই ব্যবহৃত হয়।
অ্যালোকেশন সফল হলে এমন একটি পয়েন্টার রিটার্ন হয়, যা অ্যালোকেট করা মেমরির প্রথম বাইটের অ্যাড্রেসের দিকে ইশারা করে।
অ্যালোকেশন সফল না হলে `NULL` রিটার্ন হয়।
`calloc`-এর ফলাফল `NULL` কি না তা যাচাই করে নেওয়া এবং ব্যর্থ হলে সুন্দরভাবে সামলে নেওয়া বিচক্ষণতার পরিচয়।
রিটার্ন হওয়া পয়েন্টারটি `pointer-to-void` টাইপের, যাকে মোটামুটি একটি "জেনেরিক" পয়েন্টার হিসেবে ধরা যায়, যা মেমরিতে ব্যবহৃত নির্দিষ্ট টাইপে রূপান্তর করা যায়।
`calloc`-এর দুটি প্যারামিটার আছে।
প্রথম প্যারামিটারটি বলে দেয় নির্দিষ্ট ডেটা টাইপের কতটি অ্যালোকেট করতে হবে।
দ্বিতীয় প্যারামিটারটি বলে দেয় অ্যালোকেট করার জন্য নির্দিষ্ট ডেটা টাইপের আকার কত।

নিচের উদাহরণে সব `printf` স্টেটমেন্টেই সর্বদা `0` দেখানো উচিত, কারণ `calloc` নতুন অ্যালোকেট করা মানগুলোকে শূন্য করে দেওয়ার নিশ্চয়তা দেয়।

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` হলো `stdlib.h`-তে ঘোষিত একটি ফাংশন, যা আগে থেকে অ্যালোকেট করা মেমরি বড় করা বা ছোট করা, দুটোর যেকোনোটির জন্য ব্যবহৃত হয়।
রি-অ্যালোকেশন সফল হলে এমন একটি পয়েন্টার রিটার্ন হয়, যা রি-অ্যালোকেট করা মেমরির প্রথম বাইটের অ্যাড্রেসের দিকে ইশারা করে।
রি-অ্যালোকেশন সফল না হলে `NULL` রিটার্ন হয়।
`realloc`-এর ফলাফল `NULL` কি না তা যাচাই করে নেওয়া এবং ব্যর্থ হলে সুন্দরভাবে সামলে নেওয়া বিচক্ষণতার পরিচয়।
`realloc`-এর দুটি প্যারামিটার আছে।
প্রথম প্যারামিটারটি হলো রি-অ্যালোকেট করার জন্য বিদ্যমান মেমরির দিকে ইশারা করা একটি পয়েন্টার।
দ্বিতীয় প্যারামিটারটি হলো রি-অ্যালোকেট করা মেমরির আকার, বাইটে।
মেমরি বড় করার আগে যে মানগুলো সেট করা হয়েছিল, সেগুলো অটুট থাকে।
মনে রাখা জরুরি, মেমরি বড় করার সময় যোগ হওয়া মেমরি শূন্য দিয়ে ইনিশিয়ালাইজ করা হয় না, তাই সেখানে যা-ই থাকতে পারে।
আবার মেমরি ছোট করার সময় সরিয়ে ফেলা মেমরিও ইনিশিয়ালাইজ করা হয় না এবং সেখানে আগের মানগুলো রয়ে যেতে পারে।
নিচের উদাহরণটি একটি অ্যারে বড় করা ও ছোট করা দেখায়

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
