# ভূমিকা

ইন্টিজারকে শুধু সংখ্যাসূচক মান হিসেবেই নয়, বিটের প্যাটার্ন হিসেবেও দেখা যায়। Factor-এর [`math`][math] ভোকাবুলারিতে ওই বিট প্যাটার্নগুলোর ওপর কাজ করার স্ট্যান্ডার্ড লো-লেভেল অপারেশন রয়েছে, আর [`math.bitwise`][bitwise] ভোকাবুলারি ফিক্সড-উইড্থ মান নিয়ে কাজ করার জন্য কয়েকটি হেল্পার যোগ করে।

## বিট শিফট

`shift ( m n -- m' )` `m`-এর বিটগুলো শিফট করে। *ধনাত্মক* `n` বামে শিফট করে (প্রতিটি ধাপে ২ দিয়ে গুণ); *ঋণাত্মক* `n` ডানে শিফট করে (প্রতিটি ধাপে ২ দিয়ে ভাগ):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

ধনাত্মক ইন্টিজারের ক্ষেত্রে রাইট-শিফট নিচ থেকে বিটগুলো ফেলে দেয় এবং শূন্য দিয়ে ভরাট করে। *ঋণাত্মক* ইন্টিজারের ক্ষেত্রে Factor-এর `shift` হলো অ্যারিথমেটিক, এটি সাইন বিট সংরক্ষণ করে এবং ধারণাগতভাবে বাম দিক থেকে সাইন বিটের কপি দিয়ে ভরাট করে। (Factor-এর ইন্টিজার আর্কিট্রারি প্রিসিশনের, তাই "বাম দিক" যতদূর দরকার ততদূর বিস্তৃত হয়।)

## বিটওয়াইজ লজিক

মূল চারটি লজিক অপারেশন হলো:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`0b1011`-এর `bitnot` হলো `-12`, কারণ Factor-এর ইন্টিজার আর্কিট্রারি প্রিসিশনের: `0b1011`-এর বিটগুলো উল্টে দিলে ধারণাগতভাবে হয় "সব বিট এক, শুধু নিচের চারটি উল্টে `0100`", যাকে সাইনড বিগনাম হিসেবে পড়লে দাঁড়ায় `-12`।

## একটি মানকে N বিট হিসেবে ধরা

`math.bitwise`-এর `bits ( x n -- y )` `x`-কে তার নিচের `n` বিটে মাস্ক করে। Factor-এ "একটি মানকে N-বিট আনসাইনড ইন্টিজার হিসেবে নতুন করে ব্যাখ্যা করার" উপায় এটিই:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

এই অনুশীলনীর জন্য দ্বিতীয় উদাহরণটি গুরুত্বপূর্ণ। আপনি যদি একটি ঋণাত্মক টু'স কমপ্লিমেন্ট Int32 মান নিয়ে সেটিকে `amount` পরিমাণ "লজিক্যালি" রাইট-শিফট করতে চান (বাম দিক থেকে শূন্য দিয়ে ভরাট করে), তাহলে Factor-এর ইডিয়ম হলো:

```
( value -- shifted )
32 bits  amount neg  shift
```

আনসাইনড ব্যাখ্যায় যেতে প্রথমে ৩২ বিটে মাস্ক করুন, তারপর শিফট করুন। মাস্ক করা মানটি ঋণাত্মক নয় বলে `shift` সহজভাবে নিচ থেকে বিটগুলো ফেলে দেয় এবং শূন্য দিয়ে প্যাড করে।
