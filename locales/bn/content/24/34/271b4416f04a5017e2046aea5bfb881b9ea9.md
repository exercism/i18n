# নির্দেশনা

ল্যারি একজন Lisp অ্যালিয়েন, যিনি গেম খেলার জন্য কোড লিখতে ভালোবাসেন।
আজ তিনি এমন একটি গেমে সহায়তা করার জন্য কয়েকটি ফাংশন লিখতে চান, যা অনেকটা টিক-ট্যাক-টো-এর মতো।

টিক-ট্যাক-টো-এর মতোই এই গেমটি এমন একটি বোর্ডে খেলা হয়, যেটি একটি ৩x৩ গ্রিড।

## 1. শূন্য থেকে শুরু

প্রথমে ল্যারির দরকার `make-empty-board` নামের একটি ফাংশন, যা একটি ফাঁকা বোর্ড তৈরি করবে।
বোর্ডের সব সেল `NIL` হওয়া উচিত।

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. বিদ্যমান বোর্ড থেকে শুরু

এরপর ল্যারির দরকার একটি ফাংশন, যা সারিগুলোর একটি অ্যারে থেকে একটি বোর্ড তৈরি করবে।
উদাহরণস্বরূপ:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. জেতার শর্ত

একই সিম্বলের তিনটি এক সারিতে থাকলে সেই খেলোয়াড় জিতে গেছে।
ল্যারির দরকার একটি ফাংশন, `all-the-same-p`, যা ৩টি আইটেমের একটি অ্যারে পেলে, সবগুলো আইটেম একই সিম্বল হলে `T` ইভ্যালুয়েট করবে।
(দুটি সিম্বল একই কিনা তা নির্ণয় করতে `eq` ব্যবহার করা যায়।)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. সারিতে

এখন ল্যারির দরকার একটি সারির এলিমেন্টগুলো পাওয়ার একটি উপায়।
`row` ফাংশনটি একটি বোর্ড ও একটি সারি নম্বর নেবে, এবং সেই সারির এলিমেন্টগুলোর একটি অ্যারে রিটার্ন করা উচিত।

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. কলামে

সবশেষে ল্যারির দরকার একটি কলামের এলিমেন্টগুলো পাওয়ার একটি উপায়।
`column` ফাংশনটি একটি বোর্ড ও একটি কলাম নম্বর নেবে, এবং সেই কলামের এলিমেন্টগুলোর একটি অ্যারে রিটার্ন করা উচিত।

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
