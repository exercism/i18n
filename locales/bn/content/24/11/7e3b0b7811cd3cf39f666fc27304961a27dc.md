# পরিচিতি

## অ্যারে ডিস্ট্রাকচারিং

JavaScript-এর অ্যারে ডিস্ট্রাকচারিং সিনট্যাক্স হলো একটি অ্যারে থেকে মান বের করে আলাদা আলাদা ভ্যারিয়েবলে অ্যাসাইন করার একটি সংক্ষিপ্ত উপায়।

এই উদাহরণে, `numberOfMoons` অ্যারের প্রতিটি মান তার সংশ্লিষ্ট গ্রহে অ্যাসাইন করা হয়েছে:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

সংক্ষেপে:

- এই সিনট্যাক্সের সাহায্যে অ্যারের _নির্দিষ্ট অবস্থানে থাকা_ এলিমেন্টগুলোর নাম দেওয়া যায়, আবার পুনরায় অ্যাসাইন করে ভ্যারিয়েবল অদলবদলও করা যায়।
- ডিস্ট্রাকচারিং সিনট্যাক্স ফাংশন প্যারামিটারের ভেতরে ব্যবহার করা যায়, এবং যেকোনো ইটারেবলের ক্ষেত্রেও ব্যবহার করা যায়।
- কোনো অবস্থানের নাম না দিলে (_কোনো_ ভ্যারিয়েবলের নাম না লিখলে) ওই অবস্থানটি নীরবে উপেক্ষিত হয়।

## অবজেক্ট ডিস্ট্রাকচারিং

JavaScript-এ অবজেক্ট থেকে প্রপার্টি বের করে আলাদা আলাদা ভ্যারিয়েবলে অ্যাসাইন করার জন্যও ডিস্ট্রাকচারিং সিনট্যাক্স আছে।

এই উদাহরণে, `weather` অবজেক্ট থেকে আবহাওয়ার প্রতীকগুলো বের করা হয়েছে:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

সংক্ষেপে:

- এই সিনট্যাক্সের সাহায্যে প্রপার্টি বের করা যায়, আবার বের করার সময় নতুন নামও দেওয়া যায়।

- ডিস্ট্রাকচারিং সিনট্যাক্স ফাংশন প্যারামিটারের ভেতরে ব্যবহার করা যায়।
