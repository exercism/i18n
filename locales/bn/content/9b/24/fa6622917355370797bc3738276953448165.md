# নির্দেশনা সংযোজন

| রেজিস্টার | ব্যবহার     | টাইপ    | বর্ণনা                  |
| -------- | --------- | ------- | ---------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং |
| `$v0`    | আউটপুট    | ইন্টিজার | স্ক্র্যাবল স্কোর               |
| `$t0-9`  | টেম্পোরারি | যেকোনো  | টেম্পোরারি সংরক্ষণের জন্য        |
