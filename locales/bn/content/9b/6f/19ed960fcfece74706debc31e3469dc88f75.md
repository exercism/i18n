# পরিচিতি

PHP-তে, একটি ভ্যারিয়েবলের পরে বন্ধনী [`()`] বসিয়ে সেটিকে একটি ফাংশন হিসেবে কল করা যায়। PHP যখন ফাংশনটি কল করার চেষ্টা করে, তখন ভ্যারিয়েবলের মানের সঙ্গে একই নামের একটি ফাংশন খোঁজে।

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## স্ট্যাটিক ক্লাস ফাংশন কল করা

স্ট্যাটিক ক্লাস ফাংশনও একইভাবে কল করা যায়:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## ইনস্ট্যান্স ক্লাস ফাংশন কল করা

ক্লাস ইনস্ট্যান্সের ফাংশন কল করাও সম্ভব:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
