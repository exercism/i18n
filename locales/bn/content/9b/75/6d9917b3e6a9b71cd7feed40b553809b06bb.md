# নির্দেশনা

একটি Markdown পার্সার রিফ্যাক্টর করুন।

Markdown অনুশীলনীটি একটি রিফ্যাক্টরিং অনুশীলনী।
এমন কোড আছে যা Markdown সিনট্যাক্স দিয়ে একটি নির্দিষ্ট স্ট্রিং পার্স করে এবং সেই স্ট্রিংয়ের সংশ্লিষ্ট HTML রিটার্ন করে।
যদিও এই কোডটি বিভ্রান্তিকরভাবে লেখা আর অনুসরণ করা কঠিন, তবুও কোনোভাবে এটি কাজ করে এবং সব test পাস করছে!
আপনার চ্যালেঞ্জ হলো এই কোডটি আবার লিখে ফেলা, যাতে এটি পড়তে ও রক্ষণাবেক্ষণ করতে সহজ হয়, আর একই সাথে নিশ্চিত করা যে সব test পাস করতেই থাকে।

আপনার রিফ্যাক্টরিংয়ে আপনি কী কী করেছেন, তা যদি কমেন্টে টুকে রাখেন, তাহলে রিভিউয়াররা সেটি দেখতে পাবেন, যা সহায়ক হবে, তবে এটি একান্ত জরুরি নয়।
সবচেয়ে গুরুত্বপূর্ণ হলো কোডটিকে আরও ভালো করে তোলা!
