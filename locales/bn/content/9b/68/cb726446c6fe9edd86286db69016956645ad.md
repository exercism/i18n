## MacOS

প্রথমে [Homebrew][1] ব্যবহার করে Lua এবং [Luarocks][2] ইনস্টল করুন:

```shell
$ brew install lua luarocks
```

এরপর Lua-এর জন্য [Busted][3] টেস্টিং ফ্রেমওয়ার্ক ইনস্টল করুন:

```shell
$ luarocks install --local busted
```

আপনার সিস্টেমের `$PATH`-এ `~/.luarocks/bin` যোগ করুন

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

মনে রাখবেন, এটি শুধুমাত্র সাময়িক।
আপনার `$PATH`-এ স্থায়ীভাবে যোগ করতে হলে, আপনি কোন শেল ব্যবহার করছেন তার উপর নির্ভর করে এটি আপনার `.bashrc`, `.zshrc` বা `config.fish`-এ যোগ করতে হবে।

এরপর আপনার টেস্টগুলো রান করুন:

```shell
$ busted
```

## Ubuntu

প্রথমে [Apt][6] ব্যবহার করে Lua এবং [Luarocks][2] ইনস্টল করুন:

```shell
$ sudo apt-get install lua5.4 liblua5.4-dev luarocks
```

এরপর Lua-এর জন্য [Busted][3] টেস্টিং ফ্রেমওয়ার্ক ইনস্টল করুন:

```shell
$ luarocks install --local busted
```

মনে রাখবেন, এটি শুধুমাত্র সাময়িক।
আপনার `$PATH`-এ স্থায়ীভাবে যোগ করতে হলে, আপনি কোন শেল ব্যবহার করছেন তার উপর নির্ভর করে এটি আপনার `.bashrc`, `.zshrc` বা `config.fish`-এ যোগ করতে হবে।

## Windows 10: WSL

প্রথমে আপনাকে [PowerShell][8] (অ্যাডমিনিস্ট্রেটর হিসেবে) ব্যবহার করে [WSL (Windows Subsystem for Linux)][7] চালু করতে হবে:

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

এর জন্য সিস্টেম রিস্টার্ট করতে হবে।

এরপর [Microsoft Store][9] থেকে Ubuntu ইনস্টল করুন, **অথবা** PowerShell ব্যবহার করে ডাউনলোড করে ইনস্টল করুন:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

এরপর আপনার প্যাকেজ তালিকা আপডেট করুন:

```shell
PS> wsl
$ sudo apt-get update
```

এখন উপরের [Ubuntu নির্দেশনা](#ubuntu) অনুসরণ করে [LuaRocks][2] এবং [Busted][3] ইনস্টল করার জন্য আপনি প্রস্তুত।

কাজ শেষ হলে আপনি যেকোনো Windows কমান্ড লাইন থেকে সরাসরি আপনার টেস্ট রান করতে পারবেন:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Gitbash ইনস্টল করা

এই ধাপটি ঐচ্ছিক। আপনি যদি Windows-এর নিজস্ব CLI বা অন্য কোনো CLI ব্যবহার করতে পছন্দ করেন, তাহলে নিচের ধাপগুলোতে সামান্য পরিবর্তন আনতে হতে পারে।

ডাউনলোড করুন [এখানে][10]।
ইনস্টল করার নির্দেশনা [এখানে][11]।

### Docker ইনস্টল করা

[Docker for Windows][12] ইনস্টল করার নির্দেশনা অনুসরণ করুন।
ইনস্টল শেষ হলে, এটি সঠিকভাবে ইনস্টল হয়েছে কিনা নিশ্চিত করতে আপনি নিচের কমান্ডটি রান করতে পারেন।

```shell
$ docker --version
```

_প্রথমবার Docker রান করার চেষ্টা করার সময় আপনি একটি এরর দেখতে পারেন।_

`cannot enable hyper-v service`

_এমন হলে, [Hyper V চালু করার][13] এই নির্দেশনাগুলো অনুসরণ করতে পারেন। আপনাকে হয়তো সেটিংটি নিষ্ক্রিয় করে কম্পিউটার রিস্টার্ট করতে হবে এবং বুট হওয়ার পর আবার সক্রিয় করতে হবে।_

### busted ইনস্টল করা

Gitbash এবং Docker ইনস্টল হয়ে গেলে, আপনি একটি busted 'কনটেইনার' ইনস্টল করতে পারবেন।

Gitbash-এ নিচেরটি রান করুন:

নিচেরটি রান করে এই বহুল ব্যবহৃত Docker কনটেইনারটি নামিয়ে আনুন:

```shell
$ docker pull imega/busted
```

একটি ফাংশন তৈরি করুন যাতে প্রতিবার পুরো কমান্ডটি টাইপ করতে না হয়।
এটি আপনার `.bashrc`-এ যোগ করুন:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

এখন, আপনার CLI-তে, আপনি যে ডিরেক্টরিতে টেস্ট রান করতে চান সেখানে যেতে পারেন। নিচেরটি রান করুন:

```shell
$ dbusted $PWD
```

আপনি আপনার busted টেস্টের আউটপুট দেখতে পাবেন।
