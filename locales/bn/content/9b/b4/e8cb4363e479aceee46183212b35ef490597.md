# পরিচিতি

## পাটিগণিত অপারেটর

JavaScript সংখ্যার উপর মৌলিক পাটিগণিত অপারেশন চালানোর জন্য ৬টি ভিন্ন অপারেটর প্রদান করে।

- `+`: যোগ অপারেটরটি সংখ্যাগুলোর যোগফল বের করতে ব্যবহৃত হয়।

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: বিয়োগ অপারেটরটি দুটি সংখ্যার পার্থক্য বের করতে ব্যবহৃত হয়

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: গুণ অপারেটরটি দুটি সংখ্যার গুণফল বের করতে ব্যবহৃত হয়

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: ভাগ অপারেটরটি দুটি সংখ্যাকে ভাগ করতে ব্যবহৃত হয়।
  যেহেতু JavaScript-এর সংখ্যাগুলো সবসময় ফ্লোটিং-পয়েন্ট সংখ্যা, তাই এখানে ইন্টিজার ভাগ বলে কিছু নেই।

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: ভাগশেষ অপারেটরটি একটি ভাগের পর অবশিষ্ট ভাগশেষ বের করতে ব্যবহৃত হয়।

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: সূচক অপারেটরটি একটি সংখ্যাকে ঘাতে উন্নীত করতে ব্যবহৃত হয়।
  এটি [`Math.pow()`][mdn-math-pow] ব্যবহারের সমতুল্য

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## অপারেশনের ক্রম

একই লাইনে একাধিক অপারেটর ব্যবহার করলে JavaScript [এই অগ্রাধিকার সারণিতে][mdn-operator-precedence] দেখানো ক্রম অনুসরণ করে।
আমাদের প্রসঙ্গে সহজ করে বললে, JavaScript আমাদের প্রাথমিক গণিতের ক্লাসে শেখা PEDMAS (Parentheses, Exponents, Division/Multiplication, Addition/Subtraction, অর্থাৎ প্রথম বন্ধনী, সূচক, ভাগ/গুণ, যোগ/বিয়োগ) নিয়মটি ব্যবহার করে।

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## সংক্ষিপ্ত অ্যাসাইনমেন্ট অপারেটর

সংক্ষিপ্ত অ্যাসাইনমেন্ট অপারেটর হলো একটি ভ্যারিয়েবলের উপর পাটিগণিত অপারেশন চালিয়ে নতুন মানটি সেই একই ভ্যারিয়েবলে অ্যাসাইন করার একটি ছোট উপায়।
উদাহরণস্বরূপ, `x` এবং `y` নামের দুটি ভ্যারিয়েবল ধরা যাক।
তাহলে, `x += y` আর `x = x + y` একই কথা।
প্রায়শই এটি `y` ভ্যারিয়েবলের বদলে একটি সংখ্যার সাথে ব্যবহার করা হয়।
বাকি ৫টি অপারেশনও একই ধরনের ভঙ্গিতে চালানো যায়।

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
