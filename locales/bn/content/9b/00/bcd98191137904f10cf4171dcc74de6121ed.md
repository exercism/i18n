# নির্দেশাবলী

স্থানীয় কবিতা ক্লাবটি নতুন মৌসুম শুরু করছে। কবিরা ক্লাবে যোগ দেন, আর তাদের মধ্যে দুজন যখন একসাথে একটি কবিতা লেখেন, তখন তাঁরা একই *লেখন চক্রের* অংশ হয়ে যান। ক্লাবটি জানতে চায় কে কার সাথে একই চক্রে আছে, এবং এটি পরিচালনা করার ওয়ার্ডগুলো লিখতে আপনাকে বলা হয়েছে।

## 1. ক্লাব খুলুন

`new-club` ডিফাইন করুন, এটি কবিদের একটি সিকোয়েন্স নেয় এবং প্রত্যেক কবি নিবন্ধিত থাকে এমন একটি নতুন ডিসজয়েন্ট সেট রিটার্ন করে। প্রত্যেক কবি নিজের একটি আলাদা লেখন চক্রে শুরু করেন।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. একটি সহযোগিতা রেকর্ড করুন

`collaborate` ডিফাইন করুন, এটি দুজন কবি আর একটি ক্লাব নেয়। এটি দুজন কবির লেখন চক্র একত্র করে এবং ক্লাবটি রিটার্ন করে, যাতে একের পর এক সহযোগিতা রেকর্ড করা যায়।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. কবির চক্র খুঁজুন

`circle-of` ডিফাইন করুন, এটি একজন কবি আর একটি ক্লাব নেয় এবং ওই কবির লেখন চক্রের প্রতিনিধি রিটার্ন করে। একই চক্রে থাকা দুজন কবি সর্বদা একই প্রতিনিধি রিপোর্ট করেন।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. একই চক্র?

`same-circle?` ডিফাইন করুন, এটি দুজন কবি আর একটি ক্লাব নেয় এবং দুজন কবিই একই লেখন চক্রের অন্তর্ভুক্ত হলে `t` রিটার্ন করে, অন্যথায় `f` রিটার্ন করে। কবিদের প্রতিনিধিদের তুলনা করুন, বিল্ট-ইন সমতুল্যতা পরীক্ষা ব্যবহার করবেন না।

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
