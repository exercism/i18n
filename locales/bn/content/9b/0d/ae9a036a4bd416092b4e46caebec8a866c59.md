# নির্দেশনা

স্কুলের হারানো জিনিসের অফিস সবকিছু বাক্সে রাখে, আর একটি বাক্সে কী যায় তা যেকোনো কিছুই হতে পারে: একটি সোয়েটার, কয়েকটি জিনিস, একটি নাম।

একটি `LOST_BOX{T}` ক্লাস লিখুন। স্টাব আপনাকে ক্লাস হেডারটি দিয়ে দেয়।

## 1. কিছু নিয়ে রাখুন

`create` জিনিসটি আর যিনি সেটি জমা দিয়েছেন তাঁর নাম নেয়, এবং একটি বাক্স দেয়। বাক্সটি শুরুতে দাবিহীন থাকে।

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. দাবি করুন

`claim` বাক্সটিকে দাবিকৃত হিসেবে চিহ্নিত করে। এটি কিছুই রিটার্ন করে না।

```sather
box.claim;
box.claimed
-- => true
```

## 3. এটি কি এখনও অপেক্ষায় আছে?

`waiting` রিটার্ন করে বাক্সটি দাবি করা হয়নি কি না।

```sather
box.waiting
-- => false
```

## 4. ভেতরের জিনিস বদলে দিন

`replace` একটি নতুন জিনিস নেয়, সেটি বাক্সে রেখে দেয় এবং আগে কী ছিল তা রিটার্ন করে। ভেতরে যাওয়া জিনিসটি আর বাইরে আসা জিনিসটি দুটোই `T`।

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. বিবরণ লিখুন

`describe` বাক্সটি সম্পর্কে একটি লাইন রিটার্ন করে, যেমন `"blue jumper, handed in by Mia"`.

জিনিসটি একটি স্ট্রিংয়ে বসাতে হলে ক্লাসটিকে জানতে হবে যে একটি `T`-কে স্ট্রিংয়ে রূপান্তর করা যায়। প্যারামিটারটিকে সীমাবদ্ধ করুন: ক্লাস হেডারটি `class LOST_BOX{T < $STR}` হিসেবে লিখুন, তাহলে `item.str` ব্যবহার করা যাবে।

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
