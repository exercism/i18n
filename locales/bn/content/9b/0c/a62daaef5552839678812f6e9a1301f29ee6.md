# পরিচিতি

Go-তে এমন কিছু মৌলিক টাইপ আছে, যেগুলো দিয়ে ইন্টিজার অথবা ফ্লোটিং-পয়েন্ট মানের সেট প্রকাশ করা যায়।

এই কনসেপ্টে মূলত দুই ধরনের টাইপ নিয়ে আলোচনা করা হবে:

- `int`: যেমন `0`, `255`, `2147483647`.
   একটি সাইনড ইন্টিজার, যার আকার কমপক্ষে ৩২ বিট (মানের পরিসীমা: -2147483648 থেকে 2147483647)।
   তবে এটা সিস্টেম আর্কিটেকচারের উপর নির্ভর করে।
   বেশিরভাগ আধুনিক কম্পিউটার ৬৪ বিটের, তাই `int`-এর আকার হয় ৬৪ বিট (মানের পরিসীমা: -9223372036854775808 থেকে 9223372036854775807)।

- `float64`: যেমন `0.0`, `3.14`.
   এতে সব ৬৪-বিট ফ্লোটিং-পয়েন্ট সংখ্যার সেট থাকে।

Go সাধারণ গাণিতিক অপারেটরগুলো সাপোর্ট করে: `+`, `-`, `*`, `/` এবং `%` (ভাগশেষ, মডুলো নয়)।

Go-তে এক টাইপের মান অন্য টাইপে অ্যাসাইন করতে হলে এক্সপ্লিসিট কনভার্সন করতে হয়।
যেমন, একটি `int`-কে `float64`-তে রূপান্তর করতে হলে আপনাকে নিচের কাজটি করতে হবে:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
