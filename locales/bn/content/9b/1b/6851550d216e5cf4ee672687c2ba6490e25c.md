# পরিচিতি

C# টাইপ ক্লাস বা স্ট্রাক্টের স্কোপের মধ্যে ডিফাইন করা যায়। ঘেরাও করা টাইপটি একধরনের নেমস্পেসের কাজ করে। ডট সিনট্যাক্স দিয়ে ঘেরাও করা টাইপের মাধ্যমে টাইপটিতে অ্যাক্সেস করা যায়।

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

ভেতরের টাইপগুলোর জন্য আপনি অ্যাক্সেস লেভেল সেট করতে পারেন।

ঘেরাও করা টাইপের প্রাইভেট মেম্বারগুলো ভেতরের টাইপের মেম্বারের জন্য স্কোপের মধ্যে থাকে, কিন্তু উল্টোটা নয়।
