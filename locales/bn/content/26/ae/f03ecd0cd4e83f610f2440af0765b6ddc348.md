# নির্দেশনার সংযোজন

## শব্দ

ইমপ্লিমেন্ট করুন:

- `grep ( pattern flags files -- lines )`

`pattern` হলো খোঁজার স্ট্রিং, `flags` হলো `"-n"`, `"-l"`, `"-i"`, `"-v"` বা `"-x"` ফ্ল্যাগ স্ট্রিংয়ের শূন্য বা তার বেশি সদস্যের একটি অ্যারে, এবং `files` হলো এক বা তার বেশি ফাইল নামের একটি অ্যারে। মিলে যাওয়া লাইনগুলো (চাওয়া হলে ফাইল নাম ও লাইন নম্বরের প্রিফিক্স-সহ) স্ট্রিংয়ের অ্যারে হিসেবে রিটার্ন করুন।

`-l` ফ্ল্যাগ দেওয়া হলে, যে ফাইলগুলোতে অন্তত একটি মিল আছে সেই ফাইলগুলোর নামের একটি অ্যারে রিটার্ন করুন।

## ফাইল পড়া

`file-lines` দিয়ে একটি ফাইলের লাইনগুলো পড়ুন, একটি এনকোডিং পাস করে:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

তিনটি ফিক্সচার ফাইল (`iliad.txt`, `midsummer-night.txt` আর `paradise-lost.txt`) অনুশীলনীর সাথে ওয়ার্কিং ডিরেক্টরিতে দেওয়া থাকে, তাই নাম দিয়ে সেগুলো পড়া কোনো ঝামেলা ছাড়াই কাজ করে।
