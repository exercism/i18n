# সম্পর্কে

[`throw` এক্সপ্রেশন][throw-expressions] হলো `throw` স্টেটমেন্টের একটি বিকল্প, এবং বিশেষভাবে এটি টার্নারি ও অন্যান্য যৌগিক এক্সপ্রেশনের ক্ষমতা বাড়াতে পারে।

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

উপরের কোডে যদি `str` হলো `null`, তাহলে একটি এক্সেপশন থ্রো হয়।

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
