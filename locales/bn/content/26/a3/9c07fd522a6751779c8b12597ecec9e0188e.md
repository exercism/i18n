# নির্দেশনা

চাকরি করা প্রায় সবার মতো Layla the Lisp Alien-কেও মাঝে মাঝে রিপোর্ট তৈরি করতে হয়, যাতে অন্যরা কোনো তথ্য জেনে যায়। তিনি জিজ্ঞেস করেন, এই রিপোর্টের জন্য তার কাছে থাকা ডেটা ফরম্যাট করতে আপনি কি তাঁকে সাহায্য করতে পারবেন?

## 1. ত্রৈমাসিক মান ফরম্যাট করা

Layla-এর প্রথমে যা দরকার তা হলো একটি ফাংশন: `format-quarter-value`, যা দুটি প্যারামিটার নেয়, ক্যালেন্ডার ত্রৈমাসিক ও মান, এবং সেটিকে একটি রিপোর্টের জন্য ফরম্যাট করে। এর ফলাফল একটি স্ট্রিং হওয়া উচিত।

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. দুই ত্রৈমাসিকের রিপোর্ট

`format-quarter-value` ফাংশনের জন্য Layla আপনাকে ধন্যবাদ জানান এবং বলেন, *পরবর্তী* যে ফাংশনটির দরকার হবে, সেখানে এটি খুব কাজে লাগবে।

পরের রিপোর্টে দুই ত্রৈমাসিকের নাম ও মান দুই লাইনে ছাপিয়ে দেখাতে হবে।

এছাড়া আউটপুট প্রথম আর্গুমেন্ট হিসেবে দেওয়া স্ট্রিমে পাঠাতে হবে।

যেমন: `(format-two-quarters t "last" 3.14 "this" 0)` স্ট্যান্ডার্ড আউটপুটে নিচের ফলাফল দেবে:

```

The value last quarter: 3.14
The value this quarter: 0

```

লক্ষ্য করুন, এর চারপাশে ফাঁকা লাইন আছে।

## 3. মানুষের পাঠযোগ্য বনাম Lisp Alien-এর পাঠযোগ্য

Layla আপনাকে বলতে ভুলে গেছেন যে Lisp Alien-রা মানগুলো এমনভাবে দেখতে পছন্দ করেন, যাতে সেগুলো Lisp ডেটা হিসেবে পড়া যায়। তাই তাদের একটি নতুন ফাংশন দরকার, যা Lisp ডেটা হিসেবে পড়া যাবে (আবারও নির্দিষ্ট স্ট্রিমে):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
