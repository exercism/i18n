# পরিচিতি

মেথড হলো এমন একটি ফাংশন, যার একটি বিশেষ _রিসিভার_ আর্গুমেন্ট থাকে।
রিসিভার নিজের আর্গুমেন্ট তালিকায় `func` কিওয়ার্ড আর মেথডের নামের মাঝখানে থাকে।

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

একই প্যাকেজে যে টাইপ ডিফাইন করা হয়েছে, শুধু সেই টাইপের রিসিভার দিয়েই আপনি একটি মেথড ডিফাইন করতে পারেন।

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

রিসিভার দুই ধরনের: ভ্যালু রিসিভার আর পয়েন্টার রিসিভার।

ভ্যালু রিসিভারযুক্ত মেথড তার কাছে পাঠানো মানের একটি কপির উপর কাজ করে, অর্থাৎ মেথডের ভেতরে রিসিভারে যে পরিবর্তনই করা হোক, তা কলারের কাছে দৃশ্যমান হয় না।

রিসিভার যে মানের দিকে নির্দেশ করে সেটি পরিবর্তন করার জন্য আপনি পয়েন্টার রিসিভার দিয়ে মেথড ডিক্লেয়ার করতে পারেন।
এটি করা হয় টাইপের নামের আগে একটি `*` বসিয়ে; যেমন `rect` টাইপের ক্ষেত্রে পয়েন্টার রিসিভার ডিক্লেয়ার করা হবে `*rect` হিসেবে।
এ ধরনের পরিবর্তনও মেথডের কলারের কাছে দৃশ্যমান হয়।

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
