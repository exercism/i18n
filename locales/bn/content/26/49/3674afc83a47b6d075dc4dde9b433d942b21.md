# ইনস্টলেশন

এই ট্র্যাকটি Wren-এর জন্য একটি লোকাল রানটাইম दিতে সর্বত্র [Wren Console][wren-console]-এর উপর নির্ভর করে। এর মানে হলো, আপনার কম্পিউটারে Wren-এর সব কিছু [Wren Console][wren-console] দিয়েই চলবে বলে আমরা ধরে নিই। অনুগ্রহ করে এটিকে অফিসিয়াল Wren <abbr title="Command Line Interface">CLI</abbr>-এর সাথে গুলিয়ে ফেলবেন না। সবকিছু আদর্শ হলে আপনি ওই রানটাইমটিই ব্যবহার করতে পারতেন, কিন্তু এতে বর্তমানে [রয়েছে](https://github.com/wren-lang/wren-cli/pull/74) [কয়েকটি](https://github.com/wren-lang/wren/pull/1006) [ভিন্ন](https://github.com/wren-lang/wren-cli/issues/108) [সমস্যা](https://github.com/wren-lang/wren-cli/pull/105), যার কারণে Exercism-এর সাথে Wren শেখার জন্য এটি তেমন ভালো পছন্দ নয়।

Wren Console হলো Wren CLI থেকে ফর্ক করা একটি প্রকল্প, যা এই সমস্যাগুলোর সমাধান করে এবং আপনার শেখার অভিজ্ঞতা আরও মসৃণ করতে নতুন ফিচার যোগ করে। চিন্তার কিছু নেই, এখানে আপনি Wren ভাষার যে জ্ঞান ও ধারণাগুলো শিখবেন, ভবিষ্যতে যেখানেই Wren ব্যবহার করতে চান, সেখানেই তা কাজে লাগবে।

## ইনস্টলেশনের সারসংক্ষেপ

- `git` কমান্ডের জন্য Git ইনস্টল করুন
- `wrenc` কমান্ডের জন্য [Wren Console][wren-console] ইনস্টল করুন

### Git ইনস্টল করা

আপনার `git` বাইনারিটি ইনস্টল করা এবং PATH-এ থাকা দরকার। Wren Package এইভাবেই প্যাকেজ ইনস্টল করে (যেমন আপনার অনুশীলনী পরীক্ষা করার জন্য প্রয়োজনীয় টেস্ট স্যুট ইত্যাদি)।

- **Windows** - শুরু করার জন্য অফিসিয়াল [Git ডাউনলোড](https://git-scm.com/download/win) একটি ভালো জায়গা।
- **Linux** - আপনার প্রিয় প্যাকেজ ম্যানেজারই কাজটি করে দেবে।
- **Mac** - Mac OS-এর সাম্প্রতিক সব ভার্সনের সাথেই `git` আগে থেকেই দেওয়া থাকে।

`git --version` দিয়ে Git ইনস্টল হয়েছে কিনা নিশ্চিত হতে পারেন:

```
$ git --version
git version 2.31.1
```

সঠিক ভার্সনটি না মিললেও चিন্তার কিছু নেই, সাধারণত এটি খুব একটা জরুরি নয়।


### Wren Console ইনস্টল করা

#### Windows

আপনি সম্ভবত GitHub থেকে [সর্বশেষ রিলিজটি ডাউনলোড][releases] করতে চাইবেন। এরপর আনজিপ করে `wrenc` এক্সিকিউটেবলটি আপনার path-এ কপি করতে হবে।

Visual Studio ব্যবহার করে [সোর্স থেকে বিল্ড][build-from-source] করাও সম্ভব।

#### Linux

আপনি GitHub থেকে [সর্বশেষ রিলিজ ডাউনলোড][releases] করতে পারেন, অথবা [সোর্স থেকে বিল্ড][build-from-source] করতে পারেন।

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

আর নিশ্চিত করুন যে এটি আপনার `PATH`-এ আছে।

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

সবচেয়ে সহজ ইনস্টলেশন হলো Exercism-এর [Homebrew][homebrew] ট্যাপ ও ফর্মুলা ব্যবহার করা:

```
brew tap exercism/wren
brew install wren-console
```

বিকল্পভাবে আপনি GitHub থেকে [সর্বশেষ রিলিজ][releases] ডাউনলোড করে Linux-এর নির্দেশনায় দেখানো মতো নিজে হাতে ইনস্টল করতে পারেন। এ ধরনের কাজে অভ্যস্ত থাকলে সোর্স থেকে বিল্ড করাও বেশ সহজ।

### ইনস্টলেশন পরীক্ষা করা

বাইনারিটি ঠিকভাবে ইনস্টল হয়েছে বলে আপনার মনে হওয়ার পর, সবকিছু ঠিকঠাক কাজ করছে কিনা পরীক্ষা করে দেখা ভালো।

1. একটি _টার্মিনাল_ খুলুন (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. `wrenc -v` রান করুন

এখানে `wrenc` এবং Wren দুটোরই ভার্সন তালিকাভুক্ত দেখতে পাবেন:

```
wrenc v0.3.1 (wren v0.4.0)
```

**নোট**: আপনি একটি _নতুন_ টার্মিনাল উইন্ডো খুলছেন, এটি গুরুত্বপূর্ণ। ইনস্টলেশন শেষ হওয়ার পর খোলা টার্মিনাল উইন্ডোগুলো রিফ্রেশ নাও হয়ে থাকতে পারে। এর মানে হলো, খোলা টার্মিনালগুলো জানে না যে একটি নতুন প্রোগ্রাম ইনস্টল হয়েছে।

> _**সাহায্য**_: `'wrenc' is not recognised`
>
> সম্ভবত আপনি `wrenc`-কে আপনার PATH-এ রাখেননি... MacOS ও Linux-এ নিচের লাইনটি `~/.bash_profile` অথবা `~/.zshrc`-এ
> যোগ করে আপনার path বদলাতে পারেন:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **এর কোনোটাই সঠিক কিনা আমার কোনো ধারণা নেই।**
> Windows-এ স্টার্ট মেনু খুলে "environment variables" খুঁজুন। এখানে `PATH` এন্ট্রিটি
> সম্পাদনা করে `wrenc` বাইনারিগুলোর path _যোগ_ করতে হবে। সাধারণত এগুলো
> `C:\Program Files\nodejs`-এ পাওয়া যায়। আপনার `File Explorer` দিয়ে এখানে গেলে
> `node.exe`, `npm.bat` এবং `npx.bat` দেখতে পাবেন।
>
> খোলা থাকা সব টার্মিনাল বন্ধ করে নতুন একটি খুলুন।

## অনুশীলনীর প্রয়োজনীয়তা

আপনার OS-এর জন্য `exercism` CLI ডাউনলোড করতে [এই নির্দেশনাগুলো][cli-walkthrough] অনুসরণ করুন।

CLI পুরোপুরি সেটআপ ও কনফিগার হয়ে গেলে প্রথম অনুশীলনীটি ডাউনলোড করুন, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

এরপর প্রতিটি অনুশীলনীর টেস্ট চালানোর জন্য কিছু Wren প্যাকেজ দরকার। অনুশীলনীর ডিরেক্টরির ভেতরে
এই কমান্ডটি রান করে সেগুলো ইনস্টল করা যায়:

```bash
$ wrenc package.wren install
```
