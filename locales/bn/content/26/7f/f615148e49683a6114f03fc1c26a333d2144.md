# নির্দেশনা

একটি জটিল সংখ্যা হলো `a + b * i` আকারের একটি সংখ্যা, যেখানে `a` ও `b` বাস্তব এবং `i`-এর ক্ষেত্রে `i^2 = -1` সত্য।

`a`-কে `z`-এর বাস্তব অংশ এবং `b`-কে `z`-এর কাল্পনিক অংশ বলা হয়।
`a + b * i` সংখ্যাটির অনুবন্ধী হলো `a - b * i` সংখ্যাটি।
`z = a + b * i` জটিল সংখ্যাটির পরম মান `|z| = sqrt(a^2 + b^2)` হলো একটি বাস্তব সংখ্যা। পরম মানের বর্গ `|z|^2` হলো `z`-কে তার জটিল অনুবন্ধী দিয়ে গুণ করার ফল।

দুটি জটিল সংখ্যার যোগফল/বিয়োগফল পেতে তাদের বাস্তব ও কাল্পনিক অংশ আলাদা আলাদাভাবে যোগ/বিয়োগ করতে হয়:
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

সংজ্ঞা অনুযায়ী গুণের ফলাফল হলো
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

একটি অশূন্য জটিল সংখ্যার অন্যোন্যক হলো
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

একটি জটিল সংখ্যা `a + i * b`-কে আরেকটি জটিল সংখ্যা `c + i * d` দিয়ে ভাগ করলে পাওয়া যায়:
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

e-কে একটি জটিল সূচকে উন্নীত করা যায় এভাবে: `e^(a + i * b) = e^a * e^(i * b)`, যার শেষ পদটি অয়লারের সূত্র `e^(i * b) = cos(b) + i * sin(b)` থেকে পাওয়া যায়।

নিচের অপারেশনগুলো ইমপ্লিমেন্ট করুন:
 - দুটি জটিল সংখ্যার যোগ, বিয়োগ, গুণ ও ভাগ,
 - একটি প্রদত্ত জটিল সংখ্যার অনুবন্ধী, পরম মান ও সূচক।


ধরে নিন, আপনি যে প্রোগ্রামিং ভাষা ব্যবহার করছেন সেটিতে জটিল সংখ্যার কোনো ইমপ্লিমেন্টেশন নেই।
