# সম্পর্কে

Swift-এ [ক্লোজার][closures] হলো স্বয়ংসম্পূর্ণ কোড ব্লক, যাদের কাছে প্যারামিটার পাঠিয়ে তাদের গণনা চালানো যায় এবং মান রিটার্ন করানো যায়।
ক্লোজার তাদের পরিবেশ থেকে মানও ধারণ করে এবং সেই মানগুলি তাদের গণনায় ব্যবহার করে।
যেহেতু এগুলি স্বয়ংসম্পূর্ণ, তাই একটি প্রোগ্রামে অন্যান্য মানের মতোই এগুলিকে এদিক-ওদিক পাঠানো যায়, বা কনস্ট্যান্ট ও ভ্যারিয়েবলে অ্যাসাইন করা যায়।

ক্লোজার শুনতে অনেকটা Swift ফাংশনের মতোই লাগতে পারে; সত্যিই লাগে, আর তার ভালো কারণও আছে।
Swift-এ ফাংশন হলো ক্লোজারেরই এক বিশেষ রূপ, যাদের একটি নাম থাকা আবশ্যক এবং যাদের ডিফাইন করা হয় কিছুটা ভিন্ন সিনট্যাক্সে।

Swift-এ ফাংশন প্রযুক্তিগতভাবে ক্লোজার হলেও, যখন কেউ Swift-এ "ক্লোজার" বলে, তারা বোঝায় [ক্লোজার এক্সপ্রেশন][closure-expressions]।
ক্লোজার এক্সপ্রেশন লেখা হয় একটি প্যারামিটার তালিকা, তারপর একটি রিটার্ন টাইপ, তারপর `in` কিওয়ার্ড এবং ক্লোজারের বডি দিয়ে, সবকিছু একটি জোড়া দ্বিতীয় বন্ধনীর ভেতরে:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

এটি `(Double, Double) -> Double` টাইপের একটি ক্লোজার এক্সপ্রেশন ডিফাইন করে, এবং এই টাইপের একটি ফাংশনের মতোই যথাযথ টাইপের প্যারামিটার প্রয়োগ করে এটি চালানো যায়:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

যেহেতু প্রতিবার এটি চালাতে চাইলে পুরো ক্লোজার এক্সপ্রেশনটি লিখে ফেলা খুব সুবিধাজনক নয়, তাই Swift-এর অন্য যেকোনো মানের মতোই ক্লোজারকে নামে অ্যাসাইন করা যায়।
এরপর সেই নামের সাথে প্যারামিটার প্রয়োগ করে সেগুলিকে কল করা যায়:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

উপরে দেখা গেছে, সাধারণ ফাংশনের মতোই ক্লোজারও `return` কিওয়ার্ড বাদ দিতে পারে, যদি ক্লোজারের বডি একটি মাত্র এক্সপ্রেশন হয়।

বেশিরভাগ ক্ষেত্রেই ক্লোজার ব্যবহৃত হয় হায়ার-অর্ডার ফাংশনের সাথে, হয় প্যারামিটার হিসেবে পাঠানো হয়, নয়তো ফলাফল হিসেবে রিটার্ন করা হয়:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## ক্লোজার টাইপ অনুমান করা

যখন রিটার্ন টাইপ বা প্যারামিটার টাইপ [প্রসঙ্গ থেকে অনুমান করা যায়][inferring-closure-types], তখন সেগুলি ক্লোজার এক্সপ্রেশন থেকে বাদ দেওয়া যায়।
এছাড়া, প্যারামিটার টাইপ বাদ দেওয়া গেলে প্যারামিটার নামের চারপাশের প্রথম বন্ধনীও বাদ দেওয়া যায়:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- প্রথম উদাহরণে, টাইপটি `mean` কনস্ট্যান্টের অ্যানোটেশন থেকে অনুমান করা যায়।
- দ্বিতীয়টিতে, কম্পাইলার `makeAdder`-এর সংজ্ঞা থেকে জানে যে `base` একটি ইন্ট এবং রিটার্ন করা ফাংশনটি অবশ্যই `(Int) -> Int` টাইপের হতে হবে। সেখান থেকে এটি যাচাই করতে পারে যে `x` যদি একটি `Int` হয়, তবে ক্লোজারটির টাইপ হবে `(Int) -> Int`, আর তাই আমরা ক্লোজারে টাইপ সিগনেচার বাদ দিতে পারি, কারণ `(Int) -> Int` হলো একমাত্র সম্ভাব্য বৈধ সিগনেচার যা ক্লোজারটির থাকতে পারে।
- তৃতীয় উদাহরণটি একই রকম, তবে কম্পাইলারকে টাইপের কিছু তথ্য নিতে হয় সেই অ্যারে থেকে, যার সাথে মেথডটি ব্যবহার করা হচ্ছে। এটি জানে যে `sorted(by:)` মেথড প্যারামিটার হিসেবে এমন একটি ক্লোজার নেয় যার দুটি প্যারামিটার সাজানো হচ্ছে এমন কালেকশনের এলিমেন্টগুলির সমান টাইপের, এবং যা একটি `Bool` রিটার্ন করে, তাই কম্পাইলার অনুমান করতে পারে যে ক্লোজারটির রিটার্ন টাইপ অবশ্যই `Bool` হতে হবে। আর যেহেতু মেথডটি একটি String অ্যারের সাথে ব্যবহার করা হচ্ছে, এটি নির্ধারণ করতে পারে যে `s1` ও `s2` প্যারামিটার দুটির টাইপই অবশ্যই `String` হতে হবে।

## ক্লোজারের সীমাবদ্ধতা

উপরে বলা হয়েছে, Swift-এ ফাংশন ও ক্লোজার খুবই একই রকম, তবে কিছু গুরুত্বপূর্ণ পার্থক্য আছে:

- ক্লোজার এক্সটার্নাল আর্গুমেন্ট লেবেল ব্যবহার করতে পারে না। এগুলি ডিফাইন করার কোনো উপায় নেই, এবং ক্লোজার কল করার সময় প্যারামিটারের নাম ব্যবহার করার চেষ্টা করলে এরর হয়:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- ক্লোজারের প্যারামিটারের কোনো ডিফল্ট প্যারামিটার মান থাকতে পারে না।
- ক্লোজারের প্যারামিটার ভ্যারিয়েডিক প্যারামিটার হতে পারে, তবে তাদের একটি নাম ও টাইপ অ্যানোটেশন থাকতে হবে।
