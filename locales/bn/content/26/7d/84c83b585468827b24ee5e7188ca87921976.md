# নির্দেশনা

বেহালা একটি রেফারেন্স নোটের সঙ্গে কান খাটিয়ে সুর মেলানো হয়। তারগুলোর পিচ একে অপরের থেকে অনেক দূরে, আর এখানে যে সংখ্যাগুলো আসে সেগুলো পূর্ণসংখ্যা নয়।

পাঁচটি কাজই `TUNING_THE_STRINGS` ক্লাসে যাবে।

## 1. এক অক্টেভ উপরে

এক অক্টেভ উপরে থাকা একটি নোটের কম্পাঙ্ক দ্বিগুণ।

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. এক অক্টেভ নিচে

এক অক্টেভ নিচে থাকা নোটের কম্পাঙ্ক অর্ধেক।

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. ঠিক মাঝখানে

দুটি কম্পাঙ্ক দেওয়া হলে, তাদের ঠিক মাঝখানের কম্পাঙ্কটি রিটার্ন করুন।

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. কতটা সুরের বাইরে?

দুটি নোট কাছাকাছি কিন্তু একই না হলে, তারা যে পরিমাণ সাইকেলে আলাদা, তার প্রতিটি সাইকেলের জন্য সেকেন্ডে একবার বিট শোনা যায়। কম্পাঙ্ক দুটি কতটা দূরে আছে তা রিটার্ন করুন। কোন নোটটি বেশি উচ্চ হোক না কেন, উত্তরটি কখনো ঋণাত্মক নয়।

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. অনুশীলন ভাগ করে নেওয়া

মিনিটের সংখ্যা ও বাদকের সংখ্যা দেওয়া থাকলে, প্রত্যেকে কত মিনিট পাবে? মিনিট আর বাদকের সংখ্যাগুলো পূর্ণসংখ্যা, কিন্তু উত্তরটি পূর্ণ নাও হতে পারে।

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
