# সম্পর্কে

একটি মেথড প্যারামিটারকে ডিফল্ট মান অ্যাসাইন করে অপশনাল করা যায়। অপশনাল প্যারামিটারসহ কোনো মেথড কল করার সময়, কলকারীকে সেগুলোর জন্য কোনো মান পাস করতে হয় না। কোনো অপশনাল প্যারামিটারের জন্য কোনো মান পাস না করা হলে, এর ডিফল্ট মান ব্যবহৃত হবে।

অপশনাল প্যারামিটারগুলোকে প্যারামিটার তালিকার শেষে থাকতে হবে; এগুলোর পরে নন-অপশনাল প্যারামিটার থাকতে পারবে না।

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

অপশনাল প্যারামিটারটিকে ভ্যারিয়েবলের নামের আগে `?` অপারেটর ব্যবহার করে `null`-এ সেট করা যায়:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
