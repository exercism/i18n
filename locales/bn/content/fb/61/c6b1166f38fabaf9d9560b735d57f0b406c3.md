# Elm সিনট্যাক্সের বেসিক ১

## ধ্রুবক ও ফাংশন

Elm প্রোগ্রাম গঠিত হয় ডেফিনিশন আর এক্সপ্রেশন দিয়ে।
Elm-এ সবকিছুই হয় একটি ডেফিনিশন, নয় একটি এক্সপ্রেশন।

একটি ধ্রুবক মান ডিফাইন করা হয় `name = expression` দিয়ে।

```elm
five = 5

six = 3 + 3
```

ফাংশন ডিফাইন করা হয় `name parameters... = expression` দিয়ে,
যেখানে প্যারামিটারগুলো শুধু স্পেস দিয়ে আলাদা করা হয়।

```elm
add number1 number2 = number1 + number2
```

একটি ফাংশন কল করাও একটি এক্সপ্রেশন, আর এটি করা হয় ফাংশনের নাম লিখে
এবং তার প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে,
যেগুলো স্পেস দিয়ে আলাদা করা হয়, ঠিক ফাংশন ডিফাইন করার মতোই।

```elm
five = add 2 3
```

একটি এক্সপ্রেশন কোন ক্রমে হিসাব করা হবে তা নির্দিষ্ট করতে প্রথম বন্ধনী ব্যবহার করা যায়।

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## ইনডেন্টেশন / তাৎপর্যপূর্ণ হোয়াইটস্পেস

কোডের সীমানা নির্দিষ্ট করতে Elm দ্বিতীয় বন্ধনী, প্রথম বন্ধনী বা সেমিকোলনের মতো সিনট্যাকটিক চিহ্ন ব্যবহার করে না। এর বদলে এটি হোয়াইটস্পেস আর ইনডেন্টেশন ব্যবহার করে।

- মডিউল, import এবং টপ-লেভেল ফাংশন ডেফিনিশন অবশ্যই একদম বাম দিকের কলাম থেকে শুরু হতে হবে।
- কোনো এক্সপ্রেশন একাধিক লাইনে ভাগ করা হলে, সেই এক্সপ্রেশনের যে অংশটি কোড, সেটি অবশ্যই ওই এক্সপ্রেশনের নিচে অন্তত একটি স্পেস দিয়ে ইনডেন্ট করতে হবে।
- এক্সপ্রেশনের যে অংশগুলো একসাথে গ্রুপ করা হয়েছে, সেগুলো সমান সংখ্যক স্পেস দিয়ে ইনডেন্ট করা উচিত।

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## মডিউল

Elm-এ প্রতিটি ফাইলই একটি মডিউল, আর অন্য সব কোডের আগে সেখানে একটি `module` স্টেটমেন্ট থাকতে হবে।
মডিউলের নাম অবশ্যই ফাইলের নামের সাথে মিলতে হবে, তাই `Calculator` মডিউলটি অবশ্যই Calculator.elm ফাইলে থাকতে হবে।
একটি মডিউলের ভেতরে ডিফাইন করা যেকোনো কিছু শুধু সেই মডিউলের মধ্যেই সীমাবদ্ধ থাকে
এবং `exposing` তালিকায় উল্লেখ না থাকলে মডিউলের বাইরে থেকে সেগুলো ব্যবহার করা যায় না।

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## কমেন্ট

কমেন্ট হলো Elm ফাইলের ভেতরের এমন কিছু লেখা, যাকে কোড হিসেবে ধরা হয় না।
এটি মূলত আপনি নিজে এবং অন্য প্রোগ্রামারদের পড়ার জন্যই লেখা হয়।
এক লাইনের কমেন্টের জন্য ডাবল ড্যাশ ভিত্তিক একটি হালকা সিনট্যাক্স আছে।
শুরু আর শেষ বোঝানোর জোড়া ডিলিমিটার `{-` এবং `-}` দিয়ে মাল্টিলাইন কমেন্টও লেখা যায়।

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
