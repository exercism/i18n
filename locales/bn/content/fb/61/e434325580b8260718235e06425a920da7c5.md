# অপ্রয়োজনীয় শর্ত

এই সলিউশনে অপ্রয়োজনীয়ভাবে শর্ত ব্যবহার করা হয়েছে। [ডিফল্ট আর্গুমেন্ট][default argument] এবং [str.format][str.format] বা [f-strings][f-strings] (_যাকে "formatted string literals" বা "interpolated strings"-ও বলা হয়_) একসঙ্গে ব্যবহার করলে code আরও পরিষ্কার ও কম বাহুল্যপূর্ণ হয়ে উঠতে পারে।

আরও বিস্তারিত জানতে [Python-এর ডিফল্ট আর্গুমেন্ট][python default arguments] নিয়ে লেখা এই পোস্টটি দেখুন। [Python-এ স্ট্রিং ফরম্যাটিং][string formatting in python] ব্লগ পোস্টটিও Python-এর স্ট্রিং ফরম্যাটিংয়ের নানা অপশন সম্পর্কে জানার একটি ভালো সূচনা হতে পারে।
