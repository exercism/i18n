# সম্পর্কে

ফিল্টারিং হলো একটি সিকোয়েন্স থেকে আরেকটি সিকোয়েন্স তৈরির প্রক্রিয়া, যেখানে মূল সিকোয়েন্সের নির্দিষ্ট কিছু এলিমেন্ট বাদ দিয়ে বাকি সবগুলো কপি করা হয়। নতুন সিকোয়েন্সে কোন কোন আইটেম রাখা হবে, তা ঠিক করা যায় একটি প্রেডিকেট ফাংশন দিয়ে (এমন একটি ফাংশন, যা একটি বুলিয়ান মান দেয়), কিংবা কোনো নির্দিষ্ট অবজেক্টের সাথে সমতা দিয়ে।

## প্রেডিকেট দিয়ে বাদ দেওয়া

`remove-if` এমন একটি ফাংশন, যা আর্গুমেন্ট হিসেবে একটি প্রেডিকেট ফাংশন ও একটি সিকোয়েন্স নেয় এবং কেবল সেই এলিমেন্টগুলোর একটি সিকোয়েন্স রিটার্ন করে, যেগুলোর জন্য প্রেডিকেটটি ফলস মান দিয়েছে। অন্য কথায়, সিকোয়েন্সের যে এলিমেন্টগুলোর জন্য প্রেডিকেটটি ট্রু মান দেয়, সেগুলোকে এটি "বাদ দেয়"। তবে মনে রাখবেন, এই ফাংশনটি মূল সিকোয়েন্স পরিবর্তন করে না! বরং, সংশ্লিষ্ট এলিমেন্টগুলো ছাড়া একটি নতুন সিকোয়েন্স রিটার্ন করে। যদি সব মানের জন্যই প্রেডিকেটটি ট্রু হয়, তবে একটি খালি সিকোয়েন্স রিটার্ন করা হয়।

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## প্রেডিকেট দিয়ে এলিমেন্ট রাখা

`remove-if-not` নামে একটি ফাংশন আছে, যা ঠিক `remove-if`-এর মতোই, শুধু পার্থক্য হলো এটি সেই এলিমেন্টগুলো *রাখে*, যেগুলোর জন্য প্রেডিকেটটি ট্রু মান দেয়।

বিকল্প হিসেবে `complement` ব্যবহার করে একটি প্রেডিকেটকে তার 'বিপরীত'-এ বদলে নেওয়া যায়।

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## নির্দিষ্ট একটি আইটেম বাদ দেওয়া

কোনো সিকোয়েন্স থেকে নির্দিষ্ট একটি আইটেম বাদ দিতে চাইলে `remove` ব্যবহার করা যায়, যা বাদ দেওয়ার আইটেমটি ও একটি সিকোয়েন্স নেয়। সিকোয়েন্সের যে মানগুলো বাদ দেওয়ার আইটেমটির সমান নয়, সেগুলোই রিটার্ন করা হয়।

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

সমতা যাচাইয়ের জন্য কোন ফাংশন ব্যবহার হবে, তা `:test` [কিওয়ার্ড প্যারামিটার][concept-keyword-parameters] দিয়ে নির্দিষ্ট করা যায়।

মনে রাখবেন, নির্দিষ্ট একটি আইটেমের সাথে কোনো অবজেক্টের সমতা যাচাই করে এমন একটি প্রেডিকেট লিখে `remove-if` দিয়েও `remove` তৈরি করা যেত।

## অনেক রকম অপশন

এই ফাংশনগুলোর প্রত্যেকটিই আরও অনেক [কিওয়ার্ড প্যারামিটার][concept-keyword-parameters] নেয়, যেগুলোর সাহায্যে কেবল সাবসিকোয়েন্সের উপর কাজ করা, নির্দিষ্ট সংখ্যকবার প্রয়োগ করা ইত্যাদি করা যায়। বিস্তারিত জানতে [Hyperspec ডকুমেন্টেশন][hyperspec-remove] দেখুন।


## ডেস্ট্রাক্টিভ অপশন

`remove`, `remove-if` ও `remove-if-not` ছাড়াও আছে `delete`, `delete-if` ও `delete-if-not`, যেগুলোর প্রভাব একই, তবে এরা নিজেদের কাছে পাঠানো সিকোয়েন্সটি পরিবর্তন করে দিতে পারে।
