# নির্দেশনার সংযোজন

## ইঙ্গিত

এই অনুশীলনীটি টেক্সটভিত্তিক ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর `String` টাইপ `[Char]`-এর সমার্থক, যা ক্যারেক্টারগুলোর একটি অ্যারে। টেক্সটভিত্তিক ডেটা আরও দক্ষভাবে সামলানোর জন্য `Text` টাইপটি ব্যবহার করা যেতে পারে।

এই অনুশীলনীর ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি যা করতে পারেন:

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml-এ আপনার ডিপেন্ডেন্সিগুলোর তালিকায় `- text` যোগ করুন।
- `Data.Text` [নিম্নলিখিত উপায়ে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) ইমপোর্ট করুন:

        import qualified Data.Text as T
        import           Data.Text (Text)

- এখন আপনি যেমন `transform :: Map Int Text -> Map Char Int` লিখতে পারেন, এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.toLower` হিসেবে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখে নিন।

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
