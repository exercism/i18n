# পরিচিতি

Swift-এ আপনি একটি স্ট্রিং-এ ইন্টিজার দিয়ে ইনডেক্স করতে পারেন না (যেমন `string[3]`)।
কারণ Swift স্ট্রিংগুলো ভ্যারিয়েবল-দৈর্ঘ্যের ইউনিকোড ক্যারেক্টার দিয়ে গঠিত, তাই একটি ক্যারেক্টার খুঁজে পেতে আগের ক্যারেক্টারগুলোর মধ্য দিয়ে একে একে যেতে হয়।

নির্দিষ্ট অবস্থানের একটি ক্যারেক্টার অ্যাক্সেস করতে হলে আপনাকে `String.Index` টাইপের একটি ইনডেক্স গণনা করতে হবে।
এই ইনডেক্সগুলোকে *ওপেক ইনডেক্স* বলা হয়, কারণ এগুলোর অভ্যন্তরীণ গঠন Swift পরিচালনা করে, সরাসরি কাঁচা ইন্টিজার হিসেবে এগুলো নিয়ে কাজ করা হয় না:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
