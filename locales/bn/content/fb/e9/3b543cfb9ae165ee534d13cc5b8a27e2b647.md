# নির্দেশনা

হঠাৎ আপনার প্যানকেক খেতে খুব ইচ্ছে করছে।
আধুনিক ও প্রযুক্তি-মনস্ক একজন মানুষ হিসেবে আপনি প্যানকেকের উপকরণের একটি কেনাকাটার তালিকা JSON ফরম্যাটে লেখেন।
তালিকার গঠনটি হলো:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

একটি উপকরণকে JSON অবজেক্ট দিয়ে এভাবে প্রকাশ করা হয়:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

একটি উপকরণে `"substitute"` নামের একটি ঐচ্ছিক প্রপার্টি থাকতে পারে, যেখানে থাকে এমন আরেকটি জিনিসের স্ট্রিং যা এর বদলে ব্যবহার করা যায়।

চলুন দেখি `jq` দিয়ে কেনাকাটার তালিকাটি কীভাবে খতিয়ে দেখা যায়

## 1. কেনাকাটার তালিকার নাম বের করুন

এমন একটি এক্সপ্রেশন লিখুন যা কেনাকাটার তালিকার "name" এলিমেন্টটি আউটপুট দেয়।

## 2. কতগুলো উপকরণ দরকার তা গুনুন

শুধু "আবশ্যক" উপকরণগুলোই গুনুন। ঐচ্ছিক উপকরণগুলো ধরবেন না।

## 3. কতটা চিনি?

এমন একটি এক্সপ্রেশন লিখুন যা চিনির পরিমাণ আউটপুট দেয়।
শুধু সংখ্যার অংশটুকুই দরকার।

## 4. যে উপকরণগুলো বদলে ব্যবহার করা যায় সেগুলো ম্যাপ করুন

কিছু উপকরণ বদলে ব্যবহার করা যায় (যদি আপনার কাছে X উপকরণ না থাকে, তাহলে Y ব্যবহার করতে পারেন)।
প্রস্তাবিত উপকরণকে তার বিকল্পের সঙ্গে ম্যাপ করা একটি JSON অবজেক্ট আউটপুট দিন।
ম্যাপিংয়ের মধ্যে ঐচ্ছিক উপকরণগুলোও রাখুন।
