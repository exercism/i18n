# নির্দেশাবলি

এই অনুশীলনীতে আপনি লগ-লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট নিম্নরূপ: `"[<LEVEL>]: <MESSAGE>"`.

এখানে তিনটি ভিন্ন লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার কয়েকটি কাজ আছে, যার প্রত্যেকটি একটি লগ লাইন নেবে এবং সেটি নিয়ে আপনাকে কিছু করতে বলবে।

## 1. নির্দিষ্ট সাবস্ট্রিংয়ের পরে থাকা স্ট্রিং বের করা

গত মাসের লগগুলো দেখে আপনি বুঝতে পারেন যে টেস্ট মেসেজটি সর্বদা একটি নির্দিষ্ট সাবস্ট্রিংয়ের পরে অবস্থান করে। আপনি আশা করছেন যে খুব শীঘ্রই আপনাকে টেস্ট মেসেজটি বের করতে হবে, তাই সেটির জন্য একটি হেল্পার মেথড তৈরি করার সিদ্ধান্ত নেন।

(_static_) `LogAnalysis.SubstringAfter()` এক্সটেনশন মেথডটি ইমপ্লিমেন্ট করুন, যা একটি স্ট্রিং ডেলিমিটার নেয় এবং ডেলিমিটারের পরে থাকা সাবস্ট্রিং রিটার্ন করে।

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. দুটি সাবস্ট্রিংয়ের মাঝখানে থাকা স্ট্রিং বের করা

আরও খেয়াল করলে আপনি দেখবেন যে লগ লেভেলটি সর্বদা তৃতীয় বন্ধনীর (`[` এবং `]`) মধ্যে অবস্থান করে। আপনি এটাও আশা করছেন যে খুব শীঘ্রই আপনাকে লগ লেভেলটি বের করতে হবে, তাই সেটির জন্যও আরেকটি হেল্পার মেথড তৈরি করার সিদ্ধান্ত নেন।

(_static_) `LogAnalysis.SubstringBetween()` এক্সটেনশন মেথডটি ইমপ্লিমেন্ট করুন, যা দুটি স্ট্রিং ডেলিমিটার নেয় এবং দুটি ডেলিমিটারের মাঝখানে থাকা সাবস্ট্রিং রিটার্ন করে।

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. একটি লগে মেসেজ পার্স করা

একটি লগে থাকা মেসেজ রিটার্ন করার জন্য (_static_) `LogAnalysis.Message()` এক্সটেনশন মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. একটি লগে লগ লেভেল পার্স করা

একটি লগের লগ লেভেল রিটার্ন করার জন্য (_static_) `LogAnalysis.LogLevel()` এক্সটেনশন মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
