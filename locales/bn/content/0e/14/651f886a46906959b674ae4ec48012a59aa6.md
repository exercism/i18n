# টেস্ট

একটি Elm প্রজেক্টের টেস্টগুলো থাকে সেই প্রজেক্টের `tests/` সাবডিরেক্টরিতে।
প্রতিটি অনুশীলনীর টেস্ট স্যুট ওই অনুশীলনীর রুট ডিরেক্টরি থেকে চালানো যায়।

```bash
$ cd ~/exercism/elm/hello-world
$ elm-test
```

## পরিবর্তনের জন্য নজর রাখুন

আপনি পরিবর্তন সেভ করলেই স্বয়ংক্রিয়ভাবে আবার টেস্ট চালানো হবে:

```bash
$ elm-test --watch
```

## টেস্ট ড্রিভেন ডেভেলপমেন্ট প্রবাহ

বেশিরভাগ অনুশীলনীতে টেস্টগুলো আগেই `tests/Tests.elm` ফাইলে লেখা থাকে।
আপনার লক্ষ্য হলো `src/<exercise>.elm` ফাইলে দরকারি কোড লিখে সেগুলো পাস করানো।
প্রথম যে টেস্টটি ফেল করছে তার দিকে মনোযোগ দিন, সেটি ঠিক করুন,
তারপর টেস্ট ফাইলের পরের `skip <|` স্নিপেটটি মুছে ফেলুন বা কমেন্ট করুন, এবং সব টেস্ট পাস না হওয়া পর্যন্ত এভাবে চালিয়ে যান।

## আটকে গেছেন?

আপনার প্রথম লক্ষ্য হলো আপনার কোড কম্পাইল করানো, তাতে `Debug.todo` থাকলেও।
যদি মনে হয় আপনি কোনো কিছু কীভাবে করবেন তা জানেন না,
তাহলে সেই অংশটিকে আলাদা একটি অ-ইমপ্লিমেন্টেড ফাংশনে সরিয়ে নেওয়া প্রায়ই কাজে লাগে।

```elm
complexOperationOnMultipleStrings : List String -> List String
complexOperationOnMultipleStrings allStrings =
    List.map complexOperation allStrings


complexOperation : String -> String
complexOperation input =
    Debug.todo "Extracted operation into its own function"
```

এই বের করা ফাংশনে একটি টাইপ অ্যানোটেশন যোগ করলে তা আপনার ভাবনাকে এবং কম্পাইলারকে আরও ভালো এরর মেসেজ দিতে সাহায্য করবে।

## আপনার কোড গুছিয়ে নেওয়া

সাবমিট করার আগে আপনার কোডে [`elm-format`](https://github.com/avh4/elm-format) চালানোর কথা ভাবুন,
এমনকি সেভ করার সময় স্বয়ংক্রিয় ফরম্যাটিংয়ের জন্য এটি আপনার টেক্সট এডিটরে সেট আপ করার কথাও ভাবুন।
