# টাইপ জাগলিং

টাইপ জাগলিংকে টাইপ কোয়ার্শন নামেও জানা যায়।
টাইপ জাগলিং তখন ঘটে, যখন একটি অপারেশন চালানোর জন্য ভিন্ন ভিন্ন টাইপের দুটি মানকে একই টাইপে রূপান্তর করা হয়।

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

এটি নিজে থেকেই (উপরের উদাহরণটি দেখুন) হতে পারে, আবার `C`-স্টাইলের টাইপ কাস্টিং দিয়ে স্পষ্টভাবেও করা যায়:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

হাতে করে টাইপ কাস্টিং করার জন্য অনুমোদিত টাইপগুলো হলো: `bool`, `int`, `float`, `string`, `array`, `object`।
সাধারণত একটি ইন্টিজার (`int`) থেকে ফ্লোটে (`float`), বা উল্টোটা পরিবর্তন করতেই টাইপ কাস্টিং বেশি ব্যবহার করা হয়।
