# ভূমিকা

টার্নারি অপারেটর দিয়ে স্টেটমেন্ট ব্লকের বদলে এক্সপ্রেশনে if শর্তগুলো ডিফাইন করা যায়। এটি ফাংশনাল প্রোগ্রামিংয়ের ধরনকে মনে করিয়ে দেয় এবং প্রায়ই কোডকে আরও এক্সপ্রেসিভ করে তোলে, এরর হওয়ার সম্ভাবনাও কমায়।

টার্নারি অপারেটর তিনটি এক্সপ্রেশন মিলিয়ে তৈরি: একটি শর্ত, তারপর শর্তটি ট্রু হলে যে এক্সপ্রেশনটি মূল্যায়ন করে রিটার্ন করা হয় (এটাই `if` অংশ, যার আগে `?` বসে), এবং শর্তটি ফলস হলে যে এক্সপ্রেশনটি মূল্যায়ন করে রিটার্ন করা হয় (এটাই `else` অংশ, যার আগে `:` বসে)।

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
