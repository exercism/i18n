# ভূমিকা

C#-এ একটি প্রপার্টি হলো একটি ক্লাসের মেম্বার, যা ওই ক্লাসের ভেতরের ডেটাতে অ্যাকসেস দেয়। কলাররা ডেটা সেট বা রিট্রিভ (গেট) করতে পারেন। প্রপার্টি হয় অটো-ইমপ্লিমেন্টেড হতে পারে, নয়তো এর একটি ব্যাকিং ফিল্ড থাকতে পারে। এগুলো একটি সেট অ্যাকসেসর এবং/অথবা একটি গেট অ্যাকসেসর নিয়ে গঠিত। অন্য কিছু ভাষায় একটি "মিউটেটর" মোটামুটি সেট অ্যাকসেসরের সমতুল্য এবং একটি "অ্যাকসেসর" মোটামুটি গেট অ্যাকসেসরের সমতুল্য, যদিও সিনট্যাক্সের গঠন সম্পূর্ণ ভিন্ন।

একটি প্রপার্টি সেট করার সময় ইনপুট মান যাচাই করা, ফরম্যাট করা বা অন্যভাবে ম্যানিপুলেট করা যায়, এবং আসলে ক্লাসের কোড থেকে অ্যাকসেসযোগ্য যেকোনো প্রোগ্রাম্যাটিক অপারেশন চালানো যায়।

একইভাবে একটি প্রপার্টি রিট্রিভ করার সময় ডেটা গণনা করা বা ফরম্যাট করা যায়, এবং আবারও ক্লাসে উপলব্ধ যেকোনো প্রোগ্রাম্যাটিক অপারেশন চালানো যায়।

প্রপার্টিগুলোর অ্যাকসেস মডিফায়ার (`public`, `private` ইত্যাদি) থাকে অন্য ক্লাস মেম্বারগুলোর মতোই, তবে সেট অ্যাকসেসরের অ্যাকসেস লেভেল রিট্রিভ (গেট) অ্যাকসেসর থেকে স্বাধীন হতে পারে এবং এর উল্টোটাও। একটি প্রপার্টিতে দুটো অ্যাকসেসরই থাকতে হয় না, শুধু একটি থাকলেও চলে (গেট অথবা সেট)।

প্রপার্টি প্রকাশ করার মৌলিক সিনট্যাক্স দুটি রূপ নিতে পারে:

## ফিল্ড/এক্সপ্রেশন ব্যাকড প্রপার্টি:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## অটো-ইমপ্লিমেন্টেড প্রপার্টি

```
public int MyProperty { get; private set; } = 42;
```
