# পরিচিতি

একটি [`for` লুপ][for-statement] দিয়ে একটি শর্ত পূরণ হওয়া পর্যন্ত কোড বারবার চালানো যায়।

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

একটি `for` লুপ চারটি অংশ নিয়ে গঠিত:

1. ইনিশিয়ালাইজার: লুপে ঢোকার আগে একবার চালানো হয়। সাধারণত লুপের ভেতরে ব্যবহৃত ভ্যারিয়েবল ডিফাইন করতে এটি ব্যবহার করা হয়।
2. শর্ত: প্রতিটি লুপ ইটারেশনের আগে এটি চালানো হয়। এটি `true` মান দিলে লুপ চলতে থাকে।
3. ইটারেটর: প্রতিটি লুপ ইটারেশনের পরে এটি চালানো হয়। সাধারণত লুপ ভ্যারিয়েবল পরিবর্তন করতে (প্রায়ই: ইনক্রিমেন্ট/ডিক্রিমেন্ট) ব্যবহার করা হয়।
4. বডি: প্রতি লুপ ইটারেশনে যে কোডটি চালানো হয়।

## `for` বনাম `foreach` লুপ

সাধারণভাবে, নিচের কারণগুলোতে [concept:csharp/foreach-loops]() `for` লুপের চেয়ে বেশি পছন্দনীয়:

- একটি `foreach` লুপ _সব_ মানের উপরই ইটারেট করবে, তা নিশ্চিত। `for` লুপে এলিমেন্ট বাদ পড়া সহজ, যেমন অফ-বাই-ওয়ান এররের কারণে।
- একটি `foreach` লুপ আরও _ডিক্লারেটিভ_, আপনার কোড _কী_ করতে চায় সেটাই জানায়, অন্যদিকে `for` লুপ জানায় _কীভাবে_ করতে চান।
- একটি `foreach` লুপ নিরাপদ, যেখানে `for` লুপে সহজেই অফ-বাই-ওয়ান এরর হয়ে যেতে পারে।
- একটি `foreach` লুপ সব ধরনের কালেকশনে কাজ করে, এমন কালেকশনসহ যেগুলোতে এলিমেন্ট পাওয়ার জন্য ইনডেক্সার ব্যবহার করা যায় না।

`foreach` লুপ যে _সব_ মানের উপরই ইটারেট করবে তা নিশ্চিত করতে কম্পাইলার `foreach` লুপের ভেতরে কালেকশন পরিবর্তনের অনুমতি দেয় না:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for` লুপের আবার `foreach` লুপের চেয়ে কিছু সুবিধা আছে:

- আপনি চাইলে যে ইনডেক্সে শুরু বা শেষ করতে পারেন।
- আপনি চাইলে যেকোনো (বুলিয়ান) সমাপ্তির শর্ত ব্যবহার করতে পারেন।
- লুপ ভ্যারিয়েবলের ইনক্রিমেন্ট নিজের মতো সাজিয়ে এলিমেন্ট বাদ দিতে পারেন।
- কাউন্ট ডাউন করে কালেকশন পিছন থেকে সামনে প্রসেস করতে পারেন।
- যেসব পরিস্থিতিতে কালেকশন নেই, সেখানেও `for` লুপ ব্যবহার করতে পারেন।
