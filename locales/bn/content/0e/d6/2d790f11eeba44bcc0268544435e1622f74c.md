# পরিচিতি

একটি `Map` **কী (key)** ও **মান**ের জোড়া সংরক্ষণ করতে ব্যবহৃত হয়। `Maps` ঠিক অ্যারের মতোই ইনিশিয়ালাইজ করা হয়, তবে এতে ম্যাপ লিটারাল অপারেটর `=>` ব্যবহার করা হয়। এগুলোর কী (key) ও মানের টাইপ স্পষ্টভাবে ডিফাইন করা যায়, আবার টাইপ অনুমান করেও নেওয়া যায়। কী (key) ইউনিক হতে হবে, নাহলে একটি এরর থ্রো করা হয়।

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

একটি `Map`-এর উপর একটি `for` লুপ দিয়ে ইটারেশন করা যায়। আপনি মানগুলোর উপর ইটারেশন করতে পারেন, আবার কী (key) গুলোর উপরও:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
