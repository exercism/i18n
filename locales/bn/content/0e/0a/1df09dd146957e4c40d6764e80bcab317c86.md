# ভূমিকা

একটি *টাপল* কয়েকটি নামযুক্ত মানকে একসাথে একটি অবজেক্টে বেঁধে রাখে, অন্য ভাষায় যাকে রেকর্ড, স্ট্রাক্ট বা ক্লাস বলা হয়। প্রতিটি টাপল ক্লাসে নামযুক্ত স্লটের একটি নির্দিষ্ট সেট থাকে এবং Factor স্বয়ংক্রিয়ভাবে সেগুলোর জন্য গেটার ও সেটার তৈরি করে।

## একটি টাপল ডিফাইন করা

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

প্রতিটি স্লট `{ name initial: default-value }` আকারে ডিক্লেয়ার করা হয়। `initial:` ক্লজ না থাকলে ডিফল্ট মান হয় `f`।

## একটি টাপল তৈরি করা

সবচেয়ে সহজ কনস্ট্রাক্টরটি হলো `new`:

```factor
point new .
! => T{ point }
```

`boa` (আর্গুমেন্টের ক্রম অনুযায়ী) ডেটা স্ট্যাক থেকে ডিক্লেয়ারেশনের ক্রমে স্লটগুলো পূরণ করে:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

লিটারেল সিনট্যাক্স `T{ class { slot value } … }` দিয়ে আপনি স্লটের একটি উপসেট সেট করে একটি টাপল তৈরি করতে পারেন, আর এটি একইভাবে প্রিন্ট হয়:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

কোনো স্লটের মান তার ডিফল্টের সাথে মিলে গেলে প্রিন্টার সেটি বাদ দেয়।

## একটি স্লট পড়া

Factor প্রতিটি স্লটের জন্য একটি গেটার `slot>>` তৈরি করে। গেটারগুলো [`accessors`][accessors]-এ থাকে:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## একটি স্লট আপডেট করা

সেটারগুলো `>>slot` আকারে লেখা হয় এবং টাপলটিকে একই জায়গায় *মিউটেট* করে:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

আসলটি অপরিবর্তিত রাখতে প্রথমে `clone` করুন:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` একটি কোয়োটেশন নেয় যা বর্তমান মানকে নতুন মানে রূপান্তর করে:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x`-ও মিউটেটিং, তাই আসলটি সংরক্ষণ করতে চাইলে এটি কল করার আগে `clone` করুন।
