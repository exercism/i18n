# ভূমিকা

অ্যারের সঙ্গে যে সাবস্ক্রিপ্ট মেথড ব্যবহার করা হয়, তা দিয়েই একটি `String`-এর প্রতিটি আলাদা ক্যারেক্টার অ্যাক্সেস করা যায়।
তবে স্ট্রিংয়ের জন্য ব্যবহৃত [ইনডেক্সগুলো][string-indices] _ইন্টিজার নয়_, এবং সরাসরি এগুলো নিয়ে কাজ করা যায় না।
বরং কিছু অন্য পরিচিত ইনডেক্সের ভিত্তিতে এগুলো হিসাব করে বের করতে হয়, যেমন `startIndex`, যা খালি নয় এমন একটি স্ট্রিংয়ের প্রথম ক্যারেক্টারের অবস্থান দেখায়। এর জন্য [`String`][string-docs] ও [`NSString`][nsstring-docs] লাইব্রেরিতে থাকা মেথডগুলো ব্যবহার করা হয় (`Foundation` মডিউল ইমপোর্ট করা থাকলে Swift-এর স্ট্রিংগুলো NSString-এর সব প্রপার্টি ও মেথড ব্যবহার করতে পারে)।

উদাহরণস্বরূপ, নিচের স্ট্রিংটি দেখুন:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

"orange"-এর "g" পেতে `csv[21]` লেখা যায় না; বরং `String.Index` টাইপের একটি মান হিসাব করে সেই ইনডেক্সটি দিতে হয়।
মনে রাখবেন, এই ইনডেক্সগুলো নিজে নিজে মানুষের পড়ার জন্য বানানো নয়।
এগুলোকে বলা হয় _অপাক ইনডেক্স_, কারণ ভেতরে কী আছে তা মানুষের জানার দরকার নেই।

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

তবে লক্ষ্য রাখুন, অফসেট যদি বৈধ ইনডেক্স না হয়, অর্থাৎ যদি তা `startIndex`-এর আগের বা `endIndex`-এর পরের ইনডেক্স দেয়, তাহলে অপারেশনটি একটি এরর তুলবে এবং প্রোগ্রামটি ক্র্যাশ করবে।
এই সমস্যা এড়াতে একটি সীমাবদ্ধকারী ইনডেক্স নির্দিষ্ট করা যায়।
এটি একটি অপশনাল ইনডেক্স রিটার্ন করে এবং অন্যথায় অবৈধ ইনডেক্সের জন্য nil রিটার্ন করবে।

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

এছাড়াও, ইনডেক্স এক স্ট্রিং থেকে আরেক স্ট্রিংয়ে শেয়ার করা যায় না।
উদাহরণস্বরূপ, উপরে "orange"-এর "g"-এর জন্য হিসাব করা `index` দিয়ে `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` স্ট্রিংয়ে ইনডেক্স করতে চাইলে, অর্থাৎ `fam[index]` লিখলে আপনার প্রোগ্রামটি ক্র্যাশ করবে।

এসবের পেছনে অনেক কারণ আছে, তবে মূল কথা একটাই: "ইউনিকোড জটিল ব্যাপার"।

সাধারণভাবে বলতে গেলে, আলাদা আলাদা ক্যারেক্টারে র্যান্ডম অ্যাক্সেস দরকার হলে আপনার সম্ভবত অন্য কোনো ডেটা স্ট্রাকচার ব্যবহার করা উচিত, যেমন `Array<Character>`।

## কিছু দরকারি মেথড

Swift-এ `first` আর `last` মেথড আছে, যা দিয়ে একটি স্ট্রিংয়ের প্রথম ও শেষ ক্যারেক্টার পাওয়া যায়।
এই মেথডগুলো একটি অপশনাল ক্যারেক্টার রিটার্ন করে, তাই স্ট্রিংটি খালি হলে সেগুলো nil রিটার্ন করবে।

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

এছাড়াও `prefix` আর `suffix` মেথড দিয়ে একটি স্ট্রিংয়ের সাবস্ট্রিং পেতে পারেন।
এই মেথডগুলো আর্গুমেন্ট হিসেবে একটি ইন্টিজার নেয় এবং স্ট্রিংয়ের প্রথম বা শেষ n সংখ্যক ক্যারেক্টার সম্বলিত একটি সাবস্ট্রিং রিটার্ন করে।

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
