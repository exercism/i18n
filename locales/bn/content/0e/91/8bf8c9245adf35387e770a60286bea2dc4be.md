# সম্পর্কে

একটি ফ্লোটিং-পয়েন্ট সংখ্যা হলো এমন একটি সংখ্যা যার দশমিক বিভাজকের পরে শূন্য বা তার বেশি অঙ্ক থাকে।
উদাহরণ হলো `4.0`, `0.1`, `3.14`, `-6.4` `16.984025` এবং `1024.0`।
রুবিতে ফ্লোটিং-পয়েন্ট সংখ্যা [Float][Float] ক্লাসের মাধ্যমে বাস্তবায়িত হয়।

ফ্লোটিং-পয়েন্ট সংখ্যা সম্পর্কে একটি সংক্ষিপ্ত পরিচিতি পাবেন [0.30000000000000004.com][0.30000000000000004.com] ঠিকানায়।

কীভাবে একটি ফ্লোটিং-পয়েন্ট সংখ্যার বিটগুলো প্রকৃত ফ্লোটিং-পয়েন্ট মানে রূপান্তরিত হয়, তার একটি চমৎকার গ্রাফিক্যাল ব্যাখ্যা রয়েছে [Float Toy পৃষ্ঠাটিতে][evanw.github.io-float-toy]।

লজিক বারবার সম্পাদন করতে লুপ ব্যবহার করা যায়।
এই উদাহরণে `while` লুপটি কাজে লাগে, কারণ কোনো শর্ত ট্রুথি মানে (অর্থাৎ `false` বা `nil` নয়) মূল্যায়িত হওয়া পর্যন্ত এটি লুপ চালিয়ে যায়।
`while` লুপের মতোই একটি লুপ রুবিতে বাস্তবায়িত হয়েছে।
এর নাম `until` লুপ, এবং এটি কী করে তা আপনি নিশ্চয়ই অনুমান করতে পেরেছেন।
কোনো বুলিয়ান শর্ত `true` হিসেবে মূল্যায়িত হওয়া পর্যন্ত এটি লুপ চালিয়ে যায়।
কিছু ভাষায় কোডের একটি অংশকে অসীমবার চালানোর জন্য `while true` জাতীয় গঠন ব্যবহার করা হয়।
রুবিতে এই কাজের জন্যই `loop` লুপটি রয়েছে।
যদিও `loop` লুপটি কোনো একক শর্তের উপর নির্ভর করে না, তবুও `return` বা `break` কিওয়ার্ড ব্যবহার করে এটি বাতিল করা যায়।

আগের অনুশীলনীর `#years_before_desired_balance` মেথডটি উল্লেখিত তিনটি লুপের যেকোনো একটি দিয়ে লেখা যেত:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

আপনি নিশ্চয়ই খেয়াল করেছেন, অন্য কিছু ভাষার মতো রুবিতে `i++`-এর মতো কোনো ইনক্রিমেন্ট অপারেটর নেই।
তার বদলে `i += 1`-এর মতো গঠন ব্যবহার করা যায় (যা `i = i + 1`-এর সমান)।
