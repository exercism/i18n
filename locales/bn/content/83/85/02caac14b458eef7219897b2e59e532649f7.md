# পরিচিতি

ফাংশন হলো সুসংগঠিত, পুনরায় ব্যবহারযোগ্য কোডের একটি ব্লক, যা দিয়ে কোনো একটি কাজ করা হয়।
JavaScript-এ ফাংশন ডিফাইন করার একাধিক উপায় আছে।
এখানে আমরা _ফাংশন ডিক্লারেশন_ এবং _ফাংশন এক্সপ্রেশন_ দেখব।
[অ্যারো ফাংশন][concept-arrow-functions]-এর মতো অন্যান্য সম্ভাবনা অন্য কনসেপ্টে আলোচনা করা হবে।

## ফাংশন ডিক্লারেশন

JavaScript-এ ফাংশন ডিফাইন করার আদর্শ উপায় হলো _ফাংশন ডিক্লারেশন_, যাকে _ফাংশন ডেফিনিশন_ বা _ফাংশন স্টেটমেন্ট_-ও বলা হয়।

এটি `function` কিওয়ার্ড, ফাংশনের নাম এবং প্রথম বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা প্যারামিটারের একটি তালিকা নিয়ে গঠিত।
এরপর দ্বিতীয় বন্ধনীতে মোড়ানো ফাংশন বডি থাকে (ফাংশনটি কী কাজ করে তা নির্ধারণকারী স্টেটমেন্টের সমষ্টি)।

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

JavaScript-এ একটি ফাংশন কল করা হয় এভাবে: ফাংশনের নাম লিখে তারপর প্রথম বন্ধনীর ভেতরে আর্গুমেন্ট দিতে হয়।

```javascript
someName(arg1, arg2, arg3);
```

## প্যারামিটার

ফাংশন বডির ভেতরে প্যারামিটার নিয়ে কাজ করার সময় সম্ভাব্য সাইড এফেক্ট সম্পর্কে সচেতন থাকুন।

- [প্রিমিটিভ ডেটা টাইপ][mdn-primitives]-এর মানগুলো _ইমিউটেবল_।
  ফাংশন বডিতে আর্গুমেন্টের সাথে যা-ই ঘটুক না কেন, তাতে আসল মান কখনো প্রভাবিত হয় না।
- অন্য সব মানের (অবজেক্ট, অ্যারে, ফাংশন) ক্ষেত্রে, নতুন করে অ্যাসাইন করলে আসল মান প্রভাবিত হয় না।
  তবে, এমন কোনো আর্গুমেন্ট যদি আপনি পরিবর্তন করেন (যেমন একটি অবজেক্টে একটি কী (key) যোগ করা), তাহলে পাস করা আসল মানটিও পরিবর্তিত হয়।

ডিফল্টভাবে, JavaScript-এ ফাংশন ডিক্লারেশনে ডিফাইন করা সব প্যারামিটারই ঐচ্ছিক।
প্যারামিটারের চেয়ে কম আর্গুমেন্ট দিলে, অনুপস্থিত আর্গুমেন্টগুলো ফাংশনের ভেতরে `undefined` হবে, দেখুন [Null and Undefined][concept-null-undefined]।
অনেক ক্ষেত্রেই `undefined`-এর বদলে আরও উপযুক্ত একটি ডিফল্ট মান অ্যাসাইন করা অর্থবহ।
এটি করা যায় ফাংশন ডেফিনিশনে সরাসরি ডিফল্ট প্যারামিটার উল্লেখ করে।

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## রিটার্ন স্টেটমেন্ট

একটি `return` স্টেটমেন্ট ফাংশনের এক্সিকিউশন শেষ করে এবং ফাংশন কলকারীর কাছে রিটার্ন করার জন্য একটি মান নির্দিষ্ট করে। একটি ফাংশনে একাধিক `return` স্টেটমেন্ট থাকতে পারে।

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

যে ফাংশন কোনো মান `return` করে না বা যার কোনো `return` স্টেটমেন্ট নেই, তার ফলাফল `undefined`।
JavaScript-এ কোনো অন্তর্নিহিত `return` নেই।

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

JavaScript-এ আপনি কেবল ঠিক একটি মানই রিটার্ন করতে পারেন।
আরও বেশি তথ্য পাঠাতে চাইলে, প্রথমে সেগুলোকে একটি সত্তায় একত্র করতে হবে, সাধারণত একটি [অবজেক্ট][concept-objects]-এ বা একটি [অ্যারে][concept-arrays]-তে।

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## ফাংশন এক্সপ্রেশন

একটি ফাংশন ডিক্লারেশন একটি স্বতন্ত্র স্টেটমেন্ট।
কিন্তু কখনো কখনো অন্য একটি এক্সপ্রেশনের অংশ হিসেবে ফাংশন ডিফাইন করা সুবিধাজনক, যেমন একটি অ্যাসাইনমেন্টে, একটি ফাংশন প্যারামিটার হিসেবে ([কলব্যাক][concept-callbacks]) বা একটি [অবজেক্ট][concept-objects]-এর মান হিসেবে।
এটি করা যায় একটি ফাংশন এক্সপ্রেশন দিয়ে।
এর সিনট্যাক্স একটি ফাংশন ডিক্লারেশনের মতোই, শুধু ফাংশনের নাম বাদ দিয়ে একটি _অ্যানোনিমাস ফাংশন_ তৈরি করা যায়।

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
