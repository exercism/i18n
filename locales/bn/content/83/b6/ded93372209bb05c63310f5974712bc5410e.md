# নির্দেশনার সংযোজন

## ওয়ার্ড

রোস্টার ধরে রাখতে একটি `school` টিউপল ডিফাইন করুন (এর ভেতরে শিক্ষার্থীদের কীভাবে রাখবেন, সেটি সম্পূর্ণ আপনার উপর নির্ভর করে), তারপর নিচের ওয়ার্ডগুলো ইমপ্লিমেন্ট করুন।

- `<school> ( -- school )`: একটি খালি school তৈরি করে।
- `add-student ( school name grade -- ? )`: `grade`-এ `name` যোগ করে। সফল হলে `t` রিটার্ন করে, আর `name` আগেই যোগ করা থাকলে (এই গ্রেডে বা অন্য যেকোনো গ্রেডে) `f` রিটার্ন করে; সেক্ষেত্রে রোস্টার অপরিবর্তিত থাকে।
- `roster ( school -- names )`: গ্রেড অনুযায়ী, তারপর নামের বর্ণানুক্রমে সাজানো সব শিক্ষার্থী।
- `grade ( school n -- names )`: গ্রেড `n`-এর শিক্ষার্থীরা, নামের বর্ণানুক্রমে সাজানো।
