# সম্পর্কে

[সিম্বলগুলো][symbols] হলো নামযুক্ত আইডেন্টিফায়ার, যা কোনো মান নির্দেশ করতে ব্যবহার করা যায়।
সিম্বল তৈরি হয় সিম্বল লিটারালের মাধ্যমে, অর্থাৎ একটি নামের আগে `:` ক্যারেক্টার বসিয়ে, যেমন `:foo`.
কোটেশন মার্ক দিয়েও এগুলো লেখা যায়, যেমন `:"foo"`, যার ফলে নামের মধ্যে স্পেসও ব্যবহার করা যায়।

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

ভাষাটির অনেক জায়গায় সিম্বল ব্যবহৃত হয়, যেমন হ্যাশে কী (key) হিসেবে, কিংবা মেথডের নাম ও ভ্যারিয়েবলের নাম প্রকাশ করতে।

## আইডেন্টিফায়ার

স্ট্রিং থেকে সিম্বলের পার্থক্য হলো, সিম্বল আসলে আইডেন্টিফায়ার, এরা কোনো ডেটা বা টেক্সট প্রকাশ করে না।
এর মানে হলো, একই নামের দুটি সিম্বল সবসময় একই অবজেক্ট।

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## সিম্বল পরিবর্তন

সিম্বল ইমিউটেবল, অর্থাৎ এগুলো পরিবর্তন করা যায় না।
এর মানে হলো, আপনি যখন কোনো সিম্বল "পরিবর্তন" করেন, তখন আসলে একটি নতুন সিম্বল তৈরি হয়।
সিম্বল নিয়ে কাজ করার জন্য কয়েকটি মেথড আছে, এগুলোর সবগুলোই নতুন সিম্বল রিটার্ন করে।
সব মেথড [Symbol API][symbols-api]-তে পাওয়া যাবে।

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

সিম্বলের ইমিউটেবল হওয়ার সুবিধা হলো, এগুলো স্ট্রিংয়ের চেয়ে মেমোরিতে বেশি সাশ্রয়ী, আর আইডেন্টিফায়ার হিসেবে ব্যবহার করাও বেশি নিরাপদ।

## রূপান্তর

সিম্বলকে স্ট্রিংয়ে রূপান্তর করা যায়, আবার উল্টোটাও।
কোনো সিম্বল পরিবর্তন করতে চাইলে, কিংবা কোনো সিম্বলকে স্ট্রিং হিসেবে ব্যবহার করতে চাইলে এটি কাজে লাগতে পারে।
কোনো স্ট্রিংকে সিম্বল হিসেবে উপস্থাপন করতে `String#to_sym` মেথডটি ব্যবহার করতে পারেন, আর উল্টোটা করতে `Symbol#to_s` মেথডটি।
সিম্বলে সীমিত সংখ্যক মেথড থাকায়, নতুন একটি সিম্বল দরকার হলে সিম্বলটিকে স্ট্রিংয়ে রূপান্তর করে তার উপর স্ট্রিংয়ের মেথড ব্যবহার করা কাজে লাগতে পারে।

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
