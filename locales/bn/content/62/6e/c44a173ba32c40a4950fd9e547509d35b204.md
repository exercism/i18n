# নির্দেশাবলি

এই অনুশীলনীতে আপনি একজন বন্ধুর সাথে একটি সংখ্যা অনুমান করার গেম খেলছেন। নিয়মগুলো সহজ: আপনি গোপনে `1` থেকে `100`-এর মধ্যে একটি সংখ্যা বেছে নেন, আর আপনার বন্ধু আপনার বেছে নেওয়া সংখ্যাটি অনুমান করার চেষ্টা করে। বন্ধুকে সাহায্য করার জন্য, আপনি বেছে নেওয়া সংখ্যাটির (`42`) সাথে অনুমানটি কতটা কাছাকাছি ছিল তার উপর নির্ভর করে আপনি ভিন্নভাবে জবাব দেন। বিভিন্ন জবাবের নিয়মগুলো এই রকম:

- অনুমানটি `42` হলে: "Correct"
- অনুমানটি `41` বা `43` হলে: "So close"
- অনুমানটি `41`-এর কম হলে: "Too low"
- অনুমানটি `43`-এর বেশি হলে: "Too high"

অনুমানগুলোর জবাব তৈরি করতে আপনার সামনে চারটি কাজ রয়েছে।

## 1. সঠিক অনুমানের জবাব দিন

সঠিক অনুমানের জবাব দিতে `reply` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
reply 42
// => "Correct"
```

## 2. কাছাকাছি অনুমানের জবাব দিন

কাছাকাছি অনুমানের জবাব দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```fsharp
reply 41
// => "So close"
```

## 3. খুব কম অনুমানের জবাব দিন

খুব কম অনুমানের জবাব দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```fsharp
reply 25
// => "Too low"
```

## 4. খুব বেশি অনুমানের জবাব দিন

খুব বেশি অনুমানের জবাব দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```fsharp
reply 88
// => "Too high"
```
