# টেস্ট

## অনুশীলনীর ফাইল

ডাউনলোড করা একটি অনুশীলনীতে আপনার সমাধান তৈরি ও পরীক্ষা করার জন্য এই ফাইলগুলো থাকে:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

ফাইলের নামগুলো অনুশীলনীভেদে ভিন্ন হয়।
আপনার সমাধান লিখুন সেই `.vb` ফাইলে, যার নাম `Tests` দিয়ে শেষ হয় না।
`Tests.vb` দিয়ে শেষ হওয়া ফাইলটি হলো xUnit টেস্ট স্যুট; সাধারণত আপনি এটি কেবল `Skip` আর্গুমেন্টগুলো মুছে ফেলার জন্যই সম্পাদনা করবেন।
সাধারণত আপনার প্রজেক্ট বা লক ফাইল সম্পাদনার দরকার পড়ে না।

## টেস্ট চালান

অনুশীলনীর ডিরেক্টরিতে একটি টার্মিনাল খুলে চালান:

```bash
dotnet test
```

কমান্ডটি প্রজেক্টের ডিপেন্ডেন্সিগুলো রিস্টোর করে, প্রজেক্ট বিল্ড করে এবং এর টেস্টগুলো চালায়।
কোনো সোর্স ফাইল পরিবর্তন হলেই টেস্টগুলো আবার চালানোর জন্য আপনি `dotnet watch test`-ও ব্যবহার করতে পারেন।

## স্কিপ করা টেস্ট

অনুশীলনীগুলো শুরুতে কেবল প্রথম টেস্টটি চালু রাখে, যাতে আপনি বাকিগুলো এক ধাপ করে সমাধান করতে পারেন।
টেস্টগুলো খুঁজে পেতে `Tests.vb` দিয়ে শেষ হওয়া ফাইলটি খুলুন।
প্রতিটি টেস্ট হলো একটি `Sub` সাবরুটিন, যা একটি xUnit `<Fact>` অ্যাট্রিবিউট দিয়ে চিহ্নিত।
কোনো টেস্টের `<Fact>` অ্যাট্রিবিউটে যতক্ষণ একটি `Skip` আর্গুমেন্ট থাকে, ততক্ষণ সেটি স্কিপ হয়ে যাবে:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

টেস্টটি চালু করতে শুধু `Skip` আর্গুমেন্টটি সরিয়ে ফেলুন:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

নতুন করে চালু করা টেস্টটি পাস হওয়ার পর, পরের স্কিপ করা টেস্টটির জন্য এই প্রক্রিয়াটিই আবার করুন।
সব টেস্ট চালু হয়ে পাস হয়ে গেলে, আপনার কাজ শেষ।
