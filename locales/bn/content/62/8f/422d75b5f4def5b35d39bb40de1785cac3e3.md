# নির্দেশনা

এই অনুশীলনীতে, আপনি একজন ডেভেলপারকে আইডেন্টিফায়ার নাম পরিষ্কার করতে সাহায্য করার জন্য কিছু ইউটিলিটি রুটিনের একটি আংশিক সেট তৈরি করবেন।
৫টি কাজে আপনি ধীরে ধীরে `Clean` রুটিনটি গড়ে তুলবেন।
একটি বৈধ আইডেন্টিফায়ারে শূন্য বা তার বেশি অক্ষর ও আন্ডারস্কোর থাকে।
সব ক্ষেত্রেই ইনপুট স্ট্রিংটি নন-নাল হওয়া নিশ্চিত।
`Clean` ফাংশনে যদি একটি খালি স্ট্রিং পাস করা হয়, তাহলে একটি খালি স্ট্রিং রিটার্ন করা উচিত।
মনে রাখবেন, খালি আইডেন্টিফায়ার দিয়ে `Clean` রুটিনটি কল করা কলকারীর এড়িয়ে চলা উচিত, কারণ এমন আইডেন্টিফায়ার অকার্যকর।

## 1. যেকোনো স্পেসকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করুন

যেকোনো স্পেসকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করতে (_static_) `Identifier.Clean()` মেথডটি ইমপ্লিমেন্ট করুন।
এটি শুরুতে ও শেষে থাকা স্পেসের ক্ষেত্রেও প্রযোজ্য।

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. কন্ট্রোল ক্যারেক্টারকে বড় হাতের "CTRL" স্ট্রিং দিয়ে প্রতিস্থাপন করুন

কন্ট্রোল ক্যারেক্টারকে বড় হাতের `"CTRL"` স্ট্রিং দিয়ে প্রতিস্থাপন করতে (_static_) `Identifier.Clean()` মেথডটি পরিবর্তন করুন।

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. kebab-case-কে camelCase-এ রূপান্তর করুন

kebab-case-কে camelCase-এ রূপান্তর করতে (_static_) `Identifier.Clean()` মেথডটি পরিবর্তন করুন।

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. অক্ষর নয় এমন ক্যারেক্টার বাদ দিন

অক্ষর নয় এমন যেকোনো ক্যারেক্টার বাদ দিতে (_static_) `Identifier.Clean()` মেথডটি পরিবর্তন করুন।

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. গ্রিক ছোট হাতের অক্ষর বাদ দিন

'α' থেকে 'ω' রেঞ্জের যেকোনো গ্রিক অক্ষর বাদ দিতে (_static_) `Identifier.Clean()` মেথডটি পরিবর্তন করুন।

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
