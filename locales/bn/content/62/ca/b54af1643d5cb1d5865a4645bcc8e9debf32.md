# পরিচিতি

## With

[স্পেশাল ফর্ম with][with] এমন একটি উপায় দেয় যার সাহায্যে ব্যর্থ হতে পারে এমন একগুচ্ছ ধাপের "হ্যাপি পাথ"-এ মনোযোগ দেওয়া যায় এবং ব্যর্থতাগুলো পরে সামলানো যায়।

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

প্রতিটি ধাপে, কোনো ক্লজ মিলে গেলে, `do` ব্লকটি চালানো পর্যন্ত শৃঙ্খলটি চলতে থাকে। কোনো একটি মিল ব্যর্থ হলে শৃঙ্খলটি থেমে যায় এবং যে ক্লজটি মেলেনি সেটি রিটার্ন করা হয়। ব্যর্থ মিলগুলো ধরে ফেলতে এবং রিটার্ন ভ্যালু পরিবর্তন করতে আপনি `else` ব্লক ব্যবহার করার সুযোগ পেয়েছেন।
