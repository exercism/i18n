# পরিচিতি

## টেম্পোরাল অ্যাডজাস্টার

`LocalDate`-এর মতো `java.time` অবজেক্ট নিয়ে কাজ করার সময় প্রায়ই জটিল তারিখ সমন্বয় করতে হয়, যেমন "মাসের দ্বিতীয় মঙ্গলবার" খুঁজে বের করা।
এটি নিজ হাতে হিসাব না করে আপনি **`TemporalAdjusters`** ব্যবহার করতে পারেন।

`java.time.temporal.TemporalAdjusters` (শেষে 's' আছে, খেয়াল করুন) ইউটিলিটি ক্লাসটি অনেক কমন তারিখ সমন্বয়ের জন্য স্ট্যাটিক মেথড দেয়।
এই সমন্বয়গুলো আপনি একটি টেম্পোরাল অবজেক্টের (যেমন `LocalDate`) ওপর `.with()` মেথড দিয়ে প্রয়োগ করেন।

```exercism/note
`with(TemporalAdjuster)` ব্যবহার করলে একটি _নতুন_ ইনস্ট্যান্স রিটার্ন হয়, বিদ্যমান ইনস্ট্যান্সটি আপডেট হয় না, কারণ `java.time` অবজেক্টগুলো ইমিউটেবল।
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

সময়সূচির হিসাবে কাজে লাগে এমন কয়েকটি গুরুত্বপূর্ণ অ্যাডজাস্টার এখানে দেখুন:

### সপ্তাহের নির্দিষ্ট ক্রমিক বার খুঁজে বের করা

সপ্তাহের কোনো একটি বারের n-তম পুনরাবৃত্তি খুঁজতে `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` ব্যবহার করুন।

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### মাসে সপ্তাহের প্রথম/শেষ বার খুঁজে বের করা

`firstInMonth(DayOfWeek dayOfWeek)` অথবা `lastInMonth(DayOfWeek dayOfWeek)` ব্যবহার করুন।

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### আপেক্ষিক সমন্বয় (পরের/আগের)

`next()`, `previous()`, `nextOrSame()` আর `previousOrSame()`-এর মতো অ্যাডজাস্টার চলতি তারিখের সাপেক্ষে সপ্তাহের একটি নির্দিষ্ট বারের পরের বা আগের পুনরাবৃত্তি খুঁজে দেয়।

- `next()`/`previous()`: চলতি তারিখটি মিলে গেলেও সেটি বাদ দেয়।
- `nextOrSame()`/`previousOrSame()`: চলতি তারিখটি মিলে গেলে সেটিকেও ধরে নেয়।

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### নিজের মতো অ্যাডজাস্টার

`TemporalAdjuster` একটি ফাংশনাল ইন্টারফেস, তাই আপনি ল্যাম্বডা দিয়ে নিজের অ্যাডজাস্টার লিখতে পারেন, যা সমন্বয় করার জন্য টেম্পোরালটি নেয় আর সমন্বয় করা টেম্পোরালটি রিটার্ন করে।
এটি আগে থেকে দেওয়া অ্যাডজাস্টারগুলোর মতোই `.with()` দিয়ে প্রয়োগ করা হয়, আর ভেতরে ওগুলোও ব্যবহার করতে পারে।

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

`TemporalAdjusters` ক্লাসের এই অ্যাডজাস্টারগুলো ব্যবহার করলে তারিখ নিয়ে কাজ অনেক সহজ হয়ে যায়।
