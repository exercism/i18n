# প্লেসহোল্ডার

## List অপারেশন ইমপ্লিমেন্ট করা

এই অনুশীলনীর লক্ষ্য হলো List-এর কিছু মেথড নিজে নিজে ইমপ্লিমেন্ট করা।
ডেটা ধরে রাখার জন্য পেছনে একটি List অবজেক্ট ব্যবহার করা স্বাভাবিক।
তবে List-এর মেথডগুলো (যেমন `where`, `map` ইত্যাদি) ব্যবহার করা থেকে হাত দূরে রাখুন।

কিছু "প্রাথমিক" List অপারেশন আছে যেগুলো এড়ানো সম্ভব নয়, যেমন:

* স্লাইসিং: `list[from..to]`
* যোগ করা: `list.add(item)`

## ইটারেটর প্রোটোকল

যে List অপারেশনগুলো ইমপ্লিমেন্ট করতে হবে, সেগুলো সবই নানা রকমে ইটারেট করার সাথে সম্পর্কিত।
[ইটারেটর প্রোটোকল][iter] সম্পর্কে পড়ুন।
তাহলে আপনি এটা করতে পারবেন:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
