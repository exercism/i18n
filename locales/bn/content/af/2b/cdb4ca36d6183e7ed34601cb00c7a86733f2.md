# ভূমিকা

Gleam-এ অপ্যাক টাইপ হলো এমন কাস্টম টাইপ, যেখানে কেবল যে মডিউলটি টাইপটি ডিফাইন করে সেটিই ওই টাইপের মান তৈরি করতে বা প্যাটার্ন ম্যাচ করতে পারে। কেবল একটি নির্দিষ্ট উপায়ে ব্যবহার করা উচিত, এমন টাইপ তৈরির জন্য এটি কাজে লাগে।

অপ্যাক টাইপ ডিফাইন করা হয় `opaque` কিওয়ার্ড দিয়ে।

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

এই `PositiveInt` টাইপটি এমন পরিস্থিতিতে ব্যবহারের জন্য যেখানে একটি ইন্টিজার প্রয়োজন, তবে সেটি শূন্য বা তার বেশি হতে হবে। সাধারণ Gleam `Int` এখানে ব্যবহার করা যেত না, কারণ সেগুলো ঋণাত্মকও হতে পারে।

যে মডিউলটি এই টাইপটি ডিফাইন করে, সেটি ভেতরের ইন্টিজার মানটি পাওয়ার জন্য একটি ফাংশন ডিফাইন করতে পারে, আর `PositiveInt` টাইপটি তৈরির জন্য আরেকটি ফাংশনও, যা মানটি ধনাত্মক না হলে একটি এরর রিটার্ন করবে।

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

এই API-এর মাধ্যমে অন্য মডিউলগুলো ঋণাত্মক মান দিয়ে একটি `PositiveInt` তৈরি করতে পারে না, তাই `PositiveInt` নেয় এমন যেকোনো ফাংশন নিশ্চিত থাকতে পারে যে মানটি ধনাত্মক।
