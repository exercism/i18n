# পরিচিতি

ক্যারেক্টার ক্লাস আর কোয়ান্টিফায়ারের বাইরেও রেগুলার এক্সপ্রেশন টেক্সটের *গঠন* ও *প্রসঙ্গ* বর্ণনা করতে পারে। এই বৈশিষ্ট্যগুলো একই [`regexp`][regexp] ভোকাবুলারিতেই থাকে, লেখা হয় `R/ /` লিটারাল দিয়ে।

## গ্রুপিং ও অল্টারনেশন

গোল বন্ধনী `( )` প্যাটার্নের একটি অংশকে গ্রুপ করে, যাতে একটি কোয়ান্টিফায়ার বা একটি `|` ("এটা বা ওটা") পুরো গ্রুপটির উপর কাজ করে। গ্রুপের পরে `?` বসালে সেটি ঐচ্ছিক হয়ে যায়:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## অ্যাঙ্কর

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

একটি *ওয়ার্ড বাউন্ডারি* (`\b`) হলো সেই জায়গা, যেখানে একটি ওয়ার্ড ক্যারেক্টার (একটি অক্ষর, ডিজিট বা আন্ডারস্কোর) একটি নন-ওয়ার্ড ক্যারেক্টারের সাথে মেলে, স্ট্রিংয়ের দুই প্রান্তসহ। তাই `\bcat\b` শুধু তখনই `cat`-এর সাথে মেলে, যখন সেটি একা দাঁড়িয়ে থাকে:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## লুকঅ্যারাউন্ড

একটি *লুকঅ্যারাউন্ড* কোনো একটি জায়গার ঠিক আগে বা পরে কী আছে তা যাচাই করে, কিন্তু সেই ক্যারেক্টারগুলোকে ম্যাচের অংশ বানায় না। এটি জিরো-উইথ:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## অপশন

ক্লোজিং `/`-এর পরে একটি অপশন অক্ষর পুরো প্যাটার্নটি বদলে দেয়। `i` মানে কেস-ইনসেনসিটিভ:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## প্রতিটি ম্যাচ রূপান্তর করা

`map-matches` প্রতিটি ম্যাচের উপর একটি কোয়েশন চালায় এবং ফলাফলগুলো সংগ্রহ করে; `each-match` শুধু সাইড ইফেক্টের জন্য একই কাজ করে। দুটোই কোয়েশনকে ম্যাচের `start` ইনডেক্স, `end` ইনডেক্স এবং পুরো স্ট্রিং দিয়ে দেয়, তাই `subseq` ম্যাচ হওয়া টেক্সটটি ফিরে পায়:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Factor যেসব সমর্থন করে না

Factor-এর regexp ইঞ্জিনে **ক্যাপচার-গ্রুপ এক্সট্র্যাকশন** নেই (একটি `( )` গ্রুপ প্যাটার্নটি সাজায়, কিন্তু সেটি যে টেক্সটের সাথে মিলেছে তা ফিরে পড়া যায় না), **ব্যাক-রেফারেন্স** (`\1`) নেই, আর **লেজি/নন-গ্রিডি** কোয়ান্টিফায়ার (`*?`, `+?`) নেই। ক্যাপচার গ্রুপের স্বাভাবিক বিকল্প হলো লুকঅ্যারাউন্ড: যে অংশটি চান সেটি ম্যাচ করুন, চারপাশের প্রসঙ্গ দিয়ে চিনে নিন।
