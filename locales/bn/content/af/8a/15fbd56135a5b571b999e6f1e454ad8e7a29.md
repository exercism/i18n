# ভূমিকা

এই অনুশীলনীতে Ruby-এর মৌলিক গঠন উপাদানগুলো শেখানো হবে।
এতে অনেকগুলো বিষয় আছে, তবে প্রথমে কঠিন মনে হলেও চিন্তার কিছু নেই, ট্র্যাকটি যত এগোবে আমরা সবকিছু আরও অনেক গভীরে গিয়ে দেখব।

Ruby সম্পর্কে বোঝার জন্য সবচেয়ে গুরুত্বপূর্ণ একটি বিষয় হলো এটি একটি [অবজেক্ট-ওরিয়েন্টেড ভাষা][object-oriented-programming], আর **Ruby-তে সবকিছুই একটি [অবজেক্ট][object]**। সংখ্যা, স্ট্রিং, অ্যারে, সবই অবজেক্ট।

## ভ্যারিয়েবল ও কনস্ট্যান্ট

আমরা সাধারণত অবজেক্টকে নাম দিয়ে ব্যবহার করি, সেটা ভ্যারিয়েবল হোক বা কনস্ট্যান্ট।

ভ্যারিয়েবল সবসময় [স্নেক কেসে][snake-case] লেখা হয়।
একটি ভ্যারিয়েবল তার পুরো জীবনকালে বিভিন্ন অবজেক্টকে নির্দেশ করতে পারে।
যেমন, `=` অপারেটর দিয়ে `my_first_variable` অনেকবার ডিফাইন ও আবার ডিফাইন করা যায়:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

কনস্ট্যান্ট অবশ্য একবারই অ্যাসাইন করার জন্য।
এগুলো অবশ্যই বড় হাতের অক্ষর দিয়ে শুরু হতে হবে এবং সাধারণত সব বড় হাতের অক্ষরে লেখা হয়, শব্দগুলো আন্ডারস্কোর দিয়ে আলাদা করা থাকে।
যেমন:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## ক্লাস

Ruby ক্লাসে সাজানো।
ক্লাস ডিফাইন করা হয় `class` কিওয়ার্ড দিয়ে, তার পরে ক্লাসের নাম লেখা হয়।
অবজেক্ট সাধারণত `.new` মেথড দিয়ে ক্লাস ইনস্ট্যান্টিয়েট করে তৈরি করা হয়।
যেমন:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## মেথড

কার্যকারিতার এককগুলো মেথডে আবদ্ধ থাকে, অনেকটা অন্য ভাষার _ফাংশন_-এর মতো।

একটি মেথড পজিশনাল আর্গুমেন্ট বা কিওয়ার্ড আর্গুমেন্ট (যেগুলো `:` সিনট্যাক্স দিয়ে ডিফাইন ও কল করা হয়) দিয়ে ডিফাইন করা যায়, আবার একেবারেই কোনো আর্গুমেন্ট নাও থাকতে পারে।

মেথড হয় সর্বশেষ মূল্যায়িত স্টেটমেন্টের ফলাফল অন্তর্নিহিতভাবে রিটার্ন করে, নয়তো `return` কিওয়ার্ড দিয়ে স্পষ্টভাবে একটি অবজেক্ট রিটার্ন করতে পারে।

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

মেথড `.` সিনট্যাক্স দিয়ে কল করা হয়:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
