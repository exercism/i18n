# পরিচিতি

এটি একটি _বিশাল_ বিষয়!
এটি নিয়ে একটি দীর্ঘ বই লেখা সম্ভব, এবং অনেকে তা করেছেনই (কিছু উদাহরণ দেখতে Amazon-এ "unicode book" খুঁজে দেখুন)।

## একটি খুবই সংক্ষিপ্ত ইতিহাস

কম্পিউটারে ক্যারেক্টার নিয়ে কাজ করা আগের দশকগুলোতে অনেক সহজ ছিল, যখন প্রোগ্রামাররা ধরে নিতেন ইংরেজিই একমাত্র গুরুত্বপূর্ণ ভাষা।
অর্থাৎ: ২৬টি অক্ষর, ছোট ও বড় হাতের অক্ষর, ১০টি সংখ্যা, কয়েকটি যতিচিহ্ন, সঙ্গে ঘণ্টা বাজানোর একটি কোড (0x07), আর সব মিলিয়ে ৭ বিটে ধরে যেত: ASCII ক্যারেক্টার সেট।

স্বাভাবিকভাবেই, মানুষ প্রশ্ন করতে শুরু করল à, ä আর Ł নিয়ে, তারপর অন্যরা প্রশ্ন করতে শুরু করল ऄ, ஹ আর ญ নিয়ে, আর তরুণরা চাইল ইমোজি 😱।
কী করা যায়?

সংক্ষেপে বলতে গেলে, অনেক বুদ্ধিমান ও ধৈর্যশীল মানুষকে বছরের পর বছর কমিটিতে কাজ করতে হয়েছে, Unicode ক্যারেক্টার সেট আর UTF-8-এর মতো এনকোডিংয়ের খুঁটিনাটি ঠিক করতে, আর অনেক সফটওয়্যারকে _অত্যন্ত_ জটিলভাবে নতুন করে লিখতে হয়েছে।
এছাড়া অনেক নতুন বাগও তৈরি হয়েছিল।

_সবকিছু_ ভেঙে না পড়ার জন্য, Unicode/UTF-8 নকশা নিশ্চিত করে যে প্রথম ১২৭টি কোড ASCII-এর সঙ্গে অভিন্ন _(এমনকি ঘণ্টাটিও)_।

## Julia-তে ক্যারেক্টার

২০০৫ সালের পরে ডিজাইন করা ভাষাগুলোর বড় সুবিধা হলো, তখন একটি মোটামুটি স্থিতিশীল Unicode স্ট্যান্ডার্ড আগেই তৈরি হয়ে গিয়েছিল।

Julia (প্রথম প্রকাশ ২০১২ সালে) ধরে নিতে পেরেছিল সবকিছুই Unicode হবে: ক্যারেক্টার, স্ট্রিং, ভ্যারিয়েবল আর ফাংশনের নাম, গাণিতিক অপারেটর...

ম্যানুয়াল থেকে উদ্ধৃত করতে গেলে, "Julia সাধারণ ASCII টেক্সট নিয়ে কাজ করাকে সহজ ও দক্ষ করে তোলে, আর Unicode নিয়ে কাজ করা যতটা সম্ভব সহজ ও দক্ষ করে।"
"যতটা সম্ভব" অংশটি খেয়াল করুন, এটি এই বক্তব্যের একটি গুরুত্বপূর্ণ অংশ।

***ক্যারেক্টার লিটারাল একক উদ্ধৃতি চিহ্নে (single-quotes) লেখা হয়, আর এটি দ্বৈত উদ্ধৃতি চিহ্নে লেখা স্ট্রিং থেকে আলাদা।***

C/C++ জগতের মানুষদের কাছে এটি স্পষ্ট, কিন্তু Python আর Javascript প্রোগ্রামারদের কাছে বিভ্রান্তিকর হতে পারে।

```julia-repl
julia> a = 'a'  # Roman alphabet
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> typeof(a)
Char

julia> jha = 'झ'  # Devanagari alphabet
'झ': Unicode U+091D (category Lo: Letter, other)

julia> typeof(jha)
Char

julia> '❤'  # heart emoji
'❤': Unicode U+2764 (category So: Symbol, other)
```

উদাহরণগুলো থেকে দেখা যায় টাইপটি `Char`, আর Julia-র কাছে ক্যারেক্টারের ক্যাটাগরি সম্পর্কে আরও তথ্য থাকে।

একটু খেয়াল করলে দেখা যায়, এই ক্যারেক্টারগুলো ৪টি হেক্সাডেসিমাল ডিজিট দিয়ে প্রকাশ করা যায়।
সম্পূর্ণ ক্যারেক্টার সেটের জন্য সর্বোচ্চ ৬টি হেক্স ডিজিট প্রয়োজন।

এই সংখ্যাগুলোকে "কোড পয়েন্ট" বলা হয়, যা বর্তমানে U+0000 থেকে U+10FFFF পর্যন্ত বিস্তৃত।
এগুলো REPL-এ দেখানো হয়, কিন্তু কোডের ভেতরে কোড পয়েন্ট পেতে `codepoints()` ব্যবহার করুন।

`Char` আর `Int`-এর মধ্যে রূপান্তর করা সহজ:

```julia-repl
julia> Int('a')
97

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

কম্পাইলার `Char`-এর উপর _কিছু_ ধরনের ইন্টিজার গাণিতিক কাজের অনুমতি দেয়:

```julia-repl
julia> 'b' - 'a'  # interval, in alphabetic order
1

julia> 'b' + 'a'
ERROR: MethodError: no method matching +(::Char, ::Char)

julia> 'a' + 5
'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> 'f' + ('A' - 'a')  # same as `uppercase('f')`
'F': ASCII/Unicode U+0046 (category Lu: Letter, uppercase)
```

## ক্যারেক্টারের জন্য ফাংশন

অনেক স্ট্রিং-হ্যান্ডলিং ফাংশন `Char` ইনপুট নিয়েও কাজ করতে পারে।

- উপযুক্ত বর্ণমালার ক্ষেত্রে `uppercase()` আর `lowercase()` দিয়ে কেস পরিবর্তন করুন।
- `isuppercase()` আর `islowercase()` দিয়ে কেস পরীক্ষা করুন।
- ক্যারেক্টারের ধরন পরীক্ষা করুন এগুলো দিয়ে:
  - `isletter()` অনেক বর্ণমালা কভার করে
  - `isdigit()`, কঠোরভাবে 0:9 পরীক্ষা করে
  - `isnumeric()`, `isdigit`-এর চেয়ে ব্যাপক, তাই ¾ আর নানা অ-ইউরোপীয় লিপির জন্য `true` দেয়
  - `isxdigit()`, হেক্সাডেসিমাল ডিজিট
  - `isascii()`, প্রাক-Unicode ক্যারেক্টার
  - `ispunct()`, যতিচিহ্ন
  - `isspace()`, যেকোনো হোয়াইটস্পেস ক্যারেক্টার
  - `isprint()`, মুদ্রণযোগ্য ক্যারেক্টার (এর বিপরীতটি `iscntrl()`)

```julia
islowercase('A')  # false
uppercase('γ')  # 'Γ': Unicode U+0393 (category Lu: Letter, uppercase)
ispunct('@')  # true
isdigit('A')  # false
isxdigit('A')  # true
```

## Char Vector আর String-এর আন্তঃরূপান্তর

String থেকে Char Vector-এ যেতে আমরা `collect()` ব্যবহার করতে পারি।

Char Vector থেকে String-এ যেতে আছে `String()` কনস্ট্রাক্টর।

```julia-repl
julia> s = "abcde"
"abcde"

julia> cv = collect(s)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)

julia> String(cv)
"abcde"
```

এটি যেকোনো ক্যারেক্টারের সঙ্গে কাজ করে, শুধু ASCII নয়।

```julia-repl
julia> collect("❤,😱")
3-element Vector{Char}:
 '❤': Unicode U+2764 (category So: Symbol, other)
 ',': ASCII/Unicode U+002C (category Po: Punctuation, other)
 '😱': Unicode U+1F631 (category So: Symbol, other)
```

মনে রাখবেন, `String()` কনস্ট্রাক্টর একটি Vector-এর উপর কাজ করে।
একটি একক `Char`-কে ১-ক্যারেক্টারের স্ট্রিং-এ _কাস্ট_ করতে ফাংশনটি হলো `string()`, ছোট হাতের `s` দিয়ে।

```julia-repl
julia> string('a')
"a"
```

## স্টোরেজ

এতদূর পর্যন্ত এই ডকুমেন্টের সবকিছু মোটামুটি সহজ মনে হচ্ছে, তাহলে কি সত্যিই চিন্তার তেমন কিছু নেই?

দুর্ভাগ্যবশত, এটি বড় বেশি আশাবাদী!

একটি জটিলতা আসে প্রতি কোড পয়েন্টে "সর্বোচ্চ" ৬টি হেক্স ডিজিটের প্রয়োজন থেকে।
এর মানে হলো, UTF-8 এনকোড করা হলে বিভিন্ন ক্যারেক্টারের জন্য মেমোরিতে বিভিন্ন পরিমাণ জায়গা লাগে।

একটি বাইট শুধু ২৫৫ পর্যন্ত (unsigned) সংখ্যা ধরে রাখতে পারে, অর্থাৎ দুটি হেক্স ডিজিট, তাই UTF-8 একটি `Char` সংরক্ষণে পরিবর্তনশীল সংখ্যক বাইট (১ থেকে ৪) ব্যবহার করে।
এগুলোকে "কোড ইউনিট" বলা হয়, আর `ncodeunits()` ফাংশন একটি নির্দিষ্ট ক্যারেক্টারের জন্য প্রয়োজনীয় সংখ্যাটি ফিরিয়ে দেবে।

```julia-repl
julia> codepoint(jha)  # jha 'झ' is defined in an earlier example
0x0000091d

julia> ncodeunits(jha)
3

julia> ncodeunits('a')  # ASCII character
1

julia> ncodeunits('😱')  # emoji
4
```

এছাড়াও, স্ক্রিনে যা দেখানো যায় তার প্রত্যেকটির নিজস্ব অনন্য কোড পয়েন্ট থাকে না।
কিছু দৃষ্টিগতভাবে পৃথক ক্যারেক্টারকে অন্যগুলো থেকে উদ্ভূত বলে ধরা হয়, তাই Unicode এগুলোকে একটি মূল (parent) ক্যারেক্টার প্লাস একটি মডিফায়ার হিসেবে দেখে।
