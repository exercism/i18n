# নির্দেশনার সংযোজন

## এক্সেপশন মেসেজ

কখনও কখনও [একটি এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটি করার সময়, এররটির উৎস কী তা বোঝাতে আপনার সবসময় একটি **অর্থবহ এরর মেসেজ** যোগ করা উচিত। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিংয়ে অনেক সাহায্য করে। এমন পরিস্থিতিতে, যেখানে আপনি জানেন যে এররটির উৎস একটি নির্দিষ্ট টাইপ হবে, আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) যেকোনো একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যোগ করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে ভিন্ন ইনপুট ও আউটপুট বেসের জন্য একটি `ValueError` "throw" করতে [রেইজ স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করতে বলা হয়েছে। আপনি যদি `exception`-টি `raise` করে তার সঙ্গে একটি অর্থবহ মেসেজও দেন, তবেই টেস্টগুলো পাস করবে।

একটি মেসেজ-সহ `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
