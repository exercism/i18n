# সম্পর্কে

`Time` মডিউলটি মানুষের পড়ার উপযোগী তারিখ / সময় দেখানোর জন্য ব্যবহৃত হয়।
কারিগরি দিক থেকে `Time` দিয়ে সময় নিয়ে কাজ করা সম্ভব হলেও, এই কাজের জন্য Elm কমিউনিটির এমন কিছু প্যাকেজ আছে যেগুলো অনেক বেশি উপযুক্ত, যেমন [`justinmimbs/date`][date] বা [`CoderDennis/elm-time-format`][elm-time-format]।

## Posix

সময় প্রকাশ করা হয় `Posix` ওপাক টাইপ দিয়ে, যা ইউনিক্স এপক টাইম ধারণ করে, অর্থাৎ ১৯৭০ সালের ১ জানুয়ারি UTC মাঝরাত থেকে অতিক্রান্ত মিলিসেকেন্ডের সংখ্যা।
একটি `Posix` হলো একটি দ্ব্যর্থতাহীন মান, যা টাইম জোনভেদে বদলায় না, তাই সময় ধরে রাখার জন্য এটি ভালো একটি পছন্দ।
একটি Elm অ্যাপ্লিকেশনে `Posix` সময় সাধারণত ব্রাউজারের মতো বাইরের উৎস থেকে সরবরাহ করা হয়।

নিচের ফাংশনগুলো দিয়ে একটি `Posix`-কে মিলিসেকেন্ডের সংখ্যায়, এবং এর উল্টোটাও রূপান্তর করা সম্ভব:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## টাইম জোন

আমাদের দৈনন্দিন জীবনে আমরা মানুষ সাধারণত `Posix` পড়ি না, বরং স্থানীয় সময় পছন্দ করি, যা পৃথিবীতে আমাদের অবস্থান এবং স্থানীয় ডেলাইট-সেভিং নিয়মের ওপর নির্ভর করে।
Elm-এ এই তথ্য `Zone` ওপাক টাইপে এনকোড করা থাকে, যা সাধারণত ব্রাউজার সরবরাহ করে।

এমন একটি বিশেষ `Zone` আছে যা সবসময় ব্যবহার করা যায়:

```elm
utc : Zone
```

## মানুষের পড়ার উপযোগী সময়

একটি `Posix` আর একটি `Zone` থাকলে যেকোনো স্তরের বিস্তারিতে স্থানীয় সময় দেখানোর জন্য আমাদের কাছে যথেষ্ট তথ্য থাকে।
এটি করার জন্য যেসব ফাংশন ব্যবহার করা যায়, তার একটি তালিকা এখানে:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

আপনি নিশ্চয়ই আরও দুটি `Time` কাস্টম টাইপ লক্ষ্য করেছেন:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

এই কাস্টম টাইপগুলোকে মানুষের পড়ার উপযোগী মানে রূপান্তর করার দায়িত্ব ব্যবহারকারীদের ওপর ছেড়ে দেওয়া হয়েছে।
