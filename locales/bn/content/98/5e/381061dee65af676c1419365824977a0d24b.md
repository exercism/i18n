# নির্দেশাবলি

এই অনুশীলনীতে আপনি নিউ ইয়র্কের একটি বিউটি সেলুনের জন্য অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন, যেটি ২০১২ সালের ১৫ই সেপ্টেম্বর চালু হয়েছিল।

## 1. অ্যাপয়েন্টমেন্টের তারিখ পার্স করুন

একটি অ্যাপয়েন্টমেন্ট তারিখের টেক্সট উপস্থাপনাকে সংশ্লিষ্ট `LocalDateTime`-এ পার্স করার জন্য `AppointmentScheduler.schedule()` মেথডটি ইমপ্লিমেন্ট করুন:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. অ্যাপয়েন্টমেন্ট আগেই পেরিয়ে গেছে কি না পরীক্ষা করুন

`AppointmentScheduler.hasPassed()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্ট তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি অতীতে কোনো এক সময়ে ছিল কি না তা পরীক্ষা করে:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. অ্যাপয়েন্টমেন্টটি বিকেলে কি না পরীক্ষা করুন

`AppointmentScheduler.isAfternoonAppointment()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্ট তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি বিকেলে (>= 12:00 এবং < 18:00) কি না তা পরীক্ষা করে:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. অ্যাপয়েন্টমেন্টের সময় ও তারিখ বর্ণনা করুন

`AppointmentScheduler.getDescription()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্ট তারিখ নেয় এবং সেই তারিখ ও সময়ের একটি বর্ণনা রিটার্ন করে:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. বার্ষিকীর তারিখ রিটার্ন করুন

`AppointmentScheduler.getAnniversaryDate()` মেথডটি ইমপ্লিমেন্ট করুন, যা এই বছরের বার্ষিকীর তারিখ রিটার্ন করে, যা ১৫ই সেপ্টেম্বর:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
