# নির্দেশাবলি

এমন একটি ফাংশন বাস্তবায়ন করুন যা `a, b, and c` সংখ্যাগুলো নেয়, যেগুলো ax^2 + bx + c আকারের একটি বহুপদী বর্ণনা করে। সম্ভব হলে বহুপদীটির বাস্তব মূল নির্ণয় করুন এবং সেগুলো একটি টিউপল হিসেবে রিটার্ন করুন। মূল হলো সেই সংখ্যাগুলো, যেগুলো বসালে বহুপদী এক্সপ্রেশনটির মান 0 হয়। r1 ও r2 নির্ণয় করতে দ্বিঘাত সূত্র ব্যবহার করবেন না। এক্সপ্রেশনটির বাস্তব মূল না থাকলে `None` রিটার্ন করুন।
