# নির্দেশনার সংযোজন

## ওয়ার্ড

একটি `custom-set` টুপল ডিফাইন করুন এবং `INSTANCE: custom-set set` দিয়ে এটিকে `set` মিক্সিনের একটি ইনস্ট্যান্স হিসেবে ডিক্লেয়ার করুন।

- `<custom-set> ( -- set )` একটি খালি সেট তৈরি করে।
- `>custom-set ( seq -- set )` একটি সিকোয়েন্স থেকে সেট তৈরি করে, ডুপ্লিকেটগুলো নীরবে বাদ দিয়ে।

এরপর `custom-set`-এর জন্য `members`, `in?`, `adjoin` এবং `set-like`-এ (`sets` থেকে) `M:` মেথডগুলো দিন। `INSTANCE:` ডিক্লেয়ারেশন আর ওই চারটি মেথড ঠিকঠাক থাকলে, `sets` ভোকাবুলারির `null?`, `union`, `intersect`, `diff`, `subset?`, `set=` এবং `intersects?` সবই প্রোটোকলের ডিফল্ট ইমপ্লিমেন্টেশনের মাধ্যমে আপনার সেটে কাজ করবে। টেস্টগুলো সরাসরি ওই ওয়ার্ডগুলোই কল করে।

`adjoin ( elt set -- )` মিউটেটিং: এটি আগে থেকে উপস্থিত না থাকলে `elt`-কে জায়গাতেই `set`-এ যোগ করে।
