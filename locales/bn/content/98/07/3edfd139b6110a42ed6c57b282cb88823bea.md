# পরিচিতি

হ্যাশ হলো Perl-এর একটি ডেটা টাইপ, যেটি স্ট্রিং কী (key) আর স্কেলার মানের জোড়ায় গঠিত একটি অবিন্যস্ত সংগ্রহ ধারণ করে।

সাধারণত হ্যাশ ভ্যারিয়েবলে একটি অ্যারে অ্যাসাইন করে তার মানগুলো ভরে দেওয়া হয়, যেমন `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`।

অ্যারের উপাদানগুলো সাধারণত কমা দিয়ে আলাদা করা হয়, তবে অ্যারের কী (key) আর মান আলাদা করতে আপনি প্রায়ই তথাকথিত "ফ্যাট কমা" `=>` দেখতে পাবেন। এর আচরণ কমার প্রায় হুবহু মতোই, তবে এর বাড়তি সুবিধা হলো এটি বাম দিকের এলিমেন্টটিকে স্ট্রিং হিসেবে ধরে নেয়।

আলাদা আলাদা কী (key)-তে অ্যাসাইন করেও হ্যাশ ভরে রাখা যায়, যেমন `$scores{Alice} = 10;`।

সাবস্ক্রিপ্টের মাধ্যমে কী (key) উল্লেখ করে হ্যাশের মান পড়া যায়, যেমন `$scores{Bob} # 15`।

হ্যাশের কী (key) গুলো অনন্য। কোনো কী (key) একাধিকবার দেওয়া হলে কেবল শেষ যে মানটি দেওয়া হয়েছে সেটিই রাখা হয়।

## ফাংশন

হ্যাশ নিয়ে কাজ করার ফাংশনের মধ্যে আছে [keys][keys] আর [values][values], যা দিয়ে হ্যাশের ওই অংশগুলো অ্যারে হিসেবে বের করা যায়। [keys][keys] আর [values][values] ফাংশন যে অ্যারে ফেরত দেয়, সেগুলো [grep][grep], [map][map] ও [sort][sort]-এর মতো অ্যারে নিয়ে কাজ করা ফাংশনে, আর [for][for] লুপেও কাজে লাগে।

আরও কিছু হ্যাশ ফাংশন হলো [exists][exists], যা দিয়ে হ্যাশে কোনো কী (key) আছে কি না তা দেখা যায় (তার মান `undef` হলেও), আর [delete][delete], যা দিয়ে হ্যাশ থেকে একটি কী (key) মুছে ফেলা যায়।

## সিগিলের ভিন্নতা

হ্যাশের মান বের করার সময় কোন সিগিল দিচ্ছেন সেটিই ফলাফল নির্ধারণ করে। ভ্যারিয়েবল নামের শেষে বসা সাবস্ক্রিপ্ট `{}` দিয়েই Perl বুঝতে পারে যে আপনি ওই নামের একটি হ্যাশ ব্যবহার করছেন।

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

এটি অনুমোদিত হলেও, পড়ার সুবিধার জন্য আলাদা ধরনের ভ্যারিয়েবলকে একই নাম দেওয়া না-ই সুপারিশ করা হয়।
