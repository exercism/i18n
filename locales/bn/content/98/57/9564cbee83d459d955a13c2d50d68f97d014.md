# ইঙ্গিত

## 1. অনুমোদনটি ডিফাইন করুন

- `pub type Name { Variant1 }` সিনট্যাক্স ব্যবহার করে কাস্টম টাইপ ডিফাইন করা যায়।

## 4. কার্যক্রমটি ডিফাইন করুন

- ডেটা ধারণ করা কাস্টম টাইপ `pub type Name { Variant1(SomeType) }` সিনট্যাক্স ব্যবহার করে ডিফাইন করা যায়।

## 5. কার্যক্রমের রেটিং দিন

- কেস এক্সপ্রেশন ব্যবহার করে কাস্টম টাইপের ভ্যারিয়েন্টগুলোর ওপর প্যাটার্ন ম্যাচ করা যায়।
- কোনো প্যাটার্নে অতিরিক্ত শর্ত যোগ করতে চাইলে, `if` কিওয়ার্ড ব্যবহার করে ওই প্যাটার্নে একটি গার্ড যোগ করা যায়।
