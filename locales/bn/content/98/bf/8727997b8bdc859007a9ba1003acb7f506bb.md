# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নেওয়ার জন্য কিছু কোড লিখবেন।

আপনার তিনটি কাজ আছে: একটি হলো আপনার লাইসেন্স দরকার কি না তা নির্ধারণ করা, একটি হলো দুটি যানবাহনের মধ্যে বাছাই করতে সাহায্য করা, আর একটি হলো ব্যবহৃত যানবাহনের জন্য গ্রহণযোগ্য দাম অনুমান করা।

## 1. আপনার ড্রাইভিং লাইসেন্স দরকার হবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালাতে ড্রাইভিং লাইসেন্স লাগে।
ধরে নিন শুধু `"car"` ও `"truck"` ধরনের যানবাহনের জন্য লাইসেন্স লাগে, বাকি সব লাইসেন্স ছাড়াই চালানো যায়।

`needsLicense(kind)` ফাংশনটি বাস্তবায়ন করুন, যা যানবাহনের ধরন নেয় এবং একটি বুলিয়ান রিটার্ন করে, যা বলে ওই ধরনের যানবাহনের জন্য আপনার লাইসেন্স দরকার কি না।

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. কেনার জন্য দুটি সম্ভাব্য যানবাহনের মধ্যে বাছাই করুন

আপনি হাতের কাছে থাকা যানবাহনগুলোর মধ্যে থেকে আপনার বিকল্পগুলো যাচাই করছেন।
শেষ পর্যন্ত আপনি দুটি অপশনে নামিয়ে এনেছেন, কিন্তু চূড়ান্ত সিদ্ধান্ত নিতে আপনার সাহায্য দরকার।
এর জন্য `chooseVehicle(option1, option2)` ফাংশনটি বাস্তবায়ন করুন, যা আর্গুমেন্ট হিসেবে দুটি যানবাহন নেয় এবং এমন একটি সিদ্ধান্ত রিটার্ন করে যাতে [আভিধানিক ক্রমে][lexicographical-order] আগে আসা অপশনটি থাকে।

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. ব্যবহৃত যানবাহনের দামের একটি আনুমানিক হিসাব করুন

এখন যেহেতু সিদ্ধান্ত হয়ে গেছে, আপনি নিশ্চিত হতে চান ডিলারশিপে আপনি ন্যায্য দামই পাচ্ছেন।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, তাই দাম নির্ভর করে যানবাহনটির বয়সের উপর।
মোটামুটি অনুমানের জন্য ধরে নিন, যানবাহনটির বয়স ৩ বছরের কম হলে এর দাম একেবারে নতুন অবস্থায় থাকা আসল দামের ৮০%।
আর বয়স অন্তত ১০ বছর হলে ৫০%।
আর যদি যানবাহনটির বয়স অন্তত ৩ বছর কিন্তু ১০ বছরের কম হয়, তবে এর দাম আসল দামের ৭০%।

`calculateResellPrice(originalPrice, age)` ফাংশনটি বাস্তবায়ন করুন, যা `if`, `else if` ও `else` ব্যবহার করে এই যুক্তি প্রয়োগ করে (চর্চা করতে চাইলে অন্য উপায়ও আছে)।
এটি আর্গুমেন্ট হিসেবে আসল দাম ও যানবাহনটির বয়স নেয় এবং ডিলারশিপে আনুমানিক দাম রিটার্ন করে।

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```
