# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | হেক্সাডেসিমাল ক্যারেক্টারের নাল-টার্মিনেটেড স্ট্রিং |
| `$v0`    | আউটপুট    | ইন্টিজার | ইনপুট স্ট্রিংয়ের দশমিক মান               |
| `$t0-9`  | অস্থায়ী | যেকোনো     | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত                  |
