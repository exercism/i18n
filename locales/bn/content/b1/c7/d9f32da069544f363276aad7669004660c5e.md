# ইঙ্গিত

## সাধারণ

- পড়া ও লেখার প্রতিটি শব্দ [`io.files`][io.files]-এ থাকে; এরা সবাই যে `utf8` এনকোডিং নেয়, সেটি আসে [`io.encodings.utf8`][utf8] থেকে।

## 1. প্রতিটি রিডিং পড়ুন

- `file-lines` নিউলাইন বাদ দিয়ে লাইনগুলোর একটি অ্যারে রিটার্ন করে।

## 2. সর্বশেষ রিডিংটি খুঁজুন

- `file-lines` দিয়ে লাইনগুলো পড়ুন, তারপর (`sequences` থেকে) `last`-টি নিন।

## 3. কাঁচা লগ পড়ুন

- `file-contents` ফাইলটিকে নিউলাইন-সহ একটি একক স্ট্রিং হিসেবে রিটার্ন করে।

## 4. একটি রিডিং রেকর্ড করুন

- অ্যাপেন্ড করার জন্য ফাইলটি খুলুন এবং কোয়োটেশনের ভিতরে রিডিংটি `print` করুন:
  `with-file-appender ( path encoding quot -- )`. রিডিংটি কোয়োটেশনের ভিতরে ব্যবহৃত হয়, আর path-টি তার আগেই খরচ হয়ে যায়, তাই `::` লোকাল দিয়ে body-টি পড়ার উপযোগী রাখা যায়:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. লগটি নতুন করে লিখুন

- `set-file-lines` একটি সিকোয়েন্সের প্রতিটি এলিমেন্টকে তার নিজের লাইনে লেখে, আর আপনার জন্য নিউলাইনগুলো যোগ করে দেয়।
