# ভূমিকা

বাইনারি ডেটা নিয়ে কাজ করা যেকোনো ভাষার জন্যই একটি গুরুত্বপূর্ণ ধারণা, আর Elixir বাইনারি ডেটা লেখা, মেলানো এবং তৈরি করার জন্য একটি সুন্দর সিনট্যাক্স দেয়।

Elixir-এ বাইনারি ডেটাকে বলা হয় বিটস্ট্রিং টাইপ। বাইনারি ডেটা _টাইপ_ (সাধারণ অর্থে বাইনারি ডেটার সঙ্গে গুলিয়ে ফেলা যাবে না) হলো বিটস্ট্রিংয়ের একটি নির্দিষ্ট রূপ, যা নিয়ে আমরা পরে একটি অনুশীলনীতে আলোচনা করব।

বিটস্ট্রিং লিটারেল তৈরি করা হয় বিটস্ট্রিং স্পেশাল ফর্ম `<<>>` ব্যবহার করে। বিটস্ট্রিং লিটারেল ডিফাইন করার সময় এটি সেগমেন্টে সেগমেন্টে ডিফাইন করা হয়। প্রতিটি সেগমেন্টের একটি মান ও একটি টাইপ থাকে, যা `::` অপারেটরের মাধ্যমে আলাদা করা হয়। টাইপটি নির্দেশ করে মানটি এনকোড করতে কত বিট ব্যবহার করা হবে। টাইপটি পুরোপুরি বাদও দেওয়া যায়, তখন ডিফল্ট হিসেবে ৮-বিটের ইন্টিজার মান ধরা হয়।

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

টাইপ `::1` হিসেবে লেখা হলো `::size(1)` লেখার সংক্ষিপ্ত রূপ। বিট সাইজ যদি কোনো ভ্যারিয়েবল থেকে আসে, তাহলে বড় সিনট্যাক্সটি ব্যবহার করতে হবে।

## বাইনারি

বাইনারি ইন্টিজার লিটারেল লেখার সময় লিটারেলের আগে `0b` বসিয়ে সরাসরি বেজ-২ নোটেশনে লেখা যায়। মনে রাখবেন, টেস্টের ফলাফলে বা iex ব্যবহার করার সময় এগুলো যেভাবেই হোক দশমিক সংখ্যা হিসেবেই দেখানো হয়।

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## ট্রাঙ্কেট করা

সেগমেন্টের মান যদি সেগমেন্টের টাইপের ধারণক্ষমতা ছাড়িয়ে যায়, তাহলে এটি বাম দিক থেকে ট্রাঙ্কেট হয়ে যাবে।

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## প্রিপেন্ড ও অ্যাপেন্ড করা

স্পেশাল ফর্ম ব্যবহার করে বিদ্যমান বিটস্ট্রিংয়ের শুরুতে ও শেষে দুটোই যোগ করা যায়। বিদ্যমান বিটস্ট্রিংয়ের সাইজ অজানা হলে তার জন্য `::bitstring` টাইপ ব্যবহার করতে হবে।

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## কনক্যাটিনেট করা

স্পেশাল ফর্ম ব্যবহার করে ভ্যারিয়েবলে রাখা বিটস্ট্রিংগুলো কনক্যাটিনেট করা যায়। অজানা সাইজের দুটি বিটস্ট্রিং কনক্যাটিনেট করার সময় `::bitstring` টাইপ ব্যবহার করতে হবে।

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## প্যাটার্ন ম্যাচিং

স্পেশাল ফর্ম থেকে মান বের করার জন্য প্যাটার্ন ম্যাচিংও করা যায়। যে অংশটি ধরতে চান তার জন্য কত বিট লাগবে তা জানতে হবে, তবে একটি ব্যতিক্রম আছে: অজানা সাইজের বিটস্ট্রিংয়ের ওপর প্যাটার্ন ম্যাচিং করতে `::bitstring` টাইপ ব্যবহার করা যায়, কিন্তু এটি কেবল শেষ অংশের জন্যই ব্যবহার করা যাবে।

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## বিটস্ট্রিং দেখা

~~~~exercism/note
বিটস্ট্রিং হয়তো (টেস্ট রানার বা iex-এ) যে ফরম্যাটে তৈরি করা হয়েছিল তার চেয়ে আলাদা ফরম্যাটে দেখানো হতে পারে। বিটস্ট্রিং শেখার সময় এতে অনেক সময় বিভ্রান্তি তৈরি হয়।
~~~~

ডিফল্টভাবে বিটস্ট্রিং ৮ বিটের (এক বাইট) অংশে দেখানো হয়, এমনকি আপনি যদি সেগুলো ভিন্ন সাইজের অংশে তৈরি করে থাকেন।

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

UTF-8 এনকোড করা কোনো প্রিন্টযোগ্য স্ট্রিং যে বিটস্ট্রিং প্রকাশ করে, সেটি স্ট্রিং হিসেবেই দেখানো হয়।

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
