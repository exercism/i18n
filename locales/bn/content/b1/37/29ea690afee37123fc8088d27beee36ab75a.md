# জেনেরিক ক্লাস

শুরুর দিক থেকেই আপনি `ARRAY{STR}`, `FMAP{STR,INT}` আর `FSET{STR}` ব্যবহার করে আসছেন। এই বন্ধনীগুলো সবসময়ই একটি টাইপ ধারণ করে এসেছে। এখন আপনি নিজেই এমন একটি ক্লাস লিখবেন, যার নিজস্ব বন্ধনী আছে।

## সমস্যাটি

হারানো জিনিসপত্রের অফিসের এমন একটি বাক্স দরকার, যাতে একটি জিনিস রাখা যায় এবং কে সেটি জমা দিয়েছে তা মনে রাখা যায়। একটি জাম্পার রাখার বাক্স:

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

তারপর একই ক্লাস আবার পানির বোতলের জন্য, আর আবার একটি ফোনের জন্য। তিনটি কপি, যাদের মাত্র একটি শব্দে পার্থক্য।

## টাইপ প্যারামিটার

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

ক্লাস নামের পরে `{T}` হলো একটি **টাইপ প্যারামিটার**। `T` কোনো টাইপ নয়, বরং ক্লাসটি ব্যবহারের সময় যে টাইপ দেওয়া হয় তার একটি প্রতিনিধি। ক্লাসের ভেতরে `T` ঠিক যেকোনো টাইপ নামের মতোই ব্যবহার করা হয়।

## এটি ব্যবহার করা

বন্ধনীর ভেতরে টাইপটি দিতে হয়:

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}` আর `LOST_BOX{INT}` দুটি আলাদা টাইপ। যেখানে একটির দরকার সেখানে অন্যটি বসানো একটি এরর, যা কম্পাইলার ধরে ফেলে; ঠিক যেন আপনি দুটি ক্লাস হাতে লিখেছেন। আর আসলে ঘটনাটাও তাই: Sather প্রকৃতপক্ষে ব্যবহৃত প্রতিটি টাইপের জন্য প্যাটার্ন থেকে একটি আলাদা ক্লাস তৈরি করে।

তাই রান টাইমে এর জন্য কোনো খরচ নেই, টাইপ সম্পর্কিত কোনো তথ্যও হারায় না: `jumper.item` সত্যিই একটি `STR`, এমন কিছু নয় যাকে যাচাই বা রূপান্তর করতে হয়।

## একটির বেশি

একটি ক্লাস একাধিক প্যারামিটার নিতে পারে, কমা দিয়ে আলাদা করা। `FMAP{K,T}` হলো এমন একটি উদাহরণ, যা আপনি ইতোমধ্যে জানেন।

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## নামকরণ

প্রচলিত রীতিতে একটিমাত্র বড় হাতের অক্ষর ব্যবহার করা হয়: `T` দিয়ে একটি জিনিস, `K` দিয়ে একটি কী (key), `E` দিয়ে একটি এলিমেন্ট বোঝানো হয়। লাইব্রেরিতে সর্বত্র এগুলোই ব্যবহৃত হয়।
