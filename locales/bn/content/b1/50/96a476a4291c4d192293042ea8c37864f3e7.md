# নির্দেশনা

এই অনুশীলনীতে আপনি একটি গাড়ি কারখানার অ্যাসেম্বলি লাইন বিশ্লেষণ করার কোড লিখবেন।

## 1. প্রতি ঘণ্টায় উৎপাদিত কর্মক্ষম গাড়ির সংখ্যা গণনা করুন

এমন একটি ফাংশন ইমপ্লিমেন্ট করুন যা ইনপুট হিসেবে প্রতি ঘণ্টায় উৎপাদিত গাড়ির সংখ্যা ও সফলতার হার নেয় এবং প্রতি ঘণ্টায় তৈরি হওয়া সফল গাড়ির সংখ্যা গণনা করে। সফলতার হার শতাংশ আকারে দেওয়া থাকে, `0` থেকে `100` পর্যন্ত:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**দ্রষ্টব্য:** রিটার্ন ভ্যালুটি ফ্লোট হওয়া উচিত।

## 2. প্রতি মিনিটে উৎপাদিত কর্মক্ষম গাড়ির সংখ্যা গণনা করুন

এমন একটি ফাংশন ইমপ্লিমেন্ট করুন যা ইনপুট হিসেবে প্রতি ঘণ্টায় উৎপাদিত গাড়ির সংখ্যা ও সফলতার হার নেয় এবং প্রতি মিনিটে কতটি গাড়ি সফলভাবে তৈরি হয় তা গণনা করে:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**দ্রষ্টব্য:** রিটার্ন ভ্যালুটি ইন্টিজার হওয়া উচিত।

## 3. উৎপাদন খরচ গণনা করুন

সাধারণত প্রতিটি গাড়ি আলাদাভাবে উৎপাদন করতে $10.000 খরচ হয়, সেটি সফল হোক বা না হোক। কিন্তু একটু পরিকল্পনা করলে ১০টি গাড়ি একসাথে $95.000-এ উৎপাদন করা যায়। উদাহরণস্বরূপ, ৩৭টি গাড়ি এভাবে উৎপাদন করা যায়:
37 = 3 x দশটি গাড়ির গ্রুপ + 7টি আলাদা গাড়ি

তাহলে ৩৭টি গাড়ির খরচ:
3 \* 95,.000 + 7 \* 10.000 = 355.000

এমন একটি ফাংশন ইমপ্লিমেন্ট করুন যা কতগুলো গাড়ি উৎপাদনের খরচ গণনা করে, সেগুলো সফল হোক বা না হোক:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**দ্রষ্টব্য:** রিটার্ন ভ্যালুটি ইন্টিজার হওয়া উচিত।
