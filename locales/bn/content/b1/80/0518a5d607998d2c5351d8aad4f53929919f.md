# নির্দেশনা

লিলি নামের লিস্প অ্যালিয়েন আপনার সাহায্যে নিশ্চিতভাবেই অনেক লাসাগনা বানিয়েছে। কৃতজ্ঞতা জানাতে সে আপনাকে কিছু উদ্বৃত্ত খাবার দিতে চায়। তবে তার আগে, আপনি যে ফাংশনগুলোর কাজে সাহায্য করেছিলেন তার একটির ব্যাপারে তার কিছু মতামত আছে।

এই অনুশীলনীতে আপনি আরও কিছু ফাংশন লিখবেন, যা দিয়ে লিলিকে তার লাসাগনা রান্নায় সাহায্য করবেন, আর আপনার সাথে উদ্বৃত্ত খাবার ভাগ করে নিতেও সাহায্য করবেন।

এখানে আপনার জন্য ছয়টি কাজ আছে: তিনটি আগের লাসাগনা রান্নার ফাংশনগুলোর উন্নতি করা নিয়ে, আর তিনটি উদ্বৃত্ত খাবার ভাগ করা নিয়ে।

## 1. `preparation-time-in-minutes` ব্যবহার করা আরও সহজ করুন

লিলি বলছে, আপনার `preparation-time-in-minutes` ব্যবহার করা তার কাছে একটু অস্বস্তিকর লাগছিল, কারণ ফাংশনগুলো ব্যবহার করার আগে তাকে সব স্তর গুনতে হতো। লিলি ভাবছে, আপনি কি ফাংশনটির এমন একটি সংস্করণ বানাতে পারবেন যা আর্গুমেন্ট হিসেবে স্তরগুলো (যতগুলোই হোক) নেয়, আর তারপর কতগুলো স্তর আছে তার ভিত্তিতে প্রস্তুতির সময় হিসাব করে? মনে করিয়ে দিই, একটি স্তর প্রস্তুত করতে ১৯ মিনিট লাগে।

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. প্রত্যাশিত ওভেন সময় পরিবর্তনের সুযোগ দিন

লিলির প্যারেন্টাল-ইউনিটরা সবসময় তাদের লাসাগনা ৩৩৭ মিনিট ধরে রান্না করত, তবুও লিলি স্বীকার করে যে অন্য লিস্প অ্যালিয়েনরা তাদের লাসাগনা আরও বেশি বা কম সময় ধরে রান্না করতে পছন্দ করে।

তাই ভালো হবে যদি `remaining-minutes-in-oven` আর `expected-minutes-in-oven` ব্যবহার না করে, বরং একটি _ঐচ্ছিক_ প্যারামিটার নিতে পারে যা ঠিক করে সময়টা বেশি, খুব বেশি, কম নাকি খুব কম হবে। বেশি বা কম মানে ডিফল্ট ৩৩৭ সময়ের সাথে ১০০ যোগ বা বিয়োগ করা। খুব বেশি বা খুব কম মানে ২০০ যোগ বা বিয়োগ করা। কোনো প্যারামিটার দেওয়া না থাকলে, বা আর্গুমেন্টটি 'normal' হলে, ডিফল্ট মান ৩৩৭ রিটার্ন করা উচিত।

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. লিলির আরেকটি প্রিয় রান্নার ধরন মনে পড়ল

সেই পরিবর্তন শেষ করার পরপরই লিলির মনে পড়ল যে কিছু লিস্প অ্যালিয়েন আছে যারা _একেবারে কম_ রান্নার সময় পছন্দ করে। আসলে তারা চায় এটা কাঁচা থাকুক। তাই এখন ফাংশনটি যদি আর্গুমেন্ট হিসেবে `NIL` পায় তাহলে 0 রিটার্ন করবে, আর আগের কাজের মতোই বাকি মানগুলোও দেবে।

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. উদ্বৃত্ত খাবার ভাগ করা

এখন যেহেতু আপনি লাসাগনা রান্নার ফাংশনগুলোর উন্নতিতে সাহায্য করেছেন, _অনেক লাসাগনা_ জমে গেছে! লিলি আপনার সব সাহায্যের কৃতজ্ঞতা হিসেবে আপনার সাথে উদ্বৃত্ত খাবার ভাগ করে নিতে চায়। আপনাকে একটি ফাংশন লিখতে হবে যা তিনটি প্যারামিটার নেয়: মোট উদ্বৃত্ত খাবার, লিলি তার আলমারিতে যতগুলো খাবারের পাত্র পেয়েছে, আর আপনার জন্য একই সংখ্যা। যেহেতু খাবারের পাত্র খুঁজতে ভিন্ন ভিন্ন সময় লাগতে পারে, আর আপনি ও লিলি আলমারি খুঁজতে ব্যস্ত থাকার সময়েই উদ্বৃত্ত খাবারের সঠিক পরিমাণ ঠিক হয়ে যেতে পারে, তাই你们两个 একমত যে ফাংশনটি আর্গুমেন্ট যেকোনো ক্রমে নেবে, যাতে প্রতিটি সংখ্যা ঠিক হওয়ার সাথে সাথেই আপনি সেটি লিখে রাখতে পারেন। তিনটি সংখ্যাই পেয়ে গেলে ফাংশন কলের বন্ধনীটি বন্ধ করে সেটি ইভালুয়েট করতে পারেন।

ফাংশনটি এমন উদ্বৃত্ত খাবারের পরিমাণ রিটার্ন করবে যা সত্যিই উদ্বৃত্ত থেকে যায়, অর্থাৎ উদ্বৃত্ত খাবারের ওজন আর আপনি ও লিলি মিলে যতগুলো পাত্র পেয়েছেন সেই সংখ্যার পার্থক্য।

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. অনুমান করা

নিজ নিজ আলমারিতে কয়েকবার যাওয়া-আসার পর আপনি আর লিলি দুজনেই একমত হলেন যে, সংখ্যা আলাদা করে না বললে ফাংশনটি যদি ধরে নিতে পারত যে আপনার বা লিলির কাছে... ধরা যাক, ১০টি পাত্র আছে, তাহলে দারুণ হতো।

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. উদ্বৃত্ত খাবারের আদর্শ পরিমাণ

আরও ভালো হতো যদি ফাংশনটি _ধরে নিতে পারত_ যে পাত্রগুলো ভরে যাওয়ার মতো যথেষ্ট উদ্বৃত্ত খাবার আছে। তাই ওজন দেওয়া না থাকলে ফাংশনটি `:just-split-it` রিটার্ন করবে। _তবে_ ওজন দেওয়া থাকলে আর সেটি `nil` হলে, ফাংশনটি `:looks-like-someone-was-hungry` রিটার্ন করবে।

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
