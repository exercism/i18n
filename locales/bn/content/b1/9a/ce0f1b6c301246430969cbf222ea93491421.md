# সম্পর্কে

Haxe-এ [স্ট্রিং][strings] হলো ইমিউটেবল অবজেক্ট, যা ইউনিকোড ক্যারেক্টারের (অক্ষর, ডিজিট, যতিচিহ্ন ইত্যাদি) একটি ক্রম হিসেবে টেক্সটকে প্রকাশ করে। একটি `string` ইন্সট্যান্স ডিফাইন করতে ডাবল কোট ব্যবহার করা হয়:

```haxe
var fruit:String = "Apple";
```

কোনো স্ট্রিংয়ের [মেথড বা প্রপার্টি][string-api] কল করে সেটিকে ম্যানিপুলেট করা যায়। যেহেতু ডিফাইন হওয়ার পর স্ট্রিং মান কখনোই বদলায় না, তাই সব স্ট্রিং ম্যানিপুলেশন মেথডই একটি নতুন স্ট্রিং রিটার্ন করে।

একটি স্ট্রিং ডাবল কোট (`"`) ক্যারেক্টার দিয়ে ঘেরা থাকে। কিছু বিশেষ ক্যারেক্টারকে ব্যাকস্ল্যাশ (`\`) ক্যারেক্টার দিয়ে [এস্কেপিং][escaping] করতে হয়। এছাড়া Haxe-এর স্ট্রিং মাল্টি-লাইন, তাই দীর্ঘ স্ট্রিং লিটারাল সহজেই তৈরি করা যায়:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

স্ট্রিং জোড়া লাগানোর সবচেয়ে সহজ উপায় হলো [`+` অপারেটর][plus-operator] ব্যবহার করা।

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

আরও জটিল স্ট্রিং ফরম্যাটিংয়ের জন্য [স্ট্রিং ইন্টারপোলেশন][interpolation] বেশি পছন্দনীয়। এটি করতে স্ট্রিংটিকে সিঙ্গেল কোট (`'`) ক্যারেক্টার দিয়ে ঘেরা হয় এবং ভ্যারিয়েবল ইন্টারপোলেশন চালু করতে ডলার চিহ্ন (`$`) ব্যবহার করা হয়। `${expr}` দিয়ে গোটা এক্সপ্রেশনও মূল্যায়ন করা যায়, যেখানে `expr` হলো যেকোনো বৈধ Haxe এক্সপ্রেশন:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
