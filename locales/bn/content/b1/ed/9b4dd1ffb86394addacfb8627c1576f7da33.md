# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি `TranslationService` তৈরি করবেন, যা ফ্রি সদস্যদের জন্য সাধারণ অনুবাদ সেবা এবং কোয়ালিটির নিশ্চয়তাসহ প্রিমিয়াম সদস্যদের জন্য উন্নত অনুবাদ প্রদান করে।

**API**

আপনি মহাকাশে একটি অনুবাদ API খুঁজে পেয়েছেন, যা যেকোনো অনুবাদ `request` যুক্তিসঙ্গত সময়ের মধ্যে পূরণ করে।
আপনি এর সুবিধা নিতে চান।
মহাকাশের অনুবাদকরা অত্যন্ত খামখেয়ালী এবং পুনরাবৃত্তি অপছন্দ করেন, তাই তারা _API স্টোরেজ_ স্যাটেলাইটও দেন, যেখান থেকে আপনি তাদের বিরক্ত না করেই আগের অনুবাদগুলো `fetch` করতে পারেন।

**_একটি অনুবাদ ফেচ করা_**

`api.fetch(text)` _API স্টোরেজ_ থেকে `text`-এর একটি অনুবাদ ফেচ করে এবং একটি `promise` রিটার্ন করে, যা দুটি মান দেয়:

- `translation`: প্রকৃত অনুবাদ
- `quality`: একটি সংখ্যায় প্রকাশ করা কোয়ালিটি

_API স্টোরেজ_-এ কোনো অনুবাদ না পাওয়া গেলে API একটি `NotAvailable` এরর ছোড়ে।
`api.request` মেথড ব্যবহার করে অনুবাদ যোগ করা যায়।
'text' অনুবাদযোগ্য না হলে API একটি `Untranslatable` এরর ছোড়ে।

```javascript
api.fetch('jIyaj');
// => Promise({ resolved: 'I understand' })
```

**_একটি অনুবাদ রিকোয়েস্ট করা_**

কিছু অনুবাদ নিশ্চিতভাবেই আছে, কিন্তু সেগুলো এখনো _API স্টোরেজ_-এ যোগ করা হয়নি। এটাই `NotAvailable` (স্টোরেজে নেই, তবে রিকোয়েস্ট করা যায়) আর `Untranslatable` (অনুবাদ করা যায় না)-এর মধ্যে পার্থক্য।

`api.request(text, callback)` অনুরোধ করে যে `text`-এর একটি অনুবাদ সম্পন্ন করে _API স্টোরেজ_-এ যোগ করা হোক।
কাজ শেষ হলে `callback` ফাংশনটি কল করা হয়।

- সফল হলে `callback`-এ `undefined` পাঠানো হয়: এটি বোঝায় অনুবাদটি সফল হয়েছে এবং `api.fetch` মেথড দিয়ে তা পাওয়া যাবে।
- ব্যর্থ হলে `callback`-এ একটি `error` পাঠানো হয়: এটি বোঝায় কোথাও কিছু ভুল হয়েছে।
  আউটার স্পেস API-টি _অস্থির_, অর্থাৎ API প্রায়ই ব্যর্থ হয়।
  এমন হলে আবার `api.request` করলে অসুবিধা নেই।

```javascript
api.request('majQa’', callback);
// => undefined
//
// later: the passed callback is called with undefined
//        because it was successful.
```

**⚠ সতর্কতা! ⚠**

## 1. কোয়ালিটি উপেক্ষা করে একটি অনুবাদ ফেচ করুন

ফ্রি সেবাটি কেবল সেই অনুবাদই দেয়, যেগুলো এই মুহূর্তে _API স্টোরেজ_-এ আছে।

এমন একটি মেথড `free(text)` ইমপ্লিমেন্ট করুন, যা ফ্রি সদস্যদের _API স্টোরেজ_-এ আগে থেকেই থাকা অনুবাদ দেয়।
কোয়ালিটি উপেক্ষা করুন এবং API-এর ছোড়া যেকোনো এরর ফরওয়ার্ড করুন।

- অনুবাদটি আনা সম্ভব হলে, তার কোয়ালিটি যাই হোক না কেন, সেটি রিটার্ন করে
- অনুবাদ API থেকে আসা যেকোনো এরর ফরওয়ার্ড করে
- `api.fetch` মেথড ব্যবহার করে (`api.fetch` একটি `promise` রিটার্ন করে)

```javascript
service.free('jIyaj');
// => Promise<...> resolves "I understand."

service.free("jIyajbe'");
// => Promise<...> rejects Error("Not yet translated")
```

## 2. একগুচ্ছ অনুবাদ একবারে ফেচ করুন, সব নয়তো কিছুই নয়

ফ্রি সদস্যদের জন্য একটি মেথড `batch([text, text, ...])` ইমপ্লিমেন্ট করুন, যা ফ্রি সেবা ব্যবহার করে টেক্সটের একটি অ্যারে অনুবাদ করে এবং সব অনুবাদ অথবা একটি এরর রিটার্ন করে।

- সবগুলো পাওয়া গেলে সব অনুবাদ (একই ক্রমে) রিজলভ করে
- যে এররটি প্রথমে আসে, সেটি দিয়ে রিজেক্ট করে
- কোনো টেক্সট না দিলে `BatchIsEmpty` এরর দিয়ে রিজেক্ট করে

```javascript
service.batch(['jIyaj', "majQa'"]);
// => Promise<...> resolves ["I understand.", "Well done!"]

service.batch(['jIyaj', "jIyajbe'"]);
// => Promise<...> rejects new Error("Not yet translated")

service.batch([]);
// => Promise<...> rejects BatchIsEmpty()
```

## 3. একটি অনুবাদ রিকোয়েস্ট করুন, সর্বোচ্চ ২ বার রিট্রাই করে

একটি প্রিমিয়াম ইউজার মেথড `request(text)` ইমপ্লিমেন্ট করুন, যা _API স্টোরেজ_-এ একটি অনুবাদ যোগ করার _রিকোয়েস্ট_ করে।
কোনো ব্যর্থতা ঘটলে রিকোয়েস্টটি স্বয়ংক্রিয়ভাবে আবার চেষ্টা করবে।
একই রিকোয়েস্টের জন্য এটি **৩ বারের বেশি কল** করবে না (_মহাকাশের অনুবাদকদের রাগাবেন না!!!_)।

- `api.request` কোনো এরর না দিলে `undefined` দিয়ে রিজলভ করে
- `api.request` একটি এরর দিলে সর্বোচ্চ দুইবার রিট্রাই করে
- রিট্রাই শেষ হয়ে গেলে সর্বশেষ পাওয়া এরর দিয়ে রিজেক্ট করে

```javascript
service.request("jIyajbe'");
// => Promise<...> resolves (with nothing), can now be retrieved using the fetch API
```

## 4. একটি অনুবাদ ফেচ করুন, কোয়ালিটি যাচাই করুন, নয়তো রিকোয়েস্ট করুন

একটি অনুবাদ ফেচ করার জন্য প্রিমিয়াম ইউজার মেথড `premium(text, quality)` ইমপ্লিমেন্ট করুন।
কোনো অনুবাদ `NotAvailable` হলে, অনুবাদটি রিকোয়েস্ট করুন এবং সেটি _API স্টোরেজ_-এ যোগ হওয়ার পর ফেচ করুন।
মেথডটি কেবল তখনই অনুবাদ রিটার্ন করবে, যখন তা একটি নির্দিষ্ট `quality` থ্রেশহোল্ড পূরণ করে।

- `api.fetch` রিজলভ করলে, রিজলভ করার আগে কোয়ালিটি যাচাই করুন
- `api.fetch` রিজেক্ট করলে, বরং অনুবাদটি _রিকোয়েস্ট_ করুন
- `api.request` রিজেক্ট করলে, এররটি ফরওয়ার্ড করুন

```javascript
service.premium("jIyajbe'", 100);
// => Promise<...> resolves "I don't understand."

service.premium("'arlogh Qoylu'pu'?", 100);
// => Promise<...> rejects QualityThresholdNotMet()

service.premium("'arlogh Qoylu'pu'?", 40);
// => Promise<...> resolves "What time is it?"
```
