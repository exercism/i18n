# নির্দেশনা

Alizé একটি অনলাইন ফ্যাশন বুটিক চালান। বছরের বড় সেল ঘনিয়ে আসছে, তাই তিনি ইনভেন্টরির হিসাব নিতে সাহায্য করার জন্য কিছু ফাংশনালিটি তৈরি করতে চান।

ইনভেন্টরির একটি আইটেম একটি কাস্টম টাইপ দিয়ে প্রকাশ করা হয়।

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. আইটেমগুলোর নামের একটি অ্যারে রিটার্ন করুন

`item_names` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আইটেমের একটি ইটারেটর নেয় এবং একই ক্রমে তাদের নামের একটি ইটারেটর রিটার্ন করে।

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. সস্তা যেসব আইটেম আছে সেগুলো রিটার্ন করুন

`cheap` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আইটেমের একটি ইটারেটর নেয় এবং ৩০-এর কম দামের আইটেমের একটি ইটারেটর রিটার্ন করে।

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. স্টকে নেই এমন যেসব আইটেম আছে সেগুলো রিটার্ন করুন

`out_of_stock` ফাংশনটি ইমপ্লিমেন্ট করুন, যা এমন সব আইটেম রিটার্ন করে যেগুলোর স্টক নেই।

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. মোট স্টক রিটার্ন করুন

`total_stock` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আপনার গুদামে থাকা আইটেমের মোট পরিমাণ হিসাব করে:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
