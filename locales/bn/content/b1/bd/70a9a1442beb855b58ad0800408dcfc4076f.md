# পরিচিতি

Gleam-এর স্ট্যান্ডার্ড লাইব্রেরি `gleam/queue` মডিউলে একটি `Queue` টাইপ তৈরি করেছে। এটি `List` টাইপের মতোই, তবে কয়েকটি গুরুত্বপূর্ণ পার্থক্য আছে:

- `Queue` টাইপে এমন কোনো লিটারাল সিনট্যাক্স নেই যা দিয়ে কিউ তৈরি করা যায় বা তাদের উপর প্যাটার্ন ম্যাচ করা যায়।
- `Queue` টাইপের সামনে ও পিছনে দুই দিক থেকেই দক্ষতার সঙ্গে এলিমেন্ট যোগ করা ও সরানো যায়, অথচ `List` টাইপে কেবল সামনের দিক থেকে দক্ষতার সঙ্গে এলিমেন্ট যোগ করা ও সরানো যায়।

বেশিরভাগ সময়েই আপনি `List` টাইপ ব্যবহার করতে চাইবেন, কিন্তু যখন কোনো কালেকশনের শেষ প্রান্ত থেকে এলিমেন্ট যোগ করা ও সরানোর দরকার হবে, তখন `Queue` টাইপ ভালো একটি পছন্দ।

`queue.new` ও `queue.from_list` ফাংশন দিয়ে কিউ তৈরি করা যায়:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

`queue.push_front` ও `queue.push_back` ফাংশন দিয়ে কিউতে এলিমেন্ট যোগ করা যায়:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

`queue.pop_front` ও `queue.pop_back` ফাংশন দিয়ে কিউ থেকে এলিমেন্ট সরানো যায়:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

`queue.to_list` ফাংশন দিয়ে একটি কিউকে অ্যারেতে রূপান্তর করা যায়:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## কিউয়ের সমতা

কিউ যেভাবে তৈরি করা হয়েছে তার কারণে, একই ক্রমে একই এলিমেন্ট থাকা দুটি কিউ `==` অপারেটরের হিসাবে সমান নাও হতে পারে, কারণ এই অপারেটর মানগুলো গঠনগতভাবে তুলনা করে। যেমন:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

দুটি কিউয়ের সমতা যাচাই করার দরকার হলে আপনি `queue.is_logically_equal` ফাংশন ব্যবহার করতে পারেন।

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
