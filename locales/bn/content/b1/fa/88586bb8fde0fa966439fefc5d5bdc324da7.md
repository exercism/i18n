# স্ট্রিং কনক্যাটিনেশন

স্ট্রিং কনক্যাটিনেশন Crystal-এ পুরোপুরি বৈধ, তবে স্ট্রিং তৈরি করার আরও প্রচলিত একটি উপায় হলো [স্ট্রিং ইন্টারপোলেশন][interpolation]।
যেমন:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
