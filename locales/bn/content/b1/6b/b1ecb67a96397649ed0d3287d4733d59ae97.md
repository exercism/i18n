# নির্দেশনা সংযোজন

## শব্দ

- `tick ( matrix cols -- matrix' )`: গ্রিডটিকে এক প্রজন্ম এগিয়ে নিয়ে যায় এবং নতুন গ্রিড রিটার্ন করে।

গ্রিডের প্রতিটি সারি একটি ৬৪-বিট ইন্টিজার হিসেবে প্রকাশ করা হয়; `cols` হলো কলামের সংখ্যা (সর্বোচ্চ ৬৪)। উদাহরণস্বরূপ,

```
    0 1 0
    1 0 0
    1 1 0
```

এভাবে প্রকাশ করা হয়

```
0b010
0b100
0b110
```
