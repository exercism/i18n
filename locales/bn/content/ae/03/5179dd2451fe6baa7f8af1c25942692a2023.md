# ভূমিকা

Haxe-এ ইটারেটর একটি `for` লুপ ব্যবহার করে একটি মানের উপর ইটারেট করতে ব্যবহৃত হয়। ইটারেটর দুই ধরনের:

- `Iterator` যা একটি মানের উপর ইটারেট করে।
- `Iterable` ডেটা যা একটি ডেটা টাইপের উপর ইটারেট করা সম্ভব করে।

এই দুটি ধারণাই `Iterator<T>` এবং `Iterable<T>` দিয়ে প্রকাশ করা হয়:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

যে কোনো ক্লাস এই টাইপগুলোর একটির সাথে ইউনিফাই করে, সেটিকে একটি `for` লুপ ব্যবহার করে ইটারেট করা যায়। যদি একটি ক্লাস `hasNext` এবং `next` মেথডগুলো ডিফাইন করে, তবে সেটিকে একটি ইটারেটর হিসেবে ধরা হয়; অন্যথায় যদি সেটি একটি `iterator` মেথড ডিফাইন করে, তবে সেটিকে একটি ইটারেবল টাইপ হিসেবে ধরা হয়।
