Haxe-এ [বুলিয়ান][booleans] প্রকাশ করা হয় `Bool` টাইপ দিয়ে, যার মান হতে পারে `true` অথবা `false`।

Haxe সমর্থন করে তিনটি [বুলিয়ান অপারেটর][operators]: `!` (ইউনারি NOT), `&&` (বাইনারি AND), এবং `||` (বাইনারি OR)

যৌগিক বুলিয়ান এক্সপ্রেশন (`&&` এবং `||`) _শর্ট-সার্কিট_ ইভালুয়েশন ব্যবহার করে, যেখানে এক্সপ্রেশনগুলো বাঁ থেকে ডানে ইভালুয়েট করা হয়, কিন্তু শুধু যতটা প্রয়োজন ততটুকুই। নিচের মতো ক্ষেত্রে এটা গুরুত্বপূর্ণ:

```haxe
object != null && object.field == x
```

প্রথম বুলিয়ান পরীক্ষাটি নিশ্চিত করে যে `object.field` অ্যাক্সেস করা হয় কেবল তখনই, যখন `object` `null` নয়, ফলে রানটাইম এরর থেকে রক্ষা পাওয়া যায়।

তিনটি বুলিয়ান অপারেটরের [প্রিসিডেন্স][precedence] আলাদা আলাদা, এবং এগুলো এই ক্রমে ইভালুয়েট করা হয়: `!` -> `&&` -> `||`।

এক্সপ্রেশনগুলো `()` বন্ধনীর ভেতরে রাখলে এই প্রিসিডেন্স নিয়মগুলো অগ্রাহ্য করা যায়, কারণ বন্ধনীর প্রিসিডেন্স বেশি।

```haxe
!true && false   // => false
!(true && false) // => true
```
