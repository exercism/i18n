# পরিচিতি

C++-এ কন্ডিশনাল অন্য ভাষার কন্ডিশনালের মতোই।
যেকোনো কন্ডিশনাল অপারেশনের অন্তর্নিহিত টাইপ হলো `bool` টাইপ, যার মান `true` বা `false` হতে পারে।
নানা শর্ত পরীক্ষা করার জন্য কন্ডিশনাল প্রায়ই ফ্লো কন্ট্রোলের মাধ্যম হিসেবে ব্যবহৃত হয়।

`if` স্টেটমেন্ট ব্যবহার করা যায়, যা অন্তর্নিহিত শর্তটি `true` হলে তার কোড চালায়, এভাবে:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

একাধিক কেস জড়িত থাকলে `else if` এবং `else` স্টেটমেন্ট দিয়ে অনেকগুলো `if` স্টেটমেন্ট একসাথে চেইন করা যায়।

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17 থেকে if স্টেটমেন্টে একটি ছোট ইনিশিয়ালাইজেশন স্টেটমেন্টও থাকতে পারে, যা দিয়ে if স্টেটমেন্টের জন্য এক বা একাধিক ভ্যারিয়েবল ইনিশিয়ালাইজ করা যায়।
যেমন:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> দ্রষ্টব্য: ইনিশিয়ালাইজেশনে তৈরি করা কোনো ভ্যারিয়েবল if স্টেটমেন্ট শেষ হওয়ার পর আর অ্যাক্সেস করা যায় না।
