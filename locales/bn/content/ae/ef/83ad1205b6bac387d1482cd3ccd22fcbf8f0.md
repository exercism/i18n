# নির্দেশনা

এই অনুশীলনীতে আপনি একটি ইনভেন্টরি সিস্টেম পরিচালনা করবেন।

ইনভেন্টরিটি আইটেমের নাম অনুসারে সাজানো থাকবে এবং প্রতিটি আইটেম কতগুলো আছে তার হিসাব রাখবে।

আপনাকে ইনভেন্টরিতে আইটেম যোগ করার কাজও সামলাতে হবে।
কোনো নির্দিষ্ট ভেক্টরে কোনো আইটেম যতবার থাকবে, ইনভেন্টরিতে সেই আইটেমের পরিমাণ ততবার `1` করে বাড়াতে হবে।
এছাড়া অনুরোধ করা হলে পরিমাণ `1` করে কমিয়ে ইনভেন্টরি থেকে আইটেম মোছার কাজটিও আপনাকে সামলাতে হবে।

সবশেষে, আপনাকে এমন একটি ফাংশন বাস্তবায়ন করতে হবে যা একটি নির্দিষ্ট ইনভেন্টরির সব কী (key)-ভ্যালু জোড়া `pair`-এর একটি `vector` হিসেবে রিটার্ন করবে।

~~~~exercism/note
এই অনুশীলনীর টেস্টগুলো মিউটেশন নিরপেক্ষ, তবে ফাংশনগুলোর নামই বলে দেয় যে এগুলো ইনপুট বদলাবে না।
ভূমিকার ফাংশনগুলো ব্যবহার করতে চাইলে, কিন্তু ইনপুট বদলাতে না চাইলে, `copy()` ফাংশনটি আপনার কাজে লাগবে।
~~~~

## 1. একটি ভেক্টরের ভিত্তিতে ইনভেন্টরি তৈরি করুন

ইনপুট হিসেবে আইটেমের একটি ভেক্টর নিয়ে সেটি থেকে একটি "ইনভেন্টরি" তৈরি করে, এমন `create_inventory(<input vector>)` ফাংশনটি বাস্তবায়ন করুন।
এটি প্রতিটি আইটেমের নামের সাথে তার নিজস্ব পরিমাণ জুড়ে দিয়ে একটি `dict` রিটার্ন করবে।

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. একটি ভেক্টর থেকে বিদ্যমান ডিকশনারিতে আইটেম যোগ করুন

পাস করা ইনভেন্টরিতে আইটেমের একটি ভেক্টর যোগ করে, এমন `add_items(<inventory dict>, <item vector>)` ফাংশনটি বাস্তবায়ন করুন:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. ইনভেন্টরির আইটেমের পরিমাণ কমান

আইটেমের একটি `vector` নেয়, এমন `decrement_items(<inventory dict>, <items vector>)` ফাংশনটি বাস্তবায়ন করুন।
`vector`-এ কোনো আইটেম যতবার থাকবে, আপনার ফাংশন প্রতিবার সেই আইটেমের সংখ্যা থেকে `1` কমাবে:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

ইনভেন্টরিতে কোনো আইটেমের সংখ্যা ০-এর নিচে নামতে দেওয়া যাবে না।
ইনপুট `vector`-এ কোনো আইটেম যতবার থাকলে তা যদি উপলব্ধ সংখ্যার চেয়ে বেশি হয়, তবে সেই আইটেমের জন্য লেখা পরিমাণ ০-তেই থাকবে।
সংখ্যা শূন্য হয়ে গেলে পরিমাণ কমানোর অতিরিক্ত অনুরোধগুলো উপেক্ষা করতে হবে।

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. ইনভেন্টরি থেকে একটি এন্ট্রি সম্পূর্ণ মুছে ফেলুন

ইনভেন্টরি থেকে একটি আইটেম ও তার সংখ্যা সম্পূর্ণ মুছে ফেলে, এমন `remove_item(<inventory dict>, <item>)` ফাংশনটি বাস্তবায়ন করুন:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

ইনভেন্টরিতে আইটেমটি না থাকলে ফাংশনটি মূল ইনভেন্টরিটিই অপরিবর্তিত অবস্থায় রিটার্ন করবে।

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. ইনভেন্টরির সম্পূর্ণ বিষয়বস্তু রিটার্ন করুন

একটি ইনভেন্টরি নিয়ে `(item, quantity)` জোড়ার একটি ভেক্টর রিটার্ন করে, এমন `list_inventory(<inventory dict>)` ফাংশনটি বাস্তবায়ন করুন।

ভেক্টরটিতে কেবল _উপলব্ধ_ আইটেমগুলোই (_অর্থাৎ যাদের পরিমাণ শূন্যের চেয়ে বেশি_) থাকবে এবং সেগুলো আইটেমের নাম অনুসারে বর্ণানুক্রমে সাজানো থাকবে:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
