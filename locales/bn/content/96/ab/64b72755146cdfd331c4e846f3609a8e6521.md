# নির্দেশাবলি

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসানিয়া রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে চারটি কাজ আছে, সবগুলোই লাসানিয়া রান্না করতে যে সময় লাগে তার সাথে সম্পর্কিত।

## 1. মিনিটে প্রত্যাশিত ওভেনের সময় ডিফাইন করুন

লাসানিয়াকে কত মিনিট ওভেনে থাকতে হবে তা জানার জন্য `expected-time` ভ্যারিয়েবলটি ডিফাইন করুন। রান্নার বই অনুযায়ী, মিনিটে প্রত্যাশিত ওভেনের সময় ৪০:

```clojure
expected-time
;;=> 40
```

## 2. মিনিটে ওভেনে বাকি থাকা সময় গণনা করুন

`remaining-time` ফাংশনটি ডিফাইন করুন, যা আর্গুমেন্ট হিসেবে লাসানিয়া এতক্ষণ কত মিনিট ওভেনে ছিল সেই সংখ্যাটি নেয় এবং আগের কাজের মিনিটে প্রত্যাশিত ওভেনের সময়ের ভিত্তিতে লাসানিয়াকে ওভেনে আরও কত মিনিট থাকতে হবে তা রিটার্ন করে।

```clojure
(remaining-time 30)
;;=> 10
```

## 3. মিনিটে প্রস্তুতির সময় গণনা করুন

`prep-time` ফাংশনটি ডিফাইন করুন, যা আর্গুমেন্ট হিসেবে লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যাটি নেয় এবং লাসানিয়া প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```clojure
(prep-time 2)
;;=> 4
```

## 4. মিনিটে মোট কাজের সময় গণনা করুন

`total-time` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসানিয়া কত মিনিট ধরে ওভেনে আছে সেই সংখ্যা। ফাংশনটি রিটার্ন করবে লাসানিয়া রান্না করতে আপনার মোট কত মিনিট লেগেছে, যা হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```clojure
(total-time 3 20)
;;=> 26
```
