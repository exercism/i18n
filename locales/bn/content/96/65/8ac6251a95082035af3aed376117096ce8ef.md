# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নিতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে তিনটি কাজ আছে: একটি হলো আপনার লাইসেন্স লাগবে কি না তা নির্ধারণ করা, একটি হলো দুটি যানবাহনের মধ্যে বাছাই করতে সাহায্য করা, আর একটি হলো পুরোনো যানবাহনের গ্রহণযোগ্য দাম অনুমান করা।

## 1. আপনার ড্রাইভিং লাইসেন্সের প্রয়োজন হবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালানোর জন্য ড্রাইভিং লাইসেন্স লাগে।
ধরে নিন, কেবল `"car"` এবং `"truck"` ধরনের যানবাহনের জন্য লাইসেন্স লাগে; বাকি সবকিছু লাইসেন্স ছাড়াই চালানো যায়।

`NeedsLicense(kind)` ফাংশনটি বাস্তবায়ন করুন, যা যানবাহনের ধরন নেয় এবং ওই ধরনের যানবাহনের জন্য আপনার লাইসেন্স লাগবে কি না তা বোঝানো একটি বুলিয়ান রিটার্ন করে।

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. কেনার জন্য বিবেচনায় থাকা দুটি যানবাহনের মধ্যে বাছাই করুন

আপনি হাতে থাকা যানবাহনগুলোর মধ্যে থেকে বেছে নেওয়ার চেষ্টা করছেন।
অনেকগুলো অপশন থেকে আপনি দুটিতে নামিয়ে আনতে পেরেছেন, কিন্তু চূড়ান্ত সিদ্ধান্ত নিতে আপনার সাহায্য দরকার।
এর জন্য `ChooseVehicle(option1, option2)` ফাংশনটি বাস্তবায়ন করুন, যা আর্গুমেন্ট হিসেবে দুটি যানবাহন নেয় এবং এমন একটি সিদ্ধান্ত রিটার্ন করে যেখানে অভিধানিক ক্রমে প্রথমে আসা অপশনটি থাকে।

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. পুরোনো যানবাহনের দামের একটি আনুমানিক হিসাব করুন

এখন যেহেতু সিদ্ধান্ত নেওয়া হয়ে গেছে, আপনি ডিলারশিপে ন্যায্য দাম পাচ্ছেন কি না তা নিশ্চিত করতে চান।
যেহেতু আপনি একটি পুরোনো যানবাহন কিনতে আগ্রহী, তাই দাম নির্ভর করে যানবাহনটির বয়স কত তার উপর।
মোটা দাগে অনুমান করতে ধরুন, যানবাহনটির বয়স ৩ বছরের কম হলে একেবারে নতুন অবস্থায় যে দাম ছিল তার ৮০% দাম পড়বে।
বয়স কমপক্ষে ১০ বছর হলে দাম পড়বে ৫০%।
আর যানবাহনটির বয়স কমপক্ষে ৩ বছর কিন্তু ১০ বছরের কম হলে দাম পড়বে মূল দামের ৭০%।

`CalculateResellPrice(originalPrice, age)` ফাংশনটি বাস্তবায়ন করুন, যা `if`, `else if` এবং `else` ব্যবহার করে এই যুক্তি প্রয়োগ করে (অনুশীলন করতে চাইলে অন্য উপায়ও আছে)।
এটি আর্গুমেন্ট হিসেবে মূল দাম এবং যানবাহনের বয়স নেয় এবং ডিলারশিপে আনুমানিক দামটি রিটার্ন করে।

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**লক্ষ্য করুন**, রিটার্ন ভ্যালুটি একটি `float64`।
