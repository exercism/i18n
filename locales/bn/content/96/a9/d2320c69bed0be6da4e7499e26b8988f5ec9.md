# ভূমিকা

`Result` টাইপটি Elm ভাষায় এরর রিপোর্টিংয়ের সমাধান এবং এরর থেকে পুনরুদ্ধারে সহায়ক। এটি `Maybe` টাইপের সাথে কিছুটা মেলে, তবে ব্যর্থ হতে পারে এমন ফাংশন থেকে Maybe রিটার্ন করা যায় বটে, কিন্তু কেন ব্যর্থ হলো সে সম্পর্কে এটি আপনাকে কিছুই জানায় না। Result কেন কিছু ব্যর্থ হলো, তার এই প্রসঙ্গটি নিজের মধ্যে ধারণ করে।

`Result` টাইপটি নিচের মতো ডিফাইন করা হয়েছে:

```elm
type Result error value
  = Ok value
  | Err error
```

Elm-এর পরিভাষায় এটিকে "কাস্টম টাইপ" ডেফিনিশন বলা হয়।
`OK value` এবং `Error error`-এ `error` ও `value` একটি টাইপ ভ্যারিয়েবলকে বোঝায়, অর্থাৎ এটি যেকোনো টাইপ হতে পারে, যেমন `Int`, `Bool` বা `String`।
সুতরাং `Result String Int` হলো এমন একটি ভ্যারিয়েবল, যেটিতে একটি `Int` থাকার কথা, আর যদি কোনো এরর থাকে, তাহলে সেটি একটি `String` হিসেবে প্রকাশ পাবে।
Result-এর জন্য অনেকগুলো কাজের হেল্পার ফাংশনসহ একটি [Result মডিউল](https://package.elm-lang.org/packages/elm/core/latest/Result) আছে।
