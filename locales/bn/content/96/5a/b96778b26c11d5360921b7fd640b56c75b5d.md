# নির্দেশনা

বোসুন ডেকে প্রতিদিনের ওয়াচ ব্রিফিং পরিচালনা করেন: একটি নির্দিষ্ট অভিবাদন, কর্তব্যরত ক্রুদের হাজিরা, আর শেষে ছুটি দেওয়ার ঘোষণা। আপনি ব্রিফিংটিকে ছোট ছোট নামযুক্ত লাইনে ভাগ করবেন এবং সেগুলো জুড়ে দেবেন।

এই অনুশীলনীর জন্য আপনি **দুটি ফাইল** সম্পাদনা করবেন:

- `bosuns-briefing/helpers/helpers.factor`: ছোট, পুনরায় ব্যবহারযোগ্য টুকরো। ভোকাবুলারি: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: মূল ফাইল, যেটি হেল্পারগুলো জুড়ে দেয়। ভোকাবুলারি: `bosuns-briefing`.

## 1. অভিবাদন

`helpers.factor` ফাইলে `greeting` ডিফাইন করুন যাতে এটি নির্দিষ্ট সূচনা স্ট্রিং `"All hands, attention!"` রিটার্ন করে।

```factor
greeting .
! => "All hands, attention!"
```

## 2. ক্রু লাইন

`helpers.factor` ফাইলে `crew-line` ডিফাইন করুন যাতে এটি একটি নাম-স্ট্রিং নেয় এবং সেই নামের আগে `"  - "` (দুটি স্পেস, একটি হাইফেন, একটি স্পেস) বসিয়ে রিটার্ন করে।

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. সমাপ্তি

`helpers.factor` ফাইলে `closing` ডিফাইন করুন যাতে এটি নির্দিষ্ট সমাপ্তি-স্ট্রিং `"Carry on."` রিটার্ন করে।

```factor
closing .
! => "Carry on."
```

## 4. রোস্টার

`bosuns-briefing.factor` ফাইলে `roster` ডিফাইন করুন যাতে এটি ক্রুদের নামের একটি অ্যারে নেয় এবং একটি একক বহু-লাইনের স্ট্রিং রিটার্ন করে, যেখানে প্রতিটি নাম `crew-line` দিয়ে ফরম্যাট করা এবং সেগুলো নিউলাইন দিয়ে জোড়া।

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. ব্রিফিং

`bosuns-briefing.factor` ফাইলে `briefing` ডিফাইন করুন যাতে এটি ক্রুদের নামের একটি অ্যারে নেয় এবং সম্পূর্ণ ব্রিফিং একটি একক স্ট্রিং হিসেবে রিটার্ন করে: প্রথম লাইনে অভিবাদন, পরের লাইনগুলোতে রোস্টার, আর শেষ লাইনে সমাপ্তি। হেল্পারগুলো ও `roster` ব্যবহার করুন।

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
