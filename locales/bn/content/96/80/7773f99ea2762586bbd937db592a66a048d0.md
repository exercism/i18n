# ভূমিকা

## কনস্ট্যান্ট ও ফাংশন

Haskell প্রোগ্রাম ডেফিনিশন ও এক্সপ্রেশন দিয়ে গঠিত।

একটি কনস্ট্যান্ট মান `name = expression` দিয়ে ডিফাইন করা হয়।

```haskell
five = 5

six = 3 + 3
```

ফাংশন ডিফাইন করা হয় `name parameters... = expression` দিয়ে, যেখানে প্যারামিটারগুলো শুধু স্পেস দিয়ে আলাদা করা হয়।

```haskell
add number1 number2 = number1 + number2
```

একটি ফাংশন কল করাও একটি এক্সপ্রেশন। এটি করা হয় ফাংশনটির নাম উল্লেখ করে এবং তার প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে, স্পেস দিয়ে আলাদা করা, ঠিক ফাংশন ডেফিনিশনের মতোই।

```haskell
five = add 2 3
```

একটি এক্সপ্রেশনের মূল্যায়নের ক্রম নির্দিষ্ট করতে বন্ধনী ব্যবহার করা যায়।

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## ইন্ডেন্টেশন / গুরুত্বপূর্ণ হোয়াইটস্পেস

Haskell কোডের সীমানা নির্দিষ্ট করতে হোয়াইটস্পেস ও ইন্ডেন্টেশন ব্যবহার করে।
***কোনো এক্সপ্রেশনের অংশ যে কোড, তা ওই এক্সপ্রেশনের শুরুর চেয়ে আরও ভেতরে ইন্ডেন্ট করা উচিত।***

- মডিউল, import এবং টপ-লেভেল ফাংশন ডেফিনিশন অবশ্যই একদম বাম কলাম থেকে শুরু করতে হবে।
- যদি একটি এক্সপ্রেশন একাধিক লাইনে ভাগ করা হয়, তাহলে সেই এক্সপ্রেশনের অংশ যে কোড, তা ওই এক্সপ্রেশনের নিচে অন্তত একটি স্পেস দিয়ে ইন্ডেন্ট করতে হবে।
- এক্সপ্রেশনের যে অংশগুলো একসাথে গ্রুপ করা হয়েছে, সেগুলো সমান সংখ্যক স্পেস দিয়ে ইন্ডেন্ট করা উচিত।

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## মডিউল

মডিউল ফাংশন এক্সপোর্ট করে।
তার মানে আপনি মডিউলটি তার এক্সপোর্ট স্টেটমেন্টে যে ফাংশনগুলো উপলব্ধ করে, সেগুলো ব্যবহার করতে পারেন।
একটি মডিউল শুধু অভ্যন্তরীণ ব্যবহারের জন্য ফাংশনও ডিফাইন করতে পারে।
ডিফল্টভাবে, যে ফাংশনগুলো স্পষ্টভাবে এক্সপোর্ট করা হয় না, সেগুলো মডিউলের বাইরে থেকে ব্যবহার করা যায় না।

মডিউলের শুরুতে আমরা মডিউলের নাম উল্লেখ করি।
যদি আমাদের Calculator.hs নামের একটি ফাইল থাকে, তাহলে আমাদের মডিউলের নাম রাখা উচিত Calculator।
এরপর, আমরা এটি যে ফাংশনগুলো এক্সপোর্ট করে সেগুলো উল্লেখ করি, এবং এর পরে আমরা ফাংশনগুলো লেখা শুরু করতে পারি।
তাহলে চলুন এটি দিয়ে শুরু করি।

```haskell
module Calculator ( add ) where
```

## কমেন্ট

একটি কমেন্ট হলো Haskell ফাইলের ভেতরে থাকা এমন কিছু টেক্সট, যা কোড হিসেবে ইন্টারপ্রেট করা হয় না।
এটি মূলত আপনার নিজের এবং অন্য প্রোগ্রামারদের পড়ার জন্য বোঝানো হয়েছে।
সিঙ্গেল লাইন কমেন্টের জন্য একটি হালকা সিনট্যাক্স আছে, যা ডাবল ড্যাশের উপর ভিত্তি করে।
মাল্টিলাইন কমেন্টও `{-` এবং `-}` ওপেনিং ও ক্লোজিং ডেলিমিটার জোড়া দিয়ে সম্ভব।

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
