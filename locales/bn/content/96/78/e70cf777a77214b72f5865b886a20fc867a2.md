# ভূমিকা

Haskell-এ `Num` নামে একটি টাইপ আছে, যা সব সাংখ্যিক টাইপের মূল টাইপ।
Number টাইপের ভেতরে চারটি প্রধান উপ-টাইপ আছে: [`Int`][int], [`Integer`][integer], [`Double`][double] আর [`Float`][float]।

Haskell-এ ইন্টিজার টাইপ দুই ধরনের, যারা পূর্ণসংখ্যা প্রকাশ করে।
`Int` একটি নির্দিষ্ট আকারের ইন্টিজার, অন্যদিকে `Integer` হলো সীমাহীন নির্ভুলতার ইন্টিজার।
একটি `Integer` যত বড় সংখ্যাই হোক না কেন, আপনার মেশিনের মেমোরির সীমা পর্যন্ত যেকোনো সংখ্যা ধরে রাখতে পারে; অন্যদিকে `Int` বলতে ৩২ বা ৬৪ বিটে প্রকাশ করা যায় এমন ধনাত্মক ও ঋণাত্মক ইন্টিজারের সেটকে বোঝায় (অন্তত -2^29 থেকে 2^29 - 1 পর্যন্ত নিশ্চিত)।

মনে রাখবেন, ঋণাত্মক সংখ্যা লেখার সময় দ্ব্যর্থতা এড়াতে বন্ধনী ব্যবহার করা উচিত।

```haskell
1

(-1)
```

`Float` বাস্তব সংখ্যার সেটের সাথে মেলে, যা কম্পিউটারের নির্ভুলতার সীমার মধ্যে সীমাবদ্ধ।

সংখ্যার ওপর সংজ্ঞায়িত অপারেশনগুলো সাধারণত এক টাইপ বা অন্যটির ওপর কাজ করে, কিন্তু দুটিতেই নয়।
`Double` হলো ডাবল প্রিসিশনের একটি ফ্লোটিং-পয়েন্ট সংখ্যা।

```haskell
10.5
```

## ইন্টিজার আর ফ্লোটের মধ্যে রূপান্তর

`toFloat` ফাংশনটি ব্যবহার করে আপনি একটি `Int` বা `Integer`-কে `Float`-এ রূপান্তর করতে পারেন।

```haskell
toFloat 1
-- -> 1.0
```

`fromIntegral`-ও আছে, যা যেকোনো সাংখ্যিক টাইপকে প্রয়োজনমতো অনুমিত সাংখ্যিক টাইপে রূপান্তর করে।

```haskell
fromIntegral 1
-- -> 1.0
```

একটি `Float`-কে `Int`-এ রূপান্তর করতে আপনি [`round`][round], [`floor`][floor] বা [`ceiling`][ceiling] ফাংশনগুলো ব্যবহার করতে পারেন।
`round` ফাংশনটি নিকটতম ইন্টিজারে রাউন্ড করে, `floor` নিচের দিকে রাউন্ড করে, আর `ceiling` ওপরের দিকে রাউন্ড করে।

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## গাণিতিক অপারেটর

সাংখ্যিক টাইপগুলোর ওপর আপনি [মৌলিক গাণিতিক অপারেটরগুলো][math] ব্যবহার করতে পারেন।
অপারেটরগুলো হলো `+`, `-`, `*`, `/` আর `%`.
এই অপারেটরগুলো ব্যবহার করার সময় সংখ্যাগুলোর টাইপ মিলতে হবে।
`fromIntegral` ফাংশনটি এমনভাবে রূপান্তর করবে যাতে টাইপগুলো মিলে যায়।

### যোগ, বিয়োগ ও গুণ

`+` অপারেটরটি যোগের জন্য, `-` অপারেটরটি বিয়োগের জন্য আর `*` অপারেটরটি গুণের জন্য ব্যবহৃত হয়।

| অপারেটর | উদাহরণ        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### ভাগ

সংখ্যা ভাগ করার কাজে ভাগ ব্যবহার করা হয়।
`/` অপারেটরটি ভাগের জন্য ব্যবহৃত হয়।
ফলাফল সবসময় একটি ফ্লোট হবে।

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
কিছু প্রোগ্রামিং ভাষায় শূন্য দিয়ে ভাগ করলে ফলাফল একটি এরর হয়।

Haskell-এ শূন্য দিয়ে ভাগ করলে ফলাফল হয় `Infinity` বা `-Infinity`।
একমাত্র ব্যতিক্রম হলো শূন্যকে শূন্য দিয়ে ভাগ করা, যার ফল হয় `NaN` (Not a Number)।

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## ইন্টিজার ভাগ

ইন্টিজার ভাগ দিয়ে পূর্ণসংখ্যা ভাগ করে ফলাফলের পূর্ণ অংশটি পাওয়া যায়।
Haskell-এ ইন্টিজার ভাগের দুটি ফাংশন আছে, যারা ফলাফল ঋণাত্মক হলে কীভাবে রাউন্ড করবে তা নিয়ে আলাদা:

- `div` নিচের দিকে, ঋণাত্মক ইনফিনিটির দিকে রাউন্ড করে।
- `quot` শূন্যের দিকে রাউন্ড করে।

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
ইন্টিজার ভাগে শূন্য দিয়ে ভাগ করলে একটি Exception হয়।
এটি সাধারণ ভাগ থেকে আলাদা।
~~~~

### ভাগশেষ

ইন্টিজার ভাগের ভাগশেষ `mod` বা `rem` দিয়ে পাওয়া যায়।
সংখ্যাগুলোর একটি ঋণাত্মক হলে ফলাফলের চিহ্ন নিয়ে এরা আলাদা:

- `mod` থাকে `div`-এর সাথে, আর এর ফলাফলের চিহ্ন ভাজকের চিহ্নের মতোই হয়।
- `rem` থাকে `quot`-এর সাথে, আর এর ফলাফলের চিহ্ন ভাজ্যের চিহ্নের মতোই হয়।

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

যেকোনো `x` আর `y`-এর জন্য (যেখানে `y` শূন্য নয়), এই নিয়মগুলো প্রযোজ্য:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
দুটি সংখ্যাই ধনাত্মক হলে `div` আর `quot` একই ফলাফল দেয়, যেমন দেয় `mod` আর `rem`।
সে ক্ষেত্রে `quot` আর `rem` কিছুটা বেশি কার্যকর হতে পারে, কারণ ঋণাত্মক সংখ্যা সামলাতে `div` আর `mod`-এর বাড়তি ধাপ লাগে।
~~~~

~~~~exercism/caution
`mod` বা `rem` দিয়ে শূন্য দিয়ে ভাগ করলে একটি Exception হয়।
এটি সাধারণ ভাগ থেকে আলাদা।

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## সূচকীকরণ

Haskell-এ "পাওয়ারে উন্নীত করার" তিনটি অপারেটর আছে, যারা আলাদাভাবে কাজ করে আর আলাদা ধরনের আর্গুমেন্ট নেয়।

- `**` দুটি **ফ্লোটিং পয়েন্ট সংখ্যা** নেয় আর পাওয়ার হিসাব করতে লগারিদম ব্যবহার করে।
- `^^` একটি **ফ্লোটিং পয়েন্ট** নেয় আর সেটিকে ধনাত্মক বা ঋণাত্মক **ইন্টিজার** পাওয়ারে উন্নীত করে।
- `^` **যেকোনো সাংখ্যিক টাইপ** নেয় আর সেটিকে **ধনাত্মক ইন্টিজার** পাওয়ারে উন্নীত করে।

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## অগ্রাধিকার ও বন্ধনী

Haskell বন্ধনী(`()`) ব্যবহার করতে দেয়, যা দিয়ে এক্সপ্রেশনগুলোকে দলে ভাগ করা যায়।
অপারেশনের ক্রম বদলাতে চাইলে এটি কাজে লাগে।

একাধিক গাণিতিক অপারেটর ব্যবহার করলে অপারেশনের ক্রম গণিতের মতোই হয়, যাকে [PEMDAS][pemdas] বলা হয়।
এটি বন্ধনী(`()`), সূচক(`**`), গুণ(`*`) ও ভাগ(`/`), আর যোগ(`+`) ও বিয়োগ(`-`) এই ক্রমটি অনুসরণ করে।

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
