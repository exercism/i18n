# সম্পর্কে

যখন এমন ডেটা মডেল করা হয় যা কেবল কিছু নির্দিষ্ট সম্ভাব্য অবস্থাতেই থাকতে পারে, যেমন সপ্তাহের বার, কম্পাসের দিক, বা কন্ট্রোলারের বোতাম, তখন `Int` বা `String`-এর মতো বেসিক টাইপ ব্যবহারে বড় বড় অসুবিধা থাকে।
ইন্টিজার বা স্ট্রিং দিয়ে আপনার কোডকে বারবার অবৈধ মান যাচাই করতে হয় (যেমন `999` স্টেটাস কোড, বা `"leftt"`-এর মতো বানান ভুল), আর পড়ার সময় মানুষের পক্ষে বোঝা কঠিন হয়ে পড়ে কোন সংখ্যা কী বোঝায়।

Swift এই সমস্যার সমাধান করে [_এনামারেশন_][enumerations] দিয়ে (প্রায়ই সংক্ষেপে *এনাম* বলা হয়)।
একটি এনাম পরস্পর সম্পর্কিত, নামযুক্ত মানের একটি দলের জন্য একটি কমন টাইপ ডিফাইন করে। যেহেতু কম্পাইলার আগেই সব সম্ভাব্য কেস জানে, তাই এটি কম্পাইল টাইমে আপনার কোডের নির্ভুলতা ও সম্পূর্ণতা যাচাই করতে পারে।
এনামে মেথড, ইনিশিয়ালাইজার আর কম্পিউটেড প্রোপার্টিও থাকতে পারে।

## এনাম ডিফাইন করা

`enum` কিওয়ার্ড ও তারপর টাইপের নাম দিয়ে একটি এনাম ডিফাইন করুন, আর এর কেসগুলো দ্বিতীয় বন্ধনীর ভেতরে তালিকাবদ্ধ করুন।
Swift-এর রীতি অনুযায়ী টাইপের নামে `UpperCamelCase` আর প্রতিটি কেসে `lowerCamelCase` ব্যবহৃত হয়:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

কমা দিয়ে আলাদা করে একই লাইনে 여러 কেস-ও ডিফাইন করতে পারেন:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

একটি এনাম কেস বোঝাতে এনাম টাইপের নাম, একটি ডট (`.`), আর কেসের নাম লিখুন। একবার টাইপ জানা গেলে বা কম্পাইলার সেটি অনুমান করতে পারলে, আপনি টাইপের নাম বাদ দিয়ে ছোট ডট সিনট্যাক্স ব্যবহার করতে পারেন:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## এনাম ও `switch` স্টেটমেন্ট

এনাম [`switch` স্টেটমেন্টের][enums-and-switches] সাথে নির্বিঘ্নে কাজ করে।
যেহেতু Swift-এর একটি `switch`-কে সব কেস কভার করতেই হয়, তাই কম্পাইলার নিশ্চিত করে যে আপনি প্রতিটি সম্ভাব্য কেস সামলেছেন:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

`default` ক্লজ না দিয়ে যদি আপনি কোনো কেস বাদ দেন, কম্পাইলার একটি এরর দেখায়:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

সব কেস আলাদা আলাদা করে তালিকাবদ্ধ করা প্রায়ই `default` ব্যবহারের চেয়ে ভালো। এভাবে, ভবিষ্যতে যদি নতুন একটি কেস যোগ করেন, কম্পাইলার সঙ্গে সঙ্গে আপনাকে সতর্ক করে দেবে যাতে ওই এনাম নিয়ে কাজ করা প্রতিটি `switch` স্টেটমেন্ট আপনি হালনাগাদ করেন।

## মেথড ও ইনিশিয়ালাইজার

এনাম ক্লাস আর স্ট্রাক্টের মতোই মেথড ও কাস্টম ইনিশিয়ালাইজার ডিফাইন করতে পারে। এনামের একটি মেথডের ভেতরে `self` বলতে বর্তমান কেসের মান বোঝায়:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## র ভ্যালু

এনাম কেসগুলো আগে থেকেই ডিফল্ট মান দিয়ে পূরণ করা যায়, যাদের [_র ভ্যালু_][raw-values] বলা হয়।
একটি এনামের সব র ভ্যালু একই টাইপের হতে হয় (যেমন `Int`, `String`, বা `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

আপনি `init(rawValue:)` ব্যবহার করে একটি র ভ্যালু থেকে এনাম ইনিশিয়ালাইজ করতে পারেন। যেহেতু একটি অবৈধ র ভ্যালু দেওয়া হতে পারে, তাই এই ইনিশিয়ালাইজারটি একটি অপশনাল রিটার্ন করে:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift `String` আর `Int` এনামের জন্য স্বয়ংক্রিয়ভাবে র ভ্যালু অ্যাসাইন করতে পারে:

- `String` এনামের জন্য, প্রতিটি কেসের র ভ্যালু ডিফল্টভাবে তার কেসের নাম হয়।
- `Int` এনামের জন্য, অন্যথা নির্দিষ্ট না করলে র ভ্যালু `0` থেকে শুরু করে ১ করে বাড়ে।

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## অ্যাসোসিয়েটেড ভ্যালু

এনাম কেসগুলো প্রতিটি কেসের সাথে مختلف টাইপের কাস্টম মানও সংরক্ষণ করতে পারে, যাদের [_অ্যাসোসিয়েটেড ভ্যালু_][associated-values] বলা হয়:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

একটি এনাম র ভ্যালু বা অ্যাসোসিয়েটেড ভ্যালু, এই দুটোর যেকোনো একটি ব্যবহার করতে পারে, দুটোই নয়।

## রিকার্সিভ এনামারেশন

একটি [রিকার্সিভ এনামারেশন][recursive-enumerations] হলো এমন একটি এনাম যার এক বা একাধিক কেসে অ্যাসোসিয়েটেড ভ্যালু হিসেবে ওই এনামেরই আরেকটি ইনস্ট্যান্স থাকে।
রিকার্সন চালু করতে, কেসটি (বা গোটা এনামটি) `indirect` কিওয়ার্ড দিয়ে চিহ্নিত করুন:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
