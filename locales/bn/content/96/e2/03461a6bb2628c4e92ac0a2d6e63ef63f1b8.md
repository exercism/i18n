# নির্দেশনার সংযোজন

## Stream অ্যাবিলিটি সম্পর্কে

`Stream` হলো Unison-এর একটি অ্যাবিলিটি, যা মান ইমিট করার জন্য ব্যবহার করা হয়।

যদি এমন একটি ফাংশন থাকে যা কল হওয়ার সময় গৌণ ইফেক্ট হিসেবে মান তৈরি করে, তাহলে আপনি `Stream` অ্যাবিলিটি ব্যবহার করতে পারেন। উদাহরণস্বরূপ, এই ফাংশনটি অ্যারের শেষ মান রিটার্ন করে, কিন্তু প্রতিটি এলিমেন্ট দেখার সাথে সাথে একটি চলমান যোগফল ইমিট করে:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

অ্যাবিলিটি হ্যান্ডলারের সাহায্যে যে ফাংশনটি স্ট্রিম তৈরি করে, তার রিটার্ন ভ্যালুর পাশাপাশি আমরা স্ট্রিমটিকে একটি List হিসেবে ম্যাটেরিয়ালাইজ করতে পারি:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
