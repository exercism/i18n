# নির্দেশনা

দাবা খেলার একজন উৎসাহী হিসেবে আপনি খেলাটির নিজের একটি সংস্করণ লিখতে চাইবেন। হ্যাঁ, অনলাইনে দাবার অনেক ইমপ্লিমেন্টেশন হয়তো আগেই পাওয়া যায়, কিন্তু আপনারটি হবে অনন্য!

তবে আপনার কল্পনাকে ডানা মেলতে দেওয়ার আগে প্রাথমিক বিষয়গুলো সামলে নিতে হবে। চলুন বোর্ড তৈরি করে শুরু করি।

দাবার বোর্ডের প্রতিটি ঘর চিহ্নিত করা হয় একটি অক্ষর-সংখ্যার জোড়া দিয়ে। ঘরগুলোর খাড়া কলামগুলোকে বলা হয় ফাইল, যেগুলো A থেকে H পর্যন্ত লেবেল করা। আর আড়াআড়ি সারিগুলোকে বলা হয় র্যাঙ্ক, যেগুলো ১ থেকে ৮ পর্যন্ত সংখ্যায়িত।

## 1. র‍্যাঙ্ক রেঞ্জ ডিফাইন করুন

`rank_range/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ১ থেকে ৮ পর্যন্ত ইন্টিজারের একটি রেঞ্জ রিটার্ন করবে।

```elixir
Chessboard.rank_range()
```

## 2. ফাইল রেঞ্জ ডিফাইন করুন

`file_range/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি বড় হাতের অক্ষর A-এর কোড পয়েন্ট থেকে বড় হাতের অক্ষর H-এর কোড পয়েন্ট পর্যন্ত ইন্টিজারের একটি রেঞ্জ রিটার্ন করবে।

```elixir
Chessboard.file_range()
```

## 3. র‍্যাঙ্ক রেঞ্জকে র‍্যাঙ্কের অ্যারেতে রূপান্তর করুন

`ranks/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ১ থেকে ৮ পর্যন্ত ইন্টিজারের একটি অ্যারে রিটার্ন করবে। অ্যারেটি হাতে লিখবেন না, `rank_range/0` ফাংশন থেকে পাওয়া রেঞ্জ থেকে এটি তৈরি করুন।

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. ফাইল রেঞ্জকে ফাইলের অ্যারেতে রূপান্তর করুন

`files/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি "A" থেকে "H" পর্যন্ত অক্ষরের (স্ট্রিং) একটি অ্যারে রিটার্ন করবে। অ্যারেটি হাতে লিখবেন না, `file_range/0` ফাংশন থেকে পাওয়া রেঞ্জ থেকে এটি তৈরি করুন।

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
