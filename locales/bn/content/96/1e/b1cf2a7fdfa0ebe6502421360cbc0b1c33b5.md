# পরিচিতি

C#-এ, একটি মানের অনুপস্থিতি বোঝাতে [`null` লিটারালটি][null-keyword] ব্যবহার করা হয়। একটি _নালেবল_ টাইপ হলো এমন একটি টাইপ, যা `null` মান গ্রহণ করতে দেয়।

C# 8.0-এর আগে, রেফারেন্স টাইপগুলো সবসময়ই নালেবল ছিল, আর ভ্যালু টাইপগুলো ছিল না। তবে একটি ভ্যালু টাইপের শেষে প্রশ্নচিহ্ন (`?`) যোগ করে [সেটিকে নালেবল করা যায়][nullable-value-types]।

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

যে ভ্যারিয়েবলের মান `null`, তার কোনো মেম্বার অ্যাক্সেস করলে কম্পাইল ঠিকঠাক হবে, কিন্তু রানটাইমে একটি `NullReferenceException` ছুঁড়ে ফেলা হবে:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

এই কমন ধরনের ভুল ঠেকাতে, C# 8 একটি ফিচার [ব্যবহার করার সুযোগ দেয়][nullable-csharp-8], যা [ডিফল্টভাবে রেফারেন্স টাইপগুলোকে নন-নালেবল করে তোলে][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

নালেবল মান নিয়ে [নিরাপদে কাজ করতে][nullable-types-tutorial], সেগুলো নিয়ে কাজ করার আগে সেগুলো `null` কি না তা যাচাই করা উচিত:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

কোনো মান `null` হলে [`??` অপারেটরটি][null-coalescing-operator] একটি ডিফল্ট মান রিটার্ন করার সুযোগ দেয়:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

সম্ভাব্য `null` মানের ওপর নিরাপদে মেম্বার কল করতে [`?.` অপারেটরটি][null-conditional-operator] সুযোগ দেয়:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

কম্পাইলার যদি মনে করে কোনো মান `null` হতে পারে, কিন্তু আপনি নিশ্চিত যে তা হবে না, তাহলে ওয়ার্নিং চাপা দিতে [`!.` অপারেটরটি][null-forgiving-operator] ব্যবহার করা যায়। তবে এই অপারেটরটি কেবল শেষ উপায় হিসেবেই ব্যবহার করুন।

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
