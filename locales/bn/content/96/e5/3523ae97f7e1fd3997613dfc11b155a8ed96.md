# অপ্রয়োজনীয় `if` স্টেটমেন্ট

একটি `if (...) {}` ব্লক তৈরি না করে, প্যারামিটারের মান যাচাই করে সরাসরি যে বুলিয়ান মানটি পাওয়া যায়, সেটিই ব্যবহার করুন।

উদাহরণস্বরূপ, নিচের কোডটি:

```javascript
if (param === true) {
  return true;
}
```

এভাবে লেখা যেতে পারে:

```javascript
return param === true;
```
