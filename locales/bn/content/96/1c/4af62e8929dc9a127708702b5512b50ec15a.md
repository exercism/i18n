# পরিচিতি

## ভ্যারিয়েবল

Elixir একটি ডাইনামিক টাইপড প্রোগ্রামিং ভাষা, অর্থাৎ একটি ভ্যারিয়েবলের টাইপ শুধু রানটাইমে যাচাই করা হয়। ম্যাচ `=` অপারেটর ব্যবহার করে যেকোনো টাইপের একটি মান একটি ভ্যারিয়েবলের নামের সাথে বাইন্ড করা যায়:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## মডিউল

Elixir একটি [ফাংশনাল প্রোগ্রামিং ভাষা][functional-programming] এবং এতে সব নেমড ফাংশন একটি _মডিউলে_ ডিফাইন করতে হয়। মডিউল ডিফাইন করতে `defmodule` কিওয়ার্ডটি ব্যবহার করা হয়। সব মডিউল রানটাইমে অন্য সব মডিউলের কাছে উপলব্ধ থাকে এবং প্রোগ্রামের অন্য অংশের কাছে সেগুলো দৃশ্যমান করতে কোনো _অ্যাক্সেস মডিফায়ারের_ দরকার হয় না। একটি _মডিউল_ অন্য প্রোগ্রামিং ভাষার _ক্লাসের_ মতো।

```elixir
defmodule Calculator do
  # ...
end
```

## নেমড ফাংশন

_নেমড ফাংশন_ একটি মডিউলে ডিফাইন করতে হয়। একটি _পাবলিক_ নেমড ফাংশন ডিফাইন করতে `def` কিওয়ার্ডটি ব্যবহার করা হয়।

প্রতিটি ফাংশনে শূন্য বা তার বেশি আর্গুমেন্ট থাকতে পারে। কোনো ফাংশনের শেষ এক্সপ্রেশনের মান সবসময় _অন্তর্নিহিতভাবে রিটার্ন করা হয়_।

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

ফাংশন কল করার জন্য তার মডিউল ও ফাংশনের নাম উল্লেখ করে ফাংশনের প্রতিটি আর্গুমেন্টের জন্য মান পাস করতে হয়।

```elixir
sum = Calculator.add(1, 2)
# => 3
```

একটি _প্রাইভেট_ ফাংশন ডিফাইন করতে `def`-এর বদলে `defp` কিওয়ার্ড ব্যবহার করা যায়। প্রাইভেট ফাংশন শুধু যে মডিউল সেগুলো ডিফাইন করেছে তার ভেতর থেকেই ব্যবহার করা যায়।

একই মডিউলের ভেতরে থাকা কোনো ফাংশন কল করার সময় যে মডিউলে এটি ডিফাইন করা হয়েছে তার নাম বাদ দেওয়া যায়।

আপনি এক লাইনের সিনট্যাক্স ব্যবহার করে ছোট ফাংশনও লিখতে পারেন (কিওয়ার্ড `do`-এর ঠিক আগে থাকা কমা `,` ও কোলন `:` লক্ষ্য করুন)।

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## ফাংশনের আরিটি

ফাংশনকে সাধারণত তার _আরিটি_ দিয়ে বোঝানো হয়। একটি ফাংশনের _আরিটি_ বলতে সে যে সংখ্যক আর্গুমেন্ট গ্রহণ করে সেই সংখ্যাকে বোঝায়।

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## নামকরণের নিয়ম

মডিউলের নামে `PascalCase` ব্যবহার করা উচিত। মডিউলের নাম অবশ্যই একটি বড় হাতের অক্ষর `A-Z` দিয়ে শুরু হতে হবে এবং এতে অক্ষর `a-zA-Z`, সংখ্যা `0-9` ও আন্ডারস্কোর `_` থাকতে পারে।

ভ্যারিয়েবল ও ফাংশনের নামে `snake_case` ব্যবহার করা উচিত। ভ্যারিয়েবল বা ফাংশনের নাম অবশ্যই একটি ছোট হাতের অক্ষর `a-z` বা একটি আন্ডারস্কোর `_` দিয়ে শুরু হতে হবে, এতে অক্ষর `a-zA-Z`, সংখ্যা `0-9` ও আন্ডারস্কোর `_` থাকতে পারে, এবং নামের শেষে একটি প্রশ্নবোধক চিহ্ন `?` বা বিস্ময়বোধক চিহ্ন `!` থাকতে পারে।

## স্ট্যান্ডার্ড লাইব্রেরি

Elixir-এ খুব সমৃদ্ধ ও সুন্দরভাবে ডকুমেন্ট করা স্ট্যান্ডার্ড লাইব্রেরি আছে। ডকুমেন্টেশন অনলাইনে [hexdocs.pm/elixir][docs]-এ পাওয়া যায়। এই লিংকটি কোথাও সংরক্ষণ করে রাখুন, আপনি এটি অনেকবার ব্যবহার করবেন!

বেশিরভাগ বিল্ট-ইন ডেটা টাইপের জন্য একটি সংশ্লিষ্ট মডিউল থাকে, যা ওই ডেটা টাইপ নিয়ে কাজ করার ফাংশন দেয়। যেমন ইন্টিজারের জন্য `Integer` মডিউল, স্ট্রিংয়ের জন্য `String` মডিউল, লিস্টের জন্য `List` মডিউল ইত্যাদি।

একটি উল্লেখযোগ্য মডিউল হলো `Kernel` মডিউল। স্ট্যান্ডার্ড লাইব্রেরির বাকি অংশ যেসব মৌলিক সুবিধার উপরে তৈরি, সেগুলো এটি দেয়, যেমন গাণিতিক অপারেটর, কন্ট্রোল-ফ্লো ম্যাক্রো এবং আরও অনেক কিছু। `Kernel` মডিউলের ফাংশনগুলো স্বয়ংক্রিয়ভাবে ইমপোর্ট করা হয়, তাই `Kernel.` প্রিফিক্স ছাড়াই সেগুলো ব্যবহার করতে পারেন।
