# পরিচিতি

Elm নির্ভরযোগ্য ওয়েব অ্যাপ্লিকেশন তৈরির জন্য একটি দারুণ প্রোগ্রামিং ভাষা। এতে আছে বন্ধুত্বপূর্ণ এরর মেসেজ, দুর্দান্ত পারফরম্যান্স, ছোট অ্যাসেট, আর কোনো রানটাইম এক্সেপশন নেই।

Elm-এর সম্ভবত সবচেয়ে বিখ্যাত এবং সবচেয়ে বেশি অনুসরণ করা অংশটি হলো The Elm Architecture, যা ওয়েব অ্যাপ্লিকেশন গঠন করার একটি সরল প্যাটার্ন, আর Elm-এর সব ওয়েব অ্যাপ্লিকেশনই এভাবে লেখা হয়।

মূল ধারণাটি হলো, আপনার কোড তৈরি হয় অ্যাপ্লিকেশনের স্টেটের একটি `Model`, সেই মডেল `update` করার একটি উপায় আর সেই মডেল `view` করার একটি উপায়কে ঘিরে।

`Model`-এ অ্যাপ্লিকেশনের স্টেট থাকে, অর্থাৎ অ্যাপ্লিকেশনের প্রয়োজনীয় সব ডেটা। এটি যেকোনো টাইপ হতে পারে, তবে যেকোনো কাজের অ্যাপ্লিকেশনে এটি সাধারণত একটি [রেকর্ড][record] হয়ে থাকে। যদি আপনি একটি সাধারণ অ্যাপ্লিকেশনের কথা ভাবেন যেখানে একটি টেক্সট বক্স আছে আর সেই টেক্সটের উল্টো রূপ দেখানো টেক্সট আছে, তাহলে মডেলটি দেখতে নিচের মতো হবে। আপনি এই উদাহরণটি [Elm গাইড][elm-guide-text-fields]-এও দেখতে পারেন।

```elm
type alias Model =
  { text : String
  }
```

`update` হলো এমন একটি ফাংশন, যা কোনো পরিবর্তন ঘটলে (যেমন ব্যবহারকারীর একটি বাটনে ক্লিক করা) একটি `Msg` নিয়ে কল করা হয়। এটি `Msg` আর বর্তমান `Model` নেয়, এবং একটি নতুন `Model` রিটার্ন করে। `Msg` যেকোনো টাইপ হতে পারে, তবে সাধারণত এটি একটি [কাস্টম টাইপ][custom-type] হয়।

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

সব কাস্টম টাইপের মতোই, `Msg`-এর ভ্যারিয়েন্টগুলো তাদের প্রয়োজন অনুযায়ী যত খুশি তথ্য ধারণ করতে পারে। উপরের উদাহরণে `TextChanged` ভ্যারিয়েন্টটি একটি `String` ধারণ করে।

`view` হলো এমন একটি ফাংশন, যা ব্রাউজারে ব্যবহারকারীকে দেখানোর জন্য HTML রিটার্ন করে। এটি বর্তমান `Model` নেয় আর একটি `Html Msg` রিটার্ন করে (HTML বোঝাতে Elm যে টাইপটি ব্যবহার করে)। প্রতিটি HTML এলিমেন্টের (যেমন `<div>`) জন্য `Html` প্যাকেজে সংশ্লিষ্ট একটি Elm ফাংশন (`Html.div`) থাকে। এই ফাংশনগুলোর প্রত্যেকটি দুটি প্যারামিটার নেয়: প্রথমটি অ্যাট্রিবিউটের একটি অ্যারে (`Html.Attributes` আর `Html.Events` প্যাকেজ থেকে), আর দ্বিতীয়টি চাইল্ড এলিমেন্টের একটি অ্যারে (`Html` প্যাকেজের ফাংশন)। এছাড়া একটি `text` ফাংশনও আছে, যা HTML স্ট্রিং কনটেন্ট বোঝায়; এটি শুধু একটি স্ট্রিং প্যারামিটার নেয়, তবে বাকি সব দিক থেকে `Html` প্যাকেজের অন্য সব ফাংশন বা এলিমেন্টের মতোই ব্যবহৃত হয়।

`view` ফাংশনটি নির্দিষ্ট করতে পারে যে বাটনে ক্লিক করা বা টেক্সট বক্সে টেক্সট সম্পাদনার মতো কিছু ইভেন্টের ফলে একটি `Msg` তৈরি হয়, যা Elm Runtime ব্যবহার করে `update` ফাংশন কল করতে, `Model` পরিবর্তন করতে আর হালনাগাদ করা HTML তৈরি করতে। নিচের কোডে এটি ঘটে `Html.Events.onInput TextChanged` দিয়ে।

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

`Html.Events.onInput` একটি ফাংশন (`String -> Msg`) পাস করার প্রত্যাশা করে, যা দিয়ে এটি `Msg` তৈরি করবে। কোন ইভেন্ট কী তথ্য দিতে পারে তার উপর নির্ভর করে ভিন্ন ইভেন্ট ভিন্ন ফাংশন প্রত্যাশা করে; যেমন `Html.Events.onCheck` (চেকবক্সের জন্য) `Bool -> Msg` প্রত্যাশা করে, আর `Html.Events.onClick` শুধু একটি `Msg` প্রত্যাশা করে।

Elm ভাষাটি পিউর ও ফাংশনাল, আর এতে কোনো মিউটেশন সম্ভব নয়, তাই পরিবর্তনশীল সব কিছু Elm Runtime সামলায়। আপনি Elm প্যাকেজ রেজিস্ট্রিতে সব রকম [HTML এলিমেন্ট][html-elements], [এলিমেন্ট অ্যাট্রিবিউট][element-attributes] আর [HTML ইভেন্ট][html-events] দেখতে পারেন।

Elm-এ আপনি ৪টি "লেভেল"-এর ওয়েব অ্যাপ্লিকেশন লিখতে পারেন, যেগুলো ক্রমে আরও শক্তিশালী আর আরও জটিল হয়ে ওঠে (যদিও Elm একটি দুর্দান্ত সরল প্রোগ্রামিং ভাষা আর ইকোসিস্টেম হিসেবেই থাকে)। এগুলো সবই [Browser প্যাকেজ][browser-package]-এ সংজ্ঞায়িত:

- [sandbox][browser-sandbox]: বাটন আর চেকবক্সের মতো ব্যবহারকারীর ইনপুটে সাড়া দেয়
- [element][browser-element]: HTTP আর JavaScript ইন্টারঅপ ব্যবহার করে বাইরের জগতের সাথে কথা বলে
- [document][browser-document]: একটি ওয়েব পেজের `<title>` আর `<body>` নিয়ন্ত্রণ করে
- [application][browser-application]: রাউটিং / url পরিবর্তন সামলানো পূর্ণাঙ্গ সিঙ্গেল-পেজ অ্যাপ্লিকেশন তৈরি করে

এই কনসেপ্টে [sandbox][browser-sandbox] ব্যবহার করা হয়েছে, কারণ এটি সবচেয়ে সরল (আর যেহেতু এটি একটি sandbox, Exercism অনলাইন এডিটরের সাথে কাজ করা তুলনামূলক সহজ)। একটি Elm প্রোগ্রামের এন্ট্রি মডিউলের নাম অবশ্যই `Main` হতে হবে, আর যে ফাংশনটি অ্যাপ্লিকেশন তৈরি করে তার নাম হতে হবে `main`, নিচের মতো।

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

আমরা ইতিমধ্যেই `update` আর `view` ফাংশন দেখেছি, আর [sandbox][browser-sandbox]-এর জন্য অতিরিক্তভাবে একটি `init` ফাংশন প্রয়োজন, যা `Model`-এর প্রাথমিক স্টেট রিটার্ন করে।
