# Null

Null হলো একটি প্রিমিটিভ ভ্যালু টাইপ, যার মান কেবল একটি: `null`।
Null প্রায়ই কিছু না থাকা বা শূন্যতা বোঝাতে ব্যবহৃত হয়।
এটিকে "ফালসি" ধরা হয়, তবে এটি `false` এবং অন্য ফালসি মান থেকে আলাদা।

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Null মান নিয়ে কাজ করা

PHP-তে, null মান প্রায়ই এররের একটি কমন কারণ হয়ে দাঁড়ায়, কারণ এরর অবস্থার জায়গায় বা কিছু না থাকা বোঝাতে এগুলো প্রায়ই রিটার্ন করা হয়।
এরর যাতে না হয়, সেজন্য প্রায়ই মানটির উপর কাজ করার আগে "null-checking" করে নিশ্চিত করতে হয় যে সেটি null নয়।

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

বারবার null-checking করা ভুল হওয়ার সম্ভাবনা বাড়ায়, তাই null মান নিয়ে কাজ করার জন্য PHP দুটি অপারেটর দেয়: null-safe অ্যাক্সেস `?->` অপারেটর এবং null কোয়ালেসিং `??` অপারেটর।

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
