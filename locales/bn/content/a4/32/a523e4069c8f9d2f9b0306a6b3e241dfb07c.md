# পরিচিতি

## টাইপ অ্যালিয়াস

Gleam-এ টাইপ অ্যালিয়াস দিয়ে এমন একটি বিদ্যমান টাইপের সুবিধাজনক নাম দেওয়া যায়, যেটি অন্যথায় লিখতে ঝামেলা হতো।

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type` দিয়ে লিখলে অ্যালিয়াসটি যে মডিউলের ভেতরে ডিফাইন করা হয়েছে, তার বাইরেও ব্যবহার করা যায়। `pub` বাদ দিলে অ্যালিয়াসটি প্রাইভেট হয়ে যায় এবং অন্য মডিউলে এটির রেফারেন্স দেওয়া যায় না।
