# ভূমিকা

স্পেশাল ফর্ম `import` আপনাকে একটি বাইরের মডিউল থেকে ফাংশন ব্যবহার করতে দেয়, মডিউলটির নাম ব্যবহার না করেই।

একটি সম্পূর্ণ বাইরের মডিউল ইমপোর্ট করলে বিদ্যমান লোকাল ফাংশনগুলির সাথে দ্বন্দ্ব তৈরি হতে পারে। এটি এড়ানোর জন্য দুটি অপশন আছে: `:except` এবং `:only`। দুটিই একটি কিওয়ার্ড লিস্ট আশা করে, যেখানে কী (key) হলো ফাংশনের নাম, এবং মান হলো ফাংশনের অ্যারিটি।

সাধারণত ইমপোর্টগুলো মডিউল ডেফিনিশনের শুরুতে যোগ করা হয়।

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
