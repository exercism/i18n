# পরিচিতি

Clojure-এ একটি মানকে একটি নামের সাথে বেঁধে রাখাকে _ভ্যার_ বলা হয়। টপ-লেভেল (গ্লোবাল) ভ্যারগুলো অন্য ভাষার কনস্ট্যান্টের মতোই, তবে ডাইনামিক ডেভেলপমেন্ট সহজ করতে এগুলো সাধারণত নতুন করে ডিফাইন করা হয়।

টপ-লেভেল ভ্যার ডিফাইন করা হয় `def` দিয়ে:

```clojure
(def fingers 10)
```

`defn` ম্যাক্রো দিয়ে এমন একটি ফাংশন ডিফাইন করা যায়, যেটি শূন্য বা তার বেশি আর্গুমেন্ট নেয়। একটি ফাংশন সবসময় তার বডির শেষ এক্সপ্রেশনের ফলাফল রিটার্ন করে।

```clojure
(defn add [x y]
  (+ x y))
```

কোনো ফাংশন কল করতে হলে তার নাম লিখতে হয় এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করতে হয়।

```clojure
(def five (add 2 3))
```

Clojure-এ ফাংশন আর মান কেবল এগুলো ডিফাইন করার _পরেই_ ব্যবহার করা যায়। ডিফাইন করার আগে ব্যবহার করলে কম্পাইল এরর হয়।

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Clojure-এ হোয়াইটস্পেসের ফরম্যাটিং ছাড়া আর কোনো তাৎপর্য নেই।

Clojure-এর ফাংশন ও ভ্যারগুলো নেমস্পেসে সাজানো থাকে। একটি নেমস্পেস সম্পর্কিত কার্যকারিতা একত্র করে এবং `ns` ম্যাক্রো দিয়ে ডিফাইন করা হয়:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure দুই ধরনের কমেন্ট সমর্থন করে। এক লাইনের কমেন্টের আগে `;` থাকে, আর `comment` ফর্মটি `(comment` ও `)`-এর মধ্যবর্তী সবকিছুর ইভ্যালুয়েশন ঠেকাতে ব্যবহার করা হয়।
