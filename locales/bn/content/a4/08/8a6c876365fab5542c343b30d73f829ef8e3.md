# এনাম

এনাম হলো Cairo-এর একটি ডেটা টাইপ, যা কোডের পাঠযোগ্যতা ও নিরাপত্তার জন্য কিছু পূর্বনির্ধারিত ভ্যারিয়েন্টের একটি সেট সংজ্ঞায়িত করতে ব্যবহৃত হয়।
Cairo-তে `enum`-এর ভ্যারিয়েন্টগুলোকে ভিন্ন ভিন্ন ডেটা টাইপ (ইন্টিজার, স্ট্রাক্ট, টাপল, অন্য এনাম ইত্যাদি) ধারণ করার জন্য ঘোষণা করা যায়।

নিচের কোড স্নিপেটে দেখানো হয়েছে কীভাবে এনাম সংজ্ঞায়িত করা যায়:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

উপরে ঘোষণা করা `Direction` এনামটি চারটি ভ্যারিয়েন্টের একটি সরল এনাম: `North`, `East`, `South` এবং `West`।
এনামের ভ্যারিয়েন্টের জন্য নামকরণের রীতি হলো PascalCase ব্যবহার করা।
প্রতিটি ভ্যারিয়েন্ট `Direction` এনাম টাইপের একটি আলাদা মান প্রকাশ করে।
এই নির্দিষ্ট এনাম উদাহরণের প্রতিটি ভ্যারিয়েন্টের সঙ্গে কোনো মান যুক্ত নেই, আর এগুলো এই সিনট্যাক্সে ইনস্ট্যানশিয়েট করা যায়:

```rust
let direction = Direction::North;
```

নিচে একই `Direction` এনাম দেওয়া হলো, তবে এবার এমন ভ্যারিয়েন্ট নিয়ে যেগুলোর সঙ্গে যুক্ত মান আছে, যা দিকটির সঠিক ডিগ্রি সংরক্ষণ করে:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

এই উদাহরণ থেকে স্পষ্ট যে `Direction` এনামের প্রতিটি ভ্যারিয়েন্টের সঙ্গে `u128` টাইপের একটি যুক্ত মান আছে।
এই ধরনের এনাম এভাবে ইনস্ট্যানশিয়েট করা যায়:

```rust
let direction = Direction::North(10);
```

## কাস্টম টাইপ নিয়ে জটিল এনামের উদাহরণ

ভিন্ন ভিন্ন ডেটা টাইপের সমন্বয়ে একটি এনামের ভ্যারিয়েন্ট ঘোষণা করা যায়।
নিচের উদাহরণে `Action` একটি জটিল এনাম, যার ভ্যারিয়েন্ট হিসেবে আছে `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` এবং `ProfileState`।

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## এনামের জন্য ট্রেইট ইমপ্লিমেন্টেশন

Cairo-তে কাস্টম এনামের উপর ট্রেইট সংজ্ঞায়িত ও ইমপ্লিমেন্ট করা যায়।
এতে আপনি একটি এনামের সঙ্গে যুক্ত মেথড ও অ্যাট্রিবিউট সংজ্ঞায়িত করতে পারেন।
নিচে এর একটি উদাহরণ দেওয়া হলো, যেখানে আমরা একটি `Message` এনাম সংজ্ঞায়িত করি এবং তার জন্য একটি `Processing` ট্রেইট ইমপ্লিমেন্ট করি:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

এখানে দেখানো হলো কীভাবে ট্রেইটটি একটি `Quit` মেসেজ প্রসেস করতে ব্যবহার করা যায়:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

অনেক ক্ষেত্রেই এনাম কাজে আসে, বিশেষ করে `match` ফ্লো-এর সঙ্গে ব্যবহার করলে, যেমনটি উপরে ট্রেইট ইমপ্লিমেন্টেশনে করা হয়েছে।
`match` ফ্লো সম্পর্কে আরও পড়ুন [The Cairo Book][match]-এ।
