# সম্পর্কে

[ভার্বাটিম স্ট্রিংগুলো][verbatim-strings] মাল্টি-লাইন স্ট্রিং লেখার সুযোগ দেয়। এগুলো @ দিয়ে শুরু হয়। এগুলো স্ট্রিং ইন্টারপোলেশনের সাথে ব্যবহার করা যায়। শুরুর উদ্ধৃতি চিহ্নের আগে শুধু "\$" যোগ করুন।

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
