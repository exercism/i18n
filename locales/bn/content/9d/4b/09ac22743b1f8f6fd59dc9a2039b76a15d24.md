# ভূমিকা

## JavaScript-এ রেগুলার এক্সপ্রেশন

একটি [রেগুলার এক্সপ্রেশন][mdn-regular-expressions] (বা Regex) হলো ক্যারেক্টারের একটি ক্রম, যা দিয়ে আমরা স্ট্রিংয়ের নির্দিষ্ট কিছু এলিমেন্ট লক্ষ্য করতে ও সেগুলো নিয়ে কাজ করতে পারি। তাই আমরা করতে পারি:

- স্ট্রিংয়ের মধ্যে একটি টেক্সট **সার্চ করা**
- স্ট্রিংয়ের সাবস্ট্রিং **রিপ্লেস করা**
- স্ট্রিং থেকে তথ্য **এক্সট্র্যাক্ট করা**

> 💡 JavaScript-এর রেগেক্স ফ্লেভার ভাষাটির ECMA-262 স্ট্যান্ডার্ডের অংশ। এর মানে হলো, ব্রাউজার-নির্দিষ্ট কম্প্যাটিবিলিটি নিয়ে আপনাকে ভাবতে হবে না।

## রেগুলার এক্সপ্রেশন কীভাবে তৈরি করবেন

JavaScript-এ রেগুলার এক্সপ্রেশন সাধারণত `/pattern/modifiers` ফরম্যাটে লেখা হয়।

রেগুলার এক্সপ্রেশন তৈরির দুটি উপায় আছে:

1. **রেগুলার এক্সপ্রেশন লিটারাল**:

```javascript
const regex = /[a-z]/;
```

2. কনস্ট্রাক্টর **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

দুটি ক্ষেত্রেই JavaScript রেগেক্স থেকে একটি অবজেক্ট তৈরি করে। ডিফল্ট হিসেবে লিটারাল নিয়ে ইমিউটেবল প্যাটার্ন ব্যবহার করার পরামর্শ দেওয়া হয়।

যেসব ক্ষেত্রে রেগেক্স বদলাবে বা আমরা এখনো তা জানি না (যেমন কোনো ইনপুট), সেখানে RegExp কনস্ট্রাক্টর ব্যবহার করা যেতে পারে।

## 🏴‍☠️ ফ্ল্যাগ

রেগুলার এক্সপ্রেশনের [`flags`][mdn-flags] নামের ঐচ্ছিক সুপারপাওয়ার আছে, যা বাড়তি ফিচার ব্যবহারের সুযোগ দেয়।

বেশ জনপ্রিয় কিছু ফ্ল্যাগ হলো:

- `/g` - গ্লোবাল সার্চ
- `/i` - কেস ইনসেনসিটিভ
- `/m` - মাল্টিলাইন সার্চ

এখানে একটি সহজ উদাহরণ:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

`g` ক্যারেক্টারটি স্ট্রিংয়ের ভেতরে সম্ভাব্য সব ম্যাচ পার্স করার সুযোগ দেয়। এই ফিচারটি ছাড়া JavaScript কেবল প্রথম `Home` ম্যাচটিই এক্সট্র্যাক্ট করত।

কেস ইনসেনসিটিভ ফ্ল্যাগ `/i` কোনো প্যাটার্ন খোঁজার সময় আমাদের নমনীয় হতে দেয়। এভাবে আমরা যা খুঁজছি সেটি `UPPERCASE`-এ লেখা হোক বা `lowercase`-এ, কিছু যায় আসে না।

`RegExp` কনস্ট্রাক্টর ব্যবহার করার সময় ফ্ল্যাগ যোগ করার সিনট্যাক্স আলাদা।

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## সবচেয়ে কমন ফাংশন

JavaScript-এর বর্তমান বিল্ট-ইন ফাংশনগুলোর সাথে রেগুলার এক্সপ্রেশন মিলিয়ে ব্যবহার করলে স্ট্রিং থেকে ডেটা বের করা ও তা নিয়ে কাজ করার বেশ শক্তিশালী সব উপায় হাতে আসে।

রেগেক্সের সাথে ব্যবহৃত সবচেয়ে কমন কিছু ফাংশন নিচে দেওয়া হলো।

### Test

[test()][mdn-regex-test] মেথডটি একটি রেগুলার এক্সপ্রেশন ও নির্দিষ্ট একটি স্ট্রিংয়ের মধ্যে ম্যাচ আছে কি না তা সার্চ করে। এটি ট্রু বা ফলস রিটার্ন করে।

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

[match()][mdn-regex-match] মেথড দিয়ে আমরা একটি দরকারি অ্যারে পাই, যার ভেতরের এলিমেন্ট নির্ভর করে খুঁজে পাওয়া ম্যাচগুলো আছে কি নেই তার উপর।

এভাবে আমরা যেকোনো স্ট্রিং থেকে তথ্য **সার্চ** ও **এক্সট্র্যাক্ট** দুটোই করতে পারি। যেমন:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

গ্লোবাল সার্চ ফ্ল্যাগ `/g` থাকলে মেথডটি কেবল একটি ম্যাচ আর তার সাথে index বা input-এর মতো দরকারি তথ্য না দিয়ে অ্যারেতে থাকা সব ম্যাচ রিটার্ন করে:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScript-এর [replace()][mdn-regex-replace] মেথড দিয়ে আমরা কোনো নির্দিষ্ট স্ট্রিংয়ের ভেতরে একটি মান খুঁজে সেটিকে পছন্দের নতুন একটি মান দিয়ে রিপ্লেস করতে পারি।

```javascript
string.replace(searchValue, newValue);
```

যে প্যাটার্ন দিয়ে প্রতিস্থাপনটি খোঁজা হবে, সেটি একটি সাধারণ স্ট্রিং বা একটি রেগুলার এক্সপ্রেশন হতে পারে।

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

এর বাইরে, প্রতিটি মানে বাড়তি পরিবর্তন আনতে আমরা রিপ্লেসমেন্টের জায়গায় একটি ফাংশনও দিতে পারি।

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### Split

JavaScript-এর [split()][mdn-regex-split] মেথড রেগুলার এক্সপ্রেশন দিয়ে স্ট্রিং নিয়ে কাজ করার আরেকটি ভিন্ন উপায়।

এখানে আমরা একটি প্যাটার্ন চিনে নিয়ে নির্দিষ্ট একটি স্ট্রিং ভাগ করতে রেগেক্স ব্যবহার করি, যেমন `str.split(/[,.\s]/)`। এই প্যাটার্নটিই `separator` হিসেবে কাজ করে।

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
