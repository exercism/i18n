# নির্দেশনা

এই অনুশীলনীতে আপনি একটি গাড়ি কারখানার উৎপাদন বিশ্লেষণ করার কোড লিখবেন।

## 1. প্রতি ঘণ্টায় উৎপাদিত কার্যকর গাড়ির সংখ্যা গণনা করুন

গাড়িগুলো একটি অ্যাসেম্বলি লাইনে উৎপাদিত হয়।
অ্যাসেম্বলি লাইনের একটি নির্দিষ্ট গতি থাকে, যা পরিবর্তন করা যায়।
অ্যাসেম্বলি লাইনের গতি যত বেশি হয়, তত বেশি গাড়ি উৎপাদিত হয়।
তবে অ্যাসেম্বলি লাইনের গতি পরিবর্তন করলে সফলভাবে উৎপাদিত গাড়ির সংখ্যাও পরিবর্তিত হয়, অর্থাৎ যেসব গাড়ির উৎপাদনে কোনো এরর থাকে না।

এমন একটি ফাংশন লিখুন, যা প্রতি ঘণ্টায় উৎপাদিত গাড়ির সংখ্যা ও সফলতার হার নিয়ে প্রতি ঘণ্টায় উৎপাদিত সফল গাড়ির সংখ্যা গণনা করে।
সফলতার হার শতকরা হিসেবে দেওয়া হয়, `0` থেকে `100` পর্যন্ত:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**নোট:** রিটার্ন ভ্যালুটি একটি `float64` হওয়া উচিত।

## 2. প্রতি মিনিটে উৎপাদিত কার্যকর গাড়ির সংখ্যা গণনা করুন

এমন একটি ফাংশন লিখুন, যা প্রতি ঘণ্টায় উৎপাদিত গাড়ির সংখ্যা ও সফলতার হার নিয়ে গণনা করে প্রতি মিনিটে কতগুলো গাড়ি সফলভাবে উৎপাদিত হয়:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**নোট:** রিটার্ন ভ্যালুটি একটি `int` হওয়া উচিত।

## 3. উৎপাদনের খরচ গণনা করুন

সাধারণভাবে প্রতিটি গাড়ি আলাদাভাবে উৎপাদন করতে $১০,০০০ খরচ হয়, সেটি সফল হোক বা না হোক।
কিন্তু একটু পরিকল্পনা করলে ১০টি গাড়ি একসাথে $৯৫,০০০-এ উৎপাদন করা যায়।

যেমন, ৩৭টি গাড়ি নিচের উপায়ে উৎপাদন করা যায়:
৩৭ = ৩ x দশের দল + ৭টি আলাদা গাড়ি

তাহলে ৩৭টি গাড়ির খরচ হলো:
৩\*৯৫,০০০+৭\*১০,০০০=৩৫৫,০০০

`CalculateCost` ফাংশনটি লিখুন, যা একটি নির্দিষ্ট সংখ্যক গাড়ি উৎপাদনের খরচ গণনা করে, সেগুলো সফল হোক বা না হোক:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**নোট:** রিটার্ন ভ্যালুটি একটি `uint` হওয়া উচিত।
