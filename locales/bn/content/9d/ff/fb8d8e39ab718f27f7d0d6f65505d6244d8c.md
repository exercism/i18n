# নির্দেশনা সংযোজন

আউটপুটটি [রো-মেজর অর্ডারে](https://en.wikipedia.org/wiki/Row-_and_column-major_order) সাজানো উচিত: প্রথম সারির সব ওয়ার্ড, তারপর দ্বিতীয় সারির ওয়ার্ড, এভাবে চলতে থাকবে।

## রেজিস্টার

| Register | Usage        | Type    | Description                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | আকার                                |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | রো-মেজর অর্ডারে সাজানো ওয়ার্ডের ম্যাট্রিক্স |
| `$v0`    | আউটপুট       | ইন্টিজার | ম্যাট্রিক্সের ওয়ার্ডের সংখ্যা       |
| `$t0-9`  | টেম্পোরারি    | যেকোনো  | সাময়িক সংরক্ষণের জন্য              |
