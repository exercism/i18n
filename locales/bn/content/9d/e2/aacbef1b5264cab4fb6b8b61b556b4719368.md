# Tests

একটি Clojurescript REPL-এর সাহায্যে আপনি সহজেই কোড রান করে সঙ্গে সঙ্গে ফিডব্যাক পেতে পারেন, এবং এটি tests চালাতেও ব্যবহার করা যায়।

## Leiningen
Clojure CLI দিয়ে একটি REPL খুলতে হলে, অনুশীলনীর ফাইল যে ডিরেক্টরিতে আছে সেখানে গিয়ে রান করুন:
``` bash
$ clojure -m cljs.main -re node
```

মনে রাখবেন, আপনার সিস্টেমে Node ইনস্টল করা থাকা দরকার।

একটি অনুশীলনীতে কাজ করার জন্য প্রস্তুত হয়ে আপনার সমাধান রাখার একটি ফাইল তৈরি করে ফেললে (যেমন `bob.cljs`), আপনি আপনার টার্মিনালে `$ clojure -A:test` দিয়ে tests চালাতে পারবেন।

প্রথমে, test namespace-টি `require` করুন:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

ns-টি test namespace-এ পরিবর্তন করুন:
```clojure
=> (ns bob-test)
nil
```

তারপর `bob-test`-এর উপর `run-tests` কল করুন:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Clojure CLI দিয়ে একটি অনুশীলনীর tests চালাতে, শুধু এভাবে কল করুন:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
