# পরিচিতি

## কাস্টিং

কাস্টিং আর টাইপ কনভার্সন হলো একটি এক্সপ্রেশনকে এক ডেটা টাইপ থেকে আরেক ডেটা টাইপে বদলানোর দুটি ভিন্ন উপায়।

কাস্ট অপারেটর `(<type>)` দিয়ে একটি এক্সপ্রেশনকে অন্য টাইপে কাস্ট করা যায়।

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

টাইপগুলো পরস্পর সামঞ্জস্যপূর্ণ না হলে `InvalidCastException`-এর একটি ইনস্ট্যান্স থ্রো হয়। সংখ্যার ক্ষেত্রে এটা বোঝায়, যে টাইপে মানটি নেওয়া হচ্ছে সেটি কাস্ট করা মানটি প্রকাশ করতে পারে না। ক্লাসের ক্ষেত্রে দুটি টাইপের একটি অন্যটি থেকে ডিরাইভ করা থাকতে হবে (স্ট্রাক্টের বেলাতেও এটি সহজভাবে প্রযোজ্য)।

_কাস্টিং_-এর একটি বিকল্প হলো `is` অপারেটর ব্যবহার করে _টাইপ কনভার্সন_। এটি সাধারণত রেফারেন্স ও নালেবল টাইপে প্রয়োগ করা হয়।

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

কোনো অবজেক্টের সঠিক টাইপ শনাক্ত করতে হলে `is` হয়তো একটু বেশি উদার, কারণ এটি একটি ক্লাস এবং তার থেকে সরাসরি বা পরোক্ষভাবে ডিরাইভ করা যেকোনো ক্লাস ও ইন্টারফেসের জন্য true রিটার্ন করে। এক্ষেত্রে `typeof` আর `Object.GetType()`-ই সমাধান।

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
