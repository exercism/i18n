# ইনস্টলেশন

এই সমস্যাগুলোর জন্য আমরা জনপ্রিয় MIPS সিমুলেটর [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html) ব্যবহার করি। [GitHub](https://github.com/dpetersanderson/MARS/releases) থেকে MARS-এর জার আর্কাইভটি ডাউনলোড করে সহজে হাতের কাছে পাওয়া যায় এমন একটি জায়গায় রেখে দিন। Java SDK-ও আগে থেকে ইনস্টল করা না থাকলে সেটিও ইনস্টল করে নিন।
