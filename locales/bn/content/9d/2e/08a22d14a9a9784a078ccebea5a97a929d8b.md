# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে নেওয়া দুর্দান্ত লাসাগনা প্রস্তুত ও রান্নার সাথে সম্পর্কিত আরও কিছু কোড লিখবেন।

আপনার সামনে পাঁচটি কাজ আছে।
প্রথমটি রান্নার সাথেই সম্পর্কিত, বাকি চারটি নিখুঁত প্রস্তুতি নিয়ে।

## 1. প্রস্তুতির সময় হিসাব করুন

আগামীবার যে লাসাগনা তৈরি করবেন, তার জন্য যথেষ্ট সময় রাখা আছে কিনা তা নিশ্চিত করতে চান, যাতে রান্নাটা উপভোগ করতে পারেন।
আপনার লাসাগনায় কোন কোন স্তর থাকবে তা আপনি আগেই পরিকল্পনা করেছেন।
এখন সেটির ভিত্তিতে প্রস্তুতিতে কত সময় লাগবে তা হিসাব করতে চান।

এমন একটি ফাংশন `preparationTime` বাস্তবায়ন করুন, যা `string` হিসেবে স্তরের একটি ভেক্টর এবং প্রতি স্তরের গড় প্রস্তুতির সময় মিনিটে `int` হিসেবে গ্রহণ করে।
ফাংশনটি স্তরের সংখ্যার ভিত্তিতে মোট প্রস্তুতির সময়ের হিসাব `int` হিসেবে রিটার্ন করবে।
গড় প্রস্তুতির সময় পাঠানো না হলে `2` ডিফল্ট মান হিসেবে ব্যবহার করা হবে।

```cpp
std::vector<std::string> layers{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"};
preparationTime(layers, 3)
// => 18
preparationTime(layers)
// => 12
```

## 2. প্রয়োজনীয় নুডলস ও সসের পরিমাণ হিসাব করুন

সময় আলাদা রাখার পাশাপাশি, আপনার স্বপ্নের লাসাগনা রান্নার জন্য যথেষ্ট সস ও নুডলস আছে কিনা তাও নিশ্চিত করতে চান।
আপনার লাসাগনার প্রতিটি নুডলস স্তরের জন্য ৫০ গ্রাম নুডলস লাগবে।
আপনার লাসাগনার প্রতিটি সস স্তরের জন্য ০.২ লিটার সস লাগবে।

`quantities` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে `string` আকারে স্তরের একটি ভেক্টর নেয়।
এরপর ফাংশনটি আপনার খাবার তৈরির জন্য প্রয়োজনীয় নুডলস ও সসের পরিমাণ নির্ধারণ করবে।
ফলাফলটি একটি `amount` _struct_ হিসেবে রিটার্ন করা উচিত, যা আপনার জন্য আগেই ডিফাইন করা আছে।
`amount`-এ দুটি মেম্বার ভ্যারিয়েবল আছে, একটি `noodles`-এর ওজন `int` হিসেবে, আর দ্বিতীয়টি `sauce`-এর আয়তন `double` হিসেবে।

```cpp
struct amount { int noodles; double sauce; };

amount needed{quantities({"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})};
// needed.noodles => 100
// needed.sauce => 0.4
```

## 3. গোপন উপকরণ যোগ করুন

কিছুদিন আগে আপনি এক বন্ধুর বাড়িতে গিয়েছিলেন এবং সেখানে লাসাগনা খেয়েছিলেন।
এটি ছিল অসাধারণ এবং এতে বিশেষ কিছু ছিল।
বন্ধুটি আপনাকে উপকরণের তালিকা পাঠিয়েছিলেন এবং বলেছিলেন, তালিকার শেষ জিনিসটিই হলো সেই "গোপন উপকরণ", যা খাবারটিকে এত বিশেষ করে তুলেছিল।
এখন আপনি সেই গোপন উপকরণটিও আপনার রেসিপিতে যোগ করতে চান।

এমন একটি ফাংশন `addSecretIngredient` লিখুন, যা প্যারামিটার হিসেবে দুটি `vector of strings` গ্রহণ করে।
প্রথম প্যারামিটারটি আপনার নিজের রেসিপির উপকরণের একটি _রেফারেন্স_, আর দ্বিতীয় _ভেক্টর_-টিতে স্ট্রিং হিসেবে আছে আপনার বন্ধু যে উপকরণগুলো পাঠিয়েছেন।
আপনার উপকরণ তালিকার শেষ এলিমেন্টটি সবসময় `"?"`।
ফাংশনটি সেটিকে আপনার বন্ধুর তালিকার শেষ জিনিস দিয়ে প্রতিস্থাপন করবে।
**নোট:** `addSecretIngredient` কিছুই রিটার্ন করে না, আপনাকে সরাসরি আপনার উপকরণের তালিকাটি পরিবর্তন করতে হবে।
আপনার বন্ধুর উপকরণের তালিকাটিও একটি রেফারেন্স হতে পারে (পারফরম্যান্স উন্নত করার জন্য), কিন্তু এটি পরিবর্তন করা **যাবে না**।
`const` রেফারেন্স দিয়ে যেন তালিকাটি পরিবর্তন না হয় তা নিশ্চিত করুন।

```cpp
std::vector<std::string> friendsList{"noodles", "sauce", "mozzarella", "kampot pepper"};
std::vector<std::string> myList{"noodles", "meat", "sauce", "mozzarella", "?"};

addSecretIngredient(myList, friendsList);
// myList => {"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. রেসিপি স্কেল করুন

আপনার রান্নার বইয়ে দেওয়া পরিমাণ দিয়ে কেবল দুই ভাগের জন্য যথেষ্ট লাসাগনা তৈরি হয়।
আগামীবার আরও মানুষের জন্য রান্না করতে চান বলে, বিভিন্ন সংখ্যক ভাগের জন্য পরিমাণ হিসাব করতে চান।

এমন একটি ফাংশন `scaleRecipe` বাস্তবায়ন করুন, যা দুটি প্যারামিটার নেয়।

- ২ ভাগের জন্য প্রয়োজনীয় `double` পরিমাণের একটি ভেক্টর।
- আপনি যে সংখ্যক ভাগ রান্না করতে চান।

ফাংশনটি আপনার কাঙ্ক্ষিত সংখ্যক ভাগের জন্য প্রয়োজনীয় পরিমাণের একটি নতুন ভেক্টর রিটার্ন করবে।
তবে আপনি মূল রেসিপিটি অপরিবর্তিত রাখতে চান।
এর মানে হলো এই ফাংশনে `quantities` আর্গুমেন্টটি পরিবর্তন করা উচিত নয়।

```cpp
std::vector<double> quantities{1.2, 3.6, 10.5};
scaleRecipe(quantities, 4);
// => { 2.4, 7.2, 21 }
```

## 5. পারিবারিক রহস্য উন্মোচন করুন

আপনার শৈশবের গল্প মনে পড়ে, আপনার প্রপিতামহীর কাহিনি, যিনি পরিবারের গভীরতম রান্নার রহস্যের রক্ষক।
কথিত আছে, কল্পনাতীত স্বাদ উন্মোচনের চাবিকাঠি তাঁর কাছেই আছে, তবে তাঁর পদ্ধতি অপ্রচলিত।
তিনি তালিকা বা মাপ নিয়ে কাজ করেন না; তিনি ফিসফিস করে বলেন, একবারে কেবল একটি উপকরণ প্রকাশ করেন।

উত্তেজনা আর শঙ্কার মিশ্রণে আপনি আপনার প্রপিতামহীর সাথে যোগাযোগ করার সিদ্ধান্ত নেন।
প্রত্যাশামতোই, তিনি তাঁর রহস্যময় ভঙ্গিতে উত্তর দেন, রহস্যে মোড়া একটি মাত্র গোপন উপকরণ দেন।

আপনার প্রপিতামহীর অবদান জটিলতার একটি স্তর যোগ করে, যা আপনি আপনার রেসিপিতে ব্যবহার করতে চান।
`addSecretIngredient` ফাংশনের আরেকটি সংস্করণ বাস্তবায়ন করুন, যা দুটি আর্গুমেন্ট গ্রহণ করে: আপনার উপকরণ তালিকা উপস্থাপন করা একটি ভেক্টরের রেফারেন্স এবং আপনার প্রপিতামহীর কাছ থেকে পাওয়া রহস্যময় উপহার উপস্থাপন করা একটি স্ট্রিং।

```cpp
std::vector<std::string> myList{"noodles", "meat", "sauce", "mozzarella", "?"};
std::string secretIngredient{"spice melange"};
addSecretIngredient(myList, secretIngredient);
// myList => {"noodles", "meat", "sauce", "mozzarella", "spice melange"}
```
