# নির্দেশনা পরিশিষ্ট

## একটি ইন্ডাক্টিভ টাইপ ডিফাইন করা

এই অনুশীলনীতে আশা করা হয় যে রিটার্ন ভ্যালু হবে একটি [ইন্ডাক্টিভ টাইপ][inductive] `Classification`, যা আপনাকে ডিফাইন করতে হবে।

এই টাইপের একটি [BEq][beq] ইনস্ট্যান্স থাকতে হবে, অর্থাৎ এটি একটি বুলিয়ান সমতা পরীক্ষা সমর্থন করে, এবং একটি [Repr][repr] ইনস্ট্যান্স থাকতে হবে, অর্থাৎ টাইপের মানগুলো প্রদর্শনের জন্য ফরম্যাট করা যাবে।

ইনস্ট্যান্স ডিক্লারেশন সম্পর্কে [এই পৃষ্ঠাটি][instance] দেখতে পারেন।
Lean অনেক ক্লাসের জন্য স্বয়ংক্রিয়ভাবে [ইনস্ট্যান্স জেনারেট][deriving] করতে পারে।

## সাবটাইপ

`classify` ফাংশনের আর্গুমেন্ট হলো `Positive` নামের একটি [সাবটাইপ][subtype]:

```
def Positive := { x : Nat // x > 0 }
```

সাবটাইপ কোনো নির্দিষ্ট টাইপের সেই এলিমেন্টগুলোকে বোঝায়, যেগুলো একটি প্রেডিকেট সন্তুষ্ট করে।
`Positive` হলো `Nat`-এর সেই এলিমেন্টগুলো, যেগুলো `0`-এর চেয়ে বড়।

সাবটাইপের যেকোনো এলিমেন্টকে একটি জোড় হিসেবে ভাবা যায়, যার একটি অংশ হলো আন্ডারলাইং টাইপের একটি মান আর অন্যটি হলো গাণিতিক অর্থে একটি প্রমাণ যে এই মানটি সংশ্লিষ্ট প্রেডিকেট সন্তুষ্ট করে।

সাবটাইপ টাইপ লেভেলে ইনভ্যারিয়েন্ট নিশ্চিত করে, ফলে ত্রুটিপূর্ণ মান তৈরি করা যায় না।
