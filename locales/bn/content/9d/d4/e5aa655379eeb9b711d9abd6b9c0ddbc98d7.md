# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার এলাকার আর্কেড হলের সবচেয়ে জনপ্রিয় গেমটির হাই স্কোর হিসাব রাখার একটি উপায় তৈরি করবেন।

## 1. হাই স্কোর বোর্ডে প্লেয়ার যোগ করা

হাই স্কোর বোর্ডে একজন প্লেয়ার যোগ করতে, দুটি `add_player!` মেথড ডিফাইন করুন, যেগুলো নিচের আর্গুমেন্টগুলো নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ডিকশনারি।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে একজন প্লেয়ারের নাম।
- তৃতীয় আর্গুমেন্টটি ইন্টিজার হিসেবে স্কোর।
  এই আর্গুমেন্টটি ঐচ্ছিক; কোনো মান দেওয়া না হলে স্কোরটি ০-এ সেট করা উচিত।

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. স্কোর বোর্ড থেকে প্লেয়ার সরানো

স্কোর বোর্ড থেকে একজন প্লেয়ার সরাতে, `remove_player!` ডিফাইন করুন, যেটি ২টি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ডিকশনারি।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে প্লেয়ারের নাম।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. একজন প্লেয়ারের স্কোর হালনাগাদ করা

আগের স্কোরটি প্রতিস্থাপন করে একজন প্লেয়ারের স্কোর হালনাগাদ করতে, `update_score!` ডিফাইন করুন, যেটি ৩টি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ডিকশনারি।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে সেই প্লেয়ারের নাম, যার স্কোর আপনি হালনাগাদ করতে চান।
- তৃতীয় আর্গুমেন্টটি হলো সেই স্কোর, যেটিতে আপনি সংরক্ষিত হাই স্কোর সেট করতে চান।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. একজন প্লেয়ারের স্কোর রিসেট করা

একজন প্লেয়ারের স্কোর রিসেট করতে, `reset_score!` ডিফাইন করুন, যেটি ২টি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ডিকশনারি।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে সেই প্লেয়ারের নাম, যার স্কোর আপনি রিসেট করতে চান।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. প্লেয়ারদের একটি অ্যারে পাওয়া

প্লেয়ারদের একটি অ্যারে পেতে, `players` ডিফাইন করুন, যেটি ১টি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ডিকশনারি।

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
