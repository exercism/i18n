# পরিচিতি

আগের ধারণাগুলোতে আমরা দেখেছি, Julia-তে টাইপগুলো একটি স্তরক্রম গঠন করে, যার একেবারে উপরে থাকে `Any`.

`Number`-এর মতো অ্যাবস্ট্রাক্ট টাইপের সাবটাইপ থাকে, কিন্তু তাদের নিজেদেরকে ইন্সট্যানশিয়েট করা যায় না।
কোনো ভ্যারিয়েবলকে একটি অ্যাবস্ট্রাক্ট টাইপে সেট করলে ভ্যারিয়েবলটির মানগুলোকে ওই অ্যাবস্ট্রাক্ট টাইপের যেকোনো সাবটাইপ হতে হবে, এই _সীমাবদ্ধতা_ আরোপিত হয়।
যেমন:

```julia-repl
julia> x::Number = 3
3
julia> typeof(x)  # one subtype of Number
Int64
julia> x = 4.2
4.2
julia> typeof(x) # another subtype of Number
Float64
julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

এতে কোন কোন ইনপুট বৈধ হবে তা সীমাবদ্ধ করার এক ধরনের সুবিধা মেলে।

কিন্তু ধরুন, আমরা চাই একটি ভ্যারিয়েবল একইসাথে ইন্টিজার ও স্ট্রিং মান নিতে পারবে?
এই দুই টাইপ স্তরক্রমের একই শাখায় নেই।

আমরা টাইপটি `Any` সেট করতে পারি, বা ডিফল্ট হিসেবেই সেটিকে `Any` হতে দিতে পারি, কিন্তু তাহলে অনুমোদিত টাইপগুলোর উপর আমাদের সব নিয়ন্ত্রণ হারিয়ে যায়।

আরও ভালো একটি পদ্ধতির জন্য আমাদের হাতে আছে `Union{ }` সিনট্যাক্স, যার বন্ধনীর ভেতরে দুটি বা তার বেশি টাইপ লেখা হয়।

```julia-repl
julia> y::Union{Integer, String} = 4
4
julia> typeof(y)
Int64
julia> y = "works"
"works"
julia> typeof(y)
String
julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

আরেকটি উদাহরণে একই টাইপ ইউনিয়ন ব্যবহার করা হয়েছে একটি ফাংশন সিগনেচারে:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}
julia> f(z::IntOrString) = z^3
f (generic function with 1 method)
julia> f(2) # integers are cubed
8
julia> f("ab") # strings are repeated 3 times
"ababab"
```

এখানে আমরা টাইপটিকে একটি নাম দিয়েছি, যা সুবিধাজনক শর্টহ্যান্ড হিসেবে কাজ করে, তবে একান্ত জরুরি নয়।
`g(z::Union{Integer, String}) = z^3` ফাংশনটিও ঠিক একইভাবে কাজ করে।

ফাংশন সিগনেচার নিয়ে আরও অনেক কিছু বলার আছে মাল্টিপল ডিসপ্যাচ ধারণায়।

## nothing-এর সাথে ইউনিয়ন

আরও বেশ কিছু ভাষায় এমন টাইপ আছে যা মান ধারণ করতে পারে, আবার নাও পারে; এগুলোর নাম হতে পারে `Option`, `Nullable` বা `Maybe`.

Julia-তে এর জন্য নির্দিষ্ট কোনো সিনট্যাক্স নেই, তবে টাইপ ইউনিয়ন হলো একই ধারণার একটি সাধারণ রূপ।

`Nothingness` ধারণায় আমরা দেখেছি, Julia-তে মান-না-থাকার অবস্থা বোঝানোর নানা রকম উপায় আছে, যার মধ্যে আছে `nothing` ও `missing`.
এদের যেকোনোটিকেই একটি টাইপ ইউনিয়নে রাখা যায়।

যেমন, একধরনের লিঙ্কড লিস্ট ডিফাইন করতে গেলে আর কোনো নোড না থাকলে লিস্টটি শেষ করার একটি উপায় দরকার হয়।
`Nothing` হলো সেই টাইপ, যার একমাত্র মান `nothing`; আর Node-এর এই সংজ্ঞা দিয়ে চেইনের শেষ বোঝানো সম্ভব:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

একইভাবে, অনুপস্থিত মানের জায়গায় প্লেসহোল্ডার হিসেবে `missing` ব্যবহার করা যায়, বিশেষত ভেক্টরের মতো কালেকশনে।
নিচের উদাহরণটি খুবই কৃত্রিম, তবে বাস্তব জগতের ডেটা সেটে অনুপস্থিত মান কমন।

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)
julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
