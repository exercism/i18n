# নির্দেশনা

এই অনুশীলনীতে আপনি একটি সাইন কোম্পানিকে তাদের সাইনের জন্য কাস্টম বার্তা তৈরি করতে সাহায্য করার কোড লিখবেন।

## 1. দরকারি স্ট্রিংয়ের একটি সেট তৈরি করুন

নিচের ধ্রুবক স্ট্রিংগুলো ডিফাইন করুন, যেগুলো সাইন তৈরি করতে ব্যবহার করা হবে:

- `birthday`: এতে "Birthday" মানটি থাকে
- `valentine`: এতে "Valentine's Day" মানটি থাকে
- `anniversary`: এতে "Anniversary" স্ট্রিংটি থাকে

## 2. দরকারি ক্যারেক্টারের একটি সেট তৈরি করুন

নিচের ধ্রুবক ক্যারেক্টারগুলো ডিফাইন করুন, যেগুলো সাইন তৈরি করতে ব্যবহার করা হবে:

- `space`: এতে " " মানটি থাকে (একটি মাত্র স্পেস)
- `exclamation`: এতে "!" মানটি থাকে

## 3. বার্তা গড়ে তুলতে ফ্রেজ একত্র করুন

`buildSign(for:name:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `for` আর্গুমেন্ট নেয়, যেটি প্রথম টাস্কে আপনি ডিফাইন করা তিনটি স্ট্রিংয়ের একটি ধারণ করে, আর `name` আর্গুমেন্ট নেয়, যেটি এমন একটি স্ট্রিং যা ধারণ করে সাইনটি যার জন্য সেই ব্যক্তির নাম।
সাইনের বার্তা গড়ে তুলতে আপনাকে কনক্যাটেনেশন ব্যবহার করতে হবে এবং আগে থেকে ডিফাইন করা ধ্রুবকগুলো আবার ব্যবহার করার কথা মনে রাখতে হবে।
ফাংশনটি সাইন বার্তাটি একটি স্ট্রিং হিসেবে রিটার্ন করবে।

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. একটি গ্র্যাজুয়েশন সাইন তৈরি করুন

`graduationFor(name:year:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `name` আর্গুমেন্ট নেয়, যেটি এমন একটি স্ট্রিং যা ধারণ করে সাইনটি যার জন্য সেই ব্যক্তির নাম, আর `year` আর্গুমেন্ট নেয়, যেটি একটি ইন্টিজার যা ধারণ করে ব্যক্তিটি যে বছর গ্র্যাজুয়েট করছে সেই বছর।
সাইনের বার্তা গড়ে তুলতে আপনাকে টেমপ্লেট স্ট্রিং ব্যবহার করতে হবে।
ফাংশনটি সাইন বার্তাটি একটি স্ট্রিং হিসেবে রিটার্ন করবে।

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. একটি সাইনের খরচ হিসাব করুন

`costOf(sign:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `sign` আর্গুমেন্ট নেয়, যেটি এমন একটি স্ট্রিং যা সাইনের বার্তাটি ধারণ করে।
সাইনটির প্রদত্ত মুদ্রায় একটি বেস প্রাইস আছে ২০। এছাড়া প্রতিটি অক্ষরের খরচ ২ (হিসাবের মধ্যে হোয়াইটস্পেসও ধরা হয়)।
ফাংশনটি সাইনটির খরচ একটি ইন্টিজার হিসেবে রিটার্ন করবে।

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
