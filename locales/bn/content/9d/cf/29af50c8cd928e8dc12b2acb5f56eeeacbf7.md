# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার তিনটি কাজ আছে, যেগুলোর সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে ডিফাইন করুন

লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত তা হিসাব করার জন্য `expectedMinutesInOven` ডিফাইন করুন। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```elm
expectedMinutesInOven
    --> 40
```

## 2. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTimeInMinutes` ডিফাইন করুন, যা লাসাগনার স্তরের সংখ্যা প্যারামিটার হিসেবে নেয় এবং লাসাগনা প্রস্তুত করতে কত মিনিট লাগে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে ২ মিনিট লাগে।

```elm
preparationTimeInMinutes 3
    --> 6
```

## 3. অতিবাহিত সময় মিনিটে হিসাব করুন

`elapsedTimeInMinutes` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসাগনার স্তরের সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ওভেনে আছে তা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্না করতে আপনি কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```elm
elapsedTimeInMinutes 3 20
    --> 26
```
