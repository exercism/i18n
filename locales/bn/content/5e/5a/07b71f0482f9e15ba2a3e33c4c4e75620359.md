# ভূমিকা

`when` হলো এক্সেপশন ফিল্টার করার কিওয়ার্ড। এটি `catch` স্টেটমেন্টের পরে বসানো হয় এবং সেই সময়ে স্কোপে থাকা যেকোনো মান ধারণকারী একটি বুলিয়ান এক্সপ্রেশন নিতে পারে। এক্সপ্রেশনটি যদি ট্রু হয়, তাহলে ওই `catch` স্টেটমেন্টের সাথে যুক্ত ব্লকটি চালানো হয়, অন্যথায় পরবর্তী `catch` স্টেটমেন্ট থাকলে সেটি যাচাই করা হয়।

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
