# টেস্ট চালানো

আপনার অপারেটিং সিস্টেম বেছে নিন:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. একটি Command Prompt খুলুন।
2. প্রথম অনুশীলনীটি সংগ্রহ করুন:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. অনুশীলনীর ডিরেক্টরিতে চলে যান:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. টেস্ট চালান:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(শুরুতে টেস্ট ফেল করলেও চিন্তা করবেন না, প্রতিটি অনুশীলনী এভাবেই শুরু হয়।)_

5. অনুশীলনীটি সমাধান করুন। `instructions.append.md` গাইডটি খুঁজে নিন এবং সেটি ধরে ধরে এগিয়ে যান ([GitHub-এ দেখুন][hello-world-tutorial])।

শুভকামনা!

## Linux

1. টার্মিনাল উইন্ডোতে প্রথম অনুশীলনীটি সংগ্রহ করুন:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. অনুশীলনীর ডিরেক্টরিতে চলে যান:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. টেস্ট চালান:

   ```sh
   ./gradlew test
   ```

   _(শুরুতে টেস্ট ফেল করলেও চিন্তা করবেন না, প্রতিটি অনুশীলনী এভাবেই শুরু হয়।)_

   যদি নিচের এররটি আসে:

   ```sh
   ./gradlew: Permission denied
   ```

   তাহলে ফাইলটিতে এক্সিকিউট পারমিশন নেই। এটি ঠিক করতে রান করুন:

   ```sh
   chmod +x ./gradlew
   ```

   আর এখন আপনি আগের কমান্ডটি চালাতে পারবেন।

4. অনুশীলনীটি সমাধান করুন। `instructions.append.md` গাইডটি খুঁজে নিন এবং সেটি ধরে ধরে এগিয়ে যান ([GitHub-এ দেখুন][hello-world-tutorial])।

শুভকামনা!
