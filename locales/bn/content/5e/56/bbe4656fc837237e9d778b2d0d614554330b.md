# নির্দেশনা

একটি [আর্মস্ট্রং সংখ্যা][armstrong-number] হলো এমন একটি সংখ্যা, যেটি তার নিজের অঙ্কগুলোর যোগফলের সমান, যেখানে প্রতিটি অঙ্ককে অঙ্কসংখ্যার সমান ঘাতে উন্নীত করা হয়।

যেমন:

- 9 একটি আর্মস্ট্রং সংখ্যা, কারণ `9 = 9^1 = 9`
- 10 আর্মস্ট্রং সংখ্যা _নয়_, কারণ `10 != 1^2 + 0^2 = 1`
- 153 একটি আর্মস্ট্রং সংখ্যা, কারণ: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 আর্মস্ট্রং সংখ্যা _নয়_, কারণ: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

একটি সংখ্যা আর্মস্ট্রং সংখ্যা কি না, তা নির্ণয় করার জন্য কিছু কোড লিখুন।
