# Instructions

আপনি একজন আগ্রহী পাখি-পর্যবেক্ষক, যিনি আপনার বাগানে আসা পাখিদের প্রতিদিনের সংখ্যা লিখে রাখেন। এই সংখ্যাগুলো একটি অ্যারেতে রাখা থাকে, সবচেয়ে পুরনো দিনটি সবার আগে।

## 1. Today's count

স্ট্যাক থেকে দৈনিক সংখ্যাগুলোর অ্যারে নিয়ে আজকের সংখ্যাটি রিটার্ন করার জন্য `today` ডিফাইন করুন।

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Increment today's count

আজকের সংখ্যা এক বাড়িয়ে একটি নতুন অ্যারে রিটার্ন করার জন্য `increment-todays-count` ডিফাইন করুন। মূল অ্যারেটি পরিবর্তন করা উচিত নয়।

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Was there a day with no birds?

কমপক্ষে একটি দিনে যদি শূন্য পাখি রেকর্ড করা হয়ে থাকে তবে `t` রিটার্ন করতে, নাহলে `f` রিটার্ন করতে `has-day-without-birds?` ডিফাইন করুন।

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Sum the first few days

সংখ্যাগুলোর একটি অ্যারে এবং একটি সংখ্যা `n` নিয়ে প্রথম `n`টি সংখ্যার যোগফল রিটার্ন করার জন্য `count-for-first-days` ডিফাইন করুন।

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Count the busy days

পাঁচটি বা তার বেশি পাখি থাকলে সেদিনটি ব্যস্ত দিন। অ্যারেতে ব্যস্ত দিনের সংখ্যা রিটার্ন করার জন্য `busy-days` ডিফাইন করুন।

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Pad missing days

`n` দিনের একটি সময়ের প্রতিটি দিনে যদি আপনি পর্যবেক্ষণ না করে থাকেন, তবে শেষের অনুপস্থিত দিনগুলো `0` দিয়ে পূরণ করুন। সংখ্যাগুলোর একটি অ্যারে এবং একটি লক্ষ্য দৈর্ঘ্য `n` নিয়ে এমন একটি অ্যারে রিটার্ন করার জন্য `pad-missing-days` ডিফাইন করুন, যার দৈর্ঘ্য অন্তত `n` এবং যার বাড়তি ঘরগুলো `0`। বিদ্যমান সংখ্যাগুলো অপরিবর্তিত রাখতে হবে; ইনপুটটি যদি ইতিমধ্যেই অন্তত `n` দীর্ঘ হয়, তবে সেটি অপরিবর্তিত রিটার্ন করুন।

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
