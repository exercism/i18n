# সম্পর্কে

একটি [switch স্টেটমেন্ট][switch] একটি মানকে একাধিক সম্ভাব্য মিলে যাওয়া প্যাটার্নের সাথে তুলনা করে।
একাধিক `if-else` স্টেটমেন্ট চেইন করার চেয়ে এটি আরও পরিচ্ছন্ন ও পাঠযোগ্য একটি বিকল্প দেয়।

একটি `switch` স্টেটমেন্ট শুরু হয় `switch` কিওয়ার্ড দিয়ে, তার পরে থাকে যে মানটি পরীক্ষা করা হবে।
প্রতিটি সম্ভাব্য মিল `case` কিওয়ার্ড দিয়ে শুরু হয়।
`default` কিওয়ার্ড এমন একটি ফলব্যাক কেস নির্ধারণ করে, যা স্পষ্ট কোনো কেসের সাথে মিল না হলে চালানো হয়।
`if-else` চেইনের মতোই, একটি `switch` স্টেটমেন্ট শুধু প্রথম মিলে যাওয়া কেসের সাথে সম্পর্কিত কোড ব্লকটিই চালায়।

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

নিচের `if-else` চেইনটি দেখুন:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

এটিকে একটি `switch` স্টেটমেন্ট দিয়ে আরও পরিষ্কারভাবে লেখা যায়:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## মান বাইন্ডিং ও `where` ক্লজ

একটি `switch` কেস মিলে যাওয়া মানগুলোকে সাময়িক কনস্ট্যান্ট বা ভ্যারিয়েবলে বাইন্ড করতে পারে, যাতে সেগুলো ওই কেসের বডিতে ব্যবহার করা যায়।
কেসগুলোতে একটি `where` ক্লজও থাকতে পারে, যা মেলানোর আগে অতিরিক্ত বুলিয়ান শর্ত যাচাই করে:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
