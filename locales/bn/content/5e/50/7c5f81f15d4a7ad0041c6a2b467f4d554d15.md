# সম্পর্কে

[`fold`][fold] একটি [কনজিউমিং ইটারেটর অ্যাডাপ্টর][consuming iterator adaptor], যা ইটারেশনের প্রতিটি এলিমেন্টে একটি ফাংশন প্রয়োগ করে এবং ফলাফলটি একটি নতুন মানে জমা করে।

`fold`-এর প্রতিটি ইটারেশনে দুটি আর্গুমেন্ট লাগে। প্রথমটি হলো অ্যাকুমুলেটরের একটি প্রাথমিক মান। দ্বিতীয়টি একটি ক্লোজার, যা নিজেই দুটি আর্গুমেন্ট নেয়: অ্যাকুমুলেটর আর একটি আইটেম। ক্লোজারের রিটার্ন ভ্যালুই হয় অ্যাকুমুলেটরের পরবর্তী মান। ইটারেটরটি নিঃশেষ হয়ে গেলে অ্যাকুমুলেটরের চূড়ান্ত মান রিটার্ন করা হয়।

কোনো কালেকশনকে একটি একক মানে রূপান্তর করতে চাইলে `fold` ব্যবহার করা যায়। উদাহরণস্বরূপ, সব জোড় সংখ্যার যোগফল চাইলে

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

এটি `30` প্রিন্ট করে।

`fold`-এ যা করা যায়, তা প্রায়ই অন্য একটি ফাংশন বা কয়েকটি ফাংশন দিয়ে করা যায়। উপরের উদাহরণটির ক্ষেত্রে `(1..=10)`-এর উপর [`filter`][filter] করে তারপর [`sum`][sum] করলে কোড কম শব্দবহুল হবে এবং একই ফলাফল দেবে, এভাবে

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

`fold`-এর চেয়ে বেশি ব্যবহৃত আরও কিছু ফাংশনের মধ্যে রয়েছে [`product`][product] এবং [`collect`][collect]।

অ্যাকুমুলেটর শুধু সংখ্যাসূচক মানের জন্যই নয়, অন্য জিনিসের জন্যও ব্যবহার করা যায়। যেমন

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

এটি `FeeFiFoFum` প্রিন্ট করে
