# নির্দেশনার সংযোজন

## ইঙ্গিত

টেস্টটি পাস করাতে হলে আপনার কোড কাজ করার জন্য আপনাকে কিছু টাইপ তৈরি করতে হবে। আপনার `School`-এর জন্য একটি অবজেক্ট দরকার, যেটি `Student` টাইপের একটি সিকোয়েন্স ধরে রাখবে। আর এই `Student` হবে `string` ও `int`-এর একটি টাপল, যেখানে শিক্ষার্থীদের নাম ও গ্রেড থাকবে।

শুরু করার সময় কাজে লাগতে পারে এমন কিছু টাইপের কোড এখানে দেওয়া হলো।

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
