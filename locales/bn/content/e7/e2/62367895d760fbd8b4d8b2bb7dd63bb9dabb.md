# নির্দেশাবলি

এই অনুশীলনীতে আপনি ডেভেলপারকে আইডেন্টিফায়ার নাম পরিষ্কার করতে সাহায্য করার জন্য কিছু ইউটিলিটি রুটিনের একটি আংশিক সেট তৈরি করবেন।

৪টি কাজে আপনি ধীরে ধীরে `clean` রুটিনটি গড়ে তুলবেন। একটি বৈধ আইডেন্টিফায়ার শূন্য বা তার বেশি অক্ষর ও আন্ডারস্কোর দিয়ে গঠিত।

সব ক্ষেত্রেই ইনপুট স্ট্রিংটি কখনো nil হবে না, এটা নিশ্চিত। `clean` ফাংশনে যদি একটি খালি স্ট্রিং পাঠানো হয়, তবে খালি স্ট্রিং রিটার্ন করা উচিত।

মনে রাখবেন, খালি আইডেন্টিফায়ার দিয়ে `clean` রুটিনটি কল করা উচিত নয়, কারণ এমন আইডেন্টিফায়ার অকার্যকর।

## 1. যেকোনো স্পেস আন্ডারস্কোর দিয়ে প্রতিস্থাপন করুন

যেকোনো স্পেস আন্ডারস্কোর দিয়ে প্রতিস্থাপন করতে `clean` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি শুরু ও শেষে থাকা স্পেসের ক্ষেত্রেও প্রযোজ্য।

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. কন্ট্রোল ক্যারেক্টারকে বড় হাতের অক্ষরের স্ট্রিং `"CTRL"` দিয়ে প্রতিস্থাপন করুন

কন্ট্রোল ক্যারেক্টারকে বড় হাতের অক্ষরের স্ট্রিং `"CTRL"` দিয়ে প্রতিস্থাপন করতে `clean` ফাংশনটি পরিবর্তন করুন।

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. কেবাব-কেসকে ক্যামেল কেসে রূপান্তর করুন

কেবাব-কেসকে ক্যামেল কেসে রূপান্তর করতে `clean` ফাংশনটি পরিবর্তন করুন।

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. গ্রিক ছোট হাতের অক্ষর বাদ দিন

'α' থেকে 'ω' পরিসরের যেকোনো গ্রিক অক্ষর বাদ দিতে `clean` ফাংশনটি পরিবর্তন করুন।

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
