# ইঙ্গিত

## 1. মিনিটে প্রত্যাশিত ওভেনের সময় নির্ধারণ করুন

- একটি [কনস্ট্যান্ট][constants] ডিফাইন করুন, যেটিতে রেসিপিতে উল্লেখ করা [`number`][numbers] মানটি থাকবে।
- কনস্ট্যান্টটি [`export`][export] করুন।

## 2. মিনিটে বাকি ওভেনের সময় হিসাব করুন

- ফাংশন থেকে [স্পষ্টভাবে একটি সংখ্যা রিটার্ন করুন][return]।
- মান বিয়োগ করতে [বিয়োগের গাণিতিক অপারেটর][operators] ব্যবহার করুন।

## 3. মিনিটে প্রস্তুতির সময় হিসাব করুন

- ফাংশন থেকে [স্পষ্টভাবে একটি সংখ্যা রিটার্ন করুন][return]।
- মান গুণ করতে [গুণের গাণিতিক অপারেটর][operators] ব্যবহার করুন।
- প্রতি লেয়ারের মিনিটে সময়ের জন্য অতিরিক্ত কনস্ট্যান্টটি ব্যবহার করুন।

## 4. মিনিটে মোট কাজের সময় হিসাব করুন

- ফাংশন থেকে [স্পষ্টভাবে একটি সংখ্যা রিটার্ন করুন][return]।
- আগে ইমপ্লিমেন্ট করা অন্য মেথডগুলোর একটি [কল করুন][invocation]।
- মান যোগ করতে [যোগের গাণিতিক অপারেটর][operators] ব্যবহার করুন।

[constants]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/const
