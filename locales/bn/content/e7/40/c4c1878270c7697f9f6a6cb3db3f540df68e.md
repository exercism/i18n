# `jq`-এ ফাংশন

আপনি `jq`-এ নিজের **কাস্টম ফাংশন** ডিফাইন করতে পারেন, যাতে আপনার প্রয়োজনীয় যেকোনো লজিক একসাথে রাখা যায়। _ফাংশন_ বিল্টইনের মতোই কাজ করে: এরা একটি ইনপুট নেয় এবং শূন্য, একটি বা একাধিক আউটপুট দেয়।

## একটি ফাংশন ডিফাইন করা

নিচের সিনট্যাক্স ব্যবহার করে আপনি একটি `jq` _ফাংশন_ ডিফাইন করতে পারেন:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- `def` কিওয়ার্ড দিয়ে শুরু হয়,
- ফাংশনের বডির আগে একটি কোলন থাকে,
- বডি একটি একক এক্সপ্রেশন নিয়ে গঠিত,
- সেমিকোলন দিয়ে শেষ হয়,
- `jq` সিনট্যাক্সের বাকি অংশের মতোই, পড়ার সুবিধার জন্য আপনি যখন খুশি হোয়াইটস্পেস ব্যবহার করতে পারেন।

## ফাংশন কোথায় রাখবেন

_ফাংশন_ ব্যবহার করার আগে ডিফাইন করতে হবে: এটি একটি এরর:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

এর মানে হলো, "মূল" এক্সপ্রেশনের আগে আপনাকে _ফাংশনগুলো_ আপনার `jq` কোডের শুরুতে রাখতে হবে।

### নেস্টেড ফাংশন

_ফাংশন_ নেস্ট করা যায়:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

এখানে `B` _ফাংশনটি_ কেবল `A`-এর বডিতে দৃশ্যমান।

## স্কোপ

একটি _ফাংশন_ ভ্যারিয়েবল ও নেস্টেড ফাংশনের জন্য একটি নতুন **স্কোপ** তৈরি করে।

## আর্গুমেন্ট

_ফাংশনের_ **আর্গুমেন্ট** আলাদা করা হয় _সেমিকোলন_ দিয়ে, কমা দিয়ে নয়।
উদাহরণস্বরূপ, একটি _ফাংশন_ যা একটি সংখ্যা নেয়, তারপর একটি সংখ্যা যোগ করে এবং একটি সংখ্যা দিয়ে গুণ করে:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

সেমিকোলন দরকার, কারণ কমার ইতিমধ্যেই `jq`-এ একটি কাজ আছে: স্ট্রিম যোগ করার একটি অপারেটর।

সেমিকোলনের বদলে কমা ব্যবহার করলে _১-আর্গুমেন্টের_ `add_mul` ফাংশনে দুটি কল করার চেষ্টা হবে, যা অস্তিত্ব নেই এবং তাই প্রথম কলের চেষ্টাতেই ব্যর্থ হবে:

```jq
10 | add_mul(5, 4)
# error: add_mul/1 is not defined
```

`5, 4`-এর কমাটি 5 ও 4 সংখ্যাটিকে একটি স্ট্রিমে সংযুক্ত করে। 
যখন আমরা একটি ফাংশনকে আর্গুমেন্ট হিসেবে একটি স্ট্রিম দিয়ে কল করি, `jq` সেই ফাংশনটিকে একাধিকবার কল করবে, স্ট্রিমের প্রতিটি মানের জন্য একবার করে। 
এটি `jq` স্ট্রিমে স্বাভাবিকভাবেই থাকা "অন্তর্নিহিত ইটারেশন"-এর একটি উদাহরণ।
`10 | add_mul(5, 4)` নিচেরটির সমতুল্য।

```jq
(10 | add_mul(5)), (10 | add_mul(4))
```
এখন আমরা দেখতে পাই কীভাবে `add_mul/1 is not defined` এররটি দেখা দেয়।
~~~~

### আর্গুমেন্ট হলো _এক্সপ্রেশন_

ফাংশনের _আর্গুমেন্ট_ হলো ফিল্টার, মান নয়।
এই অর্থে, এরা অন্য ভাষায় যাকে কলব্যাক বলা হয়, তার মতোই কাজ করে:

উদাহরণ হিসেবে `add_mul` ফাংশনটি নেওয়া যাক:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

এখানে কী ঘটছে?

- `adder` আর্গুমেন্টটি পায় _এক্সপ্রেশন_ `. + 5`
  - ফাংশন যখন `. + adder` করে, তখন তা হয়ে যায় `. + . + 5`
  - `. == 10` হওয়ায় এর মান দাঁড়ায় 25
- একইভাবে, `multiplier` আর্গুমেন্টটি হলো এক্সপ্রেশন `. - 2`
  - এর মান দাঁড়ায় 8
  - তারপর ফলাফল হয় `25 * 8 == 200`

### মান হিসেবে আর্গুমেন্ট

কখনও কখনও আপনি একটি _আর্গুমেন্ট_-কে ভ্যারিয়েবলে "ম্যাটেরিয়ালাইজ" করতে চাইবেন:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

এর একটি শর্টহ্যান্ড আছে:

```jq
def my_func($arg):
    other stuff ...
;
```

খেয়াল রাখবেন, এটি কেবল "সিনট্যাক্টিক শুগার": `$` ছাড়া `arg` নামটি _ফাংশনে_ এখনও স্কোপে থাকে।

<!-- prettier-ignore -->
~~~~exercism/caution
উদাহরণস্বরূপ, একটি অনুশীলনী সমাধান করতে আমি এরকম কিছু লিখেছিলাম:

```jq
# function that encodes the input value
def code:
    # expression here
    ;

def equals($code):
    (. | code) as $this_code
    | $code == $this_code
    ;

("some key value" | code) as $key
| ["array", "of", "values"]
| map(select(equals($key)))
```

এবং আমি অবাক হয়েছিলাম যে অ্যারেটির প্রতিটি মান কী (key)-এর সমান হয়ে গেল।

এটি ঘটেছিল কারণ jq `equals` ফাংশনটিকে এভাবে দেখেছিল

```jq
def equals(code):
    code as $code
    | (. | code) as $this_code
    | $code == $this_code
    ;
```

**আর্গুমেন্ট** `code` আগে ডিফাইন করা **ফাংশন** `code`-কে _ওভাররাইড_ করেছিল।
এর অর্থ হলো `(. | code)` ইনপুট মানের ভিত্তিতে নতুন একটি কোড গণনা করার বদলে কেবল **আর্গুমেন্ট**-টিই আউটপুট দিত।
ফলে `$this_code` ও `$code` সবসময় একই হতো।
~~~~

## অ্যারিটি

_ফাংশনের_ একটি **অ্যারিটি** থাকে, অর্থাৎ তারা যতগুলো _আর্গুমেন্ট_ নেয় তার সংখ্যা।

_ফাংশন_ ভিন্ন _অ্যারিটিতে_ একই নাম ব্যবহার করতে পারে।
বিল্টইন [`range`][man-range] ফাংশনটি এর উদাহরণ: `range/1`, `range/2` ও `range/3` সবই একসাথে থাকতে পারে।

আর্গুমেন্টের মাধ্যমে স্টেট বহন করে এমন রিকার্সিভ ফাংশন ডিফাইন করার সময় এটি কাজে লাগতে পারে।
উদাহরণস্বরূপ `map`-কে এভাবে _ইমপ্লিমেন্ট করা যেত_:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## রিকার্সন

`jq` টেলকল অপটিমাইজেশন করে, তবে কেবল ০-অ্যারিটির ফাংশনের জন্য।

## মডিউল

একটি `jq` মডিউল হলো কেবল ফাংশন ধারণ করা একটি ফাইল।
মডিউলগুলো [`include`][man-include] বা [`import`][man-import] কমান্ডের মাধ্যমে একটি jq প্রোগ্রামে যুক্ত করা হয়।
