# নেমড এক্সপোর্ট নেই

`%{export.name}` নামে কোনো [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) পাওয়া যায়নি। এটা ছাড়া টেস্ট পাস হবে না।

`%{export.name}` আছে কি না নিশ্চিত করুন এবং তার সামনে `export` যোগ করুন:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
