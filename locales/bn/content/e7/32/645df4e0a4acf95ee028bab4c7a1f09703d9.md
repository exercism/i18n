# `Map.update/4` ব্যবহার করুন

`update_score` ফাংশনে `scores` আপডেট করতে একটিমাত্র কলেই [`Map.update`] ব্যবহার করুন। আপডেট করার ফাংশনটির জন্য [`fn`] বা [`&` অপারেটর শর্টহ্যান্ড] দিয়ে একটি অ্যানোনিমাস ফাংশন ডিফাইন করুন।
