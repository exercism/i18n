# নির্দেশনা

এই অনুশীলনীতে আপনি আরও কিছু কোড লিখবেন, যা আপনার প্রিয় রান্নার বই থেকে শেখা দুর্দান্ত লাসানিয়া রান্না করতে সাহায্য করবে।

আপনার সামনে পাঁচটি কাজ, যার সবকটিই লাসানিয়া রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় পরিবর্তনের সুযোগ

আপনি একটি উন্নত `remainingMinutesInOven` ফাংশন লিখতে চান, যা প্যারামিটার হিসেবে লাসানিয়া কত মিনিট ধরে ওভেনে আছে সেই সংখ্যাটি নেয় এবং আগের কাজে নির্ধারিত ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে রিটার্ন করে, লাসানিয়াকে আর কত মিনিট ওভেনে থাকতে হবে।
আগে আপনি `remainingMinutesInOven` ফাংশনের বাইরে থেকে আসা একটি কনস্ট্যান্ট মান, `expectedMinutesInOven`-এর উপর নির্ভর করেছিলেন।
এটা আপনার কাছে একটু বেশি জটিলও লাগছিল, আবার যথেষ্ট নমনীয়ও ছিল না, কারণ এতে ওভেনে প্রত্যাশিত সময় বদলানোর সুযোগ ছিল না।

সবকিছু গুছিয়ে নিতে `remainingMinutesInOven` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে লাসানিয়া কত মিনিট ধরে ওভেনে আছে সেই সংখ্যাটি নেয়, আর সেই সাথে একটি `expectedMinutesInOven` প্যারামিটারও নেয় যার ডিফল্ট মান ৪০।
আপনার ফাংশনটি আগের কাজে নির্ধারিত ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে রিটার্ন করবে, লাসানিয়াকে আর কত মিনিট ওভেনে থাকতে হবে।

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. বিভিন্ন সংখ্যক স্তরের সুযোগ

আপনি আগে একটি `preparationTimeInMinutes` ফাংশন লিখেছিলেন, যা প্যারামিটার হিসেবে আপনার লাসানিয়ায় যোগ করা স্তরের সংখ্যা নেয় এবং রিটার্ন করে লাসানিয়া প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন, এই ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।
তবে এই ফাংশনটি নিয়ে আপনি বিশেষ খুশি নন, কারণ এটি কল করার আগে আপনাকে নিজেই আপনার লাসানিয়ার স্তরগুলো গুনতে হয়, আর এসবের জন্য কার সময় আছে?

নিজের কাজ সহজ করতে একটি ফাংশন লিখুন, `preparationTimeInMinutes`, যা একটি ভ্যারিয়াডিক `String` প্যারামিটার, `layers` নেয়, যেখানে আপনি আপনার লাসানিয়ার বিভিন্ন স্তরের তালিকা দেন।
এরপর ফাংশনটি আপনার লাসানিয়ার স্তরের সংখ্যা গুনবে এবং প্রয়োজনীয় প্রস্তুতির সময় রিটার্ন করবে।

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. noodles ও sauce-এর পরিমাণ হিসাব করা

লাসানিয়া সাজানো শুরু করার আগে আপনি নিশ্চিত হতে চান যে আপনার স্বপ্নের লাসানিয়া বানানোর জন্য যথেষ্ট sauce আর noodles হাতে আছে।
আপনার লাসানিয়ার প্রতিটি noodle স্তরের জন্য ৩টি noodles লাগবে।
আর আপনার লাসানিয়ার প্রতিটি sauce স্তরের জন্য ০.২ লিটার sauce লাগবে।

`quantities` ফাংশনটি ডিফাইন করুন, যা একটি ভ্যারিয়াডিক `String` প্যারামিটার, `layers` নেয়, যেখানে আপনি আপনার লাসানিয়ার বিভিন্ন স্তরের তালিকা দেন।
এরপর ফাংশনটি আপনার খাবার তৈরি করতে কতটুকু noodles ও sauce লাগবে তা নির্ধারণ করবে। ফলাফলটি `(noodles: Int, sauce: Double)` টাইপের একটি টাপলে রিটার্ন করতে হবে।

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. লিটারকে ইন-প্লেসে ফ্লুইড আউন্সে রূপান্তর করা

দুর্ভাগ্যবশত, আপনার হাতে থাকা sauce-এর আয়তন লিটারের বদলে ফ্লুইড আউন্সে লেখা আছে।
হাতে যথেষ্ট sauce আছে কি না তা বুঝতে সাহায্য করার জন্য একটি ফাংশন লিখুন, `toOz`, যা একটি ইন-আউট টাপল প্যারামিটার, `(noodles: Int, sauce: Double)` নেয় এবং sauce-এর পরিমাণ ফ্লুইড আউন্সে রূপান্তর করে।
মনে রাখবেন, প্রতি লিটারে ৩৩.৮১৪ ফ্লুইড আউন্স হয়।

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. পরিবেশনের জন্য সেরা ওয়াইন নির্ধারণ করা

সবশেষে, আপনার লাসানিয়ার সাথে কোন ধরনের ওয়াইন পরিবেশন করবেন তা আপনি জানতে চান।
আপনি শুনেছেন, লাসানিয়ায় meat ও sauce-এর চেয়ে mozzarella, ricotta আর béchamel বেশি থাকলে সাদা ওয়াইন পরিবেশন করা উচিত, নাহলে লাল ওয়াইন।
একটি ফাংশন `redWine` লিখুন, যা একটি ভ্যারিয়াডিক `String` প্যারামিটার, `layers` নেয়, যেখানে আপনি আপনার লাসানিয়ার বিভিন্ন স্তরের তালিকা দেন।
ফাংশনটি পাঁচটি নেস্টেড ফাংশন ব্যবহার করে লাসানিয়ায় mozzarella, ricotta, béchamel, sauce ও meat-এর স্তর সংখ্যা নির্ধারণ করবে, এবং স্তরসংখ্যা তুলনা করে ঠিক করবে লাল ওয়াইন পরিবেশন করা উচিত কি না, উচিত হলে `true` এবং না হলে `false` রিটার্ন করবে।

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
