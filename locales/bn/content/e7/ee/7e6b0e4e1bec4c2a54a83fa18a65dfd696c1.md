# পরিচিতি

Julia-তে তিনটি প্রধান শর্তভিত্তিক স্টেটমেন্ট ব্যবহৃত হয়:

- `if` এক্সপ্রেশন
- টার্নারি অপারেটর
- শর্ট-সার্কিট ইভালুয়েশন

## `if` এক্সপ্রেশন

Julia-তে `if` এক্সপ্রেশন অন্য ভাষায় যেগুলো দেখা যায় সেগুলোর মতোই:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

`if`-এর পরে থাকা বুলিয়ান এক্সপ্রেশনটির মান `true` হলে কোডের প্রথম ব্লকটি চালানো হয় এবং দ্বিতীয় ব্লকটি বাদ দেওয়া হয়।
আর `if`-এর পরে থাকা বুলিয়ান এক্সপ্রেশনটির মান `false` হলে কোডের প্রথম ব্লকটি বাদ দেওয়া হয় এবং দ্বিতীয় ব্লকটি চালানো হয়।
এরপর প্রোগ্রামটি `end` কিওয়ার্ডের পরে থাকা কোডের প্রথম লাইন থেকে চলতে থাকে।

~~~~exercism/note
Julia-তে `end` কিওয়ার্ডটি সব ব্লক এক্সপ্রেশনের শেষ বোঝায়।
এই সিনট্যাক্স শুধু `if` এক্সপ্রেশন বা ফাংশন ডেফিনিশনের জন্য নয়।
~~~~

যেসব ক্ষেত্রে কোডের দ্বিতীয় ব্লকটি হয় কেবল আরেকটি `if` এক্সপ্রেশন, সেখানে `elseif` ব্যবহার করে ব্লকের ভেতরে `if` এক্সপ্রেশন নেস্ট করা এড়ানো যায়:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

কোনো `if` এক্সপ্রেশনে যদি কেবল একটি ক্ষেত্রের জন্য কোড চালানোর দরকার হয়, তাহলে `else` শাখাটি লেখার প্রয়োজন নেই।

## টার্নারি অপারেটর

সাধারণ `if-else` স্টেটমেন্টও টার্নারি অপারেটর `a ? b : c` দিয়ে লেখা যায়।
`a` যদি সত্য হয়, তাহলে `b`-এর মান নির্ণয় করা হবে।
অন্যথায় `c`-এর মান নির্ণয় করা হবে।

উদাহরণস্বরূপ, নিচের ফাংশনটি

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

এভাবেও লেখা যায়

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

কোনো শর্তের উপর নির্ভর করে একটি ভ্যারিয়েবলে ভিন্ন মান অ্যাসাইন করতে চাইলে এটি বিশেষভাবে কাজে লাগে।
`a` যদি `true` হয়, তাহলে `x = a ? b : c` `x`-এ `b` অ্যাসাইন করবে, অন্যথায় `x`-এ `c` অ্যাসাইন করবে।
উদাহরণ:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## শর্ট-সার্কিট ইভালুয়েশন

`&&` এবং `||` অপারেটর দিয়ে যদি একাধিক বুলিয়ান এক্সপ্রেশন শিকলের মতো জুড়ে দেওয়া হয়, তাহলে পুরো শিকলের মান নির্ণয়ের জন্য যতটুকু এক্সপ্রেশন নির্ণয় করা দরকার, Julia ঠিক ততটুকুই করবে।

উদাহরণ হিসেবে `n > 0 && k > 10` এক্সপ্রেশন শিকলটি ধরুন।
`n` যদি `5` হয়, তাহলে শিকলের প্রথম অংশ `n > 0` হলো `true`, আর পুরো এক্সপ্রেশনটি `true` কি না তা নির্ণয় করতে দ্বিতীয় এক্সপ্রেশন `k > 10`-ও নির্ণয় করা দরকার।
কিন্তু `n` যদি `-5` হয়, তাহলে আমরা জানি পুরো শিকলটি **কখনোই** `true` হতে পারে না, কারণ এর প্রথম এক্সপ্রেশনটি `false`।

এর বদলে `n > 0 || k > 10` ধরলে উল্টোটা ঘটে।
`n` যদি `5` হয়, তাহলে শিকলের প্রথম অংশ `n > 0` হলো `true`, আর আমরা জানি দ্বিতীয় এক্সপ্রেশন যা-ই হোক পুরো শিকলটি `true` হবে।
কিন্তু `n` যদি `-5` হয়, তাহলে দ্বিতীয় এক্সপ্রেশনটি নির্ণয় করা দরকার।

এই বৈশিষ্ট্য ব্যবহার করে খুব ছোট `if` স্টেটমেন্ট লেখা যায়:

```julia
if a
    b
end
```

এটি লেখার সমান

```julia
a && b
```

`&&` এবং `||`-এর শিকলে শেষ এক্সপ্রেশনটি বুলিয়ান এক্সপ্রেশন হওয়া জরুরি নয়।
এই সুবিধাটি প্রায়শই আগেভাগে এরর দেওয়া বা রিটার্ন করার জন্য ব্যবহৃত হতে দেখা যায়।
উদাহরণস্বরূপ, উপরের `dessert(fruit)` ফাংশনটি ব্যবহার করে:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
