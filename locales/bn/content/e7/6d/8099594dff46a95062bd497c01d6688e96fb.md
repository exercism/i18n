# ভূমিকা

## প্যাটার্ন ম্যাচিং লিটারেল

`if/else` এক্সপ্রেশন দিয়ে কন্ডিশনাল লজিক চালানো গেলেও, কন্ডিশনাল লজিক চালানোর আরও শক্তিশালী একটি উপায় Haskell-এ আছে: [প্যাটার্ন ম্যাচিং][pattern-matching]।
প্যাটার্ন ম্যাচিং দিয়ে একটি মানকে এক বা একাধিক _প্যাটার্নের_ বিপরীতে পরীক্ষা করা যায়।
এমন একটি প্যাটার্নের উদাহরণ হলো _কনস্ট্যান্ট প্যাটার্ন_, যা একটি মানকে একটি কনস্ট্যান্টের (যেমন `1` বা `"hello"`) সাথে মিলিয়ে দেখে।

ফাংশন ডিফাইন করার সময় আপনি ভিন্ন ভিন্ন প্যাটার্নের জন্য আলাদা ফাংশন বডি ডিফাইন করতে পারেন।
এতে কোড পরিষ্কার, সহজ ও পাঠযোগ্য হয়।
যেকোনো ডেটা টাইপে প্যাটার্ন ম্যাচ করতে পারেন: সংখ্যা, ক্যারেক্টার, অ্যারে, টুপল ইত্যাদি।

উদাহরণস্বরূপ, একটি পূর্ণসংখ্যা (`Int`) নিয়ে সেটিকে _0_-এর কাছে _1_ ধাপ কাছাকাছি নিয়ে আসে এমন একটি সহজ ফাংশন এভাবে লেখা যায়:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

অন্য প্যাটার্নের সাথে একসাথে ব্যবহার করলে প্যাটার্ন ম্যাচিংয়ের আসল জৌলুস ধরা পড়ে, যেমন _ভ্যারিয়েবল প্যাটার্ন_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

উপরের উদাহরণে _0_ ছাড়া বাকি সব ইনপুটকে একইভাবে দেখা হয়েছে, ফলে ঋণাত্মক সংখ্যার জন্য ভুল ফলাফল আসবে।
কন্ডিশনাল প্যাটার্ন ব্যবহার করে এটি সমাধান করা যায়, যাকে _গার্ড_ বলা হয় এবং যা `|` চিহ্ন দিয়ে লেখা হয়:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

উপরের উদাহরণগুলোতে সম্ভাব্য সব ইনপুটের জন্য মিলে যাওয়া প্যাটার্ন নেই।
কম্পাইলার এটি ধরে ফেলবে এবং একটি ওয়ার্নিং দেবে।
এটি Haskell-এর একটি অত্যন্ত কাজের বৈশিষ্ট্য, যা সব সম্ভাব্য পথ কভার হয়েছে কিনা নিশ্চিত করতে সাহায্য করে, যাতে রান-টাইম এরর এড়ানো যায়।
একে _এক্সহস্টিভ চেকিং_ বলা হয়।
ওয়ার্নিংটি দূর করতে আপনাকে সব কেস সামলাতে হবে।
_গার্ডের_ ভেতরে বাকি সব প্যাটার্ন ধরার জন্য `True`-এর সিনট্যাক্টিক সুগার হিসেবে `otherwise` এক্সপ্রেশনটি ব্যবহার করতে পারেন।

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

প্যাটার্ন ম্যাচিং একটি মানকে উপর থেকে নিচে একে একে প্রতিটি প্যাটার্নের সাথে পরীক্ষা করে, যতক্ষণ না মিলে যাওয়া একটি প্যাটার্ন পায় এবং সেই প্যাটার্নের সাথে সম্পর্কিত লজিক চালায়।
**প্যাটার্নের ক্রম গুরুত্বপূর্ণ!**
