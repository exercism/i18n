# সম্পর্কে

PHP-তে `while`-এর মতো বেশ কিছু বিল্ট-ইন লুপিং কন্ট্রোল স্ট্রাকচার আছে। একটি `while` স্টেটমেন্টের মূল রূপ হলো:

```php
while (expr) {
  // statements
}
```

এক্সপ্রেশনটি (_expr_) যতক্ষণ একটি _ট্রুথি_ মান দেয়, ততক্ষণ এটি লুপের ভেতরের স্টেটমেন্টগুলোর উপর ইটারেশন করবে। যদি প্রথম ইটারেশনের আগেই এক্সপ্রেশনটি (_expr_) ফলস মান দেয়, তাহলে স্টেটমেন্টগুলো কখনোই রান করা হয় না।

বিকল্পভাবে আপনি একটি `do-while` লুপ ব্যবহার করতে পারেন, যা এক্সপ্রেশনটি (_expr_) মূল্যায়ন করার আগে লুপের স্টেটমেন্টগুলো একবার রান করে।

```php
do {
  // statements
} while (expr);
```
