# পরিচিতি

R-এর একটি `list` হলো আইটেমের একটি ক্রমবদ্ধ সংগ্রহ, যা কয়েকটি দিক থেকে `vectors` থেকে আলাদা:

- আইটেমগুলো ভিন্ন ভিন্ন টাইপের হতে পারে (যেমন `numeric`-এর সাথে `character` মেশানো)।
- আইটেমগুলো জটিল গঠনও হতে পারে (যেমন ভেক্টর, অন্য লিস্ট ইত্যাদি)।
- এলিমেন্ট অ্যাক্সেস করার সিনট্যাক্সও কিছুটা আলাদা।

অন্য ভাষার সাথে এই তুলনাগুলো পুরোপুরি খাপ খায় না।
R-এর একটি `list` কিছুটা পাইথনের ডিকশনারির মতো, তবে `list` ক্রমবদ্ধ এবং সংখ্যাগত ইনডেক্স দিয়ে অ্যাক্সেস করা যায়।
এটি C-এর `struct`-এর সাথেও কিছুটা মেলে, তবে পার্থক্য হলো `list` রানটাইমে সহজেই বাড়ানো যায়।

## লিস্ট তৈরি করা

এলিমেন্টগুলোকে নাম দেওয়া (যাকে প্রায়ই "ট্যাগ" বলা হয়) ভেক্টরের চেয়ে লিস্টে বেশি দেখা যায়:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

তবে ট্যাগ ব্যবহার করা বাধ্যতামূলক নয়, সেক্ষেত্রে R শুধু ইনডেক্স নম্বর ব্যবহার করবে:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## লিস্টের এলিমেন্ট অ্যাক্সেস করা

এটি করার তিনটি উপায় আছে, প্রত্যেকটি ভিন্ন ভিন্ন প্রেক্ষাপটে কাজে লাগে।

### 1. `$tag` নোটেশন দিয়ে

ট্যাগের নাম আগে থেকেই জানা থাকলে এটি খুবই প্রচলিত।

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]` নোটেশন দিয়ে

এর সুবিধা হলো ট্যাগের নাম রানটাইমে বেছে নেওয়া যায়।
খেয়াল করুন, এখানে বন্ধনী দুবার আছে।

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. পজিশন ইনডেক্স দিয়ে

লিস্টে ট্যাগ থাকুক বা না থাকুক, এটি কাজ করে।
এখানেও বন্ধনী দুবার আছে।

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## এলিমেন্ট যোগ করা ও মুছে ফেলা

সহজ: কোনো এলিমেন্টে অ্যাসাইন করলে সেটি আগে থেকে থাকলে পরিবর্তিত হয়, আর নতুন হলে যোগ হয়।

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

মুছে ফেলতে হলে, যে এলিমেন্টটি দরকার নেই সেটিতে `NULL` অ্যাসাইন করুন।

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
