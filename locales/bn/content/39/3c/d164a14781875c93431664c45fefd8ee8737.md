# টাপল

Elm-এ টাপল দুই বা তিনটি মান ধারণ করতে পারে, আর প্রতিটি মানের টাইপ যেকোনো কিছু হতে পারে।
Elm-এ টাপল মূলত সরল, ক্ষণস্থায়ী টাইপের জন্য ব্যবহৃত হয়।
এই কারণেই টাপলে সর্বোচ্চ ৩টি মান থাকে, আর আরও নিরুৎসাহিত করতে সুবিধার ফাংশন কেবল ২টি মানের জন্যই দেওয়া হয়।
আরও জটিল ডেটার জন্য রেকর্ডে চলে যাওয়াই সবচেয়ে ভালো।
এর একটি কমন ব্যবহার হলো, যখন একটি ফাংশন থেকে একাধিক মান রিটার্ন করতে হয়।
টাপলের ফিল্ডের কোনো নাম থাকে না; ডিস্ট্রাকচারিং বা অবস্থান দিয়ে সেগুলো অ্যাক্সেস করা হয়।

আপনি [টাপলের একটি সংক্ষিপ্ত পরিচিতি][tuples-concise] পড়তে পারেন।
এছাড়াও আছে [আরও গভীরভাবে পরিচিতি][tuples-in-depth], আর [Tuple মডিউলের API ডক][tuple-core]-এ আছে কোডের উদাহরণ আর বিস্তারিত ডকুমেন্টেশন।

## ডিক্লারেশন

টাপলের টাইপ তৈরি হয় বন্ধনী দিয়ে, আর এর এলিমেন্ট টাইপগুলো কমা দিয়ে আলাদা করা হয়।

```elm
type alias IntStringTuple = (Int, String)
```

### তৈরি করা

টাপল তৈরি হয় বন্ধনী দিয়ে, আর এর এলিমেন্টগুলো কমা দিয়ে আলাদা করা হয়।

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

দুটি মানের একটি টাপল তৈরি করতে `Tuple.pair`-ও ব্যবহার করতে পারেন।

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### অ্যাক্সেস

অবস্থান অনুযায়ী টাপলের মান অ্যাক্সেস করার ফাংশনও আছে: `Tuple.first` আর `Tuple.second`।

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

বাইন্ডিংয়ে টাপল প্যাটার্ন ম্যাচিং ব্যবহার করে টাপলকে _ডিস্ট্রাকচার_ করা যায়।
ডিস্ট্রাকচারিং করা যায় let এক্সপ্রেশন, ফাংশন ডিক্লারেশন আর case স্টেটমেন্টে।

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

case স্টেটমেন্টে প্যাটার্ন ম্যাচিং দিয়ে মানগুলোর ভেতরের বিষয়বস্তুর সঙ্গেও মেলানো যায়:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
