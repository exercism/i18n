# টেস্ট

## টেস্ট চালানো

টেস্ট চালাতে হলে নিচের কমান্ডটি চালান:

```bash
make
```

## অনুশীলনী সমাধান করা

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো। ডিফল্টভাবে আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) চালানো হয়। এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন। এটি পাস হয়ে গেলে `TEST_IGNORE()` লাইনটি মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন। সব টেস্ট চালু হয়ে গেলে এবং আপনার ইমপ্লিমেন্টেশন সেগুলো সব পাস করালে, আপনি অনুশীলনীটি সমাধান করে ফেলেছেন!
