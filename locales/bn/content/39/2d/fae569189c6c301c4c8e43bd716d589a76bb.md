# নির্দেশাবলি

আপনার এক বন্ধুর **Gross Store** নামে একটি পুরনো পাইকারি দোকান আছে।

দোকানটি যে পরিমাণে পণ্য বিক্রি করে, সেই থেকেই এই নাম এসেছে: সবকিছুই হিসাব করা হয় [গ্রস একক][gross-unit]-এ।

আপনার বন্ধু আপনাকে তার দোকানের জন্য একটি পয়েন্ট অফ সেল (POS) সিস্টেম তৈরি করতে বলেছেন।

**প্রথমে আপনি এটির একটি প্রোটোটাইপ বানাতে চান।**

**আপনার প্রোটোটাইপে আপনার সিস্টেম শুধু পরিমাণ রেকর্ড করবে।**

সহায়তার জন্য আপনার বন্ধু আপনাকে পরিমাপের একটি তালিকা দিয়েছেন:

| একক               | স্কোর |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. পরিমাপের একক আপনার প্রোগ্রামে সংরক্ষণ করুন

পরিমাপটি ব্যবহার করতে হলে আপনাকে সেটি আপনার প্রোগ্রামে সংরক্ষণ করতে হবে।

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. নতুন একটি কাস্টমার বিল তৈরি করুন

কাস্টমারের জন্য একটি নতুন (খালি) বিল তৈরি করে এমন একটি ফাংশন আপনাকে তৈরি করতে হবে।

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. কাস্টমার বিলে একটি আইটেম যোগ করুন

এটি করতে হলে আপনাকে যা যা করতে হবে:

- প্রদত্ত `unit` যদি `units` ম্যাপে না থাকে, তবে `false` রিটার্ন করুন।
- অন্যথায় আইটেমটি কাস্টমার `bill`-এ যোগ করুন, আইটেমের নাম দিয়ে ইনডেক্স করে, তারপর `true` রিটার্ন করুন।
- আইটেমটি যদি ইতিমধ্যে বিলে উপস্থিত থাকে, তবে প্রদত্ত `unit`-এর অন্তর্গত পরিমাণ দিয়ে তার পরিমাণ বাড়িয়ে দিন।

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> মনে রাখবেন, রিটার্ন ভ্যালুটি `bool` টাইপের।

## 4. কাস্টমার বিল থেকে একটি আইটেম সরান

এটি করতে হলে আপনাকে যা যা করতে হবে:

- প্রদত্ত আইটেমটি যদি বিলে **না** থাকে, তবে `false` রিটার্ন করুন।
কোনো আইটেমের পরিমাণ 0 হলে সেটিকে বিলে নেই বলে ধরা হয়।
- প্রদত্ত `unit` যদি `units` ম্যাপে না থাকে, তবে `false` রিটার্ন করুন।
- নতুন পরিমাণ যদি 0-এর কম হয়, তবে `false` রিটার্ন করুন।
- নতুন পরিমাণ যদি 0 হয়, তবে আইটেমটি `bill` থেকে সরানো হয়েছে বলে ধরা হয়, তাই আপনি `true` রিটার্ন করতে পারেন।
- অন্যথায় আইটেমের পরিমাণ কমান এবং `true` রিটার্ন করুন।

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> মনে রাখবেন, রিটার্ন ভ্যালুটি `bool` টাইপের।

## 5. কাস্টমার বিলে থাকা একটি নির্দিষ্ট আইটেমের পরিমাণ রিটার্ন করুন

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> মনে রাখবেন, রিটার্ন ভ্যালুটি `u32` টাইপের।
