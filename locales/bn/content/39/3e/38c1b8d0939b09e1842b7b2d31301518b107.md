# Instructions

Lucian-এর বান্ধবী এখন বাড়ির পথে, অথচ তিনি তাদের বিবাহবার্ষিকীর রাতের খাবার এখনও রান্না করেননি!

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যাতে Lucian তার প্রিয় রান্নার বই দেখে একটি চমৎকার লাসাগনা রান্না করতে পারেন।

লাসাগনা রান্না করতে যে সময় লাগে, তার সঙ্গে সম্পর্কিত চারটি কাজ আপনার সামনে আছে।

## 1. মিনিটে প্রত্যাশিত ওভেনের সময় নির্ধারণ করুন

`EXPECTED_MINUTES_IN_OVEN` কনস্ট্যান্টটি ডিফাইন করুন, যেটি বোঝায় লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত। এটি এক্সপোর্ট করা আবশ্যক। রান্নার বই অনুযায়ী, মিনিটে প্রত্যাশিত ওভেনের সময় হলো `40`।

## 2. মিনিটে বাকি ওভেনের সময় হিসাব করুন

`remainingMinutesInOven` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি _প্যারামিটার_ হিসেবে নেয় লাসাগনাটি এখন পর্যন্ত কত মিনিট ওভেনে আছে, আর আগের কাজের **মিনিটে প্রত্যাশিত ওভেনের সময়** অনুযায়ী _রিটার্ন করে_ লাসাগনাটিকে আরও কত মিনিট ওভেনে থাকতে হবে।

```javascript
remainingMinutesInOven(30);
// => 10
```

## 3. মিনিটে প্রস্তুতির সময় হিসাব করুন

`preparationTimeInMinutes` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি _প্যারামিটার_ হিসেবে নেয় আপনি লাসাগনায় কতগুলো স্তর যোগ করেছেন, আর _রিটার্ন করে_ লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে। ধরে নিন, প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```javascript
preparationTimeInMinutes(2);
// => 4
```

## 4. মিনিটে মোট কাজের সময় হিসাব করুন

`totalTimeInMinutes` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি _দুটি প্যারামিটার_ নেয়: `numberOfLayers` প্যারামিটারটি হলো আপনি লাসাগনায় যোগ করা স্তরের সংখ্যা, আর `actualMinutesInOven` প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ওভেনে আছে তার সংখ্যা। ফাংশনটি _রিটার্ন করবে_ লাসাগনা রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```javascript
totalTimeInMinutes(3, 20);
// => 26
```
