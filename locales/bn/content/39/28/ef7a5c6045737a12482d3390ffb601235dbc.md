# সংখ্যা

`INT` হলো Sather-এ পূর্ণসংখ্যার টাইপ: `0`, `7`, `-3`। যে রুটিন পূর্ণসংখ্যা দিয়ে উত্তর দেয়, সেটি কোলনের পরে তা জানিয়ে দেয়, ঠিক যেভাবে টেক্সট দিয়ে উত্তর দেওয়া একটি রুটিন `STR` লেখে।

```sather
   goals : INT is
      return 42;
   end;
```

রুটিন **আর্গুমেন্ট** নিতে পারে, অর্থাৎ রুটিনটি কল করার সময় যে মানগুলো দেওয়া হয়। প্রতিটি আর্গুমেন্টের একটি নাম থাকে এবং একটি টাইপ দেওয়া হয়, রুটিনের নামের পরে বন্ধনীর ভেতরে:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

যখন দুটি আর্গুমেন্টের টাইপ একই হয়, তখন আপনি তাদের একসাথে নাম দিতে পারেন:

```sather
   total(first, second : INT) : INT is
```

বন্ধনীর ভেতরে মানগুলো বসিয়ে এটি কল করুন:

```sather
SCORES::total(3, 4)     -- this is 7
```

পাটিগণিতের পাঁচটি অপারেটর হলো `+`, `-`, `*`, `/` এবং `%`।

দুটি `INT`-এর ওপর `/` হলো **ইন্টিজার ডিভিশন**: এটি ভগ্নাংশ না দিয়ে যেকোনো ভাগশেষ ফেলে দেয়।

```sather
7 / 2      -- 3, not 3.5
```

`%` সেই ভাগ থেকে যা বাকি থাকে তা দেয়।

```sather
7 % 2      -- 1
```

দুটি একসাথে কাজ করে: `7` হলো `3` বার `2`, আর বাকি থাকে `1`।
