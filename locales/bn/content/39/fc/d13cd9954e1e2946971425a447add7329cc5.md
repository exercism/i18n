# ভূমিকা

কোনো প্রোগ্রাম বা কোডের অংশে কিছু ভুল বা অপ্রত্যাশিত হলে এরর রিপোর্ট করা কাজে লাগে।

এগুলো JavaScript অবজেক্ট।

এই অবজেক্টের প্রধান প্রপার্টি হলো `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw` সিনট্যাক্স ব্যবহার করে আপনি একটি এরর থ্রো করতে পারেন।

```javascript
throw new Error('Oops');
```

যখন একটি `Error` থ্রো করা হয়, তখন বর্তমান এক্সিকিউশন থেমে যায় এবং কল স্ট্যাকের প্রথম catch ব্লকে আবার শুরু হয়।

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

JavaScript-এর যেকোনো ক্লাসের মতোই, সাবক্লাসগুলো `extends` কিওয়ার্ড ব্যবহার করে `Error` থেকে ইনহেরিট করে কাস্টম এরর তৈরি করতে পারে।
`instanceof` সিনট্যাক্স পরীক্ষা করবে ধরা পড়া এররটি `Error`-এর কোনো নির্দিষ্ট সাবক্লাসের ইনস্ট্যান্স কি না।

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
