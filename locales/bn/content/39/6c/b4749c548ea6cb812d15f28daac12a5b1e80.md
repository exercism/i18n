# নির্দেশনার সংযোজন

## ফাংশন ও টেস্টিং

`SayHi` ফাংশনের জন্য একটি শুরুর ডেফিনিশন আপনাকে দেওয়া হয়েছে।

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

টেস্ট রানার এই ফাংশনটি নিয়ে সেটি রান করে, আর ফাংশনটি যে মান [রিটার্ন করে][returns] তার সঙ্গে প্রত্যাশিত মান তুলনা করে।
এই শুরুর ফাংশন ডেফিনিশনটিকেই আপনার সমাধানের ভিত্তি হিসেবে ব্যবহার করুন।

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
