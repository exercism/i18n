# ভূমিকা

## Alias

একই প্রজেক্টের ভিন্ন ভিন্ন Elixir মডিউলের মধ্যে কোড শেয়ার করতে হলে আপনাকে বাইরের মডিউলটিকে তার পুরো নাম দিয়ে রেফারেন্স করতে হবে। কিন্তু ওই নামটি যদি খুব লম্বা বা বিভ্রান্তিকর হয়?

`alias` নামের বিশেষ ফর্মটি দিয়ে আপনি বাইরের কোনো মডিউল যে নামে রেফারেন্স করেন, সেটি ছোট বা বদলে দিতে পারেন। কোনো আর্গুমেন্ট ছাড়া ব্যবহার করলে এটি মডিউলের নামটি ছেঁটে তার শেষ অংশটুকুতে নামিয়ে আনে, যেমন `MyApp.Logger.Settings` হয়ে যায় `Settings`। `:as` অপশন দিয়ে একটি কাস্টম নাম নির্দিষ্ট করা যায়।

সাধারণত alias মডিউল ডেফিনিশনের শুরুতে যোগ করা হয়।

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

`import` নামের বিশেষ ফর্মটি দিয়ে আপনি মডিউলের নাম না লিখেই বাইরের কোনো মডিউলের ফাংশন ব্যবহার করতে পারেন।

পুরো একটি বাইরের মডিউল ইমপোর্ট করলে বিদ্যমান লোকাল ফাংশনের সাথে কনফ্লিক্ট তৈরি হতে পারে। এটি এড়াতে দুটি অপশন আছে: `:except` এবং `:only`। দুটিই একটি কিওয়ার্ড লিস্ট আশা করে, যেখানে কী (key) হলো ফাংশনের নাম আর মান হলো ফাংশনের আর্গুমেন্ট সংখ্যা।

সাধারণত import মডিউল ডেফিনিশনের শুরুতে যোগ করা হয়।

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
