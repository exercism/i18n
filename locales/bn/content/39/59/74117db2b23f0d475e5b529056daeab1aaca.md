# নির্দেশাবলী

নেটবল প্রশিক্ষণ শুরু হয় ল্যাপ দিয়ে। কোচ প্রতিটি ল্যাপ আগেরটির চেয়ে একটু লম্বা করে দেন: প্রথমটি ১০০ মিটার, দ্বিতীয়টি ১১০, তৃতীয়টি ১২০, এভাবে প্রতি ল্যাপে দশ মিটার করে বাড়ে।

তিনটি কাজই `WARM_UP_LAPS` ক্লাসে থাকবে।

## 1. সব মিলিয়ে কত দূর?

কয়েকটি ল্যাপ দেওয়া থাকলে, মোট দূরত্ব বের করুন।

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

অর্থাৎ ১০০ + ১১০ + ১২০। শূন্য ল্যাপ মানে শূন্য মিটার।

## 2. একটি দূরত্বে পৌঁছাতে কত ল্যাপ?

মিটার এককে একটি দূরত্ব দেওয়া থাকলে, মোট অন্তত ততদূর না হওয়া পর্যন্ত কতগুলি ল্যাপ লাগে?

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

শূন্য মিটারের জন্য কোনো ল্যাপই লাগে না।

## 3. কোন ল্যাপটি প্রথম লম্বা হয়?

মিটার এককে একটি দূরত্ব দেওয়া থাকলে, কোন ল্যাপটি *নিজে* তার চেয়ে লম্বা হয় প্রথম? ল্যাপ ১ হলো ১০০ মিটার, ল্যাপ ২ হলো ১১০, এভাবেই চলতে থাকে।

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

ল্যাপ ৩ হলো ১২০ মিটার, যা ১১৫-এর বেশি হওয়া প্রথম ল্যাপ।
