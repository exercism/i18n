# ভূমিকা

Common Lisp-এ হ্যাশ টেবিল হলো অ্যাসোসিয়েটিভ ডেটা সংরক্ষণের জন্য ডেটা স্ট্রাকচার। 
এরা কী (key)-কে মানের সাথে ম্যাপ করে (কী (key) এবং মান, দুটোই যেকোনো অবজেক্ট হতে পারে)। 
অন্য ভাষায় এই কনসেপ্টটিকে ম্যাপ, ডিকশনারি বা হ্যাশ বলা হতে পারে।

## হ্যাশ টেবিল তৈরি করা

হ্যাশ টেবিল `make-hash-table` ফাংশন দিয়ে তৈরি করা যায়।

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(লক্ষ্য করুন, একটি হ্যাশ টেবিলের প্রিন্ট হওয়া রূপ ইমপ্লিমেন্টেশন-নির্ভর, তাই আপনার REPL-এ এটি ভিন্নভাবে দেখা যেতে পারে।)

## কী (key) দিয়ে মান বের করা

হ্যাশ টেবিল থেকে একটি কী (key) দিয়ে একটি মান পেতে আপনি `gethash` ফাংশন ব্যবহার করেন:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` [একাধিক মান][concept-multiple-values] রিটার্ন করে, যা অন্য একটি কনসেপ্টে ব্যাখ্যা করা হবে।

## মান ইনসার্ট করা

একটি হ্যাশ টেবিলে একটি মান ইনসার্ট করতে আপনি এভাবে `gethash`-এর সাথে `setf` ব্যবহার করেন:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

এটি হ্যাশ টেবিল `*hash-table*`-এ `:foo` কী (key)-এর মান `:bar`-এ পরিবর্তন করবে।
এটি মানটি রিটার্ন করে।

`setf`-এর ব্যবহার অন্য একটি কনসেপ্টে ব্যাখ্যা করা হবে।
