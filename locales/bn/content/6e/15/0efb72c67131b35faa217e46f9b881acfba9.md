# ভূমিকা

JavaScript-এ মান বিভিন্ন টাইপের হতে পারে। এক্সপ্লিসিট _টাইপ কনভার্সন_-এর মাধ্যমে একটি ভ্যারিয়েবলের টাইপ পরিবর্তন করা যায়।
এর পাশাপাশি, কনটেক্সটের প্রয়োজন হলে JavaScript _টাইপ কোয়ার্সন_ (ইমপ্লিসিট টাইপ কনভার্সন)-ও করে।

## টাইপ কনভার্সন

অনেক ভাষার মতো ভিন্ন টাইপে কাস্ট করার কোনো কনস্ট্রাক্ট JavaScript-এ নেই, তবে বদলে কিছু বিল্ট-ইন হেল্পার ব্যবহার করা যায়।
বিশেষ করে, `Boolean`, `Number` ও `String`-কে ফাংশন হিসেবে ব্যবহার করে একটি মানকে সংশ্লিষ্ট টাইপে রূপান্তর করা যায়।

### বুলিয়ানে রূপান্তর (ট্রুথি/ফালসি মান)

`Boolean(value)` দিয়ে আপনি যেকোনো মানকে বুলিয়ানে রূপান্তর করতে পারেন।
এমন কিছু নির্দিষ্ট মান আছে, যাদের _ফালসি_ মান বলা হয়, যেগুলো `false`-এ রূপান্তরিত হয়।
সবচেয়ে গুরুত্বপূর্ণ হলো, `false`, `0`, খালি স্ট্রিং, `null`, `undefined` ও `NaN` ফালসি।

বাকি সব মানের জন্য `Boolean` `true` ফেরত দেয়।
এই মানগুলোকে _ট্রুথি_ বলা হয়।

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

মনে রাখবেন, বর্ণিত নিয়ম অনুযায়ী JavaScript-এ `'0'`, `'false'`, `[]` ও `{}` **ট্রুথি**।

### সংখ্যায় রূপান্তর

`Number(value)` দিয়ে একটি মানকে সংখ্যায় রূপান্তর করা যায়।
স্ট্রিংয়ের শুরুতে ও শেষে থাকা হোয়াইটস্পেস উপেক্ষা করা হয়, আর খালি স্ট্রিং `0`-এ রূপান্তরিত হয়।
আপনি যদি কোনো নন-প্রিমিটিভ ভ্যালু বা এমন স্ট্রিং রূপান্তর করতে চেষ্টা করেন যা কোনো সংখ্যা বোঝায় না, তাহলে ফলাফল হয় `NaN` ([Not-A-Number][mdn-nan])।

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### স্ট্রিংয়ে রূপান্তর

`String(value)` দিয়ে আপনি একটি মানকে স্ট্রিংয়ে রূপান্তর করতে পারেন।
প্রিমিটিভ ভ্যালুর ক্ষেত্রে ফলাফল ঠিক যা আপনি আশা করবেন তাই।

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

অ্যারের ক্ষেত্রে `String` ফাংশন প্রতিটি এলিমেন্টের উপর স্ট্রিং কনভার্সন প্রয়োগ করে ফলাফলগুলো কমা দিয়ে জোড়া লাগায়।
আপনি নিজেও [`join` মেথড][mdn-join] প্রয়োগ করতে পারেন, যেমন সেপারেটর কাস্টমাইজ করার জন্য।
মনে রাখবেন, এসব ক্ষেত্রে `null` ও `undefined` খালি স্ট্রিংয়ে রূপান্তরিত হয়।

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

অবজেক্টের ক্ষেত্রে ডিফল্টভাবে `String` কাজের নয় এমন একটি স্ট্রিং রিটার্ন করে।

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## টাইপ কোয়ার্সন

কিছু কনটেক্সটে, কোনো স্টেটমেন্ট ইভ্যালুয়েট করার আগে JavaScript স্বয়ংক্রিয়ভাবে একটি মানকে অন্য ডেটা টাইপে রূপান্তর করে।
এই ইমপ্লিসিট রূপান্তরকে _টাইপ কোয়ার্সন_ বলা হয়।

### বুলিয়ান কনটেক্সট

বুলিয়ান কনটেক্সটে কোনো নন-বুলিয়ান মান ব্যবহার করলে JavaScript `Boolean` ফাংশনের মতো একই নিয়ম প্রয়োগ করে মানটিকে ইমপ্লিসিটভাবে রূপান্তর করে।

বুলিয়ানে কোয়ার্সন সাধারণত ঘটে

- একটি [`if` স্টেটমেন্টের][concept-conditionals] শর্তে
- [টারনারি অপারেটর][mdn-ternary] `?`-এর প্রথম অপারেন্ডে
- লজিক্যাল NOT অপারেটর `!`-এর অপারেন্ডে
- লজিক্যাল AND `&&` এবং OR `||` অপারেটরের অপারেন্ডে (এক্সপ্রেশনের ফলাফল অপারেন্ডগুলোর একটি, সবসময় বুলিয়ান নয়)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### স্ট্রিং কনটেক্সট

প্রিমিটিভ ভ্যালুর ক্ষেত্রে যোগ অপারেটর `+` ব্যবহার করলে এবং একটি অপারেন্ড স্ট্রিং হলে, অন্যটিও স্ট্রিংয়ে কোয়ার্স করা হয়।
রূপান্তরের যুক্তি `String` ফাংশন ব্যবহারের সময়ের মতোই।
এরপর দুটি স্ট্রিং কনক্যাটিনেট করা হয়।

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### নিউমেরিক কনটেক্সট

অনেক অপারেটর উপরে ব্যাখ্যা করা `Number` ফাংশনের যুক্তি অনুযায়ী অপারেন্ডগুলোকে (প্রয়োজনে) সংখ্যায় কোয়ার্স করে।

- অ্যারিথমেটিক অপারেটর: `+` (কোনো স্ট্রিং জড়িত না থাকলে), `-`, `*`, `/`, `%`, `**`
- ইউনারি প্লাস ও ইউনারি নেগেশন অপারেটর: `+`, `-`
- রিলেশনাল অপারেটর (নন-স্ট্রিং অপারেন্ডের ক্ষেত্রে): `>`, `>=`, `<`, `<=`
- বিটওয়াইজ অপারেটর: `|`, `&`, `^`, `~`

ওই অপারেটরগুলোর যেকোনোটির ব্যাপারে আরও বিস্তারিত জানতে [MDN অপারেটরের তালিকা][mdn-operators] দেখুন।

ভুল এড়াতে, এসব অপারেটর প্রয়োগ করার আগে সবসময় স্পষ্টভাবে `Number` কল করা ভালো অভ্যাস।
