# নির্দেশাবলি

এই অনুশীলনীতে আপনি একজন ডেভেলপারকে আইডেন্টিফায়ার নাম পরিষ্কার করতে সাহায্য করার জন্য কিছু ইউটিলিটি রুটিনের একটি আংশিক সেট তৈরি করবেন।

৬টি টাস্কে আপনি ধীরে ধীরে ফাংশন দুটি গড়ে তুলবেন: `transform`, যা একক ক্যারেক্টার রূপান্তর করে, এবং `clean`, যা স্ট্রিং রূপান্তর করে।

একটি বৈধ আইডেন্টিফায়ারে শূন্য বা তার বেশি অক্ষর, আন্ডারস্কোর, হাইফেন, প্রশ্নচিহ্ন এবং ইমোজি থাকতে পারে।

`clean` ফাংশনে যদি একটি খালি স্ট্রিং পাস করা হয়, তাহলে একটি খালি স্ট্রিং রিটার্ন করা উচিত।

## 1. যেকোনো হাইফেনকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করুন

যেকোনো হাইফেনকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করার জন্য `transform` ফাংশনটি তৈরি করুন।

```fsharp
transform '-'  // => "_"
```

## 2. সব হোয়াইটস্পেস মুছে ফেলুন

সব হোয়াইটস্পেস ক্যারেক্টার মুছে ফেলুন।
এর মধ্যে শুরু ও শেষের হোয়াইটস্পেসও অন্তর্ভুক্ত।

```fsharp
transform ' '  // => ""
```

## 3. camelCase-কে kebab-case-এ রূপান্তর করুন

camelCase-কে kebab-case-এ রূপান্তর করতে `transform` ফাংশনটি পরিবর্তন করুন

```fsharp
transform 'D'  // => "-d"
```

## 4. যে ক্যারেক্টারগুলো ডিজিট, সেগুলো বাদ দিন

যে ক্যারেক্টারগুলো সংখ্যা, সেগুলো বাদ দিতে `transform` ফাংশনটি পরিবর্তন করুন।

```fsharp
transform '7'  // => ""
```

## 5. গ্রিক ছোট হাতের অক্ষরকে প্রশ্নচিহ্ন দিয়ে প্রতিস্থাপন করুন

'α' থেকে 'ω' পরিসরের যেকোনো গ্রিক অক্ষর প্রতিস্থাপন করতে `transform` ফাংশনটি পরিবর্তন করুন।

```fsharp
transform 'β' // => "?"
```

## 6. একটি স্ট্রিং-এর উপর কাজ করতে এই অপারেশনগুলো একত্র করুন

সম্পূর্ণ একটি স্ট্রিং-এর উপর এই অপারেশনগুলো প্রয়োগ করতে `clean` ফাংশনটি তৈরি করুন।

নিয়মের বাইরে পড়ে এমন ক্যারেক্টারগুলো অপরিবর্তিতভাবেই পাস হয়ে যাবে।

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## ক্যারেক্টার থেকে একটি স্ট্রিং তৈরি করা

এই বিষয়টি পাঠ্যক্রমে পরে বিস্তারিতভাবে আলোচনা করা হবে।

আপাতত জেনে রাখা কাজে লাগতে পারে যে [`String.collect`][string-collect] নামে একটি [হায়ার অর্ডার ফাংশন][higher-order-function] আছে, যা আপনার দেওয়া একটি ফাংশন ব্যবহার করে `char`-এর একটি কালেকশনকে স্ট্রিং-এ রূপান্তর করে।

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
