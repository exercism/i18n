# ইনস্টলেশন

## ইনস্টলেশন

টার্মিনাল কমান্ড লাইন থেকে [zero conf](http://pharo.org/download#//*[@id="main"]/div/h2[3]) ডাউনলোড ব্যবহার করে [Pharo](http://pharo.org) ইনস্টল করা সবচেয়ে সহজ উপায়।
<br/>_দ্রষ্টব্য: আপনি যদি আগে থেকে ইনস্টল করা কোনো একটি ইনস্টলেশন আপগ্রেড করতে চান, তাহলে [upgrade instructions](https://github.com/exercism/pharo-smalltalk/blob/main/docs/UPGRADE.md) দেখুন।_

যেসব Windows ব্যবহারকারীর কম্পিউটারে UNIX ঘরানার শেল ইনস্টল করা নেই, তারা নিচের [Windows Installation](#windows-installation-skip-for-osxlinux) নির্দেশাবলিতে চলে যান।<br/>
আরও অভিজ্ঞ Linux ব্যবহারকারীরা [Linux Hackers Installation](https://github.com/exercism/pharo-smalltalk/blob/main/docs/LINUX.md) দেখতে পারেন।

### Linux/OSX ইনস্টলেশন

Linux/OSX-এর জন্য (ধরে নিচ্ছি আপনি [Exercism ইনস্টল করেছেন](https://exercism.io/getting-started) এবং [Pharo ট্র্যাক](https://exercism.io/my/tracks/pharo-smalltalk)-এ যুক্ত হয়েছেন), আপনার `/Exercism/pharo-smalltalk` ডিরেক্টরিতে গিয়ে টাইপ করুন:

```bash
curl https://get.pharo.org/64/ | bash
```

তারপর নিচের "load script" পেস্ট করে exercism টুলস-সহ Pharo চালু করুন:

```smalltalk
./pharo-ui Pharo.image eval "
Iceberg remoteTypeSelector: #httpsUrl.
Metacello new
 baseline: 'Exercism';
 repository: 'github://exercism/pharo-smalltalk:main/releases/latest';
 load.
#ExercismManager asClass welcome.
"
```

টুলস লোড করার সময় কোনো TIMEOUT সমস্যা হলে Pharo থেকে বেরিয়ে গিয়ে এভাবে টাইপ করে git ক্যাশ পরিষ্কার করুন:

```rm -rf pharo-local/iceberg/```

তারপর উপরের ```./pharo-ui ...``` উদাহরণটি আবার চালান।

সমস্যা থেকে গেলে অনুগ্রহ করে [Pharo Community](http://pharo.org/community) পাতায় বর্ণিত Pharo Discord চ্যানেলে যান।

সবকিছু ঠিকঠাক চললে স্ক্রিন জুড়ে লোডিং প্রগ্রেস বারগুলো জ্বলজ্বল করতে দেখবেন, তারপর একটি System Browser উইন্ডো খুলে যাবে।

**টিপস:** Pharo থেকে বেরোনোর সময় আপনার পরিবর্তনগুলো সেভ করুন (Pharo মেনু থেকে "Save and Quit" নির্বাচন করুন)।
এখন শুধু নিচেরটা টাইপ করলেই Exercism আগে থেকেই লোড করা অবস্থায় Pharo শুরু করতে পারবেন:

```bash
./pharo-ui Pharo.image
```

### Windows ইনস্টলেশন (OSX/Linux ব্যবহারকারীরা এটি এড়িয়ে যান)

Windows-এর জন্য সেরা কমান্ড লাইন টুলের পূর্বশর্তগুলো নিয়ে আমরা এখনও কাজ করছি, তবে [Windows Pharo Launcher](https://files.pharo.org/pharo-launcher/windows) ব্যবহার করে গ্রাফিকালভাবেও Pharo ইনস্টল করতে পারেন (একাধিক Pharo ইমেজ সামলানোর একটি সুবিধাজনক টুল)। GUI পছন্দ হলে OSX আর Linux-এর জন্যও এই লঞ্চারটি [পাওয়া যায়](http://pharo.org/download)।

1. ডাউনলোড করা .msi ফাইলটি চালিয়ে Pharo Launcher ইনস্টল করুন।  
2. Pharo Launcher চালু করুন।  
3. উপরের বাম কোণায় "New" ক্লিক করুন। 
4. উইন্ডোতে template categories থেকে "Official distributions" নির্বাচন করুন।  
5. Exercism অনুশীলনীর জন্য Pharo image template-এর তালিকা থেকে সর্বশেষ স্থিতিশীল রিলিজটি বেছে নিন (বর্তমানে সুপারিশ করা হয় "Pharo 10.0 64-bit (stable)")। 
6. একটি image template ক্লিক করে হাইলাইট করুন, তার একটি নাম দিন, তারপর নিচের create image বোতামটিতে ক্লিক করুন (কমলা রঙের একটি গিয়ার আকৃতি)।  
![লঞ্চার থেকে ইমেজ তৈরি](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Create-image-from-launcher.png)
7. template ডাউনলোড হয়ে গেলে ডান দিকে Existing Images টেবিলে সেটি দেখা যাবে। সেটিতে ক্লিক করুন, তারপর উপরের launch বোতামে ক্লিক করুন (সবুজ রঙের একটি _play_ তীর)।  
![ইমেজ চালু করা](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Launch-image.png)


8. Pharo image চালু হয়ে গেলে _Browse_ মেনু থেকে _Playground_ নির্বাচন করে একটি Playground খুলুন, অথবা `ctrl + o + w` ব্যবহার করুন।  
![Playground খোলা](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/Open-Playground.png)


9. সবশেষে নিচের অংশটি কপি করে playground-এ পেস্ট করুন:
```smalltalk
Iceberg remoteTypeSelector: #httpsUrl.
Metacello new
 baseline: 'Exercism';
 repository: 'github://exercism/pharo-smalltalk:main/releases/latest';
 load.
#ExercismManager asClass welcome.
```

তারপর পেস্ট করা কোডটি পুরোটা হাইলাইট করে, ডান ক্লিক করে মেনু থেকে _Do it_ নির্বাচন করে evaluate করুন (অথবা `ctrl + d` ব্যবহার করুন)।

**সবকিছু ঠিকঠাক চললে** স্ক্রিন জুড়ে লোডিং প্রগ্রেস বারগুলো জ্বলজ্বল করতে দেখবেন, তারপর একটি System Browser উইন্ডো খুলে যাবে।


## শুরু করা যাক (সবার জন্য)

Pharo চালু করলে আপনি একটি Welcome project দেখতে পাবেন, একটি [System Browser](https://medium.com/@richardeng/pharo-quick-start-5bab70944ce2#3099)-এ (_টিপস:_ কোনো সময়ে এই উইন্ডোটি হারিয়ে ফেললে Tools|System Browser মেনু থেকে নতুন একটি খুলতে পারেন)।


![Pharo-এর Welcome স্ক্রিন](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/PharoWelcomeScreen.png)

System browser-এর উপরের বাম দিকের প্যানেলে আপনার এনভায়রনমেন্টের প্যাকেজগুলো দেখা যায়, আর দেখবেন ইনস্টল স্ক্রিপ্ট ইতিমধ্যেই `Exercism` নামের একটি প্যাকেজ কনফিগার করে রেখেছে, যার ভেতরে `Welcome` নামের একটি sub-project ট্যাগ আছে। দ্বিতীয় প্যানেলে ক্লাসগুলো থাকে, সেখানেও `Welcome` নামের একটি ক্লাস আছে। ক্লাস প্যানেলের নিচে ৪টি রেডিও বোতাম আছে, "Flat" (প্যাকেজের ক্লাসগুলো দেখায়), "Hier." (ক্লাসের hierarchy দেখায়), "Inst. side" (instance মেথডগুলো দেখায়), "Class side" (class মেথড/কনস্ট্রাক্টর দেখায়)।

Comment ট্যাবে ক্লিক করলে Pharo Exercism ব্যবহারের সর্বশেষ নির্দেশাবলি দেখতে পাবেন। কমেন্টগুলো পড়ুন আর নিজের প্রথম টেস্টটি চালিয়ে দেখুন।

অন্য ফাইল-ভিত্তিক ভাষায় সাধারণত এই মুহূর্তে আপনি টার্মিনালে গিয়ে exercism cli দিয়ে পরের অনুশীলনীটি এনে ফেলতেন। Pharo-ও একইভাবে ফাইল নিয়ে কাজ করতে পারে, তবে এখানে এনভায়রনমেন্টটি আসলে live object নিয়ে কাজ করার জন্য সাজানো। মজার ব্যাপার হলো, ক্লাস, মেথড আর সোর্স কোড, Pharo-র বাকি সবকিছুর মতোই, সবই অবজেক্ট। এই ট্র্যাকের পুরোটা জুড়ে এ সম্পর্কে আরও শিখবেন।

## অনুশীলনী লোড করা

Exercism-এর জন্য আমরা একটি প্লাগইন যুক্ত করেছি, যা দিয়ে IDE-র ভেতর থেকেই Pharo অনুশীলনী আনা আর জমা দেওয়া যাবে।
আপনাকে শুধু একটি অনুশীলনী প্যাকেজে (এক্ষেত্রে উপরের বাম প্যানেলে থাকা Welcome প্যাকেজে) ডান ক্লিক করে `Exercism | Fetch Exercise` মেনু আইটেমটি নির্বাচন করতে হবে। তখন একটি অনুশীলনীর নাম জিজ্ঞাসা করা হবে (যেমন hello-world), নাম দিলে সেটি স্বয়ংক্রিয়ভাবে এনে দেবে।

প্রতিটি অনুশীলনীর বর্ণনায় আপনার [Pharo ট্র্যাক](https://exercism.io/my/tracks/pharo) পাতায় (একদম ডান দিকে) অনুশীলনীর নামগুলো পাওয়া যাবে।
সেখানে প্রতিটি অনুশীলনীর key-সহ একটি cli স্ট্রিং দেওয়া *Download* নির্দেশনা থাকে। cli নির্দেশনার পাশের কপি বোতামটি ব্যবহার করে পুরো স্ট্রিংটি কপি করে fetch প্রম্পটে পেস্ট করতেও পারেন (আমরা key-টি স্বয়ংক্রিয়ভাবে বের করে নেব)।

বৈধ কোনো অনুশীলনী দিলে প্লাগইনটি সংশ্লিষ্ট কোড এনে System Browser-এ দেখাবে, আর আপনি [টেস্ট দিয়ে কোড লেখা শুরু করতে](tests.md) তৈরি।

আপনার সব টেস্ট পাস হয়ে গেলে একই context মেনু ব্যবহার করে অনুশীলনী প্যাকেজ থেকে আপনার সমাধান জমা দিতে পারেন (প্যাকেজ ট্যাগে ডান ক্লিক করে `Exercism | Submit Exercise...` নির্বাচন করুন)

![Exercism Submit মেনু](https://github.com/exercism/pharo-smalltalk/raw/main/docs/images/SubmitExercise.png)

সবশেষে `Exercism | View Track Progress` মেনু ব্যবহার করে exercism ওয়েবসাইটে গিয়ে দেখুন আপনার জন্য আর কী কী অনুশীলনী খুলে দেওয়া হয়েছে, আর পাশাপাশি আপনার সমাধান নিয়ে প্রশ্ন পোস্ট করতে পারেন যাতে মেন্টররা পড়তে পারেন।

<br/>

**আপনি কি জানেন:** *Pharo চালু করার সময় আপনি আসলে একটি execution image snapshot পুনরুদ্ধার করেন, যা VMWare অপারেটিং সিস্টেম ইমেজের মতো। এটি একটি শক্তিশালী ধারণা, যা দিয়ে কাজের মাঝপথে, এমনকি কোনো কিছু ডিবাগ করার সময়ও, সবকিছু স্থগিত রাখতে পারেন। পরেরবার Pharo আবার চালু করলে পুনরুদ্ধার করা ডিবাগারে কোড ধাপে ধাপে চালিয়ে যেতে পারবেন, বা সম্ভবত একটি refactoring ধাপও চালিয়ে যেতে পারবেন।*

## আপনার CLI টোকেন কীভাবে রিসেট করবেন

নিরাপত্তাজনিত কারণে কখনো আপনার CLI টোকেন রিসেট করার দরকার হলে [Exercism Settings Page](https://exercism.io/my/settings) পাতায় গিয়ে reset token বোতামটি ব্যবহার করুন। এটি করার পর একটি Playground-এ নিচের কোডটি evaluate করে Pharo Exercism থেকে আপনার পুরোনো টোকেন মুছে ফেলতে হবে:

```smalltalk
ExercismHttpClient
    reset;
    promptForToken.
```

## Pharo Exercism কীভাবে আপগ্রেড করবেন

মাঝে মাঝে আপনার Pharo Exercism ইমেজের লাইব্রেরিগুলো আপডেট করার দরকার হতে পারে। অনুগ্রহ করে [এই নির্দেশাবলি](https://github.com/exercism/pharo-smalltalk/blob/main/docs/UPGRADE.md) অনুসরণ করুন
