# পরিচিতি

Haskell-এ `Num` নামে একটি টাইপ আছে, যা সব সংখ্যাসূচক টাইপের মূল টাইপ।
সংখ্যা টাইপের ভেতরে চারটি প্রধান উপ-টাইপ আছে: [`Int`][int], [`Integer`][integer], [`Double`][double]  এবং [`Float`][float]।

Haskell-এ ইন্টিজার টাইপ দুই ধরনের, যেগুলো পূর্ণসংখ্যা প্রকাশ করে।
`Int` একটি ফিক্সড সাইজের ইন্টিজার, আর `Integer` হলো আরবিট্রারি প্রিসিশনের ইন্টিজার।
একটি `Integer` যত বড়ই হোক যেকোনো সংখ্যা ধরে রাখতে পারে, আপনার মেশিনের মেমরির সীমা পর্যন্ত, অন্যদিকে `Int` 32 বা 64 বিটে প্রকাশ করা যায় এমন ধনাত্মক ও ঋণাত্মক ইন্টিজারের সেটের সাথে মিলে যায় (অন্তত -2^29 থেকে 2^29 - 1 নিশ্চিত)।

মনে রাখবেন, ঋণাত্মক সংখ্যা লেখার সময় অস্পষ্টতা এড়াতে বন্ধনী ব্যবহার করা উচিত।

```haskell
1

(-1)
```

`Float` বাস্তব সংখ্যার সেটের সাথে মিলে যায়, যা কম্পিউটারের নির্ভুলতা দ্বারা সীমাবদ্ধ।
সংখ্যার উপর ডিফাইন করা অপারেশন সাধারণত এক টাইপে বা অন্যটিতে কাজ করে, কিন্তু দুটোতেই নয়।
`Double` হলো ডাবল প্রিসিশনের একটি ফ্লোটিং পয়েন্ট সংখ্যা।

```haskell
10.5
```

## ইন্টিজার ও ফ্লোটের মধ্যে রূপান্তর

`toFloat` ফাংশন ব্যবহার করে আপনি একটি `Int` বা `Integer`-কে `Float`-এ রূপান্তর করতে পারেন।

```haskell
toFloat 1
-- -> 1.0
```

এছাড়া `fromIntegral`-ও আছে, যা যেকোনো সংখ্যা টাইপকে প্রয়োজন অনুযায়ী অনুমিত সংখ্যা টাইপে রূপান্তর করে।

```haskell
fromIntegral 1
-- -> 1.0
```

একটি `Float`-কে `Int`-এ রূপান্তর করতে আপনি [`round`][round], [`floor`][floor], বা [`ceiling`][ceiling] ফাংশন ব্যবহার করতে পারেন।
`round` ফাংশন নিকটতম ইন্টিজারে রাউন্ড করে, `floor` নিচের দিকে রাউন্ড করে, আর `ceiling` উপরের দিকে রাউন্ড করে।

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## গাণিতিক অপারেটর

সংখ্যাসূচক টাইপগুলোতে আপনি [মৌলিক গাণিতিক অপারেটরগুলো][math] ব্যবহার করতে পারেন।
অপারেটরগুলো হলো `+`, `-`, `*`, `/`, এবং `%`।
এই অপারেটরগুলো ব্যবহার করার সময় সংখ্যাগুলোর টাইপ মিলতে হবে।
`fromIntegral` ফাংশনটি রূপান্তর করবে যাতে টাইপগুলো মেলে।

### যোগ, বিয়োগ ও গুণ

`+` অপারেটরটি যোগের জন্য, `-` অপারেটরটি বিয়োগের জন্য, আর `*` অপারেটরটি গুণের জন্য ব্যবহৃত হয়।

| অপারেটর | উদাহরণ        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### ভাগ

সংখ্যা ভাগ করার জন্য ভাগ ব্যবহার করা হয়।
`/` অপারেটরটি ভাগের জন্য ব্যবহৃত হয়।
ফলাফলটি সবসময় একটি ফ্লোট হবে।

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
কিছু প্রোগ্রামিং ভাষায় শূন্য দিয়ে ভাগ করলে ফলাফল একটি এরর হয়।

Haskell-এ শূন্য দিয়ে ভাগ করলে ফলাফল হয় `Infinity` বা `-Infinity`।
একমাত্র ব্যতিক্রম হলো শূন্যকে শূন্য দিয়ে ভাগ করা, যার ফল হয় `NaN` (Not a Number)।

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## ইন্টিজার ভাগ

ইন্টিজার ভাগ ব্যবহার করা হয় পূর্ণসংখ্যাগুলো ভাগ করে ফলাফলের পূর্ণ অংশ পেতে।
Haskell-এ ইন্টিজার ভাগের দুটি ফাংশন আছে, যেগুলো ফলাফল ঋণাত্মক হলে কীভাবে রাউন্ড করবে তাতে ভিন্ন:

- `div` নিচের দিকে, ঋণাত্মক অসীমের দিকে রাউন্ড করে।
- `quot` শূন্যের দিকে রাউন্ড করে।

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
ইন্টিজার ভাগে শূন্য দিয়ে ভাগ করলে একটি এক্সেপশন হয়।
এটি সাধারণ ভাগ থেকে আলাদা।
~~~~

### ভাগশেষ

একটি ইন্টিজার ভাগের ভাগশেষ `mod` বা `rem` ব্যবহার করে বের করা যায়।
সংখ্যাগুলোর একটি ঋণাত্মক হলে ফলাফলের চিহ্নে এরা ভিন্ন হয়:

- `mod` `div`-এর সাথে চলে, আর এর ফলাফলের চিহ্ন ভাজকের চিহ্নের মতোই হয়।
- `rem` `quot`-এর সাথে চলে, আর এর ফলাফলের চিহ্ন ভাজ্যের চিহ্নের মতোই হয়।

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

যেকোনো `x` ও `y`-এর জন্য (`y` শূন্য নয়), এই নিয়মগুলো প্রযোজ্য:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
দুই সংখ্যাই ধনাত্মক হলে `div` ও `quot` একই ফলাফল দেয়, আর `mod` ও `rem`-ও তাই।
সেক্ষেত্রে `quot` ও `rem` কিছুটা বেশি কার্যকর হতে পারে, কারণ ঋণাত্মক সংখ্যা সামলাতে `div` ও `mod`-এর অতিরিক্ত ধাপ প্রয়োজন হয়।
~~~~

~~~~exercism/caution
`mod` বা `rem` ব্যবহার করে শূন্য দিয়ে ভাগ করলে একটি এক্সেপশন হয়।
এটি সাধারণ ভাগ থেকে আলাদা।

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## ঘাত নির্ণয়

Haskell-এ "ঘাতে উন্নীত করার" তিনটি অপারেটর আছে, যেগুলো ভিন্নভাবে কাজ করে এবং ভিন্ন ভিন্ন আর্গুমেন্ট টাইপ নেয়।

- `**` দুটি **ফ্লোটিং পয়েন্ট সংখ্যা** নেয় এবং ঘাত নির্ণয় করতে লগারিদম ব্যবহার করে।
- `^^` একটি **ফ্লোটিং পয়েন্ট** নেয় এবং সেটিকে ধনাত্মক বা ঋণাত্মক **ইন্টিজার** ঘাতে উন্নীত করে।
- `^` **যেকোনো সংখ্যাসূচক টাইপ** নেয় এবং সেটিকে **ধনাত্মক ইন্টিজার** ঘাতে উন্নীত করে।

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## অগ্রাধিকার ও বন্ধনী

Haskell বন্ধনী(`()`) ব্যবহার করতে দেয়, যা দিয়ে এক্সপ্রেশন দলবদ্ধ করা যায়।
এটি কাজে লাগে যখন আপনি অপারেশনের ক্রম বদলাতে চান।

একাধিক গাণিতিক অপারেটর ব্যবহার করার সময় অপারেশনের ক্রম গণিতের মতোই, যাকে [PEMDAS][pemdas] বলা হয়।
এটি বন্ধনী(`()`), ঘাত(`**`), গুণ(`*`) ও ভাগ(`/`), এবং যোগ(`+`) ও বিয়োগ(`-`) এই ক্রমটি অনুসরণ করে।

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
