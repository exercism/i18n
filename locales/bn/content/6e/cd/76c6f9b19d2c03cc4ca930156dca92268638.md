# ভূমিকা

প্রায়শই আমরা এমন কোড লিখতে চাই যা একটি শর্তের ভিত্তিতে শাখা-প্রশাখায় ভাগ হতে পারে। Elixir-এ এটি করার অনেক উপায় থাকলেও, সবচেয়ে সহজ উপায়গুলোর একটি হলো `cond/1` ব্যবহার করা।

সবচেয়ে সহজ রূপে, `cond` এক বা একাধিক শাখার মধ্যে প্রথম যে পথটি `true`-তে মূল্যায়িত হয়, সেটিই অনুসরণ করে:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

কোনো পথ `true`-তে মূল্যায়িত না হলে, রানটাইম একটি এরর উত্থাপন করে।
