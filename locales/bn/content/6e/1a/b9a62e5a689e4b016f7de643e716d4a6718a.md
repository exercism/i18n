# ভূমিকা

## নালেবিলিটি

C#-এ `null` লিটারাল একটি মানের অনুপস্থিতি বোঝাতে ব্যবহার করা হয়। একটি _নালেবল_ টাইপ হলো এমন একটি টাইপ যা `null` মান গ্রহণ করতে দেয়।

C# 8.0-এর আগে, রেফারেন্স টাইপগুলো সর্বদা নালেবল ছিল আর ভ্যালু টাইপগুলো ছিল না। একটি ভ্যালু টাইপের শেষে একটি প্রশ্নচিহ্ন (`?`) যোগ করে সেটিকে নালেবল করা যায়।

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

একটি null ভ্যারিয়েবলের মেম্বার অ্যাক্সেস করলে কম্পাইল এরর হয় না, বরং এর ফলে রানটাইমে একটি `NullReferenceException` থ্রো হয়:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

এই কমন ধরনের ভুল প্রতিরোধ করতে, C# 8 এমন একটি ফিচার বেছে নেওয়ার সুযোগ দেয় যা ডিফল্টভাবে রেফারেন্স টাইপগুলোকে নন-নালেবল করে দেয়:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

নালেবল মানগুলো নিয়ে নিরাপদে কাজ করতে, সেগুলো ব্যবহারের আগে দেখে নিন সেগুলো `null` কি না:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }

    // Value is not null at this point, so no compile warning
    // and no runtime NullReferenceException being thrown
    return name.ToUpper();
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

`??` অপারেটরটি মানটি `null` হলে একটি ডিফল্ট ভ্যালু রিটার্ন করার সুযোগ দেয়:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

`?.` অপারেটরটি সম্ভাব্য `null` মানের ওপর নিরাপদে মেম্বার কল করার সুযোগ দেয়:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
