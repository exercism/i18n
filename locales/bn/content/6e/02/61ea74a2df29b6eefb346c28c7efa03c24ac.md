# ভূমিকা

Common Lisp-এ একটি ফাংশনে কিছু আর্গুমেন্ট অপশনাল থাকতে পারে।
এগুলো ল্যাম্বডা লিস্টে `&optional` ল্যাম্বডা লিস্ট কিওয়ার্ড দিয়ে চিহ্নিত করা হয়।
কোনো প্যারামিটার নির্দিষ্ট করা না হলে সেটি `nil` মানে বাইন্ড হবে।
একাধিক অপশনাল প্যারামিটার থাকলে সেগুলো ক্রমানুসারে বাইন্ড হয়।
অপশনাল প্যারামিটারের জন্য ডিফল্ট মান নির্দিষ্ট করা যায়।
সবশেষে, প্রতিটি অপশনাল প্যারামিটারের জন্য একটি সিম্বল নির্দিষ্ট করা যায়, যা ফাংশনের কলকারী সেই প্যারামিটারটি সরবরাহ করেছে কি না তার উপর নির্ভর করে ট্রু বা ফলস-এ বাইন্ড হবে (এটিকে "সাপ্লাইড-পি প্যারামিটার" বলা হয়)।

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
