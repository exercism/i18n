# নির্দেশাবলীর পরিশিষ্ট

## এক্সেপশনের বার্তা

মাঝে মাঝে [এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটি করার সময় আপনি সর্বদা একটি **অর্থবহ এরর বার্তা** যুক্ত করবেন, যাতে বোঝা যায় এররটির উৎস কী। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগ করতে অনেক সুবিধা হয়। যেসব ক্ষেত্রে আপনি জানেন এররের উৎসটি নির্দিষ্ট কোনো টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) যেকোনো একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ বার্তা যুক্ত করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে `classify()` ফাংশনে এমন কোনো সংখ্যা পাস করা হলে, যা _ধনাত্মক ইন্টিজার_ নয়, তখন `ValueError` "থ্রো" করার জন্য [raise স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করতে হবে। আপনি `raise` করলে এবং `exception`-এর সঙ্গে একটি বার্তা যুক্ত করলে তবেই টেস্টগুলো পাস করবে।

একটি বার্তাসহ `ValueError` রেইজ করতে, `exception` টাইপে আর্গুমেন্ট হিসেবে বার্তাটি লিখুন:

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
