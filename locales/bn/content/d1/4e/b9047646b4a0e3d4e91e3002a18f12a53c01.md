# পরিচিতি

Common Lisp-এ একটি ফাংশনের নামযুক্ত প্যারামিটার থাকতে পারে (এগুলোকে বলা হয় "কিওয়ার্ড প্যারামিটার")। ল্যাম্বডা লিস্টে `&key` ল্যাম্বডা লিস্ট কিওয়ার্ড দিয়ে এগুলো চিহ্নিত করা হয়। কিওয়ার্ড প্যারামিটার আবশ্যক প্যারামিটার নয়। অপশনাল প্যারামিটারের মতো এগুলোতেও ডিফল্ট মান দেওয়া যায়, আর এগুলো সরবরাহ করা হয়েছে কি না সেই অবস্থার সাথে বাইন্ড করার জন্য সিম্বল দেওয়া যায়।

কিওয়ার্ড প্যারামিটারযুক্ত একটি ফাংশন কল করার সময় প্যারামিটারের মানের সামনে প্যারামিটারের নামটি একটি কিওয়ার্ড হিসেবে বসানো হয়। ফাংশনটি যে কল করে, সে যেকোনো ক্রমে কিওয়ার্ড প্যারামিটার উল্লেখ করতে পারে।

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

অপশনাল ও কিওয়ার্ড প্যারামিটার একসাথে ব্যবহার করার সময় সতর্ক থাকতে হবে, কারণ কিওয়ার্ডের নাম ও আর্গুমেন্ট অপশনাল প্যারামিটার নিজে গ্রহণ করে নিতে পারে:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
