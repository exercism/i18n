# নির্দেশনার সংযোজন

## ইঙ্গিত

আপনাকে `responseFor` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যা একটি নির্দিষ্ট ইনপুটের জন্য ববের উত্তর রিটার্ন করে। টাইপগুলো নিয়ে নিশ্চিত না থাকলে আপনি দেওয়া সিগনেচারটি ব্যবহার করতে পারেন, তবে সেটি যেন আপনার সৃজনশীলতাকে সীমিত না করে:

```haskell
responseFor :: String -> String
```

এই অনুশীলনীটি সমাধান করতে আপনি পড়ে দেখতে পারেন:

- [গার্ড][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

এই অনুশীলনীটি টেক্সট ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর `String` টাইপ `[Char]`-এর সমার্থক, অর্থাৎ ক্যারেক্টারের একটি অ্যারে। টেক্সট ডেটা আরও দক্ষভাবে হ্যান্ডেল করার জন্য `Text` টাইপটি ব্যবহার করা যায়।

এই অনুশীলনীর ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি পারেন:

- Haskell-এ [স্ট্রিং টাইপগুলো](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml-এ আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করুন।
- `Data.Text` [নিচের পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) ইমপোর্ট করুন:

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- এখন আপনি যেমন `responseFor :: Text -> Text` লিখতে পারেন এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.isSuffixOf` হিসেবে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখে নিন,
- এরপর আপনি Bob.hs-এ `String`-এর সব জায়গায় `Text` বসাতে পারেন:

    ```haskell
    responseFor :: Text -> Text
    ```

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
