# পরিচিতি

`java.time`-এর `LocalDate`-এর মতো অবজেক্ট নিয়ে কাজ করার সময় আপনাকে প্রায়ই জটিল তারিখ অ্যাডজাস্টমেন্ট করতে হয়, যেমন মাসের "দ্বিতীয় মঙ্গলবার" বের করা। এটি নিজে হাতে হিসাব না করে আপনি **`TemporalAdjusters`** ব্যবহার করতে পারেন।

`java.time.temporal.TemporalAdjusters` (শেষে 's' আছে, খেয়াল করুন) ইউটিলিটি ক্লাসটিতে অনেক কমন তারিখ অ্যাডজাস্টমেন্টের জন্য স্ট্যাটিক মেথড রয়েছে। এই অ্যাডজাস্টমেন্টগুলো আপনি একটি টেম্পোরাল অবজেক্টের (যেমন `LocalDate`) উপর `.with()` মেথড দিয়ে প্রয়োগ করেন।

```exercism/note
`with(TemporalAdjuster)` ব্যবহার করলে একটি _নতুন_ ইনস্ট্যান্স পাওয়া যায়, বিদ্যমান ইনস্ট্যান্সটি বদলে যায় না, কারণ `java.time` অবজেক্টগুলো ইমিউটেবল।
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

শিডিউলিংয়ের হিসাব-নিকাশে কাজে লাগে এমন কিছু গুরুত্বপূর্ণ অ্যাডজাস্টার নিচে দেওয়া হলো:

## সপ্তাহের নির্দিষ্ট ক্রমিক বার বের করা

`dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` ব্যবহার করে সপ্তাহের একটি বারের n-তম উপস্থিতি বের করা যায়।

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

## মাসে সপ্তাহের প্রথম/শেষ বার বের করা

`firstInMonth(DayOfWeek dayOfWeek)` অথবা `lastInMonth(DayOfWeek dayOfWeek)` ব্যবহার করুন।

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

## আপেক্ষিক অ্যাডজাস্টমেন্ট (পরবর্তী/পূর্ববর্তী)

`next()`, `previous()`, `nextOrSame()` আর `previousOrSame()`-এর মতো অ্যাডজাস্টার বর্তমান তারিখের সাপেক্ষে সপ্তাহের একটি নির্দিষ্ট বারের পরবর্তী বা পূর্ববর্তী উপস্থিতি খুঁজে বের করে।

- `next()`/`previous()`: বর্তমান তারিখটি মিলে গেলে সেটি বাদ দেয়।
- `nextOrSame()`/`previousOrSame()`: বর্তমান তারিখটি মিলে গেলে সেটিকেও ধরে নেয়।

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## কাস্টম অ্যাডজাস্টার

`TemporalAdjuster` একটি ফাংশনাল ইন্টারফেস, তাই আপনি নিজের অ্যাডজাস্টার লিখতে পারেন একটি ল্যাম্বডা হিসেবে, যা অ্যাডজাস্ট করার জন্য টেম্পোরালটি নেয় আর অ্যাডজাস্ট করা টেম্পোরালটি রিটার্ন করে। এটি `.with()` দিয়ে ঠিক পূর্বনির্ধারিত অ্যাডজাস্টারগুলোর মতোই প্রয়োগ করা হয়, আর ভেতরে সেগুলো ব্যবহারও করতে পারে।

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

`TemporalAdjusters` ক্লাসের এই অ্যাডজাস্টারগুলো ব্যবহার করলে তারিখ নিয়ে কাজ অনেক সহজ হয়ে যায়।
