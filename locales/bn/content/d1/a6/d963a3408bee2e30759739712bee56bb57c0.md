# টেস্ট চালানো

`sbt` ইনস্টল করা থাকলে কমান্ড লাইন থেকে টেস্টগুলো এভাবে চালানো যায়:

```bash
$ sbt test
```

মনে রাখবেন, প্রতিবার `sbt test` চালালে সময় বেশি লাগবে, কারণ প্রতিবার চালানোর সময় `sbt` আবার ইনিশিয়ালাইজ হয়।

`sbt` একটি শেলের মতো কাজ করে; একবার এটি চালু হলে আপনি এর ভেতরে কমান্ড চালাতে পারেন।

উদাহরণস্বরূপ, সোর্স ফাইল পরিবর্তন হলেই আবার আপনার টেস্টগুলো চালাতে আপনি `sbt` ব্যবহার করতে পারেন:
```bash
$ sbt
>~ test
```

মনে রাখবেন, আপনার কাজ করার সুবিধার জন্য প্রথম টেস্টটি ছাড়া বাকি সব টেস্ট নিষ্ক্রিয় করে রাখা হয়েছে।
এগিয়ে যেতে, প্রতিটি টেস্ট কেসের শুরু থেকে শুধু `pending` কিওয়ার্ডটি মুছে ফেলুন।

`sbt` সম্পর্কে আরও জানতে [এখানে](https://www.scala-sbt.org/) যান।


নিচের IDE-গুলোতেও টেস্ট চালানো যায়

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
