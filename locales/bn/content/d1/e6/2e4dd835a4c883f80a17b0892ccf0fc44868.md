# Case

[`case`][case] (অন্য ভাষায় সাধারণত যাকে switch বলা হয়) হলো if-else-এর মতো এক ধরনের কন্ট্রোল এক্সপ্রেশন।
`case` দিয়ে একাধিক if-else-if স্টেটমেন্ট একসাথে জোড়া যায়, এটি পড়তে আরও সহজ হতে পারে, এবং শক্তিশালী কনস্ট্রাক্ট লেখা সম্ভব করে।

একটি `case` ডিফাইন করা হয় `case` কিওয়ার্ড দিয়ে, যার পরে থাকে একটি ঐচ্ছিক এক্সপ্রেশন।
এরপর প্রতিটি ক্ষেত্রের জন্য `when` কিওয়ার্ড ব্যবহার করা হয়, যার পরে থাকে এমন একটি এক্সপ্রেশন যা case এক্সপ্রেশনের সাথে তুলনা করা হয়।
`when` কিওয়ার্ডটি `case` কিওয়ার্ডের চেয়ে ভেতরে ইনডেন্ট করা উচিত নয়।
`when` কিওয়ার্ডের পরে থাকে সেই কোড, যা case এক্সপ্রেশনটি when এক্সপ্রেশনের সাথে মিলে গেলে রান করা উচিত।
`case`-এ একটি ঐচ্ছিক `else` স্টেটমেন্ট থাকতে পারে, যা অন্য কোনো case-এর সাথে না মিললে রান করা হয়।

case এক্সপ্রেশনটি মূল্যায়ন করা হয়, তারপর প্রতিটি when এক্সপ্রেশনের সাথে তুলনা করা হয়।
এই তুলনাটি করা হয় [case সাবসাম্পশন অপারেটর (`===`)][case-subsumption] দিয়ে।

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Case সাবসাম্পশন অপারেটর (`===`)

case সাবসাম্পশন অপারেটর (`===`) সমতা অপারেটর (`==`) থেকে কিছুটা আলাদা।
এই অপারেটরটি যাচাই করে ডান দিকের মানটি বাম দিকে বর্ণিত সেটের একটি সদস্য কি না।
এর মানে হলো, প্রতিটি অপারেন্ড কোন দিকে বসানো হচ্ছে সেটি গুরুত্বপূর্ণ।
এটি কীভাবে কাজ করবে তা নির্ভর করে বাম দিকের টাইপের উপর। যেমন, একটি `Range` যাচাই করে ডান দিকের মানটি ওই রেঞ্জের মধ্যে আছে কি না, আর একটি `Object` যাচাই করে ডান দিকের মানটি `Object`-এর একটি ইনস্ট্যান্স কি না।

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## একাধিক এক্সপ্রেশনসহ case

case-এ একটি case-এর মধ্যেই একাধিক এক্সপ্রেশন মেলানো যায়, যেখানে প্রতিটি সম্ভাব্য মান কমা দিয়ে আলাদা করা হয়।
এক্সপ্রেশনগুলোর যেকোনো একটি মিললে কোডটি রান করা হয়।
একাধিক সম্ভাব্য মানের একটি case-এর জন্য এটি কাজে লাগতে পারে।

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## রেঞ্জসহ case

case দিয়ে এটাও যাচাই করা যায় যে একটি মান কোনো রেঞ্জের মধ্যে আছে কি না।
এটি করা হয় when এক্সপ্রেশন হিসেবে একটি রেঞ্জ ব্যবহার করে।

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## case এক্সপ্রেশন ছাড়া case

case এক্সপ্রেশনের প্রয়োজন না থাকলে সেটি বাদ দেওয়া যায়।
এভাবে করলে প্রতিটি এক্সপ্রেশন সত্য কি মিথ্যা, তা বিবেচনা করা হয়।
আর এতে তারা if-else-if স্টেটমেন্টের মতো আচরণ করে।

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## এক লাইনের when

Crystal এক লাইনের case স্টেটমেন্ট লেখার সুবিধা দেয়।
সরল এক লাইনের স্টেটমেন্ট থাকলে এটি ব্যবহার করা যায়।
এক লাইনের when লেখা হয় `when <expression> then <statement>.` আকারে।
আর else স্টেটমেন্টে ব্যবহার করলে লেখা হয় `else <statement>` আকারে।

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## টাইপসহ case

case দিয়ে টাইপের সাথে মেলানো যায়।
তুলনার সময় `is_a?` অপারেটর দিয়ে ভ্যারিয়েবলের টাইপ যাচাই করা হয়।
যেমন, এতে একটি ইউনিয়ন টাইপের প্রতিটি টাইপের জন্য আলাদা শাখা রাখা যায়।

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## ইমপ্লিসিট অবজেক্ট

case-এ ইমপ্লিসিট অবজেক্ট ব্যবহার করা যায়।
এতে উদাহরণস্বরূপ, একটি when এক্সপ্রেশন হয়ে ওঠে case এক্সপ্রেশনের উপর করা একটি মেথড কল।
মেথডটি ট্রুথি বা ফলসি মান রিটার্ন করে কি না, তার উপর নির্ভর করে case-টি মেলে কি না।

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
