# পরিচিতি

অনেক ভাষায় `null` বা `none`-এর মতো একটি উপায় থাকে, যা দিয়ে অস্তিত্বহীন কোনো মান বোঝানো হয়। Julia যেহেতু অনেক বড় পরিমাণ (প্রায়শই অগোছালো) ডেটা সামলানোর জন্য তৈরি, তাই এতে কিছু না থাকার একাধিক রূপ রয়েছে।

মূল লক্ষ্য হলো, অনুপস্থিত বা সন্দেহজনক মান পেলেই সেগুলো চিহ্নিত করা, আর তারপর কোনো এক্সেপশন ছাড়াই কাজ চালিয়ে যাওয়া।

## `nothing`

কোনো মান সত্যিই না থাকলে তা `nothing` দিয়ে প্রকাশ করা হয়। সম্ভবত এটি C (`NULL`) বা Python (`None`) যা করে তার সবচেয়ে কাছাকাছি।

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

তাহলে `nothing` হলো `Nothing` টাইপের একটি একক মান, আর আমরা এটি পরীক্ষা করতে পারি।

কেবল নিজেদের সাইড ইফেক্টের জন্য ব্যবহৃত ফাংশনের (প্রিন্ট করা, নেটওয়ার্ক কনফিগারেশন, বা যা-ই হোক) রিটার্ন (না-)মান হিসেবে `nothing`-এর একটি কমন ব্যবহার আছে।

## `missing`

এমন পরিস্থিতির জন্য `missing` ব্যবহার করা হয়, যেখানে মানটি তাত্ত্বিকভাবে আছে, কিন্তু তা কী তা আমরা জানি না। উদাহরণস্বরূপ, রাস্তায় চলাচলকারী যানবাহন গণনা করার সময় মানুষের পর্যবেক্ষকের বিশ্রামের দরকার হতে পারে, বা স্বয়ংক্রিয় সেন্সর নষ্ট হয়ে যেতে পারে, কিন্তু যান চলাচল তো চলতেই থাকে।

তাই `missing` একটি প্লেসহোল্ডার, যা মানুষকে সতর্ক করে যে ডেটার এই ফাঁকটি কীভাবে সামলাবে, সে ব্যাপারে তাদের একটি সিদ্ধান্ত নিতে হবে।

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

অল্প কয়েকটি ভাষায় এই সুবিধা আগে থেকেই দেওয়া থাকে, তবে এর কাছাকাছি উদাহরণ হলো R-এর `NA` বা SQL-এর `NULL`।

এক্সপ্রেশনে `missing` মান থাকলে সাধারণত সেগুলো ডিফল্টভাবে `missing` রিটার্ন করে। আপনি যদি চান এই মানগুলো উপেক্ষা করা হোক, তাহলে সেটি স্পষ্টভাবে বোঝাতে `skipmissing()` ফাংশনটি ব্যবহার করুন:

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

যেহেতু `skipmissing` একটি ইটারেটর তৈরি করে, তাই আপনার ভেক্টর দরকার হলে এটিকে `collect()`-এর মধ্যে মুড়ে নিন।

মাঝে মাঝে `missing` মানকে কোনো ডিফল্ট মান দিয়ে বদলে দেওয়া কাজে লাগে। এ কাজে `@coalesce()` ম্যাক্রোটি কাজে লাগে, কারণ এটি প্রথম অ-`missing` মান রিটার্ন করে (আর অন্য কিছু না থাকলে `missing`)।

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

"Not a Number"-এর সংক্ষিপ্ত রূপ NaN এমন পরিস্থিতিতে একটি হিসাবের সমস্যা চিহ্নিত করে, যেখানে একটি সংখ্যা প্রত্যাশিত ছিল।

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

NaN-সহ যেকোনো ধরনের হিসাব `NaN` ফলাফল দেবে।

`NaN` মান সরিয়ে ফেলার জন্য এখন বিশেষ কোনো ফাংশন নেই, তবে স্ট্যান্ডার্ড `filter()` ফাংশন দিয়ে এটি বেশ সহজেই করা যায়। কেবল সেই মানগুলোই ফলাফল অ্যারেতে কপি করা হবে, যেগুলোর জন্য প্রদত্ত কোনো শর্ত `true` হয়:

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
