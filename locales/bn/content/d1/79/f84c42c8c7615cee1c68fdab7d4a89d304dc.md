# সম্পর্কে

Gleam-এর স্ট্যান্ডার্ড লাইব্রেরির `gleam/order` মডিউলে `Order` টাইপটি আছে, যেটি মান তুলনা করতে ব্যবহৃত হয়।

`Order`-এর সংজ্ঞাটি দেখতে এরকম:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

টাইপটির তিনটি ভ্যারিয়েন্ট আছে, প্রত্যেকটি একটি মান ও আরেকটি মানের মধ্যে সম্পর্ক প্রকাশ করতে ব্যবহৃত হয়:

- `Gt` - মানটি অন্য মানের চেয়ে _বড়_।
- `Eq` - মানটি অন্য মানের _সমান_।
- `Lt` - মানটি অন্য মানের চেয়ে _ছোট_।

যদি কোনো ডেটা টাইপ আকার অনুসারে তুলনা করা যায়, তাহলে মডিউলে একটি `compare` ফাংশন ডিফাইন করা কমন, যা একটি `Order` মান রিটার্ন করে। উদাহরণস্বরূপ, `gleam/float` এবং `gleam/int` `compare` ফাংশন ডিফাইন করে, যেগুলো যথাক্রমে ফ্লোট ও ইন্টিজারের ওপর কাজ করে।

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort`-এর মতো সর্টিং ফাংশনগুলো সাধারণত এমন একটি ফাংশন নেয় যা একটি `Order` মান রিটার্ন করে, যার ফলে কলার নির্ধারণ করতে পারে অ্যারেটি কীভাবে সাজানো হবে।

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
