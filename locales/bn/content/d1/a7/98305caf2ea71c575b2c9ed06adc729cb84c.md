# পরিচিতি

Elixir ভাষায় অ্যারে বিল্ট-ইন। এগুলোকে একটি মৌলিক টাইপ ধরা হয়, যা বর্গাকার বন্ধনী দিয়ে বোঝানো হয়। অ্যারে খালি থাকতে পারে, আবার যেকোনো টাইপের যেকোনো সংখ্যক আইটেম ধারণ করতে পারে। যেমন:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir অ্যারেকে একটি লিংকড অ্যারে হিসেবে বাস্তবায়ন করে, যেখানে প্রতিটি নোড দুটি মান সংরক্ষণ করে: প্রথম আইটেমটি এবং বাকি সব আইটেম নিয়ে গঠিত আরেকটি অ্যারে। অ্যারের প্রথম আইটেমটিকে বলা হয় _হেড_ এবং বাকি আইটেমের অ্যারেটিকে বলা হয় _টেল_। আমরা কোডে এই নোটেশনটি ব্যবহার করতে পারি:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

আমরা _`[head | tail]`_ নোটেশন ব্যবহার করে অ্যারের সামনে এলিমেন্ট যোগ করতে পারি:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

অ্যারে নিয়ে কাজ করার জন্য `Kernel` মডিউলে বেশ কিছু ফাংশন আছে, আর আছে সম্পূর্ণ `List` মডিউল।

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
