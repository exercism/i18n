# নির্দেশাবলি

এই অনুশীলনীতে আমরা একটি [ব্ল্যাকজ্যাক](https://en.wikipedia.org/wiki/Blackjack) গেমের প্রথম পালা অনুকরণ করব।

আপনি দুটি কার্ড পাবেন এবং ডিলারের খোলা কার্ডটি দেখতে পাবেন। সব কার্ডকে "ace", "king", "three", "two" ইত্যাদি স্ট্রিং দিয়ে প্রকাশ করা হয়। প্রতিটি কার্ডের মান হলো:

| কার্ড  | মান | কার্ড  | মান |
| :---: | :---: | :---: | :---: |
|  ace  |  ১১   | eight |   ৮   |
|  two  |   ২   | nine  |   ৯   |
| three |   ৩   |  ten  |  ১০   |
| four  |   ৪   | jack  |  ১০   |
| five  |   ৫   | queen |  ১০   |
|  six  |   ৬   | king  |  ১০   |
| seven |   ৭   | other |   ০   |

**নোট**: সাধারণত ace-এর মান ১ বা ১১ হতে পারে, কিন্তু সহজ রাখার জন্য আমরা ধরে নেব যে এর মান কেবল ১১-ই হতে পারে।

আপনার দুটি কার্ড এবং ডিলারের কার্ডের উপর নির্ভর করে খেলার প্রথম পালার জন্য একটি কৌশল আছে, যেখানে আপনার কাছে নিচের অপশনগুলো থাকে:

    - Stand (S)
    - Hit (H)
    - Split (P)
    - Automatically win (W)

যদিও এটি এখনো সেরা নয়, তবুও আপনি আপনার বন্ধু Alex যে কৌশলটি তৈরি করছে সেটিই অনুসরণ করবেন, যা নিচের মতো:

বিভাগ: বড় হাত

- আপনার কাছে যদি এক জোড়া ace থাকে, তবে সবসময় সেগুলো স্প্লিট করতে হবে।
- আপনার কাছে ব্ল্যাকজ্যাক থাকলে (দুটি কার্ডের যোগফল ২১ হলে), এবং ডিলারের কাছে ace, ফিগার কার্ড বা ten না থাকলে আপনি স্বয়ংক্রিয়ভাবে জিতে যাবেন। ডিলারের কাছে এগুলোর কোনো একটি থাকলে আপনাকে স্ট্যান্ড করতে হবে এবং ডিলারের অন্য কার্ডটি খোলার জন্য অপেক্ষা করতে হবে।

বিভাগ: ছোট হাত

- আপনার কার্ডের যোগফল ১৭ বা তার বেশি হলে সবসময় স্ট্যান্ড করা উচিত।
- আপনার কার্ডের যোগফল ১১ বা তার কম হলে সবসময় হিট করা উচিত।
- আপনার কার্ডের যোগফল [১২, ১৬] রেঞ্জের মধ্যে হলে সবসময় স্ট্যান্ড করা উচিত, যদি না ডিলারের কার্ড ৭ বা তার বেশি হয়; সেক্ষেত্রে সবসময় হিট করা উচিত।

সামগ্রিক লজিক ইতিমধ্যে তৈরি করা হয়েছে। আপনার সামনে চারটি কাজ আছে:

## 1. যেকোনো কার্ডের স্কোর বের করুন।

কন্ডিশনাল ব্যবহার করে কার্ডের নাম থেকে তার সংখ্যাগত মান বের করার জন্য একটি ফাংশন তৈরি করুন।

```java
parseCard("ace")
// returns 11
```

## 2. দুটি কার্ড মিলে ব্ল্যাকজ্যাক হয় কি না তা নির্ণয় করুন।

দুটি কার্ড মিলে ব্ল্যাকজ্যাক হলে `true` এবং না হলে `false` রিটার্ন করে এমন একটি ফাংশন তৈরি করুন।

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. ২০ পয়েন্টের বেশি হ্যান্ড স্কোরের জন্য সিদ্ধান্তের লজিক তৈরি করুন।

আপনার কার্ড অনুযায়ী সিদ্ধান্তটি স্ট্রিং আকারে রিটার্ন করে এমন একটি ফাংশন তৈরি করুন। এই ফাংশনটি কেবল তখনই কল করা হয় যখন `handScore` ২০-এর চেয়ে বড় হয়। এটি ২টি আর্গুমেন্ট গ্রহণ করবে: `isBlackJack` এবং `dealerScore`। এটি উপরের "বড় হাত" বিভাগের বুলেট পয়েন্টগুলো বাস্তবায়ন করবে।

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. ২১ পয়েন্টের কম হ্যান্ড স্কোরের জন্য সিদ্ধান্তের লজিক তৈরি করুন।

আপনার কার্ড অনুযায়ী সিদ্ধান্তটি স্ট্রিং আকারে রিটার্ন করে এমন একটি ফাংশন তৈরি করুন। এই ফাংশনটি কেবল তখনই কল করা হয় যখন `handScore` ২১-এর কম হয়। এটি ২টি আর্গুমেন্ট গ্রহণ করবে: `handScore` এবং `dealerScore`। এটি উপরের "ছোট হাত" বিভাগের বুলেট পয়েন্টগুলো বাস্তবায়ন করবে।

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
