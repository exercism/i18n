# মিউটেবিলিটি

Cairo তার ব্লকচেইন-ভিত্তিক ডিজাইনে ডিফল্টভাবে একটি ইমিউটেবল মেমরি মডেল ব্যবহার করে।
এর মানে হলো, একবার কোনো মান মেমরিতে লেখা হলে তা আর ওভাররাইট করা যায় না, শুধু পড়া যায়।
তবে Cairo `mut` কিওয়ার্ড ব্যবহার করে মিউটেবল ভ্যারিয়েবল তৈরির একটি ব্যবস্থা দেয়।
কোনো ভ্যারিয়েবলকে মিউটেবল হিসেবে ঘোষণা করা হলে এবং তার মান পরিবর্তন করা হলে, নতুন মানটি একটি নতুন মেমরি সেলে লেখা হয়, আর ভ্যারিয়েবলটি নতুন সেলের দিকে নির্দেশ করতে আপডেট হয়।
এই ব্যবস্থা ইমিউটেবিলিটির সুবিধা অক্ষুণ্ণ রেখেই নমনীয়তা আনে।

নিচের উদাহরণে `x`-কে একটি ইমিউটেবল ভ্যারিয়েবল হিসেবে ঘোষণা করা হয়েছে।
`x`-এর মান পরিবর্তন করলে কম্পাইলার একটি এরর দেবে।

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

আমরা `mut` কিওয়ার্ড ব্যবহার করে `x`-কে একটি মিউটেবল ভ্যারিয়েবল হিসেবে ঘোষণা করতে পারি।
এতে `x` ঘোষণা করার পরেও তার মান পরিবর্তন করা যায়।

```rust
let mut x = 5;
x = 10;
```

শেষ বিচারে, মিউটেবিলিটি ব্যবহার করবেন কি না সেটি আপনার সিদ্ধান্ত, আর তা নির্ভর করে ওই নির্দিষ্ট পরিস্থিতিতে কোনটি সবচেয়ে স্পষ্ট মনে হয় তার উপর।

## কনস্ট্যান্ট

ইমিউটেবল ভ্যারিয়েবলের মতোই, কনস্ট্যান্ট হলো এমন মান যা একটি নামের সাথে বাঁধা থাকে এবং পরিবর্তন করা যায় না, তবে কনস্ট্যান্ট আর ভ্যারিয়েবলের মধ্যে কয়েকটি পার্থক্য আছে:

- কনস্ট্যান্ট ঘোষণা করা হয় `const` কিওয়ার্ড দিয়ে
- কনস্ট্যান্টের সাথে `mut` ব্যবহার করা যায় না
- মানের টাইপ সবসময় স্পষ্টভাবে সেট করতে হয়
- কনস্ট্যান্ট শুধু গ্লোবাল স্কোপে ঘোষণা করা যায়
- কনস্ট্যান্ট শুধু কনস্ট্যান্ট এক্সপ্রেশন দিয়েই সেট করা যায়, রানটাইমে হিসাব করা কোনো মানের ফলাফল দিয়ে নয়

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

`consteval_int!` ম্যাক্রো ব্যবহার করে এমন একটি `const` ভ্যারিয়েবল তৈরি করা সম্ভব যা কোনো হিসাবের ফলাফল।

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## শ্যাডোয়িং

কোনো নির্দিষ্ট মান রূপান্তরিত হওয়ার সময় একই ভ্যারিয়েবল নাম বারবার `let` দিয়ে পুনরায় ঘোষণা করে আবার ব্যবহার করা সম্ভব, এবং অনেক সময় এটাই স্বাভাবিক রীতি।
একে _শ্যাডোয়িং_ বলা হয়।
আসলে দ্বিতীয় ভ্যারিয়েবলটি প্রথমটিকে ঢেকে দেয়, এবং ভ্যারিয়েবল নামের সব ব্যবহার নিজের দিকে নিয়ে নেয়, যতক্ষণ না সে নিজেই শ্যাডো হয় বা স্কোপ শেষ হয়।

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

শ্যাডোয়িং ব্যবহার করে একই ভ্যারিয়েবল নাম আবার ব্যবহার করেই ভ্যারিয়েবলের টাইপও বদলানো যায়।

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
