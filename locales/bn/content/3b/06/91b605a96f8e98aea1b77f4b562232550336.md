# কেস স্টেটমেন্ট

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## এটি কীভাবে মেলে

`case`-এর পরে থাকা মানটিকে `=` দিয়ে উপর থেকে নিচে প্রতিটি `when` মানের সাথে তুলনা করা হয়। প্রথম যে মানটি মেলে, শুধু সেটিই চলে। বাকি `when` অংশগুলো বাদ পড়ে যায়, আর `end`-এর পরে এক্সিকিউশন চলতে থাকে।

`=` সাপোর্ট করে এমন যেকোনো টাইপ ব্যবহার করা যায়: `INT`, `CHAR`, `STR`, `BOOL`.

## `else` অংশ

যদি কোনো `case`-এর সাথে কোনো মান মিলে না যায় আর তাতে `else` না থাকে, তবে রান টাইমে একটি ফেটাল এরর হয়। তাই সবসময় একটি লিখুন। বাকি কেসগুলো যদি সত্যিই না ঘটার কথা হয়, তবে `else` বাদ না দিয়ে সেখানেই সেটি স্পষ্ট করে দিন:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` নিয়ে পরে আলোচনা হবে; ততদিন পর্যন্ত একটি যুক্তিসঙ্গত ডিফল্ট মান রিটার্ন করলেই সমস্যা নেই।

## কখন `if` ব্যবহার করা ভালো

`case` একটি মানকে ধ্রুবকগুলোর সাথে তুলনা করে। আর বাকি সবকিছুর জন্যই দরকার `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

একটি রেঞ্জ জোর করে `case`-এ ঢোকাতে গেলে যা তৈরি হয়, তা যে `if`-এর বদলে বসানো হচ্ছে তার চেয়ে লম্বা ও খারাপ হয়।

## এক্সপ্রেশন হিসেবে `case`

`case` হলো একটি স্টেটমেন্ট, এক্সপ্রেশন নয়; তাই এভাবে Sather-এ লেখা যায় না:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

প্রতিটি শাখার ভেতর থেকেই রিটার্ন করুন, অথবা প্রতিটি শাখার ভেতরেই একটি ভ্যারিয়েবলে অ্যাসাইন করুন।
