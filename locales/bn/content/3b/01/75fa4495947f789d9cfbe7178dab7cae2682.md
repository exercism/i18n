# নির্দেশনা

Daphne তার পরীক্ষাগুলো চালানো এবং সেগুলোর ফলাফল রেকর্ড করার একটি সিস্টেম নিয়ে কাজ করছেন। কোডের কিছু অংশ বেশ ভার্বোজ ও পুনরাবৃত্ত হয়ে গেছে, তাই পরিষ্কার করার জন্য তিনি আপনাকে কিছু `use` এক্সপ্রেশন লিখতে বলেছেন।

## 1. `with_retry` ফাংশনটি ডিফাইন করুন

মাঝে মাঝে একবারের ভুলে পরীক্ষা ব্যর্থ হতে পারে, তাই কোনো পরীক্ষা ব্যর্থ হলে Daphne সেটি আবার চেষ্টা করে দেখতে চান, দ্বিতীয়বার কাজ করে কি না।

`with_retry` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে এমন একটি ফাংশন নেয় যা একটি ফলাফল রিটার্ন করে।

ফাংশনটি যদি একটি `Ok` মান রিটার্ন করে, তাহলে `with_retry` সেই মানটি রিটার্ন করবে।

ফাংশনটি যদি একটি `Error` মান রিটার্ন করে, তাহলে `with_retry` ফাংশনটিকে আবার কল করবে এবং সেই কলের ফলাফল রিটার্ন করবে।

Daphne ফাংশনটি এভাবে ব্যবহার করবেন:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. `record_timing` ফাংশনটি ডিফাইন করুন

Daphne প্রতিটি পরীক্ষার আগে ও পরে একটি টাইম লগিং ফাংশন কল করে প্রতিটি পরীক্ষা চালাতে কত সময় লাগে তা রেকর্ড করেন।

`record_timing` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়:
- একটি টাইম লগিং ফাংশন, যেটি কোনো আর্গুমেন্ট নেয় না এবং `Nil` রিটার্ন করে।
- একটি পরীক্ষা ফাংশন, যেটি কোনো আর্গুমেন্ট নেয় না এবং একটি ফলাফল রিটার্ন করে।

`record_timing` প্রথমে টাইম লগিং ফাংশনটি কল করবে, তারপর পরীক্ষা ফাংশনটি কল করবে, তারপর আবার টাইম লগিং ফাংশনটি কল করবে এবং সবশেষে পরীক্ষা ফাংশনের ফলাফল রিটার্ন করবে।

Daphne ফাংশনটি এভাবে ব্যবহার করবেন:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. `run_experiment` ফাংশনটি ডিফাইন করুন

একটি পরীক্ষা তিনটি ধাপে গঠিত। সেটআপ, অ্যাকশন আর রেকর্ডিং। তিনটি ধাপই ফলাফল রিটার্ন করে, এবং প্রতিটি ধাপ চালানোর জন্য আগের ধাপের সফল ফলাফল দরকার।

`run_experiment` ফাংশনটি ডিফাইন করুন, যেটি চারটি আর্গুমেন্ট নেয়:
- পরীক্ষার নাম, একটি `String` হিসেবে।
- একটি সেটআপ ফাংশন, যেটি কোনো আর্গুমেন্ট নেয় না এবং একটি ফলাফল রিটার্ন করে।
- একটি অ্যাকশন ফাংশন, যেটি আর্গুমেন্ট হিসেবে সেটআপ ফাংশনের `Ok` মানটি নেয় এবং একটি ফলাফল রিটার্ন করে।
- একটি রেকর্ডিং ফাংশন, যেটি আর্গুমেন্ট হিসেবে সেটআপ ও অ্যাকশন ফাংশনের `Ok` মান নেয় এবং একটি ফলাফল রিটার্ন করে।

তিনটি ফাংশনই যদি সফল হয়, তাহলে `run_experiment` `Ok(#(experiment_name, recording_data))` রিটার্ন করবে।

ফাংশনগুলোর যেকোনোটি যদি একটি `Error` মান রিটার্ন করে, তাহলে `run_experiment` সেই মানটি রিটার্ন করবে।

Daphne ফাংশনটি এভাবে ব্যবহার করবেন:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
