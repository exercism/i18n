# ভূমিকা

## স্ট্রিং

মনে করুন, `jq` JSON-এর মতো একই ডেটা টাইপ সাপোর্ট করে।
JSON **স্ট্রিং**-কে এভাবে বর্ণনা করে:

> একটি স্ট্রিং হলো শূন্য বা ততোধিক ইউনিকোড ক্যারেক্টারের একটি ক্রম, যা ডাবল কোটের ভেতরে মোড়ানো থাকে এবং ব্যাকস্ল্যাশ এস্কেপ ব্যবহার করে লেখা হয়।

### এস্কেপ সিকোয়েন্স

একটি স্ট্রিংয়ের ভেতরে "বিশেষ" ক্যারেক্টার ঢোকাতে ব্যাকস্ল্যাশ ক্যারেক্টার ব্যবহার করুন:

- `\"` একটি আক্ষরিক উদ্ধৃতি চিহ্ন,
- `\\` একটি আক্ষরিক ব্যাকস্ল্যাশ,
- হোয়াইটস্পেস ক্যারেক্টার `\n`, `\t`, `\r`, `\f`, `\b`
- ইউনিকোড ক্যারেক্টার `\uAAAA`, যেখানে `A` একটি হেক্স ডিজিট

### স্ট্রিংয়ের দৈর্ঘ্য

ক্যারেক্টারের সংখ্যা বের করতে `length` ফাংশনটি ব্যবহার করুন।

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### সাবস্ট্রিং

সাবস্ট্রিং বের করতে **স্লাইস** নোটেশন ব্যবহার করা যায়।
সিনট্যাক্স হলো `.[i:j]`।
রিটার্ন করা সাবস্ট্রিংয়ের দৈর্ঘ্য `j - i`, যা ইনডেক্স `i` (অন্তর্ভুক্ত) থেকে ইনডেক্স `j` (অন্তর্ভুক্ত নয়) পর্যন্ত ক্যারেক্টার রিটার্ন করে।
যেকোনো ইনডেক্স ঋণাত্মক হতে পারে, সেক্ষেত্রে এটি স্ট্রিংয়ের শেষ থেকে পিছনের দিকে গোনে।
যেকোনো ইনডেক্স বাদ দেওয়া যেতে পারে, সেক্ষেত্রে এটি স্ট্রিংয়ের শুরু বা শেষ বোঝায়।
ইনডেক্স শূন্য থেকে শুরু হয়।

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### কনক্যাটেনেশন

স্ট্রিং জোড়া লাগাতে `+` ব্যবহার করুন:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

স্ট্রিংয়ের একটি অ্যারে দেওয়া হলে `add` ব্যবহার করুন:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### স্প্লিট ও জয়েন

স্প্লিট করতে `split/1` ফাংশনটি বা `/` অপারেটরটি ব্যবহার করা হয়:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1`-এর বিপরীত হলো `join/1`।

একটি স্ট্রিংকে ক্যারেক্টারের অ্যারে-তে রূপান্তর করা অনেক সময় প্রয়োজন হয়।
এটি করার দুটি উপায় আছে:

1. খালি স্ট্রিং-এ স্প্লিট করুন

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` করে _কোডপয়েন্ট_-এর একটি অ্যারে বানান

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` হলো `explode`-এর বিপরীত।

### একটি সাবস্ট্রিংয়ের ইনডেক্স খুঁজে বের করা

`index/1` ফাংশনটি ব্যবহার করুন; ইনডেক্স শূন্য থেকে শুরু হয়।

```jq
"hello" | index("el")'   # => 1
```

সাবস্ট্রিংটি যদি স্ট্রিংয়ে না থাকে, তাহলে ফলাফল `null`

```jq
"hello" | index("elk")   # => null
```

### স্ট্রিং ইন্টারপোলেশন

একটি স্ট্রিংয়ের ভেতরে `\(expression)` সিকোয়েন্সটি ওই এক্সপ্রেশনের _ফলাফল_ [স্ট্রিংয়ের ভেতরে][interpolate] ঢুকিয়ে দেবে:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### কেস কনভার্সন

`ascii_downcase` ও `ascii_upcase` ফাংশন দুটি ব্যবহার করুন।

### রেগুলার এক্সপ্রেশন

`jq`-তে রেগুলার এক্সপ্রেশনের জন্য সমৃদ্ধ সাপোর্ট আছে: এটি পরের একটি পাঠের বিষয় হবে।

[interpolate]: https://jqlang.org/manual/#string-interpolation
