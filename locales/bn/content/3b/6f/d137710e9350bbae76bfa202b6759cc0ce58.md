# Configlet দিয়ে ফাইল তৈরি

নতুন কোনো অ্যাপ্রোচ, আর্টিকেল বা অনুশীলনী যোগ করার সময় আপনাকে খুব নির্দিষ্ট নামের ফাইল তৈরি করতে হবে।
এগুলোর জন্য কনফিগারেশন ফাইল যোগ বা আপডেট করাও প্রয়োজন হয়।
`create` কমান্ডের সাহায্যে [configlet](/docs/building/configlet) এই সব কাজ আপনার হয়ে করে দিতে পারে।

## ব্যবহার

`create` কমান্ড দিয়ে নতুন কোনো অ্যাপ্রোচ, আর্টিকেল বা অনুশীলনী যোগ করার জন্য দরকারি ফাইল তৈরি করা যায়, সেই সঙ্গে যেকোনো কনফিগারেশন ফাইলও পরিবর্তন করা যায়।

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## প্র্যাকটিস অনুশীলনী তৈরি

[প্র্যাকটিস অনুশীলনী যোগ করার ডকুমেন্টেশনে](/docs/building/tracks/practice-exercises/add) প্র্যাকটিস অনুশীলনী কীভাবে যোগ করতে হয়, তার বিস্তারিত নির্দেশনা আছে।

## কনসেপ্ট অনুশীলনী তৈরি

একটি কনসেপ্ট অনুশীলনী তৈরি করতে হলে তার স্লাগ উল্লেখ করতে হবে:

```shell
configlet create --concept-exercise bird-watcher
```

এতে কনসেপ্ট অনুশীলনীর প্রয়োজনীয় ফাইলগুলো তৈরি হবে, যেমনটি [কনসেপ্ট অনুশীলনীর ডকুমেন্টেশনে](/docs/building/tracks/concept-exercises) বলা আছে।

অবশ্যই, অনুশীলনী তৈরির এটা কেবল প্রথম ধাপ।
এরপর আপনাকে যা যা করতে হবে:

- টেস্ট ফাইলে টেস্ট যোগ করা
- একটি এক্সেমপ্লার ইমপ্লিমেন্টেশন যোগ করা
- স্টাব ফাইলের বিষয়বস্তু নির্ধারণ করা
- `.docs/introduction.md`-এ ভূমিকা লেখা
- `.docs/instructions.md`-এ নির্দেশনা লেখা
- অনুশীলনীর `.meta/config.json` ফাইলে:
  - `authors` কী (key)-তে অনুশীলনীর লেখকদের GitHub ইউজারনেম যোগ করা
- ট্র্যাকের `config.json` ফাইলে:
  - অনুশীলনীর কাঠিন্য যাচাই/আপডেট করা
  - `concepts` কী (key)-তে কনসেপ্ট যোগ করা
  - `prerequisites` কী (key)-তে কনসেপ্ট যোগ করা

## অ্যাপ্রোচ তৈরি

একটি অ্যাপ্রোচের ফাইল তৈরি করতে হলে অ্যাপ্রোচটির আর তার অনুশীলনীর স্লাগ উল্লেখ করতে হবে:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

এতে অ্যাপ্রোচের প্রয়োজনীয় ফাইলগুলো তৈরি হবে, যেমনটি [অ্যাপ্রোচ ডকুমেন্টেশনে](/docs/building/tracks/approaches) বলা আছে।

## আর্টিকেল তৈরি

একটি আর্টিকেলের ফাইল তৈরি করতে হলে আর্টিকেলটির আর তার অনুশীলনীর স্লাগ উল্লেখ করতে হবে:

```shell
configlet create --article performance --exercise collatz-conjecture
```

এতে আর্টিকেলের প্রয়োজনীয় ফাইলগুলো তৈরি হবে, যেমনটি [আর্টিকেল ডকুমেন্টেশনে](/docs/building/tracks/articles) বলা আছে।
