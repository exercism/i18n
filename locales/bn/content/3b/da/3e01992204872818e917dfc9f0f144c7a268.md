# কোড ইনক্লুশন

```sather
   include WARM_UP;
   include WARM_UP count -> warm_up_count;
   include WARM_UP describe -> ;
   include WARM_UP count -> beats, describe -> ;
```

একটি `include` অন্য একটি ক্লাসের কোড এই ক্লাসে কপি করে। এটি একটি কম্পাইল-টাইম অপারেশন, যার কোনো রান-টাইম খরচ নেই এবং কোনো রান-টাইম সম্পর্কও নেই: এরপর দুই ক্লাস আর পরস্পরের সাথে যুক্ত থাকে না।

## ক্লজটি

```
   include CLASS  old_name -> new_name , old_name -> ;
```

প্রতিটি এন্ট্রি একটি ফিচারের নাম বদলে দেয়। নতুন নাম ছাড়া `-> ;` সেটি বাদ দিয়ে দেয়। যা উল্লেখ করা হয়নি, তা অপরিবর্তিত অবস্থায় ঢুকে পড়ে।

নাম বদল কাজ করে *বাইরে* থেকে যা দেখা যায় তার উপর। অন্তর্ভুক্ত রুটিনগুলির মধ্যে কল আগের মতোই কাজ করে: যদি `describe` `count`-কে কল করে আর `count`-এর নাম বদলে `beats` করা হয়, তাহলে `describe` কিন্তু `beats`-কেই কল করে।

## একাধিক ইনক্লুড করা

```sather
   include WARM_UP;
   include COOL_DOWN;
```

এটি অনুমোদিত, আর অন্য ভাষাগুলো যাকে মাল্টিপল ইনহেরিট্যান্স বলে, সেদার সেটি এভাবেই পায়, তবে সেই চেনা ঝামেলা ছাড়াই। কারণ সংঘর্ষ হলে সেটি কম্পাইল এরর, আর সমাধান হলো নাম বদল করা বা একটি বাদ দেওয়া। এখানে মুখস্থ করতে হয় এমন কোনো অগ্রাধিকার-ক্রম দিয়ে কিছুই মিটিয়ে ফেলা হয় না।

## private include

```sather
   private include WARM_UP;
```

এটি কোডটি এই ক্লাসের নিজের ব্যবহারের জন্য নিয়ে আসে, কিন্তু বাইরে প্রকাশ করে না। যখন আপনার ইন্টারফেস নয়, ইমপ্লিমেন্টেশন দরকার, তখন এটি কাজে লাগে।

## দুটো একসাথে

ক্লাসের একটি পরিবারের জন্য সাধারণ গঠনটি হলো:

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class ACT_BASICS is
   minutes : INT is return 5; end;
end;

class JUGGLING < $ACT is
   include ACT_BASICS;
   name : STR is return "Juggling"; end;
end;
```

`< $ACT` বলে দেয় এটি কী করতে পারে; `include ACT_BASICS` যোগায় "কীভাবে"-এর একটি অংশ। "কীভাবে" নিয়ে আপনার মত বদলে গেলেও `<` কিন্তু নড়ে না।

## কেন এভাবে করা হয়

অ্যাবস্ট্র্যাক্ট ক্লাসে কোনো কোড থাকে না, তাই ভুলে বসে সেটি থেকে ইনহেরিট করা যায় না, আর এমন কোনো সুপারক্লাসও নেই যার আচরণ আপনার পায়ের নিচেই বদলে যায়। রিইউজ এখানে কম্পাইল টাইমে নেওয়া একটি কপি, যা আপনি যে ক্লাসের নাম বলেছেন সেটি থেকে আসে, আর প্রতিটি নাম বদল লিখিত থাকে।

খরচটা হলো, প্রতিটি ক্লাসে রিইউজ আলাদা করে চাইতে হয়। এটাই এই লেনদেন: টাইপ করতে হয় বেশি, কিন্তু লুকানো কিছু নেই।
