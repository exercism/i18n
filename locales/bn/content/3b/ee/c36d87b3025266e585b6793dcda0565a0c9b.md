# নির্দেশনা

ভবিষ্যতের জাদুকর হিসেবে এলিসকে কিছু মৌলিক বিষয় অনুশীলন করতে হবে।

তার কাছে কার্ডের একটি স্ট্যাক আছে, যেটি সে নাড়াচাড়া করতে চায়।

কাজটি একটু সহজ করতে সে শুধু ১ থেকে ১০ সংখ্যার কার্ডগুলোই ব্যবহার করে।

কার্ডের স্ট্যাকটি একটি `Array` দিয়ে প্রকাশ করা হয়, যেখানে স্ট্যাকের নিচের অংশটি অ্যারের সামনে এবং স্ট্যাকের উপরের অংশটি অ্যারের পিছনে থাকে।

## 1. স্ট্যাকের উপরে একটি কার্ড ঢোকান

`insert_top` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের একটি কপি রিটার্ন করে, যাতে নতুন দেওয়া কার্ডটি স্ট্যাকের উপরে যোগ করা থাকে।

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. স্ট্যাক থেকে উপরের কার্ডটি সরান

`remove_top_card` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের একটি কপি রিটার্ন করে, যার উপরের কার্ডটি সরিয়ে ফেলা হয়েছে।

যদি দেওয়া স্ট্যাকটি খালি হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. স্ট্যাকের নিচে একটি কার্ড ঢোকান

`insert_bottom` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের একটি কপি রিটার্ন করে, যাতে নতুন দেওয়া কার্ডটি স্ট্যাকের নিচে যোগ করা থাকে।

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. স্ট্যাকের নিচ থেকে একটি কার্ড সরান

`remove_bottom_card` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের একটি কপি রিটার্ন করে, যার নিচের কার্ডটি সরিয়ে ফেলা হয়েছে।

যদি দেওয়া স্ট্যাকটি খালি হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. স্ট্যাকের আকার যাচাই করুন

`check_size_of_stack` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে স্ট্যাকের আকার দেওয়া `stack_size`-এর সমান কি না।

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
