# নির্দেশনার সংযোজন

## এই অনুশীলনীটি Python-এ যেভাবে বাস্তবায়ন করা হয়েছে: রিকার্সন

এই অনুশীলনীটি লুপের বদলে [concept:python/recursion]() ব্যবহার করে সম্পন্ন করার জন্য তৈরি করা হয়েছে।
রিকার্সিভ ফাংশন হলো এমন একটি ফাংশন যা নিজেকেই কল করে, আর যে সমস্যাগুলো নিজেদের ভিত্তিতেই সংজ্ঞায়িত, সেগুলো সমাধানে এটি কাজে লাগে।
অসীম রিকার্সন এড়াতে (আরও নির্দিষ্ট করে বললে, স্ট্যাক ওভারফ্লো এড়াতে) "বেস কেস" নামের একটি কৌশল ব্যবহার করা হয়।
বেস কেসে পৌঁছে গেলে রিকার্সিভ নয় এমন একটি মান রিটার্ন করা হয়, যার ফলে আগের ফাংশন কলটিও নিজের কাজ শেষ করে মান রিটার্ন করতে পারে; এভাবে স্ট্যাকের নিচের দিকে ছড়িয়ে পড়ে শেষে প্রথম ফাংশন কলটি উত্তর রিটার্ন করে।
৫!-এর (অর্থাৎ ৫ * ৪ * ৩ * ২ * ১) উত্তর বের করতে আমরা এভাবে একটি রিকার্সিভ ফাংশন লিখতে পারি:

````python
def factorial(number):
  if number <= 1:  # base case
    return 1

  return number * factorial(number - 1) # recursive case

print(factorial(5)) # returns 120
````

সবশেষে মনে রাখা দরকার, Python রিকার্সিভ কল কতবার করা যাবে তা সীমিত রাখে (ডিফল্টভাবে ১০০০ বার) এবং [টেইল রিকার্সন][tail-recursion]-এর জন্য অপটিমাইজ করে না।

## এক্সেপশনের মেসেজ

কখনো কখনো [এক্সেপশন রেইজ করা][raising] প্রয়োজন হয়।
এমন করার সময় সবসময় একটি **অর্থপূর্ণ এরর মেসেজ** দিতে হবে, যাতে বোঝা যায় এররটির উৎস কী।
এতে আপনার কোড আরও পড়ার উপযোগী হয় এবং ডিবাগিংয়ে অনেক সহায়তা করে।
যেসব ক্ষেত্রে আপনি জানেন যে এররের উৎস নির্দিষ্ট কোনো টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপ][built-in-errors]-এর একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থপূর্ণ মেসেজ দিতে হবে।

এই নির্দিষ্ট অনুশীলনীতে `rows()` ফাংশনে ঋণাত্মক সংখ্যা পাঠানো হলে [রেইজ স্টেটমেন্ট][raise-statement] ব্যবহার করে একাধিক `ValueErrors` "থ্রো" করতে হবে।
টেস্ট কেবল তখনই পাস করবে, যখন আপনি `exception` `raise` করবেন এবং তার সঙ্গে একটি মেসেজও দেবেন।

মেসেজসহ একটি `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# if the rows function is passed a negative number.
raise ValueError("number of rows is negative")
```
