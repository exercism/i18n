# get_in

নিশ্চিত করুন যেন আপনি `BasketballWebsite.get_in_path/2` ফাংশনে শুধুমাত্র `get_in/2` ব্যবহার করেন, `BasketballWebsite.extract_from_path/2` ফাংশনে নয়। এই অনুশীলনীর উদ্দেশ্য হলো Access Behaviour দুটি ভিন্ন উপায়ে ব্যবহার করার চর্চা করা: প্রথমে সরাসরি `data[key]` সিনট্যাক্স ব্যবহার করে, তারপর পরোক্ষভাবে `get_in_path/2` ব্যবহার করে।
