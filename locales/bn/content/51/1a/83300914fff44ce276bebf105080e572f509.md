# ম্যাচ বেসিকস

`match` এক্সপ্রেশনটি একটি মানকে একের পর এক প্যাটার্নের সাথে সহজে তুলনা করতে দেয় এবং এরপর মিলে যাওয়া প্যাটার্নের ভিত্তিতে কোড চালাতে দেয়।
লিটারেল মান, ভ্যারিয়েবলের নাম, ওয়াইল্ডকার্ড এবং আরও অনেক কিছু মিলেই একটি প্যাটার্ন তৈরি হয়।

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

একাধিক লাইনের কোড লিখতে হলে `match`-এর কোড আর্মটি দ্বিতীয় বন্ধনী `{}` দিয়ে মুড়ে দিতে হবে:

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

`match` এক্সপ্রেশনটিতে প্যাটার্নের সাথে মিলে যাওয়া মানের সাথে বাইন্ড করার সুবিধাও রয়েছে।
এর ফলে একটি enum ভ্যারিয়েন্টের সংশ্লিষ্ট মান বের করা সম্ভব হয়।

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

এখানে `Color` enum-এর `Red` ভ্যারিয়েন্টটিকে বাড়িয়ে তার সাথে একটি সংশ্লিষ্ট enum যুক্ত করা হয়েছে।
`match` এক্সপ্রেশনের সাহায্যে আমরা সংশ্লিষ্ট মানটি, অর্থাৎ `state`, বের করতে পারি।
এটি কেবল একটি ভ্যারিয়েবলের নাম, যা পরে কোড আর্মে ব্যবহার করা যায়।

## `Option` enum টাইপের সাথে ম্যাচ করা

বিল্ট-ইন `Option` enum-ও `match` এক্সপ্রেশন দিয়ে সামলানো যায়।

চলুন এমন একটি ফাংশন তৈরি করি, যা একটি `Option<u8>` প্যারামিটার নেয়।
প্রদত্ত প্যারামিটারে যদি কোনো মান থাকে, তবে সেই মানের সাথে এক যোগ করা হবে; নাহলে ফাংশনটি কিছু না করেই `None` মান রিটার্ন করবে।

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> নোট: `{:?}` একটি বিশেষ ফরম্যাটিং সিনট্যাক্স, যা `println!` ম্যাক্রোতে পাঠানো প্যারামিটারের একটি ডিবাগ রূপ প্রিন্ট করতে দেয়।
> এটি সম্পর্কে আরও তথ্য পাবেন [The Cairo Book][debugging]-এ।

`match` কন্ট্রোল ফ্লো ব্যবহারের একটি সুবিধা হলো এর পূর্ণাঙ্গতা: আর্মগুলোর প্যাটার্ন অবশ্যই _সব_ সম্ভাবনা কভার করতে হবে।
এবার আগের উদাহরণটির এমন একটি সংস্করণ দেখুন, যেখানে `None` কেসটি সামলানো হয়নি:

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## `_` ওয়াইল্ডকার্ড দিয়ে সব ধরার প্যাটার্ন

enum ব্যবহার করে আমরা কয়েকটি নির্দিষ্ট মানের জন্য বিশেষ কিছু করতে পারি, আর বাকি সব মানের জন্য একটি ডিফল্ট কাজ করতে পারি: `match` এক্সপ্রেশনের শেষ আর্ম হিসেবে `_`-কে প্যাটার্ন ধরে একটি নতুন আর্ম যোগ করে দিলেই হয়।
`_` প্যাটার্নটি একটি বিশেষ প্যাটার্ন, যা যেকোনো মানের সাথে মেলে এবং সেই মানের সাথে বাইন্ড করে না।

`is_red` ফাংশনটি একটি প্যারামিটার নেয় এবং রংটি `Red` হলে `true`, আর অন্য যেকোনো রং হলে `false` রিটার্ন করে:

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## `|` অপারেটর দিয়ে প্যাটার্ন ম্যাচিং

Cairo-র `match` কন্ট্রোল ফ্লো কনস্ট্রাক্টটি `|` (_অথবা_) অপারেটর ব্যবহার করে একটি মানকে একাধিক প্যাটার্নের সাথে মেলানোর সুবিধা দেয়।
এতে কোড সহজ হয়।

উদাহরণস্বরূপ, `Color` enum ব্যবহার করে আমরা এমন একটি ফাংশন লিখতে চাই, যা `Red` বা `Green` রঙের জন্য `true` এবং অন্য রঙের জন্য `false` রিটার্ন করে:

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## `felt252` ও ইন্টিজার ভ্যারিয়েবলের সাথে প্যাটার্ন ম্যাচিং

`felt252` ও ইন্টিজার ভ্যারিয়েবলকে একগুচ্ছ মানের সাথে মেলানো সম্ভব।
তবে কিছু সীমাবদ্ধতা আছে;

- কেবল সেইসব ইন্টিজার সমর্থিত, যেগুলো একটি `felt252`-এর মধ্যে ধরে যায় (অর্থাৎ `u256` সমর্থিত নয়)।
- 0 হতে হবে প্রথম আর্ম।
- প্রতিটি আর্মকে একটি ক্রমিক অংশ অনুসরণ করতে হবে, যা অন্য আর্মগুলোর সাথে সংলগ্ন থাকে।

চলুন ছয় পিঠের একটি ছক্কা ছোড়ার গেম তৈরি করি।
ছক্কাটি ছোড়া হলে আমরা 0 থেকে 5-এর মধ্যে একটি সংখ্যা পাই।
ছোড়ার ফলে 0, 1 বা 2 এলে আপনি জিতে যান।
3 এলে আবার ছুড়তে পারবেন।
অন্য মানের জন্য আপনি হেরে যান:

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## টাপল ম্যাচ করা

টাপলকেও একগুচ্ছ প্যাটার্নের সাথে মেলানো যায়।
এই প্যাটার্নগুলোও টাপলের মতোই সাজানো হয়।

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

শেষ match আর্মে যেকোনো দিন ও রঙের সমন্বয় মেলাতে আমরা `(_, _)` ব্যবহার করি বা শুধু `_` ওয়াইল্ডকার্ড, তাতে কিছু আসে যায় না, কারণ কার্যকারিতার দিক থেকে দুটো একই।
