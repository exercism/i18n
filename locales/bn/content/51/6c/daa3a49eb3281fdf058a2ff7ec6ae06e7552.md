# পরিচিতি

## Pairs

একটি `Pair` আসলে দুটি জিনিসের জোড়া, যা একসঙ্গে যুক্ত করা হয়।
এরপর ওই জিনিস দুটিকে কল্পনাপ্রবণভাবে `first` ও `second` নাম দেওয়া হয়।

এগুলো তৈরি করতে পারেন `=>` অপারেটর দিয়ে, অথবা `Pair()` কনস্ট্রাক্টর দিয়ে।

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Dicts

`Pair`-এর একটি `Vector` অন্য যেকোনো অ্যারের মতোই: ক্রমানুসারে সাজানো, টাইপের দিক থেকে সমরূপ, এবং মেমোরিতে পরপর সংরক্ষিত।

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

একটি `Dict` পৃষ্ঠতলে এর মতোই দেখতে, কিন্তু এবার এর সংরক্ষণ এমনভাবে বাস্তবায়িত যে কী (key) দিয়ে দ্রুত মান বের করা যায়, এমনকি এন্ট্রির সংখ্যা অনেক বেড়ে গেলেও।

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

অন্য ভাষায় `Dict`-এর সঙ্গে খুব কাছাকাছি জিনিসটিকে হয়তো dictionary (Python), Hash (Ruby) বা HashMap (Java) বলা হয়।

Pairs-এর ক্ষেত্রে, তা একা হোক বা একটি Vector-এর ভেতরে, প্রতিটি উপাদানের টাইপ নিয়ে খুব একটা বাধা নেই।

একটি `Dict`-এ বৈধ হতে হলে `Pair`-টিকে অবশ্যই একটি `key => value` জোড়া হতে হবে, যেখানে `key`-কে হতে হবে "হ্যাশযোগ্য"।
সবচেয়ে গুরুত্বপূর্ণ হলো, এর মানে `key`-কে হতে হবে _অপরিবর্তনীয়_, তাই `Char`, `Int`, `String`, `Symbol` ও `Tuple` সবই ঠিক আছে, কিন্তু `Vector` অনুমোদিত নয়।

### একটি Dict পরিবর্তন করা

নতুন কী (key) দিয়ে এন্ট্রি যোগ করা যায়, আবার বিদ্যমান কী (key) দিয়ে সেটি ওভাররাইট করা যায়।

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

কোনো এন্ট্রি মুছে ফেলতে `delete!()` ফাংশনটি ব্যবহার করুন। কী (key) থাকলে এটি Dict পরিবর্তন করবে, নাহলে চুপচাপ কিছুই করবে না।

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### একটি কী (key) বা মান আছে কি না তা যাচাই করা

এর কয়েকটি আলাদা উপায় আছে।
একটি কী (key) যাচাই করতে আছে `haskey()` ফাংশন:

```julia-repl
julia> haskey(pd, 'b')
true
```

অথবা কী (key) বা মানের মধ্যে খুঁজুন:

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
