# ভূমিকা

`Agent` মডিউল প্রসেস এবং _রিসিভ-সেন্ড_ লুপ স্পন করার জন্য একটি অ্যাবস্ট্রাকশন সরবরাহ করে। এখান থেকে `Agent` মডিউল ব্যবহার করে শুরু করা প্রসেসগুলোকে আমরা _'এজেন্ট প্রসেস'_ বলব। একটি _এজেন্ট প্রসেস_ একটি কেন্দ্রীয় শেয়ার্ড স্টেট উপস্থাপন করার জন্য বেছে নেওয়া হতে পারে।

একটি _এজেন্ট প্রসেস_ শুরু করতে `Agent` `start/2` ফাংশনটি সরবরাহ করে। `start` দিয়ে _এজেন্ট প্রসেস_ শুরু করার সময় সরবরাহ করা ফাংশনটি প্রসেসের প্রাথমিক স্টেট রিটার্ন করে:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map` বা `List`-এর মতোই, `Agent` _এজেন্ট প্রসেস_ নিয়ে কাজ করার জন্য অনেক ফাংশন সরবরাহ করে।

যে ডোমেইন মডেল করা হচ্ছে, তার জন্য `Agent`-সম্পর্কিত সব কার্যকারিতা একটি মডিউলে সংগঠিত ও এনক্যাপসুলেট করা প্রথাগত।
