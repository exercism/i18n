# নির্দেশাবলী

এই অনুশীলনীতে আপনি কারখানার কর্মীদের জন্য নেম ব্যাজ ছাপানোর কোড লিখবেন।

## 1. একজন কর্মীর জন্য একটি ব্যাজ ছাপানো

কর্মীদের একটি ID, নাম ও ডিপার্টমেন্টের নাম থাকে।
কর্মীদের ব্যাজের লেবেল নিচের মতো ফরম্যাট করা হয়: `"[id] - name - DEPARTMENT"`।
একজন কর্মীর ব্যাজের লেবেল রিটার্ন করতে `printBadge()` মেথডটি ইমপ্লিমেন্ট করুন:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
লক্ষ্য করুন, লেবেলে ডিপার্টমেন্টের নাম বড় হাতের অক্ষরে লেখা হয়।
~~~~

## 2. নতুন একজন কর্মীর জন্য একটি ব্যাজ ছাপানো

কম্পিউটার সিস্টেমের এক অদ্ভুত কারণে, কারখানায় কাজ শুরু করার সময় নতুন কর্মীদের অনেক সময়ই তখনও কোনো ID থাকে না।
ব্যাজ বাধ্যতামূলক হওয়ায়, তারা ID প্রিফিক্স ছাড়া একটি সাময়িক ব্যাজ পাবেন।
যেসব নতুন কর্মীর তখনও ID নেই তাদের সাপোর্ট করতে `printBadge()` মেথডটি পরিবর্তন করুন:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. মালিকের জন্য একটি ব্যাজ ছাপানো

কারখানার মালিককেও সব সময় একটি ব্যাজ পরে থাকতে হয়।
তবে মালিকের কোনো ডিপার্টমেন্ট থাকে না।
এক্ষেত্রে ডিপার্টমেন্টের নামের বদলে লেবেলে `"OWNER"` ছাপা হবে।
মালিকের জন্য একটি লেবেল ছাপাতে `printBadge()` মেথডটি পরিবর্তন করুন:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
লক্ষ্য করুন, মালিকও নতুন কর্মী হতে পারেন:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
