# ভূমিকা

## নালেবিলিটি

Java-তে, `null` লিটারালটি কোনো মানের অনুপস্থিতি বোঝাতে ব্যবহৃত হয়।

Java-এর প্রিমিটিভ ডেটা টাইপগুলোর প্রত্যেকটিরই একটি ডিফল্ট মান থাকে, তাই সেগুলো কখনোই `null` হতে পারে না। প্রচলিত রীতি অনুযায়ী এগুলো ছোট হাতের অক্ষর দিয়ে শুরু হয়, যেমন `int`।

রেফারেন্স টাইপ কোনো অবজেক্টের মেমোরি অ্যাড্রেস ধারণ করে এবং এর মান `null` হতে পারে। এগুলো সাধারণত বড় হাতের অক্ষর দিয়ে শুরু হয়, যেমন `String`।

একটি প্রিমিটিভ ভ্যারিয়েবলে `null` মান অ্যাসাইন করার চেষ্টা করলে কম্পাইল টাইম এরর দেখা দেবে, কারণ ভ্যারিয়েবলটি সবসময়ই তার অ্যাসাইন করা টাইপের একটি প্রিমিটিভ মান ধারণ করে।

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

একটি রেফারেন্স ভ্যারিয়েবলে `null` মান অ্যাসাইন করলে কম্পাইল টাইম এরর হবে না, কারণ রেফারেন্স ভ্যারিয়েবলগুলো নাল হতে পারে।

```java
//No error will occur as the String variable str is nullable
String str = null;
```
