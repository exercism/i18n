# পরিচিতি

আপনি যখন Factor সিকোয়েন্স *পরিবর্তন* করতে চান, তখন সেগুলো দুই রকমের হয়:

- **অ্যারে** (`{ … }`) এর দৈর্ঘ্য নির্দিষ্ট। `set-nth` / `change-nth` দিয়ে আপনি প্রতিটি অবস্থানে *যা আছে* তা বদলাতে পারেন, কিন্তু সেগুলোর আকার বাড়াতে বা কমাতে পারেন না।
- **ভেক্টর** (`V{ … }`) পরিবর্তনশীল দৈর্ঘ্যের। `push` শেষে যোগ করে, `pop` শেষ এলিমেন্টটি সরিয়ে সেটি রিটার্ন করে।

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| ওয়ার্ড            | এফেক্ট                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`, `elt`-এর `n` সংখ্যক কপি দিয়ে গঠিত অ্যারে |
| `<vector>`      | `( n -- vector )`, `n` ধারণক্ষমতার খালি ভেক্টর |
| `V{ }`          | খালি ভেক্টর লিটারাল                            |
| `set-nth`       | `( elt n seq -- )`, `n` ইনডেক্সের এলিমেন্ট অ্যাসাইন করে |
| `change-nth`    | `( i seq quot -- )`, `i` অবস্থানের এলিমেন্টে `quot` প্রয়োগ করে |
| `push`          | `( elt seq -- )`, ভেক্টরের শেষে যোগ করে        |
| `suffix!`       | `( seq elt -- seq )`, একই জায়গায় যোগ করে, ভেক্টরটি রিটার্ন করে |
| `pop`           | `( seq -- elt )`, শেষটি সরিয়ে রিটার্ন করে      |
| `pop*`          | `( seq -- )`, শেষটি সরিয়ে ফেলে দেয়            |
| `clone`         | `( obj -- copy )`, স্বাধীন নতুন কপি            |
| `new-sequence`  | `( n exemplar -- newseq )`, `exemplar`-এর মতো একই ক্লাসের নতুন সিকোয়েন্স |
| `new-resizable` | `( n exemplar -- newseq )`, আকার পরিবর্তনযোগ্য নতুন ভ্যারিয়েন্ট |

আপনি যখন কলার থেকে পাঠানো কোনো সিকোয়েন্স পরিবর্তন করেন, সেই পরিবর্তন কলারের কাছেও দৃশ্যমান হয়, কারণ তারা একই অবজেক্ট ধরে রেখেছে। আপনি যদি সেটি না চান, তবে প্রথমে `clone` করে একটি স্বাধীন কপি নিয়ে নিন।
