# পরিচিতি

লুপ হলো একগুচ্ছ স্টেটমেন্ট বারবার কল করার একটি উপায়। স্টেটমেন্টের একটি গ্রুপকে একবার চালানোকে একটি ইটারেশন বলা হয়।

## While লুপ

একটি `while` লুপ লুপের উপরের দিকে থাকা একটি বুলিয়ান এক্সপ্রেশন ট্রু থাকা পর্যন্ত একগুচ্ছ স্টেটমেন্ট চালায়। বুলিয়ান এক্সপ্রেশনটি ফলস হলে লুপ চলা বন্ধ হয়ে যায় এবং কার্যক্রম লুপের পরের কোড লাইনে এগিয়ে যায়।

শুরু থেকেই যদি বুলিয়ান এক্সপ্রেশনটি ফলস হয়, তাহলে `while` লুপটি একেবারেই চলবে না এবং কার্যক্রম লুপের পরের কোড লাইনে এগিয়ে যাবে।

লুপ শেষ করার একটি শর্ত থাকা জরুরি; নাহলে এটি একটি অসীম লুপ হয়ে যায়, যা কোডের সব অগ্রগতি আটকে দেয়। উপরের কোডে `i` থেকে `++` সরিয়ে দিলে এটি একটি অসীম লুপ হয়ে যেত।

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

## Do লুপ

একটি `do` লুপের বুলিয়ান এক্সপ্রেশনটি লুপের নিচের দিকে পরীক্ষা করা হয়। একটি `do` লুপ সবসময় অন্তত একবার চলে, যেমনটি নিচের উদাহরণে দেখা যায়

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

একটি `while` লুপ দিয়ে এটি আরও লম্বা হয়ে যেত

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## For লুপ

প্রায়ই একটি লুপ একটি ভ্যারিয়েবল আপডেট করে এবং ভ্যারিয়েবলটি একটি নির্দিষ্ট মানে পৌঁছালে শেষ হয়। একটি `for` লুপ হলো বন্ধনীর ভেতরে একই লাইনে এক বা একাধিক ভ্যারিয়েবল ইনিশিয়ালাইজ, আপডেট ও টেস্ট করার একটি উপায়। প্রথম অংশটি ভ্যারিয়েবল ইনিশিয়ালাইজ করার জন্য, দ্বিতীয় অংশটি ভ্যারিয়েবল টেস্ট করার জন্য, আর তৃতীয় অংশটি ভ্যারিয়েবলের মান আপডেট করার জন্য।

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

এটি সমতুল্য `while` লুপের চেয়ে কম লম্বা, তবুও এটি পড়ার মতোই সহজ।
