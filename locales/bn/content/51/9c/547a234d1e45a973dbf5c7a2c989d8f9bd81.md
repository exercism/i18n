# নির্দেশনা

এই অনুশীলনীতে আপনি একটি রিমোট কন্ট্রোলড কার নিয়ে খেলবেন, যেটি কেনার জন্য অবশেষে আপনার যথেষ্ট টাকা জমেছে।

গাড়িগুলো পুরো (১০০%) চার্জ করা ব্যাটারি নিয়ে শুরু করে। রিমোট কন্ট্রোল দিয়ে প্রতিবার গাড়িটি চালালে এটি ২০ মিটার চলে এবং ব্যাটারির এক শতাংশ ক্ষয় করে।

রিমোট কন্ট্রোলড কারটিতে একটি চমৎকার LED ডিসপ্লে আছে, যা দুই ধরনের তথ্য দেখায়:

- এটি মোট কত দূরত্ব চালানো হয়েছে, যা দেখানো হয় এভাবে: `"Driven <METERS> meters"`.
- ব্যাটারির বাকি চার্জ, যা দেখানো হয় এভাবে: `"Battery at <PERCENTAGE>%"`.

ব্যাটারি ০% থাকলে আপনি আর গাড়িটি চালাতে পারবেন না, এবং ব্যাটারি ডিসপ্লে দেখাবে `"Battery empty"`.

আপনার সামনে ছয়টি কাজ আছে, যার প্রতিটিতে রিমোট কন্ট্রোলড কারের ইনস্ট্যান্স নিয়ে কাজ করতে হবে।

## 1. একেবারে নতুন একটি রিমোট কন্ট্রোলড কার কিনুন

একেবারে নতুন একটি রিমোট কন্ট্রোলড কার ইনস্ট্যান্স রিটার্ন করার জন্য (_static_) `RemoteControlCar.Buy()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. চালানো দূরত্ব দেখান

LED ডিসপ্লেতে যেমন দেখানো হয় সেভাবে দূরত্ব রিটার্ন করার জন্য `RemoteControlCar.DistanceDisplay()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. ব্যাটারির শতাংশ দেখান

LED ডিসপ্লেতে যেমন দেখানো হয় সেভাবে ব্যাটারির শতাংশ রিটার্ন করার জন্য `RemoteControlCar.BatteryDisplay()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. গাড়ি চালানোর সময় চালানো মিটারের সংখ্যা হালনাগাদ করুন

চালানো মিটারের সংখ্যা হালনাগাদ করে এমন `RemoteControlCar.Drive()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. গাড়ি চালানোর সময় ব্যাটারির শতাংশ হালনাগাদ করুন

ব্যাটারির শতাংশ হালনাগাদ করার জন্য `RemoteControlCar.Drive()` মেথডটি হালনাগাদ করুন:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. ব্যাটারি শেষ হয়ে গেলে গাড়ি চালানো ঠেকান

ব্যাটারি শেষ হয়ে গেলে (০%) যাতে চালানো দূরত্ব না বাড়ে এবং ব্যাটারির শতাংশ না কমে, সেভাবে `RemoteControlCar.Drive()` মেথডটি হালনাগাদ করুন:

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
