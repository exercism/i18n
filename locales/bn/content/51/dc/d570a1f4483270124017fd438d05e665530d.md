# পরিচিতি

চারলিস্ট তৈরি করা হয় `~c` সিজিল ব্যবহার করে।

```elixir
~c"hello"
```

~~~~exercism/note
খেয়াল রাখুন, Elixir-এর পুরোনো সংস্করণে চারলিস্টকে সিঙ্গেল কোট দিয়ে `'hello'` হিসেবে লেখা হতো।
~~~~

যদিও দেখতে এরা স্ট্রিংয়ের সাথে খুবই মিল, তবে এই দুটি ডেটা টাইপ একে অপরের থেকে যথেষ্ট আলাদা। একটি চারলিস্ট হলো ইন্টিজারের একটি অ্যারে। এই ইন্টিজারগুলো একটি নির্দিষ্ট ক্যারেক্টারের ইউনিকোড মান প্রকাশ করে, যাকে কোড পয়েন্টও বলা হয়।

```elixir
[65, 66, 67]
# => ~c"ABC"
```

কোনো ক্যারেক্টারের কোড পয়েন্ট পেতে চাইলে তার আগে `?` বসাতে পারেন।

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

যেহেতু চারলিস্ট এক ধরনের অ্যারে, তাই অন্য যেকোনো অ্যারের মতোই এদের নিয়ে কাজ করতে পারেন, রিকার্শন ও প্যাটার্ন ম্যাচিং ব্যবহার করে।

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

`++` ব্যবহার করে দুটি অ্যারে সংযুক্ত করতে পারেন।

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

প্রথম অ্যারেটি যত বড় হবে, সংযুক্ত করাটা তত ধীর হবে, তাই ইচ্ছেমতো দৈর্ঘ্যের অ্যারেতে বারবার কিছু যোগ করা এড়িয়ে চলুন।
