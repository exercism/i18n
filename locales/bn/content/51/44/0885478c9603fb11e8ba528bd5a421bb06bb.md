# পরিচিতি

Clojure-এ একটি নামের সাথে একটি মান বাইন্ডিং করাকে [_var_][vars] বলা হয়। টপ-লেভেল (গ্লোবাল) var অন্য ভাষার কনস্ট্যান্টের মতো, তবে ডাইনামিক ডেভেলপমেন্ট সহজতর করতে সাধারণত এগুলো পুনরায় ডিফাইন করা হয়।

টপ-লেভেল var [`def`][def] দিয়ে ডিফাইন করা হয়:

```clojure
(def fingers 10)
```

মানের উপর গাণিতিক কাজ করতে আপনি [সংখ্যার উপর অপারেশনগুলো][operators] করার জন্য কোর ফাংশনগুলো ব্যবহার করতে পারেন।

`defn` ম্যাক্রো দিয়ে শূন্য বা তার বেশি আর্গুমেন্ট নেয় এমন একটি [ফাংশন][functions] ডিফাইন করা যায়। একটি ফাংশন সবসময় তার বডির শেষ এক্সপ্রেশনের ফলাফল রিটার্ন করে।

```clojure
(defn add [x y]
  (+ x y))
```

একটি ফাংশন কল করা হয় তার নাম উল্লেখ করে এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```clojure
(def five (add 2 3))
```

Clojure-এ ফাংশন ও মান কেবল সেগুলো ডিফাইন করার _পরে_ ব্যবহার করা যায়। ডিফাইন করার আগে ব্যবহার করলে কম্পাইল এরর হয়।

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Clojure-এ হোয়াইটস্পেসের ফরম্যাটিং ছাড়া আর কোনো তাৎপর্য নেই।

Clojure-এর ফাংশন ও var নেমস্পেসে সংগঠিত থাকে। একটি নেমস্পেস সম্পর্কিত কার্যকারিতা একত্র করে এবং `ns` ম্যাক্রো দিয়ে ডিফাইন করা হয়:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure দুই ধরনের কমেন্ট সমর্থন করে। এক লাইনের কমেন্টের আগে `;` থাকে এবং `(comment` ও `)`-এর মধ্যবর্তী সবকিছুর ইভালুয়েশন ঠেকাতে `comment` ফর্ম ব্যবহার করা হয়।

[vars]: https://clojure.org/reference/vars
[functions]: https://clojure.org/guides/learn/functions
[operators]: https://clojuredocs.org/quickref#numbers
