# নির্দেশনা

এই অনুশীলনীতে আপনি একটি বিউটি সেলুনের জন্য অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন, যেটি ২০১২ সালের ১৫ সেপ্টেম্বর চালু হয়েছিল।

আপনার পাঁচটি কাজ আছে, যার প্রত্যেকটিতেই অ্যাপয়েন্টমেন্টের তারিখ জড়িত থাকবে।

## 1. অ্যাপয়েন্টমেন্টের তারিখ পার্স করুন

একটি অ্যাপয়েন্টমেন্টের তারিখের লিখিত রূপকে সংশ্লিষ্ট `time.Time` ফরম্যাটে পার্স করতে `Schedule` ফাংশনটি ইমপ্লিমেন্ট করুন:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. অ্যাপয়েন্টমেন্ট আগেই পেরিয়ে গেছে কি না যাচাই করুন

`HasPassed` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি অতীতে পড়ে কি না তা যাচাই করে:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. অ্যাপয়েন্টমেন্ট বিকেলে কি না যাচাই করুন

`IsAfternoonAppointment` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি বিকেলে কি না (>= 12:00 এবং < 18:00) তা যাচাই করে:

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. অ্যাপয়েন্টমেন্টের সময় ও তারিখ বর্ণনা করুন

`Description` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং সেই তারিখ ও সময়ের একটি বিবরণ রিটার্ন করে:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. সেলুনটি চালু হওয়ার বার্ষিকী তারিখ রিটার্ন করুন

`AnniversaryDate` ফাংশনটি ইমপ্লিমেন্ট করুন, যা UTC-তে চলতি বছরের জন্য সেলুনটি চালু হওয়ার বার্ষিকী তারিখ রিটার্ন করে।

ধরে নিন চলতি বছর ২০২০:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**নোট:** রিটার্ন ভ্যালুটি একটি `time.Time` এবং দিনের সময় গুরুত্বপূর্ণ নয়।
