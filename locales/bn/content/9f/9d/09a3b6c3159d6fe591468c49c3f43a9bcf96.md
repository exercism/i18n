# স্ট্রাক্ট

স্ট্রাক্ট হলো কাস্টম ডেটা টাইপ, যার সাহায্যে একাধিক সম্পর্কিত মানের নাম দিয়ে সেগুলোকে একসাথে প্যাকেজ করা যায়।
এগুলো টিউপলের মতোই, তবে আরও নমনীয় এবং এতে প্রতিটি ডেটার আলাদা নাম দেওয়া যায়, যা আপনার কোডকে আরও স্পষ্ট করে তোলে।
Cairo-তে স্ট্রাক্টের বৈশিষ্ট্যগুলো এই রকম:

- প্রতিটি স্ট্রাক্ট টাইপের একটি নির্দিষ্ট নাম থাকে।
- স্ট্রাক্টের প্রতিটি সদস্যকে **ফিল্ড** বলা হয়।
- স্ট্রাক্টের প্রতিটি ফিল্ডের একটি নির্দিষ্ট নাম থাকে।
- দৃশ্যমানতা ফিল্ড পর্যায়ে ট্র্যাক করা হয়: প্রতিটি ফিল্ড স্বতন্ত্রভাবে পাবলিক বা প্রাইভেট হতে পারে।

## স্ট্রাক্ট ডিফাইন ও ইনস্ট্যান্টিয়েট করা

স্ট্রাক্ট ডিফাইন করতে `struct` কিওয়ার্ডটি ব্যবহার করুন, তারপর একটি নাম এবং ফিল্ডগুলোর নাম ও টাইপ নিয়ে দ্বিতীয় বন্ধনী `{}` লিখুন:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

`struct`-এর একটি ইনস্ট্যান্স তৈরি করতে `struct`-এর নাম উল্লেখ করুন এবং ফিল্ডগুলোর জন্য কী-ভ্যালু জোড়া নিয়ে দ্বিতীয় বন্ধনী ব্যবহার করুন।
খেয়াল করুন, ইনস্ট্যান্স তৈরি করার সময় ফিল্ডগুলো যেকোনো ক্রমে লিখতে পারেন:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## স্ট্রাক্টের ইনস্ট্যান্সের সাথে কাজ করা

`struct` ইনস্ট্যান্সের ফিল্ডগুলো অ্যাক্সেস বা পরিবর্তন করতে ডট নোটেশন ব্যবহার করুন।
খেয়াল করুন, কোনো ফিল্ড পরিবর্তন করতে হলে ইনস্ট্যান্সটি মিউটেবল হতে হবে:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

যেকোনো এক্সপ্রেশনের মতোই, আমরা ফাংশন বডির শেষ এক্সপ্রেশন হিসেবে `struct`-এর একটি নতুন ইনস্ট্যান্স তৈরি করতে পারি, যা সেই নতুন ইনস্ট্যান্সটি ইমপ্লিসিটলি রিটার্ন করে:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## ফিল্ড ইনিশিয়ালাইজেশনের শর্টহ্যান্ড

গত উদাহরণে `email` ও `username` ফাংশন প্যারামিটারগুলোর নাম `struct`-এর ফিল্ডগুলোর মতোই রাখা সুবিধাজনক ছিল, কিন্তু ফিল্ডে অ্যাসাইন করার সময় সেগুলো আবার লিখতে হওয়াটা একটু বিরক্তিকর।
ভাগ্যক্রমে, একই নামের ভ্যারিয়েবল থেকে স্ট্রাক্ট ফিল্ড ইনিশিয়ালাইজ করার একটি সুবিধাজনক শর্টহ্যান্ড আছে:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## স্ট্রাক্ট আপডেট সিনট্যাক্স দিয়ে অন্য ইনস্ট্যান্স থেকে ইনস্ট্যান্স তৈরি করা

কোনো বিদ্যমান ইনস্ট্যান্স থেকে নতুন একটি ইনস্ট্যান্স তৈরি করতে স্ট্রাক্ট আপডেট সিনট্যাক্স ব্যবহার করুন, যেখানে কিছু ফিল্ড বদলে দিয়ে বাকিগুলো আগের মতোই রাখা হয়।
এটি করা হয় `..` অপারেটরের সাহায্যে।

আপডেট সিনট্যাক্স ছাড়া:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

আপডেট সিনট্যাক্স দিয়ে:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

`..user1` সিনট্যাক্সটি `user1` থেকে বাকি ফিল্ডগুলো `user2`-তে কপি করে।
খেয়াল করুন, এটি `user1` থেকে ডেটা `user2`-তে মুভ করে দেয়, তাই `user1`-এ যদি কপি করা যায় না এমন টাইপ থাকে, তবে এরপর আর `user1` ব্যবহার করা যাবে না।
