# নির্দেশনা

অ্যামিউজমেন্ট পার্ক নিয়ে আপনার কাজ চালিয়ে যাওয়ার সময়, কোনো দর্শনার্থী একটি রাইড ব্যবহার করতে পারবে কি না তা যাচাই করা সহজ করার জন্য কিছু ইউটিলিটি মেথড লেখার দায়িত্ব আপনি পেয়েছেন।

## 1. কোনো দর্শনার্থীর রাইড পাস আছে কি না তা যাচাই করা

`Attendee#has_pass?` মেথডটি ইমপ্লিমেন্ট করুন, যাতে রাইড পাস আছে কি না তার ভিত্তিতে একটি বুলিয়ান (`true`/`false`) মান রিটার্ন করা যায়।

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. কোনো দর্শনার্থী একটি রাইডে উঠতে পারবে কি না তা যাচাই করা

`Attendee#fits_ride?` মেথডটি ইমপ্লিমেন্ট করুন, যাতে উচ্চতার ভিত্তিতে কোনো দর্শনার্থী একটি রাইডে উঠতে পারবে কি না তা দেখা যায়।
রাইডের জন্য প্রয়োজনীয় সর্বনিম্ন উচ্চতা একটি আর্গুমেন্ট হিসেবে দেওয়া হয়।
দর্শনার্থীর উচ্চতা রাইডের প্রয়োজনীয় সর্বনিম্ন উচ্চতার সমান বা তার চেয়ে বেশি হতে হবে।

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. কোনো দর্শনার্থীর রাইড করার অনুমতি আছে কি না তা যাচাই করা

`Attendee#allowed_to_ride?` মেথডটি ইমপ্লিমেন্ট করুন, যাতে কোনো দর্শনার্থী রাইডে চড়ার অনুমতি পাবে কি না তা দেখা যায়। রাইডের জন্য প্রয়োজনীয় সর্বনিম্ন উচ্চতা একটি আর্গুমেন্ট হিসেবে দেওয়া হয়। দর্শনার্থীর একটি রাইড পাস থাকতে হবে এবং রাইডে উঠতে সক্ষম হতে হবে।

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
