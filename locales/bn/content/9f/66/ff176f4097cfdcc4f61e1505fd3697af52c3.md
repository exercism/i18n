# নির্দেশনা

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট নিচের মতো: `"[<LEVEL>]: <MESSAGE>"`।

এখানে তিনটি ভিন্ন লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে, প্রতিটিতে একটি লগ লাইন দেওয়া থাকবে এবং সেটি নিয়ে আপনাকে কিছু একটা করতে বলা হবে।

## 1. লগ লাইন থেকে মেসেজ বের করা

লগ লাইনের মেসেজ রিটার্ন করার জন্য (_static_) `LogLevels.message()` মেথডটি ইমপ্লিমেন্ট করুন:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

শুরুতে বা শেষে থাকা হোয়াইটস্পেস বাদ দিতে হবে:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. লগ লাইন থেকে লগ লেভেল বের করা

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য (_static_) `LogLevels.logLevel()` মেথডটি ইমপ্লিমেন্ট করুন; লগ লেভেলটি ছোট হাতের অক্ষরে রিটার্ন করতে হবে:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. একটি লগ লাইন রিফরম্যাট করা

লগ লাইনটি রিফরম্যাট করার জন্য (_static_) `LogLevels.reformat()` মেথডটি ইমপ্লিমেন্ট করুন, যেখানে মেসেজটি আগে থাকবে আর তার পরে প্রথম বন্ধনীর ভিতরে লগ লেভেলটি:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
