# পরিচিতি

[F#](https://try.fsharp.org/) হলো মাইক্রোসফটের .NET ভাষা-স্ট্যাকের অংশ, একটি স্ট্রংলি টাইপড ফাংশনাল প্রোগ্রামিং ভাষা।

F# ডেটা সায়েন্সের সমস্যাগুলোর জন্য দারুণ হলেও, আপনি যেকোনো সমস্যা ছুঁড়ে দিলেই তা সুন্দরভাবে সামলে নিতে পারে।

F# যেহেতু .NET রানটাইমে চলে, তাই পুরো .NET ইকোসিস্টেমেই আপনার অ্যাক্সেস থাকে, যার মধ্যে [nuget.org](https://www.nuget.org/)-এর সব প্যাকেজও রয়েছে।

বিদ্যমান .NET কোডের সাথে ইন্টিগ্রেশন আরও সহজ হয়ে যায়, কারণ F# আপনাকে অবজেক্ট-ওরিয়েন্টেড কোড লেখার সুযোগও দেয়।

F#-এর হোমপেজ [fsharp.org](http://fsharp.org/), আর F# শেখার দারুণ একটি ভূমিকা পাবেন [F# for fun and profit](http://fsharpforfunandprofit.com/) ওয়েবসাইটে।
