# ক্যারেক্টার সম্পর্কে

এটি হতে পারে একটি _বিশাল_ বিষয়!
এটি নিয়ে একটি দীর্ঘ বই লেখা সম্ভব, আর বেশ কয়েকজন তা করেছেন (কিছু উদাহরণ দেখতে Amazon-এ "unicode book" লিখে খুঁজুন)।

## এক অতি সংক্ষিপ্ত ইতিহাস

আগের দশকগুলোতে কম্পিউটারে ক্যারেক্টার নিয়ে কাজ করা অনেক সহজ ছিল, যখন প্রোগ্রামাররা ধরে নিতেন যে ইংরেজিই একমাত্র গুরুত্বপূর্ণ ভাষা।
তাই: ২৬টি অক্ষর, বড় হাতের ও ছোট হাতের, ১০টি সংখ্যা, কয়েকটি যতিচিহ্ন, সঙ্গে বেল বাজানোর জন্য একটি কোড (0x07), আর এই সবকিছু ৭ বিটে এঁটে যেত: [ASCII][wiki-ascii] ক্যারেক্টার সেট।

স্বাভাবিকভাবেই, মানুষ জিজ্ঞাসা করতে শুরু করল à, ä আর Ł নিয়ে কী হবে, তারপর অন্যরা জিজ্ঞাসা করতে শুরু করল ऄ, ஹ আর ญ নিয়ে, আর তরুণরা চাইল ইমোজি 😱।
কী করা যায়?

সংক্ষেপে বলতে গেলে, অনেক বুদ্ধিমান ও ধৈর্যশীল মানুষকে বছরের পর বছর কমিটিতে কাজ করতে হয়েছে, [Unicode][web-unicode] ক্যারেক্টার সেট আর [UTF-8][wiki-utf-8]-এর মতো এনকোডিংয়ের খুঁটিনাটি ঠিক করতে, আর অনেক সফটওয়্যারকে _অত্যন্ত_ জটিলভাবে নতুন করে লিখতে হয়েছিল।
এছাড়া অনেক নতুন bug-ও এসে পড়ল।

_সবকিছু_ যাতে ভেঙে না পড়ে, সেজন্য Unicode/UTF-8 ডিজাইনে নিশ্চিত করা হয়েছে যে প্রথম ১২৭টি কোড ASCII-এর সঙ্গে হুবহু এক _(এমনকি বেলটিও)_।

## Kotlin-এ ক্যারেক্টার

২০০৫ সালের পর ডিজাইন করা ভাষাগুলোর বড় সুবিধা হলো, তখন একটি মোটামুটি স্থিতিশীল Unicode স্ট্যান্ডার্ড আগে থেকেই ছিল।

Kotlin (প্রথম প্রকাশ ২০১১ সালে) ধরে নিতে পেরেছিল যে ব্যবহারকারীরা নানা রকম (মানব) ভাষা ব্যবহার করবেন, আর সেগুলো প্রকাশ করতে তাঁদের Unicode দরকার হবে।

~~~~exercism/advanced
Kotlin-এ [ক্যারেক্টার][ref-char] হলো ১৬-বিট (UTF-16) [`codepoints`][wiki-codepoint], যা JVM-এর `char`-এর মতোই।
এটি বেশিরভাগ লিখিত বর্ণমালা প্রকাশের জন্য যথেষ্ট, কিন্তু ইমোজির পুরো পরিসর নয়।

সম্পূর্ণ Unicode স্ট্যান্ডার্ডে প্রতি ক্যারেক্টারে সর্বোচ্চ ছয় বাইট (৪৮ বিট) ব্যবহার করা হয় (যাকে [`grapheme`][wiki-grapheme] বলা হয়)।

প্রয়োজনে প্রতি ক্যারেক্টারে একাধিক কোডপয়েন্ট ব্যবহার করে Kotlin-এর `Strings` এই সম্পূর্ণ স্ট্যান্ডার্ড সমর্থন করে।
উদাহরণস্বরূপ, 😱 হবে `\uD83D` আর `\uDE31`।

দুর্ভাগ্যবশত, Java-তে বিল্ট-ইন গ্রাফিম সাপোর্ট নেই, আর সামঞ্জস্যের জন্য Kotlin-এও নেই।

[wiki-codepoint]: https://en.wikipedia.org/wiki/Code_point
[wiki-grapheme]: https://en.wikipedia.org/wiki/Grapheme
[ref-char]: https://kotlinlang.org/docs/characters.html
~~~~


ক্যারেক্টার লিটারাল একক কোটেশনে লেখা হয়, আর ডাবল কোটেশনে লেখা স্ট্রিং থেকে এটি আলাদা।
C/C++ জগৎ থেকে আসা মানুষের কাছে এটি সম্ভবত স্পষ্ট, কিন্তু Python আর JavaScript প্রোগ্রামারদের জন্য বিভ্রান্তিকর হতে পারে।

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code // => 65535 (64k, the largest code point allowed)

val not_char = 'abc' // => Too many characters in a character literal.
```

`Char` আর `Int`-এর মধ্যে রূপান্তর করা সহজ:

```kotlin
a.code  // => 97
Char(97) // => 'a'
```

কম্পাইলার `Char`-এর উপর _কিছু_ ধরনের ইন্টিজার অ্যারিথমেটিক অনুমোদন করে:

```kotlin
'a' + 5     // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char`-এর জন্য কিছু ফাংশন

সবসময়ের মতোই, এখানে আলোচনা করার জন্য [অনেক ফাংশন][ref-char-lib]ই আছে, তাই এটি কেবল একটি বাছাই করা তালিকা।

- উপযুক্ত বর্ণমালায় [`uppercase()`][ref-uppercase] আর [`lowercase()`][ref-lowercase] দিয়ে কেস পরিবর্তন করুন।
- [`isUpperCase()`][ref-isuppercase] আর [`isLowerCase()`][ref-islowercase] দিয়ে কেস পরীক্ষা করুন।
- ক্যারেক্টারের ধরন পরীক্ষা করুন এগুলো দিয়ে:
  - [`isLetter()`][ref-isletter], অনেক বর্ণমালা কভার করে (unicode-এ Lu, Ll, Lt, Lm আর Lo ক্যাটাগরি)
  - [`isDigit()`][ref-isdigit], 0..9 পরিসরে (unicode-এ Nd ক্যাটাগরি)
  - `isLetterOrDigit()`, আগের দুটি একসঙ্গে করে
  - [`isWhitespace()`][ref-iswhitespace], যেকোনো হোয়াইটস্পেস ক্যারেক্টার (unicode-এ Cc, Zp, Zl আর Zs ক্যাটাগরি)

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

এছাড়া, [রেগুলার এক্সপ্রেশন][ref-regex] (যা পরে একটি কনসেপ্টে আলোচনা করা হবে) শক্তিশালী সার্চ আর ম্যানিপুলেশনের সুযোগ দেয়।

## ক্যারেক্টার লিস্ট আর স্ট্রিং-এর পারস্পরিক রূপান্তর

একটি `String` থেকে `Char`-এর একটি `List`-এ রূপান্তর করতে আমরা `toList()` ব্যবহার করতে পারি।

`Char`-এর একটি `List`-কে `String`-এ রূপান্তর করতে আছে [`joinToString()`][ref-jointostring] ফাংশনটি, যা আর্গুমেন্ট হিসেবে একটি সেপারেটর নেয় (প্রায়ই খালি স্ট্রিং)।

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

মনে রাখবেন, `joinToString()` একটি List বা Array-এর উপর কাজ করে।
একটি `Char`-কে _কাস্ট_ করে এক ক্যারেক্টারের স্ট্রিং বানাতে `toString()` ব্যবহার করুন।

```kotlin
'a'.toString() // => "a"
```

একটি ক্যারেক্টার `String`-এ, বা `Char`-এর লিস্ট বা অ্যারেতে আছে কি না, তা দেখতে আমাদের আছে `in`, যা [`contains()`][ref-contains] ফাংশনের সঙ্গে মেলে।

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
