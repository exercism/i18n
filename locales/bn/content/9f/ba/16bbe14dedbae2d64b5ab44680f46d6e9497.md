# পরিচিতি

Factor-এর সিকোয়েন্স লাইব্রেরি ইটারেশন প্যারামিটারাইজ করতে *কোটেশন*-এর উপর অনেকটাই নির্ভর করে, অর্থাৎ `[ ]` বন্ধনীর ভেতরের কোড। গঠনটা সবসময় একই: একটি সিকোয়েন্স আর একটি কোটেশন পাস করুন, তারপর হায়ার-অর্ডার ওয়ার্ডটি প্রতিটি এলিমেন্টের উপর কোটেশনটি চালায়।

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

সাধারণভাবে ব্যবহৃত ওয়ার্ডগুলোর পুরো তালিকা:

| word         | shape                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

যখন *আপনার* ওয়ার্ড কোনো রানটাইম কোটেশনকে এই কম্বিনেটরগুলোর একটিতে ফরওয়ার্ড করে, তখন আপনার ওয়ার্ডটি `; inline` দিয়ে ডিক্লেয়ার করুন, যাতে কম্বিনেটরটির ইফেক্ট ইনফারেন্স কল সাইটে কোটেশনটির গঠন দেখতে পারে। কেবল লিটারাল কোটেশন দিয়ে তৈরি ওয়ার্ডগুলোর এটির দরকার নেই।

মূল সিকোয়েন্স অপারেশনগুলোর বাইরেও:

| vocab              | provides                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

পেয়ার (`bi`, `tri`) আর "n-ary" কম্বিনেটরগুলো (`2map`, `2each`, `zip`) একই প্যাটার্নটাই বাড়িয়ে নেয়, যখন কোটেশনটির একাধিক ইনপুট দরকার হয়।
