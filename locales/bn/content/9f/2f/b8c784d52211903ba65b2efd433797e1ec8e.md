# পরিচিতি

Factor-এর I/O গড়ে উঠেছে *স্ট্রিম*-এর উপর, অর্থাৎ এমন অবজেক্টের উপর, যা থেকে আপনি বাইট বা ক্যারেক্টার পড়েন, বা যেগুলোতে লেখেন। [`io`][io] ভোক্যাবুলারি একই [প্রোটোকল][stream-protocol]-এর দুটি রূপ আপনাকে দেয়।

## দুটি রূপ

**এক্সপ্লিসিট-স্ট্রিম** শব্দগুলো স্ট্রিমকে আর্গুমেন্ট হিসেবে নেয়। এদের সবগুলোই `stream-` দিয়ে শুরু হয়:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

**অ্যাম্বিয়েন্ট-স্ট্রিম** শব্দগুলো এমন স্ট্রিম থেকে পড়ে বা সেটিতে লেখে, যেটি *এই মুহূর্তে বাইন্ড করা* আছে, অর্থাৎ প্রোগ্রামজুড়ে থাকা ডাইনামিক ভ্যারিয়েবল `input-stream` বা `output-stream`। এদের নাম ছোট:

```
read1 read readln write write1 print flush
```

অ্যাম্বিয়েন্ট রূপটিই বেশিরভাগ দৈনন্দিন কোডে ব্যবহৃত হয়। আর নির্দিষ্ট কোনো স্ট্রিম হাতে থাকলে এবং অ্যাম্বিয়েন্ট স্ট্রিমটি বদলাতে না চাইলে আপনি এক্সপ্লিসিট রূপটির দ্বারস্থ হন।

## ইন-মেমোরি স্ট্রিম

এই অনুশীলনীতে আপনি [`io.streams.string`][io.streams.string] থেকে আসা স্ট্রিং-নির্ভর স্ট্রিম নিয়ে কাজ করবেন:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

একটি `<string-reader>` আক্ষরিক স্ট্রিং থেকে এমনভাবে পড়ে যেন সেটি একটি ফাইল; আর একটি `<string-writer>` তার মধ্যে লেখা সবকিছু জমা রাখে, যাতে পরে সেটি আবার পড়তে পারেন। দুটোই ফাইল স্ট্রিমের মতো একই প্রোটোকল ইমপ্লিমেন্ট করে, তাই এখানকার শিক্ষা সরাসরি `<file-reader>` / `<file-writer>`-এ কাজে লাগবে।

## `with-…` দিয়ে স্কোপিং

কোনো কোয়োটেশনের জন্য একটি এক্সপ্লিসিট স্ট্রিমকে অ্যাম্বিয়েন্ট হিসেবে বাইন্ড করতে এবং পরে সেটি ডিসপোজ করতে হলে একটি `with-…` কম্বিনেটর ব্যবহার করুন:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

"এই কোয়োটেশন যা প্রিন্ট করে তা জমা করো" এই কাজের সুবিধাজনক রূপটি হলো [`with-string-writer`][with-string-writer]। এটি রাইটারটি তৈরি করে, ওই রাইটারকে অ্যাম্বিয়েন্ট আউটপুট ধরে কোয়োটেশনটি চালায়, এবং ধরা পড়া স্ট্রিংটি রিটার্ন করে:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

সব `with-…` কম্বিনেটরই ডেস্ট্রাক্টর কম্বিনেটর ([`boatswains-bilge`][boatswains-bilge]-এর `with-disposal` ও `with-destructors`-এর মতো একই পরিবারের), অর্থাৎ কোয়োটেশনটি থ্রো করলেও বেরোনোর সময় স্ট্রিমটি ডিসপোজ হয়ে যায়।
