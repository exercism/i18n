# ভূমিকা

Pyret-এ দুটি আলাদা বুলিয়ান প্রিমিটিভ আছে, `true` এবং `false`।
এই দুটি মান দিয়ে বোঝানো হয়, একটি বিবৃতি বা শর্ত বৈধ কি না।

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret-এ `and` ও `or` অপারেটর আছে, যেগুলো দিয়ে একাধিক বুলিয়ান মান একত্র করা যায়।

and অপারেটর ট্রু রিটার্ন করে, যদি দুই দিকেই ট্রু হয়; আর বাকি সব ক্ষেত্রে ফলস রিটার্ন করে।

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

or অপারেটর ট্রু রিটার্ন করে, যদি অন্তত এক দিক ট্রু হয়; আর দুই দিকই ফলস হলে ফলস রিটার্ন করে।

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` একটি বিল্ট-ইন ফাংশন, যা ট্রু কে ফলস করে দেয়, আর ফলস কে ট্রু।

```pyret
not(true) # false
not(false) # true
```
