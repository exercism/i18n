# নির্দেশাবলি

স্ট্রিং হিসেবে লেখা একটি ট্রাইনারি সংখ্যা (যেমন '102012') কে মৌলিক নীতিগুলো ব্যবহার করে তার দশমিক সমতুল্যে রূপান্তর করুন।

যেসব স্ট্রিং অবৈধ ট্রাইনারি বোঝায়, প্রোগ্রামটি সেগুলোকে 0 মান হিসেবে ধরবে।

ট্রাইনারি সংখ্যায় তিনটি চিহ্ন থাকে: 0, 1 আর 2।

ট্রাইনারি সংখ্যায় শেষ ঘরটি হলো 1-এর ঘর। শেষ থেকে দ্বিতীয়টি 3-এর ঘর, শেষ থেকে তৃতীয়টি 9-এর ঘর, ইত্যাদি।

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

আপনার ভাষার স্ট্যান্ডার্ড লাইব্রেরিতে যদি এই রূপান্তরটি করার কোনো মেথড থাকে, তবে ধরে নিন সেটি নেই, এবং এটি নিজেই ইমপ্লিমেন্ট করুন।
