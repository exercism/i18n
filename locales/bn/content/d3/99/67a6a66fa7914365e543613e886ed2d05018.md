# পরিচিতি

## `use` এক্সপ্রেশন

Gleam-এ হায়ার অর্ডার ফাংশন লেখা ও ব্যবহার করা খুব কমন একটি বিষয়, অর্থাৎ এমন ফাংশন যা আর্গুমেন্ট হিসেবে অন্য ফাংশন গ্রহণ করে। কখনও কখনও একসাথে অনেকগুলো হায়ার অর্ডার ফাংশন ব্যবহার করলে কোড পড়া কঠিন হয়ে যেতে পারে, কারণ তখন ইনডেন্টেশনের অনেক স্তর তৈরি হয়।

উদাহরণ হিসেবে, এখানে এমন একটি ফাংশন দেওয়া হলো যা এমন কয়েকটি ফাংশন কল করে যেগুলো `Result(Int, Nil)` রিটার্ন করে, এবং চারটি ফাংশনই সফল হলে মানগুলো যোগ করে।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam-এর `use` এক্সপ্রেশন আমাদের এই কোডটি ইনডেন্টেশন ছাড়াই লিখতে দেয়, যা প্রায়শই কোড পড়া আরও সহজ করে তোলে।

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

একটি `use` এক্সপ্রেশন ব্লকের পরের সব স্টেটমেন্ট একসাথে সংগ্রহ করে এবং সেটিকে একটি কলব্যাক ফাংশন হিসেবে ফাংশন কলে শেষ আর্গুমেন্ট হিসেবে পাঠিয়ে দেয়। `use` কিওয়ার্ড এবং `<-` চিহ্নের মাঝের ভ্যারিয়েবলগুলো হলো সেই আর্গুমেন্টগুলোর নাম, যেগুলো কলব্যাক ফাংশনে পাঠানো হবে।

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

কলব্যাক ফাংশন যেকোনো সংখ্যক আর্গুমেন্ট নিতে পারে, আবার একটিও নাও নিতে পারে।

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

`use` এক্সপ্রেশন দিয়ে কল করা যায় এমন একটি ফাংশন তৈরির জন্য শেষ আর্গুমেন্ট হিসেবে একটি কলব্যাক ফাংশন নেওয়া ছাড়া আর কোনো বিশেষ শর্ত নেই।

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam-এর `use` এক্সপ্রেশন একটি অত্যন্ত শক্তিশালী ফিচার, যা অনেক সমস্যায় কাজে লাগানো যায়, কিন্তু বেশি ব্যবহার করলে কোড পড়া কঠিন হয়ে যেতে পারে। সাধারণত সাধারণ ফাংশন কল সিনট্যাক্স ব্যবহার করাই বেশি পছন্দনীয়, আর `use` এক্সপ্রেশনের সাহায্য নেওয়া উচিত শুধু তখনই, যখন তা কোড পড়া সহজ করে তোলে।
