# সম্পর্কে

ColdFusion (CFML) হলো একটি JVM স্ক্রিপ্টিং ভাষা, যার সিনট্যাক্স C বা JavaScript-এর মতো।
এটি JIT কম্পাইল হয়ে বাইট কোডে পরিণত হয়, যা JVM-এ চলে, তবে ডাইনামিক ও লুজলি টাইপড, তাই এতে ডেভেলপ করা দ্রুত ও সহজ।
CF একটি মাল্টি-প্যারাডাইম ভাষা, যা ক্লাসিক্যাল OO ও ফাংশনাল প্রোগ্রামিং সমর্থন করে।

CFML-এ একটি বিল্ট-ইন ট্যাগ-ভিত্তিক টেমপ্লেটিং ভাষাও আছে, যা এটিকে ওয়েব অ্যাপের জন্য আদর্শ করে তোলে।
এটি একটি J2EE কনটেইনারে চলে, যেখানে অনেক বান্ডল করা লাইব্রেরি থাকে, ফলে অনেক প্যাকেজ ইনস্টল করার দরকার ছাড়াই এটিকে দিয়ে খুব উৎপাদনশীলভাবে কাজ করা যায়।
CFML-এ জিপ ফাইল, PDF ও Excel তৈরি, ইমেইল, FTP, HTTP, S3 ফাইল সিস্টেম, ESAPI সিকিউরিটি লাইব্রেরি, JDBC ড্রাইভার, JSON ও REST API-এর নেটিভ সাপোর্ট আছে।

CFML চাইলে যেকোনো Java প্রকল্পও কাজে লাগাতে পারে, শুধু জার ফাইলগুলো প্রকল্পে রেখে দিলেই হয়, আর আপনার কোডে সরাসরি Java অবজেক্ট ইনস্ট্যানশিয়েট করা যায়।
