# ভূমিকা

মেথডগুলোতে একটি ভারআর্গস প্যারামিটার থাকতে পারে, যা কলকারীকে শূন্য বা তার বেশি আর্গুমেন্ট নিয়মিত প্যারামিটারের মতো নির্দিষ্ট করার সুযোগ দেয়। মেথডটি এই আর্গুমেন্টগুলো একটি মাত্র অ্যারেতে পাবে।

একটি প্যারামিটারকে ভারআর্গস প্যারামিটার করতে হলে, প্যারামিটার ডিক্লারেশনে `params` কিওয়ার্ড যোগ করুন:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
