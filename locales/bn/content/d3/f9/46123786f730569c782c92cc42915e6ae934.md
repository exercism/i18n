# নির্দেশনা

বন্ধুদের জন্য কুকি বেক করার প্রস্তুতি নিতে গিয়ে দেখলেন, রেসিপিতে ব্যবহৃত কিছু পরিমাপ আপনাকে রূপান্তর করতে হবে। আপনি যেহেতু কেবল মেট্রিক পদ্ধতির সাথেই পরিচিত, তাই নিজের সুবিধার জন্য মার্কিন বেকিংয়ের কমন পরিমাপগুলোকে মিলিলিটার (mL)-এ রূপান্তর করার একটি উপায় বের করতে হবে।

আপনার সমাধানের জন্য এই রূপান্তর ছকটি ব্যবহার করুন:

| যে একক রূপান্তর করবেন | আয়তন | মিলিলিটার (mL)-এ |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| মার্কিন কাপ          | 1      | 240                 |
| মার্কিন ফ্লুইড আউন্স  | 1      | 30                  |
| মার্কিন টিস্পুন     | 1      | 5                   |
| মার্কিন টেবিলস্পুন   | 1      | 15                  |

প্রশিক্ষণরত এক প্রতিভাবান প্রোগ্রামার হিসেবে আপনি ঠিক করলেন, তালিকাভুক্ত যেকোনো একক থেকে যেকোনো অন্য এককে (এমনকি নিজের মধ্যেও) রূপান্তর সহজ করতে মিলিলিটারকে একটি অন্তর্বর্তী একক হিসেবে ব্যবহার করবেন।

## 1. একটি ভলিউম-পেয়ার থেকে সংখ্যাগত উপাদান বের করুন

`KitchenCalculator.get_volume/1` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল দেওয়া হলে, এটি শুধু সংখ্যাগত উপাদানটি রিটার্ন করবে।

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. ভলিউম-পেয়ারকে মিলিলিটারে রূপান্তর করুন

`KitchenCalculator.to_milliliter/1` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল দেওয়া হলে, রূপান্তর ছক ব্যবহার করে এটি ভলিউমটি মিলিলিটারে রূপান্তর করবে।

প্রতিটি এককের জন্য ফাংশন তৈরি করতে একাধিক ফাংশন ক্লজ ও প্যাটার্ন ম্যাচিং ব্যবহার করুন। প্রতিটি একক বোঝাতে ব্যবহৃত অ্যাটমগুলো হলো: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. রূপান্তরের ফলাফলটি একটি টাপলে মুড়ে রিটার্ন করুন।

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. মিলিলিটার ভলিউম-পেয়ারকে অন্য এককে রূপান্তর করুন

`KitchenCalculator.from_milliliter/2` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল ও কাঙ্ক্ষিত একক দেওয়া হলে, রূপান্তর ছক ব্যবহার করে এটি ভলিউমটি কাঙ্ক্ষিত এককে রূপান্তর করবে।

প্রতিটি এককের জন্য ফাংশন তৈরি করতে একাধিক ফাংশন ক্লজ ও প্যাটার্ন ম্যাচিং ব্যবহার করুন। প্রতিটি একক বোঝাতে ব্যবহৃত অ্যাটমগুলো হলো: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. যেকোনো একক থেকে যেকোনো এককে রূপান্তর করুন

`KitchenCalculator.convert/2` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল ও কাঙ্ক্ষিত একক দেওয়া হলে, এটি প্রদত্ত ভলিউমটি কাঙ্ক্ষিত এককে রূপান্তর করবে।

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
