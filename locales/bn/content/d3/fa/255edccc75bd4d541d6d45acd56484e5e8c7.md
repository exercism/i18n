# ইনস্টলেশন

## Windows (প্রস্তাবিত)

আপনি কি Windows অপারেটিং সিস্টেম ব্যবহার করছেন?

`Windows Key` চাপুন, `cmd` টাইপ করুন এবং `enter` চাপুন।

> আপনার অপারেটিং সিস্টেম Windows হলে, Batch ইতিমধ্যেই আপনার সিস্টেমে ইনস্টল করা আছে।

আপনি যদি অন্য কোনো অপারেটিং সিস্টেম ব্যবহার করেন, তাহলে নিচের নির্দেশনাগুলো অনুসরণ করে Batch ইনস্টল করতে পারেন।

## Mac OS

1. Gatekeeper যেন সাইন করা না থাকা প্যাকেজ ব্লক না করে, সেভাবে সেট করা থাকতে হবে।
2. Terminal অ্যাপ্লিকেশনটি খুলুন।
3. Batch ইনস্টল করতে নিচের কমান্ডটি রান করুন:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. আপনার সিস্টেম যদি ৬৪ বিটের হয়, তাহলে ৩২ বিট আর্কিটেকচার চালু করুন (যদি আগে থেকে চালু করা না থাকে):

```bash
sudo dpkg --add-architecture i386
```

2. WineHQ রিপোজিটরি যোগ করুন:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. WineHQ ইনস্টল করুন:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Wine রিপোজিটরি চালু করুন:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. WineHQ ইনস্টল করুন:

```bash
dnf install winehq-stable
```
