# সম্পর্কে

Lua-তে বুলিয়ান টাইপে দুটি প্রচলিত বুলিয়ান মান আছে: `true` এবং `false`। এই মানগুলো একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়, লজিক্যাল অপারেটর (`and`, `or`, `not`) এর সাথে যুক্ত করা যায় এবং শর্তসাপেক্ষ পরীক্ষায় ব্যবহার করা যায় (যেমন কন্ট্রোল স্ট্রাকচারে)।

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

শর্তসাপেক্ষ পরীক্ষা এবং লজিক্যাল অপারেটরগুলো বুলিয়ান `false` এবং `nil` উভয়কেই ফলস হিসেবে বিবেচনা করে এবং অন্য সব কিছুকে ট্রু হিসেবে বিবেচনা করে।
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and` এবং `or` উভয়ই *শর্ট-সার্কিট ইভালুয়েশন* ব্যবহার করে, যার মানে তারা তাদের দ্বিতীয় অপারেন্ড শুধুমাত্র প্রয়োজন হলে ইভ্যালুয়েট করে। সব অপারেশন [অপারেটর প্রিসিডেন্স](https://www.lua.org/manual/5.4/manual.html#3.4.8) অনুসারে ইভ্যালুয়েট করা হয়, যেখানে `not` `and` এবং `or` এর আগে ইভ্যালুয়েট করা হয়।

যেহেতু শুধুমাত্র `false` এবং `nil` কে ফলস হিসেবে বিবেচনা করা হয় এবং অন্য সব কিছু ট্রু, তাই Lua-তে একটি কমন ইডিয়ম হলো:
```lua
x = x or y
```

এটি সমতুল্য:
```lua
if not x then
  x = y
end
```

ফাংশনে এটি ব্যবহার করা বেশ কমন, যখন একটি প্যারামিটারের কোনো মান না থাকে (`nil` হয়) তখন একটি ডিফল্ট মান অ্যাসাইন করার জন্য:
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
