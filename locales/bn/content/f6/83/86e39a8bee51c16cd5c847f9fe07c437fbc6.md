# পরিচিতি

## সংখ্যা

অনেক প্রোগ্রামিং ভাষায় বিভিন্ন ধরনের সংখ্যা প্রকাশ করার জন্য আলাদা আলাদা সংখ্যাসূচক টাইপ থাকে, কিন্তু JavaScript-এ আছে মাত্র দুটি:

- `number`: ডাবল-প্রিসিশন ৬৪-বিট ফ্লোটিং-পয়েন্ট ফরম্যাটে (IEEE 754) একটি সংখ্যাসূচক ডেটা টাইপ।
  উদাহরণ: `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` এবং `500000`.
- `bigint`: একটি সংখ্যাসূচক ডেটা টাইপ, যা আরবিট্রারি প্রিসিশন ফরম্যাটে _ইন্টিজার_ প্রকাশ করতে পারে।
  উদাহরণ: `-12n`, `0n`, `4n`, এবং `9007199254740991n`.

আপনার যদি আরবিট্রারি প্রিসিশন দরকার হয় বা খুব বড় সংখ্যা নিয়ে কাজ করতে হয়, তাহলে `bigint` টাইপ ব্যবহার করুন।
অন্যথায় `number` টাইপই সম্ভবত ভালো বিকল্প।

### রাউন্ডিং

`Math` নামে একটি বিল্ট-ইন গ্লোবাল অবজেক্ট আছে, যা বিভিন্ন [রাউন্ডিং ফাংশন][ref-math-object-rounding] দেয়।
যেমন, আপনি দশমিক সংখ্যাকে নিকটতম পূর্ণসংখ্যায় নিচের দিকে (`floor`) বা উপরের দিকে (`ceil`) রাউন্ড করতে পারেন।

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## গাণিতিক অপারেটর

সংখ্যার উপর মৌলিক গাণিতিক কাজ করার জন্য JavaScript ৬টি ভিন্ন অপারেটর দেয়।

- `+`: যোগ অপারেটর দিয়ে সংখ্যাগুলোর সমষ্টি বের করা হয়।
- `-`: বিয়োগ অপারেটর দিয়ে দুটি সংখ্যার পার্থক্য বের করা হয়
- `*`: গুণ অপারেটর দিয়ে দুটি সংখ্যার গুণফল বের করা হয়।
- `/`: ভাগ অপারেটর দিয়ে দুটি সংখ্যাকে ভাগ করা হয়।

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: ভাগশেষ অপারেটর দিয়ে একটি ভাগের ভাগশেষ বের করা হয়।

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: সূচক অপারেটর দিয়ে একটি সংখ্যাকে ঘাতে উন্নীত করা হয়।

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### অপারেশনের ক্রম

একই লাইনে একাধিক অপারেটর ব্যবহার করলে JavaScript [এই প্রিসিডেন্স টেবিলে][mdn-operator-precedence] দেখানো অনুযায়ী একটি প্রাধান্যের ক্রম মেনে চলে।
আমাদের প্রসঙ্গে সহজ করে বললে, JavaScript আমাদের প্রাথমিক গণিতের ক্লাসে শেখা PEDMAS নিয়মটি ব্যবহার করে, যার পুরো অর্থ: Parentheses, Exponents, Division/Multiplication, Addition/Subtraction (অর্থাৎ বন্ধনী, সূচক, ভাগ/গুণ, যোগ/বিয়োগ)।

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### শর্টহ্যান্ড অ্যাসাইনমেন্ট অপারেটর

শর্টহ্যান্ড অ্যাসাইনমেন্ট অপারেটর হলো একটি ভ্যারিয়েবলের উপর গাণিতিক অপারেশন চালিয়ে নতুন মানটি সেই একই ভ্যারিয়েবলে অ্যাসাইন করার কোড লেখার ছোট একটি উপায়।
যেমন, দুটি ভ্যারিয়েবল `x` ও `y` ধরা যাক।
তাহলে `x += y` আর `x = x + y` একই।
প্রায়ই এটি ভ্যারিয়েবল `y`-এর বদলে একটি সংখ্যার সাথে ব্যবহার করা হয়।
বাকি ৫টি অপারেশনও একই ধরনে করা যায়।

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
