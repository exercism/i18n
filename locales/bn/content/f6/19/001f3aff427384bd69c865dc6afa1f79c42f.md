# নির্দেশাবলি

স্কুলের নাটকে প্রতিটি ভূমিকার জন্য একজন আন্ডারস্টাডি থাকে: এমন একজন, যিনি প্রয়োজনে ঢুকে সেই ভূমিকার যা দরকার তা করে দিতে পারেন, অথচ মঞ্চ ব্যবস্থাপক জানেন না তিনি কে।

পাঁচটি কাজই `UNDERSTUDY` ক্লাসে থাকবে। প্রথম দুটি সাধারণ রুটিন, যেগুলো পরের কাজগুলোতে বাইন্ড করা হবে।

## 1. একটি লাইন বলার দুটি উপায়

`shout` লিখুন, যা লাইনটি বড় হাতের অক্ষরে রিটার্ন করে, আর `whisper` লিখুন, যা এটিকে ছোট হাতের অক্ষরে, দুই দিকে `"..."` সহ রিটার্ন করে।

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. একটি লাইন রিহার্স করা

`rehearse` একটি লাইন আর তা বলার একটি উপায় নেয়, এবং ফলাফলটি রিটার্ন করে। এর দ্বিতীয় আর্গুমেন্টের টাইপ `ROUT{STR}:STR`।

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. পুরো দৃশ্যটি

`run_scene` লাইনগুলোর একটি অ্যারে আর সেগুলো বলার একটি উপায় নেয়, এবং সেগুলো সব ওই উপায়ে বলা অবস্থায়, `" "` দিয়ে জোড়া দিয়ে রিটার্ন করে।

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

খালি দৃশ্য মানে খালি স্ট্রিং।

## 4. কথা বলার একটি উপায় ফিরিয়ে দেওয়া

`understudy_for` একটি স্টাইলের নাম নেয়, `"shout"` বা অন্য যা-ই হোক, আর একটি `ROUT{STR}:STR` রিটার্ন করে। `"shout"` দিলে চিৎকার করারটি পাওয়া যায়; অন্য কিছু দিলে ফিসফিস করারটি।

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. একটি আর্গুমেন্ট স্থির করা

`repeat` লিখুন, যা কতবার বলতে হবে সেই সংখ্যাটি আর একটি লাইন নেয়, এবং লাইনটি ততবার, মাঝখানে কিছু না দিয়ে, রিটার্ন করে:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

এরপর `doubler` লিখুন, যা কোনো আর্গুমেন্ট নেয় না এবং একটি `ROUT{STR}:STR` রিটার্ন করে, যা তাকে যা-ই দেওয়া হোক তা দুইবার পুনরাবৃত্তি করে, অর্থাৎ `repeat`-কে সংখ্যাটি আগেই বসিয়ে বাইন্ড করার মাধ্যমে।

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
