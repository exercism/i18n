# ভূমিকা

## ইন্টিজার সংখ্যা

C# ভাষা, অনেক স্ট্যাটিক টাইপড ভাষার মতো, এমন কিছু টাইপ সরবরাহ করে যেগুলো ইন্টিজার উপস্থাপন করে, আর প্রত্যেকটির নিজস্ব মানের পরিসর থাকে। সবচেয়ে ছোট প্রান্তে, `sbyte` টাইপের সর্বনিম্ন মান -128 এবং সর্বোচ্চ মান 127। সব ইন্টিজার টাইপের মতোই এই মানগুলো `<type>.MinValue` এবং `<type>.MaxValue` হিসেবে পাওয়া যায়। সবচেয়ে বড় প্রান্তে, `long` টাইপের সর্বনিম্ন মান -9,223,372,036,854,775,808 এবং সর্বোচ্চ মান 9,223,372,036,854,775,807। আর এদের মাঝখানে রয়েছে `short` এবং `int` টাইপ।

এই পরিসরগুলো নির্ধারিত হয় টাইপের স্টোরেজ প্রস্থ দিয়ে, যা সিস্টেম বরাদ্দ করে। উদাহরণস্বরূপ, একটি `byte` ৮ বিট ব্যবহার করে এবং একটি `long` ৬৪ বিট ব্যবহার করে।

উপরের প্রতিটি টাইপের সাথে একটি আনসাইনড সমতুল্য টাইপ জোড়া লাগানো আছে: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` এবং `long`/`ulong`। সব ক্ষেত্রেই মানের পরিসর 0 থেকে নেগেটিভ সাইনড সর্বোচ্চ মানের দুই গুণ যোগ এক পর্যন্ত।

| টাইপ   | প্রস্থ  | সর্বনিম্ন                   | সর্বোচ্চ                     |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 bit  | -128                       | +127                        |
| short  | 16 bit | -32_768                    | +32_767                     |
| int    | 32 bit | -2_147_483_648             | +2_147_483_647              |
| long   | 64 bit | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 bit  | 0                          | +255                        |
| ushort | 16 bit | 0                          | +65_535                     |
| uint   | 32 bit | 0                          | +4_294_967_295              |
| ulong  | 64 bit | 0                          | +18_446_744_073_709_551_615 |

একটি টাইপের একটি ভ্যারিয়েবল (বা এক্সপ্রেশন) সহজেই আরেকটি টাইপে রূপান্তর করা যায়। যেমন, একটি অ্যাসাইনমেন্ট অপারেশনে, যদি যে মানটি অ্যাসাইন করা হচ্ছে তার টাইপ (lhs) নিশ্চিত করে যে মানটি যে টাইপে অ্যাসাইন করা হচ্ছে (rhs) তার পরিসরের মধ্যে থাকবে, তাহলে সেটি একটি সরল অ্যাসাইনমেন্ট:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

অন্যদিকে, যদি যে টাইপ থেকে অ্যাসাইন করা হচ্ছে তার পরিসর গ্রহণকারী টাইপের মানের পরিসরের একটি উপসেট না হয়, তাহলে একটি কাস্ট, `()` অপারেশন প্রয়োজন, এমনকি নির্দিষ্ট মানটি গ্রহণকারী টাইপের পরিসরের মধ্যেই থাকলেও:

```csharp
short s = 42;
uint ui = (uint)s;
```

### বিট রূপান্তর

`BitConverter` ক্লাস ইন্টিজার টাইপকে বাইটের অ্যারেতে এবং অ্যারে থেকে বাইটে রূপান্তর করার একটি সুবিধাজনক উপায় দেয়।
