# ভূমিকা

Elm-এ টেক্সট রিপ্রেজেন্টেশনের ভিত্তি গড়ে তোলে ক্যারেক্টার আর স্ট্রিং।
স্ট্রিংকে ক্যারেক্টারের অ্যারে হিসেবে ভাবা যায়, আর `List`-এর বেশিরভাগ ফাংশনের সমতুল্য ফাংশন `String` মডিউলে আছে।

## ক্যারেক্টার

`Char` টাইপটি সিঙ্গেল কোটের ভেতরে একটি ইউনিকোড ক্যারেক্টার বোঝায়, যেমন `'a'`।
`Char` মডিউলে একটি ক্যারেক্টারের গুণাবলি পরীক্ষা করার জন্য প্রেডিকেট ফাংশন (`Char -> Bool`) আছে: `isUpper`, `isLower`, `isAlpha` আর `isAlphaNum`।
মডিউলটিতে আবার একটি ক্যারেক্টারকে `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower` দিয়ে রূপান্তর করার ফাংশনও আছে, পাশাপাশি `toCode` আর `fromCode` দিয়ে তার সংখ্যাগত ইউনিকোড মানের (`Int`) সাথে যাওয়া-আসার ফাংশন।

## স্ট্রিং

`String` টাইপটি দক্ষ স্ট্রিং ম্যানিপুলেশনের জন্য একটি বিল্ট-ইন রিপ্রেজেন্টেশন দেয় এবং ইউনিকোড ক্যারেক্টারের যেকোনো ক্রম প্রকাশ করতে পারে, যেমন "this is an Elm string."
মাল্টিলাইন স্ট্রিং ট্রিপল ডাবল কোট দিয়ে লেখা হয় এবং এতে আনএস্কেপড কোট আর নিউলাইন থাকতে পারে।
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## স্ট্রিং ফাংশন

`String` মডিউলে নিচের টেবিলে সংক্ষেপে দেওয়া সব ফাংশনই আছে।
এর মধ্যে সবচেয়ে বেশি ব্যবহৃত কিছু ফাংশন হলো:

`cons : Char -> String -> String` একটি স্ট্রিংয়ের শুরুতে একটি ক্যারেক্টার যোগ করে।
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` দুটি স্ট্রিং পাশাপাশি জুড়ে দেয়।
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` প্রদত্ত সেপারেটর দিয়ে একটি স্ট্রিংকে স্ট্রিংয়ের অ্যারেতে ভাগ করে।
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` প্রদত্ত একটি সেপারেটর দিয়ে স্ট্রিংয়ের একটি অ্যারে কনক্যাটেনেট করে।
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` একটি প্রদত্ত সাবস্ট্রিংয়ের সব উপস্থিতি প্রতিস্থাপন করে।
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` একটি স্ট্রিংয়ে কতগুলো ক্যারেক্টার আছে তা রিটার্ন করে।
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` একটি স্ট্রিংকে `Just Int`-এ রূপান্তর করার চেষ্টা করে, আর ভুল ফরম্যাটের স্ট্রিংয়ের জন্য `Nothing` রিটার্ন করে।
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` দ্বিতীয় স্ট্রিংটিতে প্রথমটি আছে কি না তা চেক করে।
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` স্ট্রিংয়ের প্রতিটি `Char`-এ একটি প্রদত্ত ফাংশন প্রয়োগ করে।
মনে রাখবেন, যে ফাংশনটি দেওয়া হয় তা অবশ্যই `Char` থেকে `Char`-এ একটি ম্যাপিং হতে হবে।
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
