# পরিচিতি

Swift তার স্ট্যান্ডার্ড লাইব্রেরিতে বিস্তৃত সুবিধা দেয়, আর বাইরের লাইব্রেরি ও ফ্রেমওয়ার্ক import করে আপনি আরও অনেক ফিচার ব্যবহার করতে পারেন।
এই মডিউলগুলো সরাসরি Swift প্রজেক্ট থেকে আসতে পারে (যেমন [Swift Argument Parser][argument-parser]), Apple প্ল্যাটফর্ম ফ্রেমওয়ার্ক থেকে (যেমন [Foundation][apple-foundation] ও [Network Framework][network-framework]), অথবা থার্ড-পার্টি ওপেন সোর্স লাইব্রেরি থেকে (যেমন [SwiftyBeaver][swifty-beaver])।

Foundation-এর মতো কোর মডিউলগুলো (Swift-এ সবচেয়ে বেশি ব্যবহৃত লাইব্রেরিগুলোর একটি) Swift টুলচেইনের সাথে অন্তর্ভুক্ত থাকে।
থার্ড-পার্টি লাইব্রেরি import করার আগে সেগুলোকে আপনার প্রজেক্ট কনফিগারেশনে যোগ করতে হবে (যেমন Swift Package Manager ব্যবহার করে)।

একটি মডিউল import করতে `import` কিওয়ার্ডটি লিখুন, তারপর মডিউলের নাম:

```swift
import Foundation
```

একটি মডিউল import করলে তার টাইপ, মেথড ও ফাংশন আপনার কোডে ব্যবহারের জন্য উপলব্ধ হয়ে যায়।
উদাহরণস্বরূপ, Foundation import করলে `String`-এর সাথে `components(separatedBy:)`-এর মতো দরকারি ইউটিলিটি মেথড যুক্ত হয়।

প্রচলিত রীতি অনুযায়ী, `import` স্টেটমেন্টগুলো Swift ফাইলের উপরে রাখা হয়, যাতে কোড পড়া যে কেউ ডিপেন্ডেন্সিগুলো সাথে সাথেই দেখতে পায়।
