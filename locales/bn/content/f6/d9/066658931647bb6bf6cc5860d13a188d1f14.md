# নির্দেশনা

এই অনুশীলনীতে আপনি একজন বড় ক্রীড়াপ্রেমী এবং NBA বাস্কেটবলের প্রতি সদ্য আকৃষ্ট হয়েছেন। NBA বাস্কেটবলে নতুন হওয়ায়, আপনি NBA-এর ইতিহাসে গভীরভাবে ডুব দিচ্ছেন, দল, কোচ, তাদের জয়/পরাজয়ের পরিসংখ্যান ট্র্যাক করছেন এবং তাদের একে অপরের সাথে তুলনা করছেন।

যেহেতু আপনার এখনও প্রিয় কোনো দল নেই, আপনি একটি অ্যালগরিদমও তৈরি করবেন যা নির্ধারণ করবে যে কোনো নির্দিষ্ট দলকে সমর্থন করবেন কিনা।

আপনার নিজস্ব _দল-সমর্থনের_ অ্যালগরিদম তৈরি করতে সাতটি কাজ রয়েছে।

## 1. মডেলটি ডিফাইন করুন

নিম্নলিখিত দুটি ফিল্ড সহ `Coach` রেকর্ড ডিফাইন করুন:

- `Name`: কোচের নাম, টাইপ `string`.
- `FormerPlayer`: কোচ পূর্বে খেলোয়াড় ছিলেন কিনা তা নির্দেশ করে, টাইপ `bool`.

নিম্নলিখিত দুটি ফিল্ড সহ `Stats` রেকর্ড ডিফাইন করুন:

- `Wins`: জয়ের সংখ্যা, টাইপ `int`.
- `Losses`: পরাজয়ের সংখ্যা, টাইপ `int`.

নিম্নলিখিত তিনটি ফিল্ড সহ `Team` রেকর্ড ডিফাইন করুন:

- `Name`: দলের নাম, টাইপ `string`.
- `Coach`: দলের কোচ, টাইপ `Coach`.
- `Stats`: দলের পরিসংখ্যান, টাইপ `Stats`.

## 2. দলের কোচ তৈরি করুন

`createCoach` ফাংশনটি ইমপ্লিমেন্ট করুন যা প্যারামিটার হিসেবে কোচের নাম এবং তার পূর্বে খেলোয়াড় থাকার স্ট্যাটাস নেয়, এবং তার `Coach` রেকর্ড রিটার্ন করে:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. দলের পরিসংখ্যান তৈরি করুন

`createStats` ফাংশনটি ইমপ্লিমেন্ট করুন যা প্যারামিটার হিসেবে জয়ের সংখ্যা এবং পরাজয়ের সংখ্যা নেয়, এবং তার `Stats` রেকর্ড রিটার্ন করে:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. একটি দল তৈরি করুন

`createTeam` ফাংশনটি ইমপ্লিমেন্ট করুন যা প্যারামিটার হিসেবে দলের নাম, কোচ এবং রেকর্ড নেয়, এবং তার `Team` রেকর্ড রিটার্ন করে:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. কোচ প্রতিস্থাপন করুন

NBA মালিকরা অধৈর্য হয়ে পড়ায়, আপনি দেখলেন যে খারাপ দলীয় ফলাফলের কারণে প্রায়শই কোচ পরিবর্তন করতে হয়। `replaceCoach` ফাংশনটি ইমপ্লিমেন্ট করুন যা প্যারামিটার হিসেবে দল এবং তার নতুন কোচ নেয়, এবং নতুন কোচসহ দলটি রিটার্ন করে:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. একই দল কিনা পরীক্ষা করুন

পরিসংখ্যান খতিয়ে দেখার সময়, আপনি দল এবং তাদের রেকর্ডের তালিকা রাখছেন। মাঝে মাঝে আপনি ভুল করেন এবং আপনার তালিকায় ডুপ্লিকেট এন্ট্রি থাকে। `isSameTeam` ফাংশনটি ইমপ্লিমেন্ট করুন যা দুটি দল নেয় এবং যদি তারা একই দল হয় তবে `true` রিটার্ন করে; অন্যথায় `false` রিটার্ন করে:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. আপনি কোন দলকে সমর্থন করবেন কিনা পরীক্ষা করুন

অনেক দল ও ম্যাচ দেখার পর, আপনি একটি অ্যালগরিদম বের করেছেন। নিম্নলিখিতগুলোর মধ্যে একটি সত্য হলে, আপনি সেই দলকে সমর্থন করবেন:

- কোচের নাম "Gregg Popovich"
- কোচ একজন সাবেক খেলোয়াড়
- দলের নাম "Chicago Bulls"
- দলটি ৬০ বা তার বেশি গেম জিতেছে
- দলের পরাজয়ের সংখ্যা জয়ের চেয়ে বেশি

`rootForTeam` ফাংশনটি ইমপ্লিমেন্ট করুন যা একটি দল নেয় এবং যদি আপনার সেই দলকে সমর্থন করা উচিত হয় তবে `true` রিটার্ন করে; অন্যথায় `return` false:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
