# পরিচিতি

লুয়ার বুলিয়ান টাইপে প্রচলিত দুটি বুলিয়ান মান থাকে: `true` এবং `false`। এই মানগুলো একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়, লজিক্যাল অপারেটরের (`and`, `or`, `not`) সাথে মিলিয়ে ব্যবহার করা যায় এবং শর্তসাপেক্ষ পরীক্ষায় (যেমন কন্ট্রোল স্ট্রাকচারে) ব্যবহার করা যায়।

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

শর্তসাপেক্ষ পরীক্ষা এবং লজিক্যাল অপারেটরগুলো বুলিয়ান `false` ও `nil` — দুটোকেই ফলস ধরে, আর বাকি সবকিছুকে ট্রু ধরে।
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and` এবং `or` — দুটোই *শর্ট-সার্কিট ইভ্যালুয়েশন* ব্যবহার করে, অর্থাৎ তারা তাদের দ্বিতীয় অপারেন্ড শুধু প্রয়োজন হলেই মূল্যায়ন করে। সব অপারেশন [অপারেটর প্রিসিডেন্স](https://www.lua.org/manual/5.4/manual.html#3.4.8) অনুযায়ী মূল্যায়ন করা হয়, যেখানে `and` ও `or`-এর আগে `not` মূল্যায়ন করা হয়।
