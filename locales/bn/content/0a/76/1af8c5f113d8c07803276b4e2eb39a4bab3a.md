# ফাংশন অ্যানোটেশনের ক্রম

প্রচলিত নিয়ম অনুযায়ী, `@doc` ফাংশন অ্যানোটেশন `@spec` ফাংশন অ্যানোটেশনের আগে থাকা উচিত, এবং `@spec` ফাংশন অ্যানোটেশন সরাসরি ফাংশনের আগে থাকা উচিত। ফাংশনের একাধিক ক্লজ থাকলে, ফাংশন অ্যানোটেশন প্রথম ক্লজের আগে থাকা উচিত।

উদাহরণ:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
