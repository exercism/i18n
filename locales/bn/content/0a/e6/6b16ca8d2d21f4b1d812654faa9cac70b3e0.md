# নির্দেশনা

আপনি একটি পিৎজার দোকান চালান, এবং তিন ধরনের পিৎজা বিক্রি করেন:

- Margherita: $7
- Caprese: $9
- Formaggio: $10

গ্রাহকরা চাইলে যত খুশি এক্সট্রা অপশন যোগ করতে পারেন: হয় "ExtraSauce" $1-এ, নয়তো "ExtraToppings" $2-এ।

আপনার কাজ হলো এমন কোড লেখা, যা গ্রাহককে তার খরচ হিসাব করতে সাহায্য করে।

## একটি পিৎজার দাম হিসাব করুন

প্রথম আর্গুমেন্ট হিসেবে পিৎজার নাম এবং যত খুশি যোগ করা অপশন দেওয়া হলে, পিৎজার দাম ডলারে হিসাব করুন।

```js
pizzaPrice('Margherita');
// => 7

pizzaPrice('Caprese', 'ExtraSauce', 'ExtraToppings');
// => 12

pizzaPrice(
  'Caprese',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
);
// => 17
```

## একটি অর্ডারের মোট দাম হিসাব করুন

আপনার ফাংশনটি `PizzaOrder`-এর একটি লিস্ট দিয়ে কল করা হয় এবং এটি অর্ডারটির মোট দাম ডলারে রিটার্ন করা উচিত।
প্রতিটি `PizzaOrder`-এ একটি `pizza` প্রপার্টি থাকে, যা পিৎজার নাম, এবং একটি `extras` প্রপার্টি, যা এক্সট্রা অপশনগুলোর লিস্ট।

```js
const margherita = new PizzaOrder('Margherita');
const caprese = new PizzaOrder('Caprese', 'ExtraToppings');
orderPrice([margherita, caprese]);
// => 18
```

আপনি দেখবেন যে রিকার্সন ব্যবহার করে এটি লেখা যাবে না, কারণ প্রচুর অর্ডার নিয়ে একটি টেস্ট `Maximum call stack size exceeded` এরর ছুড়ে দেবে।
চিন্তার কিছু নেই, এটি ইচ্ছাকৃত। একটি ইম্পারেটিভ লুপ ব্যবহার করে এই ফাংশনটি ইমপ্লিমেন্ট করার চেষ্টা করুন!
আপনার সামনে অনেক অপশন আছে, যেমন `reduce` বা একটি `for` লুপ, তবে এগুলোতেই সীমাবদ্ধ নয়।

JavaScript ইন্টারপ্রেটার যখন JavaScript কোড রান করে, তখন সে কোন কোন ফাংশনে ঢুকেছে (কল করা শুরু করেছে) তা "স্ট্যাক" নামের একটি ডেটা স্ট্রাকচারে হিসাব রাখে।
ফাংশনটি রিটার্ন করলে (শেষ হলে), সেটি স্ট্যাক থেকে সরে যায়।

তবে এই স্ট্যাকের আকার সীমিত।
সবচেয়ে কমন ভুল হলো এমন একটি রিকার্সিভ ফাংশন, যা কখনো শেষ হয় না।
প্রতিটি কল স্ট্যাকে রাখা হয়, কিন্তু সেটি রিটার্ন করার আগেই স্ট্যাকে আরেকটি কল রাখা হয়।

```javascript
function kaboom() {
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded
```

এই এররের স্ট্যাকট্রেসে একই লাইন বারবার দেখা যায়, যা যুক্তিসঙ্গত, কারণ ফাংশনটি নিজেই নিজেকে কল করে।
বেশিরভাগ ক্ষেত্রে এর কোনো বাস্তব ব্যবহারিক প্রয়োগ না থাকলেও, আপনি বের করতে পারেন যে স্ট্যাকটি কতটা লম্বা হতে পারে।

```javascript
let calls = 0;
function kaboom() {
  calls +=1 ;
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded

console.log(calls)
// => a number, generally higher than 10.000
```

সিঙ্ক্রোনাস রিকার্সিভ ফাংশনের কারণে হওয়া কল স্ট্যাক এররের মাত্র দুটি কার্যকর সমাধান আছে:
- ফাংশনগুলো স্ট্যাকের সীমায় পৌঁছানোর আগেই রিটার্ন করা নিশ্চিত করুন, সাধারণত একটি বেস কেস যোগ বা ঠিক করার মাধ্যমে।
- রিকার্সিভ ফাংশনটি একটি ইম্পারেটিভ লুপ হিসেবে নতুন করে লিখুন, যা ফাংশনে ঢুকতে না হয়েই লুপের বডি নির্বাহ করবে, ফলে স্ট্যাক বাড়বে না।
