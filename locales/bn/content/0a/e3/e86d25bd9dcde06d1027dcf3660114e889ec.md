# নির্দেশনা

এই অনুশীলনীতে আপনি একটি নতুন RPG গেমের কোয়েস্ট লজিক বাস্তবায়ন করবেন, যেটি আপনার এক বন্ধু তৈরি করছেন। গেমটির প্রধান চরিত্র অ্যানালিন, একজন সাহসী মেয়ে, যার আছে একটি হিংস্র কিন্তু বিশ্বস্ত পোষা কুকুর। দুর্ভাগ্যবশত বিপদ ঘটে যায়, কারণ বনে বেরি খুঁজতে গিয়ে তার সেরা বন্ধু অপহৃত হয়। অ্যানালিন তার সেরা বন্ধুকে খুঁজে বের করে মুক্ত করার চেষ্টা করবে, এবং চাইলে এই কোয়েস্টে তার কুকুরটিকেও সঙ্গে নিতে পারে।

তার সেরা বন্ধুর সূত্র ধরে কিছু সময় অনুসরণ করার পর, সে সেই ক্যাম্প খুঁজে পায় যেখানে তার বন্ধু বন্দী। দেখা যায় সেখানে দুই অপহরণকারী আছে: একজন শক্তিশালী নাইট আর একজন ধূর্ত আর্চার।

অপহরণকারীদের খুঁজে পাওয়ার পর, অ্যানালিন ভেবে দেখে নিচের কোন কোন অ্যাকশন সে নিতে পারে:

- দ্রুত আক্রমণ: নাইট ঘুমিয়ে থাকলে দ্রুত আক্রমণ করা যায়, কারণ বর্ম পরতে তার সময় লাগে, ফলে সে দুর্বল থাকে।
- গুপ্তচরবৃত্তি: তাদের মধ্যে অন্তত একজন জেগে থাকলে দলটির উপর গুপ্তচরবৃত্তি করা যায়। নাহলে গুপ্তচরবৃত্তি শুধু সময়ের অপচয়।
- বন্দীকে সংকেত: বন্দী জেগে থাকলে এবং আর্চার ঘুমিয়ে থাকলে পাখির ডাক দিয়ে বন্দীকে সংকেত পাঠানো যায়, কারণ আর্চারদের পাখির সংকেত দেওয়ার প্রশিক্ষণ থাকে, তাই তারা বার্তাটি আটকে দিতে পারে।
- _বন্দীকে মুক্ত করা_: বন্দীকে মুক্ত করতে অ্যানালিন চুপিসারে ক্যাম্পে ঢোকার চেষ্টা করতে পারে।
  এটি একটি ঝুঁকিপূর্ণ কাজ, আর এটি কেবল দুটি উপায়ের একটিতে সফল হতে পারে:
  - অ্যানালিনের সঙ্গে তার পোষা কুকুর থাকলে, আর্চার ঘুমিয়ে থাকলে সে বন্দীকে উদ্ধার করতে পারে।
    নাইট কুকুরটিকে ভয় পায়, আর অ্যানালিন ও বন্দী পালিয়ে যাওয়ার আগে আর্চারের তৈরি হওয়ার সময় থাকবে না।
  - অ্যানালিনের সঙ্গে কুকুর না থাকলে তাকে ও বন্দীকে খুব চুপিসারে কাজ করতে হবে!
    বন্দী জেগে থাকলে এবং নাইট ও আর্চার দুজনেই ঘুমিয়ে থাকলে অ্যানালিন বন্দীকে মুক্ত করতে পারে, কিন্তু বন্দী ঘুমিয়ে থাকলে তাকে উদ্ধার করা যাবে না: অ্যানালিনের হঠাৎ আবির্ভাবে বন্দী চমকে উঠবে এবং নাইট ও আর্চারকে জাগিয়ে ফেলবে।

আপনার চারটি কাজ: বনের মধ্যে পাওয়া তিনটি চরিত্রের অবস্থা এবং অ্যানালিনের পোষা কুকুর উপস্থিত আছে কি না, তার ভিত্তিতে উপরের অ্যাকশনগুলো নেওয়া সম্ভব কি না তা নির্ধারণের লজিক বাস্তবায়ন করা।

## 1. 'দ্রুত আক্রমণ' অ্যাকশনটি সম্ভব কি না যাচাই করুন

`canExecuteFastAttack` নামের একটি ফাংশন বাস্তবায়ন করুন, যা একটি বুলিয়ান মান নেয়, যেটি বোঝায় নাইট জেগে আছে কি না। চরিত্রটির অবস্থার ভিত্তিতে 'দ্রুত আক্রমণ' অ্যাকশনটি পাওয়া গেলে এই ফাংশনটি `true` রিটার্ন করে। নাহলে `false` রিটার্ন করে:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. 'গুপ্তচরবৃত্তি' অ্যাকশনটি সম্ভব কি না যাচাই করুন

`canSpy` নামের একটি ফাংশন বাস্তবায়ন করুন, যা তিনটি বুলিয়ান মান নেয়, যেগুলো বোঝায় যথাক্রমে নাইট, আর্চার ও বন্দী জেগে আছে কি না। চরিত্রগুলোর অবস্থার ভিত্তিতে 'গুপ্তচরবৃত্তি' অ্যাকশনটি পাওয়া গেলে ফাংশনটি `true` রিটার্ন করে। নাহলে `false` রিটার্ন করে:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. 'বন্দীকে সংকেত' অ্যাকশনটি সম্ভব কি না যাচাই করুন

`canSignalPrisoner` নামের একটি ফাংশন বাস্তবায়ন করুন, যা দুটি বুলিয়ান মান নেয়, যেগুলো বোঝায় যথাক্রমে আর্চার ও বন্দী জেগে আছে কি না। চরিত্রগুলোর অবস্থার ভিত্তিতে 'বন্দীকে সংকেত' অ্যাকশনটি পাওয়া গেলে ফাংশনটি `true` রিটার্ন করে। নাহলে `false` রিটার্ন করে:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. 'বন্দীকে মুক্ত করা' অ্যাকশনটি সম্ভব কি না যাচাই করুন

`canFreePrisoner` নামের একটি ফাংশন বাস্তবায়ন করুন, যা চারটি বুলিয়ান মান নেয়। প্রথম তিনটি প্যারামিটার বোঝায় যথাক্রমে নাইট, আর্চার ও বন্দী জেগে আছে কি না। শেষ প্যারামিটারটি বোঝায় অ্যানালিনের পোষা কুকুরটি উপস্থিত আছে কি না। চরিত্রগুলোর অবস্থা এবং অ্যানালিনের পোষা কুকুরের উপস্থিতির ভিত্তিতে 'বন্দীকে মুক্ত করা' অ্যাকশনটি পাওয়া গেলে ফাংশনটি `true` রিটার্ন করে। নাহলে এটি `false` রিটার্ন করে:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
