# main মেথড ব্যবহার করবেন না

আপনার কোড থেকে `main` মেথডটি সরিয়ে ফেলার চেষ্টা করে দেখুন।
অনুশীলনীর টেস্টে কোডে `main` মেথড থাকার প্রয়োজন নেই, আর এটি থাকলে কোডটি পড়তে একটু কঠিন হয়ে যায়।

সাধারণত কোড ডিবাগ করতে সাহায্য করার জন্য `main` মেথড যোগ করা হয়।
তবে এর চেয়ে ভালো উপায় হলো, এক বা একাধিক ইউনিট টেস্ট চালানোর সময় কোড ডিবাগ করা।
এর বাড়তি সুবিধা হলো, এতে একটি নির্দিষ্ট টেস্ট কেস ডিবাগ করার দিকে মনোযোগ দেওয়া যায়।

বিভিন্ন IDE-তে ইউনিট টেস্ট চালানোর সময় Java কোড কীভাবে ডিবাগ করতে হয়, তা ব্যাখ্যা করা কয়েকটি লিংক নিচে দেওয়া হলো:

- [Visual Studio Code-এ Java টেস্ট চালানো ও ডিবাগ করা](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [IntelliJ IDEA-তে টেস্ট ডিবাগ করা](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
