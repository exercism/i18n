# পরিচিতি

Clojure-এ একটি `vector` হলো শূন্য বা তার বেশি মানের একটি সিকোয়েন্সিয়াল, ইনডেক্সড, ইমিউটেবল কালেকশন। এর মানে হলো, একটি ভেক্টর একবার তৈরি হয়ে গেলে আর সেটি পরিবর্তন করা যায় না। ভেক্টরের উপর কাজ করার ফাংশনগুলো একটি নতুন ভেক্টর রিটার্ন করে, আর মূল ভেক্টর অপরিবর্তিত থাকে। একটি ভেক্টরের মানগুলো ভিন্ন ভিন্ন টাইপের হতে পারে। ভেক্টর ডিফাইন করা যায় এভাবে:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

ইনডেক্স ব্যবহার করে একটি ভেক্টর থেকে এলিমেন্ট পাওয়া যায়। Clojure ভেক্টর জিরো-বেজড, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

মূল ভেক্টর অপরিবর্তিত থাকে:

```clojure
numbers
;;=> [2 3 5]
```

আপডেট করা মানটি মনে রাখতে হলে সেটি পাস করে নিয়ে যেতে হবে, অথবা একটি var-এ ধরে রাখতে হবে:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
