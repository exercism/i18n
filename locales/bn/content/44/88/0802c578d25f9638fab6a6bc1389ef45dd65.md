# নির্দেশনা

RNA সিকোয়েন্সকে প্রোটিনে রূপান্তর করুন।

RNA-কে তিনটি নিউক্লিওটাইডের সিকোয়েন্সে ভেঙে ফেলা যায়, যাদেরকে কোডন বলা হয়, তারপর সেগুলোকে নিচের মতো একটি প্রোটিনে রূপান্তর করা যায়:

RNA: `"AUGUUUUCU"` => রূপান্তরিত হয়

কোডন: `"AUG", "UUU", "UCU"`
=> যেগুলো মিলে নিচের সিকোয়েন্সের একটি প্রোটিন তৈরি করে =>

প্রোটিন: `"Methionine", "Phenylalanine", "Serine"`

এখানে ৬৪টি কোডন আছে, যেগুলো আবার ২০টি অ্যামিনো অ্যাসিডের সাথে মিলে যায়; তবে এই অনুশীলনীতে সব কোডন সিকোয়েন্স আর তাদের থেকে তৈরি হওয়া অ্যামিনো অ্যাসিড জানা জরুরি নয়।
একটি কোডনের জন্য কাজ করলে প্রোগ্রামটির সবগুলোর জন্যই কাজ করা উচিত।
তবে নির্দ্বিধায় টেস্ট স্যুটের তালিকাটি বাড়িয়ে সবগুলোকে যোগ করে নিতে পারেন।

এছাড়া তিনটি টার্মিনেটিং কোডনও আছে (যাদের 'STOP' কোডনও বলা হয়); এই কোডনগুলোর যেকোনো একটি এলে (রাইবোজোমের মাধ্যমে), পুরো রূপান্তর শেষ হয়ে যায় আর প্রোটিনটিও সমাপ্ত হয়।

এরপরের সব কোডন উপেক্ষা করা হয়, যেমনটি এখানে:

RNA: `"AUGUUUUCUUAAAUG"` =>

কোডন: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

প্রোটিন: `"Methionine", "Phenylalanine", "Serine"`

খেয়াল করুন, `"UAA"` স্টপ কোডনটি রূপান্তর শেষ করে দেয় এবং শেষের methionine-টি প্রোটিন সিকোয়েন্সে রূপান্তরিত হয় না।

নিচে এই অনুশীলনীর জন্য প্রয়োজনীয় কোডন আর তাদের থেকে তৈরি হওয়া অ্যামিনো অ্যাসিডগুলো দেওয়া হলো।

| কোডন              | অ্যামিনো অ্যাসিড |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
