# নির্দেশাবলি

এই অনুশীলনীতে আপনি নিউ ইয়র্কের একটি বিউটি সেলুনের জন্য অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন, যেটি ২০১২ সালের ১৫ সেপ্টেম্বর চালু হয়েছিল।

আপনার সামনে পাঁচটি কাজ আছে, যার সবকটিতেই অ্যাপয়েন্টমেন্টের তারিখ নিয়ে কাজ করতে হবে।
সময় ২৪-ঘণ্টার ফরম্যাটে দেওয়া আছে (AM/PM নেই)।
টাইমজোন সংক্রান্ত জটিলতা যতটা সম্ভব কম রাখতে ধরে নিন যে সবকিছু UTC ব্যবহার করে।

## 1. সব সংখ্যায় লেখা অ্যাপয়েন্টমেন্টের তারিখ পার্স করুন

টেক্সটে লেখা একটি অ্যাপয়েন্টমেন্টের তারিখকে সংশ্লিষ্ট `DateTime` ফরম্যাটে পার্স করার জন্য `schedule_appointment()` ফাংশনটি ইমপ্লিমেন্ট করুন।

মনে রাখবেন, ইনপুটটি মার্কিন ধাঁচের মাস/দিন/বছর ক্রমে দেওয়া।

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. একটি অ্যাপয়েন্টমেন্ট ইতিমধ্যে পেরিয়ে গেছে কি না দেখুন

`has_passed()` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি অতীতে পড়ে কি না তা দেখে:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. অ্যাপয়েন্টমেন্টটি বিকেলে কি না দেখুন

`is_afternoon_appointment()` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি বিকেলে (>= 12:00 এবং < 18:00) কি না তা দেখে:

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. একটি অ্যাপয়েন্টমেন্টের জন্য সপ্তাহের দিন দেখুন

`day_of_week()` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি সপ্তাহের _সংখ্যাগত_ দিন রিটার্ন করে।
সেলুনটি রবিবার বন্ধ থাকে, তাই সোমবার হলো দিন ১ এবং শনিবার হলো দিন ৬।

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. একটি অ্যাপয়েন্টমেন্টের নতুন সময় নির্ধারণ করুন

কোনো গ্রাহককে একটি অ্যাপয়েন্টমেন্টের নতুন সময় নির্ধারণ করতে হলে, এটি স্বয়ংক্রিয়ভাবে পরের শুক্রবারে একই সময়ে করে দেওয়া হয় (কারণ এই দিনে সপ্তাহের সবচেয়ে কম ভিড় থাকে)।

`reschedule()` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি মূল অ্যাপয়েন্টমেন্টটি (মাস/দিন/বছর ক্রমে লেখা একটি টেক্সট স্ট্রিং হিসেবে) নেয় এবং নতুন সময় নির্ধারিত একটি অ্যাপয়েন্টমেন্ট রিটার্ন করে।

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

যদি মূল অ্যাপয়েন্টমেন্টটি সোমবার থেকে বৃহস্পতিবারের মধ্যে হয়ে থাকে, তবে নতুন সময় নির্ধারণ করুন _এই_ সপ্তাহের শুক্রবারে।
শুক্রবার বা শনিবারের অ্যাপয়েন্টমেন্টের ক্ষেত্রে নতুন সময় নির্ধারণ করুন _পরের_ সপ্তাহের শুক্রবারে।
