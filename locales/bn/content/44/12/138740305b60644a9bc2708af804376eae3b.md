# পরিচিতি

`new` অপারেটরের মাধ্যমে [_কনস্ট্রাক্টর_][constructor] কল করে একটি ক্লাসের ইন্সট্যান্স তৈরি করা হয়। কনস্ট্রাক্টর হলো একটি ক্লাসের ভেতরে থাকা একটি বিশেষ মেথড, যার কাজ ক্লাসটি ইনিশিয়ালাইজ করা। Haxe-এ কনস্ট্রাক্টর মেথডের নাম হলো `new()`।

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

সাধারণ মেথডের মতোই কনস্ট্রাক্টরেও প্যারামিটার থাকতে পারে। এই প্যারামিটারগুলো (সাধারণত) প্রাইভেট ফিল্ডে রাখা হয় এবং পরে ব্যবহার করা হয়।

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

কোনো ক্লাসে কনস্ট্রাক্টর না থাকলে আপনি সেই ক্লাসের নতুন ইন্সট্যান্স তৈরি করতে **পারবেন না**। তাই একমাত্র উপায় হলো একটি খালি কনস্ট্রাক্টর ব্যবহার করা।

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
