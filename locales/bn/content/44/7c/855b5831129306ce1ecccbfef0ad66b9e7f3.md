# সম্পর্কে

Clojure-এ একটি `string` হলো একটি Java স্ট্রিং। এটি একটি অবজেক্ট যা অপরিবর্তনীয় টেক্সটকে Unicode ক্যারেক্টারের একটি ক্রম (অক্ষর, অঙ্ক, যতিচিহ্ন ইত্যাদি) হিসেবে উপস্থাপন করে। এটি নিম্নরূপে ডিফাইন করা হয়:

```clojure
(def fruit "Apple")
```

`clojure.string` লাইব্রেরি অনেক স্ট্যান্ডার্ড স্ট্রিং ম্যানিপুলেশন ও প্রসেসিং ফাংশন প্রদান করে। এছাড়াও, স্ট্রিং নিয়ে কাজ করার জন্য Java-এর সব প্রচলিত মেথড ইন্টারঅপের মাধ্যমে পাওয়া যায়।
