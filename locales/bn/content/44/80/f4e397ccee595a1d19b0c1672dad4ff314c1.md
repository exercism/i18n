# ইনস্টলেশন

আপনার সিস্টেমে সবকিছু সেটআপ করার নির্দেশনাগুলোর জন্য [System/Installation][install-link] দেখুন।

~~~exercism/caution
যদি আপনার সিস্টেমে Java Development Kit (JDK) ইনস্টল করা থাকে, তাহলে `jconsole` এক্সিকিউটেবলটি Java Console-এর সাথে সংঘাতে পড়তে পারে, কারণ দুটিই একই নাম ব্যবহার করে।

সম্ভাব্য কিছু সমাধান:

- J প্রোগ্রামিং ভাষার `jconsole` এক্সিকিউটেবলটির নাম বদলে একটি অনন্য নাম দিন (যেমন `jconsole-jlang`)।

- J প্রোগ্রামিং ভাষার `jconsole`-কে অগ্রাধিকার দিতে আপনার সিস্টেমের এনভায়রনমেন্ট ভেরিয়েবল বা PATH সামঞ্জস্য করুন।

- **Linux ব্যবহারকারীদের জন্য**, `bin/install.sh`-এ একটি bash স্ক্রিপ্ট রয়েছে, যা `/usr/` ডিরেক্টরিতে `ijconsole` নামে একটি **সিমবলিক লিংক** তৈরি করবে। টার্মিনালে `ijconsole` টাইপ করে আপনি এই লিংকটি ব্যবহার করতে পারেন।
~~~

J ইনস্টল হয়ে গেলে আপনার টার্মিনালে একটি J কনসোল খুলুন এবং ইউনিট টেস্ট ফ্রেমওয়ার্ক ইনস্টল করতে নিচের কমান্ডগুলো লিখুন:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
