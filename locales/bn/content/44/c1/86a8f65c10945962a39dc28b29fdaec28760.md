# পরিচিতি

Go-তে বুলিয়ান প্রকাশ করা হয় পূর্বঘোষিত বুলিয়ান টাইপ `bool` দিয়ে, যার মান `true` বা `false` হতে পারে।
এটি একটি ডিফাইনড টাইপ।

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go তিনটি লজিক্যাল অপারেটর সমর্থন করে, যেগুলো এক্সপ্রেশনকে বুলিয়ান মান পর্যন্ত মূল্যায়ন করতে পারে এবং `true` বা `false` রিটার্ন করে।

| অপারেটর   | এর অর্থ                                        |
| ----------- | --------------------------------------------- |
| `&&` (এবং)  | দুটি বিবৃতিই সত্য হলে এটি সত্য হয়।              |
| `\|\|` (অথবা) | অন্তত একটি বিবৃতি সত্য হলে এটি সত্য হয়।      |
| `!` (নয়)   | বিবৃতিটি মিথ্যা হলেই এটি সত্য হয়।              |
