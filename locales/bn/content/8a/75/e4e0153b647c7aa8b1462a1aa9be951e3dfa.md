# পরিচিতি

ফ্যাক্টরের সব কন্ডিশনালই শাখা হিসেবে **কোটেশন** নেয়: তৃতীয় বন্ধনীর (`[ ... ]`) ভেতরে লেখা কোড, যা কন্ডিশনাল সেটি বেছে নেওয়ার আগে রান করা হয় না, বরং একটি মান হিসেবে পুশ করা হয়। (কোটেশন নিয়ে বিস্তারিত আলোচনা আছে পরের একটি অনুশীলনীতে।)

মূল তিনটি আছে `kernel`-এ:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

দুটি তারা-চিহ্নিত (`*`) ভ্যারিয়েন্ট বুলিয়ানটিকে কাজে লাগানোর মতো একটি মান হিসেবে ধরে, যখন সেটি ট্রুথি হয়। এটাই প্রচলিত "মান নাকি `f`" জোড়া:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

দুটির বেশি শাখা থাকলে `combinators`-এর `cond` `{ predicate body }` জোড়ার একটি অ্যারে ধরে একে একে পরীক্ষা করে এবং প্রথম যে প্রিডিকেটটি সত্য হয়, তার বডিটি রান করে। প্রচলিত প্যাটার্নে প্রতিটি প্রিডিকেটে `dup` ব্যবহার করা হয়, যাতে ইনপুটটি টিকে থাকে; আর বডি শুরু হয় একটি `drop` দিয়ে, যাতে ফলাফল পুশ করার আগে সেটি ফেলে দেওয়া যায়:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

শেষে প্রিডিকেট ছাড়া যে এন্ট্রিটি থাকে, সেটিই ডিফল্ট শাখা।
