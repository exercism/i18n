# সম্পর্কে

লজিক বারবার চালানোর জন্য লুপ ব্যবহার করা যায়। যদি লুপের ভেতরের code সবসময় অন্তত একবার চালানো দরকার হয়, তাহলে একটি `do`/`while` লুপ ব্যবহার করা যায়:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

এটি `while` লুপের চেয়ে কম ব্যবহার করা হয়, তবে কিছু ক্ষেত্রে আরও স্বাভাবিক দেখতে code তৈরি করে।
