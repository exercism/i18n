# জাভাস্ক্রিপ্টে রিকার্সন বোঝা

রিকার্সন প্রোগ্রামিংয়ের একটি শক্তিশালী ধারণা, যেখানে একটি ফাংশন নিজেকেই কল করে।
শুরুতে এটি বুঝতে একটু কঠিন লাগতে পারে, কিন্তু মূল বিষয়গুলো একবার বুঝে গেলে জটিল সমস্যা সমাধানে এটি একটি দরকারি হাতিয়ার হয়ে ওঠে।
এই টিউটোরিয়ালে আমরা সহজে বোঝা যায় এমন উদাহরণের মাধ্যমে জাভাস্ক্রিপ্টে রিকার্সন দেখব।

## রিকার্সন কী?

কোনো ফাংশন যখন সরাসরি বা পরোক্ষভাবে নিজেকেই কল করে, তখন তাকে রিকার্সন বলে।
এটি লুপের মতোই, তবে এতে একটি সমস্যাকে ছোট ছোট, সহজে সামলানো যায় এমন উপ-সমস্যায় ভাগ করা হয়।

### উদাহরণ ১: কাউন্টডাউন

চলুন একটি সহজ উদাহরণ দিয়ে শুরু করি: একটি কাউন্টডাউন ফাংশন।

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

এই উদাহরণে:

- **বেস কেস**: `num` যখন 0 বা তার কম হয়ে যায়, তখন ফাংশনটি "Blastoff!" প্রিন্ট করে এবং নিজেকে কল করা বন্ধ করে দেয়।
- **রিকার্সিভ কেস**: ফাংশনটি বর্তমান `num` প্রিন্ট করে এবং `num - 1` দিয়ে নিজেকে কল করে।

### উদাহরণ ২: ফ্যাক্টোরিয়াল

এবার চলুন রিকার্সনের একটি ক্লাসিক উদাহরণ দেখি: একটি সংখ্যার ফ্যাক্টোরিয়াল নির্ণয়।

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

এই উদাহরণে:

- **বেস কেস**: `n` যখন 0 বা 1, ফাংশনটি 1 রিটার্ন করে।
- **রিকার্সিভ কেস**: ফাংশনটি `n`-কে `n - 1`-এর ফ্যাক্টোরিয়াল দিয়ে গুণ করে।

## মূল ধারণাগুলো

### বেস কেস

প্রতিটি রিকার্সিভ ফাংশনে অন্তত একটি বেস কেস থাকতে হবে, অর্থাৎ এমন একটি শর্ত যেখানে ফাংশনটি নিজেকে কল করা বন্ধ করে।
বেস কেস না থাকলে রিকার্সনটি অনির্দিষ্টকাল ধরে চলতেই থাকবে, যার ফলে স্ট্যাক ওভারফ্লো হতে পারে।

### রিকার্সিভ কেস

রিকার্সিভ কেস ঠিক করে দেয় কীভাবে ফাংশনটি সমস্যার আরও ছোট বা সরল একটি সংস্করণ দিয়ে নিজেকে কল করবে।

## রিকার্সনের সুবিধা ও অসুবিধা

**সুবিধা:**

- নির্দিষ্ট কিছু সমস্যার জন্য সুন্দর সমাধান।
- গাণিতিক আরোহ পদ্ধতির ধারণার মতো কাজ করে।

**অসুবিধা:**

- ইটারেটিভ সমাধানের চেয়ে কম দক্ষ হতে পারে।
- গভীর রিকার্সনে স্ট্যাক ওভারফ্লো হতে পারে।

## উপসংহার

রিকার্সন একটি মূল্যবান কৌশল, যা জটিল সমস্যাকে ছোট ছোট, সহজে সামলানো যায় এমন উপ-সমস্যায় ভেঙে দিয়ে সহজ করে তুলতে পারে।
জাভাস্ক্রিপ্টে কার্যকর রিকার্সিভ সমাধান করতে বেস কেস আর রিকার্সিভ কেস বোঝা খুবই জরুরি।
