# ফাংশন লেভেল গার্ড ব্যবহার করুন

[comment]: # (সলিউশনে গার্ড ব্যবহার করা হলে এই এররটি আসে, কিন্তু ফাংশন ক্লজে নয়)

ফাংশন ক্লজে [গার্ড](https://hexdocs.pm/elixir/master/guards.html) ব্যবহার করুন, যাতে `two_fer/1` নন-বাইনারি ইনপুট নিয়ে কোড চালাতে না পারে।

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

কোনো ফাংশন যদি এমন আর্গুমেন্ট নিয়ে কল করা হয় যা দেওয়া কোনো ক্লজের সঙ্গে মেলে না, তাহলে `FunctionClauseError` রেইজ হয়।

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
