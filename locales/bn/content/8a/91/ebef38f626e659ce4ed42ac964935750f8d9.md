# পরিচিতি

এই অনুশীলনীটি [লিয়ার সুস্বাদু লাসাগনা][lasagna] থেকে শেখা ইন্টিজার পাটিগণিতের ওপর তৈরি। এখানে আপনি ফ্লোট সংখ্যা নিয়ে কাজ করবেন আর কাজ অনুযায়ী সঠিক ভাগের ওয়ার্ড বেছে নেবেন।

## ইন্টিজার আর ফ্লোট

Factor ইন্টিজার (`1`, `42`, `1_000_000`) আর ফ্লোট সংখ্যার (`1.0`, `3.14`, `6.02e23`) মধ্যে পার্থক্য করে। একই হিসাবে ইন্টিজার আর ফ্লোট মেশালে ফলাফল ফ্লোট হিসেবে আসে:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

সংখ্যার ভেতরে আন্ডারস্কোর দিয়ে অঙ্কগুলো গুছিয়ে রাখতে পারেন, যেমন `1_000_000`, আর Factor সেগুলো একেবারে উপেক্ষা করে।

## ভাগের ওয়ার্ডগুলো

Factor-এ ভাগ করার জন্য আলাদা আলাদা ওয়ার্ড আছে। এগুলো সবই [`math`][math] ভোকাবুলারিতে থাকে।

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` দুটি ইন্টিজারের জন্য একটি `ratio` (Factor-এর সঠিক মূলদ টাইপ) তৈরি করে, আর ইনপুটের যেকোনো একটি ফ্লোট হলে একটি `float`। `/f` দুটি ইন্টিজার হলেও ফ্লোট ফলাফল দিতে বাধ্য করে। `/i` সবসময় শূন্যের দিকে ছেঁটে ফেলে।

## যাচাই

[`math`][math], [`math.functions`][math.functions] আর [`math.primes`][math.primes] থেকে সংখ্যার প্রেডিকেট:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## ফ্লোট থেকে ইন্টিজার

[`math.functions`][math.functions] ভোকাবুলারির `floor`, `ceiling` আর `round` সবাই একটি ফ্লোট রিটার্ন করে (`3.0`, `3` নয়)। সত্যিকারের ইন্টিজার পেতে হলে `>integer` চেইন করুন:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## ঘাত আর পরম মান

[`math.functions`][math.functions]-এর `sq`, `^` আর `abs` বর্গ, যেকোনো ঘাত আর পরম মান হিসাব করে:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## সর্বনিম্ন আর সর্বোচ্চ

[`math.order`][math.order]-এর `min ( x y -- z )` আর `max ( x y -- z )` দুটি সংখ্যার ছোটটি বা বড়টি রিটার্ন করে:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

সবচেয়ে বেশি ব্যবহার হয় *ক্ল্যাম্পিং*, অর্থাৎ `max` দিয়ে একটি মানকে নিচের সীমায় আটকে রাখা (যেমন `0 max` একটি মানকে ঋণাত্মক হতে দেয় না) বা `min` দিয়ে উপরের সীমায়।

## ক্রমের প্রেডিকেট

`math.order` আবার তুলনার প্রেডিকেট হিসেবে `before?`, `after?`, `before=?`, `after=?` দেয়, যেগুলো যেকোনো ক্রমযোগ্য টাইপে কাজ করে: সংখ্যা, স্ট্রিং, ক্যারেক্টার।

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

মানগুলো যখন স্ট্রিং হতে পারে, তখন `<`/`<=`-এর বদলে এগুলো ব্যবহার করুন। পাটিগণিত অপারেটরগুলো স্ট্রিংয়ে ডিসপ্যাচ করে না।
