# টেস্ট

প্রতিটি অনুশীলনীতে একটি টেস্ট ফাইল থাকে।
`bats` প্রোগ্রাম দিয়ে টেস্টগুলো রান করুন।

```bash
bats hello_world.bats
```

লোকালি টেস্ট রান করার সময় ডিবাগ আউটপুট প্রিন্ট করতে চাইলে দেখুন [লোকালি ডিবাগিং][debugging]।

`bats` ইনস্টল করা থাকতে হবে।
আপনার সিস্টেমে `bats` ইনস্টল করার নির্দেশনার জন্য [Bash ট্র্যাকের টেস্টিং][tests] পৃষ্ঠাটি দেখুন।

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## assert ফাংশনগুলোর জন্য সহায়তা

টেস্টগুলো [bats-assert][bats-assert] লাইব্রেরির ফাংশন ব্যবহার করে।
বিভিন্ন `assert*` ফাংশনের সহায়তা সেখানেই পাবেন।

[bats-assert]: https://github.com/bats-core/bats-assert

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
ডিফল্টভাবে, আপনি টেস্ট রান করলে কেবল একটি টেস্ট (প্রথমটি) রান হয়।
এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।
এটি পাস হয়ে গেলে, পরের অ্যানোটেশনটি কমেন্ট আউট করে বা মুছে দিয়ে আপনি পরের টেস্টটি চালু করতে পারেন:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## স্কিপ ওভাররাইড করা

`skip` অ্যানোটেশনযুক্তগুলোসহ সব টেস্ট রান করতে, আপনি রান করতে পারেন:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

টাইপিং কমাতে একটি র‍্যাপার ফাংশন ব্যবহার করা সুবিধাজনক হতে পারে:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

এরপর কেবল এভাবে টেস্ট রান করুন:

```bash
bats
```
