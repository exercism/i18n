# পরিচিতি

## এক্সেপশন

এলিক্সিরে সব এরর _Exception Behaviour_ ইমপ্লিমেন্ট করে। _Access Behaviour_-এর মতোই, _Exception Behaviour_ এমন কিছু কলব্যাক ফাংশন নির্ধারণ করে যা একটি মডিউলকে অবশ্যই ইমপ্লিমেন্ট করতে হয়, বিহ্যাভিয়ারের সফটওয়্যার চুক্তিটি পূরণ করার জন্য। একবার একটি এরর ডিফাইন করা হলে তার নিচের বৈশিষ্ট্যগুলো থাকে:

- মডিউলের নামটিই এররের নাম নির্ধারণ করে।
- মডিউলটি একটি এরর-স্ট্রাক্ট ডিফাইন করে।
- স্ট্রাক্টটিতে একটি `:message` ফিল্ড থাকবে।
- কাঙ্ক্ষিত এররটি রেইজ করতে মডিউলটি `raise/1` এবং `raise/2` দিয়ে ব্যবহার করা যায়।

_Exception Behaviour_ আরও দুটি কলব্যাক নির্দিষ্ট করে: `message/1` এবং `exception/1`। এগুলো ইমপ্লিমেন্ট করা না হলে ডিফল্ট ইমপ্লিমেন্টেশন ব্যবহার করা হবে। `raise` দিয়ে কল করা হলে `message/1` এরর-স্ট্রাক্টটিকে একটি পাঠযোগ্য মেসেজে রূপান্তর করে। `raise/2` দিয়ে কল করা হলে `exception/1` মেসেজে অতিরিক্ত কনটেক্সট যোগ করার সুযোগ দেয়

### একটি এক্সেপশন ডিফাইন করা

একটি এরর মডিউল থেকে এক্সেপশন ডিফাইন করতে আমরা `defexception` ম্যাক্রো ব্যবহার করি:

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

### এক্সেপশন ব্যবহার করা

ডিফাইন করা এররগুলো বিল্ট-ইন এররের মতোই `raise/1` বা `raise/2` দিয়ে ব্যবহার করা যায়।

- `raise/1` মডিউলের নাম দিয়ে নির্দিষ্ট একটি এরর রেইজ করে; আর যদি আর্গুমেন্টটি একটি স্ট্রিং হয়, তাহলে সেই স্ট্রিংটিকে মেসেজ হিসেবে নিয়ে একটি `RuntimeError` রেইজ করবে।
- `raise/2` মডিউলের নাম দিয়ে নির্দিষ্ট একটি এরর রেইজ করে এবং একটি অ্যাট্রিবিউটস আর্গুমেন্ট নেয়, যা দিয়ে উপযুক্ত মেসেজসহ এররটি পাওয়া যায়।
