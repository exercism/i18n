# ভূমিকা

`Rational numbers` হলো এমন ভগ্নাংশ, যার লব একটি ইন্টিজার আর হরও একটি ইন্টিজার।

উদাহরণস্বরূপ, আনুমানিক `Float64` মান `0.6666...`-এর বদলে আমরা `2//3`-কে একটি সঠিক ভগ্নাংশ হিসেবে সংরক্ষণ করতে পারি।

এর সুবিধা হলো, (*ইন্টিজার ওভারফ্লো*-র চরম পরিস্থিতি ছাড়া) একটি র‍্যাশনাল সংখ্যা নির্ভুল থাকে, ফলে ফ্লোটিং-পয়েন্ট সংখ্যায় যে রাউন্ডিং এরর প্রায়শই অনিবার্য হয়ে দাঁড়ায়, তা এড়ানো যায়।

র‍্যাশনাল সংখ্যা একটি বেশ সরল সংখ্যার টাইপ, আর আপনি যেমনটা আশা করবেন ঠিক তেমনভাবেই কাজ করার লক্ষ্য নিয়ে এগুলো তৈরি।

Julia-র প্রথম দিকের সংস্করণগুলো থেকেই এগুলো একটি স্ট্যান্ডার্ড টাইপ, তাই বেশিরভাগ ফাংশনই ইন্টিজার আর ফ্লোটের মতোই এগুলোকে ইনপুট হিসেবে গ্রহণ করে।

## র‍্যাশনাল সংখ্যা তৈরি করা

তৈরি করা ততটাই সহজ: দুটি ইন্টিজারের মাঝে শুধু `//` ব্যবহার করলেই হয়।

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

কমন গুণনীয়কগুলো স্বয়ংক্রিয়ভাবে বাদ পড়ে, আর ভগ্নাংশটি চলে আসে তার "লঘিষ্ঠ আকারে": অর্থাৎ সবচেয়ে ছোট সেই ইন্টিজারগুলো, যারা ভগ্নাংশটিকে নির্ভুলভাবে প্রকাশ করে, এবং হরটি হয় অ-ঋণাত্মক।

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## র‍্যাশনাল সংখ্যার সাথে পাটিগণিত

সাধারণ `arithmetic operators` `+ - * / ^ %` র‍্যাশনালের সাথে কাজ করে, মূলত অন্য যেকোনো সংখ্যার টাইপের মতোই।

ইন্টিজার আর অন্যান্য `Rational`-ও এতে রাখা যায়, আর ফলাফল আসে একটি `Rational` হিসেবে।
এক্সপ্রেশনে একটি `float` রাখলে ফলাফল আসে `float` হিসেবে, আর তার ফলে নির্ভুলতা (হতে পারে) কমে যায়।

`float` চাইলে শুধু `float()` ফাংশনটি দিয়ে র‍্যাশনালকে রূপান্তর করে নিন।
একটি লম্বা হিসাব জুড়ে নির্ভুলতা ধরে রাখতে র‍্যাশনাল সংখ্যা ব্যবহার করা, আর একেবারে শেষে সেটিকে ফ্লোটে রূপান্তর করা, বেশ স্বাভাবিক ব্যাপার।

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## অন্যান্য অপারেশন

Julia-তে র‍্যাশনাল সংখ্যা আসলে সাধারণ সংখ্যাই।
কম্পাইলার সাধারণত প্রয়োজন অনুযায়ী টাইপগুলো রূপান্তর করে নেয়।

তবে মনে রাখবেন, সসীম দশমিক রূপ আছে এমন ভগ্নাংশের ক্ষেত্রে তুলনা কাজ করে:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

কিন্তু তা ছাড়া, তুলনার জন্য একটি `Rational`-কে `Float`-এ রূপান্তর করতে হবে:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

গাণিতিক ফাংশন র‍্যাশনালকে ইনপুট হিসেবে নেয়, তবে ফলাফল দিতে পারে ফ্লোটিং-পয়েন্ট সংখ্যা:

```julia-repl
julia> sqrt(9//16)
0.75
```
