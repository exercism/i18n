# সম্পর্কে

Go একটি বিল্ট-ইন প্যাকেজ সরবরাহ করে, যার নাম `fmt` (ফরম্যাট প্যাকেজ)। এটি ইনপুট ও আউটপুটের ফরম্যাট নিয়ন্ত্রণ করার জন্য নানা ধরনের ফাংশন দেয়।
সবচেয়ে বেশি ব্যবহৃত ফাংশনটি হলো `Sprintf`, যা `%s`-এর মতো _ভার্ব_ ব্যবহার করে একটি স্ট্রিংয়ের ভেতরে মান বসায় এবং সেই স্ট্রিংটি রিটার্ন করে।

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Go ভাষায় ফ্লোটিং পয়েন্ট মানগুলো Sprintf-এর ভার্ব দিয়ে সুবিধাজনকভাবে ফরম্যাট করা যায়: `%g` (সংক্ষিপ্ত রূপ), `%e` (এক্সপোনেন্ট) বা `%f` (এক্সপোনেন্ট ছাড়া)।
তিনটি ভার্বই ফিল্ডের প্রস্থ এবং সংখ্যাগত অবস্থান নিয়ন্ত্রণ করার সুযোগ দেয়।

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

উপলব্ধ ভার্বগুলোর পূর্ণ তালিকা পাবেন [ফরম্যাট প্যাকেজের ডকুমেন্টেশন][fmt-docs]-এ।

`fmt`-এ স্ট্রিং নিয়ে কাজ করার জন্য আরও কিছু ফাংশন আছে, যেমন `Println`, যা শুধু যে আর্গুমেন্টগুলো পায় সেগুলো কনসোলে প্রিন্ট করে, আর `Printf`, যা ইনপুটকে `Sprintf`-এর মতোই ফরম্যাট করে তারপর প্রিন্ট করে।

[fmt-docs]: https://pkg.go.dev/fmt
