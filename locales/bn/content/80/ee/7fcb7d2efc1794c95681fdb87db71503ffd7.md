# Bash ফুলের মাঠ অনুশীলনীর ইঙ্গিত

এই অনুশীলনীতে একটি দ্বিমাত্রিক অ্যারে লাগে বলে মনে হচ্ছে।
Bash-এ কেবল একমাত্রিক ইনডেক্সড বা অ্যাসোসিয়েটিভ [অ্যারে][array] পাওয়া যায়।

অ্যাসোসিয়েটিভ অ্যারে ব্যবহার করে মাল্টিডাইমেনশনাল অ্যারে সিমুলেট করা যায়: অ্যারের কী (key) হিসেবে ব্যবহার করার জন্য ইনডেক্সগুলোকে কমা দিয়ে আলাদা করা একটি স্ট্রিং-এ এনকোড করুন।

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
