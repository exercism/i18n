# নির্দেশনা সংযোজন

## ইমপ্লিমেন্টেশন নোট

Cipher ইন্টারফেসের সংজ্ঞা আছে `cipher.go` ফাইলে।

আপনার ইমপ্লিমেন্টেশনগুলো Cipher ইন্টারফেস মেনে চলা উচিত।

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

ধরে নেওয়া হয়, `Encode` স্ট্রিংয়ের মধ্যে A-Za-z ছাড়া বাকি সব মান উপেক্ষা করবে; সেগুলো আউটপুটে থাকবে না।
আউটপুটও ছোট হাতের অক্ষরে রূপান্তর করা হবে।

সাইফারগুলো পাওয়ার জন্য যে ফাংশনগুলো ব্যবহার করা হয়:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

`NewShift`-এর আর্গুমেন্ট ১ থেকে ২৫ অথবা -১ থেকে -২৫ এর মধ্যে থাকতে হবে।
শূন্য অনুমোদিত নয়।
অবৈধ আর্গুমেন্টের ক্ষেত্রে `NewShift` nil রিটার্ন করে।

`NewVigenere`-এর আর্গুমেন্টে শুধু ছোট হাতের a-z অক্ষর থাকতে হবে।
শুধু 'a' অক্ষর দিয়ে গঠিত মান অনুমোদিত নয়।
অবৈধ আর্গুমেন্টের ক্ষেত্রে `NewVigenere` `nil` রিটার্ন করে।
