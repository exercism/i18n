# ক্যারেক্টার

`CHAR` হলো একটি ক্যারেক্টার, যা একক উদ্ধৃতি চিহ্নের মাঝে লেখা হয়।

```sather
   c : CHAR := 'M';
```

## বিশেষ ক্যারেক্টার

কিছু ক্যারেক্টার সরাসরি টাইপ করা যায় না, এগুলো ব্যাকস্ল্যাশ দিয়ে লেখা হয়:

| লেখা হয় | তা হলো |
| --- | --- |
| `'\n'` | একটি নতুন লাইন |
| `'\t'` | একটি ট্যাব |
| `'\''` | একটি একক উদ্ধৃতি চিহ্ন |
| `'\\'` | একটি ব্যাকস্ল্যাশ |

## প্রশ্ন

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## বড় হাতের ও ছোট হাতের অক্ষর

`.upper` ও `.lower` একটি অক্ষরের বড়-ছোট রূপ বদলে দেয়, বাকি সবকিছু অপরিবর্তিত রাখে, তাই আপনি যাচাই করেননি এমন একটি ক্যারেক্টারের উপরও নির্দ্বিধায় এগুলো প্রয়োগ করতে পারেন।

## সংখ্যা

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` আর `.char` একে অপরের ঠিক বিপরীত। সংখ্যাকরণ নিয়ে কাজে লাগার মতো বিষয়গুলো হলো, `'a'` থেকে `'z'` পর্যন্ত পরপর সাজানো, `'A'` থেকে `'Z'` পর্যন্তও পরপর, আর `'0'` থেকে `'9'` পর্যন্তও পরপর। তাই:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## ঘুরে ফিরে আসা

সাইফার চাকা `z` পেরিয়ে ঘুরে আবার `a`-তে ফিরে আসে। `%` ঠিক এই কাজটিই করে:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

ডান দিকের মান ধনাত্মক হলে Sather-এর `%` কখনো ঋণাত্মক উত্তর দেয় না, তাই চাকাটি সামনের দিকের মতো পেছনের দিকেও ঘোরানোর জন্য এটি কাজ করে।

## ক্যারেক্টার ও স্ট্রিং

একটি `STR` হলো বাইটের একটি সারি, আর একটি `CHAR` হলো এক বাইট। ইংরেজি লেখার ক্ষেত্রে এক বাইট মানে এক অক্ষর, তাই `"Marlowe".size` হলো 7 আর `"Marlowe"[0]` হলো `'M'`। অ্যাকসেন্টযুক্ত লেখা বা অন্য বর্ণমালার ক্ষেত্রে একটি অক্ষর কয়েক বাইট নিতে পারে, আর তখন ওই দুটি কথা কোনোটিই আর খাটে না।
