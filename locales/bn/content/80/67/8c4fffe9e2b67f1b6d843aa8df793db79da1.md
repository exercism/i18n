# পরিচিতি

## R-এ বুলিয়ান

ট্রু বা ফলস মান প্রকাশ করা হয় `logical` টাইপ দিয়ে।
এতে মাত্র দুটি মান থাকে: `TRUE` এবং `FALSE`।

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## বুলিয়ান অপারেটর

R-এ পাঁচটি বুলিয়ান অপারেটর আছে, তবে সিলেবাসের এই পর্যায়ে কেবল তিনটি প্রাসঙ্গিক।
বাকি দুটি গুরুত্বপূর্ণ হবে ভেক্টর নিয়ে কাজ করার সময়, যা পরের কয়েকটি কনসেপ্টে আলোচনা করা হয়েছে।

`&&` হলো বুলিয়ান "এবং"।
`&&`-এর *দুই* দিকের এক্সপ্রেশনই `TRUE` হলে এর ফলাফল `TRUE` হয়।

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` হলো বুলিয়ান "অথবা"।
`||`-এর *যেকোনো* এক দিকের এক্সপ্রেশন `TRUE` হলে এর ফলাফল `TRUE` হয়।

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` হলো বুলিয়ান "না"।
এটি `TRUE` ও `FALSE` মান পরস্পরের সঙ্গে বিনিময় করে।

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

আরও দীর্ঘ ও জটিল এক্সপ্রেশনের ক্ষেত্রে নিজের উদ্দেশ্য স্পষ্ট করতে প্রথম বন্ধনী ব্যবহার করা ভালো।

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
