# ভূমিকা

## রেগুলার এক্সপ্রেশন

অন্যান্য জনপ্রিয় ভাষা যেমন Java, JavaScript বা Ruby-র মতোই Gleam-এ রেগুলার এক্সপ্রেশন **PCRE** স্পেসিফিকেশন (**P**erl **C**ompatible **R**egular **E**xpressions, অর্থাৎ পার্ল, কম্প্যাটিবল, রেগুলার আর এক্সপ্রেশন) অনুসরণ করে।

`gleam_regexp` প্যাকেজের `gleam/regexp` মডিউলটি রেগুলার এক্সপ্রেশন নিয়ে কাজ করার জন্য ফাংশন সরবরাহ করে।

~~~~exercism/note
এই অনুশীলনীতে ধরে নেওয়া হয়েছে যে আপনি রেগুলার এক্সপ্রেশনের সিনট্যাক্স আগেই জানেন, যার মধ্যে আছে ক্যারেক্টার ক্লাস, কোয়ান্টিফায়ার, গ্রুপ এবং ক্যাপচার।

আপনার রেগুলার এক্সপ্রেশন সম্পর্কে জ্ঞান হালনাগাদ করার দরকার হলে, নিচের যেকোনো একটি সূত্র দেখে নিন: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/)।
~~~~

রেগুলার এক্সপ্রেশন তৈরি করার সবচেয়ে কমন উপায় হলো `regexp.from_string` ফাংশনটি ব্যবহার করা।

```gleam
let assert Ok(re) = regexp.from_string("test")
```

রেগুলার এক্সপ্রেশন তৈরির ফাংশনগুলো রেগুলার এক্সপ্রেশনের সিনট্যাক্স অবৈধ হলে একটি এরর রিটার্ন করে, তাই এখানে রেগুলার এক্সপ্রেশনটি বৈধ কি না তা নিশ্চিত করতে একটি let-assertion ব্যবহার করা হয়েছে।

একটি রেগুলার এক্সপ্রেশন কোনো স্ট্রিংয়ের সাথে মেলে কি না, তা যাচাই করতে `regexp.check` ফাংশনটি ব্যবহার করা যায়।

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### ক্যাপচার

আপনি যদি কোনো রেগুলার এক্সপ্রেশন দিয়ে সাবস্ট্রিং ক্যাপচার করতে চান, তাহলে ম্যাচগুলোর একটি অ্যারে ফেরাতে `regexp.scan` ফাংশনটি ব্যবহার করা যায়।

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### মডিফায়ার

`regexp.compile` ফাংশন দিয়ে রেগুলার এক্সপ্রেশন তৈরি করার সময় অপশন পাস করে এর আচরণ পরিবর্তন করা যায়।

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
