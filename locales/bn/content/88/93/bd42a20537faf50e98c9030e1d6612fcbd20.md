# নির্দেশনা

এই অনুশীলনীতে আপনি সেভিংস অ্যাকাউন্ট নিয়ে কাজ করবেন। প্রতি বছর আপনার সেভিংস অ্যাকাউন্টের ব্যালেন্স তার সুদের হার অনুযায়ী আপডেট করা হয়। আপনার ব্যাংক আপনাকে যে সুদের হার দেয়, তা আপনার অ্যাকাউন্টে থাকা টাকার পরিমাণের (অর্থাৎ এর ব্যালেন্সের) ওপর নির্ভর করে:

- ঋণাত্মক ব্যালেন্সের জন্য ৩.২১৩% (ফলে সুদ ঋণাত্মক হয়)।
- `1000` ডলারের কম ধনাত্মক ব্যালেন্সের জন্য ০.৫%।
- `1000` ডলার বা তার বেশি এবং `5000` ডলারের কম ধনাত্মক ব্যালেন্সের জন্য ১.৬২১%।
- `5000` ডলার বা তার বেশি ধনাত্মক ব্যালেন্সের জন্য ২.৪৭৫%।

প্রতি বছর সরকার আপনাকে করমুক্তভাবে আপনার টাকার একটি শতাংশ দাতব্য সংস্থায় দান করার সুযোগ দেয়। যেহেতু আপনি একজন ভালো মানুষ, তাই বছরের শেষে আপনার ব্যালেন্স ধনাত্মক হলে আপনি করমুক্ত শতাংশটি নিয়ে তা দ্বিগুণ করেন এবং নিকটতম পূর্ণ ডলারে রাউন্ড ডাউন করেন। দানের দ্বিতীয় অংশের ওপর কর দিতে আপনার আপত্তি নেই।

আপনার সামনে তিনটি কাজ আছে, যার প্রতিটিতে আপনার ব্যালেন্স ও তার সুদের হার নিয়ে কাজ করতে হবে।

## 1. সুদের হার হিসাব করুন

নির্দিষ্ট ব্যালেন্সের ভিত্তিতে সুদের হার হিসাব করতে `interestRate` ফাংশনটি বাস্তবায়ন করুন:

```fsharp
interestRate 200.75m
// => 0.5f
```

খেয়াল করুন, রিটার্ন করা মানটি একটি `single`.

## 2. সুদ হিসাব করুন

নির্দিষ্ট ব্যালেন্সের ভিত্তিতে সুদ হিসাব করতে `interest` মেথডটি বাস্তবায়ন করুন:

```fsharp
interest 200.75m
// => 1.00375m
```

খেয়াল করুন, রিটার্ন করা মানটি একটি `decimal`.

## 3. বার্ষিক ব্যালেন্স আপডেট হিসাব করুন

সুদের হার বিবেচনায় নিয়ে বার্ষিক ব্যালেন্স আপডেট হিসাব করতে `annualBalanceUpdate` ফাংশনটি বাস্তবায়ন করুন:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

খেয়াল করুন, রিটার্ন করা মানটি একটি `decimal`.

## 4. কত টাকা দান করতে হবে তা হিসাব করুন

ব্যালেন্স এবং সরকার যে করমুক্ত শতাংশ অনুমোদন করে, তার ভিত্তিতে দাতব্য সংস্থায় কত টাকা দান করতে হবে তা হিসাব করতে `amountToDonate` ফাংশনটি বাস্তবায়ন করুন:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

খেয়াল করুন, রিটার্ন করা মানটি একটি `int`.
