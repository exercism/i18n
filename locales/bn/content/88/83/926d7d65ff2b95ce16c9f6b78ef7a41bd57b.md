# সংখ্যা

Crystal-এ `Number` নামে একটি টাইপ আছে, যা সব সংখ্যাগত টাইপের মূল টাইপ। `Number` টাইপের ভিতরে প্রধান দুটি সাব-টাইপ আছে: [`Int`][int] এবং [`Float`][float]।

`Int` হলো ইন্টিজার-এর সংক্ষিপ্ত রূপ, আর এটি পূর্ণসংখ্যা বোঝায়। `Int` ঋণাত্মক ও ধনাত্মক দুটোই হতে পারে, এর সাথে কোনো দশমিক বিন্দু থাকে না।

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` দশমিক বিন্দুসহ সংখ্যা বোঝায়। `Float`-ও ঋণাত্মক ও ধনাত্মক দুটোই হতে পারে।

```crystal
10.5.class
# => Float64
```

## `Int` আর `Float`-এর মধ্যে রূপান্তর

'to_i' আর 'to_f' মেথড ব্যবহার করে আপনি `Int` আর `Float`-এর মধ্যে রূপান্তর করতে পারেন। `Float` থেকে `Int`-এ রূপান্তর করার সময় সংখ্যাটি নিচের দিকে রাউন্ড করা হয়।

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## গাণিতিক অপারেটর

আপনি `Int` আর `Float`-এর উপর [মৌলিক গাণিতিক অপারেটরগুলো][math] ব্যবহার করতে পারেন। অপারেটরগুলো হলো `+`, `-`, `*`, `/` এবং `%`. এগুলো ব্যবহার করার সময় আপনি `Int` আর `Float` মিশিয়ে ব্যবহার করতে পারেন।

### যোগ, বিয়োগ ও গুণ

`+` অপারেটর যোগের জন্য, `-` অপারেটর বিয়োগের জন্য আর `*` অপারেটর গুণের জন্য ব্যবহৃত হয়।

| অপারেটর | উদাহরণ         |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### ভাগ

ভাগ দিয়ে সংখ্যা ভাগ করা হয়। ভাগের জন্য `/` অপারেটর ব্যবহৃত হয়। ফলাফল সবসময় একটি Float হয়।

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
কিছু প্রোগ্রামিং ভাষায় শূন্য দিয়ে ভাগ করলে ফলাফল একটি এরর হয়।

Crystal-এ শূন্য দিয়ে ভাগ করলে ফলাফল হয় `Infinity` বা `-Infinity`। একমাত্র ব্যতিক্রম শূন্যকে শূন্য দিয়ে ভাগ করা, যার ফলাফল `NaN` (Not a Number)। `Infinity` আর `NaN` হলো `Float` টাইপের বিশেষ মান।

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### মডুলাস

মডুলাস দিয়ে ভাগের ভাগশেষ পাওয়া যায়। মডুলাসের জন্য `%` অপারেটর ব্যবহৃত হয়।

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
মডুলো ব্যবহার করার সময় শূন্য দিয়ে ভাগ করলে DivisionByZeroError হয়। এটি সাধারণ ভাগ থেকে আলাদা।

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## রাউন্ডিং

`round` মেথডটি একটি ঐচ্ছিক আর্গুমেন্ট নেয়: কত দশমিক স্থান পর্যন্ত রাউন্ড করতে হবে তার সংখ্যা। ডিফল্ট দশমিক স্থানের সংখ্যা হলো ০।

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## প্রাধান্য ও বন্ধনী

Crystal বন্ধনী(`()`) ব্যবহার করতে দেয়, যা দিয়ে এক্সপ্রেশন গোষ্ঠীভুক্ত করা যায়। অপারেশনের ক্রম বদলাতে চাইলে এটি কাজে লাগে।

একাধিক গাণিতিক অপারেটর ব্যবহার করলে অপারেশনের ক্রম গণিতের মতোই হয়, যাকে [PEMDAS][pemdas] বলা হয়। এটি বন্ধনী(`()`), সূচক(`**`), গুণ(`*`) ও ভাগ(`/`), এবং যোগ(`+`) ও বিয়োগ(`-`) এই ক্রম অনুসরণ করে।

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
