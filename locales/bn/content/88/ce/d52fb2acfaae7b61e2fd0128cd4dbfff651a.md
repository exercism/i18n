# ভূমিকা

কখনও কখনও কোডের একটি নির্দিষ্ট অংশ একাধিকবার ব্যবহার করা প্রয়োজন হয়। এমন হলে, সেই কোডটি একটি ফাংশনে রাখা সুবিধাজনক হতে পারে। একটি ফাংশন সাধারণত কেবল একটি নির্দিষ্ট কাজই করে। Rust-এ ফাংশন ডিফাইন করতে ```fn``` কিওয়ার্ডটি ব্যবহার করা হয়। ফাংশনের কোডটি সর্বদা দ্বিতীয় বন্ধনীর (অর্থাৎ `{}`) মধ্যে থাকে। `main` নামের ফাংশনটি বিশেষ, কারণ এটি প্রোগ্রামগুলোর এন্ট্রি পয়েন্ট। সেই ফাংশন থেকে আপনি অন্য ফাংশন কল করতে পারেন।

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

ফাংশন প্যারামিটারও নিতে পারে, যেমন ```say_my_name()```-এর ```name: &str```। ফাংশন রিটার্ন ভ্যালুও রিটার্ন করতে পারে, যেমন উপরে `-> &str`।
