# পরিচিতি

Factor-এর ক্যারেক্টারগুলো আসলে ইন্টিজার, অর্থাৎ Unicode কোড পয়েন্ট। তাই `<`, `>`, `=` এই সংখ্যাগত তুলনাগুলো আপনাকে সরাসরি কেস-সংবেদনশীল ক্রম দিয়ে দেয়। [`unicode`][unicode] ভোকাবুলারিটি Unicode-সচেতন প্রেডিকেট এবং একক ক্যারেক্টারের কেস রূপান্তর যোগ করে।

## ক্যারেক্টার প্রেডিকেট

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## কেস রূপান্তর

`ch>upper` আর `ch>lower` একটি একক ক্যারেক্টারের কেস বদলে দেয়। আর স্ট্রিং-স্তরের `>upper` ও `>lower` সেগুলোকে স্ট্রিংয়ের প্রতিটি ক্যারেক্টারে প্রয়োগ করে।

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
