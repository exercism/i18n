# নির্দেশাবলি

আপনার বন্ধু, একজন উচ্চাকাঙ্ক্ষী শিল্পী, একটি প্রজেক্টের আইডিয়া নিয়ে আপনার কাছে এসেছেন। চলুন তাঁর ভিজ্যুয়াল সৃজনশীলতার সাথে আপনার টেকনিক্যাল দক্ষতা মিলিয়ে দিই। এখন [জেনারেটিভ আর্ট][generative-art] নিয়ে একটু হাত পাকানোর সময় এসেছে!

সীমাবদ্ধতা সৃজনশীলতাকে সাহায্য করে আর প্রজেক্টের সময়সীমা কমিয়ে দেয়, তাই你们两个 — no. আপনি দুজনে মিলে আপনার মাস্টারপিসটিকে একটি মাত্র আকৃতিতে সীমিত রাখতে রাজি হয়েছেন, আর সেই আকৃতিটি হলো বৃত্ত। কিন্তু বৃত্ত থাকবে অনেক। আর তারা এদিক-ওদিক চলাফেরাও করতে পারবে! এর নাম হবে... ড্যান্সিং ডটস।

আপনার বন্ধু নিশ্চিতভাবেই ডটগুলোর জন্য নতুন নতুন জটিল মুভমেন্ট বানাতে চাইবেন, তাই আপনি কোডিং শুরু করবেন এমন একটি আর্কিটেকচার তৈরি করে, যা দিয়ে পরে সহজেই নতুন অ্যানিমেশন ডিফাইন করা যাবে।

## 1. অ্যানিমেশন বিহেভিয়ার ডিফাইন করুন

প্রতিটি অ্যানিমেশন মডিউলকে দুটি কলব্যাক ইমপ্লিমেন্ট করতে হবে: `init/1` আর `handle_frame/3`। এগুলো `Animation` মডিউলে ডিফাইন করুন।

`init/1` কলব্যাকটি ডিফাইন করুন। এটি `opts` টাইপের একটি আর্গুমেন্ট নেবে এবং `{:ok, opts}` টাপল অথবা `{:error, error}` টাপল রিটার্ন করবে। এই কলব্যাকের ইমপ্লিমেন্টেশনগুলো যাচাই করবে, দেওয়া অপশনগুলো এই নির্দিষ্ট ধরনের অ্যানিমেশনের জন্য বৈধ কি না।

`handle_frame/3` কলব্যাকটি ডিফাইন করুন। এটি তিনটি আর্গুমেন্ট নেবে: ডট, একটি ফ্রেম নম্বর এবং অপশন। এটি সবসময় একটি ডট রিটার্ন করবে। এই কলব্যাকের ইমপ্লিমেন্টেশনগুলো বর্তমান ফ্রেম নম্বর ও অ্যানিমেশনের অপশনের ভিত্তিতে ডটের অ্যাট্রিবিউট পরিবর্তন করবে।

## 2. `init/1` কলব্যাকের একটি ডিফল্ট ইমপ্লিমেন্টেশন দিন

`use DancingDots.Animation` কল করে `Animation` বিহেভিয়ারটি যেন সহজেই অন্য মডিউলে যুক্ত করা যায়।

সেটি করতে `Animation` মডিউলে `__using__` ম্যাক্রোটি ইমপ্লিমেন্ট করুন, যাতে এটি `Animation` মডিউলটিকে অন্য মডিউলের বিহেভিয়ার হিসেবে সেট করে। এটি `init/1` কলব্যাকের একটি ডিফল্ট ইমপ্লিমেন্টেশনও দেবে। `init/1`-এর ডিফল্ট ইমপ্লিমেন্টেশন দেওয়া অপশনগুলো অপরিবর্তিত রেখে রিটার্ন করবে।

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. `Flicker` অ্যানিমেশনটি ইমপ্লিমেন্ট করুন

একটি ফ্লিকারিং অ্যানিমেশন ইমপ্লিমেন্ট করতে `Animation` বিহেভিয়ারটি ব্যবহার করুন।

এটি ডিফল্ট `init/1` কলব্যাকটি ব্যবহার করবে, কারণ এটি কোনো অপশন নেয় না।

`handle_frame/3` কলব্যাকটি ইমপ্লিমেন্ট করুন, যা একটি মাত্র ফ্রেম হ্যান্ডেল করে। ফ্রেম নম্বর যদি চারের গুণিতক হয়, তাহলে ফাংশনটি ডটটিকে তার মূল অপাসিটির অর্ধেক অপাসিটিসহ রিটার্ন করবে। অন্য ফ্রেমে এটি ডটটি অপরিবর্তিত অবস্থায় রিটার্ন করবে।

ফ্রেম গণনা শুরু হয় `1` থেকে। `handle_frame/3`-এ পাঠানো ডটটি সবসময় তার মূল অবস্থার ডট, আগের ফ্রেমের অবস্থার নয়।

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. `Zoom` অ্যানিমেশনটি ইমপ্লিমেন্ট করুন

এই অ্যানিমেশনটি একটি অপশন নেয়: ভেলোসিটি। ভেলোসিটি যেকোনো সংখ্যা হতে পারে। এটি ঋণাত্মক হলে ডটটি জুম-ইনের বদলে জুম-আউট হয়।

`init/1` কলব্যাকটি ইমপ্লিমেন্ট করুন। এটি যাচাই করবে যে পাঠানো অপশনগুলো `:velocity` কী (key) সহ একটি কিওয়ার্ড লিস্ট। ভেলোসিটির মান অবশ্যই একটি সংখ্যা হতে হবে। এটি সংখ্যা না হলে এই এররটি রিটার্ন করুন: `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`।

`handle_frame/3` কলব্যাকটি ইমপ্লিমেন্ট করুন। এটি ডটটির রেডিয়াস বাড়িয়ে রিটার্ন করবে, যেখানে বাড়ার পরিমাণ হলো (বর্তমান ফ্রেম নম্বর − ১) × ভেলোসিটি।

ফ্রেম গণনা শুরু হয় `1` থেকে। `handle_frame/3`-এ পাঠানো ডটটি সবসময় তার মূল অবস্থার ডট, আগের ফ্রেমের অবস্থার নয়।

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
