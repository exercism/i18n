# পরিচিতি

C#-এ অবজেক্ট-অরিয়েন্টেড প্রোগ্রামিংয়ের প্রধান গঠনটি হল _ক্লাস_, যা ডেটা (_ফিল্ড_) ও আচরণের (_মেথড_) সমন্বয়। একটি ক্লাসের ফিল্ড ও মেথডগুলোকে তার _মেম্বার_ বলা হয়।

অ্যাক্সেস মডিফায়ারের মাধ্যমে মেম্বারগুলোর অ্যাক্সেস সীমিত করা যায়। সবচেয়ে কমন দুটি মডিফায়ার হল:

- `public`: যেকোনো কোড থেকে মেম্বারটি অ্যাক্সেস করা যায় (কোনো বিধিনিষেধ নেই)।
- `private`: শুধুমাত্র একই ক্লাসের কোড থেকে মেম্বারটি অ্যাক্সেস করা যায়।

একটি ক্লাসকে সেই ক্লাসের ইনস্ট্যান্স তৈরির টেমপ্লেট হিসেবে ভাবতে পারেন। একটি ক্লাসের ইনস্ট্যান্স (যাকে _অবজেক্ট_ও বলা হয়) তৈরি করতে `new` কিওয়ার্ডটি ব্যবহার করা হয়:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

ফিল্ডের একটি টাইপ থাকে এবং ক্লাসের যেকোনো জায়গায় সেগুলো ডিফাইন করা যায়।
public ফিল্ডগুলো PascalCase-এ আর private ফিল্ডগুলো camelCase-এ ডিফাইন করা হয় এবং তার আগে একটি আন্ডারস্কোর `_` বসানো হয়:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

চাইলে একটি ফিল্ডে প্রাথমিক মান অ্যাসাইন করা যায়। কোনো ফিল্ডে প্রাথমিক মান _না_ দিলে সেটিতে তার টাইপের ডিফল্ট মান বসে যায়। একটি ইনস্ট্যান্সের ফিল্ডের মান ডট নোটেশন দিয়ে অ্যাক্সেস ও আপডেট করা যায়।

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

সাধারণত একটি মেথড কল করার পার্শ্বপ্রতিক্রিয়া হিসেবে private ফিল্ড আপডেট করা হয়। এমন মেথড সাধারণত কোনো মান রিটার্ন করে না, সেক্ষেত্রে রিটার্ন টাইপ `void` হওয়া উচিত:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
