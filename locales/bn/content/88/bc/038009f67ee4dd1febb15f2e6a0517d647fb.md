# সর্টিং

জিনিসপত্র সাজিয়ে রাখা এতটাই কমন কাজ যে লাইব্রেরিই এটি আপনার হয়ে করে দেয়।

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` এমন যেকোনো কিছুর উপর কাজ করে যা ইতিমধ্যেই নিজেকে তুলনা করতে জানে: সংখ্যা আর স্ট্রিং পারে, কারণ তাদের একটি `is_lt` আছে।

## নিজের নিয়মে সর্টিং

বেশিরভাগ ক্রমই বিল্ট-ইন নয়। একটি নেটবলের লিডারবোর্ড বর্ণানুক্রমিকও নয়, নামের দৈর্ঘ্য দিয়েও নয়: এটি পয়েন্ট দিয়ে সাজানো, আর পয়েন্টে সমান থাকা দলগুলোর ক্ষেত্রে গোল পার্থক্য দিয়ে। `ARRAY`-এর পক্ষে তা অনুমান করার কোনো উপায় নেই।

তাই আপনি ক্রমটি একটি বাউন্ড রুটিন হিসেবে দিয়ে দেন:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` একটি `ROUT{T,T}:BOOL` নেয়: এমন একটি রুটিন, যা সাজানো হচ্ছে এমন দুটি জিনিস নেয় এবং প্রথমটি দ্বিতীয়টির আগে বসবে কি না তা উত্তর দেয়। এটি প্রয়োজনমতো সেই রুটিনটিকে কল করে আর উত্তরগুলো যা বোঝায় সেই ক্রমে অ্যারেটি সাজিয়ে দেয়।

`understudy`-এর উদ্দেশ্য ছিল ঠিক এটাই। লাইব্রেরি জানে কীভাবে সর্ট করতে হয়, কিন্তু আপনার ক্রম-ভাবনা সম্পর্কে কিছুই জানে না; বাউন্ড রুটিনই সেই জায়গা যেখানে এই দুটি মিলিত হয়।

## তুলনাটি লেখা

রুটিনটি **ট্রু** উত্তর দেয় যখন প্রথম আর্গুমেন্টটি আগে আসে।

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

একাধিক অংশওয়ালা নিয়মের ক্ষেত্রে অংশগুলো গুরুত্বের ক্রমে দেখুন:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

পয়েন্ট ভিন্ন হলেই প্রথম `if` বিষয়টি নিষ্পত্তি করে। পয়েন্ট সমান হলেই কেবল দ্বিতীয় লাইনটি কিছু বলার সুযোগ পায়। টাই ভাঙার নিয়মটি আগে লিখলে পয়েন্টের কোনো ভূমিকাই থাকত না।

## সর্টিং অ্যারেটিকেই বদলে দেয়

`insertion_sort_by` অ্যারেটিকেই ক্রমে সাজায় আর কোনো উত্তর দেয় না:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

যদি মূল ক্রমটি গুরুত্বপূর্ণ হয়, তাহলে একটি কপি সর্ট করুন:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
