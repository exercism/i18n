# ইঙ্গিত

## সাধারণ

## 1. একেবারে নতুন একটি রিমোট কন্ট্রোলড কার কিনুন

- [এই পৃষ্ঠায় একটি ক্লাসের নতুন ইনস্ট্যান্স তৈরি করার পদ্ধতি দেখানো হয়েছে][creating-objects]।

## 2. অতিক্রান্ত দূরত্ব দেখান

- অতিক্রান্ত দূরত্ব ট্র্যাক রাখতে একটি [ফিল্ড][fields] ব্যবহার করুন।
- ফিল্ডটির জন্য কী ভিজিবিলিটি ব্যবহার করবেন তা ভেবে দেখুন (এটি কি ক্লাসের বাইরে ব্যবহার করার প্রয়োজন আছে?)।
- রিটার্ন করার স্ট্রিংটি ফরম্যাট করতে [স্ট্রিং ইন্টারপোলেশন][string-interpolation] ব্যবহার করার কথা ভেবে দেখুন।

## 3. ব্যাটারির পার্সেন্টেজ দেখান

- শুরুর ব্যাটারি চার্জ ট্র্যাক রাখতে একটি [ফিল্ড][fields] ব্যবহার করুন।
- প্রত্যাশিত শুরুর ব্যাটারি চার্জের সাথে মিলে যায় এমন একটি নির্দিষ্ট মান দিয়ে ফিল্ডটি ইনিশিয়ালাইজ করুন।
- ফিল্ডটির জন্য কী ভিজিবিলিটি ব্যবহার করবেন তা ভেবে দেখুন (এটি কি ক্লাসের বাইরে ব্যবহার করার প্রয়োজন আছে?)।
- রিটার্ন করার স্ট্রিংটি ফরম্যাট করতে [স্ট্রিং ইন্টারপোলেশন][string-interpolation] ব্যবহার করার কথা ভেবে দেখুন।

## 4. গাড়ি চালানোর সময় অতিক্রান্ত মিটারের সংখ্যা আপডেট করুন

- অতিক্রান্ত দূরত্ব নির্দেশ করে এমন ফিল্ডটি আপডেট করুন।

## 5. গাড়ি চালানোর সময় ব্যাটারির পার্সেন্টেজ আপডেট করুন

- ব্যাটারির পার্সেন্টেজ নির্দেশ করে এমন ফিল্ডটি আপডেট করুন।

## 6. ব্যাটারি শেষ হয়ে গেলে গাড়ি চালানো প্রতিরোধ করুন

- ব্যাটারি ইতিমধ্যে শেষ না হয়ে থাকলে কেবল দূরত্ব ও ব্যাটারি আপডেট করার জন্য একটি শর্ত যুক্ত করুন।
- ব্যাটারি শেষ হয়ে গেলে খালি ব্যাটারির বার্তা দেখানোর জন্য একটি শর্ত যুক্ত করুন।
