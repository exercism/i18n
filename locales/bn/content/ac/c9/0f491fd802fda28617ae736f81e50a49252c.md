# পরিচিতি

একটি ফাংশন আপনাকে কোডকে একটি পুনর্ব্যবহারযোগ্য এককে গুছিয়ে রাখতে দেয়।
এটি তৈরি হয় `func` কিওয়ার্ড, ফাংশনের নাম, এবং প্রথম বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা শূন্য বা তার বেশি প্যারামিটার ও টাইপের তালিকা নিয়ে।

## ফাংশনের প্যারামিটার

সব প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হয়; প্যারামিটারের জন্য কোনো টাইপ ইনফারেন্স নেই।
প্যারামিটারের কোনো ডিফল্ট মানও নেই, তাই ফাংশনের সব প্যারামিটারই আবশ্যক।

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

একই টাইপের প্যারামিটারগুলো একসাথে ডিক্লেয়ার করা যায়, আর শেষে একবার মাত্র টাইপ লিখলেই হয়।

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## প্যারামিটার বনাম আর্গুমেন্ট

চলুন দ্রুত দুটি পরিভাষা দেখে নিই, যেগুলো নিয়ে প্রায়ই বিভ্রান্তি হয়: `parameters` এবং `arguments`।
ফাংশনের প্যারামিটার হলো ফাংশনের সিগনেচারে ডিফাইন করা নামগুলো, যেমন উপরের `PrintGreetingName` ফাংশনে `greeting` ও `name`।
ফাংশনের আর্গুমেন্ট হলো সেই নির্দিষ্ট মানগুলো, যেগুলো আমরা ফাংশন ইনভোক করার সময় ফাংশনের প্যারামিটারগুলোতে পাঠাই।
যেমন নিচের উদাহরণে `"Hello"` ও `"Katrina"` হলো `greeting` ও `name` প্যারামিটারে পাঠানো আর্গুমেন্ট:

```go
PrintGreetingName("Hello", "Katrina")
```

## রিটার্ন ভ্যালু

ফাংশনের প্যারামিটারের পরে থাকে শূন্য বা তার বেশি রিটার্ন ভ্যালু, যেগুলোর টাইপও স্পষ্টভাবে উল্লেখ করতে হয়।
একটি মাত্র রিটার্ন ভ্যালু হলে তা খালি অবস্থায় রাখা হয়, আর একাধিক রিটার্ন ভ্যালু হলে সেগুলোকে প্রথম বন্ধনীর মধ্যে রাখা হয়।
`return` কিওয়ার্ড ব্যবহার করে ফাংশন থেকে কল করা কোডে মানগুলো ফিরিয়ে দেওয়া হয়।
একটি ফাংশনে একাধিক `return` স্টেটমেন্ট থাকতে পারে।
ওই `return` স্টেটমেন্টগুলোর যেকোনো একটিতে পৌঁছালেই ফাংশনের এক্সিকিউশন শেষ হয়ে যায়।
কোনো ফাংশন থেকে যদি একাধিক মান রিটার্ন করতে হয়, তাহলে সেগুলো কমা দিয়ে আলাদা করতে হয়।

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## ফাংশন কল করা

ফাংশন ইনভোক করতে হলে ফাংশনের নাম লিখে, প্রথম বন্ধনীর ভেতরে ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাঠাতে হয়।

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## নামযুক্ত রিটার্ন ভ্যালু ও নেকেড রিটার্ন

প্যারামিটারের মতো রিটার্ন ভ্যালুগুলোও ইচ্ছে হলে নাম দেওয়া যায়।
নামযুক্ত রিটার্ন ভ্যালু ব্যবহার করলে, আর্গুমেন্ট ছাড়া একটি `return` স্টেটমেন্ট ওই মানগুলোই রিটার্ন করে।
একে 'নেকেড' রিটার্ন বলা হয়।

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## ভ্যালু দিয়ে পাস বনাম রেফারেন্স দিয়ে পাস

ভ্যালু দিয়ে পাস আর রেফারেন্স দিয়ে পাসের ধারণাটা স্পষ্ট করাও জরুরি।

প্রথমে চলুন ভ্যালু দিয়ে পাস স্পষ্ট করে নিই।
নিচের উদাহরণে, আমরা যখন `MultiplyByTwo` ফাংশনে `val` ভ্যারিয়েবলটি পাঠাই, তখন আসলে `val`-এর একটি কপি পাঠাই।
এর ফলে `newVal`-এ আপডেট হওয়া মান `4` থাকে, কিন্তু মূল ভ্যারিয়েবল `val` তখনও `2` থাকে।
পর্দার আড়ালে Go আসলে মূল মানটির একটি কপি তৈরি করে, যাতে ফাংশন শুধু এই কপিটিকেই, অর্থাৎ `v`-কে, পরিবর্তন করে।

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

কঠোরভাবে বললে, Go-তে সব আর্গুমেন্টই ভ্যালু দিয়ে পাস হয়, অর্থাৎ ফাংশনে দেওয়া মান বা ডেটার একটি কপি তৈরি হয়।
কিন্তু আপনি যদি ফাংশনে পাঠানো ডেটার কপি তৈরি করতে না চান এবং ফাংশনের ভেতরেই ডেটা বদলাতে চান,
তাহলে আর্গুমেন্ট হিসেবে `pointers` ব্যবহার করুন, যাকে বলে রেফারেন্স দিয়ে পাস।

## পয়েন্টার

রেফারেন্স দিয়ে পাস করার জন্য আমরা `pointer` ব্যবহার করি।
ফাংশনে `pointer` আর্গুমেন্ট পাঠিয়ে আমরা ফাংশনে পাঠানো মূল ডেটাই পরিবর্তন করতে পারি, শুধু ডেটার একটি কপি নিয়ে কাজ করার বদলে।

আপাতত এটুকু জানলেই যথেষ্ট যে ফাংশন সিগনেচারে টাইপের সামনে `*` থাকলে পয়েন্টার টাইপ চেনা যায়।

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

`pointer`-এর ধারণাটা যদি বিভ্রান্তিকর লাগে, চিন্তার কিছু নেই।
সিলেবাসে পরে একটি আলাদা সেকশন আছে যা আপনাকে পয়েন্টার আয়ত্ত করতে সাহায্য করবে।

## ব্যতিক্রম

মনে রাখবেন, `slices` আর `maps` উপরে বলা নিয়মের ব্যতিক্রম।
ফাংশনে আর্গুমেন্ট হিসেবে `slice` বা `map` পাঠালে সেগুলোকে পয়েন্টার টাইপ হিসেবে ধরা হয়, যদিও টাইপে স্পষ্ট কোনো `*` থাকে না।
এর মানে হলো, আমরা যদি কোনো ফাংশনে একটি স্লাইস বা ম্যাপ পাঠিয়ে তার মূল ডেটা পরিবর্তন করি,
তাহলে পরিবর্তনগুলো মূল স্লাইস বা ম্যাপে প্রতিফলিত হবে।
