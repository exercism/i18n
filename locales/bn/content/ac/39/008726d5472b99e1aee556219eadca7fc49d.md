# নির্দেশনা

একটি ত্রিভুজ _equilateral_, _isosceles_ নাকি _scalene_, তা নির্ধারণ করুন।

একটি _equilateral_ ত্রিভুজের তিনটি বাহুর দৈর্ঘ্যই একই।

একটি _isosceles_ ত্রিভুজের অন্তত দুটি বাহুর দৈর্ঘ্য একই।
(কখনও কখনও এটিকে ঠিক দুটি বাহুর দৈর্ঘ্য একই হওয়া হিসেবে বলা হয়, তবে এই অনুশীলনীর উদ্দেশ্যে আমরা অন্তত দুটি বলব।)

একটি _scalene_ ত্রিভুজের সব বাহুর দৈর্ঘ্য ভিন্ন ভিন্ন।

## লক্ষণীয়

কোনো আকৃতি আদৌ একটি ত্রিভুজ হতে হলে তার সব বাহুর দৈর্ঘ্য > 0 হতে হবে, এবং যেকোনো দুটি বাহুর দৈর্ঘ্যের যোগফল তৃতীয় বাহুর দৈর্ঘ্যের চেয়ে বড় বা সমান হতে হবে।

সমীকরণে:

`a`, `b` ও `c` ত্রিভুজের বাহু ধরা যাক।
তাহলে নিচের তিনটি এক্সপ্রেশনই সত্য হতে হবে:

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```
