# নির্দেশনা

আপনি একটি হেলথ-মনিটরিং সিস্টেম তৈরি করার কাজ করছেন।
এর অংশ হিসেবে আপনার ব্যবহারকারীদের স্বাস্থ্য পরিসংখ্যান সংরক্ষণ করা প্রয়োজন।

আপনি শুরু করবেন একটি `impl` ব্লকে থাকা কিছু স্টাব করা ফাংশন আর নিচের স্ট্রাক্ট ডেফিনিশনটি নিয়ে:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

আপনার লক্ষ্য হলো `impl` ব্লকে ডিফাইন করা `User` `struct`-এর ওপর স্টাব করা মেথডগুলো ইমপ্লিমেন্ট করা।

উদাহরণস্বরূপ, `new` মেথডটি নির্দিষ্ট নাম, বয়স ও ওজন মান নিয়ে `User` স্ট্রাক্টের একটি ইনস্ট্যান্স রিটার্ন করবে।

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

`weight` মেথডটি `User`-এর ওজন রিটার্ন করবে।

```rust
bob.weight();
// Returns: 72
```

`set_age` মেথডটি `User`-এর বয়স সেট করবে।

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

শুভকামনা!
