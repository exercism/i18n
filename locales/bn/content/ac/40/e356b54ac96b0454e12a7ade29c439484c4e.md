# নির্দেশাবলি

আপনার বন্ধু এইমাত্র আপনাকে একটি গুরুত্বপূর্ণ গোপন বার্তা পাঠিয়েছেন।
অন্যরা যাতে সহজে এটি পড়তে না পারে, সেজন্য একগুচ্ছ বিট ম্যানিপুলেশনের মাধ্যমে বার্তাটি এনক্রিপ্ট করা হয়েছে।
বার্তাটি ডিক্রিপ্ট করতে সাহায্য করার জন্য আপনাকে একটি প্রোগ্রাম লিখতে হবে।

## 1. বিটগুলো আবার পিছনে শিফট করুন

বার্তা ডিক্রিপ্ট করার প্রথম ধাপ হলো এনক্রিপশন প্রক্রিয়ার শিফটটি বাতিল করা, অর্থাৎ বিটগুলোকে আবার বামে শিফট করা।
কত ঘর শিফট করতে হবে তা বার্তা অনুযায়ী ভিন্ন হতে পারে।

এমন একটি মেথড `Secrets.shift_back` ইমপ্লিমেন্ট করুন যেটি একটি মান এবং বামে শিফট করার ঘরসংখ্যা নেয়।

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. একটি বিট মাস্ক প্রয়োগ করুন

পরের ধাপে নির্দিষ্ট কিছু বিটের মান বের করার জন্য একটি বিট মাস্ক প্রয়োগ করা হয়।
মান এবং মাস্কের মধ্যে বিটওয়াইজ AND চালিয়ে মাস্কটি প্রয়োগ করা হয়।

এমন একটি মেথড `Secrets.apply_mask` ইমপ্লিমেন্ট করুন যেটি একটি মান নেয় এবং একটি মাস্ক প্রয়োগ করে।

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. কিছু বিট সেট করুন

বিটগুলো বামে শিফট করার ফলে কিছু নতুন 0 বিট যোগ হয়েছে।
এই নতুন বিটগুলোর কয়েকটিকে 1 করে সেট করতে হবে।
বাকিগুলো অপরিবর্তিত রেখে নির্দিষ্ট কিছু বিট 1 করে সেট করার জন্য বিটওয়াইজ OR কাজে লাগে।

এমন একটি মেথড `Secrets.set_bits` ইমপ্লিমেন্ট করুন যেটি দুটি মান নেয় এবং একটি বিটওয়াইজ OR সম্পন্ন করে।

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. রিভার্স XOR

এনক্রিপশন প্রক্রিয়ার একটি অংশে একটি সম্মত মানের সাথে XOR প্রয়োগ করা হয়।
মূল মানে ফিরে যেতে চাইলে এনক্রিপ্ট করা মানটির সাথে আবার সম্মত মানটি XOR করলেই হবে।
তবে একটি ভুল বোঝাবুঝির কারণে, XOR প্রয়োগ করার আগে আপনার বন্ধু সম্মত মানটির বিটগুলো উল্টে ফেলেছেন (অর্থাৎ সম্মত মানটির উপর বিটওয়াইজ NOT প্রয়োগ করেছেন)।

এমন একটি মেথড `Secrets.reverse_xor` ইমপ্লিমেন্ট করুন যেটি এনক্রিপ্ট করা ও সম্মত মান দুটি নেয় এবং মূল মানটি গণনা করে।

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
