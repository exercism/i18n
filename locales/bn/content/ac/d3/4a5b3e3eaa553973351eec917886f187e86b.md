# নির্দেশাবলি

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট নিম্নরূপ: `"[<LVL>]: <MESSAGE>"`।

লগ লেভেলগুলো নিম্নরূপ:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

আপনার তিনটি কাজ আছে, প্রয়োজনীয় কার্যকারিতা সরবরাহ করতে এগুলোর প্রত্যেকটি সম্পন্ন করতে হবে।

## 1. LogLevel enum তৈরি করুন

এমন একটি `LogLevel` enum ডিফাইন করুন, যার উপরের লগ লেভেলগুলোর সাথে মিলে যাওয়া ছয়টি কেস থাকবে, এবং যেসব লেভেল অনুপস্থিত বা নন-স্ট্যান্ডার্ড, তাদের জন্য একটি unknown কেসও থাকবে।

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. লগ লেভেল পার্স করুন

এরপর, একটি লগ লাইনের লগ লেভেল পার্স করার জন্য `LogLevel`-এর ইনিশিয়ালাইজার ইমপ্লিমেন্ট করুন:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. লগ লাইনকে শর্ট ফরম্যাটে রূপান্তর করুন

একটি লগ লাইনের লগ লেভেল বেশ লম্বা হয়।
লগ লাইনগুলো সংরক্ষণ করতে প্রয়োজনীয় ডিস্ক স্পেস কমাতে একটি শর্ট ফরম্যাট তৈরি করা হয়েছে: `"<ENCODED_LEVEL>:<MESSAGE>"`।

এনকোড করা লগ লেভেল হলো একটি লগ লেভেলের সাথে একটি সংখ্যার সহজ ম্যাপিং:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

`shortFormat(message: String) -> String` মেথডটি ইমপ্লিমেন্ট করুন, যা সংক্ষিপ্ত লগ লাইন ফরম্যাটকে একটি `String` হিসেবে আউটপুট দিতে পারবে:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
