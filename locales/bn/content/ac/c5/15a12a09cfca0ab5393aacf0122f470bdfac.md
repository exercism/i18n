# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | প্রদত্ত সংখ্যা                  |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড ফলাফল স্ট্রিং |
| `$t0-9`  | টেম্পোরারি    | যেকোনো     | টেম্পোরারি স্টোরেজের জন্য         |
