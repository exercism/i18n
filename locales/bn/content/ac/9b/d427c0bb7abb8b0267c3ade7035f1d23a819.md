# `_is` ও প্রশ্নচিহ্নসহ `defmacro`

Elixir-এর নির্দিষ্ট কিছু নামকরণের নিয়ম আছে, যার মধ্যে রয়েছে [বুলিয়ান রিটার্ন করে এমন ফাংশনের নামকরণ](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) এবং [বুলিয়ান রিটার্ন করে ও গার্ড ক্লজে বৈধ এমন চেকের নামকরণ](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> বুলিয়ান রিটার্ন করে এমন ফাংশনের নামের শেষে একটি প্রশ্নচিহ্ন থাকে।

> টাইপ চেক এবং গার্ড ক্লজে অনুমোদিত অন্যান্য বুলিয়ান চেকের নামের শুরুতে `is_` প্রিফিক্স থাকে।

ম্যাক্রো উভয় প্রসঙ্গেই ব্যবহার করা যায়, তাই নোটেশনটি কোন প্রসঙ্গে ব্যবহার হচ্ছে তার উপর নির্ভর করে, কিন্তু দুটি নামকরণের নিয়ম কখনও মেশানো যাবে না।

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
