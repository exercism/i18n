# ওনারশিপ

Cairo-তে ওনারশিপের ধারণাটি _ভ্যারিয়েবল_-এর সাথে যুক্ত, ভ্যারিয়েবলগুলো যে _মান_ ধারণ করে তার সাথে নয়।

Cairo-তে মান অপরিবর্তনীয়; এই অপরিবর্তনীয়তা নিশ্চিত করে যে অনেক ভ্যারিয়েবল একই মানে নির্দেশ করলেও মানটি নিজে স্থির ও অপরিবর্তিত থাকে।
তাই প্রোগ্রামার যেন সেগুলো সঠিকভাবে ব্যবহার করেন, তা কম্পাইলারকে নিশ্চিত করতে হয়।
এটাই ভ্যারিয়েবলের _ওনারশিপ_-এর অর্থ: মালিক হলো সেই কোড, যা ভ্যারিয়েবলটি পড়তে পারে (আর মিউটেবল হলে লিখতেও পারে)।

## ভ্যারিয়েবল ওনারশিপের নিয়ম

```console
1. Each variable in Cairo has an owner.
2. There can only be one owner at a time.
3. When the owner goes out of scope, the variable is destroyed.
```

## ভ্যারিয়েবলের স্কোপ

স্কোপ হলো একটি প্রোগ্রামের ভেতরের সেই পরিসর, যেখানে একটি ভ্যারিয়েবল বৈধ।
চলুন নিচের উদাহরণটি দেখি, যেখানে আনসাইনড ইন্টিজার টাইপের একটি `x` ভ্যারিয়েবল ডিক্লেয়ার করা হয়েছে এবং কমেন্টে খেয়াল রাখা হয়েছে কোথায় ভ্যারিয়েবলটি বৈধ:

```rust
fn main() {
                      // `x` is not valid here, it has not been declared yet
    let x: u32 = 3;   // `x` is declared, it is valid from this point forward
                      // do stuff with `x`

} // this scope ended here, `x` goes out of scope and is no longer valid
```

লক্ষণীয়:

- `x` যখন স্কোপে আসে, তখন এটি বৈধ।
- এটি স্কোপের বাইরে চলে যাওয়া পর্যন্ত বৈধ থাকে, এই ক্ষেত্রে `main()` ফাংশনের শেষ পর্যন্ত।

## মান মুভ করা

একটি মুভ ঘটে যখন একটি মান অন্য একটি ফাংশনে পাস করা হয়; এতে মানটিকে নির্দেশ করা মূল ভ্যারিয়েবলটি ধ্বংস হয়ে যায় (ফলে ভ্যারিয়েবলটি অকেজো হয়ে পড়ে) এবং একই মান ধারণ করার জন্য একটি নতুন ভ্যারিয়েবল তৈরি হয়।

অ্যারে হলো এমন একটি কমপ্লেক্স টাইপের উদাহরণ, যা অন্য একটি ফাংশনে পাস করার সময় মুভ হয়।
এখানে সংক্ষেপে মনে করিয়ে দেওয়া হলো অ্যারে দেখতে কেমন হয়:

```rust
    let mut arr: Array<u128> = array![];
    arr.append(1);
    arr.append(2);
```

টাইপ সিস্টেম কীভাবে নিশ্চিত করে যে Cairo প্রোগ্রাম কখনো একই মেমরি সেলে দুবার লেখার চেষ্টা করে না?
নিচের কোডটি দেখুন, যেখানে আমরা অ্যারের সামনের অংশটি দুবার সরিয়ে ফেলার চেষ্টা করছি:

```rust
fn foo(mut arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let arr: Array<u128> = array![1];
    foo(arr);
    foo(arr); // -> compiler error: Variable was previously moved.
}
```

এক্ষেত্রে আমরা একই মান (অর্থাৎ `arr` ভ্যারিয়েবলের অ্যারে) দুটি ফাংশন কলে-ই পাস করার চেষ্টা করছি।
এর অর্থ আমাদের কোড প্রথম এলিমেন্টটি দুবার সরিয়ে ফেলতে চাইছে, যা একই মেমরি সেলে দুবার লেখার চেষ্টা করবে, আর Cairo VM এটি নিষিদ্ধ করে, ফলে একটি রানটাইম এরর ঘটে।
ভাগ্যক্রমে, এই কোডটি আসলে কম্পাইল হয় না।
একবার আমরা অ্যারেটি `foo` ফাংশনে পাস করে ফেললে, `arr` ভ্যারিয়েবলটি আর ব্যবহারযোগ্য থাকে না।
আমরা এই কম্পাইল-টাইম এররটি পাই, যা বলে যে আমাদের `Array`-কে `Copy` ট্রেইট ইমপ্লিমেন্ট করতে হবে:

## Copy ট্রেইট

কোনো টাইপ যদি `Copy` ট্রেইট ইমপ্লিমেন্ট করে, তাহলে সেটি একটি ফাংশনে পাস করলে মানটি মুভ হয় না, বরং একই মানে নির্দেশ করা একটি নতুন ভ্যারিয়েবল তৈরি হয়।
এটি একটি ফ্রি অপারেশন, কারণ ভ্যারিয়েবল হলো Cairo-এর একটি অ্যাবস্ট্রাকশন আর মান সবসময়ই অপরিবর্তনীয়।

আপনার টাইপে `Copy` ট্রেইট ইমপ্লিমেন্ট করতে, টাইপ ডেফিনিশনে `#[derive(Copy)]` অ্যানোটেশনটি যোগ করুন।
তবে, টাইপটি বা তার কোনো উপাদান যদি `Copy` ট্রেইট ইমপ্লিমেন্ট না করে, তাহলে Cairo এটি অনুমোদন করবে না।

```rust
#[derive(Copy, Drop)]
struct Point {
    x: u128,
    y: u128,
}

fn main() {
    let p1 = Point { x: 5, y: 10 };
    foo(p1);
    foo(p1);
}

fn foo(p: Point) { // do something with p
}
```

## মান ধ্বংস করা

লিনিয়ার টাইপগুলোকে ধ্বংস করার মাধ্যমেও কাজে লাগানো যায়, যা নিশ্চিত করে যে সংশ্লিষ্ট রিসোর্সটি সঠিকভাবে মুক্ত করা হয়।
এটি সম্পন্ন হয় `Drop` ট্রেইট ইমপ্লিমেন্ট বা ডিরাইভ করার মাধ্যমে, যা কম্পাইলারকে জানায় যে টাইপটি আর কাজে না লাগলে নিরাপদে ধ্বংস করা যায়।

```rust
#[derive(Drop)]
struct A {}

fn main() {
    A {}; // this value can be destroyed after going out of scope
}
```

এই মুহূর্তে, সব টাইপের জন্যই `Drop` ইমপ্লিমেন্টেশন ডিরাইভ করা যায়, শুধু ডিকশনারি (`Felt252Dict`) আর ডিকশনারি ধারণ করা টাইপগুলো ছাড়া।
এর কারণ হলো ডিকশনারি ধ্বংস করার সময় সেগুলোকে "স্কোয়াশ" করতে হয়।
এর জন্য আমরা `Destruct` ট্রেইট ডিরাইভ করি:

```rust
#[derive(Destruct)]
struct A {
    dict: Felt252Dict<u128>
}

fn main() {
    A { dict: Default::default() };
}
```

## রিটার্ন ভ্যালু ও স্কোপ

মান রিটার্ন করা তাদের মুভ করার সমতুল্য।
নিচের উদাহরণটি এমন একটি ফাংশন দেখায়, যা একটি মান রিটার্ন করে:

```rust
#[derive(Drop)]
struct A {}

fn main() {
    let a1 = gives_ownership();           // gives_ownership moves its return
                                          // value into a1

    let a2 = A {};                        // a2 comes into scope

    let a3 = takes_and_gives_back(a2);    // a2 is moved into
                                          // takes_and_gives_back, which also
                                          // moves its return value into a3

} // Here, a3 goes out of scope and is dropped. a2 was moved, so nothing
  // happens. a1 goes out of scope and is dropped.

fn gives_ownership() -> A {               // gives_ownership will move its
                                          // return value into the function
                                          // that calls it

    let some_a = A {};                    // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}

// This function takes an instance some_a of A and returns it
fn takes_and_gives_back(some_a: A) -> A { // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}
```
