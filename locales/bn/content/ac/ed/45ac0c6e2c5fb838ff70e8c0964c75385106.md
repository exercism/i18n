# অনুশীলনী সমাধান

Exercism আপনাকে শিখতে সাহায্য করে প্রধানত অনুশীলনী সমাধান করার মাধ্যমে।

Exercism-এ অনুশীলনী সমাধান করার দুটি উপায় রয়েছে:

1. [ওয়েবসাইটের ব্রাউজার এডিটর দিয়ে অনলাইনে](/docs/using/solving-exercises/using-the-online-editor)
2. [CLI-এর মাধ্যমে নিজের কম্পিউটারে](/docs/using/solving-exercises/working-locally)

## কোনটি বেছে নেব?

অনলাইন এডিটর আর CLI ব্যবহারের মধ্যে সুবিধা-অসুবিধার কিছু পার্থক্য আছে:

|            | অনলাইন এডিটর                          | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| ইনস্টল করা | লাগে না                                | লাগে (যেমন SDK)                              |
| এডিট করা   | ব্রাউজার                               | আপনার পছন্দের এডিটর                          |
| Test করা   | ওয়েবসাইটে Test রান করা                | নিজের কম্পিউটারে Test রান করা                |
| Debug করা  | সীমিত সাপোর্ট (শুধু কিছু ট্র্যাকের জন্য) | সম্পূর্ণ সাপোর্ট (আপনার পরিবেশের উপর নির্ভর করে) |

সাধারণভাবে বলতে গেলে, নতুন ট্র্যাক শুরু করার জন্য অনলাইন এডিটরটাই আদর্শ, আর আপনি যদি নিজের ব্যক্তিগত প্রোগ্রামিং পরিবেশ ব্যবহার করতে চান, তাহলে CLI-ভিত্তিক পদ্ধতিটি দারুণ।
