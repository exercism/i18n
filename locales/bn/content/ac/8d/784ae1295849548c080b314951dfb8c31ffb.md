# date value ব্যবহার করবেন না

[`Date#valueOf`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf)-এর বদলে [`Date#getTime`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime) ব্যবহার করুন। এরা কার্যকারিতার দিক থেকে একই, তবে `valueOf` সম্পর্কে ডকুমেন্টেশনে লেখা আছে:

> এই মেথডটি সাধারণত JavaScript নিজেই ভেতরে ভেতরে কল করে, কোডে সরাসরি নয়।
