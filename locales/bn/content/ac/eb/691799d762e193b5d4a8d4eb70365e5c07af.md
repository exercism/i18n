# নির্দেশাবলি

Bob একজন আর্থিক উপদেষ্টা এবং মানুষকে তাদের খরচ সামলাতে সাহায্য করেন।
Bob-এর ক্লায়েন্টরা বিশ্লেষণের জন্য তাঁকে খরচের রেকর্ড পাঠান।
Bob-এর কাছে আগের সময়কালগুলোর রেকর্ড থাকে, যাতে তিনি খরচের পরিবর্তন দেখতে পারেন।
Bob ক্যালেন্ডার পছন্দ করেন না এবং তারিখের বদলে *Bob epoch* ব্যবহার করেন।
*Bob epoch* হলো Bob-এর ক্লায়েন্ট তাদের কাজ শুরু করার পর যত দিন পেরিয়েছে সেই সংখ্যা।

এই অনুশীলনীতে আপনি এমন একটি প্রোগ্রাম তৈরি করবেন, যা Bob-কে তাঁর ক্লায়েন্টদের খরচ সামলাতে ও বিশ্লেষণ করতে সাহায্য করবে।

Bob `Record` ও `DaysPeriod` নিয়ে কাজ করেন।

একটি `Record` হলো একটি খরচের রেকর্ড, যাতে থাকে খরচটি যে দিনে করা হয়েছে সেই দিন, খরচ করা টাকার পরিমাণ এবং খরচের ক্যাটাগরি।

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

একটি `DaysPeriod` হলো দিনের একটি পরিসর, যাতে `From` দিন থেকে `To` দিন পর্যন্ত সব দিন ধরা হয়।
পরিসরে দুই প্রান্তই ধরা হয়।

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. সাধারণ রেকর্ড ফিল্টার তৈরি করুন

Bob প্রতিদিন অনেক রেকর্ড নিয়ে কাজ করেন, কিন্তু তিনি যে বিশ্লেষণ করছেন তার উপর নির্ভর করে সেগুলোর সবগুলোই আকর্ষণীয় নয়।
চলুন Bob-কে রেকর্ডের কিছু মৌলিক ফিল্টারিং করতে সাহায্য করি।

এমন একটি ফাংশন দিয়ে দেওয়া মানদণ্ড অনুযায়ী রেকর্ড ফিল্টার করার জন্য জেনেরিক `Filter` ফাংশনটি তৈরি করুন।
এই ফিল্টার ফাংশনটি রেকর্ডের একটি সংগ্রহ ও একটি প্রেডিকেট ফাংশন নেয় এবং কেবল সেই রেকর্ডগুলো ফেরত দেয়, যেগুলো প্রেডিকেটটি সন্তুষ্ট করে।

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. একটি সময়কালের মধ্যে রেকর্ড ফিল্টার করুন

Bob-কে প্রায়ই এমন রেকর্ড ফিল্টার করতে হয়, যেগুলো একটি নির্দিষ্ট সময়কালের মধ্যে আছে।

`ByDaysPeriod` ফাংশনটি তৈরি করুন, যা Bob-কে এমন ফিল্টার বানাতে সাহায্য করবে।
এই ফাংশনটি একটি `DaysPeriod` নেয় এবং এমন একটি ফাংশন ফেরত দেয়, যা একটি রেকর্ড নিয়ে বলে দেয় রেকর্ডটি আর্গুমেন্ট হিসেবে দেওয়া `DaysPeriod`-এর নির্দিষ্ট সময়কালের মধ্যে আছে কি না।

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. ক্যাটাগরি অনুযায়ী রেকর্ড ফিল্টার করুন

সময়কাল অনুযায়ী রেকর্ড ফিল্টার করার পাশাপাশি Bob-কে রেকর্ডের ক্যাটাগরি অনুযায়ীও ফিল্টার করতে হয়।

`ByCategory` ফাংশনটি তৈরি করুন, যা Bob-কে এমন ফিল্টার বানাতে সাহায্য করবে।
এই ফাংশনটি একটি ক্যাটাগরি নেয় এবং এমন একটি ফাংশন ফেরত দেয়, যা একটি রেকর্ড নিয়ে বলে দেয় রেকর্ডটির ক্যাটাগরি আর্গুমেন্ট হিসেবে দেওয়া ক্যাটাগরির সঙ্গে একই কি না।

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. একটি সময়কালে মোট খরচের পরিমাণ হিসাব করুন

Bob একটি সময়কালের মধ্যে মোট খরচের পরিমাণও জানতে চান।

দিনের সময়কালে খরচের যোগফল ফেরত দিতে `TotalByPeriod` ফাংশনটি তৈরি করুন।

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. একটি সময়কালে একটি ক্যাটাগরির রেকর্ডের মোট খরচ হিসাব করুন

Bob তাঁর ক্লায়েন্টদের জন্য যে সবচেয়ে জটিল রিপোর্টগুলো তৈরি করেন, তার জন্য তাঁকে একইসঙ্গে ক্যাটাগরি ও সময়কাল অনুযায়ী রেকর্ড ফিল্টার করতে হয়।
অর্থাৎ Bob একটি নির্দিষ্ট সময়কালে একটি ক্যাটাগরির রেকর্ডের মোট খরচ জানতে চান।

`CategoryExpenses` ফাংশনটি তৈরি করুন, যা একটি নির্দিষ্ট দিন-সময়কালে একটি ক্যাটাগরির মোট খরচের পরিমাণ ফেরত দেয়।
ফাংশনটির উচিত দেওয়া ক্যাটাগরিটি খরচের রেকর্ডে না থাকার ক্ষেত্রটি এবং দেওয়া সময়কালে ওই ক্যাটাগরির কোনো খরচ না থাকার ক্ষেত্রটি আলাদা করে চেনা।
যখন ক্যাটাগরিটি কোনো রেকর্ডেরই ক্যাটাগরি নয় (সময়কাল যাই হোক), তখন ফাংশনটির একটি এরর ফেরত দেওয়া উচিত।

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
