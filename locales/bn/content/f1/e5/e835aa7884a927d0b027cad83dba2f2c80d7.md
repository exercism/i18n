# টপ লেভেলে কনস্ট্যান্ট আলাদা করে রাখা ভালো

কনস্ট্যান্টটি টপ লেভেল স্কোপে আলাদা করে রাখার কথা ভাবুন:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

শুধু `export` করা ফাংশন, ক্লাস আর কনস্ট্যান্টগুলোই বাইরে থেকে দেখা যায় এবং অ্যাক্সেস করা যায়।
এই কনস্ট্যান্টগুলো অন্য কোনো কোডের কাছে উন্মুক্ত না হয়েও একই ফাইলে থাকতে পারে।
এছাড়া, কনস্ট্যান্ট আলাদা করে রাখলে মেমোরি বাঁচে, কারণ একই কনস্ট্যান্টগুলো আবার ব্যবহার করলে ফাংশনে বারবার অ্যালোকেশন এড়ানো যায়।
