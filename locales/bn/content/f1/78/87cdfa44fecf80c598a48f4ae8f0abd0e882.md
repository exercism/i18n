# Unison-এর মূল বিষয়

## টার্ম ও ফাংশন

Unison প্রোগ্রাম লেখার মূল একক হলো টার্ম ও ফাংশন।

"টার্ম" বলতে আমরা একটি স্ট্যাটিক মানকে বুঝি। এটি `name = expression` দিয়ে ডিফাইন করা হয়, আর চাইলে তার আগে `name : MyType` ফর্মের একটি টাইপ সিগনেচার বসানো যায়। Unison টাইপ ইনফারেন্স সমর্থন করে, তাই সাধারণ ডেফিনিশনে টাইপ সিগনেচার বাদ দেওয়া থাকতে পারে।

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

Unison ফাংশন দেখতে `myFunctionName argument1 argument2 = myImplementation`-এর মতো হয়; এরা ফাংশনের নাম দিয়ে শুরু হয়, তারপর স্পেস দিয়ে আলাদা করা আর্গুমেন্ট থাকে।

```
getMax a b = Nat.max a b
```

ফাংশনে চাইলে একটি টাইপ সিগনেচার রাখা যায়। ডান দিকের শেষ টাইপটিই সবসময় ফাংশনের চূড়ান্ত রিটার্ন টাইপ, আর প্রতিটি আর্গুমেন্ট আলাদা করা হয় ফাংশন অ্যারো `->` দিয়ে।

```
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

কোনো ফাংশন কল করতে হলে তার নাম লিখুন, তারপর শুধু স্পেস দিয়ে আলাদা করা আর্গুমেন্ট দিন।

```
maximum = getMax 1 10
```

ফাংশন কল করার সময়, ঠিক ডান দিকে যা-ই থাকে Unison সেটিকে তার আর্গুমেন্ট হিসেবে ধরার চেষ্টা করে; ফলে ফাংশন কী ক্রমে ইভ্যালুয়েট হবে সেটা সবসময় কাঙ্ক্ষিত নাও হতে পারে।

ধরুন, আমরা নিচের এক্সপ্রেশন থেকে `1` মানটি পেতে চাই

```
shouldBe1 = getMax 1 10 - 10
```

যেভাবে লেখা আছে, `shouldBe1` ইভ্যালুয়েট হয় `0`-এ, কারণ এখানে অনুমিত ফাংশন অ্যাপ্লিকেশনের ক্রমটি হলো `getMax 1 10`, যার মান `10`, তারপর `10 - 10`, যার মান `0`।

বন্ধনী ব্যবহার করে এক্সপ্রেশনটি আবার সাজিয়ে অপারেশনগুলোর কাঙ্ক্ষিত ক্রমে আনা যায়।

```
shouldBe1 = getMax 1 (10 - 10)
```

## মাল্টি-লাইন ফাংশন

Unison-এর মাল্টি-লাইন ফাংশনে ইনডেন্টেশন বা `let` ব্লক দিয়ে কোডের সীমানা নির্ধারণ করা হয়, যাকে "লেক্সিক্যাল স্কোপ" বলা হয়।

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

একই ইনডেন্টেশন স্তরে থাকা সবকিছু একই স্কোপ ভাগ করে নেয়, তাই শেষ লাইনে আমরা `newBeginning` ভ্যারিয়েবলটি রেফারেন্স করতে পারি।

## নেমস্পেস ও `use` স্টেটমেন্ট

নেমস্পেসের মাধ্যমে আমরা Unison ফাংশনগুলো দলবদ্ধ ও সাজিয়ে রাখি। এগুলোকে "ডিরেক্টরি"-র মতো ভাবতে পারেন। এগুলো কাঠামো ও যৌক্তিক বিন্যাস দেয়।

`use` স্টেটমেন্ট দিয়ে একটি নেমস্পেসের ফাংশনগুলো স্কোপে আনা যায়।

ধরুন, আপনি এমন একটি ফাংশন লিখছেন যেখানে Unison `List` মান ব্যবহার করবেন। আপনি জানেন আপনার `List.map` ও `List.flatMap`-এর মতো ফাংশন লাগবে, যেখানে `List` হলো নেমস্পেস আর `map` ও `flatMap` হলো ফাংশন। নিজেকে বারবার না লিখতে আপনি আপনার ফাংশনে `List` নেমস্পেসের সবকিছু এভাবে লেক্সিক্যাল স্কোপে নিয়ে আসতে পারেন:

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

`use List` লাইনটি `map` ও `flatMap`-এর রেফারেন্সগুলোর অস্পষ্টতা দূর করে। [`use` স্টেটমেন্ট সম্পর্কে আরও পড়তে পারেন এখানে][use-statements]।

## Unison-এর স্ট্যান্ডার্ড লাইব্রেরি

Unison-এর স্ট্যান্ডার্ড লাইব্রেরির নাম `base`। আপনি যদি কুইকস্টার্ট গাইড অনুসরণ করে স্থানীয়ভাবে একটি কোডবেস তৈরি করে থাকেন, তাহলে স্ট্যান্ডার্ড লাইব্রেরি স্বয়ংক্রিয়ভাবে ডাউনলোড হয়ে যাওয়ার কথা। স্ট্যান্ডার্ড লাইব্রেরির ডকুমেন্টেশন অনলাইনে [Unison Share][unison-share-base]-এ ব্রাউজ করতে পারেন।

## কমেন্ট ও ডকুমেন্টেশন লিটারাল

Unison-এ কমেন্ট একটু অস্বাভাবিক একটি বৈশিষ্ট্য। Unison কোড লেখার সময় `.u` এক্সটেনশনের ফাইলে আপনি এমন টেক্সট লিখতে পারেন যা নিচের সিনট্যাক্সে ইন্টারপ্রেট হয় না:

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

_তবে_, যেহেতু Unison কোড ফাইল সিস্টেমে টেক্সট-ভিত্তিক ফাইল হিসেবে নয়, বরং তার অ্যাবস্ট্রাক্ট সিনট্যাক্স ট্রির হ্যাশ হিসেবে সংরক্ষিত হয়, তাই ফাইলে কোনো Unison ফাংশন বা টার্মের টেক্সট-ভিত্তিক "সাজসজ্জা" হিসেবে থাকা কমেন্ট আসলে সংরক্ষণ করে শেয়ার করার জন্য আবার দেখানো যায় না। আপনি যদি আপনার Unison টার্মে এমনভাবে কোনো তথ্য যোগ করতে চান যা অন্যদের পড়ার ও বোঝার জন্য সংরক্ষিত থাকবে, তাহলে ডকুমেন্টেশন লিটারাল ব্যবহার করতে পারেন।

Unison প্রোগ্রামিং ভাষায় ডকুমেন্টেশন একটি ফার্স্ট-ক্লাস মান। এর মানে হলো একটি `Doc` এলিমেন্ট কোনো মানে অ্যাসাইন করা যায়, ফাংশনে মান হিসেবে পাঠানো যায়, বা ফাংশনের মান হিসেবে রিটার্ন করা যায়। ডকুমেন্টেশন লিটারাল এলিমেন্ট খোলা ও বন্ধ করা হয় ডাবল কার্লি ব্রেস দিয়ে। এখানে দেখুন কীভাবে আমরা `Doc` এলিমেন্টকে কমেন্ট হিসেবে ব্যবহার করতে পারি।

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
