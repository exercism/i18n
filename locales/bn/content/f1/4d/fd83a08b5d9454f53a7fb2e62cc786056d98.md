# ইঙ্গিত

## সাধারণ

- চারটি কার্ডিনাল সিম্বল এবং চারটি রিলেটিভ-বিয়ারিং সিম্বল একটি `SYMBOLS:` লাইন দিয়ে ডিক্লেয়ার করুন:
  `SYMBOLS: north east south west ahead starboard behind port ;`
- প্রতিটি টাপল `TUPLE: <class> <slot1> <slot2> ;` দিয়ে ডিক্লেয়ার করা হয়।
- একটি `GENERIC:` লাইন ওয়ার্ডটি ডিক্লেয়ার করে; প্রতিটি `M:` লাইন একটি ক্লাসের জন্য একটি মেথড যোগ করে। মেথড বডিতে নামযুক্ত লোকাল চাইলে `M::` ব্যবহার করুন।

## 1. কার্ডিনালের জন্য `>cartesian`

- চারটি দিকের সিম্বলের ওপর একটি ছোট `case` ব্যবহার করলেই যথেষ্ট।
- `{ north [ 0 1 ] }`: বডি শুধু দুটি মান পুশ করে; টেস্ট আশা করে স্ট্যাকে `y`-এর নিচে `x` থাকবে।

## 2. পোলারের জন্য `>cartesian`

- ডিগ্রি থেকে রেডিয়ানে রূপান্তর করুন: `bearing pi * 180 /`।
- `sin` ও `cos` আছে `math.functions`-এ।
- `magnitude * sin(rad)` তারপর `magnitude * cos(rad)` পুশ করুন।

## 3. রিলেটিভের জন্য `>cartesian`

- একটি ডাইনামিক ভেরিয়েবল ডিক্লেয়ার করুন: `SYMBOL: heading`।
- আপনার মেথডে `heading get` দিয়ে এটি পড়ুন।
- একটি `case` দিয়ে `ahead/starboard/behind/port`-কে `0/90/180/270` অফসেটে ম্যাপ করুন, তারপর হেডিং যোগ করুন। সেখান থেকে এটি টাস্ক ২-এর মতো একই পোলার রূপান্তর। একটি হেল্পার আলাদা করার কথা ভাবুন: `: deg>cartesian ( magnitude bearing -- x y ) ... ;`।

## 4. `flip`

- `cardinal`-এর ওপর `change-direction` এবং `polar` বা `relative`-এর ওপর `change-bearing` একটি স্লট পরিবর্তন করে একটি নতুন টাপল তৈরি করে, বাকিটা অপরিবর্তিত রাখে: `[ <transformation-quotation> ] change-bearing`।
- `polar`-এর ঘূর্ণনের জন্য: `[ 180 + 360 mod ] change-bearing`।

## 5. `add-bearings`

- প্রতিটি ইনপুটে `>cartesian` কল করুন, তারপর x-কম্পোনেন্ট ও y-কম্পোনেন্ট যোগ করুন। লোকাল ব্যবহার করলে এটি পড়া সহজ হয়:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
