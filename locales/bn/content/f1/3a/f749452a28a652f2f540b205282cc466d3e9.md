# ভূমিকা

## তুলনা

### সংখ্যার তুলনা

`jq`-তে নিচের সম্পর্কমূলক ও সমতা অপারেটরগুলো দিয়ে সংখ্যা তুলনা করা যায়।

| তুলনা              | অপারেটর |
| ---------------------- | -------- |
| এর চেয়ে বড়           | `a > b`  |
| এর চেয়ে বড় বা সমান | `a >= b` |
| এর চেয়ে ছোট              | `a < b`  |
| এর চেয়ে ছোট বা সমান    | `a <= b` |
| সমান                 | `a == b` |
| অসমান                 | `a != b` |

তুলনার ফলাফল সবসময়ই একটি বুলিয়ান মান, অর্থাৎ হয় `true` নয়তো `false`।

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### স্ট্রিংয়ের তুলনা

উপরের তুলনা অপারেটরগুলো দিয়ে স্ট্রিংও তুলনা করা যায়।
সেক্ষেত্রে অভিধানিক (লেক্সিকোগ্রাফিক্যাল) ক্রম প্রয়োগ করা হয়।
ক্রমটি _ইউনিকোড কোডপয়েন্ট মান অনুসারে_।

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

দুটি ভ্যারিয়েবলের তুলনা করার সময় সাবধান থাকতে হবে, যেগুলো দেখতে সংখ্যাসূচক মান ধারণ করছে মনে হলেও আসলে স্ট্রিং টাইপের।
অভিধানিক ক্রমের কারণে ফলাফল সংখ্যা টাইপের মানের তুলনার মতো হবে না।

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### "কঠোর" সমতা

`jq`-এর `==` অপারেটরটি Javascript-এর `===`-এর মতো: যা দেখতে একই রকম মনে হয় কিন্তু ভিন্ন টাইপের, তা সমান নয়।

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### অ্যারের তুলনা

দুটি অ্যারে সমান হয় যদি তাদের সব সংশ্লিষ্ট এলিমেন্ট সমান হয়।

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### অবজেক্টের তুলনা

দুটি অবজেক্ট সমান হয় যদি তাদের একই কী (key)-ভ্যালু জোড়া থাকে।

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## কন্ডিশনাল

### if এক্সপ্রেশন

`jq`-এর **শর্তাধীন এক্সপ্রেশন** হলো `if A then B else C end`।

`if-then-else` হলো `jq`-এর অন্য সব বিল্ট-ইনের মতোই একটি ফিল্টার: এটি একটি ইনপুট নেয় এবং একটি আউটপুট তৈরি করে।

যদি `A` এক্সপ্রেশনটি একটি "ট্রুথি" মান তৈরি করে, তাহলে `if` ফিল্টার `B` ইভ্যালুয়েট করে।
নাহলে এটি `C` ইভ্যালুয়েট করে।
`if` ফিল্টারের ইনপুট `B` বা `C`-তে পাঠানো হয়।

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else` ক্লজটি **ঐচ্ছিক**; নিচের দুটি স্টেটমেন্ট সমতুল্য।

```jq
if A then B else . end
if A then B end
```
~~~~

### নেস্টেড if-স্টেটমেন্ট

`elif` দিয়ে আরও শর্ত যোগ করা যায়।

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

যতগুলো দরকার ততগুলো `elif` ক্লজ ব্যবহার করুন।

### ট্রুথিনেস

`jq`-এ একমাত্র "false" মান হলো `false` আর `null`।
বাকি সবকিছুই "true", এমনকি শূন্য সংখ্যাটি, খালি স্ট্রিং, খালি অ্যারে আর খালি অবজেক্টও।

### বুলিয়ান অপারেটর

জটিল কোয়েরি তৈরি করতে **বুলিয়ান অপারেটর** `and` আর `or` ব্যবহার করা যায়।

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

নেগেট করতে `not` ব্যবহার করুন। এটি একটি **ফিল্টার**, অপারেটর নয়।

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### অল্টারনেটিভ অপারেটর

**অল্টারনেটিভ অপারেটর** দিয়ে কোনো এক্সপ্রেশন false বা null হলে একটি "ডিফল্ট" মান নির্দিষ্ট করা যায়।

```jq
A // B

# This is identical to
if A then A else B end
```

উদাহরণ হিসেবে

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
