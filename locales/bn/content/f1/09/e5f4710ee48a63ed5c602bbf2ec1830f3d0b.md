# নির্দেশনা

আপনি একটি অভিজাত রেস্তোরাঁর ম্যানেজার, আর সেই রেস্তোরাঁয় আছে বেশ বড় একটি ওয়াইনের ভান্ডার। আপনার অনেক গ্রাহকই ওয়াইনের ব্যাপারে খুব খুঁটিনাটি পছন্দ করেন। নির্দিষ্ট একজন গ্রাহকের জন্য ঠিক সঠিক ওয়াইনের বোতলটি খুঁজে বের করা সহজ কাজ নয়।

টেক-সচেতন রেস্তোরাঁ মালিক হিসেবে আপনি ঠিক করেছেন, গ্রাহকদের পছন্দ অনুযায়ী ওয়াইন ফিল্টার করার একটি অ্যাপ লিখে ওয়াইন বাছাইয়ের কাজটি দ্রুত করবেন।

## 1. ওয়াইনের রং ব্যাখ্যা করুন

আপনার অ্যাপের স্বাগত স্ক্রিনে প্রতিটি ওয়াইনের রঙের একটি ছোট ব্যাখ্যা দেখাতে চান।

`WineCellar.explain_colors/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি কোনো আর্গুমেন্ট নেয় না এবং ওয়াইনের রংগুলোকে কী(key) আর ব্যাখ্যাগুলোকে ভ্যালু হিসেবে নিয়ে একটি কিওয়ার্ড লিস্ট রিটার্ন করে।

| রং       | ব্যাখ্যা                                                                    |
| -------- | -------------------------------------------------------------------------- |
| `:white` | Fermented without skin contact.                                            |
| `:red`   | Fermented with skin contact using dark-colored grapes.                     |
| `:rose`  | Fermented with some skin contact, but not enough to qualify as a red wine. |

## 2. নির্দিষ্ট একটি রঙের সব ওয়াইন পান

ওয়াইনের একটি বোতলকে আঙুরের জাত, বছর আর উৎপত্তির দেশ — এই তিনটি এলিমেন্টের একটি ৩-টিউপল হিসেবে প্রকাশ করা হয়। ওয়াইনগুলো ওয়াইনের রং অনুযায়ী একটি কিওয়ার্ড লিস্টে সংরক্ষণ করা হয়।

```elixir
[
  white: {"Chardonnay", 2015, "Italy"},
  white: {"Pinot grigio", 2017, "Germany"},
  red: {"Pinot noir", 2016, "France"},
  rose: {"Dornfelder", 2018, "Germany"}
]
```

`WineCellar.filter/3` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ওয়াইনগুলোর একটি কিওয়ার্ড লিস্ট, একটি রং অ্যাটম এবং অপশনগুলোর একটি কিওয়ার্ড লিস্ট নেবে, যার ডিফল্ট মান `[]`। ফাংশনটি নির্দিষ্ট একটি রঙের ওয়াইনগুলোর একটি লিস্ট রিটার্ন করবে।

```elixir
WineCellar.filter(
  [
    white: {"Chardonnay", 2015, "Italy"},
    white: {"Pinot grigio", 2017, "Germany"},
    red: {"Pinot noir", 2016, "France"},
    rose: {"Dornfelder", 2018, "Germany"}
  ],
  :white
)

# => [
#      {"Chardonnay", 2015, "Italy"},
#      {"Pinot grigio", 2017, "Germany"}
#    ]
```

## 3. নির্দিষ্ট একটি রঙের এবং নির্দিষ্ট একটি বছরে বোতলজাত সব ওয়াইন পান

`WineCellar.filter/3` ফাংশনটি বাড়িয়ে লিখুন। একটি `:year` অপশন দেওয়া হলে ফাংশনটি নির্দিষ্ট একটি রঙের এবং নির্দিষ্ট একটি বছরের ওয়াইনগুলোর একটি লিস্ট রিটার্ন করবে।

আগেই ইমপ্লিমেন্ট করা `WineCellar.filter_by_year/2` ফাংশনটি ব্যবহার করুন। এটি আর্গুমেন্ট হিসেবে ওয়াইনগুলোর একটি লিস্ট আর একটি বছর নেয় এবং নির্দিষ্ট একটি বছরের ওয়াইনগুলোর একটি লিস্ট রিটার্ন করে।

```elixir
WineCellar.filter(
  [
    white: {"Chardonnay", 2015, "Italy"},
    white: {"Pinot grigio", 2017, "Germany"},
    red: {"Pinot noir", 2016, "France"},
    rose: {"Dornfelder", 2018, "Germany"}
  ],
  :white,
  year: 2015
)

# => [
#      {"Chardonnay", 2015, "Italy"}
#    ]
```

## 4. নির্দিষ্ট একটি রঙের এবং নির্দিষ্ট একটি দেশে বোতলজাত সব ওয়াইন পান

`WineCellar.filter/3` ফাংশনটি বাড়িয়ে লিখুন। একটি `:country` অপশন দেওয়া হলে ফাংশনটি নির্দিষ্ট একটি রঙের এবং নির্দিষ্ট একটি দেশের ওয়াইনগুলোর একটি লিস্ট রিটার্ন করবে।

আগেই ইমপ্লিমেন্ট করা `WineCellar.filter_by_country/2` ফাংশনটি ব্যবহার করুন। এটি আর্গুমেন্ট হিসেবে ওয়াইনগুলোর একটি লিস্ট আর একটি দেশ নেয় এবং নির্দিষ্ট একটি দেশের ওয়াইনগুলোর একটি লিস্ট রিটার্ন করে।

খেয়াল রাখবেন, ফাংশনটি যখন একসাথে `:year` এবং `:country` — এই দুটি অপশনই, যেকোনো ক্রমে — পায়, তখনও যেন কাজ করে।

```elixir
WineCellar.filter(
  [
    white: {"Chardonnay", 2015, "Italy"},
    white: {"Pinot grigio", 2017, "Germany"},
    red: {"Pinot noir", 2016, "France"},
    rose: {"Dornfelder", 2018, "Germany"}
  ],
  :white,
  year: 2015,
  country: "Germany"
)

# => []
```
