# নির্দেশনা

একটি ব্যস্ত ব্যাংক অপেক্ষমাণ গ্রাহকদের সেবা দেয় তারা যে ক্রমে এসেছে সেই ক্রমে নয়, বরং *প্রায়োরিটি* অনুসারে। প্রতিটি গ্রাহক টিকিট নেওয়ার সময় একটি প্রায়োরিটি নম্বর পান, আর টেলার সবসময় পরের গ্রাহক হিসেবে সবচেয়ে কম নম্বরের জনকে সেবা দেন (`1` হলো সবচেয়ে জরুরি)। অপেক্ষার লাইনের জন্য একটি মিন-হিপ একেবারে উপযুক্ত।

## 1. কিউ খুলুন

`new-queue` ডিফাইন করুন, যা কিছুই নেয় না এবং একটি নতুন, খালি প্রায়োরিটি কিউ রিটার্ন করে।

```factor
new-queue
! => an empty priority queue
```

## 2. একজন গ্রাহক যোগ করুন

`join-queue` ডিফাইন করুন, যা একটি গ্রাহকের নাম, একটি প্রায়োরিটি নম্বর আর একটি কিউ নেয়। এটি গ্রাহককে কিউতে যোগ করে এবং কিউটি রিটার্ন করে, যাতে একের পর এক গ্রাহক যোগ করা যায়।

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. এরপর কে?

`next-name` ডিফাইন করুন, যা একটি কিউ নেয় এবং পরের গ্রাহক হিসেবে যাকে সেবা দেওয়া উচিত তার নাম রিটার্ন করে, অর্থাৎ যে গ্রাহকের প্রায়োরিটি নম্বর সবচেয়ে কম, অথচ তাকে কিউ থেকে *সরানো হয় না*।

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. সবাইকে সেবা দিন

`serve-all` ডিফাইন করুন, যা একটি কিউ নেয় এবং অপেক্ষমাণ সব গ্রাহকের নাম, যে ক্রমে তাদের সেবা দেওয়া হবে সেই ক্রমে, রিটার্ন করে।

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
