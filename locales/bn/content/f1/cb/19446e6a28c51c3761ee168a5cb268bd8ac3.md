# ভূমিকা

অনেক অন্যান্য ভাষার বিপরীতে, JavaScript-এ এমন দুটি ভিন্ন সত্তা আছে যা একটি (অর্থবহ) মানের অনুপস্থিতি বোঝায়।
সেগুলো হলো `null` এবং `undefined`।

## Null

প্রিমিটিভ মান `null` যেকোনো টাইপের ভ্যারিয়েবলের জন্য ইচ্ছাকৃত "খালি মান" হিসেবে ব্যবহার করা হয়।

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

`===` [স্ট্রিক্ট ইকুয়ালিটি অপারেটর][mdn-strict-equality] দিয়ে আপনি যাচাই করতে পারেন কোনো ভ্যারিয়েবল null কি না।

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> যে ভ্যারিয়েবলে মান অ্যাসাইন করা হয়নি, তার টাইপ `undefined`।[^1]

এর মানে হলো, `null` যেমন একটি খালি মান বোঝায় (তবুও একটি মান), `undefined` বোঝায় মানের সম্পূর্ণ অনুপস্থিতি। 🤯

`undefined` বিভিন্ন প্রসঙ্গে দেখা যায়।

- কোনো ভ্যারিয়েবল যদি কোনো মান ছাড়া (ইনিশিয়ালাইজেশন ছাড়া) ডিক্লেয়ার করা হয়, তাহলে সেটি `undefined` হয়।

  ```js
  let name;
  console.log(name); // => undefined
  ```

- আপনি যদি কোনো অবজেক্টে না-থাকা কোনো কী (key) থেকে মান অ্যাক্সেস করতে চান, তাহলে `undefined` পান।

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- কোনো ফাংশন যদি কোনো মান রিটার্ন না করে, তাহলে ফলাফল `undefined` হয়।

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- কোনো ফাংশনে যদি কোনো আর্গুমেন্ট পাঠানো না হয়, তাহলে সেটি `undefined` হয়, যদি না ওই আর্গুমেন্টের একটি ডিফল্ট মান থাকে।

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

স্ট্রিক্ট ইকুয়ালিটি অপারেটর `===` ব্যবহার করে আপনি যাচাই করতে পারেন কোনো ভ্যারিয়েবল undefined কি না।

```javascript
let name;

name === undefined;
// => true
```

## Optional Chaining

আপনি যদি কোনো অবজেক্টে নেস্টেড কোনো মান বের করার চেষ্টা করেন, কিন্তু প্যারেন্ট কী (key) না থাকে, তাহলে JavaScript একটি এরর ছুড়ে দেবে।
এটি সহজে এড়ানোর জন্য ২০২০ সালে ভাষার স্পেসিফিকেশনে অপশনাল চেইনিং যুক্ত করা হয়।
অপশনাল চেইনিং অপারেটর `?.` দিয়ে আপনি নিশ্চিত করতে পারেন যে প্যারেন্ট `null` বা `undefined` না হলে তবেই JavaScript নেস্টেড কী (key) অ্যাক্সেস করার চেষ্টা করবে।
অন্যথায় `undefined` রিটার্ন হয়।

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish Coalescing

এমন পরিস্থিতি আছে যখন আপনি কোনো ডিফল্ট মান প্রয়োগ করতে চান, যদি কোনো ভ্যারিয়েবল null বা undefined হয় (কিন্তু কেবল তখনই)।
এটা সামলানোর জন্য ২০২০ সালে নালিশ কোলেসিং অপারেটর `??` চালু করা হয়।
এটি ডান দিকের অপারেন্ড কেবল তখনই রিটার্ন করে, যখন বাম দিকের অপারেন্ড `null` বা `undefined` হয়।
অন্যথায় বাম দিকের অপারেন্ড রিটার্ন করা হয়।

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
