# পরিচিতি

[Java](https://go.java/index.html) নানা রকম কাজে ব্যবহারের সুবিধা আর সামঞ্জস্যের কারণে বর্তমানে পাওয়া সবচেয়ে জনপ্রিয় প্রোগ্রামিং ভাষাগুলোর একটি। সফটওয়্যার ডেভেলপমেন্ট, মোবাইল অ্যাপ্লিকেশন আর বড় বড় সিস্টেম তৈরিতে এটি ব্যাপকভাবে ব্যবহৃত হয়।

Java-র জন্ম ১৯৯৫ সালে, আর এর রক্ষণাবেক্ষণ করে [Oracle](https://www.oracle.com/index.html)। বাজারে থাকা নতুন নতুন ভাষাগুলোর মতো এটি ততটা তরুণ না হলেও Java এখনও সত্যিই জনপ্রিয়। এটি দ্রুত, নিরাপদ, নির্ভরযোগ্য, নতুনদের জন্য সহজ এবং সহজে এক প্ল্যাটফর্ম থেকে আরেক প্ল্যাটফর্মে বহনযোগ্য হওয়ার কথা মাথায় রেখে ডিজাইন করা হয়েছিল। এই বহনযোগ্যতার সুবিধাটি আছে কারণ Java চালানো হয় একটি ক্রস-প্ল্যাটফর্ম উপযোগী [Java Virtual Machine - JVM](https://en.wikipedia.org/wiki/Java_virtual_machine)-এ। Android অ্যাপগুলোও Java দিয়ে তৈরি করা হয়, কারণ [Android Operating System](<https://en.wikipedia.org/wiki/Android_(operating_system)>) একটি Java ভাষার পরিবেশে চালিত হয়।

Java-র কমিউনিটি বিশাল! উদাহরণ হিসেবে GitHub-এ ১৫ লক্ষেরও বেশি Java প্রজেক্ট আছে। উল্লেখ করার মতো আরেকটি বিষয় হলো, [StackOverflow](https://stackoverflow.com/questions/tagged/java)-তে Java-র কমিউনিটি দ্বিতীয় বৃহত্তম! এটি গুরুত্বপূর্ণ, কারণ কোনো প্রোগ্রামিং ভাষার কমিউনিটি যত বড় হয়, আপনি তত বেশি সহায়তা পাবেন বলে আশা করতে পারেন।

Java-তে আছে শক্তিশালী ও সুপরিকল্পিত কিছু বিল্ট-ইন [API](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) (অর্থাৎ একটি প্রোগ্রাম অন্য প্রোগ্রামের সাথে কথা বলার নিয়ম), যা ডেটাবেস সংযোগ, নেটওয়ার্কিং, I/O, XML পার্সিং, ইউটিলিটি আরও অনেক কিছুসহ নানা ধরনের কাজে ব্যবহার করা যায়।

ল্যাপটপ থেকে ডেটা সেন্টার, গেম কনসোল থেকে বৈজ্ঞানিক সুপারকম্পিউটার, মোবাইল ফোন থেকে ইন্টারনেট পর্যন্ত, [সবখানেই Java](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
