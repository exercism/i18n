# ইনস্টলেশন

## Perl সংস্করণ সম্পর্কে নোট
ট্র্যাকটি Perl-এর সর্বশেষ স্থিতিশীল রিলিজকে লক্ষ্য করে।
পুরোনো সংস্করণের Perl ব্যবহার করা সম্ভব, তবে সামঞ্জস্যের জন্য দেওয়া স্টাব ফাইলগুলোতে কিছু পরিবর্তন করার প্রয়োজন হতে পারে।
স্টাব ফাইলগুলোতে উল্লেখিত সংস্করণটি যদি আপনি ব্যবহার করতে না পারেন, তাহলে `use v5.XX;`-এর জায়গায় নিচের কোডটি বসানোর পরামর্শ দেওয়া হয়:

```perl
use strict;
use warnings;
use feature qw<signatures>;
```

স্টাব ফাইলে যদি `use experimental qw<class>;` থাকে এবং আপনি যে Perl সংস্করণটি ব্যবহার করছেন সেটি এটি সমর্থন না করে, তাহলে এর বদলে `use Feature::Compat::Class;` বসাতে পারেন, অথবা বিকল্প অবজেক্ট ওরিয়েন্টেশন সিস্টেম ব্যবহার করতে পারেন, যেমন [Moo](https://metacpan.org/pod/Moo)।

## Unix/Linux/Mac OSX
Perl সম্ভবত আগেই ইনস্টল করা আছে, তবে সেটি সর্বশেষ সংস্করণ নাও হতে পারে।
আপনার কাছে কোন সংস্করণ আছে তা দেখতে `perl -v` চালান।
আপনি যদি আরও নতুন কোনো সংস্করণ ব্যবহার করতে চান, তাহলে 'অন্যান্য অপশন' অংশটি দেখুন।

আপনি যদি Fedora/Red Hat/CentOS ব্যবহার করেন, তাহলে কিছু কোর মডিউল Perl-এর সাথে দেওয়া থাকে না।
সেগুলো ইনস্টল করতে `yum install perl-core` কমান্ডটি ব্যবহার করুন।

## Windows
[Strawberry Perl](http://strawberryperl.com/): Windows-এর জন্য ১০০% ওপেন সোর্স Perl, যা অন্য সব জায়গার Perl-এর সাথে হুবহু একই;
এতে CPAN-এর মডিউল ব্যবহার করা যায়, বাইনারি প্যাকেজের প্রয়োজন ছাড়াই।

আপনি এটি সরাসরি সাইট থেকে ইনস্টল করতে পারেন, অথবা [chocolatey প্যাকেজ ম্যানেজার](https://chocolatey.org/packages/StrawberryPerl) ব্যবহার করতে পারেন।

## অন্যান্য অপশন
* [asdf](https://asdf-vm.com/):
  একটি টুল সংস্করণ ম্যানেজার, যা দিয়ে Perl-সহ একাধিক ভাষা ইনস্টল করা যায়; এটি একটি [কমিউনিটি প্লাগইন](https://github.com/asdf-vm/asdf-plugins) হিসেবে পাওয়া যায়।
* [perlbrew](https://perlbrew.pl/):
  আপনার `$HOME` ডিরেক্টরিতে একাধিক Perl ইনস্টলেশন ম্যানেজ করার একটি টুল।
  এগুলো সম্পূর্ণ আলাদা Perl ইউনিভার্স।
* [plenv](https://github.com/tokuhirom/plenv):
  আপনার হোম ডিরেক্টরির অধীনে Perl ইনস্টল করে, স্থানীয়ভাবে মডিউল ইনস্টল করার সুযোগ দেয়, আর আপনার শেলে যেকোনো Perl সংস্করণে সুইচ করার অনুমতি দেয়।
* [ActivePerl Community Edition](https://www.activestate.com/activeperl/downloads):
  Windows, Linux ও Mac OS X-এর জন্য একটি ফ্রি, তৈরি-অবস্থায় ইনস্টলযোগ্য Perl ডিস্ট্রিবিউশন, যা সেইসব কমিউনিটি ডেভেলপার বা ওপেন সোর্স প্রকল্পের জন্য তৈরি যেগুলো ব্যবসায়িকভাবে বা মিশন-ক্রিটিক্যাল নয়।

### প্রয়োজনীয় মডিউল ইনস্টল করা
আপনি যদি 5.40-এর চেয়ে পুরোনো কোনো Perl সংস্করণ ব্যবহার করেন, তাহলে `Test2::V0` টেস্টিং বান্ডেলটি ইনস্টল করতে হবে।
OOP অনুশীলনীর জন্য `Feature::Compat::Class` অথবা একটি বিকল্প অবজেক্ট ওরিয়েন্টেশন সিস্টেমও ইনস্টল করতে হবে।
এটি সেট আপ করতে নিচের নির্দেশাবলি অনুসরণ করুন (অথবা আপনি যদি ইতিমধ্যে Perl-এর সাথে পরিচিত হন, তাহলে নিজের পছন্দের মডিউল ইনস্টলার ব্যবহার করতে পারেন):

#### local::lib
* নিশ্চিত করুন যে exercism CLI আগেই ইনস্টল ও কনফিগার করা হয়েছে।
`exercism workspace` চালালে আপনার উপযুক্ত পাথটি দেখা উচিত।

* `cpm` মডিউল ইনস্টলারটি ডাউনলোড করুন এবং সেটি দিয়েই নিজে, `local::lib`, `Test2::V0` ও `Feature::Compat::Class` আপনার `exercism/perl5` ডিরেক্টরিতে ইনস্টল করুন:
```
# *nix
curl -sL --compressed https://git.io/cpm | \
  perl - install -L $(exercism workspace)/perl5 App::cpm local::lib Test2::V0 Feature::Compat::Class

# Microsoft PowerShell
(Invoke-WebRequest -UseBasicParsing 'https://git.io/cpm').Content |
  perl - install -L "$(exercism workspace)/perl5" App::cpm local::lib Test2::V0 Feature::Compat::Class
```

* আপনি `exercism/perl5`-এ যে মডিউলগুলো ইনস্টল করেছেন সেগুলো ব্যবহার করতে আপনার এনভায়রনমেন্ট সেট আপ করতে `local::lib` চালান:
```
# *nix
eval $(perl -I$(exercism workspace)/perl5/lib/perl5 -Mlocal::lib=$(exercism workspace)/perl5)

# Microsoft PowerShell
perl -I"$(exercism workspace)/perl5/lib/perl5"
  -M"local::lib=--shelltype=powershell,$(exercism workspace)/perl5" | Invoke-Expression
```

উপরের কমান্ড থেকে হওয়া এনভায়রনমেন্ট পরিবর্তনগুলো স্থায়ী হবে না, এবং আপনি যদি আপনার শেল পুনরায় চালু করেন তাহলে সেগুলো আবার চালাতে হবে।
আপনি যদি চান প্রতিবারই আপনার এনভায়রনমেন্ট স্বয়ংক্রিয়ভাবে সেট আপ হোক, তাহলে উপরের কমান্ডটি যোগ করতে আপনার `.bashrc` (বা \*nix-এর সমতুল্য ফাইল) অথবা আপনার `PowerShell_profile.ps1` সম্পাদনা করুন।

local::lib-এর ডকুমেন্টেশন [এখানে](https://perldoc.perl.org/local::lib) পাওয়া যাবে।

#### OS প্যাকেজ
বিকল্পভাবে, আপনার OS-এর প্যাকেজ ম্যানেজারে ইনস্টল করার জন্য একটি Test2 Suite প্যাকেজ থাকতে পারে।
যেসব অপশন পাওয়া যায়:

* Ubuntu: [libtest2-suite-perl](https://launchpad.net/ubuntu/+source/libtest2-suite-perl)
* Debian: [libtest2-suite-perl (via backports)](https://packages.debian.org/stretch-backports/libtest2-suite-perl)
* Arch: [perl-test2-suite](https://www.archlinux.org/packages/community/any/perl-test2-suite/)
