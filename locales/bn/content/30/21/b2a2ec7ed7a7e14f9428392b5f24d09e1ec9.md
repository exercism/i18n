# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বইয়ের একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে তিনটি কাজ রয়েছে, যেগুলোর সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে ওভেনের প্রত্যাশিত সময় নির্ধারণ করুন

লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত তা যাচাই করার জন্য `expectedMinutesInOven` টার্মটি ডিফাইন করুন। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```
> expectedMinutesInOven
  ⧩
  40
```

## 2. মিনিটে প্রস্তুতির সময় গণনা করুন

`preparationTimeInMinutes` ফাংশনটি ডিফাইন করুন, যা লাসাগনায় আপনি যে সংখ্যক স্তর যোগ করেছেন তা প্যারামিটার হিসেবে নেয় এবং লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```
> preparationTimeInMinutes 3
  ⧩
  6
```

## 3. মিনিটে অতিবাহিত সময় গণনা করুন

`elapsedTimeInMinutes` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসাগনায় আপনি যে সংখ্যক স্তর যোগ করেছেন, আর দ্বিতীয় প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে আছে। ফাংশনটি রিটার্ন করবে লাসাগনা রান্না করতে আপনি কত মিনিট কাজ করেছেন, যা হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনাটি ওভেনে যে সময় মিনিটে ব্যয় করেছে তার সমষ্টি।

```
> elapsedTimeInMinutes 3 20
  ⧩
  26
```
