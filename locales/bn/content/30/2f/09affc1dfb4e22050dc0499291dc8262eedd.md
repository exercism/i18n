# সম্পর্কে

`assocs` কোনো একক ডেটা টাইপ নয়, এটি একটি [প্রোটোকল][assoc-protocol]। হ্যাশটেবিল (`H{ }`), অ্যাসোসিয়েশন লিস্ট (`{ key value }` জোড়ার সিকোয়েন্স) আর ট্রি ম্যাপ, সবই এটি ইমপ্লিমেন্ট করে, আর assocs-এর বেশিরভাগ ওয়ার্ড এদের মধ্যে বিনিময়যোগ্যভাবে ব্যবহার করা যায়।

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

সামগ্রিক পরিসর বেশ বিস্তৃত: সাজিয়ে ইটারেশন, ম্যাপিং, ফিল্টারিং। তবে অনুশীলনীর বেশিরভাগ কাজে দরকার হয় অল্প কয়েকটি ওয়ার্ড:

| ওয়ার্ড        | ইফেক্ট                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` মান হিসেবে f থাকা আর মান একেবারেই না থাকার পার্থক্য বোঝায় |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )` — পরিবর্তন করে            |
| `change-at` | `( key assoc quot -- )` — `quot` হলো `( old -- new )` |
| `inc-at`    | `( key assoc -- )` — `+1` করে, আর না থাকলে `1` যোগ করে |
| `delete-at` | `( key assoc -- )` — পরিবর্তন করে                  |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` আর `sort-values` (`sorting`-এ আছে) একটি অ্যালিস্টকে বেছে নেওয়া ফিল্ড অনুযায়ী সাজায়।

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
