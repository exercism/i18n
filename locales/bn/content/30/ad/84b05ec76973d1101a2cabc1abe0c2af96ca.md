# ভূমিকা

Elm-এর মতো খাঁটি ফাংশনাল ভাষায় একই আর্গুমেন্ট দিয়ে কল করা একটি ফাংশনকে সবসময় একই মান রিটার্ন করতে হয়। তাই `rand : Int` টাইপ সিগনেচারের একটি ফাংশন কেবল `rand = 4` হিসেবেই ডিফাইন করা যায়, যা র্যান্ডম ইন্টিজার জেনারেট করার জন্য মোটেও সুখবর নয়।

তাহলে Elm-এ আমরা কীভাবে র্যান্ডম মান জেনারেট করি?
আমরা সমস্যাটিকে দুই ভাগে ভাগ করি: প্রথমে আমরা `Random.Generator a` দিয়ে বর্ণনা করি কোন মানটি জেনারেট করতে চাই, তারপর একটি মান জেনারেট করি।

একটি মান জেনারেট করার প্রথম উপায় হলো `initialSeed : Int -> Seed` দিয়ে একটি `Random.Seed` তৈরি করা, তারপর `step : Generator a -> Seed -> ( a, Seed )` ব্যবহার করা, যা একটি মান ও একটি নতুন সিড রিটার্ন করে।
খেয়াল করুন, এই দুটি ফাংশনই খাঁটি, তাই একই আর্গুমেন্ট দিয়ে দুবার কল করলে একই মান পাওয়া যাবে।

মান জেনারেট করার দ্বিতীয় উপায় হলো `generate : (a -> msg) -> Generator a -> Cmd msg` ব্যবহার করা, তবে এটি কেবল একটি Elm অ্যাপ্লিকেশনের ভেতরেই করা যায়।
সেক্ষেত্রে Elm রানটাইম সিড জেনারেট করতে `step`-এর পাশাপাশি বাইরের, খাঁটি নয় এমন রিসোর্সও ব্যবহার করতে পারে।

এখন থেকে আমরা জেনারেটরগুলোর দিকেই মন দেব।

উদাহরণ দেখানোর সুবিধার্থে ধরে নিই, আমরা `initialSeed` ও `step` দিয়ে একটি ফাংশন `generate : Int -> Generator a -> List a` ডিফাইন করেছি, যা একটি জেনারেটর থেকে কয়েকটি মান জেনারেট করে।

`Random` মডিউল নির্দিষ্ট একটি রেঞ্জের মধ্যে ইন্টিজার ও ফ্লোট জেনারেট করার জন্য দুটি মৌলিক জেনারেটর দেয়:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

এই মানগুলো টাপলে, কিংবা মানের অ্যারেতে একত্র করা যায়:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra` প্যাকেজটি নানা ধরনের ডেটা স্ট্রাকচারের জন্য আরও অনেক জেনারেটর দেয়: স্ট্রিং, তারিখ, ডিকশনারি, অ্যারে, সেট ইত্যাদি।

`Random.constant` ব্যবহার করে আমরা এমন জেনারেটর বানাতে পারি যেগুলো কেবল একটি মানই রিটার্ন করবে:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform` ব্যবহার করে আমরা প্রদত্ত এলিমেন্ট থেকে সমান সম্ভাবনায় র্যান্ডমভাবে বেছে নিতে পারি:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` দুটি আর্গুমেন্ট নেয় (`Red` ও `[Green, Blue]`), যাতে বেছে নেওয়ার জন্য অন্তত একটি মান থাকে, কারণ একটি অ্যারে খালি থাকতেও পারে।

`Random.weighted` ব্যবহার করে আমরা সম্ভাবনাগুলো একটু বদলে দিতেও পারি:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

মানগুলো যোগ করে ১০০ হতে হবে না, এগুলো এমনিতেই রিনরমালাইজ হয়ে যাবে।

`Random.map` দিয়ে আমরা একটি জেনারেটরের ভেতরে পৌঁছাতে পারি:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

আরও বেশি জেনারেটর একত্র করতে আমরা `Random.map2` থেকে শুরু করে `Random.map5` পর্যন্ত ব্যবহার করতে পারি:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

আরও জটিল কাজে আমাদের আছে `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, যা একটি জেনারেটরের জেনারেট করা মান দিয়ে আরেকটি জেনারেটর বানাতে পারে:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

কখনও কখনও একটি জেনারেটরকে রিকার্সিভভাবে ডিফাইন করা কাজে লাগে।
সেসব ক্ষেত্রে কম্পাইলারকে জেনারেটরটি অসীমভাবে আনরোল করা থেকে আটকাতে আপনাকে `Random.lazy` ব্যবহার করতে হতে পারে।

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

এই উদাহরণটি একটু ভারী, তাই চলুন এটিকে ভেঙে দেখি।

`Peano` হলো এমন একটি টাইপ যা ধনাত্মক ইন্টিজার বোঝায়: `Zero` মানে ০, `Next(Zero)` মানে ১, `Next(Next(Zero))` মানে ২, ইত্যাদি।
আমরা `peano` ডিফাইন করি যাতে এটি আমাদের একটি র্যান্ডম `Peano` সংখ্যা দেয়।

প্রথমেই খেয়াল করুন, `Random.lazy` লজিকের সাথে নতুন কিছু যোগ করে না, এটি কেবল কম্পাইলারকে `peano`-কে অনির্দিষ্টকাল ধরে `peano`-র ভেতরে লিখে ফেলা থেকে আটকায়।

আমরা `Random.uniform` দিয়ে দুটির মধ্যে একটি বেছে নিই: শূন্য (৫০% সম্ভাবনায়), কিংবা আরেকটি `Peano` সংখ্যার সাথে এক যোগ করা মান (৫০% সম্ভাবনায়)।
তবে আগের উদাহরণের বিপরীতে, `Random.uniform` এখানে মান (যেমন `Zero`) থেকে নয়, বরং জেনারেটর (যেমন `Random.constant Zero`) থেকে বেছে নিচ্ছে, কারণ আমরা `peano`-কে নিজেই ব্যবহার করতে চাই।
এর মানে, `Random.uniform` `Generator (Generator Peano)` টাইপের একটি মান রিটার্ন করবে, যা আমাদের প্রয়োজন নয়।

জেনারেটরটিকে "ফ্ল্যাটেন" করতে আমরা এটিকে `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`-এ পাইপ করি, যেখানে আমরা `b`-কে `Peano` চাই।
যেহেতু `Generator a` হলো `Generator (Generator Peano)`, তাই `a` অবশ্যই `Generator Peano` হতে হবে, এবং ফাংশন `(a -> Generator b)`-এর টাইপ হতে হবে `(Generator Peano -> Generator Peano)`।
আমরা কিছুই বদলাতে চাই না, তাই `identity`-ই সঠিক পছন্দ।

সবশেষে, `peano` আসলে কেমন সংখ্যা তৈরি করবে?
আমরা জানি, এটি ৫০% সময় ০ তৈরি করবে, আর ৫০% সময় নিজের আরেকটি ইটারেশনের সাথে এক যোগ করা মান তৈরি করবে।
এর মানে সংখ্যাগুলো হবে ০ (৫০% সময়), ১ (২৫% সময়), ২ (১২% সময়), ৩ (৬% সময়), ইত্যাদি।
`peano` ইচ্ছেমতো বড় সংখ্যা তৈরি করতে পারে, তবে সম্ভাবনা সূচকীয়ভাবে কমতে থাকে।
