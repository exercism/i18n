# পরিচিতি
C++-এর বিল্ট-ইন সংখ্যার টাইপগুলোকে ইন্টিজার ও ফ্লোটিং পয়েন্টে ভাগ করা যায়।
ইন্টিজার হলো `0`, `691` বা `-2`-এর মতো পূর্ণসংখ্যা।
ফ্লোটিং পয়েন্ট সংখ্যা হলো `6.02214076`, `0.1` বা `-1.616`-এর মতো দশমিক বিন্দুযুক্ত সংখ্যা।

## ইন্টিজার
নিচের উদাহরণে চারটি ভিন্ন ভ্যারিয়েবলের ডিক্লারেশন ও ইনিশিয়ালাইজেশন দেখানো হয়েছে

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

আপনি যখন একটি `int` ভ্যারিয়েবলে একটি মান অ্যাসাইন করেন, তখন সরাসরি একটি লিটারেল দিয়েই তা করতে পারেন।
লিটারেল হলো `9241`-এর মতো কোডে সরাসরি বসানো একটি সংখ্যা।
রিপ্রেজেন্টেশনের বিভিন্ন বেসের জন্য আলাদা আলাদা ইন্টিজার লিটারেল আছে।
দশমিক ইন্টিজার লিটারেল সবচেয়ে কমন এবং এতে `0` থেকে `9` পর্যন্ত অঙ্কগুলো ব্যবহার হয়।
`0x`-এর মতো একটি বিশেষ প্রিফিক্স যোগ করে অন্য বেসও ব্যবহার করা সম্ভব।
উপরের উদাহরণে `9421` সংখ্যাটি তার চারটি রিপ্রেজেন্টেশন ও প্রিফিক্সসহ দেখানো হয়েছে।
সব ভ্যারিয়েবলই একই মানে ইনিশিয়ালাইজ করা হয়েছে।

বিভিন্ন রিপ্রেজেন্টেশন সিস্টেম সম্পর্কে আরও বিস্তারিত জানতে [একটি ছোট টিউটোরিয়াল][cpp_numerical_bases] দেখে নিন।

পড়তে সুবিধার জন্য আপনি ডিজিট আলাদা করতে একটি অ্যাপোস্ট্রফি ব্যবহার করতে পারেন।
`9'241` আর `0b0100'100'0001'1001` বা `92'4'1` একই।

## ফ্লোটিং পয়েন্ট সংখ্যা

ফ্লোটিং পয়েন্ট লিটারেল দুই রকমের হয়।
সহজবোধ্য `0.0024` ছাড়াও এর সায়েন্টিফিক নোটেশন `2.4e-3`ও ব্যবহার করা যায়।
সবচেয়ে কমন ফ্লোটিং পয়েন্ট টাইপ হলো `double`।

## পাটিগণিত

এক্সপ্রেশন গঠনের জন্য C++ `+`, `-`, `*`, `/`, `(` ও `)` এবং `%` সাপোর্ট করে।
দুটি ইন্টিজারের মধ্যে অপারেশনের ফলাফলও একটি ইন্টিজার হয়।
`5 / 2` রিটার্ন করবে `2`।
জড়িত টাইপগুলোর একটি যদি ফ্লোটিং পয়েন্ট টাইপ হয়, তাহলে ফলাফলও ফ্লোটিং পয়েন্ট হবে।
`5.0 / 2` আর `5 / 2.0` রিটার্ন করবে `2.5`।
`%` হলো রিমেইন্ডার অপারেটর, যা একটি ইন্টিজার ভাগের ভাগশেষ রিটার্ন করে: `5%3` হলো `2`।

## অ্যাসাইনমেন্ট অপারেটর

অ্যাসাইনমেন্ট অপারেটর একটি ভ্যারিয়েবলে একটি লিটারেল অ্যাসাইন করে।
এটি সবসময় ডান থেকে বামে ঘটে, কখনোই উল্টো দিকে নয়।

```cpp
int length = 5;
int width = 2;
length = width;
```

এখানে ইন্টিজার মান `5` ভ্যারিয়েবল `length`-এ অ্যাসাইন করা হয়েছে।
তারপর ইন্টিজার মান `2` ভ্যারিয়েবল `width`-এ অ্যাসাইন করা হয়েছে।
সবশেষে `width`-এর মান ভ্যারিয়েবল `length`-এ কপি করা হয় এবং আগের মান `5` হারিয়ে যায়।
এটাও মনে রাখবেন, অ্যাসাইনমেন্ট অপারেশনের মুহূর্তে আমরা শুধু `width`-এর মানটাই `length`-এ অ্যাসাইন করছি।
তাই পরে `width`-এর মান বদলে গেলেও তা `length`-এর মানকে প্রভাবিত করবে না।

অ্যাসাইনমেন্ট অপারেটরকে অন্য অপারেটরগুলোর (পাটিগণিত ও বিটওয়াইজ) সঙ্গে মিলিয়ে তৈরি করা যায়, যেগুলো `compound assignment` অপারেটর নামে পরিচিত: `+=`, `-=`, `*=`, `/=`, `%=`।
এই অপারেটরগুলো একটি ভ্যারিয়েবলের উপর একটি অপারেশন চালিয়ে তার বর্তমান মান পরিবর্তন করে।

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

`people` ও `eggs` ভ্যারিয়েবল দুটি `0` দিয়ে ইনিশিয়ালাইজ করা হয়েছে।
তারপর আমরা ভ্যারিয়েবল `people`-এর বিদ্যমান মান `0`-এর সঙ্গে ইন্টিজার মান `2` যোগ করি এবং তা আবার `people`-এ অ্যাসাইন করি।
এখন `people` হয়ে যায় `2`।
পরে আমরা প্রতি ব্যক্তির জন্য `3`টি করে ডিম যোগ করি, যা মোট `6`টি ডিম হয়।
এখন এই `6` ভ্যারিয়েবল `eggs`-এর বিদ্যমান মান `0`-এর সঙ্গে যোগ করে আবার `eggs`-এ অ্যাসাইন করা হয়।
এখন `eggs` হবে `6`।
সমতুল্য এক্সপ্রেশন হবে `people = people + 2` এবং `eggs = eggs + (3 * people)`।
