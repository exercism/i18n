# সম্পর্কে

অবজেক্ট ইনিশিয়ালাইজার হলো কনস্ট্রাক্টরের একটি বিকল্প। এর সিনট্যাক্স হলো কমা দিয়ে আলাদা করা ফিল্ডের নাম=মান জোড়ার একটি তালিকা, যা নিচে দেখানো হয়েছে:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

কালেকশনও এভাবে ইনিশিয়ালাইজ করা যায়। সাধারণত এটি কমা দিয়ে আলাদা করা তালিকা দিয়ে করা হয়, যেমনটি এখানে দেখানো হয়েছে:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

এই পদ্ধতি (এবং সিনট্যাক্স) এমন যেকোনো ক্লাসের সাথে ব্যবহার করা যায় যা `IEnumerable` ইমপ্লিমেন্ট করে এবং একটি `Add()` মেথড আছে।

ফিল্ডগুলো যেকোনো ক্রমে তালিকাভুক্ত করা যায়, অথবা সম্পূর্ণ বাদ দেওয়া যায়।

ডিকশনারিগুলো নিচের সিনট্যাক্স ব্যবহার করে:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

ইনিশিয়ালাইজ করা ফিল্ডগুলো কলারের কাছে অ্যাক্সেসযোগ্য হতে হবে। সাধারণত এর মানে হলো এগুলো `public` বা `internal` হতে হবে।

ভাষার ডিজাইনার এবং শীর্ষস্থানীয় প্র্যাকটিশনারদের মধ্যে ইমিউটেবিলিটির পক্ষে প্রবল প্রবণতা আছে, তাই এভাবে ইনিশিয়ালাইজ করা অবজেক্টের মিউটেবিলিটিকে একটি অসুবিধা হিসেবে দেখা হয়। ভাষার আসন্ন সংস্করণ C# 9-এ একটি `init` ক্লজ চালু করার প্রস্তাব আছে, যা হয়তো এটি সমাধান করতে পারে।

- [অবজেক্ট ইনিশিয়ালাইজার][object-initializers] ডকুমেন্টেশন বর্ণনা করে কীভাবে ইনিশিয়ালাইজার ব্যবহার করতে হয়।
- [কালেকশন ইনিশিয়ালাইজার][collection-initializers] ডকুমেন্টেশন একটি প্রিভিউ দেয় যে কীভাবে ইনিশিয়ালাইজার ডিকশনারি ও লিস্টের মতো কালেকশনের সাথে ব্যবহার করা যায়।
