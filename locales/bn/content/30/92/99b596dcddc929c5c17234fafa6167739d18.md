# নির্দেশনা

এই অনুশীলনীতে আপনি নিউ ইয়র্কের একটি বিউটি সেলুনের জন্য অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন। সেলুনটি ২০১২ সালের ১৫ সেপ্টেম্বর চালু হয়েছিল।

আপনার পাঁচটি কাজ আছে, যার প্রতিটিতেই অ্যাপয়েন্টমেন্টের তারিখ জড়িত থাকবে।
সময় ২৪-ঘণ্টার ফরম্যাটে দেখানো হয় (AM/PM ছাড়া)।

## 1. מספר্যায় লেখা অ্যাপয়েন্টমেন্টের তারিখ পার্স করুন

একটি অ্যাপয়েন্টমেন্টের তারিখের টেক্সট রূপকে সংশ্লিষ্ট `DateTime` ফরম্যাটে পার্স করতে `schedule_appointment()` ফাংশনটি ইমপ্লিমেন্ট করুন।

লক্ষ্য করুন, ইনপুটটি মার্কিন ধাঁচের মাস/দিন/বছর ক্রমে দেওয়া।

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. একটি অ্যাপয়েন্টমেন্ট ইতিমধ্যে পেরিয়ে গেছে কি না তা যাচাই করুন

`has_passed()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি অতীতে কোনো এক সময়ে ছিল কি না তা যাচাই করে:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. অ্যাপয়েন্টমেন্টটি দুপুরের পরে কি না তা যাচাই করুন

`is_afternoon_appointment()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি দুপুরের পরে কি না (>= 12:00 এবং < 18:00) তা যাচাই করে:

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. অ্যাপয়েন্টমেন্টের সময় ও তারিখ বর্ণনা করুন

`description()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং সেই তারিখ ও সময়ের একটি বর্ণনা রিটার্ন করে:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. অ্যানিভার্সারি তারিখ রিটার্ন করুন

`anniversary_date()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা এ বছরের অ্যানিভার্সারি তারিখ রিটার্ন করে, অর্থাৎ ১৫ সেপ্টেম্বর:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
