# টেস্ট

আপনি প্রদত্ত টেস্টগুলো DrRacket-এর মাধ্যমে, অথবা কমান্ড লাইন থেকে রান করতে পারেন।

DrRacket-এর মাধ্যমে টেস্ট রান করতে, শুধু টেস্ট ফাইলটি খুলে উপরের ডান দিকের 'Run' বোতামে ক্লিক করুন।

কমান্ড লাইন থেকে টেস্ট রান করতে, শুধু অনুশীলনীর ডিরেক্টরি থেকে টেস্টটি রান করুন। উদাহরণস্বরূপ, যদি টেস্ট স্যুটটির নাম `hello-world-test.rkt` হয়, তাহলে আপনি নিচের কমান্ডটি রান করতে পারেন:

```
raco test hello-world-test.rkt
```

এতে নিচের ফলাফলটি দেখানো হবে:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
