# নির্দেশনার সংযোজন

## ইঙ্গিত

এই অনুশীলনীটি সম্পূর্ণ করতে আপনাকে `score` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যা বোলিং *রোল*ের একটি সিকোয়েন্স নেয় এবং চূড়ান্ত স্কোর বা উপযুক্ত এরর রিটার্ন করে:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

এই ডেফিনিশনগুলো ইতিমধ্যেই দেওয়া আছে, তবে ফাংশনটি ডিফাইন করা আপনার হাতেই।

মনে রাখবেন, টেস্ট স্যুট আশা করে রোলগুলোর নম্বর শূন্য থেকে শুরু হবে।
