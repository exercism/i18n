# পরিচিতি

## মডিউল

Gleam কোড মডিউলে সাজানো থাকে, আর প্রতিটি ফাইল হলো একটি Gleam মডিউল।

এখন পর্যন্ত আমরা `pub fn` সিনট্যাক্স দিয়ে ফাংশন লিখেছি, যা এমন একটি ফাংশন ডিফাইন করে যা অন্য মডিউল থেকে পাবলিকভাবে ব্যবহার করা যায়। `fn` দিয়ে ডিফাইন করা ফাংশন যে মডিউলে ডিফাইন করা হয়েছে সেটির কাছে প্রাইভেট, অন্য মডিউল সেগুলো ব্যবহার করতে পারে না।

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam মডিউলের নিজস্ব নাম থাকে, আর সেই নাম তৈরি হয় `src` বা `test` ডিরেক্টরির ভেতরে তার ফাইল পাথের ভিত্তিতে।

যেমন, `src\geometry\rectangle.gleam` (Windows-এ) বা `src/geometry/rectangle.gleam` (UNIX-সদৃশ অপারেটিং সিস্টেমে) ডিফাইন করা একটি মডিউলের নাম হবে `geometry/rectangle`।

## অন্য মডিউল থেকে ফাংশন ইমপোর্ট করা

অন্য মডিউলে ডিফাইন করা ফাংশন ব্যবহার করা হয় ইমপোর্টের মাধ্যমে।
কোনো মডিউল ইমপোর্ট করলে, সেই মডিউল যে ফাংশনগুলো এক্সপোজ করেছে সেগুলো ব্যবহারযোগ্য হয়ে যায়।
তবে সেগুলো কীভাবে ব্যবহার করবেন, তা নির্ভর করে মডিউলটি কীভাবে ইমপোর্ট করা হয়েছে তার উপর।

কোয়ালিফাইড ইমপোর্ট হলো ডিফল্ট, আর এমন মডিউলের ভেতরের কোনো ফাংশন (যেমন `gleam/list` মডিউলের `map` ফাংশন) ব্যবহার করতে মডিউলের নাম আগে বসাতে হয় (`list.map`)।

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

ডিফল্টভাবে মডিউলকে বোঝাতে ব্যবহৃত নামটি হয় মডিউল নামের শেষ অংশ, এখানে সেটি `int`, তবে `as` কিওয়ার্ড ব্যবহার করে এটি বদলানো যায়।

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

আনকোয়ালিফাইড ইমপোর্ট সেই মডিউলের এক্সপোজ করা ফাংশনগুলো সরাসরি, কোনো প্রিফিক্স ছাড়াই ব্যবহার করার সুযোগ দেয়।

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

কোয়ালিফাইড ইমপোর্টই বেশি পছন্দনীয়, কারণ এতে পাঠক সহজেই বুঝতে পারেন একটি ফাংশন কোথা থেকে এসেছে, আর নামের সংঘর্ষ এড়ানো যায়।


## স্ট্যান্ডার্ড লাইব্রেরি

Gleam-এর স্ট্যান্ডার্ড লাইব্রেরি সমৃদ্ধ এবং সুন্দরভাবে ডকুমেন্টেড। ডকুমেন্টেশন অনলাইনে পাওয়া যায় [hexdocs.pm/gleam_stdlib][docs]-এ। লিংকটি কোথাও সেভ করে রাখুন, আপনি এটি বহুবার কাজে লাগাবেন!

বেশিরভাগ বিল্ট-ইন ডেটা টাইপের জন্যই একটি সংশ্লিষ্ট মডিউল আছে, যেখানে সেই ডেটা টাইপ নিয়ে কাজ করার ফাংশন থাকে। যেমন ইন্টিজারের জন্য `gleam/int` মডিউল, স্ট্রিংয়ের জন্য `gleam/string` মডিউল, লিস্টের জন্য `gleam/list` মডিউল, এভাবেই।

[docs]: https://hexdocs.pm/gleam_stdlib/
