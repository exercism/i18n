# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে দুর্দান্ত একটি লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার পাঁচটি কাজ আছে, সবগুলোই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে প্রত্যাশিত ওভেন সময় ডিফাইন করুন

`expected_minutes_in_oven` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং লাসাগনাটি ওভেনে কত মিনিট থাকা উচিত তা রিটার্ন করে। রান্নার বই অনুযায়ী, প্রত্যাশিত ওভেন সময় ৪০ মিনিট:

```gleam
expected_minutes_in_oven()
// -> 40
```

## 2. মিনিটে অবশিষ্ট ওভেন সময় গণনা করুন

`remaining_minutes_in_oven` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসাগনাটি ওভেনে এখন পর্যন্ত যত মিনিট থেকেছে সেই সময় মিনিটে নেয় এবং আগের কাজের প্রত্যাশিত ওভেন সময়ের ভিত্তিতে লাসাগনাটি ওভেনে আর কত মিনিট থাকতে হবে তা রিটার্ন করে।

```gleam
remaining_minutes_in_oven(30)
// -> 10
```

## 3. মিনিটে প্রস্তুতির সময় গণনা করুন

`preparation_time_in_minutes` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসাগনায় আপনার যোগ করা স্তরের সংখ্যা নেয় এবং লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```gleam
preparation_time_in_minutes(2)
// -> 4
```

## 4. মিনিটে মোট কাজের সময় গণনা করুন

`total_time_in_minutes` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্ট হলো লাসাগনায় আপনার যোগ করা স্তরের সংখ্যা, এবং দ্বিতীয় আর্গুমেন্ট হলো লাসাগনাটি ওভেনে এখন পর্যন্ত যত মিনিট থেকেছে সেই সংখ্যা। ফাংশনটির রিটার্ন করা উচিত লাসাগনা রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন তা, যা মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```gleam
total_time_in_minutes(3, 10)
// -> 16
```

## 5. লাসাগনা তৈরি হয়েছে জানিয়ে একটি নোটিফিকেশন তৈরি করুন

`alarm` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং লাসাগনা খাওয়ার জন্য তৈরি হয়েছে এই মর্মে একটি বার্তা রিটার্ন করে।

```gleam
alarm()
// -> "Ding!"
```
