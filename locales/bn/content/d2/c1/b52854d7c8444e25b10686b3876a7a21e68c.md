# পরিচিতি

## ইন্টিজার

ইন্টিজার হলো পূর্ণসংখ্যা, যেগুলো `{..., -2, -1, 0, 1, 2, ...}` সেটের অন্তর্গত।
একটি ইন্টিজারের সর্বোচ্চ ও সর্বনিম্ন মান নির্ভর করে PHP যে সিস্টেমে রান করে তার উপর।
সাধারণত আধুনিক বেশিরভাগ সিস্টেমে ইন্টিজার একটি ৬৪-বিট মান, অর্থাৎ এটি `-9_223_372_036_854_775_808` থেকে `9_223_372_036_854_775_807` পর্যন্ত মান রাখতে পারে, দুটি প্রান্তের মানসহ।

```php
<?php

$a = 1234;
$a = 1_234_567;
```

দশ ভিত্তি ছাড়াও একটি বেস প্রিফিক্স ব্যবহার করে আপনি ইন্টিজার লিটারাল লিখতে পারেন:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> PHP-এর [ডকুমেন্টেশন][syntax] থেকে নেওয়া।

## ফ্লোটিং পয়েন্ট সংখ্যা

PHP-তে বাস্তব সংখ্যার একটি উপসেট প্রকাশ করতে ফ্লোটিং পয়েন্ট সংখ্যা ব্যবহার করা হয়।
এগুলো এক বা একাধিক অঙ্ক দিয়ে শুরু হয়, আর একটি দশমিক বিভাজক দিয়ে আলাদা করা হয়।

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### কমন বিপদ

সব সংখ্যা ও গাণিতিক অপারেশন ফ্লোটিং পয়েন্ট সংখ্যা দিয়ে করা যায় না।
ডলার ও সেন্ট প্রকাশ করতে ফ্লোটিং পয়েন্ট সংখ্যা ব্যবহার করলে রাউন্ডিং এরর হতে পারে।

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## গাণিতিক অপারেটর

গাণিতিক অপারেশন চালানোর জন্য PHP বেশ কিছু অপারেটর দেয়। নিজের গাণিতিক অপারেটরগুলোর ক্ষেত্রে PHP গণিতের প্রচলিত অপারেশন-ক্রম অনুসরণ করে। PHP যে অপারেটরগুলো দেয় সেগুলো হলো:

* অভেদক (+)
* ঋণাত্মকীকরণ (-)
* যোগ (+)
* বিয়োগ (-)
* গুণ (*)
* ভাগ (/)
* মডুলো (%)
* সূচকীকরণ (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
