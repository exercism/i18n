# টার্নারি অপারেটর

টার্নারি অপারেটর একটি `if..else..` তুলনা করার এবং একটি মান রিটার্ন করার বিকল্প সিনট্যাক্স দেয়।

## সিনট্যাক্স

PHP একটি `if` স্টেটমেন্ট সরবরাহ করে, যেখানে একটি শর্তের 'সত্যতা'র ভিত্তিতে একটি কাজ মূল্যায়ন করা যায়।

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

বিকল্প হিসেবে, টার্নারি অপারেটর একই কাজ প্রকাশ করতে পারে:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

তুলনার সিনট্যাক্সটি সংক্ষিপ্ত, যা এভাবে লেখা হয়: `(condition) ? (evaluate if true) : (evaluate if false);`.

## সুবিধা

টার্নারি অপারেটর ব্যবহারের স্পষ্ট সুবিধা হলো সংক্ষিপ্ততা, অর্থাৎ একটি `if..else..` স্টেটমেন্টের তুলনায় শর্তভিত্তিক এক্সপ্রেশনটি লিখতে কম জায়গা লাগে। তবে এর পাশাপাশি আরও কয়েকটি সুবিধা আছে:

- এটি একটি এক্সপ্রেশন, যা আরেকটি এক্সপ্রেশনের ভেতরে ব্যবহার করা যায়
- এটি প্রতিটি ব্র্যাঞ্চের লেজি ইভ্যালুয়েশন সহজ করে।

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  এই উদাহরণে, সঠিক উত্তরটির প্রয়োজন না থাকলে ব্যয়বহুল গণনাটি চালানো হয় না।

## অসুবিধা

টার্নারি অপারেটরের কয়েকটি অসুবিধা আছে, তাই এটি ব্যবহার করার আগে ভেবে নেওয়া জরুরি:

- টার্নারি অপারেটর পড়তে বেশি কঠিন হতে পারে, কারণ এটি কিওয়ার্ড ব্যবহারের বদলে চিহ্নের ব্যাখ্যার উপর নির্ভর করে।
- টার্নারি অপারেটর অনিচ্ছাকৃতভাবে Bug তৈরি করতে পারে, কারণ PHP-তে টার্নারি অপারেটর লেফট-অ্যাসোসিয়েটিভ, যা সমসাময়িক বেশিরভাগ ভাষার (যেমন C, Java, JavaScript) থেকে আলাদা।
- ট্রু বা ফলস ব্র্যাঞ্চে মূল্যায়িত এক্সপ্রেশনটিকে অবশ্যই একটি মান রিটার্ন করতে হবে।

## আরও সংক্ষিপ্ত

টার্নারি সিনট্যাক্সটিকে আরও সংক্ষিপ্ত করে `(condition) ?: (evaluate if falsey)` লেখা যায়।
এর একটি ব্যবহার হতে পারে এক্সপ্রেশনের ভেতরে একটি ফলব্যাক ভ্যালু সরবরাহ করা:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

এটিকে অনেক সময় _Elvis operator_ (`?:`) নামেও ডাকা হয়।
