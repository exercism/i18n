# পরিচিতি

Gleam-এ `Iterator` অনেকটা অ্যারের মতো: এটি মানের একটি সাজানো সংগ্রহ, যেখানে সব মান একই টাইপের। এটি অ্যারে থেকে আলাদা কারণ এটি লেজি, অর্থাৎ এটি তার সব মান একসাথে মেমোরিতে জমা রাখে না, বরং যেভাবে দরকার হয় সেভাবে সেগুলো হিসাব করে।

খুব বড়, এমনকি অসীম আকারের সিকোয়েন্স নিয়ে কাজ করার সময় এটি কাজে লাগে, কারণ সব মান একসাথে জমা রাখার মতো যথেষ্ট খালি মেমোরি না থাকলেও এগুলো নিয়ে কাজ করা যায়।

`gleam/iterator` মডিউলে `Iterator` টাইপ এবং ইটারেটর নিয়ে কাজ করার ফাংশনগুলো ডিফাইন করা আছে।

অ্যারের জন্য যেসব ফাংশন আছে, তার অনেকগুলোই ইটারেটরের জন্যও আছে, যেমন `map`, `filter` এবং `take`. এই ফাংশনগুলো ইটারেটর রিটার্ন করে, তাই ইটারেটরটি কনজিউম করা না হলে এরা আসলে কোনো কাজ করে না।

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` ফাংশন দিয়ে এমন একটি ফাংশন থেকে ইটারেটর তৈরি করা যায়, যেটি সিকোয়েন্সের পরের মানটি তৈরি করতে বারবার কল করা হয়।

এখানে `unfold` ফাংশন দিয়ে এমন একটি ইটারেটর তৈরি করা হয়েছে যা ফিবোনাচি সিকোয়েন্স তৈরি করে:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

এখানে সিকোয়েন্সটি অসীম, তাই মানগুলো অ্যারেতে সংগ্রহের আগে `take` ফাংশন দিয়ে এটিকে সীমিত করা হয়েছে। কোনো অসীম ইটারেটরের ওপর `to_list` কল করলে প্রোগ্রামটি মেমোরি শেষ হওয়া পর্যন্ত চলতে থাকবে এবং শেষে ক্র্যাশ করবে।
