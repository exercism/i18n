# ইঙ্গিত

## সাধারণ

- `Random` প্যাকেজের ডকুমেন্টেশন [এখানে][random-module] পাওয়া যাবে

## 1. শেষ থেকে শুরু করুন

- [`Random.constant`][random-constant] ফাংশনটি ব্যবহার করুন

## 2. ভিনেগার দিয়ে মাছি ধরা যায় না

- ট্রেজার তৈরি করতে [`Random.uniform`][random-uniform] ফাংশনটি ব্যবহার করুন
- ট্রেজার মোড়ানোর জন্য [`Random.map`][random-map] ফাংশনটি ব্যবহার করুন

## 3. শাখা ছড়ানো

- ২ থেকে ৪-এর মধ্যে একটি মান তৈরি করতে [`Random.int`][random-int] ফাংশনটি ব্যবহার করুন
- এই মানটি ব্যবহার করে আপনি [`Random.andThen`][random-andThen] ফাংশনের সাহায্যে একটি `Branch` তৈরি করতে পারেন
- শাখাগুলো তৈরি করতে [`Random.list`][random-list] ফাংশনটি ব্যবহার করুন
- শাখাগুলো মোড়ানোর জন্য [`Random.map`][random-map] ফাংশনটি ব্যবহার করুন

## 4. দুর্দান্ত গোলকধাঁধা

- ফলাফলের অসমান বিতরণ তৈরি করতে [`Random.weighted`][random-weighted] ফাংশনটি ব্যবহার করুন
- একটি জেনারেটর রিকার্সিভভাবে ব্যবহার করতে [`Random.lazy`][random-lazy] ফাংশনটি ব্যবহার করুন
- রিকার্সিভ ডেটা স্ট্রাকচার ডিফাইন করা সম্পর্কে আরও পড়ুন [এখানে][bad-recursion]
- যদি আপনি শেষ পর্যন্ত একটি নেস্টেড `Generator (Generator Maze)` জেনারেটর ডিফাইন করেন, তাহলে সেটি ফ্ল্যাট করতে [`Random.andThen`][random-andThen] ফাংশনটি `identity` ফাংশনের সাথে একসাথে ব্যবহার করতে পারেন

## 5. আরও গভীরে যেতে হবে

- গভীরতা `0`-এ বন্ধ গলি বা রুম তৈরি করতে [`Random.uniform`][random-uniform] ফাংশনটি ব্যবহার করুন
- যদি আপনি শেষ পর্যন্ত একটি নেস্টেড `Generator (Generator Maze)` জেনারেটর ডিফাইন করেন, তাহলে সেটি ফ্ল্যাট করতে [`Random.andThen`][random-andThen] ফাংশনটি `identity` ফাংশনের সাথে একসাথে ব্যবহার করতে পারেন
- একটি জেনারেটর রিকার্সিভভাবে ব্যবহার করতে [`Random.lazy`][random-lazy] ফাংশনটি ব্যবহার করুন
- রিকার্সিভ ডেটা স্ট্রাকচার ডিফাইন করা সম্পর্কে আরও পড়ুন [এখানে][bad-recursion]
