# পরিচিতি

Gleam-এ ফার্স্ট ক্লাস ফাংশন আছে, অর্থাৎ ফাংশন হলো সাধারণ মান, যা ভ্যারিয়েবলে অ্যাসাইন করা যায়, আর্গুমেন্ট হিসেবে পাস করা যায়, এবং অন্য ফাংশন থেকে রিটার্ন করা যায়।

মডিউলে ডিফাইন করা একটি নামযুক্ত ফাংশনকে তার নাম দিয়ে রেফার করা যায়।

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam-এ অ্যানোনিমাস ফাংশনও আছে, যেগুলো অন্য ফাংশনের ভেতরে ডিফাইন করা হয়।

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

একটি ফাংশনের টাইপ অ্যানোনিমাস ফাংশনের অনুরূপ সিনট্যাক্স ব্যবহার করে লেখা হয়। যে ফাংশন একটি `Int` এবং একটি `Float` নেয় এবং একটি `Int` রিটার্ন করে, তার টাইপ এভাবে লেখা হয়:

```gleam
fn(Int, Float) -> Int
```

অ্যানোনিমাস ফাংশনগুলো সেই ভ্যারিয়েবলগুলো রেফার করতে পারে যেগুলো ডিফাইন করার সময় স্কোপে ছিল, ফলে এগুলো _ক্লোজার_ হয়ে যায়।

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_ফাংশন ক্যাপচার_ সিনট্যাক্স এমন অ্যানোনিমাস ফাংশন তৈরির একটি সুবিধাজনক শর্টকাট দেয়, যেগুলো একটি ফাংশনে একক আর্গুমেন্ট পাস করে। এই দুটি এক্সপ্রেশন সমতুল্য:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
