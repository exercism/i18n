# ভূমিকা

বেশিরভাগ প্রোগ্রামিং ভাষার মতো Gleam-এরও "সাইড ইফেক্ট" আছে, তাই ফাংশনগুলো একটি মান রিটার্ন করার পাশাপাশি পৃথিবীর অবস্থা পড়তে ও বদলাতেও পারে।

Gleam-এর স্ট্যান্ডার্ড লাইব্রেরির `gleam/io` মডিউলটি কনসোলে স্ট্রিং প্রিন্ট করার ফাংশন দেয়।

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

অন্য প্যাকেজগুলোও অন্য IO ফাংশন দিতে পারে, যেমন `simplifile`, একটি প্যাকেজ যা ফাইল পড়া ও লেখার ফাংশন দেয়।

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
