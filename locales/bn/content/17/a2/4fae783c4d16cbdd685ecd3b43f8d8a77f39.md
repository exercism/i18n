# নির্দেশাবলি

একটি ABAP ইন্টারনাল টেবিলের মধ্যে ডেটা কীভাবে অ্যাগ্রিগেট ও গ্রুপ করতে হয় তা শিখুন।


আপনার ক্লাসে `initial_numbers` নামের একটি ইন্টারনাল টেবিল দেওয়া হবে। এতে দুটি কলাম থাকে: `GROUP` এবং `NUMBER`.

```abap
TYPES: BEGIN OF initial_numbers_type,
        group  TYPE group,
        number TYPE i,
       END OF initial_numbers_type,
       initial_numbers TYPE STANDARD TABLE OF initial_numbers_type WITH EMPTY KEY.
```

এই টেবিলের ডেটা তিনটি গ্রুপ নিয়ে গঠিত: A, B এবং C। প্রতিটি গ্রুপে একাধিক রেকর্ড আছে।

| GROUP | NUMBER |
| --- | ----------- |
| A | 10 |
| B | 5 |
| A | 6 |
| C | 22 |
| A | 13 |
| C | 500 |

আপনার কাজ হলো প্রতিটি গ্রুপের জন্য একটি করে রেকর্ডসহ একটি ইন্টারনাল টেবিল রিটার্ন করা। এই রেকর্ডে থাকা উচিত মূল টেবিলে প্রতিটি গ্রুপের রেকর্ডসংখ্যা (`COUNT`), এই গ্রুপের সব `NUMBER` মানের যোগফল (`SUM`), গ্রুপের সর্বনিম্ন মান (`MIN`), গ্রুপের সর্বোচ্চ মান (`MAX`) এবং সেই গ্রুপের সব মানের গড় (`AVERAGE`)।

প্রত্যাশিত রিটার্ন টেবিলের সংজ্ঞা নিম্নরূপ:

```abap
TYPES: BEGIN OF aggregated_data_type,
        group   TYPE group,
        count   TYPE i,
        sum     TYPE i,
        min     TYPE i,
        max     TYPE i,
        average TYPE f,
       END OF aggregated_data_type,
       aggregated_data TYPE STANDARD TABLE OF aggregated_data_Type WITH EMPTY KEY.
```

## বোনাস

ABAP-এ এই কাজটি সম্পন্ন করার অনেক উপায় আছে। আপনি কতটা দক্ষতার সাথে কাজটি সম্পন্ন করতে পারেন? টেবিলের প্রতিটি রেকর্ড মাত্র একবার পড়েই কি আপনি এটি করতে পারবেন?
