# নির্দেশাবলি

আপনি একটি স্বাস্থ্য মনিটরিং সিস্টেম তৈরি করার কাজ করছেন। তার অংশ হিসেবে আপনাকে ইউজারদের স্বাস্থ্য পরিসংখ্যানের হিসাব রাখতে হবে।

শুরুতে একটি `impl` ব্লকে কিছু স্টাব করা ফাংশন পাবেন, সঙ্গে পাবেন নিচের স্ট্রাক্ট ডেফিনিশনটিও:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

আপনার লক্ষ্য হলো `impl` ব্লকে ডিফাইন করা `User` `struct`-এর স্টাব করা মেথডগুলো ইমপ্লিমেন্ট করা।

যেমন, `new` মেথডটি নির্দিষ্ট নাম, বয়স ও ওজনের মানসহ `User` struct-এর একটি ইনস্ট্যান্স রিটার্ন করবে।

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

`weight` মেথডটি `User` struct-এর ওজন রিটার্ন করবে।

```rust
bob.weight();
// Returns: 155.2
```

`set_age` মেথডটি `User` struct-এর বয়স সেট করবে।

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
