# পরিচিতি

ইন্টারফেস হলো এমন একটি টাইপ, যাতে থাকা মেম্বারগুলো একগুচ্ছ সম্পর্কিত কার্যকারিতা নির্ধারণ করে। এটি একটি ক্লাসের ব্যবহারকে তার ইমপ্লিমেন্টেশন থেকে দূরে সরিয়ে রাখে, ফলে একাধিক ভিন্ন ইমপ্লিমেন্টেশন সম্ভব হয়, অথবা ফরম্যাটিং, তুলনা কিংবা কনভার্সনের মতো কোনো জেনেরিক আচরণ সমর্থন করা যায়।

ইন্টারফেসের সিনট্যাক্স অনেকটা ক্লাসের মতোই, শুধু পার্থক্য হলো এখানে মেথডগুলো কেবল সিগনেচার হিসেবে দেখা যায়, কোনো বডি দেওয়া হয় না।

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

ইন্টারফেসে নির্ধারিত সব অপারেশন ইমপ্লিমেন্ট করা ক্লাসকে অবশ্যই ইমপ্লিমেন্ট করতে হবে।

ইন্টারফেসে সাধারণত ইনস্ট্যান্স মেথড থাকে।

Java Class Library-তে পাওয়া এমন একটি ইন্টারফেসের উদাহরণ, উপরে দেখানো `Cloneable` ছাড়াও, হলো `Comparable<T>`। কালেকশনে ডিফল্ট জেনেরিক সাজানোর ক্রম প্রয়োজন হলে `Comparable<T>` ইন্টারফেসটি ইমপ্লিমেন্ট করা যায়।
