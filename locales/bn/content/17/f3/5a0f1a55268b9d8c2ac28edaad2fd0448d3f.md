# পরিচিতি

Java-তে র‍্যান্ডম সংখ্যা তৈরি করতে `java.util.Random` ক্লাসের একটি ইনস্ট্যান্স ব্যবহার করা যায়।

## র‍্যান্ডম ইন্টিজার

`nextInt()` মেথড ব্যবহার করে একটি র‍্যান্ডম ইন্টিজার তৈরি করা যায়।
এটি `Integer.MIN_VALUE` থেকে `Integer.MAX_VALUE` পর্যন্ত পরিসরে একটি মান তৈরি করবে।

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

তৈরি হওয়া মানের পরিসর সীমিত করতে `nextInt(int)` ব্যবহার করুন।
এটি `0` (অন্তর্ভুক্ত) থেকে প্রদত্ত ঊর্ধ্বসীমা (অন্তর্ভুক্ত নয়) পর্যন্ত পরিসরে একটি মান তৈরি করবে।

উদাহরণস্বরূপ, এটি `0` থেকে `9` পর্যন্ত একটি র‍্যান্ডম সংখ্যা তৈরি করবে।

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

আর এটি `10` থেকে `19` পর্যন্ত একটি র‍্যান্ডম সংখ্যা তৈরি করবে।

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## র‍্যান্ডম ডাবল

`nextDouble()` মেথড ব্যবহার করে একটি র‍্যান্ডম ডাবল তৈরি করা যায়।
এটি `0.0` থেকে `1.0` পর্যন্ত পরিসরে একটি মান তৈরি করবে।

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

আর এটি `100.0` থেকে `200.0` পর্যন্ত একটি র‍্যান্ডম সংখ্যা তৈরি করবে।

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
