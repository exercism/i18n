# নির্দেশনা

ব্যবহারকারীর ইনপুট থেকে CSV রেকর্ড তৈরি করার কাজ আপনার কোম্পানি পেয়েছে।

[RFC 4180](https://tools.ietf.org/html/rfc4180)-এ বর্ণিত স্ট্যান্ডার্ড অনুযায়ী আমাদের একটি CSV রেকর্ডের জন্য বিল্ডার দরকার।

যদিও একটি আনুষ্ঠানিক স্পেসিফিকেশন আছে, আপনার কোম্পানিকে শুধু নিচের কার্যকারিতাটুকুই তৈরি করতে হবে:
- একটি নতুন রেকর্ড বিল্ডার তৈরি করা
- রেকর্ডে একটি করে ফিল্ড যোগ করা
- বেসিক এস্কেপিং দিয়ে রেকর্ড সিরিয়ালাইজ করা

বেসিক এস্কেপিং বলতে বোঝায়:

- লাইন ব্রেক, ডাবল-কোট এবং কমা থাকা ফিল্ডগুলো ডাবল-কোটের ভেতরে রাখতে হবে।

- ফিল্ড ঘেরাও করতে ডাবল-কোট ব্যবহার করলে, ফিল্ডের ভেতরে থাকা ডাবল-কোটের আগে আরেকটি ডাবল-কোট বসিয়ে সেটি এস্কেপ করতে হবে।


## 1. নতুন একটি বিল্ডার তৈরি করুন

নতুন একটি বিল্ডার তৈরি করতে আপনাকে `new` মেথডটি ইমপ্লিমেন্ট করতে হবে।

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. রেকর্ডে একটি করে ফিল্ড যোগ করুন

আপনার রেকর্ড বিল্ডারে ফিল্ড যোগ করতে আপনাকে `add` মেথডটি ইমপ্লিমেন্ট করতে হবে।
`add` আর্গুমেন্ট হিসেবে ইমিউটেবল স্ট্রিং স্লাইস, `&str`, নেয়।

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. বেসিক এস্কেপিং দিয়ে রেকর্ড সিরিয়ালাইজ করুন

আপনাকে `build` মেথডটি ইমপ্লিমেন্ট করতে হবে।
`build` বিল্ডারটি কনজিউম করে এবং একটি CSV রেকর্ড রিটার্ন করে।
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
