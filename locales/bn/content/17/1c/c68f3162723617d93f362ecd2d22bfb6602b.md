# ভূমিকা

## সংখ্যা

Swift-এ মূলত দুই ধরনের সংখ্যা থাকে: ইন্টিজার আর ফ্লোটিং-পয়েন্ট সংখ্যা।

- [ইন্টিজার][integers] হলো ভগ্নাংশবিহীন পূর্ণ সংখ্যা, যেমন `0`, `1`, `-1`, `42` আর `-273`.
- [ফ্লোটিং-পয়েন্ট সংখ্যা][floatingpoint] হলো ভগ্নাংশযুক্ত সংখ্যা, যেমন `0.0`, `3.14` আর `-1.36969e-10`.

পাঠযোগ্যতা বাড়াতে আপনি সংখ্যার লিটারেলে আন্ডারস্কোর বসাতে পারেন: `1_000_000` আর `1000000` একেবারে একই।
ফ্লোটিং-পয়েন্ট লিটারেল দশমিক বা সূচকীয় নোটেশনে লেখা যায়।

বেশিরভাগ ক্ষেত্রেই ইন্টিজারের জন্য আপনি [`Int`][int] আর ফ্লোটিং-পয়েন্ট সংখ্যার জন্য [`Double`][double] ব্যবহার করেন:

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## পাটিগণিত অপারেটর

সংখ্যা নিয়ে হিসাব করার জন্য Swift সাধারণ [পাটিগণিত অপারেটর][arithmetic-operators] দেয়:

| অপারেটর | বিবরণ    | উদাহরণ |
| -------- | -------------- | ------- |
| `+`      | যোগ       | `4 + 6`-এর ফলাফল `10` |
| `-`      | বিয়োগ    | `15 - 10`-এর ফলাফল `5` |
| `*`      | গুণ | `2 * 3`-এর ফলাফল `6`  |

~~~~exercism/caution
Swift টাইপ-সেফ, তাই পাটিগণিতের কাজে ভিন্ন টাইপের সংখ্যা একসাথে মেশাতে দেয় না।
আপনি সরাসরি একটি `Int` আর একটি `Double` যোগ বা গুণ করতে পারবেন না; আগে একটি টাইপকে অন্যটির সাথে মিলিয়ে কনভার্ট করতে হবে।
~~~~

### ভাগ

`/` অপারেটর দিয়ে ভাগ করা হয়।
দুই পাশের অপারেন্ড দুটোই ইন্টিজার হলে, ইন্টিজার ভাগ ভগ্নাংশের অবশিষ্ট অংশটুকু বাদ দিয়ে দেয়:

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

শূন্য নয় এমন কোনো ফ্লোটিং-পয়েন্ট সংখ্যাকে শূন্য দিয়ে ভাগ করলে ফল আসে `inf` বা `-inf`.
`0.0`-কে `0.0` দিয়ে ভাগ করলে পাওয়া যায় `nan` (Not a Number, অর্থাৎ সংখ্যা নয়)।
এর বিপরীতে, কোনো ইন্টিজারকে শূন্য দিয়ে ভাগ করলে কম্পাইল-টাইম বা রানটাইম এরর হয়:

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### ভাগশেষ অপারেটর

[ভাগশেষ অপারেটর][remainder-operator] (`%`) দুইটি ইন্টিজার ভাগ করার পর যে ভাগশেষ অবশিষ্ট থাকে তা বের করে:

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
Swift-এ `%` মডুলো অপারেটর নয়, বরং সত্যিকারের *ভাগশেষ* অপারেটর।
ফল সবসময় প্রথম অপারেন্ডের (যেটিকে ভাগ করা হচ্ছে) চিহ্নই নেয়, দ্বিতীয় অপারেন্ডের চিহ্ন যা-ই হোক না কেন:

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## ফ্লোটিং-পয়েন্ট সংখ্যা রাউন্ড করা

আপনি `rounded()` মেথড দিয়ে একটি ফ্লোটিং-পয়েন্ট সংখ্যাকে রাউন্ড করতে পারেন।
ডিফল্টভাবে `rounded()` নিকটতম ইন্টিজারে রাউন্ড করে।
চাইলে আপনি নির্দিষ্ট একটি [রাউন্ডিং রুল][rounding-rule] দিতে পারেন, যেমন `.up` বা `.down`:

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## টাইপ ইনফারেন্স

টাইপ অ্যানোটেশন ছাড়া কোনো সংখ্যার কনস্ট্যান্ট বা ভ্যারিয়েবল ডিক্লেয়ার করলে Swift নিজেই তার টাইপ অনুমান করে নেয়:

- পূর্ণ সংখ্যাগুলোর ডিফল্ট `Int`.
- দশমিক বিন্দুযুক্ত সংখ্যাগুলোর ডিফল্ট `Double`.

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## টাইপ কনভার্সন (ডেটা টাইপ রূপান্তর)

ভিন্ন টাইপের মান নিয়ে কাজ করতে হলে `Double(_:)` বা `Int(_:)`-এর মতো টাইপ ইনিশিয়ালাইজার দিয়ে একটি মানকে অন্যটিতে কনভার্ট করুন:

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
