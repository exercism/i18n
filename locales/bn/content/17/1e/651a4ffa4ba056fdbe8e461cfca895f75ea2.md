# পরিচিতি

C++-এ একটি `string` হলো একটি মিউটেবল অবজেক্ট, যা টেক্সটকে ক্যারেক্টারের একটি ক্রম (অক্ষর, সংখ্যা, যতিচিহ্ন ইত্যাদি) হিসেবে উপস্থাপন করে।
স্ট্রিংয়ের মেথডগুলো কল করে স্ট্রিং নিয়ে কাজ করা হয়।

## স্ট্রিংস লাইব্রেরি

C++-এ ব্যবহারের আগে স্ট্রিং টাইপ এবং সংশ্লিষ্ট ফাংশনগুলো স্ট্রিংস লাইব্রেরি থেকে ইনক্লুড করতে হয়।
আপনি ফাইলের শুরুতে `#include <string>` যোগ করে তা করতে পারেন।
এরপর এগুলো `std` নেইমস্পেসে যুক্ত হবে।
স্ট্রিং টাইপের পূর্ণাঙ্গ নাম `std::string`।
স্ট্রিং লিটারাল ডাবল কোট অক্ষর ব্যবহার করে: `"`।

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## কমন স্ট্রিং অপারেশন

আপনি `+` অপারেটর দিয়ে স্ট্রিং কনক্যাটিনেট করতে পারেন:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

স্ট্রিংস লাইব্রেরি ব্যবহার করতে হলে জানতে হবে যে, কোনো অবজেক্টের অন্তর্গত ফাংশন কল করা সম্ভব।
এগুলোকে মেম্বার ফাংশন বলা হয়।
পরে পাঠ্যক্রমে আপনি মেম্বার ফাংশন এবং তার সাথে সম্পর্কিত ক্লাসের ধারণা সম্পর্কে আরও শিখবেন।

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


`find` ফাংশনটিও খুবই কার্যকর।
এটি স্ট্রিংয়ের একটি মেম্বার ফাংশন হিসেবে কল করা হয় এবং আর্গুমেন্ট হিসেবে একটি স্ট্রিং নেয়।
`find` স্ট্রিংয়ের _প্রথম_ উপস্থিতির শূন্য-ভিত্তিক অবস্থান রিটার্ন করে।

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

এছাড়াও `std::to_string` ফাংশনটি আছে, যা দিয়ে ইন্টিজার এবং ফ্লোট/ডাবল মানকে স্ট্রিংয়ে রূপান্তর করা যায়।

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
