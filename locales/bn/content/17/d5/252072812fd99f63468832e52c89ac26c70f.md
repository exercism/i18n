# নির্দেশাবলির সংযোজন

## ইমপ্লিমেন্টেশন

ডিস্টাকচারিংয়ের মাধ্যমে অ্যারে তৈরি ও ভেঙে ফেলতে ভাষার মূল ফিচারগুলো ব্যবহার করা এবং `[]` অ্যারে লিটারাল ব্যবহার করা যাবে, তবে `Array.prototype`-এর কোনো ফাংশন ব্যবহার করা যাবে না।

আপনার সমাধান পরীক্ষা করার জন্য নিশ্চিত করুন যে `forEach` ইমপ্লিমেন্ট করা হয়েছে।

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
