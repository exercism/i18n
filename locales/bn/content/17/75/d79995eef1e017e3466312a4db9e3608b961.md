# পরিচিতি

রিকার্শন হলো একটি ফাংশনের ভেতরে কোড পুনরাবৃত্তি করার একটি উপায়, যেখানে ফাংশনটি নিজেই নিজেকে কল করে। 
এটিকে লুপ করা বা ইটারেশন করার আরেকটি উপায় হিসেবে দেখা যায়।
লুপিংয়ের মতোই, রিকার্সিভ এক্সিকিউশন কখন থামবে তা নির্ধারণ করতে একটি বুলিয়ান এক্সপ্রেশন বা `True`/`False` পরীক্ষা ব্যবহার করা হয়।
_লুপিংয়ের বিপরীতে_, Python-এ সমাপ্তি ছাড়া রিকার্শন অসীমভাবে চলতে পারে না।
প্রতিটি ফাংশন কলে ব্যবহৃত মানগুলো Python-এর [ইন্টারপ্রেটার স্ট্যাকের][what-is-the-call-stack] ভেতরে নিজস্ব [ফ্রেমে][stack-frame] রাখা হয়।
ফাংশন কলের মোট সংখ্যা যদি স্ট্যাকের জায়গার চেয়ে বেশি জায়গা নেয়, তাহলে এর ফলে একটি এরর হয়।

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

এটি প্রিন্ট করবে

```
The step is 1
The step is 2
After recursion
```

এমন কিছু পরিস্থিতি থাকতে পারে, যা লুপিংয়ের বদলে রিকার্শনে প্রকাশ করলে পড়ার জন্য আরও সহজ এবং/অথবা যুক্তি দিয়ে বুঝে নেওয়ার জন্য আরও সুবিধাজনক হয়।
