# নির্দেশনা

আপনি একটি উপকূলীয় টহল জাহাজের সিগন্যালার। সকালের ওয়াচ শুরু হওয়ার আগেই আজকের ব্যাগে পাঁচটি ছোট শব্দ তৈরি থাকা দরকার।

## 1. একটি মান কোট করুন

লগ বইটি প্রতিটি পর্যবেক্ষণ *Factor source form*-এ লিখে রাখে, ঠিক সেই টেক্সটটাই যা পার্সার পরে পড়ে। যেকোনো মানকে তার সোর্স-ফর্ম স্ট্রিংয়ে রূপান্তর করতে `quote-value` ডিফাইন করুন।

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. পতাকা থেকে ফ্রেম সরান

আগত সিগন্যাল পতাকাগুলো দুই প্রান্তে একটি মার্কার ক্যারেক্টার দিয়ে ফ্রেম করা অবস্থায় আসে। দুই মার্কারের *মাঝের* সবকিছু রিটার্ন করতে `flag-body` ডিফাইন করুন, অর্থাৎ প্রথম ক্যারেক্টারটি বাদ দিন, শেষ ক্যারেক্টারটিও বাদ দিন।

কপি না করে একটি স্লাইস (একটি ভিউ) রিটার্ন করুন।

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. একটি পতাকা ভাগ করুন

প্রতিটি পতাকায় থাকে একটি ছোট প্রিফিক্স কোড, তারপর থাকে পেলোড। একটি পতাকা আর একটি হেডার দৈর্ঘ্য নিয়ে *দুটোই* রিটার্ন করতে `split-flag` ডিফাইন করুন: হেডার স্লাইস আর বডি স্লাইস।

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. দুটি রিডিং থেকে ট্রায়াঙ্গুলেট করুন

পরপর দুইটি সিগন্যাল রিডিং থেকে তিনটি উদ্ভূত পরিমাপ পাওয়া যায়: তাদের *পার্থক্য* `a - b`, তাদের *মধ্যবিন্দু* `(a + b) / 2`, আর তাদের *অনুপাত* `a / b`। প্রতিটি পরিমাপেই দুই রিডিং ব্যবহার হয়।

একজোড়া রিডিং থেকে তিনটিই রিটার্ন করতে `triangulate` ডিফাইন করুন।

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. তিনটি রিডিং সারসংক্ষেপ করুন

পরপর তিনটি রিডিংকে তাদের **যোগফল**, **গুণফল** আর **সর্বোচ্চ** হিসেবে সারসংক্ষেপ করা হয়। প্রতিটি পরিসংখ্যানেই তিনটি রিডিং ব্যবহার হয়।

তিনটিই রিটার্ন করতে `triangle-stats` ডিফাইন করুন।

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
