# SQLite-নির্দিষ্ট নির্দেশনা

**list_one** এবং **list_two** কলামে পূর্ণসংখ্যার একটি JSON-এনকোড করা তালিকা থাকে।

উদাহরণ:

```json
[1, 2, 3]
```

## টেবিল স্কিমা

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
