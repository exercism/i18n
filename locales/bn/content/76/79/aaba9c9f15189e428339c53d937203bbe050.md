# পরিচিতি

JavaScript একটি ডাইনামিক ভাষা, যা অবজেক্ট-ওরিয়েন্টেড, ইম্পারেটিভ এবং ডিক্লারেটিভ (যেমন ফাংশনাল প্রোগ্রামিং) স্টাইল সমর্থন করে।

## (পুনরায়) অ্যাসাইনমেন্ট

JavaScript-এ নামে মান অ্যাসাইন করার কয়েকটি প্রধান উপায় আছে, সেগুলো হলো ভ্যারিয়েবল বা কনস্ট্যান্ট ব্যবহার করা। Exercism-এ ভ্যারিয়েবল সবসময় [camelCase][wiki-camel-case]-এ লেখা হয়; কনস্ট্যান্ট লেখা হয় [SCREAMING_SNAKE_CASE][wiki-snake-case]-এ। অনুসরণ করার মতো কোনো অফিসিয়াল গাইড নেই, আর বিভিন্ন কোম্পানি ও প্রতিষ্ঠানের স্টাইল গাইডও বিভিন্ন রকম। _ভ্যারিয়েবল আপনার ইচ্ছেমতো যেভাবেই চান লিখতে পারেন_। অনুশীলনীগুলো যে নিয়মে তৈরি করা হয়েছে সেভাবে লিখলে সুবিধা হলো, ওয়েব ইন্টারফেস আর বেশিরভাগ IDE-তে সেগুলো আলাদাভাবে হাইলাইট হবে।

JavaScript-এ ভ্যারিয়েবল [`const`][mdn-const], [`let`][mdn-let] বা [`var`][mdn-var] কিওয়ার্ড দিয়ে ডিফাইন করা যায়।

`let` বা `var` ব্যবহার করলে একটি ভ্যারিয়েবল তার পুরো জীবনকালে বিভিন্ন মান রেফার করতে পারে। উদাহরণস্বরূপ, অ্যাসাইনমেন্ট অপারেটর `=` ব্যবহার করে `myFirstVariable` বারবার ডিফাইন ও পুনরায় ডিফাইন করা যায়:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

`let` ও `var`-এর বিপরীতে, `const` দিয়ে ডিফাইন করা ভ্যারিয়েবলে একবারই অ্যাসাইন করা যায়। JavaScript-এ কনস্ট্যান্ট ডিফাইন করতে এটি ব্যবহার করা হয়।

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 পরের একটি কনসেপ্ট অনুশীলনীতে _কনস্ট্যান্ট_ অ্যাসাইনমেন্ট / বাইন্ডিং আর _কনস্ট্যান্ট_ মানের মধ্যে পার্থক্য নিয়ে আলোচনা ও ব্যাখ্যা করা হয়েছে।

## ফাংশন ডিক্লারেশন

JavaScript-এ কার্যকারিতার এককগুলো _ফাংশনে_ এনক্যাপসুলেট করা হয়, আর যে ফাংশনগুলো একসাথে থাকা দরকার সেগুলো সাধারণত একই ফাইলে একত্রে রাখা হয়। এই ফাংশনগুলো প্যারামিটার (আর্গুমেন্ট) নিতে পারে, আর `return` কিওয়ার্ড ব্যবহার করে একটি মান _রিটার্ন_ করতে পারে। ফাংশন কল করা হয় `()` সিনট্যাক্স দিয়ে।

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 JavaScript-এ একটি ফাংশন ডিক্লারেট করার _অনেক_ ভিন্ন উপায় আছে। এই অন্য উপায়গুলো `function` কিওয়ার্ড ব্যবহার করার চেয়ে আলাদা দেখায়। ট্র্যাকটি ধীরে ধীরে সেগুলোর সাথে পরিচয় করিয়ে দেওয়ার চেষ্টা করে, তবে আপনি যদি আগে থেকেই সেগুলো সম্পর্কে জানেন, তবে নির্দ্বিধায় যেকোনোটি ব্যবহার করতে পারেন। বেশিরভাগ ক্ষেত্রেই একটি বা অন্যটি ব্যবহার করা ভালো-খারাপ কোনোটিই নয়।

## অন্য ফাইলে এক্সপোজ করা

একটি `function`, একটি কনস্ট্যান্ট বা একটি ভ্যারিয়েবলকে _অন্য ফাইলে_ ব্যবহার করার সুযোগ দিতে, `export` কিওয়ার্ড দিয়ে সেগুলোকে [এক্সপোর্ট][mdn-export] করতে হয়। এরপর অন্য একটি ফাইল `import` কিওয়ার্ড দিয়ে সেগুলো [ইমপোর্ট][mdn-import] করতে পারে। এটিকে মডিউল সিস্টেমও বলা হয়। এর একটি দুর্দান্ত উদাহরণ হলো সব টেস্ট যেভাবে কাজ করে। প্রতিটি অনুশীলনীতে অন্তত একটি ফাইল থাকে, যেমন `lasagna.js`, যেখানে _ইমপ্লিমেন্টেশন_ থাকে। এছাড়া অন্তত আরেকটি ফাইল থাকে, যেমন `lasagna.spec.js`, যেখানে _টেস্ট_ থাকে। এই ফাইলটি ইমপ্লিমেন্টেশন পরীক্ষা করার জন্য পাবলিক (অর্থাৎ এক্সপোর্ট করা) এনটিটিগুলো _ইমপোর্ট_ করে:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
