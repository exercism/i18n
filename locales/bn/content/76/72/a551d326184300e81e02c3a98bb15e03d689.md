# রিটার্ন

Crystal-এ, একটি মেথডের শেষ এক্সপ্রেশনটি তার মান রিটার্ন করে।
তবে, কখনও কখনও শেষ এক্সপ্রেশনের আগেই একটি মান রিটার্ন করতে হয়।
এর জন্য আপনি `return` কিওয়ার্ডটি ব্যবহার করতে পারেন, যা এর পরের এক্সপ্রেশনটির মান রিটার্ন করবে।
`return` কিওয়ার্ডের পরে লেখা কোড রান করা হবে না।

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
একটি মেথডের শেষ এক্সপ্রেশনটি যখন এমন মান হয় যা রিটার্ন করা উচিত, তখন `return` কিওয়ার্ডটি বাদ দেওয়া উচিত।
~~~~
