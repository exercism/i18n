# সম্পর্কে

`reduce` হলো Factor-এর সাধারণ ফোল্ড: এটি একটি সিকোয়েন্সের উপর দিয়ে হেঁটে যায় আর একটি বাইনারি কোয়োটেশনের মধ্য দিয়ে একটি অ্যাকুমুলেটর এগিয়ে নিয়ে যায়, যেখানে কোয়োটেশনটি চলমান অ্যাকুমুলেটর ও পরের এলিমেন্ট নিয়ে নতুন অ্যাকুমুলেটর বানায়।

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

কাস্টম সিড দিয়ে `reduce` এমন ফোল্ড প্রকাশ করতে পারে, যা `sum` বা `product` পারে না। যেমন, একটি সিকোয়েন্সের সবচেয়ে বড় মান বের করা, যেখানে সব এলিমেন্ট হেরে গেলে একটি ডিফল্ট মান ধরা হয়:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

সিড `0` নিজেও তুলনায় অংশ নেয়, তাই সব ঋণাত্মক সিকোয়েন্সও তার সবচেয়ে ছোট মান নয়, বরং `0` দেয়।

## `produce`: আনফোল্ড

`reduce`-এর দ্বৈত হলো `produce` (যা [`sequences`][sequences]-এ আছে): যেখানে `reduce` একটি সিকোয়েন্স *গ্রাস করে*, সেখানে `produce` একটি সিকোয়েন্স *তৈরি করে*। একটি প্রেডিকেট কোয়োটেশন চলমান অবস্থা পরীক্ষা করে; যতক্ষণ এটি ট্রুথি মান রিটার্ন করে, ততক্ষণ একটি বডি কোয়োটেশন পরের এলিমেন্ট তৈরি করে।

```
produce ( pred quot -- seq )
```

একসাথে ব্যবহার করলে `reduce` আর `produce` মিলে Factor-এর ফোল্ড/আনফোল্ড জোড়া তৈরি করে।

## কিউমুলেটিভ রিডাকশন

[`math.statistics`][math.statistics]-এর কিউমুলেটিভ পরিবার ইনপুটের সমান দৈর্ঘ্যের একটি সিকোয়েন্স রিটার্ন করে, যেখানে প্রতিটি এলিমেন্ট হলো সেই অবস্থানসহ তার আগ পর্যন্ত প্রিফিক্সের উপর করা রিডাকশন:

| word          | running operation |
|---------------|-------------------|
| `cum-sum`     | চলমান যোগফল      |
| `cum-product` | চলমান গুণফল       |
| `cum-min`     | চলমান সর্বনিম্ন     |
| `cum-max`     | চলমান সর্বোচ্চ      |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

কোনো রাশি সিকোয়েন্স জুড়ে *কীভাবে* বদলে গেল, কেবল তার চূড়ান্ত মান নয়, সেটি দেখতে চাইলে কিউমুলেটিভ রিডাকশন কাজে লাগে। এগুলো একটির পর একটি জুড়ে দেওয়াও কাজের: একটির আউটপুট নিজেই একটি সিকোয়েন্স, যা সরাসরি আরেকটিতে দেওয়া যায়।
