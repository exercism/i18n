# ভূমিকা

Common Lisp-এ স্ট্রিং হলো [ভেক্টর][concept-vectors], যা [ক্যারেক্টার][concept-characters] দিয়ে তৈরি। এগুলো ডাবল কোটেশনের ভেতরে রাখা ক্যারেক্টার হিসেবে লেখা হয় (_যেমন_ "Hello World!")।

`stringp` প্রেডিকেট ট্রু রিটার্ন করবে কেবল তখনই, যখন প্রদত্ত মানটি একটি স্ট্রিং হয়।

`subseq` ফাংশন দিয়ে স্ট্রিংকে সাব-স্ট্রিংয়ে ভাগ করা যায়; এটি স্ট্রিং, একটি শুরুর ইনডেক্স এবং ঐচ্ছিকভাবে একটি শেষ ইনডেক্স নেয়। ইনডেক্সিং শূন্য থেকে শুরু হয়।

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

`string=` দিয়ে স্ট্রিংয়ের সমতা যাচাই করা যায়। অক্ষরগুলোর বড়-ছোট হাতের পার্থক্য উপেক্ষা করতে চাইলে `string-equal` ব্যবহার করা যায়।

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

স্ট্রিংয়ের অক্ষর বড় হাতের করা, ছোট হাতের করা এবং প্রতিটি শব্দের প্রথম অক্ষর বড় করার মতো কাজ `string-upcase`, `string-downcase` এবং `string-capitalize` দিয়ে করা যায়।

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
