# সম্পর্কে

C++-এর যাত্রা শুরু করছি আমরা ভ্যারিয়েবল, ফাংশন কল আর কমেন্ট দিয়ে।

## কমেন্ট

কমেন্ট দুই ধরনের হয়: এক লাইনের আর একাধিক লাইনের।
একই লাইনে `//`-এর পরে যা কিছু আসে, কম্পাইলার সেগুলো উপেক্ষা করে।
একাধিক লাইনের কমেন্টকে C-স্টাইল কমেন্টও বলা হয়।
এগুলো `/*` আর `*/` দিয়ে ঘেরা থাকে।
এগুলোর মাঝখানে যা কিছু থাকে, সেটিও উপেক্ষা করা হয়।

## ভ্যারিয়েবল

C++ একটি টাইপযুক্ত প্রোগ্রামিং ভাষা।
সব টাইপ কম্পাইল টাইমেই জানা থাকা দরকার, আর সাধারণত সেগুলো আপনাকে স্পষ্টভাবে বলে দিতে হয়।
একটি ভ্যারিয়েবলের টাইপ বদলানো যায় না।
`years` নামের একটি ইন্টিজার ভ্যারিয়েবল এভাবে ডিক্লেয়ার করা যায়:

```cpp
int years;
```

ভ্যারিয়েবল ডিক্লেয়ারের সময়ই ইনিশিয়ালাইজ করা ভালো অভ্যাস।
এটা করার জন্য C++ বিভিন্ন উপায় দেয়।
দ্বিতীয় বন্ধনী `{}` দিয়ে লেখা সংস্করণটি আধুনিক C++-এর সঙ্গে বেশি মেলে, তবে সমান চিহ্নের সংস্করণটিও বেশ কমন।

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++-এ আনইনিশিয়ালাইজড ভ্যারিয়েবল ব্যবহার করা আসলেই যায়।
যতক্ষণ না ভ্যারিয়েবলটি সচেতনভাবে সেট করা হয়, ততক্ষণ এটি আনডিফাইন্ড থাকে এবং তাতে যা-ই থাকতে পারে।

আনডিফাইন্ড বিহেভিয়ার আপনার প্রোগ্রামকে একদম সবচেয়ে খারাপ মুহূর্তে ক্র্যাশ করাতে পারে, যদিও এর আগে পর্যন্ত সব ঠিকঠাক চলছিল।

## গাণিতিক অপারেশন

`*`, `+` বা `-`-এর মতো গাণিতিক অপারেটর `3 * 2` বা `tomatoes + potatoes`-এর মতো এক্সপ্রেশনের অংশ হতে পারে।

## ভ্যারিয়েবল আপডেট করা

টাইপ একই থাকলে আপনি ভ্যারিয়েবলে আবার ভ্যালু অ্যাসাইন করতে পারেন:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## ফাংশন

ফাংশনের একটি নাম, একটি রিটার্ন টাইপ আর একটি (খালিও হতে পারে) প্যারামিটার লিস্ট থাকে।
`always_fortyseven` নামের একটি ফাংশনের উদাহরণ, যা সবসময় 47 রিটার্ন করবে, দেখতে এমন হবে:

```cpp
int always_fortyseven() {
    return 47;
}
```

এখানে `vip_fee`, যার একটি প্যারামিটার আছে:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

অথবা `total_fee`, তিনটি প্যারামিটারযুক্ত একটি ফাংশন, যার ভেতরে আরেকটি ফাংশন কল করা হয়েছে।

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

অন্য কিছু প্রোগ্রামিং ভাষার মতো C++-এ ফাংশন শেষ স্টেটমেন্টের মান রিটার্ন করে না।
কোড কম্পাইল হতে হলে `return` কিওয়ার্ডটি লাগবেই।

### হোয়াইটস্পেস

হোয়াইটস্পেস সোর্স কোড ফরম্যাট করতে ব্যবহৃত হয় এবং এতে স্পেস, ট্যাব বা নিউলাইন থাকে।
কম্পাইলার অপ্রয়োজনীয় হোয়াইটস্পেস উপেক্ষা করে, তাই আপনি এটি দিয়ে আপনার কোড সাজাতে পারেন।
হোয়াইটস্পেসের বুদ্ধিদীপ্ত ব্যবহার আপনার কোড পড়া সহজ করে তুলতে পারে।
ফরম্যাটিংয়ের বিভিন্ন স্ট্যান্ডার্ড আছে, তবে এগুলো সবই প্রচলিত রীতি মাত্র, কম্পাইলার এগুলো মানতে বাধ্য করে না।

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
