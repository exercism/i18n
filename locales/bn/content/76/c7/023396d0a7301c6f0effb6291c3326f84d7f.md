# পরিচিতি

Kotlin-এ ডেটা ও আচরণ একসাথে ধরে রাখতে ক্লাস ব্যবহার করা যায়।
`class` কিওয়ার্ড দিয়ে একটি ক্লাস ডিক্লেয়ার করা হয়।
উদাহরণস্বরূপ:

```kotlin
class Car
```

ক্লাসটিকে কল করলেই তার একটি ইনস্ট্যান্স তৈরি হয়।

```kotlin
val instance = Car()
```

## প্রপার্টি

উপরের উদাহরণগুলোতে `Car` ক্লাসটি কোনো প্রপার্টি ছাড়াই ডিক্লেয়ার করা হয়েছিল।
ক্লাসের বডিতে, `{}`-এর ভেতরে প্রপার্টি ডিক্লেয়ার করা যায়; পরিবর্তনযোগ্য প্রপার্টির জন্য `var` আর অপরিবর্তনযোগ্য প্রপার্টির জন্য `val` ব্যবহার করতে হয়।
উদাহরণস্বরূপ:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

এর বিকল্পে, যে কনস্ট্রাক্টর প্রপার্টিগুলো গ্রহণ করে, তার মধ্যেও প্রপার্টি ডিফাইন করা যায়।

## কনস্ট্রাক্টর

Kotlin-এ দুই ধরনের কনস্ট্রাক্টর রয়েছে: [প্রাইমারি][primary-constructors] আর [সেকেন্ডারি কনস্ট্রাক্টর][secondary-constructors]।
প্রাইমারি কনস্ট্রাক্টর ক্লাস ডিক্লারেশনের একই লাইনে ডিক্লেয়ার করা হয়।
উদাহরণস্বরূপ:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

কোনো অ্যানোটেশন বা ভিজিবিলিটি মডিফায়ার না থাকলে `constructor` কিওয়ার্ডটি বাদ দেওয়া যায়:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
ক্লাসে শুধু প্রপার্টি থাকলে Kotlin ক্লাসটিকে বডিসহ ডিফাইন করার সুযোগ দেয়, কার্লি ব্রেস `{}`-এর কোনো দরকার নেই:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

একটি ক্লাসে কেবল একটি প্রাইমারি কনস্ট্রাক্টর থাকতে পারে।
সেকেন্ডারি কনস্ট্রাক্টর হলো অতিরিক্ত কনস্ট্রাক্টর, যা ক্লাসের বডিতে `constructor` কিওয়ার্ড দিয়ে ডিক্লেয়ার করে যোগ করা যায়।
উদাহরণস্বরূপ:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

সেকেন্ডারি কনস্ট্রাক্টরকে `this` কল করার মাধ্যমে প্রাইমারি কনস্ট্রাক্টরকে ইনভোক করতে হয়।

## ইনিশিয়ালাইজার ব্লক

প্রাইমারি কনস্ট্রাক্টরই ক্লাসের প্রপার্টিগুলো সেট করে।
অবজেক্ট তৈরির সময় আরও কিছু করার দরকার হলে অতিরিক্ত কাজ সম্পন্ন করতে `init` ব্লক ব্যবহার করা যায়।

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## ফাংশন

ক্লাসের বডিতে ফাংশন ডিফাইন করা যায়।
উদাহরণস্বরূপ:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## ভিজিবিলিটি

প্রপার্টি আর ফাংশন `private`, `public`, `internal` বা `protected` হতে পারে।

- `private` শুধু ক্লাসের ভেতর থেকেই অ্যাক্সেস করা যায়
- `protected` ক্লাসের ভেতরের জিনিসপত্র থেকে অ্যাক্সেস করা যায়, সেই সাথে যেকোনো সাবক্লাস থেকেও
- `internal` একই [মডিউল][kotlin-modules]-এর ভেতরের জিনিসপত্র থেকে অ্যাক্সেস করা যায়
- `public` ক্লাসটি ব্যবহার করা অন্য কম্পোনেন্টগুলো থেকেও অ্যাক্সেস করা যায়

উদাহরণস্বরূপ:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```

[kotlin-modules]: https://kotlinlang.org/spec/packages-and-imports.html#modules
[primary-constructors]: https://kotlinlang.org/docs/classes.html#primary-constructor
[secondary-constructors]: https://kotlinlang.org/docs/classes.html#secondary-constructors
