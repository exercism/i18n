# সম্পর্কে

[বিশেষ ফর্ম with][with] এমন একটি উপায় দেয় যাতে সম্ভাব্য ব্যর্থ ধাপগুলোর একটি সিরিজের "হ্যাপি পাথ"-এ মনোযোগ দেওয়া যায় এবং ব্যর্থতাগুলো পরে সামলানো যায়।

ধরুন, আপনি কয়েকটি চেক দিয়ে একটি ইউজারনেম যাচাই করতে চান। তখন আপনি হয়তো `case` ব্যবহার করতে পারেন:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

এখন হয়তো এটি পাঠযোগ্য মনে হচ্ছে, কিন্তু আরও নেস্টেড চেক যোগ করলে এটি 점점 জটিল হয়ে উঠবে। এমন পরিস্থিতিতে `with` ব্যবহার করুন:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

প্রতিটি ধাপে, কোনো ক্লজ মিললে, `do` ব্লকটি কার্যকর হওয়া পর্যন্ত শৃঙ্খলটি চলতে থাকবে। কোনো মিল ব্যর্থ হলে, শৃঙ্খলটি থেমে যায় এবং যে ক্লজটি মেলেনি সেটিই রিটার্ন করা হয়।

শৃঙ্খলে আপনি গার্ড ব্যবহার করতে পারেন, পাশাপাশি সাধারণ মিলের জন্য `=` অপারেটরও।

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

সবশেষে, ব্যর্থ মিলগুলো ধরার এবং রিটার্ন ভ্যালু পরিবর্তন করার জন্য আপনি একটি `else` ব্লক ব্যবহারের সুযোগ পাবেন।

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

`else` হলো `with` ক্লজের যেকোনো অমিল ভ্যালুর জন্য একটি `case` স্টেটমেন্টের মতো। যে ভ্যালুটি প্রথমে মিলবে সেটিই ব্যবহৃত হবে।
