# নির্দেশনা

আপনি একটি স্থানীয় বাস্কেটবল দলের ওয়েবসাইট রক্ষণাবেক্ষণের জন্য একটি ওয়েব ডেভেলপমেন্ট টিমের সাথে কাজ করছেন। ওয়েব ডেভেলপমেন্ট টিমটি Elixir-এর সাথে কম পরিচিত এবং দ্রুত ডেভেলপমেন্ট সহজ করতে নেস্টেড ম্যাপের একটি সিরিজ থেকে ডেটা বের করার জন্য একটি ফাংশন চাইছে।

## 1. একটি নেস্টেড ম্যাপ স্ট্রাকচার থেকে ডেটা বের করুন

`extract_from_path/2` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি দুটি আর্গুমেন্ট নেয়:

- `data`: বাস্কেটবল দল সম্পর্কিত ডেটাসহ একটি নেস্টেড ম্যাপ স্ট্রাকচার।
- `path`: পিরিয়ড দিয়ে আলাদা করা কী (key) নিয়ে গঠিত একটি স্ট্রিং, যা শেষ কী (key) থেকে সংশ্লিষ্ট মান বের করতে ব্যবহৃত হয়।

যদি path-এর কোনো এক ধাপে মান বা কী (key) বিদ্যমান না থাকে, তাহলে `nil` রিটার্ন করা উচিত।

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

এই ফাংশনটি ইমপ্লিমেন্ট করার সময় _Access Behaviour_ ব্যবহার করুন।

নেস্টেড ম্যাপ ডেটা স্ট্রাকচার নিয়ে কাজ করার জন্য `Map` বা `Kernel` মডিউলের কোনো ফাংশন ব্যবহার করবেন না।

## 2. অন্তর্ভুক্ত ফাংশন ব্যবহার করে রিফ্যাক্টর করুন

আপনার কোড রিভিউ করা সহকর্মী আপনার ইমপ্লিমেন্টেশনের সাথে প্রায় একই রকম কাজ করে এমন একটি `Kernel` মডিউল ফাংশনের কথা জানান।

এই `Kernel` মডিউল ফাংশনটি ব্যবহার করতে `get_in_path/2` ইমপ্লিমেন্ট করুন।

প্রত্যাশিত আর্গুমেন্টগুলো অংশ ১-এর মতোই।

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
