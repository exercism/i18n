# ভূমিকা

## অ্যারে

PHP-তে অ্যারে হলো অর্ডারড ম্যাপ।
ম্যাপ হলো এমন একটি ডেটা স্ট্রাকচার, যা একটি মানের সঙ্গে একটি কী (key) যুক্ত করে।
অ্যারে বহুমুখী, এগুলোকে লিনিয়ার অ্যারে (`C` বা `Java`-এর মতো), লিস্ট [ভেক্টর], হ্যাশ-টেবিল, ডিকশনারি, কালেকশন, স্ট্যাক বা কিউ হিসেবেও ব্যবহার করা যায়।

কী (key) ঐচ্ছিক, তবে দিলে সেটি অবশ্যই একটি `int` বা একটি `string` হতে হবে।
কোনো কী (key) না দিলে, PHP ডিফল্টভাবে `0` থেকে শুরু করে ক্রমবর্ধমান ইন্টিজারকে কী (key) হিসেবে ব্যবহার করে।

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

একটি অ্যারে সব টাইপের মান রাখতে পারে।
প্রতিটি মানের টাইপ আলাদা হতে পারে।

### অ্যারে ব্যবহার করা

অ্যারে লিটারাল হিসেবে ডিক্লেয়ার করা যায় (উপরের মতো কোডে লেখা), অথবা ফাংশন দিয়ে তৈরি ও পরিচালনা করা যায়।
ইনডেক্স অপারেটর দিয়ে মান অ্যাক্সেস, অ্যাসাইন ও অ্যাপেন্ড করা যায়:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## পরিবর্তনশীল দৈর্ঘ্যের আর্গুমেন্ট

ফাংশনের আর্গুমেন্ট এমনভাবে নির্দিষ্ট করা যায় যাতে সেটি যেকোনো সংখ্যক আর্গুমেন্ট নিতে পারে:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
