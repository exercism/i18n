## টেস্ট চালানো

1. আপনার PHP অনুশীলনী ডিরেক্টরির রুটে যান, যা `<EXERCISM_WORKSPACE>/php`.
   Exercism ওয়ার্কস্পেস খুঁজে বের করতে রান করুন

   ```shell
   exercism workspace
   ```

2. [PHPUnit] আগে থেকে ইনস্টল করা না থাকলে ইনস্টল করুন।
3. এই কমান্ড দিয়ে টেস্টগুলো চালান:

   ```shell
   phpunit test_file.php
   ```

   উদাহরণস্বরূপ, Hello World অনুশীলনীর টেস্ট চালাতে হলে এটি চালান:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
