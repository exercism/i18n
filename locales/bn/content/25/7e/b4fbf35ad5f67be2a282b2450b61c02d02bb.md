# নির্দেশাবলি

লিস্প এলিয়েনরা যখন প্রথম পৃথিবীতে এসেছিল, তখন তারা অগণিত অদ্ভুত আর বিস্ময়কর জিনিসের মুখোমুখি হয়েছিল, কিন্তু তাদের সবচেয়ে প্রিয় আবিষ্কারগুলোর একটা ছিল "পোষা প্রাণী"। সত্যি কথা বলতে, কোন এলিয়েনই বা একটা কুকুরছানা বা বিড়ালছানা দেখে গলে পড়বে না?

লুডভিগ, সম্প্রতি পৃথিবীতে ছুটি কাটিয়ে ফেরার পর, ঠিক করেছে তারা নিজের একটা পোষা প্রাণী চায়! সমস্যা শুধু একটাই? পছন্দের সংখ্যাটা একেবারে বেশি! তাহলে আপনি হয়তো একটা প্রোগ্রাম লিখে লুডভিগকে সাহায্য করতে পারেন, যাতে তারা তাদের পরের আদুরে বন্ধুটি খুঁজে বের করতে আর তার যত্ন নিতে পারে?

## 1. সঙ্গী বাছাই

লুডভিগ পোষা প্রাণী নেওয়ার ব্যাপারে দৃঢ়প্রতিজ্ঞ, কিন্তু ভেবে দেখা বলতে এর বেশি দূর এগোয়নি। তাহলে প্রথম ধাপ হলো, কোন ধরনের পোষা প্রাণী নেওয়া হবে সেটা ঠিক করা!

লুডভিগ এমন একজন সঙ্গী খুঁজে পেতে চায় যার ব্যক্তিত্ব তাদের নিজের ব্যক্তিত্বের সঙ্গে মানিয়ে যায়। আপনি কি লুডভিগের জন্য `pal-picker` নামের একটা ফাংশন লিখতে পারেন, যেটা কোনো ব্যক্তিত্বের বৈশিষ্ট্য (একটা কিওয়ার্ড) নেয় আর সেই বৈশিষ্ট্যের পোষা প্রাণীর ধরনটা (একটা স্ট্রিং) রিটার্ন করে?

এই নির্দিষ্ট ক্ষেত্রে:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

অন্য, অজানা ব্যক্তিত্বের ক্ষেত্রে আপনার ফাংশনের ফল হওয়া উচিত: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. তাদের স্বাভাবিক আবাসস্থলে

এখন লুডভিগের একজন নতুন বন্ধু আছে, তাই থাকার জায়গা দরকার! তাদের পোষা প্রাণীর জন্য সঠিক মাপের বিছানা / ট্যাংক / খাঁচা বেছে নিতে আপনি কি লুডভিগকে সাহায্য করতে পারেন?

এখানে লুডভিগের `habitat-fitter` নামের একটা ফাংশন দরকার, যা পোষা প্রাণীর ওজন কিলোগ্রামে (একটা ইন্টিজার) থেকে উপযুক্ত আবাসস্থলের আকার (একটা কিওয়ার্ড) বেছে নেবে।

প্রতিটি মাপের পোষা প্রাণীর জন্য যে আবাসস্থলগুলো দরকার:

- More than or equal to 40kg -> `:massive`
- 20kg to 39kg inclusive -> `:large`
- 10kg to 19kg inclusive -> `:medium`
- 1kg to 9kg inclusive -> `:small`
- Less than or equal to 0kg -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. আর এখন, খাওয়ার পালা

পৃথিবীর সব পোষা প্রাণীর একটা কমন বিষয় হলো খাবারের দরকার! তবে লুডভিগের কাছে এই ধারণাটা কিছুটা অপরিচিত, কারণ তারা প্রায়ই পোষা প্রাণীর খাবারের বাটি আবার ভরে দিতে ভুলে যায়।

বাটি কখন আবার ভরতে হবে সেটা জানানোর জন্য লুডভিগের `feeding-time` নামের একটা সরল ফাংশন কাজে লাগবে। ফাংশনটা বাটি কতটা ভরা, তার শতকরা হার (একটা ইন্টিজার) নেবে আর একটা স্ট্রিং আকারে বার্তা রিটার্ন করবে।

যদি খাবারের মাত্রা হয়:

- Above 20% -> `"All is well."`
- 20% or below -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. আচরণবিধি

সব মৌলিক বিষয় গুছিয়ে ফেলার পর, লুডভিগ "আদর করা" আর "ফেচ" খেলার মতো বেশ কিছু দারুণ কাজ করতে মুখিয়ে আছে। তবে কথা হলো, সব পোষা প্রাণী এই কাজগুলোর জন্য উপযুক্ত নয়।

লুডভিগ দুটো ফাংশন চায়, `pet` আর `play-fetch`, যেগুলো পোষা প্রাণীর ধরনটা (একটা স্ট্রিং হিসেবে) নেয় আর কাজটা যদি না মানায়, তাহলে হয় কিছুই রিটার্ন করে না, নাহয় এমন একটা বার্তা দেয়: `"Maybe not with this pet..."`

ধরে নিন, শুধু `"Dog"`-ই ফেচ খেলবে আর `"Fish"` ছাড়া বাকি সব পোষা প্রাণীকে আদর করা যাবে।

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
