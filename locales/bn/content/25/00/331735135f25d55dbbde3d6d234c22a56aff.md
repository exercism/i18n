# পরিচিতি

C# স্ট্রিং সম্পর্কে মনে রাখার মূল বিষয়টি হলো, এগুলো অপরিবর্তনীয় অবজেক্ট, যা ইউনিকোড ক্যারেক্টারের (অক্ষর, সংখ্যা, যতিচিহ্ন ইত্যাদি) একটি ক্রম হিসেবে টেক্সট প্রকাশ করে। একটি `string` ইনস্ট্যান্স ডিফাইন করতে ডাবল কোট ব্যবহার করা হয়:

```csharp
string fruit = "Apple";
```

কোনো স্ট্রিং ম্যানিপুলেট করতে হলে তার একটি [মেথড][methods] বা [প্রপার্টি][properties] কল করা যায়। ডিফাইন হওয়ার পর স্ট্রিং ভ্যালু কখনোই বদলাতে পারে না, তাই সব স্ট্রিং ম্যানিপুলেশন মেথড নতুন একটি স্ট্রিং রিটার্ন করে।

একটি স্ট্রিং ডাবল কোট (`"`) ক্যারেক্টার দিয়ে ঘেরা থাকে। কিছু বিশেষ ক্যারেক্টার ব্যাকস্ল্যাশ (`\`) ক্যারেক্টার দিয়ে [এস্কেপ][escaping] করতে হয়। স্ট্রিংয়ের শুরুতে অ্যাট (`@`) চিহ্নও বসানো যায়, যা এটিকে [ভার্বাটিম স্ট্রিং][verbatim] বানায় এবং তখন কোনো এস্কেপ করা ক্যারেক্টার আর গ্রাহ্য হয় না।

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

আপনার যদি একটি স্ট্রিংয়ের শুধু একটি অংশ দরকার হয়, তাহলে [`Substring()` মেথড][substring] দিয়ে ঠিক সেই অংশটুকু বের করে নিতে পারেন:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

একটি `string`-এর মধ্যে অন্য একটি `string` প্রথমবার কোথায় আসে, তার ইনডেক্স বের করতে [`IndexOf`() মেথড][indexof] ব্যবহার করা যায়; নির্দিষ্ট ভ্যালুটি খুঁজে না পেলে এটি `-1` রিটার্ন করে:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

সবশেষে, একটি স্ট্রিং [কনক্যাটিনেট করার অনেক উপায় আছে][concatenation]। সবচেয়ে সহজ উপায় হলো [`+` অপারেটর][plus-operator] ব্যবহার করা।

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

সাধারণ কনক্যাটিনেশনের চেয়ে জটিল যেকোনো স্ট্রিং ফরম্যাটিংয়ের জন্য [স্ট্রিং ইন্টারপোলেশন][interpolation] বেশি পছন্দনীয়। একটি স্ট্রিংয়ে ইন্টারপোলেশন চালু করতে তার শুরুতে ডলার (`$`) চিহ্ন বসান।

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
