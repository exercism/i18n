# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি স্থানীয় নিউজ স্টেশনের জন্য ওয়েদার রিপোর্ট তৈরি করবেন।

## ওয়েদার রিপোর্ট তৈরি করুন

আপনি কিছু স্টাব করা ফাংশন আর নিচের enum দিয়ে শুরু করবেন:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

আপনাকে `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."` এর মতো করে একটি ওয়েদার রিপোর্ট ফরম্যাট করতে হবে।
সঠিক আবহাওয়ার অবস্থা আউটপুট দেয় এমন ফাংশনটিও আপনাকে ইমপ্লিমেন্ট করতে হবে।

উদাহরণস্বরূপ, নিচের স্নিপেটটি একটি বৃষ্টির দিনের জন্য `get_weather_report` ফাংশনের প্রত্যাশিত আউটপুট দেখাচ্ছে।

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

আর একটি রোদেলা দিনের জন্য:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
