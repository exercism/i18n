# পরিচিতি

একটি [টাপল](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) হলো নামহীন কিন্তু ক্রমবদ্ধ মানের একটি _ইমিউটেবল_ দল। টাপল যেকোনো (বা একাধিক) ডেটা টাইপ ধারণ করতে পারে, এমনকি অন্য টাপলও।

টাপলকে `(` ও `)` অক্ষরের মধ্যে কমা দিয়ে আলাদা করা মান হিসেবে ডিফাইন করা হয়: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

শুধু একই দৈর্ঘ্য এবং একই টাইপের (একই ক্রমে) টাপলদেরই তুলনা করা যায়। টাপলের স্ট্রাকচারাল সমতা থাকে, অর্থাৎ সেগুলো সমান হয় _শুধু_ তখনই, যখন তাদের সব মান সমান হয়।

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

টাপল থেকে মান বের করার [তিনটি উপায়](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) রয়েছে:

- `fst` ও `snd` ফাংশন
- টাপল ডিকনস্ট্রাকশন
- প্যাটার্ন ম্যাচিং

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
প্রযুক্তিগতভাবে, আপনি `.Item1`, `.Item2`, ... প্রপার্টি ব্যবহার করে একটি টাপলের মান অ্যাক্সেস করতে পারেন, তবে এটি নিরুৎসাহিত এবং এর ফলে একটি কম্পাইলার ওয়ার্নিং আসে।
~~~~

## টাপল সম্পর্কে মূল বিষয়গুলো

টাপল সম্পর্কে জেনে রাখার মতো কিছু মূল বিষয় হলো:

- একটি টাপল টাইপের নির্দিষ্ট একটি ইনস্ট্যান্স হলো একটি একক অবজেক্ট, অনেকটা C#-এর দুই এলিমেন্টের অ্যারের মতো। ফাংশনের সাথে এগুলো ব্যবহার করলে সেগুলো একটি একক প্যারামিটার হিসেবে গণ্য হয়। একমাত্র ব্যতিক্রম হলো একাধিক প্যারামিটার নিয়ে F#-বহির্ভূত কোড কল করার সময়, সেক্ষেত্রে আপনি একটি টাপল পাস করেন এবং এর মানগুলো স্বয়ংক্রিয়ভাবে সংশ্লিষ্ট প্যারামিটারের মান হিসেবে বের করে নেওয়া হয়।
- টাপল টাইপকে স্পষ্ট নাম দেওয়া যায় না। টাপল টাইপের “নাম” নির্ধারিত হয় যে টাইপগুলো একসাথে গুণ করা হয় সেই টাইপগুলোর সমন্বয়ে।
- টাপল নির্ধারণ করে কমা, বন্ধনী নয়; কমাই হলো মূল চিহ্ন। বন্ধনী ছাড়াও আপনি টাপল ডিফাইন করতে পারেন, যদিও মাঝে মাঝে তা বিভ্রান্তিকর হতে পারে। F#-এ আপনি যদি একটি কমা দেখেন, সম্ভবত তা একটি টাপলের অংশ।
- টাপল ফাংশনের আর্গুমেন্ট হিসেবে এবং ফাংশনের রিটার্ন ভ্যালু হিসেবে ব্যবহার করা যায়।
