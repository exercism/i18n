# Introduction

## ইনস্ট্যান্স ভ্যারিয়েবল

অবজেক্টগুলো _ইনস্ট্যান্স ভ্যারিয়েবল_ সেট করে নিজেদের স্টেট ধরে রাখতে পারে।
এই ভ্যারিয়েবলগুলো একটি অবজেক্টের ভেতরে থাকে এবং সাধারণত কিছু অভ্যন্তরীণ স্টেট সংরক্ষণ করতে ব্যবহৃত হয়।

ইনস্ট্যান্স ভ্যারিয়েবল সবসময় একটি `@` দিয়ে শুরু হয়।
আপনি একটি `@` দিয়ে শুরু হওয়া ভ্যারিয়েবল সেট করে নতুন ইনস্ট্যান্স ভ্যারিয়েবল তৈরি করতে পারেন।
যেমন:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

অবজেক্টগুলো সাধারণত তাদের প্রাথমিক স্টেট একটি `initialize` মেথডে সেট করে, যা একটি ক্লাসে `new` কল করলে স্বয়ংক্রিয়ভাবে কল হয়।

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

`initialize` মেথড আর্গুমেন্টও নিতে পারে, যাতে প্রতিটি ইনস্ট্যান্স একটি কাস্টম স্টেট নিয়ে শুরু করতে পারে:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

_ইনস্ট্যান্স_ ভ্যারিয়েবলগুলোকে বাইরের পড়া ও লেখা থেকে প্রাইভেট ধরে নেওয়া ভালো অভ্যাস।
তার বদলে আমরা তাদের মান পড়া ও সেট করার জন্য মেথড ডিফাইন করি।
যেমন:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## নিল

[নিল][nil-dictionary] একটি ইংরেজি শব্দ, যার অর্থ "কিছুই না" বা "শূন্য"।
রুবিতে, একটি অবজেক্টের _অনুপস্থিতি_ বোঝাতে `nil` ব্যবহৃত হয়।
অন্য প্রোগ্রামিং ভাষায় `null` বা `none` মান একই ধরনের ভূমিকা পালন করতে পারে।

```ruby
# I do not have a favorite color
favorite_color = nil
```

রুবি যেকোনো ইনস্ট্যান্স ভ্যারিয়েবলকে প্রথমবার পেলেই ডিফল্ট মান হিসেবে `nil` দেয়, যতক্ষণ না অন্য কোনো মান দেওয়া হয়।

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
