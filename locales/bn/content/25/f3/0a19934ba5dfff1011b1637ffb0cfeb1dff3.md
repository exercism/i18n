# নির্দেশনার সংযোজন

## Python-এ এই অনুশীলনীটি কীভাবে সাজানো আছে

লিংকড লিস্ট বিভিন্ন রকম অন্তর্নিহিত ডেটা স্ট্রাকচার দিয়ে বিভিন্নভাবে ইমপ্লিমেন্ট করা যায়, তবে এখানে আমরা চাই আপনি আপনার লিংকড লিস্টটি OOP ধাঁচে ইমপ্লিমেন্ট করুন।

স্টাব ফাইলে আপনি একটি `Node` ক্লাসের শুরু দেখতে পাবেন, সেই সঙ্গে একটি `LinkedList` ক্লাসও।
আপনার `Node` ক্লাসকে তার মান ট্র্যাক করতে হবে, সেই সঙ্গে কোন নোডগুলো তার আগে বা পরে থাকে তাও।
আপনার `push`, `pop`, `shift`, `unshift`, আর `len`-এর জন্য বিশেষ মেথডটি `LinkedList` ক্লাসে ইমপ্লিমেন্ট করতে হবে।
ইটারেশনের জন্য একটি বিশেষ `iter` মেথড ইমপ্লিমেন্ট করাও আপনার কাজে লাগতে পারে।

মূল অনুশীলনীর থেকে আলাদা, আমরা খালি `LinkedLists`-এর উপর `pop` এবং `shift` কল করে এরর পরিস্থিতি পরীক্ষা করব, তাই আপনাকে যথাযথভাবে এরর `raise` করতে হবে।

সবশেষে, উপরে বর্ণিত মেথডগুলোর পাশাপাশি আমরা চাই আপনি `delete` ইমপ্লিমেন্ট করুন।
`delete` একটি আর্গুমেন্ট নেবে, যেটি হলো লিংকড লিস্ট থেকে যে মানটি সরাতে হবে তা।
মানটি যদি একবারের বেশি থাকে, তবে কেবল **প্রথম** উপস্থিতিটি সরানো উচিত।

## এক্সেপশন মেসেজ

কখনও কখনও [এক্সেপশন raise করা][raising] প্রয়োজন হয়। এটি করার সময়, এররটির উৎস কী তা বোঝাতে আপনার সর্বদা একটি **অর্থবহ এরর মেসেজ** যোগ করা উচিত।
এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিং করতে যথেষ্ট সাহায্য করে।
এমন পরিস্থিতির জন্য যেখানে আপনি জানেন এররের উৎসটি নির্দিষ্ট কোনো টাইপ হবে, আপনি [বিল্ট-ইন এরর টাইপগুলোর][error types] একটি raise করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যোগ করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে প্রয়োজন, `delete()` করা একটি নোড মান লিংকড লিস্টে পাওয়া না গেলে একটি `ValueError` "থ্রো" করতে আপনি [raise স্টেটমেন্টটি][raise] ব্যবহার করুন।
এর পাশাপাশি, `pop()` করার জন্য কোনো নোড বাকি না থাকলে একটি `IndexError` থ্রো করা উচিত।
আপনি যদি এই `exceptions`-গুলো `raise` করেন এবং সেগুলোর সঙ্গে মেসেজও দেন, তবেই টেস্টগুলো পাস করবে।

মেসেজসহ একটি `ValueError` raise করতে, মেসেজটি `exception` টাইপে একটি আর্গুমেন্ট হিসেবে লিখুন:

```python
# When the value passed to `delete()` is not found.
if not found:
    raise ValueError("Value not found")

```

মেসেজসহ একটি `IndexError` raise করতে, মেসেজটি `exception` টাইপে একটি আর্গুমেন্ট হিসেবে লিখুন:

```python
# When pop() is called and there are no nodes left in the linked list
if self.length == 0:
    raise IndexError("List is empty")

```


## Python-এ বিশেষ মেথড

এই অনুশীলনীর টেস্টগুলো আপনার `LinkedList`-এর উপর `len()`-ও কল করবে।
`len()` কাজ করার জন্য আপনাকে একটি `__len__` বিশেষ মেথড তৈরি করতে হবে।
Python-এ বিশেষ বা "dunder" মেথড ইমপ্লিমেন্ট করার বিস্তারিত জানতে দেখুন [Python Docs: বেসিক অবজেক্ট কাস্টমাইজেশন][basic customization] এবং [Python Docs: object.__len__(self)][__len__]।

আমরা আরও সুপারিশ করি যে আপনার লিংকড লিস্টের উপর ইটারেশন করতে সাহায্য করবে এমন একটি বিশেষ [`__iter__`][__iter__] মেথড তৈরি করুন।
