# পরিচিতি

যখন একটি ফাংশন প্যারামিটার হিসেবে আরেকটি ফাংশন (বা ক্লোজার) গ্রহণ করে, তখন পাস করা সেই ক্লোজারকে ডিফল্টভাবে *নন-এস্কেপিং* বলা হয়।
ফাংশনটি নিজে ইতিমধ্যে রিটার্ন করার পরেও যদি কোনো ক্লোজারকে কল করা হয়, তখন বলা হয় যে ক্লোজারটি ফাংশনটি *এস্কেপ* করছে।

এই পরিস্থিতি সাধারণত ঘটে যখন:

- কোনো ক্লোজার একটি এক্সটার্নাল ভ্যারিয়েবল বা প্রপার্টিতে সংরক্ষণ করা হয়।
- কোনো কাজ সম্পন্ন হওয়ার পর অ্যাসিনক্রোনাসভাবে একটি ক্লোজার রান করা হয়।
- পরে কল করার জন্য ফাংশন থেকে একটি ক্লোজার রিটার্ন করা হয়।

নিচের উদাহরণটি দেখুন:

```swift
func emptyKitchen(_ order: String) -> String {
    "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}
```

এই কোডে `prepare` `kitchen` নামের একটি ফাংশন গ্রহণ করে, `kitchen`-কে কল করে এমন একটি নতুন ফাংশন `newKitchen` তৈরি করে, এবং `newKitchen` রিটার্ন করে।
এই কোড কম্পাইল করার চেষ্টা করলে একটি এরর দেখা যায়: `Escaping local function captures non-escaping parameter 'kitchen'`.

যেহেতু `newKitchen` `prepare`-এর পরেও টিকে থাকে, তাই `kitchen` ক্লোজারটি এস্কেপ করে।
এটি সম্ভব করতে প্যারামিটারের টাইপে `@escaping` অ্যাট্রিবিউট দিয়ে চিহ্নিত করুন।

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}

let restaurant = prepare(
    order: "sandwich",
    kitchen: prepare(
        order: "chicken",
        kitchen: prepare(order: "steak", kitchen: emptyKitchen)
    )
)

print(restaurant("pork chop"))
// Prints "Sorry, we're all out of pork chop."

print(restaurant("chicken"))
// Prints "One chicken coming up!"
```

`@escaping` অ্যাট্রিবিউট Swift কম্পাইলারকে জানায় যে ক্লোজারটি ঠিক এই ফাংশন কলের পরেও টিকে থাকবে, ফলে Swift যথাযথভাবে মেমরি ও ক্যাপচার করা রেফারেন্স পরিচালনা করতে পারে।
