# নির্দেশনা

আপনি আপনার বাগানে কত পাখি আসে তার দৈনিক গণনা রাখছেন। তথ্যটি ইন্টিজারের একটি অ্যারে হিসেবে সংরক্ষিত থাকে, যেখানে **আজকের গণনা প্রথমে** থাকে।

## 1. আজকের গণনা

`today` ডিফাইন করুন যাতে এটি স্ট্যাক থেকে দৈনিক গণনার একটি অ্যারে নেয় এবং আজকের গণনা রিটার্ন করে, অথবা অ্যারেটি খালি হলে `f` রিটার্ন করে।

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. আজকের গণনা এক বাড়ান

`increment-day-count` ডিফাইন করুন যাতে এটি একটি নতুন অ্যারে রিটার্ন করে, যেখানে আজকের গণনা এক বাড়ানো হয়েছে। ইনপুট খালি হলে `{ 1 }` রিটার্ন করুন।

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. কোনো দিনে কি একটিও পাখি ছিল না?

`has-day-without-birds?` ডিফাইন করুন যাতে এটি `t` রিটার্ন করে, যদি অন্তত একটি দিনে শূন্য পাখি রেকর্ড করা থাকে, অন্যথায় `f`।

**রিকার্সন ব্যবহার করুন**, `any?` বা অন্য হায়ার-অর্ডার সিকোয়েন্স শব্দের বদলে।

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. শুরু থেকে মোট পাখি

`total` ডিফাইন করুন যাতে এটি প্রতিটি গণনার যোগফল রিটার্ন করে।

**রিকার্সন ব্যবহার করুন**, `sum`-এর বদলে।

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. ব্যস্ত দিনগুলো

ব্যস্ত দিন হলো সেদিন, যেদিন পাঁচটি বা তার বেশি পাখি থাকে। `busy-days` ডিফাইন করুন যাতে এটি ব্যস্ত দিনের সংখ্যা রিটার্ন করে।

**রিকার্সন ব্যবহার করুন**, `count`-এর বদলে।

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
