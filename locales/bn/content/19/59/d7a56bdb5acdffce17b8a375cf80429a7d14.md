# ভূমিকা

`const` মডিফায়ারটি এমন যেকোনো ফিল্ডে প্রয়োগ করা যেতে পারে (এবং সাধারণত করা উচিত) যার মান কম্পাইল টাইমে জানা থাকে এবং প্রোগ্রামের লাইফটাইমে পরিবর্তিত হয় না।

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly` মডিফায়ারটি এমন যেকোনো ফিল্ডে প্রয়োগ করা যেতে পারে (এবং সাধারণত করা উচিত) যেটিকে `const` করা যায় না, যার মান প্রোগ্রামের লাইফটাইমে পরিবর্তিত হয় না এবং যা হয় কোনো ইনলাইন ইনিশিয়ালাইজার দিয়ে, নয়তো ইনস্ট্যানশিয়েশনের সময় (কনস্ট্রাক্টরের মাধ্যমে বা কনস্ট্রাক্টর কর্তৃক কল করা কোনো মেথডের মাধ্যমে) সেট করা হয়।

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
