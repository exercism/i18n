# ভূমিকা

রিকার্সিভ ফাংশন হলো এমন ফাংশন, যেগুলো নিজেদেরকে কল করে।

একটি রিকার্সিভ ফাংশনে অন্তত একটি _বেস কেস_ এবং অন্তত একটি _রিকার্সিভ কেস_ থাকতে হয়।

_বেস কেস_ ফাংশনটিকে আবার কল না করে একটি মান রিটার্ন করে। _রিকার্সিভ কেস_ ফাংশনটিকে আবার কল করে, ইনপুট এমনভাবে পরিবর্তন করে যাতে কোনো এক সময়ে বেস কেসের সাথে মিলে যায়।

অনেক সময়ই প্রতিটি কেস নিজস্ব ফাংশন ক্লজে লেখা হয়।

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
