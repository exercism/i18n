# ভূমিকা

## অ্যারে

Elm-এ একটি [`Array`][array] হলো একই টাইপের শূন্য বা ততোধিক মানের একটি দ্রুত, ইমিউটেবল কালেকশন।

`List` হলো একটি [ডিফল্ট ইমপোর্ট][default-imports], কিন্তু এর বিপরীতে `Array` মডিউলটি `import Array` বা অনুরূপ কিছু দিয়ে স্পষ্টভাবে ইমপোর্ট করতে হয়।

অ্যারে নিচের মতো করে ডিফাইন করা যায়:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

`Array.push` দিয়ে অ্যারেতে এলিমেন্ট যোগ করা হয়:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

`Array.get` দিয়ে অ্যারের একটি এলিমেন্ট বের করা হয়:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

`Array.set` দিয়ে অ্যারের একটি এলিমেন্ট সেট করা হয়:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

[`Array` মডিউলে][array-module] ডিফাইন করা ফাংশন দিয়ে অ্যারে নিয়ে কাজ করা হয়।

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```
