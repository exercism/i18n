# পরিচিতি

## বিট অ্যারে

বাইনারি ডেটা নিয়ে কাজ করা জটিল হতে পারে, তাই Gleam একটি `BitArray` টাইপ এবং তার সঙ্গে থাকা সিনট্যাক্স দেয়, যা দিয়ে বাইনারি ডেটা তৈরি করা যায় ও প্যাটার্ন ম্যাচ করা যায়।

বিট অ্যারে লিটারেল `<<>>` সিনট্যাক্স দিয়ে লেখা হয়। একটি বিট অ্যারে লিটারেল লেখার সময় সেটি সেগমেন্টে সেগমেন্টে লেখা হয়। প্রতিটি সেগমেন্টে একটি মান ও একটি অ্যানোটেশন থাকে, যাদের `:` দিয়ে আলাদা করা হয়। অ্যানোটেশনটি ঠিক করে দেয় মানটি এনকোড করতে কতগুলি বিট ব্যবহার হবে। এটি সম্পূর্ণ বাদও দেওয়া যায়, তখন ডিফল্ট হিসেবে ৮-বিটের একটি ইন্টিজার মান ধরা হয়।

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

`:1` দিয়ে টাইপ নির্দিষ্ট করা আসলে `:size(1)` লেখার সংক্ষিপ্ত রূপ। বিট সাইজ যদি কোনো ভ্যারিয়েবল থেকে আসে, তাহলে দীর্ঘ সিনট্যাক্সটিই ব্যবহার করতে হবে।

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### বাইনারি

বাইনারি ইন্টিজার লিটারেল লেখার সময় লিটারেলের আগে `0b` বসিয়ে সরাসরি ২-ভিত্তিক নোটেশনে লেখা যায়। মনে রাখবেন, টেস্টে বা আপনার প্রোগ্রামে প্রিন্ট হলে এগুলি দশমিক সংখ্যা হিসেবে দেখানো হবে।

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### ছেঁটে ফেলা

সেগমেন্টের মান যদি সেগমেন্টের টাইপের ধারণক্ষমতা ছাড়িয়ে যায়, তাহলে বাম দিক থেকে তা ছেঁটে ফেলা হবে।

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### সামনে ও পিছনে যোগ করা

বিট অ্যারে সিনট্যাক্স ব্যবহার করে একটি বিদ্যমান বিট অ্যারের সামনে বা পিছনে দুটোই যোগ করা যায়। বিদ্যমান বিট অ্যারের জন্য অবশ্যই `:bits` অ্যানোটেশন ব্যবহার করতে হবে।

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### কনক্যাটিনেশন

ভ্যারিয়েবলে রাখা বিট অ্যারে বিট অ্যারে সিনট্যাক্স দিয়ে কনক্যাটিনেট করা যায়। ভিন্ন ভিন্ন সাইজের দুটি বিট অ্যারে কনক্যাটিনেট করার সময় অবশ্যই `:bits` অ্যানোটেশন ব্যবহার করতে হবে।

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### প্যাটার্ন ম্যাচিং

বিট অ্যারে থেকে মান বের করতেও প্যাটার্ন ম্যাচ করা যায়। যে সেগমেন্ট ধরতে চাইবেন, তার জন্য কতগুলি বিট লাগবে সেটি জানা থাকতে হবে। তবে একটি ব্যতিক্রম আছে: অজানা সাইজের বিট অ্যারে প্যাটার্ন ম্যাচ করতে `:bits` অ্যানোটেশন ব্যবহার করা যায়, কিন্তু এটি কেবল শেষ সেগমেন্টের জন্যই ব্যবহার করা যাবে।

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### বিট অ্যারে পরীক্ষা করা

~~~~exercism/note
বিট অ্যারে যে ফরম্যাটে তৈরি করা হয়েছিল, তার থেকে ভিন্ন ফরম্যাটে সেটি প্রিন্ট হতে পারে। বিট অ্যারে শেখার সময় এতে প্রায়ই বিভ্রান্তি হয়।
~~~~

ডিফল্টভাবে বিট অ্যারে ৮ বিটের সেগমেন্টে (এক বাইট) দেখানো হয়, এমনকি আপনি যদি ভিন্ন সাইজের সেগমেন্টে সেটি তৈরি করে থাকেনও।

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

আপনি যদি এমন একটি বিট অ্যারে তৈরি করেন যা একটি প্রিন্টযোগ্য UTF-8 এনকোডেড স্ট্রিং বোঝায়, তাহলে `io.debug`-এর মতো ফাংশন সেটিকে স্ট্রিং হিসেবে দেখাতে পারে। Gleam ভেতরে ভেতরে স্ট্রিং কীভাবে রাখে, তার একটি ইমপ্লিমেন্টেশন ডিটেইলের কারণেই এটি হয়।

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
