# পরিচিতি

ইনহেরিটেন্স হলো ক্লাসগুলোর মধ্যে প্যারেন্ট-চাইল্ড সম্পর্ক তৈরির একটি উপায়।
চাইল্ড ক্লাসের (যাকে অনেক সময় _সাবক্লাস_ বলা হয়) কাছে প্যারেন্ট ক্লাস (যাকে অনেক সময় _সুপারক্লাস_ বলা হয়) দ্বারা নির্ধারিত আচরণ ও ডেটায় অ্যাক্সেস থাকে।

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

চাইল্ড ক্লাসের ঘোষণায় `extends` কিওয়ার্ডটি [প্রোটোটাইপ চেইন][prototype-chain]-এর মাধ্যমে প্যারেন্ট ক্লাসের সাথে একটি সম্পর্ক স্থাপন করে।

চাইল্ডের কনস্ট্রাক্টর দিয়ে তৈরি অবজেক্টগুলোর প্রোটোটাইপ চেইনে প্যারেন্ট ক্লাসের প্রোটোটাইপ থাকবে, যা প্যারেন্ট দ্বারা নির্ধারিত যেকোনো মেথড বা ডেটায় অ্যাক্সেস দেবে।

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
