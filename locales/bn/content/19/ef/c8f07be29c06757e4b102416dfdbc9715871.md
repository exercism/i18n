# নির্দেশনা

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট হলো: `"[<LEVEL>]: <MESSAGE>"`।

তিনটি আলাদা লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার তিনটি কাজ আছে, প্রতিটিতে একটি লগ লাইন নিয়ে সেটি দিয়ে কিছু একটা করতে হবে। এই কাজগুলো সমাধান করার অনেক উপায় আছে, উপরের উদাহরণগুলো থেকে আপনার পছন্দের পদ্ধতি বেছে নিন এবং দেখুন আপনি কী বের করতে পারেন।

## 1. একটি লগ লাইন থেকে মেসেজ বের করা

লগ লাইনের মেসেজ রিটার্ন করার জন্য `LogLineParser#message` মেথডটি ইমপ্লিমেন্ট করুন:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

শুরুতে বা শেষে থাকা যেকোনো হোয়াইটস্পেস সরিয়ে ফেলা উচিত:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. একটি লগ লাইন থেকে লগ লেভেল বের করা

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য `LogLineParser#log_level` মেথডটি ইমপ্লিমেন্ট করুন, যেটি ছোট হাতের অক্ষরে রিটার্ন করা উচিত:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. একটি লগ লাইন রিফরম্যাট করা

`LogLineParser#reformat` মেথডটি ইমপ্লিমেন্ট করুন, যা লগ লাইনটি রিফরম্যাট করে, মেসেজটি আগে বসায় এবং তার পরে বন্ধনীর ভেতরে লগ লেভেল বসায়:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
