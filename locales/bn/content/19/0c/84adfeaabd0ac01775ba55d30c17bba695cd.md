# নির্দেশাবলীর সংযোজন

## রেজিস্টারসমূহ

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | প্রথম অ্যারের এলিমেন্টসমূহ                                         |
| `$a1`    | ইনপুট     | ইন্টিজার | প্রথম অ্যারের সাইজ, ওয়ার্ডে                                |
| `$a2`    | ইনপুট     | অ্যাড্রেস | দ্বিতীয় অ্যারের এলিমেন্টসমূহ                                         |
| `$a3`    | ইনপুট     | ইন্টিজার | দ্বিতীয় অ্যারের সাইজ, ওয়ার্ডে                                |
| `$v0`    | আউটপুট    | ইন্টিজার | `0` = সমান, `1` = অসমান, `2` = সাবলিস্ট, `3` = সুপারলিস্ট |
| `$t0-9`  | টেম্পোরারি | যেকোনো     | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত                                 |
