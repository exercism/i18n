# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | --------- | ------- | ------------------------------- |
| `$a0` | ইনপুট | অ্যাড্রেস | প্রথম স্ট্রিং, null-terminated |
| `$a1` | ইনপুট | অ্যাড্রেস | দ্বিতীয় স্ট্রিং, null-terminated |
| `$v0` | আউটপুট | ইন্টিজার | হ্যামিং দূরত্ব |
| `$t0-9` | টেম্পোরারি | যেকোনো | সাময়িক স্টোরেজের জন্য |
