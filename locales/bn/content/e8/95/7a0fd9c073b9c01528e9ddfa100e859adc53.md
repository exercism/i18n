# ভূমিকা

## Agent

`Agent` মডিউলটি [প্রসেস এবং _রিসিভ-সেন্ড_ লুপ][exercism-processes] স্পন করার জন্য একটি অ্যাবস্ট্রাকশন সরবরাহ করে। এখান থেকে, `Agent` মডিউল ব্যবহার করে শুরু করা প্রসেসগুলোকে আমরা _'এজেন্ট প্রসেস'_ বলব। কেন্দ্রীয় শেয়ার্ড স্টেট উপস্থাপনের জন্য একটি _এজেন্ট প্রসেস_ বেছে নেওয়া হতে পারে।

একটি _এজেন্ট প্রসেস_ শুরু করার জন্য `Agent` `start/2` ফাংশনটি দেয়। _এজেন্ট প্রসেস_ `start` করার সময় সরবরাহ করা ফাংশনটি প্রসেসটির প্রাথমিক স্টেট রিটার্ন করে:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map` বা `List`-এর মতোই, `Agent` _এজেন্ট প্রসেস_ নিয়ে কাজ করার জন্য অনেক ফাংশন দেয়।

মডেল করা ডোমেইনের জন্য `Agent`-সংক্রান্ত সব কার্যকারিতা একটি মডিউলে সাজিয়ে এনক্যাপসুলেট করা প্রথাগত।
