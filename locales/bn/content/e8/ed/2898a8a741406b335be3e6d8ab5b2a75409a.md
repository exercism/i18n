# পরিচিতি

Factor-এর কন্ডিশনাল **কোয়োটেশন**-এর মধ্যে বেছে নেয়, অর্থাৎ তৃতীয় বন্ধনী `[ ... ]` দিয়ে লেখা কোডের টুকরোগুলোর মধ্যে। `[ ... ]` লিখলে কোডটি রান হয় না, বরং একটি মান হিসেবে স্ট্যাকে পুশ হয়; এরপর কন্ডিশনাল ঠিক করে কোন কোয়োটেশনটি রান করবে। (কোয়োটেশন নিয়ে বিস্তারিত আলোচনা আছে পরের একটি অনুশীলনীতে।)

`if` ([`kernel`][kernel]-এ) হলো Factor-এর মৌলিক কন্ডিশনাল। এটি একটি বুলিয়ান আর দুটি কোয়োটেশন নেয়; বুলিয়ানটি ট্রুথি হলে প্রথমটি রান করে, নাহলে দ্বিতীয়টি।

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` তার কোয়োটেশনটি রান করে কেবল তখনই, যখন বুলিয়ানটি ট্রুথি; আর `unless` কেবল তখন, যখন ফলসি। একাধিক শাখায় ভাগ করার জন্য রয়েছে `cond` ([`combinators`][combinators]-এ):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
