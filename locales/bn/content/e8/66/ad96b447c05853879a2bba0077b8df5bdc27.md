# পরিচিতি

## Try/Rescue/Else/After

এরর ঘটার সময় সেগুলো ধরার জন্য `try..rescue` ব্যবহার করা একটি শক্তিশালী কৌশল। এরর রেসকিউ করা প্রয়োজন হলে ফাংশনকে নির্দিষ্ট মান রিটার্ন করার সুযোগ দেয়। এছাড়াও `try..rescue` কাঠামোটি আমাদের কাজে লাগানোর মতো আরও দুটি সুবিধা দেয়:

- `else` ব্লক
  - try ব্লকটি সফল হলে তার ফলাফল এই ব্লকের সাথে মেলানো হয়।
- `after` ব্লক
  - try ব্লক সফল হোক বা এরর উত্থাপন করুক, প্রোগ্রামটি সেই মুহূর্তে চলমান থাকলে `after` ব্লকের কোড সর্বদা চালানো হয়।
  - `after` ব্লকের ফলাফল কলিং স্কোপে রিটার্ন করা হয় না।

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## ডাইনামিক ডিসপ্যাচ

Elixir কোন ফাংশনটি আহ্বান করতে হবে তা নির্ধারণ করার সময় খোঁজার কাজে মডিউলের নামটি ব্যবহার করে। মডিউলের নামটি কোনো ভ্যারিয়েবলের সাথে বাঁধা থাকলে সেই খোঁজ ডাইনামিকভাবে করা যায়।

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

ভেতরে ভেতরে মডিউলের নামটি আসলে একটি অ্যাটম। Elixir-এর সব মডিউল অ্যাটমের সামনে স্বয়ংক্রিয়ভাবে `Elixir.` যোগ করা হয়।

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
