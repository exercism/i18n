# নির্দেশনা

এই অনুশীলনীতে প্রোগ্রামিং ভাষার একটি অ্যারে নিয়ে কাজ করার জন্য আপনাকে কিছু ফাংশন তৈরি করতে হবে।

## 1. একটি খালি প্রোগ্রামিং ভাষার অ্যারে রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`new/0` ফাংশনটি ডিফাইন করুন, যা কোনো আর্গুমেন্ট নেয় না এবং একটি খালি অ্যারে রিটার্ন করে।

```elixir
LanguageList.new()
# => []
```

## 2. অ্যারেতে একটি প্রোগ্রামিং ভাষা যোগ করার জন্য একটি ফাংশন ডিফাইন করুন

`add/2` ফাংশনটি ডিফাইন করুন, যা ২টি আর্গুমেন্ট নেয় (একটি _প্রোগ্রামিং ভাষার অ্যারে_ এবং একটি _প্রোগ্রামিং ভাষার_ স্ট্রিং লিটারাল)। এটি প্রদত্ত অ্যারের শুরুতে নতুন প্রোগ্রামিং ভাষাটি যোগ করে প্রাপ্ত অ্যারেটি রিটার্ন করবে।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. অ্যারে থেকে একটি প্রোগ্রামিং ভাষা সরানোর জন্য একটি ফাংশন ডিফাইন করুন

`remove/1` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _প্রোগ্রামিং ভাষার অ্যারে_)। এটি প্রথম এলিমেন্টটি বাদ দিয়ে অ্যারেটি রিটার্ন করবে। ধরে নিন যে অ্যারেতে সবসময় অন্তত একটি এলিমেন্ট থাকবে।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. অ্যারেতে থাকা প্রথম এলিমেন্টটি রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`first/1` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _প্রোগ্রামিং ভাষার অ্যারে_)। এটি অ্যারেতে থাকা প্রথম প্রোগ্রামিং ভাষাটি রিটার্ন করবে। ধরে নিন যে অ্যারেতে সবসময় অন্তত একটি এলিমেন্ট থাকবে।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. অ্যারেতে কতগুলো প্রোগ্রামিং ভাষা আছে তা রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`count/1` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _প্রোগ্রামিং ভাষার অ্যারে_)। এটি অ্যারেতে থাকা প্রোগ্রামিং ভাষার সংখ্যা রিটার্ন করবে।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. অ্যারেতে একটি ফাংশনাল ভাষা আছে কি না তা নির্ণয় করার জন্য একটি ফাংশন ডিফাইন করুন

`functional_list?/1` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _প্রোগ্রামিং ভাষার অ্যারে_)। এটি একটি বুলিয়ান মান রিটার্ন করবে। অ্যারেতে থাকা প্রোগ্রামিং ভাষাগুলোর মধ্যে _"Elixir"_ থাকলে এটি ট্রু রিটার্ন করবে।

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
