# পরিচিতি

[while লুপ][while-loops] হলো একটি কন্ট্রোল ফ্লো স্টেটমেন্ট, যা দিয়ে নির্দিষ্ট কোনো শর্ত সত্য থাকা পর্যন্ত কোড চালানো যায়।
Swift-এ দুই ধরনের while লুপ আছে: while এবং repeat-while লুপ।
while লুপের শর্তটি লুপ বডি চালানোর আগে মূল্যায়ন করা হয়; শর্তটি ফলস হলে লুপ বডি একেবারেই চালানো হবে না।
Swift-এ while লুপের গঠনটি এমন:

```swift
while <#condition#> {
  <#code#>
}
```

এখানে count ০-এর চেয়ে বড় থাকা পর্যন্ত লুপটি চলবে, আর ফলে ২, ১ এবং "Liftoff!" প্রিন্ট হবে।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[repeat-while লুপ][while-loops] while লুপের মতোই, তবে এতে লুপ বডি চালানোর পরে শর্তটি মূল্যায়ন করা হয়।
এর মানে হলো, শর্ত ফলস হলেও লুপ বডি অন্তত একবার চালানো হবে।
Swift-এ repeat-while লুপের গঠনটি এমন:

```swift
repeat {
  <#code#>
} while <#condition#>
```

এখানে শর্তটি ফলস হওয়ায় লুপটি কেবল একবারই চলবে।
যেহেতু এটি একটি repeat-while লুপ, তাই শর্তটি মূল্যায়নের আগেই লুপ বডি একবার চালানো হবে।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## অপশনাল বাইন্ডিং লুপ

Swift-এ while লুপের একটি কমন ধরন হলো অপশনাল বাইন্ডিং while লুপ।
কোনো ফাংশন কল করলে যে অপশনাল মান পাওয়া যায়, সেটি `nil` নয় এমন একটি মান রিটার্ন করা পর্যন্ত এই লুপগুলো চলতে থাকে।
এরপর সেই (অপশনাল নয় এমন) মানটি আপনার পছন্দের একটি নামে বাইন্ড করা হয় এবং লুপের বডিতে ব্যবহার করা যায়।

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
