# পরিচিতি

কখনও কখনও কিছু স্টেট একাধিক ওয়ার্ডের মধ্যে শেয়ার করা দরকার, প্রতিবার সেটিকে তাদের স্ট্যাক ইফেক্টের মধ্য দিয়ে পার করানো ছাড়াই। Factor-এর *ডায়নামিক ভ্যারিয়েবল*, যা `SYMBOL:` দিয়ে ডিক্লেয়ার করা হয়, প্রতিটি ওয়ার্ডকে একটি নেমস্পেসে রাখা একটি মান ব্যবহারের সুযোগ দেয়।

## `SYMBOL:` এবং `SYMBOLS:`

`SYMBOL: name` একটি ভ্যারিয়েবল ডিক্লেয়ার করে। `SYMBOLS: a b c ;` একসাথে কয়েকটি ডিক্লেয়ার করে:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## সেট করা এবং পাওয়া

`set-global` এবং `get-global` ([`namespaces`][namespaces]-এ) গ্লোবাল নেমস্পেসে কাজ করে:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

মডিউল-লেভেল স্টেটের জন্য `-global` ধরনগুলোই আপনার দরকার।

## `with-variable` দিয়ে স্কোপড বাইন্ডিং

একটি ডায়নামিক ভ্যারিয়েবল আরেকটি, *স্কোপড* ধরনও সমর্থন করে। `set` / `get` / `change` (`-global` প্রত্যয় ছাড়া) *বর্তমান* ডায়নামিক স্কোপ পড়ে ও লেখে, আর `with-variable` ([`namespaces`][namespaces]-এ) একটি কোয়োটেশন চলার সময়টুকুর জন্য নতুন একটি স্কোপ তৈরি করে:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

`quot` চলার সময় ভ্যারিয়েবলটি `value` মানের সাথে বাইন্ড থাকে; এটি রিটার্ন করা মাত্র বাইন্ডিংটি আর থাকে না। এতে বাইরের কোনো কলার একটি মান "ইনজেক্ট" করতে পারে, যা ভেতরের কোড প্রতিটি স্ট্যাক সিগনেচার দিয়ে না পাঠিয়েও পড়তে পারে।

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

এই অনুশীলনীতে সর্বত্র গ্লোবাল ধরনটিই ব্যবহার করা হয়েছে, তবে সমান্তরাল `set`/`get`/`change` পরিবারটি চিনতে পারলে অন্য কারও কোড পড়ার সময় কাজে লাগে।

## মিউটেবল ভেক্টর

যেহেতু ডায়নামিক ভ্যারিয়েবল একটি রেফারেন্স ধরে রাখে, তাই এর ভেতরে একটি *মিউটেবল* কালেকশন রেখে সেটি জায়গায় বসেই আপডেট করতে পারেন:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` একটি লিটারেল ভেক্টর। কোনো `V{ }` লিটারেল সংরক্ষণ করার আগে সবসময় `clone` করুন: লিটারেলগুলো কলের মধ্যে শেয়ার করা থাকে।

## `find`: প্রথম মিল

`find` ([`sequences`][sequences]-এ) প্রথম যে এলিমেন্টের জন্য প্রেডিকেট সত্য হয় সেটি, আর তার সাথে ইনডেক্সটি রিটার্ন করে:

```
find ( seq quot -- index elt/f )
```

কিছুই মিল না হলে দুটি মানই `f`। `nip` দিয়ে ইনডেক্সটি ফেলে দিয়ে `unless*` ব্যবহার করাই হলো "কিছু না পেলে ডিফল্ট" ধরনের স্ট্যান্ডার্ড কম্বিনেশন।

## `reject`: মিলগুলো বাদ দিন

`reject` ([`sequences`][sequences]-এও আছে) হলো `filter`-এর বিপরীত: এটি সেই এলিমেন্টগুলো রিটার্ন করে যেগুলো প্রেডিকেটে *ফেল* করে।
