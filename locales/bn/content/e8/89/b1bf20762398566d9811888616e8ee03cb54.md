# নির্দেশনা

IOU ট্র্যাক করার জন্য একটি RESTful API তৈরি করুন।

চারজন রুমমেটের প্রায়ই একে অন্যের কাছ থেকে টাকা ধার নেওয়ার অভ্যাস, আর কে কার কাছে কত টাকা পাওনা তা মনে রাখতে গিয়ে তারা সমস্যায় পড়ে।

আপনার কাজ হলো একটি সরল [RESTful API][restful-wikipedia] তৈরি করা, যা POST রিকোয়েস্ট হিসেবে [IOU][iou] গ্রহণ করে এবং GET রিকোয়েস্টের মাধ্যমে নির্দিষ্ট সারসংক্ষেপ তথ্য দিতে পারে।

## API স্পেসিফিকেশন

### ব্যবহারকারী অবজেক্ট

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### মেথড

| বর্ণনা              | HTTP মেথড | URL    | পেলোড ফরম্যাট                                                            | পেলোড ছাড়া রেসপন্স                   | পেলোড-সহ রেসপন্স                                                             |
| ------------------------ | ----------- | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| ব্যবহারকারীর তথ্যের তালিকা | GET         | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| ব্যবহারকারী তৈরি করুন              | POST        | /add   | `{"user":<name of new user (unique)>}`                                    | N/A                                    | `<User object for new user>`                                                    |
| IOU তৈরি করুন               | POST        | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | N/A                                    | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
