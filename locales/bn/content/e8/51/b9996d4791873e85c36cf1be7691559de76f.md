# ভাগশেষ

গণিতে, কোনো হিসাব করার পর যা "বাকি পড়ে থাকে", সেটাই **ভাগশেষ**। উদাহরণস্বরূপ, `5 / 3`-এর ভাগশেষ হলো `2`।

অনেক প্রোগ্রামিং ভাষায় ভাগশেষ বের করার জন্য অপারেটর হিসেবে শতাংশ চিহ্ন (`%`) ব্যবহার করা হয়।
উদাহরণস্বরূপ:
```javascript
5 % 3 == 2
```

প্রায়শই ইন্টিজার ও ফ্লোট, দুই ধরনের সংখ্যার ক্ষেত্রেই ভাগশেষ হিসাব করা যায়।
উদাহরণস্বরূপ,
```javascript
5.3 % 3 == 2.3
```

ঋণাত্মক সংখ্যা নিয়ে কাজ করার সময় ফলাফলের চিহ্ন সবসময় ভাজ্যের (বাঁ দিকে থাকা যে সংখ্যাটিকে ভাগ করা হয়) চিহ্নের মতোই হয়।
উদাহরণস্বরূপ:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

কিছু ভাষা (যেমন Python) ভাগশেষ নয়, বরং মডুলাস হিসাব করার জন্য `%` অপারেটর ব্যবহার করে।
এতে ঋণাত্মক সংখ্যার আচরণ আলাদা হয়।
এই বিষয়ে আপনি [উইকিপিডিয়ায়](https://en.wikipedia.org/wiki/Modulo) আরও জানতে পারেন।
