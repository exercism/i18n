# ভূমিকা

## কন্ডিশনাল: If

### লজিক্যাল অপারেটর

Java তিনটি লজিক্যাল অপারেটর সমর্থন করে: `&&` (AND), `||` (OR) এবং `!` (NOT)।

### If স্টেটমেন্ট

যেকোনো কন্ডিশনাল অপারেশনের অন্তর্নিহিত টাইপ হলো `boolean` টাইপ, যার মান `true` বা `false` হতে পারে। বিভিন্ন শর্ত যাচাই করতে কন্ডিশনালগুলো প্রায়ই ফ্লো কন্ট্রোল ব্যবস্থা হিসেবে ব্যবহৃত হয়। কোনো নির্দিষ্ট কেস যাচাই করতে একটি `if` স্টেটমেন্ট ব্যবহার করা যায়, যা অন্তর্নিহিত শর্ত `true` হলে তার কোড চালায়, এভাবে:

```java
int val;

if(val == 9) {
    // conditional code
}
```

একাধিক কেস জড়িত পরিস্থিতিতে `else if` এবং `else` স্টেটমেন্ট ব্যবহার করে অনেকগুলো `if` স্টেটমেন্ট একসাথে চেইন করা যায়।

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### Switch স্টেটমেন্ট

একাধিক অপশনযুক্ত পরিস্থিতির জন্য Java একটি `switch` স্টেটমেন্টও দেয়।

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
