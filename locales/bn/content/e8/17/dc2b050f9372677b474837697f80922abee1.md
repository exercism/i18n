# নির্দেশনার সংযোজন

## বাস্তবায়ন

যদি তালিকার শেষ এলিমেন্টটি `string`-এর বদলে `object` হয়, তাহলে সেটি একটি কোয়ালিফায়ার ধারণ করে, যা প্রবাদের শেষ লাইনটি পরিবর্তন করে।

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
