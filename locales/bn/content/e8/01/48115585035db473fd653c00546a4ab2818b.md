# সম্পর্কে

Rust-এ বুলিয়ানকে `bool` টাইপ দিয়ে প্রকাশ করা হয়, আর এর মান `true` বা `false` হতে পারে।

Rust একটি [বুলিয়ান নেগেশন অপারেটর][negation operators] সমর্থন করে: `!` (নট)।

Rust ছয়টি [তুলনা অপারেটর][comparison operators] সমর্থন করে: `==` (সমান), `!=` (সমান নয়), `>` (বড়), `<` (ছোট), `>=` (বড় বা সমান), `<=` (ছোট বা সমান)। এগুলো দিয়ে অ-বুলিয়ান মানগুলোর মধ্যে সম্পর্ক যাচাই করে একটি বুলিয়ান মান পাওয়া যায়।

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

কিছু অন্য ভাষার বিপরীতে, Rust-এ `0`-কে `false` ধরা হয় না, আর শূন্য ছাড়া অন্য কোনো মানকে `true` ধরা হয় না।

Rust তিনটি [লজিক্যাল বাইনারি অপারেটর][logical binary operators] সমর্থন করে: `&` (লজিক্যাল অ্যান্ড), `|` (লজিক্যাল অর), `^` (লজিক্যাল এক্সঅর)।

Rust দুটি [বুলিয়ান অপারেটর][lazy boolean operators] সমর্থন করে: `||` (অর), `&&` (অ্যান্ড)। এগুলো `|` আর `&` থেকে আলাদা, কারণ ডান দিকের অপারেন্ড কেবল তখনই মূল্যায়ন করা হয়, যখন বাম দিকের অপারেন্ড এক্সপ্রেশনের ফলাফল আগেই নির্ধারণ করে না। অর্থাৎ, `||` তার ডান দিকের অপারেন্ড মূল্যায়ন করে কেবল তখনই, যখন বাম দিকের অপারেন্ডের মান `false` হয়; আর `&&` তা করে তখনই, যখন সেটির মান `true` হয়।

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
