# ভূমিকা

Cairo-এর স্ট্রিংয়ের জন্য কোনো নেটিভ টাইপ নেই, তবে স্ট্রিং সামলানোর দুটি উপায় আছে: সরল কোট ব্যবহার করে শর্ট স্ট্রিং, আর ডাবল কোট ব্যবহার করে `ByteArray`।

একটি শর্ট স্ট্রিং হলো একটি ASCII স্ট্রিং, যেখানে প্রতিটি ক্যারেক্টার এক বাইটে এনকোড করা হয়।

শর্ট স্ট্রিংয়ের জন্য Cairo ডিফল্টভাবে যে টাইপ ব্যবহার করে তা হলো `felt252`, যার কারণে এদের সর্বোচ্চ দৈর্ঘ্য মাত্র ৩১টি ক্যারেক্টার।

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

টেকনিক্যালি, `felt252`-এর চেয়ে ছোট যেকোনো ইন্টিজার টাইপ শর্ট স্ট্রিং ফরম্যাটে রিপ্রেজেন্ট করা যায়।

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

৩১ ক্যারেক্টারের চেয়ে লম্বা স্ট্রিংয়ের জন্য Cairo `ByteArray` দেয়, যার দৈর্ঘ্যের কোনো সীমা নেই।

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

`+` অপারেটরের মাধ্যমে ByteArray-গুলো কনক্যাটেনেট করা যায়:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

কিছু বিশেষ ক্যারেক্টারকে সামনে ব্যাকস্ল্যাশ দিয়ে এস্কেপ করতে হয়, যেমন স্ট্রিংয়ে ট্যাবের জন্য `\t` আর নতুন লাইনের জন্য `\n`।

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

আপনি এমনকি ইনডেক্স ব্যবহার করে একটি ByteArray-এর ভেতরের প্রতিটি আলাদা বাইট অ্যাক্সেসও করতে পারেন।

তবে সাবধান, রিটার্ন হওয়া বাইটের টাইপ `u8`, `ByteArray` নয়!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

কোর লাইব্রেরি ByteArray নিয়ে কাজ করার জন্য অনেক কাজের মেথড ও অপারেটর দেয়।

ByteArray-এর মেথড সম্পর্কে আরও জানতে, [ByteArrayTrait ডকুমেন্টেশন][docs] দেখে নিন।

এখানে কিছু উদাহরণ আছে:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
