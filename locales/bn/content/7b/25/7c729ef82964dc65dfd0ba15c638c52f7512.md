# ভূমিকা

কাস্টম টাইপ হলো Gleam-এ নতুন ডেটা টাইপ ডিফাইন করার উপায়। এগুলোর একাধিক _ভ্যারিয়েন্ট_ থাকতে পারে, প্রতিটির নিজের নাম থাকে।

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

কাস্টম টাইপের প্রতিটি কেস ঐচ্ছিকভাবে কিছু ডেটা ধারণ করতে পারে, আর ভিন্ন ভিন্ন কেসে ভিন্ন ভিন্ন ধরনের ডেটা থাকতে পারে। কোনো ভ্যারিয়েন্ট ডেটা ধারণ করলে তাকে _রেকর্ড_ বলা হয়।

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

কোনো নির্দিষ্ট কেসের মান তৈরি করা যায় দুভাবে: কেসটিতে অতিরিক্ত ডেটা না থাকলে তার নাম উল্লেখ করে (`Spring`), আর ডেটা থাকলে সেটিকে ফাংশন হিসেবে কল করে (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Gleam-এর সবকিছুর মতো কাস্টম টাইপেও _স্ট্রাকচারাল ইকুয়ালিটি_ আছে, অর্থাৎ একই ভ্যারিয়েন্টের এবং একই ডেটাযুক্ত দুটি মান পরস্পর সমতুল্য।

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

কেস এক্সপ্রেশন ব্যবহার করে কাস্টম টাইপের ভ্যারিয়েন্টগুলোর উপর প্যাটার্ন ম্যাচ করা যায়।

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
