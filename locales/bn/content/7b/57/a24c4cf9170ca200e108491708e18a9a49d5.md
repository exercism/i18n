# নির্দেশনা

মহারানি [কালমার ইউনিয়নের][kalmar_union] রাজধানী কোপেনহেগেনে একটি ডিনার পার্টির আয়োজন করছেন।
এটি বছরের সবচেয়ে বড় পার্টি এবং সব অভিজাত ব্যক্তিকে আমন্ত্রণ জানানো হয়েছে।
কিন্তু দেশজুড়ে গুজব ছড়াচ্ছে যে মহারানিকে বিষ খাওয়ানোর একটি ষড়যন্ত্র চলছে।

মহারানি আপনাকে, রাজদরবারের বিষ-অনুসন্ধানকারী হিসেবে, খুঁজে বের করতে বলেছেন খাবার বা পানীয়ের মধ্যে কোনোটিতে বিষ আছে কি না।
মহারানি খাবার হিসেবে শুধু **Mushroom pasties** পরিবেশনের পরিকল্পনা করেছেন, তবে পানীয়ের ক্ষেত্রে নানা ধরনের পানীয় থাকবে।

## 1. খাবার সঠিক কি না তা যাচাই করুন

মহারানি যা অর্ডার করেছেন তা যদি খাবার না হয়, তাহলে খাবারে বিষ থাকার সম্ভাবনা অনেক বেশি।
খাবার যদি মহারানির অর্ডার করা জিনিস না হয়, তাহলে তা ফেলে দেওয়া উচিত।

`check_food?` মেথডটি ইমপ্লিমেন্ট করুন, যা `food` আর্গুমেন্ট নেয়, যেখানে খাবারের নাম একটি `String` হিসেবে থাকে।
খাবারটি `Mushroom pasties` হলে মেথডটি সেই খাবার রিটার্ন করবে; অন্যথায় এটি `nil` রিটার্ন করবে।

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. পানীয়তে বিষ আছে কি না তা যাচাই করুন

পানীয়ে বিষ থাকাও সম্ভব, তবে তা আছে কি না বোঝা একটু কঠিন।
পানীয়ের নামে `i` অক্ষরটি **না** থাকলে সেই পানীয়ে বিষ আছে বলে ধরে নিতে হবে; অক্ষর ছোট হাতের না বড় হাতের, সেটা কোনো ব্যাপার নয়।
পানীয়ে বিষ থাকলে তা ফেলে দেওয়া উচিত।

`check_drink?` মেথডটি ইমপ্লিমেন্ট করুন, যা `drink` আর্গুমেন্ট নেয়, যেখানে পানীয়ের নাম একটি `String` হিসেবে থাকে।
পানীয়ে বিষ না থাকলে মেথডটি সেই পানীয় রিটার্ন করবে, অন্যথায় এটি `nil` রিটার্ন করবে।

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. পানীয় বদলে দিন

মহারানি চাইবেন না তাঁর অতিথিরা খাবারে বিষ নিয়ে চিন্তিত হোক।
তাই পানীয়ে বিষ থাকলে তার বদলে নতুন একটি পানীয় দেওয়া উচিত, আর সেটি হবে **Apple juice**।

`replace_drink` মেথডটি ইমপ্লিমেন্ট করুন, যা `drink` আর্গুমেন্ট নেয়, যেখানে পানীয়ের নাম একটি `String` হিসেবে থাকে।
পানীয়ে বিষ না থাকলে মেথডটি সেই পানীয় রিটার্ন করবে, অন্যথায় এটি `"Apple juice"` রিটার্ন করবে।

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
