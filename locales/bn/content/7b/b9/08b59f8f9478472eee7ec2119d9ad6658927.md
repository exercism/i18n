Elixir-এর নামকরণের কিছু নির্দিষ্ট নিয়ম আছে, যার মধ্যে রয়েছে [বুলিয়ান রিটার্ন করে এমন ফাংশনের](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) নাম কীভাবে দিতে হবে:

> যে ফাংশনগুলো বুলিয়ান রিটার্ন করে, তাদের নামের শেষে একটি প্রশ্নবোধক চিহ্ন বসানো হয়।

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

মনে রাখবেন, গার্ড, আর কিছু বিল্ট-ইন ফাংশন ও ম্যাক্রো যেগুলো বুলিয়ান রিটার্ন করে এবং গার্ডে ব্যবহার করা যায়, সেগুলো অন্য একটি নিয়ম মেনে চলে এবং নামের শুরুতে `is_` প্রিফিক্স দিয়ে নাম দেওয়া হয় (`def is_integer`, `defguard is_foo`, `defmacro is_foo`)। এই দুটি নিয়ম কখনো একসাথে মেশানো যাবে না।
