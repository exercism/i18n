# পরিচিতি

[Repeat-while লুপগুলো][repeat-loops] `while` লুপের মতোই, তবে একটি বড় পার্থক্য আছে: লুপের বডি চালু হওয়ার *পরে* শর্ত পরীক্ষা করা হয়, আগে নয়।
এর ফলে, একটি `repeat-while` লুপ তার কোড ব্লক অন্তত একবার চালাবে, এটি নিশ্চিত।

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
