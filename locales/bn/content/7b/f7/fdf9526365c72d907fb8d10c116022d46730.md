# নির্দেশনার সংযোজন

## ইঙ্গিত

আপনাকে `recite` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যা 'The Twelve Days of Christmas' গানের কথা আউটপুট দেয়। টাইপগুলো নিয়ে নিশ্চিত না থাকলে প্রদত্ত সিগনেচারটি ব্যবহার করতে পারেন, তবে সেটি যেন আপনার সৃজনশীলতাকে সীমিত না করে।

এই অনুশীলনীতে টেক্সট ডেটা নিয়ে কাজ করা হয়। ঐতিহাসিক কারণে Haskell-এর `String` টাইপটি `[Char]`-এর সমার্থক, অর্থাৎ ক্যারেক্টারের একটি অ্যারে। টেক্সট ডেটা আরও দক্ষভাবে সামলানোর জন্য `Text` টাইপটি ব্যবহার করা যায়।

এই অনুশীলনীর একটি ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি করতে পারেন:

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়তে।
- package.yaml-এ আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করতে।
- [নিচের পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) `Data.Text` ইমপোর্ট করতে:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- যেমন `recite :: Int -> Int -> [Text]` লিখতে এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.pack` হিসেবে ব্যবহার করতে।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন খুঁজে দেখতে।
- TwelveDays.hs-এ `String`-এর সব ব্যবহারের জায়গায় `Text` বসাতে, অর্থাৎ:

```haskell
recite :: Int -> Int -> [Text]
```

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
