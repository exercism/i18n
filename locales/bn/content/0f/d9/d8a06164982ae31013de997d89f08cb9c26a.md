# ইঙ্গিত

## সাধারণ

- [তুলনা অপারেটর][comparison-operators] সম্পর্কে ডকুমেন্টেশন পড়ুন
- [অ্যারে সাজানো][list-sort] সম্পর্কে ডকুমেন্টেশন পড়ুন
- আপনি কীভাবে [রেকর্ড অ্যাক্সেস বা প্যাটার্ন ম্যাচ][records] করতে পারেন, তা মনে রাখুন

## 1. পাওয়ার লেভেল তুলনা করুন

- [`(>)` অপারেটরটি][greater] ব্যবহার করুন

## 2. সর্বোচ্চ পাওয়ার খুঁজুন

- [`max` ফাংশনটি][max] ব্যবহার করুন

## 3. কার্ডগুলো সাজান

- [`List.sortBy` ফাংশনটি][sort-by] ব্যবহার করুন

## 4. সবচেয়ে কুল কার্ডগুলো আগে

- [`List.sortBy`][sort-by] বা [`List.sortWith`][sort-with] ফাংশন ব্যবহার করুন
- স্তরভিত্তিক সাজানোর জন্য টুপল ব্যবহার করতে পারেন

## 5. শাইনি পাওয়ার

- আপনি একটি ক্রম স্পষ্টভাবে ডিফাইন করতে পারেন, অথবা নির্দিষ্ট কোনো মানের সাথে [`compare` ফাংশনটি][compare] ব্যবহার করতে পারেন
- স্তরভিত্তিক সাজানোর জন্য টুপল ব্যবহার করতে পারেন

## 6. বাজি ধরুন

- `expectedWinner`-এ `compareShinyPower` ব্যবহার করুন
- ক্রমটি [প্যাটার্ন ম্যাচ][pattern-match] করতে একটি `case` ব্যবহার করুন
