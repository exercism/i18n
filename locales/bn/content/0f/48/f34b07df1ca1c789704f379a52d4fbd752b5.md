# ইনস্টলেশন

## আমার কাছে কোন awk আছে?

Exercism-এর AWK ট্র্যাকটি `gawk` ব্যবহার করে, যা GNU-র AWK।
আপনার কাছে এটি হয়তো আগেই আছে; যাচাই করতে এই কমান্ডটি চালান
```sh
awk --version
```

এর ফলাফল যদি হয়:

* `GNU Awk 5.1.0 ...`-এর মতো কিছু
    - আপনার কাছে আগেই GNU awk আছে, তাই আপনি অনুশীলনীগুলো চালিয়ে যেতে পারেন।

* `awk version 20200816`-এর মতো কিছু
    - এটি `nawk`, যা BWK awk (ব্রায়ান কার্নিহানের নাম অনুসারে) বা "one true awk" নামেও পরিচিত।
    - MacOS ও BSD সিস্টেমের সাথে এটিই আসে।
    - ইনস্টলেশনের নির্দেশনার জন্য নিচে পড়ুন।

* `awk: not an option: --version` এররটি
    - সম্ভবত আপনার কাছে `mawk` আছে।
    - নিশ্চিত করুন: `awk -W version`, যা `mawk 1.3.4 20200120` ফেরত দিতে পারে।
    - mawk একটি খুব ভালো ও দ্রুত awk ইমপ্লিমেন্টেশন, তবে এতে gawk-নির্দিষ্ট কিছু ফিচার নেই যা আমরা ট্র্যাকটিতে ব্যবহার করব।
    - ইনস্টলেশনের নির্দেশনার জন্য নিচে পড়ুন।

* `awk: unrecognized option: version` এররটি, যার পরে `BusyBox v1.35.0 ...`
    - আপনি হয়তো Alpine Linux ব্যবহার করছেন।
    - ইনস্টলেশনের নির্দেশনার জন্য নিচে পড়ুন।

* একটি "command not found" এরর
    - তাহলে হয় আপনার PATH-এ গোলমাল আছে, নয়তো আপনার awk ইনস্টল করা নেই।
    - ইনস্টলেশনের নির্দেশনার জন্য নিচে পড়ুন।

### Linux

আপনার ডিস্ট্রো-র প্যাকেজ ম্যানেজার অনুযায়ী এটি ভিন্ন হয়। সাধারণত:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
সঠিক কমান্ডটি চালানোর জন্য আপনার `sudo` ব্যবহার করতে হতে পারে।

### MacOS

[Homebrew][brew] আপনার বন্ধু। ইনস্টল করতে লিঙ্কটি অনুসরণ করুন, তারপর চালান:
```sh
brew install gawk
```

### Windows

[WSL][wsl]-এর জন্য উপরের Linux-এর নির্দেশনা দেখুন।
cygwin-এর জন্য `gawk` প্যাকেজটি ইনস্টল করুন।

### সোর্স থেকে কম্পাইল করা

সাহসীদের জন্য, নির্দেশনা [`gawk` ম্যানুয়ালে][build] পাওয়া যাবে।
