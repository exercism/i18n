# পরিচিতি

ফাংশন হলো সুসংগঠিত, পুনরায় ব্যবহারযোগ্য কোডের একটি ব্লক, যা দিয়ে কোনো কাজ করা হয়। JavaScript-এ ফাংশন ডিফাইন করার একাধিক উপায় আছে। এখানে আমরা _ফাংশন ডিক্লারেশন_ ও _ফাংশন এক্সপ্রেশন_ দেখব। [অ্যারো ফাংশন][concept-arrow-functions]-এর মতো অন্য সম্ভাবনাগুলো নিয়ে আলোচনা হবে অন্য কনসেপ্টে।

## ফাংশন ডিক্লারেশন

JavaScript-এ ফাংশন ডিফাইন করার মানক উপায় হলো _ফাংশন ডিক্লারেশন_, যাকে _ফাংশন ডেফিনিশন_ বা _ফাংশন স্টেটমেন্ট_-ও বলা হয়।

এতে থাকে `function` কিওয়ার্ড, ফাংশনের নাম, এবং প্রথম বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা প্যারামিটারগুলোর একটি তালিকা। এর পরে থাকে দ্বিতীয় বন্ধনীতে মোড়ানো ফাংশন বডি (স্টেটমেন্টের সমষ্টি, যা ঠিক করে ফাংশনটি কী কাজ করে)।

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

JavaScript-এ কোনো ফাংশন ইনভোক (কল) করা হয় এভাবে: আগে ফাংশনের নাম লেখা হয়, তারপর প্রথম বন্ধনীর ভেতরে আর্গুমেন্টগুলো দেওয়া হয়।

```javascript
someName(arg1, arg2, arg3);
```

## প্যারামিটার

ফাংশন বডির ভেতরে প্যারামিটার নিয়ে কাজ করার সময় সম্ভাব্য সাইড ইফেক্ট সম্পর্কে সতর্ক থাকুন।

- [প্রিমিটিভ ডেটা টাইপ][mdn-primitives]-এর মান _অপরিবর্তনীয়_। ফাংশন বডির ভেতরে আর্গুমেন্টের সঙ্গে যা-ই ঘটুক, মূল মান এতে কখনোই বদলায় না।
- অন্য সব মানের (অবজেক্ট, অ্যারে, ফাংশন) ক্ষেত্রে নতুন করে অ্যাসাইন করলে মূল মান বদলায় না। তবে আপনি যদি এমন আর্গুমেন্ট পরিবর্তন করেন (যেমন কোনো অবজেক্টে একটি কী (key) যোগ করেন), তাহলে যে মূল মানটি পাঠানো হয়েছিল সেটিও বদলে যায়।

ডিফল্টভাবে, ফাংশন ডিক্লারেশনে ডিফাইন করা সব প্যারামিটার JavaScript-এ ঐচ্ছিক। প্যারামিটারের চেয়ে কম আর্গুমেন্ট দিলে, বাদ পড়া আর্গুমেন্টগুলো ফাংশনের ভেতরে `undefined` হয়ে থাকবে, দেখুন [Null ও Undefined][concept-null-undefined]। অনেক ক্ষেত্রেই `undefined`-এর বদলে আরও উপযুক্ত কোনো ডিফল্ট মান অ্যাসাইন করা বুদ্ধিমানের কাজ। ফাংশন ডেফিনিশনেই সরাসরি ডিফল্ট প্যারামিটার উল্লেখ করে এটা করা যায়।

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## রিটার্ন স্টেটমেন্ট

`return` স্টেটমেন্ট ফাংশনের কার্যক্রম শেষ করে এবং ফাংশন কলকারীর কাছে যে মান রিটার্ন করা হবে তা নির্দিষ্ট করে। একটি ফাংশনে একাধিক `return` স্টেটমেন্ট থাকতে পারে।

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

ফাংশনের রিটার্ন ভ্যালু একটি ভ্যারিয়েবলে রাখা যায়।

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

যে ফাংশন কোনো মান `return` করে না বা যার `return` স্টেটমেন্ট নেই, তার ফলাফল `undefined`. JavaScript-এ কোনো অন্তর্নিহিত `return` নেই।

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

JavaScript-এ আপনি ঠিক একটি মানই রিটার্ন করতে পারেন। আরও তথ্য পাঠাতে চাইলে প্রথমে সেগুলোকে একটি সত্তায় জোড়া লাগাতে হবে, সাধারণত কোনো [অবজেক্ট][concept-objects] বা [অ্যারে][concept-arrays]-এ।

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## ফাংশন এক্সপ্রেশন

ফাংশন ডিক্লারেশন একটি স্বতন্ত্র স্টেটমেন্ট। তবে কখনো কখনো অন্য একটি এক্সপ্রেশনের অংশ হিসেবে ফাংশন ডিফাইন করা কাজে লাগে, যেমন কোনো অ্যাসাইনমেন্টে, ফাংশন প্যারামিটার হিসেবে ([কলব্যাক][concept-callbacks]) বা কোনো [অবজেক্টে][concept-objects] মান হিসেবে। এটা করা যায় ফাংশন এক্সপ্রেশন দিয়ে। এর সিনট্যাক্স ফাংশন ডিক্লারেশনের মতোই, শুধু ফাংশনের নাম বাদ দিয়ে একটি _অ্যানোনিমাস ফাংশন_ তৈরি করা যায়।

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
