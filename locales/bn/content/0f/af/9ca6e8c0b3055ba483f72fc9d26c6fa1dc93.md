# ইঙ্গিত

## 1. একজন কর্মীর জন্য একটি ব্যাজ প্রিন্ট করুন

- বর্ণনা স্ট্রিং তৈরি করতে [স্ট্রিং ইন্টারপোলেশন][string-interpolation] ব্যবহার করা যায়।
- একটি স্ট্রিংকে বড় হাতের অক্ষরে রূপান্তর করার জন্য [বিল্ট-ইন মেথড][to-upper-case] আছে।

## 2. নতুন একজন কর্মীর জন্য একটি ব্যাজ প্রিন্ট করুন

- ব্যবহার করার আগে ID `null` কি না, তা পরীক্ষা করা উচিত।
- মানটি `null`-এর সাথে তুলনা করতে আপনি [সমতা অপারেটর][equality-operators] ব্যবহার করতে পারেন

## 3. মালিকের জন্য একটি ব্যাজ প্রিন্ট করুন

- ব্যবহার করার আগে ডিপার্টমেন্টটি `null` কি না, তা পরীক্ষা করা উচিত।
- মানটি `null`-এর সাথে তুলনা করতে আপনি [সমতা অপারেটর][equality-operators] ব্যবহার করতে পারেন
