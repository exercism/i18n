# ভূমিকা

শর্তসাপেক্ষে লজিক চালানোর জন্য `if/elif/else` এক্সপ্রেশন ব্যবহার করা যায়। শর্তসাপেক্ষে লজিক চালানোর আরও একটি শক্তিশালী উপায়ও F#-এ আছে: প্যাটার্ন ম্যাচিং। প্যাটার্ন ম্যাচিংয়ে একটি মানকে এক বা একাধিক _প্যাটার্ন_-এর সাথে মিলিয়ে পরীক্ষা করা যায়। এমন একটি প্যাটার্নের উদাহরণ হলো _কনস্ট্যান্ট প্যাটার্ন_, যা একটি মানকে একটি ধ্রুবকের (যেমন `1` বা `"hello"`) সাথে মিলিয়ে দেখে।

F#-এ প্যাটার্ন ম্যাচিং করা হয় `match` কিওয়ার্ডের মাধ্যমে:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

অন্য ভাষার `switch` স্টেটমেন্টের মতো দেখতে হলেও, অন্য প্যাটার্নও সাথে ব্যবহার করলে প্যাটার্ন ম্যাচিংয়ের আসল শক্তি প্রকাশ পায়। এমন একটি প্যাটার্ন হলো _ভ্যারিয়েবল প্যাটার্ন_, যার সাহায্যে একটি মান ধরে রাখা যায়:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

কিছু ক্ষেত্রে আপনি একটি প্যাটার্নে অতিরিক্ত একটি শর্ত যোগ করতে চাইতে পারেন। এটিকে _গার্ড_ (ক্লজ) বলা হয়, যা `when` কিওয়ার্ড দিয়ে যোগ করা যায়:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

উপরের উদাহরণে সম্ভাব্য সব ইনপুটের জন্য মিলে যাওয়া প্যাটার্ন থাকবে না। কম্পাইলার এটি ধরে ফেলে একটি ওয়ার্নিং দেবে। এটিকে _এক্সহসটিভ চেকিং_ বলা হয়। ওয়ার্নিংটি দূর করতে সব ক্ষেত্রই সামলাতে হয়। এর জন্য ব্যবহার করা যায় _ওয়াইল্ডকার্ড প্যাটার্ন_, যা যেকোনো মানের সাথে মেলে:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

প্যাটার্ন ম্যাচিং একটি মানকে উপর থেকে নিচে একে একে প্রতিটি প্যাটার্নের সাথে মিলিয়ে দেখে, যতক্ষণ না মিলে যাওয়া প্যাটার্নটি পাওয়া যায় এবং তার সাথে যুক্ত লজিক চালানো হয়। প্যাটার্নের ক্রম গুরুত্বপূর্ণ!
