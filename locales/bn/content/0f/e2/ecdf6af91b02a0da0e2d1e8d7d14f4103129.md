# ভূমিকা

মনে করুন, একটি `jq` প্রোগ্রাম হলো _এক্সপ্রেশনগুলোর একটি পাইপলাইন_।
**ভ্যারিয়েবল অ্যাসাইনমেন্ট** এই নিয়মটি মেনে চলে: একটি _ভ্যারিয়েবল অ্যাসাইনমেন্ট_ হলো এমন একটি এক্সপ্রেশন, যা দেখতে এরকম:

```jq
... | expr as $varname | ...
```

## ফিল্টার ইনপুটটিই আউটপুট দেয়

_আইডেন্টিটি এক্সপ্রেশন_ `.`-এর মতোই, _ভ্যারিয়েবল অ্যাসাইনমেন্ট_-এর আউটপুট তার ইনপুটের সমান।
ভ্যারিয়েবলের মান সেট করা একটি সাইড-এফেক্ট।

উদাহরণ, যা দেখায় অ্যাসাইনমেন্টের পরে `.` প্রাথমিক ইনপুটের মতোই:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## ভ্যারিয়েবলের স্কোপ

ভ্যারিয়েবলের স্কোপ "লেক্সিক্যাল"। ভ্যারিয়েবলটি পাইপলাইনের বাকি অংশে স্কোপে থাকবে।
ফাংশনে ডিফাইন করা ভ্যারিয়েবলগুলো (ফাংশন নিয়ে আমরা পরে কথা বলব) ওই ফাংশনের কাছে "লোকাল" হয়।

## ভ্যারিয়েবলের নাম

ভ্যারিয়েবলটিকে অবশ্যই `$` দিয়ে শুরু করতে হবে।
ভ্যারিয়েবলের নামের বাকি অংশটি একটি **আইডেন্টিফায়ার**: এটি একটি অক্ষর বা আন্ডারস্কোর দিয়ে শুরু হয়, তারপর থাকে অক্ষর, সংখ্যা বা আন্ডারস্কোর।

## ডিস্ট্রাকচারিং অ্যাসাইনমেন্ট

ম্যানুয়াল থেকে:

> একটি প্যাটার্ন দিয়ে, যা _ইনপুটের গঠনের সাথে মেলে_, একটি একক `as` এক্সপ্রেশন ব্যবহার করে একাধিক ভ্যারিয়েবল ডিক্লেয়ার করা যায় (একে "ডিস্ট্রাকচারিং" বলা হয়)।

উদাহরণ:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

ভ্যারিয়েবলের নাম _অবজেক্ট কী (key)_-এর সাথে মেলালে একটি শর্টকাট পাওয়া যায়:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## কনস্ট্যান্ট

উপরের উদাহরণে দেখা গেছে, কনস্ট্যান্ট সংরক্ষণ করার জন্য ভ্যারিয়েবল সুবিধাজনক।
কোডে "ম্যাজিক নাম্বার" দেখানোর চেয়ে কনস্ট্যান্টকে একটি নাম দেওয়া ভালো।

## অনেক সময় ভ্যারিয়েবলের দরকার হয় না

ভ্যারিয়েবল বাদ দিলে অনেক সময় কোড আরও সহজে পড়া যায়।

সংখ্যাগুলোর একটি অ্যারের গড় বের করার কথা ভাবুন

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

এর তুলনায়

```jq
[2, 4, 8, 7] | add / length
```

এটি `jq`-এর সবচেয়ে শক্তিশালী দিকগুলোর একটি তুলে ধরে: একটি ফিল্টারের ইনপুট _প্রতিটি_ সাব-এক্সপ্রেশনকে দেওয়া হয়:

- ইনপুট অ্যারে `[2,4,8,7]` `add`-কে দেওয়া হয় (যা সব এলিমেন্টে `+` অপারেটর প্রয়োগ করে সংখ্যাগুলো যোগ করে)
- _সমান্তরালে_, `[2,4,8,7]` `length`-কেও দেওয়া হয়
- এই সাব-এক্সপ্রেশনগুলো শেষ হলে তাদের ফলাফলগুলো ভাগ করা হয়, ফলে ইনপুট অ্যারের সংখ্যাগুলোর গড় মান রিটার্ন হয়।
