# নির্দেশনার সংযোজন

## ইনপুট ফরম্যাট

গেম বোর্ড বোঝানো `board` প্যারামিটারটি স্ট্রিংয়ের একটি অ্যারে আকারে থাকে।

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

স্ট্রিংয়ের প্রতিটি ক্যারেক্টার একটি সেল বোঝায়।
একটি সেলের বৈধ মানগুলো হলো:

- ` ` একটি স্পেস, যা একটি খালি সেল বোঝায়
- `B` কালো খেলোয়াড়ের দখলে থাকা একটি সেল
- `W` সাদা খেলোয়াড়ের দখলে থাকা একটি সেল

## আউটপুট ফরম্যাট

`getTerritory` ফাংশনটি ২টি প্রপার্টিসহ একটি অবজেক্ট রিটার্ন করবে বলে আশা করা হয়:

- `owner` টেরিটরির মালিক (`NONE`, `BLACK` বা `WHITE`)
- `territory` টেরিটরির প্রতিটি সেলের স্থানাঙ্কের একটি অ্যারে।

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

`getTerritories` ফাংশনটি ৩টি প্রপার্টিসহ একটি অবজেক্ট রিটার্ন করবে বলে আশা করা হয়:

- `territoryBlack` `BLACK` খেলোয়াড়ের মালিকানাধীন টেরিটরিগুলোর প্রতিটি সেলের স্থানাঙ্কের একটি অ্যারে
- `territoryWhite` `WHITE` খেলোয়াড়ের মালিকানাধীন টেরিটরিগুলোর প্রতিটি সেলের স্থানাঙ্কের একটি অ্যারে
- `territoryNone` দুই খেলোয়াড়ের কারও মালিকানাধীন নয় এমন টেরিটরিগুলোর প্রতিটি সেলের স্থানাঙ্কের একটি অ্যারে

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
