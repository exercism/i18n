# sharewith সিগনেচার বদলে গেছে

`ShareWith` ফাংশনের সিগনেচার ঠিক করুন। প্রত্যাশিত সিগনেচার হলো `ShareWith(name string) string`।
Exercism গড়ে উঠেছে TDD ([Test Driven Development](http://testfirst.org/about#tdd)) নীতির উপর।
টেস্টগুলো আগেই লেখা আছে, আর সেগুলোই বাইরের দিকে মুখ করা ইন্টারফেস এবং যে code লিখতে হবে তার আচরণ নির্ধারণ করে দেয়।
সিগনেচার বদলালে টেস্টগুলো ফেল করবে।
