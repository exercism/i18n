# পরিচিতি

Factor, [`calendar`][calendar] ভোকাবুলারি দিয়ে তারিখ ও সময়কে মডেল করে। সময়ের একটি বিন্দু হলো `timestamp`; সময়ের একটি বিস্তার হলো `duration`.

## তারিখ তৈরি করা

`<date>` ([`calendar`][calendar]-এ) নির্দিষ্ট দিনের মধ্যরাতে একটি `timestamp` তৈরি করে:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` একটি `timestamp`-কে আবার তার অংশে ভাগ করে:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## তারিখ খতিয়ে দেখা

`day-of-week` সপ্তাহের দিনটিকে একটি ইন্টিজার হিসেবে রিটার্ন করে: রবিবারের জন্য `0` থেকে শনিবারের জন্য `6` পর্যন্ত। `day-names` ([`calendar.english`][english]-এ) হলো সেই অনুযায়ী নামের তালিকা, তাই `day-names nth` সংখ্যাটিকে একটি নামে বদলে দেয়:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` একটি বছর (বা একটি `timestamp`) নেয়, আর `days-in-month` একটি `timestamp`-এর মাসের দৈর্ঘ্য রিটার্ন করে, যেখানে অধিবর্ষ আগেই হিসাবে ধরা থাকে:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## তারিখের হিসাব

`days`, `weeks` আর `hours`-এর মতো ওয়ার্ড একটি `duration` তৈরি করে, আর `time+` একটি `timestamp`-কে একটি `duration` দিয়ে সরিয়ে দেয়:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

মাস আর বছরের সীমানা পেরিয়েও হিসাব ঠিকঠাক চলে, আর একই মুহূর্ত বোঝায় এমন দুটি `timestamp` `=` দিয়ে তুলনা করলে সমান হয়।

## দিনের সময়

`<timestamp>` সেকেন্ড পর্যন্ত একটি পূর্ণ `timestamp` তৈরি করে। এর শেষ আর্গুমেন্টটি হলো UTC থেকে অফসেট; `instant` (একটি শূন্য `duration`) `timestamp`-কে UTC-তেই রাখে:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` হলো `>date<`-এর প্রতিরূপ, যা একটি `timestamp`-কে তার ঘণ্টা, মিনিট আর সেকেন্ডে ভাগ করে:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` আর `minutes` ঠিক `days`, `weeks` আর `hours`-এর মতোই একটি `duration` তৈরি করে, তাই এদের যেকোনোটিকে `time+`-কে দেওয়া যায়:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

একটি `timestamp`-এর আলাদা আলাদা ফিল্ড পড়া হয় `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` আর `second>>` অ্যাকসেসর দিয়ে:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
