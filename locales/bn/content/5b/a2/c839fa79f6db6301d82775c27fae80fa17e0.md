# নির্দেশনা সংযোজন

## ইঙ্গিত

এই অনুশীলনীতে আমরা `Planet` নামের [অ্যালজেব্রিক ডেটা টাইপ](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)-এর সংজ্ঞা দিয়েছি।
আপনাকে `ageOn` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যা সেকেন্ডে বয়স দেওয়া থাকলে কেউ একটি `Planet`-এ কত বছর বয়সী হবে তা গণনা করে।

টাইপগুলো নিয়ে নিশ্চিত না থাকলে আপনি দেওয়া সিগনেচারটি ব্যবহার করতে পারেন, তবে এটিকে আপনার সৃজনশীলতাকে সীমাবদ্ধ করতে দেবেন না:

```haskell
ageOn :: Planet -> Float -> Float
```
