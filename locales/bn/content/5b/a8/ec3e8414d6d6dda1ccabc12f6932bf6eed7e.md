# নির্দেশনা সংযোজন

## বিটওয়াইজ অপারেটর

PHP-তে [বিটওয়াইজ অপারেটর](https://www.php.net/manual/en/language.operators.bitwise.php) রয়েছে।

উদাহরণস্বরূপ, "বিটওয়াইজ অ্যান্ড" অপারেটর (`&`) ব্যবহার করে যাচাই করা যায় যে একটি সংখ্যার একটি বিট ডিফাইন করা আছে কি না:

```php
$number = 89; // 0b01011001
$mask16 = 16; // 0b00010000
$mask32 = 32; // 0b00100000

$isMask16 = ($number & $mask16) > 0; // 0b00010000 > 0 => TRUE
$isMask32 = ($number & $mask32) > 0; // 0b00000000 > 0 => FALSE
```
