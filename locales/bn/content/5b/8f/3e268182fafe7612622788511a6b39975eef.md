# নির্দেশনা

এই অনুশীলনীতে আপনি একটি উইন্ডো-ভিত্তিক কম্পিউটার সিস্টেম সিমুলেট করবেন।
আপনি এমন কিছু উইন্ডো তৈরি করবেন যা সরানো যায় এবং রিসাইজ করা যায়।
নিচের ছবিটি নিচে আপনি যে মানগুলো নিয়ে কাজ করবেন তার একটি প্রতিনিধিত্ব করে।

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. Program Window-এর প্রপার্টি ডিফাইন করুন

প্রদত্ত ক্লাস স্ক্যাফোল্ড ব্যবহার করে `y`, `x`, `height` ও `width` মানগুলোর জন্য প্রপার্টিগুলো দিন।

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. প্রোগ্রাম উইন্ডোর প্রাথমিক মান ডিফাইন করুন

`ProgramWindow`-এর জন্য একটি কনস্ট্রাক্টর ফাংশন ডিফাইন করুন।
এটি কোনো আর্গুমেন্ট নেবে না, তবে কনস্ট্রাক্টরটি চলার সময় এর প্রপার্টিগুলোর ডিফল্ট মান সেট করবে।
এটি প্রাথমিক `y` ও `x` মান `0` হিসেবে সেট করবে।
এটি প্রাথমিক `height` ও `width` মান একটি `600x800` স্ক্রিন সাইজ হিসেবে সেট করবে।

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. উইন্ডো রিসাইজ করার একটি ফাংশন ডিফাইন করুন

একটি Size ক্লাসের জন্য `Size.php` ফাইলে একটি নতুন ক্লাস ডিফাইন করুন।
এটি `height` ও `width` প্রপার্টি সেট করার জন্য কনস্ট্রাক্টর আর্গুমেন্ট নেবে।
এছাড়াও `ProgramWindow`-এর একটি রিসাইজ ফাংশন প্রয়োজন, যা `Size` অবজেক্ট ইনস্ট্যান্স গ্রহণ করে এবং নিজের প্রপার্টিগুলো আপডেট করে।

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. উইন্ডো সরানোর একটি ফাংশন ডিফাইন করুন

একটি Position ক্লাসের জন্য `Position.php` ফাইলে একটি নতুন ক্লাস ডিফাইন করুন।
এটি `y` ও `x` প্রপার্টি সেট করার জন্য কনস্ট্রাক্টর আর্গুমেন্ট নেবে।
এছাড়াও `ProgramWindow`-এর একটি সরানোর ফাংশন প্রয়োজন, যা `Position` অবজেক্ট ইনস্ট্যান্স গ্রহণ করে এবং নিজের প্রপার্টিগুলো আপডেট করে।

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
