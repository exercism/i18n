# নির্দেশাবলি

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার চারটি কাজ আছে, যেগুলোর সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

~~~~exercism/note
আপনি হয় টাইপ ইনফারেন্স ব্যবহার করতে পারেন, যেখানে আপনি কোনো টাইপ নির্দিষ্ট করেন না, নয়তো এক্সপ্লিসিট টাইপিং ব্যবহার করতে পারেন, যেখানে আপনি টাইপ নির্দিষ্ট করেন।
পরেরটি বেছে নিলে টাইপ হিসেবে `int` ব্যবহার করুন।
~~~~

## 1. মিনিটে ওভেনে প্রত্যাশিত সময় নির্ধারণ করুন

লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত তা যাচাই করার জন্য `expectedMinutesInOven` বাইন্ডিংটি ডিফাইন করুন। রান্নার বই অনুযায়ী, মিনিটে প্রত্যাশিত ওভেন সময় হলো ৪০:

```fsharp
expectedMinutesInOven
// => 40
```

## 2. মিনিটে ওভেনে অবশিষ্ট সময় গণনা করুন

`remainingMinutesInOven` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে লাসাগনাটি ইতোমধ্যে ওভেনে যত মিনিট রয়েছে তা নেয় এবং পূর্বের কাজ থেকে পাওয়া মিনিটে প্রত্যাশিত ওভেন সময়ের ভিত্তিতে রিটার্ন করে লাসাগনাটিকে আরও কত মিনিট ওভেনে থাকতে হবে।

```fsharp
remainingMinutesInOven 30
// => 10
```

## 3. মিনিটে প্রস্তুতির সময় গণনা করুন

`preparationTimeInMinutes` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে লাসাগনায় আপনি যত স্তর যোগ করেছেন তার সংখ্যা নেয় এবং রিটার্ন করে লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```fsharp
preparationTimeInMinutes 2
// => 4
```

## 4. মিনিটে অতিবাহিত সময় গণনা করুন

`elapsedTimeInMinutes` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসাগনায় আপনি যত স্তর যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসাগনাটি যত মিনিট ওভেনে রয়েছে তার সংখ্যা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্নার কাজে আপনার কত মিনিট লেগেছে, যা হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```fsharp
elapsedTimeInMinutes 3 20
// => 26
```
