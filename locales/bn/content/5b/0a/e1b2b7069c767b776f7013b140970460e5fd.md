# সম্পর্কে

হ্যাক্সে, একটি `class` হলো প্রাথমিক ডেটা স্ট্রাকচার, যা ডেটা (ফিল্ড) ও আচরণ (মেথড) একসাথে ধারণ করে। ফিল্ড ও মেথডগুলোকে একটি ক্লাসের মেম্বারও বলা হয়।

[অ্যাক্সেস মডিফায়ার][visibility] ব্যবহার করে মেম্বারগুলোর অ্যাক্সেস সীমাবদ্ধ করা যায়, সেগুলো হলো:

- `public`: যেকোনো জায়গা থেকে মেম্বারটি অ্যাক্সেস করা যায়।
- `private`: শুধু একই ক্লাস থেকে মেম্বারটি অ্যাক্সেস করা যায়।

ক্লাসকে ইনস্ট্যান্স তৈরির টেমপ্লেট হিসেবে ভাবা যায়। একটি [ইনস্ট্যান্স][class-instance] তৈরি করতে শুধু `new` কিওয়ার্ডটি ব্যবহার করুন:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

একটি ফিল্ড ডিফাইন করতে অ্যাক্সেস মডিফায়ার লিখুন, তারপর ভ্যারিয়েবলের নাম আর টাইপ:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

ফিল্ড ডিফাইন করার সময় চাইলে একটি প্রাথমিক মানও বসিয়ে দিতে পারেন। কোনো ফিল্ডে প্রাথমিক মান উল্লেখ না করলে সেটি `null` মান নেবে। ডট নোটেশন ব্যবহার করে ফিল্ড অ্যাক্সেস করতে পারেন:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
