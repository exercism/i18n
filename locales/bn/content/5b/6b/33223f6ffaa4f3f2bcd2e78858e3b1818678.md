# পরিচিতি

PowerShell হলো মাইক্রোসফটের তৈরি একটি ডাইনামিক ও ইমপ্লিসিট টাইপিংয়ের (_তবে [স্ট্রং টাইপড][strong typed] ভ্যারিয়েবলও সমর্থন করে_) স্ক্রিপ্টিং ভাষা, যা মূলত টাস্ক অটোমেশন ও কনফিগারেশন ম্যানেজমেন্টে ব্যবহৃত হয়।

PowerShell ইমপারেটিভ, ফাংশনাল, অবজেক্ট-ওরিয়েন্টেড এবং এমনকি পাইপলাইন স্টাইল প্রোগ্রামিংও সমর্থন করে।

PowerShell তৈরি হয়েছিল .NET প্ল্যাটফর্মের উপর এবং এটি প্রথম প্রকাশিত হয় ২০০৬ সালে।
এটি সমস্ত আধুনিক Windows অপারেটিং সিস্টেমে ডিফল্টভাবে অন্তর্ভুক্ত এবং Mac ও Linux-এও ইনস্টল করা যায়।


## ভ্যারিয়েবল

PowerShell-এ একটি ভ্যারিয়েবল ডিফাইন করার দুটি কমন উপায় রয়েছে।

PowerShell-এ ভ্যারিয়েবলের নাম অবশ্যই একটি `$` দিয়ে শুরু হতে হবে এবং ভ্যারিয়েবলের নামের সাথে একটি মান বাঁধতে অ্যাসাইনমেন্ট অপারেটর `=` ব্যবহার করতে হবে।

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

আপনি চাইলে একটি ভ্যারিয়েবলের টাইপ স্পষ্টভাবে উল্লেখও করতে পারেন, যদি আপনি চান যে মানটি অবশ্যই একটি নির্দিষ্ট টাইপের হতে হবে।
PowerShell সম্ভব হলে একটি টাইপ থেকে আরেকটি টাইপে মানটি রূপান্তর করার সর্বোচ্চ চেষ্টা করবে।

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### কনস্ট্যান্ট

PowerShell-এ কনস্ট্যান্ট হলো এমন ভ্যারিয়েবল যা ডিফাইন করার পর **পরিবর্তন** করা যায় না, **মুছে ফেলাও** যায় না।
এটি আমাদের ভ্যারিয়েবল ডিফাইন করার দ্বিতীয় উপায়ে নিয়ে যায়: `New-Variable` cmdlet ব্যবহার করা।

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

নতুন ভ্যারিয়েবল তৈরির আরও বিস্তারিত ও অ্যাডভান্সড উপায় জানতে, অনুগ্রহ করে [New-Variable][New-Variable] পড়ুন।


## ফাংশন

PowerShell-এ [ফাংশন][functions] ডিফাইন করা হয় `function` কিওয়ার্ড ব্যবহার করে।
প্রতিটি ফাংশনে `()` বন্ধনীর মধ্যে শূন্য বা তার বেশি ফরমাল প্যারামিটার থাকতে পারে, তারপরে থাকে ফাংশন স্কোপ, যা `{` দিয়ে শুরু হয় এবং `}` দিয়ে শেষ হয়।

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell-এ ফাংশন `return` কিওয়ার্ডের মাধ্যমে মান স্পষ্টভাবে রিটার্ন করতে পারে, `FuncName $Arg` সিনট্যাক্স ব্যবহার করে কল করার পর।

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

কীভাবে একটি বিস্তারিত ফাংশন ডেফিনিশন লিখতে হয় এবং কীভাবে ফাংশন অন্তর্নিহিতভাবে মান রিটার্ন করতে পারে, তার একটি অ্যাডভান্সড আলোচনা `Functions` কনসেপ্ট মডিউলে দেওয়া হবে।


## কমেন্ট

PowerShell-এ একক কমেন্ট `#` দিয়ে শুরু হয় এবং লাইনের শেষে গিয়ে শেষ হয়।
PowerShell-এ কমেন্ট ব্লক শুরু হয় `<#` দিয়ে এবং শেষ হয় `#>` দিয়ে।
Comment-Based Help তৈরির জন্য কমেন্ট ব্লকের একটি অ্যাডভান্সড ব্যবহার `Functions` কনসেপ্ট মডিউলে দেখানো হবে।

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
