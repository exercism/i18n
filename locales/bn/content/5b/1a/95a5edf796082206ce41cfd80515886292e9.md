# পরিচিতি

Factor একটি *কনক্যাটিনেটিভ* ভাষা: প্রতিটি ওয়ার্ড একটি শেয়ার করা **ডেটা স্ট্যাক** থেকে নিজের ইনপুট পড়ে, আর নিজের আউটপুট আবার তার উপরেই পুশ করে। মান এক জায়গা থেকে আরেক জায়গায় পাঠানোর অন্য কোনো উপায় নেই।

একটি লিটারাল লিখলে সেটি স্ট্যাকের একদম উপরে পুশ হয়; কোড পড়া হয় বাম থেকে ডানে:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

একটি *স্ট্যাক ইফেক্ট* ঘোষণা লিপিবদ্ধ করে একটি ওয়ার্ডের চুক্তি:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` বলছে, ওয়ার্ডটি দুটি মান পপ করে এবং উল্টো ক্রমে দুটি মান রেখে যায়। নামগুলো কেবল ডকুমেন্টেশন, কম্পাইলার কেবল ইনপুট আর আউটপুটের *সংখ্যা* যাচাই করে, আর স্ট্যাকের একদম উপরে থাকে ডান দিকের নামটি।

প্রতিদিনের `kernel` **শাফল ওয়ার্ড**গুলো স্ট্যাকের উপরের অংশ পুনর্বিন্যাস করে:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

ওয়ার্ড ডিফাইন করা হয় `:` দিয়ে এবং শেষ করা হয় `;` দিয়ে; যে ডেফিনিশনের বডি ঘোষিত ইফেক্টের সাথে মেলে না, কম্পাইলার তা বাতিল করে দেয়।
