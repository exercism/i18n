# পরিচিতি

ক্যারেক্টার ক্লাস আর কোয়ান্টিফায়ারের বাইরেও রেগুলার এক্সপ্রেশন দিয়ে *গঠন* ও *প্রসঙ্গ* বোঝানো যায়। এই বৈশিষ্ট্যগুলোও একই [`regexp`][regexp] ভোকাবুলারিতে আর একই `R/ /` লিটারালে পাওয়া যায়।

প্রথম বন্ধনী `( )` প্যাটার্নের একটি অংশকে দলবদ্ধ করে, যাতে কোনো কোয়ান্টিফায়ার বা `|` ("এটা অথবা ওটা") পুরো দলের ওপরেই কাজ করে; কোনো দলের পরে `?` বসালে সেটি ঐচ্ছিক হয়ে যায়:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

অ্যাঙ্কর একটি প্যাটার্নকে নির্দিষ্ট অবস্থানে আটকে রাখে: `^` (শুরু), `$` (শেষ), এবং `\b` (ওয়ার্ড বাউন্ডারি)।

*লুকঅ্যারাউন্ড* কোনো একটি জায়গার আশপাশ দেখে মিল খুঁজে, কিন্তু জায়গাটি নিজে দখল করে না:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

শেষের `/`-এর পরে বসানো অপশন অক্ষর পুরো প্যাটার্নটাই বদলে দেয়; `i` বসালে প্যাটার্নটি কেস-ইনসেনসিটিভ হয়ে যায়:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

ক্যাপচার গ্রুপের বদলে Factor-এ লুকঅ্যারাউন্ড ব্যবহার করা হয়: এতে ক্যাপচার গ্রুপ এক্সট্র্যাকশন, ব্যাক-রেফারেন্স কিংবা লেজি কোয়ান্টিফায়ার নেই।
