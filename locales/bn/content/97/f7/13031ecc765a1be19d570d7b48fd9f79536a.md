# Tests

DrRacket-এর মাধ্যমে test চালাতে হলে শুধু test ফাইলটি খুলে উপরের ডান দিকের 'Run' বাটনে ক্লিক করুন।

কমান্ড লাইন থেকে test চালাতে হলে, অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি দিয়ে test চালান:

```
raco test <exercise>-test.rkt
```

এখানে `<exercise>` অংশটির জায়গায় অনুশীলনীর স্লাগ বসাতে হবে।
