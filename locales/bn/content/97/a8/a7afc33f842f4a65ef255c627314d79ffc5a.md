# নির্দেশনা সংযোজন

## Arturo-নির্দিষ্ট তথ্য

এই অনুশীলনীতে, ঐ গ্রহে এক বছরের দৈর্ঘ্য বোঝায় এমন একটি নিজস্ব এককসহ [ভৌত রাশি] ব্যবহার করে আপনাকে বয়সগুলো রিটার্ন করতে হবে।
Arturo-তে একটি রাশি একটি সংখ্যাগত পরিমাণ এবং একটি সংশ্লিষ্ট [পরিমাপের একক][unit-of-measurement] নিয়ে গঠিত।

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Arturo-এর বিল্ট-ইন `yr এককটি 31556952 সেকেন্ডে রূপান্তরিত হয়।
তাই আগের নির্দেশনায় উল্লেখিত সেকেন্ডের সংখ্যার হিসাবে আপনার নিজের বছরের একক ডিফাইন করে ব্যবহার করতে হবে।
~~~~

রাশিগুলোকে সামঞ্জস্যপূর্ণ অন্য একটি এককে [রূপান্তর][convert] করা যায়।
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
ফ্লোটিং পয়েন্ট সংখ্যার নির্ভুলতার সীমাবদ্ধতার কারণে Arturo কখনো কখনো স্কেলারকে একটি মূলদ সংখ্যা হিসেবে সংরক্ষণ করে।
এর বদলে মানটি আনুমানিক ফ্লোটিং পয়েন্ট সংখ্যা হিসেবে পেতে [`to` ফাংশন][to] ব্যবহার করা যায়।

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo আমাদের রাশির জন্য নিজস্ব একক [নির্ধারণ][specify] করার সুযোগও দেয়।

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
