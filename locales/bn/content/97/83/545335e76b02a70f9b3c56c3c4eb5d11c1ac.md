# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নিতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে তিনটি কাজ আছে: একটি হলো আপনার লাইসেন্সের প্রয়োজন হবে কি না তা নির্ধারণ করা, একটি হলো দুটি যানবাহনের মধ্যে একটি বেছে নিতে সাহায্য করা, আর একটি হলো ব্যবহৃত যানবাহনের গ্রহণযোগ্য দাম অনুমান করা।

## 1. আপনার ড্রাইভারের লাইসেন্সের প্রয়োজন হবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালাতে ড্রাইভারের লাইসেন্স লাগে।
ধরে নিন যে কেবল `"car"` এবং `"truck"` ধরনের যানবাহনের জন্য লাইসেন্স লাগে, বাকি সবকিছু লাইসেন্স ছাড়াই চালানো যায়।

`needs_license(kind)` ফাংশনটি লিখুন, যা ইনপুট হিসেবে যানবাহনের ধরন একটি স্ট্রিং হিসেবে নেয় এবং সেই ধরনের যানবাহনের জন্য আপনার লাইসেন্স লাগবে কি না তা বোঝানো একটি বুলিয়ান রিটার্ন করে।

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. কেনার জন্য সম্ভাব্য দুটি যানবাহনের মধ্যে একটি বেছে নিন

আপনি হাতে থাকা যানবাহনগুলোর মধ্যে থেকে আপনার বিকল্পগুলো মূল্যায়ন করেন।
আপনি সেগুলো দুটি বিকল্পে নামিয়ে আনতে পেরেছেন, কিন্তু চূড়ান্ত সিদ্ধান্ত নিতে আপনার সাহায্যের প্রয়োজন।
সেজন্য `choose_vehicle(option1, option2)` ফাংশনটি লিখুন, যা আর্গুমেন্ট হিসেবে দুটি যানবাহন নেয় এবং লেক্সিকোগ্রাফিক্যাল ক্রমে যেটি আগে আসে সেই বিকল্পটি সম্বলিত একটি সিদ্ধান্ত রিটার্ন করে।

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

রিটার্ন করা স্ট্রিংটি "<CHOSEN_VEHICLE> is clearly the better choice." প্যাটার্নটি অনুসরণ করা উচিত, যেখানে `<CHOSEN_VEHICLE>` হলো পাস করা আর্গুমেন্টগুলোর মধ্যে থেকে বেছে নেওয়া বিকল্পটি।

## 3. ব্যবহৃত যানবাহনের দামের একটি আনুমানিক হিসাব বের করুন

এখন আপনি সিদ্ধান্ত নিয়ে ফেলেছেন, তাই ডিলারশিপে আপনি ন্যায্য দাম পাচ্ছেন কি না তা নিশ্চিত করতে চান।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, তাই দাম নির্ভর করে যানবাহনটির বয়সের উপর।
মোটামুটি একটি অনুমানের জন্য ধরে নিন, যানবাহনের বয়স যদি ৩ বছরের কম হয়, তবে এর দাম হয় একেবারে নতুন অবস্থায় থাকা মূল দামের ৮০%।
আর যদি বয়স কমপক্ষে ১০ বছর হয়, তবে দাম ৫০%।
আর যদি যানবাহনের বয়স কমপক্ষে ৩ বছর কিন্তু ১০ বছরের কম হয়, তবে দাম মূল দামের ৭০%।

`calculate_resell_price(original_price, age)` ফাংশনটি লিখুন, যা `if`, `else if` এবং `else` ব্যবহার করে এই যুক্তিটি প্রয়োগ করে (চর্চা করতে চাইলে অন্য উপায়ও আছে)।
এটি আর্গুমেন্ট হিসেবে মূল দাম এবং যানবাহনের বয়স নেয় এবং ডিলারশিপে আনুমানিক দামটি রিটার্ন করে।

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> নোট: রিটার্ন ভ্যালুটি `double` টাইপের।
