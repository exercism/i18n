# নির্দেশনা

এই অনুশীলনীতে আপনি নানা ধরনের রিমোট কন্ট্রোলড গাড়ির মধ্যে রেস আয়োজন করবেন। প্রতিটি গাড়ির নিজস্ব গতি ও ব্যাটারি ড্রেনের বৈশিষ্ট্য থাকে।

গাড়ি যাত্রা শুরু করে সম্পূর্ণ (১০০%) ব্যাটারি নিয়ে। প্রতিবার যখন আপনি রিমোট কন্ট্রোল দিয়ে গাড়িটি চালাবেন, এটি গাড়ির গতির সমান মিটার এগিয়ে যাবে এবং অবশিষ্ট ব্যাটারির শতাংশ কমবে তার ব্যাটারি ড্রেনের পরিমাণ সমান।

কোনো গাড়ির ব্যাটারি যদি তার ব্যাটারি ড্রেনের শতাংশের চেয়ে কম হয়ে যায়, তাহলে আপনি আর সেই গাড়িটি চালাতে পারবেন না।

প্রতিটি রেস ট্র্যাকের নিজস্ব দৈর্ঘ্য থাকে। ব্যাটারি শেষ না করে গাড়িগুলো ট্র্যাকটি শেষ করতে পারে কি না তা যাচাই করে তাদের পরীক্ষা করা হয়।

## 1. একটি রিমোট কন্ট্রোলড গাড়ি তৈরি করুন

নিচের এলিমেন্টগুলো নিয়ে একটি `car` অ্যারে ডিফাইন করুন:

- speed
- battery_drain
- battery
- distance_traveled

গাড়ির গতি মিটারে এবং ব্যাটারি ড্রেনের শতাংশ, এই দুটি প্যারামিটার নিয়ে `new_car` নামের একটি ফাংশন ডিফাইন করে আপনি একটি রিমোট কন্ট্রোলড গাড়ি তৈরি করতে পারবেন, যেটি একটি `car` অ্যারে রিটার্ন করে।

নতুন গাড়ির ক্ষেত্রে ব্যাটারি থাকে ১০০%-এ এবং অতিক্রান্ত দূরত্ব শূন্য।

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. একটি রেস ট্র্যাক তৈরি করুন

`track_length` নামের একটিমাত্র এলিমেন্ট নিয়ে `track` নামে আরেকটি অ্যারে ডিফাইন করুন। ট্র্যাকের দূরত্ব মিটারে নিয়ে `new_track` নামের একটি ফাংশন ডিফাইন করে আপনি একটি রেস ট্র্যাক তৈরি করতে পারবেন:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. ব্যাটারি ড্রেন হয়ে গেছে কি না পরীক্ষা করুন

ব্যাটারি ড্রেন হয়ে গেছে কি না তা বোঝায় এমন `battery_drained()` ফাংশনটি ইমপ্লিমেন্ট করুন। আর একবার এগোনোর জন্য যথেষ্ট ব্যাটারি না থাকলে ব্যাটারিটি ড্রেন হয়ে গেছে বলে ধরা হয়।

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. গাড়ি চালান

`drive` ফাংশনটি ইমপ্লিমেন্ট করুন, যা গাড়ির গতির ভিত্তিতে অতিক্রান্ত মিটারের সংখ্যা হালনাগাদ করে এবং ব্যাটারি ড্রেন অনুযায়ী ব্যাটারি কমিয়ে দেয়। আর একবার চালানোর জন্য যথেষ্ট ব্যাটারি না থাকলে গাড়িটি নড়বে না।

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. একটি রিমোট কন্ট্রোলড গাড়ি একটি রেস শেষ করতে পারবে কি না পরীক্ষা করুন

একটি রেস শেষ করতে হলে গাড়িকে রেসের দৈর্ঘ্যের সমান চালাতে সক্ষম হতে হবে। অর্থাৎ ফিনিশ লাইন পার হওয়ার আগে তার ব্যাটারি শেষ হয়ে যাওয়া চলবে না।

`can_finish` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে একটি `car` ও একটি `track` নেয় এবং গাড়িটি রেস শেষ করতে পারলে `TRUE` রিটার্ন করে; অন্যথায় `FALSE` রিটার্ন করে।

ধরে নিন যে আপনি এখন রেসের শুরুর লাইনে দাঁড়িয়ে আছেন এবং রেসের জন্য গাড়ির ইঞ্জিন চালু করছেন। মনে রাখবেন, রেস শুরু করার সময় গাড়ির ব্যাটারি পুরোপুরি চার্জ থাকবে এমন নাও হতে পারে।

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. সম্পূর্ণ চার্জে গাড়িটি একটি ট্র্যাক শেষ করতে পারবে কি না তা সংরক্ষণ করুন

আপনি বিভিন্ন দৈর্ঘ্যের বেশ কিছু ট্র্যাক তৈরি করেছেন, এবং সম্পূর্ণ চার্জে আপনার গাড়ি সেগুলো শেষ করতে পারবে কি না তা সংরক্ষণ করতে হবে।

`store_track` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি গাড়ি, একটি ট্র্যাক ও একটি ট্র্যাকের নাম নেয় এবং একটি অতিরিক্ত এলিমেন্টসহ হালনাগাদ করা গাড়ি রিটার্ন করে। এই এলিমেন্টে থাকবে ট্র্যাকের `name`, এবং এর মান হবে একটি সাব-অ্যারে যাতে থাকবে `track_length` এবং গাড়িটি সেটি `complete` করতে পারবে কি না।

আর্গুমেন্ট হিসেবে দেওয়া গাড়িটি সম্পূর্ণ চার্জেড নাও থাকতে পারে, তাই এটি ব্যবহার করার আগে ব্যাটারি ও অতিক্রান্ত দূরত্ব রিসেট করে নিন।

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
