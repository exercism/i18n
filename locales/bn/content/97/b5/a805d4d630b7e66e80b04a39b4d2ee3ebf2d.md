# ভূমিকা

## ফ্লোটিং পয়েন্ট সংখ্যা

ফ্লোটিং পয়েন্ট সংখ্যা হলো এমন একটি সংখ্যা, যার দশমিক বিন্দুর পরে শূন্য বা তার বেশি ডিজিট থাকে। উদাহরণ: `-2.4`, `0.1`, `3.14`, `16.984025` এবং `1024.0`।

ভিন্ন ভিন্ন ফ্লোটিং পয়েন্ট টাইপ দশমিক বিন্দুর পরে ভিন্ন সংখ্যক ডিজিট সংরক্ষণ করতে পারে। একেই বলে তার প্রিসিশন।

C#-এ তিনটি ফ্লোটিং পয়েন্ট টাইপ আছে:

- `float`: ৪ বাইট (প্রায় ৬-৯ ডিজিট প্রিসিশন)। লেখা হয় `2.45f`।
- `double`: ৮ বাইট (প্রায় ১৫-১৭ ডিজিট প্রিসিশন)। এটি সবচেয়ে কমন টাইপ। লেখা হয় `2.45` অথবা `2.45d`।
- `decimal`: ১৬ বাইট (২৮-২৯ ডিজিট প্রিসিশন)। সাধারণত আর্থিক ডেটা নিয়ে কাজ করার সময় এটি ব্যবহার করা হয়, কারণ এর প্রিসিশন রাউন্ডিং এররের সম্ভাবনা কমিয়ে দেয়। লেখা হয় `2.45m`।

যেমনটি দেখা যাচ্ছে, প্রতিটি টাইপ ভিন্ন সংখ্যক ডিজিট সংরক্ষণ করতে পারে। উদাহরণস্বরূপ, একটি `float` টাইপে PI সংরক্ষণ করতে চাইলে শুধু প্রথম ৬টি দশমিক স্থান সংরক্ষিত হবে (শেষ সংরক্ষিত ডিজিটটি রাউন্ড করা হয়)।

## while লুপ

এই অনুশীলনীতে আপনি একটি লুপ ব্যবহার করতে চাইতে পারেন। C#-এ লুপ লেখার একাধিক উপায় আছে, তবে এখানে `while` লুপই সবচেয়ে উপযুক্ত:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## do while লুপ

লুপের কোডটি যদি অন্তত একবার সবসময় চালানো দরকার হয়, তাহলে `do`/`while` লুপ ব্যবহার করা যায়:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
