# ইনস্টলেশন

## Ubuntu (এবং বেশিরভাগ অন্যান্য Debian-ভিত্তিক ডিস্ট্রিবিউশন)

স্থানীয়ভাবে কোড বিল্ড করতে আপনার gcc আর make দরকার, যেগুলো এভাবে ইনস্টল করা যায়:

```shell
sudo apt install gcc make
```

আপনার কম্পিউটার যদি ARM64 হার্ডওয়্যার না হয়, তাহলে [QEMU][] এমুলেটর আর GCC ARM64 ক্রস-টুলচেইন এভাবে ইনস্টল করুন:

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Debian-ভিত্তিক একটি ডিস্ট্রিবিউশনসহ [Windows Subsystem for Linux][] ব্যবহার করুন এবং উপরের Ubuntu নির্দেশাবলি অনুসরণ করুন।
বিকল্পভাবে, একটি Linux ভার্চুয়াল মেশিন সেট আপ করুন।

## macOS

যেকোনো উপযুক্ত ভার্চুয়ালাইজেশন সমাধান (যেমন [Lima][]) দিয়ে একটি Linux ভার্চুয়াল মেশিন চালু করা যায়।

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
