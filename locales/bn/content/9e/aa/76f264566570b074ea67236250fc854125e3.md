# সহায়তা

আপনি যদি সমস্যায় পড়েন, তাহলে সহায়তা পেতে নিচের রিসোর্সগুলোর একটি ব্যবহার করতে পারেন:

- [ClojureScript API](http://cljs.github.io/api/) অফিসিয়াল API ডকুমেন্ট।
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet), একটি অফিসিয়াল চিট-শিট।
- [/r/clojurescript](https://www.reddit.com/r/clojurescript) হল C# সাবরেডিট।
- [StackOverflow](http://stackoverflow.com/questions/tagged/clojurescript) আপনার সমস্যা খুঁজতে এবং সেটি ইতিমধ্যে উত্তর দেওয়া হয়েছে কিনা তা দেখতে ব্যবহার করা যেতে পারে। আপনি প্রশ্নও করতে পারেন এবং উত্তরও দিতে পারেন।
