# ভূমিকা

[`Nothingness`][concept-nothingness] ধারণাটিতে যেমন আলোচনা করা হয়েছে, তেমনি অনুপস্থিত (`NULL`), অজানা (`NA`) বা গাণিতিকভাবে অবৈধ (`NaN`, `Inf`) ডেটা উপস্থাপন করার নানা উপায় R-এর হাতে আছে।
সাধারণভাবে, R এগুলো দিয়ে সমস্যাগুলোকে জায়গাতেই চিহ্নিত করার চেষ্টা করে এবং কোনো এক্সেপশন ছাড়াই চালিয়ে যায়।

## `stop()`

কিছু সমস্যা এতটাই মৌলিক যে প্রোগ্রামটিকে আর চলতে দেওয়া যায় না।
এমন ক্ষেত্রে, প্রোগ্রামটিকে সঙ্গে সঙ্গে একটি `Error` দিয়ে থামাতে এবং `msg` প্রিন্ট করতে `stop(msg)` ব্যবহার করুন।

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

অন্য ভাষার `assert`-এর মতোই, এটি `stop()`-এর একটি সুবিধাজনক র‍্যাপার।
প্যারামিটারগুলো হলো কমা দিয়ে আলাদা করা যেকোনো সংখ্যক বুলিয়ান শর্ত, আর সেগুলোর সবগুলো `TRUE` হলেই কেবল প্রোগ্রামটি এগিয়ে যাবে।

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `try()`

এরর সামলানোর জন্য R-এর হাতে নানা রকম উপায় আছে।
এগুলো Common Lisp-এর উপর ভিত্তি করে তৈরি এবং বহু জনপ্রিয় ভাষার থেকে অনেকটাই আলাদা।

সবচেয়ে সহজ উপায় হলো সম্ভাব্য সমস্যাযুক্ত কোডকে `try()`-এর ভেতরে র‍্যাপ করা।

```R
g <- function(val) {
  log10(val)
}

g(3)
#> [1] 0.4771213

g("3")
#> Error in log10(val) : non-numeric argument to mathematical function

# with try() and a default value
h <- function(val) {
  result <- NA
  try(result <- log10(val))
  result
}

h(3) # works as before
#> [1] 0.4771213

h("3") # returns a default value plus the error message
#> Error in log10(val) : non-numeric argument to mathematical function
#> [1] NA
```

## `warning()` ও `message()`

এগুলো গুরুতর নয় এমন শর্তের প্রতিক্রিয়া, যেমন:

- এমন কোনো সমস্যার বিষয়ে সতর্ক করার জন্য, যা থেকে প্রোগ্রামটি অন্তত আংশিকভাবে সেরে উঠতে পারে।
- দীর্ঘ সময় ধরে চলা কোনো প্রোগ্রামের অগ্রগতি ব্যবহারকারীকে জানানোর জন্য।

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

`suppressWarnings()` ফাংশনটি মাঝেমধ্যে Exercism-এর ভেতরে কাজে লাগতে পারে, অবাঞ্ছিত আউটপুট দিয়ে টেস্ট রানারকে বিভ্রান্ত করা এড়াতে।
