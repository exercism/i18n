# টেস্ট

## ইন্টারঅ্যাক্টিভভাবে টেস্ট করা

আপনি যে অনুশীলনীতে কাজ করছেন তার ডিরেক্টরিতে আপনার Common Lisp ইমপ্লিমেন্টেশন চালু করুন (অথবা আগে থেকে চলমান Common Lisp ইমপ্লিমেন্টেশনের বর্তমান ডিরেক্টরি সেই ডিরেক্টরিতে বদলে নিন)।
roswell ব্যবহার করে এটি `ros run` দিয়ে করুন।

(এখানে সব উদাহরণে `exercise-name` নামের একটি অনুশীলনী ধরে নেওয়া হয়েছে, প্রয়োজনে বদলে নিন।)

আপনার চলমান Lisp ইমপ্লিমেন্টেশনে টেস্ট ফাইলটি লোড করুন, যেমন `(load "exercise-name-test")`। 
(এটি আপনার জন্য সমাধান ফাইলটিও লোড করে দেবে।)
টেস্ট ফাইলটি লোড হওয়ার পর আপনি REPL-এ `(exercise-name-test:run-tests)` ইভ্যালুয়েট করে টেস্টগুলো চালাতে পারেন।

আপনি যে সমাধানটি লিখছেন তাতে পরিবর্তন আনার সময় পরিবর্তনগুলো লোড করতে আপনার এডিটরের ফিচার ব্যবহার করুন, অথবা আপনার সমাধান ফাইল লোড করতে `(load "exercise-name")` ইভ্যালুয়েট করুন।

আপনার আপডেট করা সমাধান লোড করার পর টেস্টগুলো আবার চালাতে `(exercise-name-test:run-tests)` ইভ্যালুয়েট করতে ভুলবেন না।

## কমান্ড লাইন থেকে টেস্ট করা

আপনি এই কমান্ড লাইন ইনভোকেশন দিয়ে টেস্টগুলো চালু করতে পারেন (আবারও, দুটি জায়গায় "exercise" এর বদলে উপযুক্ত নাম বসান)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

ওই কমান্ডটি বেশ জটিল।
একজন কন্ট্রিবিউটর [এটি আরও সহজে চালু করার উপায়](https://glennj.github.io/exercism/cli) নিয়ে কিছু নোট লিখেছেন।
