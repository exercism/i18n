# নির্দেশনা

জেন একটি বড় কারখানার বাছাই কক্ষে কাজ করছেন।
বাছাই কক্ষে যা-ই আসুক, সেটিকে একটি লেবেল দিয়ে শ্রেণীবদ্ধ করে প্রসেস করতে হয়।
আগেই যেসব জিনিস সংখ্যা হিসেবে শ্রেণীবদ্ধ করা হয়েছে, সেগুলোর দায়িত্ব জেনের, আর বাছাইয়ের কাজে সাহায্যের জন্য তাঁর একটি প্রোগ্রাম দরকার।

বেশিরভাগ প্রিমিটিভ মান সরল লেবেল পাওয়া উচিত।
সংখ্যার জন্য তিনি এমন স্ট্রিং চান যেখানে লেখা থাকবে `"This is the number 2.0"` (সংখ্যাটি যদি 2 হয়)।
ইন্টিজার আর ফ্লোট, দুটোর জন্যই জেন একই আউটপুট চান।

কয়েকটি `Box` ইন্টারফেস আছে, যেগুলোর ভেতরের জিনিস পেতে হলে সেগুলো আনর্যাপ করতে হয়।
`NumberBox` টাইপের জন্য তিনি এমন স্ট্রিং চান যেখানে লেখা থাকবে `"This is a box containing the number 3.0"` (`Number()` মেথডটি যদি 3 রিটার্ন করে)।
`FancyNumberBox` টাইপের জন্য তিনি এমন স্ট্রিং চান যেখানে লেখা থাকবে `"This is a fancy box containing the number 4.0"`, তবে কেবল যদি টাইপটি `FancyNumber` হয়।

অপ্রত্যাশিত যেকোনো কিছু `"Return to sender"` বলা উচিত, যাতে জেন সেগুলো যেখান থেকে এসেছে সেখানে ফেরত পাঠাতে পারেন।

## 1. সরল সংখ্যা বর্ণনা করুন

জেন চান সংখ্যাগুলো এমন স্ট্রিং রিটার্ন করুক যেখানে লেখা থাকবে `"This is the number 2.0"` (দশমিকের পরে একটি ডিজিটসহ):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. একটি নাম্বার বক্স বর্ণনা করুন

জেন চান নাম্বার বক্সগুলো এমন স্ট্রিং রিটার্ন করুক যেখানে লেখা থাকবে `"This is a box containing the number 2.0"` (আবারও দশমিকের পরে একটি ডিজিটসহ):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. ফ্যান্সি নাম্বার বক্স থেকে সংখ্যা বের করে আনে এমন একটি মেথড তৈরি করুন

জেনের একটি `FancyNumberBox` থেকে সংখ্যাটি বের করার জন্য একটি হেল্পার ফাংশন দরকার।
যদি `FancyNumberBox` টাইপটি `FancyNumber` হয়, তাহলে তার মান বের করে সেটিকে `string` থেকে `int` টাইপে রূপান্তর করুন।
অন্য যেকোনো ধরনের `FancyNumberBox` 0 রিটার্ন করবে।

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. একটি ফ্যান্সি নাম্বার বক্স বর্ণনা করুন

যদি `FancyNumberBox` টাইপটি `FancyNumber` হয়, তাহলে জেন এমন স্ট্রিং চান যেখানে লেখা থাকবে `"This is a fancy box containing the number 4.0"`।
অন্য যেকোনো ধরনের `FancyNumberBox` হলে লেখা থাকবে `"This is a fancy box containing the number 0.0"`।

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

দ্রষ্টব্য: আমাদের `ExtractFancyNumber` ফাংশনটি ব্যবহার করা উচিত!

## 5. `DescribeAnything` তৈরি করুন, যা এদের সবগুলো ব্যবহার করে

এটি জেনের প্রয়োজনীয় মূল ফাংশন, যা যেকোনো ইনপুট নেয়।
`DescribeAnything` ফাংশনটিকে পাস করা মানের টাইপ অনুযায়ী অন্য ফাংশনগুলোতে ডেলিগেট করতে হবে।
আরও নির্দিষ্টভাবে:

- `int` আর `float64` দুটোই `DescribeNumber` ফাংশনে ডেলিগেট করবে
- `NumberBox` `DescribeNumberBox` ফাংশনে ডেলিগেট করবে
- `FancyNumberBox` `DescribeFancyNumberBox` ফাংশনে ডেলিগেট করবে
- বাকি যেকোনো কিছু হলে ফলাফল হবে `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
