# টেস্ট

টেস্ট রানার ব্যবহার করতে হলে আপনার [Godot সঠিকভাবে ইনস্টল করা][installation] থাকা দরকার।

## টেস্ট চালানো

সলুশন লোড ও টেস্ট করতে [টেস্ট রানারটি][test runner] ব্যবহার করা হয়।
টেস্ট রানারটি চালাতে হলে, প্রথমে এটি ডাউনলোড করুন, তারপর টেস্ট রানারটি চালাতে `godot` ব্যবহার করুন।
ভবিষ্যতে, `exercism download` ব্যবহার করলে অনুশীলনীগুলোর সাথে টেস্ট রানারটি স্বয়ংক্রিয়ভাবে ডাউনলোড হয়ে যাবে।

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
