# সম্পর্কে

ডিফল্টভাবে, ভ্যারিয়েবল যে স্কোপে ডিফাইন করা হয়, সেই স্কোপেই সীমাবদ্ধ থাকে। কোনো ফাংশন বা ক্লাসের বাইরে কোনো ফাইলে ডিফাইন করলে সেগুলো ওই ফাইলের স্কোপে সীমাবদ্ধ থাকে। আর কোনো ফাংশন বা ক্লাসের ভেতরে ডিফাইন করলে সেগুলো ওই ফাংশন বা ক্লাসের স্কোপে সীমাবদ্ধ থাকে।

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## গ্লোবাল স্কোপ

ভ্যারিয়েবল অ্যাসাইনমেন্টের আগে `global` কিওয়ার্ড ব্যবহার করলে ভ্যারিয়েবলটি গ্লোবাল স্কোপ পায়। এই প্যাটার্নটি অনেক সময় নিরুৎসাহিত করা হয়, কারণ এটি [শক্তভাবে সংযুক্ত কোড](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>) তৈরি করে।

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## স্ট্যাটিক স্কোপ

ভ্যারিয়েবল অ্যাসাইনমেন্ট বা ডিক্লারেশনের আগে `static` কিওয়ার্ড বসালে ভ্যারিয়েবলের স্কোপ বজায় থাকে, তবে এক এক্সিকিউশন স্কোপ থেকে পরেরটিতে এর মানও সংরক্ষিত থাকে।

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

এই উদাহরণে, `$count` ভ্যারিয়েবলটি _শুধু প্রথমবার ফাংশন কল করার সময়_ 0 দিয়ে ইনিশিয়ালাইজ করা হয়। এর পরের প্রতিটি কলে মানটি পরের কলে বহন করা হয়। ফলে ফাংশনটি প্রতিবার কল করলে ক্রমবর্ধমান একটি ইন্টিজার রিটার্ন করে।
