# নির্দেশনা সংযোজন

## ইঙ্গিত

এই অনুশীলনীতে টেক্সট ডেটা নিয়ে কাজ করা হয়। ঐতিহাসিক কারণে Haskell-এর `String` টাইপ `[Char]`-এর সমার্থক, যা ক্যারেক্টারের একটি অ্যারে। টেক্সট ডেটা আরও দক্ষতার সাথে পরিচালনা করার জন্য `Text` টাইপ ব্যবহার করা যেতে পারে।

এই অনুশীলনীর ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি:

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml-এ আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করুন।
- `Data.Text` [এইভাবে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) ইমপোর্ট করুন:

        import qualified Data.Text as T
        import           Data.Text (Text)

- এখন আপনি যেমন `abbreviate :: Text -> Text` লিখতে পারেন এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.filter` হিসেবে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখুন।

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
