# পরিচিতি

`Option` টাইপ হলো F# ভাষার এমন একটি ব্যবস্থা, যা দিয়ে এমন মান নিয়ে কাজ করা যায় যেগুলো থাকতেও পারে, আবার নাও থাকতে পারে।
অন্য ভাষায় এ ধরনের মান সামলাতে `null` ব্যবহার করা খুব কমন; `Option` তার একটি টাইপ-সেফ বিকল্প।
F#-এর স্ট্যান্ডার্ড লাইব্রেরির অনেক ফাংশনেই এটি ব্যবহৃত হয়, তাই স্ট্যান্ডার্ড F# লাইব্রেরি কার্যকরভাবে ব্যবহার করতে হলে এটি বোঝা অপরিহার্য।

## ব্যবহার 

`Option` একটি জেনেরিক টাইপ (এর একটি অন্তর্নিহিত টাইপ থাকে)।  
`Option` মান হয় `Some value`, যা কোনো নির্দিষ্ট মান বোঝায়, নয়তো `None`, যা কোনো মান নেই বোঝায়।

নিচের ফাংশনটি দেখায় কীভাবে একটি `Option` মান তৈরি করতে হয়:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` হলো `Option<T>`-এর সমতুল্য পোস্টফিক্স সিনট্যাক্স; দুটি সিনট্যাক্স ফর্মই একে অপরের বদলে ব্যবহার করা যায়।
তবে F# Style Guide অনুযায়ী, Option টাইপের জন্য পোস্টফিক্স নোটেশনকেই প্রাধান্য দেওয়া হয় (দেখুন [F# Style Guide-এর Formatting Types and Type Annotations অংশ](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions))। 
~~~~

## একটি Option মানের ভেতরের মান পড়া

`Option` মান পড়ার সবচেয়ে স্বাভাবিক উপায় হলো প্যাটার্ন ম্যাচিং, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## ডিফল্ট মান দিয়ে Option আনর‍্যাপ করা

`Option.defaultValue` ফাংশন দিয়ে ডিফল্ট মান দিলে `Option`-গুলোকে "আনর‍্যাপ" করা যায় (অর্থাৎ, সেগুলোর ভেতরের টাইপে রূপান্তর করা যায়)। 
আপনি যখন নিশ্চিত করতে চান যে মানটি `None` নয়, তখন এটি বিশেষভাবে কাজে লাগে।
যেমন:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
