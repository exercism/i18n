# পরিচিতি

কোনো মেথডের প্যারামিটারকে একটি ডিফল্ট মান অ্যাসাইন করে অপশনাল করা যায়। কোনো প্যারামিটার অপশনাল হলে সেই প্যারামিটারের জন্য আর্গুমেন্ট দিতে কলার বাধ্য নন; সেক্ষেত্রে ডিফল্ট মানটিই ব্যবহৃত হয়। [অপশনাল প্যারামিটার][optional-arguments] _অবশ্যই_ প্যারামিটার তালিকার একদম শেষে থাকতে হবে; তাদের পরে নন-অপশনাল প্যারামিটার থাকতে পারবে না। কোনো মেথডে একাধিক অপশনাল প্যারামিটার থাকলে [নেমড আর্গুমেন্ট][named-arguments] ব্যবহার করে আপনি সেগুলোর মধ্য থেকে কয়েকটিই নির্দিষ্ট করতে পারেন।

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

একটি অপশনাল প্যারামিটারের মান অবশ্যই নিচের যেকোনো একটি হতে হবে:

- একটি কনস্ট্যান্ট এক্সপ্রেশন (যেমন `"hi"`, `2`, `DayOfWeek.Friday`, `null` ইত্যাদি)
- ভ্যালু টাইপের একটি `new` এক্সপ্রেশন
- ভ্যালু টাইপের একটি `default` এক্সপ্রেশন
