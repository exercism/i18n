# নির্দেশনা

আপনার কাছের একটি স্থানীয় স্কুলে শিক্ষার্থীদের একটি অত্যন্ত সক্রিয় সমিতি আছে। শিক্ষার্থীদের এই সমিতিটি পরিচালিত হয় একজন প্রেসিডেন্টের নেতৃত্বে, আর প্রতি দুই বছর পরপর নতুন প্রেসিডেন্ট নির্বাচনের জন্য নির্বাচন অনুষ্ঠিত হয়।

এ বছরের নির্বাচনে ঠিক করা হয় যে ভোট গণনার জন্য একটি নতুন ডিজিটাল সিস্টেম প্রয়োজন। এই নতুন সিস্টেমটি তৈরি করতে স্কুলের আপনার সাহায্য দরকার।

## 1. একটি `ElectionResult` থেকে ভোটের সংখ্যা বের করুন

নতুন সিস্টেমের জন্য একটি কাউন্টার থেকে ভোটের সংখ্যা পাওয়ার একটি উপায় থাকতে হবে।

নির্বাচনের ফলাফলের struct-টি আপনার জন্য আগেই তৈরি করা হয়েছে এবং এটি এভাবে ডিফাইন করা:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

`struct`-এর সব সদস্য public হওয়ায় একটি `ElectionResult` অবজেক্ট ইনিশিয়ালাইজ করতে আপনাকে একটি `constructor` লিখতে হবে না। এর বদলে আপনি একটি `initializer list` ব্যবহার করতে পারেন:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

এমন একটি ফাংশন `vote_count` তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি `ElectionResult`-এর রেফারেন্স নেবে এবং `ElectionResult`-টির ভোটের সংখ্যা রিটার্ন করবে।

```cpp
vote_count(hamilton);
// => 1804
```

## 2. একটি `ElectionResult`-এর ভোট বাড়ান

অবশেষে ভোট প্রক্রিয়া করার সময় এসেছে! এখন আপনার একটি `ElectionResult`-এর ভোট বাড়ানোর একটি উপায় দরকার।

এমন একটি `void` ফাংশন `increment_vote_count` তৈরি করুন, যা আর্গুমেন্ট হিসেবে একটি `ElectionResult`-এর রেফারেন্স এবং একটি ভোট-সংখ্যা নেবে, এবং সেই সংখ্যক ভোট দিয়ে `ElectionResult`-টি বাড়িয়ে দেবে।

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. ভোট গণনা এবং প্রেসিডেন্টশিপ

স্কুল তাদের ভোট জমা দিয়েছে, আর এখন বিজয়ী কে তা নির্ধারণের জন্য ফলাফল যাচাই করার সময়।

এমন একটি ফাংশন `determine_result` তৈরি করুন, যা চূড়ান্ত গণনার একটি রেফারেন্স গ্রহণ করে এবং নতুন প্রেসিডেন্টের `ElectionResult`-এর একটি রেফারেন্স রিটার্ন করে। এছাড়া এটি বিজয়ীর নামের আগে "President" প্রিফিক্স বসিয়ে নামটি পরিবর্তন করবে। চূড়ান্ত গণনাটি দেওয়া হয় `std::vector<ElectionResult>`-এর একটি `reference` আকারে, অর্থাৎ অংশগ্রহণকারী সব প্রার্থীর `ElectionResults` সম্বলিত একটি ভেক্টর।

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

সহজ রাখতে আপনি নিচের বিষয়গুলো ধরে নিতে পারেন:
- `vector`-টিতে অন্তত একটি এলিমেন্ট থাকবে।
- প্রথম স্থান নিয়ে কোনো ড্র থাকবে না।
