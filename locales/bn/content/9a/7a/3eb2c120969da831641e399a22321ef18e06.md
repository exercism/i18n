# পরিচিতি

## for লুপ

একটি `for` স্টেটমেন্ট একটি কোড ব্লক বারবার চালায়। এর প্রথম লাইনটি নিয়ন্ত্রণ করে ব্লকটি কতবার পুনরাবৃত্তি হবে:

```go
for init; condition; post {
    // loop body
}
```

- **init** স্টেটমেন্টটি প্রথম ইটারেশনের আগে একবার চলে। সাধারণত লুপে ব্যবহৃত একটি কাউন্টার ভ্যারিয়েবল এখানেই ডিক্লেয়ার ও ইনিশিয়ালাইজ করা হয়।
- **শর্ত** (ইংরেজিতে _condition_) হলো একটি বুলিয়ান এক্সপ্রেশন, যা প্রতিটি ইটারেশনের আগে মূল্যায়ন করা হয়। এর মান `false` হলে লুপ থেমে যায়।
- **post** স্টেটমেন্টটি প্রতিটি সম্পূর্ণ ইটারেশনের পরে চলে। এটি দিয়ে কাউন্টার হালনাগাদ করা যায়।

`init; condition; post` অংশটিকে প্রথম বন্ধনী `()` দিয়ে ঘিরবেন না। তবে লুপের বডিকে ঘিরে রাখা দ্বিতীয় বন্ধনী `{ }` সবসময়ই লাগে।

নিচের লুপটি `i`-কে `1` দিয়ে শুরু করে, `i`-এর বর্তমান মান প্রিন্ট করে, পরের ইটারেশনের জন্য তা বাড়ায়, আর `i` যখন `10`-এ পৌঁছায় তখন থেমে যায়:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## লুপের অন্যান্য রূপ

### শুধু শর্তযুক্ত লুপ

init আর post স্টেটমেন্ট বাদও দেওয়া যায়। শুধু একটি শর্ত থাকা `for` স্টেটমেন্ট অন্য ভাষার `while` লুপের মতোই কাজ করে। Go-তে `while` কিওয়ার্ড বলে কিছু নেই।

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### অসীম লুপ

শর্ত ছাড়াও একটি `for` স্টেটমেন্ট লেখা যায়:

```go
for {
    // loop body
}
```

এই লুপ নিজে থেকে শেষ হয় না। এক্সিকিউশনকে স্পষ্টভাবে লুপ থেকে বেরোতে হবে, যেমন `break` বা `return` দিয়ে।

## লুপ নিয়ন্ত্রণ

### Break এবং Continue

নিচের লুপে `break` লুপ থেকে বেরিয়ে আসে:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` বর্তমান লুপ বডির বাকি অংশ বাদ দিয়ে পরের ইটারেশন শুরু করে:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### লেবেলযুক্ত Break এবং Continue

নেস্টেড লুপের ক্ষেত্রে লেবেল ছাড়া `break` বা `continue` সবচেয়ে ভেতরের লুপে প্রযোজ্য হয়। বাইরের কোনো লুপকে লেবেল করতে চাইলে তার ঠিক উপরের লাইনে একটি আইডেন্টিফায়ার আর তার পরে একটি কোলন বসান। তারপর `break` বা `continue`-এর পরে লুপটির লেবেল লিখলে কাজটি সেই লুপে গিয়ে পড়ে:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
