# নির্দেশনার সংযোজন

## সংরক্ষিত মেমরি

ইনপুট স্ট্রিংয়ের বাফারটি লিনিয়ার মেমরির 64 থেকে 191 নম্বর বাইট ব্যবহার করে।


## আউটপুট ফরম্যাট

সংখ্যাগুলোর সিরিজটি u8 সংখ্যার একটি একটানা অ্যারে হিসেবে প্রত্যাশিত; ডিসিরিয়ালাইজেশনের সময় দৈর্ঘ্য অনুযায়ী এটিকে ভাগ করা হবে:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
