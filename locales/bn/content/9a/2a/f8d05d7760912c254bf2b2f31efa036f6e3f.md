# নির্দেশাবলি

একজন দাবা অনুরাগী হিসেবে আপনি খেলার নিজের একটি সংস্করণ লিখতে চান। হ্যাঁ, অনলাইনে ইতিমধ্যে দাবার অনেক ইমপ্লিমেন্টেশন পাওয়া যায়, কিন্তু আপনারটি হবে অনন্য!

কিন্তু আপনার কল্পনাকে পুরো লাগাম ছেড়ে দেওয়ার আগে, আপনাকে মৌলিক বিষয়গুলো সামলে নিতে হবে। চলুন বোর্ড জেনারেট করে শুরু করি।

দাবার বোর্ডের প্রতিটি ঘর একটি অক্ষর-সংখ্যা জোড়া দিয়ে চিহ্নিত করা হয়। ঘরগুলোর খাড়া কলামগুলো, যাদের ফাইল বলা হয়, A থেকে H পর্যন্ত লেবেল করা থাকে। ঘরগুলোর অনুভূমিক সারিগুলো, যাদের র‍্যাঙ্ক বলা হয়, ১ থেকে ৮ পর্যন্ত সংখ্যায়িত।

## 1. র‍্যাঙ্ক রেঞ্জ ডিফাইন করুন

`rank_range()` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ১ থেকে ৮ পর্যন্ত ইন্টিজারের একটি রেঞ্জ রিটার্ন করবে।

```julia-repl
julia> rank_range()
# output omitted
```

## 2. ফাইল রেঞ্জ ডিফাইন করুন

`file_range()` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি বড় হাতের A থেকে বড় হাতের H পর্যন্ত ক্যারেক্টারের একটি রেঞ্জ রিটার্ন করবে।

```julia-repl
julia> file_range()
# output omitted
```

## 3. র‍্যাঙ্ক রেঞ্জকে র‍্যাঙ্কের ভেক্টরে রূপান্তর করুন

`ranks()` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ১ থেকে ৮ পর্যন্ত ইন্টিজারের একটি ভেক্টর রিটার্ন করবে। ভেক্টরটি হাতে লিখবেন না, `rank_range()` ফাংশন থেকে রিটার্ন করা রেঞ্জ থেকে এটি জেনারেট করুন।

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. ফাইল রেঞ্জকে ফাইলের ভেক্টরে রূপান্তর করুন

`files` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি 'A' থেকে 'H' পর্যন্ত ক্যারেক্টারের একটি ভেক্টর রিটার্ন করবে। ভেক্টরটি হাতে লিখবেন না, `file_range()` ফাংশন থেকে রিটার্ন করা রেঞ্জ থেকে এটি জেনারেট করুন।

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
