# নির্দেশনা

আপনি একজন উৎসাহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কতটি পাখি এসেছে তার হিসাব রাখেন।

আপনার ছয়টি কাজ আছে, সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. গত সপ্তাহের সংখ্যাগুলো কী ছিল তা যাচাই করুন

তুলনার সুবিধার জন্য আপনি সবসময় গত সপ্তাহের সংখ্যাগুলোর একটি কপি কাছে রাখেন, যেগুলো ছিল: 0, 2, 5, 3, 7, 8 এবং 4। গত সপ্তাহের সংখ্যাগুলো ধারণ করে এমন `lastWeek` বাইন্ডিংটি ডিফাইন করুন:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. গতকাল কতটি পাখি এসেছিল তা দেখুন

গতকাল আপনার বাগানে কতটি পাখি এসেছিল, তা রিটার্ন করার জন্য `yesterday` ফাংশনটি ইমপ্লিমেন্ট করুন। পাখির সংখ্যাগুলো দিন অনুসারে সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরোনো দিনের সংখ্যা আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. আসা পাখির মোট সংখ্যা হিসাব করুন

আপনার বাগানে যত পাখি এসেছে তার মোট সংখ্যা রিটার্ন করার জন্য `total` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. কোনো দিনে একটিও পাখি আসেনি কিনা দেখুন

`dayWithoutBirds` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `true` রিটার্ন করে যদি এমন কোনো দিন থাকে যেদিন বাগানে শূন্য পাখি এসেছিল; অন্যথায় `false` রিটার্ন করুন:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. আজকের সংখ্যা এক বাড়ান

আজকের সংখ্যা এক বাড়িয়ে হালনাগাদ সংখ্যাগুলো রিটার্ন করার জন্য `incrementTodaysCount` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. অস্বাভাবিক সপ্তাহ কিনা দেখুন

গত এক বছরে আপনি লক্ষ্য করেছেন, কিছু সপ্তাহে একই রকম অস্বাভাবিক প্যাটার্ন দেখা যায়:
- সপ্তাহের প্রতিটি জোড় দিনে কোনো পাখি ছিল না
- সপ্তাহের প্রতিটি জোড় দিনে ঠিক ১০টি পাখি দেখা গেছে
- সপ্তাহের প্রতিটি বিজোড় দিনে ঠিক ৫টি পাখি দেখা গেছে

`unusualWeek` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `true` রিটার্ন করে যদি এই সপ্তাহের পাখি-সংখ্যার প্যাটার্নটি ওই অস্বাভাবিক প্যাটার্নগুলোর একটির সাথে মেলে:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(লক্ষ্য করুন, দিনের জোড়-বিজোড় হিসাব 1-ইনডেক্সড, 0-ইনডেক্সড নয়। অ্যারের প্রথম এলিমেন্টটি একটি বিজোড় দিনের সাথে মেলে)
