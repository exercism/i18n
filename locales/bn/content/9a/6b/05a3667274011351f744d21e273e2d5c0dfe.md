# পরিচিতি

বাইনারি ডিজিট শেষ বিচারে সরাসরি আপনার CPU বা RAM-এর ট্রানজিস্টরগুলোর সাথে মিলে যায়, এবং প্রতিটি ট্রানজিস্টর "অন" না "অফ" সেটাই নির্ধারণ করে।

নিম্নস্তরের ম্যানিপুলেশন, যাকে অনানুষ্ঠানিকভাবে "বিট-টুইডলিং" বলা হয়, সিস্টেম ভাষায় বিশেষভাবে গুরুত্বপূর্ণ।

Kotlin-এর মতো উচ্চস্তরের ভাষা সাধারণত এই বিবরণের বেশিরভাগই আড়াল করে রাখে।
তবে বিট-স্তরের কিছু মৌলিক অপারেশন [পাওয়া যায়][ref-bitwise]।

## বিট-শিফট অপারেশন

`Int` বা `Long` টাইপ, সাইনড বা আনসাইনড, 1 আর 0-এর একটি স্ট্রিং হিসেবে প্রকাশ করা যায় এবং বিটের একটি ক্রম হিসেবে ম্যানিপুলেট করা যায়।

সম্ভবত আশ্চর্যজনকভাবে, Kotlin-এ `Byte` বা `Short` টাইপ বেশিরভাগ বিটওয়াইজ অপারেশনের সাথে সামঞ্জস্যপূর্ণ নয়।
নিচের সব উদাহরণে ৩২-বিট ইন্টিজার (`Int` বা `UInt`) ব্যবহার করা হয়েছে।

```kotlin
val ns = 0b111  // 7 decimal
Integer.toBinaryString(ns)  // => "111"
```

বিট-শিফট কেবল সবকিছু নির্দিষ্ট সংখ্যক অবস্থান বামে বা ডানে সরিয়ে দেয়।
কিছু বিট এক প্রান্ত থেকে ঝরে পড়ে, আর অন্য প্রান্তটি শূন্য বা এক দিয়ে প্যাড করা হয়।

- `shl` দিয়ে বাম শিফট: শূন্য দিয়ে প্যাডিং।
- `shr` বা `ushr` দিয়ে ডান শিফট: ধনাত্মক সংখ্যার জন্য শূন্য দিয়ে প্যাডিং (ঋণাত্মক সংখ্যার জন্য পরে দেখুন)।

```kotlin
val ns = 0b111  // 7 decimal
ns shl 1  // => 0b1110, decimal 14
ns shr 1  // => 0b11, decimal 3
ns ushr 1  // => 0b11

val nu: UInt = 0b111u  // 7 unsigned
nu shr 1  //  => 0b11
```

প্রতিটি বাম শিফট মানকে দ্বিগুণ করে, আর প্রতিটি ডান শিফট এটিকে অর্ধেক করে (যদিও ট্রাংকেশন হতে পারে)।
দশমিক রূপে এটি আরও স্পষ্ট:

```kotlin
3 shl 2  // => 12
24 shr 3 // => 3
```

এ ধরনের বিট-শিফটিং "নিয়মিত" পাটিগণিতের চেয়ে অনেক দ্রুত, যা এই কৌশলটিকে নিম্নস্তরের কোডিংয়ে খুব জনপ্রিয় করে তুলেছে।

_ঋণাত্মক ইন্টিজার_-এর ক্ষেত্রে আমাদের আরেকটু সতর্ক থাকতে হবে।

ঋণাত্মক মান [টু'স কমপ্লিমেন্ট][wiki-2complement] আকারে সংরক্ষিত হয়, যার মানে বাঁদিকের বিটটি 1।
বাম শিফটে কোনো সমস্যা নেই, কিন্তু ডান শিফট করার সময় বাঁদিকের বিটগুলো কীভাবে প্যাড করব?

```kotlin
val ns = -0b111  // => 0b11111111111111111111111111111001

// shift left: simple
ns shl 1  // => 0b11111111111111111111111111110010, decimal -14

// shift right: preserves sign bit
ns shr 1  // => 0b11111111111111111111111111111100, decimal -4

// unsigned shift right: left-pads with zeros
ns ushr 1 // => 0b01111111111111111111111111111100, decimal 2147483644
```

`shr` অপারেটর [অ্যারিথমেটিক শিফট][wiki-arithmetic] করে, যা সাইন বিট সংরক্ষণ করে।

`ushr` অপারেটর [লজিক্যাল শিফট][wiki-logical] করে, সংখ্যাটিকে আনসাইনড ধরে শূন্য দিয়ে প্যাড করে।

## বিটওয়াইজ লজিক

[বুলিয়ান ধারণা][concept-booleans]-তে আমরা দেখেছি যে `&&` (and), `||` (or) এবং `!` (not) অপারেটরগুলো বুলিয়ান মানের সাথে ব্যবহৃত হয়।

দুটি ইন্টিজারের বিট তুলনা করার জন্য সমতুল্য অপারেটর `and`, `or`, `xor` ([এক্সক্লুসিভ-অর][wiki-xor]) আছে, আর সব বিট উল্টে দেওয়ার জন্য একটি `inv` (ইনভার্সন) ফাংশন আছে।

```kotlin
0b1011 and 0b0010 //  bit is 1 in both numbers
// => 0b0010

0b1011 or 0b0010 // bit is 1 in at least one number
// => 0b1011

0b1011 xor 0b0010 // bit is 1 in exactly one number, not both
// => 0b1001

0b1011.inv() // flip all bits (in a 32-bit signed Int)
// => 0b11111111111111111111111111110100
```
