# নির্দেশাবলি

আপনি একজন শিক্ষক সহকারী, শিক্ষার্থীদের পরীক্ষার খাতা মূল্যায়ন করছেন।
ফলাফল হাতে হাতে হিসাব রাখা ক্রমশ ক্লান্তিকর ও ভুলপ্রবণ হয়ে উঠছে।
তাই আপনি ঠিক করলেন, ক্লাসের ফলাফল গণনা ও হিসাব করার জন্য কিছু ফাংশন বানিয়ে বিষয়টাকে একটু মজাদার করে তুলবেন।

## 1. স্কোর রাউন্ডিং

পরীক্ষার প্রশ্নে আপনি "আংশিক নম্বর" দিতে পারলেও, সামগ্রিক পরীক্ষার স্কোর `int` হতে হবে।
তাই ক্লাসের স্কোর নিয়ে আর কিছু করার আগে, আপনাকে গ্রেডগুলো একবার দেখে নিতে হবে এবং যেকোনো `double` স্কোরকে `int`-এ বদলে ফেলতে হবে।

`round_down_scores()` ফাংশনটি তৈরি করুন, যা `student_scores`-এর একটি `vector` নেয়।
স্কুলগুলো যে রাউন্ডিং চেয়েছে, সেটি হলো দশমিকের পরের অংশ ছেঁটে ফেলা।
আপনার ভাগ্য ভালো, C++ `static_cast` দিয়ে এক টাইপকে আরেক টাইপে কাস্ট করতে পারে।
`double` থেকে `int`-এ `static_cast` রূপান্তর দশমিকের পরের যেকোনো অঙ্ক কেটে ফেলে।
এই ফাংশনটি ইনপুট `vector` নেবে এবং এমন একটি নতুন ভেক্টর `return` করবে যেখানে সব স্কোর `int`-এ রূপান্তরিত।

```cpp
std::vector<double> student_scores {90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3};
round_down_scores(student_scores)
// => {90, 40, 55, 70, 30, 25, 80, 95, 38, 40}
```

একই ফলাফল পাওয়ার আরও উপায় আছে, তবে _কাস্ট_ খুব কমন একটি ব্যাপার।

```cpp
int new_PI{static_cast<int>(3.14) + static_cast<int>(0.001592653589)};
// new_PI is 3.
```

## 2. যেসব শিক্ষার্থী পাস করেনি

পরীক্ষার খাতা মূল্যায়ন করার সময় আপনি লক্ষ্য করলেন, কিছু শিক্ষার্থী আপনার আশানুরূপ ভালো করছে না।
কিন্তু আপনি মনোযোগ হারিয়ে ফেলেছিলেন, এবং ঠিক _কতজন_ শিক্ষার্থী তা লিখে রাখতে ভুলে গিয়েছিলেন।

`count_failed_students()` ফাংশনটি তৈরি করুন, যা `student_scores`-এর একটি `vector` নেয়।
এই ফাংশনটি এমন শিক্ষার্থীর সংখ্যা গণনা করবে যাদের পাস করার মতো স্কোর নেই, এবং সেই সংখ্যাটি একটি ইন্টিজার হিসেবে রিটার্ন করবে।
পরীক্ষায় পাস করার জন্য একজন শিক্ষার্থীর স্কোর **40**-এর বেশি হতে হবে।

```cpp
count_failed_students({90,40,55,70,30,25,80,95,38,40});
// => 5
```

## 3. লেটার গ্রেড গণনা

আপনি যে শিক্ষককে সহায়তা করছেন, তিনি সংখ্যাসূচক স্কোরের পাশাপাশি লেটার গ্রেডও দিতে পছন্দ করেন।
পরীক্ষায় শিক্ষার্থীরা খুব কমই 100 পায়, তাই "লেটার গ্রেড"-এর নিম্ন সীমাগুলো সর্বোচ্চ প্রাপ্ত স্কোরের ভিত্তিতে হিসাব করা হয়, এবং সর্বোচ্চ স্কোর থেকে **<= 40** ফেলের সীমা পর্যন্ত সমানভাবে বাড়তে থাকে।

`letter_grades()` ফাংশনটি তৈরি করুন, যা পরীক্ষার "সর্বোচ্চ" স্কোরকে প্যারামিটার হিসেবে নেয় এবং প্রতিটি "আমেরিকান স্টাইল" গ্রেড ব্যবধানের নিম্ন স্কোর সীমার একটি `array` (ভেক্টর নয়) রিটার্ন করে: `["D", "C", "B", "A"]`।

```cpp
/*Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
*/

letter_grades(100);
// => {41, 56, 71, 86}


/*Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
*/

letter_grades(88);
// => {41, 53, 65, 77}
```

## 4. নামের সাথে স্কোর মেলানো

আপনার কাছে পরীক্ষার স্কোর অবরোহ ক্রমে আছে, এবং সেই অনুযায়ী শিক্ষার্থীদের নামও (তাদের পরীক্ষার স্কোরের ক্রম অনুসারে সাজানো)।
আপনি প্রতিটি শিক্ষার্থীর নাম তাদের পরীক্ষার স্কোরের সাথে মেলাতে চান এবং পুরো ক্লাসের একটি সামগ্রিক র‍্যাঙ্কিং ছাপতে চান।

`student_scores` এবং `student_names` প্যারামিটার নিয়ে `student_ranking()` ফাংশনটি তৈরি করুন।
student_names `vector`-এর প্রতিটি শিক্ষার্থীর নাম student_scores `vector`-এর সংশ্লিষ্ট স্কোরের সাথে মিলিয়ে দিন।
আপনি ধরে নিতে পারেন যে প্রতিটি আর্গুমেন্ট `vector` সর্বোচ্চ স্কোর থেকে সর্বনিম্ন স্কোর পর্যন্ত সাজানো।
ফাংশনটি `<rank>. <student name>: <student score>` ফরম্যাটে স্ট্রিং-এর একটি `vector` রিটার্ন করবে।

```cpp
std::vector<int> student_scores {100, 99, 90, 84, 66, 53, 47};
std::vector<std::string> student_names {"Joci", "Sara","Kora","Jan","Indra","Bern", "Fred"};
student_ranking(student_scores, student_names)
// =>
//  {"1. Joci: 100", "2. Sara: 99", "3. Kora: 90", "4. Jan: 84", "5. Indra: 66", "6. Bern: 53", "7. Fred: 47"}
```

## 5. একটি "পারফেক্ট" স্কোর

পরীক্ষায় 100-এর একটি "পারফেক্ট" স্কোর বিরল হলেও, অন্তত একজন শিক্ষার্থী সেটি অর্জন করেছে কি না, তা জানতে ভালো লাগে।

`student_scores` এবং `student_names` প্যারামিটার নিয়ে `perfect_score()` ফাংশনটি তৈরি করুন।
তালিকাগুলো টাস্ক ৫-এর মতোই।
ফাংশনটি পরীক্ষায় 100 পাওয়া শিক্ষার্থীর _প্রথম_ `<name>`-টি (একটি স্ট্রিং হিসেবে) `return` করবে।

কোনো 100 স্কোর না পাওয়া গেলে, একটি খালি স্ট্রিং `""` রিটার্ন করা উচিত।

```cpp
perfect_score({"Nur", "Tony", "Fatima"}, {90, 80, 100});
// => "Fatima"

perfect_score({"Nur", "Tony"}, {90, 80});
// => ""
```
