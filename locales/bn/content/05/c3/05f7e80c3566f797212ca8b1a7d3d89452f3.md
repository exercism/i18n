# ভূমিকা

## টাইপ ডিক্লারেশন

PHP-তে টাইপ ডিক্লারেশন ফাংশনের আর্গুমেন্ট, রিটার্ন ভ্যালু এবং ক্লাস প্রোপার্টির জন্য রানটাইমে টাইপ অ্যাসারশন প্রদান করে।
ফাংশনে `void` রিটার্ন টাইপ যোগ করা যায়, যা বোঝায় যে ফাংশন থেকে কোনো মান রিটার্ন হয় না।
ডিক্লেয়ার করা টাইপগুলো রানটাইম অ্যাসারশন হিসেবেও কাজ করে যে, ফাংশনগুলো যুক্তিসঙ্গত টাইপের একটি রেসপন্স রিটার্ন করছে।

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### টাইপ ইউনিয়ন

যদি একটি ফাংশন আর্গুমেন্ট, রিটার্ন ভ্যালু বা ক্লাস প্রোপার্টি একাধিক টাইপের হতে পারে, তাহলে একটি টাইপ ইউনিয়ন ডিক্লেয়ার করা যায়।

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### মিক্সড টাইপ

কোড নিয়ে কাজ করার সময় আমরা অনেক সময় টাইপ নির্দিষ্ট করতে পারি না।
PHP 8.0 থেকে `mixed` নামে একটি এস্কেপ-হ্যাচ টাইপ দেওয়া হয়েছে।
`mixed` হলো `object|resource|array|string|float|int|bool|null`-এর একটি টাইপ ইউনিয়নের সমতুল্য।
