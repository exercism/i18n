# পরিচিতি

[টার্নারি কন্ডিশনাল অপারেটর][ternary-operator] হলো `if-else` এক্সপ্রেশনের একটি সংক্ষিপ্ত রূপ। এটি একটি শর্ত মূল্যায়ন করে এবং সেই শর্তটি `true` না `false` তার উপর নির্ভর করে দুটি মানের একটি রিটার্ন করে।

এই অপারেটরটি তিনটি অংশ ব্যবহার করে: `condition ? trueExpression : falseExpression`। যদি `condition`-এর মূল্যায়নের ফল `true` হয়, তবে `trueExpression` মূল্যায়ন করে রিটার্ন করা হয়; অন্যথায় `falseExpression` মূল্যায়ন করে রিটার্ন করা হয়।

সহজ, এক লাইনের পছন্দের জন্য টার্নারি অপারেটরটি আদর্শ:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

উপরের উদাহরণটি এর সংক্ষিপ্ত সমতুল্য রূপ:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
