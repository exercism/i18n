# ইনস্টলেশন

- macOS: `brew install futhark` চালান।
- linux: `brew install futhark` চালান।
- Windows: হয় WSL ব্যবহার করুন, নয়তো [Windows-এর জন্য নির্দিষ্ট নির্দেশনা][windows-specific-instructions] অনুসরণ করুন।

বিকল্প ইনস্টলেশন পদ্ধতিগুলো [অফিসিয়াল ইনস্টলেশন নির্দেশনা][instructions] থেকে জানতে পারবেন।

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
