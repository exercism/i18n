# জাভাস্ক্রিপ্টে রিকারশন বোঝা

রিকারশন প্রোগ্রামিংয়ের একটি শক্তিশালী ধারণা, যেখানে একটি ফাংশন নিজেই নিজেকে কল করে।
প্রথমে বিষয়টি বুঝতে একটু কঠিন লাগতে পারে, কিন্তু একবার মূল বিষয়গুলো বুঝে গেলে জটিল সমস্যা সমাধানে এটি একটি মূল্যবান হাতিয়ার হয়ে ওঠে।
সহজে বোঝা যায় এমন উদাহরণ দিয়ে আমরা জাভাস্ক্রিপ্টে রিকারশন ঘুরে দেখব।

## রিকারশন কী?

কোনো ফাংশন যখন সরাসরি বা পরোক্ষভাবে নিজেই নিজেকে কল করে, তখন তাকে রিকারশন বলে।
এটি লুপের মতোই, তবে এতে একটি সমস্যাকে ছোট ছোট, সহজে সামলানো যায় এমন উপসমস্যায় ভেঙে ফেলা হয়।

### উদাহরণ ১: কাউন্টডাউন

চলুন একটি সহজ উদাহরণ দিয়ে শুরু করি: একটি কাউন্টডাউন ফাংশন।

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

এই উদাহরণে:

- **বেস কেস**: যখন `num`-এর মান 0 বা তার চেয়ে কম হয়ে যায়, তখন ফাংশনটি "Blastoff!" প্রিন্ট করে এবং নিজেকে কল করা বন্ধ করে দেয়।
- **রিকার্সিভ কেস**: ফাংশনটি বর্তমান `num` প্রিন্ট করে এবং `num - 1` দিয়ে নিজেকে কল করে।

### উদাহরণ ২: ফ্যাক্টোরিয়াল

এখন চলুন রিকারশনের একটি ক্লাসিক উদাহরণ দেখি: একটি সংখ্যার ফ্যাক্টোরিয়াল নির্ণয়।

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

এই উদাহরণে:

- **বেস কেস**: যখন `n`-এর মান 0 বা 1 হয়, ফাংশনটি 1 রিটার্ন করে।
- **রিকার্সিভ কেস**: ফাংশনটি `n`-কে `n - 1`-এর ফ্যাক্টোরিয়াল দিয়ে গুণ করে।

## মূল ধারণাগুলো

### বেস কেস

প্রতিটি রিকার্সিভ ফাংশনে অন্তত একটি বেস কেস থাকা উচিত, অর্থাৎ এমন একটি শর্ত যেখানে ফাংশনটি নিজেকে কল করা বন্ধ করে।
বেস কেস না থাকলে রিকারশন অনির্দিষ্টকাল ধরে চলতেই থাকবে, যার ফলে স্ট্যাক ওভারফ্লো ঘটে।

### রিকার্সিভ কেস

রিকার্সিভ কেস ঠিক করে দেয় কীভাবে ফাংশনটি সমস্যার আরও ছোট বা সহজ একটি রূপ দিয়ে নিজেকে কল করবে।

## রিকারশনের সুবিধা ও অসুবিধা

**সুবিধা:**

- কিছু কিছু সমস্যার জন্য চমৎকার সমাধান।
- গাণিতিক আরোহের ধারণার সঙ্গে মিলে যায়।

**অসুবিধা:**

- ইটারেটিভ সমাধানের চেয়ে কম কার্যকর হতে পারে।
- গভীর রিকারশনে স্ট্যাক ওভারফ্লো হতে পারে।

## উপসংহার

রিকারশন একটি মূল্যবান কৌশল, যা জটিল সমস্যাকে ছোট ছোট, সহজে সামলানো যায় এমন উপসমস্যায় ভেঙে দিয়ে সমাধান সহজ করে তোলে।
জাভাস্ক্রিপ্টে কার্যকর রিকার্সিভ সমাধান লিখতে বেস কেস ও রিকার্সিভ কেস বোঝা খুবই জরুরি।
