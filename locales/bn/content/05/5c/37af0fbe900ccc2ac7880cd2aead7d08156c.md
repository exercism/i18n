# সম্পর্কে

সাধারণত ফাংশন শুধু একটি নির্দিষ্ট সংখ্যার আর্গুমেন্ট নেয়।
তবে শেষ প্যারামিটারের টাইপের আগে `...` বসালে ফাংশনটি তার পেছনে যেকোনো সংখ্যার আর্গুমেন্ট নিতে পারে।
এতে শেষ প্যারামিটারটি একটি _ভ্যারিয়াডিক প্যারামিটার_ হয়ে যায়।

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

ফাংশনের ভেতরে ভ্যারিয়াডিক প্যারামিটারটি একটি স্লাইস:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

একটি ফাংশনে ভ্যারিয়াডিক প্যারামিটারের আগে নন-ভ্যারিয়াডিক প্যারামিটার থাকতে পারে।
একটি ফাংশনে সর্বাধিক একটি ভ্যারিয়াডিক প্যারামিটার থাকতে পারে এবং সেটি অবশ্যই শেষ প্যারামিটার হতে হবে।

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## স্লাইস ছড়িয়ে দেওয়া

ভ্যারিয়াডিক প্যারামিটারে একটি স্লাইস পাঠাতে হলে তার পরে `...` বসান:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

ভ্যারিয়াডিক প্যারামিটারে স্লাইস পাঠানোর সময়েই কেবল `...` বৈধ।
