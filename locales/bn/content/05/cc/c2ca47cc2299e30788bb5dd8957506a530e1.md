# টেস্ট

## ইন্টার‍্যাক্টিভভাবে টেস্ট করা

আপনি যে ডিরেক্টরিতে অনুশীলনীটি ডাউনলোড করেছেন, সেখান থেকে REPL চালু করুন।

আপনি `(load "exercise-test")` দিয়ে টেস্ট ফাইলটি REPL-এ লোড করে টেস্টগুলো রান করতে পারেন ("exercise"-এর জায়গায় উপযুক্ত নাম বসিয়ে)। এরপর সব টেস্ট রান করতে `(exercise-test:run-tests)` ইভ্যালুয়েট করুন।

আপনি যদি সরাসরি REPL-এ কোড লেখেন, তাহলে কেবল `(exercise-test:run-tests)` ইভ্যালুয়েট করুন।

আপনি যদি অনুশীলনীর lisp ফাইলে কোড লেখেন, তাহলে `(load "exercise")` দিয়ে সেটি লোড করুন, তারপর `(exercise-test:run-tests)` ইভ্যালুয়েট করুন।

## কমান্ড লাইন থেকে টেস্ট করা

আপনি এই কমান্ড লাইনটি দিয়ে টেস্টগুলো চালু করতে পারেন (আবারও, দুই জায়গায় "exercise"-এর জায়গায় উপযুক্ত নাম বসান)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
