# ভূমিকা

`bit` হলো কম্পিউটিংয়ের সবচেয়ে সূক্ষ্ম মান।
`bit` শব্দের অর্থ "বাইনারি ডিজিট"।
এটি এক্সিকিউশন এনভায়রনমেন্টে ডেটা সংরক্ষণের একটি একক, যা দুটি মানের মধ্যে যেকোনো একটি হতে পারে এমন অবজেক্ট ধারণ করার জন্য যথেষ্ট বড়।
তাই এর বাইনারি মান `1` অথবা `0`।
বাকি সব ডেটা টাইপ একাধিক `bits` দিয়ে গঠিত।
যেমন, একটি `byte` সাধারণত আটটি `bits` নিয়ে গঠিত।

## বিট মাস্ক

একটি বিট মাস্ক হলো এমন যেকোনো মান, যা আলাদা আলাদা বিট সেট করতে ব্যবহৃত হয়।
যেমন, ইংরেজি বর্ণমালায় ২৬টি অক্ষর আছে।
কমপক্ষে ২৬টি বিটের একটি মান, যেমন একটি আনসাইনড ৩২-বিট ইন্টিজার, প্রতিটি ইংরেজি অক্ষরের জন্য `true` বা `false` শর্ত সেট করার বিট মাস্ক হিসেবে ব্যবহার করা যেতে পারে।
প্রয়োজনীয় সংখ্যক `true` বা `false` শর্ত সামলানোর মতো যথেষ্ট বিট আছে এমন যেকোনো মানই বিট মাস্ক হিসেবে কাজ করতে পারে।
আলাদা আলাদা বিট সেট করা ও পড়া হয় বিটওয়াইজ অপারেটর ব্যবহার করে।

## বিটওয়াইজ অপারেটর

ধরা যাক, আমরা একটি `string`-এ কোন কোন অক্ষর আছে তার হিসাব রাখতে চাই।
আমাদের উদাহরণে আমরা শুধু ইংরেজি বর্ণমালার ২৬টি অক্ষর ব্যবহার করব।
আমাদের বিট মাস্ক হবে একটি আনসাইনড ৩২-বিট ইন্টিজার।
কোনো অক্ষর না থাকলে সেটি বোঝাবে `0`।
কোনো অক্ষর একবার বা তার বেশি বার থাকলে সেটি বোঝাবে `1`।
শুরুতে আমাদের বিট মাস্কের বিট রূপ হবে পরপর ৩২টি `0s`: `00000000000000000000000000000000`।
সবচেয়ে ডানের ঘরটি হবে `A`-এর জন্য।
বাম দিক থেকে দ্বিতীয়টি হবে `B`-এর জন্য, আর এভাবে চলবে।
ধরা যাক, আমরা একটি লুপে স্ট্রিংয়ের সব অক্ষর প্রসেস করছি, তাই যেকোনো অক্ষর সেট করার জন্য আমাদের এমন একটি কোড লাইন দরকার, যা সবার জন্য কাজ করবে।

### বিটওয়াইজ শিফট লেফট অপারেটর: একটি বিট নির্দিষ্ট অবস্থানে বসানোর উপায়

`<<` হলো বামে শিফট করার বিটওয়াইজ অপারেটর।

আমাদের অক্ষর যদি `A` হয়, তবে বামে শিফট করতে চাই না; অক্ষর যদি `B` হয়, তবে এক ঘর বামে শিফট করতে চাই; আর অক্ষর যদি `C` হয়, তবে দুই ঘর বামে শিফট করতে চাই, এভাবে চলবে।
যদিও আমরা `chars`-কে `A` বা `B`-এর মতো অক্ষর হিসেবে দেখি, মেমরিতে `char` আসলে একটি ইন্টিজার টাইপ হিসেবে থাকে, তাই `char` দিয়ে সহজ গণনা করা যায়।
আমরা যে `char` প্রসেস করছি তা বোঝানো `letter` নামের একটি ভ্যারিয়েবল ধরে নিলে, `letter` আর `A` `char`-এর মধ্যে পার্থক্য অনুযায়ী `1`-কে বামে শিফট করে প্রয়োজনীয় সংখ্যক ঘর বামে শিফট করতে পারি, এভাবে: `1 << letter - 'A'`।
`A` - `A` হলো `0`, তাই `letter` যদি `A` হয়, তবে এটি `0` ঘর বামে শিফট করবে।
`B` - `A` হলো `1`, তাই `letter` যদি `B` হয়, তবে এটি `1` ঘর বামে শিফট করবে, এভাবে চলবে।

### বিটওয়াইজ ইনক্লুসিভ OR অপারেটর: একটি বিট সেট করার উপায়

আমরা _কোথায়_ একটি বিট সেট করতে চাই সেটি জানা হয়ে গেলে, বিটওয়াইজ ইনক্লুসিভ OR অপারেটর অর্থাৎ `|` ব্যবহার করে সেটি সত্যিই সেট করা যায়।
`|` অপারেটরের ফলাফল প্রতিটি সেই অবস্থানে `1` হবে, যেখানে বাম বা ডান অপারেন্ডের যেকোনো একটিতে বিট সেট আছে।
তাহলে `0010 | 0001`-এর ফলাফল হবে `0011`।
(মনে রাখা জরুরি, মানটি বাইনারিতে `11`, কিন্তু দশমিকে `3`।)
ফলাফল কোনো মানে অ্যাসাইন করতে `|` অপারেটরকে অ্যাসাইনমেন্ট অপারেটরের সাথে মিলিয়ে বিট সেট করা যায়, এভাবে: `|=`।
সহজ রাখতে নিচের উদাহরণে লুপ ব্যবহার করা হয়নি, তবে এটি দেখায় কীভাবে আমরা একটি বিট মাস্কে `ABA` অক্ষরগুলো প্রসেস করতে পারি।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

`A`-এর জন্য আমাদের মাস্কের সবচেয়ে ডানের অংশ `0001` করি, তারপর `B`-এর জন্য মাস্কটি `0011` করি।
আরেকটি `A` সেট করলে বিদ্যমান মাস্কে কোনো পরিবর্তন হয় না।
`A` আগেই সেট হয়েছে কি না তা দেখে আমরা বিটটি আবার সেট করা এড়াতে পারতাম।

### বিটওয়াইজ AND অপারেটর: একটি বিট পড়ার উপায়

`&` হলো বিটওয়াইজ AND অপারেটর।
`&` অপারেটরের ফলাফল প্রতিটি সেই অবস্থানে `1` হবে, যেখানে বাম ও ডান, দুই অপারেন্ডেই বিট সেট আছে।
তাহলে `0011 & 0001`-এর ফলাফল হবে `0001`।
নিচের উদাহরণে এটি কাজ করতে দেখা যায়।

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### বিটওয়াইজ এক্সক্লুসিভ OR অপারেটর: একটি বিট উল্টে দেওয়ার উপায়

`^` হলো বিটওয়াইজ এক্সক্লুসিভ OR অপারেটর।
_ইনক্লুসিভ_ OR অপারেটর থাকলে বোঝা যায়, ভিন্ন আচরণের একটি _এক্সক্লুসিভ_ OR অপারেটরও আছে।
`^` অপারেটরের ফলাফল প্রতিটি সেই অবস্থানে `1` হবে, যেখানে বাম বা ডান অপারেন্ডের _শুধু একটিতে_ বিট সেট আছে।
তাহলে `0001 ^ 0011`-এর ফলাফল হবে `0010`।
সবচেয়ে ডানের বিটটি সেট হবে না, কারণ _দুই_ অপারেন্ডেরই সবচেয়ে ডানের অবস্থানে `1` আছে।
এক্সক্লুসিভ OR অপারেশনকে কখনো কখনো XOR হিসেবে লেখা হয়।
XOR করা কোনো মানের ফলাফলকে আবার XOR করলে মূল মানটিই ফিরে আসে।
এটি খুব সহজ একটি এনক্রিপশনে ব্যবহার করা যায়, যেখানে একই কী দিয়ে ডেটা এনক্রিপ্ট ও ডিক্রিপ্ট দুটোই করা হয়।
যেমন

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## বিট ফিল্ড

সাধারণ একটি ডেটা টাইপে গাদাগাদি করা বিটকে তার অবস্থান দিয়ে চিহ্নিত করা যায়, তা আমরা দেখেছি।
`struct`-এ গাদা করা বিটকে নাম দিয়ে চিহ্নিত করা যায়।
এমন ডেটা টাইপকে বলা হয় `bit field`।
`bit fields`-এর একটি ব্যবহার হতে পারে, যখন ON/OFF ফ্ল্যাগের একটি সেট দরকার এবং মেমরি ব্যবহার কমাতে চাওয়া হয়।

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;` সিনট্যাক্সটি struct-এর ভিতরে থাকা একটি `unsigned int`-এর মধ্যে `1` বিটের একটি ফিল্ড তৈরি করে।
`unsigned int`-এর বদলে `signed int` ব্যবহার করা যায়, অথবা C99 বা তার পরের সংস্করণে `bool` টাইপ ব্যবহার করা যায়।
বিট ফিল্ড থাকা একটি struct-এ অন্য ডেটা টাইপের ফিল্ডও থাকতে পারে, যেমন উপরের উদাহরণের `number_of_lights`।
