# নির্দেশনা

এই অনুশীলনীতে আপনি সেমি-স্ট্রাকচার্ড লগ মেসেজ তৈরি করবেন।

## 1. সেমি-স্ট্রাকচার্ড মেসেজ তৈরি করুন

শুরুতে আপনার কাছে কিছু স্টাব করা ফাংশন এবং নিচের enum থাকবে:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

আপনার লক্ষ্য হলো নিচের ফরম্যাটে একটি লগ মেসেজ তৈরি করা: `"[<LEVEL>]: <MESSAGE>"`।
এর জন্য আপনাকে লগ লেভেলগুলোর সাথে মিলে যায় এমন ফাংশন ইমপ্লিমেন্ট করতে হবে।

উদাহরণস্বরূপ, নিচের স্নিপেটটি `log` ফাংশনের প্রত্যাশিত আউটপুট দেখায়।

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

আর `info` ফাংশনের জন্য:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

শুভকামনা!

## 2. ঐচ্ছিক অতিরিক্ত অনুশীলন

এই স্যুটে একটি ফিচার-গেটেড টেস্ট আছে।
ফিচার গেট আপনার প্রোগ্রামের নির্দিষ্ট কিছু অংশের কম্পাইলেশন পুরোপুরি বন্ধ করে দেয়।
এগুলো নিয়ে পরে আলোচনা করা হবে।
আপাতত শুধু জেনে রাখুন, একটি টেস্ট আছে যা কেবল একটি বিশেষ টেস্টিং ইনভোকেশন ব্যবহার করলে বিল্ড ও রান করা হয়:

```sh
cargo test --features add-a-variant
```

এই টেস্টটি আপনাকে দেখানোর জন্য যে আপনি কীভাবে আপনার enum-এ একটি ভ্যারিয়েন্ট যোগ করবেন।
