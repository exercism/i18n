# অতিরিক্ত

## GNU awk এবং আরবিট্রারি প্রিসিশন অ্যারিথমেটিক

ডিফল্টভাবে `awk`-এ সংখ্যাগুলো ডাবল-প্রিসিশন ফ্লোটিং পয়েন্ট সংখ্যা হিসেবে উপস্থাপিত হয়। এতে ৫৩ বিট প্রিসিশন পাওয়া যায় (ম্যানুয়ালের [সারণি ১৬.৩][table-16.3] দেখুন)। দুর্ভাগ্যবশত, এই অনুশীলনীটি সম্পূর্ণ করতে এটি যথেষ্ট নয় (স্পয়লার অ্যালার্ট: একটি টেস্টে ৬৩ বিট প্রিসিশন দরকার)।

"যথেষ্ট প্রিসিশন নেই" দেখতে এরকম হয়:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk`-এর আরবিট্রারি-প্রিসিশনের সংখ্যা ব্যবহারের ক্ষমতা আছে, যদি সংশ্লিষ্ট লাইব্রেরিগুলো `awk` এক্সিকিউটেবলে কম্পাইল করা থাকে। আপনার awk ভার্সন দেখে নিন, এবং "GNU MPFR" খুঁজুন:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

যদি সেটি থাকে, তাহলে `-M` অপশন দিয়ে এই ক্ষমতাটি চালু করুন:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

আমার `awk`-এ যদি `-M` না থাকে তাহলে কী করব? তাহলে `bc`-এর মতো এমন বাইরের কোনো প্রোগ্রাম কল করতে হবে, যা আরবিট্রারি প্রিসিশন অ্যারিথমেটিক করতে পারে। এটি কীভাবে করা যায় তার একটি উদাহরণের জন্য [পাইপ থেকে getline দিয়ে একটি ভ্যারিয়েবলে আনা][getline-pipe] অংশটি দেখুন।
