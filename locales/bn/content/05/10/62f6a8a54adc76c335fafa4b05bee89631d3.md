# বেসিকস পরিচিতি

[Go](https://golang.org) একটি স্ট্যাটিক টাইপের, কম্পাইল করা প্রোগ্রামিং ভাষা।
Go-এর সিনট্যাক্স C-এর মতো।
আগের ডোমেইন নাম golang.org-এর কারণে ভাষাটিকে প্রায়ই Golang বলা হয়, কিন্তু এর সঠিক নাম Go.

বেসিকস কনসেপ্টে ভাষার তিনটি প্রধান বৈশিষ্ট্য পরিচয় করিয়ে দেওয়া হবে: প্যাকেজ, ফাংশন আর ভ্যারিয়েবল।

## প্যাকেজ

Go অ্যাপ্লিকেশন প্যাকেজে সাজানো থাকে।
একটি প্যাকেজ হলো একই ডিরেক্টরিতে থাকা সোর্স ফাইলের সমষ্টি।
একটি ডিরেক্টরির সব সোর্স ফাইলকে একই প্যাকেজ নাম শেয়ার করতে হয়।
প্রচলিত নিয়ম হলো প্যাকেজের নাম হবে ইমপোর্ট পাথের শেষ ডিরেক্টরির নাম।
উদাহরণস্বরূপ, ["math/rand" প্যাকেজের](https://golang.org/src/math/rand/) ফাইলগুলো `package rand` স্টেটমেন্ট দিয়ে শুরু হয়।
কোনো প্যাকেজ ইমপোর্ট করলে শুধু সেই এনটিটিগুলোই (ফাংশন, টাইপ, ভ্যারিয়েবল, কনস্ট্যান্ট) ব্যবহার বা অ্যাক্সেস করা যায়, যাদের নাম বড় হাতের অক্ষর দিয়ে শুরু হয়।
Go-তে নামকরণের সুপারিশ করা স্টাইল হলো আইডেন্টিফায়ারগুলো `camelCase` দিয়ে নামকরণ করা হবে, তবে যেগুলো প্যাকেজের বাইরে থেকেও অ্যাক্সেসযোগ্য হওয়ার কথা সেগুলো হবে `PascalCase`.

```go
package lasagna
```

## ভ্যারিয়েবল

Go স্ট্যাটিকভাবে টাইপকৃত, অর্থাৎ কম্পাইলের সময় সব ভ্যারিয়েবলের [একটি নির্দিষ্ট টাইপ থাকতে হয়](https://en.wikipedia.org/wiki/Type_system)।

ভ্যারিয়েবল স্পষ্টভাবে একটি টাইপ উল্লেখ করে ডিফাইন করা যায়:

```go
var explicit int // Explicitly typed
```

আপনি একটি ইনিশিয়ালাইজারও ব্যবহার করতে পারেন, তখন কম্পাইলার ইনিশিয়ালাইজারের টাইপ অনুযায়ী ভ্যারিয়েবলের টাইপ নির্ধারণ করবে।

```go
implicit := 10   // Implicitly typed as an int
```

একবার ডিক্লেয়ার করা হলে, `=` অপারেটর দিয়ে ভ্যারিয়েবলে মান অ্যাসাইন করা যায়।
একবার ডিক্লেয়ার করার পর ভ্যারিয়েবলের টাইপ কখনোই বদলানো যায় না।

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## কনস্ট্যান্ট

কনস্ট্যান্ট ভ্যারিয়েবলের মতোই একটি ডেটা ধারণ করে, কিন্তু প্রোগ্রাম চলার সময় তাদের মান বদলানো যায় না।

কনস্ট্যান্ট `const` কিওয়ার্ড দিয়ে ডিফাইন করা হয় এবং সেগুলো সংখ্যা, ক্যারেক্টার, স্ট্রিং বা বুলিয়ান হতে পারে:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## ফাংশন

Go ফাংশন শূন্য বা তার বেশি প্যারামিটার গ্রহণ করে।
প্যারামিটার স্পষ্টভাবে টাইপ করা লাগে, এখানে কোনো টাইপ ইনফারেন্স নেই।

`return` কিওয়ার্ড দিয়ে ফাংশন থেকে মান রিটার্ন করা হয়।

ফাংশনের নাম উল্লেখ করে এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে একটি ফাংশন কল করা হয়।

লক্ষ্য করুন, Go দুই ধরনের কমেন্ট সমর্থন করে।
একলাইন কমেন্টের আগে `//` বসে আর মাল্টিলাইন কমেন্ট `/*` এবং `*/`-এর মাঝে লেখা হয়।

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
