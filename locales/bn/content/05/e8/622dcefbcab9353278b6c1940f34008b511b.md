# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা বানাতে সাহায্য করবে।

আপনার সামনে চারটি কাজ আছে, সবগুলোই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে ওভেনে রাখার প্রত্যাশিত সময় নির্ধারণ করুন

`$expected_minutes_in_oven` নামে একটি কনস্ট্যান্ট ডিফাইন করুন।
রান্নার বই অনুযায়ী, ওভেনে রাখার প্রত্যাশিত সময় মিনিটে ৪০:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. মিনিটে ওভেনে বাকি সময় হিসাব করুন

এই মানটি ইনপুট হিসেবে নেয় লাসাগনা ওভেনে কত মিনিট ছিল, আর আগের কাজে পাওয়া মিনিটে প্রত্যাশিত ওভেন সময়ের ভিত্তিতে রিটার্ন করে লাসাগনাকে ওভেনে আরও কত মিনিট থাকতে হবে।

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. মিনিটে প্রস্তুতির সময় হিসাব করুন

প্রস্তুতির সময় হলো লাসাগনা ওভেনে দেওয়ার আগে সেটি তৈরি করতে যত সময় লাগে।
প্রতিটি স্তর প্রস্তুত করতে ২ মিনিট লাগে।

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. মিনিটে মোট কাজের সময় হিসাব করুন

লাসাগনা রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, তা হিসাব করুন।
এটি হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনা ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
