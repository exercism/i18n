# ভূমিকা

## অ্যানোনিমাস ফাংশন

Gleam-এ ফার্স্ট-ক্লাস ফাংশন আছে, অর্থাৎ ফাংশন হলো সাধারণ মান, যেগুলো ভ্যারিয়েবলে অ্যাসাইন করা যায়, আর্গুমেন্ট হিসেবে পাঠানো যায় এবং অন্য ফাংশন থেকে রিটার্ন করা যায়।

মডিউলে ডিফাইন করা একটি নামযুক্ত ফাংশনকে তার নাম দিয়েই রেফার করা যায়।

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam-এ আবার অ্যানোনিমাস ফাংশনও আছে, যেগুলো অন্য ফাংশনের ভেতরে ডিফাইন করা হয়।

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

ফাংশনের টাইপ লেখা হয় অ্যানোনিমাস ফাংশনের মতোই সিনট্যাক্স ব্যবহার করে। যে ফাংশন একটি `Int` আর একটি `Float` নেয় এবং একটি `Int` রিটার্ন করে, তার টাইপ লেখা হয় এভাবে:

```gleam
fn(Int, Float) -> Int
```

অ্যানোনিমাস ফাংশন এমন ভ্যারিয়েবল রেফার করতে পারে যেগুলো ফাংশনটি ডিফাইন করার সময় স্কোপে ছিল, আর এ কারণেই এগুলো _ক্লোজার_।

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_ফাংশন ক্যাপচার_ সিনট্যাক্স একটি সুবিধাজনক শর্টহ্যান্ড দেয়, যার মাধ্যমে এমন অ্যানোনিমাস ফাংশন তৈরি করা যায় যা একটি ফাংশনে একটি মাত্র আর্গুমেন্ট পাঠায়। এই দুটি এক্সপ্রেশন সমতুল্য:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
