# স্ট্রিং

একটি **স্ট্রিং** হলো টেক্সটের একটি টুকরো। Sather-এ এর টাইপ `STR`, এবং একটি স্ট্রিং ডাবল কোটেশনের মধ্যে লেখা হয়।

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## স্ট্রিং জোড়া দেওয়া

`+` দুটি স্ট্রিংকে একটির পর একটি জুড়ে দেয়।

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

তাদের মাঝখানে কিছুই বসানো হয় না, তাই স্পেস আলাদা করে চাইতে হয়। এটা বাদ দিলে পাওয়া যায় `"JeanSibelius"`।

## এটা কত বড়?

`.size` হলো একটি স্ট্রিংয়ে কতগুলি ক্যারেক্টার আছে তা। এটা একটি পূর্ণসংখ্যা, তাই এর টাইপ `INT`।

```sather
"Sibelius".size      -- 8
```

`.size`-এর পরে কোনো বন্ধনী নেই, ঠিক যেমন আর্গুমেন্ট নেয় না এমন একটি রুটিনের ক্ষেত্রে।

## একটি অংশ নেওয়া

`.head(n)` হলো প্রথম `n` ক্যারেক্টার। `.tail(n)` হলো শেষ `n`টি।

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` সামনে থেকে গোনে, `tail` পিছন থেকে গোনে। দুটোই মূল স্ট্রিংটিকে অপরিবর্তিত রেখে একটি নতুন স্ট্রিং ফিরিয়ে দেয়।
