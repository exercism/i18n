# মেইনটেইনারদের রিপো অনুমতি

একজন ট্র্যাক মেইনটেইনার হলেন এমন একজন ব্যক্তি যিনি ট্র্যাকের GitHub টিমের সদস্য।
একটি ট্র্যাক টিমের সদস্য হওয়া _আমন্ত্রণভিত্তিক_।

```exercism/note
আপনি যদি একজন ট্র্যাক মেইনটেইনার হতে চান, তাহলে অনুগ্রহ করে [ফোরামে](https://forum.exercism.org/c/exercism/building-exercism/125) একটি টপিক খুলুন।
```

## মেইনটেন্যান্স ক্যাটাগরি

এখানে পাঁচটি মেইনটেন্যান্স ক্যাটাগরি রয়েছে:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

একটি ট্র্যাকের মেইনটেন্যান্স ক্যাটাগরি তিনটি বিষয়ের দ্বারা নির্ধারিত হয়:

1. ট্র্যাকটি সক্রিয় কিনা (অর্থাৎ শিক্ষার্থীরা ওয়েবসাইটে ট্র্যাকটিতে যোগ দিতে পারে)
2. ট্র্যাক মেইনটেইনারের সংখ্যা
3. এমন ট্র্যাক মেইনটেইনারের সংখ্যা যারা `cross-track-maintainers` GitHub টিমেও আছেন

মেইনটেন্যান্স ক্যাটাগরি নির্ধারণ করতে, এই টেবিল থেকে ট্র্যাকের সাথে মেলে এমন প্রথম ক্যাটাগরিটি খুঁজুন:

| ক্যাটাগরি              | সক্রিয়? | মেইনটেইনারের সংখ্যা | ক্রস-ট্র্যাক মেইনটেইনারের সংখ্যা |
| --------------------- | ------- | --------------------- | --------------------------------- |
| wip-track             | না      | যেকোনো                   | যেকোনো                               |
| unmaintained          | হ্যাঁ     | 0                     | 0                                 |
| maintained-autonomous | হ্যাঁ     | > 0                   | = মেইনটেইনারের সংখ্যা           |
| maintained-solitary   | হ্যাঁ     | 1                     | 0                                 |
| maintained            | হ্যাঁ     | > 1                   | < মেইনটেইনারের সংখ্যা           |

## রিপো অনুমতি

মেইনটেন্যান্স ক্যাটাগরি ট্র্যাকের GitHub রিপো(গুলো)র অনুমতি নির্ধারণ করতে ব্যবহৃত হয়।

| ক্যাটাগরি              | PR প্রয়োজন | PR অনুমোদন প্রয়োজন | ক্রস-ট্র্যাক টিম পর্যালোচনা |
| --------------------- | ----------- | -------------------- | ------------------------ |
| wip-track             | না          | না                   | না                       |
| unmaintained          | হ্যাঁ         | হ্যাঁ                  | হ্যাঁ                      |
| maintained-solitary   | হ্যাঁ         | হ্যাঁ                  | হ্যাঁ                      |
| maintained-autonomous | হ্যাঁ         | না                   | না                       |
| maintained            | হ্যাঁ         | না                   | না                       |

```exercism/caution
`wip-track` ক্যাটাগরিটি একমাত্র ক্যাটাগরি যা মেইনটেইনারদের `main`-এ পুশ করতে দেয়।
```

```exercism/caution
টুলিং রিপোতে _সর্বদা_ PR অনুমোদন প্রয়োজন, কারণ তাদের বিষয়বস্তু একটি [CODEOWNERS ফাইল](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners) দ্বারা সুরক্ষিত।
```
