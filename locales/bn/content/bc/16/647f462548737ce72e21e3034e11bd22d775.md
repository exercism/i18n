# ভূমিকা

একটি টুপল হলো নামহীন কিন্তু ক্রমানুসারে সাজানো মানের একটি _ইমিউটেবল_ সমষ্টি।
টুপল যেকোনো (বা একাধিক) ডেটা টাইপ ধারণ করতে পারে, এমনকি অন্য টুপলও।

টুপলকে `(` এবং `)` অক্ষরের মধ্যে কমা দিয়ে পৃথক করা মান হিসেবে সংজ্ঞায়িত করা হয়: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

কেবল একই দৈর্ঘ্য এবং একই টাইপ (একই ক্রমে) থাকা টুপলগুলোর তুলনা করা যায়।
টুপলগুলোর স্ট্রাকচারাল ইকুয়ালিটি থাকে, অর্থাৎ তারা _কেবল_ তখনই সমান হয় যখন তাদের সব মান সমান হয়।

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

টুপল থেকে মান বের করার তিনটি উপায় আছে:

- `fst` এবং `snd` ফাংশন
- টুপল ডিকনস্ট্রাকশন
- প্যাটার্ন ম্যাচিং

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
