# পরিচিতি

Unison ট্রু ও ফলস মান প্রকাশ করে `Boolean` টাইপ দিয়ে। এই টাইপে মাত্র দুটি মান থাকে: `true` এবং `false`.

```unison
trueVariable = true
falseVariable = false
```

বুলিয়ান এক্সপ্রেশন মূল্যায়নের জন্য আমরা এবং, অথবা আর নয়, এই অপারেটরগুলো ব্যবহার করি। এগুলো যথাক্রমে `&&`, `||` আর `not` দিয়ে লেখা হয়।

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Unison-এর বুলিয়ান এক্সপ্রেশনে শর্ট-সার্কিটিং হয়। কোনো `&&` এক্সপ্রেশনের প্রথম আর্গুমেন্ট `false` হলে দ্বিতীয় আর্গুমেন্টটি মূল্যায়ন চালিয়ে যাওয়ার কোনো কারণ নেই। একইভাবে, কোনো `||` এক্সপ্রেশনের প্রথম আর্গুমেন্ট `true` হলে এক্সপ্রেশনটি সঙ্গে সঙ্গে `true` রিটার্ন করে।

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
