# পরিচিতি

একটি switch এক্সপ্রেশন একটি মানকে প্যাটার্নের একটি সেটের মধ্যে থাকা একটি কেসের সাথে ম্যাচ করতে পারে এবং সংশ্লিষ্ট মানটি রিটার্ন করতে পারে, কিংবা সংশ্লিষ্ট কাজটি করতে পারে। এই সংযোগ বোঝানো হয় `=>` চিহ্ন দিয়ে। এছাড়া প্রতিটি প্যাটার্নে `when` কিওয়ার্ড দিয়ে শুরু হওয়া একটি ঐচ্ছিক কেস গার্ড থাকতে পারে। switch-এর ওই "আর্ম"টি নির্বাচিত হওয়ার জন্য কেস গার্ড এক্সপ্রেশনটির মান অবশ্যই ট্রু হতে হবে। কেসগুলো (যেগুলোকে _switch আর্ম_ নামেও বলা হয়) লেখার ক্রম অনুযায়ী মূল্যায়ন করা হয়, আর একটি ম্যাচ পাওয়া মাত্রই প্রক্রিয়াটি মাঝপথেই থেমে যায় এবং সংশ্লিষ্ট মানটি রিটার্ন করা হয়।

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
