# পরিচিতি

Elixir-এ দুই ধরনের সংখ্যা আছে: ইন্টিজার আর ফ্লোট।

ইন্টিজার হলো পূর্ণসংখ্যা।

```elixir
integer = 3
# => 3
```

ইন্টিজার নিয়ে কাজ করার জন্য কিছু দরকারি ফাংশন [`Integer`][integer] মডিউলে পাবেন।

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

বড় ইন্টিজার (আর ফ্লোটও) সাধারণত আন্ডারস্কোর দিয়ে প্রতি তিনটি সংখ্যা করে গ্রুপে ভাগ করে লেখা হয়।

```elixir
1_000_000
# => 1000000
```

Elixir-এ সংখ্যার সর্বোচ্চ আকার কেবল সিস্টেমে থাকা মেমোরির দ্বারাই সীমিত, কারণ Elixir [আরবিট্রারি প্রিসিশন অ্যারিথমেটিক][arbitrary-precision-arithmetic] ব্যবহার করে।

Elixir-এ [বাইনারি, অক্টাল আর হেক্সাডেসিমাল ইন্টিজার][integers-in-other-bases] লেখার শর্টকাট নোটেশনও আছে।

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## তুলনা

একই মান থাকলে ইন্টিজার আর ফ্লোটকে সমান ([`==`][kernel-equal]) ধরা যায়। তবে এরা আলাদা ডেটা টাইপ হওয়ায় কখনোই স্ট্রিক্টলি ইকুয়াল ([`===`][kernel-strictly-equal]) হয় না।

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
