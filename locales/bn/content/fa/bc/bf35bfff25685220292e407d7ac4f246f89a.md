# নির্দেশনার সংযোজন

নন-স্ট্যান্ডার্ড স্ট্রিং লিটারেল ও মেটাপ্রোগ্রামিং নিয়ে পরীক্ষা-নিরীক্ষা করার জন্য এটি একটি ভালো অনুশীলনী।

নন-স্ট্যান্ডার্ড স্ট্রিং লিটারেলের একটি সংক্ষিপ্ত পরিচিতি পাওয়া যাবে এই [ব্লগ পোস্টে](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html)। মেটাপ্রোগ্রামিংয়ের বিস্তারিত গাইড পাওয়া যাবে [ম্যানুয়ালে](https://docs.julialang.org/en/v1/manual/metaprogramming/)।

নিচে বর্ণিত কার্যকারিতা যোগ করে আপনি আপনার সলিউশন বাড়িয়ে নিতে পারেন।

বোনাস A-এর জন্য ব্লগ পোস্টে বর্ণিত মৌলিক বিষয়গুলোই শুধু প্রয়োজন। বোনাস B-এর জন্য Julia-তে মেটাপ্রোগ্রামিংয়ের অনেক বেশি জ্ঞান দরকার।

## বোনাস A
এমন একটি স্ট্রিং লিটারেল তৈরি করুন যা স্ট্রিংটির উপর `ROT13`-এর মতো কাজ করে:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## বোনাস B
`R<i>` স্ট্রিং লিটারেলগুলো তৈরি করুন, যেখানে `i = 0, ..., 26`, যা স্ট্রিংটিকে `i` মান অনুযায়ী শিফট করে:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
