# রক্ষণাবেক্ষণকারীদের জন্য

## Fortran টেস্ট তৈরির সহায়ক স্ক্রিপ্ট: create_fortran_test.py

একটি অনুশীলনীর টেস্ট তৈরি করার সহজ উপায় হলো `bin/create\_fortran\_test.py` স্ক্রিপ্টটি ব্যবহার করা।

এই স্ক্রিপ্টটি দিয়ে একটি প্রাথমিক <exercise>\_test.f90 ফাইল তৈরি করুন, যা আপনার টেস্টের টেমপ্লেট হিসেবে ব্যবহার করা যাবে। সাধারণত, জেনারেট করা ফাইলে থাকা 'response' ফাংশনটিকে সঠিক ফাংশন কল দিয়ে প্রতিস্থাপন করতে হবে।

এছাড়াও মনে রাখবেন, Fortran-এর `\n` আর `\t`-এর মতো বিশেষ অক্ষর নিয়ে সমস্যা আছে, তাই এগুলো হ্যান্ডল করার সময় বিশেষভাবে সতর্ক থাকুন।

### পূর্বশর্ত

- কার্যকর CMake ও Fortran কম্পাইলার
- Python3.x (আপনি চাইলে Python2 দিয়েও এটি কাজ করাতে পারেন, তবে ব্যাকওয়ার্ড কম্প্যাটিবল করতে আমি চেষ্টা করিনি)
- https://github.com/exercism/problem-specifications.git-এর সর্বশেষ সংস্করণ
- git

### নতুন একটি টেস্ট তৈরির কাজের ধারা

- `exercism/problem-specifications` থেকে সর্বশেষ পরিবর্তনগুলো টেনে আনুন, যেমন git clone git@github.com:exercism/problem-specifications.git
- নতুন একটি অনুশীলনী তৈরির জন্য নতুন ব্রাঞ্চ তৈরি করুন, যেমন git checkout -b exercise-bob
- যে উদাহরণটি তৈরি করতে চান সেটির জন্য এই স্ক্রিপ্টটি রান করুন
- `config/CMakeLists.txt` অনুশীলনীর ডিরেক্টরিতে কপি করুন (এর জন্য `bin/update-cmake-files` ব্যবহার করতে পারেন)
- কাজ করা অনুশীলনী ইমপ্লিমেন্ট করুন
- সম্ভাব্য সমস্যাযুক্ত টেস্টগুলো ঠিক করুন (দেখুন যেমন exercise/bob-এর "Test 20" ও "Test 24")
- `ctest` কমান্ডটি কোনো এরর ছাড়াই ভ্যালিডেট করে কিনা নিশ্চিত করুন
- আপনার সমাধান .meta/example.f90-এ কপি করুন এবং অনুশীলনীর ফাইল, যেমন bob.f90, থেকে আসল ইমপ্লিমেন্টেশনটি মুছে ফেলুন
- .docs ও .meta ডিরেক্টরি আপডেট করুন
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - "# Description"-এর জায়গায় "# Instructions" লিখুন
  - .meta/tests.toml ম্যানুয়ালি পূরণ করুন (স্বয়ংক্রিয় কোনো উপায় না আসা পর্যন্ত)
  - .meta/config.json ম্যানুয়ালি পূরণ করুন (স্বয়ংক্রিয় কোনো উপায় না আসা পর্যন্ত)
    - ../problem-specifications/exercises/bob/metadata.yml ব্যবহার করুন
- আপনার পরিবর্তনগুলো নিয়ে একটি পুল রিকোয়েস্ট খুলুন

bob উদাহরণের জন্য:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### `CMakeLists.txt` পরিবর্তন করা

cmake ফাইল পরিবর্তন করার সময় `config/`-এর মাস্টার কপিটি আপডেট করুন এবং `bin/update-cmake-files` দিয়ে এটি সব অনুশীলনীর ডিরেক্টরিতে কপি করুন।

## সমাধান

আপনার সমাধান তৈরি হয়ে গেলে সেটি ".meta" ডিরেক্টরিতে "example.f90" নামে কপি করুন।

সম্ভবত আপনি শিক্ষার্থীর সুবিধার্থে ফাংশন বা সাবরুটিনের একটি কাঠামোগত ইমপ্লিমেন্টেশন রেখে দিতে চাইবেন, আর অনুশীলনীর ডিরেক্টরিতে অনুশীলনীর নামের ফাইলটি রেখে দিতে চাইবেন।
