# ইনস্টলেশন

PureScript ইনস্টল করার সবচেয়ে সহজ উপায় হলো Node.js আর NPM-এর মাধ্যমে।

যদি আপনার কম্পিউটারে আগে থেকে Node.js ইনস্টল করা না থাকে, তবে আপনি এটি [Node.js ওয়েবসাইট](https://nodejs.org/) থেকে ডাউনলোড করতে পারেন। Node.js চালু হয়ে গেলে, PureScript কম্পাইলার আর Spago বিল্ড টুল ইনস্টল করতে টার্মিনালে এই কমান্ডটি লিখুন:

    npm install --global purescript spago

আরও তথ্য পাওয়া যাবে [PureScript রিপোজিটরিতে](https://github.com/purescript/purescript/blob/master/INSTALL.md)।
