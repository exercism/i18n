# পরিচিতি

রেকর্ড হলো একসাথে সম্পর্কিত কিছু ফিল্ডের সমাহার (যেগুলো ভিন্ন ভিন্ন টাইপের হতে পারে)। একটি রেকর্ড ডিফাইন করতে `type` কিওয়ার্ডটি ব্যবহার করা হয়। রেকর্ডের ফিল্ডগুলো `{` ও `}` অক্ষরের মাঝখানে ডিফাইন করা হয়, আর প্রতিটি ফিল্ডের একটি নাম _এবং_ একটি টাইপ থাকে। একটি রেকর্ড তৈরি করতে ফিল্ডগুলোর নাম লিখুন এবং `{` ও `}` অক্ষরের মাঝখানে সেগুলোতে একটি মান অ্যাসাইন করুন। রেকর্ড তৈরির সময় সব ফিল্ডেই একটি মান অ্যাসাইন করতে হবে। ডট নোটেশন ব্যবহার করে একটি রেকর্ড ইনস্ট্যান্সের ফিল্ডের মানগুলো অ্যাক্সেস করা যায়।

রেকর্ড ডিফাইন বা তৈরি করার সময় প্রতিটি ফিল্ড হয় আলাদা লাইনে থাকতে হবে, নয়তো একই লাইনে থাকলে সেমিকোলন (`;`) দিয়ে আলাদা করতে হবে।

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

যেহেতু রেকর্ড ইমিউটেবল, তাই একবার একটি রেকর্ড তৈরি হয়ে গেলে তার ফিল্ডের মান আর কখনোই বদলানো যায় না। আপনি যদি একটি রেকর্ডের মান পরিবর্তন করতে চান, তাহলে `with` কিওয়ার্ডটি দিয়ে বিদ্যমান একটি রেকর্ডের কপি তৈরি করতে পারেন, তবে এক বা একাধিক ফিল্ডের জন্য নতুন মান দিয়ে।

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

রেকর্ডে _স্ট্রাকচারাল ইকুয়ালিটি_ থাকে, অর্থাৎ একই রেকর্ডের অভিন্ন মানবিশিষ্ট দুটি ইনস্ট্যান্স সমতুল্য।

ডট নোটেশন দিয়ে একটি রেকর্ডের ফিল্ড অ্যাক্সেস করার পাশাপাশি, বাইন্ডিং ও প্যাটার্ন ম্যাচিংয়ের মধ্যেও রেকর্ডকে _ডিকনস্ট্রাক্ট_ করা যায়:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
