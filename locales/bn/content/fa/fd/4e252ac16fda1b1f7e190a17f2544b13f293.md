# নির্দেশনা

কিছু "অন্য" ডেভেলপার রিমোট কন্ট্রোল কার প্রকল্পটি [exercise:csharp/remote-control-competition]() নিয়ে কাজ করছিলেন। কোড পরিষ্কার করার জন্য আপনাকে ডেকে পাঠানো হয়েছে।

## 1. গাড়িটি নিজে আর টেলিমেট্রি সিস্টেমের দায়িত্বগুলো আলাদা করুন

`RemoteControlCar` ক্লাসটি রিফ্যাক্টর করে টেলিমেট্রির মেথড ও প্রপার্টিগুলো আলাদা করে ফেলুন, যেগুলো একটি `Telemetry` প্রপার্টির মাধ্যমে অ্যাক্সেস করা হয়।

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. অন্য কোড যেন Telemetry টাইপের উপর অতিরিক্ত নির্ভরতা না নেয়, তা প্রতিরোধ করুন

নিশ্চিত করুন যে গাড়ির স্কোপের বাইরে `Telemetry` ইনস্ট্যান্স তৈরি করা না যায়।

## 3. অন্য কোড যেন Speed struct-এর উপর নির্ভরতা না নেয়, তা প্রতিরোধ করুন

নিশ্চিত করুন যে `RemoteControlCar` ক্লাসের স্কোপের বাইরে `Speed` struct ব্যবহার করা না যায়।

## 4. অন্য কোড যেন SpeedUnits enum-এর উপর নির্ভরতা না নেয়, তা প্রতিরোধ করুন

নিশ্চিত করুন যে `RemoteControlCar` ক্লাসের স্কোপের বাইরে `SpeedUnits` enum ব্যবহার করা না যায়।
