# ক্লাস

ক্লাস হলো [অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং][object-oriented-programming]-এর একটি কেন্দ্রীয় ধারণা।
[Crystal-এ সবকিছুই একটি অবজেক্ট][everything-is-an-object], প্রতিটি অবজেক্টের একটি টাইপ থাকে, আর সে কিছু মেথডে সাড়া দিতে পারে।
ক্লাস হলো অবজেক্ট তৈরির নকশা, যা ভ্যারিয়েবলের মতো স্টেটের জন্য প্রাথমিক মান আর মেথডের মতো আচরণের বাস্তবায়ন দেয়।
অবজেক্ট হলো ক্লাসের ইনস্ট্যান্স, যা সব ইনস্ট্যান্স ভ্যারিয়েবল ও স্টেট ধরে রাখে।

## ক্লাস ডেফিনিশন

`class` কিওয়ার্ড ব্যবহার করে একটি ক্লাস ডিফাইন করা হয়, তারপর `UpperCamelCase`-এ লেখা ক্লাসের নাম থাকে।

```crystal
class Account
end
```

## একটি ইনস্ট্যান্স তৈরি করা

একটি ক্লাসের [ইনস্ট্যান্স তৈরি করতে][new-initialize], `new` মেথড ব্যবহার করে ক্লাসের নাম কল করুন।

```crystal
class Account
end

account = Account.new
```

উপরের উদাহরণে `account` ভ্যারিয়েবলটি `Account` ক্লাসের একটি ইনস্ট্যান্স।

ইনস্ট্যান্স তৈরি করার সময় `initialize` নামের একটি বিশেষ মেথড কনস্ট্রাক্টর হিসেবে কাজ করে।
ইনস্ট্যান্স তৈরি হলে এটি কল করা হয়।
কনস্ট্রাক্টরটি আপনাকে ইনস্ট্যান্সের প্রাথমিক স্টেট সেট করার সুযোগ দেয়।
`initialize` মেথড আর্গুমেন্ট নিতে পারে, যা ইনস্ট্যান্স তৈরির সময় পাস করা হয়।

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize` মেথড হাতে করে কোনো মান রিটার্ন করতে পারে না; এর বদলে `new` নতুন তৈরি হওয়া ইনস্ট্যান্সটি রিটার্ন করে।

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## ইনস্ট্যান্স মেথড

ইনস্ট্যান্স মেথড হলো এমন একটি মেথড, যা একটি ক্লাসের ইনস্ট্যান্সে পাওয়া যায় এবং ওই ইনস্ট্যান্সে কল করা যায়।
ইনস্ট্যান্স মেথড `def` কিওয়ার্ড ব্যবহার করে ডিফাইন করা হয়, তারপর মেথডের নাম থাকে।
এগুলো ক্লাস ডেফিনিশনের ভেতরে ডিফাইন করা হয়।

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## ইনস্ট্যান্স ভ্যারিয়েবল

[ইনস্ট্যান্স ভ্যারিয়েবল][instance-variable] হলো এমন ভ্যারিয়েবল, যা ইনস্ট্যান্সের সব মেথডে পাওয়া যায়।
একটি ইনস্ট্যান্স ভ্যারিয়েবল অ্যাক্সেস করতে হলে আপনাকে একটি ইনস্ট্যান্স মেথড ডিফাইন করতে হবে।
এগুলো `initialize` মেথডে ইনিশিয়ালাইজ করা যায়।
এগুলো `@` প্রিফিক্স ব্যবহার করে ডিফাইন করা হয়।

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

ইনস্ট্যান্স ভ্যারিয়েবল ক্লাস ডেফিনিশনের ভেতরেও ডিফাইন করা যায়।

```crystal
class Account
  @age = 0
end
```

### ইনিশিয়ালাইজেশন-সহ ইনস্ট্যান্স ভ্যারিয়েবল

`initialize` মেথডে পাস করা আর্গুমেন্ট দিয়ে ইনস্ট্যান্স ভ্যারিয়েবল ইনিশিয়ালাইজ করা যায়।
ইনিশিয়ালাইজেশনের সময় ব্যবহৃত আর্গুমেন্টের টাইপ Crystal অনুমান করতে পারে না, তাই এটি উল্লেখ করতে হয়।
এই বিষয়ে আরও পড়তে চাইলে পড়ুন: [টাইপ ইনফারেন্স][type-inference]।
ভ্যারিয়েবলের টাইপ উল্লেখ করতে `:` চিহ্ন ব্যবহার করা যায়, তারপর টাইপ লিখতে হয়।
উদাহরণস্বরূপ, `Int32` টাইপের `balance` নামের একটি ইনস্ট্যান্স ভ্যারিয়েবল তৈরি করতে চাইলে এভাবে করতে পারেন: `@balance : Int32`।
অথবা `Bool` টাইপের `raining` নামের একটি ইনস্ট্যান্স ভ্যারিয়েবল তৈরি করতে চাইলে এভাবে করতে পারেন: `@raining : Bool`।

এটি বাস্তবায়নের কয়েকটি উপায় আছে। একটি হলো `initialize` মেথডে টাইপ-সহ আর্গুমেন্ট ঘোষণা করা, তারপর আর্গুমেন্টটি ইনস্ট্যান্স ভ্যারিয়েবলে অ্যাসাইন করা, যেমন নিচের উদাহরণে:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

আরেকটি উপায় হলো ক্লাস ডেফিনিশনে `@<variable> : <Type>` আকারে ইনস্ট্যান্স ভ্যারিয়েবলের টাইপ ঘোষণা করা, যেমন নিচের উদাহরণে:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## ইনস্ট্যান্স ভ্যারিয়েবল পরিবর্তন করা

মেথড ইনস্ট্যান্স ভ্যারিয়েবল পরিবর্তন করতে পারে।
এই মেথডগুলো ক্লাসের ইনস্ট্যান্সে কল করা যায়।
কোনো মেথড ইনস্ট্যান্স ভ্যারিয়েবল পরিবর্তন করলে সেই পরিবর্তন কেবল যে ইনস্ট্যান্সে কল করা হয়েছে সেখানেই পাওয়া যায়।

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## ক্লাস মেথড

[ক্লাস মেথড][class-methods] হলো এমন মেথড, যা একটি ক্লাসের জন্য ডিফাইন করা হয়, কিন্তু তার ইনস্ট্যান্সের জন্য নয়।
এগুলো ইনস্ট্যান্সের স্টেটের ওপর নির্ভর করে না, এমন মেথড তৈরির একটি উপায় দেয়।
এগুলো `def` কিওয়ার্ড ব্যবহার করে ডিফাইন করা হয়, তারপর `self.<method name>` থাকে।
`self` হলো এমন নেমস্পেসের একটি রেফারেন্স, যা থেকে self কল করা হচ্ছে।
এক্ষেত্রে এটি `Account` ক্লাসকে বোঝায়।
এটি `Account.` লেখার মতোই হতো, তবে `self.` হলো পছন্দনীয় উপায়।

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
