# পরিচিতি

## স্ট্রিং

Common Lisp-এ স্ট্রিং আসলে [ক্যারেক্টার][concept-characters]-এর [ভেক্টর][concept-vectors]। ডাবল কোটেশনের ভেতরে ক্যারেক্টার বসিয়ে এগুলো লেখা হয় (যেমন "Hello World!")।

`stringp` প্রেডিকেট ট্রু রিটার্ন করে কেবল তখনই, যখন দেওয়া মানটি একটি স্ট্রিং হয়।

`subseq` ফাংশন দিয়ে স্ট্রিংকে ছোট ছোট অংশে ভাগ করা যায়। এটি স্ট্রিং, একটি শুরু ইনডেক্স আর চাইলে একটি শেষ ইনডেক্স নেয়। ইনডেক্স গোনা শুরু হয় শূন্য থেকে।

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

`string=` দিয়ে দুইটি স্ট্রিং সমান কি না তা মেলানো যায়। ক্যারেক্টারের ছোট-বড় হাতের অক্ষরের পার্থক্য উপেক্ষা করতে চাইলে `string-equal` ব্যবহার করা যায়।

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

স্ট্রিংয়ের সব অক্ষর বড় হাতের করা, ছোট হাতের করা আর প্রতিটি শব্দের প্রথম অক্ষর বড় করা ইত্যাদি কাজ `string-upcase`, `string-downcase` আর `string-capitalize` দিয়ে করা যায়।

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
