# চুক্তি

```sather
   spare_capacity(load : INT) : INT
      pre load >= 0 and load <= limit
      post result >= 0
   is
      return limit - load;
   end;
```

| দফা | কী বলে | ভাঙলে কার দোষ |
| --- | --- | --- |
| `pre` | প্রবেশের সময় যা সত্য থাকতেই হবে | কলকারীর |
| `post` | ফেরার সময় যা সত্য থাকে | রুটিনের |

দুটিই একটি `BOOL` নেয়, আর দুটিই রুটিনের আর্গুমেন্ট এবং অবজেক্টের অ্যাট্রিবিউট ব্যবহার করতে পারে। `post` আরও `result` ব্যবহার করতে পারে, অর্থাৎ যে মানটি রিটার্ন করা হচ্ছে।

## assert

একটি রুটিনের বডির ভিতরে `assert` এমন কিছু বলে যা ওই মুহূর্তে সত্য হতে হবে:

```sather
      assert load <= limit;
```

এটিও বাকিগুলোর মতো একই সুইচের অধীনে চেক করা হয়।

## ক্লাস ইনভ্যারিয়েন্ট

একটি ক্লাস তার প্রতিটি অবজেক্ট সম্পর্কে এমন কিছু বলতে পারে যা কলের মাঝের সময়ে সত্য:

```sather
   invariant : BOOL is
      return checks >= 0 and limit > 0;
   end;
```

চেকিং চালু থাকলে প্রতিটি পাবলিক রুটিনে ঢোকার ও বেরোনোর সময় এটি চেক করা হয়।

## এটি চালু করা

| ফ্ল্যাগ | কী চেক করে |
| --- | --- |
| `-chk` | সবকিছু: pre, post, assert, invariant, bounds, arithmetic |
| `-chk_no` | কিছুই না |

লক্ষ্য করুন, একা `-chk_pre` এই কম্পাইলারে প্রিকন্ডিশন চেকিং চালু করে *না*; কাজ করে `-chk`-ই। কোনো দফা ভাঙলে প্রোগ্রামটি রুটিন ও সোর্স লাইন প্রিন্ট করে এবং প্রোগ্রাম থামিয়ে দেয়। এটি কোনো এক্সেপশন নয়, আর `protect` এটি ধরবে না।

সাধারণ নিয়ম হলো `-chk` দিয়ে ডেভেলপ ও টেস্ট করা আর ছাড়াই শিপ করা, যাতে শিপ করা প্রোগ্রামে চেকগুলোর কোনো খরচ না পড়ে। তবে টেস্টগুলো আসলে ওই পথগুলো ব্যবহার করলে তবেই এতে লাভ।

## ভালো চুক্তি কেমন হয়

রুটিনের কী দরকার সেটাই বলুন, এটি কীভাবে কাজ করে তা নয়:

```sather
   pre load >= 0 and load <= limit        -- yes
   pre load /= 47                         -- what?
```

যে `post` বডির কথাই আবার বলে, তা কাউকে কিছু শেখায় না:

```sather
   post result = limit - load             -- says the body twice
   post result >= 0                       -- says something worth knowing
```

## ইনহেরিট্যান্স

একটি সাবটাইপ `pre` দুর্বল করতে পারে আর `post` জোরদার করতে পারে, অর্থাৎ বেশি গ্রহণ করে আর বেশি প্রতিশ্রুতি দেয়, কিন্তু কখনোই এর উল্টোটা নয়, নাহলে সুপারটাইপ ধরে লেখা কোড ভেঙে যাবে। চুক্তি থাকেই ঠিক এই নিয়মটিকে যাচাইযোগ্য করার জন্য।
