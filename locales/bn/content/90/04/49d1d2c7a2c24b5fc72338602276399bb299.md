# নির্দেশনা

এই নির্দেশনায় আপনি আপনার প্রিয় রান্নার বই থেকে একটি লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার চারটি কাজ আছে, যেগুলো সবই আপনার রেসিপি রান্নার সাথে সম্পর্কিত।

## 1. ওভেনের প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

`lasagna.oven_time` টেবিল ফিল্ডটি ডিফাইন করুন, যাতে বোঝা যায় লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে হলো ৪০:

```lua
lasagna.oven_time
-- => 40
```

## 2. ওভেনে অবশিষ্ট সময় মিনিটে হিসাব করুন

`lasagna.remaining_oven_time` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে নেয় লাসাগনাটি আসলে কত মিনিট ওভেনে আছে, এবং আগের কাজে পাওয়া ওভেনের প্রত্যাশিত সময় মিনিটের ভিত্তিতে রিটার্ন করে যে লাসাগনাটিকে ওভেনে আর কত মিনিট থাকতে হবে।

```lua
lasagna.remaining_oven_time(30)
-- => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`lasagna.preparation_time` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে নেয় লাসাগনায় আপনি কতটি লেয়ার যোগ করেছেন, এবং রিটার্ন করে যে লাসাগনা প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন, ধরে নিয়ে যে প্রতিটি লেয়ার প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```lua
lasagna.preparation_time(2)
-- => 4
```

## 4. অতিবাহিত কাজের সময় মিনিটে হিসাব করুন

`lasagna.elapsed_time` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসাগনায় আপনি কতটি লেয়ার যোগ করেছেন সেই সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসাগনাটি কত মিনিট ওভেনে আছে সেই সংখ্যা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```lua
lasagna.elapsed_time(3, 20)
-- => 26
```
