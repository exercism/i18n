# পরিচিতি

F#-এ `array` হলো শূন্য বা তার বেশি মানের একটি পরিবর্তনযোগ্য কলেকশন, যার দৈর্ঘ্য নির্দিষ্ট। এর মানে হলো, একবার একটি অ্যারে তৈরি হয়ে গেলে তার আকার আর বদলানো যায় না, কিন্তু তার মানগুলো বদলানো যায়। একটি অ্যারের সব মানের টাইপ একই হতে হয়। অ্যারে নিচের মতো করে ডিফাইন করা যায়:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

ইনডেক্স ব্যবহার করে অ্যারের এলিমেন্টে মান অ্যাসাইন করা যায়, আবার অ্যারে থেকে মান পড়াও যায়। F# অ্যারে শূন্য-ভিত্তিক, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

অ্যারে নিয়ে কাজ করা হয় `Array` মডিউলে ডিফাইন করা ফাংশন ও অপারেটরের মাধ্যমে, অথবা সরাসরি _অ্যারে_ প্যাটার্ন ব্যবহার করে প্যাটার্ন ম্যাচিংয়ের মাধ্যমে:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

প্যাটার্ন ম্যাচিং করার সময় আপনি একটি মান _বাতিলও_ করতে পারেন; কোনো নির্দিষ্ট কেসে যখন কোনো মান নিয়ে আপনার কিছু যায়-আসে না (অর্থাৎ সেই মানটি আপনি আর _ব্যবহার_ করবেন না), তখন সেটি বোঝাতে একটি আন্ডারস্কোর (`'_'`) ব্যবহার করতে পারেন:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

প্যাটার্ন ম্যাচিংয়ের সময় একক `'_'` সবসময় _শেষে_ থাকা উচিত, কারণ অন্য কোনো কেসের সাথে যে মান _মেলে না_, সেটি এই কেসেই সামলানো হয়।
