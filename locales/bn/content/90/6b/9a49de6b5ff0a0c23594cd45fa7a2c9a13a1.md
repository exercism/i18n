# নির্দেশাবলি

ESA (Exercism Space Agency) মঙ্গলগ্রহের একটি উপগ্রহ [ফোবোস][phobos]-এ নতুন একটি মিশনের পরিকল্পনায় পুরোদমে এগিয়ে চলেছে। মিশনের লক্ষ্য হলো ফোবোসের পৃষ্ঠে একটি প্রোব অবতরণ করানো এবং সেই পৃষ্ঠ সম্পর্কে ডেটা ফেরত পাঠানো। প্রোবটির নেভিগেশন কম্পিউটার তৈরিতে ESA আপনার সাহায্য চেয়েছে। নেভিগেশন কম্পিউটারের মেমরি সীমিত, তাই মেমরির ব্যবহার যতটা সম্ভব কম রাখতে হবে। তাই আমাদের উপযুক্ত ডেটা টাইপ ব্যবহার করতে হবে।

## 1. নেভিগেশন কনস্ট্যান্ট

সঠিক হিসাব করার জন্য নেভিগেশন কম্পিউটারকে মহাকাশের কিছু বস্তুর মধ্যে দূরত্ব জানতে হয়। এই দূরত্ব মাপা হয় km-এ।

নিচের কনস্ট্যান্টগুলো ডিফাইন করুন:

- `NEPTUNE_DISTANCE` নামে `4_400_000_000` মানের একটি কনস্ট্যান্ট, যা `Int64` হিসেবে সংরক্ষণ করতে হবে
- `MARS_DISTANCE` নামে `227_940_000` মানের একটি কনস্ট্যান্ট, যা `Int32` হিসেবে সংরক্ষণ করতে হবে
- `ATMOSPHERE_DISTANCE` নামে `10_000` মানের একটি কনস্ট্যান্ট, যা `Int16` হিসেবে সংরক্ষণ করতে হবে

## 2. সঠিক ক্ষেত্রফল বিশ্লেষণ

সঠিক হিসাব করার জন্য নেভিগেশন কম্পিউটারকে মহাকাশের কিছু বস্তুর ক্ষেত্রফল জানতে হয়। একটি ক্ষেত্রফল ঋণাত্মক হতে **পারে না**। ইঞ্জিনিয়াররা প্রোগ্রামটি এমনভাবে বানানোর পরিকল্পনা করেছিলেন যাতে ক্ষেত্রফল ঋণাত্মক হলে একটি ওভারফ্লো এরর তৈরি হয়। তবে ইঞ্জিনিয়াররা সাইনড ইন্টিজারটিকে আনসাইন্ড ইন্টিজারে বদলাতে ভুলে গিয়েছিলেন।

তাই ইঞ্জিনিয়াররা এমন একটি প্রোগ্রাম চান যা একটি সাইনড ইন্টিজারকে আনসাইন্ড ইন্টিজারে রূপান্তর করে।

`Navigation#correct_area_analysis` মেথডটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে একটি `measurement` নেয় এবং ৩২ বিটের একটি আনসাইন্ড ইন্টিজার হিসেবে ক্ষেত্রফল রিটার্ন করে।

~~~~exercism/note
প্রদত্ত ক্ষেত্রফল সর্বদা ৩২ বিটের একটি আনসাইন্ড ইন্টিজার হিসেবে ধরে যাবে।
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. বেগ হিসাব করা

নেভিগেশন কম্পিউটারকে প্রোবের বেগ জানতে হবে। বেগ মাপা হয় m/s-এ।

বেগ হিসাব করতে হলে অতিক্রম করা দূরত্ব এবং সেই দূরত্ব অতিক্রম করতে যে সময় লেগেছে, তা জানতে হবে। তারপর দূরত্ব নিয়ে সেটিকে সময় দিয়ে ভাগ করুন।

বেগ সবসময় নিখুঁত নাও হতে পারে এবং কখনোই খুব বড় কোনো সংখ্যা হবে না। তাই আমরা একটি `Float32` ব্যবহার করতে পারি।

`Navigation#calculate_velocity` মেথডটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে `distance` ও `time` নেয় এবং ৩২ বিটের একটি `Float` হিসেবে বেগ রিটার্ন করে।

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
