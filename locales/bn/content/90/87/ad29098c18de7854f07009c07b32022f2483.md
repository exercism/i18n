# ভূমিকা

## টার্নারি অপারেটর

_টার্নারি অপারেটর_ হলো সাধারণ _if/else_ স্টেটমেন্টের একটি হালকা ও সংক্ষিপ্ত বিকল্প।

সাধারণত রিটার্ন স্টেটমেন্টে ব্যবহৃত হয় (তবে শুধু সেখানেই সীমাবদ্ধ নয়), সিদ্ধান্ত নিতে এটির মাত্র একটি লাইন লাগে; এক্সপ্রেশনটি `true` হলে বাম দিকের মান এবং `false` হলে ডান দিকের মান রিটার্ন করে, নিম্নরূপ:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

অনেক সাধারণ _if/else_ এক্সপ্রেশন _টার্নারি অপারেটর_ ব্যবহার করে সহজ করা যায়।
