# পরিচিতি

একটি [রেকর্ড][records] হলো একসাথে থাকা কিছু ফিল্ডের সংগ্রহ (ফিল্ডগুলো ভিন্ন ভিন্ন টাইপের হতে পারে)। একটি [রেকর্ড ডিফাইন করতে][define] `type` কিওয়ার্ডটি ব্যবহার করা হয়। একটি রেকর্ডের ফিল্ডগুলো `{` আর `}` অক্ষরের মধ্যে ডিফাইন করা হয়, এবং প্রতিটি ফিল্ডের একটি নাম _এবং_ একটি টাইপ থাকে।

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

একটি [রেকর্ড তৈরি করতে][create], `{` আর `}` অক্ষরের মধ্যে ফিল্ডগুলোর নাম উল্লেখ করুন এবং সেগুলোতে একটি মান অ্যাসাইন করুন। রেকর্ড তৈরির সময় এর সব ফিল্ডেই একটি মান অ্যাসাইন করতে হবে। ফিল্ডগুলো যেকোনো ক্রমে উল্লেখ করা যায়; রেকর্ড টাইপ ডেফিনিশনের ক্রমের সাথে মিল থাকা জরুরি নয়। একটি রেকর্ড ইনস্ট্যান্সের ফিল্ডের মান পেতে ডট নোটেশন ব্যবহার করা হয়।

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

রেকর্ড ডিফাইন বা তৈরি করার সময় প্রতিটি ফিল্ড হয় আলাদা লাইনে থাকতে হবে, নয়তো একই লাইনে থাকলে সেমিকোলন (`;`) দিয়ে আলাদা করতে হবে:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

একটি রেকর্ডের ফিল্ডের নামগুলো যদি অনন্য হয়, তবে টাইপ অ্যানোটেশন না দিলেও চলে, কারণ কম্পাইলার নিজে থেকেই টাইপটি অনুমান করতে পারবে। ফিল্ডের নামগুলোর সমন্বয় যদি _অনন্য না_ হয়, তাহলে রেকর্ড বাইন্ডিংয়ে স্পষ্টভাবে একটি টাইপ উল্লেখ করে, অথবা এক বা একাধিক ফিল্ডের সামনে রেকর্ড টাইপ বসিয়ে আপনি কম্পাইলারকে সঠিক রেকর্ড বেছে নিতে সাহায্য করতে পারেন:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

যেহেতু রেকর্ড অপরিবর্তনীয়, তাই একবার একটি রেকর্ড তৈরি হয়ে গেলে তার ফিল্ডের মান আর কখনোই বদলাতে পারে না। আপনি যদি একটি রেকর্ডের মান বদলাতে চান, তাহলে `with` কিওয়ার্ডের সাহায্যে [বিদ্যমান রেকর্ডের একটি কপি তৈরি করতে পারেন, তবে এক বা একাধিক ফিল্ডের নতুন মানসহ][create]।

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

রেকর্ডে [_স্ট্রাকচারাল ইকুয়ালিটি_][equality] থাকে, অর্থাৎ একই রেকর্ডের দুটি ইনস্ট্যান্সের মান যদি হুবহু এক হয়, তবে সেগুলো সমতুল্য:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

ডট নোটেশন দিয়ে রেকর্ডের ফিল্ডে ঢোকা ছাড়াও, [রেকর্ড প্যাটার্ন][record-patterns] ব্যবহার করে বাইন্ডিং ও প্যাটার্ন ম্যাচিংয়ের মধ্যে রেকর্ডকে _ডিকনস্ট্রাক্ট_ করা যায়:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
