# পরিচিতি

## মূল বিষয়গুলো

### ভ্যারিয়েবল

Elixir একটি ডাইনামিকালি-টাইপড ভাষা, অর্থাৎ কোনো ভ্যারিয়েবলের টাইপ কেবল রানটাইমেই যাচাই করা হয়। ম্যাচ `=` অপারেটরের সাহায্যে আমরা যেকোনো টাইপের একটি মান একটি ভ্যারিয়েবলের নামের সাথে বেঁধে দিতে পারি:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### মডিউল

Elixir একটি [ফাংশনাল প্রোগ্রামিং ভাষা][functional-programming] এবং এতে সব নামযুক্ত ফাংশন একটি _মডিউলে_ ডিফাইন করা আবশ্যক। মডিউল ডিফাইন করতে `defmodule` কিওয়ার্ডটি ব্যবহার করা হয়। সব মডিউল রানটাইমে অন্য সব মডিউলের কাছে পাওয়া যায় এবং প্রোগ্রামের অন্য অংশের কাছে সেগুলো দৃশ্যমান করতে কোনো _অ্যাক্সেস মডিফায়ার_-এর দরকার হয় না। একটি _মডিউল_ অন্য প্রোগ্রামিং ভাষার _ক্লাস_-এর সমতুল্য।

```elixir
defmodule Calculator do
  # ...
end
```

### নামযুক্ত ফাংশন

_নামযুক্ত ফাংশন_ অবশ্যই একটি মডিউলে ডিফাইন করতে হয়। একটি _পাবলিক_ নামযুক্ত ফাংশন ডিফাইন করতে `def` কিওয়ার্ডটি ব্যবহার করা হয়।

প্রতিটি ফাংশনে শূন্য বা তার বেশি আর্গুমেন্ট থাকতে পারে। কোনো ফাংশনের শেষ এক্সপ্রেশনের মান সবসময় _অন্তর্নিহিতভাবে রিটার্ন হয়_।

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

কোনো ফাংশন কল করতে হলে তার মডিউল ও ফাংশনের নাম লিখে ফাংশনের প্রতিটি আর্গুমেন্টের জন্য মান পাস করতে হয়।

```elixir
sum = Calculator.add(1, 2)
# => 3
```

একটি _প্রাইভেট_ ফাংশন ডিফাইন করতে `def`-এর বদলে `defp` কিওয়ার্ডটি ব্যবহার করা যায়। প্রাইভেট ফাংশন কেবল যে মডিউল সেটি ডিফাইন করেছে, তার ভেতর থেকেই ব্যবহার করা যায়।

যে মডিউলে কোনো ফাংশন ডিফাইন করা হয়েছে, সেই মডিউলের ভেতর থেকে সেটি কল করার সময় মডিউলের নাম বাদ দেওয়া যায়।

এক লাইনের সিনট্যাক্স ব্যবহার করে ছোট ফাংশনও লিখতে পারেন (লক্ষ্য করুন `do` কিওয়ার্ডের চারপাশে কমা `,` আর কোলন `:`)।

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### ফাংশনের অ্যারিটি

ফাংশনকে তার _অ্যারিটি_ দিয়ে উল্লেখ করা বেশ সাধারণ ব্যাপার। একটি ফাংশনের _অ্যারিটি_ হলো সে কতগুলো আর্গুমেন্ট নেয় তার সংখ্যা।

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### নামকরণের রীতি

মডিউলের নামে `PascalCase` ব্যবহার করা উচিত। মডিউলের নাম অবশ্যই একটি বড় হাতের অক্ষর `A-Z` দিয়ে শুরু হতে হবে এবং এতে অক্ষর `a-zA-Z`, সংখ্যা `0-9` আর আন্ডারস্কোর `_` থাকতে পারে।

ভ্যারিয়েবল ও ফাংশনের নামে `snake_case` ব্যবহার করা উচিত। ভ্যারিয়েবল বা ফাংশনের নাম অবশ্যই ছোট হাতের অক্ষর `a-z` বা একটি আন্ডারস্কোর `_` দিয়ে শুরু হতে হবে, এতে অক্ষর `a-zA-Z`, সংখ্যা `0-9` ও আন্ডারস্কোর `_` থাকতে পারে এবং শেষে একটি জিজ্ঞাসাচিহ্ন `?` বা বিস্ময়চিহ্ন `!` থাকতে পারে।

### স্ট্যান্ডার্ড লাইব্রেরি

Elixir-এর স্ট্যান্ডার্ড লাইব্রেরি অনেক সমৃদ্ধ ও সুন্দরভাবে ডকুমেন্টেড। ডকুমেন্টেশন অনলাইনে [hexdocs.pm/elixir][docs] ঠিকানায় পাওয়া যায়। এই লিঙ্কটি কোথাও সেভ করে রাখুন, এটি আপনার অনেক কাজে আসবে!

বেশিরভাগ বিল্ট-ইন ডেটা টাইপের জন্যই একটি সংশ্লিষ্ট মডিউল আছে, যেখানে সেই ডেটা টাইপ নিয়ে কাজ করার ফাংশন থাকে। যেমন ইন্টিজারের জন্য `Integer` মডিউল, স্ট্রিংয়ের জন্য `String` মডিউল, অ্যারের জন্য `List` মডিউল ইত্যাদি।

উল্লেখযোগ্য একটি মডিউল হলো `Kernel` মডিউল। এটি সেই মৌলিক সক্ষমতাগুলো দেয় যার ওপর ভিত্তি করে স্ট্যান্ডার্ড লাইব্রেরির বাকি অংশ তৈরি, যেমন গাণিতিক অপারেটর, কন্ট্রোল-ফ্লো ম্যাক্রো আরও অনেক কিছু। `Kernel` মডিউলের ফাংশনগুলো স্বয়ংক্রিয়ভাবে ইমপোর্ট হয়, তাই `Kernel.` প্রিফিক্স ছাড়াই সেগুলো ব্যবহার করতে পারেন।

### কোড কমেন্ট

সোর্স কোড পড়বে এমন অন্য ডেভেলপারদের জন্য নোট রেখে যেতে কমেন্ট ব্যবহার করা যায়। Elixir-এ এক লাইনের কমেন্টের আগে `#` বসে।
