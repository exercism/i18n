# সম্পর্কে

Gleam-এ একটি `case` এক্সপ্রেশন দিয়ে শর্তসাপেক্ষে কোড চালানো যায়। কেস এক্সপ্রেশনে একটি মানকে এক বা একাধিক _প্যাটার্ন_-এর সাথে মিলিয়ে দেখা যায়। এমন একটি প্যাটার্নের উদাহরণ হলো _লিটারেল প্যাটার্ন_, যা একটি মানকে একটি লিটারেল মানের (যেমন `1` বা `"hello"`) সাথে মিলিয়ে দেখে।

কেস এক্সপ্রেশন লেখা হয় `case` কিওয়ার্ড দিয়ে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

এটি অন্য ভাষার `switch` স্টেটমেন্টের মতো দেখালেও, অন্য প্যাটার্নও ব্যবহার করা হলে প্যাটার্ন ম্যাচিংয়ের আসল সুবিধা বোঝা যায়। এমন একটি প্যাটার্ন হলো _ভ্যারিয়েবল প্যাটার্ন_, যা দিয়ে একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করা যায়। এই উদাহরণে, `number` যদি `0` না হয়, তবে ভ্যারিয়েবল `i`-তে `number`-এর মান অ্যাসাইন করা হবে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

কিছু ক্ষেত্রে আপনি একটি প্যাটার্নে একটি অতিরিক্ত শর্ত যোগ করতে চাইতে পারেন। এটিকে _গার্ড_ (ক্লজ) বলা হয়, যা `if` কিওয়ার্ড দিয়ে যোগ করা যায়:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

পারফরম্যান্সের কারণেগার্ডে শুধু মৌলিক গাণিতিক ও বুলিয়ান অপারেটর ব্যবহারের অনুমতি আছে, গার্ডে অন্য কোনো ফাংশন ব্যবহার করা যায় না।

উপরের উদাহরণে সব সম্ভাব্য ইনপুটের জন্যই মিলে যাওয়া প্যাটার্ন নেই। কম্পাইলার এটি ধরতে পারবে এবং একটি এরর দেখাবে। এটিকে _এক্সহসটিভ চেকিং_ বলা হয়। ওয়ার্নিংটি সমাধান করতে সব ক্ষেত্রই সামলাতে হবে। এর জন্য _ডিসকার্ড প্যাটার্ন_ ব্যবহার করা যায়, যা যেকোনো মানের সাথে মিলে যায়:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

কেস এক্সপ্রেশন একটি মানকে উপর থেকে নিচে প্রতিটি প্যাটার্নের সাথে মিলিয়ে দেখবে, যতক্ষণ না মিলে যাওয়া একটি প্যাটার্ন খুঁজে পায় এবং সেই প্যাটার্নের সাথে সম্পর্কিত লজিক চালায়। প্যাটার্নের ক্রম গুরুত্বপূর্ণ!
