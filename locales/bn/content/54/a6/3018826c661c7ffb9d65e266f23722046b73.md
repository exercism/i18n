# Bash শেলে পাটিগণিতের পরিচিতি

Bash পাটিগণিত করতে পারে, তবে _শুধু ইন্টিজার নিয়ে_।
আপনার যদি ফ্লোট-পয়েন্ট গণিত করার প্রয়োজন হয়, তাহলে ([awk][awk] বা [bc][bc]-এর মতো) কোনো বাহ্যিক প্রোগ্রাম ডাকতে হবে।

পাটিগণিতের অপারেটরগুলো ম্যানুয়ালে (প্রাধান্যের ক্রম অনুসারে) তালিকাভুক্ত আছে: [শেল পাটিগণিত][arithmetic]।

এছাড়া, Bash কেবল নির্দিষ্ট কিছু জায়গায়ই পাটিগণিত করে (যেগুলোকে পাটিগণিতের "কনটেক্সট" বলা হয়)।

## পাটিগণিতের প্রসারণ

পাটিগণিতের প্রসারণ দেখতে [কমান্ড সাবস্টিটিউশনের][cmd-sub] মতো, তবে এখানে ডাবল বন্ধনী ব্যবহার হয়।

```bash
$(( expression ))
```

এই সিনট্যাক্সটি এক্সপ্রেশনটি মূল্যায়ন করার ফলাফলে প্রসারিত হয়।
ফলাফলটি একটি ভ্যারিয়েবলে ধরে রাখতে এটি সাধারণত ব্যবহৃত হয়:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
বন্ধনীর ভেতরে কতটুকু হোয়াইটস্পেস থাকবে তা আপনার ইচ্ছা।
এটি স্টাইল আর পড়ার সুবিধার ব্যাপার।

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

আপনার বন্ধুত্বপূর্ণ লেখক স্পেস যোগ করতে ভালোবাসেন, যাতে বন্ধনীর ভেতরে পাটিগণিতের এক্সপ্রেশনটি আরও স্পষ্ট দেখা যায়।
~~~~

## পাটিগণিত শর্ত

পাটিগণিত শর্তটি ডাবল বন্ধনীর ভেতরে, শুরুতে `$` _ছাড়াই_ সম্পন্ন হয়:

```bash
(( expression ))
```

এটি ফলাফলে প্রসারিত হয় না।
তবে এটি একটি _এক্সিট স্টেটাস_ তৈরি করে।

* এক্সপ্রেশনের ফলাফল **অ-শূন্য** হলে এক্সিট স্টেটাস 0 (সফলতা) হয়।
* এক্সপ্রেশনের ফলাফল **শূন্য** হলে এক্সিট স্টেটাস 1 (ব্যর্থতা) হয়।

~~~~exercism/note
`((`-এর ভেতরে Bash C ভাষার মতোই একই ট্রু/ফলস অর্থ ব্যবহার করে: শূন্য মানে ফলস, অ-শূন্য মানে ট্রু।
**কিন্তু Bash এক্সিট স্টেটাস মূল্যায়ন করে ঠিক তার উল্টোভাবে!**
~~~~

এই সিনট্যাক্সটি সাধারণত দুটি জায়গায় ব্যবহৃত হয়:

1. একটি [`if` স্টেটমেন্টের][conditional-if] বা একটি [`while` লুপের][looping-while] COMMAND অংশ হিসেবে।

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. একটি ভ্যারিয়েবলের মান পরিবর্তন করার জন্য স্বতন্ত্র কমান্ড হিসেবে।

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   `set -e`-এর সাথে মিলিয়ে এভাবে পাটিগণিত ব্যবহার করার সময় সাবধান থাকুন।
   এক্সপ্রেশনটির মূল্যায়নে শূন্য এলে এক্সিট স্টেটাস অ-শূন্য হবে এবং Bash বন্ধ হয়ে যাবে।

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   `++` অপারেটর নিয়ে আরও বিস্তারিত আলোচনার জন্য [পোস্টইনক্রিমেন্ট বনাম প্রিইনক্রিমেন্ট][incr] আর্টিকেলটি দেখুন

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## পাটিগণিতের কনটেক্সট থাকা আরও কিছু জায়গা

আরও কয়েকটি জায়গা আছে যেগুলো পাটিগণিতের কনটেক্সট:

* [পাটিগণিত for লুপ][looping-for]।

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* সাংখ্যিকভাবে ইনডেক্স করা অ্যারের ইনডেক্স অংশ।

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  অ্যারে নিয়ে আরও জানতে [অ্যারে][arrays] কনসেপ্ট ডকুমেন্টটি পড়ুন।

* `${var:offset:length}` প্রসারণের অফসেট ও লেংথ অংশ।
* [`let` বিল্ট-ইন কমান্ড][let]।
  * মনে রাখবেন, `let "expresson"`-এর চেয়ে `(( expression ))` বেশি পছন্দনীয়।
    পাটিগণিত শর্তের গঠনের বিপরীতে, `let` এক্সপ্রেশন ফাইলনেম-এক্সপ্যানশন আর ওয়ার্ড-স্প্লিটিংয়ের অধীন, এবং এতে কোটিং করা আবশ্যক।
* ভ্যারিয়েবল অ্যাসাইনমেন্ট, যখন ভ্যারিয়েবলটির "ইন্টিজার অ্যাট্রিবিউট" থাকে।

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  লেখকের মতানুযায়ী `declare -i`-এর ব্যবহার সীমিত।
  এর মূল সুবিধা হলো "বেয়ার" পাটিগণিত (পাটিগণিত এক্সপ্রেশনের সিনট্যাক্স ছাড়া) করার সুযোগ দেওয়া।
  এতে আপনার কোডের পাঠকেরা বিভ্রান্ত হতে পারেন, কারণ এতে অপ্রত্যাশিত জায়গায় পাটিগণিত এক্সপ্রেশন মূল্যায়িত হয়।
  ~~~~

## পাটিগণিত এক্সপ্রেশনে ভ্যারিয়েবল ব্যবহার

পাটিগণিতের কনটেক্সটের এমন একটি দিক এখানে আছে যা পড়ার সুবিধা বাড়ায়।

```bash
height=10
width=20
area=$(( height * width ))
```

লক্ষ্য করেছেন কি, পাটিগণিত এক্সপ্রেশনের ভ্যারিয়েবলগুলোতে `$` ডলার চিহ্ন নেই?
Bash আপনাকে এটা করার সুযোগ দেয়।
এতে এক্সপ্রেশন পড়া অনেক সহজ হয়।

ম্যানুয়ালে বলা হয়েছে,

> একটি এক্সপ্রেশনের ভেতরে শেল ভ্যারিয়েবলগুলো প্যারামিটার এক্সপ্যানশন সিনট্যাক্স ব্যবহার না করেও নাম দিয়ে উল্লেখ করা যায়।

এটি অ্যারের এলিমেন্টের ক্ষেত্রেও কাজ করে:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

কিন্তু অন্য প্যারামিটার এক্সপ্রেশনগুলোকে তাদের বিশেষ সিনট্যাক্স ব্যবহার করতে হয়।
যেমন, একটি স্ট্রিংয়ের দৈর্ঘ্য দ্বিগুণ করা:

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

আর পজিশনাল প্যারামিটারগুলোও তাই করতে হয়।
যদি প্রথম দুটি পজিশনাল প্যারামিটার প্রস্থ আর উচ্চতা বোঝায়:

```bash
area=$(( $1 * $2 ))
```
