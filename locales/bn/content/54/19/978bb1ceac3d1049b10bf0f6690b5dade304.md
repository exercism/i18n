# নির্দেশনার সংযোজন

## ওয়ার্ড

`smallest` আর `largest` প্রত্যেকটি **দুটি** স্ট্যাক মান রিটার্ন করে: প্যালিনড্রোম মান (বা রেঞ্জে কোনোটি না থাকলে `f`) এবং গুণনীয়ক জোড়ার একটি অ্যারে।

- `smallest ( mn mx -- value factors )`
- `largest  ( mn mx -- value factors )`

`factors`-এর প্রতিটি জোড়া একটি ২-এলিমেন্টের অ্যারে `{ a b }`. `mn > mx` হলে `"min must be <= max"` স্ট্রিংটি থ্রো করুন।
