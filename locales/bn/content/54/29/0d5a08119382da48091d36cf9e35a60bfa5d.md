# পরিচিতি

## তুলনা অপারেটর

তুলনা অপারেটরগুলো অন্য অনেক ভাষার মতোই।

সমানতা যাচাইয়ের জন্য অপারেটর দুটি হলো `==` (সমান) এবং `!=` (সমান নয়)।

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

বড়/ছোট অপারেটরগুলোও প্রচলিত।

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if` দিয়ে শাখা তৈরি

এটি একটি `if` এক্সপ্রেশনের পূর্ণ রূপ:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- প্রতিটি শর্তের চারপাশে বন্ধনী `()` দিতে হবে।
- একটি শর্তের ফলাফল অবশ্যই বুলিয়ান `true` বা `false` হতে হবে।
  কিছু ভাষায় যেমন "truthy" আর "falsy" থাকে, Kotlin-এ তেমন কোনো ধারণাই নেই।
- যদি কেবল একটি এক্সপ্রেশন থাকে, তবে দ্বিতীয় বন্ধনী `{}` ঐচ্ছিক।
- `else if` আর `else` দুটোই ঐচ্ছিক, এবং একাধিক `else if` ব্লক থাকতে পারে।

`if` এক্সপ্রেশন দিয়ে একটি মান "বেছে নেওয়াও" যায়:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## বিকল্প?

সচেতন সিদ্ধান্তে, Java-তে থাকা টারনারি অপারেটর `? :` Kotlin-এ _নেই_।
এর বদলে `if ... else`-এর সংক্ষিপ্ত রূপকেই প্রাধান্য দেওয়া হয়:

```Kotlin
return if (isOK) goodValue else badValue
```
