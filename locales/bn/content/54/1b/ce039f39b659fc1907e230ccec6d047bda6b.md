# পরিচিতি

ফ্লোট হলো এমন সংখ্যা যার দশমিক বিভাজকের পরে এক বা একাধিক অঙ্ক থাকে।

```gleam
let float = 3.45
// -> 3.45
```

ফ্লোটেরও নিজস্ব কিছু অপারেটর রয়েছে।

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

স্পষ্টতার জন্য ফ্লোটে আন্ডারস্কোরও যোগ করা যায়।

```gleam
1_000_000.0 // One million
```

ফ্লোটের সাথে বৈজ্ঞানিক নোটেশনও ব্যবহার করা যায়:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
