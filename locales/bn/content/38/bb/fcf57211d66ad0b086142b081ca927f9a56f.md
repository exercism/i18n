# পরিচিতি

## মেথড ওভারলোডিং

Java-তে মেথড ওভারলোডিং এমন একটি ফিচার, যা একটি ক্লাসকে একই নামের একাধিক মেথড রাখার সুযোগ দেয়, যদি তাদের
প্যারামিটার তালিকা আলাদা হয়।
এটি কম্পাইল-টাইম (বা স্ট্যাটিক) পলিমরফিজমের সাথে সম্পর্কিত।
একই ধরনের কাজ করে কিন্তু ইনপুট আলাদা, এমন মেথড তৈরি করার জন্য এই কনসেপ্টটি খুবই গুরুত্বপূর্ণ।

### কেন মেথড ওভারলোড করবেন?

মেথড ওভারলোডিং প্রোগ্রামের পাঠযোগ্যতা বাড়ায়।
আলাদা আলাদা মেথডকে একই নাম দেওয়া যায়, তবে
প্যারামিটার আলাদা হবে।
প্যারামিটারের সংখ্যা বা প্যারামিটারের টাইপের ওপর নির্ভর করে সংশ্লিষ্ট মেথডটি কল করা হয়।

### কীভাবে মেথড ওভারলোড করবেন?

মেথড ওভারলোডিংয়ের মূল চাবিকাঠি হলো মেথডের সিগনেচার।
দুটি মেথডের সিগনেচার আলাদা হলে তাদের আলাদা বলে ধরা হবে।
একটি মেথড ওভারলোড করার দুইটি উপায় আছে:

১. **প্যারামিটারের সংখ্যা ভিন্ন**: মেথডের নাম একই হতে পারে, কিন্তু প্যারামিটারের সংখ্যা আলাদা।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

২. **প্যারামিটারের টাইপ ভিন্ন**: মেথডের নাম ও প্যারামিটারের সংখ্যা একই হতে পারে, কিন্তু
   টাইপ আলাদা।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### মনে রাখার মতো বিষয়

- ওভারলোড করা মেথডে অবশ্যই আর্গুমেন্ট তালিকা বদলাতে হবে।
- ওভারলোড করা মেথড রিটার্ন টাইপও বদলাতে পারে, তবে শুধু রিটার্ন টাইপ বদলালেই সেটি মেথড
  ওভারলোডিং হয় না।
- একই ক্লাসে বা একটি সাবক্লাসে মেথড ওভারলোড করা যায়।

এই কনসেপ্টে আমরা Java-তে মেথড ওভারলোডিংয়ের নানা উদাহরণ ও সূক্ষ্ম দিক দেখব।
