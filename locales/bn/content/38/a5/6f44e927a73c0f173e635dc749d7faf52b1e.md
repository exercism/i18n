# পরিচিতি

## এরর

কোনো প্রোগ্রাম বা কোডের অংশে ভুল বা অপ্রত্যাশিত কিছু ঘটলে তা জানানোর জন্য এরর কাজে লাগে।

এগুলো JavaScript অবজেক্ট।

এই অবজেক্টের প্রধান প্রপার্টি হলো `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw` সিনট্যাক্স ব্যবহার করে আপনি একটি এরর থ্রো করতে পারেন।

```javascript
throw new Error('Oops');
```

কোনো এরর থ্রো করা হলে বর্তমান এক্সিকিউশন থেমে যায় এবং কল স্ট্যাকের প্রথম ক্যাচ ব্লকে আবার শুরু হয়।

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## ইনহেরিটেন্স

ইনহেরিটেন্স হলো ক্লাসগুলোর মধ্যে প্যারেন্ট-চাইল্ড সম্পর্ক তৈরি করার একটি উপায়।
চাইল্ড ক্লাসের (যাকে কখনও কখনও _সাবক্লাস_ বলা হয়) কাছে প্যারেন্ট ক্লাস (যাকে কখনও কখনও _সুপারক্লাস_ বলা হয়) দ্বারা ডিফাইন করা আচরণ ও ডেটাতে অ্যাক্সেস থাকে।

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

চাইল্ড ক্লাসের ডিক্লারেশনে `extends` কিওয়ার্ডটি [প্রোটোটাইপ চেইন][prototype-chain]-এর মাধ্যমে প্যারেন্ট ক্লাসের সাথে একটি সম্পর্ক স্থাপন করে।

চাইল্ডের কনস্ট্রাক্টর দিয়ে তৈরি অবজেক্টগুলোর নিজেদের প্রোটোটাইপ চেইনে প্যারেন্ট ক্লাসের প্রোটোটাইপ থাকবে, যা প্যারেন্ট দ্বারা ডিফাইন করা যেকোনো মেথড বা ডেটাতে অ্যাক্সেস দেয়।

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

JavaScript-এর যেকোনো ক্লাসের মতোই, `extends` কিওয়ার্ড ব্যবহার করে সাবক্লাসগুলো কাস্টম এরর তৈরি করতে `Error` থেকে ইনহেরিট করতে পারে।
`instanceof` সিনট্যাক্স চেক করবে যে ধরা পড়া এররটি `Error`-এর কোনো নির্দিষ্ট সাবক্লাসের ইনস্ট্যান্স কি না।

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
