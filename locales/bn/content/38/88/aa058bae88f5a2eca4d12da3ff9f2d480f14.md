# পরিচিতি

Swift-এ সত্য-মিথ্যার মান, অর্থাৎ `true` এবং `false`, প্রকাশের জন্য [`Bool`][bools] নামের একটি বিল্ট-ইন টাইপ আছে।

## লজিক্যাল অপারেটর

বুলিয়ান এক্সপ্রেশন একত্র করতে ও মূল্যায়ন করতে Swift তিনটি [লজিক্যাল অপারেটর][logical-operators] (`!`, `&&` এবং `||`) দেয়।

### লজিক্যাল অ্যান্ড (`&&`)

[_অ্যান্ড_ অপারেটর][and] (`&&`) কেবল তখনই `true` রিটার্ন করে, যখন দুটি অপারেন্ডই `true` হয়।
কোনো একটি অপারেন্ড `false` হলে এটি `false` রিটার্ন করে।
`&&` চিহ্নের দুই পাশে একটি এক্সপ্রেশন বা বুলিয়ান মান বসান:

```swift
true && true  // true
true && false // false
```

### লজিক্যাল অর (`||`)

[_অর_ অপারেটর][or] (`||`) `true` রিটার্ন করে, যদি অপারেন্ডগুলোর **অন্তত একটি** `true` হয়।
এটি কেবল তখনই `false` রিটার্ন করে, যখন দুটি অপারেন্ডই `false` হয়।
`||` চিহ্নের দুই পাশে একটি এক্সপ্রেশন বা বুলিয়ান মান বসান:

```swift
true || true   // true
true || false  // true
false || false // false
```

### লজিক্যাল নট (`!`)

[_নট_ অপারেটর][not] (`!`) একটি বুলিয়ান মান উল্টে দেয়।
মানটি `false` হলে এটি `true` রিটার্ন করে, আর মানটি `true` হলে `false`।
`!` অপারেটরটি মান বা এক্সপ্রেশনের ঠিক আগে বসান:

```swift
!true  // false
!false // true
```

## বন্ধনী (`()`) ব্যবহার

আপনি [বন্ধনী][explicit-parentheses] দিয়ে এক্সপ্রেশন গ্রুপ করতে এবং মূল্যায়নের ক্রম নিয়ন্ত্রণ করতে পারেন।
Swift-এ বন্ধনীর ভেতরের এক্সপ্রেশনগুলো আগে মূল্যায়িত হয়:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

বন্ধনী দিয়ে গ্রুপ করা এটাও ঠিক করে যে জটিল এক্সপ্রেশনে নট অপারেটর কীভাবে প্রযোজ্য হবে:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

মূল্যায়নের ক্রম স্পষ্ট করার প্রয়োজন হলে, বা জটিল শর্ত পড়া সহজ করতে চাইলে বন্ধনী ব্যবহার করুন।
