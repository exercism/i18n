# পরিচিতি

[`Vectors`][vectors] কনসেপ্টে আমরা বলেছিলাম যে "অ্যারেগুলো Julia ভাষার কেন্দ্রবিন্দু" এবং একটি ভেক্টর হলো এক-মাত্রিক অ্যারে।

এটা মাথায় রেখে আমরা যুক্তিসঙ্গতভাবেই আশা করতে পারি যে ভাষাটি ভেক্টর নিয়ে _কাজ করার_ অনেক বহুমুখী ও শক্তিশালী উপায় দেবে, এর মানে যা-ই হোক।

## ভেক্টর ইনপুট প্রত্যাশা করে এমন ফাংশন

কিছু খুব সাধারণ ফাংশন একটি ভেক্টর ইনপুট নেয় এবং একটি স্কেলার আউটপুট রিটার্ন করে।

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## পাটিগণিত

ধরুন আপনার কাছে একটি সাংখ্যিক ভেক্টর আছে এবং আপনি প্রতিটি মান থেকে 0.5 বিয়োগ করতে চান।

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

এটা ব্যর্থ হয়, তাহলে আরেকটি ভেক্টর বিয়োগ করলে কেমন হয়?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

সফল, কিন্তু ভেক্টর লম্বা হতে থাকলে এটি বেশ ঝামেলার ও প্রচুর মেমরি খরচ করে।

সৌভাগ্যক্রমে, Julia-তে এই সমস্যাটি খুব সহজে সমাধান করার জন্য একটি "জাদু" ডট আছে: আপনার যা দরকার তা হলো শুধু `v .- 0.5`।

পরের অংশে ব্যাখ্যা করা হয়েছে কেন।

## ব্রডকাস্টিং

তাহলে, `v - 0.5` ব্যর্থ হয় কিন্তু `v .- 0.5` সফল হয়, এবং ডটটি কী করছে সেটা আমাদের বুঝতে হবে।

দুটি কাজ, যা একসাথে মিলে কাঙ্ক্ষিত ফলাফল দেয়।

### ১. এলিমেন্টভিত্তিক প্রয়োগ

প্রথমত, যেকোনো ইনফিক্স অপারেটরের _আগে_ একটি ডট যোগ করার মানে হলো "এই ক্রিয়াটি প্রতিটি এলিমেন্টে আলাদাভাবে প্রয়োগ করুন"।

একইভাবে, একটি ফাংশনের নামের _পরে_ ডট যোগ করলে সেটি "ভেক্টরাইজ" হয়, এমনকি ফাংশনটি যদি স্কেলার ইনপুটের জন্য লেখা হয়েও থাকে।

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### ২. সিঙ্গলটন সম্প্রসারণ

আগের একটি উদাহরণে আমরা দেখেছি যে সমান দৈর্ঘ্যের ভেক্টর বিয়োগ করা যায়, তবে অনুগ্রহ করে বুঝুন যে `.-` অপারেটরটি এলিমেন্টভিত্তিক উদ্দেশ্য স্পষ্ট করে দেওয়ায় `-` এর চেয়ে _নিরাপদ_।

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

অসমান দৈর্ঘ্যের ভেক্টরের ক্ষেত্রে কী হবে?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

সাধারণভাবে, অসমান দৈর্ঘ্য একটি এরর, _তবে_ যখন একটির দৈর্ঘ্য 1 হয় তখন নয় (প্রযুক্তিগতভাবে, একটি "সিঙ্গলটন" ডাইমেনশন)।

`[0.5,]` এর মতো সিঙ্গলটন বা শুধু `0.5` পুনরাবৃত্তির মাধ্যমে স্বয়ংক্রিয়ভাবে প্রয়োজনীয় দৈর্ঘ্যে সম্প্রসারিত হয়।
এটাই `broadcasting` এর কেন্দ্রবিন্দু।

### ইন-প্লেস ব্রডকাস্টিং

যদি মেমরি ব্যবহার নিয়ে চিন্তা থাকে, তাহলে ইন-প্লেস অপারেশন হলো অ্যালোকেশন কমানোর একটি প্রচলিত উপায়।

তবে, উপরের উদাহরণগুলোর ব্রডকাস্টিং অপারেশনগুলো মূল ভেক্টর পরিবর্তন না করে একটি নতুন `Vector` তৈরি করে।

মূল `Vector` ইন-প্লেস পরিবর্তন করতে হলে, পরিবর্তনটিকে ব্রডকাস্ট করতে হবে।

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## ইনডেক্সিং

ইনডেক্স নম্বর দিয়ে একটি ভেক্টরের এলিমেন্ট নির্বাচন নিয়ে আগের কনসেপ্টগুলোতে আলোচনা করা হয়েছে।

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### লজিক্যাল ইনডেক্সিং

কোনো লজিক্যাল এক্সপ্রেশন (প্রযুক্তিগতভাবে, একটি "প্রেডিকেট") পূরণ করে এমন এলিমেন্টও নির্বাচন করা সম্ভব।
এর জন্য সাধারণত ব্রডকাস্টিং দরকার হয়।

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

আরও জটিল এক্সপ্রেশনের ক্ষেত্রে ডটগুলো বেড়ে যায় (কিন্তু এগুলো ছোট এবং টাইপ করা সহজ)।

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

একটি স্মারক: "ভেক্টর" আসলে যেকোনো উপযুক্ত ক্রমানুসারী ইটারেবল হতে পারে, যেমন একটি রেঞ্জ:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
