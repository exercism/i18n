# নির্দেশাবলী

লুসিয়ানের প্রেমিকা বাড়ির পথে, অথচ তিনি এখনো তাদের বিবাহবার্ষিকীর রাতের খাবার রান্না করেননি!

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা লুসিয়ানকে তার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করবে।

লাসাগনা রান্নায় কত সময় লাগে, তা নিয়ে আপনার সামনে চারটি কাজ রয়েছে।

## 1. মিনিটে ওভেনে রাখার প্রত্যাশিত সময় নির্ধারণ করুন

`EXPECTED_MINUTES_IN_OVEN` কনস্ট্যান্টটি ডিফাইন করুন, যা নির্দেশ করে লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত। এটি এক্সপোর্ট করা আবশ্যক। রান্নার বই অনুযায়ী, মিনিটে ওভেনে রাখার প্রত্যাশিত সময় হলো `40`।

## 2. ওভেনে বাকি সময় মিনিটে হিসাব করুন

`remainingMinutesInOven` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি _প্যারামিটার_ হিসেবে নেয় লাসাগনাটি এখন পর্যন্ত কত মিনিট ওভেনে রয়েছে, আর আগের কাজের **মিনিটে ওভেনে রাখার প্রত্যাশিত সময়** অনুযায়ী _রিটার্ন_ করে লাসাগনাটিকে আরও কত মিনিট ওভেনে থাকতে হবে।

```javascript
remainingMinutesInOven(30)
// => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTimeInMinutes` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি _প্যারামিটার_ হিসেবে নেয় আপনি লাসাগনায় কতগুলো স্তর যোগ করেছেন, আর ধরে নেয় যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে, তারপর _রিটার্ন_ করে লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে।

```javascript
preparationTimeInMinutes(2)
// => 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`totalTimeInMinutes` ফাংশনটি ইমপ্লিমেন্ট করুন, যা _দুটি প্যারামিটার_ নেয়: `numberOfLayers` প্যারামিটারটি হলো আপনি লাসাগনায় যোগ করা স্তরের সংখ্যা, আর `actualMinutesInOven` প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে রয়েছে সেই সংখ্যা। ফাংশনটি _রিটার্ন_ করবে লাসাগনা রান্নার পেছনে আপনার মোট কত মিনিট খরচ হয়েছে, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```javascript
totalTimeInMinutes(3, 20)
// => 26
```
