# পরিচিতি

Elixir কোডে _বিহেভিয়ার_ ব্যবহার করে কমন ও জেনেরিক ইন্টারফেস তৈরি করে, আর যে মডিউল সেটি ইমপ্লিমেন্ট করে তার জন্য নির্দিষ্ট ইমপ্লিমেন্টেশন লেখাও সহজ করে দেয়। এমন একটি কমন উদাহরণ হলো _অ্যাক্সেস বিহেভিয়ার_।

_অ্যাক্সেস বিহেভিয়ার_ কী (key)-ভিত্তিক ডেটা স্ট্রাকচার থেকে ডেটা বের করার জন্য একটি কমন ইন্টারফেস দেয়। _অ্যাক্সেস বিহেভিয়ার_ ম্যাপ ও কিওয়ার্ড লিস্টের জন্য ইমপ্লিমেন্ট করা আছে, তবে চলুন ম্যাপের ক্ষেত্রে এর ব্যবহারটা দেখি, যাতে ব্যাপারটা বোঝা যায়। _অ্যাক্সেস বিহেভিয়ার_ বলে দেয় যে, কোনো ম্যাপ থাকলে আপনি তার পরে _তৃতীয় বন্ধনী_ বসিয়ে ভেতরে কী (key) লিখে সেই কী (key)-এর সাথে যুক্ত মানটি বের করতে পারেন।

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

ডেটা স্ট্রাকচারে কী (key) না থাকলে `nil` রিটার্ন হয়। এটি অনাকাঙ্ক্ষিত আচরণের জন্ম দিতে পারে, কারণ তখন কোনো এরর রেইজ হয় না। লক্ষ্য করুন, `nil` নিজেও অ্যাক্সেস বিহেভিয়ার ইমপ্লিমেন্ট করে এবং যেকোনো কী (key)-এর জন্যই সবসময় `nil` রিটার্ন করে।
