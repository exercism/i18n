# সংখ্যার টাইপ

Crystal-এ নানা কাজের জন্য বিভিন্ন রকমের সংখ্যার টাইপ রয়েছে।
উদাহরণস্বরূপ, কিছু টাইপ দ্রুততর, কিন্তু সম্ভাব্য মানের পরিসর অন্য টাইপগুলোর চেয়ে ছোট।
আবার কিছু টাইপের সম্ভাব্য মানের পরিসর অনেক বড়, কিন্তু সেগুলো ধীরগতির।

Crystal-এ সাইনড এবং আনসাইনড, দুধরনের ইন্টিজার টাইপই আছে।
সাইনড ইন্টিজার টাইপ ধনাত্মক বা ঋণাত্মক হতে পারে।
আনসাইনড ইন্টিজার টাইপ কেবল ধনাত্মক হতে পারে।

## সাইনড ইন্টিজার টাইপ

Crystal-এ এগুলো হলো [সাইনড ইন্টিজার টাইপ][int]:

| টাইপ     | আকার (বিট) | পরিসর                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 to 127                                                                                                 |
| `Int16`  | 16          | -32_768 to 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 to 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 to 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 to 170_141_183_460_469_231_731_687_303_715_884_105_727 |

ছোট টাইপগুলো বড় টাইপের চেয়ে কম মেমরি ব্যবহার করে এবং দ্রুততর, তবে সম্ভাব্য মানের পরিসর ছোট।

যখন আপনি জানেন যে মানগুলো একটি নির্দিষ্ট পরিসরের মধ্যে থাকবে, তখন মেমরি বাঁচাতে ও পারফরম্যান্স বাড়াতে সম্ভব হলে সবচেয়ে ছোট টাইপ ব্যবহার করাই সবচেয়ে ভালো।

ডিফল্ট ইন্টিজার টাইপ হলো `Int32`.
নির্দিষ্ট টাইপের একটি ইন্টিজার ডিক্লেয়ার করতে, `<number>_I <bit>` যোগ করে টাইপের নামটি সাফিক্স হিসেবে ব্যবহার করতে পারেন।

```crystal
1_i8.class
# => Int8
```

ভিন্ন ভিন্ন ইন্টিজার টাইপের মধ্যে রূপান্তর করতে আপনি `to_i<bit>` মেথড ব্যবহার করতে পারেন।
`to_i` মেথড ডিফল্ট ইন্টিজার টাইপ `Int32`-এ রূপান্তর করে।

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## আনসাইনড ইন্টিজার টাইপ

Crystal-এ এগুলো হলো [আনসাইনড ইন্টিজার][uint] টাইপ:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

সাইনড ও আনসাইনড ইন্টিজারের মধ্যে একমাত্র পার্থক্য হলো, আনসাইনড ইন্টিজার কেবল ধনাত্মক হতে পারে।
নির্দিষ্ট টাইপের একটি আনসাইনড ইন্টিজার ডিক্লেয়ার করতে, `<number>_u<bit>` যোগ করে টাইপের নামটি সাফিক্স হিসেবে ব্যবহার করতে পারেন।
ভিন্ন ভিন্ন আনসাইনড ইন্টিজার টাইপের মধ্যে রূপান্তর করতে আপনি `to_u<bit>` মেথড ব্যবহার করতে পারেন।
`to_u` মেথড ডিফল্ট আনসাইনড ইন্টিজার টাইপ `UInt32`-এ রূপান্তর করে।

```crystal
1_u8.to_u16.class
# => UInt16
```

## ফ্লোটিং পয়েন্ট টাইপ

Crystal-এ এগুলো হলো ফ্লোটিং পয়েন্ট টাইপ:

| টাইপ      | আকার (বিট) | পরিসর                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 to 3.4E+38   |
| `Float64` | 64          | 2.3E-308 to 1.7E+308 |

এখানে দুটি ভিন্ন [ফ্লোটিং পয়েন্ট টাইপ][float] আছে, যার একটি অন্যটির চেয়ে বেশি নির্ভুল।

ডিফল্ট ফ্লোটিং পয়েন্ট টাইপ হলো `Float64`.

ভিন্ন ভিন্ন ফ্লোটিং পয়েন্ট টাইপের মধ্যে রূপান্তর করতে আপনি `to_f<bit>` মেথড ব্যবহার করতে পারেন।
`to_f` মেথড ডিফল্ট ফ্লোটিং পয়েন্ট টাইপ `Float64`-এ রূপান্তর করে।

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
