# for লুপ

লুপিং প্রোগ্রামিংয়ের একটি মৌলিক ধারণা, যা দিয়ে আপনি একই কোড ব্লক বারবার চালাতে পারেন।
Swift-এ দুই ধরনের লুপ আছে: [`for-in` লুপ][for-loops] এবং `while` লুপ।
এই অধ্যায়ে আপনি `for-in` লুপ সম্পর্কে জানবেন।

for লুপ দিয়ে আপনি মানের একটি সিকোয়েন্সের উপর ইটারেশন করতে পারেন, একে একে প্রতিটি এলিমেন্ট নিয়ে সেটি আপনার পছন্দমতো একটি ভ্যারিয়েবলের সাথে বাইন্ড করতে পারেন।
Swift-এ আপনি নানা রকম সিকোয়েন্সের উপর ইটারেশন করতে পারেন, যেমন রেঞ্জ, অ্যারে ও স্ট্রিং (আরও কিছু টাইপ আছে, যেগুলো পরে আলোচনা করা হবে)।
সিকোয়েন্সের প্রতিটি এলিমেন্টে ইটারেশন শেষ হয়ে গেলে লুপটি শেষ হয়।

for লুপ ঘোষণা করা হয় `for` কিওয়ার্ড দিয়ে, তারপর একটি ভ্যারিয়েবলের নাম, `in` কিওয়ার্ড এবং যে মানের সিকোয়েন্সের উপর ইটারেশন হবে সেটি লিখে।
`for-in` লুপে দেওয়া ভ্যারিয়েবলটি অপরিবর্তনীয়, অর্থাৎ লুপের ভেতরে আপনি এর মান বদলাতে পারবেন না।
নিচে সংখ্যার একটি অ্যারের উপর ইটারেশন করা একটি `for-in` লুপের উদাহরণ:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` ভ্যারিয়েবলটি `for-in` লুপে ঘোষণা করা হয়েছে, তাই এটি কেবল লুপটির স্কোপের ভেতরেই পাওয়া যায়।

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## একটি রেঞ্জের উপর ইটারেশন

`for-in` লুপ ব্যবহার করে সংখ্যার একটি রেঞ্জের উপরও ইটারেশন করতে পারেন।
এতে করে আপনি নির্দিষ্ট সংখ্যকবার একটি কোড ব্লক চালাতে পারেন; যেমন `1...5` রেঞ্জটি 1, 2, 3, 4 ও 5 সংখ্যাগুলোর উপর ইটারেশন করবে, তাই লুপটি ৫ বার চলবে।
কখনও কখনও অ্যারের মতো একটি ডেটা স্ট্রাকচারে ইনডেক্সের উপর ইটারেশন করতে চাইতে পারেন; তখন `0..<array.count` রেঞ্জটি ব্যবহার করতে পারেন।

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## একটি স্ট্রিংয়ের উপর ইটারেশন

`for-in` লুপ ব্যবহার করে একটি স্ট্রিংয়ের উপরও ইটারেশন করতে পারেন।
এতে করে আপনি স্ট্রিংয়ের প্রতিটি ক্যারেক্টারের উপর ইটারেশন করতে পারেন; আর খেয়াল করুন, লুপে যে টাইপটি পাওয়া যায় সেটি `Character`।

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## অব্যবহৃত ভ্যারিয়েবল

লুপে ভ্যারিয়েবলের মানটির প্রয়োজন না হলে, সেটি এড়িয়ে যেতে আন্ডারস্কোর `_` ব্যবহার করতে পারেন।

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift-এ `stride` নামের একটি ফাংশনও আছে, যা দিয়ে নির্দিষ্ট ধাপে একটি রেঞ্জের উপর একটি সিকোয়েন্স তৈরি করতে পারেন।
এরপর `for-in` লুপ দিয়ে সেই সিকোয়েন্সের উপর ইটারেশন করা যায়।
`stride`-এর দুইটি রূপ আছে: [`stride(from:to:by:)`][stride-to] আর [`stride(from:through:by:)`][stride-through]; প্রথমটি এক্সক্লুসিভ আর দ্বিতীয়টি ইনক্লুসিভ।

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

খেয়াল করুন, `to` প্যারামিটারটি এক্সক্লুসিভ, তাই লুপটি `to` প্যারামিটারের ঠিক আগের সংখ্যা পর্যন্ত ইটারেশন করে; আর `through` প্যারামিটারটি ইনক্লুসিভ, তাই এখানে `10`-ও এর অন্তর্ভুক্ত হয়।

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
