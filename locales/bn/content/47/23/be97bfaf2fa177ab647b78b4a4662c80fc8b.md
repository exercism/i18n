# নির্দেশাবলীর সংযোজন

## ইঙ্গিত

এই অনুশীলনীটি টেক্সচুয়াল ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর
`String` টাইপ `[Char]`-এর সাথে সমার্থক, যা ক্যারেক্টারের একটি অ্যারে। টেক্সচুয়াল
ডেটা আরও দক্ষভাবে পরিচালনা করার জন্য `Text` টাইপটি ব্যবহার করা যেতে পারে।

এই অনুশীলনীর জন্য একটি ঐচ্ছিক এক্সটেনশন হিসেবে আপনি নিম্নলিখিত কাজগুলো করতে পারেন

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml-এ আপনার ডিপেন্ডেন্সির অ্যারেতে `- text` যোগ করুন।
- `Data.Text` [নিম্নলিখিত উপায়ে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) ইমপোর্ট করুন:

        import qualified Data.Text as T
        import           Data.Text (Text)

- এখন আপনি যেমন `isIsogram :: Text -> Bool` লিখতে পারেন এবং `Data.Text` কম্বিনেটরগুলোকে যেমন `T.toLower` হিসেবে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখুন।

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
