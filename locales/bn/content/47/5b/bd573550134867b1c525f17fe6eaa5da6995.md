# নির্দেশাবলির সংযোজন

## ইঙ্গিত

আপনার ফাংশনটি ইমপ্লিমেন্ট করতে হবে

```haskell
value :: (Color, Color) -> Int
```

যা কেবল দুটি রং নেয় এবং রেজিস্টরের রেজিস্ট্যান্সের সংখ্যাসূচক মানের উপাদানটি তৈরি করে।

**বোনাস - প্রপার্টি টেস্টিং:**

এই অনুশীলনীটি কিছু [প্রপার্টি টেস্ট](https://en.wikipedia.org/wiki/Property_testing) লেখার একটি ভালো সুযোগ। আপনি যদি আগে কখনো প্রপার্টি টেস্ট না লিখে থাকেন, তাহলে এখানে কিছু রিসোর্স আছে:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

আমরা টেস্ট ফাইলে একটি নমুনা QuickCheck প্রপার্টি টেস্ট দিয়েছি।

যে প্রপার্টিগুলো টেস্ট করা যায় তার উদাহরণ:

- `value (x, y) >= 10`, এমন সব `(x, y)`-এর জন্য যেখানে `x` `Black` নয়

- `value (x, y)`-এর ওপর `show` কল করলে `value (y, x)`-এর ওপর `show` কল করার `reverse` স্ট্রিং উৎপন্ন হয়।

- সব রঙের নাম অনন্য। (যেকোনো দুটি রঙের জন্য, রঙ দুটি আলাদা হলে নামও আলাদা।)
