# ফাংশন হেডারের ব্যবহার

[comment]: # (এই এররটি দেখানো হয় যখন সলিউশনে একটি ফাংশন হেডার ব্যবহার করা হয়)

ফাংশন হেডার (বডি ছাড়া একটি ফাংশন ডেফিনিশন) কেবল তখনই দরকার, যখন ফাংশনে ডিফল্ট আর্গুমেন্ট থাকে এবং একাধিক ক্লজ থাকে।

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

আর যেসব ফাংশনে ডিফল্ট আর্গুমেন্ট আছে অথচ ক্লজ মাত্র একটি, সেগুলোর ক্ষেত্রে ওই ক্লজেই ডিফল্ট আর্গুমেন্টগুলো সরাসরি নির্দিষ্ট করা যায়।

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

`two_fer/1` ফাংশনের একটি মাত্র ক্লজই যথেষ্ট, তাই এটির কোনো ফাংশন হেডার দরকার নেই।
