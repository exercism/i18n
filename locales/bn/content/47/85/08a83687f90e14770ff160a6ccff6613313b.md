# টাপল

টাপল হলো নির্দিষ্ট সংখ্যক, যেকোনো টাইপের ডেটা একসাথে গুছিয়ে রাখার একটি হালকা উপায়। টাপলের কোনো নির্দিষ্ট নাম থাকে না; কোনো ডেটা স্ট্রাকচারের নাম দিয়ে দিলে সেটি `struct`-এ পরিণত হয়। টাপলের ফিল্ডগুলোর নাম থাকে না; এগুলো ডিস্ট্রাকচারিংয়ের মাধ্যমে বা অবস্থান দিয়ে অ্যাক্সেস করা হয়।

## সিনট্যাক্স

টাপল হলো বন্ধনী দিয়ে ঘেরা ফিল্ডের একটি তালিকা:

- `()` হলো `unit type`, যা একটি [বিশেষ কেস](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _এক্সপ্রেশন_ **,)** হলো একটি এলিমেন্টের টাপল এক্সপ্রেশন
- **(** _টাইপ_ **,)** হলো একটি এলিমেন্টের টাপল টাইপ
- **(** _এক্সপ্রেশন_ **,** ... **)** হলো একটি সাধারণ টাপল এক্সপ্রেশন
- **(** _টাইপ_ **,** ... **)** হলো একটি সাধারণ টাপল টাইপ

### তৈরি

টাপল সবসময় একটি টাপল এক্সপ্রেশন দিয়ে তৈরি করা হয়:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

টাপলে যেকোনো সংখ্যক এলিমেন্ট থাকতে পারে।

### ডিস্ট্রাকচারিং দিয়ে অ্যাক্সেস

ডিস্ট্রাকচারিংয়ের মাধ্যমে টাপলের এলিমেন্টগুলো অ্যাক্সেস করা সম্ভব। এর মানে হলো টাপলের প্রতিটি এলিমেন্টকে আলাদা ভ্যারিয়েবলের নাম দিয়ে অ্যাসাইন করা, আর এর ফলে টাপলটি ব্যবহৃত হয়ে যায়।

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### অবস্থান দিয়ে অ্যাক্সেস

সংখ্যাভিত্তিক অবস্থানগত ইনডেক্স দিয়েও টাপলের এলিমেন্টগুলো অ্যাক্সেস করা সম্ভব। ইনডেক্সিং সবসময়ের মতোই 0 থেকে শুরু হয়।

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## টাপল স্ট্রাকট

আপনাকে টাপল স্ট্রাকট নিয়েও কাজ করতে বলা হবে। সাধারণ স্ট্রাকটের মতো এগুলোও নামযুক্ত টাইপ; তবে সাধারণ স্ট্রাকটের বিপরীতে এগুলোর ফিল্ডগুলো নামহীন। এগুলোর সিনট্যাক্স সাধারণ টাপল সিনট্যাক্সের সাথে খুব মিল। এখানে ডিস্ট্রাকচারিং এবং অবস্থানভিত্তিক অ্যাক্সেস, দুটোই ব্যবহার করা বৈধ।

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### ফিল্ডের দৃশ্যমানতা

নামহীন টাপলের সব ফিল্ড সবসময় পাবলিক থাকে। তবে টাপল স্ট্রাকটের ফিল্ডগুলোর আলাদা আলাদা দৃশ্যমানতা থাকে, যা ডিফল্টভাবে প্রাইভেট, ঠিক সাধারণ স্ট্রাকটের ফিল্ডের মতোই। সাধারণ স্ট্রাকটের মতো `pub` মডিফায়ার দিয়ে আপনি ফিল্ডগুলো পাবলিক করতে পারেন।

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
