# ইনস্টলেশন

elm-এর বর্তমান সংস্করণ 0.19.1।
ভাষা বিকশিত হওয়ার সাথে সাথে ইনস্টলেশনের নির্দেশনা বদলে যায়।
হালনাগাদ ইনস্টলেশন নির্দেশনার জন্য [elm গাইডের ইনস্টলেশন নির্দেশনা][elm-install] দেখুন।

[elm-install]: https://guide.elm-lang.org/install/elm.html

## অতিরিক্ত টুল

**elm-test**

কমান্ড লাইন থেকে টেস্ট চালানোর জন্য যে টুলটি ব্যবহার করা হয় তার নাম elm-test।
বর্তমানে elm-test-এর জন্য Node.js আর npm দরকার, তাই আপনি যদি আগে থেকে
[Node.js আর npm ইনস্টল][npm-install] না করে থাকেন, তাহলে অনুগ্রহ করে সেটি আগে করে নিন।
npm ইনস্টল হয়ে গেলে আপনি elm-test ইনস্টল করতে পারবেন এভাবে:

```shell
npm install --global elm-test@latest-0.19.1
```

আরও তথ্য রয়েছে [elm-test-এর npm হোম পেজে][elm-test]।

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

বেশিরভাগ elm প্রোগ্রামার তাঁদের elm কোড ফরম্যাট করতে elm-format ব্যবহার করেন।
এটি একটি শূন্য কনফিগারেশনের কোড ফরম্যাটিং টুল।
স্বয়ংক্রিয় ফরম্যাটিং টুলে অভ্যস্ত না থাকলে শুরুতে এটি একটু বিরক্তিকর লাগতে পারে, কিন্তু
একবার অভ্যস্ত হয়ে গেলে আপনি ভাবতে শুরু করবেন, আগে এটি ছাড়া কীভাবে কোড করতেন।
এটি npm দিয়েও ইনস্টল করা যায়:

```shell
npm install --global elm-format@latest-0.19.1
```

আরও তথ্য রয়েছে [GitHub-এ elm-format-এর হোম পেজে][elm-format]।

[elm-format]: https://github.com/avh4/elm-format

**টেক্সট এডিটর**

Elm-এর সাপোর্ট অন্তত [IntelliJ][intellij]-তে ভালো, আর [elm language server][els]-এর
সাথে কাজ করে এমন টেক্সট এডিটর যেমন VS Code, Sublime Text বা Vim-এও ভালো।

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## npm-এর সাথে পারমিশন এরর

elm-test বা elm-format ইনস্টল করার সময় আপনি npm-এর সাথে EACCESS পারমিশন এররের
মুখোমুখি হতে পারেন।
এমন হলে অনুগ্রহ করে npm ওয়েবসাইটের নির্দেশনা অনুসরণ করুন।
[প্যাকেজ গ্লোবালি ইনস্টল করার সময় EACCES পারমিশন এরর সমাধান করা][eaccess]।

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
