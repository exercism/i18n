# পরিচিতি

C# একটি স্ট্যাটিকালি টাইপড ভাষা, অর্থাৎ কম্পাইল-টাইমেই সবকিছুর একটি টাইপ থাকে। একটি নামে মান অ্যাসাইন করাকেই ভ্যারিয়েবল ডিফাইন করা বলা হয়। ভ্যারিয়েবল ডিফাইন করা যায় হয় তার টাইপ স্পষ্টভাবে উল্লেখ করে, নয়তো অ্যাসাইন করা মানের ভিত্তিতে C# কম্পাইলারকে তার টাইপ অনুমান করতে দিয়ে (যাকে _টাইপ ইনফারেন্স_ বলা হয়)। তাই নিচের দুটি ভ্যারিয়েবল ডেফিনিশন সমতুল্য:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

একটি ভ্যারিয়েবলের মান আপডেট করা হয় `=` অপারেটর দিয়ে। একবার ডিফাইন হয়ে গেলে ভ্যারিয়েবলের টাইপ আর কখনোই পরিবর্তন করা যায় না।

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# একটি [অবজেক্ট-ওরিয়েন্টেড ভাষা][object-oriented-programming] এবং এতে সব ফাংশন একটি _ক্লাসের_ ভেতরে ডিফাইন করতে হয়। `class` কিওয়ার্ড দিয়ে ক্লাস ডিফাইন করা হয়। `new` কিওয়ার্ড ব্যবহার করে অবজেক্ট (বা _ইনস্ট্যান্স_) তৈরি করা হয়।

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

একটি ক্লাসের ভেতরের ফাংশনকে _মেথড_ বলা হয়। প্রতিটি মেথডে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে। সব প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হয়, প্যারামিটারের জন্য কোনো টাইপ ইনফারেন্স নেই। একইভাবে রিটার্ন টাইপও স্পষ্টভাবে উল্লেখ করতে হয়। `return` কিওয়ার্ড দিয়ে মেথড থেকে মান রিটার্ন করা হয়। অন্য ফাইলের কোড থেকে একটি মেথড কল করা সম্ভব করতে `public` অ্যাক্সেস মডিফায়ার যোগ করতে হয়।

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

ইনস্ট্যান্সের উপর ডট (`.`) সিনট্যাক্স ব্যবহার করে মেথড কল করা হয়; তখন কল করার মেথডের নাম দিতে হয় এবং মেথডের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করতে হয়। আর্গুমেন্টে চাইলে সংশ্লিষ্ট প্যারামিটারের নামও উল্লেখ করা যায়।

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C#-এ স্কোপ নির্ধারিত হয় `{` ও `}` অক্ষরের মধ্যে।

C# দুই ধরনের কমেন্ট সমর্থন করে। এক-লাইন কমেন্টের আগে `//` বসে এবং একাধিক লাইনের কমেন্ট `/*` ও `*/`-এর মধ্যে লেখা হয়।

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
