# পরিচিতি

[ডিসক্রিমিনেটেড ইউনিয়ন][define] টাইপটি নির্দিষ্ট সংখ্যক নামযুক্ত কেস উপস্থাপন করে। একটি ডিসক্রিমিনেটেড ইউনিয়নের প্রতিটি মান ঠিক একটি নামযুক্ত কেসের সাথে অনুরূপ হয়। এই ধরনের ডেটা টাইপকে বলা হয় _সাম টাইপ_।

ডিসক্রিমিনেটেড ইউনিয়নের প্রতিটি কেসের সাথে ইচ্ছেমতো ডেটা যুক্ত থাকতে পারে, আর ভিন্ন ভিন্ন কেসে ভিন্ন ভিন্ন ধরনের ডেটা থাকতে পারে। কোনো কেসের সাথে ডেটা যুক্ত না থাকলে, ডিসক্রিমিনেটেড ইউনিয়নটি অন্য ভাষাগুলোতে সাধারণত যা _এনামারেশন_ (বা _এনাম_) নামে পরিচিত হয়, তার অনুরূপ হয়।

ডিসক্রিমিনেটেড ইউনিয়ন ডিফাইন করা হয় `type` কিওয়ার্ড দিয়ে, আর এর জন্য খুব কম সিনট্যাক্স লাগে। এতে এগুলো ব্যবহার করা সহজ হয়, আর বেস লাইব্রেরিসহ অনেক জায়গায় এগুলোর ব্যবহার দেখতে পাবেন।

```fsharp
// Discriminated union without associated data
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter

// Discriminated union with associated data
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

নির্দিষ্ট কোনো কেসের জন্য মান তৈরি করা যায় তার নাম উল্লেখ করে, আর নামটি যদি অনন্য না হয় তাহলে তার পুরো নাম উল্লেখ করে। যেহেতু কেসের নামগুলো আসলে কনস্ট্রাক্টর ফাংশন, তাই সংশ্লিষ্ট ডেটা সাধারণ ফাংশন আর্গুমেন্ট হিসেবেই পাঠানো যায়।

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

ডিসক্রিমিনেটেড ইউনিয়নের _স্ট্রাকচারাল ইকুয়ালিটি_ থাকে, যার মানে একই কেসের এবং একই (ঐচ্ছিক) ডেটাযুক্ত দুটি মান পরস্পর সমতুল্য।

ডিসক্রিমিনেটেড ইউনিয়ন নিয়ে কাজ করার সবচেয়ে পছন্দের উপায় হলো [আইডেন্টিফায়ার প্যাটার্ন][identifier-patterns] ব্যবহার করে [প্যাটার্ন ম্যাচিং][pattern-matching] করা:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
