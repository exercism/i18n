# কেস

[কেস][case] (অন্য ভাষায় প্রায়ই যাকে switch বলা হয়) হলো if-else-এর মতো এক ধরনের কন্ট্রোল এক্সপ্রেশন। কেস একাধিক if-else-if স্টেটমেন্ট পরপর সাজানোর সুযোগ দেয় এবং ফ্লো কন্ট্রোল দিতে দিয়েও পড়তে বেশি সুবিধাজনক হতে পারে।

একটি কেস বোঝানো হয় `case` কিওয়ার্ড দিয়ে, তার পরে থাকে একটি ঐচ্ছিক এক্সপ্রেশন। এরপর প্রতিটি কেসের জন্য `when` কিওয়ার্ডটি ব্যবহার করা হয়, তার পরে থাকে একটি এক্সপ্রেশন, যা কেস এক্সপ্রেশনের সাথে তুলনা করা হয়। `when` কিওয়ার্ডটি `case` কিওয়ার্ড থেকে ইনডেন্ট করা উচিত নয়। `when` কিওয়ার্ডের পরে থাকে সেই কোড, যা কেস এক্সপ্রেশনটি when এক্সপ্রেশনের সাথে মিললে চালানো হয়। কেসে একটি ঐচ্ছিক `else` স্টেটমেন্ট থাকতে পারে, যা অন্য কোনো কেস না মিললে চালানো হয়।

কেস এক্সপ্রেশনটি মূল্যায়ন করা হয়, তারপর প্রতিটি `when` এক্সপ্রেশনের সাথে তুলনা করা হয়। এই তুলনা করা হয় কেস সমতা অপারেটর (`===`) দিয়ে।

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## কেস সমতা অপারেটর (`===`)

কেস সমতা অপারেটর (`===`) সমতা অপারেটর (`==`) থেকে একটু আলাদা। এই অপারেটরটি যাচাই করে যে ডান দিকেরটি বাম দিক বর্ণিত সেটের একটি সদস্য কি না। এর মানে হলো, প্রতিটি অপারেন্ড কোথায় বসছে সেটি গুরুত্বপূর্ণ। এটি কীভাবে কাজ করে তা নির্ভর করে বাম দিকের টাইপের উপর; উদাহরণস্বরূপ, একটি `Range` যাচাই করবে ডান দিকটি রেঞ্জের ভেতরে আছে কি না, আর একটি `Object` যাচাই করবে ডান দিকটি `Object`-এর একটি ইনস্ট্যান্স কি না।

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## একাধিক এক্সপ্রেশনসহ কেস

কেসে একটি কেসের ভেতরেই একাধিক এক্সপ্রেশন মেলানো যায়, যেখানে প্রতিটি সম্ভাব্য মান কমা দিয়ে আলাদা করা থাকে। এক্সপ্রেশনগুলোর যেকোনো একটি মিললেই এটি কোডটি চালায়। একটি কেসেই একাধিক সম্ভাব্য মান চাইলে এটি কাজে লাগে।

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## রেঞ্জসহ কেস

কেস দিয়ে কোনো মান রেঞ্জের ভেতরে আছে কি না, তাও যাচাই করা যায়। এটি করা হয় when এক্সপ্রেশন হিসেবে একটি রেঞ্জ ব্যবহার করে।

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## কেস এক্সপ্রেশন ছাড়া কেস

কেস এক্সপ্রেশনের প্রয়োজন না থাকলে সেটি বাদ দেওয়া যায়। এভাবে করলে প্রতিটি কেস এক্সপ্রেশন সত্যতা হিসেবে মূল্যায়ন করা হয়। আর তখন এগুলো if-else-if স্টেটমেন্টের মতো আচরণ করে।

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## এক লাইনের when

Ruby এক লাইনের কেস স্টেটমেন্টের সুযোগ দেয়। সরল এক লাইনের স্টেটমেন্ট থাকলে এটি ব্যবহার করা যায়। এক লাইনের when স্টেটমেন্ট লেখা হয় `when <expression> then <statement>` আকারে। আর else স্টেটমেন্টে ব্যবহার করলে লেখা হয় `else <statement>` আকারে।

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## টাইপসহ কেস

কেস দিয়ে টাইপের সাথে মেলানোও যায়। কোনো ভ্যারিয়েবলের টাইপ অনুযায়ী আলাদা আচরণ চাইলে এটি কাজে লাগে।

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
