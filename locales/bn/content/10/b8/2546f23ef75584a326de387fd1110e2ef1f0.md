# নির্দেশনা

এই অনুশীলনীতে আপনি একটি `Map` ব্যবহার করে আন্তর্জাতিক ডায়ালিং কোডের একটি ডিকশনারি পরিচালনা করার কোড লিখবেন।

ডিকশনারিটি আন্তর্জাতিক ডায়ালিং কোড দিয়ে (ম্যাপের কী (key), যা একটি `Integer`) দেশের নাম (ম্যাপের মান, যা একটি `String`) খুঁজে বের করার সুযোগ দেয়,

## 1. একটি ম্যাপে কোডগুলো রিটার্ন করুন

`getCodes` মেথডটি বাস্তবায়ন করুন, যা কোনো প্যারামিটার নেয় না এবং ডিকশনারিতে বর্তমানে থাকা ডায়ালিং কোড থেকে দেশে একটি ম্যাপ রিটার্ন করে।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. ডিকশনারিতে এন্ট্রি যোগ করুন

ডিকশনারিটি পূরণ করা প্রয়োজন।
`setDialingCode` মেথডটি বাস্তবায়ন করুন, যা একটি ডায়ালিং কোড এবং সংশ্লিষ্ট দেশ নেয় এবং ডায়ালিং কোড ও দেশ যোগ করে।
ডায়ালিং কোডটি যদি ইতিমধ্যেই ম্যাপে থাকে, তবে প্রদত্ত কোড ও দেশ দিয়ে ম্যাপটি আপডেট করুন।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. একটি ডায়ালিং কোডের দেশ খুঁজে বের করুন

`getCountry` মেথডটি বাস্তবায়ন করুন, যা একটি ডায়ালিং কোড নেয় এবং ওই ডায়ালিং কোডের দেশের নাম রিটার্ন করে।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. ডুপ্লিকেট অনুমোদন করবেন না

একটি ডায়ালিং কোড যোগ করার সময়, একটি কোড বা দেশ যাতে দুইবার যোগ না হয় সেদিকে খেয়াল রাখতে হবে।
এমন পরিস্থিতিতে, ধরে নেওয়া যেতে পারে যে প্রথম এন্ট্রিটিই সঠিক এন্ট্রি।
`addNewDialingCode` মেথডটি বাস্তবায়ন করুন, যা প্রদত্ত ডায়ালিং কোড ও দেশের জন্য একটি এন্ট্রি যোগ করে।
তবে `setDialingCode` মেথডের বিপরীতে, ডায়ালিং কোড বা দেশটি যদি ইতিমধ্যেই ম্যাপে থাকে তবে এটি কিছুই করে না।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. একটি দেশের ডায়ালিং কোড খুঁজে বের করুন

এটি বিরল, তবে ভুল হতে পারে।
ভুলটি সংশোধন করার জন্য, দেশটি বর্তমানে কোন ডায়ালিং কোডে ম্যাপ করা আছে তা আমাদের জানতে হবে।
কোন ডায়ালিং কোডটি সংশোধন করা প্রয়োজন তা খুঁজে বের করার জন্য, `findDialingCode` মেথডটি বাস্তবায়ন করুন, যা একটি দেশ নেয় এবং সেই দেশের ডায়ালিং কোড রিটার্ন করে।
দেশটি যদি ম্যাপে _না_ থাকে, তবে `null` রিটার্ন করুন।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. দেশের ডায়ালিং কোড আপডেট করুন

এখন যেহেতু আমরা জানি কোন ডায়ালিং কোডটি সংশোধন করা প্রয়োজন, তাই আমরা কোডটি আপডেট করতে এগোই।
`updateCountryDialingCode` মেথডটি বাস্তবায়ন করুন, যা দেশের নতুন ডায়ালিং কোড এবং দেশের নাম নেয় এবং সেই অনুযায়ী আপডেট করে।
দেশটি যদি ম্যাপে _না_ থাকে তবে কিছুই করবেন না (কারণ এই মেথডটি কেবল ভুল সংশোধন করতে সহায়তা করার জন্য বোঝানো হয়েছে)।

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
