# নির্দেশনা

এলেন একটি গেম বানাচ্ছেন, যেখানে খেলোয়াড়কে এলিয়েনদের সাথে লড়াই করতে হবে।
তিনি সবেমাত্র অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং (OOP) সম্পর্কে শিখেছেন এবং `classes` ব্যবহার করে তাঁর প্রোগ্রামে কী কী সুবিধা পাওয়া যায়, তা কাজে লাগাতে আগ্রহী।

এলেনের খুশিতে, আপনি সাহায্যের হাত বাড়িয়ে দিয়েছেন এবং তিনি আপনাকে সেই এলিয়েনদের প্রোগ্রাম করার দায়িত্ব দিয়েছেন, যাদের সাথে খেলোয়াড়কে লড়াই করতে হবে।

## 1. Alien ক্লাস তৈরি করুন

Alien ক্লাসটি এমন একটি কনস্ট্রাক্টর দিয়ে ডিফাইন করুন, যা দুটি প্যারামিটার `<x_coordinate>` এবং `<y_coordinate>` নেয় এবং সেগুলোকে `x_coordinate` ও `y_coordinate` ইনস্ট্যান্স ভ্যারিয়েবলে রাখে।
প্রতিটি এলিয়েনও শুরুতে ৩ হেলথ লেভেল নিয়ে যাত্রা করবে, তাই `health` ভ্যারিয়েবলটিও ইনিশিয়ালাইজ করতে হবে।

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

এখন প্রতিটি এলিয়েনের নিজের পজিশন ও হেলথ নিজের ভেতরেই ট্র্যাক করার ক্ষমতা থাকা উচিত।

## 2. `hit` মেথড

এলেন চান Alien `class`-এ একটি `hit` মেথড থাকুক, যা কল করা হলে এলিয়েন অবজেক্টের হেলথ ১ কমিয়ে দেবে।
এতে তিনি নিজ হাতে এলিয়েনের হেলথ পরিবর্তন না করে সহজেই `<alien>.hit()` কল করতে পারবেন।
`hit()` হেলথ পয়েন্ট শূন্য _পর্যন্ত_ কমাবে, নাকি শূন্যের _নিচেও_ নামতে দেবে, সেটি আপনার সিদ্ধান্ত।

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. `is_alive` মেথড

আপনি খেয়াল করলেন, হেলথ যদি কমতেই থাকে, একসময় সেটি সম্ভবত ০-এ গিয়ে ঠেকবে (_বা আরও কমে যাবে!_)।
এলেন যেন দ্রুত কল করে দেখতে পারেন এলিয়েনটি... মানে... জীবিত কি না, সেজন্য একটি `is_alive` মেথড যোগ করা ভালো হবে। 😉
`<alien>.is_alive()` একটি বুলিয়ান রিটার্ন করা উচিত।

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. `teleport` মেথড

এলেনের গেমে এলিয়েনদের টেলিপোর্ট করার ক্ষমতা আছে!
আপনাকে একটি `teleport` মেথড লিখতে হবে, যা নতুন `x_coordinate` ও `y_coordinate` মান নেয় এবং সেই অনুযায়ী এলিয়েনের কোঅর্ডিনেট পরিবর্তন করে।

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. `collision_detection` মেথড

স্বাভাবিকভাবেই, এলিয়েনদের যদি কোনো কিছুতে আঘাত লাগতে পারে, তাহলে এমন সংঘর্ষ কখন ঘটেছে তা শনাক্ত করার ক্ষমতাও তাদের থাকা দরকার।
তবে কোলিশন ডিটেকশন অ্যালগরিদম জটিল হতে পারে, আর সেটি কীভাবে বাস্তবায়ন করতে হয় তা আপনি এখনো জানেন না।
এলেন বলেছেন, তিনি এটি পরে করবেন, তবে ফাংশনালিটিটা পরে পুরোপুরি গড়ে তোলার কথা মনে করিয়ে দিতে তিনি চান `collision_detection` মেথডটি ক্লাসে থাকুক।
এটিকে কোনো এক ধরনের ভ্যারিয়েবল (সম্ভবত আরেকটি অবজেক্ট) নিতে হবে, কিন্তু আপনি আসলে এটুকুই জানেন।
মেথড ডেফিনিশনটি ক্লাসে রেখে কল করলে কোনো এরর হয় কি না, তা আপনি নিশ্চিত করতে হবে:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. অ্যালিয়েন কাউন্টার

এলেন নতুন একটি অনুরোধ নিয়ে আপনার কাছে ফিরে এসেছেন।
গেমটি যতদিন চলবে, ততদিনে মোট কতজন এলিয়েন তৈরি হয়েছে, তিনি তার হিসাব রাখতে চান।
তিনি বললেন, এটির সাথে স্কোরিং সিস্টেমের কিছু সম্পর্ক আছে।

যেমন:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. অ্যালিয়েনদের একটি অ্যারে তৈরি করা

এখন পর্যন্ত আপনি যা করেছেন, এলেন তা খুব পছন্দ করেছেন, তবে তাঁর আরও একটি অনুরোধ আছে।
তিনি চান একটি স্বতন্ত্র ফাংশন (_ `Alien()` ক্লাসের বাইরে_), যা পজিশনের একটি অ্যারে (`tuples` আকারে) দিলে `Alien()` অবজেক্টের একটি `list` তৈরি করে।

যেমন:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
