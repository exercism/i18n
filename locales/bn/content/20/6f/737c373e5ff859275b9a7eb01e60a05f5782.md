# নির্দেশনা

নৃত্য দলটি সারি সারি হয়ে দাঁড়ায়, আর কে কোথায় দাঁড়ায় তার হিসাব আপনি রাখছেন।

পাঁচটি কাজই `DANCE_FORMATION` ক্লাসে যাবে।

## 1. সারিতে কতজন?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. নেতৃত্ব দেন কে?

যিনি সবার আগে দাঁড়ান, তিনিই নেতা।

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. সবার পেছনে কে?

সারি যত বড়ই হোক না কেন, যিনি সবার শেষে দাঁড়ান তিনিই পেছনের ব্যক্তি।

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. উদ্বোধনী বিন্যাস

দলটি সবসময় একই ক্রমে শুরু করে: Mia, Ana, Ben। সেই সারিটি রিটার্ন করুন।

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

এই রুটিনটি কোনো আর্গুমেন্ট নেয় না।

## 5. ধাপ গুনুন

প্রতিটি নৃত্যশিল্পীর নির্দিষ্ট সংখ্যক ধাপ করতে হয়। সেগুলো যোগ করুন।

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

খালি সারিতে ধাপ শূন্য।
