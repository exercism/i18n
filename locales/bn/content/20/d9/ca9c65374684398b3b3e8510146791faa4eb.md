# Tests

## Clojure CLI

Exercism-এ Clojure অনুশীলনীগুলো একটি `deps.edn` ফাইল নিয়ে আসে, যেটিতে [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) চালু করার জন্য `:test` অ্যালিয়াস থাকে:

``` bash
clj -X:test
```

## Leiningen

অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি চালিয়ে Leiningen দিয়েও অনুশীলনীর test চালানো যায়:

```bash
lein test
```
