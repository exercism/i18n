# ভূমিকা

PHP-তে একটি ফাংশনের ভেতরে আরও ফাংশন ডিক্লেয়ার করা যায়। এই ফাংশনগুলোর নাম দেওয়ার দরকার নেই, তবে এগুলো ভ্যারিয়েবলে অ্যাসাইন করা যায়, এমনকি সরাসরি আরেকটি ফাংশনে পাস করা যায় যার একটি ফাংশন প্যারামিটার দরকার।

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
