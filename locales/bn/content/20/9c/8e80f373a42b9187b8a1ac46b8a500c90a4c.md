# নির্দেশনা

এই অনুশীলনীতে আপনি লগ এন্ট্রি প্রসেস করবেন।

প্রতিটি লগ লাইন হলো একটি স্ট্রিং, যার ফরম্যাট নিচের মতো: `"[<LEVEL>]: <MESSAGE>"`।

এখানে তিনটি ভিন্ন লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে, প্রতিটিতে একটি লগ লাইন নিয়ে সেটি দিয়ে কিছু করতে বলা হবে। এই কাজগুলো সমাধান করার অনেক উপায় আছে। উপরের উদাহরণগুলো থেকে আপনার পছন্দের কৌশল বেছে নিন এবং দেখুন আপনি কী বের করতে পারেন।

## 1. লগ লাইন থেকে মেসেজ বের করা

লগ লাইনের মেসেজ রিটার্ন করার জন্য `message` ফাংশনটি ইমপ্লিমেন্ট করুন:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

শুরুতে বা শেষে থাকা যেকোনো হোয়াইট স্পেস সরিয়ে ফেলা উচিত:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. লগ লাইন থেকে লগ লেভেল বের করা

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য `log_level` ফাংশনটি ইমপ্লিমেন্ট করুন, যা ছোট হাতের অক্ষরে রিটার্ন করা উচিত:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. একটি লগ লাইন নতুন করে ফরম্যাট করা

`reformat` ফাংশনটি ইমপ্লিমেন্ট করুন, যা লগ লাইনটি নতুন করে ফরম্যাট করে, মেসেজটি আগে বসায় আর তার পরে বন্ধনীর মধ্যে লগ লেভেল বসায়:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
