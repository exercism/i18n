# পরিচিতি

Elixir ট্রু ও ফলস মান বুলিয়ান টাইপ দিয়ে প্রকাশ করে। এর মাত্র দুটি মান আছে: `true` এবং `false`। এই মানগুলো একটি ভ্যারিয়েবলে রাখা যায়:

```elixir
true_variable = true
false_variable = false
```

আমরা `and/2`, `or/2`, এবং `not/1` অপারেটর ব্যবহার করে কঠোর বুলিয়ান এক্সপ্রেশন মূল্যায়ন করতে পারি।

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

কোনো ফাংশন থেকে বুলিয়ান মান রিটার্ন করতে চাইলে ফাংশনের নামের শেষে একটি `?` দেওয়াই প্রচলিত রীতি। একই রীতি বুলিয়ান মান রাখা ভ্যারিয়েবলের ক্ষেত্রেও ব্যবহার করা যায়।

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
