# ভূমিকা

গাণিতিক ওভারফ্লো তখন ঘটে, যখন কোনো গণনা, যেমন কোনো গাণিতিক অপারেশন বা টাইপ কনভার্সন, এমন একটি মান তৈরি করে যা গ্রহণকারী টাইপের ধারণক্ষমতার চেয়ে বড়।

`int` এবং `long` টাইপের এক্সপ্রেশন এবং তাদের unsigned সমতুল্য টাইপগুলি এই পরিস্থিতিতে নীরবে র‍্যাপ অ্যারাউন্ড করে।

`checked` কিওয়ার্ড ব্যবহার করে পূর্ণসংখ্যার গণনার আচরণ পরিবর্তন করা যায়। কোনো `checked` ব্লকের ভিতরে ওভারফ্লো ঘটলে `OverflowException`-এর একটি ইনস্ট্যান্স থ্রো করা হয়।

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

`float` এবং `double` টাইপের এক্সপ্রেশনগুলি ইনফিনিটি নামের একটি বিশেষ মান নেবে।

`decimal` টাইপের এক্সপ্রেশনগুলি `OverflowException`-এর একটি ইনস্ট্যান্স থ্রো করবে।
