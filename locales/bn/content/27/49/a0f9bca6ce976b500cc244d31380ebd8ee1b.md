# নির্দেশনা

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার বিন্যাস নিচের মতো: `"[<LVL>]: <MESSAGE>"`।

লগ লেভেলগুলো হলো:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

আপনার তিনটি কাজ আছে।

## 1. লগ লেভেল পার্স করা

উপরের লগ লেভেলগুলোর সাথে মিলে যায় এমন ছয়টি এলিমেন্টযুক্ত একটি `LogLevel` এনাম ডিফাইন করুন।

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

এরপর, একটি লগ লাইনের লগ লেভেল পার্স করতে (_static_) `LogLine.ParseLogLevel()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. অজানা লগ লেভেল সাপোর্ট করা

দুর্ভাগ্যবশত, মাঝেমধ্যে কিছু লগ লাইনে অজানা লগ লেভেল থাকে। এই লগ লাইনগুলো সুন্দরভাবে হ্যান্ডেল করতে, `LogLevel` এনামে একটি `Unknown` এলিমেন্ট যোগ করুন, যা অজানা লগ লেভেল পার্স করার সময় রিটার্ন করা উচিত:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. লগ লাইনকে শর্ট ফরম্যাটে রূপান্তর করা

একটি লগ লাইনে লগ লেভেল লেখা বেশ লম্বা হয়ে যায়। লগ লাইনগুলো সংরক্ষণ করতে যে ডিস্ক স্পেস লাগে তা কমাতে একটি শর্ট ফরম্যাট তৈরি করা হয়েছে: `"[<ENCODED_LEVEL>]:<MESSAGE>"`।

এনকোড করা লগ লেভেল হলো লগ লেভেল থেকে একটি সংখ্যায় সরল ম্যাপিং:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

সংক্ষিপ্ত লগ লাইন ফরম্যাট আউটপুট দিতে পারে এমন (_static_) `LogLine.OutputForShortLog()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
