# ভূমিকা

Go-তে `map` একটি বিল্ট-ইন ডেটা টাইপ, যা কী (key) থেকে মানে ম্যাপ করে।
অন্য প্রোগ্রামিং ভাষায় আপনি হয়তো ডিকশনারি, হ্যাশ টেবিল, কী (key) ও মানের স্টোর বা অ্যাসোসিয়েটিভ অ্যারে হিসেবে `map`-এর ধারণার সাথে পরিচিত হতে পারেন।

সিনট্যাক্সের দিক থেকে `map` দেখতে এমন হয়:

```go
map[KeyType]ElementType
```

এটাও জেনে রাখা জরুরি যে প্রতিটি কী (key) অনন্য, অর্থাৎ একই কী (key) দুবার অ্যাসাইন করলে সংশ্লিষ্ট কী (key)-এর মান ওভাররাইট হয়ে যাবে।

একটি ম্যাপ তৈরি করতে পারেন এভাবে:

```go
  // With map literal
  foo := map[string]int{}
```

অথবা

```go
  // or with make function
  foo := make(map[string]int)
```

ম্যাপ দিয়ে আপনি যেসব কাজ করতে পারেন, তার কিছু উদাহরণ এখানে দেওয়া হলো।

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

ম্যাপে নেই এমন কোনো কী (key)-এর মান বের করার চেষ্টা করলে এটি ভ্যালু টাইপের শূন্য মান রিটার্ন করবে।
এতে আপনি বিভ্রান্ত হতে পারেন, বিশেষ করে যদি আপনার `ElementType`-এর ডিফল্ট মান (যেমন int টাইপের ক্ষেত্রে 0) একটি বৈধ মান হয়।
আপনার ম্যাপে কোনো কী (key) আছে কি না তা যাচাই করতে পারেন এভাবে:

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
