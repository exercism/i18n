# পরিচিতি

F#-এ একটি `string` হলো এমন একটি অবজেক্ট, যা ইউনিকোড ক্যারেক্টারের (অক্ষর, অঙ্ক, যতিচিহ্ন ইত্যাদি) একটি ক্রম হিসেবে অপরিবর্তনীয় টেক্সট প্রকাশ করে। এটি এভাবে ডিফাইন করা হয়:

```fsharp
let fruit = "Apple"
```

স্ট্রিং নিয়ে কাজ করা যায় স্ট্রিংয়ের মেথড কল করে, অথবা `String` মডিউলের ফাংশন ব্যবহার করে। একবার একটি স্ট্রিং তৈরি হয়ে গেলে তার মান আর কখনোই বদলানো যায় না। যেসব মেথড বা ফাংশন স্ট্রিং পরিবর্তন করে বলে মনে হয়, তারা আসলে একটি নতুন স্ট্রিং রিটার্ন করে।

স্ট্রিং সংযুক্ত করা বা ফরম্যাট করার কয়েকটি ভিন্ন উপায় আছে।
* সংযুক্ত করার জন্য আপনি `+` অপারেটর ব্যবহার করতে পারেন:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* টেক্সট ফরম্যাট করার জন্য আপনি `sprintf` ফাংশন ব্যবহার করতে পারেন, যেখানে ফরম্যাট টেক্সটে প্লেসহোল্ডার থাকে (`string`-এর জন্য `%s`) এবং মানগুলো আর্গুমেন্ট হিসেবে দিয়ে দেন:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
