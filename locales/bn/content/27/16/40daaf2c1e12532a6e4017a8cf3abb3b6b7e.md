# পরিচিতি

## ভূমিকা

জেনেরিক্স হলো ভাষার এমন একটি বৈশিষ্ট্য, যা কোড রিইউজ করা সম্ভব করে।
যেমন, একটি অ্যারের দৈর্ঘ্য বের করতে তার ভেতরে কোন টাইপের মান আছে, সেটা গুরুত্বপূর্ণ হওয়া উচিত নয়।
সেজন্যই `length` ফাংশনটি তার টাইপ সিগনেচারে একটি জেনেরিক টাইপ প্যারামিটার `a` ব্যবহার করে।

```elm
length : List a -> Int
```

## টাইপে প্যারামিটার

কোনো টাইপ যখন অন্য একটি টাইপের উপর জেনেরিক হয়, তখন আমরা সেই অন্য টাইপের জন্য ছোট হাতের অক্ষরে একটি নাম ব্যবহার করি এবং এটিকে টাইপ প্যারামিটার বলি।
কমন উদাহরণ হলো `List`, `Maybe` এবং `Result` কাস্টম টাইপ।

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

টাইপ প্যারামিটারের নাম নিয়ে একটি গুরুত্বপূর্ণ কথা হলো, এদের নাম একাধিক অক্ষরেরও হতে পারে।
একমাত্র শর্ত হলো এদের নাম ছোট হাতের হতে হবে।
তাই যখন কাজে লাগে, আমরা এদের বর্ণনামূলক নাম দিতে পছন্দ করি।

একটি টাইপ একাধিক অন্য টাইপের উপর জেনেরিক হতে পারে, আর তাই একাধিক টাইপ প্যারামিটার থাকতে পারে।
সেক্ষেত্রে প্রতিটি স্বাধীন টাইপ আলাদা ছোট হাতের নাম পায়।
স্বাধীন হওয়া তাদের একই টাইপ হয়ে যাওয়া আটকায় না, এটি কেবল তাদের আলাদা হওয়া সম্ভব করে।

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

রেকর্ড টাইপ অ্যালিয়াসেও টাইপ প্যারামিটার থাকতে পারে, যদিও এটি খুব একটা কমন নয়।

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## ফাংশনে টাইপ প্যারামিটার

যেহেতু টাইপ জেনেরিক হতে পারে, ফাংশনও তাই হতে পারে।
জেনেরিক টাইপ নিয়ে কাজ করা ফাংশন লেখা যায়, যেমন `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

যে ফাংশনগুলো অন্য ফাংশনকে প্যারামিটার হিসেবে নেয়, তাদের হায়ার-অর্ডার ফাংশন বলা হয়, আর এগুলোও জেনেরিক হতে পারে।

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
