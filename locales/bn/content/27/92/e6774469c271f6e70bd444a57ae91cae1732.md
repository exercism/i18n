# ভূমিকা

এলিক্সিরে ম্যাপ হলো কী (key)-মান জোড়ায় তথ্য সংরক্ষণ করার ডেটা স্ট্রাকচার। অন্য ভাষায় এগুলোকে অ্যাসোসিয়েটিভ অ্যারে (PHP), হ্যাশ (Perl 5, Raku), বা ডিকশনারি (Python) নামেও জানা যেতে পারে।

কী (key) ও মান যেকোনো ডেটা টাইপের হতে পারে, কিন্তু যদি কী (key) অ্যাটম হয়, আমরা একটি শর্টহ্যান্ড সিনট্যাক্স ব্যবহার করতে পারি। অ্যাক্সেস বা রিটার্ন করার সময় ম্যাপ তাদের এন্ট্রিগুলোর ক্রম নিশ্চিত করে না।

## লিটারেল ফর্ম

খালি ম্যাপ কেবল `%{}` দিয়ে ঘোষণা করা হয়। আমরা যদি একটি ম্যাপ লিটারেলে আইটেম যোগ করতে চাই, তাহলে দুটি ফর্ম ব্যবহার করতে পারি:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

যদিও কোনো ক্যানোনিকাল ফরম্যাট নেই, কী (key)-মান লিটারেল জোড়াগুলো উপস্থাপন করার জন্য একটি সামঞ্জস্যপূর্ণ উপায় বেছে নিন।

## Map মডিউলের ফাংশন

এলিক্সির ম্যাপ নিয়ে কাজ করার জন্য _Map মডিউলে_ অনেক ফাংশন প্রদান করে। কিছু _Map মডিউল_ ফাংশনে ম্যাপ ট্রান্সফরমেশনে সহায়তা করার জন্য ফাংশনের ভেতরে একটি _অ্যানোনিমাস_ ফাংশন পাস করতে হয়।
