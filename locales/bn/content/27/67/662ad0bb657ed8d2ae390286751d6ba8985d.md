# পরিচিতি

কোনো কিছুকে তার নিজেরই সাপেক্ষে সংজ্ঞায়িত করার এই ক্ষমতাকে রিকার্সন বলা হয়। F#-এ রিকার্সন সবচেয়ে বেশি দেখা যায় রিকার্সিভ ফাংশনে, অর্থাৎ এমন ফাংশনে যা নিজেকে নিজেই কল করে।

একটি রিকার্সিভ ফাংশনে অন্তত একটি _বেস কেস_ এবং অন্তত একটি _রিকার্সিভ কেস_ থাকতে হয়। একটি _বেস কেস_ ফাংশনটিকে আর কল না করেই একটি মান রিটার্ন করে। আর একটি _রিকার্সিভ কেস_ ফাংশনটিকে আবার কল করে, তবে ইনপুট এমনভাবে বদলে দেয় যাতে একসময় সেটি বেস কেসের সঙ্গে মিলে যায়।

রিকার্সিভ ফাংশন সাধারণ ফাংশনের মতোই ডিফাইন করা হয়, তবে `rec` মডিফায়ার দিয়ে। এই মডিফায়ার ছাড়া একটি ফাংশন নিজেকে নিজে কল করতে _পারবে না_, আর এমন চেষ্টা করলে কম্পাইলেশন এরর হবে। তাই রিকার্সন ব্যবহার করতে হলে তা স্পষ্টভাবে বেছে নিতে হয়।

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# ডিসক্রিমিনেটেড ইউনিয়ন টাইপের মাধ্যমে রিকার্সিভ টাইপও সাপোর্ট করে। একটি রিকার্সিভ ডিসক্রিমিনেটেড ইউনিয়ন টাইপের এক বা একাধিক কেস তাদের ডেটার মধ্যে ওই ডিসক্রিমিনেটেড ইউনিয়ন টাইপটিকেই নির্দেশ করে। রিকার্সিভ ফাংশনের মতোই রিকার্সিভ টাইপেও একটি বেস কেস থাকতে হয়। তবে রিকার্সিভ ফাংশনের বিপরীতে রিকার্সিভ টাইপ `rec` কিওয়ার্ড ব্যবহার করে না।

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
