# ভূমিকা

একটি টাপল হলো মানের একটি ক্রমবদ্ধ কন্টেইনার। Gleam-এর সব ডেটা টাইপের মতো টাপলও অপরিবর্তনীয়। একটি টাপলের প্রতিটি এলিমেন্ট ভিন্ন টাইপের হতে পারে, এমনকি সেগুলো অন্য টাপলও হতে পারে।

টাপলকে `#(` এবং `)`-এর মধ্যে কমা দিয়ে আলাদা করা মান হিসেবে ডিফাইন করা হয়: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

একই দৈর্ঘ্য এবং একই টাইপের (একই ক্রমে) টাপলকে সমতা যাচাইয়ের জন্য তুলনা করা যায়।

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

একটি টাপল থেকে এর ভিতরের মানগুলো বের করার তিনটি উপায় আছে:

- ইনডেক্সিং।
- `let` দিয়ে প্যাটার্ন ম্যাচিং।
- `case` দিয়ে প্যাটার্ন ম্যাচিং।

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

টাপল ইনডেক্সিং case এক্সপ্রেশনের গার্ডে ব্যবহার করা যায়।

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
