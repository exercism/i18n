# পরিচিতি

Common Lisp-এ The Printer নামে একটি ধারণা আছে, যার মধ্যে Lisp ডেটার টেক্সটুয়াল রূপ লেখার সব ফাংশন অন্তর্ভুক্ত। এমন একটি ফাংশন হলো `format`, যা দিয়ে প্রোগ্রামার তাঁর ইচ্ছেমতো ডেটা ফরম্যাট করতে পারেন।

`format`-এর ক্ষমতা এবং সাধারণভাবে Lisp Printer-এর ক্ষমতা একটি বিশাল বিষয়; এখানে `format` ব্যবহারের মূল বিষয়গুলো বর্ণনা করা হবে।

## FORMAT ফাংশন

`format` ফাংশনটি অন্তত দুটি আর্গুমেন্ট নেয়: যে স্ট্রিমে প্রিন্ট করা হবে সেটি, এবং একটি কন্ট্রোল স্ট্রিং, যা ঠিক করে দেয় কী প্রিন্ট হবে আর কীভাবে হবে।

স্ট্রিম নিজেই আলাদা একটি ধারণা, যা অন্যত্র বর্ণনা করা হবে। তবে আপাতত শুধু এটুকু জানলেই যথেষ্ট যে প্রিন্টিং হয় স্ট্রিমে, আর এই আর্গুমেন্টের জন্য দুটি বিশেষ মান আছে: `t` এবং `nil`। `t` মানে স্ট্যান্ডার্ড আউটপুটে প্রিন্ট করা (আসলে যে স্ট্রিমে `*standard-output*` ভ্যারিয়েবলটি বাঁধা থাকে)। আর `nil` মানে একটি স্ট্রিং তৈরি করে সেটি রিটার্ন করা।

মনে রাখুন, `format` সর্বদা `nil`-এ ইভ্যালুয়েট হয়, কেবল শেষের সেই ক্ষেত্রে ছাড়া, যেখানে স্ট্রিম হিসেবে `nil` দেওয়া হয়। সাধারণ স্ট্রিং ইন্টারপোলেশন বা স্ট্রিং তৈরি করার একটি কমন উপায় এটি।

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## ফরম্যাট ডিরেক্টিভ

কন্ট্রোল স্ট্রিং-এ "ফরম্যাট ডিরেক্টিভ" থাকতে পারে, যেগুলো `format`-কে নির্দেশ দেয় কী প্রিন্ট করতে হবে এবং `format`-এর অন্য যেকোনো প্যারামিটার কীভাবে ব্যাখ্যা করতে হবে। এক অর্থে কন্ট্রোল স্ট্রিং হলো একটি প্রোগ্রাম, যেটি `format` ইন্টারপ্রেট করে রান করে। সব ডিরেক্টিভ শুরু হয় `~` দিয়ে এবং তারপর আসে একটি ক্যারেক্টার (_যেমন_ `~A`, `~D`, `~&`)। ক্যারেক্টারটি বড় হাতের না ছোট হাতের, তা কোনো ব্যাপার নয়।

বেশিরভাগ ফরম্যাট ডিরেক্টিভ কেবল `format`-এর একটি আর্গুমেন্ট আউটপুটে ইন্টারপোলেট করে। এটিকে বলা হয় আর্গুমেন্টটি "কনজিউম" করা। কিছু ডিরেক্টিভ কোনো আর্গুমেন্ট কনজিউম করে না, আবার কিছু একাধিক কনজিউম করে। এমনকি একটি ডিরেক্টিভ দিয়ে আর্গুমেন্টগুলোর মধ্যে এদিক-ওদিক লাফানো বা আর্গুমেন্ট বাদ দেওয়া যায়।

## মৌলিক ফরম্যাটিং

খুবই সাধারণ-উদ্দেশ্যের একটি ফরম্যাট ডিরেক্টিভ হলো `~A`। এটি ডেটার একটি 'মানুষের পড়ার উপযোগী' রূপ প্রিন্ট করে।

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

আরেকটি কাজের ফরম্যাট ডিরেক্টিভ হলো `~S`। এটি ডেটার একটি 'মেশিনের পড়ার উপযোগী' রূপ প্রিন্ট করে। তৈরি হওয়া আউটপুটকে Lisp ডেটা হিসেবে ব্যাখ্যা করতে চাইলে এটি খুবই কাজে লাগতে পারে। অনেক জিনিসের ক্ষেত্রেই এটি `~A`-এর মতোই দেখাবে, তবে খেয়াল করুন, যেমন স্ট্রিংয়ের ক্ষেত্রে আউটপুটে কোটেশন চিহ্নও থাকবে (অন্য একটি স্ট্রিংয়ের ভেতরে এলে সেগুলো এস্কেপ করা থাকে), যাতে মানটি আবার স্ট্রিং প্যারামিটার হিসেবে পড়া যায়।

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

আরও দুটি খুব কাজের ডিরেক্টিভ হলো `~%` এবং `~&`। প্রথমটি একটি নিউলাইন ক্যারেক্টার আউটপুট করে, আর দ্বিতীয়টি আউটপুট করে একটি "ফ্রেশ লাইন"। পার্থক্য হলো, `~%` সব সময় একটি নিউলাইন দেয়, আর `~&` একটি দেয় তখনই, যখন বর্তমানে লাইনের শুরুতে নেই। এদের কোনোটিই কোনো আর্গুমেন্ট কনজিউম করে না।

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

সবশেষে, `~~` একটি সরল ডিরেক্টিভ, যা একটি আক্ষরিক `~` আউটপুট করে।
