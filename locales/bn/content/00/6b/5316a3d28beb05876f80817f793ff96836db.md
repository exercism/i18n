# সম্পর্কে

Elixir-এ ফাংশন ডাইনামিকভাবে ডিসপ্যাচ করা যায়।

সব মডিউলের নামই অ্যাটম। কম্পাইল হওয়ার সময় Elixir-এর সব মডিউলের নামের সামনে স্বয়ংক্রিয়ভাবে `Elixir.` যোগ হয়ে যায়।

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir রানটাইমে ঠিক করে দিতে পারে কোন ফাংশনটি কল হবে, আর এর জন্য মডিউলের নাম ব্যবহার করে লুকআপ করে। মডিউলের নামটি যদি কোনো ভ্যারিয়েবলে বাঁধা থাকে, তাহলে সেই লুকআপ ডাইনামিকভাবে করা যায়।

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
