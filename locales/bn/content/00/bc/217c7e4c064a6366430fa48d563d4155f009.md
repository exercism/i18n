# পরিচিতি

JavaScript-এ শর্তসাপেক্ষে লজিক চালানোর একটি কমন উপায় হলো `if` স্টেটমেন্ট। এটি `if` কিওয়ার্ড, প্রথম বন্ধনীতে মোড়ানো একটি শর্ত এবং দ্বিতীয় বন্ধনীতে মোড়ানো একটি কোড ব্লক দিয়ে গঠিত। শর্তটি `true` হলে কেবল তখনই কোড ব্লকটি চালানো হবে।

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

এটি একা ব্যবহার করা যায়, আবার `else` কিওয়ার্ডের সাথে মিলিয়েও ব্যবহার করা যায়।

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

`else` স্টেটমেন্টের ভেতরে আরেকটি শর্ত নেস্ট করতে আপনি `else if` ব্যবহার করতে পারেন।

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
