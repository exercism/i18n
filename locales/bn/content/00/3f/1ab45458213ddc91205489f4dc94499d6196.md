# পরিচিতি

একটি `Tuple` অনেক দিক থেকেই একটি `Vector` (একমাত্রিক `array`)-এর সঙ্গে বেশ মিল। তবে কয়েকটি গুরুত্বপূর্ণ পার্থক্যও আছে।

- টিউপল লেখা হয় প্রথম বন্ধনী `( )` দিয়ে, তৃতীয় বন্ধনী `[ ]` দিয়ে নয়; তবে যেখানে অর্থ স্পষ্ট, সেখানে বন্ধনী বাদ দেওয়া যায়।
- টিউপল সমজাতীয় হওয়া আবশ্যক নয়: প্রতিটি এলিমেন্টের টাইপ আলাদাভাবে সংরক্ষিত থাকে।
- টিউপল ইমিউটেবল।

ইমিউটেবিলিটির কারণে কম্পাইলার আরও অপটিমাইজেশন করতে পারে এবং ভেক্টরের চেয়ে টিউপল বেশি পারফরম্যান্ট হয়, তাই যেখানে মিউটেবিলিটি দরকার নেই সেখানে টিউপল ব্যবহার করাই ভালো।

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

এছাড়া একটি `Tuple()` কনস্ট্রাক্টরও আছে, যা যেকোনো ইটারেবল কালেকশনকে টিউপলে পরিণত করে। সুবিধাজনকভাবে, এটি একটি স্ট্রিংকে ক্যারেক্টারের ইটারেবল কালেকশন হিসেবে ধরে।

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

যেকোনো টিউপলের ক্ষেত্রেই ইনডেক্স দিয়ে এলিমেন্ট অ্যাক্সেস করা বা তাদের উপর লুপ চালানো সম্ভব।

শুধু সংখ্যা দিয়ে গঠিত যেকোনো টিউপল অ্যারেগুলোর মতোই `sum()` ইত্যাদি গাণিতিক ফাংশনেও ব্যবহার করা যায়।

## আনপ্যাকিং

মাল্টিপল অ্যাসাইনমেন্ট ব্যবহার করে একটি টিউপলকে আলাদা আলাদা এলিমেন্টে আনপ্যাক করা যায়। যে এলিমেন্টগুলো দরকার নেই, সেগুলোর জন্য ডামি ভ্যারিয়েবল হিসেবে আন্ডারস্কোর `_` ব্যবহার করুন।

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Python প্রোগ্রামারদের কাছে এই মাল্টিপল-অ্যাসাইনমেন্ট সিনট্যাক্স খুব চেনা লাগবে।

## নেমড টিউপল

একটি `Tuple` কেবল মান ধারণ করে। একটি `NamedTuple` প্রতিটি মানের সঙ্গে একটি নাম জুড়ে দেয়।

এরপর আলাদা আলাদা ফিল্ড "ডট" নোটেশন দিয়ে অ্যাক্সেস করা যায়:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

নামটি অভ্যন্তরীণভাবে একটি `Symbol` হিসেবে সংরক্ষিত থাকে (এটি একটি ইমিউটেবল টাইপ, আর নামের আগে কোলন `:` বসানো হয়), তাই একটি বিকল্প সিনট্যাক্সও পাওয়া যায়:

```julia-repl
julia> nt[:b]
7.3
```

নামগুলো (যাদের "কী (key)"-ও বলা হয়) বা মানগুলো আলাদাভাবে বের করা সহজ:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

লক্ষ্য করুন, একটি নেমড টিউপলের উপর ইটারেশন করলে শুধু _মানগুলো_ পাওয়া যায়, _নামগুলো_ উপেক্ষিত থাকে।

টিউপল (নেমড হোক বা না হোক) ফাংশনে স্ট্রাকচার্ড ডেটা পাঠানো-আনায় খুব কমন একটি উপায়। এই ক্ষেত্রে ইমিউটেবিলিটি ভালো, কারণ এটি ডেটার নিরাপত্তা দেয় এবং কম্পাইলারকে আরও জোরালো অপটিমাইজেশনের সুযোগ দেয়।
