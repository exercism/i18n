# পরিচিতি

কখনও কখনও কোনো সিকোয়েন্সকে এলিমেন্টের পর এলিমেন্ট না ভেবে বরং *টুকরো*-র একটি সিরিজ হিসেবে দেখার দরকার পড়ে। [`grouping`][grouping], [`splitting`][splitting] এবং [`splitting.monotonic`][splitting.monotonic] ভোকাবুলারিগুলি সেটি করার চারটি উপায় দেয়।

## `group`: *n* আকারের আলাদা আলাদা খণ্ড

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

সিকোয়েন্সের দৈর্ঘ্য যদি *n*-এর গুণিতক না হয়, তাহলে শেষ গ্রুপটি *n*-এর চেয়ে ছোট হয়।

## `clump`: *n* আকারের ওভারল্যাপিং স্লাইডিং উইন্ডো

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

সিকোয়েন্সটি *n*-এর চেয়ে ছোট হলে ফলাফল খালি হয়।

## `split-when`: প্রেডিকেট যেখানেই সত্য হয়, সেখানেই ভাগ

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

প্রতিটি এলিমেন্টের জন্য আলাদাভাবে প্রেডিকেট কল করা হয়; যে এলিমেন্টগুলির জন্য প্রেডিকেট সত্য হয় সেগুলিই *ব্রেক পয়েন্ট* এবং সেগুলি ফলাফলে রাখা হয় না।

## `monotonic-split`: সন্নিহিত জোড়ার পরীক্ষা যেখানে ব্যর্থ হয়, সেখানে রান ভাঙুন

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

প্রেডিকেটটি চলে *সন্নিহিত জোড়া*-র উপর। যতক্ষণ এটি সত্য রিটার্ন করে, ততক্ষণ রান চলতে থাকে; এটি `f` রিটার্ন করলে একটি নতুন টুকরো শুরু হয়। `[ = ]` দিয়ে পাবেন সমান এলিমেন্টের রান; `[ <= ]` দিয়ে পাবেন অ-হ্রাসমান রান; ইত্যাদি।

## কখন কোনটি ব্যবহার করবেন

- **`group`/`clump`**: আপনি জানেন আপনি কোন *আকার* চান।
- **`split-when`**: আপনি জানেন একটি *ব্রেক এলিমেন্ট* দেখতে কেমন হয়।
- **`monotonic-split`**: আপনি জানেন কোন জিনিসে দুটি সন্নিহিত এলিমেন্ট *এখনও একসাথে থাকে*।
