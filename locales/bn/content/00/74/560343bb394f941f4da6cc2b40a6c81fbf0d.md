# নির্দেশাবলি

একটি অক্টাল সংখ্যাকে, যা একটি স্ট্রিং আকারে দেওয়া থাকে (যেমন '1735263'), মৌলিক নীতি ব্যবহার করে তার দশমিক সমতুল্যে রূপান্তর করুন (অর্থাৎ না, এই রূপান্তরটি করতে আপনি বিল্ট-ইন বা বাইরের কোনো লাইব্রেরি ব্যবহার করতে পারবেন না)।

অক্টাল থেকে দশমিকে রূপান্তর ইমপ্লিমেন্ট করুন।
একটি অক্টাল ইনপুট স্ট্রিং দেওয়া হলে, আপনার প্রোগ্রামের একটি দশমিক আউটপুট তৈরি করা উচিত।

## নোট

- রূপান্তরটি আপনি নিজে ইমপ্লিমেন্ট করুন।
  রূপান্তরটি আপনার হয়ে করার জন্য অন্য কোনো কিছু ব্যবহার করবেন না।
- অবৈধ ইনপুটকে অক্টাল ০ হিসেবে ধরুন।

## অক্টাল সম্পর্কে (বেস-৮)

দশমিক হলো একটি বেস-১০ পদ্ধতি।

বেস-১০ স্বরলিপিতে লেখা একটি সংখ্যা ২৩৩-কে ১০-এর ঘাতগুলোর একটি রৈখিক সমন্বয় হিসেবে বোঝা যায়:

- একেবারে ডান দিকের অঙ্কটি ১০^০ = ১ দিয়ে গুণ করা হয়
- পরের সংখ্যাটি ১০^১ = ১০ দিয়ে গুণ করা হয়
- ...
- n-তম সংখ্যাটি ১০^_(n-১)_ দিয়ে গুণ করা হয়।
- এই সব মান যোগ করা হয়।

তাহলে:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

অক্টালও একই রকম, তবে ১০-এর ঘাতের বদলে ৮-এর ঘাত ব্যবহার করে।

তাহলে:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
