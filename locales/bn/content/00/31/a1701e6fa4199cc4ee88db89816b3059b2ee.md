# ভূমিকা

Go-তে একটি `string` হলো বাইটের একটি অপরিবর্তনীয় ক্রম, যা অগত্যা অক্ষর প্রকাশ করতেই হবে এমন নয়।

একটি স্ট্রিং লিটারাল ডাবল কোটেশনের মধ্যে সংজ্ঞায়িত করা হয়:

```go
const name = "Jane"
```

`+` অপারেটর দিয়ে স্ট্রিংগুলোকে সংযুক্ত করা যায়:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

কিছু বিশেষ অক্ষরকে একটি অগ্রগামী ব্যাকস্ল্যাশ দিয়ে এস্কেপ করতে হয়, যেমন স্ট্রিংয়ে ট্যাবের জন্য `\t` এবং নতুন লাইনের জন্য `\n`।

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings` প্যাকেজটিতে স্ট্রিং নিয়ে কাজ করার জন্য অনেক দরকারী ফাংশন রয়েছে।
স্ট্রিং ফাংশন সম্পর্কে আরও তথ্যের জন্য, [strings প্যাকেজ ডকুমেন্টেশন](https://pkg.go.dev/strings) দেখুন।
এখানে কিছু উদাহরণ দেওয়া হলো:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
