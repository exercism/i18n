# ইঙ্গিত

আপনার কোডে একটি frequency :: Int -> [Text] -> Map Char Int ফাংশন থাকা উচিত, যা সমান্তরালে ব্যবহারের জন্য ওয়ার্কারের একটি সংখ্যা এবং টেক্সটের একটি তালিকা নেয়, আর টেক্সটে প্রতিটি অক্ষরের মোট ফ্রিকোয়েন্সি ফিরিয়ে দেয়।

## বেঞ্চমার্ক

বেঞ্চমার্ক চালিয়ে দেখুন, ওয়ার্কারের সংখ্যা বদলালে আপনার সমাধানের পারফরম্যান্সে কী পরিবর্তন আসে। এটি চালাতে `stack bench` ব্যবহার করুন। ভিন্ন ভিন্ন ইনপুটে আপনার সমাধানের পারফরম্যান্স কেমন হয় তা জানতে `bench/Benchmark.hs` নির্দ্বিধায় পরিবর্তন করতে পারেন।
