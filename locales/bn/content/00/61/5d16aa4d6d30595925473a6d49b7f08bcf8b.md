# নির্দেশনা

সার্কাসের প্রতিটি হারনেস কিলোগ্রামে একটি লোডের জন্য নির্ধারিত, আর সংখ্যাগুলো যাচাই না হওয়া পর্যন্ত কেউ উপরে ওঠে না।

`SAFETY_HARNESS` ক্লাসের যা যা দরকার তা নিচে দেওয়া। স্টাব আপনাকে ক্লাসটি ও তার অ্যাট্রিবিউট দিয়ে দেয়; বাকিটা আপনি যোগ করুন। নিচের প্রতিটি রুটিনের সাথে একটি কনট্রাক্ট যুক্ত, আর কোনটি কী, তা ইঙ্গিতগুলোতে বলা আছে।

## 1. একটি হারনেস তৈরি করুন

`create` হারনেসটি যে লোডের জন্য নির্ধারিত, সেই লোড নেয় এবং একটি হারনেস ফিরিয়ে দেয়। শূন্য বা তার কম রেটিং কোনো হারনেসই নয়, তাই সেটি একটি `pre`।

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. কতটা বাড়তি আছে?

`spare_capacity` হারনেসের উপর থাকা লোড নেয় এবং আর কতটা নিতে পারবে তা রিটার্ন করে। লোড ঋণাত্মক হতে পারবে না, আর সীমার বেশি-ও হতে পারবে না, দুটোই `pre`। উত্তরটি কখনো ঋণাত্মক হয় না, যেটি একটি `post`।

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. এটা কতটা ভরা?

`percent_used` লোড নেয় এবং সীমার শতকরা হিসেবে তা রিটার্ন করে, নিচের দিকে রাউন্ড করে। লোড ঋণাত্মক হতে পারবে না, আর উত্তরটিও কখনো ঋণাত্মক হয় না।

```sather
harness.percent_used(60)
-- => 50
```

## 4. এটা কি নিরাপদ?

`is_safe` লোড নেয় এবং তা সীমার ভেতরে আছে কি না, তা জানায়। যেকোনো লোড নিয়েই জিজ্ঞেস করা যেতে পারে, এমনকি হাস্যকর লোডও, তাই লোডের উপর কোনো `pre` নেই। তবে একটি `post` লিখুন যেখানে বলা থাকবে, লোড সীমার ভেতরে থাকলে ঠিক তখনই উত্তরটি ট্রু হয়।

```sather
harness.is_safe(200)
-- => false
```
