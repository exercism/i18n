# পরিচিতি

## ক্লাস

ক্লাস হলো PHP-তে কোড সংগঠনের একটি একক। কোনো বস্তুর আচরণ বা কোনো প্রক্রিয়ার আচরণ প্রকাশ করে এমন কোডকে একটি ক্লাস হিসেবে একসাথে গোষ্ঠীভুক্ত করা যায়। কোনো ক্লাসের সাথে যুক্ত করা ফাংশনগুলোকে প্রচলিতভাবে `methods` বলা হয়।

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

ক্লাস ইন্সট্যান্টিয়েট করা হয় `new` কিওয়ার্ড দিয়ে; এটি ক্লাস ইন্সট্যান্সের জন্য মেমোরি অ্যালোকেট করে এবং ক্লাসের কনস্ট্রাক্টর মেথড কল করে। ইন্সট্যান্টিয়েট করা ক্লাস একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়। ক্লাস ইন্সট্যান্সের মেথডগুলো কল করার জন্য আমরা `->` অ্যাকসেস অপারেটর ব্যবহার করতে পারি।

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

ইন্সট্যান্টিয়েট করা একটি ক্লাস বিশেষ `$this` ভ্যারিয়েবল ব্যবহার করে তার নিজের ইন্সট্যান্সকে রেফার করতে পারে। ক্লাসে প্রপার্টিও থাকতে পারে; এগুলো ক্লাস অবজেক্টের ইন্সট্যান্সের সাথে বাঁধা ভ্যারিয়েবলের মতো কাজ করে। এই প্রপার্টিগুলো অভ্যন্তরীণভাবে বা বাহ্যিকভাবে রেফার করা যায়।

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
