# টেস্ট

টেস্ট রানার ব্যবহার করতে হলে আপনার [Godot সঠিকভাবে ইনস্টল করা][installation] থাকা দরকার।

## টেস্ট চালানো

সলুশন লোড ও টেস্ট করতে [টেস্ট রানারটি][test runner] ব্যবহার করা হয়।
টেস্ট রানারটি চালাতে হলে, প্রথমে এটি ডাউনলোড করুন, তারপর টেস্ট রানারটি চালাতে `godot` ব্যবহার করুন।
ভবিষ্যতে, `exercism download` ব্যবহার করলে অনুশীলনীগুলোর সাথে টেস্ট রানারটি স্বয়ংক্রিয়ভাবে ডাউনলোড হয়ে যাবে।

### টেস্ট রানার সংগ্রহ করা

টেস্ট রানারটি ডাউনলোড করতে নিচের শেল স্নিপেটটি ব্যবহার করা যেতে পারে।

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### টেস্ট রানার চালানো

টেস্ট রানারটি হেডলেস মোডে (কোনো IDE ছাড়াই) `godot` দিয়ে চালানো হয়।
`-s` বা `--script` Godot-কে টেস্ট রানার স্ক্রিপ্টটি চালাতে বলে।
টেস্ট রানার দুটি আর্গুমেন্ট আশা করে: স্লাগ এবং সলুশন ডিরেক্টরির পাথ।

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

যেমন,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
