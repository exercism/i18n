# মূল বিষয়

একটি Sather প্রোগ্রাম তৈরি হয় **ক্লাস** দিয়ে। একটি ক্লাস হলো নাম দেওয়া একটি বাক্স, যার ভেতরে থাকে রুটিন। একটি **রুটিন** হলো নাম দেওয়া কাজের একটি টুকরো, যা একটি উত্তর তৈরি করে।

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

উপর থেকে পড়লে:

- `class GREETER is` বাক্সটি খোলে এবং তার নাম দেয়। ক্লাসের নাম লেখা হয় বড় হাতের অক্ষরে।
- `hello : STR is` শুরু করে `hello` নামের একটি রুটিন, যা একটি `STR` তৈরি করে, অর্থাৎ এক টুকরো টেক্সট, যাকে বলা হয় *স্ট্রিং*। `: STR` হলো একটি প্রতিশ্রুতি, কোন ধরনের উত্তর ফিরে আসবে তা নিয়ে।
- `return "Hello!";` উত্তরটি ফিরিয়ে দেয়। টেক্সট লেখা হয় ডাবল কোটের ভেতরে।
- `end;` রুটিনটি বন্ধ করে, আর দ্বিতীয় `end;` ক্লাসটি বন্ধ করে।

একটি লাইনে `--` এর পরের সবকিছুই একটি **কমেন্ট**। Sather এটি উপেক্ষা করে; এটি রাখা আছে মানুষের জন্য।

```sather
-- This line is for the reader, not the computer.
```

অন্য কোথাও থেকে একটি রুটিন ব্যবহার করতে হলে লিখুন ক্লাসের নাম, দুটি কোলন, আর রুটিনের নাম:

```sather
GREETER::hello        -- this is "Hello!"
```

একই ক্লাসের ভেতরে আপনি ক্লাসের নাম বাদ দিতে পারেন:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

যে রুটিন কোনো আর্গুমেন্ট নেয় না, তাকে বন্ধনী ছাড়াই কল করা হয়: `hello`, `hello()` নয়।
