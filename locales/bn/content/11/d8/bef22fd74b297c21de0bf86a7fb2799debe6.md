# নির্দেশনা

আপনি বেরিং প্রণালী পাড়ি দেওয়া একটি কাটারের ওয়াচ অফিসার। দৃষ্টিসীমার মধ্যে থাকা প্রতিটি বরফের চাঁই আর অন্তরীপের অবস্থান তিনটি উৎস জানিয়ে দিচ্ছে:

- **চার্ট ডেস্ক** কথা বলে কম্পাস দিকের ভাষায়: `north`, `east`, `south`, `west`। শুধু একটি হেডিং, দূরত্ব নয়।
- **ন্যাভিগেটর** কথা বলে কাটারের সর্বশেষ অবস্থান নির্ণয় থেকে মাপা *পোলার* স্থানাঙ্কে: নটিক্যাল মাইলে একটি ম্যাগনিচিউড, আর north থেকে ঘড়ির কাঁটার দিকে ডিগ্রিতে একটি বিয়ারিং (তাই `0` মানে north, `90` মানে east, `180` মানে south, `270` মানে west)।
- **মাস্তুলের চূড়ার প্রহরী** কথা বলে *আপেক্ষিক* স্থানাঙ্কে: সামনের দিকে একটি দূরত্ব, আর `ahead`, `starboard`, `behind`, `port`-এর একটি। আপেক্ষিক বিয়ারিং মাপা হয় *জাহাজের বর্তমান হেডিং* সাপেক্ষে, যে হেডিং ক্যাপ্টেন প্রতিটি ওয়াচ শুরুর আগে ব্রিজে ঘোষণা করেন।

আপনার কাজ হলো তিনটিকেই একটি সাধারণ কার্তেসীয় `(x, y)` ফ্রেমে রূপান্তর করা, যাতে চার্টটি প্লট করা যায়। বিয়ারিং ডিগ্রিতে মাপা হয়; `(0, 1)` হলো north দিকে এক নটিক্যাল মাইল, `(1, 0)` হলো east দিকে এক নটিক্যাল মাইল।

## 1. ডেটা মডেল, আর কার্ডিনালের জন্য কার্তেসীয়

প্রথমে পুরো অনুশীলনী জুড়ে যে অংশগুলো ব্যবহৃত হয়, সেগুলো গুছিয়ে নিন:

- তিনটি টাপল ডিফাইন করুন: `cardinal` (একটি স্লট, `direction`), `polar` (স্লট `magnitude` আর `bearing`), এবং `relative` (স্লট `distance` আর `bearing`)।
- `SYMBOLS:` দিয়ে দিকের সিম্বলগুলো ডিক্লেয়ার করুন: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`।
- `SYMBOL:` দিয়ে একটি ডাইনামিক ভ্যারিয়েবল `heading` ডিক্লেয়ার করুন (টাস্ক ৩-এ এটি ব্যবহার করা হয়)।
- দুটি জেনেরিক শব্দ ডিক্লেয়ার করুন: `GENERIC: >cartesian ( direction -- x y )` এবং `GENERIC: flip ( direction -- direction' )`। পরের টাস্কগুলোতে আপনি এগুলোর মেথড যোগ করবেন।

তারপর `>cartesian`-এর `M: cardinal` মেথডটি যোগ করুন, যা উল্লিখিত দিকের জন্য ইউনিট ভেক্টর রিটার্ন করে।

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. পোলারের জন্য কার্তেসীয়

`>cartesian`-এ একটি `M: polar` মেথড যোগ করুন, যা পোলার রূপকে `(x, y)`-তে রূপান্তর করে:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. আপেক্ষিকের জন্য কার্তেসীয়

`>cartesian`-এ একটি `M: relative` মেথড যোগ করুন। এখানেই আসল চমক: একটি আপেক্ষিক বিয়ারিং মাপা হয় জাহাজের *বর্তমান হেডিং* সাপেক্ষে, যা টাপলের অংশ নয়। `heading get` দিয়ে `heading` ভ্যারিয়েবলটি (টাস্ক ১-এ ডিক্লেয়ার করা) পড়ুন, বিয়ারিং অফসেটটি যোগ করুন (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`), এবং কার্তেসীয় বিন্দুটি বের করুন। কলার একটি `with-variable` ব্লকের ভেতরে `heading` সেট করে।

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. ফ্লিপ

`flip` জেনেরিকের (টাস্ক ১-এ ডিক্লেয়ার করা) মেথডগুলো যোগ করুন, যাতে এটি বিপরীত দিক রিটার্ন করে।

- `cardinal`-এর জন্য: north ↔ south, east ↔ west।
- `polar`-এর জন্য: বিয়ারিংয়ের সাথে ১৮০° যোগ করুন (মডুলো ৩৬০)।
- `relative`-এর জন্য: ahead ↔ behind, starboard ↔ port।

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. বিয়ারিং যোগ করা

`add-bearings ( a b -- x y )` ডিফাইন করুন, যা দুই দিককেই কার্তেসীয়ে রূপান্তর করে এবং তাদের যোগফল রিটার্ন করে। এটি `cardinal`, `polar` আর `relative`-এর যেকোনো মিশ্রণে কাজ করে, এটাই `>cartesian`-এর জন্য জেনেরিক ব্যবহার করার আসল লাভ।

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
