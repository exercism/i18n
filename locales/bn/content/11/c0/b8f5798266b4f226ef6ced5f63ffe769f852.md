# পরিচিতি

## অ্যারে ইটারেশন

একটি `for` লুপ দিয়ে একটি অ্যারের উপর ইটারেশন করা যায় এবং প্রতিটি এলিমেন্টের জন্য কোডটি বারবার চালানো যায়:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

উপরের উদাহরণে, `fruit` হলো সেই ভ্যারিয়েবল যেটি `fruitList` অ্যারের একটি আলাদা এলিমেন্টের মান ধারণ করে। কম্পাইলার নিশ্চিত করে যে `fruitList` অ্যারে ইটারেট করা সম্ভব, নাহলে এটি এক্সিকিউশন থামিয়ে দেবে।

## রেঞ্জ ইটারেশন

রেঞ্জ অপারেটর ব্যবহার করে সংখ্যার উপর ইটারেশন করা যায়। অপারেটরটি দুটি `Int` অপারেন্ড নেয় এবং `min...max` আকারে লেখা হয়। এখানে `min` অন্তর্ভুক্ত আর `max` বহির্ভূত (`min` <= i AND `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## কী (key)-ভ্যালু ইটারেশন

কী (key)-ভ্যালু জোড়ার কালেকশনের উপরও ইটারেশন করা সম্ভব। সিনট্যাক্সে একমাত্র পার্থক্য হলো, একটি মাত্র ভ্যারিয়েবলের বদলে একটি কী (key) ভ্যারিয়েবল আইডেন্টিফায়ার লেখা হয়, তারপর `=>`, তারপর ভ্যালু ভ্যারিয়েবল আইডেন্টিফায়ার:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
