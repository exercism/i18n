# ইনস্টলেশন

## Dart ইনস্টল করা

Dart SDK ইনস্টল করার নির্দেশনা Dart-এর ওয়েবসাইটে পাওয়া যাবে: [Dart সংগ্রহ করুন][get-dart]

## আপনার IDE বা এডিটরের জন্য Dart প্লাগইন

আপনি যদি কোনো IDE বা এডিটর ব্যবহার করেন এবং আপনার পছন্দের এডিটরের জন্য Dart প্লাগইনটি থাকে, তাহলে [একটি Dart প্লাগইন যোগ করুন][editors]।

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
