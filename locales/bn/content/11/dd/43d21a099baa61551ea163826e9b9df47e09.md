# নির্দেশনা

আপনি প্রাগে ভ্লতাভা নদীর তীরে একটি ছোট্ট আবহাওয়া স্টেশন চালান, আর প্রতি শিফটে তাপমাত্রার রিডিংগুলো একটি প্লেইন-টেক্সট লগে টুকে রাখেন, প্রতি লাইনে একটি করে রিডিং। পাঁচটি ছোট শব্দেই এক শিফটের হিসাব-নিকাশ সামলে দেয়।

প্রতিটি শব্দকে লগ ফাইলের পাথ দেওয়া হয়।

## 1. প্রতিটি রিডিং পড়ুন

`read-readings` ডিফাইন করুন, যাতে এটি লগের সব রিডিং স্ট্রিংয়ের একটি অ্যারে হিসেবে রিটার্ন করে, প্রতি লাইনে একটি করে।

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. সর্বশেষ রিডিং খুঁজুন

`latest-reading` ডিফাইন করুন, যাতে এটি সর্বশেষ রিডিং, অর্থাৎ লগের শেষ লাইনটি রিটার্ন করে।

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. কাঁচা লগ পড়ুন

`log-text` ডিফাইন করুন, যাতে এটি পুরো লগ ফাইলটি একটি একক স্ট্রিং হিসেবে, ফাইলে যেভাবে সংরক্ষিত আছে ঠিক সেভাবেই রিটার্ন করে।

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. একটি রিডিং রেকর্ড করুন

`record-reading` ডিফাইন করুন, যাতে এটি লগের শেষে একটি নতুন রিডিং আলাদা একটি লাইন হিসেবে যোগ করে, আগের রিডিংগুলো অপরিবর্তিত রেখে। এটি কিছুই রিটার্ন করে না।

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. লগ নতুন করে লিখুন

`rewrite-log` ডিফাইন করুন, যাতে এটি পুরো লগকে রিডিংয়ের একটি নতুন অ্যারে দিয়ে প্রতিস্থাপন করে, প্রতি লাইনে একটি করে।

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
