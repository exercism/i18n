# নির্দেশনা

অ্যান্ড্রু তাঁর কোম্পানির একজন ডেভেলপার। সম্প্রতি তিনি একটি ডেটাবেজ মাইগ্রেশন টুলের জন্য হালকা একটি SQL কোয়েরি জেনারেটর ইউটিলিটি তৈরি করেছেন।
ছোট আকারের ডেটার জন্য তাঁর প্রথম সরল বাস্তবায়নটি পুরোপুরি কাজ করেছিল।
তবে বড় প্রোডাকশন মাইগ্রেশনের সময় অ্যাপ্লিকেশনটি অতিরিক্ত মেমরি খরচ করতে শুরু করে এবং ভারী লোডে হিমশিম খেতে থাকে।
অ্যাপ্লিকেশনটি প্রোফাইল করার পর অ্যান্ড্রু বুঝতে পারেন, লুপের ভেতরে সাধারণ স্ট্রিং কনক্যাটেনেশনের কারণে Go বারবার মেমরি রিঅ্যালোকেট করতে বাধ্য হচ্ছিল।
এখন অ্যাপ্লিকেশনটি যাতে ভালোভাবে স্কেল করতে পারে এবং মেমরি হিপ চেপে না ফেলেই বিপুল পরিমাণ টেক্সট সামলাতে পারে, সেজন্য Go-এর `strings.Builder` ব্যবহার করে ইউটিলিটিটি রিফ্যাক্টর করতে তিনি আপনার সাহায্য চান।

## 1. SELECT কোয়েরি তৈরি করুন

`BuildSelectQuery` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি একটি টেবিলের নাম (`string`) এবং কলামের নামের একটি স্লাইস (`[]string`) নেয়।
এটি সেমিকোলন দিয়ে শেষ হওয়া একটি সম্পূর্ণ SQL `SELECT` স্টেটমেন্ট রিটার্ন করবে।
কলামের স্লাইসটি খালি বা `nil` হলে, কোয়েরিটি সব কলাম বাছাই করতে `*` ওয়াইল্ডকার্ড ব্যবহার করবে।

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. ব্যাচ INSERT স্টেটমেন্ট তৈরি করুন

`BuildBatchInserts` ফাংশনটি ইমপ্লিমেন্ট করুন।
এটি একটি টেবিলের নাম (`string`) এবং ডেটাবেজের সারি নির্দেশ করা একটি দ্বিমাত্রিক স্লাইস (`[][]ColumnValue`) নেয়।
একটি সারির প্রতিটি এলিমেন্ট একটি নির্দিষ্ট কলামের নামকে তার স্ট্রিং মানের সাথে যুক্ত করে।
ফাংশনটিকে আলাদা আলাদা `INSERT` SQL স্ট্রিংয়ের একটি স্লাইস রিটার্ন করতে হবে।
স্ট্রাকচার্ড স্লাইস ফরম্যাটটি কোয়েরি আউটপুটের একটি পূর্বানুমেয় ও স্থির ক্রম নিশ্চিত করে।
সারির ইনপুট স্লাইসটি খালি হলে একটি খালি স্ট্রিং স্লাইস রিটার্ন করুন।
কোনো একটি সারি খালি হলে সেটি বাদ দিন।
`VALUES` ক্লজের ভেতরের স্ট্রিং মান অবশ্যই একক কোট `'` দিয়ে ঘেরা থাকবে।

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
