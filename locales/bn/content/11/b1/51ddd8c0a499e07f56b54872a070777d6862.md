# নির্দেশনা সংযোজন

জটিল সংখ্যার সূচকীয়করণের জন্য একটি সূচকীয় ফাংশন, একটি সাইন ও একটি কোসাইন ফাংশন দরকার, যার কোনোটিই WebAssembly-তে পাওয়া যায় না। ভাগ্যক্রমে, এগুলো গণনা করতে একটি [টেলর সিরিজ](https://en.wikipedia.org/wiki/Taylor_series) ব্যবহার করা যায়। প্রত্যাশিত মানগুলোর সাথে মিলতে আপনার অন্তত `1/26!` নির্ভুলতা থাকা উচিত।

## সূচকীয় ফাংশন

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## সাইন ফাংশন

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## কোসাইন ফাংশন

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
