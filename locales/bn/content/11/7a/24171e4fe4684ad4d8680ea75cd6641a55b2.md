## নির্দেশাবলি

আপনাকে একটি রিসাইক্লিং সেন্টারে নিয়োগ করা হয়েছে।
জায়গার অভাবে সব পণ্য একই কনভেয়র বেল্টে রাখা হয়, কিন্তু এর ফলে ভিন্ন ভিন্ন উপাদান একসাথে মিশে যায় এবং সেগুলো ব্যবহারের অযোগ্য হয়ে পড়ে।
এটি ঠিক করার জন্য আপনাকে এমন ফাংশন বানানোর দায়িত্ব দেওয়া হয়েছে, যা কোনো পণ্যের ধরন শনাক্ত করতে পারে।

### 1. একটি মান বুলিয়ান কি না তা যাচাই করুন

`isBoolean` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো মান বুলিয়ান কি না।

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. একটি মান সংখ্যা কি না তা যাচাই করুন

`isNumber` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো মান একটি _সীমাবদ্ধ_ `number` বা `bigint`, অর্থাৎ `NaN` বা `Infinity` নয়।

কখনো কখনো আইডি পড়ার ডিভাইসটি নষ্ট হয়ে যায় এবং কোনো অ-সংখ্যাসূচক মানকে `NaN` (Not a Number, অর্থাৎ সংখ্যা নয়) বা `Infinity` হিসেবে পড়ে।
আপনার ফাংশনের এটি সঠিকভাবে সামলাতে পারা উচিত।

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. একটি মান অবজেক্ট কি না তা যাচাই করুন

`isObject` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করবে যে মানটি একটি অবজেক্ট কি না।
কনভেয়রে `null` কিছুই নয় এবং এটি অবজেক্ট হিসেবে গণ্য হয় না।

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. একটি স্ট্রিং সংখ্যাসূচক কি না তা যাচাই করুন

`isNumericString` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করবে যে মানটি এমন একটি স্ট্রিং কি না, যেটি শুধু অঙ্ক দিয়ে গঠিত, অথবা একটি বিয়োগ চিহ্নের পরে অঙ্ক, যা একটি ঋণাত্মক সংখ্যা বোঝায়।
এখানে কেবল পূর্ণসংখ্যাকে বিবেচনা করতে হবে, রিসাইক্লিং রোবটের এই যাচাইয়ে দশমিক সংখ্যাকে সংখ্যাসূচক হিসেবে গণ্য করা হয় না।

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. একটি অবজেক্ট ইলেকট্রনিক কি না তা যাচাই করুন

`isElectronic` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো অবজেক্ট প্রদত্ত `ElectronicDevice` ক্লাস বা তার কোনো চাইল্ড ক্লাসের ইনস্ট্যান্স কি না।

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. একটি মান অ-খালি অ্যারে কি না তা যাচাই করুন

`isNonEmptyArray` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো মান একটি অ-খালি অ্যারে কি না।

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. একটি মান খালি অ্যারে কি না তা যাচাই করুন

`isEmptyArray` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো মান একটি খালি অ্যারে কি না।

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. একটি অবজেক্টের `type` প্রপার্টি বা মেথড আছে কি না তা যাচাই করুন

`hasType` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো অবজেক্টের `type` প্রপার্টি বা মেথড আছে কি না।

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. কোনো অবজেক্টের `id` প্রপার্টি বা মেথড না থাকলে একটি এরর থ্রো করুন

`assertHasId` ফাংশনটি ইমপ্লিমেন্ট করুন, যা কোনো অবজেক্টে `id` প্রপার্টি না থাকলে একটি `Error` থ্রো করবে।

যদি কোনো অবজেক্টে `id` প্রপার্টি থাকে, তাহলে এটি কিছুই রিটার্ন করা উচিত নয়।

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. কোনো অবজেক্টের `id` প্রপার্টি আছে কি না তা যাচাই করুন

`hasIdProperty` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো অবজেক্টের `id` প্রপার্টি আছে কি না।

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. কোনো অবজেক্টের একটি ডিফাইন করা `type` প্রপার্টি আছে কি না তা যাচাই করুন

`hasDefinedType` ফাংশনটি ইমপ্লিমেন্ট করুন, যা যাচাই করে যে কোনো অবজেক্টের `type` প্রপার্টি আছে এবং তা `undefined` নয় কি না।

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
