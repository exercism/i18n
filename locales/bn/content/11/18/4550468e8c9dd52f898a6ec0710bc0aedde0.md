# নির্দেশনা

টাইপ চেকিং থাকলে HTTP এন্ডপয়েন্ট আরও ভালো হয়। একটি POST রিকোয়েস্টে রেকর্ড টাইপ যোগ করলে প্রতিবারই সঠিক ডেটা পাঠানো নিশ্চিত হয়।

## লক্ষ্যসমূহ

- প্রদত্ত কোডটি পরিবর্তন করুন।
- দুটি অপারেন্ড ও একটি অপারেটর নেওয়ার জন্য প্রয়োজনীয় অ্যাট্রিবিউটগুলো এই রেকর্ডে যোগ করুন।
- '/calc' পাথে POST রিকোয়েস্ট গ্রহণ করার জন্য একটি HTTP রিসোর্স ফাংশন যোগ করুন।
- ফাংশনটি পেলোড হিসেবে Calculation রেকর্ড টাইপটি গ্রহণ করবে এবং একটি জেনেরিক JSON অবজেক্ট রিটার্ন করবে।

### গ্রহণ করে

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### রিটার্ন করে

```json
{ "expression": "4+10.2", "result": 14.2 }
```
