# সম্পর্কে

`TUPLE:` নামযুক্ত স্লট সহ একটি ক্লাস ডিক্লেয়ার করে। Factor স্বয়ংক্রিয়ভাবে একটি কনস্ট্রাক্টর ওয়ার্ড (ক্লাসের নামের শেষে `new` যুক্ত হয়), একটি `boa` ("আর্গুমেন্টের ক্রম অনুযায়ী") কনস্ট্রাক্টর, একটি লিটারেল সিনট্যাক্স `T{ class … }`, এবং প্রতি স্লটের জন্য অ্যাকসেসর ওয়ার্ড তৈরি করে।

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

[`accessors`][accessors]-এর অ্যাকসেসর সিস্টেম প্রতি স্লটের জন্য চারটি রকম দেয়: `name>>`, `>>name`, `change-name`, এবং মিউটেটিং জোড়া `[ … ] change-name`। `>>name` এবং `change-name` টিউপলটি মিউটেট করে; মূল টিউপলটি অপরিবর্তিত রাখতে চাইলে আগে `clone` করুন।

টিউপল স্ট্রাকচারাল ইকুয়ালিটি দিয়ে `=` সমর্থন করে এবং প্রিন্টের সময় ডিফল্ট নয় এমন স্লট মান দেখায়।

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
