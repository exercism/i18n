# পরিচিতি

আগের কনসেপ্টগুলোতে আমরা দেখেছি, Julia-র টাইপগুলো একটি হায়ারার্কি তৈরি করে, যার একেবারে উপরে থাকে `Any`।

`Number`-এর মতো অ্যাবস্ট্রাক্ট টাইপের সাবটাইপ থাকে, কিন্তু সেগুলোকে নিজে থেকে ইনস্ট্যানশিয়েট করা যায় না।
কোনো ভ্যারিয়েবলকে একটি অ্যাবস্ট্রাক্ট টাইপে সেট করলে, ভ্যারিয়েবলটির মানগুলো অ্যাবস্ট্রাক্ট টাইপটির যেকোনো সাবটাইপ হওয়ার মধ্যে _সীমাবদ্ধ_ হয়ে যায়।
যেমন:

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

কোন ইনপুট বৈধ হবে তা সীমাবদ্ধ করার ক্ষেত্রে এটি আমাদের এক ধরনের নমনীয়তা দেয়।

কিন্তু ধরা যাক, আমরা চাই একটি ভ্যারিয়েবল একই সাথে ইন্টিজার আর স্ট্রিং, দুই ধরনের মানই গ্রহণ করুক?
এই দুটি টাইপ হায়ারার্কির একই শাখায় নেই।

আমরা টাইপটি `Any` হিসেবে সেট করতে পারি, বা ডিফল্টভাবেই সেটিকে `Any` হতে দিতে পারি, কিন্তু তখন কোন টাইপগুলো অনুমোদিত হবে তার সব নিয়ন্ত্রণ আমাদের হাতছাড়া হয়ে যায়।

আরও ভালো একটি উপায় হলো `Union{ }` সিনট্যাক্স, যেখানে বন্ধনীর ভেতরে দুই বা তার বেশি টাইপ লেখা হয়।

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

আরেকটি উদাহরণে একই টাইপ ইউনিয়ন একটি ফাংশন সিগনেচারে ব্যবহার করা হয়েছে:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

এখানে আমরা টাইপটির একটি নাম দিয়েছি, যা সুবিধাজনক শর্টহ্যান্ড হিসেবে কাজ করে, তবে কঠোরভাবে প্রয়োজনীয় নয়।
`g(z::Union{Integer, String}) = z^3` ফাংশনটিও একইভাবে কাজ করে।

ফাংশন সিগনেচার নিয়ে আরও অনেক কিছু বলার আছে মাল্টিপল ডিসপ্যাচ কনসেপ্টে।

## nothing-এর সাথে ইউনিয়ন

অন্যান্য বেশ কিছু ভাষায় এমন টাইপ আছে যা হয়তো একটি মান ধারণ করে, নাও করতে পারে; যেমন `Option`, `Nullable` বা `Maybe`।

Julia-তে এর জন্য আলাদা কোনো সিনট্যাক্স নেই, তবে টাইপ ইউনিয়ন একই ধারণার একটি সাধারণ রূপ।

`Nothingness` কনসেপ্টে আমরা দেখেছি যে Julia-তে মান-না-থাকার অবস্থা বোঝানোর নানা উপায় আছে, যার মধ্যে `nothing` ও `missing` অন্যতম।
এর যেকোনোটিই একটি টাইপ ইউনিয়নে রাখা যায়।

যেমন, একধরনের লিংকড লিস্ট বানাতে গেলে, আর কোনো নোড না থাকলে লিস্টটি শেষ করার একটি উপায় আমাদের দরকার।
`Nothing` হলো সেই টাইপ, যার একমাত্র মান `nothing`; আর নিচের Node সংজ্ঞাটি চেইনের শেষ বোঝানো সম্ভব করে তোলে:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

একইভাবে, অনুপস্থিত মানের জায়গা পূরণকারী হিসেবে `missing` ব্যবহার করা যায়, বিশেষত ভেক্টরের মতো কালেকশনে।
নিচের উদাহরণটি খুবই কৃত্রিম, তবে বাস্তব জীবনের ডেটা সেটে missing মান খুব সাধারণ ব্যাপার।

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
