# পরিচিতি

C#-এর `enum` টাইপ নামযুক্ত কনস্ট্যান্টের একটি নির্দিষ্ট সেট (একটি এনামারেশন) প্রতিনিধিত্ব করে। এর মূল উদ্দেশ্য হলো সংখ্যাসূচক কনস্ট্যান্টের সাথে ইন্টারঅ্যাক্ট করার একটি টাইপ-সেফ উপায় দেওয়া, যা উপলব্ধ মানগুলোকে একটি পূর্বনির্ধারিত সেটে সীমাবদ্ধ করে। একটি সাধারণ enum নিম্নলিখিতভাবে ডিফাইন করা যায়:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

স্পষ্টভাবে ডিফাইন করা না হলে, enum-এর সদস্যদের স্বয়ংক্রিয়ভাবে ক্রমান্বয়ে বাড়তে থাকা ইন্টিজার মান অ্যাসাইন করা হবে, যেখানে প্রথম মানটি শূন্য হয়। মানগুলো স্পষ্টভাবে অ্যাসাইন করাও সম্ভব:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
