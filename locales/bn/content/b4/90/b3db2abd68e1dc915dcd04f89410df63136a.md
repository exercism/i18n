# পরিচিতি

## প্রপার্টি

C#-এ একটি প্রপার্টি হলো একটি ক্লাসের এমন একটি মেম্বার, যা ওই ক্লাসের ভেতরের ডেটায় অ্যাক্সেস দেয়। কলাররা ডেটাটি সেট করতে বা রিট্রিভ (get) করতে পারে। প্রপার্টি হয় অটো-ইমপ্লিমেন্টেড হতে পারে, নয়তো এতে একটি ব্যাকিং ফিল্ড থাকে। এতে একটি set অ্যাক্সেসর এবং/অথবা একটি get অ্যাক্সেসর থাকে।
কিছু অন্যান্য ভাষায় একটি "mutator" মোটামুটি একটি set অ্যাক্সেসরের সমান এবং একটি "accessor" মোটামুটি একটি get অ্যাক্সেসরের সমান, যদিও সিনট্যাক্সের গঠন সম্পূর্ণ আলাদা।

কোনো প্রপার্টি সেট করার সময় ইনপুট মানটি ভ্যালিডেট করা, ফরম্যাট করা বা অন্যভাবে ম্যানিপুলেট করা যায়, এবং আসলে ক্লাসের কোড থেকে অ্যাক্সেসযোগ্য যেকোনো প্রোগ্রাম্যাটিক অপারেশন চালানো যায়।

একইভাবে, কোনো প্রপার্টি রিট্রিভ করার সময় ডেটা গণনা করা বা ফরম্যাট করা যায়, এবং আবারও ক্লাসের কাছে থাকা যেকোনো প্রোগ্রাম্যাটিক অপারেশন চালানো যায়।

অন্য ক্লাস মেম্বারদের মতোই প্রপার্টিরও অ্যাক্সেস মডিফায়ার (`public`, `private` ইত্যাদি) থাকে, তবে set অ্যাক্সেসরের অ্যাক্সেস লেভেল রিট্রিভ (get) অ্যাক্সেসর থেকে স্বাধীন হতে পারে, আবার উল্টোটাও। একটি প্রপার্টির দুটি অ্যাক্সেসর থাকতেই হবে না, এতে একটি থাকলেও চলে (get অথবা set)।

প্রপার্টি প্রকাশ করার মূল সিনট্যাক্স দুটি রূপ নিতে পারে:

### ফিল্ড/এক্সপ্রেশন ব্যাকড প্রপার্টি:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### অটো-ইমপ্লিমেন্টেড প্রপার্টি

```
public int MyProperty { get; private set; } = 42;
```
