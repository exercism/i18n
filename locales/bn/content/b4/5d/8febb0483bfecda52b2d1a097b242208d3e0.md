# সম্পর্কে

সেট হলো ইউনিক মানের একটি কালেকশন, যা ইমিউটেবল ও আনঅর্ডার্ড। সেটের সব আইটেম একই টাইপের হতে হয়।

`gleam/set` মডিউলটি `Set` টাইপটি ডিফাইন করে এবং সেট নিয়ে কাজ করার ফাংশন দেয়।

`set.to_list` আর `set.from_list` দিয়ে আপনি অ্যারে আর সেটকে একে অপরের মধ্যে রূপান্তর করতে পারেন। একটি সেটে আইটেমগুলোর ক্রম নিশ্চিত নয়।

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

আপনি `set.new`, `set.insert` আর `set.delete` দিয়ে সেট তৈরি ও পপুলেট করতে পারেন।

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

`set.contains` আর `set.size` ফাংশন দিয়ে আপনি সেটে কী কী আছে তা জানতে পারেন।

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

`set.union` আর `set.intersect` দিয়ে সেটকে একত্র করা যায়।

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

আপনি সেট ফিল্টার করতে পারেন।

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
