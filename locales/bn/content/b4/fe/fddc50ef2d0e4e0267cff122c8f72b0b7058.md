# নির্দেশনার সংযোজন

## ইঙ্গিত

আপনাকে `label` এবং `ohms` ফাংশন দুটি ইমপ্লিমেন্ট করতে হবে। `label` ফাংশনের জন্য দেওয়া সিগনেচারটি ব্যবহার করতে পারেন, তবে সেটি যেন আপনার সৃজনশীলতাকে সীমাবদ্ধ না করে।

এই অনুশীলনীটি টেক্সচুয়াল ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর `String` টাইপ আসলে `[Char]`-এর সমার্থক, অর্থাৎ ক্যারেক্টারের একটি অ্যারে। টেক্সচুয়াল ডেটা আরও দক্ষভাবে পরিচালনার জন্য `Text` টাইপটি ব্যবহার করা যায়।

এই অনুশীলনীর একটি ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি করতে পারেন:

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml ফাইলে আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করুন।
- `Data.Text` ইমপোর্ট করুন [এই পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- এখন আপনি যেমন `label :: Resistor -> Text` লিখতে পারেন, আর `Data.Text`-এর কম্বিনেটরগুলো ব্যবহার করতে পারেন যেমন `T.pack`।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখুন,

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
