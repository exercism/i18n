# নির্দেশনা

আপনি একটি ছোট কোম্পানির হিসাব রাখেন, আর প্রতিদিনের লেনদেন আপনার কাছে পৌঁছায় এলোমেলো লেখার লাইন হিসেবে। পরিমাণ যাচাই করতে, যে চিহ্ন দিয়ে সেগুলো চেনা যায় সেই চিহ্ন ধরে সংখ্যাগুলো বের করতে এবং আরেকবার ভালো করে দেখা দরকার এমন লাইন চিহ্নিত করতে আপনি রেগুলার এক্সপ্রেশন ব্যবহার করবেন।

## 1. একটি পরিমাণ যাচাই করুন

সঠিক গঠনের একটি পরিমাণ হলো একটি `$`, তারপর এক বা একাধিক অঙ্ক, আর তারপর *ঐচ্ছিক* একটি সেন্টের অংশ, যা একটি ডট ও ঠিক দুটি অঙ্ক দিয়ে গঠিত: `$100` বা `$100.50`, কিন্তু `$100.5` নয়। `valid-amount?` ডিফাইন করুন, যা `t` রিটার্ন করে যখন *পুরো* স্ট্রিংটি সঠিক গঠনের পরিমাণ হয়।

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. ডলারের সংখ্যাগুলো বের করুন

`dollar-amounts` ডিফাইন করুন, যা লাইনে সরাসরি `$` চিহ্নের পরে আসা প্রতিটি সংখ্যা ক্রমানুসারে রিটার্ন করে, শুধু অঙ্কগুলো, `$` ছাড়া।

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. শতাংশগুলো বের করুন

`percentages` ডিফাইন করুন, যা এমন প্রতিটি সংখ্যা রিটার্ন করে যার ঠিক পরেই একটি `%` থাকে।

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. একটি লাইন চিহ্নিত করুন

`flagged?` ডিফাইন করুন, যা `t` রিটার্ন করে যখন লাইনটিতে `refund` বা `chargeback` বড় হাতের ও ছোট হাতের অক্ষরের যেকোনো মিশ্রণে থাকে।

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
