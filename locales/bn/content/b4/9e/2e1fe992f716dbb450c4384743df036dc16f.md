# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                                                           |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | সংখ্যা                                                                                |
| `$v0`    | আউটপুট    | ইন্টিজার | ক্লাসিফিকেশন (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`) |
| `$t0-9`  | টেম্পোরারি | যেকোনো   | সাময়িক স্টোরেজের জন্য ব্যবহৃত হয়                                                            |
