# নির্দেশনা

আপনি জাহাজের পার্সার, প্যান্ট্রির ইনভেন্টরি সামলানো আপনার কাজ। ইনভেন্টরি হলো একটি হ্যাশটেবিল, যেখানে প্রতিটি কী (key) একটি আইটেমের নাম আর মান হলো স্টকে থাকা পরিমাণ।

## 1. একটি তালিকা থেকে ইনভেন্টরি তৈরি করুন

`create-inventory` ডিফাইন করুন, যা আইটেমের নামের একটি সিকোয়েন্স নেয় এবং প্রতিটি অনন্য নামকে তার সংখ্যার সাথে জুড়ে দিয়ে একটি হ্যাশটেবিল রিটার্ন করে।

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. আরও আইটেম যোগ করুন

`add-items` ডিফাইন করুন, যা একটি ইনভেন্টরি ও আইটেমের একটি সিকোয়েন্স নেয় এবং তালিকাভুক্ত প্রতিটি আইটেমের জন্য সংখ্যাগুলো বাড়ানো একটি নতুন ইনভেন্টরি রিটার্ন করে। মূল ইনভেন্টরি পরিবর্তন করা উচিত নয়।

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. সংখ্যাগুলো কমিয়ে আনুন

`decrement-items` ডিফাইন করুন, যা একটি ইনভেন্টরি ও আইটেমের একটি সিকোয়েন্স নেয় এবং তালিকাভুক্ত প্রতিটি আইটেমের জন্য সংখ্যাগুলো এক করে কমানো একটি নতুন ইনভেন্টরি রিটার্ন করে। সংখ্যা কখনোই শূন্যের নিচে নামা উচিত নয়, আর ইনভেন্টরিতে আগে থেকে না থাকা আইটেম বাদ দিতে হবে (কোনো ঋণাত্মক এন্ট্রি যোগ করা হয় না)।

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. একটি আইটেম পুরোপুরি মুছে ফেলুন

`remove-item` ডিফাইন করুন, যা একটি ইনভেন্টরি ও একটি আইটেম নেয় এবং আইটেমটি বাদ দেওয়া একটি নতুন ইনভেন্টরি রিটার্ন করে। আইটেমটি উপস্থিত না থাকলে অপরিবর্তিত একটি অনুলিপি রিটার্ন করুন।

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. যে আইটেমগুলো পাওয়া যাচ্ছে সেগুলোর তালিকা করুন

`list-inventory` ডিফাইন করুন, যা একটি ইনভেন্টরি নেয় এবং শুধু যেসব আইটেমের পরিমাণ শূন্যের বেশি সেগুলো নিয়ে `{ name quantity }` জোড়ার একটি অ্যারে রিটার্ন করে, যা নাম অনুসারে বর্ণানুক্রমে সাজানো থাকে।

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
