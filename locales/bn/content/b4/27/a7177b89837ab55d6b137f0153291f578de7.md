## ভ্যারিয়েবল

ভ্যারিয়েবল হলো প্রতীকী নাম, যা মান অথবা কনটেইনারকে নির্দেশ করে।
ভ্যারিয়েবলের নাম শুরু হতে পারে [সিজিল][sigils] নামের একটি বিশেষ চিহ্ন দিয়ে, আবার তা ছাড়াও; এর পরে থাকে একটি আইডেন্টিফায়ার।
একটি সিজিলের পরে একটি [টুইজিল][twigils]-ও থাকতে পারে।

ভিন্ন সিজিলযুক্ত ভ্যারিয়েবল ভিন্ন ধরনের ডেটা স্ট্রাকচার ধারণ করে।

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

সাধারণত যে টুইজিলগুলো আপনি প্রায়ই দেখবেন সেগুলো হলো `^` আর `:`, যেগুলো কোড ব্লক সিগনেচারের শর্টকাট হিসেবে কাজ করে।
`^` হলো পজিশনাল প্যারামিটারের জন্য।
`:` হলো নেইমড প্যারামিটারের জন্য।

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## কনটেইনার

কনটেইনারই ভ্যারিয়েবলকে পরিবর্তন করার সুযোগ দেয়।

`constant` দিয়ে ঘোষণা করা ভ্যারিয়েবল, আর সিজিলবিহীন ভ্যারিয়েবলের (আইডেন্টিফায়ারের আগে `\` দিয়ে ঘোষণা করা) কোনো কনটেইনার থাকে না; এগুলো বরং সরাসরি মানকে নির্দেশ করে।

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## টাইপ

ভ্যারিয়েবল টাইপ কনস্ট্রেইন্ট দিয়ে ঘোষণা করা যায়।
টাইপ কনস্ট্রেইন্টে কোয়ার্সনও থাকতে পারে, যেখানে কাঙ্ক্ষিত টাইপের আর্গুমেন্ট হিসেবে একটি গ্রহণযোগ্য টাইপ দিতে হয়।

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

টাইপ কনস্ট্রেইন্ট ব্যবহার করা হলো মাল্টি-ডিসপ্যাচ রুটিন কাজে লাগানোর একটি উপায়।

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Raku-তে টাইপ আসলে আরেক ধরনের অবজেক্ট।
`class`, `role` বা `enum` ঘোষণা করা হলো নিজের টাইপ অবজেক্ট তৈরির উপায়।
উদাহরণস্বরূপ, বিল্ট-ইন টাইপ `Bool` তৈরি হয়েছে একটি এনাম দিয়ে: `enum Bool <False True>`।

`subset` কিওয়ার্ড দিয়ে অন্য টাইপের উপর ভিত্তি করে সহজ টাইপ কনস্ট্রেইন্টও তৈরি করতে পারেন।
`where` ক্লজ ব্যবহার করে এই নতুন টাইপকে আরও সীমাবদ্ধ করতে পারেন।
`where` ক্লজ একটি সিগনেচারেও ব্যবহার করা যায়।

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
