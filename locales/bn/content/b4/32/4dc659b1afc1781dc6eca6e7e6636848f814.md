# নির্দেশনা

আপনার লাইব্রেরিয়ান বন্ধু আপনাকে তার লাইব্রেরি সফটওয়্যার এক্সটেন্ড করতে বলেছেন যাতে এটি স্বয়ংক্রিয়ভাবে বিলম্ব ফি হিসাব করতে পারে।
তার বর্তমান সিস্টেম একটি বই চেকআউটের সঠিক তারিখ ও সময় একটি [ISO8601](https://en.wikipedia.org/wiki/ISO_8601) ডেটটাইম স্ট্রিং হিসেবে সংরক্ষণ করে।
তিনি ঘানার একটি ছোট শহরে একটি স্থানীয় লাইব্রেরি চালান। ঘানা GMT টাইমজোন (UTC +0) ব্যবহার করে, ডেলাইট সেভিং টাইম ব্যবহার করে না, এবং অন্য টাইমজোন নিয়ে চিন্তা করতে হয় না।

## 1. সংরক্ষিত ডেটটাইমগুলো পার্স করুন

`LibraryFees.datetime_from_string/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি আর্গুমেন্ট হিসেবে একটি ISO8601 ডেটটাইম স্ট্রিং নেবে এবং একটি `NaiveDateTime` স্ট্রাক্ট রিটার্ন করবে।

```elixir
LibraryFees.datetime_from_string("2021-01-01T13:30:45Z")
# => ~N[2021-01-01 13:30:45]
```

## 2. বই দুপুরের আগে চেকআউট করা হয়েছিল কিনা নির্ধারণ করুন

কোনো বই দুপুরের আগে চেকআউট করা হলে পাঠকের তা ফেরত দেওয়ার জন্য ২৮ দিন সময় থাকে। আর যদি দুপুরে বা দুপুরের পরে চেকআউট করা হয়, তাহলে পাঠকের ২৯ দিন সময় থাকে।

`LibraryFees.before_noon?/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি `NaiveDateTime` স্ট্রাক্ট নেবে এবং একটি বুলিয়ান রিটার্ন করবে।

```elixir
LibraryFees.before_noon?(~N[2021-01-12 08:23:03])
# => true
```

## 3. ফেরত তারিখ হিসাব করুন

চেকআউট ডেটটাইমের ভিত্তিতে ফেরত তারিখ হিসাব করুন।

`LibraryFees.return_date/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি `NaiveDateTime` স্ট্রাক্ট নেবে এবং ২৮ বা ২৯ দিন পরের একটি `Date` স্ট্রাক্ট রিটার্ন করবে।

```elixir
LibraryFees.return_date(~N[2020-11-28 15:55:33])
# => ~D[2020-12-27]
```

## 4. বইটি ফেরত দিতে কত দেরি হয়েছিল তা নির্ধারণ করুন

লাইব্রেরিতে দেরিতে ফেরত দেওয়ার জন্য একটি নির্দিষ্ট হার রয়েছে। ফি হিসাব করার জন্য আমাদের জানতে হবে নির্ধারিত ফেরত তারিখের কত দিন পরে বইটি সত্যিই ফেরত দেওয়া হয়েছিল।

`LibraryFees.days_late/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি `Date` স্ট্রাক্ট - পরিকল্পিত ফেরত তারিখ, এবং একটি `NaiveDateTime` স্ট্রাক্ট - প্রকৃত ফেরত ডেটটাইম নেবে।

যদি প্রকৃত ফেরত তারিখ পরিকল্পিত ফেরত ডেটটাইমের আগের বা একই দিনে হয়, তাহলে ফাংশনটি 0 রিটার্ন করবে। অন্যথায়, ফাংশনটি এই দুই তারিখের মধ্যে দিনে পার্থক্য রিটার্ন করবে।

লাইব্রেরি পরিসংখ্যানের উদ্দেশ্যে বইটির প্রকৃত ফেরতের তারিখ ও সময় উভয়ই ট্র্যাক করে, কিন্তু বিলম্ব ফি হিসাব করার সময় সময়টি ব্যবহার করে না।

```elixir
LibraryFees.days_late(~D[2020-12-27], ~N[2021-01-03 09:23:36])
# => 7
```

## 5. বইটি সোমবারে ফেরত দেওয়া হয়েছিল কিনা নির্ধারণ করুন

লাইব্রেরিতে সোমবারে বই ফেরত দেওয়ার জন্য একটি বিশেষ অফার রয়েছে।

`LibraryFees.monday?/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি `NaiveDateTime` স্ট্রাক্ট নেবে এবং একটি বুলিয়ান রিটার্ন করবে।

```elixir
LibraryFees.monday?(~N[2021-01-03 13:30:45Z])
# => false
```

## 6. বিলম্ব ফি হিসাব করুন

`LibraryFees.calculate_late_fee/3` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি তিনটি আর্গুমেন্ট নেবে - দুটি ISO8601 ডেটটাইম স্ট্রিং, চেকআউট ডেটটাইম এবং প্রকৃত ফেরত ডেটটাইম, এবং এক দিনের বিলম্ব ফি। এটি বইটির প্রকৃত ফেরত কত দেরিতে হয়েছিল সেই অনুযায়ী মোট বিলম্ব ফি রিটার্ন করবে।

সোমবারের বিশেষ অফারটি অন্তর্ভুক্ত করুন। আপনি যদি সোমবারে বইটি ফেরত দেন, আপনার বিলম্ব ফি ৫০% ছাড়, নিচের দিকে রাউন্ড করা।

```elixir
# Sunday, 7 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-03T13:30:45Z", 100)
# => 700

# one day later, Monday, 8 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-04T09:02:11Z", 100)
# => 400
```
