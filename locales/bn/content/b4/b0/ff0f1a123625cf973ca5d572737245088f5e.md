# ভূমিকা

ফ্লোট হলো এমন সংখ্যা যার দশমিক বিন্দুর পরে এক বা একাধিক অঙ্ক থাকে।

```gleam
let float = 3.45
// -> 3.45
```

ফ্লোটেরও নিজস্ব অপারেটর সেট আছে।

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```
