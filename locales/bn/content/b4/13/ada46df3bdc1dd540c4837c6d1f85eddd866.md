# পরিচিতি

AWK একটি খুব ছোট ভাষা, আর এতে মাত্র কয়েকটি মৌলিক ডেটা টাইপ আছে।
এই পাঠে আমরা সংখ্যা ও স্ট্রিং নিয়ে আলোচনা করব।

## সংখ্যা

AWK-এ সংখ্যাগুলো ডাবল-প্রিসিশন ফ্লোটিং পয়েন্ট সংখ্যা হিসেবে তৈরি করা হয়।
ইন্টিজার, ফ্লোট আর ডাবলের মধ্যে কোনো পার্থক্য রাখা হয় না।

AWK অক্টাল সংখ্যা কনস্ট্যান্ট (`0` দিয়ে শুরু) এবং হেক্সাডেসিমাল সংখ্যা কনস্ট্যান্ট (`0x` বা `0X` দিয়ে শুরু) চিনতে পারে।

### সংখ্যাগত অপারেশন

আপনি [স্ট্যান্ডার্ড গাণিতিক অপারেটর][ops-arith] `+`, `-`, `*`, `/`, `%` ব্যবহার করতে পারেন।
সূচক অপারেটর হলো `^` (এটি POSIX-এ নির্দিষ্ট করা আছে), যদিও `**`-ও ব্যবহার করা যায়।
কিছু [বিল্ট-ইন সংখ্যাগত ফাংশন][funcs-numeric] আছে: ত্রিকোণমিতিক ফাংশন, র্যান্ডম সংখ্যা তৈরি, আর `int(x)` যা একটি সংখ্যাকে _x_ ও শূন্যের মধ্যবর্তী নিকটতম পূর্ণসংখ্যায় ছেঁটে দেয়।

বিটওয়াইজ _অপারেটর_ বলে কিছু নেই।
gawk এগুলোকে ফাংশন হিসেবে ইমপ্লিমেন্ট করে।
আর্গুমেন্টগুলো অবশ্যই অঋণাত্মক সংখ্যা হতে হবে।

| function            | operation                                      |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | আর্গুমেন্টগুলোর বিটওয়াইজ AND                    |
| `or(a, b [, ...])`  | আর্গুমেন্টগুলোর বিটওয়াইজ OR                     |
| `xor(a, b [, ...])` | আর্গুমেন্টগুলোর বিটওয়াইজ XOR                    |
| `lshift(v, count)`  | _v_-এর মান _count_ বিট বামে শিফট করা            |
| `rshift(v, count)`  | _v_-এর মান _count_ বিট ডানে শিফট করা            |
| `compl(v, count)`   | _v_-এর বিটওয়াইজ কমপ্লিমেন্ট                     |

## স্ট্রিং

AWK স্ট্রিং হলো ক্যারেক্টারের একটি ক্রম।
ডাবল কোট দিয়ে একটি স্ট্রিং কনস্ট্যান্ট লেখা হয়।

~~~~exercism/caution
GNU awk স্ট্রিংয়ে Unicode ক্যারেক্টার ব্যবহারের অনুমতি দেয়, অন্য awk ইমপ্লিমেন্টেশন নাও দিতে পারে।
আরেকটি জনপ্রিয় AWK হলো `mawk`, `gawk`-এর সঙ্গে এটি তুলনা করলে:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### স্ট্রিং অপারেশন

স্ট্রিং অপারেশন মাত্র একটি: কনক্যাটেনেশন।
কনক্যাটেনেশনের জন্য আলাদা কোনো অপারেটর নেই;
দুটি স্ট্রিং পাশাপাশি বসিয়ে দিলেই সেগুলো কনক্যাটেনেট হয়ে যায়:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` একটি **স্টেটমেন্ট**, ফাংশন নয়।
`print`-এর জন্য বন্ধনী লাগে না।
~~~~

AWK-এ আছে প্রচুর [স্ট্রিং ম্যানিপুলেশন ফাংশন][funcs-string]।
ট্র্যাকের পরের পাঠগুলোতে এগোতে এগোতে আমরা এগুলোর সঙ্গে বিস্তারিতভাবে পরিচিত হব।

## সংখ্যা ও স্ট্রিংয়ের মধ্যে রূপান্তর

সংখ্যা ও স্ট্রিংয়ের মধ্যে রূপান্তর করার জন্য আলাদা কোনো অপারেটর নেই।
AWK প্রোগ্রামের প্রেক্ষাপট দেখে নিজে থেকেই এই রূপান্তর করে।
এর ফলে ইনপুট ফিল্ডের মান নিয়ে কাজ করা খুব সহজ হয়ে যায়: AWK সাধারণত আপনি যা চান ঠিক সেটাই করে।

* `print x + y` ফাংশনটি `+` সংখ্যাগত অপারেশনের কারণে `x` ও `y` ভ্যারিয়েবলের মানগুলোকে সংখ্যায় রূপান্তর করবে।
* `print x y` ফাংশনটি কনক্যাটেনেশন অপারেশনের কারণে `x` ও `y` ভ্যারিয়েবলের মানগুলোকে স্ট্রিংয়ে রূপান্তর করবে।

আপনি যদি এটি স্পষ্টভাবে করতে চান, `0 + x` দেয় _x_-এর সংখ্যা রূপ, আর `"" x` দেয় _x_-এর স্ট্রিং রূপ।

### স্ট্রিং থেকে সংখ্যায়

AWK কীভাবে একটি স্ট্রিংকে সংখ্যায় রূপান্তর করে, তা বিভ্রান্তিকর লাগতে পারে।
সহজভাবে ভাবলে, AWK স্ট্রিংয়ের শুরু থেকে "সংখ্যার ক্যারেক্টার" পড়তে থাকে, যতক্ষণ না কোনো "সংখ্যা নয়" এমন ক্যারেক্টার পায়।
কিছু উদাহরণ:

* `"2.5"` রূপান্তরিত হয় `2.5` সংখ্যায়;
* `"1e3"` রূপান্তরিত হয় `1000` সংখ্যায় (বৈজ্ঞানিক নোটেশন);
* `"456abc"` রূপান্তরিত হয় `456` সংখ্যায় (কারণ `a` কোনো "সংখ্যা" নয়, তাই সেখানেই রূপান্তর থেমে যায়)।
* `"abc789"` রূপান্তরিত হয় `0` সংখ্যায় (স্ট্রিংয়ের **শুরুতে** কোনো সংখ্যা নেই)।

সম্পূর্ণ বিস্তারিত [ম্যানুয়ালে][str-to-num] আছে।

## একটি ভ্যারিয়েবলের টাইপ নির্ণয় করা

[`typeof(var)` ফাংশনটি][func-typeof] টাইপটি একটি স্ট্রিং হিসেবে রিটার্ন করে।

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
এর আউটপুট
```none
42 string
43 number
```
