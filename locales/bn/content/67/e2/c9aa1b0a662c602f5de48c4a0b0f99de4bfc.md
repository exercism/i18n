# পরিচিতি

Go-তে `rune` টাইপটি `int32`-এর একটি অ্যালিয়াস।
এই অন্তর্নিহিত `int32` টাইপের কারণে `rune` টাইপে একটি সাইনড ৩২-বিট ইন্টিজার মান সংরক্ষণ করা হয়।
তবে, `int32` টাইপের বিপরীতে, `rune` টাইপে সংরক্ষিত ইন্টিজার মানটি একটি একক ইউনিকোড ক্যারেক্টার বোঝায়।

## ইউনিকোড এবং ইউনিকোড কোড পয়েন্ট

ইউনিকোড হলো ASCII-এর একটি সুপারসেট, যা প্রতিটি ক্যারেক্টারকে একটি অনন্য সংখ্যা বরাদ্দ করে ক্যারেক্টারগুলোকে উপস্থাপন করে।
এই অনন্য সংখ্যাটিকে বলা হয় ইউনিকোড কোড পয়েন্ট।
ইউনিকোডের লক্ষ্য হলো বিশ্বের সমস্ত ক্যারেক্টার, যার মধ্যে রয়েছে বিভিন্ন বর্ণমালা, সংখ্যা, চিহ্ন এবং এমনকি ইমোজি, ইউনিকোড কোড পয়েন্ট হিসেবে উপস্থাপন করা।

Go-তে `rune` টাইপ একটি একক ইউনিকোড কোড পয়েন্ট বোঝায়।

নিচের টেবিলে উদাহরণস্বরূপ কিছু ইউনিকোড ক্যারেক্টার এবং তাদের ইউনিকোড কোড পয়েন্ট ও দশমিক মান দেওয়া হলো:

| ইউনিকোড ক্যারেক্টার | ইউনিকোড কোড পয়েন্ট | দশমিক মান |
|-------------------|--------------------|---------------|
| 0                 | `U+0030`           | `48`          |
| A                 | `U+0041`           | `65`          |
| a                 | `U+0061`           | `97`          |
| ¿                 | `U+00BF`           | `191`         |
| π                 | `U+03C0`           | `960`         |
| 🧠                | `U+1F9E0`          | `129504`      |

## UTF-8

UTF-8 হলো একটি ভ্যারিয়েবল-প্রস্থের ক্যারেক্টার এনকোডিং, যা প্রতিটি ইউনিকোড কোড পয়েন্টকে ১, ২, ৩ বা ৪ বাইট হিসেবে এনকোড করতে ব্যবহৃত হয়।
যেহেতু একটি ইউনিকোড কোড পয়েন্ট সর্বোচ্চ ৪ বাইটে এনকোড করা যায়, তাই `rune` টাইপকে ৪ বাইট পর্যন্ত ডেটা ধারণ করতে সক্ষম হতে হয়।
এ কারণেই `rune` টাইপ `int32`-এর একটি অ্যালিয়াস, কারণ একটি `int32` টাইপ ৪ বাইট পর্যন্ত ডেটা ধারণ করতে সক্ষম।

Go সোর্স কোড ফাইল UTF-8 ব্যবহার করে এনকোড করা হয়।

## রুন ব্যবহার

`rune` টাইপের ভ্যারিয়েবল ঘোষণা করা হয় একটি ক্যারেক্টারকে একক কোটেশনের ভেতরে রেখে:

```go
myRune := '¿'
```

যেহেতু `rune` কেবল `int32`-এর একটি অ্যালিয়াস, তাই একটি রুনের টাইপ প্রিন্ট করলে `int32` পাওয়া যাবে:

```go
myRune := '¿'
fmt.Printf("myRune type: %T\n", myRune)
// Output: myRune type: int32
```

একইভাবে, একটি রুনের মান প্রিন্ট করলে তার ইন্টিজার (দশমিক) মান পাওয়া যাবে:

```go
myRune := '¿'
fmt.Printf("myRune value: %v\n", myRune)
// Output: myRune value: 191
```

রুনটি যে ইউনিকোড ক্যারেক্টার বোঝায় তা প্রিন্ট করতে `%c` ফরম্যাটিং ভার্ব ব্যবহার করুন:

```go
myRune := '¿'
fmt.Printf("myRune Unicode character: %c\n", myRune)
// Output: myRune Unicode character: ¿
```

রুনটি যে ইউনিকোড কোড পয়েন্ট বোঝায় তা প্রিন্ট করতে `%U` ফরম্যাটিং ভার্ব ব্যবহার করুন:

```go
myRune := '¿'
fmt.Printf("myRune Unicode code point: %U\n", myRune)
// Output: myRune Unicode code point: U+00BF
```

## রুন এবং স্ট্রিং

Go-তে স্ট্রিং UTF-8 ব্যবহার করে এনকোড করা হয়, যার অর্থ সেগুলোতে ইউনিকোড ক্যারেক্টার থাকে।
স্ট্রিংয়ের ক্যারেক্টারগুলো যে ইউনিকোড ক্যারেক্টার বোঝায় তার উপর নির্ভর করে ১, ২, ৩ বা ৪ বাইট হিসেবে সংরক্ষণ ও এনকোড করা হয়।

Go-তে ক্রম বোঝাতে স্লাইস ব্যবহার করা হয় এবং range দিয়ে এই স্লাইসগুলোর উপর ইটারেশন করা যায়।
আমরা যখন একটি স্ট্রিংয়ের উপর ইটারেশন করি, Go তখন স্ট্রিংটিকে রুনের একটি সিরিজে রূপান্তর করে, যার প্রতিটি ৪ বাইটের (মনে রাখবেন, রুন টাইপটি `int32`-এর একটি অ্যালিয়াস!)

যদিও একটি স্ট্রিং কেবল বাইটের একটি স্লাইস, `range` কিওয়ার্ড একটি স্ট্রিংয়ের বাইটের উপর নয়, বরং তার রুনগুলোর উপর ইটারেশন করে।

এই উদাহরণে, `index` ভ্যারিয়েবলটি বর্তমান রুনের বাইট সিকোয়েন্সের শুরুর ইনডেক্স বোঝায় এবং `char` ভ্যারিয়েবলটি বর্তমান রুনটিকে বোঝায়:

```go
myString := "❗hello"
for index, char := range myString {
  fmt.Printf("Index: %d\tCharacter: %c\t\tCode Point: %U\n", index, char, char)
}
// Output:
// Index: 0	Character: ❗		Code Point: U+2757
// Index: 3	Character: h		Code Point: U+0068
// Index: 4	Character: e		Code Point: U+0065
// Index: 5	Character: l		Code Point: U+006C
// Index: 6	Character: l		Code Point: U+006C
// Index: 7	Character: o		Code Point: U+006F
```

যেহেতু রুনগুলো ১, ২, ৩ বা ৪ বাইট হিসেবে সংরক্ষণ করা যায়, তাই একটি স্ট্রিংয়ের দৈর্ঘ্য সবসময় স্ট্রিংয়ের ক্যারেক্টারের সংখ্যার সমান নাও হতে পারে।
একটি স্ট্রিংয়ের দৈর্ঘ্য বাইটে পেতে বিল্ট-ইন `len` ফাংশন এবং স্ট্রিংয়ে রুনের সংখ্যা পেতে `utf8.RuneCountInString` ফাংশন ব্যবহার করুন:

```go
import "unicode/utf8"

myString := "❗hello"
stringLength := len(myString)
numberOfRunes := utf8.RuneCountInString(myString)

fmt.Printf("myString - Length: %d - Runes: %d\n", stringLength, numberOfRunes)
// Output: myString - Length: 8 - Runes: 6
```
