# সম্পর্কে

Crystal একটি কম্পাইলড, অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং ভাষা।
ভাষাটির লক্ষ্যগুলোর মধ্যে কয়েকটি হল:

- Ruby থেকে অনুপ্রাণিত সিনট্যাক্স।

- স্ট্যাটিকভাবে টাইপ-চেক করা হয়, কিন্তু ভ্যারিয়েবল বা মেথড আর্গুমেন্টের টাইপ আলাদা করে উল্লেখ করতে হয় না।

- Crystal-এ bindings লিখে C code কল করা যায়।

- কম্পাইল-টাইম ইভ্যালুয়েশন ও code জেনারেশনের সুবিধা থাকা, যাতে বয়লারপ্লেট code এড়ানো যায়।

- দক্ষ নেটিভ code-এ কম্পাইল হওয়া।
