# বিস্তারিত

[বিটওয়াইজ বাইনারি ফাংশন][bitwise-wiki] [Bitwise মডিউল][bitwise-hexdocs]-এর ফাংশন ব্যবহার করে ইন্টিজারের উপর চালানো যায়।

- [`band/2`][bitwise-and]: বিটওয়াইজ AND
- [`bsl/2`][bitwise-shift-left]: বিটওয়াইজ SHIFT LEFT
- [`bsr/2`][bitwise-shift-right]: বিটওয়াইজ SHIFT RIGHT
- [`bxor/2`][bitwise-xor]: বিটওয়াইজ XOR
- [`bor/2`][bitwise-or]: বিটওয়াইজ OR
- [`bnot/1`][bitwise-not]: বিটওয়াইজ NOT

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
