# নির্দেশাবলি

মৌলিক নীতি থেকে শুরু করে একটি বাইনারি সংখ্যা, যা একটি স্ট্রিং হিসেবে প্রকাশ করা (যেমন '101010'), তার দশমিক সমতুল্যে রূপান্তর করুন।

বাইনারি থেকে দশমিকে রূপান্তর নিজে বাস্তবায়ন করুন।
একটি বাইনারি ইনপুট স্ট্রিং দেওয়া হলে আপনার প্রোগ্রামের একটি দশমিক আউটপুট তৈরি করা উচিত।
প্রোগ্রামটির অবৈধ ইনপুটও সামলাতে হবে।

## নোট

- রূপান্তরটি নিজেই বাস্তবায়ন করুন।
  রূপান্তরের কাজটি আপনার হয়ে করার জন্য অন্য কিছু ব্যবহার করবেন না।

## বাইনারি সম্পর্কে (বেস-২)

দশমিক একটি বেস-১০ পদ্ধতি।

বেস ১০ পদ্ধতিতে লেখা ২৩ সংখ্যাটিকে ১০-এর ঘাতগুলোর একটি রৈখিক সমন্বয় হিসেবে বোঝা যায়:

- একদম ডানদিকের অঙ্কটি ১০^০ = ১ দিয়ে গুণিত হয়
- এর পরের অঙ্কটি ১০^১ = ১০ দিয়ে গুণিত হয়
- ...
- n-তম অঙ্কটি ১০^_(n-1)_ দিয়ে গুণিত হয়।
- এরপর এই সব মান যোগ করা হয়।

তাহলে: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

বাইনারিও একই রকম, তবে ১০-এর ঘাতের বদলে ২-এর ঘাত ব্যবহার করে।

তাহলে: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
