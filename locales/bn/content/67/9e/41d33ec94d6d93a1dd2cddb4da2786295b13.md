# সম্পর্কে

Haxe-এ _ইনহেরিটেন্স_ ব্যবহার করে একটি ক্লাস হায়ারার্কি ডিফাইন করা যায়, যার ফলে একটি ডেরাইভড ক্লাস (`Car`) তার প্যারেন্ট ক্লাসের (`Vehicle`) আচরণ ও ডেটা ইনহেরিট করতে পারে।

প্যারেন্ট ক্লাসে আপনি রাখতে পারেন:

- এমন মেথড, যা ওভাররাইড করা যায়
- অ্যাবস্ট্রাক্ট মেথড, যা ডেরাইভড ক্লাসগুলোকে অবশ্যই ইমপ্লিমেন্ট করতে হয়

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

প্যারেন্ট ক্লাসে যদি একটি কনস্ট্রাক্টর থাকে, তবে সেটি কল করার জন্য আমরা `super()` ব্যবহার করি:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
