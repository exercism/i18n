# মেন্টরিংয়ে Markdown কীভাবে ব্যবহার করবেন

GitHub-এ আপনার মেন্টরিং মন্তব্যে আপনি Markdown ব্যবহার করতে পারেন।
এতে আপনি কোড স্নিপেট যুক্ত করতে, হেডিং, বোল্ড, ইটালিক, তালিকা ইত্যাদি যোগ করতে এবং আগের বাক্য উদ্ধৃত করতে পারবেন।

Exercism-এ আমরা "Github-flavoured Markdown"-এর কিছু উপাদানও ব্যবহার করতে দিই, বিশেষভাবে সিনট্যাক্স হাইলাইটিং, টেবিল আর স্ট্রাইকথ্রু।

Markdown বা GitHub-এর এই বাড়তি সুবিধাগুলোর সাথে আপনার পরিচয় না থাকলে আমরা [GitHub-এর Markdown নির্দেশিকা](https://guides.github.com/features/mastering-markdown/) পড়ার পরামর্শ দিই।
