# Debug

YS-এর একটি বিল্ট-ইন `DBG` ফাংশন আছে, যা আপনার লেখা কোড ডিবাগ করার সময় কাজে লাগতে পারে।
এটি যেকোনো সংখ্যক আর্গুমেন্ট নেয় এবং সেগুলো stderr-এর মাধ্যমে কনসোলে প্রিন্ট করে।
এটি শেষ আর্গুমেন্টটি রিটার্ন করে, তাই আপনি কোডের ভেতরে ইনলাইনে এটি ব্যবহার করতে পারেন।


আপনি `.>` ইনলাইন অপারেটরটি ব্যবহার করতে পারেন, যা `.DBG()`-এর একটি শর্টকাট।

এখানে একটি উদাহরণ কোড ফাইল দেখা যাচ্ছে:

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

`ys` দিয়ে এই কোডটি রান করলে আপনি নিচের আউটপুটটি দেখতে পাবেন:

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## কম্পাইলেশন

কোনো সমস্যা বুঝে বের করার আরেকটি কমন উপায় হলো, আপনার YS কোড যে Clojure কোডে কম্পাইল হয় সেটি দেখা।

আপনি `-c` ফ্ল্যাগসহ `ys` কমান্ড-লাইন ইন্টারপ্রেটারটি রান করে এটি করতে পারেন।

উপরের `program.ys` ফাইলটি কম্পাইল করা হলে কেমন দেখায়, তা এখানে দেখুন:

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

`.>` অপারেটরটি কীভাবে `DBG` ফাংশন কলে কম্পাইল হয়েছে, তা আপনি স্পষ্ট দেখতে পাচ্ছেন।
