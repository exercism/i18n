# নির্দেশাবলি

ABAP ইন্টারনাল টেবিল সম্পর্কে মূল বিষয়গুলো শিখুন।

আপনার ক্লাসে `initial_data` নামে একটি ইন্টারনাল টেবিল আছে। এতে তিনটি কলাম রয়েছে: `GROUP`, `NUMBER`, এবং `DESCRIPTION`।

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## ধাপ ১

আপনার প্রথম কাজ হলো `fill_itab` মেথডটি সম্পূর্ণ করা এবং নিচের মানগুলো দিয়ে এই টেবিলে ৬টি রেকর্ড বসানো:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## ধাপ ২

এরপর `add_to_itab` মেথডটি তৈরি করুন, যা নিচের মানটি দিয়ে ইন্টারনাল টেবিলের শেষে একটি রেকর্ড যোগ করবে:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## ধাপ ৩

এখন `sort_itab` মেথডে ইন্টারনাল টেবিলটি এমনভাবে সাজান যাতে `GROUP` কলামটি বর্ণানুক্রমিক ক্রমে এবং `NUMBER` কলামটি অবরোহ ক্রমে থাকে।

## ধাপ ৪

`search_itab` মেথডে সাজানো টেবিলটি সার্চ করুন এবং যে রেকর্ডের `NUMBER` কলামের মান 6, তার ইনডেক্স রিটার্ন করুন।
