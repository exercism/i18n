# টেস্ট

## সব টেস্ট চালান

`.rakutest` এক্সটেনশনের একটি Raku স্ক্রিপ্ট আছে, যা আপনার সমাধান টেস্ট করতে ব্যবহার করা হবে।
আপনি এই কমান্ডটি ব্যবহার করে টেস্টগুলো চালাতে পারেন:

`prove6`

অনুশীলনী শুরু করার আগে আউটপুটটি সম্ভবত এমন কিছু দেখাবে:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

আপনাকে `lib/` ডিরেক্টরিতে থাকা `.rakumod` এক্সটেনশনের মডিউলটি পরিবর্তন করতে হবে এবং টেস্ট পাস করার জন্য একটি সমাধান লিখতে হবে।
টেস্ট পাস হয়ে গেলে উপরের কমান্ডটির আউটপুট সম্ভবত এমন কিছু দেখাবে:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## প্রথম ব্যর্থতাতেই থামুন

আপনার `RAKU_TEST_DIE_ON_FAIL` এনভায়রনমেন্ট ভ্যারিয়েবলটি সেট করা থাকলে, টেস্ট রানার প্রথম ব্যর্থতার পরেই থেমে যাবে। যেমন:

Linux / OS X-এ:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

অথবা Windows-এ:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

আরও তথ্যের জন্য Raku ডকুমেন্টেশনের
[টেস্টিং অধ্যায়](https://docs.raku.org/language/testing.html) দেখুন।

## সমস্যা সমাধান

```
===SORRY!===
Could not find JSON::Fast
```

Raku ট্র্যাকে ব্যবহৃত সব মডিউল Rakudo Star-এর সঙ্গে দেওয়া হয়।
টেস্ট চালানোর চেষ্টা করার সময় উপরের মতো কোনো এরর মেসেজ পেলে, আপনাকে হয় নিশ্চিত করতে হবে যে আপনার কাছে Rakudo Star-এর সর্বশেষ ডিস্ট্রিবিউশন আছে, নয়তো কোনো প্যাকেজ ম্যানেজার দিয়ে মডিউলটি নিজে ইনস্টল করতে হবে।
মডিউল ইনস্টল করার তথ্যের জন্য Raku ডকুমেন্টেশনের [মডিউল সংক্রান্ত অংশ](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.) দেখুন।
