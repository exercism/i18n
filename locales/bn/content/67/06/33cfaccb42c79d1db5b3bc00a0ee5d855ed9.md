# নির্দেশনা

এই অনুশীলনীতে আপনি সেভিংস অ্যাকাউন্ট নিয়ে কাজ করবেন। প্রতি বছর আপনার সেভিংস অ্যাকাউন্টের ব্যালান্স তার সুদের হারের ভিত্তিতে হালনাগাদ হয়। আপনার ব্যাংক আপনাকে যে সুদের হার দেয়, তা আপনার অ্যাকাউন্টে থাকা অর্থের পরিমাণের (অর্থাৎ ব্যালান্সের) উপর নির্ভর করে:

- ঋণাত্মক ব্যালান্সের জন্য 3.213% (ব্যালান্স আরও ঋণাত্মক হয়ে যায়)।
- `1000` ডলারের কম ধনাত্মক ব্যালান্সের জন্য 0.5%।
- `1000` ডলার বা তার বেশি এবং `5000` ডলারের কম ধনাত্মক ব্যালান্সের জন্য 1.621%।
- `5000` ডলার বা তার বেশি ধনাত্মক ব্যালান্সের জন্য 2.475%।

আপনার জন্য চারটি কাজ রয়েছে, যার প্রতিটিতে আপনার ব্যালান্স ও তার সুদের হার নিয়ে কাজ করতে হবে।

## 1. সুদের হার হিসাব করুন

নির্দিষ্ট ব্যালান্সের ভিত্তিতে সুদের হার হিসাব করতে (_static_) `SavingsAccount.InterestRate()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
SavingsAccount.InterestRate(balance: 200.75m)
// 0.5f
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `float`.

## 2. সুদ হিসাব করুন

নির্দিষ্ট ব্যালান্সের ভিত্তিতে সুদ হিসাব করতে (_static_) `SavingsAccount.Interest()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
SavingsAccount.Interest(balance: 200.75m)
// 1.00375m
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `decimal`.

## 3. বার্ষিক ব্যালান্স হালনাগাদ হিসাব করুন

সুদের হার বিবেচনায় নিয়ে হালনাগাদ বার্ষিক ব্যালান্স হিসাব করতে (_static_) `SavingsAccount.AnnualBalanceUpdate()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
SavingsAccount.AnnualBalanceUpdate(balance: 200.75m)
// 201.75375m
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `decimal`.

## 4. কাঙ্ক্ষিত ব্যালান্সে পৌঁছাতে কত বছর লাগবে তা হিসাব করুন

প্রতি বছর চক্রবৃদ্ধি সুদ প্রয়োগ হলে কাঙ্ক্ষিত ব্যালান্সে পৌঁছাতে ন্যূনতম কত বছর লাগবে তা হিসাব করতে (_static_) `SavingsAccount.YearsBeforeDesiredBalance()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
SavingsAccount.YearsBeforeDesiredBalance(balance: 200.75m, targetBalance: 214.88m)
// 14
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `int`.

~~~~exercism/note
মূল ব্যালান্সে সরল সুদ প্রয়োগ করা হলে, ব্যালান্সটিকে সুদের হার দিয়ে গুণ করা হয় এবং এই দুটির গুণফলই সুদের পরিমাণ।

অন্যদিকে চক্রবৃদ্ধি সুদ প্রয়োগ করা হয় নির্দিষ্ট বিরতিতে বারবার।
প্রতিবার প্রয়োগের সময় সুদের পরিমাণ হিসাব করে তা মূল ব্যালান্সের সাথে যোগ করা হয়, যাতে পরের সুদের হিসাবগুলো আরও বড় একটি মূল ব্যালান্সের উপর করা হয়।
