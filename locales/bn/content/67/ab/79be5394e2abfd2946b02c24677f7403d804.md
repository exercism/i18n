# সম্পর্কে

Elm একটি পুরোপুরি ফাংশনাল ভাষা, তাই এখানে কোনো স্টেটমেন্ট নেই, শুধু এক্সপ্রেশন, আর ফাংশন সবসময় একটি একক এক্সপ্রেশন হয়।

এটি ছোট, সরল ফাংশন লিখতে উৎসাহ দেয়, আর সাধারণভাবে এটি ভালো একটি বিষয়। কিন্তু মাঝে মাঝে ফাংশন অনিবার্যভাবে আরও জটিল হয়ে পড়ে, আর তখন এই ফাংশনগুলো যাতে সুন্দরভাবে লেখা যায় তা নিশ্চিত করার একটি উপায় আমাদের দরকার।

এখানেই `let` এক্সপ্রেশন কাজে আসে। এর দুটি অংশ থাকে, একটি `let` অংশ যেখানে আপনি যত খুশি ডেফিনিশন তৈরি করতে পারেন, আর তারপর একটি `in` অংশ, যা একটি একক এক্সপ্রেশন এবং এই ডেফিনিশনগুলো ব্যবহার করতে পারে।

কম্পিউটিংয়ের পরিভাষায়, `let` এমন একটি স্কোপ তৈরি করে যা `in`-এর এক্সপ্রেশনটির জন্য লোকাল।

`let` এক্সপ্রেশন কয়েকটি পরিস্থিতিতে কাজে লাগে:

- এক্সপ্রেশন সরল করার জন্য
- মধ্যবর্তী এক্সপ্রেশনগুলোর ফলাফলের নাম দেওয়ার জন্য
- এক্সপ্রেশন বড় হয়ে উঠলে সেটিকে ছোট ছোট টুকরোয় ভাগ করার জন্য

একটি `let` এক্সপ্রেশনের ভেতরে আপনি বেশিরভাগ কাজই করতে পারেন, ডিস্ট্রাকচারিং সহ। তবে নিচের বিষয়গুলো করা যায় না:

- কাস্টম টাইপ
- টাইপ অ্যালিয়াস
- নাম শ্যাডোয়িং (স্কোপে আগে থেকেই থাকা একটি নাম আপনি আবার ডিফাইন বা পুনরায় ব্যবহার করতে পারেন না)

## এক্সপ্রেশন সরল করা

এই এক্সপ্রেশনটি ৩টি সংখ্যার কিউব যোগ করে, কিন্তু এটি পড়া কঠিন, আর ভিন্ন ভিন্ন সংখ্যার জন্য হিসাবটি ভিন্ন হয়ে যাওয়াও সহজ।

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

হিসাবটি আরও সরল, আরও এক্সপ্রেসিভ এবং আরও নিরাপদ করতে আমরা একটি `let` এক্সপ্রেশনের ভেতরে একটি `cube` ফাংশন ডিফাইন করতে পারি। এই ফাংশনের একটি টাইপ অ্যানোটেশন থাকতে পারে, কিন্তু ইডিওম্যাটিক Elm কোডে এটি তুলনামূলকভাবে বিরল।

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## মধ্যবর্তী এক্সপ্রেশনগুলোর ফলাফলের নাম দেওয়া

হিসাবটি আরও সরল ও আরও এক্সপ্রেসিভ করতে এই কোডটি sideArea এবং topArea ডিফাইন করে।

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## একটি বড় এক্সপ্রেশন ভাগ করা

এই কোডটি [Game of Life](https://playgameoflife.com/) (প্রোগ্রামিংয়ের একটি কমন উদাহরণ অনুশীলনী) এর জন্য একটি প্রাথমিক প্যাটার্ন তৈরি করে।

এটি ঠিক কীভাবে কাজ করে তা বোঝা জরুরি নয়, তবে আশা করা যায় এটা স্পষ্ট যে `let` ছাড়া একে একটি একক এক্সপ্রেশন হিসেবে লিখলে এটি অনেক বড় হয়ে যেত।

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
