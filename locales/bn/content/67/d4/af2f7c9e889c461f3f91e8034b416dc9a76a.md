# ভূমিকা

স্ট্রাক্ট ও ক্লাসের অনেক ধরনের মেম্বার (প্রধান ব্যতিক্রম হলো ফিল্ড) এক্সপ্রেশন-বডিড মেম্বার সিনট্যাক্স ব্যবহার করতে পারে। একটি মেম্বার এক্সপ্রেশন দিয়ে ডিফাইন করলে প্রথাগত ব্লক/স্টেটমেন্টের চেয়ে প্রায়ই আরও সংক্ষিপ্ত ও পাঠযোগ্য কোড তৈরি হয়।

মেথড ও রিড-ওনলি প্রপার্টি হলো এমন মেম্বার, যেগুলো এক্সপ্রেশন বডি দিয়ে ডিফাইন করা যায়।

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
