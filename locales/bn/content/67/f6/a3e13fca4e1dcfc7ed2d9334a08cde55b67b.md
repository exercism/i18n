# পরিচিতি

## ডকুমেন্টেশন

Elixir-এ ডকুমেন্টেশন প্রথম শ্রেণির নাগরিক।

আপনার কোড ডকুমেন্ট করার জন্য সাধারণত দুটি মডিউল অ্যাট্রিবিউট ব্যবহার করা হয়। একটি মডিউল ডকুমেন্ট করার জন্য `@moduledoc`, আর অ্যাট্রিবিউটটির পরে থাকা একটি ফাংশন ডকুমেন্ট করার জন্য `@doc`। `@moduledoc` অ্যাট্রিবিউট সাধারণত মডিউলের প্রথম লাইনে থাকে, আর `@doc` অ্যাট্রিবিউট সাধারণত থাকে ঠিক একটি ফাংশন ডেফিনিশনের আগে, অথবা ফাংশনটির টাইপস্পেক থাকলে তার আগে। ডকুমেন্টেশন সাধারণত হেরেডক সিনট্যাক্স ব্যবহার করে একটি মাল্টিলাইন স্ট্রিং-এ লেখা হয়।

Elixir-এর ডকুমেন্টেশন লেখা হয় [**Markdown**][markdown]-এ।

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

## টাইপস্পেক

Elixir একটি ডাইনামিক্যালি টাইপড ভাষা, অর্থাৎ এটি কম্পাইল-টাইমে কোনো টাইপ চেক করে না। তবুও, টাইপ স্পেসিফিকেশন ডকুমেন্টেশনের একটি রূপ হিসেবে ব্যবহার করা যায়।

ফাংশন ডেফিনিশনের ঠিক আগে `@spec` মডিউল অ্যাট্রিবিউট ব্যবহার করে একটি ফাংশনে টাইপ স্পেসিফিকেশন যোগ করা যায়। `@spec`-এর পরে থাকে ফাংশনের নাম এবং বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা তার সব আর্গুমেন্টের টাইপের একটি তালিকা। রিটার্ন ভ্যালুর টাইপ ফাংশনের আর্গুমেন্ট থেকে ডাবল কোলন `::` দিয়ে আলাদা করা হয়।

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

### টাইপ

সবচেয়ে বেশি ব্যবহৃত টাইপগুলো হলো:

- বুলিয়ান: `boolean()`
- স্ট্রিং: `String.t()`
- সংখ্যা: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- অ্যারে: `list()`
- যেকোনো টাইপের মান: `any()`

কিছু টাইপ প্যারামিটারাইজডও হতে পারে, যেমন `list(integer)` হলো ইন্টিজারের একটি অ্যারে।

লিটারাল মানও টাইপ হিসেবে ব্যবহার করা যায়।

পাইপ `|` ব্যবহার করে টাইপের ইউনিয়ন লেখা যায়। যেমন, `integer() | :error` মানে হয় একটি ইন্টিজার, নয়তো অ্যাটম লিটারাল `:error`।

সব টাইপের সম্পূর্ণ তালিকা পাওয়া যাবে [অফিসিয়াল ডকুমেন্টেশনের "Typespecs" অংশে][types]।

### আর্গুমেন্টের নামকরণ

টাইপস্পেকে আর্গুমেন্টের নামও দেওয়া যায়, যা একই টাইপের একাধিক আর্গুমেন্ট আলাদা করতে কাজে লাগে। আর্গুমেন্টের টাইপের আগে থাকে আর্গুমেন্টের নাম, তারপর একটি ডাবল কোলন।

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

### কাস্টম টাইপ

টাইপস্পেক শুধু বিল্ট-ইন টাইপেই সীমাবদ্ধ নয়। `@type` মডিউল অ্যাট্রিবিউট ব্যবহার করে কাস্টম টাইপ ডিফাইন করা যায়। একটি কাস্টম টাইপের ডেফিনিশন শুরু হয় টাইপের নাম দিয়ে, তারপর একটি ডাবল কোলন এবং তারপর টাইপটি নিজেই।

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

একটি কাস্টম টাইপ যে মডিউলে ডিফাইন করা হয়েছে সেই মডিউল থেকে, বা অন্য কোনো মডিউল থেকেও ব্যবহার করা যায়।
