# সম্পর্কে

রিকার্সন হলো কোনো ফাংশনের ভেতরে কোড পুনরাবৃত্তি করার একটি উপায়, যেখানে ফাংশনটি নিজেই নিজেকে কল করে।
এটি লুপ করা বা ইটারেশন করার আরেকটি উপায়। লুপের মতোই, কখন থামতে হবে তা জানার জন্য ফাংশনটিকে একটি বুলিয়ান এক্সপ্রেশন পরীক্ষা করতে হবে।
লুপের বিপরীতে, যে রিকার্সন কখনো শেষ হয় না, সেটি অসীমভাবে চলতে থাকবে না।
প্রতিটি ফাংশন কলের মানগুলো স্ট্যাকের নিজস্ব ফ্রেমে রাখা হতে পারে।
ফাংশন কলের সংখ্যা স্ট্যাকের জায়গার চেয়ে বেশি জায়গা নিলে তা স্ট্যাক ওভারফ্লো এরর ডেকে আনবে।

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

এটি প্রিন্ট করবে

```
The number is 1
The number is 2
After recursion
```

কিছু পরিস্থিতি থাকতে পারে, যেগুলো লুপ দিয়ে প্রকাশ করার চেয়ে রিকার্সন দিয়ে প্রকাশ করলে পড়তে বেশি আরামদায়ক এবং/অথবা সহজে যুক্তি করা যায়।


## টেইল কল

টেইল কল হলো যখন কোনো ফাংশনের শেষ স্টেটমেন্টটি কেবল নিজেকেই কল করে, আর কিছুই নয়।

টেইল কল হলো রিকার্সনের একটি বিশেষ রূপ, যা কম্পাইলারকে কম্পাইল করা কোডে রিকার্সনটিকে একটি লুপে অপটিমাইজ করার সুযোগ দিতে পারে।
এতে দুই জগতের সেরাটাই পাওয়া যায়: রিকার্সনের পাঠযোগ্যতা আর লুপের পারফরম্যান্স।
রিকার্সনকে লুপে কম্পাইল করাকেই বলা হয় `tail call elimination` বা `tail call optimization.`

কোনো টেইল কল যখন লুপে কম্পাইল হয়, তখন প্রতিটি ফাংশন কলের জন্য নতুন স্ট্যাক ফ্রেম তৈরি হয় না।
মূলত যে সময়ে কল করা হয়েছিল সেই ফাংশনের অ্যাড্রেসটিতে হালনাগাদ করা মানগুলো পাঠানো হয়, ফলে স্ট্যাকের জায়গা বাঁচে এবং পারফরম্যান্স বাড়ে।

এই উদাহরণটি টেইল কল নয়, কারণ ফাংশনটি নিজেকে কল করার ফলাফলের সাথে ১ যোগ করে

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

এটি প্রিন্ট করবে

```
The number is 1
The number is 2
j is 3 after recursion
```

এটিকে টেইল কলে রিফ্যাক্টর করতে, `printIncrement` ফাংশনের একটি প্যারামিটার হিসেবে `j` যোগ করুন

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

আপনি দেখতে পাবেন, টেইল কল নয় এমন রিকার্সিভ কলে যুক্তি করার চেয়ে টেইল কলে সহজে যুক্তি করা যায়।
তবে সাধারণত কম্পাইলাররা নিশ্চয়তা দেয় না যে সব টেইল কলই অপটিমাইজ করা হবে।
রিকার্সন ব্যবহার করার সময় সবসময় এটা জানা জরুরি যে এত বেশি ইটারেশন হবে না যাতে স্ট্যাক ওভারফ্লো হয়ে যায়।
