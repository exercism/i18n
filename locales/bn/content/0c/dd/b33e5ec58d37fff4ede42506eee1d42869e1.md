# প্রদত্ত সিগনেচার পরিবর্তন করবেন না

নির্দেশাবলিতে যেমন বলা হয়েছে, `makeChest` ও `makeTreasureChest` ফাংশন দুটির সিগনেচার আপনার পরিবর্তন করা উচিত নয়। এগুলো হুবহু এভাবেই থাকবে:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
