# ভূমিকা

Swift-এ লুপ ও switch স্টেটমেন্টের এক্সিকিউশন ফ্লো বদলানোর জন্য কন্ট্রোল ট্রান্সফার স্টেটমেন্ট আছে।
`return` ছাড়াও Swift-এ আছে `continue`, `break`, লুপ লেবেল এবং `fallthrough`।

## Continue

`continue` স্টেটমেন্টটি লুপকে বলে, বর্তমান ইটারেশনটি আর চালাবে না, সঙ্গে সঙ্গে পরের ইটারেশন শুরু করো।
`while` বা `repeat-while` লুপে এটি সোজা শর্ত পরীক্ষায় লাফ দেয়।
`for-in` লুপে এটি সিকোয়েন্সের পরের এলিমেন্টে এগিয়ে যায়।

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break` স্টেটমেন্টটি একটি পুরো লুপ বা switch স্টেটমেন্ট থেকে সঙ্গে সঙ্গে বেরিয়ে যায়।
এরপর লুপ বা switch-এর পরের প্রথম কোড লাইন থেকে এক্সিকিউশন চলতে থাকে।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## লেবেলযুক্ত স্টেটমেন্ট

লুপগুলো নেস্টেড থাকলে আপনি হয়তো চাইবেন `break` বা `continue` সবচেয়ে ভেতরের লুপে নয়, বরং কোনো বাইরের লুপে কাজ করুক।
লুপের আগে একটি নাম আর তারপর একটি কোলন (`labelName:`) বসিয়ে লুপে লেবেল দেওয়া যায়।
এরপর সেই লেবেলটি `break` বা `continue`-কে দিতে পারেন:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
