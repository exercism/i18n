Raku একটি অসাধারণ সমৃদ্ধ, নমনীয় ও শক্তিশালী প্রোগ্রামিং ভাষা।
এর নমনীয়তা প্রোগ্রামারদের নিজের স্টাইলের সাথে মানানসই ভাবপ্রকাশকারী কোড লিখতে দেয়।

Raku একটি বিশাল ভাষা, শেখার, ঘেঁটে দেখার আর পরীক্ষা-নিরীক্ষা করার মতো যথেষ্ট গভীরতা এতে আছে।
এই সিলেবাসের লক্ষ্য হলো শুরু করার জন্য প্রয়োজনীয় মৌলিক বিষয়গুলো তুলে ধরা।

অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং Raku-এর একেবারে কেন্দ্রে আছে, তবে এটি অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিংয়ের চর্চা চাপিয়ে দেয় না।
এর অবজেক্ট ওরিয়েন্টেড প্রকৃতির কারণেই এই সিলেবাসে প্রায়ই [অবজেক্ট, ক্লাস ও মেথড][object-orientation] নিয়ে আলোচনা আসবে।

## ভ্যারিয়েবল

বিষয়টা সহজ রাখতে বেসিকস-এ আমরা শুধু স্কেলার [ভ্যারিয়েবল][variables] ব্যবহার করব।

স্কেলার ভ্যারিয়েবল হলো `$` সিগিল দিয়ে শুরু হওয়া [আইডেন্টিফায়ার][identifiers]।

স্কেলার ভ্যারিয়েবলে কার্যত যেকোনো কিছু থাকতে পারে, আর এর ডিফল্ট টাইপ [`Any`][Any]।

আপনি যে ভ্যারিয়েবলগুলো ব্যবহার করবেন, তাদের বেশিরভাগেরই একটি [ডিক্লারেশন][variable-declarator] দরকার হবে।
আপাতত [`my`][my] আর [`constant`][constant] নিয়েই থাকুন।

```raku
my $foo;
constant $BAR;
```

## সাবরুটিন

একটি সাবরুটিন [`sub`][sub-declarator] ডিক্লারেটর দিয়ে ডিক্লেয়ার করা হয়।

একটি `sub` ডিক্লারেশনের পরে থাকে একটি ঐচ্ছিক [আইডেন্টিফায়ার][identifiers], তারপর একটি ঐচ্ছিক [সিগনেচার][signatures], আর সবশেষে একটি [ব্লক][blocks]।

সাবরুটিনগুলোকে (অন্যান্য জিনিসের পাশাপাশি) [`is export`][exporting] ট্রেইট যোগ করে এক্সপোর্ট করা যায়।

আইডেন্টিফায়ারের উপর একটি [পোস্টসার্কামফিক্স `( )`][postcircumfix-()] অপারেটর দিয়ে সাবরুটিন কল করা যায়।

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## অপারেটর

Raku-এ নানা রকম [অপারেটর][operators] আছে।
বেসিকস ধারণার অনুশীলনীগুলোতে আমরা Raku-এর `+` আর `-`-এর মতো কিছু মৌলিক গাণিতিক অপারেটর ব্যবহার করব।

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

চাইলে আপনি সহজেই Raku-এ নিজের অপারেটর ডিফাইন করতে পারেন।
বেশিরভাগ বিল্ট-ইন অপারেটর সাবরুটিন হিসেবেও পাওয়া যায়।

## প্যাকেজ ও মডিউল

Raku-এ কয়েক ধরনের [প্যাকেজ][package-declarator] আছে। বেসিকস-এ আমরা শুধু `module` ব্যবহার করব।

গোটা ফাইলকে একটি `module` হিসেবে ডিক্লেয়ার করতে মডিউল ডিক্লারেশনের আগে `unit` বসানো হয়।

```raku
unit module Foo;

sub bar () { ... }
```

## কমেন্ট

Raku-এ [এক লাইনের][single-line-comments] আর [বহু লাইন/এমবেডেড][multi-line-comments] কমেন্ট আছে।

এক লাইনের কমেন্ট `#` দিয়ে শুরু হয় এবং লাইনের শেষ পর্যন্ত চলে।

বহু লাইন/এমবেডেড কমেন্ট শুরু হয় একটি হ্যাশ, তারপর একটি ব্যাকটিক আর একটি Unicode Open Punctuation অক্ষর দিয়ে।
এরা শেষ হয় মিলে যাওয়া জোড়া ক্লোজিং অক্ষর দিয়ে।

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## স্টাইল কনভেনশন

Raku-এ ভ্যারিয়েবল ও সাবরুটিনের [আইডেন্টিফায়ার][identifiers] লেখা হয় `kebab-case`-এ।
কনস্ট্যান্ট লেখা হয় `ALL-CAPS`-এ।
প্যাকেজের নাম লেখা হয় `PascalCase`-এ।
