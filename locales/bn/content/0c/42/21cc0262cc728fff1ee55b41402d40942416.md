# ভূমিকা

Go-তে, একটি `struct` হলো _ফিল্ড_ নামে পরিচিত নামযুক্ত এলিমেন্টের একটি ক্রম, আর প্রতিটি ফিল্ডের একটি নাম ও একটি টাইপ থাকে।
একটি স্ট্রাক্টের ভেতরে একটি ফিল্ডের নাম অবশ্যই অনন্য হতে হবে।
অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং প্যারাডাইমে স্ট্রাক্টকে _ক্লাস_-এর সাথে তুলনা করা যায়।

## একটি স্ট্রাক্ট ডিফাইন করা

`type` ও `struct` কিওয়ার্ড ব্যবহার করে আপনি একটি নতুন স্ট্রাক্ট তৈরি করেন, আর ফিল্ডগুলোর নাম ও টাইপ স্পষ্টভাবে ডিফাইন করেন।
উদাহরণস্বরূপ, এখানে আমরা `Shape` স্ট্রাক্ট ডিফাইন করছি, যা একটি আকৃতির নাম ও তার আকার ধারণ করে:

```go
type Shape struct {
    name string
    size int
}
```

স্ট্রাক্টে ফিল্ডের নাম Go-এর প্রচলিত রীতি অনুসরণ করে। যে ফিল্ডের নাম ছোট হাতের অক্ষর দিয়ে শুরু হয়, সেগুলো কেবল একই প্যাকেজের কোড থেকে দেখা যায়, অন্যদিকে যে ফিল্ডের নাম বড় হাতের অক্ষর দিয়ে শুরু হয়, সেগুলো অন্য প্যাকেজ থেকেও দেখা যায়।

## একটি স্ট্রাক্টের ইনস্ট্যান্স তৈরি করা

`struct` ডিফাইন করার পর, ফিল্ডের নাম ব্যবহার করে যেকোনো ক্রমে ফিল্ডগুলো উল্লেখ করে আপনাকে একটি নতুন ইনস্ট্যান্স তৈরি করতে হবে:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

ইনস্ট্যান্সের ফিল্ড পড়তে বা পরিবর্তন করতে `.` নোটেশন ব্যবহার করুন:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

যে ফিল্ডগুলোতে কোনো প্রাথমিক মান অ্যাসাইন করা হয়নি, সেগুলোতে শূন্য মান থাকবে।
উদাহরণস্বরূপ:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

ফিল্ডের নাম ব্যবহার না করেও আপনি একটি `struct`-এর ইনস্ট্যান্স তৈরি করতে পারেন, যতক্ষণ আপনি ফিল্ডগুলো _ক্রম অনুসারে_ ডিফাইন করেন:

```go
s := Shape {
	"Oval",
	20,
}
```

তবে এই সিনট্যাক্সকে _ভঙ্গুর কোড_ বলা হয়, কারণ কোনো ফিল্ড যোগ করা হলে এটি ভেঙে যেতে পারে, বিশেষ করে নতুন ফিল্ডটি ভিন্ন টাইপের হলে।
নিচের উদাহরণে আমরা `Shape`-এ একটি বাড়তি ফিল্ড যোগ করছি:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## "New" ফাংশন

মাঝে মাঝে এমন ফাংশন থাকা সুবিধাজনক, যা আমাদের স্ট্রাক্টের ইনস্ট্যান্স তৈরি করতে সাহায্য করে।
প্রচলিত রীতি অনুসারে এসব ফাংশনের নাম সাধারণত `New` রাখা হয় বা নাম `New` দিয়ে শুরু হয়, কিন্তু যেহেতু এগুলো নিছক সাধারণ ফাংশন, আপনি ইচ্ছেমতো নাম দিতে পারেন।
এগুলো হয়তো আপনাকে অন্য ভাষার কনস্ট্রাক্টরদের কথা মনে করিয়ে দেবে, কিন্তু Go-তে এগুলো নিছক সাধারণ ফাংশন।

নিচের উদাহরণে, এরকম একটি `New` ফাংশন ব্যবহার করে `Shape`-এর একটি নতুন ইনস্ট্যান্স তৈরি করা হয়েছে এবং আকৃতির `size`-এর জন্য স্বয়ংক্রিয়ভাবে একটি ডিফল্ট মান সেট করা হয়েছে:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New` ফাংশন ব্যবহার করলে নিচের সুবিধাগুলো পাওয়া যায়:

* প্রদত্ত মানগুলোর ভ্যালিডেশন
* ডিফল্ট মানগুলো সামলানো
* যেহেতু `New` ফাংশনগুলো প্রায়শই যে স্ট্রাক্টগুলোকে ইনিশিয়ালাইজ করে সেগুলোর একই প্যাকেজে ডিক্লেয়ার করা হয়, তাই এগুলো স্ট্রাক্টের প্রাইভেট ফিল্ডও ইনিশিয়ালাইজ করতে পারে

এই টাইপ সম্পর্কে আরও গভীরে জানতে, আপনি এই রিসোর্সগুলো দেখতে পারেন: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] বা [Structures in Go (structs)][medium-structures-in-go]

## `new` বিল্টইন

একটি স্ট্রাক্টের নতুন ইনস্ট্যান্স তৈরি করার আরেকটি উপায় হলো `new` বিল্টইন ব্যবহার করা:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

এই উদাহরণে, `new` স্ট্রাক্ট `Shape`-এর একটি ইনস্ট্যান্স তৈরি করে, যার সমস্ত মান তাদের টাইপের শূন্য মান দিয়ে ইনিশিয়ালাইজ করা থাকে, এবং এর একটি পয়েন্টার রিটার্ন করে।

~~~~exercism/note
বেশিরভাগ ক্ষেত্রেই আপনি `new` বিল্টইন ব্যবহার করে তৈরি করা স্ট্রাক্টের নতুন ইনস্ট্যান্স দেখতে পাবেন না।
স্ট্রাক্ট তৈরি করতে সাহায্য করে এমন একটি স্ট্রাক্ট লিটারাল, একটি কাস্টম `New` ফাংশন বা প্যাকেজের দেওয়া অন্য যেকোনো ফাংশন ব্যবহার করাই সবসময় পছন্দ করুন।
সর্বশেষ উপায় হিসেবে `new` বিল্টইন দিয়ে স্ট্রাক্টের নতুন ইনস্ট্যান্স তৈরি করুন।
