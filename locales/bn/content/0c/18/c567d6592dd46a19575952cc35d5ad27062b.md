# নির্দেশাবলী

টরি একজন জলবায়ু সাংবাদিক এবং তিনি বিভিন্ন শহরের আবহাওয়া নিয়ে একটি নিবন্ধ লিখতে চান। তাঁর কাছে বিভিন্ন শহরের আবহাওয়ার তথ্য আছে এবং তিনি তাপমাত্রার ভিত্তিতে সেগুলো র‍্যাংক করতে চান, তবে কিছু তাপমাত্রা ফারেনহাইটে আর কিছু সেলসিয়াসে। তাপমাত্রাগুলোকে একই এককে রূপান্তর করে সেগুলো র‍্যাংক করতে তাঁর আপনার সাহায্য প্রয়োজন।

## 1. ফারেনহাইটকে সেলসিয়াসে রূপান্তর করুন

`fahrenheit_to_celsius` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে ফারেনহাইটে একটি তাপমাত্রা নেয় এবং সেলসিয়াসে তাপমাত্রাটি রিটার্ন করে।

ফারেনহাইট থেকে সেলসিয়াসে রূপান্তর করতে ফারেনহাইট মান থেকে ৩২ বিয়োগ করুন এবং এরপর ফলাফলটি ১.৮ দিয়ে ভাগ করুন।

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. দুটি তাপমাত্রা তুলনা করুন

`compare_temperature` ফাংশনটি ডিফাইন করুন, যেটি দুটি তাপমাত্রা নেয় এবং একটি `Order` মান রিটার্ন করে, যা জানায় প্রথম তাপমাত্রাটি দ্বিতীয় তাপমাত্রার চেয়ে কম, সমান, নাকি বেশি।

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. তাপমাত্রা অনুযায়ী শহরগুলো সাজান

`sort_cities_by_temperature` ফাংশনটি ডিফাইন করুন, যেটি শহরগুলোর একটি অ্যারে নেয় এবং সেগুলোকে সবচেয়ে ঠান্ডা থেকে সবচেয়ে উষ্ণ পর্যন্ত ক্রমে রিটার্ন করে।

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
