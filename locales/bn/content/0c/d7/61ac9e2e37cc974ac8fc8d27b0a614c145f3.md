# ভূমিকা

ক্লাসের একটি ইনস্ট্যান্স তৈরি করা হয় `new` অপারেটরের মাধ্যমে তার _কনস্ট্রাক্টর_ কল করে। কনস্ট্রাক্টর হলো ক্লাসের ভেতরে থাকা একটি বিশেষ মেথড, যার উদ্দেশ্য ক্লাসটি ইনিশিয়ালাইজ করা। Haxe-এ কনস্ট্রাক্টর মেথডের নাম `new()`।

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

সাধারণ মেথডের মতোই কনস্ট্রাক্টরেও প্যারামিটার থাকতে পারে। এই প্যারামিটারগুলো (সাধারণত) প্রাইভেট ফিল্ডে সংরক্ষণ করা হয় এবং পরে সেগুলো ব্যবহার করা হয়।

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
