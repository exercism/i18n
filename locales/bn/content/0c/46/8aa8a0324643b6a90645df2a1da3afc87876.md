# নির্দেশনা

আপনি একটি এক্সক্লুসিভ মুভি থিয়েটার পরিচালনা করেন।
সিনেমা দেখতে হলে মানুষকে বার্ষিক পাস কিনতে হয়, এরপর তারা বিনামূল্যে সিনেমা দেখতে পারেন।

আপনার থিয়েটার উপস্থিতির একটি লগ রাখে।
এই মাসে কোন সদস্যরা তাদের বার্ষিক পাস ব্যবহার করেছেন, তা ট্র্যাক করতে আপনি ওই লগটি ব্যবহার করতে চান।
এছাড়া আপনার গ্রাহকদের বয়সভিত্তিক ডেমোগ্রাফিক তথ্যও পেতে চান আপনি।
এই লক্ষ্যগুলো পূরণে সেট ব্যবহার করা যায় তা আপনি বুঝতে পারেন।

## সেট

এ ধরনের ডেটা সংরক্ষণের জন্য সেট একটি আদর্শ ডেটা টাইপ।

সেট হলো এমন একটি ডেটা টাইপ যা আলাদা আলাদা, অনন্য মান কোনো নির্দিষ্ট ক্রম ছাড়াই সংরক্ষণ করে।
আলাদা ও অনন্য মানে হলো, একটি এলিমেন্ট হয় সেটে আছে, নয়তো নেই; অ্যারের মতো নয়, এটি সেটে একাধিকবার থাকতে পারে না।
সেট সাধারণত অনির্দিষ্ট ক্রমের হয়; সেটের এলিমেন্টগুলো আপনি যদি তালিকাবদ্ধ করেন, তবে যে ক্রম পাবেন তা যোগ করার ক্রম থেকে ভিন্ন হতে পারে, এমনকি আগের তালিকায় যে ক্রম পেয়েছিলেন তা থেকেও ভিন্ন হতে পারে!

সেটের একটি মৌলিক বৈশিষ্ট্য হলো মেম্বারশিপ চেক: কোনো সেটে একটি এলিমেন্ট আছে কি না তা যাচাই করার ক্ষমতা।
সেটের প্রায় সব ব্যবহারেই মেম্বারশিপ চেক কেন্দ্রীয়।

Go-তে বিল্ট-ইন সেট ডেটা টাইপ নেই।
সেটের জায়গায় `map[<type>]struct{}` বা `map[<type>]bool` ব্যবহার করা কমন; সেটের মতোই একটি `map` আলাদা আলাদা, অনন্য এলিমেন্ট যোগ করতে দেয় এবং মেম্বারশিপ চেক সমর্থন করে।

## 1. উপস্থিতদের তথ্য রাখার জায়গা

উপস্থিতি ও বয়সভিত্তিক ডেমোগ্রাফিক ট্র্যাক করতে আপনি একটি সেট ব্যবহার করতে চান।

নাম আর বয়সের জন্য আলাদা আলাদা সেট লিখতে আপনি চান না; বরং দুটির জন্যই একটি জেনেরিক সেট ব্যবহার করতে পারেন।
উপস্থিতদের সংরক্ষণের জন্য `map[T comparable]struct{}` হিসেবে একটি `Set` টাইপ ডিফাইন করুন।
একটি খালি `Set[T]` রিটার্ন করে এমন একটি `NewSet[T comparable]()` ফাংশন লিখুন।

```go
names := NewSet[string]()
```

## 2. উপস্থিতদের ট্র্যাক করা

এখন আপনি উপস্থিতদের তথ্য রেকর্ড করার জন্য প্রস্তুত।

সেটে একটি এলিমেন্ট যোগ করে এমন একটি `Add[T]()` মেথড লিখুন।

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. উপস্থিতদের যাচাই

এখন আপনার কাছে উপস্থিতদের একটি সেট আছে, তাই নির্দিষ্ট সদস্যরা এবং বয়সভিত্তিক ডেমোগ্রাফিক উপস্থিত ছিলেন কি না তা যাচাই করতে পারেন।
কোনো সদস্য বা বয়সভিত্তিক ডেমোগ্রাফিক `Set`-এ আছে কি না তা রিটার্ন করে এমন একটি `Contains[T](element)` মেথড লিখুন।

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. উপস্থিতদের তুলনা

আরও একটি মাস কেটে গেছে, এবং আপনার কাছে বয়সভিত্তিক ডেমোগ্রাফিকের একটি নতুন `Set` আছে।
এই মাসের নতুন রিলিজগুলোয় কোন বয়সের গ্রাহকরা আসছেন তা বদলে গেছে কি না, আপনার মার্কেটিং ম্যানেজার তা জানতে চান।
দুটি সেটের এলিমেন্ট একই কি না তা নির্ধারণ করে এমন একটি `Equals[T](other)` মেথড লিখুন।

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
