# পরিচিতি

একটি ফাংশন [টেইল-রিকার্সিভ][recursion-tc] হয়, যদি ফাংশনটি যে কাজটি সবার _শেষে_ করে সেটি হয় নিজেকে কল করা।

কোনো ফাংশন প্রতিবার কল করা হলে তার লোকাল ভ্যারিয়েবল, আর্গুমেন্ট ইত্যাদি নিয়ে একটি _স্ট্যাক ফ্রেম_ [ফাংশন কল স্ট্যাকের][call-stack] উপরে রাখা হয়। কোনো ফাংশন রিটার্ন করলে স্ট্যাক ফ্রেমটি স্ট্যাক থেকে সরিয়ে ফেলা হয়।

টেইল-রিকার্সিভ ফাংশন [টেইল কল অপটিমাইজেশনের][tail-call-optimization] সুযোগ দেয়। এটি এমন একটি অপটিমাইজেশন, যা পরবর্তী ফাংশন কলের সময় সর্বশেষ স্ট্যাক ফ্রেমটি পুনর্ব্যবহার করার সুযোগ দেয়, কারণ আগের ফাংশনটির যে এটির আর দরকার নেই তা নিশ্চিত। এটি ফাংশন কল স্ট্যাক ওভারফ্লো হওয়ার আশঙ্কা কমিয়ে দেয়, অর্থাৎ এমন পরিস্থিতি যেখানে ফাংশন কল স্ট্যাকে এত বেশি ফ্রেম থাকে যে আর একটি তৈরি করার জন্য কোনো মেমোরি অবশিষ্ট থাকে না।

- Elixir-এ টেইল কল রিকার্সন পেতে হলে প্রায়ই একটি অ্যাকুমুলেটরের দরকার হয়, কারণ ডেটার ইমিউটেবিলিটির নিয়ম।

  - অ্যাকুমুলেটর হলো একটি ভ্যারিয়েবল, যা রিকার্সিভ কলের সাথে সাথে চলে এবং বেস কেসে চূড়ান্ত ফলাফল রিটার্ন না হওয়া পর্যন্ত রিকার্সিভ ফাংশনের _এখন পর্যন্ত_ বর্তমান অবস্থা ধরে রাখে।

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- অ্যারে নিয়ে কাজ করার সময় মনে রাখবেন, এগুলো সিঙ্গলি-লিংকড অ্যারে হিসেবে ইমপ্লিমেন্ট করা হয়: প্রিপেন্ড অপারেশন খুব দ্রুত, কিন্তু অ্যাপেন্ড অপারেশন খুব ধীর।

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
