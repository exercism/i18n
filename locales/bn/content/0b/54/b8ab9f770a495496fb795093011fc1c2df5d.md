# উপেক্ষা করুন

## jq-এর অতিরিক্ত কমান্ড-লাইন অপশন

টেস্টগুলোতে `jq`-এর জন্য অতিরিক্ত কিছু অপশন দেখতে পাবেন।

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

এগুলো কী?

- `-s`

  এটি "slurp" মোড।
  ইনপুটকে JSON অবজেক্টের একটি স্ট্রিম হিসেবে না ধরে,
  পুরো ইনপুট একটি অ্যারেতে slurp করা হয়।

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  `-r` অপশনটি আপনি হয়তো আগেই দেখেছেন, যেটি "raw" স্ট্রিং আউটপুট দেয় (কোট ছাড়া)।
  এটা তার উল্টো।
  ইনপুটের প্রতিটি লাইনকে একটি স্ট্রিং হিসেবে ধরা হয়।

  দুটি উদাহরণ:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

এই দুইটি অপশন একসাথে ব্যবহার করলে আপনি স্ট্রিংয়ের একটি অ্যারে _পাবেন না_:
বরং পুরো ইনপুটটাই একটি একক স্ট্রিং হিসেবে পাবেন, লাইন-শেষের নিউলাইনগুলোসহ।

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

এটা সামলানোই এই অনুশীলনীর চ্যালেঞ্জের একটি অংশ।
