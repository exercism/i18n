# নির্দেশনা

জশ একটি নতুন রোল-প্লেয়িং গেম তৈরি করছে এবং এর কিছু মেকানিক ইমপ্লিমেন্ট করতে আপনার সাহায্য প্রয়োজন।

## 1. নিজের পরিচয় দিন

`introduce` ফাংশনটি ইমপ্লিমেন্ট করুন।

স্টিলথি প্লেয়াররা হয়তো তাদের নাম গোপন করে থাকতে পারেন এবং `"Mighty Magician"` হিসেবে পরিচয় দেওয়া হবে।
অন্যথায়, পরিচয় দিতে শুধু প্লেয়ারের নামটি ব্যবহার করুন।

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. রিভাইভ মেকানিকটি ইমপ্লিমেন্ট করুন

`revive` ফাংশনটি যাচাই করবে যে প্লেয়ারের ক্যারেক্টারটি সত্যিই মৃত (তাদের হেলথ ০-এ পৌঁছেছে)।
তারা মৃত হলে, এটি ১০০ হেলথসহ নতুন একটি `Player` ইনস্ট্যান্স রিটার্ন করবে।
অন্যথায়, প্লেয়ারের ক্যারেক্টারটি মৃত না হলে, `revive` ফাংশনটি `None` রিটার্ন করে।

প্লেয়ারের লেভেল ১০ বা তার বেশি হলে, এছাড়াও তাদের ১০০ ম্যানাসহ রিভাইভ করা উচিত।
প্লেয়ারের লেভেল ১০-এর নিচে হলে, তাদের ম্যানা অপরিবর্তিত রাখা উচিত।
`revive` ফাংশনটি প্লেয়ারের লেভেল অপরিবর্তিত রাখবে।

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

যদি `revive` মেথডটি এমন কোনো প্লেয়ারের ওপর কল করা হয় যাদের হেলথ ১ বা তার বেশি, তবে ফাংশনটি `None` রিটার্ন করবে।

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. স্পেল কাস্টিং মেকানিকটি ইমপ্লিমেন্ট করুন

`cast_spell` ফাংশনটি আর্গুমেন্ট হিসেবে একটি `Int` নেয়, যা নির্দেশ করে স্পেলটির কত ম্যানা খরচ হয়, এবং এর সাথে একটি `Player`-ও নেয়।
এটি আপডেট হওয়া প্লেয়ার এবং কাস্ট করা স্পেল যে পরিমাণ ড্যামেজ করে, তা রিটার্ন করে।
সফলভাবে স্পেল কাস্ট করলে স্পেলটির ম্যানা খরচের দুই গুণের সমান ড্যামেজ হয়।
তবে, প্লেয়ারের কাছে যথেষ্ট ম্যানা না থাকলে কিছুই হয় না, প্লেয়ার অপরিবর্তিত থাকে এবং কোনো ড্যামেজ হয় না।
প্লেয়ারের যদি ম্যানা পুলই না থাকে, তবে স্পেল কাস্ট করার চেষ্টা করলে তাদের হেলথ স্পেলটির ম্যানা খরচের সমান কমিয়ে দেবে এবং কোনো ড্যামেজ করবে না।
মনে রাখবেন, প্লেয়ারদের হেলথ শূন্যের (০) নিচে হতে পারে না।

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
