# ইঙ্গিত

## 1. নিজের পরিচয় দিন

`introduce` ফাংশনটিকে `player.Name`-এর ভেতরে থাকা মানটি "আনর্যাপ" করতে হবে।
[`Options.defaultValue` ফাংশনটি][defaultvalue] দিয়ে `player.Name`-কে, সেটি `Some` থাকলে তার "র্যাপ করা" মানে, আর `None` থাকলে প্রয়োজনীয় ডিফল্ট মানে রূপান্তর করার কথা ভাবতে পারেন।

## 2. রিভাইভ মেকানিকটি বাস্তবায়ন করুন

`revive` ফাংশনটিকে হয় `Some <player>` নয়তো `None` রিটার্ন করতে হবে, যেখানে `<player>` হলো একটি `Player` রেকর্ড, যার কিছু ফিল্ড পরিবর্তিত থাকতে পারে।

## 3. জাদু নিক্ষেপের মেকানিকটি বাস্তবায়ন করুন

`Some` ও `None` দুটো ক্ষেত্রই কভার করতে একটি match এক্সপ্রেশন ব্যবহার করার কথা ভাবতে পারেন, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
