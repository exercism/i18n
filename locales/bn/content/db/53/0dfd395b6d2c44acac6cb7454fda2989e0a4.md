# পরিচিতি

[বিটস্ট্রিং][bitstring] প্রোগ্রামারদের বাইনারি ডেটা নিয়ে কার্যকরভাবে কাজ করার সুযোগ দেয়।

- আপনি [`<<>>` স্পেশাল ফর্ম][bitstring-form] ব্যবহার করে বিটস্ট্রিং খুব সুন্দরভাবে তৈরি করতে পারেন।

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- আপনি `<<>>` ফর্ম দিয়ে ম্যাচ করতে পারেন এবং সেই ম্যাচ ব্যবহার করে আরও [বাইনারি ডেটা বিশ্লেষণ][bitstring-matching] করতে পারেন।

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- আপনি `::bitstring` ব্যবহার করে বিটস্ট্রিংয়ের বাকি অংশের সাথে ম্যাচ করতে পারেন।

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- বাইনারি ডেটা *টাইপ* হলো এক বিশেষ ধরনের বিটস্ট্রিং, যেখানে বিটের সংখ্যা ৮ দিয়ে নিঃশেষে বিভাজ্য হয়।
  - সব বাইনারিই বিটস্ট্রিং, কিন্তু সব বিটস্ট্রিং বাইনারি নয়।
- Elixir বিভিন্ন রূপে [ইন্টিজার লিটারেল][integer-literal] নিয়ে কাজ করার জন্য সিনট্যাকটিক সুগার দেয়:
  - `0b1000001 = ?A = 65`

[bitstring]: https://hexdocs.pm/elixir/binaries-strings-and-charlists.html#bitstrings
[bitstring-form]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#%3C%3C%3E%3E/1
