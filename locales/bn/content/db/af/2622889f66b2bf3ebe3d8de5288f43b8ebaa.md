# নির্দেশনা

চোখ কপালে তোলার মতো দৈনিক পারিশ্রমিকের লোভে আপনাকে আবার হাইপেরিয়ায় (উচ্চ মুদ্রাস্ফীতি নিয়ে) ফিরিয়ে আনা হয়েছে।

কেন্দ্রীয় ব্যাংক মার্কিন ডলারকে দ্বিতীয় মুদ্রা হিসেবে চালু করার কথা ভাবছে, তাই একাধিক মুদ্রা সামলাতে সব হিসাবরক্ষণ সিস্টেমকে মানিয়ে নিতে হবে।

কারেন্সি অ্যামাউন্ট অবজেক্টটি তৈরি করতে আপনাকে বলা হয়েছে।

## 1. কারেন্সি অ্যামাউন্টের সমতা যাচাই চালু করুন

অনুগ্রহ করে সমতা সামলানোর জন্য `CurrencyAmount` স্ট্রাক্টটি পরিবর্তন করুন। দুটি কারেন্সি অ্যামাউন্ট স্ট্রাক্টের মুদ্রা একই না হলে ("USD" অথবা "HD"), তাহলে `ArgumentException`-এর একটি ইনস্ট্যান্স থ্রো করা উচিত।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. কারেন্সি অ্যামাউন্ট তুলনা করুন

অনুগ্রহ করে তুলনা সামলানোর জন্য (`>` এবং `<`, শুধু এই দুটি) `CurrencyAmount` স্ট্রাক্টটি পরিবর্তন করুন। দুটি কারেন্সি অ্যামাউন্ট স্ট্রাক্টের মুদ্রা একই না হলে ("USD" অথবা "HD"), তাহলে `ArgumentException`-এর একটি ইনস্ট্যান্স থ্রো করা উচিত।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. কারেন্সি অ্যামাউন্ট যোগ ও বিয়োগ করুন

অনুগ্রহ করে গাণিতিক যোগ ও বিয়োগ সামলানোর জন্য (`+` এবং `-`, শুধু এই দুটি) `CurrencyAmount` স্ট্রাক্টটি পরিবর্তন করুন। দুটি কারেন্সি অ্যামাউন্ট স্ট্রাক্টের মুদ্রা একই না হলে ("USD" অথবা "HD"), তাহলে `ArgumentException`-এর একটি ইনস্ট্যান্স থ্রো করা উচিত।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. কারেন্সি অ্যামাউন্ট গুণ ও ভাগ করুন

অনুগ্রহ করে গাণিতিক গুণ ও ভাগ সামলানোর জন্য (`*` এবং `/`, শুধু এই দুটি) `CurrencyAmount` স্ট্রাক্টটি পরিবর্তন করুন।

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. কারেন্সি অ্যামাউন্টকে `double` টাইপে রূপান্তর করুন

অনুগ্রহ করে `CurrencyAmount` স্ট্রাক্টটি এমনভাবে পরিবর্তন করুন যাতে একটি ইনস্ট্যান্সকে স্পষ্টভাবে `double`-এ কাস্ট করা যায়।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. কারেন্সি অ্যামাউন্টকে `decimal` টাইপে রূপান্তর করুন

অনুগ্রহ করে `CurrencyAmount` স্ট্রাক্টটি এমনভাবে পরিবর্তন করুন যাতে একটি ইনস্ট্যান্স অন্তর্নিহিতভাবে `decimal`-এ রূপান্তর করা যায়।

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
