# টাইপ ডিক্লারেশন

PHP-তে টাইপ ডিক্লারেশন ফাংশন আর্গুমেন্ট, রিটার্ন ভ্যালু এবং ক্লাস প্রপার্টির জন্য রান টাইমে টাইপ অ্যাসারশন প্রদান করে।
ফাংশনে `void` রিটার্ন টাইপ যোগ করা যায়, যা বোঝায় যে ফাংশন থেকে কোনো মান রিটার্ন করা হয় না।
ডিক্লেয়ার করা টাইপগুলো রান টাইম অ্যাসারশন হিসেবেও কাজ করে, যে ফাংশনগুলো যুক্তিসঙ্গত টাইপের রেসপন্স রিটার্ন করছে।

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## টাইপ ইউনিয়ন

যদি একটি ফাংশন আর্গুমেন্ট, রিটার্ন ভ্যালু বা ক্লাস প্রপার্টি একাধিক টাইপের হতে পারে, তবে একটি টাইপ ইউনিয়ন ডিক্লেয়ার করা যায়।

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## মিক্সড টাইপ

কোড নিয়ে কাজ করার সময়, আমরা হয়তো একটি টাইপ নির্দিষ্ট করতে পারি না।
PHP 8.0 থেকে `mixed` নামে একটি এস্কেপ-হ্যাচ টাইপ প্রদান করা হয়েছে।
মিক্সড হলো `object|resource|array|string|float|int|bool|null`-এর একটি টাইপ ইউনিয়নের সমতুল্য।
