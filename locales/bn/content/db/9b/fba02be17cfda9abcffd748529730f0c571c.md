# নির্দেশনা সংযোজন

## ওয়ার্ড

`stopwatch` টাপল এবং একটি কনস্ট্রাক্টর `<stopwatch> ( -- stopwatch )` ডিফাইন করুন, যা `"ready"` স্টেটে একটি নতুন স্টপওয়াচ রিটার্ন করে; সেই স্টপওয়াচে কোনো অতিবাহিত সময় বা আগের ল্যাপ থাকে না।

স্টপওয়াচের উপর কাজ করে এমন এই ওয়ার্ডগুলো দিন:

- `state ( stopwatch -- str )`: `"ready"`, `"running"` বা `"stopped"`।
- `current-lap ( stopwatch -- str )`: চলতি ল্যাপের অতিবাহিত সময়, একটি `"HH:MM:SS"` স্ট্রিং হিসেবে।
- `total ( stopwatch -- str )`: চলতি ল্যাপ ও আগের সব ল্যাপের মিলিত অতিবাহিত সময়, একটি `"HH:MM:SS"` স্ট্রিং হিসেবে।
- `previous-laps ( stopwatch -- seq )`: আগে রেকর্ড করা ল্যাপগুলোর একটি অ্যারে, প্রতিটি একটি `"HH:MM:SS"` স্ট্রিং হিসেবে।
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )` এবং `lap ( stopwatch -- )`: উপরের টেবিলের চারটি কমান্ড। যে স্টেট থেকে কোনোটি কল করা অনুমোদিত নয়, সেখান থেকে কল করলে একটি এরর `throw` করা উচিত।

সময় এগিয়ে নেওয়া হয় এভাবে:

- `advance-time ( str stopwatch -- )`: চলতি ল্যাপে `"HH:MM:SS"` ডিউরেশনটি যোগ করুন। স্টপওয়াচটি চলছে, কেবল তখনই এর কোনো প্রভাব পড়ে।
