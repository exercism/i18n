# টেস্ট

টেস্ট চালানোর কয়েকটি উপায় আছে।

## Emacs-এর ভেতর থেকে ইন্টারঅ্যাক্টিভভাবে

1. টেস্ট ফাইল খুলুন, `M-x eval-buffer RET`
2. ইন্টারঅ্যাক্টিভভাবে এবং আলাদা আলাদা করে, `M-x ert RET test-name RET` দিয়ে
3. ইন্টারঅ্যাক্টিভভাবে এবং একসাথে সবগুলো, `M-x ert RET t RET` দিয়ে
   মনে রাখবেন, এটি Emacs-এ এই মুহূর্তে লোড করা সব টেস্ট চালাবে!
4. পরিবর্তন করলে টেস্ট করার আগে `M-x eval-buffer RET` আবার চালান

শুধু বর্তমান বাফারের টেস্টগুলো চালাতে চাইলে আপনি এটি আপনার `.emacs` বা `init.el`-এ যোগ করতে পারেন:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Emacs আবার চালু করার পর:

1. টেস্ট ফাইল খুলুন
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## টার্মিনাল থেকে

টার্মিনাল থেকে ব্যাচ মোডে সব টেস্ট চালাতে, `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit` চালান

উপরের কমান্ডটি একটু জটিল, তাই চাইলে:

1. আপনার `$PATH`-এ (সম্ভবত `~/bin`-এ) `ert-run` নামে একটি ফাইল তৈরি করুন
2. ফাইলটির বিষয়বস্তু নিম্নরূপ হওয়া উচিত:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. `chmod +x ert-run` দিয়ে ফাইলটিকে এক্সিকিউটেবল করুন

এখন আপনি সহজেই `ert-run *-test.el` কল করে ব্যাচ মোডে টেস্ট চালাতে পারবেন।

## অন্যান্য অপশন

অন্যান্য অপশন ডকুমেন্টেশনে পাওয়া যাবে, `C-h i m ert RET`.
