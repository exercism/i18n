# পরিচিতি

Rust-এ বুলিয়ানকে `bool` টাইপ দিয়ে প্রকাশ করা হয়, যার মান `true` অথবা `false` হতে পারে।

Rust ছয়টি তুলনা অপারেটর সমর্থন করে: `==` (সমান), `!=` (সমান নয়), `>` (বড়), `<` (ছোট), `>=` (বড় বা সমান), `<=` (ছোট বা সমান)। এগুলি বুলিয়ান নয় এমন মানের সম্পর্ককে একটি বুলিয়ান মানে মূল্যায়ন করতে ব্যবহার করা যায়।

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

কিছু অন্য ভাষার মতো নয়, এখানে `0` মানে `false` নয় এবং অ-শূন্য মানে `true` নয়।

Rust দুটি বুলিয়ান অপারেটর সমর্থন করে: `||` (অথবা), `&&` (এবং)। এগুলি শুধু তখনই মূল্যায়ন করা হয় যখন বামদিকের অপারেন্ড ইতিমধ্যে এক্সপ্রেশনের ফলাফল নির্ধারণ করে না। অর্থাৎ, `||` তার ডানদিকের অপারেন্ড শুধু তখনই মূল্যায়ন করে যখন বামদিকের অপারেন্ড `false`-এ মূল্যায়ন করে, এবং `&&` শুধু তখনই যখন এটি `true`-এ মূল্যায়ন করে।
