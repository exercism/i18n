# ভূমিকা

## টাইপ অ্যালিয়াস

### টাইপ অ্যালিয়াস

Gleam-এ কোনো টাইপ অ্যালিয়াস ব্যবহার করে এমন একটি বিদ্যমান টাইপের জন্য সুবিধাজনক নাম দেওয়া যায়, যা অন্যথায় লিখতে ঝামেলার হতো।

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type` দিয়ে লেখা হলে অ্যালিয়াসটি যে মডিউলে ডিফাইন করা হয়েছে তার বাইরেও ব্যবহার করা যায়। `pub` বাদ দিলে অ্যালিয়াসটি প্রাইভেট হয়ে যায় এবং অন্য মডিউল থেকে রেফারেন্স করা যায় না।

## ডিক্ট

Gleam-এ ডিক্ট হলো কী (key) আর মানের জোড়া হিসেবে তথ্য সংরক্ষণ করার ডেটা স্ট্রাকচার। অন্য ভাষায় এগুলোকে অ্যাসোসিয়েটিভ অ্যারে, হ্যাশ বা ডিকশনারি নামেও চেনা যায়।

ডিক্টে কী (key) ও মানের জন্য যেকোনো টাইপ ব্যবহার করা যায়, আর অ্যাক্সেস বা রিটার্ন করার সময় ডিক্ট তার এন্ট্রিগুলোর ক্রম নিশ্চিত করে না।

### ডিক্ট নিয়ে কাজ করা

`gleam/dict` মডিউলের ফাংশন ব্যবহার করে ডিক্ট তৈরি ও ম্যানিপুলেট করা হয়।

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
