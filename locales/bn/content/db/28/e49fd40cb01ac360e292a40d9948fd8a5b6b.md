# পরিচিতি

## অ্যারে

Cairo-এর কোর লাইব্রেরি একটি `Array` টাইপ ইমপ্লিমেন্ট করে।

এটি অন্য প্রোগ্রামিং ভাষায় দেখা সাধারণ অ্যারে টাইপগুলোর মতোই, তবে কয়েকটি গুরুত্বপূর্ণ পার্থক্য আছে:

- এলিমেন্ট কেবল `Array` টাইপের পেছনে দক্ষতার সাথে যোগ করা যায়, আর কেবল সামনে থেকে দক্ষতার সাথে সরানো যায়।
- অ্যারে ইনডেক্স ব্যবহার করে হাতে কোনো আইটেম সেট করা সম্ভব নয়।

`ArrayTrait::new` ফাংশন এবং `array!` ম্যাক্রো দিয়ে অ্যারে তৈরি করা যায়:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

`ArrayTrait::append` ফাংশন দিয়ে অ্যারেতে এলিমেন্ট যোগ করা যায়:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

`ArrayTrait::pop_front` ফাংশন দিয়ে অ্যারে থেকে এলিমেন্ট সরানো যায়:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo একটি `Span` টাইপও নিয়ে আসে, যা `Array`-এর একটি "স্ন্যাপশট"-এর মতো আচরণ করে।

`ToSpanTrait::span` ফাংশন দিয়ে প্রতিটি `Array`-কে একটি `Span`-এ রূপান্তর করা যায়:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

অ্যারে-কে `Span`-এ রূপান্তর করা খুবই দক্ষ, কারণ `Span` কেবল একটি ডেটা স্ট্রাকচার, যা Cairo-কে অ্যারের একটি অংশ "দেখতে" দেয়, এটি কোনোভাবেই অ্যারেটি পরিবর্তন করে না।

অ্যারে-কে `Span`-এ রূপান্তর করে Cairo সরাসরি `Array`-এর উপর যেসব অপারেশন অনুমোদিত হতো তার চেয়ে বেশি অপারেশন করার সুযোগ দেয়, যেমন span-এর সামনে থেকে একটি এলিমেন্ট সরিয়ে ফেলা।

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

লক্ষ্য করুন, `pop_back` কল করার জন্য আমাদের `mut` কিওয়ার্ড দিয়ে `one_to_four_span`-কে মিউটেবল করতে হয়েছিল, যা span-টি অ্যারের যে অংশটি "দেখছে" সেটি ছোট করে span-টিকে মিউটেট করে।
