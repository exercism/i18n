# নির্দেশনা

এই অনুশীলনীতে আপনি একটি ওজন মাপার যন্ত্র মডেল করবেন, যেখানে একক হিসেবে থাকবে কিলোগ্রাম।

আপনার জন্য ৬টি কাজ আছে, যার প্রতিটিতে এক বা একাধিক প্রপার্টি ইমপ্লিমেন্ট করতে হবে:

## 1. ওজন মাপার যন্ত্রে একটি প্রিসিশন থাকতে দিন

ভিন্ন ভিন্ন চাহিদা মেটাতে আমরা প্রতিটি ওজন মাপার যন্ত্রকে একটি প্রিসিশন দিয়ে কাস্টমাইজ করার সুযোগ দিই (দশমিক বিভাজকের পরে কতটি অঙ্ক থাকবে তার সংখ্যা)।
কনস্ট্রাক্টরের `precision` আর্গুমেন্ট দিয়ে সেট করা একটি গেট-অনলি `Precision` প্রপার্টি রাখতে `WeighingMachine` ক্লাসটি ইমপ্লিমেন্ট করুন:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. ওজন মাপার যন্ত্রে ওজন সেট করার সুযোগ দিন

ওজন get _এবং_ set করার সুযোগ দিতে `WeighingMachine.Weight` প্রপার্টিটি ইমপ্লিমেন্ট করুন:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. ঋণাত্মক ইনপুট ওজন যেন বাতিল হয় তা নিশ্চিত করুন

স্পষ্টতই, কারও ওজন ঋণাত্মক হতে পারে না।
ঋণাত্মক ওজন সেট করার চেষ্টা করলে একটি `ArgumentOutOfRangeException` থ্রো করতে `WeighingMachine.Weight` প্রপার্টিতে ভ্যালিডেশন যোগ করুন:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. ওজন মাপার যন্ত্রে টেয়ার অ্যাডজাস্টমেন্ট প্রয়োগ করার সুযোগ দিন

টেয়ার অ্যাডজাস্টমেন্ট যেকোনো মান হতে পারে (এমনকি ঋণাত্মক, বা এমন মান যা ডিসপ্লের ওজনকে ঋণাত্মক করে দেয়)
টেয়ার অ্যাডজাস্টমেন্ট সেট করার সুযোগ দিতে `WeighingMachine.TareAdjustment` প্রপার্টিটি ইমপ্লিমেন্ট করুন:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. ওজন মাপার যন্ত্রের একটি ডিফল্ট টেয়ার অ্যাডজাস্টমেন্ট যেন থাকে তা নিশ্চিত করুন

বেশ কিছু পুঙ্খানুপুঙ্খ পরীক্ষার পর দেখা গেল, একটি উৎপাদন ত্রুটির কারণে সব ওজন মাপার যন্ত্রেরই ওজন `5` বেশি দেখানোর দিকে একটা ঝোঁক রয়েছে।
`WeighingMachine.TareAdjustment` প্রপার্টিটির ডিফল্ট মান হিসেবে `5` নির্ধারণ করুন।

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. ওজন পড়ার সুযোগ দিন

`WeighingMachine.DisplayWeight` প্রপার্টিটি ইমপ্লিমেন্ট করুন, যা টেয়ার অ্যাডজাস্টমেন্ট প্রয়োগের পরের ওজন, সঠিক প্রিসিশনসহ এবং একক যোগ করা অবস্থায়, একটি স্ট্রিং হিসেবে রিটার্ন করবে।
লক্ষ্য করুন:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
