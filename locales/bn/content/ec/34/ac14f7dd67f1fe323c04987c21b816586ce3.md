# সম্পর্কে

C++-এ আপনি তুলনা অপারেটর ব্যবহার করে মান তুলনা করতে পারেন।

| তুলনা             | অপারেটর   |
| ------------------| --------- |
| সমান             | `==`      |
| অসমান            | `!=`      |
| কম               | `<`       |
| কম বা সমান       | `<=`      |
| বেশি             | `>`       |
| বেশি বা সমান     | `>=`      |

এই তুলনাগুলোর ফলাফল সবসময় একটি বুলিয়ান মান:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

`==` আর `!=` অপারেটর দুটি যথাক্রমে যাচাই করে একটি মান অন্য একটি মানের সমান কি না।
এখানে কিছু কমন উদাহরণ আছে:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

বাকি অপারেটরগুলো যাচাই করে একটি মান অন্য একটি মানের চেয়ে বেশি কি না (`>`), বেশি বা সমান কি না (`>=`), কম কি না (`<`), আর কম বা সমান কি না (`<=`)।
এই ধরনের তুলনা সংখ্যা ও স্ট্রিংয়ের জন্য ব্যবহার করা যায়।
স্ট্রিং তুলনা করার সময় অভিধানের ক্রম (যা লেক্সিকোগ্রাফিক ক্রম নামেও পরিচিত) অনুসরণ করা হয়।

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
