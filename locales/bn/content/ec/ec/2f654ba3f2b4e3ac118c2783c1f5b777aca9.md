# সম্পর্কে

## স্ট্রাক্ট টাইপ

আমরা আগেই স্ট্রাক্ট টাইপ দেখেছি; সংক্ষেপে বলতে গেলে, একটি `struct` হলো নামযুক্ত এলিমেন্টের একটি সিরিজ, যাদেরকে _ফিল্ড_ বলা হয়, আর প্রতিটি ফিল্ডের একটি নাম ও একটি টাইপ থাকে।
একটি স্ট্রাক্টের ভেতরে একটি ফিল্ডের নাম অবশ্যই অনন্য হতে হবে।
`Structs`-কে অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং প্যারাডাইমের _ক্লাস_-এর সাথে তুলনা করা যায়।

`type` ও `struct` কিওয়ার্ড ব্যবহার করে আপনি একটি নতুন স্ট্রাক্ট তৈরি করেন, তারপর নিচের উদাহরণে দেখানো মতো ফিল্ডগুলোর নাম ও টাইপ স্পষ্টভাবে ডিফাইন করেন।

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## নন-স্ট্রাক্ট টাইপ

আপনি এমন নন-স্ট্রাক্ট টাইপও ডিফাইন করতে পারেন, যা বিল্ট-ইন টাইপ ডিক্লারেশনের অ্যালিয়াস হিসেবে ব্যবহার করা যায়।

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

অ্যারে ও ম্যাপ দিয়ে গঠিত নন-স্ট্রাক্ট টাইপও আপনি ডিফাইন করতে পারেন।

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
