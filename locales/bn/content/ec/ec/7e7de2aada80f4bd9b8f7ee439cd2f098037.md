# ফ্লোটিং পয়েন্ট সংখ্যা

`INT` কেবল পূর্ণ সংখ্যা ধরে রাখে, আর সেগুলোর দুটিকে ভাগ করলে ভাগশেষ বাদ পড়ে যায়:

```sather
7 / 2        -- 3, not 3.5
```

ভগ্নাংশটা যখন গুরুত্বপূর্ণ, তখন টাইপটি `FLTD`, একটি **ফ্লোটিং পয়েন্ট** সংখ্যা, যা পূর্ণ সংখ্যাগুলোর মাঝের মানও ধরে রাখতে পারে।

## কীভাবে লিখবেন

একটি ফ্লোটিং পয়েন্ট লিটারেলে দশমিক বিন্দু থাকে আর শেষে একটি `d` থাকে।

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

`d` ঐচ্ছিক নয়। একা `440.0` একটি ভিন্ন টাইপ, যার নির্ভুলতা কম; `d` দিয়ে সেই টাইপটিই চাওয়া হয় যা এই ট্র্যাক সর্বত্র ব্যবহার করে।

`2.0d` লিখুন, `2d` নয়; দশমিক বিন্দুটাও থাকতে হবে।

## পাটিগণিত

`+`, `-`, `*` আর `/` সবই কাজ করে, আর `/` এখন ভগ্নাংশ ধরে রাখে:

```sather
7.0d / 2.0d      -- 3.5
```

দুই পাশেই `FLTD` থাকতে হবে। Sather চুপচাপ দুই টাইপ মিশিয়ে দেয় না, তাই `7 / 2.0d` বিস্ময়ের বদলে একটি এরর।

## পূর্ণ সংখ্যা থেকে

`.fltd` একটি `INT`-কে `FLTD`-তে রূপান্তর করে:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` হলো `3.5`। খেয়াল করুন রূপান্তরটা কোথায় বসছে: `(7 / 2).fltd` হতো `3.0`, কারণ ভাগটা ইতিমধ্যেই অর্ধেকটা ফেলে দিত। ভাগ করার **আগে** রূপান্তর করুন, পরে নয়।

## কতটা দূরে?

`.abs` মাইনাস চিহ্নটা ফেলে দেয়; কোনটি বড় তা গ্রাহ্য না করেই দুটি মান কতটা দূরে তা জানার উপায় এটাই:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
