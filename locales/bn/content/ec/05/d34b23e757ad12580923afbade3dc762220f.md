# পরিচিতি

## সমতা

Common Lisp-এ অনেকগুলো ভিন্ন সমতা প্রেডিকেট আছে।
এটি অন্য প্রোগ্রামিং ভাষাগুলোর থেকে আলাদা, যেখানে সম্ভবত মাত্র একটি বা দুটি থাকে (যেমন `==` আর `===`)।
Common Lisp-এর এসব প্রেডিকেটের মধ্যে কিছু টাইপ-নির্দিষ্ট, আবার কিছু জেনেরিক।
এখানে আলোচনা করা হবে এই শেষেরগুলো নিয়ে।

চারটি জেনেরিক সমতা প্রেডিকেট আছে, আর কীকে তারা "equal" মনে করে, সেই বিচারে তাদের কঠোরতা আলাদা।
সবচেয়ে কঠোর থেকে সবচেয়ে শিথিল ক্রমে সেগুলো হলো: `eq`, `eql`, `equal` আর `equalp`।

সংক্ষেপে কয়েকটি সংজ্ঞা (কিছু খুঁটিনাটি বাদ দিয়ে) নিচে দেওয়া হলো:

- `eq`: সমতা বলতে বোঝায় দুটি অবজেক্ট একেবারে অভিন্ন।
  _যেমন_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: সমতা বলতে বোঝায় একই টাইপ ও মানের দুটি সংখ্যা, দুটি একই ক্যারেক্টার, কিংবা অন্য যেকোনো কিছু যদি তারা `eq` হয়।
  _যেমন_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: সমতা বলতে বোঝায়: দুটি তালিকা `equal` হয় যদি তাদের প্রতিটি এলিমেন্টও `equal` হয়; দুটি স্ট্রিং `equal` হয় যদি প্রতিটি এলিমেন্ট `eql` হয়; দুটি অ্যারে `equal` হয় যদি তারা `eq` হয়; আর বাকি সবকিছু `equal` হয় যদি তারা `eql` হয়।
  _যেমন_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: সমতা বলতে বোঝায়: স্ট্রিং আর ক্যারেক্টার তুলনা করা হয় বড়-ছোট হাতের অক্ষর নির্বিশেষে; সংখ্যা তুলনা করা হয় কিছু টাইপ কনভার্সন-সহ; তালিকা আর অ্যারে `equalp` হয় যদি প্রতিটি এলিমেন্টও `equalp` হয়, স্ট্রাকচার হয় যদি সেগুলো একই টাইপের হয় আর সব স্লট `equalp` হয়, আর হ্যাশ-টেবিল হয় যদি তার কী (key) ও মান `equalp` হয়
  _যেমন_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
