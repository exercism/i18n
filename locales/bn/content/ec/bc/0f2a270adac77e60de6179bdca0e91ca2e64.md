# ভূমিকা

একটি ডিকশনারি হলো এলিমেন্টের এমন একটি কালেকশন, যেখানে প্রতিটি এলিমেন্ট একটি কী (key) আর একটি মান নিয়ে গঠিত, এবং ডিকশনারির কোনো মেথডে সেই কী (key) পাঠালে তার সঙ্গে যুক্ত মানটি রিটার্ন করা হয়। অন্য ভাষায় ম্যাপ বা অ্যাসোসিয়েটিভ অ্যারে যে ভূমিকা পালন করে, ডিকশনারিরও তা-ই।

একটি ডিকশনারি এভাবে তৈরি করা যায়:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

অথবা

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

লক্ষ্য করুন, কী (key) ও মানের টাইপ ডিকশনারির সংজ্ঞারই অংশ।

একবার তৈরি হয়ে গেলে, ডিকশনারির বিল্ট-ইন মেথড `Add` ও `Remove` দিয়ে এন্ট্রি যোগ বা মুছে ফেলা যায়।

ডিকশনারির মান পড়া বা হালনাগাদ করা হয় একটি কী (key) দিয়ে ডিকশনারিতে ইনডেক্স করার মাধ্যমে:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

ডিকশনারিতে কোনো মান আছে কি না, তা এভাবে পরীক্ষা করতে পারেন:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

কোনো ডিকশনারিতে এনুমারেট করলে তার কী (key)/মান জোড়াগুলোর উপর এনুমারেট করা হয়। ডিকশনারির এমন প্রপার্টিও থাকে, যা দিয়ে শুধু তার কী (key) বা মানগুলোর উপর এনুমারেট করা যায়।
