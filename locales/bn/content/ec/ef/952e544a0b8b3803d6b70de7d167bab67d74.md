# নির্দেশনার সংযোজন

## আউটপুট ফরম্যাট

বয়স বছরের এক-শতাংশে আউটপুট করুন।

উদাহরণস্বরূপ, 100 × 1,000,000,000 ÷ 31,557,600 ≈ 3,169, তাই 1,000,000,000 সেকেন্ড বয়সী কারও বয়স হয় পৃথিবীর এক বছরের `3169` এক-শতাংশ।

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | গ্রহ (`0` = বুধ, `1` = শুক্র, `2` = পৃথিবী, `3` = মঙ্গল, `4` = বৃহস্পতি, `5` = শনি, `6` = ইউরেনাস, `7` = নেপচুন) |
| `$a1`    | ইনপুট     | ইন্টিজার | সেকেন্ড                       |
| `$v0`    | আউটপুট    | ইন্টিজার | বছরের এক-শতাংশে বয়স   |
| `$t0-9`  | অস্থায়ী | যেকোনো     | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত হয়    |
