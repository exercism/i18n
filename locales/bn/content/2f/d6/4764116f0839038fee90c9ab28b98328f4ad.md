## অপশনাল আর্গুমেন্ট

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

is equivalent to

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

REPL-এ আসা রেসপন্সে আপনি দেখতে পাবেন যে প্রথম ডেফিনিশনটি একবারে দুটি মেথড ডিফাইন করে।
