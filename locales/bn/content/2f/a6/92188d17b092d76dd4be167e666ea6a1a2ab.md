# পরিচিতি

C একটি স্ট্যাটিক্যালি টাইপড ভাষা, যার মানে কম্পাইল-টাইমেই সবকিছুর একটি টাইপ থাকে। একটি ভ্যারিয়েবলের জন্য নাম বেছে নেওয়া এবং তার টাইপ ঠিক করাকে ভ্যারিয়েবল ডিক্লেয়ার করা বলা হয়।

টাইপ স্পষ্টভাবে উল্লেখ করে একটি ভ্যারিয়েবল ডিক্লেয়ার করা হয়।
ভ্যারিয়েবলের নাম শুরু হতে হয় একটি অক্ষর বা একটি আন্ডারস্কোর দিয়ে।
কিছু নাম ব্যবহার করা যায় না, কারণ সেগুলো [কিওয়ার্ডের][reserved-keywords] জন্য বা [অন্য আইডেন্টিফায়ারের][reserved-identifiers] জন্য সংরক্ষিত।

ভ্যারিয়েবলে মান বসানো বা তা হালনাগাদ করা হয় ভ্যারিয়েবল অ্যাসাইনমেন্টের মাধ্যমে।
মান বসানোর মাধ্যমেই ওই ভ্যারিয়েবলটি ডিফাইন হয়।
ভ্যারিয়েবল ডিফাইন করাকে ইনিশিয়ালাইজেশনও বলা হয়।

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

`=` সরল অ্যাসাইনমেন্ট অপারেটর ব্যবহার করে ভ্যারিয়েবলের মান অ্যাসাইন ও হালনাগাদ করা যায়।
একবার ডিফাইন হয়ে গেলে ভ্যারিয়েবলের টাইপ আর কখনোই বদলানো যায় না।

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C একটি ইম্পেরেটিভ প্রসিডিউরাল ভাষা।
সব হিসাব-নিকাশ করা হয় একগুচ্ছ স্টেটমেন্টের মাধ্যমে, যেগুলো একটি বা একাধিক ফাংশনের অংশ।

প্রতিটি ফাংশনে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে।
ফাংশন ডিফাইন করার সময় সব প্যারামিটার এবং রিটার্ন ভ্যালুর টাইপ স্পষ্টভাবে উল্লেখ করতে হয়।
`return` কিওয়ার্ড ব্যবহার করে ফাংশন থেকে মান রিটার্ন করা হয়।
ফাংশনের ডিফল্ট স্টোরেজ ক্লাস এক্সটার্নাল, অর্থাৎ এটি প্রোগ্রামের পুরো জীবনকাল জুড়ে থাকে এবং ফাইলের বাইরে থেকেও দৃশ্যমান হতে পারে।
এটা আটকাতে `static` কিওয়ার্ড যোগ করে ইন্টার্নাল ভিজিবিলিটি নির্দিষ্ট করা যায়।

```c
static int add(int x, int y) {
  return x + y;
}
```

উপরের উদাহরণে `x` ও `y` ভ্যারিয়েবল দুটি কেবল ওই ফাংশনের ভেতরেই ব্যবহার করা যায়, অর্থাৎ এদের ফাংশন স্কোপ আছে।
স্কোপ বলতে বোঝায়, একটি নামের (একটি প্রোগ্রাম এলিমেন্টের) সঙ্গে যুক্ত মান কেবল সেখানেই ব্যবহার করা যায় যে কোড "এলাকার" ভেতরে এটি ডিফাইন করা হয়েছে।
C-তে প্রধান কোড এলাকাগুলো হলো:

- ফাইল
- ফাংশন
- ব্লক (যেমন লুপ বা অন্য কোনো গঠনের ভেতরে)

ফাংশন কল করা হয় ফাংশনের নাম উল্লেখ করে এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```c
int sum = add(1, 2);
```

C দুই ধরনের কমেন্ট সমর্থন করে।
একলাইনের কমেন্টের আগে `//` বসে (C99 থেকে), আর বহুলাইনের কমেন্ট `/*` ও `*/`-এর মাঝে লেখা হয়।
