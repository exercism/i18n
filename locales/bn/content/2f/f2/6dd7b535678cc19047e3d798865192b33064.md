# পরিচিতি

কিওয়ার্ড লিস্ট হলো একটি কী (key)-মান ডেটা স্ট্রাকচার।

```elixir
[month: "April", year: 2018]
```

কিওয়ার্ড লিস্ট হলো `{key, value}` [টাপল][exercism-tuples]-এর লিস্ট, আর এভাবেও লেখা যায়, তবে সংক্ষিপ্ত সিনট্যাক্সটিই বেশি ব্যবহৃত হয়।

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

কিওয়ার্ড লিস্টের কী (key) অবশ্যই [অ্যাটম][exercism-atoms] হতে হবে, তবে মান যেকোনো কিছু হতে পারে। প্রতিটি কী (key) একাধিকবার ব্যবহার করা যায়। কিওয়ার্ড লিস্টের কী (key)-মান জোড়াগুলো একটি নির্দিষ্ট ক্রমে সাজানো থাকে।

আপনি লিস্টের ক্ষেত্রে যেভাবে কাজ করেন, সেই একই পদ্ধতিতে কিওয়ার্ড লিস্ট নিয়েও কাজ করতে পারেন, অথবা `Keyword` মডিউলটি ব্যবহার করতে পারেন।

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
