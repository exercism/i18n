# পরিচিতি

ফান্ডামেন্টালস ধারণাটির কথা মনে করুন: একটি AWK প্রোগ্রাম গঠিত হয় **প্যাটার্ন-অ্যাকশন জোড়া** দিয়ে।

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## "প্যাটার্ন" বলতে আমরা কী বুঝি?

"প্যাটার্ন" হলো যেকোনো AWK এক্সপ্রেশন।
এক্সপ্রেশনের ফলাফলের ট্রুথিনেসই ঠিক করে দেয় অ্যাকশনটি চালানো হবে কি না।

## খালি প্যাটার্ন

প্যাটার্নটি বাদ দেওয়া যায়।
এক্ষেত্রে প্রতিটি রেকর্ডের জন্যই অ্যাকশনটি সম্পাদন করা হয়।

passwd ফাইলের সব ইউজারনেম আমরা প্রিন্ট করতে পারি।

```sh
awk -F: '{print $1}' /etc/passwd
```

## রেগুলার এক্সপ্রেশন

একটি বুলিয়ান ফলাফল পেতে AWK স্ট্রিংগুলোকে রেগুলার এক্সপ্রেশনের সঙ্গে তুলনা করতে পারে।

নির্দিষ্ট কোনো ফিল্ড মেলাতে `~` রেগুলার-এক্সপ্রেশন-মেলানোর অপারেটরটি ব্যবহার করুন।
এই অপারেটরটি বাম দিকের অপারেন্ড হিসেবে একটি স্ট্রিং আর ডান দিকের অপারেন্ড হিসেবে একটি রেগুলার এক্সপ্রেশন নেয়।
একটি রেগুলার এক্সপ্রেশন লিটারেল `/` স্ল্যাশের ভেতরে রাখা হয়।

passwd ফাইলে যেসব ইউজার bash দিয়ে লগ ইন করেন, তাদের খুঁজে বের করতে:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` হলো "রেগুলার এক্সপ্রেশন **মেলে না**" অপারেটর।

বর্তমান রেকর্ডের সঙ্গে একটি রেগুলার এক্সপ্রেশন মেলাতে আপনি `$0 ~ /regex/` লিখতে পারেন।
এটি এতটাই কমন যে এর একটি সংক্ষিপ্ত রূপ আছে: আপনি `$0` আর `~` বাদ দিয়ে শুধু `/regex/` লিখতে পারেন।

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
ওই AWK এক-লাইনের কমান্ডটির সঙ্গে এর সমতুল্য grep কমান্ডটি মিলিয়ে দেখুন

```sh
grep 'regex' data.txt
```

সংক্ষিপ্ততা বিসর্জন না দিয়েই AWK আপনাকে গোটা একটি প্রোগ্রামিং ভাষা দিয়ে দেয়।
~~~~

GNU AWK-এর রেগুলার এক্সপ্রেশনের ধরন নিয়ে আমরা আরও একটি ধারণায় বিস্তারিত জানব।

## এক্সপ্রেশন

AWK এক্সপ্রেশন (পাটিগণিতের, যুক্তির বা অন্য যেকোনো) প্যাটার্ন হিসেবে ব্যবহার করা যায়।

UID 1000 বা তার বেশি এমন সব ইউজার বের করতে:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

মনে করুন, AWK-এর ফলস মান হলো সংখ্যা শূন্য আর খালি স্ট্রিং, আর বাকি সব সংখ্যা বা স্ট্রিং ট্রু।
যে এক্সপ্রেশনের ফল একটি সংখ্যা বা স্ট্রিং, সেটিই প্যাটার্ন হিসেবে ব্যবহার করা যায়।

## ফাংশন

যেকোনো [বিল্ট-ইন][builtins] বা [ইউজার-ডিফাইনড][user-defined] ফাংশনই একটি এক্সপ্রেশনে, আর তাই প্যাটার্নেও ব্যবহার করা যায়।
কয়েকটি উদাহরণ:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## ধ্রুবক প্যাটার্ন

একটি কমন AWK ইডিয়ম হলো:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` হলো একটি ট্রুথি প্যাটার্ন, যার সঙ্গে কোনো অ্যাকশন যুক্ত নেই।
এর অর্থ হলো "বর্তমান রেকর্ডটি প্রিন্ট করা"।
