# নির্দেশনার সম্পূরক

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বর্ণনা                                            |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | ইনপুট     | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং                           |
| `$v0`    | আউটপুট     | বুলিয়ান | ইনপুট স্ট্রিংয়ের বৈধতা (`0` = `false`, `1` = `true`) |
| `$t0-9`  | টেম্পোরারি | যেকোনো     | সাময়িক সংরক্ষণের জন্য ব্যবহৃত হয়                             |
