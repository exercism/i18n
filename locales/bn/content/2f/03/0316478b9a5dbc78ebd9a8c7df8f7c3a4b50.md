# পরিচিতি

- Pony স্ট্যাটিকভাবে টাইপড। এর মানে হলো, আপনার প্রোগ্রামে ডেটার টাইপ আপনাকে *অবশ্যই* আগে থেকেই ডিফাইন করতে হবে। আপনি যদি Pony-কে বলেন যে ভ্যারিয়েবল `x` একটি ইন্টিজার, তাহলে তাতে একটি স্ট্রিং অ্যাসাইন করতে পারবেন না।
- Pony-এর টাইপ সিস্টেমই Pony-এর গ্যারান্টিগুলো সম্ভব করে তোলে।
  - আপনার প্রোগ্রাম কম্পাইল হলে সেটি ক্র্যাশ করবে না।
  - কখনোই কোনো আনহ্যান্ডেলড এক্সেপশন থাকবে না।
  - `null` বলে কোনো কিছুই নেই, তাই আপনার প্রোগ্রাম কখনোই `null` ডিরেফারেন্স করার চেষ্টা করবে না।
  - কখনোই কোনো ডেটা-রেস থাকবে না।
  - কখনোই কোনো ডেডলক থাকবে না।
  - আপনার কোড সবসময় ক্যাপাবিলিটিজ সিকিউর থাকবে (সাপ্লাই-চেইন আক্রমণ থেকে সুরক্ষা।
- Pony আপনাকে টাইপ কাস্ট করার সুযোগ দেয় না। সব টাইপ পরিবর্তনকে এমন একটি ফাংশনের মধ্য দিয়ে হতে হবে যা নতুন টাইপের একটি নতুন ইনস্ট্যান্স তৈরি করে।
- Pony-এর টাইপ সিস্টেম প্রায় সব অন্য ভাষার থেকে আলাদা, তাই আমরা এটি ছোট ছোট টুকরোয় নিয়ে আলোচনা করব।

## প্রিমিটিভ

- প্রিমিটিভ হলো Pony-তে কোড সংগঠনের সবচেয়ে সরল রূপ।
  - এটাকে আপনি একটি কন্টেইনার, বা ফাংশনের জন্য নেমস্পেস হিসেবে ভাবতে পারেন।
  - এতে কোনো ফিল্ড থাকে না (সেটার জন্য আমাদের কাছে ক্লাস আছে)।
  - এটি `primitive` কিওয়ার্ড দিয়ে ডিফাইন করা হয়।

## ফাংশন

- ফাংশন `fun` কিওয়ার্ড দিয়ে ডিফাইন করা হয়।
  - ফাংশনকে অবশ্যই একটি `primitive`-এর ভিতরে থাকতে হবে (বা একটি `class` বা একটি `actor`-এর ভিতরে), কিন্তু সেগুলো পরে আসবে)।
  - ফাংশনে ভিতরে আসা আর্গুমেন্ট থাকতে পারে, একটি রিটার্ন ভ্যালু থাকতে পারে। এগুলো অবশ্যই টাইপযুক্ত হতে হবে।
  - আপনি যদি একটি রিটার্ন টাইপ ডিফাইন করেন, তাহলে আপনার ফাংশনকে *অবশ্যই* ওই টাইপের একটি মান রিটার্ন করতে হবে। Pony-তে Null-এর কোনো ধারণা নেই।

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## কমেন্ট

কমেন্ট দিয়ে নোট, রিমাইন্ডার রাখা যায়, বা শুধু সাময়িকভাবে সোর্স কোড থেকে কোড সরিয়ে রাখা যায়। উপরে যেমন দেখেছেন, এক লাইনের কমেন্টে `//` ব্যবহার করা হয়। একাধিক লাইনের কমেন্টে C-স্টাইলের `/*` ও `*/` ব্যবহার করা হয়।

## ভ্যারিয়েবল

- ভ্যারিয়েবল সবসময় ছোট হাতের অক্ষর দিয়ে শুরু হয়
  - আমরা এগুলো `var` দিয়ে ডিক্লেয়ার করব। (`let` আর `embed` পরে আসবে)।
  - Pony যদি ভ্যারিয়েবলের টাইপ নির্ধারণ করতে পারে, তাহলে সেটি আপনার হয়েই তা করে দেবে।
  - ভ্যারিয়েবলের টাইপ কম্পাইল-টাইমে যাচাই করা হয় এবং কখনোই বদলাতে পারে না।
  - Pony শুরু করার সময় আমরা টাইপ স্পষ্টভাবে লেখার পরামর্শ দিই।

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
