# নির্দেশনার সংযোজন

## বোর্ডের ফরম্যাট

বোর্ডটি একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে রিপ্রেজেন্ট করা হয়, যার প্রতিটি সারির শেষে একটি নিউলাইন ক্যারেক্টার থাকে।

একটি উদাহরণ হলো `"X  \n XO\nOX \n"`

## রেজিস্টার

| Register | Usage        | Type    | Description                                                             |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | input        | address | null-terminated input string                                            |
| `$v0`    | output       | integer | game state (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | temporary    | any     | for temporary storage                                                   |
