# পরিচিতি

[অ্যারে][arrays-concept]-এ অ্যারের ভেতরের বিষয়বস্তু বিশ্লেষণ করার জন্য বিল্ট-ইন মেথড রয়েছে।
এই মেথডগুলোর বেশিরভাগই আর্গুমেন্ট হিসেবে এমন একটি ফাংশন নেয়, যা ট্রু বা ফলস রিটার্ন করে।
এমন ফাংশনকে বলা হয় [`predicate`][predicate_in_programming]।

এই বিল্ট-ইন মেথডগুলো _একটি `for` লুপের বদলে_ বা বিল্ট-ইন `forEach` মেথডের বদলে ব্যবহার করার জন্যই তৈরি:

`for` লুপ ব্যবহার করে বিশ্লেষণের উদাহরণ:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

বিল্ট-ইন মেথড ব্যবহার করে বিশ্লেষণের উদাহরণ:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

অ্যারে বিশ্লেষণ করার জন্য আরও কিছু সহায়ক বিল্ট-ইন মেথড নিচে দেখানো হয়েছে। অ্যারে মেথডের পূর্ণ তালিকার জন্য [MDN][mdn-array-methods] দেখুন।

## `includes`

> includes() মেথডটি নির্ধারণ করে যে অ্যারের এন্ট্রিগুলোর মধ্যে একটি নির্দিষ্ট মান রয়েছে কি না, এবং উপযুক্ত অনুযায়ী ট্রু বা ফলস রিটার্ন করে। [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> every() মেথডটি পরীক্ষা করে যে অ্যারের সব এলিমেন্ট কি প্রদত্ত ফাংশন দ্বারা বাস্তবায়িত টেস্টে উত্তীর্ণ হয়। এটি একটি বুলিয়ান মান রিটার্ন করে। [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> some() মেথডটি পরীক্ষা করে যে অ্যারের অন্তত একটি এলিমেন্ট কি প্রদত্ত ফাংশন দ্বারা বাস্তবায়িত টেস্টে উত্তীর্ণ হয়। [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> find() মেথডটি প্রদত্ত অ্যারেতে প্রথম যে এলিমেন্টটি প্রদত্ত টেস্টিং ফাংশনের শর্ত পূরণ করে, তার মান রিটার্ন করে। কোনো মান যদি টেস্টিং ফাংশনের শর্ত পূরণ না করে, তাহলে undefined রিটার্ন করা হয়। [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> findIndex() মেথডটি অ্যারেতে প্রথম যে এলিমেন্টটি প্রদত্ত টেস্টিং ফাংশনের শর্ত পূরণ করে, তার ইনডেক্স রিটার্ন করে। অন্যথায়, এটি -1 রিটার্ন করে, যা বোঝায় কোনো এলিমেন্টই টেস্টে উত্তীর্ণ হয়নি। [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
