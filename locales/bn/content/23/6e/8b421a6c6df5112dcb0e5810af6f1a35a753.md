# পরিচিতি

[`Rational numbers`][rational] হলো এমন ভগ্নাংশ, যার লব একটি ইন্টিজার আর হরও একটি ইন্টিজার।

উদাহরণস্বরূপ, আনুমানিক `Float64` মান `0.6666...`-এর বদলে আমরা `2//3`-কে একটি নির্ভুল ভগ্নাংশ হিসেবে সংরক্ষণ করতে পারি।

এর সুবিধা হলো, ([integer overflow][integer-overflow]-এর চরম পরিস্থিতি ছাড়া) একটি র‍্যাশনাল সংখ্যা নির্ভুল থাকে, ফলে ফ্লোটিং-পয়েন্ট সংখ্যায় প্রায়ই অনিবার্য হয়ে ওঠা রাউন্ডিং এরর এড়ানো যায়।

Julia-র [ম্যানুয়াল পেজে][julia-rational] আরও কিছু বিস্তারিত আছে।

র‍্যাশনাল সংখ্যা বেশ সরল একটি সংখ্যাসূচক টাইপ, আর আপনি যেমনটা আশা করবেন ঠিক তেমনভাবেই কাজ করার লক্ষ্য রাখে। যেহেতু শুরুর দিকের সংস্করণ থেকেই এরা Julia-র একটি স্ট্যান্ডার্ড টাইপ, তাই বেশিরভাগ ফাংশন ইন্টিজার ও ফ্লোটের মতোই এদের ইনপুট হিসেবে গ্রহণ করে।

## র‍্যাশনাল সংখ্যা তৈরি করা

তৈরি করা ঠিক ততটাই সহজ: দুইটি ইন্টিজারের মাঝে `//` ব্যবহার করুন।

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

কমন গুণনীয়কগুলো স্বয়ংক্রিয়ভাবে বাদ পড়ে, আর ভগ্নাংশটি চলে যায় তার ["লঘিষ্ঠ আকারে"][lowest-terms]: যে ক্ষুদ্রতম ইন্টিজারগুলো ভগ্নাংশটিকে নির্ভুলভাবে প্রকাশ করে এবং যাদের হর অ-ঋণাত্মক।

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

অসীম ফলাফল গ্রহণযোগ্য, তবে [`NaN`][NaN] নয়।

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## র‍্যাশনাল সংখ্যা দিয়ে পাটিগণিত

সাধারণ [`arithmetic operators`][operators] `+ - * / ^ %` র‍্যাশনালের সাথে কাজ করে, অন্য সংখ্যাসূচক টাইপের সাথে যেমন হয় প্রায় তেমনভাবেই।

এক্সপ্রেশনে ইন্টিজার আর অন্য `Rational`-ও থাকতে পারে, তখন ফলাফলও আসে একটি `Rational` হিসেবে। এক্সপ্রেশনে একটি `float` থাকলে আউটপুট আসে `float` হিসেবে, আর তার ফলে নির্ভুলতা (হয়তো) কমে যেতে পারে।

`float` দরকার হলে শুধু `float()` ফাংশন দিয়ে র‍্যাশনালটিকে রূপান্তর করে নিন। দীর্ঘ কোনো হিসাবের পুরোটা জুড়ে নির্ভুলতা ধরে রাখতে র‍্যাশনাল সংখ্যা ব্যবহার করা, আর একেবারে শেষে সেটিকে ফ্লোটে রূপান্তর করা বেশ স্বাভাবিক ব্যাপার।

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

র‍্যাশনালের সাথে [জটিল সংখ্যা][complex]-ও মেলানো যায়। জটিল সংখ্যা নিয়ে আলোচনা আছে [আলাদা একটি কনসেপ্টে][complex-concept]।

## অন্যান্য অপারেশন

Julia-তে র‍্যাশনাল সংখ্যা আসলে কেবলই সংখ্যা। কম্পাইলার সাধারণত প্রয়োজন অনুযায়ী টাইপ রূপান্তর করে নেয়।

তবে মনে রাখবেন, সসীম দশমিক প্রকাশ রয়েছে এমন ভগ্নাংশের ক্ষেত্রে তুলনা কাজ করে:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

কিন্তু অন্য ক্ষেত্রে তুলনা করার আগে `Rational`-কে `Float`-এ রূপান্তর করা উচিত:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

গাণিতিক ফাংশন র‍্যাশনালকে ইনপুট হিসেবে নেয়, তবে ফলাফল দিতে পারে ফ্লোটিং-পয়েন্ট মান হিসেবে:

```julia-repl
julia> sqrt(9//16)
0.75
```
