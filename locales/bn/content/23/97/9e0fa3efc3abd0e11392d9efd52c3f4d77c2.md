# নির্দেশাবলি

নবীন জাদুকর হিসেবে Elyse-কে তার ডেক নানা ভাবে বিশ্লেষণ করতে হয়। সহজ রাখতে তিনি শুধু ১ থেকে ১০ মানের কার্ড ব্যবহার করেন।

## 1. ডেকে নির্দিষ্ট ধরনের কতটি কার্ড আছে তা নির্ণয় করুন

Elyse জানতে চান তার ডেকে একটি নির্দিষ্ট ধরনের কতটি কার্ড আছে।

এমন একটি ফাংশন `cardTypeCheck` লিখুন যা দুটি প্যারামিটার নেয়: কার্ডের একটি অ্যারে (Elyse-এর ডেক) এবং যে ধরনের কার্ড গুনতে হবে সেটি।

<!--prettier-ignore -->
~~~exercism/note
ফাংশনটি `forEach` ব্যবহার করবে এবং নির্দিষ্ট ধরনের কতটি কার্ড ডেকে আছে সেই সংখ্যা রিটার্ন করবে।
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. কতটি জোড় বা বিজোড় কার্ড আছে তা নির্ণয় করুন

আরেকটি ট্রিকের জন্য Elyse জানতে চান তার ডেকে কতটি জোড় বা বিজোড় কার্ড আছে।

এমন একটি ফাংশন `determineOddEvenCards` তৈরি করুন যা দুটি প্যারামিটার নেয়: কার্ডের একটি অ্যারে (Elyse-এর ডেক) এবং একটি বুলিয়ান (ট্রু মানে 'জোড়', আর ফলস মানে 'বিজোড়')।

এই ফাংশনটি একটি সংখ্যা রিটার্ন করবে: ডেকে কতটি জোড় বা বিজোড় কার্ড আছে সেই সংখ্যা (দ্বিতীয় আর্গুমেন্টের মানের উপর নির্ভর করে)।

<!--prettier-ignore -->
~~~exercism/note
অনুশীলনের জন্য এবার ফাংশনের বাস্তবায়নে একটি `for...of` লুপ ব্যবহার করুন।
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
