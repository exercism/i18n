# ডেটাবেস পেমেন্ট অডিট

## সমস্যার বিবৃতি

আরও প্রক্রিয়াকরণের জন্য ABC Corp-এর সব ডেটা SQL ডেটাবেস থেকে একটি [Ballerina টেবিলে](https://ballerina.io/learn/by-example/table-syntax/) লোড করতে হবে। এরপর লোড করা Ballerina টেবিলে কোয়েরি চালিয়ে এমন কর্মচারীদের নাম বের করতে হবে, যাদের পেমেন্ট এন্ট্রি নির্দিষ্ট একটি পরিমাণের (যেমন 3000.00) চেয়ে বড়।

**ধাপ ১:**

নিচের কলামগুলো দিয়ে একটি Ballerina টেবিল তৈরি করুন।

`payment_id` - ইন্টিজার

`amount` - দশমিক সংখ্যা

`employee_name` - স্ট্রিং

**ধাপ ২:**

H2 ডেটাবেসে থাকা সংশ্লিষ্ট সম্পূর্ণ ডেটা সেট লোড করে উপরের Ballerina টেবিলটি পূরণ করুন। টেবিলের প্রাইমারি কী হিসেবে `payment_id` ব্যবহার করুন।

**ধাপ ৩**

Ballerina কোয়েরি এক্সপ্রেশন দিয়ে Ballerina টেবিলে কোয়েরি চালিয়ে এমন কর্মচারীদের নাম খুঁজে বের করুন, যাদের পেমেন্ট এন্ট্রি প্রদত্ত পরিমাণের চেয়ে বড়। ফলাফলটি কর্মচারীর নামের ঊর্ধ্বক্রমে সাজান। রিটার্ন করার আগে ফলাফল থেকে ডুপ্লিকেট নামের এন্ট্রিগুলো সরিয়ে দিন।

> দ্রষ্টব্য : সমাধানটি তৈরি করতে Ballerina টেবিল ব্যবহার করা বাধ্যতামূলক।

## ডেটাবেসের বিবরণ

এই সমস্যার জন্য দেওয়া H2 ডেটাবেসটি ব্যবহার করুন।

> নমুনা ডেটাবেস ফাইলটি হলো `gofigure.mv.db`, আর ডেটাবেসের নাম `gofigure`। এটি `db` ফোল্ডারের ভেতরে দেওয়া আছে।

নিচের টেবিলগুলো নমুনা H2 ডেটাবেসে কিছু নমুনা ডেটাসহ আগেই আছে। কলামের নাম ও ডেটা টাইপ নিচে দেওয়া হলো।

**টেবিলের নাম** : `Employee`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `employee_id`     | ইন্টিজার, অটো-ইনক্রিমেন্টেড প্রাইমারি কী       |
| `name`            | স্ট্রিং        |
| `city`            | স্ট্রিং        |
| `department`      | স্ট্রিং        |
| `age`             | ইন্টিজার        |

**টেবিলের নাম**: `Payment`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `payment_id`      | ইন্টিজার, অটো-ইনক্রিমেন্টেড প্রাইমারি কী       |
| `date`            | তারিখ        |
| `amount`          | দশমিক সংখ্যা        |
| `employee_id`     | ইন্টিজার        |
| `reason`          | স্ট্রিং        |

* ডেটাবেস ফাইলটি `gofigure.mv.db`। JDBC URL হিসেবে `jdbc:h2:file:/path/to/db/file` ব্যবহার করুন
* ব্যবহারকারীর নাম: `root`
* পাসওয়ার্ড: `root`

## সীমাবদ্ধতা

* কোয়েরিগুলো এবং Ballerina নমুনাটি যাচাই করতে `db` ফোল্ডারে দেওয়া H2 ডেটাবেস ফাইলটি ব্যবহার করুন
* আপনার Ballerina.toml-এ H2 ডেটাবেস ড্রাইভারকে প্ল্যাটফর্ম ডিপেন্ডেন্সি হিসেবে যোগ করতে maven dependency params পদ্ধতিটি ব্যবহার করুন

## ইঙ্গিত

* ডেটাবেস নিয়ে কাজ করতে [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) মডিউলটি ব্যবহার করুন
* JDBC ড্রাইভারকে ডিপেন্ডেন্সি হিসেবে যোগ করার ধাপগুলো জানতে [পূর্বশর্ত](https://lib.ballerina.io/ballerinax/java.jdbc/latest) অংশটি দেখুন
* DB থেকে ডেটা কোয়েরি করতে [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) রিমোট মেথডটি ব্যবহার করুন
* [সাধারণ কোয়েরি](https://ballerina.io/learn/by-example/mysql-query-operation) উদাহরণটি দেখুন
* [টেবিল সিনট্যাক্স](https://ballerina.io/learn/by-example/table) উদাহরণটি দেখুন
* Ballerina টেবিল থেকে প্রয়োজনীয় ডেটা খুঁজে বের করতে [টেবিলে কোয়েরি করা](https://ballerina.io/learn/by-example/querying-tables) দেখুন
