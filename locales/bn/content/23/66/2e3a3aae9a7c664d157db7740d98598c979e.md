# টেস্ট

## কমান্ড লাইন

কমান্ড লাইন থেকে টেস্ট চালানোর জন্য নিচের কমান্ডটি ব্যবহার করা যায়:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>`-এর জায়গায় আপনি যে অনুশীলনীটি ইমপ্লিমেন্ট করছেন তার নামটি বসান।

## ইন্টার‍্যাক্টিভ

Prolog ইন্টার‍্যাক্টিভভাবে চালাতে হলে প্রথমে রান করুন:

```bash
swipl
```

Prolog কনসোল চালু হওয়ার পর, আপনার ইমপ্লিমেন্টেশন লোড করুন এবং এই কমান্ডগুলো দিয়ে টেস্ট চালান:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>`-এর জায়গায় আপনি যে অনুশীলনীটি ইমপ্লিমেন্ট করছেন তার নামটি বসান।

### পরিবর্তন রিলোড করা

উপরের ফাইলগুলো লোড হয়ে গেলে, আপনি যে পরিবর্তনগুলো করেছেন সেগুলো এর মাধ্যমে প্রয়োগ করতে পারেন:

```
?- make.
```

## স্কিপ করা টেস্ট

আপনি যখন প্রথম কোনো অনুশীলনী শুরু করেন, তখন শুধু প্রথম টেস্টটি চলবে। `test` গোলে `condition(pending)` যোগ করে বাকিগুলো স্কিপ করা হয়েছে। প্রথম টেস্টটি পাস হয়ে গেলে, `condition(pending)`-এর `pending` কে `true` করে পরের টেস্টটি আন-স্কিপ করুন। সবগুলো টেস্ট চালু হয়ে পাস না হওয়া পর্যন্ত প্রতিটি টেস্টের জন্য এটা করতে থাকুন।

### কমান্ড লাইন

কমান্ডের শেষে `-- --all` আর্গুমেন্টটি যোগ করলে পেন্ডিং টেস্টগুলোও রান করা যায়:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
