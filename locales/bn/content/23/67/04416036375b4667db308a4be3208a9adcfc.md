# ভূমিকা

## বুলিয়ান

Gleam ট্রু ও ফলস মান প্রকাশ করতে `Bool` টাইপ ব্যবহার করে। মান মাত্র দুটি: `True` এবং `False`। এই মানগুলো একটি ভ্যারিয়েবলে বাইন্ড করা যায়:

```gleam
let true_variable = True
let false_variable = False
```

`&&`, `||` এবং `!` অপারেটর দিয়ে বুলিয়ান মান নিয়ে কাজ করা যায়:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&` ও `||` অপারেটর শর্ট-সার্কিট ইভ্যালুয়েশন ব্যবহার করে, অর্থাৎ অপারেটরের ডান দিকের এক্সপ্রেশনটি কেবল প্রয়োজন হলেই মূল্যায়ন করা হয়।

প্রতিটি অপারেটরের প্রিসিডেন্স আলাদা, যেখানে `!` কে `&&` ও `||` অপারেটরের আগে মূল্যায়ন করা হয়। দ্বিতীয় বন্ধনী দিয়ে এক্সপ্রেশনের একটি অংশকে বাকি অংশের আগে মূল্যায়ন করা যায়:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
