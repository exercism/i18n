# পরিচিতি

[টাপল][tuples] একাধিক মানকে একটি যৌগিক মানে একত্র করে।
অ্যারের বিপরীতে, একটি টাপলের মানগুলোকে একই টাইপের হতে হয় না, আর একবার তৈরি হয়ে গেলে টাপলের আকার নির্দিষ্ট হয়ে যায়।

কমা দিয়ে আলাদা করা কয়েকটি মান বন্ধনীর ভেতরে রেখে একটি টাপল তৈরি করুন:

```swift
let order = ("biscuits", 2.99, 3)
```

চাইলে টাইপ অ্যানোটেশনও স্পষ্টভাবে লিখে দিতে পারেন:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

নামহীন টাপল থেকে আলাদা আলাদা এলিমেন্ট বের করতে শূন্য থেকে শুরু হওয়া ইনডেক্স সিনট্যাক্স (`.0`, `.1` ইত্যাদি) ব্যবহার করুন:

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## নামযুক্ত টাপল

টাপল ডিফাইন করার সময় এর আলাদা আলাদা এলিমেন্টের নাম দিতে পারেন:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

এলিমেন্টের নাম দিলে কোড পড়তে সহজ হয়, আর লেবেল দিয়ে ডট নোটেশন ব্যবহার করে এলিমেন্টগুলোতে অ্যাক্সেস করতে পারেন:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

টাইপ অ্যানোটেশনে এলিমেন্টের নামও দিতে পারেন:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## টাপল পরিবর্তন করা

টাপলকে যদি ভ্যারিয়েবল (`var`) হিসেবে ডিক্লেয়ার করা হয়, তাহলে এর এলিমেন্টগুলো আপডেট করতে পারেন:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## একাধিক মান রিটার্ন করা

Swift ফাংশন একবারে কেবল একটি মান রিটার্ন করতে পারে, কিন্তু একটি টাপল রিটার্ন করলে আপনি একাধিক মান একসাথে প্যাক করে একটি ফাংশন থেকে [একাধিক মান রিটার্ন][multiple-return-values] করতে পারেন:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## টাপল ডিকম্পোজিশন

আপনি একটি টাপলের মানগুলোকে আলাদা কনস্ট্যান্ট বা ভ্যারিয়েবলে ভেঙে (আনপ্যাক করে) নিতে পারেন:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

টাপল ডিকম্পোজিশন সরাসরি `for-in` লুপেও কাজ করে:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
