# ভূমিকা

ইনহেরিটেন্স হলো OOP (অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং)-এর একটি মূল ধারণা।
এটি একটি IS-A সম্পর্ক নির্দেশ করে।
প্রোগ্রামিংয়ে এর অর্থ ঠিক সেটাই, যা ইংরেজিতে বোঝায়: প্যারেন্টের কাছ থেকে বৈশিষ্ট্য উত্তরাধিকার করা (প্রোগ্রামিংয়ে বৈশিষ্ট্য সাধারণত ফাংশন আর ভ্যারিয়েবল হয়ে থাকে)।

নিচে দেখানো একটি ক্লাস `Animal` ধরা যাক,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` একটি প্যারেন্ট ক্লাস, কারণ এই ক্লাসের বৈশিষ্ট্যগুলো সাধারণভাবে সব প্রাণীর কাছে এক্সটেন্ড করা যায়।

`Lion` নামের একটি প্রাণী ধরা যাক, যার একটি ক্লাস নিচের মতো,

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` অ্যানোটেশনটি দিয়ে বোঝানো হয় যে একটি সাবক্লাসের একটি মেথড তার সুপারক্লাসের একটি মেথডকে ওভাররাইড করছে।
এটি একান্ত জরুরি নয়, তবে ব্যবহার করা ভালো অভ্যাস।
~~~~

এখন আমরা যখনই করি,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

লক্ষ্য করুন: `Animal` ক্লাসটি `Lion` দিয়ে ইনিশিয়ালাইজ করা হচ্ছে।
আউটপুট হবে এরকম

```java
Lion here!!
```

OOP অনুযায়ী ইনহেরিটেন্সের অনেক ধরন আছে, কিন্তু Java এর মধ্যে মাত্র কয়েকটি সাপোর্ট করে (মাল্টি-লেভেল ও হায়ারার্কিকাল)।
এ সম্পর্কে আরও জানতে, [এটি][java-inheritance] পড়ুন।
