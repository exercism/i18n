# লিস্ট সম্পর্কে

**লিস্ট** হলো জাভার ক্রমসজ্জিত সিকোয়েন্স কালেকশন।
অ্যারের বিপরীতে, একটি [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) যেকোনো সংখ্যক আইটেম ধারণ করার জন্য আকারে বাড়তে পারে।
একটি স্ট্যান্ডার্ড ইমপ্লিমেন্টেশন হলো `ArrayList`, যার ভিত্তি একটি রি-সাইজেবল অ্যারে।
আরেকটি স্ট্যান্ডার্ড ইমপ্লিমেন্টেশন হলো `LinkedList` ক্লাস, যার ভিত্তি একটি ডাবলি-লিংকড লিস্ট।

`List` খালি থাকতে পারে, আবার যেকোনো সংখ্যক আইটেম ধারণ করতে পারে (ডুপ্লিকেটসহ)।
`List` হলো একটি **জেনেরিক ইন্টারফেস**, যা কোন ধরনের অবজেক্ট ধারণ করতে পারবে তা নির্দেশ করার জন্য টাইপ করা হয়।
যেমন:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`-এ এলিমেন্ট যোগ করা, সরিয়ে ফেলা, সংগ্রহ করা এবং কোনো এলিমেন্ট উপস্থিত আছে কিনা তা যাচাই করার জন্য নানা রকম সহায়ক মেথড রয়েছে:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

[`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) ক্লাসেও `List`-এর মতো কালেকশন নিয়ে কাজ করার জন্য কিছু সহায়ক ইউটিলিটি রয়েছে:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
