# ভূমিকা

## ডিফল্ট প্যারামিটার মান

ফাংশনের যেকোনো প্যারামিটারের জন্য [ডিফল্ট প্যারামিটার মান][default-parameter-values] দেওয়া যায়, প্যারামিটার লিস্টে প্যারামিটারের টাইপ অ্যানোটেশনের পরে সেই প্যারামিটারে একটি মান অ্যাসাইন করে। কোনো ডিফল্ট প্যারামিটার মান নির্দিষ্ট করা থাকলে, ফাংশনটি কল করার সময় কলকারী সেই প্যারামিটারটি বাদ দিতে পারেন, আর বদলে ডিফল্ট মানটি ব্যবহৃত হয়।

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## ভ্যারিয়াডিক প্যারামিটার

Swift-এ [_ভ্যারিয়াডিক প্যারামিটার_][variadic-parameters] একটি ফাংশনের একটিমাত্র প্যারামিটারে একই টাইপের শূন্য বা তার বেশি মান পাঠানোর সুযোগ দেয়। এটি বোঝানো হয় প্যারামিটারের টাইপ অ্যানোটেশনের শেষে `...` যোগ করে।

এই মানগুলো স্বয়ংক্রিয়ভাবে একটি অ্যারেতে একত্রিত করা হয়, যার এলিমেন্টগুলোর টাইপ ভ্যারিয়াডিক প্যারামিটারের টাইপের সমান।

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

মনে রাখবেন, ভ্যারিয়াডিক প্যারামিটার ব্যবহার করার সময় Swift-এর একটি সীমাবদ্ধতা আছে।
ডেফিনিশনে যদি ভ্যারিয়াডিক প্যারামিটারের পরে আরও প্যারামিটার থাকে, তাহলে ভ্যারিয়াডিক প্যারামিটারের পরের প্রথম প্যারামিটারটির একটি আর্গুমেন্ট লেবেল থাকা _বাধ্যতামূলক_।

## ইন-আউট প্যারামিটার

একটি ফাংশনের বডির ভেতরে প্যারামিটারগুলোকে ভ্যারিয়েবল নয়, কনস্ট্যান্ট হিসেবে ধরা হয়; কোনো প্যারামিটারের মান পরিবর্তন করার চেষ্টা করলে একটি কম্পাইল-টাইম এরর হয়।
কোনো ফাংশন যদি প্যারামিটারের মান পরিবর্তন করতে চায়, তাহলে এই পরিবর্তনযোগ্যতা স্পষ্ট করতে তাকে একটি [_ইন-আউট প্যারামিটার_][in-out-parameters] ব্যবহার করতে হবে।

ইন-আউট প্যারামিটার ব্যবহার করতে হলে একজন প্রোগ্রামারকে তিনটি বিষয়ে নিশ্চিত হতে হয়:

1. ফাংশন ডেফিনিশনে প্যারামিটারের টাইপ অ্যানোটেশনে `:` ও টাইপ নামের মাঝখানে `inout` কিওয়ার্ডটি লিখে ইন-আউট প্যারামিটারগুলো স্পষ্টভাবে চিহ্নিত করতে হবে।
2. ইন-আউট প্যারামিটারে যে মানটি পাঠানো হয়, তা কনস্ট্যান্ট নয়, ভ্যারিয়েবল হিসেবে ডিক্লেয়ার করা থাকতে হবে। একইভাবে এটি একটি লিটারালও হতে পারে না।
3. ফাংশনে কল করার সময় ভ্যারিয়েবলের নামের আগে একটি `&` থাকতে হবে, যা এটিকে পরিবর্তনযোগ্য হিসেবে স্পষ্টভাবে চিহ্নিত করে।

এভাবে করলে ফাংশনটি ইন-আউট প্যারামিটারের একটি অভ্যন্তরীণ কপি তৈরি করে, ফাংশনের বডিতে নির্দেশ অনুযায়ী তা পরিবর্তন করে, আর ফাংশনটি রিটার্ন করার সময় পরিবর্তিত মানটি ফেরত সেই ভ্যারিয়েবলে কপি করে দেয় যেটি পাঠানো হয়েছিল।

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
ইন-আউট প্যারামিটার নিয়ে আরও কয়েকটি অতিরিক্ত নিয়ম সম্পর্কে সচেতন থাকা ভালো।

1  ইন-আউট প্যারামিটার আছে এমন একটি ফাংশনের ভেতরে, ইন-আউট প্যারামিটার হিসেবে যে ভ্যারিয়েবলটি পাঠানো হয়েছিল, সেটি রেফারেন্স করার অনুমতি নেই।
2. একই ফাংশনে একই ভ্যারিয়েবলকে একাধিক ইন-আউট প্যারামিটার হিসেবে পাঠানো যায় না।
   উদাহরণস্বরূপ, `inoutFunc(&mutVar, &mutVar)` একটি কম্পাইলার এরর তৈরি করে।
~~~~

## নেস্টেড ফাংশন

Swift-এ আপনি [অন্য ফাংশনের ভেতরে ফাংশন][nested-functions] ডিফাইন করতে পারেন।
এগুলোকে **নেস্টেড ফাংশন** বলা হয়।

নেস্টেড ফাংশন সাধারণত প্রাইভেট হেল্পার হিসেবে ব্যবহৃত হয়, যারা বাইরের স্কোপ অগোছালো না করে যে ফাংশনের ভেতরে তারা থাকে তার জন্য নির্দিষ্ট কিছু কাজ সম্পন্ন করে:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

নেস্টেড ফাংশন সাধারণ ফাংশনের মতোই আচরণ করে, তবে তাদের দৃশ্যমানতা কেবল যে ফাংশনের ভেতরে তারা থাকে তার বডির মধ্যে সীমাবদ্ধ।
