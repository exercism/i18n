# পরিচিতি

`jq` হলো JSON ডেটা পার্স ও রূপান্তর করার একটি টুল।
`jq` হলো JSON ডেটার জন্য `sed`-এর মতো। `sed`, `awk`, `grep` আর তাদের সঙ্গীরা যেভাবে সহজে টেক্সট নিয়ে খেলতে দেয়, ঠিক সেভাবেই আপনি এটি দিয়ে স্ট্রাকচার্ড ডেটা স্লাইস, ফিল্টার, ম্যাপ আর রূপান্তর করতে পারেন।

`jq` একটি ডাইনামিক্যালি টাইপড ফাংশনাল প্রোগ্রামিং ভাষা।
এখানে সব মানই অপরিবর্তনীয়।

`jq` প্রোগ্রাম গঠিত হয় “ফিল্টার”-এর পাইপলাইন দিয়ে: প্রতিটি ফিল্টার ইনপুট হিসেবে একটি করে আইটেম নেয়, তার উপর কাজ করে, আর শূন্য বা তার বেশি রূপান্তরিত এলিমেন্ট আউটপুট দেয়।
একটি “ফিল্টার”-কে “এক্সপ্রেশন”ও বলা হয়।

`|` অপারেটর ব্যবহার করে একটি এক্সপ্রেশনের আউটপুট অন্য এক্সপ্রেশনে পাঠানো যায়।
`expressionA | expressionB` কোনো ইনপুটে `expressionA` প্রয়োগ করে, তারপর `expressionA` যতগুলো আউটপুট দেয়, তার প্রতিটির জন্য `expressionB` বারবার চলে।

একটি এক্সপ্রেশনের ইনপুটকে স্পষ্টভাবে `.` দিয়ে বোঝানো যায়।
যে এক্সপ্রেশন তার ইনপুটের সাথে `1` যোগ করে, সেটি লেখা হয় এভাবে: `. + 1` (বা `1 + .`)।

## `jq` (প্রোগ্রাম) বনাম `jq` (ভাষা)

`jq` এমন একটি প্রোগ্রাম, যা আপনি নানা ধরনের অপারেটিং সিস্টেমে প্যাকেজ হিসেবে ইনস্টল করতে পারেন, অথবা সোর্স থেকে বিল্ড করতে পারেন (এটি C ভাষায় লেখা)।
এতে বেশ কিছু কাজের [কমান্ড-লাইন অপশন][cli-options] আছে, আর এটি বেশ দ্রুত।

`jq` প্রোগ্রামটি ইনপুট ডেটার উপর ইচ্ছেমতো জটিল ম্যানিপুলেশন করার সুবিধার্থে একটি _ভাষাও_ ইমপ্লিমেন্ট করে।

এই Exercism ট্র্যাকটি এই ভাষার উপরেই জোর দেবে।
টেস্টগুলোতে আপনি `jq` প্রোগ্রামের ব্যবহার দেখতে পাবেন।

## সংস্করণ

এই Exercism ট্র্যাকটি `jq`-এর মূল ইমপ্লিমেন্টেশন নিয়ে আলোচনা করবে, যার নিজস্ব ঠিকানা [https://jqlang.org/][jq]।
অন্য ইমপ্লিমেন্টেশন, যেমন [`gojq`][gojq], এখানে বর্ণিত সিনট্যাক্স থেকে ভিন্ন সিনট্যাক্স ব্যবহার করতে পারে।

## JSON

[json.org][json] থেকে:

> JSON (JavaScript Object Notation) একটি হালকা ডেটা-বিনিময় ফরম্যাট।
> মানুষের পক্ষে এটি পড়া ও লেখা সহজ।
> মেশিনের পক্ষে এটি পার্স করা ও জেনারেট করা সহজ।
> এটি JavaScript Programming Language Standard ECMA-262 3rd Edition - December 1999-এর একটি সাবসেটের উপর ভিত্তি করে তৈরি।
> JSON একটি টেক্সট ফরম্যাট, যা সম্পূর্ণ ভাষা-নিরপেক্ষ, কিন্তু C পরিবারের ভাষার প্রোগ্রামারদের কাছে পরিচিত রীতিনীতি ব্যবহার করে; এর মধ্যে আছে C, C++, C#, Java, JavaScript, Perl, Python আরও অনেক ভাষা।
> এই বৈশিষ্ট্যগুলোর কারণেই JSON একটি আদর্শ ডেটা-বিনিময় ভাষা।

এই ট্র্যাকটি JSON নিয়ে নয়, `jq` নিয়ে।
আমরা ধরে নিচ্ছি আপনি [JSON সিনট্যাক্স ও ডেটা টাইপ][wiki-json] সম্পর্কে আগে থেকেই জানেন।
