# সম্পর্কে

একটি [C# `Attribute`][attribute-concept] হলো একটি ক্লাস, একটি মেথড, একটি এনাম, একটি ফিল্ড, একটি প্রপার্টি বা [সমর্থিত অন্যান্য][attribute-targets] ডিক্লারেশনের সাথে মেটাডেটা যুক্ত করতে সেটিকে ডেকোরেট করার একটি উপায়।

ডিক্লারেশনের আগে বন্ধনী `[]`-এর মধ্যে অ্যাট্রিবিউট যোগ করে আপনি একটি ডিক্লারেশনে [একটি অ্যাট্রিবিউট][attribute] প্রয়োগ করতে পারেন। নিচের উদাহরণে একটি `ClassAttribute` এবং একটি `FieldAttribute`, দুটোই ব্যবহার করা হয়েছে:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

ডিক্লারেটিভ মেটাডেটা কেবল কোডের সাথে অতিরিক্ত সুগঠিত তথ্য যুক্ত করে, কোডের আচরণ বদলায় না। তবে কোডের অন্য অংশ এই মেটাডেটা ব্যবহার করে তার টার্গেটের আচরণ বদলায়, অথবা তার কিছু কার্যকারিতা যোগ, পরিবর্তন, অপসারণ বা সীমিত করে।

এমন অনেক পূর্বনির্ধারিত অ্যাট্রিবিউট রয়েছে, যেমন: `Flags`, `Obsolete`, `Conditional`. লক্ষ্য করুন, [`Flags` অ্যাট্রিবিউট][flags-attribute]-এর পুরো নাম `FlagsAttribute`, কিন্তু অ্যাট্রিবিউট হিসেবে ব্যবহার করার সময় "Attribute" প্রত্যয়টি বাদ দেওয়া যায়।

নিচের চারটি পূর্বনির্ধারিত অ্যাট্রিবিউট নিয়মিত ব্যবহার করা হয়:

- `[Flags]`: System নেমস্পেসে পূর্বনির্ধারিত। বোঝায় যে এনামটি বিটওয়াইজ অপারেশন এবং `Enum.HasFlag()` মেথড, দুটোই সমর্থন করে; এছাড়া `ToString` সব ফ্ল্যাগ দেখাবে: [উদাহরণ দেখুন][flags-example]।
- `[Obsolete]`: System নেমস্পেসে পূর্বনির্ধারিত। কোডটি কেন অপ্রচলিত, তা জানানোর একটি বার্তা যোগ করার সুযোগ দেয়; কম্পাইলার ওয়ার্নিং বা এরর দেখাতে এটি ব্যবহার করা যায়।
- `[Conditional]`: System.Diagnostics নেমস্পেসে পূর্বনির্ধারিত। ডিবাগিং (ডায়াগনস্টিকস) উদ্দেশ্যে কম্পাইল টাইমে কিছু মেথড কল সরিয়ে ফেলার সুযোগ দেয়।
- `[CallerMemberName]`: System.Runtime.CompilerServices নেমস্পেসে পূর্বনির্ধারিত। একটি মেথডকে তার কলার সম্পর্কে তথ্য পাওয়ার সুযোগ দেয়।
