# টেস্ট

প্রতিটি অনুশীলনীর জন্য একবার সেটআপ করতে হয়, যা কয়েক মিনিট সময় নিতে পারে:

```
npm install
```

দুটি শেল খুলুন, আর প্রথমটিতে বিল্ড প্রসেস শুরু করুন।

```
npm start
```

দ্বিতীয়টিতে টেস্টগুলো চালানো শুরু করুন।

```
npm test
```

আপনি যখন কোড এডিট করবেন, দুটি প্রসেসই ক্রমাগত রিবিল্ড করবে আর টেস্টগুলো আবার চালাবে।
