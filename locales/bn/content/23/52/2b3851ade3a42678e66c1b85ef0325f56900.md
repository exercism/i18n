# রিডঅনলি ক্লাস ও প্রপার্টি

রিডঅনলি ক্লাস ও প্রপার্টি ক্লাসকে সহজে অ্যাক্সেসের জন্য public প্রপার্টি নির্দিষ্ট করার সুযোগ দেয়, কিন্তু সেগুলো পরিবর্তন করতে দেয় না।
কোনো প্রপার্টিকে রিডঅনলি হিসেবে ডিক্লেয়ার করতে হলে টাইপ স্পেসিফিকেশনের আগে `readonly` যোগ করতে হবে।
প্রপার্টিটিতে কেবল একবারই মান অ্যাসাইন করা যায়, কিন্তু মানটি আবার অ্যাসাইন করা বা পরিবর্তন করার যেকোনো চেষ্টার ফলে একটি এরর হবে।

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

রিডঅনলি ক্লাস এই আচরণের ওপরই তৈরি: ক্লাসটিকে `readonly` হিসেবে ডিক্লেয়ার করলে প্রতিটি প্রপার্টিতেই রিডঅনলি ডিক্লারেশন প্রযোজ্য হয়।
এছাড়াও এটি ডাইনামিক প্রপার্টি যোগ করা বন্ধ করে।

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
