# নির্দেশাবলি

যে দিনটির জন্য আপনি এতদিন অপেক্ষা করেছিলেন, সেটি অবশেষে এসে গেছে, আর এখন আপনি আল্পসের একটি সুন্দর খামারের গর্বিত মালিক।

সকালে খুব ভোরে উঠে গরুদের খাবার খাওয়ানো আপনার এখনও ভালো লাগে না।
যেহেতু আপনি একজন দুর্দান্ত ইঞ্জিনিয়ার, তাই আপনি একটি ফুড ডিসপেনসার বানান, যার নাম `FEED-M-ALL`।

আপনার প্রকল্প শেষ করার জন্য সর্বশেষ যে জিনিসটি দরকার, তা হলো এমন এক টুকরো কোড, যা হিসাব করে প্রতিটি গরু কতটুকু গোখাদ্য পাওয়া উচিত।
প্রতিটি গরু যেন সমান পরিমাণ পায়, সেটি জরুরি; আপনাকে দ্বন্দ্ব এড়িয়ে চলতে হবে।
গরু খুবই সংবেদনশীল।

ভাগ্য ভালো, গোখাদ্যের পরিমাণ হিসাব করার সব সূত্র আপনাকে নিজে বের করতে হবে না।
আপনি ইন্টারনেটে খুঁজে পাওয়া এক রহস্যময় এক্সটার্নাল লাইব্রেরি ব্যবহার করেন।
এটি ব্যবহার করলে গরুরা সবচেয়ে খুশি থাকার কথা।
লাইব্রেরিটি এমন একটি টাইপ প্রকাশ করে, যা নিচের ইন্টারফেসটি পূরণ করে।
নিজে যে কোডটি লিখবেন, সেখানে আপনি এটির উপর নির্ভর করবেন।

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

কোড নিয়ে কাজ করার সময় আপনি এরর হ্যান্ডলিং আরও উন্নত করবেন, যাতে এটি আরও নির্ভরযোগ্য হয় এবং পরে দৈনন্দিন খামারের কাজে ব্যবহার করার সময় Debug করা সহজ হয়।

## 1. খাবার সমানভাবে ভাগ করুন

সবার আগে আপনি এমন কোড লেখায় মনোযোগ দেন, যা প্রতিটি গরুর জন্য গোখাদ্যের পরিমাণ হিসাব করতে দরকার।

এমন একটি ফাংশন `DivideFood` লিখুন, যা আর্গুমেন্ট হিসেবে একটি `FodderCalculator` এবং ইন্টিজার হিসেবে গরুর সংখ্যা নেয়।
*এই কাজের জন্য আপনি ধরে নিতে পারেন, পাঠানো গরুর সংখ্যা সবসময় শূন্যের চেয়ে বেশি।*
ফাংশনটি প্রতিটি গরুর জন্য খাবারের পরিমাণ `float64` হিসেবে রিটার্ন করবে, আর কোনো এরর ঘটলে সেই এরর রিটার্ন করবে।

হিসাব করার জন্য প্রথমে সব গরুর মোট গোখাদ্যের পরিমাণ বের করতে হবে।
এটি করা হয় `FodderAmount` মেথড কল করে এবং গরুর সংখ্যা পাঠিয়ে।
এছাড়া এমন একটি ফ্যাক্টর দরকার, যা দিয়ে এই পরিমাণ গুণ করতে হবে।
এই ফ্যাক্টরটি আপনি পান `FatteningFactor` মেথড কল করে।
এই দুটি মান আর গরুর সংখ্যা দিয়ে এখন আপনি প্রতিটি গরুর জন্য খাবারের পরিমাণ হিসাব করতে পারেন (`float64` হিসেবে)।
`DivideFood` ফাংশন থেকে এটিই রিটার্ন করা উচিত।

আপনি যে মেথডগুলো কল করেন, তার কোনোটি এরর রিটার্ন করলে কার্যক্রম থেমে যাবে এবং সেই এররটি (যেমন আছে তেমনই) `DivideFood` ফাংশন থেকে রিটার্ন করা উচিত।

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. গরুর সংখ্যা যাচাই করুন

উপরের প্রথম কাজটি করতে গিয়ে আপনি বুঝতে পারলেন, আপনি যে এক্সটার্নাল লাইব্রেরিটি ব্যবহার করছেন, তা আপনার ভাবনার মতো উচ্চমানের নয়।
যেমন, এটি অবৈধ ইনপুট ঠিকভাবে হ্যান্ডল করতে পারে না।
আপনি নিজের কোডে ইনপুট মানের জন্য একটি যাচাই যোগ করে এই সীমাবদ্ধতা কাটিয়ে উঠতে চান।

এমন একটি ফাংশন `ValidateInputAndDivideFood` লিখুন, যার সিগনেচার উপরের `DivideFood`-এর মতোই।

- পাঠানো গরুর সংখ্যা 0-এর চেয়ে বেশি হলে ফাংশনটি `DivideFood` কল করবে এবং সেই কলে যা রিটার্ন আসে তা রিটার্ন করবে।
- গরুর সংখ্যা 0 বা তার কম হলে ফাংশনটি `"invalid number of cows"` বার্তাসহ একটি এরর রিটার্ন করবে।

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. এরর হ্যান্ডলিং উন্নত করুন

পাঠানোর আগে গরুর সংখ্যা যাচাই করা ভালো পদক্ষেপ ছিল, তবে অনির্দিষ্ট এরর বার্তাটি নিয়ে আপনি পুরোপুরি সন্তুষ্ট নন।
আপনি ঠিক করেন `InvalidCowsError` নামের একটি কাস্টম এরর টাইপ বানিয়ে আরও ভালো কিছু করবেন।

কাস্টম এররটিতে গরুর সংখ্যা (`int`) আর একটি কাস্টম বার্তা (`string`) থাকবে, এবং `Error` মেথডটি ডেটাকে নিচের ফরম্যাটে সিরিয়ালাইজ করবে:

```txt
{number of cows} cows are invalid: {custom message}
```

কাস্টম এররটি হাতে নিয়ে এমন একটি ফাংশন `ValidateNumberOfCows` লিখুন, যা ইন্টিজার হিসেবে গরুর সংখ্যা নেয় এবং একটি এরর (অথবা nil) রিটার্ন করে।

- গরুর সংখ্যা 0-এর কম হলে ফাংশনটি একটি `InvalidCowsError` রিটার্ন করে, যার কাস্টম বার্তা `"there are no negative cows"`।
- গরুর সংখ্যা 0 হলে ফাংশনটি একটি `InvalidCowsError` রিটার্ন করে, যার কাস্টম বার্তা `"no cows don't need food"`।
- অন্যথায় ফাংশনটি `nil` রিটার্ন করে, যা বোঝায় ভ্যালিডেশন সফল হয়েছে।

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

এই ভ্যালিডেশন ফাংশনটি সেট আপ করার কঠিন কাজ শেষে আপনি খেয়াল করেন, সন্ধ্যা হয়ে গেছে, আর আপনি ডেস্ক ছেড়ে পাহাড়ের উপরে সূর্যাস্ত উপভোগ করতে বেরিয়ে পড়েন।
নতুন ভ্যালিডেশন ফাংশনটি সত্যিকারের কোডে যোগ করার কাজটি আপনি অন্য একদিনের জন্য ফেলে রাখেন।
