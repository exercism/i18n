# ইঙ্গিত

## 1. একটি পিৎজার দাম হিসাব করুন

- এমন একটি রিকার্সিভ ফাংশন লিখুন, যা ওই অতিরিক্ত টপিং ছাড়া পিৎজার দামের সাথে একটি অতিরিক্ত অপশন যোগ করলে যে দাম হয়, সেটি রিটার্ন করে।
- যদি `Maximum call stack size exceeded` এররটি আসে, তাহলে দেখুন আপনি বেস কেসটি বাদ দিয়ে ফেলেননি তো।
- যদি `Memory Allocation Error` পান, তাহলে দেখুন আপনি টপিংয়ের ইনপুট অ্যারেটি মিউটেট করার বদলে ডুপ্লিকেট করছেন কি না।

## 2. একটি অর্ডারের মোট দাম হিসাব করুন

- `pizzaPrice` ব্যবহার করে অ্যারেটির প্রতিটি পিৎজার দাম হিসাব করুন এবং সেটি একটি যোগফলে যোগ করুন।
- যদি `Maximum call stack size exceeded` এররটি আসে আর একাধিক টেস্ট ফেল করে, তাহলে দেখুন আপনি বেস কেসটি বাদ দিয়ে ফেলেননি তো। যদি কেবল একটি টেস্ট ফেল করে, তাহলে এটি একটি লুপ দিয়ে করার চেষ্টা করে দেখুন!
- যদি `Memory Allocation Error` পান, তাহলে দেখুন আপনি ইনপুট অ্যারেটি মিউটেট করার বদলে ডুপ্লিকেট করছেন কি না।
