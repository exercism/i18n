# সম্পর্কে

ইনিশিয়ালাইজার হলো বিশেষ মেথড, যা একটি এনামের একটি মান সেট আপ করতে ব্যবহৃত হয়। এদের ডেফিনিশন অনেকটা মেথডের ডেফিনিশনের মতোই, শুধু এখানে `func` কিওয়ার্ড নেই, রিটার্ন টাইপ নেই, আর নামটি অবশ্যই `init` হতে হবে এবং ইনিশিয়ালাইজারকে _অবশ্যই_ এনামের একটি মান `self`-এ অ্যাসাইন করতে হবে। ইনিশিয়ালাইজার কল করা হয় ডট নোটেশন দিয়ে, অথবা এনামের নামে ইনিশিয়ালাইজারের প্যারামিটারগুলো পাস করে।

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
