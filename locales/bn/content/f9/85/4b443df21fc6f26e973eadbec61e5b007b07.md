# ভূমিকা

## তুলনা অপারেটর

R-এ অপারেটরগুলোর একটি সেট আছে, যা অন্য অনেক প্রোগ্রামিং ভাষার মতোই:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## ব্রাঞ্চিং

if-else-এর মূল রূপটি হলো

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

এখানে বুলিয়ানকে ঘিরে প্রথম বন্ধনী `()` আর স্টেটমেন্টকে ঘিরে দ্বিতীয় বন্ধনী `{}`, দুটোই আবশ্যক।
একটি সাধারণ `if` স্টেটমেন্টকে ছোট করে লেখা যায়:

```R
if (x == 0) return("success")
```
