# পরিচিতি

একটি _if/else_ স্টেটমেন্টের মতোই, একটি `switch` স্টেটমেন্ট শর্তসাপেক্ষে কোড চালিয়ে প্রোগ্রামের প্রবাহ বদলে দিতে পারে।
পার্থক্য হলো, একটি `switch` স্টেটমেন্ট কেবল একটি প্রিমিটিভ বা স্ট্রিং এক্সপ্রেশনের মানকে আগে থেকে নির্ধারিত কনস্ট্যান্ট মানের সাথে তুলনা করতে পারে।

switch স্টেটমেন্ট ব্যবহারের সময় কিছু কিওয়ার্ড কাজে লাগে।

- `switch`: এই কিওয়ার্ডটি দিয়ে আপনি switch স্টেটমেন্টের গঠন ঘোষণা করতে পারেন।
  এর পরে থাকে সেই এক্সপ্রেশন বা ভ্যারিয়েবল, যেটি ফলাফল বদলে দেবে।
- `case`: এই কিওয়ার্ডটি দিয়ে আপনি ফলাফলের বিভিন্ন সম্ভাবনা ঘোষণা করবেন।
- `break`: কাঙ্ক্ষিত প্রবাহের শেষে switch স্টেটমেন্টের কার্যক্রম থামানোর জন্য `break` কিওয়ার্ডটি খুবই দরকারি।
  এটি ভুলে গেলে প্রোগ্রাম চলতেই থাকবে এবং অপ্রত্যাশিত ফলাফলও দিতে পারে।
- `default`: নাম থেকেই বোঝা যায়, আপনার এক্সপ্রেশনের ফলাফলের সাথে অন্য কোনো কেস না মিললে এটিকে ডিফল্ট ফলাফল হিসেবে ব্যবহার করুন।

এদের সবচেয়ে সরল রূপে এরা একটি প্রিমিটিভ বা স্ট্রিং এক্সপ্রেশন পরীক্ষা করে এবং তার মানের ভিত্তিতে একটি সিদ্ধান্ত নেয়।
যেমন:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
