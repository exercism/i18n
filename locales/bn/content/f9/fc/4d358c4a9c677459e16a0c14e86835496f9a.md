# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে দুর্দান্ত একটি লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার পাঁচটি কাজ আছে, যেগুলোর সবটাই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে ওভেনে থাকার প্রত্যাশিত সময় নির্ধারণ করুন

`Lasagna` ক্লাসে `expectedCookTime` ফাংশনটি ইমপ্লিমেন্ট করুন, যা কোনো আর্গুমেন্ট নেয় না এবং লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত তা রিটার্ন করে।
রান্নার বই অনুযায়ী, ওভেনে থাকার প্রত্যাশিত সময় মিনিটে ৪০:

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. ওভেনে থাকার বাকি সময় মিনিটে হিসাব করুন

`Lasagna` ক্লাসে `remainingCookTime` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে লাসাগনাটি কত মিনিট ধরে ওভেনে আছে তা নেয় এবং আগের কাজে পাওয়া ওভেনে থাকার প্রত্যাশিত সময়ের ভিত্তিতে লাসাগনাটিকে আর কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`Lasagna` ক্লাসে `totalPreparationTime` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে আপনি লাসাগনায় যত স্তর যোগ করেছেন তার সংখ্যা নেয় এবং লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`Lasagna` ক্লাসে `totalElapsedTime` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো আপনি লাসাগনায় যত স্তর যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে আছে তার সংখ্যা।
ফাংশনটি রিটার্ন করবে লাসাগনা রান্নায় আপনি মোট কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় (মিনিটে) আর এই মুহূর্তে লাসাগনাটি ওভেনে যত সময় (মিনিটে) কাটিয়েছে তার যোগফল।

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. লাসাগনা প্রস্তুত হয়েছে এমন একটি নোটিফিকেশন তৈরি করুন

`Lasagna` ক্লাসে `alarm` ফাংশনটি ইমপ্লিমেন্ট করুন, যা কোনো আর্গুমেন্ট নেয় না এবং লাসাগনা খাওয়ার জন্য প্রস্তুত বোঝায় এমন একটি মেসেজ রিটার্ন করে।

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
