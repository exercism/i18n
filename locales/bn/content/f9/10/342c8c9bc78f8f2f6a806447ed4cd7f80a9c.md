# পরিচিতি

একটি *কোটেশন* হলো `[ ]` বন্ধনীর ভেতরে লেখা কোডের একটি অংশ। এটি একটি মান: আপনি এটি স্ট্যাকে পুশ করতে পারেন, অন্য একটি ওয়ার্ডে পাস করতে পারেন, বা একটি অ্যারেতে রেখে দিতে পারেন।

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

বেশিরভাগ হায়ার-অর্ডার ওয়ার্ড তাদের দ্বিতীয় আর্গুমেন্ট হিসেবে একটি কোটেশন নেয়:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

কোটেশনের ভেতরে থাকে সাধারণ Factor কোড, অর্থাৎ যে অপারেটর ও স্ট্যাক এফেক্ট আপনি অন্য সব জায়গায় ব্যবহার করেন, ঠিক সেগুলোই।

যখন আপনি ডেটা থেকে কোড তৈরি করেন, যেমন টুকরো জোড়া লাগিয়ে বা টোকেনকে অপারেশনে ম্যাপ করে, ফলাফলটি একটি সিকোয়েন্স; সেটিকে কল করা যায় এমন করতে `>quotation`-এর মধ্য দিয়ে চালান:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
