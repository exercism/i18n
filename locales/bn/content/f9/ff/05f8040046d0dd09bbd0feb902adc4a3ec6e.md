# পরিচিতি

একটি বুলিয়ান এক্সপ্রেশন হলো এক বা একাধিক মানের কাছে করা একটি প্রশ্ন, যার উত্তর `true` বা `false` দিয়ে দেওয়া যায়।
একটি সত্য এক্সপ্রেশন `1` রিটার্ন করে; একটি মিথ্যা এক্সপ্রেশন `0` রিটার্ন করে।
এছাড়াও, সংখ্যারও ট্রু/ফলস মান থাকে। শূন্য হলো `false`; অশূন্য হলো `true`.

পুরনো C কোড হয় সরাসরি বুলিয়ান মানের জন্য `int` টাইপ ব্যবহার করবে, নয়তো প্রোগ্রামার `1` ও `0`-কে বুলিয়ান রূপে ম্যাপ করার জন্য `TRUE` আর `FALSE`-এর মতো কনস্ট্যান্ট ডিফাইন করে রেখেছেন।

C99 ভার্সনে `_Bool` টাইপটি যোগ করা হয়।
`stdbool.h` হেডার ফাইলটি তিনটি নতুন বুলিয়ান সিম্বল ডিফাইন করে: `bool`; `true` আর `false`.
`true` ম্যাপ হয় `1`-এ; `false` ম্যাপ হয় `0`-এ; আর `bool` ম্যাপ হয় `_Bool`-এ।
তাই এখন, সরাসরি `int` ব্যবহার করা বা নিজেরাই বুলিয়ান ম্যাপিং বানানোর বদলে, প্রোগ্রামাররা `stdbool.h` ইনক্লুড করতে পারেন এবং নিজেদের কোডে স্বয়ংক্রিয়ভাবে বুলিয়ান সিম্বল পেয়ে যান।

## তুলনা অপারেটর

C ছয়টি তুলনা অপারেটর সাপোর্ট করে: `==` (সমান), `!=` (সমান নয়), `>` (এর চেয়ে বড়), `<` (এর চেয়ে ছোট), `>=` (এর চেয়ে বড় বা সমান), `<=` (এর চেয়ে ছোট বা সমান)।
এই অপারেটরগুলো মানের মধ্যকার সম্পর্ক তুলনা করে এবং সেগুলোকে বুলিয়ান মানে রূপান্তর করে।

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## বুলিয়ান অপারেটর

C তিনটি বুলিয়ান অপারেটর সাপোর্ট করে: `||` (অথবা), `&&` (এবং), আর `!` (নয়)।

`!` একটি অপারেন্ড নিয়ে ব্যবহৃত হয়।
এটি অপারেন্ডের বুলিয়ান মান উল্টে দেয়।
উদাহরণস্বরূপ, `0` হলো `false`, কিন্তু `!0` হলো `true`.

`||` আর `&&` দুটি অপারেন্ড নিয়ে ব্যবহৃত হয়।
ডান দিকের অপারেন্ড তখনই মূল্যায়ন করা হয়, যখন বাম দিকের অপারেন্ড এক্সপ্রেশনের ফলাফল আগেই নির্ধারণ করে না।
অর্থাৎ, `||` তার ডান দিকের অপারেন্ড তখনই মূল্যায়ন করে, যখন তার বাম দিকের অপারেন্ডের মান `false` হয়।
`&&` তার ডান দিকের অপারেন্ড তখনই মূল্যায়ন করে, যখন তার বাম দিকের অপারেন্ডের মান `true` হয়।


## শর্ট-সার্কিটিং

সব অপারেন্ড মূল্যায়ন না করাকেই বলা হয় "শর্ট-সার্কিটিং"।
শর্ট-সার্কিটিং নির্দিষ্ট কিছু পরিস্থিতি সামলানোর একটি সংক্ষিপ্ত ও শক্তিশালী উপায়।
উদাহরণস্বরূপ, একটি কমন আইডিয়ম হলো: একটি পয়েন্টার `NULL` নয় কিনা তা যাচাই করা এবং (&&), সেটি `NULL` না হলে, তাকে ডিরেফারেন্স করা, ফলে একটি `NULL` পয়েন্টার ডিরেফারেন্স করা এড়ানো যায়।
কিন্তু শর্ট-সার্কিটিং Bug-ও ডেকে আনতে পারে।
মাঝে মাঝে একজন প্রোগ্রামার ভুলে যান যে `||` বা `&&`-এর ডান দিকের অপারেন্ড সব সময় মূল্যায়ন নাও হতে পারে।
ডান দিকের অপারেন্ড যদি এমন একটি এক্সপ্রেশন হয় যার একটি সাইড ইফেক্ট সব সময় ঘটবে বলে আশা করা হয়, তাহলে বাম দিকের অপারেন্ডের বুলিয়ান মানের উপর নির্ভর করে সেটি একটি Bug হয়ে দাঁড়াবে।


## বুলিয়ান এক্সপ্রেশন রিটার্ন করা

একটি বুলিয়ান এক্সপ্রেশনের ফলাফল সরাসরি রিটার্ন করা যায়।
উদাহরণস্বরূপ, এই `if` স্টেটমেন্টটি

```c
if (count > 0)
    return true;
else
    return false;
end
```

এভাবে বদলে দেওয়া যায়

```c
return count > 0;
```
