# পরিচিতি

Go-তে স্ট্রিং ইমিউটেবল। লুপে `+` দিয়ে স্ট্রিং জোড়া লাগালে ঘন ঘন অ্যালোকেশন হয় এবং ডেটা একাধিকবার কপি হয়। মেমরি ওভারহেড কমাতে [`strings` প্যাকেজ](https://pkg.go.dev/strings) [`Builder`](https://pkg.go.dev/strings#Builder) দেয়, যার সাহায্যে দক্ষভাবে স্ট্রিং তৈরি করা যায়।

## স্ট্রিং তৈরি করা

একটি `strings.Builder`-এর জিরো ভ্যালু কোনো স্পষ্ট ইনিশিয়ালাইজেশন বা অ্যালোকেশন ছাড়াই সঙ্গে সঙ্গে ব্যবহারের জন্য প্রস্তুত থাকে। আপনি নির্দিষ্ট রাইট মেথড ব্যবহার করে বিল্ডারে নতুন ডেটা ঢুকাতে পারেন। প্রতিটি রাইট মেথড স্ট্যান্ডার্ড Go ইন্টারফেসের শর্ত পূরণ করতে একটি এরর মান রিটার্ন করে, তবে এটি সবসময় `nil` হওয়ার নিশ্চয়তা থাকে এবং সাধারণ কোডে এটিকে সাধারণত উপেক্ষা করা হয়।

সবচেয়ে বেশি ব্যবহৃত মেথডগুলো হলো:

- `WriteString(s string) (int, error)`: বাফারে একটি স্ট্রিং যোগ করে।
- `WriteRune(r rune) (int, error)`: একটি রুনের UTF-8 এনকোডিং যোগ করে।
- `WriteByte(c byte) error`: একটি মাত্র বাইট যোগ করে।

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## রিট্রিভ করা ও রিসেট করা

আপনার টেক্সট তৈরি হয়ে গেলে `String()` মেথড কল করে জমে থাকা কনটেন্টকে স্ট্যান্ডার্ড Go স্ট্রিং হিসেবে বের করতে পারেন। `String()` কল করা খুবই কম খরচের একটি অপারেশন, কারণ এটি জমে থাকা ডেটা কপি না করেই অন্তর্নিহিত বাইট স্লাইসকে সরাসরি স্ট্রিং হিসেবে রিটার্ন করে।

নতুন একটি স্ট্রিং তৈরি করতে একই বিল্ডার ইনস্ট্যান্স আবার ব্যবহার করার প্রয়োজন হলে (যেমন কোনো লুপের ভিতরে), আপনি `Reset()` মেথড কল করতে পারেন। এটি অভ্যন্তরীণ বাফার খালি করে দেয়, যার ফলে আপনি নতুন করে শুরু করতে পারেন এবং ভেতরে ইতিমধ্যে অ্যালোকেট করা মেমরি ক্যাপাসিটি ধরে রেখেই পরের স্ট্রিং তৈরি করতে পারেন।

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
