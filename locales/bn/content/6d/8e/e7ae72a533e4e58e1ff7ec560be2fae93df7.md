# রিসোর্স

* [The Rust Programming Language](https://doc.rust-lang.org/book/) হলো Rust শুরু করার এবং Rust-এর নির্দিষ্ট কিছু ফিচার নিয়ে গভীরে যাওয়ার একটি দারুণ রিসোর্স।
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) এ আপনি Rust-এ লেখা সবচেয়ে কমন জিনিসগুলোর উদাহরণ দেখতে পাবেন।
* নতুন নতুন মেথড এবং সেগুলো কীভাবে কাজ করে তা জানতে [Rust API Documentation](http://doc.rust-lang.org/std/) ব্যবহার করতে পারেন।
* আপনার সমস্যাটি খুঁজতে এবং এটি আগেই উত্তর দেওয়া হয়েছে কি না দেখতে [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) ব্যবহার করতে পারেন। এছাড়া আপনি প্রশ্ন করতে ও উত্তর দিতেও পারেন।
* [Rust User Forum](http://users.rust-lang.org) হলো Rust নিয়ে সাধারণ আলোচনার জায়গা।
* [/r/rust](http://www.reddit.com/r/rust/) হলো Rust-এর অফিসিয়াল সাবরেডিট।
* ভাষাটি নিয়ে দ্রুত প্রশ্ন ও আলোচনার জন্য [Discord](https://discordapp.com/) এ [The Rust Programming Language](https://discord.gg/rust-lang)-এর অফিসিয়াল সার্ভার ব্যবহার করতে পারেন।
