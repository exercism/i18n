# ভূমিকা

অন্যান্য অনেক ভাষার মতো C++-এও _পয়েন্টার_ আছে।
আপনি ইতিমধ্যেই জানেন যে _রেফারেন্স_ আর _পয়েন্টার_ একই রকম, তবে এগুলোকে আপনার কম্পিউটারের ভেতরের কার্যপ্রণালীর আরও কাছের একটি স্তর ভাবুন।
_পয়েন্টার_ হলো এমন ভ্যারিয়েবল, যেগুলো অবজেক্টের অ্যাড্রেস ধরে রাখে।
এগুলো দিয়ে সরাসরি অবজেক্টের সাথে কাজ করা যায়, যা C++-এ ডাইনামিক মেমরি অ্যালোকেশন আর দক্ষ ডেটা ম্যানিপুলেশন সম্ভব করে।

আপনি যদি _পয়েন্টারে_ নতুন হন, তবে শুরুতে এগুলো একটু রহস্যময় লাগতে পারে, কিন্তু একবার অভ্যস্ত হয়ে গেলে এগুলো বেশ সহজ।

এগুলো C++-এর একটি অত্যন্ত গুরুত্বপূর্ণ অংশ, তাই এগুলো সত্যিকারভাবে বোঝার জন্য একটু সময় নিন।
এই কনসেপ্টে যে সাধারণ রূপটি দেখানো হয়েছে, তাকে _ডাম পয়েন্টার_ বা _র পয়েন্টার_ও বলা হয়।
আধুনিক C++-এ _স্মার্ট পয়েন্টার_-ও আছে, তবে মূল টাইপটি তো আদৌ স্মার্ট নয়, সব কাজ আপনাকেই হাতে হাতে সামলাতে হয়।

বিস্তারিত আলোচনায় ঢোকার আগে _পয়েন্টারের_ ব্যবহারটা বুঝে নেওয়া ভালো।
_পয়েন্টার_ হলো আমাদের প্রোগ্রামের অন্য অংশগুলোর সাথে একটি অবজেক্টের অ্যাড্রেস ভাগ করে নেওয়ার একটি উপায়, যা দুটি বড় কারণে কাজে লাগে:

1. _রেফারেন্সের_ মতোই পয়েন্টার কপি এড়ায় এবং আপনার প্রোগ্রামের রিসোর্স ফুটপ্রিন্ট কমাতে সাহায্য করে।
1. _রেফারেন্সের_ বিপরীতে, পয়েন্টারকে ভিন্ন ভিন্ন অবজেক্টে আবার অ্যাসাইন করা যায়।
1. পয়েন্টার একটি নাল ভ্যালুও দেখাতে পারে, যা বোঝায় যে এটি এই মুহূর্তে কোনো অবজেক্টের দিকে দেখছে না।

## সাধারণ সিনট্যাক্স

C++-এ একটি পয়েন্টার ডিক্লেয়ার করতে হলে প্রথমে বলে দিতে হয় এটি কোন ডেটা টাইপের দিকে দেখছে, তারপর একটি অ্যাস্টেরিস্ক (`*`) আর পয়েন্টারের নাম লিখতে হয়।
পয়েন্টার ডিক্লেয়ার করা হলে সেগুলো স্বয়ংক্রিয়ভাবে ইনিশিয়ালাইজ হয় না।
স্পষ্টভাবে অ্যাসাইন না করলে একটি পয়েন্টার সাধারণত একটি অনির্দিষ্ট মান ধারণ করে, যাকে প্রায়ই "গার্বেজ অ্যাড্রেস" বলা হয়।
কিছু কম্পাইলার পয়েন্টারকে `nullptr` দিয়ে ইনিশিয়ালাইজ করতে পারে, তবে সব কম্পাইলারে এমনটা হবে এমন কোনো নিশ্চয়তা নেই, তাই এর উপর ভরসা করা একেবারেই উচিত নয়।
সম্ভাব্য সমস্যা এড়াতে র পয়েন্টার স্পষ্টভাবে ইনিশিয়ালাইজ করা এবং ব্যবহারের আগে সেটি নাল নয় কি না যাচাই করা সর্বোত্তম অভ্যাস।

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

একটি ভ্যারিয়েবলের অ্যাড্রেস পয়েন্টারে অ্যাসাইন করতে আপনি অ্যাড্রেস-অব অপারেটর (`&`) ব্যবহার করেন।
পয়েন্টার ডিরেফারেন্স করতে _ইনডিরেকশন অপারেটর_ (`*`) ব্যবহার করা হয়।

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

লক্ষ্য করুন: ডিরেফারেন্স করতে হয় স্পষ্টভাবে, অথচ _রেফারেন্স_ তো অ্যালিয়াসের মতোই কাজ করত।

## পয়েন্টার অ্যারিথমেটিক

_পয়েন্টার অ্যারিথমেটিক_ দিয়ে পয়েন্টারের উপর গাণিতিক অপারেশন করা যায়, যা অ্যারে নিয়ে কাজ করার সময় বিশেষভাবে কাজে লাগে।
একটি পয়েন্টারের সাথে একটি ইন্টিজার যোগ করলে সেটি ভিন্ন একটি এলিমেন্টের দিকে দেখাতে শুরু করে।

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution

## মেম্বার ভ্যারিয়েবল অ্যাক্সেস করা

C++-এ কোনো অবজেক্টের দিকে থাকা পয়েন্টার দিয়ে সেই অবজেক্টের মেম্বার অ্যাক্সেস করতে `->` অপারেটর ব্যবহার করা হয়।
এটি একটি শর্টহ্যান্ড, যা পয়েন্টার দিয়ে দেখানো অবজেক্টগুলোর মেম্বার অ্যাক্সেস করা সহজ করে তোলে।
যেমন, `ptr` যদি `x` নামের মেম্বার ভ্যারিয়েবলযুক্ত কোনো অবজেক্টের পয়েন্টার হয়, তাহলে `(*ptr).x` ব্যবহার না করে সোজা `ptr->x` লিখতে পারেন।
অবজেক্টের পয়েন্টার নিয়ে কাজ করার সময় এই অপারেটর কোডের পাঠযোগ্যতা বাড়ায় এবং বাহুল্য কমায়।

এখানে একটি সংক্ষিপ্ত উদাহরণ, যেখানে `Superhero` নামের একটি _স্ট্রাক্ট_-এর একটি মেম্বার ভ্যারিয়েবল `superpower` আছে।
main ফাংশনটি `Superhero` অবজেক্টের (যা Wonder Woman-কে বোঝায়) একটি পয়েন্টার `dianaPrince` তৈরি করে।
`->` অপারেটর দিয়ে মেম্বার ভ্যারিয়েবল `superpower` অ্যাক্সেস করা হয়েছে, যা Wonder Woman-এর আইকনিক "Lasso of Truth" তুলে ধরে।

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## পয়েন্টার বনাম রেফারেন্স

পয়েন্টার আর রেফারেন্স দুটোই অবজেক্টে পরোক্ষভাবে অ্যাক্সেস দেয়, তবে সক্ষমতা আর নিরাপত্তার দিক থেকে এদের মধ্যে পার্থক্য আছে।
পয়েন্টার নিজের লক্ষ্য অবজেক্ট বদলানোর নমনীয়তা দেয় এবং এটিকে নাল অ্যাসাইন করা যায়।
তবে এই নমনীয়তা সঙ্গে কিছু ঝুঁকিও আনে, যেমন নাল পয়েন্টার ডিরেফারেন্স করা বা ড্যাঙ্গলিং পয়েন্টার তৈরি করা।
অন্যদিকে রেফারেন্স কখনো নাল হতে পারে না এবং তৈরি হওয়ার সময়ই বৈধ অবজেক্টের সাথে বাঁধা পড়ে যায়, ফলে এসব ঝুঁকি এড়ানো যায়।
যেহেতু রেফারেন্স নিরাপদ, তাই পয়েন্টারের দেওয়া বাড়তি সুবিধাগুলো প্রয়োজন না হলে পয়েন্টারের চেয়ে রেফারেন্সকেই প্রাধান্য দেওয়া উচিত।
