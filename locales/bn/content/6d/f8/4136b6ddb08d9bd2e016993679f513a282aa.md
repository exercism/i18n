# শেখা

## Emacs দিয়ে শুরু করা

তাহলে আপনি Emacs ইনস্টল করেছেন। এখন কী করবেন?

শুরু করার জন্য `C-h t` চেপে টিউটোরিয়ালটি চালু করতে পারেন, আর শুরু করার জন্য এটি মোটেও খারাপ জায়গা নয়। টিউটোরিয়ালে Emacs-এ এডিটিং, সার্চিং আর নেভিগেশনের মূল বিষয়গুলো শেখানো হবে।

Emacs-এ আপনি যদি একেবারে নতুন হন, তাহলে একটি স্টার্টার কিট নিয়ে নেওয়াটা যুক্তিসঙ্গত হতে পারে, যেটিতে আগে থেকেই কিছু কনফিগারেশন আর প্যাকেজ সেট করা থাকে।

[Emacs Prelude](http://batsov.com/prelude/) প্যাকেজে বেশ কিছু যুক্তিসঙ্গত ডিফল্ট আর প্যাকেজ রয়েছে।

Emacs Prelude ইনস্টল করতে টার্মিনালে নিচেরটা রান করুন:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

আর আরও নির্দেশনার জন্য [ইনস্টলেশন গাইড](https://prelude.emacsredux.com/en/latest/installation/) অবশ্যই দেখে নিন।


আপনি যদি vim-এর সাথে পরিচিত হন, তাহলে [Doom Emacs](https://github.com/doomemacs/doomemacs) স্টার্টার কিটটি আপনার ভালো লাগতে পারে, যেটিতে [evil-mode](https://github.com/emacs-evil/evil)-এর সাহায্যে vim এমুলেশন যুক্ত করা হয়েছে।

Doom Emacs ইনস্টল করতে টার্মিনালে নিচেরটা রান করুন:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

আর আরও নির্দেশনার জন্য [ইনস্টলেশন গাইড](https://github.com/doomemacs/doomemacs#install) অবশ্যই দেখে নিন।

## সিনট্যাক্স চেকিং ও লিন্টিং সেটআপ করা

[Flycheck](https://www.flycheck.org/en/latest/) দিয়ে সিনট্যাক্স চেকিং ও লিন্টিং সেটআপ করার পরামর্শ দেওয়া হয়।

আপনি যদি ইতিমধ্যে আপনার Emacs-এ [MELPA](https://melpa.org/) রিপোজিটরি যোগ না করে থাকেন, তাহলে আপনার [init file](https://www.flycheck.org/en/latest/glossary.html#term-init-file)-এ নিচেরটা যোগ করে সেটি করুন

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

[use-package](https://github.com/jwiegley/use-package) ছাড়া Flycheck ইনস্টল ও সেটআপ করতে আপনার [init file](https://www.flycheck.org/en/latest/glossary.html#term-init-file)-এ নিচেরটা যোগ করুন

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

[use-package](https://github.com/jwiegley/use-package) দিয়ে Flycheck ইনস্টল ও সেটআপ করতে আপনার [init file](https://www.flycheck.org/en/latest/glossary.html#term-init-file)-এ নিচেরটা যোগ করুন

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

আরও তথ্য আর সমস্যা সমাধানের জন্য [Flycheck ডকুমেন্টেশন](https://www.flycheck.org/en/latest/user/troubleshooting.html) দেখে নিন।

## Emacs Lisp শেখা

Emacs Lisp-এর সেরা ডকুমেন্টেশন... আসলে Emacs-এর সাথেই দেওয়া আছে!
[Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html)-এ যেতে
`C-h i` টাইপ করে Elisp এন্ট্রিটি খুঁজুন, অথবা Help &rarr; More Manuals
&rarr; Emacs Lisp Reference নির্বাচন করুন।  মনে রাখবেন, কিছু
ডিস্ট্রিবিউশনে এই ম্যানুয়ালটি নাও থাকতে পারে, সেক্ষেত্রে এটি
[অনলাইনে](https://www.gnu.org/software/emacs/manual/elisp.html) পাবেন।

Elisp-এ আপনি যদি একেবারে নতুন হন, তাহলে
[Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro) পড়তে পারেন,
যেটি একইভাবে খোলা হয়।

## Emacs Lisp-এর বেস্ট প্র্যাকটিস ও কনভেনশন

The Emacs Manual-এ Emacs Lisp-এর [Coding Conventions](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) নামে একটি অংশ আছে।
এছাড়া GitHub-এ রক্ষণাবেক্ষণ করা একটি কমিউনিটি-চালিত [Style Guide](https://github.com/bbatsov/emacs-lisp-style-guide)-ও আছে।
