# ইনস্টলেশন

এই ট্র্যাকের সমাধানগুলো ৩২-বিট RISC-V অ্যাসেম্বলিতে লেখা এবং এমুলেশনে চালানো হয়, তাই কোনো RISC-V হার্ডওয়্যার লাগে না।
প্রতিটি অনুশীলনীর সাথে একটি Makefile দেওয়া থাকে, যা টেস্ট বিল্ড করে এবং সেগুলো রান করে।
এটি ব্যবহার করতে আপনার তিনটি টুল দরকার:

- [Zig][zig], যা `zig cc`-এর মাধ্যমে RISC-V অ্যাসেম্বলার, C কম্পাইলার ও লিংকার দেয়।
- [Make][make], যা বিল্ডটি রান করে।
- [QEMU][qemu]-এর `qemu-riscv32`, যা তৈরি হওয়া প্রোগ্রামটি চালায়।

## macOS

যেকোনো উপযুক্ত ভার্চুয়ালাইজেশন সমাধান (যেমন [Lima][lima]) দিয়ে একটি লিনাক্স ভার্চুয়াল মেশিন চালু করুন এবং নিচের লিনাক্স ডিস্ট্রিবিউশন অংশটি অনুসরণ করুন।

## Windows

[Windows Subsystem for Linux][wsl] ব্যবহার করুন এবং নিচের লিনাক্স ডিস্ট্রিবিউশন অংশটি অনুসরণ করুন।
বিকল্পভাবে, একটি লিনাক্স ভার্চুয়াল মেশিন সেট আপ করুন।

## Debian / Ubuntu

Make ও QEMU-এর ইউজার-মোড এমুলেটর ইনস্টল করুন:

```shell
sudo apt install make qemu-user
```

এরপর [সরাসরি ডাউনলোড][zig-install] অংশে বর্ণনা অনুযায়ী Zig 0.15.2 বা তার পরের ভার্সন ইনস্টল করুন।

## Fedora

তিনটি টুলই ইনস্টল করুন এভাবে:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

তিনটি টুলই ইনস্টল করুন এভাবে:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

তিনটি টুলই ইনস্টল করুন এভাবে:

```shell
sudo zypper install zig make qemu-linux-user
```

## ইনস্টলেশন যাচাই করা

নিশ্চিত করুন যে তিনটি টুলই খুঁজে পাওয়া যাচ্ছে:

```shell
zig version
make --version
qemu-riscv32 --version
```

এরপর Exercism CLI দিয়ে একটি অনুশীলনী ডাউনলোড করুন এবং তার টেস্ট রান করুন:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
