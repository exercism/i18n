# ভিজিবিলিটি

ক্লাস দিয়ে কোড সাজানোর সময়, প্রপার্টি, মেথড আর কনস্ট্যান্টের ভিজিবিলিটি যথাযথ অ্যাবস্ট্রাকশন আর দায়িত্ব গঠনে সাহায্য করে।
প্রপার্টি, মেথড আর কনস্ট্যান্টের ভিজিবিলিটি নির্ধারিত হয় সেগুলো ডিক্লেয়ার করার সময় `public`, `private` বা `protected` কিওয়ার্ড যেভাবে ব্যবহার করা হয়েছে তার দ্বারা।
ভিজিবিলিটি সবসময় ক্লাসের ওই প্রপার্টি, মেথড বা কনস্ট্যান্ট বাইরে থেকে ব্যবহারের সাপেক্ষে বিচার করা হয়।
অর্থাৎ, কোনো প্রপার্টি `public` হিসেবে ডিক্লেয়ার করা হলে সেটি বাইরের কল থেকে অবজার্ভ করা যায় এবং ব্যবহার করা যায়।
Private প্রপার্টি, মেথড আর কনস্ট্যান্ট বাইরের কল থেকে অবজার্ভ করা বা ব্যবহার করা যায় না।

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Protected প্রপার্টি, মেথড আর কনস্ট্যান্ট কেবল নিজেদের আর ইনহেরিট্যান্সের মাধ্যমে পাওয়া চাইল্ড ক্লাসের কাছেই অবজার্ভযোগ্য।

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
