# ইনস্টলেশন

## .NET ইনস্টল করা

C# ট্র্যাকটি [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) প্ল্যাটফর্মের উপরে তৈরি, যা Windows, Linux ও macOS-এ চলে।
.NET প্রজেক্ট বানাতে আপনি .NET কমান্ড লাইন ইন্টারফেস (CLI) ব্যবহার করতে পারেন।
এই CLI হলো .NET SDK-এর অংশ, যা আপনি [ইনস্টলেশনের নির্দেশাবলি](https://dotnet.microsoft.com/download/dotnet/8.0) অনুসরণ করে ইনস্টল করতে পারেন।
দ্রষ্টব্য: C# ট্র্যাকটির জন্য SDK সংস্করণ 9.0 বা তার বেশি প্রয়োজন।

ইনস্টলেশন শেষ করার পর, টার্মিনালে এই কমান্ডটি চালিয়ে আপনি যাচাই করতে পারেন যে CLI সফলভাবে ইনস্টল হয়েছে কি না:

```bash
dotnet --version
```

আউটপুট যদি `9.0.100` বা তার চেয়ে বড় কোনো সংস্করণ হয়, তাহলে .NET SDK সফলভাবে ইনস্টল হয়েছে।

## একটি IDE ব্যবহার করা

আরও পূর্ণাঙ্গ এডিটিং অভিজ্ঞতা চাইলে আপনি সম্ভবত একটি [IDE বা ইন্টিগ্রেটেড ডেভেলপমেন্ট এনভায়রনমেন্ট)](https://en.wikipedia.org/wiki/Integrated_development_environment) ব্যবহার করতে চাইবেন।
নিচেরগুলো .NET প্রজেক্ট বানানো সমর্থন করে এমন সবচেয়ে জনপ্রিয় IDE:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) with the [C# extension](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

দ্রষ্টব্য: .NET প্রজেক্টের ফরম্যাট আগের সংস্করণগুলো থেকে অনেকটাই আলাদা হওয়ায় Visual Studio 2015-এর মতো পুরনো IDE সমর্থিত নয়।
