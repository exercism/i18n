# অ্যারের ফাংশন ব্যবহার করবেন না

আপনার ইমপ্লিমেন্টেশনে List, Enum বা Stream-এর মতো কোনো এক্সটার্নাল মডিউল ব্যবহার করবেন না। এই অনুশীলনীর মূল উদ্দেশ্য হলো এই সাধারণ ফাংশনগুলো নিজে তৈরি করা। সংখ্যা যোগ করার জন্য `Kernel.+/2`-এর মতো সাধারণ Kernel ফাংশন আপনি ব্যবহার করতে পারেন, তবে অ্যারের জন্য ব্যবহৃত `++`, `--`, `hd`, `tl`, `in`, `for` ও `length`-এর মতো Kernel ফাংশন ব্যবহার করবেন না।
