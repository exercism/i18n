# ভূমিকা

Gleam-এ দুই ধরনের সংখ্যা আছে: ইন্টিজার আর ফ্লোট।

ইন্টিজার হলো পূর্ণসংখ্যা।

```gleam
let integer = 3
// -> 3
```

Gleam-এ কয়েকটি অপারেটর আছে যেগুলো ইন্টিজার নিয়ে কাজ করে।

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
