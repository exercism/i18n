# পরিচিতি

Go-তে স্লাইস অন্য ভাষার লিস্ট বা অ্যারের মতোই।
এগুলো একটি নির্দিষ্ট টাইপের (বা ইন্টারফেসের) একাধিক এলিমেন্ট ধারণ করে।

Go-তে স্লাইস অ্যারের উপর ভিত্তি করে তৈরি।
অ্যারের আকার নির্দিষ্ট থাকে।
অন্যদিকে একটি স্লাইস হলো একটি অ্যারের এলিমেন্টগুলোর ডাইনামিক আকারের একটি নমনীয় ভিউ।

একটি স্লাইস লেখা হয় `[]T` এর মতো, যেখানে `T` হলো স্লাইসের এলিমেন্টগুলোর টাইপ:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

তৃতীয় বন্ধনী নোটেশন ব্যবহার করে আপনি নির্দিষ্ট শূন্য-ভিত্তিক ইনডেক্সে একটি এলিমেন্ট পেতে বা সেট করতে পারেন:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

এলিমেন্টের একটি রেঞ্জ নিয়ে আপনি বিদ্যমান স্লাইস থেকে নতুন স্লাইস তৈরি করতে পারেন।
আবারও তৃতীয় বন্ধনী নোটেশন ব্যবহার করে, তবে এবার শুরু (অন্তর্ভুক্ত) ও শেষ (অন্তর্ভুক্ত নয়) দুটি ইনডেক্সই উল্লেখ করে।
আপনি যদি শুরুর ইনডেক্স উল্লেখ না করেন, তাহলে তা ডিফল্টভাবে 0 হয়।
আপনি যদি শেষের ইনডেক্স উল্লেখ না করেন, তাহলে তা ডিফল্টভাবে স্লাইসের দৈর্ঘ্য হয়।

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

`append` ফাংশন ব্যবহার করে আপনি একটি স্লাইসে এলিমেন্ট যোগ করতে পারেন।
নিচে আমরা `a` স্লাইসে `4` ও `2` যোগ করছি।

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append` সবসময় একটি নতুন স্লাইস রিটার্ন করে, আর যখন আমরা শুধু বিদ্যমান স্লাইসে এলিমেন্ট যোগ করতে চাই, তখন উপরের মতো প্রথম আর্গুমেন্ট হিসেবে পাস করা স্লাইস ভ্যারিয়েবলেই এটিকে আবার অ্যাসাইন করে দেওয়াটাই সাধারণ রীতি।

দুটি স্লাইস একত্র করতেও `append` ব্যবহার করা যায়:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## স্লাইসের ইনডেক্স

স্লাইসের ইনডেক্স নিয়ে কাজ করার সময় সবসময় কোনোভাবে একটি চেক দিয়ে সুরক্ষিত রাখা উচিত, যা নিশ্চিত করে যে ইনডেক্সটি সত্যিই আছে।
তা না করলে পুরো অ্যাপ্লিকেশনটাই ক্র্যাশ করবে।

## খালি স্লাইস

`nil`-স্লাইস হলো ডিফল্ট খালি স্লাইস।
কোনো মান নেই এমন স্লাইসের তুলনায় এগুলোর কোনো অসুবিধা নেই।
`len` ফাংশন `nil`-স্লাইসে কাজ করে, এটিকে ইনিশিয়ালাইজ না করেই আইটেম যোগ করা যায়, ইত্যাদি।
নতুন স্লাইস তৈরি করতে হলে `s := []int{}` (খালি, non-`nil` স্লাইস) এর চেয়ে `var s []int` (`nil`-স্লাইস) কে প্রাধান্য দিন।

## পারফরম্যান্স

ধাপে ধাপে ভরে তোলার জন্য স্লাইস তৈরি করার সময়, যদি স্লাইসের চূড়ান্ত আকার আগে থেকেই জানা থাকে, তাহলে পারফরম্যান্স উন্নত করার একটি সহজ সুযোগ আছে।
মূল কথা হলো মেমরি অ্যালোকেট করার সংখ্যা যতটা সম্ভব কমানো, কারণ এটি বেশ খরচসাপেক্ষ, আর স্লাইস তার বরাদ্দ করা মেমরি স্পেসের বাইরে বেড়ে গেলেই এটি ঘটে।
এটি করার সবচেয়ে নিরাপদ উপায় হলো `s := make([]int, 0, cap)` দিয়ে স্লাইসের জন্য একটি ক্যাপাসিটি `cap` নির্দিষ্ট করা, তারপর যথারীতি স্লাইসে `append` করা।
এভাবে স্লাইসের দৈর্ঘ্য শূন্য থাকা অবস্থাতেই `cap` পরিমাণ আইটেমের জন্য জায়গা সাথে সাথে অ্যালোকেট হয়ে যায়।
বাস্তবে `cap` প্রায়ই অন্য একটি স্লাইসের দৈর্ঘ্য হয়ে থাকে: `s := make([]int, 0, len(otherSlice))`.

## `append` কোনো পিউর ফাংশন নয়

Go-র `append` ফাংশনটি পারফরম্যান্সের জন্য অপ্টিমাইজ করা, তাই এটি ইনপুট স্লাইসের কোনো কপি তৈরি করে না।
এর মানে হলো মূল স্লাইসটি (`append` এর ১ম প্যারামিটার) কখনো কখনো পরিবর্তিত হয়ে যায়।
