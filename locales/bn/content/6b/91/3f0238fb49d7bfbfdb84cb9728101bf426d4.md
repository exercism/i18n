# সম্পর্কে

Gleam-এ একটি `Iterator` একটি অ্যারের মতোই, কারণ এটি মানের একটি ক্রমবদ্ধ সংগ্রহ, যেখানে সব মান একই টাইপের। এটি অ্যারের থেকে আলাদা কারণ এটি লেজি, অর্থাৎ এটি তার সব মান একসাথে মেমরিতে সংরক্ষণ করে না, বরং প্রয়োজন অনুযায়ী সেগুলো গণনা করে।

এটি খুব বড় বা অসীম আকারের সিকোয়েন্স নিয়ে কাজ করার সময় দরকারী, কারণ এটি আমাদের সেইসব নিয়ে কাজ করার সুযোগ দেয় যখন সেগুলো একসাথে সংরক্ষণ করার জন্য পর্যাপ্ত ফ্রি মেমরি থাকে না।

`gleam/iterator` মডিউলটি `Iterator` টাইপ এবং ইটারেটর নিয়ে কাজ করার ফাংশনগুলো সংজ্ঞায়িত করে।

অ্যারের জন্য অনেক ফাংশন ইটারেটরেও আছে, যেমন `map`, `filter`, এবং `take`। এই ফাংশনগুলো ইটারেটর রিটার্ন করে, তাই ইটারেটরটি কনজিউম না হওয়া পর্যন্ত ফাংশনগুলো আসলে কোনো কাজ করে না।

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` ফাংশনটি ব্যবহার করে এমন একটি ফাংশন থেকে ইটারেটর তৈরি করা যায়, যেটি সিকোয়েন্সের পরবর্তী মান তৈরি করার জন্য বারবার কল করা হয়।

এখানে `unfold` ফাংশনটি ফিবোনাচি সিকোয়েন্স তৈরি করে এমন একটি ইটারেটর বানাতে ব্যবহার করা হয়েছে:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

এখানে সিকোয়েন্সটি অসীম, তাই মানগুলোকে অ্যারেতে সংগ্রহ করার আগে `take` ফাংশনটি ব্যবহার করে এটিকে সীমিত করা হয়েছে। যদি একটি অসীম ইটারেটরের উপর `to_list` কল করা হয়, তাহলে প্রোগ্রামটি মেমরি শেষ হয়ে ক্র্যাশ না করা পর্যন্ত চলতে থাকবে।
