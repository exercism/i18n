# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু ইউটিলিটি রুটিনের একটি আংশিক সেট ইমপ্লিমেন্ট করবেন, যা একজন ডেভেলপারকে SqueakyClean নাম পরিষ্কার করতে সাহায্য করবে।

৪টি টাস্কে আপনি ধীরে ধীরে `clean` মেথডটি গড়ে তুলবেন।
একটি বৈধ SqueakyClean নাম শূন্য বা তার বেশি সংখ্যক অক্ষর ও আন্ডারস্কোর নিয়ে গঠিত।

সব ক্ষেত্রেই ইনপুট স্ট্রিংটি নন-নাল হওয়ার নিশ্চয়তা আছে। মনে রাখবেন, `clean` মেথডটি একটি খালি স্ট্রিংকে বৈধ হিসেবে গণ্য করবে।

## 1. যেকোনো স্পেসকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করুন

যেকোনো স্পেসকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করতে (_static_) `SqueakyClean.clean()` মেথডটি ইমপ্লিমেন্ট করুন। এটি শুরু ও শেষে থাকা স্পেসেও প্রযোজ্য।

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. kebab-case থেকে camelCase-এ রূপান্তর করুন

kebab-case থেকে camelCase-এ রূপান্তর করতে (_static_) `SqueakyClean.clean()` মেথডটি পরিবর্তন করুন।

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. লিটস্পিককে সাধারণ লেখায় রূপান্তর করুন

[লিটস্পিক][leet-speak]কে সাধারণ লেখায় রূপান্তর করতে (_static_) `SqueakyClean.clean()` মেথডটি পরিবর্তন করুন।

সহজ রাখতে আমরা শুধু `4`, `3`, `0`, `1` ও `7`-কে যথাক্রমে `a`, `e`, `o`, `l` ও `t` দিয়ে প্রতিস্থাপন করব।

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. যে ক্যারেক্টারগুলো অক্ষর নয়, সেগুলো বাদ দিন

যেসব ক্যারেক্টার অক্ষর নয়, সেগুলো বাদ দিতে (_static_) `SqueakyClean.clean()` মেথডটি পরিবর্তন করুন।

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```
