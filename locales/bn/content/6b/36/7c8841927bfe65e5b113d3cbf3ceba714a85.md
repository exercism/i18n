# নির্দেশাবলীর সংযোজন

## ইঙ্গিত

আপনার `decode` এবং `encode` ফাংশন দুটি ইমপ্লিমেন্ট করতে হবে, যেগুলো Affine সাইফার ব্যবহার করে একটি `String` ডিকোড ও এনকোড করে।
টাইপ নিয়ে নিশ্চিত না থাকলে প্রদত্ত সিগনেচারটি ব্যবহার করতে পারেন, তবে সেটি যেন আপনার সৃজনশীলতাকে সীমাবদ্ধ না করে।

এই অনুশীলনীটি টেক্সট ডেটা নিয়ে কাজ করে।
ঐতিহাসিক কারণে Haskell-এর `String` টাইপটি `[Char]`-এর সমার্থক, যা ক্যারেক্টারের একটি অ্যারে।
টেক্সট ডেটা আরও দক্ষভাবে সামলাতে চাইলে `Text` টাইপটি ব্যবহার করা যেতে পারে।

এই অনুশীলনীর ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি করতে পারেন

- package.yaml-এ আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করা।
- [নিচের পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) `Data.Text` ইমপোর্ট করা:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` টাইপ ব্যবহার করা, যেমন `decode :: Text -> Text`, এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.pack` নামে উল্লেখ করা।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখে নেওয়া।
- Affine.hs-এ `String`-এর সব ব্যবহার `Text` দিয়ে প্রতিস্থাপন করা, অর্থাৎ:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
