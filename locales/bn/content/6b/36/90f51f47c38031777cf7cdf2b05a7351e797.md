# সম্পর্কে

F#-এ বুলিয়ানকে `bool` টাইপ দিয়ে প্রকাশ করা হয়, যার মান `true` অথবা `false` হতে পারে।

F# তিনটি [বুলিয়ান অপারেটর][operators] সমর্থন করে: `not` (NOT), `&&` (AND), এবং `||` (OR)। `&&` ও `||` অপারেটর _শর্ট-সার্কিট ইভালুয়েশন_ ব্যবহার করে, অর্থাৎ অপারেটরের ডান দিকটি কেবল প্রয়োজন হলেই মূল্যায়ন করা হয়।

```fsharp
true || false // => true
true && false // => false
```

তিনটি বুলিয়ান অপারেটরের প্রতিটির [_অপারেটর প্রিসিডেন্স_][precedence] আলাদা। ফলে এগুলো এই ক্রমে মূল্যায়ন করা হয়: প্রথমে `not`, তারপর `&&`, এবং সবশেষে `||`। আপনি যদি এই নিয়মগুলো থেকে 'বেরিয়ে আসতে' চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন প্রথম বন্ধনীর (`()`) ভেতরে রাখতে পারেন, কারণ বন্ধনীর অপারেটর প্রিসিডেন্স আরও বেশি।

```fsharp
not true && false   // => false
not (true && false) // => true
```
