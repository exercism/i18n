# নির্দেশনা

আপনার দল একটি আবহাওয়াবিদ্যা-সংক্রান্ত অ্যাপ্লিকেশনে কাজ করছে।
তারা আবহাওয়ার ডেটা নির্দেশ করে এমন নানা টাইপ ও কনস্ট্যান্ট নিয়ে একটি API সংজ্ঞায়িত করেছে; দেখুন `meteorology.go` ফাইলটি।

আপনার কাজ হলো সব টাইপে উপযুক্ত `String` মেথড যোগ করা, যাতে সেগুলো `Stringer` ইন্টারফেসটি ইমপ্লিমেন্ট করে।

## 1. `TemperatureUnit` টাইপের জন্য `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করুন

কিছুটা আলোচনার পর দলটি একমত হয়েছে যে তাপমাত্রার একক হবে `Celsius` অথবা `Fahrenheit`।
মানগুলো নিচের উদাহরণে দেখানো মতো ফরম্যাট করা উচিত।

`TemperatureUnit` টাইপে একটি `String` মেথড যোগ করে সেটিকে `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করান।
তাপমাত্রার একক Celsius হলে এই মেথডটি অবশ্যই `"°C"` স্ট্রিংটি রিটার্ন করবে, আর তাপমাত্রার একক Fahrenheit হলে `"°F"`।

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. `Temperature` টাইপের জন্য `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করুন

তাপমাত্রার মান একটি ইন্টিজার ও একটি তাপমাত্রা একক নিয়ে গঠিত।
এগুলো নিচের উদাহরণের মতো ফরম্যাট করা উচিত।

এটির জন্য `Temperature` টাইপে একটি `String` মেথড যোগ করে সেটিকে `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করান।
এই মেথডটি এমন একটি স্ট্রিং রিটার্ন করবে যেখানে তাপমাত্রার সাংখ্যিক মান ও তাপমাত্রার একক একটি স্পেস দিয়ে আলাদা করা থাকবে: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. `SpeedUnit` টাইপের জন্য `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করুন

দীর্ঘ আলোচনার পর দলটি একমত হয়েছে যে বাতাসের গতির একক হবে `KmPerHour` অথবা `MilesPerHour`।
মানগুলো নিচের উদাহরণের মতো ফরম্যাট করা উচিত।

এটির জন্য `SpeedUnit` টাইপে একটি `String` মেথড যোগ করে সেটিকে `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করান।
গতির একক kilometers per hour হলে এই মেথডটি অবশ্যই `"km/h"` স্ট্রিংটি রিটার্ন করবে, আর গতির একক miles per hour হলে `"mph"`:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. `Speed`-এর জন্য `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করুন

বাতাসের গতির মান একটি ইন্টিজার ও একটি গতির একক নিয়ে গঠিত।
এগুলো নিচের উদাহরণের মতো ফরম্যাট করা উচিত।

এটির জন্য `Speed` টাইপে একটি `String` মেথড যোগ করে সেটিকে `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করান।
এই মেথডটি এমন একটি স্ট্রিং রিটার্ন করবে যেখানে গতির সাংখ্যিক মান ও গতির একক একটি স্পেস দিয়ে আলাদা করা থাকবে: `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. `MeteorologyData` টাইপের জন্য `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করুন

আবহাওয়ার ডেটায় অবস্থান, তাপমাত্রা, বাতাসের দিক, বাতাসের গতি ও আর্দ্রতা নির্দিষ্ট করা থাকে।
এটি নিচের উদাহরণের মতো ফরম্যাট করা উচিত:

এটির জন্য `MeteorologyData` টাইপে একটি `String` মেথড যোগ করে সেটিকে `Stringer` ইন্টারফেস ইমপ্লিমেন্ট করান।
এই মেথডটি নিচের ফরম্যাটে আবহাওয়ার ডেটা রিটার্ন করবে:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
