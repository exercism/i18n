# পরিচিতি

Unison ট্রু ও ফলস মান প্রকাশ করে `Boolean` টাইপ দিয়ে। এখানে মাত্র দুটি মান আছে: `true` এবং `false`.

```unison
trueVariable = true
falseVariable = false
```

আমরা and, or আর not অপারেটর দিয়ে বুলিয়ান এক্সপ্রেশন মূল্যায়ন করতে পারি। and লেখা হয় `&&` দিয়ে, or লেখা হয় `||` দিয়ে, আর not লেখা হয় `not` দিয়ে।

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
