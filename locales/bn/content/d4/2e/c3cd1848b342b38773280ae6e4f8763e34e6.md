# নির্দেশনা

*ChronoRealms*-এর জগতে স্বাগতম, এক জাদুকরী ভূমি যেখানে শক্তিশালী Timekeepers সময়ের প্রবাহ নিয়ন্ত্রণ করেন।

এই ভূমিতে Timekeepers "TimeShards" পরিচালনা করেন, বিশেষ একক যা যোগ করা, বিয়োগ করা, তুলনা করা এবং এমনকি সমতা যাচাই করা যায়।

এই TimeShards পরিচালনার জন্য কাস্টম অপারেটর ইমপ্লিমেন্ট করে Timekeepers-কে সাহায্য করাই আপনার কাজ।

Timekeepers চান আপনি এমন একটি কাস্টম স্ট্রাক্ট `TimeShard` তৈরি করুন, যা নিচের অপারেশনগুলো সমর্থন করে:

1. **TimeShards যোগ ও বিয়োগ করা**: টাইমলাইন নিয়ন্ত্রণ করার জন্য Timekeepers-এর TimeShards যোগ ও বিয়োগ করার ক্ষমতা দরকার।
2. **TimeShards তুলনা করা**: কখনও কখনও কোনটি বড়, বা তারা সমান কি না, তা দেখার জন্য TimeShards তুলনা করা দরকার।
3. **সমতা যাচাই করা**: দুটি TimeShards মানে অভিন্ন কি না, তা Timekeepers-কে যাচাই করতে হয়।

আপনার লক্ষ্য হলো `TimeShard` স্ট্রাক্টের জন্য নিচের ট্রেইটগুলো ইমপ্লিমেন্ট করা:

1. **যোগ (`Add`)**: দুটি `TimeShard` ইনস্ট্যান্স একসাথে যোগ করা সম্ভব করে তোলে।
2. **বিয়োগ (`Sub`)**: একটি `TimeShard` থেকে আরেকটি বিয়োগ করা সম্ভব করে তোলে।
3. **সমতা (`PartialEq`)**: দুটি `TimeShard` ইনস্ট্যান্স একই কি না, তা Timekeepers-কে যাচাই করার সুযোগ দেয়।
4. **তুলনা (`PartialOrd`)**: কোনটি বড় বা ছোট, তা দেখতে দুটি `TimeShard` ইনস্ট্যান্সের তুলনা করার সুযোগ দেয়।

একটি `TimeShard` এমন একটি স্ট্রাক্ট দিয়ে প্রকাশ করা হবে, যেটি একটি ইন্টিজার মান (`i32`) ধরে রাখে।

Timekeepers-এর কাজ সহজ করতে প্রয়োজনীয় ট্রেইটগুলো ইমপ্লিমেন্ট করুন।

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
