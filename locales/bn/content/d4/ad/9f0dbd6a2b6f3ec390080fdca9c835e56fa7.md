# হিন্ট

## সাধারণ

- `<min-heap>`, `heap-push`, `heap-peek` আর `heap-pop-all` সবই আছে [`heaps`][heaps]-এ; আর `values` আছে [`assocs`][assocs]-এ।
- একটি হিপ প্রতিটি আইটেমকে একটি *মান* আর একটি *কী (key)* হিসেবে সংরক্ষণ করে; এই কী (key)-ই হলো অগ্রাধিকার। `heap-push` এগুলো নেয় এভাবে: `( value key heap -- )`।

## 1. কিউ খুলুন

- `<min-heap>` একটি খালি মিন-হিপ তৈরি করে, অর্থাৎ সবচেয়ে ছোট কী (key)-টি সবার আগে সেবা পায়।

## 2. একজন গ্রাহক যোগ করুন

- গ্রাহকের নামটিই মান, আর অগ্রাধিকারটিই কী (key); `heap-push` ঠিক এই ক্রমেই এগুলো চায়।
- `heap-push` কিউটি খেয়ে ফেলে। গ্রাহক যোগ করার পরও কিউটি ফেরত পেতে `[ heap-push ] keep` ব্যবহার করুন।

## 3. পরের জন কে?

- `heap-peek` সামনের আইটেমের জন্য `value key` রিটার্ন করে, কিন্তু সেটি সরায় না। আপনার দরকার শুধু নাম, তাই কী (key)-টি `drop` করে দিন।

## 4. সবাইকে সেবা দিন

- `heap-pop-all` হিপটি খালি করে `{ key value }` জোড়ার একটি অ্যাসোসিয়েশন লিস্ট বানায়, যা আগেই অগ্রাধিকার অনুসারে সাজানো থাকে।
- `values` শুধু মানগুলোই রাখে, অর্থাৎ নামগুলো।
