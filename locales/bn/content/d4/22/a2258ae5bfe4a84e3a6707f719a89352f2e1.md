# নির্দেশনা সংযোজন

## ইঙ্গিত

একটি [ডাবলি লিংকড লিস্ট](https://en.wikipedia.org/wiki/Doubly_linked_list) হলো একটি মিউটেবল ডেটা স্ট্রাকচার। যেহেতু F# একটি ফাংশনাল-ফার্স্ট ভাষা, তাই সাধারণভাবে ইমিউটেবিলিটিকেই প্রাধান্য দেওয়া হয়, তবে ভাষায় এমন কিছু ফিচার আছে যেগুলো প্রয়োজনে মিউটেশন ব্যবহার করতে দেয়।

- `let` বাইন্ডিং এবং [রেকর্ড](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records) ফিল্ডের আগে `mutable` কিওয়ার্ডটি বসানো যায়, যার ফলে এগুলোতে নতুন মান অ্যাসাইন করা যায়।

- `set` কিওয়ার্ড দিয়ে একটি প্রপার্টি সেটার উল্লেখ করে [ক্লাস](https://fsharpforfunandprofit.com/posts/classes)-এর প্রপার্টি মিউটেবল করা যায়।

মিউটেবল বাইন্ডিং `<-` দিয়ে আবার অ্যাসাইন করতে হয়

```fsharp
let mutable x = "initial value"
x <- "new value"
```
