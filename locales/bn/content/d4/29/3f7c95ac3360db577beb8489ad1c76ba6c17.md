# নির্দেশনা

আপনি একটি ছোট Reverse Polish Notation (RPN) ক্যালকুলেটর বানাচ্ছেন।
ক্যালকুলেটরের স্টেট হলো একটি *ভ্যালুর স্ট্যাক*, যা একটি Factor অ্যারে
দিয়ে প্রকাশ করা হয়, আর একটি *অপারেশন* হলো এমন একটি কোয়োটেশন, যা এমন
একটি স্ট্যাক নিয়ে নতুন একটি স্ট্যাক রিটার্ন করে।

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. যোগ ইমপ্লিমেন্ট করুন

`add-op` ডিফাইন করুন, যা স্ট্যাক থেকে উপরের দুটি মান পপ করবে, তাদের
যোগফল পুশ করবে এবং নতুন স্ট্যাকটি রিটার্ন করবে।

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. গুণ ইমপ্লিমেন্ট করুন

একইভাবে `multiply-op` ডিফাইন করুন, তবে গুণের জন্য।

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. একটি একক অপারেশন প্রয়োগ করুন

`apply-op` ডিফাইন করুন, যা ডেটা স্ট্যাক থেকে একটি স্ট্যাক ও একটি
অপারেশন (একটি কোয়োটেশন) নেবে এবং নতুন ক্যালকুলেটর স্ট্যাকটি রিটার্ন
করবে।

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. একটি প্রোগ্রাম ইভ্যালুয়েট করুন

`evaluate` ডিফাইন করুন, যা একটি শুরুর স্ট্যাক ও অপারেশনগুলোর একটি
অ্যারে নেবে এবং পালাক্রমে প্রতিটি অপারেশন প্রয়োগ করে চূড়ান্ত স্ট্যাকটি
রিটার্ন করবে।

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. নাম দিয়ে ইভ্যালুয়েট করুন

এখন প্রোগ্রামটি হলো *অপারেটরের নামের* (স্ট্রিং) একটি তালিকা, আর
ক্যালকুলেটর প্রতিটি নাম একটি assoc-এ খুঁজে দেখে, যা নামগুলোকে
অপারেশনের সাথে ম্যাপ করে।

`evaluate-named` ডিফাইন করুন, যা একটি শুরুর স্ট্যাক, নামযুক্ত
অপারেশনগুলোর একটি assoc এবং নামের একটি অ্যারে নেবে এবং চূড়ান্ত
স্ট্যাকটি রিটার্ন করবে।

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. নিরাপত্তা সহ ভাগ করা

শূন্য দিয়ে ভাগ করতে বলা হলে একটি সত্যিকারের ক্যালকুলেটর চুপচাপ
আবর্জনা তৈরি করতে পারে না। `zero-divisor-error` এরর ক্লাসটি ইতিমধ্যেই
আপনার জন্য ডিফাইন করা আছে। `add-op` ও `multiply-op`-এর অনুরূপভাবে
`divide-op` ইমপ্লিমেন্ট করুন, তবে পার্থক্য হলো স্ট্যাকের উপরে থাকা
ভাজকটি `0` হলে এটি একটি নতুন `zero-divisor-error` `throw` করে।

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
