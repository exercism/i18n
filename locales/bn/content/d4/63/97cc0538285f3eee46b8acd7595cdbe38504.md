# পরিচিতি

## তুলনা অপারেটর

Julia-তে তুলনা অপারেটরগুলো অনেক অন্য ভাষার মতোই, তবে গণিতপ্রেমীদের জন্য কিছু বাড়তি সুবিধাও আছে।

সমতার জন্য অপারেটরগুলো হলো `==` (সমান) এবং `!=` বা `≠` (সমান নয়)।

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

এছাড়া বড়/ছোট বোঝানোর নানা অপারেটরও আছে।

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Julia-এর ক্ষেত্রে প্রায়ই যেমন হয়, একটি উপযুক্ত এডিটর থাকলে গাণিতিক চিহ্ন ব্যবহার করা সহজ হয়ে যায়।
`≠`, `≤` বা `≥` পেতে `\ne`, `\le` বা `\ge` টাইপ করুন, তারপর `TAB` চাপুন।

আগের উদাহরণে শুধু সংখ্যা ব্যবহার করা হয়েছে, তবে পাঠ্যক্রমের অন্য অংশে আমরা দেখব যে আরও কিছু ডেটা টাইপের মধ্যে ক্রমের ধারণা আছে এবং সেগুলো বড়/ছোট হিসেবে পরীক্ষা করা যায়।

তুলনা অপারেটরগুলো চেইন করা যায়, ফলে পরিষ্কার ও সংক্ষিপ্ত সিনট্যাক্স লেখা সম্ভব হয়:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

আগের উদাহরণটি `1 ≤ n && n ≤ 5`-এর সমার্থক।

## `if` দিয়ে শাখাবিভাজন

এটি একটি `if` স্টেটমেন্টের পূর্ণ রূপ:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

প্রথম বন্ধনী `()` বা দ্বিতীয় বন্ধনী `{}`-এর কোনো দরকার নেই, আর ইনডেন্টেশন "শুধু" পড়ার সুবিধার জন্য _(কিন্তু পড়ার সুবিধা খুবই গুরুত্বপূর্ণ!)_।

`elseif` এবং `else` দুটোই ঐচ্ছিক, আর একাধিক `elseif` ব্লক থাকতে পারে।
তবে `end` অবশ্যই লাগবে।

`if` স্টেটমেন্ট নেস্ট করা সম্ভব, তবে বন্ধনী, ইনডেন্ট আর কমেন্ট বুদ্ধি করে ব্যবহার করলে পড়ার সুবিধা বাড়ে।

একটি `if` স্টেটমেন্টের সবচেয়ে ছোট রূপটা হবে এরকম:

```julia
if n < 0
    n = 0
end
```

মনে রাখবেন: শুধু `true` বা `false`-এ মূল্যায়িত হওয়া এক্সপ্রেশনই শর্ত হিসেবে ব্যবহার করা যায়।
Julia ইচ্ছাকৃতভাবে "truthiness"-এর কোনো ধারণা এড়িয়ে চলে, তাই শূন্য মান, খালি স্ট্রিং আর খালি অ্যারে _কখনোই_ `false`-এর সমান নয়।

## টার্নারি অপারেটর

সহজ ও প্রচলিত একটি পরিস্থিতি হলো শর্তের ভিত্তিতে দুটি মানের একটি বাছাই করা।

অনেক ভাষার মতো Julia-তেও একটি টার্নারি অপারেটর আছে, যা দিয়ে এটা আরও সংক্ষিপ্ত করা যায়।

এর সিনট্যাক্স হলো `conditional ? value_if_true : value_if_false`।

তাই আগের উদাহরণটি এভাবে আবার লেখা যেতে পারে:

```julia
n = n < 0 ? 0 : n
```

কম্পাইলার বন্ধনী চায় না, তবে বন্ধনী দিলে পড়ার সুবিধা বাড়তে পারে।
