# ভূমিকা

Cairo-তে অপারেটর ওভারলোডিং দিয়ে আপনি নিজের টাইপ নিয়ে কাজ করার সময় `+`, `-`, `==`, `<` ইত্যাদির মতো স্ট্যান্ডার্ড অপারেটরগুলোর জন্য নিজস্ব আচরণ ডিফাইন করতে পারেন।

এটি করা হয় আপনার কাস্টম টাইপের জন্য নির্দিষ্ট ট্রেইট ইমপ্লিমেন্ট করে।

## অপারেটরগুলোর জন্য মূল ট্রেইট

### `Add` ও `Sub`

`Add` ও `Sub` ট্রেইট আপনার টাইপের সাথে যোগ (`+`) ও বিয়োগ (`-`) কীভাবে কাজ করবে তা ডিফাইন করার সুযোগ দেয়:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`PartialEq` ট্রেইট আপনার টাইপের ইনস্ট্যান্সগুলোর মধ্যে সমতা তুলনা (`==` ও `!=`) করতে দেয়।

এটি প্রায়শই `#[derive(PartialEq)]` দিয়ে স্বয়ংক্রিয়ভাবে ডিরাইভ করা যায়।

### `PartialOrd`

`PartialOrd` ট্রেইট আপনার টাইপের ইনস্ট্যান্সগুলোর মধ্যে তুলনার অপারেশন (`<`, `>`, `<=`, `>=`) চালানোর সুযোগ দেয়।

এতে আপনাকে অন্তত `lt` (less than) মেথডটি ইমপ্লিমেন্ট করতে হয়:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
