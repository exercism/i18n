# পরিচিতি

R-এ `list` হলো উপাদানসমূহের একটি ক্রমবদ্ধ সংগ্রহ, যা কয়েকটি বিষয়ে `vectors` থেকে আলাদা:

- উপাদানগুলো ভিন্ন ভিন্ন টাইপের হতে পারে (যেমন `numeric` আর `character` একসাথে মেশানো)।
- উপাদানগুলো জটিল গঠনও হতে পারে (যেমন ভেক্টর, অন্য লিস্ট ইত্যাদি)।
- এলিমেন্ট অ্যাক্সেস করার সিনট্যাক্স কিছুটা আলাদা।

অন্য ভাষার সাথে এর তুলনা পুরোপুরি মেলে না।
R-এর `list` Python-এর ডিকশনারির সাথে কিছুটা মিলে যায়, তবে `list` ক্রমবদ্ধ এবং সংখ্যা দিয়ে ইনডেক্স করে অ্যাক্সেস করা যায়।
এটির সাথে C-এর `struct`-এরও কিছুটা মিল আছে, তবে `list` রানটাইমে সহজেই সম্প্রসারিত করা যায়।

## লিস্ট তৈরি করা

ভেক্টরের তুলনায় লিস্টে এলিমেন্টগুলোর নাম (যাকে প্রায়ই "ট্যাগ" বলা হয়) দেওয়াই বেশি প্রচলিত:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

তবে ট্যাগ ঐচ্ছিক; ট্যাগ না দিলে R শুধু ইনডেক্স নম্বর ব্যবহার করে:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## লিস্টের এলিমেন্ট অ্যাক্সেস করা

এটি করার তিনটি উপায় আছে, প্রতিটি ভিন্ন প্রেক্ষাপটে কার্যকর।

### ১. `$tag` নোটেশন দিয়ে

ট্যাগের নাম আগে থেকেই জানা থাকলে এটি খুবই প্রচলিত।

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### ২. `[[tag]]` নোটেশন দিয়ে

এর সুবিধা হলো, ট্যাগের নাম রানটাইমে বেছে নেওয়া যায়।
লক্ষ্য করুন, বন্ধনী দুটি দ্বিগুণ।

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### ৩. পজিশন ইনডেক্স দিয়ে

লিস্টে ট্যাগ থাকুক বা না থাকুক, এটি কাজ করে।
এখানেও বন্ধনী দুটি দ্বিগুণ।

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## এলিমেন্ট যোগ ও মুছে ফেলা

সহজ: কোনো এলিমেন্টে অ্যাসাইন করলে সেটি আগে থেকে থাকলে পরিবর্তিত হয়, আর নতুন হলে যোগ হয়।

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

মুছে ফেলতে চাইলে অনাকাঙ্ক্ষিত এলিমেন্টে `NULL` অ্যাসাইন করুন।

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
