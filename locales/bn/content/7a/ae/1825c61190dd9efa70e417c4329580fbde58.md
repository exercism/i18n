# টেস্ট

টেস্ট স্যুট চালানোর জন্য:
```bash
tclsh exercise.test
```

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করার অর্থ হলো তার সব টেস্ট পাস করানো। ডিফল্টভাবে, আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) চালানো হয়। এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন। সেটি পাস হয়ে গেলে, তার আগে থাকা `skip` কমান্ডটি কমেন্ট করে বা মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন।

বিকল্পভাবে, টেস্টগুলোর "স্কিপ" অবস্থা যা-ই হোক, সব টেস্ট চালাতে:
```bash
RUN_ALL=1 tclsh exercise.test
```
