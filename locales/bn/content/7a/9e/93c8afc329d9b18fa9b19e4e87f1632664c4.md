# বাইনারি, অক্টাল ও হেক্সাডেসিমাল

বাইনারি, অক্টাল ও হেক্সাডেসিমাল (_হেক্স নামেও পরিচিত_) বিভিন্ন ভিত্তির [সংখ্যা পদ্ধতি][numeral-systems]। বাইনারির ভিত্তি 2, অক্টালের ভিত্তি 8, আর হেক্সাডেসিমালের ভিত্তি 16। Crystal-এ সাধারণ ইন্টিজারগুলোর ভিত্তি 10। বাইনারি, অক্টাল ও হেক্সাডেসিমাল সবই ইন্টিজারের উপস্থাপন। এর মানে হলো, এগুলো ভগ্নাংশ বা দশমিক ছাড়াই ধনাত্মক ও ঋণাত্মক সংখ্যা (_শূন্যসহ_) উপস্থাপন করে এবং ইন্টিজার নিয়ে আমরা যে সব অপারেশন করতে পারি, সেগুলোও সমর্থন করে।

## বাইনারি

[বাইনারি][binary] হলো ভিত্তি 2-এর একটি সংখ্যা পদ্ধতি, যেখানে কেবল 0 ও 1 অঙ্ক ব্যবহার করা হয়। কম্পিউটারের ট্রানজিস্টর ও সুইচের মধ্য দিয়ে বিদ্যুৎ প্রবাহের 0 ("বন্ধ") ও 1 ("চালু") অবস্থা, সেই সাথে চৌম্বকীয় স্টোরেজ মাধ্যমের ধনাত্মক ও ঋণাত্মক চার্জ বোঝাতে সাধারণত এটি ব্যবহৃত হয়। বাইনারি দিয়ে ভিত্তি 10-এ ব্যবহৃত সব ইন্টিজার উপস্থাপন করা যায়।

ভিত্তি 2-এর পদ্ধতির একটি অংশ দেখতে এমন, যদিও এটি অসীমভাবে চলতে থাকে এবং 128-এ থেমে যায় না:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

তাহলে আমরা যদি 6 সংখ্যাটি উপস্থাপন করতে চাই, বাইনারিতে তা হবে: 110

| স্থানীয় মান    | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| বাইনারি সংখ্যা | 1   | 1   | 0   |

আর অপারেশনটি হবে: `4 + 2 + 0 = 6`

আরেকটি উদাহরণ: 19

| স্থানীয় মান    | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| বাইনারি সংখ্যা | 1   | 0   | 0   | 1   | 1   |

বাইনারি সংখ্যাটি হবে: 10011
আর অপারেশনটি হবে: `16 + 0 + 0 + 2 + 1 = 19`

## Crystal-এ বাইনারি

Crystal-এ `0b` প্রিফিক্স ব্যবহার করে বাইনারি লিটারাল লেখা যায়। আমরা যদি `0b10011` লিখি, Crystal এটিকে একটি বাইনারি সংখ্যা হিসেবে বুঝে ভিত্তি 10-এ রূপান্তর করবে।

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

আপনি যদি `0b` প্রিফিক্স দিয়ে এমন একটি সংখ্যা লেখেন যা বাইনারি পদ্ধতির নয়, তাহলে কম্পাইলেশন এরর হবে।

```crystal
0b10211
# => Error: unexpected token: "211"
```

### বাইনারি সংখ্যা দিয়ে অপারেশন

যেহেতু বাইনারি সংখ্যাগুলো ইন্টিজার, তাই ইন্টিজার নিয়ে আমরা যে সব অপারেশন করতে পারি, সেগুলো এগুলো নিয়েও করতে পারি।

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### বাইনারি উপস্থাপনে ও তা থেকে রূপান্তর

Crystal স্বয়ংক্রিয়ভাবে একটি বাইনারি লিটারালকে `Int32`-এ রূপান্তর করে। কোনো `Int32`-কে বাইনারি উপস্থাপনে রূপান্তর করতে [`<int>.to_s(base)`][to_s] মেথডটি ব্যবহার করুন, যেখানে base আর্গুমেন্ট 2 সেট করা থাকবে। মেথডটি বাইনারি সংখ্যাটির একটি স্ট্রিং আকারের উপস্থাপন রিটার্ন করবে:

```crystal
19.to_s(2)
# => "10011"
```

একটি বাইনারির স্ট্রিং আকারের উপস্থাপনাকে ইন্টিজারে রূপান্তর করতে আমরা [`<int>.to_i(base)`][to_i] মেথডটি ব্যবহার করতে পারি, যেখানে আর্গুমেন্ট হিসেবে ভিত্তি (2) পাঠানো হয়:

```crystal
"10011".to_i(2)
# => 19
```

ভুল ভিত্তি (_বা একটি অবৈধ বাইনারি উপস্থাপন_) দিলে `ArgumentError` হবে:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### বাইনারি মেথড

সংখ্যাটির বাইনারি উপস্থাপন সম্পর্কে তথ্য পেতে ইন্টিজারের উপর কিছু মেথড ব্যবহার করা যায়।

[`<int>.bit_length`][bit_length] সংখ্যাটি উপস্থাপন করতে কতগুলো বিট লাগবে তা রিটার্ন করবে:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] ডান দিক থেকে শুরু করে (_সবচেয়ে কম গুরুত্বপূর্ণ বিট_) প্রদত্ত ইনডেক্সের বিটটি রিটার্ন করবে:

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## অক্টাল

[অক্টাল][octal] ভিত্তি 8-এর একটি সংখ্যা পদ্ধতি। এটি 0, 1, 2, 3, 4, 5, 6 ও 7 অঙ্ক ব্যবহার করে।

Crystal-এ `0o` প্রিফিক্স ব্যবহার করে অক্টাল সংখ্যা লেখা যায়। বাইনারির মতোই, Crystal স্বয়ংক্রিয়ভাবে একটি অক্টাল উপস্থাপনকে `Int32`-এ রূপান্তর করে।

```crystal
0o123
# => 83
```

কোনো সংখ্যার আগে `0o` বসিয়ে দিলে, যদি সেটি অক্টাল পদ্ধতির না হয়, তাহলে কম্পাইলেশন এরর হবে।

### অক্টাল উপস্থাপনে ও তা থেকে রূপান্তর 

বাইনারির মতোই, কোনো `Int32`-কে অক্টাল উপস্থাপনে রূপান্তর করতে আমরা [`<int>.to_s(base)`][to_s] মেথডটি ব্যবহার করতে পারি। আর একটি অক্টাল উপস্থাপনকে `Int32`-এ রূপান্তর করতে [`<int>.to_i(base)`][to_s] মেথডটি ব্যবহার করতে পারি।

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

বাইনারির মতোই, ভুল ভিত্তি দিলে `ArgumentError` হবে।

## হেক্সাডেসিমাল

[হেক্সাডেসিমাল][hexadecimal] ভিত্তি 16-এর একটি সংখ্যা পদ্ধতি। এটি 0 - 9 অঙ্ক এবং A, B, C, D, E ও F অক্ষর ব্যবহার করে। A মানে 10, B মানে 11, C মানে 12, D মানে 13, E মানে 14, আর F মানে 15।

Crystal-এ `0x` প্রিফিক্স ব্যবহার করে হেক্সাডেসিমাল সংখ্যা লেখা যায়। বাইনারি ও অক্টালের মতোই, Crystal স্বয়ংক্রিয়ভাবে হেক্সাডেসিমাল লিটারালকে `Int32`-এ রূপান্তর করবে।

```crystal
#=> 0x123
291
```
 
কোনো নন-হেক্সাডেসিমাল সংখ্যার আগে `0x` বসালে কম্পাইলেশন এরর হবে।

### হেক্সাডেসিমাল উপস্থাপনে ও তা থেকে রূপান্তর

বাইনারির মতোই, কোনো `Int32`-কে হেক্সাডেসিমাল উপস্থাপনে রূপান্তর করতে আমরা [`<int>.to_s(base)`][to_i] মেথডটি ব্যবহার করতে পারি। আর একটি হেক্সাডেসিমাল উপস্থাপনকে `Int32`-এ রূপান্তর করতে [`<int>.to_i(base)`][to_s] মেথডটি ব্যবহার করতে পারি।

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

বাইনারি ও অক্টালের মতোই, ভুল ভিত্তি দিলে `ArgumentError` হবে।

## প্রিসিশন

কোনো সংখ্যাকে স্ট্রিং আকারের উপস্থাপনে রূপান্তর করার সময় আমরা সংখ্যাটির প্রিসিশন নির্দিষ্ট করতে পারি। অর্থাৎ সংখ্যাটি উপস্থাপন করতে **সর্বনিম্ন** কতটি অঙ্ক ব্যবহার করা হবে তা। সংখ্যাটির অঙ্ক প্রিসিশনের চেয়ে কম হলে স্ট্রিং উপস্থাপনায় সামনে শূন্য যোগ করা হয়। এটি করা হয় [`<int>.to_s(<base>, precision: <value>)`][to_s] মেথডে `precision` আর্গুমেন্ট পাঠিয়ে।

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## আপকেস

কোনো সংখ্যাকে স্ট্রিং আকারের উপস্থাপনে রূপান্তর করার সময় স্ট্রিংয়ের অক্ষরগুলো বড় হাতের করতে চাই কি না তা নির্দিষ্ট করতে পারি। এটি করা হয় [`<int>.to_s(<base>, upcase: <value>)`][to_s] মেথডে `upcase` আর্গুমেন্ট পাঠিয়ে।

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
