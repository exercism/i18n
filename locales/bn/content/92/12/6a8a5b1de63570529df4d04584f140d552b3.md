# নির্দেশনার সংযোজন

## স্টাব

`src/TreeBuilding.hs`-এ ইতিমধ্যে একটি সমাধান আছে যা কাজ করে এবং সব টেস্ট পাস করে।
এটি ধীরগতির এবং পড়তে কঠিন; আপনার কাজ হলো টেস্ট না ভেঙে এটিকে আরও ভালো করা।

যখন রেকর্ডগুলো কোনো বৈধ ট্রি গঠন করে না, তখন `buildTree` `Nothing` রিটার্ন করে।

## রিপ্রেজেন্টেশন পরিবর্তন

টেস্টগুলো কখনোই সরাসরি `Tree`-এর কনস্ট্রাক্টর ব্যবহার করে না।
এর বদলে তারা ফাংশনটি দিয়ে প্রত্যাশিত ট্রি তৈরি করে

```haskell
node :: Int -> [Tree] -> Tree
```

যেখানে `node i children` হলো `i` আইডি ও প্রদত্ত চিলড্রেনবিশিষ্ট নোড, আইডির ঊর্ধ্বক্রমে।

এর মানে হলো, `Tree` কীভাবে রিপ্রেজেন্ট করা হয় তা আপনি নির্দ্বিধায় বদলাতে পারেন, উদাহরণস্বরূপ

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

যতক্ষণ `Tree`-এর এখনও `Eq` ও `Show` ইনস্ট্যান্স থাকে এবং `node` তার অর্থ ধরে রাখে।
যদি `containers`-এর মতো কোনো লাইব্রেরি ব্যবহার করেন, তাহলে `package.yaml`-এর `dependencies`-এ এটি যোগ করতে মনে রাখবেন।
