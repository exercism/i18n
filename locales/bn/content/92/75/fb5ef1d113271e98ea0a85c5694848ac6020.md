# টেস্ট

টেস্ট চালানোর জন্য অনুশীলনী ডিরেক্টরির ভেতরে থেকে `v test .` কমান্ডটি চালান।

যেসব টেস্ট চালানো হয়েছে, সেগুলো সব এবং গতির পরিসংখ্যান যদি দেখতে চান, তাহলে `v -stats test .` ব্যবহার করুন।

V-তে টেস্টিং সম্পর্কে আরও তথ্যের জন্য [ডকুমেন্টেশনটি](https://github.com/vlang/v/blob/master/doc/docs.md#testing) দেখুন।
