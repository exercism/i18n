# নির্দেশনা

আপনি আবারও ORM (Object Relationship Mapping) সিস্টেম নিয়ে কাজ করছেন, যেটি [exercise:csharp/object-relational-mapping]() অনুশীলনীতে পরিচয় করিয়ে দেওয়া হয়েছিল।

আমাদের ORM ব্যবহারের বিশ্লেষণে দেখা গেছে, ৯৫% ট্রানজেকশন একটি মাত্র কলিং মেথডের ভেতর থেকেই চালানো হয়। তাই সিদ্ধান্ত হয়েছে, একটি একক ORM মেথড থাকাই বেশি যুক্তিযুক্ত, যা একটি ট্রানজেকশন খুলবে, লিখবে এবং কমিট করবে।

ডেটাবেসে নিচের ইনস্ট্যান্স মেথডগুলো আছে:

- `Database.BeginTransaction()` ডেটাবেসে একটি ট্রানজেকশন শুরু করে।
- `Database.Write(string data)` ট্রানজেকশনের ভেতরে ডেটাবেসে ডেটা লেখে। খারাপ ডেটা পেলে একটি এক্সেপশন ছুড়ে দেওয়া হবে। আগে `BeginTransaction()` কল না করে এই মেথড কল করার চেষ্টা করলে একটি এক্সেপশন ছুড়ে দেওয়া হবে। সফল হলে ডেটাবেসের অভ্যন্তরীণ স্টেট `DataWritten`-এ বদলে যাবে।
- `Database.EndTransaction()` ডেটাবেসে ট্রানজেকশনটি কমিট করে। ট্রানজেকশন বন্ধ করতে না পারলে বা `Database.BeginTransaction()` কল করা না থাকলে এটি একটি এক্সেপশন ছুড়তে পারে।
- ট্রানজেকশনের মাঝে কোনো এক্সেপশন ছুড়ে দেওয়া হলে `Database.Dispose()` কল করলে ডেটাবেস পরিষ্কার করা হবে। এতে ডেটাবেসের স্টেট `Closed`-এ বদলে যাবে।

## 1. ডেটাবেসে লিখুন

ডেটাবেস ট্রানজেকশন শুরু করতে, পাঠানো ডেটা লিখতে এবং ট্রানজেকশন কমিট করতে `Orm.Write()` মেথডটি ইমপ্লিমেন্ট করুন। `InvalidOperationException`-সহ সব এক্সেপশনই কোনো লগিং বা অন্য কোনো হস্তক্ষেপ ছাড়া কলারের কাছে চলে যেতে দেওয়া উচিত।

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. ডেটাবেসে লিখুন এবং কলারকে জানান লেখাটি সফল হয়েছিল কি না

`Orm.Write()` চালু হওয়ার পর কয়েক মাস কেটে গেছে, আর দলটির মধ্যে মতভেদ দেখা দিয়েছে। অনেক ডেভেলপার চান _ORM_ নিজেই এক্সেপশন ছুড়ে দেওয়া হলে এররগুলো সামলাক এবং কলারকে কেবল সাফল্যের একটি ইঙ্গিত ফিরিয়ে দিক।

অনুগ্রহ করে `Orm.WriteSafely()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি ডেটাবেস ট্রানজেকশন শুরু করবে, পাঠানো ডেটা লিখবে এবং ট্রানজেকশন কমিট করবে (উপরের মতোই)। _লেখাটি_ সফল হলে এটি `true` রিটার্ন করবে, নাহলে `false`। এক্সেপশনটি লগ করার চেষ্টা করবেন না।

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
