# নির্দেশনা

শহরে নতুন একটি কবিতা ক্লাব খুলেছে, আর আপনি সেখানে যাওয়ার কথা ভাবছেন।
আগে বেশ কিছু ঘটনা ঘটেছে, তাই ক্লাবে ঢোকার চেষ্টা করার আগে দরজার একটি খুব নির্দিষ্ট নিয়ম আপনাকে ভালোভাবে শিখে নিতে হবে।

কবিতা ক্লাবে দুটি দরজা আছে, দুটোতেই পাহারাদার রয়েছে।
ভিতরে ঢুকতে হলে সেদিনের পাসওয়ার্ড আপনাকে বের করতে হবে:

## 1. একটি স্ট্রিংকে আলাদা আলাদা লাইনে ভাগ করা

প্রথমে আপনাকে কবিতাটিকে আলাদা আলাদা লাইনে ভাগ করতে হবে।
পাহারাদার একটি কবিতা আবৃত্তি করবেন, আর আপনাকে সেটিকে লাইনে ভাগ করতে হবে।

`splitOnNewlines` ফাংশনটি লিখুন, যা একটি স্ট্রিং নেয় এবং নতুন লাইন অক্ষরকে ডেলিমিটার হিসেবে ব্যবহার করে সেটিকে স্ট্রিংয়ের অ্যারেতে ভাগ করে।
ফাংশনটি স্ট্রিংয়ের একটি অ্যারে রিটার্ন করবে, যেখানে প্রতিটি স্ট্রিং কবিতার একটি লাইন।

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. সামনের দরজা

1. পাহারাদার একটি কবিতা আবৃত্তি করবেন
2. আপনাকে কবিতাটিকে আলাদা আলাদা লাইনে ভাগ করতে হবে।
3. আপনাকে প্রতিটি লাইনের প্রথম অক্ষর নিতে হবে।
   - লাইনটি খালি হলে তার বদলে `_` ব্যবহার করবেন।
4. আপনাকে অক্ষরগুলো একত্র করতে হবে, যা মিলে একটি শব্দ তৈরি করবে।

উদাহরণস্বরূপ, তাঁদের প্রিয় লেখকদের একজন মাইকেল লকউড নিচের _অ্যাক্রোস্টিক_ কবিতাটি লিখেছেন, যার অর্থ হলো প্রতিটি বাক্যের প্রথম অক্ষর মিলে একটি শব্দ তৈরি করে:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

পাহারাদার কবিতাটি আবৃত্তি করলে আপনি সেটিকে আলাদা আলাদা লাইনে ভাগ করবেন এবং প্রতিটি লাইনের প্রথম অক্ষর দিয়ে উত্তর দেবেন, অর্থাৎ `["S", "H", "I", "R", "E"]`।

এরপর পাহারাদার আপনার দেওয়া অক্ষরের অ্যারে থেকে তৈরি শব্দটি দেবেন, যাতে আপনি সেটিকে বড় হাতের অক্ষরের শব্দে রূপান্তর করেন।
সবশেষে আপনি যে পাসওয়ার্ড রিটার্ন করবেন তা হলো `"SHIRE"`, এবং আপনি ভিতরে ঢুকে যাবেন।

`frontDoorPassword` ফাংশনটি লিখুন, যা কবিতাটি বোঝানো একটি স্ট্রিং নেয়।
ফাংশনটি সেই পাসওয়ার্ড রিটার্ন করবে যা আপনি পাহারাদারকে দেবেন।

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. পিছনের দরজা

ক্লাবের পিছনে পাবেন সবচেয়ে নামকরা কবিদের, যা অনেকটা VIP এলাকার মতো।
যেহেতু এটা সবার জন্য নয়, পিছনের দরজার প্রক্রিয়াটি একটু বেশি জটিল।

1. পাহারাদার একটি কবিতা আবৃত্তি করবেন।
2. আপনাকে কবিতাটিকে লাইনে ভাগ করতে হবে।
3. আপনাকে প্রতিটি লাইনের শেষ অক্ষর নিতে হবে।
   - লাইনের শেষে অনেক সময় বাড়তি স্পেস থাকবে, তাই সেগুলো সরিয়ে ফেলতে হবে।
4. আপনাকে অক্ষরগুলো একত্র করতে হবে এবং তারপর অক্ষরগুলো দিয়ে তৈরি শব্দের শেষে `", please"` যোগ করতে হবে।

উদাহরণস্বরূপ, আগে উল্লেখ করা কবিতাটি আবার _টেলেস্টিক_ও, যার অর্থ হলো প্রতিটি বাক্যের শেষ অক্ষর মিলে একটি শব্দ তৈরি করে:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

পাহারাদার কবিতাটি আবৃত্তি করলে আপনি সেটিকে আলাদা আলাদা লাইনে ভাগ করবেন, পেছনের বাড়তি স্পেসগুলো সরিয়ে ফেলবেন এবং প্রতিটি লাইনের প্রথম অক্ষর দিয়ে উত্তর দেবেন, অর্থাৎ `["h", "o", "r", "s", "e"]`।

এরপর পাহারাদার আপনার দেওয়া অক্ষরের অ্যারে থেকে তৈরি শব্দটি দেবেন, যাতে আপনি সেটিকে বড় হাতের অক্ষরের শব্দে রূপান্তর করেন এবং শেষে `", please"` যোগ করেন।
সবশেষে আপনি যে পাসওয়ার্ড রিটার্ন করবেন তা হলো `"horse, please"`, এবং আপনি ভিতরে ঢুকে যাবেন।

`backDoorPassword` ফাংশনটি লিখুন, যা কবিতাটি বোঝানো একটি স্ট্রিং নেয়।
ফাংশনটি সেই পাসওয়ার্ড রিটার্ন করবে যা আপনি পাহারাদারকে দেবেন।

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. গোপন কক্ষ

ক্লাবের পিছনের কক্ষের ভিতরে আরেকটি দরজা আছে, যা নিয়ে যায় গোপন কক্ষে, যেখানে কেবল সবচেয়ে সেরা কবিরাই ঢুকতে পারেন।

1. পাহারাদার একটি কবিতা আবৃত্তি করবেন।
2. আপনাকে কবিতাটিকে লাইনে ভাগ করতে হবে।
3. আপনাকে i<sup>th</sup> লাইনের i<sup>th</sup> অক্ষর নিতে হবে। 
4. আপনাকে অক্ষরগুলো একত্র করতে হবে এবং তারপর অক্ষরগুলো দিয়ে তৈরি শব্দের শেষে `"!"` যোগ করতে হবে।
5. আপনাকে শব্দটিকে বড় হাতের অক্ষরের রূপে বসাতে হবে।

উদাহরণস্বরূপ, আগে উল্লেখ করা কবিতার একটি পরিবর্তিত রূপ এই নিয়মের সাথে মেলে:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

পাহারাদার কবিতাটি আবৃত্তি করলে আপনি সেটিকে আলাদা আলাদা লাইনে ভাগ করবেন, পেছনের বাড়তি স্পেসগুলো সরিয়ে ফেলবেন এবং প্রতিটি লাইনের i<sup>th</sup> অক্ষর দিয়ে উত্তর দেবেন, অর্থাৎ ["S", "u", "p", "e", "r"]।

এরপর পাহারাদার আপনার দেওয়া অক্ষরের অ্যারে থেকে তৈরি শব্দটি দেবেন, যাতে আপনি সেটিকে বড় হাতের অক্ষরের শব্দে রূপান্তর করেন এবং শেষে `"!"` যোগ করেন।
সবশেষে আপনি যে পাসওয়ার্ড রিটার্ন করবেন তা হলো `SUPER!`, এবং আপনি ভিতরে ঢুকে যাবেন।

`secretRoomPassword` ফাংশনটি লিখুন, যা কবিতাটি বোঝানো একটি স্ট্রিং নেয়।
ফাংশনটি সেই পাসওয়ার্ড রিটার্ন করবে যা আপনি পাহারাদারকে দেবেন।

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
