# পরিচিতি

## সেট

একটি [`Set`][set-docs] হলো এমন একটি কলেকশন যার কোনো নির্দিষ্ট ক্রম নেই এবং যা (`List`-এর বিপরীতে) কোনো ডুপ্লিকেট মান ধারণ করে না।

`Set` ইন্টারফেসের জেনেরিক টাইপ প্যারামিটার দিয়ে বোঝানো হয় `Set`-এর ভেতরে থাকা এলিমেন্টগুলোর ডেটা টাইপ কী:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

খেয়াল করুন, `Set.of()` মেথডটি একটি [_অপরিবর্তনীয়_][unmodifiable-set-docs] `Set` ইনস্ট্যান্স তৈরি করে।
এই ইনস্ট্যান্সে `add` ও `remove`-এর মতো মেথড কল করার চেষ্টা করলে রানটাইমে একটি এক্সেপশন হবে।

পরিবর্তনযোগ্য `Set` তৈরি করতে হলে `Set` ইন্টারফেস ইমপ্লিমেন্ট করে এমন একটি ক্লাস ইনস্ট্যান্টিয়েট করতে হবে।
এই ইন্টারফেস ইমপ্লিমেন্ট করা সবচেয়ে বেশি ব্যবহৃত বিল্ট-ইন ক্লাসটি হলো [`HashSet`][hashset-docs] ক্লাস।

```java
Set<Integer> ints = new HashSet<>();
```

`Set` ইন্টারফেসটি [`Collection`][collection-docs] ও [`Iterable`][iterable-docs] ইন্টারফেস থেকে এক্সটেন্ড করা হয়েছে, তাই এটি অন্য ধরনের কলেকশনের সাথে অনেক মেথড শেয়ার করে।
তবে `Collection` ইন্টারফেসের সাথে একটি লক্ষণীয় পার্থক্য হলো, `add` ও `remove`-এর মতো মেথডগুলো `void`-এর বদলে একটি `boolean` রিটার্ন করে, যা জানায় মেথডটি যখন কল করা হয়েছিল তখন ওই আইটেমটি সেটে ছিল কি না:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
