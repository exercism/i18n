# নির্দেশনা

এই অনুশীলনীতে আপনাকে ক্লাসিক গেম Pac-Man-এর কিছু নিয়ম Gleam ফাংশনে অনুবাদ করতে হবে।

আপনার অনুবাদ করার জন্য চারটি নিয়ম আছে, যেগুলো সবই গেমের স্টেটের সাথে সম্পর্কিত।

> আর্গুমেন্টগুলো কীভাবে আসছে তা নিয়ে চিন্তা করবেন না, শুধু কাঙ্ক্ষিত ফলাফল রিটার্ন করার জন্য আর্গুমেন্টগুলো কীভাবে একসাথে জুড়বেন সেদিকে মন দিন।

## 1. Pac-Man একটি ভূত খায় কি না তা ডিফাইন করুন

`eat_ghost` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man ভূত খেতে সক্ষম কি না তা বুলিয়ান মান হিসেবে রিটার্ন করে। ফাংশনটি `True` রিটার্ন করবে কেবল তখনই, যখন Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় থাকে এবং সে একটি ভূত স্পর্শ করছে।

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Pac-Man স্কোর করে কি না তা ডিফাইন করুন

`score` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man একটি পাওয়ার পেলেট স্পর্শ করছে কি না_ এবং _Pac-Man একটি ডট স্পর্শ করছে কি না_) এবং Pac-Man স্কোর করেছে কি না তা বুলিয়ান মান হিসেবে রিটার্ন করে। Pac-Man একটি পাওয়ার পেলেট বা একটি ডট স্পর্শ করলে ফাংশনটি `True` রিটার্ন করবে।

```gleam
score(True, True)
// -> True
```

## 3. Pac-Man হারে কি না তা ডিফাইন করুন

`lose` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man হারে কি না তা বুলিয়ান মান হিসেবে রিটার্ন করে। Pac-Man একটি ভূত স্পর্শ করলে এবং তার কোনো পাওয়ার পেলেট সক্রিয় না থাকলে ফাংশনটি `True` রিটার্ন করবে।

```gleam
lose(False, True)
// -> True
```

## 4. Pac-Man জেতে কি না তা ডিফাইন করুন

`win` ফাংশনটি ডিফাইন করুন, যা তিনটি আর্গুমেন্ট নেয় (_Pac-Man সব ডট খেয়ে ফেলেছে কি না_, _Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_, এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man জিতেছে কি না তা বুলিয়ান মান হিসেবে রিটার্ন করে। Pac-Man সব ডট খেয়ে ফেললে এবং ৩ নম্বর অংশে ডিফাইন করা আর্গুমেন্ট অনুযায়ী না হারলে ফাংশনটি `True` রিটার্ন করবে।

```gleam
win(False, True, False)
// -> False
```
