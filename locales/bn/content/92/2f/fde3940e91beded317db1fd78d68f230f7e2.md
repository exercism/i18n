# নির্দেশনা

আপনি উপকূলীয় রেডিও কক্ষে চ্যানেলের কথাবার্তা মনোযোগ দিয়ে শুনছেন: তারে বার্তা আসে, আপনি সেগুলো লিখে রাখেন, আর উত্তর ফিরিয়ে পাঠান। পাঁচটি ছোট শব্দ এক শিফটের পুরো কাজ সামলে দেয়।

টেস্ট আপনাকে `<string-reader>` ইনপুট (ভেতরে আসা ট্রাফিক) দেয় আর বাইরে পাঠানোর জন্য `<string-writer>` ব্যবহার করে। তবে এখানকার প্রতিটি শব্দই আসল `<file-reader>` বা সকেটের বিপরীতে একইভাবে কাজ করে।

## 1. সবটা শুনে নিন

একটি ইনপুট স্ট্রিম পুরোটা শুষে নিয়ে একটি স্ট্রিংয়ে ভরে ফেলার জন্য `hear-out` ডিফাইন করুন।

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. বার্তা গুনুন

একটি ইনপুট স্ট্রিম থেকে প্রতিটি লাইন পড়ে সেগুলো কতটি ছিল তা রিটার্ন করার জন্য `count-messages` ডিফাইন করুন।

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. শেষ কলটি ফিরিয়ে দিন

প্রতিটি লাইন পড়ে **শেষটি বড় হাতের অক্ষরে** রিটার্ন করার জন্য `echo-back` ডিফাইন করুন। এটাই রেডিওর চিরাচরিত "আপনি বলেছিলেন X" ধরনের উত্তর।

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. একটি বার্তা ব্রডকাস্ট করুন

একটি রাইটারে একটি বার্তা লিখে স্ট্রিম ফ্লাশ করার জন্য `broadcast` ডিফাইন করুন, যাতে সেটি সঙ্গে সঙ্গে বাইরে চলে যায়। কিছুই রিটার্ন করে না।

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. একটি কোশনের আউটপুট ক্যাপচার করুন

একটি কোশনকে নতুন একটি স্ট্রিং-রাইটার অ্যাম্বিয়েন্ট আউটপুট বানিয়ে রান করার জন্য `capture` ডিফাইন করুন, আর কোশনটি যা কিছু প্রিন্ট করেছে সেটিই রিটার্ন করুন। কোশনটি কোনো আর্গুমেন্ট নেয় না, সে বরাবরের মতোই অ্যাম্বিয়েন্ট স্ট্রিমে লিখে।

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
