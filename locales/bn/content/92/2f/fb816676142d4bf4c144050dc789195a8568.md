# বুলিয়ান টাইপ

Cairo-তে লজিক্যাল অপারেশন ও শর্তভিত্তিক স্টেটমেন্টের জন্য বুলিয়ান টাইপ অপরিহার্য।
Cairo-তে বুলিয়ানের আকার এক `felt252`, যা ট্রু/ফলস লজিকের সরলতা বজায় রেখেই জায়গার দক্ষ ব্যবহার নিশ্চিত করে।

Cairo-তে বুলিয়ান টাইপ নির্দিষ্ট করা হয় `bool` কিওয়ার্ড দিয়ে।
এর ফলে ভাষাটিতে বুলিয়ান ভ্যারিয়েবল ডিক্লেয়ার ও ম্যানিপুলেট করা যায়।
উদাহরণ হিসেবে নিচের কোডটি দেখুন:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

এই উদাহরণে দুটি বুলিয়ান ভ্যারিয়েবল ডিক্লেয়ার করা হয়েছে।
`t` ভ্যারিয়েবলে `true` মানটি অ্যাসাইন করা হয়েছে এবং এটিকে অন্তর্নিহিতভাবে বুলিয়ান টাইপ হিসেবে ডিক্লেয়ার করা হয়েছে, অন্যদিকে `f` ভ্যারিয়েবলে স্পষ্টভাবে `bool` টাইপ অ্যানোটেশন দেওয়া হয়েছে এবং `false` মানটি অ্যাসাইন করা হয়েছে।

একটি গুরুত্বপূর্ণ বিষয় খেয়াল রাখা দরকার, Cairo-তে কোনো বুলিয়ান ভ্যারিয়েবল ডিক্লেয়ার করার সময় মান হিসেবে `true` বা `false` লিটারাল ব্যবহার করা বাধ্যতামূলক।
এর মানে হলো `0` বা `1`-এর মতো ইন্টিজার লিটারাল `false` বা `true`-এর বিকল্প হিসেবে ব্যবহার করা যায় না।
এই নিয়মটি কঠোরভাবে প্রয়োগ করা টাইপ সেফটি নিশ্চিত করে এবং স্মার্ট কন্ট্র্যাক্ট ডেভেলপমেন্টে সম্ভাব্য লজিক্যাল এরর প্রতিরোধ করে।

## Cairo-তে বুলিয়ান অপারেটর

- `||` (লজিক্যাল OR): অপারেন্ডগুলোর অন্তত একটি `true` হলে `true` রিটার্ন করে।
- `&&` (লজিক্যাল AND): উভয় অপারেন্ড `true` হলে `true` রিটার্ন করে।
- `!` (লজিক্যাল NOT): অপারেন্ডের বিপরীত বুলিয়ান মান রিটার্ন করে।

## উদাহরণ কোড

নিচের কোড স্নিপেটে দেখানো হয়েছে কীভাবে Cairo-তে বুলিয়ান টাইপ ব্যবহার করতে হয়।
এতে বুলিয়ান ভ্যারিয়েবলের ডিক্লারেশন, বুলিয়ান এক্সপ্রেশনের অ্যাসাইনমেন্ট এবং বুলিয়ান লজিকের সঠিকতা যাচাইয়ের জন্য অ্যাসারশনের ব্যবহার দেখানো হয়েছে:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
