# নির্দেশাবলি

এই অনুশীলনীতে আপনি Cairo-এর কন্ট্রোল ফ্লো কনস্ট্রাক্ট ব্যবহার করে একটি ছোট বেকারির দৈনন্দিন কাজ পরিচালনায় সাহায্য করবেন।

## 1. অর্ডারের মোট হিসাব করুন

`calculate_total` ইমপ্লিমেন্ট করুন, যা পেস্ট্রির ধরন ও পরিমাণের ভিত্তিতে একটি অর্ডারের খরচ হিসাব করে:

- ক্রোয়াসাঁ: প্রতিটি ৩ কয়েন
- মাফিন: প্রতিটি ২ কয়েন
- কুকি: প্রতিটি ১ কয়েন

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. ভলিউম ডিসকাউন্ট প্রয়োগ করুন

`apply_discount` ইমপ্লিমেন্ট করুন, যা অর্ডারের মোটের ভিত্তিতে ডিসকাউন্ট প্রয়োগ করে।
মোটের উপর শতকরা ডিসকাউন্ট প্রয়োগ করুন, তারপর নিকটতম পূর্ণ কয়েনে রাউন্ড ডাউন করুন (ফ্লোর)।

- ২০ কয়েন বা তার বেশি অর্ডারে: ১০% ডিসকাউন্ট
- ১০ কয়েন বা তার বেশি অর্ডারে: ৫% ডিসকাউন্ট
- ১০ কয়েনের কম অর্ডারে: কোনো ডিসকাউন্ট নেই

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. বেকিং শিডিউল তৈরি করুন

`baking_schedule` ইমপ্লিমেন্ট করুন, যা একটি দৈনিক বেকিং প্ল্যান তৈরি করে।
বেকারিটি প্রতি ঘণ্টায় ৫টি অর্ডারের ব্যাচে বেক করে:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

প্রতিটি সমস্যা দক্ষতার সাথে সমাধান করতে উপযুক্ত কন্ট্রোল ফ্লো কনস্ট্রাক্ট (`if`/`else`, `loop`) ব্যবহার করুন।
