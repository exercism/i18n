# পরিচিতি

Gleam ট্রু ও ফলস মান প্রকাশ করে `Bool` টাইপ দিয়ে। এর মাত্র দুটি মান আছে: `True` এবং `False`। এই মানগুলো একটি ভ্যারিয়েবলে বাইন্ড করা যায়:

```gleam
let true_variable = True
let false_variable = False
```

`&&`, `||` ও `!` অপারেটর দিয়ে বুলিয়ান মান নিয়ে কাজ করা যায়:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&` এবং `||` অপারেটর শর্ট-সার্কিট মূল্যায়ন ব্যবহার করে, অর্থাৎ অপারেটরের ডান দিকের এক্সপ্রেশনটি কেবল প্রয়োজন হলেই মূল্যায়ন করা হয়।

প্রতিটি অপারেটরের অগ্রাধিকার আলাদা: `!` মূল্যায়িত হয় `&&` ও `||`-এর আগে। দ্বিতীয় বন্ধনী ব্যবহার করে এক্সপ্রেশনের একটি অংশ অন্যগুলোর আগে মূল্যায়ন করা যায়:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
