# সম্পর্কে

Factor-এ বেশিরভাগ ইটারেশন কম্বিনেটর (`each`, `map`, `reduce`) দিয়ে লেখা হয়, তবে স্পষ্ট রিকার্সনেরও নিজস্ব জায়গা আছে। যেমন যখন রিকার্সনটি কোনো অ্যারের আকারে থাকে না, যখন বেস কেসটি সহজ নয়, বা যখন আপনি নিজেই একটি কম্বিনেটর বানাচ্ছেন।

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

কয়েকটি বিষয় জেনে রাখুন:

- সাধারণ `:` ডেফিনিশন কোনো বিশেষ সিনট্যাক্স ছাড়াই রিকার্স করতে পারে। কম্পাইলার রিকার্সিভ কল জুড়ে স্ট্যাক ইফেক্ট অনুমান করে।
- `loop ( quot -- )` দিয়ে আপনি এমন একটি কোয়োটেশন ইটারেট করতে পারেন যা একটি বুলিয়ান রিটার্ন করে। যতক্ষণ এটি ট্রুথি থাকে, ততক্ষণ চলতে থাকে।
- টেইল কল জাম্পে কম্পাইল হয়, তাই গভীরভাবে রিকার্সিভ ওয়ার্ডগুলো স্ট্যাক ওভারফ্লো করে না।

`unclip` / `if-empty` জোড়াটিই সিকোয়েন্স রিকার্সনের আদর্শ রূপ; `cond` হলো একাধিক কেস ডিসপ্যাচের আদর্শ রূপ।
