# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | ইনপুট কয়েনের সংখ্যা                       |
| `$a1`    | ইনপুট        | ইন্টিজার | টার্গেট                                      |
| `$a2`    | ইনপুট/আউটপুট | অ্যাড্রেস | কয়েন ওয়ার্ডের ওভাররাইটযোগ্য অ্যারে            |
| `$v0`    | আউটপুট       | ইন্টিজার | আউটপুট কয়েনের সংখ্যা, ইনপুট অবৈধ হলে -1 |
| `$t0-9`  | সাময়িক    | যেকোনো     | সাময়িক স্টোরেজের জন্য ব্যবহৃত                  |
