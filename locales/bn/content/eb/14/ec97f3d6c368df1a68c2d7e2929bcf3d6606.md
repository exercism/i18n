# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে চারটি কাজ, সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে কত মিনিট লাগবে তা ডিফাইন করুন

`Lasagna.expectedMinutesInOven()` মেথডটি ডিফাইন করুন, যেটি কোনো প্যারামিটার নেয় না এবং লাসাগনাকে ওভেনে কত মিনিট থাকতে হবে তা রিটার্ন করে। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় ৪০ মিনিট:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. ওভেনে আর কত মিনিট বাকি আছে তা হিসাব করুন

`Lasagna.remainingMinutesInOven()` মেথডটি ডিফাইন করুন, যেটি লাসাগনা এতক্ষণ ওভেনে কত মিনিট ছিল তা প্যারামিটার হিসেবে নেয় এবং আগের কাজে পাওয়া ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে লাসাগনাকে ওভেনে আর কত মিনিট থাকতে হবে তা রিটার্ন করে।

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. প্রস্তুতির সময় কত মিনিট তা হিসাব করুন

`Lasagna.preparationTimeInMinutes()` মেথডটি ডিফাইন করুন, যেটি লাসাগনায় আপনি কতগুলো লেয়ার যোগ করেছেন তার সংখ্যা প্যারামিটার হিসেবে নেয় এবং প্রতি লেয়ার প্রস্তুত করতে আপনার ২ মিনিট লাগে ধরে নিয়ে, লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে।

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. অতিবাহিত সময় কত মিনিট তা হিসাব করুন

`Lasagna.elapsedTimeInMinutes()` মেথডটি ডিফাইন করুন, যেটি দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসাগনায় আপনি কতগুলো লেয়ার যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসাগনা কত মিনিট ধরে ওভেনে আছে তার সংখ্যা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্নায় আপনার কত মিনিট কাজ হয়েছে, যা হলো প্রস্তুতির সময় (মিনিটে) এবং এই মুহূর্তে লাসাগনা ওভেনে কত মিনিট কাটিয়েছে তার যোগফল।

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
