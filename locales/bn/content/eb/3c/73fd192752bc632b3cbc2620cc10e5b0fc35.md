# ভূমিকা

ইলিক্সির যখন ঠিক করে যে কোন ফাংশনটি কল করা হবে, তখন লুকআপটি করার জন্য এটি মডিউলের নাম ব্যবহার করে। মডিউলের নামটি কোন ভ্যারিয়েবলে বাঁধা থাকলে এই লুকআপটি ডাইনামিকভাবে করা যায়।

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

অভ্যন্তরীণভাবে মডিউলের নাম আসলে একটি অ্যাটম। ইলিক্সিরের সব মডিউল অ্যাটমের শুরুতে স্বয়ংক্রিয়ভাবে `Elixir.` যোগ হয়।

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
