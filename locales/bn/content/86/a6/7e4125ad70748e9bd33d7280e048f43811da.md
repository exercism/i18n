# টেস্ট

টেস্টগুলো এভাবে চালান:

```shell
phpunit test_file.php
```

উদাহরণস্বরূপ, Hello World অনুশীলনীর টেস্টগুলো চালাতে হলে এভাবে চালানো হয়:

```shell
phpunit HelloWorldTest.php
```
