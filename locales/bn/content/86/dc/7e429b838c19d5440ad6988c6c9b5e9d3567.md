# টেস্ট

## সব টেস্ট চালান

`t/` ডিরেক্টরিতে `.t` এক্সটেনশনযুক্ত একটি Perl স্ক্রিপ্ট থাকে, যা আপনার সমাধান পরীক্ষা করতে ব্যবহার করা হবে।
আপনি এই কমান্ডটি দিয়ে টেস্টগুলো চালাতে পারেন:

`prove`

অনুশীলনী শুরু করার আগে আউটপুটটি দেখতে অনেকটা এমন হবে:

```
./t/hello-world.t .. 1/2
# Failed test 'Say Hi!'
# at exercises/hello-world/t/hello-world.t line 15.
# +---------+---------------+
# | GOT     | CHECK         |
# +---------+---------------+
# | <UNDEF> | Hello, World! |
# +---------+---------------+
exercises/hello-world/t/hello-world.t .. Dubious, test returned 1 (wstat 256, 0x100)
Failed 1/2 subtests

Test Summary Report
-------------------
./t/hello-world.t (Wstat: 256 Tests: 2 Failed: 1)
  Failed test:  2
  Non-zero exit status: 1
Files=1, Tests=2,  0 wallclock secs ( 0.03 usr  0.00 sys +  0.18 cusr  0.02 csys =  0.23 CPU)
Result: FAIL
```

আপনাকে `lib/` ডিরেক্টরিতে থাকা `.pm` এক্সটেনশনযুক্ত মডিউলটি পরিবর্তন করতে হবে এবং টেস্ট পাস করার জন্য একটি সমাধান লিখতে হবে।
টেস্টগুলো পাস হয়ে গেলে উপরের কমান্ডের আউটপুট দেখতে অনেকটা এমন হবে:

```
./t/hello-world.t .. ok
All tests successful.
Files=1, Tests=2,  0 wallclock secs ( 0.02 usr  0.00 sys +  0.07 cusr  0.01 csys =  0.10 CPU)
Result: PASS
```

টেস্ট ফাইলগুলোতে ব্যবহৃত অ্যাসারশন সম্পর্কে ডকুমেন্টেশন পাওয়া যাবে [Test2::Manual::Testing::Introduction][test2-manual] থেকে।
`Test2` সম্পর্কে আরও বিস্তারিত ব্যাখ্যা পাবেন [perldoc][test2] থেকে।

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
[test2]: https://perldoc.perl.org/Test2
