# ইঙ্গিত

এই অনুশীলনীতে এমন মিউটেবল স্টেট পরীক্ষা করা হচ্ছে, যেটি একাধিক থ্রেড থেকে নিরাপদে অ্যাক্সেস করা যায়। মিউটেবল স্টেট রক্ষা করার নানা উপায় Scala দেয়। Java concurrency-এর সাথে পরিচিত ডেভেলপারদের জন্য Scala Java-এর concurrency সাপোর্ট কাজে লাগাতে পারে, যেমন Java synchronized ব্লক।

## কমন বিপদ

Scala-তে মিউটেবল স্টেট অর্জন করার দুটি উপায় আছে: একটি "var" ব্যবহার করা, অথবা একটি মিউটেবল অবজেক্ট। এখানে কমন দুটি ভুল হলো:
- এমন একটি "var" ব্যবহার করবেন না, যেটি আবার একটি মিউটেবল অবজেক্টও। দুটোর একটিই যথেষ্ট, একসাথে দুটো নয়।
- "var" বা মিউটেবল অবজেক্টটি বাইরের জগতের কাছে প্রকাশ করবেন না। তাই এগুলোকে "private" করে রাখুন এবং মান হিসেবে রিটার্ন করার আগে মিউটেবল অবজেক্টটিকে ইমিউটেবল করে নিন।
