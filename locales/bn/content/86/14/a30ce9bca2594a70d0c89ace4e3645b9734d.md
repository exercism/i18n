# নির্দেশনার সংযোজন

## ইঙ্গিত

আপনাকে `rotate` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যেটি একটি `Int` ও একটি `String` নেয়, এবং তারপর একটি রোটেশনাল সাইফার দিয়ে সেটি এনকোড করে।
টাইপগুলো নিয়ে নিশ্চিত না থাকলে আপনি প্রদত্ত সিগনেচারটি ব্যবহার করতে পারেন, তবে এটি যেন আপনার সৃজনশীলতাকে সীমাবদ্ধ না করে।

এই অনুশীলনীটি টেক্সট ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর `String` টাইপটি `[Char]`-এর সমার্থক, অর্থাৎ ক্যারেক্টারের একটি অ্যারে। টেক্সট ডেটা আরও দক্ষভাবে পরিচালনার জন্য `Text` টাইপটি ব্যবহার করা যেতে পারে।

এই অনুশীলনীর ঐচ্ছিক সম্প্রসারণ হিসেবে আপনি

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়তে পারেন।
- package.yaml-এ আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করতে পারেন।
- [নিচের পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) `Data.Text` ইমপোর্ট করতে পারেন:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` টাইপ ব্যবহার করতে পারেন, যেমন `rotate :: Int -> Text -> Text`, এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.pack` বলে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখে নিতে পারেন।
- RotationalCipher.hs ফাইলে `String`-এর সব জায়গায় `Text` বসাতে পারেন, অর্থাৎ:

```haskell
rotate :: Int -> Text -> Text
```

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
