# পরিচিতি

কোনো ডেটার টাইপ কী, সেটি জানা কোড মসৃণভাবে এবং এরর ছাড়াই চলার জন্য প্রায়ই খুবই গুরুত্বপূর্ণ।

JavaScript-এ একটি মান বা অবজেক্টের টাইপ যাচাই করার কয়েকটি উপায় আছে।

```exercism/note
JavaScript-এর টাইপ যাচাইয়ের পদ্ধতিগুলো কিছুটা অনির্ভরযোগ্য হতে পারে।

আরও ভালো টাইপ সেফটি এবং আরও শক্তিশালী টাইপের জন্য আপনার সম্ভবত TypeScript ব্যবহার করা উচিত, যা JavaScript-এর উপর তৈরি একটি ভাষা, তবে স্ট্যাটিক-টাইপড ভাষার টাইপ সিনট্যাক্স নিয়ে কাজ করে।
```

## `typeof` অপারেটর

`typeof` অপারেটরটি তার অপারেন্ডের টাইপ রিটার্ন করে।
আউটপুট হয় একটি স্ট্রিং, যা [প্রিমিটিভ ডেটা টাইপ][primitives]-এর একটির নামের সাথে মেলে, শুধু `"null"` ছাড়া।
এটি `"function"` বা `"object"`-ও হতে পারে।

```javascript
typeof undefined;
// => "undefined"

typeof true;
// => "boolean"

typeof 42;
// => "number"

typeof 'Hello, World!';
// => "string"

typeof function () {
  return 'Hello, World';
};
// => "function"

typeof [1, 2, 3, 4];
// => "object"

typeof { city: 'Stockholm', country: 'Sweden' };
// => "object"
```

[ঐতিহাসিক কারণে][`typeof null` is `"object"`]।

## `instanceof` অপারেটর

একটি অবজেক্টের টাইপ যাচাই করার জন্য আপনি `instanceof` অপারেটর ব্যবহার করতে পারেন।
দ্বিতীয় অপারেন্ডটি প্রথম অপারেন্ডের [প্রোটোটাইপ চেইন][prototype chain]-এ আছে কি না, তার উপর নির্ভর করে এটি একটি `boolean`-এ মূল্যায়িত হয়।
স্পষ্ট করে বললে, `instanceof` রিটার্ন করে যে প্রথম অপারেন্ডটি দ্বিতীয় অপারেন্ডের বা তার কোনো চাইল্ড ক্লাসের ইনস্ট্যান্স কি না।
`instanceof` শুধু অবজেক্টের উপর কাজ করে।

```javascript
class Beverage {
  // ...
}

// The Coffee class is a child of the Beverage class.
class Coffee extends Beverage {
  // ...
}

const java = new Coffee();

java instanceof Coffee;
// => true

java instanceof Beverage;
// => true
```

````exercism/advanced
`Array` ক্লাসে `Array.isArray()` নামের একটি মেথড আছে, যা যাচাই করে তার আর্গুমেন্টটি একটি অ্যারে কি না।

ওয়েবপেজের `iframe`-এর মতো ভিন্ন রেল্মে তৈরি একটি অ্যারের ক্ষেত্রে `instanceof Array` কাজ করবে না, কিন্তু `Array.isArray()` কাজ করবে।

এর কারণ হলো প্রতিটি রেল্মে Array ক্লাসের কনস্ট্রাক্টর আলাদা, এবং প্রতিটি `iframe`-এর নিজস্ব রেল্ম থাকে, অর্থাৎ প্রোটোটাইপ চেইনের ফাংশনটি আলাদা হবে, যার ফলে `instanceof Array` ব্যর্থ হয়।
`Array.isArray()` এটি উপেক্ষা করতে সক্ষম, এবং সম্ভব হলে সবসময় এটি ব্যবহার করা উচিত।

এটি এমন ভুয়া পজিটিভও সামলাতে পারে যেখানে একটি অবজেক্ট আসলে `Array` নয়, শুধু তার প্রোটোটাইপ চেইনে `Array` আছে।

```javascript
({ __proto__: Array.prototype }) instanceof Array
// => true

Array.isArray({ __proto__: Array.prototype })
// => false
```
````

## `in` অপারেটর

`in` অপারেটরটি রিটার্ন করে যে প্রথম অপারেন্ডটি দ্বিতীয় অপারেন্ডের একটি প্রপার্টি কি না।
এটি যাচাই করে না যে প্রপার্টিটির একটি নির্দিষ্ট মান আছে কি না।
`undefined`-এ সেট করা একটি প্রপার্টি তবুও `in` দ্বারা শনাক্ত হবে।

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
    this.isDarkMatter = undefined;
  }

  coolDown() {
    this.temperature = 'warm';
  }
}

const espresso = new Coffee();

'temperature' in espresso;
// => true

'color' in espresso;
// => false

'isDarkMatter' in espresso;
// => true
```

````exercism/note
উত্তরাধিকারসূত্রে পাওয়া প্রপার্টি ও মেথডের জন্য `in` `true` রিটার্ন করবে।

```javascript
"coolDown" in espresso
// => true

"constructor" in espresso
// => true
```
````

## `Object.hasOwn()` ফাংশন

`Object.hasOwn()` মেথডটি রিটার্ন করে যে নির্দিষ্ট অবজেক্টটি _প্রদত্ত প্রপার্টিটির মালিক_ কি না (অর্থাৎ এটি উত্তরাধিকারসূত্রে পাওয়া নয় বা কোনো মেথড নয়)।

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
  }

  coolDown() {
    this.temperature = 'warm';
  }
}
const cappuccino = new Coffee();

Object.hasOwn(cappucino, 'temperature');
// => true

Object.hasOwn(cappucino, 'constructor');
// => false

Object.hasOwn(cappucino, 'coolDown');
// => false
```
