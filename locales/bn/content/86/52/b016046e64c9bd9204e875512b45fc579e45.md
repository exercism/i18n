# নির্দেশনা

নিউ ইয়র্কের যে বিউটি সেলুনটিতে আপনি Booking Up For Beauty অনুশীলনীতে সাহায্য করেছিলেন, তার ব্যবসা ভালোই চলছে, আর এর অনেক গ্রাহক এখন নিয়মিত হয়ে গেছেন। প্রতিটি ভিজিট আলাদা করে বুক না করে, নিয়মিত গ্রাহকদের জন্য থাকে একটি স্থায়ী ব্যবস্থা: "প্রতি দ্বিতীয় মঙ্গলবার", "মাসের শেষ শুক্রবার" ইত্যাদি। মালিক আপনাকে একটি সহায়ক মেথড বানাতে বলেছেন, যা এই ব্যবস্থাগুলোর পিছনের তারিখগুলো এবং সাথে সেলুনের নিজস্ব মাসিক রুটিনের তারিখও বের করে দেবে।

## 1. নিয়মিত গ্রাহকের স্থায়ী অ্যাপয়েন্টমেন্ট বের করা

`SalonCalendar.standingAppointment()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি বছর, একটি মাস, একটি পুনরাবৃত্তি-সংখ্যা (প্রথমটির জন্য `1`, দ্বিতীয়টির জন্য `2`, এভাবে) এবং সপ্তাহের একটি বার নেয়। এটি ওই মাসের মধ্যে সপ্তাহের ওই বারের ওই পুনরাবৃত্তিটি যে তারিখে পড়ে, সেই তারিখ রিটার্ন করে:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. নিয়মিত গ্রাহকের মাসের-শেষের অ্যাপয়েন্টমেন্ট বের করা

কিছু নিয়মিত গ্রাহক মাসের ভেতরে তাঁদের বারের শেষ পুনরাবৃত্তিটি পছন্দ করেন। `SalonCalendar.lastAppointment()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি বছর, একটি মাস ও সপ্তাহের একটি বার নেয় এবং ওই মাসের মধ্যে সপ্তাহের ওই বারের শেষ পুনরাবৃত্তিটি যে তারিখে পড়ে, সেই তারিখ রিটার্ন করে:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. ওয়াক-ইনের জন্য পরের কোন দিনটি খালি, তা বের করা

রিসেপশনে একজন ক্লায়েন্ট জিজ্ঞেস করেন "পরের শনিবার"। তিনি যেদিন জিজ্ঞেস করছেন সেদিনই যদি শনিবার হয়, তাহলে তিনি সেই দিনটাই বোঝাচ্ছেন। `SalonCalendar.nextAvailable()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি তারিখ ও সপ্তাহের একটি বার নেয়, আর দেওয়া তারিখটি বা তার পরের যে প্রথম তারিখটি ওই বারে পড়ে, সেটি রিটার্ন করে:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. হিসাবরক্ষণের দিনটি বের করা

সেলুন প্রতি মাসের শেষ দিনে তার হিসাবের খাতা বন্ধ করে। তবে সপ্তাহান্তে সেলুন বন্ধ থাকে, তাই মাসের শেষ দিনটি যদি শনিবার বা রবিবারে পড়ে, তাহলে তার আগের শুক্রবারেই খাতা বন্ধ করা হয়। `SalonCalendar.bookkeepingDay()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি বছর ও একটি মাস নেয় এবং ওই মাসের হিসাবরক্ষণের দিনটি রিটার্ন করে:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. বেতন দেওয়ার দিনেও সপ্তাহান্তের নিয়মটি পুনরায় ব্যবহার করা

কর্মীদের প্রতি মাসের ১৫ তারিখে বেতন দেওয়া হয়, একই সপ্তাহান্তের নিয়মে: ১৫ তারিখটি যদি শনিবার বা রবিবারে পড়ে, তাহলে বেতন দেওয়া হয় তার আগের শুক্রবারে। নিয়মটি আরেকবার না লিখে এটিকে পুনরায় ব্যবহারযোগ্য অ্যাডজাস্টারে পরিণত করুন।

`SalonCalendar.precedingWorkday()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি `TemporalAdjuster` রিটার্ন করে; এটি কোনো কর্মদিবস অপরিবর্তিত রাখে আর শনিবার বা রবিবারকে পিছিয়ে আগের শুক্রবারে নিয়ে যায়। এরপর ওই অ্যাডজাস্টার ব্যবহার করে `SalonCalendar.payday()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি বছর ও একটি মাস নেয়:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

চাইলে আপনি ফিরে গিয়ে `bookkeepingDay()`-তেও অ্যাডজাস্টারটি ব্যবহার করতে পারেন।
