# পরিচিতি

## তুলনার অপারেটর

[তুলনার অপারেটর][comparison-operators] একই টাইপের দুটি মান তুলনা করে এবং একটি `Bool` মান (`true` বা `false`) রিটার্ন করে।
ভিন্ন টাইপের মান তুলনা করার চেষ্টা করলে কম্পাইলার একটি এরর দেয়।

Swift-এ স্ট্যান্ডার্ড তুলনার অপারেটরগুলো হলো:

| অপারেটর | বিবরণ | উদাহরণ |
| -------- | ------------------------ | --------------- |
| `==`     | সমান | `1 == 1` (ট্রু) |
| `!=`     | অসমান | `1 != 2` (ট্রু) |
| `<`      | থেকে ছোট | `4 < 5`  (ট্রু) |
| `<=`     | থেকে ছোট বা সমান | `4 <= 4` (ট্রু) |
| `>`      | থেকে বড় | `3 > 1`  (ট্রু) |
| `>=`     | থেকে বড় বা সমান | `2 >= 2` (ট্রু) |

## if এবং else স্টেটমেন্ট

একটি [কন্ডিশনাল স্টেটমেন্ট][conditional-statement] কোনো শর্ত `true` না `false`-এ মূল্যায়িত হয়, তার ভিত্তিতে কোড চালায়।
সবচেয়ে কমন কন্ডিশনালটি হলো [if স্টেটমেন্ট][if], যা কেবল তখনই কোডের একটি ব্লক চালায় যখন তার শর্ত `true` হয়।
`if` কিওয়ার্ড দিয়ে একটি `if` স্টেটমেন্ট লিখুন, যার পরে থাকে শর্ত এবং দ্বিতীয় বন্ধনীর ভেতরে আবদ্ধ কোড ব্লক:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

শর্তটি `false` হলে বিকল্প কোড চালানোর জন্য আপনি `if`-এর সাথে একটি `else` ক্লজ যুক্ত করতে পারেন:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

পরপর একাধিক শর্ত পরীক্ষা করতে `else if` দিয়ে স্টেটমেন্টগুলো একসাথে জুড়ে দিন।
একটি `if` স্টেটমেন্টের `else` শাখা থাকা আবশ্যক নয়, তবে কোনো শর্তই মিলে না, এমন পরিস্থিতি সামলাতে আপনি একটি যোগ করতে পারেন:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## if এক্সপ্রেশন

আধুনিক Swift-এ `if` স্টেটমেন্টকে এমন এক্সপ্রেশন হিসেবেও ব্যবহার করা যায় যা একটি মান তৈরি করে।
প্রতিটি শাখা একটি মানে মূল্যায়িত হয়, ফলে শর্তের ভিত্তিতে ফলাফল অ্যাসাইন করা সহজ হয়ে যায়:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## টার্নারি অপারেটর

[টার্নারি কন্ডিশনাল অপারেটর][ternary-operator] হলো একটি `if-else` এক্সপ্রেশনের সংক্ষিপ্ত রূপ।
এটি একটি শর্ত মূল্যায়ন করে এবং সেই শর্তটি `true` না `false` তার উপর নির্ভর করে দুটি মানের একটি রিটার্ন করে।

এই অপারেটরটি তিনটি অংশ ব্যবহার করে: `condition ? trueExpression : falseExpression`।
`condition` যদি `true`-এ মূল্যায়িত হয়, তবে `trueExpression` মূল্যায়িত হয় ও রিটার্ন করা হয়; অন্যথায় `falseExpression` মূল্যায়িত হয় ও রিটার্ন করা হয়।

সরল, এক লাইনের সিদ্ধান্তের জন্য টার্নারি অপারেটর আদর্শ:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

উপরের উদাহরণটি সংক্ষেপে এটিরই সমতুল্য:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
