# সম্পর্কে

Common Lisp-এ সময় তিনটি উপায়ে উপস্থাপন করা হয়

- ইউনিভার্সাল টাইম একটি পরম সময়, একটি ইন্টিজার যা `1900-01-01T00:00:00Z` থেকে অতিক্রান্ত সেকেন্ডের সংখ্যা বোঝায় (অর্থাৎ UTC-তে ১৯০০ সালের ১ জানুয়ারির মধ্যরাত)।
- ডিকোডেড টাইম হলো ৯টি মানের একটি টাপল, যা একসাথে একটি নির্দিষ্ট ক্যালেন্ডার সময় প্রকাশ করে: সেকেন্ড, মিনিট, ঘণ্টা, মাসের দিন, মাস, বছর, সপ্তাহের বার, DST ফ্ল্যাগ, টাইম জোন।
(নিচে বিস্তারিত আলোচনা করা হয়েছে।)
- ইন্টারনাল টাইম হলো ইমপ্লিমেন্টেশন-নির্ধারিত 'ইন্টারনাল টাইম ইউনিট'-এর একটি ধনাত্মক ইন্টিজার, যা রানটাইম পরিমাপে ব্যবহার করা যায়।

## ইউনিভার্সাল টাইম

বর্তমান ইউনিভার্সাল টাইম পেতে `get-universal-time` বা `get-decoded-time` ব্যবহার করা হয়।
প্রথমটি `1900-01-01T00:00Z` থেকে বর্তমান সেকেন্ড রিটার্ন করে এবং দ্বিতীয়টি একই তথ্য ডিকোডেড ফরম্যাটে রিটার্ন করে।

মনে রাখবেন, এই সংখ্যাটি ধনাত্মক ইন্টিজার হওয়ায় ১৯০০ সালের আগের তারিখ এনকোড করা অসম্ভব।

## ডিকোডেড টাইম

সময় নিয়ে কাজ করার প্রধান ফাংশন হলো `decode-universal-time` এবং `encode-universal-time`।
প্রথমটি একটি ইউনিভার্সাল টাইম নেয় এবং [মাল্টিপল ভ্যালুস][concept-multiple-values] হিসেবে একটি ডিকোডেড টাইম মান রিটার্ন করে; দ্বিতীয়টি আর্গুমেন্ট হিসেবে ডিকোডেড টাইমের মানগুলো নেয় এবং একটি ইউনিভার্সাল টাইম রিটার্ন করে।

দুটোই একটি অপশনাল টাইম-জোন আর্গুমেন্ট নেয়।
টাইম-জোনের ফরম্যাট নিচে দেখুন।

একটি ডিকোডেড টাইম হলো কতগুলো মানের একটি সেট:

- *সেকেন্ড*: ০ থেকে ৫৯-এর মধ্যে একটি ইন্টিজার
- *মিনিট*: ০ থেকে ৫৯-এর মধ্যে একটি ইন্টিজার
- *ঘণ্টা*: ০ থেকে ২৩-এর মধ্যে একটি ইন্টিজার
- *মাসের দিন*: ১ থেকে ৩১-এর মধ্যে একটি ইন্টিজার (ঊর্ধ্বসীমা অবশ্যই মাস ও বছরের উপর নির্ভর করে)
- *মাস*: ১ থেকে ১২-এর মধ্যে একটি ইন্টিজার
- *বছর*: বছর বোঝানো একটি ইন্টিজার।
- *সপ্তাহের বার*: ০ থেকে ৬-এর মধ্যে একটি ইন্টিজার। ০ মানে সোমবার, ১ মানে মঙ্গলবার ইত্যাদি ... ৬ মানে রবিবার।
- *ডেলাইট সেভিং টাইম ফ্ল্যাগ*: ট্রু মান বোঝায় DST কার্যকর আছে।
- *টাইমজোন*: -২৪ থেকে ২৪-এর মধ্যে ঘণ্টার একটি সংখ্যা, যা UTC থেকে অফসেট বোঝায়।
সংখ্যাটি একটি মূলদ সংখ্যা এবং অবশ্যই `1/3600`-এর গুণিতক হতে হবে।

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

মনে রাখবেন, টাইম-জোন প্যারামিটার দেওয়া না হলে কিছু মজার আচরণ দেখা যায়।
বিস্তারিত জানতে [`decode-universal-time`][hyperspec-decode-universal-time] এবং [`encode-universal-time`][hyperspec-encode-universal-time] ফাংশন দুটির ডকুমেন্টেশন দেখুন।

## ইন্টারনাল টাইম

ইন্টারনাল টাইম হলো 'ইন্টারনাল টাইম ইউনিট'-এর একটি ধনাত্মক ইন্টিজার সংখ্যা। এগুলোর দুটির পার্থক্য দিয়ে রানটাইমে সময় মাপা যায়।

- `get-internal-real-time` বর্তমান "রিয়েল" বা "ক্লক" সময় রিটার্ন করে।
- `get-internal-run-time` বেশ ইমপ্লিমেন্টেশন-নির্ভর এবং এতে উদাহরণস্বরূপ পেজিং বা গার্বেজ কালেকশনে ব্যয় হওয়া সময় থাকতেও পারে, না-ও থাকতে পারে।

`internal-time-units-per-second` ভ্যারিয়েবলটিতে একটি মান থাকে, যা চলমান Lisp এনভায়রনমেন্টে প্রতি সেকেন্ডে 'ইন্টারনাল টাইম ইউনিট'-এর সংখ্যা।
