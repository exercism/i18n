# পরিচিতি

Elixir-এ পলিমরফিজম অর্জনের একটি প্রক্রিয়া হলো প্রোটোকল, যা আপনি তখন ব্যবহার করেন যখন চান ডেটা টাইপ অনুযায়ী আচরণ ভিন্ন হোক।

প্রোটোকল `defprotocol` দিয়ে ডিফাইন করা হয় এবং এতে এক বা একাধিক ফাংশন হেডার থাকে।

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

`defimpl` দিয়ে প্রোটোকল ইমপ্লিমেন্ট করা যায়।

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Elixir-এর যেকোনো বিদ্যমান ডেটা টাইপের জন্য বা একটি স্ট্রাক্টের জন্য প্রোটোকল ইমপ্লিমেন্ট করা যায়।

কোনো প্রোটোকলের ফাংশন কল করা হলে, প্রথম আর্গুমেন্টের টাইপের ভিত্তিতে উপযুক্ত ইমপ্লিমেন্টেশন স্বয়ংক্রিয়ভাবে বেছে নেওয়া হয়।
