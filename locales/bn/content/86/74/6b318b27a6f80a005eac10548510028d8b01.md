# নির্দেশাবলি

এই অনুশীলনীতে আপনি নিউ ইয়র্কের একটি বিউটি সেলুনের জন্য অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন, যে সেলুনটি ২০১২ সালের ১৫ সেপ্টেম্বর চালু হয়েছিল।

আপনার চারটি কাজ আছে, যার প্রতিটিতেই অ্যাপয়েন্টমেন্টের তারিখ জড়িত থাকবে। তারিখ ও সময় নিচের তিনটি ফরম্যাটের একটি ব্যবহার করবে:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

টেস্টগুলো স্বয়ংক্রিয়ভাবে কালচার `en-US`-তে সেট করবে। আপনাকে নিজে কালচার সেট করতে বা উল্লেখ করতে হবে না।

## 1. অ্যাপয়েন্টমেন্টের তারিখ পার্স করুন

(_static_) `Appointment.Schedule()` মেথডটি ইমপ্লিমেন্ট করুন, যা অ্যাপয়েন্টমেন্টের তারিখের একটি টেক্সট রূপকে সংশ্লিষ্ট `DateTime` ফরম্যাটে পার্স করবে:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. অ্যাপয়েন্টমেন্ট ইতিমধ্যে পেরিয়ে গেছে কি না তা যাচাই করুন

(_static_) `Appointment.HasPassed()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি অতীতে কোথাও ছিল কি না তা যাচাই করে:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. অ্যাপয়েন্টমেন্টটি বিকেলের কি না তা যাচাই করুন

(_static_) `Appointment.IsAfternoonAppointment()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি বিকেলে (>= 12:00 এবং < 18:00) কি না তা যাচাই করে:

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. অ্যাপয়েন্টমেন্টের সময় ও তারিখের বর্ণনা দিন

(_static_) `Appointment.Description()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং সেই তারিখ ও সময়ের একটি বর্ণনা রিটার্ন করে:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. বার্ষিকীর তারিখ রিটার্ন করুন

(_static_) `Appointment.AnniversaryDate()` মেথডটি ইমপ্লিমেন্ট করুন, যা এ বছরের বার্ষিকীর তারিখ রিটার্ন করে, আর সেটি হলো ১৫ সেপ্টেম্বর:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
