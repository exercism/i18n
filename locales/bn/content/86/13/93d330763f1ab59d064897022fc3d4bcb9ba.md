# ভূমিকা

Factor-এ বেশিরভাগ ডেটাই *সিকোয়েন্স*-এ থাকে। অ্যারে, ভেক্টর আর স্ট্রিং সবই সিকোয়েন্স, আর এরা সবাই [`sequences`][sequences] ভোকাবুলারির একদল সাধারণ ওয়ার্ড শেয়ার করে।

## অ্যারে লিটারাল

একটি লিটারাল অ্যারে লেখা হয় `{ }` দিয়ে, আর এলিমেন্টগুলোর মাঝে থাকে হোয়াইটস্পেস:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

অ্যারে নির্দিষ্ট দৈর্ঘ্যের, তাই `suffix` আর `remove-nth`-এর মতো ওয়ার্ডগুলো, যেগুলো এলিমেন্টের সংখ্যা বদলে দেয়, মূল অ্যারেটিকে বড় না করে বরং একটি *নতুন* সিকোয়েন্স রিটার্ন করে।

## দৈর্ঘ্য ও ইনডেক্সিং

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` হলো সীমা-নিরাপদ সংস্করণ: দৈর্ঘ্য আগে যাচাই না করেই আপনি একটি পজিশন পরীক্ষা করে দেখতে পারেন।

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## স্লাইসিং

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

সিকোয়েন্সের চেয়ে `n` বড় হলে দুটোই এরর থ্রো করে। `n` খুব বড় হলে `index-or-length` সেটিকে ছোট করে সিকোয়েন্সের দৈর্ঘ্যে নামিয়ে আনে, যাতে পরের স্লাইসটি সিকোয়েন্সের শেষ ছাড়িয়ে যেতে না পারে:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

তারা চিহ্ন দেওয়া ভ্যারিয়েন্ট `head*` আর `tail*` শেষ থেকে গণনা করে: `head*` শেষের `n` টি বাদ দেয়, `tail*` শেষের `n` টি রেখে দেয়:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

দুটি ইনডেক্সের মাঝখানে খুশিমতো স্লাইস নিতে `subseq` নেয় *শুরুর* ইনডেক্স (সেটি সহ) আর *শেষের* ইনডেক্স (সেটি ছাড়া):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

যখন আপনার কাছে *শুরু আর দৈর্ঘ্য* থাকে, তখন দুটো যোগ করলেই শেষ ইনডেক্স পাওয়া যায়:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(এটি হলো `[2, 5)` ইনডেক্স রেঞ্জ, অর্থাৎ পজিশন ২ থেকে শুরু করে তিনটি ক্যারেক্টার।)

উল্টো প্রশ্ন, অর্থাৎ একটি সাবসিকোয়েন্স *কোথায়* আছে, তার উত্তর দেয় `subseq-index`, যা প্রথম মিলটির শুরুর ইনডেক্স রিটার্ন করে, আর কোনো মিল না থাকলে রিটার্ন করে `f`:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## প্যাডিং

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

দুটোই `seq`-কে বাড়াতে থাকে যতক্ষণ না এর দৈর্ঘ্য কমপক্ষে `n` হয়। `seq` যদি আগেই ততটা লম্বা হয়, তাহলে সেটি অপরিবর্তিত অবস্থায় রিটার্ন করা হয়।

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## একই ওয়ার্ডগুলো স্ট্রিংয়েও কাজ করে

একটি স্ট্রিং হলো ক্যারেক্টারের সিকোয়েন্স, তাই উপরের সবকিছুই স্ট্রিংয়েও কাজ করে, শুধু ফলাফলটি অ্যারের বদলে আরেকটি স্ট্রিং হয়:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## অ্যাগ্রিগেশন

`sum` আর `product` ([`sequences`][sequences] ভোকাবুলারিতে আছে) একটি সংখ্যার সিকোয়েন্সের এলিমেন্টগুলো যোগ বা গুণ করে:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` সিকোয়েন্সের ওপর একটি প্রেডিকেট চালায় আর রিটার্ন করে কতগুলো এলিমেন্টের জন্য সেটি সত্য হয়েছে:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## পুরো সিকোয়েন্সের ওপর প্রেডিকেট

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## নতুন সিকোয়েন্স তৈরি করা

`suffix` সিকোয়েন্সের শেষে একটি এলিমেন্ট যোগ করে; `prefix` সামনে যোগ করে একটি। `unclip` প্রথম এলিমেন্টটি খুলে নেয় আর `unclip-last` শেষটি খুলে নেয়:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

`unclip-last` আর `suffix` একসাথে ব্যবহার করলে মূল সিকোয়েন্স না নষ্ট করেই শেষ এলিমেন্টটি আপডেট করা যায় (`unclip` + `prefix` প্রথম এলিমেন্টের জন্য একই কাজ করে):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## সিকোয়েন্স টাইপের মধ্যে রূপান্তর

`>array`, `>vector`, আর `>string` ([`arrays`][arrays] আর সংশ্লিষ্ট ভোকাবুলারিগুলোতে আছে) একটি সিকোয়েন্সকে জোর করে নির্দিষ্ট একটি কনক্রিট টাইপে রূপান্তর করে। কোনো অপারেশন যখন স্লাইস বা জেনেরিক সিকোয়েন্স রিটার্ন করে, আর আপনার দরকার হয় একটি অ্যারে (বা স্ট্রিং), তখন এটি কাজে লাগে।

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
