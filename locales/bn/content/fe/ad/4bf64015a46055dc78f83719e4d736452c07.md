# ভূমিকা

## Python-এ অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং

আপনি যদি [ফাংশনাল][functional], [ডিক্লারেটিভ][declarative], বা [ইম্পারেটিভ][imperative] স্টাইলে প্রোগ্রামিং করে থাকেন, তাহলে মনোযোগ [অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং][oop] (OOP)-এর দিকে সরিয়ে নেওয়া হয়তো একটু অপরিচিত লাগতে পারে।
OOP পদ্ধতিতে প্রোগ্রামারকে একটি সমস্যাকে এক বা একাধিক `objects` হিসেবে মডেল করার কথা ভাবতে বলা হয়, যারা একে অন্যের সাথে ইন্টারঅ্যাক্ট করে, স্টেট সংরক্ষণ করে এবং ডেটার উপর কাজ করে।
অবজেক্ট বাস্তব জগতের সত্তা (_যেমন গাড়ি বা বিড়াল_) উপস্থাপন করতে পারে, অথবা আরও বিমূর্ত ধারণা (_যেমন ইন্টিজার, যানবাহন বা স্তন্যপায়ী প্রাণী_)।
প্রতিটি অবজেক্ট কম্পিউটার মেমোরিতে একটি অনন্য ইনস্ট্যান্স হয়ে ওঠে এবং সামগ্রিক মডেলের কিছু অংশ উপস্থাপন করে।

## ক্লাস

`Classes` হলো নতুন অবজেক্ট টাইপের সংজ্ঞা, আর এগুলো থেকেই অবজেক্টের নতুন `instances` তৈরি হয়।
এগুলো প্রায়ই ডেটার সাথে কোড বা ফাংশন একসাথে রাখে, যারা ওই ডেটার উপর কাজ করে।
এই অর্থে, ক্লাস হলো _ব্লুপ্রিন্ট_ বা নির্দেশনার সমষ্টি, যা থেকে একই ধরনের অনেক অবজেক্ট তৈরি করে ব্যবহার করা যায়।
একটি জটিল প্রোগ্রামে অনেক ক্লাস থাকতে পারে, যার প্রত্যেকে নানা স্বাদের অবজেক্ট তৈরি করে।
ক্লাস থেকে অবজেক্ট তৈরির প্রক্রিয়াকে `instantiation` (_বা ক্লাসের একটি ইনস্ট্যান্স তৈরি করা_) বলা হয়।

Python-এ একটি ক্লাস ডেফিনিশন সহজ:

```python
class MyClass:
    # Class body goes here
```

### ক্লাস অ্যাট্রিবিউট

ক্লাসের বডিতে ক্লাস ফিল্ড (_যা `properties`, `attributes`, `data members`, বা `variables` নামেও পরিচিত_) যোগ করা যায়:

```python
class MyClass:
    number = 5
    string = "Hello!"
```

ক্লাসটিকে [_কল করে_][calling] `MyClass`-এর একটি ইনস্ট্যান্স (_অবজেক্ট_) তৈরি করা যায় এবং একটি নামের সাথে বাঁধা যায় (_একটি ফাংশন কল করার মতোই_):

```python
>>> new_object = MyClass()

# Class is instantiated and resulting object is bound to the "new_object" name.
# Note: the object address 'at 0x15adc55b0' will vary by computer.
>>> new_object
<__main__.MyClass at 0x15adc55b0>
```

`Class attributes` ক্লাস থেকে তৈরি সব অবজেক্ট (_বা ইনস্ট্যান্স_)-এর মধ্যে ভাগ করা থাকে, এবং [`dot notation`][dot notation] দিয়ে অ্যাক্সেস করা যায়, অর্থাৎ অবজেক্টের নামের পরে এবং অ্যাট্রিবিউটের নামের আগে একটি `.` বসিয়ে:

```python
>>> new_object = MyClass()

# Accessing the class attribute "number" via dot-notation.
>>> new_object.number
5

# Accessing the class attribute "string" via dot-notation.
>>> new_object.string
'Hello!'

# Instantiating an additional object and binding it to the "second_new_object" name.
>>> second_new_object = MyClass()

>>> second_new_object
# Note: the object address "at 0x15ad99970" will vary by computer.
<__main__.MyClass at 0x15ad99970>

# Second_new_object shares the same class attributes as new_object.
>>> new_object.number == second_new_object.number
True
```

ক্লাস অ্যাট্রিবিউট ক্লাসের শরীরেই, অন্য যেকোনো মেথডের আগে সংজ্ঞায়িত করা হয়।
এগুলো ক্লাসের মালিকানাধীন, যা তাদের ক্লাসের বিভিন্ন ইনস্ট্যান্সের মধ্যে ভাগ করে নেওয়ার সুযোগ দেয়।
যেহেতু এই অ্যাট্রিবিউটগুলো ভাগ করা, তাই এদের মান ক্লাস থেকে _সরাসরি_ অ্যাক্সেস ও পরিবর্তন করা যায়।
ক্লাস অ্যাট্রিবিউটের মান পরিবর্তন করলে _**ক্লাস থেকে তৈরি সব অবজেক্টের**_ মান পরিবর্তিত হয়:

```python
>>> obj_one = MyClass()
>>> obj_two = MyClass()

# Accessing a class attribute from an object.
>>> obj_two.number
5

# Accessing the class attribute from the class itself.
>>> MyClass.number
5

# Modifying the value of the "number" class attribute.
>>> MyClass.number = 27

# Modifying the "number" class attribute changes the "number" attribute for all objects.
>>> obj_one.number
27

>>> obj_two.number
27
```

সব সময় সিঙ্ক্রোনাইজড ডেটা-সহ অনেক অবজেক্ট থাকা বিশেষ কাজের নয়।
ভাগ্যক্রমে, ক্লাস থেকে তৈরি অবজেক্টগুলোকে তাদের নিজস্ব `instance attributes` (_বা ইনস্ট্যান্স প্রোপার্টি, ভ্যারিয়েবল, বা ফিল্ড_) দিয়ে কাস্টমাইজ করা যায়।
নাম থেকেই বোঝা যায়, ইনস্ট্যান্স অ্যাট্রিবিউট প্রতিটি অবজেক্টের জন্য আলাদা এবং স্বাধীনভাবে পরিবর্তন করা যায়।


## `__init__()` দিয়ে অবজেক্ট ইনস্ট্যান্টিয়েশন কাস্টমাইজ করা

বিশেষ ["ডান্ডার মেথড"][dunder] (_"double underscore method"-এর সংক্ষিপ্ত রূপ_) `__init__()` ক্লাস ইনস্ট্যান্স কাস্টমাইজ করতে ব্যবহৃত হয়, এবং এটি দিয়ে অবজেক্টের ইনস্ট্যান্স অ্যাট্রিবিউট বা প্রোপার্টি ইনিশিয়ালাইজ করা যায়।
ইনস্ট্যান্স অ্যাট্রিবিউট ইনিশিয়ালাইজ করার ভূমিকার কারণে `__init__()`-কে `class constructor` বা `initializer`-ও বলা হয়।
`__init__()` একটি আবশ্যক প্যারামিটার নেয় যার নাম `self`, যা সদ্য ইনিশিয়ালাইজ করা বা তৈরি করা অবজেক্টকে বোঝায়।
এরপর ইনস্ট্যান্স অ্যাট্রিবিউট বা প্রোপার্টির ডেটা `self` প্যারামিটারের পরে `__init__()`-এর আর্গুমেন্ট হিসেবে পাঠানো যায়।

নিচে, `MyClass`-এ এখন `location_x` ও `location_y` নামের ইনস্ট্যান্স অ্যাট্রিবিউট আছে।
আপনি দেখতেই পাচ্ছেন, দুটি অ্যাট্রিবিউট `__init__()`-এ পাঠানো `location` (_একটি টাপল_) আর্গুমেন্টের প্রথম ও দ্বিতীয় ইনডেক্সে অ্যাসাইন করা হয়েছে।
আপনি যখন ক্লাস ইনস্ট্যান্টিয়েট করেন এবং একটি অবজেক্ট তৈরি হয়, তখন ক্লাস ইনস্ট্যান্সের `location_x` ও `location_y` অ্যাট্রিবিউট ইনিশিয়ালাইজ হয়ে যাবে:

```python
class MyClass:
    # These are class attributes, variables, or fields.
    number = 5
    string = "Hello!"

    # This is the class "constructor", with a "location" parameter that is a tuple.
    def __init__(self, location):

        # This is an instance or object property, attribute, or variable.
        # Note that we are unpacking the tuple argument into two separate instance variables.
        self.location_x = location[0]
        self.location_y = location[1]

# Create a new object "new_object_one", with object property (1, 2).
>>> new_object_one = MyClass((1, 2))

# Create a second new object "new_object_two" with object property (-8, -9).
>>> new_object_two = MyClass((-8, -9))

# Note that new_object_one.location_x and new_object_two.location_x two different values.
>>> new_object_one.location_x
1

>>> new_object_two.location_x
-8
```

মনে রাখবেন, উপরে `MyClass` ইনিশিয়ালাইজ করার সময় আপনাকে কেবল একটি আর্গুমেন্ট পাঠাতে হয়। ক্লাস কল করা হলে `self` পাঠানোর কাজ Python নিজেই সামলে নেয়।


## মেথড

একটি `method` হলো এমন একটি `function` যা হয় ক্লাসের সাথেই বাঁধা (_যাকে [class method][class method] বলা হয়, যা পরের একটি অনুশীলনীতে আলোচনা করা হবে_), নাহয় ক্লাসের একটি _ইনস্ট্যান্স_ (অবজেক্ট)-এর সাথে বাঁধা।
যে মেথডগুলো একটি অবজেক্ট (ইনস্ট্যান্স)-এর উপর কাজ করে, সেগুলোকে প্রথম প্যারামিটার হিসেবে `self` দিয়ে ডিফাইন করতে হয়।
এরপর বাকি প্যারামিটারগুলো আপনি একটি "সাধারণ" বা আনবাউন্ড ফাংশনের মতোই ডিফাইন করতে পারেন:

```python
class MyClass:
    number = 5
    string = "Hello!"

    # Class constructor.
    def __init__(self, location):
        # Instance properties
        self.location_x = location[0]
        self.location_y = location[1]

    # Instance method. Note "self" as first parameter.
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y
```

অ্যাট্রিবিউট অ্যাক্সেসের মতোই, একটি মেথড কল করতে কেবল অবজেক্টের নামের পরে এবং মেথডের নামের আগে একটি `.` বসাতে হয়।
কল করা মেথডের প্রথম প্যারামিটার হিসেবে অবজেক্টের একটি কপি লাগে না, Python স্বয়ংক্রিয়ভাবে `self` বসিয়ে দেয়:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

# Make a new test_object with location (3,7)
>>> test_object = MyClass((3,7))
>>> (test_object.location_x, test_object.location_y)
(3,7)

# Call change_location to increase location_x and location_y by 7.
>>> test_object.change_location(7)
(10, 14)
```

ক্লাসের বাইরে যেভাবে অ্যাক্সেস করা হয়, ঠিক সেভাবেই ইনস্ট্যান্স মেথডের ভেতর থেকেও ক্লাস অ্যাট্রিবিউট অ্যাক্সেস করা যায়:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

    # Alter class variable number for all instances from within an instance.
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1


>>> test_object_one = MyClass((0,0))
>>> test_object_one.number
5

>>> test_object_two = MyClass((13, -3))
>>> test_object_two.increment_number()
>>> test_object_one.number
6
```

## Pass দিয়ে ইমপ্লিমেন্টেশন প্লেসহোল্ডিং বা স্টাবিং

আগের কনসেপ্ট অনুশীলনী ও প্র্যাকটিস অনুশীলনীর স্টাবে আপনি ফাংশনের বডিতে প্রকৃত কোডের বদলে `pass` কিওয়ার্ড ব্যবহৃত হতে দেখেছেন।
`pass` কিওয়ার্ডটি সিনট্যাক্টিক্যালি বৈধ একটি প্লেসহোল্ডার, এটি খালি ফাংশন বা ক্লাস ডেফিনিশনের জন্য Python-কে সিনট্যাক্স এরর ছুঁড়তে বাধা দেয়।
মূলত এটি Python ইন্টারপ্রেটারকে বলার একটি উপায়, 'চিন্তা করো না! আমি _একসময়_ এখানে কোড বসাব, এখনো বসাইনি শুধু।'

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return  self.location_x, self.location_y

    # Alter class variable number for all instances
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1

    # This will compile and run without error, but has no current functionality.
    def pending_functionality(self):
       # Stubbing or placholding the body of this method.
       pass
```
