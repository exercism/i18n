# নির্দেশাবলি

এই অনুশীলনীতে আপনি আপনার এলাকার আর্কেড হলের সবচেয়ে জনপ্রিয় গেমটির হাই স্কোর হিসাব রাখার একটি উপায় তৈরি করবেন।

আপনার ৬টি ফাংশন লিখতে হবে, যেগুলোর বেশিরভাগই হাই স্কোর ধরে রাখা একটি অবজেক্ট নিয়ে কাজ করার সাথে সম্পর্কিত।

## 1. নতুন একটি হাই স্কোর বোর্ড তৈরি করুন

একটি ফাংশন `create_score_board` লিখুন, যা হাই স্কোর বোর্ড হিসেবে কাজ করে এমন একটি অবজেক্ট তৈরি করে।
এই অবজেক্টের কী (key) গুলো হবে খেলোয়াড়দের নাম, আর মান হবে তাদের স্কোর।
টেস্টের সুবিধার জন্য আপনি অবজেক্টটিতে সরাসরি একটি এন্ট্রি রাখতে চান।
এই প্রাথমিক এন্ট্রিতে খেলোয়াড়ের নাম হিসেবে `"The Best Ever"` এবং স্কোর হিসেবে `1000000` থাকা উচিত।

```jq
create_score_board
# returns an object with one initial entry
```

## 2. একটি স্কোর বোর্ডে খেলোয়াড় যোগ করুন

হাই স্কোর বোর্ডে একজন খেলোয়াড় যোগ করতে `add_player` ফাংশনটি লিখুন।
এটি ইনপুট হিসেবে একটি স্কোর বোর্ড নেয় এবং দুটি প্যারামিটার চায়: খেলোয়াড়ের নাম ও খেলোয়াড়ের স্কোর।
ফাংশনটি নতুন খেলোয়াড় যোগ করা স্কোর বোর্ড অবজেক্টটি আউটপুট দেয়।

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

খেলোয়াড় যদি ইতিমধ্যেই বোর্ডে থাকে, তবে বোর্ডটি অপরিবর্তিত আউটপুট দিন।

## 3. একটি স্কোর বোর্ড থেকে খেলোয়াড় সরান

খেলোয়াড়রা যদি আর্কেড হলের নিয়ম ভাঙে, তবে তাদের ম্যানুয়ালি হাই স্কোর বোর্ড থেকে সরিয়ে ফেলা হয়।
`remove_player` লিখুন, যা ইনপুট হিসেবে একটি বোর্ড এবং একটি প্যারামিটার নেয়: যে খেলোয়াড়কে সরাতে হবে তার নাম।
এই ফাংশনের উচিত বোর্ড থেকে নির্দিষ্ট খেলোয়াড়ের এন্ট্রিটি সরিয়ে ফেলা এবং নতুন বোর্ডটি আউটপুট দেওয়া।
খেলোয়াড় যদি শুরুতেই বোর্ডে না থাকে, তবে বোর্ডটির কিছুই হওয়া উচিত নয়; এটি যেমন আছে তেমনই রিটার্ন করা উচিত।

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. একজন খেলোয়াড়ের স্কোর বাড়ান

কোনো খেলোয়াড় আর্কেড হলে আরেকটি গেম শেষ করলে বোর্ডে তার আগের স্কোরের সাথে নির্দিষ্ট পরিমাণ পয়েন্ট যোগ হবে।
`update_score` লিখুন, যা ইনপুট হিসেবে একটি স্কোর বোর্ড নেয় এবং দুটি প্যারামিটার চায়: খেলোয়াড়ের নাম ও যে পরিমাণ স্কোর যোগ করতে হবে।
আপডেট হওয়ার পর ফাংশনটির উচিত স্কোর বোর্ডটি রিটার্ন করা।

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

খেলোয়াড় আগে থেকে বোর্ডে না থাকলে এই ফাংশনের উচিত তাকে বোর্ডে যোগ করা।

## 5. সোমবারের বোনাস পয়েন্ট প্রয়োগ করুন

আর্কেড হল সোমবারগুলোতে আলাদা একটি স্কোর বোর্ড রাখে।
দিনের শেষে ওই বোর্ডের প্রতিটি খেলোয়াড় অতিরিক্ত ১০০ পয়েন্ট পায়।

`apply_monday_bonus` ফাংশনটি লিখুন।
ফাংশনটি ওই বোর্ডে থাকা প্রতিটি খেলোয়াড়ের জন্য বোনাস পয়েন্ট যোগ করে।

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. মোট স্কোর বের করুন

কে সেরা খেলোয়াড়দের নিয়ে গড়ে উঠেছে তা নির্ধারণ করতে বিভিন্ন আর্কেড হল একে অপরের সাথে প্রতিযোগিতা করে।
সবচেয়ে বেশি মোট স্কোর পাওয়া আর্কেডটি সম্মানটি জিতে নেয়।

একটি ফাংশন `total_score` লিখুন।
এটি ইনপুট হিসেবে একটি স্কোর বোর্ড নেয় এবং সব খেলোয়াড়ের স্কোরের যোগফল আউটপুট দেয়।

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
