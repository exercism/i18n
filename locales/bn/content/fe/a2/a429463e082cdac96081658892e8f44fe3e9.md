# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার চারটি কাজ আছে, যেগুলো সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. একটি কনস্ট্যান্টে প্রত্যাশিত বেক করার সময় সংরক্ষণ করুন

`expected-bake-time` কনস্ট্যান্টটি ডিফাইন করুন, যেটি রিটার্ন করবে ওভেনে লাসাগনাটি বেক হতে কত মিনিট লাগবে।

রান্নার বই অনুযায়ী, লাসাগনাকে ওভেনে মোট ৪০ মিনিট থাকতে হবে।

```factor
expected-bake-time .
! => 40
```

## 2. মিনিটে প্রস্তুতির সময় নির্ণয় করুন

`preparation-time` ওয়ার্ডটি ডিফাইন করুন। এটি স্ট্যাক থেকে লাসাগনায় আপনি যতগুলো স্তর যোগ করেছেন তার সংখ্যা নেয় এবং প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রেখে দেয়, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে ২ মিনিট লাগে।

```factor
4 preparation-time .
! => 8
```

## 3. মিনিটে অবশিষ্ট ওভেনের সময় নির্ণয় করুন

`remaining-time` ওয়ার্ডটি ডিফাইন করুন। এটি লাসাগনা ইতিমধ্যে ওভেনে যত মিনিট কাটিয়েছে তার সংখ্যা নেয় এবং সেখানে আরও কত মিনিট থাকতে হবে তা রেখে দেয়।

```factor
25 remaining-time .
! => 15
```

## 4. মিনিটে মোট কাজের সময় নির্ণয় করুন

`total-working-time` ওয়ার্ডটি ডিফাইন করুন। এটি স্ট্যাক থেকে দুটি আর্গুমেন্ট নেয়, প্রথমে লাসাগনার স্তরের সংখ্যা, তারপর লাসাগনা ইতিমধ্যে ওভেনে যত মিনিট ছিল তার সংখ্যা, এবং এখন পর্যন্ত রান্নায় ব্যয় হওয়া মোট সময় রেখে দেয়: প্রস্তুতির সময় যোগ ওভেনে ইতিমধ্যে কাটানো সময়।

```factor
3 20 total-working-time .
! => 26
```
