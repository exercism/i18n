# পরিচিতি

Lua সংখ্যার জন্য দুটি রূপ ব্যবহার করে: ৬৪-বিটের ইন্টিজার সংখ্যা এবং ডাবল-প্রিসিশনের ফ্লোটিং-পয়েন্ট সংখ্যা। এটি সাধারণ গাণিতিক অপারেটরগুলোর একটি সেট সমর্থন করে: যোগ, বিয়োগ, গুণ, ভাগ আর নেগেশন। এছাড়াও এটি ফ্লোর ডিভিশন, মডুলো আর এক্সপোনেনশিয়েশন সমর্থন করে।

| অপারেটর | উদাহরণ             |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
