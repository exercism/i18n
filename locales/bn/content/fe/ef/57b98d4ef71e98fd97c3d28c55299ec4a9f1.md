# ভূমিকা

## ভ্যারিয়েবল

মনে করুন, একটি `jq` প্রোগ্রাম হলো _এক্সপ্রেশনের একটি পাইপলাইন_।
**ভ্যারিয়েবল অ্যাসাইনমেন্ট** এই নিয়মটি মেনে চলে: একটি _ভ্যারিয়েবল অ্যাসাইনমেন্ট_ হলো এমন একটি এক্সপ্রেশন, যা দেখতে এরকম:

```jq
... | expr as $varname | ...
```

### ফিল্টারটি ইনপুট আউটপুট করে

_আইডেন্টিটি এক্সপ্রেশন_ `.`-এর মতোই, _ভ্যারিয়েবল অ্যাসাইনমেন্ট_-এর আউটপুটও তার ইনপুটের মতোই।
ভ্যারিয়েবলের মান সেট করা একটি সাইড-এফেক্ট মাত্র।

উদাহরণ, যা দেখায় যে অ্যাসাইনমেন্টের পরে `.` শুরুর ইনপুটের মতোই থাকে:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### ভ্যারিয়েবলের স্কোপ

ভ্যারিয়েবলের স্কোপ "লেক্সিকাল", অর্থাৎ পাইপলাইনের বাকি অংশজুড়ে ভ্যারিয়েবলটি স্কোপে থাকবে।
ফাংশনের ভেতরে ডিফাইন করা ভ্যারিয়েবল (ফাংশন নিয়ে আমরা পরে আলোচনা করব) ফাংশনের কাছে "লোকাল"।

### ভ্যারিয়েবলের নাম

ভ্যারিয়েবলের নাম অবশ্যই `$` দিয়ে শুরু হতে হবে।
নামের বাকি অংশটি একটি **আইডেন্টিফায়ার**: একটি অক্ষর বা আন্ডারস্কোর দিয়ে শুরু হয়, তারপর আসে অক্ষর, সংখ্যা বা আন্ডারস্কোর।

### ডিস্ট্রাকচারিং অ্যাসাইনমেন্ট

ম্যানুয়াল থেকে:

> একটিমাত্র `as` এক্সপ্রেশন ব্যবহার করে একাধিক ভ্যারিয়েবল ঘোষণা করা যায়, যদি এমন একটি প্যাটার্ন দেওয়া হয় যা _ইনপুটের গঠনের সঙ্গে মেলে_ (একে বলা হয় "ডিস্ট্রাকচারিং")।

উদাহরণ:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

ভ্যারিয়েবলের নাম _অবজেক্ট কী (key)_-এর সঙ্গে মিলিয়ে দিলে একটি শর্টকাট পাওয়া যায়:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### কনস্ট্যান্ট

উপরের উদাহরণেই দেখা গেছে, কনস্ট্যান্ট সংরক্ষণ করার জন্য ভ্যারিয়েবল সুবিধাজনক।
কোডে "ম্যাজিক নাম্বার" দেখানোর চেয়ে কনস্ট্যান্টকে একটি নাম দেওয়া ভালো।

### অনেক সময় ভ্যারিয়েবলের দরকার হয় না

অনেক সময়ই ভ্যারিয়েবল বাদ দিলে কোড পড়তে আরও সহজ হয়।

সংখ্যার একটি তালিকার গড় নির্ণয় করার কথা ভাবুন

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

এর তুলনায়

```jq
[2, 4, 8, 7] | add / length
```

এটি `jq`-এর সবচেয়ে শক্তিশালী দিকগুলোর একটি তুলে ধরে: একটি ফিল্টারের ইনপুট _প্রতিটি_ সাব-এক্সপ্রেশনকে দেওয়া হয়:

- ইনপুট অ্যারে `[2,4,8,7]` পাঠানো হয় `add`-এ (যা সব এলিমেন্টে `+` অপারেটর প্রয়োগ করে সংখ্যাগুলো যোগ করে)
- _একই সঙ্গে_, `[2,4,8,7]` পাঠানো হয় `length`-এও
- এই সাব-এক্সপ্রেশনগুলো শেষ হলে তাদের ফলাফল ভাগ করা হয়, ফলে ইনপুট অ্যারেতে থাকা সংখ্যাগুলোর গড় মান পাওয়া যায়।

### শেখার অনুশীলনীর জন্য যে `jq` অপারেটরগুলো আপনার দরকার হবে

#### বিকল্প অপারেটর: `//`

`a // b` এক্সপ্রেশনটি `a` যদি ফলস বা null হয় তাহলে `b` আউটপুট করে, অন্যথায় `a` আউটপুট করে।
ভ্যারিয়েবল সেট করার সময় একটি ডিফল্ট মান দেওয়ার জন্য এটি খুবই সুবিধাজনক:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### পাটিগণিত অপারেটর

- `+`, `-`, `*` হলো স্বাভাবিক সংখ্যাগত যোগ, বিয়োগ ও গুণের অপারেটর।
