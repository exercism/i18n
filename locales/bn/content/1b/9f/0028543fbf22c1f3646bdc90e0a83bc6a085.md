# পরিচিতি

Elixir-এ রেগুলার এক্সপ্রেশন **PCRE** স্পেসিফিকেশন (**P**erl **C**ompatible **R**egular **E**xpressions) মেনে চলে, ঠিক Java, JavaScript বা Ruby-র মতো অন্যান্য জনপ্রিয় ভাষার মতোই।

`Regex` মডিউলে রেগুলার এক্সপ্রেশন নিয়ে কাজ করার জন্য ফাংশন আছে। `String` মডিউলের কিছু ফাংশনও আর্গুমেন্ট হিসেবে রেগুলার এক্সপ্রেশন নেয়।

~~~~exercism/note
এই অনুশীলনীতে ধরে নেওয়া হয়েছে যে আপনি রেগুলার এক্সপ্রেশনের সিনট্যাক্স ইতিমধ্যেই জানেন, যার মধ্যে ক্যারেক্টার ক্লাস, কোয়ান্টিফায়ার, গ্রুপ আর ক্যাপচারও আছে।

আপনার রেগুলার এক্সপ্রেশনের জ্ঞান একটু ঝালিয়ে নিতে চাইলে, এই সোর্সগুলোর একটি দেখে নিন: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/)।
~~~~

## সিজিল

রেগুলার এক্সপ্রেশন তৈরির সবচেয়ে কমন উপায় হলো `~r` সিজিল ব্যবহার করা।

```elixir
~r/test/
```

মনে রাখবেন, Elixir-এর সব সিজিল শুধু `/` নয়, [বিভিন্ন ধরনের ডেলিমিটার][sigils]-ও সাপোর্ট করে।

## ম্যাচিং

`=~/2` অপারেটর দিয়ে এমন একটি রেজেক্স ম্যাচ করা যায় যেটি `boolean` ফলাফল রিটার্ন করে। বিকল্প হিসেবে, `Regex` মডিউলে এবং `String` মডিউলেও `match?/2` ফাংশন আছে।

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## ক্যাপচারিং

সাধারণ বুলিয়ান চেক যথেষ্ট না হলে, সব ক্যাপচারের একটি অ্যারে পেতে `Regex.run/3` ফাংশন ব্যবহার করুন (ম্যাচ না থাকলে `nil`)। রিটার্ন করা অ্যারের প্রথম এলিমেন্ট সবসময় পুরো রেগুলার এক্সপ্রেশনের একটি ম্যাচ, আর পরের এলিমেন্টগুলো হলো ম্যাচ হওয়া গ্রুপ।

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## মডিফায়ার

বিশেষ ফ্ল্যাগ যোগ করে একটি রেগুলার এক্সপ্রেশনের আচরণ পরিবর্তন করা যায়। সিজিল দিয়ে রেগুলার এক্সপ্রেশন তৈরি করলে, দ্বিতীয় ডেলিমিটারের পরে মডিফায়ারগুলো যোগ করুন।

কমন মডিফায়ারগুলো হলো:
- `i` - ম্যাচটিকে কেস-ইনসেনসিটিভ করে।
- `u` - `\p`-এর মতো ইউনিকোড-নির্দিষ্ট প্যাটার্ন চালু করে এবং `\w`, `\s` ইত্যাদি ক্যারেক্টার ক্লাসগুলোও যাতে ইউনিকোড ম্যাচ করে তা নিশ্চিত করে।

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```

[sigils]: https://hexdocs.pm/elixir/syntax-reference.html#sigils
