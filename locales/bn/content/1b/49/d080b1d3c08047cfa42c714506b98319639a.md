# টেস্ট

আপনার বর্তমান OS বেছে নিন:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# টেস্ট চালানো

## Windows

1. একটি Command Prompt খুলুন।

2. প্রথম অনুশীলনীটি সংগ্রহ করুন:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. অনুশীলনীর ফোল্ডারে ডিরেক্টরি পরিবর্তন করুন:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. টেস্ট চালান:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(প্রথমবার চালানোর সময় টেস্ট ফেল করলে চিন্তা করবেন না, প্রতিটি অনুশীলনী এভাবেই শুরু হয়।)*

5. অনুশীলনীটি সমাধান করুন। 
    `instructions.md` পড়ুন এবং অনুশীলনীটি কীভাবে সমাধান করতে হয় দেখে নিন ([GitHub-এ দেখুন](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md))।


শুভকামনা! COBOL ট্র্যাকে আপনাকে স্বাগতম!

----

## macOS

1. একটি Terminal উইন্ডো খুলুন।

2. প্রথম অনুশীলনীটি সংগ্রহ করুন:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. অনুশীলনীর ফোল্ডারে ডিরেক্টরি পরিবর্তন করুন:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. টেস্ট চালান:

    ```
     $ bash test.sh
    ```
    *(প্রথমবার চালানোর সময় টেস্ট ফেল করলে চিন্তা করবেন না, প্রতিটি অনুশীলনী এভাবেই শুরু হয়।)*

    ইঙ্গিত: যদি `basename` নেই এমন একটি মেসেজ পান, তাহলে coreutils ইনস্টল করতে [brew](https://brew.sh/) ব্যবহার করতে পারেন। (`brew install coreutils`)

5. অনুশীলনীটি সমাধান করুন। 

    `instructions.md` পড়ুন এবং অনুশীলনীটি কীভাবে সমাধান করতে হয় দেখে নিন ([GitHub-এ দেখুন](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md))।


শুভকামনা! COBOL ট্র্যাকে আপনাকে স্বাগতম!
