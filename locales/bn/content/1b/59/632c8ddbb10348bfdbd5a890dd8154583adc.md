# কন্ট্রিবিউটরদের জন্য টুল

শিক্ষার্থীদের শুধু [INSTALLATION.md](INSTALLATION.md) ফাইলে থাকা টুলগুলোই দরকার।
কন্ট্রিবিউটরদের আরও কয়েকটি টুল দরকার, কারণ ট্র্যাকের স্ক্রিপ্টগুলো এগুলো ব্যবহার করে:

- `git`, রিপোজিটরি ক্লোন করতে এবং পুল রিকোয়েস্ট খুলতে।
- `jq`, যা `bin/verify-exercises` এবং `bin/add-practice-exercise` ব্যবহার করে।
- `curl`, যা `bin/fetch-configlet` ব্যবহার করে।
- Python 3.11 বা তার পরের সংস্করণ, টেস্ট জেনারেটরের জন্য।
- `clang-format`, যেটি টেস্ট জেনারেটর তার লেখা ফাইলগুলোর ওপর চালায়।
- `pre-commit`, যা প্রতিটি কমিটের আগে রিপোজিটরির চেকগুলো চালায়।

আপনার ডিস্ট্রিবিউশনের জন্য দেওয়া কমান্ড দিয়ে এগুলো ইনস্টল করুন, তারপর "রিপোজিটরি সেটআপ করুন" অংশের ধাপগুলো অনুসরণ করুন।

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## রিপোজিটরি সেটআপ করুন

রিপোজিটরির রুট থেকে:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
