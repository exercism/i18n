# ক্লাস

ক্লাস হলো [অবজেক্ট-অরিয়েন্টেড প্রোগ্রামিং][object-oriented-programming]-এর একটি কেন্দ্রীয় ধারণা। [Crystal-এ সবকিছুই একটি অবজেক্ট][everything-is-an-object], প্রতিটি অবজেক্টের একটি টাইপ থাকে এবং এটি কিছু মেথডে সাড়া দিতে পারে। ক্লাস হলো অবজেক্ট তৈরির এক ধরনের নকশা, যা স্টেটের জন্য প্রাথমিক মান (যেমন ভ্যারিয়েবল) এবং আচরণের বাস্তবায়ন (যেমন মেথড) দেয়। অবজেক্ট হলো ক্লাসের ইন্সট্যান্স, যেগুলো সব ইন্সট্যান্স ভ্যারিয়েবল ও স্টেট ধারণ করে।

## ক্লাসের সংজ্ঞা

একটি ক্লাস ডিফাইন করা হয় `class` কিওয়ার্ড দিয়ে, যার পরে থাকে `UpperCamelCase`-এ লেখা ক্লাসের নাম।

```crystal
class Account
end
```

## ইন্সট্যান্স তৈরি করা

[ক্লাসের একটি ইন্সট্যান্স তৈরি করতে][new-initialize] `new` মেথড দিয়ে ক্লাসের নাম কল করুন।

```crystal
class Account
end

account = Account.new
```

উপরের উদাহরণে `account` ভ্যারিয়েবলটি `Account` ক্লাসের একটি ইন্সট্যান্স।

একটি ইন্সট্যান্স তৈরি করার সময় `initialize` নামের একটি বিশেষ মেথড কনস্ট্রাক্টর হিসেবে কাজ করে। ইন্সট্যান্স তৈরি হলে এটিকে কল করা হয়। কনস্ট্রাক্টরটি আপনাকে ইন্সট্যান্সের প্রাথমিক স্টেট নির্ধারণ করার সুযোগ দেয়। `initialize` মেথড আর্গুমেন্ট নিতে পারে, যেগুলো ইন্সট্যান্স তৈরির সময় পাঠানো হয়।

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize` মেথড নিজে থেকে কোনো মান রিটার্ন করতে পারে না; বরং `new` নতুন তৈরি করা ইন্সট্যান্সটি রিটার্ন করে।

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## ইন্সট্যান্স মেথড

ইন্সট্যান্স মেথড হলো এমন একটি মেথড যা একটি ক্লাসের ইন্সট্যান্সে পাওয়া যায় এবং সেই ইন্সট্যান্সের উপর কল করা যায়। ইন্সট্যান্স মেথড `def` কিওয়ার্ড দিয়ে ডিফাইন করা হয়, যার পরে থাকে মেথডের নাম। এগুলো ক্লাসের সংজ্ঞার ভেতরে ডিফাইন করা হয়।

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## ইন্সট্যান্স ভ্যারিয়েবল

[ইন্সট্যান্স ভ্যারিয়েবল][instance-variable] হলো এমন ভ্যারিয়েবল যা ইন্সট্যান্সের সব মেথডে পাওয়া যায়। একটি ইন্সট্যান্স ভ্যারিয়েবল অ্যাক্সেস করতে হলে আপনাকে একটি ইন্সট্যান্স মেথড ডিফাইন করতে হবে। এগুলো `initialize` মেথডে ইনিশিয়ালাইজ করা যায়। এগুলো `@` প্রিফিক্স দিয়ে ডিফাইন করা হয়।

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

ইন্সট্যান্স ভ্যারিয়েবল ক্লাসের সংজ্ঞার ভেতরেও ডিফাইন করা যায়।

```crystal
class Account
  @age = 0
end
```

### ইনিশিয়ালাইজেশনসহ ইন্সট্যান্স ভ্যারিয়েবল

`initialize` মেথডে পাঠানো একটি আর্গুমেন্ট দিয়ে ইন্সট্যান্স ভ্যারিয়েবল ইনিশিয়ালাইজ করা যায়। ইনিশিয়ালাইজেশনের সময় ব্যবহৃত আর্গুমেন্টের টাইপ Crystal নিজে থেকে অনুমান করতে পারে না, তাই তা উল্লেখ করতে হয়। এ বিষয়ে আরও পড়তে চাইলে দেখুন: [টাইপ ইনফারেন্স][type-inference]। ভ্যারিয়েবলের টাইপ উল্লেখ করতে আপনি `:` চিহ্নটি ব্যবহার করতে পারেন, যার পরে থাকে টাইপ। উদাহরণস্বরূপ, `Int32` টাইপের `balance` নামের একটি ইন্সট্যান্স ভ্যারিয়েবল তৈরি করতে চাইলে আপনি এভাবে লিখতে পারেন: `@balance : Int32`। কিংবা `Bool` টাইপের `raining` নামের একটি ইন্সট্যান্স ভ্যারিয়েবল তৈরি করতে চাইলে এভাবে লিখতে পারেন: `@raining : Bool`।

এটি বাস্তবায়নের কয়েকটি উপায় আছে। একটি হলো `initialize` মেথডে টাইপসহ আর্গুমেন্ট ঘোষণা করা, তারপর ইন্সট্যান্স ভ্যারিয়েবলে সেই আর্গুমেন্ট অ্যাসাইন করা, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

আরেকটি উপায় হলো ক্লাসের সংজ্ঞায় `@<variable> : <Type>` আকারে ইন্সট্যান্স ভ্যারিয়েবলের টাইপ ঘোষণা করা, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### ইন্সট্যান্স ভ্যারিয়েবল ইনিশিয়ালাইজ করার শর্টহ্যান্ড

`initialize` মেথডের আর্গুমেন্টেই একই `@<variable> : <Type>` সিনট্যাক্স ব্যবহার করে ইন্সট্যান্স ভ্যারিয়েবল ইনিশিয়ালাইজ করার একটি শর্টহ্যান্ড আছে। এটি আর্গুমেন্ট থেকে ইন্সট্যান্স ভ্যারিয়েবলে অ্যাসাইনমেন্ট এবং ইন্সট্যান্স ভ্যারিয়েবলের টাইপ ঘোষণা, দুটোই একসাথে করে।

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## ইন্সট্যান্স ভ্যারিয়েবল পরিবর্তন করা

মেথড ইন্সট্যান্স ভ্যারিয়েবল পরিবর্তন করতে পারে। এই মেথডগুলো ক্লাসের ইন্সট্যান্সের উপর কল করা যায়। কোনো মেথড যখন একটি ইন্সট্যান্স ভ্যারিয়েবল পরিবর্তন করে, তখন সেই পরিবর্তন শুধু যে ক্লাসের ইন্সট্যান্সের উপর কল করা হয়েছিল সেখানেই পাওয়া যায়।

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## ক্লাস মেথড

[ক্লাস মেথড][class-methods] হলো এমন মেথড যা একটি ক্লাসের জন্য ডিফাইন করা হয়, কিন্তু তার ইন্সট্যান্সগুলোর জন্য নয়। এগুলো ইন্সট্যান্সের স্টেটের উপর নির্ভর করে না, এমন মেথড তৈরি করার একটি উপায় দেয়। এগুলো `def` কিওয়ার্ড দিয়ে ডিফাইন করা হয়, যার পরে থাকে `self.<method name>`। `self` হলো সেই নেমস্পেসের একটি রেফারেন্স, যেখান থেকে self-কে কল করা হচ্ছে। এখানে এটি `Account` ক্লাসকে বোঝায়। এটি `Account.` লিখলে যা হতো, ঠিক সেটিই হবে, তবে `self.` ব্যবহারই বেশি পছন্দ করা হয়।

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
