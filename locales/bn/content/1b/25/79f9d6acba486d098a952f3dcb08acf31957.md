# নির্দেশনা

আপনার কাজ হলো Mickey ও Minerva-এর জন্য নিখুঁত মেজ তৈরি করা, যেগুলোর সমাধান একটিই আর কোনো বিচ্ছিন্ন অংশ নেই।
যা যা জানা দরকার:

- মেজটির আকার আয়তাকার এবং শুরুতে ও শেষে একটি করে খোলা মুখ থাকে।
- মেজে ঘর ও পথ থাকে, যেগুলো পরস্পরকে সমকোণে ছেদ করে।
- প্রোগ্রামটির দুটি প্যারামিটার নেওয়া উচিত: rows ও columns। মেজের আকার ৫ থেকে ১০০ সেলের মধ্যে হওয়া উচিত।
- যে মেজটি `x` কলাম চওড়া ও `y` সারি উঁচু, সেটি `2x + 1` ক্যারেক্টার চওড়া এবং `2y + 1` ক্যারেক্টার উঁচু হওয়া উচিত।
- যদি কোনো সিড দেওয়া না হয়, তাহলে একটি র‍্যান্ডম মেজ তৈরি করুন। একই সিড একাধিকবার দেওয়া হলে প্রতিবার মেজটি একই রকম হওয়া উচিত।
- দেয়াল আঁকতে [বক্স-ড্রয়িং][Box-drawing] ক্যারেক্টার ব্যবহার করুন, আর বাম দিকে প্রবেশপথ ও ডান দিকে বেরোনোর পথ বোঝাতে একটি তির চিহ্ন (⇨) ব্যবহার করুন।

এখন সময় হয়েছে এই দুঃসাহসী ইঁদুরগুলোর জন্য কিছু নিখুঁত মেজ তৈরি করার!

## উদাহরণ

1. একটি ছোট বর্গাকার মেজ, ৫x৫ সেল (বা ১১x১১ ক্যারেক্টার)

    ```text
    ┌───────┬─┐
    │       │ │
    │ ┌─┬── │ │
    │ │ │   │ ⇨
    │ │ │ ──┤ │
    ⇨ │ │   │ │
    ┌─┤ └── │ │
    │ │     │ │
    │ │ ────┘ │
    │         │
    └─────────┘
    ```

2. একটি আয়তাকার মেজ, ৬x১৮ সেল

    ```text
    ┌───────────┬─────────┬───────────┬─┐
    │           │         │           │ │
    │ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
    │ │       │ │ │ │   │     │ │   │   ⇨
    │ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
    │   │ │ │   │   │   │   │ │ │   │   │
    └── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
    ⇨   │   │       │ │   │   │ │   │   │
    ┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
    │ │   │   │ │ │ │   │   │   │     │ │
    │ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
    │   │       │       │     │     │   │
    └───┴───────┴───────┴─────┴─────┴───┘
    ```

[Box-drawing]: https://en.wikipedia.org/wiki/Box-drawing_character
