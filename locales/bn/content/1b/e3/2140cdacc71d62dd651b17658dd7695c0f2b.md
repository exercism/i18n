# শর্তসমূহ

Crystal-এ কন্ট্রোল এক্সপ্রেশন নামে পরিচিত জিনিস আছে; এগুলো প্রোগ্রাম কীভাবে চলবে তা নিয়ন্ত্রণ করতে ব্যবহৃত হয় এবং এরা একটি ট্রুথি বা ফলসি মান নেয়।
এমন অপারেটরও আছে যেগুলো ট্রুথি বা ফলসি মান তৈরি করতে ব্যবহার করা যায়; এগুলো [সমানতা ও তুলনা অপারেটর][equality-and-comparison] নামে পরিচিত।

দুটি প্রধান কন্ট্রোল এক্সপ্রেশন আছে, যেগুলো কোন কোড চলবে আর কোনটি চলবে না তা নিয়ন্ত্রণ করতে ব্যবহৃত হয়।
অর্থাৎ কোন নির্দিষ্ট শাখা চলবে তা-ও বোঝায়।

এই দুটি হলো: `if` এবং `unless` এক্সপ্রেশন।

## তুলনা অপারেটরসমূহ

তুলনা অপারেটরগুলো মান তুলনা করতে এবং একটি `true` বা `false` মান রিটার্ন করতে ব্যবহৃত হয়।
এই অপারেটরগুলোর মাধ্যমে তুলনা করতে একই টাইপের দুটি মান লাগে।
যদি মানগুলো একই টাইপের না হয়, তাহলে কম্পাইলার একটি এরর দেবে।
এখানে তুলনা অপারেটরগুলোর একটি তালিকা এবং কখন তারা `true` মান দেয় তার একটি উদাহরণ রয়েছে:

| Method | Description           | Example |
| ------ | --------------------- | ------- |
| <      | এর চেয়ে ছোট             | 4 < 5   |
| <=     | এর চেয়ে ছোট বা সমান    | 4 <= 4  |
| >      | এর চেয়ে বড়          | 3 > 1   |
| >=     | এর চেয়ে বড় বা সমান | 2 >= 2  |

## সমানতা অপারেটরসমূহ

সমানতা অপারেটরগুলো তুলনা অপারেটরের মতোই, তবে এগুলো দুটি মান সমান কি না তা যাচাই করতে ব্যবহৃত হয়।

`==` অপারেটর পরীক্ষা করে দুটি মান সমান কি না, মানের টাইপসহ।
যদি মানগুলো একই হয়, তবে এটি `true` রিটার্ন করবে; অন্যথায় `false` রিটার্ন করবে।
`==` অপারেটর যেকোনো টাইপের মানের সাথে যেকোনো অন্য টাইপের মান তুলনা করতে পারে।
`!=` একইভাবে কাজ করে, তবে মানগুলো সমান না হলে `true` এবং সমান হলে `false` রিটার্ন করবে।

## স্পেসশিপ অপারেটর

স্পেসশিপ অপারেটর একটি অনন্য তুলনা অপারেটর, আর এর নাম এসেছে এটা দেখতে কেমন তা থেকে।
এটি অনন্য এই অর্থে যে এটি ট্রুথি বা ফলসি মান রিটার্ন করে না, বরং একটি সংখ্যা রিটার্ন করে।
এটি `<=>` হিসেবে লেখা হয় এবং দুটি মান তুলনা করতে ব্যবহৃত হয়।
বাম মান ডান মানের চেয়ে বড় হলে এটি `1` রিটার্ন করবে, বাম মান ডান মানের চেয়ে ছোট হলে `-1`, আর মানগুলো সমান হলে `0`।

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## if স্টেটমেন্ট

[`if`][if] স্টেটমেন্ট একটি প্রদত্ত শর্ত ট্রুথি বা ফলসি কি না তা যাচাই করতে ব্যবহৃত হয়।
শর্তটি ট্রুথি হলে `if` স্টেটমেন্টের ভেতরের কোড চলবে।
একটি `if` স্টেটমেন্ট `end` কিওয়ার্ড দিয়ে শেষ হয়।

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## unless স্টেটমেন্ট

[`unless`][unless] স্টেটমেন্ট `if` স্টেটমেন্টের মতোই কাজ করে, তবে শর্তটি ফলসি হলে এটি `unless` স্টেটমেন্টের ভেতরের কোড চালাবে।

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## else স্টেটমেন্ট

`else` স্টেটমেন্ট `if` ও `unless` স্টেটমেন্টের সাথে একসাথে ব্যবহার করা যায়।
`if` শাখা বা `unless` শাখা চালানো না হলে `else` স্টেটমেন্ট চালানো হবে।

~~~~exercism/warning
যদিও `unless,`-এর সাথে একটি `else` শাখা ব্যবহার করা যায়, তবে এটি করতে নিরুৎসাহিত করা হয় কারণ এটি পাঠযোগ্যতা নষ্ট করে।
এর বদলে `if !condition`-এর সাথে একটি else শাখা ব্যবহার করার সুপারিশ করা হয়।
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## "ক্যাসকেডিং-if" স্টেটমেন্ট

`elsif` স্টেটমেন্ট if স্টেটমেন্টের সাথে একসাথে ব্যবহার করা যায়।
if শাখা চালানো না হলে এবং `elsif` স্টেটমেন্টের শর্ত ট্রুথি হলে `elsif` স্টেটমেন্ট চালানো হবে।
`elsif` স্টেটমেন্টগুলো একসাথে চেইন করা যায় এবং প্রথম ট্রুথি শর্তটি চালানো হবে।
if স্টেটমেন্টের শেষে একটি else স্টেটমেন্টও থাকতে পারে, যা আগের কোনো স্টেটমেন্ট ট্রু না হলে চলবে।

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## টার্নারি অপারেটর

Crystal-এ একটি টার্নারি অপারেটর আছে, এটি এক লাইনের if-else স্টেটমেন্ট: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## সাফিক্স হিসেবে if ও unless

if ও unless স্টেটমেন্ট [সাফিক্স][if-as-suffix] হিসেবেও ব্যবহার করা যায়; কোনো শর্ত ট্রু হলে এক লাইনের কোড চালাতে চাইলে এটি কাজে লাগে।
এটি করা হয় আপনি যে কোডটি চালাতে চান তার পরে if বা unless স্টেটমেন্ট বসিয়ে।

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## শর্তযুক্ত টাইপ

ভিন্ন টাইপে অ্যাসাইন করা হলে ভ্যারিয়েবলটি দুটি টাইপই বহন করবে।
এর কারণ কম্পাইলার জানে না কোন শাখা চালানো হবে।
এই একাধিক অ্যাসাইনমেন্ট, যাকে ইউনিয়নও বলা হয়, পরের ধারণাগুলোতে ব্যাখ্যা করা হবে।
এটি নিচের উদাহরণে দেখা যায়:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
