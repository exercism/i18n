# প্লেসহোল্ডার

## সময় ফাংশন

এই অনুশীলনীতে GNU awk-এর [সময় ফাংশন][time-func] ব্যবহার করা প্রয়োজন।

ডেটটাইম পার্সিং ও ফরম্যাটিং ফাংশনগুলোর জন্য অবশ্যই **UTC ফ্ল্যাগ সেট করুন**।
উদাহরণস্বরূপ:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

আউটপুট:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
