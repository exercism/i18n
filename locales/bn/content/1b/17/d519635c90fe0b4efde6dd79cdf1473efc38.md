# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নিতে সাহায্য করার জন্য একটি প্রোগ্রাম লিখবেন।

আপনার দুটি কাজ আছে: আপনার লাইসেন্স নিতে হবে কি না তা নির্ধারণ করা, এবং একটি ব্যবহৃত যানবাহনের জন্য গ্রহণযোগ্য দাম অনুমান করা।

## 1. আপনার ড্রাইভার লাইসেন্স লাগবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালানোর জন্য ড্রাইভার লাইসেন্স প্রয়োজন।
ধরে নিন যে কেবল `car` বা `truck` থাকা যানবাহনেরই লাইসেন্স প্রয়োজন; বাকি সবকিছু লাইসেন্স ছাড়াই চালানো যায়।

এমন একটি `pattern {action}` জোড়া ইমপ্লিমেন্ট করুন যা তখন মিলে যখন প্রথম ফিল্ডটি `needs_license` হয়।
এটি দ্বিতীয় ফিল্ড থেকে যানবাহনের ধরনটি নেবে, এবং ওই ধরনের যানবাহনের জন্য আপনার লাইসেন্স প্রয়োজন হলে "true" প্রিন্ট করবে।
আপনার লাইসেন্স প্রয়োজন না হলে, কিছু প্রিন্ট করার দরকার নেই।

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. ব্যবহৃত যানবাহনের দামের একটি অনুমান হিসাব করুন

এখন যেহেতু আপনি সিদ্ধান্ত নিয়ে ফেলেছেন, আপনি নিশ্চিত করতে চান যে ডিলারশিপে আপনি ন্যায্য দাম পাচ্ছেন।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, দামটি নির্ভর করে যানবাহনটির বয়স কত তার উপর।
মোটামুটি একটি অনুমানের জন্য ধরে নিন, যানবাহনটির বয়স ৩ বছরের কম হলে, নতুন অবস্থায় তার যে মূল দাম ছিল তার ৮০% দাম পড়বে।
এটির বয়স ১০ বছরের বেশি হলে, দাম পড়বে ৫০%।
যানবাহনটির বয়স যদি কমপক্ষে ৩ বছর হয় কিন্তু ১০ বছরের বেশি না হয়, তবে মূল দামের ৭০% দাম পড়বে।

এমন একটি `pattern {action}` জোড়া ইমপ্লিমেন্ট করুন যা তখন মিলে যখন প্রথম ফিল্ডটি `resell_price` হয়।
এটি দ্বিতীয় ফিল্ড থেকে যানবাহনটির মূল দাম নেবে, এবং তৃতীয় ফিল্ড থেকে বয়সটি নেবে।
অ্যাকশনটি অনুমানকৃত দামটি প্রিন্ট করবে।

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
