# নির্দেশনা

এই অনুশীলনীতে আপনি Exercism প্ল্যাটফর্ম থেকে যে প্রোগ্রামিং ভাষাগুলো অনুশীলন করার পরিকল্পনা করছেন, সেগুলোর একটি অ্যারে প্রসেস করার কোড লিখবেন।

আপনার ছয়টি কাজ আছে।

## 1. একটি নতুন অ্যারে তৈরি করুন

ভাষা যোগ করার আগে, আপনাকে প্রথমে একটি নতুন অ্যারে তৈরি করে শুরু করতে হবে। এমন একটি ফাংশন ডিফাইন করুন যা একটি খালি অ্যারে রিটার্ন করে।

```clojure
(new-list)
;; => ()
```

## 2. অ্যারেতে একটি নতুন ভাষা যোগ করুন

আপনি যখন Exercism ঘুরে দেখবেন এবং শিখতে চান এমন ভাষা খুঁজে পাবেন, তখন সেগুলো আপনার অ্যারেতে যোগ করতে পারার সুবিধা দরকার হবে। আপনার অ্যারের শুরুতে একটি নতুন ভাষা যোগ করার জন্য একটি ফাংশন ডিফাইন করুন।

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. সর্বশেষ যোগ করা ভাষাটি যাচাই করুন

আপনি এইমাত্র কোন ভাষাটি যোগ করলেন, তা দ্রুত যাচাই করতে চাইবেন। এমন একটি ফাংশন ডিফাইন করুন যা আপনার অ্যারে থেকে প্রথম ভাষাটি রিটার্ন করে।

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. অ্যারে থেকে প্রথম ভাষাটি সরিয়ে ফেলুন

মাঝে মাঝে এইমাত্র যোগ করা কোনো ভাষা নিয়ে আপনার মন বদলে যেতে পারে। আপনার অ্যারে থেকে প্রথম ভাষাটি সরিয়ে ফেলার জন্য একটি ফাংশন ডিফাইন করুন।

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. অ্যারেতে ভাষাগুলো গণনা করুন

ভাষাগুলো এক এক করে গণনা করা অসুবিধাজনক। আপনার অ্যারেতে থাকা ভাষার সংখ্যা গণনা করার জন্য একটি ফাংশন ডিফাইন করুন।

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. সবকিছু একসাথে জোড়া লাগান

একটি `learning-list` ফাংশন ডিফাইন করুন, যার ভেতরে আপনি উপরে ডিফাইন করা কিছু ফাংশন ব্যবহার করবেন।

- একটি খালি অ্যারে তৈরি করুন
- অ্যারেতে ২টি নতুন প্রোগ্রামিং ভাষা যোগ করুন।

  - "Clojure"
  - "Lisp"

- অ্যারে থেকে "Lisp" সরিয়ে ফেলুন, কারণ বছরের জন্য আপনার যথেষ্ট সময় নাও থাকতে পারে, আর এটি Clojure-এর সাথে বেশ মিলও আছে।
- অ্যারেতে আরও ২টি প্রোগ্রামিং ভাষা যোগ করুন।

  - "Java"
  - "JavaScript"

- মোট ভাষার সংখ্যা রিটার্ন করুন। ইঙ্গিত: এটি ৩ হওয়া উচিত।

```clojure
(learning-list)
;; => 3
```
