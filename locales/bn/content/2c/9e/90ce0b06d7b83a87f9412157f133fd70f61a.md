# `case` স্টেটমেন্ট

যখন একটি মানকে সম্ভাবনার একটি তালিকার সঙ্গে তুলনা করা হয়, তখন একের পর এক `elsif`-এর শৃঙ্খল একই কথাই বারবার বলে:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` কথাটি বলে একবারেই:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

মানটি বসে `case`-এর পরে। প্রতিটি `when` তুলনা করার জন্য একটি মান দেয়, আর যেটি প্রথমে মেলে সেটিই চলে।

## এক `when`-এ একাধিক মান

একটি `when`-এ কমা দিয়ে আলাদা করে একাধিক মান লেখা যায়:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

এটি ইন্টিজার, ক্যারেক্টার আর স্ট্রিং-এ কাজ করে, অর্থাৎ যা কিছু `=` দিয়ে তুলনা করা যায়।

## `else` ঐচ্ছিক নয়

**যে `case` কোনো কিছু মেলাতে পারে না আর যার `else` নেই, সেটি একটি এরর, যা ঘটলে প্রোগ্রাম থেমে যায়।**

এটি `if`-এর থেকে আলাদা, যেখানে `else` না লিখলে কেবল কিছুই ঘটে না। এটি বেশিরভাগ প্রোগ্রামিং ভাষার থেকেও আলাদা, যেখানে কোনো কিছু না মেলা `case` চুপচাপ কিছুই করে না।

তাই প্রতিটি `case`-এর একটি `else` দরকার, এমনকি যখন আপনি নিশ্চিত যে `when` অংশগুলো ইতিমধ্যেই প্রতিটি মান কভার করে রেখেছে। পরে একটি চতুর্থ জোন যোগ করা হয়, সেটির সঙ্গে মিলিয়ে `case` হালনাগাদ করা হয় না, আর যে প্রথম যাত্রী সেটি ব্যবহার করে তার কাছেই প্রোগ্রাম থেমে যায়।

## একটিমাত্র `when` চলে

কোনো `when` মিলে গেলে তার `then`-এর পরের স্টেটমেন্টগুলো চলে এবং `case` শেষ হয়ে যায়, আর প্রোগ্রাম `end`-এর পরে চলতে থাকে। তার নিচের `when` অংশগুলো আর দেখা হয় না, তাই পরেরটিও যাতে না চলে সেজন্য আপনাকে কিছু লিখতে হয় না।
