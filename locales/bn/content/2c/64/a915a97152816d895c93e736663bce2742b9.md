# ভূমিকা

একটি স্ট্যাটিক এক্সটেনশন বিদ্যমান টাইপগুলোর সোর্স পরিবর্তন না করেই সেগুলোকে ছদ্মভাবে এক্সটেন্ড করার সুযোগ দেয়। এটি করা হয় `using` স্টেটমেন্ট ব্যবহার করে। স্ট্যাটিক এক্সটেনশন একটি শক্তিশালী হাতিয়ার হতে পারে, যার সাহায্যে টাইপগুলোকে আসলে পরিবর্তন না করেই সেগুলোকে বর্ধিত করা যায়।

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
