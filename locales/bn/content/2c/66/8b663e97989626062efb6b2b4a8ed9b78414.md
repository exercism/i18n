# নির্দেশনা

আপনি একটি সিস্টেম তৈরি করছেন, যা একটি ফুটবল ক্লাবের ওয়েবসাইটের কর্মীদের ম্যাচের রিপোর্ট করতে সাহায্য করবে। বিভিন্ন সোর্স থেকে ডেটা আসে এবং পরিষ্কার করার পর সেগুলো একটি একক স্ট্রিমে পাইপ করা হয়।

## 1. জার্সি নম্বরের ভিত্তিতে খেলোয়াড়দের বিবরণ আউটপুট করুন

দলটি কেবল ৪-৩-৩ ফর্মেশনেই খেলে এবং খেলোয়াড় বদলের অনুমতি দেওয়া ১৯৬৫ সালের নিয়ম পরিবর্তনটি তারা কখনো মেনে নেয়নি, বড় স্কোয়াডের কথা তো দূরের কথা।

খেলোয়াড়দের বিবরণ নিচে দেওয়া হলো:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

জার্সি নম্বরের ভিত্তিতে খেলোয়াড়ের বিবরণ আউটপুট দেওয়ার জন্য স্ট্যাটিক `FootballMatchReports.onField()` মেথডটি ইমপ্লিমেন্ট করুন।

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. জার্সি নম্বরটি অফিসিয়াল তালিকার অংশ না হলে "invalid" আউটপুট করুন

১-১১ রেঞ্জের বাইরের কোনো জার্সি নম্বর প্রসেস করা হলে 'invalid' রিটার্ন করার জন্য `FootballMatchReports.onField()` মেথডটি পরিবর্তন করুন।

```java
FootballMatchReports.onField(13);
// => "invalid"
```
