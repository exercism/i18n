# পরিচিতি

## বুলিয়ান

ট্রু ও ফলস মান প্রকাশ করতে PowerShell-এ [`bool`][booleans] টাইপটি রয়েছে।
এই টাইপে মাত্র দুটি মান থাকে: `True` এবং `False`।
আপনি `$` প্রিফিক্স দিয়ে এই মানগুলো ভ্যারিয়েবলে বেঁধে রাখতে পারেন:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

বুলিয়ান এক্সপ্রেশন একত্রিত করতে ও মূল্যায়ন করতে আমরা `-and`, `-or` ও `-not`-এর মতো [লজিক্যাল অপারেটর][logical-operators] ব্যবহার করতে পারি।

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## রূপান্তর ও ট্রুথিনেস

PowerShell যেকোনো টাইপকে অন্তর্নিহিতভাবে বুলিয়ান হিসেবে ধরতে পারে।
তবে আপনি স্পষ্ট রূপান্তরের জন্য বুলিয়ান টাইপ অ্যাক্সিলারেটর `[bool]`-ও ব্যবহার করতে পারেন।

অন্য টাইপকে বুলিয়ান মানে রূপান্তর করতে PowerShell যে কয়েকটি সাধারণ নিয়ম ব্যবহার করে, তা নিচে দেওয়া হলো:

$false:
- খালি স্ট্রিং, যেমন `''` বা `""`
- নাল মান, যেমন `$null`
- শূন্য (0) মানের সংখ্যাগত টাইপ

$true:
- খালি নয় এমন স্ট্রিং
- অন্য যেকোনো নন-কলেকশন টাইপের ইনস্ট্যান্স

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

কলেকশন টাইপ থেকে বুলিয়ান মান রূপান্তরের বিস্তারিত নিয়ম জানতে [এখানে][collection-conversion] পড়ুন।
