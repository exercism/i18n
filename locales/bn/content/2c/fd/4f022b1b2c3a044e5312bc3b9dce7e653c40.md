# কাজ

কাজ হলো এমন GitHub ইস্যু, যেগুলোতে আমরা মানুষের সাহায্য চাই, টেক্সট প্রুফরিড করা থেকে শুরু করে কনসেপ্ট অনুশীলনী তৈরি করা পর্যন্ত।
এগুলো ওয়েবসাইটে দেখানো হয় এবং সংশ্লিষ্ট GitHub ইস্যুতে লিংক করে।
প্রতিটি কাজে এক বা একাধিক প্রপার্টি ট্যাগ থাকে, যেগুলো ইস্যুর লেবেল থেকে নেওয়া হয়।
এরপর ব্যবহারকারী প্রপার্টি অনুযায়ী কাজ ফিল্টার করতে পারেন।

## ট্যাগ

কোনো ইস্যুকে কাজ হিসেবে গণ্য করতে হলে সেটিতে এক বা একাধিক কাজ-সংক্রান্ত লেবেল থাকতে হবে।
এভাবে মেইনটেইনাররা চাইলে শুধু কিছু ইস্যুকে কাজ হিসেবে দেখাতে পারেন।

প্রতিটি কাজের লেবেল এভাবে সংজ্ঞায়িত: `x:<type>/<value>`, এবং পাঁচটি কাজের টাইপ সমর্থিত:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### অ্যাকশন ট্যাগ

`x:action/<value>` লেবেলগুলো বোঝায়, ইস্যুতে কাজ করার সময় অবদানকারী কী ধরনের কাজে যুক্ত হবেন।

| ট্যাগ               | বিবরণ                                  |
| -------------------- | -------------------------------------- |
| `x:action/create`    | একেবারে শূন্য থেকে কিছু তৈরি করা        |
| `x:action/fix`       | একটি ইস্যু ঠিক করা                      |
| `x:action/improve`   | বিদ্যমান ফাংশনালিটি/কনটেন্ট উন্নত করা   |
| `x:action/proofread` | টেক্সট প্রুফরিড করা                     |
| `x:action/sync`      | কনটেন্টকে তার সর্বশেষ ভার্সনের সাথে সিঙ্ক করা |

### নলেজ ট্যাগ

`x:knowledge/<value>` লেবেলগুলো বোঝায়, অবদানকারীর কতটা Exercism জ্ঞান প্রয়োজন।

| ট্যাগ                      | বিবরণ                                      |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | Exercism-এর আগের কোনো জ্ঞান প্রয়োজন নেই    |
| `x:knowledge/elementary`   | Exercism-এর সামান্য জ্ঞান প্রয়োজন           |
| `x:knowledge/intermediate` | Exercism-এর যথেষ্ট জ্ঞান প্রয়োজন            |
| `x:knowledge/advanced`     | Exercism-এর ব্যাপক জ্ঞান প্রয়োজন            |

### মডিউল ট্যাগ

`x:module/<value>` লেবেলগুলো নির্দেশ করে, অবদানকারী Exercism-এর কোন অংশে কাজ করবেন।

| ট্যাগ                        | বিবরণ                       |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | অ্যানালাইজার নিয়ে কাজ       |
| `x:module/concept`           | কনসেপ্ট নিয়ে কাজ            |
| `x:module/concept-exercise`  | কনসেপ্ট অনুশীলনী নিয়ে কাজ   |
| `x:module/generator`         | অনুশীলনী জেনারেটর নিয়ে কাজ  |
| `x:module/practice-exercise` | প্র্যাকটিস অনুশীলনী নিয়ে কাজ |
| `x:module/representer`       | রিপ্রেজেন্টার নিয়ে কাজ      |
| `x:module/test-runner`       | টেস্ট রানার নিয়ে কাজ        |

### সাইজ ট্যাগ

`x:size/<value>` লেবেলগুলো বোঝায়, একজন অবদানকারীর জন্য প্রত্যাশিত কাজের পরিমাণ।

| ট্যাগ            | বিবরণ                 |
| ---------------- | --------------------- |
| `x:size/tiny`    | খুব অল্প কাজ          |
| `x:size/small`   | অল্প কাজ              |
| `x:size/medium`  | মাঝারি পরিমাণ কাজ     |
| `x:size/large`   | বেশ কিছু কাজ          |
| `x:size/massive` | প্রচুর কাজ            |

### টাইপ ট্যাগ

`x:type/<value>` লেবেলগুলো বোঝায়, অবদানকারী কী ধরনের কাজে যুক্ত হবেন।

| ট্যাগ            | বিবরণ                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | কন্টিনিউয়াস ইন্টিগ্রেশন (CI) নিয়ে কাজ (যেমন GitHub Actions ওয়ার্কফ্লো)                                                                                                                                     |
| `x:type/coding`  | শিক্ষার্থীদের জন্য তৈরি কনটেন্টের অংশ নয়, এমন কোড লেখা। সাধারণত এগুলো প্রোডাকশন টুলিং (যেমন টেস্ট রানার), ইন্টারনাল টুলিং (জেনারেটর), বা Exercism যে লাইব্রেরিগুলো রক্ষণাবেক্ষণ করে সেগুলোর সাথে সম্পর্কিত কাজ। |
| `x:type/content` | কনটেন্ট নিয়ে কাজ (যেমন অনুশীলনী, কনসেপ্ট)                                                                                                                                                                     |
| `x:type/docker`  | Dockerfiles নিয়ে কাজ                                                                                                                                                                                            |
| `x:type/docs`    | ডকুমেন্টেশন নিয়ে কাজ                                                                                                                                                                                          |

## দাবি করা বনাম দাবি না করা ট্যাগ

কেউ ইতিমধ্যেই কাজ করছেন বলে কোনো কাজ লুকাতে চাইলে, ইস্যুতে `x:status/claimed` লেবেল যোগ করা যেতে পারে।
