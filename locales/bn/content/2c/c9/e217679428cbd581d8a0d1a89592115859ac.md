# সম্পর্কে

শর্ত অনুযায়ী কোড চালানো [`if/elif/else` এক্সপ্রেশন][conditional-expression] ব্যবহার করে করা যায়। একটি `if/elif/else` এক্সপ্রেশনে ব্যবহৃত শর্তগুলো অবশ্যই `bool` টাইপের হতে হবে। F#-এ _truthy_ মানের কোনো ধারণা নেই।

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

যেহেতু `if/elif/else` একটি এক্সপ্রেশন, তাই এটি একটি নামে অ্যাসাইন করা যায় বা কোনো ফাংশন থেকে রিটার্ন করা যায়।

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

সব শাখাকেই একই টাইপ রিটার্ন করতে হবে। তা না করলে কম্পাইলার এরর হয়:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

`else` ও `elif` শাখা ঐচ্ছিক, তবে কেবল তখনই যখন রিটার্ন করা এক্সপ্রেশনের টাইপ [`unit`][unit-type] হয়।

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

একটি `if/else` এক্সপ্রেশন এক লাইনেও লেখা যায়। এটি কেবল সাধারণ `if` এক্সপ্রেশনের ক্ষেত্রেই ব্যবহার করা উচিত।

```fsharp
let y = if x > 5 then 10 else 20
```
