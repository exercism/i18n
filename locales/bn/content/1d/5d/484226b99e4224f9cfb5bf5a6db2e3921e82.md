# সম্পর্কে

C++-এ একটি `string` হলো পরিবর্তনযোগ্য অবজেক্ট, যা টেক্সটকে ক্যারেক্টারের (অক্ষর, সংখ্যা, যতিচিহ্ন ইত্যাদি) একটি ক্রম হিসেবে প্রকাশ করে। স্ট্রিংয়ের মেথড কল করে স্ট্রিং নিয়ে কাজ করা হয়।

## স্ট্রিং লাইব্রেরি

C++-এ ব্যবহারের আগে স্ট্রিং টাইপ ও তার সংশ্লিষ্ট ফাংশনগুলো স্ট্রিং লাইব্রেরি থেকে ইনক্লুড করতে হয়।
আপনি আপনার ফাইলের শুরুতে `#include <string>` যোগ করে এটি করতে পারেন।
এরপর সেগুলো `std` নেমস্পেসে যুক্ত হয়ে যাবে।
স্ট্রিং লিটারাল ডাবল কোট ক্যারেক্টার ব্যবহার করে: `"`।

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## স্ট্রিংয়ের সাধারণ অপারেশন

স্ট্রিং জোড়া লাগাতে আপনি `+` অপারেটর ব্যবহার করতে পারেন:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

স্ট্রিং লাইব্রেরি ব্যবহার করতে হলে জানা দরকার, কোনো অবজেক্টের অন্তর্গত ফাংশনও কল করা সম্ভব।
এদের মেম্বার ফাংশন বলা হয়।
পরে সিলেবাসে আপনি মেম্বার ফাংশন এবং তার সাথে জড়িত ক্লাস কনসেপ্ট সম্পর্কে আরও শিখবেন।

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


`find` ফাংশনটিও খুব কাজের।
এটি স্ট্রিংয়ের উপর একটি মেম্বার ফাংশন হিসেবে কল করা হয় এবং আর্গুমেন্ট হিসেবে একটি স্ট্রিং নেয়।
`find` স্ট্রিংয়ের ভেতরে প্রথম যে জায়গায় এটি পাওয়া যায়, তার শূন্য-ভিত্তিক অবস্থান রিটার্ন করে।

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

এছাড়া `to_string` ফাংশনও আছে, যা ইন্টিজার এবং ফ্লোট/ডাবল মানকে স্ট্রিংয়ে রূপান্তর করতে ব্যবহার করা যায়।
`to_string` একটি স্ট্রিং রিটার্ন করে।

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
