# পরিচিতি

ফ্যান্টম টাইপ হলো একটি কাস্টম টাইপের টাইপ প্যারামিটার, যেগুলো সেই টাইপের কোনো ভ্যালু কনস্ট্রাক্টরে ব্যবহৃত হয় না।

এটা একটু বিমূর্ত, তাই একটি উদাহরণ দেখা যাক:

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

এই উদাহরণে `unit` টাইপ প্যারামিটারটি `Length` ভ্যালু কনস্ট্রাক্টরে ব্যবহৃত হয়নি, তাই `unit` একটি ফ্যান্টম টাইপ।

এই অব্যবহৃত টাইপ প্যারামিটারটি হয়তো অপ্রয়োজনীয় মনে হতে পারে, তবে `Length` মানগুলো কীভাবে ব্যবহার করা যাবে তার উপর আরও কিছু বিধিনিষেধ আরোপ করতে এটি ব্যবহার করা যায়।

উদাহরণস্বরূপ, আমাদের একটি `double` ফাংশন থাকতে পারে, যা দৈর্ঘ্যকে গুণ করে। এটি যেকোনো ইউনিটের দৈর্ঘ্যের সাথে কাজ করে, তাই টাইপ প্যারামিটারটি একটি জেনেরিক টাইপ ভ্যারিয়েবল।

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

আমাদের একটি `add_inch` ফাংশনও থাকতে পারে, যা কেবল তখনই কাজ করে যখন দৈর্ঘ্যটি ইঞ্চিতে হয়।

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

`add_inch` ফাংশনটি অন্য কোনো ইউনিট প্যারামিটারের দৈর্ঘ্য গ্রহণ করবে না; সঠিক ইউনিটই ব্যবহৃত হয় তা নিশ্চিত করতে ফ্যান্টম টাইপটি ব্যবহার করা হয়েছে।

একই টাইপ ভ্যারিয়েবল দুটির জন্যই ব্যবহার করে, দুটি দৈর্ঘ্যের মান একই ইউনিটের কি না তা নিশ্চিত করার জন্য একটি ফাংশনও লেখা যায়।

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

ফ্যান্টম টাইপ অপেক টাইপের সাথে ভালোভাবে কাজ করতে পারে। যদি অন্য মডিউলগুলো `Length` মান তৈরি করতে না পারে, তাহলে আমরা নিশ্চিত করতে পারি যে সেগুলো কোনো অবৈধ ইউনিট টাইপ দিয়ে তৈরি হয়নি, এবং সেগুলোর সাথে কেবল উপরে ডিফাইন করা ফাংশনগুলোই ব্যবহার করা যায়।
