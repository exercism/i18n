# পরিচিতি

প্যাটার্ন ম্যাচিং হলো এমন একটি প্রক্রিয়া যেখানে একটি মান নির্দিষ্ট, প্রয়োজনে গভীর প্যাটার্নের সাথে মেলে কি না, তার উপর নির্ভর করে শাখা তৈরি করা হয়। Haxe-এ **প্যাটার্ন ম্যাচিং** করা হয় `switch` এক্সপ্রেশন এবং আলাদা আলাদা `case` এক্সপ্রেশন দিয়ে।

এই ডেটা স্ট্রাকচারটি লক্ষ্য করুন:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- প্যাটার্নগুলো সবসময় উপর থেকে নিচে মেলানো হয়।
- ইনপুট মানের সাথে যে প্যাটার্নটি সবার উপরে মেলে, তার এক্সপ্রেশনটিই চালানো হয়।
- `_` প্যাটার্ন যেকোনো কিছুর সাথে মেলে, তাই `case _:` আর `default:` একই কথা।

## ইনাম ম্যাচিং

ইনামগুলোকে তাদের কনস্ট্রাক্টর দিয়েই সহজে মেলানো যায়:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
