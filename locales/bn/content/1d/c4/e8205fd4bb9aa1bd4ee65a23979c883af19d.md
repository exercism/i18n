# পরিচিতি

জাভা স্ট্রিং সম্পর্কে মনে রাখার মূল বিষয়টি হলো, এগুলো ইমিউটেবল অবজেক্ট, যা ইউনিকোড ক্যারেক্টারের একটি ক্রম (অক্ষর, সংখ্যা, যতিচিহ্ন ইত্যাদি) হিসেবে টেক্সট প্রকাশ করে। একটি `String` ইনস্ট্যান্স ডিফাইন করতে ডাবল কোট ব্যবহার করা হয়:

```java
String fruit = "Apple";
```

[`String`][string-class] ক্লাসের মেথড ব্যবহার করে একটি স্ট্রিং ম্যানিপুলেট করা যায়। যেহেতু ডিফাইন করার পর স্ট্রিং মান কখনোই বদলাতে পারে না, তাই সব স্ট্রিং ম্যানিপুলেশন মেথডই একটি নতুন স্ট্রিং রিটার্ন করে।

একটি স্ট্রিং ডাবল কোট (`"`) ক্যারেক্টার দিয়ে ঘেরা থাকে। কিছু বিশেষ ক্যারেক্টার ব্যাকস্ল্যাশ (`\`) ক্যারেক্টার দিয়ে এস্কেপ করতে হয়। জাভায় যে ক্যারেক্টারগুলো এস্কেপ করতে হয়:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

সবশেষে, একটি স্ট্রিং কনক্যাটেনেট করার অনেক উপায় আছে। সবচেয়ে সহজ উপায়টি হলো `+` অপারেটর:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

সাধারণ কনক্যাটেনেশনের চেয়ে জটিল যেকোনো স্ট্রিং ফরম্যাটিংয়ের জন্য `String.format` মেথডটি ব্যবহার করাই ভালো।

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

আরও কয়েকটি সম্ভাবনা হলো:

- [`StringBuilder` ক্লাস][string-builder] ব্যবহার করা
- [`String.concat` মেথড][string-concat] ব্যবহার করা
