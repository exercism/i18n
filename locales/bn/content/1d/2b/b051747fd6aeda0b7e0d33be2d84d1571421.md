# নির্দেশাবলির সংযোজন

## আউটপুট ফরম্যাট

গানের কথাগুলো একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে আউটপুট করুন।

## রেজিস্টার

| Register | Usage        | Type    | Description                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | input        | integer | শুরুর বোতল সংখ্যা                |
| `$a1`    | input        | integer | যত বোতল নামাতে হবে                |
| `$a2`    | input/output | address | নাল-টার্মিনেটেড আউটপুট স্ট্রিং      |
| `$t0-9`  | temporary    | any     | সাময়িকভাবে সংরক্ষণের জন্য         |
