# পরিচিতি

## টেইল কল অপটিমাইজেশন

প্রতিবার একটি ফাংশন কল করা হলে মেমরিতে একটি নতুন স্ট্যাক ফ্রেম তৈরি হয়, যেখানে ফাংশনের আর্গুমেন্ট ও লোকাল ভ্যারিয়েবলগুলো সংরক্ষণ করা হয়, আর ফাংশনটি রিটার্ন করলে এই স্ট্যাক ফ্রেমটি ডি-অ্যালোকেট হয়ে যায়। Gleam লুপিং সিনট্যাক্সের বদলে রিকার্সিভ ফাংশন কল ব্যবহার করে, তাই এই স্ট্যাক ফ্রেমগুলো প্রচুর মেমরি দখল করে ফেলতে পারে।

এই সমস্যা এড়াতে Gleam টেইল কল অপটিমাইজেশন সমর্থন করে, যা কম্পাইলারকে বর্তমান ফাংশনের স্ট্যাক ফ্রেম আবার ব্যবহার করতে দেয়, যদি ফাংশনটি সর্বশেষ যে কাজটি করে তা একটি ফাংশন কল হয়। এর মানে হলো, একটি ফাংশন নিজেকে অসীমবার কল করতে পারে, বাড়তি কোনো মেমরি ব্যবহার না করেই।

অপটিমাইজড নয় এমন রিকার্সিভ ফাংশনকেও প্রায়ই একটি _অ্যাকুমুলেটর_ ব্যবহার করে টেইল কল অপটিমাইজড ফাংশনে রূপান্তর করা যায়।

অ্যাকুমুলেটর হলো একটি ভ্যারিয়েবল, যা ডেটার পাশাপাশি বাড়তি হিসেবে পাঠানো হয়। এটি ফাংশনের নির্বাহের বর্তমান অবস্থা বহন করতে ব্যবহৃত হয়, যতক্ষণ না বেস কেসে পৌঁছানো যায়।

অ্যাকুমুলেটর ইনিশিয়ালাইজ করা উচিত ফাংশনের লেখকের, ফাংশনের ব্যবহারকারীর নয়। এটি করার জন্য দুটি ফাংশন ডিক্লেয়ার করুন: একটি পাবলিক ফাংশন, যা আর্গুমেন্ট হিসেবে শুধু প্রয়োজনীয় ডেটা নেয় এবং অ্যাকুমুলেটর ইনিশিয়ালাইজ করে, আর একটি প্রাইভেট ফাংশন, যা একটি অ্যাকুমুলেটরও নেয়।

```gleam
// Count the length of a list without tail call optimisation
pub fn count(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> {
      let amount = count(rest) // Non-tail recursive call
      amount + 1
    }
  }
}
```

```gleam
// Count the length of a list with tail call optimisation
pub fn count(list: List(String)) -> Int {
  count_elements(list, 0)
}

fn count_elements(list: List(String), accumulator: Int) -> Int {
  case list {
    [] -> accumulator
    [_, ..rest] -> {
      let accumulator = accumulator + 1
      count_elements(rest, accumulator) // Tail recursive call
    }
  }
}
```
