# পরিচিতি

## শর্তাধীন স্টেটমেন্ট

শর্তাধীন স্টেটমেন্ট হলো সিদ্ধান্ত গ্রহণের স্টেটমেন্ট, যেগুলো হয় সাইড-ইফেক্ট ঘটাতে পারে, নয়তো একটি প্রোগ্রামের এক্সিকিউশন প্রবাহ নিয়ন্ত্রণ করতে পারে।
শর্তাধীন স্টেটমেন্টের মধ্যে আছে `if`, `if/else`, `switch` এবং `ternary` স্টেটমেন্ট।

শর্তাধীন স্টেটমেন্ট ব্যবহার করা হয় কোনো মান বা মানগুলোর সম্পর্ক নিয়ে প্রশ্ন করতে।
প্রশ্নটির মূল্যায়ন একটি বুলিয়ান উত্তরে রূপ নেয়, কিন্তু `if` স্টেটমেন্ট নিজেই যেকোনো মান রিটার্ন করতে পারে, অথবা শুধু একটি সাইড-ইফেক্ট ঘটাতে পারে।

## if স্টেটমেন্ট

সবচেয়ে সরল `if` স্টেটমেন্ট একটি এক্সপ্রেশন মূল্যায়ন করে এবং একটি লাইন চালায়।
যে এক্সপ্রেশনটি পরীক্ষা করা হয়, সেটি সবসময় প্রথম বন্ধনীর ভেতরে থাকে।

এটি একটি সাইড-ইফেক্ট ঘটাতে পারে

```c
if (count > 10)
    printf("count is greater than 10");
```

অথবা এটি এক্সিকিউশনের প্রবাহ বদলাতে পারে


```c
if (count > 10)
    return sum;
```

যদি একটি `if` স্টেটমেন্ট একাধিক লাইন চালায়, তবে এটিকে লাইনগুলো কোঁকড়ানো বন্ধনীর ভেতরে রাখতে হবে

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

কিছু কোডিং টিম স্ট্যান্ডার্ডাইজ করতে পারে যে `if` স্টেটমেন্টে সবসময় কোঁকড়ানো বন্ধনী ব্যবহার করা উচিত, এক লাইনের ক্ষেত্রেও।


## if else

একটি `if` স্টেটমেন্টের সাথে একটি `else` যুক্ত করা যায়

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if else if


`else`-কে আরেকটি `if`-এর সাথে জুড়ে যা তৈরি করা যায়, তাকে বলা হয় `if-else-if ladder`।

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


কখনও কখনও একটি `if-else-if ladder`-কে `switch` দিয়ে আরও ভালোভাবে উপস্থাপন করা যায়।
`if`-এর মতো, যে এক্সপ্রেশনটি পরীক্ষা করা হয় সেটি সবসময় প্রথম বন্ধনীর ভেতরে রাখা হয়।

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default` কেসটি এক্সিকিউট হয় যদি পরীক্ষা করা মানটি আগের কোনো কেসের সাথে না মেলে।

যদি একটি `switch` কেস রিটার্ন না করে, তাহলে সাধারণত প্রতিটি কেস শেষ করতে একটি `break` বসানো হয়; অন্যথায় লজিক পরের কেসে "ফলথ্রু" করে।
কখনও কখনও ফলথ্রু ইচ্ছাকৃতভাবে ব্যবহার করা হয়

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

যখন ফলথ্রু অনিচ্ছাকৃতভাবে ঘটে, তখন এটি একটি bug।

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

নির্দিষ্ট কিছু মানের বিরুদ্ধে পরীক্ষা করার সময় মানের পরিসরের বদলে switch সুবিধাজনক হতে পারে।
এটি `if-else-if ladder`-এর চেয়ে দ্রুত হতে পারে, কারণ কম্পাইলার `switch` স্টেটমেন্টটি এমনভাবে অপটিমাইজ করতে পারে যা একটি ladder-এর ক্ষেত্রে করতে পারে না।
switch কখনও কখনও ladder-এর চেয়ে বেশি পাঠযোগ্য দেখাতে পারে।

## টার্নারি (অর্থাৎ শর্তাধীন) অপারেটর

টার্নারি অপারেটর হলো তিন অংশের একটি শর্তাধীন স্টেটমেন্ট, যা প্রায়ই একটি মান সেট করতে ব্যবহৃত হয়।
যে এক্সপ্রেশনটি পরীক্ষা করতে হবে সেটি প্রশ্নচিহ্নের আগে থাকে এবং প্রথম বন্ধনীর ভেতরে থাকা আবশ্যক নয়।
যদি ট্রু হয় তবে যে মানটি রিটার্ন হয় সেটি কোলনের আগে, আর যদি ফলস হয় তবে যে মানটি রিটার্ন হয় সেটি কোলনের পরে।
একটি লিটারাল মান অথবা একটি ভ্যারিয়েবল রিটার্ন করা যেতে পারে।

```c
int i = j > 5 ? 5: j;
```

সিনট্যাক্সের জট কমাতে টার্নারি অপারেটরগুলো নেস্ট করা যায়।

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## ফ্লোটিং পয়েন্ট মানের জন্য শর্তাধীন তুলনা

ফ্লোটিং পয়েন্ট সংখ্যাগুলো কীভাবে ইমপ্লিমেন্ট করা হয় তার কারণে, একটি সাধারণ গাণিতিক অপারেশনে রাউন্ডিং এরর হতে পারে, যা সমতার পরীক্ষায় প্রত্যাশিত ফলাফল না পাওয়ার কারণ হতে পারে।

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

`epsilon` নামে পরিচিত একটি টলারেন্স মান ব্যবহার করে এমন একটি পরিসর নির্ধারণ করা যায়, যার মধ্যে একটি মান পড়লে অন্য একটি মানের সাথে তুলনা করার সময় সেটিকে এখনও সমান হিসেবে গণ্য করা যায়।
কিছু প্ল্যাটফর্মে ফ্লোট ও ডাবল এপসিলনের জন্য বিল্ট-ইন কনস্ট্যান্ট থাকে।
আরও জানতে আপনার কম্পাইলারের ডকুমেন্টেশন দেখুন।
এপসিলন গণনা করা জটিল হতে পারে এবং প্ল্যাটফর্মভেদে ভিন্ন হতে পারে: এমনকি আলাদা আলাদা মেশিনেও।
নিচে একটি সাধারণ তুলনা ব্যবহার করা একটি উদাহরণ প্রোগ্রাম দেওয়া হলো।

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

`float`s বা `double`s-কে সমতার জন্য তুলনা করার সময় সতর্ক থাকুন!
