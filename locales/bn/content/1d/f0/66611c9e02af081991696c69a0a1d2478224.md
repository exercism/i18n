# নির্দেশনার সংযোজন

## আউটপুট

এই অনুশীলনীতে, আপনি একটি ভার্ব তৈরি করবেন যা নির্দিষ্ট সংখ্যক সারি পর্যন্ত প্যাসকেলের ত্রিভুজ তৈরি করে। আপনার ভার্বের আউটপুট দুইটি উপায়ের একটিতে ফরম্যাট করা যেতে পারে:

  1. বক্সড অ্যারের একটি অ্যারে হিসেবে, যেখানে প্রতিটি অ্যারে প্যাসকেলের ত্রিভুজের একটি সারি উপস্থাপন করে।
  1. টেবিল হিসেবে, যেখানে সংখ্যাগুলো ডানে সারিবদ্ধ থাকে এবং বাম দিকের খালি জায়গা পূরণ করতে শূন্য ব্যবহার করা হয়।

### উদাহরণ আউটপুট

এখানে `pascal 3`-এর জন্য দুটি বৈধ আউটপুট আছে:

  - বক্সড অ্যারের একটি অ্যারে হিসেবে:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - প্যাডিংসহ টেবিল হিসেবে:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
