# Emacs ইনস্টল করা

যেহেতু Emacs Lisp (elisp) হলো Emacs-এর এক্সটেনশন ভাষা, তাই প্রথমে আপনাকে [GNU Emacs](http://www.gnu.org/software/emacs/) ইনস্টল করতে হবে।

সর্বশেষ Emacs ইনস্টল করা ভালো, তবে অনুশীলনীগুলোর জন্য 28.1 বা তার উপরের সংস্করণকে লক্ষ্য ইমপ্লিমেন্টেশন হিসেবে ধরা উচিত।
আপনার যদি আগেই Emacs ইনস্টল করা থাকে, তবে `M-x emacs-version RET` দিয়ে Emacs-এর সংস্করণ দেখে নিতে পারেন।

## OS X-এ
সবচেয়ে সহজ উপায় হলো [Emacs For Mac OS X](http://emacsformacosx.com/) সাইটে গিয়ে dmg ফাইলটি নামিয়ে নেওয়া, যা GNU Emacs-কে একটি প্যাকেজ করা OS X অ্যাপ হিসেবে ইনস্টল করে দেবে।

চাইলে অন্য বিকল্পও আছে, যেমন Aquamacs (সুপারিশ করা হয় না), অথবা [Homebrew](https://formulae.brew.sh/formula/emacs) দিয়ে ইনস্টল করা।

## Linux-এ
কিছু ডিস্ট্রোতে Emacs আগেই ইনস্টল করা থাকে, কারণ এটি GNU-এর অংশ।

### Ubuntu
বর্তমানে সর্বাধিক সাম্প্রতিক Emacs ইনস্টল করার সুপারিশকৃত উপায় হলো [snap](https://snapcraft.io/emacs) ব্যবহার করা:

```
sudo snap install emacs --classic
```

আপনি যদি snap ব্যবহার করতে না চান, তাহলে snap দিয়েও Emacs ইনস্টল করতে পারেন, তবে Ubuntu-র রিপোজিটরি থেকে পাওয়া সংস্করণটি প্রায়শই পুরোনো হয়ে থাকে।
apt দিয়ে Emacs-এর আরও সাম্প্রতিক কোনো সংস্করণ ইনস্টল করতে চাইলে আপনাকে একটি [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) ব্যবহার করতে হবে, অথবা [সোর্স থেকে বিল্ড করতে হবে](https://www.emacswiki.org/emacs/BuildingEmacs)।

সর্বশেষ সংস্করণ ইনস্টল করার বিষয়ে আপনার তেমন কিছু যায় আসে না যদি, তবে কাজটি এতটুকুই সহজ হওয়া উচিত

```
sudo apt-get install emacs
```

### Arch
Arch সাধারণত সর্বশেষ Emacs সংস্করণসহ আসে, তাই চালান:

```
sudo pacman -S emacs
```

তাহলেই আপনি প্রস্তুত।

### অন্যান্য ডিস্ট্রো
আপনার ডিস্ট্রোতে কোন সংস্করণটি বর্তমানে আছে তা দেখে নিন, এবং উপযুক্ত হলে আপনার প্যাকেজ
ম্যানেজার ব্যবহার করুন বা সোর্স থেকে বিল্ড করুন।

### Windows
Windows-এ Emacs ইনস্টল করতে হলে নিকটস্থ
[FTP আর্কাইভ মিরর](https://ftpmirror.gnu.org/emacs/windows)-এ যান, ইনস্টলারটি (=emacs-XX.X-installer.exe=) নামিয়ে নিন এবং চালু করুন।
ইনস্টল না করেই Emacs ব্যবহার করতে চাইলে আপনি =emacs-XX.x.zip= প্যাটার্নের ফাইলটি নামিয়ে নিতে পারেন, এটি আনপ্যাক করুন এবং `bin\runemacs.exe` চালু করুন।

আপনি যদি [MSYS2](https://www.msys2.org/) ব্যবহার করেন, তবে ৬৪-বিট Emacs বিল্ড ইনস্টল করতে পারেন এভাবে

```
pacman -S mingw-w64-x86_64-emacs
```

অথবা ৩২-বিট বিল্ড এভাবে

```
pacman -S mingw-w64-i686-emacs
```
