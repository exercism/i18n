# ভূমিকা

## অ্যারে

F#-এ একটি `array` হলো শূন্য বা তার বেশি মানের একটি মিউটেবল কালেকশন, যার দৈর্ঘ্য নির্দিষ্ট। এর মানে হলো, একবার একটি অ্যারে তৈরি হয়ে গেলে তার আকার আর পরিবর্তন করা যায় না, কিন্তু তার মানগুলো পরিবর্তন করা যায়। একটি অ্যারেতে থাকা সব মানের টাইপ একই হতে হবে। অ্যারে নিচের মতো করে ডিফাইন করা যায়:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

এলিমেন্টগুলো একটি ইনডেক্স ব্যবহার করে অ্যারেতে অ্যাসাইন করা যায় বা অ্যারে থেকে পড়া যায়। F#-এর অ্যারে জিরো-বেজড, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

অ্যারে হয় `Array` মডিউলে ডিফাইন করা ফাংশন ও অপারেটর দিয়ে ম্যানিপুলেট করা হয়, অথবা _অ্যারে_ প্যাটার্ন ব্যবহার করে প্যাটার্ন ম্যাচিংয়ের মাধ্যমে ম্যানুয়ালি করা হয়:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

প্যাটার্ন ম্যাচিংয়ের সময় আপনি একটি মান _বাদ_ দিতেও পারেন; যখন কোনো নির্দিষ্ট কেসে কোনো মান নিয়ে আপনার কিছু যায় আসে না (অর্থাৎ মানটি আপনি _ব্যবহার_ করবেন না), তখন এটি বোঝাতে একটি আন্ডারস্কোর (`'_'`) ব্যবহার করতে পারেন:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

প্যাটার্ন ম্যাচিংয়ের সময় একক `'_'` সর্বদা _সবার শেষে_ আসা উচিত; অন্য কোনো কেসের সাথে _মিলে না_ এমন প্রতিটি মান এই কেসটি দিয়ে হ্যান্ডেল করা হবে।
