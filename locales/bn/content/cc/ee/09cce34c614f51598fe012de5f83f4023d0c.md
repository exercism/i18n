# নির্দেশাবলি

এলেনা একটি সংবাদপত্র কারখানার নতুন কোয়ালিটি ম্যানেজার। কোম্পানিতে এইমাত্র যোগ দেওয়ায় তিনি কারখানার কিছু প্রক্রিয়া খতিয়ে দেখে বুঝতে চান কোথায় কী উন্নতি করা যায়।
তিনি দেখতে পান, টেকনিশিয়ানরা হাতে করে অনেক কোয়ালিটি চেক করছেন।
এতে অটোমেশনের ভালো একটি সুযোগ আছে বলে তিনি মনে করেন এবং আপনাকে, একজন ফ্রিল্যান্স ডেভেলপারকে, কিছু মেশিন মনিটর করার একটি সফটওয়্যার বানাতে বলেন।

## 1. ঘরটির আর্দ্রতার মাত্রা মনিটর করুন

আপনার প্রথম কাজ হলো উৎপাদন কক্ষের আর্দ্রতার মাত্রা মনিটর করার একটি সফটওয়্যার লেখা। কোম্পানির সফটওয়্যারের সাথে আগে থেকেই একটি সেন্সর যুক্ত আছে, যা নিয়মিত ঘরটির আর্দ্রতার শতকরা হার রিটার্ন করে।

সফটওয়্যারটিতে আপনাকে এমন একটি ফাংশন লিখতে হবে, যা আর্দ্রতার শতকরা হার বেশি হলে একটি এরর থ্রো করবে।
ফাংশনটির নাম হবে `checkHumidityLevel` এবং এটি প্যারামিটার হিসেবে আর্দ্রতার শতকরা হার নেবে।

শতকরা হার 70% ছাড়িয়ে গেলে আপনি একটি এরর থ্রো করবেন (মেসেজটি গুরুত্বপূর্ণ নয়)।

```javascript
checkHumidityLevel(60);
// => undefined
```

```javascript
checkHumidityLevel(100);
// Throws an error
```

## 2. অতিরিক্ত গরম হওয়া শনাক্ত করুন

এলেনা আপনার প্রথম কাজটিতে খুব খুশি হয়ে মেশিনগুলোর তাপমাত্রা মনিটর করার দায়িত্ব দেন।
একজন টেকনিশিয়ান গ্রেগের সাথে কথা বলার সময় আপনি জানতে পারেন, কোনো মেশিনের তাপমাত্রা 500°C ছাড়িয়ে গেলে টেকনিশিয়ানরা অতিরিক্ত গরম হওয়া নিয়ে চিন্তা শুরু করেন।

মেশিনটিতে একটি সেন্সর লাগানো আছে, যা এর ভেতরের তাপমাত্রা মাপে।
জেনে রাখুন, সেন্সরটি খুব সংবেদনশীল এবং প্রায়ই নষ্ট হয়ে যায়।
এমন হলে টেকনিশিয়ানদের এটি বদলাতে হবে।

আপনার কাজ হলো `reportOverheating` নামে একটি ফাংশন লেখা, যা প্যারামিটার হিসেবে তাপমাত্রা নেবে এবং সেন্সর নষ্ট হলে বা মেশিন অতিরিক্ত গরম হতে শুরু করলে একটি এরর থ্রো করবে।
যেহেতু পরে এররভেদে আলাদা আলাদাভাবে প্রতিক্রিয়া জানাতে হবে, তাই দুই ধরনের এরর আলাদা করার একটি উপায় দরকার।
আপনি এরর মেসেজের উপর ভরসা করতে পারেন, কিন্তু তাতে আপনার কোডটি ভঙ্গুর হয়ে যাবে, কারণ মেসেজ আপডেট হলে কোড ভেঙে পড়বে।
তাই এটি সঠিকভাবে করার জন্য আপনি ভিন্ন ভিন্ন এরর ক্লাসের ইনস্ট্যান্স থ্রো করবেন।

- সেন্সর নষ্ট থাকলে তাপমাত্রা হবে `null`।
  এক্ষেত্রে আপনার একটি `ArgumentError` থ্রো করা উচিত।
- সবকিছু ঠিকঠাক চললে, তাপমাত্রা 500°C ছাড়িয়ে গেলে আপনার একটি `OverheatingError` থ্রো করা উচিত।
  এই এরর ক্লাসটি তাপমাত্রা আর্গুমেন্ট দিয়ে ইনস্ট্যান্টিয়েট করা হবে।
  আপনার থ্রো করা `OverheatingError`-টিতে যেন একটি temperature প্রপার্টি যুক্ত থাকে, তা নিশ্চিত করুন।

```javascript
reportOverheating(null);
// Throws an ArgumentError
```

```javascript
reportOverheating(800);
// Throws an OverheatingError
```

## 3. মেশিনটি মনিটর করুন

এখন যেহেতু আপনার মেশিন এরর শনাক্ত করতে পারে, তাই এবার আপনি এমন একটি ফাংশন লিখবেন যা সেই এররগুলোতে ভিন্ন ভিন্নভাবে প্রতিক্রিয়া জানায় :

- সেন্সর নষ্ট হলে আপনাকে একজন টেকনিশিয়ানকে সতর্ক করতে হবে
- তাপমাত্রা বেশি হলে, তা 600°C ছাড়িয়ে গেলে মেশিনটি বন্ধ করে দিতে হবে, আর এর চেয়ে কম হলে একটি ওয়ার্নিং লাইট জ্বালাতে হবে।
- অন্য কোনো এরর ঘটলে সেটি আবার থ্রো করবেন।

`monitorTheMachine` নামে একটি ফাংশন লিখুন, যা আর্গুমেন্ট হিসেবে `actions` নেয়।

`actions` হলো এমন একটি অবজেক্ট যার ৪টি প্রপার্টি আছে :

| property           | description                                                                         |
| ------------------ | ----------------------------------------------------------------------------------- |
| `check`            | একটি _*ফাংশন*_। মেশিনের তাপমাত্রা চেক করে। এটি বিভিন্ন ধরনের এরর থ্রো করতে পারে। |
| `alertDeadSensor`  | একটি _*ফাংশন*_। তাপমাত্রার সেন্সরটি নষ্ট হয়ে গেছে বলে একজন টেকনিশিয়ানকে সতর্ক করে।          |
| `alertOverheating` | একটি _*ফাংশন*_। মেশিনে একটি ওয়ার্নিং লাইট জ্বালাবে।                        |
| `shutdown`         | একটি _*ফাংশন*_। মেশিনটি বন্ধ করে দেবে।                                          |

`monitorTheMachine(actions)` ফাংশনটি অভ্যন্তরীণভাবে `check()` কল করবে।
সেটি ঠিকঠাক পার হলে ফাংশনটি কিছুই রিটার্ন করবে না।
সেটি কোনো এরর `throw` করলে ভিন্ন আচরণ প্রত্যাশিত:

| exception          | expected behaviour                   |
| ------------------ | ------------------------------------ |
| `ArgumentError`    | `alertDeadSensor` ফাংশনটি কল করুন। |
| `OverheatingError` | অতিরিক্ত গরম হওয়ার প্রোটোকল কার্যকর করুন।    |
| _(anything else)_  | এররটি আবার থ্রো করুন                    |

**অতিরিক্ত গরম হওয়ার প্রোটোকল**
তাপমাত্রা 600 °C-এর কম হলে `alertOverheating` ফাংশনটি কল করে ওয়ার্নিং লাইটটি জ্বালান।
তাপমাত্রা 600 °C ছাড়িয়ে গেলে পরিস্থিতি সংকটপূর্ণ, তাই `shutdown` ফাংশনটি কল করুন।

```javascript
monitorTheMachine({
  check,
  alertDeadSensor,
  alertOverheating,
  shutdown,
});
```
