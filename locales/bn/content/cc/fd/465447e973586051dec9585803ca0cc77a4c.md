# নির্দেশনার পরিশিষ্ট

## শব্দ

একটি `game` টাপল এবং একটি কনস্ট্রাক্টর `<game> ( -- game )` ডিফাইন করুন, যা কোনো রোল ছাড়া একটি নতুন গেম রিটার্ন করে।

একটি গেমের উপর কাজ করে এমন এই শব্দগুলো দিন:

- `roll ( pins game -- )`: রেকর্ড করুন যে `pins` সংখ্যক পিন পড়ে গেছে। রোলটি অবৈধ হলে একটি এরর থ্রো করুন:
  - ঋণাত্মক সংখ্যক পিনের ক্ষেত্রে `"Negative roll is invalid"`.
  - দশটি ফ্রেম (এবং কোনো ফিল বল) রোল করা হয়ে যাওয়ার পর `"Cannot roll after game is over"`.
  - দাঁড়িয়ে থাকা পিনের চেয়ে বেশি পিন পড়ে গেলে `"Pin count exceeds pins on the lane"`.
- `score ( game -- n )`: গেমটির মোট স্কোর। গেমটি এখনো সম্পূর্ণ না হলে `"Score cannot be taken until the end of the game"` থ্রো করুন।

মনে রাখবেন, `roll` শব্দটি `kernel` ভোকাবুলারির `roll` শাফল শব্দটিকে শ্যাডো করে। টেস্ট স্যুটটি `FROM: bowling => roll ;` দিয়ে অস্পষ্টতা দূর করে।
