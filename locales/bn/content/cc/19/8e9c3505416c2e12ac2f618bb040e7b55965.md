# নির্দেশনা

এই অনুশীলনীতে আপনি অ্যাপয়েন্টমেন্ট পরিচালনার জন্য কিছু ফাংশন নিয়ে কাজ করবেন।
সিস্টেমটি সবকিছু ISO 8601 ফরম্যাটের স্ট্রিং-এ সংরক্ষণ করে, কিন্তু মানুষ ক্যালেন্ডার এভাবে ব্যবহার করে না।
বিভিন্ন ফরম্যাটের মধ্যে রূপান্তরের জন্য নানা ফাংশন প্রয়োজন।

## 1. একটি অ্যাপয়েন্টমেন্ট তৈরি করুন

এখন থেকে `n` দিন পরে বর্তমান সময়ে একটি অ্যাপয়েন্টমেন্ট তৈরি করুন।
ফাংশনটি `n` দিন নেয় এবং এখন থেকে `n` দিন পরের অ্যাপয়েন্টমেন্টের সময় রিটার্ন করে।

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

যদি দ্বিতীয় প্যারামিটার `now` ব্যবহার না করা হয়, তবে তার বদলে বর্তমান সময় ব্যবহার করা উচিত।

## 2. একটি তারিখকে টাইমস্ট্যাম্পে রূপান্তর করুন

বিভিন্ন টুল কেবল আন্তর্জাতিকভাবে মানসম্মত ISO 8601 ফরম্যাটেই কাজ করে।
একটি তারিখ নিয়ে সেই ফরম্যাটে একটি স্ট্রিং রিটার্ন করার জন্য `getAppointmentTimestamp` ফাংশনটি লিখুন।

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. একটি অ্যাপয়েন্টমেন্টের বিবরণ পান

টাইমস্ট্যাম্প পড়া কঠিন; অ্যাপয়েন্টমেন্টের বিবরণ পাওয়ার একটি ফাংশন এতে সাহায্য করবে।
`getAppointmentDetails` ফাংশনটি ISO 8601 ফরম্যাটের একটি টাইমস্ট্যাম্প নেয় এবং বছর, মাস, তারিখ, ঘণ্টা আর মিনিট রিটার্ন করে।

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. দেওয়া অপশন অনুযায়ী একটি অ্যাপয়েন্টমেন্ট আপডেট করুন

ফাংশনটি প্রথম আর্গুমেন্ট হিসেবে অ্যাপয়েন্টমেন্টের সময় এবং দ্বিতীয় আর্গুমেন্ট হিসেবে কিছু অপশনের অবজেক্ট পাবে।
অবজেক্টের অপশন অনুযায়ী আপনাকে অ্যাপয়েন্টমেন্টটি আপডেট করতে হবে এবং নতুন অ্যাপয়েন্টমেন্টের তারিখ রিটার্ন করতে হবে।
অপশন অবজেক্টে একাধিক অপশন থাকতে পারে।

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. দুটি অ্যাপয়েন্টমেন্টের মধ্যে উপলব্ধ সময় বের করুন

ফাংশনটি আর্গুমেন্ট হিসেবে দুটি অ্যাপয়েন্টমেন্ট (টাইমস্ট্যাম্প) পাবে।
আপনাকে ওই দুই সময়ের পার্থক্য সেকেন্ডে রিটার্ন করতে হবে।

আধা সেকেন্ডের প্রায় কোনো অর্থই নেই, তাই রিটার্ন করার আগে সংখ্যাটি রাউন্ড করে নিন।

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. একটি অ্যাপয়েন্টমেন্ট এখন বৈধ কি না তা যাচাই করুন

সবশেষে, অ্যাপয়েন্টমেন্ট তৈরি হওয়ার সময় সিস্টেমকে যাচাই করতে হয় এটি বৈধ কি না।
অর্থাৎ, অ্যাপয়েন্টমেন্টটি অবশ্যই ভবিষ্যতে হতে হবে, অতীতে নয়।

`isValid` ফাংশনটি লিখুন, যা দুটি আর্গুমেন্ট নেয়: একটি অ্যাপয়েন্টমেন্ট টাইমস্ট্যাম্প (স্ট্রিং), আর বর্তমান সময় একটি টাইমস্ট্যাম্প (স্ট্রিং) হিসেবে। বর্তমান সময়ের সাপেক্ষে অ্যাপয়েন্টমেন্টটি ভবিষ্যতে থাকলে এটি `true` রিটার্ন করে।

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
