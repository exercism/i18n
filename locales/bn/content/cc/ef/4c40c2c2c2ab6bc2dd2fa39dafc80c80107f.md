# আর্মস্ট্রং নাম্বারের ধারণাসমূহ

> একটি [আর্মস্ট্রং নাম্বার](https://en.wikipedia.org/wiki/Narcissistic_number) হলো এমন একটি সংখ্যা, যার প্রতিটি অঙ্ককে অঙ্কসংখ্যার সমান ঘাতে উন্নীত করে যোগ করলে যোগফলটি ওই সংখ্যাটিরই সমান হয়।

## উদাহরণ সমাধান

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## ধারণাসমূহ

- ফাংশন: সমাধান যাচাই ও লজিক নির্ধারণের জন্য অপরিহার্য
- টেস্ট স্যুট: সমাধান যাচাই করার জন্য প্রয়োজন
- ইন্টিজার: আর্গুমেন্ট ও অভিন্নতা যাচাইয়ের জন্য u32
- `&str`: সংখ্যাটির দৈর্ঘ্য গণনার জন্য প্রয়োজন, কারণ Rust একটি স্ট্রংলি টাইপড ভাষা
- `Option<T>`: `char::to_digit`-এর প্রকৃত মান পেতে প্রয়োজন
- টাইপ কাস্টিং: গাণিতিক অপারেশন প্রয়োগের জন্য প্রয়োজন
- ইটারেটরের ফিচার:
  - একটি একক এক্সপ্রেশনেই সমাধান লেখা সম্ভব করতে টার্বোফিশ
  - `map` ও `sum`: এক্সপ্রেশনটিকে যাচাই করার জন্য প্রয়োজনীয় মানে সহজে কমিয়ে আনার জন্য
