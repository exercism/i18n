# পরিচিতি

PowerShell হলো Microsoft-এর একটি ডাইনামিকভাবে ইমপ্লিসিট টাইপড (স্ট্রংলি টাইপড ভ্যারিয়েবলও সমর্থন করে) স্ক্রিপ্টিং ভাষা, যা মূলত টাস্ক অটোমেশন ও কনফিগারেশন ম্যানেজমেন্টে মনোযোগ দেয়।

PowerShell ইম্পারেটিভ, ফাংশনাল, অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং এবং এমনকি পাইপলাইন স্টাইলও সমর্থন করে।

PowerShell .NET প্ল্যাটফর্মের উপর তৈরি এবং প্রথম প্রকাশিত হয় ২০০৬ সালে।
সব আধুনিক Windows OS-এ এটি ডিফল্টভাবে অন্তর্ভুক্ত থাকে এবং Mac ও Linux-এ ইনস্টল করা যায়।


## ভ্যারিয়েবল

PowerShell-এ একটি ভ্যারিয়েবল ডিফাইন করার দুটি কমন উপায় আছে।

PowerShell-এ ভ্যারিয়েবলের নাম অবশ্যই `$` দিয়ে শুরু হতে হবে এবং অ্যাসাইনমেন্ট অপারেটর `=` দিয়ে ভ্যারিয়েবলের নামের সাথে একটি মান বাঁধতে হয়।

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

আপনি চাইলে একটি নির্দিষ্ট [টাইপ][strong typed] নিশ্চিত করতে ভ্যারিয়েবলের টাইপ স্পষ্টভাবে উল্লেখও করতে পারেন।
সামর্থ্য থাকলে PowerShell তার সর্বোচ্চ চেষ্টা করে একটি টাইপের মানকে আরেকটি টাইপে রূপান্তর করতে।

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### কনস্ট্যান্ট

PowerShell-এ কনস্ট্যান্ট হলো রিড-অনলি ভ্যারিয়েবল, যা ডিফাইন করার পর **মুছে ফেলা** যায় না।
এটাই আমাদের দ্বিতীয় উপায়ে নিয়ে যায়, যেখানে `New-Variable` cmdlet ব্যবহার করে ভ্যারিয়েবল ডিফাইন করা হয়।

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

নানা অপশনসহ নতুন ভ্যারিয়েবল তৈরির আরও বিস্তারিত ও অ্যাডভান্সড উপায় জানতে [New-Variable][New-Variable] cmdlet দেখুন।


## ফাংশন

PowerShell-এ [ফাংশন][functions] ডিফাইন করা হয় `function` কিওয়ার্ড দিয়ে।
প্রতিটি ফাংশনে `()` বন্ধনীর ভেতরে শূন্য বা তার বেশি ফরমাল [প্যারামিটার][parameters] থাকতে পারে, আর তারপর থাকে ফাংশনের নিজস্ব [স্কোপ][scope], যা `{` দিয়ে শুরু হয়ে `}` দিয়ে শেষ হয়। 

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell-এ ফাংশন `FuncName $Arg` সিনট্যাক্সে কল করার পর `return` কিওয়ার্ডের মাধ্যমে স্পষ্টভাবে মান রিটার্ন করতে পারে।

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

বিস্তারিত ফাংশন ডেফিনিশন কীভাবে লিখতে হয় এবং ফাংশন কীভাবে ইমপ্লিসিটভাবে মান রিটার্ন করতে পারে, তার একটি অ্যাডভান্সড আলোচনা `Functions` কনসেপ্ট মডিউলে থাকবে।


## কমেন্ট

PowerShell-এ একক কমেন্ট শুরু হয় `#` দিয়ে এবং লাইন শেষ হলে শেষ হয়।
PowerShell-এ কমেন্ট ব্লক শুরু হয় `<#` দিয়ে এবং শেষ হয় `#>` দিয়ে।
কমেন্ট-বেজড হেল্প তৈরির জন্য কমেন্ট ব্লকের একটি অ্যাডভান্সড ব্যবহার `Functions` কনসেপ্ট মডিউলে দেখানো হবে।

```powershell
function Main() {
    #This is a comment
}
```
