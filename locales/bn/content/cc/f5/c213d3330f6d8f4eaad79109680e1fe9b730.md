# সম্পর্কে

Elixir-এ [লিস্টগুলো][list] মানের একটি সংগ্রহ ধরে রাখার একটি মৌলিক ডেটা টাইপ। লিস্ট _ইমিউটেবল_, অর্থাৎ এগুলো পরিবর্তন করা যায় না। যে কোনো অপারেশন যা একটি লিস্ট পরিবর্তন করে, সেটি একটি নতুন লিস্ট রিটার্ন করে। লিস্টগুলো [Enumerable প্রোটোকল][enum-protocol] ইমপ্লিমেন্ট করে, যার ফলে [Enum][enum] ও [Stream][stream] মডিউলের ফাংশনগুলো ব্যবহার করা যায়।

Elixir-এ লিস্টগুলো [লিঙ্কড লিস্ট][linked-list-wiki] হিসেবে ইমপ্লিমেন্ট করা হয়, একটানা মেমরি লোকেশনের অ্যারে হিসেবে নয়। তাই একটি লিস্টের কোনো এলিমেন্ট অ্যাক্সেস করতে লিস্টের দৈর্ঘ্যের ওপর নির্ভর করে লিনিয়ার টাইম লাগে।

লিস্ট লেখা যায় লিটারেল ফর্মে, হেড-টেইল নোটেশনে (যেখানে `cons` অপারেটর `|` ব্যবহার করা হয়), অথবা দুটোর মিশ্রণে:

```elixir
# Literal Form
[]
[1]
[1, 2, 3]

# Head-tail Notation
[]
# same as [1]
[1 | []]
# same as [1, 2, 3]
[1 | [2 | [3 | []]]]

# Mixed
# same as [1, 2, 3]
[1 | [2, 3]]
```

_cons_ (`|`) অপারেটরের আগে একাধিক এলিমেন্টও থাকতে পারে।

```elixir
# Multiple prepends
[1, 2, 3 | [4, 5]]
```

লিস্টে আইটেম অ্যাপেন্ড করতে হেড-টেইল নোটেশন ব্যবহার করা যায়।

```elixir
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

ইটারেশনের সময় একটি লিস্টে এলিমেন্ট অ্যাপেন্ড করা একটি অ্যান্টি-প্যাটার্ন হিসেবে ধরা হয়। একটি এলিমেন্ট অ্যাপেন্ড করতে পুরো লিস্টের মধ্য দিয়ে যেতে হয় এবং শেষে এলিমেন্টটি যোগ করতে হয়, তাই প্রতিটি ইটারেশনে নতুন এলিমেন্ট অ্যাপেন্ড করতে হলে প্রতিটি ইটারেশনে পুরো লিস্টের মধ্য দিয়ে যেতে হবে।

রিভার্স করা লিস্টের শুরুতে একটি এলিমেন্ট প্রিপেন্ড করে, তারপর ফলাফলটি রিভার্স করে আমরা একই ফলাফল পেতে পারি। প্রিপেন্ড করা একটি দ্রুত অপারেশন এবং এতে কনস্ট্যান্ট টাইম লাগে।

```elixir
# Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

# Prepend to the start of a list (faster, due to the nature of linked lists)
[6 | [5 | [4 | [3, 2, 1]]]]
# then reverse!
```

লিস্টের জন্য `Kernel`-এর বেশ কিছু কমন ফাংশন আছে:

- [`hd/1`][hd] একটি লিস্টের _হেড_ রিটার্ন করে, অর্থাৎ লিস্টের _প্রথম_ আইটেম।
- [`tl/1`][tl] লিস্টের _টেইল_ রিটার্ন করে, অর্থাৎ লিস্ট থেকে _প্রথম_ আইটেমটি _বাদ দিলে_ যা থাকে।
- [`length/1`][length] লিস্টে থাকা আইটেমের সংখ্যা রিটার্ন করে।
- [`in/2`][in] একটি বুলিয়ান মান রিটার্ন করে, যা নির্দেশ করে আইটেমটি লিস্টের একটি এলিমেন্ট কি না।

এছাড়াও [`List` মডিউল][list] রয়েছে।

লিস্টে যেকোনো ডেটা টাইপ এবং বিভিন্ন ডেটা টাইপের মিশ্রণ থাকতে পারে।

```elixir
list = [1, :a, 2.0, "string"]
```
