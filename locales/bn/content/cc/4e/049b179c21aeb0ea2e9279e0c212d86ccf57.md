# নির্দেশাবলী

এই অনুশীলনীতে আপনি সঞ্চয়ী হিসাব নিয়ে কাজ করবেন।
প্রতি বছর আপনার সঞ্চয়ী হিসাবের ব্যালেন্স তার সুদের হার অনুযায়ী হালনাগাদ করা হয়।
আপনার ব্যাংক আপনাকে যে সুদের হার দেয়, তা আপনার হিসাবে থাকা অর্থের পরিমাণের (তার ব্যালেন্সের) উপর নির্ভর করে:

- ঋণাত্মক ব্যালেন্সের জন্য 3.213% (ব্যালেন্স আরও ঋণাত্মক হয়)।
- `1000` ডলারের কম ধনাত্মক ব্যালেন্সের জন্য 0.5%।
- `1000` ডলারের সমান বা তার বেশি এবং `5000` ডলারের কম ধনাত্মক ব্যালেন্সের জন্য 1.621%।
- `5000` ডলারের সমান বা তার বেশি ধনাত্মক ব্যালেন্সের জন্য 2.475%।

আপনার চারটি কাজ আছে, যার প্রত্যেকটিতে আপনার ব্যালেন্স এবং তার সুদের হার নিয়ে কাজ করতে হবে।

## 1. সুদের হার গণনা করুন

`SavingsAccount.interest_rate()` মেথডটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে একটি ব্যালেন্স নেয়।
মেথডটি প্রদত্ত ব্যালেন্সের জন্য সুদের হার রিটার্ন করবে।

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. সুদ গণনা করুন

`SavingsAccount.interest()` মেথডটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে একটি ব্যালেন্স নেয়।
মেথডটি প্রদত্ত ব্যালেন্সের জন্য সুদ রিটার্ন করবে।

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. বার্ষিক ব্যালেন্স হালনাগাদ গণনা করুন

`SavingsAccount.annual_balance_update()` মেথডটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে একটি ব্যালেন্স নেয়।
মেথডটি এক বছর পরের ব্যালেন্স রিটার্ন করবে।

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. কাঙ্ক্ষিত ব্যালেন্সে পৌঁছাতে কত বছর লাগবে তা গণনা করুন

`SavingsAccount.years_before_desired_balance()` মেথডটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে একটি ব্যালেন্স এবং একটি লক্ষ্য ব্যালেন্স নেয়।
মেথডটি লক্ষ্য ব্যালেন্সে পৌঁছাতে কত বছর লাগবে সেই সংখ্যা রিটার্ন করবে।

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
সরল সুদ একটি মূলধনী ব্যালেন্সে প্রয়োগ করার সময়, ব্যালেন্সটি সুদের হার দিয়ে গুণ করা হয় এবং এই দুটির গুণফলই সুদের পরিমাণ।

অন্যদিকে চক্রবৃদ্ধি সুদ নিয়মিত বিরতিতে সুদ প্রয়োগের মাধ্যমে করা হয়।
প্রতিবার প্রয়োগের সময় সুদের পরিমাণ গণনা করা হয় এবং মূলধনী ব্যালেন্সের সাথে যোগ করা হয়, যাতে পরবর্তী সুদ গণনাগুলো বড় মূলধনী ব্যালেন্সের উপর হয়ে থাকে।
