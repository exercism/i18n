# Instructions

সম্প্রতি কেনা সেই রিমোট কন্ট্রোল কারটি আপনার একেবারে নতুন একটি শখে পরিণত হয়েছে। আপনি রিমোট কন্ট্রোল কার রেসের আয়োজন করছেন।

রেস সিমুলেশন রান করার একটি প্রোগ্রাম লেখা আপনি প্রায় শেষ করে ফেলেছিলেন, ঠিক তখনই আপনার বিড়াল আপনার কিবোর্ডের উপর লাফিয়ে পড়ে কোডের কয়েকটি লাইন মুছে দিল। এখন আপনার প্রোগ্রামটি আর কম্পাইল হয় না...

## 1. কম্পাইলেশন এরর `Race.__struct__/0 is undefined` ঠিক করুন

একটি অ্যালিয়াস যোগ করুন, যাতে `NeedForSpeed.Race` মডিউলটিকে ছোট নাম `Race` দিয়ে রেফার করা যায়।

## 2. কম্পাইলেশন এরর `Car.__struct__/0 is undefined` ঠিক করুন

একটি অ্যালিয়াস যোগ করুন, যাতে `NeedForSpeed.RemoteControlCar` মডিউলটিকে ছোট নাম `Car` দিয়ে রেফার করা যায়।

## 3. কম্পাইলেশন এরর `undefined function puts/1` ঠিক করুন

`puts/1` ফাংশনটি আসে `IO` মডিউল থেকে। মডিউলটি রেফার না করেই এটি ব্যবহার করতে পারার জন্য এটি ইমপোর্ট করুন।

## 4. কম্পাইলেশন এরর `undefined function default_color/0` ঠিক করুন

`default_color/0`, `red/0`, `cyan/0` এবং `green/0` ফাংশনগুলো সবই আসে `IO.ANSI` মডিউল থেকে। আপনি অন্য গাড়ির রঙের সাপোর্ট যোগ করার পরিকল্পনা করছেন, তাই পুরো মডিউলটি ইমপোর্ট করতে চান। দুর্ভাগ্যক্রমে, `IO.ANSI` মডিউলের `color/1` ফাংশনটি আপনার একটি লোকাল ফাংশনের সঙ্গে সংঘর্ষ করে। ওই একটি ফাংশন বাদে পুরো `IO.ANSI` মডিউলটি ইমপোর্ট করুন।
