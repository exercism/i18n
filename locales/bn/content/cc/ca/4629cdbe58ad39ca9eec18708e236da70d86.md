# সম্পর্কে

[গার্ড][guards] ব্যবহার করা হয় [প্যাটার্ন ম্যাচিং][exercism-pattern-matching]-এর পরিপূরক হিসেবে। এগুলো আরও জটিল চেক করার সুযোগ দেয়। প্যাটার্ন ম্যাচিং যেসব ক্ষেত্রে ব্যবহার করা যায়, তার [কিছু ক্ষেত্রে, তবে সব ক্ষেত্রে নয়][where-guards-can-be-used], গার্ড ব্যবহার করা যায়, যেমন ফাংশন ক্লজ বা কেস ক্লজে।

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- গার্ড শুরু হয় `when` কিওয়ার্ড দিয়ে, এরপর থাকে একটি বুলিয়ান এক্সপ্রেশন।
- গার্ড এক্সপ্রেশন হলো বিশেষ ধরনের ফাংশন, যেগুলো:
  - অবশ্যই [পিউর][pure-function] হতে হবে এবং কোনো গ্লোবাল স্টেট পরিবর্তন করবে না।
  - অবশ্যই কঠোরভাবে `true` বা `false` মান রিটার্ন করতে হবে।
- কমন গার্ডের একটি তালিকা [Elixir ডকুমেন্টেশনে][kernel-guards] পাওয়া যায়। এর মধ্যে আছে:
  - টাইপ চেক: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] ইত্যাদি।
  - গাণিতিক অপারেটর: [`+/2`][guard-plus], [`-/2`][guard-minus] ইত্যাদি।
  - তুলনা: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] ইত্যাদি।
  - বুলিয়ান অপারেটর: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - মেম্বারশিপ অপারেটর: [`in/2`][guard-in]
- আপনি [`defguard`][defguard] দিয়ে নিজের গার্ড ডিফাইন করতে পারেন।

  - Elixir-এর [নেমিং][naming] কনভেনশন অনুযায়ী, গার্ডের নাম `is_` দিয়ে শুরু হওয়া উচিত।

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
