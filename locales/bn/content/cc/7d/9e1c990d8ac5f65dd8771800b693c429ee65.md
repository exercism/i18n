# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার        | টাইপ    | বিবরণ                             |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং            |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | চূড়ান্ত নিউক্লিওটাইড-গণনা ধারণ করা ওয়ার্ড অ্যারে |
| `$t0-9`  | টেম্পোরারি    | যেকোনো     | অস্থায়ীভাবে সংরক্ষণের জন্য                   |
