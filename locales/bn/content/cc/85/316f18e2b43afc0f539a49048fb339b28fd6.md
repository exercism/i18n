# সম্পর্কে

C++-এ বুলিয়ান প্রকাশ করা হয় `bool` টাইপ দিয়ে।
একটি `bool` হয় `true`, নয়তো `false`।

## লজিক্যাল অপারেটর

C++ তিনটি বুলিয়ান অপারেটর সমর্থন করে: `!` (NOT), `&&` (AND) এবং `||` (OR)।
আপনি বিকল্প রূপগুলোও ব্যবহার করতে পারেন: `not`, `and` এবং `or`।

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## অগ্রাধিকার

তিনটি বুলিয়ান অপারেটরের _অপারেটর অগ্রাধিকার_ আলাদা আলাদা।
এর ফলে, এগুলো এই ক্রমে মূল্যায়ন করা হয়: প্রথমে `!`, দ্বিতীয়তে `&&` এবং শেষে `||`।
আপনি যদি ভিন্ন কোনো ক্রম চাপিয়ে দিতে চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন বন্ধনীর (অর্থাৎ `()`) ভেতরে রাখতে পারেন, কারণ বন্ধনীর অপারেটর অগ্রাধিকার আরও বেশি।

```cpp
!true && false   // => false
!(true and false) // => true
```

## কনভার্সন

আপনি যদি এমন জায়গায় `true` বা `false` ব্যবহার করেন যেখানে একটি সংখ্যা প্রত্যাশিত, তাহলে সেগুলো যথাক্রমে `1` ও `0`-এ রূপান্তরিত হবে।
আপনি যদি কোনো বুলিয়ান অপারেশনে একটি সংখ্যা ব্যবহার করেন, তাহলে `0` ছাড়া বাকি সবকিছুই `true` হিসেবে ধরা হয়, এমনকি ঋণাত্মক মানও।

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
