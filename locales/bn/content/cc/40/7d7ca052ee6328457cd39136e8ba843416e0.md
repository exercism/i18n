# পরিচিতি

বাইনারি ডেটা নিয়ে কাজ করা জটিল হতে পারে, তাই Gleam বাইনারি ডেটা তৈরি করতে ও প্যাটার্ন ম্যাচ করতে একটি `BitArray` টাইপ এবং তার সঙ্গে সম্পর্কিত সিনট্যাক্স দেয়।

বিট অ্যারে লিটারেল `<<>>` সিনট্যাক্স দিয়ে লেখা হয়। একটি বিট অ্যারে লিটারেল লেখার সময় তা সেগমেন্টে সেগমেন্টে লেখা হয়। প্রতিটি সেগমেন্টে একটি মান ও একটি অ্যানোটেশন থাকে, যেগুলোকে `:` দিয়ে আলাদা করা হয়। অ্যানোটেশনটি বলে দেয় মানটি এনকোড করতে কত বিট ব্যবহার করা হবে, এবং এটি সম্পূর্ণ বাদও দেওয়া যায়, তখন ডিফল্ট হিসেবে ৮-বিটের একটি ইন্টিজার মান ধরা হয়।

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

টাইপ হিসেবে `:1` লেখা হলো `:size(1)` লেখার সংক্ষিপ্ত রূপ। বিট সাইজ যদি কোনো ভ্যারিয়েবল থেকে আসে, তাহলে আপনাকে বড় সিনট্যাক্সটি ব্যবহার করতে হবে।

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## বাইনারি

বাইনারি ইন্টিজার লিটারেল লেখার সময় লিটারেলের আগে `0b` বসিয়ে সরাসরি বেস-২ নোটেশনে সেগুলো লেখা যায়। মনে রাখবেন, টেস্টে বা আপনার প্রোগ্রামে প্রিন্ট করলে এগুলো দশমিক সংখ্যা হিসেবে দেখানো হবে।

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## ট্রাঙ্কেশন

সেগমেন্টের মান যদি সেগমেন্টের টাইপের ধারণক্ষমতা ছাড়িয়ে যায়, তাহলে বাম দিক থেকে এটি ট্রাঙ্কেট করা হবে।

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## প্রিপেন্ড ও অ্যাপেন্ড করা

বিট অ্যারে সিনট্যাক্স ব্যবহার করে আপনি বিদ্যমান একটি বিট অ্যারে প্রিপেন্ড ও অ্যাপেন্ড দুটোই করতে পারেন। বিদ্যমান বিট অ্যারের জন্য `:bits` অ্যানোটেশনটি ব্যবহার করতে হবে।

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## কনক্যাটেনেট করা

ভ্যারিয়েবলে রাখা বিট অ্যারে এই সিনট্যাক্স দিয়ে কনক্যাটেনেট করা যায়। ভিন্ন সাইজের দুটি বিট অ্যারে কনক্যাটেনেট করার সময় `:bits` অ্যানোটেশনটি ব্যবহার করতে হবে।

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## প্যাটার্ন ম্যাচিং

বিট অ্যারে থেকে মান বের করতেও প্যাটার্ন ম্যাচিং করা যায়। আপনি যে ফ্র্যাগমেন্টটি ধরতে চান, তার জন্য কত বিট লাগবে তা আপনাকে জানতে হবে, তবে একটি ব্যতিক্রম আছে: অজানা সাইজের বিট অ্যারে প্যাটার্ন ম্যাচ করতে `:bits` অ্যানোটেশনটি ব্যবহার করা যায়, কিন্তু এটি কেবল শেষ ফ্র্যাগমেন্টের জন্যই ব্যবহার করা যায়।

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## বিট অ্যারে ইনস্পেক্ট করা

~~~~exercism/note
বিট অ্যারে তৈরি করতে যে ফরম্যাট ব্যবহার করা হয়েছিল, তার থেকে ভিন্ন ফরম্যাটে বিট অ্যারে প্রিন্ট হতে পারে। বিট অ্যারে শেখার সময় এটি প্রায়ই বিভ্রান্তির সৃষ্টি করে।
~~~~

ডিফল্টভাবে বিট অ্যারে ৮ বিটের (এক বাইট) ফ্র্যাগমেন্টে দেখানো হয়, এমনকি আপনি যদি ভিন্ন সাইজের ফ্র্যাগমেন্ট দিয়ে সেগুলো তৈরি করে থাকেন।

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

আপনি যদি এমন একটি বিট অ্যারে তৈরি করেন যা একটি প্রিন্টযোগ্য UTF-8 এনকোডেড স্ট্রিং প্রকাশ করে, তাহলে `io.debug`-এর মতো ফাংশন এটিকে স্ট্রিং হিসেবে দেখাতে পারে। এর কারণ, Gleam অভ্যন্তরীণভাবে স্ট্রিং কীভাবে উপস্থাপন করে, তার একটি ইমপ্লিমেন্টেশন ডিটেইল।

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
