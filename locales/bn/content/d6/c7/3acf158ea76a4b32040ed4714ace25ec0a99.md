# নির্দেশনা সংযুক্তি

## ওয়ার্ড

একটি `linked-list-node` টিউপল ডিফাইন করুন।

একটি `linked-list` টিউপল ডিফাইন করুন এবং `sequences` থেকে একটি `M: linked-list length` মেথড দিন, যাতে টেস্টগুলো সরাসরি আপনার লিস্টে `length` কল করতে পারে।

- `<linked-list> ( -- linked-list )`: একটি খালি লিস্ট তৈরি করে।
- `>linked-list ( seq -- linked-list )`: `seq`-এর প্রতিটি এলিমেন্ট ক্রম অনুযায়ী একটি নতুন লিস্টে পুশ করে।
- `linked-list>array ( linked-list -- array )`: লিস্টের সবচেয়ে উপরের মানটি সবার আগে রেখে মানগুলো রিটার্ন করে।
- `list-push ( linked-list value -- linked-list )`: একটি মান উপরে পুশ করে।
- `list-pop ( linked-list -- linked-list value )`: সবচেয়ে উপরের মানটি সরিয়ে সেটি রিটার্ন করে।
- `list-peek ( linked-list -- value )`: উপরের মানটি না সরিয়ে সেটি রিটার্ন করে।
- `list-reverse ( linked-list -- linked-list )`: এলিমেন্টগুলো উল্টো ক্রমে সাজানো একটি লিস্ট রিটার্ন করে।

লিস্ট খালি থাকলে `list-pop` এবং `list-peek` থেকে একটি `list-empty` এরর ক্লাস থ্রো করুন।
