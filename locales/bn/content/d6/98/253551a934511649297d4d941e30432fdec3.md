# ভূমিকা

[`function`][function] হলো কোডকে আলাদা আলাদা ভাগে গুছিয়ে রাখার একটি উপায়, যাতে প্রোগ্রামের এক বা একাধিক জায়গা থেকে নাম ধরে এটিকে কল করা যায়।
ফাংশন নির্দিষ্ট ও পুনরাবৃত্তিমূলক কাজ সম্পাদন করতে ব্যবহৃত হয়।

আরও আনুষ্ঠানিকভাবে বললে: ফাংশন হলো এমন যেকোনো Python অবজেক্ট, যার উপর [`function call`][calls] অপারেশন প্রয়োগ করা যায়।
কোনো অপারেশনের ফলাফল হিসেবে এক বা একাধিক মান [`return`][return] করার জন্য একটি ফাংশন ব্যবহার করা যেতে পারে, আবার এক বা একাধিক [`side effects`][side effects]-এর জন্যও ব্যবহার করা যেতে পারে।
কোনো ফাংশন যদি কোনো রিটার্ন ভ্যালু নির্দিষ্ট না করে, তবুও এটি `None` রিটার্ন করবে।

নিচে সাইড ইফেক্টযুক্ত একটি ফাংশনের উদাহরণ দেওয়া হলো:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

উপরের উদাহরণে ফাংশন ডেফিনিশনের শুরু বোঝাতে [`def`][def] কিওয়ার্ডটি ব্যবহার করা হয়েছে।
`hello` হলো ফাংশনটির নাম।
খালি বন্ধনী দুটি বোঝায় যে ফাংশনটিতে কোনো মান পাঠানো হচ্ছে না।
ফাংশনটির বডি হলো একটিমাত্র `print("Hello")` স্টেটমেন্ট।
`print`-ও একটি ফাংশন।
`print` ফাংশনের বন্ধনীর ভেতরে থাকা `"Hello"`-কে বলা হয় একটি [`argument`][arguments]।
কী প্রিন্ট করতে হবে তা জানার জন্য `print` ফাংশনটি এই আর্গুমেন্টটি ব্যবহার করে।
লক্ষ্য করুন, ফাংশনটির বডি ইনডেন্ট করা আছে।
এই ইনডেন্টেশনটি গুরুত্বপূর্ণ, কারণ কোডের ওই ব্লকটি কোথায় শেষ হচ্ছে তা জানতে Python এই ইনডেন্টেশনের উপর নির্ভর করে।
ফাংশন বডি শেষ হয় হয় প্রোগ্রামের একেবারে শেষে, নয়তো পরের যে কোড লাইনটি ইনডেন্ট করা _নয়_ তার ঠিক আগে।
যেহেতু `hello()` কোনো `return` ভ্যালু নির্দিষ্ট করে না, তাই এটি তার সাইড ইফেক্ট সম্পাদন করে, অর্থাৎ `print()` কল করে, এবং এরপর `None` রিটার্ন করে।
সবশেষে, আমরা ফাংশনটির নাম ও বন্ধনী ব্যবহার করে এটিকে কল করি, যা Python ইন্টারপ্রেটারকে বোঝায় যে এটি একটি _কল করার যোগ্য_ নাম।

নিচে রিটার্ন ভ্যালুযুক্ত একটি ফাংশনের উদাহরণ দেওয়া হলো:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

এই ফাংশনের বডি _`print` কল করা_ থেকে বদলে _`string` "Hello" রিটার্ন করা_ হয়েছে।
শেষ পর্যন্ত কোডটি তবুও `"Hello"` প্রিন্ট করে, তবে সাইড ইফেক্টটি `hello` ফাংশনের বদলে _কল করা কোড_-এ ঘটে।
`hello` ফাংশনটি কল করার সময় যদি বন্ধনী দুটি বাদ দেওয়া হয় (যেমন `print(hello)`), তাহলে `print` কিছুটা এমন আউটপুট দেবে

```
<function hello at 0x0000026E18E93E20>
```

গুরুত্বপূর্ণ বিষয় হলো, কোনো ফাংশন যদি কোনো আর্গুমেন্ট না-ও নেয় (_অর্থাৎ কোনো প্যারামিটার নেই_), তবুও সেটিকে সঠিকভাবে _কল_ করতে খালি বন্ধনী অবশ্যই ব্যবহার করতে হবে।
এটি Ruby-র মতো কোনো ভাষার থেকে আলাদা, যেখানে কোনো আর্গুমেন্ট ছাড়া ফাংশন কল করতে খালি বন্ধনী লাগে না।

একটি ফাংশন শূন্য বা তার বেশি [`parameters`][parameters] ডিফাইন করতে পারে। একটি প্যারামিটার নির্ধারণ করে যে ফাংশনটি কোন কোন আর্গুমেন্ট গ্রহণ করবে।

নিচে একটি আর্গুমেন্ট গ্রহণ করে এমন ফাংশনের উদাহরণ দেওয়া হলো:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

প্যারামিটারটি `name` হিসেবে ডিফাইন করা হয়েছে।
`"Bob"` হলো সেই আর্গুমেন্ট, যা প্রোগ্রামটি `hello` ফাংশনে পাঠায়।
ফাংশনটি `string` "Hello, Bob" _রিটার্ন করে_।

কেউ যদি কোনো আর্গুমেন্ট না পাঠিয়ে `hello` কল করে, তাহলে কী হবে?
প্রোগ্রামটি একটি এরর দেয়:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

আমরা যদি না চাই যে আর্গুমেন্ট ছাড়া প্রোগ্রামটি এরর দেবে (_কিন্তু চাই যে কল করা কোড চাইলে একটি না-ও দিতে পারবে_), তাহলে একটি [ডিফল্ট আর্গুমেন্ট][default arguments] ডিফাইন করতে পারি।
ফাংশন কল করার সময় আর্গুমেন্ট না থাকলে কোন মানটি ব্যবহার করতে হবে, তা একটি ডিফল্ট আর্গুমেন্ট নির্ধারণ করে।

নিচে ডিফল্ট আর্গুমেন্টযুক্ত একটি ফাংশনের উদাহরণ দেওয়া হলো:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

`name` প্যারামিটারটিকে `"you"` ডিফল্ট আর্গুমেন্ট হিসেবে দেওয়া হয়েছে, তাই কোনো `name` আর্গুমেন্ট না পাঠালে প্রোগ্রামটি `Hello, you` আউটপুট দেয়।

ফাংশন আর্গুমেন্ট সম্পর্কে আরও জানতে, [ফাংশন আর্গুমেন্ট][function arguments] ধারণাটি দেখুন।
