# টেস্ট

টেস্ট চালানোর আগে, ইনস্টলেশনের ধাপগুলো অনুসরণ করে নিশ্চিত হয়ে নিন যে অ্যাসাইনমেন্ট ফোল্ডারটি ঠিকভাবে সেট-আপ করা হয়েছে, অর্থাৎ `corepack yarn install` এবং Editor SDK সেটআপ।

টেস্টগুলো চালান এভাবে:

```bash
$ corepack yarn test
```

নিশ্চিত করুন যে আপনার কোড অন্য ব্যবহারকারীদের মতো বেস্ট প্র্যাকটিস মেনে চলে, eslint-এর সাহায্যে, যা আপনার কোডে স্ট্যাটিক অ্যানালাইসিস চালানোর একটি টুল। এ ধরনের টুল আপনার কোডের টাইপো বা ছোটখাটো ভুল ধরতে আপনার সময় বাঁচায়:

```bash
$ corepack yarn lint
```

অথবা দুটো একসাথে চালান:

```bash
$ corepack yarn test && corepack yarn lint
```

Exercism-এর TypeScript ট্র্যাক কোডের _স্টাইল_ নিয়ে কোনো বাধ্যবাধকতা রাখে না, তাই সেমিকোলন, ট্যাব বনাম স্পেস, আর এই দুইয়ের মাঝের সবকিছু নিয়ে আপনি নিজের ইচ্ছেমতো বেছে নিতে পারেন।

## আপনার প্রথম মডিউল তৈরি করা

সাধারণত এই ট্র্যাকের টেস্টগুলো আপনার ইমপ্লিমেন্টেশনকে একটি মডিউল হিসেবে ইমপোর্ট করে লোড করে: `import Bob from './bob';`.

এটি কাজ করাতে হলে টেস্টগুলো যে ফাইলে আপনার মডিউল খোঁজে, সেই ফাইল থেকেই আপনাকে আপনার ইমপ্লিমেন্টেশন এক্সপোর্ট করতে হবে, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

আমরা প্রতিটি অনুশীলনীতে স্টাব দিয়ে দিয়েছি এবং সেখানেই আপনার জন্য এই `export` বসিয়ে দিয়েছি।
