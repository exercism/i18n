# বুলিয়ান

Crystal-এ [`Bool`][bools] নামে একটি টাইপ আছে।
এটি `true` এবং `false` মান নির্দেশ করে।

## লজিক্যাল অপারেটর

Crystal-এ তিনটি লজিক্যাল অপারেটর আছে (`!`, `||`, `&&`), যেগুলো বুলিয়ান মান একসাথে যুক্ত করে এমন এক্সপ্রেশন তৈরি করে যার ফলাফল ভিন্ন ভিন্ন হতে পারে।

### অ্যান্ড(`&&`)

Crystal-এ [_অ্যান্ড_ অপারেটর][and] `&&` দিয়ে প্রকাশ করা হয় এবং উভয় মান `true` হলে এটি `true` রিটার্ন করে; অন্যথায় `false` রিটার্ন করে।
_অ্যান্ড_ অপারেটর ব্যবহার করার সময় একটি বুলিয়ান মান `&&`-এর ডান দিকে এবং অন্যটি বাম দিকে বসানো হয়।

```crystal
true && true
# => true

true && false
# => false
```

### অর(`||`)

Crystal-এ [_অর_ অপারেটর][or] `||` দিয়ে প্রকাশ করা হয় এবং প্রদত্ত মানগুলোর **অন্তত একটি** `true` হলে এটি `true` রিটার্ন করে।
উভয় মানই `false` হলে এটি `false` রিটার্ন করে।
_অর_ অপারেটর ব্যবহার করার সময় একটি বুলিয়ান মান `||`-এর ডান দিকে এবং অন্যটি বাম দিকে বসানো উচিত।

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### নট(`!`)

Crystal-এ _নট_ অপারেটর `!` দিয়ে প্রকাশ করা হয় এবং প্রদত্ত বুলিয়ানটি `false` হলে `true` রিটার্ন করে, আর `true` দিলে `false` রিটার্ন করে।
_নট_ অপারেটর ব্যবহার করার সময় বুলিয়ান মানটি অপারেটরের (`!`) পরে বসানো উচিত।

```crystal
!true
# => false

!false
# => true
```

## বন্ধনী(`()`) ব্যবহার

বুলিয়ান নিয়ে কাজ করার সময়, কোন বুলিয়ানটি আগে মূল্যায়ন হবে তা ঠিক করতে আপনি বন্ধনী ব্যবহার করতে পারেন।
বন্ধনী কীভাবে ব্যবহার করা হয়েছে তার উপর নির্ভর করে ফলাফল ভিন্ন হতে পারে।
Crystal-এ বন্ধনীর ভেতরের অংশ আগে মূল্যায়ন করা হয়।

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

যেহেতু বন্ধনীর ভেতরের অংশ আগে মূল্যায়ন করা হয়, তাই নিচের উদাহরণে _নট_ অপারেটরটি বন্ধনীর ভেতরের এক্সপ্রেশনের উপর প্রযোজ্য হবে।

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
বন্ধনী কেবল তখনই ব্যবহার করা উচিত যখন সেগুলো ফলাফলকে প্রভাবিত করে; অন্যথায় সেগুলো বাদ দেওয়া উচিত।
~~~~
