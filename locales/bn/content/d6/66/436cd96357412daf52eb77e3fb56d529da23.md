# ভূমিকা

`Time` মডিউলটি মানুষের পড়ার উপযোগী তারিখ ও সময় দেখানোর কাজে ব্যবহৃত হয়। কারিগরি দিক থেকে `Time` দিয়ে সময় নিয়ে কাজ করা সম্ভব হলেও, Elm কমিউনিটির এমন কিছু প্যাকেজ আছে যেগুলো এই কাজের জন্য অনেক বেশি উপযুক্ত, যেমন [`justinmimbs/date`][date] বা [`CoderDennis/elm-time-format`][elm-time-format]।

## Posix

সময়কে উপস্থাপন করা হয় `Posix` নামের অস্বচ্ছ টাইপ দিয়ে, যা ইউনিক্স এপক টাইম ধারণ করে, অর্থাৎ ১৯৭০ সালের ১ জানুয়ারি UTC মধ্যরাত থেকে যত মিলিসেকেন্ড পেরিয়ে গেছে সেই সংখ্যা। একটি `Posix` হলো দ্ব্যর্থহীন একটি মান, যা টাইম জোন থেকে জোনে বদলায় না, তাই সময় ধরে রাখার জন্য এটি ভালো একটি পছন্দ। একটি Elm অ্যাপ্লিকেশনে `Posix` সময় সাধারণত বাইরের সূত্র থেকে পাওয়া যায়, যেমন ব্রাউজার।

নিচের ফাংশনগুলো দিয়ে একটি `Posix`-কে মিলিসেকেন্ডের সংখ্যায় রূপান্তর করা যায়, আবার উল্টোটাও করা যায়:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## টাইম জোন

দৈনন্দিন জীবনে আমরা মানুষরা সাধারণত `Posix` পড়ি না, বরং স্থানীয় সময় পছন্দ করি, যা পৃথিবীতে আমাদের অবস্থান এবং স্থানীয় ডেলাইট-সেভিং নিয়মের উপর নির্ভর করে। Elm-এ এই তথ্য সংকেতবদ্ধ থাকে `Zone` নামের অস্বচ্ছ টাইপে, যা সাধারণত ব্রাউজার থেকে আসে।

এমন একটি বিশেষ `Zone` আছে যা সবসময় ব্যবহার করা যায়:

```elm
utc : Zone
```

## মানুষের উপযোগী সময়

একটি `Posix` আর একটি `Zone` হাতে থাকলে, যেকোনো মাত্রার বিস্তারিতসহ স্থানীয় সময় দেখানোর জন্য প্রয়োজনীয় সব তথ্য আমাদের থাকে। সেটার জন্য ব্যবহার করা যায় এমন ফাংশনগুলোর তালিকা এখানে:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

আপনি নিশ্চয়ই আরও দুটি `Time` কাস্টম টাইপ খেয়াল করেছেন:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

এই কাস্টম টাইপগুলোকে মানুষের পড়ার উপযোগী মানে রূপান্তরের দায়িত্ব ব্যবহারকারীর উপর ছেড়ে দেওয়া হয়েছে।
