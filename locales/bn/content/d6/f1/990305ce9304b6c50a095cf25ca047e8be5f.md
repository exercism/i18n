# নির্দেশনা সংযুক্তি

## অতিরিক্ত নির্দেশনা

আপনাকে "isogram" নামে একটি টেবিল দেওয়া হবে।
প্রথম কলাম, "phrase", কিছু টেক্সট ধারণ করে।
ফ্রেজটি আইসোগ্রাম কিনা তা আপনাকে নির্ধারণ করতে হবে।
দ্বিতীয় কলাম, "is_isogram", একটি ইন্টিজার মান দিয়ে আপডেট করুন:

* 1 যদি ফ্রেজটি একটি আইসোগ্রাম হয়,
* 0 যদি ফ্রেজটি আইসোগ্রাম না হয়।

~~~~exercism/note
SQLite-এর তুলনা অপারেশনগুলো বুলিয়ান মান 0/1 সংখ্যা হিসেবে রিটার্ন করে।

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
