# অ্যানোনিমাস ফাংশন ও ক্লোজার সম্পর্কে

PHP অন্য ফাংশনের ভেতরে ফাংশন ডিক্লেয়ার করার সুযোগ দেয়। এই ফাংশনগুলোর নাম থাকার দরকার নেই, তবে এগুলো ভ্যারিয়েবলে অ্যাসাইন করা যায়, এমনকি সরাসরি অন্য একটি ফাংশনে পাসও করা যায়, যেটি একটি ফাংশন প্যারামিটার চায়।

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

উপরের কোডে যে ফাংশনটি ডিফাইন করে `array_filter`-এ পাস করা হয়েছে, সেটিই একটি অ্যানোনিমাস ফাংশন। `array_filter` এই ফাংশনটি দিয়ে ঠিক করে, অ্যারেতে থাকা কোনো একটি নির্দিষ্ট মান `array_filter`-এর ফলাফলে রিটার্ন হবে কি না। ফাংশনটি কোনো মানের জন্য `true` রিটার্ন করলে, সেটি ফলাফল অ্যারেতে যুক্ত হবে।

অ্যানোনিমাস ফাংশন দিয়ে ফাংশনের বাইরে স্কোপে থাকা ভ্যারিয়েবল ফাংশনের ভেতর থেকে রেফার করাও যায়। একে বলা হয় ফাংশনের স্কোপ ভ্যারিয়েবলটির উপর "ক্লোজ" হচ্ছে, আর সেখান থেকেই "ক্লোজার" নামটি এসেছে। কিছু ভাষায় স্কোপে থাকা সব ভ্যারিয়েবলই স্বয়ংক্রিয়ভাবে ক্লোজারের ভেতরে ব্যবহার করা যায়। PHP-তে বর্তমান অবজেক্টকে বোঝানো `$this` স্বয়ংক্রিয়ভাবে ক্লোজারের ভেতরে ব্যবহার করা যায়। বাকি সব ভ্যারিয়েবল `use` কিওয়ার্ড দিয়ে স্পষ্টভাবে রেফার করতে হয়।

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

উপরের `makeAdderFunction` ফাংশনে যে `$number` মানটি পাস করা হয়, সেটি ভেতরে ডিফাইন করা অ্যানোনিমাস ফাংশনের উপর "ক্লোজ" হয়ে যায়, আর পরে ওই ফাংশনটিই রিটার্ন করা হয়। এরপর ওই ফাংশনটি যখনই চালানো হয়, তখন সেটি জানে যে `$number`-এর কোন মানটি পাস করা হয়েছিল। আপনি যদি আবার অন্য একটি সংখ্যা দিয়ে এই ফাংশনটি কল করেন, তাহলে সেটি সম্পূর্ণ আলাদা একটি ফাংশন রিটার্ন করবে। এতে প্রথম ফাংশন কলের মান বা কার্যকারিতা বদলে যাবে না।
একটির বেশি ভ্যারিয়েবল ক্লোজ করার দরকার হলে কমা দিয়ে আলাদা করে সেগুলো `use` কিওয়ার্ডে যোগ করা যায়।

PHP-তে আরও ছোট একটি ফাংশন সিনট্যাক্স আছে, যার নাম `arrow functions`। এগুলো বেশ সহজ হতে হয়। এগুলোর মূল রূপটি হলো:

```php
fn(arguments) => expression
```

এই ফাংশন স্টাইলে আপনাকে `use` ব্যবহার করতে হবে না। এটি স্বয়ংক্রিয়ভাবে প্যারেন্ট স্কোপের যেকোনো মান ক্লোজ করে ক্যাপচার করে নেবে। এই অ্যারো ফাংশনগুলোর এক্সপ্রেশন `return` কিওয়ার্ড ব্যবহার না করেই স্বয়ংক্রিয়ভাবে রিটার্ন হয়ে যায়। তাই উপরের `onlyOdds` ফাংশনটি এভাবে নতুন করে লেখা যায়:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

উপরের `makeAdderFunction` এভাবে নতুন করে লেখা যায়:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**নোট:** ফাংশনটি যদি একটি এক্সপ্রেশন হিসেবে লেখা না যায়, তাহলে ছোট অ্যারো ফাংশন সিনট্যাক্সটি ব্যবহার করা যাবে না।

অ্যানোনিমাস ফাংশন ও ক্লোজারে ভ্যারিয়েবল মান হিসেবে পাস হয় এবং ব্যবহৃত হয়। এর মানে হলো, আপনি ফাংশনের ভেতরে ভ্যারিয়েবলের মান বদলালে ফাংশনের বাইরের ভ্যারিয়েবলের মানে তার কোনো প্রভাব পড়বে না। মানটি বদলানোর দরকার হলে আপনাকে সেটি রেফারেন্স হিসেবে পাস করতে হবে।

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

উপরের উদাহরণে `array_walk` অ্যারেটির প্রতিটি এলিমেন্টের উপর ইটারেশন করে, প্রতিটি মান কলের মধ্যে ডিক্লেয়ার করা ফাংশনে পাঠায়। এটি `$total`-এ একটি চলমান যোগফল রাখে, যেখানে প্রতিবার যোগ হওয়া মানটি সংখ্যাটির পরম মান। এটি আরও মনে রাখে কতগুলো সংখ্যা ছিল। দুটি মানই ক্লোজারে রেফারেন্স হিসেবে ব্যবহৃত হয়, যা `use` অংশে প্রতিটি ভ্যারিয়েবলের সামনে থাকা `&` দিয়ে বোঝানো হয়। এর মানে হলো `array_walk` শেষ হলে ভ্যারিয়েবলগুলোতে হওয়া পরিবর্তনগুলো তখনও থাকবে, তাই ফাংশনটি অ্যারের সংখ্যাগুলোর পরম মানের গড় রিটার্ন করতে পারে।

অ্যানোনিমাস ফাংশন ও ক্লোজার এমন একটি ফাংশন ডিফাইন করার সুবিধাজনক উপায় দিতে পারে, যেটি হয়তো কেবল একটি নির্দিষ্ট প্রেক্ষাপটেই দরকার, অথবা এমন একটি ফাংশন ডিফাইন করতে পারে যেটি কিছু প্যারামিটারের ভিত্তিতে একটি ডায়নামিক ফাংশন রিটার্ন করে, যেসব প্যারামিটার ফাংশনটি আসলে ব্যবহৃত হওয়ার সময়ের চেয়ে আলাদা সময়ে জানা থাকে।
