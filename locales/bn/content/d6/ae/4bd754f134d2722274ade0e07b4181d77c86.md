# সম্পর্কে

Java-এর `char` প্রিমিটিভ টাইপ হলো একটি Unicode ক্যারেক্টারের ১৬ বিটের রিপ্রেজেন্টেশন।

~~~~exercism/note
`char` টাইপটি [Unicode-এর মূল স্পেসিফিকেশন][unicode-specification]-এর উপর ভিত্তি করে তৈরি, যা ক্যারেক্টার রিপ্রেজেন্ট করতে ১৬ বিট ব্যবহার করত।
এটি বেশিরভাগ কমন অক্ষর কভার করার জন্য যথেষ্ট, আর 0x0000 থেকে 0xFFFF রেঞ্জের ক্যারেক্টারগুলো কভার করে।
স্পেসিফিকেশনটি এরপর থেকে সম্ভাব্য ক্যারেক্টারের রেঞ্জ 0x01FFFF পর্যন্ত বাড়িয়েছে।

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

একাধিক `char` মিলে একটি স্ট্রিং তৈরি করতে পারে, যেমন `"word"`, আবার `char`গুলোকে আলাদাভাবেও প্রসেস করা যায়।
একটি `char` লিটারেল একক কোট চিহ্নের মধ্যে লেখা হয় (যেমন `'A'`)।

```java
char lowerA = 'a';
char upperB = 'B';
```

## একটি `String` থেকে `char`গুলো পাওয়া

`String.toCharArray` মেথড একটি String-এর ক্যারেক্টারগুলোকে একটি অ্যারে হিসেবে রিটার্ন করে।
[arrays][concept-arrays]-এ যেমন বলা হয়েছে, আপনি একটি `for` লুপ দিয়ে অ্যারের উপর ইটারেশন করতে পারেন।

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## [Character][docs-character] ক্লাস

`char` যাচাই ও ম্যানিপুলেট করার জন্য লাইব্রেরিতে অনেক বিল্ট-ইন মেথড রয়েছে।
এগুলো [`java.lang.Character`][docs-character] ক্লাসের স্ট্যাটিক মেথড হিসেবে পাওয়া যায়।
এখানে কিছু উদাহরণ দেওয়া হলো:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Character ক্লাসের কিছু মেথডে একটি ওভারলোড আছে, যাতে সেগুলো একটি `char` বা একটি `int` দুটোরই নিতে পারে।
যেমন, `isDigit`-এর একটি ওভারলোড [`char`][is-digit-char] গ্রহণ করে আর অন্যটি [`int`][is-digit-int]।
যেমনটি আগে বলা হয়েছে, `char` টাইপ কেবল 0x0000 থেকে 0xFFFF রেঞ্জের ক্যারেক্টারগুলোই রিপ্রেজেন্ট করতে পারে।
অন্যদিকে `int` সব ক্যারেক্টারই রিপ্রেজেন্ট করতে পারে, তাই `int` ওভারলোডগুলো রয়েছে।

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## একটি `String`-এর সাথে একটি `char` যোগ করা

একটি `String`-এর সাথে একটি `char` যোগ করতে `+` অপারেটর ব্যবহার করা যায়।

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
দুটি `char` জোড়া লাগিয়ে একটি `String` তৈরি করতে `+` ব্যবহার করবেন _না_!
এভাবে দুটি `char` যোগ করলে একটি `int` পাওয়া যায়, `String` _নয়_!
যেমন:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

এর কারণ হলো Java `char`-কে একটি `int`-এ প্রোমোট করে (দেখুন [4.2 Primitive Types and Values ][jls-primitives], যা [Java Language Specification][jls-main]-এর অংশ)।

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

তবে যখন যোগ করার মতো অনেক ক্যারেক্টার থাকে, তখন এর বদলে একটি [`StringBuilder`][docs-stringBuilder] ব্যবহার করা বেশি কার্যকর হতে পারে:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
