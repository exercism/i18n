# পরিচিতি

Elixir-এর স্ট্যান্ডার্ড লাইব্রেরি তারিখ ও সময় নিয়ে কাজ করার জন্য ৪টি আলাদা মডিউল দেয়, যার প্রতিটির নিজস্ব স্ট্রাক্ট আছে।

- [`Date` মডিউলটি][date]। [`~D` সিজিল][sigil-d] দিয়ে একটি `Date` স্ট্রাক্ট তৈরি করা যায়।
    ```elixir
    ~D[2021-01-01]
    ```

- [`Time` মডিউলটি][time]। [`~T` সিজিল][sigil-t] দিয়ে একটি `Time` স্ট্রাক্ট তৈরি করা যায়।
    ```elixir
    ~T[12:00:00]
    ```

- টাইমজোন ছাড়া ডেটটাইমের জন্য [`NaiveDateTime` মডিউলটি][naivedatetime]। [`~N` সিজিল][sigil-n] দিয়ে একটি `NaiveDateTime` স্ট্রাক্ট তৈরি করা যায়।
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- টাইমজোন-সহ ডেটটাইমের জন্য [`DateTime` মডিউলটি][datetime]। UTC ছাড়া অন্য টাইমজোনের জন্য এই মডিউলটি ব্যবহার করতে একটি বাহ্যিক ডিপেন্ডেন্সি লাগে, একটি টাইমজোন ডেটাবেস। [`~U` সিজিল][sigil-u] দিয়ে একটি `DateTime` স্ট্রাক্ট লেখা যায়, তবে এটি তৈরি করা উচিত `DateTime`-এর ফাংশন দিয়ে।
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## তুলনা

তারিখ বা সময়ের মধ্যে তুলনা করতে সংশ্লিষ্ট মডিউলে একটি `compare` বা `diff` ফাংশন খুঁজুন। `==`, `>`, আর `<`-এর মতো তুলনা অপারেটরগুলো কাজ করে বলে _মনে হয়_, কিন্তু এই স্ট্রাক্টগুলোর জন্য তারা সঠিক অর্থগত তুলনা করে না।

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## শিফট করা

তারিখ, সময় আর ডেটটাইম সংশ্লিষ্ট মডিউলের `add/2` ফাংশন দিয়ে সময়ের মধ্যে সামনে ও পিছনে শিফট করা যায়।

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## রূপান্তর

[`NaiveDateTime.to_date/1`][naivedatetime-to-date] আর [`NaiveDateTime.to_time/1`][naivedatetime-to-time] দিয়ে একটি `NaiveDateTime` স্ট্রাক্টকে ভেঙে একটি `Date` স্ট্রাক্ট ও একটি `Time` স্ট্রাক্টে পরিণত করা যায়। [`NaiveDateTime.new!/2`][naivedatetime-new] দিয়ে এর উল্টোটা করা যায়।

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
