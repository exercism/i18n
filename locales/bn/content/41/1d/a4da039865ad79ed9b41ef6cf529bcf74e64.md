# ইনস্টলেশন

প্রথমে নিশ্চিত হয়ে নিন যে আপনার সিস্টেমে Erlang ইনস্টল করা আছে। এর জন্য আপনার ক্ষেত্রে যেভাবে প্রযোজ্য সেভাবে [Erlang][1] ইনস্টলেশন পেজে দেওয়া নির্দেশনাগুলো অনুসরণ করুন।
[1]: /languages/erlang

## Mac OS X-এর জন্য Homebrew

আপনার Homebrew সর্বশেষ সংস্করণে আপডেট করুন:

```bash
$ brew update
```

LFE ইনস্টল করুন:

```bash
$ brew install lfe
```

## সোর্স থেকে ইনস্টল করা

আপনার সিস্টেমের "ডেভেলপার টুলস" বা "অপরিহার্য বিল্ড প্যাকেজ", `git` এবং Erlang-এর `erl` ইনস্টল করুন।

উদাহরণস্বরূপ, Ubuntu 18.04-এ:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

এরপর আপনি নিচের কমান্ডগুলো দিয়ে LFE ডাউনলোড করে বিল্ড করতে পারেন:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

LFE কম্পাইল হয়ে গেলে আপনি ``lfe`` বাইনারিটি চালিয়ে REPL (ইন্টার‍্যাক্টিভ সেশন) শুরু করতে পারেন:

```bash
$ ./bin/lfe
```
