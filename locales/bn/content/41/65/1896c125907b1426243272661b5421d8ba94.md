# ইঙ্গিত

## সাধারণ

- Getting Started গাইডে [`alias` এবং `import`][getting-started] সম্পর্কে পড়ুন।
- elixirschool.com সাইটে [মডিউল কম্পোজিশন][elixir-school-module-composition] সম্পর্কে পড়ুন।

## 1. কম্পাইলেশন এরর `Race.__struct__/0 is undefined` ঠিক করুন

- একটি অ্যালিয়াস [`alias`][alias] স্পেশাল ফর্ম দিয়ে তৈরি করা যায়।

## 2. কম্পাইলেশন এরর `Car.__struct__/0 is undefined` ঠিক করুন

- একটি অ্যালিয়াস [`alias`][alias] স্পেশাল ফর্ম দিয়ে তৈরি করা যায়।
- `alias` স্পেশাল ফর্মটি একটি `:as` অপশন গ্রহণ করে।

## 3. কম্পাইলেশন এরর `undefined function puts/1` ঠিক করুন

- ফাংশনগুলো [`import`][import] স্পেশাল ফর্ম দিয়ে ইমপোর্ট করা যায়।
- [`import`][import] স্পেশাল ফর্মটি একটি `:only` অপশন গ্রহণ করে। এর মান একটি কিওয়ার্ড অ্যারে হওয়া উচিত, যেখানে ফাংশনের নাম কী (key) হিসেবে এবং ফাংশনের আর্গুমেন্ট সংখ্যা ভ্যালু হিসেবে থাকে।

## 4. কম্পাইলেশন এরর `undefined function default_color/0` ঠিক করুন

- ফাংশনগুলো [`import`][import] স্পেশাল ফর্ম দিয়ে ইমপোর্ট করা যায়।
- [`import`][import] স্পেশাল ফর্মটি একটি `:except` অপশন গ্রহণ করে। এর মান একটি কিওয়ার্ড অ্যারে হওয়া উচিত, যেখানে ফাংশনের নাম কী (key) হিসেবে এবং ফাংশনের আর্গুমেন্ট সংখ্যা ভ্যালু হিসেবে থাকে।
