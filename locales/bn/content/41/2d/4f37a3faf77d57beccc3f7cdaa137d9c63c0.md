# নির্দেশাবলি

এলেনা একটি সংবাদপত্র কারখানার নতুন কোয়ালিটি ম্যানেজার।
কোম্পানিতে সদ্য যোগ দেওয়ায় তিনি কারখানার কিছু প্রক্রিয়া পর্যালোচনা করার সিদ্ধান্ত নিয়েছেন, যাতে দেখা যায় কী কী উন্নত করা যায়।
তিনি আবিষ্কার করেন যে টেকনিশিয়ানরা অনেক কোয়ালিটি চেক নিজ হাতে করে। অটোমেশনের জন্য এটি একটি ভালো সুযোগ বলে তিনি মনে করেন এবং আপনাকে, একজন ফ্রিল্যান্স ডেভেলপার হিসেবে, কিছু মেশিন মনিটর করার জন্য একটি সফটওয়্যার তৈরি করতে বলেন।

## 1. ঘরের আর্দ্রতার মাত্রা যাচাই করুন

আপনার প্রথম কাজ হলো উৎপাদন কক্ষের আর্দ্রতার মাত্রা মনিটর করার জন্য একটি সফটওয়্যার লেখা। কোম্পানির সফটওয়্যারের সাথে আগে থেকেই একটি সেন্সর যুক্ত আছে, যা নিয়মিতভাবে ঘরের আর্দ্রতার শতাংশ ফেরত দেয়।

সফটওয়্যারে আপনাকে একটি ফাংশন ইমপ্লিমেন্ট করতে হবে, যা আর্দ্রতার শতাংশ বেশি হলে একটি এরর থ্রো করবে।
আর্দ্রতা গ্রহণযোগ্য মাত্রায় থাকলে একটি ইনফো লগ যোগ করা হবে।
ফাংশনটির নাম হবে `humiditycheck` এবং এটি আর্গুমেন্ট হিসেবে আর্দ্রতার শতাংশ নেবে।

শতাংশ 70%-এর বেশি হলে আপনাকে একটি ErrorException দিয়ে থামতে হবে (সঠিক বার্তাটি গুরুত্বপূর্ণ নয়, তবে তাতে মাপা আর্দ্রতার মাত্রা থাকতে হবে)।
অন্যথায় একটি Info লগ যোগ করুন, যার বার্তা `"humidity level check passed: h%"`, যেখানে `h` হলো আর্দ্রতার শতাংশ।

```julia-repl
julia> humiditycheck(60)
[ Info: humidity level check passed: 60%
```

```julia-repl
julia> humiditycheck(100)
ERROR: humidity check failed: 100%
```

## 2. অতিরিক্ত গরম হওয়া যাচাই করুন

এলেনা আপনার প্রথম অ্যাসাইনমেন্টে খুব খুশি এবং মেশিনগুলোর তাপমাত্রা মনিটর করার দায়িত্ব আপনাকে দেন।
টেকনিশিয়ান গ্রেগের সাথে কথা বলার সময় আপনাকে বলা হয় যে কোনো মেশিনের তাপমাত্রা 500°C ছাড়িয়ে গেলে টেকনিশিয়ানরা অতিরিক্ত গরম হওয়া নিয়ে চিন্তা করতে শুরু করেন।

মেশিনটিতে একটি সেন্সর লাগানো আছে, যা তার অভ্যন্তরীণ তাপমাত্রা মাপে।
জেনে রাখুন, সেন্সরটি খুবই সংবেদনশীল এবং প্রায়ই নষ্ট হয়ে যায়।
সেক্ষেত্রে টেকনিশিয়ানদের এটি বদলাতে হবে।

আপনার কাজ হলো `temperaturecheck` নামে একটি ফাংশন ইমপ্লিমেন্ট করা, যা আর্গুমেন্ট হিসেবে তাপমাত্রা নেয় এবং সবকিছু ঠিক থাকলে একটি লগ যোগ করে, অন্যথায় সেন্সর নষ্ট হলে বা মেশিন অতিরিক্ত গরম হতে শুরু করলে একটি এরর থ্রো করে।
পরে এরর অনুযায়ী ভিন্নভাবে প্রতিক্রিয়া জানাতে হবে জেনে, দুই ধরনের এরর আলাদা করার একটি ব্যবস্থা আপনার দরকার।

- সেন্সর নষ্ট হলে তাপমাত্রা হবে `nothing`।
  সেক্ষেত্রে আপনাকে একটি `ArgumentError` দিয়ে থামতে হবে (বার্তাটি গুরুত্বপূর্ণ নয়)।
- সেন্সর কাজ করলে, তাপমাত্রা 500°C ছাড়িয়ে গেলে আপনাকে একটি `DomainError` থ্রো করতে হবে, যাতে মাপা তাপমাত্রা থাকবে।
- অন্যথায় সবকিছু ঠিক আছে, তাই একটি Info লগ যোগ করুন, যার বার্তা `"temperature check passed: t °C"`, যেখানে `t` হলো তাপমাত্রা।

```julia-repl
julia> temperaturecheck(nothing)
ERROR: ArgumentError: sensor is broken

julia> temperaturecheck(800)
ERROR: DomainError with 800:
"overheating detected"

julia> temperaturecheck(500)
[ Info: temperature check passed: 500 °C
```

## 3. কাস্টম এরর ডিফাইন করুন

পরের কাজের জন্য আপনাকে আরও সাধারণ, সব ধরনের ক্ষেত্রে প্রযোজ্য একটি এরর ডিফাইন করতে হবে।
এটি একটি এরর হওয়া এবং নামটি `MachineError` হওয়া ছাড়া ইমপ্লিমেন্টেশনের বিস্তারিত গুরুত্বপূর্ণ নয়।
আপনার সুবিধামতো ফিল্ড ও বার্তা যোগ করতে পারেন।

## 4. মেশিন মনিটর করুন

এখন আপনার মেশিন এরর ধরতে পারে এবং আপনার একটি কাস্টম মেশিন এরর আছে, তাই আপনি একটি র‍্যাপার ফাংশন যোগ করেন, যা সবকিছু কেমন চলছে তা জানাতে পারে।
আগের ফাংশনগুলোর লগ রিটার্ন করা ছাড়াও, এই র‍্যাপারকে ঘটে যাওয়া যেকোনো ধরনের ব্যর্থতার ওপর নির্ভর করে লগ যোগ করতে হবে।

- আর্দ্রতা ও তাপমাত্রা যাচাই করুন।
- আর্দ্রতা যাচাই একটি `ErrorException` থ্রো করলে, `"humidity level check failed: h%"` বার্তাসহ একটি Error লগ যোগ করতে হবে, যেখানে `h` হলো আর্দ্রতার শতাংশ।
- তাপমাত্রা যাচাই একটি `ArgumentError` থ্রো করলে, `"sensor is broken"` বার্তাসহ একটি Warn লগ যোগ করতে হবে।
- তাপমাত্রা যাচাই একটি `DomainError` থ্রো করলে, `"overheating detected: t °C"` বার্তাসহ একটি Error লগ যোগ করতে হবে, যেখানে `t` হলো তাপমাত্রা।
- দুটি যাচাইয়ের যেকোনো একটি বা দুটিই ব্যর্থ হলে, লগগুলো যোগ করার পর একটি মাত্র `MachineError` থ্রো করতে হবে।
- সবকিছু ঠিক থাকলে, কেবল `humiditycheck` ও `temperaturecheck`-এর লগগুলো যোগ করা হবে।

আর্গুমেন্ট হিসেবে আর্দ্রতা ও তাপমাত্রা নেয় এমন একটি `machinemonitor()` ফাংশন ইমপ্লিমেন্ট করুন।

```julia-repl
julia> machinemonitor(42, 450)
[ Info: humidity level check passed: 42%
[ Info: temperature check passed: 450 °C

julia> machinemonitor(42, 550)
[ Info: humidity level check passed: 42%
┌ Error: overheating detected: 550 °C
└ @ Main # output truncated

Error: MachineError

julia> machinemonitor(82, 521)
┌ Error: humidity level check failed: 82%
└ @ Main # output truncated
┌ Error: overheating detected: 521 °C
└ @ Main # output truncated

Error: MachineError

julia> machinemonitor(42, nothing)
[ Info: humidity level check passed: 42%
┌ Warning: sensor is broken
└ @ Main # output truncated

Error: MachineError
```
