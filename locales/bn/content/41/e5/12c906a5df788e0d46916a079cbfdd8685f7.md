# সম্পর্কে

Ruby-এর সাথে আসে একটি স্ট্যান্ডার্ড লাইব্রেরি (প্রায়ই সংক্ষেপে "stdlib" বলা হয়), যেখানে তারিখ, json আর নেটওয়ার্কিংয়ের মতো জিনিস নিয়ে কাজ করার জন্য অনেক ক্লাসের সংগ্রহ থাকে।
এটি আপনার কোড নিয়ে কাজ করা আরও সহজ করে তোলার কিছু দরকারি সুবিধাও দেয়।

`OpenStruct` স্ট্যান্ডার্ড লাইব্রেরির একটি অংশ, আর এটি আপনাকে `Hash` থেকে সহজে একটি অবজেক্ট তৈরি করতে দেয়।
`Hash`-এর কী (key) দিয়ে অ্যাক্সেস করতে না গিয়ে, `OpenStruct` বদলে আমাদের মেথড দিয়ে মান অ্যাক্সেস করা আর সেট করার সুবিধা দেয়।

স্ট্যান্ডার্ড লাইব্রেরি বা অন্য যেকোনো লাইব্রেরির ক্লাস ব্যবহার করার সময়, `require` মেথড দিয়ে সেই ক্লাসটি `require` করে নিতে হয়।

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

এর একটি বাড়তি সুবিধা হলো, ব্লক সিনট্যাক্স ব্যবহার করার সময় আপনি একটি শর্টকাটের সুযোগ নিতে পারেন।
এমন পরিস্থিতিতে যেখানে একটি ব্লক একটিমাত্র মেথড কল করে, সেখানে আপনি ব্লকটির বদলে `&:` আর তার পরে মেথডের নাম বসাতে পারেন।
যেমন, এই দুই লাইন একই কাজ করে:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
