# ইনস্টলেশন

আপনার [NodeJS LTS](https://nodejs.org/en) প্রয়োজন।

> 💡 এই ট্র্যাক সম্ভবত পুরনো স্টেবল ভার্সনগুলোর সাথে, সেইসাথে "current" ভার্সনের সাথেও কাজ করে।
> তবে [ডিজাইন অনুযায়ী](https://github.com/nodejs/release#release-schedule), বিজোড় ভার্সন কখনোই স্টেবল হয় না।
> সবসময় খেয়াল রাখুন যেন আপনি NodeJS-এর একটি জোড় ভার্সন ইনস্টল করেন।

Node.JS-এর `corepack` ব্যবহার করে [Yarn 4+](https://yarnpkg.com/getting-started/install) ইনস্টল করুন:

```shell
corepack enable yarn
```

## আপনার ইনস্টলেশন যাচাই করা

সদ্য ইনস্টল করা বাইনারি ব্যবহার করতে সাধারণত আপনাকে একটি নতুন টার্মিনাল খুলতে হবে।

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_লক্ষ্য করুন: আপনার ভার্সনগুলো সম্ভবত এর থেকে আলাদা হবে।_

## অনুশীলনীর ইনস্টলেশন

**প্রতিটি অনুশীলনীর** টেস্ট চালানোর জন্য কিছু টুল দরকার:

প্রতিটি অনুশীলনীর ডিরেক্টরির ভেতরে এই কমান্ডটি চালিয়ে সেগুলো ইনস্টল করা যায়:

```bash
$ corepack yarn install
```

আপনার এডিটরের উপর নির্ভর করে, Plug'n'Play ইনস্টলের সাথে কাজ করার জন্য প্রতিটি অনুশীলনীতে [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks) ইনস্টল করা প্রয়োজন।
এই লেখার সময়ে নিচেরগুলো সমর্থিত:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)

উদাহরণস্বরূপ, VSCode ব্যবহার করলে আপনি যে কমান্ডগুলো চালাবেন সেগুলো হলো:
