# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা আপনার প্রিয় রান্নার বই থেকে একটি চমৎকার লাসানিয়া রান্না করতে আপনাকে সাহায্য করবে।

আপনার সামনে পাঁচটি কাজ আছে, যেগুলোর সবই লাসানিয়া রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

`expectedMinutesInOven` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং ওভেনে লাসানিয়াটি কত মিনিট থাকা উচিত তা রিটার্ন করে। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```haskell
expectedMinutesInOven
-- -> 40
```

## 2. ওভেনে অবশিষ্ট সময় মিনিটে হিসাব করুন

`remainingMinutesInOven` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসানিয়া এতক্ষণ কত মিনিট ধরে ওভেনে আছে তা নেয় এবং আগের কাজের ওভেনে প্রত্যাশিত সময় মিনিটের ভিত্তিতে লাসানিয়াকে আর কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```haskell
remainingMinutesInOven 30
-- -> 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTimeInMinutes` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসানিয়ায় আপনি যে সংখ্যক স্তর যোগ করেছেন তা নেয় এবং লাসানিয়া প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন তা রিটার্ন করে; ধরে নিন প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```haskell
preparationTimeInMinutes 3
-- -> 6
```

## 4. অতিবাহিত সময় মিনিটে হিসাব করুন

`totalTimeInMinutes` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসানিয়ায় আপনি যে সংখ্যক স্তর যোগ করেছেন, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসানিয়া কত মিনিট ধরে ওভেনে আছে। ফাংশনটি রিটার্ন করবে লাসানিয়া রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসানিয়া ওভেনে যে সময় মিনিটে ব্যয় করেছে তার যোগফল।

```haskell
elapsedTimeInMinutes 3 20
-- -> 26
```

## 5. লাসানিয়া তৈরি হয়ে গেছে জানিয়ে একটি নোটিফিকেশন তৈরি করুন

`alarm` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং লাসানিয়া খাওয়ার জন্য তৈরি হয়ে গেছে বোঝায় এমন একটি মেসেজ রিটার্ন করে।

```haskell
alarm
-- -> "Ding!"
```
