# ইঙ্গিত

## 1. একটি নির্দিষ্ট ধরনের কতগুলো কার্ড ডেকে আছে তা নির্ধারণ করুন

- প্রথমে, নির্দিষ্ট ধরনের কার্ডের সংখ্যা ট্র্যাক করার জন্য একটি ইন্টিজার ভ্যারিয়েবল সেট আপ করুন।
- এরপর নির্দেশাবলিতে যেমন বলা হয়েছে, ডেকের ওপর ইটারেশন করতে [forEach][mdn-foreach] ব্যবহার করুন।
- কাঙ্ক্ষিত ধরনের একটি কার্ড পেলে কলব্যাকে আপনার কাউন্টার ভ্যারিয়েবলটি বাড়িয়ে নিন।

## 2. কতগুলো বিজোড় বা জোড় কার্ড আছে তা নির্ধারণ করুন

- প্রথমে, কাঙ্ক্ষিত ধরনের (বিজোড় বা জোড়) কার্ডের সংখ্যা ট্র্যাক করার জন্য একটি ইন্টিজার ভ্যারিয়েবল সেট আপ করুন।
- এরপর নির্দেশাবলিতে যেমন বলা হয়েছে, ডেকের ওপর ইটারেশন করতে [for...of][mdn-for-of] ব্যবহার করুন।
- ২ দিয়ে ভাগ করলে যে ভাগশেষ থাকে, তা থেকেই বোঝা যায় একটি সংখ্যা বিজোড় না জোড়।
  [মডুলো অপারেটর][mdn-modulo] `%` ব্যবহার করে আপনি ভাগশেষটি বের করতে পারেন।
- কাঙ্ক্ষিত ভাগশেষযুক্ত একটি সংখ্যায় পৌঁছালে আপনার কাউন্টার ভ্যারিয়েবলটি বাড়িয়ে নিন।

[mdn-foreach]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/forEach
[mdn-for-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of
[mdn-modulo]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Remainder
