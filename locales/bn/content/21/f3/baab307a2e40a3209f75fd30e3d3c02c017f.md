# পরিচিতি

Gleam Erlang ভার্চুয়াল মেশিনে (BEAM) বা JavaScript রানটাইমে চলতে পারে। এই রানটাইমগুলো আরও অনেক ভাষা ব্যবহার করে, আর এই ভাষাগুলোতে লেখা কোড Gleam থেকে কল করতে পারা অনেক সময়ই কাজে আসে।

Gleam-এর _এক্সটার্নাল ফাংশন_ ফিচারটি দিয়ে অন্য ভাষার ফাংশন Gleam-এ ইমপোর্ট করা যায় এবং কোনো রানটাইম ওভারহেড ছাড়াই কল করা যায়।

আপনার Gleam প্রজেক্ট যদি Erlang ভার্চুয়াল মেশিনে চলে এবং আপনি Erlang-এর `lists` মডিউল থেকে `reverse` ফাংশনটি কল করতে চান, তাহলে এভাবে একটি Gleam ফাংশন হেডে `@external` অ্যাট্রিবিউট যোগ করে তা করতে পারেন:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

এরপর এটিকে একটি সাধারণ Gleam ফাংশনের মতো কল করা যায়:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

এই কোডটি যদি আপনি JavaScript রানটাইমের জন্য কম্পাইল করার চেষ্টা করেন, তাহলে এটি একটি এরর মেসেজ দিয়ে ব্যর্থ হবে, কারণ JavaScript-এর জন্য কোনো ইমপ্লিমেন্টেশন নেই। এভাবে JavaScript রানটাইমের জন্য আরেকটি ইমপ্লিমেন্টেশন উল্লেখ করা যায়:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

এছাড়াও বর্তমান কম্পাইল টার্গেটের জন্য কোনো এক্সটার্নাল ইমপ্লিমেন্টেশন না থাকলে যে Gleam ইমপ্লিমেন্টেশন ব্যবহার করা হবে, সেটি লেখাও সম্ভব:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
