# নির্দেশনা

অ্যাস্ট্রিড নামের এক দুঃসাহসী আলকেমিস্ট বিভিন্ন জগৎ থেকে সংগৃহীত জাদুকরী পরিমাপ-এককগুলোকে একটি আদর্শ মানে আনতে চাইছেন।
কিছু জগৎ সাইনড পরিমাপ ব্যবহার করে (যা ঋণাত্মক হতে পারে), আবার অন্য জগৎগুলো আনসাইনড পরিমাপ ব্যবহার করে (যা সবসময় ধনাত্মক)।
তা ছাড়াও, কিছু বিরল উপকরণের জন্য অ্যাস্ট্রিডের কাছে দুটি কাস্টম টাইপ আছে, আর এই টাইপগুলোর মধ্যে সহজে রূপান্তর করার একটি উপায় তার দরকার।

আপনার কাজ হলো সাইনড ও আনসাইনড ইন্টিজারের মধ্যে রূপান্তরে অ্যাস্ট্রিডকে সাহায্য করা, এবং Cairo-র `Into` ও `TryInto` ট্রেইট ব্যবহার করে তার বিশেষ উপকরণ টাইপগুলোর জন্য কাস্টম টাইপ রূপান্তর তৈরি করা।

## 1. জাদুকরী একক সাইনড ও আনসাইনডের মধ্যে রূপান্তর

অ্যাস্ট্রিডের পরিমাপগুলো কখনো ধনাত্মক বা ঋণাত্মক মান হিসেবে আসে (সাইনড ইন্টিজার), কিন্তু কিছু কাজের জন্য তাকে নিশ্চিত করতে হয় যে মানগুলো সবসময় ধনাত্মক (আনসাইনড ইন্টিজার)।

এমন একটি ফাংশন লিখে অ্যাস্ট্রিডকে সাহায্য করুন যা রূপান্তর করে:

1. একটি সাইনড ইন্টিজার (`i32`) থেকে একটি আনসাইনড ইন্টিজার (`u16`)।
2. একটি আনসাইনড ইন্টিজার (`u16`) থেকে একটি সাইনড ইন্টিজার (`i32`)।

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. কাস্টম উপকরণ টাইপ রূপান্তর

অ্যাস্ট্রিড দুটি বিরল উপকরণ নিয়ে কাজ করেন, **Essence** আর **Elixir**, যেগুলো কাস্টম টাইপ দিয়ে প্রকাশ করা হয়।
তিনি **Essence**-কে **Elixir**-এ রূপান্তর করতে চান, কিন্তু উল্টো দিকে নয়।

দুটি কাস্টম টাইপ, `Essence` ও `Elixir`, তৈরি করে এবং `Essence` থেকে `Elixir`-এ রূপান্তর করার জন্য `Into` ট্রেইট ইমপ্লিমেন্ট করে অ্যাস্ট্রিডকে সাহায্য করুন।

এমন একটি ফাংশন লিখুন যা একটি `Essence` নেয় এবং `.into()` ব্যবহার করে সেটিকে একটি `Elixir`-এ রূপান্তর করে।

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
