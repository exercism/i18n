জাদুকর হতে চলা এলিসের কিছু মৌলিক বিষয় অনুশীলন করা দরকার।
তার কাছে তাসের একটি ডেক আছে, যা সে নাড়াচাড়া করতে চায়।

ব্যাপারটা একটু সহজ করতে সে শুধু ১ থেকে ১০ নম্বরের তাসগুলোই ব্যবহার করে।

## 1. ডেক থেকে একটি তাস বের করা

প্রদত্ত ডেক থেকে `idx` অবস্থানের তাসটি রিটার্ন করুন।

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. ডেকে একটি তাস বদল করা

প্রদত্ত নতুন তাসটি দিয়ে `idx` অবস্থানের তাসটি বদলে ফেলুন এবং বদলানো ডেকটি রিটার্ন করুন।
মনে রাখবেন, এটি ইনপুট ভেক্টরকে মিউটেট (পরিবর্তন) করবে, এবং এটা ঠিক আছে।

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. ডেকের উপরে একটি তাস ঢোকানো

ডেকের উপরে একটি নতুন তাস ঢুকিয়ে ডেকটি রিটার্ন করুন।

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. ডেক থেকে একটি তাস সরানো

ডেক থেকে `idx` অবস্থানের তাসটি সরিয়ে ডেকটি রিটার্ন করুন।

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. ডেকের উপরের তাসটি সরানো

ডেকের উপরের তাসটি সরিয়ে ডেকটি রিটার্ন করুন।

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. ডেকের নিচে একটি তাস ঢোকানো

ডেকের নিচে একটি নতুন তাস ঢুকিয়ে ডেকটি রিটার্ন করুন।

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. ডেকের নিচ থেকে একটি তাস সরানো

ডেকের নিচের তাসটি সরিয়ে ডেকটি রিটার্ন করুন।

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. ডেকের আকার যাচাই করা

ডেকের আকার প্রদত্ত `deck_size`-এর সমান কি না তা যাচাই করুন।

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
