# নির্দেশাবলি

আপনি আবার রান্নাঘরে ফিরেছেন, [লিয়ার সুস্বাদু লাসানিয়ার][lasagna] রেসিপিটি আরও নিখুঁত করতে। এখানকার কাজগুলোতে একসাথে বেশ কয়েকটি ইনপুট সামলাতে হবে, আর ঠিক তখনই *লোকাল*, অর্থাৎ Factor-এর নামযুক্ত বাইন্ডিং, কাজে আসে।

## 1. রান্নার স্ট্যাটাস নির্ণয় করুন

`cooking-status` ডিফাইন করুন, যা স্ট্যাক থেকে একটি টাইমার রিডিং নেয় এবং একটি স্ট্যাটাস স্ট্রিং রিটার্ন করে।

- `0` → `"Lasagna is done."`
- `f` (টাইমার কখনো সেট করা হয়নি) → `"You forgot to set the timer."`
- অন্য যেকোনো সংখ্যা → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. প্রস্তুতির সময় অনুমান করুন

`preparation-time` ডিফাইন করুন, যা লেয়ারের নামের একটি অ্যারে এবং প্রতি লেয়ারে মিনিটের একটি গড় সংখ্যা নেয়, আর মোট প্রস্তুতির সময় রিটার্ন করে।

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. প্রয়োজনীয় নুডলস ও সস হিসাব করুন

`quantities` ডিফাইন করুন, যা লেয়ারের নামের একটি অ্যারে নেয় এবং *দুটি* মান রিটার্ন করে: প্রয়োজনীয় নুডলসের গ্রাম (প্রতি নুডলস লেয়ারে 50 g) এবং প্রয়োজনীয় সসের লিটার (প্রতি সস লেয়ারে `1/5` লিটার)।

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. গোপন উপকরণ যোগ করুন

আপনার বন্ধু উপকরণের একটি তালিকা পাঠায়; তালিকার *শেষ* আইটেমটিই তার গোপন উপকরণ। `add-secret-ingredient` ডিফাইন করুন, যা তার তালিকা ও আপনার তালিকা নেয় এবং শেষে গোপন উপকরণটি যোগ করা আপনার তালিকাটি রিটার্ন করে।

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. রেসিপিটি স্কেল করুন

রান্নার বইয়ের রেসিপিতে দুই পোরশন হয়। `scale-recipe` ডিফাইন করুন, যা একটি রেসিপি (উপকরণের নাম থেকে পরিমাণে একটি হ্যাশটেবিল) এবং পোরশনের লক্ষ্য সংখ্যা নেয়, আর সেই অনুপাতে স্কেল করা একটি নতুন রেসিপি রিটার্ন করে।

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
