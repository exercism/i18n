# ডিকশনারি

কায়রোতে ডিকশনারি হলো কী (key)-ভ্যালু স্টোর, যা অন্য ভাষার ম্যাপ বা হ্যাশ টেবিলের মতো।

তবে কায়রোর ইমিউটেবল মেমোরি মডেলের কারণে এদের কিছু অনন্য বৈশিষ্ট্য আছে।

## মূল ধারণা

`Felt252Dict<T>` টাইপটি কায়রোতে ডিকশনারির কার্যকারিতা দেয়, যেখানে কী (key) টাইপ হিসেবে থাকে `felt252` এবং ভ্যালু টাইপ হিসেবে থাকে যেকোনো সমর্থিত টাইপ `T`।

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## গুরুত্বপূর্ণ বৈশিষ্ট্য

অন্য ভাষার ডিকশনারির বিপরীতে কায়রোর ডিকশনারির কিছু বিশেষ বৈশিষ্ট্য আছে:

1. কী (key)গুলো অবশ্যই `felt252` মান হতে হবে।
2. সব কী (key) অন্তর্নিহিতভাবে শূন্য মান নিয়ে শুরু হয়।
3. এন্ট্রি মুছে ফেলা যায় না, কেবল মান আপডেট করা যায়।
4. মানগুলোকে অবশ্যই `Felt252DictValue` ট্রেইট ইমপ্লিমেন্ট করতে হবে।

## পারফরম্যান্স নোট

কায়রোর ইমিউটেবল মেমোরি মডেলের কারণে ডিকশনারি অপারেশনগুলোর কমপ্লেক্সিটি $O(n)$, যেখানে $n$ হলো ডিকশনারিতে করা অপারেশনের সংখ্যা।

প্রতিটি অপারেশন পরিবর্তনটি রেকর্ড করে একটি নতুন এন্ট্রি তৈরি করে।

## জটিল টাইপ নিয়ে কাজ করা

যেসব টাইপ `Felt252DictValue` ইমপ্লিমেন্ট করে না (যেমন অ্যারে বা স্ট্রাক্ট), সেগুলো আপনি `Nullable<T>`-এ মুড়ে দিতে পারেন:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## মেমোরি ম্যানেজমেন্ট

ডিকশনারি `Destruct` ট্রেইট ইমপ্লিমেন্ট করে, অর্থাৎ স্কোপের বাইরে চলে গেলে এগুলো স্বয়ংক্রিয়ভাবে "স্কোয়াশড" হয় (যাচাই ও অপ্টিমাইজ করা হয়)।

এটি কায়রোর প্রুফ সিস্টেমের অংশ, এবং পর্দার আড়ালে ঘটে।

মনে রাখুন: অন্য ভাষার তুলনায় ডিকশনারি কম দক্ষ মনে হলেও, কায়রোর অনন্য মেমোরি মডেল ও প্রুফ সিস্টেমের চাহিদার সাথে খাপ খাওয়ানোর জন্যই এগুলো এভাবে ডিজাইন করা হয়েছে।
