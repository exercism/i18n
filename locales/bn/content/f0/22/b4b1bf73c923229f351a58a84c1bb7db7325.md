# টেস্ট চালানো

টার্মিনাল থেকে অনুশীলনীর বেস ডিরেক্টরিতে চলে যান, তারপর এই কমান্ড দিয়ে টেস্টগুলো চালান:

```bash
$ mix test
```

এটি `test` সাবফোল্ডারে থাকা টেস্ট ফাইলটি চালাবে, অর্থাৎ যে ফাইলের নাম `_test.exs` দিয়ে শেষ হয়।

ডকুমেন্টেশন:

* [`mix test` - Elixir-এর টেস্ট চালানোর টুল](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit` - Elixir-এর ইউনিট টেস্ট লাইব্রেরি](https://hexdocs.pm/ex_unit/ExUnit.html)

## পেন্ডিং টেস্ট

প্র্যাকটিস অনুশীলনীর টেস্ট স্যুটে প্রথমটি ছাড়া বাকি সব টেস্ট স্কিপ করার জন্য ট্যাগ করা থাকে।

একটি টেস্ট পাস হয়ে গেলে, সংশ্লিষ্ট `@tag :pending` লাইনটি `#` চিহ্ন দিয়ে কমেন্ট করে পরের টেস্টটি আনস্কিপ করতে পারেন।

উদাহরণস্বরূপ:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

যদি একবারে সব টেস্ট চালাতে চান, তাহলে `mix test` কমান্ডে `--include` ফ্ল্যাগ ব্যবহার করে সব স্কিপ করা টেস্ট অন্তর্ভুক্ত করতে পারেন:

```bash
$ mix test --include pending
```

অথবা, `test/test_helper.exs` ফাইলে `ExUnit.configure` লাইনটি কমেন্ট করে সব টেস্ট চালু করতে পারেন।

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## দরকারি `mix test` অপশন

* `test/<FILE>.exs:LINENUM` - শুধু একটি টেস্ট চালায়; `<FILE>.exs` ফাইলের যে টেস্টের ডেফিনিশন `LINENUM` লাইনে আছে সেটিই চালায়
* `--failed` - শুধু সেই টেস্টগুলো চালায় যেগুলো গতবার রান করার সময় ফেল করেছিল
* `--max-failures` - এই সংখ্যক টেস্ট ফেল হলে স্যুটটি আর টেস্ট যাচাই করা বন্ধ করে দেয়
* `--seed 0` - র্যান্ডমাইজেশন বন্ধ করে, যাতে একটি ফাইলের টেস্টগুলো সবসময় যে ক্রমে ডিফাইন করা হয়েছিল সেই ক্রমেই চলে
