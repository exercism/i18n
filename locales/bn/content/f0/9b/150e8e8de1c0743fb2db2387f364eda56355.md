# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] একটি এক্সপ্রেশন, যা একটি মান রিটার্ন করে।
Pyret নির্দিষ্ট একটি কোড ব্লকের ভিতরে কেবল একটি এক্সপ্রেশন ব্যবহারের অনুমতি দেয়, যদি না বাইরের ব্লকটি `block` দিয়ে চিহ্নিত করা থাকে।
দ্বিতীয় উদাহরণে, ফাংশন ডিক্লারেশনে `block` যোগ করলে 42 রিটার্ন করার আগেই সেটি প্রিন্ট করা যায়।

## স্পাই

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

একটি স্পাই স্টেটমেন্ট একটি ঐচ্ছিক লেবেল, এক বা একাধিক ভ্যারিয়েবল নেয় এবং প্রতিটি ভ্যারিয়েবল ও তার মান জানায়।
যেহেতু এটি একটি এক্সপ্রেশন নয়, তাই বাইরের ব্লকটি `block` দিয়ে চিহ্নিত না করেও একটি ব্লকে স্পাই ব্যবহার করা যায়।
