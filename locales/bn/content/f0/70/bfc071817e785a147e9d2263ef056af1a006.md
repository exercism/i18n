# অ্যানালাইজার

Exercism-এর অ্যানালাইজারগুলো স্বয়ংক্রিয়ভাবে শিক্ষার্থীদের সাবমিশন মূল্যায়ন করে এবং মেন্টর-স্টাইলের মন্তব্য দেয়।

## অ্যানালাইজারে অবদান রাখা

প্রতিটি ভাষার নিজস্ব অ্যানালাইজার থাকে, যা সেই ভাষাতেই লেখা।
ওয়েবসাইটটি অ্যানালাইজার আর শিক্ষার্থীদের সাবমিশনের মধ্যে সমন্বয়কারীর কাজ করে।

প্রতিটি অ্যানালাইজার Exercism GitHub অর্গানাইজেশনে `<track_slug>-analyzer` নামের একটি রিপোজিটরিতে থাকে (যেমন [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer))।
বিদ্যমান অ্যানালাইজারগুলো [এখানে](https://github.com/search?q=topic%3Aexercism-analyzer&type=repositories) দেখে নিতে পারেন।

কোনো বিদ্যমান অ্যানালাইজারে সাহায্য করতে আগ্রহী হলে, তার রিপোজিটরিতে একটি ইস্যু খুলে জিজ্ঞেস করুন কোথাও আপনার সাহায্যের সুযোগ আছে কি না।
যে ভাষার এখনো অ্যানালাইজার নেই, তার জন্য একটি অ্যানালাইজার বানাতে চাইলে [অ্যানালাইজার তৈরি করা](/docs/building/tooling/analyzers/creating-from-scratch) নির্দেশনা অনুসরণ করুন।
