# পরিচিতি

## সংখ্যা ও সংখ্যার অপারেটর

সব **সংখ্যাই**, ইন্টিজার হোক বা অন্য কিছু, IEEE754 ডাবল প্রিসিশন ফ্লোটিং পয়েন্ট সংখ্যা।
`jq`-এর ইমপ্লিমেন্টেশন C-এর `double` টাইপ ব্যবহার করে।
এটি আমাদের ৫৩ বিট প্রিসিশনে সীমাবদ্ধ করে।

সংখ্যার সাথে ব্যবহারের জন্য সাধারণ অপারেটরগুলো পাওয়া যায়:

- পাটিগণিত: `+`, `-`, `*`, `/`, `%`
- তুলনা: `==`, `!=`, `<`, `<=`, `>=`, `>`
- স্ট্যান্ডার্ড [গাণিতিক ফাংশন][man-math]

  এক-ইনপুট ফাংশনের জন্য মানটি ফাংশনে পাইপ করুন

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  দুই-ইনপুট ফাংশনের ক্ষেত্রে ফাংশনগুলো ইনপুট উপেক্ষা করে এবং প্যারামিটার হিসেবে ইনপুটগুলো প্রত্যাশা করে

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  ফাংশনের আর্গুমেন্ট আলাদা করতে সেমিকোলন ব্যবহার হয়, কমা নয়।

## শর্তসাপেক্ষ এক্সপ্রেশন

`jq` **শর্তসাপেক্ষ এক্সপ্রেশনের** জন্য একটি [`if-then-else` এক্সপ্রেশন][if-then-else] ব্যবহার করে।
একটি _এক্সপ্রেশন_ হিসেবে এটি পাইপলাইনে বসানো হয়।

সিনট্যাক্স হলো: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

`else` ক্লজটি ঐচ্ছিক।

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

অতিরিক্ত শর্তের জন্য `elif` ব্যবহার হয়

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```

[man-types]: https://jqlang.org/manual/#types-and-values
[man-math]: https://jqlang.org/manual/#math
[if-then-else]: https://jqlang.org/manual/#if-then-else-end
