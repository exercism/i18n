# পরিচিতি

Factor-এ আপনি `: name ( stack-effect ) body ;` দিয়ে একটি নতুন শব্দ ডিফাইন করেন। বডিটি শব্দের একটি ক্রম। আপনার নতুন শব্দটি কল করলে সেটি শব্দগুলোকে ক্রমানুসারে রান করে।

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

কোনো রুটিন যখন বড় হয়ে ওঠে, তখন আপনি সেটিকে *ফ্যাক্টর* করতে পারেন, বরং করা উচিত: শব্দের দলগুলোকে টেনে এনে ছোট ছোট নামযুক্ত শব্দে ভাগ করুন, যার প্রত্যেকটির একটিই কাজ। ভাষার নাম রাখা হয়েছে এখান থেকেই।

## ভোকাবুলারি

প্রতিটি `.factor` ফাইল `IN:` দিয়ে একটি ভোকাবুলারি ঘোষণা করে। এক ভোকাবুলারির শব্দগুলো অন্য ভোকাবুলারির শব্দ কল করতে পারে, যদি `USING:`-এ সেই ভোকাবুলারিটি লিখে দেওয়া হয়।

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

ডিরেক্টরি বিন্যাসটি ভোকাবুলারির ডটযুক্ত নাম অনুসরণ করে: `my-vocab` ভোকাবুলারিটি থাকে `my-vocab/my-vocab.factor`-এ, আর `my-vocab.helpers` ভোকাবুলারিটি থাকে `my-vocab/helpers/helpers.factor`-এ। Factor-এর লোডার `USING:` ঘোষণাগুলো শৃঙ্খলাবদ্ধভাবে অনুসরণ করে এবং প্রতিটি ভোকাবুলারি প্রয়োজন অনুসারে লোড করে।
