# সম্পর্কে

প্যারামিটারগুলোর টাইপ অনুমান করা গেলে Swift প্যারামিটারের নাম এবং `in` কিওয়ার্ডটি ক্লোজার ডিফিনিশন থেকে বাদ দেওয়ার সুযোগও দেয়। এর বদলে প্যারামিটারগুলোকে একটি [বিশেষ শর্টহ্যান্ড সিনট্যাক্স][shorthand-argument-names] ব্যবহার করে উল্লেখ করা যায়, যেখানে `$0` প্রথম প্যারামিটারকে বোঝায়, `$1` দ্বিতীয়টিকে বোঝায়, ইত্যাদি।

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

এই স্টাইলটি বেশিরভাগ ক্ষেত্রেই ব্যবহৃত হয় যখন হায়ার-অর্ডার ফাংশনে ক্লোজার পাস করা হয় এবং সংক্ষিপ্ততাকে গুরুত্ব দেওয়া হয়।

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
