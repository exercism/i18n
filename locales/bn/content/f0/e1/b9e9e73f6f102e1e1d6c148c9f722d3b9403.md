# নির্দেশাবলি

আপনার বন্ধুদের জন্য কুকি বেক করার প্রস্তুতি নিতে গিয়ে আপনি দেখতে পেয়েছেন যে রেসিপিতে ব্যবহৃত কিছু মাপ আপনাকে কনভার্ট করতে হবে। যেহেতু আপনি কেবল মেট্রিক সিস্টেমের সাথে পরিচিত, তাই নিজের সুবিধার জন্য কমন মার্কিন বেকিং মাপ মিলিলিটার (mL)-এ কনভার্ট করার একটি উপায় বের করতে হবে।

আপনার সমাধানের জন্য এই কনভার্সন চার্টটি ব্যবহার করুন:

| যে একক কনভার্ট করতে হবে | ভলিউম | মিলিলিটারে (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| মার্কিন কাপ          | 1      | 240                 |
| মার্কিন ফ্লুইড আউন্স  | 1      | 30                  |
| মার্কিন চা-চামচ       | 1      | 5                   |
| মার্কিন টেবিল চামচ    | 1      | 15                  |

প্রশিক্ষণরত একজন প্রতিভাবান প্রোগ্রামার হিসেবে আপনি সিদ্ধান্ত নিলেন যে তালিকাভুক্ত যেকোনো একক থেকে অন্য যেকোনো এককে (এমনকি নিজের মধ্যেও) কনভার্ট করা সহজ করতে মিলিলিটারকে একটি ট্রানজিশন একক হিসেবে ব্যবহার করবেন।

## 1. একটি ভলিউম-পেয়ার থেকে সংখ্যাগত উপাদানটি বের করুন

`getVolume` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল দেওয়া হলে, এটি শুধু সংখ্যাগত উপাদানটি রিটার্ন করবে।

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. ভলিউম-পেয়ারকে মিলিলিটারে কনভার্ট করুন

`toMilliliter` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল দেওয়া হলে, এটি কনভার্সন চার্ট ব্যবহার করে ভলিউমটিকে মিলিলিটারে কনভার্ট করবে।

প্রতিটি এককের জন্য ফাংশন তৈরি করতে একাধিক ফাংশন ক্লজ এবং প্যাটার্ন ম্যাচিং ব্যবহার করুন। প্রতিটি একক বোঝাতে ব্যবহৃত অ্যাটমগুলো হলো: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`। কনভার্সনের ফলাফল একটি টাপলে মুড়িয়ে রিটার্ন করুন।

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. মিলিলিটার ভলিউম-পেয়ারকে অন্য একটি এককে কনভার্ট করুন

`fromMilliliter` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল এবং কাঙ্ক্ষিত একক দেওয়া হলে, এটি কনভার্সন চার্ট ব্যবহার করে ভলিউমটিকে কাঙ্ক্ষিত এককে কনভার্ট করবে।

প্রতিটি এককের জন্য ফাংশন তৈরি করতে একাধিক ফাংশন ক্লজ এবং প্যাটার্ন ম্যাচিং ব্যবহার করুন। প্রতিটি একক বোঝাতে ব্যবহৃত অ্যাটমগুলো হলো: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`।

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. যেকোনো একক থেকে যেকোনো এককে কনভার্ট করুন

`convert` ফাংশনটি ইমপ্লিমেন্ট করুন। একটি ভলিউম-পেয়ার টাপল এবং কাঙ্ক্ষিত একক দেওয়া হলে, এটি প্রদত্ত ভলিউমটিকে কাঙ্ক্ষিত এককে কনভার্ট করবে।

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
