# নির্দেশনা

একটি শব্দ দেওয়া হলে, সেই শব্দের স্ক্র্যাবল স্কোর গণনা করুন।

## অক্ষরের মান

আপনার এগুলো লাগবে:

```text
Letter                           Value
A, E, I, O, U, L, N, R, S, T       1
D, G                               2
B, C, M, P                         3
F, H, V, W, Y                      4
K                                  5
J, X                               8
Q, Z                               10
```

## উদাহরণ

"cabbage" শব্দটির স্কোর হওয়া উচিত ১৪ পয়েন্ট:

- C-এর জন্য ৩ পয়েন্ট
- A-এর জন্য ১ পয়েন্ট, দুইবার
- B-এর জন্য ৩ পয়েন্ট, দুইবার
- G-এর জন্য ২ পয়েন্ট
- E-এর জন্য ১ পয়েন্ট

আর সব মিলিয়ে:

- `3 + 2*1 + 2*3 + 2 + 1`
- = `3 + 2 + 6 + 3`
- = `5 + 9`
- = 14
