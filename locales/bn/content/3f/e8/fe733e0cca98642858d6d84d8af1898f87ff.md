# ইঙ্গিত

## 1. সাধারণ সংখ্যাগুলো বর্ণনা করুন

- ফরম্যাট করতে `fmt.Sprintf` ব্যবহার করুন।

## 2. একটি সংখ্যা বক্স বর্ণনা করুন

- `Number()` মেথড থেকে ফলাফলটি নিন।
- ফরম্যাট করতে `fmt.Sprintf` ব্যবহার করুন।

## 3. একটি ফ্যান্সি সংখ্যা বক্স থেকে সংখ্যা বের করে আনে এমন একটি মেথড বাস্তবায়ন করুন

- এটি একটি `FancyNumber` কি না তা যাচাই করতে টাইপ অ্যাসারশন ব্যবহার করুন।
- `Value()` মেথড থেকে `string` নিন।
- `string`-কে `int`-এ রূপান্তর করতে `strconv.Atoi` ব্যবহার করুন (`int`-এ রূপান্তর করা না গেলে আমাদের 0 চাই, তাই আমরা এররটি ফেলে দিতে পারি)।

## 4. একটি ফ্যান্সি সংখ্যা বক্স বর্ণনা করুন

- `int` মানটি পেতে `ExtractFancyNumber` ব্যবহার করুন।
- `int`-কে `float64`-এ রূপান্তর করুন।
- ফরম্যাট করতে `fmt.Sprintf` ব্যবহার করুন।

## 5. `DescribeAnything` বাস্তবায়ন করুন, যা এদের সবগুলোই ব্যবহার করে

- হয় টাইপ অ্যাসারশন (যেমন `i.(someType)`) ব্যবহার করুন, নয়তো টাইপ সুইচ (`switch v := i.(type)`)।
- `int`-কে `float64`-এ রূপান্তর করতে ভুলবেন না।
