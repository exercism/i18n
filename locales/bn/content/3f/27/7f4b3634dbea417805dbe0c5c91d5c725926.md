# নির্দেশাবলির সংযোজন

## ইঙ্গিত

এই অনুশীলনীতে আপনাকে ডেটার একটি কালেকশন প্রসেস করতে হবে।
LINQ (Language Integrated Query) ব্যবহার করে আপনি আপনার code সহজ করতে পারেন।
আরও তথ্যের জন্য দেখুন [LINQ ব্যবহার][using linq]।
