# নির্দেশনার সংযোজন

## ইঙ্গিত

এই অনুশীলনীটি সম্পূর্ণ করতে হলে আপনাকে `slices` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যা একটি *টেক্সট* নিয়ে নির্দিষ্ট আকারের ডিজিটের উপ-অনুক্রম রিটার্ন করে:

এই অনুশীলনীটি যদি আপনি প্রথমবার সমাধান করছেন, তাহলে দেওয়া সিগনেচারটিই ধরে রাখার পরামর্শ দেওয়া হচ্ছে:

```haskell
slices :: Int -> String -> [[Int]]
```

পরে এই সমস্যাটিতে আবার ফিরে এসে অন্য ডেটা টাইপ ও লাইব্রেরি নিয়ে খেলা ভালো হতে পারে:

- `ByteString`, *bytestring* প্যাকেজ থেকে।
- `Sequence`, *containers* প্যাকেজ থেকে।
- `Text`, *text* প্যাকেজ থেকে।
- `Vector`, *vector* প্যাকেজ থেকে।

টেস্ট স্যুটটি ইচ্ছাকৃতভাবেই এমনভাবে তৈরি করা হয়েছে যাতে বোধগম্য প্রায় যেকোনো টাইপ সিগনেচার গ্রহণ করে, তাই আপনার কাছে যেটি সবচেয়ে ভালো মনে হয়, সেটি খুঁজে বের করতে আপনাকে উৎসাহিত করা হচ্ছে।
