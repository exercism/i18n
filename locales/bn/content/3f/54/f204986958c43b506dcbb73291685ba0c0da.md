# পরিচিতি

## প্যারামিটার

এই অনুশীলনীতে মেথড প্যারামিটারের কিছু খুঁটিনাটি এবং C#-এ এগুলোর ব্যবহার নিয়ে আলোচনা করা হয়েছে।

প্যারামিটার একটি কল করা মেথড থেকে কলকারীর কাছে তথ্য পৌঁছে দেয়।

- `ref` ও `out`-এর মতো মডিফায়ার ব্যবহার করে প্যারামিটারের আচরণ পরিবর্তন করা যায়।

- `out` মডিফায়ারযুক্ত একটি প্যারামিটার কল করা মেথড থেকে কলকারীর কাছে একটি মান ফেরত পাঠায়। প্যারামিটারটি ইনিশিয়ালাইজ না করেই কল করা মেথডে পাঠানো যায়, আর যেভাবেই পাঠানো হোক, কল করা মেথডের ভেতরে এটিকে এমনভাবে ধরা হয় যেন মেথডে ঢোকার সময় এটি ইনিশিয়ালাইজ করা ছিল না। প্যারামিটার মডিফায়ার সম্পর্কিত আচরণ ও নিয়মগুলো সবচেয়ে সহজে বোঝা যায় উদাহরণ (নিচে দেখুন) এবং কম্পাইলারের মেসেজ থেকে।

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- কল করা মেথডের ভেতরে `out` প্যারামিটারে অবশ্যই মান অ্যাসাইন করতে হবে।

- `ref` মডিফায়ারযুক্ত একটি প্যারামিটার কল করা মেথডে একটি মান পাঠায়। মেথডটি রিটার্ন করলে কলকারী দেখবেন, কল করা মেথড ওই প্যারামিটারে যে পরিবর্তনগুলো করেছে তা সেখানেই আছে।

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` প্যারামিটার অবশ্যই ভ্যারিয়েবল হতে হবে, কারণ কল করা মেথড কলকারীর দেখা সেই প্যারামিটারের উপরেই সরাসরি কাজ করবে।
- `out` ও `ref` মডিফায়ার কল করা মেথডের সিগনেচারে এবং কল করার জায়গায়, দুই ক্ষেত্রেই থাকা আবশ্যক।
