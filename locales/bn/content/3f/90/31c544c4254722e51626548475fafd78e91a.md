# ভূমিকা

## ক্লাস

Java-র প্রধান অবজেক্ট-ওরিয়েন্টেড গঠন হলো _ক্লাস_, যা ডেটা (_ফিল্ড_) ও আচরণ (_মেথড_) নিয়ে গঠিত।
একটি ক্লাসের ফিল্ড ও মেথডগুলোকে তার _মেম্বার_ বলা হয়।

অ্যাক্সেস মডিফায়ারের মাধ্যমে মেম্বারদের অ্যাক্সেস নিয়ন্ত্রণ করা যায়, যার মধ্যে সবচেয়ে কমন দুটি হলো:

- `public`: যেকোনো কোড থেকেই মেম্বারটি অ্যাক্সেস করা যায় (কোনো নিষেধাজ্ঞা নেই)।
- `private`: কেবল একই ক্লাসের কোড থেকেই মেম্বারটি অ্যাক্সেস করা যায়।

ক্লাসটিকে ওই ক্লাসের ইনস্ট্যান্স তৈরির একটি টেমপ্লেট হিসেবে ভাবতে পারেন।
একটি ক্লাসের ইনস্ট্যান্স (যাকে _অবজেক্ট_ও বলা হয়) তৈরি করতে `new` কিওয়ার্ডটি ব্যবহার করা হয়:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

ফিল্ডের একটি টাইপ ও একটি নাম থাকে (যা camelCase-এ লেখা হয়) এবং ক্লাসের যেকোনো জায়গায় ডিফাইন করা যায় (প্রথা অনুযায়ী PascalCase-এ লেখা হয়):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

চাইলে একটি ফিল্ডে প্রাথমিক মান অ্যাসাইন করা যায়।
কোনো ফিল্ডে যদি প্রাথমিক মান _না_ নির্দিষ্ট করা হয়, তবে সেটি তার টাইপের ডিফল্ট মান হিসেবে সেট হয়ে যায়।
ডট নোটেশন ব্যবহার করে একটি ইনস্ট্যান্সের ফিল্ডের মান অ্যাক্সেস ও আপডেট করা যায়।

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

সাধারণত একটি মেথড কল করার সাইড ইফেক্ট হিসেবে প্রাইভেট ফিল্ড আপডেট হয়।
এমন মেথড সাধারণত কোনো মান রিটার্ন করে না, সেক্ষেত্রে রিটার্ন টাইপ `void` হওয়া উচিত:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
