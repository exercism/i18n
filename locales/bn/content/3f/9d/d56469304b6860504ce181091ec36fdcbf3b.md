# নির্দেশনা

আপনার এলাকার পিৎজার দোকানের মালিক আপনাকে বিভিন্ন পিৎজার রান্নার সময় হিসাব করতে সাহায্য করতে বলেছেন। এই অনুশীলনীতে আপনি সেটি হিসাব করার জন্য কয়েকটি ফাংশন লিখবেন।

আপনার তিনটি কাজ আছে।

## 1. বাকি বেকিংয়ের সময় মিনিটে হিসাব করুন

`remainingMinutesInOven()` ফাংশনটি ডিফাইন ও ইমপ্লিমেন্ট করুন, যা হিসাব করবে পিৎজাটি ওভেনে আর কত মিনিট রাখতে হবে।

ফাংশনটি একটি **ঐচ্ছিক** প্যারামিটার (ডিফল্ট মানসহ) নেবে, যা পিৎজা বেক করা শুরু করার পর কত মিনিট পার হয়েছে তা বোঝায়। প্যারামিটারটি না দিলে ধরে নিন যে আপনি এইমাত্র পিৎজা ওভেনে রেখেছেন এবং ইতিমধ্যে **০ (শূন্য)** মিনিট পার হয়েছে।

সহজ রাখতে ধরে নিই, সব ধরনের পিৎজা তৈরি হতে ওভেনে ঠিক ৪০ মিনিট লাগে।

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. প্রস্তুতির সময় মিনিটে হিসাব করুন

পিৎজা বেক করার আগে আপনাকে ডো তৈরি করতে হবে, বেলে নিতে হবে এবং তার উপর টপিং দিতে হবে।

`preparationTimeInMinutes()` ফাংশনটি ডিফাইন ও ইমপ্লিমেন্ট করুন, যা হিসাব করবে পিৎজা ওভেনে দেওয়ার আগে এটি প্রস্তুত করতে কত মিনিট লাগবে।

ফাংশনটি একটি **আবশ্যক** প্যারামিটার (`numberOfIngredientTypes`) নেবে, যা ব্যবহৃত টপিং উপকরণের ধরনের সংখ্যা বোঝায়।

ধরে নিন, ডো তৈরি ও বেলে নিতে ৫ মিনিট লাগে এবং **প্রতিটি** ধরনের টপিং ব্যবহার করতে ২ মিনিট লাগে।

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. অতিবাহিত সময় মিনিটে হিসাব করুন

`elapsedCookingTimeInMinutes()` ফাংশনটি ডিফাইন ও ইমপ্লিমেন্ট করুন, যা হিসাব করবে পিৎজা প্রস্তুত, বেক ও পরিবেশন করতে কত মিনিট লাগবে। হিসাব করার সময় আগের ধাপের ফাংশনগুলো ব্যবহার করুন।

ফাংশনটি দুটি প্যারামিটার নেবে। প্রথমটি **আবশ্যক** এবং তা হলো টপিং উপকরণের ধরনের সংখ্যা। দ্বিতীয়টি **ঐচ্ছিক** এবং তা হলো পরিবেশনের সময় মিনিটে (না দিলে ধরে নিন এটি ০)।

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
