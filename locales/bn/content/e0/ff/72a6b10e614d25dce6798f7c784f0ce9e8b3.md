# ভূমিকা

একটি `for` লুপ দিয়ে একটি শর্ত পূরণ হওয়া পর্যন্ত একই কোড বারবার চালানো যায়।

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

একটি `for` লুপ চারটি অংশ নিয়ে গঠিত:

1. ইনিশিয়ালাইজার: লুপে প্রবেশের আগে একবার চালানো হয়। সাধারণত লুপের ভিতরে ব্যবহৃত ভ্যারিয়েবল ডিফাইন করতে এটি ব্যবহার করা হয়।
2. শর্ত: প্রতিটি ইটারেশনের আগে চালানো হয়। যতক্ষণ এটি `true` হয়, ততক্ষণ লুপটি চলতে থাকে।
3. ইটারেটর: প্রতিটি ইটারেশনের পরে চালানো হয়। সাধারণত লুপ ভ্যারিয়েবল পরিবর্তন করতে (অনেক সময়: ইনক্রিমেন্ট/ডিক্রিমেন্ট) এটি ব্যবহার করা হয়।
4. বডি: প্রতিটি ইটারেশনে যে কোডটি চালানো হয়।
