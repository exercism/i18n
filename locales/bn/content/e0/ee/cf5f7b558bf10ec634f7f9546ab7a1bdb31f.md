# ভূমিকা

## মেথডের সেট হিসেবে ইন্টারফেস

সবচেয়ে সহজ রূপে বলতে গেলে, একটি **ইন্টারফেস টাইপ** হলো মেথড সিগনেচারের একটি সেট।
নিচে একটি ইন্টারফেস ডেফিনিশনের উদাহরণ দেওয়া হলো, যেখানে `Add` আর `Value` নামের দুটি মেথড আছে:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

`increment`-এর মতো প্যারামিটারের নাম ইন্টারফেস ডেফিনিশন থেকে বাদ দেওয়া যায়, তবে এগুলো থাকলে সাধারণত কোড পড়তে সুবিধা হয়।

Go-তে ইন্টারফেসের নামে `Interface` বা `I` শব্দটি থাকে না।
বরং এগুলো প্রায়শই `er` দিয়ে শেষ হয়, যেমন `Reader`, `Stringer`.

## ইন্টারফেস ইমপ্লিমেন্ট করা

যে টাইপই ইন্টারফেসের মেথডগুলো ডিফাইন করে, সেটি স্বয়ংক্রিয়ভাবেই ইন্টারফেসটি "ইমপ্লিমেন্ট" করে ফেলে।
Go-তে `implements` নামের কোনো কিওয়ার্ড নেই।

নিচের টাইপটি আমরা উপরে যে `Counter` ইন্টারফেস দেখেছি, সেটি ইমপ্লিমেন্ট করে।

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

ইন্টারফেস ইমপ্লিমেন্ট করার জন্য মেথডের রিসিভার ভ্যালু না পয়েন্টার, সেটা কোনো ব্যাপার নয়।
(এসব নিয়ে সন্দেহ থাকলে [মেথড ধারণাগুলো][concept-methods] আবার দেখুন।)

> ইন্টারফেস টাইপের একটি মান তার ভেতরে এমন যেকোনো মান ধারণ করতে পারে, যেটি ওই মেথডগুলো ইমপ্লিমেন্ট করে। [^1]

এর মানে হলো, এখন যেসব জায়গায় `Counter` ইন্টারফেস প্রত্যাশিত, সেসব জায়গায় `Stats` ব্যবহার করা যায়।

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

ইন্টারফেস যেহেতু স্বয়ংক্রিয়ভাবে ইমপ্লিমেন্ট হয়, তাই একটি টাইপ সহজেই একাধিক ইন্টারফেস ইমপ্লিমেন্ট করতে পারে।
এর জন্য শুধু প্রয়োজনীয় সব মেথড ডিফাইন করা থাকলেই যথেষ্ট।

## খালি ইন্টারফেস

Go-তে একটি খুব বিশেষ ইন্টারফেস টাইপ আছে, যাকে বলে **খালি ইন্টারফেস**, যাতে একটিও মেথড থাকে না।
খালি ইন্টারফেস এভাবে লেখা হয়: `interface{}`.
`any` হলো `interface{}`-এর একটি অ্যালিয়াস, আর এটি বেশি ব্যবহৃত হয়।

খালি ইন্টারফেসে যেহেতু কোনো মেথড নেই, তাই প্রতিটি টাইপই এটিকে স্বয়ংক্রিয়ভাবে ইমপ্লিমেন্ট করে।
এটি এমন একটি ফাংশন ডিফাইন করার জন্য কাজে লাগে, যা সাধারণভাবে যেকোনো মান গ্রহণ করতে পারে।
সেক্ষেত্রে ফাংশনের প্যারামিটারটি খালি ইন্টারফেস টাইপের হয়।
