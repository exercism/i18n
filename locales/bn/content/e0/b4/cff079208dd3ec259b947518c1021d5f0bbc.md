# পরিচিতি

Java-তে একটি মানের অনুপস্থিতি বোঝাতে `null` লিটারাল ব্যবহার করা হয়।

Java-এর প্রিমিটিভ ডেটা টাইপগুলোর সবগুলোরই একটি ডিফল্ট মান থাকে, তাই এরা কখনোই `null` হতে পারে না। প্রচলিত রীতি অনুযায়ী এগুলো ছোট হাতের অক্ষর দিয়ে শুরু হয়, যেমন `int`.

রেফারেন্স টাইপগুলো একটি অবজেক্টের মেমরি অ্যাড্রেস ধারণ করে এবং এদের মান `null` হতে পারে। এগুলো সাধারণত বড় হাতের অক্ষর দিয়ে শুরু হয়, যেমন `String`.

একটি প্রিমিটিভ ভ্যারিয়েবলকে `null` মান অ্যাসাইন করার চেষ্টা করলে কম্পাইল টাইম এরর হয়, কারণ ভ্যারিয়েবলটি সবসময়ই অ্যাসাইন করা টাইপের একটি প্রিমিটিভ মান ধরে রাখে।

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

একটি রেফারেন্স ভ্যারিয়েবলকে `null` মান অ্যাসাইন করলে কম্পাইল টাইম এরর হয় না, কারণ রেফারেন্স ভ্যারিয়েবলগুলো নালেবল।

```java
//No error will occur as the String variable str is nullable
String str = null;
```
