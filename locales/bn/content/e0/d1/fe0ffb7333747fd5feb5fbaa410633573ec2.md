# ইঙ্গিত

## সাধারণ

- শুরু করার জন্য Python Docs-এর [কন্ট্রোল ফ্লো টুল][control flow tools] আর Real Python-এর [কন্ডিশনাল][real python conditionals] টিউটোরিয়াল দারুণ জায়গা।
- `bools` নিয়ে ঝালিয়ে নিতে চাইলে Python Docs-এর [বুলিয়ান অপারেশন][boolean operations] এবং Real Python-এর [বুলিয়ান][python booleans] টিউটোরিয়াল দারুণ কাজে দেবে।
- তুলনা নিয়ে ঝালিয়ে নিতে চাইলে Python Docs-এর [তুলনা][comparisons] আর [তুলনার উদাহরণ][python comparisons examples] দারুণ কাজে দেবে।

## 1. ক্রিটিক্যালিটি যাচাই করুন

- তুলনা অপারেটর ([তুলনা][comparisons review]) আর বুলিয়ান অপারেশন ([concept:python/bools]()) একসাথে মিলিয়ে শর্তের সাথে ব্যবহার করা যায়।
- কন্ডিশনাল এক্সপ্রেশনের ফলাফল অবশ্যই `True` বা `False` হতে হবে।
- সব কন্ডিশনাল টেস্ট `False` রিটার্ন করলে যে কোড ব্লকটি চলে, তার জন্য `else` ব্যবহার করা যায়।

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. পাওয়ার আউটপুটের পরিসীমা নির্ণয় করুন

- তুলনা অপারেটর একসাথে মিলিয়ে শর্তের সাথে ব্যবহার করা যায়।
- সিদ্ধান্তের "শাখা" হিসেবে যেকোনো সংখ্যক `elif` স্টেটমেন্ট ব্যবহার করা যায়।
- প্রতিটি "শাখায়" আলাদা `return` থাকতে পারে, যদিও লিন্টিং টুলের চোখে এটি "খারাপ রীতি" হিসেবে ধরা হতে পারে।
- লিন্টার যদি অভিযোগ করে, তবে শাখার আউটপুট একটি কমন ভ্যারিয়েবলে অ্যাসাইন করে সেই ভ্যারিয়েবলটি `return` করার কথা ভাবুন।

## 3. ফেল সেফ মেকানিজম

- তুলনা অপারেটর একসাথে মিলিয়ে শর্তের সাথে ব্যবহার করা যায়।
