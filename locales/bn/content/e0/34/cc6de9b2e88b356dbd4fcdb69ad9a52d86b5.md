# নির্দেশনার সংযোজন

## প্রজেক্ট স্ট্রাকচার

* `src`-এ আপনার অনুশীলনীর সমাধান থাকে
* `spec`-এ অনুশীলনীর জন্য চালানোর টেস্টগুলো থাকে

## টেস্ট চালানো

আপনি যদি সঠিক ডিরেক্টরিতে থাকেন (অর্থাৎ যে ডিরেক্টরিতে `src` আর `spec` আছে), তাহলে `crystal spec` চালিয়ে ওই অনুশীলনীর টেস্টগুলো চালাতে পারবেন:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

এতে `spec` ডিরেক্টরির সব টেস্ট ফাইল চালানো হবে।

প্রতিটি টেস্ট ফাইলে প্রথম টেস্টটি ছাড়া বাকি সবগুলো স্কিপ করা আছে।

একটি টেস্ট পাস হয়ে গেলে, `pending`-কে `it`-এ পরিবর্তন করে পরের টেস্টটি আনস্কিপ করতে পারেন।

## আপনার সমাধান সাবমিট করা

সমাধান সাবমিট করার সময় অবশ্যই `src` ডিরেক্টরির সোর্স ফাইলটি সাবমিট করতে ভুলবেন না:

```bash
$ exercism submit src/hello_world.cr
```
