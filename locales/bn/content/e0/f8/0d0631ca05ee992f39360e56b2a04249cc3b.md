# উদাহরণ

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

যেসব লাইন ডট দিয়ে শুরু হয় সেগুলো _ডিরেক্টিভ_: এগুলো প্রসেসরের জন্য নয়, অ্যাসেম্বলারের জন্য নির্দেশনা।
`.equ` সংখ্যা 16-কে `FRAME_SIZE` নামটি দেয়।
`.text` বলে যে এরপর যা আসে তা কোড।
`.global` লেবেল `is_triple`-কে এই ফাইলের বাইরে দৃশ্যমান করে, যাতে অন্য কোড এটি কল করতে পারে।
আপনি `.globl`-ও দেখতে পেতে পারেন, যার অর্থ একই।

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` পরীক্ষা করে `a² + b² = c²` কি না, সত্য হলে 1 রিটার্ন করে আর অন্যথায় 0।
উদাহরণস্বরূপ, `(6, 8, 10)` 1 দেয়, কারণ `36 + 64 = 100`।
লেবেল `is_triple` চিহ্নিত করে ফাংশনটি কোথা থেকে শুরু হয়।
এটি `a`, `b` ও `c`-কে `a0`, `a1` আর `a2` রেজিস্টারে রেখে কল করা হয়।

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

`ra` রেজিস্টারে থাকে _রিটার্ন অ্যাড্রেস_, অর্থাৎ আমরা কাজ শেষ করলে কলারের যে জায়গায় ফিরে যেতে হবে তা।
প্রতিটি `call` `ra`-কে ওভাররাইট করে, তাই আমরা প্রথমে এটি _স্ট্যাক_-এ সংরক্ষণ করি।
স্ট্যাক নিচের দিকে বাড়ে, ছোট অ্যাড্রেসের দিকে, তাই স্ট্যাক পয়েন্টার `sp` থেকে 16 বিয়োগ করলে আমাদের জন্য 16 বাইট সংরক্ষিত হয়।
(`sp` সর্বদা 16-এর গুণিতক হতে হবে।)
আমরা `b` আর `c`-ও সংরক্ষণ করি, কারণ আমরা যে ফাংশন কল করি সেটি `a` রেজিস্টারগুলো পরিবর্তন করার অনুমতি পায়।

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` আগে থেকেই `a0`-তে আছে, যেখানে `square` তার ইনপুট আশা করে।
`call` `ra`-কে পরের নির্দেশনায় সেট করে আর `square`-এ লাফ দেয়, যা তার ফলাফল `a0`-তে রিটার্ন করে।

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

আমরা স্ট্যাক থেকে `b` আবার লোড করি, এটির বর্গ করি, আর তা `a * a`-এর সাথে যোগ করি।

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

পার্থক্যটি ঠিক তখনই শূন্য হয় যখন `a² + b² = c²`।
`seqz` ("শূন্যের সমান হলে সেট") এটিকে 1 বা 0-তে রূপান্তর করে।

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

আমরা `ra` পুনরুদ্ধার করি আর স্ট্যাকের 16 বাইট ফিরিয়ে দিই।
এরপর `ret` `ra`-তে থাকা অ্যাড্রেসে লাফ দেয়, ফিরে যায় কলারের কাছে।

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` অন্য কোনো ফাংশন কল করে না, তাই `ra` অটুট থাকে আর সংরক্ষণ করার কিছু নেই।
এটি `.global` দিয়ে চিহ্নিত নয়, কারণ কেবল `is_triple` এটিকে ব্যবহার করে।
