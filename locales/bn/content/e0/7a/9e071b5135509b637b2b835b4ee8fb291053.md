# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি ইন্টারনেট ফোরামে ইউজার অ্যাকাউন্টের পারমিশন যাচাই করবেন। ফোরামটি তিন ধরনের পারমিশন সাপোর্ট করে:

- Read
- Write
- Delete

তিন ধরনের অ্যাকাউন্ট আছে, প্রতিটির ডিফল্ট পারমিশন আলাদা:

- গেস্ট: পোস্ট পড়তে পারে।
- ইউজার: পোস্ট পড়তে ও লিখতে পারে।
- মডারেটর: পোস্ট পড়তে, লিখতে ও ডিলিট করতে পারে, তাদের সব পারমিশন থাকে।

কখনও কখনও আলাদা আলাদা পারমিশন পরিবর্তন করা যায়; উদাহরণস্বরূপ একটি গেস্ট অ্যাকাউন্টকে পোস্ট লেখার পারমিশনও দেওয়া সম্ভব, আবার একটি অ্যাকাউন্ট থেকে সব পারমিশন প্রত্যাহার করলে সেটির কোনো পারমিশনই থাকবে না।

## 1. একটি অ্যাকাউন্ট টাইপের ডিফল্ট পারমিশন পান

প্রথমে তিনটি অ্যাকাউন্ট টাইপ প্রকাশ করতে একটি `AccountType` এনাম ডিফাইন করুন: `Guest`, `User` এবং `Moderator`।

এরপর একটি `Permission` এনাম ডিফাইন করুন, যা তিনটি পারমিশন টাইপ প্রকাশ করবে: `Read`, `Write`, `Delete`, আরও দুটি বাড়তি টাইপও: `All`, যা সব পারমিশন থাকা বোঝায়, আর `None`, যা কোনো পারমিশন না থাকা বোঝায়।

তারপর একটি নির্দিষ্ট অ্যাকাউন্ট টাইপের ডিফল্ট পারমিশন রিটার্ন করার জন্য (_static_) `Permissions.Default()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. একটি পারমিশন দিন

(_static_) `Permissions.Grant()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি পারমিশন দেয় (অর্থাৎ যোগ করে):

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. একটি পারমিশন প্রত্যাহার করুন

(_static_) `Permissions.Revoke()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি পারমিশন প্রত্যাহার করে (অর্থাৎ সরিয়ে ফেলে):

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. একটি পারমিশন যাচাই করুন

(_static_) `Permissions.Check()` মেথডটি ইমপ্লিমেন্ট করুন, যা বর্তমান অ্যাকাউন্টের পারমিশন নিয়ে দেখে যে অ্যাকাউন্টটি নির্দিষ্ট একটি পারমিশনের জন্য অনুমোদিত কি না:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
