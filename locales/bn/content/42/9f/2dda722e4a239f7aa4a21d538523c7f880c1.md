# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | সংখ্যা                                            |
| `$v0`    | আউটপুট    | বুলিয়ান | আর্মস্ট্রং সংখ্যা কিনা (`0` = `false`, `1` = `true`) |
| `$t0-9`  | সাময়িক | যেকোনো   | সাময়িক স্টোরেজের জন্য ব্যবহৃত হয়                        |
