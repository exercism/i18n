# ভূমিকা

## ডিফল্ট প্যারামিটার মান

ফাংশনের টাইপ অ্যানোটেশনের পরে প্যারামিটার লিস্টে প্যারামিটারে একটি মান অ্যাসাইন করে ফাংশনের যেকোনো প্যারামিটারের জন্য [ডিফল্ট প্যারামিটার মান][default-parameter-values] দেওয়া যায়। যখন একটি ডিফল্ট প্যারামিটার মান নির্দিষ্ট করা হয়, তখন ফাংশনটি কল করার সময় কলকারী ওই প্যারামিটারটি বাদ দিতে পারেন এবং তার বদলে ডিফল্ট মানটি ব্যবহৃত হয়।

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## ভ্যারিয়াডিক প্যারামিটার

[ভ্যারিয়াডিক প্যারামিটার][variadic-parameters] একটি ফাংশনকে একটি নির্দিষ্ট টাইপের শূন্য বা তার বেশি মান একটি একক প্যারামিটারের জন্য গ্রহণ করার সুযোগ দেয়।
প্যারামিটারের টাইপ অ্যানোটেশনের শেষে তিনটি ডট (`...`) যোগ করে আপনি একটি ভ্যারিয়াডিক প্যারামিটার ডিফাইন করেন।

ফাংশন বডির ভেতরে Swift এই মানগুলোকে নির্দিষ্ট টাইপের একটি অ্যারে হিসেবে ব্যবহারের জন্য উপলব্ধ করে:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
কোনো ফাংশনে ভ্যারিয়াডিক প্যারামিটারের পরে অতিরিক্ত প্যারামিটার থাকলে, ভ্যারিয়াডিক প্যারামিটারটির পরে আসা প্রথম প্যারামিটারের একটি স্পষ্ট আর্গুমেন্ট লেবেল **থাকতেই হবে**, যাতে Swift বুঝতে পারে ভ্যারিয়াডিক আর্গুমেন্ট লিস্টটি কোথায় শেষ হচ্ছে।
~~~~


## ইন-আউট প্যারামিটার

ফাংশনের বডির ভেতরে প্যারামিটারগুলোকে কনস্ট্যান্ট হিসেবে ধরা হয়, ভ্যারিয়েবল হিসেবে নয়; কোনো প্যারামিটারের মান পরিবর্তন করার চেষ্টা করলে একটি কম্পাইল-টাইম এরর হবে।
কোনো ফাংশন যদি প্যারামিটারের মান পরিবর্তন করতে চায়, তাহলে এই পরিবর্তনযোগ্যতাটি স্পষ্ট করতে তাকে একটি [_ইন-আউট প্যারামিটার_][in-out-parameters] ব্যবহার করতে হবে।

ইন-আউট প্যারামিটার ব্যবহার করতে একজন প্রোগ্রামারকে তিনটি বিষয়ে নিশ্চিত হতে হবে:

1. ফাংশন ডেফিনিশনে প্যারামিটারের টাইপ অ্যানোটেশনে `:` এবং টাইপ নামের মাঝখানে `inout` কিওয়ার্ড লিখে ইন-আউট প্যারামিটারগুলোকে স্পষ্টভাবে চিহ্নিত করতে হবে।
2. ইন-আউট প্যারামিটারে যে মানটি পাঠানো হয় তা কনস্ট্যান্ট নয়, ভ্যারিয়েবল হিসেবে ঘোষণা করা থাকতে হবে। একইভাবে এটি একটি লিটারালও হতে পারে না।
3. ফাংশন কলের সময় ভ্যারিয়েবল নামের আগে একটি `&` থাকতে হবে, যা এটিকে পরিবর্তনযোগ্য হিসেবে স্পষ্টভাবে চিহ্নিত করে।

এটি করা হলে ফাংশনটি ইন-আউট প্যারামিটারের একটি অভ্যন্তরীণ কপি তৈরি করে, ফাংশনের বডিতে নির্দেশ অনুযায়ী তা পরিবর্তন করে, এবং ফাংশন রিটার্ন করার সময় পরিবর্তিত মানটি আবার সেই ভ্যারিয়েবলে কপি করে দেয়, যেটি পাঠানো হয়েছিল।

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
ইন-আউট প্যারামিটার নিয়ে আরও কয়েকটি অতিরিক্ত নিয়ম সম্পর্কে সচেতন থাকা উচিত।

1  ইন-আউট প্যারামিটারযুক্ত কোনো ফাংশনের ভেতরে, যে ভ্যারিয়েবলটি ইন-আউট প্যারামিটার হিসেবে পাঠানো হয়েছিল, সেটি রেফারেন্স করার অনুমতি নেই।
2. একই ফাংশনে একই ভ্যারিয়েবল একাধিক ইন-আউট প্যারামিটার হিসেবে পাঠানো যাবে না।
   উদাহরণস্বরূপ, `inoutFunc(&mutVar, &mutVar)` একটি কম্পাইলার এরর তৈরি করে।
~~~~

## নেস্টেড ফাংশন

Swift-এ আপনি [অন্য ফাংশনের ভেতরে ফাংশন][nested-functions] ডিফাইন করতে পারেন।
এগুলোকে **নেস্টেড ফাংশন** বলা হয়।

নেস্টেড ফাংশন সাধারণত প্রাইভেট হেল্পার হিসেবে ব্যবহৃত হয়, যেগুলো বাইরের স্কোপ নষ্ট না করে নিজেকে ঘিরে থাকা ফাংশনের জন্য নির্দিষ্ট কিছু কাজ করে:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

নেস্টেড ফাংশনগুলো সাধারণ ফাংশনের মতোই আচরণ করে, কিন্তু এগুলোর দৃশ্যমানতা ঘিরে থাকা ফাংশনের বডির মধ্যেই সীমাবদ্ধ।
