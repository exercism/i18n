# পরিচিতি

লিটারাল হলো এমন নির্দিষ্ট মান, যা কোডে সরাসরি ব্যবহৃত হয়। রান-টাইমে এদের কোনো গণনার প্রয়োজন হয় না। বিভিন্ন ধরনের ডেটা দক্ষভাবে উপস্থাপন করতে এগুলো নানা রূপে আসে। সবচেয়ে বেশি দেখা যায় সংখ্যাধর্মী লিটারাল, তবে তারিখ, সময় ও স্ট্রিং টাইপের জন্যও লিটারাল অপারেটর আছে। পরের একটি ধারণায় দেখানো হবে কীভাবে ব্যবহারকারী-সংজ্ঞায়িত লিটারাল অপারেটর ব্যবহার করা যায়।

## সংখ্যাধর্মী লিটারাল

সংখ্যাধর্মী লিটারালের মধ্যে দশমিক, অক্টাল, হেক্সাডেসিমাল ও বাইনারি রূপ অন্তর্ভুক্ত। এই মৌলিক বিষয়গুলো [সংখ্যা ধারণায়][numbers-concept] আগেই আলোচনা করা হয়েছে।

`23`, `0x50f7ba11` এবং `0xba5eba11`-এর মতো সব রূপ কম্পাইলার `int` হিসেবে বোঝে। সাধারণ `int` টাইপটি সাইনড, এবং ([কম্পাইলার ও সিস্টেমের উপর নির্ভর করে][in-depth-integers]) এর পরিসীমা প্রায়শই `-2'147'483'648` থেকে `2'147'483'647` পর্যন্ত হয়ে থাকে। বেশিরভাগ সময় এটাই যথেষ্ট, আর নির্দিষ্ট টাইপ নিয়ে আপনার চিন্তা করতে হবে না।

কিছু ক্ষেত্রে প্রোগ্রামের জন্য বড় পরিসীমা বা খুব ছোট মেমরি ব্যবহারের প্রয়োজন হয়। নির্দিষ্ট করতে চাইলে সংখ্যাধর্মী লিটারালের সাথে সরাসরি নির্দিষ্ট ইন্টিজার টাইপ উল্লেখ করা যায়।

যখন ঋণাত্মক সংখ্যার প্রয়োজন নেই, কিন্তু বাড়তি পরিসীমা দরকার, তখন _unsigned_ ইন্টিজারের জন্য `u` বা `U` সাফিক্স ব্যবহার করা হয়। আরও বড় পরিসীমার জন্য long ও long long টাইপে `L` বা এমনকি `LL` ব্যবহার করা যায়।

~~~~exercism/caution
ছোট হাতের `l` ব্যবহার করা অনুমোদিত, তবে এটি সহজেই `1` সংখ্যার সাথে গুলিয়ে ফেলা যায়, তাই এটি এড়িয়ে চলা উচিত।
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

ফ্লোটিং-পয়েন্ট সংখ্যা কম্পাইলেশনের সময় সাধারণত `double`-এ পরিণত হয়। এটি একটি ভালো ডিফল্ট, আর সংকীর্ণ `float` টাইপের ব্যবহার উপরের _unsigned_ উদাহরণের চেয়ে কম দেখা যায়।

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## ক্যারেক্টার ও স্ট্রিং লিটারাল

অন্য ধারণাগুলোতে ইতিমধ্যে `'}'` বা `'@'`-এর মতো একক কোটেশনের ক্যারেক্টার লিটারাল ব্যবহার করা হয়েছে।

C++-এ `char` প্রথম ১২৮টি [ascii ক্যারেক্টার কোডে][ascii-code] সীমাবদ্ধ। একাধিক ascii ক্যারেক্টার, অথবা `‰`-এর মতো এক্সটেন্ডেড ascii ক্যারেক্টার, এমনকি `麗` ও `ẞ`-এর মতো unicode ক্যারেক্টার ব্যবহার করতে হলে অন্য টাইপ দরকার। আগের ধারণায় _double quotes_ দিয়ে স্ট্রিং লিটারাল চেনানো হয়েছিল: `"一体どういう意味ですか。C++です"`। এই জাপানি বাক্যটির প্রকৃত টাইপ `const char (&)[46]`, যা একটি C-স্টাইল স্ট্রিং।

স্ট্রিং লিটারালের ব্যবহার ডিফল্টভাবে চালু থাকে না। _string_ লিটারাল `""s` বা _string-view_ লিটারাল `""sv` ব্যবহার করতে হলে ব্যবহারকারীকে সংশ্লিষ্ট namespace ব্যবহার করে সেটি উল্লেখ করতে হয়:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

একটি _string_view_-কে একটি const স্ট্রিংয়ের রেফারেন্স হিসেবে দেখা যায়।
