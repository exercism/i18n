# পরিচিতি

## রেকর্ড

[রেকর্ড][records] হলো এমন ডেটা স্ট্রাকচার, যা সম্পর্কিত তথ্যকে লেবেল দিয়ে একসাথে গুছিয়ে রাখে। এগুলো JavaScript বা Java-র অবজেক্ট, কিংবা C বা Rust-এর স্ট্রাক্টের মতো, তবে কিছু গুরুত্বপূর্ণ পার্থক্য আছে।

### রেকর্ড তৈরি করা

রেকর্ড [তৈরি করা হয়][create] দ্বিতীয় বন্ধনী দিয়ে, আর এর এলিমেন্টগুলোকে কমা দিয়ে আলাদা করা হয়।

```elm
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

রেকর্ডের টাইপও একই ধরনের সিনট্যাক্স দিয়ে ডিফাইন করা হয়, শুধু সমান চিহ্ন `=`-এর বদলে কোলন চিহ্ন `:` বসে।

```elm
firefly : { name : String, creator : String, episodes : Int }
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

এই টাইপ ডেফিনিশনগুলো বারবার লেখা ঝামেলার, তাই ডেফিনিশন শেয়ার করার জন্য [টাইপ অ্যালিয়াস][record-types] ব্যবহার করা একটি কমন রীতি।

```elm
type alias TvSeries =
    { name : String
    , creator : String
    , episodes : Int
    }

firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

টাইপ অ্যালিয়াস স্বয়ংক্রিয়ভাবে রেকর্ডটির জন্য একটি কনস্ট্রাক্টর ফাংশনও তৈরি করে দেয়।
এটা মাঝে মাঝে অবাক করার মতো লাগে, কারণ Elm-এ ফাংশনের নাম ছোট হাতের অক্ষর দিয়ে শুরু হতে হয়, কিন্তু টাইপ কনস্ট্রাক্টর এই নিয়মের একটি ব্যতিক্রম।

```elm
firefly : TvSeries
firefly = TvSeries "Firefly" "Joss Whedon" 14
```

### রেকর্ডের ফিল্ড অ্যাক্সেস করা

[রেকর্ড ইনস্ট্যান্সের একটি ফিল্ডের মান অ্যাক্সেস করার][access] প্রধান উপায় হলো ডট নোটেশন ব্যবহার করা, যেমন `firefly.creator`।
Elm কম্পাইলার `.` দিয়ে শুরু হওয়া বিশেষ অ্যাক্সেসর ফাংশনও সাপোর্ট করে, যেমন `.creator`, যা ওই নামের ফিল্ড আছে এমন যেকোনো রেকর্ডে কাজ করবে।
ফাংশনের নাম ছোট হাতের অক্ষর দিয়ে শুরু হতে হবে, এই নিয়মের দ্বিতীয় ব্যতিক্রম হলো এটাই।
আসলে ব্যবহারকারীর ডিফাইন করা ফাংশনের নাম অবশ্যই ছোট হাতের অক্ষর দিয়ে শুরু হতে হবে, কিন্তু আমরা এইমাত্র যে দুটি উদাহরণ পেলাম, সেগুলো কম্পাইলার তৈরি করে, প্রোগ্রামার নয়।

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

firefly.name
    --> "Firefly"

.creator firefly
    --> "Joss Whedon"
```

[রেকর্ড প্যাটার্ন ম্যাচিং][pattern-matching] ব্যবহার করে বাইন্ডিংয়ের মধ্যে রেকর্ডকে _ডিস্ট্রাকচার_ও করা যায়।
প্রাসঙ্গিক নামের ফিল্ড আছে এমন যেকোনো রেকর্ডের উপরেই ডিস্ট্রাকচারিং কাজ করে।

```elm
episodesCount : TvSeries -> Int
episodesCount { episodes } =
    episodes

complicatedCopy : TvSeries -> TvSeries
complicatedCopy show =
    let
        { name, creator } = show
    in
    { name = name
    , creator = creator
    , episodes = episodesCount show
    }
```

### রেকর্ড আপডেট করা

Elm-এ সবকিছুর মতো রেকর্ডও ইমিউটেবল, তাই একবার রেকর্ড ডিফাইন হয়ে গেলে তার ফিল্ডের মান আর কখনো বদলানো যায় না।
[বিদ্যমান রেকর্ডের একটি কপি তৈরি করার, তবে এক বা একাধিক ফিল্ড বদলানোর একটি বিশেষ সিনট্যাক্স][update] আছে।
এই সিনট্যাক্সে পাইপ চিহ্ন `|` ব্যবহার করে মূল রেকর্ড এবং যে ফিল্ডগুলো বদলাবে সেগুলোকে আলাদা করা হয়, যেমন `{ oldRecord | field1 = newValue }`।

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

updatedFirefly : TvSeries
updatedFirefly =
    { firefly | creator = "J Whedon", episodes = 15 }
```

### রেকর্ড তুলনা করা

Elm [স্ট্রাকচারাল ইকুয়ালিটি][equality] ব্যবহার করে, তার মানে একই রেকর্ডের দুটি ইনস্ট্যান্সের মান হুবহু এক হলে সেগুলো সমান।

```elm
firefly1 = TvSeries "Firefly" "Joss Whedon" 14
firefly2 = TvSeries "Firefly" "Joss Whedon" 14

firefly1 == firefly2
    --> True
```

### এক্সটেনসিবল রেকর্ড

Elm [স্ট্রাকচারাল টাইপিং][structural-typing]ও সাপোর্ট করে, অর্থাৎ কোনো ফাংশনের যদি x আর y ফিল্ডসহ একটি রেকর্ড দরকার হয়, তাহলে ওই ফিল্ডগুলো আছে এমন যেকোনো রেকর্ড দিয়েই কাজ হবে, যেমন 2D পয়েন্ট, 3D পয়েন্ট, স্পেসশিপ ইত্যাদি।
ওই রেকর্ড টাইপগুলোর ডেফিনিশনে একটি পাইপ `|` থাকে, যেমন `{ a | x : Float, y : Float }`, আর Elm-এর পরিভাষায় এগুলোকে "এক্সটেনসিবল রেকর্ড" বলা হয়।
টাইপ ডেফিনিশনের পাইপ `|` (যা একটি এক্সটেনসিবল রেকর্ড ডেফিনিশন, `{ a | x : Int }`) আর প্রকৃত রেকর্ড ইনস্ট্যান্সের পাইপ `|`-এর পার্থক্য নিয়ে সাবধান থাকুন, কারণ পরেরটি বোঝায় যে আমরা ওই রেকর্ডের কিছু ফিল্ড আপডেট করছি।

```elm
point2d = { x = 1, y = 2 }
point3d = { x = 3, y = 4, z = 7 }

.x point2d --> 1
.x point3d --> 3

length : { a | x : Float, y : Float } -> Float
length vector =
    sqrt (vector.x * vector.x + vector.y * vector.y)

length point2d --> 2.236068
length point3d --> 5

translateX : { a | x : Float } -> { a | x : Float }
translateX vector =
    { vector | x = vector.x + 1 }

translateX point2d --> { x = 2, y = 2 }
translateX point3d --> { x = 4, y = 4, z = 7 }
```
