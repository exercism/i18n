# Tests

প্রতিটি অনুশীলনী unit test এবং একটি Make বিল্ড রেসিপি সরবরাহ করে।
ইমপ্লিমেন্টেশনটি আপনাকে লিখতে হবে।

প্রতিটি test ফাইলের উদ্দেশ্য হলো আপনার ইমপ্লিমেন্টেশনের সঙ্গে লিংক হয়ে একটি কনসোল এক্সিকিউটেবল তৈরি করা, যা test চালায়।
test এক্সিকিউটেবল রান করলে প্রতিটি ব্যর্থ test-এর জন্য বার্তা ছাপা হয় এবং test ফেল করলে একটি নন-জিরো এক্সিট স্ট্যাটাস জানানো হয়।

একটি অনুশীলনী শেষ করতে:
* Make দিয়ে প্রাথমিক বিল্ডটি তৈরি করুন
* প্রতিটি unit test-এর জন্য:
  * `TEST_IGNORE()` লাইনটি মুছে ফেলুন।
  * test যাতে ফেল করে, সেজন্য কম্পাইল এররগুলো মিটিয়ে নিন।
  * test পাস করানোর জন্য ঠিক যতটুকু দরকার, ততটুকুই ইমপ্লিমেন্ট করুন।
  * রিডেবিলিটি বাড়াতে, ডুপ্লিকেশন কমাতে ইত্যাদির জন্য আপনার ইমপ্লিমেন্টেশনটি রিফ্যাক্টর করুন।
