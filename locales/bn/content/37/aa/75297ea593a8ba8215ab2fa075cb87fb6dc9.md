# নির্দেশনা

বাড়তি কুকিটি কাউকে দেওয়ার সময় আপনি কী বলবেন, সেটিই ঠিক করা আপনার কাজ।

যদি আপনার বন্ধুর কুকি পছন্দ হয়, আর তার নাম হয় Do-yun, তাহলে আপনি বলবেন:

```text
One for Do-yun, one for me.
```

যদি আপনার বন্ধুর কুকি পছন্দ না হয়, তাহলে বেকারিতে লাইনে দাঁড়ানো পরের ব্যক্তিকে কুকিটি দিয়ে দেবেন। যেহেতু তার নাম আপনি জানেন না, তাই তার বদলে _you_ বলবেন।

```text
One for you, one for me.
```

এখানে কিছু উদাহরণ দেওয়া হলো:

| নাম    | সংলাপ                       |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
