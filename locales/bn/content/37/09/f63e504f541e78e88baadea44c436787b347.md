# স্ট্রিং

Crystal-এ [`String`][strings] নামে একটি টাইপ আছে, যা টেক্সট উপস্থাপন করতে ব্যবহৃত হয়। Crystal-এর স্ট্রিং হলো ইউনিকোড ক্যারেক্টারের একটি ক্রম। স্ট্রিং অপরিবর্তনীয়, অর্থাৎ একবার তৈরি হওয়ার পর সেগুলো আর পরিবর্তন করা যায় না। এর মানে হলো আপনি যখনই কোনো স্ট্রিং পরিবর্তন করেন, তখনই একটি নতুন স্ট্রিং তৈরি হয়; তাই মূল স্ট্রিংটি পরিবর্তিত হয় না।

স্ট্রিং ডিফাইন করতে আপনি ডাবল কোট `"` ব্যবহার করেন।

```crystal
"Hello World"
```

## কনক্যাটেনেশন

দুটি স্ট্রিং কনক্যাটেনেট করতে `+` অপারেটরটি ব্যবহার করুন। `+` অপারেটর দুটি স্ট্রিং একসাথে মিলিয়ে একটি নতুন স্ট্রিং রিটার্ন করবে।

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## স্ট্রিং ও সংখ্যার মধ্যে রূপান্তর

`to_i` মেথড একটি স্ট্রিংকে ইন্টিজারে রূপান্তর করে। বিকল্প হিসেবে `to_f` মেথড ব্যবহার করে একটি ফ্লোটিং পয়েন্ট সংখ্যা রিটার্ন করা যায়। স্ট্রিংটিকে কোনো সংখ্যায় রূপান্তর করা না গেলে একটি `ArgumentError` রেইজ করা হবে।

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

`to_s` মেথড ব্যবহার করে একটি ইন্টিজার বা ফ্লোটিং পয়েন্ট সংখ্যাকে স্ট্রিংয়ে রূপান্তর করা যায়।

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## ইন্টারপোলেশন

ইন্টারপোলেশন হলো স্ট্রিং একসাথে জোড়া লাগানো এবং স্ট্রিংয়ের ভেতরে এক্সপ্রেশন বসানোর একটি সুবিধাজনক উপায়। স্ট্রিং ইন্টারপোলেট করতে আপনি `#` ক্যারেক্টারের পরে দ্বিতীয় বন্ধনী `{}` ব্যবহার করতে পারেন, যার ভেতরে এক্সপ্রেশনটি থাকে।

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal স্বয়ংক্রিয়ভাবে এক্সপ্রেশনটির ফলাফলকে একটি স্ট্রিংয়ে রূপান্তর করবে।

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## সাইজ

স্ট্রিংয়ের ক্যারেক্টার সংখ্যা জানতে হলে আপনি `size` মেথডটি ব্যবহার করতে পারেন, যা স্ট্রিংয়ের দৈর্ঘ্য একটি ইন্টিজার হিসেবে রিটার্ন করে। স্ট্রিংয়ের সাইজ স্ট্রিংয়ের একটি সংরক্ষিত প্রপার্টি, তাই মেথডটি প্রতিবার কল করার সময় সাইজ হিসাব করতে হয় না, ফলে এটি অনেক দ্রুত।

```crystal
"Hello World".size
# => 11
```

## ইনডেক্সিং

ইনডেক্সিং হলো যখন আপনি একটি স্ট্রিং থেকে নির্দিষ্ট কোনো ক্যারেক্টার পেতে চান। একটি `String` থেকে ক্যারেক্টার পেতে আপনি পরিচিত বন্ধনী নোটেশন ব্যবহার করতে পারেন।

~~~~exercism/note
`[]` একটি String ইনস্ট্যান্স মেথড হিসেবে বাস্তবায়িত, যেখানে ইনডেক্সটি মেথডের আর্গুমেন্ট।
~~~~

স্ট্রিংয়ের প্রথম ক্যারেক্টারটি ইনডেক্স 0-এ থাকে।

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

স্ট্রিংয়ের শেষ থেকে একটি ক্যারেক্টার পেতে হলে আপনি স্ট্রিংয়ের দৈর্ঘ্য থেকে এক বিয়োগ করে শেষ ক্যারেক্টারের ইনডেক্স বের করতে পারেন, আর শেষ থেকে দ্বিতীয় ক্যারেক্টার পেতে হলে স্ট্রিংয়ের দৈর্ঘ্য থেকে দুই বিয়োগ করতে পারেন, এভাবে চলতে থাকে। এর জন্য একটি শর্টকাট আছে, সেটি হলো সরাসরি একটি ঋণাত্মক ইনডেক্স ব্যবহার করা, যেখানে শেষ ক্যারেক্টারটি ইনডেক্স -1-এ, শেষ থেকে দ্বিতীয় ক্যারেক্টারটি ইনডেক্স -2-এ, এভাবে।

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### সাবস্ট্রিং টেস্ট

Crystal ইনডেক্সিং ব্যবহার করে কোনো স্ট্রিংয়ে একটি সাবস্ট্রিং আছে কি না তা টেস্ট করা সমর্থন করে। একই বন্ধনী নোটেশনই এটি করে, তবে ইনডেক্সের বদলে একটি সাবস্ট্রিং দেওয়া হয়। স্ট্রিংয়ে সাবস্ট্রিংটি পাওয়া গেলে সাবস্ট্রিংটি রিটার্ন করা হয়, নাহলে একটি `NilAssertionError` রেইজ করা হয়।

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

সাবস্ট্রিংটি পাওয়া গেছে কি না তা বোঝাতে যদি আপনি একটি `Bool` মান চান, তাহলে `includes?` মেথডটি ব্যবহার করতে পারেন।

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## এস্কেপিং

কিছু ক্যারেক্টার স্ট্রিংয়ে সরাসরি লেখা যায় না, বদলে একটি এস্কেপ সিকোয়েন্স ব্যবহার করতে হয়। উদাহরণস্বরূপ, আপনি যদি একটি স্ট্রিংয়ে ডাবল কোট ব্যবহার করতে চান, তাহলে ডাবল কোটগুলো এস্কেপ করতে হয়। যে ক্যারেক্টারটি আপনি এস্কেপ করতে চান, তার আগে `\` ক্যারেক্টার বসিয়ে একটি এস্কেপ সিকোয়েন্স লিখতে পারেন।

Crystal-এর বিশেষ ক্যারেক্টারগুলো হলো:

| মান      | বিবরণ                          |
| -------- | ----------------------------- |
| `\a`     | অ্যালার্ট                     |
| `\b`     | ব্যাকস্পেস                    |
| `\e`     | এস্কেপ                        |
| `\f`     | ফর্ম ফিড                     |
| `\n`     | লাইন ফিড বা নিউলাইন           |
| `\r`     | ক্যারেজ রিটার্ন                |
| `\t`     | হরাইজন্টাল ট্যাব               |
| `\v`     | ভার্টিকাল ট্যাব                |
| `\\`     | ব্যাকস্ল্যাশ                   |
| `\'`     | সিঙ্গেল কোট                    |
| `\"`     | ডাবল কোট                      |
| `\377`   | অক্টাল ASCII ক্যারেক্টার      |
| `\xFF`   | হেক্সাডেসিমাল ASCII ক্যারেক্টার |
| `\uFFFF` | হেক্সাডেসিমাল ইউনিকোড ক্যারেক্টার |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## মাল্টি-লাইন স্ট্রিং

মাল্টি-লাইন স্ট্রিং লিখতে আপনি সিঙ্গেল-লাইন স্ট্রিংয়ের মতো একই সিনট্যাক্স ব্যবহার করেন, তবে স্ট্রিংয়ে যে প্রতিটি লাইন চান তার জন্য নতুন লাইন তৈরি করেন।

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## ইউনিকোড

[ইউনিকোড][unicode] হলো বিভিন্ন লেখার পদ্ধতিতে টেক্সট এনকোড, উপস্থাপন ও প্রসেস করার একটি স্ট্যান্ডার্ড। ইউনিকোড ১০০,০০০-এরও বেশি ক্যারেক্টার সমর্থন করে, যার মধ্যে আছে অক্ষর, যতিচিহ্ন, প্রতীক এবং ইমোজি।

যেহেতু Crystal স্ট্রিংয়ের জন্য ইউনিকোড ব্যবহার করে, তাই আপনি উদাহরণস্বরূপ স্ট্রিংয়ে ইমোজি রাখতে পারেন।

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

কখনও কখনও আপনি এমন একটি ক্যারেক্টার ব্যবহার করতে চান যা উদাহরণস্বরূপ আপনার এডিটর বা সিস্টেমে পাওয়া যায় না। সেক্ষেত্রে আপনি ক্যারেক্টারটি লিখতে ইউনিকোড এস্কেপ সিকোয়েন্স ব্যবহার করতে পারেন।

```crystal
"\u{1F310}"
# => "🌐"
```
