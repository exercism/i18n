# ভূমিকা

প্রোগ্রামিং-এ এররগুলো সুন্দরভাবে সামলে নেওয়া খুব জরুরি, যাতে অপ্রত্যাশিত পরিস্থিতিতে প্রোগ্রাম ক্র্যাশ না করে বা এলোমেলো আচরণ না করে।
Cairo এরর সামলানোর জন্য দুটি প্রধান পদ্ধতি দেয়:

1. `panic` দিয়ে **অপুনরুদ্ধারযোগ্য এরর**, যা সঙ্গে সঙ্গে প্রোগ্রাম থামিয়ে দেয়।
2. `Result` দিয়ে **পুনরুদ্ধারযোগ্য এরর**, যা প্রোগ্রামকে এররগুলো সামলানোর ও তার প্রতিক্রিয়া জানানোর সুযোগ দেয়।

## `panic` দিয়ে অপুনরুদ্ধারযোগ্য এরর

কখনও কখনও প্রোগ্রাম এমন গুরুতর একটি এররে পড়ে যে আর এগোনো সম্ভব হয় না।
এমন ক্ষেত্রে Cairo সঙ্গে সঙ্গে প্রোগ্রাম চালানো বন্ধ করতে `panic` ফাংশনটি ব্যবহার করে।
কোনো এরর, যেমন সীমার বাইরের কোনো ইনডেক্স অ্যাক্সেস করার চেষ্টা, প্রোগ্রামের পক্ষে বুদ্ধিমানের মতো এগিয়ে চলা অসম্ভব করে দিলে এটা কাজে লাগে।
`panic` ফাংশন এমন একটি `ByteArray` বার্তা নেয়, যেখানে এররের কারণ লেখা থাকে।

যেমন, Cairo-তে:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

এই উদাহরণে জোর করে একটি প্যানিক ঘটানো হয়েছে, যা সঙ্গে সঙ্গে একটি বার্তাসহ প্রোগ্রাম থামিয়ে দেয়।

### `assert!` ম্যাক্রো

নিজের কোডে নির্দিষ্ট শর্ত প্রয়োগ করতে `assert!` ম্যাক্রো একটি দরকারি হাতিয়ার।
`assert!`-এর ভেতরের শর্ত যদি `false` হয়, তবে প্রোগ্রামটি একটি `ByteArray` এরর বার্তা নিয়ে প্যানিক করবে।
ডেভেলপমেন্টের সময় নিজের অনুমানগুলো যাচাই করতে এবং মানগুলো নির্দিষ্ট কিছু শর্ত পূরণ করে কি না নিশ্চিত করতে এটি প্রায়ই ব্যবহার করা হয়।

যেমন:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

`x` যদি শূন্যের চেয়ে বড় না হয়, তবে প্রোগ্রামটি `"x must be greater than zero"` বার্তা নিয়ে প্যানিক করবে। নিজে হাতে এরর সামলানোর কোড না লিখেই ইনভ্যারিয়েন্ট ও প্রিকন্ডিশন যাচাই করতে `assert!` কাজে লাগে।

## `Result` দিয়ে পুনরুদ্ধারযোগ্য এরর

সব এরর যে প্রোগ্রাম থামিয়ে দিতে হয়, তা নয়।
কিছু এরর সুন্দরভাবে সামলে নেওয়া যায়, যাতে প্রোগ্রাম চালিয়ে যাওয়া সম্ভব হয়।
Cairo-এর `Result` এনাম এই পুনরুদ্ধারযোগ্য এররগুলো বোঝায়, এবং এর দুটি ভ্যারিয়েন্ট রয়েছে:

- `Result::Ok` সফলতা বোঝায়।
- `Result::Err` একটি এরর বোঝায়।

`Result` ব্যবহার করে একটি ফাংশন সফলতার মান অথবা একটি এরর, দুটোর যেকোনোটি রিটার্ন করতে পারে, যার ফলে কল করা ফাংশনটি সিদ্ধান্ত নিতে পারে এরপর কী করবে।

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

এই উদাহরণে `b` যদি শূন্য হয়, তবে একটি এরর রিটার্ন করা হয়; না হলে ভাগের ফলাফল রিটার্ন করা হয়।
