# সম্পর্কে

[টুপল][tuple] সাধারণত তথ্য একসাথে গুছিয়ে রাখতে ব্যবহার করা হয়। এরা অ্যারে থেকে এভাবে আলাদা যে এদের আকার নির্দিষ্ট, আর এরা ভিন্ন ভিন্ন ডেটা টাইপ ধারণ করতে পারে। টুপল তৈরি করা হয় বন্ধনী `()` দিয়ে, আর ফাংশন থেকে একাধিক মান রিটার্ন করতেও এগুলো প্রায়ই ব্যবহার করা হয়।

```haskell
tuple = (1, "abc", False)
```

এটি কাজে লাগে, যেমন ধরুন আপনি 2D স্পেসে একটি কো-অর্ডিনেট সংরক্ষণ করতে চান; তখন আপনি জানেন যে টুপলটিতে সবসময় দুটি এলিমেন্ট থাকবে, x ও y কো-অর্ডিনেট।

```haskell
coordinate = (3, 4)
```

## এলিমেন্ট অ্যাক্সেস করা

বেশিরভাগ সময়েই আপনি ছোট টুপল নিয়ে কাজ করেন, আর `fst` ও `snd` ফাংশন ব্যবহার করে এলিমেন্টগুলো অ্যাক্সেস করতে পারেন।

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
