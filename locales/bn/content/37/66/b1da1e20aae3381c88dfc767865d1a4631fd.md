# নির্দেশনা সংযোজন

## ট্র্যাক-নির্দিষ্ট নির্দেশনা

ফাংশনগুলো গুণফল এবং গুণনীয়ক অ্যারের অফসেট ও দৈর্ঘ্য রিটার্ন করার কথা। গুণনীয়কগুলো মেমরিতে শুধু i32-এর জোড়া হিসেবে লেখা থাকে:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

এক অঙ্কের বৃহত্তম প্যালিনড্রোম গুণফলের ক্ষেত্রে এটি দেখতে এমন হবে:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
