# ভূমিকা

Go-তে ভ্যারিয়েবলের মানের জন্য খালি, null বা undefined বলে কোনো ধারণা নেই।
স্পষ্ট কোনো প্রাথমিক মান ছাড়া ডিক্লেয়ার করা ভ্যারিয়েবল ডিফল্টভাবে নিজ নিজ টাইপের শূন্য মান পায়।

বুলিয়ান, সংখ্যাসূচক টাইপ আর স্ট্রিংয়ের মতো প্রিমিটিভ টাইপের শূন্য মান যথাক্রমে `false`, `0` আর `""`।

শূন্য বোঝানো `nil` আইডেন্টিফায়ারটি পয়েন্টার, ফাংশন, ইন্টারফেস, স্লাইস, চ্যানেল আর ম্যাপের মতো আরও জটিল টাইপের শূন্য মান।

নিচের টেবিলে Go-এর টাইপগুলোর শূন্য মান বিস্তারিত দেওয়া হলো।

| টাইপ      | শূন্য মান |
| --------- | ---------- |
| বুলিয়ান   | `false`    |
| সংখ্যাসূচক | `0`        |
| স্ট্রিং    | `""`       |
| পয়েন্টার  | `nil`      |
| ফাংশন     | `nil`      |
| ইন্টারফেস  | `nil`      |
| স্লাইস     | `nil`      |
| চ্যানেল    | `nil`      |
| ম্যাপ      | `nil`      |

আপনি হয়তো খেয়াল করেছেন, উপরের টেবিলে struct টাইপ নেই।
এর কারণ, struct টাইপের শূন্য মান নির্ভর করে তার ফিল্ডগুলোর উপর।
struct-এর সব ফিল্ড যখন নিজ নিজ শূন্য মানে সেট হয়, তখন struct-টিও তার শূন্য মানে সেট হয়ে যায়।
