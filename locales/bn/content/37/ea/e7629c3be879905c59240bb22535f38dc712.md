# নির্দেশনা

[পেইন্ট বাই নাম্বার][paint-by-number] (যা _কালার বাই নাম্বার_ নামেও পরিচিত) হলো রং করার জন্য তৈরি সাদা-কালো ছবি।
ছবির বিভিন্ন অংশে ভিন্ন ভিন্ন সংখ্যা লেখা থাকে,
আর সেই সংখ্যাগুলো আগে থেকে ঠিক করা একটি রঙের প্যালেটের নির্দিষ্ট রঙের সঙ্গে মেলে।
লক্ষ্য হলো সঠিক রং দিয়ে অংশগুলো ভরা,
যাতে শেষে একটি সুন্দর রঙিন ছবি ফুটে ওঠে।
এটি শিশু আর বড় সবার জন্যই একটি আরামদায়ক কাজ।

আপনার কাজ হলো Elixir-এ একটি পেইন্ট বাই নাম্বার অ্যাপ লেখা।
আপনি চান আপনার অ্যাপ যেন একটি কাস্টম ডেটা ফরম্যাটে ছবি ইমপোর্ট ও এক্সপোর্ট করতে পারে।
আপনার ছবির ডেটা সংরক্ষণ করতে আপনি [বাইনারি ফাইল][binary-file] ব্যবহার করার সিদ্ধান্ত নিয়েছেন।

~~~~exercism/note
এই অনুশীলনীটি ধরে নেয় যে আপনি [বাইনারি সংখ্যা](https://en.wikipedia.org/wiki/Binary_number) সম্পর্কে জানেন
এবং বাইনারি সংখ্যাকে দশমিক সংখ্যায় আর দশমিক সংখ্যাকে বাইনারি সংখ্যায় বদলানোর পেছনের নীতিগুলো বোঝেন।
~~~~

চলুন কল্পনা করি আপনার কাছে নিচে দেখানো মতো একটি স্মাইলির ছবি আছে।
ছবিটির পটভূমি সাদা। স্মাইলিটির সীমানা কালো আর ভরাট রং হলুদ।

এই ছবিটিতে ৩টি রং ব্যবহৃত হয়েছে।
ধরা যাক আমরা সেই রঙগুলোর জন্য ইনডেক্স ঠিক করি:
- `0` (বাইনারি: `0b00`) সাদার জন্য,
- `1` (বাইনারি: `0b01`) কালোর জন্য,
- `2` (বাইনারি: `0b10`) হলুদের জন্য।

এখন আমরা প্রতিটি পিক্সেলের রং প্রকাশ করতে ওই রঙের ইনডেক্সগুলো ব্যবহার করতে পারি।

## 1. প্যালেটের বিট সাইজ বের করুন

`PaintByNumber.palette_bit_size/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্যালেটের রঙের সংখ্যা নেবে এবং সেই সংখ্যক রঙের ইনডেক্সকে বাইনারি সংখ্যা হিসেবে প্রকাশ করতে কতটি বিট দরকার, তা রিটার্ন করবে। রঙের ইনডেক্স সবসময় 0 থেকে শুরু হয় এবং পরপর বাড়তে থাকা ইন্টিজার হয়।

যেমন, ১৩টি ভিন্ন রং প্রকাশ করতে ৪টি বিট দরকার। ৪টি বিট দিয়ে সর্বোচ্চ ১৬টি রঙের ইনডেক্স রাখা যায় (2^4)। ৩টি বিট যথেষ্ট হবে না, কারণ ৩টি বিট দিয়ে সর্বোচ্চ ৮টি রঙের ইনডেক্স রাখা যায় (2^3)।

```elixir
PaintByNumber.palette_bit_size(13)
# => 4
```

দ্রষ্টব্য: Elixir স্ট্যান্ডার্ড লাইব্রেরিতে কোনো `log2` ফাংশন নেই। পরে আপনি শিখবেন কীভাবে Elixir থেকে [Erlang লাইব্রেরি][erlang-libraries] ব্যবহার করতে হয়, যেখানে এই ফাংশনটি পাবেন। এখন বরং রিকার্সন আর [পাওয়ার অপারেটর `**`][power-operator] দিয়ে এই কাজটি সমাধান করুন।

## 2. একটি খালি ছবি তৈরি করুন

`PaintByNumber.empty_picture/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি খালি বিটস্ট্রিং রিটার্ন করবে।

## 3. একটি টেস্ট ছবি তৈরি করুন

আপনার অ্যাপের মৌলিক ফিচারগুলো হাতে-কলমে পরীক্ষা করার জন্য একটি আগে থেকে নির্ধারিত টেস্ট ছবি ব্যবহার করা হবে।
টেস্ট ছবিটি ৪টি ভিন্ন রঙের ৪টি পিক্সেল নিয়ে গঠিত।

`PaintByNumber.test_picture/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি এমন একটি বিটস্ট্রিং রিটার্ন করবে যা ৪টি সেগমেন্ট নিয়ে গঠিত।
প্রতিটি সেগমেন্টের বিট সাইজ হবে 2। সেগমেন্টগুলোর মান হবে 0, 1, 2 আর 3।

## 4. একটি ছবির শুরুতে একটি পিক্সেল যোগ করুন

`PaintByNumber.prepend_pixel/3` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি তিনটি আর্গুমেন্ট নেবে: যে ছবির শুরুতে যোগ করা হচ্ছে সেই ছবির বিটস্ট্রিং, প্যালেটের রঙের সংখ্যা, আর নতুন পিক্সেলের রঙের ইনডেক্স। এটি এমন একটি বিটস্ট্রিং রিটার্ন করবে যেখানে নতুন পিক্সেলটি ছবির শুরুতে যোগ করা হয়েছে।

```elixir
picture = <<2::4, 0::4>>
color_count = 13
pixel_color_index = 11

PaintByNumber.prepend_pixel(picture, color_count, pixel_color_index)
# => <<178, 0::size(4)>>
# (which is equal to <<11::4, 2::4, 0::4>>)
```

## 5. একটি ছবি থেকে প্রথম পিক্সেলটি বের করুন

`PaintByNumber.get_first_pixel/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে: যে ছবিটি থেকে পড়া হচ্ছে সেই ছবির বিটস্ট্রিং, আর প্যালেটের রঙের সংখ্যা। এটি প্রদত্ত ছবির প্রথম পিক্সেলের রঙের ইনডেক্স রিটার্ন করবে। খালি ছবি দিলে এটি `nil` রিটার্ন করবে।

```elixir
picture = <<19::5, 2::5, 18::5>>
color_count = 20

PaintByNumber.get_first_pixel(picture, color_count)
# => 19
```

## 6. একটি ছবি থেকে প্রথম পিক্সেলটি বাদ দিন

`PaintByNumber.drop_first_pixel/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে: যে ছবিটি থেকে একটি পিক্সেল সরানো হচ্ছে সেই ছবির বিটস্ট্রিং, আর প্যালেটের রঙের সংখ্যা। এটি প্রথম পিক্সেল ছাড়া ছবিটি রিটার্ন করবে। খালি ছবি দিলে এটি একটি খালি ছবি রিটার্ন করবে।

```elixir
picture = <<2::3, 5::3, 5::3, 0::3>>
color_count = 6

PaintByNumber.drop_first_pixel(picture, color_count)
# => <<180, 0::size(1)>>
# (which is equal to <<5::3, 5::3, 0::3>>)
```

## 7. দুটি ছবি জোড়া লাগান

`PaintByNumber.concat_pictures/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে, দুটি বিটস্ট্রিং। এটি এমন একটি বিটস্ট্রিং রিটার্ন করবে, যা প্রথম আর্গুমেন্টটি দ্বিতীয় আর্গুমেন্টের শুরুতে যোগ করার ফল।

```elixir
picture1 = <<52::6, 51::6>>
picture2 = <<0::6, 34::6, 12::6>>

PaintByNumber.concat_pictures(picture1, picture2)
# => <<211, 48, 34, 12::size(6)>>
# (which is equal to <<52::6, 51::6, 0::6, 34::6, 12::6>>)
```
