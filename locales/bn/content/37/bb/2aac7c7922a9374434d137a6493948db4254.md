# ভূমিকা

প্রতিটি Factor সোর্স ফাইল `IN:` দিয়ে একটি *ভোকাবুলারি* ডিক্লেয়ার করে এবং যে অন্যগুলো ব্যবহার করে সেগুলো `USING:` দিয়ে ইমপোর্ট করে।

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

ডিরেক্টরির বিন্যাস ভোকাবের ডটযুক্ত নাম অনুসরণ করে:

- `my-vocab` ভোকাবটি `my-vocab/my-vocab.factor` ফাইলে থাকে।
- `my-vocab.helpers` ভোকাবটি `my-vocab/helpers/helpers.factor` ফাইলে থাকে।

Factor-এর ভোকাবুলারি লোডার `USING:` ডিক্লেয়ারেশনগুলো ট্রানজিটিভভাবে অনুসরণ করে। অর্থাৎ আপনি যে ফাইলটি রিকোয়ার করেন সেটি যখন অন্য একটি ভোকাব ইমপোর্ট করে, তখন সেই ভোকাবটি স্বয়ংক্রিয়ভাবে লোড হয়ে যায়।

বড় একটি রুটিনকে আপনি প্রায়ই দুটি ভোকাবুলারিতে ভাগ করে ফেলবেন: ছোট, পুনরায় ব্যবহারযোগ্য ওয়ার্ড নিয়ে একটি হেল্পার ভোকাব, আর সেগুলো ইমপোর্ট করে ফলাফলটি গঠন করা একটি মূল ভোকাব।
