# পরিচিতি

## ট্রেইলিং ক্লোজার

ক্লোজার নিয়ে কাজ করার সময় Swift তার সিনট্যাক্সের আরেকটি প্রকরণ দেয়, যাকে বলা হয় [ট্রেইলিং ক্লোজার][trailing-closures]। কোনো ফাংশনের প্যারামিটার তালিকার শেষ প্যারামিটারটির টাইপ যখন ফাংশন টাইপ হয়, তখনই ট্রেইলিং ক্লোজার দেখা যায়। সেক্ষেত্রে কেউ যদি একটি ক্লোজার পাস করেন, তাহলে ক্লোজারটি ক্লোজিং বন্ধনীর _পরে_ লেখা যায় এবং আর্গুমেন্ট লেবেলটি বাদ দেওয়া হয়। মনে রাখবেন, ফাংশনটির কেবল একটি প্যারামিটার থাকলে বন্ধনী দুটি সম্পূর্ণ বাদ দেওয়া যায়।

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## একাধিক ট্রেইলিং ক্লোজার

Swift-এর আগের ভার্সনগুলোতে কেবল একটি ট্রেইলিং ক্লোজার ব্যবহারের সুবিধা ছিল, কিন্তু 5.2.4 ভার্সন থেকে Swift একাধিক ট্রেইলিং ক্লোজার ব্যবহারের সুবিধা দেয়।

কোনো ফাংশনের প্যারামিটার তালিকার শেষে একাধিক ক্লোজার থাকলে, ট্রেইলিং ক্লোজার সিনট্যাক্স ব্যবহার করে সেগুলো সব বন্ধনীর বাইরে আনা যায়। তবে কেবল প্রথম আর্গুমেন্ট লেবেলটি বাদ পড়ে, বাকিগুলো লেবেল করতে হয়:

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```
