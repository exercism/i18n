# নির্দেশনা

হ্যালো, এজেন্ট Double-Null0111।

আপনার মিশন, যদি আপনি এটি গ্রহণ করতে চান, হলো UMBRA (United Minions Being Really Awful) সদর দপ্তরে অনুপ্রবেশ করে তাদের সর্বশেষ সত্যিই ভয়ানক পরিকল্পনার নথি উদ্ধার করা।
এই মিশন সম্পন্ন করতে আপনার তিনটি টুল লাগবে।

## 1. একটি আইডি নম্বর তৈরি করুন

প্রতিটি মিনিয়নের একটি অনন্য আইডেন্টিফায়ার থাকে, যা প্রতিদিন বদলে যায় এবং তারা কতগুলো গোপন তথ্য ধারণ করে ও কত ঘণ্টা ঘুমায় তার উপর নির্ভর করে।
আপনাকে একটি ফাংশন লিখতে হবে, যা দিনটি (`Int` হিসেবে) নেয় এবং সেই দিনের জন্য একটি আইডেন্টিফায়ার তৈরির ফাংশন তৈরি করে।
আইডেন্টিফায়ার তৈরির ফাংশনটি দুটি প্যারামিটার নেয়:

1. ধারণ করা গোপন তথ্যের সংখ্যা
2. মিনিয়ন কত ঘণ্টা ঘুমায় তার সংখ্যা

আইডেন্টিফায়ারটি এভাবে হিসাব করা হয়:

1. তারা যে পরিমাণ গোপন তথ্য ধারণ করে, সেটিকে তাদের ঘুমের ঘণ্টার সংখ্যা দিয়ে গুণ করুন
2. ফলাফলের সাথে দিনটি (`Int` হিসেবে প্রকাশিত) যোগ করুন

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. উদ্ধার করা গোপন পরিকল্পনাগুলো একটি গোপন পাসওয়ার্ড দিয়ে সুরক্ষিত করুন

একবার গোপন পরিকল্পনাগুলো হাতে এলে, সেগুলো এমনভাবে সুরক্ষিত করতে হবে যাতে কেবল যারা পাসওয়ার্ড জানে তারাই সেগুলো উদ্ধার করতে পারে।
এটি করার জন্য আপনাকে `protectSecret(secret: String, password: String) : (String) -> String` ফাংশনটি ইমপ্লিমেন্ট করতে হবে।
এই ফাংশনটি আরেকটি ফাংশন রিটার্ন করবে, যা ইনপুট হিসেবে সম্ভাব্য পাসওয়ার্ড স্ট্রিংগুলো নেয়।
যদি দেওয়া পাসওয়ার্ডটি সঠিক হয়, তবে নতুন ফাংশনটি লুকানো গোপন তথ্যটি রিটার্ন করে; কিন্তু পাসওয়ার্ডটি ভুল হলে ফাংশনটি "Sorry. No hidden secrets here." রিটার্ন করে।

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. গোপন পাসওয়ার্ডটি খুঁজে বের করুন

UMBRA ঘাঁটিতে বেশ কিছু ঘর আছে, যেগুলো পাহারা দেয় একজন নিরাপত্তারক্ষী, যিনি আপনার কাছে গোপন পাসওয়ার্ড চাইবেন।
গোপন পাসওয়ার্ডটি নির্ভর করে ঘরটির নম্বরের উপর।
দুর্ভাগ্যবশত, পাসওয়ার্ডটি বের করার অ্যালগরিদমের অর্ধেকই কেবল আমরা জানি।
বাকি অর্ধেকটি খুঁজে পাওয়া যাবে মিনিয়নদের একজনকে জিজ্ঞাসা করে।

`getPassword` ফাংশনটি ইমপ্লিমেন্ট করুন, যা নিচের জিনিসগুলো নেয় এবং পাসওয়ার্ডটি রিটার্ন করে:

1. ঘরের নম্বর
2. মিনিয়নের ফাংশন, এবং গোপন পাসওয়ার্ডটি রিটার্ন করে

মিনিয়নের ফাংশনটিকে আমাদের জানা অ্যালগরিদমের প্রতিনিধিত্বকারী আরেকটি ফাংশন দিয়ে কল করে গোপন পাসওয়ার্ডটি পাওয়া যায়।
অ্যালগরিদমের আমাদের অংশটি:

1. দুটি সংখ্যা নেয় এবং সেগুলো একসাথে যোগ করে
2. ফলাফলটিকে ঘরের আইডি দিয়ে গুণ করে

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
