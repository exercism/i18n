# সম্পর্কে

Haxe-এ, একটি অ্যাবস্ট্রাক্ট টাইপ হলো এমন একটি টাইপ যা রানটাইমে একটি ভিন্ন টাইপ। এটি একটি কম্পাইল-টাইম ফিচার যা কনক্রিট টাইপের 'উপরে' টাইপ ডিফাইন করে, যাতে তাদের আচরণ পরিবর্তন বা বাড়ানো যায়:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

এখানে আমরা `abstract` কিওয়ার্ড ব্যবহার করে `AbstractInt` টাইপটি ডিক্লেয়ার করছি। এর সিনট্যাক্স `class`-এর সিনট্যাক্সের সাথে অনেকটাই মিল। আর ক্লাসের মতোই, অ্যাবস্ট্রাক্ট টাইপেও মেথড থাকতে পারে। এগুলো ক্লাসের মতোই ইনস্ট্যানশিয়েট ও ব্যবহার করা যায়:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

উপরে বলা হয়েছে, অ্যাবস্ট্রাক্টগুলো একটি কম্পাইল-টাইম ফিচার। উপরের উদাহরণটি JavaScript-এ কম্পাইল করলে নিচের ফল পাওয়া যায়:

```javascript
var a = 12;
console.log(a)
```

অ্যাবস্ট্রাক্ট টাইপ `AbstractInt` আউটপুট থেকে সম্পূর্ণ হারিয়ে যায়। এর কারণ `Abstract`-এর কনস্ট্রাক্টরটি [ইনলাইন করা][inline], যা আমরা পরে দেখব।

[inline]: https://haxe.org/manual/class-field-inline.html
