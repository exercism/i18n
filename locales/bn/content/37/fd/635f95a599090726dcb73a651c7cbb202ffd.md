# নির্দেশনার পরিশিষ্ট

## ট্রি প্রিন্ট করা

এই অনুশীলনীতে ট্রিটি সুন্দর একটি ফরম্যাটে প্রিন্ট করার জন্য আগেই ডিফাইন করা কিছু ক্লাস মেথড আছে। এর মূল উদ্দেশ্য হলো debug করতে সাহায্য করা এবং বাড়তি স্পষ্টতা দেওয়া। আপনি যদি ক্লাসের বাকি অংশটি সঠিকভাবে ইমপ্লিমেন্ট করেন, তাহলে এটি আপনার হয়ে ট্রিটি প্রিন্ট করে দেবে।

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
