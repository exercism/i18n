# পরিচিতি

ABAP এমন একটি অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং মডেল সমর্থন করে, যা ABAP Objects-এর ক্লাস ও ইন্টারফেসের উপর ভিত্তি করে গড়ে উঠেছে।

## (পুনরায়) অ্যাসাইনমেন্ট

ABAP-তে নামের সাথে মান বসানোর কয়েকটি প্রধান উপায় আছে, সেগুলো হলো ভ্যারিয়েবল বা কনস্ট্যান্ট ব্যবহার করা। Exercism-এ ভ্যারিয়েবলগুলো সবসময় [snake-case][wiki-snake-case]-এ লেখা হয়। অনুসরণ করার মতো কোনো অফিসিয়াল গাইড নেই, আর বিভিন্ন কোম্পানি ও প্রতিষ্ঠানের স্টাইল গাইডও ভিন্ন ভিন্ন। _আপনি নিজের ইচ্ছেমতো যেভাবেই চান ভ্যারিয়েবল লিখতে পারেন_। অনুশীলনীগুলো যেভাবে তৈরি করা হয়েছে সেভাবে ভ্যারিয়েবল লিখলে একটা সুবিধা আছে: ওয়েব ইন্টারফেসে এবং বেশিরভাগ IDE-তে সেগুলো আলাদাভাবে হাইলাইট হবে।

ABAP-তে [`constant`][constant] বা [`data`][data] কিওয়ার্ড ব্যবহার করে ভ্যারিয়েবল ডিফাইন করা যায়।

`data` ব্যবহার করলে একটি ভ্যারিয়েবল তার জীবনকালে বিভিন্ন মান রেফার করতে পারে। উদাহরণস্বরূপ, [অ্যাসাইনমেন্ট অপারেটর `=`][assignment] দিয়ে `my_first_variable`-কে অনেকবার ডিফাইন ও পুনরায় ডিফাইন করা যায়:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

`data`-এর বিপরীতে, `constant` দিয়ে ডিফাইন করা ভ্যারিয়েবলে কেবল একবারই মান অ্যাসাইন করা যায়। ABAP-তে কনস্ট্যান্ট ডিফাইন করতে এটাই ব্যবহার করা হয়।

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## ক্লাস ও মেথড ডিক্লারেশন

ABAP-তে কার্যকারিতার এককগুলো _মেথডে_ এনক্যাপসুলেট করা হয়, আর মেথডগুলো একসাথে থাকলে সাধারণত সেগুলোকে একই [ক্লাসে][classes] একত্রিত করা হয়। এই মেথডগুলো প্যারামিটার (আর্গুমেন্ট) নিতে পারে এবং মেথড ডেফিনিশনে `returning` কিওয়ার্ড ব্যবহার করে একটি মান _রিটার্ন_ করতে পারে। মেথড কল করা হয় `( )` সিনট্যাক্স ব্যবহার করে।

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 ABAP-তে ক্লাস ও মেথড ডিক্লেয়ার করার _অনেক_ ভিন্ন উপায় আছে। ট্র্যাকটি ধীরে ধীরে সেগুলোর সাথে পরিচয় করানোর চেষ্টা করে, তবে আপনি যদি এগুলো আগে থেকেই জানেন, তবে যেকোনো একটি স্বচ্ছন্দে ব্যবহার করতে পারেন। বেশিরভাগ ক্ষেত্রেই একটির বদলে অন্যটি ব্যবহার করা ভালো বা খারাপ কিছু নয়।
