# পরিচিতি

ফিল্টারিং হলো একটি সিকোয়েন্স থেকে আরেকটি সিকোয়েন্স তৈরির প্রক্রিয়া, যেখানে মূল সিকোয়েন্সের নির্দিষ্ট কিছু এলিমেন্ট ছাড়া বাকি সব কপি করা হয়।
নতুন সিকোয়েন্সে কোন আইটেমগুলো রাখা হবে সেই বাছাইটি করা যায় একটি প্রেডিকেট ফাংশন দিয়ে (এমন একটি ফাংশন যার ফলাফল একটি বুলিয়ান মান), অথবা কোনো নির্দিষ্ট অবজেক্টের সাথে সমতা দিয়ে।

## প্রেডিকেট দিয়ে বাদ দেওয়া

`remove-if` এমন একটি ফাংশন, যা আর্গুমেন্ট হিসেবে একটি প্রেডিকেট ফাংশন আর একটি সিকোয়েন্স নেয় এবং শুধু সেই এলিমেন্টগুলো নিয়ে একটি সিকোয়েন্স রিটার্ন করে, যাদের জন্য প্রেডিকেটটি ফলস মান দিয়েছিল।
অন্য কথায়, এটি সিকোয়েন্সের সেই সব এলিমেন্ট "বাদ দেয়" যাদের জন্য প্রেডিকেটটি ট্রু মান দেয়। তবে খেয়াল করুন, এই ফাংশনটি মূল সিকোয়েন্স পরিবর্তন করে না!
বরং এটি সংশ্লিষ্ট এলিমেন্টগুলো ছাড়া একটি নতুন সিকোয়েন্স রিটার্ন করে। যদি সব মানের জন্যই প্রেডিকেটটি ট্রু হয়ে থাকে, তাহলে একটি খালি সিকোয়েন্স রিটার্ন করা হয়।

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## নির্দিষ্ট একটি আইটেম বাদ দেওয়া

কোনো সিকোয়েন্স থেকে নির্দিষ্ট একটি আইটেম বাদ দিতে চাইলে `remove` ব্যবহার করতে পারেন, যা বাদ দেওয়ার আইটেমটি আর একটি সিকোয়েন্স নেয়।
সিকোয়েন্সের যে মানগুলো বাদ দেওয়ার আইটেমটির সমান নয়, সেগুলো রিটার্ন করা হয়।
দ্রষ্টব্য: ডিফল্টভাবে সমতা যাচাই করা হয় `eql` [জেনেরিক সমতা প্রেডিকেট][concept-equality] দিয়ে।

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

[concept-equality]: /tracks/common-lisp/concepts/equality
