# SQLite-নির্দিষ্ট নির্দেশনা

**result** কলামে JSON-এনকোড করা অবজেক্টের অবজেক্ট থাকা উচিত, যেখানে প্রতিটি শব্দ কী (key) হিসেবে আর তার গণনা ইন্টিজার হিসেবে থাকবে।

উদাহরণস্বরূপ, উপরের বাক্যটি ধরুন: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
এই ইনপুটের জন্য **result** হবে:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## টেবিল স্কিমা

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
