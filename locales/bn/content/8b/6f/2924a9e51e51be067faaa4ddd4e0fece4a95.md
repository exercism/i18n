# ভূমিকা

## রিকার্সন

রিকার্সিভ ফাংশন হলো এমন ফাংশন, যেগুলো নিজেদেরকে কল করে।

একটি রিকার্সিভ ফাংশনে অন্তত একটি _বেস কেস_ এবং অন্তত একটি _রিকার্সিভ কেস_ থাকতে হয়।

একটি _বেস কেস_ ফাংশনটিকে আবার কল না করেই একটি মান রিটার্ন করে।
একটি _রিকার্সিভ কেস_ ফাংশনটিকে আবার কল করে এবং ইনপুট পরিবর্তন করে, যাতে একপর্যায়ে এটি বেস কেসের সাথে মিলে যায়।

Elm-এ, রিকার্সিভ ফাংশন সাধারণত `case` এক্সপ্রেশন বা একাধিক ফাংশন ক্লজের মাধ্যমে প্যাটার্ন ম্যাচিং করে ডিফাইন করা হয়।

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### রিকার্সনের মাধ্যমে লুপ

ইমিউটেবিলিটির কারণে, Elm-এ লুপ ইম্পারেটিভ ভাষার থেকে ভিন্নভাবে লেখা হয়।
উদাহরণস্বরূপ, লুপ সাধারণত এমন দেখতে হয়:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Elm-এর মতো ফাংশনাল ভাষায় ভ্যারিয়েবল মিউটেট করা সম্ভব নয়।
তাই, লুপ রিকার্সন দিয়ে ইমপ্লিমেন্ট করতে হয়।

Elm-এ একটি `for` লুপের সমতুল্য লেখা হবে এভাবে:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

বাস্তবে, Elm-এ অ্যারে ও অন্যান্য ডেটা স্ট্রাকচারের উপর ইটারেশন করা বেশিরভাগ ক্ষেত্রেই `List` মডিউলের ফাংশন যেমন `List.map`, `List.filter`, এবং `List.foldl` ব্যবহার করে করা হয়।
ভেতরে ভেতরে, এই ফাংশনগুলো রিকার্সন দিয়ে ইমপ্লিমেন্ট করা হয়।
