# ভূমিকা

## এক্সটার্নাল ফাংশন

Gleam চলে Erlang ভার্চুয়াল মেশিনে (BEAM), অথবা JavaScript রানটাইমে। এই রানটাইমগুলো ব্যবহার করে এমন আরও অনেক ভাষা আছে, আর এই ভাষাগুলোতে লেখা কোড Gleam থেকে কল করতে পারা প্রায়ই কাজে লাগে।

Gleam-এর _এক্সটার্নাল ফাংশন_ ফিচারটির সাহায্যে অন্য ভাষার ফাংশন Gleam-এ ইমপোর্ট করে কোনো রানটাইম ওভারহেড ছাড়াই কল করা যায়।

আপনার Gleam প্রজেক্ট যদি Erlang ভার্চুয়াল মেশিনে চলে আর আপনি Erlang-এর `lists` মডিউল থেকে `reverse` ফাংশনটি কল করতে চান, তাহলে একটি Gleam ফাংশন হেডে এভাবে `@external` অ্যাট্রিবিউট যোগ করে তা করতে পারেন:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

এরপর এটিকে সাধারণ Gleam ফাংশনের মতো কল করা যায়:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

আপনি যদি এই কোডটি JavaScript রানটাইমের জন্য কম্পাইল করার চেষ্টা করেন, তাহলে এটি একটি এরর মেসেজ দিয়ে ফেল করবে, কারণ JavaScript-এর জন্য কোনো ইমপ্লিমেন্টেশন নেই। JavaScript রানটাইমের জন্য এভাবে আরেকটি ইমপ্লিমেন্টেশন নির্দিষ্ট করা যায়:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

বর্তমান কম্পাইল টার্গেটের জন্য কোনো এক্সটার্নাল ইমপ্লিমেন্টেশন না থাকলে যে Gleam ইমপ্লিমেন্টেশনটি ব্যবহার হবে, সেটিও লেখা সম্ভব:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## এক্সটার্নাল টাইপ

এক্সটার্নাল টাইপ ব্যবহার করে অন্য ভাষায়, যেমন Erlang বা JavaScript-এ, সংজ্ঞায়িত ডেটা টাইপ বোঝানো যায়।

একটি এক্সটার্নাল টাইপ ডিফাইন করতে একটি টাইপ ডিক্লেয়ার করুন, কিন্তু কোনো কনস্ট্রাক্টর দেবেন না। এরপর এটিকে অন্য যেকোনো টাইপের মতোই ব্যবহার করা যায়।

```gleam
pub type OrderedDictionary(element)
```
