# নির্দেশনা

আপনি এখন নতুন ও বহুল প্রশংসিত গেম **ক্রিস্টাল হান্টার** তৈরির কাজ করছেন। গেমটিতে আপনি এমন একটি চরিত্র, যে এদিক-ওদিক ঘোরে আর ক্রিস্টাল সংগ্রহ করে। খেলোয়াড় সব ক্রিস্টাল তুলে নিলে জিতে যায়। খেলোয়াড় কোনো ডাকাতের সংস্পর্শে এলে তার সব ক্রিস্টাল হারিয়ে যায় এবং খেলাটিও হেরে যায়। এই নিয়মের একটি ব্যতিক্রম আছে: খেলোয়াড়ের একটি সক্রিয় পাওয়ার-আপ থাকতে পারে, যা তাকে ডাকাতদের কাছে অদৃশ্য করে দেয়।

আপনার লক্ষ্য হলো গেমে ব্যবহৃত কিছু নিয়ম লেখা।

## 1. চরিত্র বোনাস পয়েন্ট পায় কি না তা নির্ধারণ করুন

গেমে চরিত্রটি পাওয়ার-আপ সক্রিয় থাকা অবস্থায় কোনো ডাকাতকে স্পর্শ করলে বোনাস পয়েন্ট পায়।

`Rules#bonus_points?` মেথডটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_চরিত্রটির সক্রিয় পাওয়ার-আপ আছে কি না_ এবং _চরিত্রটি কোনো ডাকাতকে স্পর্শ করছে কি না_) এবং একটি বুলিয়ান মান রিটার্ন করে, যা জানায় চরিত্রটি বোনাস পয়েন্ট পাবে কি না। মেথডটি `true` রিটার্ন করবে কেবল তখনই, যখন চরিত্রটির একটি পাওয়ার-আপ সক্রিয় থাকে এবং সে একটি ডাকাতকে স্পর্শ করছে, অন্যথায় `false`।

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. চরিত্র পয়েন্ট পায় কি না তা নির্ধারণ করুন

খেলোয়াড় কোনো ক্রিস্টাল বা পাওয়ার-আপ তুলে নেওয়ার সময় পয়েন্ট পায়।

`Rules#score?` মেথডটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_চরিত্রটি কোনো পাওয়ার-আপ স্পর্শ করছে কি না_ এবং _চরিত্রটি কোনো ক্রিস্টাল স্পর্শ করছে কি না_) এবং একটি বুলিয়ান মান রিটার্ন করে, যা জানায় চরিত্রটি পয়েন্ট পেয়েছে কি না। মেথডটি `true` রিটার্ন করবে যদি চরিত্রটি কোনো পাওয়ার-আপ বা ক্রিস্টাল স্পর্শ করে, আর অন্যথায় `false` রিটার্ন করবে।

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. চরিত্র হারে কি না তা নির্ধারণ করুন

`Rules#lose?` মেথডটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_চরিত্রটির সক্রিয় পাওয়ার-আপ আছে কি না_ এবং _চরিত্রটি কোনো ডাকাতকে স্পর্শ করছে কি না_) এবং একটি বুলিয়ান মান রিটার্ন করে, যা জানায় চরিত্রটি হারে কি না। মেথডটি `true` রিটার্ন করবে যদি চরিত্রটি কোনো ডাকাতকে স্পর্শ করে এবং তার কোনো সক্রিয় পাওয়ার-আপ না থাকে, আর অন্যথায় `false` রিটার্ন করবে।

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. চরিত্র জেতে কি না তা নির্ধারণ করুন

`Rules#win?` মেথডটি ডিফাইন করুন, যা তিনটি আর্গুমেন্ট নেয় (_চরিত্রটি সব ক্রিস্টাল তুলে নিয়েছে কি না_, _চরিত্রটির সক্রিয় পাওয়ার-আপ আছে কি না_, এবং _চরিত্রটি কোনো ডাকাতকে স্পর্শ করছে কি না_) এবং একটি বুলিয়ান মান রিটার্ন করে, যা জানায় চরিত্রটি জেতে কি না। মেথডটি `true` রিটার্ন করবে যদি চরিত্রটি সব ক্রিস্টাল সংগ্রহ করে থাকে এবং ৩ নম্বর অংশে বর্ণিত আর্গুমেন্টের ভিত্তিতে না হারে, আর অন্যথায় `false` রিটার্ন করবে।

```crystal
Rules.new.win?(false, true, false)
# => false
```
