# Debug

যখন কোনো test ফেল করে, তখন একটি বার্তা দেখানো হয় যেখানে বলা থাকে কী ভুল হয়েছে এবং কোন ইনপুটের জন্য। আপনি এই বিষয়টিও কাজে লাগাতে পারেন যে যেকোনো [কনসোল আউটপুট][programiz.com-basic-input-output]ও দেখানো হবে। আপনি কনসোলে লিখতে পারেন এভাবে:

```csharp
Console.WriteLine("Debug message");
```
