# নির্দেশনা

আপনি একটি Take-A-Number মেশিনের জন্য একটি এমবেডেড সিস্টেম লিখছেন। এটি খুবই সরল একটি মডেল। এটি পরপর নম্বর দিতে পারে এবং সর্বশেষ কোন নম্বর দেওয়া হয়েছিল তা জানাতে পারে।

## 1. মেশিন চালু করুন

`start/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি নতুন প্রসেস তৈরি করবে এবং সেই প্রসেসের PID রিটার্ন করবে। নতুন প্রসেসটিকে এখনো কিছুই করতে হবে না।

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

মনে রাখবেন, এই কোডটি প্রতিবার চালালে PID ভিন্ন হতে পারে।

## 2. মেশিনের অবস্থা জানান

মেশিনটি এমনভাবে পরিবর্তন করুন যাতে নতুন তৈরি হওয়া প্রসেসটি মেসেজ গ্রহণের জন্য প্রস্তুত থাকে (একটি _রিসিভ লুপ_ শুরু করুন) এবং তার প্রাথমিক অবস্থা হয় `0`। এটি `{:report_state, sender_pid}` মেসেজ গ্রহণ করতে পারবে। এই মেসেজগুলোর উত্তরে এটি তার বর্তমান অবস্থা (সর্বশেষ দেওয়া টিকিট নম্বর) `sender_pid`-কে পাঠাবে এবং তারপর আরও মেসেজের জন্য অপেক্ষা করবে।

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. নম্বর দিন

মেশিনটি এমনভাবে পরিবর্তন করুন যাতে এটি `{:take_a_number, sender_pid}` মেসেজ গ্রহণ করতে পারে। এটি তার অবস্থা ১ বাড়াবে, নতুন অবস্থাটি `sender_pid`-কে পাঠাবে এবং তারপর আরও মেসেজের জন্য অপেক্ষা করবে।

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. মেশিন বন্ধ করুন

মেশিনটি এমনভাবে পরিবর্তন করুন যাতে এটি একটি `:stop` মেসেজ গ্রহণ করতে পারে। এটি আরও মেসেজের জন্য অপেক্ষা করা বন্ধ করবে।

## 5. অপ্রত্যাশিত মেসেজ উপেক্ষা করুন

মেশিনটি এমনভাবে পরিবর্তন করুন যাতে কোনো অপ্রত্যাশিত মেসেজ পেলে এটি সেটি উপেক্ষা করে এবং আরও মেসেজের জন্য অপেক্ষা করতে থাকে।
