# পরিচিতি

## এনাম

একটি _এনাম টাইপ_ হলো এক ধরনের বিশেষ ডেটা টাইপ, যার সাহায্যে একটি ভ্যারিয়েবল পূর্বনির্ধারিত কনস্ট্যান্টের একটি সেট হতে পারে।
ভ্যারিয়েবলটিকে তার জন্য পূর্বনির্ধারিত মানগুলোর একটির সমান হতে হবে।
কমন উদাহরণের মধ্যে আছে কম্পাসের দিকনির্দেশ (`NORTH`, `SOUTH`, `EAST` এবং `WEST` মান) আর সপ্তাহের বারগুলো।

যেহেতু এগুলো কনস্ট্যান্ট, তাই একটি এনাম টাইপের ফিল্ডগুলোর নাম বড় হাতের অক্ষরে লেখা হয়।

### একটি এনাম টাইপ ডিফাইন করা

Java প্রোগ্রামিং ভাষায় একটি এনাম টাইপ ডিফাইন করতে `enum` কিওয়ার্ডটি ব্যবহার করেন।
উদাহরণস্বরূপ, সপ্তাহের বারের একটি এনাম টাইপ আপনি এভাবে লিখতে পারেন:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

যখনই নির্দিষ্ট একটি সেটের কনস্ট্যান্ট উপস্থাপন করার দরকার হয়, তখনই এনাম টাইপ ব্যবহার করা উচিত।
এর মধ্যে আছে আমাদের সৌরজগতের গ্রহগুলোর মতো স্বাভাবিক এনাম টাইপ, আর এমন ডেটা সেট যেখানে কম্পাইল টাইমেই সম্ভাব্য সব মান জানা থাকে, যেমন মেনুর পছন্দ, কমান্ড লাইন ফ্ল্যাগ ইত্যাদি।

### একটি এনাম টাইপ ব্যবহার করা

উপরের `DayOfWeek` এনামটি কীভাবে ব্যবহার করবেন, তা নিচের কোডে দেখানো হয়েছে:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### মেথড ও ফিল্ড যোগ করা

Java প্রোগ্রামিং ভাষার এনাম টাইপগুলো অন্য ভাষার সমতুল্য জিনিসের চেয়ে অনেক বেশি শক্তিশালী।
`enum` ডিক্লারেশন একটি _ক্লাস_ ডিফাইন করে (যাকে _এনাম টাইপ_ বলা হয়)।
এনাম ক্লাসের বডিতে মেথড ও অন্যান্য ফিল্ড থাকতে পারে:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating` এনাম টাইপের একটি সদস্যের উপর `getNumberOfStars` মেথড কল করা:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
