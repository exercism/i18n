# টেস্ট


আমরা আমাদের ওয়েবসাইটের টেস্ট রানার হিসেবে [pytest][pytest: Getting Started Guide] ব্যবহার করি।
Python ট্র্যাকের টেস্টগুলো নিজের কম্পিউটারে রান করতে চাইলে আপনার ডেভেলপমেন্ট মেশিনে `pytest` ইনস্টল করতে হবে।
এর সাথে নিচের `pytest` প্লাগইনগুলোও ইনস্টল করা উচিত:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

আরও বিস্তারিত তথ্য আমাদের ওয়েবসাইটের [Python টেস্টিং গাইড][Python track tests page]-এ পাবেন।


### টেস্ট রান করা

সাথে দেওয়া টেস্টগুলো রান করতে, টার্মিনালে `cd` ব্যবহার করে যে ফোল্ডারে অনুশীলনীটি রাখা আছে সেখানে যান (_নিচের `<exercise-folder-location>`-এর জায়গায় আপনার পাথ বসান_)।
টেস্ট ফাইলগুলোর নাম সাধারণত `_test.py` দিয়ে শেষ হয়, আর সলিউশন আপলোড করলে ওয়েবসাইটে যে টেস্টগুলো রান হয়, এগুলো ঠিক সেগুলোই।

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

এরপর, আপনার টার্মিনালে `pytest` কমান্ডটি রান করুন, আর `<exercise_test.py>`-এর জায়গায় টেস্ট ফাইলের নামটি বসান:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### কমন অপশন
- `-o` : ডিফল্ট `pytest.ini` ওভাররাইড করে (_এটি ব্যবহার করে মার্কার ওয়ার্নিং এড়ানো যায়_)
- `-v` : ভারবোস আউটপুট চালু করে।
- `-x` : প্রথম ব্যর্থতাতেই টেস্ট রান করা বন্ধ করে দেয়।
- `--ff` : অন্য টেস্ট কেস রান করার আগে আগের টেস্টের ব্যর্থতাগুলো রান করে।

আরও অপশনের জন্য `python3 -m pytest -h` অথবা `py -m pytest -h` ব্যবহার করুন।


### ওয়ার্নিং ঠিক করা

`pytest` চালানোর সময় `pytest -o markers=task` ব্যবহার না করলে, আমাদের নতুন সিনট্যাক্স ব্যবহার করা টেস্টগুলোর জন্য `PytestUnknownMarkWarning` পেতে পারেন:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

প্রতিবার টেস্ট রান করার সময় `pytest -o markers=task` টাইপ করা এড়াতে, আপনি একটি `pytest.ini` কনফিগারেশন ফাইল ব্যবহার করতে পারেন।
আমরা একটি ফাইল বানিয়ে রেখেছি, যা Python ট্র্যাক ডিরেক্টরির টপ লেভেল থেকে ডাউনলোড করা যায়: [pytest.ini][pytest.ini]।

আপনি নিচের বিষয়বস্তু দিয়ে নিজের একটি `pytest.ini` ফাইলও তৈরি করতে পারেন:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

আপনার Python ট্র্যাকের অনুশীলনীগুলোর _root_ বা _working_ ডিরেক্টরিতে `pytest.ini` ফাইলটি রাখলে মার্কগুলো রেজিস্টার হবে এবং ওয়ার্নিংগুলো বন্ধ হয়ে যাবে।
pytest মার্ক সম্পর্কে আরও তথ্য `pytest` ডকুমেন্টেশনে [টেস্ট ফাংশন মার্ক করা][pytest: marking test functions with attributes] এবং [কাস্টম মার্কার নিয়ে কাজ করা][pytest: working with custom markers] অংশে পাবেন।

pytest কনফিগারেশন কাস্টমাইজ করার তথ্য `pytest` ডকুমেন্টেশনে [কনফিগারেশন ফাইলের ফরম্যাট][pytest: configuration file formats] অংশে পাবেন।
