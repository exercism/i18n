# ভূমিকা

## ইটারেটর

Gleam-এ একটি `Iterator` অ্যারের মতোই ক্রমবদ্ধ মানের সংগ্রহ, যেখানে সব মান একই টাইপের। এটি অ্যারের থেকে আলাদা কারণ এটি লেজি, অর্থাৎ এটি তার সব মান একবারে মেমরিতে সংরক্ষণ করে না, বরং প্রয়োজন অনুযায়ী সেগুলো গণনা করে।

এটি খুব বড় বা এমনকি অসীম আকারের সিকোয়েন্স নিয়ে কাজ করার সময় দরকারি, কারণ যখন তাদের সবগুলো একবারে সংরক্ষণ করার জন্য যথেষ্ট ফ্রি মেমরি থাকে না, তখন এটি আমাদের সেগুলো নিয়ে কাজ করার সুযোগ দেয়।

`gleam/iterator` মডিউলটি `Iterator` টাইপ এবং ইটারেটর নিয়ে কাজ করার ফাংশনগুলো ডিফাইন করে।

অ্যারের জন্য ব্যবহৃত অনেক ফাংশন ইটারেটরেও আছে, যেমন `map`, `filter`, এবং `take`. এই ফাংশনগুলো ইটারেটর রিটার্ন করে, তাই ইটারেটরটি কনজিউম করা না হওয়া পর্যন্ত ফাংশনগুলো আসলে কোনো কাজ করে না।

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` ফাংশনটি ব্যবহার করে এমন একটি ফাংশন থেকে ইটারেটর তৈরি করা যায়, যেটি সিকোয়েন্সের পরবর্তী মান তৈরি করতে বারবার কল করা হয়।

এখানে `unfold` ফাংশনটি দিয়ে এমন একটি ইটারেটর তৈরি করা হয়েছে, যেটি ফিবোনাচি সিকোয়েন্স তৈরি করে:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

এখানে সিকোয়েন্সটি অসীম, তাই মানগুলো একটি অ্যারেতে সংগ্রহ করার আগে এটিকে সসীম করতে `take` ফাংশনটি ব্যবহার করা হয়েছে। একটি অসীম ইটারেটরের ওপর `to_list` কল করা হলে, প্রোগ্রামটি মেমরি শেষ হয়ে ক্র্যাশ করা পর্যন্ত চলতে থাকবে।
