# ইঙ্গিত

## সাধারণ

- [`Map` API ডকুমেন্টেশন][map-docs]-এ `Map` ইন্টারফেসে থাকা মেথডগুলোর একটি তালিকা আছে।

## 1. কোডগুলো একটি ম্যাপে রিটার্ন করুন

- ক্লাসের মেথডগুলোতে ব্যবহার করতে পারার [এমন একটি উপায়ে][declaring-members] আপনাকে একটি `Map` ডিফাইন করতে হবে।

## 2. ডিকশনারিতে এন্ট্রি যোগ করুন

- একটি কী (key)-এর মান যোগ ও আপডেট করার জন্য ম্যাপে একটি [মেথড][map-put-docs] আছে।

## 3. একটি ডায়ালিং কোডের দেশ খুঁজুন

- কী (key)-এর মান পাওয়ার জন্য ম্যাপে একটি [মেথড][map-get-docs] আছে।

## 4. ডুপ্লিকেট অনুমতি দেবেন না

- ম্যাপে একটি [কী (key)][map-contains-key-docs] বা একটি [মান][map-contains-value-docs] আছে কি না, তা যাচাই করার একটি উপায় আছে।

## 5. একটি দেশের ডায়ালিং কোড খুঁজুন

- ম্যাপের এন্ট্রিগুলোর একটি ইটারেবল কালেকশন পাওয়ার [একটি উপায়][map-entry-set-docs] আছে, যা দিয়ে কী (key)-ভ্যালু জোড়াগুলো একে একে দেখা যায়।

## 6. দেশের ডায়ালিং কোড আপডেট করুন

- ভুলে যাবেন না যে দেশের আগের ডায়ালিং কোডটি ম্যাপে থাকবে।
- ম্যাপ থেকে একটি এন্ট্রি মুছে ফেলার জন্য একটি [মেথড][map-remove-docs] আছে।
