# ভূমিকা

অন্যান্য অনেক ভাষার বিপরীতে, JavaScript-এ এমন দুটি ভিন্ন সত্তা আছে যেগুলো একটি (অর্থবহ) মানের অনুপস্থিতিকে প্রকাশ করে। এগুলো হলো `null` এবং `undefined`.

## Null

প্রিমিটিভ মান `null` যেকোনো টাইপের ভ্যারিয়েবলের জন্য সচেতনভাবে একটি "খালি মান" হিসেবে ব্যবহৃত হয়।

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

আপনি [স্ট্রিক্ট ইকুয়ালিটি অপারেটর][mdn-strict-equality] `===` ব্যবহার করে দেখতে পারেন কোনো ভ্যারিয়েবল null কি না।

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> যে ভ্যারিয়েবলে কোনো মান অ্যাসাইন করা হয়নি, তার টাইপ `undefined`.<sup>1</sup>

এর মানে হলো, `null` একটি খালি মানকে বোঝায় (তবুও তা একটি মান), কিন্তু `undefined` বোঝায় একটি মানের সম্পূর্ণ অনুপস্থিতি। 🤯

`undefined` বিভিন্ন প্রসঙ্গে দেখা যায়।

- যদি কোনো ভ্যারিয়েবল কোনো মান ছাড়া ডিক্লেয়ার করা হয় (ইনিশিয়ালাইজেশন), তবে তা `undefined`.
- কোনো অবজেক্টে না-থাকা কী (key)-এর মান অ্যাক্সেস করার চেষ্টা করলে আপনি `undefined` পান।
- যদি কোনো ফাংশন কোনো মান রিটার্ন না করে, তবে ফলাফল `undefined`.
- যদি কোনো ফাংশনে কোনো আর্গুমেন্ট পাস করা না হয়, তবে তা `undefined`, যদি না ওই আর্গুমেন্টের একটি ডিফল্ট মান থাকে।

```javascript
let name;
console.log(name);
// => undefined
```

আপনি স্ট্রিক্ট ইকুয়ালিটি অপারেটর `===` ব্যবহার করে দেখতে পারেন কোনো ভ্যারিয়েবল undefined কি না।

```javascript
let name;

name === undefined;
// => true
```

## অপশনাল চেইনিং

আপনি যদি কোনো অবজেক্টে নেস্টেড কোনো মান বের করার চেষ্টা করেন কিন্তু প্যারেন্ট কী (key)-টির অস্তিত্ব না থাকে, তবে JavaScript একটি এরর থ্রো করে।
এটি সহজে এড়ানোর জন্য ২০২০ সালে ভাষার স্পেসিফিকেশনে অপশনাল চেইনিং যোগ করা হয়।
অপশনাল চেইনিং অপারেটর `?.` দিয়ে আপনি নিশ্চিত করতে পারেন যে JavaScript কেবল তখনই নেস্টেড কী (key) অ্যাক্সেস করার চেষ্টা করবে, যখন প্যারেন্টটি `null` বা `undefined` ছিল না।
অন্যথায় `undefined` রিটার্ন করা হয়।

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## নালিশ কোয়ালেসিং

এমন পরিস্থিতি আছে, যেখানে আপনি চান কোনো ভ্যারিয়েবল null বা undefined হলে একটি ডিফল্ট মান প্রয়োগ করতে (কিন্তু কেবল তখনই)।
এটি মোকাবিলার জন্য ২০২০ সালে নালিশ কোয়ালেসিং অপারেটর `??` চালু করা হয়।
এটি ডান দিকের অপারেন্ড রিটার্ন করে কেবল তখনই, যখন বাম দিকের অপারেন্ডটি `null` বা `undefined` হয়।
অন্যথায় বাম দিকের অপারেন্ড রিটার্ন করা হয়।

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
