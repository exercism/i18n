# পরিচিতি

JavaScript-এ _টেমপ্লেট স্ট্রিং_ দিয়ে স্ট্রিংয়ের ভেতরে এক্সপ্রেশন যুক্ত করা যায়, যাকে স্ট্রিং ইন্টারপোলেশনও বলা হয়। এই সুবিধাটি বিল্ট-ইন [`String`][string-reference] গ্লোবাল অবজেক্টের কার্যকারিতা বাড়িয়ে দেয়।

JavaScript-এ টেক্সট ব্যাকটিকের ভেতরে রেখে আপনি টেমপ্লেট স্ট্রিং তৈরি করতে পারেন। এগুলো শুধু টেক্সটে নতুন লাইন আর অন্যান্য বিশেষ ক্যারেক্টার রাখতেই দেয় না, বরং এর ভেতরে আপনি ভ্যারিয়েবল ও অন্যান্য এক্সপ্রেশনও যুক্ত করতে পারেন।

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

উপরের উদাহরণে টেমপ্লেট স্ট্রিং বোঝাতে ব্যাকটিক (<code>\`\`</code>) ব্যবহার করা হয়েছে। `${...}` হলো সেই প্লেসহোল্ডার, যা দিয়ে প্রতিস্থাপন করা হয়।
স্ট্রিং নয় এমন সব ডেটা টাইপ _নিজে থেকেই_ স্ট্রিংয়ে রূপান্তরিত হয়।
এই বিষয়টি [টাইপ কনভার্সন][type-conversion-concept] কনসেপ্টে আলোচনা করা হয়েছে।
সব ধরনের এক্সপ্রেশনই টেমপ্লেট স্ট্রিংয়ের সাথে ব্যবহার করা যায়।

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

আপনি যখন স্ট্রিং একাধিক লাইনে সাজাতে চান:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

টেমপ্লেট স্ট্রিং ব্যবহার না করে (অর্থাৎ ব্যাকটিক ব্যবহার না করে) সাধারণ স্ট্রিংয়ের ভেতরে নতুন লাইন বোঝাতে চাইলে আপনি নিউলাইন এস্কেপ সিকোয়েন্স `\n` ব্যবহার করতে পারেন:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

প্রতিস্থাপনের যে সুবিধাগুলো আছে, তা দিয়ে আপনি এই প্রক্রিয়ায় লজিকও যুক্ত করতে পারেন, যাতে নির্ধারণ করা যায় আউটপুট স্ট্রিংটি কী হবে।
এই লজিক সামলানোর একটি উপায় হতে পারে [টারনারি অপারেটর][ternary-operator] ব্যবহার করা।
এটি একটু ভিন্ন ফরম্যাটে একই `if/else` শর্তাধীন কার্যকারিতা দেয়।

টেমপ্লেট স্ট্রিং সিনট্যাক্সে লজিক বসাতে:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
