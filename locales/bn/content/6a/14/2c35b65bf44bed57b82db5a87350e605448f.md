# ম্যাচ বেসিকস

`match` অপারেটর একটি মানকে একের পর এক প্যাটার্নের সাথে তুলনা করে, তারপর কোন প্যাটার্নটি মিলেছে তার ওপর ভিত্তি করে কোড চালায়।

## লিটারেল মেলানো

একেবারে মূল স্তরে, `match` একটি মানকে কয়েকটি সম্ভাব্য মেলের সাথে তুলনা করে এবং যে আর্মটি প্রথমে মেলে, সেটিই বেছে নেয়। কেবল একটি আর্মই বেছে নেওয়া হয়, আর কন্ট্রোল কখনোই অন্য কোনো আর্মে "প্রবাহিত" হয় না। `match` একটি এক্সপ্রেশন, যা একটি মান দিতে পারে।

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## সম্পূর্ণতা

ম্যাচিং সবসময় সম্পূর্ণ হতে হয়: কোনো মান যদি ফাঁক দিয়ে গলে বেরিয়ে যেতে পারে, তবে Rust প্রোগ্রামটি কম্পাইল করবে না। এখানে সাহায্যের জন্য `_` একটি ওয়াইল্ডকার্ড, যা যেকোনো কিছু মেলে।

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## কন্ট্রোল ফ্লো হিসেবে ম্যাচিং

`match` যেমন একটি মান তৈরি করার জন্য এক্সপ্রেশন হিসেবে ব্যবহার করা যায়, তেমনি শুধু কন্ট্রোল ফ্লোর কাজেও স্টেটমেন্ট হিসেবে ব্যবহার করা যায়।

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## রেঞ্জ মেলানো

ম্যাচ আর্মগুলোকে একক মান হিসেবেই উল্লেখ করতে হয় না; সেগুলো রেঞ্জও হতে পারে।

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## অর প্যাটার্ন

একটি ম্যাচ আর্ম `|` টোকেনকে বিভাজক হিসেবে ব্যবহার করে কয়েকটি সম্ভাব্য অপশনের যেকোনো একটির সাথে মিলতে পারে।

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## স্ট্রাকচারাল ম্যাচিং ও বাইন্ডিং

ম্যাচিং এমন একটি বাইন্ডিং তৈরি করতে পারে, যা নির্দিষ্ট একটি ম্যাচ আর্মের ভেতরে বৈধ থাকে। যে enum-এর ভ্যারিয়েন্টগুলো নিজের ভেতরে ডেটা বহন করে, সেগুলো আনপ্যাক করার জন্য এটি বিশেষভাবে কাজে লাগে।

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

এই বিষয়ে আরও জানতে `match-advanced` কনসেপ্টটি দেখুন।
