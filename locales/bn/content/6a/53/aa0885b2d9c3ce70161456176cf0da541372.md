# সমান্তরাল অক্ষর কম্পাঙ্কের ধারণাগুলো

এই অনুশীলনীতে বাইরের ক্রেটের সহায়তায় নানা রকম সম্ভাব্য সমাধান রয়েছে। কাজের পরিমাণ সহনীয় রাখতে এই ডকুমেন্টে সম্ভাব্য সমাধানগুলোর একটি ছোট নির্বাচন সাজানো হয়েছে। Crossbeam-এর সমাধানেও এখানে তালিকাভুক্ত ধারণাগুলোর মতোই একটি সেট থাকে, আর Rayon-এর জন্য এর একটি উপসেটই যথেষ্ট।

## সাধারণ

- স্ট্রিং: বিশেষত এখানে `str` সব সময়ই একটি বিবেচ্য বিষয়
- Unicode: ASCII বনাম Unicode মেথডের পারফরম্যান্স/ফিচারের ছাড়। বেঞ্চমার্কে Unicode মেথড ব্যবহার হলে আর সমাধানে ASCII মেথড ব্যবহার হলে বেঞ্চমার্কিং বিকৃত হয়ে যায়।
- ইটারেটর: ইনপুট বা এর খণ্ডগুলোতে ইটারেশন করা।
- কালেকশন: একটি `HashMap`-এর উপর ইটারেশন করা এবং `Entry` ব্যবহার করা। সাধারণত হ্যান্ডেলগুলো `Vec`-এ সংগ্রহ করা হয়।
- রেফারেন্স
- সংখ্যা: বিশেষত `Add` ট্রেইট
- For লুপ: `move`-এর কারণে একটি ইটারেটরে থ্রেড জয়েন করা যায় না।
- **ঐচ্ছিক** ভিজিবিলিটি: ইমপ্লিমেন্টেশনের খুঁটিনাটি পাবলিক না রাখা
- **ঐচ্ছিক** স্লাইস: ওয়ার্কার থ্রেডের জন্য ইনপুট ভাগ করতে `.chunks()` প্রায়ই ব্যবহৃত একটি মেথড। বিকল্প হিসেবে সাবস্লাইস ব্যবহার করা হয়।
- **ঐচ্ছিক** হায়ার-অর্ডার ফাংশন: একটি ইটারেটরসহ হায়ার-অর্ডার ফাংশন দিয়ে HashMapগুলো একত্র করা যায়।
- **ঐচ্ছিক** টাইপ: ইনপুট ভাগ করার জন্য রাউন্ডিং প্রয়োগ করতে আমরা ইন্টিজারকে ফ্লোটিং পয়েন্ট মানে কাস্ট করতে পারি
- **ঐচ্ছিক** ক্রেট

## চ্যানেলসহ বা ছাড়া Std অ্যাপ্রোচ

- প্যারালেলিজম - উপবিষয় স্পনিং/জয়েনিং থ্রেড।
- ইটারেটর - উপবিষয় লেজি-ইভ্যালুয়েটেড: একই ইটারেটর দিয়ে থ্রেড স্পন ও জয়েন করলে প্যারালেলিজম বাধাগ্রস্ত হয়।
- লাইফটাইম - উপবিষয় `'static lifetime` এবং স্পষ্ট `move` সেমান্টিকস
- ইটারেটর/লাইফটাইম - উপবিষয় কনজিউমিং ইটারেটর: ইটারেটর ব্যবহার করে থ্রেড জয়েন করা যায় না।
- Option টাইপ: থ্রেড বা চ্যানেলের ফলাফল আনর‍্যাপ করা
- ফাংশন: বিশেষত থ্রেড স্পনের জন্য হায়ার-অর্ডার ফাংশন দরকার। ক্লোজার এখানে একটি বিকল্প।

## চ্যানেলসহ Std অ্যাপ্রোচ

- প্যারালেলিজম - উপবিষয় চ্যানেল।
- টাপল: `mpsc::channel()` একটি টাপল রিটার্ন করে
- ডিস্ট্রাকচারিং: অ্যাসাইনমেন্টের সময় টাপল ডিস্ট্রাকচার করা যায়
- লাইফটাইম: `drop()`

## শেয়ারড ভ্যারিয়েবলসহ বিকল্প অ্যাপ্রোচ

- রেফারেন্স কাউন্টিং: রেফারেন্স কাউন্টেড কালেকশন দিয়ে থ্রেডের মধ্যে সমষ্টিগত ডেটা শেয়ার করা।
- **বিশেষ উল্লেখ**: প্যারালেলিজম - উপবিষয় Mutex। এই অনুশীলনীর জন্য প্রয়োজনীয়/উপযোগী নয়, তবুও একটি কমন ধারণা। সম্পর্কিত: `RwLock`।

### চ্যানেলসহ Std-এর উদাহরণ

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Arc-সহ ক্রেটের উদাহরণ

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
