# লুপ

Rust-এ লুপ ব্যবহার করে একটি কোড ব্লক বারবার চালানো যায়, যতক্ষণ না আপনি এটিকে থামতে বলেন বা কোনো নির্দিষ্ট শর্ত পূরণ হয়।

লুপের সবচেয়ে সাধারণ রূপে `loop` কিওয়ার্ডটি ব্যবহার করা হয়:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

উপরের কোড স্নিপেটটি একটি অসীম লুপ তৈরি করে। লুপ থেকে বেরিয়ে আসতে break কিওয়ার্ডটি ব্যবহার করুন:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## `for` ও `while` দিয়ে লুপ

`loop` কিওয়ার্ড ছাড়াও আপনি `for` ও `while` দিয়ে লুপ তৈরি করতে পারেন।

একটি `for` লুপ কালেকশন বা ইটারেটরের এলিমেন্টগুলোর উপর দিয়ে ইটারেট করতে ব্যবহার করা হয়।

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

রেঞ্জও ইটারেটর, তাই `for` লুপ দিয়ে সেগুলোর উপর দিয়ে ইটারেট করা খুবই সুবিধাজনক:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

একটি while লুপ কোনো একটি শর্ত পূরণ না হওয়া পর্যন্ত কোড বারবার পুনরাবৃত্তি করতে থাকে। আগের উদাহরণটি আমরা একটি while লুপ ব্যবহার করে এভাবে আবার লিখতে পারি:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```
