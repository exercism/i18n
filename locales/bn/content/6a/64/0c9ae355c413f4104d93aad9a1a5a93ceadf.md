# নির্দেশনা

এই অনুশীলনীতে আপনি রিমোট কন্ট্রোল গাড়ি নিয়ে আরও কিছু কাজ করবেন।

একটি এক্সপেরিমেন্টাল গাড়ি তৈরি করা হয়েছে, আর এখন টেস্ট ট্র্যাকটি প্রোডাকশন ও এক্সপেরিমেন্টাল, দুই ধরনের মডেলই সামলানোর উপযোগী করে বদলাতে হবে। দুই ধরনের গাড়িই তৈরি হয়ে গেছে, এবং টেস্ট ট্র্যাকে দুটোকেই কীভাবে সামলাবেন, তার একটি উপায় আপনাকে খুঁজে বের করতে হবে।

এর সঙ্গে প্রোডাকশন গাড়িগুলোও কিছুটা সফল হতে শুরু করেছে। প্রতিযোগিতার মনোভাব ধরে রাখতে টিমের বস প্রোডাকশন গাড়িগুলোর একটি র‍্যাঙ্কিং প্রকাশ করতে চান।

## 1. একই টেস্ট ট্র্যাকে গাড়ি চালানো সম্ভব করা

`IRemoteControlCar` ইন্টারফেসে একটি মেথড যোগ করুন, যাতে দুই ধরনের গাড়ির `Drive()`-এর ইমপ্লিমেন্টেশন প্রকাশ পায়।

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. টেস্ট ট্র্যাকে ভিন্ন ভিন্ন মডেলের অতিক্রান্ত দূরত্বের তুলনা করা সম্ভব করা

`IRemoteControlCar` ইন্টারফেসে একটি প্রপার্টি যোগ করুন, যাতে দুই ধরনের গাড়ির `DistanceTravelled` প্রপার্টির ইমপ্লিমেন্টেশন প্রকাশ পায়।

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. প্রোডাকশন গাড়িগুলোকে র‍্যাঙ্ক করা সম্ভব করা

`ProductionRemoteControlCar` ক্লাসে `IComparable<T>` ইন্টারফেসটি ইমপ্লিমেন্ট করুন। গাড়িগুলোর ডিফল্ট সাজানোর ক্রম হবে জয়ের সংখ্যার ঊর্ধ্বক্রম।

পাস করা গাড়িগুলোকে জয়ের সংখ্যার ঊর্ধ্বক্রমে সাজিয়ে ফেরত দিতে static `TestTrack.GetRankedCars()` ইমপ্লিমেন্ট করুন।

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
