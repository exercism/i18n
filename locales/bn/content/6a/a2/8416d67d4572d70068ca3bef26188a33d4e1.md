# নির্দেশনার সংযোজন

## ইমপ্লিমেন্টেশন

twobucket প্যাকেজে, নিচের সিগ্নেচারসহ একটি Go ফাংশন Solve ইমপ্লিমেন্ট করুন:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve চারটি মান রিটার্ন করে: লক্ষ্য বাকেটটি ("one" বা "two"), লক্ষ্য পরিমাণে পৌঁছাতে প্রয়োজনীয় মুভ/স্টেপের সংখ্যা, অন্য বাকেটে পড়ে থাকা লিটার, এবং একটি এরর ভ্যালু।
কোনো অবৈধ প্যারামিটারের জন্য, বা কোনো সমাধান সম্ভব না হলে, একটি এরর রিটার্ন করুন।
