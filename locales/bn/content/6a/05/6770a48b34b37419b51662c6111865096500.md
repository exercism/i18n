# NuVoc

[NuVoc][nuvoc-link] হলো J-এর প্রামাণ্য রেফারেন্স। এটি J-এর প্রিমিটিভ ও ভাষার অত্যন্ত সংক্ষিপ্ত কিন্তু তথ্যসমৃদ্ধ একটি ওভারভিউ।

# Rosetta Code

Rosetta Code-এর অনেক টাস্কেই `J` দিয়ে লেখা সমাধান রয়েছে। অধ্যয়ন করার মতো J প্রোগ্রাম খুঁজে পেতে এটি একটি ভালো রিসোর্স। রজার হুই-এর লেখা একটি সুডোকু সমাধানকারী [এখানে](https://rosettacode.org/wiki/Sudoku#J) আছে।
