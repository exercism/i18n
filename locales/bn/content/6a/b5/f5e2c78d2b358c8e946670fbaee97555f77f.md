# পরিচিতি

## রেগুলার এক্সপ্রেশন

Elixir-এ রেগুলার এক্সপ্রেশন **PCRE** স্পেসিফিকেশন (**P**erl **C**ompatible **R**egular **E**xpressions) মেনে চলে, ঠিক যেমন Java, JavaScript বা Ruby-এর মতো অন্যান্য জনপ্রিয় ভাষাগুলো মেনে চলে।

`Regex` মডিউলটি রেগুলার এক্সপ্রেশন নিয়ে কাজ করার জন্য ফাংশন সরবরাহ করে। `String` মডিউলের কিছু ফাংশনও রেগুলার এক্সপ্রেশনকে আর্গুমেন্ট হিসেবে গ্রহণ করে।

~~~~exercism/note
এই অনুশীলনীটি ধরে নেয় যে আপনি ইতিমধ্যেই রেগুলার এক্সপ্রেশনের সিনট্যাক্স জানেন, যার মধ্যে ক্যারেক্টার ক্লাস, কোয়ান্টিফায়ার, গ্রুপ আর ক্যাপচারও পড়ে।

আপনার রেগুলার এক্সপ্রেশন সম্পর্কে জ্ঞান একটু ঝালিয়ে নিতে চাইলে এই সোর্সগুলোর একটিতে চোখ বুলিয়ে দেখুন: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

### সিগিল

রেগুলার এক্সপ্রেশন তৈরি করার সবচেয়ে কমন উপায় হলো `~r` সিগিল ব্যবহার করা।

```elixir
~r/test/
```

মনে রাখবেন, Elixir-এর সব সিগিলই [নানা ধরনের ডেলিমিটার][sigils] সমর্থন করে, শুধু `/` নয়।

### ম্যাচিং

`=~/2` অপারেটরটি দিয়ে এমন একটি রেজেক্স ম্যাচ করা যায়, যেটি `boolean` ফলাফল রিটার্ন করে। বিকল্প হিসেবে `Regex` মডিউল এবং `String` মডিউলেও `match?/2` ফাংশন আছে।

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### ক্যাপচার

শুধু বুলিয়ান চেক দিয়ে কাজ না হলে `Regex.run/3` ফাংশন ব্যবহার করে সব ক্যাপচারের একটি অ্যারে নিতে পারেন (কোনো ম্যাচ না থাকলে `nil`)। ফেরত পাওয়া অ্যারেটির প্রথম এলিমেন্টটি সবসময় পুরো রেগুলার এক্সপ্রেশনের একটি ম্যাচ, আর পরের এলিমেন্টগুলো হলো ম্যাচ হওয়া গ্রুপ।

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### মডিফায়ার

বিশেষ ফ্ল্যাগ যোগ করে রেগুলার এক্সপ্রেশনের আচরণ বদলানো যায়। সিগিল দিয়ে রেগুলার এক্সপ্রেশন তৈরি করলে দ্বিতীয় ডেলিমিটারের পরে মডিফায়ারগুলো যোগ করবেন।

কমন মডিফায়ারগুলো হলো:
- `i` - ম্যাচটিকে কেস-ইনসেনসিটিভ করে তোলে।
- `u` - `\p`-এর মতো ইউনিকোড-ভিত্তিক প্যাটার্ন সক্রিয় করে এবং `\w`, `\s` ইত্যাদি ক্যারেক্টার ক্লাসগুলোকে ইউনিকোডও ম্যাচ করাতে সাহায্য করে।

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
