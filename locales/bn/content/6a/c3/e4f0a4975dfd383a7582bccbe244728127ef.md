# নির্দেশাবলী

কাঁচা টেক্সট বা JSON ব্যবহার করলে API কল করা এররপ্রবণ হতে পারে। এই অনুশীলনীতে আপনি Ballerina রেকর্ড ব্যবহার করে রিকোয়েস্ট পেলোডগুলো গুছিয়ে সাজাবেন এবং বাইরের রিজার্ভেশন এন্ডপয়েন্টগুলোর সাথে সফল যোগাযোগ নিশ্চিত করবেন।

## লক্ষ্য

- প্রদত্ত কোডটি পরিবর্তন করুন।
- Airline রিজার্ভেশন সার্ভিস কল করে ব্যবহারকারীর জন্য একটি বিমান টিকিট রিজার্ভ করুন। উপযুক্ত পেলোডসহ airlineReservationService-এ একটি post রিকোয়েস্ট পাঠান এবং রেসপন্স নিন
- Hotel রিজার্ভেশন সার্ভিস কল করে ব্যবহারকারীর জন্য একটি হোটেল রুম রিজার্ভ করুন। উপযুক্ত পেলোডসহ hotelReservationService-এ একটি post রিকোয়েস্ট পাঠান এবং রেসপন্স নিন
- Car রেন্টাল সার্ভিস কল করে ব্যবহারকারীর জন্য একটি গাড়ি ভাড়া করুন। উপযুক্ত পেলোডসহ carRentalService-এ একটি post রিকোয়েস্ট পাঠান এবং রেসপন্সটি চেক করুন
- সবকিছু সফল হলে, message অ্যাট্রিবিউটে "Congratulations! Your journey is ready!!" সহ একটি বডি রিটার্ন করুন
