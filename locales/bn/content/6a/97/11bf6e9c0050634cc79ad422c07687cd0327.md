# ভূমিকা

রিকার্সন হলো ফাংশনের ভেতরে কোড বারবার চালানোর একটি উপায়, যেখানে ফাংশনটি নিজেই নিজেকে কল করে।
এটি লুপ করার বা ইটারেশন করার আরেকটি উপায়। লুপের মতোই, কখন শেষ করতে হবে তা জানার জন্য ফাংশনটির একটি বুলিয়ান এক্সপ্রেশন যাচাই করা উচিত।
লুপের বিপরীতে, যে রিকার্সন কখনো শেষ হয় না, তা অসীমভাবে চলতে থাকে না।
প্রতিটি ফাংশন কলের মান স্ট্যাকের নিজস্ব ফ্রেমে রাখা যেতে পারে।
ফাংশন কলের পরিমাণ যদি স্ট্যাকের কাছে থাকা জায়গার চেয়ে বেশি জায়গা নিয়ে ফেলে, তাহলে সেটি একটি স্ট্যাক ওভারফ্লো এরর তৈরি করবে।

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

এটি প্রিন্ট করবে

```
The number is 1
The number is 2
After recursion
```

এমন কিছু পরিস্থিতি থাকতে পারে, যেগুলো লুপ দিয়ে প্রকাশ করার চেয়ে রিকার্সন দিয়ে প্রকাশ করলে বেশি পড়ার উপযোগী এবং/অথবা বোঝা সহজ হয়।
