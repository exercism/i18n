# ডিফল্ট প্যারামিটার ভ্যালু

ফাংশনের যেকোনো প্যারামিটারের জন্যই একটি [ডিফল্ট প্যারামিটার ভ্যালু][default-parameter-values] দেওয়া যায়। এর জন্য প্যারামিটার লিস্টে ওই প্যারামিটারের টাইপ অ্যানোটেশনের পরে একটি মান অ্যাসাইন করে দিতে হয়। কোনো ডিফল্ট প্যারামিটার ভ্যালু নির্দিষ্ট করা থাকলে ফাংশনটি কল করার সময় কলার ওই প্যারামিটারটি বাদ দিতে পারেন, আর তার বদলে ডিফল্ট ভ্যালুটি ব্যবহার হয়।

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```
