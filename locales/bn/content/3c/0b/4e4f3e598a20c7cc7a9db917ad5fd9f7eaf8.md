# ভূমিকা

অবজেক্টগুলো _ইনস্ট্যান্স ভ্যারিয়েবল_ সেট করার মাধ্যমে নিজেদের স্টেট ধরে রাখতে পারে, যেগুলো একটি ভ্যারিয়েবল নামের আগে `@` বসিয়ে তৈরি করা হয়।

```ruby
@name = 2
```

অবজেক্টগুলো সাধারণত তাদের প্রাথমিক স্টেট একটি `initialize` মেথডে সেট করে, যেটি একটি ক্লাসে `new` কল করলে স্বয়ংক্রিয়ভাবে কল হয়।

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

`initialize` মেথড আর্গুমেন্টও নিতে পারে, যাতে প্রতিটি ইনস্ট্যান্স কাস্টম স্টেট নিয়ে শুরু করতে পারে:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

বাইরের পড়া ও লেখা থেকে _ইনস্ট্যান্স_ ভ্যারিয়েবলগুলোকে প্রাইভেট হিসেবে বিবেচনা করুন। _ইনস্ট্যান্স_ মেথডগুলো ইনস্ট্যান্স ভ্যারিয়েবল গেট ও সেট করার জন্য ব্যবহার করা উচিত:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
