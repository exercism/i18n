# পরিচিতি

একটি মেথড হলো এমন একটি ফাংশন, যার একটি বিশেষ _রিসিভার_ আর্গুমেন্ট থাকে।
রিসিভারটি নিজের আলাদা আর্গুমেন্ট তালিকায় `func` কিওয়ার্ড আর মেথডের নামের মাঝখানে বসে।

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

আপনি কেবল এমন রিসিভার দিয়ে মেথড ডিফাইন করতে পারেন, যার টাইপ মেথডটির মতো একই প্যাকেজে ডিফাইন করা হয়েছে।

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

স্ট্রাক্টের ওপর থাকা মেথডটি ডট নোটেশন দিয়ে কল করা যায়।

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

লক্ষ্য করুন, `p` নামের `Person` ইনস্ট্যান্সে আমরা `Greetings()` মেথডটি যেভাবে কল করেছি।
অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং ভাষায় আপনি যেভাবে মেথড কল করেন, এটি ঠিক সেরকমই।

মনে রাখবেন: মেথড আসলে রিসিভার আর্গুমেন্টসহ একটি ফাংশন ছাড়া আর কিছু নয়।
মেথড নামের সংঘর্ষ এড়াতে সাহায্য করে। যেহেতু একটি মেথড নির্দিষ্ট একটি রিসিভার টাইপের সঙ্গে যুক্ত থাকে, তাই ভিন্ন ভিন্ন টাইপে একই মেথডের নাম রাখা যায়।

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

রিসিভার দুই ধরনের: ভ্যালু রিসিভার আর পয়েন্টার রিসিভার।

এখন পর্যন্ত আমরা যে মেথডগুলো দেখেছি, সেগুলোর সবই ভ্যালু রিসিভার ব্যবহার করে। এর মানে হলো, মেথডে পাঠানো মানের একটি কপি তারা পায়। ফলে মেথডের ভেতরে রিসিভারে যে পরিবর্তনই করা হোক না কেন, তা কলারের কাছে দৃশ্যমান হয় না।

রিসিভার যে মানের দিকে নির্দেশ করে, সেই মান পরিবর্তন করার জন্য আপনি পয়েন্টার রিসিভার দিয়ে মেথড ডিক্লেয়ার করতে পারেন।
এজন্য টাইপের নামের আগে একটি `*` বসানো হয়।
উদাহরণস্বরূপ, `rect` টাইপের ক্ষেত্রে একটি পয়েন্টার রিসিভার `*rect` হিসেবে ডিক্লেয়ার করা হবে।
এ ধরনের পরিবর্তন মেথডের কলারের কাছেও দৃশ্যমান থাকে।

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
