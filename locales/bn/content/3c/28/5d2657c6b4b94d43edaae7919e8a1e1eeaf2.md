# পরিচিতি

## রিকার্সন

রিকার্সিভ ফাংশন হলো এমন ফাংশন, যা নিজেকে নিজেই কল করে।

একটি রিকার্সিভ ফাংশনে অন্তত একটি _বেস কেস_ আর অন্তত একটি _রিকার্সিভ কেস_ থাকা দরকার।

একটি _বেস কেস_ ফাংশনটিকে আবার কল না করেই একটি মান রিটার্ন করে। আর একটি _রিকার্সিভ কেস_ ফাংশনটিকে আবার কল করে, এবং ইনপুট এমনভাবে বদলে দেয় যাতে একসময় তা বেস কেসের সাথে মিলে যায়।

খুব বেশি সময়েই প্রতিটি কেস আলাদা আলাদা ফাংশন ক্লজে লেখা হয়।

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
