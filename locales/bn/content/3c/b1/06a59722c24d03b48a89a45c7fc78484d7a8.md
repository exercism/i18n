# ভূমিকা

`let` এক্সপ্রেশনটি একটি লোকাল স্কোপ তৈরি করতে ব্যবহৃত হয়, এবং কয়েকটি পরিস্থিতিতে এটি কাজে লাগে:

- এক্সপ্রেশন সরল করার জন্য
- মধ্যবর্তী এক্সপ্রেশনের ফলাফলগুলোর নাম দেওয়ার জন্য
- কোনো এক্সপ্রেশন বড় হয়ে গেলে সেটিকে ছোট ছোট টুকরোয় ভাগ করার জন্য

`let` এক্সপ্রেশনের ভিতরে আপনি বেশিরভাগ কাজই করতে পারেন, যার মধ্যে ডিস্ট্রাকচারিংও রয়েছে (এই বিষয়ে আরও বিস্তারিত পরবর্তী অনুশীলনীগুলোতে), তবে নতুন কাস্টম টাইপ বা টাইপ অ্যালিয়াস ডিফাইন করা সম্ভব নয়।

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
