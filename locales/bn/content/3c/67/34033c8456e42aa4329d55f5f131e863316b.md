String buffer হলো ছোট ছোট এলিমেন্ট পরপর যোগ করে বড় একটি স্ট্রিং তৈরির একটি কার্যকর উপায়। String-এর বিপরীতে, StringBuf-এর একটি ইনস্ট্যান্স ইমিউটেবল নয়, অর্থাৎ এটি ফাংশনের আর্গুমেন্ট হিসেবে পাঠানো যায়, আর সেই ফাংশন আরও মান যোগ করে এটিকে বদলে দিতে পারে।

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
