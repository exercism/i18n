# পরিচিতি

C#-এ কোনো মানের অনুপস্থিতি বোঝাতে `null` লিটারাল ব্যবহার করা হয়। একটি _নালেবল_ টাইপ হলো এমন একটি টাইপ, যা `null` মান গ্রহণ করতে দেয়।

C# 8.0-এর আগে রেফারেন্স টাইপ সবসময়ই নালেবল ছিল, আর ভ্যালু টাইপ ছিল না। তবে ভ্যালু টাইপের পরে একটি প্রশ্নচিহ্ন (`?`) বসিয়ে সেই টাইপকে নালেবল বানানো যায়।

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

যে ভ্যারিয়েবলের মান `null`, তার কোনো মেম্বার অ্যাক্সেস করলে কম্পাইল হতে কোনো সমস্যা হবে না, কিন্তু রানটাইমে একটি `NullReferenceException` ছোড়া হবে:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

এই ধরনের কমন ভুল রুখতে C# 8-এ এমন একটি ফিচার বেছে নেওয়ার সুযোগ দেয়, যা ডিফল্টভাবে রেফারেন্স টাইপকে নন-নালেবল করে দেয়:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

নালেবল মান নিয়ে নিরাপদে কাজ করতে হলে, সেগুলো নিয়ে কাজ করার আগে সেগুলো `null` কি না তা যাচাই করা উচিত:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

মান `null` হলে `??` অপারেটর দিয়ে একটি ডিফল্ট মান রিটার্ন করা যায়:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

সম্ভাব্য `null` মানের উপর `?.` অপারেটর দিয়ে নিরাপদে মেম্বার কল করা যায়:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
