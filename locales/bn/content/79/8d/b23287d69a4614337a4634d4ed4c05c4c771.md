# ইঙ্গিত

## সাধারণ

- হতে পারে আপনি ট্যাগ আর রেকর্ডের তালিকার ওপর ভিত্তি করে একটি DSL বানাতে চান, এভাবে:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- অথবা হয়তো আপনি ফাংশন কলের চেইনের ওপর ভিত্তি করে একটি DSL পছন্দ করবেন, এভাবে:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  নাকি আপনার পরিকল্পনা একেবারেই আলাদা?
  চালিয়ে যান!

- তবে একটি কথা, একটি DSL সাধারণত তখনই বেশি ভালো হয় যখন এটি স্পষ্ট, সংক্ষিপ্ত এবং খুব বেশি অপ্রত্যাশিত নয় (যেমন, `minus` ফাংশনটি বিয়োগ করার জন্য, `node("a") - node("b")`-এর মতো দুটি নোডের মাঝে এজ তৈরির জন্য নয়)।
