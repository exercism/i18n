# পরিচিতি

## Use

`use` ম্যাক্রো আমাদের মডিউলকে অন্য একটি মডিউল থেকে পাওয়া কার্যকারিতা দিয়ে দ্রুত বাড়িয়ে নেওয়ার সুযোগ দেয়। আমরা যখন কোনো মডিউল `use` করি, তখন সেই মডিউল আমাদের মডিউলে কোড ঢুকিয়ে দিতে পারে, উদাহরণস্বরূপ এটি ফাংশন ডিফাইন করতে পারে, অন্য মডিউল `import` বা `alias` করতে পারে, কিংবা মডিউল অ্যাট্রিবিউট সেট করতে পারে।

আপনি যদি এখানে Exercism-এ Elixir-এর কিছু অনুশীলনীর টেস্ট ফাইল কখনো দেখে থাকেন, তাহলে সম্ভবত লক্ষ্য করেছেন যে সেগুলো সবই `use ExUnit.Case` দিয়ে শুরু হয়। কোডের এই এক লাইনই টেস্ট মডিউলে `test` এবং `assert` ম্যাক্রোগুলোকে ব্যবহারযোগ্য করে তোলে।

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

### `__using__/1` ম্যাক্রো

আপনি যখন কোনো মডিউল `use` করেন, তখন ঠিক কী ঘটবে তা নির্ধারণ করে ওই মডিউলের `__using__/1` ম্যাক্রো। এটি একটি আর্গুমেন্ট নেয়, অপশনসহ একটি কিওয়ার্ড লিস্ট, এবং একটি [কোোটেড এক্সপ্রেশন][concept-ast] রিটার্ন করে। `use` কল করার সময় এই কোোটেড এক্সপ্রেশনের কোডটি আমাদের মডিউলে ঢোকানো হয়।

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

`use` কল করার সময় দ্বিতীয় আর্গুমেন্ট হিসেবে অপশনগুলো দেওয়া যায়, যেমন `use ExUnit.Case, async: true`। স্পষ্টভাবে দেওয়া না হলে এগুলোর ডিফল্ট হয় একটি খালি অ্যারে।

## বিহেভিয়ার

বিহেভিয়ার আমাদের একটি _বিহেভিয়ার মডিউলে_ ইন্টারফেস (ফাংশন ও ম্যাক্রোর সেট) ডিফাইন করার সুযোগ দেয়, যা পরে ভিন্ন ভিন্ন _কলব্যাক মডিউল_ ইমপ্লিমেন্ট করতে পারে। শেয়ার করা ইন্টারফেসের সুবাদে, ওই কলব্যাক মডিউলগুলোকে একে অন্যের বদলে ব্যবহার করা যায়।

~~~~exercism/note
লক্ষ্য করুন, "behaviours"-এর বানানটি ব্রিটিশ ইংরেজি অনুযায়ী।
~~~~

### বিহেভিয়ার ডিফাইন করা

একটি বিহেভিয়ার ডিফাইন করতে হলে আমাদের একটি নতুন মডিউল তৈরি করতে হবে এবং কাঙ্ক্ষিত ইন্টারফেসের অংশ এমন ফাংশনের একটি তালিকা উল্লেখ করতে হবে। প্রতিটি ফাংশনকে `@callback` মডিউল অ্যাট্রিবিউট ব্যবহার করে ডিফাইন করতে হবে। এর সিনট্যাক্স একটি [ফাংশন টাইপস্পেক][concept-typespecs] (`@spec`)-এর মতোই। আমাদের একটি ফাংশনের নাম, আর্গুমেন্ট টাইপের একটি তালিকা, এবং সম্ভাব্য সব রিটার্ন টাইপ উল্লেখ করতে হবে।

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer
end
```

### বিহেভিয়ার ইমপ্লিমেন্ট করা

আমাদের মডিউলে একটি বিদ্যমান বিহেভিয়ার যোগ করতে (একটি কলব্যাক মডিউল তৈরি করতে) আমরা `@behaviour` মডিউল অ্যাট্রিবিউট ব্যবহার করি। এর মান হওয়া উচিত যে বিহেভিয়ার মডিউলটি আমরা যোগ করছি তার নাম।

তারপর, ওই বিহেভিয়ার মডিউলটি যে সমস্ত ফাংশন (কলব্যাক) দাবি করে, সেগুলো আমাদের ডিফাইন করতে হবে। আমরা যদি অন্য কারো বিহেভিয়ার ইমপ্লিমেন্ট করি, যেমন Elixir-এর বিল্ট-ইন `Access` বা `GenServer` বিহেভিয়ার, তাহলে [hexdocs.pm][hexdocs]-এর ডকুমেন্টেশনে ওই বিহেভিয়ারের সব কলব্যাকের তালিকা পাব।

একটি কলব্যাক মডিউল কেবল তার বিহেভিয়ারের অংশ এমন ফাংশন ইমপ্লিমেন্ট করার মধ্যেই সীমাবদ্ধ নয়। একই মডিউল একাধিক বিহেভিয়ারও ইমপ্লিমেন্ট করতে পারে।

কোন ফাংশন কোন বিহেভিয়ার থেকে এসেছে তা চিহ্নিত করতে, প্রতিটি ফাংশনের আগে আমাদের `@impl` মডিউল অ্যাট্রিবিউট ব্যবহার করা উচিত। এর মান হওয়া উচিত যে বিহেভিয়ার মডিউলটি এই কলব্যাক ডিফাইন করে তার নাম।

```elixir
defmodule BookCollection do
  @behaviour Countable

  defstruct [:list, :owner]

  @impl Countable
  def count(collection) do
    Enum.count(collection.list)
  end

  def mark_as_read(collection, book) do
    # other function unrelated to the Countable behaviour
  end
end
```

### ডিফল্ট কলব্যাক ইমপ্লিমেন্টেশন

একটি বিহেভিয়ার ডিফাইন করার সময়, একটি কলব্যাকের ডিফল্ট ইমপ্লিমেন্টেশন দেওয়া সম্ভব। এই ইমপ্লিমেন্টেশনটি `__using__/1` ম্যাক্রোর কোোটেড এক্সপ্রেশনে ডিফাইন করা উচিত। বিহেভিয়ার মডিউলের ব্যবহারকারীরা যাতে ডিফল্ট ইমপ্লিমেন্টেশন ওভাররাইড করতে পারেন, সেজন্য ফাংশন ইমপ্লিমেন্টেশনের পরে `defoverridable/1` ম্যাক্রো কল করুন। এটি কী (key) হিসেবে ফাংশনের নাম আর মান হিসেবে ফাংশনের অ্যারিটি নিয়ে একটি কিওয়ার্ড লিস্ট গ্রহণ করে।

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer

  defmacro __using__(_) do
    quote do
      @behaviour Countable
      def count(collection), do: Enum.count(collection)
      defoverridable count: 1
    end
  end
end
```

মনে রাখবেন, ডিফল্ট কলব্যাক ইমপ্লিমেন্টেশন ডিফাইন করা ছাড়া অন্য কোনো উদ্দেশ্যে `__using__/1`-এর ভেতরে ফাংশন ডিফাইন করা নিরুৎসাহিত, তবে আপনি সবসময় অন্য একটি মডিউলে ফাংশন ডিফাইন করে `__using__/1` ম্যাক্রোতে সেগুলো ইমপোর্ট করতে পারেন।
