# নির্দেশনা

এই অনুশীলনীতে আপনি বিভিন্ন ধরনের রিমোট কন্ট্রোলড গাড়ির মধ্যে রেস আয়োজন করবেন। প্রতিটি গাড়ির নিজস্ব বৈশিষ্ট্য আছে এবং টুর্নামেন্টের সিজনজুড়ে রেসে এটি বিভিন্ন ট্র্যাকে চলে।

~~~~exercism/note
এই অনুশীলনীর ফাংশনগুলো প্রদত্ত সিগনেচার-সহ একটি C সোর্স ফাইলে ডিক্লেয়ার করা হয়েছে। আপনার x86-64-assembly কোডকে অবশ্যই ওই স্পেসিফিকেশন মেনে চলতে হবে।
~~~~

## 1. একটি রিমোট কন্ট্রোলড গাড়ি তৈরি করুন

রিমোট কন্ট্রোলড গাড়ি প্রকাশ করতে আপনি একটি struct `car_t` ডিফাইন করেছেন:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

x86-64 assembly-এ `new_car` নামের একটি ফাংশন ডিফাইন করে রিমোট কন্ট্রোলড গাড়ি তৈরি করা সম্ভব করুন। `battery` ফিল্ডটি সবসময় `100.0` মান দিয়ে শুরু হয়।

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. নতুন ট্র্যাক তৈরি করুন

ট্র্যাক বোঝানো হয় একটি struct `track_t` দিয়ে:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t` একটি ট্র্যাকের বিভিন্ন সারফেসের হিসাব রাখে:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

x86-64 assembly-এ `new_track` নামের একটি ফাংশন ডিফাইন করে নতুন ট্র্যাক তৈরি করা সম্ভব করুন।

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. একটি রেসিং ইভেন্ট তৈরি করুন

প্রতিটি রেসে সর্বোচ্চ ৬টি গাড়ি অংশ নেয় এবং একটি ট্র্যাকে নির্দিষ্ট সংখ্যক ল্যাপ চলে। রেস বোঝানো হয় একটি struct `race_t` দিয়ে:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

x86-64 assembly-এ `new_race` নামের একটি ফাংশন ডিফাইন করুন। শুরুর দিকে রেসটির জন্য কোনো নিশ্চিত অংশগ্রহণকারী গাড়ি থাকে না:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. রেসে একটি গাড়ির অংশগ্রহণ নিশ্চিত করুন

কোনো গাড়ির মালিক যখন সেটির একটি রেসে অংশগ্রহণের অনুরোধ করেন, তখন অ্যারেটি আগে থেকেই পূর্ণ না থাকলে তবেই তার অংশগ্রহণ নিশ্চিত হয়।

x86-64 assembly-এ `add_participant` নামের একটি ফাংশন ডিফাইন করুন। রেসে আরও একজন অংশগ্রহণকারীর জায়গা থাকলে গাড়িটি অ্যারেতে যোগ করা হয়, কাউন্টার হালনাগাদ করা হয় এবং তার অংশগ্রহণ নিশ্চিত করা হয়। অন্যথায় রেসের আয়োজকদের গাড়ির মালিককে জানাতে হবে যে এবার সে অংশ নিতে পারবে না।

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. একটি টুর্নামেন্ট তৈরি করুন

সিজনের জন্য নির্ধারিত রেসগুলোর হিসাব আপনি একটি struct `tournament_t` দিয়ে রাখেন:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

টুর্নামেন্টের অ্যারেতে একটি রেস যোগ করতে এবং তার কাউন্টারও হালনাগাদ করতে x86-assembly-এ `add_race` নামের একটি ফাংশন ডিফাইন করুন। আপনি ধরে নিতে পারেন যে নতুন রেসটির জন্য `races` অ্যারেতে সবসময় যথেষ্ট জায়গা থাকবে।

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
