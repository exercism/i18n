# সম্পর্কে

Common Lisp-এ মিথ্যা মান প্রকাশ করা হয় খালি লিস্ট `()` অথবা `nil` সিম্বল দিয়ে।
এই মানগুলো কোট করেও লেখা যায়, কোট না করেও।

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Lisp-এ এর বাইরে বাকি সব মানই সত্য বোঝায়।
এর সঙ্গে আছে বিশেষ কনস্ট্যান্ট সিম্বল `t`, যা সবসময়ই `t`-এর সমান (তাই সবসময়ই ট্রু)।

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
