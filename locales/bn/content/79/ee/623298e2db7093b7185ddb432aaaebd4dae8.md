# নির্দেশনা সংযোজন

## আউটপুট ফরম্যাট

`treeFromTraversals` ফাংশনটি ৩টি প্রপার্টিসহ একটি অবজেক্ট রিটার্ন করবে বলে আশা করা হয়:

- `value`: বর্তমান নোডের মান
- `left`: নোডের বাম চাইল্ড ধারণকারী একটি অবজেক্ট
- `right`: নোডের ডান চাইল্ড ধারণকারী একটি অবজেক্ট

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

ট্রি খালি হলে একটি খালি অবজেক্ট রিটার্ন করা উচিত।
