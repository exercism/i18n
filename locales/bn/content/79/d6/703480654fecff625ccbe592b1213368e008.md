# নির্দেশনা

আবারও স্বাগতম, Agent Double-Null0111।

UMBRA-র বাহিনী আবার মাথা চাড়া দিয়ে উঠেছে, আর তাদের এই সর্বশেষ ষড়যন্ত্র ব্যর্থ করা এখন আপনার দায়িত্ব।
আমাদের গোয়েন্দা বিভাগ জানিয়েছে, ওই মিনিয়নরা গভর্নরের বলের অনুষ্ঠানে একটি দুর্গন্ধ বোমা ফাটানোর পরিকল্পনা করছে।

মিনিয়নরা এতই এলোমেলো যে নিজেদের ল্যাব আর অফিসে প্রায়ই ভুলবশত দুর্গন্ধ বোমাগুলো সক্রিয় করে ফেলে।
আর যেহেতু তারা দুর্গন্ধ বোমা নিষ্ক্রিয় করার নিয়ম বারবার ভুলে যায়, তাই তারা এমন একটি সিস্টেম বানিয়েছে যা বোমার ID নম্বর থেকে কোন তার কোন ক্রমে কাটতে হবে তার নির্দেশনা তৈরি করে।

আপনার কাজ হলো এমন কোড লেখা, যা দিয়ে বলের অনুষ্ঠানের সেই দুর্গন্ধ বোমাটি ফেটে যাওয়ার আগেই নিষ্ক্রিয় করতে পারবেন।

## 1. দুইটি তারের ক্রম উল্টানোর জন্য একটি ক্লোজার লিখুন

প্রতিটি দুর্গন্ধ বোমায় তিনটি ভিন্ন রঙের তার থাকে।
এমন একটি ক্লোজার লিখুন যা একটি `(String, String, String)` টিউপল নেয় এবং প্রথম দুইটি এলিমেন্টের ক্রম উল্টে দিয়ে সেই টিউপল রিটার্ন করে।
এই ক্লোজারটি `flip` নামে অ্যাসাইন করুন।

মনে রাখা জরুরি, টাইপটি অবশ্যই `ChangeClosure` হতে হবে (অথবা একটি সেন্ডেবল টাইপ), টাইপ ডেফিনিশনটি স্টাব ফাইলে দেওয়া আছে।
নাহলে কোডটি কম্পাইল হবে না।

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. তারগুলোর ক্রম ঘোরানোর জন্য একটি ক্লোজার লিখুন

এমন একটি ক্লোজার লিখুন যা একটি `(String, String, String)` টিউপল নেয় এবং তারগুলোর ক্রম বাম দিকে ঘুরিয়ে সেই টিউপল রিটার্ন করে।
এই ক্লোজারটি `rotate` নামে অ্যাসাইন করুন।

মনে রাখা জরুরি, টাইপটি অবশ্যই `ChangeClosure` হতে হবে (অথবা একটি সেন্ডেবল টাইপ), টাইপ ডেফিনিশনটি স্টাব ফাইলে দেওয়া আছে।

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. তার শাফল জেনারেটর ইমপ্লিমেন্ট করুন

দুর্গন্ধ বোমার তারগুলো কোন ক্রমে কাটতে হবে তা বের করার জন্য, আপনাকে এমন একটি ফাংশন ইমপ্লিমেন্ট করতে হবে যা বোমার ID নম্বরের ভিত্তিতে সঠিক শাফলিং ফাংশন তৈরি করে।

ফাংশনটি ইমপ্লিমেন্ট করুন:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

যা ইনপুট হিসেবে দুইটি তার উল্টানোর একটি ক্লোজার আর তিনটি তার ঘোরানোর একটি ক্লোজার নেয় এবং একটি ক্লোজার রিটার্ন করে।
এই রিটার্ন করা ক্লোজারটি দুর্গন্ধ বোমার ID নম্বর আর তিনটি তারের ক্রম নেয়, তারপর তারগুলো কোন ক্রমে কাটতে হবে তা হিসাব করে।
ID নম্বরটি আটটি বিট দিয়ে তৈরি, আর প্রতিটি বিট ঠিক করে তারগুলো উল্টাতে হবে নাকি ঘোরাতে হবে।

ID নম্বরের প্রতিটি বিটের জন্য, একেবারে ডানদিকের বিট থেকে শুরু করে, বিটটি 0 হলে তারের টিউপলে `flipper` ক্লোজারটি প্রয়োগ করবেন আর বিটটি 1 হলে `rotator` ক্লোজারটি প্রয়োগ করবেন, যাতে তারগুলোর নতুন অবস্থা পাওয়া যায়।
ID-র আটটি বিটের জন্য যথাযথ ক্লোজারগুলো প্রয়োগ করার পর, তারগুলোর চূড়ান্ত অবস্থাই হলো সেগুলো যে ক্রমে কাটতে হবে সেই ক্রম।

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
