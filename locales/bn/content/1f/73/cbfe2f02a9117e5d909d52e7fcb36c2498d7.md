# পরিচিতি

`while` আর `until` ([`kernel`][kernel]-এ থাকা) হলো quotation-চালিত লুপ কম্বিনেটর, যা এমন ক্ষেত্রে কাজে লাগে যেখানে আগে থেকে ইটারেশনের সংখ্যা জানা থাকে না:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` ততক্ষণ চলতে থাকে যতক্ষণ `pred` একটি ট্রুথি মান রেখে যায়; `until` ততক্ষণ চলতে থাকে যতক্ষণ `pred` `f` রেখে যায়। এদের প্রেডিকেট উল্টে গেলেই দুটোই থেমে যায় আর রিটার্ন করে।

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

স্ট্যাকের উপরে বয়ে চলা একটি মান দিয়েই যখন যথেষ্ট স্টেট হয় না (ধরুন একই সঙ্গে একটি বাকি থাকা লিস্ট, একটি চলমান যোগফল আর একটি কাউন্টার), তখন সবচেয়ে পরিচ্ছন্ন উপায় হলো স্পষ্টতার জন্য নামযুক্ত *locals* ব্যবহার করা। locals নিয়ে আরও বিস্তারিত আলোচনা পাঠ্যক্রমের পরের দিকে আসবে; এখানে এটুকু জানাই যথেষ্ট যে `:: word ( a b -- c )` ইনপুটগুলোকে নামযুক্ত লোকাল হিসেবে ঘোষণা করে, আর `:> name!` একটি পরিবর্তনযোগ্য লোকাল যোগ করে, যা বডি `value name!` দিয়ে আপডেট করতে পারে।

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
