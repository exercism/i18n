# পরিচিতি

Python-এ একটি মানের অনুপস্থিতি বোঝাতে `None` প্রায়ই ব্যবহার করা হয়, অর্থাৎ একটি `null` (খালি) ভ্যারিয়েবল, অবজেক্ট বা আর্গুমেন্ট ডিফাইন করার প্লেসহোল্ডার হিসেবে।

আপনি যদি অন্য কোনো প্রোগ্রামিং ভাষায় `NULL` বা `nil` টাইপের কথা শুনে থাকেন বা ব্যবহার করে থাকেন, তাহলে Python-এ `None`-এর এই ব্যবহার আপনার কাছে পরিচিত লাগবে।
যেসব ভ্যারিয়েবল বা ফাংশন আর্গুমেন্টের জন্য আপনার কাছে এখনো কোনো মান নেই, সেগুলো ডিক্লেয়ার করতে `None` আপনাকে সাহায্য করে।
পরে প্রয়োজন অনুযায়ী এগুলোতে নির্দিষ্ট মান আবার অ্যাসাইন করা যায়:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

শর্ত যাচাইয়ে ব্যবহার করলে `None` ফলাফল হিসেবে `False` দেয়, তাই কোনো মানের "উপস্থিতি" বা "অনুপস্থিতি" যাচাই করার জন্য এটি দরকারি, মানটি যেটিই হোক না কেন। কোনো ফাংশন বা প্রসেস যখন `error`, `object` বা কোনো বার্তা ফেরত দিতে পারে, তখন এই প্যাটার্নটি প্রায়ই ব্যবহৃত হয়।

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
