# Haskell সিনট্যাক্সের মূল বিষয়গুলো

## কনস্ট্যান্ট ও ফাংশন

Haskell প্রোগ্রাম গঠিত হয় ডেফিনিশন ও এক্সপ্রেশন দিয়ে।

একটি কনস্ট্যান্ট মান `name = expression` দিয়ে ডিফাইন করা হয়।

```haskell
five = 5

six = 3 + 3
```

ফাংশন ডিফাইন করা হয় `name parameters... = expression` দিয়ে, যেখানে প্যারামিটারগুলো শুধু স্পেস দিয়ে আলাদা করা হয়।

```haskell
add number1 number2 = number1 + number2
```

একটি ফাংশন কল করাও একটি এক্সপ্রেশন, এবং সেটি করা হয় ফাংশনের নাম লিখে ও তার প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে, স্পেস দিয়ে আলাদা করে, ঠিক ফাংশন ডেফিনিশনের মতোই।

```haskell
five = add 2 3
```

বন্ধনী দিয়ে একটি এক্সপ্রেশনের ইভ্যালুয়েশনের ক্রম নির্দিষ্ট করা যায়।

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## ইনডেন্টেশন / সিগনিফিক্যান্ট হোয়াইটস্পেস

Haskell কোডের সীমানা নির্দিষ্ট করতে হোয়াইটস্পেস ও ইনডেন্টেশন ব্যবহার করে।
***কোনো এক্সপ্রেশনের অংশ যে কোড, তা ওই এক্সপ্রেশনের শুরুর চেয়ে আরও ভেতরে ইনডেন্ট করা উচিত।***

- মডিউল, ইমপোর্ট ও টপ-লেভেল ফাংশন ডেফিনিশন অবশ্যই একেবারে বাম দিকের কলাম থেকে শুরু হতে হবে।
- কোনো এক্সপ্রেশন যদি একাধিক লাইনে ভাগ করা হয়, তবে ওই এক্সপ্রেশনের অংশ যে কোড, তা ওই এক্সপ্রেশনের নিচে অন্তত একটি স্পেস দিয়ে ইনডেন্ট করতে হবে।
- এক্সপ্রেশনের যে অংশগুলো একসাথে গ্রুপ করা হয়েছে, সেগুলো সমান সংখ্যক স্পেস দিয়ে ইনডেন্ট করা উচিত।

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## মডিউল

মডিউল ফাংশন এক্সপোর্ট করে।
এর মানে হলো, একটি মডিউল তার এক্সপোর্ট স্টেটমেন্টে যে ফাংশনগুলো উপলব্ধ করে, সেগুলো আপনি ব্যবহার করতে পারেন।
একটি মডিউল শুধু অভ্যন্তরীণ ব্যবহারের জন্য ফাংশনও ডিফাইন করতে পারে।
ডিফল্টভাবে, যে ফাংশনগুলো স্পষ্টভাবে এক্সপোর্ট করা হয়নি, সেগুলো মডিউলের বাইরে থেকে ব্যবহার করা যায় না।

একটি মডিউলের শুরুতে আমরা মডিউলের নাম নির্দিষ্ট করি।
আমাদের যদি Calculator.hs নামে একটি ফাইল থাকে, তবে মডিউলের নাম রাখা উচিত Calculator।
এরপর আমরা নির্দিষ্ট করি এটি কোন ফাংশনগুলো এক্সপোর্ট করে, আর তার পরে আমরা ফাংশনগুলো লেখা শুরু করতে পারি।
তাহলে চলুন এটি দিয়ে শুরু করি।

```haskell
module Calculator ( add ) where
```

## কমেন্ট

একটি কমেন্ট হলো Haskell ফাইলের ভেতরের এমন কিছু টেক্সট, যা কোড হিসেবে ইন্টারপ্রেট করা হয় না।
এটি মূলত আপনার নিজের ও অন্য প্রোগ্রামারদের পড়ার জন্য।
এক লাইনের কমেন্টের জন্য হালকা একটি সিনট্যাক্স আছে, যা দুটি ড্যাশের উপর ভিত্তি করে।
`{-` ও `-}` খোলা ও বন্ধ করার ডেলিমিটার জোড়া দিয়ে বহুলাইনের কমেন্টও সম্ভব।

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
