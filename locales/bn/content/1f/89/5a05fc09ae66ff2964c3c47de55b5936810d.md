# রিসোর্স

## আপনার প্রথম Coffee মডিউল তৈরি করা

`Bob = require './bob'` দিয়ে লোড করা যায় এমন একটি মডিউল তৈরি করতে এই কোডটি `bob.coffee`-এ রাখুন:

```coffeescript
class Bob

module.exports = Bob
```

মডিউল সম্পর্কে আরও তথ্য [Node ডকুমেন্টেশন](http://nodejs.org/api/modules.html#modules_module_exports)-এ পাবেন।

## Windows-এ Visual Studio

আপনার যদি Visual Studio-র পেইড ভার্সন থাকে, তাহলে আপনি এমন একটি Visual Studio সল্যুশন ডাউনলোড করতে পারেন যা আগে থেকেই CoffeeScript এবং Visual Studio যে অন্য প্রোগ্রামিং ভাষাগুলো সমর্থন করে সেগুলোর সাথে কাজ করার জন্য সেট করা আছে।

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. পেজে Download Zip বোতামে ক্লিক করে GitHub থেকে [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio) ডাউনলোড করুন।
2. টেমপ্লেটটি আপনার অনুশীলনীর ডিরেক্টরিতে আনজিপ করুন, উদাহরণস্বরূপ `C:\src\exercises`
2. [Exercism CLI](http://exercism.io/cli) ইনস্টল করুন
3. আপনার অনুশীলনীর ডিরেক্টরিতে একটি কমান্ড প্রম্পট খুলুন
4. exercism-এ আপনার API key যোগ করুন `exercism configure --key=YOUR_API_KEY`
5. exercism-এ আপনার সোর্স ডিরেক্টরি কনফিগার করুন `exercism configure --dir=C:\src\exercises`
6. [আপনার প্রথম অনুশীলনী ফেচ করুন](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. Visual Studio-তে Exercism সল্যুশনটি খুলুন
8. Exercism.coffeescript প্রজেক্টটি এক্সপ্যান্ড করুন
9. Solution Explorer-এ **Show All Files**-এ ক্লিক করুন (নিচে দেখুন)
10. আপনি এইমাত্র যে অনুশীলনীটি ফেচ করেছেন সেটি ধূসর হয়ে দেখা যাবে। ফোল্ডারটিতে রাইট ক্লিক করে **Include In Project** নির্বাচন করুন
11. এবার কোডিং শুরু করুন...

![ফাইল যোগ করা](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Visual Studio-তে CoffeeScript নিয়ে কাজ করতে হলে আপনার [Web Essentials](http://vswebessentials.com/) এক্সটেনশনটি ইনস্টল করা উচিত। এটি Javascript নিয়ে কাজ করাও অনেক সহজ করে দেবে।

প্রজেক্টের ব্যাচ ফাইল ব্যবহার করে আপনি node.js কমান্ড লাইন থেকে ইউনিট টেস্ট চালাতে পারেন।

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

টেস্ট চালানোর পর যদি কোনো আউটপুট না দেখেন, তাহলে সম্ভবত আপনি Node.js কমান্ড প্রম্পটে নেই।
