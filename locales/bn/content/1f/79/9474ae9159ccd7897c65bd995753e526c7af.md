# পরিচিতি

SQL-এ `SELECT` স্টেটমেন্ট দিয়ে আপনি ডেটাবেস থেকে ডেটা আনতে পারেন।
একটি `SELECT` স্টেটমেন্টের ফলাফল একটি রেজাল্ট সেট।
রেজাল্ট সেটে মানগুলো সারি ও কলামে সাজানো থাকে।
প্রতিটি কলাম ডেটার একটি নির্দিষ্ট অ্যাট্রিবিউট।
প্রতিটি সারিতে প্রতিটি কলামের জন্য একটি মান থাকে।

এটাকে এভাবে ভাবা যায়: কিছু কলাম মিলে একটি ডেটা স্ট্রাকচার গড়ে তোলে, যেখানে প্রতিটি কলাম ওই ডেটা স্ট্রাকচারের একটি ফিল্ড, আর প্রতিটি সারি ওই ডেটা স্ট্রাকচারের একটি ইনস্ট্যান্স।

`SELECT` স্টেটমেন্টে আপনি বলে দিতে পারেন কোন ডেটা আনতে চান।
চাইলে আউটপুট ডেটার আকার রূপান্তর, ফিল্টার বা পরিবর্তনও করতে পারেন।

## মূল বিষয়গুলো

একটি সাধারণ `SELECT` স্টেটমেন্টের গঠন এমন:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM` ও `WHERE` ক্লজ দুটি ঐচ্ছিক।
যেমন, `SELECT "Hello, world.";`-এর মতো একটি স্টেটমেন্ট পুরোপুরি বৈধ।

এছাড়াও মনে রাখবেন, নতুন লাইনে ভাঙা বাধ্যতামূলক নয়; `SELECT` স্টেটমেন্টের বিভিন্ন ক্লজ (অর্থাৎ অংশ) আলাদা করতে যেকোনো ফাঁকাই যথেষ্ট।
~~~~

`SELECT` কিওয়ার্ডের ঠিক পরেই থাকে সেই কলামগুলোর তালিকা, যেগুলো আপনি ফলাফলে চান।
`FROM` ক্লজ ডেটার উৎস চিহ্নিত করে, যা সাধারণত ডেটাবেসের একটি টেবিল।
`WHERE` ক্লজ এক বা একাধিক শর্ত দিয়ে আউটপুট ডেটা ফিল্টার করে।

## WHERE ক্লজ দিয়ে ডেটা ফিল্টার করা

`WHERE` ক্লজ দিয়ে `SELECT` স্টেটমেন্টে আনা ডেটা ফিল্টার করা যায়।
যেমন, আমরা যদি শুধু Appliances চাই, তাহলে এভাবে লিখতে পারি:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

ফলাফল:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

অথবা আমরা যদি শুধু এমন ডেটা চাই যেখানে weight 2.0 থেকে 6.0-এর মধ্যে:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

ফলাফল:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

`=` আর `BETWEEN...AND` ছাড়াও `WHERE` ক্লজ বহু ধরনের এক্সপ্রেশন সমর্থন করে, যার মধ্যে আছে তুলনা (`<`, `<=`, `>`, `>=`), প্যাটার্ন মেলানো (`LIKE`, `GLOB`, `REGEXP`, `MATCH`) এবং কোনো তালিকায় সদস্যতা যাচাই (`IN`, `NOT IN`)।
সম্পূর্ণ ডকুমেন্টেশনের জন্য দেখুন [SQL Language Expressions](sql-expr)।
