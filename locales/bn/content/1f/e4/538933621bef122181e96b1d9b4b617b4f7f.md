# ভূমিকা

## ডিকশনারি

ডিকশনারি হলো এলিমেন্টের একটি কালেকশন, যেখানে প্রতিটি এলিমেন্টে একটি কী (key) আর একটি মান থাকে; ডিকশনারির কোনো মেথডে একটি কী (key) পাঠালে তার সঙ্গে যুক্ত মানটি ফেরত পাওয়া যায়। অন্য ভাষায় ম্যাপ বা অ্যাসোসিয়েটিভ অ্যারে যে ভূমিকা পালন করে, ডিকশনারি তারই ভূমিকা পালন করে।

ডিকশনারি তৈরি করা যায় এভাবে:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

অথবা

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

খেয়াল করুন, কী (key) আর মানের টাইপও ডিকশনারির সংজ্ঞার অংশ।

একবার তৈরি হয়ে গেলে, ডিকশনারির বিল্ট-ইন মেথড `Add` আর `Remove` ব্যবহার করে এন্ট্রি যোগ করা বা মুছে ফেলা যায়।

কী (key) দিয়ে ডিকশনারিতে ইনডেক্স করে ডিকশনারির মান পড়া বা হালনাগাদ করা হয়:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

ডিকশনারিতে একটি মান আছে কি না, তা এভাবে পরীক্ষা করতে পারেন:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

ডিকশনারির উপর এনুমারেট করলে তার কী (key) ও মানের জোড়াগুলোর উপর এনুমারেট হয়। এছাড়া ডিকশনারিতে এমন প্রপার্টিও থাকে, যা দিয়ে কেবল তার কী (key) বা মানের উপর এনুমারেট করা যায়।
