# নাল

নাল একটি প্রিমিটিভ ভ্যালু টাইপ, যার মান মাত্র একটি: `null`।
নাল প্রায়শই কিছু না থাকা বোঝাতে ব্যবহৃত হয়।
এটিকে "falsey" ধরা হয়, তবে এটি `false` ও অন্য falsey মান থেকে আলাদা।

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## নাল মান নিয়ে কাজ করা

PHP-তে নাল মান এররের একটি কমন কারণ হতে পারে, কারণ এরর অবস্থার জায়গায় বা কিছু না থাকা বোঝাতে প্রায়ই নাল রিটার্ন করা হয়।
এরর এড়াতে প্রায়ই "নাল-চেকিং" করতে হয়, যাতে মানটির উপর কাজ করার আগে সেটি নাল নয় বলে নিশ্চিত হওয়া যায়।

বারবার নাল-চেকিং করলে এরর হওয়ার সম্ভাবনা বেড়ে যায়, তাই PHP নাল মান নিয়ে কাজ করার জন্য দুটি অপারেটর দেয়: নাল-সেফ অ্যাক্সেস `?->` অপারেটর এবং নাল কোয়ালেসিং `??` অপারেটর।
