# নির্দেশনা

ইন্টারনেটে কোড লেখার একটি গুরুত্বপূর্ণ অংশ হলো API কল করা। এই অনুশীলনীতে আপনাকে একটি এন্ডপয়েন্ট থেকে ডেটা এনে তা সফলভাবে আনা হয়েছে কি না নিশ্চিত করতে হবে।

## লক্ষ্যসমূহ

- দেওয়া কোডটি পরিবর্তন করুন।
- HTTP ক্লায়েন্ট ইনভোক করুন এবং একটি কোট আনার চেষ্টা করুন। এই ফলাফলটি `string` ও `error` নিয়ে গঠিত একটি ইউনিয়ন টাইপ হওয়া উচিত।
- কোটটি পাওয়া গেলে তা কনসোলে প্রিন্ট করুন (`io:println()` ব্যবহার করে)।
- কোনো `error` ঘটে থাকলে কনসোলে এরর মেসেজটি প্রিন্ট করুন।
