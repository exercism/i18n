# পার্সেন্ট বা "পুরনো স্টাইল" ফরম্যাটিং

এই সমাধানটি স্ট্রিংয়ের জন্য `%%-formatting` বা [পুরনো স্টাইল ফরম্যাটিং][old-style formatting] ব্যবহার করেছে।

`%%-formatting` সম্পূর্ণ বৈধ একটি পদ্ধতি হলেও এটি উপস্থাপনা বা পাঠযোগ্যতার সমস্যা তৈরি করতে পারে। [str.format()][str.format()] মেথড বা [f-strings][f-strings] (_অন্যভাবে যা "formatted string literals" বা "interpolated strings" নামে পরিচিত_) ব্যবহার করে এমন কিছু অপশন পাওয়া যায়, যা পাঠযোগ্যতা বাড়ায় এবং স্ট্রিংয়ের ভেতরে ভ্যারিয়েবল প্রতিস্থাপনকে আরও স্পষ্ট করে তোলে।

[Python-এ স্ট্রিং ফরম্যাটিং][string formatting in python] ব্লগ পোস্টটি Python-এর সব স্ট্রিং ফরম্যাটিং অপশন বোঝার জন্য একটি ভালো সূচনা বিন্দু, আর [Python-এর নতুন স্ট্রিং ফরম্যাটিং কৌশল][newer python string format techniques]-এও `str.format()` এবং `f-strings` ব্যবহারের জন্য কিছু ভালো টিপস ও ট্রিকস আছে।
