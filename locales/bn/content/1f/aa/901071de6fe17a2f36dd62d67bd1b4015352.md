খেলোয়াড়রা ম্যাপে ঘুরে বেড়াবেন আর পথে গুপ্তধন কুড়িয়ে নেবেন।
বাড়তি চ্যালেঞ্জ যোগ করতে গুপ্তধন ও স্থানের অবস্থান ভিন্নভাবে লেখা হয়েছে।
এছাড়া কিছু বিশেষ স্থানও আছে, যেখানে গেমে বাড়তি মোড় আনতে নির্দিষ্ট কিছু গুপ্তধন অন্য নির্দিষ্ট কিছু গুপ্তধনের সাথে বদল করা যায়।
আপনার কাজ হলো তাদের গেমে সাহায্য করার জন্য ফাংশন লেখা।

## 1. অবস্থান রূপান্তর করুন

`placeLocationToTreasureLocation` ফাংশনটি লিখুন, যেটি একটি Place Location (যেমন `('C', 1)`) নিয়ে সেটিকে একটি Treasure Location-এ (যেমন `(1, 'C')`) রূপান্তর করে।

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. গুপ্তধন ও স্থানের অবস্থান তুলনা করুন

`treasureLocationMatchesPlaceLocation` ফাংশনটি লিখুন, যেটি একটি `PlaceLocation` (যেমন `('C', 1)`) নেয় এবং সেটি একটি `TreasureLocation`-এর (যেমন `(1, 'C')`) সাথে মিললে ট্রু রিটার্ন করে।

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. গুপ্তধনের অবস্থান গণনা করুন

`countPlaceTreasures` ফাংশনটি লিখুন, যেটি একটি Place (যেমন `("Aqua Lagoon (Island of Mystery)", ('F', 1))`) এবং গুপ্তধনের তালিকা নেয়, আর সেখানে যে কতগুলো গুপ্তধন পাওয়া যায় সেই সংখ্যা রিটার্ন করে।

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. বিশেষ স্থান

`specialCaseSwapPossible` ফাংশনটি লিখুন, যেটি একটি Treasure (যেমন `("Amethyst Octopus", (1, 'F'))`) এবং একটি Place (যেমন `("Seaside Cottages ", ('C', 1))`) নেয়, আর নিচের সমন্বয়গুলোর জন্য ট্রু রিটার্ন করে:

- Abandoned Lighthouse-এ Brass Spyglass-এর বদলে যেকোনো অন্য গুপ্তধন নেওয়া যায়
- Stormy Breakwater-এ Amethyst Octopus-এর বদলে Crystal Crab বা Glass Starfish নেওয়া যায়
- Harbor Managers Office-এ Vintage Pirate Hat-এর বদলে Model Ship in Large Bottle বা Antique Glass Fishnet Float নেওয়া যায়

if স্টেটমেন্ট ব্যবহার না করে একটি ad hoc টাপল দিয়ে case স্টেটমেন্ট হিসেবে এই ফাংশনটি লেখার চেষ্টা করুন (এটি Elm-এর একটি কমন আইডিয়ম)।
