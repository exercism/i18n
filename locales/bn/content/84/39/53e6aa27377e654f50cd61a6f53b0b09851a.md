# নির্দেশনা

এই অনুশীলনীতে আপনি হাই স্কুলের প্রেমিক-প্রেমিকাদের সোশ্যাল মিডিয়ায় তাদের ভালোবাসা প্রকাশ করতে সাহায্য করবেন, তাদের আদ্যক্ষর দিয়ে একটি ASCII হার্ট তৈরি করে:

```
❤ J.  +  M. ❤
```

## 1. নাম পরিষ্কার করুন

`HighSchoolSweetheart.clean_up_name` মেথডটি ইমপ্লিমেন্ট করুন।
এটি একটি নাম নেবে এবং সেখান থেকে সব `-` ক্যারেক্টার সরিয়ে সেগুলোর জায়গায় একটি স্পেস বসাবে।
এটি নামের শুরু ও শেষ থেকে হোয়াইটস্পেসও সরিয়ে দেবে।

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. নামের প্রথম অক্ষরটি বের করুন

`HighSchoolSweetheart.first_letter` মেথডটি ইমপ্লিমেন্ট করুন।
এটি একটি নাম নেবে এবং তার প্রথম অক্ষর রিটার্ন করবে।
আগের ধাপে আপনি যে `HighSchoolSweetheart.clean_up_name` ডিফাইন করেছিলেন, সেটি যেন অবশ্যই আবার ব্যবহার করেন।

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. প্রথম অক্ষরটিকে আদ্যক্ষর হিসেবে ফরম্যাট করুন

`HighSchoolSweetheart.initial` মেথডটি ইমপ্লিমেন্ট করুন।
এটি একটি নাম নেবে এবং তার প্রথম অক্ষরটি বড় হাতের অক্ষরে, তারপরে একটি ডট দিয়ে রিটার্ন করবে।
আগের ধাপে আপনি যে `HighSchoolSweetheart.first_letter` ডিফাইন করেছিলেন, সেটি যেন অবশ্যই আবার ব্যবহার করেন।

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. আদ্যক্ষরগুলো হার্টের ভেতরে বসান

`HighSchoolSweetheart.pair` মেথডটি ইমপ্লিমেন্ট করুন।
এটি দুটি নাম নেবে এবং আদ্যক্ষরগুলোর চারপাশে এমোজি হার্ট বসিয়ে সেগুলো রিটার্ন করবে।
আগের ধাপে আপনি যে `HighSchoolSweetheart.initial` ডিফাইন করেছিলেন, সেটি যেন অবশ্যই আবার ব্যবহার করেন।

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
