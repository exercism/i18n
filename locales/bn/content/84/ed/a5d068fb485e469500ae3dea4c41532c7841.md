# নির্দেশনা সংযোজন

## ইনপুট ফরম্যাট

প্রতিটি ডমিনো একটি একক বাইট হিসেবে সংরক্ষিত থাকে, যার বাম অর্ধাংশ থাকে উচ্চ [নিবল][nibble]-এ, আর ডান অর্ধাংশ থাকে নিম্ন [নিবল][nibble]-এ। উদাহরণস্বরূপ, `[2|1]`, `[2|3]` আর `[1|3]` পাথরগুলোকে `0x21 0x23 0x13` বাইট হিসেবে প্রকাশ করা হয়।

## রেজিস্টার

| রেজিস্টার | ব্যবহার   | টাইপ    | বিবরণ                                            |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | ইনপুট     | অ্যাড্রেস | পাথরের বাইটের অ্যারে                             |
| `$a1`    | ইনপুট     | ইন্টিজার | পাথরের সংখ্যা                                    |
| `$v0`    | আউটপুট    | বুলিয়ান | ডমিনো চেইন করা যায় (`0` = `false`, `1` = `true`) |
| `$t0-9`  | টেম্পোরারি | যেকোনো  | সাময়িক স্টোরেজের জন্য ব্যবহৃত                    |


[nibble]: https://en.wikipedia.org/wiki/Nibble
