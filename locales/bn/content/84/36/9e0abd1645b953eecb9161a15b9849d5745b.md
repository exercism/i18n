# মূল বিষয়গুলো

## শুরু করা যাক

### ভ্যারিয়েবল

[ভ্যারিয়েবল][variables] ডিক্লেয়ার করতে `=` অ্যাসাইনমেন্ট অপারেটর ব্যবহার করুন।
Crystal-এ ভ্যারিয়েবলগুলো [snake_case][snake-case] ফরম্যাটে লেখা উচিত।

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### কনস্ট্যান্ট

[কনস্ট্যান্ট][constants] একই `=` অ্যাসাইনমেন্ট অপারেটর দিয়ে ডিক্লেয়ার করা হয়, তবে এগুলো SCREAMING_SNAKE_CASE নামে পরিচিত সব বড় হাতের অক্ষরে লেখা হয়।

```crystal
NUMBER = 1
puts NUMBER # => 1
```

আগে থেকে ডিফাইন করা কোনো কনস্ট্যান্টে মান অ্যাসাইন করলে কম্পাইল-টাইম এরর হবে।

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### টাইপ

Crystal একটি কম্পাইলড ভাষা, অর্থাৎ কম্পাইল টাইমে প্রতিটি ভ্যারিয়েবল বা মেথড আর্গুমেন্টের জন্য একটি টাইপ নির্ধারিত হয়।
কম্পাইলার একটি ভ্যারিয়েবল বা মেথড আর্গুমেন্টের টাইপ অনুমান করতে পারে।
তবে কিছু কিছু ক্ষেত্রে টাইপটি স্পষ্টভাবে উল্লেখ করা প্রয়োজন হয়।
কোন কোন ক্ষেত্রে টাইপ নির্ধারণ করা দরকার, তা পরের কনসেপ্টগুলোতে ব্যাখ্যা করা হবে।

### মেথড

[মেথড][methods] হলো একগুচ্ছ নির্দেশনা একসাথে রেখে পুনরায় ব্যবহার করার একটি উপায়।
Crystal-এ মেথড সাধারণত একটি ক্লাস, মডিউল বা স্ট্রাক্টে ডিফাইন করা হয়।
তবে মেথড ক্লাস, মডিউল বা স্ট্রাকচারের বাইরেও ডিফাইন করা যায়।
মেথড ডিক্লেয়ার করা হয় `def` কিওয়ার্ড দিয়ে, তারপর লেখা হয় মেথডের নাম।
Crystal-এ মেথডের নাম snake_case-এ লেখা উচিত।
মেথডে কোনো আর্গুমেন্ট না থাকলে আপনি বন্ধনী বাদ দিতে পারেন।
মেথডের শেষ বোঝাতে আপনাকে `end` কিওয়ার্ড ব্যবহার করতে হবে।

```crystal
def hello
  puts "Hello World!"
end
```

ভ্যারিয়েবল বা মেথড আর্গুমেন্টের টাইপের জন্য যে মেথড নেই, সেটি ব্যবহার করলে কম্পাইল-টাইম এরর হবে।

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### আর্গুমেন্ট

মেথডে [আর্গুমেন্ট][arguments] থাকতে পারে।
আর্গুমেন্ট হলো এমন ডেটা যা একটি মেথডে পাঠানো হয়।
মেথডকে আর্গুমেন্ট দিতে হলে আপনাকে আর্গুমেন্টের নাম উল্লেখ করতে হবে।
Crystal-এ আর্গুমেন্টের নাম snake_case-এ লেখা উচিত।
একটি মেথডে একাধিক আর্গুমেন্ট থাকতে পারে, তবে আর্গুমেন্টগুলো কমা দিয়ে আলাদা করতে হবে।

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

মেথডে একাধিক আর্গুমেন্টও থাকতে পারে।
সেক্ষেত্রে কমা দিয়ে আর্গুমেন্টগুলো আলাদা করতে হবে।

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### মেথড কল করা

ক্লাস, মডিউল বা স্ট্রাক্টের অন্তর্গত কোনো মেথড কল করার সময় আপনাকে ডট অপারেটর (`.`) ব্যবহার করতে হবে।
ফরম্যাটটি হওয়া উচিত: `<ClassName>.<method_name>`।
কোনো মেথড ক্লাস, মডিউল বা স্ট্রাক্টের অন্তর্গত না হলে আপনি শুধু তার নাম লিখে কল করতে পারেন।
মেথড সবসময় শেষ এক্সপ্রেশনের মান নিহিতভাবে রিটার্ন করে।

মেথডে আর্গুমেন্ট থাকলে মেথড কল ও ডেফিনিশনে আর্গুমেন্ট উল্লেখ করার সময় আপনি বন্ধনী ব্যবহার করতে পারেন, এভাবে: `<method_name>(<argument_1>, <argument_2>, ...)`।
মেথডে আর্গুমেন্ট না থাকলে বন্ধনী বাদ দেওয়া উচিত।

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

একাধিক আর্গুমেন্টসহ কোনো মেথড কল করার সময় কমা দিয়ে আর্গুমেন্টগুলো আলাদা করতে হবে।
আর্গুমেন্টগুলো মেথডের আর্গুমেন্টের ক্রম অনুযায়ীই দিতে হবে।

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

ভুল সংখ্যক আর্গুমেন্ট দিয়ে মেথড কল করলে কম্পাইল-টাইম এরর হবে।

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### যোগ, বিয়োগ ও গুণ

Crystal-এ `+` অপারেটর দিয়ে দুটি সংখ্যা যোগ করা যায়।
আবার `-` অপারেটর দিয়ে দুটি সংখ্যা বিয়োগ করা যায়।
আর `*` অপারেটর দিয়ে দুটি সংখ্যা গুণ করা যায়।

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### কমেন্ট

Crystal-এ [কমেন্ট][comments] লেখা হয় `#` চিহ্ন দিয়ে, তারপর একটি স্পেস, তারপর কমেন্ট।
কমেন্ট দিয়ে কোড ডকুমেন্ট করা হয়।
কম্পাইলার কমেন্ট চালায় না।

```crystal
# This is a comment
```
