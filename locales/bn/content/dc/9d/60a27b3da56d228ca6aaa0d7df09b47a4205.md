# সম্পর্কে

কখনও কখনও একটি ফাংশন অনেকগুলো আর্গুমেন্ট নেয়, আর তখন কোন ক্রমে সেগুলো দিতে হবে তা মনে রাখা কঠিন হয়ে পড়ে। পাঠযোগ্যতার সুবিধার্থে Gleam-এ আর্গুমেন্টের সাথে একটি নামের লেবেল বসানোর সুবিধা রয়েছে।

কোনো আর্গুমেন্টে লেবেল দিতে হলে আর্গুমেন্টের নামের আগে একটি স্পেস দিয়ে লেবেলের নামটি লিখুন।

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

লেবেলযুক্ত আর্গুমেন্ট নেওয়া কোনো ফাংশন কল করার সময় আর্গুমেন্টগুলো যেকোনো ক্রমে দেওয়া যায়। `replace`-এর এই কলগুলো একে অপরের সমতুল্য:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

লেবেল সবসময় ঐচ্ছিক। কোনো ফাংশনে লেবেলযুক্ত আর্গুমেন্ট থাকলেও লেবেল ছাড়াই সেটি কল করা যায়।

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

লেবেলযুক্ত আর্গুমেন্ট নিয়ে কোনো ফাংশন ডিফাইন করার সময় প্রথম লেবেলযুক্ত আর্গুমেন্টের পরের সব আর্গুমেন্টেও লেবেল থাকতে হবে।

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
