# নির্দেশনার সংযোজন

## টেস্টিং

টেস্টগুলো কিছু অপারেশন একই সাথে চালাবে।
Account-এ করা অপারেশনগুলো যেন এটিকে একটি সামঞ্জস্যপূর্ণ অবস্থায় রাখে, তা নিশ্চিত করার চেষ্টা করা উচিত।
উদাহরণস্বরূপ: একাধিক গোরুটিন একই সাথে টাকা জমা ও উত্তোলন করতে পারে; একই সাথে ঘটে যাওয়া দুটি উত্তোলনের ফলে ব্যালেন্স যেন নেগেটিভ হয়ে না যায়।

নিজের কম্পিউটারে কাজ করার সময়, আপনার কোড কনকারেন্সি ঠিকভাবে সামলায় কিনা এবং ডেটা রেস তৈরি করে না কিনা তা টেস্ট করতে, `-race` ফ্ল্যাগ চালু করে টেস্ট রান করুন।

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
