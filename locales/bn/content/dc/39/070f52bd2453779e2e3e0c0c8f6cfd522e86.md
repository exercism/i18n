# পরিচিতি

Go 1.18-এ Go **জেনেরিক**-এর সমর্থন যোগ করেছে।
জেনেরিক ব্যবহার করে আপনি এমন ফাংশন ও ডেটা স্ট্রাকচার লিখতে পারেন যা একই কোড বারবার না লিখেই বিভিন্ন টাইপের সাথে কাজ করে।

## কেন জেনেরিক?

Go-তে ফাংশন ও টাইপ সাধারণত নির্দিষ্ট টাইপ নিয়ে কাজ করে, যেমন `int` বা `string`।
জেনেরিক আসার আগে একাধিক টাইপ সমর্থন করার দুটি উপায় ছিল।
প্রথমটি, আপনি ভিন্ন ভিন্ন নামে একাধিক ফাংশন লিখতে পারতেন, যেমন `SumInts` আর `SumFloats`।
এই পদ্ধতিতে ডুপ্লিকেট কোড তৈরি হয়, যা রক্ষণাবেক্ষণ করা কঠিন।
দ্বিতীয়টি, আপনি খালি ইন্টারফেস `any` (`interface{}`) ব্যবহার করতে পারতেন।
তবে খালি ইন্টারফেস কম্পাইল-টাইম টাইপ চেক সরিয়ে দেয় এবং রানটাইমে টাইপ অ্যাসারশনের প্রয়োজন হয়।
জেনেরিক ডুপ্লিকেট কোড এড়িয়ে টাইপ সেফটি নিশ্চিত করে এই সমস্যার সমাধান করে।

## জেনেরিক ফাংশন

ফাংশনের নামের পরে বর্গাকার বন্ধনী `[...]`-এ **টাইপ প্যারামিটার** যোগ করে আপনি একটি জেনেরিক ফাংশন ডিফাইন করেন।
নিচে একটি জেনেরিক ফাংশনের উদাহরণ দেওয়া হলো, যা উল্টো করা একটি স্লাইস রিটার্ন করে:

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

এই উদাহরণে `T` একটি টাইপ প্যারামিটার।
`T`-কে আপনি একটি আসল টাইপের প্লেসহোল্ডার হিসেবে ভাবতে পারেন।
বর্গাকার বন্ধনীর ভেতরের `any` কিওয়ার্ডটি একটি **টাইপ কনস্ট্রেইন্ট**।
কনস্ট্রেইন্টটি কম্পাইলারকে বলে দেয় `T`-এর জন্য কোন কোন টাইপ অনুমোদিত।
এখানে `any` মানে `T` যেকোনো টাইপ হতে পারে।

### জেনেরিক ফাংশন কল করা

বর্গাকার বন্ধনীতে আসল টাইপ পাস করে আপনি একটি জেনেরিক ফাংশন কল করতে পারেন।
এই আসল টাইপটিকে **টাইপ আর্গুমেন্ট** বলা হয়।

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

বেশিরভাগ ক্ষেত্রে Go কম্পাইলার ফাংশনের আর্গুমেন্ট থেকে টাইপ নিজে থেকেই শনাক্ত করতে পারে।
এই বৈশিষ্ট্যটিকে **টাইপ ইনফারেন্স** বলা হয়।
টাইপ ইনফারেন্স থাকলে বর্গাকার বন্ধনীতে টাইপ আর্গুমেন্ট লিখতে হয় না।

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

এই উদাহরণে কম্পাইলার দেখে যে `words` স্ট্রিংয়ের একটি স্লাইস, তাই এটি অনুমান করে `T` হলো `string`।

## টাইপ কনস্ট্রেইন্ট

প্রতিটি টাইপ প্যারামিটারের একটি কনস্ট্রেইন্ট থাকতেই হবে।
কনস্ট্রেইন্ট নির্ধারণ করে কোন টাইপগুলো আপনি টাইপ আর্গুমেন্ট হিসেবে ব্যবহার করতে পারবেন।
কনস্ট্রেইন্ট এটাও ঠিক করে দেয় যে ওই টাইপের মানের উপর আপনি কোন কোন অপারেশন চালাতে পারবেন।

### `any` কনস্ট্রেইন্ট

`any` কনস্ট্রেইন্ট যেকোনো টাইপকে অনুমতি দেয়।
Go-তে `any` হলো খালি ইন্টারফেস `interface{}`-এর একটি অ্যালিয়াস।
যেহেতু `any` সব টাইপকে অনুমতি দেয়, তাই ফাংশনটি কেবল এমন অপারেশনই চালাতে পারে যা সব Go টাইপে কাজ করে।
উদাহরণস্বরূপ, দুটি `any` মান যদি স্লাইস ধরে রাখে, তবে তাদের `==` দিয়ে তুলনা করা যায় না, কারণ `==` দিয়ে স্লাইস তুলনা করা যায় না।

### `comparable` কনস্ট্রেইন্ট

Go একটি বিল্ট-ইন কনস্ট্রেইন্ট দেয়, যার নাম `comparable`।
`comparable` কনস্ট্রেইন্ট এমন যেকোনো টাইপকে অনুমতি দেয় যা `==` ও `!=` অপারেটর সমর্থন করে।
তুলনাযোগ্য টাইপের মধ্যে আছে বুলিয়ান, সংখ্যা, স্ট্রিং, পয়েন্টার, চ্যানেল, এবং তুলনাযোগ্য টাইপ দিয়ে গড়া স্ট্রাক্ট বা অ্যারে।

নিচে এমন একটি ফাংশনের উদাহরণ, যা পরীক্ষা করে একটি স্লাইসে নির্দিষ্ট কোনো এলিমেন্ট আছে কি না:

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

যেহেতু `T` `comparable` কনস্ট্রেইন্ট ব্যবহার করে, তাই `elem == target` ব্যবহার করা বৈধ।
`comparable`-এর জায়গায় `any` বসালে কম্পাইলার একটি এরর দেখাবে।

### ইন্টারফেস টাইপ সেট দিয়ে কাস্টম কনস্ট্রেইন্ট

Go 1.18 থেকে ইন্টারফেস মেথডের পাশাপাশি টাইপের সেটও ডিফাইন করতে পারে।
ইন্টারফেসে অনুমোদিত টাইপগুলো তালিকাভুক্ত করতে আপনি পাইপ চিহ্ন `|` ব্যবহার করতে পারেন।

```go
type Number interface {
    int | int64 | float64
}
```

এখন আপনি একটি ফাংশনের কনস্ট্রেইন্ট হিসেবে `Number` ব্যবহার করতে পারেন:

```go
func Double[T Number](value T) T {
    return value * 2
}
```

যেহেতু `Number`-এর সব টাইপ `*` অপারেটর সমর্থন করে, তাই Go ফাংশনের ভেতরে `value * 2` ব্যবহারের অনুমতি দেয়।

### আন্ডারলাইং টাইপের অ্যাপ্রক্সিমেশন `~`

কখনও কখনও আপনি একটি প্রিমিটিভ টাইপের উপর ভিত্তি করে কাস্টম টাইপ ডেফিনিশন তৈরি করেন:

```go
type MyInt int
```

উপরে ডিফাইন করা `Number` কনস্ট্রেইন্ট কেবল `int`, `int64` আর `float64` এই নির্দিষ্ট টাইপগুলোই অনুমতি দেয়।
`Double`-এ যদি `MyInt` মান পাস করেন, তবে কম্পাইলার এরর দেয়, কারণ `MyInt` `int`-এর সাথে মেলে না।
যে কোনো টাইপের আন্ডারলাইং টাইপ `int`, এমন সব টাইপকে অনুমতি দিতে টাইপের আগে একটি টিল্ডে `~` যোগ করুন:

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

এখন আপনি `MyInt` টাইপের মানের সাথে `Double` ব্যবহার করতে পারেন।

### `cmp.Ordered` কনস্ট্রেইন্ট

স্ট্যান্ডার্ড লাইব্রেরি [`cmp` প্যাকেজ][doc-cmp]-এ `cmp.Ordered` কনস্ট্রেইন্ট দেয়।
`cmp.Ordered` কনস্ট্রেইন্ট এমন যেকোনো টাইপকে অনুমতি দেয় যা `<`, `<=`, `>` আর `>=` তুলনা অপারেটর সমর্থন করে।

## জেনেরিক টাইপ

টাইপ প্যারামিটার ব্যবহার করে আপনি জেনেরিক টাইপও ডিফাইন করতে পারেন, যেমন স্ট্রাক্ট।
নিচে একটি জেনেরিক `Stack` ডেটা স্ট্রাকচারের উদাহরণ:

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

জেনেরিক টাইপের একটি ভ্যারিয়েবল ডিক্লেয়ার করার সময় বর্গাকার বন্ধনীতে টাইপ আর্গুমেন্ট দিতে হবে:

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

টাইপ ইনফারেন্স কেবল জেনেরিক ফাংশনের ক্ষেত্রেই কাজ করে।
জেনেরিক টাইপের মান তৈরি করার সময় সবসময় টাইপ আর্গুমেন্ট উল্লেখ করতে হবে।

## কখন জেনেরিক ব্যবহার করবেন

জেনেরিক একটি শক্তিশালী ফিচার, তবে প্রতিটি সমস্যায় এটি ব্যবহার করার দরকার নেই।

এই ধরনের পরিস্থিতিতে জেনেরিক ব্যবহার করুন:
- আপনি এমন ডেটা স্ট্রাকচার তৈরি করছেন, যেমন ট্রি, লিংকড লিস্ট বা ক্যাশে, যা যেকোনো এলিমেন্ট টাইপের সাথে কাজ করে।
- আপনি এমন ইউটিলিটি ফাংশন লিখছেন যা যেকোনো টাইপের স্লাইস বা ম্যাপের উপর কাজ করে, যেমন ফিল্টারিং, সর্টিং বা সার্চিং।
- একাধিক টাইপের জন্য আপনার হুবহু একই ইমপ্লিমেন্টেশন দরকার, আর আপনি কম্পাইল-টাইম টাইপ সেফটিও চান।

এই ধরনের পরিস্থিতিতে বরং ইন্টারফেস ব্যবহার করুন:
- আপনি আন্ডারলাইং ডেটা টাইপের চেয়ে আচরণ ও মেথডকে বেশি গুরুত্ব দেন।
  উদাহরণস্বরূপ, বিভিন্ন ধরনের সোর্স (ফাইল, নেটওয়ার্ক, TTY) থেকে ডেটা পড়ে প্রসেস করতে চাইলে `func Process[T](src T)`-এর বদলে `func Process(src io.Reader)` ব্যবহার করবেন।
- ভিন্ন ভিন্ন টাইপের নিজেদের কাজ সম্পন্ন করতে ভিন্ন ভিন্ন মেথড ইমপ্লিমেন্টেশন দরকার হয়।
