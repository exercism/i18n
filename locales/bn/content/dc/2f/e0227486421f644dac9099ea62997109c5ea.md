# পরিচিতি

JSON-এ **অ্যারে** বলতে বোঝায়:

> অ্যারে হলো মানের একটি সাজানো সংগ্রহ।
> অ্যারে শুরু হয় `[` বাম বন্ধনী দিয়ে, আর শেষ হয় `]` ডান বন্ধনী দিয়ে।
> মানগুলোকে আলাদা করা হয় `,` কমা দিয়ে।

অ্যারেতে শূন্য বা তার বেশি _যেকোনো ধরনের_ JSON মান থাকতে পারে।
অ্যারের এলিমেন্টগুলোর সবগুলো একই টাইপের হওয়া জরুরি নয়।

## অ্যারে তৈরি করা

এলিমেন্টগুলোকে একটি অ্যারেতে জড়ো করতে বন্ধনী ব্যবহার করুন।

```jq
[1, 2, 3]
```

বন্ধনীর মধ্যে ঘিরে একটি _স্ট্রিম_-এর এলিমেন্টগুলো একটি অ্যারেতে ধরে রাখা যায়।

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## আকার

`length` ফাংশনটি একটি অ্যারের এলিমেন্ট সংখ্যা রিটার্ন করে।

## ইনডেক্সিং ও স্লাইসিং

অ্যারের ইনডেক্সিং শূন্য-ভিত্তিক।

বন্ধনী এক্সপ্রেশন দিয়ে অ্যারে থেকে একটি এলিমেন্ট বের করা যায়:
`.[2]` তৃতীয় এলিমেন্টটি দেয়।

ঋণাত্মক ইনডেক্স অ্যারের শেষ থেকে পিছনে গোনে:
`.[-1]` শেষ এলিমেন্টটি দেয়; `.[-2]` হলো শেষের আগেরটি।

**স্লাইস** হলো অ্যারের একটি উপ-ক্রম।
`.[10:15]` ইনডেক্স 10 থেকে শুরু করে ৫টি এলিমেন্ট রিটার্ন করে; শেষ ইনডেক্সটি _ধরা হয় না_।

সুবিধার জন্য কিছু ফাংশনও আছে:

- `first` প্রথম এলিমেন্টটি দেয়।
- `last` শেষ এলিমেন্টটি দেয়।
- `nth(n)` ইনডেক্স `n`-এর এলিমেন্টটি দেয়।

## ইটারেশন

`jq` কমন ইটারেশনের কাজ সামলানোর জন্য অনেক ফাংশন দেয়:

- `map(expr)` একটি নতুন অ্যারে রিটার্ন করে, যেখানে `expr` পালাক্রমে প্রতিটি এলিমেন্টে প্রয়োগ করা হয়।

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` হলো এমন একটি ফাংশন, যা `expr`-কে _একটি একক মান_-এর উপর প্রয়োগ করে।
  এক্সপ্রেশনের ফলাফল যদি ট্রু হয়, তাহলে মানটি রিটার্ন করা হয়;
  আর ফলাফল যদি ফলস হয়, তাহলে _কিছুই_ রিটার্ন হয় না, `null` নয়, সত্যিই কিছুই না।

  অ্যারের ক্ষেত্রে এটি প্রয়োগ করতে চাইলে `map`-এর সাথে মিলিয়ে ব্যবহার করুন।

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  অথবা `select`-কে একটি _স্ট্রিম_-এর উপর প্রয়োগ করে ফলাফলগুলো জড়ো করুন।

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` এবং `all(condition)` একটি বুলিয়ান মান রিটার্ন করে, যা বলে দেয় অ্যারের এলিমেন্টগুলোর যেকোনোটি বা সবগুলো শর্তটি পূরণ করে কি না।

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
