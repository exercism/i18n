# ইনস্টলেশন

অন্য অনেক ভাষার থেকে আলাদা, Pyret-কে গ্লোবালি ইনস্টল করার প্রয়োজন হয় না।
বরং Pyret-এর ডেভেলপাররা তাঁদের কম্পাইলার একটি [npm প্যাকেজ][pyret-npm] হিসেবে উপলব্ধ করেছেন।
আপনি প্রতিটি অনুশীলনীর জন্য `npm` ব্যবহার করে Pyret ইনস্টল করবেন:
আরও বিস্তারিত থাকবে [টেস্টিং][tests] পেজে।

আপনার Node.js ইনস্টল করতে হবে, যেটি একটি JavaScript রানটাইম এনভায়রনমেন্ট।
[Node.js ডাউনলোড][download] পেজে প্যাকেজ ম্যানেজার হিসেবে অবশ্যই `npm` বেছে নিন।

~~~~exercism/note
বর্তমানে pyret-npm প্যাকেজটি কেবল Linux আর MacOS-এর সাথে সামঞ্জস্যপূর্ণ।
Windows ব্যবহারকারীদের WSL অথবা একটি ভার্চুয়াল মেশিন ব্যবহার করে pyret-npm ইনস্টল করতে হবে।
~~~~
