# ভূমিকা

## জেনেরিক টাইপ

একটি কলেকশন ডিফাইন করার সময় সাধারণত অ্যাঙ্গেল ব্র্যাকেটের ভেতরে একটি প্লেসহোল্ডার থাকে, প্রচলন অনুযায়ী যা প্রায়ই `T` হয়। এমন কলেকশনকে জেনেরিক টাইপ বলা হয়। এতে কলেকশন ব্যবহারকারী ঠিক করতে পারেন যে কলেকশনে কোন ধরনের আইটেম রাখা হবে। নিচের উদাহরণ কোডে আমরা স্ট্রিং-এর একটি অ্যারে ইনস্ট্যানশিয়েট করছি।

## অ্যারে

C#-এ অ্যারে হলো প্রিমিটিভ মান অথবা স্ট্রাক্ট বা ক্লাসের ইনস্ট্যান্সের কলেকশন। এগুলো বেস ক্লাস লাইব্রেরিতে `List<T>` হিসেবে ইমপ্লিমেন্ট করা হয়েছে, যেখানে `T` হলো অ্যারের ভেতরের আইটেমের টাইপ। অ্যারে তৈরি ও ম্যানিপুলেট করার জন্য API বিস্তৃত মেথড সরবরাহ করে।

অ্যারেতে আইটেম যোগ করা যায় আবার মুছে ফেলা যায়। প্রয়োজন অনুসারে এগুলো বড় ও ছোট হয়।

```csharp
var listOfStrings = new List<string>();
```
