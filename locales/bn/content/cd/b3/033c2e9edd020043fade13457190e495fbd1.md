# ইঙ্গিত

## সাধারণ

- পয়েন্টারের সিনট্যাক্সের দিকে ভালোভাবে খেয়াল রাখুন।
  আপনি `*` (ডিরেফারেন্স অপারেটর) এবং `->` (পয়েন্টারের মাধ্যমে মেম্বার অ্যাক্সেস) ব্যবহার করবেন।
- যেখানে প্রয়োজন সেখানে নাল পয়েন্টার (`nullptr`) পরীক্ষা করতে ভুলবেন না, যাতে অবৈধ মেমোরিতে অ্যাক্সেস না হয়।
- আপনার কোড অসম্পূর্ণ হলেও আপনি টেস্ট রান করতে পারেন; টেস্টের ফলাফল দেখতে একটা মোটামুটি কাঠামোই যথেষ্ট।
- টেস্টে ব্যবহৃত সব ফাংশন অবশ্যই হেডার ফাইলে ডিক্লেয়ার করা থাকতে হবে।
- আপনার প্রোগ্রাম ক্র্যাশ করলে বা অপ্রত্যাশিতভাবে আচরণ করলে, সেটা প্রায়ই নাল পয়েন্টার ডিরেফারেন্স করার কারণে হয়।
  আপনি `nullptr` ঠিকভাবে হ্যান্ডেল করছেন কি না, আবার ভালোভাবে দেখে নিন।
- পয়েন্টার অ্যারিথমেটিক ব্যবহার করার সময় খেয়াল রাখুন যেন আপনি সেনসর অ্যারের সীমার ভেতরেই থাকেন।
  অ্যারের ধারণক্ষমতার বাইরে চলে গেলে মেমোরি সংক্রান্ত সমস্যা হতে পারে।

## 1. সেনসর সংযোগ পরীক্ষা করুন (`connection_check`)

- কাজটি মূলত একটা পয়েন্টার নাল কি না, সেটা যাচাই করার ব্যাপার।
- একটা পয়েন্টার বৈধ কি না তা দেখতে তুলনা অপারেটর `!=` ব্যবহার করুন।
- আপনি পয়েন্টার ঠিকভাবে পরীক্ষা করছেন কি না নিয়ে নিশ্চিত না হলে, ভাবুন `nullptr` আসলে কী বোঝায় (কোনো বৈধ মেমোরি অ্যাড্রেসের অনুপস্থিতি)।


## 2. সেনসরগুলোর অ্যাক্টিভিটি গণনা করুন (`activity_counter`)

- আপনাকে সেনসরগুলোর অ্যারে নিয়ে ইটারেশন করতে হবে।
  C++-এ একটা অ্যারেকে তার প্রথম এলিমেন্টের পয়েন্টার হিসেবে ধরা যায়।
- `i` ইনডেক্সে থাকা সেনসরে অ্যাক্সেস করতে পয়েন্টার অ্যারিথমেটিক (`sensor_array + i`) ব্যবহার করুন।
- পয়েন্টারের মাধ্যমে স্ট্রাক্টের কোনো মেম্বারে অ্যাক্সেস করতে `->` অপারেটর ব্যবহার করা হয়।

### উদাহরণ

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. অ্যালার্ম নিয়ন্ত্রণ (`alarm_control`)

- প্রথমে, সেনসরে অ্যাক্সেস করার আগে পয়েন্টারটা নাল কি না দেখে নিন।
- `pillar_men_sensor` স্ট্রাক্টের `activity` মেম্বারে অ্যাক্সেস করতে `->` অপারেটর ব্যবহার করুন।
- সেনসরের অ্যাক্টিভিটি লেভেল `0` হলে কী হওয়া উচিত, সেটা ভালোভাবে ভাবুন।
  অ্যালার্ম কি বেজে ওঠা উচিত?

## 4. `uv_alarm` ফাংশন দিয়ে ডেটায় অস্বাভাবিকতা খোঁজা

- সেনসরের ডেটা অ্যারের একটা পয়েন্টার `uv_light_heuristic` ফাংশনে পাঠাতে `&` অপারেটর ব্যবহার করুন।
- সেনসরের ডেটা অ্যাক্সেস করার আগে নাল পয়েন্টার ঠিকভাবে পরীক্ষা করছেন কি না নিশ্চিত করুন।
- অ্যালার্ম বাজা উচিত কি না তা নির্ধারণ করতে `uv_light_heuristic` ফাংশনের ফলাফলের সাথে সেনসরের `activity` মান তুলনা করুন।
