# Debug

কোনো test ফেল করলে কোন ইনপুটে কী ভুল হয়েছে তা বর্ণনা করে একটি বার্তা দেখানো হয়। "স্ট্যান্ডার্ড আউট"-এ প্রিন্ট করা যেকোনো কিছুও দেখানো হবে, এই বিষয়টিও আপনি কাজে লাগাতে পারেন। `println!` দিয়ে আপনি স্ট্যান্ডার্ড আউটে লিখতে পারেন:

```rust
println!("Debug message");
```

ভ্যারিয়েবল বা এক্সপ্রেশনের মান প্রিন্ট করতে দ্বিতীয় বন্ধনী `{}` ব্যবহার করুন:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

মনে রাখবেন, সব টাইপ এভাবে প্রিন্ট করা যায় না, শুধু সেগুলোই যায় যেগুলো ব্যবহারকারীদের কাছে দ্ব্যর্থহীনভাবে উপস্থাপন করা সম্ভব। যেমন, ভেক্টর (অ্যারে) এভাবে প্রিন্ট করা যায় না, কারণ ব্যবহারকারীদের কাছে একটি ভেক্টর কীভাবে দেখানো উচিত তা স্পষ্ট নয়! এই অন্য টাইপগুলোর ক্ষেত্রে আপনি `println!` ম্যাক্রোকে `{:?}` দিয়ে _debug-formatting_ ব্যবহার করতে বলতে পারেন। এই রূপটি কেবল ডেভেলপারদের দেখার জন্যই বোঝানো হয়েছে। একটি উদাহরণ:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

এমনকি সুবিধাজনক `dbg!` ম্যাক্রোও আছে, যা দিয়ে বড় এক্সপ্রেশনগুলোকে আলাদা আলাদা ভ্যারিয়েবল ডিক্লারেশনে ভেঙে না ফেলেই ইনলাইনে debug করা যায়।

ধরুন আমাদের কাছে নিচের এক্সপ্রেশনটি আছে:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

এখন আমরা দেখতে চাই `collect` কলটি কী রিটার্ন করে। আমরা এভাবে করতে পারতাম:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

কিন্তু এটা তো বড়ই ঝামেলার! শুধু debug করার জন্যই আমাদের সুন্দর এক্সপ্রেশনগুলো নতুন করে লিখতে আমরা চাই না। মঞ্চে স্বাগত জানাই: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

হোয়াইটস্পেসটি শুধু পরিষ্কারভাবে বোঝার জন্য। যেকোনো এক্সপ্রেশন আপনি `dbg!()` দিয়ে মুড়ে দিতে পারেন, যা ওই মানটি (debug-formatting সহ) প্রিন্ট করবে। এরপরও আপনি মানটি আরও বড় একটি এক্সপ্রেশনে ব্যবহার করে যেতে পারবেন, যেন `dbg!` সেখানে ছিলই না।

debugging-এ শুভকামনা!
