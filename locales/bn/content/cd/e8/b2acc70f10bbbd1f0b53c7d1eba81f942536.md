# নির্দেশনা

এই অনুশীলনীতে আপনাকে [Pac-Man][Pac-Man] নামের ১৯৮০-র দশকের ধ্রুপদী আর্কেড গেমের কয়েকটি নিয়ম বাস্তবায়ন করতে হবে।

মোট ছয়টি কাজ আছে, যার মধ্যে চারটি গেমের স্টেট সংক্রান্ত নিয়ম।

> _ফাংশনে আর্গুমেন্টগুলো কোথা থেকে আসছে তা নিয়ে ভাববেন না, শুধু আর্গুমেন্টগুলো একত্র করে কাঙ্ক্ষিত ফলাফল রিটার্ন করার দিকে মনোযোগ দিন।_


## 0. একটি পাওয়ার স্টেট ডিফাইন করুন

পাওয়ারটি সত্যিই চালু আছে বোঝাতে একটি মান দিয়ে `PowerOn` নামের একটি ভ্যারিয়েবল ডিফাইন করুন।

```powershell
> $PowerOn
True
```

## 1. Pac-Man একটি ভূত খায় কি না তা ডিফাইন করুন

`EatGhost` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man ভূতটি খেতে পারলে একটি বুলিয়ান মান রিটার্ন করে।
ফাংশনটি `True` রিটার্ন করবে কেবল তখনই, যখন Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় থাকে এবং সে একটি ভূত স্পর্শ করছে।

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Pac-Man স্কোর করে কি না তা ডিফাইন করুন

`Score` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয় (_Pac-Man একটি পাওয়ার পেলেট স্পর্শ করছে কি না_ এবং _Pac-Man একটি ডট স্পর্শ করছে কি না_) এবং Pac-Man স্কোর করলে একটি বুলিয়ান মান রিটার্ন করে।
ফাংশনটি `True` রিটার্ন করবে যদি Pac-Man একটি পাওয়ার পেলেট বা একটি ডট স্পর্শ করে।

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Pac-Man হারায় কি না তা ডিফাইন করুন

`Lose` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man হারলে একটি বুলিয়ান মান রিটার্ন করে।
ফাংশনটি `True` রিটার্ন করবে যদি Pac-Man একটি ভূত স্পর্শ করে এবং তার কোনো পাওয়ার পেলেট সক্রিয় না থাকে।

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Pac-Man জেতে কি না তা ডিফাইন করুন

`Win` ফাংশনটি ডিফাইন করুন, যা তিনটি প্যারামিটার নেয় (_Pac-Man সব ডট খেয়ে ফেলেছে কি না_, _Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_, এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man জিতলে একটি বুলিয়ান মান রিটার্ন করে।
ফাংশনটি `True` রিটার্ন করবে যদি Pac-Man সব ডট খেয়ে ফেলে এবং ৩ নম্বর অংশে বর্ণিত প্যারামিটারগুলোর ভিত্তিতে না হারে।

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. জেতার শর্তের জন্য Synopsis লিখুন

শেষ ফাংশনে ফিরে যান, আর কমেন্ট ব্লকে একটি `Synopsis` অংশ যোগ করুন, যা গেমটি কীভাবে জিতবেন তার সংক্ষিপ্ত বর্ণনা।
বর্ণনাটি অন্তত দশ অক্ষর দীর্ঘ হতে হবে।

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
