# পরিচিতি

Kotlin-এর `when` হলো কয়েকটি বিকল্পের মধ্যে একটি বেছে নেওয়ার জন্য একটি শর্তাধীন এক্সপ্রেশন। এটি Java-র `switch`-এর মতো, আর `if` ... `else if` ... `else`-এর চেইনের চেয়ে বেশি নমনীয়।

`if`-এর মতো `when`-কেও এমন একটি এক্সপ্রেশন হিসেবে ব্যবহার করা যায়, যা একটি মান তৈরি করে।

## একটি মান মেলানো

প্রথম বন্ধনীর ভেতরে `when`-কে যে মানটি মেলাতে হবে সেটি দিন। প্রতিটি শাখা সেই মানটির সাথে তুলনা করে, যতক্ষণ না কোনো একটি মিলে যায়:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- প্রতিটি শাখা `pattern -> result` আকারে লেখা হয়।
- শাখাগুলো উপর থেকে নিচে পরীক্ষা করা হয়, যতক্ষণ না একটি মিল পাওয়া যায়। কেবল প্রথম শাখাটিই রান হয়।
- উপরে তালিকায় না থাকা যেকোনো মানের জন্য `else` ব্যবহার করুন (`if` চেইনের শেষ `else`-এর মতো)।

এটি [প্যাটার্ন ম্যাচিং][pattern-matching]-এর মতো। `pattern` হতে পারে এমন একটি মান যার সাথে মেলানো হবে, অথবা টাইপ দিয়ে মেলাতে `is` ব্যবহার করুন:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

অথবা রেঞ্জ, কালেকশন, স্ট্রিং বা `contains` মেথড আছে এমন অন্য যেকোনো কিছুর ভেতরে মানটি আছে কি না তা দেখতে `in` ব্যবহার করুন:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## গার্ড শর্ত

কোনো মান মেলানোর সময় প্যাটার্নের পরে একটি `if`-এর মধ্যে অতিরিক্ত শর্ত বসানো যায়। এই শর্তগুলোকে গার্ড শর্ত বলা হয়।

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

এমনকি `else if`-ও ব্যবহার করা যায়।

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## শর্ত মেলানো

অন্যভাবে, মানটি বাদ দিয়ে প্রতিটি শাখায় বুলিয়ান শর্ত বসানো যায়:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

আবারও, শাখাগুলো উপর থেকে নিচে পরীক্ষা করা হয় এবং যে প্রথম শাখার শর্তটি `true`, কেবল সেটিই রান হয়।

## এক্সপ্রেশন হিসেবে `when` ব্যবহার

যখন `when`-কে এর ফলাফলের জন্য ব্যবহার করা হয় (কোনো ভ্যারিয়েবলে অ্যাসাইন করা, কোনো ফাংশন থেকে রিটার্ন করা, ইত্যাদি), তখন সম্ভাব্য সব কেস-ই কভার করতে হবে।

- মান দিয়ে মেলানোর সময় `else` যোগ করুন, যদি না সম্ভাব্য প্রতিটি মান আগেই হ্যান্ডেল করা থাকে (যেমন `Boolean` বা `enum`-এর সব মান)।
- শর্ত মেলানোর সময় `else` শাখা আবশ্যক, কারণ আপনার শর্তগুলো প্রতিটি কেস কভার করে কি না তা কম্পাইলার জানতে পারে না।

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
