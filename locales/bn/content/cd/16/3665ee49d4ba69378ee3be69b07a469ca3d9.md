# গেটার ও সেটার

গেটার ও সেটার হলো এমন মেথড, যা দিয়ে আপনি একটি অবজেক্টের প্রপার্টির মান পড়তে ও লিখতে পারেন।
Crystal-এ ম্যাক্রো আছে, যার ফলে একটি প্রপার্টির জন্য গেটার ও সেটার ডিফাইন করা সহজ হয়ে যায়।
ম্যাক্রো হলো কম্পাইল টাইমে কোড জেনারেট করার একটি উপায়, যা ম্যাক্রো কনসেপ্টে পরে আলোচনা করা হবে।

Ruby-তে এই মেথডগুলো `attr_reader`, `attr_writer` এবং `attr_accessor` মেথড দিয়ে ডিফাইন করা হয় এবং বাইরে থেকে দেখতে Crystal-এর বাস্তবায়নের সাথে খুবই মিল।
Crystal এগুলোকে `getter`, `setter` এবং `property` ম্যাক্রো হিসেবে ডিফাইন করেছে।

## গেটার

গেটার হলো একটি ম্যাক্রো, যা একটি ইনস্ট্যান্স ভ্যারিয়েবলের মান রিটার্ন করে এমন একটি মেথড ডিফাইন করে।
এর মানে হলো, অ্যাক্সেস করতে চাইলে আর ইনস্ট্যান্স ভ্যারিয়েবলের সামনে `@` লিখতে হয় না (initialize বাদে মেথডের ভেতরে); বদলে আপনি গেটার ম্যাক্রো যে মেথডটি ডিফাইন করেছে সেটি কল করতে পারেন।

গেটার ম্যাক্রো কমা দিয়ে আলাদা করে একাধিক ইনস্ট্যান্স ভ্যারিয়েবল নিতে পারে।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

আপনি দেখতেই পাচ্ছেন, গেটার ব্যবহার করলে আপনার লেখা কোডের পরিমাণ কমে যায় এবং কোড পড়তে সহজ হয়।
এছাড়াও Ruby আর Crystal-এর মধ্যে একটি পার্থক্য আছে: Crystal গেটার ম্যাক্রোর আর্গুমেন্ট হিসেবে ভ্যারিয়েবলের নাম ও সিম্বল, দুটোই গ্রহণ করে।
সিম্বল নিয়ে সিম্বল কনসেপ্টে পরে আলোচনা করা হবে।

## সেটার

সেটার হলো একটি ম্যাক্রো, যা একটি ইনস্ট্যান্স ভ্যারিয়েবলের মান সেট করে এমন একটি মেথড ডিফাইন করে।
এই ম্যাক্রো খুব একটা দেখা যায় না, সাধারণত এর বদলে `property` ম্যাক্রো ব্যবহার করা হয়।
যে মেথডগুলো তৈরি হবে সেগুলো দেখতে `name_of_method=` এর মতো হবে; এই `=` চিহ্নটিই প্রপার্টি সেট করা সম্ভব করে তোলে।

এই মেথড ডেফিনিশনটি একটু বিশেষ, কারণ মেথড যে আর্গুমেন্টটি পায় সেটি `=` চিহ্নের পরে থাকে।
Crystal-এ আরও কিছু বিশেষ মেথড এই সিনট্যাক্স ব্যবহার করে, যেমন `+` মেথড।

গেটার ম্যাক্রোর মতোই, সেটার ডিফাইন করার পরে ইনস্ট্যান্স ভ্যারিয়েবলের মান আপডেট করতে চাইলে আপনি সেটার ম্যাক্রো যে মেথডটি ডিফাইন করেছে সেটি কল করতে পারেন।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## প্রপার্টি

প্রপার্টি হলো একটি ম্যাক্রো, যা একটি ইনস্ট্যান্স ভ্যারিয়েবলের জন্য গেটার ও সেটার দুটোই ডিফাইন করে।

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
