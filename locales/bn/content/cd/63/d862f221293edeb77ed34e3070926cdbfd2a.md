# টপ-লেভেলে আলাদা করা কনস্ট্যান্টই ভালো

কনস্ট্যান্টটি ফাংশনের _ভিতরে_ ডিফাইন করার বদলে সেটি টপ-লেভেলে আলাদা করে আনার কথা ভাবুন। যে কনস্ট্যান্ট, ফাংশন আর ক্লাসগুলো `export` করা হয় না, সেগুলো ফাইলের বাইরে থেকে অ্যাক্সেস করা যায় না।

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
