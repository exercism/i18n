# ইঙ্গিত

## 1. রেজেক্স ব্যবহার করে কার্ড তৈরি করার জন্য প্রয়োজনীয় তথ্য সংগ্রহ করুন

- `\p{L}` যেকোনো ভাষার যেকোনো ধরনের অক্ষরের সাথে মিলবে।
- তথ্য সংগ্রহের জন্য আপনি নিচের এক্সপ্রেশনটি ব্যবহার করতে পারেন:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
