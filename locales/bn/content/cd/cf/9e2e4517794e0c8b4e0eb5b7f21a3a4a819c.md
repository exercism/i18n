# ভূমিকা

Gleam-এ রেগুলার এক্সপ্রেশন **PCRE** স্পেসিফিকেশন (**P**erl **C**ompatible **R**egular **E**xpressions, অর্থাৎ পার্ল কম্প্যাটিবল রেগুলার এক্সপ্রেশন) অনুসরণ করে, Java, JavaScript বা Ruby-র মতো অন্যান্য জনপ্রিয় ভাষার মতোই।

`gleam/regex` মডিউলটি রেগুলার এক্সপ্রেশন নিয়ে কাজ করার ফাংশন সরবরাহ করে।

~~~~exercism/note
এই অনুশীলনীতে ধরে নেওয়া হয়েছে যে আপনি রেগুলার এক্সপ্রেশনের সিনট্যাক্স আগেই জানেন, যার মধ্যে ক্যারেক্টার ক্লাস, কোয়ান্টিফায়ার, গ্রুপ ও ক্যাপচারও আছে।

রেগুলার এক্সপ্রেশনের জ্ঞান আরেকবার ঝালিয়ে নিতে চাইলে এই সূত্রগুলোর যেকোনো একটি দেখে নিতে পারেন: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/)।
~~~~

রেগুলার এক্সপ্রেশন তৈরি করার সবচেয়ে কমন উপায় হলো `regex.from_string` ফাংশনটি ব্যবহার করা।

```gleam
let assert Ok(re) = regex.from_string("test")
```

রেগুলার এক্সপ্রেশনের সিনট্যাক্স বৈধ না হলে `regex.from_string` ফাংশনটি একটি `Error` দেয়, তাই এখানে রেগুলার এক্সপ্রেশনটি বৈধ কিনা নিশ্চিত করতে একটি let-assertion ব্যবহার করা হয়েছে।

`regex.check` ফাংশনটি দিয়ে যাচাই করা যায় যে একটি রেগুলার এক্সপ্রেশন কোনো স্ট্রিংয়ের সাথে মেলে কিনা।

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## ক্যাপচার

রেগুলার এক্সপ্রেশন দিয়ে সাবস্ট্রিং ক্যাপচার করতে চাইলে `regex.scan` ফাংশনটি ব্যবহার করে ম্যাচগুলোর একটি অ্যারে রিটার্ন করা যায়।

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## মডিফায়ার

`regex.compile` ফাংশন দিয়ে অপশন পাস করে রেগুলার এক্সপ্রেশন তৈরি করলে তার আচরণ পরিবর্তন করা যায়।

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
