# সম্পর্কে

[ভ্যারিয়েডিক প্যারামিটার][variadic-parameters] ব্যবহার করে একটি ফাংশন একটি নির্দিষ্ট টাইপের শূন্য বা তার বেশি মান একটি মাত্র প্যারামিটারে নিতে পারে।
প্যারামিটারটির টাইপ অ্যানোটেশনের শেষে তিনটি ডট (`...`) যোগ করে আপনি একটি ভ্যারিয়েডিক প্যারামিটার ডিফাইন করেন।

ফাংশনের বডির ভেতরে Swift এই মানগুলোকে নির্দিষ্ট টাইপের একটি অ্যারে হিসেবে পাওয়া যায়:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
কোনো ফাংশনে ভ্যারিয়েডিক প্যারামিটারের পরে আরও প্যারামিটার থাকলে, ভ্যারিয়েডিক প্যারামিটারের পরের প্রথম প্যারামিটারটির একটি স্পষ্ট আর্গুমেন্ট লেবেল থাকতে **অবশ্যই** হবে, যাতে Swift বুঝতে পারে ভ্যারিয়েডিক আর্গুমেন্টের তালিকা কোথায় শেষ হচ্ছে।
~~~~
