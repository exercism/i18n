# লোকালি Debug করা

[Bats](https://github.com/bats-core/bats-core) দিয়ে Bash ট্র্যাকের টেস্ট রান করলে, আউটপুট অ্যাসারশনের জন্য Bats STDOUT ও STDERR দুটোই ধরে রাখে।

```exercism/caution
এটি `bats` দিয়ে লোকালি কাজ করে, কিন্তু Exercism অনলাইন এডিটরে **কাজ করে না**।
```

টেস্টের ফলাফলে কোনো প্রভাব না ফেলে debug আউটপুট প্রিন্ট করতে চাইলে, সেটি ফাইল ডেসক্রিপ্টর (fd) ৩-এ লিখুন।

```bash
echo 'debug message' >&3
```

টেস্ট রান চলার সময় Bats fd ৩-এ লেখা আউটপুট দেখায়, কিন্তু `assert_output`-এর মতো অ্যাসারশনে সেই আউটপুট অন্তর্ভুক্ত করে না।

একটি উদাহরণ রান:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

আপনি যখন লোকালি টেস্ট চালাচ্ছেন, তখন এটি কাজে লাগে।
