# রিসোর্স

## প্রস্তাবিত শেখার রিসোর্স
Clojurescript হলো Clojure-এর একটি সুপরিকল্পিত ডায়ালেক্ট। Clojure সম্পর্কে আপনার জ্ঞান (ভাষাটি, হোস্ট প্ল্যাটফর্ম JVM নয়) Clojurescript-এ কাজে লাগানো যায়।

- [ClojureScript API](http://cljs.github.io/api/) অফিসিয়াল API ডকুমেন্টেশন।
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet), একটি অফিসিয়াল চিট-শিট।
- [Learn Clojurescript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes) ভাষাটির সিনট্যাক্স শেখানোর একটি GitHub রিপোজিটরি।
