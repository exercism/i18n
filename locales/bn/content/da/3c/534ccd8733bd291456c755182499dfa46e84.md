# পরিচিতি

Cairo-তে একটি ফাংশন আপনাকে কোডকে একটি পুনর্ব্যবহারযোগ্য এককে গুছিয়ে রাখার সুযোগ দেয়, যা আপনার প্রোগ্রামগুলোকে আরও মডুলার এবং বোঝা সহজ করে তোলে।
Cairo-তে ফাংশন গঠিত হয় `fn` কিওয়ার্ড, তারপর ফাংশনের নাম, বন্ধনীর ভেতরে প্যারামিটারের একটি তালিকা, এবং একটি কোড ব্লক দিয়ে যা নির্ধারণ করে ফাংশনটি কী করে।

## ফাংশন প্যারামিটার

Cairo-তে সব ফাংশন প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হয়।
কিছু ভাষার মতো নয়, Cairo টাইপ অনুমান করে না, আর প্যারামিটারের কোনো ডিফল্ট মানও নেই, তাই সব প্যারামিটারই দিতে হয়।

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## প্যারামিটার বনাম আর্গুমেন্ট

`parameters` আর `arguments`-এর মধ্যে পার্থক্য বোঝা জরুরি:

- **প্যারামিটার** হলো ফাংশন ডিফিনিশনে ব্যবহৃত ভ্যারিয়েবলের নাম, যেমন `print_greeting_name` ফাংশনে `greeting` আর `name`।
- **আর্গুমেন্ট** হলো ফাংশনটি কল করার সময় তাতে পাঠানো আসল মানগুলো।

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## স্টেটমেন্ট এবং এক্সপ্রেশন

ফাংশনের বডি গঠিত হয় একগুচ্ছ স্টেটমেন্ট দিয়ে, যার শেষে ঐচ্ছিকভাবে একটি এক্সপ্রেশন থাকতে পারে।

- স্টেটমেন্ট হলো এমন নির্দেশনা যা কোনো কাজ সম্পাদন করে কিন্তু কোনো মান রিটার্ন করে না।
- এক্সপ্রেশন মূল্যায়িত হয়ে একটি ফলস্বরূপ মান দেয়।

`let` কিওয়ার্ড দিয়ে একটি ভ্যারিয়েবল তৈরি করে তাতে একটি মান অ্যাসাইন করা একটি স্টেটমেন্ট।

```rust
let y = 6;
```

কিন্তু উপরের স্টেটমেন্টের `6`-টি একটি এক্সপ্রেশন, যা মূল্যায়িত হয়ে `6` মান দেয়।

ফাংশন কল করা একটি এক্সপ্রেশন, কারণ এটি সবসময় একটি মানে পরিণত হয়: ফাংশনের স্পষ্ট রিটার্ন ভ্যালু (যদি উল্লেখ করা থাকে), অথবা অন্যথায় 'unit' টাইপ `()`।

## রিটার্ন ভ্যালু

Cairo-এর ফাংশনগুলো তাদের কল করা কোডে মান রিটার্ন করতে পারে।
রিটার্ন ভ্যালু প্যারামিটারের পরে লেখা হয়, একটি তীর `->` দিয়ে আলাদা করে।
Cairo-তে ফাংশনের রিটার্ন ভ্যালু বলতে ফাংশনের বডির ব্লকে থাকা শেষ এক্সপ্রেশনের মানকেই বোঝায়।
`return` কিওয়ার্ড ব্যবহার করে এবং একটি মান উল্লেখ করে আপনি ফাংশন থেকে আগেই রিটার্ন করতে পারেন।

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## ফাংশন কল করা

Cairo-তে একটি ফাংশন কল করতে, আপনি শুধু ফাংশনের নাম লিখবেন, তারপর বন্ধনীর ভেতরে আর্গুমেন্ট।

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
