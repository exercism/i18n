# সম্পর্কে

Factor-এর `<iota>` ইন্টিজার `0, 1, …, n-1`-এর একটি *ভার্চুয়াল* সিকোয়েন্স তৈরি করে। `map` দিয়ে এটির উপর ইটারেশন করলে একটি ট্যাবুলেটেড সিকোয়েন্স পাওয়া যায়, যেখানে প্রতিটি এলিমেন্ট তার অবস্থানের একটি ফাংশন:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

দুটি জিনিস দিয়ে আপনি ইন্টিজার কোডের একটি সিকোয়েন্সকে স্ট্রিংয়ে বদলাতে পারেন:

| word      | role                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | পার্স-টাইম লিটারাল, যা একটি ক্যারেক্টারের কোড পয়েন্ট পুশ করে |
| `>string` | কোড পয়েন্টের একটি সিকোয়েন্সকে স্ট্রিংয়ে রূপান্তর করে     |

একসাথে ব্যবহার করলে এগুলো দিয়ে অবস্থান অনুযায়ী ইনডেক্স করা ক্যারেক্টারের একটি সারি বানানোর প্রচলিত রীতিটি তৈরি হয়:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

কোয়োটেশনের ভেতরে `if` (বা `?`) দিয়ে ক্যারেক্টার বেছে নিলে, প্রতিটি অবস্থানের সিদ্ধান্তটি তার নির্ভর করা ইনডেক্সের কাছেই থাকে।
