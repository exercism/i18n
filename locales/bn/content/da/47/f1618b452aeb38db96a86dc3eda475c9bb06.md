# ইনস্টলেশন

## প্রস্তাবনা

যদিও Regina Rexx বিস্তৃতভাবে বিভিন্ন প্ল্যাটফর্মে পোর্ট করা হয়েছে, এই ইনস্টলেশন নির্দেশনাগুলো ৬৪ বিট ডেস্কটপ প্ল্যাটফর্মে Windows, Linux বা MacOS চালানোর দিকেই কেন্দ্রীভূত থাকবে।

## ইনস্টলেশনের ধাপ

মনে রাখবেন, এই ট্র্যাকটি [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/)র সর্বশেষ সংস্করণ ইনস্টল করা থাকার প্রত্যাশা করে (লেখার সময়ে 3.9.5)। দেওয়া হাইপারলিঙ্কটি আপনাকে সরাসরি Files বিভাগে নিয়ে যায়, যেখান থেকে ডাউনলোড করার জন্য একটি ফাইল বেছে নিতে পারবেন।

### Windows

Windows-এর অধীনে নেটিভভাবে চালানোর জন্য ইনস্টলেশন (একটি CMD বা Powershell উইন্ডোর মাধ্যমে) ব্রাউজারেই সহজে করা যায় [`Download Latest Version`](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/Regina395w64.exe/download) বোতামটি দিয়ে। ক্লিক করা, ডাউনলোড করা আর ইনস্টল করা ছাড়া আর কিছুই করতে হয় না।

আপনার যদি Linux এমুলেশন এনভায়রনমেন্ট থাকে, বা ব্যবহার করতে চান, যেমন:

* [Git for Windows](https://gitforwindows.org/)
* [Cygwin](https://cygwin.com/)
* [MinGW](http://mingw.org/)

তাহলে Windows-এর নেটিভ Regina বাইনারিগুলো সেখানেও ব্যবহারযোগ্য থাকবে, তাই আপনি এনভায়রনমেন্টগুলোতে সেগুলো সরাসরি চালাতে পারবেন, আর বেশিরভাগ কাজেই এটা ঠিকঠাক চলবে।

তবে একটি সতর্কতা আছে, ADDRESS নির্দেশটি সঠিকভাবে কাজ করে না (কারণ এটি হোস্ট অপারেটিং সিস্টেমের সাথে সংযোগ স্থাপন করে)। এই এনভায়রনমেন্টগুলোতে সেরা ফল পেতে হলে, সংশ্লিষ্ট এনভায়রনমেন্টের জন্য নির্দিষ্ট প্যাকেজ সোর্স করে ইনস্টল করুন। যেমন, Regina ওয়েবসাইটে একটি [Cygwin-specific](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-pc-cygwin.tgz/download) বিল্ড আছে যা ইনস্টল করা যেতে পারে।

বিকল্প হিসেবে, আপনার যদি Windows-এর অধীনে একটি _real_ Linux ডিস্ট্রিবিউশন থাকে বা ব্যবহার করতে চান, যেমন [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) বা [Virtual Box](https://www.virtualbox.org/), তবে সংশ্লিষ্ট ডিস্ট্রিবিউশনের জন্য Linux বিভাগের নির্দেশনাগুলো অনুসরণ করুন।

### Linux

সিস্টেমের প্যাকেজ ম্যানেজার ব্যবহার করলে Linux ইনস্টলেশন সাধারণত বেশ সহজ হয়। তবে সমস্যা হয় তখন, যখন পাওয়া প্যাকেজগুলো সর্বশেষ সংস্করণ _নয়_। দুঃখজনকভাবে, Regina-র ক্ষেত্রে অবস্থা ঠিক তাই।

সর্বশেষ প্যাকেজ হাতে সোর্স করে প্যাকেজ-ভিত্তিক ইনস্টলেশন এখনও সম্ভব। [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) ওয়েবসাইটে Debian পরিবার (Ubuntu সহ) এবং RHEL পরিবার (Fedora, CentOS, Rocky ও Alma সহ) ডিস্ট্রিবিউশনের জন্য প্যাকেজ আছে, আরও কিছু ডিস্ট্রিবিউশনসহ।

আপনি যে ডিস্ট্রিবিউশন বেছেছেন, তার জন্য দুটি প্যাকেজ ডাউনলোড করতে হবে, একটি লাইব্রেরি প্যাকেজ এবং একটি বাইনারি প্যাকেজ। যেমন, Debian বা Ubuntu-তে ইনস্টল করতে হলে এভাবে করুন:

```plain
sudo apt update && sudo apt -y install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx_3.9.5-2_amd64-Debian-11.deb > regina-rexx_3.9.5-2_amd64-Debian-11.deb
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3_3.9.5-2_amd64-Debian-11.deb > libregina3_3.9.5-2_amd64-Debian-11.deb
sudo apt -y install libregina3_3.9.5-2_amd64-Debian-11.deb regina-rexx_3.9.5-2_amd64-Debian-11.deb
```

আর CentOS ও RHEL 7-এ চেষ্টা করুন:
```plain
sudo yum update && sudo yum install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
sudo yum localinstall libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
```

আর Fedora, Rocky ও Alma-তে চেষ্টা করুন:
```plain
sudo dnf update && sudo dnf install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
sudo dnf localinstall libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
```

যেখানে প্যাকেজ-ভিত্তিক ইনস্টলেশন সম্ভব নয়, বা অন্য কোনোভাবে সমস্যাযুক্ত প্রমাণিত হয়েছে, সেখানে সোর্স থেকে বিল্ড করা সবসময়ই সম্ভব, আর্কাইভটি এভাবে পাওয়া যায়:

```plain
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5.tar.gz > regina-rexx-3.9.5.tar.gz
```

ধরে নিচ্ছি স্ট্যান্ডার্ড বিল্ড টুল (gcc, make) ইনস্টল করা আছে (না থাকলে, এখানকার নির্দেশনা অনুসরণ করুন: [Install Development Tools](https://ostechnix.com/install-development-tools-linux/)), তারপর নিচের ধাপগুলো করুন:

```plain
tar -xzvf regina-rexx-3.9.5.tar.gz && cd regina-rexx-3.9.5
./configure
sudo make
sudo make install
```

লাইব্রেরি (`libregina.so`) এবং দুটি সেট বাইনারি (`rexx` ও `regina`) ইনস্টল হয় (ডিফল্ট অবস্থান `/usr/local/bin`)।

`rexx` বাইনারিটি স্ট্যাটিকভাবে লিংক করা, তাই এটি স্বয়ংসম্পূর্ণ এবং ব্যবহারের জন্য প্রস্তুত।

`regina` বাইনারিটি ডাইনামিকভাবে লিংক করা, তাই রানটাইমে `libregina.so` শেয়ার্ড লাইব্রেরিটি খুঁজে পেতে এটির কিছু কনফিগারেশন দরকার। এজন্য এই ধাপগুলো অনুসরণ করুন:

```plain
# Configure shared library location
sudo su
echo /usr/local/lib64/ > /etc/ld.so.conf.d/regina-rexx-3.9.5-x86_64.conf
echo /usr/local/lib64/regina-rexx/addons > /etc/ld.so.conf.d/regina-rexx-addons-x86_64.conf
cd /usr/local/lib64
rm -f libregina.so libregina.so.3
ln -s libregina.so.3.9 libregina.so
ln -s libregina.so.3.9 libregina.so.3
ldconfig
exit

# Check symbolic link creation
ls -l /usr/local/lib64/

# Output should be similar. Note symbolic links.
-rw-r--r--. 1 root root 3887554 Dec  1 18:22 libregina.a
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so -> libregina.so.3.9
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so.3 -> libregina.so.3.9
-rwxr-xr-x. 1 root root  574104 Dec  1 18:22 libregina.so.3.9
drwxr-xr-x. 2 root root      26 Dec  1 18:22 pkgconfig
drwxr-xr-x. 4 root root      33 Dec  1 18:22 regina-rexx

# Check library path, and executable using that path
ldconfig -p | grep regina
ldd /usr/local/bin/regina

# Alternate for local user
export LD_LIBRARY_PATH=${LD_LIBRARY_PATH}:/usr/local/lib64:/usr/local/lib64/regina-rexx/addons
```

মনে রাখবেন, সোর্স থেকে বিল্ড করা এবং তার সাথে সম্পর্কিত সিস্টেম কনফিগারেশন, অভিজ্ঞ ব্যবহারকারীদের জন্যই সবচেয়ে উপযুক্ত কাজ।

### MacOS

ইনস্টলেশন একটি তিন ধাপের প্রক্রিয়া:

* [Homebrew](https://brew.sh) প্যাকেজ ম্যানেজার ইনস্টল করুন
* `Terminal` অ্যাপ্লিকেশনটি খুঁজে বের করে চালু করুন
* `Terminal` কমান্ড-লাইন থেকে নিচেরটি লিখুন:

   `brew install regina-rexx`

এতে সর্বশেষ সংস্করণ ইনস্টল হওয়া _উচিত_।

যদি তা না হয়, আপনি [Regina for MacOS](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-apple-darwin21.6.0.tgz/download) প্যাকেজটি ডাউনলোড করে নিজে ইনস্টল করতে পারেন।

## ইনস্টলেশনের পরে

### ইনস্টলেশন যাচাই

ইনস্টলেশন শেষ করার পর, টার্মিনালে এই কমান্ডটি চালিয়ে আপনি যাচাই করতে পারেন [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) সফলভাবে ইনস্টল হয়েছে কি না:

```plain
rexx --version=v
```

Windows ও Linux, উভয় প্ল্যাটফর্মেই টার্মিনালে নিচের আউটপুট দেখা যাবে:

```plain
3.9.5
```

যেটি ইন্টারপ্রেটারের সংস্করণ নম্বর।

আরেকটি বাইনারি `regina`-ও ইনস্টল হয়। এটি সর্বদিক থেকেই `rexx`-এর সমান, শুধু এটি একটি শেয়ার্ড লাইব্রেরির সাথে লিংক করা, আর বাইরের ইউটিলিটি ফাংশন ব্যবহার করতে চাইলে এর বদলে এই ইন্টারপ্রেটারটিই ব্যবহার করবেন। দেখুন [বাহ্যিক রুটিন ব্যবহার করা](###accessing-external-routines) বিভাগটি।

ট্র্যাকটি ব্যবহার শুরু করতে আর কোনো সফটওয়্যার কম্পোনেন্ট ইনস্টল করতে হবে না (ধরে নিচ্ছি Exercism CLI ইনস্টল করা আছে)।

নিচের ব্যবহার-নির্দেশনাগুলো কমান্ড লাইন থেকে ইন্টারপ্রেটার ব্যবহারের প্রাথমিক ধারণা দেবে।

### ব্যবহার

একটি Rexx স্ক্রিপ্টের সাধারণত _`.rexx`_ এক্সটেনশন থাকে, যদিও এটি বাধ্যতামূলক নয়, কারণ ইন্টারপ্রেটার আর্গুমেন্ট হিসেবে দেওয়া যে-কোনো ফাইলনাম চালানোর চেষ্টা করে, আর সেটিতে বৈধ Rexx কোড থাকলে তা সফলভাবে চলে।

নিচের কমান্ডটি `hello.rexx` নামের একটি ফাইল চালানোর চেষ্টা করবে:

```plain
rexx hello.rexx
```

ধরে নিচ্ছি ফাইলটিতে নিচের কোডটি আছে:

```rexx
say "Hello, world!"
exit 0
```

তাহলে টার্মিনালে আউটপুট হবে:

```plain
Hello, world!
```

ফাইলটির নাম বদলে `hello.txt` করে এভাবে চালালেও একই টার্মিনাল আউটপুট দেখা যাবে:

```plain
rexx hello.txt
```

এটাও জেনে রাখা ভালো, স্ক্রিপ্ট কোড ফাইলে থাকার বদলে পাইপ করে ইন্টারপ্রেটারে পাঠানো যায়। আগের কোডটি পাইপ করে এভাবে চালানো যায়:

```plain
echo "say 'Hello, world' ; exit 0" | rexx
```

এবং এটি Linux বা Windows Powershell টার্মিনাল, দুটোতেই সমান ভালোভাবে কাজ করে।

### উন্নত ব্যবহার

স্ক্রিপ্ট ফাইলে এক বা একাধিক কমান্ড-লাইন আর্গুমেন্ট দেওয়া যায়, আর এটি যেকোনো পূর্ণসংখ্যার রিটার্ন কোড ফেরত দিতে পারে। তবে স্ক্রিপ্টে একাধিক আর্গুমেন্ট পাঠানো হবে, সেটি ইন্টারপ্রেটারকে জানাতে হয়, যা `-a` অপশনের মাধ্যমে করা হয়।

যেমন, ধরে নিন `multiarg.rexx` ফাইলটিতে নিচের কোডটি আছে:

```rexx
say "My name is" ARG(1) || ", your name is" ARG(2) || ", and the script return code will be" ARG(3) || "."
exit ABS(ARG(3))
```

একাধিক স্ক্রিপ্ট আর্গুমেন্ট যাতে সঠিকভাবে ইন্টারপ্রেট হয়, সেজন্য স্ক্রিপ্টটি এভাবে চালানো হয়:

```plain
rexx -a multiarg.rexx "John" "Jill" 5
```

যা টার্মিনালে নিচের আউটপুট দেয়:

```plain
My name is John, your name is Jill, and the script return code will be 5.
```

আর প্রোগ্রামের রিটার্ন কোড (Linux-এ `$?`, বা Windows-এ `%errorlevel%` দিয়ে পাওয়া যায়) 5 মানে সেট হয়।

### বাহ্যিক রুটিন ব্যবহার করা

Regina বাহ্যিক শেয়ার্ড লাইব্রেরিতে থাকা রুটিন ব্যবহার সমর্থন করে। Regina ওয়েবসাইটে এরকম বেশ কিছু পাওয়া যায়। তবে এসব লাইব্রেরি ইনস্টল করা এখানে আলোচনা করা হয়নি।

Regina-র সাথে এরকম একটি লাইব্রেরি, _regutil_, আগে থেকেই দেওয়া থাকে। এতে গণিত, ফাইল ও ফাইলসিস্টেম নিয়ে কাজ, এবং সিস্টেম অ্যাক্সেসের কাজসহ বেশ কিছু সাধারণ উদ্দেশ্যের রুটিন থাকে।

অতিরিক্ত কোনো ইনস্টলেশন ধাপ লাগে না। তবে স্ক্রিপ্টে এই রুটিনগুলো ব্যবহার করতে হলে ইন্টারপ্রেটার লোড হওয়ার সময় সেগুলো রেজিস্টার করতে হয়। এতে দুটির বেশি ফাংশন কল লাগে না, আর প্রক্রিয়াটি এখানে দেখানো হয়েছে।

`access-external.rexx` ফাইলটিতে নিচের কোডটি আছে:

```rexx
/* Register external library and functions */
call RxFuncAdd 'SysLoadFuncs', 'regutil', 'SysLoadFuncs'
call SysLoadFuncs

say "Value of pi is" SysPi()
say "Square root of 25 is" SysSqrt(25)
say "Square root of 2 is" SysSqrt(2)

/* Deregister */
call SysDropFuncs

exit 0
```

এই রুটিনগুলো লোড করে ব্যবহার করতে হলে `regina` বাইনারি ব্যবহার করতে হয়, তাই স্ক্রিপ্টটি এভাবে চালানো হবে:

```plain
regina access-external.rexx
```

আর টার্মিনালে নিচের আউটপুট দেখা যায়:

```plain
Value of pi is 3.141592654
Square root of 25 is 5.000000000
Square root of 2 is 1.414213562
```

এর বদলে যদি `rexx` বাইনারি ব্যবহার করা হতো, Windows প্ল্যাটফর্মে টার্মিনাল আউটপুট হতো:

```plain

operable program or batch file.
'SYSPI' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSDROPFUNCS' is not recognized as an internal or external command,
operable program or batch file.
```
