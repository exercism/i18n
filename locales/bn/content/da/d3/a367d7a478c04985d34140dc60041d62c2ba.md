# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বইয়ের সেই চমৎকার লাসাগনা প্রস্তুত ও রান্নার সাথে সম্পর্কিত আরও কিছু কোড লিখবেন।

আপনার সামনে চারটি কাজ আছে।
প্রথমটি রান্নার সাথে সম্পর্কিত, বাকি তিনটি নিখুঁত প্রস্তুতি নিয়ে।

## 1. প্রস্তুতির সময় অনুমান করুন

আপনি যে পরের লাসাগনাটি তৈরি করবেন, তার জন্য যথেষ্ট সময় রাখতে চান, যাতে রান্নাটি উপভোগ করতে পারেন।
আপনার লাসাগনায় কোন কোন স্তর থাকবে তা আপনি আগেই ঠিক করে ফেলেছেন।
এখন সেই অনুযায়ী প্রস্তুতিতে কত সময় লাগবে তা অনুমান করতে চান।

`[]string` হিসেবে স্তরগুলোর একটি স্লাইস এবং `int` হিসেবে মিনিটে প্রতি স্তরের গড় প্রস্তুতির সময় নেয় এমন একটি `PreparationTime` ফাংশন ইমপ্লিমেন্ট করুন।
ফাংশনটি স্তরের সংখ্যার ভিত্তিতে মোট প্রস্তুতির সময়ের অনুমান `int` হিসেবে রিটার্ন করবে।
Go-তে ফাংশনের জন্য ডিফল্ট মান বলে কিছু নেই।
যদি গড় প্রস্তুতির সময় `0` হিসেবে পাঠানো হয় (`int`-এর ডিফল্ট প্রাথমিক মান), তাহলে ডিফল্ট মান `2` ব্যবহার করতে হবে।

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. প্রয়োজনীয় নুডলস ও সসের পরিমাণ হিসাব করুন

সময় আলাদা রাখার পাশাপাশি, আপনার স্বপ্নের লাসাগনা রান্নার জন্য যথেষ্ট সস ও নুডলস আছে কি না তাও নিশ্চিত করতে চান আপনি।
আপনার লাসাগনার প্রতিটি নুডলসের স্তরের জন্য ৫০ গ্রাম নুডলস লাগবে।
আপনার লাসাগনার প্রতিটি সসের স্তরের জন্য ০.২ লিটার সস লাগবে।

`Quantities` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে `[]string` টাইপের স্তরের একটি স্লাইস নেয়।
এরপর ফাংশনটি আপনার খাবার তৈরি করতে প্রয়োজনীয় নুডলস ও সসের পরিমাণ নির্ধারণ করবে।
ফলাফল দুটি মান হিসেবে রিটার্ন করতে হবে: `noodles` একটি `int` হিসেবে এবং `sauce` একটি `float64` হিসেবে।

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. গোপন উপাদান যোগ করুন

কিছুদিন আগে আপনি এক বন্ধুর বাড়িতে গিয়েছিলেন এবং সেখানে লাসাগনা খেয়েছিলেন।
খাবারটি ছিল অসাধারণ, তাতে বিশেষ কিছু একটা ছিল।
বন্ধুটি আপনাকে উপকরণের তালিকা পাঠিয়েছিলেন এবং বলেছিলেন, তালিকার শেষ উপাদানটিই সেই "গোপন উপাদান", যা খাবারটিকে এত বিশেষ করে তুলেছিল।
এখন আপনি সেই গোপন উপাদানটি নিজের রেসিপিতেও যোগ করতে চান।

`AddSecretIngredient` নামের একটি ফাংশন লিখুন, যা প্যারামিটার হিসেবে `[]string` টাইপের উপকরণের দুটি স্লাইস নেয়।
প্রথম প্যারামিটারটি আপনার বন্ধুর পাঠানো তালিকা, দ্বিতীয়টি আপনার নিজের রেসিপির উপকরণের তালিকা।
আপনার উপকরণের তালিকার শেষ এলিমেন্টটি সবসময় `"?"`।
ফাংশনটি সেটিকে আপনার বন্ধুর তালিকার শেষ উপাদান দিয়ে বদলে দেবে।
**লক্ষ্য করুন:** `AddSecretIngredient` কিছুই রিটার্ন করে না, আপনাকে সরাসরি আপনার উপকরণের তালিকাটি পরিবর্তন করতে হবে।
আপনার বন্ধুর উপকরণের তালিকাটি **পরিবর্তন করা উচিত নয়**।
এছাড়া, যেহেতু `slice` ফাংশনে পয়েন্টার হিসেবে পাঠানো হয়, সেহেতু `AddSecretIngredient`-এ পাঠানো দুটি `[]string` আর্গুমেন্ট সরাসরি পরিবর্তিত হবে।

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. রেসিপিটি স্কেল করুন

আপনার রান্নার বইয়ে দেওয়া পরিমাণ দিয়ে মাত্র দুই পোরশনের লাসাগনা হয়।
যেহেতু পরেরবার আপনি আরও মানুষের জন্য রান্না করতে চান, তাই বিভিন্ন সংখ্যক পোরশনের জন্য পরিমাণ হিসাব করতে চান।

দুইটি প্যারামিটার নেয় এমন একটি `ScaleRecipe` ফাংশন ইমপ্লিমেন্ট করুন।

- দুই পোরশনের জন্য প্রয়োজনীয় `float64` পরিমাণের একটি স্লাইস।
- আপনি যে সংখ্যক পোরশন রান্না করতে চান সেই সংখ্যা।

ফাংশনটি চাওয়া সংখ্যক পোরশনের জন্য প্রয়োজনীয় পরিমাণের একটি `float64` স্লাইস রিটার্ন করবে।
তবে আপনি মূল রেসিপিটি অপরিবর্তিত রাখতে চান।
এর মানে এই ফাংশনে `quantities` আর্গুমেন্টটি পরিবর্তন করা উচিত নয়।

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
