# ভূমিকা

[স্পেশাল ফর্ম with][with] সম্ভাব্য ব্যর্থ হতে পারে এমন ধাপের একটি সিরিজের "হ্যাপি পাথ"-এ মনোযোগ দেওয়ার এবং পরে ব্যর্থতাগুলো সামলানোর একটি উপায় দেয়।

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

প্রতিটি ধাপে কোনো ক্লজ ম্যাচ করলে চেইনটি চলতে থাকে, যতক্ষণ না `do` ব্লকটি চালানো হয়। কোনো একটি ম্যাচ ব্যর্থ হলে চেইনটি থেমে যায় এবং যে ক্লজটি ম্যাচ হয়নি সেটি রিটার্ন করা হয়। ব্যর্থ ম্যাচগুলো ধরে ফেলতে এবং রিটার্ন ভ্যালু পরিবর্তন করতে আপনি চাইলে একটি `else` ব্লক ব্যবহার করতে পারেন।
