# নির্দেশনা

নেটবল সিজন শেষ, আর ল্যাডারই ঠিক করে কে ফাইনাল খেলবে।

স্টাবটিতে আপনাকে একটি `TEAM` ক্লাস দেওয়া আছে। তার নিচে `FINALS_LADDER` লিখুন।

## 1. কে কার উপরে?

`higher` দুটি টিম নেয় আর উত্তর দেয় প্রথমটি দ্বিতীয়টির উপরে থাকবে কি না। বেশি পয়েন্ট আগে আসে। পয়েন্টে সমান টিমগুলো গোল ডিফারেন্স দিয়ে আলাদা করা হয়, যার গোল ডিফারেন্স বেশি সেটি আগে।

```sather
FINALS_LADDER::higher(#TEAM("Vixens", 24, 40), #TEAM("Magpies", 20, 90))
-- => true
```

## 2. ল্যাডার

`ladder` যেকোনো ক্রমে টিমগুলো নেয় আর সেগুলো র‍্যাংক করে উত্তর দেয়। যে অ্যারেটি দেওয়া হয় সেটি আগের মতোই থাকতে হবে।

```sather
FINALS_LADDER::ladder(teams)
-- => the same teams, best first
```

## 3. ল্যাডারটি পড়ে শোনান

`names` টিমের একটি অ্যারে নেয় আর `", "` দিয়ে জোড়া লাগানো তাদের নামগুলো উত্তর দেয়।

```sather
FINALS_LADDER::names(FINALS_LADDER::ladder(teams))
-- => "Vixens, Magpies, Swifts"
```

## 4. চ্যাম্পিয়ন

`premiers` যেকোনো ক্রমে টিমগুলো নেয় আর সবার উপরের টিমটির নাম উত্তর দেয়। একেবারে কোনো টিম না থাকলে উত্তর `""`।

```sather
FINALS_LADDER::premiers(teams)
-- => "Vixens"
```

## 5. সম্পূর্ণ ভিন্ন একটি ক্রম

`shortest_first` স্ট্রিংয়ের একটি অ্যারে নেয় আর সেগুলো দৈর্ঘ্য অনুযায়ী সাজিয়ে উত্তর দেয়, সবচেয়ে ছোটটি আগে। একই দৈর্ঘ্যের স্ট্রিংগুলো বর্ণানুক্রমিক ক্রমে যায়।

```sather
FINALS_LADDER::shortest_first(|"Magpies", "Vixens", "Swifts"|)
-- => "Swifts", "Vixens", "Magpies"
```

টাই-ব্রেকটা শুধু সাজসজ্জা নয়। সর্টটি স্টেবল নয়, তাই এটি ছাড়া একই দৈর্ঘ্যের দুটি নাম যেকোনো ক্রমে বেরিয়ে আসতে পারে।

এটি টাস্ক ২-এর মতোই একই সর্টিং রুটিন, তবে এতে ভিন্ন একটি নিয়ম দেওয়া হয়েছে। এটাই এই অনুশীলনীর মূল কথা।
