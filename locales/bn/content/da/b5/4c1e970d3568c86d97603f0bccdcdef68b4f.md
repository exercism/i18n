# Break, Continue

লুপিং বা ইটারেশন করা কোনো কন্ট্রোল স্ট্রাকচার ব্যবহার করার সময়, `break` ও `continue` কিওয়ার্ড দুটি একটি প্রোগ্রামের প্রবাহ নিয়ন্ত্রণে সাহায্য করতে পারে।
`break` কিওয়ার্ডটি লুপের কনটেক্সট থেকে বেরিয়ে বাইরের স্কোপে চলে যায়, ফলে লুপটি শেষ হয়ে যায়।
`continue` কিওয়ার্ডটি বর্তমান ইটারেশনের বাকি অংশ বাদ দেয় এবং পরের ইটারেশনের শুরুতে লুপের কনটেক্সট আবার শুরু করে।
যদিও কমন নয়, কিওয়ার্ডটির সাথে একটি সংখ্যা দেওয়া যেতে পারে, যাতে কতগুলো কনটেক্সট থেকে বেরিয়ে আসতে হবে বা কতগুলো কনটেক্সট বাদ দিয়ে পরের ইটারেশনে যেতে হবে তা নিয়ন্ত্রণ করা যায়।

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

আগের উদাহরণে, `continue` পাঁচ (৫) বার চালানো হয়, কিন্তু ষষ্ঠ (৬) ইটারেশনে `break` চালানো হয়, যার ফলে কোডটি লুপ থেকে বেরিয়ে যায়।
