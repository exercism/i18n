# নির্দেশনা

সাধারণ Take-A-Number মেশিনটি বেশ ভালোই বিক্রি হচ্ছিল, কিন্তু বাজারে থাকা অন্য মডেলগুলোর তুলনায় এতে উন্নত ফিচারের অভাব নিয়ে কিছু ব্যবহারকারী অভিযোগ করছিলেন।

নির্মাতা প্রতিষ্ঠান ব্যবহারকারীদের মতামত শুনে আরও ফিচারসহ একটি ডিলাক্স মডেল বাজারে ছাড়ার সিদ্ধান্ত নিল, আর এই মেশিনের সফটওয়্যার লেখার দায়িত্ব আবারও আপনার হাতে পড়ল।

ডিলাক্স মডেলে যুক্ত হওয়া নতুন ফিচারগুলোর মধ্যে রয়েছে:
- বর্তমানে কিউতে থাকা নম্বরগুলোর হিসাব রাখা।
- সর্বনিম্ন ও সর্বোচ্চ নম্বর নির্ধারণ করা। এতে একই প্রতিষ্ঠানের বিভিন্ন বিভাগে গ্রাহকদের কিউ করাতে একাধিক ডিলাক্স Take-A-Number মেশিন ব্যবহার করা যাবে, আর নম্বরের পরিসর দেখে বিভাগগুলো আলাদা করা যাবে।
- নির্দিষ্ট কিছু নম্বরকে কিউ এড়িয়ে যাওয়ার সুযোগ দেওয়া, যাতে গর্ভবতী নারী ও প্রবীণরা অগ্রাধিকারমূলক সেবা পান।
- ভুলে গিয়ে সারা সপ্তাহান্ত ধরে মেশিন চালু রেখে শক্তি নষ্ট করা আটকাতে অটো শাটডাউন।

মেশিনের বিজনেস লজিক আপনার সহকর্মী আগেই তৈরি করেছেন, যা `TakeANumberDeluxe.State` মডিউলে পাওয়া যাবে। এখন আপনার কাজ হলো সেটিকে একটি `GenServer`-এ মুড়ে দেওয়া।

## 1. মেশিন চালু করুন

`TakeANumberDeluxe` মডিউলে `GenServer` বিহেভিয়ার ব্যবহার করুন।

`start_link/1` ফাংশনটি এবং প্রয়োজনীয় `GenServer` কলব্যাকটি ইমপ্লিমেন্ট করুন।

`start_link/1`-এ যে আর্গুমেন্টটি পাঠানো হয়, সেটি একটি কিওয়ার্ড লিস্ট। এতে `:min_number` ও `:max_number` কী দুটি থাকে। এই কীগুলোর অধীন মানগুলো `TakeANumberDeluxe.State.new/2` ফাংশনে পাঠাতে হবে।

`TakeANumberDeluxe.State.new/2` যদি একটি `{:ok, state}` টাপল রিটার্ন করে, তাহলে মেশিনটি চালু হওয়া উচিত, এবং রিটার্ন করা স্টেটটিকেই তার স্টেট হিসেবে ব্যবহার করা উচিত। আর যদি বদলে একটি `{:error, error}` টাপল রিটার্ন করে, তাহলে মেশিনটি বন্ধ হয়ে যাওয়া উচিত, এবং রিটার্ন করা এররটিকেই থেমে যাওয়ার কারণ হিসেবে দেখানো উচিত।

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

আপনি হয়তো খেয়াল করে থাকবেন, `TakeANumberDeluxe.State.new/2` ফাংশনটি ঐচ্ছিক একটি তৃতীয় আর্গুমেন্টও নেয়, `auto_shutdown_timeout`। এই অনুশীলনীর শেষ ধাপে আমরা এটি ব্যবহার করব।

## 2. মেশিনের স্টেট রিপোর্ট করুন

`report_state/1` ফাংশনটি এবং প্রয়োজনীয় `GenServer` কলব্যাকটি ইমপ্লিমেন্ট করুন। মেশিনটির উচিত কল করা পক্ষকে তার বর্তমান স্টেট জানিয়ে উত্তর দেওয়া।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. নতুন নম্বর কিউ করুন

`queue_new_number/1` ফাংশনটি এবং প্রয়োজনীয় `GenServer` কলব্যাকটি ইমপ্লিমেন্ট করুন।

এটির উচিত মেশিনের বর্তমান স্টেট নিয়ে `TakeANumberDeluxe.State.queue_new_number/1` ফাংশনটি কল করা।

`TakeANumberDeluxe.State.queue_new_number/1` যদি একটি `{:ok, new_number, new_state}` টাপল রিটার্ন করে, তাহলে মেশিনটির উচিত নতুন নম্বরটি কল করা পক্ষকে জানিয়ে উত্তর দেওয়া এবং নতুন স্টেটটিকে তার স্টেট হিসেবে সেট করা। আর যদি বদলে একটি `{:error, error}` টাপল রিটার্ন করে, তাহলে মেশিনটির উচিত এররটি কল করা পক্ষকে জানিয়ে উত্তর দেওয়া এবং তার স্টেট পরিবর্তন না করা।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. কিউতে থাকা পরের নম্বরটি সার্ভ করুন

`serve_next_queued_number/2` ফাংশনটি এবং প্রয়োজনীয় `GenServer` কলব্যাকটি ইমপ্লিমেন্ট করুন।

এটির উচিত মেশিনের বর্তমান স্টেট এবং এর দ্বিতীয় ঐচ্ছিক আর্গুমেন্ট `priority_number` নিয়ে `TakeANumberDeluxe.State.serve_next_queued_number/2` ফাংশনটি কল করা।

`TakeANumberDeluxe.State.serve_next_queued_number/2` যদি একটি `{:ok, next_number, new_state}` টাপল রিটার্ন করে, তাহলে মেশিনটির উচিত পরের নম্বরটি কল করা পক্ষকে জানিয়ে উত্তর দেওয়া এবং নতুন স্টেটটিকে তার স্টেট হিসেবে সেট করা। আর যদি বদলে একটি `{:error, error}` টাপল রিটার্ন করে, তাহলে মেশিনটির উচিত এররটি কল করা পক্ষকে জানিয়ে উত্তর দেওয়া এবং তার স্টেট পরিবর্তন না করা।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. স্টেট রিসেট করুন

`reset_state/1` ফাংশনটি এবং প্রয়োজনীয় `GenServer` কলব্যাকটি ইমপ্লিমেন্ট করুন।

এটির উচিত বর্তমান স্টেটের `min_number` ও `max_number` ব্যবহার করে নতুন একটি স্টেট তৈরি করতে `TakeANumberDeluxe.State.new/2` ফাংশনটি কল করা। মেশিনটির উচিত নতুন স্টেটটিকে তার স্টেট হিসেবে সেট করা। কল করা পক্ষকে উত্তর দেওয়া উচিত নয়।

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. অটো শাটডাউন ইমপ্লিমেন্ট করুন

মেশিন চালু করার অংশটি পরিবর্তন করুন। এটির উচিত `init_arg` হিসেবে পাঠানো কিওয়ার্ড লিস্টে `:auto_shutdown_timeout` কী-এর অধীন মানটি পড়া এবং সেটি `TakeANumberDeluxe.State.new/3`-এ তৃতীয় আর্গুমেন্ট হিসেবে পাঠানো। `:auto_shutdown_timeout` দেওয়া না থাকলে ডিফল্ট মান `:infinity` ব্যবহার করুন।

মেশিনের স্টেট রিসেট করার অংশটিও এমনভাবে পরিবর্তন করুন যাতে `TakeANumberDeluxe.State.new/3`-এ `auto_shutdown_timeout` পাঠানো হয়।

ইমপ্লিমেন্ট করা সব কলব্যাকের (`init/1` এবং সব `handle_*` কলব্যাক) রিটার্ন ভ্যালু পরিবর্তন করে একটি টাইমআউট সেট করুন। এর জন্য বর্তমান মেশিন স্টেটের `:auto_shutdown_timeout` কী-এর অধীন মানটি ব্যবহার করুন। `init/1`-এর `{:stop, reason}` রিটার্ন ভ্যালুতে টাইমআউট যোগ করবেন না; টাইমআউট কেবল সার্ভার তার রিসিভ লুপ শুরু করার পরেই প্রযোজ্য।

নির্দিষ্ট টাইমআউটের মধ্যে অন্য কোনো মেসেজ না পেলে মেশিনে যে `:timeout` মেসেজটি পাঠানো হবে, সেটি সামলাতে একটি `GenServer` কলব্যাক ইমপ্লিমেন্ট করুন। এটির উচিত `:normal` কারণ দেখিয়ে প্রসেসটি এক্সিট করা।

এছাড়া যেকোনো অপ্রত্যাশিত মেসেজ যেন উপেক্ষা করা হয়, সেদিকেও খেয়াল রাখুন।

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
