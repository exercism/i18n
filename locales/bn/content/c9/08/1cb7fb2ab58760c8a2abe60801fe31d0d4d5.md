# ভূমিকা

for লুপ বারবার কিছু লজিক চালানোর জন্য সবচেয়ে বেশি ব্যবহৃত স্টেটমেন্টগুলোর একটি।
JavaScript-এ এটি `for` কিওয়ার্ড, গোল বন্ধনীর মধ্যে মোড়া একটি _হেডার_ এবং কোঁকড়া বন্ধনীর মধ্যে মোড়া লুপের _বডি_ ধারণ করা একটি কোড ব্লক নিয়ে গঠিত।

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

ইনিশিয়ালাইজেশন সাধারণত একটি কাউন্টার ভ্যারিয়েবল সেট আপ করে, শর্তটি যাচাই করে লুপটি চালিয়ে যাওয়া উচিত নাকি থামানো উচিত, এবং স্টেপ প্রতিটি পুনরাবৃত্তির শেষে কাউন্টারটি বাড়ায়।
হেডারের বিভিন্ন অংশ সেমিকোলন দিয়ে আলাদা করা হয়।

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
