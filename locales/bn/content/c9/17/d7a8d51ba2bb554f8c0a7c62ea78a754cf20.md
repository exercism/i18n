# লিস্ট

`LIST{T}` হলো একটি কালেকশন, যা বাড়তে পারে এবং ক্রম মেনে চলে। এর পেছনে থাকে একটি অ্যারে, আর সেটি ভরে গেলে তার চেয়ে বড় একটি অ্যারে দিয়ে তা বদলে দেওয়া হয়।

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## অ্যারে নাকি লিস্ট?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| আকার | তৈরি হওয়ার সময় স্থির | বদলায় |
| অ্যাপেন্ড | নেই | আছে |
| রিমুভ | নেই | আছে |
| ইনডেক্সিং | `a[i]` | `l[i]` |
| ওভারহেড | নেই | একটি আকার, আর কিছু বাড়তি জায়গা |

আকার আগেই জানা আর স্থির হলে `ARRAY` ব্যবহার করুন, যেমন এক সারি নৃত্যশিল্পী বা এক সপ্তাহের গণনা। জিনিসপত্র আসে-যায় এমন কাজে `LIST` ব্যবহার করুন।

## ইন-প্লেস, ফাংশনাল নয়

`append`, `remove_index` আর `[i] :=` — এগুলো সবই লিস্টটিকেই বদলে দেয়। আলাদা করে কিছু ফেরত অ্যাসাইন করার দরকার নেই, আর কোনো রুটিনকে হাতে দেওয়া লিস্টও এর থেকে নিরাপদ নয়।

এটা `FMAP` আর `FSET`-এর ঠিক উল্টো, তাই হাতে কোনটা আছে সেটা পরিষ্কার থাকা ভালো। সহজ নিয়ম: নামের শুরুতে `F` থাকলে সেটি ফাংশনাল, আর বাকি সব জায়গার জিনিস বদল করে।

কেউ নষ্ট করতে না পারে এমন একটি লিস্ট দিতে চাইলে তার একটি কপি দিয়ে দিন:

```sather
   return notes.copy;
```

## অ্যাপেন্ড করার খরচ

অ্যাপেন্ড করা গড়ে সস্তা। পেছনের অ্যারেটি ভরে গেলে দ্বিগুণ আকারের একটি নতুন অ্যারে নেওয়া হয় আর সবকিছু কপি করা হয়। তাই বেশিরভাগ অ্যাপেন্ডে বিশেষ কোনো খরচ নেই, আর মাঝেমধ্যে একটি অ্যাপেন্ডে একটা কপির খরচ পড়ে। অনেকগুলো অ্যাপেন্ড একসাথে দেখলে গড়ে প্রতিটির পিছু একটি ধ্রুবক খরচ দাঁড়ায়; এজন্যই প্রতিবার এক করে বাড়ানোর বদলে দ্বিগুণ করা হয়।

`remove_index` কিন্তু সস্তা নয়: সরিয়ে ফেলা অবস্থানের পরের সবকিছু এক ঘর করে সরে যায়। লম্বা লিস্টের শুরু থেকে বারবার রিমুভ করলে কাজটি ধীর হয়ে যায়, আর সেটা খেয়াল না করার সম্ভাবনাই বেশি।

## কাজের রুটিন

| কল | কাজ |
| --- | --- |
| `l.append(x)` | শেষে যোগ করে |
| `l.insert_before(i, x)` | নির্দিষ্ট অবস্থানে যোগ করে |
| `l.remove_index(i)` | একটি অবস্থান সরিয়ে দেয় |
| `l.has(x)` | ভেতরে আছে কি? |
| `l.copy` | স্বতন্ত্র একটি কপি |
| `l.str` | বিষয়বস্তু, দ্বিতীয় বন্ধনীর ভেতরে |
| `l.elt!`, `l.ind!` | মানগুলো, কিংবা অবস্থানগুলো ধরে ধরে ঘোরে |
