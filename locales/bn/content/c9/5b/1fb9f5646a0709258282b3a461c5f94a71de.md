# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার   | টাইপ    | বিবরণ                                            |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | ইনপুট     | ইন্টিজার | যাচাই করার বছর                                   |
| `$v0`    | আউটপুট    | বুলিয়ান | ইনপুটটি অধিবর্ষ (`0` = `false`, `1` = `true`)    |
| `$t0-9`  | অস্থায়ী   | যেকোনো  | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত                   |
