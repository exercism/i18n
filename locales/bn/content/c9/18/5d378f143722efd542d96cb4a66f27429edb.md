# সম্পর্কে

Gleam-এ রেগুলার এক্সপ্রেশন **PCRE** স্পেসিফিকেশন (**P**erl **C**ompatible **R**egular **E**xpressions, অর্থাৎ পার্ল-সামঞ্জস্যপূর্ণ রেগুলার এক্সপ্রেশন) মেনে চলে, Java, JavaScript বা Ruby-এর মতো অন্যান্য জনপ্রিয় ভাষার মতোই।

`gleam/regex` মডিউলে রেগুলার এক্সপ্রেশন নিয়ে কাজ করার ফাংশন রয়েছে।

~~~~exercism/note
এই অনুশীলনীতে ধরে নেওয়া হয়েছে যে আপনি রেগুলার এক্সপ্রেশনের সিনট্যাক্স আগে থেকেই জানেন, যার মধ্যে ক্যারেক্টার ক্লাস, কোয়ান্টিফায়ার, গ্রুপ এবং ক্যাপচার অন্তর্ভুক্ত।

আপনার রেগুলার এক্সপ্রেশনের জ্ঞান ঝালিয়ে নিতে চাইলে এই সোর্সগুলোর যেকোনো একটি দেখে নিতে পারেন: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/)।
~~~~

রেগুলার এক্সপ্রেশন তৈরির সবচেয়ে কমন উপায় হলো `regex.from_string` ফাংশনটি ব্যবহার করা।

```gleam
let assert Ok(re) = regex.from_string("test")
```

`regex.from_string` ফাংশনটি রেগুলার এক্সপ্রেশনের সিনট্যাক্স অবৈধ হলে একটি `Error` দেয়, তাই এখানে একটি let-assertion ব্যবহার করা হয়েছে, যাতে রেগুলার এক্সপ্রেশনটি বৈধ কিনা তা নিশ্চিত হওয়া যায়।

`regex.check` ফাংশনটি দিয়ে একটি রেগুলার এক্সপ্রেশন কোনো স্ট্রিং-এর সাথে মেলে কিনা যাচাই করা যায়।

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## ক্যাপচার

একটি রেগুলার এক্সপ্রেশন দিয়ে সাবস্ট্রিং ক্যাপচার করতে চাইলে, ম্যাচের একটি অ্যারে রিটার্ন করতে `regex.scan` ফাংশনটি ব্যবহার করা যায়।

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## মডিফায়ার

`regex.compile` ফাংশন দিয়ে রেগুলার এক্সপ্রেশন তৈরি করার সময় অপশন পাস করলে তার আচরণ পরিবর্তন করা যায়।

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
