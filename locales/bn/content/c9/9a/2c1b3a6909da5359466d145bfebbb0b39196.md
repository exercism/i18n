# পরিচিতি

## Let

`let` এক্সপ্রেশনটি একটি লোকাল স্কোপ তৈরি করতে ব্যবহৃত হয়, আর এটি কয়েকটি পরিস্থিতিতে কাজে লাগে:

- এক্সপ্রেশন সহজ করার জন্য
- মধ্যবর্তী এক্সপ্রেশনের ফলাফলের নাম দেওয়ার জন্য
- কোনো এক্সপ্রেশন বড় হয়ে উঠলে সেটিকে ছোট ছোট টুকরোয় ভাগ করার জন্য

`let` এক্সপ্রেশনের ভেতরে আপনি বেশিরভাগ কাজই করতে পারেন, যার মধ্যে ডিস্ট্রাকচারিংও পড়ে (এটি নিয়ে আরও বিস্তারিত থাকবে পরের অনুশীলনীগুলোতে), তবে নতুন কোনো Custom Type বা Type Alias ডিফাইন করা সম্ভব নয়।

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
