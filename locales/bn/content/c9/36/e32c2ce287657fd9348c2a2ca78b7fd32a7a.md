# পরিচিতি

R-এ একটি `vector` হলো একই `type`-এর মানের একটি সংগ্রহ: `numeric`, `character` ইত্যাদি। মিশ্র ইনপুট দিলে R চুপচাপ সেগুলোকে একটি কমন টাইপে, সাধারণত `character`-এ, রূপান্তর করে ফেলে, যার ফলে অপ্রত্যাশিত ফলাফল আসতে পারে।

```R
v <- c(2, 5.4, "txt")
v
#> [1] "2"   "5.4" "txt"
typeof(v)
#> [1] "character"
```

## ভেক্টর তৈরি করা

আপনার কাছে যদি সব মান আগে থেকেই থাকে, তাহলে `c()` ব্যবহার করুন ("concatenate" বা "combine"-এর সংক্ষিপ্ত রূপ):

```R
x <- 10
v <- c(4, 7, x)
```

`c()` ফাংশনটি খুব নমনীয়, আর ইনপুটে অন্য ভেক্টর ও রেঞ্জও থাকতে পারে।
`c()` যেকোনো সংখ্যক ও যেকোনো ধরনের ইনপুট নিতে পারে, এবং সেগুলোকে ফ্ল্যাট করে একটি একক ভেক্টরে পরিণত করে।

## রেঞ্জ, সিকোয়েন্স, পুনরাবৃত্তি

পরপর মানের একটি রেঞ্জের জন্য (ক্রমবর্ধমান বা ক্রমহ্রাসমান) আপনি `:` নোটেশন ব্যবহার করতে পারেন

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

`seq()` ফাংশনটি আরও সূক্ষ্ম নিয়ন্ত্রণ দেয়:

```R
# specify step size
seq(2, 11, by = 3) # c(2, 5, 8, 11)

# specify number of values, evenly-spaced
seq(2.5, 4, length.out = 5) # c(2.500, 2.875, 3.250, 3.625, 4.000) 
```

কয়েকটি রেঞ্জ আগে থেকেই বিল্ট-ইন কনস্ট্যান্ট হিসেবে সংজ্ঞায়িত:

```R
letters  # LETTERS is the UPPERCASE equivalent
#> [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q" "r" "s" "t" "u" "v" "w" "x" "y" "z"

month.name
#> [1] "January"   "February"  "March"     "April"     "May"       "June"      "July"      "August"   
#> [9] "September" "October"   "November"  "December" 

month.abb
#> [1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

## গাণিতিক অপারেশন

অপারেশনগুলো স্বয়ংক্রিয়ভাবে ভেক্টরের প্রতিটি এলিমেন্টে আলাদা আলাদাভাবে প্রয়োগ হয়।
অন্য ভাষায় কমন লুপ, লিস্ট কম্প্রিহেনশন আর রিকার্শনের এখানে দরকার নেই, এবং (*পারফরম্যান্সের কারণে*) সাধারণত এগুলো এড়িয়ে চলাই উচিত।

```R
2 + 1:3 # c(3, 4, 5)
2 * 1:3 # c(2, 4, 6)
12 / 1:3 # c(12  6  4)
2 ^ (1:3) # c(2, 4, 8) : exponentiation, precedence order here needs ()
```

ভেক্টরের জোড়াও এলিমেন্ট ধরে ধরে কাজ করে:

```R
v <- 1:3
w <- 5:7

v + w
#> [1]  6  8 10

v * w
#> [1]  5 12 21

v ^ w
#> [1]    1   64 2187
```

## ভেক্টরের এলিমেন্ট অ্যাক্সেস করা

অনেক ভাষার মতোই, আমরা বন্ধনীর ভেতরে ইনডেক্স ব্যবহার করতে পারি:

```R
v <- 4:7
v[2]
#> [1] 5
v[2:4]
#> [1] 5 6 7
```

কিন্তু সাবধান: ***R ডিফল্টভাবে ১-ভিত্তিক ইনডেক্সিং ব্যবহার করে***।

বৈজ্ঞানিক ভাষায় (Fortran, Matlab, Julia) এটি কমন, কিন্তু C ও তার উত্তরসূরি অনেক ভাষার শূন্য-ভিত্তিক ইনডেক্সিংয়ের থেকে এটি আলাদা।

রেঞ্জ ব্যবহার করা যায়, উপরের উদাহরণের মতোই, তবে অত্যন্ত নমনীয় `c()` ফাংশনেও:

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`-কে (R-এর বেশিরভাগ জিনিসের মতোই) পরিবর্তনযোগ্য হিসেবে ব্যবহার করা যায়, এক বা একাধিক এলিমেন্টে লিখতে একই রকম নমনীয় সিনট্যাক্স ব্যবহার করা যায়:

```R
v <- 1:10
v[2] <- 42
v[4:6] <- c(11, 12, 13)
v
#> [1]  1 42  3 11 12 13  7  8  9 10
```

## ঋণাত্মক ইনডেক্স

অন্য ভাষার সাথে পরিচিত প্রোগ্রামাররা হয়তো ভাবতে পারেন যে `v[-1]` ভেক্টরের শেষ এলিমেন্টটি অ্যাক্সেস করার একটি উপায়।
*ভুল!*
সেজন্য `tail(v, n=1)` ব্যবহার করুন।

ঋণাত্মক ইনডেক্স আসলে একটি এলিমেন্ট ***বাদ দেওয়ার*** উপায়, যা একটি ছোট ভেক্টর রিটার্ন করে:

```R
v <- c(2, 4, 6)
v[-2]
#> [1] 2 6  # second element gone
```

## ভেক্টরে শর্ত প্রয়োগ

একটি ভেক্টরে তুলনা প্রয়োগ করলে সমান দৈর্ঘ্যের একটি বুলিয়ান ভেক্টর রিটার্ন হয়।
`all()` আর `any()`-এর মতো ফাংশনের ভেতরে এটি খুব সুবিধাজনক হতে পারে:

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

আরও জটিল লজিক্যাল এক্সপ্রেশনের জন্য `&` ও `|` অপারেটর ব্যবহার করা জরুরি, কারণ এগুলো ভেক্টরে কাজ করে।
দুই অক্ষরের `&&` আর `||` কেবল একক মান তুলনার জন্য।

```R
v %% 2 == 0 & v > 5
#> [1] FALSE FALSE  TRUE
```
