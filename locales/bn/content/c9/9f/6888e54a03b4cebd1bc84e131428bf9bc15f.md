# জ্বালানি ট্রান্সফরমেশন JSON

## সমস্যার বিবরণ

ABC Corp-এর প্রতিটি কর্মী সীমাহীন জ্বালানি ভাতা পান। কর্মীরা প্রতিবার তাদের গাড়িতে জ্বালানি ভরলে একটি রেকর্ড পাঠাতে হয়। এই রেকর্ডগুলো একই JSON ফাইলে যুক্ত হয় এবং মাসের শেষে প্রক্রিয়া করা হয়।

ডিজিটাল অপারেশন্স টিমের একজন সদস্য হিসেবে আপনার কাজ হলো এই JSON ফাইলটি পড়া এবং ফলাফলগুলো আরেকটি JSON ফাইলে লেখা। আউটপুট ফাইলে প্রতিটি কর্মীর জন্য নিচের তথ্যগুলো নিয়ে একটি এন্ট্রি থাকা উচিত:

- কর্মীর নম্বর
- জ্বালানি ভরার সংখ্যা
- মোট জ্বালানি খরচ
- মোট গ্যালন
- মোট অর্জিত মাইল

আপনাকে দুটি `string` আর্গুমেন্ট দেওয়া হয়।

1. ইনপুট JSON ফাইলের পাথ।
1. আউটপুট JSON ফাইলের পাথ।

ইনপুট JSON ফাইলে JSON অবজেক্টের একটি অ্যারে থাকে। প্রতিটি JSON অবজেক্টের রূপ নিচের মতো।


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

আপনার কাজ হলো JSON ইনপুটকে নিচের JSON ফরম্যাটে রূপান্তর করা এবং বিষয়বস্তুটি দেওয়া পাথে লেখা। আউটপুট ফাইলে প্রতিটি কর্মীর জন্য একটি এন্ট্রি থাকা উচিত, যা `employeeId` অনুসারে ঊর্ধ্বক্রমে সাজানো।

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## সীমাবদ্ধতা

- ইনপুট JSON ফাইলে ফিল-আপ রেকর্ডের সংখ্যা `n`: 0 <= n <= 1000
- কোম্পানিতে কর্মীর সংখ্যা: 97
- জ্বালানির দাম প্রতি গ্যালন হিসেবে ধরা হয়
- কোনো ফিল-আপ রেকর্ড বাদ পড়ে না

## ইঙ্গিত

- JSON ফাইল পড়তে/লিখতে [`ballerina/io` মডিউল](https://lib.ballerina.io/ballerina/io/latest) ব্যবহার করুন।
- টাইপ-সেফ পদ্ধতিতে ডেটা নিয়ে কাজ করতে JSON মানগুলোকে অ্যাপ্লিকেশন-নির্দিষ্ট টাইপে রূপান্তর করুন। তথ্যের জন্য Ballerina By Examples (BBE)-তে [Converting to user defined type example](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) দেখুন।

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- কোডের বাহুল্য কমাতে [রেকর্ড ডিস্ট্রাকচারিং](https://ballerina.io/learn/by-example/destructure-records-using-query) কাজে লাগতে পারে।

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- একটি মাত্র এক্সপ্রেশন আছে এমন ফাংশনের জন্য এক্সপ্রেশন-বডিড ফাংশন ব্যবহার করুন। যেমন, যে ফাংশনে কেবল রিটার্ন স্টেটমেন্ট আছে।

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
