# ফ্লোটিং পয়েন্ট সংখ্যা

PHP-তে বাস্তব সংখ্যার একটি উপসেট প্রকাশ করতে ফ্লোটিং পয়েন্ট সংখ্যা ব্যবহার করা হয়।
এগুলো এক বা একাধিক অঙ্ক দিয়ে শুরু হয়, যেগুলো একটি দশমিক বিভাজক দিয়ে আলাদা করা হয়।

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## কমন বিপদ

সব সংখ্যা ও গাণিতিক অপারেশন ফ্লোটিং পয়েন্ট সংখ্যা দিয়ে করা যায় না।
ডলার ও সেন্ট প্রকাশ করতে ফ্লোটিং পয়েন্ট সংখ্যা ব্যবহার করলে রাউন্ডিং এরর হতে পারে।

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
