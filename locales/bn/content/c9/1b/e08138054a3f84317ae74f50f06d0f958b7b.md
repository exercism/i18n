# টেস্ট

## টেস্ট চালানো

টেস্টগুলো চালাতে নিচের কমান্ডটি চালান:

```bash
dotnet test
```

সোর্স ফাইল পরিবর্তন হওয়ার সাথে সাথে স্বয়ংক্রিয়ভাবে টেস্ট চালাতে নিচের কমান্ডটি চালান:

```bash
dotnet watch test
```

## অনুশীলনী সমাধান করা

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো। ডিফল্টভাবে, আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) চালানো হয়। এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন। একবার সেটি পাস করলে, টেস্টের `[Fact]` বা `[Theory]` অ্যাট্রিবিউট থেকে `Skip = "Remove this Skip property to run this test"` সরিয়ে দিয়ে আপনি পরের টেস্টটি সক্রিয় করতে পারেন। যখন সব টেস্ট সক্রিয় করা হবে এবং আপনার ইমপ্লিমেন্টেশন সেগুলোর সবগুলো পাস করাবে, তখন আপনি অনুশীলনীটি সমাধান করে ফেলবেন!

শুরু করার সুবিধার জন্য প্রতিটি অনুশীলনীর সাথে একটি স্টাব ইমপ্লিমেন্টেশন ফাইল দেওয়া থাকে। নিজের সমাধান গড়ে তোলার সূচনা বিন্দু হিসেবে আপনি এই ফাইলটি ব্যবহার করতে পারেন। এটি করাই ঠিক মনে হলে নির্দ্বিধায় ফাইলটি মুছে ফেলুন বা পরিবর্তন করুন।

## প্যাকেজ ব্যবহার করা

বেশিরভাগ অনুশীলনী আপনি বাইরের কোনো প্যাকেজ ব্যবহার না করেই সমাধান করতে পারবেন। তবে যে অনুশীলনীগুলোতে আপনি সত্যিই বাইরের একটি প্যাকেজ ব্যবহার করতে চান, সেগুলোর জন্য নিচের কমান্ডটি চালিয়ে সেটি আপনার প্রজেক্টে যোগ করতে পারেন:

```bash
dotnet add package [package-name]
```
