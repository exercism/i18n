# প্রস্তাবিত শেখার রিসোর্স

ColdFusion (CFML) শেখায় আপনাকে স্বাগতম! CFML হলো একটি ডাইনামিক ও লুজলি টাইপড JVM স্ক্রিপ্টিং ভাষা। এর দুই ধরনের ফাইল থাকে। `.cfm` ফাইল (ColdFusion markup) সম্পূর্ণ প্রসিডিউরাল, আর এগুলো HTML টেমপ্লেট বানানোর জন্য ট্যাগ-ভিত্তিক সিনট্যাক্স ব্যবহার করে। ওয়েবসাইট বানালে ভিউয়ের জন্য আপনি এগুলো ব্যবহার করবেন:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

অন্য ধরনের ফাইলটি হলো `.cfc` (ColdFusion Component), আর এই দিয়েই আপনি একটি ক্লাস ডিক্লেয়ার করেন। কম্পোনেন্ট ব্যবহৃত হয় বিজনেস লজিক, মডেল আর কন্ট্রোলারের জন্য। এগুলো সাধারণত স্ক্রিপ্ট সিনট্যাক্স ব্যবহার করে, যা পড়তে JavaScript-এর মতো লাগে।

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```

CFML সম্পর্কে আরও জানার জন্য এখানে কিছু গাইড রইল।
