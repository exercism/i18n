# নির্দেশনা

এই অনুশীলনীতে আপনাকে ক্লাসিক গেম Pac-Man-এর কয়েকটি নিয়ম Haskell ফাংশনে রূপান্তর করতে হবে।

রূপান্তর করার জন্য আপনার কাছে চারটি নিয়ম আছে, যেগুলো সবই গেম স্টেটের সাথে সম্পর্কিত।

> আর্গুমেন্টগুলো কীভাবে তৈরি হয় তা নিয়ে চিন্তা করবেন না, শুধু আর্গুমেন্টগুলো একত্র করে কাঙ্ক্ষিত ফলাফল রিটার্ন করাই লক্ষ্য রাখুন।

## 1. Pac-Man ভূত খায় কি না তা ডিফাইন করুন

`eatsGhost` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man ভূত স্পর্শ করছে কি না_) এবং Pac-Man ভূতটি খেতে সক্ষম হলে একটি `Bool` মান রিটার্ন করে।
ফাংশনটি কেবল তখনই `True` রিটার্ন করা উচিত যখন Pac-Man-এর পাওয়ার পেলেট সক্রিয় থাকে এবং Pac-Man ভূত স্পর্শ করছে।

```haskell
eatsGhost False True
-- -> False
```

## 2. Pac-Man স্কোর করে কি না তা ডিফাইন করুন

`scores` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয় (_Pac-Man একটি পাওয়ার পেলেট স্পর্শ করছে কি না_ এবং _Pac-Man একটি ডট স্পর্শ করছে কি না_) এবং Pac-Man স্কোর করলে একটি `Bool` মান রিটার্ন করে।
Pac-Man একটি পাওয়ার পেলেট বা একটি ডট স্পর্শ করলে ফাংশনটির `True` রিটার্ন করা উচিত।

```haskell
scores True True
-- -> True
```

## 3. Pac-Man হেরে যায় কি না তা ডিফাইন করুন

`loses` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man ভূত স্পর্শ করছে কি না_) এবং Pac-Man হেরে গেলে একটি `Bool` মান রিটার্ন করে।
Pac-Man যখন একটি ভূত স্পর্শ করছে এবং তার কোনো পাওয়ার পেলেট সক্রিয় নেই, তখন ফাংশনটির `True` রিটার্ন করা উচিত।

```haskell
loses False True
-- -> True
```

## 4. Pac-Man জিতে যায় কি না তা ডিফাইন করুন

`wins` ফাংশনটি ডিফাইন করুন, যেটি তিনটি আর্গুমেন্ট নেয় (_Pac-Man সব ডট খেয়ে ফেলেছে কি না_, _Pac-Man-এর পাওয়ার পেলেট সক্রিয় আছে কি না_, এবং _Pac-Man ভূত স্পর্শ করছে কি না_) এবং Pac-Man জিতে গেলে একটি `Bool` মান রিটার্ন করে।
Pac-Man সব ডট খেয়ে ফেললে _এবং_ ৩ নম্বর অংশে ডিফাইন করা আর্গুমেন্ট অনুসারে হেরে না গেলে ফাংশনটির `True` রিটার্ন করা উচিত।

```haskell
wins False True False
-- -> False
```
