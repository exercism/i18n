# নির্দেশাবলি

Lucian-এর প্রেমিকা বাড়ি ফিরছেন, অথচ Lucian তাদের বিবাহবার্ষিকীর রাতের খাবার এখনো রান্না করেননি!

এই অনুশীলনীতে, আপনি Lucian-কে তার প্রিয় রান্নার বই থেকে একটি অসাধারণ লাসানিয়া রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার চারটি কাজ আছে, সবগুলোই লাসানিয়া রান্নায় ব্যয় হওয়া সময়ের সঙ্গে সম্পর্কিত।

## 1. ওভেনে রাখার প্রত্যাশিত সময় মিনিটে ডিফাইন করুন

`Lasagna.ExpectedMinutesInOven()` মেথডটি ডিফাইন করুন, যেটি কোনো প্যারামিটার নেয় না এবং লাসানিয়া ওভেনে কত মিনিট থাকা উচিত তা রিটার্ন করে। রান্নার বই অনুযায়ী, প্রত্যাশিত ওভেন-সময় মিনিটে ৪০:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. ওভেনে বাকি থাকা সময় মিনিটে হিসাব করুন

`Lasagna.RemainingMinutesInOven()` মেথডটি ডিফাইন করুন, যেটি প্যারামিটার হিসেবে লাসানিয়া ওভেনে যত মিনিট ধরে আছে তা নেয় এবং আগের কাজের প্রত্যাশিত ওভেন-সময় মিনিটের ভিত্তিতে লাসানিয়াকে আরও কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`Lasagna.PreparationTimeInMinutes()` মেথডটি ডিফাইন করুন, যেটি প্যারামিটার হিসেবে লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন তার সংখ্যা নেয় এবং প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে ধরে নিয়ে লাসানিয়া প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন তা রিটার্ন করে।

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. অতিবাহিত সময় মিনিটে হিসাব করুন

`Lasagna.ElapsedTimeInMinutes()` মেথডটি ডিফাইন করুন, যেটি দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসানিয়ায় আপনি যোগ করা স্তরের সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসানিয়া ওভেনে যত মিনিট ধরে আছে তার সংখ্যা। ফাংশনটি রিটার্ন করবে আপনি লাসানিয়া রান্না করতে কত মিনিট ব্যয় করেছেন, যা মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
