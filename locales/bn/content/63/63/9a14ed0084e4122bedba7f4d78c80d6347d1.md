# Elm সিনট্যাক্সের মৌলিক বিষয় ২

## ফাংশন এক্সপোর্ট করা

ফাংশন এক্সপোর্ট করা নিয়ে প্রথম কনসেপ্টেই আলোচনা করা হয়েছে, এখানে সংক্ষেপে সেটি আবার ঝালিয়ে নেওয়া যাক।

Elm-এ প্রতিটি ফাইল একটি মডিউল, আর অন্য সব কোডের আগে অবশ্যই একটি `module` স্টেটমেন্ট থাকতে হবে।

মডিউলের নাম অবশ্যই তার ফাইলের নামের সাথে মিলতে হবে, অর্থাৎ `Calculator` মডিউলটি থাকতে হবে Calculator.elm ফাইলে, আর `Parser.Utils` মডিউলটি থাকতে হবে Parser/Utils.elm ফাইলে।

একটি মডিউলের ভেতরে যা কিছু ডিফাইন করা হয়, তা কেবল ওই মডিউলের মধ্যেই সীমাবদ্ধ থাকে এবং `exposing`-এ উল্লেখ না থাকলে মডিউলের বাইরে থেকে তা অ্যাক্সেস করা যায় না।

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## অন্য মডিউল থেকে ফাংশন ইমপোর্ট করা

অন্য মডিউলে ডিফাইন করা ফাংশন অ্যাক্সেস করা হয় ইমপোর্টের মাধ্যমে।
ওই মডিউল ইমপোর্ট করলে মডিউলটি যে ফাংশনগুলো এক্সপোজ করেছে, তার সবগুলোই অ্যাক্সেসযোগ্য হয়ে যায়।
তবে সেগুলো কীভাবে অ্যাক্সেস করা যায়, তা নির্ভর করে মডিউলটি কীভাবে ইমপোর্ট করা হয়েছে তার উপর।

কোয়ালিফায়েড ইমপোর্ট ডিফল্ট, আর এমন মডিউলের ভেতরের কোনো ফাংশন (যেমন `List` মডিউলের `map` ফাংশন) অ্যাক্সেস করতে মডিউলের নাম আগে বসাতে হয় (`List.map`)।

ওপেন ইমপোর্ট ওই মডিউলের এক্সপোজ করা ফাংশনগুলো সরাসরি অ্যাক্সেস করার সুযোগ দেয়, কোনো প্রিফিক্স ছাড়াই। এটি করা হয় `exposing` কিওয়ার্ড দিয়ে, এক্সপোর্টে ব্যবহৃতটির ঠিক উল্টো। আপনি সব ফাংশন (`..` দিয়ে), আবার নির্দিষ্ট কিছু ফাংশনও (যেমন `map`) এক্সপোজ করতে পারেন।

আপনি অন্য মডিউল থেকে টাইপ এবং তাদের কনস্ট্রাক্টরও ইমপোর্ট করতে পারেন, যা পরের কোনো কনসেপ্টে আলোচনা করা হয়েছে।

স্পষ্টতা বজায় রাখতে এবং নামের সংঘর্ষ এড়াতে কোয়ালিফায়েড ইমপোর্টকেই প্রাধান্য দেওয়া হয়।

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## টাইপ অ্যানোটেশন

টাইপ অ্যানোটেশন ডিফাইন করা হয় `name : parameter types -> return type` দিয়ে, যেখানে প্যারামিটারের টাইপগুলোও `->` দিয়ে আলাদা করা হয়।

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

ফাংশনের প্যারামিটার ডিফাইন করতে বন্ধনী ব্যবহার করা যায় (প্যারামিটারগুলো নিজেরাও একই সিনট্যাক্সে ডিফাইন করা হয়, তাই বন্ধনীর প্রয়োজন হয়)।

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## সংখ্যা

Elm-এ দুই ধরনের সংখ্যা পাওয়া যায়, যেগুলো `Int` ও `Float` টাইপ দিয়ে নির্ধারিত হয়।
`Int` বলতে ধনাত্মক ও ঋণাত্মক ইন্টিজারের সেট বোঝায়।
`Float` বলতে বাস্তব সংখ্যার সেট বোঝায়, যা কম্পিউটারের প্রিসিশনের মধ্যে সীমাবদ্ধ।
সংখ্যার উপর ডিফাইন করা অপারেশনগুলো সাধারণত এক ধরনের টাইপেই কাজ করে, দুটো মিশিয়ে নয়।
দুটোর মধ্যে রূপান্তর করার ফাংশনও আছে, যেমন `toFloat`, যা `Int`-কে `Float`-এ রূপান্তর করে, আর `round`, `floor`, `ceiling` বা `truncate`, যেগুলো ভিন্ন ভিন্ন সেমান্টিক্সে একটি `Float`-কে `Int`-এ রূপান্তর করে।

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## স্ট্রিং অপারেশন

কোডে শব্দ ও বাক্য বোঝাতে Elm-এ আছে নেটিভ `String` টাইপ।
স্ট্রিং লিটারেল লেখা হয় ডাবল কোটেশনের ভেতরে, যেমন `"Hello World!"`।
স্ট্রিং কনক্যাটেনেশন অপারেটর `++` এবং সমতা অপারেটর `==` ডিফল্টভাবেই পাওয়া যায়।

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

বাকি বেশিরভাগ স্ট্রিং ফাংশন আছে `String` মডিউলে, যেটি ইমপোর্ট করতে হয়।

https://package.elm-lang.org/packages/elm/core/latest/String
