# ভূমিকা

`Result` টাইপ একটি ফাংশনকে একটি একক মান রিটার্ন করা সম্ভব করে, যা নিচের সবকিছু নির্দেশ করে:
- অপারেশনটি সফল হয়েছে নাকি ব্যর্থ হয়েছে
- সফল হলে, অপারেশনের ফলস্বরূপ মান
- ব্যর্থ হলে, ব্যর্থতার কারণ

## ব্যবহার

`Result` টাইপ একটি জেনেরিক টাইপ, যার ভিতরে দুটি অন্তর্নিহিত টাইপ থাকে:
- সফল অপারেশনে ফলাফল মানের টাইপ
- ব্যর্থতায় এররের টাইপ

`Result` টাইপটি একটি [ডিসক্রিমিনেটেড ইউনিয়ন][discriminated-union]-ও, যার নিচের কেসগুলো থাকতে পারে:
* `Ok <value>` যা একটি সফল ফলাফল বোঝায়
* `Error <reason>` যা একটি ব্যর্থতা বোঝায়

নিচের ফাংশনটি দেখায় কীভাবে একটি `Result` মান তৈরি করতে হয়:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

এই উদাহরণে, `Ok` মানটি একটি স্ট্রিং (প্রদত্ত নাম), আর `Error` মানটিও একটি স্ট্রিং (এররের কারণ, মানুষের পড়ার উপযোগী রূপে)।

## একটি `Result` মানের বিষয়বস্তু পড়া

নিচের টাইপ ডেফিনিশন ও ফাংশন সিগনেচারটি খেয়াল করুন:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

`openFile` ফাংশনটি কল করা কোড প্যাটার্ন ম্যাচিং ব্যবহার করে সফল ও ব্যর্থ কেসগুলো সামলাতে পারে, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
