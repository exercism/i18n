# পরিচিতি

এটি `PHP 8.0.0` থেকে পাওয়া যায়। **ইউনিয়ন টাইপ ডিক্লারেশন** একটি নির্দিষ্ট টাইপের বদলে একাধিক ভিন্ন টাইপের মান গ্রহণ করে। ইউনিয়ন টাইপ ডিফাইন করার সময় টাইপগুলো আলাদা করতে পাইপ (`|`) ব্যবহার করা হয়।

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

স্ট্রিক্ট মোডে ইনকামিং প্যারামিটারগুলো `float` বা `int` না হলে PHP একটি `TypeError` থ্রো করবে। নন-স্ট্রিক্ট মোডে ইনকামিং প্যারামিটারগুলোকে `float` বা `int`-এ রূপান্তর করা না গেলে একটি টাইপ এরর থ্রো করা হবে।

একইভাবে, ফাংশনটি ডিক্লেয়ার করা টাইপগুলোর একটি রিটার্ন না করলে, রানটাইমে PHP একটি `TypeError` থ্রো করবে।
