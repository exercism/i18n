# বুলিয়ান

কিছু প্রশ্নের উত্তর মাত্র দুটো: হ্যাঁ বা না। এমন উত্তরের জন্য Sather-এর টাইপ হলো `BOOL`, আর দুটি উত্তর লেখা হয় `true` আর `false`।

```sather
   ready : BOOL is
      return true;
   end;
```

## তুলনা করা

দুটি সংখ্যার তুলনা করলে একটি `BOOL` পাওয়া যায়।

| অপারেটর | যা জিজ্ঞেস করে |
| --- | --- |
| `=` | দুটো কি একই? |
| `/=` | দুটো কি আলাদা? |
| `<` | বাম দিকেরটি কি ছোট? |
| `<=` | ছোট, নাকি একই? |
| `>` | বাম দিকেরটি কি বড়? |
| `>=` | বড়, নাকি একই? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

লক্ষ্য করুন, `=` একটি প্রশ্ন করে। কোনো কিছুর *ভেতরে* একটি মান বসানোকে বোঝায় `:=`, যা আপনি আগেই দেখেছেন, আর এই দুটি এক নয়।

## একত্র করা

তিনটি অপারেটর ছোট ছোট প্রশ্ন থেকে বড় প্রশ্ন তৈরি করে।

`and` তখনই ট্রু, যখন **দুই** দিকই ট্রু।

```sather
harness_on and rope_checked
```

`or` তখনই ট্রু, যখন **যেকোনো** একটি দিক ট্রু, অথবা দুটিই ট্রু।

```sather
mat_below or net_below
```

`~` একটি উত্তর উল্টে দেয়: এটি ট্রু-কে ফলস আর ফলস-কে ট্রু করে দেয়।

```sather
~ready       -- true exactly when ready is false
```

`and` আর `or` দুটি উত্তরের মাঝখানে বসে; `~` বসে একটির সামনে।
