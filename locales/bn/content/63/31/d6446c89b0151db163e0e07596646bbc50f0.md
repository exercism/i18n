# রিসোর্স

## সাহায্য পাওয়া

1. [The Emacs Wiki](http://emacswiki.org/) অমূল্য। এখানে অনেক সময় কাটান।
2. [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) হলো GNU Emacs-এর অফিসিয়াল ম্যানুয়াল।
3. IRC - [Libera.Chat](https://libera.chat/)-এ `#emacs`, `#org-mode` এবং আরও অনেক Emacs প্যাকেজের চ্যানেল আছে, আর আশেপাশে আছেন অনেক সহায়ক মানুষ। আর Emacs-এ IRC ঠিক `M-x erc`-এর মতোই কাছে।
4. Matrix - [Matrix](https://matrix.org/)-এ [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) এবং অন্যান্য Emacs প্যাকেজের রুম আছে। কোন কোন চ্যানেল পাওয়া যায় তার একটি ধারণা পেতে আপনি [Emacs Matrix স্পেসে যোগ দিতে](https://matrix.to/#/#emacs-space:matrix.org) পারেন। Emacs-এর ভেতর থেকেই Matrix-এ যোগ দিতে চাইলে [Ement.el](https://github.com/alphapapa/ement.el) প্যাকেজটি ব্যবহার করতে পারেন।
5. আপনার সমস্যাটি খুঁজতে এবং সেটির উত্তর আগেই দেওয়া হয়েছে কি না দেখতে [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) আর [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) ব্যবহার করতে পারেন। আপনি প্রশ্নও করতে পারেন, আবার উত্তরও দিতে পারেন।
