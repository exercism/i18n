# নির্দেশনা

আপনি একটি ফিল্ড গাইড বানাচ্ছেন: প্রাণীর নাম থেকে তার বাসস্থানের একটি ম্যাপ।

পাঁচটি কাজই `FIELD_GUIDE` ক্লাসে থাকবে।

## 1. এটি কি গাইডে আছে?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. এটি কোথায় থাকে?

কোনো প্রাণীর জন্য রেকর্ড করা বাসস্থানটি রিটার্ন করুন। গাইড যদি এর নাম কখনও না শুনে থাকে, তবে `"Unknown"` রিটার্ন করুন।

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. একটি এন্ট্রি যোগ করুন

আরও একটি প্রাণীসহ গাইডটি রিটার্ন করুন। আগে থেকে তালিকায় থাকা প্রাণীর বাসস্থান প্রতিস্থাপিত হয়ে যায়।

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

এটি যা-ই ফিরিয়ে দিক, এরপর থেকে সেটিই হলো ব্যবহার করার গাইড। সম্পূর্ণ খালি একটি গাইডে যোগ করলেও কাজ করে এবং একটিমাত্র প্রাণীসহ একটি গাইড পাওয়া যায়।

## 4. কতটি প্রাণী?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. কোন কোন বাসস্থান?

গাইডে উল্লেখ থাকা বাসস্থানগুলোর সেটটি রিটার্ন করুন। একাধিক প্রাণী একটি বাসস্থান শেয়ার করতে পারে, তবে সেটি যেন একবারই আসে।

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
