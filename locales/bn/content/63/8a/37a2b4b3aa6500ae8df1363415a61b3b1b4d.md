# নির্দেশাবলি

মেলবোর্নের ট্রামগুলো জোন অনুযায়ী ভাড়া নেয়, আর শহরের কেন্দ্রটি সম্পূর্ণ ফ্রি। আপনি টিকিট মেশিনের জন্য ভাড়ার নিয়মগুলো লিখছেন। সব ভাড়া সেন্টে হিসাব করা হয়।

চারটি কাজই `TRAM_FARES` ক্লাসে রাখতে হবে।

## 1. একটি জোনের ভাড়া

জোন ০ হলো ফ্রি ট্রাম জোন, এর কোনো খরচ নেই। জোন ১-এর ভাড়া ৫৫০। জোন ২-এর ৩৭০। অন্য যেকোনো সংখ্যা আদৌ ট্রাম জোন নয়, তাই এরও কোনো খরচ নেই।

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. কোন ধরনের টিকিট?

টিকিটে একটি অক্ষর থাকে। `'f'` হলো পূর্ণ ভাড়া। `'c'` আর `'s'` দুটোই ছাড়, একটি শিশুদের জন্য আর অন্যটি শিক্ষার্থীদের জন্য। `'x'` হলো ফ্রি পাস। এর বাইরে যা কিছু, তা অজানা।

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

চারটি উত্তর হলো `"Full fare"`, `"Concession"`, `"Free pass"` এবং `"Unknown"`।

## 3. কোন ধরনের দিন?

`"Sat"` আর `"Sun"` হলো ছুটির দিন। `"Mon"` থেকে `"Fri"` হলো কর্মদিবস। এর বাইরে যা কিছু, তা অজানা।

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

তিনটি উত্তর হলো `"Weekend"`, `"Weekday"` এবং `"Unknown"`।

## 4. দৈনিক ক্যাপ

আপনি যত ট্রামেই উঠুন না কেন, ওই দিনের ক্যাপের বেশি কখনোই দিতে হবে না: কর্মদিবসে ১১০০ আর ছুটির দিনে ৭০০। যে দিন কেউ চেনে না, তার কোনো ক্যাপ নেই, অর্থাৎ শূন্য।

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
