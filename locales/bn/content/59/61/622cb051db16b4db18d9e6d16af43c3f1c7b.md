# সম্পর্কে

আগের কনসেপ্টগুলোতে আমরা দেখেছি যে Julia-তে টাইপগুলো একটি হায়ারার্কি তৈরি করে, যার একেবারে উপরে থাকে `Any`.

`Number`-এর মতো অ্যাবস্ট্রাক্ট টাইপগুলোর সাবটাইপ থাকে, কিন্তু সেগুলো নিজেদের ইন্সট্যান্টিয়েট করা যায় না।
কোনো ভ্যারিয়েবলের টাইপ হিসেবে একটি অ্যাবস্ট্রাক্ট টাইপ সেট করলে, ভ্যারিয়েবলটির মানগুলোকে ওই অ্যাবস্ট্রাক্ট টাইপের যেকোনো সাবটাইপের মধ্যে _সীমাবদ্ধ_ করে দেয়।
যেমন:

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

এতে কোন কোন ইনপুট বৈধ হবে তা সীমাবদ্ধ করার একধরনের নমনীয়তা পাওয়া যায়।

কিন্তু ধরা যাক, আমরা চাই একটি ভ্যারিয়েবল একইসাথে ইন্টিজার ও স্ট্রিং দুটোই গ্রহণ করবে? এই টাইপগুলো হায়ারার্কির একই শাখায় নেই।

আমরা টাইপটি [`Any`][any] করে দিতে পারি, বা এমনিতেই সেটিকে ডিফল্ট হিসেবে থাকতে দিতে পারি, কিন্তু তাহলে কোন কোন টাইপ অনুমোদিত হবে সেই নিয়ন্ত্রণ পুরোপুরি হারিয়ে যায়।

আরও ভালো একটি উপায় হলো [`Union{ }`][union] সিনট্যাক্স, যেখানে দ্বিতীয় বন্ধনীর ভেতরে দুটি বা তার বেশি টাইপ লেখা হয়।

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

আরেকটি উদাহরণে একই টাইপ ইউনিয়ন একটি ফাংশন সিগনেচারে ব্যবহার করা হয়েছে:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

এখানে আমরা টাইপটির একটি নাম দিয়েছি, যা সুবিধাজনক সংক্ষিপ্ত রূপ হিসেবে কাজ করতে পারে, তবে কঠোরভাবে প্রয়োজনীয় নয়।
`g(z::Union{Integer, String}) = z^3` ফাংশনটিও একইভাবে কাজ করে।

ফাংশন সিগনেচার নিয়ে আরও অনেক কিছু বলার আছে মাল্টিপল ডিসপ্যাচ কনসেপ্টে।

## nothing-এর সাথে ইউনিয়ন

আরও কিছু ভাষায় এমন টাইপ আছে যেগুলোতে মান থাকতেও পারে, নাও থাকতে পারে, যেমন `Option`, `Nullable` বা `Maybe`.

Julia-তে এর জন্য নির্দিষ্ট কোনো সিনট্যাক্স নেই, তবে টাইপ ইউনিয়ন একই ধারণার একটি সাধারণ রূপ।

[`Nothingness`][nothingness] কনসেপ্টে আমরা দেখেছি যে Julia-তে কোনো মান না থাকা বোঝানোর নানা রকম উপায় আছে, যার মধ্যে [`nothing`][nothing] ও [`missing`][missing] অন্যতম।
এদের যেকোনোটিই একটি টাইপ ইউনিয়নে রাখা যায়।

যেমন, একধরনের [লিংকড লিস্ট][linked] ডিফাইন করতে গেলে, আর কোনো নোড না থাকলে লিস্টটি শেষ করার একটি উপায় দরকার।
`Nothing` হলো সেই টাইপ যার একমাত্র মান `nothing`, আর Node-এর এই ডেফিনিশন দিয়ে চেইনের শেষ বোঝানো সম্ভব হয়:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

একইভাবে, অনুপস্থিত মানের জায়গায় প্লেসহোল্ডার হিসেবে `missing` ব্যবহার করা যায়, বিশেষ করে ভেক্টরের মতো কালেকশনে।
নিচের উদাহরণটি খুব বেশি কৃত্রিম, তবে বাস্তব জগতের ডেটা সেটে অনুপস্থিত মান খুব কমন।

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
