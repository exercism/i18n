# নির্দেশনা

এই অনুশীলনীতে আপনি "উইজার্ড অ্যান্ড ওয়ারিয়রস" নামের একটি রোল-প্লেয়িং গেম খেলছেন, যেখানে আপনি Wizard অথবা Warrior হিসেবে খেলতে পারেন।

Warrior এবং Wizard-দের জন্য আলাদা আলাদা নিয়ম আছে, যা নির্ধারণ করে তারা কত ড্যামেজ পয়েন্ট দেয়।

Warrior-এর ক্ষেত্রে নিয়মগুলো হলো:

- যে ক্যারেক্টারের ওপর আক্রমণ করা হচ্ছে সে ভালনারেবল না হলে ৬ পয়েন্ট ড্যামেজ দেয়
- যে ক্যারেক্টারের ওপর আক্রমণ করা হচ্ছে সে ভালনারেবল হলে ১০ পয়েন্ট ড্যামেজ দেয়

Wizard-এর ক্ষেত্রে নিয়মগুলো হলো:

- Wizard আগে থেকে স্পেল প্রস্তুত করে রাখলে ১২ পয়েন্ট ড্যামেজ দেয়
- Wizard আগে থেকে স্পেল প্রস্তুত না করলে ৩ পয়েন্ট ড্যামেজ দেয়

সাধারণভাবে ক্যারেক্টাররা কখনোই ভালনারেবল হয় না। তবে Wizard-রা স্পেল প্রস্তুত না থাকলে _ভালনারেবল হয়_।

ছয়টি কাজে আপনাকে Warrior এবং Wizard ক্যারেক্টার নিয়ে কাজ করতে হবে।

## 1. একটি ক্যারেক্টার বর্ণনা করুন

`Character` ক্লাসের `ToString()` মেথড ওভাররাইড করুন, যাতে এটি ক্যারেক্টারের একটি বর্ণনা রিটার্ন করে, যার ফরম্যাট হবে `"Character is a <CHARACTER_TYPE>"`।

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. ক্যারেক্টাররা যেন ডিফল্টভাবে ভালনারেবল না হয় তা নিশ্চিত করুন

নিশ্চিত করুন যে `Character.Vulnerable()` মেথড সবসময় `false` রিটার্ন করে।

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Wizard-দের স্পেল প্রস্তুত করতে দিন

`Wizard.PrepareSpell()` মেথড ইমপ্লিমেন্ট করুন, যাতে একজন Wizard আগে থেকে একটি স্পেল প্রস্তুত করতে পারে।

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. স্পেল প্রস্তুত না থাকলে Wizard-দের ভালনারেবল করে তুলুন

নিশ্চিত করুন যে Wizard স্পেল প্রস্তুত না করলে `Vulnerable()` মেথড `true` রিটার্ন করে; অন্যথায় `false` রিটার্ন করে।

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. একজন Wizard-এর ড্যামেজ পয়েন্ট হিসাব করুন

`Wizard.DamagePoints()` মেথড ইমপ্লিমেন্ট করুন, যাতে প্রদত্ত ড্যামেজ পয়েন্ট রিটার্ন হয়: স্পেল প্রস্তুত থাকলে ১২ ড্যামেজ পয়েন্ট, না থাকলে ৩ ড্যামেজ পয়েন্ট।

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. একজন Warrior-এর ড্যামেজ পয়েন্ট হিসাব করুন

`Warrior.DamagePoints()` মেথড ইমপ্লিমেন্ট করুন, যাতে প্রদত্ত ড্যামেজ পয়েন্ট রিটার্ন হয়: টার্গেট ভালনারেবল হলে ১০ ড্যামেজ পয়েন্ট, না হলে ৬ ড্যামেজ পয়েন্ট।

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
