# সম্পর্কে

[রেকর্ড][records] হলো এমন ডেটা স্ট্রাকচার, যেগুলো সম্পর্কিত তথ্যকে লেবেল দিয়ে একসাথে গুছিয়ে রাখে। এগুলো JavaScript বা Java-এর অবজেক্ট, কিংবা C বা Rust-এর স্ট্রাক্টের মতো, তবে কিছু গুরুত্বপূর্ণ পার্থক্য আছে।

## রেকর্ড তৈরি করা

রেকর্ড [তৈরি][create] করা হয় দ্বিতীয় বন্ধনী দিয়ে, আর এর এলিমেন্টগুলো কমা দিয়ে আলাদা করা হয়।

```elm
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

রেকর্ডের টাইপও প্রায় একই রকম সিনট্যাক্সে সংজ্ঞায়িত করা হয়, শুধু সমান চিহ্ন `=`-এর জায়গায় বসে কোলন চিহ্ন `:`।

```elm
firefly : { name : String, creator : String, episodes : Int }
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

এই টাইপ সংজ্ঞাগুলো বারবার লিখতে থাকলে ঝামেলা হয়, তাই সংজ্ঞাটি ভাগ করে নিতে একটি [টাইপ অ্যালিয়াস][record-types] ব্যবহার করা একটি কমন রীতি।

```elm
type alias TvSeries =
    { name : String
    , creator : String
    , episodes : Int
    }

firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

টাইপ অ্যালিয়াস স্বয়ংক্রিয়ভাবে রেকর্ডটির জন্য একটি কনস্ট্রাক্টর ফাংশনও দিয়ে দেয়। এটা মাঝে মাঝে আশ্চর্যজনক মনে হয়, কারণ Elm-এ ফাংশনের নাম অবশ্যই ছোট হাতের ক্যারেক্টার দিয়ে শুরু হতে হয়, অথচ টাইপ কনস্ট্রাক্টর হলো এর একটি ব্যতিক্রম।

```elm
firefly : TvSeries
firefly = TvSeries "Firefly" "Joss Whedon" 14
```

## রেকর্ডের ফিল্ডগুলো অ্যাক্সেস করা

[একটি রেকর্ড ইনস্ট্যান্সের কোনো ফিল্ডের মান অ্যাক্সেস করার][access] প্রধান উপায় হলো ডট-নোটেশন ব্যবহার করা, যেমন `firefly.creator`। Elm কম্পাইলার ডট `.` দিয়ে শুরু হওয়া বিশেষ অ্যাক্সেসর ফাংশনও সাপোর্ট করে, যেমন `.creator`, যেগুলো এমন যেকোনো রেকর্ডে কাজ করবে যার ওই নামের একটি ফিল্ড আছে। এটাই সেই নিয়মের দ্বিতীয় ব্যতিক্রম যে ফাংশনের নাম ছোট হাতের ক্যারেক্টার দিয়ে শুরু হতে হয়। আসলে ব্যবহারকারীর সংজ্ঞায়িত ফাংশনের নাম অবশ্যই ছোট হাতের ক্যারেক্টার দিয়ে শুরু হতে হয়, কিন্তু আমরা এইমাত্র যে দুটি উদাহরণ পেলাম সেগুলো প্রোগ্রামার নয়, কম্পাইলারের তৈরি।

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

firefly.name
    --> "Firefly"

.creator firefly
    --> "Joss Whedon"
```

[রেকর্ড প্যাটার্ন ম্যাচিং][pattern-matching] ব্যবহার করে বাইন্ডিংয়ের ভেতরে রেকর্ডগুলোকে _ডিস্ট্রাকচার_ও করা যায়। ডিস্ট্রাকচারিং এমন যেকোনো রেকর্ডের সাথে কাজ করে, যার প্রাসঙ্গিক নামের ফিল্ডগুলো আছে।

```elm
episodesCount : TvSeries -> Int
episodesCount { episodes } =
    episodes

complicatedCopy : TvSeries -> TvSeries
complicatedCopy show =
    let
        { name, creator } = show
    in
    { name = name
    , creator = creator
    , episodes = episodesCount show
    }
```

## রেকর্ড আপডেট করা

Elm-এর সবকিছুর মতো রেকর্ডও অপরিবর্তনীয়, তাই একবার রেকর্ড সংজ্ঞায়িত হয়ে গেলে তার ফিল্ডের মান আর কখনো বদলানো যায় না। বিদ্যমান একটি রেকর্ডের কপি তৈরি করার, তবে তার এক বা একাধিক ফিল্ড বদলে দেওয়ার [বিশেষ সিনট্যাক্স আছে][update]। এই সিনট্যাক্সে মূল রেকর্ড আর যে ফিল্ডগুলো বদলাবে সেগুলো আলাদা করতে পাইপ চিহ্ন `|` ব্যবহার করা হয়, যেমন `{ oldRecord | field1 = newValue }`।

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

updatedFirefly : TvSeries
updatedFirefly =
    { firefly | creator = "J Whedon", episodes = 15 }
```

## রেকর্ড তুলনা করা

Elm [স্ট্রাকচারাল ইকুয়ালিটি][equality] ব্যবহার করে, অর্থাৎ একই রেকর্ডের দুটি ইনস্ট্যান্সের মান হুবহু এক হলে সেগুলো সমান।

```elm
firefly1 = TvSeries "Firefly" "Joss Whedon" 14
firefly2 = TvSeries "Firefly" "Joss Whedon" 14

firefly1 == firefly2
    --> True
```

## এক্সটেনসিবল রেকর্ড

Elm [স্ট্রাকচারাল টাইপিং][structural-typing]-ও সাপোর্ট করে, অর্থাৎ কোনো ফাংশনের যদি x ও y ফিল্ডসহ একটি রেকর্ড দরকার হয়, তাহলে সেটি এমন যেকোনো রেকর্ডের সাথে কাজ করবে যাতে ওই ফিল্ডগুলো আছে, যেমন 2D পয়েন্ট, 3D পয়েন্ট, মহাকাশযান ইত্যাদি। ওই রেকর্ড টাইপগুলোর সংজ্ঞায় একটি পাইপ `|` থাকে, যেমন `{ a | x : Float, y : Float }`, আর Elm-এর পরিভাষায় এগুলোকে বলা হয় "এক্সটেনসিবল রেকর্ড"। টাইপ সংজ্ঞার পাইপ `|` আর বাস্তব রেকর্ড ইনস্ট্যান্সের পাইপ `|`-এর পার্থক্য নিয়ে সাবধান থাকুন: টাইপ সংজ্ঞার পাইপ মানে এক্সটেনসিবল রেকর্ড সংজ্ঞা (`{ a | x : Int }`), আর রেকর্ড ইনস্ট্যান্সের পাইপ মানে আমরা ওই রেকর্ডের কিছু ফিল্ড আপডেট করছি।

```elm
point2d = { x = 1, y = 2 }
point3d = { x = 3, y = 4, z = 7 }

.x point2d --> 1
.x point3d --> 3

length : { a | x : Float, y : Float } -> Float
length vector =
    sqrt (vector.x * vector.x + vector.y * vector.y)

length point2d --> 2.236068
length point3d --> 5

translateX : { a | x : Float } -> { a | x : Float }
translateX vector =
    { vector | x = vector.x + 1 }

translateX point2d --> { x = 2, y = 2 }
translateX point3d --> { x = 4, y = 4, z = 7 }
```
