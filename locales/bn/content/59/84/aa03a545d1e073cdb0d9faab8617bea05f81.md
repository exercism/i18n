# ইঙ্গিত

## সাধারণ

- নির্দেশনার টেবিলটি রেফারেন্স করতে মনে রাখবেন।

## 1. একটি এক্সটেনশন দেওয়া হলে, প্রত্যাশিত মিডিয়া টাইপ রিটার্ন করুন

- সঠিক মিডিয়া টাইপ রিটার্ন করতে [প্যাটার্ন ম্যাচিং][pattern-matching] ব্যবহার করুন।
- আপনি [একাধিক ফাংশন ক্লজ][mfc] ব্যবহার করতে পারেন।

## 2. একটি বাইনারি ফাইল দেওয়া হলে, প্রত্যাশিত মিডিয়া টাইপ রিটার্ন করুন

- একটি বাইনারি লিটারাল লেখার জন্য আপনার কাছে থাকা [বাইনারি স্পেশাল ফর্ম][special-forms] ব্যবহার করুন।
- ফাইল বাইনারির প্রথম কয়েকটি বাইটের সাথে মেলাতে [প্যাটার্ন ম্যাচিং][binary-matching] ব্যবহার করুন।

## 3. একটি এক্সটেনশন ও একটি বাইনারি ফাইল দেওয়া হলে, ফাইলটি প্রত্যাশিত টাইপের সাথে মেলে কিনা যাচাই করুন

- ১ ও ২ নম্বর অংশের জন্য আপনি তৈরি করা ফাংশনগুলো আবার ব্যবহার করুন।
- প্রতিটি ফাংশনের রিটার্ন ভ্যালু তুলনা করুন, তারপর উপযুক্ত মানটি রিটার্ন করুন।
  - বাইনারি শর্তের জন্য আপনি [`if` ম্যাক্রো কন্ডিশনাল][if] ব্যবহার করতে পারেন।
