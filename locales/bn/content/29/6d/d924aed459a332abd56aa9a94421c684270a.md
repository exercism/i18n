# টেস্ট

## টেস্ট চালানো

টেস্টগুলো চালাতে হলে নিচের কমান্ডটি চালান:

```bash
bats test-<exercise-slug>.bats
```

### bats লেখা হয়েছে bash দিয়ে

bats ফাইলটি আসলে একটি bash স্ক্রিপ্ট, যার ভেতরে কিছু বিশেষ ফাংশন আছে যেগুলো `bats` কমান্ড চিনে নেয়।
আপনি এমন কিছু টেস্ট দেখতে পাবেন যেগুলো দেখতে এরকম:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

ওই `<<<` সিনট্যাক্সটি bash-এর একটি *Here String*।
এটি ডান দিকের স্ট্রিংটি বাম দিকের প্রোগ্রামের স্ট্যান্ডার্ড ইনপুটে পাঠায়।
এটি প্রায় নিচেরটির মতোই কাজ করে:

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
ডিফল্টভাবে, আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) চালানো হয়।
এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।
একবার সেটি পাস করলে, বাকি টেস্টগুলোর আগে বসানো

    [[ $BATS_RUN_SKIPPED == true ]] || skip

অ্যানোটেশনগুলো কমেন্ট আউট করে বা মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন।

## স্কিপ ওভাররাইড করা

`skip` অ্যানোটেশনযুক্ত টেস্টগুলোসহ সব টেস্ট চালাতে চাইলে আপনি এভাবে চালাতে পারেন:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

অথবা টেস্ট ফাইল থেকে

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

লাইনটি কমেন্ট আউট করতে বা মুছে ফেলতে পারেন।
