# বাউন্ড রুটিন

এতক্ষণ পর্যন্ত সবকিছুতেই *মান* এদিক-ওদিক পাঠানো হয়েছে: সংখ্যা, স্ট্রিং, অবজেক্ট। একটি
**বাউন্ড রুটিন** দিয়ে আপনি রুটিনকেই এদিক-ওদিক পাঠাতে পারেন, অর্থাৎ এমন কিছু যা পরে কল করা
হবে, এমন কোড দিয়ে যা জানে না সেটি আসলে কী।

আন্ডারস্টাডি ঠিক এই ধারণাটিই: মঞ্চ ব্যবস্থাপক ভূমিকাটি অভিনয় করার একটি উপায় ধরে রাখেন,
কিন্তু কে সেটি করবে বা তারা কী করবে তা জানেন না।

## এটি বানানো

`bind` এমন একটি কল নেয় যার ভেতরে ফাঁকা জায়গা থাকে, যা `_` দিয়ে লেখা হয়:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

`part` এখন অন্য যেকোনো মানের মতোই একটি মান। এটি কল করা হয় পরে:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## টাইপটি

একটি বাউন্ড রুটিনের টাইপ `ROUT`, ব্রেসের ভেতরে থাকে আর্গুমেন্টের টাইপ আর কোলনের পরে
রিটার্ন টাইপ:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

`ROUT{STR}:STR`-কে পড়ুন এভাবে: "এমন একটি রুটিন যা একটি `STR` নেয় এবং একটি `STR` উত্তর
দেয়"।

| লেখা | অর্থ |
| --- | --- |
| `ROUT{STR}:STR` | একটি `STR` নেয়, একটি `STR` উত্তর দেয় |
| `ROUT{INT,INT}:BOOL` | দুটি `INT` নেয়, একটি `BOOL` উত্তর দেয় |
| `ROUT{STR}` | একটি `STR` নেয়, কিছুই উত্তর দেয় না |
| `ROUT:INT` | কিছুই নেয় না, একটি `INT` উত্তর দেয় |

যেহেতু এটি একটি টাইপ, তাই এটি একটি আর্গুমেন্টও হতে পারে:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse`-এর কোনো ধারণাই নেই `part` কী করে। এটাই আসল কথা: এর হাতে দেওয়া যেতে পারে
`shout`, বা `whisper`, বা ওই ধরনের আর যা কিছু।

## কিছু আর্গুমেন্ট আগেই ভরে দেওয়া

প্রতিটি আর্গুমেন্টকেই ফাঁকা থাকতে হয় না। যা কিছু সরাসরি লেখা হয়, তা বাইন্ড হওয়ার সময়েই
স্থির হয়ে যায়:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice` শুধু লাইনটিই নেয়, কারণ `2` আগেই ঠিক হয়ে গেছে। মানটি বাইন্ড করার মুহূর্তেই
হিসাব করে রাখা হয়, তাই পরে যে ভ্যারিয়েবল থেকে এটি এসেছিল সেটি বদলে দিলে কোনো পার্থক্য
হয় না।

এভাবেই একটি সাধারণ রুটিন থেকে অনেকগুলো নির্দিষ্ট রুটিন তৈরি হয়।

## অবজেক্টও বাইন্ড করা

কোনো অবজেক্টের রুটিনের ক্ষেত্রে অবজেক্টটিই কলের প্রথম জিনিস, এবং এটি স্থির করা যায় বা
ফাঁকা রাখা যায়:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
