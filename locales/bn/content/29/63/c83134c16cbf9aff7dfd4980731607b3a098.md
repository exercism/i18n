# ভূমিকা

অন্য ভাষাগুলোর মতো C++-ও একটি `switch` স্টেটমেন্ট দেয়।
দীর্ঘ `if ... else if` স্টেটমেন্ট লেখার একটি সংক্ষিপ্ত উপায় হলো `switch` স্টেটমেন্ট।
একটি `switch` তৈরি করতে আমরা প্রথমে `switch` কিওয়ার্ডটি লিখি, তার পরে একটি ইন্টিজার দিই।
এরপর আমরা `case` কিওয়ার্ড দিয়ে প্রতিটি শর্ত ঘোষণা করি।
আমরা একটি `default` কেসও ঘোষণা করতে পারি, যা আগের কোনো `case` শর্তের সাথে না মিললে রান হবে।
প্রতিটি কেসের শেষে একটি `break` (বা `return`) স্টেটমেন্ট থাকা উচিত।

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## ফল-থ্রু

`switch` কনস্ট্রাক্ট সম্পর্কে একটি গুরুত্বপূর্ণ বিষয় হলো, কোডটি চলতেই থাকে যতক্ষণ না কোনো `break` (বা `return`) স্টেটমেন্ট সেটি থামায়।
এর ফলে অপ্রত্যাশিত আচরণ হতে পারে।

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

এই চলমান এক্সিকিউশন বৈশিষ্ট্যের প্রধান ব্যবহার হলো এমন একটি স্টেটমেন্ট, যার একাধিক লেবেল থাকে।
একাধিক `switch` ফলাফল একই কোডের অংশে ম্যাপ হতে পারে, যা এক্সিকিউট করা হবে।
এভাবেই, যেমন একটি বুকিং অ্যাপে, 2 ও 3 গ্রুপ সাইজের জন্য কল করা ফাংশন একই হতে পারে:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
