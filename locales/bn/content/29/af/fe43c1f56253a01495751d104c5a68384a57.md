# ইটারেশন

প্রোগ্রামিংয়ে, [ইটারেশন][iteration] বলতে একটি কোড ব্লক একাধিকবার পুনরাবৃত্তি করার প্রক্রিয়াকে বোঝায়।
এটি while লুপ ও until লুপের মতো ধারণা ব্যবহার করে করা যায়।
আবার রিকার্সন ব্যবহার করেও এটি করা যায়, যেখানে একটি ফাংশন নিজেকে কল করে।

তবে বেশিরভাগ সময়েই আপনি এলিমেন্টের একটি কালেকশনের উপর ইটারেট করতে চান, যেমন একটি `Array`, `Range` বা `String`।
Crystal-এ `Array` ও `Range` ক্লাস দুটোই [`Enumerable`][enumerable] মডিউল অন্তর্ভুক্ত করে, যা এলিমেন্টগুলোর উপর ইটারেট করার জন্য অনেকগুলো মেথড দেয়।
অন্যদিকে `String` ক্লাসের ক্যারেক্টারগুলোর উপর ইটারেট করার জন্য নিজস্ব মেথড রয়েছে।

অন্য ভাষাগুলোর মতো Crystal-এও কোনো for স্টেটমেন্ট নেই।
বদলে এতে ইটারেট করার জন্য ব্যবহারযোগ্য বেশ কিছু মেথড আছে।

## ইটারেশন করা

কালেকশনের উপর ইটারেট করার সবচেয়ে কমন উপায় হলো [`each`][each] মেথড ব্যবহার করা, যা কালেকশনের প্রতিটি এলিমেন্ট একটি ব্লকে দেয়।
এটি একটি `Range` দিয়ে সহজেই করা যায়।
ধরুন আপনি 1 থেকে 3-এর মধ্যে লুপ করতে চান, তাহলে রেঞ্জের উপর ইটারেট করতে `each` মেথড ব্যবহার করতে পারেন।

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

আরও সহজে, আপনি যদি শুধু নির্দিষ্ট সংখ্যকবার ইটারেট করতে চান, তাহলে [`times`][times] মেথড ব্যবহার করতে পারেন, যা `Int` ক্লাসে রয়েছে।

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## একটি `String`-এর উপর ইটারেশন

একটি `String` হলো ক্যারেক্টারের একটি ক্রম, আর এটি `Enumerable` মডিউলের অন্তর্ভুক্ত নয়, অর্থাৎ ক্যারেক্টারগুলোর উপর ইটারেট করার জন্য এর নিজস্ব মেথড রয়েছে।
`String`-এর উপর ইটারেট করার সবচেয়ে কমন উপায় হলো [`each_char`][each_char] মেথড ব্যবহার করা, যা `String`-এর প্রতিটি ক্যারেক্টার একটি ব্লকে দেয়।

~~~~exercism/note
`each_char` মেথড ব্লকে একটি `Char` অবজেক্ট দেয়, `String` অবজেক্ট নয়।
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String`-এর উপর ইটারেট করার আরেকটি উপায় হলো [`each_line`][each_line] মেথড ব্যবহার করা।
এই মেথডটি বেশিরভাগ ক্ষেত্রে একটি ফাইল লাইন ধরে ধরে পড়ার সময় ব্যবহৃত হয়।

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## `Enumerable` মডিউল অন্তর্ভুক্ত একটি অবজেক্টের উপর ইটারেশন

[`Enumerable`][enumerable] মডিউল একটি কালেকশনের এলিমেন্টগুলোর উপর ইটারেট করার জন্য অনেকগুলো মেথড দেয়।
`Enumerable` মডিউল অন্তর্ভুক্ত কালেকশনগুলোর মধ্যে রয়েছে `Array`, `Range`, `Hash`, `Set` এবং আরও কিছু; পরেরগুলো পরের কনসেপ্টগুলোতে আলোচনা করা হবে।

একটি `Array`-এর উপর ইটারেট করার সবচেয়ে কমন উপায় হলো [`each`][each] মেথড ব্যবহার করা, যা `Array`-এর প্রতিটি এলিমেন্ট একটি ব্লকে দেয়।

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map] মেথড একটি `Array`-এর উপর ইটারেট করার আরেকটি উপায়; এটি প্রতিটি এলিমেন্টে ব্লক প্রয়োগের ফলাফল নিয়ে একটি নতুন `Array` রিটার্ন করে।
এটি `each` মেথডের মতোই, তবে এটি রূপান্তরিত এলিমেন্টসহ একটি নতুন `Array` রিটার্ন করে।
কালেকশনের প্রতিটি এলিমেন্টে একটি ফাংশন প্রয়োগ করতে চাইলে রূপান্তর খুব কাজে লাগে, যা একটি কমন অপারেশন।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if`-এর মতো কন্ট্রোল ফ্লো ব্যবহার করে আপনি কোন এলিমেন্টগুলো রূপান্তর করবেন তা ফিল্টার করতে পারেন।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### ইনডেক্স-সহ

অনেক সময় আপনি যে এলিমেন্টের উপর ইটারেট করছেন তার ইনডেক্স জানার প্রয়োজন হয়; সেজন্য [`each_with_index`][each_with_index] বা [`map_with_index`][map_with_index] মেথড ব্যবহার করতে পারেন।
এটি প্রতিটি এলিমেন্ট ও তার ইনডেক্স একটি ব্লকে দেয়, আর মেথডটি শুরুর ইনডেক্স নির্দিষ্ট করার জন্য একটি ঐচ্ছিক আর্গুমেন্টও নেয়।

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

মনে রাখবেন, `String` অবজেক্টের জন্যও [`each_char_with_index`][each_char_with_index] মেথডটি পাওয়া যায়।

### sum

[`sum`][sum] মেথড কালেকশনের সব এলিমেন্টের যোগফল রিটার্ন করে; এটি যোগ করার আগে এলিমেন্টগুলো রূপান্তর করার জন্য একটি ঐচ্ছিক ব্লকও নেয়।
এটি যোগফলের প্রাথমিক মান নির্দিষ্ট করার জন্য একটি ঐচ্ছিক আর্গুমেন্টও নেয়।

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], বা অন্য ভাষায় যা fold নামে পরিচিত, হলো এমন একটি মেথড, যা একটি কম্বাইন মেথড ও একটি প্রাথমিক মান নিয়ে কালেকশনের সব এলিমেন্ট একত্রিত করে।
`reduce` মেথডে একটি অ্যাকুমুলেটর থাকে যা ব্লকে পাস করা হয়; অ্যাকুমুলেটরটি হলো আগের ইটারেশনের ফলাফল।
এভাবে একটি রিকার্সিভ প্রক্রিয়া তৈরি হয়, যা কালেকশনের সব এলিমেন্ট একত্রিত করে।

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` হয়তো `sum`-এর মতো মনে হতে পারে, কিন্তু `reduce` আরও নমনীয়, কারণ এটি অ্যাকুমুলেটরের প্রাথমিক মান ও কম্বাইন মেথড নির্দিষ্ট করার সুযোগ দেয়।
`reduce` দিয়ে `sum`, `count` এবং অন্যান্য মেথড তৈরি করা যায়।
