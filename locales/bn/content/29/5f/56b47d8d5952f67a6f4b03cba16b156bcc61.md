# সম্পর্কে

F# স্ট্রিং হলো ইমিউটেবল অবজেক্ট, যা ইউনিকোড ক্যারেক্টারের একটি সিকোয়েন্স হিসেবে টেক্সট প্রকাশ করে (অক্ষর, ডিজিট, যতিচিহ্ন ইত্যাদি)। একটি `string` ইনস্ট্যান্স ডিফাইন করতে ডাবল কোট ব্যবহার করা হয়:

```fsharp
let fruit = "Apple"
```

কোনো স্ট্রিং নিয়ে কাজ করার জন্য তার একটি [মেথড][methods] বা [প্রপার্টি][properties] কল করা যায়, অথবা [`String` মডিউল][string-module]-এর কোনো ফাংশন ব্যবহার করা যায়। স্ট্রিং মান একবার ডিফাইন হয়ে গেলে আর কখনো বদলাতে পারে না, তাই স্ট্রিং নিয়ে কাজ করার সব মেথড/ফাংশন নতুন একটি স্ট্রিং রিটার্ন করে।

একটি স্ট্রিং ডাবল কোট (`"`) ক্যারেক্টার দিয়ে ঘেরা থাকে। কিছু বিশেষ ক্যারেক্টার ব্যাকস্ল্যাশ (`\`) ক্যারেক্টার দিয়ে [এস্কেপিং][escaping] করতে হয়। স্ট্রিংয়ের সামনে অ্যাট (`@`) চিহ্ন বসিয়েও লেখা যায়, যা এটিকে এমন একটি [ভারবেটিম স্ট্রিং][verbatim] বানায় যেখানে এস্কেপ করা ক্যারেক্টারগুলো অগ্রাহ্য হয়।

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

অন্যভাবে, [ট্রিপল কোট][triple-quoted] (`"""`) দিয়ে স্ট্রিং ডিফাইন করা যায়, যা দিয়ে স্ট্রিংয়ের ভেতরে ডাবল কোট এস্কেপ না করেই ব্যবহার করা যায়।

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

সবশেষে, [`+` অপারেটর][plus-operator] দিয়ে স্ট্রিং জোড়া লাগানো যায়:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
