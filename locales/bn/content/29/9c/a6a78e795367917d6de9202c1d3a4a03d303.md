# পরিচিতি

## ব্যাখ্যা

JavaScript-এ `number` ও `string`-এর মতো প্রিমিটিভ ডেটা টাইপের পাশাপাশি `object` নামে আরেকটি গুরুত্বপূর্ণ ডেটা টাইপ আছে।
অবজেক্ট হলো কী (key)-মান জোড়ার সংগ্রহ।
তাই অন্য ভাষায় যাকে সাধারণত ম্যাপ বা ডিকশনারি বলা হয়, সেভাবেই এগুলো ব্যবহার করা যায়।

অন্য ভাষায় একটি ম্যাপের সব মানের ডেটা টাইপ সাধারণত একই হতে হয়।
JavaScript-এ শুধু কী (key)-এর টাইপটাই সীমাবদ্ধ: সেটি অবশ্যই একটি `string` হতে হবে।
একটি অবজেক্টের ভেতরের মানগুলো ভিন্ন ভিন্ন টাইপের হতে পারে।
সেগুলো সংখ্যার মতো প্রিমিটিভ টাইপ হতে পারে, আবার অ্যারে, অন্য অবজেক্ট বা এমনকি ফাংশনও হতে পারে।
এ কারণে অবজেক্ট খুবই বহুমুখী হয়ে ওঠে, ফলে JavaScript-এ [অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং][oop] (OOP)-এর মূল উপাদানও এগুলোই।

নিচের অংশে আমরা সংগ্রহ বা ম্যাপ হিসেবে অবজেক্ট নিয়েই আলোচনা করব।
অবজেক্টের অন্য ব্যবহারের দিকগুলো অন্য কনসেপ্টে আলোচনা করা হবে, যেমন দেখুন [ক্লাস][concept-classes]।

## একটি অবজেক্ট তৈরি করা

আপনি দ্বিতীয় বন্ধনী দিয়ে একটি অবজেক্ট তৈরি করেন।
চাইলে সরাসরি কিছু এন্ট্রিও যোগ করে দিতে পারেন।
তার জন্য প্রথমে কী (key) লিখুন, তারপর একটি কোলন এবং সবশেষে মান।

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

শেষ এন্ট্রির পরে বসানো কমা JavaScript-এ ঐচ্ছিক।

আপনার মনে প্রশ্ন জাগতে পারে, কী (key) গুলো তো স্ট্রিং হওয়ার কথা, তবু কেন সেগুলো উদ্ধৃতি চিহ্ন দিয়ে মোড়ানো হয় না?
এটি একটি শর্টহ্যান্ড নোটেশন।
কী (key) যদি JavaScript-এর [আইডেন্টিফায়ার][mdn-identifier] নামকরণের নিয়ম মেনে চলে, তাহলে আপনি উদ্ধৃতি চিহ্ন বাদ দিতে পারেন।
নামে বিশেষ অক্ষর আছে এমন কী (key)-এর ক্ষেত্রে অবশ্য স্বাভাবিক স্ট্রিং নোটেশনই ব্যবহার করতে হয়।

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## একটি মান রিট্রিভ করা

কোনো নির্দিষ্ট কী (key)-এর মান রিট্রিভ করার দুটি উপায় আছে: ডট নোটেশন ও ব্র্যাকেট নোটেশন।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

শর্টহ্যান্ড হিসেবে ডট নোটেশন ব্যবহারেরও একই সীমাবদ্ধতা আছে যা উদ্ধৃতি চিহ্ন বাদ দেওয়ার ক্ষেত্রে ছিল।
এটি তখনই কাজ করে যখন কী (key) আইডেন্টিফায়ারের নামকরণের নিয়ম মেনে চলে।

## মান যোগ করা বা পরিবর্তন করা

অ্যাসাইনমেন্ট অপারেটর `=` দিয়ে আপনি একটি মান যোগ বা পরিবর্তন করতে পারেন।
এখানেও ডট ও ব্র্যাকেট নোটেশন দুটোই আছে।

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## একটি এন্ট্রি মুছে ফেলা

`delete` কিওয়ার্ড দিয়ে আপনি একটি অবজেক্ট থেকে একটি কী (key)-মান জোড়া মুছে ফেলতে পারেন।

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## কোনো কী (key) আছে কি না যাচাই করা

`hasOwnProperty` মেথড দিয়ে আপনি যাচাই করতে পারেন একটি অবজেক্টে নির্দিষ্ট কোনো কী (key) আছে কি না।

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## একটি অবজেক্টের উপর লুপ করা

একটি অবজেক্টের সমস্ত কী (key)-এর উপর ইটারেশন করার জন্য একটি বিশেষ `for...in` লুপ আছে।

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

সূক্ষ্ম এরর এড়াতে আপনার সবসময় ধরে নেওয়া উচিত যে `for...in` লুপ কী (key) গুলো এলোমেলো ক্রমে পরিদর্শন করে।
এছাড়াও জেনে রাখুন, `for...in` তার ইটারেশনে [উত্তরাধিকারসূত্রে পাওয়া কী (key)][concept-inheritance] গুলোও অন্তর্ভুক্ত করে।
