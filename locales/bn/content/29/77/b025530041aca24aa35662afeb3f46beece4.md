# নির্দেশনার পরিশিষ্ট

## ইঙ্গিত

আপনাকে `convert` ফাংশনটি ইমপ্লিমেন্ট করতে হবে, যা সংখ্যাকে বৃষ্টির ফোঁটার শব্দে রূপান্তর করে রিটার্ন করে। টাইপগুলো নিয়ে সংশয় থাকলে প্রদত্ত সিগনেচারটি ব্যবহার করতে পারেন, তবে সেটি যেন আপনার সৃজনশীলতাকে সীমাবদ্ধ না করে:

```haskell
convert :: Int -> String
```

এই অনুশীলনীটি টেক্সট ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে, Haskell-এর `String` টাইপ `[Char]`-এর সমার্থক, যা ক্যারেক্টারগুলোর একটি অ্যারে। টেক্সট ডেটা আরও দক্ষভাবে সামলানোর জন্য `Text` টাইপটি ব্যবহার করা যায়।

এই অনুশীলনীর একটি ঐচ্ছিক বাড়তি অংশ হিসেবে আপনি করতে পারেন

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml-এ আপনার ডিপেন্ডেন্সিগুলোর তালিকায় `- text` যোগ করুন।
- [নিচের পদ্ধতিতে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) `Data.Text` ইমপোর্ট করুন:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- এখন আপনি যেমন `convert :: Int -> Text` লিখতে পারেন এবং `Data.Text`-এর কম্বিনেটরগুলোকে যেমন `T.pack` হিসেবে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখে নিন,
- এরপর আপনি Raindrops.hs-এ `String`-এর সব উপস্থিতি `Text` দিয়ে প্রতিস্থাপন করতে পারেন:

```haskell
convert :: Int -> Text
```

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
