# ক্লাস

ক্লাস হলো PHP-তে কোড সংগঠনের একটি একক।
কোনো বস্তুর আচরণ বা কোনো প্রক্রিয়ার আচরণ প্রকাশ করে এমন কোড একসাথে একটি ক্লাস হিসেবে গোষ্ঠীভুক্ত করা যায়।
প্রচলিতভাবে, একটি ক্লাসে যুক্ত করা ফাংশনগুলোকে `methods` বলা হয়।

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

`new` কিওয়ার্ড দিয়ে ক্লাসের ইন্সট্যান্স তৈরি করা হয়; এটি ক্লাস ইন্সট্যান্সের জন্য মেমোরি বরাদ্দ করে এবং ক্লাসের কনস্ট্রাক্টর মেথড কল করে।
তৈরি করা ইন্সট্যান্স একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়।
কোনো ক্লাস ইন্সট্যান্সের মেথডগুলো কল করতে আমরা `->` অ্যাক্সেস অপারেটর ব্যবহার করতে পারি।

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

তৈরি করা একটি ক্লাস বিশেষ `$this` ভ্যারিয়েবলের মাধ্যমে তার নিজের ইন্সট্যান্সকে রেফারেন্স করতে পারে।
ক্লাসের প্রপার্টিও থাকতে পারে; এগুলো এমন ভ্যারিয়েবলের মতো কাজ করে যেগুলো ক্লাস অবজেক্টের ইন্সট্যান্সের সাথে যুক্ত থাকে।
এই প্রপার্টিগুলো ভেতরে বা বাইরে থেকে রেফারেন্স করা যায়।

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
