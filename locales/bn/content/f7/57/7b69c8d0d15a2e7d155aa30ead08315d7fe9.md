# নির্দেশনা

আপনি একটি অনলাইন ফ্যাশন বুটিক চালাচ্ছেন। আপনার ইনভেন্টরির প্রতিটি আইটেম একটি ২-এলিমেন্টের অ্যারে `{ name price }`, আর পুরো ইনভেন্টরি হলো আইটেমের একটি অ্যারে।

কোনো দাম না থাকলে তা `f` হিসেবে লেখা হয়।

## 1. ইনভেন্টরি দাম অনুযায়ী সাজান

`sort-by-price` ডিফাইন করুন, যেন এটি এমন একটি নতুন অ্যারে রিটার্ন করে যেখানে আইটেমগুলো দামের ঊর্ধ্বক্রমে সাজানো থাকে।

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. যে আইটেমগুলোর দাম দেওয়া নেই সেগুলো খুঁজুন

`with-missing-price` ডিফাইন করুন, যেন এটি শুধু সেই আইটেমগুলোর একটি অ্যারে রিটার্ন করে যাদের দাম `f`।

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. দামি আইটেম গণনা করুন

`expensive-items` ডিফাইন করুন, যেন এটি একটি ইনভেন্টরি ও একটি দামের থ্রেশহোল্ড নেয় এবং রিটার্ন করে কতগুলো আইটেমের দাম থ্রেশহোল্ডের চেয়ে কঠোরভাবে বেশি।

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. সবচেয়ে কম দামের আইটেমটি খুঁজুন

`cheapest-item` ডিফাইন করুন, যেন এটি সবচেয়ে কম দামের আইটেমটি রিটার্ন করে। যে আইটেমগুলোর দাম নেই (`f`), সেগুলো ইনপুটে থাকবে না।

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. সব দামের যোগফল বের করুন

`total-price` ডিফাইন করুন, যেন এটি সব দামের যোগফল রিটার্ন করে। যে আইটেমগুলোর দাম নেই (`f`), সেগুলো ইনপুটে থাকবে না।

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. একটি আইটেমকে প্রাইস ট্যাগ হিসেবে ফরম্যাট করুন

`format-price-tag` ডিফাইন করুন, যেন এটি একটি আইটেমের জন্য `"name: $price"` আকারের একটি স্ট্রিং রিটার্ন করে। যে আইটেমগুলোর দাম নেই (`f`), সেগুলো এখানে থাকবে না।

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
