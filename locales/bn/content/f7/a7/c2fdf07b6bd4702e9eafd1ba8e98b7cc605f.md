# পরিচিতি

Go-তে `fmt` (ফরম্যাট প্যাকেজ) নামের একটি বিল্ট-ইন প্যাকেজ আছে, যা ইনপুট ও আউটপুটের ফরম্যাট নিয়ন্ত্রণ করার নানা রকম ফাংশন দেয়।
সবচেয়ে বেশি ব্যবহৃত ফাংশনটি হলো `Sprintf`, যা `%s`-এর মতো _ভার্ব_ ব্যবহার করে স্ট্রিংয়ের ভেতরে মান বসিয়ে দেয় এবং সেই স্ট্রিংটি রিটার্ন করে।

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Go-তে ফ্লোটিং পয়েন্ট মান Sprintf-এর ভার্ব দিয়ে সুবিধাজনকভাবে ফরম্যাট করা যায়: `%g` (সংক্ষিপ্ত রূপ), `%e` (সূচক) বা `%f` (সূচক ছাড়া)।
তিনটি ভার্বই ফিল্ডের প্রস্থ ও সংখ্যার অবস্থান নিয়ন্ত্রণ করার সুযোগ দেয়।

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

উপলব্ধ ভার্বগুলোর সম্পূর্ণ তালিকা [ফরম্যাট প্যাকেজের ডকুমেন্টেশনে][fmt-docs] পাবেন।

স্ট্রিং নিয়ে কাজ করার জন্য `fmt`-এ আরও কিছু ফাংশন আছে, যেমন `Println`, যা শুধু তার কাছে আসা আর্গুমেন্টগুলো কনসোলে প্রিন্ট করে, আর `Printf`, যা প্রিন্ট করার আগে `Sprintf`-এর মতোই ইনপুট ফরম্যাট করে।

[fmt-docs]: https://pkg.go.dev/fmt
