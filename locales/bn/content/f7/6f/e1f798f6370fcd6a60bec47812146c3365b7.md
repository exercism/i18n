# টেস্ট

টেস্ট চালাতে নিচের ধাপগুলো অনুসরণ করুন:

- অনুশীলনীর ডিরেক্টরিতে যান (যেমন `~/Exercism/hello-world`)।
- টার্মিনালে একটি `jconsole` সেশন শুরু করুন (যেমন `jconsole` বা `ijconsole` টাইপ করে)।
- আপনার সলিউশন ফাইল লোড করুন (যেমন `load 'hello-world.ijs'`)
- `load  'general/unittest'` টাইপ করে ইউনিট টেস্ট ফ্রেমওয়ার্কটি লোড করুন
- `unittest 'test.ijs'` টাইপ করে আপনার সলিউশন টেস্ট করুন।
<br></br>
- বিকল্পভাবে এক লাইনেই এভাবে টেস্ট চালানো সম্ভব: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`।

## স্কিপ করা টেস্ট

শুরুতে কেবল প্রাথমিক টেস্টটিই চালু থাকবে।
পদ্ধতিটি আপনাকে ধাপে ধাপে অনুশীলনীটি সমাধান করতে উৎসাহিত করে।
প্রতিটি টেস্টে তার ডেফিনিশনের উপরে একটি নাউন থাকে, যার নামের শেষে _'\_ignore'_ থাকে।
টেস্টটি চালাতে এর মান 0-তে পরিবর্তন করুন।

### উদাহরণ:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
