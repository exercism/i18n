# পরিচিতি

C#-এর [`enum` টাইপ](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) নির্দিষ্ট কিছু নামযুক্ত কনস্ট্যান্টের একটি সেট বোঝায় (একটি এনুমারেশন)।

সাধারণত একটি `enum` মেম্বার ওই নামযুক্ত কনস্ট্যান্টগুলোর মধ্যে ঠিক একটিকেই নির্দেশ করতে পারে। তবে মাঝে মাঝে একটির বেশি কনস্ট্যান্ট নির্দেশ করা কাজে লাগে। এজন্য `enum`-টির সাথে [`Flags` অ্যাট্রিবিউট](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) দিয়ে অ্যানোটেট করা যায়।

একটি ফ্ল্যাগ enum এভাবে ডিফাইন করা যায় (বাইনারি ইন্টিজার নোটেশন `0b` ব্যবহার করে):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

যে `PhoneFeatures` ইনস্ট্যান্সের মান `0b00000011`, তার `Call` _এবং_ `Text` দুটি ফ্ল্যাগই সেট করা থাকে।

ডিফল্টভাবে enum মেম্বারের মানের জন্য `int` টাইপ ব্যবহৃত হয়। enum ডিক্লারেশনে টাইপ উল্লেখ করে ভিন্ন একটি ইন্টিজার টাইপ ব্যবহার করা যায়:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
