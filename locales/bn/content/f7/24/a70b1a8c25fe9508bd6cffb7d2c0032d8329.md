# পরিচিতি

## JavaScript-এ রেগুলার এক্সপ্রেশন

একটি [রেগুলার এক্সপ্রেশন][mdn-regular-expressions] (বা রেজেক্স) হলো এমন এক গুচ্ছ ক্যারেক্টার, যা দিয়ে আমরা স্ট্রিংয়ের নির্দিষ্ট কিছু এলিমেন্ট টার্গেট ও ম্যানিপুলেট করতে পারি। তাই আমরা করতে পারি:

- স্ট্রিংয়ের ভেতরে কোনো টেক্সট **সার্চ** করা
- স্ট্রিংয়ের সাবস্ট্রিং **রিপ্লেস** করা
- স্ট্রিং থেকে তথ্য **এক্সট্র্যাক্ট** করা

> 💡 JavaScript-এর রেজেক্স ফ্লেভার ভাষাটির ECMA-262 স্ট্যান্ডার্ডের অংশ। এর মানে হলো, ব্রাউজার-নির্দিষ্ট সামঞ্জস্য নিয়ে আপনাকে চিন্তা করতে হবে না।

## কীভাবে রেগুলার এক্সপ্রেশন তৈরি করবেন

JavaScript-এ রেগুলার এক্সপ্রেশন বেশিরভাগ ক্ষেত্রে `/pattern/modifiers` ফরম্যাটে লেখা হয়।

রেগুলার এক্সপ্রেশন তৈরি করার দুটি উপায় আছে:

1. **রেগুলার এক্সপ্রেশন লিটারাল**:

```javascript
const regex = /[a-z]/;
```

2. কনস্ট্রাক্টর **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

দুটি ক্ষেত্রেই JavaScript রেজেক্স থেকে একটি অবজেক্ট তৈরি করে। ডিফল্ট হিসেবে লিটারাল দিয়ে ইমিউটেবল প্যাটার্ন ব্যবহার করার পরামর্শ দেওয়া হয়।

RegExp কনস্ট্রাক্টর এমন ক্ষেত্রে ব্যবহার করা যায়, যেখানে রেজেক্সটি বদলে যাবে বা আমরা সেটি এখনো জানি না (যেমন কোনো ইনপুট)।

## 🏴‍☠️ ফ্ল্যাগ

রেগুলার এক্সপ্রেশনের [`flags`][mdn-flags] নামে ঐচ্ছিক সুপারপাওয়ার আছে, যেগুলো দিয়ে বাড়তি সুবিধা পাওয়া যায়।

এর মধ্যে বহুল ব্যবহৃত কয়েকটি হলো:

- `/g` - গ্লোবাল সার্চ
- `/i` - কেস ইনসেনসিটিভ
- `/m` - মাল্টিলাইন সার্চ

এখানে একটি সহজ উদাহরণ:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

`g` ক্যারেক্টারটি একটি স্ট্রিংয়ের সব সম্ভাব্য ম্যাচ খুঁজে বের করতে দেয়। এই ফিচারটি না থাকলে JavaScript কেবল প্রথম `Home` ম্যাচটিই বের করত।

কেস ইনসেনসিটিভ ফ্ল্যাগ `/i` প্যাটার্ন খোঁজার সময় আমাদের নমনীয় করে তোলে। ফলে আমরা যা খুঁজছি সেটি `UPPERCASE` না `lowercase`, তা নিয়ে ভাবতে হয় না।

`RegExp` কনস্ট্রাক্টর ব্যবহার করলে ফ্ল্যাগ যোগ করার সিনট্যাক্স আলাদা হয়।

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## সবচেয়ে কমন ফাংশন

JavaScript-এর বর্তমান বিল্ট-ইন ফাংশনগুলোর সাথে রেগুলার এক্সপ্রেশন মিলিয়ে ব্যবহার করলে স্ট্রিং থেকে ডেটা বের করা ও ম্যানিপুলেট করার বেশ কিছু শক্তিশালী উপায় আমাদের হাতে আসে।

এগুলো রেজেক্সের সাথে ব্যবহৃত সবচেয়ে কমন ফাংশনগুলোর কয়েকটি।

### Test

[test()][mdn-regex-test]] মেথডটি একটি রেগুলার এক্সপ্রেশন আর একটি নির্দিষ্ট স্ট্রিংয়ের মধ্যে ম্যাচ খুঁজতে সার্চ চালায়। এটি ট্রু বা ফলস রিটার্ন করে।

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

[match()][mdn-regex-match] মেথডটি দিয়ে আমরা একটি কাজের অ্যারে পাই, যার ভেতরের বিষয়বস্তু নির্ভর করে ম্যাচগুলো পাওয়া গেল কি না তার উপর।

এভাবে আমরা যেকোনো স্ট্রিং থেকে তথ্য **সার্চ** ও **এক্সট্র্যাক্ট** দুটোই করতে পারি। যেমন:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

গ্লোবাল সার্চ ফ্ল্যাগ `/g` থাকলে মেথডটি কেবল একটি ম্যাচ আর ইনডেক্স বা ইনপুটের মতো দরকারি তথ্য না দিয়ে, অ্যারেতে দেখানো সব ম্যাচ রিটার্ন করে:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScript-এর [replace()][mdn-regex-replace] মেথডটি দিয়ে আমরা একটি নির্দিষ্ট স্ট্রিংয়ের ভেতরে কোনো মান খুঁজে সেটিকে পছন্দের নতুন মান দিয়ে বদলে দিতে পারি।

```javascript
string.replace(searchValue, newValue);
```

বদলানোর জন্য খোঁজার প্যাটার্নটি একটি স্ট্রিংও হতে পারে, আবার একটি রেগুলার এক্সপ্রেশনও হতে পারে।

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

এছাড়া প্রতিটি মানে বাড়তি পরিবর্তন আনতে আমরা রিপ্লেসমেন্টের জায়গায় একটি ফাংশন প্রয়োগ করতে পারি।

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

JavaScript-এর [split()][mdn-regex-split] মেথড রেগুলার এক্সপ্রেশন দিয়ে স্ট্রিং ব্যবহার ও ম্যানিপুলেট করার এক ভিন্ন উপায়।

এভাবে আমরা একটি প্যাটার্ন চিনে নিয়ে সেটি দিয়ে নির্দিষ্ট একটি স্ট্রিং ভাগ করব, যেমন `str.split(/[,.\s]/)`। এই প্যাটার্নটিই `separator` হিসেবে কাজ করবে।

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
