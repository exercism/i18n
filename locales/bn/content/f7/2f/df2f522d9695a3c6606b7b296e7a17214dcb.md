# পরিচিতি

## JSON

JSON (JavaScript Object Notation) মানুষের পড়ার উপযোগী একটি ডেটা ও ফাইল ফরম্যাট, যা সাধারণত ডেটা আদান-প্রদানের জন্য ব্যবহৃত হয়, বিশেষ করে ওয়েব অ্যাপ্লিকেশনে। তাই Elm ভাষায় এর একটি বিশেষ স্থান আছে, আর এটি আশ্চর্যজনক কিছু নয়।

JSON ডেটা পার্স ও লেখার জন্য Elm কোর মডিউল `Json.Decode` ও `Json.Encode` দেয়। JSON ডিকোডার হলো একটি উপায়, যার মাধ্যমে আপনি _ঘোষণা_ করেন কী ধরনের ডেটা প্রত্যাশিত এবং ডেটাটি কোন ডেটা স্ট্রাকচারে ম্যাপ হবে।

চলুন মডিউল থেকে কিছু অ্যালিয়াস ও টাইপ ইমপোর্ট করি:

```elm
import Json.Decode as Decode exposing (Decoder, Error)
import Json.Encode as Encode exposing (Value)
```

একটি ডিকোডার ও একটি JSON স্ট্রিং নিয়ে `Decode.decodeString : Decoder a -> String -> Result Error a` ব্যবহার করলে, স্ট্রিংটি ডিকোডারের স্পেসিফিকেশন মেনে চললে সফল হবে, নইলে ব্যর্থ হবে।
ডিকোডার ডিফাইন করার সময় কাঁচা JSON ডেটা দেখার কোনো উপায় নেই, যা ইমপারেটিভ ভাষা থেকে আসা কারো কাছে অস্বাভাবিক লাগতে পারে।

## মৌলিক ডেটা টাইপের ডিকোডার

JSON-এ অল্প কিছু কোর ডেটা টাইপ আছে:

- স্ট্রিং: ডাবল কোটেশন দিয়ে এনকোড করা হয় `"hello world"`
- বুলিয়ান: হয় `true`, নয়তো `false`
- সংখ্যা: যেমন `34` বা `0.12`
- নাল: ডেটার অনুপস্থিতি `null`

এগুলোর প্রত্যেকটির সাথে একটি করে `Decode` ফাংশন যুক্ত আছে:

```elm
Decode.decodeString Decode.string """\"hello\""""
    --> Ok "hello"

Decode.decodeString Decode.string """null"""
    --> Err ...

Decode.decodeString Decode.bool """true"""
    --> Ok True

Decode.decodeString Decode.bool """0"""
    --> Err ...

Decode.decodeString Decode.int """12"""
    --> Ok 12

Decode.decodeString Decode.float """3.14"""
    --> Ok 3.14

Decode.decodeString (Decode.null AnyValue) """null"""
    --> Ok AnyValue

Decode.decodeString (Decode.null AnyValue) """true"""
    --> Err ...
```

লক্ষ্য করুন, `Decode.null` আর্গুমেন্ট হিসেবে একটি ইচ্ছামতো মান চায়, ফলে আপনার প্রোগ্রামে `null`-কে কীভাবে মডেল করবেন সেটি আপনি নিজেই ঠিক করতে পারেন (হতে পারে `()`, `Nothing`, বা আপনার প্রোগ্রামের জন্য উপযুক্ত অন্য কিছু)।

## ডিকোডার একত্র করা

কোর ডেটা টাইপগুলো একত্র করার জন্য JSON আরও দুটি ডেটা স্ট্রাকচার নির্ধারণ করে:

- অ্যারে: অন্য ডেটা টাইপের একটি সংগ্রহ `[0, null, "none", []]`
- অবজেক্ট: কী (key)-ভ্যালু জোড়ার একটি সংগ্রহ `{"id": 1, "is_admin": false, "more_info": {}}`

এগুলো ডিকোড করার জন্যও `Decode` ফাংশন দেয়:

```elm
Decode.decodeString (Decode.list Decode.int) """[1, 2, 3]"""
    --> Ok [1, 2, 3]

Decode.decodeString (Decode.list Decode.int) """[1, 2, 3, "not an int"]"""
    --> Err ...

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": 71 }"""
    --> Ok (Dict.fromList [("key1", 17), ("key2", 71)])

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": "seventy-one" }"""
    --> Err ...
```

এই ফাংশন দুটি, `Decode.list : Decoder a -> Decoder (List a)` ও `Decode.dict : Decoder a -> Decoder (Dict String a)`, প্রত্যেকটিই আর্গুমেন্ট হিসেবে একটি ডিকোডার চায়, যা দিয়ে ডেটা স্ট্রাকচারের প্রতিটি এলিমেন্ট ডিকোড হওয়ার কথা।
আর্গুমেন্ট ডিকোডারটি যদি অ্যারে বা অবজেক্টের কোনো একটি এলিমেন্টও ডিকোড করতে ব্যর্থ হয়, তাহলে পুরো ডিকোডারটিই ব্যর্থ হয়, আর এটি একটি কমন প্যাটার্ন।

সরল ডিকোডারগুলোকে আরও জটিল ডিকোডারে একত্র করাই এই কৌশলের মূল ধারণা।
একটি উদাহরণের মাধ্যমে আমরা আরও কয়েকটি ফাংশন দেখাব, যা দিয়ে বাস্তব জগতের যত জটিল ডেটা ডিকোডারই হোক তৈরি করা যায়।

## GeoJSON

জটিল JSON ডেটা পার্স করার জন্য মৌলিক ডিকোডার একত্র করার অনুশীলন করতে, চলুন GeoJSON ডেটার (একটি উপসেট) পার্স করার জন্য ডিকোডার তৈরি করি।
GeoJSON হলো JSON-ভিত্তিক একটি বিশেষায়িত ডেটা ফরম্যাট, যা ভৌগোলিক বৈশিষ্ট্য, যেমন অবস্থান, পথ বা অঞ্চল, 2D বা 3D ভৌগোলিক কোঅর্ডিনেট ও আরও কিছু বৈশিষ্ট্য দিয়ে প্রকাশ করতে ব্যবহৃত হয়।

### জিওমেট্রি অবজেক্ট

একটি GeoJSON জিওমেট্রি অবজেক্ট হলো এমন একটি অবজেক্ট, যেখানে `type` নামে একটি ফিল্ড থাকে যার মান একটি স্ট্রিং (সম্ভাব্য মান ৭টি), এবং `coordinates` নামে একটি ফিল্ড থাকে যার মান ভৌগোলিক কোঅর্ডিনেট (কোন স্ট্রাকচারে সেগুলো থাকবে তা `type`-এর উপর নির্ভর করে)।
উদাহরণস্বরূপ,

```json
{
  "type": "Point",
  "coordinates": [127.831, 26.461]
}
```

বা

```json
{
  "type": "LineString",
  "coordinates": [
    [127.831, 26.461],
    [127.829, 26.465],
    [127.829, 26.469],
    [127.83, 26.47]
  ]
}
```

Elm-এ একটি জিওমেট্রি অবজেক্টকে নিচের টাইপ দিয়ে প্রকাশ করা যায়

```elm
type Geometry
  = Point (List Float)
  | LineString (List (List Float))
  | ...
```

কোনো নির্দিষ্ট ফিল্ডের মান যাচাই করতে আমরা `Decode.field : String -> Decoder a -> Decoder a` ব্যবহার করতে পারি, যা একটি অবজেক্টের নির্দিষ্ট একটি কী (key)-এর মান ডিকোড করে।

```elm
decodePointCoordinates : Decoder (List Float)
decodePointCoordinates =
    Decode.field "coordinates" (Decode.list Decode.float)

decodeLineStringCoordinates : Decoder (List (List Float))
decodeLineStringCoordinates =
    Decode.field "coordinates" (Decode.list (Decode.list Decode.float))
```

একটি ডিকোডার সফলভাবে যে মান পার্স করেছে সেটি রূপান্তর করতে আমরা `Decode.map : (a -> value) -> Decoder a -> Decoder value` বা তার সহোদর ফাংশনগুলো ব্যবহার করতে পারি, `Decode.map2  (a -> b -> value) -> Decoder a -> Decoder b -> Decoder value` থেকে `Decode.map8` পর্যন্ত।

এক্ষেত্রে `type` ফিল্ডের মানের উপর নির্ভর করে কোন কোঅর্ডিনেট ডিকোডার ব্যবহার করব তা আমাদের ঠিক করতে হবে, আর এ কাজটি একেবারে উপযুক্ত `Decode.andThen : (a -> Decoder b) -> Decoder a -> Decoder b` এবং তার বন্ধুদের জন্য: `Decode.succeed : a -> Decoder a` ও `Decode.fail : String -> Decoder a`।

```elm
decodeGeometry : Decoder Geometry
decodeGeometry =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                case value of
                    "Point" ->
                        decodePointCoordinates |> Decode.map Point

                    "LineString" ->
                        decodeLineStringCoordinates |> Decode.map LineString

                    _ ->
                        Decode.fail "Geometry not implemented yet, or invalid type value"
            )
```

এখানে লক্ষ্য করুন, কোঅর্ডিনেট যাচাই করতেও আমরা `Decode.andThen` ব্যবহার করতে পারি (যাচাই করা যে কোঅর্ডিনেটগুলো জোড়ায় বা ত্রিপলে আসছে, এবং কোঅর্ডিনেটের মানগুলো ভৌগোলিকভাবে অর্থপূর্ণ কি না)।

```elm
Decode.decodeString decodeGeometry """{"type": "Point", "coordinates": [127.831, 26.461]}"""
    --> Ok (Point [127.831, 26.461])

Decode.decodeString decodeGeometry """{"type": "LineString", "coordinates": [127.831, 26.461]}"""
    --> Err ...
```

### ফিচার অবজেক্ট

একটি GeoJSON ফিচার অবজেক্ট এমন একটি বস্তু প্রকাশ করে যার একটি স্থানিক সীমা আছে: এতে `type` নামে একটি ফিল্ড থাকে যার মান `"Feature"`, `geometry` নামে একটি ফিল্ড থাকে যার মান একটি জিওমেট্রি অবজেক্ট বা `null`, `properties` নামে একটি ফিল্ড থাকে যার মান একটি ইচ্ছামতো JSON অবজেক্ট বা `null`, এবং ঐচ্ছিক `id` নামে একটি ফিল্ড থাকে যার মান একটি JSON স্ট্রিং বা সংখ্যা।

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": null
}
```

বা

```json
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
```

চলুন প্রথমে `id` ফিল্ডটি নিয়ে কাজ করি।
এটি থাকলে তার মান স্ট্রিং বা সংখ্যা দুটোই হতে পারে, তাই আমরা হয় মানটির জন্য একটি কাস্টম টাইপ বানাতে পারি, নয়তো সবসময় এটিকে স্ট্রিং হিসেবে সংরক্ষণ করতে পারি।

দুটি সম্ভাব্য ডিকোডারের মধ্যে একটি বেছে নিতে আমরা `Decode.oneOf : List (Decoder a) -> Decoder a` ব্যবহার করতে পারি।

```elm
decodeFeatureId : Decoder String
decodeFeatureId =
    Decode.oneOf
        [ Decode.string
        , Decode.int |> Decode.map String.fromInt
        , Decode.float |> Decode.map String.fromFloat
        ]
        |> Decode.field "id"

Decode.decodeString decodeFeatureId """{"id": "seventeen"}"""
    --> Ok "seventeen"

Decode.decodeString decodeFeatureId """{"id": 17}"""
    --> Ok "17"

Decode.decodeString decodeFeatureId """{"type": "Point"}"""
    --> Er ...
```

ফিল্ডটি ঐচ্ছিক বোঝাতে আমরা একই কৌশল ব্যবহার করতে পারি

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.oneOf
        [ decodeFeatureId |> Decode.map Just
        , Decode.succeed Nothing
        ]
```

কিন্তু এর বদলে আমরা `Decode.maybe : Decoder a -> Decoder (Maybe a)` ব্যবহার করতে পারি

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.maybe decodeFeatureId

Decode.decodeString decodeMaybeFeatureId """{"id": 17}"""
    --> Ok (Just "17")

Decode.decodeString decodeMaybeFeatureId """{"type": "Point"}"""
    --> Ok Nothing
```

লক্ষ্য করুন, `decodeMaybeFeatureId` (বা `Decode.maybe` দিয়ে মোড়া যেকোনো ডিকোডার) সবসময় সফল হবে, কারণ এটি সবসময় `Ok Nothing`-এ ফলব্যাক করতে পারে, যদিও এটি ব্যবহার করা কোনো ডিকোডার এখনও ব্যর্থ হতে পারে

```elm
Decode.decodeString (Decode.list decodeMaybeFeatureId) """{"id": 17}"""
    --> Err ...
```

এরপর চলুন `geometry` ফিল্ডে মনোযোগ দিই, যার মান হয় একটি জিওমেট্রি অবজেক্ট, নয়তো `null`।
আমরা আবারও `Decode.oneOf` ব্যবহার করতে পারি, কিন্তু আরও ভালো একটি উপায় আছে: `Decode.nullable : Decoder a -> Decoder (Maybe a)`।

```elm
decodeFeatureGeometry : Decoder (Maybe Geometry)
decodeFeatureGeometry =
    Decode.nullable decodeGeometry
        |> Decode.field "geometry"

Decode.decodeString decodeFeatureGeometry """{"geometry": {"type": "Point", "coordinates": [127.831, 26.461]}}"""
    --> Ok (Just (Point [127.831, 26.461]))

Decode.decodeString decodeFeatureGeometry """{"geometry": null}"""
    --> Ok Nothing

Decode.decodeString decodeFeatureGeometry """{"geometry": {}}"""
    --> Err ...
```

`Decode.maybe` ও `Decode.nullable`-এর সিগনেচার একই, কিন্তু তাদের আচরণ আলাদা, কারণ `Decode.nullable`-এর `OK Nothing` ফলাফল কেবল নির্দিষ্ট JSON মান `null` থেকেই আসবে।

সবশেষে, `properties` ফিল্ডে একটি ইচ্ছামতো JSON অবজেক্ট বা `null` থাকতে পারে, আর এ কাজটি `Decode.value : Decoder Value`-এর।

```elm
decodeProperties : Decoder (Maybe (Dict String Value))
decodeProperties =
    Decode.nullable (Decode.dict Decode.value)
        |> Decode.field "properties"


Decode.decodeString decodeProperties """{"properties": null}"""
    --> Ok Nothing

Decode.decodeString decodeProperties """{"properties": {"country": "Japan"}}"""
    --> Ok (Just (Dict.fromList [("country", <internals>)]))

Decode.decodeString decodeProperties """{"properties": 17}"""
    --> Err ...
```

লক্ষ্য করুন, `Value` একটি অস্বচ্ছ টাইপ, অর্থাৎ এর ভেতরের বিষয়বস্তু সহজে দেখা যায় না।
এটি ব্যবহার করতে আপনি হয় এর জন্য একটি ডিকোডার লিখে `Decode.decodeValue : Decoder a -> Value -> Result Error a` দিয়ে চালাতে পারেন, নয়তো একটি পোর্টের মাধ্যমে এটি সরাসরি JavaScript-এ পাঠাতে পারেন।

আমরা ফিচার অবজেক্ট পার্স করার জন্য তৈরি:

```elm
type alias Feature =
    { id : Maybe String
    , geometry : Maybe Geometry
    , properties : Maybe (Dict String Value)
    }

decodeFeature : Decoder Feature
decodeFeature =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                if value /= "Feature" then
                    Decode.fail "not a Feature"

                else
                    Decode.map3 Feature
                        decodeMaybeFeatureId
                        decodeFeatureGeometry
                        decodeProperties
            )

Decode.decodeString decodeFeature """{"type": "Feature", "geometry": null, "properties": null}"""
    --> Ok { geometry = Nothing, id = Nothing, properties = Nothing }

"""
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
"""
  |> Decode.decodeString decodeFeature
    --> Ok { geometry = Just (Point [127.831,26.461]), id = Just "0157", properties = Just (Dict.fromList [("country",<internals>)]) }
```

## JSON এনকোডার

এনকোডার দিয়ে Elm-এর মান থেকে `Encode.encode : Int -> Value -> String` ফাংশন ব্যবহার করে বৈধ JSON লেখা যায়।
প্রথম আর্গুমেন্টটি চূড়ান্ত ফলাফলে ইন্ডেন্টেশনের পরিমাণ নির্ধারণ করে, আর দ্বিতীয় আর্গুমেন্টটি হলো যে JSON মানটি লিখতে হবে।

একটি `Value` হয় `Decode.value` থেকে পাওয়া যায়, নয়তো এনকোডারগুলোর একটি দিয়ে তৈরি করা যায়:

```elm
Encode.encode 0 (Encode.string "hello")
    --> "hello"

Encode.encode 0 (Encode.bool True)
    --> "true"

Encode.encode 0 (Encode.int 12)
    --> "12"

Encode.encode 0 (Encode.float 3.14)
    --> "3.14"

Encode.encode 0 Encode.null
    --> "null"

Encode.encode 0 (Encode.list Encode.int [1, 2, 3])
    --> "[1,2,3]"

Encode.encode 4 (Encode.list Encode.int [1, 2, 3])
    --> "[\n    1,\n    2,\n    3\n]"

Encode.encode 0 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\"key1\":17,\"key2\":71}"

Encode.encode 4 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\n    \"key1\": 17,\n    \"key2\": 71\n}"
```

সেই সঙ্গে `Encode.object : List ( String, Value ) -> Value` দিয়েও

```elm
Encode.object
    [ ( "key1", Encode.int 17 )
    , ( "key2", Encode.int 71 )
    ]
    |> Encode.encode 0
    --> "{\"key1\":17,\"key2\":71}"
```

চলুন আগে ডিফাইন করা GeoJSON ডিকোডারগুলোর জন্য এনকোডার ডিফাইন করি

```elm
encodeGeometry : Geometry -> Value
encodeGeometry geometry =
    case geometry of
        Point coord ->
            Encode.object
                [ ( "type", Encode.string "Point" )
                , ( "coordinates", Encode.list Encode.float coord )
                ]

        LineString coord ->
            Encode.object
                [ ( "type", Encode.string "LineString" )
                , ( "coordinates", Encode.list (Encode.list Encode.float) coord )
                ]

encodeFeature : Feature -> Value
encodeFeature feature =
    let
        maybeId =
            case feature.id of
                Nothing ->
                    []

                Just id ->
                    [ ( "id", Encode.string id ) ]
    in
    Encode.object
        (maybeId
            ++ [ ( "type", Encode.string "Feature" )
               , ( "geometry"
                 , case feature.geometry of
                    Nothing ->
                        Encode.null

                    Just geometry ->
                        encodeGeometry geometry
                 )
               , ( "properties"
                 , case feature.properties of
                    Nothing ->
                        Encode.null

                    Just dict ->
                        Encode.dict identity identity dict
                 )
               ]
        )
```

সাধারণভাবে, আপনার ডিকোডার-এনকোডার জোড়ার জন্য একটি ভালো পরীক্ষা হলো `elmValue |> encoder |> decoder == elmValue` মিলছে কি না তা যাচাই করা।
