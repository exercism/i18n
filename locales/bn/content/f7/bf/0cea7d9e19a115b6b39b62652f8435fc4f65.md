# ভূমিকা

## কাস্টম টাইপ

Elm-এ [কাস্টম টাইপ][custom-types] নির্দিষ্ট সংখ্যক নামযুক্ত কেস প্রকাশ করে। প্রতিটি মান নামযুক্ত কেসগুলোর মধ্যে ঠিক একটির সাথে মেলে।

কাস্টম টাইপ `type` কিওয়ার্ড দিয়ে ডিফাইন করা হয় এবং এতে খুব কম সিনট্যাক্স লাগে। Elm প্রোগ্রামিংয়ের সবচেয়ে গুরুত্বপূর্ণ কৌশলগুলোর একটি হলো এগুলো। কোডে সম্ভাব্য মানগুলোকে বাস্তব জীবনের বৈধ মানগুলোর সাথে হুবহু মিলিয়ে দিতেই এগুলো ব্যবহার করা হয়, ফলে অবৈধ ডেটার কোনো সুযোগই থাকে না এবং [অসম্ভব অবস্থা কোডে প্রকাশ করা অসম্ভব হয়ে পড়ে][impossible-states]।

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

কাস্টম টাইপের প্রতিটি কেসের সাথে চাইলে ডেটা যুক্ত থাকতে পারে, আর ভিন্ন ভিন্ন কেসে ভিন্ন ধরনের ডেটা থাকতে পারে। কোনো কেসের সাথে ডেটা যুক্ত না থাকলে, ডিসক্রিমিনেটেড ইউনিয়ন অনেকটা সেরকমই, যা অন্য ভাষায় সাধারণত _এনুমারেশন_ (বা _এনাম_) নামে পরিচিত।

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

কোনো নির্দিষ্ট কেসের জন্য মান তৈরি করা যায় তার নাম উল্লেখ করে (`Spring`), যখন কেসটি একই মডিউলে ডিফাইন করা থাকে বা `import SeasonModule exposing (Season(..))` ধরনের সিনট্যাক্স দিয়ে ইমপোর্ট করা হয়; অথবা `import SeasonModule exposing (Season)` ধরনের সিনট্যাক্স দিয়ে ইমপোর্ট করা হলে তার ফুলি কোয়ালিফাইড নাম (`Season.Spring`) উল্লেখ করে।

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Elm-এর সবকিছুর মতো কাস্টম টাইপেরও _স্ট্রাকচারাল ইকুয়ালিটি_ আছে, অর্থাৎ একই কেসের এবং একই (ঐচ্ছিক) ডেটাযুক্ত দুটি মান সমতুল্য।

কাস্টম টাইপ নিয়ে কাজ করার সবচেয়ে পছন্দের উপায় হলো [প্যাটার্ন ম্যাচিং][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
