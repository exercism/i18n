# ভূমিকা

## রিকারশন

নিজের সাপেক্ষে কোনো কিছুকে সংজ্ঞায়িত করার ক্ষমতাকে রিকারশন বলা হয়। F#-এ রিকারশন সবচেয়ে বেশি রিকারসিভ ফাংশনে দেখা যায়, যেগুলো নিজেদের কল করে।

একটি রিকারসিভ ফাংশনে অন্তত একটি _বেস কেস_ এবং অন্তত একটি _রিকারসিভ কেস_ থাকতে হয়। একটি _বেস কেস_ ফাংশনটিকে আবার কল না করেই একটি মান রিটার্ন করে। একটি _রিকারসিভ কেস_ ফাংশনটিকে আবার কল করে এবং ইনপুট পরিবর্তন করে, যাতে সেটি একসময় বেস কেসের সাথে মিলে যায়।

রিকারসিভ ফাংশন সাধারণ ফাংশনের মতোই ডিফাইন করা হয়, তবে `rec` মডিফায়ার-সহ। এই মডিফায়ার ছাড়া একটি ফাংশন নিজেকে কল করতে _পারবে না_, এবং এরকম করার কোনো চেষ্টা করলে কম্পাইলেশন এরর হবে। তাই রিকারশনকে স্পষ্টভাবে বেছে নিতে হয়।

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# ডিসক্রিমিনেটেড ইউনিয়ন টাইপের মাধ্যমে রিকারসিভ টাইপও সমর্থন করে। একটি রিকারসিভ ডিসক্রিমিনেটেড ইউনিয়ন টাইপের এক বা একাধিক কেস তাদের ডেটাতে ডিসক্রিমিনেটেড ইউনিয়ন টাইপটিকেই রেফার করে। রিকারসিভ ফাংশনের মতোই, রিকারসিভ টাইপেও একটি বেস কেস থাকতে হয়। রিকারসিভ ফাংশনের বিপরীতে, রিকারসিভ টাইপ `rec` কিওয়ার্ড ব্যবহার করে না।

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
