# নির্দেশনা

_Instruments of Texas_-এ একটি পরীক্ষামূলক RPN ক্যালকুলেটর নিয়ে আপনার কাজ চলছে। আপনার দল কয়েকটি প্রোটোটাইপ তৈরি করেছে, যেগুলো পুঙ্খানুপঙ্খভাবে পরীক্ষা করতে হবে, যাতে বড় পরিসরে উৎপাদন করা যায় এমন সবচেয়ে ভালোটি বেছে নেওয়া যায়।

আপনি দুই ধরনের যাচাই চালাতে চান।

প্রথমত, একটি নির্ভরযোগ্যতা যাচাই, যা এমন ইনপুট শনাক্ত করবে যেগুলোর জন্য পরীক্ষাধীন ক্যালকুলেটর হয় ক্র্যাশ করে, নয়তো যথেষ্ট দ্রুত সাড়া দেয় না। ব্যর্থতাগুলো আলাদা করে ধরার জন্য প্রতিটি ইনপুটের হিসাব আলাদা একটি প্রসেসে চালাতে হবে। যে প্রসেস কল করছে সেটিতে লিংক করা এবং এক্সিট ট্র্যাপ করার মাধ্যমে শনাক্ত করা যায় যে হিসাবটি শেষ হয়েছে নাকি ক্র্যাশ করেছে।

দ্বিতীয়ত, একটি সঠিকতা যাচাই, যা দেখবে যে কোনো একটি ইনপুটের জন্য ক্যালকুলেটর যে ফলাফল রিটার্ন করে তা প্রত্যাশিত কি না। কেবল যে ক্যালকুলেটরগুলো আগেই নির্ভরযোগ্যতা যাচাইয়ে উত্তীর্ণ হয়েছে, সেগুলোরই সঠিকতা যাচাই হবে, তাই ক্র্যাশ নিয়ে চিন্তার কিছু নেই। তবে অপারেশনগুলো একসাথে চালানো উচিত যাতে কাজটি দ্রুত হয়, আর এটাই অ্যাসিনক্রোনাস টাস্কের জন্য একেবারে উপযুক্ত ইউজ কেস।

## 1. একটি ইনপুটের জন্য নির্ভরযোগ্যতা যাচাই শুরু করুন

`RPNCalculatorInspection.start_reliability_check/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে: একটি ফাংশন (ক্যালকুলেটর) এবং ক্যালকুলেটরের জন্য একটি ইনপুট। এটি এমন একটি ম্যাপ রিটার্ন করবে যাতে ইনপুটটি এবং স্পন করা প্রসেসের PID থাকবে।

স্পন করা প্রসেসটি দেওয়া ইনপুট দিয়ে দেওয়া ক্যালকুলেটর ফাংশনটি কল করবে। প্রসেসটি যে প্রসেস কল করছে সেটির সাথে লিংক করা থাকবে।

```elixir
RPNCalculatorInspection.start_reliability_check(fn _ -> 0 end, "2 3 +")
# => %{input: "2 3 +", pid: #PID<0.169.0>}
```

## 2. নির্ভরযোগ্যতা যাচাইয়ের ফলাফল ব্যাখ্যা করুন

`RPNCalculatorInspection.await_reliability_check_result/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে। প্রথম আর্গুমেন্টটি হলো এমন একটি ম্যাপ, যাতে নির্ভরযোগ্যতা যাচাইয়ের ইনপুট এবং এই ইনপুটের জন্য নির্ভরযোগ্যতা যাচাই চালানো প্রসেসের PID থাকে, ঠিক যেভাবে `RPNCalculatorInspection.start_reliability_check/2` রিটার্ন করে। দ্বিতীয় আর্গুমেন্টটি একটি ম্যাপ, যা বিভিন্ন ইনপুটের নির্ভরযোগ্যতা যাচাইয়ের ফলাফলের জন্য অ্যাকুমুলেটর হিসেবে কাজ করে।

ফাংশনটি একটি এক্সিট মেসেজের জন্য অপেক্ষা করবে।

যদি এটি নির্ভরযোগ্যতা যাচাই চালানো একই প্রসেস থেকে `:normal` কারণসহ একটি এক্সিট মেসেজ (`{:EXIT, from, reason}`) পায়, তাহলে ফলাফলের ম্যাপে `input` কী (key)-এর অধীনে `:ok` মান যোগ করে সেটি রিটার্ন করবে।

যদি এটি নির্ভরযোগ্যতা যাচাই চালানো একই প্রসেস থেকে ভিন্ন কোনো কারণসহ একটি এক্সিট মেসেজ পায়, তাহলে ফলাফলের ম্যাপে `input` কী (key)-এর অধীনে `:error` মান যোগ করে সেটি রিটার্ন করবে।

যদি 100ms-এর মধ্যে এই শর্তগুলোর সাথে মেলে এমন কোনো মেসেজ না পায়, তাহলে ফলাফলের ম্যাপে `input` কী (key)-এর অধীনে `:timeout` মান যোগ করে সেটি রিটার্ন করবে।

```elixir
# when an exit message is waiting for the process in its inbox
send(self(), {:EXIT, pid, :normal})

RPNCalculatorInspection.await_reliability_check_result(
  %{input: "5 7 -", pid: pid},
  %{}
)

# => %{"5 7 -" => :ok}

# when there are no messages in the process inbox
RPNCalculatorInspection.await_reliability_check_result(
  %{input: "3 2 *", pid: pid},
  %{"5 7 -" => :ok}
)

# => %{"5 7 -" => :ok, "3 2 *" => :timeout}
```

## 3. অনেক ইনপুটের জন্য একসাথে নির্ভরযোগ্যতা যাচাই চালান

`RPNCalculatorInspection.reliability_check/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে: একটি ফাংশন (ক্যালকুলেটর) এবং ক্যালকুলেটরের জন্য ইনপুটের একটি অ্যারে।

অ্যারের প্রতিটি ইনপুটের জন্য এটি `start_reliability_check/2` ব্যবহার করে একটি নতুন লিংক করা প্রসেসে নির্ভরযোগ্যতা যাচাই শুরু করবে। তারপর এভাবে চালু হওয়া প্রতিটি প্রসেসের জন্য `await_reliability_check_result/2` ব্যবহার করে তার ফলাফলের জন্য অপেক্ষা করবে।

কোনো প্রসেস শুরু করার আগে, এক্সিট মেসেজ পেতে সক্ষম হতে ফাংশনটিকে বর্তমান প্রসেসে এক্সিট ট্র্যাপ করার ফ্ল্যাগ সেট করতে হবে। পরে এটি এই ফ্ল্যাগটি তার আগের মানে রিসেট করবে।

ফাংশনটি সব ইনপুটের নির্ভরযোগ্যতা যাচাইয়ের ফলাফলসহ একটি ম্যাপ রিটার্ন করবে।

```elixir
fake_broken_calculator = fn input ->
  if String.ends_with?(input, "*"), do: raise("oops")
end

inputs = ["2 3 +", "10 3 *", "20 2 /"]

RPNCalculatorInspection.reliability_check(fake_broken_calculator, inputs)
# => %{
#       "2 3 +" => :ok,
#       "10 3 *" => :error,
#       "20 2 /" => :ok
#     }
```

## 4. অনেক ইনপুটের জন্য একসাথে সঠিকতা যাচাই চালান

`RPNCalculatorInspection.correctness_check/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি দুটি আর্গুমেন্ট নেবে: একটি ফাংশন (ক্যালকুলেটর) এবং ক্যালকুলেটরের জন্য ইনপুটের একটি অ্যারে।

অ্যারের প্রতিটি ইনপুটের জন্য এটি একটি অ্যাসিনক্রোনাস টাস্ক চালু করবে, যা দেওয়া ইনপুট দিয়ে ক্যালকুলেটরটি কল করবে। তারপর এভাবে চালু হওয়া প্রতিটি টাস্কের জন্য এটি 100ms ধরে তার ফলাফলের জন্য অপেক্ষা করবে।

```elixir
fast_cheating_calculator = fn input -> 14 end
inputs = ["13 1 +", "50 2 *", "1000 2 /"]
RPNCalculatorInspection.correctness_check(fast_cheating_calculator, inputs)
# => [14, 14, 14]
```
