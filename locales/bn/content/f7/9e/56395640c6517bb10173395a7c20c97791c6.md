# ওয়ার্কফ্লো

GitHub Actions-এ _ওয়ার্কফ্লো_ নামের একটি ধারণা ব্যবহার করা হয়। ওয়ার্কফ্লো হলো এমন স্ক্রিপ্ট, যা নির্দিষ্ট কোনো ইভেন্ট ঘটলেই (যেমন একটি কমিট পুশ করা) স্বয়ংক্রিয়ভাবে চলে।

প্রতিটি GitHub Actions ওয়ার্কফ্লো `.github/workflows` ডিরেক্টরির একটি `.yml` ফাইলে ডিফাইন করা হয়।
ওয়ার্কফ্লো সম্পর্কে জানতে নিচের ডকুমেন্টগুলো দেখুন:

- [ওয়ার্কফ্লো সিনট্যাক্স](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)
- [আপনার ওয়ার্কফ্লো কখন চলে তা বেছে নেওয়া](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/triggering-a-workflow)
- [আপনার ওয়ার্কফ্লো কোথায় চলে তা বেছে নেওয়া](https://docs.github.com/en/actions/writing-workflows/choosing-where-your-workflow-runs)
- [আপনার ওয়ার্কফ্লো কী করবে তা বেছে নিন](https://docs.github.com/en/actions/writing-workflows/choosing-what-your-workflow-does)
- [ওয়ার্কফ্লো লেখা](https://docs.github.com/en/actions/writing-workflows)
- [সেরা চর্চা](/docs/building/github/gha-best-practices)

## শেয়ার করা ওয়ার্কফ্লো

কিছু ওয়ার্কফ্লো একাধিক রিপোজিটরিতে শেয়ার করা থাকে।

```exercism/caution
শেয়ার করা ওয়ার্কফ্লোগুলো স্বয়ংক্রিয়ভাবে সিঙ্ক করা হয় ([org-wide-files রিপো](https://github.com/exercism/org-wide-files/) থেকে)।
তাই এগুলোর বিষয়বস্তু নিজে হাতে পরিবর্তন করা উচিত নয়।
```

### সাধারণ ওয়ার্কফ্লো

- [লেবেল সিঙ্ক](/docs/building/tracks/ci/workflows/sync-labels): ফাইল থেকে রিপোজিটরির লেবেল সিঙ্ক করে

### ট্র্যাক-নির্দিষ্ট ওয়ার্কফ্লো

- [configlet](/docs/building/tracks/ci/workflows/configlet): ট্র্যাকের (কনফিগারেশন) ফাইলগুলোর গঠন সঠিক কি না যাচাই করে - সিনট্যাক্স ও সিমান্টিক্স, দুই দিক থেকেই
- [কোনো গুরুত্বপূর্ণ ফাইল বদলায়নি](/docs/building/tracks/ci/workflows/no-important-files-changed): যেসব পুল রিকোয়েস্টের কারণে বিদ্যমান সলিউশন আবার টেস্ট করা লাগতে পারে, সেগুলোতে কমেন্ট করে
- [Test](/docs/building/tracks/new/setup-continuous-integration#h-test-workflow): ট্র্যাকের অনুশীলনীগুলো যাচাই করে

### টুলিং-নির্দিষ্ট ওয়ার্কফ্লো

- [ডিপ্লয়](/docs/building/tracks/ci/workflows/deploy): ট্র্যাকের টুলিং Docker ইমেজ Docker Hub ও ECR-এ ডিপ্লয় করে

### ঐচ্ছিক ওয়ার্কফ্লো

এমন কিছু ওয়ার্কফ্লোও আছে, যেগুলো ট্র্যাক চাইলে ব্যবহার করতে পারে:

- [কমিউনিটি অবদান সাময়িকভাবে বন্ধ করা](/docs/building/tracks/ci/workflows/pause-community-contributions): Exercism GitHub অর্গানাইজেশনের সদস্য নন এমন ব্যবহারকারীদের তৈরি নতুন ইস্যু ও PR-এ স্বয়ংক্রিয়ভাবে কমেন্ট করে
