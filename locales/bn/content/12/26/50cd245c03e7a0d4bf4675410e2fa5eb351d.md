# স্ট্রিং কনক্যাটেনেশন

Ruby-তে স্ট্রিং কনক্যাটেনেশন সম্পূর্ণ বৈধ, তবে স্ট্রিং তৈরি করার আরও কমন একটি উপায় হলো [স্ট্রিং ইন্টারপোলেশন](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html)। যেমন:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
