# পরিচিতি

আমরা ধরে নিচ্ছি আপনি JSON সিনট্যাক্স ও ডেটা টাইপের সাথে পরিচিত।

jq কাজ করে আসা JSON ডেটাকে একটি _একক এক্সপ্রেশন_-এর ভেতর দিয়ে (যা _ফিল্টারগুলোর একটি পাইপলাইন_ হিসেবে লেখা হয়) পাঠিয়ে, যাতে কাঙ্ক্ষিত রূপান্তরিত ডেটা পাওয়া যায়।

<!-- prettier-ignore -->
~~~~exercism/note
`jq` ভাষাটি বাস্তবায়ন করে `jq` _প্রোগ্রাম_।
এই প্রোগ্রামটি ইনপুট কীভাবে পড়া হবে আর আউটপুট কীভাবে দেখানো হবে তা নিয়ন্ত্রণ করার জন্য বেশ কিছু সুবিধাজনক কমান্ড-লাইন অপশন দেয়।

নিচের উদাহরণগুলোতে আপনি পাবেন:

- `-n` বা `--null-input`

    সাধারণত `jq` প্রোগ্রামটিকে পড়ার জন্য একটি ফাইল দেওয়া হয়, অথবা আপনি তার ইনপুটে ডেটা পাঠান।
    `--null-input` অপশনটি আপনাকে কোনো ইনপুট ছাড়াই JSON ডেটা তৈরি করতে দেয়।

- `-c` বা `--compact-output`

    `jq` ডিফল্টভাবে তার আউটপুট সুন্দরভাবে সাজিয়ে প্রিন্ট করে।
    ডেটা সুন্দরভাবে ফরম্যাট করা থাকলে মানুষ তার দিকে তাকাতে পারে, এটা অত্যন্ত কাজের।
    তবে মেশিনের জন্য এটি দরকার নেই: `--compact-output` অপশনটি ফরম্যাটিংয়ের ফাঁকা জায়গা সরিয়ে তৈরি হওয়া JSON-এর আকার যতটা সম্ভব ছোট করে।

- `-f filename` বা `--from-file filename`

    কমান্ড লাইনে দেয়ার বদলে `filename` থেকে `jq` প্রোগ্রামটি পড়ুন।
    একই উদ্দেশ্যে `sed` আর `awk` দুটোই `-f` অপশনটি ব্যবহার করে।
    প্র্যাকটিস অনুশীলনীগুলোর টেস্ট স্ক্রিপ্টে এটি ব্যবহৃত হতে দেখবেন।

এই পাঠের বাকি অংশে আমরা `jq` _ভাষা_ নিয়েই আলোচনা করব।
~~~~

## ফিল্টার ও পাইপ

**ফিল্টার**কে **এক্সপ্রেশন**ও বলা হয়।

একটি _ফিল্টার_ একটি ইনপুট নেয় এবং একটি আউটপুট দেয়।
ইউনিক্স শেলে আপনি যেভাবে কাজ করেন, ঠিক সেভাবেই আপনি পাইপ `|` দিয়ে _ফিল্টার_গুলো জুড়ে দিতে পারেন, যাতে এক _ফিল্টারের_ আউটপুট আরেকটির ইনপুটে যুক্ত হয়।

## আইডেন্টিটি ফিল্টার: `.`

এটি সবচেয়ে সহজ _ফিল্টার_।
এটি কেবল তার ইনপুট তার আউটপুটে পাঠিয়ে দেয়।

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## অ্যারে

**অ্যারে** নিয়ে কাজ করার একটি সংক্ষিপ্ত পরিচিতি থাকবে এখানে।
এই বিষয়টি আমরা পরে আরও বিস্তারিতভাবে দেখব।

_অ্যারে_-র এলিমেন্টগুলো বন্ধনী দিয়ে অ্যাক্সেস করা হয়, এবং ইনডেক্স শূন্য থেকে শুরু।

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

একটি _ফিল্টার_ একটি এক্সপ্রেশনকে `[` আর `]` দিয়ে ঘিরে একটি _অ্যারে_ তৈরি করতে পারে

- এলিমেন্টের একটি জানা তালিকা দিয়ে:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- এলিমেন্টের একটি স্ট্রিম সংগ্রহ করতে: উদাহরণস্বরূপ,
  `range` একটি ফাংশন যা সংখ্যার একটি স্ট্রিম আউটপুট দেয়

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  `[]` ব্যবহার করলে এক্সপ্রেশনের ফলাফলগুলো একটি অ্যারেতে জড়ো হয়

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## কমা একটি অপারেটর

_কমা_ শুধু _অ্যারে_-র এলিমেন্ট আলাদা করার সিনট্যাক্স নয়।
**কমা** একটি **অপারেটর** যা স্ট্রিমগুলো জুড়ে দেয়।

উদাহরণস্বরূপ, `[1, 2, 3]` একটি _ফিল্টার_ যা `1`, `2` আর `3` এই তিনটি এক্সপ্রেশন জোড়া লাগানোর ফলাফল সংগ্রহ করতে _অ্যারে_ কনস্ট্রাক্টর `[]` ব্যবহার করে।

উপরের `range(10; 70; 15)` কলে সেমিকোলনগুলো খেয়াল করেছেন?
`jq` ভাষায় _কমা_-র একটি নির্দিষ্ট কাজ আছে, তাই একাধিক আর্গুমেন্ট নেয় এমন ফাংশনগুলো আর্গুমেন্ট আলাদা করতে সেমিকোলন ব্যবহার করে।

## অবজেক্ট

**অবজেক্ট** নিয়ে একটি সংক্ষিপ্ত পরিচিতি।

অনেক প্রোগ্রামিং ভাষার মতোই, _অবজেক্ট_-এর প্রোপার্টি অ্যাক্সেস করতে ডট ব্যবহার করুন

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
বন্ধনী _অবজেক্ট_-এর ক্ষেত্রেও ব্যবহার করা যায়, তবে তখন স্ট্রিং লিটারালের জন্য কোটেশন লাগে।
স্পেস আছে এমন কী (key) নিয়ে কাজ করার একটি পদ্ধতি এটি।

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

আপনি `{}` আর `key: value` জোড়া দিয়ে একটি _অবজেক্ট_ তৈরি করতে পারেন।
"সাধারণ" স্ট্রিং যে _কী (key)_গুলো, তাদের চারপাশে কোটেশন লাগে না।

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

আউটপুট দেয়

```none
{
  "question": 54,
  "answer": 42
}
```

কোনো _কী (key)_-কে _এক্সপ্রেশন_ হিসেবে ধরতে হলে সেটিকে বন্ধনীর ভেতরে রাখতে হবে (নিচেরটিও উপরের মতোই আউটপুট দেয়)।

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## পাইপলাইন

উদাহরণস্বরূপ, ধরা যাক `file.json` ফাইলে আছে

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

চলুন key2 _অ্যারে_-র দৈর্ঘ্য বের করি:

```sh
$ jq '.key2 | length' file.json
3
```

আমরা `.key2` এক্সপ্রেশনের আউটপুট `length` ফাংশনে ইনপুট হিসেবে _পাইপ_ করছি, যা স্বাভাবিকভাবেই _অ্যারে_-র এলিমেন্টের সংখ্যা আউটপুট দেয়।

## ফিল্টার নিজের ইনপুট উপেক্ষা করতে পারে

এই উদাহরণে ইনপুট JSON ডেটা উপেক্ষিত হয় এবং আউটপুটে কোনো প্রভাব ফেলে না:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## ফিল্টার ডেটার স্ট্রিম আউটপুট দিতে পারে

একটি _ফিল্টার_ একাধিক মান আউটপুট দিতে পারে।
উদাহরণস্বরূপ, `.[]` _ফিল্টার_ একটি _অ্যারে_-র প্রতিটি এলিমেন্ট আলাদা মান হিসেবে আউটপুট দেয়:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

এমন একটি _ফিল্টার_ থেকে অন্যটিতে পাইপ করলে **_প্রতিটি মানের জন্য_** দ্বিতীয় _ফিল্টার_টি চালানো হয়:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

এটি অনেকটা অন্তর্নিহিত ইটারেশনের মতো।
একবার এই কৌশলটি বুঝে গেলে আপনি বুঝবেন, খুব শক্তিশালী `jq` _ফিল্টার_ কত সংক্ষিপ্ত হতে পারে।

## বন্ধনী

অন্য ভাষাগুলোর মতোই, অপারেশনের ক্রম নিশ্চিত করতে সাব-এক্সপ্রেশনগুলোকে একসাথে দলবদ্ধ করতে **বন্ধনী** ব্যবহার করা হয়।
তবে `jq` ভাষায় এগুলোর প্রয়োজন পড়াটা কিছুটা অপ্রত্যাশিত মনে হতে পারে।

উদাহরণস্বরূপ, ধরা যাক আমরা ২টি এলিমেন্ট নিয়ে একটি _অ্যারে_ তৈরি করতে চাই: ৯-এর বর্গমূল, আর ১ ঘাতে উন্নীত _e_।
দুটি আলাদা এক্সপ্রেশন হলো `9 | sqrt` আর `1 | exp`।
আমরা আশা করব আউটপুট হবে _অ্যারে_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

আমরা যা আশা করেছিলাম তা পাইনি কেন? `jq` সেটিকে এভাবে ব্যাখ্যা করে:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` দুটি এলিমেন্টের (`3` আর `1`) একটি স্ট্রিম তৈরি করে, যাদের প্রত্যেকটিকে `exp` ফাংশনে পাঠানো হয়।

আমাদের নিশ্চিত করতে হবে যে `exp` ইনপুট হিসেবে কেবল একটি সংখ্যা নেয়।
অর্থাৎ, কমার আগেই পাইপটি মূল্যায়িত হয় তা আমাদের নিশ্চিত করতে হবে।

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## ফাংশন ও অপারেটর

বেশ গভীরে না গিয়েই (ফাংশন নিয়ে আলোচনা থাকবে অন্য একটি অনুশীলনীতে), এখানে কিছু কাজের বিল্ট-ইন ফাংশন রইল:

- `length`

  ইনপুট হিসেবে একটি অ্যারে পেলে অ্যারের এলিমেন্ট সংখ্যা আউটপুট দেয়।

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  এই অপারেটরটি তার অপারেন্ডের টাইপ অনুযায়ী ভিন্ন ভিন্ন কাজ করে:
  সংখ্যা যোগ করে,
  স্ট্রিং জোড়া লাগায়,
  অ্যারে যুক্ত করে,
  অবজেক্ট মার্জ করে।

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` একটি ফাংশন যা একটি অ্যারে নেয় এবং `+` অপারেটরের নিয়ম মেনে সব এলিমেন্ট একসাথে যোগ করে একটি মান রিটার্ন করে।
  `[1, 2, 3] | add` আউটপুট দেয় `6`।

- `map`

  ইনপুট হিসেবে একটি অ্যারে আর আর্গুমেন্ট হিসেবে একটি ফিল্টার পেলে এমন একটি অ্যারে আউটপুট দেয় যেখানে প্রতিটি এলিমেন্টে ফিল্টারটি প্রয়োগ করা হয়েছে

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  _কোনো_ ইনপুট আর আর্গুমেন্ট হিসেবে একটি ফিল্টার পেলে:
  - আর্গুমেন্টে প্রয়োগ করা ফিল্টারটির ফল _ট্রু_ মান হলে ইনপুটটি অপরিবর্তিত আউটপুট দেয়
  - নাহলে _কিছুই_ আউটপুট দেয় না (`null` মান নয়, সত্যিকারভাবে কোনো আউটপুটই নয়)

  উদাহরণস্বরূপ, কিছু সংখ্যা দেওয়া থাকলে, ৩ দিয়ে বিভাজ্য সংখ্যাগুলো বেছে নিন

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  মনে করুন, `range` সংখ্যার একটি _স্ট্রিম_ আউটপুট দেয়।
  `select` প্রতিটি সংখ্যার জন্য একবার করে ডাকা হবে।
  কেবল যে সংখ্যাগুলো এক্সপ্রেশনটি "পাস" করে সেগুলোই আউটপুটে আসে।

  আপনাকে প্রায়ই একটি অ্যারের এলিমেন্ট বেছে নিতে হয়।
  এটি করার কয়েকটি উপায় আছে।

  `["Anne", "Bob", "Cathy", "Dave"]` ইনপুট নিয়ে, যেসব নামের দৈর্ঘ্য ৪ সেগুলো বেছে নিন।
  - `map` আর `select` একসাথে ব্যবহার করুন

    ```jq
    map(select(length == 4))
    ```

  - অ্যারেটিকে ভেঙে এলিমেন্টে পরিণত করুন, সেই স্ট্রিমে `select` চালান, আর ফলাফলগুলো সংগ্রহ করুন

    ```jq
    [ .[] | select(length == 4) ]
    ```
