# টাপল টাইপ

টাপল হলো Cairo-তে একটি বহুমুখী ও দক্ষ কম্পাউন্ড ডেটা টাইপ, যা দিয়ে আপনি বিভিন্ন টাইপের একাধিক মান একটি একক সত্তায় একসাথে রাখতে পারেন।
টাপলের দৈর্ঘ্য নির্দিষ্ট, অর্থাৎ একবার ডিক্লেয়ার করা হলে তার আকার আর বদলানো যায় না।

## টাপল তৈরি করা

একটি টাপল তৈরি করতে প্রথম বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা মানের একটি তালিকা লিখুন।
টাপলের প্রতিটি অবস্থানের একটি নির্দিষ্ট টাইপ থাকে, এবং এই টাইপগুলো একে অপরের থেকে আলাদা হতে পারে।

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

একটি টাপল বিভিন্ন ডেটা টাইপের একাধিক মান ধারণ করতে পারে, এমনকি অন্য টাপলও।
উদাহরণ:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

এখানে `nested_tup` ভ্যারিয়েবলটি দুটি টাপল ধারণ করা একটি টাপল, যা দেখায় যে টাপল এলিমেন্ট হিসেবে অন্য টাপলও ধারণ করতে পারে।

## টাপল ডিস্ট্রাকচার করা

টাপলের ভেতরের প্রতিটি মান আলাদাভাবে পেতে আপনি প্যাটার্ন ম্যাচিং ব্যবহার করে টাপলটি ডিস্ট্রাকচার করতে পারেন।
এতে টাপলটি তার উপাদান অংশে ভেঙে যায়।

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## একসাথে ডিক্লেয়ার ও ডিস্ট্রাকচার করা

আপনি একসাথে একটি টাপল ডিক্লেয়ার ও ডিস্ট্রাকচারও করতে পারেন।

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## ইউনিট টাইপ `()`

ইউনিট টাইপ হলো Cairo-তে একটি বিশেষ টাইপ, যার মান মাত্র একটি: `()`.
এটি কোনো এলিমেন্ট ছাড়া একটি টাপল দিয়ে প্রকাশ করা হয়।
ইউনিট টাইপের আকার সবসময় শূন্য, আর কম্পাইল করা কোডে এটি একেবারেই থাকবে না, তা নিশ্চিত করা হয়েছে।

Cairo-তে প্রতিটি এক্সপ্রেশন একটি মান রিটার্ন করে, আর কোনো এক্সপ্রেশন যখন কিছুই রিটার্ন করে না, তখন সে অন্তর্নিহিতভাবে `()` রিটার্ন করে।
যে ফাংশনগুলোকে মান রিটার্ন করতে হয় কিন্তু রিটার্ন করার মতো অর্থবহ কোনো মান থাকে না, তাদের জন্য এটি কাজে লাগতে পারে।

## নেমড টাপল টাইপ ডিক্লেয়ারেশন

নেমড টাপল আপনাকে একটি টাপলের জন্য আরও বর্ণনামূলক টাইপ অ্যালিয়াস তৈরি করতে দেয়, যা কোডের পাঠযোগ্যতা বাড়ায়।

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

এই উদাহরণে `Point` হলো একটি নেমড টাপল টাইপ, যা দুটি আনসাইনড ৩২-বিট ইন্টিজারের জোড়া বোঝায় এবং কোডকে আরও প্রকাশক্ষম করে তোলে।
