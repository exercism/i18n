# নির্দেশনা

আপনি একজন আগ্রহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কত পাখি এসেছে তার হিসাব রাখেন।

আপনার সামনে ছয়টি কাজ আছে, সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. গত সপ্তাহে সংখ্যাগুলো কী ছিল তা দেখুন

তুলনার সুবিধার জন্য আপনি সবসময় গত সপ্তাহের সংখ্যাগুলোর একটি কপি কাছে রাখেন, সেগুলো ছিল: 0, 2, 5, 3, 7, 8 আর 4। গত সপ্তাহের সংখ্যাগুলো নিয়ে একটি ভেক্টর তৈরি করুন:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. আজ কত পাখি এসেছে তা দেখুন

আজ আপনার বাগানে কত পাখি এসেছে তা রিটার্ন করার জন্য `today` ফাংশনটি ডিফাইন করুন। পাখির সংখ্যাগুলো দিন অনুযায়ী সাজানো থাকে; প্রথম এলিমেন্টটি হলো সবচেয়ে পুরোনো দিনের সংখ্যা, আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. আজকের সংখ্যা বাড়ান

আজকের সংখ্যা বাড়ানোর জন্য `inc-bird` ফাংশনটি ডিফাইন করুন:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. কোনো দিন পাখি আসেনি কি না তা দেখুন

`day-without-birds?` প্রেডিকেট ফাংশনটি ডিফাইন করুন, যা `true` রিটার্ন করে যদি এমন কোনো দিন থাকে যেদিন বাগানে একটিও পাখি আসেনি; নাহলে `false` রিটার্ন করে:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. সপ্তাহের শুরু থেকে নির্দিষ্ট সংখ্যক দিনে আসা পাখির সংখ্যা হিসাব করুন

`n-days-count` ফাংশনটি ডিফাইন করুন, যা সপ্তাহের শুরু থেকে আপনার বাগানে আসা পাখির সংখ্যা রিটার্ন করে, তবে গণনাটি সপ্তাহের শুরু থেকে নির্দিষ্ট সংখ্যক দিনের মধ্যে সীমিত রাখুন।

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্য দিনের চেয়ে ব্যস্ত থাকে। ব্যস্ত দিন হলো এমন দিন, যেদিন পাঁচটি বা তার বেশি পাখি আপনার বাগানে এসেছে।
ব্যস্ত দিনের সংখ্যা রিটার্ন করার জন্য `busy-days` ফাংশনটি ডিফাইন করুন:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. অদ্ভুত সপ্তাহ আছে কি না তা দেখুন

গত এক বছরে আপনি দেখেছেন, কিছু সপ্তাহ একই অদ্ভুত প্যাটার্ন তৈরি করে, যেখানে পাখি আসার সংখ্যা এক আর শূন্যের মধ্যে পালা করে। `odd-week?` ফাংশনটি ডিফাইন করুন, যা `true` রিটার্ন করে যদি এই সপ্তাহের পাখি-সংখ্যার প্যাটার্নটি অদ্ভুত প্যাটার্নের সাথে মিলে যায়:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
