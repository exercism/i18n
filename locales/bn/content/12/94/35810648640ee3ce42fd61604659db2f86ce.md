# পরিচিতি

এলিক্সিরে সব এররই _Exception Behaviour_ ইমপ্লিমেন্ট করে। _Access Behaviour_-এর মতোই, _Exception Behaviour_ এমন কলব্যাক ফাংশন ডিফাইন করে যা ওই বিহেভিয়ারের সফটওয়্যার কনট্র্যাক্ট পূরণ করতে হলে একটি মডিউলকে অবশ্যই ইমপ্লিমেন্ট করতে হয়। একটি এরর ডিফাইন করা হলে তার নিচের বৈশিষ্ট্যগুলো থাকে:

- মডিউলের নামই এররের নাম নির্ধারণ করে।
- মডিউলটি একটি এরর-স্ট্রাক্ট ডিফাইন করে।
- স্ট্রাক্টটিতে একটি `:message` ফিল্ড থাকবে।
- কাঙ্ক্ষিত এরর রেইজ করতে মডিউলটি `raise/1` ও `raise/2`-এর সাথে ব্যবহার করা যায়

_Exception Behaviour_ আরও দুটি কলব্যাক নির্দিষ্ট করে: `message/1` ও `exception/1`। এগুলো ইমপ্লিমেন্ট না করলে ডিফল্ট ইমপ্লিমেন্টেশন ব্যবহার করা হয়। `raise` দিয়ে কল করলে `message/1` এরর-স্ট্রাক্টটিকে পড়ার উপযোগী বার্তায় রূপান্তর করে। `raise/2` দিয়ে কল করলে `exception/1` বার্তায় অতিরিক্ত প্রসঙ্গ যোগ করার সুযোগ দেয়

## একটি এক্সেপশন ডিফাইন করা

একটি এরর মডিউল থেকে এক্সেপশন ডিফাইন করতে আমরা `defexception` ম্যাক্রো ব্যবহার করি:

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## এক্সেপশন ব্যবহার করা

ডিফাইন করা এরর বিল্ট-ইন এররের মতোই `raise/1` বা `raise/2` দিয়ে ব্যবহার করা যায়।

- `raise/1` মডিউলের নাম দিয়ে একটি নির্দিষ্ট এরর রেইজ করে, অথবা আর্গুমেন্টটি স্ট্রিং হলে ওই স্ট্রিংটি বার্তা হিসেবে নিয়ে একটি `RuntimeError` রেইজ করে।
- `raise/2` মডিউলের নাম দিয়ে একটি নির্দিষ্ট এরর রেইজ করে এবং একটি অ্যাট্রিবিউট আর্গুমেন্ট নেয়, যা দিয়ে উপযুক্ত বার্তাসহ এররটি পাওয়া যায়।
