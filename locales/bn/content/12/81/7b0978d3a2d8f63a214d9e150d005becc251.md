# if-else-এর বদলে `||` ব্যবহার করুন

কোনো মান `nil` বা অন্য কোনো ফলসি মান হলে সেটি বদলাতে চাইলে, if-else স্টেটমেন্টের বদলে `||` অপারেটরটি ব্যবহার করুন।
এতে কোডটি আরও স্বাভাবিক ও সংক্ষিপ্ত হয়, আর পারফরম্যান্সও ভালো হয়।

`||` অপারেটরটি তার বাঁ দিকের মানটি ট্রুথি হলে সেটিই রিটার্ন করে, নাহলে অপারেটরের ডান দিকের মানটি রিটার্ন করে।

যেমন:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
