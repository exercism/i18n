# সম্পর্কে

[concept:csharp/enumerables]()-এর ওপর একটি [`foreach` লুপ][foreach-statement] ব্যবহার করে ইটারেশন করা যায়:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

একটি `foreach` লুপ তিনটি অংশ নিয়ে গঠিত:

1. ডিক্লারেশন: যে ভ্যারিয়েবলটি ইটারেশনের মান ধারণ করবে সেটি ডিফাইন করুন। এই ভ্যারিয়েবলটি (কেবল) লুপের ভেতরে ব্যবহার করা যায়।
2. ইটারেবল অবজেক্ট: যে অবজেক্টের ওপর ইটারেশন করা যায়।
3. লুপ বডি।

## for বনাম foreach লুপ

তবে সাধারণভাবে, নিচের কারণগুলোর জন্য একটি `for` লুপের চেয়ে `foreach` লুপ বেশি পছন্দনীয়:

- একটি `foreach` লুপ _সব_ মানের ওপর ইটারেশন করার নিশ্চয়তা দেয়। `for` লুপে এলিমেন্ট বাদ পড়ে যাওয়া সহজ, যেমন অফ-বাই-ওয়ান এররের কারণে।
- একটি `foreach` লুপ আরও _ডিক্লারেটিভ_, আপনার কোড _কী_ করতে চায় সেটি বোঝায়, যেখানে একটি `for` লুপ বোঝায় _কীভাবে_ আপনি তা করতে চান।
- একটি `foreach` লুপ নিরাপদ, যেখানে `for` লুপে অফ-বাই-ওয়ান এরর হওয়া সহজ।
- একটি `foreach` লুপ সব ধরনের কালেকশনে কাজ করে, সেগুলোসহ যেগুলো এলিমেন্ট অ্যাক্সেস করতে ইনডেক্সার ব্যবহার সমর্থন করে না।

একটি `foreach` লুপ _সব_ মানের ওপর ইটারেশন করবে তা নিশ্চিত করতে, কম্পাইলার `foreach` লুপের ভেতরে একটি কালেকশন আপডেট করার অনুমতি দেয় না:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

একটি `for` লুপের `foreach` লুপের চেয়ে কিছু সুবিধা আছে:

- আপনি যে ইনডেক্সে চান সেখানেই শুরু বা থামতে পারেন।
- আপনি চাইলে যেকোনো (বুলিয়ান) সমাপ্তি শর্ত ব্যবহার করতে পারেন।
- লুপ ভ্যারিয়েবলের ইনক্রিমেন্ট কাস্টমাইজ করে এলিমেন্ট বাদ দিতে পারেন।
- কাউন্ট ডাউন করে কালেকশন পেছন থেকে সামনে প্রসেস করতে পারেন।
- কালেকশন জড়িত নেই এমন পরিস্থিতিতেও আপনি `for` লুপ ব্যবহার করতে পারেন।

সম্পর্কিত বিষয়:

- আপনি জেনে রাখুন যে C# [মাল্টি-ডাইমেনশনাল অ্যারে][multi-dimensional-arrays] সমর্থন করে, যেমন `int[,] arr = new int[10, 5]`, যা খুব কাজে লাগতে পারে।
- আপনি এটিও জেনে রাখুন যে `Array.CreateInstance` দিয়ে [`System.Array`][system-array-object] টাইপের অবজেক্ট ইনস্ট্যানশিয়েট করতে পারেন। এমন অবজেক্টের ব্যবহার খুবই কম, মূলত VB.NET কোডের সাথে ইন্টারঅপের জন্য। এগুলো সাধারণ অ্যারের (`T[]`) সাথে বিনিময়যোগ্য নয়। এগুলোর লোয়ার বাউন্ড শূন্য ছাড়া অন্য কিছু হতে পারে।

উপরের দুটি বিষয়ই পরের একটি অনুশীলনীতে আরও বিস্তারিত আলোচনা করা হয়েছে।
