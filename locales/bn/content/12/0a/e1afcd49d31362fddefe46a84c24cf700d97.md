# ভূমিকা

Perl একটি প্রোগ্রামিং ভাষা, যেটি ল্যারি ওয়াল তৈরি করেছেন এবং যা প্রথম প্রকাশিত হয় ১৯৮৭ সালে।

## প্যাকেজ ও মডিউল

প্যাকেজ হলো কোডের একটি সংগ্রহ, যা প্রায়ই একই নামের এবং `.pm` এক্সটেনশনযুক্ত একটি মডিউল ফাইলের ভেতরে থাকে।
এরপর মডিউলটি অন্য একটি ফাইলে ইমপোর্ট করা যায়, সাধারণত `use` কিওয়ার্ড দিয়ে।

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## ভ্যারিয়েবল

স্কেলার (`$foo`), অ্যারে (`@bar`) এবং হ্যাশ (`%baz`) ভ্যারিয়েবল রয়েছে।
বিষয়টি সহজ রাখতে এখানে কেবল স্কেলার ভ্যারিয়েবল ব্যবহার করা হবে।
একটি স্কেলার মান নিচের যেকোনো একটি হতে পারে: একটি স্ট্রিং, একটি সংখ্যা, একটি বুলিয়ান, অথবা কোনো কিছুতে একটি [রেফারেন্স][perlreftut]।
কোনো মান না থাকলে সেটি `undef`।


`my` এবং `our` কিওয়ার্ড কোনো ভ্যারিয়েবলকে লেক্সিক্যাল স্কোপে ডিক্লেয়ার করে, যেমন `my $foo;`।
`our` ব্যবহার করলে ভ্যারিয়েবলটি একই নামের একটি প্যাকেজ ভ্যারিয়েবলের সাথেও অ্যালিয়াস করা হয়।
ভ্যারিয়েবল ডিক্লেয়ার করার আরও কিছু উপায় আছে, যেগুলো এখানে আলোচনা করা হবে না।

আপনি `=` অপারেটর দিয়ে একটি ভ্যারিয়েবলে মান অ্যাসাইন করতে পারেন, যেমন `$foo = 1;`। ভ্যারিয়েবল ডিক্লেয়ার করার সময়েই এটি করা যায়, যেমন `my $foo = 1;`।

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## সাবরুটিন

`sub` কিওয়ার্ড একটি [সাবরুটিন][perlsub] ডিক্লেয়ার করে।
`return` কিওয়ার্ডটি সাবরুটিন থেকে বেরিয়ে আসে এবং নির্দিষ্ট করা মানগুলো দেয়, আর কিছু নির্দিষ্ট করা না থাকলে একটি খালি অ্যারে দেয়।
`return` নির্দিষ্ট করা না থাকলে, ব্যবহৃত সাবরুটিনের এবং তার শেষ স্টেটমেন্টের কনটেক্সট (স্কেলার, অ্যারে, বা ভয়েড) দ্বারা রিটার্ন ভ্যালু নির্ধারিত হয়।

```perl
sub hello () {
    return 'Hello, World!';
}
```

Perl-এর সাম্প্রতিক সংস্করণগুলোতে আপনি একটি [সিগনেচার][perlsubsig]-এ ফর্মাল প্যারামিটার উল্লেখ করতে পারেন।
প্যারামিটার তালিকায় স্কেলার, অ্যারে বা হ্যাশ ভ্যারিয়েবল থাকতে পারে।
খালি প্যারামিটার তালিকা মানে সাবরুটিনটি কোনো আর্গুমেন্ট গ্রহণ করে না।
Perl-এর পুরোনো সংস্করণে বিশেষ ভ্যারিয়েবল `@_` থেকে আর্গুমেন্টগুলো নিতে হতো, যা এখানে আলোচনা করা হবে না।

## কমেন্ট

Perl-এ কমেন্ট শুরু হয় একটি `#` দিয়ে, যেটি কোনো স্ট্রিংয়ের অংশ নয়, এবং লাইনের শেষে গিয়ে শেষ হয়।
