# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | সীমা                               |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | মৌলিক সংখ্যার জন্য গন্তব্য অ্যারে |
| `$v0`    | আউটপুট       | ইন্টিজার | মৌলিক সংখ্যার সংখ্যা                    |
| `$t0-9`  | সাময়িক    | যেকোনো     | সাময়িক স্টোরেজের জন্য ব্যবহৃত          |
