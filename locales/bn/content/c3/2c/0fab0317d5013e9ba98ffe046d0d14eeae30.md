# পরিচিতি

F#-এর `char` টাইপ হলো একটি ১৬ বিটের মান, যা টেক্সটের ক্ষুদ্রতম অ্যাড্রেসযোগ্য উপাদান প্রকাশ করে এবং ডিফল্টভাবে অপরিবর্তনীয়।

সিঙ্গেল কোট দিয়ে `char`-কে লিটারাল হিসেবে ডিফাইন করা যায়:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

স্ট্রিং হলো `char`-এর একটি ক্রম।

শূন্য-ভিত্তিক ইনডেক্সিং দিয়ে একটি স্ট্রিং থেকে আলাদা একটি `char` পাওয়া যায়:

```fsharp
"Exercism"[4] //  =>  'c'
```

একটি স্ট্রিংয়ের উপর ইটারেশন করলে প্রতিটি ধাপে একটি `char` পাওয়া যায়।

পরের উদাহরণে সুবিধার জন্য একটি হায়ার অর্ডার ফাংশন আর একটি অ্যানোনিমাস ফাংশন ব্যবহার করা হয়েছে।
এগুলো নিয়ে সিলেবাসে পরে বিস্তারিত আলোচনা করা হবে, তবে আপাতত এগুলো মূলত একটি স্ট্রিংয়ের ক্যারেক্টারগুলোর উপর লুপ লেখার একটি সংক্ষিপ্ত উপায়।

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

উপরের উদাহরণে দেখা যাচ্ছে, একটি `char`-কে তার `int` মানে কাস্ট করা যায়।
অন্য স্ক্রিপ্টের বেলাতেও এটি কাজ করে (*অন্তত কিছু ক্ষেত্রে*):

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

ক্যারেক্টার তুলনা করার সময় অন্তর্নিহিত Int16-ই ব্যবহৃত হয়:

```fsharp
'A' < 'D'  // =>  true
```

এছাড়াও, একটি `int`-কে `char`-এ কাস্ট করা যায়:

```fsharp
char 77  // => 'M'
```

`System.Char` লাইব্রেরিতে একটি .NET ভাষার কাছে প্রত্যাশিত সব মেথড রয়েছে, যেমন বড় হাতের ও ছোট হাতের অক্ষরে রূপান্তর:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
