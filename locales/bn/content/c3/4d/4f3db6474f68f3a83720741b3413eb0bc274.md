# পরিচিতি

## জেনেরিক টাইপ

একটি **জেনেরিক টাইপ** হলো এমন একটি জেনেরিক ক্লাস বা ইন্টারফেস, যা টাইপের ওপর প্যারামিটারাইজ করা থাকে। এর ফলে কম্পাইলার ক্লাস বা ইন্টারফেসের ওপর টাইপ সেফটি নিশ্চিত করতে পারে।

এই নন-জেনেরিক `Container` ইন্টারফেসটি দেখুন:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

এটি যেহেতু Object টাইপ গ্রহণ করে এবং ফিরিয়ে দেয়, তাই যেকোনো নন-প্রিমিটিভ টাইপের সাথে এটি কাজ করে। কিন্তু এর একটি মূল্য দিতে হয়, কারণ কিছু কোড `get` কল করার সময় `Integer` আশা করতে পারে, আবার অন্য কোড `set` কল করে `String` যোগ করতে পারে, যার ফলে একটি রানটাইম এক্সসেপশন ঘটে।

একটি **জেনেরিক ক্লাস** ও একটি **জেনেরিক ইন্টারফেস**-এর রূপ নিচের মতো:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

ক্লাস বা ইন্টারফেসের নামের পরে অ্যাঙ্গেল ব্র্যাকেট (`<>`) দিয়ে ঘেরা টাইপ প্যারামিটার অংশটি টাইপ প্যারামিটারগুলোকে (যাদের টাইপ ভ্যারিয়েবলও বলা হয়) বোঝায়: `T1`, `T2`, ..., এবং `Tn`। এগুলো ক্লাস বা ইন্টারফেসের বডির ভেতরে ব্যবহার করে জেনেরিক টাইপ সেফটি পাওয়া যায়।

এখানে `Container`-এর জেনেরিক সংস্করণটি দেওয়া হলো:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

তৈরি করার সময় এখন আমাদের বলে দিতে হয় এটি কোন টাইপ ধারণ করবে, আর কম্পাইলার সেই শর্ত প্রয়োগ করে মানিয়ে নেয়:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```

## লিস্ট

**লিস্ট** হলো Java-এর ক্রমানুসারে সাজানো সিকোয়েন্স কালেকশন। অ্যারের মতো নয়, একটি [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) যেকোনো সংখ্যক আইটেম ধারণ করার জন্য আকারে বাড়তে পারে। একটি আদর্শ ইমপ্লিমেন্টেশন হলো `ArrayList`, যা একটি আকার পরিবর্তনযোগ্য অ্যারের ওপর ভিত্তি করে তৈরি। আরেকটি আদর্শ ইমপ্লিমেন্টেশন হলো `LinkedList` ক্লাস, যা একটি ডাবলি-লিংকড লিস্টের ওপর ভিত্তি করে তৈরি।

`List` খালি থাকতে পারে, আবার যেকোনো সংখ্যক আইটেম ধারণ করতে পারে (ডুপ্লিকেটসহ)। `List` হলো একটি **জেনেরিক ইন্টারফেস**, যা টাইপ করা থাকে যাতে বোঝা যায় এটি কোন ধরনের অবজেক্ট ধারণ করতে পারে। যেমন:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`-এ এলিমেন্ট যোগ করা, সরানো, পাওয়া এবং কোনো এলিমেন্ট আছে কিনা তা যাচাই করার জন্য নানা রকম সহায়ক মেথড রয়েছে:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
