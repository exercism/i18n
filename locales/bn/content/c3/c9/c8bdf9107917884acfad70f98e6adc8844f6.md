# পরিচিতি

Flags অ্যাট্রিবিউটের সাহায্যে ডিসক্রিমিনেটেড ইউনিয়নে ডিফাইন করা মানগুলোকে বিট পজিশন (অর্থাৎ ফ্ল্যাগ) হিসেবে প্রকাশ করা যায়।
ফ্ল্যাগ হিসেবে এসব মান একত্র করা যায়, ফলে একাধিক বুলিয়ান শর্ত একটি মানের মধ্যেই প্রকাশ করা সম্ভব হয়।

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

একটি ফ্ল্যাগ সেট করা যায় বিটওয়াইজ OR অপারেটর (`|||`) দিয়ে; আর একটি ফ্ল্যাগ আনসেট করা যায় বিটওয়াইজ AND অপারেটর (`&&&`) ও বিটওয়াইজ নেগেশন অপারেটর (`~~~`) একসাথে ব্যবহার করে।
ফ্ল্যাগের অবস্থা যাচাই করা যায় বিটওয়াইজ AND অপারেটর দিয়ে, আবার `HasFlag()` মেথডও ব্যবহার করা যায়।

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

F# ভাষায় পাওয়া সব বিটওয়াইজ অপারেটরের পূর্ণ তালিকার জন্য [বিটওয়াইজ অপারেটরের সারসংক্ষেপ][bitwise-operators] দেখুন।

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
