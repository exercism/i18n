# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সহায়ক কোড লিখবেন।

আপনার সামনে চারটি কাজ, যার সবগুলোই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে ওভেনে প্রত্যাশিত সময় নির্ধারণ করুন

`Lasagna` ক্লাসে `EXPECTED_MINUTES_IN_OVEN` কনস্ট্যান্টটি ডিফাইন করুন, যা সংরক্ষণ করে লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত।
রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```Crystal
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. মিনিটে ওভেনে অবশিষ্ট সময় হিসাব করুন

`Lasagna#remaining_minutes_in_oven` মেথডটি ডিফাইন করুন, যা লাসাগনা এখন পর্যন্ত কত মিনিট ওভেনে ছিল সেটি একটি প্যারামিটার হিসেবে নেয় এবং আগের কাজের ওভেনে প্রত্যাশিত সময় মিনিটের ভিত্তিতে রিটার্ন করে লাসাগনাটিকে আর কত মিনিট ওভেনে থাকতে হবে।

```Crystal
Lasagna.new.remaining_minutes_in_oven(30)
# => 10
```

## 3. মিনিটে প্রস্তুতির সময় হিসাব করুন

`Lasagna#preparation_time_in_minutes` মেথডটি ডিফাইন করুন, যা আপনি লাসাগনায় যতগুলো স্তর যোগ করেছেন তার সংখ্যা একটি প্যারামিটার হিসেবে নেয় এবং তা প্রস্তুত করতে আপনার কত মিনিট লেগেছে সেটি রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে ২ মিনিট লাগে।

```Crystal
Lasagna.new.preparation_time_in_minutes(2)
# => 4
```

## 4. মিনিটে মোট কাজের সময় হিসাব করুন

`Lasagna#total_time_in_minutes` মেথডটি ডিফাইন করুন, যা দুটি নামযুক্ত প্যারামিটার নেয়: `number_of_layers` প্যারামিটারটি হলো আপনি লাসাগনায় যতগুলো স্তর যোগ করেছেন তার সংখ্যা, আর `actual_minutes_in_oven` প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ওভেনে ছিল তার সংখ্যা।
মেথডটি রিটার্ন করবে লাসাগনা রান্নায় আপনার মোট কত মিনিট কাজ হয়েছে, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত সময় কাটিয়েছে তার যোগফল।

```Crystal
number_of_layers = 3
actual_minutes_in_oven = 20
Lasagna.new.total_time_in_minutes(number_of_layers, actual_minutes_in_oven)
# => 26
```
