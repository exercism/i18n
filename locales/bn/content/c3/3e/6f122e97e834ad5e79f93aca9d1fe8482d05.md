# প্লেসহোল্ডার

## `jq` টিপস

এই অনুশীলনীটি একটি ইনপুট অবজেক্ট নিয়ে সেটিকে নতুন একটি অবজেক্টে রূপান্তর করার বিষয়ে। সহায়ক হতে পারে এমন কয়েকটি বিল্ট-ইন ফাংশন:

- [`to_entries`][x_entries]
  - এই ফাংশনটি ইনপুট হিসেবে একটি অবজেক্ট নেয়
  - এটি একটি _অ্যারে_ আউটপুট দেয়, অ্যারেটির প্রতিটি এলিমেন্ট একটি অবজেক্ট `{"key": "K", "value": V}`
    - প্রতিটি `K` ইনপুট অবজেক্টের একটি কী (key)
    - প্রতিটি `V` হলো `K`-এর সংশ্লিষ্ট মান।
- [`from_entries`][x_entries]
  - বিপরীত অপারেশন
  - `{"key": K, "value": V}` অবজেক্টের একটি অ্যারে নিয়ে একটি অবজেক্ট তৈরি করে

একটি উদাহরণ:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

আউটপুট দেয়

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
