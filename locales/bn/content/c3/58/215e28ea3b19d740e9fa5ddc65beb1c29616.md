# টেস্ট

## টেস্ট চালানো

1. একটি অনুশীলনী সংগ্রহ করুন:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. অনুশীলনীর ডিরেক্টরিতে চলে যান:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. টেস্টগুলো চালান:

    ```bash
    $ ./gradlew test
    ```

বেশিরভাগ অনুশীলনীতে ডিফল্টভাবে শুধু প্রথম টেস্টটিই চালানো হয়।  
বাকি টেস্টগুলো এড়িয়ে যাওয়ার জন্য `@Ignore` দিয়ে অ্যানোটেট করা থাকে।  
প্রতিটি টেস্ট সমাধান করার সাথে সাথে পরের টেস্ট থেকে `@Ignore` সরিয়ে ফেলুন, তাহলেই এগিয়ে যেতে পারবেন।

টেস্ট-ড্রিভেন ডেভেলপমেন্টে (সংক্ষেপে TDD) এটি একটি কমন চর্চা।
এটি নিশ্চিত করতে ব্যবহার করা হয় যে আপনি একবারে একটি সমস্যা নিয়েই কাজ করছেন।
