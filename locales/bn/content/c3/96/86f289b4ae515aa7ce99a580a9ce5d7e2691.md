# নির্দেশাবলি

একটি বেসে অঙ্কের ধারা হিসেবে প্রকাশ করা একটি সংখ্যাকে যেকোনো অন্য বেসে রূপান্তর করুন।

সাধারণ বেস রূপান্তর বাস্তবায়ন করুন। **a** বেসে দেওয়া একটি সংখ্যা, যা অঙ্কের ধারা হিসেবে প্রকাশ করা, সেটিকে **b** বেসে রূপান্তর করুন।

## খেয়াল রাখুন

- রূপান্তরটি নিজে বাস্তবায়ন করার চেষ্টা করুন।
  আপনার হয়ে রূপান্তরটি করার জন্য অন্য কিছু ব্যবহার করবেন না।

## [পজিশনাল নোটেশন](https://en.wikipedia.org/wiki/Positional_notation) সম্পর্কে

পজিশনাল নোটেশনে, **b** বেসের একটি সংখ্যাকে **b**-এর ঘাতগুলোর একটি রৈখিক সমন্বয় হিসেবে বোঝা যায়।

*বেস 10*-এ 42 সংখ্যাটি বোঝায়:

(4 * 10^1) + (2 * 10^0)

*বেস 2*-এ 101010 সংখ্যাটি বোঝায়:

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

*বেস 3*-এ 1120 সংখ্যাটি বোঝায়:

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

আমার মনে হয় আপনি বিষয়টা ধরতে পেরেছেন!

*হ্যাঁ। উপরের তিনটি সংখ্যাই আসলে একেবারে একই। অভিনন্দন!*
