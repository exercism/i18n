# ইন্টিজার

ইন্টিজার হলো পূর্ণ সংখ্যা, যেগুলো `{..., -2, -1, 0, 1, 2, ...}` সেটের অন্তর্ভুক্ত।
একটি ইন্টিজারের সর্বোচ্চ ও সর্বনিম্ন মান নির্ভর করে PHP যে সিস্টেমে চলে তার উপর।
সাধারণত আধুনিক বেশিরভাগ সিস্টেমে ইন্টিজার একটি 64-বিট মান, অর্থাৎ এটি `-9_223_372_036_854_775_808` থেকে `9_223_372_036_854_775_807` পর্যন্ত দুই প্রান্তসহ প্রকাশ করতে পারে।

```php
<?php

$a = 1234;
$a = 1_234_567;
```

বেস প্রিফিক্স ব্যবহার করে আপনি বেস ১০ ছাড়া অন্য বেসেও ইন্টিজার লিটারাল মান লিখতে পারেন:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> PHP-এর [ডকুমেন্টেশন][syntax] থেকে নেওয়া।

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
