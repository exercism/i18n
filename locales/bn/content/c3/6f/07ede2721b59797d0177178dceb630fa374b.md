# ইনস্টলেশন

## Clojure CLI ইনস্টল করা
Clojure কমান্ড লাইন টুল সরবরাহ করে, যা দিয়ে একটি Clojure REPL চালু করা যায়, Clojure ও Java লাইব্রেরি ব্যবহার করা যায়, এবং Clojure প্রোগ্রাম চালু করা যায়।

আপনার যদি Java ইনস্টল করার প্রয়োজন হয়, আমরা [Adoptium Temurin 17](https://adoptium.net/) সুপারিশ করি।

### Linux
নিশ্চিত করুন যে নিচের ডিপেন্ডেন্সিগুলো ইনস্টল করা আছে: `bash`, `curl`, `rlwrap`, এবং `Java`। 
আপনি Clojure এই ২টি উপায়ের যেকোনো একটি দিয়ে ইনস্টল করতে পারেন:

1. LinuxBrew-এর জন্য [Homebrew](https://brew.sh/) প্রয়োজন

```bash
brew install clojure/tools/clojure
```

2. স্ক্রিপ্ট ইনস্টলার

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Mac OS X-এর জন্য Homebrew
brew দিয়ে [clojure/tools](https://github.com/clojure/homebrew-tools) ট্যাপ থেকে কমান্ড লাইন টুলগুলো ইনস্টল করুন:

```bash
brew install clojure/tools/clojure
```

#### Java

Java-এর যেকোনো ডিস্ট্রিবিউশন কাজ করবে। প্রয়োজন হলে, আপনি brew দিয়ে Temurin ইনস্টল করতে পারেন:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Windows-এ Clojure সম্প্রতি যথেষ্ট উন্নতি করেছে। আমরা আগে WSL2 ব্যবহারের সুপারিশ করতাম, যা দারুণ কাজ করে,
কিন্তু এখন একটি PowerShell ইনস্টলার আছে। Windows-এ Clojure বর্তমানে আলফা অবস্থায় আছে, পরিচিত সমস্যাগুলোর জন্য [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) দেখুন।

নিশ্চিত করুন যে Java ইনস্টল করা আছে এবং `JAVA_HOME` এনভায়রনমেন্ট ভ্যারিয়েবল সেট করা আছে, তারপর চালান:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Windows-এ Clojure ইনস্টল করার আরেকটি উপায় হলো [Scoop](https://scoop.sh/) প্যাকেজ ম্যানেজার। Scoop ইনস্টল করতে, PowerShell খুলুন এবং এই ২টি কমান্ড একটির পর একটি চালান:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Scoop দিয়ে Clojure ইনস্টল করতে হলে প্রথমে দুটি গুরুত্বপূর্ণ বাকেট যোগ করতে হবে:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

এখন আমরা নিচের কমান্ডগুলো দিয়ে Java ও Clojure ইনস্টল করার জন্য প্রস্তুত:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

উপরের ধাপগুলো সফলভাবে চালানোর পর, আপনি নিচেরটি দিয়ে Clojure চালাতে পারবেন:

```sh
clj
```

## Leiningen ইনস্টল করা (ঐচ্ছিক)

যদিও আর প্রয়োজন নেই, আমরা এখনও পূর্ণ বৈশিষ্ট্যসম্পন্ন প্রজেক্ট ম্যানেজমেন্ট টুল [Leiningen](https://leiningen.org/) সমর্থন করি।
এটি সুবিধাজনক টেস্টিং, বিল্ড এবং উন্নত REPL-এর মতো নানা সহায়ক কাজের সুবিধা দেয়।

1. [lein স্ক্রিপ্ট](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) অথবা [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) ডাউনলোড করুন (Windows)
2. এটি আপনার `$PATH`-এ রাখুন যেখানে আপনার শেল এটি খুঁজে পাবে (যেমন `/usr/local/bin/`)
3. এটিকে এক্সিকিউটেবল করুন (`sudo chmod a+x /usr/local/bin/lein`)
4. `lein` চালান।
