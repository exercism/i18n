# ভূমিকা

Lambda ক্লাসটি Haxe দিয়ে ফাংশনাল-স্টাইল প্রোগ্রামিং ব্যবহার করার জন্য ফাংশনাল মেথডের একটি সংগ্রহ। এটি আমাদের পুরো একটি Iterable-এর উপর একসাথে কাজ করতে দেয়। লুপিং রুটিনের চেয়ে এটি প্রায়শই বেশি পছন্দনীয়, কারণ এতে ভুল হওয়ার সম্ভাবনা কম এবং পড়তে সহজ। সুবিধার জন্য, Array এবং List ক্লাসে Lambda ক্লাসের প্রায়শই ব্যবহৃত কিছু মেথড রয়েছে।

`Lambda` ক্লাসের কিছু ফাংশনের মধ্যে রয়েছে:

- `Lambda.array`, `Lambda.list` Iterable-কে Array বা List-এ রূপান্তর করে। এটি সর্বদা একটি নতুন ইনস্ট্যান্স রিটার্ন করে।
- `Lambda.count` এলিমেন্টের সংখ্যা গণনা করে। যদি Iterable একটি Array বা List হয়, তাহলে এর length প্রোপার্টি ব্যবহার করা দ্রুততর।
- `Lambda.has` নির্দিষ্ট এলিমেন্টটি Iterable-এ আছে কি না তা নির্ধারণ করে।
- `Lambda.indexOf` নির্দিষ্ট এলিমেন্টের ইনডেক্স খুঁজে বের করে।
- `Lambda.find` প্রদত্ত সার্চ ফাংশনের প্রথম এলিমেন্ট খুঁজে বের করে।
- `Lambda.concat` দুটি Iterable মার্জ করে, একটি নতুন List রিটার্ন করে।
- `Lambda.filter` একটি ক্রাইটেরিয়া পূরণ করে এমন এলিমেন্টগুলো খুঁজে বের করে, একটি নতুন List রিটার্ন করে।

কিছু ফাংশন দেখানোর একটি উদাহরণ:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
