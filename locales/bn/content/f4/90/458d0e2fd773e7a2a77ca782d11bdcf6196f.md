# নির্দেশনা

লুসিয়ানের বান্ধবী এখন বাড়ির পথে, আর তিনি তখনও তাদের বিবাহবার্ষিকীর ডিনার রান্না করেননি!

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা দিয়ে লুসিয়ান তাঁর প্রিয় রান্নার বই থেকে একটি চমৎকার লাসানিয়া রান্না করতে পারবেন।

আপনার সামনে চারটি কাজ, যেগুলোর সবই লাসানিয়া রান্না করতে লাগা সময়ের সাথে সম্পর্কিত।

## 1. মিনিটে প্রত্যাশিত ওভেন সময় ডিফাইন করুন

`ovenTime()` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং লাসানিয়াকে কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।
রান্নার বই অনুযায়ী, প্রত্যাশিত ওভেন সময় ৪০ মিনিট:

```cpp
ovenTime();
// => 40
```

## 2. ওভেনে বাকি থাকা সময় মিনিটে হিসাব করুন

`remainingOvenTime(int actualMinutesInOven)` ফাংশনটি ডিফাইন করুন, যেটি লাসানিয়া ওভেনে যত মিনিট আছে তা আর্গুমেন্ট হিসেবে নেয় এবং আগের কাজের প্রত্যাশিত ওভেন সময়ের ভিত্তিতে লাসানিয়াকে আরও কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```cpp
remainingOvenTime(30);
// => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTime(int numberOfLayers)` ফাংশনটি ডিফাইন করুন, যেটি লাসানিয়ায় আপনি যত স্তর যোগ করেছেন তার সংখ্যা আর্গুমেন্ট হিসেবে নেয় এবং লাসানিয়া প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```cpp
preparationTime(2);
// => 4
```

## 4. অতিবাহিত সময় মিনিটে হিসাব করুন

`elapsedTime(int numberOfLayers, int actualMinutesInOven)` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসানিয়ায় আপনি যত স্তর যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসানিয়া কত মিনিট ওভেনে আছে তার সংখ্যা। ফাংশনটি রিটার্ন করবে লাসানিয়া রান্না করতে আপনি কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় (মিনিটে) এবং এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```cpp
elapsedTime(3, 20);
// => 26
```
