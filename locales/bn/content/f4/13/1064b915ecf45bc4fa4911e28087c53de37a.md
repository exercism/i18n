# পরিচিতি

একটি *টাপল* হলো Factor-এর রেকর্ড/স্ট্রাক্ট/ক্লাস টাইপ। প্রতিটি টাপল ক্লাসে নির্দিষ্ট সংখ্যক নামযুক্ত স্লট থাকে, আর Factor ওগুলোর জন্য গেটার ও সেটার নিজে থেকেই তৈরি করে দেয়।

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` ("আর্গুমেন্টের ক্রম অনুযায়ী") স্ট্যাক থেকে ডিক্লারেশনের ক্রম অনুযায়ী স্লটগুলো পূরণ করে। আর `new` প্রতিটি স্লটকে তার ডিক্লারেশন করা `initial:` মানে রেখে একটি ইনস্ট্যান্স তৈরি করে (`initial:` না থাকলে `f`)।

প্রতিটি স্লটের গেটার হলো `slot>>` আর সেটার হলো `>>slot`। সেটার *মিউটেট* করে, তাই মূল মান অপরিবর্তিত রেখে আপডেট করতে চাইলে আগে `clone` করুন:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

স্লটের ডিফল্ট মান দিতে `{ name initial: value }` লেখা হয়; `initial:` না থাকলে ডিফল্ট হয় `f`।
