# নির্দেশনা

এই অনুশীলনীতে আপনি এমন একটি সহায়ক প্রোগ্রাম তৈরি করবেন, যাতে ব্যান্ডগুলোর মান আপনাকে আর মনে রাখতে না হয়।
প্রোগ্রামটি ইনপুট হিসেবে ১, ৪ বা ৫টি রং নেবে এবং সঠিক মান ওহমে আউটপুট দেবে।
রঙের ব্যান্ডগুলো এভাবে এনকোড করা হয়:

| রং  | মান |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

আপনি [`Resistor Color Trio`][resistor-color-trio-exercise] অনুশীলনীতে প্রথম তিনটি রঙের ব্যান্ড ডিকোড করেছিলেন।
উদাহরণস্বরূপ: orange-orange-brown মূল মান `330`-এ রূপান্তরিত হয়েছিল।
এই অনুশীলনীতে আপনাকে এর সঙ্গে _টলারেন্স_-ও যোগ করতে হবে।
টলারেন্স হলো মূল মানের চেয়ে একটি মান সর্বোচ্চ কতটা বেশি বা কম হতে পারে তার সীমা।
যেমন, শেষ ব্যান্ডটি green হলে সর্বোচ্চ টলারেন্স হবে `±0.5%`।

টলারেন্স ব্যান্ডের মান এইগুলোর একটি হবে:

| রং  | টলারেন্স |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

চার-ব্যান্ড রেজিস্টরটি এভাবে গঠিত:

| ব্যান্ড_১  | ব্যান্ড_২  | ব্যান্ড_৩     | ব্যান্ড_৪    |
| ------- | ------- | ---------- | --------- |
| মান_১ | মান_২ | মাল্টিপ্লায়ার | টলারেন্স |

উদাহরণ:

- orange-orange-brown-green হলে `330` ওহম এবং `±0.5%` টলারেন্স হতো।
- orange-orange-red-grey হলে `3300` ওহম এবং `±0.05%` টলারেন্স হতো।

চার-ব্যান্ড ও পাঁচ-ব্যান্ড রেজিস্টরের পার্থক্য হলো, পাঁচ-ব্যান্ড রেজিস্টরে অতিরিক্ত একটি ব্যান্ড থাকে, যা আরও নির্ভুল মান নির্দেশ করে।

| ব্যান্ড_১  | ব্যান্ড_২  | ব্যান্ড_৩  | ব্যান্ড_৪     | ব্যান্ড_৫    |
| ------- | ------- | ------- | ---------- | --------- |
| মান_১ | মান_২ | মান_৩ | মাল্টিপ্লায়ার | টলারেন্স |

উদাহরণ:

- orange-orange-orange-black-green হলে `333` ওহম এবং `±0.5%` টলারেন্স হতো।
- orange-red-orange-blue-violet হলে `323 million` ওহম এবং `±0.1%` টলারেন্স হতো।

এক-ব্যান্ড রেজিস্টরও আছে।
এক-ব্যান্ড রেজিস্টরে শুধু black রং থাকে, যার মান 0।

আপনার প্রোগ্রামটি রেজিস্টরের ব্যান্ডের রঙের ইনপুট `list` থেকে একটি লেবেল তৈরি করবে:

"... ohms ±...%"

তাহলে ইনপুট `list` যদি `["orange", "orange", "black", "green"]` হয়, তবে এটি রিটার্ন করবে:

"33 ohms ±0.5%"

ওহমের পরিমাণ হাজারে পৌঁছালে আমরা "kiloohms" বলি।
এটা ১০০০ মিটারের জন্য "কিলোমিটার" এবং ১০০০ গ্রামের জন্য "কিলোগ্রাম" বলার মতো।

তাহলে ইনপুট `list` যদি `["orange", "orange", "orange", "grey"]` হয়, তবে এটি রিটার্ন করবে:

"33 kiloohms ±0.05%"

ওহমের পরিমাণ মিলিয়নে পৌঁছালে আমরা "megaohms" বলি।

তাহলে ইনপুট `list` যদি `["orange", "orange", "blue", "red"]` হয়, তবে এটি রিটার্ন করবে:

"33 megaohms ±2%"
