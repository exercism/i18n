# কার্নেল ফরম্যাট

`format` মেথডের পাশাপাশি, রুবিতে স্ট্রিং তৈরি করার একটি কমন উপায় হলো [স্ট্রিং ইন্টারপোলেশন](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) ব্যবহার করা। যেমন:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
