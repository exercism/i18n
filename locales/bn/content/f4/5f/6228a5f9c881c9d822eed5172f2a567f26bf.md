# ভূমিকা

Factor-এর অ্যাসোসিয়েটিভ অ্যারে, অর্থাৎ হ্যাশটেবিল আর তার সঙ্গীরা, [`assocs`][assocs] থেকে আসা একটি কমন [protocol][assoc-protocol] শেয়ার করে। হ্যাশটেবিল লিটারাল হলো `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

কমন অপারেশন:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

হ্যাশটেবিল *মিউটেবল*। কলগুলোর মধ্যে লিটারালটি শেয়ার হয়ে না যাওয়ার জন্য, পরিবর্তন করার আগে একটি `H{ }` লিটারাল `clone` করে নিন।

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
