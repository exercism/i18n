# নির্দেশনা

নিরাপত্তা যাচাই পাস না হওয়া পর্যন্ত সার্কাসে কেউ ট্র্যাপিজে ওঠে না।
আপনি এই যাচাইগুলো লিখে রাখছেন, যাতে সবার জন্য একই নিয়ম প্রযোজ্য হয়।

পাঁচটি কাজই `SAFETY_CHECK` ক্লাসে রাখতে হবে।

## 1. ম্যাট তৈরি আছে কি?

ম্যাট তখনই তৈরি হয়, যখন সেটি বিছানো থাকে এবং পরিষ্কার থাকে।

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. নিচে পড়ার মতো কিছু আছে কি?

নিচে একটি ম্যাট থাকতে হবে, অথবা নিচে একটি নেট থাকতে হবে। যেকোনো একটি
হলেই চলবে, আর দুটোই থাকলে সমস্যা নেই।

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. কার এখনও ব্রিফিং দরকার?

যার ব্রিফিং হয়নি, তারই ব্রিফিং দরকার।

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. এই পারফর্মার কি যথেষ্ট বড়?

ট্র্যাপিজ ১৩ বছর বা তার বেশি বয়সী পারফর্মারদের জন্য।

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. সব একসাথে মিলিয়ে দেখুন

কোনও পারফর্মার যথেষ্ট বড় হলে, তার ব্রিফিং হয়ে গেলে এবং ম্যাট তৈরি
থাকলে তাকে ট্র্যাপিজের জন্য অনুমতি দেওয়া হয়।

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

চারটি আর্গুমেন্ট হলো বয়স, তার ব্রিফিং হয়েছে কি না, ম্যাট বিছানো আছে
কি না এবং ম্যাট পরিষ্কার আছে কি না।
