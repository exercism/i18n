# ডিস্ট্রাকচারিং

ডিস্ট্রাকচারিং হলো কোনো আইটেমকে তার উপাদান অংশে ভেঙে ফেলার এবং প্রতিটিকে ছোট ছোট ভ্যারিয়েবলে বাইন্ড করার প্রক্রিয়া।

## টাপল ডিস্ট্রাকচারিং

টাপল ডিস্ট্রাকচারিং সহজ: টাপলের প্রতিটি ফিল্ডে শুধু নতুন ভ্যারিয়েবলের নাম অ্যাসাইন করুন:

```rust
let (first, second) = (1, 2);
```

## টাপল স্ট্রাক্ট ডিস্ট্রাকচারিং

টাপল স্ট্রাক্ট ডিস্ট্রাকচারিং আর টাপল ডিস্ট্রাকচারিং একেবারে একই, শুধু এর সাথে স্ট্রাক্টের নাম যোগ করা হয়:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## স্ট্রাক্ট ডিস্ট্রাকচারিং

স্ট্রাক্ট ডিস্ট্রাকচারিং টাপল স্ট্রাক্ট ডিস্ট্রাকচারিংয়ের মতোই। শুধু ফিল্ডের নামগুলো ব্যবহার করুন:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## আংশিক ডিস্ট্রাকচারিং

ডিস্ট্রাকচারিংয়ের সময় কিছু ফিল্ড উপেক্ষা করতে `..` অপারেটর ব্যবহার করা যায়:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## শর্তসাপেক্ষ ডিস্ট্রাকচারিং

স্ট্রাক্ট ও টাপল ডিস্ট্রাকচারিং কখনো ব্যর্থ হয় না। তবে `if let`, `while let` ও `match` নামের ভাষার কনস্ট্রাক্টগুলো ব্যবহার করে এনামও ডিস্ট্রাকচার করা যায়।

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
