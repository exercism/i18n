# সহায়তা

যদি কোনো সমস্যায় পড়েন, সহায়তা পাওয়ার জন্য নিচে কিছু রিসোর্স দেওয়া হলো:

- [The PSF](https://www.python.org) Python ডাউনলোড, ডকুমেন্টেশন আর কমিউনিটির রিসোর্স হোস্ট করে।
- [Python কমিউনিটি ফোরাম](https://discuss.python.org/) সহায়তা, PEP আলোচনা, Python-এর মূল কমিটার এবং আরও অনেক কিছু।
- [Discord-এ Exercism কমিউনিটি](https://exercism.org/r/discord)
- [Exercism কমিউনিটির আলোচনা ফোরাম](https://forum.exercsim.org)
- [Discord-এ Python কমিউনিটি](https://pythondiscord.com/) একটি খুবই সহায়ক ও সক্রিয় কমিউনিটি।
- [/r/learnpython/](https://www.reddit.com/r/learnpython/) এমন একটি সাবরেডিট, যা Python শিক্ষার্থীদের জন্য তৈরি করা হয়েছে।
- [Libera.chat-এ #python](https://www.python.org/community/irc/) এখানেই ভাষাটির মূল ডেভেলপাররা আড্ডা দেন আর কাজ সারেন।
- [Free Code Camp কমিউনিটি ফোরাম](https://forum.freecodecamp.org/)
- ছোট ছোট কোড স্নিপেট ধাপে ধাপে চোখের সামনে দেখে বোঝার জন্য [Pythontutor](http://pythontutor.com/)।

এর বাইরে, আপনার সমস্যা বা প্রশ্নটির উত্তর আগেই কেউ দিয়েছে কি না তা খুঁজে দেখার জন্য [StackOverflow](http://stackoverflow.com/questions/tagged/python) একটি ভালো জায়গা।
তা না থাকলে, আপনি সবসময় অন্য কারও প্রশ্ন [জিজ্ঞাসা করতে](https://stackoverflow.com/help/how-to-ask) বা [উত্তর দিতে](https://stackoverflow.com/help/how-to-answer) পারেন।
