# অ্যাবস্ট্রাক্ট ক্লাস

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class JUGGLING < $ACT is
   name : STR is return "Juggling"; end;
   minutes : INT is return 5; end;
   create : SAME is return new; end;
end;
```

## $ নামের অংশ

প্রতিটি অ্যাবস্ট্রাক্ট ক্লাসের নামের শুরুতে একটি `$` থাকে, আর শুধু অ্যাবস্ট্রাক্ট ক্লাসের ক্ষেত্রেই তা থাকে। তাই `$` দিয়ে শুরু হওয়া টাইপ এমন একটি টাইপ, যার অবজেক্ট আপনি বানাতে পারবেন না, আর নামটি যেখানেই দেখা যায় সেখানেই এটা স্পষ্ট।

## এর ভেতরে কী থাকতে পারে

রুটিন ও ইটারেটরের সিগনেচার, সেমিকোলনে গিয়ে শেষ। কোনো বডি নেই, কোনো অ্যাট্রিবিউট নেই, `create` নেই। একটি অ্যাবস্ট্রাক্ট ক্লাস বলে দেয় কোনো কিছুকে কী *জিজ্ঞাসা* করা যায়, কখনও বলে না সেটি কী ধরে রাখে।

## কনফরম্যান্স

```sather
class TRAPEZE < $ACT is
```

ক্লাসটিকে তালিকাভুক্ত প্রতিটি রুটিন ডিফাইন করতে হবে, সাথে মিলতে হবে আর্গুমেন্টের টাইপ ও রিটার্ন টাইপও। কম্পাইল করার সময়ই এটা যাচাই করা হয়।

একটি ক্লাস একাধিক ক্লাসের সাথে কনফর্ম করতে পারে:

```sather
class TRAPEZE < $ACT, $RISKY is
```

এবং অ্যাবস্ট্রাক্ট ক্লাসগুলো একে অপরকে এক্সটেন্ড করতে পারে:

```sather
abstract class $TIMED_ACT < $ACT is
   overrun : INT;
end;
```

## ডিসপ্যাচ কোথায় ঘটে

একটি অ্যাবস্ট্রাক্ট টাইপের ভ্যারিয়েবল কোনো কনফর্মিং অবজেক্টের একটি রেফারেন্স ধরে রাখে। তার উপর কোনো রুটিন কল করলে, রান টাইমে অবজেক্টটির আসল ক্লাসের সংস্করণটিই বেছে নেওয়া হয়।

সেটাই একমাত্র জায়গা যেখানে Sather রান টাইমে কোনো সিদ্ধান্ত নেয়। একটি কনক্রিট টাইপের ভ্যারিয়েবলের উপর কল কম্পাইল করার সময়ই ঠিক হয়ে যায়।

## typecase

কখনও কখনও ধরনটি সত্যিই গুরুত্বপূর্ণ হয়ে ওঠে। `typecase` জিজ্ঞাসা করে:

```sather
   typecase act
   when TRAPEZE then #OUT + "rig the net";
   else            #OUT + "nothing to rig";
   end;
```

একটি আর্মের ভেতরে ভ্যারিয়েবলটির টাইপ আরও সংকীর্ণ। এটি খুব কমই ব্যবহার করুন: প্রতিটি ধরনের অ্যাক্টের উপর `typecase` সাধারণত এমন একটি রুটিন, যা আসলে শুরু থেকেই অ্যাবস্ট্রাক্ট ক্লাসেরই হওয়া উচিত ছিল।

## $OB

`$OB` হলো সেই অ্যাবস্ট্রাক্ট ক্লাস, যার সাথে প্রতিটি অবজেক্ট কনফর্ম করে। এটি মাঝেমধ্যে কাজে লাগে, আর বেশিরভাগ ক্ষেত্রেই এটা এমন একটি চিহ্ন যে পথে কোথাও একটি টাইপ হারিয়ে গেছে।

## উত্তরাধিকার কেন নয়?

Sather এমন দুটি জিনিস আলাদা করে রাখে, যা বেশিরভাগ ভাষা জোড়া লাগিয়ে ফেলে। `<` শুধু বলে দেয় একটি ক্লাস কী *করতে* পারে। অন্য কোথাও থেকে একটি ইমপ্লিমেন্টেশন নেওয়াটা `include`, যা পরের পরের অনুশীলনী, আর সেটা একটি আলাদা সিদ্ধান্ত।
