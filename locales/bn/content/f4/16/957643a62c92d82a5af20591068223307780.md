# Visual Basic শেখা

## ওয়েবসাইট

বছরের পর বছর ধরে Visual Basic যথেষ্ট বদলেছে, আর অনেক থার্ড-পার্টি টিউটোরিয়ালে এখন পুরোনো হয়ে যাওয়া টুল বা ফিচারের কথা বলা হয়।
আপনার যাত্রা শুরুর সবচেয়ে হালনাগাদ ও নির্ভরযোগ্য জায়গা হলো [Visual Basic-এর অফিসিয়াল ডকুমেন্টেশন](https://learn.microsoft.com/en-us/dotnet/visual-basic/)।

## .NET ইকোসিস্টেম

Visual Basic চলে .NET রানটাইমে, আর C# ও F#-এর সঙ্গে অনেক মূল ফাংশনালিটি ভাগ করে নেয়।
তাই .NET কীভাবে কাজ করে সেটা বুঝলে আপনি আরও দক্ষ VB ডেভেলপার হয়ে উঠবেন।

- [.NET গ্লোসারি](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [কমন টাইপ সিস্টেম (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
