# নির্দেশনার সংযোজন

## আউটপুট ফরম্যাট

সেপারেটর হিসেবে একটি কমা ও একটি স্পেস ব্যবহার করে একটি নাল-টার্মিনেটেড স্ট্রিং আউটপুট করুন।

একটি উদাহরণ আউটপুট হতে পারে `"491, 914, 142"`।

ইনপুট অবৈধ হলে একটি খালি স্ট্রিং আউটপুট করুন।

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | ইনপুট        | অ্যাড্রেস | নাল-টার্মিনেটেড সিরিজ স্ট্রিং  |
| `$a1`    | ইনপুট        | ইন্টিজার | স্লাইসের দৈর্ঘ্য                   |
| `$a2`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং  |
| `$t0-9`  | সাময়িক    | যেকোনো     | সাময়িক স্টোরেজের জন্য ব্যবহৃত     |
