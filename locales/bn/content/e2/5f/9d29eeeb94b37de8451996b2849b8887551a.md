# ডিবাগিং

প্রতিটি টেস্ট চালানোর সময় আপনার Red স্ক্রিপ্টের সব আউটপুট কনসোলে দেখা যায়। আপনি যা চান `print` করতে পারেন, যেমন ওয়ার্ডগুলোর মান:

```red
print ["x =" x]
```

এছাড়া `probe` ফাংশনটি খুব কাজে লাগে। মূল্যায়ন করা হলে এটি তার ইনপুট মূল্যায়ন করে, ফলাফলটি এমনভাবে প্রিন্ট করে যাতে তার টাইপ বোঝা যায়, আর তারপর সেটি রিটার্ন করে। তাই বেশিরভাগ ক্ষেত্রেই এটি "স্বচ্ছ", আর আপনি এটি এক্সপ্রেশনের ভেতরে বসাতে পারেন:

```red
x: 10
y: probe x + 5
```

মাঝে মাঝে `type?` নামের ফাংশনটি (হ্যাঁ, এর নামেই প্রশ্নচিহ্ন আছে!) কোনো মানের টাইপ যাচাই করার জন্য কাজে লাগতে পারে:

```red
print ["x type:" type? x]
```

এছাড়া আরও কিছু উন্নত ডিবাগিং কৌশল আছে, যেগুলো [Red-এর Wiki-তে তালিকাভুক্ত](https://github.com/red/red/wiki/%5BDOC%5D-Debugging)।
