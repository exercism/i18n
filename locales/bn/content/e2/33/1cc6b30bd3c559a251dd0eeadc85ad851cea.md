# সম্পর্কে

[এক্সটেনশন মেথড][extension-methods] ব্যবহার করে নতুন কোনো ডেরাইভড টাইপ তৈরি করা, আবার রিকম্পাইল করা বা মূল টাইপটি অন্য কোনোভাবে পরিবর্তন না করেই বিদ্যমান টাইপে মেথড যোগ করা যায়।

এক্সটেনশন মেথড আসলে স্ট্যাটিক মেথড, কিন্তু এগুলোকে এমনভাবে কল করা হয় যেন সেগুলো এক্সটেনড করা টাইপের ইনস্ট্যান্স মেথড। এটি করা হয় টাইপের আগে `this` বসিয়ে, যা বোঝায় যে আমরা যে ইনস্ট্যান্সের উপর `.` বসাই, সেটিই প্রথম প্যারামিটার হিসেবে পাঠানো হয়। ক্লায়েন্ট কোডের জন্য, একটি এক্সটেনশন মেথড কল করা আর কোনো টাইপে ডিফাইন করা মেথড কল করার মধ্যে ظاهری কোনো পার্থক্য নেই।

```csharp
namespace MyExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split().Length;
    }
}

"Hello World".WordCount();
// => 2
```

এক্সটেনশন মেথডগুলো স্কোপে আসে নেমস্পেসের স্তরে। এর মানে হলো, যে নেমস্পেসে এক্সটেনশন মেথডটি ডিফাইন করা হয়েছে, আপনি যদি তার থেকে ভিন্ন কোনো নেমস্পেসে থাকেন, তাহলে প্রথমে একটি `using` ডিরেক্টিভে ওই নেমস্পেসটি রাখতে হবে। উদাহরণস্বরূপ, আমরা যদি আমাদের কোডে উপরের উদাহরণটি ব্যবহার করতে চাই, তবে প্রথমে একটি `using MyExtensions` ডিরেক্টিভ দরকার হবে। আপনি যদি একই নেমস্পেসে থাকেন যেখানে এক্সটেনশন মেথডটি ডিফাইন করা হয়েছে, তাহলে `using` ডিরেক্টিভ ছাড়াই এক্সটেনশন মেথডগুলো ব্যবহার করতে পারবেন।

এক্সটেনশন মেথডের একটি সুপরিচিত উদাহরণ হলো [LINQ][linq]-এর স্ট্যান্ডার্ড কোয়েরি অপারেটরগুলো, যেগুলো বিদ্যমান IEnumerable টাইপে কোয়েরি করার সুবিধা যোগ করে। এগুলো স্কোপে আনতে আমাদের একটি `using System.Linq;` ডিরেক্টিভ দরকার।
