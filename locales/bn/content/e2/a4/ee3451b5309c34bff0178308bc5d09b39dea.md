# নির্দেশনা

আপনার সংস্থার লগ ব্যবস্থাপনায় সহায়তা করার জন্য একটি লগ লাইব্রেরি তৈরির দায়িত্ব আপনাকে দেওয়া হয়েছে। এই লাইব্রেরির সাহায্যে ব্যবহারকারীরা কোন অ্যাপ্লিকেশন একটি নির্দিষ্ট লগ নির্গত করেছে তা শনাক্ত করতে পারবেন, নষ্ট হয়ে যাওয়া লগ ঠিক করতে পারবেন, এবং একটি নির্দিষ্ট লগ লাইন নির্দিষ্ট ক্যারেক্টার সীমার মধ্যে আছে কি না তা নির্ধারণ করতে পারবেন।

## 1. কোন অ্যাপ্লিকেশন একটি লগ নির্গত করেছে তা শনাক্ত করুন

লগ আসে একাধিক অ্যাপ্লিকেশন থেকে, যার প্রত্যেকে নিজস্ব মালিকানাধীন লগ ফরম্যাট ব্যবহার করে।
একটি লগ লগ অ্যাগ্রিগেশন সিস্টেমে সংরক্ষণ করার আগে কোন অ্যাপ্লিকেশনটি লগটি নির্গত করেছে তা শনাক্ত করতে হবে।

এমন একটি `Application` ফাংশন বাস্তবায়ন করুন যা একটি লগ লাইন নেয় এবং যে অ্যাপ্লিকেশনটি লগ লাইনটি নির্গত করেছে তা রিটার্ন করে।

একটি নির্দিষ্ট লগ লাইন কোন অ্যাপ্লিকেশন নির্গত করেছে তা শনাক্ত করতে, নিচের টেবিলে উল্লেখিত একটি নির্দিষ্ট ক্যারেক্টারের জন্য লগ লাইনটি খুঁজুন:

| অ্যাপ্লিকেশন      | ক্যারেক্টার | ইউনিকোড কোড পয়েন্ট |
|------------------|-----------|--------------------|
| `recommendation` | ❗        | `U+2757`           |
| `search`         | 🔍        | `U+1F50D`          |
| `weather`        | ☀         | `U+2600`           |

কোনো লগ লাইনে উপরের টেবিলের কোনো ক্যারেক্টার না থাকলে কলারকে `default` রিটার্ন করুন।
কোনো লগ লাইনে উপরের টেবিলের একটির বেশি ক্যারেক্টার থাকলে, লগ লাইনে বাম থেকে ডানে খুঁজে পাওয়া প্রথম ক্যারেক্টারের সাথে সম্পর্কিত অ্যাপ্লিকেশনটি রিটার্ন করুন।

```go
Application("❗ recommended search product 🔍")
// => recommendation
```

## 2. নষ্ট হয়ে যাওয়া লগ ঠিক করুন

লগিং অবকাঠামোতে একটি বিরল কিন্তু দীর্ঘস্থায়ী bug-এর কারণে লগের কিছু ক্যারেক্টার নষ্ট হয়ে যেতে পারে।
নষ্ট হওয়া ক্যারেক্টারগুলো এবং তাদের মূল মান শনাক্ত করতে সময় ব্যয় করার পর, আপনি নষ্ট হওয়া লগ ঠিক করতে সহায়তা করার জন্য লগ লাইব্রেরি হালনাগাদ করার সিদ্ধান্ত নেন।

এমন একটি `Replace` ফাংশন বাস্তবায়ন করুন যা একটি লগ লাইন, একটি নষ্ট হওয়া ক্যারেক্টার এবং মূল মান নেয় এবং একটি পরিবর্তিত লগ লাইন রিটার্ন করে, যেখানে নষ্ট হওয়া ক্যারেক্টারের সব উপস্থিতি মূল মান দিয়ে প্রতিস্থাপিত হয়েছে।

```go
log := "please replace '👎' with '👍'"

Replace(log, '👎', '👍')
// => please replace '👍' with '👍'"
```

## 3. একটি লগ প্রদর্শন করা যায় কি না তা নির্ধারণ করুন

লগ প্রদর্শনের দায়িত্বে থাকা সিস্টেমগুলোর প্রতি লগ লাইনে প্রদর্শন করা যায় এমন ক্যারেক্টারের সংখ্যার একটি সীমা থাকে।
সেই কারণে, ব্যবহারকারীরা একটি নির্দিষ্ট ক্যারেক্টার সীমার মধ্যে লগ লাইনটি আছে কি না তা নির্ধারণ করার জন্য এই লাইব্রেরিতে একটি হেল্পার ফাংশন যুক্ত করার অনুরোধ করছেন।

এমন একটি `WithinLimit` ফাংশন বাস্তবায়ন করুন যা একটি লগ লাইন এবং ক্যারেক্টার সীমা নেয় এবং লগ লাইনটি ক্যারেক্টার সীমার মধ্যে আছে কি না তা রিটার্ন করে।

```go
WithinLimit("hello❗", 6)
// => true
```
