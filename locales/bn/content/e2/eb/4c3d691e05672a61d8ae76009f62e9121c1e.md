# ভূমিকা

## টাইপ জাগলিং

টাইপ জাগলিংকে টাইপ কোয়ার্শনও বলা হয়।
টাইপ জাগলিং হলো যখন ভিন্ন টাইপের দুটি মান কোনো অপারেশন করার জন্য একই টাইপে রূপান্তরিত হয়।

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

এটি অন্তর্নিহিতভাবে (উপরের উদাহরণ দেখুন) করা যায়, অথবা `C`-স্টাইলের টাইপ কাস্টিং দিয়ে স্পষ্টভাবে করা যায়:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

ম্যানুয়াল টাইপ কাস্টিংয়ের জন্য অনুমোদিত টাইপগুলো হলো: `bool`, `int`, `float`, `string`, `array`, `object`.

সাধারণত, একটি ইন্টিজারকে (`int`) একটি ফ্লোটে (`float`) বা এর বিপরীতে পরিবর্তন করতে টাইপ কাস্টিং ব্যবহার করা হয়।
