# ভূমিকা

[স্ট্রাকচার][structs-and-classes] (সাধারণত *স্ট্রাক্ট* নামে পরিচিত) Swift প্রোগ্রামের প্রধান বিল্ডিং ব্লকগুলোর একটি। স্ট্রাক্টের সাহায্যে আপনি এমন কাস্টম টাইপ তৈরি করতে পারেন, যেখানে সম্পর্কিত প্রোপার্টি (ডেটা) আর মেথড (আচরণ) একসাথে থাকে। আসলে Swift-এর স্ট্যান্ডার্ড টাইপগুলো, যেমন `Int`, `Double`, `Bool`, `String`, `Array` আর `Dictionary`, সবই স্ট্রাক্ট হিসেবে ইমপ্লিমেন্ট করা হয়েছে।

## স্ট্রাক্ট ডিফাইন করা

`struct` কিওয়ার্ড দিয়ে একটি স্ট্রাক্ট ডিফাইন করুন, তারপর টাইপের নাম এবং এর ডেফিনিশন ধারণ করা দ্বিতীয় বন্ধনী লিখুন। Swift-এর রীতি অনুযায়ী স্ট্রাক্টের নামে `UpperCamelCase` ব্যবহার করা হয়:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## ইনস্ট্যান্স তৈরি করা

একটি স্ট্রাক্ট ডেফিনিশন হলো একটি ব্লুপ্রিন্ট। একটি স্ট্রাক্টের *ইনস্ট্যান্স* তৈরি করতে টাইপের নাম লিখে তারপর প্রথম বন্ধনী বসিয়ে তার ইনিশিয়ালাইজার কল করুন:

```swift
var someStats = CharacterStats()
```

এভাবে ডেফিনিশনের ডিফল্ট প্রোপার্টি মান দিয়ে ভরা একটি ইনস্ট্যান্স তৈরি হয়।

Swift স্ট্রাক্টের জন্য স্বয়ংক্রিয়ভাবে একটি **মেম্বারওয়াইজ ইনিশিয়ালাইজার**ও তৈরি করে দেয়, যার সাহায্যে নাম ধরে প্রোপার্টিগুলো ইনিশিয়ালাইজ করা যায়:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## প্রোপার্টি অ্যাক্সেস ও পরিবর্তন করা

*ডট নোটেশন* দিয়ে আপনি একটি ইনস্ট্যান্সের প্রোপার্টি অ্যাক্সেস ও পরিবর্তন করতে পারেন:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

স্ট্রাক্ট যেহেতু ভ্যালু টাইপ, তাই একটি ইনস্ট্যান্সের প্রোপার্টি পরিবর্তন করতে হলে ইনস্ট্যান্সটি নিজেই `var` দিয়ে ডিক্লেয়ার করা থাকতে হবে। ইনস্ট্যান্সটি `let` দিয়ে ডিক্লেয়ার করা হলে তার সব প্রোপার্টি অপরিবর্তনীয় হয়ে যায়।
