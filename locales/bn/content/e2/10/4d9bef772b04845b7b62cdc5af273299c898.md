# নির্দেশনার পরিশিষ্ট

## ওয়ার্ড

`real` ও `imaginary` স্লটসহ একটি `cmplx` টাপল ডিফাইন করুন। `real>>` ও `imaginary>>` স্লট অ্যাক্সেসরগুলো টাপল ডেফিনিশনের সঙ্গেই এমনিতেই পাওয়া যায়, আর টেস্টগুলো কম্পোনেন্ট পড়তে এগুলোই ব্যবহার করে।

- `<cmplx> ( real imag -- cmplx )`: একটি জটিল সংখ্যা গঠন করে।
- `>cmplx ( pair -- cmplx )`: `{ real imaginary }` থেকে একটি `cmplx` তৈরি করে।
- `cmplx>pair ( cmplx -- pair )`: `{ real imaginary }` রিটার্ন করে।
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )`: দুটি জটিল সংখ্যার অ্যারিথমেটিক।
- `c-abs ( a -- |a| )`: পরম মান (একটি বাস্তব সংখ্যা)।
- `c-conj ( a -- a* )`: জটিল অনুবন্ধী।
- `c-exp ( z -- e^z )`: জটিল সূচকীয়।

Factor-এর `MATH:` জেনেরিকগুলো (`+`, `-`, `*`, `/`) কেবল বিল্ট-ইন ম্যাথ হায়ারার্কির উপরেই ডিসপ্যাচ করে, তাই এই অনুশীলনীতে ওই জেনেরিকগুলোর মেথড হিসেবে নয়, বরং আলাদা আলাদা নামের ওয়ার্ড ব্যবহার করা হয়েছে।

বাস্তব সংখ্যার সঙ্গে জটিল সংখ্যা মেশানো অ্যারিথমেটিকের টেস্ট বাদ দেওয়া হয়েছে। এখানে প্রতিটি অপারেশন দুটি `cmplx` মানের মধ্যেই সীমাবদ্ধ।
