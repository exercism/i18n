# নির্দেশনা

এই অনুশীলনীতে আপনি খেলাধুলার বড় ভক্ত, আর আপনি সবে NBA বাস্কেটবলের প্রেমে পড়েছেন।
NBA বাস্কেটবলে নতুন হওয়ায় আপনি NBA-র ইতিহাসে গভীরভাবে ডুব দিচ্ছেন, দল, কোচ আর তাদের জয়-পরাজয়ের পরিসংখ্যান নজরে রাখছেন এবং একে অপরের সঙ্গে তুলনা করছেন।

যেহেতু আপনার এখনো কোনো প্রিয় দল নেই, তাই নির্দিষ্ট কোনো দলকে সমর্থন করা উচিত কি না, তা বের করার একটি অ্যালগরিদমও আপনি তৈরি করবেন।
আপনার নিজস্ব _দল-সমর্থন_ অ্যালগরিদম তৈরি করতে আপনাকে সাহায্য করবে সাতটি কাজ।

## 1. মডেলটি ডিফাইন করুন

নিচের ক্রমে দুটি ফিল্ড আছে এমন একটি রেকর্ডের জন্য `Coach` টাইপ অ্যালিয়াস ডিফাইন করুন:

- `name`: কোচের নাম, টাইপ `String`।
- `formerPlayer`: কোচ আগে খেলোয়াড় ছিলেন কি না তা নির্দেশ করে, টাইপ `Bool`।

নিচের ক্রমে দুটি ফিল্ড আছে এমন একটি রেকর্ডের জন্য `Stats` টাইপ অ্যালিয়াস ডিফাইন করুন:

- `wins`: জয়ের সংখ্যা, টাইপ `Int`।
- `losses`: পরাজয়ের সংখ্যা, টাইপ `Int`।

নিচের ক্রমে তিনটি ফিল্ড আছে এমন একটি রেকর্ডের জন্য `Team` টাইপ অ্যালিয়াস ডিফাইন করুন:

- `name`: দলের নাম, টাইপ `String`।
- `coach`: দলের কোচ, টাইপ `Coach`।
- `stats`: দলের পরিসংখ্যান, টাইপ `Stats`।

## 2. একটি দল তৈরি করুন

আপনি এমন কিছু থার্ড-পার্টি কোডের সঙ্গে কাজ করতে চান যেখানে দলের ধারণা আছে, কিন্তু যেটি ভিন্ন ক্রমে প্যারামিটার দিয়ে আপনার কোড কল করে। নিচের সিগনেচারসহ একটি `createTeam` ফাংশন যোগ করুন: `String -> Stats -> Coach -> Team`।

## 3. কোচ পরিবর্তন করুন

NBA মালিকরা অধৈর্য হওয়ায় আপনি দেখলেন, দলের খারাপ ফলাফল প্রায়ই কোচ বদলে দেওয়ার দিকে নিয়ে যায়।
`replaceCoach` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি প্যারামিটার হিসেবে নতুন কোচ ও দল নেয় এবং নতুন কোচসহ দলটি রিটার্ন করে:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. কোনো দলকে সমর্থন করা উচিত কি না, তা যাচাই করুন

ভবিষ্যতে কোনো দলকে সমর্থন করা উচিত কি না, তা নিয়ে একটি জটিল অ্যালগরিদম বানানোর পরিকল্পনা আপনার আছে, কিন্তু প্রথম প্রচেষ্টায় আপনি সিদ্ধান্ত নিয়েছেন যে জয়ের সংখ্যা পরাজয়ের চেয়ে বেশি, এমন যেকোনো দলকেই আপনি সমর্থন করবেন।

আপনি চান এই ফাংশনটি যেন অন্য প্রসঙ্গেও ব্যবহার করা যায়, তাই টাইপ সিগনেচারে একটি এক্সটেনসিবল রেকর্ড ব্যবহার করে এমন যেকোনো রেকর্ড গ্রহণ করুন যেটিতে প্রাসঙ্গিক ফিল্ডগুলো আছে।
ফাংশনটি যতটা সম্ভব সংক্ষিপ্ত রাখতে আপনি ফাংশনের প্যারামিটার থেকে `stats` নিতে প্যাটার্ন ম্যাচিং ব্যবহার করতে চান।
`rootForTeam` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি একটি দল নেয় এবং ওই দলটিকে সমর্থন করা উচিত হলে `True` রিটার্ন করে; অন্যথায় `False` রিটার্ন করে।

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
