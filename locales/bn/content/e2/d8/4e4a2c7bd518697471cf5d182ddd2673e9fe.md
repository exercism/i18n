# নির্দেশনার সংযোজন

## আউটপুট ফরম্যাট

প্রতিটি জাতীয়তা একটি করে অক্ষর দিয়ে নির্দিষ্ট করা হয় (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)।

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বর্ণনা |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | আউটপুট    | বাইট    | পানি পানকারীর জাতীয়তা |
| `$v1`    | আউটপুট    | বাইট    | জেব্রার মালিকের জাতীয়তা   |
| `$t0-9`  | সাময়িক | যেকোনো     | সাময়িকভাবে সংরক্ষণের জন্য        |
