# ইঙ্গিত

## সাধারণ

- Go-তে স্লাইস জিরো-বেজড।
  স্লাইসের প্রথম ইনডেক্সটি `0`.
- বিল্ট-ইন [`append`][append-builtin] ফাংশনটি [`variadic`][variadic-gobyexample]
- থ্রি ডটস নোটেশন ব্যবহার করে আপনি একটি স্লাইসের এলিমেন্টগুলো আরেকটি স্লাইসে অ্যাপেন্ড করতে পারেন:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. নির্দিষ্ট কিছু কার্ড দিয়ে একটি স্লাইস তৈরি করুন

- কিছু ডেটা দিয়ে আগে থেকে ভরা একটি স্লাইস তৈরি করতে স্লাইস লিটারাল নোটেশন ব্যবহার করুন: `s := []T{x1, x2, ..., xn}`.

## 2. স্ট্যাক থেকে একটি কার্ড বের করুন

- একটি স্লাইসের `n`-তম এলিমেন্ট পেতে [ইনডেক্স ব্যবহার করুন][go-slices].
- একটি স্লাইসে কোনো এলিমেন্ট আছে কি না তা যাচাই করতে একটি শর্ত ব্যবহার করুন এবং ইনডেক্সকে [স্লাইসের দৈর্ঘ্যের সাথে][len-builtin] তুলনা করুন।

## 3. স্ট্যাকের একটি কার্ড বদল করুন

- একটি স্লাইসের `n`-তম এলিমেন্ট সেট করতে [ইনডেক্স ব্যবহার করুন][go-slices] এবং সেটিতে একটি নতুন মান অ্যাসাইন করুন।
- একটি স্লাইসের শেষে একটি নতুন এলিমেন্ট যোগ করতে `append` ফাংশনটি ব্যবহার করুন।

## 4. স্ট্যাকের উপরে কার্ড যোগ করুন

- মূল স্লাইসের এলিমেন্টগুলো `value` আর্গুমেন্ট স্লাইসে অ্যাপেন্ড করে একটি স্লাইসের সামনে এলিমেন্ট যোগ করা যায়।

## 5. স্ট্যাক থেকে একটি কার্ড সরান

- `index`-এর পরের অংশটি index-এর আগের অংশে অ্যাপেন্ড করে একটি স্লাইস থেকে এলিমেন্ট সরানো যায়।
