# পরিচিতি

হ্যাশ হলো Perl-এর একটি ডেটা টাইপ, যেখানে স্ট্রিং কী (key)-এর সঙ্গে স্কেলার মান জোড়া লাগানো একটি ক্রমহীন সংগ্রহ থাকে।

সাধারণত তাতে একটি অ্যারে অ্যাসাইন করে হ্যাশ ভ্যারিয়েবল পূরণ করা হয়, যেমন `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`।

অ্যারের উপাদানগুলো সাধারণত কমা দিয়ে আলাদা করা হয়, তবে অ্যারের মধ্যে কী (key) আর মান আলাদা করতে আপনি প্রায়ই "ফ্যাট কমা" `=>` নামে পরিচিত জিনিসটি দেখতে পাবেন।
এর আচরণ কমার সঙ্গে প্রায় অভিন্ন, তবে এর বাড়তি সুবিধা হলো এটি বাম দিকের এলিমেন্টটিকে একটি স্ট্রিং হিসেবে ব্যাখ্যা করে।

আলাদা আলাদা কী (key)-তে অ্যাসাইন করেও হ্যাশ পূরণ করা যায়, যেমন `$scores{Alice} = 10;`।

সাবস্ক্রিপ্টের মাধ্যমে কী (key) উল্লেখ করে হ্যাশের মান পাওয়া যায়, যেমন `$scores{Bob} # 15`।

হ্যাশের কী (key) গুলো ইউনিক হয়।
একই কী (key) একাধিকবার দিলে কেবল শেষবার দেওয়া মানটিই রাখা হয়।

## ফাংশন

হ্যাশ নিয়ে কাজ করার ফাংশনের মধ্যে আছে [keys][keys] আর [values][values], যা দিয়ে হ্যাশের ওই অংশগুলো অ্যারে হিসেবে বের করা যায়।
[keys][keys] আর [values][values] ফাংশন যে অ্যারে রিটার্ন করে, তা [grep][grep], [map][map] ও [sort][sort]-এর মতো অ্যারে ফাংশনে এবং [for][for] লুপেও কাজে লাগে।

অন্য হ্যাশ ফাংশনের মধ্যে আছে [exists][exists], যা দিয়ে হ্যাশে কোনো কী (key) আছে কি না তা দেখা যায় (তার মান `undef` হলেও), এবং [delete][delete], যা দিয়ে হ্যাশ থেকে একটি কী (key) মুছে ফেলা যায়।

## সিগিলের ভিন্নতা

হ্যাশের মান বের করার সময় কোন সিগিল দিচ্ছেন সেটিই ফলাফল নির্ধারণ করে। ভ্যারিয়েবল নামের শেষে থাকা সাবস্ক্রিপ্ট `{}`-ই Perl-কে জানায় যে আপনি ওই নামের একটি হ্যাশ অ্যাক্সেস করছেন।

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

এটি অনুমোদিত হলেও, পড়ার সুবিধার জন্য ভিন্ন ভিন্ন টাইপের ভ্যারিয়েবলকে একই নাম দেওয়া না-ই ভালো।
