# নির্দেশনার সংযোজন

## ইমপ্লিমেন্টেশন

এই অনুশীলনীতে আপনাকে এমন একটি ফাংশন কল করতে হবে, যা আর্গুমেন্ট হিসেবে পাস করা হয়।
Uiua-তে আপনি এটি করতে পারেন [ম্যাক্রো](https://www.uiua.org/tutorial/macros) ব্যবহার করে, আর এই অনুশীলনীও সেভাবেই সমাধান করার প্রত্যাশা করে।

```exercism/note
`!` প্রত্যয় দেখেই আপনি সঙ্গে সঙ্গে বুঝে নিতে পারবেন যে বাইন্ডিংটি একটি ম্যাক্রো।
```
