# টেস্ট

## কোড লেখা

আপনার কোড `src/lib.cairo`-এ লিখুন।
অনুশীলনীগুলোর সঙ্গে `src/lib.cairo`-এ একটি স্টাব ফাইল থাকে, যা আপনার যে কোডটি লিখতে হবে তার সিগনেচারগুলো দেখিয়ে দেবে।

বেশিরভাগ অনুশীলনীর ক্ষেত্রে আপনার সব কোড `src/lib.cairo` ফাইলেই লেখা সবচেয়ে ভালো।
আপনি যদি আপনার সমাধান কয়েকটি ফাইলে ভাগ করতে চান, তবে The Cairo Book-এর [মডিউল সংক্রান্ত অধ্যায়টি][chapter-modules] দেখুন।

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## টেস্ট চালানো

টেস্ট চালাতে হলে প্রথমে যে অনুশীলনীটি টেস্ট করতে চান তার ডিরেক্টরিতে আপনার ওয়ার্কিং ডিরেক্টরি বদলাতে হবে:

```bash
cd path/to/exercise
```

এরপর নিচের কমান্ডটি চালান:

```bash
scarb cairo-test
```

ডিফল্টভাবে কেবল প্রথম টেস্টটি এনাবল থাকে।
পরের টেস্টটি পাস করার জন্য প্রস্তুত হলে, পরের টেস্ট থেকে ignore ফ্ল্যাগটি (`#[ignore]`) সরিয়ে দিন।

ignore করা টেস্টগুলোসহ সব টেস্ট চালাতে আপনি সব টেস্ট থেকে `ignore` ফ্ল্যাগটি সরিয়ে দিতে পারেন, অথবা শুধু এটুকু চালাতে পারেন:

```bash
scarb cairo-test --include-ignored
```

টেস্টগুলো পাস করাতে নির্দ্বিধায় যতটা সম্ভব কম কোড লিখুন।
টেস্টের ব্যর্থতাগুলোই আপনাকে বলে দেবে এরপর কী লেখা উচিত।

Cairo কম্পাইল টাইমে সব কোড যাচাই করে, তাই প্রয়োজনীয় কোড না লেখা পর্যন্ত আপনার টেস্ট কম্পাইল নাও হতে পারে।
এমনকি `ignore` করা টেস্টগুলোও কম্পাইল টাইমে যাচাই করা হয়।
যে টেস্টগুলো কম্পাইল হবে না, সেগুলোর প্রতিটি লাইন `//` দিয়ে শুরু করে আপনি সেগুলো [কমেন্ট আউট][comments] করতে পারেন।
এরপর যখন সেই টেস্টটি নিয়ে কাজ করার জন্য প্রস্তুত হবেন, তখন সেটি আন-কমেন্ট করতে পারবেন।
Cairo-তে `panic!()` নামের একটি বিশেষ ম্যাক্রোও আছে, যা আপনি অসম্পূর্ণ কোড পাথে ব্যবহার করে আপনার প্রোগ্রাম কম্পাইল করাতে পারেন।

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
