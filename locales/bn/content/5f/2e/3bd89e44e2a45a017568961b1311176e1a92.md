# ইনস্টলেশন

## Linux

GNU/Linux সিস্টেমে Bash, অর্থাৎ GNU শেল, সবসময় পাওয়া যাবে।
BSD ও অন্যান্য UNIX ডেরিভেটিভ ব্যবহার করতে হলে সাধারণত ব্যবহারকারীকে নিজেই ইনস্টল করতে হয়।
আপনি যদি BSD, AIX বা এমন Linux ব্যবহার করেন যার সাথে bash আসে না, তাহলে কোর-বহির্ভূত প্যাকেজ ইনস্টল করার বিষয়ে আপনার অপারেটিং সিস্টেমের রিসোর্স দেখুন।

আপনার পছন্দের গ্রাফিক্যাল ইন্টারফেসে "Terminal" নামের একটি অ্যাপ্লিকেশন খুঁজুন: এটি হয়তো "Administrative/System Tools" সেকশনের অধীনে থাকতে পারে।

আপনার কাছে থাকা Bash-এর ভার্সন যাচাই করতে, কমান্ড লাইন বা টার্মিনাল থেকে চালান:

    echo $BASH_VERSION

আপনার শেল যদি `bash` হয়, তাহলে এটি এমন কিছু দেখাবে:

    4.4.19(1)-release

এর বাইরে আপনার আর কিছু করার দরকার নেই; যেহেতু bash-ই আপনার বর্তমান শেল, তাই এটি ইনস্টল করা অবস্থায় আপনার PATH-এ থাকার কথা।

আপনার শেল যদি bash না হয়, তাহলে তা বদলানোর কোনো দরকার নেই।
bash শেলে না থেকেও আপনি bash স্ক্রিপ্ট লিখতে ও চালাতে পারেন।

আপনার ইনস্টল করা bash-এর ভার্সন যাচাই করতে চালান:

```plain
bash --version
```

এটি এমন কিছু দেখাবে:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

যদি না দেখায়, তাহলে হয়তো আপনার কম্পিউটারে bash ইনস্টল নেই।
আপনার ডিস্ট্রিবিউশনের প্যাকেজ ম্যানেজার দিয়ে এটি ইনস্টল করে নিন।

## Windows

Windows 10-এর জন্য আপনি [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) ইনস্টল করতে পারেন।
এটি একটি সম্পূর্ণ Linux ডিস্ট্রিবিউশন (আসলে, GUI ছাড়া অংশটুকু) ইনস্টল করে, যা Windows-এ নেটিভভাবে চলে।

অন্যথায়, আপনি ইনস্টল করতে পারেন:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* একটি [ভার্চুয়াল মেশিনে](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/) সম্পূর্ণ Linux ডিস্ট্রিবিউশন

## MacOS

Apple OSX-এর জন্য:

* Finder খুলুন,
* আপনার Applications ফোল্ডার খুলুন,
* Utilities ফোল্ডার খুলুন,
* সবশেষে `Terminal` অ্যাপ্লিকেশনটি খুলুন।

মনে রাখবেন, MacOS-এ ইনস্টল করা bash-এর ভার্সনটি বেশ পুরোনো, 3.2।
এর কারণ (i) নতুন bash ভার্সনগুলো GPLv3 লাইসেন্সের অধীনে, আর (ii) Apple ওই লাইসেন্সের শর্ত মানতে বাধ্য হতে চায় না।
এছাড়া Apple জানিয়েছে যে MacOS থেকে bash বাদ পড়বে: সম্প্রতি ডিফল্ট লগইন শেল [bash থেকে zsh-এ বদলে দেওয়া হয়েছে](https://support.apple.com/en-us/HT208050)।

আপনার Mac-এ হালনাগাদ bash পেতে:

1. [Homebrew](https://brew.sh) ইনস্টল করুন
1. একটি Terminal-এ লিখুন: `brew install bash`

এটি হালনাগাদ bash ইনস্টল করে (আমার বিশ্বাস) `/usr/local/bin/bash` হিসেবে (যাতে সিস্টেমের ডিফল্ট bash মুছে না যায়; অন্য টুলগুলো /bin/bash-এর উপর নির্ভর করতে পারে)।

আপনি `bash` টাইপ করলে যদি homebrew-এর bash চালু করতে চান, তাহলে আপনার ~/.bash_profile (বা ~/.profile) ফাইলটি এডিট করে PATH-এ /bin-এর *আগে* /usr/local/bin বসান:

    PATH=/usr/local/bin:$PATH
