# পরিচিতি

## রেকর্ড

রেকর্ড হলো একসাথে থাকা কিছু ফিল্ডের (যেগুলো ভিন্ন ভিন্ন টাইপের হতে পারে) একটি সংগ্রহ। একটি রেকর্ড ডিফাইন করতে `type` কিওয়ার্ডটি ব্যবহার করা হয়। রেকর্ডের ফিল্ডগুলো `{` আর `}` অক্ষরের মাঝে ডিফাইন করা হয়, এবং প্রতিটি ফিল্ডের একটি নাম _এবং_ একটি টাইপ থাকে। একটি রেকর্ড তৈরি করতে, ফিল্ডগুলোর নাম উল্লেখ করে `{` আর `}` অক্ষরের মাঝে সেগুলোতে একটি মান অ্যাসাইন করতে হয়। রেকর্ড তৈরি করার সময় সব ফিল্ডেই একটি মান অ্যাসাইন করতে হবে। ডট-নোটেশন ব্যবহার করে একটি রেকর্ড ইনস্ট্যান্সের ফিল্ডের মান অ্যাক্সেস করা যায়।

একটি রেকর্ড ডিফাইন বা তৈরি করার সময় প্রতিটি ফিল্ড হয় আলাদা লাইনে থাকতে হবে, নয়তো একই লাইনে থাকলে সেমিকোলন (`;`) দিয়ে আলাদা করতে হবে।

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

যেহেতু রেকর্ড ইমিউটেবল, তাই একবার একটি রেকর্ড তৈরি হয়ে গেলে তার ফিল্ডের মান আর কখনো বদলানো যায় না। আপনি যদি একটি রেকর্ডের মান বদলাতে চান, তাহলে `with` কিওয়ার্ডটি দিয়ে বিদ্যমান রেকর্ডের একটি কপি তৈরি করতে পারেন, তবে এক বা একাধিক ফিল্ডের নতুন মান দিয়ে।

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

রেকর্ডে _স্ট্রাকচারাল ইকুয়ালিটি_ থাকে, যার মানে একই রেকর্ডের একই মানের দুটি ইনস্ট্যান্স সমতুল্য।

ডট-নোটেশন দিয়ে রেকর্ডের ফিল্ড অ্যাক্সেস করা ছাড়াও, রেকর্ডকে বাইন্ডিং এবং প্যাটার্ন ম্যাচিংয়ে _ডিকনস্ট্রাক্ট_ করা যায়:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
