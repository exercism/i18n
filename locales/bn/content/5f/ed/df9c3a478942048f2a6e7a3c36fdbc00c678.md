# পরিচিতি

[টার্নারি অপারেটর][ternary-operators] দিয়ে if-শর্ত স্টেটমেন্ট ব্লকের বদলে এক্সপ্রেশনের ভেতরে লেখা যায়। এটি ফাংশনাল প্রোগ্রামিংয়ের ধরনের সঙ্গে মেলে এবং প্রায়শই কোডকে আরও প্রকাশক্ষম ও কম এররপ্রবণ করে তোলে।

টার্নারি অপারেটর তিনটি এক্সপ্রেশন একসঙ্গে জুড়ে দেয়: একটি শর্ত, তারপর শর্তটি সত্য হলে যে এক্সপ্রেশনটি হিসাব করে রিটার্ন করা হবে (অর্থাৎ `if` অংশ, যা শুরু হয় `?` দিয়ে), এবং শর্তটি ফলস হলে যে এক্সপ্রেশনটি হিসাব করে রিটার্ন করা হবে (অর্থাৎ `else` অংশ, যা শুরু হয় `:` দিয়ে)।

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
