# ভূমিকা

একটি কালেকশনের সংজ্ঞায় সাধারণত কোণ বন্ধনীর ভেতরে একটি প্লেসহোল্ডার থাকে, প্রচলন অনুসারে যা প্রায়ই T হয়। এমন কালেকশনকে জেনেরিক টাইপ বলা হয়। এতে কালেকশনের ব্যবহারকারী নির্দিষ্ট করতে পারেন, কালেকশনে কোন ধরনের আইটেম সংরক্ষণ করা হবে। উপরের উদাহরণ কোডে আমরা স্ট্রিংয়ের একটি অ্যারে ইন্সট্যানশিয়েট করছি।

`@:generic` অ্যাট্রিবিউট ব্যবহার করে একটি ক্লাস বা ফাংশনকে **জেনেরিক** করা হয়। এতে কম্পাইলার ক্লাসটি বা ফাংশনটিকে জেনেরিক হিসেবে চিহ্নিত করে:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
