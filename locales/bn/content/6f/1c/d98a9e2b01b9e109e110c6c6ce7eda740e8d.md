# ফ্লোটিং পয়েন্ট সংখ্যা

`FLTD` এমন একটি সংখ্যা ধারণ করে যার একটি ভগ্নাংশ থাকতে পারে। একটি লিটারেল লিখতে দশমিক বিন্দু আর একটি `d` লাগে:

```sather
   440.0d
   0.5d
   -2.25d
```

`FLT` একই ধারণা, তবে এর নির্ভুলতা অর্ধেক। এই ট্র্যাকে সর্বত্র `FLTD` ব্যবহার করা হয়; মেমরি কম থাকলে ছাড়া `FLT`-এর দিকে হাত বাড়ানোর কোনো কারণ নেই।

## গাণিতিক অপারেশন

| অপারেটর | অর্থ |
| --- | --- |
| `+` `-` `*` | `INT`-এর মতোই |
| `/` | ভাগ, ভগ্নাংশটি রেখে দেওয়া হয় |

`FLTD`-এর জন্য কোনো `%` নেই।

দুটি অপারেন্ডই `FLTD` হতে হবে। মাঝে একটি `INT` মিশিয়ে ফেলা একটি কম্পাইল এরর, কোনো নীরব রূপান্তর নয়। আর এটাই আসলে একটি সুবিধা: এটি যেখানে একমাত্র ঝামেলা করে, সেটি ঠিক সেই জায়গা যেখানে মানুষ ভুল করে।

## রূপান্তর

```sather
   7.fltd            -- 7.0, an INT made into an FLTD
   7.5d.int          -- 7, the fraction thrown away
   7.5d.round        -- 8, to the nearest whole number
   7.5d.floor        -- 7.0, down to a whole number
   7.5d.ceiling      -- 8.0, up to a whole number
```

ভাগ করার আগে রূপান্তর করুন, পরে নয়: `n.fltd / 2.0d` অর্ধেকটি ধরে রাখে, কিন্তু `(n / 2).fltd` তা আগেই হারিয়ে ফেলেছে।

## দরকারি রুটিন

```sather
   (-2.5d).abs       -- 2.5
   2.0d.sqrt         -- 1.41421
   (2.0d).max(3.0d)  -- 3.0
```

## ফ্লোটিং পয়েন্ট আসন্ন মান

একটি `FLTD` অত্যন্ত নিকটবর্তী একটি আসন্ন মান ধারণ করে, সঠিক মান নয়। বেশিরভাগ দশমিক ভগ্নাংশ সঠিকভাবে সংরক্ষণ করা যায় না, ঠিক যেভাবে এক-তৃতীয়াংশ দশমিক পদ্ধতিতে সঠিকভাবে লেখা যায় না। তাই:

```sather
0.1d + 0.2d          -- very nearly 0.3, but not exactly
```

মনে রাখার মতো দুটি পরিণতি আছে:

**`=` দিয়ে তুলনা করবেন না।** যে দুটি হিসাবের একই উত্তর আসা উচিত, তারা প্রায়ই শেষ কয়েকটি অঙ্কে আলাদা হয়ে যায়। বদলে জিজ্ঞেস করুন, তারা কাছাকাছি কি না:

```sather
   (a - b).abs < 0.0001d
```

**অনেকগুলো ছোট মান যোগ করলে নির্ভুলতা কমে যায়।** প্রতিটি যোগ একটু একটু করে আসন্ন করে, আর এররগুলো জমতে থাকে।

যখন মান নির্ভুল হওয়া জরুরি, বিশেষ করে টাকাপয়সার হিসাবে, তখন বদলে `INT` দিয়ে পূর্ণ এককে গুনুন (ডলারের বদলে সেন্ট)।

## প্রিন্ট করা

`.str` প্রায় ছয়টি তাৎপর্যপূর্ণ অঙ্ক দেখায়, যা আসলে ধারণ করা নির্ভুলতার চেয়ে কম:

```sather
   #OUT + (1.0d / 3.0d).str;      -- 0.333333
```
