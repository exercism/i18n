# বিবরণ

আজ বিশ্বের বেশিরভাগ মানুষ আরবি সংখ্যা (০–৯) ব্যবহার করে।
কিন্তু আপনি যদি দুই হাজার বছর পিছিয়ে যেতেন, তাহলে দেখতে পেতেন যে বেশিরভাগ ইউরোপীয় বরং রোমান সংখ্যা ব্যবহার করছিলেন।

একটি রোমান সংখ্যা লিখতে আমরা নিচের লাতিন অক্ষরগুলো ব্যবহার করি, যার প্রত্যেকটির একটি মান আছে:

| M    | D   | C   | L   | X   | V   | I   |
| ---- | --- | --- | --- | --- | --- | --- |
| 1000 | 500 | 100 | 50  | 10  | 5   | 1   |

একটি রোমান সংখ্যা হলো এই অক্ষরগুলোর একটি ক্রম, আর এর মান হলো অক্ষরগুলোর মানের যোগফল।
উদাহরণস্বরূপ, `XVIII`-এর মান ১৮ (`10 + 5 + 1 + 1 + 1 = 18`)।

তবে একটি নিয়ম বিষয়টা আরও জটিল করে তোলে, সেটি হলো **একই অক্ষর পরপর তিনবারের বেশি ব্যবহার করা যাবে না**।
এর মানে হলো, ৪-এর মতো সংখ্যা আপাতদৃষ্টিতে স্বাভাবিক লাগা `IIII` দিয়ে প্রকাশ করা যায় না।
তার বদলে ওই সংখ্যাগুলোর জন্য আমরা দুটি অক্ষরের মধ্যে বিয়োগ পদ্ধতি ব্যবহার করি।
তাই আমরা `4`-কে `1 + 1 + 1 + 1` হিসেবে নয়, বরং `5 - 1` হিসেবে ভাবি।
আর আমাদের আধুনিক চিন্তাধারার কাছে একটু বিভ্রান্তিকর হলেও, আমরা ছোট সংখ্যাটি আগে লিখি।
এটি কেবল নিচের ক্ষেত্রগুলোতেই প্রযোজ্য: ৪ (`IV`), ৯ (`IX`), ৪০ (`XL`), ৯০ (`XC`), ৪০০ (`CD`) এবং ৯০০ (`CM`)।

রোমান সংখ্যায় ক্রম গুরুত্বপূর্ণ!
অক্ষরগুলো (এবং উপরের বিশেষ সংমিশ্রণগুলো) বাম থেকে ডানে মান কমার ক্রমে সাজানো থাকতে হবে।

এখানে কয়েকটি উদাহরণ:

```text
 105 => CV
---- => --
 100 => C
+  5 =>  V
```

```text
 106 => CVI
---- => --
 100 => C
+  5 =>  V
+  1 =>   I
```

```text
 104 => CIV
---- => ---
 100 => C
+  4 =>  IV
```

আর শেষে আরও জটিল একটি উদাহরণ:

```text
 1996 => MCMXCVI
----- => -------
 1000 => M
+ 900 =>  CM
+  90 =>    XC
+   5 =>      V
+   1 =>       I
```
