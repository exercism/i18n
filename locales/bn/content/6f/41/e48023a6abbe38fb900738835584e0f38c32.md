# ইনস্টলেশন

## .NET ইনস্টল করা

F# ট্র্যাকটি [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) প্ল্যাটফর্মের উপরে তৈরি, যা Windows, Linux আর macOS-এ চলে। .NET প্রজেক্ট বানাতে আপনি .NET কমান্ড লাইন ইন্টারফেস (CLI) ব্যবহার করতে পারেন। এই CLI-টি .NET SDK-এর অংশ, যা আপনি [ইনস্টলেশন নির্দেশাবলি](https://dotnet.microsoft.com/download) অনুসরণ করে ইনস্টল করতে পারেন। মনে রাখবেন: F# ট্র্যাকের জন্য SDK-এর 8.0 বা তার পরের ভার্সন দরকার।

ইনস্টলেশন শেষ করার পর টার্মিনালে এই কমান্ডটি চালিয়ে দেখতে পারেন CLI ঠিকভাবে ইনস্টল হয়েছে কি না:

```bash
dotnet --version
```

আউটপুট যদি `8.0.100` বা তার চেয়ে বড় কোনো ভার্সন হয়, তাহলে .NET SDK ঠিকভাবে ইনস্টল হয়েছে।

## একটি IDE ব্যবহার করা

আপনি যদি আরও পূর্ণাঙ্গ এডিটিং অভিজ্ঞতা চান, তাহলে সম্ভবত একটি IDE-ই ব্যবহার করতে চাইবেন। যেসব জনপ্রিয় IDE .NET প্রজেক্ট বানানো সাপোর্ট করে, সেগুলো হলো:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) ও [Ionide-fsharp এক্সটেনশন](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

মনে রাখবেন: .NET প্রজেক্টের ফরম্যাট আগের ভার্সনগুলোর থেকে যথেষ্ট আলাদা, তাই পুরোনো IDE (যেমন Visual Studio 2015) সাপোর্ট করে না।
