# ভূমিকা

## বুলিয়ান

Java-তে বুলিয়ান বোঝানো হয় `boolean` টাইপ দিয়ে, যার মান `true` বা `false` হতে পারে।

Java তিনটি বুলিয়ান অপারেটর সমর্থন করে:  

- `!` (NOT): বুলিয়ানটিকে উল্টে দেয়  
- `&&` (AND): দুটি বুলিয়ান নেয় এবং দুটিই `true` হলে `true` রিটার্ন করে
- `||` (OR): দুটি বুলিয়ানের যেকোনো একটি `true` হলে `true` রিটার্ন করে

### উদাহরণ

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
