# ইনস্টলেশন

## প্রয়োজনীয়তা

* একটি ৬৪-বিট x86 CPU
* একটি আধুনিক C কম্পাইলার
* Make বিল্ড টুল
* Netwide Assembler (NASM)

মনে রাখবেন, এই ট্র্যাকটি শুধু System V AMD64 ABI-এর কলিং কনভেনশন সমর্থন করে। Windows ব্যবহারকারীদের Windows Subsystem for Linux (WSL) ইনস্টল করতে হবে, অথবা একটি Linux ভার্চুয়াল মেশিন সেট আপ করতে হবে।

## Linux

আপনার সিস্টেমের প্যাকেজ ম্যানেজার দিয়ে প্রয়োজনীয় সফটওয়্যার ইনস্টল করুন:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Xcode Command Line Tools ইনস্টল করুন:

```bash
$ xcode-select --install
```

[Homebrew](http://brew.sh/) দিয়ে NASM ইনস্টল করুন:

```bash
$ brew install nasm
```

## Windows

WSL ইনস্টল করতে দেখুন https://docs.microsoft.com/en-us/windows/wsl/install-win10.
