# ইঙ্গিত

## সাধারণ

- [সেট][set]-এর ডকুমেন্টেশন পড়ুন।
- [অ্যারে][lists]-এর ডকুমেন্টেশনও কাজে লাগতে পারে।

## 1. একটি সংগ্রহ শুরু করুন

- সবচেয়ে উপযুক্ত `Set` ফাংশনটি হলো [`Set.singleton`][singleton]।

## 2. সংগ্রহ বাড়ান

- [`Set.insert` ফাংশনটি][insert] ব্যবহার করুন।
- [`Set.member` ফাংশনটি][member] ব্যবহার করুন।

## 3. ট্রেডিং শুরু করুন

- [`Set.member` ফাংশনটি][member] ব্যবহার করুন।
- [`Set.insert` ফাংশনটি][insert] ব্যবহার করুন।
- [`Set.remove` ফাংশনটি][remove] ব্যবহার করুন।

## 4. প্রতিটির একটি মাত্র থাকতে পারে

- `Set`-এর বৈশিষ্ট্য হলো এতে কেবল অনন্য মান থাকে।
- [`Set.fromList` ফাংশনটি][fromList] ব্যবহার করুন।
- [`Set.toList` ফাংশনটি][toList] ব্যবহার করুন।
- `Set.toList` নিশ্চিতভাবে একটি সাজানো অ্যারে রিটার্ন করে।

## 5. যেসব কার্ড তাদের নেই

- [`Set.diff` ফাংশনটি][diff] ব্যবহার করুন।
- [`Set.size` ফাংশনটি][size] ব্যবহার করুন।

## 6. যেসব কার্ড তাদের সবার আছে

- [`List.foldl` বা `List.foldr` ফাংশন][fold] ব্যবহার করুন।
- খালি এবং খালি নয় এমন অ্যারে আলাদা করতে অ্যারের ওপর প্যাটার্ন ম্যাচিং ব্যবহার করুন।
- [`Set.intersect` ফাংশনটি][intersect] ব্যবহার করুন।
- [`Set.toList` ফাংশনটি][toList] ব্যবহার করুন।
- `Set.toList` নিশ্চিতভাবে একটি সাজানো অ্যারে রিটার্ন করে।

## 7. সব কার্ড

- [`List.foldl` বা `List.foldr` ফাংশন][fold] ব্যবহার করুন।
- অ্যাকুমুলেটর হিসেবে [`Set.empty`][empty] ব্যবহার করুন।
- [`Set.union` ফাংশনটি][union] ব্যবহার করুন।
- [`Set.size` ফাংশনটি][size] ব্যবহার করুন।

## 8. শাইনিতেই জয়

- [`Set.partition` ফাংশনটি][partition] ব্যবহার করুন।
- [`String.startsWith` ফাংশনটি][startsWith] ব্যবহার করুন।
- [`Set.toList` ফাংশনটি][toList] ব্যবহার করুন।
- `Set.toList` নিশ্চিতভাবে একটি সাজানো অ্যারে রিটার্ন করে।
