# Introduction

একটি [`Set`][set] হলো কিছু আইটেমের কালেকশন, যার বৈশিষ্ট্যগুলো হলো:

- কোনো নির্দিষ্ট ক্রম নেই।
- এন্ট্রিগুলো অনন্য, তাই ডুপ্লিকেট যোগ করার চেষ্টা নীরবে উপেক্ষা করা হয়।
- গাণিতিক সেটের সঙ্গে কমন অনেক অপারেশন সাপোর্ট করে।

এগুলো তৈরি করুন `Set()` কনস্ট্রাক্টর দিয়ে, যেকোনো ইটারেটরকে প্যারামিটার হিসেবে নিয়ে।

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

`push!()` দিয়ে নতুন এলিমেন্ট যোগ করুন (অ্যারের ক্ষেত্রে যেমন, ঠিক তেমনই), আর `delete!()` দিয়ে সেগুলো মুছে ফেলুন।

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## সেট অপারেশন

আরও কয়েকটি কালেকশন টাইপের মতোই, `in` বা `∈` অপারেটর দিয়ে সদস্যপদ যাচাই করুন (`\in` লিখে তারপর ট্যাব চাপলে সিম্বলটি পাবেন)।

```julia-repl
julia> 3 ∈ s1
true
```

সেটের জোড়ার উপর নিচের অপারেশনগুলো সাপোর্ট করা হয় (অপারেটর সিম্বলের শর্টকাট প্রথম বন্ধনীর ভেতরে দেখানো হয়েছে)।

- `union(A, B)` বা `A ∪ B` (`\cup`): A বা B বা দুটোতেই আছে এমন সব এন্ট্রি।
- `intersect(A, B)` বা `A ∩ B` (`\cap`): A ও B দুটোতেই কমন এমন সব এন্ট্রি।
- `setdiff(A, B)` (কোনো সিম্বল নেই): A-তে আছে কিন্তু B-তে নেই এমন এন্ট্রি।
- `symdiff(A, B)` (কোনো সিম্বল নেই): A বা B যেকোনো একটিতে আছে কিন্তু দুটোতেই নয়, এমন এন্ট্রি।
- `issubset(A, B)` বা `A ⊆ B` (`\subseteq`) বা `B ⊇ A` (`\supseteq`): A-র সব এন্ট্রি B-তেও থাকলে `true`।
- `issetequal(A, B)` (কোনো সিম্বল নেই): A ও B-তে হুবহু একই এন্ট্রি থাকলে `true`।
- `isdisjoint(A, B)` (কোনো সিম্বল নেই): A ও B-তে কমন কোনো এন্ট্রি না থাকলে `true` (অর্থাৎ ইন্টারসেক্ট খালি)।

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

এগুলোর অনেকগুলোরই মিউটেটিং ভার্সন আছে, যেখানে ফাংশনের নামের শেষে `!` যোগ করা থাকে। ফাংশনের সম্পূর্ণ তালিকার জন্য [ম্যানুয়াল][set] দেখুন।
