# পরিচিতি

JavaScript-এ অ্যারে হলো তালিকার মতো একটি গঠন, যার কোনো নির্দিষ্ট দৈর্ঘ্য নেই এবং যা যেকোনো ধরনের প্রিমিটিভ বা অবজেক্ট ধারণ করতে পারে, এমনকি মিশ্র টাইপও।

একটি অ্যারে তৈরি করতে, তৃতীয় বন্ধনী `[]`-এর মধ্যে এলিমেন্ট যোগ করুন।
অ্যারে থেকে পড়তে, আইডেন্টিফায়ারের পরে তৃতীয় বন্ধনী `[]`-এর মধ্যে ইনডেক্স বসান।
অ্যারের ইনডেক্স শুরু হয় শূন্য থেকে।

যেমন:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

অ্যারেতে কতগুলো এলিমেন্ট আছে তা জানতে, `length` প্রোপার্টি ব্যবহার করুন:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

অ্যারের একটি এলিমেন্ট পরিবর্তন করতে, ইনডেক্সে একটি মান অ্যাসাইন করুন:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## মেথড

প্রতিটি Array অবজেক্টে উপলব্ধ কিছু [মেথড][mdn-array] দিয়ে অ্যারেতে যোগ করা বা অ্যারে থেকে সরানো যায়।
এই অনুশীলনীতে কাজ করার সময় বিবেচনা করার জন্য কয়েকটি এখানে দেওয়া হলো:

### push

`.push(value)` ব্যবহার করে অ্যারের শেষে একটি `value` _যোগ_ করা যায়।
মেথডটি অ্যারের নতুন দৈর্ঘ্য রিটার্ন করে।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

`.pop()` ব্যবহার করে অ্যারে থেকে _শেষ_ `value`টি _সরিয়ে ফেলা_ যায়।
মেথডটি সরানো মানটি রিটার্ন করে।
এই পরিবর্তনের ফলে অ্যারের দৈর্ঘ্য কমে যাবে।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

`.shift()` ব্যবহার করে অ্যারে থেকে _প্রথম_ `value`টি _সরিয়ে ফেলা_ যায়।
মেথডটি সরানো মানটি রিটার্ন করে।
এই পরিবর্তনের ফলে অ্যারের দৈর্ঘ্য কমে যাবে।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

`.unshift(value)` ব্যবহার করে অ্যারের শুরুতে একটি `value` _যোগ_ করা যায়।
মেথডটি অ্যারের নতুন দৈর্ঘ্য রিটার্ন করে।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

`.splice(index, 1)` ব্যবহার করে অ্যারে থেকে নির্দিষ্ট `index`-এ থাকা একটি `value` _সরিয়ে ফেলা_ যায়।
মেথডটি সরানো এলিমেন্টটি (বা এলিমেন্টগুলো) রিটার্ন করে।

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
