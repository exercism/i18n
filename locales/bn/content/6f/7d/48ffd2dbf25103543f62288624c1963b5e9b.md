# ভূমিকা

[ম্যানুয়াল][man-types] থেকে

> jq, JSON-এর মতো একই সেটের ডেটা টাইপ সাপোর্ট করে: সংখ্যা, স্ট্রিং, বুলিয়ান, অ্যারে, অবজেক্ট (JSON-এর ভাষায় যা শুধু স্ট্রিং কী (key) দিয়ে গঠিত হ্যাশ), আর "null"।

চলুন এখন **সংখ্যা** নিয়েই কথা বলি।

## সংখ্যা এবং সংখ্যার অপারেটর

সব সংখ্যাই, ইন্টিজার হোক বা অন্য কিছু, IEEE754 ডাবল প্রিসিশন ফ্লোটিং পয়েন্ট সংখ্যা।
এতে আমাদের নির্ভুলতা ৫৩ বিটে সীমাবদ্ধ হয়ে যায়।

সংখ্যার সাথে ব্যবহারের জন্য সাধারণ অপারেটরগুলো পাওয়া যায়:

- পাটিগণিত: `+`, `-`, `*`, `/`, `%`
- তুলনা: `==`, `!=`, `<`, `<=`, `>=`, `>`
- স্ট্যান্ডার্ড [গণিতের ফাংশন][man-math]

  যে ফাংশন একটি ইনপুট নেয়, তার ক্ষেত্রে মানটি পাইপ করে ফাংশনে পাঠান

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  আর যে ফাংশন দুটি ইনপুট নেয়, সেগুলো ইনপুট উপেক্ষা করে এবং ইনপুটগুলোকে প্যারামিটার
  হিসেবে আশা করে (মনে রাখবেন, প্যারামিটারগুলো সেমিকোলন দিয়ে আলাদা করা হয়)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  ফাংশনের আর্গুমেন্টের বিভাজক হলো সেমিকোলন, কমা নয়।

## `jq`-এর অন্যান্য এক্সপ্রেশন

অনুশীলনীটি সমাধান করতে আপনার শর্তমূলক এক্সপ্রেশন সম্পর্কে জানা দরকার।

### শর্তমূলক এক্সপ্রেশন

**শর্তমূলক এক্সপ্রেশনের** জন্য `jq` একটি [`if-then-else` এক্সপ্রেশন][if-then-else] ব্যবহার করে।
এটি একটি _এক্সপ্রেশন_ হওয়ায় পাইপলাইনে বসানো হয়।

এর সিনট্যাক্স হলো: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

`else` অংশটি ঐচ্ছিক।

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

অতিরিক্ত শর্তের জন্য `elif` ব্যবহার করা হয়

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
