# ইনস্টলেশন

## tclsh ইনস্টল করা

আপনার শুধু একটি সরঞ্জাম দরকার, TCL ইন্টারপ্রেটার `tclsh`।

Windows-এর জন্য Tcl পাওয়ার সবচেয়ে ভালো জায়গা হলো [Magicsplat-এর Tcl ইনস্টলার][magicsplat]।

MacOS আর Unix-জাতীয় অপারেটিং সিস্টেমে `tclsh` আগে থেকেই ইনস্টল করা থাকে।
সাধারণত ইনস্টল করা ভার্সনটি হয় 8.6.*something*।
বর্তমান স্টেবল 9.1 ভার্সনটি ইনস্টল করতে:
 - MacOS-এ [Homebrew][brew] ব্যবহার করুন।
 - Linux-এর জন্য আপনার প্যাকেজ ম্যানেজার দেখে নিন।
 - অথবা [সোর্স ডাউনলোড করে][download] সেটি [বিল্ড করুন][build]।

Exercism-এর ওয়েব ইন্টারফেস ব্যবহার করে অনুশীলনী সমাধান করতে গেলে test runner (ফেব্রুয়ারি ২০২৩ অনুযায়ী) Tcl ভার্সন 8.7a4 ব্যবহার করে।

## ইন্টারঅ্যাকটিভ tclsh শেল ব্যবহার করা

কোড লেখার সময় কমান্ড পরীক্ষা করে দেখার জন্য ইন্টারঅ্যাকটিভ [`tclsh`][tclsh] সেশন চালু করা খুব সাধারণ ব্যাপার।
তবে tclsh-এ থাকে কেবল খুব সাধারণ একটি REPL ইন্টারপ্রেটার, যেখানে কমান্ড লাইন সম্পাদনা বা কমান্ড ইতিহাসের সুবিধা নেই।
আরও ভালো অভিজ্ঞতার জন্য `rlwrap` নামে একটি প্রোগ্রাম আছে, যা readline-এর সুবিধা যোগ করে:

```bash
rlwrap tclsh
```

rlwrap ইনস্টল করতে:
 - MacOS-এ [Homebrew][brew] ব্যবহার করুন।
 - Linux-এর ক্ষেত্রে আপনার প্যাকেজ ম্যানেজার দেখে নিন।
 - অথবা [সোর্স ডাউনলোড করে][rlwrap-download] সেটি [বিল্ড করুন][rlwrap-build]।

এটি এতটাই সুবিধাজনক যে আপনি সব সময়ই এটি ব্যবহার করতে চাইবেন: নিচের লাইনটি আপনার ~/.bashrc ফাইলে যোগ করুন

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## কোন ভার্সন ব্যবহার করবেন?

বর্তমান স্টেবল ভার্সন 9.1।
উপরে বলা হয়েছে, 8.6 ভার্সনটি এখনও ব্যাপকভাবে ব্যবহৃত হয়।

আপনার ইনস্টল করা `tclsh` কোন ভার্সন, তা নিচের কমান্ডটি চালিয়ে পরীক্ষা করতে পারেন:

```bash
echo 'puts [info patchlevel]' | tclsh
```
