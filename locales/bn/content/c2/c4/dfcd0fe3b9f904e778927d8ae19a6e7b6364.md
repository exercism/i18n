# পরিচিতি

Kotlin-এ একটি [`string`][ref-string] হলো ইউনিকোড ক্যারেক্টারের একটি ইমিউটেবল সিকোয়েন্স।

[`Immutable`][wiki-immutable] মানে হলো, একটি স্ট্রিং-এর উপর যেকোনো অপারেশনকে অবশ্যই একটি নতুন স্ট্রিং রিটার্ন করতে হবে: মূল স্ট্রিংটি কখনোই বদলাতে পারে না।

[`Unicode`][wiki-unicode] মানে হলো, বিশ্বের বেশিরভাগ লিখন পদ্ধতি প্রকাশ করা যায়, তবে (C-এর মতো পুরোনো ভাষার বিপরীতে) ক্যারেক্টার আর বাইটের মধ্যে ১:১ সম্পর্ক নেই।

একটি স্ট্রিং সাধারণত ডাবল কোটেশন `" "` দিয়ে ঘেরা থাকে।

কিছু ক্যারেক্টার এস্কেপ করতে হয়: `\'`, `\\`, সাথে সাধারণ নন-প্রিন্টিং ক্যারেক্টার যেমন `\t` (ট্যাব) আর `\n` (নিউলাইন)।

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

মাল্টি-লাইন স্ট্রিং ৩টি ডাবল কোটেশন দিয়ে ঘেরা হয়, এবং এতে যা খুশি টেক্সট থাকতে পারে (এস্কেপ করার দরকার নেই)।

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

লাইনগুলো থেকে সাধারণ ইন্ডেন্টিং সরাতে [trimIndent][trimIndent-doc] ব্যবহার করুন।
স্ট্রিং ফরম্যাট করার জন্য এটি কাজে লাগে:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

বিকল্পভাবে, [trimMargin][trimMargin-doc] দিয়ে আপনি একটি ডেলিমিটার নির্দিষ্ট করতে পারেন।
এরপর `String`-এর প্রতিটি লাইন ডেলিমিটারের পরে শুরু হয়।
ডেলিমিটারের ডিফল্ট মান `|`, তবে আপনি প্যারামিটার হিসেবে ভিন্ন একটি ডেলিমিটারও নির্দিষ্ট করতে পারেন।
উদাহরণস্বরূপ:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

স্ট্রিংগুলো `+` দিয়ে জোড়া লাগানো যায়, তবে এটি ছোট ও সরল ক্ষেত্রে সীমাবদ্ধ রাখাই ভালো।
অন্য, প্রায়শই আরও ভালো, উপায়ও আছে।

## স্ট্রিং টেমপ্লেট

এটি বোঝায় সেটিকেই, যাকে কিছু অন্য ভাষায় "ইন্টারপোলেশন" বলে।

যদি একটি স্ট্রিং-এ একটি ডলার চিহ্ন `$` থাকে, যার পরে একটি আইডেন্টিফায়ার থাকে, অথবা একটি এক্সপ্রেশনকে ঘিরে ব্রেস (`{expression}`) থাকে, তবে সেগুলো যথাক্রমে মানটি বা এক্সপ্রেশনের ফলাফল দিয়ে প্রতিস্থাপিত হয়।

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

ব্রেস `{ }` তখন দরকার হয়, যখন অন্যথায় পার্সিং অস্পষ্ট হয়ে যেত।

সাধারণভাবে, `+` ব্যবহার করার চেয়ে স্ট্রিং টেমপ্লেট ব্যবহার করা স্ট্রিং জোড়া লাগানোর আরও দক্ষ ও ভাষাসুলভ উপায়।

## স্ট্রিং ফাংশন

Kotlin স্ট্রিং নিয়ে কাজ করার জন্য _অনেক_ [`functions`][ref-string-functions] দেয়।

এগুলো বেশিরভাগই `String` ক্লাসের মেম্বার নয়, বরং [`extensions functions`][ref-extensions], যদিও আমরা কীভাবে এগুলো ব্যবহার করি তাতে এর তেমন প্রভাব পড়ে না।

~~~~exercism/note
Kotlin-এর বরং জটিল [ডকুমেন্টেশন][ref-string-functions] পেজগুলো ডিফল্ট ভিউতে এক্সটেনশন ফাংশনগুলো লুকিয়ে রাখে।
এই অংশটি খুলতে `Members & Extensions`-এ ক্লিক করতে ভুলবেন না।

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

নিচের উদাহরণগুলোতে যা পাওয়া যায় তার মাত্র একটি ছোট্ট নির্বাচন দেখানো হয়েছে:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
