# নির্দেশাবলি

`accumulate` অপারেশনটি ইমপ্লিমেন্ট করুন। এটি একটি কালেকশন এবং কালেকশনের প্রতিটি এলিমেন্টে করার জন্য একটি অপারেশন নেয়, আর ইনপুট কালেকশনের প্রতিটি এলিমেন্টে ওই অপারেশন প্রয়োগের ফলাফল নিয়ে একটি নতুন কালেকশন রিটার্ন করে।

ধরা যাক, সংখ্যাগুলোর কালেকশনটি হলো:

- 1, 2, 3, 4, 5

আর অপারেশনটি হলো:

- একটি সংখ্যার বর্গ করা (`x => x * x`)

আপনার কোড বর্গগুলোর কালেকশন তৈরি করতে সক্ষম হওয়া উচিত:

- 1, 4, 9, 16, 25

প্রত্যাশিত ফাংশন সিগনেচার দেখতে টেস্ট স্যুটটি দেখুন।

## বিধিনিষেধ

আপনার স্ট্যান্ডার্ড লাইব্রেরির দেওয়া collect/map/fmap/whatchamacallit ফাংশনালিটির ওপর হাত দূরে রাখুন!
এর বদলে অন্য সাধারণ টুল ব্যবহার করে এটি নিজেই সমাধান করুন।
