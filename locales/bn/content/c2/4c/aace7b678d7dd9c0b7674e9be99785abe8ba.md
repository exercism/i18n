# পরিচিতি

Elixir একটি ডাইনামিকভাবে টাইপড ভাষা, যার মানে এটি কম্পাইল-টাইম টাইপ চেক দেয় না। তবুও, টাইপ স্পেসিফিকেশন ডকুমেন্টেশনের একটি রূপ হিসেবে ব্যবহার করা যায়।

ফাংশন ডেফিনিশনের ঠিক আগে `@spec` মডিউল অ্যাট্রিবিউট ব্যবহার করে একটি ফাংশনে টাইপ স্পেসিফিকেশন যোগ করা যায়। `@spec`-এর পরে থাকে ফাংশনের নাম এবং বন্ধনীর ভেতরে কমা দিয়ে আলাদা করা তার সব আর্গুমেন্টের টাইপের একটি তালিকা। রিটার্ন ভ্যালুর টাইপকে ফাংশনের আর্গুমেন্ট থেকে আলাদা করা হয় একটি ডাবল কোলন `::` দিয়ে।

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## টাইপ

সবচেয়ে বেশি ব্যবহৃত টাইপগুলোর মধ্যে রয়েছে:

- বুলিয়ান: `boolean()`
- স্ট্রিং: `String.t()`
- সংখ্যা: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- অ্যারে: `list()`
- যেকোনো টাইপের মান: `any()`

কিছু টাইপ প্যারামিটারাইজডও হতে পারে, যেমন `list(integer)` হলো ইন্টিজারগুলোর একটি অ্যারে।

লিটারাল মানও টাইপ হিসেবে ব্যবহার করা যায়।

পাইপ `|` ব্যবহার করে টাইপের একটি ইউনিয়ন লেখা যায়। উদাহরণস্বরূপ, `integer() | :error` মানে হয় একটি ইন্টিজার, নয়তো অ্যাটম লিটারাল `:error`।

সব টাইপের পূর্ণ তালিকা পাওয়া যাবে [অফিসিয়াল ডকুমেন্টেশনের "Typespecs" অংশে][types]।

## আর্গুমেন্টের নাম দেওয়া

টাইপস্পেকের আর্গুমেন্টগুলোর নামও দেওয়া যায়, যা একই টাইপের একাধিক আর্গুমেন্ট আলাদা করতে কাজে লাগে। আর্গুমেন্টের নাম, তার পরে একটি ডাবল কোলন, বসে আর্গুমেন্টের টাইপের আগে।

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## কাস্টম টাইপ

টাইপস্পেক শুধু বিল্ট-ইন টাইপেই সীমাবদ্ধ নয়। `@type` মডিউল অ্যাট্রিবিউট ব্যবহার করে কাস্টম টাইপ ডিফাইন করা যায়। একটি কাস্টম টাইপ ডেফিনিশন শুরু হয় টাইপের নাম দিয়ে, তার পরে একটি ডাবল কোলন, আর তারপর টাইপটি নিজে।

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

একটি কাস্টম টাইপ যে মডিউলে ডিফাইন করা হয়েছে সেই মডিউল থেকেই ব্যবহার করা যায়, আবার অন্য মডিউল থেকেও।

[types]: https://hexdocs.pm/elixir/typespecs.html#types-and-their-syntax
