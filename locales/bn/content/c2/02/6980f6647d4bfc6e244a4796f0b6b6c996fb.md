# ইনস্টলেশন

আমরা Standard ML-এর ইমপ্লিমেন্টেশন হিসেবে *PolyML* ব্যবহার করব।

আপনি যদি Windows ব্যবহার করেন, তাহলে [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases) থেকে একটি ইনস্টলার ডাউনলোড করতে পারেন।
Linux/OS X/Free BSD-এর সাধারণ নির্দেশাবলি পাওয়া যাবে [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme) ঠিকানায়।

আপনি যদি সোর্স থেকে ইনস্টল করতে চান, প্রক্রিয়াটি বেশ সহজ:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

আপনি যদি এটি নিজের পছন্দের কোনো জায়গায় ইনস্টল করতে চান, যেমন `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

শেষ ধাপ:

```sh
$ make compiler
$ make install
```

সঠিকভাবে ইনস্টল হয়েছে কি না, তা যাচাই করে দেখুন:

```sh
$ poly
```

ইন্টারপ্রেটার দেখতে পেলে বুঝবেন, আপনি প্রস্তুত!
না হলে, সম্ভবত আপনাকে আপনার `$PATH`-এ `$HOME/.local/bin` (অথবা `<you prefix>/bin`) যোগ করতে হবে।
