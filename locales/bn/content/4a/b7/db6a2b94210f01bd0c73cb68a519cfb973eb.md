# ভূমিকা

## ডিসক্রিমিনেটেড ইউনিয়ন

ডিসক্রিমিনেটেড ইউনিয়ন টাইপ নির্দিষ্ট সংখ্যক নামযুক্ত কেসের প্রতিনিধিত্ব করে। ডিসক্রিমিনেটেড ইউনিয়নের প্রতিটি মান ঠিক একটি নামযুক্ত কেসের সাথে মিলে যায়।

ডিসক্রিমিনেটেড ইউনিয়ন `type` কিওয়ার্ড দিয়ে ডিফাইন করা হয়, যেখানে কেসগুলো পাইপ (`|`) ক্যারেক্টার দিয়ে আলাদা করা থাকে:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

ডিসক্রিমিনেটেড ইউনিয়নের প্রতিটি কেসের সাথে ঐচ্ছিকভাবে ডেটা যুক্ত থাকতে পারে, আর ভিন্ন ভিন্ন কেসে ভিন্ন ভিন্ন ধরনের ডেটা থাকতে পারে। কোনো কেসের সাথেই যদি ডেটা যুক্ত না থাকে, তাহলে ডিসক্রিমিনেটেড ইউনিয়নটি অনেকটা সেরকম হয়, যাকে অন্য ভাষাগুলো সাধারণত _এনুমারেশন_ (বা _এনাম_) নামে ডাকে।

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

নির্দিষ্ট কোনো কেসের জন্য মান তৈরি করা যায় তার নাম উল্লেখ করে (যেমন, `Success`)। যেহেতু কেসের নামগুলো শুধুই কনস্ট্রাক্টর ফাংশন, তাই সংশ্লিষ্ট ডেটা সাধারণ ফাংশন আর্গুমেন্ট হিসেবে পাঠানো যায়। যদি অন্য কোনো ডিসক্রিমিনেটেড ইউনিয়নে একই নামের একটি কেস ডিফাইন করা থাকে, তাহলে আপনাকে তার পুরো নাম ব্যবহার করতে হবে (যেমন `Result.Success`)।

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

ডিসক্রিমিনেটেড ইউনিয়নের _স্ট্রাকচারাল ইকুয়ালিটি_ থাকে, যার মানে হলো একই কেসের এবং একই (ঐচ্ছিক) ডেটাসহ দুটি মান সমতুল্য।

ডিসক্রিমিনেটেড ইউনিয়নের সাথে কাজ করতে `if/elif/else` এক্সপ্রেশন ব্যবহার করা গেলেও, এদের সাথে কাজ করার প্রস্তাবিত উপায় হলো _আইডেন্টিফায়ার প্যাটার্ন_ ব্যবহার করে প্যাটার্ন ম্যাচিং:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
