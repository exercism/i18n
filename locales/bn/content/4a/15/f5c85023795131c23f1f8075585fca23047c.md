# পরিচিতি

অনেক অপারেটরকে [কম্পাউন্ড অ্যাসাইনমেন্ট][compound-assignment] হিসেবেও ব্যবহার করা যায়, যেগুলো এক ধরনের সংক্ষিপ্ত রূপ, যেখানে `x = op y`-এর বদলে `x op= y` লেখা যায়:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
