# পরিচিতি

Go-তে একটি [`Time`][time] হলো একটি টাইপ, যা সময়ের একটি মুহূর্ত বর্ণনা করে।
এর মেথডগুলোর মাধ্যমে তারিখ ও সময়ের তথ্য অ্যাক্সেস করা, তুলনা করা এবং পরিবর্তন করা যায়, তবে `time` প্যাকেজের উপর সরাসরি কল করা কিছু ফাংশনও আছে।
বর্তমান তারিখ ও সময় [`time.Now`][now] ফাংশনের মাধ্যমে পাওয়া যায়।

[`time.Parse`][parse] ফাংশন স্ট্রিংকে `Time` টাইপের মানে পার্স করে।
পার্সিংয়ের জন্য আপনি যে লেআউট আশা করেন তা নির্ধারণ করার একটি বিশেষ পদ্ধতি Go-তে আছে।
এই বিশেষ টাইমস্ট্যাম্পের মানগুলো ব্যবহার করে লেআউটের একটি উদাহরণ লিখতে হয়:
`Mon Jan 2 15:04:05 -0700 MST 2006`।

উদাহরণস্বরূপ:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

[`Time.Format()`][format] মেথড সময়ের একটি স্ট্রিং উপস্থাপনা রিটার্ন করে।
`Parse` ফাংশনের ক্ষেত্রেই যেমন, লক্ষ্য লেআউটও আবার এই বিশেষ টাইমস্ট্যাম্পের মানগুলো ব্যবহার করা একটি উদাহরণের মাধ্যমে নির্ধারণ করা হয়।

উদাহরণস্বরূপ:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## লেআউটের অপশন

নিজস্ব লেআউটের জন্য এই অপশনগুলোর সমন্বয় ব্যবহার করুন।
Go-তে পূর্বনির্ধারিত তারিখ ও টাইমস্ট্যাম্পের [ফরম্যাট কনস্ট্যান্ট][const]-ও পাওয়া যায়।

| সময়        | অপশন                                        |
| ----------- | ---------------------------------------------- |
| বছর        | 2006 ; 06                                      |
| মাস       | Jan ; January ; 01 ; 1                         |
| দিন         | 02 ; 2 ; \_2 (সামনে শূন্যের জন্য)                 |
| সপ্তাহের বার     | Mon ; Monday                                   |
| ঘণ্টা        | 15 (২৪-ঘণ্টার ফরম্যাট) ; 3 ; 03 (AM বা PM) |
| মিনিট      | 04 ; 4                                         |
| সেকেন্ড      | 05 ; 5                                         |
| AM/PM চিহ্ন  | PM                                             |
| বছরের দিন | 002 ; \_\_2                                    |

`time.Time` টাইপে নির্দিষ্ট একটি সময় অ্যাক্সেস করার জন্য নানা রকম মেথড আছে। যেমন Hour: [`Time.Hour()`][hour], Month: [`Time.Month()`][month]।
এটি কীভাবে কাজ করে সে সম্পর্কে আরও জানতে [অফিসিয়াল ডকুমেন্টেশন][time] দেখুন।

[`time`][time]-এ আরও একটি টাইপ আছে, [`Duration`][duration], যা অতিবাহিত সময় বোঝায়; এর সাথে লোকেশন/টাইম জোন, টাইমার এবং আরও কিছু সম্পর্কিত সুবিধা রয়েছে, যেগুলো অন্য একটি কনসেপ্টে আলোচনা করা হবে।
