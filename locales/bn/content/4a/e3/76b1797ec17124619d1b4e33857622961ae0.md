# ভূমিকা

ফাংশনগুলো ডিফল্টভাবে এক্সটার্নাল লিংকেজ থাকে এবং প্রকল্পের অন্য যেকোনো ফাইল থেকে কল করা যায়।
লিংকেজ সম্পর্কে আরও জানতে [লিংকেজ ধারণা](../linkage/introduction.md#Introduction) দেখুন।
একটি `static` ফাংশন শুধুমাত্র যেই সোর্স ফাইলে ডিফাইন করা হয়েছে সেখানেই কল করা যায়।

উদাহরণস্বরূপ:

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
