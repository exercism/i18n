# ভূমিকা

Kotlin-এ ফাংশন প্রথম শ্রেণির নাগরিক।
এর মানে হলো, এগুলো ভ্যারিয়েবলে রাখা যায়, আর্গুমেন্ট হিসেবে পাঠানো যায়, এমনকি অন্য ফাংশন থেকে রিটার্নও করা যায়।
উদাহরণস্বরূপ, `addOne` ভ্যারিয়েবলে একটি ফাংশন অ্যাসাইন করা:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

একটি ফাংশন আবার অন্য একটি ফাংশনও রিটার্ন করতে পারে:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

একবার অ্যাসাইন হয়ে গেলে, ভ্যারিয়েবলটির মাধ্যমে ফাংশনটিকে ঠিক অন্য আরেকটি ফাংশনের মতোই কল করা যায়:
```kotlin
addOne(3)
// => 4
```

## ফাংশন টাইপ ডিক্লেয়ার করা

`(parameter types) -> return type` সিনট্যাক্স ব্যবহার করে একটি ভ্যারিয়েবল বা প্যারামিটারের টাইপ ডিক্লেয়ার করা যায়।
উদাহরণস্বরূপ, একটি ভ্যারিয়েবল ডিক্লেয়ার করা:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

আর একটি ফাংশন প্যারামিটারের ক্ষেত্রে:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## ল্যাম্বডা এক্সপ্রেশন

ল্যাম্বডা এক্সপ্রেশন হলো ফাংশন ডিফাইন করার একটি ছোট উপায়।
এগুলো `{ parameters -> body }` আকারে লেখা হয়।
এক্সপ্রেশনটি বডির শেষ স্টেটমেন্টের শেষ মানটি রিটার্ন করে।
উদাহরণস্বরূপ:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

যথেষ্ট তথ্য থাকলে Kotlin টাইপ অনুমান করতে পারে।
উদাহরণস্বরূপ, উপরের উদাহরণগুলো এভাবেও লেখা যায়:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## একক প্যারামিটারের ল্যাম্বডায় `it`

যখন এক্সপ্রেশনে মাত্র একটি প্যারামিটার থাকে, তখন প্যারামিটারটি বাদ দেওয়া যায়।
তখন Kotlin বডিতে `it` নামে একটি প্যারামিটার ব্যবহারের সুযোগ করে দেয়।
উদাহরণস্বরূপ:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## ট্রেইলিং ল্যাম্বডা পাস করা

কোনো ফাংশনের শেষ আর্গুমেন্ট যখন একটি ল্যাম্বডা, তখন ল্যাম্বডা এক্সপ্রেশনটি সরাসরি বন্ধনীর _পরে_ লেখা হয়।
উদাহরণস্বরূপ:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
