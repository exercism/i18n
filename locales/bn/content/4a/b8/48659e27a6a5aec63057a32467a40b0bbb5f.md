# নির্দেশাবলির সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                              |
| -------- | --------- | ------- | ---------------------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং             |
| `$v0`    | আউটপুট    | বুলিয়ান | বৈধ isbn (`0` = `false`, `1` = `true`) |
| `$t0-9`  | সাময়িক | যেকোনো     | সাময়িক স্টোরেজের জন্য ব্যবহৃত               |
