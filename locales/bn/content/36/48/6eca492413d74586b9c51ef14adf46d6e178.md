# সম্পর্কে

`Maybe` টাইপটি Elm ভাষায় ঐচ্ছিক মানের সমাধান।
তাই এটি Elm-এর অনেক কোর ফাংশনের টাইপ সিগনেচারে উপস্থিত, এবং এটি বোঝা অত্যন্ত গুরুত্বপূর্ণ।

## সংজ্ঞা ও টাইপ ভ্যারিয়েবল

`Maybe` টাইপটি এভাবে সংজ্ঞায়িত করা হয়:

```elm
type Maybe a = Nothing | Just a
```

Elm-এর পরিভাষায় এটিকে "কাস্টম টাইপ" সংজ্ঞা বলা হয়।
কাস্টম টাইপগুলো এই ট্র্যাকের আরেকটি কনসেপ্টে বিস্তারিতভাবে পরিচয় করানো হয়েছে, কিন্তু শুধু `Maybe` বোঝার জন্য আমাদের সেটির দরকার নেই।
`Maybe a` এবং `Just a`-এর `a` একটি টাইপ ভ্যারিয়েবল বোঝায়, অর্থাৎ এটি যেকোনো টাইপ হতে পারে, যেমন `Int`, `Bool` বা `String`.
তাই একটি `Maybe String` এমন একটি ভ্যারিয়েবল যা ঐচ্ছিকভাবে একটি `String` ধারণ করে, আর একটি `Maybe Int` ঐচ্ছিকভাবে একটি `Int` ধারণ করবে।

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

`Maybe`-এর টাইপ সংজ্ঞায় উল্লম্ব বার `|` মানে "অথবা"।
এটি বোঝায় যে এই টাইপের একটি মান হয় `Nothing` হবে, অথবা টাইপ `a`-এর কোনো কিছু `Just` হবে।
তাহলে ধরুন, ওই ব্যক্তি নাম ও বয়স পূরণ করেননি। সেক্ষেত্রে আমরা নিচেরটি পাব।

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## `Maybe` মানের বিষয়বস্তু পড়া

`Maybe` মানের বিষয়বস্তু পড়া হয় "প্যাটার্ন ম্যাচিং"-এর মাধ্যমে।
প্যাটার্ন ম্যাচিংও আরেকটি কনসেপ্টে আরও বিস্তারিতভাবে পরিচয় করানো হয়েছে, তাই আমরা শুধু এদিকে মনোযোগ দিই যে একটি `Maybe`-এর প্যাটার্ন ম্যাচিং কীভাবে কাজ করে।

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

প্রতিবার আপনি যখন একটি `Maybe` মান ব্যবহার করবেন, Elm কম্পাইলার যাচাই করবে যে আপনার কোড সব সম্ভাবনা হ্যান্ডেল করে, তাই আপনি কখনো এমনভাবে `Maybe`-এর প্যাটার্ন ম্যাচ করতে পারবেন না যে শুধু `Just someValue` থাকার ক্ষেত্রটিই হ্যান্ডেল করবেন।
এটা প্রথমে বিরক্তিকর লাগতে পারে, কিন্তু এটি Elm ভাষার সবচেয়ে বড় শক্তিগুলোর একটি।
এটি শত শত Bug প্রতিরোধ করবে এবং কম্পাইলার-নির্দেশিত রিফ্যাক্টরিংকে নির্ভীক ও ফলপ্রসূ অভিজ্ঞতা করে তুলবে।

## `Maybe` নিয়ে কাজ করার আরও ফাংশন

`Maybe` মডিউলে `Maybe` টাইপ নিয়ে কাজ করার জন্য বেশ কিছু দরকারি ফাংশনও আছে।

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
