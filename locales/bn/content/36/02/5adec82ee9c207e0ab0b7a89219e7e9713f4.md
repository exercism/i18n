# নির্দেশনা সংযোজন

## আউটপুট ফরম্যাট

বিভাজক হিসেবে কমা ও একটি স্পেস ব্যবহার করে ক্রিয়াগুলোর ক্রমটি একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে আউটপুট করুন।

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | ১ থেকে ৩১-এর মধ্যে একটি সংখ্যা |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং  |
| `$t0-9`  | টেম্পোরারি   | যেকোনো  | সাময়িক স্টোরেজের জন্য ব্যবহৃত হয় |
