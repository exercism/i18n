# পরিচিতি

যদি প্যারামিটারগুলোর টাইপ অনুমান করা যায়, তাহলে Swift ক্লোজার ডিফাইন করার সময় প্যারামিটারের নাম আর `in` কিওয়ার্ড দুটোই বাদ দেওয়ার সুযোগ দেয়। এর বদলে বিশেষ একটি শর্টহ্যান্ড সিনট্যাক্স ব্যবহার করে প্যারামিটারগুলোকে বোঝানো যায়, যেখানে `$0` প্রথম প্যারামিটারকে বোঝায়, `$1` দ্বিতীয়টিকে, আর এভাবে বাকিগুলোকেও।

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
