# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে চারটি কাজ আছে, যেগুলোর সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. প্রত্যাশিত ওভেনের সময় মিনিটে ডিফাইন করুন

লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত, তা দিয়ে `OvenTime` কনস্ট্যান্টটি ডিফাইন করুন।
রান্নার বই অনুসারে, প্রত্যাশিত ওভেনের সময় মিনিটে ৪০:

```go
OvenTime
// => 40
```

    // TODO

## 4. ব্যয় হওয়া কাজের সময় মিনিটে হিসাব করুন

`ElapsedTime` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসাগনায় আপনি যতগুলো লেয়ার যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ওভেনে আছে তার সংখ্যা।
