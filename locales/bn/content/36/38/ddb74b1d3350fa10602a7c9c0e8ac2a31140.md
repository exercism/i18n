# নির্দেশাবলি

একটি ট্রাইনারি সংখ্যা (যা স্ট্রিং হিসেবে প্রকাশ করা থাকে, যেমন '102012')-কে মৌলিক নীতির ভিত্তিতে তার দশমিক সমতুল্য মানে রূপান্তর করুন।

প্রোগ্রামটি অবৈধ ট্রাইনারি বোঝানো স্ট্রিংগুলোকে 0 মান হিসেবে গণ্য করবে।

ট্রাইনারি সংখ্যায় তিনটি প্রতীক থাকে: 0, 1 এবং 2।

ট্রাইনারি সংখ্যায় শেষ ঘরটি 1-এর ঘর। শেষ থেকে দ্বিতীয়টি 3-এর ঘর, শেষ থেকে তৃতীয়টি 9-এর ঘর, ইত্যাদি।

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

আপনার ভাষার স্ট্যান্ডার্ড লাইব্রেরিতে যদি রূপান্তরটি করার কোনো মেথড থাকে, তাহলে ধরে নিন সেটি নেই, এবং নিজে এটি ইমপ্লিমেন্ট করুন।
