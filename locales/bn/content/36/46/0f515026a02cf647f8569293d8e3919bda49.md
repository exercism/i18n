# সম্পর্কে

ABAP-এ বিভিন্ন সংখ্যাসূচক টাইপ আছে। ছোট প্রাথমিক অনুশীলনীর জন্য সবচেয়ে কমন হলো `i` (ইন্টিজার মানের জন্য) এবং `p` (প্যাকড দশমিক মানের জন্য)।

`i` ব্যবহার করুন যখন মানটি অবশ্যই একটি পূর্ণ সংখ্যা হতে হবে, যেমন দিনের সংখ্যা। দশমিক টাইপ ব্যবহার করুন যখন মানটিতে ভগ্নাংশের অঙ্ক থাকতে পারে, যেমন প্রতি ঘণ্টার হার।

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

ব্যবসায়িক অ্যাপ্লিকেশনে প্রায়শই প্যাকড সংখ্যা ব্যবহার করা হয় যখন নির্দিষ্ট সংখ্যক দশমিক স্থান প্রয়োজন হয়। ABAP-এ দশমিক ফ্লোটিং পয়েন্ট সংখ্যা (`decfloat16` এবং `decfloat34`) এবং বাইনারি ফ্লোটিং পয়েন্ট সংখ্যা (`f`) ও আছে। বাইনারি ফ্লোটিং পয়েন্ট সংখ্যা বৈজ্ঞানিক গণনার জন্য উপযোগী হতে পারে, কিন্তু অর্থ-সংক্রান্ত উদাহরণের জন্য এগুলো ভালো ডিফল্ট নয়, কারণ অনেক দশমিক ভগ্নাংশ সঠিকভাবে উপস্থাপন করা যায় না।
