# সম্পর্কে

## পার্শিয়াল অ্যাপ্লিকেশন

Elm-এর সব ফাংশনই [কারিড][currying], অর্থাৎ আপনি যদি সব আর্গুমেন্ট পাস না করে কোনো ফাংশন কল করেন, তাহলে সেটি একটি নতুন ফাংশন রিটার্ন করে।

এভাবে কাজ করার ফলাফলকে বলা হয় [পার্শিয়াল অ্যাপ্লিকেশন][partial-application] (আপনি ফাংশনে সব আর্গুমেন্ট পাস করছেন না, বরং এর কয়েকটি আংশিকভাবে অ্যাপ্লাই করছেন)।

```elm
add: Int -> Int -> Int
add a b = a + b

add2: Int -> Int
add2 = add 2

eight: Int
eight = add2 6
--> 8
```

পার্শিয়াল অ্যাপ্লিকেশন সবসময় ক্রমানুসারে আর্গুমেন্টগুলো অ্যাপ্লাই করে।

```elm
contains: String -> String -> Bool
contains first second =
--> This function is in the standard library, and returns True if the second string contains the first one

containsCedd: String -> Bool
containsCedd = contains "Cedd"
--> (partial application always applies the arguments in order, so "Cedd" becomes the first argument to contains
--> This is a function that takes a string, and returns True if that string contains Cedd)

ceddBurgeContainsCedd: Bool
ceddBurgeContainsCedd = containsCedd "Cedd Burge"
--> True
--> ("Cedd Burge" ends up being the second argument to contains, and it does include "Cedd", the first argument)
```

## পাইপ অপারেটর (`|>`)

`x |> f` লেখা ঠিক `f x` লেখার মতোই। একটি নির্দিষ্ট উদাহরণ হলো `"5" |> String.toInt`, যা `String.toInt "5"`-এর সমান।

প্রথমে এটি খুব একটা কাজের মনে না হলেও, এটিকে [পাইপ অপারেটর][pipe-operator] বলা হয়, কারণ এটি দিয়ে আপনি “পাইপলাইন করা” কোড লিখতে পারেন।

উদাহরণস্বরূপ, ধরা যাক ব্যবহারকারীর ইনপুটকে ইন্টিজারে রূপান্তর করার একটি sanitize ফাংশন আমাদের আছে:

```elm
sanitize : String -> Maybe Int
sanitize input =
    String.toInt (String.trim input)
```

আমরা এটিকে এভাবে আবার লিখতে পারি:

```elm
sanitize : String -> Maybe Int
sanitize input =
    input
    |> String.trim
    |> String.toInt
```

এটি বন্ধনী ব্যবহার করা এড়ায় এবং ফাংশনগুলো যে ক্রমে অ্যাপ্লাই করা হয় সেই ক্রমেই দেখায় (প্রথমে `String.trim`, তারপর `String.toInt`), যা পড়তে সহজ করে।

এছাড়া একটি [রিভার্স পাইপ অপারেটর `(<|)`][reverse-pipe-operator]ও আছে।
`x <| f` লেখা ঠিক `f x` লেখার মতোই।
প্রথম দেখায় এটিও খুব একটা কাজের মনে হয় না, এবং পাইপ অপারেটরের মতো এতটা ব্যবহারও হয় না, তবে কিছু পরিস্থিতিতে এটি বন্ধনী এড়াতে সাহায্য করে।

## ফাংশন কম্পোজিশন / পয়েন্ট ফ্রি স্টাইল

[`(>>)`][forward-composition] অপারেটরের টাইপ `(a -> b) -> (b -> c) -> (a -> c)`, এবং এটি `a -> b ` ও `b -> c` টাইপের দুটি সামঞ্জস্যপূর্ণ ফাংশন কম্পোজ করে `a -> c` টাইপের একটি ফাংশন তৈরি করে।
এটি করে প্রথম ফাংশনের আউটপুট (টাইপ `b`) নিয়ে সেটিকে দ্বিতীয় ফাংশনের প্রথম আর্গুমেন্ট হিসেবে ব্যবহার করে (যার টাইপ অবশ্যই একই `b` হতে হবে)।
তৈরি হওয়া ফাংশনটি প্রথম ফাংশনের মতোই একই ইনপুট (টাইপ `a`) নেয়, এবং দ্বিতীয় ফাংশন যা `c` রিটার্ন করে সেটিই রিটার্ন করে।

একটি নির্দিষ্ট উদাহরণ হলো `String.trim >> String.toInt`.
`String.trim` তার একমাত্র প্যারামিটার হিসেবে একটি স্ট্রিং নেয়, তাই তৈরি হওয়া ফাংশনও সেটিই নেয়।
`String.toInt` একটি `Maybe Int` রিটার্ন করে, তাই তৈরি হওয়া ফাংশনও সেটিই রিটার্ন করে।
`String.trim` একটি `String` রিটার্ন করে, যাকে `String.toInt` প্যারামিটার হিসেবে গ্রহণ করে, তাই উদাহরণটি কম্পাইল হয়।

এখন আমরা আমাদের `sanitize` ফাংশনটি এভাবে আবার লিখতে পারি:

```elm
sanitize : String -> Maybe Int
sanitize =
    String.trim >> String.toInt
```

লক্ষ করুন, মূল উদাহরণে যে `input` প্যারামিটারটি দেখতে পাচ্ছেন সেটি আর আমরা ব্যবহার করছি না, যদিও কার্যকারিতা হুবহু একই।
নিজেদের প্যারামিটারের কোনো উল্লেখ না রেখে ফাংশন তৈরির এই পদ্ধতিকে বলা হয় "পয়েন্ট ফ্রি স্টাইল"।
এই স্টাইলের সুবিধা হলো কোড আরও সংক্ষিপ্ত হয়, আর অসুবিধা হলো এটি বোঝা কঠিন হতে পারে, বিশেষ করে নতুনদের জন্য।

মনে রাখা ভালো, Elm-এ সব ফাংশনই কারিড, তাই `String.length >> max` কম্পাইল হয় এবং নিচের ফলাফল দেয়:

- একটি ফাংশন (১), যার একটি স্ট্রিং প্যারামিটার আছে (`String.length`-এর ইনপুট)
- `max` হলো এমন একটি ফাংশন যার দুটি `Int` প্যারামিটার আছে, কিন্তু ফাংশন ১ এটিতে একটি মাত্র `Int` পাস করে (`String.length`-এর রিটার্ন), তাই `max` আংশিকভাবে অ্যাপ্লাই হয়।
- আংশিকভাবে অ্যাপ্লাই করা `max` ফাংশনের রিটার্ন ভ্যালু হলো আরেকটি ফাংশন (২), যা একটি `Int` নেয় এবং এই `Int` ও `String.length` থেকে আংশিকভাবে অ্যাপ্লাই করা `Int`-এর মধ্যে বড়টি রিটার্ন করে।
- ফলে ফাংশন ১ (`String -> Int`) ফাংশন ২ (`Int -> Int`) রিটার্ন করে
- তাই `((String.length >> max) "123") 2` রিটার্ন করে `3`, কারণ `"123"`-এর দৈর্ঘ্য ৩, যা `Int` আর্গুমেন্টের ২-এর চেয়ে বড়।

## ফাংশন ডিজাইন

Elm-এ সুন্দর কোড লেখা সহজ করতে, ফাংশনের শেষ প্যারামিটার হিসেবে মূল ডেটা স্ট্রাকচারটিকে রাখা উচিত।
স্ট্যান্ডার্ড লাইব্রেরির সব কমন ফাংশনই এটি করে, যেমন `List.map` (টাইপ সিগনেচার নিচে)।

```elm
map : (a -> b) -> List a -> List b
```

এখানে দেখা যায়, `map` ফাংশনের শেষ প্যারামিটারটি `List a`, আর এটি `List b` রিটার্ন করে, তাই মূল ডেটা স্ট্রাকচারটি (`List`) শেষ প্যারামিটার।

এটি নিচের মতো সুন্দর পাইপলাইন করা কোড লেখা সম্ভব করে।

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase names =
    names
    |> List.map String.trim
    |> List.map String.toUpper
```

পাইপলাইনের বিকল্প হিসেবে এটি ফাংশন কম্পোজিশন ও পয়েন্ট ফ্রি স্টাইল ব্যবহার করাও সুবিধাজনক করে তোলে।

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map String.trim
    >> List.map String.toUpper
```

ফাংশন কম্পোজিশন দিয়ে এই উদাহরণটি `List.map`-এর একটি মাত্র কলে নামিয়েও আনা যায়।

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map (String.trim >> String.toUpper)
```
