# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় বন্ধুদের সাথে "Wizard and Warriors" নামের একটি রোল-প্লেয়িং গেম খেলছেন। আপনি গেম মাস্টার, অর্থাৎ খেলোয়াড়দের জন্য গেমের জগৎটিকে জীবন্ত করে তোলার দায়িত্ব যাঁর। এর একটি গুরুত্বপূর্ণ দিক হলো খেলোয়াড়দের কাছে গেমটি বর্ণনা করা: কোনো চরিত্রের অবস্থা কী, তারা যে নগরে গিয়েছে সেটি দেখতে কেমন, ইত্যাদি।

আপনার পাঁচটি কাজ আছে, যেগুলোতে আপনাকে খেলোয়াড়দের কাছে গেমের বিভিন্ন অংশ বর্ণনা করতে হবে।

## 1. একটি চরিত্র বর্ণনা করুন

প্রতিটি চরিত্রের একটি ক্লাস, একটি লেভেল ও হিট পয়েন্টের সংখ্যা থাকে এবং সেটি এভাবে বর্ণিত হয়: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.

`GameMaster.describe` মেথডটি ইমপ্লিমেন্ট করুন, যা একমাত্র প্যারামিটার হিসেবে একটি `Character` নেয় এবং তার বর্ণনা রিটার্ন করে।

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. একটি গন্তব্য বর্ণনা করুন

প্রতিটি গন্তব্যের একটি নাম ও বাসিন্দার সংখ্যা থাকে এবং সেটি এভাবে বর্ণিত হয়: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.

`GameMaster.describe` মেথডটি ইমপ্লিমেন্ট করুন, যা একমাত্র প্যারামিটার হিসেবে একটি `Destination` নেয় এবং তার বর্ণনা রিটার্ন করে।

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. ভ্রমণের উপায় বর্ণনা করুন

চরিত্ররা দুইটি উপায়ের একটি ব্যবহার করে কোনো গন্তব্যে যেতে পারে:

- হেঁটে, যার বর্ণনা: `"You're traveling to your destination by walking."`
- ঘোড়ায় চড়ে, যার বর্ণনা: `"You're traveling to your destination on horseback."`

`GameMaster.describe` মেথডটি ইমপ্লিমেন্ট করুন, যা একমাত্র প্যারামিটার হিসেবে একটি `TravelMethod` নেয় এবং তার বর্ণনা রিটার্ন করে।

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. কোনো গন্তব্যে যাত্রারত একটি চরিত্র বর্ণনা করুন

কোনো চরিত্র যখন কোনো গন্তব্যে যাচ্ছে, তখন সেটি আলাদা আলাদা বর্ণনাগুলোর সমন্বয়ে এভাবে বর্ণিত হয়: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.

`GameMaster.describe` মেথডটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে একটি `Character`, একটি `Destination` ও একটি `TravelMethod` নেয় এবং তার বর্ণনা রিটার্ন করে।

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. ভ্রমণের উপায় উল্লেখ না করে কোনো গন্তব্যে যাত্রারত একটি চরিত্র বর্ণনা করুন

বেশিরভাগ ক্ষেত্রেই চরিত্ররা হেঁটে কোনো গন্তব্যে যায়। সুবিধার জন্য খেলোয়াড়রা তাদের ভ্রমণের উপায় উল্লেখ না করতে পারেন, সেক্ষেত্রে হেঁটে যাওয়াকেই ভ্রমণের উপায় ধরে নেওয়া হবে।

`GameMaster.describe` মেথডটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে একটি `Character` ও একটি `Destination` নেয় এবং তার বর্ণনা রিটার্ন করে।

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
