# টেস্ট

সঠিক `${slug}_test.sql` ফাইলটি যে ডিরেক্টরিতে আছে সেখানে যান। এখানে `${slug}` হলো অনুশীলনীর নাম, যেখানে স্পেসের বদলে হাইফেন ব্যবহার করা হয় এবং সব অক্ষর ছোট হাতের হয় (যেমন `Hello World` অনুশীলনীর জন্য `hello-world_test.sql`)।

```bash
sqlite3 -bail < ${slug}_test.sql
```

ডিবাগ করার জন্য আপনি `SELECT` স্টেটমেন্ট ব্যবহার করতে পারেন।
টেস্ট ফেল করলে আউটপুট `user_output.md`-এ পাঠানো হয় এবং ওয়েব এডিটরে দেখানো হয়।

টেস্টিং নিয়ে sqlite ট্র্যাকের ডকুমেন্টেশনে [আরও তথ্য পাবেন](https://exercism.org/docs/tracks/sqlite/tests)।
