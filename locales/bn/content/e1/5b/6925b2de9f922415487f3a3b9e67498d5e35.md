# ইঙ্গিত

## সাধারণ

- আপনার প্রয়োজনীয় সব শব্দ [`math`][math] এবং [`math.functions`][math.functions] ভোকাবুলারিতে রয়েছে। সেগুলো আপনার `USING:` লাইনে যোগ করুন।

## 1. বিনিময়ের পর মান অনুমান করুন

- বাজেটকে রেট দিয়ে ভাগ করতে `/` ব্যবহার করুন (স্ট্যাক ইফেক্ট `( x y -- x/y )`)।

## 2. বিনিময়ের পর অবশিষ্ট মুদ্রা হিসাব করুন

- বিয়োগ করতে `-` ব্যবহার করুন।

## 3. নোটের মান হিসাব করুন

- গুণ করতে `*` ব্যবহার করুন।

## 4. নোটের সংখ্যা হিসাব করুন

- `amount` একটি ফ্লোট হতে পারে; আপনার একটি ইন্টিজার ফলাফল দরকার।
- একটি উপায়: প্রথমে `floor >integer` দিয়ে অ্যামাউন্টকে ইন্টিজারে রূপান্তর করুন, তারপর `/i` দিয়ে ভাগ করুন।
- একটি বিকল্প: সরাসরি `/i` ব্যবহার করুন, কারণ ইন্টিজার হর-এর ক্ষেত্রে এটি ফ্লোটকেও ট্রাঙ্কেট করে, তারপর `>integer` দিয়ে রূপান্তর করুন।

## 5. নোটে বিনিময়ের পর অবশিষ্ট হিসাব করুন

- ভাগশেষের জন্য `mod` ব্যবহার করুন।

## 6. বিনিময়ের পর মান হিসাব করুন

- *মোট* বিনিময় হার হিসাব করুন: `exchange-rate`-এর `spread` শতাংশ নিন এবং সেটি `exchange-rate`-এর সাথে যোগ করুন।
- তারপর বাজেট ও মোট হার দিয়ে `exchange-money` কল করুন।
- তারপর প্রদত্ত ডিনমিনেশনের নোটের পূর্ণসংখ্যায় নামাতে `number-of-bills` কল করুন।
- তারপর চূড়ান্ত মান পেতে `value-of-bills` কল করুন।
- চারটি উপ-হিসাব স্বাভাবিকভাবেই শৃঙ্খলাবদ্ধ হয়; আপনার স্ট্যাক সামলানো যদি কঠিন লাগতে শুরু করে, তবে লোকালস ফর্ম (`::` এবং নামযুক্ত প্যারামিটার) এখানে ঠিক আছে।
