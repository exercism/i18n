# পরিচিতি

কোড সংগঠিত করার একটি গুরুত্বপূর্ণ পদ্ধতি হলো নেমস্পেস।
দুটি ফাংশনের নামের সংঘর্ষ হতে পারে, সেগুলোকে আলাদা আলাদা নেমস্পেসে রেখে তা সমাধান করা যায়।
নেমস্পেস নেস্টেড হতে পারে, যা বড় কোডবেস গঠনে সাহায্য করতে পারে।
নেমস্পেসগুলোতে অ্যাক্সেস করা হয় স্কোপ-রেজোলিউশন অপারেটর `::` দিয়ে।

নিচের উদাহরণে দুটি ভিন্ন `foo` ফাংশনের ব্যবহার দেখা যায়।
এদের প্রতিটির নিজ নিজ নেমস্পেস সামনে বসিয়ে এগুলোকে একসাথে ব্যবহার করা হয়।

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
