# বিস্তারিত

একটি [while লুপ][while-loops] হলো এমন একটি কন্ট্রোল ফ্লো স্টেটমেন্ট, যা দিয়ে কোনো নির্দিষ্ট শর্ত ট্রু থাকা পর্যন্ত কোড চালানো যায়।
Swift দুই ধরনের while লুপ দেয়: while এবং repeat-while লুপ।
while লুপের শর্ত লুপের বডি চালানোর আগে মূল্যায়ন করা হয়; শর্তটি যদি ফলস হয়, তাহলে লুপের বডি একবারও চালানো হবে না।
Swift-এ while লুপের গঠনটি এমন:

```swift
while <#condition#> {
  <#code#>
}
```

এখানে count 0-এর বেশি থাকা পর্যন্ত লুপটি চলবে, আর এর ফলে 2, 1 এবং "Liftoff!" প্রিন্ট হবে।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

একটি [repeat-while লুপ][while-loops] while লুপের মতোই, তবে শর্তটি লুপের বডি চালানোর পরে মূল্যায়ন করা হয়।
এর মানে হলো, শর্ত ফলস হলেও লুপের বডি অন্তত একবার চলবেই।
Swift-এ repeat-while লুপের গঠনটি এমন:

```swift
repeat {
  <#code#>
} while <#condition#>
```

এখানে শর্ত ফলস হওয়ায় লুপটি মাত্র একবার চলবে।
যেহেতু এটি একটি repeat-while লুপ, তাই শর্ত মূল্যায়নের আগেই লুপের বডি একবার চলবে।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
