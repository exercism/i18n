# ভূমিকা

## সংখ্যা

Go-তে মৌলিক সাংখ্যিক টাইপ আছে, যেগুলো ইন্টিজার বা ফ্লোটিং-পয়েন্ট মানের সেট প্রকাশ করতে পারে।
আপনার প্রয়োজন অনুযায়ী মানের আকার এবং যে কম্পিউটারে অ্যাপ্লিকেশনটি চলছে তার আর্কিটেকচার অনুসারে টাইপ ভিন্ন হয় (যেমন ৩২-বিট ও ৬৪-বিট)।

এই অনুশীলনীর জন্য আপনাকে শুধু এগুলোর সাথেই কাজ করতে হবে:

- `int`: যেমন `0`, `255`, `2147483647`।
  একটি সাইনড ইন্টিজার, যার আকার অন্তত ৩২ বিট (মানের পরিসীমা: -2147483648 থেকে 2147483647)।
  তবে এটি সিস্টেমের আর্কিটেকচারের উপর নির্ভর করে।
  আধুনিক কম্পিউটারগুলোর বেশিরভাগই ৬৪ বিট, তাই `int`-এর আকার হবে ৬৪ বিট (মানের পরিসীমা: -9223372036854775808 থেকে 9223372036854775807)।

- `float64`: যেমন `0.0`, `3.14`।
  এতে সব ৬৪-বিট ফ্লোটিং-পয়েন্ট সংখ্যার সেট থাকে।

- `uint`: যেমন `0`, `255`।
  একটি আনসাইনড ইন্টিজার, যার আকার `int`-এর সমান (মানের পরিসীমা: ৩২ বিটের জন্য 0 থেকে 4294967295 এবং ৬৪ বিটের জন্য 0 থেকে 18446744073709551615)

সংখ্যাগুলো টাইপ কনভার্সন (ডেটা টাইপ রূপান্তর) এর মাধ্যমে অন্য সাংখ্যিক টাইপে রূপান্তর করা যায়।

## গাণিতিক অপারেটর

Go অনেক স্ট্যান্ডার্ড গাণিতিক অপারেটর সমর্থন করে:

| অপারেটর | উদাহরণ         |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

ইন্টিজার বিভাজনের ক্ষেত্রে ভাগশেষ বাদ দেওয়া হয় (যেমন `5 / 2 == 2`)।

উপরের অপারেটরগুলোর জন্য Go-তে শর্টহ্যান্ড অ্যাসাইনমেন্ট আছে (যেমন `a += 5` হলো `a = a + 5`-এর সংক্ষিপ্ত রূপ)।
Go `++` এবং `--` ইনক্রিমেন্ট ও ডিক্রিমেন্ট স্টেটমেন্টও সমর্থন করে (যেমন `a++`)।

## টাইপের মধ্যে রূপান্তর

টাইপের মধ্যে রূপান্তর করা হয় এমন একটি ফাংশনের মাধ্যমে, যার নাম হয় যে টাইপে রূপান্তর করতে চান সেই টাইপের নাম।
যেমন:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## ভিন্ন টাইপে গাণিতিক অপারেশন

অনেক ভাষায় আপনি ভিন্ন টাইপের ভ্যারিয়েবলে গাণিতিক অপারেশন চালাতে পারেন, কিন্তু Go-তে এটি এরর দেয়।
যেমন:

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
