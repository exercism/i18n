# নির্দেশাবলি

এই অনুশীলনীতে আপনি এমন কোড লিখবেন যা একটি সাইন কোম্পানিকে তাদের সাইনের জন্য কাস্টম বার্তা তৈরি করতে সাহায্য করবে।

## 1. একটি উপলক্ষের সাইন তৈরি করুন

`build_sign( )` মেথডটি ইমপ্লিমেন্ট করুন, যা `occasion` প্যারামিটার হিসেবে একটি স্ট্রিং এবং `name` প্যারামিটার হিসেবে কারও নাম ধারণ করে থাকা একটি স্ট্রিং গ্রহণ করে। এই দুটি প্যারামিটার একটি স্ট্রিং টেমপ্লেটে বসানো হবে, যাতে সাইনে বার্তাটি আউটপুট হিসেবে আসে।

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. একটি জন্মদিনের সাইন তৈরি করুন

`build_birthday_sign( )` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি বয়স গ্রহণ করে এবং সেই বয়সের ভিত্তিতে সাইনের বার্তার একটি অংশ নির্ধারণ করে। বয়স ৫০ বা তার বেশি হলে সাইনে _mature_ শব্দটি থাকবে, নাহলে সাইনে _young_ শব্দটি থাকবে।

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. একটি গ্র্যাজুয়েশন সাইন তৈরি করুন

`graduation_for( )` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি নাম স্ট্রিং প্যারামিটার হিসেবে এবং একটি বছর সংখ্যাসূচক প্যারামিটার হিসেবে নেয় এবং স্ট্রিং টেমপ্লেট ব্যবহার করে সাইনের জন্য একটি বাক্য তৈরি করে, যেখানে বার্তার দুটি লাইন আলাদা করতে একটি নিউলাইন ব্যবহার করা হয়।

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. একটি সাইনের খরচ হিসাব করুন

`cost_of( sign currency )` ফাংশনটি ইমপ্লিমেন্ট করুন, যা সাইনের বিষয়বস্তু ধারণ করে থাকা একটি স্ট্রিং এবং কারেন্সি বোঝায় এমন একটি স্ট্রিং গ্রহণ করে।
নির্দিষ্ট কারেন্সিতে সাইনের ভিত্তিমূল্য ২০। এছাড়া প্রতিটি অক্ষরের খরচ ২। (হিসাবের মধ্যে হোয়াইটস্পেসও ধরা হয়।)
রিটার্ন করা বাক্যে সাইন তৈরি করার খরচ থাকে, যা দশমিক বিন্দুর পরে দুই অঙ্কে লেখা হয় এবং তার পরে কারেন্সি স্ট্রিংটি থাকে।

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
