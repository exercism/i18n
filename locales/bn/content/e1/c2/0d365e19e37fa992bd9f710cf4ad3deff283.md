# পরিচিতি

TypeScript হলো টাইপের সিনট্যাক্স-সহ JavaScript। এটি একটি স্ট্রংলি টাইপড প্রোগ্রামিং ভাষা, যা অবজেক্ট-ওরিয়েন্টেড, ইম্পারেটিভ আর ডিক্লারেটিভ (যেমন ফাংশনাল প্রোগ্রামিং) স্টাইল সমর্থন করে এবং যেকোনো আকারে আপনাকে আরও ভালো টুলিং দেয়।

যেহেতু [JavaScript না শিখে TypeScript শেখা যায় না][handbook-js-or-ts], তাই এই ট্র্যাকের কিছু কনটেন্ট JavaScript-এর ধারণা শেখানোর দিকে মনোযোগ দেয়, আবার কিছু ধারণা শুধু TypeScript-এর নিজস্ব ফিচার নিয়ে আলোচনা করে।

## (পুনরায়) অ্যাসাইনমেন্ট

TypeScript-এ নামের সাথে মান অ্যাসাইন করার কয়েকটি প্রধান উপায় আছে: ভ্যারিয়েবল কিংবা কনস্ট্যান্ট।
Exercism-এ ভ্যারিয়েবল সবসময় [camelCase][wiki-camel-case] শৈলীতে লেখা হয়; আর কনস্ট্যান্ট লেখা হয় [SCREAMING_SNAKE_CASE][wiki-snake-case] শৈলীতে।
অনুসরণ করার মতো কোনো অফিসিয়াল গাইড নেই, আর বিভিন্ন কোম্পানি ও প্রতিষ্ঠানের স্টাইল গাইডও নানা রকম।
_ভ্যারিয়েবল আপনি যেভাবে খুশি লিখতে পারেন_।
অনুশীলনীগুলো যেভাবে প্রস্তুত করা হয়েছে সেভাবে লিখলে একটা সুবিধা আছে: ওয়েব ইন্টারফেস আর বেশিরভাগ IDE-তে এগুলো আলাদাভাবে হাইলাইট হয়ে ওঠে।

TypeScript-এ [`const`][mdn-const], [`let`][mdn-let] বা [`var`][mdn-var] কিওয়ার্ড দিয়ে ভ্যারিয়েবল ডিফাইন করা যায়।

`let` বা `var` ব্যবহার করলে একটি ভ্যারিয়েবল তার জীবনকাল জুড়ে বিভিন্ন মান রেফার করতে পারে।
উদাহরণস্বরূপ, অ্যাসাইনমেন্ট অপারেটর `=` দিয়ে `myFirstVariable`-কে বহুবার ডিফাইন ও রিডিফাইন করা যায়:

```typescript
let myFirstVariable = 1
myFirstVariable = 0
myFirstVariable = 42
```

`let` আর `var`-এর বিপরীতে, `const` দিয়ে ডিফাইন করা ভ্যারিয়েবলে মান শুধু একবারই অ্যাসাইন করা যায়।
TypeScript-এ কনস্ট্যান্ট ডিফাইন করতেই এটা ব্যবহার করা হয়।

```typescript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

যেহেতু TypeScript এটি স্ট্যাটিকভাবেই ধরতে পারে, তাই TypeScript কম্পাইলারও একটি এরর দেবে:

```typescript
// ^? Cannot assign to 'MY_FIRST_CONSTANT' because it is a constant.(2588)
```

এর মানে, `TypeError` ধরার জন্য আপনাকে কোড রান করতে হবে না।

## টাইপ ইনফারেন্স

[টাইপ ইনফারেন্স][handbook-type-inference] বিষয়ে খুব গভীরে না গিয়েও জেনে রাখা ভালো, টাইপ অ্যানোটেশন ছাড়াই একটি অ্যাসাইন করা ভ্যারিয়েবলের সাধারণত একটি ইনফার্ড টাইপ থাকে।

```typescript
const MY_FIRST_CONSTANT = 10
// ^? const MY_FIRST_CONSTANT: number
```

এরপর পুরো কোডজুড়ে এই টাইপটিই প্রয়োগ করা হয়।
এর মানে হলো, নিচের কোডটি যেখানে বৈধ JavaScript:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
```

TypeScript-এ ব্যবহার করলে কিন্তু এটি এরর দেখায়:

```typescript
let myFirstVariable = 1
myFirstVariable = 'Some string'
// ^? Type 'string' is not assignable to type 'number'.(2322)
```

এই বৈশিষ্ট্যটি টাইপ অ্যানোটেশন ব্যবহার না করলেও টাইপ-সেফটি নিশ্চিত করে।

## ফাংশন ডিক্লারেশন

TypeScript-এ কার্যকারিতার এককগুলো _ফাংশনে_ মোড়া থাকে; সাধারণত একসাথে সম্পর্কিত ফাংশনগুলো একই ফাইলে রাখা হয়।
এই ফাংশনগুলো প্যারামিটার (আর্গুমেন্ট) নিতে পারে, আর `return` কিওয়ার্ড দিয়ে একটি মান _রিটার্ন_ করতে পারে।
ফাংশন কল করা হয় `()` সিনট্যাক্স দিয়ে।

```typescript
function add(num1: number, num2: number): number {
  return num1 + num2
}

add(1, 3)
// => 4
```

ফাংশনের প্যারামিটার সাধারণত কোলন (`:`) দিয়ে তারপর টাইপ লিখে অ্যানোটেট করা উচিত।
ফাংশনের রিটার্ন ভ্যালু অ্যানোটেট করা যায় প্যারামিটার তালিকা বন্ধ করার পরে, কোলন (`:`) দিয়ে তারপর টাইপ লিখে।

💡 TypeScript-এ একটি ফাংশন ডিক্লেয়ার করার _অনেক_ রকম উপায় আছে।
এই অন্য উপায়গুলো `function` কিওয়ার্ড ব্যবহারের চেয়ে আলাদা দেখায়।
ট্র্যাকটি ধীরে ধীরে এগুলো চালু করার চেষ্টা করে, তবে আপনি যদি এগুলো আগে থেকেই জানেন, তাহলে যেকোনোটি নির্দ্বিধায় ব্যবহার করতে পারেন।
বেশিরভাগ ক্ষেত্রে, একটির বদলে অন্যটি ব্যবহার করা ভালো বা খারাপ কিছু নয়।
~~~~

## টাইপ অ্যানোটেশন

`add`-এর ফাংশন ডিক্লারেশনে যেমন দেখানো হয়েছে, সেখানে প্যারামিটারগুলোর স্পষ্ট টাইপ অ্যানোটেশন `: number` দেওয়া আছে।
ভ্যারিয়েবল ডিক্লারেশন, ক্লাস প্রপার্টি, ফাংশন ডিক্লারেশন এবং আরও অনেক কিছুই টাইপ অ্যানোটেশন সমর্থন করে।

স্পষ্ট টাইপ অ্যানোটেশন আর ইনফার্ড টাইপ, দুটোই টাইপ-চেকার প্রয়োগ করে নিশ্চিত করে।

```typescript
add('foo', 3)
// ^? Argument of type 'string' is not assignable to parameter of type 'number'.(2345)
```

## অন্য ফাইলে প্রকাশ করা

একটি `function`, কনস্ট্যান্ট কিংবা ভ্যারিয়েবলকে _অন্য ফাইলে_ ব্যবহার করতে হলে, `export` কিওয়ার্ড দিয়ে সেগুলো [এক্সপোর্ট][mdn-export] করতে হয়।
এরপর অন্য একটি ফাইল `import` কিওয়ার্ড দিয়ে এগুলো [ইমপোর্ট][mdn-import] করতে পারে।
এটাকেই মডিউল সিস্টেম বলা হয়।
এর দারুণ একটি উদাহরণ হলো সব টেস্ট যেভাবে কাজ করে।
প্রতিটি অনুশীলনীতে অন্তত একটি ফাইল থাকে, যেমন `lasagna.ts`, যেটিতে _ইমপ্লিমেন্টেশন_ থাকে।
এর বাইরে অন্তত আরেকটি ফাইল থাকে, যেমন `lasagna.test.ts`, যেটিতে _টেস্ট_ থাকে।
এই ফাইলটি পাবলিক (অর্থাৎ এক্সপোর্ট করা) এনটিটিগুলো _ইমপোর্ট_ করে, যাতে ইমপ্লিমেন্টেশন টেস্ট করা যায়:

```typescript
// file.ts
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.test.ts
import { MY_VALUE, add } from './file.js'

add(MY_VALUE, 5)
// => 15
```
