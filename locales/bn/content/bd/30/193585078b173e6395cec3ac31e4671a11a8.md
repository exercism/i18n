# নির্দেশাবলি

আপনি একজন আগ্রহী পাখি পর্যবেক্ষক, যিনি হিসাব রাখেন কোনও একটি দিনে আপনার বাগানে কতগুলো পাখি এসেছে।

আপনি সিদ্ধান্ত নিয়েছেন যে আপনার পাখি পর্যবেক্ষণকে নতুন একটি স্তরে নিয়ে যাবেন এবং কয়েকটি টুল ইমপ্লিমেন্ট করবেন, যা ডেটা ট্র্যাক করতে ও প্রক্রিয়া করতে সাহায্য করবে।

আপনি ডেটা ইন্টিজারের একটি অ্যারে হিসেবে সংরক্ষণ করার সিদ্ধান্ত নিয়েছেন। অ্যারের প্রথম সংখ্যাটি আজ আপনার বাগানে আসা পাখির সংখ্যা, দ্বিতীয়টি গতকালের, আর এভাবে চলতে থাকে।

## 1. আজ কতগুলো পাখি এসেছে তা দেখুন

`BirdCount.today/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্রতিদিনের পাখি গণনার একটি অ্যারে নেবে এবং আজকের গণনা রিটার্ন করবে। অ্যারেটি খালি হলে এটি `nil` রিটার্ন করবে।

```elixir
BirdCount.today([2, 5, 1])
# => 2
```

## 2. আজকের গণনা বাড়ান

`BirdCount.increment_day_count/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্রতিদিনের পাখি গণনার একটি অ্যারে নেবে এবং আজকের গণনা ১ বাড়াবে। অ্যারেটি খালি হলে `[1]` রিটার্ন করবে।

```elixir
BirdCount.increment_day_count([4, 0, 2])
# => [5, 0, 2]
```

## 3. পাখি আসেনি এমন কোনো দিন ছিল কি না তা দেখুন

`BirdCount.has_day_without_birds?/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্রতিদিনের পাখি গণনার একটি অ্যারে নেবে। বাগানে অন্তত একটি দিন কোনো পাখি না এলে এটি `true` রিটার্ন করবে, নাহলে `false`।

```elixir
BirdCount.has_day_without_birds?([2, 0, 4])
# => true

BirdCount.has_day_without_birds?([3, 8, 1, 5])
# => false
```

## 4. মোট আসা পাখির সংখ্যা হিসাব করুন

`BirdCount.total/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্রতিদিনের পাখি গণনার একটি অ্যারে নেবে এবং আপনি ডেটা সংগ্রহ শুরু করার পর থেকে আপনার বাগানে আসা মোট পাখির সংখ্যা রিটার্ন করবে।

```elixir
BirdCount.total([4, 0, 9, 0, 5])
# => 18
```

## 5. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্য দিনের চেয়ে ব্যস্ত থাকে। যে দিনে আপনার বাগানে পাঁচটি বা তার বেশি পাখি এসেছে, সেটি একটি ব্যস্ত দিন।

`BirdCount.busy_days/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্রতিদিনের পাখি গণনার একটি অ্যারে নেবে এবং ব্যস্ত দিনের সংখ্যা রিটার্ন করবে।

```elixir
BirdCount.busy_days([4, 5, 0, 0, 6])
# => 2
```
