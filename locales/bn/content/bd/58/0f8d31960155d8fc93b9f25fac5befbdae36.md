# পরিচিতি

## শুরু করা যাক

### ভ্যারিয়েবল

একটি [ভ্যারিয়েবল][constants-variables] ডিফাইন করে আপনি মান সংরক্ষণ করতে ও তার একটি নাম দিতে পারেন।
ভ্যারিয়েবল ডিফাইন করার পর, আপনার পুরো কোড জুড়ে সেই মানটি বোঝাতে আপনি তার নাম ব্যবহার করতে পারেন।
ভ্যারিয়েবল _মিউটেবল_, অর্থাৎ ডিফাইন করার পরেও তাদের মান পরিবর্তন করা যায়।

`var` কিওয়ার্ড দিয়ে একটি ভ্যারিয়েবল ডিফাইন করুন:

```swift
var variableName = 10
```

Swift একটি স্ট্যাটিকালি টাইপড ভাষা, অর্থাৎ কম্পাইল টাইমে প্রতিটি মানের টাইপ জানা থাকে।
আপনি একটি [টাইপ অ্যানোটেশন][type annotations] দিয়ে স্পষ্টভাবে টাইপ ডিক্লেয়ার করতে পারেন, অথবা অ্যাসাইন করা মান থেকে Swift কম্পাইলারকে [টাইপ অনুমান করতে][type-inferring] দিতে পারেন:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

অ্যাসাইনমেন্ট অপারেটর (`=`) দিয়ে আপনি একটি ভ্যারিয়েবলের মান হালনাগাদ করতে পারেন:

~~~~exercism/note
একবার ডিক্লেয়ার করার পর একটি ভ্যারিয়েবলের টাইপ পরিবর্তন করা যায় না।

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

টাইপ উল্লেখ করে আপনি প্রাথমিক মান ছাড়াই একটি ভ্যারিয়েবল ডিক্লেয়ার করতে পারেন, তবে ব্যবহার করার আগে অবশ্যই একটি মান অ্যাসাইন করতে হবে:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### কনস্ট্যান্ট

[কনস্ট্যান্ট][constants-variables]-ও একটি নামের সাথে একটি মান যুক্ত করে, তবে অ্যাসাইনমেন্টের পর তাদের মান পরিবর্তন করা যায় না।
এগুলো _ইমিউটেবল_।
`let` কিওয়ার্ড দিয়ে একটি কনস্ট্যান্ট ডিফাইন করুন:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### গাণিতিক অপারেটর

Swift মৌলিক গণনার জন্য স্ট্যান্ডার্ড [গাণিতিক অপারেটর][arithmetical-operators] দেয়:

- যোগ: `+`
- বিয়োগ: `-`
- গুণ: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### ফাংশন

Swift-এ [ফাংশন][functions] হলো স্বয়ংসম্পূর্ণ কোড ব্লক, যা একটি নির্দিষ্ট কাজ সম্পন্ন করে।
ফাংশন ইনপুট নিতে পারে, একটি মান রিটার্ন করতে পারে, এবং অন্য ফাংশনে মান হিসেবে পাস করা যায়।
`func` কিওয়ার্ড দিয়ে একটি ফাংশন ডিফাইন করুন, তারপর ফাংশনের নাম, বন্ধনীর ভেতরে প্যারামিটার তালিকা এবং ঐচ্ছিক একটি রিটার্ন টাইপ লিখুন:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift ফাংশনে [আর্গুমেন্ট লেবেল][argument-labels] ব্যবহার হয়, যা কোডকে স্বাভাবিক বাক্যের মতো পড়তে সাহায্য করে:

- ফাংশন কল করার সময় **আর্গুমেন্ট লেবেল** ব্যবহার হয়।
- মানটি ব্যবহার করতে ফাংশনের বডির ভেতরে **প্যারামিটার নাম** ব্যবহার হয়।

আপনি যদি কেবল একটি নাম উল্লেখ করেন, Swift সেটিকেই আর্গুমেন্ট লেবেল এবং প্যারামিটার নাম উভয় হিসেবেই ব্যবহার করে:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

ফাংশন কল করার সময় আপনি আর্গুমেন্ট লেবেল না চাইলে প্যারামিটার নামের আগে একটি আন্ডারস্কোর (`_`) লিখুন:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

ডিফল্টভাবে সব ফাংশন প্যারামিটারই কনস্ট্যান্ট (`let`), অর্থাৎ ফাংশনের বডির ভেতরে তাদের মান পরিবর্তন করা যায় না।

একটি ফাংশন থেকে মান রিটার্ন করতে `->` চিহ্নের পরে রিটার্ন টাইপ উল্লেখ করুন এবং `return` কিওয়ার্ড ব্যবহার করুন:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

কোনো ফাংশন যখন মান রিটার্ন করে না, তখন তার রিটার্ন টাইপ `Void` (`()`, অর্থাৎ একটি খালি টাপলের সমতুল্য)।
এমন ফাংশনে আপনি `-> Void` রিটার্ন টাইপ এবং `return` স্টেটমেন্ট দুটোই বাদ দিতে পারেন।

### কমেন্ট

Swift দুই ধরনের [কমেন্ট][comments] সমর্থন করে:

- **এক লাইনের কমেন্ট** `//` দিয়ে শুরু হয় এবং লাইনের শেষ পর্যন্ত চলতে থাকে।
- **বহু লাইনের কমেন্ট** `/*` এবং `*/` চিহ্নের মাঝখানে থাকে।

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
