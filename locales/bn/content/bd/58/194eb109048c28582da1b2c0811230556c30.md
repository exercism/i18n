# পরিচিতি

একটি _স্ট্রিং_ হলো টেক্সট ডেটা সংরক্ষণ করার JavaScript ডেটা টাইপ।

## একটি স্ট্রিং তৈরি করা

আপনি টেক্সটটিকে সিঙ্গেল কোট বা ডাবল কোটের ভেতরে রেখে একটি স্ট্রিং তৈরি করেন।
Exercism-এ সিঙ্গেল কোট ব্যবহার করা হয়।

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## ক্যারেক্টারের তালিকা হিসেবে স্ট্রিং

স্ট্রিংকে ক্যারেক্টারের একটি তালিকা হিসেবে ভাবা যায়, যেখানে প্রথম ক্যারেক্টারের ইনডেক্স `0`।
আপনি যে অক্ষরটি নিতে চান তার ইনডেক্সসহ তৃতীয় বন্ধনী ব্যবহার করে স্ট্রিংয়ের একটি নির্দিষ্ট ক্যারেক্টার পেতে পারেন।

```javascript
'cat'[1];
// => 'a'
```

`length` প্রপার্টি ব্যবহার করে একটি স্ট্রিংয়ে কতগুলো ক্যারেক্টার আছে তা জানতে পারেন।

```javascript
'cat'.length;
// => 3
```

## জোড়া লাগানো ও মেথড

স্ট্রিং জোড়া লাগানোর সবচেয়ে সহজ উপায় হলো যোগ অপারেটর `+` ব্যবহার করা।

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

স্ট্রিংয়ে অনেক সহায়ক মেথড আছে, সম্পূর্ণ তালিকার জন্য [স্ট্রিং মেথড নিয়ে MDN ডকস][mdn-string-methods] দেখুন।
নিচের তালিকায় কিছু বহুল ব্যবহৃত সহায়ক মেথড দেখানো হয়েছে।

- [`toUpperCase`][mdn-to-upper-case] এবং [`toLowerCase`][mdn-to-lower-case] - সব ক্যারেক্টারের কেস বদলে দেয়
- [`trim`][mdn-trim] - শুরু ও শেষের হোয়াইটস্পেস মুছে দেয়
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] এবং [`endsWith`][mdn-ends-with] - অন্য একটি স্ট্রিং প্রদত্ত স্ট্রিংয়ের অংশ কি না তা নির্ধারণ করে
- [`slice`][mdn-slice] - স্ট্রিংয়ের একটি অংশ বের করে আনে

JavaScript-এ স্ট্রিং ইমিউটেবল। তাই উপরের কিছু মেথড দিয়ে একটি "পরিবর্তন" করলেও সবসময়ই বদলে একটি নতুন স্ট্রিং তৈরি হয়।
