# সম্পর্কে

## ইনহেরিটেন্স

Java তার মূল বৈশিষ্ট্য হিসেবেই ইনহেরিটেন্স সমর্থন করে, আর ইনহেরিটেন্স ব্যবহার করে অ্যাবস্ট্রাকশনের মতো অনেক OOP নীতি অর্জন করা যায়।

একটি ক্লাস `extends` কিওয়ার্ড ব্যবহার করে আরেকটি ক্লাসকে এক্সটেন্ড করতে পারে, আর `implements` কিওয়ার্ড ব্যবহার করে একটি ইন্টারফেস থেকে ইনহেরিট করতে পারে।

## অ্যাক্সেস মডিফায়ার

অ্যাক্সেস মডিফায়ার একটি ক্লাসের মেম্বার ভ্যারিয়েবল ও মেথডগুলো অন্য ক্লাস থেকে (বা কোডের যেকোনো জায়গা থেকে) অ্যাক্সেস করার নিয়ম ঠিক করে দেয়।

অ্যাক্সেস মডিফায়ার চারটি:

- `private`
- `public`
- `protected`
- ডিফল্ট (কোনো কিওয়ার্ড লাগে না)

এগুলো সম্পর্কে আরও জানতে [এই নিবন্ধটি][access-modifiers] পড়তে পারেন

## ইনহেরিটেন্স বনাম কম্পোজিশন

এই দুটি ধারণা অনেকটাই একরকম, আর প্রায়ই এগুলো নিয়ে বিভ্রান্তি হয়।

- ইনহেরিটেন্স মানে হলো, চাইল্ড ক্লাসের সাথে প্যারেন্ট ক্লাসের সম্পর্কটি একটি IS-A সম্পর্ক।

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

এখানে `Dog`-এর সাথে `Animal`-এর সম্পর্কটি IS-A

- কম্পোজিশন বোঝায় একটি HAS-A সম্পর্ক।

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

এখানে `Car`-এর সাথে `Engine`-এর সম্পর্কটি HAS-A
