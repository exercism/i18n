# ভূমিকা

`Tuple` অনেক দিক থেকেই `Vector` (একমাত্রিক `array`)-এর সঙ্গে bastante মিল রাখে। তবে কয়েকটি গুরুত্বপূর্ণ পার্থক্যও আছে।

- টুপল লেখা হয় তৃতীয় বন্ধনী `[ ]`-এর বদলে প্রথম বন্ধনী `( )` দিয়ে, যদিও অর্থ স্পষ্ট থাকলে বন্ধনীগুলো বাদ দেওয়া যায়।
- টুপল সমজাতীয় হওয়ার বাধ্যবাধকতা নেই: প্রতিটি এলিমেন্টের টাইপ আলাদাভাবে সংরক্ষিত থাকে।
- টুপল ইমিউটেবল।

ইমিউটেবিলিটির কারণে কম্পাইলার আরও অপটিমাইজেশন করতে পারে এবং টুপল ভেক্টরের চেয়ে বেশি পারফরম্যান্ট হয়, তাই যেখানে মিউটেবিলিটির প্রয়োজন নেই সেখানে টুপল ব্যবহার করাই ভালো।

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

এছাড়া `Tuple()` নামের একটি কনস্ট্রাক্টরও আছে, যা যেকোনো ইটারেবল কালেকশনকে একটি টুপলে পরিণত করে। সুবিধার কথা হলো, এটি একটি স্ট্রিংকে ক্যারেক্টারের ইটারেবল কালেকশন হিসেবে বিবেচনা করে।

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

যেকোনো টুপলের ক্ষেত্রেই ইনডেক্স দিয়ে এলিমেন্ট অ্যাক্সেস করা বা সেগুলোর উপর লুপ চালানো সম্ভব।

শুধু সংখ্যা দিয়ে গঠিত যেকোনো টুপল অ্যারেগুলোর মতোই `sum()`-এর মতো গাণিতিক ফাংশনে ব্যবহার করা যায়।

## আনপ্যাকিং

একাধিক অ্যাসাইনমেন্ট ব্যবহার করে একটি টুপলকে আলাদা আলাদা এলিমেন্টে আনপ্যাক করা যায়।
যে এলিমেন্টগুলো দরকার নেই সেগুলোর জন্য ডামি ভ্যারিয়েবল হিসেবে আন্ডারস্কোর `_` ব্যবহার করুন।

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Python প্রোগ্রামারদের কাছে এই একাধিক-অ্যাসাইনমেন্ট সিনট্যাক্স বেশ পরিচিতই।

## নেমড টুপল

একটি `Tuple`-এ শুধু ভ্যালু থাকে।
`NamedTuple` প্রতিটি ভ্যালুর সঙ্গে একটি নাম জুড়ে দেয়।

এরপর "ডট" নোটেশন দিয়ে প্রতিটি ফিল্ড অ্যাক্সেস করা যায়:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

নামটি অভ্যন্তরীণভাবে `Symbol` (একটি ইমিউটেবল টাইপ, যার শুরুতে কোলন `:` থাকে) হিসেবে সংরক্ষিত হয়, তাই একটি বিকল্প সিনট্যাক্সও পাওয়া যায়:

```julia-repl
julia> nt[:b]
7.3
```

নামগুলো (যাদের কী (key)-ও বলা হয়) কিংবা শুধু ভ্যালুগুলো আলাদাভাবেও সহজেই পাওয়া যায়:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

মনে রাখবেন, একটি নেমড টুপলের উপর ইটারেশন করলে শুধু _ভ্যালুগুলোই_ পাওয়া যায়, আর _নামগুলো_ উপেক্ষিত থাকে।

টুপল (নেমড হোক বা না হোক) ফাংশনে ও ফাংশন থেকে স্ট্রাকচার্ড ডেটা পাঠানোর খুব কমন একটি উপায়।
এই কাজে ইমিউটেবিলিটি ভালো, কারণ এটি ডেটার নিরাপত্তা দেয় এবং কম্পাইলারকে আরও জোরালো অপটিমাইজেশনের সুযোগ করে দেয়।
