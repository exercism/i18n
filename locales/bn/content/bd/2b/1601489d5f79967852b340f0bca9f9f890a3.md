# পরিচিতি

`Result` টাইপের সাহায্যে একটি ফাংশন এমন একটি মান রিটার্ন করতে পারে, যা নিচের সবগুলো বিষয় একসাথে বোঝায়:

- অপারেশনটি সফল হয়েছে, নাকি ব্যর্থ হয়েছে
- সফল হলে, অপারেশনের ফলে পাওয়া মান
- ব্যর্থ হলে, ব্যর্থতার কারণ

## ব্যবহার

`Result` হলো একটি জেনেরিক টাইপ, যার ভেতরে আরও দুইটি টাইপ থাকে:

- সফল অপারেশনে পাওয়া মানের টাইপ
- ব্যর্থতার ক্ষেত্রে ব্যর্থতার কারণ বোঝানো টাইপ

`Result` টাইপটি একটি [ডিসক্রিমিনেটেড ইউনিয়ন][discriminated-union]ও, যার নিচের কেসগুলো সম্ভব:

- `Ok <value>` সফল ফলাফল বোঝায়
- `Error <reason>` ব্যর্থতা বোঝায়

নিচের ফাংশনটি একটি `Result` মান তৈরি করার পদ্ধতি দেখায়:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

এই উদাহরণে `Ok` মানটি একটি স্ট্রিং (যে নামটি দেওয়া হয়েছে), আর `Error` মানটিও একটি স্ট্রিং (এররটির কারণ, মানুষের পড়ার উপযোগী আকারে)।

## একটি `Result` মানের বিষয়বস্তু পড়া

নিচের টাইপ ডেফিনিশন ও ফাংশন সিগনেচারটি দেখুন:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

`openFile` ফাংশনটি যে কোড কল করে, সে কোড প্যাটার্ন ম্যাচিং ব্যবহার করে সফল ও ব্যর্থ কেসগুলো সামলাতে পারে, যেমনটি নিচের উদাহরণে দেখানো হয়েছে:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```

[discriminated-union]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/discriminated-unions
