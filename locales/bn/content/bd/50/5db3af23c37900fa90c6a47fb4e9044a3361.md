# নির্দেশাবলির সংযোজন

## নিজের DSL তৈরি করুন

এই অনুশীলনীতে আপনি সম্পূর্ণ স্বাধীনভাবে আপনার স্বপ্নের গ্রাফ DSL ডিজাইন করতে পারেন।

টেস্টগুলো শুধু কয়েকটি নির্দিষ্ট গ্রাফ তৈরি করতে বলে, সেগুলো আপনি কীভাবে বানাবেন তা সম্পূর্ণ আপনার নিজের ব্যাপার।

মজা আরও বাড়াতে চাইলে আপনি ঐচ্ছিকভাবে একটি `to_dot` ফাংশন ইমপ্লিমেন্ট করার চেষ্টা করতে পারেন, যা আপনার গ্রাফকে DOT ফরম্যাটে রূপান্তর করে!

## গ্রাফ রিপ্রেজেন্টেশন

`Graph.roc` ফাইলে আপনার DSL ডিফাইন করুন, তারপর স্টাব যে গ্রাফগুলো তৈরি করতে বলে সেগুলো বানাতে সেটি ব্যবহার করুন। প্রতিটি `EdgeId`-এর দুটি নোড আইডি বর্ণানুক্রমে সাজানো থাকতে হবে।

| সংজ্ঞা | যে গ্রাফ তৈরি করতে হবে |
| --- | --- |
| `empty_graph` | একটি ফাঁকা গ্রাফ |
| `graph_with_one_node` | একটি নোড |
| `graph_with_one_node_with_attribute` | একটি অ্যাট্রিবিউটসহ একটি নোড |
| `graph_with_one_edge` | একটি এজ |
| `graph_with_one_attribute` | একটি গ্রাফ অ্যাট্রিবিউট |
| `graph_with_nodes_edges_and_attributes` | নোড, এজ ও অ্যাট্রিবিউট |
| `multiple_edges_on_one_line` | এক লাইনে প্রকাশ করা একাধিক এজ |
| `only_1_edge_between_nodes` | প্রতি জোড়া নোডের মাঝে কেবল একটি এজ |
