# Debug

যখন কোনো test ফেল করে, তখন কী ভুল হয়েছে এবং কোন ইনপুটের জন্য ভুল হয়েছে তা বর্ণনা করে একটি বার্তা দেখানো হয়। আপনি আপনার প্রোগ্রামের যেকোনো মান `debug` মেথডে পাস করে দেখতে পারেন (`exercism/test_runner`-এ পাওয়া যায়)। এটি মানগুলো ধরে নিয়ে আপনাকে আউটপুট দেখাবে।


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
