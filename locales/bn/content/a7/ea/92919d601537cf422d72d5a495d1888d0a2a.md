# নির্দেশাবলি

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট এমন: `"[<LEVEL>]: <MESSAGE>"`।

তিনটি ভিন্ন লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার তিনটি কাজ আছে, প্রতিটিতে একটি লগ লাইন নেওয়া হবে এবং সেটি দিয়ে কিছু করতে বলা হবে।

## 1. লগ লাইন থেকে মেসেজ বের করা

লগ লাইনের মেসেজ রিটার্ন করার জন্য `message` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

শুরুতে বা শেষে থাকা যেকোনো হোয়াইট স্পেস মুছে ফেলা উচিত:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. লগ লাইন থেকে লগ লেভেল বের করা

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য `logLevel` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি ছোট হাতের অক্ষরে রিটার্ন করতে হবে:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. একটি লগ লাইন রিফরম্যাট করা

লগ লাইনটি রিফরম্যাট করার জন্য `reformat` ফাংশনটি ইমপ্লিমেন্ট করুন, যেখানে মেসেজটি আগে থাকবে আর তার পরে বন্ধনীর মধ্যে লগ লেভেল থাকবে:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
