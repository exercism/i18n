# ডিফল্ট প্যারামিটার ভ্যালু

[ডিফল্ট প্যারামিটার ভ্যালু][default-parameter-values] ফাংশনের যেকোনো প্যারামিটারের জন্য দেওয়া যায়, প্যারামিটার লিস্টে প্যারামিটারের টাইপ অ্যানোটেশনের পরে একটি মান অ্যাসাইন করে। যখন একটি ডিফল্ট প্যারামিটার ভ্যালু নির্দিষ্ট করা হয়, তখন ফাংশনটি কল করার সময় কলকারী সেই প্যারামিটারটি বাদ দিতে পারেন, এবং তার বদলে ডিফল্ট মানটি ব্যবহৃত হয়।

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```
