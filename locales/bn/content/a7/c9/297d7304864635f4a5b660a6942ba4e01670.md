# টাইপ কনভার্সনের পরিচিতি

Go-তে ভিন্ন ভিন্ন টাইপের মধ্যে এক্সপ্লিসিট কনভার্সন প্রয়োজন।
টাইপের মধ্যে রূপান্তর (**টাইপ কাস্টিং** নামেও পরিচিত) করার জন্য যে টাইপে রূপান্তর করতে চান, তার নামের একটি ফাংশন ব্যবহার করা হয়।
উদাহরণস্বরূপ, একটি `int`-কে `float64`-তে রূপান্তর করতে হলে আপনাকে নিচের কাজটি করতে হবে:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## প্রিমিটিভ টাইপ ও স্ট্রিংয়ের মধ্যে রূপান্তর

প্রিমিটিভ টাইপ (যেমন `int`) আর `string`-এর মধ্যে রূপান্তর করার জন্য `strconv` নামের একটি প্যাকেজ আছে।

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```
