# পরিচিতি

## ইনহেরিটেন্স

ইনহেরিটেন্স অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং (OOP)-এর একটি মূল ধারণা।
এটি একটি IS-A সম্পর্ক প্রকাশ করে।
প্রোগ্রামিংয়ে এর অর্থ হুবহু ইংরেজিতে যেভাবে বোঝায় সেভাবেই: প্যারেন্ট থেকে বৈশিষ্ট্য উত্তরাধিকারসূত্রে পাওয়া (প্রোগ্রামিংয়ে বৈশিষ্ট্য সাধারণত ফাংশন ও ভ্যারিয়েবল হয়)।

নিচে দেখানো মতো একটি `Animal` ক্লাস ধরুন,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` একটি প্যারেন্ট ক্লাস, কারণ এই ক্লাসের বৈশিষ্ট্যগুলো সাধারণভাবে সব প্রাণীতে এক্সটেন্ড করা যায়।

এখন `Lion` নামের একটি প্রাণী ধরুন, যার ক্লাসটি দেখতে এমন,

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` অ্যানোটেশনটি বোঝায় যে সাবক্লাসের একটি মেথড তার সুপারক্লাসের একটি মেথড ওভাররাইড করছে।
এটি কঠোরভাবে জরুরি নয়, তবে এটি ব্যবহার করা একটি ভালো অভ্যাস।
~~~~

এখন যখনই আমরা এটা করি,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

লক্ষ করুন: এখানে `Animal` ক্লাসটি `Lion` দিয়ে ইনিশিয়ালাইজ করা হচ্ছে।
আউটপুট দেখতে এমন হবে

```java
Lion here!!
```

OOP অনুযায়ী ইনহেরিটেন্সের অনেক ধরন আছে, তবে Java এর মধ্যে কয়েকটিই সাপোর্ট করে (মাল্টি-লেভেল ও হায়ারার্কিক্যাল)।
এটি নিয়ে আরও পড়তে, অনুগ্রহ করে [এটি][java-inheritance] পড়ুন।
