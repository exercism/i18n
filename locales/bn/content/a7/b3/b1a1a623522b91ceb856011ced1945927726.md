# পরিচিতি

JavaScript-এ একটি ইনক্রিমেন্ট অপারেটর এবং একটি ডিক্রিমেন্ট অপারেটর আছে।
এরা একটি ভ্যারিয়েবলকে জায়গাতেই পরিবর্তন করে।
`++` একটি সংখ্যার সাথে এক যোগ করে, `--` একটি সংখ্যা থেকে এক বিয়োগ করে।

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

উপরের উদাহরণে পোস্টফিক্স ইনক্রিমেন্ট/ডিক্রিমেন্ট অপারেটর দেখানো হয়েছে।
এক্ষেত্রে অপারেটরটি ভ্যারিয়েবলের পরে বসে, আর এক্সপ্রেশনের রিটার্ন ভ্যালু হয় বাড়া বা কমার _আগে_ ভ্যারিয়েবলটির যে মান ছিল সেটিই।

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

আবার প্রিফিক্স রূপটিও আছে, যেখানে অপারেটরটি ভ্যারিয়েবলের আগে বসে।
তখন রিটার্ন ভ্যালু হয় বাড়া বা কমার _পরে_ ভ্যারিয়েবলটির মান।

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
