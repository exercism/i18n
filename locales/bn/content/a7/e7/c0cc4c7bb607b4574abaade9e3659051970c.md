# নির্দেশনা

আপনি এইমাত্র এমন একটি দলে যোগ দিয়েছেন যারা jq-ভিত্তিক ডেটা পাইপলাইন রক্ষণাবেক্ষণ করে।
আপনার প্রথম পেয়ারিং সেশনে আপনার নতুন সহকর্মীর কৌতূহল জাগে:
*"আপনি কি জানেন `add`, `reverse`, এবং `map` ভেতরে কীভাবে কাজ করে? চলুন দেখি, রিকার্সন ব্যবহার করে বিল্ট-ইন ছাড়াই সেগুলো নিজে ইমপ্লিমেন্ট করার চেষ্টা করুন।"*

## 1. একটি অ্যারেতে সংখ্যাগুলো যোগ করার জন্য একটি ফাংশন ইমপ্লিমেন্ট করুন

রিকার্সন অনুশীলনের জন্য আমরা বিল্ট-ইন `add` ফিল্টারটি আবার ইমপ্লিমেন্ট করব।
_বেস কেস_ হলো, একটি খালি অ্যারের যোগফল **শূন্য**।

এটি রিকার্সিভ ফাংশন দিয়ে নিজে ইমপ্লিমেন্ট করুন; বিল্ট-ইন `add` ব্যবহার করবেন না।

```jq
[5, 4, 6, 10] | array_add     # => 25
```

## 2. একটি অ্যারে রিভার্স করুন

আমরা বিল্ট-ইন `reverse` ফিল্টারটি আবার ইমপ্লিমেন্ট করব।
_বেস কেস_ হলো, একটি খালি অ্যারে রিভার্স করলে খালি অ্যারে পাওয়া যায়।

এটি রিকার্সিভ ফাংশন দিয়ে নিজে ইমপ্লিমেন্ট করুন; বিল্ট-ইন `reverse` ব্যবহার করবেন না।

```sh
[5, 4, 6, 10] | array_reverse   # => [10, 6, 4, 5]
```

## 3. একটি অ্যারে ম্যাপ করুন

আমরা বিল্ট-ইন `map` ফিল্টারটি আবার ইমপ্লিমেন্ট করব।
ফাংশনটি একটি ফিল্টারকে প্যারামিটার হিসেবে নেয়, ইনপুট অ্যারের প্রতিটি এলিমেন্টের জন্য সেই ফিল্টারটি রান করে, এবং আউটপুটগুলো একটি নতুন অ্যারেতে রিটার্ন করে।
_বেস কেস_ হলো, একটি খালি অ্যারে ম্যাপ করলে খালি অ্যারে পাওয়া যায়।

এটি রিকার্সিভ ফাংশন দিয়ে নিজে ইমপ্লিমেন্ট করুন; বিল্ট-ইন `map` ব্যবহার করবেন না।

```sh
[5, 4, 6, 10] | array_map(. + 10)   # => [15, 14, 16, 20]
```
