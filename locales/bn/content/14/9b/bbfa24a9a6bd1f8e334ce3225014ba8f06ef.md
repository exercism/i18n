# পরিচিতি

স্ট্রিং বাফার হলো ছোট ছোট এলিমেন্ট একটির পর একটি যোগ করে বড় একটি স্ট্রিং তৈরির একটি কার্যকর উপায়। String-এর মতো নয়, StringBuf-এর একটি ইনস্ট্যান্স ইমিউটেবল নয়: এটিকে ফাংশনে আর্গুমেন্ট হিসেবে পাস করা যায়, আর সেই ফাংশনগুলো আরও মান যোগ করে এটিকে পরিবর্তন করতে পারে।

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
