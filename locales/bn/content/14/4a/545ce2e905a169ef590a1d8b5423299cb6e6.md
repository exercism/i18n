# সম্পর্কে

একটি স্ট্রিং টেক্সট ডেটা উপস্থাপন করে।
Swift-এ [`String`][strings-and-characters] হলো `Character` মানের একটি ক্রমবদ্ধ সংগ্রহ, যেখানে প্রতিটি ক্যারেক্টার একটি ইউনিকোড ক্যারেক্টার বোঝায়।

স্ট্রিং লিটারাল ব্যবহার করে আপনি একটি স্ট্রিং তৈরি করেন। স্ট্রিং লিটারাল হলো ডাবল কোটেশন চিহ্ন (`"`) দিয়ে ঘেরা ক্যারেক্টারের একটি ক্রম।
একাধিক লাইনের স্ট্রিংয়ের জন্য তিনটি ডাবল কোটেশন চিহ্ন (`"""`) ব্যবহার করুন:

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift-এর স্ট্রিংগুলো Foundation ফ্রেমওয়ার্কের [`NSString`][nsstring-docs] ক্লাসের সাথে নির্বিঘ্নে মিলে যায়, যা টেক্সট প্রসেস করার বিস্তৃত সুবিধা দেয়।

## ক্যারেক্টার

একটি `Character` একটি একক এক্সটেন্ডেড গ্রাফিম ক্লাস্টার বোঝায়, অর্থাৎ মানুষের পড়ার উপযোগী এমন একটি ক্যারেক্টার, যা এক বা একাধিক [ইউনিকোড স্কেলার ভ্যালু][unicode-scalar-values] দিয়ে গঠিত।
একটি ইউনিকোড স্কেলার ভ্যালু হলো একটি ২১-বিটের কোড পয়েন্ট, যা `U+0000` থেকে `U+D7FF` অথবা `U+E000` থেকে `U+10FFFF` পরিসরে পড়ে, প্রান্তের মানগুলোসহ।

```swift
let aChar: Character = "A"
```

## টাইপ ইনফারেন্স

আপনি যখন একটি স্ট্রিং লিটারাল লেখেন, Swift স্বয়ংক্রিয়ভাবে তার টাইপ `String` হিসেবে অনুমান করে।
একটি একক ক্যারেক্টারকে `Character` হিসেবে সংরক্ষণ করতে হলে আপনাকে স্পষ্টভাবে টাইপ অ্যানোটেশন দিতে হবে:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## কনক্যাটেনেশন

যোগ অপারেটর (`+`) ব্যবহার করে আপনি স্ট্রিংগুলো একসাথে জোড়া দিতে পারেন:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

প্রথমে ক্যারেক্টারটিকে স্ট্রিংয়ে রূপান্তর না করে আপনি `+` দিয়ে সরাসরি একটি `Character`-কে একটি `String`-এর সাথে কনক্যাটিনেট করতে পারবেন না।
তবে [`append(_:)`][append] মেথড ব্যবহার করে আপনি সরাসরি একটি মিউটেবল স্ট্রিংয়ের সাথে স্ট্রিং বা ক্যারেক্টার যুক্ত করতে পারেন:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## স্ট্রিং ইন্টারপোলেশন

[স্ট্রিং ইন্টারপোলেশন][string-interpolation] ব্যবহার করে আপনি স্ট্রিং লিটারালের ভেতরে কনস্ট্যান্ট, ভ্যারিয়েবল, লিটারাল এবং এক্সপ্রেশন বসিয়ে একটি স্ট্রিং তৈরি করতে পারেন।
প্রতিটি এক্সপ্রেশনের চারপাশে ব্যাকস্ল্যাশসহ বন্ধনী দিন (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## স্ট্রিং ও ক্যারেক্টারের প্রপার্টি

স্ট্রিং ও ক্যারেক্টারে তাদের কনটেন্ট পরীক্ষা করার জন্য বেশ কিছু প্রপার্টি আছে।

### স্ট্রিংয়ের প্রপার্টি

সাধারণ স্ট্রিং প্রপার্টিগুলোর মধ্যে রয়েছে:

| প্রপার্টি  | বিবরণ                                          | উদাহরণ                           |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | স্ট্রিংয়ে কোনো ক্যারেক্টার না থাকলে `true` রিটার্ন করে | `"Hello".isEmpty`-এর মান `false` |
| `count`   | স্ট্রিংয়ে কতগুলো ক্যারেক্টার আছে তা রিটার্ন করে | `"Hello".count`-এর মান `5`       |

প্রপার্টিগুলোর সম্পূর্ণ তালিকার জন্য [Apple String ডকুমেন্টেশন][string-docs] দেখুন।

### ক্যারেক্টারের প্রপার্টি

সাধারণ ক্যারেক্টার প্রপার্টিগুলোর মধ্যে রয়েছে:

| প্রপার্টি       | বিবরণ                                          | উদাহরণ                                |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | ক্যারেক্টারটি ছোট হাতের হলে `true` রিটার্ন করে  | `"a".isLowercase`-এর মান `true`       |
| `isUppercase`  | ক্যারেক্টারটি বড় হাতের হলে `true` রিটার্ন করে  | `"A".isUppercase`-এর মান `true`       |
| `isNumber`     | ক্যারেক্টারটি একটি অঙ্ক হলে `true` রিটার্ন করে  | `"1".isNumber`-এর মান `true`          |
| `isWhitespace` | ক্যারেক্টারটি হোয়াইটস্পেস হলে `true` রিটার্ন করে | `" ".isWhitespace`-এর মান `true`      |

প্রপার্টিগুলোর সম্পূর্ণ তালিকার জন্য [Apple Character ডকুমেন্টেশন][character-docs] দেখুন।

## টাইপ কনভার্সন

`String(_:)` ইনিশিয়ালাইজার ব্যবহার করে আপনি অন্য টাইপগুলোকে স্ট্রিংয়ে রূপান্তর করতে পারেন, যা `Int`, `Double` এবং `Character`-এর মতো স্ট্যান্ডার্ড টাইপ সাপোর্ট করে:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## বিশেষ ক্যারেক্টার

Swift-এর স্ট্রিং লিটারাল বিশেষ ক্যারেক্টারের জন্য বেশ কিছু [ইস্কেপ সিকোয়েন্স][special-characters] সাপোর্ট করে:

| সিকোয়েন্স   | বিবরণ                         |
| ---------- | ----------------------------- |
| `\0`       | নাল ক্যারেক্টার                |
| `\\`       | ব্যাকস্ল্যাশ                    |
| `\t`       | হরাইজন্টাল ট্যাব                |
| `\n`       | লাইন ফিড (নিউলাইন)             |
| `\r`       | ক্যারেজ রিটার্ন                 |
| `\'`       | সিঙ্গেল কোটেশন চিহ্ন            |
| `\"`       | ডাবল কোটেশন চিহ্ন              |
| `\u{n}`    | যেকোনো ইউনিকোড স্কেলার (হেক্সাডেসিমাল) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
