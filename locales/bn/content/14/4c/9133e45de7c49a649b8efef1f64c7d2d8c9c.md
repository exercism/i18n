# নির্দেশাবলি

নিকোম্যাকাসের (৬০ - ১২০ খ্রিষ্টাব্দ) ধনাত্মক পূর্ণসংখ্যার শ্রেণিবিন্যাস পদ্ধতির ভিত্তিতে নির্ণয় করুন, একটি সংখ্যা perfect, abundant নাকি deficient।

গ্রিক গণিতবিদ [Nicomachus](https://en.wikipedia.org/wiki/Nicomachus) ধনাত্মক পূর্ণসংখ্যার জন্য একটি শ্রেণিবিন্যাস পদ্ধতি তৈরি করেছিলেন, যেখানে প্রতিটি সংখ্যাকে তার [অ্যালিকোট যোগফল](https://en.wikipedia.org/wiki/Aliquot_sum) অনুযায়ী **perfect**, **abundant** বা **deficient** শ্রেণির একটিতে অনন্যভাবে ফেলা হয়। অ্যালিকোট যোগফল বলতে বোঝায় একটি সংখ্যার গুণনীয়কগুলোর যোগফল, যেখানে সংখ্যাটি নিজে ধরা হয় না। যেমন, 15-এর অ্যালিকোট যোগফল (1 + 3 + 5) = 9

- **Perfect**: অ্যালিকোট যোগফল = সংখ্যা
  - 6 একটি perfect সংখ্যা, কারণ (1 + 2 + 3) = 6
  - 28 একটি perfect সংখ্যা, কারণ (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**: অ্যালিকোট যোগফল > সংখ্যা
  - 12 একটি abundant সংখ্যা, কারণ (1 + 2 + 3 + 4 + 6) = 16
  - 24 একটি abundant সংখ্যা, কারণ (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**: অ্যালিকোট যোগফল < সংখ্যা
  - 8 একটি deficient সংখ্যা, কারণ (1 + 2 + 4) = 7
  - মৌলিক সংখ্যাগুলো deficient

একটি প্রদত্ত সংখ্যা **perfect** কি না, তা নির্ণয় করার একটি উপায় বাস্তবায়ন করুন। আপনার প্রোগ্রামিং ভাষা অনুযায়ী, একটি প্রদত্ত সংখ্যা **abundant** নাকি **deficient**, সেটাও নির্ণয় করার উপায় আপনাকে বাস্তবায়ন করতে হতে পারে।
