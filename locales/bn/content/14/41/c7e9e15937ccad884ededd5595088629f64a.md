# নির্দেশনা

সাইফার হুইল হলো দুটি ডিস্ক, একটি অন্যটির ভেতরে, যা বর্ণমালাকে ঘুরিয়ে দেয়: এটিকে ৩-এ সেট করুন, তাহলে প্রতিটি বর্ণ তিন ঘর সামনের বর্ণ হয়ে যায়, আর `z` ঘুরে আবার `a`-তে ফিরে আসে। গোয়েন্দারা শতাব্দীর পর শতাব্দী ধরে এগুলি ব্যবহার করে এসেছেন। আপনি এখন একটি বানাচ্ছেন।

পাঁচটি কাজই `CIPHER_WHEEL` ক্লাসে রাখতে হবে।

## 1. এটি কি একটি বর্ণ?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. এটাকে চিৎকার করান

একটি ক্যারেক্টারের বড় হাতের রূপ রিটার্ন করুন। বর্ণ নয় এমন যেকোনো কিছু অপরিবর্তিত ফিরে আসে।

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. এর সংখ্যা কত?

একটি ক্যারেক্টারকে বোঝায় এমন সংখ্যাটি রিটার্ন করুন।

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. প্রথম ক্যারেক্টার

একটি স্ট্রিংয়ের প্রথম ক্যারেক্টার রিটার্ন করুন।

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. হুইলটি ঘোরান

একটি ছোট হাতের বর্ণ আর কত ঘর সরাতে হবে সেই সংখ্যা দেওয়া হলে, বর্ণমালায় সেই সংখ্যক ঘর সামনের বর্ণটি রিটার্ন করুন। `z` পেরিয়ে গেলে তা আবার `a`-তে ফিরে আসে।

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

ঋণাত্মক সংখ্যক ঘর দিয়ে পিছন দিকেও ঘোরানো যায়।

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

আপনি ধরে নিতে পারেন যে যে ক্যারেক্টারটি দেওয়া হচ্ছে সেটি একটি ছোট হাতের বর্ণ।
