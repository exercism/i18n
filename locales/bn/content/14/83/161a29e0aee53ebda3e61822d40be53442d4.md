# ভূমিকা

`MACRO:` ডিক্লারেশন `:` চিহ্নের মতো, তবে বডিটি *কম্পাইল টাইমে* রান হয় এবং একটি কোয়োটেশন রিটার্ন করতে হবে। কম্পাইলার ওই রিটার্ন করা কোয়োটেশনটি ম্যাক্রো কলের জায়গায় বসিয়ে দেয়। যেহেতু বডিটি সাধারণ Factor কোড, তাই ফলাফল কোয়োটেশনটি তৈরি করা মানে শুধু শব্দের সিকোয়েন্স ম্যানিপুলেট করা।

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

ম্যাক্রোর ইনপুটগুলো *কল সাইটে লিটারাল* হয়ে থাকে। কোনো নন-লিটারাল মান পাস করলে কম্পাইলার স্পেশালাইজ করতে অস্বীকার করবে, কারণ ম্যাক্রো বডির ওই মানটি কম্পাইল টাইমে দরকার, রানটাইমে নয়।

এর কাছাকাছি আরেকটি বিষয় হলো `<< … >>` পার্স-টাইম ইভালুয়েশন ব্লক, যা কোয়োটেশন রিটার্নের চুক্তি ছাড়াই কম্পাইল টাইমে যেকোনো Factor কোড রান করে। দুটোই Factor-এর [`macros`][macros] মেশিনারির অন্তর্গত।

[macros]: https://docs.factorcode.org/content/vocab-macros.html
