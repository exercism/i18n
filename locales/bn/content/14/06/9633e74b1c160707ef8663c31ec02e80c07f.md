# নির্দেশনা পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড ফলাফল স্ট্রিং |
| `$t0-9`  | টেম্পোরারি | যেকোনো | সাময়িক স্টোরেজের জন্য |
