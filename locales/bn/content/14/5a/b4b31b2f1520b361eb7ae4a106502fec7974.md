# পরিচিতি

Haxe-তে `class` হলো প্রধান ডেটা স্ট্রাকচার, যা ডেটা (ফিল্ড) আর আচরণ (মেথড) এনক্যাপসুলেট করে। ফিল্ড আর মেথড দুটোকেই ক্লাসের মেম্বার বলা হয়।

অ্যাক্সেস মডিফায়ার ব্যবহার করে মেম্বারগুলোর অ্যাক্সেস সীমিত করা যায়। এগুলো হলো:

- `public`: মেম্বারটি যেকোনো জায়গা থেকে অ্যাক্সেস করা যায়।
- `private`: মেম্বারটি কেবল একই ক্লাস থেকে অ্যাক্সেস করা যায়।

ক্লাসকে ইনস্ট্যান্স তৈরির টেমপ্লেট হিসেবে ভাবা যায়। একটি ইনস্ট্যান্স তৈরি করতে কেবল `new` কিওয়ার্ডটি ব্যবহার করুন:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

একটি ফিল্ড ডিফাইন করতে, একটি অ্যাক্সেস মডিফায়ারের পরে ভ্যারিয়েবলের নাম আর টাইপ লিখুন:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

ফিল্ড ডিফাইন করার সময় আপনি একটি প্রাথমিক মানও সেট করতে পারেন। কোনো ফিল্ডে প্রাথমিক মান উল্লেখ না থাকলে, সেটি `null` মান নেবে। ডট নোটেশনের সাহায্যে একটি ফিল্ড অ্যাক্সেস করতে পারেন:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
