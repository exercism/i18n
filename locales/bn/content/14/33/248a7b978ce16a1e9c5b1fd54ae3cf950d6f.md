# ইনস্টলেশন

এই ট্র্যাকটি ReScript 12 ব্যবহার করে এবং এতে [Node.js][nodejs] 22 বা তার চেয়ে নতুন সংস্করণ লাগবে। অনেক সিস্টেমেই এটি আগে থেকেই ইনস্টল করা থাকতে পারে, কিংবা আপনি হয়তো আগে অন্য কোনো ট্র্যাকের জন্য এটি ইনস্টল করে রেখেছেন।

একটি টার্মিনাল খুলে চালান:

```sh
node -v
```

Node ইনস্টল করা না থাকলে বা পুরোনো কোনো সংস্করণ দেখানো হলে, আপনার প্ল্যাটফর্মের জন্য [Node.js-এর অফিসিয়াল ইনস্টলেশন][nodejs-install] নির্দেশনা অনুসরণ করুন।

## ডিপেন্ডেন্সি ইনস্টল করা

প্রতিটি ReScript অনুশীলনী একটি স্বয়ংসম্পূর্ণ npm প্রজেক্ট। [Exercism CLI][exercism-cli] দিয়ে একটি অনুশীলনী ডাউনলোড করার পর, ReScript-সহ প্রজেক্টের ডিপেন্ডেন্সিগুলো ইনস্টল করে নিলেই আপনি কাজ শুরু করতে পারবেন:

```sh
cd /path/to/exercise
npm install
```
