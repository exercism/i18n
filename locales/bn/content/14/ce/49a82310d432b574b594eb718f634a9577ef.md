# জ্বালানি ভাতা

## সমস্যার বিবরণ

ABC Corp-এর প্রত্যেক কর্মচারী সীমাহীন জ্বালানি ভাতা পান। কর্মচারীরা যখনই তাদের গাড়িতে জ্বালানি ভরেন, তখনই একটি রেকর্ড পাঠাতে হয়। এই রেকর্ডগুলো একই CSV ফাইলে যুক্ত হয় এবং মাসের শেষে প্রক্রিয়া করা হয়।

ডিজিটাল অপারেশনস টিমের একজন সদস্য হিসেবে আপনার কাজ হলো এই CSV ফাইলটি পড়া এবং ফলাফলগুলো আরেকটি CSV ফাইলে লেখা। আউটপুট ফাইলে প্রত্যেক কর্মচারীর জন্য নিচের তথ্যসহ একটি এন্ট্রি থাকা উচিত:

- কর্মচারীর নম্বর
- জ্বালানি ভরার সংখ্যা
- মোট জ্বালানি খরচ
- মোট গ্যালন
- মোট অর্জিত মাইল

আপনাকে দুটি `string` আর্গুমেন্ট দেওয়া হয়েছে।

1. ইনপুট CSV ফাইলের পাথ
1. আউটপুট CSV ফাইলের পাথ

ইনপুট CSV ফাইলে `n` সংখ্যক লাইন থাকে, এবং প্রতিটি লাইন নিচের রূপ নেয়।

| কলামের নাম      | Ballerina টাইপ |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

আউটপুট ফাইলে প্রত্যেক কর্মচারীর জন্য একটি এন্ট্রি থাকা উচিত, যা `employee_id` অনুসারে ঊর্ধ্বক্রমে সাজানো। প্রতিটি লাইন নিচের রূপ নেয়:

| কলামের নাম      | Ballerina টাইপ |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## সীমাবদ্ধতা

- ইনপুট CSV ফাইলে লাইনের সংখ্যা `n`: 2 <= n <= 1000
- কোম্পানির কর্মচারীর সংখ্যা: ৯৭
- জ্বালানির দাম প্রতি গ্যালনে ধরা হয়
- কোনো ফিল-আপ রেকর্ড বাদ পড়েনি
