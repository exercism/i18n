# পরিচিতি

## অ্যারে

অ্যারে Elixir ভাষায় বিল্ট-ইন। এগুলোকে একটি বেসিক টাইপ ধরা হয়, যা স্কোয়ার ব্র্যাকেট দিয়ে লেখা হয়। অ্যারে খালি থাকতে পারে, আবার যেকোনো টাইপের যেকোনো সংখ্যক আইটেম ধারণ করতে পারে। যেমন:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir অ্যারে ইমপ্লিমেন্ট করে লিংকড অ্যারে হিসেবে, যেখানে প্রতিটি নোড দুটি মান সংরক্ষণ করে: প্রথম আইটেম, আর বাকি সব আইটেম নিয়ে গঠিত আরেকটি অ্যারে। অ্যারের প্রথম আইটেমটিকে বলা হয় _হেড_ আর বাকি আইটেমগুলোর অ্যারেটিকে বলা হয় _টেল_। কোডে আমরা এই নোটেশনটি ব্যবহার করতে পারি:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

আমরা _`[head | tail]`_ নোটেশন ব্যবহার করে একটি অ্যারের শুরুতে এলিমেন্ট যোগ করতে পারি:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

অ্যারে নিয়ে কাজ করার জন্য `Kernel` মডিউলে বেশ কিছু ফাংশন আছে, আর আছে পুরো `List` মডিউল।

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
