# নির্দেশনা

ইজি পাখি দেখার খুব শখের একজন মানুষ, যিনি প্রতিদিন তাঁর বাগানে কতগুলো পাখি এসেছে তা হিসাব করে রাখেন।

তিনি আপনাকে অনুরোধ করেছেন, তাঁর পাখি দেখার কাজটিকে নতুন একটি স্তরে নিয়ে যেতে এবং ডেটা ট্র্যাক ও প্রসেস করতে সাহায্য করবে এমন কয়েকটি টুল বানিয়ে দিতে।

আপনি ডেটাটি ইন্টিজারের একটি অ্যারে হিসেবে রাখার সিদ্ধান্ত নিয়েছেন। অ্যারেটির প্রথম সংখ্যাটি হলো আজ আপনার বাগানে আসা পাখির সংখ্যা, দ্বিতীয়টি গতকালের, এবং এভাবেই পরেরগুলো।

## 1. আজ কতগুলো পাখি এসেছে তা যাচাই করুন

`today` ফাংশনটি বানান। এটি প্রতিদিনের পাখি সংখ্যার একটি অ্যারে নেবে এবং আজকের সংখ্যাটি রিটার্ন করবে। অ্যারেটি খালি হলে এটি `0` রিটার্ন করবে।

```gleam
today([2, 5, 1])
// -> 2
```

## 2. আজকের সংখ্যাটি এক বাড়ান

`increment_day_count` ফাংশনটি বানান। এটি প্রতিদিনের পাখি সংখ্যার একটি অ্যারে নেবে এবং আজকের সংখ্যাটি ১ বাড়িয়ে দেবে। অ্যারেটি খালি হলে `[1]` রিটার্ন করবে।

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. এমন কোনো দিন ছিল কি না যেদিন একটিও পাখি আসেনি, তা যাচাই করুন

`has_day_without_birds` ফাংশনটি বানান। এটি প্রতিদিনের পাখি সংখ্যার একটি অ্যারে নেবে। বাগানে অন্তত একটি দিন যদি কোনো পাখি না এসে থাকে, তাহলে এটি `True` রিটার্ন করবে, অন্যথায় `False`। অ্যারেটি খালি হলে, এটি বোঝাবে যে _এখনো_ কোনো পাখি রেকর্ড করা হয়নি; সেক্ষেত্রে `False` রিটার্ন করুন।

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. মোট কতগুলো পাখি এসেছে তা হিসাব করুন

`total` ফাংশনটি বানান। এটি প্রতিদিনের পাখি সংখ্যার একটি অ্যারে নেবে এবং আপনি ডেটা সংগ্রহ শুরু করার পর থেকে আপনার বাগানে আসা পাখির মোট সংখ্যা রিটার্ন করবে।

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্যদিনের চেয়ে বেশি ব্যস্ত থাকে। যে দিনে আপনার বাগানে পাঁচটি বা তার বেশি পাখি আসে, সেদিন ব্যস্ত দিন।

`busy_days` ফাংশনটি বানান। এটি প্রতিদিনের পাখি সংখ্যার একটি অ্যারে নেবে এবং ব্যস্ত দিনের সংখ্যা রিটার্ন করবে।

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
