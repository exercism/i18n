# শেখা

Groovy দিয়ে শুরু করতে চান, নাকি অনুশীলনী করতে করতে আরও শিখতে চান?

Groovy চালিয়ে দেখার কয়েকটি উপায়:

* [অনলাইন ইন্টারপ্রেটার ব্যবহার করে একটি ব্রাউজারে](https://www.jdoodle.com/execute-groovy-online)
* কমান্ড লাইনে `groovyConsole` লিখে [Groovy Console](http://groovy-lang.org/groovyconsole.html)
* কমান্ড লাইনে `groovysh` লিখে [Groovy Shell](http://groovy-lang.org/groovyconsole.html)

Groovy-এর দ্রুত পরিচিতি নেওয়ার উপায়:

* Tim Rows-এর [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/), Java না জানা ডেভেলপারদের জন্যও সমান উপকারী
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* SmartThings-এর [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html)
* JDriven-এর কয়েকটি [online Groovy Koans](http://www.groovy-koans.org/)

আরও গভীরে যাওয়ার উপায়:

* [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), Groovy-এর _The Book_
* Ken Kousen-এর [Making Java Groovy](https://www.manning.com/books/making-java-groovy)
