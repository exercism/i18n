# পরিচিতি

F#-এ অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং করার মূল গঠন হল ক্লাস।

F#-এ একটি ক্লাস গড়ে ওঠে তার ফিল্ড আর মেথড দিয়ে। একটি ক্লাসের ফিল্ড ও মেথডগুলোকে একসাথে বলা হয় তার _মেম্বার_।

F#-এ ক্লাস ডিফাইন করা হয় `type` কিওয়ার্ড দিয়ে। মেথড ডিফাইন করা হয় `member` কিওয়ার্ড দিয়ে, আর এগুলো সবসময় পাবলিক। (প্রাইভেট) ফিল্ড ডিফাইন করতে `let` বাইন্ডিং ব্যবহার করা যায়।

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

ক্লাস হলো অবজেক্ট তৈরির টেমপ্লেট। একটি ক্লাসের ইনস্ট্যান্স তৈরি করতে ক্লাসের নামটি একটি ফাংশন হিসেবে কল করুন। একটি ক্লাসের ইনস্ট্যান্সকেও বলা হয় _অবজেক্ট_।

ডট নোটেশন ব্যবহার করে একটি অবজেক্টের মেম্বারগুলো অ্যাক্সেস করা যায়।

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
