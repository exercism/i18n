# পরিচিতি

Gleam-এ একটি `case` এক্সপ্রেশন দিয়ে শর্তসাপেক্ষে কোড চালানো যায়। একটি `case` এক্সপ্রেশনে একটি মানকে এক বা একাধিক _প্যাটার্ন_-এর সাথে মিলিয়ে যাচাই করা যায়। এমন একটি প্যাটার্নের উদাহরণ হল _লিটারাল প্যাটার্ন_, যা একটি মানকে একটি লিটারাল মানের (যেমন `1` বা `"hello"`) সাথে মেলায়।

`case` এক্সপ্রেশন লেখা হয় `case` কিওয়ার্ড দিয়ে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

যদিও এটি অন্য ভাষার `switch` স্টেটমেন্টের মতো দেখতে পারে, তবুও অন্য প্যাটার্নও ব্যবহার করলে প্যাটার্ন ম্যাচিংয়ের আসল সুবিধা ফুটে ওঠে। এমনই একটি প্যাটার্ন হল _ভ্যারিয়েবল প্যাটার্ন_, যা দিয়ে একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করা যায়। এই উদাহরণে, `number` যদি `0` না হয়, তাহলে `i` ভ্যারিয়েবলটিতে `number`-এর মান অ্যাসাইন করা হবে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

কিছু ক্ষেত্রে আপনি একটি প্যাটার্নে একটি অতিরিক্ত শর্ত যোগ করতে চাইতে পারেন। এটিকে _গার্ড_ (ক্লজ) বলা হয়, যা `if` কিওয়ার্ড দিয়ে যোগ করা যায়:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

পারফরম্যান্সের কারণেই গার্ডে কেবল মৌলিক গাণিতিক ও বুলিয়ান অপারেটর ব্যবহার করা যায়, গার্ডে অন্য কোনো ফাংশন ব্যবহার করা যায় না।

উপরের উদাহরণে, সম্ভাব্য সব ইনপুটের জন্যই মিলে যাওয়া প্যাটার্ন থাকবে না। কম্পাইলার এটি শনাক্ত করবে এবং একটি এরর দেখাবে। এটিকে _এক্সহস্টিভ চেকিং_ বলা হয়। এই সতর্কবার্তা দূর করতে হলে সব ক্ষেত্র সামলাতে হয়। এর জন্য ব্যবহার করা যায় _ডিসকার্ড প্যাটার্ন_, যা যেকোনো মানের সাথে মেলে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

`case` এক্সপ্রেশন একটি মানকে উপর থেকে নিচে প্রতিটি প্যাটার্নের সাথে যাচাই করে, যতক্ষণ না মিলে যাওয়া কোনো প্যাটার্ন খুঁজে পায় এবং সেই প্যাটার্নের সাথে সম্পর্কিত লজিক চালায়। প্যাটার্নের ক্রম গুরুত্বপূর্ণ!
