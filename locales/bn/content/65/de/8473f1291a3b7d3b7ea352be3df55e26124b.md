# সম্পর্কে

একটি টাইপ ডেফিনিশন একটি নতুন নামযুক্ত টাইপ তৈরি করে, যা অন্য প্রতিটি টাইপ থেকে আলাদা, এমনকি একই আন্ডারলাইং টাইপবিশিষ্ট অন্য টাইপ থেকেও।

## টাইপ ডিফাইন করা

একটি টাইপ ডেফিনিশন শুরু হয় `type` কিওয়ার্ড দিয়ে, তারপর আসে নতুন টাইপের নাম ও তার আন্ডারলাইং টাইপ:

```go
type File []bool
```

এখানে `File` বলতে দাবাবোর্ডের একটি খাড়া কলাম বোঝায়, যাকে সাধারণত A থেকে H পর্যন্ত লেবেল করা হয়।
এই কলামের প্রতিটি ঘর একটি বুলিয়ান মান দিয়ে প্রকাশ করা হয়, যা দিয়ে বোঝানো হয় ঘরটি দখল করা আছে কি না।
এখন যেহেতু `File` ডিফাইন করা হয়েছে, আমরা এটিকে অন্য ডেফিনিশনের ভেতরে ব্যবহার করতে পারি:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` ফাইলের আইডেন্টিফায়ারগুলোকে `File` মানের সাথে ম্যাপ করে।
প্রতিটি `File` হলো বুলিয়ানের একটি স্লাইস, যা দাবার একটি ফাইলের ঘরগুলো প্রকাশ করে।
এই টাইপ ডেফিনিশনগুলো না থাকলে `board` হতো একটি `map[string][]bool`, যার ফলে আমরা কী প্রকাশ করছি তা বোঝা আরও কঠিন হয়ে যেত।

## ডিফাইন করা টাইপ আলাদা

যদিও `Score` ও `int` দুটোই ইন্টিজার মান ধারণ করে, তাদের মধ্যে কনভার্ট করতে একটি স্পষ্ট কনভার্সন প্রয়োজন:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` একটি আনটাইপড কনস্ট্যান্ট, তাই এটি সরাসরি একটি `Score` ভ্যারিয়েবলে অ্যাসাইন করা যায়।

ডিফাইন করা টাইপের মেথডও থাকতে পারে, যা মেথড ধারণায় আলোচনা করা হয়েছে।

## স্ট্রাক্ট টাইপ

স্ট্রাক্ট ডেফিনিশনও একই `type` কিওয়ার্ড ব্যবহার করে:

```go
type Player struct {
    Name  string
    Score Score
}
```

স্ট্রাক্ট টাইপ নিয়ে আলোচনা করা হয়েছে স্ট্রাক্ট ধারণায়।

## টাইপ অ্যালিয়াস

একটি টাইপ অ্যালিয়াস নতুন টাইপ তৈরি না করে বরং একটি বিদ্যমান টাইপের আরেকটি নাম তৈরি করে।
যেহেতু একটি অ্যালিয়াস ও তার মূল টাইপ অভিন্ন, তাই তাদের মান পরস্পরের বদলে ব্যবহার করা যায়।
অ্যালিয়াস ডিক্লেয়ার করা হয় `type` কিওয়ার্ড, অ্যালিয়াসের নাম, সমান চিহ্ন (`=`) ও বিদ্যমান টাইপ দিয়ে।

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
