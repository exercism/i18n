# GitHub-এর মাধ্যমে অবদান রাখা

Exercism-এর কোডবেসে অবদান রাখা হয় [GitHub][github]-এর মাধ্যমে।

নাম থেকেই বোঝা যায়, GitHub তার ভার্সন কন্ট্রোল সিস্টেম হিসেবে [git][git] ব্যবহার করে।
আপনি যদি Git-এর সাথে অপরিচিত হন, তাহলে অনলাইনে সেরা রিসোর্স হলো [Pro Git][pro-git]।

আপনি যদি GitHub এবং অবদান রাখার কার্যপ্রবাহের সাথে পরিচিত না হন, তাহলে শুরু করার জন্য এই রিসোর্সগুলো সহায়ক হতে পারে:

- [GitHub-এর পরিচিতি - ইন্টারঅ্যাকটিভ কোর্স][github-course]
- [GitHub-এ কীভাবে একটি Pull Request তৈরি করবেন - টিউটোরিয়াল][pr-tutorial]
- [কীভাবে একটি সহজ GitHub PR তৈরি করবেন - anthonywritescode-এর ভিডিও][anthonywritescode]

## নির্দেশিকা

আপনার অবদান যে স্বাগত, তা নিশ্চিত করার বিষয়ে আরও পড়তে পারেন [কীভাবে একটি দুর্দান্ত Pull Request তৈরি করবেন][great-pr] নির্দেশিকায়।

আমাদের কাছে Exercism-নির্দিষ্ট বেশ কিছু Pull Request নির্দেশিকাও আছে:

- [কীভাবে একটি দুর্দান্ত Pull Request তৈরি করবেন][how-to-make-a-great-pr]
- [Pull Request নিয়ে অবদানকারীদের নির্দেশিকা][contributors-pr-guide]
- [Pull Request নিয়ে মেইনটেইনারদের নির্দেশিকা][maintainers-pr-guide]
- [মেইনটেইনারদের জন্য রিপোজিটরি পারমিশন][maintainers-repo-permissions]
