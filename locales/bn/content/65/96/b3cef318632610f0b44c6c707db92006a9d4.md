# পরিচিতি

একটি `:` ডেফিনিশন সরাসরি নিজেকেই কল করতে পারে। Factor-এর কম্পাইলার অন্য যেকোনো ওয়ার্ডের মতোই রিকার্সিভ ওয়ার্ডের স্ট্যাক ইফেক্ট অনুমান করে। সাধারণ রিকার্শনের জন্য আলাদা কোনো ঘোষণার প্রয়োজন নেই।

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

এই দুই অংশ হলো রিকার্শনের *বেস কেস* (এখানে খালি সিকোয়েন্সের যোগফল `0`) আর *রিকার্সিভ ধাপ* (একটি এলিমেন্ট আলাদা করে বাকিগুলোর উপর রিকার্স করে ফলাফলগুলো একত্র করা)।

সিকোয়েন্স রিকার্শনের স্বাভাবিক সহচর হলো `if-empty` আর `unclip`। `if-empty ( seq emptyquot nonemptyquot -- )` সিকোয়েন্সের উপর নির্ভর করে দুটি কোয়োটেশনের একটি চালায়। আর `unclip` প্রথম এলিমেন্টটি সরিয়ে দেয়, যাতে রিকার্সিভ ধাপের হাতে আরও সহজ কিছু থাকে।
