# ভূমিকা

## অ্যাক্সেস বিহেভিয়ার

Elixir code _বিহেভিয়ার_ ব্যবহার করে কমন জেনেরিক ইন্টারফেস প্রদান করতে, একই সাথে যে প্রতিটি মডিউল এটি ইমপ্লিমেন্ট করে তার জন্য নির্দিষ্ট ইমপ্লিমেন্টেশন সহজ করে। এরকম একটি কমন উদাহরণ হলো _অ্যাক্সেস বিহেভিয়ার_।

_অ্যাক্সেস বিহেভিয়ার_ একটি কী (key)-ভিত্তিক ডেটা স্ট্রাকচার থেকে ডেটা আনার জন্য একটি কমন ইন্টারফেস প্রদান করে। _অ্যাক্সেস বিহেভিয়ার_ ম্যাপ ও কিওয়ার্ড লিস্টের জন্য ইমপ্লিমেন্ট করা হয়েছে, তবে এটির ব্যবহার বুঝতে চলুন ম্যাপের ক্ষেত্রে এটি দেখি। _অ্যাক্সেস বিহেভিয়ার_ বলে যে, যখন আপনার একটি ম্যাপ থাকে, তখন আপনি এটির পরে _তৃতীয় বন্ধনী_ দিয়ে, তারপর কী (key) ব্যবহার করে সেই কী (key)-এর সাথে সম্পর্কিত মানটি পেতে পারেন।

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

ডেটা স্ট্রাকচারে যদি কী (key) না থাকে, তাহলে `nil` রিটার্ন করা হয়। এটি অনিচ্ছাকৃত আচরণের কারণ হতে পারে, কারণ এটি কোনো এরর রেইজ করে না। লক্ষ্য করুন, `nil` নিজেই অ্যাক্সেস বিহেভিয়ার ইমপ্লিমেন্ট করে এবং যেকোনো কী (key)-এর জন্য সর্বদা `nil` রিটার্ন করে।
