# readonly ক্লাস ও প্রপার্টি

readonly ক্লাস ও প্রপার্টি দিয়ে ক্লাসে সহজে ব্যবহারের জন্য public প্রপার্টি নির্দিষ্ট করা যায়, কিন্তু সেগুলো বদলানো আটকে দেওয়া হয়। কোনো প্রপার্টিকে readonly ঘোষণা করতে হলে টাইপ লেখার আগে `readonly` যোগ করতে হয়। প্রপার্টিটিতে একবারই মান বসানো যায়, কিন্তু মানটি আবার বসাতে বা বদলাতে গেলে Error দেখা দেবে।

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

readonly ক্লাস এই আচরণের উপরেই গড়া: ক্লাসটিকে `readonly` হিসেবে ঘোষণা করলে প্রতিটি প্রপার্টিতেই readonly ঘোষণাটি প্রযোজ্য হয়। এর সঙ্গে এটি ডাইনামিক প্রপার্টি যোগ করা আটকে দেয়।

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
