# পরিচিতি

## এক্সেপশন

C#-এ এক্সেপশন রানটাইমে ঘটা এরর পরিস্থিতি সামলানোর একটি সুসংগঠিত, অভিন্ন ও টাইপ-সেফ উপায় দেয়। অ্যাপ্লিকেশন ক্র্যাশ আটকাতে চাইলে এক্সেপশন ও এরর সঠিকভাবে সামলানো জরুরি।

C#-এ সব এক্সেপশনের বেস টাইপ হলো `System.Exception` ক্লাস। এতে `Message`-এর মতো গুরুত্বপূর্ণ প্রোপার্টি থাকে, যেখানে এক্সেপশনটি থ্রো হওয়ার কারণের মানুষের পড়ার উপযোগী একটি বর্ণনা থাকে।

কোডের কোনো নির্দিষ্ট অংশে একটি এরর আছে বোঝাতে হলে `throw` কিওয়ার্ড ব্যবহার করে নতুন একটি এক্সেপশন অবজেক্ট তৈরি করতে হবে এবং সেটি থ্রো করতে হবে:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

কোনো এক্সেপশন থ্রো হলে, সেই এক্সেপশন সামলানোর দায়িত্বে থাকা কোডের অংশটি খুঁজে বের করার কাজ রানটাইমকে করতে হয়। যদি উপযুক্ত কোনো হ্যান্ডলার না পাওয়া যায়, তবে রানটাইম প্রোগ্রামের এক্সিকিউশন বন্ধ করার পাশাপাশি আনহ্যান্ডলড এক্সেপশনের মেসেজটি দেখায়।

এক্সেপশনের জন্য হ্যান্ডলার তৈরি করতে C# ব্যবহার করে try-catch স্টেটমেন্ট, যা একটি `try` ব্লক এবং এক বা একাধিক `catch` ক্লজ নিয়ে গঠিত। `try` ব্লকে এমন কোড থাকা উচিত যা এক্সেপশন থ্রো করতে পারে, আর এই ব্লকটিই সেই কোডকে পাহারা দেয়। `catch` ক্লজগুলোতে এমন কোড থাকা উচিত যা এরর হওয়ার পর প্রোগ্রামের আচরণ সামলায়। খেয়াল রাখা জরুরি যে `try` ব্লকের পরে এক্সেপশনগুলোর ক্রম গুরুত্বপূর্ণ, কারণ একাধিক এক্সেপশন তালিকাভুক্ত থাকলে প্রথম মিলে যাওয়া `catch` ক্লজটিই এক্সিকিউট হয়।

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
