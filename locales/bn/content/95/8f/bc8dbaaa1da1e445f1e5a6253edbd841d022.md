# সম্পর্কে

একটি কালেকশন ডেফিনিশনে সাধারণত অ্যাঙ্গেল ব্র্যাকেটের ভেতরে একটি প্লেসহোল্ডার থাকে, প্রথা অনুসারে যার নাম প্রায়ই T হয়। এমন কালেকশনকে জেনেরিক টাইপ বলা হয়। এটি কালেকশনের ব্যবহারকারীকে কালেকশনে কোন ধরনের আইটেম সংরক্ষণ করবেন তা নির্দিষ্ট করার সুযোগ দেয়। উপরের উদাহরণ কোডে আমরা স্ট্রিং-এর একটি অ্যারে ইনস্ট্যান্টিয়েট করছি।

একটি ক্লাস বা ফাংশনকে **জেনেরিক** করা হয় `@:generic` অ্যাট্রিবিউট ব্যবহার করে। এর ফলে কম্পাইলার ক্লাসটি বা ফাংশনটিকে জেনেরিক হিসেবে চিহ্নিত করে:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
