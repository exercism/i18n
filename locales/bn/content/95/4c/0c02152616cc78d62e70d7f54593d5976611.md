# পরিচিতি

টাপল অন্য টাপলকে এক্সটেন্ড করতে পারে। `TUPLE: child < parent slots ;` একটি ক্লাস ডিক্লেয়ার করে যার ইনস্ট্যান্সগুলোও `parent` ক্লাসের ইনস্ট্যান্স, তারা নিজেদের স্লটের সঙ্গে প্যারেন্টের স্লটও পায়, আর প্যারেন্টের অ্যাক্সেসরগুলোও তাদের উপর কাজ করে, ঠিক যেন সেগুলো চাইল্ড ক্লাসে ডিফাইন করা হয়েছিল।

```factor
USING: accessors ;

TUPLE: animal name age ;
TUPLE: dog < animal breed ;

"Rex" 4 "labrador" dog boa .
! => T{ dog { name "Rex" } { age 4 } { breed "labrador" } }

"Rex" 4 "labrador" dog boa name>> .   ! => "Rex"   (inherited accessor)
```

## `boa` স্লটের ক্রম

`boa` কনস্ট্রাক্টর স্লটগুলো নেয় *ডিক্লারেশনের ক্রমে, প্যারেন্ট আগে*। উপরের `dog` ক্লাসের জন্য:

```
dog boa ( name age breed -- dog )
```

এর একটি নাতনি ক্লাস `puppy < dog ` যদি `weeks` যোগ করত, তবে সেটি হতো:

```
puppy boa ( name age breed weeks -- puppy )
```

## প্রেডিকেট অনুক্রম

প্রতিটি `TUPLE:` ডিক্লারেশন একটি প্রেডিকেট (`name?`) তৈরি করে। ইনহেরিট্যান্সের ক্ষেত্রে প্রেডিকেটগুলো নেস্ট হয়, অর্থাৎ প্রতিটি ডেসেন্ড্যান্ট তার পূর্বপুরুষদের প্রেডিকেট পূরণ করে:

```factor
"Rex" 4 "labrador" dog boa
dup dog? .        ! => t
dup animal? .     ! => t
```

উল্টোটা সত্য নয়: যে `animal` কোনো `dog` নয়, সেটি `dog?` প্রেডিকেটে ফেল করে।

## পরবর্তী বিষয়ে নোট

জেনেরিক মেথডগুলোও (`M:`, যা [`generics`][generics] অনুশীলনীতে শেখানো হয়) অনুক্রমের উপরের দিকেও ডিসপ্যাচ করে। `animal` ক্লাসের একটি মেথড প্রতিটি ডেসেন্ড্যান্টের জন্য চলে, যদি না আরও নির্দিষ্ট কোনো ওভাররাইড অগ্রাধিকার পায়। এই অনুশীলনীর ঠিক পরেই আপনি সেটি `boatswains-bilge`-এ দেখতে পাবেন।
