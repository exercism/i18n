# স্টেটসহ ক্লাস

এতদিনের প্রতিটি ক্লাস ছিল রুটিনের একটি বাক্স। প্রত্যেকে তার আর্গুমেন্ট নিত, একটি উত্তর বের করত আর সবকিছু ভুলে যেত।

ক্লাস বরং জিনিসপত্র **মনে রাখতে** পারে। একটি স্কোরবোর্ডকে তা রাখতেই হয়: গেম শুরু হওয়ার পরের প্রতিটি গোলের উপর এখন স্কোর নির্ভর করে।

## অ্যাট্রিবিউট

`attr` একটি ক্লাসকে মনে রাখার মতো কিছু দেয়।

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

প্রতিটি `attr` একটি রুটিনে পরিণত হয় যা মানটি পড়ে, আর আরেকটি যা তা বদলায়:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

একই টাইপের অ্যাট্রিবিউট একই ডিক্লারেশনে ভাগ করে নিতে পারে, যেমনটি আর্গুমেন্টের ক্ষেত্রে হয়:

```sather
   attr home_score, away_score : INT;
```

## অবজেক্ট

অ্যাট্রিবিউটসহ একটি ক্লাস **অবজেক্ট** বানানোর একটি ছাঁচ। প্রতিটি অবজেক্টের কাছে অ্যাট্রিবিউটগুলোর নিজস্ব কপি থাকে, তাই দুটি স্কোরবোর্ড দুটি স্কোর আলাদা রাখে।

`new` একটি অবজেক্ট তৈরি করে। এটি `create` নামের একটি রুটিনের ভেতরে থাকে, যা তারপর অবজেক্টটি ভরিয়ে ফেরত দেয়:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` মানে "এই ক্লাসটি"। সেখানে `SCOREBOARD` লিখলে একই কথা বোঝাত, কিন্তু ক্লাসটির নাম বদলালেও `SAME` কাজ করতে থাকে।

## একটি তৈরি করা

`#` আসলে `create`-কে কল করে:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

`rehearsal-script` থেকে আপনি `#` ব্যবহার করে আসছেন। `#FSTR` আসলে ঠিক এটাই।

## যে রুটিনগুলো অবজেক্ট বদলায়

ক্লাসের ভেতরে অ্যাট্রিবিউটকে সামনে কোনো অবজেক্ট না দিয়ে শুধু নাম ধরে ব্যবহার করা হয়। এটি বোঝায় সেই অবজেক্টকে, যার উপর রুটিনটি কল করা হয়েছিল।

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` কোনো রিটার্ন টাইপ ঘোষণা করে না, কারণ এটি কোনো উত্তর দেয় না, বরং অবজেক্টটিই বদলে দেয়। এটিকে একটি স্টেটমেন্ট হিসেবে কল করুন:

```sather
   board.home_goal;
```

## অ্যাট্রিবিউট শুরুতেই খালি

কেউ না-সেট-করা অ্যাট্রিবিউট একটি `INT`-এর জন্য শূন্য, `BOOL`-এর জন্য `false`, আর একটি স্ট্রিং বা অবজেক্টের জন্য ভয়েড ধরে রাখে। তাই নতুন একটি স্কোরবোর্ড কেউ কিছু না বললেও 0 থেকে 0 দেখায়।
