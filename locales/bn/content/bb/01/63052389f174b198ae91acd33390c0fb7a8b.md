# পরিচিতি

## কেস এক্সপ্রেশন

Gleam-এ `case` এক্সপ্রেশন দিয়ে শর্তসাপেক্ষে কোড চালানো যায়। একটি কেস এক্সপ্রেশন ব্যবহার করে একটি মানকে এক বা একাধিক _প্যাটার্ন_-এর সাথে মেলানো যায়। এমন একটি প্যাটার্নের উদাহরণ হলো _লিটারেল প্যাটার্ন_, যা কোনো মানকে একটি নির্দিষ্ট লিটারেল মানের (যেমন `1` বা `"hello"`) সাথে মেলায়।

কেস এক্সপ্রেশন লেখা হয় `case` কিওয়ার্ড দিয়ে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

এটি অন্য ভাষার `switch` স্টেটমেন্টের মতো দেখালেও, অন্য প্যাটার্নও ব্যবহার করলে প্যাটার্ন ম্যাচিংয়ের আসল শক্তি বোঝা যায়। এমনই একটি প্যাটার্ন হলো _ভ্যারিয়েবল প্যাটার্ন_, যা দিয়ে একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করা যায়। এই উদাহরণে, `number` যদি `0` না হয়, তাহলে `i` ভ্যারিয়েবলটিতে `number`-এর মানটি অ্যাসাইন করা হবে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

কিছু ক্ষেত্রে আপনি একটি প্যাটার্নে একটি অতিরিক্ত শর্ত যোগ করতে চাইতে পারেন। এটিকে _গার্ড_ (ক্লজ) বলা হয়, যা `if` কিওয়ার্ড দিয়ে যোগ করা যায়:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

পারফরম্যান্সের কারণে গার্ডে শুধু মৌলিক গাণিতিক ও বুলিয়ান অপারেটর ব্যবহার করা যায়; গার্ডে অন্য কোনো ফাংশন ব্যবহার করা যায় না।

উপরের উদাহরণে, সম্ভাব্য সব ইনপুটের জন্যই মিলে যাওয়া প্যাটার্ন থাকবে না। কম্পাইলার এটি ধরে ফেলবে এবং একটি এরর দেখাবে। এটিকে _এক্সহস্টিভ চেকিং_ বলা হয়। এই সতর্কবার্তা দূর করতে হলে সব কেস সামলাতে হবে। এর জন্য _ডিসকার্ড প্যাটার্ন_ ব্যবহার করা যায়, যা যেকোনো মানের সাথে মেলে:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

একটি ক্লজে একাধিক প্যাটার্নের সাথে মেলানো যায়, প্রতিটি প্যাটার্ন আলাদা করতে `|` ব্যবহার করা হয়। একটি ক্লজে কেবল একটি গার্ড যোগ করা যায়:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

কেস এক্সপ্রেশন একটি মানকে উপর থেকে নিচে প্রতিটি প্যাটার্নের সাথে যাচাই করে, যতক্ষণ না মিলে যাওয়া একটি প্যাটার্ন পায় এবং সেই প্যাটার্নের সাথে যুক্ত লজিক চালায়। প্যাটার্নের ক্রম গুরুত্বপূর্ণ!
