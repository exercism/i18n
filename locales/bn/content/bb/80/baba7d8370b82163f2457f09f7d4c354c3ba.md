# ভূমিকা

## ক্যারেক্টার

Java-এর `char` প্রিমিটিভ টাইপ হলো একটি একক ক্যারেক্টারের ১৬ বিটের রূপ।
একাধিক `char` মিলে একটি স্ট্রিং গঠন করতে পারে, যেমন `"word"`, অথবা `char`গুলোকে আলাদাভাবে প্রসেস করা যেতে পারে।
একটি `char` লিটারাল একক উদ্ধৃতি চিহ্নের ভেতরে থাকে (যেমন `'A'`)।

```java
char lowerA = 'a';
char upperB = 'B';
```

## একটি `String`-এর `char`গুলো পাওয়া

`String.toCharArray` মেথডটি একটি `String`-এর `char`গুলোকে অ্যারে হিসেবে রিটার্ন করে।
অ্যারে অংশে বলা হয়েছে, আপনি অ্যারের ওপর ইটারেশন করতে একটি `for` লুপ ব্যবহার করতে পারেন।

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Character ক্লাস

`char` পরীক্ষা ও ম্যানিপুলেট করার জন্য অনেক বিল্ট-ইন লাইব্রেরি মেথড আছে।
এগুলো `java.lang.Character` ক্লাসের স্ট্যাটিক মেথড হিসেবে পাওয়া যায়।
এখানে কিছু উদাহরণ:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## একটি `String`-এ `char` যোগ করা

`+` অপারেটর দিয়ে একটি `String`-এ `char` যোগ করা যায়।

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
দুটি `char` জোড়া লাগিয়ে একটি `String` তৈরি করতে `+` ব্যবহার করবেন _না_, সেদিকে খেয়াল রাখুন!
এইভাবে দুটি `char` যোগ করলে একটি `int` পাওয়া যায়, একটি `String` _নয়_!
উদাহরণস্বরূপ:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

এর কারণ, Java `char`-কে `int`-এ প্রমোট করে (দেখুন [4.2 প্রিমিটিভ টাইপ ও ভ্যালু ][jls-primitives], যা [Java Language Specification][jls-main]-এ আছে)।

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

তবে যখন যোগ করার জন্য অনেক ক্যারেক্টার থাকে, তখন পরিবর্তে একটি `StringBuilder` ব্যবহার করা আরও দক্ষ হতে পারে:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
