# সম্পর্কে

C# টাইপ ক্লাস বা স্ট্রাক্টের স্কোপের ভেতরে ডিফাইন করা যায়। যে টাইপটি ঘিরে রাখে, সেটি এক ধরনের নেমস্পেসের কাজ করে। টাইপটিতে অ্যাক্সেস করা হয় ঘিরে রাখা টাইপের মাধ্যমে, ডট সিনট্যাক্স দিয়ে।

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## অ্যাক্সেস লেভেল

ভেতরের টাইপগুলোর ক্ষেত্রে অ্যাক্সেস লেভেল প্রয়োগ করা যায়। উদাহরণস্বরূপ, একটি ক্লাস `private` হলে সেটি ঘিরে রাখা টাইপের স্কোপের বাইরে থেকে দেখা যায় না, এবং অবশ্যই এর ইনস্ট্যান্সগুলোও স্কোপের বাইরে থেকে দেখা বা ব্যবহার করা যায় না।

আউটার ক্লাসের প্রাইভেট মেম্বারগুলো ভেতরের ক্লাসের সব মেম্বারের কাছেই অ্যাক্সেসযোগ্য, কিন্তু ভেতরের ক্লাসের কেবল নন-প্রাইভেট মেম্বারগুলোই আউটার ক্লাসের মেম্বারদের কাছে অ্যাক্সেসযোগ্য। আউটার ক্লাসের মেম্বারগুলো অ্যাক্সেস করতে হলে ভেতরের ক্লাসটিকে আউটার ক্লাসের একটি ইনস্ট্যান্স দিতে হয়।

এটি নিচের উদাহরণে দেখা যায়:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## স্বাধীন ইনস্ট্যান্টিয়েশন প্রতিরোধ

ঘিরে রাখা টাইপের বাইরে একটি ইনস্ট্যান্টিয়েবল টাইপ তৈরি হওয়া আটকানোর একটি প্যাটার্ন আছে। আপনি একটি পাবলিক ইন্টারফেস প্রকাশ করেন, কিন্তু বাস্তবায়নকারী ক্লাসটি private রাখেন।

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Java ডেভেলপারদের জন্য নোট

C#-এর নেস্টেড ক্লাস হলো Java-এর static নেস্টেড ক্লাস আর inner ক্লাসের এক মিশ্রণ। C#-এ ঘিরে রাখা ক্লাসের প্রাইভেট মেম্বারগুলো নেস্টেড ক্লাসের মেম্বারের কাছে অ্যাক্সেসযোগ্য, কিন্তু সেগুলো ইনস্ট্যান্টিয়েট করে ঘিরে রাখা ক্লাসের একটি ইনস্ট্যান্সের সাথে যুক্ত করার জন্য কোনো আলাদা সিনট্যাক্স নেই। উপরের উদাহরণগুলোতে দেখানো প্যাটার্নের কোনো একটি রূপ আপনাকে ব্যবহার করতে হবে।

C#-এ static নেস্টেড ক্লাসও আছে, কিন্তু এগুলো আসলে static আচরণসহ ঘেরা ক্লাস মাত্র।
