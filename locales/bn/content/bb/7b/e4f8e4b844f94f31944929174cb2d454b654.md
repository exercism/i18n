# পরিচিতি

প্রচলিত গাণিতিক ফাংশনগুলো থাকে [`math.functions`][math.functions]-এ, কনস্ট্যান্টগুলো থাকে [`math.constants`][math.constants]-এ, আর ফ্লোট-নির্দিষ্ট আরও কয়েকটি ওয়ার্ড থাকে [`math.libm`][math.libm]-এ। এগুলোর প্রতিটি স্ট্যাক থেকে ইনপুট নেয়:

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .            ! => 3.0
1.0 1.0 fatan2 .    ! => 0.7853981633974483
```

## কনস্ট্যান্ট

| ওয়ার্ড | মান |
| --- | --- |
| `pi` | π, 3.14159… |
| `e` | *e*, 2.71828… |

## মূল ও ঘাত

| ওয়ার্ড | স্ট্যাক এফেক্ট | উত্তর |
| --- | --- | --- |
| `sqrt` | `( x -- y )` | `x`-এর বর্গমূল |
| `sq` | `( x -- y )` | `x * x` |
| `^` | `( x y -- z )` | `x`-এর `y` ঘাত, যেখানে `y` পূর্ণসংখ্যা না-ও হতে পারে |

## ত্রিকোণমিতি

| ওয়ার্ড | স্ট্যাক এফেক্ট | উত্তর |
| --- | --- | --- |
| `sin` `cos` `tan` | `( x -- y )` | রেডিয়ানে থাকা `x` কোণের জন্য |
| `asin` `acos` `atan` | `( x -- y )` | যে কোণের সাইন, কোসাইন বা ট্যানজেন্ট `x` হয়, সেই কোণটি রেডিয়ানে |
| `fatan2` | `( y x -- z )` | ধনাত্মক `x` দিক থেকে (`x`, `y`) বিন্দু পর্যন্ত কোণটি রেডিয়ানে |
| `deg>rad` | `( x -- y )` | ডিগ্রিকে রেডিয়ানে রূপান্তর |
| `rad>deg` | `( x -- y )` | রেডিয়ানকে ডিগ্রিতে রূপান্তর |

প্রতিটি কোণ **রেডিয়ানে**: এক পূর্ণ ঘূর্ণন 2π, 360 নয়। প্রান্তে রূপান্তর করুন এবং মাঝখানে রেডিয়ানেই কাজ করুন।

দিক বের করার জন্য `fatan2` (`math.libm` থেকে) `atan`-এর চেয়ে ভালো। `1 1 / atan` (1, 1) আর (−1, −1)-এর পার্থক্য বুঝতে পারে না, কারণ দুটোরই ভাগফল `1` হয়, আর `x` শূন্য হলে এটি ব্যর্থ হয়। `fatan2` দুই চিহ্নই দেখে এবং −π থেকে π পর্যন্ত যেকোনো মান উত্তর দেয়:

```factor
1 1 / atan rad>deg .          ! => 45.0
-1 -1 / atan rad>deg .        ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
```

## সূচকীয় ও লগারিদম

| ওয়ার্ড | স্ট্যাক এফেক্ট | উত্তর |
| --- | --- | --- |
| `e^` | `( x -- y )` | *e*-এর `x` ঘাত |
| `log` | `( x -- y )` | স্বাভাবিক লগারিদম: `x` পেতে *e*-কে যে ঘাতে উন্নীত করতে হয় |
| `10^` | `( x -- y )` | 10-এর `x` ঘাত |
| `log10` | `( x -- y )` | ১০ ভিত্তিক লগারিদম |
| `log2` | `( x -- y )` | ২ ভিত্তিক লগারিদম |

`e^` আর `log` একে অপরের কাজ বাতিল করে, তেমনি `10^` আর `log10`-ও।

প্রতি ধাপে একই অনুপাতে কমে যায় এমন কিছু `start * e^(-rate * t)` অনুসরণ করে। `start` থেকে `level`-এ নামতে যে সময় লাগে, তা হলো `log(start / level) / rate`।

## যখন কোনো বাস্তব উত্তর নেই

এই ওয়ার্ডগুলোর কোনোটিই অস্বাভাবিক ইনপুটে এরর দেয় না। ঋণাত্মক সংখ্যার বর্গমূল বা লগারিদম একটি **জটিল** ফলাফল দেয়, যা সাধারণ সংখ্যার বদলে চারপাশে `C{ ... }` নিয়ে প্রিন্ট হয়:

```factor
-1 sqrt .     ! => C{ 0.0 1.0 }
-1.0 log .    ! => C{ 0.0 3.141592653589793 }
0.0 log .     ! => -1/0.
```

`-1/0.` হলো ঋণাত্মক অসীম। যদি খারাপ আর্গুমেন্ট আসার সম্ভাবনা থাকে, কল করার আগে আর্গুমেন্ট যাচাই করুন। আরও তিনটি হিসাব পরে পাওয়া জটিল সংখ্যা বা অসীম মানের উৎস খুঁজে বের করা কঠিন।

## এখানে রাউন্ডিংও আনুমানিক

এই ওয়ার্ডগুলো নিকটতম ফ্লোট উত্তর দেয়, সঠিক মান নয়, তাই `~ ( x y epsilon -- ? )` ব্যবহার করে টলারেন্স দিয়ে ফলাফল তুলনা করুন, `=` দিয়ে কখনোই নয়:

```factor
pi 6 / sin .             ! => 0.49999999999999994
pi 6 / sin 0.5 = .       ! => f
pi 6 / sin 0.5 1e-9 ~ .  ! => t
```
