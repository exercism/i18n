# নির্দেশনা

আপনার ডিজাইন টিম তার লেআউটের কাজের কিছু অংশে CSS ট্রান্সফর্ম থেকে Factor-এ চলে যাচ্ছে। টিমের বাকি সবাইকে খুশি রাখতে আপনি ছোট, পুনরায় ব্যবহারযোগ্য রূপান্তর তৈরি করবেন কোয়োটেশন হিসেবে, যেগুলো একটি 2D পয়েন্ট নেয় এবং একটি 2D পয়েন্ট রিটার্ন করে।

একটি পয়েন্ট হলো একটি 2-অ্যারে `{ x y }`।

## 1. স্থানাঙ্ক স্থানান্তর করুন

`translate-2d` ডিফাইন করুন যা স্ট্যাক থেকে `dx` এবং `dy` দুটি মান নেয় এবং এমন একটি কোয়োটেশন রিটার্ন করে যা একটি পয়েন্টকে `(dx, dy)` দিয়ে স্থানান্তর করে।

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. স্থানাঙ্ক স্কেল করুন

একইভাবে `scale-2d` ডিফাইন করুন, যা এমন একটি কোয়োটেশন রিটার্ন করে যা একটি পয়েন্টকে `(sx, sy)` দিয়ে স্কেল করে।

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. দুটি রূপান্তর একত্রিত করুন

`compose-transformations` ডিফাইন করুন যা `f` এবং `g` দুটি রূপান্তর কোয়োটেশন নেয় এবং একটি একক কোয়োটেশন রিটার্ন করে, যা প্রথমে `f` এবং তারপর `g` প্রয়োগ করে।

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. একটি রূপান্তর প্রয়োগ করুন

`apply-transformation` ডিফাইন করুন যা স্ট্যাক থেকে একটি পয়েন্ট এবং একটি রূপান্তর কোয়োটেশন নেয় এবং রূপান্তরিত পয়েন্টটি রিটার্ন করে।

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. একবারে অনেক পয়েন্ট রূপান্তর করুন

`transform-points` ডিফাইন করুন যা পয়েন্টের একটি অ্যারে এবং একটি রূপান্তর কোয়োটেশন নেয়, এবং রূপান্তরিত পয়েন্টগুলোর অ্যারে রিটার্ন করে।

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
