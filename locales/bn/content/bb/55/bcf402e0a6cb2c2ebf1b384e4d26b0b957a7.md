# নির্দেশাবলি

এই অনুশীলনীতে লগ ফাইল পার্স করা নিয়ে আলোচনা করা হয়েছে।

সাম্প্রতিক একটি নিরাপত্তা পর্যালোচনার পর আপনাকে প্রতিষ্ঠানের আর্কাইভ করা লগ ফাইলগুলো পরিষ্কার করার দায়িত্ব দেওয়া হয়েছে।

মেথডগুলোতে পাঠানো সব স্ট্রিং null নয় এবং শুরুতে বা শেষে স্পেস নেই বলে নিশ্চিত করা হয়েছে।

## 1. এলোমেলো লগ লাইন চিহ্নিত করুন

আপনার আর্কাইভে কতগুলো লগ লাইন বর্তমান মানদণ্ড মেনে চলে না, সে সম্পর্কে আপনার কিছুটা ধারণা দরকার। আপনার মনে হয়, একটি সহজ পরীক্ষাই বলে দিতে পারে একটি লগ লাইন বৈধ কি না। বৈধ হতে একটি লাইনকে নিচের স্ট্রিংগুলোর একটি দিয়ে শুরু হতে হবে:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

স্ট্রিংটি বৈধ না হলে `false` আর অন্যথায় `true` রিটার্ন করার জন্য `LogParser.IsValidLine()` মেথডটি ইমপ্লিমেন্ট করুন।

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. লগ লাইনটি ভাগ করুন

প্রতিষ্ঠানে একটি নতুন টিম যোগ দিয়েছে, আর আপনি দেখতে পেলেন তারা "ফিল্ড" আলাদা করতে অদ্ভুত একটি সেপারেটর ব্যবহার করছে। বুদ্ধিমান কিছু যেমন কোলন ":" ব্যবহার না করে তারা "<--->" বা "<=>" (কারণ এটি বেশি সুন্দর) জাতীয় একটি স্ট্রিং ব্যবহার করে। আসলে এমন যেকোনো স্ট্রিং, যার প্রথম ক্যারেক্টার "<" এবং শেষ ক্যারেক্টার ">" এবং মাঝখানে "^", "\*", "=" ও "-" ক্যারেক্টরগুলোর যেকোনো সমন্বয় থাকতে পারে।

এমন একটি লাইন নিয়ে কাজ করে স্ট্রিংয়ের একটি অ্যারে রিটার্ন করার জন্য `LogParser.SplitLogLine()` মেথডটি ইমপ্লিমেন্ট করুন, যার প্রতিটি এলিমেন্টে একটি ফিল্ড থাকবে।

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. উদ্ধৃতি চিহ্নে ঘেরা পাসওয়ার্ড আছে এমন লাইনের সংখ্যা গণনা করুন

কোন কোন উদ্ধৃত টেক্সটে পাসওয়ার্ড আছে তা টিমের জানা দরকার, যাতে সেগুলো হাতে-কলমে যাচাই করা যায়।

হাতে যাচাইয়ের কাজটি কত বড় হতে পারে তার একটি আভাস দেওয়ার জন্য `LogParser.CountQuotedPasswords()` মেথডটি ইমপ্লিমেন্ট করুন।

এমন লগ লাইন খুঁজে বের করুন যেখানে "password" আক্ষরিক স্ট্রিংটি, যা বড় হাতের বা ছোট হাতের অক্ষরের যেকোনো সমন্বয়ে থাকতে পারে, উদ্ধৃতি চিহ্ন দিয়ে ঘেরা। উদ্ধৃতি চিহ্নের ভেতরে "password"-এর আগে ও পরে অতিরিক্ত কনটেন্ট থাকার সম্ভাবনাও আপনার বিবেচনায় নিতে হবে।

রুটিনে পাঠানো লাইনগুলো টাস্ক ১-এ সংজ্ঞায়িত নিয়ম অনুযায়ী বৈধ হতেও পারে, নাও পারে। বৈধ হোক বা না হোক, আমরা সেগুলো একইভাবে প্রসেস করি।

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. লগ থেকে অবাঞ্ছিত অংশ সরান

আপনি দেখতে পেয়েছেন, লগের কিছু আপস্ট্রিম প্রসেসিং লগজুড়ে "end-of-line" টেক্সটটি এবং তার পরপর একটি লাইন নম্বর (মাঝে কোনো স্পেস ছাড়া) ছড়িয়ে দিচ্ছে।

এমন একটি স্ট্রিং নিয়ে কাজ করে end-of-line টেক্সটটি সরিয়ে একটি "পরিষ্কার" স্ট্রিং রিটার্ন করার জন্য `LogParser.RemoveEndOfLineText()` মেথডটি ইমপ্লিমেন্ট করুন।

যেসব লাইনে end-of-line টেক্সট নেই সেগুলো অপরিবর্তিত অবস্থায় রিটার্ন করতে হবে।

শুধু end-of-line স্ট্রিংটি সরান। হোয়াইটস্পেস ঠিক করার চেষ্টা করবেন না।

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. অত্যন্ত দুর্বল পাসওয়ার্ড আছে এমন লাইন তালিকাভুক্ত করুন, যাতে অপরাধীদের শাস্তি দেওয়া যায়

ফাইল থেকে পাসওয়ার্ড মুছে ফেলার আগে আমাদের এমন সব ঘটনা তালিকাভুক্ত করতে হবে, যেখানে পাসওয়ার্ড "password" টেক্সট দিয়ে শুরু হয়।

দোষী পাসওয়ার্ডটি এবং তারপর সম্পূর্ণ লাইনটি প্রিন্ট করার জন্য `LogParser.ListLinesWithPasswords()` মেথডটি ইমপ্লিমেন্ট করুন।

উদ্ধৃতি চিহ্নে ঘেরা পাসওয়ার্ড আছে এমন লাইন ইতিমধ্যেই সরিয়ে ফেলা হয়েছে, আর লাইনগুলো বৈধ কি না তা নির্বিশেষে (টাস্ক ১ অনুযায়ী) আপনি সেগুলো প্রসেস করেন।

যেসব লাইনে দোষী পাসওয়ার্ড আছে সেগুলো "<password>: " প্রিফিক্সসহ রিটার্ন করতে হবে।

যেসব লাইনে দোষী পাসওয়ার্ড নেই সেগুলো "--------: " প্রিফিক্সসহ রিটার্ন করতে হবে।

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
