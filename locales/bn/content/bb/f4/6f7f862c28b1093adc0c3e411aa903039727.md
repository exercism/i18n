# নির্দেশাবলি

এই অনুশীলনীতে আপনি রিমোট কন্ট্রোল কার নিয়ে আরও কিছু কাজ করবেন।

একটি পরীক্ষামূলক কার তৈরি করা হয়েছে এবং প্রোডাকশন ও পরীক্ষামূলক, দুই ধরনের মডেল সামলানোর জন্য টেস্ট ট্র্যাকটি উপযোগী করে তুলতে হবে।
দুই ধরনের কারই ইতিমধ্যে তৈরি হয়ে গেছে, আর টেস্ট ট্র্যাকে তাদের দুটিকেই সামলানোর একটি উপায় আপনাকে বের করতে হবে।

এর সঙ্গে, প্রোডাকশন কারগুলোও কিছুটা সফল হতে শুরু করেছে।
প্রোডাকশন কারগুলোর একটি র‍্যাঙ্কিং প্রকাশ করে প্রতিযোগিতার মনোভাব ধরে রাখতে টিম বস উৎসুক।

## 1. ইন্টারফেসটি ইমপ্লিমেন্ট করুন

`RemoteControlCar` ইন্টারফেসে অনুগ্রহ করে দুটি মেথড যোগ করুন:

- `drive()`, যা কিছুই রিটার্ন করে না, এবং
- `getDistanceTravelled()`, যা একটি `int` রিটার্ন করে।

এরপর `ProductionRemoteControlCar` ও `ExperimentalRemoteControlCar`-কে `RemoteControlCar` ইন্টারফেসটি ইমপ্লিমেন্ট করান।
এর মধ্যে ইন্টারফেসের দাবি করা সব মেথড ইমপ্লিমেন্ট করাও অন্তর্ভুক্ত।

## 2. ড্রাইভ

`.drive()`-এর প্রতিটি কল যেন কারটিকে একটি নির্দিষ্ট দূরত্ব অতিক্রম করায়:

- একটি `ProductionRemoteControlCar` ১০ ইউনিট চলে,
- একটি `ExperimentalRemoteControlCar` ২০ ইউনিট চলে।

`.getDistanceTravelled()` মেথডটি কারটি তার পুরো জীবদ্দশায় যত ইউনিট অতিক্রম করেছে, সেই সংখ্যাটি রিটার্ন করবে।

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. রেস

`TestTrack.race(RemoteControlCar car)` মেথডটি ইমপ্লিমেন্ট করুন, যেখানে `car`-গুলো `drive()` করার সুযোগ পায়।

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. প্রোডাকশন কারগুলো সাজানোর অনুমতি দিন

`ProductionRemoteControlCar` ক্লাসে অনুগ্রহ করে `Comparable<T>` ইন্টারফেসটি ইমপ্লিমেন্ট করুন।
কারগুলোর ডিফল্ট সাজানোর ক্রম হবে জয়ের সংখ্যার অবরোহী ক্রম।

পাস করা কারগুলোকে জয়ের সংখ্যার অবরোহী ক্রমে সাজিয়ে রিটার্ন করার জন্য স্ট্যাটিক `TestTrack.getRankedCars()` ইমপ্লিমেন্ট করুন।

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
