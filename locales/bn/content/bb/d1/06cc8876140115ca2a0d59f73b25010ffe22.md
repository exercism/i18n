# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বইয়ের একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

এখানে আপনার চারটি কাজ আছে, যেগুলোর সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে ডিফাইন করুন

`Lasagna::EXPECTED_MINUTES_IN_OVEN` কনস্ট্যান্টটি ডিফাইন করুন, যেটি রিটার্ন করে লাসাগনাটিকে কত মিনিট ওভেনে থাকা উচিত। রান্নার বই অনুযায়ী ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```ruby
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. ওভেনে বাকি থাকা সময় মিনিটে হিসাব করুন

`Lasagna#remaining_minutes_in_oven` মেথডটি ডিফাইন করুন, যেটি প্যারামিটার হিসেবে নেয় লাসাগনাটি এতক্ষণ কত মিনিট ওভেনে ছিল, আর আগের কাজে পাওয়া প্রত্যাশিত ওভেন সময়ের ভিত্তিতে রিটার্ন করে লাসাগনাটিকে আরও কত মিনিট ওভেনে থাকতে হবে।

```ruby
lasagna = Lasagna.new
lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`Lasagna#preparation_time_in_minutes` মেথডটি ডিফাইন করুন, যেটি প্যারামিটার হিসেবে নেয় আপনি লাসাগনায় কতগুলো স্তর যোগ করেছেন তার সংখ্যা, আর ধরে নেয় যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে; এটি রিটার্ন করে লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে।

```ruby
lasagna = Lasagna.new
lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`Lasagna#total_time_in_minutes` মেথডটি ডিফাইন করুন, যেটি দুটি নামযুক্ত প্যারামিটার নেয়: `number_of_layers` প্যারামিটারটি হলো আপনি লাসাগনায় যে কতগুলো স্তর যোগ করেছেন তার সংখ্যা, আর `actual_minutes_in_oven` প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ওভেনে ছিল তার সংখ্যা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতিতে ব্যয় হওয়া মিনিট এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```ruby
lasagna = Lasagna.new
lasagna.total_time_in_minutes(number_of_layers: 3, actual_minutes_in_oven: 20)
# => 26
```
