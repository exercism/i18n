# টেস্ট

আপনার সমাধান টেস্ট করার জন্য আমরা stdlib থেকে [PonyTest](https://stdlib.ponylang.io/pony_test--index/) ব্যবহার করে টেস্টগুলো লিখি। আপনার সমাধান টেস্ট করার জন্য আপনার code কম্পাইল ও রান করুন।

উদাহরণস্বরূপ, "Hello World"-এর জন্য আপনার সেশনটি দেখতে এমন হতে পারে:
