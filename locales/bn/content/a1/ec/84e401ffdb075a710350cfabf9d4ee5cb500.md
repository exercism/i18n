# পরিচিতি

Gleam স্ট্যান্ডার্ড লাইব্রেরি `gleam/queue` মডিউলে একটি `Queue` টাইপ ইমপ্লিমেন্ট করে। এটি `List` টাইপের মতোই, তবে কয়েকটি গুরুত্বপূর্ণ পার্থক্য আছে:

- `Queue` টাইপের এমন কোনো লিটারেল সিনট্যাক্স নেই যা দিয়ে কিউ তৈরি করা যায় বা কিউয়ের উপর প্যাটার্ন ম্যাচ করা যায়।
- `Queue` টাইপের সামনে ও পিছনে, দুই দিক থেকেই এলিমেন্ট দক্ষতার সাথে যোগ ও মুছে ফেলা যায়, অথচ `List` টাইপে কেবল সামনের দিক থেকেই এলিমেন্ট দক্ষতার সাথে যোগ ও মুছে ফেলা যায়।

বেশিরভাগ সময়েই আপনি `List` টাইপই ব্যবহার করতে চাইবেন, কিন্তু যখন কোনো কালেকশনের শেষ প্রান্ত থেকে এলিমেন্ট যোগ বা মুছে ফেলার দরকার হয়, তখন `Queue` টাইপ ভালো একটি পছন্দ।

`queue.new` ও `queue.from_list` ফাংশন দিয়ে কিউ তৈরি করা যায়:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

`queue.push_front` ও `queue.push_back` ফাংশন দিয়ে কিউতে এলিমেন্ট যোগ করা যায়:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

`queue.pop_front` ও `queue.pop_back` ফাংশন দিয়ে কিউ থেকে এলিমেন্ট মুছে ফেলা যায়:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

`queue.to_list` ফাংশন দিয়ে একটি কিউকে লিস্টে রূপান্তর করা যায়:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## কিউয়ের সমতা

কিউ যেভাবে ইমপ্লিমেন্ট করা হয় তার কারণে, একই ক্রমে একই এলিমেন্ট থাকা দুটি কিউ `==` অপারেটরের কাছে সমান নাও হতে পারে, কারণ এই অপারেটরটি মানগুলো গাঠনিকভাবে তুলনা করে। উদাহরণস্বরূপ:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

দুটি কিউ সমতার ভিত্তিতে তুলনা করার দরকার হলে আপনি `queue.is_logically_equal` ফাংশনটি ব্যবহার করতে পারেন।

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
