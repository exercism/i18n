# নির্দেশনা সংযোজন

সরবরাহকৃত ফোন নম্বর স্ট্রিংটি ওভাররাইট করুন।
ফোন নম্বরটি অবৈধ হলে, এটি একটি খালি স্ট্রিং দিয়ে প্রতিস্থাপন করুন।

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড স্ট্রিং হিসেবে ফোন নম্বর |
| `$t0-9`  | টেম্পোরারি    | যেকোনো     | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত             |
