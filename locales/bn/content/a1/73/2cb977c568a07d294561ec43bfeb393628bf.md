# টেস্ট

## টেস্ট চালানো

টেস্ট স্পেসিফিকেশনটি এভাবে চালান:

```bash
$ gradle test
```

## আরও টেস্ট চালু করা

আপনার কোড সব সক্রিয় টেস্ট পাস করার পর, আপনার আগ্রহের পরবর্তী টেস্টটির আগে থাকা `@Ignore` সরিয়ে দিয়ে আরেকটি টেস্ট চালু করুন। এটি করতে `@Ignore` লাইনটি মুছে ফেলুন, অথবা লাইনের শুরুতে দুটি স্ল্যাশ যোগ করে সেটিকে কমেন্ট আউট করুন।

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
