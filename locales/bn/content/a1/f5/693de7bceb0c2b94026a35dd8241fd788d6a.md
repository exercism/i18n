# নির্দেশাবলি

আপনি এমন একটি সিস্টেম চালাচ্ছেন যেখানে কয়েকটি অ্যাপ্লিকেশন প্রচুর লগ তৈরি করে। আপনি একটি ছোট প্রোগ্রাম লিখতে চান, যা সেই লগগুলো একত্রিত করবে এবং সেগুলোর সিভিয়ারিটি লেভেল অনুযায়ী লেবেল দেবে। আপনার সিস্টেমের সব অ্যাপ্লিকেশন একই লগ কোড ব্যবহার করে, তবে কিছু লিগ্যাসি অ্যাপ্লিকেশন সব কোড সমর্থন করে না।

| লগ কোড | লগ লেবেল | লিগ্যাসি অ্যাপে সমর্থিত? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | না                        |
| 1                     | debug     | হ্যাঁ                       |
| 2                     | info      | হ্যাঁ                       |
| 3                     | warning   | হ্যাঁ                       |
| 4                     | error     | হ্যাঁ                       |
| 5                     | fatal     | না                        |
| অন্যান্য / অসমর্থিত | unknown   | -                         |

## 1. লগ লেবেল নির্ধারণ করুন

`LogLevel.to_label/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি ইন্টিজার কোড এবং একটি বুলিয়ান ফ্ল্যাগ নেবে, যা বলে দেবে লগটি কোনো লিগ্যাসি অ্যাপ থেকে এসেছে কি না, এবং একটি অ্যাটম হিসেবে লগ লাইনের লেবেল রিটার্ন করবে।

টেবিলে উল্লেখ না থাকা লগ কোডের ক্ষেত্রে _unknown_ লেবেল রিটার্ন করা উচিত। টেবিলে লিগ্যাসি অ্যাপে অসমর্থিত হিসেবে উল্লেখ থাকা লগ কোড থেকেও _unknown_ লেবেল রিটার্ন করা উচিত, যদি লগটি লিগ্যাসি অ্যাপ থেকে এসে থাকে।

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. একটি অ্যালার্ট পাঠান

অপ্রত্যাশিত কিছু ঘটলে কাউকে জানাতে হবে।

কার কাছে অ্যালার্ট পাঠাতে হবে তা নির্ধারণ করতে `LogLevel.alert_recipient/2` ফাংশনটি ইমপ্লিমেন্ট করুন। ফাংশনটি একটি ইন্টিজার কোড এবং একটি বুলিয়ান ফ্ল্যাগ নেবে, যা বলে দেবে লগটি কোনো লিগ্যাসি অ্যাপ থেকে এসেছে কি না, এবং একটি অ্যাটম হিসেবে প্রাপকের নাম রিটার্ন করবে।

আগের কাজের `LogLevel.to_label/2` ফাংশনটি ব্যবহার করুন। যদি লগ লেবেল _error_ বা _fatal_ হয়, তবে অ্যালার্টটি _ops_ টিমকে পাঠান। লিগ্যাসি সিস্টেম থেকে _unknown_ লেবেলযুক্ত লগ পেলে অ্যালার্টটি _dev1_ টিমকে পাঠান, আর অন্য অজানা লেবেলগুলো _dev2_ টিমকে পাঠাতে হবে। বাকি সব লগ লেবেল নিরাপদে উপেক্ষা করা যায়, সেক্ষেত্রে _false_ রিটার্ন করুন।

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
