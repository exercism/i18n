# নির্দেশনা

আপনি উচ্চ বিদ্যালয়ের প্রেমিক-প্রেমিকাদের তাদের আদ্যক্ষর দিয়ে একটি ইউনিকোড হার্ট তৈরি করে সোশ্যাল মিডিয়ায় তাদের ভালোবাসা প্রকাশ করতে সাহায্য করতে চলেছেন:

```
❤ J.  +  M. ❤
```

## 1. নাম পরিষ্কার করুন

স্ট্যাক থেকে একটি নাম নিয়ে `cleanupname` ডিফাইন করুন। প্রতিটি `-` কে একটি স্পেস দিয়ে প্রতিস্থাপন করুন, তারপর শুরু ও শেষের হোয়াইটস্পেস মুছে ফেলুন।

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. নামের প্রথম অক্ষর বের করুন

একটি নাম নিয়ে `firstletter` ডিফাইন করুন। আগের কাজের `cleanupname` আবার ব্যবহার করুন, তারপর ফলাফলের প্রথম ক্যারেক্টারটি নিয়ে সেটি এক ক্যারেক্টারের স্ট্রিং হিসেবে রিটার্ন করুন।

```factor
"Jane" firstletter .
! => "J"
```

## 3. প্রথম অক্ষরটিকে আদ্যক্ষর হিসেবে সাজান

একটি নাম নিয়ে `initial` ডিফাইন করুন। আগের কাজের `firstletter` আবার ব্যবহার করুন, সেটিকে আপারকেস করুন, তারপর একটি `.` যোগ করুন।

```factor
"Robert" initial .
! => "R."
```

## 4. আদ্যক্ষরগুলো হার্টের ভিতরে বসান

স্ট্যাক থেকে দুটি নাম নিয়ে `couple` ডিফাইন করুন। প্রতিটি নামে আগের কাজের `initial` আবার ব্যবহার করুন, তারপর ফলাফলটি একত্র করুন:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
