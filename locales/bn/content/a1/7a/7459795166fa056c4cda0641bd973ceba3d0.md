# সম্পর্কে

Swift-এ `guard` স্টেটমেন্ট ব্যবহার করা হয় ফাংশন, লুপ বা মেথড থেকে আগেভাগে বেরিয়ে যাওয়ার জন্য, যখন কোনো প্রয়োজনীয় শর্ত পূরণ হয় না:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

উপরের উদাহরণে `guard` তার পরে থাকা বুলিয়ান এক্সপ্রেশনটি মূল্যায়ন করে।
শর্তটি `true` হলে `guard` স্টেটমেন্টের পরের কোড দিয়ে এক্সিকিউশন চলতে থাকে।
আর শর্তটি `false` হলে `else` ব্লকের ভেতরের কোডটি চালানো হয়।

একটি `if` স্টেটমেন্টের বিপরীতে:

- একটি `guard` স্টেটমেন্টে **অবশ্যই** একটি `else` ক্লজ থাকতে হবে।
- `else` ক্লজটি **অবশ্যই** কন্ট্রোল ট্রান্সফার করে আশপাশের স্কোপ থেকে বেরিয়ে যাবে (যেমন `return`, `continue`, `break` ব্যবহার করে, অথবা একটি এরর থ্রো করে)।

প্রিকন্ডিশন পরিচ্ছন্নভাবে যাচাই করতে `guard` প্রায়ই ব্যবহৃত হয়।
উদাহরণ হিসেবে sinc ফাংশনটি দেখুন ($\text{sinc}(x) = \frac{\sin(x)}{x}$, যেখানে শূন্য দিয়ে ভাগ করার সমস্যা এড়াতে $\text{sinc}(0) = 1$):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
