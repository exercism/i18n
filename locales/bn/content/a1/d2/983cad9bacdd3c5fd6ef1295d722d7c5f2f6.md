# ভূমিকা

## ভ্যারিয়েবল ডিফাইন করা

ভ্যারিয়েবল ডিফাইন করা মানে একটি নামের সাথে একটি মান অ্যাসাইন করা। Scala-তে দুই ধরনের ভ্যারিয়েবল আছে, val এবং var।

একটি `val` ইমিউটেবল, তাই প্রথম অ্যাসাইনমেন্টের পরে এর মান আর পরিবর্তন করা যায় না:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

অন্যদিকে একটি `var`-কে একই টাইপের নতুন একটি মান দিয়ে আবার অ্যাসাইন করা যায়:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala একটি স্ট্যাটিকালি টাইপড ভাষা, যার মানে হলো কম্পাইল-টাইমে প্রতিটি জিনিসেরই একটি টাইপ থাকে। একটি ভ্যারিয়েবল ডিফাইন করা যায় হয় স্পষ্টভাবে তার টাইপ উল্লেখ করে, অথবা অ্যাসাইন করা মানের ভিত্তিতে Scala কম্পাইলারকে তার টাইপ অনুমান করতে দিয়ে (একে টাইপ ইনফারেন্স বলা হয়)। তাই নিচের দুটি ভ্যারিয়েবল ডেফিনিশন সমতুল্য:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

একবার ডিফাইন করার পর একটি ভ্যারিয়েবলের টাইপ আর কখনও পরিবর্তন করা যায় না।

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## ক্লাসের ভেতরে মেথড ডিফাইন করা

Scala একটি _অবজেক্ট-ওরিয়েন্টেড ভাষা_ এবং এতে সব মেথড একটি _ক্লাসের_ ভেতরে ডিফাইন করতে হয়। একটি ক্লাস ডিফাইন করতে `class` কিওয়ার্ডটি ব্যবহার করা হয়।

```scala
class Calculator {
  // ...
}
```

ক্লাসের ভেতরে মেথড ডিফাইন করা যায় `def` কিওয়ার্ড দিয়ে শুরু করে তারপর একটি নাম দিয়ে। প্রতিটি মেথডে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে, যেগুলো প্রথম বন্ধনীর ভেতরে কমা দিয়ে আলাদা করে লেখা হয়। সব প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হয়, প্যারামিটারের ক্ষেত্রে কোনো টাইপ ইনফারেন্স নেই। প্যারামিটারের তালিকার পরে আরেকটি কোলন দিয়ে মেথডের রিটার্ন টাইপ উল্লেখ করা হয়।

মেথড ডেফিনিশনের পরে একটি `=` চিহ্ন দিয়ে মেথড বডি শুরু হয়। নিচের উদাহরণে মেথড বডিতে দুটি স্টেটমেন্ট আছে, যেগুলো দ্বিতীয় বন্ধনী দিয়ে ঘেরা।

মেথডটি শেষ এক্সপ্রেশনের মান রিটার্ন করে, এক্ষেত্রে `add` মেথডটি `sum` ভ্যারিয়েবলের মান রিটার্ন করে:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

পাঠযোগ্যতা বাড়াতে ওই মেথডটি ছোট করার কয়েকটি উপায় আছে:

- যেহেতু মান রিটার্ন করার জন্য `sum` ভ্যারিয়েবলটি মাত্র একবার ব্যবহার করা হয়, তাই এটি বাদ দেওয়া যায়
- শুধু একটি স্টেটমেন্ট নিয়ে গঠিত মেথডে দ্বিতীয় বন্ধনী লাগে না
- ভ্যারিয়েবলের টাইপের মতোই মেথডের রিটার্ন টাইপও অনুমান করা যায়

এতে একই কাজ করে এমন নিচের এক-লাইন মেথডটি পাওয়া যায়:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## ক্লাস ইনস্ট্যান্স করা এবং মেথড কল করা

একটি মেথড কল করতে প্রথমে ক্লাসের একটি ইনস্ট্যান্স তৈরি করতে হয়, তারপর ওই ইনস্ট্যান্সের উপর আর্গুমেন্ট দিয়ে মেথডটি কল করতে হয়:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## কমেন্ট করা

Scala দুই ধরনের কমেন্ট সমর্থন করে, একলাইন কমেন্ট এবং মাল্টিলাইন কমেন্ট:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
