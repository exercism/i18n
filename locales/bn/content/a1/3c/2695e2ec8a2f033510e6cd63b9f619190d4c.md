# নির্দেশনা সংযোজন

## উদাহরণ ইনপুট

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

এর অর্থ হলো আপনার ইনপুটগুলো নিম্নরূপ:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## অবৈধ ইনপুট সামলানো

ইনপুট মানগুলোর মধ্যে কোনোটি অবৈধ হলে আপনার ভার্ব-টি একটি `empty` রিটার্ন করা উচিত (যেমন `0$0` বা `''`)।

### উদাহরণ

- যদি _ইনপুট বেস_-টি 2-এর চেয়ে ছোট হয়:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- যদি _আউটপুট বেস_-টি 2-এর চেয়ে ছোট হয়:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- যদি _ডিজিট_-এ ইনপুট বেসের সমান বা তার চেয়ে বড় কোনো মান থাকে:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
