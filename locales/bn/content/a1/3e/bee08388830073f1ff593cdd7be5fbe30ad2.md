# পরিচিতি

একটি অপশনাল প্যারামিটার ল্যাম্বডা লিস্টে `&optional` ল্যাম্বডা লিস্ট কিওয়ার্ড দিয়ে চিহ্নিত করা হয়। অপশনাল প্যারামিটার বাধ্যতামূলক নয়, এর একটি ডিফল্ট মান থাকতে পারে এবং এটি একটি "supplied-p প্যারামিটার"-ও নির্দিষ্ট করতে পারে, যেটি ওই প্যারামিটারটির জন্য কোনো আর্গুমেন্ট দেওয়া হয়েছে কি না তার উপর নির্ভর করে "ট্রু" বা "ফলস" হবে।

```lisp
(defun optional-parameter (&optional (arg -1)) arg)
(optional-parameter)    ; => -1
(optional-parameter 13) ; => 13
```

অপশনাল প্যারামিটার অবশ্যই প্রয়োজনীয় প্যারামিটারের পরে, কিন্তু নেমড বা রেস্ট প্যারামিটারের আগে বসাতে হবে। আর্গুমেন্ট প্রথমে প্রয়োজনীয় প্যারামিটারে বাইন্ড করা হয়, তারপর অপশনাল প্যারামিটারে, এবং সবশেষে রেস্ট ও নেমড প্যারামিটারে।

```lisp
(defun req-and-opt (req &optional (opt -1)) (list req opt)
(req-and-opt 1)    ; => (1 -1)
(req-and-opt 1 13) ; => (1 13)
```

একাধিক ধরনের প্যারামিটার অন্য ধরনের প্যারামিটারের সাথে (অপশনাল ও কিওয়ার্ড প্যারামিটার) একসাথে মেলানো গেলেও এটি সমস্যাযুক্ত হতে পারে, তাই সাবধানতার সাথে করা উচিত।
Practical Common Lisp-এ ["বিভিন্ন ধরনের প্যারামিটার মেশানো"][pcl-function] অংশটি দেখুন।
