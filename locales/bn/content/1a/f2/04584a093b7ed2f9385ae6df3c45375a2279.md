# নির্দেশনা

এই অনুশীলনীতে আপনি Exercism-এ শিখতে চান এমন প্রোগ্রামিং ভাষার একটি অ্যারের হিসাব রাখার কোড লিখবেন।
এখানে ছয়টি কাজ আছে, যার প্রতিটিতেই অ্যারে নিয়ে কাজ করতে হবে।

## 1. একটি নতুন অ্যারে তৈরি করুন

আপনি যে ভাষাগুলো শিখতে চান সেগুলোর হিসাব রাখতে হলে একটি নতুন অ্যারে তৈরি করতে হবে।
একটি নতুন, খালি অ্যারে ধারণ করে এমন `newList` কনস্ট্যান্ট ডিফাইন করুন।

```elm
newList
    --> []
```

## 2. একটি বিদ্যমান অ্যারে ডিফাইন করুন

এই মুহূর্তে আপনার কাছে কাগজের একটি টুকরো আছে, যেখানে আপনি যে ভাষাগুলো শিখতে চান সেগুলো লেখা আছে: Elm, Clojure আর Haskell।
এই অ্যারেটি বোঝাতে `existingList` কনস্ট্যান্ট ডিফাইন করুন।

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. অ্যারেতে একটি নতুন ভাষা যোগ করুন

Exercism ঘুরে ঘুরে যখন আরও মজার ভাষা খুঁজে পাবেন, তখন সেগুলো আপনার অ্যারেতে যোগ করতে চাইবেন।
আপনার অ্যারের শুরুতে একটি নতুন ভাষা যোগ করতে `addLanguage` ফাংশনটি ইমপ্লিমেন্ট করুন।

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. অ্যারের ভাষাগুলো গণনা করুন

হাতে হাতে ভাষাগুলো গণনা করা অসুবিধাজনক।
আপনার অ্যারেতে কতগুলো ভাষা আছে গণনা করতে `countLanguages` ফাংশনটি ইমপ্লিমেন্ট করুন।

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. অ্যারেটি উল্টে দিন

একপর্যায়ে আপনি বুঝতে পারবেন, আপনার অ্যারেটি আসলে উল্টো ক্রমে সাজানো!
আপনার অ্যারেটি উল্টে দিতে `reverseList` ফাংশনটি ইমপ্লিমেন্ট করুন।

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. অ্যারেটি উত্তেজনাকর কিনা যাচাই করুন

আপনি সব ভাষাই ভালোবাসেন, তবে Elm-এর জন্য আপনার হৃদয়ে বিশেষ একটি জায়গা আছে।
তাই একটি ভাষার অ্যারে নিয়ে আপনি সত্যিই উত্তেজিত হবেন যদি:

- অ্যারের প্রথম এলিমেন্টটি Elm হয়।
- অথবা অ্যারের দ্বিতীয় এলিমেন্টটি Elm হয় এবং অ্যারেতে তিনটি বা তার কম ভাষা থাকে।

কোনো ভাষার অ্যারে উত্তেজনাকর কিনা যাচাই করতে `excitingList` ফাংশনটি ইমপ্লিমেন্ট করুন:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
