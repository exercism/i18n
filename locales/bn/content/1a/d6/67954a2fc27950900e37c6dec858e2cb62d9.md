# পরিচিতি

একটি _ক্লাস_-এর ইনস্ট্যান্স তৈরি করা হয় তার [_কনস্ট্রাক্টর_][constructors]-কে [`new` অপারেটর][new]-এর মাধ্যমে কল করে। কনস্ট্রাক্টর হলো এক বিশেষ ধরনের মেথড, যার উদ্দেশ্য হলো সদ্য তৈরি হওয়া একটি ইনস্ট্যান্স ইনিশিয়ালাইজ করা। [কনস্ট্রাক্টর দেখতে সাধারণ মেথডের মতোই][constructor-syntax], তবে এর কোনো রিটার্ন টাইপ থাকে না এবং নামটি ক্লাসের নামের সাথে মিলে যায়।

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

সাধারণ মেথডের মতোই কনস্ট্রাক্টরেও প্যারামিটার থাকতে পারে। কনস্ট্রাক্টরের প্যারামিটার সাধারণত (private) [ফিল্ড][fields] হিসেবে সংরক্ষণ করা হয় যাতে পরে সেগুলো ব্যবহার করা যায়, কিংবা কোনো এক-বারের হিসাব-নিকাশে ব্যবহার করা হয়। সাধারণ মেথডে আর্গুমেন্ট পাঠানোর মতোই কনস্ট্রাক্টরেও আর্গুমেন্ট পাঠানো যায়।

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

কনস্ট্রাক্টর উল্লেখ করা বাধ্যতামূলক নয়। কোনো কনস্ট্রাক্টর উল্লেখ না করা হলে কম্পাইলার একটি [প্যারামিটারবিহীন কনস্ট্রাক্টর][parameterless-constructors] তৈরি করে দেয়:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

ফিল্ডে যদি শুরুর মান অ্যাসাইন করা থাকে, তবে কম্পাইলার এমন কোড তৈরি করে যেখানে অ্যাসাইনমেন্টটি আসলে কনস্ট্রাক্টরের ভেতরেই করা হয়। তাই নিচের ক্লাস ঘোষণাগুলো কার্যকারিতার দিক থেকে সমতুল্য:

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
