# পরিচিতি
## সুইচ

একটি [সুইচ স্টেটমেন্ট][switch] দিয়ে আপনি একটি মানকে একাধিক সম্ভাব্য মিলে যাওয়া মানের সাথে তুলনা করতে পারেন।
এটি একাধিক `else-if` স্টেটমেন্ট ব্যবহার করার চেয়ে বেশি সংক্ষিপ্ত কোড লিখতে দেয়।
একটি সুইচ স্টেটমেন্ট শুরু হয় `switch` কিওয়ার্ড দিয়ে, তারপরে থাকে যে মানটি তুলনা করা হবে।
এরপর আপনি `case` কিওয়ার্ড আর তারপরে যে মানের সাথে তুলনা করা হবে তা দিয়ে কেসগুলো ডিফাইন করতে পারেন।
কোনো কেস মিলে না গেলে ডিফল্ট কেস ডিফাইন করতে `default` কিওয়ার্ড ব্যবহার করা হয়।
`else-if` স্টেটমেন্টের মতোই, `switch` স্টেটমেন্ট শুধু প্রথম মিলে যাওয়া কেসের সাথে যুক্ত কোড ব্লকটিই চালায়।

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

নিচের উদাহরণটি দেখুন:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

এটির বদলে এভাবে লেখা যেতে পারে:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## হোয়াইল লুপ

একটি [হোয়াইল লুপ][while-loops] হলো একটি কন্ট্রোল ফ্লো স্টেটমেন্ট, যা দিয়ে নির্দিষ্ট একটি শর্ত ট্রু থাকা পর্যন্ত কোড চালানো যায়।
Swift দুই ধরনের হোয়াইল লুপ দেয়: while আর repeat-while লুপ।
হোয়াইল লুপের শর্ত লুপ বডি চালানোর আগে যাচাই করা হয়; শর্তটি ফলস হলে লুপ বডি একেবারেই চালানো হবে না।
Swift-এ হোয়াইল লুপের গঠনটি এরকম:

```swift
while <#condition#> {
  <#code#>
}
```

এখানে count 0-এর চেয়ে বড় থাকা পর্যন্ত লুপটি চলবে এবং তাই 2, 1 আর "Liftoff!" প্রিন্ট করবে।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

একটি [repeat-while লুপ][while-loops] হোয়াইল লুপের মতোই, তবে শর্তটি লুপ বডি চালানোর পরে যাচাই করা হয়।
এর মানে হলো লুপ বডি অন্তত একবার চালানো হবে, এমনকি শর্তটি ফলস হলেও।
Swift-এ repeat-while লুপের গঠনটি এরকম:

```swift
repeat {
  <#code#>
} while <#condition#>
```

এখানে শর্তটি ফলস হওয়ায় লুপটি শুধু একবারই চলবে।
যেহেতু এটি একটি repeat-while লুপ, তাই শর্ত যাচাইয়ের আগে লুপ বডি একবার চলবে।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## কন্ট্রোল ট্রান্সফার

Swift-এ এমন কিছু স্টেটমেন্ট আছে যা লুপের স্বাভাবিক কন্ট্রোল ফ্লো পরিবর্তন করতে ব্যবহার করা যায়।
এগুলোকে কন্ট্রোল ট্রান্সফার স্টেটমেন্ট বলা হয়।
আপনি ইতিমধ্যেই `return` দেখেছেন; এই কনসেপ্টে আরও কয়েকটি পরিচয় করানো হবে, যার মধ্যে আছে `continue`, `break` আর লেবেল।
এই কনসেপ্টে আমরা `fallthrough` নিয়ে আলোচনা করব না, তবে এটি সম্পর্কে [Swift বই][fallthrough]-তে পড়তে পারেন।

### কন্টিনিউ

মাঝে মাঝে লুপের বর্তমান ইটারেশনের বাকি স্টেটমেন্টগুলো শেষ না করেই আগেভাগে পরের ইটারেশনে চলে যাওয়া দরকার হয়।
এর জন্য `continue` কিওয়ার্ড ব্যবহার করা যায়।
`continue` চালানো হলে লুপটি পরের যাচাইয়ে চলে যায়, অর্থাৎ লুপের পরের ইটারেশনটি চালানো যায় কি না তা দেখে, মানে হোয়াইল ও repeat-while লুপে `while`, আর for-in লুপে সিকোয়েন্সে আরেকটি এলিমেন্ট আছে কি না সেই যাচাই।

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### ব্রেক

লুপ থেকে আগেভাগে বেরিয়ে আসতে ব্রেক ব্যবহার করা হয়।
`break` চালানো হলে লুপটি সঙ্গে সঙ্গে বন্ধ হয়ে যায় এবং প্রোগ্রামটি লুপের পরে থাকা প্রথম স্টেটমেন্ট থেকে চালু থাকে।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### লেবেল

লুপগুলো নেস্টেড থাকলে কখনো কখনো `break` বা `continue` দিয়ে সেই লুপের 바াইরের লুপ থেকে বেরিয়ে আসতে বা সেটি আবার চালু করতে চাইতে পারেন, যে লুপের ভেতরে `break` বা `continue` ব্যবহার করা হচ্ছে।
এমন ক্ষেত্রে কোন লুপ থেকে বেরোতে হবে বা কোনটি আবার চালু করতে হবে তা নির্দিষ্ট করতে লেবেল ব্যবহার করা যায়।
লুপ শুরু করা `while`, `repeat`, বা `for`-এর আগে একটি নাম আর তারপর একটি কোলন বসিয়ে লুপে লেবেল দেওয়া যায়।

এভাবে লেবেল ব্যবহারের ফল কী হয় তা দেখতে নিচের লুপটি দেখুন।

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
