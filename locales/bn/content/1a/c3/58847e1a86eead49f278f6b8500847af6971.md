# ইঙ্গিত

## সাধারণ

- `MACRO:` আছে [`macros`][macros]-এ। বিল্ডিং ব্লকগুলো থাকে
  `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`,
  `<repetition>`, `map`), আর `quotations` (`>quotation`)-এ।
- একটি ম্যাক্রো বডিকে স্ট্যাকে **একটি কোয়োটেশন** রেখে যেতেই হবে। আপনার
  বডি যদি কোডের একটি অ্যারে তৈরি করে, তাহলে `>quotation` দিয়ে শেষ করুন।
- আপনার ভাবনা যাচাই করতে, লিসেনারে একটি লিটারালের উপর বডির শব্দগুলো
  রান করুন এবং ফেরত পাওয়া কোয়োটেশনটি দেখুন। এটি টাস্কের "কম্পাইল হয়"
  লাইনের স্ট্রেইট-লাইন কোড হওয়া উচিত।

## 1. দুইবার

- আপনি `[ A ]` পান, আর চান `[ A A ]`। এর একটি কপি বানিয়ে সেগুলো একত্র
  করুন: `dup append`।

## 2. N বার পুনরাবৃত্তি

- আপনি `[ A ] n` পান, আর চান `n`টি কপি একসাথে জোড়া লাগানো।
- `<repetition>` কপিগুলো তৈরি করে, কিন্তু এর এফেক্ট হলো
  `( length elt -- repetition )`। সংখ্যাটি উপরে থাকতে হবে, তাই `swap`
  আগে করুন।
- এরপর ফ্ল্যাট করে কনভার্ট করুন: `swap <repetition> concat >quotation`।

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. অনেকগুলো একত্র করা

- আপনি কোয়োটেশনগুলোর অ্যারে ইতিমধ্যেই পান; শুধু সেগুলো ফ্ল্যাট করে
  একটি বানাতে হবে। `concat >quotation`-ই পুরো বডি।

## 4. আনরোলড ইটারেশন

আপনি একটি সিকোয়েন্স আর একটি কোয়োটেশন পান, যেমন `{ 10 20 30 } [ + ]`,
আর চান `[ 10 + 20 + 30 + ]`। তিনটি ধাপে এটি গড়ে তুলুন।

**একটি এলিমেন্ট।** কোয়োটেশনের ভেতরে একটি এলিমেন্ট বেক করে বসানো মানে
ঠিক সেটাই যা `curry` করে:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**প্রতিটি এলিমেন্ট।** আপনি সেটিকে সিকোয়েন্সের উপর `map` করতে চান। কিন্তু
`map` ম্যাপিং কোয়োটেশনকে একটিমাত্র ইনপুট (এলিমেন্টটি) দেয়, অথচ প্রতিবার
আপনার হাতে `[ + ]`-ও থাকা দরকার। তাই আগে `curry` দিয়ে `[ + ]`-কে ম্যাপিং
কোয়োটেশনের ভেতরে বেক করে নিন:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry`-কে পড়া হয় এভাবে: "ছোট কোয়োটেশন `[ curry ]` পুশ করুন,
তারপর `[ + ]`-কে তার ভেতরে কারি করুন", ফলে পাওয়া যায় `[ [ + ] curry ]`।
এটি একটি এলিমেন্ট `e`-এর উপর ম্যাপ করলে চলে `e [ + ] curry`, যা আসলে
`[ e + ]`।

**এগুলো জোড়া লাগান।** অন্য টাস্কগুলোর মতোই শেষ করুন:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- পুরো বডি: `[ curry ] curry map concat >quotation`।

[macros]: https://docs.factorcode.org/content/vocab-macros.html
