# নির্দেশনা

এই অনুশীলনীতে আপনি এমন একটি প্রোগ্রাম বানাবেন, যা একটি [টিক-ট্যাক-টো][tic-tac-toe] গেমের অবস্থা নির্ধারণ করে। (_এই গেমটি আপনি "noughts and crosses" বা "Xs and Os" নামেও চিনতে পারেন।_)

গেমটি একটি ৩×৩ গ্রিডে খেলা হয়।
খেলোয়াড়রা পালা করে গ্রিডে `X` ও `O` বসান।
একজন খেলোয়াড় সারি, কলাম বা কর্ণ বরাবর তিনটি চিহ্ন বসিয়ে জিতে গেলে, কিংবা পুরো গ্রিড ভরে গেলে গেমটি শেষ হয়।

এই অনুশীলনীতে আমরা ধরে নেব যে খেলা শুরু করে `X`।

একটি নির্দিষ্ট গেম কোন অবস্থায় আছে, সেটি নির্ধারণ করা আপনার কাজ।

গেমের সম্ভাব্য অবস্থা তিনটি:

- গেমটি **ongoing**।
- গেমটি **draw**-এ শেষ হয়েছে।
- গেমটি **win**-এ শেষ হয়েছে।

প্রদত্ত বোর্ডটি অবৈধ হলে একটি উপযুক্ত এরর থ্রো করুন।

কোনো বোর্ড নিচের শর্তগুলো পূরণ করলে সেটি অবৈধ:

- সঠিক ক্রমে পালা নিলে প্রদত্ত বোর্ডে পৌঁছানো যায় না (মনে রাখুন, খেলা শুরু করে `X`)।
- গেম শেষ হওয়ার পরেও খেলা চালিয়ে যাওয়া হয়েছে।

## উদাহরণ

### চলমান গেম

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### ড্র

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

   |   |
