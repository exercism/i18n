# ডিবাগিং

ডিবাগিংয়ে সাহায্য করার জন্য আপনি এই বিষয়টি ব্যবহার করতে পারেন যে সমস্ত কনসোল আউটপুট ক্যাপচার করা হবে এবং টেস্ট ফলাফল উইন্ডোতে দেখানো হবে।
আপনি যেকোনো মান `@show`-এ পাস করে আউটপুট দিতে পারেন।

`@show` একটি এক্সপ্রেশন এবং তার ফলাফল দেখায়, আর একই সঙ্গে তার ফলাফল রিটার্ন করে।

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

এছাড়া আপনি [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) বা [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout))-এ আউটপুট লেখে এমন অন্য যেকোনো মেথডও ব্যবহার করতে পারেন।
