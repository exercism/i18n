# নির্দেশাবলি

একটি মূলদ সংখ্যা বলতে দুটি ইন্টিজার `a` এবং `b`-এর ভাগফলকে বোঝায়, যাদের যথাক্রমে লব ও হর বলা হয়, যেখানে `b != 0`।

মূলদ সংখ্যা `r = a/b`-এর পরম মান `|r|` হলো `|a|/|b|`-এর সমান।

দুটি মূলদ সংখ্যা `r₁ = a₁/b₁` এবং `r₂ = a₂/b₂`-এর যোগফল হলো `r₁ + r₂ = a₁/b₁ + a₂/b₂ = (a₁ * b₂ + a₂ * b₁) / (b₁ * b₂)`।

দুটি মূলদ সংখ্যা `r₁ = a₁/b₁` এবং `r₂ = a₂/b₂`-এর বিয়োগফল হলো `r₁ - r₂ = a₁/b₁ - a₂/b₂ = (a₁ * b₂ - a₂ * b₁) / (b₁ * b₂)`।

দুটি মূলদ সংখ্যা `r₁ = a₁/b₁` এবং `r₂ = a₂/b₂`-এর গুণফল (গুণ) হলো `r₁ * r₂ = (a₁ * a₂) / (b₁ * b₂)`।

একটি মূলদ সংখ্যা `r₁ = a₁/b₁`-কে আরেকটি মূলদ সংখ্যা `r₂ = a₂/b₂` দিয়ে ভাগ করলে হয় `r₁ / r₂ = (a₁ * b₂) / (a₂ * b₁)`, যদি `a₂` শূন্য না হয়।

একটি মূলদ সংখ্যা `r = a/b`-কে একটি অঋণাত্মক ইন্টিজার ঘাত `n`-এ সূচকীকরণ করলে হয় `r^n = (a^n)/(b^n)`।

একটি মূলদ সংখ্যা `r = a/b`-কে একটি ঋণাত্মক ইন্টিজার ঘাত `n`-এ সূচকীকরণ করলে হয় `r^n = (b^m)/(a^m)`, যেখানে `m = |n|`।

একটি মূলদ সংখ্যা `r = a/b`-কে একটি বাস্তব (ফ্লোটিং-পয়েন্ট) সংখ্যা `x`-এ সূচকীকরণ করলে ভাগফল হয় `(a^x)/(b^x)`, যা একটি বাস্তব সংখ্যা।

একটি বাস্তব সংখ্যা `x`-কে একটি মূলদ সংখ্যা `r = a/b`-এ সূচকীকরণ করলে হয় `x^(a/b) = root(x^a, b)`, যেখানে `root(p, q)` হলো `p`-এর `q`-তম মূল।

নিচের অপারেশনগুলো ইমপ্লিমেন্ট করুন:
 - দুটি মূলদ সংখ্যার যোগ, বিয়োগ, গুণ ও ভাগ,
 - পরম মান, একটি প্রদত্ত মূলদ সংখ্যাকে একটি ইন্টিজার ঘাতে সূচকীকরণ, একটি প্রদত্ত মূলদ সংখ্যাকে একটি বাস্তব (ফ্লোটিং-পয়েন্ট) ঘাতে সূচকীকরণ, একটি বাস্তব সংখ্যাকে একটি মূলদ সংখ্যায় সূচকীকরণ।

আপনার মূলদ সংখ্যার ইমপ্লিমেন্টেশন সর্বদা লঘিষ্ঠ আকারে নামিয়ে আনা উচিত। যেমন, `4/4` কমে `1/1` হওয়া উচিত, `30/60` কমে `1/2` হওয়া উচিত, `12/8` কমে `3/2` হওয়া উচিত, ইত্যাদি। একটি মূলদ সংখ্যা `r = a/b`-কে লঘিষ্ঠ করতে `a` এবং `b`-কে `a` ও `b`-এর গরিষ্ঠ সাধারণ গুণনীয়ক (gcd) দিয়ে ভাগ করুন। সুতরাং, উদাহরণস্বরূপ, `gcd(12, 8) = 4`, তাই `r = 12/8`-কে কমিয়ে `(12/4)/(8/4) = 3/2` করা যায়।

ধরে নিন, আপনি যে প্রোগ্রামিং ভাষাটি ব্যবহার করছেন সেটিতে মূলদ সংখ্যার কোনো ইমপ্লিমেন্টেশন নেই।
