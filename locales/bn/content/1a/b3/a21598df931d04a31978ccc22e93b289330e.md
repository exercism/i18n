# টেস্ট

  ## এক নজরে

  1. `<myFileName>.u` ফাইলে আপনার পরিবর্তনগুলো করুন
  2. `<myFileName>.u` ফাইলটি সেভ করুন
  3. ফাইলটি টাইপচেক পাস করলে, UCM-এর `add` বা `update` কমান্ডগুলো রান করুন
    * ফাইলটি টাইপচেক পাস না করলে, আপনার `<myFileName>.u` ফাইলের কোডে পরিবর্তন করতে থাকুন যতক্ষণ না এটি কম্পাইল হয়। পরিবর্তনের পর আপনার ফাংশনগুলো `update` করতে ভুলবেন না!
  4. টেস্টগুলো স্কোপে এনে রান করার জন্য UCM CLI-তে `load <myFileName>.test.u` কমান্ডটি রান করুন

  ## বিস্তারিতভাবে দেখা যাক

  কমান্ড লাইন থেকে Exercism-এর কোনো সমস্যা নিয়ে কাজ করলে, সম্ভবত আপনি নির্দিষ্ট অনুশীলনীটির নামে থাকা ডিরেক্টরিতে আপনার সমাধান লিখবেন। উদাহরণস্বরূপ, অনুশীলনীটি যদি `hello-world` হয়, তাহলে `~/exercism/unison/hello-world`-এ `cd` করার পর কমান্ড লাইন থেকে `ucm` চালু করুন। `hello.u` ফাইলে আপনার ইমপ্লিমেন্টেশনের পরিবর্তনগুলো করুন, এবং আপনার ইমপ্লিমেন্টেশন নিয়ে সন্তুষ্ট হলে, ফাইলের কাজটি কোডবেসে যোগ করতে Unison codebase manager CLI (UCM)-তে `add` বা `update` কমান্ড দিন।

  প্রতিটি অনুশীলনীর টেস্ট যে ফাইলে থাকে তার নামের শেষে `.test.u` থাকে। টেস্টগুলো স্কোপে এনে রান করতে আপনি UCM-এর `load` কমান্ডটি ব্যবহার করবেন। `load` কমান্ডটি আর্গুমেন্ট হিসেবে একটি ফাইল পাথ নেয়। hello world অনুশীলনীর জন্য সেটি দেখতে এমন হতে পারে:

  ```
  .> load hello.test.u
  ```

  স্কোপে আনা টার্মগুলো সম্পর্কে UCM থেকে একটি বার্তা দেখতে পাবেন, আর সবচেয়ে গুরুত্বপূর্ণ হলো টেস্ট চালানোর ফলাফল:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  ধরা যাক প্রথমবার আপনার টেস্ট পাস করেনি। আবার আপনার `myExercise.u` ফাইল এডিট করতে ফিরে যান, আর সেভ করার পর আপনি `update` করতে পারেন

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  এরপর কিছু বদলেছে কি না দেখতে আমরা আমাদের টেস্ট আবার লোড করতে পারি!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
