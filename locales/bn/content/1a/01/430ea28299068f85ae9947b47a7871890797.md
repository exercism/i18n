# বুলিয়ান মানকে ট্রু বা ফলসের সাথে তুলনা করবেন না

বুলিয়ান মানকে ট্রু বা ফলসের সাথে তুলনা করা অপ্রয়োজনীয়।
`==` ব্যবহার করলে একটি বুলিয়ান মান তৈরি হয়, তাই সেটিকে আরেকটি হার্ডকোড করা বুলিয়ান মানের সাথে তুলনা করার দরকার নেই।
বুলিয়ান মানটি উল্টাতে চাইলে `!` অপারেটরটি ব্যবহার করুন।

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
