# পরিচিতি

একটি `for` লুপ দিয়ে একটি অ্যারের উপর ইটারেশন করা যায় এবং প্রতিটি এলিমেন্টের জন্য কোডটি বারবার চালানো যায়:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

উপরের উদাহরণে `fruit` হলো সেই ভ্যারিয়েবল, যেটি `fruitList` অ্যারের একটি নির্দিষ্ট এলিমেন্টের মান ধারণ করে। কম্পাইলার নিশ্চিত করে যে `fruitList`-এর উপর ইটারেশন করা সম্ভব, নাহলে এটি এক্সিকিউশন থামিয়ে দেয়।

রেঞ্জ অপারেটর ব্যবহার করে আপনি সংখ্যার উপরও ইটারেশন করতে পারেন। এই অপারেটরটি দুটি `Int` অপারেন্ড নেয় এবং এটি `min...max` আকারে লেখা হয়:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
