# ভূমিকা

## স্ট্রিং

Elixir-এ স্ট্রিং ডাবল কোট দিয়ে ঘেরা হয় এবং সেগুলো UTF-8-এ এনকোড করা হয়:

```elixir
"Hi!"
```

`<>/2` অপারেটর দিয়ে স্ট্রিংগুলো সংযুক্ত করা যায়:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir-এর স্ট্রিংগুলো `#{}` সিনট্যাক্স ব্যবহার করে ইন্টারপোলেশন সমর্থন করে:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

একটি স্ট্রিংয়ে নিউলাইন ক্যারেক্টার বসাতে `\n` এস্কেপ কোড ব্যবহার করুন:

```elixir
"1\n2\n3\n"
```

অনেক নিউলাইন আছে এমন টেক্সট নিয়ে সহজে কাজ করার জন্য বদলে ট্রিপল-ডাবল-কোট হেরেডক সিনট্যাক্স ব্যবহার করুন:

```elixir
"""
1
2
3
"""
```

Elixir `String` মডিউলে স্ট্রিং নিয়ে কাজ করার জন্য অনেক ফাংশন প্রদান করে।

## পাইপ অপারেটর

`|>` অপারেটরকে পাইপ অপারেটর বলা হয়। এটি এমনভাবে একাধিক ফাংশন কল একসাথে চেইন করতে ব্যবহার করা যায়, যাতে আগের ফাংশন কল থেকে রিটার্ন করা মান পরের ফাংশন কলে প্রথম আর্গুমেন্ট হিসেবে পাস হয়।

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
