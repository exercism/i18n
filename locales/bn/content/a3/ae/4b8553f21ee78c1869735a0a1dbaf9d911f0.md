# নির্দেশনা সংযোজন

## ট্র্যাক-নির্দিষ্ট নির্দেশনা

এই অনুশীলনীটির মূল লক্ষ্য হলো Swift-এর `Int` স্ট্রাকচারে মেথড যোগ করা।
এটি করার সবচেয়ে সহজ উপায় হলো [এক্সটেনশন][extensions] ব্যবহার করা।

```swift
extension Int {
  // 
}
```

`Int`-এর ডকুমেন্টেশন [এখানে][int] পাওয়া যাবে।

[int]: https://developer.apple.com/documentation/swift/int
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
