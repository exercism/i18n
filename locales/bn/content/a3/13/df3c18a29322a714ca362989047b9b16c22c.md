# ফাংশন

JavaScript-এ ফাংশন হলো _ফার্স্ট ক্লাস অবজেক্ট_, অর্থাৎ এগুলো ভ্যারিয়েবল ও প্রপার্টিতে অ্যাসাইন করা যায়, অন্য ফাংশনে পাস করা যায়, আর ফাংশন থেকে রিটার্ন করা যায়। যেকোনো _অবজেক্ট_-এর মতোই এগুলোরও প্রপার্টি ও মেথড থাকতে পারে।

## ইনপুট: আর্গুমেন্ট পাস করা

JavaScript ফাংশনে কল করার সময় আর্গুমেন্ট পাস করা যায়। আর্গুমেন্ট সবসময় [ভ্যালু হিসেবে পাস হয়](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7)। অন্য কথায়, কোনো ফাংশনের ভেতরে প্যারামিটার আবার অ্যাসাইন করলে ফাংশনের বাইরে তার মান বদলাবে না। এর মানে অবশ্য এই নয় যে পাস করা অবজেক্ট পরিবর্তন করা যায় না।

> [!TIP]
> কোনো অবজেক্ট পাস করলে ওই অবজেক্টের রেফারেন্সটাই ভ্যালু হিসেবে পাস হয়। এতে _মনে হয়_ যেন অবজেক্ট পাস করার ক্ষেত্রে আলাদা নিয়ম চলে, কিন্তু আসলে তা নয়।

দুটি আর্গুমেন্ট নিয়ে তাদের গুণ করে, এমন একটি ফাংশনের উদাহরণ:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## আউটপুট: রিটার্ন ভ্যালু

JavaScript-এ `return` কিওয়ার্ডের পর একটি এক্সপ্রেশন লিখে ফাংশন থেকে একটিমাত্র মান রিটার্ন করা যায়। কোনো ফাংশন থেকে কিছু রিটার্ন না করলে রিটার্ন ভ্যালু হয় `undefined`।

একটি মান রিটার্ন করে, এমন একটি ফাংশনের উদাহরণ:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## ফাংশন ডিফাইন করা

JavaScript-এ ফাংশনের চারটি ধরন আছে:

1. সাধারণ ফাংশন, যা যেকোনো কিছু রিটার্ন করতে পারে এবং সবসময় পুরোপুরি রান হয়;
2. অ্যাসিন্ক ফাংশন, যা সবসময় একটি `Promise` রিটার্ন করে এবং `await` অপারেটর দিয়ে থামানো ও আবার চালু করা যায়;
3. জেনারেটর ফাংশন, যা সবসময় একটি `Generator` অবজেক্ট রিটার্ন করে এবং `yield` অপারেটর দিয়ে থামানো ও আবার চালু করা যায়;
4. অ্যাসিন্ক জেনারেটর ফাংশন, যা সবসময় একটি `AsyncGenerator` অবজেক্ট রিটার্ন করে এবং _একইসাথে_ `yield` ও `await` অপারেটর দিয়ে থামানো ও আবার চালু করা যায়।

এই চারটি ধরনের প্রতিটির জন্য এগুলো ডিফাইন করার তিনটি উপায় আছে:

1. ডিক্লারেশন ব্যবহার করে
2. এক্সপ্রেশন ব্যবহার করে
3. কনস্ট্রাক্টর ব্যবহার করে

সবশেষে _অ্যারো ফাংশন ও মেথড_ ডিফাইন করার জন্য কিছু বিশেষ সিনট্যাক্স আছে।
