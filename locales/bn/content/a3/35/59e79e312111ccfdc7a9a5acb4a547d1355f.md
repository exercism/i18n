# নির্দেশনা

এই অনুশীলনীতে আপনি একটি রোল-প্লেয়িং গেমের কিছু মেকানিক বাস্তবায়ন করবেন।
একজন খেলোয়াড়ের চরিত্রকে নিচের টাইপটি দিয়ে প্রকাশ করা হয়:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

এই গেমে খেলোয়াড়দের স্পেল কাস্ট করা শুরু করার জন্য ম্যানা পুল আনলক করতে হলে প্রথমে লেভেল ১০-এ পৌঁছাতে হবে।
এই গেমে আপনি দুটি কাজ নিয়ে কাজ করবেন: রিভাইভ মেকানিক এবং স্পেল কাস্টিং মেকানিক।

## 1. নিজের পরিচয় দিন

`introduce` ফাংশনের ভেতরের অংশটি লিখুন।
খেয়াল করুন, `Player` রেকর্ডের `Name` ফিল্ডটি একটি `Option`.
চুপিসারে থাকতে চাওয়া খেলোয়াড়েরা হয়তো নামটি `None` রেখে গোপন করতে চাইবেন; এমন খেলোয়াড়দের পরিচয় দেওয়া হবে `"Mighty Magician"` হিসেবে।
অন্যথায়, নিজের নাম দিয়েই নিজের পরিচয় দিন।

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. রিভাইভ মেকানিক বাস্তবায়ন করুন

`revive` ফাংশনটি যাচাই করবে যে খেলোয়াড়ের চরিত্রটি সত্যিই মৃত কি না (তার হেলথ ০-তে পৌঁছেছে কি না)।
যদি মৃত হয়ে থাকে, তবে ১০০ হেলথ নিয়ে একটি নতুন `Player` ইনস্ট্যান্স রিটার্ন করবে।
অন্যথায়, খেলোয়াড়ের চরিত্রটি যদি মৃত না হয়, তাহলে `revive` ফাংশনটি `None` রিটার্ন করে।

খেলোয়াড়ের লেভেল যদি ১০ বা তার বেশি হয়, তাহলে তাকে ১০০ ম্যানা নিয়েও রিভাইভ করা হবে।
খেলোয়াড়ের লেভেল ১০-এর কম হলে, তার ম্যানা হবে `None`.
`revive` ফাংশনটি খেলোয়াড়ের লেভেল অপরিবর্তিত রাখবে।

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

যদি `revive` মেথডটি এমন কোনো খেলোয়াড়ের উপর কল করা হয় যার হেলথ ১ বা তার বেশি, তাহলে ফাংশনটি `None` রিটার্ন করবে।

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. স্পেল কাস্টিং মেকানিক বাস্তবায়ন করুন

`castSpell` ফাংশনটি আর্গুমেন্ট হিসেবে একটি `int`, যা বোঝায় স্পেলটির ম্যানা খরচ কত, এবং একটি `Player` নেয়।
এটি আপডেট হওয়া খেলোয়াড়টি রিটার্ন করে, সাথে কাস্ট করা স্পেলটি যে পরিমাণ ড্যামেজ করে সেটিও।
একটি সফল স্পেল কাস্টে স্পেলটির ম্যানা খরচের দ্বিগুণের সমান ড্যামেজ হয়।
তবে খেলোয়াড়ের কাছে যদি পর্যাপ্ত ম্যানা না থাকে, তাহলে কিছুই হয় না, খেলোয়াড় অপরিবর্তিত থাকে এবং কোনো ড্যামেজও হয় না।
খেলোয়াড়ের যদি ম্যানা পুলই না থাকে, তাহলে স্পেল কাস্ট করার চেষ্টা করলে তার হেলথ স্পেলটির ম্যানা খরচের সমান কমতে হবে এবং কোনো ড্যামেজ হবে না।

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
