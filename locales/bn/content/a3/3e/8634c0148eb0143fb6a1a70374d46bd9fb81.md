# বাইনারি, অক্টাল ও হেক্সাডেসিমেল

বাইনারি, অক্টাল ও হেক্সাডেসিমেল (_যাকে হেক্স নামেও ডাকা হয়_) ভিন্ন ভিন্ন বেসের [সংখ্যা পদ্ধতি][numeral-systems]।
বাইনারি বেস 2, অক্টাল বেস 8 আর হেক্সাডেসিমেল বেস 16।
Crystal-এ সাধারণ ইন্টিজার বেস 10।
বাইনারি, অক্টাল ও হেক্সাডেসিমেল সবই ইন্টিজারের রিপ্রেজেন্টেশন।
এর মানে হলো, এগুলো ভগ্নাংশ বা দশমিক ছাড়াই ধনাত্মক ও ঋণাত্মক সংখ্যা (_শূন্যসহ_) প্রকাশ করে এবং ইন্টিজার দিয়ে আমরা যেসব অপারেশন করতে পারি, সেগুলোর সবই সমর্থন করে।

## বাইনারি

[বাইনারি][binary] একটি বেস 2 সংখ্যা পদ্ধতি, যেখানে কেবল 0 ও 1 অঙ্ক ব্যবহার করা হয়।
এটি সাধারণত কম্পিউটারের ট্রানজিস্টর ও সুইচের মধ্য দিয়ে বিদ্যুৎ প্রবাহের 0 ("বন্ধ") ও 1 ("চালু") অবস্থা, আর সঙ্গে চৌম্বকীয় স্টোরেজ মাধ্যমের ধনাত্মক ও ঋণাত্মক চার্জ প্রকাশ করে।
বাইনারি দিয়ে বেস 10-এ ব্যবহৃত সব ইন্টিজার প্রকাশ করা যায়।

বেস 2 পদ্ধতির একটি ছোট অংশ দেখতে এমন, যদিও এটি অসীম পর্যন্ত চলতে থাকে এবং 128-এ থেমে যায় না:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

তাহলে আমরা যদি 6 সংখ্যাটি প্রকাশ করতে চাই, বাইনারিতে সেটি হবে: 110

| স্থানীয় মান    | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| বাইনারি সংখ্যা | 1   | 1   | 0   |

আর অপারেশনটি হবে: `4 + 2 + 0 = 6`

আরেকটি উদাহরণ: 19

| স্থানীয় মান    | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| বাইনারি সংখ্যা | 1   | 0   | 0   | 1   | 1   |

বাইনারি সংখ্যাটি হবে: 10011
আর অপারেশনটি হবে: `16 + 0 + 0 + 2 + 1 = 19`

## Crystal-এ বাইনারি

Crystal-এ আমরা `0b` প্রিফিক্স ব্যবহার করে বাইনারি লিটারেল প্রকাশ করতে পারি।
আমরা যদি `0b10011` লিখি, Crystal এটিকে একটি বাইনারি সংখ্যা হিসেবে ইন্টারপ্রেট করবে এবং বেস 10-এ রূপান্তর করবে।

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

আপনি যদি `0b` প্রিফিক্স দিয়ে এমন একটি সংখ্যা লেখেন যা বাইনারি পদ্ধতিতে নেই, তাহলে এটি একটি কম্পাইলেশন এরর দেবে।

```crystal
0b10211
# => Error: unexpected token: "211"
```

### বাইনারি সংখ্যার অপারেশন

যেহেতু বাইনারি সংখ্যা ইন্টিজার, তাই ইন্টিজার দিয়ে আমরা যেসব অপারেশন করতে পারি, সেগুলোর সবই এগুলোর উপর করতে পারি।

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### বাইনারি রিপ্রেজেন্টেশনে ও সেখান থেকে রূপান্তর

Crystal স্বয়ংক্রিয়ভাবে একটি বাইনারি লিটারেলকে `Int32`-এ রূপান্তর করে।
একটি `Int32`-কে বাইনারি রিপ্রেজেন্টেশনে রূপান্তর করতে, base আর্গুমেন্টটি 2 সেট করে [`<int>.to_s(base)`][to_s] মেথডটি ব্যবহার করুন।
মেথডটি বাইনারি সংখ্যাটির একটি স্ট্রিং রিপ্রেজেন্টেশন রিটার্ন করবে:

```crystal
19.to_s(2)
# => "10011"
```

বাইনারির একটি স্ট্রিং রিপ্রেজেন্টেশনকে ইন্টিজারে রূপান্তর করতে, আমরা [`<int>.to_i(base)`][to_i] মেথডটি ব্যবহার করতে পারি এবং আর্গুমেন্ট হিসেবে base (2) পাস করতে পারি:

```crystal
"10011".to_i(2)
# => 19
```

ভুল base (_বা একটি অবৈধ বাইনারি রিপ্রেজেন্টেশন_) দিলে একটি `ArgumentError` দেবে:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### বাইনারি মেথড

এমন কিছু মেথড আছে যেগুলো ইন্টিজারে ব্যবহার করে সংখ্যাটির বাইনারি রিপ্রেজেন্টেশন সম্পর্কে তথ্য পাওয়া যায়।

[`<int>.bit_length`][bit_length] সংখ্যাটি প্রকাশ করতে যে কতগুলো বিট লাগে, সেটি রিটার্ন করবে:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] ডান দিক থেকে শুরু করে (_লিস্ট সিগনিফিক্যান্ট বিট_) প্রদত্ত ইনডেক্সে থাকা বিটটি রিটার্ন করবে:

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## অক্টাল

[অক্টাল][octal] একটি বেস 8 সংখ্যা পদ্ধতি।
এটি 0, 1, 2, 3, 4, 5, 6 ও 7 অঙ্ক ব্যবহার করে।

Crystal-এ আমরা `0o` প্রিফিক্স ব্যবহার করে অক্টাল সংখ্যা প্রকাশ করতে পারি।
বাইনারির মতোই, Crystal স্বয়ংক্রিয়ভাবে একটি অক্টাল রিপ্রেজেন্টেশনকে `Int32`-এ রূপান্তর করে।

```crystal
0o123
# => 83
```

অক্টাল পদ্ধতিতে নেই এমন একটি সংখ্যার আগে `0o` বসালে কম্পাইলেশন এরর দেবে।

### অক্টাল রিপ্রেজেন্টেশনে ও সেখান থেকে রূপান্তর

বাইনারির মতোই, আমরা [`<int>.to_s(base)`][to_s] মেথড ব্যবহার করে একটি `Int32`-কে অক্টাল রিপ্রেজেন্টেশনে রূপান্তর করতে পারি।
আর আমরা [`<int>.to_i(base)`][to_s] মেথড ব্যবহার করে একটি অক্টাল রিপ্রেজেন্টেশনকে `Int32`-এ রূপান্তর করতে পারি।

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

বাইনারির মতোই, ভুল base দিলে একটি `ArgumentError` দেবে।

## হেক্সাডেসিমেল

[হেক্সাডেসিমেল][hexadecimal] একটি বেস 16 সংখ্যা পদ্ধতি।
এটি 0 - 9 অঙ্ক এবং A, B, C, D, E ও F অক্ষর ব্যবহার করে।
A হলো 10, B হলো 11, C হলো 12, D হলো 13, E হলো 14 আর F হলো 15।

আমরা Crystal-এ `0x` প্রিফিক্স ব্যবহার করে হেক্সাডেসিমেল সংখ্যা প্রকাশ করতে পারি।
বাইনারি ও অক্টালের মতোই, Crystal স্বয়ংক্রিয়ভাবে হেক্সাডেসিমেল লিটারেলকে `Int32`-এ রূপান্তর করবে।

```crystal
#=> 0x123
291
```
 
হেক্সাডেসিমেল নয় এমন একটি সংখ্যার আগে `0x` বসালে কম্পাইলেশন এরর দেবে।

### হেক্সাডেসিমেল রিপ্রেজেন্টেশনে ও সেখান থেকে রূপান্তর

বাইনারির মতোই, আমরা [`<int>.to_s(base)`][to_i] মেথড ব্যবহার করে একটি `Int32`-কে হেক্সাডেসিমেল রিপ্রেজেন্টেশনে রূপান্তর করতে পারি।
আর আমরা [`<int>.to_i(base)`][to_s] মেথড ব্যবহার করে একটি হেক্সাডেসিমেল রিপ্রেজেন্টেশনকে `Int32`-এ রূপান্তর করতে পারি।

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

বাইনারি ও অক্টালের মতোই, ভুল base দিলে একটি `ArgumentError` দেবে।

## প্রিসিশন

কোনো সংখ্যাকে স্ট্রিং রিপ্রেজেন্টেশনে রূপান্তর করার সময় আমরা সংখ্যাটির প্রিসিশন নির্দিষ্ট করতে পারি।
এর মানে হলো সংখ্যাটি প্রকাশ করতে **সর্বনিম্ন** কতগুলো সংখ্যা ব্যবহার করা হবে তা।
সংখ্যাটির অঙ্ক যদি প্রিসিশনের চেয়ে কম হয়, তবে স্ট্রিং রিপ্রেজেন্টেশনে লিডিং জিরো যোগ করা হবে।
এটি করা হয় [`<int>.to_s(<base>, precision: <value>)`][to_s] মেথডে `precision` আর্গুমেন্ট পাস করে।

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
