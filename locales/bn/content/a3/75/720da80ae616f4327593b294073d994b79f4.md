# পরিচিতি

আপনি এখন পর্যন্ত যে প্রোগ্রামই চালান না কেন, সেটি গেম হোক, ওয়েব ব্রাউজার হোক বা ফোনের অ্যাপ, শেষ পর্যন্ত সেটি ছোট ছোট নির্দেশের একটি লম্বা তালিকা, যেগুলো প্রসেসর একে একে সম্পন্ন করে।
অ্যাসেম্বলি ভাষা হলো সেই উপায়, যার মাধ্যমে আপনি নিজেই ওই নির্দেশগুলো লেখেন।
ভ্যারিয়েবল, অ্যারে আর `for` লুপের বদলে আপনি কাজ করেন প্রসেসরের নিজের গঠন-উপাদান নিয়ে: অল্প কয়েকটি রেজিস্টার, মেমোরি অ্যাড্রেস, এবং এক নির্দেশ থেকে আরেক নির্দেশে লাফ।

RISC-V (উচ্চারণ "রিস্ক ফাইভ") হলো প্রসেসরের একটি ডিজাইন, যার শুরু ২০১০ সালে ইউনিভার্সিটি অব ক্যালিফোর্নিয়া, বার্কলিতে।
বেশিরভাগ প্রসেসর ডিজাইনের মতো নয়, এটি একটি ওপেন স্ট্যান্ডার্ড: একটি RISC-V চিপ বানাতে কাউকে টাকা দিতে হয় না বা অনুমতি চাইতে হয় না, আর স্পেসিফিকেশনটি যে কেউ বিনামূল্যে পড়তে পারে।
RISC-V চিপ পাওয়া যায় মাইক্রোকন্ট্রোলার, সিঙ্গেল-বোর্ড কম্পিউটার, স্টোরেজ ডিভাইস এবং আরও অনেক কিছুতে।

প্রথম অ্যাসেম্বলি ভাষা হিসেবে RISC-V ভালো, কারণ এটি সহজ হওয়ার কথা মাথায় রেখে বানানো হয়েছে।
এর নির্দেশগুলো অল্প কয়েকটি নিয়মিত প্যাটার্ন মেনে চলে, আর এর ৩২টি রেজিস্টারের ভূমিকা স্পষ্ট ও সামঞ্জস্যপূর্ণ, তাই বেশিরভাগ ল্যাপটপের প্রসেসরের তুলনায় মুখস্থ করার জিনিস অনেক কম।
এই সরলতার কারণেই এখন অনেক বিশ্ববিদ্যালয় কম্পিউটার কীভাবে কাজ করে শেখাতে RISC-V ব্যবহার করে।

এখানে ছোট্ট একটি নমুনা, দুটি সংখ্যা যোগ করা একটি ফাংশন:

```riscv
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

এই ট্র্যাকে আপনি লেখেন ৩২-বিট RISC-V অ্যাসেম্বলি।
আপনার কোনো RISC-V হার্ডওয়্যারও লাগবে না: আপনার প্রোগ্রাম টেস্ট করা হয় একটি এমুলেটরে, যেটি নিজেকে একটি RISC-V প্রসেসর বলে দেখায়।
আপনি অনুশীলনীগুলো সমাধান করতে পারেন অনলাইন এডিটরে, অথবা নিজের কম্পিউটারে ফ্রি টুল ব্যবহার করে।

অ্যাসেম্বলি শিখতে ধৈর্য লাগে, তবে এর সুফলও আছে।
একটি লুপ বা একটি ফাংশন কল প্রসেসরের কাছে কেমন দেখায়, তা একবার দেখে ফেললে বাকি সব প্রোগ্রামিং ভাষাও আপনার কাছে একটু বেশি অর্থবহ হয়ে ওঠে।
