# ভূমিকা

## স্ট্রাক্ট টাইপ

আমরা ইতিমধ্যেই স্ট্রাক্ট টাইপ দেখেছি। সংক্ষেপে বললে, একটি `struct` হলো _ফিল্ড_ নামে পরিচিত কিছু নামযুক্ত এলিমেন্টের ক্রম, যার প্রতিটি ফিল্ডের একটি নাম ও একটি টাইপ থাকে।
একটি স্ট্রাক্টের ভেতরে একটি ফিল্ডের নাম অবশ্যই অনন্য হতে হবে।
স্ট্রাক্টকে অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং প্যারাডাইমের _ক্লাস_-এর সঙ্গে তুলনা করা যায়।

আপনি `type` ও `struct` কিওয়ার্ড ব্যবহার করে একটি নতুন স্ট্রাক্ট তৈরি করেন, তারপর নিচের উদাহরণে দেখানো অনুযায়ী ফিল্ডগুলোর নাম ও টাইপ স্পষ্টভাবে ডিফাইন করেন।

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## নন-স্ট্রাক্ট টাইপ

বিল্ট-ইন টাইপ ডিক্লারেশনের অ্যালিয়াস হিসেবে ব্যবহার করার জন্য নন-স্ট্রাক্ট টাইপও ডিফাইন করা সম্ভব।

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

অ্যারে ও ম্যাপ দিয়ে গঠিত নন-স্ট্রাক্ট টাইপও আপনি ডিফাইন করতে পারেন।

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
