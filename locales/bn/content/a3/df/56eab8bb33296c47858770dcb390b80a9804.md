# পরিচিতি

Elixir-এ [স্ট্রিং][getting-started-strings] ডাবল কোটেশন দিয়ে ঘেরা হয়, আর এগুলো UTF-8-এ এনকোড করা থাকে:

```elixir
"Hi!"
```

[`<>/2`][kernel-concat] অপারেটর দিয়ে স্ট্রিংগুলো জোড়া লাগানো যায়:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir-এ স্ট্রিং `#{}` সিনট্যাক্স ব্যবহার করে [ইন্টারপোলেশন][string-interpolation] সমর্থন করে:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

ইন্টারপোলেশনের ভেতরে যেকোনো Elixir এক্সপ্রেশন ব্যবহার করা যায়। যদি কোনো স্ট্রিং দেওয়া হয়, তাহলে স্ট্রিংটি যেমন আছে তেমনভাবেই ইন্টারপোলেট হয়। আর যদি অন্য কোনো মান দেওয়া হয়, তাহলে Elixir সেটিকে স্ট্রিং-এ রূপান্তর করার চেষ্টা করে।

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

`String` মডিউলে Elixir স্ট্রিং নিয়ে কাজ করার জন্য অনেক ফাংশন দেয়। আপনার প্রয়োজন অনুযায়ী একটি স্ট্রিং কীভাবে সামলাবেন তা নিয়ে যদি নিশ্চিত না হন, তাহলে [`` `String` `` মডিউলে থাকা ফাংশনগুলো][string-module-functions] একবার ঘুরে দেখুন, সব সম্ভাবনায় আপনার দরকারের জিনিসটি পেয়ে যাবেন।

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

ওই ফাংশনগুলো ব্যবহার করার সময় মনে রাখবেন, একটি স্ট্রিংয়ের প্রথম ক্যারেক্টারের ইনডেক্স `0`।

কিছু ক্যারেক্টার স্ট্রিং-এর ভেতরে বসাতে হলে [এস্কেপ][escape-characters] করতে হয়, যেমন নিউলাইন, ডাবল কোট, বা `#` ক্যারেক্টার:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

অনেক নিউলাইন আছে এমন টেক্সট নিয়ে সহজে কাজ করতে চাইলে, বরং [ট্রিপল ডাবল কোটের হেরেডক সিনট্যাক্স][heredoc-syntax] ব্যবহার করুন:

```elixir
"""
1
2
3
"""
```

কোড ডকুমেন্ট করার জন্য এই সিনট্যাক্সটি খুব বেশি ব্যবহৃত হতে দেখবেন:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
