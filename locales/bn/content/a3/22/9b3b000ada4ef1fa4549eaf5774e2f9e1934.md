# পরিচিতি

## ইমপোর্ট

Swift তার স্ট্যান্ডার্ড লাইব্রেরিতে প্রচুর সুবিধা দেয়, তবে বাহ্যিক লাইব্রেরি ও ফ্রেমওয়ার্ক ইমপোর্ট করে আপনি আরও অনেক ফিচার ব্যবহার করতে পারেন।
এই মডিউলগুলো সরাসরি Swift প্রকল্প থেকে আসতে পারে ([Swift Argument Parser][argument-parser]-এর মতো), Apple প্ল্যাটফর্মের ফ্রেমওয়ার্ক থেকে ([Foundation][apple-foundation] ও [Network Framework][network-framework]-এর মতো), অথবা থার্ড-পার্টি ওপেন সোর্স লাইব্রেরি থেকে ([SwiftyBeaver][swifty-beaver]-এর মতো)।

Foundation-এর মতো কোর মডিউলগুলো, যা Swift-এর সবচেয়ে বেশি ব্যবহৃত লাইব্রেরিগুলোর একটি, Swift টুলচেইনের সাথে আসে।
থার্ড-পার্টি লাইব্রেরি ইমপোর্ট করার আগে সেগুলোকে আপনার প্রকল্পের কনফিগারেশনে যোগ করতে হয় (যেমন Swift Package Manager ব্যবহার করে)।

মডিউল ইমপোর্ট করা হয় `import` কিওয়ার্ড লিখে, তার পরে মডিউলের নাম লিখে।
তাই প্রোগ্রামে নিচের লাইনটি যোগ করে Foundation ইমপোর্ট করা যায়।

```swift
import Foundation
```

একটি মডিউল ইমপোর্ট করলে তার টাইপ, মেথড ও ফাংশন আপনার কোডের জন্য উপলব্ধ হয়।
যেমন, Foundation ইমপোর্ট করলে `String`-এ `components(separatedBy:)`-এর মতো কাজের ইউটিলিটি মেথড যুক্ত হয়।

প্রচলিত রীতি অনুসারে `import` স্টেটমেন্টগুলো Swift ফাইলের শুরুতে রাখা হয়, যাতে কোড পড়ছে যে কেউই নির্ভরতাগুলো সঙ্গে সঙ্গে দেখতে পায়।

## স্ট্রিং ইনডেক্সিং

অ্যারের সাথে ব্যবহৃত সাবস্ক্রিপ্ট পদ্ধতি ব্যবহার করে `String`-এর প্রতিটি ক্যারেক্টার অ্যাক্সেস করা যায়।
তবে স্ট্রিংয়ের জন্য ব্যবহৃত [ইনডেক্সগুলো][string-indices] ইন্টিজার _নয়_ এবং সরাসরি এগুলো নিয়ে কাজ করা যায় না।
বরং এগুলো অন্য কোনো জানা ইনডেক্স, যেমন `startIndex`-এর ওপর ভিত্তি করে হিসাব করতে হয়। `startIndex` একটি খালি নয় এমন স্ট্রিংয়ের প্রথম ক্যারেক্টারের অবস্থান বোঝায়। এই হিসাবের জন্য [`String`][string-docs] ও [`NSString`][nsstring-docs] লাইব্রেরিতে থাকা মেথডগুলো ব্যবহার করা যায় (`Foundation` মডিউল ইমপোর্ট করা থাকলে Swift-এর স্ট্রিংগুলো NSString-এর সব প্রপার্টি ও মেথড ব্যবহার করতে পারে)।

উদাহরণস্বরূপ, নিচের স্ট্রিংটি ধরুন:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

"orange"-এর "g" পেতে কেউ `csv[21]` লিখতে পারে না, বরং `String.Index` টাইপের একটি মান হিসাব করে সেটি দিতে হয়।
লক্ষ্য করুন, এই ইনডেক্সগুলো এমনিতে মানুষের পড়ার জন্য বানানো নয়।
এগুলোকে _অপাক ইনডেক্স_ বলা হয়, কারণ ভেতরে কী আছে তা মানুষকে জানতে হয় না।

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

তবে মনে রাখবেন, অফসেট যদি বৈধ ইনডেক্স না হয়, অর্থাৎ যদি তা `startIndex`-এর আগে বা `endIndex`-এর পরে ইনডেক্স দেয়, তাহলে অপারেশনটি এরর উত্থাপন করবে এবং প্রোগ্রামটি ক্র্যাশ করবে।
এই সমস্যা এড়াতে একটি সীমা নির্ধারণকারী ইনডেক্স উল্লেখ করা যায়।
এটি একটি অপশনাল ইনডেক্স রিটার্ন করে, আর অন্যথায় অবৈধ ইনডেক্সের ক্ষেত্রে nil রিটার্ন করবে।

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

এছাড়া, একটি স্ট্রিংয়ের ইনডেক্স অন্য স্ট্রিংয়ে ব্যবহার করা যায় না।
উদাহরণস্বরূপ, উপরে হিসাব করা "orange"-এর "g"-এর `index` দিয়ে `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` স্ট্রিংয়ে ইনডেক্স করলে, অর্থাৎ `fam[index]` লিখলে আপনার প্রোগ্রাম ক্র্যাশ করবে।

এর পেছনে অনেক কারণ আছে, তবে মূলত সবই দাঁড়ায় একটাই কথা: "ইউনিকোড জটিল"।

সাধারণভাবে বলতে গেলে, যদি আলাদা আলাদা ক্যারেক্টারে র‍্যান্ডম অ্যাক্সেস দরকার হয়, তাহলে সম্ভবত `Array<Character>`-এর মতো অন্য কোনো ডেটা স্ট্রাকচার ব্যবহার করা উচিত।

### কিছু কাজের মেথড

স্ট্রিংয়ের প্রথম ও শেষ ক্যারেক্টার পেতে Swift-এ `first` ও `last` মেথড আছে।
এই মেথডগুলো একটি অপশনাল ক্যারেক্টার রিটার্ন করে, তাই স্ট্রিং খালি হলে তারা nil রিটার্ন করবে।

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

স্ট্রিংয়ের একটি সাবস্ট্রিং পেতেও `prefix` ও `suffix` মেথড ব্যবহার করতে পারেন।
এই মেথডগুলো একটি ইন্টিজার আর্গুমেন্ট নেয় এবং স্ট্রিংয়ের প্রথম বা শেষ n ক্যারেক্টার নিয়ে গঠিত একটি সাবস্ট্রিং রিটার্ন করে।

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## স্ট্রিং মেথড

প্রোগ্রামিংয়ে টেক্সট নিয়ে কাজ করা একটি কমন কাজ।
Swift, Foundation ফ্রেমওয়ার্কসহ, স্ট্রিং পরীক্ষা, রূপান্তর ও ম্যানিপুলেশনের জন্য অনেক সুবিধাজনক মেথড ও প্রপার্টি দেয়।

## `components(separatedBy:)` দিয়ে স্ট্রিং ভাগ করা

কোনো ডিলিমিটার অনুসারে একটি স্ট্রিংকে সাবস্ট্রিংয়ের অ্যারেতে ভাগ করতে `components(separatedBy:)` ব্যবহার করুন (এজন্য Foundation ইমপোর্ট করা লাগে):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## `hasPrefix(_:)` ও `hasSuffix(_:)` দিয়ে প্রিফিক্স ও সাফিক্স পরীক্ষা করা

একটি স্ট্রিং নির্দিষ্ট ক্যারেক্টারের একটি সিকোয়েন্স দিয়ে শুরু বা শেষ হয় কি না পরীক্ষা করতে `hasPrefix(_:)` ও `hasSuffix(_:)` ব্যবহার করুন:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## কেস পরিবর্তন করা

এই স্ট্যান্ডার্ড মেথড ও প্রপার্টিগুলো ব্যবহার করে স্ট্রিংয়ের কেস রূপান্তর করতে পারেন:

- `lowercased()`: স্ট্রিংয়ের ছোট হাতের অক্ষরে লেখা একটি কপি রিটার্ন করে।
- `uppercased()`: স্ট্রিংয়ের বড় হাতের অক্ষরে লেখা একটি কপি রিটার্ন করে।
- `capitalized`: প্রতি শব্দের প্রথম অক্ষর বড় হাতের করে লেখা একটি কপি রিটার্ন করে (Foundation থেকে)।

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## `replacingOccurrences(of:with:)` দিয়ে সাবস্ট্রিং প্রতিস্থাপন করা

একটি লক্ষ্য সাবস্ট্রিংয়ের সব উপস্থিতি অন্য একটি স্ট্রিং দিয়ে প্রতিস্থাপন করতে `replacingOccurrences(of:with:)` ব্যবহার করুন (Foundation থেকে):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## `joined(separator:)` দিয়ে স্ট্রিং জোড়া দেওয়া

`joined(separator:)` মেথডটি `[String]`-এর মতো স্ট্রিংয়ের কালেকশনের অন্তর্গত।
এটি একটি সেপারেটর ব্যবহার করে এলিমেন্টগুলোকে জোড়া দিয়ে একটি স্ট্রিং বানায়:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
