# পরিচিতি

## স্ট্রাক্ট ও ক্লাস

স্ট্রাক্ট ও ক্লাস হলো Swift প্রোগ্রামিংয়ের দুটি প্রধান বিল্ডিং ব্লক। দুটোই সম্পর্কিত ডেটা ও ফাংশনকে স্বয়ংসম্পূর্ণ কার্যকারিতার এককে গুছিয়ে রাখার উপায়। আর আপনি যখন কোনো স্ট্রাক্ট বা ক্লাস ডিফাইন করেন, তখন Swift-এর ভেতরে ব্যবহারের জন্য একটি নতুন টাইপ ডিফাইন করছেন, ঠিক যেমন `Int` আর `String`-এর মতো টাইপ আপনি আগেই ব্যবহার করেছেন।

Swift-এ স্ট্রাক্ট আর ক্লাসের মধ্যে অনেক মিল আছে। আরও অনেক মিলের মধ্যে, দুটোই _প্রপার্টিতে_ মান সংরক্ষণ করতে পারে এবং _মেথড_ ব্যবহারের মাধ্যমে কার্যকারিতা প্রদান করে।

দুটোর প্রত্যেকটিই কিছু অতিরিক্ত কার্যকারিতা দেয়, যা এই অনুশীলনীর আওতার বাইরে।

### স্ট্রাক্ট ও ক্লাস ডিফাইন করা

স্ট্রাক্ট আর ক্লাস দুটোই প্রায় একইভাবে ডিফাইন করা হয়। এরা শুরু হয় উপযুক্ত কিওয়ার্ড দিয়ে, তারপর আসে যে টাইপটি ডিফাইন করা হচ্ছে তার নাম, তারপর দ্বিতীয় বন্ধনী `{}`-এর মধ্যে বসে স্ট্রাক্ট/ক্লাসের বডি।

বডিতে থাকতে পারে স্টোরড প্রপার্টি, যেগুলো সাধারণ কনস্ট্যান্ট বা ভ্যারিয়েবলের মতোই ডিফাইন করা হয় এবং আচরণ করে।

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### ইনস্ট্যান্স

উপরে বলা হয়েছে, একটি স্ট্রাক্ট বা ক্লাস ডিফাইন করা মানে শুধু একটি নতুন _টাইপ_ ডিফাইন করা। এটি শুধু একটি ব্লুপ্রিন্ট, যা বলে দেয় ওই টাইপের মানগুলো কেমন হবে, কিন্তু এটি আসলে ওই টাইপের কোনো মান তৈরি করে না, যাতে আপনি কাজ করতে পারেন।

ওই টাইপের একটি _ইনস্ট্যান্স_ তৈরি করতে আপনাকে টাইপের নাম লিখতে হবে, তারপর একটি জোড়া প্রথম বন্ধনী।

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

এতে এই টাইপের মান তৈরি হবে, যেখানে প্রপার্টিগুলো ডেফিনিশনে দেওয়া ডিফল্ট মান দিয়ে পূরণ হয়। খেয়াল রাখবেন, GameCharacter-এর `name` প্রপার্টির মতো অপশনাল ক্ষেত্রে, কোনো মান না দিলে প্রপার্টিটি ডিফল্টভাবে nil হবে, ঠিক যেমন সাধারণ অপশনাল টাইপ ডিফাইন করার সময় কোনো মান সাথে সাথে দেওয়া না হলে হয়।

স্ট্রাক্টের ক্ষেত্রে, Swift স্বয়ংক্রিয়ভাবে _মেম্বারওয়াইজ ইনিশিয়ালাইজার_ নামের একটি জিনিস দেয়, যেখানে প্রথম বন্ধনীর ভেতরে স্ট্রাক্টের প্রপার্টিগুলোর মান দেওয়া যায়, যা ডেফিনিশনের ডিফল্ট মানগুলোকে ওভাররাইড করবে।

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### প্রপার্টি অ্যাক্সেস করা

স্ট্রাক্ট আর ক্লাসের প্রপার্টি অ্যাক্সেস করা যায় _ডট নোটেশন_ দিয়ে, যেখানে মানের নামের পরে একটি ডট (`.`) আর তারপর প্রপার্টির নাম থাকে। যদি কোনো স্ট্রাক্ট বা ক্লাসের প্রপার্টির নিজেরও প্রপার্টি থাকে, তাহলে এই ডট নোটেশন দিয়ে ওই নেস্টেড প্রপার্টিগুলোও অ্যাক্সেস করা যায়।

এই নোটেশন দিয়ে প্রপার্টির মান পড়া যায়, আর যেখানে অনুমতি আছে সেখানে তা বদলানোও যায়।

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### মেথড

প্রপার্টির মতো, যা আপনার স্ট্রাক্ট আর ক্লাসে ডেটা সংরক্ষণ করে, আপনি _মেথডও_ ডিফাইন করতে পারেন, যা আপনার স্ট্রাক্ট বা ক্লাসে ফাংশন সংরক্ষণ করে।

মেথড সাধারণ ফাংশনের মতোই ডিফাইন করা হয়, শুধু স্ট্রাক্ট বা ক্লাসের বডির ভেতরে। খেয়াল রাখবেন, কোনো ফাংশন যদি স্ট্রাক্টের কোনো প্রপার্টির মান বদলায়, তাহলে তার আগে অবশ্যই `mutating` কিওয়ার্ড থাকতে হবে। এছাড়া, কোনো মেথড যদি কোনো প্রপার্টি বদলাতে পারে, তাহলে সেই প্রপার্টি `let`-এর বদলে `var` দিয়ে ডিফাইন করতে হবে, ঠিক সাধারণ ভ্যারিয়েবলের মতো।

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

এই মেথডগুলো প্রপার্টির মতোই ডট নোটেশন দিয়ে কল করা যায়।

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

স্ট্রাক্ট বা ক্লাসের প্রতিটি ইনস্ট্যান্সের `self` নামে একটি অন্তর্নিহিত প্রপার্টি থাকে, যা ইনস্ট্যান্সটিকেই বোঝায়।
`self`-এর সবচেয়ে কমন ব্যবহার হলো একই নামের একটি ইনস্ট্যান্স প্রপার্টি আর একটি প্যারামিটারের মধ্যে পার্থক্য স্পষ্ট করা:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift টাইপ আবার একটি বড় হাতের অক্ষরে লেখা `Self` কিওয়ার্ডও দেয়, যা ইনস্ট্যান্সের বদলে ইনস্ট্যান্সের *টাইপকে* বোঝায়।
