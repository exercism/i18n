# নির্দেশনা

এই অনুশীলনীতে আপনি উচ্চ বিদ্যালয়ের প্রেমিক-প্রেমিকাদের সামাজিক মাধ্যমে তাদের ভালোবাসা প্রকাশ করতে সাহায্য করবেন, তাদের নামের আদ্যক্ষর দিয়ে একটি ইউনিকোড হার্ট তৈরি করে:

```
❤ J.  +  M. ❤
```

## 1. নাম পরিষ্কার করুন

`cleanupname` মেথডটি ইমপ্লিমেন্ট করুন।
এটি একটি নাম নেবে এবং নামটি থেকে সব `-` ক্যারেক্টার মুছে ফেলে সেগুলোর জায়গায় একটি স্পেস বসাবে।
এটি নামের শুরু ও শেষ থেকে যেকোনো হোয়াইটস্পেসও মুছে ফেলবে।

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. নামের প্রথম অক্ষর বের করুন

`firstletter` মেথডটি ইমপ্লিমেন্ট করুন।
এটি একটি নাম নেবে এবং তার প্রথম অক্ষরটি একটি স্ট্রিং হিসেবে রিটার্ন করবে।
আগের ধাপে আপনি যে `cleanupname` ডিফাইন করেছিলেন সেটি আবার ব্যবহার করতে ভুলবেন না এবং তা অন্য ফাংশনের সঙ্গে কম্পোজ করুন।

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. প্রথম অক্ষরটিকে আদ্যক্ষর হিসেবে ফরম্যাট করুন

`initial` মেথডটি ইমপ্লিমেন্ট করুন।
এটি একটি নাম নেবে এবং তার প্রথম অক্ষরটি বড় হাতের অক্ষরে রিটার্ন করবে, যার পরে একটি ডট থাকবে।
আগের ধাপে আপনি যে `firstletter` ডিফাইন করেছিলেন সেটি আবার ব্যবহার করতে ভুলবেন না।

```julia-repl
initial("Robert")
"R."
```

## 4. আদ্যক্ষরগুলো হার্টের ভেতরে বসান

`couple` মেথডটি ইমপ্লিমেন্ট করুন।
এটি দুটি নাম নেবে এবং দুপাশে ইমোজি হার্ট দিয়ে আদ্যক্ষরগুলো রিটার্ন করবে।
আগের ধাপে আপনি যে `initial` ডিফাইন করেছিলেন সেটি আবার ব্যবহার করতে ভুলবেন না।

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
