# পরিচিতি

## ইনাম

C#-এর `enum` টাইপ নির্দিষ্ট নামযুক্ত কনস্ট্যান্টের একটি সেট প্রকাশ করে। এর মূল উদ্দেশ্য হলো সংখ্যাসূচক কনস্ট্যান্টের সাথে টাইপ-সেফ উপায়ে কাজ করার সুযোগ দেওয়া, যেখানে উপলব্ধ মানগুলো আগে থেকেই নির্ধারিত একটি সেটে সীমাবদ্ধ থাকে। একটি সাধারণ ইনাম এভাবে ডিফাইন করা যায়:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

স্পষ্টভাবে ডিফাইন করা না হলে, ইনামের সদস্যগুলো স্বয়ংক্রিয়ভাবে ক্রমবর্ধমান ইন্টিজার মান পায়, যেখানে প্রথম মানটি শূন্য। চাইলে স্পষ্টভাবেও মান অ্যাসাইন করা যায়:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
