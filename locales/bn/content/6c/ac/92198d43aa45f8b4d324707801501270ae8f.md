# নির্দেশনা

এই অনুশীলনীতে আপনি কারখানার কর্মীদের জন্য নেম ব্যাজ প্রিন্ট করার কোড লিখবেন।

## 1. একজন কর্মীর জন্য ব্যাজ প্রিন্ট করুন

কর্মীদের একটি ID, একটি নাম ও একটি ডিপার্টমেন্টের নাম থাকে। কর্মীদের ব্যাজের লেবেল এভাবে ফরম্যাট করা হয়: `"[id] - name - DEPARTMENT"`. একজন কর্মীর ব্যাজের লেবেল রিটার্ন করার জন্য (_static_) `Badge.Print()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

খেয়াল করুন, লেবেলে ডিপার্টমেন্টের নাম বড় হাতের অক্ষরে থাকবে।

## 2. একজন নতুন কর্মীর জন্য ব্যাজ প্রিন্ট করুন

কম্পিউটার সিস্টেমের একটি খুঁতের কারণে, নতুন কর্মীরা কারখানায় কাজ শুরু করার সময় মাঝে মাঝে তখনও কোনো ID পায় না। ব্যাজ বাধ্যতামূলক হওয়ায়, তারা ID প্রিফিক্স ছাড়া একটি অস্থায়ী ব্যাজ পাবে। যে নতুন কর্মীদের তখনও কোনো ID নেই তাদের সাপোর্ট করার জন্য (_static_) `Badge.Print()` মেথডটি পরিবর্তন করুন:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. মালিকের জন্য ব্যাজ প্রিন্ট করুন

এমনকি কারখানার মালিককেও সব সময় একটি ব্যাজ পরতে হয়। তবে মালিকের কোনো ডিপার্টমেন্ট থাকে না। এক্ষেত্রে লেবেলে ডিপার্টমেন্টের নামের বদলে `"OWNER"` প্রিন্ট হওয়া উচিত। মালিকের জন্য একটি লেবেল প্রিন্ট করার জন্য (_static_) `Badge.Print()` মেথডটি পরিবর্তন করুন:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

খেয়াল করুন, মালিকও যে নতুন কর্মী হবেন, সেটা সম্ভব:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
