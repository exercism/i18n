# নির্দেশনা

আপনার DNA গবেষণাগারে আপনি স্টোরেজ জায়গা বাঁচাতে গবেষণার ডেটা কমপ্রেস করার নানা উপায় নিয়ে কাজ করে যাচ্ছেন। একজন সহকর্মী DNA ডেটাকে বাইনারি রূপে রূপান্তর করার প্রস্তাব দেন:

| নিউক্লিক অ্যাসিড | কোড   |
| ------------ | ------ |
| একটি স্পেস      | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

আপনি এটি নিয়ে ভাবেন, কারণ এতে সম্ভবত প্রয়োজনীয় ডেটা স্টোরেজ খরচ অর্ধেক হয়ে যাবে, তবে মানুষের পড়ার সহজতার খরচে। আপনার সঞ্চয় পরিমাপ করতে আপনি ডেটা এনকোড ও ডিকোড করার একটি মডিউল লেখার সিদ্ধান্ত নেন।

## 1. নিউক্লিক অ্যাসিডকে বাইনারি মানে এনকোড করুন

নিউক্লিক অ্যাসিডের কোড পয়েন্ট গ্রহণ করে এনকোড করা কোডের ইন্টিজার মান রিটার্ন করার জন্য `encode_nucleotide/1` ইমপ্লিমেন্ট করুন।

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. বাইনারি মানকে নিউক্লিক অ্যাসিডে ডিকোড করুন

এনকোড করা কোডের ইন্টিজার মান গ্রহণ করে নিউক্লিক অ্যাসিডের কোড পয়েন্ট রিটার্ন করার জন্য `decode_nucleotide/1` ইমপ্লিমেন্ট করুন।

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. একটি DNA চারলিস্ট এনকোড করুন

নিউক্লিক অ্যাসিড ও গ্যাপ প্রতিনিধিত্বকারী একটি চারলিস্ট গ্রহণ করে এনকোড করা ডেটার একটি বিটস্ট্রিং রিটার্ন করার জন্য `encode/1` ইমপ্লিমেন্ট করুন।

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. একটি DNA বিটস্ট্রিং ডিকোড করুন

নিউক্লিক অ্যাসিড ও গ্যাপ প্রতিনিধিত্বকারী একটি বিটস্ট্রিং গ্রহণ করে ডিকোড করা ডেটা একটি চারলিস্ট হিসেবে রিটার্ন করার জন্য `decode/1` ইমপ্লিমেন্ট করুন।

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
