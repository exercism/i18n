# পরিচিতি

অনেক প্রোগ্রামিং ভাষাতেই বিভিন্ন ধরনের সংখ্যা প্রকাশের জন্য আলাদা আলাদা নির্দিষ্ট সংখ্যাসূচক টাইপ থাকে, কিন্তু JavaScript-এ মাত্র দুটি আছে:

- `number`: ডাবল-প্রিসিশন ৬৪-বিট ফ্লোটিং-পয়েন্ট ফরম্যাটে (IEEE 754) একটি সংখ্যাসূচক ডেটা টাইপ।
  উদাহরণ: `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` এবং `500000`।
- `bigint`: একটি সংখ্যাসূচক ডেটা টাইপ, যা আরবিট্রারি প্রিসিশন ফরম্যাটে _ইন্টিজার_ প্রকাশ করতে পারে।
  উদাহরণ: `-12n`, `0n`, `4n`, এবং `9007199254740991n`।

আপনার যদি [আরবিট্রারি প্রিসিশন][ref-arbitrary-precision] দরকার হয় বা অত্যন্ত বড় সংখ্যা নিয়ে কাজ করতে হয়, তাহলে `bigint` টাইপ ব্যবহার করুন।
নাহলে `number` টাইপই সম্ভবত ভালো পছন্দ।

## রাউন্ডিং

`Math` নামে একটি বিল্ট-ইন গ্লোবাল অবজেক্ট আছে, যা বিভিন্ন [রাউন্ডিং ফাংশন][ref-math-object-rounding] দেয়। উদাহরণস্বরূপ, আপনি দশমিক সংখ্যাকে নিকটতম পূর্ণসংখ্যায় নিচের দিকে (`floor`) বা উপরের দিকে (`ceil`) রাউন্ড করতে পারেন।

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

[ref-arbitrary-precision]: https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic
