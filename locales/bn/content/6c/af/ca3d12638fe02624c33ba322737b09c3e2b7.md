# রেঞ্জ

[রেঞ্জ][range] হলো দুটি মানের মধ্যবর্তী একটি ব্যবধান।
রেঞ্জ সমর্থন করে এমন সবচেয়ে কমন টাইপগুলো হলো `Integer` এবং `String`।
এগুলো অনেক কাজে ব্যবহার করা যায়, যেমন দ্রুত একটি কালেকশন তৈরি করা, স্ট্রিং স্লাইস করা, কোনো মান রেঞ্জের মধ্যে আছে কি না তা চেক করা, আর ইটারেশন।
এগুলো তৈরি করা হয় রেঞ্জ অপারেটর `..` বা `...` দিয়ে (যথাক্রমে ইনক্লুসিভ ও এক্সক্লুসিভ)।

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

দুটি রেঞ্জ অপারেটর থাকার কারণ হলো শেষ মানসহ বা শেষ মান ছাড়া রেঞ্জ তৈরি করার সুযোগ দেওয়া, যা কাজে লাগে যেমন জিরো-বেজড ইনডেক্স নিয়ে কাজ করার সময়।

`Range` কনস্ট্রাক্টর `new` ব্যবহার করেও রেঞ্জ তৈরি করা যায়।

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
রুবিতে `..` বা `...` রেঞ্জ অপারেটর দিয়ে একটি রেঞ্জ তৈরি করার সময় যদি আপনি রেঞ্জের ওপর কোনো মেথড কল করতে চান, তাহলে রেঞ্জটিকে বন্ধনীর মধ্যে রাখতে হবে।
কারণ অন্যথায় মেথডটি রেঞ্জ অপারেটরের দ্বিতীয় আর্গুমেন্টের ওপর কল হবে।

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## সাবস্ট্রিং বের করা

স্ট্রিং স্লাইস করতে চাইলে সাবস্ট্রিং পেতে রেঞ্জ অপারেটর ব্যবহার করা যায়।
অর্থাৎ, সাবস্ট্রিংয়ের শুরু ও শেষ ইনডেক্স দিয়ে একটি রেঞ্জ তৈরি করে।

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

স্ট্রিংয়ের শেষ থেকে সাবস্ট্রিং পেতে নেগেটিভ ইনডেক্সও ব্যবহার করা যায়।

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## রেঞ্জের মেথডগুলো

রেঞ্জের সাথে কাজ করার জন্য কিছু মেথড আছে।
যেমন, এসব মেথড দিয়ে রেঞ্জের সব মানের যোগফল পাওয়া যায় বা রেঞ্জে কোনো মান আছে কি না তা চেক করা যায়।

| মেথড                  | বর্ণনা                                                             | উদাহরণ                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | রেঞ্জের সব মানের যোগফল রিটার্ন করে                          | `(1..5).sum # => 15`            |
| [`size`][size]          | রেঞ্জের আকার রিটার্ন করে                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | রেঞ্জে প্রদত্ত মান থাকলে `true`, অন্যথায় `false` রিটার্ন করে | `(1..5).include?(3) # => true` |

## এন্ডলেস ও বিগিনলেস রেঞ্জ

একটি রেঞ্জ এন্ডলেস ও বিগিনলেস হতে পারে।
এন্ডলেস বা বিগিনলেস রেঞ্জের শুরু বা শেষ মান `nil` হয়, তবে রেঞ্জ ডিফাইন করার সময় `nil` বাদ দেওয়া যায়।

বিগিনলেস ও এন্ডলেস রেঞ্জ কাজে লাগে যখন আপনি চান, যেমন, স্ট্রিংয়ের শুরু থেকে বা শেষ পর্যন্ত স্লাইস করতে।

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
কোনো কালেকশনের ওপর ব্যবহার না করলে, সাবধান না থাকলে এন্ডলেস রেঞ্জ একটি এন্ডলেস সিকোয়েন্স তৈরি করতে পারে।
~~~~

## স্ট্রিং রেঞ্জ

স্ট্রিংও রেঞ্জে ব্যবহার করা যায়, আর এভাবে দুই স্ট্রিংয়ের মধ্যবর্তী স্ট্রিংয়ের ইন্টারভাল পাওয়া যায়।
কিছু স্ট্রিং ব্যবহার করলে এর আচরণ একটু অপ্রত্যাশিত হতে পারে, তাই সাবধানে ব্যবহার করুন।

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
