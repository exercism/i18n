# নির্দেশনা

বন্ধুদের সাথে গেম নাইটের পরিকল্পনা করতে করতে দলটি ঠিক করে যে তারা তাদের শৈশবের প্রিয় খেলাগুলোতে ফিরে যাবে। আপনার জার্মান বন্ধু _Mensch ärgere Dich nicht_ (_মানুষ, রাগ করবেন না_) প্রস্তাব করে, যা অনেক ইউরোপীয় দেশে একটি ক্লাসিক (ইংরেজি _Ludo_ বা উত্তর আমেরিকার _Parcheesi_-এর মতো)।

খেলার প্রস্তুতি নিতে আপনি Elixir-এ ডাই রোল করার ফাংশনটি তৈরি করার সিদ্ধান্ত নেন।

_Mensch ärgere Dich nicht_-এ খেলোয়াড়েরা পরের চাল নির্ধারণ করতে একটি ৬-তাহার ডাই রোল করে। ভাগ্য ভালো থাকলে যদি ৬ পড়ে, তবে তারা আবার রোল করে চাল দিতে পারে।

## 1. একটি ৬-তাহার ডাই একবার রোল করুন

`d6/0` ফাংশনটি তৈরি করুন, যা প্রতিবার কল করা হলে ১ থেকে ৬-এর মধ্যে একটি ইন্টিজার এলোমেলোভাবে বেছে নেবে।

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. যতক্ষণ ৬ পড়ছে ততক্ষণ রোল চালিয়ে যান

`roll/0` ফাংশনটি তৈরি করুন। এটি ডাই রোলের একটি স্ট্রিম রিটার্ন করবে। ডাই রোলগুলো খেলার নিয়ম অনুসরণ করবে। আমি যদি ৬ রোল করি, তবে আবার রোল করতে পারি। অন্যথায় রোল করা বন্ধ হয়ে যাবে। আগের ধাপে ডিফাইন করা `d6/0` ফাংশনটি ব্যবহার করুন।

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. রিগড ডাই ব্যবহারের সুযোগ দিন

আপনার কোড পরীক্ষা করা সহজ করতে একটি রিগড ডাই ব্যবহারের সুযোগ দিন।

`roll/0` ফাংশনটি সম্প্রসারিত করুন। এটি একটি ঐচ্ছিক আর্গুমেন্ট গ্রহণ করবে, যা আসলে একটি ফাংশন। আর্গুমেন্টটি পাস করা হলে সেটি দিয়েই ডাই রোল করুন। অন্যথায় `MenschAergereDichNicht.d6/0`-এ ফিরে যান।

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
