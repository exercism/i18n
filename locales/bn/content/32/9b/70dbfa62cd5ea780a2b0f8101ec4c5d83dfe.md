# পরিচিতি

`if` স্টেটমেন্টের পাশাপাশি JavaScript-এ `switch` স্টেটমেন্টও আছে, যা দিয়ে শর্তসাপেক্ষে লজিক চালানো যায়।
একটি মাত্র ভ্যারিয়েবলকে একাধিক বিকল্পের সাথে তুলনা করতে হলে এটি ব্যবহার করা হয়।
তুলনাটি করা হয় স্ট্রিক্ট ইকুয়ালিটি (`===`) যাচাই করে, দেখুন [তুলনার কনসেপ্ট][concept-comparison]।
কোনো একটি ভ্যারিয়েবল `x`-এর জন্য JavaScript-এ `switch` স্টেটমেন্টের সিনট্যাক্স নিচের মতো।

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default` কেসটি ঐচ্ছিক, আর অন্য কোনো বিকল্প ভ্যারিয়েবলটির সাথে না মিললে কিছু কোড চালাতে চাইলে এটি ব্যবহার করা হয়।

উপরের `break` স্টেটমেন্টগুলো দরকার, কারণ JavaScript-এ ডিফল্টভাবে সব কেসই "ফলথ্রু"।
এর মানে হলো, কোনো `break` স্টেটমেন্ট ছাড়া প্রথম যে বিকল্পটি মিলেছে তার নিচের সব কেসের কোডই চালানো হবে, যদিও `x` ওই বিকল্পগুলোর সাথে মেলেনি।
`switch` ব্যবহার করার সময় JavaScript-এ এই "ডিফল্টভাবে ফলথ্রু" আচরণ একটি কমন বিপদ।
ফাংশনের ভেতরে এই সমস্যা এড়াতে `break`-এর বদলে `return`-ও ব্যবহার করা যায়।
