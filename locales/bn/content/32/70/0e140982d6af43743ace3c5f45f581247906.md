# সম্পর্কে

Haskell ফাংশন লেখার সময় আমরা [প্যাটার্ন ম্যাচিং][pattern-matching] ব্যবহার করতে পারি।
প্যাটার্ন ম্যাচিং Haskell-এর একটি অত্যন্ত শক্তিশালী ফিচার, যা দিয়ে আপনি ডেটা কনস্ট্রাক্টরের সাথে মেলাতে এবং প্যাটার্নের ভেতরের মানের সাথে ভ্যারিয়েবল বাইন্ড করতে পারেন।
নাম থেকেই বোঝা যায়, আমরা মানকে প্যাটার্নের সাথে মেলাই, আর মানটি যদি প্যাটার্নের সাথে মেলে, তাহলে আমরা প্যাটার্নের ভেতরের মানের সাথে ভ্যারিয়েবল বাইন্ড করতে পারি।
প্যাটার্ন ম্যাচিং মূলত এই ধারণাগুলো নিয়ে গঠিত: মান চেনা, ভ্যারিয়েবল বাইন্ড করা এবং মান ভেঙে ফেলা।

~~~~exercism/note
Elixir-এর মতো ভাষায় প্যাটার্ন ম্যাচিং Haskell-এর প্যাটার্ন ম্যাচিং থেকে একটু আলাদা।
যেমন Elixir একটি প্যাটার্নে একই বাইন্ডিং নাম একাধিকবার থাকতে দেয়, কিন্তু Haskell দেয় না।
~~~~


এই ফাংশনটি ধরুন:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

এখানে আমাদের একটি ফাংশন `lucky` আছে, যা একটি `Int` নেয় এবং একটি `String` রিটার্ন করে।
আমরা এই ফাংশনের জন্য দুটি প্যাটার্ন ডিফাইন করেছি: একটি `7` সংখ্যাটির সাথে মেলে, আর অন্যটি যেকোনো সংখ্যার সাথে মেলে। নাম যেকোনো কিছুই হতে পারে (যতক্ষণ তা Haskell-এর নামকরণের প্রচলিত নিয়ম মেনে চলে), তবে এখানে আমরা `x` ব্যবহার করেছি।
সংখ্যাটি `7` হলে ফাংশনটি `"Lucky number seven!"` রিটার্ন করবে, নাহলে এটি `"Sorry, you're out of luck, pal!"` রিটার্ন করবে।
এখানে লক্ষণীয় বিষয় হলো, প্যাটার্নগুলো উপর থেকে নিচে চেক করা হয়, তাই আমরা যদি প্যাটার্নগুলোর ক্রম বদলে দিতাম, ফাংশনটি সবসময় `"Lucky number seven!"` রিটার্ন করত।

## অ্যারের প্যাটার্ন

খুব কমন একটি প্যাটার্ন হলো অ্যারের সাথে মেলানো, অর্থাৎ অ্যারের হেড ও টেইল নেওয়া।
এর কারণ, অ্যারেটি আসলে লিঙ্কড লিস্ট আকারে গঠিত।
নিচে এমন একটি ফাংশনের উদাহরণ দেওয়া হলো, যা একটি অ্যারের হেড ও টেইল রিটার্ন করে:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

এখানে আমাদের দুটি প্যাটার্ন আছে, একটি খালি অ্যারের সাথে মেলে, আর অন্যটি অন্তত একটি এলিমেন্টওয়ালা অ্যারের সাথে মেলে।
এর কারণ হলো, অ্যারেটি খালি হলে তার জন্য একটি কেস রাখা দরকার, নাহলে আমরা একটি রানটাইম এরর পাব।
অ্যারেটি খালি না হলে, আমরা অ্যারের হেডকে `x`-এর সাথে এবং টেইলকে `xs`-এর সাথে মেলাতে পারি।
এটি করা হয় `:` (cons) অপারেটর দিয়ে, যা একটি অ্যারের সামনে একটি এলিমেন্ট বসাতে ব্যবহৃত হয়।
কিন্তু প্যাটার্ন ম্যাচিংয়ে এটি আমাদের একটি অ্যারেকে তার হেড ও টেইলে ভেঙে ফেলার সুযোগ দেয়, অর্থাৎ একভাবে ঠিক উল্টো কাজ করে।

`xs` হলো অ্যারের টেইলের জন্য একটি কমন নাম; এটি বোঝায় যে এটি একটি অ্যারে। তবে আপনি যদি একটি নেস্টেড অ্যারে নিয়ে কাজ করেন, তাহলে বোঝাতে `xss` ব্যবহার করতে পারেন যে এটি অ্যারের অ্যারে।

## টাপলের প্যাটার্ন

অ্যারের মতোই, আমরা টাপলের সাথেও মেলাতে পারি।
নিচে এমন একটি ফাংশনের উদাহরণ, যা একটি টাপল নেয় এবং প্রথম ও দ্বিতীয় এলিমেন্ট রিটার্ন করে:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

এখানে আমাদের এমন একটি প্যাটার্ন আছে যা দুটি এলিমেন্টযুক্ত একটি টাপলের সাথে মেলে: প্রথম এলিমেন্টটি `x`-এ এবং দ্বিতীয় এলিমেন্টটি `y`-এ বাইন্ড করা হয়।

## ওয়াইল্ডকার্ড প্যাটার্ন

কখনও কখনও কোনো ভ্যারিয়েবলের মান নিয়ে আমাদের কিছু যায় আসে না, আমরা শুধু প্যাটার্নের সাথে মেলাতে চাই।
এখানেই ওয়াইল্ডকার্ড প্যাটার্নের কাজ, এটি একটি আন্ডারস্কোর `_` দিয়ে বোঝানো হয়।

নিচে এমন একটি ফাংশনের উদাহরণ, যা একটি অ্যারের প্রথম এলিমেন্ট রিটার্ন করে:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

এখানে আমরা বলছি যে অ্যারের টেইল আমাদের দরকার নেই, তাই এটি উপেক্ষা করতে ওয়াইল্ডকার্ড প্যাটার্ন ব্যবহার করি।

## টাইপ প্যাটার্ন

আমরা টাইপের সাথেও মেলাতে পারি, এটি করা হয় ওই টাইপের কনস্ট্রাক্টর ব্যবহার করে।
আমরা টাইপ থেকে মানও বের করতে পারি, যেমনটি টাপলের ক্ষেত্রে করেছি।

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

প্রথম প্যাটার্নে আমরা `Guest` কনস্ট্রাক্টরের সাথে মেলাই, আর দ্বিতীয় প্যাটার্নে আমরা `User` কনস্ট্রাক্টরের সাথে মেলাই এবং ভেতরের মানটি `name`-এ বাইন্ড করি।
