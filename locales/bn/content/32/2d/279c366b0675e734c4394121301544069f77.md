# পরিচিতি

কখনো কখনো স্টেটযুক্ত একটি অবজেক্ট তৈরি করার বাড়তি ঝামেলার দরকার পড়ে না। এমন ক্ষেত্রে একটি `module` ব্যবহার করা যায়।

একটি মডিউল অনেকটাই একটি ক্লাসের মতো (আসলে অবজেক্ট হায়ারার্কিতে `Module` হলো `Class`-এর পূর্বপুরুষ)। মূল পার্থক্য হলো এই যে, ইনস্ট্যান্স মেথডের বদলে আমরা ক্লাস মেথড ব্যবহার করি। ক্লাস মেথড `self.` দিয়ে শুরু হয় এবং সরাসরি একটি মডিউলের উপর কল করা হয়।

উদাহরণস্বরূপ:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
