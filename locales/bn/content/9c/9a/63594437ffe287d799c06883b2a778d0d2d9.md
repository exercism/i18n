# নির্দেশনা

ওয়েলিংটনের আবহাওয়া স্টেশন তাদের হাতে চালানো তাপমাত্রা রেকর্ডিং সিস্টেমের বদলে একটি নতুন ডিজিটাল সিস্টেম বসাতে যাচ্ছে।
পুরনো সিস্টেমে হিসাবগুলো হাতে করা হতো।
নতুন সিস্টেমে সেগুলো স্বয়ংক্রিয় করা হবে।
হিসাবের মধ্যে রয়েছে সেলসিয়াস থেকে ফারেনহাইটে তাপমাত্রা রূপান্তর এবং গড় তাপমাত্রা নির্ণয়।
নতুন সিস্টেমে সেলসিয়াসে তাপমাত্রার ডেটা রেকর্ড করার সেন্সর আছে।

ওয়েলিংটনের আবহাওয়া স্টেশন চায় আপনি নতুন সিস্টেমে তাদের সাহায্য করুন।

## 1. সেলসিয়াস থেকে কেলভিনে তাপমাত্রা রূপান্তর করুন

আবহাওয়া স্টেশনের ওয়েবসাইটে গবেষকদের জন্য নির্ধারিত একটি অংশ আছে।
গবেষকরা কেলভিনে তাপমাত্রা জানতে আগ্রহী।

কেলভিন হলো তাপমাত্রা মাপার একটি একক।
এটি সেলসিয়াসের মতো একই স্কেলে, তবে শুরুর বিন্দু আলাদা।
এর শুরুর বিন্দু পরম শূন্য, যা 0K (কেলভিন) বা -273.15°C (সেলসিয়াস)।

সেলসিয়াস ও কেলভিনের মধ্যে রূপান্তর দেখানো একটি টেবিল এখানে:

| সেলসিয়াস(°C) | কেলভিন(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

আবহাওয়া স্টেশন চায় আপনি এমন একটি মেথড তৈরি করুন যা সেলসিয়াস থেকে কেলভিনে তাপমাত্রা রূপান্তর করে।

`Temperature#to_kelvin` মেথডটি তৈরি করুন, যা একটি `celsius` আর্গুমেন্ট নেয় এবং দেওয়া `celsius` মানের সাথে 273.15 যোগ করে কেলভিনে তাপমাত্রা রিটার্ন করে।

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. তাপমাত্রা রাউন্ড করুন

আবহাওয়া স্টেশনের তাপমাত্রা সেন্সরটি নির্ভুল।
এটি 0.0001°C পর্যন্ত সূক্ষ্মভাবে তাপমাত্রা মাপতে পারে।
আবহাওয়া স্টেশন শুধু ১ দশমিক স্থান পর্যন্ত রাউন্ড করা তাপমাত্রা দেখাতে চায়, কারণ বেশিরভাগ ব্যবহারকারী এতটা নির্ভুলতায় আগ্রহী নন।

আবহাওয়া স্টেশন চায় আপনি এমন একটি মেথড তৈরি করুন যা তাপমাত্রাকে ১ দশমিক স্থান পর্যন্ত রাউন্ড করে।

`Temperature#round` মেথডটি তৈরি করুন, যা একটি `celsius` আর্গুমেন্ট নেয় এবং ১ দশমিক স্থান পর্যন্ত রাউন্ড করা তাপমাত্রা রিটার্ন করে।

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. সেলসিয়াস থেকে ফারেনহাইটে তাপমাত্রা রূপান্তর করুন

আবহাওয়া স্টেশনের ওয়েবসাইটে পর্যটকদের জন্য নির্ধারিত একটি অংশ আছে।
পর্যটকরা ফারেনহাইটে তাপমাত্রা জানতে আগ্রহী।

ফারেনহাইট তাপমাত্রা পরিমাপের একটি একক।
এর স্কেল সেলসিয়াসের থেকে আলাদা।
0°C হলো 32°F, আর 1 ডিগ্রি সেলসিয়াস সমান 1.8 ডিগ্রি ফারেনহাইট।

সেলসিয়াস ও ফারেনহাইটের মধ্যে রূপান্তর দেখানো একটি টেবিল এখানে:

| সেলসিয়াস(°C) | ফারেনহাইট(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148            |
| 0           | 32             |
| 100         | 212            |

আবহাওয়া স্টেশন চায় আপনি এমন একটি মেথড তৈরি করুন যা সেলসিয়াস থেকে ফারেনহাইটে তাপমাত্রা রূপান্তর করে।

`Temperature#to_fahrenheit` মেথডটি তৈরি করুন, যা একটি `celsius` আর্গুমেন্ট নেয় এবং ফারেনহাইটে তাপমাত্রা পূর্ণসংখ্যা হিসেবে রিটার্ন করে।

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. অনুপস্থিত সেন্সরের সংখ্যা বের করুন

তাপমাত্রা সেন্সর বসানোর সময় রক্ষণাবেক্ষণ কর্মীরা বুঝতে পারলেন কিছু সেন্সর অনুপস্থিত।
প্রতিটি তাপমাত্রা পরিমাপ ইউনিটের জন্য চারটি তাপমাত্রা সেন্সর লাগে।
রক্ষণাবেক্ষণ দল গুনে দেখল তাদের কাছে কতগুলো সেন্সর আছে, কিন্তু কতগুলো নেই সেটাও জানা দরকার ছিল।
আরও একটি সম্পূর্ণ তাপমাত্রা পরিমাপ ইউনিট তৈরি করতে তাদের কতগুলো সেন্সর কিনতে হবে, তা গুনতে তারা সাহায্য চায়।

`Temperature#number_missing_sensors` মেথডটি তৈরি করুন, যা একটি `number_of_sensors` আর্গুমেন্ট নেয় এবং অনুপস্থিত সেন্সরের সংখ্যা রিটার্ন করে।

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
