# নির্দেশাবলীর সংযোজন

কেন কায়রোতে অ্যারে নিয়ে কাজ করা অন্য প্রোগ্রামিং ভাষার মতো সহজ নয়, তা বুঝতে হলে মনে রাখা সহায়ক যে কায়রো একটি ইমিউটেবল মেমরি মডেল ব্যবহার করে, যার মানে হল একবার কোনো মেমরি সেলে লেখা হলে সেটি কখনোই ওভাররাইট করা যায় না, শুধু পড়া যায়।

ভাষাটি এই বৈশিষ্ট্যটিকে কিছুটা অ্যাবস্ট্রাক্ট করে দেয়, যা ডেভেলপারদের তাদের ভ্যারিয়েবলগুলো এমনভাবে ডিক্লেয়ার ও ব্যবহার করতে দেয় যেন সেগুলো মিউটেবল।

যদিও এটি code লেখাকে একটু বেশি চ্যালেঞ্জিং করে তোলে, বিশেষ করে সেই code যা `Array` টাইপ ব্যবহার করে (`ByteArray` সহ, যা আসলে একটি "বাইটের অ্যারে"), এটি _প্রমাণযোগ্য_ প্রোগ্রাম লেখা সম্ভব করে, যা অবিশ্বস্ত মেশিনেও আত্মবিশ্বাসের সাথে চালানো যায়, যা এই ট্রেড-অফকে যথেষ্ট সার্থক করে তোলে।
