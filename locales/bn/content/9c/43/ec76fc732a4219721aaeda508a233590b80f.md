# পরিচিতি

অ্যারে হলো Factor-এর প্রধান নির্দিষ্ট দৈর্ঘ্যের সিকোয়েন্স টাইপ, যা লেখা হয়
`{ … }` দিয়ে: আপনি এর এলিমেন্টগুলো বদলাতে পারেন, তবে দৈর্ঘ্য বদলাতে পারেন না।
`arrays` আর `sequences` ভোকাবুলারি দুটি একসাথে আপনাকে ছোট ছোট কনস্ট্রাক্টর দেয়, যেগুলো
স্ট্যাক থেকে মান নিয়ে নেয়, আর দেয় জোড়া লাগানো, উল্টে দেওয়া আর এলিমেন্ট খোঁজার মতো
নিত্যদিনের অপারেশনও।

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
