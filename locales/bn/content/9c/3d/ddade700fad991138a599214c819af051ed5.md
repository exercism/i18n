# পরিচিতি

Go-তে প্রতিটি ভ্যারিয়েবলের একটি মান থাকে।
কোনো মান অ্যাসাইন না করে একটি ভ্যারিয়েবল ডিক্লেয়ার করলে, এটিকে তার টাইপের শূন্য মানে সেট করা হয়।

মৌলিক টাইপ, যেমন `bool`, নিউমেরিক টাইপ, এবং `string`, প্রত্যেকেরই একটি নির্দিষ্ট শূন্য মান থাকে:

| টাইপ                   | শূন্য মান |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, etc. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

পয়েন্টার, ফাংশন, ইন্টারফেস, স্লাইস, চ্যানেল এবং ম্যাপ প্রত্যেকের শূন্য মান `nil` হয়।

অ্যারে এবং স্ট্রাক্ট কখনোই `nil` হয় না, কারণ তারা ডেটা সরাসরি ধারণ করে, এর প্রতি রেফারেন্স নয়।
একটি অ্যারের প্রতিটি এলিমেন্ট এবং একটি স্ট্রাক্টের প্রতিটি ফিল্ড তার নিজের টাইপের শূন্য মানে ইনিশিয়ালাইজ করা হয়।
উদাহরণস্বরূপ, `var a [3]int` অ্যারেটি `[0, 0, 0]` তৈরি করে।

## শূন্য মান ডিক্লেয়ার করা

একটি ডিক্লেয়ারেশনের জন্য `var` ব্যবহার করুন:

```go
var myBool bool   // false
var mySlice []int // nil
```

স্ট্রাক্টের জন্য একটি কম্পোজিট লিটারাল `T{}` ব্যবহার করুন:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
