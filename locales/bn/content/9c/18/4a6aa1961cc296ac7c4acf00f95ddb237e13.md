# কোড অন্তর্ভুক্তি

`circus-acts`-এ `<` দিয়ে বোঝানো হয়েছিল যে একটি ক্লাস একটি অ্যাবস্ট্রাক্ট ক্লাস যা বর্ণনা করে, তা *করতে পারে*। কিন্তু কীভাবে, তা নিয়ে কিছুই বলা হয়নি।

`include` হলো এর অন্য অর্ধেক: এটি অন্য একটি ক্লাস থেকে আসল কোড নিয়ে এসে এই ক্লাসে তার একটি কপি বসিয়ে দেয়।

```sather
class WARM_UP is

   count : INT is return 8; end;

   describe : STR is return count + " counts"; end;

end; -- class WARM_UP

class JAZZ_ROUTINE is

   include WARM_UP;

   -- count and describe are now here too, as though written out.

end; -- class JAZZ_ROUTINE
```

`JAZZ_ROUTINE`-এ কোথাও উল্লেখ না থাকলেও `JAZZ_ROUTINE::count`-এর মান ৮।

## এগুলি দুটি আলাদা সিদ্ধান্ত

বেশিরভাগ ভাষা এই দুটিকে একসাথে জোড়ে: একটি `extends` একইসাথে কোডটি উত্তরাধিকারসূত্রে দিয়ে দেয় এবং যেখানে সুপারক্লাস চলে সেখানেই সাবক্লাসকে ব্যবহারযোগ্য করে তোলে। Sather এই দুটিকে আলাদা রাখে।

| যা লেখা হয় | যা বোঝায় |
| --- | --- |
| `class A < $B` | `$B` যেখানে দরকার, সেখানে একটি `A` ব্যবহার করা যায় |
| `class A is include B` | `A` শুরু হয় `B`-এর কোডের একটি কপি দিয়ে |

একটি ছাড়া অন্যটি, কিংবা দুটিই একসাথে। কোনো ক্লাস অন্তর্ভুক্ত করলে সেটি সাবটাইপ হয়ে যায় **না**: `include WARM_UP` করার পরেও যেখানে `WARM_UP` দরকার সেখানে `JAZZ_ROUTINE` ব্যবহার করা যায় না, আর এর উল্টোটা ভানও করা হয় না।

## নতুন নাম দেওয়া

অন্তর্ভুক্ত করা রুটিনকে ভিন্ন একটি নামে নিয়ে আসা যায়:

```sather
   include WARM_UP count -> warm_up_count;
```

একাধিক রুটিনকে কমা দিয়ে আলাদা করা হয়:

```sather
   include WARM_UP count -> warm_up_count, describe -> warm_up_describe;
```

## একটি বাদ দেওয়া

*কিছু না*-তে নাম বদলালে সেটি বাদ পড়ে যায়, আর এভাবেই সেটিকে প্রতিস্থাপন করা হয়:

```sather
class TAP_ROUTINE is

   include WARM_UP describe -> ;

   describe : STR is return "Tap: " + count + " counts"; end;

end; -- class TAP_ROUTINE
```

`count` যথারীতি ভেতরে আসে; `describe` আসে না, তাই এখানে একটি লিখে দিলে কোনো সংঘর্ষ হয় না। `describe -> ;` না থাকলে কম্পাইলার রাজি হতো না: একই ক্লাসে একই নাম ও আর্গুমেন্টের দুটি রুটিন থাকা একটি এরর, আর আপনি কোনটি চেয়েছেন তা Sather অনুমান করবে না।

বেশিরভাগ ভাষার ওভাররাইডের সাথে এখানেই পার্থক্য: প্রতিস্থাপনটি ইঙ্গিত করে নয়, ঘোষণা করেই করা হয়।
