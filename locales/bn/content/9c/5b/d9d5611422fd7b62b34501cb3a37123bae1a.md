# ভূমিকা

একটি টাইপ ডেফিনিশন একটি নতুন নামযুক্ত টাইপ তৈরি করে, যা অন্য সব টাইপ থেকে আলাদা, এমনকি একই আন্ডারলাইং টাইপের হলেও।

## টাইপ ডিফাইন করা

একটি টাইপ ডেফিনিশন শুরু হয় `type` কিওয়ার্ড দিয়ে, তারপর আসে নতুন টাইপের নাম ও তার আন্ডারলাইং টাইপ:

```go
type File []bool
```

এখানে `File` বলতে দাবাবোর্ডের একটি খাড়া কলাম বোঝায়, যা সাধারণত A থেকে H পর্যন্ত লেবেল করা হয়।
এই কলামের প্রতিটি ঘর একটি বুলিয়ান মান দিয়ে প্রকাশ করা হয়, যা বোঝায় ঘরটি দখল করা আছে কি না।
এখন যেহেতু `File` ডিফাইন করা হয়েছে, আমরা এটিকে অন্য ডেফিনিশনের ভেতরে ব্যবহার করতে পারি:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` কলামের শনাক্তকারীগুলোকে `File` মানের সঙ্গে ম্যাপ করে।
প্রতিটি `File` হলো বুলিয়ান মানের একটি স্লাইস, যা দাবার একটি কলামের ঘরগুলো প্রকাশ করে।
এই টাইপ ডেফিনিশনগুলো ছাড়া `board` হতো একটি `map[string][]bool`, ফলে আমরা কী প্রকাশ করছি তা বোঝা আরও কঠিন হয়ে যেত।
