# পরিচিতি

## অ্যারে

জাভাতে অ্যারে হলো একই টাইপের একাধিক মান একটি কাঠামোয় জমা রাখার একটি উপায়।
অন্য ডেটা স্ট্রাকচারের মতো নয়, অ্যারে একবার তৈরি হলে তার আকার আর পরিবর্তন করা যায় না।
ইনডেক্স ব্যবহার করে অ্যারেতে এলিমেন্ট অ্যাসাইন করা যায় বা অ্যারে থেকে সেগুলো বের করা যায়।
জাভার অ্যারেতে জিরো-বেজড ইনডেক্সিং ব্যবহৃত হয়: প্রথম এলিমেন্টের ইনডেক্স 0, দ্বিতীয় এলিমেন্টের ইনডেক্স 1, ইত্যাদি।

অ্যারে ইনিশিয়ালাইজ করার স্ট্যান্ডার্ড সিনট্যাক্স হলো:

```java
type[] variableName = new type[size];
```

এখানে `type` হলো অ্যারেতে থাকা এলিমেন্টগুলোর টাইপ, যা একটি প্রিমিটিভ টাইপ (যেমন `int`) বা একটি ক্লাস (যেমন `String`) হতে পারে।

`size` হলো এই অ্যারেটি যতগুলো এলিমেন্ট ধারণ করবে তার সংখ্যা (যা পরে আর পরিবর্তন করা যাবে না)।
অ্যারে তৈরি হওয়ার পর এলিমেন্টগুলো তাদের ডিফল্ট মানে ইনিশিয়ালাইজ হয় (সাধারণত `0`, `false` বা `null`)।

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

শর্টকাট নোটেশন ব্যবহার করেও অ্যারে ডিফাইন করা যায়, যার মাধ্যমে আপনি একইসাথে অ্যারে তৈরি করতে এবং তার মান সেট করতে পারেন:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

যেহেতু এখন কম্পাইলার বুঝতে পারে অ্যারেতে কতগুলো এলিমেন্ট থাকবে, তাই দৈর্ঘ্য বাদ দেওয়া যায়।

বন্ধনীর মধ্যে ইনডেক্স লেখার নোটেশন ব্যবহার করে অ্যারের এলিমেন্ট অ্যাসাইন ও অ্যাক্সেস করা যায়:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

অ্যারের বৈধ ইনডেক্সের বাইরের কোনো ইনডেক্স অ্যাক্সেস করলে `IndexOutOfBoundsException` হয়।

অ্যারে ম্যানিপুলেট করা যায় হয় কোনো অ্যারে ইনস্ট্যান্সের মেথড বা প্রপার্টি কল করে, নয়তো `Arrays` ক্লাসে ডিফাইন করা স্ট্যাটিক মেথড ব্যবহার করে (সাধারণত শুধু জেনেরিক কোডে ব্যবহৃত হয়)।
`length` প্রপার্টিতে একটি অ্যারের দৈর্ঘ্য থাকে।
এটা এভাবে অ্যাক্সেস করা যায়:

```java
int arrayLength = someArray.length;
```

জাভা এছাড়াও একটি দরকারি ইউটিলিটি ক্লাস [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) দেয়, যেখানে অ্যারে সংক্রান্ত অনেক কাজের মেথড আছে (যেমন `Arrays.equals`)।

জাভা [মাল্টি-ডাইমেনশনাল অ্যারে](https://www.programiz.com/java-programming/multidimensional-array)-ও সাপোর্ট করে, যেমন `int[][] arr = new int[3][4];`, যা খুবই কাজের হতে পারে।

অ্যারে আসলে একটি _কালেকশন_ও, তাই ইনডেক্স দিয়ে মান অ্যাক্সেস করার পাশাপাশি `for-each` লুপ ব্যবহার করে তার _সব_ মানের উপর ইটারেশন করা যায়:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

কোন মানগুলোর উপর ইটারেশন করবেন সে বিষয়ে আরও নিয়ন্ত্রণ চাইলে `for` লুপ ব্যবহার করা যায়:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
