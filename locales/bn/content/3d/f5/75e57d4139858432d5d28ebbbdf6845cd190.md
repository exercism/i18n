# ভূমিকা

Haxe টাইপ ও ফিল্ডের রানটাইম রিফ্লেকশন সমর্থন করে। রিফ্লেকশন সঠিকভাবে ব্যবহার করতে হলে কোন ধরনের অপারেশন সমর্থিত আর কোনটি নয়, সেটি বুঝতে হবে। রিফ্লেকশনের গতিশীল প্রকৃতির কারণে এটি সবসময় কম্পাইল টাইমে নির্ধারণ করা যায় না।

রিফ্লেকশন API-তে দুটি ক্লাস আছে:

- `Reflect`: একটি হালকা API, যা অ্যানোনিমাস স্ট্রাকচারে সবচেয়ে ভালো কাজ করে; ক্লাসের জন্য সমর্থন সীমিত।
- `Type`: ক্লাস ও এনাম নিয়ে কাজ করার জন্য আরও শক্তিশালী API।

নিচের উদাহরণে আমরা JavaScript টার্গেট ব্যবহার করছি:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
