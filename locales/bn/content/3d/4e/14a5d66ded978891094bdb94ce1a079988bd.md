# টেস্ট

## clojure.test

Babashka-এর সঙ্গে clojure.test আগে থেকেই বান্ডল করা থাকে। কোনো অনুশীলনীতে কাজ করার জন্য আপনি প্রস্তুত হয়ে গেলে এবং আপনার সমাধান রাখার জন্য একটি ফাইল তৈরি করে নিলে (যেমন `bob.clj`), আপনি `clojure.test/run-tests` ব্যবহার করে টেস্ট চালাতে পারেন [যেভাবে এখানে বর্ণনা করা হয়েছে](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests)।


REPL-এর সাহায্যে আপনি সহজেই কোড চালাতে পারেন এবং সঙ্গে সঙ্গে ফিডব্যাক পেতে পারেন, আবার টেস্ট চালানোর জন্যও এটি ব্যবহার করা যায়। উপর-নিচের তীরচিহ্ন দিয়ে লাইন এডিটিং ও কমান্ড হিস্টরি চালু করতে `rlwrap` ব্যবহার করার পরামর্শ দেওয়া হয়। একটি অনুশীলনী টেস্ট করতে তার ডিরেক্টরিতে চলে যান এবং ক্লাসপাথে `src` ও `test` ডিরেক্টরি যোগ করে একটি socket REPL খুলুন:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

প্রথমে টেস্ট নেমস্পেসটি `require` করুন:
``` clojure
=> (require 'bob-test)
nil
```

তারপর `bob-test`-এর উপর `run-tests` কল করুন:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

একটি টেস্ট রানার স্ক্রিপ্ট তৈরি করতে:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
