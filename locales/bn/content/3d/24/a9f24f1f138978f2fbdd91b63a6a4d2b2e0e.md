# ভূমিকা

## মূল বিষয়

F#-এ, একটি নামে একটি মান অ্যাসাইন করাকে _বাইন্ডিং_ বলা হয়। বাইন্ডিংগুলি ইমিউটেবল, যা এগুলোকে অন্য ভাষার কনস্ট্যান্টের মতো করে তোলে। যেহেতু F# একটি স্ট্যাটিক্যালি টাইপড ভাষা, তাই প্রতিটি বাইন্ডিংয়ের কম্পাইল-টাইমে একটি টাইপ থাকে।

বাইন্ডিংগুলি `let` কিওয়ার্ড ব্যবহার করে ডিফাইন করা হয়। বেশিরভাগ বাইন্ডিংয়ের জন্য টাইপ উল্লেখ করা ঐচ্ছিক, কারণ F#-এর _টাইপ ইনফারেন্স_ সাধারণত মানের উপর ভিত্তি করে টাইপ অনুমান করতে পারে। একটি বাইন্ডিং দেখতে এমন:

```fsharp
// Automatically inferred type
let fingers = 10
```

ফাংশনগুলিও নিয়মিত বাইন্ডিং, তবে এক বা একাধিক প্যারামিটার সহ। একটি ফাংশন স্বয়ংক্রিয়ভাবে তার শেষ এক্সপ্রেশন রিটার্ন করে। টাইপ ইনফারেন্স বেশিরভাগ ফাংশনের জন্যও কাজ করে, কারণ এটি বিশ্লেষণ করে ফাংশনটি কী কী মান দিয়ে কল করা হয় এবং ফাংশনটি কী মান রিটার্ন করে।

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

একটি ফাংশন কল করা হয় তার নাম উল্লেখ করে এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```fsharp
let five = add 2 3
```

যদি একটি বাইন্ডিংয়ের টাইপ অনুমান করা না যায়, তবে কম্পাইলার একটি এরর রিপোর্ট করবে। এটি ঠিক করতে, বাইন্ডিংয়ে একটি স্পষ্ট টাইপ অ্যানোটেশন যোগ করুন।

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F#-এ বাইন্ডিংগুলি শুধুমাত্র ডিফাইন করার _পরে_ ব্যবহার করা যেতে পারে। কোনো বাইন্ডিং ডিফাইন করার আগে ব্যবহার করলে কম্পাইল এরর হয়।

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# স্কোপ নির্ধারণ করতে সিগনিফিক্যান্ট হোয়াইটস্পেস ব্যবহার করে। এর মানে হল যে স্কোপ বাইন্ডিং ঘোষণা করে এমন লাইনের সাপেক্ষে স্পেস দিয়ে কোড ইনডেন্ট করে নির্ধারণ করা হয়। ডিফল্ট কনভেনশন হল ইনডেন্টেশনের জন্য চারটি স্পেস ব্যবহার করা:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F# বাইন্ডিংগুলি (যার মধ্যে ফাংশনও অন্তর্ভুক্ত) সাধারণত মডিউলে সংগঠিত হয়। একটি মডিউল সম্পর্কিত কার্যকারিতা গ্রুপ করে এবং `module` কিওয়ার্ড ব্যবহার করে ডিফাইন করা হয়। মডিউল ডেফিনিশনটি এর বাইন্ডিংগুলির আগে থাকতে হবে:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# দুই ধরনের কমেন্ট সমর্থন করে। একলাইন কমেন্টের আগে `//` থাকে এবং মাল্টিলাইন কমেন্ট `(*` এবং `*)` এর মধ্যে লেখা হয়।
