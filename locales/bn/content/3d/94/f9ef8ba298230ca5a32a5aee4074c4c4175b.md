# পরিচিতি


## বুলিয়ান

PowerShell-এ ট্রু ও ফলস মান প্রকাশের জন্য [`bool`][booleans] টাইপ আছে।
এই টাইপে মাত্র দুটি মান আছে: `True` এবং `False`.
`$` প্রিফিক্স দিয়ে আপনি এই মানগুলো ভ্যারিয়েবলে বাঁধতে পারেন:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

`-and`, `-or` আর `-not`-এর মতো [লজিক্যাল অপারেটর][logical-operators] দিয়ে বুলিয়ান এক্সপ্রেশন জোড়া লাগানো ও মূল্যায়ন করা যায়।

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## কমেন্ট-ভিত্তিক হেল্প

PowerShell-এ [`Comment-based help`][comment-based help] কমেন্টে লেখা ফাংশন ও স্ক্রিপ্টের জন্য বিস্তারিত তথ্য দিতে সাহায্য করে।
এটি আলোচনার বিষয়গুলো নির্দিষ্ট করতে `.SYNOPSIS`, `.EXAMPLE` বা `.NOTES`-এর মতো বিশেষ হেল্প কমেন্ট কিওয়ার্ড ব্যবহার করে।

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

`Get-Help` কম্যান্ডলেট দিয়ে কমেন্ট-ভিত্তিক হেল্পের তথ্য দেখাতে পারেন।

```powershell
> Get-Help -Name "ExampleFunction"
```
