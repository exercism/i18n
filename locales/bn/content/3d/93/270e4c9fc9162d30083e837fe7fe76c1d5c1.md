# নির্দেশনা

আপনি একজন আগ্রহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কতগুলো পাখি এসেছে তার হিসাব রাখেন।

আপনার পাঁচটি কাজ আছে, যার সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. গত সপ্তাহের সংখ্যাগুলো কী ছিল দেখুন

তুলনার জন্য আপনি সবসময় কাছে গত সপ্তাহের সংখ্যাগুলোর একটি কপি রাখেন, যেগুলো ছিল: 0, 2, 5, 3, 7, 8 এবং 4। গত সপ্তাহের সংখ্যাগুলো রিটার্ন করে এমন `BirdCount.last_week` মেথডটি ইমপ্লিমেন্ট করুন:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. গতকাল কতগুলো পাখি এসেছিল দেখুন

গতকাল আপনার বাগানে কতগুলো পাখি এসেছিল তা রিটার্ন করতে `BirdCount#yesterday` মেথডটি ইমপ্লিমেন্ট করুন। পাখির সংখ্যাগুলো দিন অনুযায়ী সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরনো দিনের সংখ্যা আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. আসা পাখির মোট সংখ্যা হিসাব করুন

আপনার বাগানে আসা পাখির মোট সংখ্যা রিটার্ন করতে `BirdCount#total` মেথডটি ইমপ্লিমেন্ট করুন:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্য দিনের চেয়ে বেশি ব্যস্ত থাকে। ব্যস্ত দিন বলতে সেই দিনকে বোঝায়, যেদিন পাঁচটি বা তার বেশি পাখি আপনার বাগানে এসেছে।
ব্যস্ত দিনের সংখ্যা রিটার্ন করতে `BirdCount#busy_days` মেথডটি ইমপ্লিমেন্ট করুন:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. কোনো দিন পাখি না আসার ঘটনা ছিল কি না দেখুন

`BirdCount#day_without_birds?` মেথডটি ইমপ্লিমেন্ট করুন, যা `true` রিটার্ন করবে যদি এমন কোনো দিন থাকে যেদিন শূন্য পাখি বাগানে এসেছে; নাহলে `false` রিটার্ন করবে:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
