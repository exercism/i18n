# নির্দেশনা

একটি মামলা যত এগোতে থাকে, একজন গোয়েন্দার নোটবুক তত ভরে ওঠে; আর তদন্তের সূত্রগুলো বাদ পড়তে থাকলে সেটি আবার খালি হয়ে যায়।

পাঁচটি কাজই `CASE_NOTES` ক্লাসে থাকবে।

## 1. একটি মামলা খুলুন

একটি নতুন, খালি নোটবুক রিটার্ন করুন।

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. একটি সূত্র লিখে রাখুন

নোটবুকের শেষে একটি সূত্র যোগ করুন। এটি কোনো উত্তর দেয় না; বরং যে নোটবুকটি দেওয়া হয়, সেটিকেই বদলে দেয়।

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. কতগুলো সূত্র?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. একটি সূত্র বাদ দিন

নির্দিষ্ট অবস্থানে থাকা সূত্রটি নোটবুক থেকে সরিয়ে নিন। এর পরে যা কিছু আছে সব উপরে সরে যায়। এটিও কোনো উত্তর দেয় না।

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. মামলাটি আবার পড়ুন

নোটবুকের প্রতিটি সূত্র `"; "` দিয়ে জোড়া লাগিয়ে রিটার্ন করুন। খালি নোটবুক খালি স্ট্রিং হিসেবে পড়া হয়।

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
