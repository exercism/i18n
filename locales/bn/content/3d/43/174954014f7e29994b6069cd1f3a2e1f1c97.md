# শেখা

Vim-এর সাথে আগে থেকেই দুর্দান্ত ডকুমেন্টেশন দেওয়া থাকে। এই ডকুমেন্টেশন দেখার মাধ্যম হলো `:help` কমান্ড।

পরিচিতির জন্য দেখুন `:h user-manual`।

প্রায় সব Vim ইনস্টলেশনের সাথেই একটি ইন্টারঅ্যাকটিভ টিউটোরিয়াল থাকে:

```
$ vimtutor
```

Vim কয়েক দশকের পুরোনো, তবুও আজও জনপ্রিয়। ওয়েবে এটি নিয়ে অনেক রিসোর্স পাবেন, কোনোটার মান ভালো, কোনোটার খারাপ। ভালোগুলোর তালিকা [এখানে](https://exercism.org/docs/tracks/vimscript/resources) দেওয়া আছে।
