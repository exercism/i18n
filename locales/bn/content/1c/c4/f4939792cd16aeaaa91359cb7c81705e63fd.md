# নির্দেশনা

আপনি একজন আগ্রহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কত পাখি এসেছে তার হিসাব রাখেন।

আপনার পাঁচটি কাজ আছে, যার সবই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. গত সপ্তাহের হিসাবগুলো কী ছিল তা দেখুন

আপনি আপনার পাখির হিসাবগুলো JSON ফরম্যাটে রাখেন।
একটি "main" অ্যারে সাপ্তাহিক হিসাবের অ্যারেগুলো ধারণ করে।
প্রতিটি সাপ্তাহিক হিসাব সাতটি ইন্টিজারের একটি অ্যারে, সপ্তাহের প্রতিটি দিনের জন্য একটি সংখ্যা।
আপনি সবসময় নতুন সপ্তাহগুলো main অ্যারের শেষে যোগ করেন।
গত সপ্তাহের হিসাবগুলো রিটার্ন করে এমন ফিল্টারটি ইমপ্লিমেন্ট করুন।

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. গতকাল কত পাখি এসেছে তা দেখুন

গতকাল আপনার বাগানে কত পাখি এসেছে তা রিটার্ন করার ফিল্টারটি ইমপ্লিমেন্ট করুন।
পাখির হিসাবগুলো দিন অনুসারে সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরনো দিনের হিসাব আর শেষ এলিমেন্টটি আজকের হিসাব।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. আসা পাখির মোট সংখ্যা হিসাব করুন

এই সপ্তাহে আপনার বাগানে যত পাখি এসেছে তার মোট সংখ্যা রিটার্ন করার ফিল্টারটি ইমপ্লিমেন্ট করুন।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্যদের চেয়ে বেশি ব্যস্ত থাকে।
ব্যস্ত দিন মানে এমন একটি দিন, যেদিন আপনার বাগানে পাঁচটি বা তার বেশি পাখি এসেছে।
এই সপ্তাহের ব্যস্ত দিনের সংখ্যা রিটার্ন করার ফিল্টারটি ইমপ্লিমেন্ট করুন।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. কোনো দিন পাখি না আসার ঘটনা ছিল কি না তা দেখুন

এমন ফিল্টারটি ইমপ্লিমেন্ট করুন যা `true` রিটার্ন করে, যদি এই সপ্তাহে এমন কোনো দিন থাকে যখন বাগানে শূন্য পাখি এসেছে; অন্যথায় `false` রিটার্ন করে।

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
