# ভূমিকা

**রিকার্সিভ ফাংশন** হলো এমন ফাংশন যা নিজেকে কল করে।

একটি _রিকার্সিভ ফাংশনে_ অন্তত একটি _বেস কেস_ এবং অন্তত একটি _রিকার্সিভ কেস_ থাকতে হবে।

একটি **বেস কেস** ফাংশনটিকে আবার কল না করেই একটি মান রিটার্ন করে।
একটি **রিকার্সিভ কেস** ফাংশনটিকে আবার কল করে এবং ইনপুট এমনভাবে পরিবর্তন করে যাতে কোনো এক সময়ে সেটি বেস কেসের সঙ্গে মিলে যায়।

এখানে একটি উদাহরণ দেওয়া হলো যা একটি অ্যারের এলিমেন্টগুলো গণনা করে।

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

একটি _রিকার্সিভ ফাংশনে_ অনেক _বেস কেস_ এবং/অথবা অনেক _রিকার্সিভ কেস_ থাকতে পারে।
উদাহরণস্বরূপ [ফিবোনাচি সিকোয়েন্স][wiki-fibonacci] একটি রিকার্সিভ সিকোয়েন্স, যার দুটি _বেস কেস_ আছে।

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

একটি অ্যারেতে কোনো নির্দিষ্ট মান `x` কতবার আছে তা গণনা করার দুটি _রিকার্সিভ কেস_ থাকে।

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

বাস্তবে, অ্যারে এবং অন্যান্য এনুমারেবল ডেটা স্ট্রাকচারের উপর ইটারেশন করা বেশিরভাগ ক্ষেত্রেই বিল্ট-ইন ফাংশন দিয়ে করা হয়, যেমন `map` এবং `reduce`, অথবা [স্ট্রিম ব্যবহার করে][map-implementation], যেমন `[.[] | select(...)]`.
ভেতরে ভেতরে, কিছু বিল্ট-ইন [রিকার্সন ব্যবহার করে তৈরি করা হয়েছে][walk-implementation]।
