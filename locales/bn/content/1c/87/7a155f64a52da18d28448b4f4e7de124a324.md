# নির্দেশনা সংযোজন

## বোনাস

`uüu` স্ট্রিংটিতে আপনার ফাংশন পরীক্ষা করে দেখুন, আর দেখুন কী ঘটে।
এই স্ট্রিংটি ঠিকভাবে উল্টে দেয় এমন একটি ফাংশন লেখার চেষ্টা করুন।
ইঙ্গিত: গ্রাফিম ক্লাস্টার

বোনাস টেস্টটি চালু করতে হলে শেষ টেস্ট থেকে ignore ফ্ল্যাগটি (`#[ignore]`) মুছে ফেলুন এবং এই কমান্ডটি দিয়ে টেস্টগুলো চালান:

```bash
cargo test --features grapheme
```

বোনাস কাজটির জন্য আপনার বাইরের লাইব্রেরি (Rust-এর পরিভাষায় একটি `crate`) ব্যবহার করতে হবে।
সেগুলো খুঁজতে ভালো একটি জায়গা হলো [crates.io](https://crates.io/), যা crates-এর অফিসিয়াল রিপোজিটরি।
মনে রাখবেন, আমাদের টেস্ট রানার সীমিত সংখ্যক crate-ই সাপোর্ট করে।
পুরো তালিকাটি [এই ফাইলটিতে](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) `[dependencies]` সেকশনের নিচে আছে।

নিজের প্রজেক্টে বাইরের crate কীভাবে ব্যবহার করবেন, তার নির্দেশনার জন্য [ডকুমেন্টেশন দেখুন](https://doc.rust-lang.org/cargo/guide/dependencies.html)।
