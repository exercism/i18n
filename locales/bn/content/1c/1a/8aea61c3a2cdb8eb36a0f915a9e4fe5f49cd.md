# নির্দেশনা

একটি পিথাগোরীয় ত্রয়ী হলো তিনটি স্বাভাবিক সংখ্যার একটি সেট, {a, b, c}, যার জন্য

```text
a² + b² = c²
```

এবং যাতে,

```text
a < b < c
```

উদাহরণস্বরূপ,

```text
3² + 4² = 5².
```

একটি ইনপুট ইন্টিজার N দেওয়া হলে, এমন সব পিথাগোরীয় ত্রয়ী খুঁজুন যেখানে `a + b + c = N`.

উদাহরণস্বরূপ, N = 1000 হলে, ঠিক একটি পিথাগোরীয় ত্রয়ী আছে যেখানে `a + b + c = 1000`: `{200, 375, 425}`.
