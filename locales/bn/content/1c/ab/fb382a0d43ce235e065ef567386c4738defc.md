# নির্দেশনার সংযোজন

## একটু দাঁড়ান, এটা তো অসম্ভব!

_কোনো_ বিল্ট-ইন ফাংশন ব্যবহার না করে এই অ্যারে অপারেশনগুলো Roc-এ বাস্তবায়ন করা কার্যত অসম্ভব, কারণ অ্যারেতে নতুন এলিমেন্ট যোগ করতে বা সামনে যোগ করতে হলে আপনার একটা উপায় লাগবে।
অন্য ভাষায় আপনি হয়তো Haskell-এ `:` বা Python-এ `+=`-এর মতো অপারেটর ব্যবহার করতেন, কিন্তু Roc-এ আপনাকে [`List` ফাংশনগুলো](https://www.roc-lang.org/builtins/main/#Builtin.List) ব্যবহার করতে হবে।

তাই এই অনুশীলনীতে আপনি `List.append` ব্যবহার করতে পারবেন (তবে অন্য কোনো বিল্ট-ইন ফাংশন ব্যবহার করা এড়িয়ে চলুন)।

অনেক ফাংশনাল প্রোগ্রামিং ভাষা প্রধান কালেকশন টাইপ হিসেবে লিংকড লিস্ট ব্যবহার করে।
লিংকড লিস্টে নতুন এলিমেন্ট সামনে যোগ করা বা প্রথম এলিমেন্টটি বের করে নেওয়া বেশ দক্ষ, তাই সেই ভাষাগুলোতে আপনি `List.prepend` দিয়ে অ্যারে অপারেশনগুলো বাস্তবায়ন করতেন।
কিন্তু Roc-এ একটি `List` হলো একটি অ্যারে (একটানা বাইটের একটি অংশ)।
অ্যারের বৈশিষ্ট্য লিংকড লিস্টের চেয়ে আলাদা, যেমন ইনডেক্স দিয়ে দ্রুত এলিমেন্ট অ্যাক্সেস করা আর নতুন এলিমেন্ট যোগ করা।
এই কারণেই Roc-এ আমরা প্রায়ই `List.append` ব্যবহার করি, আর `List.prepend` ব্যবহার করি খুব কমই।

## নামকরণ

সাধারণ নির্দেশাবলিতে দেওয়া নামগুলোর চেয়ে Roc-এ কিছুটা আলাদা নাম ব্যবহার করা হয়:

- `append`-এর বদলে `concat`
- `concatenate`-এর বদলে `join`
- `length`-এর বদলে `len`
- `foldl`-এর বদলে `fold`
- `foldr`-এর বদলে `fold_rev`

তবে Roc-এ নিচের ফাংশন নামগুলো স্ট্যান্ডার্ড:
- `filter`
- `map`
- `reverse`

## ইঙ্গিত

এভাবে চেষ্টা করে দেখুন:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

বা

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
