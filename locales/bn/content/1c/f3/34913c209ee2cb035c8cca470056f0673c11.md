# নির্দেশনা

এই অনুশীলনীতে আপনি একটি ইন্টারন্যাশনাল ডায়ালিং কোড হ্যাশম্যাপের মাধ্যমে ইন্টারন্যাশনাল ডায়ালিং কোডগুলো ট্র্যাক রাখার কোড লিখবেন।

ম্যাপটি তার কী (key) হিসেবে একটি ইন্টিজার (ডায়ালিং কোড) এবং তার মান হিসেবে একটি স্ট্রিং (দেশের নাম) ব্যবহার করে।

আপনার সামনে ডায়ালিং কোড সংক্রান্ত ১১টি কাজ আছে।

## 1. একটি প্রি-পপুলেটেড হ্যাশম্যাপ তৈরি করুন

এমন একটি প্রি-পপুলেটেড হ্যাশম্যাপ আছে যাতে নিচের ৩টি ডায়ালিং কোড রয়েছে: "United States of America" দেশটির কোড 1, "Brazil" দেশটির কোড 55 এবং "India" দেশটির কোড 91। প্রি-পপুলেটেড হ্যাশম্যাপটি সংরক্ষণ করতে `countries` ভ্যারিয়েবলটি ডিফাইন করুন:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. একটি ম্যাপে একটি দেশ যোগ করুন

১ নম্বর কাজে তৈরি করা ম্যাপে 44 ডায়ালিং কোডসহ "United Kingdom" যোগ করুন:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. একটি দেশের কোডের সাথে মেলে এমন দেশের নাম বের করুন

ডায়ালিং কোড 55-এর দেশটির নাম বের করুন

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. একটি দেশের নাম আপডেট করুন

"United States of America" দেশটির নাম বদলে "Les États-Unis" করুন:

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. ম্যাপে একটি দেশ আছে কি না যাচাই করুন

১ নম্বর কাজে তৈরি করা ম্যাপে "Brazil" দেশটির কোনো রেকর্ড আছে কি না যাচাই করুন

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. ম্যাপে নেই এমন দেশের নাম আপডেট করার চেষ্টা করুন

ম্যাপে নেই এমন কোডের দেশের নাম বদলানোর চেষ্টা করুন, যেমন 999। এতে ম্যাপে কোনো পরিবর্তন হওয়া উচিত নয়:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. ম্যাপ থেকে একটি দেশ মুছে ফেলুন

ম্যাপ থেকে "India" মুছে ফেলুন:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. সবচেয়ে লম্বা নামের দেশটি খুঁজে বের করুন

সবচেয়ে লম্বা নামের দেশটি খুঁজে বের করতে ম্যাপের মানগুলো প্রসেস করুন:

```clojure
(longest-name countries)
;;=> "United States of America"
```
