# পরিচিতি

[Nil][nil-dictionary] একটি ইংরেজি শব্দ, যার অর্থ "কিছুই না" বা "শূন্য"। Elixir-এ `nil` একটি বিশেষ মান, যা কোনো মানের _অনুপস্থিতি_ বোঝায়।

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` একটি অ্যাটম, তবে এটি সাধারণত `nil` হিসেবেই লেখা হয়, `:nil` নয়। `true` ও `false` বুলিয়ান মানগুলোও অ্যাটম।

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

একটি ভ্যারিয়েবলের মান `nil` কি না, তা আপনি [`==`][kernel-equal] দিয়ে, প্যাটার্ন ম্যাচিং দিয়ে, কিংবা [`is_nil` গার্ড][kernel-is-nil] দিয়ে যাচাই করতে পারেন।

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
