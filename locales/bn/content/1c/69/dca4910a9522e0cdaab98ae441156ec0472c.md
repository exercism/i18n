# ভূমিকা

F#-এর `char` টাইপ হলো ১৬ বিটের একটি মান, যা টেক্সটের ক্ষুদ্রতম অ্যাড্রেসযোগ্য উপাদান প্রকাশ করে এবং ডিফল্টভাবে ইমিউটেবল।

একক উদ্ধৃতি চিহ্ন দিয়ে `char` লিটারেল ডিফাইন করা যায়:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

স্ট্রিং হলো ক্যারেক্টারের একটি সিকোয়েন্স।

স্ট্রিং থেকে (শূন্য-ভিত্তিক) ইনডেক্সিং দিয়ে একটি একক `char` বের করা যায়:

```fsharp
"Exercism"[4] //  =>  'c'
```

একটি স্ট্রিংয়ের উপর ইটারেশন করলে প্রতি ধাপে একটি `char` পাওয়া যায়।

পরের উদাহরণে সুবিধার জন্য একটি হায়ার-অর্ডার ফাংশন আর একটি অ্যানোনিমাস ফাংশন ব্যবহার করা হয়েছে।
সিলেবাসে এগুলো পরে ভালোভাবে আলোচনা করা হবে, তবে আপাতত এগুলো একটি স্ট্রিংয়ের ক্যারেক্টারগুলোর উপর লুপ লেখার একটি সংক্ষিপ্ত উপায়।

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

উপরে যেমন দেখানো হয়েছে, কাস্ট করে একটি `char` থেকে তার `int` মান পাওয়া যায়।
এটি অন্য লিপির ক্ষেত্রেও কাজ করে (*অন্তত কিছু ক্ষেত্রে*):

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

ক্যারেক্টার তুলনা করার সময় অন্তর্নিহিত Int16 ব্যবহার করা হয়:

```fsharp
'A' < 'D'  // =>  true
```

এছাড়া, কাস্ট করে একটি `int` থেকে `char` বানানো যায়:

```fsharp
char 77  // => 'M'
```

`System.Char` লাইব্রেরিতে একটি .NET ভাষার জন্য প্রত্যাশিত সব মেথড রয়েছে, যেমন বড় হাতের ও ছোট হাতের অক্ষরে রূপান্তর:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
