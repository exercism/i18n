# ডেটাবেসে কর্মী অনবোর্ডিং

## সমস্যার বিবরণ

ABC Corp কর্মীদের দেওয়া সব ছোটখাটো নগদ পেমেন্টের তথ্য একটি ডেটাবেসে সংরক্ষণ করার পরিকল্পনা করছে। ABC Corp-এর ফিন্যান্স বিভাগকে এটি বাস্তবায়নে সাহায্য করছেন আপনি। যেহেতু ABC Corp তাদের কার্যক্রম বাড়াচ্ছে, নতুন কর্মী নিয়োগের কারণে সিস্টেমে নতুন কর্মী যোগ করা একটি কমন প্রয়োজন।

আপনার কাজ হলো প্রদত্ত নতুন কর্মীর তথ্য ডেটাবেসের `Employee` টেবিলে যোগ করা এবং সেটি খুঁজে বের করার জন্য ডেটাবেসে আরেকটি কোয়েরি না পাঠিয়েই অটো-জেনারেট হওয়া `employee_id` কলামের মান রিটার্ন করা। এক্সিকিউশনের সময় কোনো এরর হলে `-1` রিটার্ন করতে হবে।

## ডেটাবেসের বিবরণ

এই সমস্যার জন্য প্রদত্ত H2 ডেটাবেসটি ব্যবহার করুন।

> স্যাম্পল ডেটাবেস ফাইলটি `gofigure.mv.db`, আর ডেটাবেসের নাম `gofigure`। এটি `db` ফোল্ডারের ভিতরে দেওয়া আছে।

নিচের টেবিলগুলি ইতিমধ্যেই স্যাম্পল H2 ডেটাবেসে কিছু স্যাম্পল ডেটাসহ রয়েছে। কলামের নাম ও ডেটা টাইপ নিচে দেওয়া হলো।

**টেবিলের নাম** : `Employee`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `employee_id`     | ইন্টিজার, অটো-ইনক্রিমেন্টেড প্রাইমারি কী       |
| `name`            | স্ট্রিং        |
| `city`            | স্ট্রিং        |
| `department`      | স্ট্রিং        |
| `age`             | ইন্টিজার        |

**টেবিলের নাম**: `Payment`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `payment_id`      | ইন্টিজার, অটো-ইনক্রিমেন্টেড প্রাইমারি কী       |
| `date`            | তারিখ        |
| `amount`          | দশমিক সংখ্যা        |
| `employee_id`     | ইন্টিজার        |
| `reason`          | স্ট্রিং        |

* ডেটাবেস ফাইলটি `gofigure.mv.db`. JDBC URL হিসেবে `jdbc:h2:file:/path/to/db/file` ব্যবহার করুন
* ইউজারনেম: `root`
* পাসওয়ার্ড: `root`

## সীমাবদ্ধতা

* কোয়েরি এবং Ballerina স্যাম্পল যাচাই করতে `db` ফোল্ডারে দেওয়া H2 ডেটাবেস ফাইলটি ব্যবহার করুন
* আপনার Ballerina.toml-এ প্ল্যাটফর্ম ডিপেন্ডেন্সি হিসেবে H2 ডেটাবেস ড্রাইভার যোগ করতে maven ডিপেন্ডেন্সি প্যারামস পদ্ধতি ব্যবহার করুন
* অটো-জেনারেট হওয়া id খুঁজে বের করতে ডেটাবেসে আরেকটি কোয়েরি দেবেন না


## টেস্ট এনভায়রনমেন্ট
