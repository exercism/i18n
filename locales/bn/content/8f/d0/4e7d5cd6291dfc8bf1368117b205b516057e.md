# স্কোপ রেজোলিউশন অপারেটর

স্কোপ রেজোলিউশন অপারেটর (`::`) দিয়ে আমরা একটি ক্লাস রেফারেন্স করে তার নাম কনস্ট্যান্ট, স্ট্যাটিক প্রপার্টি বা স্ট্যাটিক মেথড অ্যাক্সেস করতে পারি।

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## স্কোপ রেজোলিউশন অপারেটরের সাথে `self` ও `static` ব্যবহার

কখনও কখনও একটি অবজেক্টের নিজের স্কোপ রেফারেন্স করার প্রয়োজন হতে পারে। এটা সহজ করতে `self` কিওয়ার্ডটি একটি ক্লাসকে তার নিজের স্কোপ রেফারেন্স করার সুবিধা দেয়। `self` কিওয়ার্ড ব্যবহার করলে ক্লাসটি তার নিজের নাম থেকে আলাদা হয়ে যায়, ফলে সময়ের সাথে কোড রক্ষণাবেক্ষণ করা সহজ হয়।

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

বর্তমান ডিসেন্ডেন্ট ক্লাসের সাথে রেফারেন্সটি "লেট বাইন্ড" করতে স্কোপ রেজোলিউশন অপারেটরের সাথে `static` কিওয়ার্ডটি ব্যবহার করুন।

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## স্কোপ রেজোলিউশন অপারেটরের সাথে `parent` ব্যবহার

`parent` কিওয়ার্ডটি প্যারেন্ট ক্লাসের কনস্ট্যান্ট, প্রপার্টি বা মেথড রেফারেন্স করতে ব্যবহার করা হয়। সাধারণত কোনো অবজেক্ট ইনস্ট্যান্টিয়েট করার সময় প্যারেন্ট কনস্ট্রাক্টর কল করতে এটি ব্যবহৃত হয়:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## সতর্কতা

### কনস্ট্যান্ট, প্রপার্টি ও মেথডের ভিজিবিলিটি

স্কোপ রেজোলিউশন অপারেটরটি এখনও `public`, `private` ও `protected` ভিজিবিলিটি মডিফায়ার দ্বারা নির্ধারিত নিয়মগুলোই অনুসরণ করে।
