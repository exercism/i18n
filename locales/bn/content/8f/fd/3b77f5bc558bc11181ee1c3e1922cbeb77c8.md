# পরিচিতি

রুবিতে এক্সেপশন, অনেক ভাষার মতোই, অপ্রত্যাশিত ঘটনা মোকাবিলার একটি উপায় দেয়। আপনার প্রোগ্রাম যাতে ক্র্যাশ না করে তা প্রতিরোধ করতে চাইলে এক্সেপশন সঠিকভাবে সামলানো গুরুত্বপূর্ণ।

যখন কোনো এক্সেপশন রেইজ করা হয়, তা আপনি নিজে রেইজ করুন বা রুবি ইন্টারপ্রেটার রেইজ করুক, প্রোগ্রামটি স্বাভাবিক কাজকর্ম থামিয়ে দেয় এবং শেষে একটি এরর বার্তা নিয়ে বন্ধ হয়ে যায়:

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

এই বন্ধ হয়ে যাওয়ার প্রক্রিয়াটি থামাতে চাইলে আমাদের এক্সেপশনের প্রতি সাড়া দিতে হবে। এটাকেই এক্সেপশন "রেসকিউ" করা বলা হয়:

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

এই প্রোগ্রামটি ক্র্যাশ করবে না এবং এটি "Got an exception" আউটপুট দেবে। বন্ধ হয়ে যাওয়ার বদলে রুবি rescue ব্লকের কোডটি চালায়, যা একটি বার্তা প্রিন্ট করে।

রুবিতে সবকিছুর মতো এক্সেপশনও অবজেক্ট, আর এরা সাধারণত এক্সেপশন সম্পর্কিত ডেটা ধরে রাখে। এভাবেই আমরা এক্সেপশন অবজেক্টটি পেতে পারি:

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

রুবিতে নিজের এক্সেপশন রেইজ করাও সম্ভব। যেমন:

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

আগের এক্সেপশনটি রুবির বিল্ট-ইন এক্সেপশনগুলোর একটি, তবে কাস্টম এক্সেপশন ডিফাইন করে সেগুলো রেইজ করাও সম্ভব:

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
