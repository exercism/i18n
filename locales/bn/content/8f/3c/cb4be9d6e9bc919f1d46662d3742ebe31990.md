# নির্দেশনা

ভ্যালেন্টাইনস ডে এসে গেছে। আপনার সঙ্গীর কয়েকটি অ্যাক্টিভিটির আইডিয়া আছে, আর তিনি আপনাকে প্রতিটির রেটিং দিতে বলছেন: `yes`, `no`, বা `maybe`।

অ্যাক্টিভিটিগুলোকে ২টি এলিমেন্টের অ্যারে `{ tag value }` হিসেবে প্রকাশ করা হয়, যেখানে `tag` হলো `board-game`, `chill`, `movie`, `restaurant`, বা `walk`-এর একটি।

| অ্যাক্টিভিটি                  | গঠন                       |
| ------------------------- | --------------------------- |
| বোর্ড গেম খেলা             | `{ board-game f }`          |
| আরাম করা                  | `{ chill f }`               |
| `genre` ধরনের সিনেমা দেখা  | `{ movie genre }`           |
| `cuisine` খাবারের রেস্টুরেন্টে খাওয়া | `{ restaurant cuisine }`    |
| `km` কিলোমিটার হাঁটা       | `{ walk km }`               |

ধরনটি `crime`, `horror`, `romance`, `thriller`-এর একটি। খাবারটি `korean` বা `turkish`.

## 1. খাবার রেট করুন

স্ট্যাক থেকে একটি খাবার নিয়ে আপনার সম্মতি রিটার্ন করে, এমন একটি `rate-restaurant` ডিফাইন করুন:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. সিনেমার ধরন রেট করুন

একটি ধরন নিয়ে রিটার্ন করে, এমন একটি `rate-movie` ডিফাইন করুন:

- `romance` → `yes`
- আর সবকিছু → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. হাঁটা রেট করুন

কিলোমিটারের একটি সংখ্যা নিয়ে রিটার্ন করে, এমন একটি `rate-walk` ডিফাইন করুন:

- `11`-এর বেশি → `yes`
- `6`-এর বেশি, `11` পর্যন্ত → `maybe`
- অন্যথায় → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. অ্যাক্টিভিটি রেট করুন

স্ট্যাক থেকে একটি `{ tag value }` অ্যাক্টিভিটি নিয়ে আপনার সম্মতি রিটার্ন করে, এমন একটি `rate-activity` ডিফাইন করুন। উপরের হেল্পারগুলো আবার ব্যবহার করুন:

- `board-game`, `chill` → সবসময় `no`
- `movie` → `rate-movie`-এর হাতে ছেড়ে দিন
- `restaurant` → `rate-restaurant`-এর হাতে ছেড়ে দিন
- `walk` → `rate-walk`-এর হাতে ছেড়ে দিন

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. সম্মতিগুলোর হিসাব করুন

অ্যাক্টিভিটির একটি অ্যারে নিয়ে, কতগুলোকে কোন রেটিং দেওয়া হয়েছিল তা জানিয়ে একটি ৩টি এলিমেন্টের অ্যারে `{ yes-count maybe-count no-count }` রিটার্ন করে, এমন একটি `approval-counts` ডিফাইন করুন।

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
