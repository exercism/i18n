## নির্দেশনা

আপনার কাজ হলো মিকি ও মিনার্ভার জন্য নিখুঁত গোলকধাঁধা তৈরি করা, যেগুলোর সমাধান মাত্র একটি আর কোনো বিচ্ছিন্ন অংশ নেই। যে বিষয়গুলো আপনার জানা দরকার:

- গোলকধাঁধাটি আয়তাকার, শুরুতে ও শেষে একটি করে খোলা মুখ থাকে।
- গোলকধাঁধাটিতে ঘর আর পথ থাকে, যেগুলো সমকোণে ছেদ করে।
- প্রোগ্রামটির দুটি প্যারামিটার নেওয়া উচিত: rows এবং columns. গোলকধাঁধার আকার ৫ থেকে ১০০ সেলের মধ্যে হওয়া উচিত।
- যে গোলকধাঁধাটি `x` কলাম চওড়া এবং `y` রো উঁচু, সেটি `2x + 1` ক্যারেক্টার চওড়া আর `2y + 1` ক্যারেক্টার উঁচু হওয়া উচিত।
- কোনো seed দেওয়া না হলে একটি র‍্যান্ডম গোলকধাঁধা তৈরি করুন। একই seed একাধিকবার দিলে প্রতিবার একই গোলকধাঁধা তৈরি হওয়া উচিত।
- দেয়াল আঁকতে [বক্স-ড্রয়িং][Box-drawing] ক্যারেক্টার ব্যবহার করুন, আর বাম দিকের প্রবেশপথ এবং ডান দিকের বাহিরপথ বোঝাতে একটি তীর চিহ্ন (⇨) ব্যবহার করুন।

এখন সময় হয়েছে এই দুঃসাহসী ইঁদুরগুলোর জন্য কিছু নিখুঁত গোলকধাঁধা তৈরির!

### উদাহরণ

1. ছোট বর্গাকার গোলকধাঁধা, ৫x৫ সেল (বা ১১x১১ ক্যারেক্টার)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. আয়তাকার গোলকধাঁধা, ৬x১৮ সেল
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
