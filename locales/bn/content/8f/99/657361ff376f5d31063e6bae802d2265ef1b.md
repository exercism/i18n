সব অপ্রয়োজনীয় লিটারেল সরিয়ে ফেলুন।

JavaScript-এ বুলিয়ান রিটার্ন করতে `true` বা `false` লিটারেল `return` করা প্রয়োজন হয় না। একটি এক্সপ্রেশনের ফলাফল সরাসরি রিটার্ন করা যায়।

```javascript
// instead of
if (some_expression) {
  return true;
} else {
  return false;
}

// ...in JavaScript, these can be returned directly
return some_expression;
```
