# পরিচিতি

`try..rescue` ব্যবহার করা এরর ঘটার সময় সেগুলো ধরে ফেলার একটি শক্তিশালী কনস্ট্রাক্ট। এরর রেসকিউ করা ফাংশনগুলোকে প্রয়োজন হলে নির্দিষ্ট মান রিটার্ন করার সুযোগ দেয়। `try..rescue` কনস্ট্রাক্টটি আমাদের জন্য আরও দুটি অতিরিক্ত সুবিধা নিয়ে আসে, যেগুলো আমরা কাজে লাগাতে পারি:

- `else` ব্লক
  - try ব্লক সফল হলে ফলাফলটি এই ব্লকের সাথে মেলানো হয়।
- `after` ব্লক
  - try ব্লক সফল হোক বা এরর রেইজ করুক, প্রোগ্রামটি সেই মুহূর্তে চলমান থাকলে `after` ব্লকের কোডটি সর্বদা চালানো হয়।
  - `after` ব্লকের ফলাফল কলিং স্কোপে রিটার্ন করা হয় না।

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
