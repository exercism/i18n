# পরিচিতি

[কম্প্রিহেনশন][for] _Enumerable_-গুলোকে সহজে ও ডিক্লারেটিভভাবে রূপান্তর করার একটি উপায় দেয়। এগুলো Elixir-এ enumerable-গুলোর মধ্য দিয়ে ইটারেশন করার একধরনের _সিনট্যাক্টিক সুগার_।

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

একটি কম্প্রিহেনশনের তিনটি অংশ থাকে:

1. _জেনারেটর_:
   - _Enumerable_ প্রোটোকল বাস্তবায়ন করে এমন স্ট্রাকচার থেকে পাওয়া মান।
   - প্রাপ্ত মান ডিস্ট্রাকচার করার জন্য প্যাটার্ন ম্যাচিং এক্সপ্রেশন।
2. _ফিল্টার_: বুলিয়ান শর্ত, যা নতুন মান তৈরি করার সময় কোন কোন মান ব্যবহার করা হবে তা বেছে নিতে ব্যবহৃত হয়।
3. _কালেক্টেবল_: এমন একটি স্ট্রাকচার, যা _Collectable_ প্রোটোকল বাস্তবায়ন করে এবং নতুন মানগুলো সংগ্রহ করতে ব্যবহৃত হয়।

এক-লাইন ও বহু-লাইনের কম্প্রিহেনশন দুটোই আছে। একাধিক জেনারেটর ব্যবহার করলে উৎপন্ন মানগুলোর একটি [কার্তেসীয় গুণফল][cartesian-product] তৈরি হয়। এর মানে হলো, প্রথম জেনারেটরের প্রতিটি মান দ্বিতীয় জেনারেটরের প্রতিটি মানের সাথে একবার করে জোড়া বাঁধে।

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

do-ব্লকের মানটি _enumerable_ থেকে উৎপন্ন **প্রতিটি মানের জন্যই** _কালেক্টেবল_-এ যুক্ত করা হয়।

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

কম্প্রিহেনশনে প্যাটার্ন ম্যাচিং করা যায়, হয় `<-`-এর বাম দিকে, নয়তো আলাদা লাইনে।

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
