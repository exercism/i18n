# পরিচিতি

C#-এ, যেসব ডেটা স্ট্রাকচারে শূন্য বা তার বেশি এলিমেন্ট থাকতে পারে, সেগুলোকে _কালেকশন_ বলা হয়। **অ্যারে** হলো এমন একটি কালেকশন, যার সাইজ/দৈর্ঘ্য নির্দিষ্ট এবং যার সব এলিমেন্ট অবশ্যই একই টাইপের হতে হয়। ইনডেক্স ব্যবহার করে অ্যারেতে এলিমেন্ট অ্যাসাইন করা যায় বা অ্যারে থেকে এলিমেন্ট পড়ে নেওয়া যায়। C# অ্যারে জিরো-বেজড, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

সংক্ষিপ্ত একটি নোটেশন ব্যবহার করেও অ্যারে ডিফাইন করা যায়, যেখানে একইসাথে অ্যারে তৈরি করা ও তার মান সেট করা যায়। কম্পাইলার এখন বুঝতে পারে অ্যারেতে কতগুলো এলিমেন্ট থাকবে, তাই দৈর্ঘ্য বাদ দেওয়া যায়:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

অ্যারে ইনস্ট্যান্সের মেথড বা প্রপার্টি কল করে, কিংবা `Array` ক্লাসে ডিফাইন করা স্ট্যাটিক মেথড ব্যবহার করে অ্যারে নিয়ে কাজ করা যায়।
