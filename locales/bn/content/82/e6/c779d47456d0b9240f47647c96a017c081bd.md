# পরিচিতি

প্যাটার্ন ম্যাচিং হলো এমন একটি প্রক্রিয়া, যেখানে একটি মান নির্দিষ্ট, প্রয়োজনে গভীর প্যাটার্নের সাথে মেলে কি না তার উপর নির্ভর করে শাখা বেছে নেওয়া হয়। Haxe-তে **প্যাটার্ন ম্যাচিং** করা হয় `switch` এক্সপ্রেশন এবং আলাদা আলাদা `case` এক্সপ্রেশনের সাহায্যে।

এই ডেটা স্ট্রাকচারটি দেখুন:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- প্যাটার্নগুলো সবসময় উপর থেকে নিচে মিলিয়ে দেখা হয়।
- ইনপুট মানের সাথে যে প্যাটার্নটি সবার উপরে থেকে মেলে, চালানো হয় তার এক্সপ্রেশনটি।
- `_` প্যাটার্নটি যেকোনো কিছুর সাথে মেলে, তাই `case _:` আর `default:` একই কথা।

## এনাম ম্যাচিং

এনামগুলোর কনস্ট্রাক্টর দিয়ে স্বাভাবিকভাবেই মিলিয়ে দেখা যায়:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
