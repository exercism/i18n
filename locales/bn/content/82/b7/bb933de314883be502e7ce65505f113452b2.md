# নির্দেশনা

এই অনুশীলনীতে আপনি ছয়টি সিভিয়ারিটি লেভেলের লগ মেসেজ প্রসেস করবেন।

প্রতিটি লগ লাইন হলো একটি স্ট্রিং, যা এভাবে ফরম্যাট করা থাকে: `"[<LVL>]: <MESSAGE>"`.

এগুলো হলো বিভিন্ন লগ লেভেল:

| লেভেল | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. লগ লেভেল পার্স করুন

উপরে বর্ণিত লগ লেভেলগুলোর সাথে মিলে যায় এমন ছয়টি এলিমেন্টবিশিষ্ট একটি `LogLevel` enum ডিফাইন করুন। এরপর `parse_log_level` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে লগ মেসেজটি নেয় এবং তার লেভেলের enum মেম্বারটি রিটার্ন করে।

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. অজানা লগ লেভেল সাপোর্ট করুন

দুর্ভাগ্যবশত, মাঝে মাঝে কিছু লগ মেসেজ _অজানা_ সিভিয়ারিটি নিয়ে আসে। `parse_log_level` ফাংশনে এই 'রহস্যময়' লগ মেসেজগুলো সুন্দরভাবে সামলাতে `LogLevel` enum-এ একটি `Unknown` মেম্বার যোগ করুন, যা কোনো অজানা লগ লেভেল পার্স করার সময় রিটার্ন হয়:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. লগ মেসেজকে শর্ট ফরম্যাটে রূপান্তর করুন

একটি লগ লাইনের লগ লেভেল বেশ ভার্বোস। লগ মেসেজগুলো সংরক্ষণ করতে যে ডিস্ক স্পেস লাগে তা কমাতে একটি শর্ট ফরম্যাট নির্ধারণ করা হয়েছে: `"[<CODE_LEVEL>]:<MESSAGE>"`.

লগ লেভেল কোডগুলো একটি সরল ম্যাপিং অনুসরণ করে:

| লেভেল | CODE |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

`convert_to_short_log()` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়:

1. Log level - পাঠানো লগের লগ লেভেল। যেমন: `LogLevel.Error`.
2. Log Message - `str` টাইপের মেসেজ।

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. একটি অ্যালিয়াস তৈরি করুন

দেখে মনে হচ্ছে ব্যবহারকারী `LogLevel.Warning`-এর বদলে `LogLevel.Warn`-এর জন্য লগ তৈরি করেছেন। `LogLevel.Warning`-এর জন্য একটি `alias` তৈরি করুন এবং `get_warn_alias` ফাংশনে নতুন alias মেম্বারটি রিটার্ন করুন।

এটি ফাইলের শুরুতে আগেই ডিফাইন করা একই `LogLevel` enum ক্লাসেই করা যায়। দুটি LogLevel মেম্বারই একই মান নির্দেশ করা উচিত: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. সব মেম্বারের নাম ও মান

`get_members()` ফাংশনটি ডিফাইন করুন।

এই ফাংশনটি `(name, value)` টাপল নিয়ে গঠিত একটি অ্যারে রিটার্ন করা উচিত, যেখানে `LogLevel` enum-এর সব মেম্বার থাকবে।

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
