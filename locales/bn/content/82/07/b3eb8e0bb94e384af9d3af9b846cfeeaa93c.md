# নির্দেশনা সংযোজন

## আউটপুট ফরম্যাট

`solve()` মেথডটি নিচের প্রপার্টিসহ একটি অবজেক্ট রিটার্ন করবে বলে আশা করা হয়:

- `moves` - লক্ষ্যে পৌঁছাতে যে কতগুলো বালতি-অ্যাকশন লাগবে তার সংখ্যা
  (শুরুর বালতিটি ভরাট করাও এর মধ্যে পড়ে),
- `goalBucket` - যে বালতিটি লক্ষ্য পরিমাণে পৌঁছেছে তার নাম,
- `otherBucket` - অন্য বালতিতে থাকা পরিমাণ।

উদাহরণ:

```json
{
  "moves": 5,
  "goalBucket": "one",
  "otherBucket": 2
}
```
