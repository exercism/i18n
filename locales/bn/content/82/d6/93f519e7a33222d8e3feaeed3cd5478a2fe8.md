# নির্দেশাবলি সংযোজন

## বাস্তবায়ন

অনুমানসমূহ:

1. আউটপুটে শূন্যকে সর্বদা []-এর বদলে [0] হিসেবে দেখানো হয়।
2. অন্য কোনো ক্ষেত্রে আউটপুটে শুরুর শূন্য থাকে না।
3. ইনপুটে শুরুর শূন্য গ্রহণ করা হয়।
4. ইনপুট ডিজিটের একটি খালি ক্রমকে এরর নয়, বরং শূন্য হিসেবে ধরা হয়।

সমস্যাযুক্ত ক্ষেত্রে একটি এরর রিটার্ন করে সামলান, যার Error() মেথড নিচের যেকোনো একটি মেসেজ রিটার্ন করে:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
