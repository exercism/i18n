# নির্দেশাবলি

জাদুকর হতে চলা এলিসের কিছু বেসিক বিষয় অনুশীলন করা দরকার। তার কাছে কার্ডের একটি স্ট্যাক আছে, যা সে নাড়াচাড়া করতে চায়।

বিষয়টি একটু সহজ করতে সে শুধু ১ থেকে ১০ নম্বরের কার্ডগুলো ব্যবহার করে, তাই তার কার্ডের স্ট্যাকটিকে সংখ্যার একটি অ্যারে দিয়ে প্রকাশ করা যায়। কোনো একটি কার্ডের পজিশন অ্যারের ইনডেক্সের সঙ্গে মিলে যায়। অর্থাৎ পজিশন ০ মানে প্রথম কার্ড, পজিশন ১ মানে দ্বিতীয় কার্ড, ইত্যাদি।

## 1. স্ট্যাক থেকে একটি কার্ড বের করা

একটি কার্ড তুলতে হলে প্রদত্ত স্ট্যাক থেকে ইনডেক্স `position`-এর কার্ডটি রিটার্ন করুন।

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. স্ট্যাকের একটি কার্ড বদল করা

হাতের কিছু কৌশল দেখিয়ে ইনডেক্স `position`-এর কার্ডটি প্রদত্ত বদলি কার্ড দিয়ে বদলে ফেলুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. স্ট্যাকের উপরে একটি কার্ড যোগ করা

স্ট্যাকের উপরে একটি নতুন কার্ড যোগ করে একটি কার্ড হাজির করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. স্ট্যাক থেকে একটি কার্ড সরানো

স্ট্যাক থেকে প্রদত্ত `position`-এর কার্ডটি সরিয়ে একটি কার্ড উধাও করে দিন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. স্ট্যাক থেকে উপরের কার্ডটি সরানো

স্ট্যাকের উপরের কার্ডটি সরিয়ে একটি কার্ড উধাও করে দিন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. স্ট্যাকের নিচে একটি কার্ড যোগ করা

স্ট্যাকের নিচে একটি নতুন কার্ড যোগ করে একটি কার্ড হাজির করুন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. স্ট্যাকের নিচ থেকে একটি কার্ড সরানো

স্ট্যাকের নিচের কার্ডটি সরিয়ে একটি কার্ড উধাও করে দিন।
পরিবর্তিত স্ট্যাকটি রিটার্ন করুন।

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. স্ট্যাকের সাইজ যাচাই করা

স্ট্যাকের সাইজ `stackSize`-এর সমান কি না তা যাচাই করুন।

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
