# নির্দেশনা

যেকোনো দুটি অ্যারে `A` এবং `B` দেওয়া হলে, নির্ণয় করুন:

- অ্যারে `A` অ্যারে `B`-এর equal; অথবা
- অ্যারে `A` অ্যারে `B`-কে ধারণ করে (`A` হলো `B`-এর superlist); অথবা
- অ্যারে `A` অ্যারে `B` দ্বারা ধারণ করা হয়েছে (`A` হলো `B`-এর sublist); অথবা
- উপরের কোনোটিই সত্য নয়, ফলে অ্যারে `A` এবং `B` unequal

বিশেষভাবে, অ্যারে `A` অ্যারে `B`-এর equal যদি উভয় অ্যারেতে একই ক্রমে একই মান থাকে।
অ্যারে `A` হলো `B`-এর superlist যদি `A`-তে `B`-এর সমান মানের একটি সংলগ্ন সাব-সিকোয়েন্স থাকে।
অ্যারে `A` হলো `B`-এর sublist যদি `B`-তে `A`-এর সমান মানের একটি সংলগ্ন সাব-সিকোয়েন্স থাকে।

উদাহরণ:

- যদি `A = []` এবং `B = []` হয় (উভয় অ্যারে খালি), তবে `A` এবং `B` equal
- যদি `A = [1, 2, 3]` এবং `B = []` হয়, তবে `A` হলো `B`-এর superlist
- যদি `A = []` এবং `B = [1, 2, 3]` হয়, তবে `A` হলো `B`-এর sublist
- যদি `A = [1, 2, 3]` এবং `B = [1, 2, 3, 4, 5]` হয়, তবে `A` হলো `B`-এর sublist
- যদি `A = [3, 4, 5]` এবং `B = [1, 2, 3, 4, 5]` হয়, তবে `A` হলো `B`-এর sublist
- যদি `A = [3, 4]` এবং `B = [1, 2, 3, 4, 5]` হয়, তবে `A` হলো `B`-এর sublist
- যদি `A = [1, 2, 3]` এবং `B = [1, 2, 3]` হয়, তবে `A` এবং `B` equal
- যদি `A = [1, 2, 3, 4, 5]` এবং `B = [2, 3, 4]` হয়, তবে `A` হলো `B`-এর superlist
- যদি `A = [1, 2, 4]` এবং `B = [1, 2, 3, 4, 5]` হয়, তবে `A` এবং `B` unequal
- যদি `A = [1, 2, 3]` এবং `B = [1, 3, 2]` হয়, তবে `A` এবং `B` unequal
