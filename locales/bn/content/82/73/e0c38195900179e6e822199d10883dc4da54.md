## সেটআপ

শুরু করার নির্দেশনার জন্য [Common Lisp ইনস্টল করা][track-install] দেখে নিন, অথবা [ট্র্যাকের ডকুমেন্টেশন পেজগুলোতে][track-docs] পাওয়া গাইডগুলোতে চোখ বুলিয়ে নিন।

## সাহায্য কোথায় খুঁজবেন

[দরকারি Common Lisp রিসোর্স][track-resources]-এর তালিকায় থাকা যেকোনো রিসোর্স তথ্য খোঁজার ভালো জায়গা।

এছাড়া কিছু [অনলাইন কমিউনিটি][awesome-cl-communities]-ও আছে, যেগুলো সাহায্যের জন্য যাওয়ার ভালো জায়গা হতে পারে।

## ফরম্যাটিং

Common Lisp কোডের ইনডেন্টেশন আর লেআউট নিয়ে মাথা ঘামায় না, আপনি স্পেস ব্যবহার করছেন না ট্যাব তা নিয়েও না; তবুও exercism-এ জমা দেওয়ার সময় এটি একটি গুরুত্বপূর্ণ বিষয়।
Exercism.org-এর কোড উইজেট ট্যাব আর স্পেস ক্যারেক্টারের মিশ্রণ ভালোভাবে সামলাতে পারে না, তাই মানব রিভিউয়ারদের জন্য কোড আরও পাঠযোগ্য করতে শুধু স্পেস ব্যবহার করার পরামর্শ দেওয়া হচ্ছে।
এটি কীভাবে করবেন, তার জন্য আপনার এডিটরের সেটিংস একবার দেখে নিন।
নিচে Common Lisp-এর জনপ্রিয় এডিটরগুলোর জন্য নির্দেশনা দেওয়া হলো।

### VIM

VIM যেন ইনডেন্টেশনের জন্য শুধু স্পেস ব্যবহার করে, তা নিশ্চিত করতে নিচের কমান্ডগুলো ব্যবহার করুন:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(অথবা এক লাইনে `:set tabstop=2 shiftwidth=2 expandtab`)। সব সময় এটি ব্যবহার করতে আপনার `~/.vimrc` ফাইলে এটি যোগ করতে পারেন।

### Emacs

Common Lisp এডিট করার জন্য Emacs দারুণ উপযুক্ত, আর এর অনেক শক্তিশালী অ্যাড-অন প্যাকেজ পাওয়া যায়। সাধারণ emacs দিয়েই exercism.org-এর সাথে ভালোভাবে কাজ করাতে হলে শুধু নিচের কোডটি ইভ্যালুয়েট করতে হবে:

`(setq-default indent-tabs-mode nil)`

Emacs চালু হওয়ার সময়েই যাতে এটি সেট থাকে, সেজন্য এটি আপনার `~/.emacs` (বা `~/.emacs.d/init.el`) ফাইলে রাখতে পারেন।

Emacs আর Common Lisp-এর জন্য একটি প্রস্তাবিত অ্যাড-অন হলো [SLIME][slime], যা REPL-এর সাথে নিবিড় সংযোগ দেয়; এতে ধাপে ধাপে কোড লেখা ও টেস্ট করা খুব সহজ হয়ে যায়।
