# নির্দেশনা

ইভেন্ট আয়োজক মিকা কাজে পদোন্নতি পেয়েছেন, আর নতুন দায়িত্বের অংশ হিসেবে এখন ইভেন্ট ডেটাবেসের ভার তাঁর কাছেই। তিনি দ্রুত খেয়াল করলেন যে ডেটার অনেকটাই এমনভাবে সংরক্ষিত যা নিয়ে কাজ করা কঠিন, তাই একবারই চালানোর একটি স্ক্রিপ্ট দিয়ে তা গুছিয়ে ফেলার জন্য আপনি আর তিনি মিলে কাজ করছেন।

যেহেতু স্ক্রিপ্টটি একবারই চালানো হবে, আর ডেটার কাঠামো নিয়ে আপনার পূর্ণ আস্থা আছে, তাই এখানে Gleam-এর _let অ্যাসারশন_ ব্যবহার করাই ভালো বলে আপনি মনে করছেন।

## 1. এররগুলো বের করুন

প্রতিটি অতীত ইভেন্টে সেই ইভেন্ট চলাকালীন ঘটে যাওয়া সমস্যার একটি তালিকা আছে। এগুলো রেজাল্ট হিসেবে সংরক্ষণ করা হয়েছে, কিন্তু এরা সবসময়ই `Error` ভ্যারিয়েন্ট।

`extract_error` ফাংশনটি লিখুন, যা এমন একটি রেজাল্ট নেয় যেটি সবসময় একটি `Error` হবে বলে ধরে নেওয়া হয়, আর ভেতরে থাকা এরর মানটি রিটার্ন করে।

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. টিম প্রিফিক্স সরান

টিমের নামের আগে "Team " শব্দটি বসানো হয়েছে, কিন্তু এর দরকার নেই। টিমের নাম থেকে প্রিফিক্সটি সরানোর জন্য `remove_team_prefix` ফাংশনটি লিখুন।

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. অঞ্চল ও টিম আলাদা করুন

প্রতিটি ইভেন্ট পরিচালনা করে একটি টিম, আর প্রতিটি টিম belongs একটি অঞ্চলের অন্তর্ভুক্ত। ডেটাবেসে এগুলো একটি কমা দিয়ে আলাদা করে একক স্ট্রিং হিসেবে সংরক্ষিত থাকে।

`split_region_and_team` ফাংশনটি লিখুন, যা স্ট্রিংটিকে দুটি স্ট্রিংয়ের একটি টাপলে ভাগ করবে: একটি অঞ্চলের জন্য, আর একটি টিমের জন্য। টিমের নাম থেকে "Team " প্রিফিক্সটি সরিয়ে ফেলা উচিত।

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
