# স্ট্যাক হিসেবে ভেক্টর

স্ট্যাক হলো একটি লিনিয়ার ডেটা স্ট্রাকচার, যা এক প্রান্ত থেকে অ্যাক্সেস করার জন্য অপ্টিমাইজ করা হয়েছে। এর জন্য একটি ভালো উপমা হলো কাঁটার উপর রাখা কাগজের স্তূপ: নতুন কাগজ সবসময় একই প্রান্তে যোগ করা হয়, আর কাগজগুলো সরানো হয় যোগ করার উল্টো ক্রমে। যে কাগজগুলো আগে যোগ করা হয়, সেগুলো সবার শেষে সরানো হয়; আর যেগুলো শেষে যোগ করা হয়, সেগুলো সবার আগে সরানো হয়।

স্ট্যাক হিসেবে ব্যবহারের জন্য Rust-এর `Vec` ডেটা স্ট্রাকচারটি উপযুক্ত। [`push` মেথড](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) ভেক্টরের শেষ প্রান্তে আইটেম যোগ করে। [`pop` মেথড](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) ভেক্টর থেকে শেষ আইটেমটি সরিয়ে ফেলে। `push` আর `pop` দুটোরই শুধু অ্যামোর্টাইজড `O(1)` সময় লাগে।

## উদাহরণ

এই উদাহরণে আমরা একটি সাধারণ [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) ক্যালকুলেটরের জন্য ভেক্টরকে স্ট্যাক হিসেবে ব্যবহার করি। সম্পূর্ণ সোর্স পাওয়া যাবে [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736)-এ।

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
