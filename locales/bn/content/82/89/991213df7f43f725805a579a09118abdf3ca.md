# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | ইনপুট     | অ্যাড্রেস | প্রথম রংটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে                  |
| `$a1`    | ইনপুট     | অ্যাড্রেস | দ্বিতীয় রংটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে                |
| `$a2`    | ইনপুট     | অ্যাড্রেস | তৃতীয় রংটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে (খালিও থাকতে পারে) |
| `$v0`    | আউটপুট    | ইন্টিজার | রেজিস্টরের মান                                         |
| `$t0-9`  | অস্থায়ী   | যেকোনো   | অস্থায়ী স্টোরেজের জন্য                                 |
