# পরিচিতি

## মেথড ওভারলোডিং

_মেথড ওভারলোডিং_-এর মাধ্যমে একই ক্লাসের একাধিক মেথডের নাম একই রাখা যায়। ওভারলোড করা মেথডগুলোকে নিচের যেকোনো একটি দিয়ে একে অপরের থেকে আলাদা হতে হবে:

- প্যারামিটারের সংখ্যা
- প্যারামিটারের টাইপ

রিটার্ন টাইপের ভিত্তিতে মেথড ওভারলোডিং হয় না।

প্যারামিটারের সংখ্যা ও তাদের টাইপের ভিত্তিতে কোন ওভারলোড করা মেথডটি কল করতে হবে, কম্পাইলার তা স্বয়ংক্রিয়ভাবে বুঝে নেয়।

## নেমড আর্গুমেন্ট

এখন পর্যন্ত আমরা দেখেছি যে একটি মেথডে পাঠানো আর্গুমেন্টগুলো অবস্থানের ভিত্তিতে মেথডের ঘোষিত প্যারামিটারের সাথে মেলানো হয়। বিকল্প একটি উপায় হলো, বিশেষত যখন কোনো রুটিন অনেকগুলো আর্গুমেন্ট নেয়, কলকারী ঘোষিত প্যারামিটারের আইডেন্টিফায়ার উল্লেখ করে আর্গুমেন্ট মেলাতে পারেন।

নিচের উদাহরণে সিনট্যাক্সটি দেখানো হয়েছে:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## অপশনাল প্যারামিটার

একটি মেথড প্যারামিটারকে একটি ডিফল্ট মান দিয়ে অপশনাল করা যায়। অপশনাল প্যারামিটারযুক্ত একটি মেথড কল করার সময় কলকারীকে সেগুলোর জন্য কোনো মান পাঠাতে হয় না। কোনো অপশনাল প্যারামিটারের জন্য কোনো মান না পাঠালে তার ডিফল্ট মান ব্যবহৃত হবে।

অপশনাল প্যারামিটারগুলো প্যারামিটার তালিকার _অবশ্যই_ শেষে থাকতে হবে; তাদের পরে নন-অপশনাল প্যারামিটার থাকতে পারবে না।

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
