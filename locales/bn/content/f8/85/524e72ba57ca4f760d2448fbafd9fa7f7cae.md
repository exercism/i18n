# নির্দেশনার সংযোজন

## ইমপ্লিমেন্টেশন

টেস্টগুলোর জন্য এমন একটি কনস্ট্রাক্টর লাগে যা একটি অ্যারে নেয়। আপনার কাস্টম সেট ইমপ্লিমেন্টেশনের ভেতরের অংশ অন্য ডেটা স্ট্রাকচার ব্যবহার করতে পারে, তবে টেস্টগুলো পাস করার জন্য আপনাকে এমন একটি বাইরের কনস্ট্রাক্টর ইমপ্লিমেন্ট করতে হতে পারে যা ঠিক একটি অ্যারে নেয়।

কিছু মেথডের জন্য ইউনিকোড অপারেটর সমতুল্য আছে। যেমন, `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` হলো `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`-এর সমতুল্য।
