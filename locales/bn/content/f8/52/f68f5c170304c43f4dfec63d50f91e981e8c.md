# পরিচিতি

JavaScript একটি ডাইনামিক ভাষা, যা অবজেক্ট-ওরিয়েন্টেড, ইম্পারেটিভ ও ডিক্লারেটিভ (যেমন ফাংশনাল প্রোগ্রামিং) স্টাইল সমর্থন করে।

## ভ্যারিয়েবল

JavaScript-এ নামের সাথে মান অ্যাসাইন করার কয়েকটি প্রধান উপায় রয়েছে, যেমন ভ্যারিয়েবল বা কনস্ট্যান্ট ব্যবহার করা।
Exercism-এ ভ্যারিয়েবল সবসময় [camelCase][wiki-camel-case] স্টাইলে লেখা হয়; আর কনস্ট্যান্ট লেখা হয় [SCREAMING_SNAKE_CASE][wiki-snake-case] স্টাইলে।
এখানে অনুসরণ করার মতো কোনো অফিসিয়াল গাইড নেই, আর বিভিন্ন কোম্পানি ও প্রতিষ্ঠানের স্টাইল গাইডও আলাদা আলাদা।
_ভ্যারিয়েবল আপনি যেভাবে খুশি লিখতে পারেন_।
অনুশীলনীগুলো যেভাবে তৈরি করা হয়েছে, সেভাবে ভ্যারিয়েবল লিখলে একটা সুবিধা আছে: ওয়েব ইন্টারফেস আর বেশিরভাগ IDE-তে সেগুলো ভিন্নভাবে হাইলাইট হয়।

JavaScript-এ ভ্যারিয়েবল [`const`][mdn-const], [`let`][mdn-let] বা [`var`][mdn-var] কিওয়ার্ড দিয়ে ডিফাইন করা যায়।

`let` বা `var` ব্যবহার করলে একটি ভ্যারিয়েবল তার জীবনকাল ধরে ভিন্ন ভিন্ন মান রেফার করতে পারে।
যেমন, অ্যাসাইনমেন্ট অপারেটর `=` দিয়ে `myFirstVariable` নামটি অনেকবার ডিফাইন ও রিডিফাইন করা যায়:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let` আর `var`-এর বিপরীতে, `const` দিয়ে ডিফাইন করা ভ্যারিয়েবল কেবল একবারই অ্যাসাইন করা যায়।
JavaScript-এ কনস্ট্যান্ট ডিফাইন করতে এটাই ব্যবহার করা হয়।

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## ফাংশন ডিক্লারেশন

JavaScript-এ কার্যকারিতার এককগুলো _ফাংশনে_ এনক্যাপসুলেট করা থাকে, আর একসাথে থাকার মতো ফাংশনগুলো সাধারণত একই ফাইলে একত্রে রাখা হয়।
এই ফাংশনগুলোর প্যারামিটার থাকে (তাই এরা আর্গুমেন্ট নিতে পারে), আর `return` কিওয়ার্ড দিয়ে একটি মান _রিটার্ন_ করতে পারে।
`()` সিনট্যাক্স দিয়ে ফাংশন কল করা হয়।

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

এই উদাহরণে ফাংশনের নাম `add`।
এটির দুটি প্যারামিটার আছে, `num1` আর `num2`।
এটি একটি মান রিটার্ন করে: `num1 + num2` এক্সপ্রেশনের ফলাফল

এরপর `add` ফাংশনটিকে দুটি আর্গুমেন্ট দিয়ে _কল_ করা হয়: `1` আর `3`।
ফাংশনের ফলাফল, অর্থাৎ রিটার্ন ভ্যালুটি, হচ্ছে `4`।

```exercism/note
💡 JavaScript-এ ফাংশন ডিক্লেয়ার করার _অনেক_ রকম উপায় আছে।
এর মধ্যে কিছু উপায় `function` কিওয়ার্ড ব্যবহারের চেয়ে আলাদা দেখায়।
ট্র্যাকটি ধীরে ধীরে সেগুলো চেনানোর চেষ্টা করে, তবে আপনি যদি সেগুলো আগে থেকেই জানেন, তাহলে যেকোনোটি ব্যবহার করতে পারেন।
বেশিরভাগ ক্ষেত্রে একটি বা অন্যটি ব্যবহার করা ভালো বা খারাপ কিছু নয়।
```

## অন্য ফাইলে এক্সপোজ করা

`function`, কনস্ট্যান্ট বা ভ্যারিয়েবল _অন্য ফাইলেও_ ব্যবহারের জন্য পাওয়া করতে হলে `export` কিওয়ার্ড দিয়ে সেগুলো [এক্সপোর্ট][mdn-export] করতে হয়।
এরপর অন্য একটি ফাইল `import` কিওয়ার্ড দিয়ে এগুলো [ইমপোর্ট][mdn-import] করতে পারে।
এটিকে মডিউল সিস্টেমও বলা হয়।

সব টেস্ট কীভাবে কাজ করে, সেটাই এর একটি ভালো উদাহরণ।
প্রতিটি অনুশীলনীতে অন্তত একটি ফাইল থাকে, যেমন `lasagna.js`, যেটিতে _ইমপ্লিমেন্টেশন_ থাকে।
_ইমপ্লিমেন্টেশনটি_ ফাইল থেকে `export` করা হয়, ফলে অন্য ফাইলে এটি ইমপোর্ট করে ব্যবহার করা যায়।
এছাড়া অন্তত আরেকটি ফাইল থাকে, যেমন `lasagna.spec.js`, যেটিতে _টেস্টগুলো_ থাকে।
এই ফাইলটি ইমপ্লিমেন্টেশন টেস্ট করার জন্য পাবলিক (অর্থাৎ `export` করা) এনটিটিগুলো `import` করে:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
