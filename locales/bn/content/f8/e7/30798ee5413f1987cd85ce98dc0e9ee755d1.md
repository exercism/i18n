# পরিচিতি

[ডিকশনারি][dictionaries] হলো Swift-এর প্রধান কালেকশন টাইপগুলোর একটি।
ডিকশনারি স্বতন্ত্র কী (key) ও সংশ্লিষ্ট মানের মধ্যে ক্রমহীন সম্পর্ক সংরক্ষণ করে।
ডিকশনারির সব কী (key) একই টাইপের হতে হবে, আর সব মানও একই টাইপের হতে হবে।

ডিকশনারি লিটারেল লেখা হয় কমা দিয়ে আলাদা করা `key: value` জোড়ার আকারে, যা তৃতীয় বন্ধনীর ভেতরে রাখা হয়:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

ডিকশনারি টাইপ স্পষ্টভাবে দুইভাবে লেখা যায়: `Dictionary<Key, Value>` অথবা সংক্ষিপ্ত রূপ `[Key: Value]`।

খালি ডিকশনারি তৈরি করতে চাইলে তার কী (key) ও মানের টাইপ স্পষ্টভাবে উল্লেখ করুন:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## মান অ্যাক্সেস করা

সাবস্ক্রিপ্ট নোটেশন ব্যবহার করে আপনি মান অ্যাক্সেস করতে পারেন: ডিকশনারির নামের পরে তৃতীয় বন্ধনীর ভেতরে কী (key) বসিয়ে দিন।
যেহেতু কোনো কী (key) ডিকশনারিতে নাও থাকতে পারে, তাই সাবস্ক্রিপ্ট অ্যাক্সেস একটি *অপশনাল* (`Value?`) রিটার্ন করে।
কী (key) উপস্থিত থাকলে Swift ভেতরে থাকা মানটি রিটার্ন করে; না থাকলে রিটার্ন করে `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

অপশনাল নিয়ে কাজ করা এড়াতে আপনি `default` প্যারামিটার দিয়ে একটি ডিফল্ট মান দিতে পারেন:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## ডিকশনারি পরিবর্তন করা

`var` দিয়ে ডিক্লেয়ার করা পরিবর্তনযোগ্য ডিকশনারির ক্ষেত্রে আপনি সাবস্ক্রিপ্ট অ্যাসাইনমেন্ট দিয়ে কী (key) ও মানের জোড়া যোগ বা হালনাগাদ করতে পারেন:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## ডিকশনারির উপর ইটারেশন করা

`for-in` লুপ ব্যবহার করে আপনি ডিকশনারির প্রতিটি কী (key) ও মানের জোড়ার উপর দিয়ে ইটারেশন করতে পারেন।
প্রতিটি আইটেম দেওয়া হয় একটি `(key, value)` টাপল হিসেবে:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## ডিকশনারি সাজানো

ডিকশনারি ক্রমহীন হওয়ায়, সেগুলো সাজালে কী (key) ও মানের জোড়ার একটি অ্যারে তৈরি হয়।
আপনি `sorted(by:)` মেথডে একটি ক্লোজার পাস করতে পারেন, যা দুটি `(key, value)` টাপল তুলনা করে এবং প্রথম টাপলটি দ্বিতীয়টির আগে বসা উচিত হলে `true` রিটার্ন করে:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
