# সম্পর্কে

## ফাংশন

Gleam-এ ফাংশন ডিফাইন করা হয় `pub fn` সিনট্যাক্স ব্যবহার করে।

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

এই ফাংশনটি দুটি আর্গুমেন্ট নেয়, দুটিই `Int` টাইপের, এবং `Int` টাইপের একটি মান রিটার্ন করে। Gleam-এ `return` কিওয়ার্ড নেই; ফাংশনের শেষ এক্সপ্রেশনের মান সবসময় _অন্তর্নিহিতভাবে রিটার্ন করা হয়_।

আর্গুমেন্টের টাইপ অ্যানোটেশন এবং রিটার্ন টাইপ ঐচ্ছিক, আর Gleam সবসময় আপনার কোড পুরোপুরি টাইপ চেক করবে। সাধারণত Gleam প্রোগ্রামাররা স্পষ্টতার জন্য তাদের ফাংশনে টাইপ অ্যানোটেশন দেন, তবে চাইলে আপনি সেগুলো বাদ দিতে পারেন।

```gleam
pub fn add(x, y) {
  x + y
}
```

`function_name(argument1, argument2)` সিনট্যাক্স ব্যবহার করে একটি ফাংশন কল করা যায়।

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## ভ্যারিয়েবল

Gleam-এ ভ্যারিয়েবল ডিফাইন করা হয় `let name = expression` সিনট্যাক্স ব্যবহার করে।

```gleam
pub fn main() {
  let count = 1
}
```

ভ্যারিয়েবল টাইপ অ্যানোটেশনসহ ঘোষণা করা যায়। ফাংশনের আর্গুমেন্টের মতো এগুলোও ঐচ্ছিক, যদিও বেশিরভাগ Gleam প্রোগ্রামার ভ্যারিয়েবলের জন্য টাইপ অ্যানোটেশন বাদ দেন।

```gleam
pub fn main() {
  let count: Int = 1
}
```

## স্ট্রিং লিটারাল

Gleam-এ স্ট্রিং লেখা হয় ডাবল কোটেশন চিহ্ন দিয়ে।

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## কোড কমেন্ট

সোর্স কোড পড়ছেন এমন অন্য ডেভেলপারদের জন্য নোট রেখে যেতে কমেন্ট ব্যবহার করা যায়। Gleam-এ কমেন্ট এক লাইনের হয়, যার শুরুতে `//` থাকে।

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
