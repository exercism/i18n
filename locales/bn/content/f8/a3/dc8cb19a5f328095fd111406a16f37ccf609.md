# SQLite-নির্দিষ্ট নির্দেশনা

* **candidates** কলামে স্ট্রিংয়ের একটি JSON-এনকোড করা তালিকা থাকে।
  উদাহরণ:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* **result** কলামেও স্ট্রিংয়ের একটি JSON-এনকোড করা তালিকা থাকা উচিত।

## টেবিল স্কিমা

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
