# Luhn-এর ধারণাগুলো

Luhn হলো একটি ভ্যালিডেশন অ্যালগরিদম, যা টেক্সটভিত্তিক ও সংখ্যাভিত্তিক অ্যাসারশনকে একত্র করে। Rust-এর সমাধানগুলোতে ফাংশনাল পদ্ধতিকে প্রাধান্য দেওয়া হয়।

## সাধারণ

### প্রিমিটিভ

- `&str` ও `char`
  - প্রদত্ত ইনপুটের নির্দিষ্ট অংশ সঠিকভাবে বাদ দিতে বা অন্তর্ভুক্ত করতে শিক্ষার্থীদের আলাদা `char`-এর সাথে `&str`-এর পার্থক্য বুঝতে হবে।
- ইন্টিজার
  - প্রয়োজনীয় সংখ্যাগত ভ্যালিডেশন করার জন্য ইন্টিজার বোঝা জরুরি।
- বুলিয়ান
  - আইডেন্টিটি অ্যাসারশন ও চূড়ান্ত তুলনার জন্য অপরিহার্য।

### ইটারেটরের বৈশিষ্ট্য

- চেইনিং
  - এখানে সমস্যাটি সঠিক ক্রমে সমাধান করার জন্য ইটারেটর চেইন বোঝা গুরুত্বপূর্ণ।
- `map`, `filter`, turbofish, আর সম্ভবত `fold`
  - `map` ও `filter` একসাথে ব্যবহার করলে এই ধরনের ভ্যালিডেশন সমস্যার জন্য একটি মৌলিক ডিজাইন প্যাটার্ন পাওয়া যায়। `fold` দিয়ে করা সমাধানগুলো আরও সংক্ষিপ্তও হয়।
  - কিছু সমাধানে চেইন করা এক্সপ্রেশন থেকে আপনি কোন ডেটা টাইপ তৈরি করছেন, সেটি Rust-কে জানানোর জন্য turbofish দরকার হয়।

## উদাহরণ সমাধান ১

york-এর [সমাধান](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## উদাহরণ সমাধান ২

ক্যানোনিকাল

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
