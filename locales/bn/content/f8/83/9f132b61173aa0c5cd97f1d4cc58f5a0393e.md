# ভূমিকা

## লেবেলযুক্ত আর্গুমেন্ট

কখনও কখনও একটি ফাংশন অনেক আর্গুমেন্ট নেয়, আর তখন সেগুলো কোন ক্রমে দিতে হবে তা মনে রাখা কঠিন হয়ে যায়। কোড পড়তে সুবিধা হয় বলে Gleam-এ আর্গুমেন্টের সাথে একটি নামের লেবেল দেয়া যায়।

কোনো আর্গুমেন্টে লেবেল দিতে আর্গুমেন্টের নামের আগে লেবেলের নামটি লিখুন, মাঝে একটি স্পেস দিয়ে।

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

লেবেলযুক্ত আর্গুমেন্ট আছে এমন কোনো ফাংশন কল করার সময় আর্গুমেন্টগুলো যেকোনো ক্রমে দেয়া যায়। `replace` ফাংশনের এই কলগুলো সবই সমতুল্য:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

লেবেল সবসময় ঐচ্ছিক। কোনো ফাংশনে লেবেলযুক্ত আর্গুমেন্ট থাকলেও লেবেল ছাড়াই সেটি কল করা যায়।

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
