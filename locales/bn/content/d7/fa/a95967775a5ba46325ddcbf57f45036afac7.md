# পরিচিতি

Cairo-তে টাইপ কনভার্সনের মাধ্যমে আপনি একটি টাইপ থেকে আরেকটি টাইপে ডেটা রূপান্তর করতে পারেন, যা নমনীয় ও নিরাপদ ডেটা ম্যানিপুলেশন সম্ভব করে।

## মূল বিষয়গুলো

Cairo টাইপ কনভার্সনের জন্য বেশ কয়েকটি পদ্ধতি দেয়:

### সরাসরি কাস্টিং

সামঞ্জস্যপূর্ণ সংখ্যাগত টাইপের ক্ষেত্রে আপনি সরাসরি কাস্টিং ব্যবহার করতে পারেন:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Into ট্রেইট

`Into` ট্রেইট একটি টাইপ থেকে আরেকটিতে রূপান্তর সক্ষম করে:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### TryInto ট্রেইট

ব্যর্থ হতে পারে এমন কনভার্সনের জন্য `TryInto` ব্যবহার করুন, যা একটি `Option` রিটার্ন করে:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## কাস্টম টাইপ কনভার্সন

আপনি নিজের টাইপের জন্য `Into` ইমপ্লিমেন্ট করতে পারেন:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## নিরাপত্তার বিবেচনাগুলো

- কনভার্সন ব্যর্থ হতে পারে এমন ক্ষেত্রে `TryInto` ব্যবহার করুন (যেমন বড় টাইপ থেকে ছোট টাইপে)
- কনভার্সন সবসময় সফল হয় এমন ক্ষেত্রে `Into` ব্যবহার করুন
- `TryInto` থেকে আসা `Option::None` কেসগুলো সবসময় হ্যান্ডেল করুন
- সাইনড ও আনসাইনড টাইপের মধ্যে রূপান্তর করার সময় ওভারফ্লো ও আন্ডারফ্লো বিবেচনা করুন
