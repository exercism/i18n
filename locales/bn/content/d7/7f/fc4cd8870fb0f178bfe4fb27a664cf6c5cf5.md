# পরিচিতি

`LocalDate` ও `LocalDateTime`-এর মতো ক্লাসগুলো সময়ের একটি _বিন্দু_ বোঝায়। `java.time` প্যাকেজে আরও দুটি ক্লাস আছে যেগুলো সময়ের একটি _পরিমাণ_ বোঝায়:

- `java.time.Period` হলো বছর, মাস ও দিনে প্রকাশ করা সময়ের পরিমাণ, যেমন "২ মাস ও ৫ দিন"।
- `java.time.Duration` হলো ঘণ্টা, মিনিট, সেকেন্ড, মিলিসেকেন্ড ও ন্যানোসেকেন্ডে প্রকাশ করা সময়ের পরিমাণ, যেমন "১ ঘণ্টা ও ৩০ মিনিট"।

`Period` ক্যালেন্ডার অনুসরণ করে, তাই এটি তারিখ ও ডেট-টাইমের সাথে ব্যবহার করা হয়। `Duration` নির্দিষ্ট সময় মাপে, তাই এটি সময় ও ডেট-টাইমের সাথে ব্যবহার করা হয়, তবে তারিখের সাথে নয়।

```exercism/note
`java.time`-এর অন্য ক্লাসগুলোর মতোই `Period` ও `Duration` ইমিউটেবল। যে মেথডগুলো দেখে মনে হয় তারা এগুলোকে বদলে দিচ্ছে, তারা আসলে একটি _নতুন_ ইনস্ট্যান্স রিটার্ন করে।
```

## `Period`

`Period` তৈরি করা হয় এর স্ট্যাটিক ফ্যাক্টরি মেথডগুলোর একটি দিয়ে:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`-এর ফলাফল [ISO-8601][iso-8601-durations] নোটেশন ব্যবহার করে: `P` ("period" বোঝাতে), তারপর বছর (`Y`), মাস (`M`) ও দিন (`D`)।

কোনো তারিখের সাথে একটি `Period` যোগ বা বিয়োগ করা যায়:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

মাসের দৈর্ঘ্য আলাদা আলাদা হওয়ায়, মাস যোগ করলে এমন একটি দিনে পৌঁছানো যেতে পারে যার অস্তিত্ব নেই। সে ক্ষেত্রে ফলাফলটিকে সেই মাসের শেষ বৈধ দিনে সরিয়ে আনা হয়:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` একটি তারিখ (সেটিসহ) থেকে আরেকটি তারিখ (সেটি ছাড়া) পর্যন্ত সময়ের পরিমাণ রিটার্ন করে:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## `ChronoUnit` দিয়ে একক গোনা

`Period` তার বছর, মাস ও দিন আলাদা আলাদা রাখে। তাই `getDays()` শুধু `Period`-এর দিনের _অংশটুকু_ রিটার্ন করে, মোট দিনসংখ্যা নয়। দুটি তারিখের মধ্যে কোনো একটি নির্দিষ্ট এককের মোট সংখ্যা গুনতে [`java.time.temporal.ChronoUnit`][chronounit-docs]-এর `between()` মেথড ব্যবহার করুন:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

দ্বিতীয় তারিখটি প্রথমটির আগে হলে ফলাফল ঋণাত্মক হয়:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration`-ও স্ট্যাটিক ফ্যাক্টরি মেথড দিয়ে তৈরি করা হয়:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601 নোটেশনে `T` তারিখের অংশকে সময়ের অংশ থেকে আলাদা করে, তাই `Duration` লেখা হয় `PT...` আকারে।

কোনো ডেট-টাইমের সাথে একটি `Duration` যোগ বা বিয়োগ করা যায়:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` দুটি ডেট-টাইমের মধ্যে সময়ের সঠিক পরিমাণ রিটার্ন করে:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

`toHours()`, `toMinutes()` ও `toSeconds()`-এর মতো মেথড দিয়ে একটি `Duration`-কে একটি এককে রূপান্তর করা যায়। এগুলো ওই এককে _মোট_ পরিমাণ রিটার্ন করে, নিচের দিকে রাউন্ড করে:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

ঘড়ির মতো করে একটি `Duration`-কে তার অংশে ভাগ করতে চাইলে বরং `toXxxPart()` মেথডগুলো ব্যবহার করুন:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
