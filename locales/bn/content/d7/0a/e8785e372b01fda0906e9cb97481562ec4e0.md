# Instructions

Blorkemon™️ কার্ডের প্রতি আপনার নস্টালজিয়া যেন একটুও কমার নাম নেই, আপনি আবার সেগুলো সংগ্রহও শুরু করে ফেলেছেন, আর বন্ধুদেরও নিজের সঙ্গে যোগ করাচ্ছেন।

এই অনুশীলনীতে একটি `Card` সংগ্রহ বোঝানো হয় `Set Card` দিয়ে, কারণ আপনার লক্ষ্য যখন বর্তমানে থাকা সব কার্ড সংগ্রহ করা, তখন ডুপ্লিকেট কার্ড কোনো ব্যাপারই না।

## 1. Start a collection

আপনি তো সত্যিই চান আপনার বন্ধুরাও আপনার Blorkemon™️-পাগলামিতে যোগ দিক, আর তার সবচেয়ে ভালো উপায় হলো তাদের একটি করে কার্ড দিয়ে তাদের সংগ্রহটা শুরু করে দেওয়া।

`newCollection` ইমপ্লিমেন্ট করুন, যা একটি কার্ডকে একটি সংগ্রহে রূপান্তর করে।

```elm
newCollection "Newthree"
    --> Set.fromList ["Newthree"]
```

## 2. Grow the collection

একবার একটি সংগ্রহ তৈরি হয়ে গেলে তা যেন নিজের একটা জীবন পেয়ে যায়, আর তাকে বাড়তেই হবে।

`addCard` ইমপ্লিমেন্ট করুন, যেটি একটি `Card` ও একটি সংগ্রহ নেয়, এবং দুটি মানসহ একটি `Tuple` রিটার্ন করে: একটি `Bool`, যা বলে দেয় `Card`-টি আগেই সংগ্রহে ছিল কি না, আর কার্ডটি যোগ করা সংগ্রহটি।

```elm
addCard "Scientuna" (Set.fromList ["Newthree"])
    --> (False, Set.fromList ["Newthree", "Scientuna"])
```

## 3. Start trading

এখন যেহেতু আপনার বন্ধুরা আবার Blorkemon™️ নিয়ে পাগল হয়ে উঠেছে, আপনি এটি কাজে লাগিয়ে কার্ড বিনিময় করে নিজের সংগ্রহও বড় করতে পারেন।

সব বিনিময়ই করা যায় না, বা করলেও লাভ হয় না।
আপনার কাছে নেই এমন কার্ড আপনি বিনিময় করতে পারেন না, আর আপনার কাছে আগেই আছে এমন কার্ডের বদলে কোনো কার্ড বিনিময়ও করা উচিত নয়।

`tradeCard` ইমপ্লিমেন্ট করুন, যেটি বিনিময়ের জন্য দুটি কার্ড (আপনার আর তাদের) এবং আপনার বর্তমান সংগ্রহ নেয়।
রিটার্ন ভ্যালু দুটি মানের একটি `Tuple`: একটি `Bool`, যা জানায় বিনিময়টি সম্ভব এবং লাভজনক কি না, আর বিনিময়টি করলে আপনি যে সংগ্রহে পৌঁছাতেন সেটি (যদিও সেটি আসলে সম্ভব না হয়)।

```elm
tradeCard "Scientuna" "Newthree" (Set.fromList ["Scientuna"])
    --> (True, Set.fromList ["Newthree"])
```

## 4. There can be only one of each

ফ্লি মার্কেটে আপনি পুরনো কার্ডের একটি ভাণ্ডার খুঁজে পান।
তালিকাটিকে আপনার সংগ্রহের সঙ্গে মিলিয়ে দেখার জন্য আপনাকে কার্ডগুলো সাজাতে হবে এবং ডুপ্লিকেটগুলো সরাতে হবে।

`removeDuplicates` ইমপ্লিমেন্ট করুন, যা কার্ডের একটি তালিকা সাজায় এবং সাজানো, অনন্য কার্ডের একটি তালিকা রিটার্ন করে।

```elm
removeDuplicates ["Newthree", "Newthree", "Newthree", "Scientuna"]
    --> ["Newthree", "Scientuna"]
```

## 5. Cards they don't have

এবার নিজের সংগ্রহ নিয়ে একটু গর্ব করার পালা।

`extraCards` ইমপ্লিমেন্ট করুন, যেটি আপনার সংগ্রহ ও আরেকটি সংগ্রহ নেয়, এবং অন্য সংগ্রহটির কাছে নেই এমন কার্ডের সংখ্যা রিটার্ন করে।

```elm
extraCards (Set.fromList ["Scientuna"]) (Set.fromList ["Newthree", "Scientuna"])
    --> 0
```

## 6. Cards they all have

আপনি আর আপনার Blorkemon™️-উৎসাহী বন্ধুরা একসঙ্গে বসে ভাবছেন, কোন কার্ডগুলো সবচেয়ে কমন।

`boringCards` ইমপ্লিমেন্ট করুন, যেটি সংগ্রহের একটি তালিকা নেয় এবং সাজানো এমন কার্ডের একটি তালিকা রিটার্ন করে যা সব সংগ্রহেই আছে।

```elm
boringCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> ["Scientuna"]
```

## 7. All of the cards

আপনি আর আপনার বন্ধুরা মিলে কি সব Blorkemon™️ কার্ডের মালিক?

`totalCards` ইমপ্লিমেন্ট করুন, যেটি সংগ্রহের একটি তালিকা নেয় এবং সব সংগ্রহ মিলিয়ে ভিন্ন ভিন্ন কার্ডের মোট সংখ্যা রিটার্ন করে।

```elm
totalCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> 2
```

## 8. Shiny for the win

আপনার ভাইপো শিগগিরই আপনার সঙ্গে দেখা করতে আসছে, আর আপনি তাকে মুগ্ধ করতে চান।
বাচ্চারা তো চকচকে জিনিস পছন্দ করে, তাই না?
Blorkemon™️ কার্ড চকচকে হতে পারে!

`splitShinyCards` ইমপ্লিমেন্ট করুন, যেটি একটি সংগ্রহ নেয় এবং সাজানো কার্ডের দুটি তালিকাসহ একটি `Tuple` রিটার্ন করে: একটি তালিকায় সেই সব কার্ড যা `"Shiny"` দিয়ে শুরু, আর অন্যটিতে বাকি কার্ডগুলো।

```elm
splitShinyCards (Set.fromList ["Newthree", "Scientuna", "Shiny Scientuna"])
    --> (["Shiny Scientuna"], ["Newthree", "Scientuna"])
```
