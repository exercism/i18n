# নির্দেশনা

এই অনুশীলনীতে আপনাকে ক্লাসিক ১৯৮০-এর দশকের আর্কেড গেম [Pac-Man][Pac-Man]-এর কয়েকটি নিয়ম ইমপ্লিমেন্ট করতে হবে।

আপনার ইমপ্লিমেন্ট করার জন্য চারটি নিয়ম আছে, যেগুলো সবই গেম স্টেটের সাথে সম্পর্কিত।

> _আর্গুমেন্টগুলো কীভাবে আসছে তা নিয়ে ভাববেন না, শুধু আর্গুমেন্টগুলো একসাথে করে কাঙ্ক্ষিত ফলাফল রিটার্ন করার দিকে মনোযোগ দিন।_

## 1. Pac-Man একটি ভূত খায় কি না তা ডিফাইন করুন

`eat_ghost()` ফাংশনটি ডিফাইন করুন, যেটি দুটি প্যারামিটার নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man একটি ভূত খেতে পারলে একটি বুলিয়ান মান রিটার্ন করে।
 ফাংশনটি `True` রিটার্ন করবে শুধু তখনই, যখন Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় থাকে এবং সে একটি ভূত স্পর্শ করছে।

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Pac-Man স্কোর করে কি না তা ডিফাইন করুন

`score()` ফাংশনটি ডিফাইন করুন, যেটি দুটি প্যারামিটার নেয় (_Pac-Man একটি পাওয়ার পেলেট স্পর্শ করছে কি না_ এবং _Pac-Man একটি ডট স্পর্শ করছে কি না_) এবং Pac-Man স্কোর করলে একটি বুলিয়ান মান রিটার্ন করে।
 ফাংশনটি `True` রিটার্ন করবে, যদি Pac-Man একটি পাওয়ার পেলেট বা একটি ডট স্পর্শ করছে।

```python
>>> score(True, True)
...
True
```

## 3. Pac-Man হারে কি না তা ডিফাইন করুন

`lose()` ফাংশনটি ডিফাইন করুন, যেটি দুটি প্যারামিটার নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man হেরে গেলে একটি বুলিয়ান মান রিটার্ন করে।
 ফাংশনটি `True` রিটার্ন করবে, যদি Pac-Man একটি ভূত স্পর্শ করছে এবং তার কোনো পাওয়ার পেলেট সক্রিয় না থাকে।

```python
>>> lose(False, True)
...
True
```

## 4. Pac-Man জেতে কি না তা ডিফাইন করুন

`win()` ফাংশনটি ডিফাইন করুন, যেটি তিনটি প্যারামিটার নেয় (_Pac-Man সব ডট খেয়ে ফেলেছে কি না_, _Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_, এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man জিতলে একটি বুলিয়ান মান রিটার্ন করে।
 ফাংশনটি `True` রিটার্ন করবে, যদি Pac-Man সব ডট খেয়ে ফেলেছে এবং ৩ নম্বর অংশে ডিফাইন করা নিয়ম অনুযায়ী হারেনি।

```python
>>> win(False, True, False)
...
False
```
