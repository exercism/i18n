# টেস্ট

## টেস্ট চালানো

টেস্ট চালানোর জন্য নিচের কমান্ডটি চালান:

```bash
make
```

## অনুশীলনী সমাধান করা

কোনো অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো। আপনি যখন টেস্ট চালান, ডিফল্টভাবে কেবল একটি টেস্ট (প্রথমটি) চলে। এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন। সেটি পাস হয়ে গেলে `TEST_IGNORE()` লাইনটি মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন। সব টেস্ট চালু হয়ে গেলে এবং আপনার ইমপ্লিমেন্টেশন সেগুলো সব পাস করালে, আপনি অনুশীলনীটি সমাধান করে ফেলেছেন!
