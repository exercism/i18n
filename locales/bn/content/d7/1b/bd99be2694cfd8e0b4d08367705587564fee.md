# নির্দেশাবলি

আপনার বন্ধু কোজো সংখ্যার বড় ভক্ত।
তার 'fun-with-numbers' নামে একটি ছোট ওয়েবসাইট আছে।
কোজো প্রোগ্রামিংয়ে খুব একটা ভালো নন, তাই তিনি আপনার কাছে সাহায্য চেয়েছেন।

আপনি কোজোর ওয়েবসাইটে নতুন সংখ্যার গেমের জন্য দুটি হেল্পার ফাংশন বানাবেন, আর ব্যবহারকারীর দেওয়া কিছু ইনপুট যাচাই করার জন্য একটি তৃতীয় ফাংশন বানাবেন।

## 1. স্লট মেশিনের সংখ্যাগুলোর যোগফল বের করুন

কোজোর ওয়েবসাইটের একটি গেম দেখতে স্লট মেশিনের মতো, যেখানে অঙ্ক লেখা চাকার দুটি দল দেখা যায়।
অঙ্কের প্রতিটি দল একটি সংখ্যা বোঝায়।
গেমের কার্যপ্রণালীর জন্য কোজোকে ওই দুই সংখ্যার যোগফল জানতে হবে।

এমন একটি ফাংশন `twoSum` লিখুন, যা প্যারামিটার হিসেবে দুটি অ্যারে নেয়।
প্রতিটি অ্যারে 0 থেকে 9-এর মধ্যে এক বা একাধিক সংখ্যা নিয়ে গঠিত।
ফাংশনটি প্রতিটি অ্যারেকে একটি সংখ্যা হিসেবে ধরে নেবে এবং ওই দুই সংখ্যার যোগফল রিটার্ন করবে।

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. একটি সংখ্যা প্যালিনড্রোম কি না তা নির্ণয় করুন

ওয়েবসাইটের আরেকটি গেম হলো "Lucky Numbers" নামের একটি ছোট কুইজ।
একজন ব্যবহারকারী একটি সংখ্যা লিখতে পারেন এবং তারপর দেখেন সংখ্যাটি কোনো গোপন ক্রম বা প্যাটার্নের অন্তর্গত কি না।
"lucky numbers"-এর ক্রম বা প্যাটার্ন প্রতি মাসে বদলে যায়, আর প্রতিটি ব্যবহারকারীর তা অনুমান করার সুযোগ থাকে সীমিত সংখ্যকবার।

এই মাসের lucky numbers হবে এমন সংখ্যা, যেগুলো প্যালিনড্রোম।
অঙ্কগুলো উল্টে দিলেও প্যালিনড্রোমিক সংখ্যা একই থাকে।

এমন নতুন একটি ফাংশন `luckyNumber` তৈরি করুন, যা প্যারামিটার হিসেবে একটি সংখ্যা নেয়।
সংখ্যাটি প্যালিনড্রোম হলে ফাংশনটি `true` রিটার্ন করবে, নাহলে `false`।
ইনপুট সংখ্যাটি সবসময় একটি ধনাত্মক ইন্টিজার হবে।

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. ব্যবহারকারীর ভুল ইনপুটের জন্য একটি এরর মেসেজ তৈরি করুন

ওয়েবসাইটের বিভিন্ন জায়গায় ইনপুট ফিল্ড আছে, যেখানে ব্যবহারকারীরা সংখ্যা লিখতে পারেন এবং কোনো কাজ শুরু করতে একটি বোতামে ক্লিক করতে পারেন।
কোজো তার সাইটের ইউজার এক্সপেরিয়েন্স উন্নত করতে চান।
ব্যবহারকারী বোতামে ক্লিক করলেও ফিল্ডে যদি অবৈধ কোনো ইনপুট ভ্যালু থাকে, তাহলে তিনি একটি এরর মেসেজ দেখাতে চান।

একটি ইনপুট ফিল্ডের ভ্যালু কীভাবে পাওয়া যায়, সে সম্পর্কে আরও কিছু তথ্য নিচে দেওয়া হলো।

- ব্যবহারকারী কোনো ফিল্ডে কিছু লিখলে সংশ্লিষ্ট ভ্যালুটি সবসময় একটি স্ট্রিং হয়, এমনকি তিনি কেবল সংখ্যাই লিখে থাকলেও।
- ব্যবহারকারী কিছু লিখে আবার মুছে ফেললে ভ্যারিয়েবলটি একটি খালি স্ট্রিং হবে।
- ব্যবহারকারী টাইপ করা শুরু করার আগে ভ্যারিয়েবলটি `undefined` বা `null` হতে পারে।

ব্যবহারকারীর ইনপুট প্যারামিটার হিসেবে নেয় এমন একটি ফাংশন `errorMessage` লিখুন।
ব্যবহারকারী কোনো ইনপুট না দিলে `errorMessage` ফেরত দেবে `'Required field'`।
ইনপুটটি যদি (JavaScript-এর কনভার্সন নিয়ম অনুযায়ী) শূন্য নয় এমন কোনো সংখ্যা প্রকাশ না করে, তাহলে ফেরত দেওয়া উচিত `'Must be a number besides 0'`।
বাকি সব ক্ষেত্রে ধরে নিতে পারেন ইনপুটটি বৈধ, রিটার্ন ভ্যালুটি হবে একটি খালি স্ট্রিং।

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
