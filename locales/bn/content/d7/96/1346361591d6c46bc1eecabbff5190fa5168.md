# ভূমিকা

## ফাংশন এক্সপোর্ট করা

ফাংশন এক্সপোর্ট করা নিয়ে প্রথম কনসেপ্টেই আলোচনা করা হয়েছে, এখানে দ্রুত একবার ঝালিয়ে নেওয়া যাক।

এলমে প্রতিটি ফাইলই একটি মডিউল, এবং অন্য সব কোডের আগে সেখানে একটি `module` স্টেটমেন্ট থাকতে হবে।

মডিউলের নাম তার ফাইলের নামের সাথে মিলতে হবে, তাই `Calculator` মডিউলটিকে থাকতে হবে Calculator.elm ফাইলে, আর `Parser.Utils` মডিউলটিকে থাকতে হবে Parser/Utils.elm ফাইলে।

একটি মডিউলের ভেতরে যা কিছু ডিফাইন করা হয়, তা সেই মডিউলেই সীমাবদ্ধ থাকে এবং `exposing`-এ তালিকাভুক্ত না থাকলে মডিউলের বাইরে থেকে অ্যাক্সেস করা যায় না।

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## অন্য মডিউল থেকে ফাংশন ইমপোর্ট করা

অন্য মডিউলে ডিফাইন করা ফাংশন অ্যাক্সেস করা হয় ইমপোর্টের মাধ্যমে।
কোনো মডিউল ইমপোর্ট করলে সেই মডিউল যেসব ফাংশন এক্সপোজ করেছে, সেগুলো সবই অ্যাক্সেসযোগ্য হয়ে যায়।
তবে সেগুলো কীভাবে অ্যাক্সেস করা হবে, তা নির্ভর করে মডিউলটি কীভাবে ইমপোর্ট করা হয়েছে তার উপর।

কোয়ালিফাইড ইমপোর্ট হলো ডিফল্ট, আর এমন মডিউলের ভেতরের কোনো ফাংশন (যেমন `List` মডিউলের `map` ফাংশন) অ্যাক্সেস করতে মডিউলের নামটা আগে বসাতে হয় (`List.map`)।

ওপেন ইমপোর্ট সেই মডিউলের এক্সপোজ করা ফাংশনগুলো প্রিফিক্স ছাড়াই সরাসরি অ্যাক্সেস করতে দেয়। এগুলো করা হয় `exposing` কিওয়ার্ড দিয়ে, এক্সপোর্টে ব্যবহৃতটির ঠিক উল্টো প্রতিচ্ছবির মতো। আপনি সব ফাংশনই এক্সপোজ করতে পারেন (`..` দিয়ে), আবার নির্দিষ্ট কিছুও (যেমন `map`)।

অন্য মডিউল থেকে টাইপ আর তাদের কনস্ট্রাক্টরও ইমপোর্ট করা যায়, যেটি পরের একটি কনসেপ্ট।

স্পষ্টতা বজায় রাখতে এবং নামের সংঘর্ষ এড়াতে কোয়ালিফাইড ইমপোর্টকেই প্রাধান্য দেওয়া হয়।

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## টাইপ অ্যানোটেশন

টাইপ অ্যানোটেশন ডিফাইন করা হয় `name : parameter types -> return type` দিয়ে, যেখানে প্যারামিটার টাইপগুলোও `->` দিয়ে আলাদা করা হয়।

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

ফাংশনের প্যারামিটার ডিফাইন করতেও বন্ধনী ব্যবহার করা যায় (এগুলোও একই সিনট্যাক্সে ডিফাইন করা হয়, তাই বন্ধনীর প্রয়োজন পড়ে)।

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## সংখ্যা

এলমে দুই ধরনের সংখ্যা পাওয়া যায়, যেগুলো `Int` আর `Float` টাইপ দিয়ে নির্ধারিত।
`Int` বলতে ধনাত্মক ও ঋণাত্মক ইন্টিজারগুলোর সেট বোঝায়।
`Float` বলতে বাস্তব সংখ্যাগুলোর সেট বোঝায়, যা কম্পিউটারের নির্ভুলতার সীমার মধ্যে সীমাবদ্ধ।
সংখ্যার উপর ডিফাইন করা অপারেশনগুলো সাধারণত এক টাইপের উপরই কাজ করে, দুটো মিশিয়ে নয়।
দুটোর মধ্যে রূপান্তরের জন্য কিছু ফাংশন আছে, যেমন `toFloat` যা `Int`-কে `Float`-এ রূপান্তর করে, আর `round`, `floor`, `ceiling` বা `truncate` যা ভিন্ন ভিন্ন সেমান্টিক্সে একটি `Float`-কে `Int`-এ রূপান্তর করে।

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## স্ট্রিং অপারেশন

কোডে শব্দ ও বাক্য বোঝাতে এলমের আছে একটি নেটিভ `String` টাইপ।
স্ট্রিং লিটারাল ডাবল কোটের মাঝে লেখা হয়, যেমন `"Hello World!"`।
স্ট্রিং কনক্যাটেনেশন অপারেটর `++` আর ইকুয়ালিটি অপারেটর `==` ডিফল্টভাবেই পাওয়া যায়।

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

বাকি বেশিরভাগ স্ট্রিং ফাংশন `String` মডিউলে আছে, যেটি ইমপোর্ট করতে হয়।

https://package.elm-lang.org/packages/elm/core/latest/String
