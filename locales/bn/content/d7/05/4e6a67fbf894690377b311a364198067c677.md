# পরিচিতি

JSON **অবজেক্ট** হলো, অন্য ভাষার পরিভাষা ব্যবহার করলে, একটি "হ্যাশ", "ম্যাপ" বা "ডিকশনারি"।

JSON একটি _অবজেক্ট_-কে এভাবে সংজ্ঞায়িত করে:

> একটি অবজেক্ট হলো **নাম**/**মান** জোড়ার একটি অবিন্যস্ত সেট।
> একটি অবজেক্ট শুরু হয় `{` বাম ব্রেস দিয়ে এবং শেষ হয় `}` ডান ব্রেস দিয়ে।
> প্রতিটি _নাম_-এর পরে থাকে `:` কোলন, আর _নাম/মান_ জোড়াগুলোকে আলাদা করে `,` কমা।

_নাম_ **অবশ্যই একটি স্ট্রিং হতে হবে**।
_নাম_-এর আরেকটি নাম হলো _কী (key)_।

_মান_ যেকোনো JSON টাইপের হতে পারে।
একই অবজেক্টের ভিন্ন ভিন্ন _মান_ ভিন্ন ভিন্ন টাইপের হতে পারে, যেমন এই উদাহরণে।

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

মনে রাখবেন, _শেষ_ কী (key)-মান জোড়ার পরে কোনো কমা **থাকতে পারবে না**।

## অবজেক্ট তৈরি করা

নাম/মান জোড়াগুলো একত্র করতে ব্রেস ব্যবহার করুন।
নামগুলো অবশ্যই স্ট্রিং হতে হবে, তবে নামগুলো **আইডেন্টিফায়ার-এর মতো** হলে (অ্যালফানিউমেরিক ক্যারেক্টার ও আন্ডারস্কোর দিয়ে গঠিত, এবং শুরুতে কোনো সংখ্যা নয়) সেগুলোকে কোট করার দরকার নেই।

```jq
{name: "Jane", age: 42}
```

_আইডেন্টিফায়ার-এর মতো_ নয় এমন কী (key) ব্যবহার করাও বৈধ।
শুধু সেগুলোকে কোট করে দিন।

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

নামটি যদি কোনো এক্সপ্রেশনের ফলাফল হয়, তবে এক্সপ্রেশনটি **অবশ্যই** প্রথম বন্ধনীর ভেতরে থাকতে হবে।

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## ইনডেক্সিং

অবজেক্ট থেকে মান পাওয়া যায় **ডট নোটেশন** দিয়ে।

```jq
{name: "Jane", age: 42} | .age    # => 42
```

কী (key)-কে আইডেন্টিফায়ার হিসেবে উল্লেখ করতে না পারলে **ব্র্যাকেট নোটেশন** ব্যবহার করুন।

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## কী (key)-মান জোড়া যোগ করা বা পরিবর্তন করা

অ্যারেতে নতুন একটি কী (key)-মান জোড়া যোগ করতে, বা কোনো বিদ্যমান কী (key)-এর মান আপডেট করতে, `=` অ্যাসাইনমেন্ট অপারেটর ব্যবহার করুন, যার বাম পাশে থাকবে একটি ইনডেক্স এক্সপ্রেশন।

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+` অপারেটর অবজেক্টগুলোকে _মার্জ_ করবে।

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## একটি কী (key) মুছে ফেলা

একটি কী (key) মুছে ফেলতে `del` ফাংশনটি ব্যবহার করুন।
এটি আপডেট হওয়া অবজেক্টটি রিটার্ন করে।

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

`del`-এর প্যারামিটার হলো একটি **ইনডেক্স এক্সপ্রেশন** (ডট বা ব্র্যাকেট নোটেশন ব্যবহার করে) যা অবজেক্টের একটি কী (key)-কে নির্দেশ করে।
`jq` এটাকে বলে **পাথ এক্সপ্রেশন**।
শুধু একটি স্ট্রিং দিলেই যথেষ্ট হয় না।

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## সদস্যতা

- অবজেক্টে কোনো কী (key) আছে কি না পরীক্ষা করতে `has` ফাংশনটি ব্যবহার করুন।

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- `in` দিয়ে পরীক্ষা করুন কোনো কী (key) অবজেক্টে আছে কি না।

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## সব কী (key) তালিকা করা

সব কী (key)-এর একটি তালিকা আউটপুট করতে `keys` ফাংশনটি ব্যবহার করুন।

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

মনে রাখবেন, `keys` কী (key)গুলোকে _সর্ট_ করে ফেলে।
আসল ক্রমে কী (key)গুলো পেতে `keys_unsorted` ব্যবহার করুন।

সব _মান_ তালিকা করার মতো সমতুল্য কোনো ফাংশন নেই।
তবে `.[]` ফিল্টার অবজেক্টের মানগুলোকে একটি _স্ট্রিম_ হিসেবে আউটপুট করে, আর সেই স্ট্রিমকে `[...]` অ্যারে কনস্ট্রাক্টর দিয়ে ধরে ফেলা যায়।

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## ইটারেশন করা

- `map_values(filter)` ফাংশনটি অবজেক্টের প্রতিটি _মান_-এর উপর ফিল্টারটি প্রয়োগ করে।

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- একটি অবজেক্টের উপর ইটারেট করতে হলে প্রথমে সেটিকে কী (key)-মান অবজেক্টের একটি অ্যারেতে রূপান্তর করতে হবে।
  `to_entries` ফাংশনটি সেটিই করে।

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  এই পর্যায়ে আমরা `map`-এর মতো অ্যারে ইটারেশন ফাংশন ব্যবহার করতে পারি।

- `from_entries` ফাংশনটি এর উল্টো: কী (key)-মান অবজেক্টের একটি অ্যারে থেকে একটি অবজেক্ট বানায়।

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- অবজেক্টের _প্রতিটি_ কী (key)-মান জোড়ার উপর একটি ফিল্টার প্রয়োগ করতে `with_entries(filter)` ফাংশনটি ব্যবহার করুন।

  উদাহরণস্বরূপ, একটি নামকে বয়সে ম্যাপ করা একটি অবজেক্ট দেওয়া থাকলে, কী (key) ও মানগুলো এভাবে বদলে দেওয়া যায়।

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  আউটপুট দেয়

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` হলো নিচেরটির সমান

  ```jq
  to_entries | map(filter) | from_entries
  ```
