# নির্দেশনা

সারাহ একটি নতুন রোল-প্লেয়িং গেম নিয়ে কাজ করছেন এবং প্লেয়ার মেকানিক্সে আপনার সাহায্য দরকার।

## 1. `player` টিউপলটি ডিফাইন করুন

`player` নামে চারটি স্লট ও ডিফল্ট মানসহ একটি টিউপল ক্লাস ডিফাইন করুন:

| স্লট     | ডিফল্ট |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

একবার ডিফাইন করা হলে, আপনি একটি প্লেয়ারকে লিটারাল হিসেবে তৈরি করতে পারেন:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. প্লেয়ারটিকে পরিচয় করান

`introduce` ডিফাইন করুন যেন এটি প্লেয়ারের নাম রিটার্ন করে। স্টেলথি প্লেয়াররা তাদের নাম লুকিয়ে রাখে (`name` হলো `f`) এবং তাদের `"Mighty Magician"` হিসেবে পরিচয় দিতে হবে।

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. পড়ে যাওয়া প্লেয়ারকে পুনরুজ্জীবিত করুন

`revive` ডিফাইন করুন যেন এটি একটি *নতুন* প্লেয়ার রিটার্ন করে, যার `health` 100 এবং `mana` 100 সেট করা থাকবে, কিন্তু কেবল যদি প্লেয়ারের `health` `0` হয়। প্লেয়ারটি যদি এখনও জীবিত থাকে, তবে `f` রিটার্ন করুন।

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. ড্যামেজ নিন

`take-damage` ডিফাইন করুন যেন এটি একটি *নতুন* প্লেয়ার রিটার্ন করে, যার `health` প্রদত্ত পরিমাণ কমিয়ে আনা হয়েছে, এবং যা কখনও `0`-এর নিচে নামবে না।

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
