# নির্দেশনা

আপনি একজন উৎসাহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কত পাখি এসেছে তার হিসাব রাখেন।

আপনার সামনে ছয়টি কাজ, সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. গত সপ্তাহে সংখ্যাগুলো কত ছিল দেখুন

তুলনার সুবিধার জন্য আপনি গত সপ্তাহের সংখ্যাগুলোর একটি কপি সবসময় হাতের কাছে রাখেন, যেগুলো ছিল: ০, ২, ৫, ৩, ৭, ৮ এবং ৪। (_static_) `BirdCount.LastWeek()` মেথডটি ইমপ্লিমেন্ট করুন যা গত সপ্তাহের সংখ্যাগুলো রিটার্ন করে:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. আজ কত পাখি এসেছে দেখুন

`BirdCount.Today()` মেথডটি ইমপ্লিমেন্ট করুন যেন এটি রিটার্ন করে আজ আপনার বাগানে কত পাখি এসেছে। পাখির সংখ্যাগুলো দিন অনুসারে সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরোনো দিনের সংখ্যা আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. আজকের সংখ্যা বাড়ান

`BirdCount.IncrementTodaysCount()` মেথডটি ইমপ্লিমেন্ট করুন যা আজকের সংখ্যা বাড়ায়:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. পাখি আসেনি এমন কোনো দিন ছিল কি না দেখুন

`BirdCount.HasDayWithoutBirds()` মেথডটি ইমপ্লিমেন্ট করুন যা `true` রিটার্ন করে, যদি এমন কোনো দিন থাকে যেদিন শূন্য পাখি বাগানে এসেছিল; না হলে `false` রিটার্ন করুন:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. প্রথম কয়েক দিনে আসা পাখির সংখ্যা হিসাব করুন

`BirdCount.CountForFirstDays()` মেথডটি ইমপ্লিমেন্ট করুন যা সপ্তাহের শুরু থেকে আপনার বাগানে আসা পাখির সংখ্যা রিটার্ন করে, তবে সংখ্যাটি সপ্তাহের শুরু থেকে নির্দিষ্ট সংখ্যক দিনের মধ্যে সীমাবদ্ধ রাখুন।

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্য দিনের চেয়ে ব্যস্ত থাকে। ব্যস্ত দিন বলতে সেদিনকে বোঝায় যেদিন পাঁচ বা তার বেশি পাখি আপনার বাগানে এসেছে।
`BirdCount.BusyDays()` মেথডটি ইমপ্লিমেন্ট করুন যা ব্যস্ত দিনের সংখ্যা রিটার্ন করে:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
