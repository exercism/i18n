# পরিচিতি

## ইন্টিজার

Elixir-এ দুই ধরনের সংখ্যা আছে - ইন্টিজার আর ফ্লোট।

ইন্টিজার হলো পূর্ণসংখ্যা।

```elixir
integer = 3
# => 3
```

## ফ্লোটিং পয়েন্ট সংখ্যা

ফ্লোট হলো এমন সংখ্যা, যার দশমিক বিভাজকের পরে এক বা একাধিক অঙ্ক থাকে। এগুলো ৬৪-বিট ডাবল প্রেসিশন ফ্লোটিং-পয়েন্ট ফরম্যাট ব্যবহার করে।

```elixir
float = 3.45
# => 3.45
```

### সংখ্যা নিয়ে কাজ করা

[`Integer`][integer-functions] আর [`Float`][float-functions] মডিউলে এই টাইপগুলো নিয়ে কাজ করার জন্য কিছু কাজের ফাংশন পাবেন। মৌলিক গাণিতিক অপারেটরগুলো [`Kernel`][kernel-arithmetic-operators] মডিউলে ডিফাইন করা আছে।

### রূপান্তর

একই গাণিতিক এক্সপ্রেশনে ইন্টিজার আর ফ্লোট একসাথে মেশানো যায়। কোনো এক্সপ্রেশনে ফ্লোট ব্যবহার করলে ফলাফলটিও যে ফ্লোট হবে তা নিশ্চিত হয়।

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

তবে ভাগ করার সময় ফলাফল সবসময় ফ্লোট হবে, এমনকি শুধু ইন্টিজার ব্যবহার করলেও।

```elixir
6 / 2
# => 3.0
```

একটি ফ্লোটকে ইন্টিজারে রূপান্তর করতে, [`trunc/1`][trunc-1] দিয়ে দশমিক অংশটি বাদ দিতে পারেন।
