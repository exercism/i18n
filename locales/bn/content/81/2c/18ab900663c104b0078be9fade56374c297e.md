# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার        | টাইপ    | বিবরণ             |
| -------- | ------------ | ------- | ----------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | ত্রিভুজের সারির সংখ্যা |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | ওয়ার্ডের অ্যারে          |
| `$v0`    | আউটপুট       | ইন্টিজার | আউটপুট ওয়ার্ডের সংখ্যা  |
| `$t0-9`  | টেম্পোরারি    | যেকোনো     | টেম্পোরারি স্টোরেজের জন্য   |
