# নির্দেশনা

শহরে একটি নতুন কবিতা ক্লাব খুলেছে, আর আপনি সেখানে যাওয়ার কথা ভাবছেন।
আগে বেশ কিছু ঘটনা ঘটে যাওয়ায়, ক্লাবটির দরজায় প্রবেশের জন্য একটি নির্দিষ্ট নিয়ম রয়েছে, যা ঢোকার চেষ্টা করার আগে আপনাকে ভালোভাবে শিখে নিতে হবে।

কবিতা ক্লাবে দুটি দরজা আছে, একটি সামনের আর একটি পিছনের, এবং দুটিতেই পাহারাদার রয়েছে।
ভেতরে ঢুকতে হলে আপনাকে সেই দিনের পাসওয়ার্ড বের করতে হবে।

পাসওয়ার্ডটি সবসময় একটি কবিতার ভিত্তিতে তৈরি হয় এবং দুই ধাপে বের করা যায়।

1. পাহারাদার কবিতাটি এক লাইন করে আবৃত্তি করবেন, আর আপনাকে সেই লাইনের নির্দিষ্ট অক্ষরটি দিয়ে জবাব দিতে হবে।
2. এরপর পাহারাদার আপনার দেওয়া সব অক্ষর একসাথে বলে দেবেন, আর আপনাকে সেগুলো একটি কাগজে নির্দিষ্ট একটি ফরম্যাটে লিখে রাখতে হবে।

প্রক্রিয়ার বিস্তারিত নির্ভর করে আপনি কোন দরজা দিয়ে ঢুকতে চাইছেন তার উপর।

~~~~exercism/note
এই অনুশীলনীর সব স্ট্রিং ASCII-এনকোডেড এবং NUL-টার্মিনেটেড হবে।
এর মানে হলো সব ক্যারেক্টার ASCII এনকোডিং ব্যবহার করে এবং প্রতিটি স্ট্রিং ঠিক তখনই শেষ হয়, যখন '\0' (NUL ক্যারেক্টার, যার মান `0`) পাওয়া যায়।
~~~~

~~~~exercism/note
এই কনসেপ্টে যে স্ট্রিং ইনস্ট্রাকশনগুলোর কথা বলা হয়েছে:

| ইনস্ট্রাকশন | এটি কী করে                                                                                                        |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | `rsi` নির্দেশিত মেমরি লোকেশন থেকে একটি মান `rax`-এ লোড করে                                                       |
| `stos`       | `rax` থেকে একটি মান `rdi` নির্দেশিত মেমরি লোকেশনে স্টোর করে                                                      |
| `movs`       | `rsi` নির্দেশিত মেমরি লোকেশন থেকে একটি মান কপি করে এবং তা `rdi` নির্দেশিত মেমরি লোকেশনে স্টোর করে                 |

এগুলোর প্রতিটির সাথে অপারেশনের আকার বোঝানোর জন্য একটি সাফিক্স থাকতে হবে:

| সাফিক্স | আকার             |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

সব স্ট্রিং ইনস্ট্রাকশন `rsi` এবং/অথবা `rdi`-এর অ্যাড্রেসও পরিবর্তন করে (শুধু সেই রেজিস্টারগুলোতে, যেগুলো ইনস্ট্রাকশনটি ব্যবহার করে)।
ডিফল্টভাবে এগুলো অপারেশনের আকার অনুযায়ী অ্যাড্রেস বাড়ায়।

উপরের যেকোনো স্ট্রিং ইনস্ট্রাকশনের সাথে `rep` প্রিফিক্স যোগ করা যায়, যাতে সেটি `rcx`-এর সমান সংখ্যক বার পুনরাবৃত্তি হয়।
~~~~

## 1. একটি বাক্যের প্রথম অক্ষর বের করুন

সামনের দরজার পাসওয়ার্ডের অক্ষরগুলো নির্ধারণ করতে, পাহারাদার কবিতার যে লাইনটি আপনার কাছে আবৃত্তি করেন, তার প্রথম অক্ষর দিয়ে আপনাকে জবাব দিতে হবে।

সুন্দর একটি পাসওয়ার্ড পাওয়ার জন্য কবিতা ক্লাবের সদস্যরা _অ্যাক্রোস্টিক_ কবিতা ব্যবহার করতে পছন্দ করেন।
এর মানে প্রতিটি বাক্যের প্রথম অক্ষর মিলে একটি শব্দ তৈরি করে।
তাঁদের প্রিয় লেখকদের একজন Michael Lockwood-এর একটি উদাহরণ এখানে।

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

তাই পাহারাদার যখন **Stands so high** আবৃত্তি করেন, আপনি জবাব দেবেন **S**; আর পাহারাদার যখন **Huge hooves too** আবৃত্তি করেন, আপনি জবাব দেবেন **H**।

`front_door_response` ফাংশনটি লিখুন, যা আর্গুমেন্ট হিসেবে কবিতার একটি লাইনের মেমরি অ্যাড্রেস নেয় এবং সেই লাইনের প্রথম অক্ষর রিটার্ন করে।
এই অক্ষরটি ASCII-এনকোডেড ক্যারেক্টার হিসেবে রিটার্ন করতে হবে, যা ১ বাইট জায়গা নেয়।

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. একটি শব্দ বড় হাতের অক্ষরে লিখুন

এখন আপনার কাছে সব সঠিক অক্ষর রয়েছে, তাই সামনের দরজার পাসওয়ার্ড পেতে শুধু শব্দটি সঠিকভাবে বড় হাতের অক্ষরে লিখতে হবে।

`front_door_password` ফাংশনটি লিখুন, যা আর্গুমেন্ট হিসেবে এমন একটি স্ট্রিংয়ের মেমরি অ্যাড্রেস নেয়, যাতে শুধু ১ নম্বর কাজে পাওয়া একত্রিত অক্ষরগুলো থাকে।
এটিকে [ইন-প্লেস][in-place] ইনপুট স্ট্রিংটি পরিবর্তন করতে হবে, যাতে সেটি সঠিকভাবে বড় হাতের অক্ষরে লেখা হয়।
এর মানে হলো সঠিক স্ট্রিংটি ইনপুটের একই মেমরি লোকেশনে সংরক্ষিত থাকবে।

ফাংশনটির কোনো রিটার্ন ভ্যালু নেই।

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. একটি বাক্যের শেষ অক্ষর বের করুন

পিছনের দরজার পাসওয়ার্ডের অক্ষরগুলো নির্ধারণ করতে, পাহারাদার কবিতার যে লাইনটি আপনার কাছে আবৃত্তি করেন, তার শেষ অক্ষর দিয়ে আপনাকে জবাব দিতে হবে।

কবিতা ক্লাবের সদস্যরা সত্যিই বুদ্ধিমান।
আগে উল্লেখ করা কবিতাটি _টেলেস্টিক_-ও, যার মানে প্রতিটি বাক্যের শেষ অক্ষরও মিলে একটি শব্দ তৈরি করে:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

পাহারাদার যখন **Stands so high** আবৃত্তি করেন, আপনি জবাব দেবেন **h**; আর যখন **Huge hooves too** আবৃত্তি করেন, আপনি জবাব দেবেন **o**।

মনে রাখবেন, পাহারাদার কখনো কখনো কবিতা আবৃত্তির সময় শৈলীগত বিরতি (যতিচিহ্ন বা হোয়াইটস্পেসের আকারে) দেন।
সঠিক অক্ষরটি বের করতে হলে সেই বিরতিগুলো উপেক্ষা করতে হবে।

`back_door_response` ফাংশনটি লিখুন, যা আর্গুমেন্ট হিসেবে কবিতার একটি লাইনের মেমরি অ্যাড্রেস নেয় এবং সেই লাইনের শেষ অক্ষর রিটার্ন করে।
এই অক্ষরটি ASCII-এনকোডেড ক্যারেক্টার হিসেবে রিটার্ন করতে হবে, যা ১ বাইট জায়গা নেয়।

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. ভদ্র হোন

পিছনের দরজা দিয়ে কবিতা ক্লাবে ঢুকতে হলে আপনাকে বাড়তি ভদ্রতা দেখাতে হবে।
তাই এবার পাসওয়ার্ড বের করতে শব্দটি সঠিকভাবে বড় হাতের অক্ষরে লিখতে হবে এবং শেষে `", please."` যোগ করতে হবে।

`back_door_password` ফাংশনটি লিখুন, যা এই ক্রমে আর্গুমেন্ট গ্রহণ করে:

1. বাফারের মেমরি অ্যাড্রেস, যেখানে ফলাফল স্ট্রিংটি সংরক্ষিত হবে।
2. এমন একটি স্ট্রিংয়ের মেমরি অ্যাড্রেস, যাতে ৩ নম্বর কাজে পাওয়া একত্রিত অক্ষরগুলো থাকে।

ফাংশনটি বড় হাতের অক্ষরে লেখা পাসওয়ার্ডের ভদ্র সংস্করণটি [বাফার][buffer]-এ সংরক্ষণ করবে।
_বাফার_ হলো একটি অ্যারে, যা মেমরিতে মান সংরক্ষণ করে সেগুলো এক ফাংশন থেকে আরেক ফাংশনে নিয়ে যেতে ব্যবহৃত হয়।

এই ফাংশনটির কোনো রিটার্ন ভ্যালু নেই।

```c
back_door_password("horse");
// => "Horse, please."
```
