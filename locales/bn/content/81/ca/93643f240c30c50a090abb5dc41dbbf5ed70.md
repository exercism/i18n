# সম্পর্কে

`Bool` টাইপ হলো ভাষার মৌলিক উপাদানগুলোর একটি।
এর উদ্দেশ্য হলো কোনো কিছু সত্য না মিথ্যা তা বর্ণনা করা, যার জন্য যথাক্রমে `True` ও `False` মান ব্যবহৃত হয়।
`Bool` নামটি বুলিয়ানের সংক্ষিপ্ত রূপ। বুলিয়ান গণিতের একটি শাখা, যা যুক্তিনির্ভর চিন্তার সাথে সম্পর্কিত এবং জর্জ বুলের কাজের নামে নামকরণ করা হয়েছে।

## বুলিয়ান অপারেটর

`Bool` টাইপের মান নিয়ে কাজ করার জন্য দুটি ফাংশন ও দুটি অপারেটর আছে।

- `not : Bool -> Bool`
  এই ফাংশনটি `True`-কে `False`-এ এবং `False`-কে `True`-এ রূপান্তর করে।
- `(&&) : Bool -> Bool -> Bool`
  "AND" নামের এই অপারেটরটি দুটি বুলিয়ান নেয় এবং দুটোই `True` হলে `True` রিটার্ন করে।
  উদাহরণস্বরূপ, `True && True` রিটার্ন করে `True`, কিন্তু `True && False` রিটার্ন করে `False`।
- `(||) : Bool -> Bool -> Bool`
  "OR" নামের এই অপারেটরটি দুটি বুলিয়ান নেয় এবং অন্তত একটি `True` হলে `True` রিটার্ন করে।
  উদাহরণস্বরূপ, `False || False` রিটার্ন করে `False`, কিন্তু `True || False` রিটার্ন করে `True`।
- `xor : Bool -> Bool -> Bool`
  "XOR" নামের এই ফাংশনটি (অপারেটর নয়) দুটি বুলিয়ান নেয় এবং কেবল তখনই `True` রিটার্ন করে যখন একটি `True` আর অন্যটি `False` হয়।

`&&` ও `||` অপারেটরের অগ্রাধিকার এক নয়।
`*` গুণ ও `+` যোগের মতোই `&&`-এর অগ্রাধিকার `||`-এর চেয়ে বেশি।
এর ফলাফলস্বরূপ, `True || False && False` এক্সপ্রেশনটি `True || (False && False)`-এর সমতুল্য, যা `(True || False) && False` থেকে আলাদা।
প্রথমটি `True` রিটার্ন করে, আর দ্বিতীয়টি রিটার্ন করে `False`।

## শর্তভিত্তিক শাখা

আপনার কোডে এমন শাখা তৈরি করতে বুলিয়ান অত্যন্ত কাজের, যা কেবল নির্দিষ্ট কিছু শর্ত পূরণ হলেই চালানো হয়।
Elm-এ এটি করা হয় একটি `if-then-else` এক্সপ্রেশন দিয়ে, যা নিচের মতো করে ব্যবহার করা হয়।

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

`someCondition` মানটি এমন যেকোনো এক্সপ্রেশন হতে পারে যা একটি `Bool` রিটার্ন করে।
ঐ বুলিয়ান মানটি `True` হলে কোডটি `doSomething` চালাবে।
অন্যথায় তা `False` হবে এবং কোডটি `doSomethingElse` চালাবে।
অন্য কিছু প্রোগ্রামিং ভাষার বিপরীতে এখানে `else` শাখাটি বাধ্যতামূলক।

আপনার যদি একাধিক শর্ত পরপর জুড়তে হয়, তাহলে `if-then-else` এক্সপ্রেশনগুলো পরপর জুড়ে দিলেই হবে।

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
