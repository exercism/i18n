# পরিচিতি

আপনার যখন কনস্ট্যান্টের একটি সেট প্রকাশ করার দরকার হয়, তখনই আপনি [অ্যাটম][atom] ব্যবহার করতে পারেন। অ্যাটম মান তুলনা করার একটি টাইপ-সেফ উপায় দেয়। একটি অ্যাটম তার নাম দিয়েই সংজ্ঞায়িত হয়, যে নাম একটি কোলন দিয়ে শুরু হয়:

```elixir
# Atoms start with a ':',
# followed by alphanumeric snake_cased characters
:an_atom
```

Elixir-এর স্ট্যান্ডার্ড লাইব্রেরির অনেক ফাংশন ফলাফল বোঝাতে একটি অ্যাটম রিটার্ন করে:

```elixir
Enum.fetch([1], 0)
# => {:ok, 1}
Enum.fetch([1], 2)
# => :error
```

[_অ্যাটম_][atom]-গুলো অভ্যন্তরীণভাবে একটি লুকআপ টেবিলে একটি ইন্টিজার দিয়ে রিপ্রেজেন্ট করা হয়, যেগুলো স্বয়ংক্রিয়ভাবে সেট করা হয়। এ কারণে স্ট্রিং তুলনার চেয়ে অ্যাটম তুলনা করা দ্রুততর। এই অভ্যন্তরীণ মানটি বদলানো সম্ভব নয়। ব্যবহারকারীর দেওয়া ইনপুট থেকে ডাইনামিকভাবে অ্যাটম তৈরি করাকে সাধারণত একটি [অ্যান্টি-প্যাটার্ন][anti-pattern] হিসেবে ধরা হয়। রানটাইমে সীমিত সংখ্যক অ্যাটমের জন্যই জায়গা থাকে, তাই অ্যাটম টেবিল ভরে গেলে রানটাইমে নতুন অ্যাটম তৈরি করা ব্যর্থ হতে পারে।

[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[anti-pattern]: https://en.wikipedia.org/wiki/Anti-pattern
