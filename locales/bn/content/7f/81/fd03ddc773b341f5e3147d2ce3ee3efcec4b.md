# মেথড সিনট্যাক্স

Cairo-তে মেথডগুলো ফাংশনের মতোই, তবে ট্রেইটের মাধ্যমে এগুলো একটি নির্দিষ্ট টাইপের সাথে যুক্ত থাকে।

এদের প্রথম প্যারামিটার সবসময় `self`, যা সেই ইনস্ট্যান্সকে বোঝায় যার উপর মেথডটি কল করা হয়।

Cairo সরাসরি কোনো টাইপের উপর মেথড ডিফাইন করার সুবিধা না দিলেও, একটি ট্রেইট ডিফাইন করে সেটি ওই টাইপের জন্য ইমপ্লিমেন্ট করলে একই কাজ করা যায়।

ট্রেইট ব্যবহার করে `Rectangle` টাইপে একটি মেথড ডিফাইন করার উদাহরণ দেখুন:

```rust
#[derive(Copy, Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[generate_trait]
impl RectangleImpl of RectangleTrait {
    fn area(self: @Rectangle) -> u64 {
        (*self.width) * (*self.height)
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };
    println!("Area is {}", rect.area());
}
```

উপরের উদাহরণে `area` মেথডটি একটি আয়তক্ষেত্রের ক্ষেত্রফল হিসাব করে।

`#[generate_trait]` অ্যাট্রিবিউট ব্যবহার করলে প্রয়োজনীয় ট্রেইটটি স্বয়ংক্রিয়ভাবে তৈরি হয়ে যায়, যা প্রক্রিয়াটি সহজ করে দেয়।

এতে আপনার কোড আরও পরিচ্ছন্ন হয়, আর একই সাথে নির্দিষ্ট টাইপের সাথে মেথড যুক্ত করার সুবিধাও থাকে।

## অ্যাসোসিয়েটেড ফাংশন

অ্যাসোসিয়েটেড ফাংশনগুলো মেথডের মতোই, তবে এগুলো কোনো টাইপের ইনস্ট্যান্সের উপর কাজ করে না, অর্থাৎ এগুলো প্যারামিটার হিসেবে `self` নেয় না।

এই ফাংশনগুলো প্রায়ই কনস্ট্রাক্টর বা টাইপের সাথে যুক্ত ইউটিলিটি ফাংশন হিসেবে ব্যবহৃত হয়।

```rust
#[generate_trait]
impl RectangleImpl of RectangleTrait {
    fn square(size: u64) -> Rectangle {
        Rectangle { width: size, height: size }
    }
}

fn main() {
    let square = RectangleTrait::square(10);
    println!("Square dimensions: {}x{}", square.width, square.height);
}
```

`Rectangle::square`-এর মতো অ্যাসোসিয়েটেড ফাংশনগুলো `::` সিনট্যাক্স ব্যবহার করে এবং টাইপের নেমস্পেসের অন্তর্গত।

এগুলো আগে থেকে কোনো অবজেক্ট না থাকলেও ইনস্ট্যান্স তৈরি করা বা নিয়ে কাজ করা সহজ করে তোলে।

সংশ্লিষ্ট কার্যকারিতা ট্রেইট ও ইমপ্লিমেন্টেশনে সাজিয়ে রাখার মাধ্যমে Cairo পরিচ্ছন্ন, মডুলার ও এক্সটেনসিবল কোড স্ট্রাকচার সম্ভব করে তোলে।
