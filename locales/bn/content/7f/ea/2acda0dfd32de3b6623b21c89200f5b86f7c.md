# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার এলাকার আর্কেড হলের সবচেয়ে জনপ্রিয় গেমের হাই স্কোর হিসাব রাখার একটি উপায় তৈরি করছেন।

আপনার ৫টি ফাংশন তৈরি করতে হবে, যার বেশিরভাগই হাই স্কোর ধারণ করা একটি অবজেক্ট নিয়ে কাজ করার সাথে সম্পর্কিত।

## 1. নতুন একটি হাই স্কোর বোর্ড তৈরি করুন

এমন একটি ফাংশন `createScoreBoard` তৈরি করুন যা একটি অবজেক্ট তৈরি করে, যেটি হাই স্কোর বোর্ড হিসেবে কাজ করে।
এই অবজেক্টের কী (key) গুলো হবে প্লেয়ারদের নাম, আর মান হবে তাদের স্কোর।
টেস্ট করার সুবিধার্থে আপনি অবজেক্টটিতে সরাসরি একটি এন্ট্রি রাখতে চান।
এই প্রাথমিক এন্ট্রিতে প্লেয়ারের নাম হিসেবে `The Best Ever` এবং স্কোর হিসেবে `1000000` থাকা উচিত।

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. স্কোর বোর্ডে প্লেয়ার যোগ করুন

হাই স্কোর বোর্ডে একজন প্লেয়ার যোগ করতে `addPlayer` ফাংশনটি ডিফাইন করুন।
এটি ৩টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো একটি বিদ্যমান স্কোর বোর্ড অবজেক্ট।
- দ্বিতীয় প্যারামিটারটি হলো স্ট্রিং হিসেবে একজন প্লেয়ারের নাম।
- তৃতীয় প্যারামিটারটি হলো সংখ্যা হিসেবে স্কোর।

নতুন প্লেয়ারটি যোগ করার পর ফাংশনটি ইনপুট হিসেবে পাওয়া একই স্কোর বোর্ড অবজেক্টটি রিটার্ন করে।

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. স্কোর বোর্ড থেকে প্লেয়ার সরিয়ে ফেলুন

প্লেয়াররা যদি আর্কেড হলের নিয়ম ভঙ্গ করে, তবে তাদের হাতে হাতে হাই স্কোর বোর্ড থেকে সরিয়ে ফেলা হয়।
`removePlayer` ডিফাইন করুন, যা ২টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো একটি বিদ্যমান স্কোর বোর্ড অবজেক্ট।
- দ্বিতীয় প্যারামিটারটি হলো স্ট্রিং হিসেবে প্লেয়ারের নাম।

এই ফাংশনটি বোর্ড থেকে নির্দিষ্ট প্লেয়ারের এন্ট্রিটি সরিয়ে ফেলবে এবং এরপর বোর্ডটি রিটার্ন করবে।
প্লেয়ারটি যদি শুরু থেকেই বোর্ডে না থাকে, তবে বোর্ডে কোনো পরিবর্তন ঘটবে না।
এটিকে অপরিবর্তিত অবস্থায় রিটার্ন করতে হবে।

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. একজন প্লেয়ারের স্কোর বাড়ান

কেউ আর্কেড হলে আরেকটি গেম শেষ করলে বোর্ডে তার আগের স্কোরের সাথে নির্দিষ্ট পরিমাণ পয়েন্ট যোগ হয়।
`updateScore` তৈরি করুন, যা ৩টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো একটি বিদ্যমান স্কোর বোর্ড অবজেক্ট।
- দ্বিতীয় প্যারামিটারটি হলো সেই প্লেয়ারের নাম, যার স্কোর বাড়ানো উচিত।
- তৃতীয় প্যারামিটারটি হলো সেই স্কোর, যা আপনি সংরক্ষিত হাই স্কোরের সাথে **যোগ** করতে চান।

আপডেট শেষ হলে ফাংশনটি স্কোর বোর্ডটি রিটার্ন করবে।

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. সোমবারের বোনাস পয়েন্ট প্রয়োগ করুন

আর্কেড হল সোমবারে আলাদা একটি স্কোর বোর্ড রাখে।
দিনের শেষে ওই বোর্ডের প্রত্যেক প্লেয়ার ১০০ অতিরিক্ত পয়েন্ট পায়।

এমন একটি ফাংশন `applyMondayBonus` তৈরি করুন যা একটি স্কোর বোর্ড গ্রহণ করে।
ফাংশনটি ওই বোর্ডে থাকা প্রত্যেক প্লেয়ারের জন্য বোনাস পয়েন্ট যোগ করে।
এরপর বোর্ডটি রিটার্ন করা হয়।

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
