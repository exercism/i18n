# টেস্ট

## টেস্ট চালানো

টেস্ট চালানোর জন্য, নিচের কমান্ডটি চালান:

```bash
dotnet test
```

## অনুশীলনী সমাধান

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো। ডিফল্টভাবে, আপনি টেস্ট চালালে শুধু একটি টেস্ট (প্রথমটি) চালানো হয়। এটি ইচ্ছাকৃত, কারণ এতে আপনি শুধু ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন। এটি পাস হলে, আপনি টেস্টের `[<Fact>]` বা `[<Theory>]` অ্যাট্রিবিউট থেকে `Skip = "Remove this Skip property to run this test"` সরিয়ে পরের টেস্টটি চালু করতে পারেন। সব টেস্ট চালু হয়ে গেলে এবং আপনার ইমপ্লিমেন্টেশন সেগুলোকে সব পাস করালে, আপনি অনুশীলনীটি সমাধান করে ফেলবেন!

শুরু করার জন্য, প্রতিটি অনুশীলনীর সাথে একটি স্টাব ইমপ্লিমেন্টেশন ফাইল দেওয়া থাকে। আপনি এই ফাইলটি আপনার সমাধান তৈরির সূচনা বিন্দু হিসেবে ব্যবহার করতে পারেন। এটি করা ঠিক মনে হলে আপনি নির্দ্বিধায় এই ফাইলটি মুছে ফেলতে বা বদলে দিতে পারেন।

## প্যাকেজ ব্যবহার

আপনি কোনো এক্সটার্নাল প্যাকেজ ব্যবহার না করেই বেশিরভাগ অনুশীলনী সমাধান করতে পারবেন। তবে, যে অনুশীলনীগুলোতে আপনি সত্যিই একটি এক্সটার্নাল প্যাকেজ ব্যবহার করতে চান, সেগুলোর জন্য নিচের কমান্ডটি চালিয়ে আপনার প্রজেক্টে সেটি যোগ করতে পারেন:

```bash
dotnet add package [package-name]
```
