# নির্দেশাবলি

আপনি একটি গবেষণা কেন্দ্রের নিরাপত্তা ডেস্ক চালান। কর্মীরা এমন *ব্যাজ* বহন করেন যার কোডগুলো একটি কঠোর ফরম্যাট মেনে চলে; অ্যাক্সেস লগে সাধারণ লেখার ভেতরে মিশে থাকা সেই কোডে ভরপুর, আর লগটি শেয়ার করার আগে তা পরিষ্কার করে নিতে হয়। এই প্রতিটি কাজের জন্যই উপযুক্ত টুল হলো রেগুলার এক্সপ্রেশন।

একটি বৈধ ব্যাজ কোড হলো **দুটি বড় হাতের অক্ষর, একটি ড্যাশ, তারপর চারটি ডিজিট**, উদাহরণস্বরূপ `NS-1024`।

## 1. ব্যাজ কোড যাচাই করুন

`valid-badge?` ডিফাইন করুন; এটি একটি ব্যাজ স্ট্রিং নেয় এবং *সম্পূর্ণ* স্ট্রিংটি বৈধ ব্যাজ কোড হলে `t`, নাহলে `f` রিটার্ন করে।

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. লগের একটি লাইন থেকে প্রতিটি কোড বের করুন

`badge-codes` ডিফাইন করুন; এটি অ্যাক্সেস লগের একটি লাইন নেয় এবং তাতে থাকা সব ব্যাজ কোড ক্রমানুসারে একটি সিকোয়েন্স আকারে রিটার্ন করে।

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. একটি কোডে ডিজিট গুনুন

`digit-count` ডিফাইন করুন; এটি একটি স্ট্রিং নেয় এবং এতে কতগুলো ডিজিট আছে তা রিটার্ন করে।

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. পাসওয়ার্ড মুছে ফেলুন

লগের লাইনে কখনও কখনও পাসওয়ার্ড লেখা থাকে `pass=` দিয়ে শুরু করে তারপর গোপন অংশটি (স্পেস ছাড়া একটানা যেকোনো ক্যারেক্টার)। `redact` ডিফাইন করুন; এটি একটি লাইন নেয় এবং এমন প্রতিটি পাসওয়ার্ডের বদলে `pass=****` বসিয়ে সেটি রিটার্ন করে।

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
