# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।
এখানে চারটি কাজ আছে, সবই লাসাগনাটি রান্না করতে যে সময় লাগে তার সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে ডিফাইন করুন

`expectedMinutesInOven` কনস্ট্যান্টটি ডিফাইন করুন, যেটি সংরক্ষণ করে লাসাগনাটি কত মিনিট ধরে ওভেনে থাকা উচিত।
রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. ওভেনে বাকি সময় মিনিটে হিসাব করুন

`remainingMinutesInOven(elapsedMinutes:)` ফাংশনটি ডিফাইন করুন, যেটি `elapsedMinutes` আর্গুমেন্টটি নেয় এবং যেটি ধরে রাখে লাসাগনাটি ইতিমধ্যে কত মিনিট ধরে ওভেনে আছে।
আগের কাজে পাওয়া ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে ফাংশনটি রিটার্ন করবে লাসাগনাটিকে আর কত মিনিট ওভেনে থাকতে হবে।

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTimeInMinutes(layers:)` ফাংশনটি ডিফাইন করুন, যেটি `layers` আর্গুমেন্টটি নেয় এবং যেটি ধরে রাখে লাসাগনায় আপনি কতগুলো লেয়ার যোগ করেছেন।
প্রতিটি লেয়ার প্রস্তুত করতে আপনার ২ মিনিট লাগে ধরে নিয়ে, ফাংশনটি রিটার্ন করবে লাসাগনাটি প্রস্তুত করতে আপনার কত মিনিট লেগেছে।

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`totalTimeInMinutes(layers:elapsedMinutes:)` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: `layers` প্যারামিটারটি হলো লাসাগনায় আপনি যতগুলো লেয়ার যোগ করেছেন তার সংখ্যা, আর `elapsedMinutes` প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে আছে তার সংখ্যা।
ফাংশনটি রিটার্ন করবে লাসাগনাটি রান্না করতে আপনি মোট কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
