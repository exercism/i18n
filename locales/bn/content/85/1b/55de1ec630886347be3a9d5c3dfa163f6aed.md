# ভূমিকা

## ফাংশন টাইপ

Swift ফাংশন সিগনেচার থেকে সব নাম ও লেবেল সরিয়ে ফেললে শুধু ফাংশনের টাইপটি থেকে যায়।

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

লক্ষ্য করুন, প্রথম দুটি ফাংশনের টাইপ একই, `(String, Int) -> String`, যদিও দুটি সিগনেচার আলাদা এবং দুটি ফাংশন খুব ভিন্নভাবে কাজ করে। দুটোই ইনপুট হিসেবে একটি `String` আর একটি `Int` নেয় এবং একটি `String` রিটার্ন করে। আর তৃতীয় ফাংশনের টাইপ দেখেই বোঝা যায়, যদিও ফাংশন বডি আপাতদৃষ্টিতে কিছু রিটার্ন করে না, কিন্তু আসলে এটি অন্তর্নিহিতভাবে `()` রিটার্ন করে, যা `Void` টাইপের একমাত্র মান।

এই ফাংশন টাইপগুলো Swift-এর অন্য যেকোনো টাইপের মতোই ব্যবহার করা যায়; যেমন, ভ্যারিয়েবল বা কনস্ট্যান্ট ঘোষণায় এগুলো ব্যবহার করা যায়। আর Swift-এ যেহেতু ফাংশনও মান, তাই আগে থেকে থাকা ফাংশনগুলো এই কনস্ট্যান্ট/ভ্যারিয়েবলগুলোতে অ্যাসাইন করা যায়:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

অন্য ভ্যারিয়েবল/কনস্ট্যান্টের মতোই, এতে আপনি যে মানটি অ্যাসাইন করবেন সেটি অবশ্যই সঠিক টাইপের হতে হবে:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## প্যারামিটার টাইপ হিসেবে ফাংশন টাইপ

যেহেতু অন্য টাইপ যেখানে যেখানে ব্যবহার করা যায় সেখানে ফাংশন টাইপও ব্যবহার করা যায়, তাই এগুলো প্যারামিটার টাইপ হিসেবেও ব্যবহার করা যায় এবং অন্য ফাংশনে পাস করা যায় ও সেই ফাংশনের ভেতর থেকে কল করা যায়।

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## রিটার্ন টাইপ হিসেবে ফাংশন টাইপ

একইভাবে, ফাংশনের রিটার্ন টাইপ হিসেবেও ফাংশন টাইপ ব্যবহার করা যায়। অর্থাৎ, এমন ফাংশন লেখা যায় যেগুলো অন্য ফাংশন তৈরি করে এবং রিটার্ন করে। এসব ফাংশন তৈরি করার সময়, যে ফাংশনটি রিটার্ন করা হয় সেটি প্যারেন্ট ফাংশনে পাস করা অন্য প্যারামিটারগুলো বা প্যারেন্ট ফাংশনের ভেতরে তৈরি করা লোকাল ভ্যারিয়েবলগুলো ব্যবহার করতে পারে।

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
