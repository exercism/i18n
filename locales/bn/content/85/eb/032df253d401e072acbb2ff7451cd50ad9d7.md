# ভূমিকা

Python ট্রু ও ফলস মান প্রকাশ করতে [`bool`][bools] টাইপ ব্যবহার করে, যেটি `int` টাইপের একটি সাবক্লাস। এই টাইপের আওতায় মাত্র দুটি মান আছে: `True` এবং `False`। এই মানগুলো একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়:

```python
>>> true_variable = True
>>> false_variable = False
```

আমরা `and`, `or` ও `not` অপারেটর ব্যবহার করে বুলিয়ান এক্সপ্রেশন মূল্যায়ন করতে পারি।

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
