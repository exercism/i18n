# নির্দেশনার সংযোজন

## ইঙ্গিত

ইউনিট টেস্টে শব্দের উদাহরণ দেওয়া আছে। ইউনিট টেস্টে ব্যঞ্জনবর্ণের যে নির্দিষ্ট সংমিশ্রণগুলি রয়েছে সেগুলি নির্বিশেষে ব্যঞ্জনবর্ণগুলি ক্লাস্টার করার চেষ্টা করে দেখুন।

এই অনুশীলনীটি টেক্সট ডেটা নিয়ে কাজ করে। ঐতিহাসিক কারণে Haskell-এর `String` টাইপটি `[Char]`-এর সমার্থক, অর্থাৎ ক্যারেক্টারের একটি অ্যারে। টেক্সট ডেটা আরও দক্ষভাবে নিয়ে কাজ করার জন্য `Text` টাইপটি ব্যবহার করা যায়।

এই অনুশীলনীর একটি ঐচ্ছিক এক্সটেনশন হিসেবে আপনি করতে পারেন

- Haskell-এ [স্ট্রিং টাইপ](https://haskell-lang.org/tutorial/string-types) সম্পর্কে পড়ুন।
- package.yaml-এ আপনার ডিপেন্ডেন্সির তালিকায় `- text` যোগ করুন।
- [নিম্নলিখিত উপায়ে](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c) `Data.Text` ইমপোর্ট করুন:

      import qualified Data.Text as T
      import           Data.Text (Text)

- এখন আপনি উদাহরণস্বরূপ `translate :: Text -> Text` লিখতে পারেন এবং `Data.Text`-এর কম্বিনেটরগুলিকে `T.isSuffixOf` ইত্যাদি নামে উল্লেখ করতে পারেন।
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)-এর ডকুমেন্টেশন দেখে নিন,

এই অংশটি সম্পূর্ণ ঐচ্ছিক।
