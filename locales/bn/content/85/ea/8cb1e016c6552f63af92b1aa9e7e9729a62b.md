# নির্দেশাবলি

লেসলি দ্য লিস্প অ্যালিয়েন তাদের গোলকধাঁধা-রোবট প্রোগ্রাম করছেন (যেমনটা অল্পবয়সী লিস্প অ্যালিয়েনদের অভ্যাস) এবং কিছু সাহায্য প্রয়োজন। গোলকধাঁধাটি ধারাবাহিক কিছু ঘর নিয়ে গঠিত। প্রতিটি ঘরে কয়েকটি দরজার মধ্যে থেকে বেছে নেওয়ার সুযোগ থাকে। প্রতিটি দরজার জন্য একটি চাবি দরকার। দরজায় ভুল চাবি ব্যবহার করলে দরজাটি ফেটে যাওয়ার সম্ভাবনা থাকে (রোবটের জন্য চিন্তার কিছু নেই, কোনো ক্ষতি হবে না, তবে পোড়া দাগ ঘষে তুলে ফেলা লেসলির জন্য বেশ বিরক্তিকর)। রোবটের কাছে যদি এমন কোনো চাবি না থাকে যা দিয়ে কোনো দরজা খোলা যায়, তাহলে পুরো ঘরটাই ফেটে যাবে! (আবারও, চিন্তার কিছু নেই, ক্ষতি হবে না, তবে পরিষ্কার করা ঝামেলার হবে।)

লেসলিকে যা সাহায্য করতে হবে তা হলো প্রতিটি ঘরের জন্য রোবটকে সঠিক চাবি দেওয়া। রোবট ঘরের প্রতিটি দরজায় ক্রমানুসারে চাবি ব্যবহার করবে এবং যে দরজাটি প্রথমে খুলবে সেটি দিয়েই বেরিয়ে যাবে।

প্রতিটি টেস্ট একটি গোলকধাঁধা এবং প্রতিটি অ্যাসারশন একটি ঘর। আপনাকে প্রেডিকেট ফাংশন লিখতে হবে, যেগুলো আর্গুমেন্ট সমান হলে `T` এবং সমান না হলে `NIL` রিটার্ন করবে।

## 1. অবজেক্ট সমতার গোলকধাঁধা

এই গোলকধাঁধায় মাত্র একটি ঘর আছে। আপনাকে এমন একটি ফাংশন দিতে হবে যা বলতে পারবে দুটি অবজেক্ট একই অবজেক্ট কি না।

উদাহরণস্বরূপ:

```lisp
a                         ; => "pizza"
b                         ; => "pizza"

(key-object-identity a a) ; => T
(key-object-identity a b) ; => NIL
```

কারণ `a` এবং `b` একই বলে মনে হলেও তারা একই অবজেক্ট নয়।

## 2. সংখ্যার গোলকধাঁধা

এই গোলকধাঁধায় দুটি ঘর আছে। প্রথমটির একটি দরজা খোলা যাবে যদি আপনার চাবি বলতে পারে দুটি সংখ্যা কঠোরভাবে সমান কি না। দ্বিতীয় ঘরের জন্য এমন চাবি দরকার যা সংখ্যার সমতা যাচাইয়ে কিছুটা নমনীয়তা দেয়।

উদাহরণস্বরূপ:

```lisp
a                                    ; => 13
b                                    ; => 13.0
c                                    ; => 13

(key-numbers a b)                    ; => NIL
(key-numbers a c)                    ; => T
(key-numbers-of-different-types a b) ; => T
```

কারণ `a` এবং `b` সংখ্যাগতভাবে একই হলেও তাদের টাইপ আলাদা।

## 3. ক্যারেক্টারের গোলকধাঁধা

এই গোলকধাঁধায় দুটি ঘর আছে। প্রথমটির একটি দরজা খোলা যাবে যদি আপনার চাবি বলতে পারে দুটি ক্যারেক্টার কঠোরভাবে সমান কি না। দ্বিতীয় ঘরের জন্য এমন চাবি দরকার যা ক্যারেক্টারগুলোর কেস-ইনসেনসিটিভ তুলনা করতে দেয়।

উদাহরণস্বরূপ:

```lisp
a                                       ; => #\X
b                                       ; => #\x
c                                       ; => #\X

(key-characters a b)                    ; => NIL
(key-characters a c)                    ; => T
(key-characters-case-insensitively a b) ; => T
```

কারণ দুটি ক্যারেক্টার তুলনা করার সময় শুধুমাত্র খুব নমনীয় সমতা-প্রেডিকেটগুলোই কেস উপেক্ষা করে।

## 4. স্ট্রিংয়ের গোলকধাঁধা

ক্যারেক্টারের গোলকধাঁধার মতো প্রথম ঘরের জন্য এমন চাবি দরকার যা যাচাই করে দুটি স্ট্রিং সমান কি না; দ্বিতীয় ঘরের জন্য দরকার এমন চাবি যা কেস-ইনসেনসিটিভ তুলনা করতে দেয়।

উদাহরণস্বরূপ:

```lisp
a                                    ; => "pizza"
b                                    ; => "PIZZA"
c                                    ; => "pizza"

(key-strings a b)                    ; => NIL
(key-strings a c)                    ; => T
(key-strings-case-insensitively a b) ; => T
```

কারণ দুটি স্ট্রিং তুলনা করার সময় শুধুমাত্র খুব নমনীয় সমতা-প্রেডিকেটগুলোই কেস উপেক্ষা করে।

## 5. কনসের গোলকধাঁধা

এটি অনেক ঘরওয়ালা একটি বড় গোলকধাঁধা। প্রতিটি ঘরের জন্য এমন চাবি দরকার যা যাচাই করবে যে কনসগুলো যে জিনিসগুলো _ধারণ_ করছে সেগুলো সমান কি না। প্রতিটি ঘর ভিন্ন ভিন্ন কনটেন্টের কনসের সমতা যাচাই করবে: সিম্বল, সংখ্যা, ক্যারেক্টার, আর কিছু ক্ষেত্রে ওই কনটেন্টগুলোর জন্য আরও নমনীয় সমতার সংজ্ঞা লাগবে।

উদাহরণস্বরূপ:

```lisp
syms-a                                     ; => (left . right)
syms-b                                     ; => (up . down)
syms-c                                     ; => (left . right)
chars-a                                    ; => (#\x . #\y)
chars-b                                    ; => (#\x . #\Y)
chars-c                                    ; => (#\x . #\y)
nums-a                                     ; => (13 . 23)
nums-b                                     ; => (13 . 23.0)
nums-c                                     ; => (13 . 23)


(key-conses-of-symbols syms-a syms-b)      ; => NIL
(key-conses-of-symbols syms-a syms-c)      ; => T

(key-conses-of-characters chars-a chars-b) ; => NIL
(key-conses-of-characters chars-a chars-c) ; => T
(key-conses-of-characters-case-insensitively 
  chars-a chars-b)                         ; => T

(key-conses-of-numbers nums-a nums-b)      ; => NIL
(key-conses-of-numbers nums-a nums-c)      ; => T
(key-conses-of-numbers-of-different-types 
  nums-a nums-b)                           ; => T
```

কারণ কনসের ভেতরে তাকায় এমন একটি সমতা-প্রেডিকেট থাকলেও, তুলনা করার সময় কেস বা সংখ্যার টাইপ উপেক্ষা করার জন্য সেটি যথেষ্ট নমনীয় নাও হতে পারে।

## 6. অ্যারের গোলকধাঁধা

এই গোলকধাঁধাটি সহজ, এতে মাত্র দুটি ঘর আছে।
প্রথমটির জন্য এমন চাবি দরকার যা যাচাই করে অ্যারেগুলো একই অ্যারে কি না।
দ্বিতীয়টির জন্য এমন চাবি দরকার যা অ্যারেগুলোর কনটেন্ট যাচাই করবে।

উদাহরণস্বরূপ:

```lisp
a                        ; => #[13 23]
b                        ; => #[13 23]
c                        ; => #[13 23.0]

(key-arrays a b)         ; => NIL
(key-arrays a c)         ; => NIL
(key-arrays-loosely a b) ; => T
(key-arrays-loosely a c) ; => T
```

কারণ শুধুমাত্র খুব নমনীয় সমতা-যাচাইকারীরাই অ্যারের কনটেন্ট সমান কি না তা যাচাই করে।
