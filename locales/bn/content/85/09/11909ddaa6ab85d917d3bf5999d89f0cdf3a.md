# সম্পর্কে

চারলিস্ট তৈরি করা হয় `~c` সিগিল ব্যবহার করে।

```elixir
~c"hello"
```

~~~~exercism/note
মনে রাখবেন, Elixir-এর পুরোনো ভার্সনে চারলিস্টকে একক উদ্ধৃতি চিহ্নসহ `'hello'` হিসেবে দেখানো হতো।
~~~~

একটি চারলিস্ট হলো ইন্টিজারগুলোর একটি অ্যারে। ইন্টিজারগুলো একটি নির্দিষ্ট ক্যারেক্টারের ইউনিকোড মান নির্দেশ করে, যাকে কোড পয়েন্টও বলা হয়।

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## চারলিস্ট _আসলে_ অ্যারে

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

যেহেতু চারলিস্ট অ্যারে, তাই অন্য যেকোনো অ্যারের মতোই এগুলো নিয়ে কাজ করতে পারেন: রিকার্সন ও প্যাটার্ন ম্যাচিং ব্যবহার করে, অথবা [`List`][list] মডিউল ব্যবহার করে।

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

[`++`][kernel-concat-list] ব্যবহার করে দুটি অ্যারে একসাথে জোড়া লাগাতে পারেন।

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

প্রথম অ্যারে যত লম্বা হয়, জোড়া লাগানো তত ধীর হয়, তাই যেকোনো দৈর্ঘ্যের অ্যারেতে বারবার অ্যাপেন্ড করা এড়িয়ে চলুন।

## প্রিন্টযোগ্যতা

কোনো ইন্টিজারের অ্যারেতে যদি শুধু প্রিন্টযোগ্য ক্যারেক্টারের কোড পয়েন্ট থাকে, তাহলে সেটি চারলিস্ট হিসেবে দেখানো হয়। এমনকি যদি সেটি `[]` সিনট্যাক্স দিয়ে বানানো হয়ে থাকে।

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

কোনো ইন্টিজারের অ্যারেতে যদি প্রিন্টযোগ্য নয় এমন ক্যারেক্টারের (যেমন `0-6`, `14-26`, `28-31`) একটিমাত্র কোড পয়েন্টও থাকে, তাহলে সেটি অ্যারে হিসেবে দেখানো হয়। এমনকি যদি সেটি `~c""` সিনট্যাক্স দিয়ে বানানো হয়ে থাকে।

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

[`List.ascii_printable?`][list-ascii-printable] দিয়ে প্রিন্টযোগ্যতা যাচাই করা যায়।

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

মনে রাখবেন, এগুলো একই ডেটা _দেখানোর_ দুটি ভিন্ন উপায়। মানগুলো কিন্তু সম্পূর্ণ সমান।

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

[`IO.inspect`][io-inspect] দিয়ে কোনো অ্যারে প্রিন্ট করার সময় [`:charlists`][inspect-opts] অপশন ব্যবহার করে নিয়ন্ত্রণ করতে পারেন অ্যারেগুলো কীভাবে প্রিন্ট হবে।

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## কোড পয়েন্ট

কোনো ক্যারেক্টারের আগে `?` বসিয়ে তার কোড পয়েন্ট পাওয়া যায়।

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## চারলিস্ট বনাম স্ট্রিং

একই ক্যারেক্টার নিয়ে গঠিত চারলিস্ট আর স্ট্রিং সমান বলে গণ্য হয় না।

```elixir
~c"hello" == "hello"
false
```

চারলিস্টের প্রতিটি মান হলো [একটি ক্যারেক্টারের ইউনিকোড কোড পয়েন্ট][unicode-table], অন্যদিকে স্ট্রিংয়ে কোড পয়েন্টগুলো [UTF-8][utf8] হিসেবে এনকোড করা হয়।

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

লক্ষ্য করুন, `ü` (কোড পয়েন্ট `252`) UTF-8-এ `195` আর `188` হিসেবে এনকোড করা হয়েছে।

**বাস্তবে চারলিস্ট খুব কমই ব্যবহার করা হয়**। এর মূল ব্যবহার হলো Erlang-এর সাথে ইন্টারফেস করা, বিশেষ করে যখন এমন পুরোনো লাইব্রেরি ব্যবহার করা হয় যেগুলো আর্গুমেন্ট হিসেবে বাইনারি গ্রহণ করে না।

Elixir নিয়ে কাজ করার সময় **টেক্সট সংরক্ষণ করতে স্ট্রিং ব্যবহার করুন**। `String` মডিউলে টেক্সট প্রসেস করার জন্য অনেক ফাংশন আছে, যে ফাংশনগুলো চারলিস্টের জন্য নেই।

[`to_string`][kernel-to-string] দিয়ে চারলিস্টকে স্ট্রিংয়ে রূপান্তর করা যায়।

```elixir
to_string(~c"hello")
# => "hello"
```
