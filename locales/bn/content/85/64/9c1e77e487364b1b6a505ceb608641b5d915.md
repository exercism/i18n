# নির্দেশনা

এই অনুশীলনীতে আপনি এমন কোড লিখবেন যা একজন ফ্রিল্যান্সারকে নির্দিষ্ট কিছু প্রকল্পের দাম নিয়ে তার ক্লায়েন্টদের সাথে যোগাযোগ করতে সাহায্য করবে।
ক্লায়েন্টদের খরচ দ্রুত হিসাব করার জন্য আপনি কয়েকটি ইউটিলিটি ফাংশন লিখবেন।

```exercism/note
`ratePerHour` ভ্যারিয়েবল আর `dayRate` ফাংশন দুটোই টাকার সাথে সম্পর্কিত।
পরিমাপের একক হলো প্রতি একক সময়ের জন্য টাকা: যথাক্রমে ঘণ্টা আর দিন।
```

## 1. ঘণ্টাপ্রতি হার দিলে দৈনিক হার হিসাব করুন

একজন ক্লায়েন্ট ফ্রিল্যান্সারের সাথে যোগাযোগ করে তার হার সম্পর্কে জানতে চায়।
ফ্রিল্যান্সার ব্যাখ্যা করেন যে **_তিনি দিনে ৮ ঘণ্টা কাজ করেন।_**
তবে প্রকল্পের জন্য তার শুধু ঘণ্টাপ্রতি হারটিই জানা।
ঘণ্টাপ্রতি হার জানা থাকলে দৈনিক হার হিসাব করতে তাকে সাহায্য করুন।

```javascript
dayRate(89);
// => 712
```

দৈনিক হার রাউন্ড করতে বা "fixed" নির্ভুলতায় বদলানোর দরকার নেই।

## 2. নির্দিষ্ট বাজেট দিলে কত কর্মদিবস তা হিসাব করুন

অন্য একদিন একজন প্রজেক্ট ম্যানেজার ফ্রিল্যান্সারকে নির্দিষ্ট বাজেটের একটি প্রকল্পে কাজ করার প্রস্তাব দেন।
নির্দিষ্ট বাজেট আর ফ্রিল্যান্সারের ঘণ্টাপ্রতি হার জানা থাকলে, বাজেট শেষ হওয়ার আগে তিনি কত দিন কাজ করবেন তা হিসাব করতে তাকে সাহায্য করুন।
ফলাফলটি _অবশ্যই_ নিকটতম পূর্ণ সংখ্যায় **নিচের দিকে রাউন্ড** করতে হবে।

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. বড় প্রকল্পের জন্য ছাড়যুক্ত হার হিসাব করুন

প্রায়ই ফ্রিল্যান্সারের ক্লায়েন্টরা কয়েক মাস জুড়ে চলা প্রকল্পে কাজের জন্য তাকে ভাড়া করেন।
এসব ক্ষেত্রে ফ্রিল্যান্সার প্রতি পূর্ণ মাসের জন্য ছাড় দেওয়ার সিদ্ধান্ত নেন, আর বাকি দিনগুলোর বিল দৈনিক হারে হয়।
আপনার দারুণ ওয়ার্ক-লাইফ ব্যালান্সের কারণে আপনি প্রতি ক্যালেন্ডার মাসে মাত্র ২২ দিন কাজ করেন, তাই **_প্রতিটি মাসেই ২২টি বিলযোগ্য দিন থাকে।_**
ঘণ্টাপ্রতি হার, প্রকল্পে থাকা বিলযোগ্য দিনের সংখ্যা আর মাসিক ছাড়ের হার জানা থাকলে, এমন প্রকল্পে তার আনুমানিক খরচ হিসাব করতে তাকে সাহায্য করুন।
ছাড়টি সবসময় একটি সংখ্যা হিসেবে পাঠানো হয়, যেখানে `42%` হয়ে যায় `0.42`।
ফলাফলটি _অবশ্যই_ নিকটতম পূর্ণ সংখ্যায় **উপরের দিকে রাউন্ড** করতে হবে।

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
