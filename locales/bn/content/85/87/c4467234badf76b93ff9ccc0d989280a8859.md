# পরিচিতি

*ডিসপোজেবল* হলো এমন যেকোনো কিছু, যা একটি OS রিসোর্স ধরে রাখে, যেমন একটি খোলা ফাইল, একটি সকেট বা একটি হ্যাশ টেবিল-ভিত্তিক লক, এবং তা নিয়ে কাজ শেষ হলে সেটি মুক্ত করতে হয়। Factor-এর [`destructors`][destructors] vocab এগুলোকে একটি ছোট ফ্রেমওয়ার্কে মুড়ে দেয়, যাতে কোনো এক্সেপশন স্ট্যাকের মধ্য দিয়ে বেরিয়ে গেলেও ক্লিনআপ হয়ে যায়।

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` রিসোর্সটির সাথে কোটেশনটি চালায় এবং বেরিয়ে যাওয়ার সময় সেটি ডিসপোজ করে দেয়। একাধিক রিসোর্সের ক্ষেত্রে `with-destructors` দিয়ে একটি স্কোপ খুলুন এবং প্রতিটিকে `&dispose` (সাধারণভাবে বেরিয়ে গেলে *এবং* এরর হলেও ডিসপোজ করে) বা `|dispose` (শুধু এরর হলে ডিসপোজ করে) দিয়ে নিবন্ধন করুন।

একটি ক্লাস `disposable` এক্সটেন্ড করে এবং `dispose*` জেনেরিকটি ইমপ্লিমেন্ট করে এই ফ্রেমওয়ার্কে যুক্ত হয়। ফ্রেমওয়ার্কটি প্রতি অবজেক্টে এটি একবারই, তার বেশি নয়, কল করে। কলাররা যে পাবলিক ওয়ার্ডটি ব্যবহার করে তা হলো `dispose`।
