# সম্পর্কে

.NET-এর বেস ক্লাস লাইব্রেরিগুলো রেগুলার এক্সপ্রেশন প্রসেস করার জন্য [`Regex`][regex] ক্লাসটি প্রদান করে।

রেগুলার এক্সপ্রেশনের অন্যান্য রূপের সাথে C#-এর তুলনা দেখতে এই [আর্টিকেল][regex-comparison] দেখুন।

## ক্যাপচার গ্রুপ

একটি দিক বিবেচনা করা দরকার, তা হলো ক্যাপচার গ্রুপ, যেগুলো রিজেক্স প্যাটার্নের বিভিন্ন অংশের সাথে মিলে যাওয়া টেক্সটের অংশগুলো ফেরত দেয়। ক্যাপচার গ্রুপের এই পদ্ধতির সাথে অভ্যস্ত হতে হয়। বিস্তারিত জানতে এই [ডকুমেন্টেশন][capture] দেখুন।

লক্ষ্য করুন, যেখানে ক্যাপচার গ্রুপ, `(?<capture-name>pattern)`, জড়িত সেখানে একটি শ্রেণিবিন্যাস আছে:

- যেখানে শূন্য বা তার বেশি ম্যাচের একটি সেট ফেরত দেওয়া হয় (টেক্সটে পাওয়া প্রতিটি ম্যাচের জন্য একটি)।
- প্রতিটি ম্যাচে কয়েকটি ক্যাপচার গ্রুপ থাকে।
- প্রতিটি গ্রুপে কয়েকটি ক্যাপচার থাকে।

এছাড়াও:

- `Match` `Group` থেকে ডিরাইভ করা হয়েছে।
- `Group` `Capture` থেকে ডিরাইভ করা হয়েছে।

সতর্কতা:

- সবচেয়ে নিরাপদ পদ্ধতি হলো নেমড ক্যাপচার ব্যবহার করা।
- ক্যাপচার গ্রুপ সাধারণত `Groups` কালেকশনে টেক্সটে যে ক্রমে দেখা যায় সেই ক্রমেই থাকে।
- `Groups[0]` পুরো ম্যাচের সাথে সম্পর্কিত বলে মনে হয়।
- `Groups[<capture name>].Value` প্রায় নিশ্চিতভাবেই আপনি যা খুঁজছেন সেটিই। পৃথক ক্যাপচারগুলো (`Caputures[0]` ছাড়া) যদি উপস্থিত থাকে, তাহলে সেগুলো ডায়াগনস্টিক উদ্দেশ্যে বোঝানো হয়েছে বলে মনে হয়।

## রিজেক্স অপশন

`RegexOptions`-এর সাথে পরিচিত হয়ে নিন।

সাধারণ `IgnoreCase` অপশনগুলোর পাশাপাশি `MultiLine`-এর জন্যও অপশন আছে, যা একবারে টেক্সটের একাধিক লাইন প্রসেস করার জন্য উপযোগী, এবং `IgnorePatternWhitespace`, যা ভার্বেটিম স্ট্রিং, স্ট্রিং ইন্টারপোলেশন ও কমেন্টের সাথে মিলিয়ে ব্যবহার করলে এই উদাহরণে দেখানো মতো খুবই এক্সপ্রেসিভ হতে পারে:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

আরেকটি আগ্রহের বিষয় হলো `RegexOptions.Compiled`, যা [কম্পাইলড][regex-compilation] রিজেক্সের জন্য।
