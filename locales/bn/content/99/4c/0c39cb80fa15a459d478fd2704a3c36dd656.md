# ভূমিকা

Python ট্রু ও ফলস মানকে [`bool`][bools] টাইপ দিয়ে প্রকাশ করে, যেটি `int`-এর একটি সাবক্লাস। এই টাইপে মাত্র দুটি মান আছে: `True` এবং `False`। এই মানগুলো একটি ভ্যারিয়েবলে বাইন্ড করা যায়:

```python
>>> true_variable = True
>>> false_variable = False
```

আমরা `and`, `or` এবং `not` অপারেটর ব্যবহার করে বুলিয়ান এক্সপ্রেশন মূল্যায়ন করতে পারি:

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
