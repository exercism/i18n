# অতিরিক্ত নির্দেশনা

## পরামর্শ

*রিটার্ন টাইপ* আছে এমন একটি ফাংশন কেবল ওই *টাইপের* ডেটা এবং `null` রিটার্ন করতে পারে। কিন্তু ফাংশনটি যে কল করে, সে কেবল একটি ডেটা টাইপই আশা করছে।

উদাহরণ:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
এই ফাংশনটি `null` বা আরও ডেটা টাইপও রিটার্ন করতে পারে, সেটি আরও স্পষ্ট করতে `dynamic` ব্যবহার করুন।
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
