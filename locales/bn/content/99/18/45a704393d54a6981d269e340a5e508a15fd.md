# নির্দেশনা

আপনি আপনার ছোট বোনকে তার ইংরেজি ভোকাবুলারির হোমওয়ার্ক করতে সাহায্য করছেন, যেটি তার কাছে খুবই একঘেয়ে লাগছে।
 ওর ক্লাসে _উপসর্গ_ ও _প্রত্যয়_ যোগ করে নতুন শব্দ তৈরি করা শিখছে।
 শব্দের একটি সেট দেওয়া থাকলে, শিক্ষক চান শুরুর দিকে উপসর্গ বা শেষে প্রত্যয় যোগ করে সঠিক বানানে সঠিকভাবে রূপান্তরিত শব্দ।

এই অ্যাসাইনমেন্টে চারটি অ্যাক্টিভিটি আছে, প্রতিটিতে কাজ করার জন্য কিছু টেক্সট বা শব্দ দেওয়া আছে।


## 1. একটি শব্দে উপসর্গ যোগ করুন

ইংরেজিতে সবচেয়ে কমন উপসর্গগুলোর একটি হলো `un`, যার অর্থ "not"।
 এই অ্যাক্টিভিটিতে আপনার বোনকে `un` যোগ করে নেতিবাচক, অর্থাৎ "not" অর্থের শব্দ বানাতে হবে।

`add_prefix_un(<word>)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে `word` নেয় এবং `un` উপসর্গযুক্ত একটি নতুন শব্দ রিটার্ন করে:


```python
>>> add_prefix_un("happy")
'unhappy'

>>> add_prefix_un("manageable")
'unmanageable'
```


## 2. শব্দগুচ্ছে উপসর্গ যোগ করুন

আপনার বোনের ক্লাস আরও চারটি কমন উপসর্গ নিয়ে পড়ছে:
 `en` (_অর্থ 'ভেতরে রাখা' বা 'ঢেকে দেওয়া'_),
 `pre` (_অর্থ 'আগে' বা 'সামনে'_),
 `auto` (_অর্থ 'নিজে' বা 'একই'_),
  আর `inter` (_অর্থ 'মাঝে' বা 'মধ্যে'_);

 এই অনুশীলনীতে ক্লাসটি এই উপসর্গগুলো ব্যবহার করে ভোকাবুলারি শব্দের দল তৈরি করছে, যাতে সেগুলো একসাথে পড়া যায়।
 প্রতিটি উপসর্গ তার সাথে ব্যবহৃত কমন শব্দগুলোর একটি তালিকা নিয়ে আসে।
 শিক্ষার্থীদের সেই উপসর্গটি প্রয়োগ করে একটি স্ট্রিং তৈরি করতে হবে, যা দেখায় উপসর্গটি সব শব্দে প্রয়োগ করা হয়েছে।

`make_word_groups(<vocab_words>)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা নিচের রূপে প্যারামিটার হিসেবে `vocab_words` নেয়:
 `[<prefix>, <word_1>, <word_2> .... <word_n>]`, এবং এমন একটি স্ট্রিং রিটার্ন করে যেখানে প্রতিটি শব্দে উপসর্গটি প্রয়োগ করা থাকে:
  `'<prefix> :: <prefix><word_1> :: <prefix><word_2> :: <prefix><word_n>'`.

ইনপুট প্রসেস করার জন্য এখানে `for` বা `while` লুপ তৈরি করার দরকার নেই।
বদলে কোন স্ট্রিং মেথড (এবং ডেলিমিটার) ব্যবহার করতে পারেন, সেটি ভালো করে ভাবুন।


```python
>>> make_word_groups(['en', 'close', 'joy', 'lighten'])
'en :: enclose :: enjoy :: enlighten'

>>> make_word_groups(['pre', 'serve', 'dispose', 'position'])
'pre :: preserve :: predispose :: preposition'

>> make_word_groups(['auto', 'didactic', 'graph', 'mate'])
'auto :: autodidactic :: autograph :: automate'

>>> make_word_groups(['inter', 'twine', 'connected', 'dependent'])
'inter :: intertwine :: interconnected :: interdependent'
```


## 3. একটি শব্দ থেকে প্রত্যয় সরান

`ness` একটি কমন প্রত্যয়, যার অর্থ _'কোনো কিছু হওয়ার অবস্থা'_।
 এই অ্যাক্টিভিটিতে আপনার বোনকে `ness` প্রত্যয়টি সরিয়ে মূল শব্দটি খুঁজে বের করতে হবে।
  কিন্তু অবশ্যই কিছু বিরক্তিকর বানানের নিয়ম আছে: যদি মূল শব্দটি আসলে একটি ব্যঞ্জনবর্ণের পরে 'y' দিয়ে শেষ হতো, তাহলে সেই 'y' বদলে 'i' হয়ে যেত।
 সেই মূল শব্দগুলোতে 'ness' সরালে 'y' আবার ফিরিয়ে আনতে হবে। যেমন `happiness` --> `happi` --> `happy`।

`remove_suffix_ness(<word>)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে `word` নেয় এবং `ness` প্রত্যয় ছাড়া মূল শব্দটি রিটার্ন করে।


```python
>>> remove_suffix_ness("heaviness")
'heavy'

>>> remove_suffix_ness("sadness")
'sad'
```

## 4. একটি শব্দ বের করে রূপান্তর করুন

একটি শব্দ যে পার্টস অফ স্পিচে পড়ে, তা বদলাতে প্রায়ই প্রত্যয় ব্যবহার করা হয়।
 ইংরেজিতে একটি কমন প্রথা হলো "verbing" বা "verbifying", যেখানে `en` প্রত্যয় যোগ করে একটি বিশেষণ _ক্রিয়ায়_ পরিণত হয়।

এই কাজে আপনার বোন একটি বাক্য থেকে বিশেষণ বের করে সেটিকে ক্রিয়ায় পরিণত করার মাধ্যমে শব্দ "verbing" অনুশীলন করবে।
 সৌভাগ্যক্রমে, এখানে যে শব্দগুলো রূপান্তর করতে হবে সেগুলো সবই "regular", অর্থাৎ প্রত্যয় যোগ করতে বানান বদলানোর দরকার নেই।

`adjective_to_verb(<sentence>, <index>)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি প্যারামিটার নেয়।
 একটি `sentence`, যেখানে ভোকাবুলারির শব্দটি ব্যবহৃত হয়েছে, আর বাক্যটি টুকরো করে ভাগ করার পর শব্দটির `index`।
 ফাংশনটি বের করা বিশেষণটিকে ক্রিয়া হিসেবে রিটার্ন করবে।


```python
>>> adjective_to_verb('I need to make that bright.', -1 )
'brighten'

>>> adjective_to_verb('It got dark as the sun set.', 2)
'darken'
```
