# ভূমিকা

`Promise` ক্লাসটি আসার আগে অ্যাসিনক্রোনাস কোড নিয়ে কাজ করার একটাই উপায় ছিল: _কলব্যাক প্যাটার্ন_।

কলব্যাক হলো এমন একটি ফাংশন, যেটি অন্য একটি ফাংশনে আর্গুমেন্ট হিসেবে পাঠানো হয় এবং ওই অন্য ফাংশনের কোনো একটি কাজ শেষ হয়ে গেলে সেটিকে কল করা হয়। এসব কলব্যাক ফাংশনের একটি কমন রীতি হলো, তারা প্রথম প্যারামিটার হিসেবে একটি "error" নেয় (নিচের উদাহরণটি দেখুন)।

```javascript
function callback(error, arg2, arg3) {}
```

এর সঙ্গে অ্যাসিনক্রোনাস কোডের সম্পর্কটা কী?

ঐতিহাসিকভাবে কলব্যাক ব্যবহার করা হতো যেন কোনো অ্যাসিনক্রোনাস কাজ শেষ হওয়ার পর পুরো প্রোগ্রাম ব্লক না করে আমরা কিছু কাজ করতে পারি।

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

উপরের উদাহরণে `fetchProduct` ফাংশনটি (যেটি অ্যাসিনক্রোনাস) দ্বিতীয় আর্গুমেন্ট হিসেবে একটি কলব্যাক নেয়, আর সেই কলব্যাকই ঠিক করে দেয় প্রোডাক্টের ডেটা এসে গেলে কী করতে হবে।
