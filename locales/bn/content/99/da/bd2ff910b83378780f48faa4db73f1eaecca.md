# Debug

যখন কোনো test ব্যর্থ হয়, তখন কী ভুল হয়েছে এবং কোন ইনপুটের জন্য তা ঘটেছে, তা বর্ণনা করে একটি বার্তা দেখানো হয়। আপনার প্রোগ্রামের যেকোনো মান `debug` মেথডে পাঠিয়ে আপনি সেগুলো পরীক্ষা করে দেখতে পারেন। এটি ওই মানগুলো ধরে রাখবে এবং আপনাকে আউটপুটটি দেখাবে।

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
