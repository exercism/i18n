# নির্দেশনা

দ্রষ্টব্য: এই অনুশীলনীটি `need-for-speed` অনুশীলনীর ধারাবাহিকতা।

এই অনুশীলনীতে আপনি বিভিন্ন ধরনের রিমোট কন্ট্রোলড গাড়ির মধ্যে রেস আয়োজন করবেন।
প্রতিটি গাড়ির নিজস্ব গতি এবং ব্যাটারি ড্রেনের বৈশিষ্ট্য থাকে।

গাড়িগুলো পুরোপুরি (১০০%) চার্জ করা ব্যাটারি নিয়ে শুরু করে।
প্রতিবার যখন আপনি রিমোট কন্ট্রোল দিয়ে গাড়িটি চালান, তখন এটি গাড়ির গতির সমান দূরত্ব মিটারে অতিক্রম করে এবং তার ব্যাটারি ড্রেনের পরিমাণ অনুযায়ী অবশিষ্ট ব্যাটারির শতাংশ কমিয়ে দেয়।

কোনো গাড়ির ব্যাটারি যদি তার ব্যাটারি ড্রেনের শতাংশের নিচে নেমে যায়, তবে আপনি আর গাড়িটি চালাতে পারবেন না।

রিমোট কন্ট্রোলড গাড়িটিতে একটি চমৎকার LED ডিসপ্লে আছে, যেখানে দুই ধরনের তথ্য দেখা যায়:

- এটি এখন পর্যন্ত মোট যে দূরত্ব চালানো হয়েছে, যা এভাবে দেখানো হয়: `"Driven <METERS> meters"`.
- অবশিষ্ট ব্যাটারি চার্জ, যা এভাবে দেখানো হয়: `"Battery at <PERCENTAGE>%"`.

প্রতিটি রেস ট্র্যাকের নিজস্ব দূরত্ব থাকে।
ব্যাটারি শেষ হওয়া ছাড়াই গাড়িগুলো ট্র্যাকটি শেষ করতে পারে কি না, তা দেখে তাদের পরীক্ষা করা হয়।

## 1. গাড়ি চালান

`Car`-এর উপর `Drive` মেথডটি তৈরি করুন, যা গাড়ির গতির ভিত্তিতে চালানো মিটারের সংখ্যা হালনাগাদ করে এবং ব্যাটারি ড্রেন অনুযায়ী ব্যাটারি কমায়:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

দ্রষ্টব্য: গাড়ি চালালে যদি গাড়ির ব্যাটারি 0-এর নিচে নেমে যায়, তবে গাড়িটি চালানোর চেষ্টা করা উচিত নয়।

## 2. চালানো দূরত্ব দেখান

`Car`-এ একটি `DisplayDistance` মেথড তৈরি করুন, যা LED ডিসপ্লেতে যেভাবে দেখানো হয় সেভাবে দূরত্ব একটি `string` হিসেবে রিটার্ন করে:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. ব্যাটারির শতাংশ দেখান

`Car`-এ `DisplayBattery` মেথডটি তৈরি করুন, যা LED ডিসপ্লেতে যেভাবে দেখানো হয় সেভাবে ব্যাটারির শতাংশ একটি `string` হিসেবে রিটার্ন করে:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. একটি রিমোট কন্ট্রোলড গাড়ি রেস শেষ করতে পারে কি না তা যাচাই করুন

একটি রেস শেষ করতে হলে গাড়িটিকে রেসের দূরত্ব চালাতে সক্ষম হতে হবে।
এর মানে হলো ফিনিশ লাইন পার হওয়ার আগেই যেন তার ব্যাটারি শেষ না হয়ে যায়।
`CanFinish` মেথডটি তৈরি করুন, যা প্যারামিটার হিসেবে একটি `trackDistance int` নেয় এবং গাড়িটি রেস শেষ করতে পারলে `true` রিটার্ন করে; অন্যথায় `false` রিটার্ন করে:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
