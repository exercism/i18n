# স্থানীয়ভাবে অনুশীলনী সমাধান করা

আপনার লোকাল মেশিনে অনুশীলনী সমাধান করলে আপনি আপনার পরিচিত একটি পরিবেশে সব কোডিং করতে পারবেন।

## CLI ইনস্টল করা

আপনার লোকাল মেশিনে কোনো অনুশীলনী সমাধান করতে হলে প্রথমে [এই নির্দেশাবলি](https://exercism.org/cli-walkthrough) অনুসরণ করে Exercism Command Line Interface ইনস্টল ও কনফিগার করতে হবে।

### কনফিগারেশন

আমরা যাতে সঠিকভাবে সবকিছু ডাউনলোড করতে পারি, সেজন্য আপনি কে, তা CLI-কে জানাতে হবে।
আপনার টোকেনটি [সেটিংস পেজে](/settings/api_cli) পাবেন।
এরপর সেটিংস পেজে দেওয়া মানটি `<your-api-token>` অংশের জায়গায় বসিয়ে নিচের কমান্ড দিয়ে CLI কনফিগার করতে পারেন:

```
exercism configure --token=<your-api-token>
```

## অনুশীলনী ডাউনলোড করা

ইনস্টল হয়ে গেলে, নিচের কমান্ডটি দিয়ে CLI-এর সাহায্যে অনুশীলনীটি আপনার লোকাল মেশিনে ডাউনলোড করতে পারেন (`<exercise-slug>` ও `<track-slug>` অংশ দুটির জায়গায় প্রাসঙ্গিক মান বসান:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

এই কমান্ডের গঠন আপনার মনে রাখার দরকার নেই, কারণ অনুশীলনীর পেজে সেই অনুশীলনীর জন্য প্রযোজ্য কমান্ডটি দেওয়া থাকে।

ডাউনলোড কমান্ডটি শেষ হলে অনুশীলনীর ফাইলগুলো আপনার লোকাল মেশিনে ডাউনলোড হয়ে যাবে।

## অনুশীলনী সমাধান করা

প্রতিটি অনুশীলনীর লক্ষ্য হলো এমন একটি ইমপ্লিমেন্টেশন তৈরি করা, যা সব টেস্ট পাস করে।
এমন ইমপ্লিমেন্টেশনকেই বলা হয় _সমাধান_।

এতে সাহায্য করার জন্য প্রতিটি অনুশীলনীতে নিচের ফাইলগুলো থাকে:

- README.md: আপনার কাছে কী প্রত্যাশিত, তা ব্যাখ্যা করা নির্দেশাবলি
- HELP.md: টেস্ট কীভাবে চালাবেন এবং আটকে গেলে কীভাবে সাহায্য পাবেন তার তথ্য
- HINTS.md (ঐচ্ছিক): অনুশীলনী সমাধানে সাহায্যকারী ইঙ্গিত
- টেস্ট ফাইল: এতে আপনার সমাধানের সঠিকতা যাচাইকারী টেস্টগুলো থাকে
- স্টাব ফাইল: আপনার ইমপ্লিমেন্টেশন তৈরি শুরু করার জন্য একটি সূচনা বিন্দু এগুলো দেয়

ট্র্যাকভেদে টেস্ট চালানোর জন্য ট্র্যাকের টুলিংয়ের প্রয়োজন হয় এমন আরও ফাইল থাকতে পারে।

## আপনার সমাধান জমা দেওয়া

আপনার সমাধান সব টেস্ট পাস করলে, নিচের কমান্ডটি দিয়ে আপনার সমাধান জমা দিতে পারেন:

```
exercism submit <implementation_file_paths>
```

এই কমান্ডটি আপনার সমাধান Exercism ওয়েবসাইটে আপলোড করবে এবং সমাধান পেজের URL প্রিন্ট করবে।

আবারও বলি, এই কমান্ডটি আপনার মনে রাখার দরকার নেই, কারণ অনুশীলনীর `HELP.md` ফাইলে সঠিক কমান্ডটি দেওয়া থাকবে।

অসম্পূর্ণ সমাধানও জমা দেওয়া সম্ভব, যা দিয়ে আপনি:

- অন্যরা কীভাবে অনুশীলনীটি সম্পন্ন করেছে তা দেখতে পারবেন
- একজন মেন্টরের কাছে সাহায্য চাইতে পারবেন

## CLI-এর অন্যান্য সুবিধা

### সব কমান্ড দেখা

উপলব্ধ সব কমান্ডের পূর্ণ তালিকা পেতে help সাবকমান্ডটি রান করুন।

```bash
exercism help
```

### সমস্যা সমাধান

নিশ্চিত করুন যে আপনি সর্বশেষ ভার্সনে আছেন।

আপনি কোন ভার্সনে আছেন তা যাচাই করুন:

```bash
exercism version
```

সর্বশেষ রিলিজের সাথে মিলিয়ে যাচাই করুন, আর আপনার ভার্সনটি যদি সর্বশেষটি না হয় তাহলে আপগ্রেড করুন।

আপগ্রেড করার পর ভার্সনটি আবার যাচাই করুন। ভার্সন না বদলালে, নিশ্চিত করুন যে আপনি আপগ্রেড করা বাইনারিটিই রান করছেন।

```bash
which exercism
```

তবুও সমস্যা থাকলে troubleshoot কমান্ডের আউটপুটসহ GitHub-এ exercism/cli-তে একটি ইস্যু খুলুন।

```bash
exercism troubleshoot
```

আপনি [আমাদের ইস্যু ট্র্যাকারে](https://github.com/exercism/exercism/issues) ইস্যু খুলতে পারেন, আর কমিউনিটি আপনাকে সাহায্য করার চেষ্টা করবে। **ইস্যু খোলার আগে অনুগ্রহ করে [ইন্টারঅ্যাকটিভ ওয়াকথ্রু](https://exercism.org/cli-walkthrough) সম্পন্ন করেছেন কি না নিশ্চিত করুন।**
