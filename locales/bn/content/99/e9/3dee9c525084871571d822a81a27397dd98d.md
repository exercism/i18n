# নির্দেশনা

একজন জলদস্যু গোপন খাঁড়ির একটি চার্ট ধরে পথের পরিকল্পনা করছে। চার্টটি একটি হ্যাশটেবিল, যার কী (key) হলো খাঁড়ির নাম; প্রতিটি মান হলো একটি অ্যারে, যাতে সেই খাঁড়ি থেকে সরাসরি পৌঁছানো যায় এমন খাঁড়িগুলো থাকে।

## 1. জোয়ারের কিউ খালি করুন

`tide-queue` ডিফাইন করুন যাতে এটি আইটেমের একটি অ্যারে নেয়, ক্রম অনুযায়ী প্রতিটি আইটেম একটি নতুন ডেকে পুশ করে, তারপর সবগুলো পপ করে এমন একটি অ্যারে ফিরিয়ে দেয় যা মূল ক্রম অটুট রাখে। এটাই FIFO-এর রূপ: পিছনে পুশ করুন, সামনে থেকে পপ করুন।

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. পৌঁছানো যায় এমন খাঁড়ি

`coves-reachable` ডিফাইন করুন যাতে এটি একটি শুরুর খাঁড়ি ও একটি চার্ট নেয় এবং `start` থেকে পৌঁছানো যায় এমন প্রতিটি খাঁড়ির একটি হ্যাশ-সেট রিটার্ন করে, `start` নিজেও সহ।

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

BFS ফ্রন্টিয়ার হিসেবে একটি `<dlist>` আর ভিজিটেড সেটের জন্য একটি `HS{ }` ব্যবহার করুন।

## 3. হপের হিসাব

`hop-count` ডিফাইন করুন যাতে এটি একটি শুরুর খাঁড়ি, একটি লক্ষ্য খাঁড়ি ও একটি চার্ট নেয় এবং তাদের মধ্যে সর্বনিম্ন কতগুলো হপ লাগে তা রিটার্ন করে। লক্ষ্যে পৌঁছানো না গেলে রিটার্ন করে `f`।

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

ডেকে প্রতিটি খাঁড়ির সঙ্গে শুরুর খাঁড়ি থেকে তার দূরত্বও বহন করুন (২টি এলিমেন্টের একটি অ্যারে হলেই চলবে)।

## 4. সোনার হিসাব

স্টাবটি `:` দিয়ে `gold-count` ডিক্লেয়ার করে। এটিকে `MEMO:` (আর `:` নয়) করুন, যাতে প্রতিটি খাঁড়ির ফল একবারই হিসাব হয়ে ক্যাশে জমা থাকে। অনুশীলনীটি যে `gold-distribution` কনস্ট্যান্ট দেয়, সেখানে খাঁড়িটির সোনা খুঁজে নিন। যে খাঁড়ি ডিস্ট্রিবিউশনে নেই, তার সোনা শূন্য।

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. গুপ্তধনের পথ

`treasure-route` ডিফাইন করুন যাতে এটি একটি শুরুর খাঁড়ি ও একটি চার্ট নেয় এবং পৌঁছানো যায় এমন খাঁড়িগুলোর মধ্যে যেটিতে সবচেয়ে বেশি সোনা আছে, সেটি রিটার্ন করে। টাস্ক ২-এর `coves-reachable` আর টাস্ক ৪-এর `gold-count` ব্যবহার করুন।

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

মেমোইজড `gold-count` বারবার খোঁজার খরচ শূন্য রাখে, যা তখন কাজে লাগে যখন অ্যালগরিদমের কয়েকটি অংশ একই খাঁড়ি দেখে।
