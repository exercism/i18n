# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | N, ত্রিভুজের বাহুগুলোর যোগফল  |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | a-এর মানগুলো                     |
| `$a2`    | ইনপুট/আউটপুট | অ্যাড্রেস | b-এর মানগুলো                     |
| `$a3`    | ইনপুট/আউটপুট | অ্যাড্রেস | c-এর মানগুলো                     |
| `$v0`    | আউটপুট       | ইন্টিজার | ট্রিপলেটের সংখ্যা           |
| `$t0-9`  | টেম্পোরারি    | যেকোনো     | টেম্পোরারি স্টোরেজের জন্য        |
