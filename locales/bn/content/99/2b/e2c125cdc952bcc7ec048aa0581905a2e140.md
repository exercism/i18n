# ভূমিকা

**ক্লোজার** হলো [Clojure-এ একটি প্রোগ্রামিং প্যাটার্ন][clojure-guide-closures], যা একটি বাইরের [লেক্সিকাল স্কোপ][wiki-lexical-scope] থেকে ভ্যারিয়েবল একটি ফাংশনের ভিতরে ব্যবহার করার সুযোগ দেয়। Clojure স্বচ্ছভাবে ক্লোজার সমর্থন করে, আর সেগুলো কী তা না জেনেই এগুলো প্রায়শই ব্যবহৃত হয়।

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## স্টেট সংরক্ষণ ও মান পাঠানোর ক্লোজার

একটি অ্যাটম ব্যবহার করলে কিছু স্টেট সংরক্ষণ করে রাখা যায়:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

`increment`-কে প্রতিবার কল করলে তার কাউন্টার এক এক করে বেড়ে যায়:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
