# ভূমিকা

লিটারেল হলো এমন নির্দিষ্ট মান, যেগুলো সরাসরি কোডে ব্যবহার করা হয়।
রান-টাইমে এদের কোনো গণনার প্রয়োজন হয় না।
বিভিন্ন ধরনের ডেটা দক্ষভাবে প্রকাশ করতে এরা নানা রূপে আসে।
সবচেয়ে বেশি দেখা যায় সংখ্যাসংক্রান্ত লিটারেল, তবে তারিখ, সময় ও স্ট্রিং টাইপের জন্যও লিটারেল অপারেটর রয়েছে।
পরের একটি কনসেপ্টে দেখানো হবে কীভাবে ব্যবহারকারী-নির্ধারিত লিটারেল অপারেটর ব্যবহার করা যায়।

## সাংখ্যিক লিটারেল

সাংখ্যিক লিটারেলের মধ্যে দশমিক, অক্টাল, হেক্সাডেসিমাল ও বাইনারি রূপ রয়েছে।
এই মৌলিক বিষয়গুলো [সংখ্যার কনসেপ্টে][numbers-concept] আগেই আলোচনা করা হয়েছে।

`23`, `0x50f7ba11` ও `0xba5eba11`-এর মতো সব রূপকেই কম্পাইলার `int` হিসেবে ধরে নেয়।
সাধারণ `int` টাইপটি সাইনড এবং ([কম্পাইলার ও সিস্টেমের উপর নির্ভর করে][in-depth-integers]) এর রেঞ্জ প্রায়শই `-2'147'483'648` থেকে `2'147'483'647` পর্যন্ত হয়।
বেশিরভাগ সময়েই এটি যথেষ্ট, আর নির্দিষ্ট টাইপ নিয়ে আপনার চিন্তা করার দরকার নেই।

কিছু ক্ষেত্রে প্রোগ্রামের বড় রেঞ্জ বা খুব ছোট মেমরি ব্যবহার প্রয়োজন হয়।
স্পষ্টভাবে বলতে চাইলে সাংখ্যিক লিটারেলের সাথে সরাসরি নির্দিষ্ট ইন্টিজার টাইপ উল্লেখ করা যায়।

যখন ঋণাত্মক সংখ্যার দরকার নেই, কেবল বেশি রেঞ্জ দরকার, তখন _আনসাইনড_ ইন্টিজারের জন্য `u` বা `U` সাফিক্স ব্যবহার করা হয়।
আরও বড় রেঞ্জের জন্য long ও long long টাইপে `L` বা এমনকি `LL` ব্যবহার করা যায়।

~~~~exercism/caution
ছোট হাতের `l` ব্যবহার করা অনুমোদিত, তবে সহজেই এটিকে `1` সংখ্যার সাথে গুলিয়ে ফেলা যায়, তাই এটি নিরুৎসাহিত করা হয়।
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

ফ্লোটিং-পয়েন্ট সংখ্যা কম্পাইলের সময় সাধারণত `double` হিসেবে ধরা হয়।
এটি একটি ভালো ডিফল্ট, আর সরু `float` টাইপ নিয়ে কাজের ক্ষেত্র উপরের আনসাইনড উদাহরণের চেয়ে কম দেখা যায়।

~~~~exercism/advanced
[C++23 স্ট্যান্ডার্ড][cpp23-literals] `f128` বা `F16`-এর মতো লিটারেল দিয়ে আরও সূক্ষ্ম নিয়ন্ত্রণ নিয়ে আসে।
কিছু কম্পাইলার নিজস্ব লিটারেল অনুমোদন করে।
GCC একটি লিটারেল হিসেবে `d` ব্যবহারের অনুমতি দেয়, কিন্তু স্ট্যান্ডার্ডে এটির কোনো ব্যবস্থা নেই এবং এটি ক্রস-প্ল্যাটফর্ম সামঞ্জস্যতা ব্যাহত করতে পারে।

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## ক্যারেক্টার ও স্ট্রিং লিটারেল

অন্য কনসেপ্টগুলোতে `'}'` বা `'@'`-এর মতো সিঙ্গল কোট দিয়ে ক্যারেক্টার লিটারেল আগেই ব্যবহার করা হয়েছে।

C++-এ `char` প্রথম 128টি [ascii ক্যারেক্টার কোডে][ascii-code] সীমাবদ্ধ।
একাধিক ascii ক্যারেক্টার, বা `‰`-এর মতো এক্সটেন্ডেড ascii ক্যারেক্টার, এমনকি `麗` ও `ẞ`-এর মতো ইউনিকোড ক্যারেক্টার ব্যবহার করতে হলে অন্য টাইপ দরকার।
আগের কনসেপ্টে _ডাবল কোট_ দিয়ে স্ট্রিং লিটারেল চালু করা হয়েছিল: `"一体どういう意味ですか。C++です"`.
এই জাপানি বাক্যটির প্রকৃত টাইপ `const char (&)[46]`, একটি C-স্টাইল স্ট্রিং।

স্ট্রিং লিটারেলের ব্যবহার ডিফল্টভাবে চালু থাকে না।
_স্ট্রিং_ লিটারেল `""s` বা _স্ট্রিং-ভিউ_ লিটারেল `""sv` ব্যবহার করতে হলে ব্যবহারকারীকে সম্পর্কিত নেমস্পেস ব্যবহার করে তা উল্লেখ করতে হয়:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

একটি _string_view_-কে একটি const স্ট্রিংয়ের রেফারেন্স হিসেবে দেখা যায়।
