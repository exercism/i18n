# Kotlin ইনস্টল করা

exercism CLI এবং আপনার পছন্দের টেক্সট এডিটর ছাড়াও, Exercism-এর Kotlin অনুশীলনীগুলো নিয়ে অনুশীলন করতে যা যা প্রয়োজন:

* **Java Development Kit** (JDK): Kotlin কম্পাইল হয়ে Java বাইটকোডে পরিণত হয়; আপনাকে JDK ইনস্টল করতে হবে, যার মধ্যে Java রানটাইম *এবং* ডেভেলপমেন্ট টুল দুটোই থাকে (বিশেষত Java কম্পাইলার); আর
* **Gradle**: বিশেষভাবে JVM-ভিত্তিক প্রজেক্টের জন্য তৈরি একটি বিল্ড টুল, যা Kotlin সমর্থন করে।

আপনার অপারেটিং সিস্টেম বেছে নিন:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... অথবা ...
* আপনি যদি প্যাকেজ ম্যানেজার ব্যবহার করতে না চান, তাহলে [ম্যানুয়ালি ইনস্টল করতে পারেন](#h-install-manually)।

## Windows

একটি প্রশাসনিক কমান্ড প্রম্পট খুলুন।  (প্রশাসনিক প্রম্পট খোলার জন্য সাহায্যের প্রয়োজন হলে দেখুন [Windows 8+-এ একটি এলিভেটেড প্রম্পট খোলা](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (বা [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/))।

1. আপনি যদি Chocolatey ইনস্টল না করে থাকেন, তাহলে এখনই করে নিন:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  JDK ইনস্টল করুন:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

আমরা প্রশাসনিক কমান্ড প্রম্পটটি বন্ধ করে নতুন একটি কমান্ড প্রম্পট খোলার পরামর্শ দিই। Exercism-এর অনুশীলনী অনুশীলন করতে আপনার প্রশাসকের অনুমতির প্রয়োজন নেই।

এখন আপনি Exercism-এর Kotlin ট্র্যাক শুরু করার জন্য প্রস্তুত!

শুরু করতে দেখুন "[টেস্ট চালানো](https://exercism.org/docs/tracks/kotlin/tests)"।

## macOS

নিচে সবচেয়ে প্রচলিত পদ্ধতিতে, অর্থাৎ Homebrew ব্যবহার করে ইনস্টল করার নির্দেশনা দেওয়া হয়েছে।  আপনি চাইলে [Homebrew ছাড়াও macOS-এ ইনস্টল করতে পারেন](#h-installing-on-macos-without-homebrew)।

### ইনস্টল করা

1. আপনি যদি এখনও [Homebrew](http://brew.sh) ইনস্টল না করে থাকেন, তাহলে এখনই করে নিন:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. [Homebrew Cask](https://caskroom.github.io/) ট্যাপ করুন। এটি আমাদের JDK-এর মতো আগে থেকে বিল্ট করা বাইনারি ইনস্টল করতে দেয়।

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  JDK ইনস্টল করুন:

       ```
        $ brew install --cask adoptopenjdk11
       ```

এখন আপনি Exercism-এর Kotlin ট্র্যাক শুরু করার জন্য প্রস্তুত!

শুরু করতে দেখুন "[টেস্ট চালানো](https://exercism.org/docs/tracks/kotlin/tests)"।

### Debian

আপনি যদি Debian বা তার ডেরিভেটিভ (যেমন Ubuntu বা Linux Mint) ব্যবহার করেন, তাহলে APT ব্যবহার করুন:

*(যাচাই করা হয়েছে: Ubuntu 14, 16 এবং 18)*

1. JDK ইনস্টল করুন:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```

### অন্যান্য Linux ডিস্ট্রিবিউশন

Jdk 11 ইনস্টল করার অনেক উপায় আছে, তবে সবচেয়ে সহজ উপায়গুলোর একটি হলো SDKMAN ব্যবহার করা, 
যা দিয়ে খুব সহজেই OpenJdk11 ইনস্টল করা যায়। নিচের ধাপগুলো অনুসরণ করুন:

1. SDKMAN ইনস্টল করুন:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (এটা কাজ না করলে এখানে দেওয়া নির্দেশনা দেখুন: https://sdkman.io/install )
1. openjdk11 ইনস্টল করুন:
    ```
    $ sdk install java 11.0.2-open
    ```

### Windows-এ ম্যানুয়ালি ইনস্টল করা

*লক্ষ্য করুন: এই নির্দেশনাগুলো অভিজ্ঞ Windows ব্যবহারকারীদের জন্য।  আপনি যদি এনভায়রনমেন্ট ভ্যারিয়েবল সেট করা না জানেন বা ডিরেক্টরি স্ট্রাকচার পরিচালনায় স্বচ্ছন্দ না হন, তাহলে আমরা দৃঢ়ভাবে [উপরের](#h-windows) Chocolatey-ভিত্তিক ইনস্টল পদ্ধতি ব্যবহার করার পরামর্শ দিই।*

1. JDK ইনস্টল করুন:
   1. [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) থেকে "**OpenJDK 11 (LTS)**" ডাউনলোড করুন (**"Install JDK"** বেছে নিন)।
   -  সব ডিফল্ট রেখে ইনস্টলারটি চালান।

এখন আপনি Exercism-এর Kotlin ট্র্যাক শুরু করার জন্য প্রস্তুত!
