# ভূমিকা

Factor-এ বেশিরভাগ ডেটাই থাকে *সিকোয়েন্স*-এ। অ্যারে (`{ … }`), ভেক্টর (`V{ … }`), আর স্ট্রিং সবগুলোই [`sequences`][sequences] থেকে আসা একই [প্রোটোকল][sequence-protocol] শেয়ার করে।

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

অ্যাগ্রিগেশন (`sum`, `count`, `any?`, `all?`) আর `empty?`, `member?`-এর মতো প্রেডিকেটগুলো প্রতিটি সিকোয়েন্স টাইপে একইভাবে কাজ করে। মিউটেশন ছাড়াই নতুন সিকোয়েন্স তৈরির উপায়: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

কোনো জেনেরিক অপারেশন থেকে নির্দিষ্ট কোনো কনক্রিট সিকোয়েন্স ফেরত পেতে হলে, `>array`, `>vector` আর `>string` ([`arrays`][arrays] ও সংশ্লিষ্ট ভোকাবুলারিগুলোতে আছে) সিকোয়েন্স টাইপের মধ্যে কোয়ার্স করে।

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
