# ইনস্টলেশন

## কোন ভার্সন বেছে নেবেন?

আমরা সক্রিয় সাপোর্টসহ একটি স্থিতিশীল PHP রিলিজ ব্যবহার করতে উৎসাহিত করি।
বর্তমানে এগুলো হলো **PHP 8.2, 8.3 এবং 8.4**।
বর্তমান রিলিজ এবং তাদের সময়রেখা সম্পর্কে বিস্তারিত [অফিসিয়াল PHP ডকুমেন্টেশনে](https://www.php.net/supported-versions.php) পাওয়া যাবে।

## PHP ইনস্টল করুন

Linux / macOS-এর অধিকাংশ প্যাকেজ ম্যানেজার আগেই বিল্ড করা প্যাকেজ সরবরাহ করে।
PHP ডাউনলোড করে সোর্স থেকে বিল্ড করা যায়, যা [php.net/downloads.php](https://php.net/downloads.php) বা [windows.php.net/download](https://windows.php.net/download)-এ পাওয়া যায়।

~~~~

### Linux

বিভিন্ন ডিস্ট্রিবিউশনে পদ্ধতি ভিন্ন।
আপনি নিম্নলিখিতটি করতে পারবেন:

```shell
yum install php
```

অথবা

```shell
apt-get install php
```

আপনার প্যাকেজ ম্যানেজারের উপর নির্ভর করে।

আরও নির্দেশনার জন্য, [Unix সিস্টেমে ইনস্টলেশন](https://www.php.net/manual/en/install.unix.php) সম্পর্কে PHP ম্যানুয়াল পড়ুন।

### macOS

যদিও PHP প্রায়শই macOS-এর সাথে বান্ডল করা থাকে, এটি প্রায়শই পুরনো হয়ে যায়।
আমরা [Homebrew](https://brew.sh/) এর মাধ্যমে PHP ইনস্টল করার পরামর্শ দিই।
[তাদের হোমপেজে](https://brew.sh/#install) নির্দেশনা অনুসরণ করে আপনি Homebrew ইনস্টল করতে পারেন।

এর ইনস্টলেশন নিশ্চিত করতে নিম্নলিখিত কমান্ডটি চেষ্টা করুন, এটি এই লেখার সময় Homebrew `4.5.x` আউটপুট দেবে।

```shell
brew --version 
```

Homebrew-এর মাধ্যমে PHP ইনস্টল করুন

```shell
brew install php@8.4
```

এটি এখন ইনস্টল করা PHP-এর ভার্সন প্রদর্শন করবে, কমপক্ষে `8.2.0` ভার্সন।

```shell
php -v
```

আরও নির্দেশনার জন্য, [macOS-এ ইনস্টলেশন](https://www.php.net/manual/en/install.macosx.php) সম্পর্কে ম্যানুয়াল পড়ুন।

### Windows

Windows-এর জন্য অফিসিয়াল PHP বাইনারি [windows.php.net/download](https://windows.php.net/download) থেকে ডাউনলোড করা যাবে।

আগেই বিল্ড করা স্ট্যাক রয়েছে, যার মধ্যে [WAMP](https://www.wampserver.com/en/) - (Windows, Apache, MySQL, PHP) এবং [XAMPP](https://www.apachefriends.org/de/index.html) অন্তর্ভুক্ত।

আরও নির্দেশনার জন্য, [Windows সিস্টেমে ইনস্টলেশন](https://www.php.net/manual/en/install.windows.php) সম্পর্কে ম্যানুয়াল পড়ুন।

### Docker

আপনি যদি কন্টেইনারাইজড সমাধান পছন্দ করেন, তাহলে [Docker Hub থেকে অফিসিয়াল PHP ইমেজ](https://hub.docker.com/_/php) ডাউনলোড করতে পারেন।
আপনার [Docker](https://docs.docker.com/engine/install/)ও প্রয়োজন হবে।

### অন্যান্য

আপনি যদি ভিন্ন OS ব্যবহার করতে চান, তাহলে [php.net/manual/en/install](https://www.php.net/manual/en/install.php)-এ নির্দেশনা দেখুন।

### PHP আর্কাইভ (PHAR)-এর মাধ্যমে

Exercism-এর অনুশীলনীগুলোর জন্য PHPUnit ব্যবহারের সবচেয়ে সহজ উপায় হলো PHP আর্কাইভ (PHAR) হিসেবে প্যাকেজ করা একটি ডিস্ট্রিবিউশন ডাউনলোড করা, যা PHPUnit ব্যবহারের জন্য সুপারিশকৃত পদ্ধতিও।
যেখানেই থাকুন না কেন PHPUnit চালানোর জন্য `exercism` CLI যেখানে রেখেছেন সেখানেই PHAR সংরক্ষণ করুন।

আপনি PHPUnit প্যাকেজের একটি রিলিজ PHP আর্কাইভ হিসেবে ডাউনলোড করতে পারেন:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

তারপর ডাউনলোড করা ফাইলটিকে এক্সিকিউটেবল করুন:

```shell
chmod +x phpunit.phar
```

এবং `exercism` CLI যেখানে সরিয়েছেন সেখানে এটি সরিয়ে নিন, কমান্ডটির নাম দিয়ে `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

এখন আপনি যেখানেই থাকুন `phpunit` চালাতে পারবেন, যেমনটি [PHP ট্র্যাক টেস্টিং ডকস](https://exercism.org/docs/tracks/php/tests)-এ দেখানো হয়েছে:

```shell
phpunit --version
```

আউটপুটটি দেখতে এরকম হবে:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

আপনি PHPUnit ইনস্টল করতে অফিসিয়াল [PHPUnit ইনস্টল করার নির্দেশাবলী](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) অনুসরণ করতে পারেন।

### Composer-এর মাধ্যমে

PHPUnit version 11 [Composer](https://getcomposer.org)-এর মাধ্যমেও ইনস্টল করা যায়।

#### Composer ইনস্টল করুন

আপনার ডিভাইসের OS [ইনস্টলেশন নির্দেশাবলী](https://getcomposer.org/doc/00-intro.md) অনুসরণ করে [Composer](https://getcomposer.org) ইনস্টল করুন।
সহজ ব্যবহারের জন্য এটি গ্লোবালি ইনস্টল করার পরামর্শ দিই।

#### PHPUnit গ্লোবাল টুল হিসেবে যোগ করুন

নিম্নলিখিত কমান্ডটি ব্যবহার করে:

```shell
composer global require phpunit/phpunit ^11.5
```

অনুগ্রহ করে নিশ্চিত করুন যে আপনি 11.5 বা তার পরের ভার্সন ইনস্টল করছেন।
