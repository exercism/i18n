# নির্দেশনার সংযোজন

## Python ট্র্যাক-এ এই অনুশীলনীটি কীভাবে সাজানো হয়েছে

এই অনুশীলনীর টেস্টগুলো আশা করে যে আপনি একটি Matrix [`class`][classes] তৈরি করবেন (_আরও দেখুন [concept:python/classes]()_)।
এটি তৃতীয় পক্ষের লাইব্রেরির, যেমন [Numpy][numpy-matrix]-এর, একটি Matrix অবজেক্ট _ব্যবহার_ করা থেকে আলাদা, যা এখানে সমর্থিত নয়।
 _চিন্তা করবেন না, এটা আপনি যতটা ভাবছেন ততটা জটিল নয়!_
 `classes` ও ডেটা স্ট্রাকচার নিয়ে আরও শুরুর জায়গা এবং বিস্তারিত জানতে নিচের রিসোর্সগুলো একবার দেখে নিন:


-   [**A First Look at Classes**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) Python 3 ডকুমেন্টেশন থেকে। 
-   [**How to Define a Class in Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) Real Python ওয়েবসাইট থেকে।  
-   [**Data Structures in Python**](https://docs.python.org/3/tutorial/datastructures.html) Python 3 ডকুমেন্টেশন থেকে।
