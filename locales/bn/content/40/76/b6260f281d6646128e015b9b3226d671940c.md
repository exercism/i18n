# টেস্ট

পরীক্ষাগুলো চালানোর চেষ্টা করার আগে ইনস্টলেশনের ধাপগুলো অনুসরণ করে নিশ্চিত হয়ে নিন যে অ্যাসাইনমেন্ট ফোল্ডারটি সঠিকভাবে সেট-আপ করা হয়েছে, যথা `corepack yarn install` এবং Editor SDK সেটআপ।

দিয়ে টেস্টগুলো চালান:

```bash
$ corepack yarn test
```

## স্কিপ করা টেস্ট

টেস্ট স্যুটগুলোতে প্রথমটি ছাড়া বাকি সব টেস্ট স্কিপ করা আছে।

একটি টেস্ট পাস করাতে পারলে `xit`-এর জায়গায় `it` বসিয়ে পরেরটি চালু করতে পারেন।
এছাড়া `xdescribe` ব্যবহার করে টেস্টগুলো গ্রুপ করা যায়।
ওটির জায়গায় `describe` বসিয়ে গ্রুপটি চালু করুন।
সবশেষে, কিছু অনুশীলনীতে ঐচ্ছিক টেস্ট `it.skip` থাকতে পারে।
ঐচ্ছিক টেস্টটি চালাতে `.skip` মুছে ফেলুন।
