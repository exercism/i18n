# নির্দেশনা

দুইজন ভায়োলিন বাদক একটি ডুয়েটের মহড়া দিচ্ছেন। প্রতিটি পার্ট হলো একটি অ্যারে, যেখানে প্রতিটি বারে কতগুলো নোট আছে তা রাখা থাকে, আর পার্ট দুটির দৈর্ঘ্য সবসময় সমান হয় না।

চারটি কাজই `DUET_PRACTICE` ক্লাসে থাকবে।

## 1. তারা একসাথে কতগুলো বার বাজায়?

দুই পার্টেই যতক্ষণ একটি করে বার বাকি থাকে, ততক্ষণ তারা একসাথে বাজায়।

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. কতগুলো বার মেলে?

যেসব বারে দুই পার্টে একই সংখ্যক নোট আছে, সেগুলো গুনুন। কেবল যে বারগুলো দুই পার্টেই আছে, সেগুলোই মিলতে পারে।

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. কে বেশি ব্যস্ত?

যেসব বারে প্রথম পার্টে দ্বিতীয় পার্টের চেয়ে বেশি নোট আছে, সেগুলো গুনুন।

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. বারগুলোর ওজন নির্ণয় করুন

পরে আসা বারগুলো বেশি কঠিন, তাই একটি বার তার অবস্থান অনুযায়ীই গণ্য হয়: প্রথম বার একবার, দ্বিতীয় বার দুইবার, তৃতীয় বার তিনবার। প্রতিটি বারের নোটের সংখ্যাকে তার ক্রমসংখ্যা দিয়ে গুণ করুন এবং সবগুলো যোগ করুন।

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

অর্থাৎ 1×4 + 2×4 + 3×8। বারগুলো এক থেকে গণনা করা হয়, শূন্য থেকে নয়।
