# ভূমিকা

## প্যাটার্ন নিয়ে আরও

ফান্ডামেন্টালস কনসেপ্ট থেকে মনে করুন, একটি AWK প্রোগ্রাম **প্যাটার্ন-অ্যাকশন জোড়া** দিয়ে গঠিত।

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### "প্যাটার্ন" বলতে আমরা কী বুঝি?

"প্যাটার্ন" হলো যেকোনো AWK এক্সপ্রেশন।
এক্সপ্রেশনের ফলাফল সত্য কি মিথ্যা, তা-ই নির্ধারণ করে অ্যাকশনটি চালানো হবে কি না।

### খালি প্যাটার্ন

প্যাটার্নটি বাদ দেওয়া যায়।
এক্ষেত্রে প্রতিটি রেকর্ডের জন্য অ্যাকশনটি সম্পাদিত হয়।

আমরা passwd ফাইলের সব ইউজারনেম প্রিন্ট করতে পারি।

```sh
awk -F: '{print $1}' /etc/passwd
```

### রেগুলার এক্সপ্রেশন

AWK একটি বুলিয়ান ফলাফল পেতে স্ট্রিংগুলিকে রেগুলার এক্সপ্রেশনের সাথে তুলনা করতে পারে।

নির্দিষ্ট কোনো ফিল্ড মেলাতে `~` রেগেক্স-ম্যাচিং অপারেটরটি ব্যবহার করুন।
এই অপারেটরটি বাম দিকের অপারেন্ড হিসেবে একটি স্ট্রিং এবং ডান দিকের অপারেন্ড হিসেবে একটি রেগুলার এক্সপ্রেশন নেয়।
একটি রেগুলার এক্সপ্রেশন লিটারাল `/` স্ল্যাশের মধ্যে আবদ্ধ থাকে।

passwd ফাইলে যে ইউজাররা bash দিয়ে লগ ইন করেন, তাদের খুঁজে পেতে:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` হলো "রেগেক্স **মেলে না**" অপারেটর।

বর্তমান রেকর্ডের সাথে একটি রেগেক্স মেলাতে, আপনি `$0 ~ /regex/` লিখতে পারেন।
এটি এতটাই কমন যে এর একটি শর্টহ্যান্ড আছে: আপনি `$0` আর `~` বাদ দিয়ে শুধু `/regex/` লিখতে পারেন

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
সেই AWK ওয়ান-লাইনারটিকে সমতুল্য grep কমান্ডের সাথে তুলনা করুন

```sh
grep 'regex' data.txt
```

AWK সংক্ষিপ্ততা ত্যাগ না করেই আপনাকে একটি সম্পূর্ণ প্রোগ্রামিং ভাষা দেয়।
~~~~

আরও একটি কনসেপ্টে আমরা GNU AWK-এর রেগুলার এক্সপ্রেশন ফ্লেভার নিয়ে আরও বিশদে জানব।

### এক্সপ্রেশন

AWK এক্সপ্রেশন (গাণিতিক, যৌক্তিক বা অন্য যেকোনো) প্যাটার্ন হিসেবে ব্যবহার করা যায়।

UID 1000 বা তার বেশি এমন সব ইউজার বের করতে:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

মনে করুন, AWK-এর মিথ্যা মান হলো শূন্য সংখ্যা আর খালি স্ট্রিং, আর বাকি সব সংখ্যা বা স্ট্রিং সত্য।
যেকোনো এক্সপ্রেশন যা একটি সংখ্যা বা স্ট্রিং-এ মূল্যায়িত হয়, তা প্যাটার্ন হিসেবে ব্যবহার করা যায়।

### ফাংশন

যেকোনো [বিল্ট-ইন][builtins] বা [ইউজার-ডিফাইন্ড][] ফাংশন একটি এক্সপ্রেশনে, আর তাই প্যাটার্নেও ব্যবহার করা যায়।
কয়েকটি উদাহরণ:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### স্থির প্যাটার্ন

AWK-এর একটি কমন ইডিয়ম হলো:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` হলো একটি ট্রুথি প্যাটার্ন, যার সাথে কোনো অ্যাকশন যুক্ত নেই।
এর মানে হলো "বর্তমান রেকর্ডটি প্রিন্ট করা।"
