# সম্পর্কে

যে টাইপগুলো [`IEnumerable<T>`][IEnumerable] ইন্টারফেস ইমপ্লিমেন্ট করে, তাদেরকে _এনিউমারেবল_ বলা হয়।
সব বিল্ট-ইন কালেকশন টাইপ এই ইন্টারফেসটি ইমপ্লিমেন্ট করে।

একটি এনিউমারেবল টাইপ `foreach` লুপ ব্যবহার করে ইটারেট করা যায়:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>` ইমপ্লিমেন্ট করতে হলে একটি টাইপকে একটি মেথড ইমপ্লিমেন্ট করতে হয়: `IEnumerator<T> GetEnumerator()`।
যেমনটি দেখা যাচ্ছে, একটি এনিউমারেবল প্রকৃত ইটারেশনটি একটি `IEnumerator<T>` টাইপের কাছে ছেড়ে দেয়।
এই ইন্টারফেসটিতে ইমপ্লিমেন্ট করার জন্য একটি প্রপার্টি এবং তিনটি মেথড রয়েছে:

- `public T Current { get; }`: বর্তমান এলিমেন্টটি পাওয়া যায়।
- `public bool MoveNext ();`: পরের এলিমেন্টে যায়, পরের এলিমেন্টে যাওয়াটি সফল হলে `true` রিটার্ন করে, আর না হলে (আর কোনো এলিমেন্ট না থাকলে) `false` রিটার্ন করে।
- `public void Reset ();`: এনিউমারেটরটিকে তার প্রাথমিক অবস্থায় (প্রথম এলিমেন্টের আগে) রিসেট করে।

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
