# নির্দেশনা

আপনি একটি সিগন্যাল স্টেশনের কোড-জেনারেশন টুলকিট রক্ষণাবেক্ষণ করছেন।
প্রতিটি ম্যাক্রো হলো একটি *স্টেনসিল*, অর্থাৎ একটি ছোট টেমপ্লেট, যা কম্পাইলার
প্রতিটি কল সাইটে বিশেষায়িত কোড তৈরি করতে ব্যবহার করে।

আপনি শুধু চারটি ম্যাক্রো লেখেন। টেস্ট ফাইলটি ছোট কিছু র্যাপার শব্দ ডিফাইন
করে, যেগুলো আপনার ম্যাক্রোগুলোকে *কল* করে (একটি ম্যাক্রোকে কেবল তার
জেনারেট করা কোড দিয়েই দেখা যায়), তারপর র্যাপারগুলোর রানটাইম ফলাফল
পরীক্ষা করে। র্যাপারগুলো যেমন আছে তেমনই রাখুন।

প্রতিটি কাজে, বডি স্ট্যাকে কল সাইটের লিটারাল ইনপুটগুলো পায় এবং
**একটি কোয়োটেশন** রেখে যেতে হবে। ‘compiles to’ লাইনগুলো দেখায় আপনার
কোয়োটেশন থেকে যে স্ট্রেইট-লাইন কোড তৈরি হওয়া উচিত।

## 1. পরপর দুইবার

`twice` একটি লিটারাল কোয়োটেশন নেয় এবং এমন একটি কোয়োটেশন রিটার্ন করে,
যা মূলটিকে পরপর দুইবার রান করে।

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N পুনরাবৃত্তি

`repeat-quot` একটি লিটারাল কোয়োটেশন এবং একটি লিটারাল সংখ্যা `n` নেয়,
আর এমন একটি কোয়োটেশন রিটার্ন করে, যা মূলটিকে পরপর `n` বার রান করে।
`n = 0` হলে খালি কোয়োটেশন `[ ]` রিটার্ন করে।

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. অনেকগুলো একত্র করা

`compose-many` কোয়োটেশনের একটি লিটারাল অ্যারে নেয় এবং একটি একক
কোয়োটেশন রিটার্ন করে, যা একটির পর একটি রান করে। খালি অ্যারে
খালি কোয়োটেশন রিটার্ন করে।

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. আনরোল্ড ইটারেশন

`each-literal` একটি লিটারাল সিকোয়েন্স এবং একটি কোয়োটেশন নেয়। এটি
এমন একটি কোয়োটেশন রিটার্ন করে, যা সিকোয়েন্সের প্রতিটি এলিমেন্টের
জন্য সেই এলিমেন্টটি পুশ করে এবং তারপর কোয়োটেশনটি রান করে; এই
ইটারেশন কম্পাইল টাইমে ঘটে, তাই জেনারেট হওয়া কোড স্ট্রেইট-লাইন।

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

চারটির মধ্যে এটি সবচেয়ে কাঠামোগত: সিকোয়েন্সটির দৈর্ঘ্য *এবং* তার
এলিমেন্টের মান, দুটোই জেনারেট হওয়া কোডের গঠন নির্ধারণ করে। ইঙ্গিতগুলো
এক ধাপ করে এটি তৈরির পথ দেখিয়ে দেয়।
