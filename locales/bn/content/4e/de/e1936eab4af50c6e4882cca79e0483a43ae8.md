# পরিচিতি

জাভাতে বুলিয়ান প্রকাশ করা হয় `boolean` টাইপ দিয়ে, যার মান `true` অথবা `false` হতে পারে।

জাভা তিনটি [বুলিয়ান অপারেটর][operators] সমর্থন করে:

- `!` (NOT): বুলিয়ানটিকে নেগেট করে
- `&&` (AND): দুটি বুলিয়ান নেয় এবং দুটিই ট্রু হলে ফলাফল ট্রু হয়
- `||` (OR): দুটি বুলিয়ানের যেকোনো একটি ট্রু হলে ফলাফল ট্রু হয়

`&&` এবং `||` অপারেটর _শর্ট-সার্কিট ইভ্যালুয়েশন_ ব্যবহার করে, অর্থাৎ অপারেটরের ডান দিকের অংশটি কেবল দরকার হলেই ইভ্যালুয়েট করা হয়।

এদের কন্ডিশনাল বা লজিক্যাল অপারেটরও বলা হয়।
ডকুমেন্টেশনে `!`-কে মাঝে মাঝে বিটওয়াইজ অপারেশন হিসেবে ধরা হয়, তবে এর অর্থ প্রচলিত _NOT_ অর্থই।

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

তিনটি বুলিয়ান অপারেটরের [_অপারেটর প্রেসিডেন্স_][precedence] আলাদা আলাদা।
এর ফলে এদের ইভ্যালুয়েট করা হয় এই ক্রমে: প্রথমে `not`, তারপর `&&`, আর সবশেষে `||`।
আপনি যদি এই নিয়মগুলো 'এড়াতে' চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন বন্ধনীর (`()`) ভেতরে রাখতে পারেন, কারণ বন্ধনীর অপারেটর প্রেসিডেন্স আরও বেশি।

```java
!true && false   // => false
!(true && false) // => true
```
