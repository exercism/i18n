# নির্দেশাবলী

লিস্প এলিয়েন লিলি ফিরে এসেছে, আর এবার সে আরও রান্না করবে! এবার সে বানাবে লিস্প এলিয়েন লাসানিয়া, যা মানুষের লাসানিয়ার সঙ্গে মোটামুটি মিল রাখে।

লাসানিয়ার রান্নার সময় হিসাব করতে সাহায্য করার জন্য লিলির কিছু ফাংশন লিখে দিতে হবে। আর প্রতিটি ফাংশনের ভালো ডকুমেন্টেশন থাকতে হবে, যাতে লিলি ভুলে না যায় কোনটি কী করে।

লাসানিয়ার রান্নার সময় মেলাতে লিলিকে ফাংশন লিখতে সাহায্য করবেন কি?

## 1. মিনিটে ওভেনে প্রত্যাশিত সময় নির্ধারণ করুন

`expected-time-in-oven` ফাংশনটি ডিফাইন করুন, যা কোনো প্যারামিটার নেয় না এবং রিটার্ন করে লাসানিয়াকে কত মিনিট ওভেনে থাকতে হবে। লিস্প এলিয়েন ঐতিহ্য অনুযায়ী (একদম লিলির প্যারেন্টাল-ইউনিট যেভাবে রান্না করতেন সেভাবেই), মিনিটে প্রত্যাশিত ওভেন সময় হলো 337:

```lisp
(expected-time-in-oven) ;; => 337
```

## 2. মিনিটে ওভেনে বাকি সময় হিসাব করুন

`remaining-minutes-in-oven` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে নেয় লাসানিয়া আসলে কত মিনিট ধরে ওভেনে আছে, আর আগের টাস্কে পাওয়া মিনিটে প্রত্যাশিত ওভেন সময়ের ভিত্তিতে রিটার্ন করে লাসানিয়াকে আর কত মিনিট ওভেনে থাকতে হবে।

```lisp
(remaining-minutes-in-oven 100) ;; => 237
```

## 3. মিনিটে প্রস্তুতির সময় হিসাব করুন

`preparation-time-in-minutes` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে নেয় লিলি লাসানিয়ায় কতগুলো স্তর যোগ করেছে, আর ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে 19 মিনিট লাগে, রিটার্ন করে লিলি লাসানিয়া প্রস্তুত করতে কত মিনিট ব্যয় করেছে।

```lisp
(preparation-time-in-minutes 3) ;; => 57
```

## 4. মিনিটে অতিবাহিত সময় হিসাব করুন

`elapsed-time-in-minutes` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লিলি লাসানিয়ায় যতগুলো স্তর যোগ করেছে তার সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসানিয়া কত মিনিট ধরে ওভেনে আছে তার সংখ্যা। ফাংশনটি রিটার্ন করবে লিলি লাসানিয়া রান্না করতে কত মিনিট কাজ করেছে, যা হলো মিনিটে প্রস্তুতির সময় আর এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```lisp
(elapsed-time-in-minutes 3 100) ;; => 157
```
