# ভূমিকা

## _if-then_ স্টেটমেন্ট

জাভায় সবচেয়ে মৌলিক কন্ট্রোল ফ্লো স্টেটমেন্ট হলো _if-then_ স্টেটমেন্ট।
এই স্টেটমেন্টটি শুধুমাত্র কোডের একটি অংশ চালানোর জন্য ব্যবহার করা হয়, যদি একটি নির্দিষ্ট শর্ত `true` হয়।
একটি _if-then_ স্টেটমেন্ট `if` ক্লজ ব্যবহার করে ডিফাইন করা হয়:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

উপরের উদাহরণে, যদি গাড়ির জ্বালানি না থাকে, তাহলে `Car.drive` মেথড কল করলে কিছুই হবে না।

## _if-then-else_ স্টেটমেন্ট

_if-then-else_ স্টেটমেন্টটি তখন এক্সিকিউশনের একটি বিকল্প পথ দেয়, যখন `if` ক্লজের শর্তটি `false` হিসেবে মূল্যায়িত হয়।
এই বিকল্প এক্সিকিউশন পথটি একটি `if` ক্লজ অনুসরণ করে এবং `else` ক্লজ ব্যবহার করে ডিফাইন করা হয়:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

উপরের উদাহরণে, যদি গাড়ির জ্বালানি না থাকে, তাহলে `Car.drive` মেথড কল করলে গাড়ি থামানোর জন্য আরেকটি মেথড কল হবে।

_if-then-else_ স্টেটমেন্টটি `else if` ক্লজ ব্যবহার করে একাধিক শর্তও সাপোর্ট করে:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

উপরের উদাহরণে, জ্বালানি `5`-এর কম বা সমান হলে গাড়ি চালালে গাড়ি চলবে, তবে জ্বালানি লাইট জ্বালিয়ে দেবে।
যখন জ্বালানি `0`-তে পৌঁছায়, গাড়ি চলা বন্ধ করবে।
