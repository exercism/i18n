# ইনস্টলেশন

Zig ইনস্টল করার অনেক উপায় আছে, আর ভাষাটি যত পরিণত হচ্ছে, Zig ইনস্টল করার উপায়ের সংখ্যাও তত বাড়ছে।
সৌভাগ্যের বিষয়, জনপ্রিয় সব ইনস্টলেশন পদ্ধতির তালিকা আছে [Zig ইনস্টল পেজে][install-zig]।

## Zig ভার্সন

Exercism Zig 0.17.0 ব্যবহার করে (মুক্তি পেয়েছে 2026-10-01 তারিখে)।

একটি অনুশীলনী ভিন্ন কোনো Zig ভার্সনের সাথে কাজ করতে পারে, তবে তার কোনো নিশ্চয়তা নেই।
Zig এখনো 1.0 ভার্সনে পৌঁছায়নি, আর ব্রেকিং চেঞ্জ খুব কমন।

## অতিরিক্ত ইউটিলিটি

### Zig fmt - ভালোভাবে ফরম্যাট করা কোড তৈরি

যেকোনো অনুশীলনী সমাধান করার সময় আপনি আপনার সমাধানে যেকোনো ধরনের কোড স্টাইল ব্যবহার করতে পারেন।
তবে অনুশীলনী সমাধানের বাইরে, যেমন অ্যাপ্লিকেশন বা লাইব্রেরি বানানোর সময়, আপনার কোড ধারাবাহিক ও পড়ার উপযোগী করে তোলা সাধারণত ভালো অভ্যাস।
এই ধারণাটি বিশেষভাবে গুরুত্বপূর্ণ তখন, যখন আপনার প্রজেক্টে সাহায্য করতে চাওয়া অন্য কাউকে আপনার কোড পড়তে হয়।

এই সমস্যার সমাধানে Zig কম্পাইলারে একটি বিল্ট-ইন, হালকা [লিন্টার][linters] আছে, যা সুবিধাজনকভাবে আপনার কোড ফরম্যাট করে।
এই কোড ফরম্যাটার [Zig ডকুমেন্টেশন][documentation] দ্বারা ইতিমধ্যে প্রতিষ্ঠিত [স্টাইল গাইড][style-guide] অনুসরণ করার লক্ষ্য রাখে।

Zig-এর নেটিভ ফরম্যাটারের ফিচারগুলো দেখতে নিচের কমান্ডটি ব্যবহার করুন:

```bash
zig fmt --help
```

### Zig Zen - কোড লেখার নিয়ম

যেকোনো কাজ শেষ করার সময়, এমনকি কোড লেখার সময়ও, মাঝে মাঝে একটু দিকনির্দেশ অনেক দূর এগিয়ে নিয়ে যায়।
ভাগ্য ভালো, ভালো Zig কোড লেখার পেছনের কিছু লক্ষ্য নিজেদের মনে করিয়ে দেওয়ার জন্য Zig কম্পাইলারেই একটি মজার কমান্ড আছে।

এই প্রজ্ঞার বাণীগুলো দেখতে আপনি নিচের কমান্ডটি ব্যবহার করতে পারেন:

```bash
zig zen
```

### Zig Language Server - Zig-এর জন্য পূর্ণাঙ্গ এডিটর সাপোর্ট

এই থার্ড-পার্টি সফটওয়্যারটি এডিটর কমপ্লিশন ও উন্নত Zig কোড নেভিগেশনের সুবিধা দেয়, যা আপনাকে ভাষাটি আরও দ্রুত শিখতে সাহায্য করতে পারে।

সর্বশেষ নির্দেশনার জন্য [ZLS ইনস্টলেশন গাইড][install-zls] দেখুন।
