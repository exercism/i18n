# নেস্টেড if স্টেটমেন্ট ব্যবহার করবেন না

গভীর নেস্টিং এড়াতে if স্টেটমেন্টগুলো নতুন করে লেখার চেষ্টা করুন, কারণ এতে কোড অনুসরণ করা কঠিন হয়ে যেতে পারে। নিচের দুটি কোড একবার দেখুন:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

এবার এটির সাথে নিচের কোডটি মিলিয়ে দেখুন:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

দ্বিতীয় উদাহরণটির গঠন বেশ স্পষ্ট: এরর সংক্রান্ত সব পথই ইন্ডেন্ট করা ব্লকে সামলানো হয়, আর "হ্যাপি পাথ" সবসময় একেবারে বাম দিকে সারিবদ্ধ থাকে। এতে পড়া খুব সহজ হয়, কারণ কোডের মধ্য দিয়ে সবচেয়ে কমন, এরর-মুক্ত পথটি কোনটি তা দ্রুত চোখে পড়ে।
