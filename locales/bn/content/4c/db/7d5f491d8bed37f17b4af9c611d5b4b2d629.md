# পরিচিতি

## সেট

সেট হলো অনন্য মানের একটি অপরিবর্তনীয় ও ক্রমহীন সংগ্রহ। একটি সেটের সব এলিমেন্ট একই টাইপের হতে হবে।

`gleam/set` মডিউলটি `Set` টাইপ ডিফাইন করে এবং সেট নিয়ে কাজ করার ফাংশন দেয়।

আপনি `set.to_list` আর `set.from_list` দিয়ে অ্যারে ও সেটকে পরস্পরে রূপান্তর করতে পারেন। সেটে এলিমেন্টের ক্রম নিশ্চিত নয়।

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

আপনি `set.new`, `set.insert` আর `set.delete` দিয়ে সেট তৈরি ও পূরণ করতে পারেন।

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

আপনি `set.contains` আর `set.size` ফাংশন দিয়ে সেটের বিষয়বস্তু জানতে পারেন।

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

সেটগুলো `set.union` আর `set.intersection` দিয়ে মেলানো যায়।

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

আপনি সেট ফিল্টারও করতে পারেন।

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
