# নির্দেশনা

আপনি সবেমাত্র একটি ক্লাইম্বিং জিমের ফ্রন্ট ডেস্কে কাজ শুরু করেছেন।
সদস্যরা নির্দিষ্ট কয়েক মাসের জন্য সদস্যপদ কেনেন এবং প্রতিবার আসার সময় চেক ইন ও চেক আউট করেন।
ম্যানেজার আপনাকে একটি হেল্পার লিখতে বলেছেন, যা সদস্যরা সবচেয়ে বেশি জিজ্ঞেস করেন এমন প্রশ্নগুলোর উত্তর দেবে।

## 1. সদস্যপদ কখন শেষ হয় তা বের করা

নির্দিষ্ট একটি তারিখে শুরু হওয়া সদস্যপদ ঠিক ওই মাসের একই দিনে শেষ হয়, প্রদত্ত মাসসংখ্যা পরে।
যখন সেই দিনটি শেষ মাসে থাকে না, তখন সদস্যপদটি বরং ওই মাসের শেষ দিনে শেষ হয়।

`FrontDesk.membershipEnd()` মেথডটি বাস্তবায়ন করুন, যা সদস্যপদের শুরুর তারিখ ও মাসসংখ্যা নেয় এবং সদস্যপদ যে তারিখে শেষ হয় তা রিটার্ন করে:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. সদস্যপদ কত দিন স্থায়ী হয় তা দেখানো

সদস্যপদ কার্ডে জিম ছাপে সদস্যপদটি কত বছর, মাস ও দিন স্থায়ী হয়।

`FrontDesk.membershipLength()` মেথডটি বাস্তবায়ন করুন, যা সদস্যপদের শুরুর তারিখ ও শেষ তারিখ নেয় এবং সদস্যপদের দৈর্ঘ্য একটি `Period` হিসেবে রিটার্ন করে:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. সদস্যপদে কত দিন বাকি তা গণনা করা

সদস্যরা প্রায়ই জিজ্ঞেস করেন তাদের সদস্যপদ শেষ হওয়ার আগে আর কত দিন বাকি আছে।

`FrontDesk.daysLeft()` মেথডটি বাস্তবায়ন করুন, যা আজকের তারিখ ও সদস্যপদের শেষ তারিখ নেয় এবং আজ থেকে শেষ তারিখ পর্যন্ত মোট দিনসংখ্যা রিটার্ন করে।
শেষ তারিখ আজ হলে বা ইতিমধ্যে পেরিয়ে গেলে আর কোনো দিন বাকি থাকে না, তাই মেথডটি `0` রিটার্ন করে:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. একটি ভিজিট পরিমাপ করা

জিমটি দিনরাত খোলা, এবং টার্নস্টাইল সদস্য কখন চেক ইন ও চেক আউট করেন তার তারিখ ও সময় রেকর্ড করে।

`FrontDesk.visitDuration()` মেথডটি বাস্তবায়ন করুন, যা একটি ভিজিটের চেক-ইন ও চেক-আউট date-time নেয় এবং ভিজিটটি কতক্ষণ স্থায়ী হয়েছিল তা একটি `Duration` হিসেবে রিটার্ন করে:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. রসিদে একটি ভিজিট ছাপানো

রসিদে একটি ভিজিটের দৈর্ঘ্য ঘণ্টা ও মিনিটে দেখানো হয়, যেমন `1h 35m`।
মিনিট সবসময় দুই অঙ্কে লেখা হয়, সেকেন্ড বাদ দেওয়া হয়, এবং ঘণ্টা এক দিনের মধ্যে সীমিত নয়।

`FrontDesk.formatVisit()` মেথডটি বাস্তবায়ন করুন, যা একটি ভিজিটের duration নেয় এবং সেটি এই ফরম্যাটে রিটার্ন করে:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
