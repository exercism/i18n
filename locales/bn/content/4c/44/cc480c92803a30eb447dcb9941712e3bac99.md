# ইনস্টলেশন

Racket ডিস্ট্রিবিউশনটি https://download.racket-lang.org থেকে ডাউনলোড করা যেতে পারে।

এর জন্য ইনস্টলার দেওয়া আছে

* Windows
* Linux
* macOS

নির্দেশনার উপকরণের জন্য Racket-এর [Getting Started](http://docs.racket-lang.org/getting-started/) পেজটি দেখুন।

[Racket Guide](https://docs.racket-lang.org/guide/intro.html) পেজটি আপনাকে Racket-এর সাথে কাজ করার পরিচয় করিয়ে দেয়।

DrRacket IDE ব্যবহারের নির্দেশনার জন্য [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html) দেখুন।

Racket কমান্ড-লাইন টুল এবং অন্য এডিটর ব্যবহারের পরিচিতির জন্য [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html) দেখুন।


## Linux ইনস্টলার সম্পর্কে:
Linux বিল্ডটি যথেষ্ট জেনেরিক, তাই এটি বেশিরভাগ ডিস্ট্রিবিউশনে চলা উচিত, তুলনামূলকভাবে পুরোনো ডিস্ট্রিবিউশনসহ।

ইনস্টলার ফাইলটি ডাউনলোড করার পর এটি চালান
```
sh racket-8.10-x86_64-linux-cs.sh
```

প্রশাসক অ্যাক্সেস প্রয়োজন হয় এমন কোনো লোকেশনে ইনস্টল করতে হলে কমান্ডের শুরুতে `sudo` বসাতে হতে পারে।

**সতর্কতা: আপনার ডিস্ট্রিবিউশনের প্যাকেজ ম্যানেজারের মাধ্যমেও Racket পাওয়া যেতে পারে, তবে সেটি সর্বশেষ Racket সংস্করণের চেয়ে পুরোনো হতে পারে।**
আপনি চাইলে এটি পরে করতেও পারেন, তবে একজন শিক্ষার্থী হিসেবে https://download.racket-lang.org থেকে পাওয়া বর্তমান রিলিজেই থাকলে আপনার অভিজ্ঞতা অনেক বেশি ভালো হবে।


## macOS ইনস্টলার সম্পর্কে:

আপনার মেশিনে যদি M1 বা M2 সিরিজের প্রসেসর থাকে, তাহলে ডাউনলোড করার আগে প্ল্যাটফর্ম ড্রপডাউন মেনু থেকে **Apple Silicon** নির্বাচন করুন।
