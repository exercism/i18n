# পরিচিতি

বাস্তব জগতের ঘটনা সিমুলেট করতে অনেক প্রোগ্রামেরই (সিউডো-)র্যান্ডম মান প্রয়োজন হয়।

কমন ও পরিচিত কিছু উদাহরণ:

- কয়েন টস: ('H', 'T') থেকে একটি র্যান্ডম মান।
- পাশা গড়ানো: ১ থেকে ৬-এর মধ্যে একটি র্যান্ডম ইন্টিজার।
- কার্ডের ডেক শাফল করা: কার্ডের অ্যারের একটি র্যান্ডম ক্রমবিন্যাস।
- 3-D গ্রাফিক্স সিমুলেশনে গাছ ও ঝোপ তৈরি করা।

কম্পিউটার দিয়ে সত্যিকারের র্যান্ডম মান তৈরি করা একটি [আশ্চর্যজনকভাবে কঠিন প্রযুক্তিগত চ্যালেঞ্জ][why-randomness-is-hard], তাই "সিউডোর্যান্ডম" জেনারেটরও আছে।

## র্যান্ডম সংখ্যা তৈরি করা

Javascript-এ, আপনি [`Math.random()`][Math.random] ফাংশনটি ব্যবহার করে সিউডোর্যান্ডম সংখ্যা তৈরি করতে পারেন।
এটি ০ (সহ) এবং ১ (ব্যতীত) এর মধ্যে একটি সিউডোর্যান্ডম ফ্লোটিং-পয়েন্ট সংখ্যা রিটার্ন করবে।

_min_ (সহ) এবং _max_ (ব্যতীত) এর মধ্যে একটি র্যান্ডম সংখ্যা পেতে আপনি এরকম একটি ফাংশন ব্যবহার করতে পারেন:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## র্যান্ডম ইন্টিজার তৈরি করা

একটি র্যান্ডম ইন্টিজার তৈরি করতে, আপনি `Math.floor()` বা `Math.ceil()` ব্যবহার করে র্যান্ডমভাবে তৈরি হওয়া একটি সংখ্যাকে ইন্টিজারে রূপান্তর করতে পারেন।
