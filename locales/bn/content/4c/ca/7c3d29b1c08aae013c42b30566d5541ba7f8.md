# বিবরণ

[কনস][hyper-conses] হলো Common Lisp-এর একটি মৌলিক ডেটা টাইপ। এরা একটি হেড আর একটি টেইল দিয়ে গঠিত (যাদের [ঐতিহাসিক কারণে][history] `car` আর `cdr` বলা হয়)। কনসের হেড আর টেইলের ডেটা টাইপ নিয়ে কোনো বিধিনিষেধ নেই।

কনস তৈরি করা হয় [`cons`][hyper-cons] ফাংশন দিয়ে, যা দুটি অবজেক্ট নেয় এবং ফলাফল হিসেবে একটি কনস দেয় (যাকে কখনও কখনও 'কনস সেল' বলা হয়)।

কনসের অংশগুলো অ্যাক্সেস করা যায় [`car`][hyper-car] আর [`cdr`][hyper-cdr] ফাংশন দিয়ে।

## রেফারেন্স

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
