# পরিচিতি

## ভ্যারিয়েবল ও অ্যাসাইনমেন্ট

R একটি ডাইনামিকভাবে টাইপড ভাষা, তাই সাধারণভাবে ভ্যারিয়েবলের টাইপ উল্লেখ করার প্রয়োজন হয় না। পছন্দের অ্যাসাইনমেন্ট অপারেটর হলো `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

`<-` এর বদলে `=` ব্যবহার করলে অনেক সময় কাজ হবে, তবে সব সময় নয়, এবং এটি খারাপ স্টাইল হিসেবে নিরুৎসাহিত করা হয়।
RStudio-তে কাজ করলে, কীবোর্ড শর্টকাট `Alt-minus` দিয়ে এটি লেখা যায়।

অপারেটরগুলো বেশিরভাগই প্রচলিত, তবে `%/%` আর `%%` খেয়াল করুন:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

R-এ `#` দিয়ে এক-লাইনের কমেন্ট শুরু হয়।
বহু-লাইনের কমেন্টের জন্য আলাদা কোনো সিনট্যাক্স নেই।

## ফাংশন

একটি ফাংশন ডিফাইন করতে:

```R
squareit <- function(x) {
    x * x
}
```

ফাংশনে শূন্য বা তার বেশি আর্গুমেন্ট থাকতে পারে, যা কমা দিয়ে আলাদা করা হয়।
`function()` এর সাথে প্রথম বন্ধনী `()` লাগে, এমনকি প্যারামিটার না থাকলেও।

ফাংশনের আর্গুমেন্টের জন্য ডিফল্ট মান নির্দিষ্ট করা যায়, তবে সেগুলো ডিফল্টবিহীন সব আর্গুমেন্টের পরে থাকতে হবে, এবং ডিফল্ট মান অ্যাসাইন করতে `=` ব্যবহার করতে হবে, `<-` নয়।
বরং অর্থহীন একটি উদাহরণ:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

এক-লাইনের ফাংশন বডির জন্য দ্বিতীয় বন্ধনী `{ }` কঠোরভাবে প্রয়োজন হয় না, তবে এগুলো ব্যবহার করা ভালো স্টাইল হিসেবে ধরা হয়।

R স্বয়ংক্রিয়ভাবে একটি ফাংশনের শেষ মান রিটার্ন করে, উপরের উদাহরণগুলোর মতো।

রিটার্ন ভ্যালু স্পষ্ট করতে ফাংশন বডির যেকোনো জায়গায় `return()` ব্যবহার করা যায়।

ফাংশন কল করা অন্য অনেক ভাষার মতোই:

```R
squareit(3)
#> [1] 9
```
