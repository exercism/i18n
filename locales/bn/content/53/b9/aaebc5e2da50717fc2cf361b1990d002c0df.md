# ইনস্টলেশন

## .NET 10 ইনস্টল করুন

Visual Basic ট্র্যাকটি .NET 10 ব্যবহার করে।
স্থানীয়ভাবে অনুশীলনীগুলো বিল্ড ও টেস্ট করতে, [আপনার অপারেটিং সিস্টেমের জন্য .NET 10 SDK][install-sdk] ইনস্টল করুন:
শুধু রানটাইম নয়, SDK ইনস্টল করুন।

## আপনার ইনস্টলেশন যাচাই করুন

একটি নতুন টার্মিনাল খুলে রান করুন:

```bash
dotnet --version
```

কমান্ডটি `10.0.0` বা তার পরের ভার্সন আউটপুট করা উচিত।

## এডিটর সাপোর্ট

.NET SDK আর বাড়তি সুবিধা ছাড়া একটি সাধারণ টেক্সট এডিটর, এতটুকুই অনুশীলনীগুলো শেষ করার জন্য যথেষ্ট।
কোড কমপ্লিশন আর ডিবাগিংয়ের মতো আরও উন্নত সুবিধার জন্য, নিচের এডিটরগুলোর একটি বিবেচনা করতে পারেন:

- Windows-এ [Visual Studio 2026][visual-studio]
- Windows, Linux বা macOS-এ [Visual Studio Code][visual-studio-code]
- Windows, Linux বা macOS-এ [JetBrains Rider][rider]

[install-sdk]: https://learn.microsoft.com/en-us/dotnet/core/install
[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
[visual-studio-code]: https://code.visualstudio.com/download
