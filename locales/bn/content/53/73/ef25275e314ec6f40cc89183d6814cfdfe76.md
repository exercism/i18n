# সম্পর্কে

সিকোয়েন্স ধরে হাঁটার সময় কখনও কখনও শুধু এলিমেন্ট থাকলেই যথেষ্ট হয় না, পজিশনটাও দরকার হয়। Factor-এর *indexed* ইটারেশন ওয়ার্ডগুলো প্রতি-এলিমেন্ট কোটােশনকে দুটোই দেয়, আর ইনডেক্সটি থাকে স্ট্যাকের একদম উপরে। `times` হলো এর সঙ্গে সম্পর্কিত ওয়ার্ড, যা পেছনে কোনো সিকোয়েন্স ছাড়াই নির্দিষ্ট সংখ্যকবার ইটারেশনের কাজ করে।

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| ওয়ার্ড      | ইফেক্ট                                                               |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )` — তবে নিচে দেখুন                            |

`times` নিয়ে একটি সূক্ষ্ম বিষয় আছে: এর কোটােশনের ডকুমেন্টেশনে `( -- )` লেখা থাকলেও ওয়ার্ডটি `inline`, তাই `( str -- str )`-এর মতো ইফেক্ট-ব্যালান্সড কোটােশনও ভালোমতোই কাজ করে এবং এক ইটারেশন থেকে পরের ইটারেশনে স্ট্যাক বহন করে নিয়ে যায়। ফলে কোনো মিউটেবল স্টেট ছাড়াই আপনি একটি গণনাভিত্তিক অ্যাকুমুলেটর পেয়ে যান:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

একই কৌশল `each-index` আর `map-index`-এর ক্ষেত্রেও কাজ করে: ঘোষিত প্রতি-এলিমেন্ট ইফেক্টটি একটি *সর্বনিম্ন* সীমা, *সর্বোচ্চ* নয়।
