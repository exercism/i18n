# ইঙ্গিত

## 1. SELECT কোয়েরি তৈরি করুন

- মনে রাখবেন, বিল্ডারটি শুরু করার জন্য কোনো কনস্ট্রাক্টর বা লিটারালের দরকার নেই। একটি সাধারণ `var sb strings.Builder` লিখলেই সেটি সঙ্গে সঙ্গেই কাজ করার উপযোগী হয়ে যায়।
- `columns` স্লাইসটি খালি বা `nil` হলে সেই ক্ষেত্রেও যেন কাজ করে, সেটি খেয়াল রাখুন, তখন ওয়াইল্ডকার্ড `*` চিহ্নটি অ্যাপেন্ড করুন।
- খেয়াল করুন, এখানে কোনো মেটা ক্যারেক্টার সামলানো বা SQL স্যানিটাইজেশনের দায়িত্ব আপনার নেই, প্রত্যাশাও করা হয় না। আপনি নিশ্চিন্তে `sb.WriteString(col)` দিয়ে সরাসরি কলামের নামগুলো অ্যাপেন্ড করতে পারেন।

## 2. ব্যাচ INSERT স্টেটমেন্ট তৈরি করুন

- `for` লুপের ভেতরে প্রতিবার একেবারে নতুন একটি `strings.Builder` অ্যালোকেট করলে পারফরম্যান্সের সুবিধাটুকু নষ্ট হয়ে যায়। এর বদলে লুপ শুরু হওয়ার *আগে* একটি বিল্ডার ডিক্লেয়ার করুন।
- লুপের প্রতিটি ইটারেশনের শুরুতে আপনার বিল্ডার ইনস্ট্যান্সের `Reset()` মেথডটি কল করুন। এতে বাফার খালি হয়ে যায়, ফলে ভেতরে ইতিমধ্যে অ্যালোকেট করা মেমরি ক্যাপাসিটি অক্ষুণ্ণ রেখেই আপনি নতুন একটি কোয়েরি শুরু করতে পারেন।
- ভুলবেন না, SQL-এর `VALUES` ক্লজে স্ট্রিং মানগুলো একক উদ্ধৃতি `'` দিয়ে স্পষ্টভাবে ঘিরে দিতে হয়। সেগুলো পরিষ্কারভাবে যোগ করতে আপনি `WriteByte('\'')` ব্যবহার করতে পারেন।
- SELECT কোয়েরিগুলোর ক্ষেত্রে যেমন, তেমনি কলামের মানের ভেতর বিশেষ ক্যারেক্টার এস্কেপ করা বা SQL ইনজেকশন ঠেকানোর চিন্তা করবেন না। ইনপুট স্ট্রিংগুলোকে সরাসরি ব্যবহারের জন্য নিরাপদ ধরুন।
