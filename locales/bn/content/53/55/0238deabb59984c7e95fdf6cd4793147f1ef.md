# মডুলো

মডুলো তুলনা Crystal-এ সম্পূর্ণ বৈধ, তবে ভাগের ভাগশেষ তুলনা করার আরও পাঠযোগ্য একটি উপায় হলো [`divisible_by?`][divisible_by] মেথডটি। আরও ভালো, কোনো সংখ্যা জোড় না বিজোড় কিনা যাচাই করতে চাইলে [`odd?`][odd?] এবং [`even?`][even?] মেথড ব্যবহার করুন।

উদাহরণস্বরূপ:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```

[even]: https://crystal-lang.org/api/Int.html#odd%%3F%%3ABool-instance-method
