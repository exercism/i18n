# সম্পর্কে

ধ্রুবক মানের একটি নির্দিষ্ট সেট থাকলে আপনি [এনামেরেশন টাইপ][enumeration types] ব্যবহার করতে পারেন। একটি `enum` ব্যবহার করলে ধ্রুবক মানগুলোর সাথে কাজ করার একটি টাইপ-সেফ উপায় পাওয়া যায়। একটি এনাম ডিফাইন করা হয় `enum` কিওয়ার্ডের মাধ্যমে। এনাম মেম্বার উল্লেখ করা হয় তার আগে এনামের নাম আর একটি ডট বসিয়ে (যেমন `Status.Active`)।

প্রতিটি এনাম মেম্বার আসলে একটি নাম আর একটি `int` মানের জোড়া। প্রথম মেম্বারের কোনো স্পষ্ট মান না থাকলে তার মান `0` ধরে নেওয়া হয়। কোনো এনাম মেম্বারের জন্য স্পষ্টভাবে কোনো মান ডিফাইন করা না থাকলে তার মান স্বয়ংক্রিয়ভাবে আগের মেম্বারের মানের সাথে `1` যোগ করে বসানো হয়।

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

এনাম বেশ ডিক্লারেটিভ। নিচের দুটি মেথড কলের তুলনা করুন:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

কোড পড়ছেন এমন কারও কাছে দ্বিতীয় সংস্করণটি (এনামসহ) বুঝতে সহজ হবে।

## সংখ্যাসূচক টাইপের এনাম

মানগুলোর ডিফল্ট সংখ্যাসূচক টাইপ `int` হলেও অন্য যেকোনো [অখণ্ড সংখ্যাসূচক][integral numeric] টাইপ স্পষ্টভাবে উল্লেখ করে সেটি বদলানো যায়।

নিচের এনামটি তার মানের জন্য `byte` সংখ্যাসূচক টাইপ ব্যবহার করে:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## এনাম মেম্বারে রূপান্তর

বুলিয়ানের মতো কোনো কিছু মডেল করতে চাইলে সবসময় এনাম ব্যবহারের কথা ভাবা উচিত। উপরে বলা পাঠযোগ্যতার সুবিধার পাশাপাশি বুলিয়ানের চেয়ে এনামের আরেকটি সুবিধা আছে: এনামে সবসময় নতুন মান যোগ করা যায়, অথচ বুলিয়ান মান কখনোই `true` বা `false` ছাড়া কিছু হয় না। তাই এনাম ব্যবহার করা ভবিষ্যতের দিক থেকে বেশি নিরাপদ।

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

লক্ষ করুন, ইন্টিজার মান এনামে কাস্ট করা _যায়_ বটে, কিন্তু ইন্টিজার মানটি এনামের কোনো মানের সাথে না মিললে এভাবে কাস্ট করলে অপ্রত্যাশিত ফলাফল পাওয়া যেতে পারে:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## এনাম পার্স করা

মাঝে মাঝে নাম দেখে একটি স্ট্রিংকে এনাম মেম্বারে রূপান্তর করা কাজে লাগে, [`Enum.Parse`][enum parse] দিয়ে:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

এনামে কোনো নাম বা মান আছে কি না তা যাচাই করতে আপনি [`Enum.TryParse`][enum tryparse] বা [`Enum.IsDefined`][enum isdefined] ব্যবহার করতে পারেন; দুটোই একটি বুলিয়ান রিটার্ন করে, যা বলে এনাম মেম্বারটি আছে কি না:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
