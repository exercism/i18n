# স্ট্রিং

স্ট্রিং হলো ক্যারেক্টারের একটি ধারা, যা উদ্ধৃতি চিহ্ন দিয়ে ঘেরা থাকে।
একক এবং দ্বৈত উদ্ধৃতি, দুটোই ব্যবহার করা যায়।

```php
<?php

$where = "Spain";
$what = 'rain';
```

## স্ট্রিং ভ্যারিয়েবল এক্সপ্যানশন

দ্বৈত উদ্ধৃতির স্ট্রিংয়ে, স্কোপে থাকা কোনো ভ্যারিয়েবলের রেফারেন্স থাকলে সেই ভ্যারিয়েবলের মানটি স্ট্রিংটির ভেতরে বসিয়ে দেওয়া হয়।

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## ক্যারেক্টার এনকোডিং সাপোর্ট

ঐতিহাসিকভাবে, PHP-এর স্ট্রিং ফাংশনগুলো কেবল ASCII ক্যারেক্টার সাপোর্ট করত এবং আধুনিক ইউনিকোড এনকোডিং সাপোর্ট করত না।
প্রতিটি ASCII ক্যারেক্টারের আকার ১ বাইট, অন্যদিকে ইউনিকোড ক্যারেক্টারের দৈর্ঘ্য ১ থেকে ৪ বাইট হতে পারে।
ইউনিকোড স্ট্রিং নিরাপদে নিয়ে কাজ করতে হলে, পুরোনো ফাংশনগুলোর [মাল্টিবাইট ভার্সনগুলো][multi-byte-fns] দেখুন।

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
