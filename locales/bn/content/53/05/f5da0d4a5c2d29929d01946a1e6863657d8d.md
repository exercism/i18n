# টেস্ট

আপনার সমাধান টেস্ট করতে শুধু চালান:

```bash
make test
```

এটি `<exercise-name>-test.ys` টেস্ট ফাইলটি রান করবে, যেখানে আপনার সমাধান সঠিক হওয়ার জন্য পাস করতে হওয়া সমস্ত টেস্ট রয়েছে।
আপনার সমাধান ঠিক কী করতে হবে তা বুঝতে টেস্ট ফাইলটি ভালোভাবে পড়ে দেখা উচিত।

> নোট: প্রথমবার `make test` চালালে এটি এটাও নিশ্চিত করবে যে `ys` YAMLScript ইন্টারপ্রেটারের সঠিক সংস্করণটি সঠিক জায়গায় ইনস্টল করা আছে।

কোনো ফাইল পরিবর্তন করার আগেই যদি `make test` চালান, তাহলে সব টেস্ট ব্যর্থ হবে।
এটাই স্বাভাবিক ও প্রত্যাশিত আচরণ।
অনুশীলনী বিকাশের স্বাভাবিক প্রক্রিয়া হলো ধাপে ধাপে আপনার সমাধান উন্নত করা, প্রতিটি পরিবর্তনের পরে `make test` চালানো, যতক্ষণ না সব টেস্ট পাস করে।

আপনি যদি শুধু একটি নির্দিষ্ট টেস্ট চালাতে চান (সমাধানের ওই অংশটিতে মনোযোগ দেওয়ার সময়), তাহলে সেই টেস্টে এই কী (key)/মান জোড়াটি যোগ করতে পারেন:

```yaml
  ONLY: true
```

আপনি যদি নির্দিষ্ট কিছু টেস্ট বাদ দিতে চান (সমাধানের অন্য অংশগুলোতে কাজ করার সময়), তাহলে সেই টেস্টগুলোতে এই কী (key)/মান জোড়াটি যোগ করতে পারেন:

```yaml
  SKIP: true
```


## টেস্টের পূর্বশর্ত

YAMLScript আপাতত MacOS আর Linux-এ চলে।

আপনার কম্পিউটারে নিচের অত্যন্ত পরিচিত কমান্ডগুলো ইনস্টল করা থাকা দরকার:

* `bash` - আপনি যেকোনো শেলেই টেস্ট চালাতে পারেন, তবে `bash` থাকা আবশ্যক।
* `make` - টেস্ট চালানোর জন্য GNU `make` ব্যবহার করতে হবে।
  কিছু পরিবেশে এর নাম `make` ছাড়া অন্য কিছু হতে পারে।
  হতে পারে `gmake`।
* `prove` - এই প্রোগ্রামটি যেকোনো সাধারণ Perl ইনস্টলেশনের অংশ।
* `curl` - ys আগে থেকে ইনস্টল না থাকলে সেটি ইনস্টল করতে ব্যবহৃত হয়।

এই প্রোগ্রামগুলো আপনার কাছে আগেই ইনস্টল করা আছে বলেই ধরে নেওয়া যায়।
