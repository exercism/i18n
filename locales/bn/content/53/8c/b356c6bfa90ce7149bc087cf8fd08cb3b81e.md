# ইনস্টলেশন

## Clojure CLI ইনস্টল করা

Clojure কমান্ড লাইন টুল সরবরাহ করে; এর সাহায্যে একটি ইন্টারঅ্যাকটিভ REPL (Read-Eval-Print Loop) চালানো, Clojure প্রোগ্রাম রান করা এবং Clojure এক্সপ্রেশন ইভ্যালুয়েট করা যায়।
আমরা অনুশীলনীগুলোর সঙ্গে Clojure CLI ব্যবহার করার পরামর্শ দিই। [Clojure CLI](https://clojure.org/guides/deps_and_cli) ইনস্টল করতে:

### Windows
Windows-এ ইনস্টলেশনের নির্দেশনার জন্য দেখুন: [Clojure CLI ইনস্টলেশন](https://clojure.org/guides/getting_started#_installation_on_windows)।

### Linux
বেশিরভাগ প্ল্যাটফর্মে ইনস্টলেশনের নির্দেশনার জন্য দেখুন: [Clojure CLI ইনস্টলেশন](https://clojure.org/guides/getting_started#_installation_on_linux)।

### Mac OS X-এর জন্য Homebrew
আপনার Homebrew আপডেট করুন:

``` bash
$ brew update
```

Clojure CLI ইনস্টল করুন:
``` bash
$ brew install node clojure/tools/clojure
```

node এনভায়রনমেন্টের জন্য `Node` প্রয়োজন।

## ইনস্টলেশন পরীক্ষা করা

ইনস্টলেশনটি ঠিকভাবে হয়েছে কিনা পরীক্ষা করতে `clojure --help` রান করুন; সবকিছু ঠিকঠাক থাকলে এটি আপনাকে ভার্সনটি দেখাবে।

```bash
$ clojure --help
Version: 1.10.1.547
...
```
