# বিবরণ

বেশিরভাগ প্রোগ্রামিং ভাষার মতোই Gleam-এও "সাইড ইফেক্ট" আছে, তাই ফাংশন একটি মান রিটার্ন করার পাশাপাশি বিশ্বের অবস্থা পড়তে ও পরিবর্তন করতে পারে।

Gleam স্ট্যান্ডার্ড লাইব্রেরির `gleam/io` মডিউলটি কনসোলে স্ট্রিং প্রিন্ট করার ফাংশন সরবরাহ করে।

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

অন্য প্যাকেজগুলো IO-এর আরও ফাংশন সরবরাহ করতে পারে, যেমন `simplifile`, যা ফাইল পড়া ও লেখার ফাংশন দেয়।

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
