# নির্দেশনার সংযোজন

## রেজিস্টারসমূহ

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | যে স্বাভাবিক সংখ্যাটিকে মৌলিক গুণনীয়কে বিশ্লেষণ করতে হবে |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | মৌলিক গুণনীয়কগুলোর জন্য গন্তব্য অ্যারে |
| `$v0`    | আউটপুট       | ইন্টিজার | গুণনীয়কের সংখ্যা |
| `$t0-9`  | অস্থায়ী     | যেকোনো | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত হয় |
