# নির্দেশনা

আপনি একজন আগ্রহী পাখি-পর্যবেক্ষক, যিনি গত সাত দিনে আপনার বাগানে কত পাখি এসেছে তার হিসাব রাখেন।

আপনার হাতে ছয়টি কাজ, সবগুলোই আপনার বাগানে আসা পাখির সংখ্যা নিয়ে।

## 1. আজ কত পাখি এসেছে, তা দেখুন

আজ আপনার বাগানে কত পাখি এসেছে তা রিটার্ন করার জন্য `today()` ফাংশনটি ইমপ্লিমেন্ট করুন।
পাখির সংখ্যাগুলো দিন অনুযায়ী সাজানো, যেখানে প্রথম এলিমেন্টটি সবচেয়ে পুরোনো দিনের সংখ্যা আর শেষ এলিমেন্টটি আজকের সংখ্যা।

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> today(birds_per_day)
1
```

## 2. আজকের সংখ্যা এক বাড়ান

আজকের সংখ্যা এক বাড়ানোর জন্য `increment_todays_count()` ফাংশনটি ইমপ্লিমেন্ট করুন:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> increment_todays_count(birds_per_day)
[2, 5, 0, 7, 4, 2]
```

## 3. কোনো দিন একটিও পাখি আসেনি কি না, তা দেখুন

`has_day_without_birds()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `true` রিটার্ন করে যদি এমন কোনো দিন থাকে যেদিন বাগানে একটিও পাখি আসেনি; অন্যথায় `false` রিটার্ন করে:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> has_day_without_birds(birds_per_day)
true
```

## 4. সপ্তাহের প্রথম কয়েক দিনে আসা পাখির সংখ্যা হিসাব করুন

`count_for_first_days()` ফাংশনটি ইমপ্লিমেন্ট করুন, যা সপ্তাহের শুরু থেকে আপনার বাগানে আসা পাখির সংখ্যা রিটার্ন করে, তবে হিসাবটি সপ্তাহের শুরু থেকে নির্দিষ্ট সংখ্যক দিনের মধ্যে সীমিত রাখে।

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> count_for_first_days(birds_per_day, 4)
14
```

## 5. ব্যস্ত দিনের সংখ্যা হিসাব করুন

কিছু দিন অন্যদিনের চেয়ে ব্যস্ত থাকে।
ব্যস্ত দিন বলতে সেই দিনকে বোঝায়, যেদিন পাঁচটি বা তার বেশি পাখি আপনার বাগানে এসেছে।
ব্যস্ত দিনের সংখ্যা রিটার্ন করার জন্য `busy_days()` ফাংশনটি ইমপ্লিমেন্ট করুন:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> busy_days(birds_per_day)
2
```

## 6. সপ্তাহের প্রতিটি বারের গড় হিসাব করুন

আপনি একাধিক সপ্তাহের হিসাব রেখে নিজের রেকর্ড বাড়ানোর সিদ্ধান্ত নিলেন।
প্রতিটি ক্ষেত্রেই সংখ্যাগুলো সপ্তাহের বার অনুযায়ী সাজানো, প্রথম এন্ট্রি সোমবার আর শেষ এন্ট্রি রবিবার।

দুই সপ্তাহের গড় রিটার্ন করার জন্য `average_per_day()` ফাংশনটি ইমপ্লিমেন্ট করুন।

```julia-repl
julia> week1 = [7, 2, 9, 1, 3, 0, 10]
julia> week2 = [2, 6, 4, 1, 3, 8, 9]
julia> average_per_day(week1, week2)
[4.5, 4.0, 6.5, 1.0, 4.0, 3.0, 9.5]
```
