# রেঞ্জ

[রেঞ্জ][range] দুইটি মানের মধ্যবর্তী একটি ব্যবধান বোঝায়।
রেঞ্জ সমর্থন করে এমন সবচেয়ে কমন টাইপগুলো হলো `Integer` ও `String`.
এগুলো অনেক কাজে ব্যবহার করা যায়, যেমন দ্রুত একটি কালেকশন তৈরি করা, স্ট্রিং স্লাইস করা, কোনো মান রেঞ্জের মধ্যে আছে কি না তা যাচাই করা, আর ইটারেশন।
এগুলো তৈরি করা হয় রেঞ্জ অপারেটর `..` বা `...` দিয়ে (যথাক্রমে শেষ মানসহ ও শেষ মান ছাড়া)।

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

রেঞ্জ অপারেটর দুইটি থাকার কারণ হলো, শেষ মানটি রেঞ্জে থাকবে কি থাকবে না তা বেছে নেওয়ার সুযোগ দেওয়া, যা কাজে লাগে যেমন শূন্য-ভিত্তিক ইনডেক্স নিয়ে কাজ করার সময়।

`Range` ইনিশিয়ালাইজার ব্যবহার করেও রেঞ্জ তৈরি করা যায়।

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Ruby-তে `..` বা `...` রেঞ্জ অপারেটর দিয়ে রেঞ্জ তৈরি করার সময় যদি আপনি সেই রেঞ্জের উপর কোনো মেথড কল করতে চান, তাহলে রেঞ্জটিকে বন্ধনীর মধ্যে রাখতে হবে।
কারণ অন্যথায় মেথডটি রেঞ্জ অপারেটরের দ্বিতীয় আর্গুমেন্টের উপর কল হবে।

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## সাবস্ট্রিং বের করা

কোনো স্ট্রিং স্লাইস করতে চাইলে রেঞ্জ অপারেটর ব্যবহার করে একটি সাবস্ট্রিং পেতে পারেন।
অর্থাৎ সাবস্ট্রিংয়ের শুরু ও শেষ ইনডেক্স দিয়ে একটি রেঞ্জ তৈরি করে।

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

স্ট্রিংয়ের শেষ থেকে সাবস্ট্রিং পেতে নেগেটিভ ইনডেক্সও ব্যবহার করতে পারেন।

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## রেঞ্জের মেথড

রেঞ্জের কিছু মেথড আছে যেগুলো দিয়ে এদের নিয়ে কাজ করা যায়।
যেমন এসব মেথড দিয়ে রেঞ্জের সব মানের যোগফল বের করা যায় বা রেঞ্জে কোনো মান আছে কি না তা যাচাই করা যায়।

| Method                  | Description                                                             | Example                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | রেঞ্জের সব মানের যোগফল রিটার্ন করে                                       | `(1..5).sum # => 15`            |
| [`size`][size]          | রেঞ্জের সাইজ রিটার্ন করে                                                | `(1..5).size # => 5`            |
| [`include?`][indlude]   | রেঞ্জে প্রদত্ত মানটি থাকলে `true`, নাহলে `false` রিটার্ন করে             | `(1..5).include?(3) # => true` |

## শেষহীন ও শুরহীন রেঞ্জ

একটি রেঞ্জ শেষহীন বা শুরহীন হতে পারে।
শেষহীন বা শুরহীন রেঞ্জের শুরু বা শেষ মান হয় `nil`, তবে রেঞ্জ ডিফাইন করার সময় `nil` বাদ দেওয়া যায়।

শুরহীন ও শেষহীন রেঞ্জ ব্যবহার করা কাজে লাগে যখন আপনি, যেমন, কোনো স্ট্রিং শুরুর দিক থেকে বা শেষ পর্যন্ত স্লাইস করতে চান।

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
কোনো কালেকশনের উপর ব্যবহার না করলে, সাবধানতা ছাড়া শেষহীন রেঞ্জ একটি শেষহীন সিকোয়েন্স তৈরি করতে পারে।
~~~~

## স্ট্রিং রেঞ্জ

রেঞ্জে স্ট্রিংও ব্যবহার করা যায়, এবং এভাবে দুইটি স্ট্রিংয়ের মধ্যবর্তী স্ট্রিংগুলোর একটি ব্যবধান পাওয়া যায়।
কিছু কিছু স্ট্রিং ব্যবহার করলে এর আচরণ একটু অপ্রত্যাশিত হতে পারে, তাই সাবধানতার সাথে ব্যবহার করুন।

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
