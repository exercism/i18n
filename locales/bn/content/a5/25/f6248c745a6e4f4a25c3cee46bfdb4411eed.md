# সম্পর্কে

পাইথনে একটি ডিকশনারি (`dict`) হলো এমন একটি ডেটা স্ট্রাকচার, যা [হ্যাশেবল][term-hashable] _কী (key)_-এর সাথে _মান_ যুক্ত করে। অন্য প্রোগ্রামিং ভাষায় এটিকে আকার পরিবর্তনযোগ্য [হ্যাশ টেবিল][hashtable-wikipedia], হ্যাশম্যাপ বা [অ্যাসোসিয়েটিভ অ্যারে][associative-array] নামে জানা যায়। ডিকশনারি পাইথনের একমাত্র বিল্ট-ইন [ম্যাপিং টাইপ][mapping-types-dict]।

`keys` অবশ্যই হ্যাশেবল হতে হবে এবং ডিকশনারি জুড়ে অনন্য হতে হবে। কী (key)-এর টাইপের মধ্যে থাকতে পারে `number`s, `str`s বা `tuple`s (_ইমিউটেবল_ মানের)। এগুলোতে _মিউটেবল_ ডেটা স্ট্রাকচার যেমন `list`s, `dict`s বা `set`s থাকতে পারে না। পাইথন 3.7 থেকে, `dict`-এর কী (key)-এর ক্রম এন্ট্রি যেভাবে যোগ করা হয় সেই ক্রমেই নিশ্চিত করা হয়।

`values` যেকোনো ডেটা টাইপ বা স্ট্রাকচারের হতে পারে। মানগুলো _যথেচ্ছভাবে_ নেস্টও হতে পারে, তাই এতে অ্যারে-এর ভেতরে অ্যারে, সাব-ডিকশনারি এবং অন্য কাস্টম বা যৌগিক ডেটা স্ট্রাকচার থাকতে পারে।

একটি `key` দিলে ডিকশনারি (গড়ে) ধ্রুবক সময়ে একটি `value` বের করতে পারে (_এন্ট্রির সংখ্যা নির্বিশেষে_)। একটি `list` বা `array`-এর ভেতরে মান খোঁজার (_`index` অবস্থান না জেনে_) তুলনায় একটি `dict` উল্লেখযোগ্যভাবে বেশি মেমরি ব্যবহার করে, কিন্তু অনেক দ্রুত মান বের করে।

বিশেষত এমন পরিস্থিতিতে ডিকশনারি দারুণ উপযোগী, যেখানে উপাদানের সংগ্রহ বড় হয় এবং সেগুলো ঘন ঘন অ্যাক্সেস ও আপডেট করতে হয়।


## ডিকশনারি তৈরি

ডিকশনারি অনেক ভিন্ন উপায়ে তৈরি করা যায়, যেমন:
 - [`fromkeys()`][fromkeys] ক্লাস মেথড ব্যবহার করে।
 - [ডিকশনারি কম্প্রিহেনশন][dict-comprehensions] ব্যবহার করে।
 - আনপ্যাকিং (`**`) দিয়ে দুটি ডিকশনারি একত্র করা।
 - `|` (_আপডেট_) অপারেটর দিয়ে ডিকশনারি একত্র করা।
 - লুপ ব্যবহার করে আগে তৈরি করা একটি খালি `dict`-এ ধাপে ধাপে এন্ট্রি যোগ করা।

সবচেয়ে সোজা দুটি পদ্ধতি হলো ডিকশনারি _কনস্ট্রাক্টর_ এবং ডিকশনারি _লিটারাল_।

### ডিকশনারি কনস্ট্রাক্টর

`dict()` (_`dict` ক্লাসের কনস্ট্রাক্টর_) `key`, `value` জোড়ার যেকোনো ইটারেবল-এর সাথে ব্যবহার করা যায়। এছাড়া ধারাবাহিক `<name>=<value>` _আর্গুমেন্ট_ দিয়েও এটি কল করা যায়:

```python
# Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),
...              ('speed', 23),
...              ('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


# Using key=value arguments.
>>> bear = dict(name="Black Bear",
...             speed=40,
...             land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

`dict` সম্পর্কিত [ডকুমেন্টেশন][dicts-docs]-এ কনস্ট্রাক্টর ব্যবহারের আরও কিছু ভিন্নতা ও বিকল্প তুলে ধরা হয়েছে।


### ডিকশনারি লিটারাল

একটি ডিকশনারি সরাসরি _ডিকশনারি লিটারাল_ হিসেবেও লেখা যায়, যেখানে দ্বিতীয় বন্ধনী (`{}`) দিয়ে `key : value` জোড়া ঘেরা হয়। `{}`-এর ভেতরে থাকা এন্ট্রিগুলো আলাদা আলাদা লাইনে-ও লেখা যায়:

```python
>>> whale = {"name": "Blue Whale", 
             "speed": 35, 
             "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}

>>> wombat = {'name': 'Wombat',
              'speed': 23,
              'land_animal': True,
              'color': 'Brindle'}

>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True, 'color': 'Brindle'}
```

ডিকশনারি যথেচ্ছভাবে নেস্ট করা যায়:

animals = {

## একটি `dict`-এ মান অ্যাক্সেস করা

তৃতীয় বন্ধনীর ভেতরে একটি _কী (key)_ ব্যবহার করে আপনি ডিকশনারির একটি `value` অ্যাক্সেস করতে পারেন। ডিকশনারিতে কোনো কী (key) না থাকলে একটি `KeyError` উত্থাপিত হয়:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

`get(<key>, <default value>)` মেথড দিয়ে একটি এন্ট্রি অ্যাক্সেস করলে `KeyError` এড়ানো যায়:

```python
>>> bear.get("color", 'not found')
'not found'
```

### নেস্টেড ডিকশনারি এন্ট্রি অ্যাক্সেস করা

নেস্টেড ডিকশনারির এন্ট্রি অ্যাক্সেস করতে ধারাবাহিকভাবে বন্ধনী ব্যবহার করুন। কোনো নির্দিষ্ট কী (key) না থাকলে স্বাভাবিকভাবে KeyError উত্থাপিত হবে:

```python
# Using the animals nested dictionary.
>>> animals["Real"]["winged"]["Kestrel"]["speed"]
15

>>> animals["Imaginary"]["winged"]["Kestrel"]["speed"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'Kestrel'
```

`KeyError` এড়াতে `.get()` ব্যবহার করা যায়, তবে `.get()`-এর কলগুলো _চেইন_ করতে হবে:

```python
# Using the animals nested dictionary.
# Note the use of parenthesis to enable placing the 
# .get() calls on separate lines.
>>> (animals.get("Imaginary", {})
            .get("Legged", {})
            .get("Sphinx", {})
            .get("Color", "I have no idea!"))
'I have no idea!'
```

## ডিকশনারির মান পরিবর্তন বা যোগ করা

এন্ট্রির _কী (key)_-তে অ্যাসাইন করে আপনি একটি `value` পরিবর্তন করতে পারেন:

```python
# Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

একইভাবে নতুন `key`:`value` জোড়া _যোগ_ করা যায়:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```


## ডিকশনারি এন্ট্রি মুছে ফেলা (pop করা ও del)

ডিকশনারির একটি এন্ট্রি মুছে ফেলতে আপনি `<dict>.pop(<key>)` মেথড ব্যবহার করতে পারেন। `<dict>.pop()` (`key`, `value`) জোড়াটি সরিয়ে দেয় এবং ব্যবহারের জন্য `value` রিটার্ন করে। `<dict>.get()`-এর মতো `<dict>.pop(<key>)`-ও একটি দ্বিতীয় আর্গুমেন্ট (_`<dict>.pop(<key>, <default value>)`_) নেয়, যা `key` না পাওয়া গেলে রিটার্ন করা হয়। এতে একটি `KeyError` উত্থাপিত হওয়া আটকে যায়:

```python
# Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


# The "name" key is now removed from the dictionary.
# Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


# Using a default argument with .pop() will 
# prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

এক বা একাধিক এন্ট্রি মুছে ফেলতে `del` স্টেটমেন্ট-ও ব্যবহার করা যায়। মুছে ফেলার এন্ট্রিটি ডিকশনারিতে না থাকলে একটি `KeyError` উত্থাপিত হয়:

```python
>>> wombat = {'name': 'Wombat',
              'speed': 23,
              'land_animal': True,
              'color': 'Brindle',
              'talent': 'Singing',
              'size': 'small'}

# Remove a single entry from the dictionary.
>>> del wombat["color"]
>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True, 'talent': 'Singing', 'size': 'small'}


# Remove multiple entries from the dictionary.
>>> del wombat["talent"], wombat["size"]
>>> wombat
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


# Attempting a deletion of a non-existent key raises a KeyError
>>> del wombat["number_of_legs"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'number_of_legs'
```

## ডিকশনারির মধ্য দিয়ে লুপ করা/ইটারেশন করা

`for item in dict` বা `while item` দিয়ে ডিকশনারির মধ্য দিয়ে লুপ করলে ডিফল্টভাবে _কী (key)_-গুলোর উপর ইটারেশন হয়। একই লুপের ভেতরে _তৃতীয় বন্ধনী_ ব্যবহার করে _মান_ অ্যাক্সেস করতে পারেন:

```python
>>> for key in bear:
...     print((key, bear[key])) # <--This prints a tuple of (key, value).
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

আপনি `.items()` মেথড-ও ব্যবহার করতে পারেন, যা (`key`, `value`) টাপল রিটার্ন করে:

```python
# dict.items() forms (key, value tuples) that can be 
# unpacked and iterated over.
>>> for key, value in whale.items():
...     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

একইভাবে, `.keys()` `keys` রিটার্ন করবে এবং `.values()` `values` রিটার্ন করবে।

পাইথনে ডিকশনারি সম্পর্কে বিস্তারিত জানতে [অফিসিয়াল ডকুমেন্টেশন][dicts-docs] চমৎকার একটি সূচনা, অথবা [W3-Schools][how-to-dicts] টিউটোরিয়ালটিও দেখতে পারেন।


## ডিকশনারির কার্যকারিতা বাড়ানো: Collections মডিউল

[`collections`][collections-docs] মডিউল পাইথনের স্ট্যান্ডার্ড কালেকশন-ভিত্তিক ডেটা টাইপগুলোতে (`dict`, `set`, `list`, `tuple`) বিশেষ কার্যকারিতা যোগ করে। সবচেয়ে উপযোগী তিনটি ডিকশনারি-ভিত্তিক ক্লাস হলো:

- [`Counter`][counter-dicts] স্বয়ংক্রিয়ভাবে উপাদান গণনা করে এবং সেগুলো একটি `dict`-এ রিটার্ন করে, যেখানে উপাদানগুলো কী (key) আর তাদের গণনা মান হিসেবে থাকে।
- [`OrderedDict`][ordered-dicts-docs]-এ ডিকশনারি এন্ট্রির ক্রম সাজানোর জন্য বিশেষায়িত মেথড রয়েছে।
- [`defaultdict`][default-dicts] একটি ফ্যাক্টরি মেথড ব্যবহার করে ডিফল্ট মান সেট করে, যখন কোনো ডিকশনারি এন্ট্রি বের করতে বা অ্যাসাইন করতে গিয়ে একটি `key` না পাওয়া যায়।
