# টেস্ট

## Exercism GDScript ট্র্যাকের টেস্ট রানার ইনস্টল করা

টেস্ট রানার ব্যবহার করতে হলে আপনার [Godot সঠিকভাবে ইনস্টল করা][installation] থাকা দরকার।

Exercism-এর জন্য GDScript স্ক্রিপ্ট বিল্ড ও টেস্ট করতে, CLI থেকে Godot-কে "হেডলেস" মোডে রান করা হবে।
এই নির্দেশাবলির জন্য বর্তমানে Linux আর bash প্রয়োজন।

### ধাপ ১: সামগ্রিক টেস্ট রানার অবকাঠামো ইনস্টল করা

টেস্টের প্রস্তুতি নিতে [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] ক্লোন করুন এবং এর ভেতরের বিষয়বস্তু `/opt/test-runner/`-এ সরিয়ে নিন:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### ধাপ ২: একক-অনুশীলনীর টেস্ট রানার স্ক্রিপ্ট ডাউনলোড করা

ধরে নিচ্ছি আপনার `exercism` টুল সেট আপ করা আছে এবং আপনি অন্তত একটি GDScript অনুশীলনী ডাউনলোড করেছেন, তাহলে এটি অনুশীলনীগুলো রাখার জন্য একটি `exercism/gdscript` ফোল্ডার তৈরি করেছে।
এই ফোল্ডারে [টেস্ট রানারটি][test-local-gdscript-solution] সেভ করুন এবং ফাইলটি এক্সিকিউটেবল হিসেবে চিহ্নিত করুন, অথবা শুধু এটির একটি লিংক তৈরি করুন:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## টেস্ট চালানো

ইনস্টলের ধাপগুলো শেষ হলে, আপনি যেকোনো অনুশীলনীর ডিরেক্টরি থেকে (যেমন `~/exercism/gdscript/two-fer`) শুরু করে স্ক্রিপ্টটি চালাতে পারবেন (যেটি এক ধাপ উপরে, `../`-এ আছে), যাতে ওই অনুশীলনীর আপনার লোকাল সমাধান টেস্ট করতে পারেন:

```sh
../test-local-gdscript-solution.sh
```
