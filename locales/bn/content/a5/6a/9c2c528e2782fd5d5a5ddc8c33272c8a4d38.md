# পরিচিতি

Factor-এর ক্যারেক্টার হলো ইন্টিজার, অর্থাৎ Unicode কোড পয়েন্ট। তাই সংখ্যাগত `<`, `>`, `=` তুলনা সরাসরি কেস-সেনসিটিভ ক্রম দেয়। [`unicode`][unicode] ভোকাবুলারি এতে যোগ করে Unicode-সচেতন প্রেডিকেট আর একক-ক্যারেক্টারের কেস কনভার্সন।

## ক্যারেক্টার প্রেডিকেট

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## কেস কনভার্সন

`ch>upper` আর `ch>lower` একটি ক্যারেক্টারের কেস উল্টে দেয়। আর স্ট্রিং-স্তরের `>upper` ও `>lower` এগুলো একটি স্ট্রিংয়ের প্রতিটি ক্যারেক্টারে প্রয়োগ করে।

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` পুরো একটি স্ট্রিংকে ছোট হাতের অক্ষরে নামিয়ে আনে, তারপর তার প্রথম ক্যারেক্টারটিকে বড় হাতের অক্ষরে তোলে। এটি একটি একক শব্দের টাইটেল কেস:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## ক্যারেক্টার লিটারাল

`CHAR: A` পার্স করে `A`-এর ইন্টিজার কোড পয়েন্ট দেয়। নামযুক্ত ক্যারেক্টারের জন্য `space`, `tab`, `\n` ইত্যাদি নাম ব্যবহার করুন:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## সিম্বল

যখন কোনো ওয়ার্ডকে মানের বদলে একটি ট্যাগ রিটার্ন করতে হয়, যেমন বুলিয়ানের বদলে `yes`/`no`/`maybe`, তখন প্রতিটি ট্যাগকে *সিম্বল* হিসেবে ঘোষণা করুন। সিম্বল হলো এমন একটি ওয়ার্ড, যা কল করা হলে নিজেকেই স্ট্যাকে তোলে, আর দুটি সিম্বল তখনই সমান হয় যখন তাদের নাম একই হয়।

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` একটি ঘোষণা করে; `SYMBOLS: a b c ;` একাধিক ঘোষণা করে।
