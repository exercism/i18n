# নির্দেশনার পরিশিষ্ট

## রিজার্ভড মেমরি

ইনপুট স্ট্রিংয়ের বাফারটি লিনিয়ার মেমরির ৬৪-১৯১ বাইট ব্যবহার করে।

## ইনপুট ফরম্যাট

ইনপুটটি তিনটি লাইনের একটি একক স্ট্রিং হিসেবে আসে, যার প্রতিটির শেষে একটি লাইন ব্রেক থাকে। ক্রস ও নট সবসময় বড় হাতের `X` এবং `O` হবে।

তাহলে বোর্ডটি

```
X··
OXO
XOX
```
এভাবে এনকোড করা হবে

```
"X  \nOXO\nXOX\n"
```
