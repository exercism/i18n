# ভূমিকা

JavaScript একটি ডাইনামিক ভাষা, যা অবজেক্ট-ওরিয়েন্টেড, ইম্পারেটিভ এবং ডিক্লেরেটিভ (যেমন ফাংশনাল প্রোগ্রামিং) স্টাইল সমর্থন করে।

## (পুনরায়) অ্যাসাইনমেন্ট

JavaScript-এ নামের সাথে মান অ্যাসাইন করার কয়েকটি প্রধান উপায় আছে, সেগুলো হলো ভ্যারিয়েবল বা কনস্ট্যান্ট ব্যবহার করা। Exercism-এ ভ্যারিয়েবল সবসময় [camelCase][wiki-camel-case] স্টাইলে লেখা হয়; কনস্ট্যান্ট লেখা হয় [SCREAMING_SNAKE_CASE][wiki-snake-case] স্টাইলে। এটি মেনে চলার মতো কোনো অফিসিয়াল গাইড নেই, আর বিভিন্ন কোম্পানি ও প্রতিষ্ঠানের স্টাইল গাইডও ভিন্ন ভিন্ন। _ভ্যারিয়েবল আপনি যেভাবে খুশি লিখতে পারেন_। অনুশীলনীগুলো যেভাবে তৈরি করা হয়েছে সেভাবে লিখলে সুবিধা হলো, ওয়েব ইন্টারফেসে এবং বেশিরভাগ IDE-তে সেগুলো আলাদাভাবে হাইলাইট হবে।

JavaScript-এ ভ্যারিয়েবল [`const`][mdn-const], [`let`][mdn-let] বা [`var`][mdn-var] কিওয়ার্ড দিয়ে ডিফাইন করা যায়।

`let` বা `var` ব্যবহার করলে একটি ভ্যারিয়েবল তার পুরো জীবনকালে বিভিন্ন মান রেফার করতে পারে। উদাহরণস্বরূপ, অ্যাসাইনমেন্ট অপারেটর `=` দিয়ে `myFirstVariable`-কে অনেকবার ডিফাইন ও পুনরায় ডিফাইন করা যায়:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let` ও `var`-এর বিপরীতে, `const` দিয়ে ডিফাইন করা ভ্যারিয়েবলে কেবল একবারই অ্যাসাইন করা যায়। JavaScript-এ কনস্ট্যান্ট ডিফাইন করতে এটি ব্যবহার করা হয়।

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 পরবর্তী একটি শেখার অনুশীলনীতে _কনস্ট্যান্ট_ অ্যাসাইনমেন্ট / বাইন্ডিং এবং _কনস্ট্যান্ট_ মানের মধ্যে পার্থক্য খতিয়ে দেখা ও ব্যাখ্যা করা হয়।

## ফাংশন ডিক্লারেশন

JavaScript-এ কার্যকারিতার এককগুলো _ফাংশনে_ মোড়ানো থাকে; সাধারণত যে ফাংশনগুলো একসাথে থাকা উচিত সেগুলোকে একই ফাইলে একত্র করা হয়। এই ফাংশনগুলো প্যারামিটার (আর্গুমেন্ট) নিতে পারে, আর `return` কিওয়ার্ড দিয়ে একটি মান _রিটার্ন_ করতে পারে। ফাংশন কল করা হয় `()` সিনট্যাক্স দিয়ে।

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 JavaScript-এ একটি ফাংশন ডিক্লার করার _অনেক_ ভিন্ন উপায় আছে। এই অন্য উপায়গুলো `function` কিওয়ার্ড ব্যবহারের চেয়ে আলাদা দেখতে। ট্র্যাকটি ধীরে ধীরে সেগুলোর সাথে পরিচয় করানোর চেষ্টা করে, তবে আপনি যদি ইতিমধ্যে সেগুলো সম্পর্কে জানেন, তাহলে যেকোনোটি নির্দ্বিধায় ব্যবহার করতে পারেন। বেশিরভাগ ক্ষেত্রে একটি বা অন্যটি ব্যবহার করা ভালো বা খারাপ কিছু নয়।

## অন্য ফাইলে এক্সপোজ করা

একটি `function`, কনস্ট্যান্ট বা ভ্যারিয়েবলকে _অন্য ফাইলগুলোতে_ ব্যবহারযোগ্য করতে হলে `export` কিওয়ার্ড দিয়ে সেগুলোকে [এক্সপোর্ট][mdn-export] করতে হয়। এরপর আরেকটি ফাইল `import` কিওয়ার্ড দিয়ে এগুলো [ইমপোর্ট][mdn-import] করতে পারে। এটিকে মডিউল সিস্টেমও বলা হয়। এর একটি চমৎকার উদাহরণ হলো সব টেস্ট যেভাবে কাজ করে। প্রতিটি অনুশীলনীতে অন্তত একটি ফাইল থাকে, যেমন `lasagna.js`, যেটিতে _ইমপ্লিমেন্টেশন_ থাকে। এছাড়া অন্তত আরেকটি ফাইল থাকে, যেমন `lasagna.spec.js`, যেটিতে _টেস্ট_ থাকে। এই ফাইলটি ইমপ্লিমেন্টেশন পরীক্ষা করার জন্য পাবলিক (অর্থাৎ এক্সপোর্ট করা) এনটিটিগুলো _ইমপোর্ট_ করে:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
