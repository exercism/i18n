# নির্দেশনার সংযোজন

## এক্সেপশন মেসেজ

কখনও কখনও [এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটা করার সময় আপনার সর্বদা একটি **অর্থবহ এরর মেসেজ** যোগ করা উচিত, যাতে বোঝা যায় এররটির উৎস কী। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং Debug করতে অনেক সুবিধা হয়। এমন পরিস্থিতিতে যেখানে আপনি জানেন যে এররের উৎসটি একটি নির্দিষ্ট টাইপ হবে, আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যোগ করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে একটি `ValueError` "থ্রো" করতে আপনার [raise স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করা আবশ্যক। আপনি যদি `exception` `raise` করেন এবং এর সাথে একটি মেসেজও যোগ করেন, তবেই টেস্টগুলো পাস করবে।

একটি মেসেজসহ `ValueError` রেইজ করতে, `exception` টাইপের আর্গুমেন্ট হিসেবে মেসেজটি লিখুন:

```python
raise ValueError("A meaningful error message here.")
```
