# নির্দেশনার সংযোজন

## এক্সেপশন মেসেজ

কখনও কখনও [এক্সেপশন রেইজ করা][raising-exceptions] প্রয়োজন হয়।
এটা করলে, এররটির উৎস কী তা বোঝাতে আপনার সবসময় একটি **অর্থবহ এরর মেসেজ** যুক্ত করা উচিত।
এতে আপনার কোড আরও পড়ার উপযোগী হয় এবং ডিবাগিংয়ে যথেষ্ট সাহায্য করে।
যেসব ক্ষেত্রে আপনি জানেন এররের উৎসটি একটি নির্দিষ্ট টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপগুলোর][error-base-classes] একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যুক্ত করা উচিত।


একটি বৈধ `Tic Tac Toe` গেম শেষ হয় যখন একজন খেলোয়াড় জিতে যায়।
দুজন খেলোয়াড়ই যদি জয়ী অবস্থায় থাকে, তবে এই অনুশীলনীটি আশা করে যে আপনি [raise স্টেটমেন্ট][raise] ব্যবহার করে আপনার সমাধানে একটি `ValueError` "থ্রো" করবেন।
একজন খেলোয়াড় পরপর দুটি চাল খেলেছে বলে বিবেচিত হলে, অথবা তাকে দ্বিতীয় চাল খেলার জন্য নির্ধারিত করা হয়েছিল অথচ সে প্রথম চাল খেলেছিল বলে বিবেচিত হলে, আপনার কোড থেকে একটি `ValueError` থ্রো করার প্রত্যাশাও করা হয়।


একটি মেসেজ-সহ `ValueError` রেইজ করতে, ওই মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

টেস্টগুলো এরর মেসেজটি হুবহু মিলিয়ে দেখবে, তাই প্রত্যাশিত ফলাফলগুলো মনোযোগ দিয়ে পড়ুন।
