# ভূমিকা

Ruby-তে **অ্যারে** হলো যেকোনো অবজেক্টের সাজানো, ইন্টিজার-ইনডেক্সযুক্ত সংগ্রহ।
অ্যারে ইনডেক্সিং শুরু হয় `0` থেকে।
একটি ঋণাত্মক ইনডেক্স অ্যারের শেষ প্রান্ত থেকে গণনা করা হয়। অর্থাৎ `-1` ইনডেক্সটি অ্যারের শেষ এলিমেন্ট বোঝায়, `-2` হলো অ্যারের শেষের আগের এলিমেন্ট, ইত্যাদি।
Ruby-এর অ্যারে [Enumerable মডিউল][enumerable-module] মিশিয়ে নেয়, যা একাধিক ট্রাভার্সাল ও সার্চিং মেথড এবং সাজানোর ক্ষমতা যোগ করে।

## অ্যারে তৈরি করা

- Ruby-এর একটি অ্যারেতে ভিন্ন ভিন্ন টাইপের অবজেক্ট থাকতে পারে।

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## এলিমেন্ট অ্যাসাইনমেন্ট

ইনডেক্স ব্যবহার করে এলিমেন্ট অ্যাক্সেস বা পরিবর্তন করা যায়।
একটি শুরুর ইনডেক্স আর একটি সাইজ উল্লেখ করে সাবঅ্যারে অ্যাক্সেস করা যায়।

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- ঋণাত্মক ইনডেক্স অ্যারের শেষ থেকে পিছনের দিকে গণনা করে।

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## এলিমেন্ট রেফারেন্স

- অ্যারের এলিমেন্ট #[] মেথড দিয়ে পাওয়া যায়।
- এটি নির্দিষ্ট ইনডেক্সের এলিমেন্ট রিটার্ন করে, অথবা শুরুর ইনডেক্স থেকে শুরু করে length সংখ্যক এলিমেন্ট নিয়ে একটি সাবঅ্যারে রিটার্ন করে।

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- ঋণাত্মক ইনডেক্স অ্যারের শেষ থেকে পিছনের দিকে গণনা করে (-1 হলো শেষ এলিমেন্ট)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## অ্যারে সম্পর্কে তথ্য পাওয়া

অ্যারে সব সময় নিজের length-এর হিসাব রাখে।
অ্যারেতে কতগুলো এলিমেন্ট আছে তা জানতে length, count বা size ব্যবহার করুন।

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## অ্যারেতে আইটেম যোগ করা

`push` বা `<<` ব্যবহার করে অ্যারের শেষে আইটেম যোগ করা যায়:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## অ্যারে থেকে আইটেম সরানো

pop মেথডটি অ্যারের শেষ এলিমেন্ট সরিয়ে ফেলে এবং সেটি রিটার্ন করে:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
