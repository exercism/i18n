# সম্পর্কে

Kotlin-এ বুলিয়ানকে প্রকাশ করা হয় `Boolean` টাইপ দিয়ে, যার মান `true` অথবা `false` হতে পারে।

Kotlin তিনটি বিল্ট-ইন [বুলিয়ান অপারেটর][reference] সমর্থন করে: `!` (নেগেশন, অর্থাৎ NOT), `&&` (লেজি কনজাংশন, অর্থাৎ AND), এবং `||` (লেজি ডিসজাংশন, অর্থাৎ OR)। `&&` এবং `||` অপারেটর _শর্ট-সার্কিট ইভালুয়েশন_ ব্যবহার করে, যার মানে হলো অপারেটরের ডান দিকের অংশটি কেবল প্রয়োজন হলেই মূল্যায়ন করা হয়।

```kotlin
true || false // => true
true && false // => false
```

তিনটি বুলিয়ান অপারেটরের প্রতিটির [_অপারেটর প্রেসিডেন্স_][precedence] আলাদা। এর ফলে, এগুলো এই ক্রমে মূল্যায়িত হয়: প্রথমে `!`, তারপর `&&`, এবং সবশেষে `||`। আপনি যদি এই নিয়মগুলো থেকে 'বেরিয়ে আসতে' চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন বন্ধনীর (`()`) ভেতরে রেখে দিতে পারেন, কারণ বন্ধনীর অপারেটর প্রেসিডেন্স আরও বেশি।

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
