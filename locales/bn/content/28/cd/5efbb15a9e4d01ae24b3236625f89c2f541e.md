# নির্দেশাবলি

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার চারটি কাজ আছে, সবগুলোই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. একটি কনস্ট্যান্টে প্রত্যাশিত বেক করার সময় সংরক্ষণ করুন

`expected_bake_time` কনস্ট্যান্টটি ডিফাইন করুন, যেটি রিটার্ন করে লাসাগনাটি ওভেনে কত মিনিট বেক করা উচিত।

রান্নার বই অনুযায়ী, লাসাগনাকে মোট ৬০ মিনিট ওভেনে থাকতে হবে।

```julia-repl
julia> expected_bake_time
60
```

## 2. মিনিটে প্রস্তুতির সময় গণনা করুন

`preparation_time` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসাগনায় আপনি যে সংখ্যক স্তর যোগ করেছেন তা নেয় এবং রিটার্ন করে লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```julia-repl
julia> preparation_time(4)
8
```

## 3. মিনিটে ওভেনে অবশিষ্ট সময় গণনা করুন

`remaining_time` ফাংশনটি ডিফাইন করুন, যেটি প্যারামিটার হিসেবে লাসাগনা ওভেনে থাকার প্রকৃত মিনিট নেয় এবং রিটার্ন করে লাসাগনাকে আরও কত মিনিট ওভেনে থাকতে হবে।

```julia-repl
julia> remaining_time(50)
10
```

## 4. মিনিটে মোট কাজের সময় গণনা করুন

`total_working_time` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসাগনায় আপনি যে সংখ্যক স্তর যোগ করেছেন, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসাগনা কত মিনিট ওভেনে আছে।

ফাংশনটি রিটার্ন করবে লাসাগনা রান্না করতে মোট কত মিনিট আপনি কাজ করেছেন, যা হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনা ওভেনে যে মিনিট ব্যয় করেছে তার যোগফল।

```julia-repl
julia> total_working_time(3, 20)
26
```
