# ভূমিকা

Clojure-এ একটি `vector` হলো শূন্য বা তার বেশি মানের একটি ক্রমিক, ইনডেক্সযুক্ত, অপরিবর্তনীয় কালেকশন। এর মানে হলো, একটি ভেক্টর একবার তৈরি হয়ে গেলে তা আর পরিবর্তন করা যায় না। ভেক্টরের উপর কাজ করার ফাংশনগুলি একটি নতুন ভেক্টর রিটার্ন করে, আর মূল ভেক্টরটি অপরিবর্তিত থাকে। একটি ভেক্টরের মানগুলি ভিন্ন ভিন্ন টাইপের হতে পারে। ভেক্টর নিচের মতো করে ডিফাইন করা যায়:

```clojure
(def empty [])
(def single-value [5])
```

ইনডেক্স ব্যবহার করে একটি ভেক্টর থেকে এলিমেন্ট পাওয়া যায়। Clojure ভেক্টরের ইনডেক্স শূন্য থেকে শুরু হয়, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

মূল ভেক্টরটি অপরিবর্তিত থাকে:

```clojure
numbers
;;=> [2 3 5]
```

আপডেট হওয়া মানটি মনে রাখতে হলে সেটি অন্যত্র পাস করতে হবে বা একটি var-এ ধরে রাখতে হবে:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
