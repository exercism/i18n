# সম্পর্কে

C++-এর বিল্ট-ইন সংখ্যা টাইপগুলোকে মূলত ইন্টিজার আর ফ্লোটিং-পয়েন্টে ভাগ করা যায়।

ইন্টিজার হলো পূর্ণসংখ্যা, যেমন `0`, `691` বা `-2`।

ফ্লোটিং-পয়েন্ট সংখ্যা হলো দশমিক বিন্দুসহ সংখ্যা, যেমন `6.02214076`, `0.1` বা `-1.616`।

## ইন্টিজার

নিচের উদাহরণে চারটি ভিন্ন ভ্যারিয়েবলের ডিক্লারেশন ও ইনিশিয়ালাইজেশন দেখানো হয়েছে

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

কোনো `int` ভ্যারিয়েবলে মান অ্যাসাইন করার সময় সরাসরি একটি লিটারাল ব্যবহার করতে পারেন।
লিটারাল হলো কোডে সরাসরি লেখা একটি সংখ্যা, যেমন `9241`।
রিপ্রেজেন্টেশনের বিভিন্ন ভিত্তির জন্য আলাদা আলাদা ইন্টিজার লিটারাল রয়েছে।
দশমিক ইন্টিজার লিটারাল সবচেয়ে কমন, এগুলোতে `0` থেকে `9` পর্যন্ত অঙ্ক ব্যবহার করা হয়।
`0x`-এর মতো একটি বিশেষ প্রিফিক্স যোগ করে অন্য ভিত্তিও ব্যবহার করা যায়।
উপরের উদাহরণে `9421` সংখ্যাটিকে তার চারটি রিপ্রেজেন্টেশন ও প্রিফিক্সসহ দেখানো হয়েছে।
সব ভ্যারিয়েবলই একই মানে ইনিশিয়ালাইজ করা হয়েছে।

বিভিন্ন রিপ্রেজেন্টেশন সিস্টেম সম্পর্কে আরও বিস্তারিত জানতে [একটি ছোট টিউটোরিয়াল][cpp_numerical_bases] দেখে নিতে পারেন।

সহজে পড়ার সুবিধার জন্য অ্যাপোস্ট্রফি দিয়ে অঙ্কগুলো আলাদা করতে পারেন।
`9'241`-এর মান `0b0100'100'0001'1001` বা `92'4'1`-এর সমান।

## ফ্লোটিং-পয়েন্ট সংখ্যা

ফ্লোটিং-পয়েন্ট লিটারাল মূলত দুই ধরনের হয়।
সহজবোধ্য `0.0024` ছাড়াও এর সায়েন্টিফিক নোটেশন `2.4e-3`-ও ব্যবহার করা যায়।
সবচেয়ে কমন ফ্লোটিং-পয়েন্ট টাইপ হলো `double`।

## গাণিতিক অপারেশন

C++ এক্সপ্রেশন গঠনের জন্য `+`, `-`, `*`, `/`, `(` ও `)` এবং `%` সাপোর্ট করে।
দুটি ইন্টিজারের মধ্যে অপারেশনের ফলাফলও একটি ইন্টিজার হয়।
`5 / 2` রিটার্ন করে `2`।
যখন জড়িত টাইপগুলোর একটি ফ্লোটিং-পয়েন্ট টাইপ হয়, তখন ফলাফলও ফ্লোটিং-পয়েন্ট হয়।
`5.0 / 2` ও `5 / 2.0` রিটার্ন করে `2.5`।
`%` হলো ভাগশেষ অপারেটর এবং এটি একটি পূর্ণসংখ্যা ভাগের ভাগশেষ রিটার্ন করে: `5%3` হলো `2`।

## অ্যাসাইনমেন্ট অপারেটর

অ্যাসাইনমেন্ট অপারেটর একটি ভ্যারিয়েবলে একটি লিটারাল অ্যাসাইন করে।
এটি সর্বদা ডান থেকে বামে ঘটে, কখনোই উল্টো দিকে নয়।

```cpp
int length = 5;
int width = 2;
length = width;
```

এখানে `length` ভ্যারিয়েবলে ইন্টিজার মান `5` অ্যাসাইন করা হয়েছে।
এরপর `width` ভ্যারিয়েবলে ইন্টিজার মান `2` অ্যাসাইন করা হয়েছে।
সবশেষে `width`-এর মান `length` ভ্যারিয়েবলে কপি করা হয় এবং আগের মান `5` হারিয়ে যায়।
এটাও খেয়াল রাখুন, অ্যাসাইনমেন্ট অপারেশনের মুহূর্তে আমরা শুধু `width`-এর মান `length`-এ অ্যাসাইন করছি।
তাই পরে যদি `width`-এর মান বদলে যায়, তা `length`-এর মানকে প্রভাবিত করবে না।

অ্যাসাইনমেন্ট অপারেটরকে অন্য অপারেটরগুলোর (গাণিতিক ও বিটওয়াইজ) সাথে মিলিয়ে `compound assignment` নামে পরিচিত অপারেটর বানানো যায়: `+=`, `-=`, `*=`, `/=`, `%=`।
এই অপারেটরগুলো একটি ভ্যারিয়েবলের উপর অপারেশন চালিয়ে তার বর্তমান মান পরিবর্তন করে।

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

`people` ও `eggs` ভ্যারিয়েবল দুটি `0` দিয়ে ইনিশিয়ালাইজ করা হয়েছে।
এরপর `people` ভ্যারিয়েবলের বর্তমান মান `0`-এর সাথে ইন্টিজার মান `2` যোগ করে আবার `people`-এ অ্যাসাইন করি।
এখন `people` হয়ে যায় `2`।
পরে প্রতিটি ব্যক্তির জন্য `3`টি ডিম যোগ করি, যা মোট `6`টি ডিম হয়।
এখন এই `6`-কে `eggs` ভ্যারিয়েবলের বর্তমান মান `0`-এর সাথে যোগ করে আবার `eggs`-এ অ্যাসাইন করি।
এখন `eggs` হবে `6`।
এর সমতুল্য এক্সপ্রেশন হবে `people = people + 2` এবং `eggs = eggs + (3 * people)`।

## কাস্টিং

কাস্টিং হলো এক টাইপ থেকে আরেক টাইপে রূপান্তর।
কোনো জায়গায় `double` দরকার হলে সেখানে `int` ব্যবহার করা যায়।
উপরের `5.0 / 2` উদাহরণটিতে `2`-কে `2.0`-এ ইমপ্লিসিট কাস্ট করে কাজটি করা হয়।
কোনো `double`-কে `int`-এ কাস্ট করলে তথ্য হারিয়ে যেতে পারে।
অন্য কোনো টাইপ T-তে এমন কাস্ট `static_cast<T>` দিয়ে এক্সপ্লিসিট করা ভালো অভ্যাস।
আধুনিক C++-এ `(T)` দিয়ে পুরনো C-স্টাইলের কাস্ট নিরুৎসাহিত, তবুও এটি জানা থাকা ভালো।

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## প্রিসিশন ও রিপ্রেজেন্টেশন

C++-এ সংখ্যা ইচ্ছেমতো বড় হতে পারে না।
যেমন `int` রিপ্রেজেন্ট করা হয় ৩২ বিট দিয়ে।
এটি `2^32`টি সংখ্যার সেটের জন্য যথেষ্ট, অর্থাৎ প্রায় ৪০০ কোটি।
`0` ধরে নিলে এর মধ্যে সবচেয়ে বড় ও ছোট `int` সংখ্যা হয় `-2^31` এবং `2^31 - 1`।

ফ্লোটিং-পয়েন্ট সংখ্যা সাধারণত ১৫ দশমিক স্থানের প্রিসিশন দিয়ে তৈরি হয়, তবে হোস্ট সিস্টেম অনুযায়ী এর রিপ্রেজেন্টেশন বদলে যায়।
