# সম্পর্কে

একটি ফাইল হলো ডিস্কে একটি নামযুক্ত স্ট্রিম। [`io.files`][io.files] ভোকাবুলারি একটি ফাইলের সাথে কাজ করার দুটি উপায় দেয়: পুরো ফাইলের সুবিধাজনক ওয়ার্ড, যা একটিমাত্র কলে সবকিছু পড়ে বা লেখে, আর স্ট্রিম ওপেনার (`with-…` কম্বিনেটর), যা দিয়ে ধীরে ধীরে পড়া বা লেখা যায়। দুটিই `io-streams` কনসেপ্টের ইন-মেমরি স্ট্রিমগুলোর মতো একই [স্ট্রিম প্রোটোকল][stream-protocol]-এর উপর দাঁড়িয়ে আছে, আর একটি `<file-reader>` এবং একটি `<string-reader>` একই ওয়ার্ডেরই উত্তর দেয়।

প্রতিটি ফাইল-ওয়ার্ড একটি **এনকোডিং** নেয়, অর্থাৎ সেই স্কিম যা বাইটকে ক্যারেক্টারে এবং আবার ফিরে ম্যাপ করে। টেক্সটের জন্য এটি প্রায় সবসময়ই `io.encodings.utf8` থেকে নেওয়া [`utf8`][utf8]; বাইনারি কাজে `latin1` বা একটি `<byte-array>` এনকোডিং ব্যবহার করা হয়।

## পুরো ফাইল পড়া

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` পুরো ফাইলটিকে একটি স্ট্রিং হিসেবে রিটার্ন করে। `file-lines` তার লাইনগুলোকে একটি অ্যারে হিসেবে রিটার্ন করে, লাইন টার্মিনেটরগুলো সরিয়ে দিয়ে। প্রতিটি লাইন যখন একটি রেকর্ড, তখন এটি দারুণ কাজে লাগে।

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## পুরো ফাইল লেখা

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

দুটিই ফাইলটি **রিপ্লেস** করে, আর ফাইলটি না থাকলে সেটি তৈরি করে। `set-file-contents` একটি স্ট্রিং হুবহু লেখে; `set-file-lines` একটি সিকোয়েন্সের প্রতিটি এলিমেন্টকে তার নিজের লাইনে লেখে, আর প্রয়োজনীয় নিউলাইনগুলো যোগ করে।

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## স্কোপড স্ট্রিম

আপনি যখন একটি ফাইলে নতুন কিছু যোগ করতে চান, বা টুকরো টুকরো করে পড়তে ও লিখতে চান, তখন একটি `with-…` কম্বিনেটর দিয়ে ফাইলটি খুলুন এবং কোয়োটেশনের ভিতরে অ্যাম্বিয়েন্ট স্ট্রিম ওয়ার্ডগুলো ব্যবহার করুন:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

`with-file-writer` প্রথমে ফাইলটি ট্রাঙ্কেট করে; `with-file-appender` আগের কনটেন্ট রেখে দেয় এবং তার পরে লেখে। প্রতিটিই একেকটি ডেস্ট্রাক্টর স্কোপ: কোয়োটেশন শেষ হলেই ফাইল হ্যান্ডেলটি ক্লোজ হয়ে যায়, এমনকি সেটি থ্রো করলেও। `boatswains-bilge` কম্বিনেটরগুলো যে গ্যারান্টি দেয়, এখানে সেটিই ফাইলের জন্য বিশেষায়িত।

## পুরো ফাইল, নাকি স্কোপড?

ফাইলটি যখন মেমরিতে ধরে রাখার মতো যথেষ্ট ছোট এবং আপনি পুরোটা একবারে চান, তখন `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines` ব্যবহার করুন। আর `with-…` ওপেনারগুলো ব্যবহার করুন যখন আপনার অ্যাপেন্ড করা দরকার, `readln` দিয়ে বড় ফাইল এক লাইন করে স্ট্রিম করা দরকার, বা পড়া ও লেখা পালা করে করতে দরকার। অর্থাৎ যেখানেই পুরো ফাইল মেমরিতে ধরে রাখা অপচয় হবে বা ভুল হবে, সেখানেই।
