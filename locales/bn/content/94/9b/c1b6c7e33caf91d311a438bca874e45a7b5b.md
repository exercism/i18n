# নির্দেশনা

এলেনা একটি সংবাদপত্র কারখানার নতুন কোয়ালিটি ম্যানেজার।
কোম্পানিতে সদ্য যোগ দেওয়ায় তিনি কারখানার কিছু প্রক্রিয়া পর্যালোচনা করার সিদ্ধান্ত নিয়েছেন, যাতে বোঝা যায় কোন কোনটা উন্নত করা যায়।

তিনি দেখতে পান যে টেকনিশিয়ানরা অনেক কোয়ালিটি চেক নিজ হাতে করছেন।

অটোমেশনের জন্য এটি একটি ভালো সুযোগ বলে তিনি মনে করেন এবং আপনাকে, একজন ফ্রিল্যান্স ডেভেলপারকে, কিছু মেশিন মনিটর করার জন্য একটি সফটওয়্যার তৈরি করতে অনুরোধ করেন।

## 1. ঘরের আর্দ্রতার মাত্রা মনিটর করুন

আপনার প্রথম কাজ হলো প্রোডাকশন রুমের আর্দ্রতার মাত্রা মনিটর করার জন্য একটি সফটওয়্যার লেখা।
কোম্পানির সফটওয়্যারের সাথে আগে থেকেই একটি সেন্সর যুক্ত আছে, যা নিয়মিত ঘরটির আর্দ্রতার শতাংশ রিটার্ন করে।

সফটওয়্যারে আপনাকে একটি ফাংশন ইমপ্লিমেন্ট করতে হবে, যা আর্দ্রতার শতাংশ বেশি হলে একটি এরর থ্রো করবে।
ফাংশনটির নাম হবে `check_humidity_level` এবং এটি প্যারামিটার হিসেবে আর্দ্রতার শতাংশ নেবে।

শতাংশ 70%-এর বেশি হলে вам এরর দিয়ে থেমে যেতে হবে (মেসেজটি গুরুত্বপূর্ণ নয়)।
অন্যথায়, "humidity test passed" সম্বলিত একটি মেসেজ দিন এবং পরিমাপটি ঠিক আছে নিশ্চিত করতে `TRUE` রিটার্ন করুন।

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. ওভারহিটিং শনাক্ত করুন

এলেনা আপনার প্রথম কাজটিতে খুব খুশি এবং মেশিনগুলোর তাপমাত্রা মনিটর করার দায়িত্ব আপনাকে দেন।
গ্রেগ নামের এক টেকনিশিয়ানের সাথে কথা বলার সময় вам বলা হয়, কোনো মেশিনের তাপমাত্রা 500°C ছাড়িয়ে গেলে টেকনিশিয়ানরা ওভারহিটিং নিয়ে চিন্তা করতে শুরু করেন।

মেশিনটিতে এমন একটি সেন্সর লাগানো আছে যা তার অভ্যন্তরীণ তাপমাত্রা মাপে।
জেনে রাখুন, সেন্সরটি খুবই সংবেদনশীল এবং প্রায়ই নষ্ট হয়ে যায়।
সেক্ষেত্রে টেকনিশিয়ানদের এটি বদলাতে হবে।

আপনার কাজ হলো `report_overheating` নামের একটি ফাংশন ইমপ্লিমেন্ট করা, যা প্যারামিটার হিসেবে তাপমাত্রা নেয় এবং সেন্সর নষ্ট হলে বা মেশিন ওভারহিট হতে শুরু করলে একটি এরর থ্রো করে।

পরে এররভেদে আলাদাভাবে সাড়া দিতে হবে জেনে, দুই ধরনের এররকে আলাদা করার একটি মেকানিজম আপনার দরকার।

- সেন্সর নষ্ট থাকলে তাপমাত্রা হবে `NULL`।
  সেক্ষেত্রে вам এমন একটি এরর মেসেজ দিয়ে থেমে যেতে হবে, যাতে স্ট্রিংয়ের অংশ হিসেবে "Sensor Broken" থাকে।
- সেন্সর ঠিকভাবে কাজ করলে, তাপমাত্রা 600°C ছাড়িয়ে গেলে вам তাপমাত্রা সম্বলিত একটি মেসেজ দিয়ে থেমে যেতে হবে।
- তাপমাত্রা 500°C ছাড়ালেও 600°C না ছাড়ালে, তাপমাত্রা সম্বলিত একটি ওয়ার্নিং দিন এবং `FALSE` রিটার্ন করুন।
- অন্যথায় সব ঠিক আছে, তাই `"temperature check passed: t °C"` মেসেজটি দিন, যেখানে `t` হলো তাপমাত্রা, এবং `TRUE` রিটার্ন করুন।

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. মেশিন মনিটর করুন

এখন যেহেতু আপনার মেশিন এরর শনাক্ত করতে পারে এবং আপনার কাছে একটি কাস্টম মেশিন এরর আছে, вам একটি র‍্যাপার ফাংশন যোগ করতে হবে, যা সবকিছু কেমন চলছে তা রিপোর্ট করতে পারবে।
আগের ফাংশনগুলোর লগ রিটার্ন করার পাশাপাশি, এই র‍্যাপারটিকে ঘটা যেকোনো ধরনের ব্যর্থতার উপর নির্ভর করে লগ যোগও করতে হবে।

- আর্দ্রতা ও তাপমাত্রা চেক করুন।
- সমস্যা থাকলে, `check_humidity_level()` এবং `report_overheating()` যেন তাদের লগ আউটপুট করে।
- সব ঠিক থাকলে, "All OK" সম্বলিত একটি মেসেজ যোগ করুন।

`monitor_the_machine()` নামের একটি ফাংশন ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে আর্দ্রতা ও তাপমাত্রা নেয়।

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
