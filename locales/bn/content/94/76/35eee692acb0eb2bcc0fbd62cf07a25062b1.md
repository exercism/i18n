# নির্দেশনা

আপনি সান্তা ক্লজের লজিস্টিকস বিভাগে কাজ করা একজন এলফ, এবং সিস্টেমের সফটওয়্যার হালনাগাদ করার জন্য বসের কাছ থেকে আপনি দুটি কাজ পেয়েছেন।

## 1. খেলনার নাম বের করুন

সিস্টেমটিকে ডেটাবেস থেকে একটি খেলনার নাম বের করতে পারতে হবে।
ডেটাবেসটি `(name: String, quantity: Int)` টাইপের টাপল দিয়ে তৈরি।

`getName(_:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি আর্গুমেন্ট নেয়, যেখানে `(name: String, quantity: Int)` টাইপের একটি টাপল থাকে।

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. ডেটাবেসে নতুন একটি খেলনা যোগ করুন

খেলনার বাজার খুব দ্রুত বদলে যায়, কোনটা জনপ্রিয় তা অতি দ্রুত পরিবর্তন হয়।
তাই নতুন খেলনা তৈরি করার একটি ফাংশন প্রয়োজন।

`createToy(name:amount:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা `name` আর্গুমেন্টে খেলনার নাম এবং `amount` আর্গুমেন্টে খেলনার পরিমাণ নেয়।

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. খেলনার পরিমাণ হালনাগাদ করুন

সান্তার কারখানার এলফরা অবিরত নতুন খেলনা তৈরি করে, আর সান্তাকে প্রতিটি খেলনার পরিমাণের হিসাব রাখতে হয়।
এজন্য সিস্টেমটিকে ডেটাবেসে একটি খেলনার পরিমাণ হালনাগাদ করার সুবিধা থাকতে হবে।

`updateQuantity(_:toy:Amount:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা এই আর্গুমেন্টগুলো নেয়:
- `toys`-এ `(name: String, quantity: Int)` টাইপের টাপলগুলোর একটি অ্যারে থাকে।
- `toy`-এ হালনাগাদ করতে হবে এমন খেলনার নাম থাকে।
- `amount`-এ খেলনার নতুন পরিমাণ থাকে।

আপনি ধরে নিতে পারেন যে খেলনাটি আগেই ডেটাবেসে আছে, এটি যাচাই করার দরকার নেই।

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. খেলনায় ক্যাটেগরি কী (key) যোগ করুন

সান্তা ডেটাবেসের খেলনাগুলোকে ক্যাটেগরি অনুযায়ী সাজাতে চান।
এতে ডেলিভারি দিতে হলে তারা সহজে খেলনা খুঁজে পাবেন, আর ডেটাবেসের খেলনাগুলো সাজিয়েও রাখতে পারবেন।

তবে সিস্টেমটি প্রথমবার বানানোর সময় ক্যাটেগরি কী (key) যোগ করার কথা ভুলে যাওয়া হয়েছিল।
এখন সিস্টেমটিকে ডেটাবেসের একটি খেলনায় ক্যাটেগরি কী (key) যোগ করার সুবিধা দিতে হবে।

`addCategory(_:category:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা এই আর্গুমেন্টগুলো নেয়:
- `toys`-এ `(name: String, quantity: Int)` টাইপের টাপলগুলোর একটি অ্যারে থাকে।
- `category`-তে খেলনাগুলোতে যোগ করতে হবে এমন ক্যাটেগরি কী (key) থাকে।

আপনি ধরে নিতে পারেন যে খেলনাটি আগেই ডেটাবেসে আছে, এটি যাচাই করার দরকার নেই।
আপনি এও ধরে নিতে পারেন যে খেলনায় আগে থেকে কোনো ক্যাটেগরি কী (key) নেই।

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
