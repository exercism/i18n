# ডেটাবেসের বড় খরচ

## সমস্যার বিবৃতি

ABC Corp আপনার কাছে এমন কর্মচারীদের নাম ও বিভাগ খুঁজে বের করতে চায়, যাদের পেমেন্ট এন্ট্রির পরিমাণ একটি নির্দিষ্ট অঙ্কের (যেমন `3000.00`) চেয়ে বেশি।

প্রয়োজনীয় ডেটা রিটার্ন করার জন্য `HighPayment` নামে একটি রেকর্ড তৈরি করুন। রেকর্ডটির সংজ্ঞা নিচে দেওয়া হলো।

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

ডেটাবেস থেকে প্রয়োজনীয় ডেটা পেতে JDBC ক্লায়েন্টের `query` অপারেশনটি ব্যবহার করুন।

> দ্রষ্টব্য: ফলাফলটি `payment_id` অনুসারে ঊর্ধ্বক্রমে সাজান।

## ডেটাবেসের বিবরণ

এই সমস্যার জন্য দেওয়া H2 ডেটাবেসটি ব্যবহার করুন।

> নমুনা ডেটাবেস ফাইলটি `gofigure.mv.db`, আর ডেটাবেসের নাম `gofigure`। এটি `db` ফোল্ডারের ভেতরে দেওয়া আছে।

নিচের টেবিলগুলো ইতিমধ্যেই নমুনা H2 ডেটাবেসে কিছু নমুনা ডেটাসহ আছে। কলামের নাম ও ডেটা টাইপ নিচে দেওয়া হলো।

**টেবিলের নাম**: `Employee`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `employee_id`     | ইন্টিজার, অটো-ইনক্রিমেন্টেড প্রাইমারি কী       |
| `name`            | স্ট্রিং        |
| `city`            | স্ট্রিং        |
| `department`      | স্ট্রিং        |
| `age`             | ইন্টিজার        |

**টেবিলের নাম**: `Payment`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `payment_id`      | ইন্টিজার, অটো-ইনক্রিমেন্টেড প্রাইমারি কী       |
| `date`            | ডেট        |
| `amount`          | দশমিক সংখ্যা        |
| `employee_id`     | ইন্টিজার        |
| `reason`          | স্ট্রিং        |

* ডেটাবেস ফাইলটি `gofigure.mv.db`। JDBC URL হিসেবে `jdbc:h2:file:/path/to/db/file` ব্যবহার করুন।
* ইউজারনেম: `root`
* পাসওয়ার্ড: `root`

## সীমাবদ্ধতা

* কোয়েরি এবং Ballerina নমুনা যাচাই করতে `db` ফোল্ডারে দেওয়া H2 ডেটাবেস ফাইলটি ব্যবহার করুন।
* আপনার Ballerina.toml-এ প্ল্যাটফর্ম ডিপেন্ডেন্সি হিসেবে H2 ডেটাবেস ড্রাইভার যোগ করতে maven ডিপেন্ডেন্সি প্যারামস পদ্ধতিটি ব্যবহার করুন।

## টেস্ট এনভায়রনমেন্ট

* আপনি `bal test` দিয়ে টেস্ট চালাতে পারেন, যা দেওয়া নমুনা DB-র বিপরীতে চলবে।

## ইঙ্গিত

* ডেটাবেস নিয়ে কাজ করতে [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) মডিউলটি ব্যবহার করুন
* ডিপেন্ডেন্সি হিসেবে JDBC ড্রাইভার যোগ করার ধাপগুলো জানতে [পূর্বশর্ত](https://lib.ballerina.io/ballerinax/java.jdbc/latest) অংশটি দেখুন
* DB থেকে ডেটা কোয়েরি করতে [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) রিমোট মেথডটি ব্যবহার করুন
* [সহজ কোয়েরি](https://ballerina.io/learn/by-example/mysql-query-operation) উদাহরণটি দেখুন
* ডেটা অ্যাক্সেস করতে Ballerina-র [স্ট্রিম](https://ballerina.io/learn/by-example/stream-type) টাইপটি ব্যবহার করুন
* DB থেকে প্রয়োজনীয় ডেটাসেট খুঁজে বের করতে SQL জয়েন ব্যবহার করুন
