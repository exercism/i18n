# পরিচিতি

Cairo-তে বুলিয়ান মান প্রকাশ করা হয় আগে থেকেই ঘোষিত বুলিয়ান টাইপ `bool` দিয়ে, যার মান `true` কিংবা `false` হতে পারে।

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo তিনটি লজিক্যাল অপারেটর সমর্থন করে, যেগুলো এক্সপ্রেশনকে বুলিয়ান মান পর্যন্ত মূল্যায়ন করতে পারে এবং `true` অথবা `false` রিটার্ন করে।

| অপারেটর    | এর অর্থ                                 |
| ----------- | --------------------------------------------- |
| `&&` (এবং)  | উভয় বিবৃতি ট্রু হলে এটি ট্রু হয়।       |
| `\|\|` (অথবা) | অন্তত একটি বিবৃতি ট্রু হলে এটি ট্রু হয়। |
| `!` (নয়)   | কেবল বিবৃতিটি ফলস হলেই এটি ট্রু হয়।    |
