# ভূমিকা

`Types` কনসেপ্টে আমরা শিখেছিলাম যে:

- Julia-তে টাইপগুলি একটি হায়ারার্কি গঠন করে।
- প্রতিটি টাইপের একটি সুপারটাইপ থাকে।
- `Any` হায়ারার্কির শীর্ষে থাকে এবং নিজেই নিজের সুপারটাইপ।
- টাইপের সাবটাইপ _থাকতে পারে_, আর যেগুলোর থাকে সেগুলোকে `abstract types` বলা হয়।
- যেসব টাইপের সাবটাইপ নেই (গাছের পাতার নোড) সেগুলোকে `concrete types` বলা হয়।
- `Char` বা `Int64`-এর মতো অবিভাজ্য টাইপগুলোকে `primitive types` বলা হয়।

শুধু `primitive` টাইপগুলোই সরল আকারে অ্যাবস্ট্রাক্ট বনাম কনক্রিট প্যাটার্ন অনুসরণ করে। `Vector` একটি কালেকশন, যাকে নিজস্ব টাইপযুক্ত এলিমেন্টে ভাগ করা যায়।

```julia-repl
julia> isprimitivetype(Int)
true

julia> isprimitivetype(Vector)
false
```

_কিসের কালেকশন?_

প্রতিটি ভেক্টর (বা সেট) হলো একই রকম টাইপের এলিমেন্টের একটি কালেকশন। এর টাইপ কোঁকড়া বন্ধনী `{ }`-এর ভেতরে একটি _প্যারামিটার_ দিয়ে নির্দিষ্ট করা যায়, অথবা টাইপ ইনফারেন্সকে তা নির্ণয় করতে দিয়ে বাদ দেওয়া যায়।

```julia-repl
julia> v = [1, 2, 3]
3-element Vector{Int64}:
 1
 2
 3

julia> v8 = Vector{Int8}([2, 4, 6])
3-element Vector{Int8}:
 2
 4
 6
```

এই `parametric types` হলো `generic programming`-এর একটি রূপ, এবং অনেক আধুনিক ভাষায় মোটামুটি সমতুল্য কিছু আছে, যদিও বিস্তারিত বিষয়ে অনেক পার্থক্য রয়েছে।

## প্যারামেট্রিক কম্পোজিট টাইপ

কখনও কখনও আমরা এমন একটি কম্পোজিট টাইপ বানাতে চাই যা যথেষ্ট নমনীয় (জেনেরিক) এবং বিভিন্ন ফিল্ড টাইপ সামলাতে পারে।

সংজ্ঞায় একটি ডামি টাইপ দিয়ে এটি করা যায়, যাকে সাধারণত `T` বলা হয়।

```julia-repl
julia> struct Point{T}
               x::T
               y::T
       end

# high definition version

julia> real_point = Point(7.3, 4.2)
Point{Float64}(7.3, 4.2)

julia> typeof(real_point)
Point{Float64}

# low definition version

julia> int8point = Point{Int8}(17, 23)
Point{Int8}(17, 23)

julia> typeof(int8point)
Point{Int8}

julia> Point(Int8(17), Int8(23))
Point{Int8}(17, 23)
```

স্বাভাবিকভাবেই, এই পদ্ধতি ফিল্ডের ভেতরে কালেকশন নিয়েও কাজ করে:

```julia-repl
julia> struct Record{T}
           data::Vector{T}
           comment::String
       end

julia> rec = Record{Float64}([1.3, 5.2], "some data")
Record{Float64}([1.3, 5.2], "some data")

julia> rec.data
2-element Vector{Float64}:
 1.3
 5.2

julia> rec2 = Record{Int32}([3, 5], "more data")
Record{Int32}(Int32[3, 5], "more data")

julia> rec2.data
2-element Vector{Int32}:
 3
 5
```
