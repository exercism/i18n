# ভূমিকা

## `switch` স্টেটমেন্ট

একটি _if/else_ স্টেটমেন্টের মতো, একটি `switch` স্টেটমেন্ট আপনাকে শর্তসাপেক্ষে কোড চালিয়ে প্রোগ্রামের ফ্লো বদলানোর সুযোগ দেয়।
পার্থক্য হলো, একটি `switch` স্টেটমেন্ট কেবল একটি প্রিমিটিভ বা স্ট্রিং এক্সপ্রেশনের মানকে পূর্বনির্ধারিত কনস্ট্যান্ট মানের সাথে তুলনা করতে পারে।

একটি `switch` স্টেটমেন্ট ব্যবহার করার সময় কিছু কিওয়ার্ড কাজে আসে।

- `switch`: এই কিওয়ার্ডটি আপনাকে switch স্টেটমেন্টের গঠন ডিক্লেয়ার করতে দেয়।
  এর পরে সেই এক্সপ্রেশন বা ভ্যারিয়েবল থাকে, যেটি ফলাফল বদলে দেবে।
- `case`: ফলাফলের বিভিন্ন সম্ভাবনা ডিক্লেয়ার করতে আপনি এই কিওয়ার্ডটি ব্যবহার করবেন।
- `break`: কাঙ্ক্ষিত ফ্লো-এর শেষে switch-এর এক্সিকিউশন থামানোর জন্য `break` কিওয়ার্ডটি খুবই উপযোগী।
  যদি আপনি এটি ভুলে যান, তবে প্রোগ্রাম চলতে থাকবে এবং অনাকাঙ্ক্ষিত ফলাফল দিতে পারে।
- `default`: নাম অনুযায়ী, যখন অন্য কোনো case আপনার এক্সপ্রেশনের ফলাফলের সাথে মেলে না, তখন এটিকে ডিফল্ট ফলাফল হিসেবে ব্যবহার করুন।

সবচেয়ে সরল রূপে এগুলো একটি প্রিমিটিভ বা স্ট্রিং এক্সপ্রেশন পরীক্ষা করে এবং তার মানের ভিত্তিতে সিদ্ধান্ত নেয়।
যেমন:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
