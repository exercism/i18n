# পরিচিতি

একটি `Map` ব্যবহার করা হয় **কী (key)** আর **মান**-এর জোড়া সংরক্ষণ করতে। `Maps` ঠিক অ্যারের মতোই ইনিশিয়ালাইজ করা হয়, তবে এখানে ম্যাপ লিটারেল অপারেটর `=>` ব্যবহার করা হয়। এগুলোর কী (key)-মান টাইপ স্পষ্টভাবে ডিফাইন করাও যায়, আবার টাইপ অনুমান করেও নেওয়া যায়। কী (key) গুলো অবশ্যই অনন্য হতে হবে, নাহলে একটি এরর থ্রো হয়।

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`for` লুপ ব্যবহার করে একটি `Map`-এর ওপর ইটারেশন করা যায়। আপনি হয় মানগুলোর ওপর, নয়তো কী (key) গুলোর ওপর ইটারেশন করতে পারেন:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

ভেতরে ভেতরে `Map` আসলে একটি অ্যাবস্ট্রাক্ট টাইপ। কম্পাইল হওয়ার সময় কী (key)-এর টাইপের ওপর নির্ভর করে এটি কয়েকটি বিশেষায়িত টাইপের একটিতে রূপান্তরিত হয়:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

`Map` টাইপটি রানটাইমে আর থাকে না; এর জায়গা নিয়েছে উপরের অবজেক্টগুলোর একটি।
