# সম্পর্কে

[repeat-while লুপ][repeat-loops] আর `while` লুপের মতোই, তবে একটি মূল পার্থক্য আছে: শর্ত পরীক্ষা করা হয় লুপের বডি চালানোর *পরে*, আগে নয়।
ফলে একটি `repeat-while` লুপ অন্তত একবার তার কোড ব্লক চালাবে, এটা নিশ্চিত।

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
