# শেখা

* [The Rust Programming Language](https://doc.rust-lang.org/book/) Rust শেখা শুরু করার জন্য এবং Rust-এর নির্দিষ্ট কিছু ফিচার আরও গভীরে গিয়ে জানার জন্য দারুণ একটি রিসোর্স।
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) Rust-এ আপনি সাধারণত যা যা লিখবেন, তার উদাহরণ দেখায়।
* [Into_rust()](http://intorust.com/) "Rust শেখার জন্য স্ক্রিনকাস্ট।"
* [Rustlings](https://github.com/carols10cents/rustlings) "Rust কোড পড়া ও লেখায় অভ্যস্ত হওয়ার জন্য ছোট ছোট অনুশীলনী।"
* [Rust User Forum](http://users.rust-lang.org)-এ সব স্তরের প্রশ্নের উত্তর পাওয়া যায়
