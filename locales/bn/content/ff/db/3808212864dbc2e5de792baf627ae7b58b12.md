# ভূমিকা

## Nil

[Nil][nil-dictionary] একটি ইংরেজি শব্দ, যার অর্থ "কিছুই না" বা "শূন্য"। Elixir-এ `nil` একটি বিশেষ মান, যা একটি মানের _অনুপস্থিতি_ বোঝায়।

```elixir
# I do not have a favorite color
favorite_color = nil
```

অন্য প্রোগ্রামিং ভাষায় `null` বা `none` মান একই ধরনের ভূমিকা পালন করতে পারে।

## If

`cond` ছাড়াও Elixir আরেকটি ম্যাক্রো দেয়, [`if/2`][getting-started-if], যা কেবল একটি শর্ত যাচাই করতে হলে কাজে লাগে।

[`if/2`][kernel-if] একটি শর্ত আর দুটি অপশন নেয়। শর্তটি _ট্রুথি_ হলে এটি প্রথম অপশনটি রিটার্ন করে, আর শর্তটি _ফলসি_ হলে দ্বিতীয়টি।

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

একটি `if` এক্সপ্রেশন এক লাইনেও লেখা সম্ভব। শর্তের পরের কমাটি লক্ষ্য করুন।

```elixir
if age > 16, do: "beer", else: "no beer"
```

এই সিনট্যাক্স খুব ছোট এক্সপ্রেশনের জন্য কাজে লাগে, তবে এক্সপ্রেশনটি এক লাইনে না ধরলে এটি এড়িয়ে চলা উচিত।

### _ট্রুথি_ ও _ফলসি_

Elixir-এ বুলিয়ান প্রেক্ষাপটে (যেমন একটি `if` এক্সপ্রেশন) থাকা সব ডেটা টাইপ _ট্রুথি_ বা _ফলসি_ মানে মূল্যায়িত হয়। `false` আর `nil` **ছাড়া** বাকি সব ডেটাকেই _ট্রুথি_ ধরা হয়। বিশেষ করে খালি স্ট্রিং, ইন্টিজার `0`, আর খালি অ্যারে, সবই Elixir-এ _ট্রুথি_ হিসেবে গণ্য হয়।
