# বেসিকস বিস্তারিত

বেসিকস কনসেপ্টে [Go](https://golang.org)-কে একটি স্ট্যাটিক টাইপের, কম্পাইলড প্রোগ্রামিং ভাষা হিসেবে পরিচয় করিয়ে দেওয়া হয়েছে। আগে ডোমেইন নাম golang.org ছিল বলে ভাষাটিকে প্রায়ই Golang বলা হয়, কিন্তু এর আসল নাম Go।

বেসিকস কনসেপ্টে ভাষার তিনটি প্রধান বৈশিষ্ট্য সম্পর্কে জানানো হয়েছে: প্যাকেজ, ফাংশন এবং ভ্যারিয়েবল।

## প্যাকেজ

Go অ্যাপ্লিকেশনগুলো প্যাকেজে সাজানো থাকে।
একটি প্যাকেজ হলো একই ডিরেক্টরিতে থাকা সোর্স ফাইলগুলোর একটি সংগ্রহ।
একটি ডিরেক্টরির সব সোর্স ফাইলকে একই প্যাকেজ নাম ব্যবহার করতে হবে।
প্রচলিত নিয়ম হলো, প্যাকেজের নাম হবে ইমপোর্ট পাথে থাকা শেষ ডিরেক্টরির নাম।
উদাহরণস্বরূপ, ["math/rand" প্যাকেজের](https://golang.org/src/math/rand/) ফাইলগুলো `package rand` স্টেটমেন্ট দিয়ে শুরু হয়।
কোনো প্যাকেজ ইমপোর্ট করা হলে, শুধু সেই এনটিটিগুলোই (ফাংশন, টাইপ, ভ্যারিয়েবল, কনস্ট্যান্ট) ব্যবহার বা অ্যাক্সেস করা যায়, যাদের নাম বড় হাতের অক্ষর দিয়ে শুরু হয়।
Go-তে নামকরণের সুপারিশ করা স্টাইল হলো, আইডেন্টিফায়ারগুলোর নাম `camelCase` দিয়ে দেওয়া হবে, তবে যেগুলো বিভিন্ন প্যাকেজ থেকে অ্যাক্সেসযোগ্য হওয়ার কথা সেগুলো হবে `PascalCase`।

```go
package lasagna
```

## ভ্যারিয়েবল

Go স্ট্যাটিক টাইপের, অর্থাৎ সব ভ্যারিয়েবলেরই কম্পাইল সময়ে [একটি নির্দিষ্ট টাইপ থাকতে হয়](https://en.wikipedia.org/wiki/Type_system)।

টাইপ স্পষ্টভাবে উল্লেখ করে ভ্যারিয়েবল ডিফাইন করা যায়:

```go
var explicit int // Explicitly typed
```

আপনি একটি ইনিশিয়ালাইজারও ব্যবহার করতে পারেন, তখন কম্পাইলার ইনিশিয়ালাইজারের টাইপের সাথে মিলিয়ে ভ্যারিয়েবলের টাইপ নির্ধারণ করবে।

```go
implicit := 10   // Implicitly typed as an int
```

একবার ডিক্লেয়ার করার পর, `=` অপারেটর দিয়ে ভ্যারিয়েবলে মান অ্যাসাইন করা যায়।
আর একবার ডিক্লেয়ার হয়ে গেলে, ভ্যারিয়েবলের টাইপ কখনোই বদলানো যায় না।

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## কনস্ট্যান্ট

কনস্ট্যান্টও ভ্যারিয়েবলের মতোই একটি তথ্য ধরে রাখে, কিন্তু প্রোগ্রাম চলাকালীন তাদের মান বদলাতে পারে না।

কনস্ট্যান্ট `const` কিওয়ার্ড দিয়ে ডিফাইন করা হয় এবং সেগুলো সংখ্যা, ক্যারেক্টার, স্ট্রিং বা বুলিয়ান হতে পারে:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## ফাংশন

Go ফাংশন শূন্য বা তার বেশি প্যারামিটার নিতে পারে।
প্যারামিটারগুলোর টাইপ স্পষ্টভাবে উল্লেখ করতে হয়, এখানে কোনো টাইপ ইনফারেন্স নেই।

`return` কিওয়ার্ড দিয়ে ফাংশন থেকে মান রিটার্ন করা হয়।

ফাংশনের নাম উল্লেখ করে এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে ফাংশন কল করা হয়।

মনে রাখবেন, Go দুই ধরনের কমেন্ট সমর্থন করে।
এক লাইনের কমেন্টের আগে `//` বসে এবং বহু লাইনের কমেন্ট `/*` আর `*/`-এর মাঝে লেখা হয়।

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
