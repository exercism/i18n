# নির্দেশনা

আপনার বন্ধু এইমাত্র আপনাকে একটি গুরুত্বপূর্ণ গোপন বার্তা পাঠিয়েছে।
অন্য কেউ যাতে সহজে এটি পড়তে না পারে, তাই একগুচ্ছ বিট ম্যানিপুলেশন করে বার্তাটি এনক্রিপ্ট করা হয়েছে।
বার্তাটি ডিক্রিপ্ট করতে সাহায্য করার জন্য আপনাকে কয়েকটি ফাংশন লিখতে হবে।

## 1. বিটগুলো শিফট করে ফিরিয়ে আনা

বার্তাটি ডিক্রিপ্ট করার প্রথম ধাপ হলো, বিটগুলোকে আবার ডানে শিফট করে এনক্রিপশন প্রক্রিয়ার শিফটটি আগের অবস্থায় ফিরিয়ে আনা।
ডিক্রিপশন প্রক্রিয়ার পরের ধাপগুলো ধরে নেবে যে বাম দিক থেকে 0 ঢোকানো হয়েছে।

`shiftBack` ফাংশনটি লিখুন, যা একটি মান এবং কত ঘর শিফট করতে হবে সেই সংখ্যা নেয় এবং শিফটটি সম্পন্ন করে।

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. কিছু বিট সেট করা

এরপর কিছু বিট আছে যেগুলোকে 1-এ সেট করতে হবে।

`setBits` ফাংশনটি লিখুন, যা একটি মান ও একটি মাস্ক নেয় এবং মানের বিটগুলো 1-এ সেট করার ফলাফল রিটার্ন করে।
মাস্কের যে বিটটি 1, সেই অবস্থানে মানের বিটটিও 1 করা উচিত।
বাকি সব বিট অপরিবর্তিত রাখতে হবে।

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. নির্দিষ্ট কিছু বিট ফ্লিপ করা

এনক্রিপশনের সময় কিছু বিট ফ্লিপ করা হয়।
বার্তাটি ডিক্রিপ্ট করতে সেগুলো আবার ফ্লিপ করতে হবে।

`flipBits` ফাংশনটি লিখুন, যা একটি মান ও একটি মাস্ক নেয়।
মাস্কটি বলে দেয় মানের কোন কোন বিট ফ্লিপ করতে হবে।
মাস্কে যদি বিটটি 1 হয়, তবে মানের সেই বিটটি ফ্লিপ করা হয়।
বাকি সব বিট অপরিবর্তিত রাখা হয়।

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. নির্দিষ্ট কিছু বিট ক্লিয়ার করা

সর্বশেষে, কিছু নির্দিষ্ট বিট আছে যেগুলো সবসময় 0-এ ডিক্রিপ্ট হয়।

`clearBits` ফাংশনটি লিখুন, যা একটি মান ও একটি মাস্ক নেয়।
মাস্কের যে বিটটি 1, সেই অবস্থানে `value`-এর বিটগুলো 0 করতে হবে।
বাকি সব বিট অপরিবর্তিত রাখতে হবে।

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
