# নির্দেশনার পরিশিষ্ট

## এক্সেপশন মেসেজ

কখনও কখনও [এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটি করলে এররটির উৎস কী, তা বোঝাতে আপনার সর্বদা একটি **অর্থবহ এরর মেসেজ** যুক্ত করা উচিত। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিংয়ে যথেষ্ট সাহায্য মেলে। যেসব পরিস্থিতিতে আপনি জানেন এররটির উৎস একটি নির্দিষ্ট টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) মধ্যে থেকে একটি রেইজ করতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যুক্ত করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে ইনপুটে সঠিক ডেলিমিটার না থাকলে, ইনপুট আপারকেসে না থাকলে, ইনপুট নোড-সহ কোনো ট্রি তৈরি না করলে, বা ইনপুটে একেবারেই কোনো ট্রি তৈরি না হলে, [raise স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করে একটি `ValueError` "throw" করতে হবে। টেস্ট পাস করবে কেবল তখনই, যদি আপনি `exception` `raise` করেন এবং তার সঙ্গে একটি মেসেজও যুক্ত করেন।

একটি মেসেজ-সহ `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# if the tree properties as given do not have proper delimiters.
raise ValueError("properties without delimiter")

# if the tree properties as given are not all in uppercase.
raise ValueError("property must be in uppercase")

# if the input does not form a tree, or is empty.
raise ValueError("tree missing")

# if the input is a tree without any nodes.
raise ValueError("tree with no nodes")
```
