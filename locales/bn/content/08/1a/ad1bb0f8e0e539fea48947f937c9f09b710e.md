# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি উইন্ডোভিত্তিক কম্পিউটার সিস্টেম সিমুলেট করবেন।
আপনি এমন কিছু উইন্ডো তৈরি করবেন যেগুলো সরানো ও রিসাইজ করা যায় এবং যেগুলো তাদের কনটেন্ট প্রদর্শন করে।
নিচের ছবিটিতে নিচে আপনি যে মানগুলো নিয়ে কাজ করবেন তার একটি ধারণা দেওয়া হয়েছে।

```
                  <--------------------- screenSize.width --------------------->

       ^          ╔════════════════════════════════════════════════════════════╗
       |          ║                                                            ║
       |          ║          position.x,_                                      ║
       |          ║          position.y  \                                     ║
       |          ║                       \<----- size.width ----->            ║
       |          ║                 ^      *──────────────────────┐            ║
       |          ║                 |      │        title         │            ║
       |          ║                 |      ├──────────────────────┤            ║
screenSize.height ║                 |      │                      │            ║
       |          ║            size.height │                      │            ║

```

## 1. একটি Size স্ট্রাক্ট ডিফাইন করুন

`width` ও `height` নামের দুটি `Int` প্রোপার্টিসহ `Size` নামে একটি স্ট্রাক্ট ডিফাইন করুন, যেগুলো যথাক্রমে উইন্ডোর বর্তমান প্রস্থ ও উচ্চতা সংরক্ষণ করে।
প্রাথমিক প্রস্থ ও উচ্চতা যথাক্রমে 80 ও 60 হওয়া উচিত।
এমন একটি মেথড `resize(newWidth:newHeight:)` যোগ করুন যা নতুন প্রস্থ ও উচ্চতার প্যারামিটার নেয় এবং নতুন আকার প্রতিফলিত করতে প্রোপার্টিগুলো পরিবর্তন করে।

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. একটি Position স্ট্রাক্ট ডিফাইন করুন

`x` ও `y` নামের দুটি `Int` প্রোপার্টিসহ `Position` নামে একটি স্ট্রাক্ট ডিফাইন করুন, যেগুলো যথাক্রমে উইন্ডোর উপরের বাম কোণের বর্তমান অনুভূমিক ও উল্লম্ব অবস্থান সংরক্ষণ করে।
x ও y-এর প্রাথমিক মান প্রত্যেকটি 0 হওয়া উচিত। (0, 0) অবস্থানটি স্ক্রিনের উপরের বাম কোণ, যেখানে ডানে সরলে `x`-এর মান বাড়ে এবং নিচে সরলে `y`-এর মান বাড়ে।

এমন একটি মেথড `moveTo(newX:newY:)` যোগ করুন যা নতুন x ও y প্যারামিটার নেয় এবং নতুন অবস্থান প্রতিফলিত করতে প্রোপার্টিগুলো পরিবর্তন করে।

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. একটি Window ক্লাস ডিফাইন করুন

নিচের প্রোপার্টিগুলোসহ একটি উইন্ডো ক্লাস ডিফাইন করুন:

- `title` : `String`, প্রাথমিক মান "New Window"
- `screenSize` : `Size`, `width` = 800 ও `height` = 600 সহ ধ্রুবক মান
- `size` : `Size`, প্রাথমিক মান `Size` স্ট্রাক্টের ডিফল্ট মান
- `position` : `Position`, প্রাথমিক মান `Position` স্ট্রাক্টের ডিফল্ট মান
- `contents` : `String?`, প্রাথমিক মান `nil`

ক্লাসটির জন্য একটি খালি ইনিশিয়ালাইজারও ডিফাইন করা উচিত।

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. উইন্ডো রিসাইজ করার একটি মেথড যোগ করুন

- `resize(to:)` : `(Size) -> ()` - এই মেথডটি ইনপুট হিসেবে একটি `Size` স্ট্রাক্ট নেয় এবং উইন্ডোটিকে নির্দিষ্ট আকারে রিসাইজ করার চেষ্টা করে। তবে নতুন আকার নির্দিষ্ট সীমা অতিক্রম করতে পারে না।
- অনুমোদিত সর্বনিম্ন উচ্চতা বা প্রস্থ হলো 1।
  1-এর কম চাওয়া উচ্চতা বা প্রস্থ 1-এ ক্লিপ করা হবে।
- সর্বোচ্চ উচ্চতা ও প্রস্থ উইন্ডোর বর্তমান অবস্থানের উপর নির্ভর করে, উইন্ডোর প্রান্ত স্ক্রিনের প্রান্ত অতিক্রম করে যেতে পারে না।
  এই সীমার চেয়ে বড় মান যতটা বড় আকার নেওয়া সম্ভব তাতে ক্লিপ করা হবে।
  যেমন, উইন্ডোর অবস্থান `x` = 400, `y` = 300 এবং `height` = 400, `width` = 300-এ রিসাইজ চাওয়া হলে উইন্ডোটি `height` = 300, `width` = 300-এ রিসাইজ করা হবে, কারণ অনুরোধটি সম্পূর্ণভাবে মিটানোর জন্য `y` দিকে স্ক্রিনটি যথেষ্ট বড় নয়।

## 5. উইন্ডো সরানোর একটি মেথড যোগ করুন

- `move(to:)` : `(Position) -> ()` - এটি `resize(to:)`-এর মতোই, তবে এই মেথডটি আকারের বদলে উইন্ডোর _অবস্থান_ অনুরোধকৃত মানে সমন্বয় করে। `resize`-এর মতোই নতুন অবস্থানও নির্দিষ্ট সীমা অতিক্রম করতে পারে না।
- `x` ও `y` উভয়ের জন্য সর্বনিম্ন অবস্থান 0।
- যেকোনো দিকে সর্বোচ্চ অবস্থান উইন্ডোর বর্তমান আকারের উপর নির্ভর করে; প্রান্তগুলো স্ক্রিনের প্রান্ত অতিক্রম করে যেতে পারে না।
      এই সীমার চেয়ে বড় মান যতটা বড় আকার নেওয়া সম্ভব তাতে ক্লিপ করা হবে। যেমন, উইন্ডোর আকার `x` = 250, `y` = 100 এবং `x` = 600, `y` = 200-এ সরানো চাওয়া হলে উইন্ডোটি `x` = 550, `y` = 200-এ সরানো হবে, কারণ অনুরোধটি সম্পূর্ণভাবে মিটানোর জন্য `x` দিকে স্ক্রিনটি যথেষ্ট বড় নয়।

## 6. উইন্ডোর টেক্সট হালনাগাদ ও উইন্ডোর তথ্য প্রদর্শনের মেথড যোগ করুন

- `update(title:)` : `(String) -> ()` - এই মেথডটি পাস করা স্ট্রিংয়ের মানে `title` প্রোপার্টি সেট করে।
- `update(text:)` : `(String?) -> ()` - এই মেথডটি পাস করা অপশনাল স্ট্রিংয়ের মানে `contents` প্রোপার্টি সেট করে।
- `display()` : `() -> String` - এই মেথডটি উইন্ডোর বর্তমান অবস্থা বর্ণনা করে একটি স্ট্রিং রিটার্ন করে। উদাহরণস্বরূপ, যদি উইন্ডোর `title` হয় "My First Window", অবস্থান: x = 10, y = 100; আকার: width = 200, height = 150; এবং কনটেন্ট: "I 😍 my window", তাহলে এটি স্ট্রিংটি রিটার্ন করবে: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - যদি `contents` nil হয়, শেষ লাইনটি হবে "[This window intentionally left blank]"

## 7. Window ক্লাসের জন্য একটি ইনিশিয়ালাইজার তৈরি করুন

উইন্ডো সিস্টেমে একটি ইনিশিয়ালাইজার থাকা উচিত যাতে কাস্টম ইনপুট দিয়ে উইন্ডো তৈরি করা যায়।
`Window` ক্লাসের জন্য **আরেকটি** ইনিশিয়ালাইজার তৈরি করুন।
ইনিশিয়ালাইজারটি নিচের প্যারামিটারগুলো নেবে: `title`, `contents`, এবং দুটি অপশনাল প্যারামিটার `size` ও `position`।
`size` ও `position` প্যারামিটারের ডিফল্ট মান হওয়া উচিত `Size` ও `Position` স্ট্রাক্টের ডিফল্ট মান।

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
