# ভূমিকা

কাইরোতে কন্ট্রোল ফ্লো ব্যবহার করে আপনি শর্ত ও পুনরাবৃত্তির ভিত্তিতে আপনার প্রোগ্রামের চলার পথ নিয়ন্ত্রণ করতে পারেন।

## শর্তভিত্তিক এক্সিকিউশন

শর্তের ভিত্তিতে কোড চালাতে `if` এক্সপ্রেশন ব্যবহার করুন:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` একটি এক্সপ্রেশন, তাই এটি মান রিটার্ন করতে পারে:

```rust
let result = if condition { 5 } else { 10 };
```

## লুপ

কোড পুনরাবৃত্তি করতে `loop` ব্যবহার করুন।
আপনি না থামালে একটি লুপ অনির্দিষ্টকাল ধরে চলতে থাকে; শর্ত পূরণ হলে লুপ থেকে বেরিয়ে যেতে `break` ব্যবহার করুন।

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

লুপ `break` ব্যবহার করে মান রিটার্ন করতে পারে:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

পরের ইটারেশনে চলে যেতে `continue` ব্যবহার করুন:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
