# ইনস্টলেশন


## GHCup সংগ্রহ করুন

Haskell টুল ইনস্টল করার প্রস্তাবিত উপায় হলো [GHCup][ghcup]।

GHCup দিয়ে আপনি আপনার ইনস্টল করা কম্পাইলার, প্রজেক্ট/প্যাকেজ ম্যানেজার আর ভাষা সার্ভার পরিচালনা করতে পারবেন।


## Stack ইনস্টল করুন

Exercism-এর অনুশীলনী করার জন্য আপনার শুধু Stack দরকার।

Stack ইনস্টল করতে GHCup-এর ইনস্টলেশন কমান্ড বা স্ক্রিপ্টটি রান করুন।
ডিফল্টগুলো অনুসরণ করুন, তবে জানিয়ে দিন যে আপনি Stack-ও ইনস্টল করতে চান।

আপনি কি ভুল করে Stack ইনস্টল করা বাদ দিয়েছেন?
চিন্তার কিছু নেই: পরে শুধু `ghcup install stack` রান করুন।

GHCup ইনস্টল করবে

- **একটি কম্পাইলার** (GHC: the Glasgow Haskell Compiler)

  কঠোরভাবে বলতে গেলে Exercism-এর জন্য এটি আপনার দরকার নেই, তবে অনুশীলনীর ডিরেক্টরির বাইরে [GHCi][ghc-guide-ghci] নিয়ে খেলতে চাইলে এটি কাজে লাগে।

- **Cabal**

  একটি প্রজেক্ট/প্যাকেজ ম্যানেজার।
  Exercism-এর জন্য এটি আপনার দরকার নেই।

- **Stack**

  যে প্রজেক্ট/প্যাকেজ ম্যানেজারটি আপনি Exercism-এর জন্য ব্যবহার করবেন।
  এটি নিশ্চিত করবে যে প্রতিটি আলাদা প্রজেক্টের (অনুশীলনীর) জন্য আপনার সঠিক কম্পাইলার আর লাইব্রেরি আছে।

ইনস্টলেশন সফল হয়েছে কিনা যাচাই করতে নিচের যেকোনো একটি কমান্ড রান করুন

- `ghcup list`: সফল হলে টুল ভার্সনের একটি লম্বা তালিকা দেখবেন, যেখানে Stack installed হিসেবে চিহ্নিত থাকবে
- `stack --version`: সফল হলে দেখাবে `Version 2.7.5, Git revision ...`


## সঠিক GHC ভার্সন নিন

Stack প্রয়োজনে স্বয়ংক্রিয়ভাবে GHC ডাউনলোড ও ইনস্টল করবে।
আপনি টার্মিনালে নিচের কমান্ডগুলো রান করে ইনস্টলেশন শুরু করতে ও যাচাই করতে পারেন:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

এটি যদি এমন কিছু আউটপুট দেয়

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

তাহলে GHC সঠিকভাবে ইনস্টল হয়েছে।


## Haskell-এর সাথে কাজ করার জন্য আপনার এডিটর সেট আপ করুন

Haskell সাপোর্ট দেয় Haskell Language Server (HLS)।
ভাষা সাপোর্ট বাধ্যতামূলক নয়, তবে দৃঢ়ভাবে সুপারিশ করা হয়।


### Visual Studio Code (প্রস্তাবিত)

শুধু [Visual Studio Code-এর জন্য Haskell এক্সটেনশন][vscode-haskell] নিয়ে নিন।
এটি স্বয়ংক্রিয়ভাবে HLS ইনস্টল করতে GHCup ব্যবহার করবে, এরপর আপনি সম্পূর্ণ প্রস্তুত।

**নোট:** সদ্য ডাউনলোড করা অনুশীলনীর ক্ষেত্রে HLS চালু হতে সমস্যা হতে পারে।
এমন হলে `stack test` রান করুন এবং ভাষা সার্ভার রিস্টার্ট করুন।


### অন্যান্য এডিটর

এডিটর কনফিগারেশনের জন্য [HLS documentation on editor configuration][hls-editor-config] দেখুন।
HLS ম্যানুয়ালি ইনস্টল করার দরকার হতে পারে।
সেজন্য `ghcup install hls` রান করুন।
