# টেস্ট

টেস্টগুলো এভাবে চালান:

```bash
$ wrenc exercise-name.spec.wren
```

উদাহরণস্বরূপ, `hello-world`-এর ক্ষেত্রে:

```bash
$ wrenc hello-world.spec.wren
```


## স্কিপ করা টেস্ট বোঝা

`skip` মেথড টেস্ট স্যুটকে নির্দেশ দেয় যে একটি নির্দিষ্ট টেস্ট রান করা হবে না।

- কেন এগুলো স্কিপ করা হয়?

যাতে ব্যবহারকারীরা একবারে একটি টেস্টে মনোযোগ দিতে পারেন এবং নিজেদের সমাধান গড়ে তোলার সময় একটির পর একটি টেস্ট চালু করতে পারেন।

- এগুলো কীভাবে চালু করবেন?

একটি স্কিপ করা টেস্ট:

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

শুধু `skip.test`-এর জায়গায় `do.test` লিখলেই হবে।

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## আপনার প্রথম Wren মডিউল তৈরি করা

এই ট্র্যাকের টেস্টগুলো আপনার ইমপ্লিমেন্টেশনকে একটি Wren মডিউল হিসেবে ইমপোর্ট করার মাধ্যমে লোড করে: `import "./bob" for Bob`. আপনার ইমপ্লিমেন্টেশন এক্সপোর্ট করার জন্য কোনো বিশেষ সিনট্যাক্স নেই। শুধু `for Bob` ইমপোর্ট স্টেটমেন্টগুলোর সাথে মেলাতে আপনার ক্লাসের নাম `Bob` রাখুন, তাহলেই সব ঠিকঠাক কাজ করবে।

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

মডিউল সম্পর্কে আরও তথ্য পাবেন [Wren Modularity ডকুমেন্টেশন][modularity]-এ।
শুরুটা সহজ করতে প্রতিটি অনুশীলনীর ডিরেক্টরিতে একটি _স্কেলিটন_ Wren ফাইল দেওয়া আছে।

[modularity]: https://wren.io/modularity.html
