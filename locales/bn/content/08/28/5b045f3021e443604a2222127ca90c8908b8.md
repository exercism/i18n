# সম্পর্কে

Go-তে আমরা সমতা ও ক্রম নির্ধারণকারী অপারেটর দিয়ে মান তুলনা করতে পারি।
এরকম ৬টি অপারেটর আছে:

| তুলনা             | অপারেটর  |
| ------------------| --------- |
| সমান              | `==`      |
| সমান নয়           | `!=`      |
| ছোট               | `<`       |
| ছোট বা সমান       | `<=`      |
| বড়               | `>`       |
| বড় বা সমান       | `>=`      |

তুলনার ফলাফল সবসময়ই একটি বুলিয়ান মান:

```go
a := 3

a != 4 // true
a > 5  // false
```

## সমতার অপারেটর

সমতার অপারেটর `==` এবং `!=` যথাক্রমে যাচাই করে একটি মান অন্য একটি মানের সমান কি না।
Go-তে বেশিরভাগ টাইপের ওপরেই আমরা সমতার অপারেটর ব্যবহার করতে পারি।
এখানে কিছু কমন উদাহরণ দেওয়া হলো:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## ক্রম নির্ধারণকারী অপারেটর

ক্রম নির্ধারণকারী অপারেটর যাচাই করে একটি মান অন্য একটি মানের চেয়ে বড় (`>`), বড় বা সমান (`>=`), ছোট (`<`) কিংবা ছোট বা সমান (`<=`) কি না।
এই ধরনের তুলনা সংখ্যা, বাইট, রুন আর স্ট্রিংয়ের জন্য ব্যবহার করা যায়।
স্ট্রিং তুলনা করার সময় অভিধানের ক্রম (যা লেক্সিকোগ্রাফিক ক্রম নামেও পরিচিত) অনুসরণ করা হয়।

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
