# পরিচিতি

আপনার যখন `n`-সংখ্যক মানের একটি সিকোয়েন্স দরকার, যেখানে প্রতিটি মান নিজের ইনডেক্সের ওপর নির্ভর করে, তখন Factor আপনাকে দেয় `<iota>` (`0, 1, …, n-1` ইন্টিজারগুলোর একটি ভার্চুয়াল সিকোয়েন্স) আর `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` শুরুতেই ইন্টিজারগুলো তৈরি করে রাখে না; `map` ক্রমানুসারে একটার পর একটা এগুলোর ওপর কোয়োটেশনটি প্রয়োগ করে।

প্রতিটি ইনডেক্সের ফল যদি একটি ক্যারেক্টার কোড হয়, তবে `>string` ফলটিকে একটি স্ট্রিংয়ে রূপান্তর করে। ইনডেক্স-নির্ভর সিদ্ধান্ত থেকে ক্যারেক্টারের একটি সারি সাজানোর স্বাভাবিক উপায় এটাই:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```
