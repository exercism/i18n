# ইঙ্গিত

## সাধারণ

- [gleam/set][set]-এর ডকুমেন্টেশন পড়ুন
- [gleam/list][list]-এর ডকুমেন্টেশনও কাজে লাগতে পারে

## 1. একটি কালেকশন শুরু করুন

- সবচেয়ে উপযুক্ত ফাংশনটি হলো [`set.from_list`][from_list]

## 2. কালেকশনটি বাড়ান

- [`set.insert` ফাংশনটি][insert] ব্যবহার করুন
- [`set.contains` ফাংশনটি][contains] ব্যবহার করুন

## 3. ট্রেডিং শুরু করুন

- [`set.contains` ফাংশনটি][contains] ব্যবহার করুন
- [`set.insert` ফাংশনটি][insert] ব্যবহার করুন
- [`set.delete` ফাংশনটি][delete] ব্যবহার করুন

## 4. প্রতিটির মধ্যে একটিই থাকতে পারে

- `Set`-এর একটি বৈশিষ্ট্য হলো এটি কেবল ইউনিক মান ধরে রাখে
- [`set.from_list` ফাংশনটি][from_list] ব্যবহার করুন
- [`set.to_list` ফাংশনটি][to_list] ব্যবহার করুন
- `set.to_list` সাজানো অ্যারে রিটার্ন করবে এমন কোনো নিশ্চয়তা নেই

## 5. সবার কাছে যা যা কার্ড আছে

- [`set.intersection` ফাংশনটি][intersection] ব্যবহার করুন
- [`set.to_list` ফাংশনটি][to_list] ব্যবহার করুন

## 6. সবগুলো কার্ড

- অ্যাকুমুলেটর হিসেবে [`set.new`][new] ব্যবহার করুন
- [`set.union` ফাংশনটি][union] ব্যবহার করুন
- [`set.size` ফাংশনটি][size] ব্যবহার করুন

## 7. জেতার জন্য শাইনি

- [`set.filter` ফাংশনটি][filter] ব্যবহার করুন
