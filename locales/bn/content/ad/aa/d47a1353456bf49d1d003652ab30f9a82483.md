# পূর্বশর্ত

D ভাষার ট্র্যাকে আপনার সিস্টেমে নিচের সফটওয়্যারগুলো ইনস্টল থাকা প্রয়োজন:

* একটি D ভার্সন ২ কম্পাইলার
* (ঐচ্ছিক তবে সুপারিশকৃত) DUB

## পূর্বশর্ত: D ভার্সন ২ কম্পাইলার

D ভাষার ওয়েবসাইটে [dlang.org](https://dlang.org) থেকে রেফারেন্স কম্পাইলার DMD (Digital Mars D)-এর সর্বশেষ কম্পাইলার ভার্সনটি বেশ কয়েকটি প্ল্যাটফর্মের জন্য ডাউনলোড ও ইনস্টল করা যায়।
আরও তথ্যের জন্য [অফিসিয়াল ডাউনলোড পেজ](https://dlang.org/download.html) দেখুন।
Windows-এ বিকল্প উপায় হলো [Chocolatey ব্যবহার করা](https://chocolatey.org/packages/dmd)।
Intel-ভিত্তিক Mac-এ বিকল্প উপায় হলো [Homebrew ব্যবহার করা](https://formulae.brew.sh/formula/dmd)।

### অন্যান্য কম্পাইলার
নিজস্ব backend ব্যবহার করা DMD রেফারেন্স কম্পাইলার ছাড়াও আরও দুটি কম্পাইলার আছে, যেগুলো dlang.org-এর ডাউনলোড সেকশন থেকে নামানো যায়:

* [GDC](http://gdcproject.org/downloads) যা GCC backend ব্যবহার করে
* [LDC](https://github.com/ldc-developers/ldc#installation) যা LLVM backend-ভিত্তিক

GDC আর LDC সবসময় DMD frontend-এর সর্বশেষ ভার্সনে থাকে না, তবে অন্য প্ল্যাটফর্ম, যেমন ARM-এর সাপোর্টের পাশাপাশি আরও ভালো অপটিমাইজেশন লেভেল দেয়।

আরও তথ্যের জন্য [উইকিটি](https://wiki.dlang.org/Compilers) দেখুন।

### IDE সাপোর্ট

বিভিন্ন IDE-তে D ভাষার সাপোর্টও আছে, যেমন Visual Studio-র জন্য [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) এবং IntelliJ-এর CLion-এর জন্য [D plugin](https://plugins.jetbrains.com/plugin/7727?pr=clion)।
আরও তথ্যের জন্য [উইকিটি](https://wiki.dlang.org/IDEs) দেখুন।

### পূর্বশর্ত: DUB

[DUB](https://github.com/dlang/dub) হলো D-এর একটি বিল্ড ম্যানেজার।

টেস্ট চালানোর কাজটি সহজ করতে আমরা এটি সুপারিশ করি, তবে আপনি যদি DUB ইনস্টল করতে না পারেন বা না চান, তবুও DUB ছাড়া চালানো সম্ভব।

#### Windows

[DUB ওয়েবসাইটের ডাউনলোড পেজে](https://code.dlang.org/download) একটি Windows ইনস্টলার আছে।

#### MacOS

* [DUB ওয়েবসাইটের ডাউনলোড পেজে](https://code.dlang.org/download) macOS বাইনারি আছে।
* Intel এবং Apple Silicon-ভিত্তিক উভয় Mac-এর জন্যই [একটি Homebrew প্যাকেজও পাওয়া যায়](https://formulae.brew.sh/formula/dub):

#### Linux

* [DUB ওয়েবসাইটের ডাউনলোড পেজে](https://code.dlang.org/download) Linux বাইনারি আছে।
* বিভিন্ন ডিস্ট্রিবিউশনের জন্য প্যাকেজ দেওয়া আছে:
    * [ArchLinux](https://www.archlinux.org/packages/community/x86_64/dub/)
    * [Debian/Ubuntu](http://d-apt.sourceforge.net/)
    * [Gentoo](https://github.com/gentoo/dlang/tree/master/dev-util/dub)
    * [OpenSUSE](http://software.opensuse.org/download.html?project=devel%3Alanguages%3AD&package=dub)
