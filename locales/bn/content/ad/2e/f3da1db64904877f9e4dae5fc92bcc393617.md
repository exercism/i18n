# ভূমিকা

## গণিতের ফাংশন

বর্গমূল, কোণ আর বৃদ্ধির রেখা শুধু `+`, `-`, `*` আর `/` দিয়ে বের করা কঠিন। [`math.functions`][math.functions] ভোকাবুলারিতে এমন শব্দ আছে যা আপনার হয়ে সেগুলো বের করে দেয়, আর [`math.constants`][math.constants]-এ আছে π। অন্য প্রতিটি শব্দের মতো, প্রত্যেকটিই তার ইনপুট স্ট্যাক থেকে নেয় আর তার উত্তর সেখানেই রেখে দেয়।

## বর্গমূল

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

5 মিটার লম্বা একটি মই, যার পাদদেশ দেয়াল থেকে 3 মিটার দূরে, দেয়াল বরাবর 4 মিটার ওপরে পৌঁছায়:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## পাই

`pi` (`math.constants` থেকে) π পুশ করে, অর্থাৎ একটি বৃত্তের ব্যাস তার পরিধি বরাবর কতবার বসে:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## কোণ রেডিয়ানে

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` আর `tan` একটি কোণ নেয়, তবে ডিগ্রিতে নয়। তারা **রেডিয়ান** ব্যবহার করে, যেখানে অর্ধেক ঘূর্ণন 180 নয়, π। তাদের ডিগ্রি দিলে সেটা এরর নয়: চুপচাপ ভুল উত্তর দেয়।

`deg>rad` ডিগ্রিকে রেডিয়ানে রূপান্তর করে, আর `rad>deg` আবার ফিরিয়ে আনে। এগুলো π দিয়ে গুণ করে 180 দিয়ে ভাগ করার মতোই, বা উল্টোটার মতো:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

`sin` কল করার আগে ডিগ্রিকে রেডিয়ানে রূপান্তর করুন:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

30 ডিগ্রিতে 10 মিটার লম্বা একটি ঢাল 5 মিটার ওপরে ওঠে। উত্তরটি `4.999999999999999` হিসেবে প্রিন্ট হয়, কারণ গণিতের ফাংশনগুলো নিকটতম ফ্লোট দেয়, সঠিক মান নয়। রূপান্তর ছাড়া, `30 sin` 30-কে রেডিয়ান (প্রায় পাঁচ পূর্ণ ঘূর্ণন) হিসেবে ধরে আর ঢালটি `-9.88` মিটার "ওঠে"।

## কোণ নির্ণয়

`fatan2` উল্টো পথে যায়: কতটা ওপরে আর কতটা আড়াআড়ি তা দেওয়া থাকলে, এটি রেডিয়ানে কোণটি উত্তর দেয়। এটি থাকে [`math.libm`][math.libm]-এ। *উপরের* দূরত্ব আগে স্ট্যাকে যায়, তারপর *আড়াআড়ি* দূরত্ব:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

কোণটি মাপা হয় ধনাত্মক *আড়াআড়ি* দিক থেকে। `fatan2` দুটি দূরত্বেরই চিহ্ন দেখে, তাই এটি −180 থেকে 180 ডিগ্রি পর্যন্ত যেকোনো জায়গার উত্তর দিতে পারে।

## দশের ঘাত: 10^ আর log10

`10^` 10-কে একটি ঘাতে তোলে:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` উল্টো পথে ফিরে আসে। এটি প্রশ্নটির উত্তর দেয়: "10-এর কোন ঘাতে এই সংখ্যাটি পাওয়া যায়?" সেই উত্তরটাই সংখ্যাটির **লগারিদম**:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ আর log

`e^` আর `log` একই জোড়া, তবে 10-এর জায়গায় *e* (প্রায় 2.718)। `e^` *e*-কে একটি ঘাতে তোলে, আর `log` উত্তর দেয় "*e*-এর কোন ঘাতে এই সংখ্যাটি পাওয়া যায়?"

```
e^  ( x -- y )
log ( x -- y )
```

যে কোনো কিছু প্রতি ধাপে একই অনুপাতে বাড়ে বা কমে, তার জন্য গণিতবিদরা *e* ব্যবহার করেন। সুদে আয় করা টাকা একটি উদাহরণ, আর ঠান্ডা হতে থাকা এক কাপ চা আরেকটি:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` হলো `e^`-এর বিপরীত ক্রিয়া। সেটি প্রশ্নটির উল্টো দিক থেকে উত্তর দেয়: ব্যবধান 40 ডিগ্রিতে নামতে কত মিনিট লাগবে?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
