# নির্দেশাবলি

বাড়তি কুকিটি কাউকে দিয়ে দেওয়ার সময় আপনি কী বলবেন, তা নির্ধারণ করাই আপনার কাজ।

যদি আপনি ব্যক্তিটির নাম জানেন (যেমন তাঁর নাম যদি Do-yun হয়), তাহলে আপনি বলবেন:

```text
One for Do-yun, one for me.
```

যদি আপনি ব্যক্তিটির নাম না জানেন, তাহলে তার বদলে _you_ বলবেন।

```text
One for you, one for me.
```

এখানে কিছু উদাহরণ দেওয়া হলো:

| নাম    | সংলাপ                       |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
