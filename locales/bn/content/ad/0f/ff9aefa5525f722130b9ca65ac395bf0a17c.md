# ইনস্টলেশন

## যা যা প্রয়োজন

Common Lisp-এ ডেভেলপ করার জন্য যেসব মৌলিক জিনিস দরকার, সেগুলো হলো:

- একটি Lisp "ইমপ্লিমেন্টেশন", যা দিয়ে আপনি কোড কম্পাইল ও চালাতে পারবেন, এবং একটি REPL-ও পাবেন।
- Lisp কোড লেখার সুবিধাসহ একটি টেক্সট এডিটর।
- (থাকলে ভালো) Common Lisp ভাষার বহুল ব্যবহৃত রেফারেন্স, ["Common Lisp Hyperspec"][hyperspec]।

## Roswell

[Roswell][roswell] হলো Common Lisp ইমপ্লিমেন্টেশন ইনস্টল ও ম্যানেজ করার একটি কমান্ড, আর Lisp অ্যাপ্লিকেশন ডেভেলপ ও ডিস্ট্রিবিউট করা সহজ করতে এর অনেক ফিচার আছে।
ইনস্টল ও টেস্ট করার ধাপগুলো সহজ করতে আমরা এটি ব্যবহার করছি।

### Roswell ইনস্টল করুন

[Installation Guide][ros-inst] দেখুন এবং আপনার প্ল্যাটফর্মের জন্য নির্দেশনা অনুসরণ করুন।
বেশিরভাগ ব্যবহারকারীর জন্য নিচেরটাই যথেষ্ট হবে:

* MacOS ও Linux-এর জন্য [Homebrew][brew] দিয়ে এটি সহজ:
  ```sh
  brew install roswell
  ```
* Windows-এর জন্য [Scoop][scoop] ব্যবহার করুন:
  ```powershell
  scoop install roswell
  ```

আপনি প্রথমবার Roswell ব্যবহার করলে এটি SBCL ও Quicklisp নামিয়ে ইনস্টল করবে।
শুধু এটি রান করুন:
```sh
ros help
```

REPL-এ ঢুকতে লিখুন
```sh
ros run
```

## আপনার টেক্সট এডিটর কনফিগার করুন

Common Lisp-এ নতুন যারা, বিশেষ করে যাদের আগে Emacs নিয়ে অভিজ্ঞতা আছে, তারা [Portacle, the Portable Common Lisp Environment][portacle] ইনস্টল করে সহজে ও দ্রুত শুরু করতে পারেন।
এটি ফ্রি ও পূর্ণাঙ্গ ফিচারসমৃদ্ধ, সব প্রচলিত প্ল্যাটফর্মে চলে এবং শুরুতেই ব্যবহারের জন্য প্রস্তুত অবস্থায় আসে। এতে থাকবে:

- একটি Lisp ইমপ্লিমেন্টেশন: SBCL, সাথে Quicklisp ও ASDF।
- একটি টেক্সট এডিটর: Emacs

... সাথে Lisp কোড লেখার জন্য অনেক অ্যাড-অন:
- SLIME, "Superior Lisp Interaction Mode for Emacs", Emacs-কে একটি Common Lisp IDE-তে পরিণত করে
- ParEdit, যা বন্ধনী নিয়ে কাজ করা সহজ করে তোলে।

সবকিছুই আগে থেকেই কনফিগার করা অবস্থায় আসে। [হোমপেজ][portacle] থেকে ডাউনলোড করে Portacle ইনস্টল করুন।

দ্রষ্টব্য: Emacs (টেক্সট এডিটর) প্রথমে বিভ্রান্তিকর লাগতে পারে, যদি আপনি এতে অভ্যস্ত না থাকেন। ভাগ্যক্রমে, Emacs ও SLIME নিয়ে অনলাইনে অনেক প্রাইমার পাওয়া যায়।

## প্রচলিত পদ্ধতিতে শুরু

আপনি যদি প্রয়োজনীয় টুলগুলো আলাদা আলাদা ইনস্টল করতে পছন্দ করেন, তাহলে সেগুলো ইনস্টল ও সেট আপ করতে হবে:

- Lisp-সচেতন একটি টেক্সট এডিটর: [Emacs][emacs]-এর সাথে [Slime][slime] বা [Sly][sly] প্যাকেজ একটি প্রচলিত পছন্দ, তবে [VIM][vim]-এর সাথে [SLIMV][slimv], [Atom][atom]-এর সাথে [SLIMA][slima] বা [VSCode][vscode]-এর সাথে একটি [Common Lisp প্লাগইন][vscode-plugin]-ও ভালো।
- একটি Common Lisp ইমপ্লিমেন্টেশন: [SBCL][sbcl] একটি "নিরাপদ" পছন্দ, যা Linux, MacOS ও Windows জুড়ে কাজ করে। যেহেতু ভাষাটি একটি স্ট্যান্ডার্ডের ওপর ভিত্তি করে তৈরি, তাই অন্য [সঙ্গতিপূর্ণ ইমপ্লিমেন্টেশন][awesome-cl-implementations]-ও কাজ করবে।
- লাইব্রেরি ম্যানেজমেন্টের জন্য [Quicklisp][quicklisp]। এটি ডাউনলোড করার পর [নির্দেশনা][quicklisp-install] অনুসরণ করুন, যাতে এটি আপনার Common Lisp ইমপ্লিমেন্টেশনের সাথে সঠিকভাবে যুক্ত হয়।
