# পরিচিতি

[`Basics`][basics] ধারণায় ফাংশন ডিফাইন করার দুটি উপায় সম্পর্কে জানানো হয়েছে।

সবচেয়ে সাধারণভাবে, মাল্টিলাইন রূপটি:

```julia
function muladd(x, y, z)
    x * y + z
end
```

আর সংক্ষিপ্ত ডেফিনিশনের জন্য "অ্যাসাইনমেন্ট", বা "সিঙ্গেল-লাইন" রূপ:
```julia
muladd(x, y, z) = x * y + z
```

তৃতীয় আরও সংক্ষিপ্ত একটি রূপে, একবার ব্যবহারের ছোট একটি ফাংশন নাম ছাড়াই তৈরি করা যায়:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

এক্ষেত্রে `x -> 2x` হলো একটি "অ্যানোনিমাস ফাংশন"।
এটি অন্য কিছু ভাষায় "ল্যাম্বডা ফাংশন" নামে পরিচিত জিনিসটিরই সমতুল্য।

মনে রাখবেন, একাধিক আর্গুমেন্ট দিলে বন্ধনী লাগে, যেমন `(x, y) -> x * y`।

জুলিয়া কোডে অ্যানোনিমাস ফাংশন কমন, বিশেষ করে `map()` আর `filter()`-এর মতো হায়ার-অর্ডার ফাংশনের সঙ্গে মিলিয়ে ব্যবহার করলে।

## ফাংশনের আর্গুমেন্ট

সিলেবাসে এতদিন আমরা কেবল এমন ফাংশন দেখেছি যেগুলোর আর্গুমেন্টের সংখ্যা নির্দিষ্ট, আর ফাংশন কল করার সময় সেগুলো সবই সঠিক ক্রমে দিতে হয়।
এতে সুবিধা সীমিত হয়ে যেত, তাই আরও কিছু বিকল্প আছে।

### ঐচ্ছিক আর্গুমেন্ট

অনেক ভাষার মতোই জুলিয়া ফাংশন ডেফিনিশনে প্রতিটি আর্গুমেন্টের জন্য ডিফল্ট মান দেওয়ার সুযোগ দেয়।

তখন ফাংশন কল করার সময় ওই আর্গুমেন্টের মান দিতে পারেন, নয়তো সেটি বাদ দিয়ে ডিফল্ট মানের উপর ভরসা করতে পারেন।

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

ডিফল্ট _ছাড়া_ সব আর্গুমেন্ট ডিফল্ট _সহ_ সব আর্গুমেন্টের আগে থাকতে হবে, অর্থাৎ `f(x=2, y)` বৈধ হবে না।

### কিওয়ার্ড আর্গুমেন্ট

এতক্ষণের সব উদাহরণেই `positional arguments` ব্যবহার করা হয়েছে, যেখানে ফাংশন কলে দেওয়া মানগুলোকে ফাংশন ডেফিনিশনের সংশ্লিষ্ট আর্গুমেন্টের ক্রমের সঙ্গে মিলিয়ে দিতে হয়।

অনেক ভাষার মতোই জুলিয়াও `keyword arguments` ব্যবহার করতে দেয়।
ফাংশন কল করার সময় আর্গুমেন্টের নাম উল্লেখ করতে হয়, তবে এরপর একাধিক কিওয়ার্ড আর্গুমেন্ট যেকোনো ক্রমে দেওয়া যায়।

জুলিয়ার একটি বিশেষ বৈশিষ্ট্য হলো, ফাংশন ডেফিনিশনে কিওয়ার্ড আর্গুমেন্ট (যদি থাকে) লেখার আগে একটি সেমিকোলন `;` দিতে হয়, যাতে সেগুলো পজিশনাল আর্গুমেন্ট থেকে আলাদা করা যায়।
ফাংশন কলে শেষ পজিশনাল আর্গুমেন্ট আর প্রথম কিওয়ার্ড আর্গুমেন্টের মাঝে `;` বা `,` যেকোনোটি ব্যবহার করা যায়।

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

চাইলে ডিফল্ট মানও দেওয়া যায়, পজিশনাল আর্গুমেন্টের ক্ষেত্রে ঠিক যেমনটা করা হয়।

প্যারামিটারের মতো একই নামের কোনো ভ্যারিয়েবল আগেই হিসাব করে রাখা থাকলে, ফাংশন কলে `myarg=myarg`-এর মতো সিনট্যাক্স লেখা কমন ব্যাপার।
এমন ক্ষেত্রে শর্টহ্যান্ড সিনট্যাক্স ব্যবহার করা যায়:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### স্প্ল্যাট ও স্লার্প

জুলিয়া সিনট্যাক্সের একটি দরকারি দিকের প্রচলিত নাম এগুলো, যদি আপনি কখনো ভেবে থাকেন।
দুটোই `...` অপারেটরের কথা বোঝায়।

#### স্প্ল্যাট

ফাংশন _কল_ করার সময় স্প্ল্যাটিং ব্যবহার করা হয়, যাতে একটি কালেকশনকে ভেঙে ফাংশনের প্রয়োজনীয় আলাদা আলাদা মানে পরিণত করা যায়।

ব্যাখ্যা করার চেয়ে উদাহরণ দিয়ে দেখানোই সহজ:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

কিছু "ফাংশন কল" সিনট্যাক্টিক সুগারের আড়ালে থাকে, তাই স্প্ল্যাটিং কম স্পষ্ট উপায়েও ব্যবহার করা যায়।

যেমন, মাল্টিপল অ্যাসাইনমেন্ট ভেতরে ভেতরে একটি টাপল কনস্ট্রাক্টর ফাংশন ব্যবহার করে:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

স্প্ল্যাটিং করে কিওয়ার্ড আর্গুমেন্টও দেওয়া যায়, সাধারণত একটি `named tuple` ব্যবহার করে। 
একটি `Dict` দিয়েও কাজ হবে, তবে কী (key) গুলো অবশ্যই সিম্বল হতে হবে (স্ট্রিং দিয়ে কাজ হবে না)।

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### স্লার্প

ফাংশন _ডেফিনিশনে_ স্লার্পিং ব্যবহার করা হয়, যাতে ইচ্ছেমতো সংখ্যক আলাদা মানকে একটি কালেকশনে প্যাক করা যায়।

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

স্লার্প করা আর্গুমেন্টের নাম (এক্ষেত্রে `more`) কোনো গুরুত্বপূর্ণ বিষয় নয়।
এই ভ্যারিয়েবলের টাইপ কম্পাইলার ঠিক করে, তবে পজিশনাল আর্গুমেন্টের ক্ষেত্রে তা সম্ভবত `tuple` বা তার মতো কিছু হয়।

কিওয়ার্ড আর্গুমেন্টও স্লার্প করা যায়, যার ফলে একটি `Dict` (বা অনুরূপ কিছু) পাওয়া যায়।

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

কলে যেকোনো কিওয়ার্ড আর্গুমেন্ট ব্যবহার করা যায়।
কোন কিওয়ার্ডে সাড়া দেবে আর কোনটি উপেক্ষা করবে, তা ঠিক করার দায়িত্ব ফাংশন ডেফিনিশনের।
