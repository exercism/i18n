# পরিচিতি

C++-এ বুলিয়ানগুলো `bool` টাইপ দিয়ে প্রকাশ করা হয়।
একটি `bool`-এর মান হয় `true` নয়তো `false`।

## লজিক্যাল অপারেটর

C++ তিনটি বুলিয়ান অপারেটর সমর্থন করে: `!` (নট), `&&` (অ্যান্ড), এবং `||` (অর)।
আপনি বিকল্প রূপ হিসেবে `not`, `and`, এবং `or`-ও ব্যবহার করতে পারেন।

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## প্রিসিডেন্স

তিনটি বুলিয়ান অপারেটরের প্রত্যেকটির _অপারেটর প্রিসিডেন্স_ আলাদা।
এর ফলে এগুলো এই ক্রমে মূল্যায়ন করা হয়: প্রথমে `!`, দ্বিতীয়তে `&&`, এবং শেষে `||`।
আপনি যদি ভিন্ন ক্রম চাপিয়ে দিতে চান, তাহলে একটি বুলিয়ান এক্সপ্রেশন বন্ধনীর মধ্যে রাখতে পারেন (অর্থাৎ `()`), কারণ বন্ধনীর অপারেটর প্রিসিডেন্স আরও বেশি।

```cpp
!true && false   // => false
!(true and false) // => true
```

## রূপান্তর

আপনি যদি এমন জায়গায় `true` বা `false` ব্যবহার করেন যেখানে একটি সংখ্যা প্রত্যাশিত, তাহলে সেগুলো যথাক্রমে `1` এবং `0`-এ রূপান্তরিত হবে।
আপনি যদি একটি বুলিয়ান অপারেশনে একটি সংখ্যা ব্যবহার করেন, তাহলে `0` ছাড়া বাকি সবকিছু, এমনকি ঋণাত্মক মানও, `true` হিসেবে ধরা হয়।

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
