# পরিচিতি

## স্ট্রাক্ট

স্ট্রাক্ট হলো [ম্যাপের][exercism-maps] উপরে তৈরি একটি এক্সটেনশন, যা কম্পাইল-টাইম চেক আর ডিফল্ট মান দেয়। স্ট্রাক্টের নামকরণ করা হয় যে মডিউলে এটি ডিফাইন করা হয় সেই মডিউলের নাম অনুসারে। স্ট্রাক্ট ডিফাইন করতে `defstruct` কনস্ট্রাক্ট ব্যবহার করুন। সাধারণত এই কনস্ট্রাক্টটি মডিউল ডেফিনিশনের ঠিক পরেই বসে। `defstruct` হয় অ্যাটমের একটি লিস্ট নেয় (`nil` ডিফল্ট মানের জন্য), নাহয় একটি কিওয়ার্ড লিস্ট নেয় (নির্দিষ্ট ডিফল্ট মানের জন্য)। যে ফিল্ডগুলোর ডিফল্ট মান নেই সেগুলো অবশ্যই ডিফল্ট মানযুক্ত ফিল্ডগুলোর আগে থাকতে হবে।

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### ফিল্ড অ্যাক্সেস করা ও আপডেট করা

যেহেতু স্ট্রাক্ট ম্যাপের উপরে তৈরি, তাই মান পাওয়া ও পরিবর্তন করার জন্য আমরা বেশিরভাগ ম্যাপ ফাংশনই ব্যবহার করতে পারি। স্ট্রাক্টের জন্য _Access Behaviour_ **ইমপ্লিমেন্ট করা হয়নি**। এর বদলে স্ট্রাক্টের ফিল্ড অ্যাক্সেস করতে _static access operator_ `.` ব্যবহার করার পরামর্শ দেওয়া হয়।

- ফিল্ডের মান get/fetch করা:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- ফিল্ডের মান আপডেট করা

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### প্যাটার্ন ম্যাচিং

স্ট্রাক্টের নাম দিয়ে বা নাম ছাড়াই স্ট্রাক্ট প্যাটার্ন ম্যাচিংয়ে ব্যবহার করা যায়।

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

প্যাটার্নে স্ট্রাক্টের নাম যোগ করলে আপনি নিশ্চিত করতে পারেন যে বাম ও ডান দুই দিকেই একই টাইপের স্ট্রাক্ট আছে।

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### ফিল্ডের মান ইনিশিয়ালাইজ করা বাধ্যতামূলক করা

স্ট্রাক্ট তৈরি হওয়ার সময় মানগুলো ইনিশিয়ালাইজ হয়েছে কি না তা নিশ্চিত করতে আমরা ফিল্ডের কী (key)-গুলোর একটি লিস্টসহ `@enforce_keys` মডিউল অ্যাট্রিবিউট ব্যবহার করতে পারি। কোনো কী (key) লিস্টে না থাকলে তার মান `nil` হবে, যেমন উপরের উদাহরণে দেখা যায়। কোনো বাধ্যতামূলক কী (key) ইনিশিয়ালাইজ না হলে একটি এরর রেইজ হয়।

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
