# ভূমিকা

## টাইপ অ্যালিয়াস

Gleam-এ টাইপ অ্যালিয়াস দিয়ে আগে থেকেই থাকা কোনো টাইপের জন্য এমন একটি সুবিধাজনক নাম দেওয়া যায়, যা না থাকলে লিখতে বেশ ঝামেলা হতো।

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type` দিয়ে লিখলে অ্যালিয়াসটি যে মডিউলে ডিফাইন করা হয়েছে তার বাইরেও ব্যবহার করা যায়। `pub` বাদ দিলে অ্যালিয়াসটি প্রাইভেট হয়ে যায় এবং অন্য কোনো মডিউল থেকে রেফার করা যায় না।
