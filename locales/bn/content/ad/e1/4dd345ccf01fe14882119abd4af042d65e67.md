# টেস্ট চালানো

আপনার অপারেটিং সিস্টেম বেছে নিন:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. একটি Command Prompt খুলুন।
2. প্রথম অনুশীলনীটি ডাউনলোড করুন:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. ডিরেক্টরি বদলে exercism ফোল্ডারে যান:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. টেস্টগুলো চালান:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(শুরুতে টেস্ট ফেল করলেও চিন্তার কিছু নেই, প্রতিটি অনুশীলনী আপনি এভাবেই শুরু করেন।)_

5. অনুশীলনীটি সমাধান করুন। `instructions.append.md` গাইডটি খুঁজে বের করে তা অনুসরণ করুন ([GitHub-এ দেখুন](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial))।

শুভকামনা!
