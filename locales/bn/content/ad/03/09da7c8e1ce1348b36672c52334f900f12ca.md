# নির্দেশনা

লিলি রান্না করতে ভালোবাসেন।
তিনি বন্ধুদের নিয়ে একটি পিৎজা পার্টি করতে চান।
উপকরণগুলোর সর্বোচ্চ ব্যবহার করতে হলে, শুরু করার আগে কোন উপকরণ কতটা লাগবে সেটা তার জানা দরকার।

এটি সমাধান করতে লিলি পরিকল্পনার কিছু অংশ স্বয়ংক্রিয় করার জন্য একটি প্রোগ্রামের খসড়া তৈরি করেছেন, তবে সেটি শেষ করতে আপনার সাহায্য দরকার।
আপনি কি লিলিকে অনুপাতে নিখুঁত পিৎজা পার্টি করতে সাহায্য করবেন?

## 1. ময়দার অনুপাত

লিলি পাতলা ক্রাস্টযুক্ত, পাতলা ও মুচমুচে পিৎজা পছন্দ করেন।
মাঝের অংশের জন্য কমপক্ষে ২০০ গ্রাম ময়দা লাগে, তবে প্রতিটি পরিবেশিত ব্যক্তির জন্য আরও ২০ গ্রাম ময়দা লাগে।

`grams = pizzas * ((persons * 20) + 200)`

লিলির একটি ফাংশন দরকার যা:

- পিৎজার সংখ্যা নেয়
- প্রতিটি পিৎজা কতজনকে পরিবেশন করবে সেই সংখ্যা নেয়
- এবং নিকটতম গ্রামে প্রয়োজনীয় ময়দা রিটার্ন করে।

উদাহরণস্বরূপ, ৮ জনকে খাওয়ানো যায় এমন ৪টি পিৎজা বানাতে:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. এক ছোঁয়া সস

লিলি সস লাগাতে খুব সতর্ক, তবে তার পিৎজার আকার সবসময় একই রকম থাকে না।
তার অভিজ্ঞতা থেকে তিনি জানেন, প্রতিটি পিৎজায় ১২৫ মিলিলিটার সস লাগে।
লিলির একটি ফাংশন দরকার, যা হিসাব করবে কত ক্যান সস কিনতে হবে।

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

উদাহরণস্বরূপ, লিলিকে যদি ৮টি পিৎজা বানাতে হয় এবং প্রতি ক্যানে ২৫০ মিলিলিটার থাকে:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. একটু চিজ, প্লিজ

চিজ নিখুঁত ঘনক আকারে পাওয়া যায় এবং আকার অনুযায়ী বিক্রি হয়।

লিলি যে সূত্রটি ব্যবহার করেন সেটি পিৎজার ক্ষেত্রফলের সূত্র নয়, কারণ তিনি _চান না_ যে চিজ পুরো ক্ষেত্রফল ঢেকে ফেলুক।
কোনো বাহুর দৈর্ঘ্যের (`cheese_dimension`) একটি চিজ ঘনক থেকে কোনো ব্যাসের (`diameter`) কতটি পিৎজা বানানো যাবে তা নির্ণয় করতে তিনি নিচের সূত্রটি ব্যবহার করার সিদ্ধান্ত নিলেন:

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

এমন একটি ফাংশন তৈরি করুন যা:

- চিজ ঘনকের একটি বাহুর দৈর্ঘ্য নেয়
- চিজ স্তরের কাঙ্ক্ষিত পুরুত্ব নেয়
- পিৎজার ব্যাস নেয়
- এবং লিলির সূত্র ব্যবহার করে নিচের দিকে রাউন্ড করে কতটি পিৎজা বানানো যাবে সেই সংখ্যা রিটার্ন করে।

উদাহরণস্বরূপ, ২৫x২৫x২৫ সেমি একটি চিজ ঘনক, ০.৫ সেমি পুরু চিজ স্তর এবং ৩০ সেমি ব্যাসের পিৎজা হলে:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. ন্যায্য ভাগ

সবশেষে, লিলি চান তার প্রতিটি পিৎজা ৮ টুকরোয় ভাগ হোক এবং বন্ধুদের মধ্যে সমানভাবে বিতরণ হোক।

এমন একটি ফাংশন তৈরি করুন যা:

- পিৎজার সংখ্যা এবং বন্ধুর সংখ্যা নেয়
- এবং প্রত্যেকে সমান সংখ্যক টুকরো নিলে কত টুকরো অবশিষ্ট থাকবে সেই সংখ্যা রিটার্ন করে।

উদাহরণস্বরূপ:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
