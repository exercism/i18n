# Babashka টেক্সট এডিটর ইন্টিগ্রেশন

## nREPL

### Emacs: [CIDER](https://cider.mx/)

এটিই সবকিছুর সূচনা করেছিল, আর এর [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) ইকোসিস্টেমই অন্য অনেক প্লাগ-ইনকে শক্তি জোগায়।

1. আপনার প্ল্যাটফর্মের জন্য [Emacs](https://www.gnu.org/software/emacs/download.html) ইনস্টল করুন।

2. একটি বিদ্যমান Emacs ডিস্ট্রিবিউশন বেছে নিন ([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) এবং [Doom Emacs](https://github.com/hlissner/doom-emacs) সবই দারুণ) অথবা আপনার `init.el` ফাইলে এটি যোগ করুন:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

[CIDER ডকুমেন্টেশন](https://docs.cider.mx/cider/platforms/babashka.html) থেকে সংক্ষেপে:

প্রজেক্ট ডিরেক্টরি থেকে nREPL সার্ভার চালু করুন:

```bash
$ bb --nrepl-server
```

`C-x C-f` দিয়ে যেকোনো Clojure ফাইল (`.clj`) তৈরি করুন বা খুলুন, তারপর `C-c C-x c j` (cider-connect-clj) দিয়ে সেটিতে কানেক্ট করুন।

[মৌলিক CIDER কি-বাইন্ডিং](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` or `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` or `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. [VSCode](https://code.visualstudio.com/) ইনস্টল করুন।

2. [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva) ইনস্টল করুন।

বর্তমানে Calva আপনার সোর্স কোডকে একটি ফোল্ডারের প্রেক্ষাপটে বোঝে, অর্থাৎ একটি Clojure প্রজেক্ট হিসেবে। এটি তৈরির একটি সুন্দর উপায় হলো [clj-new](https://github.com/seancorfield/clj-new) ব্যবহার করা:

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. প্রজেক্টের ডিরেক্টরি থেকে nREPL সার্ভার চালু করুন:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

VSCode-এ প্রজেক্ট ফোল্ডারটি খুলুন (Ctrl+K Ctrl+O), অথবা অন্য একটি টার্মিনাল থেকে:

```bash
$ cd bbtest
bbtest$ code .
```

4. VSCode-এ Calva-র `Connect to a running REPL` কমান্ডটি চালান (ctrl+alt+c ctrl+alt+c)। জিজ্ঞাসা করা হলে `Generic` প্রজেক্ট বেছে নিন, আর `localhost:1667` লিখুন।

REPL কমান্ড:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. IntelliJ [এখান থেকে](https://www.jetbrains.com/idea/download/index.html) ডাউনলোড করুন।
2. [ইউজার গাইড](https://cursive-ide.com/userguide/) অনুসরণ করে Cursive ইনস্টল করুন এবং [ডিপেন্ডেন্সি কনফিগার করুন](https://cursive-ide.com/userguide/deps.html)।
3. আরও তথ্যের জন্য [Cursive: Babashka নিয়ে কাজ করা](https://cursive-ide.com/userguide/babashka.html) দেখুন।

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. [Atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/) ইনস্টল করুন

2. `chlorine` প্যাকেজটি ইনস্টল করুন

3. socket REPL চালু করুন:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Atom-এর Command Palette খুলুন (ctrl+shift+p) এবং `localhost` `1666` দিয়ে `Connect Clojure Socket REPL` কমান্ডটি চালান

5. `Edit` মেনু -> `Keymap...` এর মাধ্যমে keymap.cson-এ কি-বাইন্ডিং সম্পাদনা করুন:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Emacs-এর জন্য, আপনার `init.el` ফাইলে এটি যোগ করে [inf-clojure](https://github.com/clojure-emacs/inf-clojure) ইনস্টল করুন:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

উপরের মতো socket REPL চালু করুন, তারপর Emacs-এ `M-x inf-clojure-connect` চালান (C-c M-c)।

C-c C-e দিয়ে ফর্ম ইভ্যালুয়েট করুন। inf-clojure-mode (অর্থাৎ REPL) এবং inf-clojure-minor-mode-এ উপলব্ধ সব কমান্ডের তালিকার জন্য আপনি হয় C-h f RET inf-clojure-mode এবং C-h f RET inf-clojure-minor-mode চালাতে পারেন, অথবা সহজভাবে তাদের মেনু ঘুরে দেখতে পারেন।

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

[Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) ডাউনলোড করুন এবং এটিকে `vim` নামে অ্যালিয়াস করুন।

* [vim-plug](https://github.com/junegunn/vim-plug) ইনস্টল করুন:

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

`~/.config/nvim/init.vim` ফাইলটি তৈরি করুন:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Neovim খুলুন এবং `:PlugInstall` কমান্ডটি চালান।

`iced` কমান্ডটি $PATH-এ যোগ করুন:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* socket REPL সার্ভার চালু করুন, সোর্স ফাইল খুলুন এবং `:IcedConnectSocketRepl 1666` চালান।

ডিফল্ট REPL কমান্ড (ডিফল্ট `<Leader>` হলো `\`):

- `<Leader>ei` : ভেতরের এলিমেন্ট ইভ্যালুয়েট করুন
- `<Leader>ee` : বাইরের লিস্ট ইভ্যালুয়েট করুন
- `<Leader>et` : বাইরের টপ লিস্ট ইভ্যালুয়েট করুন
