# সম্পর্কে

Factor-এর ক্যারেক্টারগুলো আসলে *ইন্টিজার*, অর্থাৎ ইউনিকোড কোড পয়েন্ট। তাই সাধারণ সংখ্যাসূচক `<`, `>`, `=` তুলনাই আপনাকে কেস-সেনসিটিভ ক্রম দিয়ে দেয়। তার উপরে [`unicode`][unicode] ভোকাবুলারি যোগ করে ইউনিকোড-সচেতন প্রেডিকেট আর একক ক্যারেক্টারের কেস রূপান্তর।

## প্রেডিকেট

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## কেস রূপান্তর

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

স্ট্রিং-স্তরের `>upper`, `>lower` আর `>title` এগুলো স্ট্রিংয়ের প্রতিটি ক্যারেক্টারে প্রয়োগ করে।

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
