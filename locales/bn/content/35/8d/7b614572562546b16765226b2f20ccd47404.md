# স্পেসিফিকেশন ব্যবহার করুন

[comment]: # (সমাধানে টাইপ স্পেসিফিকেশন না থাকলে এই সতর্কবার্তাটি দেখানো হয়)

ফাংশনের ইনপুট আর আউটপুটের মধ্যেকার চুক্তি বোঝাতে [টাইপ স্পেসিফিকেশন](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) যোগ করুন।

- Elixir একটি ডাইনামিকভাবে টাইপড ভাষা, অর্থাৎ টাইপ চেক হয় শুধু রানটাইমে। টাইপ স্পেসিফিকেশন ব্যবহার করলে [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (Erlang-এর [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html)-এর উপর ভিত্তি করে তৈরি) এর মতো লিন্টার ও স্ট্যাটিক অ্যানালাইসিস কোডে অনাকাঙ্ক্ষিত আচরণ আছে কি না তা যাচাই করতে পারে।
- [ভাষার ডকুমেন্টেশনে](https://hexdocs.pm/elixir/typespecs.html#content) সব বিল্ট-ইন টাইপের [সম্পূর্ণ তালিকা](https://hexdocs.pm/elixir/typespecs.html#basic-types) পাবেন
- টাইপ বন্ধনী দিয়ে বা বন্ধনী ছাড়া, দুই ভাবেই লেখা যায়, যেমন `atom()` বনাম `atom`
  - Exercism Elixir-এর স্টাইল হলো বন্ধনী ছাড়া লেখা।

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
