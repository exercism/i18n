# পরিচিতি

এই অনুশীলনীতে মেথড প্যারামিটার এবং C#-এ এগুলোর ব্যবহারের কিছু খুঁটিনাটি নিয়ে আলোচনা করা হয়েছে।

প্যারামিটার কলকারী মেথড থেকে কলকৃত মেথডে তথ্য পৌঁছে দেয়।

- `ref` ও `out`-এর মতো মডিফায়ার ব্যবহার করে প্যারামিটারের আচরণ পরিবর্তন করা যায়।

- `out` মডিফায়ারযুক্ত একটি প্যারামিটার কলকৃত মেথড থেকে কলকারীর কাছে একটি মান ফিরিয়ে আনে। প্যারামিটারটি ইনিশিয়ালাইজ না করেই কলকৃত মেথডে পাঠানো যায়, আর যেভাবেই হোক না কেন, কলকৃত মেথডের ভেতরে এটিকে এমনভাবে ধরা হয় যেন মেথডে ঢোকার সময় এটি ইনিশিয়ালাইজ করা ছিল না। প্যারামিটার মডিফায়ারের আচরণ ও নিয়মগুলো সবচেয়ে সহজে বোঝা যায় উদাহরণ (নিচে দেখুন) এবং কম্পাইলার মেসেজের মাধ্যমে।

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out` প্যারামিটারে কলকৃত মেথডের ভেতরে অবশ্যই অ্যাসাইন করা থাকতে হবে।

- `ref` মডিফায়ারযুক্ত একটি প্যারামিটার কলকৃত মেথডে একটি মান পাঠায়। মেথডটি রিটার্ন করলে কলকৃত মেথড ওই প্যারামিটারে যে পরিবর্তনই করে থাকুক, কলকারী সেটি পেয়ে যাবে।

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` প্যারামিটার অবশ্যই ভ্যারিয়েবল হতে হবে, কারণ কলকৃত মেথড কলকারীর দেখা ওই প্যারামিটারের উপরেই সরাসরি কাজ করবে।
- `out` ও `ref` মডিফায়ার কলকৃত মেথডের সিগনেচারে এবং কল করার জায়গায়, দুই জায়গাতেই দরকার।
