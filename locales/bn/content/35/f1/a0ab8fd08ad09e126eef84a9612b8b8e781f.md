# ভূমিকা

## অ্যারে কম্প্রিহেনশন

কম্প্রিহেনশন হলো _Enumerables_ সহজে ও ডিক্লারেটিভ পদ্ধতিতে রূপান্তর করার একটি সুবিধা।

খুব সাধারণ একটি কম্প্রিহেনশন ডিক্লেয়ার করতে আমরা `for` কিওয়ার্ডটি ব্যবহার করতে পারি, যার পরে থাকে একটি _জেনারেটর_ ও একটি _do-block_, যা এনুমারেট করা মান থেকে নতুন মান তৈরি করে।

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

কম্প্রিহেনশনে _ফিল্টার_ও থাকতে পারে। যে মানগুলো ফিল্টার পাস করে না, সেগুলো চূড়ান্ত অ্যারে থেকে বাদ পড়ে:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

আরও জটিল কম্প্রিহেনশন আমরা একাধিক লাইনে ডিক্লেয়ার করতে পারি:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

একাধিক জেনারেটর ব্যবহার করে একটি _কার্তেসীয় গুণফল_ তৈরি করা যায়। এর মানে হলো, প্রথম জেনারেটরের তৈরি করা প্রতিটি মান, দ্বিতীয় জেনারেটরের তৈরি করা প্রতিটি মানের সাথে একবার করে জোড়া লাগে:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
