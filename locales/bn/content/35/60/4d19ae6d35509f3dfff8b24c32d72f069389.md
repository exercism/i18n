# ভূমিকা

কোনো কোয়োটেশন যখন আশেপাশের পরিবেশ থেকে মান *মনে রাখতে* চায়, অর্থাৎ অন্য ভাষায় যাকে *ক্লোজার* বলা হয়, তখন Factor দুটি হাতিয়ার ব্যবহার করে: `curry` ওয়ার্ড আর `'[ ]` *ফ্রাই* সিনট্যাক্স।

## `curry`: একটি মান ক্যাপচার করা

`curry` ([`kernel`][kernel]-এ আছে) একটি মান আর একটি কোয়োটেশন নেয় এবং ওই মানটি ভেতরে বসিয়ে একটি নতুন কোয়োটেশন ফেরত দেয়:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

দুটি মান ক্যাপচার করতে `curry` দুবার প্রয়োগ করুন:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: দুটি কোয়োটেশন জোড়া লাগানো

`compose` ([`kernel`][kernel]-এ আছে) দুটি কোয়োটেশন জোড়া লাগায়:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## ফ্রাই কোয়োটেশন: একাধিক মান ক্যাপচার করা

এক-দুটি মানের বেশি ক্যাপচার করতে হলে একটার পর একটা `curry` কল পড়তে অসুবিধা হয়ে যায়। *ফ্রাই* এক বা একাধিক `_` প্লেসহোল্ডারসহ `'[ … ]` ব্যবহার করে; প্রতিটি `_`-এর জায়গায় ডেটা স্ট্যাক থেকে ক্রমানুসারে নেওয়া একটি মান বসে:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

ক্লোজার তৈরি হওয়ার মুহূর্তেই `curry` আর ফ্রাই, দুটোই স্ট্যাক থেকে নিজেদের মান *নিয়ে নেয়*। উপরের লাইনটি স্ট্যাকে কিছুই রাখে না এবং এটি `[ + + ] curry curry`-এর সরাসরি বিকল্প।

প্লেসহোল্ডারগুলো স্ট্যাকের মান দিয়ে বাম থেকে ডানে ভরা হয়, আর মান নেওয়া হয় নিচ থেকে উপরে: `2 3 '[ _ _ ]` হলো `[ 2 3 ]`, `[ 3 2 ]` নয়।

ফ্রাই নেস্টেড কোয়োটেশনের *ভেতরেও* পৌঁছায়, ফলে ক্যাপচার করা মানগুলো ঠিক যেখানে চান সেখানে বসাতে পারেন:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

`_` বসে ভেতরের `[ … ]`-এর ভেতরে, তবু ফ্রাই সেটিও ভরে দেয়।

## ঘোষিত ইফেক্টসহ `call`

শেষে যখন কোনো সংরক্ষিত কোয়োটেশন রান করেন, তখন `call`-এ তার স্ট্যাক ইফেক্ট ঘোষণা করুন, যাতে কম্পাইলার সেটির টাইপ-চেক করতে পারে:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## ভেক্টর অ্যারিথমেটিক

`math.vectors` ভোকাবুলারি একই দৈর্ঘ্যের দুটি সিকোয়েন্সকে এলিমেন্টভিত্তিকভাবে মিলিয়ে দেয়। `v+` আর `v*` সেগুলো যোগ বা গুণ করে; `vmax` আর `vmin` প্রতিটি কম্পোনেন্টের বড় বা ছোটটি রাখে। প্রতিটিই একটি ২-এলিমেন্টের অ্যারে ফেরত দেয়:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
