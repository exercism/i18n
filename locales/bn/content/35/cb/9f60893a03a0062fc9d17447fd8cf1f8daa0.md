# টার্নারি অপারেটর

টার্নারি অপারেটর `if..else..` তুলনা করে একটি মান রিটার্ন করার একটি বিকল্প সিনট্যাক্স দেয়।

## সিনট্যাক্স

PHP-তে একটি `if` স্টেটমেন্ট আছে, যেখানে শর্তের "ট্রুথিনেস"-এর ভিত্তিতে কোনো একটি কাজের মূল্যায়ন করা যায়।

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

বিকল্পভাবে, টার্নারি অপারেটর দিয়ে একই অপারেশন করা যায়:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

তুলনার সিনট্যাক্সটি ছোট, যা এভাবে লেখা হয়: `(condition) ? (evaluate if true) : (evaluate if false);`
