# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নিতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার তিনটি কাজ আছে: আপনার লাইসেন্সের প্রয়োজন হবে কি না তা নির্ধারণ করা; দুটি যানবাহনের মধ্যে বেছে নেওয়া; এবং একটি ব্যবহৃত যানবাহনের জন্য গ্রহণযোগ্য দাম অনুমান করা।

## 1. আপনার ড্রাইভার লাইসেন্সের প্রয়োজন হবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালানোর জন্য ড্রাইভার লাইসেন্স প্রয়োজন।
ধরে নিন শুধু `"car"` এবং `"truck"` ধরনের জন্য লাইসেন্স প্রয়োজন; বাকি সবকিছু লাইসেন্স ছাড়াই চালানো যায়।

`needs_license` ফাংশনটি বাস্তবায়ন করুন, যা যানবাহনের ধরন নেয় এবং সেই ধরনের যানবাহনের জন্য আপনার লাইসেন্স প্রয়োজন কি না তা নির্দিষ্ট করা একটি বুলিয়ান রিটার্ন করে।

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. কেনার জন্য দুটি সম্ভাব্য যানবাহনের মধ্যে বেছে নিন

আপনি আপনার কাছে থাকা যানবাহনের বিকল্পগুলো মূল্যায়ন করেছেন।
আপনি তা দুটি বিকল্পে নামিয়ে আনতে পেরেছেন, কিন্তু চূড়ান্ত সিদ্ধান্ত নিতে আপনার সাহায্য দরকার।
`choose_vehicle` ফাংশনটি বাস্তবায়ন করুন, যা ইনপুট হিসেবে দুটি যানবাহনের একটি অ্যারে নেয় এবং একটি সিদ্ধান্ত রিটার্ন করে, যেটি অভিধানের ক্রমে প্রথমে আসা বিকল্প।

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. একটি ব্যবহৃত যানবাহনের দামের একটি অনুমান হিসাব করুন

এখন যেহেতু আপনি সিদ্ধান্ত নিয়ে ফেলেছেন, আপনি ডিলারশিপে ন্যায্য দাম পাচ্ছেন কি না তা নিশ্চিত করতে চান।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, দাম নির্ভর করে যানবাহনটির বয়স কত তাের উপর।
মোটামুটি অনুমানের জন্য ধরে নিন, যানবাহনটির বয়স যদি ৩ বছরের কম হয়, তাহলে এর দাম একেবারে নতুন অবস্থায় থাকা মূল দামের ৮০%।
যদি বয়স ১০ বছরের বেশি হয়, তাহলে ৫০%।
যদি যানবাহনটির বয়স অন্তত ৩ বছর কিন্তু ১০ বছরের বেশি না হয়, তাহলে মূল দামের ৭০%।

`resell_price` ফাংশনটি বাস্তবায়ন করুন, যা `if`, `elif` এবং `else` ব্যবহার করে এই যুক্তি প্রয়োগ করে।
এটি মূল দাম ও যানবাহনের বয়স ধারণ করা একটি অবজেক্ট নেয় এবং ডিলারশিপে আনুমানিক দাম রিটার্ন করে।

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
