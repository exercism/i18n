# পরিচিতি

[`Basics`][basics] কনসেপ্টে ফাংশন ডিফাইন করার দুটি উপায় সম্পর্কে জানানো হয়েছিল।

সবচেয়ে সাধারণভাবে, মাল্টিলাইন রূপটি:

```julia
function muladd(x, y, z)
    x * y + z
end
```

সংক্ষিপ্ত ডেফিনিশনের জন্য "অ্যাসাইনমেন্ট", বা "সিঙ্গেল-লাইন" রূপটি:
```julia
muladd(x, y, z) = x * y + z
```

তৃতীয় এবং আরও সংক্ষিপ্ত একটি রূপে, ছোট, একবার ব্যবহারযোগ্য একটি ফাংশন নাম ছাড়াই তৈরি করা যায়:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

এক্ষেত্রে, `x -> 2x` হলো একটি "অ্যানোনিমাস ফাংশন"।
এটি অন্য কিছু ভাষায় যাকে "ল্যাম্বডা ফাংশন" বলা হয়, তার সমতুল্য।

মনে রাখবেন, একাধিক আর্গুমেন্টের জন্য বন্ধনী লাগে, যেমন `(x, y) -> x * y`।

অ্যানোনিমাস ফাংশন Julia কোডে কমন, বিশেষত যখন `map()` ও `filter()`-এর মতো হায়ার-অর্ডার ফাংশনের সাথে মিলিয়ে ব্যবহার করা হয় (এগুলো পরের একটি কনসেপ্টে আরও বিস্তারিতভাবে আলোচনা করা হবে)।

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## ফাংশন আর্গুমেন্ট

সিলেবাসে এখন পর্যন্ত আমরা কেবল এমন ফাংশন দেখেছি যেগুলোর নির্দিষ্ট সংখ্যক আর্গুমেন্ট থাকে এবং ফাংশন কল করার সময় সেগুলো সঠিক ক্রমে পুরোটাই দিতে হয়।
এটি সীমাবদ্ধ ও অসুবিধাজনক হতো, তাই আরও কয়েকটি বিকল্প আছে।

### ঐচ্ছিক আর্গুমেন্ট

অনেক ভাষার মতো, Julia-তেও ফাংশন ডেফিনিশনে আলাদা আলাদা আর্গুমেন্টের জন্য ডিফল্ট মান দেওয়ার সুযোগ আছে।

এরপর ফাংশন কল হয় ওই আর্গুমেন্টের জন্য একটি মান দিতে পারে, নয়তো সেটি বাদ দিয়ে ডিফল্ট মানের উপর নির্ভর করতে পারে।

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

ডিফল্ট _ছাড়া_ সব আর্গুমেন্টকে ডিফল্ট _সহ_ যেকোনো আর্গুমেন্টের আগে থাকতে হবে, অর্থাৎ `f(x=2, y)` অবৈধ হবে।

### কিওয়ার্ড আর্গুমেন্ট

এখন পর্যন্ত সব উদাহরণেই `positional arguments` ব্যবহৃত হয়েছে, যেখানে ফাংশন কলে দেওয়া মানগুলো ফাংশন ডেফিনিশনে সংশ্লিষ্ট আর্গুমেন্টের ক্রম অনুযায়ী মিলতে হয়।

অনেক ভাষার মতো, Julia `keyword arguments`-ও অনুমতি দেয়।
ফাংশন কলে আর্গুমেন্টের নাম উল্লেখ করতে হয়, তবে এরপর একাধিক কিওয়ার্ড আর্গুমেন্ট যেকোনো ক্রমে উল্লেখ করা যায়।

Julia-র একটি স্বতন্ত্র বৈশিষ্ট্য হলো, ফাংশন ডেফিনিশনে কিওয়ার্ড আর্গুমেন্টগুলো (যদি থাকে) পজিশনাল আর্গুমেন্ট থেকে আলাদা করার জন্য আগে একটি সেমিকোলন `;` দিতে হয়।
ফাংশন কলে শেষ পজিশনাল আর্গুমেন্ট ও প্রথম কিওয়ার্ড আর্গুমেন্টের মাঝে `;` বা `,` যেকোনোটি ব্যবহার করা যায়।

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

ঠিক পজিশনাল আর্গুমেন্টের মতোই, ঐচ্ছিকভাবে ডিফল্ট মানও দেওয়া যায়।

ফাংশন কলে `myarg=myarg`-এর মতো সিনট্যাক্স চলে আসা কমন, যখন প্যারামিটারের মতো একই নামের একটি ভ্যারিয়েবল আগেই গণনা করা হয়ে থাকে।
এই পরিস্থিতিতে একটি শর্টহ্যান্ড সিনট্যাক্স ব্যবহার করা যায়:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### স্প্ল্যাট ও স্লার্প

এগুলো Julia সিনট্যাক্সের একটি কাজের দিকের স্ট্যান্ডার্ড নাম, যদি কখনো ভেবে থাকেন।
দুটোই `...` অপারেটরের কথা বোঝায়।

#### স্প্ল্যাট

ফাংশন _কলের_ সময় স্প্ল্যাটিং ব্যবহৃত হয়, যাতে ফাংশনের প্রয়োজনীয় আলাদা আলাদা মানে একটি কালেকশন ভেঙে দেওয়া যায়।

ব্যাখ্যা করার চেয়ে দেখিয়ে বোঝানো সহজ হতে পারে:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

কিছু "ফাংশন কল" সিনট্যাকটিক সুগারের আড়ালে থাকে, তাই স্প্ল্যাটিং কম স্পষ্ট উপায়েও ব্যবহার করা যায়।

উদাহরণস্বরূপ, মাল্টিপল অ্যাসাইনমেন্ট অভ্যন্তরীণভাবে একটি টাপল কনস্ট্রাক্টর ফাংশন ব্যবহার করে:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

কিওয়ার্ড আর্গুমেন্টও স্প্ল্যাটিং করে দেওয়া যায়, সাধারণত একটি `named tuple` ব্যবহার করে।
`Dict`-ও কাজ করবে, তবে কী (key) গুলো সিম্বল হতে হবে (স্ট্রিং কাজ করবে না)।

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### স্লার্প

ফাংশন _ডেফিনিশনে_ স্লার্পিং ব্যবহৃত হয়, যাতে যেকোনো সংখ্যক আলাদা মান একটি কালেকশনে ভরে ফেলা যায়।

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

স্লার্প করা আর্গুমেন্টের নাম (এক্ষেত্রে `more`) তাৎপর্য বহন করে না।
এই ভ্যারিয়েবলের টাইপ কম্পাইলার বেছে নেয়, তবে পজিশনাল আর্গুমেন্টের ক্ষেত্রে এটি সম্ভবত `tuple` বা অনুরূপ কিছু হবে।

কিওয়ার্ড আর্গুমেন্টও স্লার্প করা যায়, যার ফলে একটি `Dict` (বা অনুরূপ কিছু) পাওয়া যায়।

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

কলে যেকোনো কিওয়ার্ড আর্গুমেন্ট ব্যবহার করা যায়।
কোন কিওয়ার্ডে সাড়া দেবে আর কোনটা উপেক্ষা করবে, তা ফাংশন ডেফিনিশনই ঠিক করে।
