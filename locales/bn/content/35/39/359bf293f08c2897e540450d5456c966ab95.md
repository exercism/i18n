# নির্দেশাবলি

এই অনুশীলনীতে আপনি স্কুলজীবনের প্রেমিক যুগলকে সোশ্যাল মিডিয়ায় তাদের ভালোবাসা প্রকাশ করতে সাহায্য করবেন।

## 1. যুগলের নাম একটি হৃদয় দিয়ে আলাদা করে প্রদর্শন করুন

অনুগ্রহ করে static `HighSchoolSweethearts.DisplaySingleLine()` মেথডটি ইমপ্লিমেন্ট করুন, যেটি দুটি নাম নিয়ে সেগুলোকে একটি হৃদয় দিয়ে আলাদা করে প্রদর্শন করবে।
ফরম্যাট করা টেক্সটটি ৬১ অক্ষর চওড়া হবে এবং হৃদয়টি স্ট্রিংয়ের কেন্দ্রে থাকবে।

সব নাম লাইনের চওড়ার মধ্যে সহজেই এঁটে যাবে বলে নিশ্চিত করা হয়েছে।

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. একটি ASCII আর্ট হৃদয়ে যুগলের আদ্যক্ষর প্রদর্শন করুন

static `HighSchoolSweethearts.DisplayBanner()` মেথডটি ইমপ্লিমেন্ট করুন, যেটি আদ্যক্ষরের দুটি সেটকে একটি প্লাস চিহ্ন দিয়ে আলাদা করে প্রদর্শন করে।

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. লোকেল-সেনসিটিভ ডিক্লারেশন দিয়ে জার্মান এক্সচেঞ্জ শিক্ষার্থীদের নিজেদের ঘরের মতো অনুভূতি দেওয়া উচিত।

static `HighSchoolSweethearts.DisplayGermanExchangeStudents()` মেথডটি ইমপ্লিমেন্ট করুন, যেটি আমাদের জার্মান এক্সচেঞ্জ শিক্ষার্থীদের সম্পর্ক শুরুর তারিখ ও সম্পর্কের সময়কাল দেখায়।

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
