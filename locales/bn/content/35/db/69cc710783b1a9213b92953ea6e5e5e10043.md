# gofmt ব্যবহার করা হয়নি

সমাধানটিতে `gofmt` চালান, এটি Go-তে কোড ফরম্যাট করতে সাহায্য করে।

Go-তে কোড ফরম্যাটিং কমিউনিটির কাছে খুবই গুরুত্বপূর্ণ।
বেশিরভাগ IDE প্রতিবার সেভ করার সময়ই স্বয়ংক্রিয়ভাবে কোড ফরম্যাট করার জন্য সেট আপ করা যায়। উদাহরণস্বরূপ:

- Visual Studio Code-এ [Go-এর জন্য দারুণ সাপোর্ট](https://code.visualstudio.com/docs/languages/go) আছে
- Vim-এও [দুর্দান্ত একটি Go এক্সটেনশন](https://github.com/fatih/vim-go) আছে
- [Jetbrains Goland](https://www.jetbrains.com/go/) হলো Go-এর জন্য সম্পূর্ণ একটি IDE

ম্যানুয়ালি `gofmt` চালাতে:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
