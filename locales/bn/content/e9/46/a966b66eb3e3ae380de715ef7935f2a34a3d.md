# সম্পর্কে

মূল `try .. rescue` ধারণাটি `else` ও `after` ক্লজ সমর্থন করার জন্য বাড়িয়ে নেওয়া যায়:

- `else` ব্লক:
  - যেখানে ট্রাই-ব্লকের সফল ফলাফলের উপর প্যাটার্ন ম্যাচ করা হয়।
- `after` ব্লক:
  - যেখানে ট্রাই-ব্লকটি সফল হোক বা রেসকিউ করা হোক, যতক্ষণ প্রোগ্রামটি চলছে ততক্ষণ ফাংশনগুলো কল করা হয়।
  - `after` ব্লকের ফলাফল কলিং স্কোপে রিটার্ন করা হয় না।

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
