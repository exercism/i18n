# থ্রেড

এই অনুশীলনীটি থ্রেডের সাথে পরিচয় করিয়ে দেয়, যাতে পরীক্ষা করে দেখা যায় কনকারেন্ট অপারেশনের সময় আপনার ব্যাংক অ্যাকাউন্ট কতটা মজবুত। Tcl থ্রেড নিয়ে পড়ার জন্য কিছু উপকরণ:

* [Tcl থ্রেডিং মডেল](https://www.tcl.tk/doc/howto/thread_model.html)
* [Tcl দিয়ে থ্রেড সঠিকভাবে…](https://www.activestate.com/blog/threads-done-right-tcl/)
* [মাল্টি-থ্রেডেড Tcl স্ক্রিপ্ট](http://www.beedub.com/book/4th/Threads.pdf),

    * লক্ষ্য করুন, এই অধ্যায়ে বলা হয়েছে "Tcl-এর বেশিরভাগ বাইনারি ডিস্ট্রিবিউশনে থ্রেড চালু থাকে না"। এখন আর তা নয়: Tcl ডিস্ট্রিবিউশনগুলো এখন থ্রেড সাপোর্টসহ তৈরি হয় (দেখুন [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* Tcl ডকুমেন্টেশন থেকে [থ্রেড প্যাকেজের কমান্ড](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm)।

## ইনস্টলেশন

কিছু Tcl ডিস্ট্রিবিউশনে ডিফল্টভাবে Tcl-এর থ্রেড প্যাকেজ থাকে না: আলাদা করে ইনস্টল করার প্রয়োজন হতে পারে।
এভাবে যাচাই করুন:
```bash
$ echo 'package require Thread' | tclsh
```
এর থেকে যদি _কোনো আউটপুট না_ আসে, তাহলে থ্রেড প্যাকেজ আগেই ইনস্টল করা আছে।

প্রয়োজন অনুযায়ী `apt install tcl-thread` (বা `dnf install tcl-thread`) চালান।
