# ভূমিকা

ফাংশন আর্গুমেন্টের মূল বিষয়গুলো জানতে, [ফাংশন কনসেপ্ট][function concept] দেখুন।

## প্যারামিটারের নাম

[প্যারামিটারের নাম][parameters], ভ্যারিয়েবলের নামের মতোই, একটি অক্ষর বা আন্ডারস্কোর দিয়ে শুরু হতে হবে এবং তাতে অক্ষর, আন্ডারস্কোর বা সংখ্যা থাকতে পারে।
প্যারামিটারের নামে স্পেস বা যতিচিহ্ন থাকা উচিত নয়।


## পজিশনাল আর্গুমেন্ট

পজিশনাল আর্গুমেন্ট হলো ফাংশনে পাঠানো মান, যেগুলো ঠিক সেই ক্রমেই পাঠানো হয় যে ক্রমে সেগুলোর সাথে বাঁধা প্যারামিটারগুলো থাকে।
চাইলে প্যারামিটারের নাম ব্যবহার করেও এগুলো পাঠানো যায়:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

concat-এর প্রথম কলটি আর্গুমেন্টগুলো অবস্থান অনুযায়ী পাঠায়।
concat-এর দ্বিতীয় কলটি আর্গুমেন্টগুলো _নাম_ দিয়ে পাঠায়, ফলে তাদের অবস্থান বদলানো যায়।

খেয়াল রাখুন, নাম দিয়ে পাঠানো আর্গুমেন্টের (_যাকে [কিওয়ার্ড আর্গুমেন্ট][keyword-arguments]-ও বলা হয়। ভ্যার-পজিশনাল প্যারামিটার বা [**kwargs][kwargs]-এর সাথে এগুলো **গুলিয়ে ফেলবেন না**_) পরে পজিশনাল আর্গুমেন্ট আসতে পারে না।

আর্গুমেন্টের এই সেটটি:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

এই এরর দেবে:

```
SyntaxError: positional argument follows keyword argument
```

## ডিফল্ট আর্গুমেন্টের মান

প্যারামিটার তালিকায় এক বা একাধিক আর্গুমেন্টের জন্য [ডিফল্ট মান][default arguments] দেওয়া যায়।
এতে প্রয়োজনে ফাংশনটিকে _কম_ আর্গুমেন্ট দিয়ে কল করা যায়।
ডিফল্ট মানের জায়গায় নতুন আর্গুমেন্ট দিয়ে ফাংশনটি কল করলে সেগুলো ওভাররাইড করা যায়:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## কিওয়ার্ড আর্গুমেন্ট

কিওয়ার্ড আর্গুমেন্ট ফাংশনে আর্গুমেন্ট পাঠানোর সময় প্যারামিটারের নাম ব্যবহার করে।
চাইলে এগুলোকে অবস্থান দিয়েও উল্লেখ করা যায়:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
