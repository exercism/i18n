# টেস্ট

প্রদত্ত টেস্টগুলো রান করার জন্য আপনার Minitest জেমটির প্রয়োজন হবে। একটি টার্মিনাল উইন্ডো খুলে minitest ইনস্টল করতে নিচের কমান্ডটি রান করুন:

```
gem install minitest
```


অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি ব্যবহার করে টেস্টগুলো রান করুন:

```
ruby <snake-case-exercise>_test.rb
```

অনুগ্রহ করে `<snake-case-exercise>` অংশটির জায়গায় snake_case-এ লেখা আপনার অনুশীলনীর নাম বসান।

## রঙিন আউটপুট

রঙিন আউটপুট পেতে আপনি `require 'minitest/pride'` করতে পারেন, অথবা নিচের কমান্ডটি রান করুন:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
