# Ceylon টেস্ট চালানো

টেস্ট চালানোর আগে আপনার কোড [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html) দিয়ে কম্পাইল করে নিতে হবে।

আমরা টেস্ট চালাই [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html) কমান্ড দিয়ে।

`ceylon test` টেস্ট চালানোর জন্য একটি মডিউল নাম আশা করে।
Ceylon ট্র্যাকে প্রতিটি অনুশীলনীতে মাত্র একটি করে মডিউল থাকে।

তাই আপনি এভাবে টেস্ট চালাতে পারেন:

```bash
ceylon compile && ceylon test $(basename source/*)
```
