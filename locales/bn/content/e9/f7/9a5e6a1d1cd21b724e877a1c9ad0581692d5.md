# নির্দেশাবলি

আপনি একটি মালবাহী জাহাজের ওয়্যারলেস টেলিগ্রাফার। সংকেত আসে একটি কোলাহলপূর্ণ লাইনে: জাহাজের যন্ত্রপাতি, আবহাওয়ার স্ট্যাটিক, মাঝেমধ্যে ভেসে আসা বিদেশি কথাবার্তা, এসবের সাথে মিশে থাকে আপনি যে আসল মোর্সটি শুনছেন সেটিও। বার্তাটি ধরতে আপনি তারটিকে পাঠান একটি *টেপ* ডিভাইসের মধ্য দিয়ে, যা বৈধ মোর্স প্রতীক (`.`, `-`, এবং অক্ষর আলাদা করে যে স্পেস) ছাড়া বাকি সব ঝেঁটিয়ে বাদ দেয়।

আপনার কাজ হলো টেপটিকে একটি কাস্টম Factor ইনপুট স্ট্রিম হিসেবে তৈরি করা।

## 1. টেপটি ডিফাইন করুন

এমন একটি `tape` টিউপল ডিফাইন করুন যা `disposable`-কে এক্সটেন্ড করে এবং আন্ডারলাইং ইনপুট স্ট্রিমের জন্য `wire` নামে একটি স্লট ধারণ করে।

```factor
TUPLE: tape < disposable wire ;
```

এরপর কনস্ট্রাক্টর `<tape> ( wire -- tape )` লিখুন। ডিস্ট্রাক্টর ফ্রেমওয়ার্ক যাতে টেপটি রেজিস্টার করে সেজন্য `new` নয়, `new-disposable` ব্যবহার করুন, এবং আন্ডারলাইং স্ট্রিমটি `wire` স্লটে রাখুন।

## 2. input-stream মিক্সিনে যুক্ত হোন

`tape`-কে একটি `input-stream` হিসেবে ডিক্লেয়ার করুন:

```factor
INSTANCE: tape input-stream
```

এতে প্রোটোকলের ডিফল্ট কম্বিনেটরগুলো আপনার ক্লাসে ডিসপ্যাচ করে।

## 3. একটি মোর্স প্রতীক পড়ুন

`M: tape stream-read1 ( tape -- elt/f )` ইমপ্লিমেন্ট করুন। আন্ডারলাইং তার থেকে বাইট পড়ুন, যতক্ষণ না `CHAR: .`, `CHAR: -`, বা `CHAR: \s` (স্পেস) এর একটিতে পৌঁছান। ওই বাইটটি রিটার্ন করুন। তারটি যদি `f` (স্ট্রিমের শেষ) রিটার্ন করে, তাহলে আপনিও `f` রিটার্ন করুন, টেপটির কাজ শেষ।

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. এলিমেন্ট টাইপ ডেলিগেট করুন

`M: tape stream-element-type ( tape -- type )` ইমপ্লিমেন্ট করুন, আর তা তারের কাছে ডেলিগেট করে করুন। টেপ পড়া এলিমেন্টের ধরন বদলায় না।

## 5. পরিষ্কার করুন

`M: tape dispose* ( tape -- )` ইমপ্লিমেন্ট করুন। ফ্রেমওয়ার্ক প্রতিটি `dispose`-এর জন্য আপনার মেথড একবারই কল করে; শুধু আন্ডারলাইং তারটি ডিসপোজ করুন।

এই পাঁচটি অংশ জায়গায় থাকলে টেপটি একটি সাধারণ ইনপুট স্ট্রিমের মতোই কাজ করে। `with-input-stream`, `stream-read` এবং প্রোটোকলের বাকি শব্দগুলো সবই স্বয়ংক্রিয়ভাবে আপনার মেথডে ডিসপ্যাচ করে।
