# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার  | টাইপ    | বিবরণ                              |
| --------- | -------- | ------- | ---------------------------------- |
| `$a0`     | ইনপুট    | ইন্টিজার | মৌলিক সংখ্যার ইনডেক্স              |
| `$v0`     | আউটপুট   | ইন্টিজার | n-তম মৌলিক সংখ্যার মান             |
| `$t0-9`   | অস্থায়ী | যেকোনো  | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত হয় |
