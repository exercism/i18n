# পরিচিতি

## পাটিগণিতের অপারেটর

সংখ্যার ওপর মৌলিক পাটিগণিতের কাজ করার জন্য JavaScript ৬টি ভিন্ন অপারেটর দেয়।

- `+`: যোগ অপারেটরটি সংখ্যাগুলোর সমষ্টি বের করতে ব্যবহৃত হয়।
- `-`: বিয়োগ অপারেটরটি দুই সংখ্যার পার্থক্য বের করতে ব্যবহৃত হয়
- `*`: গুণ অপারেটরটি দুই সংখ্যার গুণফল বের করতে ব্যবহৃত হয়।
- `/`: ভাগ অপারেটরটি দুই সংখ্যাকে ভাগ করতে ব্যবহৃত হয়।

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: ভাগশেষ অপারেটরটি একটি ভাগের ভাগশেষ বের করতে ব্যবহৃত হয়।

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: সূচক অপারেটরটি একটি সংখ্যাকে ঘাতে উন্নীত করতে ব্যবহৃত হয়।

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## অপারেশনের ক্রম

একটি লাইনে একাধিক অপারেটর ব্যবহার করলে JavaScript [এই অগ্রাধিকার তালিকা][mdn-operator-precedence]-এ দেখানো মতো একটি ক্রম অনুসরণ করে।
আমাদের প্রসঙ্গে সহজ করে বললে, প্রাথমিক গণিতের ক্লাসে আমরা যে PEDMAS নিয়মটি শিখেছি, JavaScript সেটিই ব্যবহার করে। PEDMAS-এর পুরো অর্থ: Parentheses, Exponents, Division/Multiplication, Addition/Subtraction (অর্থাৎ বন্ধনী, সূচক, ভাগ/গুণ, যোগ/বিয়োগ)।

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## সংক্ষিপ্ত অ্যাসাইনমেন্ট অপারেটর

সংক্ষিপ্ত অ্যাসাইনমেন্ট অপারেটর হলো কোনো ভ্যারিয়েবলের ওপর পাটিগণিতের কাজ চালিয়ে নতুন মানটি সেই ভ্যারিয়েবলেই অ্যাসাইন করার একটি ছোট উপায়।
উদাহরণস্বরূপ, `x` আর `y` নামের দুটি ভ্যারিয়েবল ধরা যাক।
তাহলে `x += y` আর `x = x + y` একই কথা।
প্রায়ই `y` ভ্যারিয়েবলের বদলে একটি সংখ্যা দিয়ে এটি ব্যবহার করা হয়।
বাকি ৫টি অপারেশনও একই ধরনের ভঙ্গিতে করা যায়।

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
