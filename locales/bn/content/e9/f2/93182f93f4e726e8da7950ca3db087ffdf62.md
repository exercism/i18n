# ইউনিয়ন টাইপ

Crystal-এ একটি ভ্যারিয়েবল একাধিক টাইপের সমন্বয়ে গঠিত হতে পারে। এটাকে [ইউনিয়ন টাইপ][union-type] বলা হয়। Crystal-এ কম্পাইলার সাধারণত ইউনিয়ন টাইপ নিজে থেকেই অনুমান করে নেয়।

~~~~exercism/note
রানটাইমে একটি ইউনিয়ন টাইপ আসলে একটি একক টাইপই, যদিও এটি একাধিক টাইপ দিয়ে তৈরি হতে পারে। এর মানে হলো, যদি একটি ইউনিয়ন টাইপ `String` ও `Int32` দিয়ে গঠিত হয়, তাহলে এটি একই সময়ে দুটোই থাকবে না। বরং এটি একটি `String` অথবা একটি `Int32` হবে।
~~~~

একটি ইউনিয়ন টাইপ ডিক্লেয়ার করা হয় টাইপগুলোর মাঝে পাইপ (`|`) বসিয়ে। এগুলোকে অনেক সময় বন্ধনীর ভেতরে রাখা হয়, তবে এটা বাধ্যতামূলক নয়। সবচেয়ে কমন ইউনিয়ন টাইপ হলো `(T | Nil)`, যেখানে `T` একটি টাইপ। এমন মেথডে এটি দেখা যায় যেগুলো `Nil` রিটার্ন করতে পারে। এটাকে ভ্যারিয়েবলের **নিলেবল** হওয়াও বলা হয়।

```crystal
foo : String = "Hello"
foo = nil # Error: type must be String, not (String | Nil)

foo : (String | Nil) = "Hello"
foo = nil
```

এটি শুধু দুইটি টাইপেই সীমাবদ্ধ নয়, আপনি যত চান তত টাইপ দিতে পারেন।

```crystal
foo : (String | Int32 | Nil | Float64) = "Hello"
foo = 1
foo = nil
foo = 1.0
```

## `typeof` বনাম `Object#class`

একটি ভ্যারিয়েবলের টাইপ পাওয়ার দুটি উপায় আছে। হয় [`typeof`][typeof] ব্যবহার করে, নয়তো [`Object#class`][Object#class] ব্যবহার করে। পার্থক্য হলো, `typeof` কম্পাইল টাইমে ভ্যারিয়েবলের টাইপ রিটার্ন করে, আর `Object#class` রানটাইমে টাইপ রিটার্ন করে। এর মানে হলো, আপনি যদি দেখতে চান একটি ভ্যারিয়েবল ইউনিয়ন টাইপ কি না, উদাহরণস্বরূপ, `Object#class` সেটা বলতে পারবে না, কারণ এটি শুধু রানটাইমে টাইপ রিটার্ন করে, যেটি একটি একক টাইপ।

```crystal
foo = 0 == 0 ? "a" : 1
typeof(foo) # => (String | Int32)
foo.class # => String
```

## ইউনিয়ন টাইপে অপারেশন

যেহেতু ইউনিয়ন টাইপ রানটাইমে একটি একক টাইপ, তাই এর উপর সব স্ট্যান্ডার্ড অপারেশন কাজ করে। কিন্তু কোড কম্পাইল করার সময় কম্পাইলারকে জানতে হয় এটি কোন টাইপ। তাই টাইপ-নির্দিষ্ট অপারেশন ব্যবহার করতে চাইলে কোড এমনভাবে সাজাতে হয় যাতে এটি শুধু একটি টাইপই হতে পারে।

```crystal
foo : (String | Int32) = "Hello"
foo.downcase # Error: undefined method 'downcase' for (String | Int32)
```

Crystal-এ ইউনিয়ন টাইপের জন্য একটি বিশেষ মেথড আছে: `is_a?` মেথড, যেটি আর্গুমেন্ট হিসেবে একটি টাইপ নেয় এবং একটি বুলিয়ান রিটার্ন করে। `nil?` মেথডটি `is_a?(Nil)`-এর একটি শর্টকাট। `is_a?` মেথডটি একটি কন্ট্রোল এক্সপ্রেশনে বসালে কম্পাইলারকে জানিয়ে দেবে এটি কোন টাইপ, আর তার ফলে নিশ্চিত হবে যে এটি ওই টাইপই। আর else শাখার ক্ষেত্রে নিশ্চিত হবে যে এটি ওই টাইপ নয়।

```crystal
foo : (String | Int32) = "Hello"
if foo.is_a?(String)
  typeof(foo)  # => String
  foo.downcase # => "hello"
end
```

এই `is_a?` শুধু একটি টাইপ আর্গুমেন্ট নিয়েই সীমাবদ্ধ নয়, এটি ইউনিয়ন টাইপও নিতে পারে। একাধিক টাইপের জন্য এটি `&&`-এর সাথে একসাথে ব্যবহার করা যায়।

~~~~exercism/note
কন্ট্রোল এক্সপ্রেশনের সাথে ব্যবহার করার সময় `is_a?` মেথডটি ইনস্ট্যান্স ভ্যারিয়েবল বা ক্লাস ভ্যারিয়েবল হতে পারে না। বরং এগুলোকে প্রথমে একটি লোকাল ভ্যারিয়েবলে অ্যাসাইন করতে হবে।
~~~~

## as

ইউনিয়ন টাইপকে একক টাইপে পরিণত করার একটি উপায় হলো এমনভাবে সাজানো যাতে কোনো শাখায় প্রবেশ করা যায় কেবল তখনই, যখন টাইপটি একটি নির্দিষ্ট টাইপ হয়। আরেকটি উপায় হলো [`as`][as] মেথড ব্যবহার করা। এটি রানটাইম চেক করে ইউনিয়ন টাইপকে একক টাইপে পরিণত করে। প্রত্যাশিত টাইপ না হলে একটি এক্সেপশন রেইজ করা হয়।

```crystal
foo : String | Int32 = "Hello"
foo.as(String).downcase # => "hello"

foo.as(Int32) # Error: can't cast String to Int32
```

~~~~exercism/caution
এই পদ্ধতিটি কেবল তখনই ব্যবহার করার কথা, যখন আপনি নিশ্চিত যে টাইপটি প্রত্যাশিত টাইপ, অথবা যখন টাইপটি প্রত্যাশিত না হলে আপনি একটি এক্সেপশন রেইজ করতে চান।

অনুপযুক্ত সেটআপে এই পদ্ধতি ব্যবহার করলে অপ্রত্যাশিত আচরণ হতে পারে।
~~~~

## as?

[`as?`][as?] প্রায় `as`-এর মতোই কাজ করে, তবে প্রত্যাশিত টাইপ না হলে এক্সেপশন রেইজ করার বদলে এটি `nil` রিটার্ন করে। এর মানে হলো, এটি প্রত্যাশিত টাইপ ও `Nil`-এর একটি ইউনিয়ন টাইপ রিটার্ন করে।

```crystal
foo : (String | Int32) = "Hello"
foo.as?(String).downcase # => "hello"

foo.as?(Int32) # => nil
```

## নিলেবল শর্টকাট

নিলেবল মানে হলো একটি ভ্যারিয়েবল হয় কোনো একটি টাইপ হতে পারে, নয়তো `Nil`। এটা `(T | Nil)` হিসেবে লেখা যায়। কিন্তু যেহেতু নিলেবল টাইপ তুলনামূলকভাবে কমন, তাই এর একটি শর্টকাট আছে: `T?`।

```crystal
# This:
foo : (String | Nil) = "Hello"
foo = nil

# Is the same as:
foo : String? = "Hello"
foo = nil
```
