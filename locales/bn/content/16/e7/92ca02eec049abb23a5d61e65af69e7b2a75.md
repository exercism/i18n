# পরিচিতি

Gleam-এর স্ট্যান্ডার্ড লাইব্রেরিতে থাকা `gleam/order` মডিউলে আছে `Order` টাইপ, যা মান তুলনা করতে ব্যবহৃত হয়।

`Order` টাইপটি এভাবে ডিফাইন করা হয়েছে:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

টাইপটির তিনটি ভ্যারিয়েন্ট আছে, যার প্রতিটি একটি মান ও আরেকটি মানের মধ্যকার সম্পর্ক বোঝাতে ব্যবহৃত হয়:

- `Gt` - মানটি অন্য মানটির চেয়ে _বড়_।
- `Eq` - মানটি অন্য মানটির _সমান_।
- `Lt` - মানটি অন্য মানটির চেয়ে _ছোট_।

কোনো ডেটা টাইপ আকার দিয়ে তুলনা করা গেলে মডিউলটির একটি `compare` ফাংশন ডিফাইন করা কমন, যেটি একটি `Order` মান রিটার্ন করে। যেমন, `gleam/float` ও `gleam/int` যথাক্রমে ফ্লোট ও ইন্টিজারের উপর কাজ করা `compare` ফাংশন ডিফাইন করে।

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort`-এর মতো সর্টিং ফাংশনগুলো একটি `Order` মান রিটার্ন করে এমন একটি ফাংশন নেওয়া কমন, যা কল করা ব্যক্তিকে তালিকাটি কীভাবে সাজানো হবে তা ঠিক করতে দেয়।

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
