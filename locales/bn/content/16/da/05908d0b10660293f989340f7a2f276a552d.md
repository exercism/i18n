# স্ট্রিং ফরম্যাট

`String#%%` মেথডের পাশাপাশি, Ruby-তে স্ট্রিং তৈরির একটি কমন উপায় হলো [স্ট্রিং ইন্টারপোলেশন](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html) ব্যবহার করা। উদাহরণ:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
