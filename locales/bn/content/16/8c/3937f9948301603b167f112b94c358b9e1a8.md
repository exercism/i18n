# ইঙ্গিত

## 1. একটি র‍্যান্ডম গ্রহ তৈরি করুন

- Java একটি কলেকশন থেকে র‍্যান্ডমভাবে একটি এলিমেন্ট বেছে নেওয়ার ফাংশন দেয় না।
- মনে রাখবেন, অ্যারে থেকে আপনি তার ইনডেক্স দিয়ে একটি এলিমেন্ট পেতে পারেন, আর ইনডেক্সটি একটি ইন্টিজার।

## 2. একটি র‍্যান্ডম স্টারশিপ রেজিস্ট্রি নম্বর তৈরি করুন

- `java.util.Random` ক্লাসে 0 থেকে একটি নির্দিষ্ট সর্বোচ্চ মানের মধ্যে র‍্যান্ডম `int` তৈরি করার একটি মেথড আছে।

## 3. একটি র‍্যান্ডম স্টারডেট তৈরি করুন

- `java.util.Random` ক্লাসের যে মেথডটি র‍্যান্ডম `double` তৈরি করে, সেটি সবসময় `0.0` থেকে `1.0`-এর মধ্যে একটি সংখ্যা রিটার্ন করে।
