# পরিচিতি

সাধারণত, ফাংশন শুধু একটি নির্দিষ্ট সংখ্যক আর্গুমেন্ট গ্রহণ করে।
তবে শেষ প্যারামিটারের টাইপের আগে `...` বসালে, ফাংশনটি যেকোনো সংখ্যক শেষের আর্গুমেন্ট গ্রহণ করতে পারে।
এতে শেষ প্যারামিটারটি একটি _ভ্যারিয়েডিক প্যারামিটার_-এ পরিণত হয়।

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

ফাংশনের ভেতরে ভ্যারিয়েডিক প্যারামিটারটি একটি স্লাইস:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

একটি ফাংশনে ভ্যারিয়েডিক প্যারামিটারের আগে ভ্যারিয়েডিক নয় এমন প্যারামিটার থাকতে পারে।
একটি ফাংশনে সর্বাধিক একটি ভ্যারিয়েডিক প্যারামিটার থাকতে পারে, আর সেটি অবশ্যই শেষ প্যারামিটার হতে হবে।

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## একটি স্লাইস স্প্রেড করা

একটি স্লাইস ভ্যারিয়েডিক প্যারামিটারে পাঠাতে হলে, তার পরে `...` বসান:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

একটি স্লাইস ভ্যারিয়েডিক প্যারামিটারে পাঠানোর সময়েই কেবল `...` বৈধ।
