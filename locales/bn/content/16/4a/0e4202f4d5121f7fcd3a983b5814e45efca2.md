# পরিচিতি

বাস্তব জগতের ঘটনা সিমুলেট করতে অনেক প্রোগ্রামেরই (_আপাতদৃষ্টিতে_) র‍্যান্ডম মান প্রয়োজন হয়।

কমন, পরিচিত উদাহরণের মধ্যে আছে:
- একটি কয়েন টস: `('Heads', 'Tails')` থেকে একটি র‍্যান্ডম মান।
- একটি পাশা গড়ানো: ১ থেকে ৬ পর্যন্ত একটি র‍্যান্ডম ইন্টিজার।
- তাসের একটি ডেক শাফল করা: কার্ডের একটি অ্যারের র‍্যান্ডম ক্রম।
- একটি থ্রি-ডি গ্রাফিক্স সিমুলেশনে গাছ ও গুল্ম তৈরি করা।

কম্পিউটার দিয়ে _সত্যিকারের_ র‍্যান্ডম মান তৈরি করা একটি [আশ্চর্যজনকভাবে কঠিন টেকনিক্যাল চ্যালেঞ্জ][truly-random], তাই এই ফলাফলগুলোকে "সিউডো-র‍্যান্ডম" বলা হতে পারে।

বাস্তবে, Python স্ট্যান্ডার্ড লাইব্রেরির [`random`][random] মডিউলের মতো সুপরিকল্পিত একটি লাইব্রেরি দ্রুত, নমনীয়, এবং মডেলিং, সিমুলেশন ও গেমের বেশিরভাগ অ্যাপ্লিকেশনের জন্য যথেষ্ট ভালো ফলাফল দেয়।

এই সংক্ষিপ্ত পরিচিতিতে আমরা মডিউলটির সবচেয়ে বেশি ব্যবহৃত চারটি ফাংশন দেখাব।
আমরা আপনাকে পূর্ণ [`random`][random] ডকুমেন্টেশন ঘুরে দেখার জন্য উৎসাহ দিচ্ছি, কারণ এতে অনেক টুল ও অপশন রয়েছে।

`random` মডিউলের টুলগুলো ব্যবহার করার আগে আপনাকে প্রথমে এটি ইমপোর্ট করতে হবে:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

মডিউলের নাম টাইপ করা এড়াতে আপনি নির্দিষ্ট ফাংশন নাম ধরে ইমপোর্ট করতে পারেন:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` এবং `randint()`

উপরের প্রথম উদাহরণে দেখানো হয়েছে, `randrange()` ফাংশনটির তিনটি রূপ আছে:

1. `randrange(stop)` একটি ইন্টিজার `n` দেয় যাতে `0 <= n < stop`
2. `randrange(start, stop)` একটি ইন্টিজার `n` দেয় যাতে `start <= n < stop`
3. `randrange(start, stop, step)` একটি ইন্টিজার `n` দেয় যাতে `start <= n < stop`
    এবং `n` থাকে `start, start + step, start + 2*step...` সিকোয়েন্সে

সবচেয়ে কমন ক্ষেত্রে, যেখানে `step == 1`, সেখানে `randint(a, b)` আরও সুবিধাজনক ও পঠনযোগ্য হতে পারে।
`randint()`-এর সম্ভাব্য ফলাফলে _ঊর্ধ্বসীমাও_ অন্তর্ভুক্ত, তাই `randint(a, b)` ব্যবহার করা `randrange(a, b+1)` ব্যবহারেরই সমান।



## `choice()` এবং `choices()`

এই দুটি ফাংশন ধরে নেয় যে আপনি কোনো [সিকোয়েন্স][sequence-types] বা অন্য কোনো কন্টেইনার থেকে শুরু করছেন।
এটি সাধারণত একটি `list` হয়, অথবা কিছু সীমাবদ্ধতাসহ একটি `tuple` বা `set` (_একটি `tuple` অপরিবর্তনীয়, আর `set` ক্রমহীন_)।

`choice()` ফাংশন প্রদত্ত সিকোয়েন্স থেকে র‍্যান্ডমে বেছে নেওয়া একটি সদস্য রিটার্ন করে, আর `choices()` প্রদত্ত সিকোয়েন্স থেকে র‍্যান্ডমে বেছে নেওয়া নির্দিষ্ট সংখ্যক সদস্য (`k`) রিটার্ন করে।
উপরের উদাহরণগুলোতে আমরা ধরে নিয়েছিলাম একটি ন্যায্য মুদ্রা, যেখানে হেড বা টেইলের সম্ভাবনা সমান, তবে ওজনও নির্দিষ্ট করা যায়।

উদাহরণস্বরূপ, যদি একটি ব্যাগে ১০টি লাল বল আর ১৫টি সবুজ বল থাকে, এবং আমরা র‍্যান্ডমে একটি বের করতে চাই:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
