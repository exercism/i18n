# নির্দেশনা

হ্যালো, এজেন্ট ডাবল-নাল0111।

আপনার মিশন, যদি আপনি এটি গ্রহণ করার সিদ্ধান্ত নেন, হলো UMBRA (United Minions Being Really Awful) সদর দপ্তরে অনুপ্রবেশ করে তাদের সর্বশেষ সত্যিই ভয়াবহ পরিকল্পনার নকশা উদ্ধার করতে সাহায্য করার জন্য দুটি টুল লেখা। এই মিশন সম্পন্ন করতে আপনার দুটি টুল লাগবে।

## 1. উদ্ধার করা গোপন নকশা একটি পাসওয়ার্ড দিয়ে সুরক্ষিত করুন

গোপন নকশা হাতে এলে আপনাকে সেটি এমনভাবে সুরক্ষিত করতে হবে যাতে কেবল যারা পাসওয়ার্ড জানে তারাই সেগুলো উদ্ধার করতে পারে।

এটি করতে হলে আপনাকে `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String` ফাংশনটি ইমপ্লিমেন্ট করতে হবে।
এই ফাংশনটি আরেকটি ফাংশন রিটার্ন করবে, যা ইনপুট হিসেবে সম্ভাব্য পাসওয়ার্ড স্ট্রিং নেয়।
লেখা পাসওয়ার্ডটি সঠিক হলে নতুন ফাংশনটি লুকানো নকশাটি রিটার্ন করে, কিন্তু পাসওয়ার্ডটি ভুল হলে ফাংশনটি "Sorry. No hidden secrets here." রিটার্ন করে।

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. তাদের সেফ খোলার জন্য একটি কম্বিনেশন তৈরি করুন

আমরা জেনেছি, UMBRA তাদের সব সেফের কম্বিনেশন ঠিক করে সেটি যে ঘরে রাখা আছে সেই ঘরের নম্বরের ভিত্তিতে।
ঘরের নম্বরে বারবার একটি বিশেষ ফাংশন প্রয়োগ করে সেফের কম্বিনেশন তৈরি করা হয়।
তাই কম্বিনেশনের প্রথম সংখ্যাটি আসে ঘরের নম্বরে ফাংশনটি প্রয়োগ করে, দ্বিতীয়টি আসে প্রথম সংখ্যাটিতে ফাংশনটি প্রয়োগ করে, আর তৃতীয়টি আসে দ্বিতীয় সংখ্যাটিতে ফাংশনটি প্রয়োগ করে।

তবে UMBRA নিয়মিতই কম্বিনেশন তৈরিতে ব্যবহৃত ফাংশন বদলে দেয়, তাই কম্বিনেশন তৈরি করতে আপনার টুলকে ঘরের নম্বর এবং উপযুক্ত ফাংশন দুটোই নিতে হবে।

আপনার প্রয়োজনীয় কম্বিনেশনটি তৈরি করতে `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` ফাংশনটি ইমপ্লিমেন্ট করুন।

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
