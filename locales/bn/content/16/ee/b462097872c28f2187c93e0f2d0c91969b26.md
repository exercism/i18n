# পরিচিতি

Go-তে, একটি `struct` হলো নামযুক্ত এলিমেন্টের একটি ক্রম, যাদের _ফিল্ড_ বলা হয়; প্রতিটি ফিল্ডের একটি নাম ও একটি টাইপ থাকে।
একটি স্ট্রাক্টের মধ্যে একটি ফিল্ডের নাম অনন্য হতে হবে।
অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং প্যারাডাইমে স্ট্রাক্টকে _ক্লাস_-এর সাথে তুলনা করা যায়।

## একটি স্ট্রাক্ট ডিফাইন করা

আপনি `type` ও `struct` কিওয়ার্ড ব্যবহার করে একটি নতুন স্ট্রাক্ট তৈরি করেন, এবং ফিল্ডগুলোর নাম ও টাইপ স্পষ্টভাবে ডিফাইন করেন।
যেমন, এখানে আমরা `Shape` স্ট্রাক্টটি ডিফাইন করি, যেখানে একটি আকৃতির নাম ও তার আকার রাখা হয়:

```go
type Shape struct {
    name string
    size int
}
```

স্ট্রাক্টের ফিল্ডের নাম Go-র কনভেনশন অনুসরণ করে: যে ফিল্ডের নাম ছোট হাতের অক্ষর দিয়ে শুরু হয়, তা কেবল একই প্যাকেজের কোড থেকে দেখা যায়, আর যে ফিল্ডের নাম বড় হাতের অক্ষর দিয়ে শুরু হয়, তা অন্য প্যাকেজ থেকেও দেখা যায়।

## একটি স্ট্রাক্টের ইনস্ট্যান্স তৈরি করা

একবার `struct` ডিফাইন করে ফেললে, আপনি ফিল্ডের নাম ব্যবহার করে যেকোনো ক্রমে ফিল্ডগুলো উল্লেখ করে একটি নতুন ইনস্ট্যান্স তৈরি করতে পারেন:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

ইনস্ট্যান্সের ফিল্ড পড়তে বা পরিবর্তন করতে, `.` নোটেশন ব্যবহার করুন:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

যে ফিল্ডগুলোর কোনো প্রাথমিক মান অ্যাসাইন করা হয় না, সেগুলো তাদের শূন্য মান পায়।
যেমন:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

আপনি ফিল্ডের নাম ব্যবহার না করেও একটি `struct`-এর ইনস্ট্যান্স তৈরি করতে পারেন, যদি আপনি ফিল্ডগুলো _ক্রম অনুযায়ী_ উল্লেখ করেন:

```go
s := Shape {
	"Oval",
	20,
}
```

তবে এই সিনট্যাক্সকে _ভঙ্গুর কোড_ ধরা হয়, কারণ কোনো ফিল্ড যোগ করা হলে এটি ভেঙে পড়তে পারে, বিশেষ করে যখন নতুন ফিল্ডটি ভিন্ন টাইপের হয়।
পরের উদাহরণে আমরা `Shape`-এ একটি অতিরিক্ত ফিল্ড যোগ করি:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## "New" ফাংশন

মাঝে মাঝে এমন ফাংশন থাকলে ভালো হয়, যেগুলো আমাদের স্ট্রাক্টের ইনস্ট্যান্স তৈরি করতে সাহায্য করে।
কনভেনশন অনুযায়ী, এই ফাংশনগুলোকে সাধারণত `New` বলা হয় বা তাদের নাম `New` দিয়ে শুরু হয়, কিন্তু যেহেতু এগুলো নিছক সাধারণ ফাংশন, আপনি চাইলে এদের যেকোনো নাম দিতে পারেন।
এগুলো আপনাকে অন্য ভাষার কনস্ট্রাক্টরদের কথা মনে করিয়ে দিতে পারে, কিন্তু Go-তে এগুলো কেবল সাধারণ ফাংশন।

পরের উদাহরণে, এই `New` ফাংশনগুলোর একটি ব্যবহার করে `Shape`-এর একটি নতুন ইনস্ট্যান্স তৈরি করা হয় এবং আকৃতির `size`-এর জন্য স্বয়ংক্রিয়ভাবে একটি ডিফল্ট মান সেট করা হয়:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New` ফাংশন ব্যবহার করলে নিচের সুবিধাগুলো পাওয়া যায়:

* প্রদত্ত মানগুলোর ভ্যালিডেশন
* ডিফল্ট মান সামলানো
* যেহেতু `New` ফাংশনগুলো প্রায়ই যে স্ট্রাক্টগুলো ইনিশিয়ালাইজ করে, তাদের একই প্যাকেজে ডিক্লেয়ার করা হয়, তাই এগুলো স্ট্রাক্টের প্রাইভেট ফিল্ডও ইনিশিয়ালাইজ করতে পারে
