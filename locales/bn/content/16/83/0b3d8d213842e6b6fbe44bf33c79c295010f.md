# পরিচিতি

## সুইচ

একটি [সুইচ স্টেটমেন্ট][switch] একটি মানকে একাধিক সম্ভাব্য মিলে যাওয়া প্যাটার্নের সাথে তুলনা করে।
একাধিক `if-else` স্টেটমেন্ট শৃঙ্খলাবদ্ধ করার চেয়ে এটি আরও পরিচ্ছন্ন ও পাঠযোগ্য একটি বিকল্প।
একটি `switch` স্টেটমেন্ট শুরু হয় `switch` কিওয়ার্ড দিয়ে, তারপরে থাকে যে মানটি যাচাই করা হবে।
প্রতিটি সম্ভাব্য মিল বোঝানো হয় `case` কিওয়ার্ড দিয়ে।
কোনো নির্দিষ্ট কেস মিলে না গেলে যে ফলব্যাক কেসটি চালানো হয়, তা ডিফাইন করতে `default` কিওয়ার্ড ব্যবহার করা হয়।
`if-else` চেইনের মতোই, `switch` স্টেটমেন্ট শুধু প্রথম মিলে যাওয়া কেসের সাথে যুক্ত কোড ব্লকটিই চালায়।

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

নিচের `if-else` চেইনটি দেখুন:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

এটি একটি `switch` স্টেটমেন্ট দিয়ে আরও স্পষ্টভাবে লেখা যায়:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## হোয়াইল লুপ

একটি [হোয়াইল লুপ][while-loops] হলো একটি কন্ট্রোল ফ্লো স্টেটমেন্ট, যা দিয়ে নির্দিষ্ট একটি শর্ত ট্রু থাকা পর্যন্ত কোড চালানো যায়।
Swift দুই ধরনের হোয়াইল লুপ দেয়: while আর repeat-while লুপ।
হোয়াইল লুপের শর্ত লুপ বডি চালানোর আগে যাচাই করা হয়; শর্তটি ফলস হলে লুপ বডি একেবারেই চালানো হবে না।
Swift-এ হোয়াইল লুপের গঠনটি এরকম:

```swift
while <#condition#> {
  <#code#>
}
```

এখানে count 0-এর চেয়ে বড় থাকা পর্যন্ত লুপটি চলবে এবং তাই 2, 1 আর "Liftoff!" প্রিন্ট করবে।

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

একটি [repeat-while লুপ][while-loops] হোয়াইল লুপের মতোই, তবে শর্তটি লুপ বডি চালানোর পরে যাচাই করা হয়।
এর মানে হলো লুপ বডি অন্তত একবার চালানো হবে, এমনকি শর্তটি ফলস হলেও।
Swift-এ repeat-while লুপের গঠনটি এরকম:

```swift
repeat {
  <#code#>
} while <#condition#>
```

এখানে শর্তটি ফলস হওয়ায় লুপটি শুধু একবারই চলবে।
যেহেতু এটি একটি repeat-while লুপ, তাই শর্ত যাচাইয়ের আগে লুপ বডি একবার চলবে।

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## কন্ট্রোল ট্রান্সফার

লুপ ও সুইচ স্টেটমেন্টের এক্সিকিউশন ফ্লো পরিবর্তন করতে Swift কন্ট্রোল ট্রান্সফার স্টেটমেন্ট দেয়।
`return` ছাড়াও Swift-এ আছে `continue`, `break`, লুপ লেবেল আর `fallthrough`।

### কন্টিনিউ

`continue` স্টেটমেন্ট লুপকে বর্তমান ইটারেশনটি আর চালাতে না বলে সঙ্গে সঙ্গে পরের ইটারেশন শুরু করতে বলে।
`while` বা `repeat-while` লুপে এটি সোজা শর্ত যাচাইয়ের জায়গায় চলে যায়।
`for-in` লুপে এটি সিকোয়েন্সের পরের এলিমেন্টে এগিয়ে যায়।

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

### ব্রেক

`break` স্টেটমেন্ট কোনো লুপ বা সুইচ স্টেটমেন্ট থেকে সঙ্গে সঙ্গে পুরোপুরি বেরিয়ে আসে।
লুপ বা সুইচের পরে থাকা প্রথম কোড লাইন থেকে এক্সিকিউশন আবার চালু হয়।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

### লেবেলযুক্ত স্টেটমেন্ট

লুপগুলো নেস্টেড থাকলে কখনো কখনো সবচেয়ে ভেতরের লুপের বদলে কোনো বাইরের লুপে `break` বা `continue`-এর প্রভাব ফেলতে চাইতে পারেন।
লুপের আগে একটি নাম আর তারপর একটি কোলন (`labelName:`) বসিয়ে লুপে লেবেল দেওয়া যায়।
এরপর সেই লেবেলটি `break` বা `continue`-কে দিতে পারেন:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
