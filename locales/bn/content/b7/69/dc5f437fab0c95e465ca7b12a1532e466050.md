# পরিচিতি

## কপি ও রেফারেন্স

আমাদের বর্তমান জ্ঞান দিয়ে একটি ফাংশনের সাহায্যে একটি ভ্যারিয়েবল আপডেট করা কিছুটা ঝামেলার। প্রতিটি ফাংশন আর্গুমেন্ট একটি কপির মতো ব্যবহার করা হয় এবং মূল মান পরিবর্তন করে না। আপনার টাইপের আকারের উপর নির্ভর করে এটি আপনার কোডের পারফরম্যান্সে গুরুতর পরিণতি ডেকে আনতে পারে।

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

`References`-কে একধরনের উপনাম হিসেবে দেখা যায়, এদের পরিবর্তন মূল ভ্যারিয়েবলের উপর প্রভাব ফেলে। `References` টাইপ ডিক্লারেশনে একটি **অ্যাম্পারস্যান্ড** (`&`) ব্যবহার করে।

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```
রিসিট করা (অর্থাৎ একটি `reference`-এর বাইন্ডিং পরিবর্তন করা) সম্ভব নয়। আপনি একটি আনইনিশিয়ালাইজড `reference` রাখতে পারেন না। `References`-কে একটি বিদ্যমান ভ্যারিয়েবল দিয়ে ইনিশিয়ালাইজ করতে হয়।

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is stil -20

int& future_budget;
// => compiler error, reference must be bound!
```

## `void`

`references`-এর ক্ষমতা দিয়ে আপনার হয়তো একটি ফাংশন থেকে কোনো মান রিটার্ন করার প্রয়োজনই নাও পড়তে পারে। এমন ক্ষেত্রে রিটার্ন টাইপ হিসেবে `void` ব্যবহার করা হয়।

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
