# ভূমিকা

Haxe-এ এক্সেপশন হলো কোড রান করার সময় ঘটে যাওয়া এরর নিরাপদে সামলানোর একটি উপায়। প্রতিটি এক্সেপশনে একটি মেসেজ থাকা উচিত, যা এররটি বর্ণনা করে। আমরা `throw` কিওয়ার্ড ব্যবহার করে এক্সেপশন _থ্রো_ করতে পারি:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

কোনো এক্সেপশন থ্রো করা হলে কোডটি এমন একটি অংশ খুঁজে দেখে, যা এররটি সামলানোর জন্য নির্ধারিত। যদি এমন কিছু খুঁজে না পাওয়া যায়, তাহলে এটি এরর মেসেজটি দেখায় এবং একই সাথে প্রোগ্রামের এক্সিকিউশন বন্ধ করে দেয়।

Haxe-এ এক্সেপশন সামলাতে আমরা `try-catch` ব্লক ব্যবহার করি। এই ব্লক স্টেটমেন্টে একটি `try` ব্লক এবং এক বা একাধিক `catch` ব্লক থাকে। `try` ব্লকটি কোডের একটি অংশ চালানোর _চেষ্টা করে_, আর `catch` ব্লকটি প্রস্তুত হয়ে অপেক্ষা করে, যদি কোনো এক্সেপশন _catch_ করার জন্য থ্রো করা হয়, যাতে এক্সিকিউশন বন্ধ হয়ে না যায়। `catch` ব্লকটি যখন কোনো এক্সেপশন ধরে ফেলে, তখন সেটি ব্লকের ভেতরের সবকিছুও চালিয়ে দেয়:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch` ব্লকের আর্গুমেন্টের টাইপ বাদ দিতে হবে।
