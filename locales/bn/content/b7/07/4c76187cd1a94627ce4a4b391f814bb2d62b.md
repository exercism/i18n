# টেস্ট

`t/` ডিরেক্টরিতে `.t` এক্সটেনশনযুক্ত একটি Perl স্ক্রিপ্ট আছে, যা দিয়ে আপনার সমাধান টেস্ট করা হবে।
নিচের কমান্ডটি ব্যবহার করে আপনি টেস্টগুলো চালিয়ে দেখতে পারেন:

```bash
`prove`
```

টেস্ট ফাইলগুলোতে ব্যবহৃত অ্যাসারশনগুলো সম্পর্কে ডকুমেন্টেশন পাওয়া যাবে [Test2::Manual::Testing::Introduction][test2-manual]-এ।

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
