# সংযোজন
## বোনাস

গ্রাফিম ক্লাস্টার সংরক্ষণ করুন, অর্থাৎ

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

এই বোনাস কাজটির জন্য `Unicode` স্ট্যান্ডার্ড লাইব্রেরিটি আপনার কাজে লাগবে বলেই সম্ভবত মনে হবে।

গ্রাফিম টেস্টটি চালু করতে আপনার ফাইলের গ্লোবাল স্কোপে `const TEST_GRAPHEMES = true` যোগ করুন।
