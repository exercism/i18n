# নির্দেশাবলি

আপনি একটি অনলাইন ফ্যাশন বুটি চালাচ্ছেন। আপনার বছরের সবচেয়ে বড় সেল আসছে, তাই আপনি প্রস্তুত আছেন কিনা নিশ্চিত করতে আপনার ইনভেন্টরির হিসাব নিতে হবে।

ইনভেন্টরির প্রতিটি আইটেম একটি ম্যাপ দিয়ে প্রকাশ করা হয়, আর পুরো ইনভেন্টরি এমন ম্যাপের একটি অ্যারে।

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. দাম অনুযায়ী আইটেম সাজান

`sort_by_price/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ইনভেন্টরি নেবে এবং আইটেমের দাম অনুযায়ী ঊর্ধ্বক্রমে সাজিয়ে রিটার্ন করবে।

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. যে সব আইটেমের দাম নেই সেগুলো খুঁজুন

দাম অনুযায়ী ইনভেন্টরি সাজানোর পর আপনি লক্ষ্য করলেন যে হিসাব নেওয়ার সময় আপনি নিশ্চয়ই একটি ভুল করেছেন এবং কয়েকটি আইটেমের দাম লিখতে ভুলে গেছেন।

`with_missing_price/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ইনভেন্টরি নেবে এবং যেসব আইটেমের দাম নেই সেগুলোর একটি অ্যারে রিটার্ন করবে।

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. আইটেমের নাম আপডেট করুন

আপনি লক্ষ্য করলেন যে কিছু আইটেমের নামে এমন একটি শব্দ আছে যা আপনি আর ব্যবহার করতে পছন্দ করেন না। এখন ওই শব্দটি দিয়ে থাকা সব আইটেমের নাম আপডেট করতে হবে।

`update_names/3` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ইনভেন্টরি, যে পুরোনো শব্দটি আপনি সরাতে চান এবং তার বদলে যে নতুন শব্দটি ব্যবহার করতে চান, সেগুলো নেবে। এটি আপডেট করা নামসহ আইটেমের একটি অ্যারে রিটার্ন করবে।

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. আইটেমের পরিমাণ বাড়ান

কিছু আইটেম বিশেষ ভালো বিক্রি হচ্ছিল, তাই আপনি সব সাইজে আরও অর্ডার করেছিলেন।

`increase_quantity/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি আইটেম এবং একটি সংখ্যা `n` নেবে, এবং প্রতিটি সাইজের পরিমাণ `n` দিয়ে বাড়িয়ে সেই আইটেম রিটার্ন করবে।

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. আইটেমের মোট পরিমাণ হিসাব করুন

আপনার স্টোরেজে কত জায়গা লাগবে তা জানতে, মোট কতগুলো আইটেম আছে তা জানা দরকার।

`total_quantity/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি আইটেম নেবে এবং যেকোনো সাইজ মিলিয়ে মোট কতটি পিস আছে তা রিটার্ন করবে।

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
