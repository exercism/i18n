# সংখ্যার টাইপ

Crystal-এ নানা কাজের জন্য নানা রকম সংখ্যার টাইপ আছে।
যেমন, কিছু টাইপ আরও দ্রুত, কিন্তু সম্ভাব্য মানের রেঞ্জ অন্য কিছু টাইপের চেয়ে ছোট।
আবার কিছু টাইপের সম্ভাব্য মানের রেঞ্জ আরও বিস্তৃত, কিন্তু সেগুলো ধীরগতির।

Crystal-এ সাইনড ও আনসাইনড, দুধরনের ইন্টিজার টাইপই আছে।
সাইনড ইন্টিজার টাইপ ধনাত্মক বা ঋণাত্মক হতে পারে।
আনসাইনড ইন্টিজার টাইপ কেবল ধনাত্মকই হতে পারে।

## সাইনড ইন্টিজার টাইপ

Crystal-এ এগুলো হলো [signed integer][int] টাইপ:

| টাইপ     | সাইজ (বিট) | রেঞ্জ                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 থেকে 127                                                                                                 |
| `Int16`  | 16          | -32_768 থেকে 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 থেকে 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 থেকে 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 থেকে 170_141_183_460_469_231_731_687_303_715_884_105_727 |

ছোট টাইপগুলো বড় টাইপের চেয়ে কম মেমোরি ব্যবহার করে এবং দ্রুততর, কিন্তু সম্ভাব্য মানের রেঞ্জ ছোট।

যখন আপনি জানেন, মানগুলো একটি নির্দিষ্ট রেঞ্জের মধ্যেই থাকবে, তখন মেমোরি বাঁচাতে ও পারফরম্যান্স বাড়াতে সম্ভাব্য সবচেয়ে ছোট টাইপটি ব্যবহার করাই সবচেয়ে ভালো।

ডিফল্ট ইন্টিজার টাইপ হলো `Int32`।
নির্দিষ্ট টাইপের একটি ইন্টিজার ডিক্লেয়ার করতে, `<number>_I <bit>` যোগ করে টাইপের নামটি সাফিক্স হিসেবে ব্যবহার করতে পারেন।

```crystal
1_i8.class
# => Int8
```

ভিন্ন ভিন্ন ইন্টিজার টাইপের মধ্যে কনভার্ট করতে `to_i<bit>` মেথডটি ব্যবহার করতে পারেন।
`to_i` মেথডটি ডিফল্ট ইন্টিজার টাইপ `Int32`-এ কনভার্ট করে।

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## আনসাইনড ইন্টিজার টাইপ

Crystal-এ এগুলো হলো [unsigned integer][uint] টাইপ:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

সাইনড ও আনসাইনড ইন্টিজারের একমাত্র পার্থক্য হলো, আনসাইনড ইন্টিজার কেবল ধনাত্মক হতে পারে।
নির্দিষ্ট টাইপের একটি আনসাইনড ইন্টিজার ডিক্লেয়ার করতে, `<number>_u<bit>` যোগ করে টাইপের নামটি সাফিক্স হিসেবে ব্যবহার করতে পারেন।
ভিন্ন ভিন্ন আনসাইনড ইন্টিজার টাইপের মধ্যে কনভার্ট করতে `to_u<bit>` মেথডটি ব্যবহার করতে পারেন।
`to_u` মেথডটি ডিফল্ট আনসাইনড ইন্টিজার টাইপ `UInt32`-এ কনভার্ট করে।

```crystal
1_u8.to_u16.class
# => UInt16
```

## ফ্লোটিং পয়েন্ট টাইপ

Crystal-এ এগুলো হলো ফ্লোটিং পয়েন্ট টাইপ:

| টাইপ      | সাইজ (বিট) | রেঞ্জ                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 থেকে 3.4E+38   |
| `Float64` | 64          | 2.3E-308 থেকে 1.7E+308 |

দুটি ভিন্ন [floating point type][float] আছে, একটি অন্যটির চেয়ে বেশি নির্ভুল।

ডিফল্ট ফ্লোটিং পয়েন্ট টাইপ হলো `Float64`।

ভিন্ন ভিন্ন ফ্লোটিং পয়েন্ট টাইপের মধ্যে কনভার্ট করতে `to_f<bit>` মেথডটি ব্যবহার করতে পারেন।
`to_f` মেথডটি ডিফল্ট ফ্লোটিং পয়েন্ট টাইপ `Float64`-এ কনভার্ট করে।

## অপারেশনের পর টাইপ

যখন আপনি দুটি সংখ্যার মধ্যে একটি অপারেশন চালান, ফলাফলের টাইপ হবে সবচেয়ে বেশি নির্ভুলতার সংখ্যাটির টাইপ।
ফ্লোট ইন্টিজারের চেয়ে বেশি নির্ভুল, আর ইন্টিজার আনসাইনড ইন্টিজারের চেয়ে বেশি নির্ভুল।
আর `Float64` হলো Float32-এর চেয়ে বেশি নির্ভুল, এভাবেই চলতে থাকে।

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## আরও গভীরে: আনসাইনড ইন্টিজার বনাম সাইনড ইন্টিজার

~~~~exercism/advanced
ভেতরে আসলে যা ঘটে, তা হলো আনসাইনড ও সাইনড ইন্টিজারের মূল পার্থক্য এই যে, সাইনড ইন্টিজার সাইন সংরক্ষণ করতে প্রথম বিটটি ব্যবহার করে।
সাইনটি ধনাত্মক বা ঋণাত্মক, যেকোনো একটি হতে পারে।
আনসাইনড ইন্টিজারের ক্ষেত্রে প্রথম বিটটি মান সংরক্ষণ করতে ব্যবহৃত হয়।
তাই একটি সাইনড ৩২-বিট ইন্টিজারের সর্বোচ্চ মান 2^31 - 1।
আর একটি আনসাইনড ৩২-বিট ইন্টিজারের সর্বোচ্চ মান 2^32 - 1।

সাইনডনেস সম্পর্কে আরও জানতে চাইলে, [উইকিপিডিয়া](https://en.wikipedia.org/wiki/Signedness)য় আরও পড়তে পারেন।
