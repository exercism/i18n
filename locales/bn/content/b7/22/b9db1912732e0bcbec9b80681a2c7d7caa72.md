# ভূমিকা

## for লুপ

`for` স্টেটমেন্ট একটি কোড ব্লক পুনরাবৃত্তি করে।
এর প্রথম লাইনটি নিয়ন্ত্রণ করে ব্লকটি কতবার পুনরাবৃত্তি হবে:

```go
for init; condition; post {
    // loop body
}
```

- **init** স্টেটমেন্টটি প্রথম ইটারেশনের আগে কেবল একবার রান করে। লুপে ব্যবহৃত একটি কাউন্টার ভ্যারিয়েবল ডিক্লেয়ার ও ইনিশিয়ালাইজ করা সাধারণ ব্যাপার।
- **condition** হলো একটি বুলিয়ান এক্সপ্রেশন, যা প্রতিটি ইটারেশনের আগে মূল্যায়িত হয়। এটি `false`-এ মূল্যায়িত হলে লুপটি থেমে যায়।
- **post** স্টেটমেন্টটি প্রতিটি সম্পন্ন ইটারেশনের পরে রান করে। এটি একটি কাউন্টার আপডেট করতে ব্যবহার করা যায়।

`init; condition; post`-কে প্রথম বন্ধনী দিয়ে ঘিরবেন না।
তবে লুপের বডিকে ঘিরে থাকা দ্বিতীয় বন্ধনী `{ }` সবসময়ই প্রয়োজন।

এই লুপটি `i`-কে `1` থেকে শুরু করে, `i`-এর বর্তমান মান প্রিন্ট করে, পরের ইটারেশনের জন্য তা বাড়ায়, এবং `i` যখন `10`-এ পৌঁছায় তখন থেমে যায়:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
