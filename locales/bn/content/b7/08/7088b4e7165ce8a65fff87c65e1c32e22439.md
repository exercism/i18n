# পরিচিতি

ক্লোজার নিয়ে কাজ করার সময় Swift তার সিনট্যাক্সের একটি ভিন্ন রূপের সুযোগ দেয়, যা ট্রেইলিং ক্লোজার নামে পরিচিত। কোনো ফাংশনের প্যারামিটার তালিকার শেষ প্যারামিটারটির টাইপ ফাংশন হলে ট্রেইলিং ক্লোজার দেখা যায়। এক্ষেত্রে ক্লোজার পাস করা হলে সেটি শেষ বন্ধনীর _পরে_ লেখা যায় এবং আর্গুমেন্ট লেবেলটি বাদ দেওয়া হয়। খেয়াল করুন, ফাংশনের যদি একটিমাত্র প্যারামিটার থাকে, তাহলে বন্ধনী দুটি সম্পূর্ণ বাদ দেওয়া যায়।

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
