# প্রিন্টিং

Cairo-তে প্রিন্টিং করলে আপনি কনসোলে মেসেজ ও মান দেখাতে পারেন, যা প্রোগ্রাম debug করা বা চালনার সময় তথ্য জানানো সহজ করে তোলে।

প্রিন্টিং সিস্টেমটি একদিকে বহুমুখী, অন্যদিকে সহজ, যা বিভিন্ন ধরনের ডেটা ফরম্যাট ও আউটপুট করার সরঞ্জাম দেয়।

## প্রিন্টিংয়ের মূল বিষয়

টেক্সট কনসোলে প্রিন্ট করার জন্য Cairo দুটি প্রধান ম্যাক্রো দেয়:

- **`println!`**: নতুন লাইনে আউটপুট প্রিন্ট করে।
- **`print!`**: নতুন লাইন না যোগ করে একই লাইনে আউটপুট প্রিন্ট করে।

দুটি ম্যাক্রোই তাদের প্রধান আর্গুমেন্ট হিসেবে একটি `ByteArray` নেয়, যা একটি সাধারণ স্ট্রিং বা মানের জন্য প্লেসহোল্ডারসহ একটি ফরম্যাটেড স্ট্রিং হতে পারে।

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

উপরের উদাহরণে:

- `{}` প্লেসহোল্ডারগুলো `x` ও `y`-এর মান দিয়ে প্রতিস্থাপিত হয়।
- `println!` নিশ্চিত করে যে আউটপুট একটি নতুন লাইনে শেষ হয়।

## স্ট্রিং ফরম্যাট করা

কখনো কখনো আপনার একটি ফরম্যাটেড স্ট্রিং তৈরি করার দরকার হতে পারে, তা সঙ্গে সঙ্গে প্রিন্ট না করেই।

`format!` ম্যাক্রোর সাহায্যে আপনি এটি করতে পারেন।

এটি `println!`-এর মতোই কাজ করে, তবে কনসোলে আউটপুট পাঠানোর বদলে একটি `ByteArray` রিটার্ন করে।

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

এই উদাহরণে:

- `format!` `s1`, `s2` ও `s3`-কে একটি স্ট্রিংয়ে জোড়া দেয়, ড্যাশ (`-`) দিয়ে আলাদা করে।
- ফলে পাওয়া স্ট্রিংটি পরে আবার ব্যবহার করা বা প্রিন্ট করা যায়।

## কাস্টম ডেটা টাইপ প্রিন্ট করা

ডিফল্টভাবে Cairo কেবল ইন্টিজার ও স্ট্রিংয়ের মতো বেসিক টাইপ প্রিন্ট করতে পারে।

কোনো কাস্টম টাইপ, যেমন একটি struct, প্রিন্ট করতে চাইলে আপনি একটি এরর পাবেন, যদি না টাইপটি `Display` বা `Debug` ট্রেইট ইমপ্লিমেন্ট করে।

### কাস্টম ফরম্যাটিংয়ের জন্য `Display` ব্যবহার করা

`Display` ট্রেইট আপনাকে নির্ধারণ করতে দেয় একটি কাস্টম টাইপ কীভাবে প্রিন্ট হবে।

এখানে একটি উদাহরণ:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

এই উদাহরণে:

- `fmt` ফাংশনটি নির্ধারণ করে `Point` struct কীভাবে একটি প্রিন্টযোগ্য স্ট্রিংয়ে রূপান্তরিত হয়।
- `write!` ম্যাক্রো ফরম্যাটেড স্ট্রিংটি `Formatter`-এ যোগ করে।

### `Debug` দিয়ে ডিবাগিং

ডিবাগিংয়ের জন্য Cairo `Debug` ট্রেইট দেয়।

বেশিরভাগ টাইপের জন্য আপনি এটি স্বয়ংক্রিয়ভাবে ডিরাইভ করতে পারেন, যা আপনার struct-গুলোর অভ্যন্তরীণ বিবরণ দ্রুত ও সহজে প্রিন্ট করা সম্ভব করে।

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

এই উদাহরণে:

- `#[derive(Debug)]` স্বয়ংক্রিয়ভাবে `Debug` ট্রেইটের ইমপ্লিমেন্টেশন তৈরি করে।
- `{:?}` প্লেসহোল্ডার `println!`-কে ফরম্যাটিংয়ের জন্য `Debug` ট্রেইট ব্যবহার করতে বলে।

## হেক্সাডেসিমালে প্রিন্ট করা

`{:x}` প্লেসহোল্ডার ব্যবহার করে Cairo ইন্টিজার হেক্সাডেসিমাল ফরম্যাটে প্রিন্ট করতে দেয়।

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

লো-লেভেল ডেটা রিপ্রেজেন্টেশন নিয়ে কাজ করার সময় এটি বিশেষভাবে কাজের।
