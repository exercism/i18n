# গেটার ও সেটার

গেটার ও সেটার হলো এমন মেথড, যেগুলো দিয়ে আপনি একটি অবজেক্টের প্রপার্টির মান পড়তে ও লিখতে পারেন।
Crystal-এ ম্যাক্রো আছে, যার ফলে একটি প্রপার্টির জন্য গেটার ও সেটার ডিফাইন করা সহজ হয়ে যায়।
ম্যাক্রো হলো কম্পাইল টাইমে কোড তৈরি করার একটি উপায়, যা নিয়ে পরে ম্যাক্রো কনসেপ্টে আলোচনা করা হবে।

Ruby-তে এই মেথডগুলো `attr_reader`, `attr_writer` ও `attr_accessor` মেথড দিয়ে ডিফাইন করা হয়, আর বাইরে থেকে দেখতে এগুলো Crystal-এর বাস্তবায়নের সাথে খুবই মিল।
Crystal এগুলোকে `getter`, `setter` ও `property` ম্যাক্রো হিসেবে ডিফাইন করেছে।

## গেটার

গেটার হলো এমন একটি ম্যাক্রো, যা একটি ইনস্ট্যান্স ভ্যারিয়েবলের মান রিটার্ন করে এমন একটি মেথড ডিফাইন করে।
এর মানে হলো, কোনো ইনস্ট্যান্স ভ্যারিয়েবল ব্যবহার করতে চাইলে (মেথডের ভেতরে, initialize বাদে) আর তার সামনে `@` লিখতে হবে না; বরং গেটার ম্যাক্রো যে মেথডটি ডিফাইন করেছে, সেটিই কল করতে পারবেন।

কমা দিয়ে আলাদা করে গেটার ম্যাক্রোতে একাধিক ইনস্ট্যান্স ভ্যারিয়েবল দেওয়া যায়।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

আপনি দেখতেই পাচ্ছেন, গেটার ব্যবহার করলে লেখা কোডের পরিমাণ কমে যায় এবং কোড পড়তেও সহজ হয়।
এছাড়া Ruby আর Crystal-এর মধ্যে একটি পার্থক্য হলো, Crystal গেটার ম্যাক্রোর আর্গুমেন্ট হিসেবে ভ্যারিয়েবলের নাম আর সিম্বল দুটোই গ্রহণ করে।
সিম্বল নিয়ে পরে সিম্বল কনসেপ্টে আলোচনা করা হবে।

## সেটার

সেটার হলো এমন একটি ম্যাক্রো, যা একটি ইনস্ট্যান্স ভ্যারিয়েবলের মান সেট করে এমন একটি মেথড ডিফাইন করে।
এই ম্যাক্রো খুব একটা দেখা যায় না, এর বদলে সাধারণত `property` ম্যাক্রোই ব্যবহার করা হয়।
যে মেথডগুলো তৈরি হবে সেগুলো দেখতে `name_of_method=`-এর মতো হবে; এই `=` চিহ্নটিই প্রপার্টি সেট করা সম্ভব করে তোলে।

এই মেথড ডেফিনিশনটি একটু বিশেষ, কারণ মেথডটি যে আর্গুমেন্ট গ্রহণ করে তা `=` চিহ্নের পরে থাকে।
Crystal-এ আরও কিছু বিশেষ মেথড এই সিনট্যাক্স ব্যবহার করে, যেমন `+` মেথড।

গেটার ম্যাক্রোর মতোই, সেটার ডিফাইন করার পর কোনো ইনস্ট্যান্স ভ্যারিয়েবলের মান আপডেট করতে চাইলে সেটার ম্যাক্রো যে মেথডটি ডিফাইন করেছে, সেটিই কল করতে পারবেন।

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## প্রপার্টি

প্রপার্টি হলো এমন একটি ম্যাক্রো, যা একটি ইনস্ট্যান্স ভ্যারিয়েবলের জন্য গেটার ও সেটার দুটোই ডিফাইন করে।

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
