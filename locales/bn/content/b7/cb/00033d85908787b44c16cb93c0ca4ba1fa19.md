# পরিচিতি

[পেয়ার ও ডিক্টস][pairs-dicts] কনসেপ্টে জুলিয়ার ডিকশনারি টাইপের মূল বিষয়গুলো নিয়ে আলোচনা করা হয়েছে।

`Dict` একটি গুরুত্বপূর্ণ ও বহুল ব্যবহৃত কালেকশন টাইপ হওয়ায় এগুলো নিয়ে কাজ করার জন্যও অনেক ফাংশন আছে।

## এন্ট্রি পাওয়া

কোনো এন্ট্রি বের করার সবচেয়ে সহজ উপায় হলো কী (key) দিয়ে (যেমনটি অনেক ভাষাতেই করা হয়)।
তবে যে কী (key) আসলে নেই, সেটি চাইলে `KeyError` হয়।

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

এন্ট্রি বের করার আগে আমরা কী (key) আছে কি না পরীক্ষা করে দেখতে পারি (`haskey(d, 4)` বা `4 ∈ keys(d)`-এর মতো কিছু দিয়ে), তবে অনুপস্থিত কী (key) ধরে সরাসরি একটি ডিফল্ট মান পেয়ে যাওয়াটাও কাজে আসতে পারে।

এর জন্য আছে `get()` ফাংশন এবং তার মিউটেটিং রূপ `get!()`.
এই দুটির মধ্যে পার্থক্য হলো, "অনুপস্থিত" কী (key) `Dict`-এ যোগ হয় কি না।

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

আগের কনসেপ্টে আমরা দেখেছি, `delete!()` একটি এন্ট্রি তার কী (key) দিয়ে মুছে ফেলে।
`pop!()` ফাংশন ব্যবহার করে মান বের করা ও মুছে ফেলা একসাথে করা যায়।

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## ইটারেশন

একটি `Dict`-এর ওপর ইটারেশন করলে ডিফল্টভাবে `key => value` পেয়ারগুলো পাওয়া যায়।
এই অংশগুলো সাধারণ `.first` ও `.second` নাম দিয়ে নেওয়া যায়।

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

অনেক সময় আমরা শুধু কীগুলো (key) বা শুধু মানগুলো ব্যবহার করতে চাই, যেটি সহজ।

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## মার্জ করা

দুটি `Dict` একসাথে করা কাজে লাগতে পারে, তবে একাধিক ইনপুটে থাকা কীগুলো (key) নিয়ে আমরা কী করতে চাই, সেটি স্পষ্ট হওয়া দরকার।

`merge()` ও `merge!()` ফাংশন সরবরাহ করা যত খুশি `Dict`-কে বাম থেকে ডানে ক্রমান্বয়ে একসাথে করে।

আগে থেকেই থাকা কীগুলো (key) আগের মান কেবল ওভাররাইট হয়ে যায়, তাই একেবারে ডানের `Dict`-টাই "জিতে যায়"।

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()` ও `mergewith!()` ফাংশনে প্রথম আর্গুমেন্ট হিসেবে একটি ফাংশন দিতে পারি, যা ঠিক করে দেয় একই কী (key) বারবার এলে সেগুলো কীভাবে মার্জ হবে।
যোগ করা এর একটি সহজ উদাহরণ।

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

মার্জ করার সময় দুটি ভেক্টর কনক্যাটেনেট করাও একটি জনপ্রিয় কাজ।
এর জন্য জুলিয়া `vcat()` ফাংশন ব্যবহার করে, যার কারণ [`Multi Dimensional Arrays`][multidim] কনসেপ্টে ব্যাখ্যা করা আছে।

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

লক্ষ করুন, `mergewith` ফাংশনগুলো [হায়ার অর্ডার ফাংশন][hof] ব্যবহারের একটি ভালো উদাহরণ।

একাধিক [`Set`][sets]-এর ক্ষেত্রে সংশ্লিষ্ট মার্জ ফাংশনটি হলো `union`.
