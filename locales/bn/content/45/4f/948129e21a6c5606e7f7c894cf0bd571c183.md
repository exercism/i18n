# পরিচিতি

JavaScript-এ একটি বিল্ট-ইন অবজেক্ট `Date` আছে, যা তারিখ ও সময় সংরক্ষণ করে এবং সেগুলো পরিচালনার জন্য মেথড সরবরাহ করে।

<!-- prettier-ignore -->
~~~exercism/caution
এটি Java-র `java.util.Date` ক্লাসের ওপর ভিত্তি করে তৈরি হয়েছিল, যা ২০১০-এর দশকের গোড়ার দিকে প্রতিস্থাপিত হয়েছিল, তবে ব্যাকওয়ার্ড কম্প্যাটিবিলিটির জন্য JavaScript-এর `Date` টিকে আছে।

সাধারণভাবে তারিখ নিয়ে কাজ করা কতটা কঠিন, আর টাইমজোন হ্যান্ডলিং কতটা দুর্বল বা একেবারেই অনুপস্থিত, তার কারণে `moment.js`, `day.js`, `date-fns` ও `luxon`-এর মতো অনেক লাইব্রেরি গড়ে উঠেছে।
এগুলোর কোনোটিই Exercism-এ পাওয়া যায় না।

আপনার নিজের প্রজেক্টে `moment.js`-এর মতো ডেপ্রিকেটেড বা রক্ষণাবেক্ষণহীন প্যাকেজ ব্যবহার করবেন না, বরং `luxon`-এর মতো আরও আধুনিক বিকল্প, কিংবা এখনো ব্যাপকভাবে পাওয়া যায় না এমন [Temporal][mdn-temporal]-এর ওপর নির্ভর করুন।
এই অনুশীলনীটি `Date`-এর ওপর কেন্দ্রীভূত, যা JavaScript-এর শেষ পর্যন্ত প্রাসঙ্গিক থাকবে।

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## তৈরি

একটি `Date` অবজেক্ট হলো `Date` ক্লাসের একটি ইনস্ট্যান্স।
কনস্ট্রাক্টর ফাংশনে কোনো আর্গুমেন্ট না পাঠিয়েও এটি তৈরি করা যায়।
এতে এমন একটি `Date` অবজেক্ট পাওয়া যায়, যা বর্তমান তারিখ ও সময় নির্দেশ করে:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### ইউনিক্স টাইমস্ট্যাম্প (সংখ্যা)

কোনো সংখ্যা পাঠালে সেটিকে একটি `timestamp` হিসেবে ব্যাখ্যা করা হবে।
টাইমস্ট্যাম্প হলো একটি পূর্ণসংখ্যা, যা **১ জানুয়ারি ১৯৭০ [UTC][defn-utc]+0** থেকে কত **মিলিসেকেন্ড** পেরিয়ে গেছে তা নির্দেশ করে।

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

কেউ হয়তো আশা করতে পারেন `new Date(0)` সবচেয়ে "আগের" ডেট অবজেক্ট তৈরি করবে, কিন্তু JavaScript তারিখটিকে আপনার স্থানীয় টাইমজোনে রূপান্তর করে, যার মানে কেবল [GMT / UTC+0][defn-gmt] টাইমজোনের আশেপাশে থাকা লোকেরাই আসলে [ইউনিক্স এপক][defn-unix-epoch] মানটি পাবেন।

### ISO 8601 টাইমস্ট্যাম্প (স্ট্রিং)

আপনি তারিখ নির্দেশ করে এমন একটি স্ট্রিং মান `Date` কনস্ট্রাক্টরে পাঠাতে পারেন।
সব ইমপ্লিমেন্টেশনে একই রকম থাকে এমন **একমাত্র** ফরম্যাট হলো আন্তর্জাতিকভাবে স্বীকৃত ও প্রমিত তথাকথিত [ISO 8601 টাইমস্ট্যাম্প স্ট্রিং][defn-iso8601]-এর [সরলীকৃত রূপ][mdn-date-string-format]।

[UTC][defn-gmt]-তে সময়ের একটি মুহূর্ত দেখতে এমন হয়:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

যেখানে নিচের প্রতিস্থাপনগুলো ঘটে:

| চিহ্ন | বিবরণ                                   | ডিফল্ট |
| ---- | --------------------------------------------- | ------- |
| YYYY | ক্যালেন্ডার বছর, ৪ অঙ্কে প্রকাশিত    |         |
| MM   | ক্যালেন্ডার মাস, ২ অঙ্কে প্রকাশিত   | 01      |
| DD   | ক্যালেন্ডার দিন, ২ অঙ্কে প্রকাশিত     | 01      |
| T    | আক্ষরিক অক্ষর T, যা তারিখকে সময় থেকে আলাদা করে |         |
| HH   | ২৪-ঘণ্টার ঘড়িতে ঘণ্টা, ২ অঙ্ক        | 00      |
| mm   | মিনিট, ২ অঙ্ক                         | 00      |
| ss   | সেকেন্ড, ২ অঙ্ক                       | 00      |
| mss  | মিলিসেকেন্ড, ৩ অঙ্ক                    | 000     |
| Z    | আক্ষরিক অক্ষর Z, অথবা একটি অফসেট `+/-HH:mm`   |         |

আক্ষরিক অক্ষর `Z` UTC বোঝায় (কোনো টাইমজোন নেই, ডে লাইট সেভিংস নেই)।

যেহেতু বেশিরভাগ কম্পোনেন্টের জন্য ডিফল্ট মান আছে, তাই শেষ থেকে অংশ বাদ দেওয়া বৈধ:

```text
YYYY-MM-DD
```

ডিফল্টভাবে সময় হয় 00:00:00.000

টাইমস্ট্যাম্প যদি `Z` দিয়ে শেষ না হয়, আর `+HH:mm` বা `-HH:mm` (টাইমজোন অফসেট বোঝায়) দিয়েও শেষ না হয়, তাহলে ঐতিহাসিক কারণে নিচের বিষয়টি প্রযোজ্য:

> টাইমজোন অফসেট অনুপস্থিত থাকলে কেবল তারিখের ফরমগুলো UTC সময় হিসেবে এবং তারিখ-সময়ের ফরমগুলো স্থানীয় সময় হিসেবে ব্যাখ্যা করা হয়।
> UTC সময় হিসেবে ব্যাখ্যা করার কারণ একটি ঐতিহাসিক স্পেক ভুল, যা ISO 8601-এর সাথে সঙ্গতিপূর্ণ ছিল না, কিন্তু ওয়েব কম্প্যাটিবিলিটির কারণে বদলানো যায়নি।
> দেখুন [ভাঙা পার্সার: ওয়েব বাস্তবতার এক সমস্যা][ref-broken-parser]।

### ডেট অবজেক্ট

বিদ্যমান একটি ডেট অবজেক্টও কনস্ট্রাক্টরের আর্গুমেন্ট হিসেবে ব্যবহার করা যায়।
এটি একই তারিখ ও সময়সহ বিদ্যমান `Date` অবজেক্টের একটি অনুলিপি তৈরি করে।

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### আলাদা আলাদা তারিখ ও সময়ের কম্পোনেন্ট মান সরবরাহ করা

শুধু তারিখ বোঝায় এমন একটি ডেট তৈরি করতে তিনটি সংখ্যা পাঠানো যায়।
তারিখ ও সময় দুটোই বোঝায় এমন একটি ডেট তৈরি করতে ৬টি সংখ্যা পাঠানো যায়।

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

দ্বিতীয় মানটি হলো `month`, যা জানুয়ারির জন্য `0` থেকে শুরু হয়ে ডিসেম্বরের জন্য `11` পর্যন্ত যায়।

## `Date.parse()`

তারিখ পার্স করার একটি ফাংশন `Date.parse`-এর উল্লেখ বা রেফারেন্স আপনি দেখতে পারেন।
যেহেতু এই ফাংশনের জন্য মাত্র কয়েকটি ইনভ্যারিয়েন্ট (সত্য) আছে এবং বাকি ইমপ্লিমেন্টেশন নির্দিষ্ট করা নেই (তাই স্ট্যান্ডার্ডও নয়), এটি ব্যবহার করা উচিত নয়।

## `Date`-এর কম্পোনেন্টগুলো অ্যাক্সেস করা

ডেট অবজেক্টে বিভিন্ন মেথড আছে, যা তারিখের কম্পোনেন্টগুলো রিটার্ন করে:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

মান আপডেট করার জন্য এগুলোর প্রত্যেকটির একটি সংশ্লিষ্ট `set` ভ্যারিয়েন্ট আছে (যেমন `setFullYear`)।
কোনো মান উপচে পড়লে তা পরের কম্পোনেন্টে গড়িয়ে যায়:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

সব মেথডের জন্য UTC ভ্যারিয়েন্ট আছে, যেগুলো স্থানীয় টাইমজোন উপেক্ষা করে।

## তারিখ থেকে রূপান্তর করা

ডেট অবজেক্টে একটি মেথড `getTime()` আছে, যা মিলিসেকেন্ডে UNIX টাইমস্ট্যাম্প রিটার্ন করে, অর্থাৎ ১ জানুয়ারি ১৯৭০, UTC-তে মধ্যরাত থেকে অতিবাহিত মিলিসেকেন্ডের পরিমাণ।
এছাড়া একটি ডেট অবজেক্টকে ISO 8601 টাইমস্ট্যাম্প স্ট্রিং-এ রূপান্তর করার জন্য `toISOString()` মেথডটি আছে।

## তারিখ তুলনা করা

দুটি তারিখের মধ্যে, বা একটি তারিখ ও একটি সংখ্যার মধ্যে সরাসরি বড় (`>`) ও বড় বা সমান (`>=`), সেইসাথে ছোট (`<`) ও ছোট বা সমান (`<=`) ব্যবহার করা যায়।
এটি কাজ করে কারণ JavaScript তারিখটিকে একটি প্রিমিটিভে কনভার্ট করার চেষ্টা করে।

<!-- prettier-ignore -->
~~~exercism/advanced
দুটি তারিখের মধ্যে বা একটি তারিখ ও একটি সংখ্যার মধ্যে তুলনা করার সময় JavaScript [`[Symbol.toPrimitive]("number")`][mdn-to-primitive] কল করে, যা ভেতরে [`date.valueOf()`][mdn-date-value-of] কল করে।
পরেরটি [`date.getTime()`][mdn-date-get-time] কল করার সমান।

আপনি যদি এই আচরণের ওপর নির্ভর করতে না চান, প্রথমে `getTime()` দিয়ে সংখ্যায় রূপান্তর করে নিন।

[mdn-to-primitive]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/Symbol.toPrimitive
[mdn-date-value-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/valueOf
[mdn-date-get-time]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/getTime
~~~

তারিখ সমতা (`==` এবং `===`) দিয়ে তুলনা করা যায় না, কিন্তু `.getTime()`-এর ফলাফল করা যায়।
