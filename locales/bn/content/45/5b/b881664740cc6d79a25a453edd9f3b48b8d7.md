# নির্দেশনা

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট এমন: `"[<LEVEL>]: <MESSAGE>"`।

এখানে তিনটি আলাদা লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে, প্রতিটিতে একটি লগ লাইন নেওয়া হবে এবং সেটি দিয়ে কিছু একটি করতে বলা হবে।

## 1. একটি লগ লাইন থেকে মেসেজ বের করুন

একটি লগ লাইনের মেসেজ রিটার্ন করার জন্য `message` ফাংশনটি ইমপ্লিমেন্ট করুন:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

শুরুতে বা শেষে থাকা অতিরিক্ত হোয়াইট স্পেস সরিয়ে ফেলতে হবে:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. একটি লগ লাইন থেকে লগ লেভেল বের করুন

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য `log-level` ফাংশনটি ইমপ্লিমেন্ট করুন, আর লেভেলটি রিটার্ন করতে হবে ছোট হাতের অক্ষরে:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. একটি লগ লাইন রিফরম্যাট করুন

লগ লাইনটি রিফরম্যাট করার জন্য `reformat` ফাংশনটি ইমপ্লিমেন্ট করুন, যেখানে মেসেজটি আগে থাকবে আর তার পরে বন্ধনীর মধ্যে লগ লেভেলটি থাকবে:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
