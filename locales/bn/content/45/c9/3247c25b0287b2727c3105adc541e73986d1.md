# ভূমিকা

## প্যাকেজ

Go-তে একটি অ্যাপ্লিকেশন প্যাকেজে সাজানো থাকে।
একটি প্যাকেজ হলো একই ফোল্ডারে থাকা সোর্স ফাইলের সংগ্রহ।
একটি ফোল্ডারের সব সোর্স ফাইলের শুরুতে একই প্যাকেজ নাম থাকতে হবে।
প্রথা অনুযায়ী প্যাকেজের নাম রাখা হয় সেগুলো যে ফোল্ডারে থাকে সেই ফোল্ডারের নামের সঙ্গে মিলিয়ে।

```go
package greeting
```

Go একটি বিস্তৃত স্ট্যান্ডার্ড লাইব্রেরি প্যাকেজ সরবরাহ করে, যা আপনি আপনার প্রোগ্রামে `import` কিওয়ার্ড ব্যবহার করে ব্যবহার করতে পারেন।
স্ট্যান্ডার্ড লাইব্রেরির প্যাকেজগুলো এগুলোর নাম ব্যবহার করে ইমপোর্ট করা হয়।

```go
package greeting

import "fmt"
```

এরপর ইমপোর্ট করা একটি প্যাকেজকে প্যাকেজের নাম দিয়ে সম্বোধন করা হয়:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go নির্ধারণ করে কোনো একটি আইটেম অন্য প্যাকেজের কোড থেকে কল করা যাবে কি না, তা নির্ভর করে সেটি কীভাবে ডিক্লেয়ার করা হয়েছে তার উপর।
একটি ফাংশন, টাইপ, ভ্যারিয়েবল, কনস্ট্যান্ট বা স্ট্রাক্ট ফিল্ডকে বাইরে থেকে দৃশ্যমান করতে (যাকে _এক্সপোর্টেড_ বলা হয়) নামটি অবশ্যই বড় হাতের অক্ষর দিয়ে শুরু হতে হবে।

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## স্ট্রিং ফরম্যাটিং

Go একটি বিল্ট-ইন প্যাকেজ সরবরাহ করে যার নাম `fmt` (ফরম্যাট প্যাকেজ), যা ইনপুট ও আউটপুটের ফরম্যাট নিয়ন্ত্রণ করার জন্য নানা রকম ফাংশন দেয়।
সবচেয়ে বেশি ব্যবহৃত ফাংশনটি হলো `Sprintf`, যা `%s`-এর মতো ভার্ব ব্যবহার করে একটি স্ট্রিংয়ের ভেতরে মান বসায় এবং সেই স্ট্রিং রিটার্ন করে।

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Go-তে ফ্লোটিং পয়েন্ট মানগুলো Sprintf-এর ভার্ব দিয়ে সুবিধাজনকভাবে ফরম্যাট করা হয়: `%g` (কম্প্যাক্ট রিপ্রেজেন্টেশন), `%e` (এক্সপোনেন্ট) অথবা `%f` (নন-এক্সপোনেন্ট)।
তিনটি ভার্বই ফিল্ডের প্রস্থ এবং সংখ্যার অবস্থান নিয়ন্ত্রণ করার সুযোগ দেয়।

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

উপলব্ধ ভার্বগুলোর সম্পূর্ণ তালিকা পাবেন [ফরম্যাট প্যাকেজের ডকুমেন্টেশনে][fmt-docs]।

`fmt`-এ স্ট্রিং নিয়ে কাজ করার আরও ফাংশন আছে, যেমন `Println`, যা শুধু তার পাওয়া আর্গুমেন্টগুলো কনসোলে প্রিন্ট করে, এবং `Printf`, যা প্রিন্ট করার আগে `Sprintf`-এর মতোই ইনপুট ফরম্যাট করে।

[fmt-docs]: https://pkg.go.dev/fmt
