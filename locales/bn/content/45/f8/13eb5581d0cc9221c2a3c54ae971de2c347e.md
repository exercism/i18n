# টেস্ট

## সেটআপ

প্রয়োজনীয় ডিপেন্ডেন্সি ইনস্টল করার জন্য JavaScript-এর [সেটআপ নির্দেশনা][docs-exercism-javascript] দেখে নিন।

## যা যা দরকার

অ্যাসাইনমেন্টের ডিপেন্ডেন্সিগুলো ইনস্টল করুন:

```shell
corepack pnpm install
```

`corepack` যদি চালু না থাকার অভিযোগ করে, তাহলে এটি চালিয়ে সেটি চালু করতে পারেন:

```bash
corepack enable pnpm
```

## টেস্ট স্যুট পাস করানো

প্রতিটি অনুশীলনীর সাথেই একটি টেস্ট স্যুট থাকে, যা সাবমিট করার আগে আপনার সলিউশন যাচাই করতে সাহায্য করে। অনুশীলনীর ডিরেক্টরিতে একটি কমান্ড প্রম্পট খুলে নিচের কমান্ডটি চালিয়ে আপনি এই টেস্টগুলো চালাতে পারেন:

```bash
corepack pnpm test
```

কিছু টেস্ট স্যুটে প্রথমটি ছাড়া বাকি সব টেস্ট স্কিপ করা থাকে।

একটি টেস্ট পাস হয়ে গেলে `xtest` কে `test` এ বদলে দিয়ে আপনি পরের টেস্টটি চালু করতে পারেন।

## নিজের টেস্ট লেখা

আপনি যদি অতিরিক্ত, নিজস্ব টেস্ট লিখতে চান, তাহলে `custom.spec.js` নামে একটি নতুন ফাইল তৈরি করুন এবং নতুন ফাইলটি আপনার সলিউশনের সাথে একসাথে সাবমিট করুন:

```shell
exercism submit numbers.js custom.spec.js
```
