# নির্দেশনা

দুটি অ্যারে দেওয়া থাকলে নির্ণয় করুন প্রথম অ্যারেটি দ্বিতীয় অ্যারেতে অন্তর্ভুক্ত কি না, দ্বিতীয় অ্যারেটি প্রথম অ্যারেতে অন্তর্ভুক্ত কি না, দুটি অ্যারে একে অপরের মধ্যে অন্তর্ভুক্ত কি না, নাকি এর কোনোটিই সত্য নয়।

বিশেষভাবে, একটি অ্যারে A হলো অ্যারে B-এর সাবলিস্ট, যদি B-এর সামনের দিক থেকে ০ বা তার বেশি এলিমেন্ট এবং B-এর পেছনের দিক থেকে ০ বা তার বেশি এলিমেন্ট বাদ দিলে এমন একটি অ্যারে পাওয়া যায়, যা A-এর সঙ্গে সম্পূর্ণ সমান।

উদাহরণ:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A হলো B-এর সাবলিস্ট
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A হলো B-এর সাবলিস্ট
 * A = [3, 4], B = [1, 2, 3, 4, 5], A হলো B-এর সাবলিস্ট
 * A = [1, 2, 3], B = [1, 2, 3], A, B-এর সমান
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A হলো B-এর সুপারলিস্ট
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A, B-এর সুপারলিস্টও নয়, সাবলিস্টও নয়, সমানও নয়
