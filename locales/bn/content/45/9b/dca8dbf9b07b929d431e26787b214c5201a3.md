# টেস্ট

Factor ট্র্যাকটি **Factor 0.101** ব্যবহার করে। প্রতিটি অনুশীলনীর সাথে বান্ডল আকারে একটি `exercism-tools` ভোকাবুলারি আসে, যেটি `STOP-HERE` ও `TASK:` পার্সিং শব্দ এবং একটি টেস্ট রানার সংজ্ঞায়িত করে। অনুশীলনীর ডিরেক্টরি থেকে রান করুন:

```
factor -roots=. -run=exercism-tools <exercise>
```

যেমন, `hello-world` অনুশীলনীর জন্য:

```
factor -roots=. -run=exercism-tools hello-world
```

সব টেস্ট পাস হলে রানারটি স্টেটাস 0 নিয়ে শেষ হয়, আর কোনো টেস্ট ফেল করলে ডায়াগনস্টিক আউটপুট-সহ অশূন্য স্টেটাস নিয়ে শেষ হয়।

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করার অর্থ হলো তার সব টেস্ট পাস করানো।
ডিফল্টভাবে আপনি টেস্ট রান করলে কেবল একটি টেস্ট (প্রথমটি) চালানো হয়।
এটা ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।

এর পেছনের ব্যবস্থাটি হলো টেস্ট ফাইলের `STOP-HERE` লাইনটি: পার্স করার সময় এটি Factor-কে তার নিচের সবকিছু উপেক্ষা করতে বলে, ফলে রানার কেবল উপরের টেস্টগুলোই দেখে। আপনার প্রথম টেস্ট পাস হয়ে গেলে আপনি দুইভাবে আরও টেস্ট চালু করতে পারেন:

- **`STOP-HERE` লাইনটি মুছে ফেলুন**, এতে বাকি সব টেস্ট একসাথে চালু হয়ে যাবে।
- **`STOP-HERE` লাইনটি আরও নিচে সরিয়ে নিন**, এতে একবারে একটি টেস্ট, বা একবারে একটি টাস্ক চালু হবে। কনসেপ্ট অনুশীলনীতে টেস্টগুলো `TASK:` মার্কারের নিচে দলবদ্ধ থাকে, তাই `STOP-HERE`-কে পরের `TASK:`-এর ঠিক আগে সরিয়ে নেওয়াই স্বাভাবিক ধাপ।

সব টেস্ট চালু হয়ে গেলে এবং আপনার ইমপ্লিমেন্টেশন সেগুলো সব পাস করালে, আপনি অনুশীলনীটি সমাধান করে ফেলেছেন!
