# পরিচিতি

Elixir-এ, একটি এনুমারেবল ডেটা স্ট্রাকচার (যেমন অ্যারে, রেঞ্জ) থেকে র‍্যান্ডম এলিমেন্ট বেছে নিতে আমরা [`Enum.random/1`][enum-random] ব্যবহার করি। এই ফাংশনটি একটি এলিমেন্ট বেছে নেয়, যেখানে প্রতিটি এলিমেন্ট বেছে নেওয়ার সম্ভাবনা সমান। একটি রেঞ্জ থেকে একটি র‍্যান্ডম মান বেছে নেওয়া পুরো রেঞ্জ ট্রাভার্স না করেই ধ্রুবক সময়ে সম্পন্ন হয়।

## র‍্যান্ডম ইন্টিজার ও অক্ষর

- র‍্যান্ডম ইন্টিজার বেছে নেওয়া
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- স্ট্রিং হিসেবে একটি র‍্যান্ডম অক্ষর বেছে নেওয়া
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- চারলিস্ট হিসেবে একটি র‍্যান্ডম অক্ষর বেছে নেওয়া
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

একটি এনুমারেবল ডেটা স্ট্রাকচার থেকে একাধিক এলিমেন্ট বেছে নিতে [`Enum.take_random/2`][enum-take-random] ব্যবহার করুন। একটি এনুমারেবল ডেটা স্ট্রাকচারকে র‍্যান্ডম ক্রমে সাজাতে [`Enum.shuffle/1`][enum-shuffle] ব্যবহার করুন।

## র‍্যান্ডম ফ্লোট

র‍্যান্ডম ফ্লোট বেছে নেওয়ার নিজস্ব ফাংশন Elixir-এ নেই। সেটি করতে আমাদের Erlang-এর [`rand`][erl-rand] মডিউল ব্যবহার করতে হয়, যা আসলে `Enum.random`-ও ভেতরে ভেতরে ব্যবহার করে।

- একটি র‍্যান্ডম ফ্লোট বেছে নেওয়া (0.0-এর সমান বা তার চেয়ে বড় এবং 1.0-এর চেয়ে ছোট):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- একটি র‍্যান্ডম ফ্লোট বেছে নেওয়া (`a`-এর সমান বা তার চেয়ে বড় এবং `b`-এর চেয়ে ছোট):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## নরমাল ডিস্ট্রিবিউশন

উপরে উল্লিখিত সব ফাংশনই এমন একটি র‍্যান্ডম মান বেছে নেয়, যেখানে প্রতিটি সম্ভাব্য মান বেছে নেওয়ার সম্ভাবনা সমান। এটিকে বলা হয় _ইউনিফর্ম ডিস্ট্রিবিউশন_। `rand` মডিউলটি [`normal/0`][erl-rand-normal-0] এবং [`normal/2`][erl-rand-normal-2] ফাংশনও দেয়, যা [নরমাল ডিস্ট্রিবিউশন][normal-distribution] অনুসরণ করে একটি র‍্যান্ডম ফ্লোট বেছে নেয়।

## সিড

এটা বোঝা জরুরি যে "র‍্যান্ডম" মানগুলো আসলে একটি [_সিউডো_ র‍্যান্ডম নাম্বার জেনারেটর][prng] দিয়ে তৈরি হয়। PRNG হলো এমন একটি অ্যালগরিদম, যাকে একটি প্রাথমিক মান দেওয়া হলে, যাকে _সিড_ বলা হয়, সে এমন এক ক্রমিক সংখ্যা তৈরি করে যা র‍্যান্ডম মনে হয়, কিন্তু আদৌ র‍্যান্ডম নয়।

এই বিষয়টি ডিবাগিংয়ের জন্য কাজে লাগতে পারে। [`:rand.seed/2`][rand-seed-2] দিয়ে সিড রিসেট করে আপনি Erlang-এর (এবং তাই Elixir-এর) সিউডো র‍্যান্ডম নাম্বার জেনারেটরকে একই ক্রমের মান তৈরি করতে বাধ্য করতে পারেন। প্রথম আর্গুমেন্টটি একটি নির্দিষ্ট PRNG অ্যালগরিদম, আর দ্বিতীয়টি সিড, যা তিনটি ইন্টিজারের একটি টাপল।

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## ক্রিপ্টোগ্রাফি

`Enum.random` এবং Erlang-এর `rand` মডিউল যে র‍্যান্ডম মান রিটার্ন করে, সেগুলো [ক্রিপ্টোগ্রাফিক্যালি সিকিউর][cryptographically-secure-rng] নয়। ক্রিপ্টোগ্রাফিক কী, পাসওয়ার্ড বা নন্স তৈরি করতে এগুলো ব্যবহার করবেন না। এই কাজের জন্য রয়েছে Erlang-এর [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes]।
