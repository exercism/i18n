# পরিচিতি

Go-তে ফাংশন হলো ফার্স্ট-ক্লাস মান।
এর মানে হলো, অন্য সব মানের সাথে যা যা করা যায়, ফাংশনের সাথেও ঠিক সেগুলোই করা যায়। যেমন, ফাংশন ভ্যারিয়েবলে অ্যাসাইন করা, অন্য ফাংশনে আর্গুমেন্ট হিসেবে পাস করা, বা এমনকি অন্য ফাংশন থেকে ফাংশন রিটার্ন করা।

নিচে আমরা দুটি ফাংশন তৈরি করছি, `engGreeting` আর `espGreeting`, এবং সেগুলোকে `greeting` ভ্যারিয়েবলে অ্যাসাইন করছি:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

ফাংশন-মান শুধু ডেটা দিয়েই নয়, আচরণ দিয়েও ফাংশন প্যারামিটারাইজ করার সুযোগ দেয়।
নিচের উদাহরণে আমরা `greetingFunc` প্যারামিটারের মাধ্যমে `dialog` ফাংশনে আচরণ পাস করছি:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

ফাংশন টাইপের কোনো ভ্যারিয়েবল ইনিশিয়ালাইজ করা না থাকলে তার মান হয় `nil`।
তাই একটি `nil` ফাংশন-মান কল করলে প্যানিক ঘটে।

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

ফাংশন-মানকে `nil`-এর সাথে তুলনা করা যায়।
প্রোগ্রামের অপ্রয়োজনীয় প্যানিক এড়াতে এটি কাজে লাগতে পারে।

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## ফাংশন টাইপ

Go-তে ফাংশন টাইপের কারণেই ফাংশন-মান ব্যবহার করা সম্ভব।
একটি ফাংশন টাইপ বলতে এমন সব ফাংশনের সেটকে বোঝায়, যাদের প্যারামিটার টাইপের ক্রম এবং রেজাল্ট টাইপের ক্রম একই।
ফাংশন টাইপের উপর ভিত্তি করে ইউজার-ডিফাইন্ড টাইপ ঘোষণা করা যায়।
উদাহরণস্বরূপ, আগের উদাহরণের `dialog` ফাংশনটি এভাবে আপডেট করা যায়:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## অ্যানোনিমাস ফাংশন

ফার্স্ট-ক্লাস ফাংশনের সুবিধার কারণে পাওয়া আরেকটি শক্তিশালী হাতিয়ার হলো অ্যানোনিমাস ফাংশন।
অ্যানোনিমাস ফাংশন ব্যবহারের জায়গাতেই ডিফাইন করা হয়, `func` কিওয়ার্ডের পরে কোনো নাম না দিয়ে।
এমন ফাংশন বাইরের ফাংশনের ভ্যারিয়েবলগুলোতে অ্যাক্সেস পায়।

যেমন:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib` কল করলে `n1` ও `n2` ভ্যারিয়েবল দুটি ঘোষিত হয় এবং একটি অ্যানোনিমাস ফাংশন রিটার্ন হয়, যা আবার প্রতিবার কল করা হলে এই ভ্যারিয়েবল দুটির মান বদলে দেয়।
অ্যানোনিমাস ফাংশনটি N-তম বার কল করলে 0 থেকে শুরু হওয়া ফিবোনাচি ক্রমের N-তম সংখ্যাটি রিটার্ন করে। ভেতরের অ্যানোনিমাস ফাংশনটি বাইরের `fib` ফাংশনের লোকাল ভ্যারিয়েবল (`n1` ও `n2`) অ্যাক্সেস করতে পারে।
এটি ফাংশন-মানের মধ্যে কলের পর কল ধরে স্টেট ধরে রাখার দুর্দান্ত একটি উপায়।
আমরা বলি, অ্যানোনিমাস ফাংশনটি `n1` ও `n2` ভ্যারিয়েবলের একটি ক্লোজার।
[ক্লোজার][closure] প্রোগ্রামিংয়ে ব্যাপকভাবে ব্যবহৃত হয়, এবং অন্য ভাষাতেও এটি সমর্থিত দেখতে পাবেন।

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
