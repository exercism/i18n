# টাইপ ডিক্লারেশন

PHP একটি _ডাইনামিক্যালি টাইপড_ ভাষা, অর্থাৎ একটি ভ্যারিয়েবলে যেকোনো ধরনের তথ্য থাকতে পারে।
PHP ক্লাস প্রপার্টি, ফাংশন আর্গুমেন্ট এবং ফাংশনের রিটার্ন ভ্যালুর জন্য _ঐচ্ছিক_ স্ট্রং টাইপ ডিক্লারেশনের সুযোগ দেয়।
PHP-তে স্ট্রং টাইপ ডিক্লারেশন রান টাইমে টাইপ অ্যাসার্শন দেয়, তবে সম্ভব হলে PHP স্কেলার টাইপগুলোকে ডিক্লারেশনের সাথে মেলাতে জোর করে রূপান্তর করার চেষ্টা করে।
ফাইলের শুরুতে `strict_types` ডিক্লারেশন ব্যবহার করে এই জোর করে রূপান্তরের আচরণ বন্ধ করা যায়।

```php
<?php
declare(strict_types=1);
```

এছাড়াও, ফাংশন থেকে কোনো মান রিটার্ন করা হবে না বোঝাতে একটি ফাংশন `void` রিটার্ন টাইপ দিতে পারে।

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## টাইপ ইউনিয়ন

কোনো ফাংশন আর্গুমেন্ট, রিটার্ন ভ্যালু বা ক্লাস প্রপার্টি একাধিক টাইপের হতে পারলে একটি টাইপ ইউনিয়ন ডিক্লেয়ার করা যায়।

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## মিক্সড টাইপ

কোড নিয়ে কাজ করার সময় আমরা অনেক ক্ষেত্রে টাইপ নির্দিষ্ট করতে পারি না।
PHP 8.0 থেকে `mixed` নামে একটি এস্কেপ-হ্যাচ টাইপ দেওয়া হয়েছে।
`mixed` আসলে `object|resource|array|string|float|int|bool|null` টাইপ ইউনিয়নের সমান।
