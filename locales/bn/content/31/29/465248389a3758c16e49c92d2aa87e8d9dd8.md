# প্রিন্ট স্টেটমেন্ট এড়িয়ে চলুন

`System.out.println()` ইত্যাদি স্টেটমেন্ট আপনার কোড থেকে মুছে ফেলার চেষ্টা করুন।
অনুশীলনীর টেস্টগুলো চায় যে আপনার সমাধান মানগুলো প্রিন্ট করার বদলে মেথড থেকে সেগুলো _রিটার্ন_ করুক।

সাধারণত কোড ডিবাগ করার সুবিধার জন্য এমন স্টেটমেন্ট যোগ করা হয়।
তবে এক বা একাধিক ইউনিট টেস্ট চালানোর সময় কোড ডিবাগ করাই এর চেয়ে ভালো উপায়।
এতে বাড়তি সুবিধা হলো, নির্দিষ্ট একটি টেস্ট কেস ডিবাগ করার দিকে মনোযোগ দেওয়া যায়।

বিভিন্ন IDE-তে ইউনিট টেস্ট চালানোর সময় Java কোড কীভাবে ডিবাগ করবেন, তার ব্যাখ্যা দেওয়া কিছু লিংক নিচে দেওয়া হলো:

- [Visual Studio Code-এ Java টেস্ট চালানো ও ডিবাগ করা](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [IntelliJ IDEA-তে টেস্ট ডিবাগ করা](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
