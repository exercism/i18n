# নির্দেশাবলি

Elaine একটি নতুন শিশুদের গেম নিয়ে কাজ করছেন, যেখানে থাকবে প্রাণী আর জাদুদণ্ড।
এখন সময় এসেছে পাশা রোল করা, র্যান্ডম জাদুদণ্ডের এনার্জি তৈরি করা আর একটি স্লাইস শাফল করার ফাংশন কোড করার।

## 1. একটি পাশা রোল করুন

একটি `RollADie` ফাংশন ইমপ্লিমেন্ট করুন।

এটি হবে প্রচলিত বিশতলীয় পাশা, যার সংখ্যাগুলো ১ থেকে ২০।

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. জাদুদণ্ডের এনার্জি তৈরি করুন

একটি `GenerateWandEnergy` ফাংশন ইমপ্লিমেন্ট করুন।
জাদুদণ্ডের এনার্জি হবে একটি র্যান্ডম ফ্লোটিং পয়েন্ট সংখ্যা, যা 0.0-এর সমান বা তার চেয়ে বড় এবং 12.0-এর চেয়ে ছোট।

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. একটি স্লাইস শাফল করুন

গেমটিতে আটটি ভিন্ন প্রাণী আছে:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

এমন একটি `ShuffleAnimals` ফাংশন লিখুন, যা র্যান্ডম ক্রমে আটটি প্রাণীসহ একটি স্লাইস রিটার্ন করে।
