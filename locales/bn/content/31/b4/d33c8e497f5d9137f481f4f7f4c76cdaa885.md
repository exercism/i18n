# ভূমিকা

## এক্সেপশন ফিল্টারিং

`when` হলো এক্সেপশন ফিল্টার করার কিওয়ার্ড। এটি `catch` স্টেটমেন্টের পরে বসে এবং সেই সময়ে স্কোপে থাকা যেকোনো মান সম্বলিত একটি বুলিয়ান এক্সপ্রেশন নিতে পারে। এক্সপ্রেশনটি যদি ট্রু হয়, তাহলে ওই `catch` স্টেটমেন্টের সাথে সংশ্লিষ্ট ব্লকটি চালানো হয়, অন্যথায় পরের `catch` স্টেটমেন্টটি, যদি থাকে, যাচাই করা হয়।

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## ব্যবহারকারী-নির্ধারিত এক্সেপশন

ব্যবহারকারী-নির্ধারিত এক্সেপশন হলো আপনার কোডে সংজ্ঞায়িত এমন যেকোনো ক্লাস, যা `System.Exception` থেকে ডেরাইভ করা। এটি ক্লাস ইনহেরিট্যান্সের সব নিয়ম মেনে চলে, তবে এর পাশাপাশি কম্পাইলার ও ভাষার রানটাইম এই ধরনের ক্লাসকে বিশেষ একটি উপায়ে বিবেচনা করে, যার ফলে স্বাভাবিক কন্ট্রোল ফ্লোরের বাইরে এদের ইনস্ট্যান্স থ্রো ও ক্যাচ করা যায়, যেমনটি `exceptions` অনুশীলনীতে আলোচনা করা হয়েছে।

ব্যবহারকারী-নির্ধারিত এক্সেপশন প্রায়ই অতিরিক্ত তথ্য বহন করতে ব্যবহৃত হয়, যেমন একটি মেসেজ এবং সংশ্লিষ্ট অন্যান্য ডেটা, যাতে সেগুলো ক্যাচ করার রুটিনগুলোর কাছে পাওয়া যায়।
