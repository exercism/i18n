# তুলনা অপারেটর

PHP-এ দশটি বিল্ট-ইন তুলনা অপারেটর আছে:

| নাম  | উদাহরণ    | ফলাফল                                             |
| ----- | ---------- | -------------------------------------------------- |
| সমান | `$a == $b` | টাইপ রূপান্তরের পর `$a` যদি `$b`-এর সমান হয়, তাহলে ট্রু। |
| অভিন্ন | `$a === $b` | `$a` যদি `$b`-এর সমান হয় এবং দুটির টাইপও একই হয়, তাহলে ট্রু। |
| সমান নয় | `$a != $b` | টাইপ রূপান্তরের পর `$a` যদি `$b`-এর সমান না হয়, তাহলে ট্রু। |
| সমান নয় | `$a <> $b` | টাইপ রূপান্তরের পর `$a` যদি `$b`-এর সমান না হয়, তাহলে ট্রু। |
| অভিন্ন নয় | `$a !== $b` | `$a` যদি `$b`-এর সমান না হয়, বা দুটির টাইপ একই না হয়, তাহলে ট্রু। |
| ছোট | `$a < $b` | `$a` যদি `$b`-এর চেয়ে কঠোরভাবে ছোট হয়, তাহলে ট্রু। |
| বড় | `$a > $b` | `$a` যদি `$b`-এর চেয়ে কঠোরভাবে বড় হয়, তাহলে ট্রু। |
| ছোট বা সমান | `$a <= $b` | `$a` যদি `$b`-এর চেয়ে ছোট বা সমান হয়, তাহলে ট্রু। |
| বড় বা সমান | `$a >= $b` | `$a` যদি `$b`-এর চেয়ে বড় বা সমান হয়, তাহলে ট্রু। |
| স্পেসশিপ | `$a <=> $b` | `$a`-এর তুলনায় `0`i এর চেয়ে ছোট, সমান বা বড় একটি ইন্টিজার রিটার্ন করে। |

PHP-এ `equal` আর `identical`-এর মধ্যে পার্থক্য করার জন্য আলাদা আলাদা সংজ্ঞা আছে। কখনও কখনও `identical`-কে `strictly equal`-ও বলা হয়।

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
