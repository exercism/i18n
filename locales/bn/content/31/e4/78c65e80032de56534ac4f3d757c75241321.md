# পরিচিতি

Go-তে একটি অ্যাপ্লিকেশন প্যাকেজে সাজানো হয়।
একটি প্যাকেজ হলো একই ফোল্ডারে থাকা সোর্স ফাইলের একটি সংগ্রহ।
একটি ফোল্ডারের সব সোর্স ফাইলের শুরুতে একই প্যাকেজ নাম থাকতে হবে।
প্রচলিত নিয়ম অনুযায়ী, প্যাকেজের নাম রাখা হয় তারা যে ফোল্ডারে থাকে তার নামের মতোই।

```go
package greeting
```

Go একটি বিস্তৃত স্ট্যান্ডার্ড লাইব্রেরি প্রদান করে, যার প্যাকেজগুলো আপনি `import` কিওয়ার্ড ব্যবহার করে আপনার প্রোগ্রামে ব্যবহার করতে পারেন।
স্ট্যান্ডার্ড লাইব্রেরির প্যাকেজগুলো এদের নাম দিয়েই ইমপোর্ট করা হয়।

```go
package greeting

import "fmt"
```

এরপর একটি ইমপোর্ট করা প্যাকেজকে তার নাম দিয়ে ব্যবহার করা হয়:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

কোনো আইটেম অন্য প্যাকেজের কোড থেকে কল করা যাবে কি না, তা Go নির্ধারণ করে সেটি কীভাবে ডিক্লেয়ার করা হয়েছে তার ভিত্তিতে।
একটি ফাংশন, টাইপ, ভ্যারিয়েবল, কনস্ট্যান্ট বা স্ট্রাক্ট ফিল্ডকে বাইরে থেকে দৃশ্যমান করতে (যাকে _এক্সপোর্টেড_ বলা হয়) নামটি অবশ্যই বড় হাতের অক্ষর দিয়ে শুরু হতে হবে।
এটি অন্য প্রোগ্রামিং ভাষার মতোই, যেমন Java, যেগুলো `public` ও `private`-এর মতো অ্যাক্সেস মডিফায়ার ব্যবহার করে।

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
