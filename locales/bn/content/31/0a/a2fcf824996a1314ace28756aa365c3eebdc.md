# সরাসরি কোডপয়েন্টকে স্ট্রিংয়ে পরিবর্তন করুন

একটি ক্যারেক্টার কোডপয়েন্টকে সেই ক্যারেক্টারবিশিষ্ট একটি স্ট্রিংয়ে পরিবর্তন করার সবচেয়ে সহজ উপায় হলো `<<>>` স্পেশাল ফর্মটি ব্যবহার করা। মধ্যবর্তী ধাপ হিসেবে চারলিস্ট ব্যবহার করার কোনো প্রয়োজন নেই।

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
