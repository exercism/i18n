# নির্দেশনা

এই অনুশীলনীতে আপনি লগ লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট নিচের মতো: `"[<LEVEL>]: <MESSAGE>"`।

তিনটি আলাদা লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি টাস্ক আছে, যার প্রত্যেকটি একটি লগ লাইন নেবে এবং সেটি দিয়ে কিছু করতে বলবে।

আপনি base R-এর লিগ্যাসি ফাংশন অথবা `stringr` লাইব্রেরি, দুটির যেকোনোটি বেছে নিতে পারেন; দুটিই ছোট ও কার্যকর সমাধান দিতে পারে।

## 1. লগ লাইন থেকে মেসেজ বের করুন

`message` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি লগ লাইনের মেসেজ রিটার্ন করে:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

শুরুতে বা শেষে থাকা অতিরিক্ত হোয়াইটস্পেস মুছে ফেলা উচিত:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. লগ লাইন থেকে লগ লেভেল বের করুন

`log_level` ফাংশনটি ইমপ্লিমেন্ট করুন যাতে এটি লগ লাইনের লগ লেভেল রিটার্ন করে, যা ছোট হাতের অক্ষরে রিটার্ন করা উচিত:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. একটি লগ লাইন নতুন করে সাজান

`reformat` ফাংশনটি ইমপ্লিমেন্ট করুন, যা লগ লাইনটি নতুন করে সাজায়: মেসেজটি আগে বসায় আর তার পরে বন্ধনীর ভেতরে লগ লেভেলটি রাখে:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
