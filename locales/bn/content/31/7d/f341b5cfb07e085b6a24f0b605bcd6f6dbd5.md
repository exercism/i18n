# ইনস্টলেশন

## Node.js ইনস্টল করুন

**Windows এবং OS X ব্যবহারকারীরা**: [প্যাকেজ ম্যানেজার][node-download]-এর মাধ্যমে [Node.js][node] ইনস্টল করুন।

**Linux ব্যবহারকারীরা**: আপনার ডিস্ট্রিবিউশনের জন্য [Node.js প্যাকেজ ম্যানেজার][linstall]-এ থাকা নির্দেশনা অনুসরণ করে [Node.js][node] ইনস্টল করুন।

## `jasmine-node` এবং `coffeescript` ইনস্টল করুন

বেশিরভাগ ব্যবহারকারীর জন্য এটি নিচের কমান্ডটি চালানোর মতোই সহজ হবে:

```bash
$ npm install -g jasmine-node coffeescript
```

আপনার সেটআপের উপর নির্ভর করে গ্লোবালি একটি `npm` মডিউল ইনস্টল করতে সুপার ইউজার অনুমতির প্রয়োজন হতে পারে।
উপরে লিংক করা অফিসিয়াল ইনস্টলার ব্যবহার করে থাকলে এটি আপনার ক্ষেত্রেও প্রযোজ্য।
অ্যাক্সেস নেই বলে NPM কোনো এরর দেখালে, উপরের কমান্ডে `sudo` যোগ করুন:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

অফিসিয়াল ইনস্টলার ব্যবহার করে থাকলে আপনার `PATH` স্বয়ংক্রিয়ভাবে কনফিগার হওয়ার কথা, তবে আপনার শেল গ্লোবালি ইনস্টল করা মডিউল খুঁজে পেতে সমস্যা করলে, অথবা আপনি সোর্স থেকে Node.js বিল্ড করলে।
তখন `~/.bash_profile` অথবা `~/.zshrc`-এ নিচেরটি যোগ করে আপনার `PATH`-এ `npm` বাইনারিগুলো অন্তর্ভুক্ত করুন:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
