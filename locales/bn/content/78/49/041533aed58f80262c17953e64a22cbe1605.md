# ইনস্টলেশন

অনুশীলনীগুলোতে কাজ করতে আপনার নিচের সফটওয়্যারগুলো লাগবে:

1. [`OPAM`, OCaml প্যাকেজ ম্যানেজার](https://opam.ocaml.org/)

   আপনার অপারেটিং সিস্টেমে `OPAM` কীভাবে ইনস্টল ও কনফিগার করবেন, তা জানতে দেখুন [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)।

2. OCaml কম্পাইলার

   কোন কোন ভার্সন পাওয়া যায়, তার তালিকা দেখুন:

   ```bash
   opam switch
   ```

   আপনার যদি OCaml 5.1-এর জন্য আগে থেকেই একটি সুইচ থাকে, তাহলে `opam switch <switch-name>` রান করে সেটি লোড করুন, অথবা নতুন একটি সুইচ তৈরি করতে রান করুন:

   ```bash
   opam switch create exercism 5.4.0
   ```

   এখানে `exercism` নামটি ঐচ্ছিক, তবে সুইচগুলোতে নাম দেওয়া ভালো অভ্যাস।

3. বর্ধিত স্ট্যান্ডার্ড লাইব্রেরি ও টেস্ট লাইব্রেরি ইনস্টল করুন

   এই ট্র্যাকের প্রয়োজনীয় ডিপেন্ডেন্সিগুলো ইনস্টল করতে নিচেরটি রান করুন:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   কিছু অনুশীলনী শুধু OCaml-এর স্ট্যান্ডার্ড লাইব্রেরি ব্যবহার করে, আর কিছু ব্যবহার করে Jane Street-এর বর্ধিত লাইব্রেরি Base ও Core_kernel।
   টেস্ট লাইব্রেরির নাম OUnit, আর কিছু অনুশীলনীতে প্রপার্টি-ভিত্তিক টেস্টের জন্য অতিরিক্তভাবে QCheck লাইব্রেরিও ব্যবহার করা হয়।
   উপরের কমান্ডটি রান করলে এই লাইব্রেরিগুলো ইনস্টল হয়ে যাবে।

4. ইন্টারঅ্যাকটিভ শেল ইনস্টল ও ব্যবহার করুন (ঐচ্ছিক)

   [`utop` সেটআপ ও ব্যবহার](https://dev.realworldocaml.org/install.html) করার সারসংক্ষেপ:

   ```bash
   opam install utop
   ```

   আপনার হোম ডিরেক্টরিতে `.ocamlinit` নামে একটি নতুন ফাইল তৈরি করুন এবং সেখানে নিচের লাইনগুলো যোগ করুন:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. VS Code-এ টুল ইনস্টল করুন (ঐচ্ছিক)

   আপনি যদি VS Code ব্যবহার করেন:
   - [এখান](https://github.com/ocaml/ocaml-lsp) থেকে OCaml ল্যাঙ্গুয়েজ সার্ভার ইনস্টল করুন।
   - [এখান](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform) থেকে OCaml VS Code এক্সটেনশন ইনস্টল করুন, অথবা Ocaml Labs-এর `OCaml Platform` সার্চ করুন।
