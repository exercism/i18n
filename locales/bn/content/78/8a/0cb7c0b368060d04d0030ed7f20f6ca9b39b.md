# নির্দেশনা সংযোজন

## বাস্তবায়ন

আইটেমগুলোকে [রেকর্ড](https://lfe.gitbooks.io/reference-guide/content/16.html) দিয়ে প্রকাশ করা হয়, যেগুলো `item.lfe`-এ ডিফাইন করা হয়েছে।
ওজন পেতে `item-weight` এবং মান পেতে `item-value` ব্যবহার করুন।

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
