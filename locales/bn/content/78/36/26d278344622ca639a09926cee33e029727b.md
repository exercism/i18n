# ভূমিকা

ABAP-এ কয়েক ধরনের সংখ্যাসূচক টাইপ রয়েছে। এই অনুশীলনীতে আপনি এর মধ্যে দুটি ব্যবহার করবেন:

- `i` — ইন্টিজার মানের জন্য, যেমন কোনো কিছু দিনের সংখ্যা।
- `p` — প্যাকড দশমিক মানের জন্য, যেমন ঘণ্টাপ্রতি রেট বা ডিসকাউন্ট।

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

প্যাকড সংখ্যাগুলো নিজেদের সর্বোচ্চ দৈর্ঘ্য ও দশমিক স্থানের সংখ্যা নির্ধারণ করে। দশমিক লিটারাল সাধারণত টেক্সট মান হিসেবে লেখা হয়, আর কম্পাইলার সেগুলোকে লক্ষ্য দশমিক টাইপে রূপান্তর করে বা `CONV` দিয়ে রূপান্তর করা হয়।

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP-এ রাউন্ডিংয়ের জন্য বিল্ট-ইন সংখ্যাসূচক ফাংশন আছে। `floor` ফাংশনটি নিকটতম পূর্ণ সংখ্যায় নিচের দিকে রাউন্ড করে, আর `ceil` নিকটতম পূর্ণ সংখ্যায় উপরের দিকে রাউন্ড করে।

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
