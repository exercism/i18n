# নির্দেশনা সংযোজন

## Callable

PHP-তে callable নামে একটি ধারণা আছে।

এগুলো একাধিক রূপ নিতে পারে, তবে আমরা অ্যানোনিমাস ফাংশন নিয়েই আলোচনা করব।

একটি ভ্যারিয়েবলে একটি অ্যানোনিমাস ফাংশন তৈরি করে প্যারামিটার দিয়ে সেটি কল করা সম্ভব:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
