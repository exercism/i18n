# সহায়তা

সমস্যায় পড়লে সহায়তা পাওয়ার জন্য আপনি নিচের যেকোনো একটি উৎস ব্যবহার করতে পারেন:

- [The Emacs Wiki](http://emacswiki.org/) অমূল্য একটি সম্পদ। এখানে অনেক সময় কাটাতে পারেন।
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) হলো GNU Emacs-এর অফিসিয়াল ম্যানুয়াল।
- IRC - `#emacs`, `#org-mode` এবং আরও অনেক Emacs প্যাকেজের জন্য [Libera.Chat](https://libera.chat/) চ্যানেল রয়েছে, আর আশেপাশে আছেন অনেক সহায়ক মানুষ। আর Emacs-এর মধ্যে থেকে IRC ব্যবহার করা `M-x erc`-এর মতোই সহজ।
- Matrix - [Matrix](https://matrix.org/)-এ [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) এবং অন্যান্য Emacs প্যাকেজের রুম আছে।
  উপলব্ধ চ্যানেলগুলোর একটি ধারণা পেতে আপনি [Emacs Matrix space-এ যোগ দিতে](https://matrix.to/#/#emacs-space:matrix.org) পারেন।
  Emacs-এর ভেতর থেকে Matrix-এ যোগ দিতে আপনি [Ement.el](https://github.com/alphapapa/ement.el) প্যাকেজটি ব্যবহার করতে পারেন।
- আপনার সমস্যাটি খুঁজতে এবং আগেই কেউ এর উত্তর দিয়েছে কি না দেখতে [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) আর [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) ব্যবহার করতে পারেন। এছাড়া প্রশ্ন করতে এবং উত্তর দিতেও পারেন।
