# পরিচিতি

অনেক প্রোগ্রামেরই বাস্তব জগতের ঘটনা সিমুলেট করার জন্য (সিউডো-)র্যান্ডম মান দরকার হয়।

কমন, পরিচিত কিছু উদাহরণ:

- একটি কয়েন টস: ('H', 'T') থেকে একটি র্যান্ডম মান।
- একটি পাশা গড়া: ১ থেকে ৬ পর্যন্ত একটি র্যান্ডম ইন্টিজার।
- তাসের একটি ডেক শাফল করা: তাসের একটি তালিকার র্যান্ডম বিন্যাস।
- থ্রি-ডি গ্রাফিক্স সিমুলেশনে গাছ ও ঝোপ তৈরি।

সব বড় ব্রাউজার এবং JavaScript রানটাইম একটি PRNG (সিউডোর্যান্ডম সংখ্যা জেনারেটর) বাস্তবায়ন করে।

[Web Cryptography][rfc] নামে একটি স্ট্যান্ডার্ড আছে, যা JavaScript-এ ক্রিপ্টোগ্রাফি করার একটি ইন্টারফেসের মান নির্ধারণ করে।
এটি [ব্রাউজারগুলোতে][crypto-web] এবং [Node.JS][crypto-node] ও [Deno][crypto-deno]-এর মতো রানটাইমেও বাস্তবায়িত হয়েছে।

এই ধারণাটি Web Crypto নিয়ে নয়, এটি শুধু সিউডোর্যান্ডম সংখ্যা জেনারেশনের মধ্যেই সীমাবদ্ধ থাকবে।

## র্যান্ডম সংখ্যা তৈরি

JavaScript-এ আপনি [`Math.random()`][Math.random] ফাংশনটি ব্যবহার করে সিউডোর্যান্ডম সংখ্যা তৈরি করতে পারেন।
এটি ০ (অন্তর্ভুক্ত) এবং ১ (অন্তর্ভুক্ত নয়) এর মধ্যে একটি সিউডোর্যান্ডম ফ্লোটিং-পয়েন্ট সংখ্যা রিটার্ন করবে।

_min_ (অন্তর্ভুক্ত) এবং _max_ (অন্তর্ভুক্ত নয়) এর মধ্যে একটি র্যান্ডম সংখ্যা পেতে আপনি এইরকম একটি ফাংশন ব্যবহার করতে পারেন:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## র্যান্ডম ইন্টিজার তৈরি

একটি র্যান্ডম ইন্টিজার তৈরি করতে, আপনি র্যান্ডমভাবে তৈরি হওয়া একটি সংখ্যাকে ইন্টিজারে রূপান্তর করতে `Math.floor()` বা `Math.ceil()` ব্যবহার করতে পারেন।

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
