# ভূমিকা

## সংখ্যা

C#-এ দুই ধরনের সংখ্যা আছে:

- ইন্টিজার: দশমিক বিন্দুর পেছনে কোনো অঙ্ক নেই এমন সংখ্যা (পূর্ণসংখ্যা)। উদাহরণ হলো `-6`, `0`, `1`, `25`, `976` এবং `500000`।
- ফ্লোটিং-পয়েন্ট সংখ্যা: দশমিক বিন্দুর পেছনে শূন্য বা তার বেশি অঙ্ক থাকে এমন সংখ্যা। উদাহরণ হলো `-2.4`, `0.1`, `3.14`, `16.984025` এবং `1024.0`।

C#-এর সবচেয়ে কমন দুটি নাম্বার টাইপ হলো `int` এবং `double`। একটি `int` হলো ৩২-বিট ইন্টিজার আর একটি `double` হলো ৬৪-বিট ফ্লোটিং-পয়েন্ট সংখ্যা।

গাণিতিক কাজ করা হয় স্ট্যান্ডার্ড গাণিতিক অপারেটর দিয়ে। সংখ্যা তুলনা করা যায় স্ট্যান্ডার্ড সাংখ্যিক তুলনা অপারেটর এবং সমতা (`==`) ও অসমতা (`!=`) অপারেটর দিয়ে।

C#-এ দুই ধরনের সাংখ্যিক রূপান্তর আছে:

1. ইমপ্লিসিট কনভার্সন: কোনো ডেটা হারাবে না এবং অতিরিক্ত কোনো সিনট্যাক্সের দরকার হয় না।
2. এক্সপ্লিসিট কনভার্সন: ডেটা হারাতে পারে এবং _কাস্ট_-এর আকারে অতিরিক্ত সিনট্যাক্সের দরকার হয়।

যেহেতু একটি `int`-এর প্রিসিশন একটি `double`-এর চেয়ে কম, তাই একটি `int` থেকে `double`-এ রূপান্তর নিরাপদ এবং সেজন্যই সেটি একটি ইমপ্লিসিট কনভার্সন। তবে একটি `double` থেকে `int`-এ রূপান্তর করলে ডেটা হারাতে পারে, তাই এর জন্য দরকার হয় একটি এক্সপ্লিসিট কনভার্সন।

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## `if` স্টেটমেন্ট

এই অনুশীলনীতে আপনাকে শর্তসাপেক্ষে লজিক চালাতে হবে। C#-এ এটি করার সবচেয়ে কমন উপায় হলো একটি `if/else` স্টেটমেন্ট ব্যবহার করা:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

একটি `if` স্টেটমেন্টের শর্ত অবশ্যই `bool` টাইপের হতে হবে। C#-এ _truthy_ মানের কোনো ধারণা নেই।
