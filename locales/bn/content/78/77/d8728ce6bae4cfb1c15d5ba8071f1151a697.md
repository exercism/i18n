# নির্দেশনা

এই অনুশীলনীতে আপনি Exercism-এ শিখতে চান এমন প্রোগ্রামিং ভাষার একটি অ্যারে নিয়ে হিসাব রাখার কোড লিখবেন।

আপনার ছয়টি কাজ আছে, যার প্রতিটিতেই অ্যারে নিয়ে কাজ করতে হবে।

## 1. একটি নতুন অ্যারে তৈরি করুন

আপনি যে ভাষাগুলো শিখতে চান সেগুলোর হিসাব রাখতে হলে আপনাকে একটি নতুন অ্যারে তৈরি করতে হবে। একটি নতুন, খালি অ্যারে ধারণ করে এমন `newList` বাইন্ডিংটি ডিফাইন করুন।

```fsharp
newList
// => []
```

## 2. একটি বিদ্যমান অ্যারে ডিফাইন করুন

বর্তমানে আপনার কাছে একটি কাগজের টুকরো আছে, যেখানে আপনি যে ভাষাগুলো শিখতে চান সেগুলো লেখা আছে: F#, Clojure এবং Haskell। এই অ্যারেটি বোঝাতে `existingList` বাইন্ডিংটি ডিফাইন করুন।

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. অ্যারেতে একটি নতুন ভাষা যোগ করুন

Exercism ঘুরে দেখতে দেখতে যখন আরও মজার ভাষা খুঁজে পান, তখন সেগুলো আপনার অ্যারেতে যোগ করতে চান। আপনার অ্যারের শুরুতে একটি নতুন ভাষা যোগ করতে `addLanguage` ফাংশনটি ইমপ্লিমেন্ট করুন।

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. অ্যারেতে ভাষার সংখ্যা গণনা করুন

একটি একটি করে ভাষা গণনা করা অসুবিধাজনক। আপনার অ্যারেতে ভাষার সংখ্যা গণনা করতে `countLanguages` ফাংশনটি ইমপ্লিমেন্ট করুন।

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. অ্যারেটি উল্টে দিন

একসময় আপনি বুঝতে পারবেন যে আপনার অ্যারেটি আসলে উল্টো ক্রমে সাজানো! আপনার অ্যারেটি উল্টে দিতে `reverseList` ফাংশনটি ইমপ্লিমেন্ট করুন।

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. অ্যারেটি রোমাঞ্চকর কি না যাচাই করুন

আপনি সব ভাষাই ভালোবাসেন, তবে F#-এর জন্য আপনার হৃদয়ে বিশেষ একটি জায়গা আছে। তাই নিচের শর্তগুলো পূরণ হলে একটি ভাষার অ্যারে আপনার কাছে সত্যিই রোমাঞ্চকর:

- অ্যারের প্রথম ভাষাটি F#.
- অ্যারের দ্বিতীয়টি F# এবং অ্যারেটিতে দুটি বা তিনটি ভাষা আছে।

একটি ভাষার অ্যারে রোমাঞ্চকর কি না তা যাচাই করতে `excitingList` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
