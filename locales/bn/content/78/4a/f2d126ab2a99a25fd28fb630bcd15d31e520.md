# নির্দেশনা

আপনি কিছুদিন ধরে সিটি অফিসে কাজ করছেন, আর আপনার দৈনন্দিন কাজ দ্রুত করতে আপনি কিছু টুল বানিয়ে ফেলেছেন, যেমন ফর্ম পূরণের কাজে।

এখন আপনার সাথে একজন নতুন সহকর্মী যোগ দিতে যাচ্ছেন, আর আপনি বুঝতে পারলেন যে আপনার টুলগুলো হয়তো নিজে থেকেই বোঝা যাবে না। আপনার অফিসে অদ্ভুত নিয়মের অভাব নেই, যেমন সবসময় বড় হাতের অক্ষরে ফর্ম পূরণ করা আর কোনো ফিল্ড খালি না রাখা।

তাই আপনি কিছু ডকুমেন্টেশন লিখে ফেলার সিদ্ধান্ত নিলেন, যাতে আপনার নতুন সহকর্মী সহজেই কাজে নেমে পড়তে পারেন এবং আপনার টুলগুলো ব্যবহার করা শুরু করতে পারেন।

## 1. ফর্ম টুলগুলোর উদ্দেশ্য ডকুমেন্ট করা

`Form` মডিউলে ডকুমেন্টেশন যোগ করুন যা এর উদ্দেশ্য বর্ণনা করে। সেটি এরকম হবে:

```
A collection of loosely related functions helpful for filling out various forms at the city office.
```

## 2. খালি মান দিয়ে ফিল্ড পূরণ ডকুমেন্ট করা

`Form.blanks/1` ফাংশনে ডকুমেন্টেশন ও একটি টাইপস্পেক যোগ করুন। ডকুমেন্টেশনটি এরকম হবে:

```
Generates a string of a given length.

This string can be used to fill out a form field that is supposed to have no value.
Such fields cannot be left empty because a malicious third party could fill them out with false data.
```

টাইপস্পেকে বোঝানো উচিত যে ফাংশনটি একটি মাত্র আর্গুমেন্ট নেয়, একটি অঋণাত্মক ইন্টিজার, এবং একটি স্ট্রিং রিটার্ন করে।

## 3. মানগুলোকে বড় হাতের অক্ষরের অ্যারে-তে ভাগ করা ডকুমেন্ট করা

`Form.letters/1` ফাংশনে ডকুমেন্টেশন ও একটি টাইপস্পেক যোগ করুন। ডকুমেন্টেশনটি এরকম হবে:

```
Splits the string into a list of uppercase letters.

This is needed for form fields that don't offer a single input for the whole string,
but instead require splitting the string into a predefined number of single-letter inputs.
```

টাইপস্পেকে বোঝানো উচিত যে ফাংশনটি একটি মাত্র আর্গুমেন্ট নেয়, একটি স্ট্রিং, এবং স্ট্রিংয়ের একটি অ্যারে রিটার্ন করে।

## 4. সর্বোচ্চ দৈর্ঘ্যের একটি ফিল্ডে একটি মান ফিট করে কি না তা যাচাই করা ডকুমেন্ট করা

`Form.check_length/2` ফাংশনে ডকুমেন্টেশন ও একটি টাইপস্পেক যোগ করুন। ডকুমেন্টেশনটি এরকম হবে:

```
Checks if the value has no more than the maximum allowed number of letters.

This is needed to check that the values of fields do not exceed the maximum allowed length.
It also tells you by how much the value exceeds the maximum.
```

টাইপস্পেকে বোঝানো উচিত যে ফাংশনটি দুটি আর্গুমেন্ট নেয়, একটি স্ট্রিং ও একটি অঋণাত্মক ইন্টিজার, এবং দুটি সম্ভাব্য মানের একটি রিটার্ন করে। এটি হয় `:ok` অ্যাটম, নয়তো একটি ২-টাপল রিটার্ন করে, যার প্রথম এলিমেন্ট `:error` অ্যাটম আর দ্বিতীয়টি একটি ধনাত্মক ইন্টিজার।

## 5. বিভিন্ন অ্যাড্রেস ফরম্যাট ডকুমেন্ট করা

আপনার অজানা কোনো এক কারণে, সিটি অফিসের অভ্যন্তরীণ সিস্টেম অ্যাড্রেস উপস্থাপনের দুটি ভিন্ন পদ্ধতি ব্যবহার করে, হয় একটি ম্যাপ হিসেবে, নয়তো একটি টাপল হিসেবে।

তিনটি কাস্টম পাবলিক টাইপ ডিফাইন করে এই বিষয়টি ডকুমেন্ট করুন:

- `address_map` - একটি ম্যাপ, যার কী (key)গুলো হলো `:street`, `:postal_code` আর `:city`. প্রতিটি কী (key) স্ট্রিং টাইপের একটি মান ধারণ করে।
- `address_tuple` - তিনটি মানের একটি টাপল: `street`, `postal_code` আর `city`. প্রতিটি মান স্ট্রিং টাইপের। টাইপস্পেকে মানগুলোর নাম দিয়ে তাদের আলাদা করুন।
- `address` - এটি `address_map` বা `address_tuple`, যেকোনো একটি হতে পারে।

## 6. অ্যাড্রেস ফরম্যাট করা ডকুমেন্ট করা

`Form.format_address/1` ফাংশনে ডকুমেন্টেশন ও একটি টাইপস্পেক যোগ করুন। ডকুমেন্টেশনটি এরকম হবে:

```
Formats the address as an uppercase multiline string.
```

টাইপস্পেকে বোঝানো উচিত যে ফাংশনটি একটি আর্গুমেন্ট নেয়, একটি অ্যাড্রেস, এবং একটি স্ট্রিং রিটার্ন করে।
