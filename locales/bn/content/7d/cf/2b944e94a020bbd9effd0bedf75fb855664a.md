# সম্পর্কে

`[ ]`-এর ভেতরে লেখা একটি কোয়োটেশন হলো Factor-এ অ্যানোনিমাস ফাংশন বা কোড ব্লকের সমতুল্য। এটি একটি ফার্স্ট-ক্লাস মান, যা আপনি পুশ করতে, সংরক্ষণ করতে বা এদিক-ওদিক পাঠাতে পারেন, আর এটি তখনই চলে যখন কোনো কিছু এটি *কল* করে।

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

কোয়োটেশন হলো ওয়ার্ডের সিকোয়েন্স, আর কোনো আচরণকে পিছিয়ে রাখা বা প্যারামিটারাইজ করার দরকার হলে Factor সব জায়গায় এগুলো ব্যবহার করে:

- `if` / `when` / `unless` / `cond`-এর শাখা
- `filter`, `count`, `any?`, `all?`-এর প্রেডিকেট
- `map`, `each`, `reduce`-এর রূপান্তর
- `times`, `while`, `loop`-এর বডি

কোয়োটেশনের স্ট্যাক এফেক্ট সাধারণত অনুমান করা যায়। যখন তা করা যায় না, সাধারণত যখন কোয়োটেশনটি সংরক্ষণ করে পরে `call` করা হয়, তখন এফেক্টটি স্পষ্টভাবে ঘোষণা করুন: `call( a b -- c )`।

## কোয়োটেশন একত্র করা

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` দুটি কোয়োটেশনকে পরপর জোড়া লাগিয়ে একটি নতুন কোয়োটেশন তৈরি করে, যা প্রথমটি চালায়, তারপর দ্বিতীয়টি। `curry` সামনে একটি নির্দিষ্ট মান যোগ করে, আর এমন একটি কোয়োটেশন ফেরত দেয় যা মূল কোয়োটেশনটি কল করার আগে ওই মানটি পুশ করবে। দুটোই সাধারণ কোয়োটেশন তৈরি করে, যেগুলো আপনি `call` করতে, সংরক্ষণ করতে, বা কম্বিনেটরের কাছে পাঠাতে পারেন।

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
