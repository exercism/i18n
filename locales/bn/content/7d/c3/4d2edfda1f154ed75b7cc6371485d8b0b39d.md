# নির্দেশনা

RNA সিকোয়েন্সগুলোকে প্রোটিনে অনুবাদ করুন।

RNA-কে কোডন নামে পরিচিত তিনটি নিউক্লিওটাইড সিকোয়েন্সে ভাগ করা যায়, তারপর সেগুলোকে নিচের মতো একটি পলিপেপটাইডে অনুবাদ করা যায়:

RNA: `"AUGUUUUCU"` => অনুবাদ হয়

কোডন: `"AUG", "UUU", "UCU"`
=> যা থেকে নিচের সিকোয়েন্সের একটি পলিপেপটাইড তৈরি হয় =>

প্রোটিন: `"Methionine", "Phenylalanine", "Serine"`

মোট ৬৪টি কোডন আছে, আর এগুলো ২০টি অ্যামিনো অ্যাসিডের সাথে মেলে; তবে এই অনুশীলনীতে সব কোডন সিকোয়েন্স আর তাদের থেকে তৈরি অ্যামিনো অ্যাসিড গুরুত্বপূর্ণ নয়।
কোনো একটি কোডনের জন্য কাজ করলে, প্রোগ্রামটির সবার জন্য কাজ করা উচিত।
তবে, সবগুলোকে অন্তর্ভুক্ত করতে নির্দ্বিধায় টেস্ট স্যুটের তালিকাটি বাড়িয়ে নিতে পারেন।

এছাড়া তিনটি সমাপ্তিকারী কোডনও আছে (যাদের 'STOP' কোডনও বলা হয়); এই কোডনগুলোর কোনোটির সঙ্গে (রাইবোজোমের) দেখা হলে, অনুবাদ পুরোপুরি থেমে যায় এবং প্রোটিনটি সমাপ্ত হয়।

এরপরের সব কোডন উপেক্ষা করা হয়, এভাবে:

RNA: `"AUGUUUUCUUAAAUG"` =>

কোডন: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

প্রোটিন: `"Methionine", "Phenylalanine", "Serine"`

লক্ষ্য করুন, স্টপ কোডন `"UAA"` অনুবাদটি থামিয়ে দেয় এবং শেষের methionine-টি প্রোটিন সিকোয়েন্সে অনুবাদ হয় না।

নিচে এই অনুশীলনীর জন্য দরকারি কোডন ও তাদের থেকে তৈরি অ্যামিনো অ্যাসিডগুলো দেওয়া আছে।

| Codon              | Protein       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
