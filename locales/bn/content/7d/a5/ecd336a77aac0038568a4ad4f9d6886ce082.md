# ভূমিকা

## অপারেটর ওভারলোডিং

মূল গাণিতিক ও তুলনা অপারেটরগুলো আপনার নিজের ক্লাস ও স্ট্রাক্টে ব্যবহারের উপযোগী করে মানিয়ে নেওয়া যায়। একেই _অপারেটর ওভারলোডিং_ বলা হয়।

বেশিরভাগ অপারেটরের রূপ হলো:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

কাস্ট অপারেটরের রূপ হলো:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

অপারেটরগুলো স্ট্যাটিক মেথডের মতোই আচরণ করে। একটি অপারেটর চিহ্ন মেথড আইডেন্টিফায়ারের জায়গা নেয়, আর এরও প্যারামিটার ও একটি রিটার্ন টাইপ থাকে। প্যারামিটার ও রিটার্ন টাইপের টাইপ-নিয়মগুলো আপনার সহজাত বোধ অনুসরণ করে, আর বিস্তারিত নির্দেশনা পেতে আপনি কম্পাইলারের উপর নির্ভর করতে পারেন।
