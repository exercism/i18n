# নির্দেশনা

এই অনুশীলনীতে, আপনাকে ক্লাসিক গেম Pac-Man-এর কিছু নিয়ম Elixir ফাংশনে অনুবাদ করতে হবে।

আপনার হাতে অনুবাদ করার জন্য চারটি নিয়ম আছে, যেগুলোর সবই গেম স্টেটের সাথে সম্পর্কিত।

> আর্গুমেন্টগুলো কীভাবে তৈরি হচ্ছে তা নিয়ে ভাববেন না, শুধু আর্গুমেন্টগুলো একসাথে মিলিয়ে কীভাবে কাঙ্ক্ষিত ফলাফলটি রিটার্ন করা যায় সেদিকে মনোযোগ দিন।

## 1. Pac-Man একটি ভূত খায় কি না তা ডিফাইন করুন

`Rules.eat_ghost?/2` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man ভূতটি খেতে পারলে একটি বুলিয়ান মান রিটার্ন করে। ফাংশনটি কেবল তখনই ট্রু রিটার্ন করা উচিত যদি Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় থাকে এবং সে একটি ভূত স্পর্শ করছে।

```elixir
Rules.eat_ghost?(false, true)
# => false
```

## 2. Pac-Man স্কোর করে কি না তা ডিফাইন করুন

`Rules.score?/2` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man একটি পাওয়ার পেলেট স্পর্শ করছে কি না_ এবং _Pac-Man একটি ডট স্পর্শ করছে কি না_) এবং Pac-Man স্কোর করলে একটি বুলিয়ান মান রিটার্ন করে। Pac-Man একটি পাওয়ার পেলেট বা একটি ডট স্পর্শ করলে ফাংশনটি ট্রু রিটার্ন করা উচিত।

```elixir
Rules.score?(true, true)
# => true
```

## 3. Pac-Man হারে কি না তা ডিফাইন করুন

`Rules.lose?/2` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man হেরে গেলে একটি বুলিয়ান মান রিটার্ন করে। Pac-Man একটি ভূত স্পর্শ করলে এবং তার কোনো পাওয়ার পেলেট সক্রিয় না থাকলে ফাংশনটি ট্রু রিটার্ন করা উচিত।

```elixir
Rules.lose?(false, true)
# => true
```

## 4. Pac-Man জেতে কি না তা ডিফাইন করুন

`Rules.win?/3` ফাংশনটি ডিফাইন করুন, যা তিনটি আর্গুমেন্ট নেয় (_Pac-Man সব ডট খেয়ে ফেলেছে কি না_, _Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_, এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man জিতে গেলে একটি বুলিয়ান মান রিটার্ন করে। Pac-Man সব ডট খেয়ে ফেললে এবং ৩ নম্বর অংশে ডিফাইন করা আর্গুমেন্ট অনুযায়ী হারিয়ে না গেলে ফাংশনটি ট্রু রিটার্ন করা উচিত।

```elixir
Rules.win?(false, true, false)
# => false
```
