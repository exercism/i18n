# পরিচিতি

ডিফল্টভাবে ভ্যারিয়েবল যে স্কোপে ডিফাইন করা হয়, তার মধ্যেই সীমাবদ্ধ থাকে। কোনো ফাংশন বা ক্লাসের বাইরে কোনো ফাইলে ডিফাইন করা হলে সেগুলো ওই ফাইলের স্কোপে সীমাবদ্ধ থাকে। আবার কোনো ফাংশন বা ক্লাসে ডিফাইন করা হলে সেগুলো ওই ফাংশন বা ক্লাসের স্কোপে সীমাবদ্ধ থাকে।

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

এ ছাড়াও ভ্যারিয়েবলকে বিশেষভাবে `global` বা `static` স্কোপে ডিক্লেয়ার করা যায়।
