# নির্দেশনা সংযুক্তি

## বাগানের ফরম্যাট

বাগানটি একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে উপস্থাপন করা হয়, যেখানে প্রতিটি সারির শেষে একটি নিউলাইন ক্যারেক্টার থাকে।

একটি উদাহরণ হলো `"   \n * \n   \n"`

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বিবরণ |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | নাল-টার্মিনেটেড ইনপুট স্ট্রিং  |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং |
| `$t0-9`  | সাময়িক     | যেকোনো     | সাময়িক স্টোরেজের জন্য         |
