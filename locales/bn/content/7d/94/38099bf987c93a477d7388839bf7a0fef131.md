# নির্দেশাবলি

এই অনুশীলনীতে প্রোগ্রামিং ভাষার একটি অ্যারে নিয়ে কাজ করার জন্য আপনাকে কিছু মেথড ইমপ্লিমেন্ট করতে হবে।

## 1. খালি ভাষার অ্যারে রিটার্ন করার একটি মেথড ডিফাইন করুন

`LanguageList.list` মেথডটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং `Array(String)` টাইপের একটি খালি অ্যারে রিটার্ন করে।

```crystal
LanguageList.list()
# => []
```

## 2. অ্যারেতে একটি ভাষা যোগ করার একটি মেথড ডিফাইন করুন

`LanguageList.add` মেথডটি ডিফাইন করুন, যেটি ২টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_ এবং একটি _ভাষার_ স্ট্রিং লিটারাল)। মেথডটি অ্যারের শেষে নতুন ভাষাটি যোগ করে সেই অ্যারেটি রিটার্ন করবে।

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. অ্যারে থেকে একটি ভাষা মুছে ফেলার একটি মেথড ডিফাইন করুন

`LanguageList.remove` মেথডটি ডিফাইন করুন, যেটি ১টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_)। মেথডটি শেষ এলিমেন্টটি ছাড়া অ্যারেটি রিটার্ন করবে। ধরে নিন যে অ্যারেতে সবসময় অন্তত একটি এলিমেন্ট থাকবে।

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. অ্যারের n-তম এলিমেন্ট রিটার্ন করার একটি মেথড ডিফাইন করুন

`LanguageList.at` ফাংশনটি ডিফাইন করুন, যেটি ২টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_ এবং একটি ইনডেক্স)। মেথডটি অ্যারেতে n ইনডেক্সে থাকা ভাষাটি রিটার্ন করবে। ধরে নিন যে ওই ইনডেক্সে সবসময় একটি ভাষা থাকবে।

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. ভাষাগুলোর একটি স্ট্রিং পার্স করার একটি মেথড ডিফাইন করুন

`LanguageList.parse` মেথডটি ডিফাইন করুন, যেটি ১টি আর্গুমেন্ট নেয় (কমা দিয়ে আলাদা করা ভাষাগুলোর একটি স্ট্রিং লিটারাল)। মেথডটি ভাষাগুলোর একটি অ্যারে রিটার্ন করবে।

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
