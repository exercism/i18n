# অতিরিক্ত নির্দেশনা

## এক্সসেপশন মেসেজ

কখনও কখনও [এক্সসেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এমনটা করলে, এররটির উৎস কী তা বোঝাতে সবসময় একটি **অর্থবহ এরর মেসেজ** দেওয়া উচিত। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিংয়ে যথেষ্ট সাহায্য করে। যেসব ক্ষেত্রে আপনি জানেন এররের উৎস নির্দিষ্ট একটি টাইপের হবে, সেখানে [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) একটি রেইজ করতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ দেওয়া উচিত।

এই নির্দিষ্ট অনুশীলনীতে, `Queen` কনস্ট্রাক্টরে ঋণাত্মক সংখ্যা, অথবা বৈধ সারি বা কলাম নয় এমন সংখ্যা পাস করা হলে [raise স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) দিয়ে `ValueErrors` "থ্রো" করতে হবে। আপনি যদি `exception` `raise` করেন এবং তার সঙ্গে একটি মেসেজও দেন, তবেই টেস্টগুলো পাস করবে। এছাড়াও, `can_attack()` মেথডে পাস করা দুটি রানি যদি একই অবস্থানে থাকে, তাহলেও আপনার একটি `ValueError` `raise` করা উচিত।

মেসেজসহ একটি `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# if the row parameter is negative
raise ValueError("row not positive")

# if the row parameter is not on the defined board
raise ValueError("row not on board")

# if the column parameter is negative
raise ValueError("column not positive")

# if the column parameter is not on the defined board
raise ValueError("column not on board")

# if both the queens are on the same location
raise ValueError("Invalid queen position: both queens in the same square")
```
