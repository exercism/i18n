# পরিচিতি

এক্সেপশন হলো এরর হ্যান্ডলিংয়ের একটি রূপ।
এদের এক্সেপশন বলা হয়, কারণ সাধারণত কোনো অপ্রত্যাশিত ঘটনা সামলাতে গিয়েই এগুলো দেখা দেয়।

আমাদের কোডের যেকোনো জায়গায় আমরা একটি এক্সেপশন "রেইজ" করতে পারি।
এটি আমরা করি `raise` মেথড দিয়ে, একটি অবজেক্ট পাস করে, সাধারণত একটি Exception অবজেক্ট, যদিও সাধারণ স্ট্রিংও ব্যবহার করা যায়।
উদাহরণস্বরূপ, অনুশীলনীর স্টাবগুলোতে আপনি দেখবেন যে আমরা বিল্ট-ইন `RuntimeError` ব্যবহার করি Ruby-কে জানাতে যে একটি মেথড এখনো ইমপ্লিমেন্ট করা হয়নি।
আপনি `raise(ExceptionObject, params)`-এর সংক্ষিপ্ত সিনট্যাক্সও ব্যবহার করতে পারেন।
এক্সেপশন ক্লাসটি বাদ দিলে ডিফল্ট হিসেবে `RuntimeError` ব্যবহৃত হয়।
উদাহরণস্বরূপ:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Ruby এটি দেখলে এররটি প্রোগ্রামের একদম উপরে তুলে দেয় এবং তারপর প্রোগ্রামটি বন্ধ হয়ে যায়।
উদাহরণস্বরূপ, আপনি যদি কোনো কিছুকে শূন্য দিয়ে ভাগ করার চেষ্টা করেন, তাহলে এরকম কিছু দেখতে পাবেন:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
