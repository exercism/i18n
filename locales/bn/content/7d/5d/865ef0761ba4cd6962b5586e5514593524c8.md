# লিস্টের পরিচিতি

**লিস্ট** হলো Java-এর অর্ডারড সিকোয়েন্স কলেকশন।
অ্যারের মতো নয়, একটি [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) যেকোনো সংখ্যক আইটেম ধারণ করার জন্য আকারে বড় হতে পারে।
একটি স্ট্যান্ডার্ড ইমপ্লিমেন্টেশন হলো `ArrayList`, যার পিছনে একটি আকার পরিবর্তনযোগ্য অ্যারে থাকে।
আরেকটি স্ট্যান্ডার্ড ইমপ্লিমেন্টেশন হলো `LinkedList` ক্লাস, যার পিছনে থাকে একটি ডাবলি-লিংকড লিস্ট।

`List` খালি থাকতে পারে, আবার যেকোনো সংখ্যক আইটেম ধারণ করতে পারে (ডুপ্লিকেটসহ)।
`List` হলো একটি **জেনেরিক ইন্টারফেস**, যা টাইপ দিয়ে বোঝায় কোন ধরনের অবজেক্ট এটি ধারণ করতে পারে।
উদাহরণস্বরূপ:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List`-এ এলিমেন্ট যোগ করা, মুছে ফেলা, পাওয়া এবং কোনো এলিমেন্ট আছে কি না তা যাচাই করার জন্য নানা রকম সহায়ক মেথড আছে:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
