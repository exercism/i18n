# পরিচিতি

## সংখ্যা

[ম্যানুয়াল][man-types] থেকে

> jq, JSON-এর মতোই একই ধরনের ডেটা টাইপ সমর্থন করে: সংখ্যা, স্ট্রিং, বুলিয়ান, অ্যারে, অবজেক্ট (JSON-এর ভাষায় যেগুলো কেবল স্ট্রিং কী (key) সমৃদ্ধ হ্যাশ) এবং "null"।

চলুন **সংখ্যা** নিয়েই কথা বলি।

### সংখ্যা ও সংখ্যার অপারেটর

সব সংখ্যাই, ইন্টিজার হোক বা অন্য কিছু, IEEE754 ডাবল প্রেসিশন ফ্লোটিং পয়েন্ট সংখ্যা।
এতে আমাদের নির্ভুলতা ৫৩ বিটে সীমাবদ্ধ হয়ে পড়ে।

সংখ্যার সাথে ব্যবহার করার জন্য স্বাভাবিক অপারেটরগুলো রয়েছে:

- পাটিগণিত: `+`, `-`, `*`, `/`, `%`
- তুলনা: `==`, `!=`, `<`, `<=`, `>=`, `>`
- সাধারণ [গাণিতিক ফাংশন][man-math]

  একটি ইনপুট নেয় এমন ফাংশনের জন্য, মানটি ফাংশনে পাইপ করুন

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  দুটি ইনপুট নেয় এমন ফাংশনের ক্ষেত্রে ফাংশনগুলো ইনপুট উপেক্ষা করবে এবং ইনপুটগুলোকে
  প্যারামিটার হিসেবে প্রত্যাশা করবে (মনে রাখবেন, প্যারামিটারগুলো সেমিকোলন দিয়ে আলাদা করা হয়)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  ফাংশন আর্গুমেন্টের বিভাজক সেমিকোলন, কমা নয়।

### `jq`-এর অন্যান্য এক্সপ্রেশন

অনুশীলনীটি সমাধান করতে হলে আপনাকে শর্তাধীন এক্সপ্রেশন সম্পর্কে জানতে হবে।

#### শর্তাধীন এক্সপ্রেশন

`jq` **শর্তাধীন এক্সপ্রেশনের** জন্য একটি [`if-then-else` এক্সপ্রেশন][if-then-else] ব্যবহার করে।
একটি _এক্সপ্রেশন_ হিসেবে এটি একটি পাইপলাইনে বসানো হয়।

এর সিনট্যাক্স হলো: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`।

`else` ক্লজটি ঐচ্ছিক।

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

অতিরিক্ত শর্তের জন্য `elif` ব্যবহার করা হয়

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
