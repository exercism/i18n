# নির্দেশনা

অজান আসন্ন একটি রোড ট্রিপের জন্য প্লেলিস্ট তৈরি করছেন। তিনি একই ট্র্যাক একবারের বেশি শুনতে চান না, কিন্তু প্লেলিস্টটি এতটাই লম্বা হয়ে গেছে যে কোন ট্র্যাকগুলো আগেই যোগ করা হয়েছে তা মনে রাখতে তাঁর সমস্যা হচ্ছে।

অজানের মিউজিক প্লেয়ারের API শুধু অ্যারে নিয়ে কাজ করতে জানে, তাই প্লেলিস্টে যোগ করার আগে কোনো ট্র্যাক আছে কি না তা `Array.indexOf()` দিয়ে যাচাই করার জন্য তিনি কিছু কোড লিখতে চেষ্টা করেন। দুঃখজনকভাবে, তাঁর প্রোগ্রামটি চালাতে অনেক বেশি সময় লাগে। তাঁর আপনার সাহায্য দরকার!

অজানকে সাহায্য করতে গিয়ে আপনি অবাক হয়ে দেখেন যে তাঁর প্লেলিস্টে _পাঁচ লক্ষ_ ট্র্যাক রয়েছে। হয়তো আপনি এমন কোনো ভিন্ন ডেটা স্ট্রাকচার জানেন, যা দিয়ে প্লেলিস্টটি আরও দক্ষতার সাথে পরিচালনা করা যাবে?

## 1. ডুপ্লিকেট ট্র্যাক সরান

`removeDuplicates` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি প্লেলিস্টকে _প্যারামিটার_ হিসেবে নেয় এবং এমন একটি নতুন প্লেলিস্ট _রিটার্ন করে_ যেখানে সব ট্র্যাক ইউনিক।

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. একটি ট্র্যাক আগেই যোগ করা হয়েছে কি না তা যাচাই করুন

`hasTrack` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি প্লেলিস্ট ও একটি ট্র্যাক _প্যারামিটার_ হিসেবে নেয় এবং একটি বুলিয়ান _রিটার্ন করে_, যা বলে দেয় প্লেলিস্টে ট্র্যাকটি আছে কি না।

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. একটি ট্র্যাক যোগ করুন

`addTrack` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি প্লেলিস্ট ও একটি ট্র্যাক _প্যারামিটার_ হিসেবে নেয় এবং ট্র্যাকটি-সহ একটি নতুন প্লেলিস্ট _রিটার্ন করে_।

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. একটি ট্র্যাক মুছে ফেলুন

`deleteTrack` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি প্লেলিস্ট ও একটি ট্র্যাক _প্যারামিটার_ হিসেবে নেয় এবং ট্র্যাকটি ছাড়া একটি নতুন প্লেলিস্ট _রিটার্ন করে_।

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. ইউনিক শিল্পীদের তালিকা করুন

`listArtists` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি প্লেলিস্টকে _প্যারামিটার_ হিসেবে নেয় এবং প্লেলিস্টে থাকা ইউনিক শিল্পীদের তালিকা _রিটার্ন করে_। মনে রাখবেন, ট্র্যাকের নামগুলো `<SONG> - <ARTIST>` আকারে লেখা থাকে।

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
