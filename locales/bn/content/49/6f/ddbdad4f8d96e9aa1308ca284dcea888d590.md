# সম্পর্কে

ফ্যাক্টর র‍্যান্ডমনেসকে একটি মাত্র জেনেরিক শব্দকে ঘিরে [`random`][random] ভোকাবুলারিতে কেন্দ্রীভূত করেছে:

```
random ( obj -- elt )
```

এটি তার আর্গুমেন্টের ভিত্তিতে ডিসপ্যাচ করে:

- একটি **ইন্টিজার** `n` `[0, n)` পরিসরে একটি র‍্যান্ডম ইন্টিজার দেয়;
- একটি **সিকোয়েন্স** একটি র‍্যান্ডম এলিমেন্ট দেয়;
- অ্যাসোস, হ্যাশ-সেট আর `uniform-distribution` টাপলও সাপোর্ট করা হয়।

এর উপরে তৈরি হয়েছে সিকোয়েন্সের দুটি হেল্পার:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` সিকোয়েন্সটি মিউটেট করে এবং সেটি রিটার্ন করে, তাই মূল ক্রমটা ধরে রাখতে চাইলে আগে `clone` করুন।

## র‍্যান্ডমনেস কোথা থেকে আসে

`random` `random-generator` ডাইনামিক ভ্যারিয়েবলে রাখা জেনারেটরটি পড়ে। ডিফল্টভাবে সেটি সিস্টেম ক্লক থেকে সিড করা একটি Mersenne Twister, তাই প্রতিটি প্রসেস আলাদা হয়। কোনো কোয়োটেশনের ব্যাপ্তিকালের জন্য আপনি ভিন্ন একটি জেনারেটর ইনস্টল করতে পারেন:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

যেহেতু `with-random` কেবল কোয়োটেশনের ডাইনামিক ব্যাপ্তির জন্য `random-generator` বাইন্ড করে, তাই এটিকে ঘিরে যে শব্দ লেখা হয় সেটিকে `inline` চিহ্নিত করা উচিত, যাতে কোয়োটেশন তার ফলাফল কলারের জন্য স্ট্যাকে রেখে যেতে পারে।

এগুলো ছাড়াও `random` অন্য ডিস্ট্রিবিউশনের জন্য `random-bits`, `random-unit`, `uniform-random` আর `normal-random` দেয়, এবং নন-রেপ্রোডিউসিবল ও ক্রিপ্টোগ্রাফিক প্রয়োজনে `system-random-generator` আর `secure-random-generator` দেয়।
