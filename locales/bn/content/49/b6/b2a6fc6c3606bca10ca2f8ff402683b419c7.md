# নির্দেশনা

এই অনুশীলনীতে আপনি একজন বন্ধুর সঙ্গে মিলে একটি সংখ্যা অনুমান করার খেলা খেলছেন। নিয়মগুলো সহজ: আপনি গোপনে `1` থেকে `100`-এর মধ্যে একটি সংখ্যা বেছে নেন, আর আপনার বন্ধু অনুমান করার চেষ্টা করে আপনি কোন সংখ্যাটি বেছে নিয়েছেন। বন্ধুকে সাহায্য করার জন্য, অনুমানটি আপনার বেছে নেওয়া সংখ্যাটির (`42`) কত কাছে হয়েছে তার ওপর নির্ভর করে আপনি ভিন্ন ভিন্ন উত্তর দেন। বিভিন্ন উত্তরের নিয়মগুলো এই রকম:

- অনুমানটি `42` হলে: "Correct"
- অনুমানটি `41` বা `43` হলে: "So close"
- অনুমানটি `41`-এর কম হলে: "Too low"
- অনুমানটি `43`-এর বেশি হলে: "Too high"

অনুমানগুলোর উত্তর তৈরি করার জন্য আপনার সামনে চারটি কাজ আছে।

## 1. সঠিক অনুমানের উত্তর দিন

সঠিক অনুমানের উত্তর দিতে `reply` ফাংশনটি ইমপ্লিমেন্ট করুন:

```gleam
reply(42)
// -> "Correct"
```

## 2. কাছাকাছি অনুমানের উত্তর দিন

কাছাকাছি অনুমানের উত্তর দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```gleam
reply(41)
// -> "So close"
```

## 3. খুব কম অনুমানের উত্তর দিন

খুব কম অনুমানের উত্তর দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```gleam
reply(25)
// -> "Too low"
```

## 4. খুব বেশি অনুমানের উত্তর দিন

খুব বেশি অনুমানের উত্তর দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```gleam
reply(88)
// -> "Too high"
```
