# নির্দেশনা

এই অনুশীলনীতে আপনি একটি ওজন মাপার মেশিনের মডেল তৈরি করবেন।

## 1. ওজন মাপার মেশিনের জন্য একটি প্রাথমিক অবস্থা তৈরি করুন

ইনিশিয়ালাইজ করা হলে ওজন মাপার মেশিনটি তার ফ্যাক্টরি সেটিংস অনুসরণ করবে, যা মেশিনটি কোথায় বিক্রি হচ্ছে তার ভিত্তিতে আলাদা হয়।
তাই মেশিনটি একটি প্রিসিশন এবং এটি মেট্রিক না ইম্পেরিয়াল, তা দিয়ে ইনিশিয়ালাইজ করা যাবে।

`WeighingMachine#initialize` মেথডটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: `precision`, যা একটি `Int32`, এবং `metric`, যা একটি `Bool`।
`metric` আর্গুমেন্টটি যখন `true`, তার অর্থ মেশিনটি মেট্রিক সিস্টেম ব্যবহার করবে, অন্যথায় এটি ইম্পেরিয়াল সিস্টেম ব্যবহার করবে।
এছাড়াও ইনিশিয়ালাইজ মেথডে ইনস্ট্যান্স ভ্যারিয়েবল `@weight`-এর মান `0.0` সেট করতে হবে।

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. ওজন মাপার মেশিনে প্রিসিশন রাখার সুযোগ দিন

বিভিন্ন চাহিদা মেটাতে, আমরা প্রতিটি ওজন মাপার মেশিনকে একটি প্রিসিশন দিয়ে কাস্টমাইজ করার সুযোগ দিই (দশমিক বিন্দুর পরে অঙ্কের সংখ্যা)।

ওজন মাপার মেশিনের প্রিসিশন রিটার্ন করার জন্য `WeighingMachine#precision` গেটার মেথডটি ইমপ্লিমেন্ট করুন।

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. ওজন মাপার মেশিনে ওজন সেট করার সুযোগ দিন

ওজন গেট _এবং_ সেট করার সুযোগ দিতে `WeighingMachine#weight` প্রপার্টিটি ইমপ্লিমেন্ট করুন:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. মেশিনকে মেট্রিক ও ইম্পেরিয়াল এককের মধ্যে বদলানোর সুযোগ দিন

একক সেট করার সুযোগ দিতে `WeighingMachine#metric=` প্রপার্টিটি ইমপ্লিমেন্ট করুন।
এটি একটি বুলিয়ান মান গ্রহণ করবে।

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
