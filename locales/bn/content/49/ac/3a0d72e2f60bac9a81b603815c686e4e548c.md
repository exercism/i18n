# পরিচিতি

## ফাংশন

আপনার প্রয়োজনমতো লজিক গুছিয়ে রাখতে আপনি `jq`-তে নিজের **কাস্টম ফাংশন** ডিফাইন করতে পারেন।
_ফাংশনগুলো_ বিল্ট-ইনের মতোই কাজ করে: এরা একটি ইনপুট নেয় এবং শূন্য, এক বা একাধিক আউটপুট দেয়।

### একটি ফাংশন ডিফাইন করা

নিচের সিনট্যাক্স ব্যবহার করে আপনি একটি `jq` _ফাংশন_ ডিফাইন করতে পারেন:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- শুরু হয় `def` কিওয়ার্ড দিয়ে,
- ফাংশনের বডির আগে একটি কোলন থাকে,
- বডি একটি মাত্র এক্সপ্রেশন নিয়ে গঠিত,
- শেষ হয় একটি সেমিকোলন দিয়ে,
- `jq`-এর বাকি সিনট্যাক্সের মতোই, পড়তে সুবিধার জন্য আপনি খুশিমতো হোয়াইটস্পেস ব্যবহার করতে পারেন।

### ফাংশন কোথায় রাখবেন

_ফাংশন_ ব্যবহারের আগেই ডিফাইন করতে হবে: এটা একটি এরর:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

এর মানে হলো, আপনার `jq` কোডের শুরুতে, "মূল" এক্সপ্রেশনের আগে _ফাংশনগুলো_ রাখতে হবে।

#### নেস্টেড ফাংশন

_ফাংশন_ নেস্টেড হতে পারে:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

এখানে `B` _ফাংশনটি_ শুধু `A`-এর বডিতেই দৃশ্যমান।

### স্কোপ

একটি _ফাংশন_ ভ্যারিয়েবল ও নেস্টেড ফাংশনের জন্য একটি নতুন **স্কোপ** তৈরি করে।

### আর্গুমেন্ট

_ফাংশনের_ **আর্গুমেন্টগুলো** আলাদা করা হয় _সেমিকোলন_ দিয়ে, কমা দিয়ে নয়।
উদাহরণস্বরূপ, এমন একটি _ফাংশন_, যা একটি সংখ্যা নেয়, তারপর একটি সংখ্যা যোগ করে এবং একটি সংখ্যা দিয়ে গুণ করে:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

10 | add_mul(5, 4)

#### আর্গুমেন্ট হলো _এক্সপ্রেশন_

ফাংশনের _আর্গুমেন্ট_ হলো ফিল্টার, মান নয়।
এই অর্থে, অন্য ভাষায় যাকে কলব্যাক বলা হয়, এরা তেমনই কাজ করে:

উদাহরণ হিসেবে `add_mul` ফাংশনটি নিই:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

এখানে কী ঘটছে?

- `adder` আর্গুমেন্টটি পায় _এক্সপ্রেশন_ `. + 5`
  - ফাংশনটি যখন `. + adder` করে, তখন তা হয়ে যায় `. + . + 5`
  - `. == 10` হওয়ায় তা ২৫-এ মূল্যায়িত হয়
- একইভাবে, `multiplier` আর্গুমেন্টটি হলো এক্সপ্রেশন `. - 2`
  - তা ৮-এ মূল্যায়িত হয়
  - তারপর ফলাফল হয় `25 * 8 == 200`

#### মান হিসেবে আর্গুমেন্ট

কখনও কখনও আপনি একটি _আর্গুমেন্টকে_ ভ্যারিয়েবলে "মূর্ত" করতে চাইবেন:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

এর একটি সংক্ষিপ্ত রূপ আছে:

```jq
def my_func($arg):
    other stuff ...
;
```

মনে রাখবেন, এটি শুধুই "সিনট্যাক্টিক সুগার": `$` ছাড়া `arg` নামটি _ফাংশনের_ ভেতরে তখনও স্কোপে থাকে।

### আরিটি

_ফাংশনের_ একটি **আরিটি** থাকে, অর্থাৎ তারা যতগুলো _আর্গুমেন্ট_ নেয়।

_ফাংশনগুলো_ একই নাম ভিন্ন _আরিটিতে_ ব্যবহার করতে পারে।
বিল্ট-ইন [`range`][man-range] ফাংশনটি এর উদাহরণ: `range/1`, `range/2` ও `range/3` সবই একসাথে থাকতে পারে।

আর্গুমেন্টের মাধ্যমে স্টেট বহন করে এমন রিকার্সিভ ফাংশন ডিফাইনে এটি কাজে লাগতে পারে।
উদাহরণস্বরূপ `map`-কে এভাবে বাস্তবায়ন করা _যেত_:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

### রিকার্সন

`jq` টেলকল অপটিমাইজেশন করে, তবে শুধু ০-আরিটির ফাংশনের জন্য।

### মডিউল

একটি `jq` মডিউল হলো এমন একটি ফাইল, যাতে শুধু ফাংশন থাকে।
মডিউলগুলো [`include`][man-include] বা [`import`][man-import] কমান্ডের মাধ্যমে একটি jq প্রোগ্রামে যুক্ত করা হয়।
