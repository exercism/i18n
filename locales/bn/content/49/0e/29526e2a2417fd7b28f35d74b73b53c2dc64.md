# টেমপ্লেটেড স্ট্রিং ব্যবহার করুন

স্ট্রিং কনক্যাটেনেশন দিয়ে নিজে হাতে স্ট্রিং তৈরি করার বদলে ডাইনামিক মান ইন্টারপোলেট করতে [টেমপ্লেটেড স্ট্রিং](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals) ব্যবহার করুন:

```javascript
"Hello there \${firstName}, I will give you \${calculateInventory()} apples."
```
