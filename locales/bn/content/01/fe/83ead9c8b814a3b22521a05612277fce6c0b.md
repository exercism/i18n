# ফাংশন

Cairo-তে ফাংশন মৌলিক একটি বিষয়।

রীতি অনুযায়ী, Cairo-তে ফাংশন ও ভ্যারিয়েবলের নামের জন্য **স্নেক কেস** ব্যবহার করা হয়, যেখানে শব্দগুলো ছোট হাতের অক্ষরে লেখা হয় এবং আন্ডারস্কোর দিয়ে আলাদা করা হয়।

এখানে একটি উদাহরণ:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

ফাংশন ডিফাইন করা হয় `fn` দিয়ে, তারপর থাকে একটি নাম, প্যারামিটারের জন্য প্রথম বন্ধনী (যদি থাকে), আর দ্বিতীয় বন্ধনীর ভেতরে ঘেরা একটি বডি।

ফাংশনের নামের পরে বন্ধনী বসিয়ে আপনি ফাংশনটি কল করতে পারেন।

ফাংশনগুলোর ক্রম গুরুত্বপূর্ণ নয়, যতক্ষণ সেগুলো স্কোপের মধ্যে থাকে।

## প্যারামিটার

ফাংশন **প্যারামিটার** নিতে পারে, যেগুলো ফাংশনের সিগনেচারে ডিফাইন করা ভ্যারিয়েবল।

ফাংশনটি কল করার সময় আপনি **আর্গুমেন্ট** দেন, যেগুলো এই প্যারামিটারগুলোর কাছে পাঠানো মান।

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

এখানে `x` হলো `felt252` টাইপের একটি প্যারামিটার।

`5` দিয়ে কল করলে ফাংশনটি প্রিন্ট করে "The value of x is: 5".

একাধিক প্যারামিটার কমা দিয়ে আলাদা করা হয়:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

এটি প্রিন্ট করে: `The measurement is: 5h`.

## স্টেটমেন্ট ও এক্সপ্রেশন

Cairo ফাংশন তৈরি হয় **স্টেটমেন্ট** আর **এক্সপ্রেশন** দিয়ে:

- **স্টেটমেন্ট** কাজ করে কিন্তু কোনো মান রিটার্ন করে না।
যেমন, `let x = 3;` একটি স্টেটমেন্ট।
- **এক্সপ্রেশন** থেকে একটি মান পাওয়া যায়।
যেমন, `5 + 6` এর মান `11`।

দ্বিতীয় বন্ধনীর ভেতরে ঘেরা ব্লকও এক্সপ্রেশন, আর তাদের শেষ মানটিই রিটার্ন করা হয়:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

এখানে `y`-কে `4` মানটি অ্যাসাইন করা হয়।

## রিটার্ন ভ্যালু

ফাংশন `->` সিনট্যাক্স ব্যবহার করে মান রিটার্ন করতে পারে, যা দিয়ে রিটার্ন টাইপ নির্দিষ্ট করা হয়।

ডিফল্টভাবে, একটি ফাংশন তার শেষ এক্সপ্রেশনের মান রিটার্ন করে:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

এটি আউটপুট দেয়: `The value of x is: 5`.

আরও জটিল ক্ষেত্রে:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

এটি প্রিন্ট করে: `The value of x is: 6`.

খেয়াল রাখবেন, শেষ এক্সপ্রেশনের শেষে যেন সেমিকোলন না বসিয়ে দেন, কারণ তাতে এক্সপ্রেশনটি একটি স্টেটমেন্টে পরিণত হবে এবং ফাংশনটি প্রত্যাশিত মানের বদলে `()` (ইউনিট টাইপ) রিটার্ন করবে।
