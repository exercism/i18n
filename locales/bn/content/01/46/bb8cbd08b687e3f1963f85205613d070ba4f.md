# ভূমিকা

কন্ডিশনাল হলো এমন স্টেটমেন্ট, যা কোনো শর্ত `true` না `false`, তার উপর নির্ভর করে আলাদা আলাদা কোড চালায়।

একটি `if` স্টেটমেন্ট তার বডি চালায় কেবল তখনই, যখন তার শর্ত `true` হয়।
Go-তে ট্রুথি বা ফালসি মানের কোনো ধারণা নেই, তাই শর্তটি অবশ্যই `bool` টাইপের হতে হবে।
`if mySlice { ... }` বা `if 1 { ... }`-এর মতো এক্সপ্রেশন কম্পাইল এরর তৈরি করে।

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

অতিরিক্ত শর্ত যাচাই করতে `else if` ব্যবহার করুন, আর কোনোটি মিলে না গেলে ফলব্যাক হিসেবে `else` ব্যবহার করুন।
শর্তগুলো উপর থেকে নিচে মূল্যায়ন করা হয়, এবং কেবল প্রথম শাখাটিই চলবে, যার শর্ত ট্রু।

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

একটি `if` স্টেটমেন্টে একটি ছোট ইনিশিয়ালাইজেশন স্টেটমেন্টও থাকতে পারে।
এভাবে ডিক্লেয়ার করা ভ্যারিয়েবল কেবল পুরো `if`/`else` চেইনের ভেতরেই স্কোপে থাকে।

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
