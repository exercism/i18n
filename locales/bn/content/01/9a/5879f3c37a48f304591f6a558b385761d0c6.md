# ভূমিকা

Elixir-এ ডকুমেন্টেশন প্রথম শ্রেণির নাগরিক।

আপনার কোড ডকুমেন্ট করার জন্য সাধারণত দুটি মডিউল অ্যাট্রিবিউট ব্যবহার করা হয়: মডিউল ডকুমেন্ট করার জন্য `@moduledoc`, আর অ্যাট্রিবিউটটির পরে থাকা ফাংশন ডকুমেন্ট করার জন্য `@doc`। `@moduledoc` অ্যাট্রিবিউট সাধারণত মডিউলের প্রথম লাইনে থাকে, আর `@doc` অ্যাট্রিবিউট সাধারণত ফাংশন ডেফিনিশনের ঠিক আগে থাকে, ফাংশনটির টাইপস্পেক থাকলে তার আগে। ডকুমেন্টেশন সাধারণত হেরেডক সিনট্যাক্স ব্যবহার করে একটি মাল্টিলাইন স্ট্রিং-এ লেখা হয়।

Elixir-এর ডকুমেন্টেশন লেখা হয় [**Markdown**][markdown]-এ।

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
