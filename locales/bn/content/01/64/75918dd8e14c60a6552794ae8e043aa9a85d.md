# পরিচিতি

## ক্যারেক্টার

### ক্যারেক্টার

Java-এর `char` প্রিমিটিভ টাইপ হলো একটি একক ক্যারেক্টারের ১৬ বিটের উপস্থাপনা।
একাধিক `char` মিলে একটি স্ট্রিং তৈরি হতে পারে, যেমন `"word"`, আবার `char`-গুলোকে আলাদাভাবে প্রসেসও করা যায়।
একটি `char` লিটারেলকে একক উদ্ধৃতি চিহ্ন দিয়ে ঘিরে লেখা হয় (যেমন `'A'`)।

```java
char lowerA = 'a';
char upperB = 'B';
```

### একটি `String`-এর `char`-গুলো পাওয়া

`String.toCharArray` মেথডটি একটি স্ট্রিংয়ের ক্যারেক্টারগুলো অ্যারে হিসেবে রিটার্ন করে।
অ্যারে নিয়ে আগের আলোচনায় যেমন বলা হয়েছে, আপনি অ্যারের উপর একটি `for` লুপ চালিয়ে ইটারেশন করতে পারেন।

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### Character ক্লাস

`char` পরীক্ষা করতে ও ম্যানিপুলেট করতে লাইব্রেরিতে অনেক বিল্ট-ইন মেথড আছে।
এগুলো `java.lang.Character` ক্লাসের স্ট্যাটিক মেথড হিসেবে পাওয়া যায়।
এখানে কিছু উদাহরণ দেওয়া হলো:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### একটি `String`-এ `char` যোগ করা

একটি `String`-এ `char` যোগ করতে `+` অপারেটর ব্যবহার করা যায়।

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
দুটি `char` জোড়া লাগিয়ে একটি `String` বানাতে `+` ব্যবহার করবেন _না_, এদিকে খেয়াল রাখুন!
এভাবে দুটি `char` যোগ করলে পাওয়া যায় একটি `int`, `String` _নয়_!
যেমন:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

এর কারণ, Java `char`-কে `int`-এ প্রমোট করে ([Java Language Specification][jls-main]-এর [4.2 Primitive Types and Values ][jls-primitives] দেখুন)।

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

তবে অনেক ক্যারেক্টার যোগ করতে হলে, বদলে একটি `StringBuilder` ব্যবহার করা আরও দক্ষ হতে পারে:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
