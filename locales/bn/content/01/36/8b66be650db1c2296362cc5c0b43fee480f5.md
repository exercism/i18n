# Debug

ব্যর্থ হওয়া টেস্টে মেসেজ যুক্ত করতে আপনি [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) ব্যবহার করতে পারেন, এভাবে:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

ব্যর্থ হওয়া একটি টেস্টে যুক্ত হওয়া লগটি হবে `secondsInOneHour: 3600`।

তবে একটি বিষয় খেয়াল রাখতে হবে: টেস্ট চালু হওয়ার আগে টপ-লেভেল কনস্ট্যান্ট কেবল একবারই ইভ্যালুয়েট হয়, তাই টেস্টগুলো তাদের লগ মেসেজ ধরতে পারে না। যেমন:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

টেস্ট চলার সময় এটি কোনো কিছু লগ করবে না, কারণ `secondsInOneHour`-এর সাথে যুক্ত JavaScript ভ্যারিয়েবলটি আগেই 3600 মানে ইভ্যালুয়েট হয়ে গেছে।
