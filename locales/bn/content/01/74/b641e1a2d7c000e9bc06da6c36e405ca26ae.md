# টেইল কল রিকার্সন ব্যবহার করুন

এই অনুশীলনীর উদ্দেশ্য হলো টেইল কল রিকার্সন শেখানো। টেইল-রিকার্সিভ নয় এমন রিকার্সিভ ফাংশন ব্যবহার না করে এটি সমাধান করুন।

আপনার সমাধানে পাওয়া টেইল-রিকার্সিভ ফাংশন: %{tail_call_recursive_functions}। আপনার সমাধানে পাওয়া অন্যান্য রিকার্সিভ ফাংশন: %{non_tail_call_recursive_functions}।

মনে রাখবেন, ফাংশনটির মূল্যায়ন করা _শেষ_ এক্সপ্রেশনটি যখন নিজেকেই কল করা হয়, তখন টেইল কল রিকার্সন ঘটে।

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
