# নির্দেশনার সংযোজন

## আউটপুট ফরম্যাট

গানের কথাগুলো একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে আউটপুট করুন।

## রেজিস্টার

| Register | Usage        | Type    | Description                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | ইনপুট        | ইন্টিজার | শুরুর স্তবক                   |
| `$a1`    | ইনপুট        | ইন্টিজার | শেষের স্তবক                   |
| `$a2`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং |
| `$t0-9`  | সাময়িক      | যেকোনো  | সাময়িক স্টোরেজের জন্য        |
