# সম্পর্কে

একটি ইন্টারফেসকে ক্লাসের সিগনেচার হিসেবে বোঝা যায়, কারণ এটি একটি ক্লাসের public ফিল্ডগুলো বর্ণনা করে। একটি ক্লাস `implments` কিওয়ার্ড দিয়ে একটি `interface` _ইমপ্লিমেন্ট_ করে।

এর সিনট্যাক্স একটি ক্লাসের সিনট্যাক্সের সাথে খুবই মিল, শুধু পার্থক্য হলো মেথডগুলো বডি ছাড়া সিগনেচার হিসেবে থাকে:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

একটি ইন্টারফেস থেকে ইমপ্লিমেন্ট করা ফিল্ডগুলোকে **অবশ্যই** সবসময় একই ভিজিবিলিটি মডিফায়ার ব্যবহার করতে হবে। উদাহরণস্বরূপ, কোনো ইন্টারফেসে ভ্যারিয়েবল `a` যদি `public` হয়, তবে তার ইমপ্লিমেন্টেশনও অবশ্যই `public` হতে হবে।
