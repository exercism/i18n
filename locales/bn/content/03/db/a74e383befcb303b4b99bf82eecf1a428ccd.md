# ভূমিকা

এনিউমারেবলগুলোর (অ্যারে, বিটস্ট্রিং, স্ট্রিং) মধ্য দিয়ে [রিকার্সন করার][exercism-recursion] সময় প্রায়ই দুটি দিক খেয়াল রাখতে হয়:

- রিকার্সিভ ফাংশন কলের ধারা সংরক্ষণ করতে কত মেমরি লাগে
- কীভাবে দক্ষতার সাথে সমাধানটি তৈরি করা যায়

এই দিকগুলো সামলাতে একটি _অ্যাকুমুলেটর_ ব্যবহার করা যেতে পারে।

অ্যাকুমুলেটর এমন একটি ভ্যারিয়েবল, যা ডেটার পাশাপাশি অতিরিক্ত হিসেবে পাঠানো হয়। ফাংশনের এক্সিকিউশনের বর্তমান অবস্থা এক ফাংশন কল থেকে আরেক ফাংশন কলে পাঠাতে এটি ব্যবহার করা হয়, যতক্ষণ না _বেস কেস_-এ পৌঁছানো যায়। বেস কেসে অ্যাকুমুলেটর দিয়ে রিকার্সিভ ফাংশন কলের চূড়ান্ত মান রিটার্ন করা হয়।

অ্যাকুমুলেটর ইনিশিয়ালাইজ করা উচিত ফাংশনের লেখকের, ফাংশন ব্যবহারকারীর নয়। এটি করতে দুটি ফাংশন ডিক্লেয়ার করুন: একটি পাবলিক ফাংশন, যা শুধু প্রয়োজনীয় ডেটাকে আর্গুমেন্ট হিসেবে নেয় এবং অ্যাকুমুলেটর ইনিশিয়ালাইজ করে; আর একটি প্রাইভেট ফাংশন, যা অ্যাকুমুলেটরও নেয়। Elixir-এ প্রাইভেট ফাংশনের নামের শুরুতে `do_` বসানো একটি কমন প্যাটার্ন।

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

অ্যাকুমুলেটর ব্যবহার করলে রিকার্সিভ ফাংশনকে _টেইল-রিকার্সিভ_ ফাংশনে রূপান্তর করা যায়। একটি ফাংশন টেইল-রিকার্সিভ হয় যদি ফাংশনটির _শেষ_ কাজটি হয় নিজেকে কল করা।
