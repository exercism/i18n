# রেঞ্জ

[রেঞ্জ][range] বলতে দুটি মানের মধ্যবর্তী একটি ব্যবধান বোঝায়।
রেঞ্জ সমর্থন করে এমন সবচেয়ে কমন টাইপগুলো হলো `Int`, `Char` ও `String`।
এগুলো নানা কাজে লাগে, যেমন দ্রুত একটি কালেকশন তৈরি করা, স্ট্রিং স্লাইস করা, একটি মান রেঞ্জের ভেতরে আছে কি না তা যাচাই করা, আর ইটারেশন।
এগুলো `..` বা `...` রেঞ্জ অপারেটর দিয়ে তৈরি করা হয় (যথাক্রমে ইনক্লুসিভ ও এক্সক্লুসিভ)।

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

দুটি রেঞ্জ অপারেটর থাকার কারণ হলো এমন রেঞ্জ তৈরি করা যা শেষ মানটিকে অন্তর্ভুক্ত করে বা বাদ দেয়, যা কাজে লাগতে পারে, উদাহরণস্বরূপ, জিরো-বেসড ইনডেক্স নিয়ে কাজ করার সময়।

`Range` ইনিশিয়ালাইজার দিয়েও রেঞ্জ তৈরি করা যায়।

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystal-এ `..` বা `...` রেঞ্জ অপারেটর দিয়ে একটি রেঞ্জ তৈরি করে তার উপর কোনো মেথড কল করতে চাইলে, রেঞ্জটি বন্ধনীর ভেতরে রাখতে হবে।
কারণ অন্যথায় মেথডটি রেঞ্জ অপারেটরের দ্বিতীয় আর্গুমেন্টের উপর কল হয়ে যাবে।

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## সাবস্ট্রিং বের করা

কোনো স্ট্রিং স্লাইস করতে চাইলে, সাবস্ট্রিং পেতে রেঞ্জ অপারেটর ব্যবহার করতে পারেন।
অর্থাৎ, সাবস্ট্রিংয়ের শুরুর ও শেষের ইনডেক্স দিয়ে একটি রেঞ্জ তৈরি করে।

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

স্ট্রিংয়ের শেষ প্রান্ত থেকে সাবস্ট্রিং পেতে নেগেটিভ ইনডেক্সও ব্যবহার করতে পারেন।

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## রেঞ্জের মেথড

রেঞ্জের সাথে কাজ করার জন্য এর নিজস্ব কিছু মেথড আছে।
যেমন, এই মেথডগুলো দিয়ে রেঞ্জের সব মানের যোগফল পাওয়া যায় বা রেঞ্জে কোনো মান আছে কি না তা যাচাই করা যায়।

| Method                  | Description                                                             | Example                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | রেঞ্জের সব মানের যোগফল রিটার্ন করে                          | `(1..5).sum # => 15`            |
| [`size`][size]          | রেঞ্জের আকার রিটার্ন করে                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | রেঞ্জে প্রদত্ত মান থাকলে `true` রিটার্ন করে, নাহলে `false` | `(1..5).includes?(3) # => true` |

## এন্ডলেস ও বিগিনলেস রেঞ্জ

একটি রেঞ্জ এন্ডলেস ও বিগিনলেস হতে পারে।
এন্ডলেস বা বিগিনলেস রেঞ্জের শুরু বা শেষ মান `nil` হয়, তবে রেঞ্জ ডিফাইন করার সময় `nil` বাদ দেওয়া যায়।

বিগিনলেস ও এন্ডলেস রেঞ্জ কাজে লাগে যখন আপনি চান, উদাহরণস্বরূপ, একটি স্ট্রিং শুরু থেকে বা শেষ পর্যন্ত স্লাইস করতে।

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
কোনো কালেকশনে ব্যবহার না করলে, साबধানতা ছাড়া ব্যবহার করলে এন্ডলেস রেঞ্জ একটি অসীম সিকোয়েন্স তৈরি করতে পারে।
~~~~

## Char রেঞ্জ

রেঞ্জে Char ব্যবহার করা যায় এবং এটি দুটি ক্যারেক্টারের মধ্যবর্তী ক্যারেক্টারগুলোর একটি ব্যবধান পেতে দেয়।
উদাহরণস্বরূপ, আপনি যখন বর্ণমালা পেতে চান তখন এটি কাজে লাগতে পারে।

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## স্ট্রিং রেঞ্জ

স্ট্রিংও রেঞ্জে ব্যবহার করা যায়, যার ফলে দুটি স্ট্রিংয়ের মধ্যবর্তী স্ট্রিংগুলোর একটি ব্যবধান পাওয়া যায়।
কিন্তু একটি স্ট্রিং রেঞ্জে একাধিক ক্যারেক্টার ব্যবহার করলে এর আচরণ `Char`-এর থেকে কিছুটা আলাদা।
আরও জটিল স্ট্রিং রেঞ্জ নিয়ে কাজ করলে এর আচরণ বিভ্রান্তিকর হয়ে উঠতে পারে, তাই সাবধান থাকুন।

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## রেঞ্জে কাস্টম অবজেক্ট

~~~~exercism/advanced
Crystal-এ রেঞ্জে কাস্টম অবজেক্ট ব্যবহার করা যায়।
এর জন্য অবজেক্টটিকে নিচের বিষয়গুলো ইমপ্লিমেন্ট করতে হয়:

- `Comparable` মডিউল ইনক্লুড করা
- `succ` মেথড
- `<=>` মেথড

এই মেথডগুলোর ফলে রেঞ্জটি অবজেক্টের উপর ইটারেট করতে পারে এবং রেঞ্জের অবজেক্টগুলো তুলনা করতে পারে।

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
