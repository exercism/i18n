# পরিচিতি

Elm-এ একটি [`List`][lists] হলো একই টাইপের শূন্য বা তার চেয়ে বেশি মানের একটি ইমিউটেবল কালেকশন।

অ্যারে এভাবে ডিফাইন করা যায়:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

অ্যারেতে একটি এলিমেন্ট যোগ করার সবচেয়ে কমন উপায় হলো `::` (cons) অপারেটর:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

অ্যারে নিয়ে কাজ করা হয় [`List` মডিউল][list-module]-এ ডিফাইন করা ফাংশন ও অপারেটর দিয়ে, অথবা [প্যাটার্ন ম্যাচিং][list-destructuring] দিয়ে

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```

[list-module]: https://package.elm-lang.org/packages/elm/core/latest/List
