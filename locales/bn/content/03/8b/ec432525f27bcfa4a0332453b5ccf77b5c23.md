# পরিচিতি

Go-তে ফাংশন প্রথম শ্রেণির মান।
এর মানে হলো, অন্য সব মানের সাথে যা যা করা যায়, ফাংশনের সাথেও ঠিক সেগুলোই করা যায়: ফাংশনকে ভ্যারিয়েবলে অ্যাসাইন করা, সেগুলোকে অন্য ফাংশনের আর্গুমেন্ট হিসেবে পাঠানো, এমনকি অন্য ফাংশন থেকে ফাংশন রিটার্ন করা।

নিচে আমরা দুটি ফাংশন তৈরি করছি, `engGreeting` আর `espGreeting`, এবং সেগুলো `greeting` ভ্যারিয়েবলে অ্যাসাইন করছি:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

ফাংশন মান শুধু ডেটা দিয়েই নয়, আচরণ দিয়েও ফাংশন প্যারামিটারাইজ করার সুযোগ দেয়।
পরের উদাহরণে আমরা `greetingFunc` প্যারামিটারটির মাধ্যমে `dialog` ফাংশনে আচরণ পাঠাচ্ছি:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

ইনিশিয়ালাইজ না করা ফাংশন টাইপের ভ্যারিয়েবলের মান `nil`।
তাই `nil` ফাংশন মান কল করলে প্যানিক হয়।

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

ফাংশন মান `nil`-এর সাথে তুলনা করা যায়।
অপ্রয়োজনীয় প্রোগ্রাম প্যানিক এড়াতে এটি কাজে লাগতে পারে।

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## ফাংশন টাইপ

Go-তে ফাংশন টাইপ থাকার কারণেই ফাংশন মান ব্যবহার করা সম্ভব।
একটি ফাংশন টাইপ বলতে এমন সব ফাংশনের সেটকে বোঝায়, যাদের প্যারামিটার টাইপের ক্রম ও রেজাল্ট টাইপের ক্রম একই।
ফাংশন টাইপের উপরে ভিত্তি করে ইউজার-ডিফাইন্ড টাইপ ডিক্লেয়ার করা যায়।
যেমন, আগের উদাহরণগুলোর `dialog` ফাংশনটি এভাবে আপডেট করা যায়:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## অ্যানোনিমাস ফাংশন

প্রথম শ্রেণির ফাংশন সাপোর্টের কারণে যে আরেকটি শক্তিশালী হাতিয়ার পাওয়া যায়, সেটি হলো অ্যানোনিমাস ফাংশন।
অ্যানোনিমাস ফাংশন ব্যবহারের জায়গাতেই ডিফাইন করা হয়, `func` কিওয়ার্ডের পরে কোনো নাম ছাড়াই।
এমন ফাংশনের কাছে যে ফাংশনের ভেতরে সেটি আছে, তার ভ্যারিয়েবলগুলো ব্যবহারের সুযোগ থাকে।

যেমন:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib` কল করলে `n1` আর `n2` ভ্যারিয়েবল ডিক্লেয়ার হয় এবং একটি অ্যানোনিমাস ফাংশন রিটার্ন হয়, যা আবার ফাংশনটি যতবার কল করা হয়, ততবারই এই ভ্যারিয়েবলগুলোর মান বদলে দেয়।
অ্যানোনিমাস ফাংশনটি N-তম বার কল করলে ০ থেকে শুরু হওয়া ফিবোনাচি অনুক্রমের N-তম সংখ্যাটি রিটার্ন করে। ভেতরের অ্যানোনিমাস ফাংশনটি বাইরের ফাংশন `fib`-এর লোকাল ভ্যারিয়েবল (`n1` আর `n2`) ব্যবহার করতে পারে।
কল থেকে কলের মধ্যে ফাংশন মান দিয়ে স্টেট ধরে রাখার এটি একটি দারুণ উপায়।
আমরা বলি, অ্যানোনিমাস ফাংশনটি `n1` আর `n2` ভ্যারিয়েবলের একটি ক্লোজার। প্রোগ্রামিংয়ে [ক্লোজার][closure] ব্যাপকভাবে ব্যবহৃত হয়, এবং অন্য ভাষাগুলোতেও এটি সমর্থিত হতে দেখতে পারেন।

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
