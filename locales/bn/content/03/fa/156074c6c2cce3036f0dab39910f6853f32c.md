# নির্দেশনা

আপনি যে কোম্পানিতে কাজ করেন, তারা তাদের কার্বন ফুটপ্রিন্ট কমাতে চায়। তাই তারা চান আপনি একটি প্রোগ্রাম লিখুন, যা দিয়ে তাদের ইলেকট্রনিকস চালাতে কতটা পাওয়ার লাগে আর কত খরচ হয় তা হিসাব করা যাবে।

## 1. বাড়তি ঘণ্টা বের করুন

আপনার নিয়োগকর্তার একটি প্রোগ্রাম আছে, যা বিভিন্ন ইলেকট্রনিকস চালাতে কত সময় লাগে তা হিসাব করে। এখন সময়টি ঘণ্টায় সংরক্ষণ করা হয়। নিয়োগকর্তা যখন ঘণ্টাগুলো যোগ করলেন, তখন দেখলেন সময়ের পরিমাণটি সঠিক হয়নি। তিনি চান আপনি সময়ের ডেটার সাথে বাড়তি ৩ ঘণ্টা যোগ করুন। ডেটাকে "পূর্ণ" দিনে (এক দিন মানে ২৪ ঘণ্টা) রূপান্তর করার পর কত "বাড়তি" ঘণ্টা থাকে, সেটিও তিনি জানতে চান। রূপান্তর করার সময়টি পূর্ণ দিনে নাও হতে পারে।

এমন একটি ফাংশন `get_extra_hours()` লিখুন, যা একটি ইন্টিজার নেয়, যেখানে ঘণ্টার সংখ্যা থাকে। ফাংশনটি এরপর উপযুক্ত "বাড়তি ঘণ্টা" সমন্বয় করবে এবং `return` করবে একটি ইন্টিজার, যা বোঝায় মোট সময় থেকে কত ঘণ্টা বাদ দিলে "পূর্ণ" দিনে সময়টি পাওয়া যাবে।

```python
>>> get_extra_hours(25)
4
```

## 2. kW মান বের করুন

আপনার নিয়োগকর্তা বিভিন্ন ইলেকট্রনিকসের পাওয়ার ব্যবহার kW-তে জানতে চান। kW মানে কিলোওয়াট; এখানে ওয়াট হলো পাওয়ারের একটি একক। এককটির নামে থাকা কিলো মেট্রিক পদ্ধতির একটি উপসর্গ, যার অর্থ ১০০০।
এক কিলোওয়াট == ১০০০ ওয়াট।

এমন একটি ফাংশন `get_kW_value()` লিখুন, যা একটি ইন্টিজার নেয়, যেখানে ওয়াটের সংখ্যা থাকে। ফাংশনটি এরপর ওয়াটকে কিলোওয়াট হিসেবে দশমিকের পর ১ ঘর পর্যন্ত রাউন্ড করে `return` করবে।

```python
>>> get_kW_value(1150)
1.2
```

## 3. kWh মান বের করুন

ইলেকট্রনিকস চালানোর খরচ হিসাব করতে হলে আপনার নিয়োগকর্তার kWh-তে পাওয়ার ব্যবহার জানা দরকার। kWh মানে কিলোওয়াট-ঘণ্টা; এখানে ঘণ্টা হলো সময়ের একটি একক।
এক কিলোওয়াট-ঘণ্টা == ১ ঘণ্টা ধরে ব্যবহৃত ১০০০ ওয়াট।
এক ঘণ্টায় ৬০ মিনিট, আর এক মিনিটে ৬০ সেকেন্ড।
এক ঘণ্টা সমান ৩৬০০ সেকেন্ড।
kWh মান হিসাব করতে হলে ওয়াটকে আগে kW-তে রূপান্তর করতে হবে, তারপর ফলাফলটিকে ৩৬০০ দিয়ে ফ্লোর-ভাগ করতে হবে।

এমন একটি ফাংশন `get_kWh_value()` লিখুন, যা একটি ইন্টিজার নেয়, যেখানে ওয়াটের সংখ্যা থাকে। ফাংশনটি এরপর কিলোওয়াট-ঘণ্টা একটি ইন্টিজার হিসেবে `return` করবে।

```python
>>> get_kWh_value(5000000)
1
```

## 4. এফিসিয়েন্সি বের করুন

ইলেকট্রনিকস ১০০% এফিসিয়েন্ট নয়। তাই আপনার নিয়োগকর্তা চান আপনি ইলেকট্রনিকসের এফিসিয়েন্সি হিসাব করুন। এফিসিয়েন্সি বের করতে হলে পাওয়ার ফ্যাক্টর (_০ থেকে ১০০-এর মধ্যে একটি ফ্লোট_) কে ১০০ দিয়ে ভাগ করতে হবে।

এমন একটি ফাংশন `get_efficiency()` লিখুন, যা একটি ফ্লোট নেয়, যেখানে পাওয়ার ফ্যাক্টর থাকে। ফাংশনটি এরপর হিসাব করা এফিসিয়েন্সি একটি ফ্লোট হিসেবে `return` করবে।

```python
>>> get_efficiency(80)
0.8
```

## 5. খরচ বের করুন

আপনার নিয়োগকর্তা ইলেকট্রনিকস চালানোর খরচ জানতে চান। ব্যবহৃত পাওয়ারকে প্রতি kWh-এর খরচ দিয়ে গুণ করলে ইলেকট্রনিকস চালানোর খরচ পাওয়া যায়। আর ব্যবহৃত পাওয়ার হলো প্রদত্ত পাওয়ারকে হিসাব করা এফিসিয়েন্সি দিয়ে ভাগ করলে যা পাওয়া যায়।

এমন একটি ফাংশন `get_cost(<watts>,<power_factor>,<price>)` লিখুন, যা একটি ইন্টিজার নেয় যেখানে ওয়াটের সংখ্যা থাকে, একটি ফ্লোট নেয় যেখানে পাওয়ার ফ্যাক্টর থাকে, এবং আরেকটি ফ্লোট নেয় যেখানে প্রতি kWh-এর খরচ থাকে। ফাংশনটি এরপর ইলেকট্রনিকস চালানোর খরচ একটি ফ্লোট হিসেবে `return` করবে।

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
