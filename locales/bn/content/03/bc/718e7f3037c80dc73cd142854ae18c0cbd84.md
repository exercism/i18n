# পরিচিতি

`Vectors` কনসেপ্টে আমরা দেখেছি যে একটি ভেক্টর শর্তসাপেক্ষ এক্সপ্রেশনে ব্যবহার করা যায়, ফলে একটি লজিক্যাল ভেক্টর পাওয়া যায়। এরপর সেটি আবার `all()` আর `any()`-এর মতো ফাংশনে ব্যবহার করা যায়।

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

এই কৌশলটি আসলে এর চেয়ে অনেক বেশি শক্তিশালী।

## ভেক্টরের সাবসেট

একটি ভেক্টরের বাছাই করা এলিমেন্ট একটি ইনডেক্স নম্বর বা ইনডেক্সের একটি ভেক্টর দিয়ে বের করে আনা যায়:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

অন্যভাবে, মূল ভেক্টরটি ফিল্টার করতে একটি লজিক্যাল ভেক্টর ব্যবহার করা যায়, যা `TRUE` মানের সাথে মেলে এমন এন্ট্রিগুলোর একটি সাবসেট ফিরিয়ে দেয়:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

সেখান থেকে শর্তসাপেক্ষ এক্সপ্রেশন দিয়ে বুলিয়ান ভেক্টর তৈরি করা মাত্র ছোট্ট এক ধাপ:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## ইনডেক্স খোঁজা

`which()` ফাংশনটি একটি বুলিয়ান আর্গুমেন্ট নেয় এবং এমন ইনডেক্সের একটি ভেক্টর ফিরিয়ে দেয় যেগুলো `TRUE` দেয়।

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## একটি এন্ট্রি আছে কি না তা যাচাই করা

আগের অংশগুলোতে কোনো একটি মানদণ্ডের সাথে মেলে এমন এন্ট্রি খোঁজার কথা ছিল।

আপনার যদি শুধু এটুকু জানার দরকার হয় যে ভেক্টরটিতে একটি নির্দিষ্ট এলিমেন্ট আছে কি না, তাহলে `%in%` অপারেটরটি ব্যবহার করা হয়।

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

এটি কার্যত নিচের কোডটির সমতুল্য, তবে অনেক বেশি সুবিধাজনক:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
