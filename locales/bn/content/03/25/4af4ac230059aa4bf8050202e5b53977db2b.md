# পরিচিতি

## মূল বিষয়

[Lua](https://lua.org) একটি সরল, তবুও শক্তিশালী, দক্ষ, হালকা ওজনের এবং এমবেড করা যায় এমন স্ক্রিপ্টিং ভাষা। ১৯৯৩ সাল থেকে ব্রাজিলের [PUC-RIO](https://www.puc-rio.br/)-তে Roberto Ierusalimschy, Waldemar Celes এবং Luiz Henrique de Figueiredo-এর দল এটি ডিজাইন, ইমপ্লিমেন্ট এবং মেইনটেইন করে আসছে।

### কমেন্ট

Lua-তে এক লাইনের কমেন্ট শুরু হয় `--` দিয়ে, আর বহু লাইনের কমেন্ট শুরু হয় `--[[` দিয়ে এবং শেষ হয় `]]` দিয়ে।

```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### ভ্যারিয়েবল

Lua-তে তিন ধরনের ভ্যারিয়েবল আছে: গ্লোবাল ভ্যারিয়েবল, লোকাল ভ্যারিয়েবল এবং টেবিল ফিল্ড। বিষয়টি সহজ রাখতে এখানে শুধু লোকাল ভ্যারিয়েবল ব্যাখ্যা করা হয়েছে। ডিফল্টভাবে সব ভ্যারিয়েবলই গ্লোবাল, তাই লোকাল ভ্যারিয়েবল ঘোষণা করার সময় কিওয়ার্ড `local` দিয়ে সেটি লোকাল বলে স্পষ্ট করে দিতে হয়।

```lua
local x
```

`=` অপারেটর ব্যবহার করে একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করা যায়।

```lua
local x = 1
```

একটি `local` ভ্যারিয়েবলের স্কোপ শুধু সেই ব্লকেই সীমাবদ্ধ যেখানে এটি ঘোষণা করা হয়েছে। একটি ব্লক হতে পারে কোনো কন্ট্রোল স্ট্রাকচারের বডি, কোনো ফাংশনের বডি, বা যে ফাইল বা স্ট্রিংয়ে ভ্যারিয়েবলটি ঘোষণা করা হয়েছে সেটি।

```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### ফাংশন

কিওয়ার্ড `function` দিয়ে একটি ফাংশন ঘোষণা করা হয় এবং ভ্যারিয়েবলের মতোই এটিও ডিফল্টভাবে গ্লোবাল। একটি ফাংশন ডেফিনিশনে থাকে একটি নাম, একগুচ্ছ প্যারামিটার এবং একটি বডি। কিওয়ার্ড `return`-এ পৌঁছালেই ফাংশনটি শেষ হয় এবং তার পরে থাকা সব মান রিটার্ন করে। আলাদা করে `return` উল্লেখ না থাকলে ফাংশনটি `nil` রিটার্ন করবে।

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### টেবিল

টেবিল হলো Lua-তে ডেটা সাজানোর একমাত্র ব্যবস্থা এবং এটি অত্যন্ত শক্তিশালী। অ্যারে, সেট, অবজেক্ট, মডিউল এবং আরও অনেক কিছু প্রকাশ করতে টেবিল ব্যবহার করা হয়। মূলত Lua-এর একটি টেবিল হলো একটি অ্যাসোসিয়েটিভ অ্যারে।

```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

এটি শুধু এক ঝলক ধারণা, যা পরের অংশের জন্য দরকার। এই বিষয়ে আমরা পরে বিস্তারিতভাবে ফিরে আসব।

### মডিউল

একটি মডিউল হলো কোডের একটি সংগ্রহ, যা একটি `.lua` সোর্স ফাইলে সংরক্ষিত থাকে। মডিউল যা কিছু এক্সপোর্ট করে, তার সবকিছু একটি টেবিলে রাখা হয় এবং ফাইলের শেষে সেই টেবিলটি রিটার্ন করা হয়। ফলে টেবিলটি মূলত এক ধরনের নেমস্পেস হিসেবে কাজ করে।

```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

এরপর সেই মডিউলটি `require` ফাংশনের মাধ্যমে অন্য একটি ফাইলে লোড করা যায়, যা টেবিলটি রিটার্ন করে।

```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

`say.hello` দেখলে আমরা ভাবতে পারি "মডিউল `say`-এর ফাংশন `hello`"। কিন্তু আমাদের `say-hello.lua` যে একটি টেবিল রিটার্ন করে, তা আমরা জানি। টেবিলের অংশটি আবার দেখলে বুঝতে পারি, Lua-তে এই এক্সপ্রেশনটির অর্থ হলো "স্ট্রিং `hello`-কে কী (key) হিসেবে ব্যবহার করে টেবিল `say`-কে ইনডেক্স করা"।

মডিউলের টেবিল রিটার্ন করা ভালো অভ্যাস হলেও, ফাংশনের মতো অন্য যেকোনো টাইপও রিটার্ন করা ঠিক তেমনই সম্ভব।

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
