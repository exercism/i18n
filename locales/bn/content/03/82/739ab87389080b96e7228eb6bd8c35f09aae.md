# নির্দেশাবলি

এলেন একটি গেম বানাচ্ছেন, যেখানে খেলোয়াড়কে এলিয়েনদের সাথে লড়াই করতে হবে।
তিনি এইমাত্র অবজেক্ট ওরিয়েন্টেড প্রোগ্রামিং (OOP) শিখেছেন এবং `classes` ব্যবহার করে তার প্রোগ্রাম কী কী সুবিধা পেতে পারে, সেটা কাজে লাগাতে আগ্রহী।

এলেনের আনন্দের সীমা নেই, কারণ আপনি তাকে সাহায্য করার প্রস্তাব দিয়েছেন এবং খেলোয়াড়কে যেসব এলিয়েনের সাথে লড়াই করতে হবে, সেগুলো প্রোগ্রাম করার দায়িত্ব তিনি আপনাকে দিয়েছেন।


## 1. `Alien` ক্লাস তৈরি করুন

এমন একটি কনস্ট্রাক্টর দিয়ে `Alien` ক্লাস ডিফাইন করুন, যা `x` ও `y` নামের দুটি `int` প্যারামিটার নেয় এবং সেগুলোকে `x_coordinate` ও `y_coordinate` মেম্বার ভ্যারিয়েবলে রেখে দেয়।
প্রতিটি এলিয়েনের স্বাস্থ্যও শুরুতে `3` থাকবে, তাই `health` মেম্বার ভ্যারিয়েবলটিও ইনিশিয়ালাইজ করতে হবে।

`health` হবে একটি private মেম্বার ভ্যারিয়েবল।
প্রোগ্রামের অন্য অংশ যাতে স্বাস্থ্যের তথ্য পড়তে পারে, সেজন্য এলেন চান একটি `public` `get_health()` মেথড থাকুক, যা একটি `int` রিটার্ন করে।

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

এখন প্রতিটি এলিয়েনের উচিত নিজের অবস্থান ও স্বাস্থ্য নিজে নিজে ট্র্যাক করতে পারা।

## 2. `hit` ফাংশন

এলেন চান `Alien` `class`-এ একটি `hit` মেথড থাকুক, যা কল করা হলে এলিয়েন অবজেক্টের স্বাস্থ্য `1` কমিয়ে দেবে।
এতে করে এলিয়েনের স্বাস্থ্য নিজে হাতে বদলাতে না গিয়ে তিনি শুধু `some_alien_instance.hit()` কল করলেই হবে।
খেয়াল রাখুন যেন স্বাস্থ্য শূন্যের নিচে নেমে না যায়।
ফাংশনটি `true` রিটার্ন করবে।
এলেন পরে শিল্ড যোগ করতে চান, তখন শিল্ড চালু থাকলে এটি `false` জানাবে।

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. `is_alive` ফাংশন

আপনি বুঝতে পারছেন, স্বাস্থ্য যদি ক্রমেই কমতে থাকে, তবে একসময় সেটি সম্ভবত `0`-তে গিয়ে ঠেকবে।
তাই একটি `is_alive` মেথড যোগ করা ভালো হবে, যা এলেন দ্রুত কল করে দেখতে পারবেন এলিয়েনটি... মানে... জীবিত আছে কি না। 😉
`some_alien_instance.is_alive()` একটি বুলিয়ান রিটার্ন করবে।

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. `teleport` ফাংশন

এলেনের গেমে এলিয়েনরা টেলিপোর্ট করতে পারে!
আপনাকে একটি `teleport` মেথড লিখতে হবে, যা `x_new` ও `y_new` মান নেয় এবং সেই অনুযায়ী এলিয়েনের স্থানাঙ্ক বদলে দেয়।
আপাতত ফাংশনটি `true` রিটার্ন করবে।
এলেন পরবর্তী লেভেলগুলোতে টেলিপোর্ট আটকানোর বোমা যোগ করতে চান, তখন ব্যর্থ টেলিপোর্টের চেষ্টার জন্য এটি `false` জানাবে।

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. `collision_detection` ফাংশন

এলিয়েনদের যদি কোনো কিছুতে আঘাত লাগতে পারে, তবে এমন সংঘর্ষ কখন ঘটতে পারে তা শনাক্ত করার ক্ষমতাও তাদের থাকা দরকার।
দুটি এলিয়েন একই স্থানাঙ্কে আছে কি না, সেটি এলেনের জানা দরকার।
`collision_detection()` ফাংশনটি আর্গুমেন্ট হিসেবে আরেকটি এলিয়েন অবজেক্ট নেয় এবং একটি `bool` রিটার্ন করে।

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
