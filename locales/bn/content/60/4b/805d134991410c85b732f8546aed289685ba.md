# সম্পর্কে

এনুমারেশন হলো একটি কালেকশনের (`Array`, `Hash`, ইত্যাদি) মধ্যে এক এক করে ঘুরে প্রতিটি অবজেক্টের উপর কোনো কাজ করার প্রক্রিয়া।

এনুমারেশন Ruby-এর একটি মূল ধারণা এবং এটি সাজানো (`sort_by`), গ্রুপ করা (`group_by`), ম্যাপ করা (`map`), রিডিউস করা (`reduce`) এবং আরও অনেক ক্ষেত্রে ব্যবহৃত হয়।
কালেকশনের মধ্য দিয়ে ইটারেশন করার স্বাভাবিক উপায় হিসেবে আপনি প্রায়শই লুপ ব্যবহার না করে এনুমারেশনই দেখতে পাবেন।

একটি অ্যারের প্রতিটি শব্দ প্রিন্ট করার জন্য একটি সহজ এনুমারেশন দেখতে এমন হবে:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

এই উদাহরণে, আমরা `Array#each` মেথড কল করেছি এবং একটি _ব্লক_ পাস করেছি, যেটি একটি প্যারামিটার (`word`) নেয় এবং সেটি প্রিন্ট করে।

আমরা এনুমারেবল মেথডগুলোও চেইন করতে পারি।
উদাহরণস্বরূপ, আমরা `each`-এর সাথে `.with_index` চেইন করতে পারি, যাতে একটি অবজেক্টের ইনডেক্স এবং তার মান দুটোই প্রিন্ট করা যায়:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

`Hash` অবজেক্ট এনুমারেট করা ঠিক `Array` অবজেক্ট এনুমারেট করার মতোই, শুধু পার্থক্য হলো ব্লকটি দুটি আর্গুমেন্ট পায়: কী (key) এবং মান:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

উপরের মেথডগুলো [`Enumerable` মডিউল][enumerable-module]-এর অংশ, যা `Array`, `Hash` এবং এনুমারেট করার ক্ষমতা প্রয়োজন এমন অন্যান্য ক্লাসের মধ্যে অন্তর্ভুক্ত।

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
