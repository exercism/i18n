# ভূমিকা

একটি [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) একটি ডিক্লারেশন সাজানোর একটি উপায় দেয়, যার মাধ্যমে মেটাডেটা যুক্ত করা যায়: একটি ক্লাস, একটি মেথড, একটি এনাম, একটি ফিল্ড, একটি প্রপার্টি অথবা যেকোনো [অন্য সমর্থিত](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) ডিক্লারেশনে।

আপনি ডিক্লারেশনের আগের লাইনে `ClassAttribute` এবং `FieldAttribute` ব্যবহার করে একটি অ্যাট্রিবিউট প্রয়োগ করতে পারেন:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

এই ডিক্লারেটিভ মেটাডেটা কেবল কোডের সাথে অতিরিক্ত সুসংগঠিত তথ্য যুক্ত করে এবং এর আচরণ পরিবর্তন করে না, তবে কোডের অন্য অংশ সেই মেটাডেটা ব্যবহার করে এর লক্ষ্যের আচরণ পরিবর্তন করতে অথবা এর কিছু কার্যকারিতা যোগ, পরিবর্তন, অপসারণ বা সীমাবদ্ধ করতে।

অনেক [পূর্বনির্ধারিত ও সংরক্ষিত অ্যাট্রিবিউট](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) রয়েছে, যেমন: `Flags`, `Obsolete`, `Conditional`, প্রত্যেকেরই একটি নির্দিষ্ট অর্থ আছে যা C# ডকুমেন্টেশনে খুঁজে পাওয়া যায়। মনে রাখবেন যে [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) এর মতো একটি অ্যাট্রিবিউটের পূর্ণ নাম প্রচলন অনুসারে `FlagsAttribute`, তবে ডিক্লারেশনে প্রয়োগ করার সময় _Attribute_ প্রত্যয়টি বাদ দেওয়া যায়।
