# পরিচিতি

## তুলনা

Go-তে সংখ্যা তুলনা করা যায় নিচের সম্পর্ক ও সমতার অপারেটরগুলো দিয়ে।

| তুলনা             | অপারেটর   |
| ------------------| --------- |
| সমান             | `==`      |
| সমান নয়          | `!=`      |
| ছোট              | `<`       |
| ছোট বা সমান       | `<=`      |
| বড়               | `>`       |
| বড় বা সমান       | `>=`      |

তুলনার ফলাফল সবসময় একটি বুলিয়ান মান, অর্থাৎ `true` অথবা `false`।

```go
a := 3

a != 4 // true
a > 5  // false
```

উপরের তুলনা অপারেটরগুলো দিয়ে স্ট্রিংও তুলনা করা যায়।
সেক্ষেত্রে অভিধানভিত্তিক ক্রম প্রয়োগ করা হয়।
যেমন:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## `if` স্টেটমেন্ট

Go-তে শর্তাধীন স্টেটমেন্টগুলো অন্য ভাষার শর্তাধীন স্টেটমেন্টের মতোই।
যেকোনো শর্তাধীন অপারেশনের অন্তর্নিহিত ডেটা টাইপ হলো `bool`, যার মান হতে পারে `true` অথবা `false`।
বিভিন্ন শর্ত যাচাই করতে শর্তাধীন স্টেটমেন্ট প্রায়ই ফ্লো কন্ট্রোলের মাধ্যম হিসেবে ব্যবহৃত হয়।

কোনো নির্দিষ্ট ক্ষেত্র যাচাই করতে একটি `if` স্টেটমেন্ট ব্যবহার করা যায়, যা অন্তর্নিহিত শর্ত `true` হলে তার কোড চালায়, এভাবে:

```go
var value string

if value == "val" {
    return "was val"
}
```

একাধিক ক্ষেত্র জড়িত পরিস্থিতিতে `else if` ও `else` স্টেটমেন্ট ব্যবহার করে অনেক `if` স্টেটমেন্ট একসাথে জুড়ে দেওয়া যায়।

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if` স্টেটমেন্টে একটি ছোট ইনিশিয়ালাইজেশন স্টেটমেন্টও থাকতে পারে, যা দিয়ে if স্টেটমেন্টের জন্য একটি বা একাধিক ভ্যারিয়েবল ইনিশিয়ালাইজ করা যায়।
যেমন:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> দ্রষ্টব্য: ইনিশিয়ালাইজেশন স্টেটমেন্টে তৈরি যেকোনো ভ্যারিয়েবল if স্টেটমেন্ট শেষ হওয়ার পর স্কোপের বাইরে চলে যায়।
