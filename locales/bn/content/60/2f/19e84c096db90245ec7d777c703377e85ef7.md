# ইঙ্গিত

## সাধারণ

- Getting Started গাইডে [এরর][errors] সম্পর্কে পড়ুন।
- ডকুমেন্টেশনে [`try`][docs-try] সম্পর্কে পড়ুন।

## 1. দলকে সতর্ক করুন

- অপারেশন ফাংশনটিকে তার এরর রেইজ করতে দিন।
- ভ্যারিয়েবলে থাকা কোনো ফাংশন কল করতে `.` অপারেটরটি ব্যবহার করুন।

## 2. এররটি র‍্যাপ করুন

- কাঙ্ক্ষিত ফলাফল রিটার্ন করতে try .. rescue ব্যবহার করুন।

## 3. বার্তাটি পৌঁছে দিন

- কাঙ্ক্ষিত ফলাফল রিটার্ন করতে try .. rescue ব্যবহার করুন।
- rescue ব্লকটি আপনাকে এররের Module নামের ওপর প্যাটার্ন ম্যাচ করতে দেয়, আর এররটি একটি ভ্যারিয়েবলে বাইন্ড করতেও দেয়।
