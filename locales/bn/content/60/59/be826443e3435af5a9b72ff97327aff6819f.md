# টেস্ট

আপনার path-এ phix বাইনারি থাকলে এই কমান্ডটি লিখুন:

```bash
p test 
```
এটি টেস্ট ফাইলটি (test.exw) রান করবে।

phix বাইনারি PATH-এ না থাকলে Windows-এ লিখুন

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## বাদ দেওয়া টেস্ট

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
ডিফল্টভাবে, test.exw ফাইলের সব টেস্ট চালানো হয়।
কোনো টেস্ট বাদ দিতে চাইলে লাইনের শুরুতে দুটি ড্যাশ (Phix-এর স্ট্যান্ডার্ড কমেন্ট মার্কার) যোগ করুন।

মনে রাখবেন, টেস্টগুলো tests.toml-এর কোনো include=false ফ্ল্যাগ মানে না; বরং Exercism সাইটের সুবিধার জন্য (যেমন ট্র্যাকের পরিসংখ্যান সংগ্রহ) বাস্তবতা প্রতিফলিত করতে সেগুলো ওই ফাইলে নিজে হাতে রক্ষণাবেক্ষণ করার দায়িত্ব test.exw-এর লেখকের। কিন্তু ট্র্যাকের নিজের মধ্যে থাকা কোনো কিছুই এগুলোর কোনো ব্যবহার করে না, বিশেষত টেস্ট জেনারেটর এবং টেস্ট রানার।
