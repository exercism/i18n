# পরিচিতি

ব্যাচ স্ক্রিপ্টিং একটি স্ক্রিপ্টিং ভাষা, যা মূলত Windows Command Prompt (cmd.exe)-এ কমান্ড রান করার জন্য ব্যবহৃত হয়। এটি ব্যবহারকারীদের একগুচ্ছ কমান্ড-লাইন নির্দেশনার মাধ্যমে কাজ স্বয়ংক্রিয় করতে, ফাইল ব্যবস্থাপনা করতে এবং সিস্টেম এনভায়রনমেন্ট নিয়ন্ত্রণ করতে দেয়।

ব্যাচ স্ক্রিপ্টিং সহজ হলেও এটি সাধারণ ফাইল অপারেশন থেকে শুরু করে আরও জটিল অটোমেশন প্রক্রিয়া পর্যন্ত বিস্তৃত কাজ সামলাতে পারে।

ব্যাচ ফাইলের এক্সটেনশন হয় `.bat` বা `.cmd`, এবং Windows কমান্ড ইন্টারপ্রেটার এগুলো সরাসরি চালাতে পারে।

ব্যাচ স্ক্রিপ্টিংয়ের নমনীয়তা এটিকে সিস্টেম অ্যাডমিনিস্ট্রেটর, ডেভেলপার এবং পাওয়ার ইউজারদের জন্য একটি শক্তিশালী টুল করে তোলে, যাঁদের নিয়মিত কাজ স্বয়ংক্রিয় করতে বা নিজস্ব কমান্ড-লাইন টুল তৈরি করতে হয়।
