# ক্লাস স্ট্যাটিক কিওয়ার্ড

PHP-তে ক্লাস হলো কোড সংগঠনের একটি একক, যা প্রায়ই কোনো বস্তু/সেবা/প্রক্রিয়ার একটি ইনস্ট্যান্স বোঝায়।
`static` এবং `self` কিওয়ার্ড ব্যবহার করে প্রোপার্টি ও মেথড সব ইনস্ট্যান্সের জন্য (বা কোনো ইনস্ট্যান্স ছাড়াই) ক্লাসের সাপেক্ষে থাকতে পারে।

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## সীমাবদ্ধতা

স্ট্যাটিক ক্লাস মেথড কেবল নিজের ক্লাসের অন্য স্ট্যাটিক প্রোপার্টি বা ক্লাস মেথড কল করতে পারে।

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
