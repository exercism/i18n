# নির্দেশনার সংযোজন

## এক্সেপশন মেসেজ

কখনও কখনও [একটি এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটি করলে আপনার সবসময় একটি **অর্থবহ এরর মেসেজ** অন্তর্ভুক্ত করা উচিত, যাতে বোঝা যায় এররটির উৎস কী। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিং করতে অনেক সাহায্য করে। যেসব ক্ষেত্রে আপনি জানেন যে এররের উৎসটি নির্দিষ্ট একটি টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ দিতে হবে।

এই নির্দিষ্ট অনুশীলনীতে `prime()` ফাংশন যখন ভুল গঠনের ইনপুট পায়, তখন একটি `ValueError` "থ্রো" করতে আপনাকে [রেইজ স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করতে হবে। যেহেতু এই অনুশীলনীতে কেবল _ধনাত্মক_ সংখ্যা নিয়ে কাজ হয়, তাই ১-এর কম যেকোনো সংখ্যাই ভুল গঠনের। টেস্টগুলো তখনই পাস করবে যখন আপনি `raise` করবেন এবং তার সঙ্গে একটি মেসেজও দেবেন।

একটি মেসেজসহ `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# when the prime function receives malformed input
raise ValueError('there is no zeroth prime')
```
