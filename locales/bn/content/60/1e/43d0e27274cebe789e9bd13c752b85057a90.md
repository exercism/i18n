# তুলনা অপারেটর

PHP-তে দশটি বিল্ট-ইন তুলনা অপারেটর আছে:

| নাম  | উদাহরণ    | ফলাফল                                             |
| ----- | ---------- | -------------------------------------------------- |
| সমান | `$a == $b` | `$a` ও `$b` টাইপ জাগলিং-এর পর সমান হলে ট্রু। |
| অভিন্ন | `$a === $b` | `$a` ও `$b` সমান এবং একই টাইপের হলে ট্রু। |
| সমান নয় | `$a != $b` | `$a` ও `$b` টাইপ জাগলিং-এর পর সমান না হলে ট্রু। |
| সমান নয় | `$a <> $b` | `$a` ও `$b` টাইপ জাগলিং-এর পর সমান না হলে ট্রু। |
| অভিন্ন নয় | `$a !== $b` | `$a` ও `$b` সমান না হলে, বা একই টাইপের না হলে ট্রু। |
| কম | `$a < $b` | `$a` যদি `$b`-এর চেয়ে কঠোরভাবে কম হয় তবে ট্রু। |
| বেশি | `$a > $b` | `$a` যদি `$b`-এর চেয়ে কঠোরভাবে বেশি হয় তবে ট্রু। |
| কম বা সমান | `$a <= $b` | `$a` যদি `$b`-এর চেয়ে কম বা সমান হয় তবে ট্রু। |
| বেশি বা সমান | `$a >= $b` | `$a` যদি `$b`-এর চেয়ে বেশি বা সমান হয় তবে ট্রু। |
| স্পেসশিপ | `$a <=> $b` | তুলনা করলে `0`-এর চেয়ে কম, `0`-এর সমান, বা `0`-এর চেয়ে বেশি একটি ইন্টিজার রিটার্ন করে। |

`equal` আর `identical`-এর মধ্যে পার্থক্য বোঝাতে PHP-তে আলাদা আলাদা সংজ্ঞা আছে।
অনেক সময় `identical`-কে `strictly equal`-ও বলা হয়।

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
