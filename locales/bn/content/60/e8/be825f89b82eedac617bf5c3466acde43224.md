# ইঙ্গিত

## সাধারণ

- পড়ার ওয়ার্ডগুলো [`io`][io]-তে থাকে; স্ট্রিং-স্ট্রিম
  কনস্ট্রাক্টরগুলো এবং `with-string-writer` থাকে
  [`io.streams.string`][io.streams.string]-এ।
- রাইটার ফ্লাশ করার কাজটিতে, লোকাল ভ্যারিয়েবল (`::` এবং `:>`)
  বডিটি পড়তে সহজ রাখে, যখন একই স্ট্রিমে দুবার হাত দিতে হয়।

## 1. সবটা শুনে নিন

- একটিমাত্র ওয়ার্ড: `stream-contents`.

## 2. মেসেজগুলো গুনুন

- `stream-lines` স্ট্রিমটিকে লাইনের একটি অ্যারেতে ভাগ করে;
  `length` সংখ্যাটি রিটার্ন করে।

## 3. শেষ কলটির প্রতিধ্বনি করুন

- উপরের মতো একই `stream-lines`, তারপর `last`, তারপর `>upper`
  (`ascii` থেকে)।

## 4. একটি মেসেজ ব্রডকাস্ট করুন

- `stream-write` মেসেজটি লেখে, `stream-flush` সেটি বাইরে
  পাঠিয়ে দেয়। রাইটারটি দুবার ব্যবহার করা হয়, তাই `::` লোকাল
  ভ্যারিয়েবল ব্যবহার করুন: `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. একটি কোয়োটেশনের আউটপুট ক্যাপচার করুন

- একটিমাত্র ওয়ার্ড: `with-string-writer`. শেষ `;`-এর পরে
  `inline` যোগ করুন, যাতে কম্পাইলার কোয়োটেশন আর্গুমেন্টটির ভেতরটা
  দেখতে পারে: `: capture ( quot -- captured ) with-string-writer ; inline`.
