# পরিচিতি

Gleam `Bool` টাইপ দিয়ে ট্রু ও ফলস মান প্রকাশ করে। এখানে মাত্র দুটি মান আছে: `True` এবং `False`। এই মানগুলো একটি ভ্যারিয়েবলে বেঁধে রাখা যায়:

```gleam
let true_variable = True
let false_variable = False
```

বুলিয়ান মান নিয়ে কাজ করতে `&&`, `||` এবং `!` অপারেটরগুলো ব্যবহার করা যায়:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&` ও `||` অপারেটর শর্ট-সার্কিট ইভালুয়েশন ব্যবহার করে, অর্থাৎ অপারেটরের ডান দিকের এক্সপ্রেশনটি কেবল দরকার হলেই ইভালুয়েট করা হয়।

প্রতিটি অপারেটরের প্রিসিডেন্স আলাদা; এখানে `!` `&&` ও `||`-এর আগে ইভালুয়েট হয়। এক্সপ্রেশনের একটি অংশ অন্যগুলোর আগে ইভালুয়েট করতে দ্বিতীয় বন্ধনী `{}` ব্যবহার করা যায়:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
