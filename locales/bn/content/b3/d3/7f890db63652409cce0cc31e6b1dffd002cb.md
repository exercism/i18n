# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নিতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার তিনটি কাজ আছে: একটি হলো আপনার লাইসেন্স নিতে হবে কি না তা নির্ধারণ করা, একটি হলো দুটি যানবাহনের মধ্যে বেছে নিতে সাহায্য করা, আর একটি হলো ব্যবহৃত যানবাহনের ন্যায্য দাম অনুমান করা।

## 1. ড্রাইভার লাইসেন্স লাগবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালানোর জন্য ড্রাইভার লাইসেন্স লাগে।
ধরে নিন শুধু `car` আর `truck` ধরনের যানবাহনের লাইসেন্স লাগে, বাকি সবকিছু লাইসেন্স ছাড়াই চালানো যায়।

`needs_license(kind)` ফাংশনটি বাস্তবায়ন করুন, যা যানবাহনের ধরন নেয় এবং ওই ধরনের যানবাহনের জন্য লাইসেন্স লাগবে কি না তা বোঝানো একটি বুলিয়ান রিটার্ন করে।

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. কেনার জন্য বিবেচনায় থাকা দুটি যানবাহনের মধ্যে বেছে নিন

আপনি হাতে থাকা যানবাহনগুলোর মধ্যে থেকে অপশনগুলো যাচাই করে দেখেন।
আপনি সেগুলো দুটি অপশনে নামিয়ে আনতে পারেন, কিন্তু চূড়ান্ত সিদ্ধান্ত নিতে আপনার সাহায্য দরকার।
সেজন্য `choose_vehicle(option1, option2)` ফাংশনটি বাস্তবায়ন করুন, যা আর্গুমেন্ট হিসেবে দুটি যানবাহন নেয় এবং অভিধানের ক্রমে যেটি আগে আসে সেটিকেই সিদ্ধান্ত হিসেবে রিটার্ন করে।

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. ব্যবহৃত যানবাহনের দামের একটি আনুমানিক হিসাব করুন

এখন যেহেতু আপনি সিদ্ধান্ত নিয়ে ফেলেছেন, আপনি নিশ্চিত হতে চান যে ডিলারশিপে আপনি ন্যায্য দামই পাচ্ছেন।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, তাই দাম নির্ভর করে যানবাহনটির বয়সের উপর।
মোটামুটি আনুমানিক হিসাবের জন্য ধরে নিন, যানবাহনটির বয়স যদি ৩ বছরের কম হয়, তবে এর দাম একেবারে নতুন অবস্থায় যে মূল দাম ছিল তার ৮০%।
আর যদি বয়স ১০ বছরের বেশি হয়, তবে দাম ৫০%।
আর যানবাহনটির বয়স যদি অন্তত ৩ বছর হয় কিন্তু ১০ বছরের বেশি না হয়, তবে দাম মূল দামের ৭০%।

`calculate_resale_price(original_price, age)` ফাংশনটি বাস্তবায়ন করুন।
এটি আর্গুমেন্ট হিসেবে মূল দাম আর যানবাহনের বয়স নেয় এবং ডিলারশিপে আনুমানিক দামটি রিটার্ন করে।

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
