# সম্পর্কে

কোনো মানের স্কোপ বলতে বোঝায় প্রোগ্রামের কোন জায়গা থেকে সেই মানটি ব্যবহার করা যাবে।

## স্কোপের চারটি ধরন: ব্লক; ফাংশন; ফাংশন প্রোটোটাইপ; ফাইল

### ব্লক স্কোপ

ব্লক স্কোপযুক্ত একটি মান কেবল যে ব্লকে এটি ডিফাইন করা হয়েছে, সেই ব্লকের ভেতর থেকেই ব্যবহার করা যায়।
ব্লক সম্পর্কে আরও জানতে [ব্লক ধারণা](../blocks/introduction.md#Introduction) দেখুন।

### ফাংশন স্কোপ

ফাংশন স্কোপ এক ধরনের বিশেষ স্কোপ, যা `goto` স্টেটমেন্টের সাথে ব্যবহৃত লেবেলের ক্ষেত্রে প্রযোজ্য।
একই ফাংশনে একই নামের দুটি লেবেল ব্যবহার করা যায় না, এমনকি ফাংশনের ভেতরে আলাদা আলাদা ব্লকে সেই লেবেলগুলো ডিফাইন করা থাকলেও।

### ফাংশন প্রোটোটাইপ স্কোপ

ফাংশন প্রোটোটাইপ স্কোপ আরেক ধরনের বিশেষ স্কোপ, যা কেবল প্রোটোটাইপের ভেতরে নাম দেওয়া প্যারামিটারগুলোর ক্ষেত্রে প্রযোজ্য (একে ডিক্লারেশনও বলা হয়, তবে মনে রাখবেন সব ডিক্লারেশনই প্রোটোটাইপ নয়)।
ফাংশন ডিক্লারেশনে প্যারামিটারের নাম সাধারণত ঐচ্ছিক।
কোনো নামের স্কোপ কেবল ডিক্লারেশনের ভেতরেই প্রাসঙ্গিক।
নিচের উদাহরণে `len` আইডেন্টিফায়ারটি ডিফাইন করা হয়েছে এবং পরে ফাংশন ডিক্লারেশনে এটিকে ব্যবহার করা হয়েছে।

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

মনে রাখবেন, একটি ডিক্লারেশনের ভেতরে একই ভ্যারিয়েবলকে বোঝানোর সময় নামগুলো মিলে যেতে হবে।
`my_func` যদি `void my_func(int len, int numbers[length]);` হিসেবে ডিক্লারেট করা হতো, তাহলে কম্পাইল এরর তৈরি হতো, যা দেখতে এমন:

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

কোনো ফাংশন ডেফিনিশনে প্যারামিটারের জন্য সেই একই নাম ব্যবহার করা বাধ্যতামূলক নয়, যা ফাংশন ডিক্লারেশনে ব্যবহৃত হয়েছিল।
উপরের উদাহরণে ডিক্লারেশনে `len` এবং ডেফিনিশনে `length` ব্যবহৃত হয়েছে, যা প্রমাণ করে `len` আইডেন্টিফায়ারটির স্কোপ কেবল ফাংশন ডিক্লারেশনের ভেতরেই সীমাবদ্ধ ছিল।

### ফাইল স্কোপ

ফাইল স্কোপযুক্ত একটি মান ফাইলের যেকোনো জায়গা থেকে ব্যবহার করা যায়।
এমন যেকোনো মান ফাংশনের বাইরে ডিফাইন করা হয়।
