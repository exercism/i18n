# নির্দেশাবলি

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা আপনার প্রিয় রান্নার বইয়ের একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করবে।

আপনার পাঁচটি কাজ থাকবে, যেগুলোর সবই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে রাখার প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

`expectedMinutesInOven` ইমিউটেবল ভ্যারিয়েবলটি ডিফাইন করুন, যেটি রিটার্ন করে লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত।
এটি এক্সপোর্ট করা আবশ্যক।
রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. ওভেনে বাকি সময় মিনিটে হিসাব করুন

`remainingMinutesInOven` প্রসিডিউরটি ইমপ্লিমেন্ট করুন, যেটি প্যারামিটার হিসেবে নেয় লাসাগনাটি এতক্ষণ কত মিনিট ওভেনে ছিল, এবং আগের কাজে পাওয়া ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে রিটার্ন করে লাসাগনাটিকে আরও কত মিনিট ওভেনে থাকতে হবে।

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTimeInMinutes` প্রসিডিউরটি ইমপ্লিমেন্ট করুন, যেটি প্যারামিটার হিসেবে নেয় আপনি লাসাগনায় কতগুলো স্তর যোগ করেছেন, এবং রিটার্ন করে লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে, এই ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`totalTimeInMinutes` প্রসিডিউরটি ইমপ্লিমেন্ট করুন, যেটি দুটি প্যারামিটার নেয়: `numberOfLayers` প্যারামিটারটি হলো আপনি লাসাগনায় যতগুলো স্তর যোগ করেছেন তার সংখ্যা, আর `actualMinutesInOven` প্যারামিটারটি হলো লাসাগনাটি যত মিনিট ধরে ওভেনে আছে সেই সংখ্যা।
প্রসিডিউরটি রিটার্ন করবে লাসাগনা রান্না করতে আপনার মোট কত মিনিট লেগেছে, যা হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
