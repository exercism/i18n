# `for` লুপ

লুপ করা প্রোগ্রামিংয়ের একটি মৌলিক ধারণা, যার সাহায্যে আপনি একটি কোড ব্লক একাধিকবার চালাতে পারেন।
Swift-এ দুই ধরনের লুপ আছে: [`for-in` লুপ][for-loops] এবং `while` লুপ।
এই অধ্যায়ে আপনি `for-in` লুপ সম্পর্কে জানবেন।

`for` লুপের সাহায্যে আপনি মানের একটি সিকোয়েন্সের উপর ইটারেশন করতে পারেন, প্রতিটি এলিমেন্ট একে একে নিয়ে সেটিকে আপনার পছন্দের একটি ভ্যারিয়েবলে বেঁধে দিতে পারেন।
Swift-এ আপনি বিভিন্ন ধরনের সিকোয়েন্সের উপর ইটারেশন করতে পারেন, যেমন রেঞ্জ, অ্যারে এবং স্ট্রিং (এবং আরও কিছু টাইপ, যা পরে আলোচনা করা হবে)।
সিকোয়েন্সের প্রতিটি এলিমেন্টের উপর ইটারেশন শেষ হলে লুপটি বন্ধ হয়ে যায়।

`for` লুপ ঘোষণা করা হয় `for` কিওয়ার্ড দিয়ে, তারপর একটি ভ্যারিয়েবলের নাম, `in` কিওয়ার্ড এবং যে মানের সিকোয়েন্সের উপর ইটারেশন করতে হবে তা লিখে।
`for-in` লুপে দেওয়া ভ্যারিয়েবলটি ইমিউটেবল, অর্থাৎ লুপের ভিতরে আপনি এর মান পরিবর্তন করতে পারবেন না।
এখানে সংখ্যার একটি অ্যারের উপর ইটারেশন করা একটি `for-in` লুপের উদাহরণ:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` ভ্যারিয়েবলটি `for-in` লুপে ঘোষণা করা হয়েছে এবং এটি কেবল লুপের স্কোপের ভিতরেই ব্যবহার করা যায়।

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## একটি রেঞ্জের উপর ইটারেশন

`for-in` লুপ ব্যবহার করে আপনি সংখ্যার একটি রেঞ্জের উপরও ইটারেশন করতে পারেন।
এর সাহায্যে আপনি একটি কোড ব্লক নির্দিষ্ট সংখ্যকবার চালাতে পারেন। উদাহরণস্বরূপ, `1...5` রেঞ্জটি 1, 2, 3, 4 এবং 5 সংখ্যাগুলোর উপর ইটারেশন করবে, তাই লুপটি 5 বার চলবে।
মাঝে মাঝে আপনি অ্যারের মতো কোনো ডেটা স্ট্রাকচারের ইনডেক্সের উপর ইটারেশন করতে চাইতে পারেন; তখন আপনি `0..<array.count` রেঞ্জটি ব্যবহার করতে পারেন।

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## একটি স্ট্রিংয়ের উপর ইটারেশন

`for-in` লুপ ব্যবহার করে আপনি একটি স্ট্রিংয়ের উপরও ইটারেশন করতে পারেন।
এর সাহায্যে আপনি স্ট্রিংয়ের প্রতিটি ক্যারেক্টারের উপর ইটারেশন করতে পারেন। খেয়াল করুন, লুপে যে টাইপটি পাওয়া যায় সেটি `Character`।

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift-এ `stride` নামের একটি ফাংশনও আছে, যার সাহায্যে আপনি নির্দিষ্ট ধাপে একটি রেঞ্জের উপর একটি সিকোয়েন্স তৈরি করতে পারেন।
এরপর `for-in` লুপ ব্যবহার করে সেই সিকোয়েন্সের উপর ইটারেশন করা যায়।
`stride`-কে সংজ্ঞায়িত করা হয়েছে [`stride(from:to:by:)`][stride-to] অথবা [`stride(from:through:by:)`][stride-through] হিসেবে; প্রথমটি এক্সক্লুসিভ এবং দ্বিতীয়টি ইনক্লুসিভ।

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

খেয়াল করুন, `to` প্যারামিটারটি এক্সক্লুসিভ, তাই লুপটি `to` প্যারামিটারের আগের সংখ্যা পর্যন্ত ইটারেশন করবে। অন্যদিকে `through` প্যারামিটারটি ইনক্লুসিভ, তাই এই ক্ষেত্রে এটি `10`-ও অন্তর্ভুক্ত করবে।

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
