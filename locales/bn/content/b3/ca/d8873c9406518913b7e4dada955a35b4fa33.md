# পরিচিতি

অন্য ভাষাগুলোর মতো Common Lisp-এও অ্যারে হলো একগুচ্ছ এলিমেন্টের সমষ্টি, যেগুলো পূর্ণসংখ্যার ইনডেক্স দিয়ে অ্যাক্সেস করা হয়।
এলিমেন্টগুলোর টাইপ ভিন্ন ভিন্ন হতে পারে।
অ্যারেটি বহুমাত্রিক হতে পারে (শুধু একমাত্রিক নয়)।

## তৈরি করা

`make-array` দিয়ে অ্যারে তৈরি করা যায়।
এতে অনেক অপশন আছে, তবে এর সহজ রূপগুলো দিয়ে N-মাত্রিক অ্যারে তৈরি করা যায়, যেখানে সব এলিমেন্ট একটি নির্দিষ্ট মানে ইনিশিয়ালাইজ করা থাকে, অথবা অ্যারেটি অন্য একটি সিকোয়েন্সের (যেমন একটি অ্যারে) মান দিয়ে ইনিশিয়ালাইজ করা হয়।
এর প্রথম আর্গুমেন্টটি হলো প্রতিটি মাত্রার আকারের একটি অ্যারে।

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(লক্ষ্য করুন, N-মাত্রিক অ্যারেগুলো মাত্রার সংখ্যা সহ প্রিন্ট হয়।)

অ্যারে তৈরি করা যায় সেগুলো যে ফরম্যাটে প্রিন্ট হয় সেই একই ফরম্যাট ব্যবহার করেও:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## এলিমেন্ট অ্যাক্সেস করা

ভেক্টরের এলিমেন্ট অ্যাক্সেস করতে `aref` ব্যবহার করুন; ইনডেক্সগুলো শূন্য থেকে শুরু হয়।
যতগুলো ইনডেক্স দেওয়া হবে, তা অ্যারের র‍্যাঙ্কের সাথে মিলতে হবে।

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
