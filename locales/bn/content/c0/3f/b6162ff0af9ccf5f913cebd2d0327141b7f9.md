# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বই থেকে একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার চারটি কাজ আছে, সবগুলোই লাসাগনা রান্না করতে ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. প্রত্যাশিত ওভেন সময় মিনিটে নির্ধারণ করুন

লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত তা যাচাই করতে `expected_minutes_in_oven` বাইন্ডিংটি নির্ধারণ করুন।
রান্নার বই অনুযায়ী, মিনিটে প্রত্যাশিত ওভেন সময় হলো ৪০:

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. ওভেনে বাকি সময় মিনিটে হিসাব করুন

`remaining_minutes_in_oven` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে লাসাগনাটি কত মিনিট ধরে ওভেনে আছে সেই প্রকৃত সময়টি নেয় এবং আগের কাজের মিনিটে প্রত্যাশিত ওভেন সময়ের ভিত্তিতে লাসাগনাটিকে আরও কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparation_time_in_minutes` ফাংশনটি ডিফাইন করুন, যা প্যারামিটার হিসেবে লাসাগনায় আপনি যতগুলো স্তর যোগ করেছেন সেই সংখ্যাটি নেয় এবং ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে, লাসাগনা প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন তা রিটার্ন করে।

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. অতিবাহিত সময় মিনিটে হিসাব করুন

`elapsed_time_in_minutes` ফাংশনটি ডিফাইন করুন, যা দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসাগনায় আপনি যতগুলো স্তর যোগ করেছেন সেই সংখ্যা, আর দ্বিতীয় প্যারামিটারটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে আছে সেই সংখ্যা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্না করতে আপনি কত মিনিট কাজ করেছেন, যা হলো মিনিটে প্রস্তুতির সময় এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
