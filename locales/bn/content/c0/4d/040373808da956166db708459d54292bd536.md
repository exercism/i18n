# ভূমিকা

`if` স্টেটমেন্টের পাশাপাশি, শর্তসাপেক্ষে লজিক কার্যকর করার জন্য `switch` স্টেটমেন্টও আছে। এটি তখন ব্যবহার করা হয় যখন একটি মাত্র ভ্যারিয়েবলকে একাধিক ভ্যারিয়েন্টের সঙ্গে তুলনা করার প্রয়োজন হয়। ধরা যাক, কোনো একটি ভ্যারিয়েবল x; Haxe-এ `switch` স্টেটমেন্টের সিনট্যাক্স নিম্নরূপ।

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

অন্য কোনো কেস মিলে না গেলে `default` কেসটি কার্যকর হয়।
