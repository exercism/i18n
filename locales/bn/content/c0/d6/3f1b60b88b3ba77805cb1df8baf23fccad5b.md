# পরিচিতি

কোনো মান প্রসেস করার সময় সমস্যায় পড়লে, যেমন একটি সংখ্যাকে স্ট্রিং দিয়ে ইনডেক্স করা, অবৈধ JSON টেক্সট পার্স করা বা ভুল ধরনের আর্গুমেন্ট দিয়ে ফাংশন কল করা, একটি `jq` প্রোগ্রাম একটি **রানটাইম এরর** তৈরি করে।
ধরা না পড়া কোনো রানটাইম এররের ফলে `jq` _স্ট্যান্ডার্ড এরর_-এ একটি মেসেজ প্রিন্ট করে এবং স্ট্যাটাস `5` নিয়ে এক্সিট করে।

## এরর তৈরি করা: `error` এবং `error(message)`

- `error` এমন একটি এরর তৈরি করে যার মান হলো **ইনপুট** মান।
- `error(message)` এমন একটি এরর তৈরি করে যার মান হলো `message`-এর ফলাফল।

এররের মান _যেকোনো_ JSON মান হতে পারে, শুধু স্ট্রিং নয়।

```jq
42 | error("invalid value: \(.)")
# => "invalid value: 42"

42 | error
(not a string): 42
```

## এরর ধরা: `try` এবং `catch`

`try EXP catch HANDLER` দিয়ে এরর ধরা যায়।
প্রথম এক্সপ্রেশনটি রান হয়; যদি এটি একটি এরর তৈরি করে, তাহলে `HANDLER` এক্সপ্রেশনটি **এররের মানকে তার ইনপুট হিসেবে নিয়ে** রান হয়।
`try catch`-এর আউটপুট হলো শেষে যে এক্সপ্রেশনটি রান করেছে (`EXP` বা `HANDLER`) তার আউটপুট।

```jq
{a: 42} | try .a catch "no index a in \(.)"
# => 42

true | try .a catch "cannot index a \(type)"
# => "cannot index a boolean"

true | try error("some exception") catch .
# => "some exception"
```

ছোট রূপ `try EXP` হলো `try EXP catch empty`-এর সমতুল্য: এররটি বাদ দেওয়া হয় এবং কোনো আউটপুট তৈরি হয় না।

```jq
[{}, true, {"a": 1}] | [.[] | try .a]
# => [null, 1]
```

## এরর দমন করা: `?` অপারেটর

`?` অপারেটরটি, যখন `EXP?` হিসেবে ব্যবহার করা হয়, তখন `try EXP`-এর সংক্ষিপ্ত রূপ।
এটি ব্যর্থ হওয়া এক্সপ্রেশনকে এমন এক্সপ্রেশনে পরিণত করে যেটি কোনো আউটপুটই তৈরি করে না।

```jq
["1", "invalid", "3", 4] | [.[] | tonumber?]
# => [1, 3, 4]
```

এটি প্রায়ই ইনডেক্সিং অপারেটরগুলোর সাথে যুক্ত অবস্থায় দেখা যায়: `.foo?` এবং `.[]?`।

## প্রোগ্রাম থামানো: `halt_error` এবং `halt`

`halt_error` প্রোগ্রামটি থামিয়ে দেয়, এর ইনপুট _স্ট্যান্ডার্ড এরর_-এ কাঁচা টেক্সট হিসেবে প্রিন্ট করে, এবং প্রদত্ত স্ট্যাটাস নিয়ে এক্সিট করে; স্ট্যাটাস দেওয়া না থাকলে ডিফল্ট `5`।
সংশ্লিষ্ট `halt` ফিল্টারটি এক্সিট স্ট্যাটাস `0` নিয়ে নিঃশব্দে প্রোগ্রামটি থামিয়ে দেয়।

```jq
"Error: something went wrong" | halt_error(1)
```
