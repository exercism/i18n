# নির্দেশাবলি

একটি ইনপুট টেক্সট দেওয়া হলে সেটির ট্রান্সপোজ আউটপুট দিন।

মোটামুটি ভাবে ব্যাখ্যা করলে, একটি ম্যাট্রিক্সের ট্রান্সপোজ:

```text
ABC
DEF
```

যেভাবে পাওয়া যায়:

```text
AD
BE
CF
```

সারি হয়ে যায় কলাম, আর কলাম হয়ে যায় সারি। দেখুন <https://en.wikipedia.org/wiki/Transpose>।

ইনপুটের সারিগুলোর দৈর্ঘ্য আলাদা আলাদা হলে, এটি নিচের নিয়মে সমাধান করতে হবে:

- বাম দিকে স্পেস দিয়ে প্যাড করুন।
- ডান দিকে প্যাড করবেন না।

তাই, এই ম্যাট্রিক্সটি ট্রান্সপোজ করলে:

```text
ABC
DE
```

ফলাফল হয়:

```text
AD
BE
C
```

আর এটি ট্রান্সপোজ করলে:

```text
AB
DEF
```

ফলাফল হয়:

```text
AD
BE
 F
```

সাধারণভাবে, ইনপুটের সব ক্যারেক্টার ট্রান্সপোজ করা আউটপুটেও থাকা উচিত। তার মানে, ইনপুট টেক্সটের কোনো কলামের একেবারে নিচের সারি বা সারিগুলোতে যদি শুধু স্পেস থাকে, তাহলে সংশ্লিষ্ট আউটপুট সারির একেবারে ডান দিকের কলাম বা কলামগুলোতে ওই স্পেসগুলো থাকা উচিত।
