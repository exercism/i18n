# শর্তাধীন স্টেটমেন্ট

Python-এ [`if`][if statement], `elif` (_'else and if'-এর সংক্ষিপ্ত রূপ_) এবং `else` স্টেটমেন্ট দিয়ে প্রোগ্রামের এক্সিকিউশনের [প্রবাহ নিয়ন্ত্রণ][control flow tools] করা হয় এবং সিদ্ধান্ত নেওয়া হয়।
অন্য অনেক প্রোগ্রামিং ভাষার বিপরীতে, Python 3.9 এবং তার নিচের সংস্করণগুলোতে আলাদা কোনো কেস-সুইচ স্টেটমেন্ট নেই; বদলে একই রকম কাজ করতে একাধিক `elif` স্টেটমেন্ট ব্যবহার করা হয়।

Python 3.10-এ `structural pattern matching` নামে কেস-সুইচ স্টেটমেন্টের একটি ভিন্ন রূপ এসেছে, যা অন্য একটি কনসেপ্টে আলাদাভাবে আলোচনা করা হবে।

শর্তাধীন স্টেটমেন্টে এমন এক্সপ্রেশন থাকে, যেগুলোর মান অবশ্যই `True` বা `False` হতে হয়: হয় সরাসরি `bool` টাইপ রিটার্ন করে, নয়তো ["ট্রুথি" বা "ফলসি"][truth value testing] হিসেবে মূল্যায়িত হয়ে।

```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

`if`-এর সাথে যুক্ত হলে, মূল `if` শর্তটি `False` হিসেবে মূল্যায়িত হলে একটি ঐচ্ছিক `else` কোড ব্লক কার্যকর হয়:

```python
x = 5
y = 10

# The comparison '>' here returns the bool 'False',
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` একাধিক মূল্যায়ন বা শাখার সুযোগ দেয়।

```python
x = 5
y = 10
z = 20

# The 'elif' statement allows for the checking of more conditions.
if x > y:
    print("x is greater than y and z")
elif y > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

আরও জটিল পরীক্ষার জন্য শর্তের সাথে [বুলিয়ান অপারেশন][boolean operations] এবং [তুলনা][comparisons] একসাথে ব্যবহার করা যায়:

```python
>>> def classic_fizzbuzz(number):
        if number % 3 == 0 and number % 5 == 0:
            say = 'FizzBuzz!'
        elif number % 5 == 0:
            say = 'Buzz!'
        elif number % 3 == 0:
            say = 'Fizz!'
        else:
            say = str(number)
        
        return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
