# পরিচিতি

## রেফারেন্স

### কপি ও রেফারেন্স

আমাদের এখনকার জ্ঞান দিয়ে একটি ফাংশনের সাহায্যে একটি ভ্যারিয়েবল আপডেট করা কিছুটা ঝামেলার কাজ। প্রতিটি ফাংশন আর্গুমেন্ট কপি হিসেবে গণ্য হয় এবং মূল মানটি বদলায় না। আপনার টাইপের আকারের উপর নির্ভর করে এটি আপনার কোডের পারফরম্যান্সে গুরুতর প্রভাব ফেলতে পারে।

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

`References`-কে অ্যালিয়াস হিসেবে দেখা যেতে পারে, এদের পরিবর্তন মূল ভ্যারিয়েবলে প্রভাব ফেলে। টাইপ ডিক্লারেশনে `References` একটি **অ্যাম্পারস্যান্ড** (`&`) ব্যবহার করে।

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```
রিসিটিং (অর্থাৎ একটি `reference`-এর বাইন্ডিং বদলানো) সম্ভব নয়। আপনি একটি আনইনিশিয়ালাইজড `reference` রাখতে পারেন না। `References`-কে একটি বিদ্যমান ভ্যারিয়েবল দিয়ে ইনিশিয়ালাইজ করতে হয়।

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is still -20

int& future_budget;
// => compiler error, reference must be bound!
```

### `void`

`references`-এর শক্তি কাজে লাগিয়ে আপনার হয়তো ফাংশন থেকে কোনো মান রিটার্ন করার দরকারই নাও পড়তে পারে। এমন ক্ষেত্রে `void`-কে রিটার্ন টাইপ হিসেবে ব্যবহার করা হয়।

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
