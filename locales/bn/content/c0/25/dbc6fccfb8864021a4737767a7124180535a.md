# Tests

## Clojure CLI

Exercism-এ Clojure অনুশীলনীগুলো একটি `deps.edn` ফাইল নিয়ে আসে, যাতে [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) চালু করার জন্য একটি `:test` অ্যালিয়াস থাকে:

``` bash
$ clj -X:test
```

এটি আপনার প্রজেক্টের `test` ডিরেক্টরি স্ক্যান করে সেখানে `clojure.test` দিয়ে ডিফাইন করা যেকোনো test খুঁজে সেগুলো রান করবে।

## Leiningen

Leiningen দিয়ে কোনো অনুশীলনীর test চালাতে, শুধু কল করুন:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
