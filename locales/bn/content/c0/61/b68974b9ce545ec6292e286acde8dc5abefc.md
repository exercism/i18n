# ভূমিকা

struct বা ক্লাসের প্রতিটি ইনস্ট্যান্সের `self` নামে একটি অন্তর্নিহিত প্রপার্টি থাকে, যা ইনস্ট্যান্সটিকেই বোঝায়।
`self`-এর সবচেয়ে কমন ব্যবহার হলো একই নামের একটি ইনস্ট্যান্স প্রপার্টি আর প্যারামিটারের মধ্যে পার্থক্য স্পষ্ট করা:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift টাইপগুলোতে বড় হাতের অক্ষরে লেখা `Self` কিওয়ার্ডটিও পাওয়া যায়, যা ইনস্ট্যান্সটির নিজের বদলে ইনস্ট্যান্সটির *টাইপকে* বোঝায়।
