# নির্দেশনা

রিমোট কন্ট্রোল কার প্রকল্পে কাজ চলছে। টেলিমেট্রি সিস্টেমে ব্যান্ডউইথ খুবই সীমিত, আর আপনাকে টেলিমেট্রি ডেটা আদান-প্রদানের জন্য একটি মেসেজ প্রোটোকল তৈরি করতে বলা হয়েছে।

ডেটা একটি বাফারে (বাইট অ্যারে) পাঠানো হয়। ইন্টিজার পাঠানোর সময় নিচে বর্ণিত প্রোটোকল ব্যবহার করে বাফারের আকার কমিয়ে আনা হয়।

প্রতিটি মানকে সম্ভব হলে সবচেয়ে ছোট ইন্টিগ্রাল টাইপে উপস্থাপন করা উচিত (`byte` ও `sbyte` টাইপ অন্তর্ভুক্ত নয়, কারণ এতে সঞ্চয় নগণ্য হবে):

| From                       | To                        | Type     |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

মানটিকে তার নির্ধারিত টাইপের জন্য উপযুক্ত সংখ্যক বাইটে রূপান্তর করতে হবে। সম্পূর্ণ বাফারে বাফারের অতিরিক্ত কতগুলি বাইট আছে তা নির্দেশ করা একটি বাইট (_prefix byte_) থাকে, তারপর ইন্টিজার ধারণ করা বাইটগুলি (_payload bytes_) থাকে।

কিছু টাইপ একই সংখ্যক বাইট ব্যবহার করে (যেমন `uint` ও `int` টাইপ)। সাধারণত তাদের _prefix byte_ একই হতো, কিন্তু তাহলে ডিকোডিং সমস্যাযুক্ত হয়ে যেত। এটি সামলাতে প্রোটোকল একটি ছোট কৌশল ব্যবহার করে: সাইনড টাইপের ক্ষেত্রে তাদের _prefix byte_-এর মান হয় বাফারের অতিরিক্ত বাইটের সংখ্যা বাদ দিয়ে `256`।

যোগাযোগে কেবল প্রিফিক্স বাইট এবং প্রিফিক্সে নির্দেশিত পরবর্তী বাইটগুলিই পাঠানো হয়। অভ্যন্তরীণভাবে পাঠানোর ও গ্রহণের রুটিন দুটোতেই একটি ৯ বাইটের বাফার ব্যবহার করা হয় (প্রয়োজনে শেষে শূন্য যুক্ত করে)।

## 1. পাঠানোর জন্য প্রস্তুত একটি ইন্টিগ্রাল মান এনকোড করুন

মেথডে পাস করা প্যারামিটারটি নিয়ে একটি বাফার এনকোড করতে অনুগ্রহ করে স্ট্যাটিক মেথড `TelemetryBuffer.ToBuffer()` ইমপ্লিমেন্ট করুন।

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. গৃহীত একটি বাফার ডিকোড করুন

গৃহীত বাফারটি ডিকোড করে একটি `long` আকারে মান রিটার্ন করতে অনুগ্রহ করে স্ট্যাটিক মেথড `TelemetryBuffer.FromBuffer()` ইমপ্লিমেন্ট করুন।

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

প্রিফিক্স বাইটের মান অপ্রত্যাশিত হলে `0` রিটার্ন করা উচিত।
