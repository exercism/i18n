# পরিচিতি

## ডিউরেশন ও পিরিয়ড

`LocalDate` ও `LocalDateTime`-এর মতো ক্লাস সময়ের একটি _বিন্দু_ বোঝায়।
`java.time` প্যাকেজে আরও দুটি ক্লাস আছে, যেগুলো সময়ের একটি _পরিমাণ_ বোঝায়:

- `java.time.Period` হলো বছর, মাস ও দিনে প্রকাশ করা সময়ের পরিমাণ, যেমন "২ মাস ও ৫ দিন"।
- `java.time.Duration` হলো ঘণ্টা, মিনিট, সেকেন্ড, মিলিসেকেন্ড ও ন্যানোসেকেন্ডে প্রকাশ করা সময়ের পরিমাণ, যেমন "১ ঘণ্টা ও ৩০ মিনিট"।

একটি `Period` ক্যালেন্ডার অনুসরণ করে, তাই এটি তারিখ ও ডেট-টাইমের সঙ্গে ব্যবহার করা হয়।
একটি `Duration` সঠিক সময় পরিমাপ করে, তাই এটি সময় ও ডেট-টাইমের সঙ্গে ব্যবহার করা হয়, কিন্তু তারিখের সঙ্গে নয়।

```exercism/note
`java.time`-এর অন্যান্য ক্লাসের মতো `Period` ও `Duration`-ও ইমিউটেবল।
যেসব মেথড দেখে মনে হয় সেগুলো এদের বদলে দিচ্ছে, তারা আসলে একটি _নতুন_ ইনস্ট্যান্স রিটার্ন করে।
```

### `Period`

`Period` তৈরি করা হয় এর স্ট্যাটিক ফ্যাক্টরি মেথডগুলোর একটি দিয়ে:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`-এর ফলাফলে [ISO-8601][iso-8601-durations] নোটেশন ব্যবহার হয়: `P` (পিরিয়ড বোঝাতে), তারপর বছর (`Y`), মাস (`M`) ও দিনের (`D`) সংখ্যা।

কোনো তারিখের সঙ্গে একটি পিরিয়ড যোগ বা বিয়োগ করা যায়:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

মাসের দৈর্ঘ্য আলাদা আলাদা হওয়ায় মাস যোগ করলে এমন দিনে পৌঁছানো যেতে পারে, যে দিনটির অস্তিত্ব নেই।
সেক্ষেত্রে ফলাফলটি মাসের শেষ বৈধ দিনে ফিরিয়ে আনা হয়:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` একটি তারিখ (সহ) থেকে আরেকটি তারিখ (বহির্ভূত) পর্যন্ত পিরিয়ড রিটার্ন করে:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### `ChronoUnit` দিয়ে একক গণনা

একটি `Period` তার বছর, মাস ও দিনকে আলাদা আলাদা রেখে চলে।
তাই `getDays()` পিরিয়ডের শুধু দিনের _অংশটি_ রিটার্ন করে, মোট দিনসংখ্যা নয়।
দুটি তারিখের মধ্যে কোনো একক এককের মোট সংখ্যা গুনতে [`java.time.temporal.ChronoUnit`][chronounit-docs]-এর `between()` মেথড ব্যবহার করুন:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

দ্বিতীয় তারিখটি প্রথমটির আগে হলে ফলাফল ঋণাত্মক হয়:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

`Duration`-ও স্ট্যাটিক ফ্যাক্টরি মেথড দিয়ে তৈরি করা হয়:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601 নোটেশনে `T` তারিখের অংশকে সময়ের অংশ থেকে আলাদা করে, তাই ডিউরেশনগুলো `PT...` আকারে লেখা হয়।

কোনো ডেট-টাইমের সঙ্গে একটি ডিউরেশন যোগ বা বিয়োগ করা যায়:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` দুটি ডেট-টাইমের মধ্যে সময়ের সঠিক পরিমাণ রিটার্ন করে:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

`toHours()`, `toMinutes()` ও `toSeconds()`-এর মতো মেথড দিয়ে একটি ডিউরেশনকে একটিমাত্র এককে রূপান্তর করা যায়।
এগুলো ওই এককে _মোট_ পরিমাণ রিটার্ন করে, নিচের দিকে রাউন্ড করে:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

ঘড়ির মতো একটি ডিউরেশনকে তার অংশগুলোতে ভাগ করতে চাইলে বদলে `toXxxPart()` মেথডগুলো ব্যবহার করুন:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
