# স্ট্রিং

`STR` টেক্সট ধরে রাখে। একটি স্ট্রিং ডাবল কোটের মধ্যে লেখা হয়।

```sather
   composer : STR is
      return "Sibelius";
   end;
```

একটি `STR` একবার তৈরি হয়ে গেলে আর কখনও বদলায় না। নিচের প্রতিটি বিষয় যে স্ট্রিংটি সম্পর্কে জিজ্ঞেস করা হয়েছে সেটি বদলানোর বদলে একটি *নতুন* স্ট্রিং দিয়ে উত্তর দেয়।

## জোড়া লাগানো

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` একটি সংখ্যাকেও স্ট্রিংয়ের সঙ্গে জুড়ে দেয়, আর এভাবেই কোনো সংখ্যা একটি বাক্যের ভেতরে ঢোকে:

```sather
"Opus " + 27           -- "Opus 27"
```

## দৈর্ঘ্য

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` ক্যারেক্টার গোনে, আর উত্তরটি একটি `INT`।

## টুকরো

| কল | উত্তর |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

যা আছে তার চেয়ে বেশি চাইলে ব্যর্থ হওয়ার বদলে যা আছে ঠিক সেটাই ফিরে পাওয়া যায়।

## তুলনা

`=` জিজ্ঞেস করে দুটি স্ট্রিং একই টেক্সট কি না, আর `/=` জিজ্ঞেস করে সেগুলো আলাদা কি না।

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

কেস গুরুত্বপূর্ণ। `.upper` আর `.lower` একটি কেসে একটি কপি দেয়, আর কেসের তোয়াক্কা না করে তুলনা করার স্বাভাবিক উপায় এটাই:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## সাইজ নিয়ে একটি কথা

একটি `STR` হলো বাইটের একটি সারি, আর `.size` বাইট গোনে। ইংরেজি টেক্সটের ক্ষেত্রে এটি অক্ষর গোনার সমান। কিন্তু অ্যাকসেন্ট বা অন্য বর্ণমালার টেক্সটের ক্ষেত্রে তা নয়, কারণ সেই অক্ষরগুলো প্রতিটি এক বাইটের বেশি জায়গা নেয়।
