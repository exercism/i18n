# টেস্ট

## সেটআপ

প্রয়োজনীয় ডিপেন্ডেন্সি ইনস্টল করতে [WebAssembly-এর সেটআপ নির্দেশাবলি][docs-exercism-wasm] দেখে নিন।

## প্রয়োজনীয়তা

অনুশীলনীর ডিপেন্ডেন্সি ইনস্টল করুন:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## টেস্ট স্যুট পাস করানো

সাবমিট করার আগে আপনার সমাধান যাচাই করতে সাহায্য করার জন্য প্রতিটি অনুশীলনীর সাথেই একটি টেস্ট স্যুট থাকে।
আপনি অনুশীলনীর ডিরেক্টরিতে একটি কমান্ড প্রম্পট খুলে নিচের কমান্ডটি চালিয়ে এই টেস্টগুলো চালাতে পারেন:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

কিছু টেস্ট স্যুটে প্রথমটি ছাড়া বাকি সব টেস্ট স্কিপ করা থাকে।

একটি টেস্ট পাস হলে, `xtest`-কে `test`-এ পরিবর্তন করে পরেরটি চালু করতে পারেন।

## নিজস্ব টেস্ট লেখা

আপনি যদি অতিরিক্ত, নিজস্ব টেস্ট লিখতে চান, তাহলে `custom.spec.js` নামে একটি নতুন ফাইল তৈরি করুন এবং নতুন ফাইলটিসহ আপনার সমাধান সাবমিট করুন:

```shell
exercism submit numbers.wat custom.spec.js
```
