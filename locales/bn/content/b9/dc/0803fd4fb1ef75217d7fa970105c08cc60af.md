# পরিচিতি

একটি বুলিয়ান মান প্রকাশ করে একটি শর্ত `true` না `false`। Go-তে `bool` টাইপ এই দুটি মানের একটিই হতে পারে।

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## লজিক্যাল অপারেটর

লজিক্যাল অপারেটর এক বা দুটি বুলিয়ান মান নিয়ে কাজ করে এবং একটি বুলিয়ান ফলাফল দেয়।

| অপারেটর | নাম | আচরণ                                       |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | একটি বুলিয়ান মানের বিপরীত মান রিটার্ন করে |
| `&&`     | AND  | দুই দিকই `true` হলে শুধু তখনই `true` রিটার্ন করে |
| `\|\|`   | OR   | যেকোনো একটি দিক `true` হলে `true` রিটার্ন করে |

একটি বুলিয়ান মানের বিপরীত মান দরকার হলে `!` (NOT) ব্যবহার করুন:

```go
!isDoorLocked // false
```

দুটি শর্তই `true` হতে হলে `&&` (AND) ব্যবহার করুন:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

অন্তত একটি শর্ত `true` হতে হলে `||` (OR) ব্যবহার করুন:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

লজিক্যাল অপারেটরগুলো এই ক্রমে মূল্যায়ন করা হয়: প্রথমে `!`, তারপর `&&`, তারপর `||`। কোড গ্রুপ করতে এবং কোন অপারেশনগুলো আগে হবে তা নিয়ন্ত্রণ করতে বন্ধনী ব্যবহার করুন:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
