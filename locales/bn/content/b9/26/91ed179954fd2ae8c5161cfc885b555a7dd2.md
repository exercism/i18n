# পরিচিতি

কমেন্ট আপনাকে কোডে নোট লেখার সুযোগ দেয়, কোড কীভাবে রান হয় তা প্রভাবিত না করেই।
এক লাইনের কমেন্ট শুরু হয় `//` দিয়ে, আর বহু লাইনের কমেন্ট `/*` ও `*/` দিয়ে ঘেরা হয়:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

কমেন্ট কোথায় বসেছে, তার উপর নির্ভর করে তার কাজও আলাদা।

## কোড কমেন্ট

কোড কমেন্ট ব্যাখ্যা করে কেন কিছু করা হচ্ছে, কী করা হচ্ছে তা নয়।
কোনো সিদ্ধান্তের পেছনের কারণ কোড দেখে স্পষ্ট না হলে সেগুলো ব্যবহার করুন:

```go
results = results[1:] // skipping the header row
```

## ডক কমেন্ট

ডক কমেন্ট বসে সরাসরি একটি ডিক্লারেশনের আগে, আর কমেন্ট ও ডিক্লারেশনের মাঝে কোনো ফাঁকা লাইন থাকে না।
[`godoc`][godoc] এগুলো পার্স করে প্যাকেজ ডকুমেন্টেশন তৈরি করে।
একটি ডক কমেন্ট হওয়া উচিত একটি সম্পূর্ণ বাক্য, যা শুরু হবে আইডেন্টিফায়ারের নাম দিয়ে এবং শেষ হবে একটি পূর্ণচ্ছেদ দিয়ে।

প্যাকেজ কমেন্ট শুরু হয় প্যাকেজের নাম দিয়ে:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

ফাংশন কমেন্ট শুরু হয় ফাংশনের নাম দিয়ে:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
