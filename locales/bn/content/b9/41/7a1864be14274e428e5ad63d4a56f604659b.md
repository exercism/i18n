# ভূমিকা

Common Lisp বেশিরভাগ কাজের জন্য প্রচলিত গাণিতিক অপারেটরগুলো ব্যবহার করে, তবে বেশি পরিচিত "ইনফিক্স নোটেশনের" বদলে এটি "প্রিফিক্স নোটেশন" ব্যবহার করে, যা কিছুটা আলাদা।

আরও স্পষ্টভাবে:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

প্রিফিক্স নোটেশন `2 + 2`-এর মতো কিছু অপারেশনকে কিছুটা অপরিচিত `(+ 2 2)` আকারে বদলে দিলেও, এটি একসাথে একাধিক সংখ্যার উপর কাজ করা অনেক সহজ করে তোলে।

## প্রাথমিক গণিত

Common Lisp-এ সব প্রচলিত ফাংশনই আছে: যোগ, বিয়োগ, গুণ ও ভাগের জন্য `+`, `-`, `*`, `/`।

ভাগের কথা ভাবলে কেউ কেউ ভাগশেষ জানতে চাইতে পারেন, যা `mod` (অর্থাৎ মডুলো) ফাংশন দিয়ে করা হয়, যা আর্গুমেন্ট হিসেবে একটি সংখ্যা ও একটি ভাজক নেয়:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## সংখ্যা তুলনা করা

সবশেষে, `=` (সমান), `/=` (সমান নয়) এবং `>=` (বড় বা সমান) এর মতো ফাংশন ব্যবহার করে বিভিন্ন সংখ্যা তুলনা করা আপনার কাজে লাগতে পারে।
এই তুলনাগুলো সত্য হলে (যেমন `(= 1 1)`) সেগুলো `T` রিটার্ন করে, আর সত্য না হলে (যেমন `(> 0 1)`) সেগুলো `NIL` রিটার্ন করে।
