# টেস্ট

## টেস্ট চালানো

কোনো অনুশীলনীর ডিরেক্টরিতে থাকলে আপনি দুটি সাবডিরেক্টরি দেখতে পাবেন:

* `src` ডিরেক্টরিতে আপনার অনুশীলনীর সমাধান থাকে
* `spec` ডিরেক্টরিতে অনুশীলনীর জন্য চালানোর টেস্টগুলো থাকে

আপনি যদি সঠিক ডিরেক্টরিতে থাকেন (অর্থাৎ যে ডিরেক্টরিতে `src` আর `spec` আছে), তাহলে `crystal spec` চালিয়ে ওই অনুশীলনীর টেস্টগুলো চালাতে পারবেন:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

এতে `spec` ডিরেক্টরির সব টেস্ট ফাইল চালানো হবে।

প্রতিটি টেস্ট ফাইলে প্রথম টেস্টটি ছাড়া বাকি সবগুলো স্কিপ করা থাকে।

একটি টেস্ট পাস করানোর পর, `pending`-এর জায়গায় `it` লিখে পরের টেস্টটি আনস্কিপ করতে পারেন।

## Crystal ফরম্যাট

সমাধান জমা দেওয়ার আগে আপনার সমাধানে `crystal tool format` চালানোর পরামর্শ দেওয়া হয়।

আপনি নিচের কমান্ড দিয়ে আপনার বর্তমান ডিরেক্টরির সবকিছু ফরম্যাট করতে পারেন:

```bash
$ crystal tool format ./
```

অথবা আপনি বেছে বেছে ফাইল ফরম্যাট করতে পারেন এভাবে:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## আপনার সমাধান জমা দেওয়া

সমাধান জমা দেওয়ার সময় `src` ডিরেক্টরির সোর্স ফাইলটি যেন জমা দেন:

```bash
$ exercism submit src/<exercise>.cr
```
