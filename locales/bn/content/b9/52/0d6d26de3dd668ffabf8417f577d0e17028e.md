## সাধারণ

`SimpleLinkedList` স্ট্রাক্টটি `Vec`-এর র‍্যাপার হিসেবে ইমপ্লিমেন্ট করবেন না। বরং হিপে নোড অ্যালোকেট করুন।

এটি এভাবে ইমপ্লিমেন্ট করা যেতে পারে:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

`head` ফিল্ডটি এই লিংকড লিস্টের প্রথম এলিমেন্ট (Node) বোঝায়।

এই ইমপ্লিমেন্টেশনে নিচের ফিল্ডগুলোসহ একটি `Node` স্ট্রাক্টও দরকার:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data`-তে সংরক্ষিত ডেটা থাকে, আর `next` পরের নোডটি (যদি থাকে) বা None বোঝায়।

## কেন `Option<Box<Node<T>>>`, শুধু `Option<Node<T>>` নয়?

নিজে চেষ্টা করে দেখুন। আপনি নিচের এররটি পাবেন।

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

সমস্যা হলো, কম্পাইল টাইমে next-এর সাইজ জানা থাকতে হয়।
যেহেতু `next` রিকার্সিভ ("একটি নোডের ভেতরে একটি নোড, তার ভেতরে আরেকটি নোড..."), কম্পাইলার জানে না কতটুকু মেমরি অ্যালোকেট করতে হবে।
এর বিপরীতে, [Box](https://doc.rust-lang.org/std/boxed/) হলো একটি নির্দিষ্ট সাইজের হিপ পয়েন্টার।
