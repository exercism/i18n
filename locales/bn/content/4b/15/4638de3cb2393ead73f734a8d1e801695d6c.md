# টাইপ কনভার্সন সম্পর্কে

Go-তে ভিন্ন ভিন্ন টাইপের মধ্যে স্পষ্ট কনভার্সন প্রয়োজন।
উদাহরণস্বরূপ, এটি একটি কম্পাইলার এরর তৈরি করে:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

টাইপের মধ্যে কনভার্সন (**টাইপ কাস্টিং** নামেও পরিচিত) করা হয় এমন একটি ফাংশনের মাধ্যমে, যার নামটি হলো যে টাইপে কনভার্ট করতে চান সেই টাইপের নাম।
`T(v)` ব্যবহার করে একটি মান `v`-কে `T` টাইপে কনভার্ট করা হয়।
উদাহরণস্বরূপ, একটি `int`-কে `float64`-এ কনভার্ট করতে হলে নিচের কাজটি করতে হবে:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

একই কথা যেকোনো কাস্টম টাইপের ক্ষেত্রেও প্রযোজ্য:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## প্রিমিটিভ টাইপ ও স্ট্রিংয়ের মধ্যে কনভার্সন

প্রিমিটিভ টাইপ (যেমন `int`) ও `string`-এর মধ্যে কনভার্ট করার জন্য `strconv` প্যাকেজ রয়েছে।

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

সতর্কতা: স্ট্যান্ডার্ড কাস্টিং পদ্ধতি ব্যবহার করলে এমন আচরণ পাওয়া যায় না।
উদাহরণস্বরূপ:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

এখানে আরও কিছু কমন কনভার্সন পদ্ধতি দেওয়া হলো:

| পদ্ধতি      | উদ্দেশ্য                     |
| ----------- | --------------------------- |
| ParseBool   | `string`-কে `bool`-এ কনভার্ট করে  |
| FormatBool  | `bool`-কে `string`-এ কনভার্ট করে  |
| ParseFloat  | `string`-কে `float`-এ কনভার্ট করে |
| FormatFloat | `float`-কে `string`-এ কনভার্ট করে |
| ParseInt    | `string`-কে `int`-এ কনভার্ট করে   |
| FormatInt   | `int`-কে `string`-এ কনভার্ট করে   |
