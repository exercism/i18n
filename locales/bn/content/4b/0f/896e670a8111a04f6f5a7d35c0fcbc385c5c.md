# নির্দেশনার সংযোজন

## Python-এর জন্য বিশেষ নির্দেশনা

এই অনুশীলনীর জন্য থার্ড-পার্টি লাইব্রেরি **প্রয়োজন নেই**। **FRP লাইব্রেরি** সংক্রান্ত নির্দেশনা অনুগ্রহ করে উপেক্ষা করুন।


## এক্সেপশন মেসেজ

মাঝে মাঝে [একটি এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটি করার সময়, এররের উৎস কী তা বোঝাতে আপনার সবসময় একটি **অর্থবহ এরর মেসেজ** যোগ করা উচিত। এতে আপনার কোড পড়তে আরও সহজ হয় এবং debugging-এ যথেষ্ট সাহায্য করে। যে সব ক্ষেত্রে আপনি জানেন এররের উৎস একটি নির্দিষ্ট টাইপ হবে, সেখানে আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যোগ করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে [raise স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করে একটি `ValueError` "থ্রো" করতে হবে, যখন গেম শেষ হয়ে গেছে কিন্তু খেলোয়াড় খেলা চালিয়ে যেতে চাইছেন। টেস্টগুলো তখনই পাস করবে যদি আপনি `exception` `raise` করেন এবং তার সাথে একটি মেসেজও যোগ করেন।

মেসেজসহ একটি `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# when player tries to play, but the game is already over.
raise ValueError("The game has already ended.")
```
