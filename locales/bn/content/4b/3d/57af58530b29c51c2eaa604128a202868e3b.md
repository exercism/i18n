# নির্দেশনা

আপনি খালি বাফার ইনিশিয়ালাইজ করবেন এবং ফিবোনাচি সিকোয়েন্সের প্রথম পাঁচটি সংখ্যা বা এলিমেন্টের তালিকা তৈরি করবেন।

ফিবোনাচি সিকোয়েন্স হলো এমন একটি সংখ্যার সেট, যেখানে প্রতিটি এলিমেন্ট তার আগের দুটির যোগফল। আমরা সিকোয়েন্সটি এক থেকে শুরু করি। তাই প্রথম দুটি এলিমেন্ট ১ এবং ১।

## 1. `count` সংখ্যক শূন্যের একটি বাফার তৈরি করুন।

এমন একটি ফাংশন তৈরি করুন যা `count` সংখ্যক শূন্যের একটি বাফার তৈরি করে।

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. ফিবোনাচি সিকোয়েন্সের প্রথম পাঁচটি এলিমেন্টের তালিকা করুন

এমন একটি ফাংশন তৈরি করুন যা ফিবোনাচি সিকোয়েন্সের প্রথম পাঁচটি সংখ্যা রিটার্ন করে।
এর প্রথম পাঁচটি এলিমেন্ট `1, 1, 2, 3, 5`।

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
