# সম্পর্কে

গাণিতিক অপারেশন করার জন্য PHP বেশ কিছু অপারেটর দেয়। নিজের গাণিতিক অপারেটরগুলোর ক্ষেত্রে PHP অপারেশনের প্রচলিত গাণিতিক ক্রম অনুসরণ করে। PHP যেসব অপারেটর দেয় সেগুলো হলো:

* আইডেন্টিটি (+)
* নেগেশন (-)
* যোগ (+)
* বিয়োগ (-)
* গুণ (*)
* ভাগ (/)
* মডুলো (%)
* এক্সপোনেনশিয়েশন (**)

চলুন প্রতিটি অপারেটর এবং সেগুলো কীভাবে ব্যবহার করা যায় সেটি দেখি:

## আইডেন্টিটি (+)

আইডেন্টিটি অপারেটর (+) একটি মাত্র মান নিয়ে কাজ করে (ইউনারি অপারেটর)। এটি ভ্যারিয়েবলের `float` বা `int` মান হিসেবে ফল দেয়।

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## নেগেশন (-)

নেগেশন অপারেটর একটি মাত্র মান নিয়ে কাজ করে (ইউনারি অপারেটর) এবং সংখ্যাটির বিপরীত মান রিটার্ন করে।

```php
$forward = 65;
$reverse = -$forward; // -65
```

## যোগ (+) এবং বিয়োগ (-)

যোগ অপারেটর তার দুই পাশের দুটি মান যোগ করে, আর বিয়োগ অপারেটর বাঁ মান থেকে ডান মান বিয়োগ করে।

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## ভাগ (/)

ভাগ অপারেটর বাঁ মানকে ডান মান দিয়ে ভাগ করার ফলাফল দেয়। ডান মান 0 হলে এটি একটি `DivisionByZeroError` এরর তৈরি করবে।

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## গুণ (*)

গুণ অপারেটর বাঁ ও ডান মান দুটি একসাথে গুণ করার ফলাফল রিটার্ন করে।

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## মডুলো (%)

বাঁ মানকে ডান মান দিয়ে ভাগ করলে যে ভাগশেষ থাকে, মডুলো অপারেটর সেটি রিটার্ন করে। একটি সংখ্যা আরেকটি সংখ্যা দিয়ে নিঃশেষে বিভাজ্য কি না, কোনো মান জোড় না বিজোড়, আরও অনেক কিছু বের করার জন্য এই অপারেটরটি খুব কাজে লাগে।

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## এক্সপোনেনশিয়েশন (**)

বাঁ মানকে ডান মানের ঘাতে উন্নীত করতে এক্সপোনেনশিয়েশন অপারেটর ব্যবহার করা হয়। PHP 5.6-এর আগে একই কাজ করতে হলে `pow` ফাংশন ব্যবহার করতে হতো।

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

এক্সপোনেনশিয়েশন অপারেটর দুই পাশেই ইন্টিজার ও ফ্লোট সমর্থন করে, তাই এটি দিয়ে বর্গমূল (বা অন্য কোনো মূল) কিংবা আরও জটিল এক্সপোনেনশিয়াল মানও বের করা যায়।

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## অপারেশনের ক্রম

PHP গণিতের প্রচলিত অপারেশন-ক্রম অনুসরণ করে। এর মানে হলো, অপারেশনগুলো বাঁ থেকে ডানে চালানোর বদলে প্রতিটি অপারেটরের একটি অগ্রাধিকার থাকে, আর অপারেশনগুলো সেই অগ্রাধিকার অনুযায়ী চলে। অপারেশনের ক্রমটি হলো:

* বন্ধনী
* এক্সপোনেনশিয়েশন
* গুণ, ভাগ
* যোগ, বিয়োগ

গুণ ও ভাগের অগ্রাধিকার একই স্তরের। একইভাবে যোগ ও বিয়োগও একই স্তরের অগ্রাধিকারে থাকে।

এর মানে হলো, নিচের মানটি 10 নয় বরং 17 হবে, কারণ গুণের অগ্রাধিকার যোগের চেয়ে বেশি:

```php
$value = 2 + 3 * 5;
```

কোনো ভ্যারিয়েবলের উপর অপারেশন চালিয়ে ফলাফলটি আবার সেই ভ্যারিয়েবলেই অ্যাসাইন করার সময় PHP গাণিতিক অপারেটরের সাথে অ্যাসাইনমেন্ট মিলিয়ে বেশ কিছু সুবিধাজনক অ্যাসাইনমেন্ট অপারেটরও দেয়। এগুলো `Assignment Operators` কনসেপ্টে আলোচনা করা হবে।
