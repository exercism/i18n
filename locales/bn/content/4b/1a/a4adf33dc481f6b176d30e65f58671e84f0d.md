# নির্দেশনার পরিশিষ্ট

## Int স্ট্রাক্টে মেথড যোগ করা

এই অনুশীলনীতে Crystal-এর `Int` স্ট্রাক্টে মেথড যোগ করার দিকে মনোযোগ দেওয়া হয়েছে।
এটি করতে হলে আপনাকে `Int` নামে একটি স্ট্রাক্ট ডিফাইন করতে হবে।
আর মেথডটি এই স্ট্রাক্টের ভেতরে রাখতে হবে।

```crystal
struct Int
  # your solution here
end
```

`Int` ক্লাসের সোর্স কোড [এখানে][int] পাওয়া যাবে।
