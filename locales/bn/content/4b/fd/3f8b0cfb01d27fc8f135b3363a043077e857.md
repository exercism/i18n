# পরিচিতি

## ট্রু এবং ফলস

রুবিতে `true` এবং `false` দিয়ে ট্রু ও ফলস লজিক্যাল অবস্থা প্রকাশ করা হয়।

```ruby
happy = true
sad = false
```

## সমতা ও তুলনা

রুবিতে সাধারণ সমতার চিহ্নগুলো ব্যবহার করে অবজেক্টগুলোর মধ্যে তুলনা করা যায়:
- দুটি অবজেক্ট সমান কি না দেখতে `==` ব্যবহার করুন
- বাম দিকের অবজেক্টটি ডান দিকের অবজেক্টের চেয়ে **বড়** কি না দেখতে `>` ব্যবহার করুন
- বাম দিকের অবজেক্টটি ডান দিকের অবজেক্টের চেয়ে **ছোট** কি না দেখতে `<` ব্যবহার করুন।
- "বড় অথবা সমান" এবং "ছোট অথবা সমান" পরীক্ষা করতে যথাক্রমে `>=` বা `<=` ব্যবহার করুন।

আপনি সাধারণ অপারেটরগুলো দিয়ে বুলিয়ান লজিকও ব্যবহার করতে পারেন:
- `x and y` ট্রু কি না দেখতে `&&` বা `and` ব্যবহার করুন
- `x or y` ট্রু কি না দেখতে `||` বা `or` ব্যবহার করুন।
- সমতা উল্টাতে `!` বা `not` ব্যবহার করুন, যেমন `x != y` (x কি y-এর সমান নয়)

এখানে কিছু উদাহরণ দেওয়া হলো:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
