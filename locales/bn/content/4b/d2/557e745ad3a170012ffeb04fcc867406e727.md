# ইনস্টলেশন

## Windows ব্যবহারকারীদের জন্য

[Windows Subsystem for Linux][wsl-link] ইনস্টল করুন এবং পরের অংশটি দেখুন।

## Linux/Mac ব্যবহারকারীদের জন্য

### brew দিয়ে ইনস্টল করা

Chapel ইনস্টল করার সবচেয়ে সহজ উপায় এটি।
এতে আপনি একটি প্রাথমিক কার্যকর ইনস্টলেশন পাবেন, যা Exercism ট্র্যাকটি ধরে কাজ করার জন্য উপযুক্ত।
আরও অভিজ্ঞ ব্যবহারকারীরা চাইলে সোর্স কোড থেকে Chapel বিল্ড করতে পারেন (পরের অংশ)।

0. আগে থেকে না করা থাকলে, [brew][brew-link] প্যাকেজ ম্যানেজারটি ইনস্টল করুন।
1. প্রথমে `brew update` রান করে নিশ্চিত করুন যে brew হালনাগাদ আছে।
2. `brew install chapel` রান করে Chapel ইনস্টল করুন।
3. `chpl --version` রান করে যাচাই করুন যে ইনস্টলেশনটি সফল হয়েছে।

এতে chapel কম্পাইলার (`chpl`), টেস্টগুলো রান করতে যা ব্যবহার করা হবে সেই প্যাকেজ ম্যানেজার `mason`, এবং ডকুমেন্টেশন তৈরির টুল `chpldoc` ইনস্টল হবে। exercism-এর জন্য এটির দরকার নেই, তবে আপনি যদি Chapel-এ নিজের লাইব্রেরি বানাতে চান (যখন :) তখন), তাহলে এটি থাকা ভালো।

### সোর্স কোড থেকে Chapel বিল্ড করা

আরও অভিজ্ঞ ব্যবহারকারীরা চাইলে নিজেরাই সোর্স কোড থেকে Chapel বিল্ড করতে পারেন। সেটি করতে হলে,

1. [প্রয়োজনীয় প্যাকেজগুলো][prereqs-link] ইনস্টল করুন।
2. সর্বশেষ Chapel রিলিজের আর্কাইভটি [ডাউনলোড করুন][download-link] এবং এক্সট্রাক্ট করুন।
3. প্রথমে, আপনি যেখানে Chapel ইনস্টল করতে চান সেখানে ইনস্টলেশন ও সেটআপের প্রস্তুতি নিতে হবে।
এর জন্য দেওয়া `configure` স্ক্রিপ্টটি রান করলেই কাজ হবে।
শুধু

```
./configure
```

রান করলেই বাইনারি, লাইব্রেরি ও শেয়ারড ফাইলগুলো `/usr/local/` ডিরেক্টরিতে ইনস্টল হয়ে যাবে। আপনি `--prefix` অপশন ব্যবহার করে এটি বদলাতে পারেন।
উদাহরণস্বরূপ, আপনি যদি `~/.chapel` ডিরেক্টরিতে chapel ইনস্টল করতে চান, তাহলে এভাবে লিখতে পারেন

```
./configure --prefix=~/.chapel
```

4. কম্পাইলার ও টুলগুলো ইনস্টল করতে, রান করুন

```
make
make mason
make chpldoc
make install
```

5. নিশ্চিত করুন যে `/dir/for/install/bin` ফোল্ডারটি আপনার `PATH` ভেরিয়েবলে আছে।

Chapel ইনস্টল করার বিভিন্ন উপায় এবং সোর্স কোড থেকে কাজ করার বিষয়ে আরও তথ্যের জন্য ডকুমেন্টেশনের [Building Chapel][building-link] পেজটি দেখুন।
