# সম্পর্কে

যে ডেটা স্ট্রাকচার শূন্য বা তার বেশি এলিমেন্ট ধরে রাখতে পারে, সেগুলোকে _কলেকশন_ বলা হয়।
Ruby-তে একটি **অ্যারে** হলো এমন একটি কলেকশন, যা তার অবজেক্টগুলো যে ক্রমে যোগ করা হয় সেই ক্রম বজায় রাখে।
অ্যারে যেকোনো অবজেক্ট ধরে রাখতে পারে।
ইনডেক্স ব্যবহার করে অ্যারেতে অবজেক্ট যোগ করা যায় বা সেখান থেকে সেগুলো বের করে আনা যায়।
Ruby-র অ্যারে ইনডেক্সিং শূন্য-ভিত্তিক, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য হয়:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Ruby-তে অ্যারে তৈরির একাধিক উপায় আছে:

- লিটারাল কনস্ট্রাক্টর `[]` ব্যবহার করে _(সবচেয়ে বেশি ব্যবহৃত)_
- স্পষ্টভাবে `Array.new` কল করে
- Kernel-এর `Array()` মেথড কল করে

`Array.new` মেথড দুটি ঐচ্ছিক আর্গুমেন্ট সমর্থন করে: অ্যারের প্রাথমিক আকার এবং একটি ডিফল্ট অবজেক্ট।

যখন একটি আকার ও ডিফল্ট দেওয়া হয়, তখন অ্যারেটি ডিফল্ট অবজেক্টের `size` সংখ্যক কপি দিয়ে ভরে দেওয়া হয়।

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

যেহেতু অ্যারের সব এলিমেন্ট একই হ্যাশ ধরে রাখে, তাই তাদের একটিতে পরিবর্তন করলে সেটি সবগুলোতেই প্রভাব ফেলবে।

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

আপনার যদি একাধিক আলাদা কপি দরকার হয়, তাহলে ব্লক সংস্করণটি ব্যবহার করা উচিত, যা অ্যারের প্রতিটি এলিমেন্ট ইনিশিয়ালাইজ করার সময়ই ওই ব্লকের ফলাফল ব্যবহার করে:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ruby অ্যারের আরেকটি বৈশিষ্ট্য হলো এরা [Enumerable][enumerable-module] মডিউলটি মিক্স-ইন করে, যা অ্যারের এলিমেন্ট ইটারেট করা, সার্চ করা, সর্ট করা, ফিল্টার করা ইত্যাদির জন্য অনেক কাজের মেথড যোগ করে।
