# পরিচিতি

## Julia-তে বুলিয়ান

ট্রু বা ফলস মান `Bool` টাইপ দিয়ে প্রকাশ করা হয়।
এতে মাত্র দুটি মান থাকে: `true` এবং `false`.

```julia-repl
julia> true
true

julia> false
false
```

## বুলিয়ান অপারেটর

Julia-তে তিনটি বুলিয়ান অপারেটর আছে।

`&&` হলো বুলিয়ান "এবং"।
`&&`-এর *দুই* দিকের এক্সপ্রেশনই `true` হলে এটি `true` ইভ্যালুয়েট করে।

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` হলো বুলিয়ান "অথবা"।
`||`-এর *যেকোনো* এক দিকের এক্সপ্রেশন `true` হলে এটি `true` ইভ্যালুয়েট করে।

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` হলো বুলিয়ান "নয়"।
এটি `true` ও `false` মান পরস্পর বদলে দেয়।

```julia-repl
julia> !true
false

julia> !false
true
```

আরও দীর্ঘ ও জটিল এক্সপ্রেশনের ক্ষেত্রে, আপনার উদ্দেশ্য স্পষ্ট করতে বন্ধনী ব্যবহার করাই সবচেয়ে ভালো।

```julia-repl
julia> (true || false) && (false && true)
false
```
