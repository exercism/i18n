# ভ্যারিয়েডিক প্যারামিটার

Swift-এ [_ভ্যারিয়েডিক প্যারামিটার_][variadic-parameters] ব্যবহার করে একই টাইপের শূন্য বা তার বেশি মান একটি ফাংশনের একটিমাত্র প্যারামিটারে পাঠানো যায়।
এটি বোঝানো হয় প্যারামিটারটির টাইপ অ্যানোটেশনের শেষে `...` যোগ করে।

এই মানগুলো স্বয়ংক্রিয়ভাবে একটি অ্যারেতে সাজানো হয়, যার এলিমেন্টগুলোর টাইপ ভ্যারিয়েডিক প্যারামিটারটির টাইপের মতোই।

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

ভ্যারিয়েডিক প্যারামিটার ব্যবহার করার সময় Swift-এর দুটি সীমাবদ্ধতা আছে:

1. Swift-এ একটি ফাংশনে কেবল একটি ভ্যারিয়েডিক প্যারামিটার থাকতে পারে। সিদ্ধান্ত হয়েছে যে Swift-এর ভবিষ্যৎ কোনো রিলিজে এই নিষেধাজ্ঞা উঠে যাবে, তবে এখনো তা বহাল আছে।
2. যদি কোনো ফাংশনের ডেফিনিশনে ভ্যারিয়েডিক প্যারামিটারের পরে আরও প্যারামিটার থাকে, তাহলে ভ্যারিয়েডিক প্যারামিটারের পরের প্রথম প্যারামিটারটির জন্য একটি আর্গুমেন্ট লেবেল থাকা _বাধ্যতামূলক_।
