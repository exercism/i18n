# টেস্ট

PureScript অনুশীলনীর টেস্ট স্যুটগুলো spago টুল ব্যবহার করে অনুশীলনীর ডিরেক্টরি থেকে রান করা যায়:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

এখানে <exercism-workspace> হলো CLI-এর ওয়ার্কস্পেস ডিরেক্টরি।

উদাহরণ:

    cd ~/exercism/purescript/accumulate
    spago test
