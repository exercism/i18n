# পরিচিতি

Common Lisp-এ একটি ফাংশন কেবল একটি মানই রিটার্ন করতে পারে না, একাধিক মানও রিটার্ন করতে পারে। উদাহরণস্বরূপ, `floor`, যা শূন্যের দিকে নিচে রাউন্ড করে, দুটি মান রিটার্ন করে: প্রথমটি রাউন্ড করা মান, আর দ্বিতীয়টি ভাগশেষ।

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(একাধিক মান রিটার্ন হলে আমরা সেগুলো আউটপুটের আলাদা আলাদা লাইনে দেখাব।)

## একাধিক মান রিটার্ন করা

আপনি যদি কোনো ফাংশন দিয়ে একাধিক মান রিটার্ন করাতে চান, তাহলে `values` অ্যাকসেসরটি ব্যবহার করেন:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## একাধিক মান সামলানো

আপনি যদি কেবল প্রথম মানটির বিষয়ে চিন্তা করেন, তাহলে বিশেষ কিছু করতে হবে না; ভাষা নিজেই সেটি সামলে নেয়:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

তবে আপনি যদি ওই অন্য মানগুলো অ্যাকসেস করতে চান, তাহলে কয়েকটি ফাংশন ব্যবহার করতে হবে। এর মধ্যে প্রধান দুটি ম্যাক্রো হলো `multiple-value-list` এবং `multiple-value-bind`। এগুলো এমন কিছু মোড়ানোর কাজে ব্যবহৃত হয়, যা একাধিক মান রিটার্ন করে এবং সব মান ধরে রাখে। প্রথমটি সব মান দিয়ে একটি অ্যারে তৈরি করবে। দ্বিতীয়টি আপনাকে আলাদা আলাদা মানের সাথে ভ্যারিয়েবল বাইন্ড করতে দেবে।

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

আরেকটি দরকারি ফাংশন হলো `nth-value`।
