# Instructions append

## গ্রিডের ফরম্যাট

গ্রিডটি একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে উপস্থাপন করা হয়, যেখানে প্রতিটি সারির শেষে একটি নিউলাইন ক্যারেক্টার থাকে।

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                                                                     |
| -------- | ------------ | ------- | ------------------------------------------------------------------------- |
| `$a0`    | ইনপুট        | address | নাল-টার্মিনেটেড ইনপুট স্ট্রিং                                              |
| `$a1`    | ইনপুট/আউটপুট | address | নাল-টার্মিনেটেড ফলাফল স্ট্রিং, গ্রিডের মাপ অবৈধ হলে খালি                     |
| `$v0`    | আউটপুট       | integer | গ্রিডের স্ট্যাটাস (`0` = `ok`, `-1` = `invalid columns`, `-2` = `invalid rows`) |
| `$t0-9`  | সাময়িক       | any     | সাময়িকভাবে সংরক্ষণের জন্য                                                 |
