# জেনেরিক ক্লাস

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## প্যারামিটারটি আসলে কী

`T` বলতে এমন একটি টাইপ বোঝায়, যা ব্যবহারের জায়গায় সরবরাহ করা হয়। প্রোগ্রাম কম্পাইল করার সময়, সত্যিই ব্যবহৃত প্রতিটি সমন্বয়ের জন্য Sather আলাদা একটি ক্লাস তৈরি করে। তাই:

- `LOST_BOX{STR}` আর `LOST_BOX{INT}` পরস্পর-সম্পর্কহীন দুইটি টাইপ;
- কোনো রানটাইম চেক নেই, কোনো বক্সিং নেই, কোনো কনভার্সন নেই;
- ক্লাসে কোনো এরর থাকলে, যে যে টাইপের সাথে এটি ব্যবহৃত হয়, প্রতিটির জন্যই সেটি ধরা পড়ে।

এটি C++-এর টেমপ্লেট বা Rust-এর জেনেরিক্সের মতো একই পদ্ধতি, আর Java-র জেনেরিক্সের মতো নয়; সেখানে টাইপ মুছে ফেলা হয়, আর সবকিছু আসলে একটি অবজেক্ট।

## কনস্ট্রেইন্ট দেওয়া প্যারামিটার

সাদামাটা `T` কে অ্যাসাইন করা যায়, পাস করা যায় আর রিটার্ন করা যায়; এর বেশি কিছু নয়, কারণ এটি সম্পর্কে আর কিছুই জানা নেই। এর উপর রুটিন কল করতে হলে বলে দিতে হয়, এটিকে কীসের সাথে কনফর্ম করতে হবে:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR` দাবি করে যে `T`, `$STR`-এর সাথে কনফর্ম করে, আর বিনিময়ে `item.str` কল করার সুযোগ দেয়। সাদামাটা `T` যা করতে পারে না, কনস্ট্রেইন্ট দিয়ে সেটাই সম্ভব করে দেওয়া হয়।

কনস্ট্রেইন্ট না থাকলে `item.str` কম্পাইল হবে না, আর মেসেজে জেনেরিক ক্লাসের ভেতরের লাইনটির কথা বলা হবে, যে লাইনটি এটি ব্যবহার করেছিল সেটির নয়।

## জেনেরিক রুটিন?

এমন কিছু নেই। প্যারামিটার নেয় শুধু ক্লাস। যে রুটিনকে একাধিক টাইপ নিয়ে কাজ করতে হবে, সেটি হয় জেনেরিক ক্লাসের ভেতরে থাকে, নয়তো `$STR`-এর মতো একটি অ্যাবস্ট্রাক্ট টাইপ নেয়।

## কোনটি কখন বেছে নেবেন

|  | জেনেরিক ক্লাস | অ্যাবস্ট্রাক্ট ক্লাস |
| --- | --- | --- |
| নির্ধারিত হয় | কম্পাইল করার সময় | রান করার সময় |
| ধরে রাখে | প্রতি ইনস্ট্যানশিয়েশনে একটি টাইপ | যেকোনো কনফর্মিং টাইপ |
| খরচ | নেই | একটি ডিসপ্যাচ |

`ARRAY{$ACT}` দুটোই ব্যবহার করে: এলিমেন্টের টাইপে জেনেরিক, আর সেই এলিমেন্ট কী হতে পারে সেখানে অ্যাবস্ট্রাক্ট।

যখন টাইপটি সর্বত্র একই থাকে আর ক্লাসের ব্যবহারকারী সেটি জানেন, তখন জেনেরিক ক্লাস বেছে নিন। আর যখন একটি কালেকশনে একাধিক টাইপ একসাথে থাকতে হবে, তখন অ্যাবস্ট্রাক্ট ক্লাস বেছে নিন।
