# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু ইউটিলিটি ফাংশনের একটি আংশিক সেট তৈরি করবেন, যা একজন ডেভেলপারকে আইডেন্টিফায়ারের নাম পরিষ্কার করতে সাহায্য করবে।

৫টি কাজে ধীরে ধীরে আপনি `clean` ফাংশনটি তৈরি করবেন।
একটি বৈধ আইডেন্টিফায়ার শূন্য বা তার বেশি অক্ষর ও আন্ডারস্কোর নিয়ে গঠিত।

যদি `clean` ফাংশনে একটি খালি স্ট্রিং পাস করা হয়, তাহলে একটি খালি স্ট্রিং রিটার্ন করা উচিত।

## 1. স্পেসকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করুন

যেকোনো স্পেসকে আন্ডারস্কোর দিয়ে প্রতিস্থাপন করতে একটি `clean1` ফাংশন তৈরি করুন। এটি শুরুর ও শেষের স্পেসের ক্ষেত্রেও প্রযোজ্য।

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. কন্ট্রোল ক্যারেক্টারকে বড় হাতের "[CTRL]" স্ট্রিং দিয়ে প্রতিস্থাপন করুন

আগের ফাংশনটি যা করে তা সব করতে এবং কমন কন্ট্রোল ক্যারেক্টারগুলোকে (\n, \t ও \r) `"[CTRL]"` স্ট্রিং দিয়ে প্রতিস্থাপন করতে `clean2` তৈরি করুন।

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. kebab-case থেকে camelCase-এ রূপান্তর করুন

আগের ফাংশনটি যা করে তা সব করতে এবং kebab-case থেকে camelCase-এ রূপান্তর করতে `clean3` তৈরি করুন।

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. ডিজিট বাদ দিন

আগের ফাংশনটি যা করে তা সব করতে এবং সমস্ত ডিজিট বাদ দিতে `clean4` তৈরি করুন।

```elm
clean4 "123"
    --> ""
```

## 5. গ্রিক ছোট হাতের অক্ষর বাদ দিন

সবশেষে, আগের ফাংশনটি যা করে তা সব করতে এবং 'α' থেকে 'ω' পরিসরের যেকোনো গ্রিক অক্ষর বাদ দিতে `clean` তৈরি করুন।

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
