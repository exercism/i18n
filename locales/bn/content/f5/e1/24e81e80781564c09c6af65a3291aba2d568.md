# নির্দেশনা

দুটি ভিন্ন ইন্টারনাল টেবিলের ডেটা কীভাবে একটি ফলাফল ইন্টারনাল টেবিলে একত্রিত করতে হয় তা শিখুন।

আপনার ক্লাসকে দুটি ইন্টারনাল টেবিল দেওয়া হবে, যেগুলোতে দুই সম্পূর্ণ ভিন্ন ডেটাসেট রয়েছে: ALPHAS এবং NUMS।

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

ALPHA টেবিলের ডেটা নিচে দেখানো হয়েছে।

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

NUMS টেবিলের ডেটা নিচে দেখানো হয়েছে।

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

আপনার কাজ হলো এমন একটি ইন্টারনাল টেবিল রিটার্ন করা, যার প্রতিটি রেকর্ড ALPHAS ইন্টারনাল টেবিল ও NUMS ইন্টারনাল টেবিলের প্রতিটি সেলের মান একসাথে একত্রিত করে তৈরি হবে। উদাহরণস্বরূপ, COMBINED_DATA ইন্টারনাল টেবিলের প্রথম সারির প্রথম কলামের মান হওয়া উচিত "A1"।

প্রত্যাশিত রিটার্ন টেবিলের সংজ্ঞা নিচে দেওয়া হলো:

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
