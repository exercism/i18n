# টেস্ট

প্রতিটি অনুশীলনীতে একটি টেস্ট ফাইল থাকে।
`bats` প্রোগ্রাম দিয়ে টেস্টগুলো চালান।

```bash
bats test-hello-world.bats
```

`bats` ইনস্টল করতে হবে।
আপনার সিস্টেমের জন্য `bats` ইনস্টল করার নির্দেশনার জন্য [Bash ট্র্যাকের টেস্টিং][bash] পৃষ্ঠাটি দেখুন।

### bats আসলে bash দিয়ে লেখা

bats ফাইলটি আসলে একটি bash স্ক্রিপ্ট, যেখানে `bats` কমান্ড চিনতে পারে এমন কিছু বিশেষ ফাংশন থাকে।
আপনি এমন কিছু টেস্ট পাবেন যেগুলো দেখতে এরকম

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

এই `<<<` সিনট্যাক্সটি bash-এর একটি [Here String][here-string]।
এটি ডান দিকের স্ট্রিংটি বাম দিকের প্রোগ্রামের স্ট্যান্ডার্ড ইনপুটে পাঠায়।
এটি ([প্রায়][so]) একই রকম

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## assert ফাংশনগুলোর জন্য সহায়তা

টেস্টগুলো [bats-assert][bats-assert] লাইব্রেরির ফাংশন ব্যবহার করে।
বিভিন্ন `assert*` ফাংশনের সাহায্য সেখানেই পাওয়া যাবে।

## স্কিপ করা টেস্ট

অনুশীলনী সমাধান করা মানে এর সব টেস্ট পাস করানো।
আপনি টেস্ট চালালে ডিফল্টভাবে কেবল একটি টেস্ট (প্রথমটি) চলে।
এটি ইচ্ছাকৃত, কারণ এতে আপনি শুধু ওই একটি টেস্ট পাস করানোর দিকেই মন দিতে পারেন।
একবার সেটি পাস হয়ে গেলে, পরের টেস্টটি চালু করতে নিচের

    [[ $BATS_RUN_SKIPPED == true ]] || skip

অ্যানোটেশনগুলো কমেন্ট করে বা মুছে ফেলুন, যেগুলো অন্য টেস্টগুলোর আগে বসানো থাকে।

## স্কিপ ওভাররাইড করা

`skip` অ্যানোটেশনওয়ালা টেস্টগুলোসহ সব টেস্ট চালাতে চাইলে এভাবে চালাতে পারেন:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

টাইপিং কমাতে একটি র‍্যাপার ফাংশন ব্যবহার করা সুবিধাজনক হতে পারে, `bash`-এ এভাবে করতে পারেন:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

এরপর শুধু এভাবে টেস্ট চালান:

```bash
bats
```

## `jq`-এ ডিবাগিং

`jq`-এর সাথে একটি সুবিধাজনক [`debug`][debug] ফিল্টার আছে।
আপনার অনুশীলনীর সমাধান তৈরি করার সময় jq পাইপলাইনে তখনকার ডেটা পরীক্ষা করতে এটি ব্যবহার করুন।
আরও বিস্তারিত জানতে [ডিবাগিং ডকুমেন্ট][debugging] দেখুন।
