# সম্পর্কে

একটি *হিপ* হলো একটি কালেকশন, যা সবসময় তার সবচেয়ে ছোট (বা বড়) আইটেমটি জানে এবং সেটি দ্রুত সরিয়ে ফেলতে দেয়। এটি *প্রায়োরিটি কিউ*-এর স্বাভাবিক বাস্তবায়ন। হিপগুলি [`heaps`][heaps] ভোকাবুলারিতে থাকে।

`<min-heap>` একটি খালি হিপ তৈরি করে, যার সবচেয়ে ছোট কী (key) প্রথমে বেরিয়ে আসে; `<max-heap>` সবচেয়ে বড় কী (key) প্রথমে দেয়। প্রতিটি আইটেম একটি *মান*, যা একটি *কী (key)*-এর অধীনে সংরক্ষিত থাকে, আর এই কী (key)-ই হলো সেই প্রায়োরিটি, যার ভিত্তিতে Factor ক্রম নির্ধারণ করে:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

একটি হিপ *মিউটেবল*: `heap-push` এবং `heap-pop` এটিকে একই জায়গায় রেখেই পরিবর্তন করে।

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` সামনেরটি না সরিয়ে পড়ে; `heap-pop` সেটি সরিয়ে ফেলে এবং রিটার্ন করে; `heap-pop-all` হিপটি প্রায়োরিটি ক্রমে `{ key value }` জোড়ার একটি অ্যাসোসিয়েশন লিস্টে ঢেলে দেয়।

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

পুশ করা `O(log n)` এবং সামনেরটি পড়া `O(1)`, তাই বারবার "সবচেয়ে জরুরি আইটেমটি নিন, তারপর আরও যোগ করুন" করলেও বড় কিউয়ের জন্যও দ্রুত থাকে। বাস্তবায়নটি একটি বাইনারি হিপ, যা একটি বড় হতে পারে এমন অ্যারেতে সংরক্ষিত থাকে; কী (key) যেকোনো ক্রমযোগ্য মান হতে পারে (সংখ্যা, স্ট্রিং, …)।
