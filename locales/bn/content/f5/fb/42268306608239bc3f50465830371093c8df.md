# ভূমিকা

## রিকার্শন

কোনো কিছুকে তার নিজের সাপেক্ষে সংজ্ঞায়িত করার ক্ষমতাকে রিকার্শন বলা হয়। Gleam-এ রিকার্শন সবচেয়ে বেশি দেখা যায় রিকার্সিভ ফাংশনে, অর্থাৎ এমন ফাংশনে যা নিজেকেই কল করে।

একটি রিকার্সিভ ফাংশনে অন্তত একটি _বেস কেস_ এবং অন্তত একটি _রিকার্সিভ কেস_ থাকতে হয়। একটি _বেস কেস_ ফাংশনটিকে আবার কল না করেই একটি মান রিটার্ন করে। একটি _রিকার্সিভ কেস_ ফাংশনটিকে আবার কল করে এবং ইনপুট এমনভাবে বদলে দেয় যাতে সেটি একসময় বেস কেসের সঙ্গে মিলে যায়।

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam-এ লুপ করার জন্য কোনো বিশেষ সিনট্যাক্স নেই, তাই সব লুপিংই রিকার্শনের সাহায্যে করা হয়।

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam রিকার্সিভ কাস্টম টাইপও সমর্থন করে। একটি রিকার্সিভ কাস্টম টাইপের এক বা একাধিক ভ্যারিয়েন্ট তাদের ধারণ করা ডেটার ভেতরে নিজেকেই নির্দেশ করে।

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
