# সম্পর্কে

একটি কিওয়ার্ড লিস্ট হলো `{key, value}` [টুপল][exercism-tuples]-এর একটি অ্যারে। কিওয়ার্ড লিস্ট লেখার দুটি উপায় আছে:

```elixir
# concise
[month: "April", year: 2018]

# explicit
[{:month, "April"}, {:year, 2018}]
```

## কী (key) অবশ্যই অ্যাটম হতে হবে

প্রতিটি 2-টুপলের অ্যারে কিওয়ার্ড লিস্ট নয়। কী (key) অবশ্যই অ্যাটম হতে হবে:

```elixir
Keyword.keyword?([{"month", "April"}])
# => false
```

কী (key)-তে অক্ষর, সংখ্যা আর `_` ছাড়া অন্য কোনো ক্যারেক্টার ব্যবহার করতে চাইলে সেটিকে কোটেশনের মধ্যে রাখতে হবে। তবে এতে এটি স্ট্রিং হয়ে যায় না, এটি তখনও একটি অ্যাটমই থাকে।

[//]: # (elixir-formatter-disable-next-block)

```elixir
Keyword.keyword?(["day of week": "Monday"])
# => true
```

## কী (key) একাধিকবার থাকতে পারে

কিওয়ার্ড লিস্টে কী (key) একাধিকবার থাকতে পারে, এবং [কী-ভ্যালু জোড়াগুলো ক্রমানুসারে সাজানো থাকে][keyword-duplicate-keys-and-ordering]। কোনো নির্দিষ্ট কী (key)-এর অধীনে একটি মান পেতে চাইলে আপনি প্রথম মানটি পাবেন, আর একই কী (key)-এর অধীনের বাকি মানগুলো নীরবে উপেক্ষিত হবে।

```elixir
list = [month: "April", month: "May"]

Keyword.get_values(list, :month)
# => ["April", "May"]

Keyword.get(list, :month)
# => "April"
```

কিওয়ার্ড লিস্ট [_অ্যাক্সেস বিহেভিয়ার_][access-behaviour]-ও সমর্থন করে।

```elixir
list[:month]
# => "April"
```

## অপশন হিসেবে কিওয়ার্ড লিস্ট

কিওয়ার্ড লিস্টের বৈশিষ্ট্যগুলোর কারণেই Elixir-এ ফাংশনে অপশন পাঠানোর ডিফল্ট পদ্ধতি হয়ে দাঁড়িয়েছে এটি।

`if` সম্পর্কে শেখার সময় আপনি একটি বিশেষ ছোট সিনট্যাক্স দেখেছেন:

```elixir
if age >= 16, do: "beer", else: "no beer"
```

দেখে মনে হতে পারে `if` দুটি আর্গুমেন্ট নেয়, কিন্তু `do:` আর `else:` জোড়াটি আসলে একটি একক আর্গুমেন্ট, একটি কিওয়ার্ড লিস্ট। একই কোড এভাবে লেখা যেত:

[//]: # (elixir-formatter-disable-next-block)

```elixir
if age >= 16, [do: "beer", else: "no beer"]
# or
if age >= 16, [{:do, "beer"}, {:else, "no beer"}]
```

ফাংশনের অপশন হিসেবে কিওয়ার্ড লিস্টের ব্যবহার এতটাই সাধারণ যে Elixir-এ আপনি ফাংশনে পাঠানো [শেষ আর্গুমেন্টটি কিওয়ার্ড লিস্ট হলে তৃতীয় বন্ধনী বাদ দিতে][keyword-call-syntax] পারেন।

যেহেতু Elixir-এর সিনট্যাক্সে টুপল, অ্যারে, ম্যাপ আর অন্যান্য জিনিস ফাংশন কলের মতোই গণ্য হয়, তাই এই সুবিধাটি তাদের ক্ষেত্রেও পাওয়া যায়।

```elixir
[1, 2, three: 3]
# => [1, 2, {:three, 3}]
```

## প্যাটার্ন ম্যাচিং

সংক্ষিপ্ত সিনট্যাক্স ব্যবহার করে একটি কিওয়ার্ড লিস্টের ওপর সফলভাবে প্যাটার্ন ম্যাচিং করতে হলে আপনাকে সঠিক ক্রমে সব কী (key) উল্লেখ করতে হবে। এ কারণে কিওয়ার্ড লিস্ট নিয়ে কাজ করার সময় প্যাটার্ন ম্যাচিং খুব একটা সম্ভাব্য পছন্দ নয়। বদলে [`Keyword`][keyword] মডিউল বা [_অ্যাক্সেস বিহেভিয়ার_][access-behaviour] ব্যবহার করুন।

```elixir
[month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]

[year: year, month: month] = [month: "April", year: 2018]
# => ** (MatchError) no match of right hand side value: [month: "April", year: 2018]
```

## কিওয়ার্ড লিস্ট বনাম ম্যাপ

|                  | কিওয়ার্ড লিস্ট                  | ম্যাপ                                 |
| ---------------- | ----------------------------- | ----------------------------------- |
| কী (key)-এর ধরন  | অ্যাটম                        | যেকোনো কিছু, একই ম্যাপে মিশিয়ে রাখা যায় |
| ডুপ্লিকেট কী (key) | আছে                        | নেই                                  |
| কী (key) ক্রমানুসারে | হ্যাঁ                     | না                                  |
| অ্যাক্সেস        | `list[:key]`, `Keyword.get/2` | `map.key`, `map[:key]`, `Map.get/2` |
| অ্যাক্সেসের সময় | রৈখিক                         | লগারিদমিক                            |
| প্যাটার্ন ম্যাচিং | খুব একটা কাজে আসে না          | কাজে আসে                             |

দ্রুততর অ্যাক্সেসের সময়, নমনীয় কী (key)-এর ধরন আর কাজে আসা প্যাটার্ন ম্যাচিংয়ের কারণে বেশিরভাগ ক্ষেত্রেই ম্যাপই ডিফল্ট পছন্দ।

যখন আপনার কাছে খুব বেশি ডেটা থাকে না, কিন্তু ডুপ্লিকেট কী (key) বা নির্দিষ্ট ক্রমে সাজানো কী (key) দরকার, তখন কিওয়ার্ড লিস্ট ব্যবহার করুন।
