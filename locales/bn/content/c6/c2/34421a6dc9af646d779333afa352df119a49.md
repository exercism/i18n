# স্ট্রিং টাইপ

Cairo-তে স্ট্রিংয়ের জন্য কোনো নেটিভ ডেটা টাইপ নেই।
তবে স্ট্রিং টাইপ প্রকাশের দুটি উপায় আছে: একটি `felt252` দিয়ে শর্ট স্ট্রিং, আর `ByteArray` দিয়ে যেকোনো দৈর্ঘ্যের স্ট্রিং।

## শর্ট স্ট্রিং

শর্ট স্ট্রিং তৈরি হয় সিঙ্গেল কোট দিয়ে, যেখানে স্ট্রিংটি গঠন করা প্রতিটি ক্যারেক্টার [ASCII স্ট্যান্ডার্ড][ascii-table] অনুসরণ করে এক বাইটে এনকোড করা হয়।

একটি ASCII স্ট্রিং হিসেবে, উদাহরণস্বরূপ, `'abc'` হবে:

- `'a'` হলো `0x61`-এর সমতুল্য
- `'b'` হলো `0x62`-এর সমতুল্য
- `'c'` হলো `0x63`-এর সমতুল্য
- `'abc'` হলো `0x616263`-এর সমতুল্য

Cairo-তে `felt252` ডেটা টাইপটিই শর্ট স্ট্রিং টাইপ ধারণ করে।
যেহেতু `felt252`-এ ২৫১ বিট থাকে, তাই একটি শর্ট স্ট্রিং ৩১টি ক্যারেক্টারে সীমাবদ্ধ (৩১ \* ৮ = ২৪৮ বিট, যা ২৫১ বিটে ফিট করা ৮-এর সর্বোচ্চ গুণিতক)।

শর্ট স্ট্রিং ডিক্লেয়ারের কিছু উদাহরণ:

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

ByteArray স্ট্রাক্টটি চালু করা হয়েছিল Cairo 2.4.0-এ।
ByteArray স্ট্রিংগুলো ডাবল কোটে এভাবে লেখা হয়:

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

টেকনিক্যালি, এই আপডেটে `bytes31` টাইপও চালু করা হয়েছিল, যা ৩১ বাইট ধারণ করে এবং একটি felt-এর মধ্যে ফিট করে।
`ByteArray` স্ট্রাক্টটি মূলত লং স্ট্রিং প্রকাশ করে `bytes31`-এর একটি অ্যারে দিয়ে, যেগুলো "পূর্ণ শব্দ" (অর্থাৎ যে শব্দগুলো পুরো felt ভরে দেয়) ধারণ করে, আর একটি একক felt ফিল্ড দিয়ে, যা একটি "অসম্পূর্ণ শব্দ" ধারণ করে (এর ভেতরের বাইট সংখ্যা আলাদা length ফিল্ডে উল্লেখ করা থাকে)।

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```
