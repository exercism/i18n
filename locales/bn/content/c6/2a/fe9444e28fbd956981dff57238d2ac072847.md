# ভূমিকা

## এক্সটেনশন মেথড

এক্সটেনশন মেথড বিদ্যমান টাইপগুলোতে নতুন কোনো ডিরাইভড টাইপ তৈরি না করে, রিকম্পাইল না করে, বা মূল টাইপটি অন্যভাবে পরিবর্তন না করেই মেথড যোগ করার সুযোগ দেয়। এগুলো স্ট্যাটিক মেথড হিসেবে ডিফাইন করা হয়, কিন্তু ইনস্ট্যান্স মেথড সিনট্যাক্স ব্যবহার করে কল করা হয়। এদের প্রথম প্যারামিটারের আগে `this` মডিফায়ার থাকে এবং সেই প্যারামিটারই বলে দেয় মেথডটি কোন টাইপের উপর কাজ করে। এগুলো নেমস্পেস লেভেলে স্কোপে আনা হয়।

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
