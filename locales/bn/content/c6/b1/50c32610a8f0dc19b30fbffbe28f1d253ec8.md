# ভূমিকা

JavaScript-এ, _টেমপ্লেট স্ট্রিং_ দিয়ে স্ট্রিংয়ের ভেতরে এক্সপ্রেশন এমবেড করা যায়, যাকে স্ট্রিং ইন্টারপোলেশনও বলা হয়।
এই সুবিধাটি বিল্ট-ইন [`String`][string-reference] গ্লোবাল অবজেক্টের কার্যকারিতা বাড়িয়ে দেয়।

JavaScript-এ টেক্সট ব্যাকটিকের ভেতরে মুড়ে আপনি টেমপ্লেট স্ট্রিং তৈরি করতে পারেন।
এগুলো শুধু টেক্সটে নতুন লাইন ও অন্যান্য বিশেষ ক্যারেক্টার রাখার সুযোগ দেয় না, বরং আপনি ভ্যারিয়েবল ও অন্যান্য এক্সপ্রেশনও এমবেড করতে পারেন।

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

উপরের উদাহরণে, ব্যাকটিক - (<code>\`\`</code>) - দিয়ে একটি টেমপ্লেট স্ট্রিং বোঝানো হয়েছে। `${...}` হলো সেই প্লেসহোল্ডার, যার মাধ্যমে প্রতিস্থাপন করা হয়।
স্ট্রিং ছাড়া অন্য যেকোনো টাইপ _অন্তর্নিহিতভাবে_ স্ট্রিংয়ে রূপান্তরিত হয়।
এই বিষয়টি [টাইপ কনভার্সন][type-conversion-concept] কনসেপ্টে আলোচনা করা হয়েছে।
সব ধরনের এক্সপ্রেশনই টেমপ্লেট স্ট্রিংয়ের সাথে ব্যবহার করা যায়।

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

যখন আপনার স্ট্রিং একাধিক লাইনে সাজানো দরকার:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

প্রতিস্থাপনের সুবিধা ব্যবহার করে আপনি আউটপুট স্ট্রিংটি কী হবে তা নির্ধারণ করতে প্রক্রিয়াটিতে লজিকও যুক্ত করতে পারেন।

এর একটি উদাহরণ হলো একটি [টার্নারি অপারেটর][ternary-operator] এমবেড করা।
এই অপারেটরটি `if/else` স্টেটমেন্ট লেখার একটি সংক্ষিপ্ত রূপ।
এর সিনট্যাক্স হলো `condition ? consequent-expression : alternative-expression`।
যদি শর্তটি ট্রুথি হয়, তাহলে কোলনের বাম দিকের অপারেন্ডটি রিটার্ন করা হবে।
অন্যথায়, টার্নারি এক্সপ্রেশনের ফলাফল হয় কোলনের ডান দিকের অপারেন্ডটি।

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
