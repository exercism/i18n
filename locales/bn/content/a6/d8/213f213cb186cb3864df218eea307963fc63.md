# ভূমিকা

Haxe-এ একটি প্রপার্টি হলো ক্লাসের এমন একটি মেম্বার, যা ওই ক্লাসের ভেতরের ডেটায় অ্যাক্সেস দেয়। কলাররা এই ডেটা সেট করতে বা রিট্রিভ (গেট) করতে পারে। এগুলো একটি সেট অ্যাক্সেসর এবং/অথবা একটি গেট অ্যাক্সেসর দিয়ে গঠিত।

ক্লাসের অন্যান্য মেম্বারের মতোই প্রপার্টিগুলোরও অ্যাক্সেস মডিফায়ার (public, private ইত্যাদি) থাকে, তবে সেট অ্যাক্সেসরের অ্যাক্সেস লেভেল রিট্রিভ (গেট) অ্যাক্সেসর থেকে স্বাধীন হতে পারে, আবার উল্টোটাও। একটি প্রপার্টির দুটো অ্যাক্সেসরই থাকতে হবে এমন নয়, এতে একটিই থাকতে পারে (গেট বা সেট যেকোনোটি)।

পড়ার অ্যাক্সেস আর লেখার অ্যাক্সেস সরাসরি সিনট্যাক্সে প্রতিফলিত হয়, যেমনটি নিচের উদাহরণটি দেখাচ্ছে:

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default` আর `null` দুটোই বিশেষ **অ্যাক্সেস আইডেন্টিফায়ার**। অ্যাক্সেস আইডেন্টিফায়ারগুলো ঠিক করে দেয়, ফিল্ডটি পড়া হলে (প্রথম আইডেন্টিফায়ার) এবং ফিল্ডটি লেখা হলে (দ্বিতীয় আইডেন্টিফায়ার) কী আচরণ হবে। গৃহীত মানগুলো হলো:

- `default`: ফিল্ডটি public হলে স্বাভাবিক ফিল্ড অ্যাক্সেসের অনুমতি দেয়।
- `null`: কেবল যে ক্লাসে এটি ডিফাইন করা হয়েছে তার ভেতর থেকেই অ্যাক্সেসের অনুমতি দেয়।
- `get/set`: অ্যাক্সেসর মেথড (`get_x()`) কল করার মাধ্যমে অ্যাক্সেস তৈরি হয়।
- `dynamic`: `get/set`-এর মতোই, তবে অ্যাক্সেসর মেথডের অস্তিত্ব যাচাই করা যায় না।
- `never`: কোনোভাবেই অ্যাক্সেসের অনুমতি দেয় না।

এখানে একটি সম্পূর্ণ উদাহরণ দেওয়া হলো:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
