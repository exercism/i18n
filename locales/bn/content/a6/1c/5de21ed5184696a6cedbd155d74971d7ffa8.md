# ভূমিকা

## লেবেলযুক্ত ফিল্ড

কোনো কাস্টম টাইপের ভ্যারিয়েন্ট যখন ডেটা ধারণ করে, তখন তাকে রেকর্ড বলা হয়, আর ভেতরে থাকা প্রতিটি মান থাকে একটি _ফিল্ড_-এ।

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

পড়ার সুবিধার জন্য Gleam ফিল্ডগুলোকে একটি নাম দিয়ে লেবেল করার সুযোগ দেয়।

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

লেবেল ব্যবহার করে রেকর্ডের কনস্ট্রাক্টরে যেকোনো ক্রমে আর্গুমেন্ট দেওয়া যায়।

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

কোনো কাস্টম টাইপে যখন কেবল একটি ভ্যারিয়েন্ট থাকে, তখন রেকর্ডের ফিল্ডগুলো পেতে `.label` অ্যাক্সেসর সিনট্যাক্স ব্যবহার করা যায়।

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

কোনো কাস্টম টাইপে একটি মাত্র ভ্যারিয়েন্ট থাকলে রেকর্ড আপডেট সিনট্যাক্স ব্যবহার করে বিদ্যমান রেকর্ড থেকে নতুন একটি রেকর্ড তৈরি করা যায়, তবে কিছু ফিল্ড নতুন মান দিয়ে বদলে দেওয়া হয়।

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

রেকর্ড থেকে মান বের করতে প্যাটার্ন ম্যাচিং করার সময়ও লেবেল ব্যবহার করা যায়।

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

কেবল কিছু ফিল্ডে ম্যাচ করতে চাইলে বাকি ফিল্ডগুলো উপেক্ষা করতে স্প্রেড অপারেটর `..` ব্যবহার করা যায়।

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
