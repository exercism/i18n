# সম্পর্কে

Go স্ট্যাটিক্যালি টাইপড, তাই প্রতিটি ভ্যারিয়েবলের একটি টাইপ থাকে যা কম্পাইল টাইমে জানা যায়।
একবার ডিক্লেয়ার করা হলে ভ্যারিয়েবলটির টাইপ আর পরিবর্তন করা যায় না।

## ভ্যারিয়েবল তৈরি করা

`var` স্টেটমেন্ট একটি নতুন ভ্যারিয়েবলের টাইপ ডিক্লেয়ার করতে পারে, তার মান সেট করতে পারে, বা একসাথে দুটোই করতে পারে:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

একটি ফাংশনের ভিতরে, `:=` শর্ট অ্যাসাইনমেন্ট স্টেটমেন্টও ব্যবহার করা যায়।

```go
count := 1 // Type implictly declared, value explicitly set
```

Go-তে একটি ভ্যারিয়েবলের সবসময় একটি মান থাকে।
যদি ডিক্লেয়ার করার সময় একটি মান সেট করা না হয়, Go ভ্যারিয়েবলটির টাইপের উপর ভিত্তি করে একটি মান দেয়, [যাকে শূন্য মান বলা হয়][zero-values]।

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## ভ্যারিয়েবল আপডেট করা

একটি ফাংশনের ভিতরে, `=` অ্যাসাইনমেন্ট অপারেটর একটি বিদ্যমান ভ্যারিয়েবলের জন্য নতুন মান সেট করতে পারে:

```go
count := 1
count = 2
```

নতুন মানটি অবশ্যই ভ্যারিয়েবলটির মতো একই টাইপের হতে হবে:

```go
count := 1
count = false // compile error: a Boolean is not an int
```
