# ইটারেশন

প্রোগ্রামিংয়ে [ইটারেশন][iteration] বলতে একটি কোড ব্লক একাধিকবার পুনরাবৃত্তি করার প্রক্রিয়াকে বোঝায়।
এটি while লুপ এবং until লুপের মতো ধারণা ব্যবহার করে করা যায়।
রিকার্সন ব্যবহার করেও এটি করা যায়, যেখানে একটি ফাংশন নিজেকে নিজেই কল করে।

তবে বেশিরভাগ সময়েই আপনি একগুচ্ছ আইটেমের কলেকশনের ওপর ইটারেশন করতে চান, যেমন `Array`, `Range` বা `String`।
Crystal-এ `Array` ও `Range` ক্লাস দুটিই [`Enumerable`][enumerable] মডিউল অন্তর্ভুক্ত করে, যা এলিমেন্টের ওপর ইটারেশন করার জন্য অনেকগুলো মেথড প্রদান করে।
অন্যদিকে `String` ক্লাসের ক্যারেক্টারগুলোর ওপর ইটারেশন করার জন্য নিজস্ব কিছু মেথড রয়েছে।

Crystal-এ অন্য ভাষার মতো কোনো for স্টেটমেন্টও নেই।
পরিবর্তে এতে কয়েকটি মেথড আছে, যা দিয়ে ইটারেশন করা যায়।

## ইটারেশন করা

কলেকশনের ওপর ইটারেশন করার সবচেয়ে কমন উপায় হলো [`each`][each] মেথড ব্যবহার করা, যা কলেকশনের প্রতিটি এলিমেন্ট একটি ব্লকে প্রদান করে।
`Range` দিয়ে এটি সহজেই করা যায়।
ধরুন আপনি 1 থেকে 3 পর্যন্ত লুপ করতে চান, তাহলে রেঞ্জের ওপর ইটারেশন করার জন্য `each` মেথড ব্যবহার করতে পারেন।

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

আরও সহজভাবে, আপনি যদি শুধু নির্দিষ্ট সংখ্যক বার ইটারেশন করতে চান, তাহলে [`times`][times] মেথড ব্যবহার করতে পারেন, যা `Int` ক্লাসে আছে।

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## একটি `String`-এর ওপর ইটারেশন

একটি `String` হলো ক্যারেক্টারের একটি ক্রম, আর এটি `Enumerable` মডিউলের অন্তর্ভুক্ত নয়, অর্থাৎ ক্যারেক্টারগুলোর ওপর ইটারেশন করার জন্য এর নিজস্ব কিছু মেথড আছে।
`String`-এর ওপর ইটারেশন করার সবচেয়ে কমন উপায় হলো [`each_char`][each_char] মেথড ব্যবহার করা, যা `String`-এর প্রতিটি ক্যারেক্টার একটি ব্লকে প্রদান করে।

~~~~exercism/note
`each_char` মেথড ব্লকে একটি `Char` অবজেক্ট পাঠায়, `String` অবজেক্ট নয়।
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String`-এর ওপর ইটারেশনের আরেকটি উপায় হলো [`each_line`][each_line] মেথড ব্যবহার করা।
এই মেথডটি মূলত কোনো ফাইল লাইন ধরে ধরে পড়ার সময় ব্যবহৃত হয়।

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## `Enumerable` মডিউল অন্তর্ভুক্ত একটি অবজেক্টের ওপর ইটারেশন

[`Enumerable`][enumerable] মডিউল একটি কলেকশনের এলিমেন্টের ওপর ইটারেশন করার জন্য অনেকগুলো মেথড প্রদান করে।
`Enumerable` মডিউল অন্তর্ভুক্ত কলেকশনগুলোর মধ্যে আছে `Array`, `Range`, `Hash`, `Set` এবং আরও কিছু; পরেরগুলো পরবর্তী কনসেপ্টগুলোতে আলোচনা করা হবে।

`Array`-এর ওপর ইটারেশন করার সবচেয়ে কমন উপায় হলো [`each`][each] মেথড ব্যবহার করা, যা `Array`-এর প্রতিটি এলিমেন্ট একটি ব্লকে প্রদান করে।

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map] মেথড `Array`-এর ওপর ইটারেশনের আরেকটি উপায়; এটি প্রতিটি এলিমেন্টে ব্লক প্রয়োগের ফলাফল নিয়ে একটি নতুন `Array` রিটার্ন করে।
এটি `each` মেথডের মতোই, তবে এটি রূপান্তরিত এলিমেন্ট নিয়ে একটি নতুন `Array` রিটার্ন করে।
কলেকশনের প্রতিটি এলিমেন্টে একটি ফাংশন প্রয়োগ করতে চাইলে রূপান্তর বেশ কাজে লাগে, যা একটি কমন কাজ।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if`-এর মতো কন্ট্রোল ফ্লো ব্যবহার করেও আপনি কোন এলিমেন্টগুলো রূপান্তর করবেন তা ফিল্টার করতে পারেন।

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## শর্টহ্যান্ড

Crystal-এ কলেকশনের প্রতিটি এলিমেন্টে ইটারেশন করে একটি মেথড প্রয়োগ করার একটি শর্টহ্যান্ড সিনট্যাক্স আছে।
সরল লজিক নিয়ে কাজ করার সময় এটি কাজে লাগে, যেখানে শুধু একটি মেথড দিয়ে রূপান্তর করলেই চলে।
এটি করা হয় `&.` সিনট্যাক্স ব্যবহার করে, যার পরে মেথডের নাম বসে।

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### ইনডেক্স-সহ

কখনো কখনো আপনি যে এলিমেন্টের ওপর ইটারেশন করছেন তার ইনডেক্স জানার দরকার হয়; সে জন্য [`each_with_index`][each_with_index] বা [`map_with_index`][map_with_index] মেথড ব্যবহার করতে পারেন।
এটি প্রতিটি এলিমেন্ট ও তার ইনডেক্স একটি ব্লকে প্রদান করে; মেথডটি শুরুর ইনডেক্স নির্দিষ্ট করার জন্য একটি ঐচ্ছিক আর্গুমেন্টও গ্রহণ করে।

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

মনে রাখবেন, [`each_char_with_index`][each_char_with_index] মেথডটি `String` অবজেক্টের জন্যও পাওয়া যায়।

### sum

[`sum`][sum] মেথড কলেকশনের সব এলিমেন্টের যোগফল রিটার্ন করে; এটি যোগ করার আগে এলিমেন্টগুলো রূপান্তর করার জন্য একটি ঐচ্ছিক ব্লকও গ্রহণ করে।
এটি যোগফলের প্রাথমিক মান নির্দিষ্ট করার জন্য একটি ঐচ্ছিক আর্গুমেন্টও গ্রহণ করে।

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], যা অন্য ভাষায় fold নামে পরিচিত, এমন একটি মেথড যা একটি কম্বাইন মেথড ও একটি প্রাথমিক মান নিয়ে কলেকশনের সব এলিমেন্ট একত্র করে।
`reduce` মেথডে একটি অ্যাকুমুলেটর থাকে যা ব্লকে পাস করা হয়; অ্যাকুমুলেটর হলো পূর্ববর্তী ইটারেশনের ফলাফল।
এভাবে এটি একটি রিকার্সিভ প্রক্রিয়া হয়ে ওঠে, যা কলেকশনের সব এলিমেন্ট একত্র করে।

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` হয়তো `sum`-এর মতো মনে হতে পারে, কিন্তু `reduce` আরও নমনীয়, কারণ এটি অ্যাকুমুলেটরের প্রাথমিক মান এবং কম্বাইন মেথড নির্দিষ্ট করার সুযোগ দেয়।
`reduce` দিয়ে `sum`, `count` এবং অন্যান্য মেথড তৈরি করা যায়।
