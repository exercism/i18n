# ইঙ্গিত

এই সব কাজের জন্যই আপনার `print` কমান্ডটি দরকার হবে:
```awk
{print "something", "something else"}
```

## 1. ইউজারনেমগুলো তালিকাভুক্ত করুন

* ফিল্ড সেপারেটর নির্ধারণ করতে [`FS` ভ্যারিয়েবলটি][var-fs] ব্যবহার করুন।

## 2. লাইন নম্বরগুলো প্রিন্ট করুন

* লাইন নম্বর পেতে [বিল্ট-ইন ভ্যারিয়েবল `NR`][var-nr] ব্যবহার করুন।

## 3. অবৈধ হোম ডিরেক্টরিযুক্ত রেকর্ডগুলো প্রিন্ট করুন।

* হোম ডিরেক্টরি হলো ষষ্ঠ ফিল্ড।
* প্রদত্ত `startsWith` ফাংশনটি ব্যবহার করুন।
* [বুলিয়ান অপারেটরগুলো][boolean-ops] ব্যবহার করুন: `&&`, `||`, `!`।

## 4. bash ব্যবহার করে এমন বৈধ ইউজারের সংখ্যা প্রিন্ট করুন

* লগইন শেল হলো শেষ ফিল্ড; আপনি [`NF` ভ্যারিয়েবলটি][var-nf] ব্যবহার করতে পারেন।

[var-nf]: https://www.gnu.org/software/gawk/manual/html_node/Auto_002dset.html#index-NF-variable-2
[var-nr]: https://www.gnu.org/software/gawk/manual/html_node/Auto_002dset.html#index-NR-variable-1
