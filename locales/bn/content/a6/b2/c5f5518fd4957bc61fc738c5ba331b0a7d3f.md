# পরিচিতি

## ট্রুথি এবং ফলসি

Common Lisp-এ `()` ছাড়া বাকি সব মানই "ট্রু", আর `()` হলো "ফলস"।
এখানে দুটি বিশেষ ধ্রুবক সিম্বল আছে, `t` এবং `nil`, যাদের মান যথাক্রমে ট্রু এবং ফলস।

## কন্ডিশনাল

Common Lisp কয়েক রকমের কন্ডিশনাল এক্সপ্রেশন দেয়, যাদের মূল পার্থক্য হলো তারা কতগুলো ব্রাঞ্চ সমর্থন করে।

- `when` এবং `unless` একটি মাত্র ব্রাঞ্চের সুযোগ দেয়:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

টেস্ট এক্সপ্রেশনের পরের অংশে একের বেশি এক্সপ্রেশনও থাকতে পারে।

- `if` ক্লাসিক if-then-else কাঠামোটি দেয়:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

মনে রাখবেন, then ও else দুটি ক্লজই কেবল একটি করে এক্সপ্রেশন হতে পারে।

- `cond` `if` এক্সপ্রেশন নেস্ট না করেই একাধিক ব্রাঞ্চ রাখার একটি উপায় দেয়:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

মনে রাখবেন, টেস্ট এক্সপ্রেশনের পরে এক্সপ্রেশনের সংখ্যার কোনো সীমা নেই।

- `case` ক্লাসিক 'switch' ধরনের একটি কাঠামো দেয়: এটি একটি মানকে কয়েকটি ব্রাঞ্চের সাথে মিলিয়ে দেখে:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

মনে রাখবেন, `cond`-এর মতোই এখানেও টেস্ট এক্সপ্রেশনের পরে এক্সপ্রেশনের সংখ্যার কোনো সীমা নেই।
