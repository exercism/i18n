# সম্পর্কে

Gleam Erlang ভার্চুয়াল মেশিনে (BEAM) রান করতে পারে, আবার JavaScript রানটাইমেও চালানো যায়। এই রানটাইমগুলো ব্যবহার করে এমন আরও অনেক ভাষা রয়েছে, আর ওই ভাষাগুলোতে লেখা কোড Gleam থেকে কল করতে পারা অনেক সময়ই কাজে লাগে।

Gleam-এর _এক্সটার্নাল ফাংশন_ ফিচারটি দিয়ে অন্য ভাষার ফাংশন Gleam-এ ইমপোর্ট করা যায় এবং কোনো রানটাইম ওভারহেড ছাড়াই সেগুলো কল করা যায়।

আপনার Gleam প্রজেক্ট যদি Erlang ভার্চুয়াল মেশিনে চলে আর আপনি Erlang-এর `lists` মডিউলের `reverse` ফাংশনটি কল করতে চান, তাহলে এভাবে একটি Gleam ফাংশনের হেডে `@external` অ্যাট্রিবিউট যোগ করে তা করতে পারেন:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

এরপর এটিকে একটি সাধারণ Gleam ফাংশন হিসেবে কল করা যায়:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

আপনি যদি এই কোডটি JavaScript রানটাইমের জন্য কম্পাইল করার চেষ্টা করেন, তাহলে এটি একটি এরর মেসেজ নিয়ে ফেল করবে, কারণ JavaScript-এর জন্য কোনো ইমপ্লিমেন্টেশন নেই। JavaScript রানটাইমের জন্য এভাবে আরেকটি ইমপ্লিমেন্টেশন উল্লেখ করা যায়:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

এমন একটি Gleam ইমপ্লিমেন্টেশন লেখাও সম্ভব, যা বর্তমান কম্পাইল টার্গেটের জন্য কোনো এক্সটার্নাল ইমপ্লিমেন্টেশন না থাকলে ব্যবহার করা হবে:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
