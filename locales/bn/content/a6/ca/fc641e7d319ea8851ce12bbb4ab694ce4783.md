# ভূমিকা

Common Lisp-এ সিম্বল হলো বিশেষ মান, যেগুলো অন্য মানের দিকে নির্দেশ করতে পারে, অথবা _কিওয়ার্ড_-এর ক্ষেত্রে নিজেদের দিকেও।
Lisp যখন সিম্বলগুলো মূল্যায়ন করে, তখন সেগুলো যে মানের দিকে নির্দেশ করে, সেই মান দিয়ে প্রতিস্থাপিত হয়:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

লক্ষ্য করুন, কিওয়ার্ডগুলোকে শুরুর কোলন (`:`) দিয়ে বোঝানো হয়।

কোটিং, অর্থাৎ একটি S-এক্সপ্রেশনের আগে `'` যোগ করা, Lisp-কে ওই এক্সপ্রেশনটি মূল্যায়ন না করতে বলে।
আমাদের `defun` উদাহরণে `'foo` কোট করার মাধ্যমে আমরা Lisp-কে `FOO` যে মানের দিকে নির্দেশ করার কথা ছিল সেটি খোঁজার চেষ্টা (এবং তা খুঁজে বের করতে ব্যর্থ হওয়া) থেকে বিরত রেখেছি; বরং `FOO` মানটি নিজেই রিটার্ন করেছি।
যদি আমাদের প্রোগ্রামে `FOO` কোথাও ডিফাইন করা না থাকে:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

আপাতত আপনি এটাকে শুধু একটি ফাংশন থেকে সিম্বল রিটার্ন করার উপায় হিসেবে ভাবতে পারেন, তবে আমরা কোটিং নিয়ে আবার আলোচনা করব এবং ভবিষ্যতের ধারণা অনুশীলনীতে এর প্রভাবগুলো আরও বিশদে খতিয়ে দেখব।
