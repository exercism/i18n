# ভূমিকা

F#-এ শর্তসাপেক্ষে কোড চালানোর সবচেয়ে কমন উপায় হলো একটি `if/elif/else` এক্সপ্রেশন ব্যবহার করা:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

একটি `if/elif/else` এক্সপ্রেশনে ব্যবহৃত শর্ত অবশ্যই `bool` টাইপের হতে হবে। F#-এ _ট্রুথি_ মানের কোনো ধারণা নেই।
