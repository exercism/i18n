# বিস্তারিত

Go-তে মৌলিক সংখ্যাসূচক টাইপ রয়েছে, যা ইন্টিজার অথবা ফ্লোটিং-পয়েন্ট মানের সেট প্রকাশ করতে পারে। আপনার প্রয়োজনীয় মানের আকার এবং যে কম্পিউটারে অ্যাপ্লিকেশনটি চলছে তার আর্কিটেকচার অনুযায়ী (যেমন 32-bit ও 64-bit) টাইপ আলাদা আলাদা হয়।

এই পাতায় দুইটি সংখ্যার টাইপ নিয়ে আলোচনা করা হবে:

- `int`: যেমন `0`, `255`, `2147483647`।
   একটি সাইনড ইন্টিজার, যার আকার কমপক্ষে 32 bits (মানের পরিসীমা: -2147483648 থেকে 2147483647)।
   তবে এটি সিস্টেমের আর্কিটেকচারের উপর নির্ভর করে।
   বেশিরভাগ আধুনিক কম্পিউটার 64-bit, তাই `int`-এর আকার হয় 64 bits (মানের পরিসীমা: -9223372036854775808 থেকে 9223372036854775807)।

- `float64`: যেমন `0.0`, `3.14`।
   এতে সব 64-bit ফ্লোটিং-পয়েন্ট সংখ্যার সেট রয়েছে।

উপলব্ধ সংখ্যাসূচক টাইপের সম্পূর্ণ তালিকা ও আরও বিস্তারিত জানতে নিচের রিসোর্সগুলো দেখুন:

- [Go-এর বিল্ট-ইন টাইপ ডিক্লারেশন][go-builtins]
- [Digital Ocean - Go-তে ডেটা টাইপ বোঝা][do-understanding-types]
- [Arden Labs - Go-তে টাইপ বোঝা][arden-understanding-types]

Go সাধারণ গাণিতিক অপারেটরগুলোর সেট সমর্থন করে: `+`, `-`, `*`, `/` এবং `%` (ভাগশেষ, মডুলো নয়)।

Go-তে ভিন্ন টাইপের মধ্যে মানের অ্যাসাইনমেন্টের জন্য স্পষ্ট কনভার্সন দরকার। যেমন, একটি `int`-কে `float64`-এ কনভার্ট করতে হলে আপনাকে নিচের কাজটি করতে হবে:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
