# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                                   |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | নাল-টার্মিনেটেড প্রশ্ন স্ট্রিং            |
| `$v0`    | আউটপুট       | ইন্টিজার | ফলাফল, প্রশ্নটি বৈধ না হলে 0             |
| `$t0-9`  | সাময়িক      | যেকোনো  | সাময়িক স্টোরেজের জন্য                  |
