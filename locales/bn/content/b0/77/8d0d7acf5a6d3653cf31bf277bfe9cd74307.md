# Bash মাইনসুইপার অনুশীলনীর হিন্ট

এই অনুশীলনীর জন্য একটি দ্বিমাত্রিক অ্যারে দরকার বলে মনে হয়।
Bash কেবল একমাত্রিক ইনডেক্সড বা অ্যাসোসিয়েটিভ [অ্যারে][array] দেয়।

বহুমাত্রিক অ্যারে অনুকরণ করা যায় একটি অ্যাসোসিয়েটিভ অ্যারে দিয়ে: অ্যারের কী (key) হিসেবে ব্যবহারের জন্য ইনডেক্সগুলোকে কমা দিয়ে আলাদা করা একটি স্ট্রিংয়ে এনকোড করুন।

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
