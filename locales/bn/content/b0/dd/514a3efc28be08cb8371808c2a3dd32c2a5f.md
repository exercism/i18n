# নির্দেশনা

এই অনুশীলনীতে আপনি একটি যানবাহন কেনার প্রস্তুতি নিতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার তিনটি কাজ আছে: একটি হলো আপনার লাইসেন্স নেওয়ার প্রয়োজন হবে কি না তা নির্ধারণ করা, একটি হলো দুটি যানবাহনের মধ্যে বেছে নিতে সাহায্য করা, আর একটি হলো ব্যবহৃত যানবাহনের গ্রহণযোগ্য দাম অনুমান করা।

## 1. আপনার ড্রাইভিং লাইসেন্সের প্রয়োজন হবে কি না তা নির্ধারণ করুন

কিছু ধরনের যানবাহন চালানোর জন্য ড্রাইভিং লাইসেন্স প্রয়োজন।
ধরে নিন শুধু `'car'` এবং `'truck'` ধরনের যানবাহনের লাইসেন্স প্রয়োজন, বাকি সব লাইসেন্স ছাড়াই চালানো যায়।

`needsLicense(kind)` ফাংশনটি তৈরি করুন, যা যানবাহনের ধরন নেয় এবং সেই ধরনের যানবাহনের জন্য আপনার লাইসেন্স প্রয়োজন কি না তা নির্দেশ করে একটি বুলিয়ান রিটার্ন করে।

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. কেনার জন্য সম্ভাব্য দুটি যানবাহনের মধ্যে বেছে নিন

আপনি উপলব্ধ যানবাহনগুলোর মধ্যে থেকে আপনার বিকল্পগুলো মূল্যায়ন করেন।
আপনি সেটি দুটি বিকল্পে নামিয়ে আনতে পারেন, কিন্তু চূড়ান্ত সিদ্ধান্ত নিতে আপনার সাহায্য দরকার।
সেজন্য `chooseVehicle(option1, option2)` ফাংশনটি তৈরি করুন, যা দুটি যানবাহন আর্গুমেন্ট হিসেবে নেয় এবং অভিধানের ক্রম অনুসারে আগে আসা বিকল্পটি অন্তর্ভুক্ত একটি সিদ্ধান্ত রিটার্ন করে।

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. ব্যবহৃত যানবাহনের দামের আনুমানিক হিসাব করুন

এখন যেহেতু আপনি সিদ্ধান্ত নিয়েছেন, আপনি নিশ্চিত হতে চান যে ডিলারশিপে আপনি ন্যায্য দাম পাবেন।
যেহেতু আপনি একটি ব্যবহৃত যানবাহন কিনতে আগ্রহী, দামটি নির্ভর করে যানবাহনটির বয়সের উপর।
মোটামুটি হিসাবের জন্য ধরে নিন, যানবাহনটির বয়স ৩ বছরের কম হলে, এর দাম হয় এটি একেবারে নতুন থাকা অবস্থায় যে মূল দাম ছিল তার ৮০%।
এর বয়স ১০ বছরের বেশি হলে, দাম হয় মূল দামের ৫০%।
যানবাহনটির বয়স কমপক্ষে ৩ বছর কিন্তু ১০ বছরের বেশি নয় হলে, এর দাম হয় মূল দামের ৭০%।

`calculateResellPrice(originalPrice, age)` ফাংশনটি তৈরি করুন, যা `if`, `else if` এবং `else` ব্যবহার করে এই লজিক প্রয়োগ করে (আপনি যদি অনুশীলন করতে চান, অন্য উপায়ও আছে)।
এটি মূল দাম এবং যানবাহনের বয়স আর্গুমেন্ট হিসেবে নেয় এবং ডিলারশিপে আনুমানিক দাম রিটার্ন করে।

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
