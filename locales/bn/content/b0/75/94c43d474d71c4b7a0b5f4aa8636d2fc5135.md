# পরিচিতি

## `while` লুপ

যতক্ষণ একটি নির্দিষ্ট শর্ত পূরণ হয়, ততক্ষণ আপনি একটি `while` লুপ দিয়ে কোড বারবার চালাতে পারেন।
এটি লেখা হয় `while` কিওয়ার্ড দিয়ে, তারপর প্রথম বন্ধনীতে মোড়া একটি শর্ত এবং দ্বিতীয় বন্ধনীতে মোড়া একটি কোড ব্লক, যেখানে লুপের _বডি_ থাকে।

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript-এ ডু-হোয়াইল লুপও আছে।
এখানে লুপের বডি চালানোর পরে শর্তটি যাচাই করা হয়।
শর্তটি যখন বডিতে করা গণনার ওপর নির্ভর করে, তখন এটি কাজে লাগে।

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

লুপের বডির ভেতরে আপনি `break` কিওয়ার্ড ব্যবহার করে লুপের এক্সিকিউশন সম্পূর্ণ থামাতে পারেন।
এর বিপরীতে, `continue` কিওয়ার্ড কেবল বর্তমান ইটারেশনের এক্সিকিউশন থামায় এবং পরের ইটারেশনে চলে যায়।
`continue` ব্যবহার করে আপনি প্রায়ই লুপের বডির বড় অংশকে একটি `if` স্টেটমেন্টে মোড়ানো এড়াতে পারেন।

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## `switch` স্টেটমেন্ট

`if` স্টেটমেন্টের পাশাপাশি JavaScript-এ শর্তসাপেক্ষে লজিক চালানোর জন্য `switch` স্টেটমেন্টও আছে।
এটি ব্যবহার করা হয় যখন একটি ভ্যারিয়েবলকে একাধিক বিকল্পের সঙ্গে তুলনা করতে হয়।
তুলনাটি করা হয় কঠোর সমতা (`===`) যাচাই করে, দেখুন [তুলনা ধারণা][concept-comparison]।
কোনো ভ্যারিয়েবল `x`-এর জন্য JavaScript-এ `switch` স্টেটমেন্টের সিনট্যাক্স নিচের মতো।

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default` কেসটি ঐচ্ছিক; অন্য কোনো অপশন ভ্যারিয়েবলের সঙ্গে না মিললে আপনি যদি কিছু কোড চালাতে চান, সেক্ষেত্রে এটি ব্যবহার করা হয়।

উপরের `break` স্টেটমেন্টগুলো দরকার, কারণ JavaScript-এ ডিফল্টভাবে সব কেস "ফলথ্রু"।
এর মানে হলো, কোনো `break` স্টেটমেন্ট না থাকলে প্রথম যে অপশনটি মিলেছে তার নিচের সব কেসের কোডই চালানো হবে, যদিও `x` ওই অপশনগুলোর সঙ্গে মেলেনি।
JavaScript-এ `switch` ব্যবহার করার সময় এই "ডিফল্টভাবে ফলথ্রু" আচরণ একটি কমন বিপদ।
একটি ফাংশনের ভেতরে এই সমস্যা এড়াতে `break`-এর বদলে `return`-ও ব্যবহার করা যায়।
