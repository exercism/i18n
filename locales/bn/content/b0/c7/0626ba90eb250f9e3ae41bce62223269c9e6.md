# নির্দেশনা

প্রপোজিশনাল লজিক ব্যবহার করে নিচের বৈশিষ্ট্যগুলো পুনরায় তৈরি করার জন্য একটি ফাংশন ইমপ্লিমেন্ট করুন:

1. A & B == (A' | B')' (ডি মরগানের সূত্র)
2. [A -> (A -> B)] -> (A -> B)
3. A & (B' -> A') -> B

ফাংশনটি Z3 নোটেশনে লেখা তিনটি উপপাদ্য রিটার্ন করবে।  
আপনার উপপাদ্যগুলোর সঠিকতা নিশ্চিত করতে prove() ফাংশনটি ব্যবহার করুন।  
ফাংশনের শেষে ক্রমানুসারে তিনটি উপপাদ্য রিটার্ন করুন।
