# পরিচিতি

## JSON

[JSON][json] (JavaScript Object Notation) একটি মানুষের পড়ার উপযোগী ডেটা ও ফাইল ফরম্যাট, যা সাধারণত ডেটা বিনিময়ের জন্য ব্যবহৃত হয়, বিশেষ করে ওয়েব অ্যাপ্লিকেশনের ক্ষেত্রে।
তাই Elm ভাষায় এর বিশেষ একটি স্থান আছে, এতে অবাক হওয়ার কিছু নেই।

Elm JSON ডেটা পার্স ও লেখার জন্য [`Json.Decode`][decode] এবং [`Json.Encode`][encode] নামের কোর মডিউল সরবরাহ করে।
JSON ডিকোডার হলো একধরনের উপায়, যার মাধ্যমে _ঘোষণা_ করা হয় কী ধরনের ডেটা প্রত্যাশিত এবং ডেটাটি কোন ডেটা স্ট্রাকচারে রূপান্তরিত হওয়া উচিত।

ডায়নামিক টাইপের ভাষা থেকে আসা মানুষের কাছে ডিকোডারগুলো প্রায়ই প্রথম দেখায় জটিল বা অতিরিক্ত কঠোর মনে হয়।
এগুলো যে বাগাড়ম্বরপূর্ণ, তা ঠিক, অন্তত Elm-এ, তবু আগত ডেটার ব্যাপারে প্রোগ্রামের প্রত্যাশা স্পষ্টভাবে বর্ণনা করার জন্য এগুলো একটি মূল্যবান হাতিয়ার, এবং [ডায়নামিক টাইপের চেয়ে কম প্রকাশক্ষম নয়][dynamic-types-not-more-open]।

চলুন মডিউলগুলো থেকে কিছু অ্যালিয়াস ও টাইপ ইমপোর্ট করি:

```elm
import Json.Decode as Decode exposing (Decoder, Error)
import Json.Encode as Encode exposing (Value)
```

একটি ডিকোডার ও একটি JSON স্ট্রিং নিয়ে `Decode.decodeString : Decoder a -> String -> Result Error a` ব্যবহার করলে, স্ট্রিংটি যদি ডিকোডারের নির্দিষ্ট নিয়ম মেনে চলে তাহলে সফল হবে, নাহলে ব্যর্থ হবে।
ডিকোডার লেখার সময় কাঁচা JSON ডেটা পরীক্ষা করার কোনো উপায় নেই, যা ইমপেরেটিভ ভাষা থেকে আসা কারও কাছে অস্বাভাবিক লাগতে পারে।

## মৌলিক ডেটা টাইপের ডিকোডার

JSON-এ অল্প কিছু কোর ডেটা টাইপ আছে:

- স্ট্রিং: ডাবল কোটেশন দিয়ে এনকোড করা হয় `"hello world"`
- বুলিয়ান: হয় `true`, নাহয় `false`
- সংখ্যা: যেমন `34` বা `0.12`
- নাল: ডেটার অনুপস্থিতি `null`

এদের প্রত্যেকটির সাথে একটি `Decode` ফাংশন যুক্ত আছে:

```elm
Decode.decodeString Decode.string """\"hello\""""
    --> Ok "hello"

Decode.decodeString Decode.string """null"""
    --> Err ...

Decode.decodeString Decode.bool """true"""
    --> Ok True

Decode.decodeString Decode.bool """0"""
    --> Err ...

Decode.decodeString Decode.int """12"""
    --> Ok 12

Decode.decodeString Decode.float """3.14"""
    --> Ok 3.14

Decode.decodeString (Decode.null AnyValue) """null"""
    --> Ok AnyValue

Decode.decodeString (Decode.null AnyValue) """true"""
    --> Err ...
```

লক্ষ্য করুন, `Decode.null` আর্গুমেন্ট হিসেবে যেকোনো মান চেয়ে নেয় (হয়তো `()`, `Nothing`, বা আপনার প্রোগ্রামের জন্য উপযুক্ত যেকোনো কিছু), ফলে `null`-কে আপনার প্রোগ্রামে কীভাবে মডেল করবেন তা আপনি নিজেই ঠিক করতে পারেন।

## ডিকোডার একত্র করা

কোর ডেটা টাইপগুলো একত্র করার জন্য JSON আরও দুটি ডেটা স্ট্রাকচার সংজ্ঞায়িত করে:

- অ্যারে: অন্যান্য ডেটা টাইপের একটি সংগ্রহ `[0, null, "none", []]`
- অবজেক্ট: কী (key)-ভ্যালু জোড়ার একটি সংগ্রহ `{"id": 1, "is_admin": false, "more_info": {}}`

এগুলো ডিকোড করার জন্যও `Decode` ফাংশন দেয়:

```elm
Decode.decodeString (Decode.list Decode.int) """[1, 2, 3]"""
    --> Ok [1, 2, 3]

Decode.decodeString (Decode.list Decode.int) """[1, 2, 3, "not an int"]"""
    --> Err ...

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": 71 }"""
    --> Ok (Dict.fromList [("key1", 17), ("key2", 71)])

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": "seventy-one" }"""
    --> Err ...
```

এই ফাংশনগুলো, `Decode.list : Decoder a -> Decoder (List a)` এবং `Decode.dict : Decoder a -> Decoder (Dict String a)`, প্রত্যেকটিই আর্গুমেন্ট হিসেবে একটি ডিকোডার চায়, যা দিয়ে ডেটা স্ট্রাকচারের প্রতিটি এলিমেন্ট ডিকোড করার প্রত্যাশা করা হয়।
আর্গুমেন্ট ডিকোডারটি যদি কোনো অ্যারে বা অবজেক্ট মানের যেকোনো এলিমেন্ট ডিকোড করতে ব্যর্থ হয়, তাহলে পুরো ডিকোডারটিই ব্যর্থ হয়, যা একটি কমন প্যাটার্ন।

সরল ডিকোডারকে আরও জটিল ডিকোডারে পরিণত করাই এই কৌশলের মূল ধারণা।
একটি উদাহরণের মাধ্যমে আমরা আরও কিছু ফাংশন চিনব, যা দিয়ে যত খুশি জটিল বাস্তব-জগতের ডেটা ডিকোডার তৈরি করা যায়।

## GeoJSON

জটিল JSON ডেটা পার্স করার জন্য মৌলিক ডিকোডার একত্র করার অনুশীলন করতে, চলুন (GeoJSON ডেটার একটি অংশ) পার্স করার জন্য ডিকোডার তৈরি করি।
[GeoJSON][geojson] হলো JSON-ভিত্তিক একটি বিশেষায়িত ডেটা ফরম্যাট, যা ভৌগোলিক বৈশিষ্ট্য, যেমন অবস্থান, পথ বা অঞ্চল উপস্থাপন করতে ব্যবহৃত হয়, যেগুলো 2D বা 3D ভৌগোলিক কোঅর্ডিনেট ও অন্যান্য প্রোপার্টি দিয়ে নির্দিষ্ট করা হয়।

### জিওমেট্রি অবজেক্ট

একটি GeoJSON জিওমেট্রি অবজেক্ট হলো এমন একটি অবজেক্ট, যাতে একটি স্ট্রিং মানসহ একটি `type` ফিল্ড থাকে (type-এর সম্ভাব্য মান ৭টি) এবং ভৌগোলিক কোঅর্ডিনেটসহ একটি `coordinates` ফিল্ড থাকে (যেগুলো type-এর উপর নির্ভরশীল একটি স্ট্রাকচারে সংগৃহীত হয়)।
যেমন,

```json
{
  "type": "Point",
  "coordinates": [127.831, 26.461]
}
```

অথবা

```json
{
  "type": "LineString",
  "coordinates": [
    [127.831, 26.461],
    [127.829, 26.465],
    [127.829, 26.469],
    [127.83, 26.47]
  ]
}
```

একটি জিওমেট্রি অবজেক্ট Elm-এ নিচের টাইপ দিয়ে প্রকাশ করা যায়

```elm
type Geometry
  = Point (List Float)
  | LineString (List (List Float))
  | ...
```

কোনো নির্দিষ্ট ফিল্ডের মান পরীক্ষা করতে আমরা `Decode.field : String -> Decoder a -> Decoder a` ব্যবহার করতে পারি, যা একটি অবজেক্টের নির্দিষ্ট কী (key)-এর মান ডিকোড করে।

```elm
decodePointCoordinates : Decoder (List Float)
decodePointCoordinates =
    Decode.field "coordinates" (Decode.list Decode.float)

decodeLineStringCoordinates : Decoder (List (List Float))
decodeLineStringCoordinates =
    Decode.field "coordinates" (Decode.list (Decode.list Decode.float))
```

একটি ডিকোডার সফলভাবে যে মান পার্স করেছে তা রূপান্তর করতে আমরা `Decode.map : (a -> value) -> Decoder a -> Decoder value`, বা তার সহোদর যেকোনোটি, `Decode.map2  (a -> b -> value) -> Decoder a -> Decoder b -> Decoder value` থেকে `Decode.map8` পর্যন্ত ব্যবহার করতে পারি।

এই ক্ষেত্রে `type` ফিল্ডের মানের উপর নির্ভর করে কোন কোঅর্ডিনেট ডিকোডার ব্যবহার করব তা আমাদের ঠিক করতে হবে, আর এর জন্য `Decode.andThen : (a -> Decoder b) -> Decoder a -> Decoder b` এবং তার সঙ্গীরা, অর্থাৎ `Decode.succeed : a -> Decoder a` ও `Decode.fail : String -> Decoder a` একেবারে উপযুক্ত।

```elm
decodeGeometry : Decoder Geometry
decodeGeometry =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                case value of
                    "Point" ->
                        decodePointCoordinates |> Decode.map Point

                    "LineString" ->
                        decodeLineStringCoordinates |> Decode.map LineString

                    _ ->
                        Decode.fail "Geometry not implemented yet, or invalid type value"
            )
```

এখানে লক্ষ্য করুন, কোঅর্ডিনেট যাচাই করতেও আমরা `Decode.andThen` ব্যবহার করতে পারতাম (যেমন কোঅর্ডিনেটগুলো জোড়া বা ত্রিপল আকারে আসছে কি না, এবং কোঅর্ডিনেটের মানগুলো ভৌগোলিকভাবে অর্থপূর্ণ কি না তা যাচাই করা)।

```elm
Decode.decodeString decodeGeometry """{"type": "Point", "coordinates": [127.831, 26.461]}"""
    --> Ok (Point [127.831, 26.461])

Decode.decodeString decodeGeometry """{"type": "LineString", "coordinates": [127.831, 26.461]}"""
    --> Err ...
```

### ফিচার অবজেক্ট

একটি GeoJSON ফিচার অবজেক্ট স্থানিকভাবে আবদ্ধ কোনো কিছু উপস্থাপন করে: এতে `"Feature"` মানসহ একটি `type` ফিল্ড, একটি জিওমেট্রি অবজেক্ট বা `null` ধারণকারী একটি `geometry` ফিল্ড, যেকোনো JSON অবজেক্ট বা `null` ধারণকারী একটি `properties` ফিল্ড, এবং JSON স্ট্রিং বা সংখ্যা মানসহ একটি ঐচ্ছিক `id` ফিল্ড থাকে।

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": null
}
```

অথবা

```json
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
```

চলুন প্রথমে `id` ফিল্ডটি নিয়ে কাজ করি।
এটি যদি থাকে, তাহলে স্ট্রিং বা সংখ্যা দুটোই ধারণ করতে হবে, তাই আমরা হয় মানটির জন্য একটি কাস্টম টাইপ চালু করতে পারি, নাহলে সবসময় এটিকে স্ট্রিং হিসেবে সংরক্ষণ করতে পারি।

দুটি সম্ভাব্য ডিকোডারের মধ্যে বেছে নিতে আমরা `Decode.oneOf : List (Decoder a) -> Decoder a` ব্যবহার করতে পারি।

```elm
decodeFeatureId : Decoder String
decodeFeatureId =
    Decode.oneOf
        [ Decode.string
        , Decode.int |> Decode.map String.fromInt
        , Decode.float |> Decode.map String.fromFloat
        ]
        |> Decode.field "id"

Decode.decodeString decodeFeatureId """{"id": "seventeen"}"""
    --> Ok "seventeen"

Decode.decodeString decodeFeatureId """{"id": 17}"""
    --> Ok "17"

Decode.decodeString decodeFeatureId """{"type": "Point"}"""
    --> Er ...
```

ফিল্ডটি ঐচ্ছিক বোঝাতে আমরা একই কৌশল ব্যবহার করতে পারি

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.oneOf
        [ decodeFeatureId |> Decode.map Just
        , Decode.succeed Nothing
        ]
```

কিন্তু এর বদলে আমরা `Decode.maybe : Decoder a -> Decoder (Maybe a)` ব্যবহার করতে পারি

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.maybe decodeFeatureId

Decode.decodeString decodeMaybeFeatureId """{"id": 17}"""
    --> Ok (Just "17")

Decode.decodeString decodeMaybeFeatureId """{"type": "Point"}"""
    --> Ok Nothing
```

লক্ষ্য করুন, `decodeMaybeFeatureId` (বা `Decode.maybe` দিয়ে মোড়ানো যেকোনো ডিকোডার) সবসময় সফল হবে, কারণ এটি সবসময় `Ok Nothing`-এ ফিরে যেতে পারে, যদিও এটি ব্যবহার করা কোনো ডিকোডার এখনও ব্যর্থ হতে পারে

```elm
Decode.decodeString (Decode.list decodeMaybeFeatureId) """{"id": 17}"""
    --> Err ...
```

এরপর চলুন `geometry` ফিল্ডে মনোযোগ দিই, যা হয় একটি জিওমেট্রি অবজেক্ট হতে পারে, নাহয় `null` হতে পারে।
আবারও আমরা `Decode.oneOf` ব্যবহার করতে পারতাম, কিন্তু এর চেয়ে ভালো একটি অপশন আছে: `Decode.nullable : Decoder a -> Decoder (Maybe a)`।

```elm
decodeFeatureGeometry : Decoder (Maybe Geometry)
decodeFeatureGeometry =
    Decode.nullable decodeGeometry
        |> Decode.field "geometry"

Decode.decodeString decodeFeatureGeometry """{"geometry": {"type": "Point", "coordinates": [127.831, 26.461]}}"""
    --> Ok (Just (Point [127.831, 26.461]))

Decode.decodeString decodeFeatureGeometry """{"geometry": null}"""
    --> Ok Nothing

Decode.decodeString decodeFeatureGeometry """{"geometry": {}}"""
    --> Err ...
```

`Decode.maybe` ও `Decode.nullable`-এর সিগনেচার একই, কিন্তু এদের আচরণ আলাদা, কারণ `Decode.nullable`-এর `OK Nothing` ফলাফল কেবল নির্দিষ্ট JSON মান `null` থেকেই আসবে।

সবশেষে, `properties` ফিল্ডে যেকোনো JSON অবজেক্ট বা একটি `null` থাকতে পারে, আর এটাই `Decode.value : Decoder Value`-এর কাজ।

```elm
decodeProperties : Decoder (Maybe (Dict String Value))
decodeProperties =
    Decode.nullable (Decode.dict Decode.value)
        |> Decode.field "properties"


Decode.decodeString decodeProperties """{"properties": null}"""
    --> Ok Nothing

Decode.decodeString decodeProperties """{"properties": {"country": "Japan"}}"""
    --> Ok (Just (Dict.fromList [("country", <internals>)]))

Decode.decodeString decodeProperties """{"properties": 17}"""
    --> Err ...
```

লক্ষ্য করুন, `Value` একটি অপেক টাইপ, অর্থাৎ এর ভেতরের বিষয়বস্তু সহজে পরীক্ষা করা যায় না।
এটি ব্যবহার করতে আপনি হয় এর জন্য একটি ডিকোডার লিখে `Decode.decodeValue : Decoder a -> Value -> Result Error a` দিয়ে চালাতে পারেন, নাহয় পোর্টের মাধ্যমে সরাসরি JavaScript-এ পাঠাতে পারেন।

এখন আমরা ফিচার অবজেক্ট পার্স করার জন্য প্রস্তুত:

```elm
type alias Feature =
    { id : Maybe String
    , geometry : Maybe Geometry
    , properties : Maybe (Dict String Value)
    }

decodeFeature : Decoder Feature
decodeFeature =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                if value /= "Feature" then
                    Decode.fail "not a Feature"

                else
                    Decode.map3 Feature
                        decodeMaybeFeatureId
                        decodeFeatureGeometry
                        decodeProperties
            )

Decode.decodeString decodeFeature """{"type": "Feature", "geometry": null, "properties": null}"""
    --> Ok { geometry = Nothing, id = Nothing, properties = Nothing }

"""
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
"""
  |> Decode.decodeString decodeFeature
    --> Ok { geometry = Just (Point [127.831,26.461]), id = Just "0157", properties = Just (Dict.fromList [("country",<internals>)]) }
```

## JSON এনকোডার

এনকোডার `Encode.encode : Int -> Value -> String` ফাংশন ব্যবহার করে Elm মান থেকে বৈধ JSON লিখতে দেয়।
প্রথম আর্গুমেন্ট চূড়ান্ত ফলাফলে ইন্ডেন্টেশনের পরিমাণ নির্দিষ্ট করে, আর দ্বিতীয় আর্গুমেন্ট হলো লেখার জন্য JSON মান।

একটি `Value` হয় `Decode.value` থেকে পাওয়া যায়, নাহয় এনকোডারগুলোর একটি থেকে তৈরি করা যায়:

```elm
Encode.encode 0 (Encode.string "hello")
    --> "hello"

Encode.encode 0 (Encode.bool True)
    --> "true"

Encode.encode 0 (Encode.int 12)
    --> "12"

Encode.encode 0 (Encode.float 3.14)
    --> "3.14"

Encode.encode 0 Encode.null
    --> "null"

Encode.encode 0 (Encode.list Encode.int [1, 2, 3])
    --> "[1,2,3]"

Encode.encode 4 (Encode.list Encode.int [1, 2, 3])
    --> "[\n    1,\n    2,\n    3\n]"

Encode.encode 0 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\"key1\":17,\"key2\":71}"

Encode.encode 4 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\n    \"key1\": 17,\n    \"key2\": 71\n}"
```

এবং `Encode.object : List ( String, Value ) -> Value` দিয়েও

```elm
Encode.object
    [ ( "key1", Encode.int 17 )
    , ( "key2", Encode.int 71 )
    ]
    |> Encode.encode 0
    --> "{\"key1\":17,\"key2\":71}"
```

চলুন আগে সংজ্ঞায়িত GeoJSON ডিকোডারগুলোর জন্য এনকোডার সংজ্ঞায়িত করি

```elm
encodeGeometry : Geometry -> Value
encodeGeometry geometry =
    case geometry of
        Point coord ->
            Encode.object
                [ ( "type", Encode.string "Point" )
                , ( "coordinates", Encode.list Encode.float coord )
                ]

        LineString coord ->
            Encode.object
                [ ( "type", Encode.string "LineString" )
                , ( "coordinates", Encode.list (Encode.list Encode.float) coord )
                ]

encodeFeature : Feature -> Value
encodeFeature feature =
    let
        maybeId =
            case feature.id of
                Nothing ->
                    []

                Just id ->
                    [ ( "id", Encode.string id ) ]
    in
    Encode.object
        (maybeId
            ++ [ ( "type", Encode.string "Feature" )
               , ( "geometry"
                 , case feature.geometry of
                    Nothing ->
                        Encode.null

                    Just geometry ->
                        encodeGeometry geometry
                 )
               , ( "properties"
                 , case feature.properties of
                    Nothing ->
                        Encode.null

                    Just dict ->
                        Encode.dict identity identity dict
                 )
               ]
        )
```

সাধারণভাবে, আপনার ডিকোডার-এনকোডার জোড়ার জন্য একটি ভালো পরীক্ষা হলো `elmValue |> encoder |> decoder == elmValue` তা যাচাই করা।

## আর কী কী?

আমরা `Json` মডিউলের প্রতিটি ফাংশন আলোচনা করিনি।
যেসব বিষয় উল্লেখ করা হয়নি তার মধ্যে আছে: অ্যারেকে `Array`-তে বা অবজেক্টকে `List (String, a)`-তে রূপান্তরের ডিকোডার, এক বা একাধিক এলিমেন্টবিশিষ্ট অ্যারের ডিকোডার, নেস্টেড JSON অবজেক্টের নির্দিষ্ট ফিল্ড বা অ্যারের নির্দিষ্ট এলিমেন্টের ডিকোডার, রিকার্সিভ স্ট্রাকচার ডিকোড করার উপায়, এবং `Error`-এর বিভিন্ন ভ্যারিয়েন্ট ও সেগুলো কীভাবে দেখাতে হয়।

অন্যান্য বহুল ব্যবহৃত প্যাকেজের মধ্যে আছে [`Json.Decode.Pipeline`][pipeline], যা জটিল JSON স্ট্রাকচারের জন্য একটি সুবিধাজনক ধারা নিয়ে আসে, এবং [`Json.Decode.Extra`][extra], যা আরও ডিকোডার, এনকোডার ও হেল্পার দেয়।
