# নির্দেশনা

এই অনুশীলনীতে আপনি একটি সাধারণ ক্যালকুলেটরের জন্য এরর হ্যান্ডলিং তৈরি করবেন।

লক্ষ্য হলো এমন একটি কার্যকর ক্যালকুলেটর তৈরি করা, যা `16`, `51` এবং `+` আর্গুমেন্ট দেওয়া হলে নিচের প্যাটার্নের একটি স্ট্রিং রিটার্ন করে: `16 + 51 = 67`।

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Handle the code that may raise errors within the method `calculate`

এই কাজে যে মূল মেথডটি বাস্তবায়ন করতে হবে সেটি হলো `SimpleCalculator.calculate()` ক্লাস মেথডটি।
এটি তিনটি আর্গুমেন্ট নেয়।
প্রথম দুটি আর্গুমেন্ট হলো এমন সংখ্যা, যেগুলোর উপর একটি অপারেশন চালানো হবে।
তৃতীয় আর্গুমেন্টটি স্ট্রিং টাইপের, এবং এই অনুশীলনীতে নিচের অপারেশনগুলো বাস্তবায়ন করা প্রয়োজন:

- `+` স্ট্রিং দিয়ে যোগ
- `*` স্ট্রিং দিয়ে গুণ
- `/` স্ট্রিং দিয়ে ভাগ

## 2. Handle illegal operations

অজানা অপারেশন চিহ্নের জন্য `UnsupportedOperation` এক্সেপশন রেইজ করতে `SimpleCalculator.calculate()` মেথডটি হালনাগাদ করুন।

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
এই অনুশীলনীতে আপনি `UnsupportedOperation` এক্সেপশনটি একটি নির্দিষ্ট স্কোপের জন্য ডিফাইন করবেন বলে আশা করা হচ্ছে।
~~~~

## 3. Handle invalid arguments

অবৈধ আর্গুমেন্ট টাইপের জন্য `ArgumentError` এক্সেপশন রেইজ করতে `SimpleCalculator.calculate()` মেথডটি হালনাগাদ করুন।

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Handle DivideByZero exceptions

`ZeroDivisionError` এক্সেপশনগুলো হ্যান্ডেল করতে `SimpleCalculator.calculate()` হালনাগাদ করুন।
হ্যান্ডলিং কোডটি `Division by zero is not allowed.` কনটেন্টসহ স্ট্রিংটি রিটার্ন করবে।
অন্য কোনো এক্সেপশন `SimpleCalculator.calculate()` মেথড দ্বারা হ্যান্ডেল করা উচিত নয়।

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
