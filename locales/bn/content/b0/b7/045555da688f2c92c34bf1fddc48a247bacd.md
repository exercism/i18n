# ভূমিকা

টেমপ্লেট হলো একটি স্ট্রিং বা ফাইল, যা ইনপুটের উপর নির্ভর করে যেকোনো ধরনের স্ট্রিং আউটপুট তৈরি করতে ব্যবহৃত হয়।

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

এছাড়াও, টেমপ্লেটের ভেতরে যাচাই করার জন্য আপনি শর্তও ব্যবহার করতে পারেন:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
