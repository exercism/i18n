# টপ লেভেল কনস্ট্যান্ট ব্যবহার করুন

`GIGASECOND` সংখ্যাটিকে একটি কনস্ট্যান্টে বের করে আনার কথা ভাবুন:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

কেবল `export` করা ফাংশন, ক্লাস আর কনস্ট্যান্টগুলোই বাইরে থেকে দৃশ্যমান ও ব্যবহারযোগ্য। সাধারণত [ম্যাজিক নাম্বার](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29)-কে একটি নাম দেওয়াই বুদ্ধিমানের কাজ, এতে কোড রক্ষণাবেক্ষণ করা সহজ হয়। এই কনস্ট্যান্টগুলো একই ফাইলেই রাখা যায়, অন্য কোডের কাছে প্রকাশ না করেই।
