# সম্পর্কে

স্ট্রাক্ট বা ক্লাসের প্রতিটি ইন্সট্যান্সে `self` নামে একটি অন্তর্নিহিত প্রপার্টি থাকে, যা ইন্সট্যান্সটিকেই নির্দেশ করে।
`self`-এর সবচেয়ে কমন ব্যবহার হলো একই নামের একটি ইন্সট্যান্স প্রপার্টি আর একটি প্যারামিটারের মধ্যে পার্থক্য স্পষ্ট করা:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift টাইপগুলো বড় হাতের অক্ষরে লেখা `Self` কিওয়ার্ডও দেয়, যা ইন্সট্যান্সটির নিজেকে নয়, বরং ইন্সট্যান্সটির *টাইপকে* নির্দেশ করে।
