# নির্দেশাবলি

এই অনুশীলনীতে প্রোগ্রামিং ভাষার একটি অ্যারে নিয়ে কাজ করার জন্য আপনাকে কয়েকটি ফাংশন ইমপ্লিমেন্ট করতে হবে।

## 1. খালি ভাষার অ্যারে রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`new` ফাংশনটি ডিফাইন করুন, যা কোনো আর্গুমেন্ট নেয় না এবং একটি খালি অ্যারে রিটার্ন করে।

```haskell
new
-- -> []
```

## 2. অ্যারেতে একটি ভাষা যোগ করার জন্য একটি ফাংশন ডিফাইন করুন

`add/2` ফাংশনটি ডিফাইন করুন, যা ২টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_ এবং একটি _ভাষার_ স্ট্রিং লিটারাল)।
এটি নতুন ভাষাটি প্রদত্ত অ্যারের সামনে যোগ করে প্রাপ্ত অ্যারেটি রিটার্ন করবে।

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. অ্যারে থেকে একটি ভাষা সরিয়ে ফেলার জন্য একটি ফাংশন ডিফাইন করুন

`remove` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_)।
এটি প্রথম এলিমেন্টটি ছাড়া অ্যারেটি রিটার্ন করবে। ধরে নিন, অ্যারেটিতে সবসময় অন্তত একটি এলিমেন্ট থাকবে।

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. অ্যারেটির প্রথম এলিমেন্ট রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`first` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_)।
এটি অ্যারেটির প্রথম ভাষাটি রিটার্ন করবে।
ধরে নিন, অ্যারেটিতে সবসময় অন্তত একটি এলিমেন্ট থাকবে।

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. অ্যারেটিতে কতগুলো ভাষা আছে তা রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`count` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_)। 
এটি অ্যারেটিতে থাকা ভাষার সংখ্যা রিটার্ন করবে।

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. অ্যারেতে কোনো ফাংশনাল ভাষা আছে কি না তা নির্ণয় করার জন্য একটি ফাংশন ডিফাইন করুন

`isFunctionalList` ফাংশনটি ডিফাইন করুন, যা ১টি আর্গুমেন্ট নেয় (একটি _ভাষার অ্যারে_)। 
এটি একটি বুলিয়ান মান রিটার্ন করবে। 
অ্যারেটিতে থাকা ভাষাগুলোর একটি যদি _"Haskell"_ হয়, তবে এটি `True` রিটার্ন করবে।

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
