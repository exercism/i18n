# সম্পর্কে

## ভূমিকা

জেনেরিকস হলো ভাষার এমন একটি বৈশিষ্ট্য, যার সাহায্যে কোড পুনরায় ব্যবহার করা যায়।
উদাহরণস্বরূপ, একটি অ্যারের দৈর্ঘ্য হিসাব করতে তার মধ্যে কোন টাইপের মান আছে, সেটা গুরুত্বপূর্ণ হওয়া উচিত নয়।
সেজন্যই `length` ফাংশনটি তার টাইপ সিগনেচারে একটি জেনেরিক টাইপ প্যারামিটার `a` ব্যবহার করে।

```elm
length : List a -> Int
```

## টাইপে প্যারামিটার

কোনো টাইপ যখন অন্য একটি টাইপের উপর জেনেরিক হয়, তখন আমরা সেই অন্য টাইপের জন্য ছোট হাতের অক্ষরে একটি নাম ব্যবহার করি এবং সেটিকে টাইপ প্যারামিটার বলি।
কমন উদাহরণ হলো `List`, `Maybe` আর `Result` কাস্টম টাইপগুলো।

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

টাইপ প্যারামিটারের নাম নিয়ে একটি গুরুত্বপূর্ণ কথা হলো, নাম একাধিক অক্ষরেরও হতে পারে।
একমাত্র বাধ্যবাধকতা হলো, নামগুলো অবশ্যই ছোট হাতের অক্ষরে হতে হবে।
তাই যখন সুবিধাজনক হয়, আমরা সেগুলোকে বর্ণনামূলক নাম দিতে পছন্দ করি।

একটি টাইপ একাধিক টাইপের উপর জেনেরিক হতে পারে, আর তাই তার একাধিক টাইপ প্যারামিটার থাকতে পারে।
সেক্ষেত্রে প্রতিটি স্বাধীন টাইপ আলাদা একটি ছোট হাতের নাম পায়।
স্বাধীন হওয়া মানে এই নয় যে তারা একই টাইপ হতে পারবে না, এটি শুধু তাদের আলাদা হওয়ার সুযোগ দেয়।

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

রেকর্ড টাইপ অ্যালিয়াসেও টাইপ প্যারামিটার থাকতে পারে, যদিও এটি খুব কমন নয়।

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

> সেজন্যই `Html` প্যাকেজটি `Html msg` টাইপ ডিফাইন করে, যার `msg` নামের একটি টাইপ প্যারামিটার থাকে।
> Elm আর্কিটেকচার আপনাকে এমন একটি কাস্টম টাইপ `Msg` তৈরি করার পথ দেখায়, যা আপনার ওয়েব পেজ যেসব মেসেজ পাঠাতে পারে সেগুলোর বর্ণনা দেয়।
> এর ফলে আপনার কোড `Html Msg` টাইপের ভিউ তৈরি করবে, যেখানে `Msg` হলো আপনি ডিফাইন করা কংক্রিট টাইপ।
> নতুন শিক্ষার্থীরা মাঝে মাঝে `Html msg` (ছোট হাতের) উল্লেখ করা এরর আর `Html Msg` সংক্রান্ত এরর নিয়ে বিভ্রান্ত হন।
> এখন তো আপনি জেনে গেছেন!
> পার্থক্য হলো, প্রথমটি যেকোনো `msg` টাইপের উপর জেনেরিক, আর দ্বিতীয়টি আপনার `Msg` টাইপের জন্য নির্দিষ্ট।

## ফাংশনে টাইপ প্যারামিটার

টাইপ যেহেতু জেনেরিক হতে পারে, ফাংশনও পারে।
জেনেরিক টাইপ নিয়ে কাজ করা ফাংশনও লেখা যায়, যেমন `Maybe.withDefault`।

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

যেসব ফাংশন প্যারামিটার হিসেবে অন্য ফাংশন নেয়, তাদের হায়ার অর্ডার ফাংশন বলা হয়, আর এরাও জেনেরিক হতে পারে।

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

টাইপ প্যারামিটার একটি ফাংশনের ইনপুট এবং আউটপুট দুটোতেই দেখা যেতে পারে, আর টাইপ প্যারামিটার দিয়ে যে জেনেরিসিটি আসে, তাকে সাধারণত **প্যারামেট্রিক পলিমরফিজম** বলা হয়।
এর বিপরীতে আছে অ্যাড হক পলিমরফিজম, যা ফাংশন ওভারলোডিং নামেও পরিচিত; এখানে একই ফাংশনের নাম একাধিক ইমপ্লিমেন্টেশনে ব্যবহার করা যায়, যেখানে টাইপ আলাদা হয়।
এটি সাবটাইপ পলিমরফিজমেরও বিপরীত, যেখানে টাইপগুলো একটি হায়ারার্কিতে ডিফাইন করা যায় এবং একটি টাইপে ডিফাইন করা ফাংশন তার সাবটাইপের আর্গুমেন্ট দিয়েও কল করা যায়।
Elm-এ জেনেরিসিটির একমাত্র উপায় হলো প্যারামেট্রিক পলিমরফিজম।
