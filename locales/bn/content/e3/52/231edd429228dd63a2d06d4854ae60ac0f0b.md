# ইনস্টলেশন

## লক্ষ্য সংস্করণ

এই ট্র্যাকের টেস্টিংয়ে `alpine:3.24.1` Docker ইমেজ ব্যবহার করা হয়, যা ২০২৬ সালের সেপ্টেম্বর অনুযায়ী `sqlite3 version 3.53.4` ব্যবহার করে।
আমরা নিশ্চিত করার চেষ্টা করি যেন এই ট্র্যাকের দেওয়া টুলগুলো সর্বশেষ Ubuntu LTS রিলিজে কাজ করে।
ব্যবহারকারীদের হয়তো আরও নতুন সংস্করণ ইনস্টল করা থাকতে পারে, তবে তাদের জেনে রাখা উচিত যে কিছু ফিচার আমাদের টেস্ট রানারের সাথে কাজ নাও করতে পারে।
[SQLite সংস্করণের ইতিহাস][version-history] পেজে ফিচারগুলোর তুলনা করা যেতে পারে।

## Windows

Windows-এ SQLite ইনস্টল করতে এই ধাপগুলো অনুসরণ করুন:

1. [অফিসিয়াল ডাউনলোড পেজ][sqlite-download] থেকে আগে থেকে কম্পাইল করা Windows বাইনারি ডাউনলোড করুন।
2. ডাউনলোড করা ZIP ফাইলটি আপনার পছন্দের একটি ডিরেক্টরিতে এক্সট্র্যাক্ট করুন।
   উদাহরণস্বরূপ, `C:\Program Files\sqlite3`.
3. `sqlite3.exe` আছে যে ডিরেক্টরিটি, সেটি সিস্টেমের PATH এনভায়রনমেন্ট ভ্যারিয়েবলে যোগ করুন।
   প্রতিটি Windows সংস্করণে এই প্রক্রিয়াটি একটু আলাদা, তবে তথ্যটি খুঁজে বের করা সহজ হওয়া উচিত।
   যেমন [Windows 11-এর নির্দেশনা][windows-11-install] এবং [Windows 10][windows-10-install].

## macOS

macOS-এ SQLite আগে থেকেই ইনস্টল করা থাকে।
তবে আপনার যদি আরও নতুন সংস্করণ দরকার হয়, তাহলে [Homebrew][homebrew] ব্যবহার করতে পারেন:

```bash
brew install sqlite
```

## Ubuntu / Debian

Ubuntu ও Debian-ভিত্তিক সিস্টেমে আপনি apt দিয়ে SQLite ইনস্টল করতে পারেন:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

CentOS, Fedora এবং Red Hat-ভিত্তিক সিস্টেমে আপনি yum বা dnf দিয়ে SQLite ইনস্টল করতে পারেন:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Arch Linux-এ আপনি pacman দিয়ে SQLite ইনস্টল করতে পারেন:

```bash
sudo pacman -S sqlite
```

## অন্যান্য ইনস্টলেশনের উপায় এবং পুরোনো সংস্করণ

আরও তথ্য ও বিকল্প ইনস্টলেশন পদ্ধতির জন্য [SQLite ডাউনলোড পেজ][sqlite-download] দেখুন।
`Build Product Names and Info` সেকশনে বিভিন্ন SQLite সংস্করণের নামকরণের টেমপ্লেট আছে, তাই আপনার পছন্দের সার্চ ইঞ্জিন দিয়ে আপনি কাঙ্ক্ষিত সংস্করণটি খুঁজে পেতে পারেন।
