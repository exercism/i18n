# ইঙ্গিত

## সাধারণ

- Erlang লাইব্রেরি ব্যবহার করা নিয়ে [অফিসিয়াল Getting Started গাইডে][getting-started-erlang-libraries] পড়ুন, আর বিশেষ করে [স্ট্রিং ফরম্যাট করা][getting-started-formatted-text-output] নিয়ে পড়ুন।

## 1. একটি র‍্যান্ডম গ্রহ তৈরি করুন

- প্রদত্ত মডিউল অ্যাট্রিবিউটটি ব্যবহার করুন, যেটিতে গ্রহের ক্লাস বোঝানো অক্ষরের একটি অ্যারে আছে।
- অ্যারে থেকে র‍্যান্ডমভাবে একটি এলিমেন্ট বাছাই করার জন্য একটি [বিল্ট-ইন ফাংশন][enum-random] আছে।

## 2. একটি র‍্যান্ডম স্টারশিপ রেজিস্ট্রি নম্বর তৈরি করুন

- রেঞ্জ থেকে র‍্যান্ডমভাবে একটি এলিমেন্ট বাছাই করার জন্য একটি [বিল্ট-ইন ফাংশন][enum-random] আছে।

## 3. একটি র‍্যান্ডম স্টারডেট তৈরি করুন

- র‍্যান্ডম ফ্লোট রিটার্ন করে এমন কোনো Elixir ফাংশন নেই।
- একটি [বিল্ট-ইন Erlang ফাংশন][erl-rand-uniform] আছে যা একটি র‍্যান্ডম ফ্লোট x রিটার্ন করে, যেখানে `0.0 <= x < 1.0`।
- যদি `x` একটি রেঞ্জ `0.0 <= x < 1.0`-এ পড়ে, কিন্তু আপনার দরকার অন্য একটি রেঞ্জ `a <= x < b`-এর একটি সংখ্যা, তাহলে x-এর রেঞ্জটি শিফট করতে পারেন এভাবে: এটিকে রেঞ্জের প্রস্থ (`b - a`) দিয়ে গুণ করুন আর রেঞ্জের শুরু (`a`) যোগ করুন। অর্থাৎ: `x * (b - a) + a`।

## 4. স্টারডেট ফরম্যাট করুন

- এক ধাপেই নির্দিষ্ট প্রিসিশনে একটি ফ্লোটকে স্ট্রিং হিসেবে ফরম্যাট করতে পারবে এমন কোনো Elixir ফাংশন নেই।
- একটি [বিল্ট-ইন Erlang ফাংশন][erl-io-lib-format] আছে যা একটি ফরম্যাট স্ট্রিং আর ডেটার একটি অ্যারে নেয়, এবং একটি চারলিস্ট রিটার্ন করে।
- একটি [বিল্ট-ইন ফাংশন][to-string] আছে যা একটি চারলিস্টকে স্ট্রিংয়ে বদলে দেয়।
- ওই ফাংশনের ফরম্যাট স্ট্রিংয়ে কন্ট্রোল সিকোয়েন্স থাকে।
- একটি কন্ট্রোল সিকোয়েন্স `~` দিয়ে শুরু হয় এবং এর প্যাটার্ন `~F.P.PadModC`, যেখানে `F` মানে আউটপুটের প্রস্থ, `P` মানে প্রিসিশন, `Pad` মানে প্যাডিং ক্যারেক্টার, `Mod` মানে কন্ট্রোল সিকোয়েন্স মডিফায়ার, আর `C` হলো কন্ট্রোল সিকোয়েন্সের টাইপ।
- কাঙ্ক্ষিত প্রিসিশনে একটি ফ্লোট ফরম্যাট করতে `~.PC` প্যাটার্নের একটি কন্ট্রোল সিকোয়েন্সই যথেষ্ট।
- ফ্লোটের জন্য কন্ট্রোল সিকোয়েন্সের টাইপ হলো `f`।
- আপনার প্রয়োজনীয় ফরম্যাট স্ট্রিংটি হলো `~.1f`।
