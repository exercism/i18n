# ইঙ্গিত
`Either`-এর একটি কমন ব্যবহার হলো এমন একটি গণনা বোঝানো, যার ফলাফল সম্ভবত একটি এরর হতে পারে
(যদি আসল এররটিতে আপনার কোনো আগ্রহ না থাকে, তাহলে সরল `Option` টাইপটি হয়তো আরও ভালো পছন্দ হতে পারে)।
এরর না থাকলে ফলাফল সাধারণত একটি `Right` হয় (মনে রাখার সহজ উপায়: এটি "সঠিক" মান), আর এরর হলে সেটি `Left`, যেমন একটি এরর মেসেজ ধারণ করা `Left[String]`।
মনে রাখবেন, Scala 2.12-এ `Either` ডিফল্টভাবে রাইট-বায়াসড, তাই `filter`, `map`, `flatMap`-এর মতো অপারেশন বা একটি ফর-কম্প্রিহেনশনে এটি প্রত্যাশামতো কাজ করে।
`Either`-এর সাথে যদি আপনার পরিচয় না থাকে, তাহলে আপনি [এই টিউটোরিয়ালটি](http://danielwestheide.com/blog/2013/01/02/the-neophytes-guide-to-scala-part-7-the-either-type.html) পড়তে পারেন। তবে মনে রাখবেন, এই টিউটোরিয়ালটি 2.12-এর আগের Scala ভার্সন নিয়ে। Scala 2.12-এর ক্ষেত্রে আপনি নিশ্চিন্তে `RightProjection` উপেক্ষা করতে পারেন এবং `.right` বাদ দিতে পারেন।
`Either` হলো তথাকথিত একটি [মোনাড](https://en.wikipedia.org/wiki/Monad_(functional_programming)), যা একটি "গণনার দিক" নিয়ে কাজ করে,
এক্ষেত্রে এরর হ্যান্ডলিং।
মোনাড সঠিকভাবে ব্যবহার করলে কোড অত্যন্ত সংক্ষিপ্ত হয়েও সুন্দর
ও পড়ার উপযোগী হতে পারে। ভুল ব্যবহারে সহজেই এর উল্টোটা ঘটতে পারে।
আরও জানতে [এই ভিডিওটি](https://www.youtube.com/watch?v=Mw_Jnn_Y5iA) দেখুন।
## যে কমন বিপদগুলো এড়িয়ে চলবেন
`Either`-এর জন্য কয়েকটি সাধারণ নিয়ম আছে:
1. দরকার না থাকলে এটি ব্যবহার করবেন না। এর বদলে
```scala
def add1(x: Int): Either[String, Int] = Right(x + 1)
```
ভালো হয়
```scala
def add1(x: Int): Int = x + 1
```
(এমন সরল ফাংশন প্রয়োগ করার জন্য `Either.map` আছে,
তাই সেগুলো `Either` দিয়ে জটিল করার দরকার নেই)।
2. সত্যিই দরকার না থাকলে আনর্যাপ করবেন না।
প্রায়ই আপনার উদ্দেশ্যের জন্য বিল্ট-ইন ফাংশন থাকে। সময়ের আগে
আনর্যাপ করার লক্ষণ হলো `isLeft/isRight` বা প্যাটার্ন ম্যাচিং। উদাহরণস্বরূপ, এর বদলে
```scala
val x: Either[String, Int] = ...

if (x.isRight) x.right.get + 1 else x.left.get
// or
x match {
  case Right(n) => n + 1
  case Left(s) => s
}
```
ভালো হয়
```scala
x fold (identity, _ + 1)
```
3. মোনাড একটি ফর-কম্প্রিহেনশনের ভেতরে ব্যবহার করা যায় FTW।
এটি তখন করা বাঞ্ছনীয় যখন আপনি একাধিক `Either` ইনস্ট্যান্স কম্পোজ করতে চান। এর বদলে
```scala
val xo: Either[String, Int] = ...
val yo: Either[String, Int] = ...
val zo: Either[String, Int] = ...

xo.flatMap(x =>
  yo.flatMap(y =>
    zo.map(z =>
	    x + y + z)))
```
ভালো হয়
```scala
for {
  x <- xo
  y <- yo
  z <- zo
} yield x + y + z
```
