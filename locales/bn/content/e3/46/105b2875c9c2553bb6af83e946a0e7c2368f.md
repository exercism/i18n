# ভূমিকা

## প্রোটোকল

প্রোটোকল হলো Elixir-এ পলিমরফিজম অর্জনের একটি মেকানিজম, যখন আপনি চান আচরণ ডেটা টাইপের উপর নির্ভর করে ভিন্ন হোক।

প্রোটোকল `defprotocol` দিয়ে ডিফাইন করা হয় এবং এতে এক বা একাধিক ফাংশন হেডার থাকে।

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

প্রোটোকল `defimpl` দিয়ে ইমপ্লিমেন্ট করা যায়।

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

যেকোনো বিদ্যমান Elixir ডেটা টাইপের জন্য বা একটি স্ট্রাক্টের জন্য প্রোটোকল ইমপ্লিমেন্ট করা যায়।

কোনো প্রোটোকল ফাংশন কল করা হলে, প্রথম আর্গুমেন্টের টাইপের ভিত্তিতে উপযুক্ত ইমপ্লিমেন্টেশন স্বয়ংক্রিয়ভাবে বেছে নেওয়া হয়।
