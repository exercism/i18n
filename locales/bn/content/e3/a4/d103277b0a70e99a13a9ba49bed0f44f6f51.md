# ভূমিকা

*কম্বিনেটরিক্স* হলো এমন একটি গাণিতিক শাখা, যেখানে আইটেমের একটি সংগ্রহকে কত উপায়ে বাছাই করা বা সাজানো যায়, তা গণনা ও তালিকা করা হয়। Factor-এর [`math.combinatorics`][math.combinatorics] শব্দভাণ্ডারে দুটি মৌলিক প্রশ্নেরই সমাধান আছে:

- **কম্বিনেশন**: এমন নির্বাচন যেখানে ক্রম *গুরুত্বপূর্ণ নয়*।
- **পারমিউটেশন**: এমন বিন্যাস যেখানে ক্রম *অবশ্যই* গুরুত্বপূর্ণ।

প্রতিটি প্রশ্নের জন্য একটি *গণনার* ওয়ার্ড আছে, যা একটি সংখ্যা রিটার্ন করে, আর একটি *তালিকা করার* ওয়ার্ড আছে, যা আসল নির্বাচনগুলো রিটার্ন করে; এছাড়া প্রতিটির জন্য একটি স্ট্রিমিং `each-` ভ্যারিয়েন্ট আছে, যা প্রতিবার একটি কোয়োটেশন কল করে:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
