# পরিচিতি

কোটলিনে ডেটা ও আচরণ এনক্যাপসুলেট করতে ক্লাস ব্যবহার করা যায়।
`class` কিওয়ার্ড ব্যবহার করে একটি ক্লাস ডিক্লেয়ার করা হয়।
উদাহরণ:

```kotlin
class Car
```

ক্লাসটিকে কল করে তার একটি ইনস্ট্যান্স তৈরি করুন।

```kotlin
val instance = Car()
```

## প্রপার্টি

উপরের উদাহরণগুলোতে `Car` ক্লাসটি কোনো প্রপার্টি ছাড়াই ডিক্লেয়ার করা হয়েছে।
ক্লাসের প্রপার্টি ক্লাসের বডিতে, `{}`-এর মধ্যে ডিক্লেয়ার করা যায়; মিউটেবল প্রপার্টির জন্য `var` এবং ইমিউটেবল প্রপার্টির জন্য `val` ব্যবহার করা হয়।
উদাহরণ:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

বিকল্পভাবে, প্রপার্টিগুলো এমন একটি কনস্ট্রাক্টরে ডিফাইন করা যায় যা প্রপার্টিগুলোকে গ্রহণ করে।

## কনস্ট্রাক্টর

কোটলিনে দুই ধরনের কনস্ট্রাক্টর আছে: প্রাইমারি ও সেকেন্ডারি কনস্ট্রাক্টর।
প্রাইমারি কনস্ট্রাক্টর ক্লাস ডিক্লেয়ারেশনের একই লাইনে ডিক্লেয়ার করা হয়।
উদাহরণ:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

কোনো অ্যানোটেশন এবং কোনো ভিজিবিলিটি মডিফায়ার না থাকলে `constructor` কিওয়ার্ডটি বাদ দেওয়া যায়:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
কোটলিনে ক্লাসটিকে বডিসহ ডিফাইন করা যায় যদি এতে কেবল প্রপার্টি থাকে; কার্লি ব্রেস `{}`-এর কোনো দরকার নেই:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

একটি ক্লাসে কেবল একটি প্রাইমারি কনস্ট্রাক্টর থাকতে পারে।
সেকেন্ডারি কনস্ট্রাক্টর হলো আরও কনস্ট্রাক্টর, যেগুলো `constructor` কিওয়ার্ড দিয়ে ক্লাসের বডিতে ডিক্লেয়ার করে যোগ করা যায়।
উদাহরণ:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

সেকেন্ডারি কনস্ট্রাক্টরকে `this` কল করে প্রাইমারি কনস্ট্রাক্টর ইনভোক করতে হয়।

## ইনিশিয়ালাইজার ব্লক

প্রাইমারি কনস্ট্রাক্টর ক্লাসের প্রপার্টিগুলো সেট করে।
অবজেক্ট তৈরির সময় আরও কিছু করার প্রয়োজন হলে অতিরিক্ত কাজ সম্পন্ন করতে `init` ব্লক ব্যবহার করা যায়।

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## ফাংশন

ক্লাসের বডিতে ফাংশন ডিফাইন করা যায়।
উদাহরণ:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## ভিজিবিলিটি

প্রপার্টি ও ফাংশন `private`, `public`, `internal` অথবা `protected` হতে পারে।

- `private` শুধু ক্লাসের ভেতরে অ্যাক্সেস করা যায়
- `protected` ক্লাসের ভেতরের যেকোনো কিছু এবং যেকোনো সাবক্লাস থেকে অ্যাক্সেস করা যায়
- `internal` একই মডিউলের ভেতরের যেকোনো কিছু থেকে অ্যাক্সেস করা যায়
- `public` ক্লাসটি ব্যবহার করে এমন অন্য কম্পোনেন্টগুলো থেকে অ্যাক্সেস করা যায়

উদাহরণ:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
