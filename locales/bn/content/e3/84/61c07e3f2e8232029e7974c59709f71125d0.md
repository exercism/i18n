# পরিচিতি

Java একটি স্ট্যাটিক টাইপড ভাষা, যার মানে হলো একটি ভ্যারিয়েবলের টাইপ কম্পাইল টাইমে জানা থাকে।
একটি নামে একটি মান অ্যাসাইন করাকে ভ্যারিয়েবল ডিফাইন করা বলা হয়।
একটি ভ্যারিয়েবল ডিফাইন করা হয় তার টাইপ স্পষ্টভাবে উল্লেখ করে।

```java
int explicitVar = 10;
```

একটি ভ্যারিয়েবলের মান আপডেট করা হয় `=` অপারেটরের মাধ্যমে।
এখানে `=` গাণিতিক সমতা বোঝায় না।
এটি শুধু একটি ভ্যারিয়েবলে একটি মান অ্যাসাইন করে।
একবার ডিফাইন করা হলে, একটি ভ্যারিয়েবলের টাইপ আর কখনো পরিবর্তন হতে পারে না।

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java একটি [অবজেক্ট-ওরিয়েন্টেড ভাষা][object-oriented-programming] এবং এতে সব ফাংশন একটি _ক্লাসের_ মধ্যে ডিফাইন করতে হয়।
একটি ক্লাস ডিফাইন করতে `class` কিওয়ার্ড ব্যবহার করা হয়।

```java
class Calculator {
    // ...
}
```

একটি ক্লাসের ভেতরের ফাংশনকে _মেথড_ বলা হয়।
প্রতিটি মেথডে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে।
সব প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হবে; প্যারামিটারের জন্য কোনো টাইপ ইনফারেন্স নেই।
একইভাবে, রিটার্ন টাইপও স্পষ্টভাবে উল্লেখ করতে হবে।
`return` কিওয়ার্ড ব্যবহার করে মেথড থেকে মান রিটার্ন করা হয়।
অন্য ক্লাসগুলো যাতে একটি মেথড কল করতে পারে, সেজন্য `public` অ্যাক্সেস মডিফায়ার যোগ করতে হবে।

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

একটি মেথড ইনভোক/কল করা হয় তার ক্লাস ও মেথডের নাম উল্লেখ করে এবং মেথডের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Java-তে স্কোপ `{` ও `}` ক্যারেক্টারের মধ্যে নির্ধারিত হয়।

Java দুই ধরনের কমেন্ট সমর্থন করে।
এক লাইনের কমেন্টের আগে `//` থাকে, আর বহু লাইনের কমেন্ট `/*` ও `*/`-এর মধ্যে বসানো হয়।

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
