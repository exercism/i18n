# শেখা

Exercism অনুশীলনী ও ফিডব্যাক দেয়, তবে যাঁরা প্রথমবার Common Lisp শিখছেন, তাঁদের কাছে এতে ঢুকে পড়া কঠিন হতে পারে।
এই রিসোর্সগুলো আপনাকে শুরু করতে সাহায্য করবে:

* [A Road to Common Lisp][road-to-cl], একটি ব্লগ পোস্ট, যেখানে একজন ব্যক্তি Common Lisp-এ তাঁর পৌঁছানোর পথ এবং এটি শুরু করার বিষয়ে নিজের মতামত ব্যাখ্যা করেছেন
* [Practical Common Lisp][practical-cl], Common Lisp শেখার একটি পূর্ণাঙ্গ বই, অনলাইনে বিনামূল্যে পাওয়া যায় (ছাপা বই হিসেবেও)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  বিভিন্ন অবদানকারীর লেখা
* [Awesome Common Lisp Learning][awesome-cl]

এছাড়াও, এই Exercism Common Lisp ট্র্যাকের মধ্যে দেখুন: [গুরুত্বপূর্ণ রিসোর্স][track-resources]।
