# নির্দেশনা

জনপ্রিয় ৫ বইয়ের একটি সিরিজের বিভিন্ন বইয়ের বিক্রি বাড়াতে ও উৎসাহ জোগাতে, একটি বইয়ের দোকান একাধিক বই একসাথে কেনার উপর ছাড় দেওয়ার সিদ্ধান্ত নিয়েছে।

পাঁচটি বইয়ের যেকোনোটির একটি কপির দাম $৮।

তবে আপনি যদি দুটি ভিন্ন বই কেনেন, তাহলে সেই দুটি বইয়ের উপর ৫% ছাড় পাবেন।

আপনি যদি ৩টি ভিন্ন বই কেনেন, তাহলে ১০% ছাড় পাবেন।

আপনি যদি ৪টি ভিন্ন বই কেনেন, তাহলে ২০% ছাড় পাবেন।

আপনি যদি পাঁচটিই কেনেন, তাহলে ২৫% ছাড় পাবেন।

লক্ষ্য করুন: আপনি যদি চারটি বই কেনেন, যার মধ্যে ৩টি ভিন্ন শিরোনামের, তাহলে যে ৩টি একটি সেটের অংশ হয় তার উপর ১০% ছাড় পাবেন, কিন্তু চতুর্থ বইটির দাম তখনও $৮।

আপনার কাজ হলো এমন একটি কোড লেখা, যা যেকোনো সম্ভাব্য কেনাকাটার ঝুড়ির (যাতে কেবল একই সিরিজের বই থাকবে) দাম হিসাব করবে এবং যতটা সম্ভব বেশি ছাড় দেবে।

উদাহরণস্বরূপ, বইয়ের এই ঝুড়িটির দাম কত?

- প্রথম বইটির ২টি কপি
- দ্বিতীয় বইটির ২টি কপি
- তৃতীয় বইটির ২টি কপি
- চতুর্থ বইটির ১টি কপি
- পঞ্চম বইটির ১টি কপি

এই ৮টি বই গ্রুপ করার একটি উপায় হলো:

- ১টি গ্রুপে ৫টি বই --> ২৫% ছাড় (১ম,২য়,৩য়,৪র্থ,৫ম)
- +১টি গ্রুপে ৩টি বই --> ১০% ছাড় (১ম,২য়,৩য়)

এতে মোট দাঁড়াবে:

- ২৫% ছাড়ে ৫টি বই
- +১০% ছাড়ে ৩টি বই

ফলে:

- ৫ x (৮ - ২.০০) == ৫ x ৬.০০ == $৩০.০০
- +৩ x (৮ - ০.৮০) == ৩ x ৭.২০ == $২১.৬০

সব মিলিয়ে মোট $৫১.৬০

তবে এই ৮টি বই গ্রুপ করার আরেকটি ভিন্ন উপায় হলো:

- ১টি গ্রুপে ৪টি বই --> ২০% ছাড়  (১ম,২য়,৩য়,৪র্থ)
- +১টি গ্রুপে ৪টি বই --> ২০% ছাড়  (১ম,২য়,৩য়,৫ম)

এতে মোট দাঁড়াবে:

- ২০% ছাড়ে ৪টি বই
- +২০% ছাড়ে ৪টি বই

ফলে:

- ৪ x (৮ - ১.৬০) == ৪ x ৬.৪০ == $২৫.৬০
- +৪ x (৮ - ১.৬০) == ৪ x ৬.৪০ == $২৫.৬০

সব মিলিয়ে মোট $৫১.২০

আর $৫১.২০ হলো সবচেয়ে বেশি ছাড়ের দাম।
