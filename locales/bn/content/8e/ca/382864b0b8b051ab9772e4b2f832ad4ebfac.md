# টেস্ট

প্রতিটি অনুশীলনীতে ইউনিট টেস্ট এবং একটি CMake বিল্ড রেসিপি দেওয়া থাকে। ইমপ্লিমেন্টেশনটি আপনাকে লিখতে হবে।
প্রতিটি টেস্ট ফাইল আপনার ইমপ্লিমেন্টেশনের সঙ্গে লিংক হয়ে একটি কনসোল এক্সিকিউটেবল তৈরি করে, যা টেস্টগুলো রান করে। টেস্ট এক্সিকিউটেবল রান করলে প্রতিটি ফেল করা টেস্টের জন্য বার্তা প্রিন্ট হয় এবং টেস্ট ফেল করলে একটি নন-জিরো এক্সিট স্ট্যাটাস রিপোর্ট করা হয়।

টেস্ট ফাইলের নাম হবে `<exercise>_test.f90`, তাই "Bob" অনুশীলনীর ক্ষেত্রে টেস্টগুলো যে ফাইলে থাকে তার নাম `bob_test.f90`। প্রতিটি টেস্টে টেস্টটির বর্ণনা দেওয়া একটি কমেন্ট থাকবে, তারপর `call assert_equal` দিয়ে শুরু হওয়া আসল টেস্টটি। যেমন:

```
  ! Test 16: non-letters with question
  call assert_equal("Sure.", hey(":) ?"), "non-letters with question")
```

কোনো টেস্ট নিষ্ক্রিয় করতে, শুধু `'!'` দিয়ে সেটি কমেন্ট করে দিন। যেমন:

```
  ! Test 16: non-letters with question
  ! call assert_equal("Sure.", hey(":) ?"), "non-letters with question")
```

প্রতিটি অনুশীলনী শেষ করার প্রক্রিয়াটি হলো:

* CMake দিয়ে প্রাথমিক বিল্ড তৈরি করা
* প্রতিটি ইউনিট টেস্টের জন্য:
 * টেস্টটি ফেল করাতে কম্পাইল এররগুলো দূর করা।
 * টেস্টটি পাস করাতে ঠিক যতটুকু দরকার ততটুকুই ইমপ্লিমেন্ট করা।
 * পড়ার যোগ্যতা বাড়াতে, পুনরাবৃত্তি কমাতে ইত্যাদির জন্য আপনার ইমপ্লিমেন্টেশন রিফ্যাক্টর করা।
 * পরের টেস্টটি আনকমেন্ট করা।


## CMake দিয়ে প্রাথমিক বিল্ড তৈরি করা

প্রতিটি অনুশীলনীর সাথে ইউনিট টেস্টের পাশাপাশি একটি `CMakeLists.txt` ফাইল আসবে। এতে রেডিমেড CMake রেসিপি থাকে, যা আপনার হয়ে বিল্ড সামলে নেয়। এই ফাইলটি আপনার সম্পাদনা করার দরকার পড়ার কথা নয়। প্রদত্ত রেসিপিটি ধরে নেয় যে আপনার ইমপ্লিমেন্টেশনটি অনুশীলনীর নামে নামকরণ করা একটি সোর্স ফাইলে রয়েছে।

যেমন, "Bob" অনুশীলনী `bob.f90` ফাইলে একটি ইমপ্লিমেন্টেশন আশা করে।

**CMake রান করার আগে আপনার প্রাথমিক ইমপ্লিমেন্টেশন ফাইলগুলো তৈরি করুন।**
"Bob" অনুশীলনীর জন্য CMake রান করার সময় আপনার কাছে `bob.f90` ফাইল না থাকলে, CMake ফাইল খুঁজে পাওয়া যায়নি এমন একটি এরর তৈরি করবে।
**এই ফাইলগুলো খালি থাকতে পারে, তবে সেগুলো অবশ্যই থাকতে হবে।**

এই রেসিপি ব্যবহার করে, উপযুক্ত জেনারেটর এবং অনুশীলনীর ডিরেক্টরির অবস্থান দিয়ে `cmake -G` রান করলে CMake আপনার এনভায়রনমেন্টের জন্য উপযুক্ত একটি প্রজেক্ট তৈরি করতে পারে। CMake আপনার অপারেটিং সিস্টেমের জন্য উপযুক্ত একটি বিল্ড স্ক্রিপ্ট তৈরি করবে। ওই জেনারেট করা ফাইলগুলো আপনার অনুশীলনীর সোর্স কোড থেকে আলাদা রাখতে, সাধারণত `build` নামে একটি ডিরেক্টরি তৈরি করা হয়, যেখানে এই জেনারেট করা বিল্ড ফাইল এবং কম্পাইল করা কোড রাখা হয়।

এতে আপনার অনুশীলনীর ফোল্ডার গোছানো ও পরিপাটি থাকে।

**দ্রষ্টব্য: প্রথমবার `cmake` কল করা হলে, [testlib](###-Testlib) স্বয়ংক্রিয়ভাবে ডাউনলোড হয়ে যাবে। ইউনিট টেস্ট কাজ করার জন্য `testlib` দরকার।

যেহেতু প্রতিটি অ্যাসাইনমেন্টের জন্য বিল্ড নির্দেশনা তৈরি করতে আপনি CMake রান করবেন, তাই এই কমান্ডের জন্য একটি ব্যাশ স্ক্রিপ্ট (Linux/MacOS) বা ব্যাচ ফাইল (Windows) তৈরি করে রাখতে পারেন।

CMake একবার বিল্ড এনভায়রনমেন্ট তৈরি করে ফেললে, আপনার এনভায়রনমেন্টের উপযুক্ত কমান্ড দিয়ে কোড বিল্ড করতে পারবেন:

* Linux-এ make দিয়ে: `make`
* Windows-এ Visual Studio দিয়ে: মেনু থেকে Build / Build Solution নির্বাচন করুন।
* Windows-এ MingW দিয়ে: `mingw32-make.exe`
* Windows-এ nMake দিয়ে: `nmake.exe`
* MacOS-এ Xcode দিয়ে: টুলবার থেকে Build নির্বাচন করুন।

বিভিন্ন এনভায়রনমেন্টে CMake রান করার উদাহরণ নিচে দেখানো হয়েছে।

### Linux\MacOS-এ Make দিয়ে

CMake-এর জেনারেটরের নাম `Unix Makefiles`।
ধরা যাক, বর্তমান অনুশীলনীটি `bob` এবং আমরা অনুশীলনীর ফোল্ডারে আছি:

```
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake -G "Unix Makefiles" ..
$ make
```

এই উদাহরণে CMake রান করার আগে ইমপ্লিমেন্টেশনের জন্য খালি ফাইল তৈরি করা দেখানো হয়েছে।

টেস্ট কম্পাইল করতে বিল্ড ডিরেক্টরিতে শুধু make টাইপ করুন। এতে কম্পাইল-টাইম এরর তৈরি হওয়া উচিত। এররগুলো ঠিক হয়ে গেলে আবার `make` রান করুন। সব বিল্ড এরর ঠিক হয়ে গেলে টেস্টগুলো রান করুন:

```
$ ctest -V
```
### Windows-এ Visual Studio 2017 দিয়ে

CMake-এর জেনারেটরের নাম `Visual Studio 15`। একই জেনারেটর Visual Studio 2017-এর সব IDE সংস্করণ সমর্থন করে: Community, Professional, এবং Enterprise। ধরা যাক, বর্তমান অনুশীলনীটি `bob` এবং আমরা অনুশীলনীর ফোল্ডারে আছি:

```
> copy nul: bob.f90
> mkdir build
> cd build
> cmake -G "Visual Studio 15" ..
```

এই উদাহরণে CMake রান করার আগে ইমপ্লিমেন্টেশনের জন্য খালি ফাইল তৈরি করা দেখানো হয়েছে।

### Testlib

টেস্টগুলো `testlib` নামের একটি ছোট লাইব্রেরির উপর নির্ভর করে, যা cmake দিয়ে প্রথমবার বিল্ড কনফিগার করার সময় github থেকে ডাউনলোড হয়।

ডাউনলোড ব্যর্থ হলে, ম্যানুয়ালি ডাউনলোড করা যায়। যেমন:

```
mkdir testlib
cd testlib
wget https://raw.githubusercontent.com/exercism/fortran/master/testlib/CMakeLists.txt
wget https://raw.githubusercontent.com/exercism/fortran/master/testlib/TesterMain.f90
```
