# নির্দেশাবলি

এই অনুশীলনীতে আপনি এমন কিছু কোড লিখবেন, যা একজন ফ্রিল্যান্সারকে নির্দিষ্ট কিছু প্রজেক্টের দাম নিয়ে তার ক্লায়েন্টদের সাথে যোগাযোগ করতে সাহায্য করবে।
ক্লায়েন্টদের জন্য খরচ দ্রুত হিসাব করার জন্য আপনি কয়েকটি ইউটিলিটি মেথড লিখবেন।

```exercism/note
`rate_per_hour` প্যারামিটার এবং `day_rate` মেথড দুটিই টাকার সাথে সম্পর্কিত।
পরিমাপের একক হলো সময়ের প্রতি এককের বিনিময়ে টাকা: যথাক্রমে ঘণ্টা এবং দিন।
```

## 1. ঘণ্টাপ্রতি রেট থেকে দৈনিক রেট হিসাব করুন

একজন ক্লায়েন্ট রেট সম্পর্কে জানতে চেয়ে ফ্রিল্যান্সারের সাথে যোগাযোগ করে।
ফ্রিল্যান্সার ব্যাখ্যা করে যে **_সে দিনে ৮ ঘণ্টা কাজ করে।_**
তবে ফ্রিল্যান্সার প্রজেক্টটির ব্যাপারে তার ঘণ্টাপ্রতি রেটই কেবল জানে।
ঘণ্টাপ্রতি রেট থেকে দৈনিক রেট হিসাব করতে তাকে সাহায্য করুন।

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

দৈনিক রেটটি রাউন্ড করতে বা একটি "নির্দিষ্ট" প্রিসিশনে বদলাতে হবে না।

## 2. নির্দিষ্ট বাজেট থেকে কর্মদিবসের সংখ্যা হিসাব করুন

আরেকদিন একজন প্রজেক্ট ম্যানেজার ফ্রিল্যান্সারকে নির্দিষ্ট বাজেটের একটি প্রজেক্টে কাজ করার প্রস্তাব দেয়।
নির্দিষ্ট বাজেট এবং ফ্রিল্যান্সারের ঘণ্টাপ্রতি রেট থেকে, বাজেট শেষ না হওয়া পর্যন্ত সে কত দিন কাজ করবে তা হিসাব করতে তাকে সাহায্য করুন।
ফলাফলটি _অবশ্যই_ **নিকটতম পূর্ণসংখ্যায় রাউন্ড ডাউন** করতে হবে।

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. বড় প্রজেক্টের জন্য ডিসকাউন্টযুক্ত রেট হিসাব করুন

প্রায়ই ফ্রিল্যান্সারের ক্লায়েন্টরা তাকে কয়েক মাসব্যাপী প্রজেক্টে নিয়োগ দেয়।
এসব ক্ষেত্রে ফ্রিল্যান্সার প্রতিটি পূর্ণ মাসের জন্য ডিসকাউন্ট দেওয়ার সিদ্ধান্ত নেয়, আর বাকি দিনগুলোর বিল দৈনিক রেটে ধরা হয়।
আপনার চমৎকার ওয়ার্ক-লাইফ ব্যালান্সের কারণে আপনি প্রতি ক্যালেন্ডার মাসে মাত্র ২২ দিন কাজ করেন, তাই **_প্রতিটি মাসে ২২টি বিলযোগ্য দিন থাকে।_**
ঘণ্টাপ্রতি রেট, প্রজেক্টে থাকা বিলযোগ্য দিনের সংখ্যা এবং মাসিক ডিসকাউন্ট রেট দিয়ে এ ধরনের প্রজেক্টের খরচ হিসাব করতে তাকে সাহায্য করুন।
ডিসকাউন্ট সবসময় একটি সংখ্যা হিসেবে দেওয়া হয়, যেখানে `42%` হয়ে যায় `0.42`.
ফলাফলটি _অবশ্যই_ **নিকটতম পূর্ণসংখ্যায় রাউন্ড আপ** করতে হবে।

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
