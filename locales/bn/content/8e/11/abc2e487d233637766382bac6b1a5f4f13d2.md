# পরিচিতি

Swift-এ এমন কিছু স্টেটমেন্ট আছে যা লুপের স্বাভাবিক কন্ট্রোল ফ্লো বদলাতে ব্যবহার করা যায়। এগুলোকে কন্ট্রোল ট্রান্সফার স্টেটমেন্ট বলা হয়। আপনি ইতিমধ্যে `return` দেখেছেন; এই কনসেপ্টে আরও কয়েকটির সঙ্গে পরিচয় করানো হবে, যার মধ্যে আছে `continue`, `break` এবং লেবেল।

## Continue

কখনও কখনও লুপের চলতি ইটারেশনের বাকি স্টেটমেন্টগুলো শেষ না করেই আগেভাগে লুপের পরের ইটারেশনে চলে যাওয়া দরকার হয়। এর জন্য `continue` কিওয়ার্ডটি ব্যবহার করা যায়। `continue` চালানো হলে লুপটি সরাসরি পরের পরীক্ষায় চলে যায়, যেখানে দেখা হয় লুপের পরের ইটারেশনটি রান করা যাবে কি না; অর্থাৎ while ও repeat-while লুপে `while` শর্তটি, আর for-in লুপে সিকোয়েন্সে আরেকটি এলিমেন্ট আছে কি না সেই পরীক্ষাটি।

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break লুপ থেকে আগেভাগে বেরিয়ে যেতে ব্যবহার করা হয়। `break` চালানো হলে লুপটি সঙ্গে সঙ্গে শেষ হয়ে যায় এবং প্রোগ্রামটি লুপের পরের প্রথম স্টেটমেন্ট দিয়ে চলতে থাকে।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## লেবেল

লুপ নেস্টেড থাকলে কখনও কখনও অবস্থা এমন হয় যে, `break` বা `continue` যে লুপে ব্যবহার করা হচ্ছে তার বাইরের লুপ থেকে বেরিয়ে আসতে বা সেই লুপ আবার শুরু করতে চাওয়া হতে পারে। এমন ক্ষেত্রে কোন লুপ থেকে বেরোতে হবে বা কোনটি আবার শুরু করতে হবে তা নির্দিষ্ট করতে লেবেল ব্যবহার করা যায়। লুপ শুরু করা `while`, `repeat` বা `for`-এর আগে একটি নাম ও তারপর একটি কোলন বসিয়ে লুপে লেবেল দেওয়া যায়।

এভাবে লেবেল ব্যবহারের ফল দেখতে হলে নিচের লুপটি দেখুন।

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

`fallthrough` কিওয়ার্ডটি switch স্টেটমেন্টে পরের কেসে চলে যাওয়ার জন্য ব্যবহার করা হয়। এর মানে হলো পরের কেসের কোডটি তার শর্ত পরীক্ষা না করেই চালানো হবে। এর ফলে switch স্টেটমেন্টটি অন্য প্রোগ্রামিং ভাষার মতো আচরণ করবে, যেখানে একটি কেস মিলে যাওয়ার পর switch স্টেটমেন্ট থেকে বেরোতে `break` স্টেটমেন্টের প্রয়োজন হয় না। `fallthrough` সম্পর্কে আরও জানতে [Swift বইটি][fallthrough] পড়ুন।

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
