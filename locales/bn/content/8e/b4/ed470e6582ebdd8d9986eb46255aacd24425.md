# নির্দেশনা

নিচের মতো একটি ASCII ডায়াগ্রামে আয়তক্ষেত্রগুলো গণনা করুন।

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

উপরের ডায়াগ্রামটিতে এই ৬টি আয়তক্ষেত্র আছে:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

আপনি ধরে নিতে পারেন যে ইনপুটটি সবসময়ই একটি যথাযথ আয়তক্ষেত্র (অর্থাৎ প্রতিটি লাইনের দৈর্ঘ্য প্রথম লাইনের দৈর্ঘ্যের সমান)।
