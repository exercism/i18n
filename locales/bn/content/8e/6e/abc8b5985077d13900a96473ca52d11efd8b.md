# Tests

## Clojure CLI

Exercism-এ Clojure অনুশীলনীগুলো একটি `deps.edn` ফাইল নিয়ে আসে, যেটিতে [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner) চালু করার জন্য `:test` অ্যালিয়াস থাকে:

``` bash
$ clj -X:test
```

## Leiningen

অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি চালিয়ে Leiningen দিয়েও অনুশীলনীর test চালানো যায়:

```bash
lein test
```

## REPL

REPL ব্যবহার করে অনুশীলনীর test চালাতে হলে, অনুশীলনীর ডিরেক্টরি থেকে নিচের কমান্ডটি চালান:

```bash
$ clj
```

-অথবা-

```bash
$ lein repl
```

এরপর অনুশীলনীর test নেমস্পেস এবং Clojure test নেমস্পেস `require` করুন:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

এরপর `<exercise>-test` নেমস্পেসে `run-tests` কল করুন:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
