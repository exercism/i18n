# পরিচিতি

Haxe একটি স্ট্রংলি টাইপড ভাষা, তবে প্রয়োজনে টাইপিং সিস্টেমকে অমান্য করা যায়। একটি নামে একটি মান অ্যাসাইন করাকে ভ্যারিয়েবল ডিফাইন করা বলা হয়। কোনো ভ্যারিয়েবল ডিফাইন করা যায় হয় তার টাইপ স্পষ্টভাবে উল্লেখ করে, নয়তো Haxe কম্পাইলারকে টাইপ অনুমান করতে দিয়ে। তাই নিচের দুটি ভ্যারিয়েবল ডেফিনিশন আসলে একই:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

`=` অপারেটর ব্যবহার করে ভ্যারিয়েবল আপডেট করা যায়:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

ভ্যারিয়েবলের থেকে ভিন্ন টাইপের একটি মান অ্যাসাইন করার চেষ্টা করলে কম্পাইলার একটি এরর ছুড়ে দেবে:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

ক্লাসের ভিতরে থাকা ফাংশনকে _মেথড_ বলা হয়। মেথডে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে। সব প্যারামিটারই স্পষ্টভাবে টাইপ করা থাকতে হবে। প্যারামিটারগুলোর মতোই, মেথডের রিটার্ন টাইপ অনুমান করা যায় না এবং অবশ্যই টাইপ করতে হবে। `return` কিওয়ার্ড ব্যবহার করে মেথড থেকে মান রিটার্ন করা হয়:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

একটি মেথড কল করতে হলে তার ক্লাস ও মেথডের নাম উল্লেখ করে আর্গুমেন্ট পাস করতে হয়:

```haxe
var sum = add(1, 2) // sum = 3
```

Haxe-এ স্কোপ নির্ধারিত হয় `{` ও `}` অক্ষর দুটির মধ্যে।

Haxe দুই ধরনের কমেন্ট সমর্থন করে। এক লাইনের কমেন্টের আগে `//` বসে, আর বহু-লাইনের কমেন্ট লেখা হয় `/*` ও `*/`-এর মধ্যে।
