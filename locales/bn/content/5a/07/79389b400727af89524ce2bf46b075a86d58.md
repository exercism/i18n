# সম্পর্কে

`if` স্টেটমেন্ট ছাড়াও শর্তসাপেক্ষে লজিক চালানোর জন্য `switch` স্টেটমেন্টও আছে। কোনো একটি ভ্যারিয়েবলের মান একাধিক ভিন্ন মানের সাথে তুলনা করার দরকার হলে এটি ব্যবহার করা হয়। Haxe-এ কোনো ভ্যারিয়েবল x-এর জন্য switch স্টেটমেন্টের সিনট্যাক্স নিম্নরূপ।

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

অন্য কোনো কেস মিলে না গেলে `default` কেসটি চালানো হয়।
