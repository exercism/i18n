# নির্দেশনা

এই অনুশীলনীতে আপনি একটি গাড়ির কারখানার অ্যাসেম্বলি লাইনের উৎপাদন বিশ্লেষণ করার কোড লিখবেন। অ্যাসেম্বলি লাইনের গতি `0` (বন্ধ) থেকে `10` (সর্বোচ্চ) পর্যন্ত হতে পারে।

সবচেয়ে কম গতিতে (`1`) প্রতি ঘণ্টায় `221`টি গাড়ি উৎপাদিত হয়। গতি বাড়ার সাথে সাথে উৎপাদন রৈখিকভাবে বাড়ে। তাই গতি `4` হলে প্রতি ঘণ্টায় `4 * 221 = 884`টি গাড়ি উৎপাদিত হওয়া উচিত। তবে গতি বেশি হলে ত্রুটিপূর্ণ গাড়ি তৈরি হওয়ার সম্ভাবনা বেড়ে যায়, যেগুলো পরে বাদ দিতে হয়। নিচের টেবিলে দেখা যায় গতি সফলতার হারকে কীভাবে প্রভাবিত করে:

- `1` থেকে `4`: ১০০% সফলতার হার।
- `5` থেকে `8`: ৯০% সফলতার হার।
- `9`: ৮০% সফলতার হার।
- `10`: ৭৭% সফলতার হার।

আপনার দুটি কাজ আছে।

## 1. ঘণ্টায় উৎপাদন হার হিসাব করুন

অ্যাসেম্বলি লাইনের বর্তমান গতি ও সফলতার হার বিবেচনা করে প্রতি ঘণ্টায় তার উৎপাদন হার হিসাব করতে `CarsAssemble.productionRatePerHour()` মেথডটি ইমপ্লিমেন্ট করুন:

```Java
CarsAssemble.productionRatePerHour(6)
// => 1193.4
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `double`।

## 2. প্রতি মিনিটে কতগুলো কার্যকর আইটেম উৎপাদিত হয় তা হিসাব করুন

প্রতি মিনিটে কতগুলো কার্যকর গাড়ি উৎপাদিত হয় তা হিসাব করতে `CarsAssemble.workingItemsPerMinute()` মেথডটি ইমপ্লিমেন্ট করুন:

```Java
CarsAssemble.workingItemsPerMinute(6)
// => 19
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `int`।
