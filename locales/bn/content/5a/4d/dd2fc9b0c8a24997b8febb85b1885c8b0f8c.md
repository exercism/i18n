# পরিচিতি

একটি ব্লক হলো একগুচ্ছ স্টেটমেন্ট ও ডিক্লারেশন, যা একটি সিনট্যাক্টিক একক হিসেবে একত্রিত করা হয়েছে।
ব্লক প্রায়ই দ্বিতীয় বন্ধনীর ভেতরে সংজ্ঞায়িত হয়, তবে সবসময় নয়।
ব্লক ফাংশনের ভেতরে এবং অন্য ব্লকের ভেতরেও নেস্ট করা যায়।

একটি ফাংশন অনেকটা একটি ব্লকের মতো কাজ করে।
একটি ফাংশনে সংজ্ঞায়িত ভ্যারিয়েবলের আইডেন্টিফায়ার ফাংশনের বাইরে থেকে দেখা যায় না, ঠিক যেমন একটি ব্লকে সংজ্ঞায়িত ভ্যারিয়েবলের আইডেন্টিফায়ার ওই ব্লকের বাইরে থেকে দেখা যায় না।
দুটি ফাংশনে থাকা দুটি ভ্যারিয়েবলের নাম একই হতে পারে, কারণ দুটি ফাংশন একটির ভেতরে আরেকটি দেখতে পায় না, ঠিক যেমন দুটি ব্লকে থাকা দুটি ভ্যারিয়েবলের নাম একই হতে পারে, কারণ দুটি ব্লক একটির ভেতরে আরেকটি দেখতে পায় না।
কিন্তু ফাংশন আর ব্লক এক জিনিস নয়।
একটি ফাংশনের ভেতরে আরেকটি ফাংশন নেস্ট করা যায় না, কিন্তু একটি ব্লকের ভেতরে আরেকটি ব্লক নেস্ট করা যায়।

নিচের উদাহরণে `number` সংজ্ঞায়িত করা হয়েছে `main` ফাংশনের ভেতরে।
`flag` সংজ্ঞায়িত করা হয়েছে `if` ব্লকের ভেতরে, যেটি আবার `main` ফাংশনের ভেতরে নেস্ট করা।
একটি ব্লকের ভেতরে সংজ্ঞায়িত ভ্যারিয়েবল কেবল ওই ব্লকেই বৈধ।
তাই কোডটি কম্পাইল করার চেষ্টা করলে একটি কম্পাইলেশন এরর দেখা দেয়।

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

এরর মেসেজটি বিভ্রান্তিকর মনে হতে পারে, কারণ ফাংশনে আগেই `flag` ব্যবহার করা _হয়েছে_।
তবে `flag` সংজ্ঞায়িত করা হয়েছে ফাংশনের ভেতরের একটি ব্লকে।
ভেতরের ব্লকটি তার বাইরের ফাংশনের `number` ভ্যারিয়েবলটি "দেখতে" পারে, কিন্তু বাইরের ফাংশনটি তার ভেতরের ব্লকে সংজ্ঞায়িত `flag` ভ্যারিয়েবলটি "দেখতে" পারে না।
একবার এক্সিকিউশন ব্লকটি ছেড়ে বেরিয়ে গেলে, `flag` ভ্যারিয়েবলটি স্বয়ংক্রিয়ভাবে ধ্বংস হয়ে যায় এবং আর প্রোগ্রামের জন্য উপলভ্য থাকে না।
`main` ফাংশন নিজেই `flag` আইডেন্টিফায়ারটি প্রথম দেখে শেষের `printf` স্টেটমেন্টে গিয়ে।
শেষের `printf` স্টেটমেন্টটি সরিয়ে দিলে, প্রোগ্রামটি কম্পাইল হবে এবং রান করলে `1` প্রিন্ট করবে।
কারণ `flag` ভ্যারিয়েবলটি প্রথম `printf` স্টেটমেন্টটি যে ব্লকে আছে, সেই ব্লকে বৈধ।

`C99` থেকে শুরু করে, একলাইনের `if`, `for`, `while` ও `do` স্টেটমেন্টকেও ব্লক হিসেবে গণ্য করা হয়।
নিচের উদাহরণে, যদিও `i` দ্বিতীয় বন্ধনীর ভেতরে সংজ্ঞায়িত নয়, এটি কেবল `for` স্টেটমেন্ট দিয়ে সংজ্ঞায়িত ব্লকেই বিদ্যমান, এবং বাইরের `main` ফাংশনের কাছে দৃশ্যমান নয়।

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

শেষের `printf` স্টেটমেন্টটি সরিয়ে দিলে, প্রোগ্রামটি কম্পাইল হবে এবং রান করলে `0 2 4 6 8 10 ` প্রিন্ট করবে।
Go ও Rust-এর মতো কিছু ভাষা স্পষ্টভাবে বলে যে একলাইনের শর্তমূলক ও লুপ স্টেটমেন্টও একটি ব্লক গঠন করে।
তারা দাবি করে যে এমন একলাইনের স্টেটমেন্টও অবশ্যই দ্বিতীয় বন্ধনীর ভেতরে রাখতে হবে।
