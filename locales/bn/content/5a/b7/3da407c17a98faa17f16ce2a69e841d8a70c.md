# Char

`Char` হলো Crystal-এর একটি ডেটা টাইপ, যা একটি ৩২-বিট [Unicode][unicode] কোড পয়েন্ট প্রকাশ করে।
এদের আকার এদেরকে মেমরি-সাশ্রয়ী করে তোলে এবং স্ট্রিংয়ের নেই এমন কিছু নির্দিষ্ট বৈশিষ্ট্য দেয়।
এগুলো একক কোটেশন চিহ্ন (`'`) দিয়ে তৈরি করা হয় এবং ভেতরে কেবল একটি Unicode কোড পয়েন্ট রাখা যায়।

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystal-এ স্ট্রিং নিয়ে কাজ করার সময় Char নিয়ে কাজ করা বেশ সাধারণ ব্যাপার, কারণ String ক্লাসের অনেক মেথড Char রিটার্ন করে বা আর্গুমেন্ট হিসেবে Char নেয়।
উদাহরণস্বরূপ, [`String#[]`][index] মেথড একটি Char রিটার্ন করে, আর [`String#chars`][chars] মেথড Char-এর একটি সংগ্রহ রিটার্ন করে।

## ইনক্রিমেন্ট / ডিক্রিমেন্ট

যেহেতু Char একটি ৩২-বিট Unicode কোড পয়েন্ট, তাই এরা ইনক্রিমেন্ট ও ডিক্রিমেন্ট সমর্থন করে। এর ফলে `'a'` থাকলে এক যোগ করে `'b'` পাওয়া যায়।

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

এছাড়া [`Char#succ`][succ] নামে একটি মেথড আছে, যা Unicode টেবিলে পরের Char রিটার্ন করে, এবং [`Char#pred`][pred], যা Unicode টেবিলে আগের Char রিটার্ন করে।

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## কনক্যাটিনেশন

যেহেতু Char কেবল একটি ৩২-বিট Unicode কোড পয়েন্ট প্রকাশ করার জন্যই তৈরি, তাই দুটি Char কনক্যাটিনেট করা যায় না।
তাই Char কেবল স্ট্রিংয়ের সাথে কনক্যাটিনেট করা যায়।

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## বৈশিষ্ট্যের মেথড

Crystal-এ একটি Char সম্পর্কে তথ্য পাওয়ার জন্য কয়েকটি মেথড আছে, যেমন এটি একটি সংখ্যা কি না, একটি অক্ষর কি না, বা এটি ছোট হাতের অক্ষর কি বড় হাতের অক্ষর।
এখানে এমন কিছু মেথডের তালিকা দেওয়া হলো; সম্পূর্ণ তালিকার জন্য দেখুন [Char API][char-api]:

| মেথড                             | বিবরণ                                                |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Char একটি সংখ্যা হলে `true` রিটার্ন করে              |
| [`Char#letter?`][letter]         | Char একটি অক্ষর হলে `true` রিটার্ন করে               |
| [`Char#lowercase?`][lowercase]   | Char ছোট হাতের অক্ষর হলে `true` রিটার্ন করে          |
| [`Char#uppercase?`][uppercase]   | Char বড় হাতের অক্ষর হলে `true` রিটার্ন করে          |
| [`Char#ascii?`][ascii]           | Char একটি ASCII অক্ষর হলে `true` রিটার্ন করে         |
| [`Char#whitespace?`][whitespace] | Char একটি হোয়াইটস্পেস অক্ষর হলে `true` রিটার্ন করে   |

## রূপান্তর

### কোড পয়েন্ট ও Char-এর মধ্যে রূপান্তর

যেহেতু Char একটি ৩২-বিট Unicode কোড পয়েন্ট, তাই Char ও কোড পয়েন্টের (Int) মধ্যে রূপান্তর করা যায়।
এটি করা যায় [`Char#ord`][ord] মেথড দিয়ে, যা Char-এর কোড পয়েন্ট রিটার্ন করে, বা [`Int#chr`][chr] মেথড দিয়ে, যা কোড পয়েন্টের Char রিটার্ন করে।

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### টাইপের মধ্যে রূপান্তর

অন্য ডেটা টাইপের মতো, Char-এরও টাইপের মধ্যে রূপান্তর করার জন্য কয়েকটি মেথড আছে।
সবচেয়ে কমনটি হলো `Char#to_s` মেথড, যা Char-কে একটি স্ট্রিংয়ে রূপান্তর করে। এছাড়া `Char#to_i` মেথডও আছে, যা Char-কে একটি Int-এ রূপান্তর করে, এবং `Char#to_f` মেথড, যা Char-কে একটি Float-এ রূপান্তর করে।

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## এস্কেপিং

স্ট্রিংয়ের মতো, কিছু ক্যারেক্টার সরাসরি লেখা যায় না, আর সেগুলো লিখতে হলে এস্কেপ করতে হয়।
আপনি `\` ক্যারেক্টার ব্যবহার করে একটি এস্কেপ সিকোয়েন্স লিখতে পারেন, তারপর যে ক্যারেক্টারটি এস্কেপ করতে চান সেটি।

Crystal-এ এগুলো হলো বিশেষ ক্যারেক্টার:

| মান      | বিবরণ                         |
| -------- | ----------------------------- |
| `\a`     | অ্যালার্ট                     |
| `\b`     | ব্যাকস্পেস                    |
| `\e`     | এস্কেপ                        |
| `\f`     | ফর্ম ফিড                      |
| `\n`     | লাইন ফিড বা নিউলাইন           |
| `\r`     | ক্যারেজ রিটার্ন                |
| `\t`     | অনুভূমিক ট্যাব                 |
| `\v`     | উল্লম্ব ট্যাব                  |
| `\\`     | ব্যাকস্ল্যাশ                   |
| `\'`     | একক কোটেশন                    |
| `\"`     | দ্বৈত কোটেশন                  |
| `\377`   | অক্টাল ASCII ক্যারেক্টার        |
| `\xFF`   | হেক্সাডেসিমাল ASCII ক্যারেক্টার |
| `\uFFFF` | হেক্সাডেসিমাল Unicode ক্যারেক্টার |
