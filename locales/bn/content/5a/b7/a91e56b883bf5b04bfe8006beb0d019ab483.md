# ভূমিকা

## R-এ বুলিয়ান

ট্রু বা ফলস মান `logical` টাইপ দিয়ে প্রকাশ করা হয়।
এতে শুধু দুটি মান থাকে: `TRUE` এবং `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## বুলিয়ান অপারেটর

R-এ পাঁচটি বুলিয়ান অপারেটর আছে, কিন্তু সিলেবাসের এই পর্যায়ে মাত্র তিনটি প্রাসঙ্গিক।
বাকি দুটি ভেক্টর নিয়ে কাজ করার সময় গুরুত্বপূর্ণ হবে, যা পরের বেশ কিছু কনসেপ্টে আলোচনা করা হয়েছে।

`&&` হলো বুলিয়ান "এবং"।
এটি `TRUE` হয় যদি `&&`-এর *উভয়* দিকের এক্সপ্রেশন `TRUE` হয়।

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` হলো বুলিয়ান "বা"।
এটি `TRUE` হয় যদি `||`-এর *যেকোনো* এক দিকের এক্সপ্রেশন `TRUE` হয়।

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` হলো বুলিয়ান "না"।
এটি `TRUE` এবং `FALSE` মান বিনিময় করে।

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

বড় এবং জটিল এক্সপ্রেশনের জন্য, আপনার উদ্দেশ্য স্পষ্ট করতে বন্ধনী ব্যবহার করা ভালো।

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
