# সম্পর্কে

ফাংশন এক বা একাধিক আর্গুমেন্টের জন্য [ডিফল্ট মান][default-arguments] ঘোষণা করতে পারে।

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- উপরের উদাহরণটি কম্পাইল করার সময় Elixir `number/0` (কোনো আর্গুমেন্ট নেই) এবং `number/1` (একটি আর্গুমেন্ট) এর জন্য একটি ফাংশন ডেফিনিশন তৈরি করে।
- যদি একাধিক আর্গুমেন্টের ডিফল্ট মান থাকে, তাহলে অনুপস্থিত আর্গুমেন্ট পূরণ করতে বাম থেকে ডান দিকে ফাংশনে ডিফল্ট মানগুলো প্রয়োগ করা হয়।
- ফাংশনে একাধিক ক্লজ থাকলে ডিফল্ট আর্গুমেন্টের জন্য একটি [ফাংশন হেডার][function-header] লিখতে হয়।
- যেকোনো এক্সপ্রেশনই ডিফল্ট মান হিসেবে কাজ করতে পারে।
- অ্যানোনিমাস ফাংশনে ডিফল্ট আর্গুমেন্ট থাকতে পারে না।

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
