# নির্দেশাবলী

মেরি টিভি সিরিজ _Star Trek: The Next Generation_-এর একজন বড় ভক্ত। তিনি প্রায়ই কলম-কাগজের রোল প্লেয়িং গেম খেলেন, যেখানে তিনি ও তাঁর বন্ধুরা _Starship Enterprise_-এর ক্রু সেজে অভিনয় করেন। মেরির চরিত্রটি ক্যাপ্টেন পিকার্ড, অর্থাৎ তাঁকে ক্যাপ্টেনের লগ রাখতে হয়। গেমটির সৃজনশীল অংশটি তিনি খুব ভালোবাসেন, কিন্তু সঙ্গে সঙ্গে র্যান্ডম ডেটা জেনারেট করতে পছন্দ করেন না।

ক্যাপ্টেনের লগে সাধারণত যে ডেটা দেখা যায়, তার জন্য র্যান্ডম জেনারেটর তৈরি করে মেরিকে সাহায্য করুন।

## 1. একটি র্যান্ডম গ্রহ তৈরি করুন

_Starship Enterprise_ তার যাত্রায় অনেক গ্রহের মুখোমুখি হয়। স্টার ট্রেক মহাবিশ্বের গ্রহগুলোকে তাদের বৈশিষ্ট্যের ভিত্তিতে ক্লাসে ভাগ করা হয়েছে। উদাহরণস্বরূপ, পৃথিবী একটি M ক্লাসের গ্রহ। সম্ভাব্য সব গ্রহের ক্লাস হলো: D, H, J, K, L, M, N, R, T এবং Y।

`random_planet_class/0` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি র্যান্ডমভাবে গ্রহের ক্লাসগুলোর একটি রিটার্ন করবে।

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. একটি র্যান্ডম স্টারশিপ রেজিস্ট্রি নম্বর তৈরি করুন

মহাকাশে ঘুরে বেড়ানো একমাত্র স্টারশিপ এন্টারপ্রাইজ (রেজিস্ট্রি নম্বর NCC-1701) নয়! অন্য একটি স্টারশিপের সঙ্গে মিলিত হলে মেরিকে সেই স্টারশিপের রেজিস্ট্রি নম্বর লগ করতে হয়।

রেজিস্ট্রি নম্বরের শুরুতে "NCC-" প্রিফিক্স থাকে এবং তারপর 1000 থেকে 9999 (সহ) পর্যন্ত একটি সংখ্যা ব্যবহৃত হয়।

`random_ship_registry_number/0` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি র্যান্ডম স্টারশিপ রেজিস্ট্রি নম্বর রিটার্ন করে।

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. একটি র্যান্ডম স্টারডেট তৈরি করুন

লগে তারিখ না থাকলে লগের কী লাভ?

স্টারডেট হলো একটি ফ্লোটিং পয়েন্ট সংখ্যা। _The Next Generation_-এর প্রথম সিজনের _Starship Enterprise_-এর অভিযানগুলো 41000.0 থেকে 42000.0 স্টারডেটের মধ্যে ঘটে। এখানে "4" বোঝায় ২৪তম শতাব্দী, আর "1" বোঝায় প্রথম সিজন।

`random_stardate/0` ফাংশনটি ইমপ্লিমেন্ট করুন, যা 41000.0 (সহ) থেকে 42000.0 (বহির্ভূত) এর মধ্যে একটি ফ্লোটিং পয়েন্ট সংখ্যা রিটার্ন করে।

ইমপ্লিমেন্টেশনে একটি Erlang ফাংশন ব্যবহার করা উচিত।

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. স্টারডেট ফরম্যাট করুন

ক্যাপ্টেনের লগে স্টারডেট সাধারণত এক দশমিক স্থান পর্যন্ত রাউন্ড করা হয়।

`format_stardate/1` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি ফ্লোটিং পয়েন্ট সংখ্যা নেবে এবং সংখ্যাটি এক দশমিক স্থান পর্যন্ত রাউন্ড করা একটি স্ট্রিং রিটার্ন করবে।

ইমপ্লিমেন্টেশনে একটি Erlang ফাংশন ব্যবহার করা উচিত।

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
