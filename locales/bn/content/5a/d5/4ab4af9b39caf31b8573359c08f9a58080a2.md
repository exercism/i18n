# Instructions

আপনার কাজ হলো টেবিলে বসার নিখুঁত বিন্যাস খুঁজে বের করা।
আপনি এটি করবেন _ফ্যাক্ট_ (যে বিষয়গুলো সবসময় সত্য) এবং _রুল_ (যে বিষয়গুলো শর্তসাপেক্ষে সত্য) ঘোষণা করে।

## 1. আড্ডাবাজ মানুষদের তালিকা করুন

আড্ডাবাজ মানুষদের বোঝাতে `chatty` ফ্যাক্টটি ডিফাইন করুন।
`chatty` ফ্যাক্টটি একটি মাত্র আর্গুমেন্ট নেয়: আড্ডাবাজ ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম।

```prolog
chatty(gustavo).
true.
```

## 2. কে কাকে পছন্দ করে তার তালিকা করুন

কে কাকে পছন্দ করে তা বোঝাতে `likes` ফ্যাক্টটি ডিফাইন করুন।
`likes` ফ্যাক্টটি দুটি আর্গুমেন্ট নেয়:

1. যে ব্যক্তি অন্যজনকে পছন্দ করে তার ছোট হাতের অক্ষরে লেখা নাম
2. যাকে পছন্দ করা হচ্ছে সেই ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম

```prolog
likes(esteban, malena).
true.
```

## 3. একে অন্যকে পছন্দ করা দুজন মানুষ ভালো জোড়া তৈরি করে

দুজন মানুষ একে অন্যকে পছন্দ করলে `pairing` রুলটি সত্য হবে বলে ডিফাইন করুন।
pairing রুলটি দুটি আর্গুমেন্ট নেয়:

1. প্রথম ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম
2. দ্বিতীয় ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম

```prolog
pairing(malena, esteban).
true.
```

## 4. আড্ডাবাজ মানুষ যে কারও সাথে জোড়া বাঁধে

জোড়া বাঁধা দুজনের (অন্তত) একজন আড্ডাবাজ হলে `pairing` রুলটি সত্য হবে বলে ডিফাইন করুন।

```prolog
pairing(valeria, jaime).
true.
```

## 5. বসার বিন্যাস যাচাই করুন

পাঁচটি জোড়াই ভালো জোড়া হলে `seating` রুলটি সত্য হবে বলে ডিফাইন করুন।

pairing রুলটি পাঁচটি আর্গুমেন্ট নেয়:

1. প্রথম ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম
2. দ্বিতীয় ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম
3. তৃতীয় ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম
4. চতুর্থ ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম
5. পঞ্চম ব্যক্তির ছোট হাতের অক্ষরে লেখা নাম

বসার বিন্যাস যাচাই করতে এইমাত্র ডিফাইন করা ফ্যাক্ট ও রুলগুলো ব্যবহার করুন।

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
