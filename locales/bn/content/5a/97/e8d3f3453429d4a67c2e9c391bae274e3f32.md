# SQLite-নির্দিষ্ট নির্দেশনা

* **digits** কলামে পূর্ণসংখ্যার একটি JSON-এনকোড করা তালিকা থাকে।
  উদাহরণ:
  ```json
  [1,0,1,0,1,0]
  ```
* **result** কলামে JSON-এনকোড করা ডেটা থাকা উচিত: একটি অবজেক্ট, যেখানে digits পূর্ণসংখ্যা হিসেবে থাকে, অথবা যেকোনো এররের বর্ণনা।
  উদাহরণ:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  অথবা
  ```json
  {"error":"some error description"}
  ```

## টেবিল স্কিমা

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
