# পরিচিতি

Factor-এর এরর সিস্টেমে তিনটি অংশ আছে: `throw` ([`kernel`][kernel]-এ) একটি এরর তোলে, `recover` ([`continuations`][continuations]-এ) সেটি ধরে, আর `ERROR:` একটি টুপল-টাইপের এরর ক্লাস ডিফাইন করে।

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` *try* কোড ব্লকটি রান করে; সেটি যদি এরর তোলে, তবে এররটি পুশ হয় আর *recovery* কোড ব্লকটি রান হয়।

`ERROR:` ক্লাসটি *এবং* একটি কনস্ট্রাক্টর ওয়ার্ড, দুটোই ডিক্লেয়ার করে; ওই কনস্ট্রাক্টর ওয়ার্ড নতুন একটি ইনস্ট্যান্স তোলে:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```
