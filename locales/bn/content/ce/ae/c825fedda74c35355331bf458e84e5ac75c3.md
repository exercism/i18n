# ভূমিকা

ছোট ওয়ার্ডের ক্ষেত্রে স্ট্যাক নিয়ে নাড়াচাড়া করলেই কাজ চলে। কিন্তু যখন একটি ওয়ার্ডে একাধিক ইনপুট থাকে আর সেগুলোকে নাম ধরে উল্লেখ করতে হয়, তখন Factor দেয় *লোকাল*, অর্থাৎ নামযুক্ত বাইন্ডিং। এগুলো চালু করা হয় `::` দিয়ে (ওয়ার্ড ডেফিনিশনের জন্য) বা `[| | ]` দিয়ে (ইনলাইন ল্যাম্বডার জন্য), আর দুটোই আসে [`locals`][locals] থেকে।

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

একটি কোয়োটেশনের ভেতরে `[| inputs | body ]` হলো নামযুক্ত ইনপুটসহ একটি ল্যাম্বডা:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
