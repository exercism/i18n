# গার্ড ব্যবহার করুন

[comment]: # (সমাধানটিতে গার্ড একেবারেই ব্যবহার না করলে এই এররটি দেখানো হয়)

নন-বাইনারি ইনপুট নিয়ে `two_fer/1` যেন কোড চালাতে না পারে, সেজন্য [গার্ড](https://hexdocs.pm/elixir/master/guards.html) ব্যবহার করুন।

> মনে রাখবেন, elixir-এ [স্ট্রিং](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)-কে [বাইনারি ডেটা](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) হিসেবে ধরা হয়।

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> এই গার্ডটি `iex`-এ পরীক্ষা করা যায়

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
