# Exercism API

## বিবরণ

Exercism-এর বেশিরভাগ ভাষার ট্র্যাক অনুশীলনী সংগ্রহ ও জমা দেওয়ার জন্য `exercism` কমান্ড লাইন টুলটি ব্যবহার করে, যা একটি REST API-এর মাধ্যমে `exercism.io`-এর সাথে যোগাযোগ করে। এর বদলে Pharo Smalltalk ভাষার ট্র্যাকটি একই REST API ব্যবহার করে কোনো মধ্যস্থতাকারী টুলের সাহায্য ছাড়াই Pharo ইমেজের ভিতরে ও বাইরে অনুশীলনী আনা-নেওয়া করে। এই ডকুমেন্টে Exercism API-এর বিস্তারিত আলোচনা করা হয়েছে, বিশেষ নজর রাখা হয়েছে Pharo Smalltalk ভাষার ট্র্যাকটি কীভাবে এটি ব্যবহার করে তার দিকে। এটি Pharo Smalltalk টুলিং-এর মেইনটেইনারদের উদ্দেশে লেখা।

## হেডার

সব এন্ডপয়েন্টের জন্য অনুরোধে হেডার নিচের মানে সেট করা আবশ্যক:

```
Authorization: Bearer <token>
```

`<token>` মানটি হলো ব্যবহারকারীর CLI অথেনটিকেশন টোকেন, যা `https://exercism.io/my/settings`-এ পাওয়া যায়।

## অনুশীলনী সংগ্রহ

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

উপরের URL-এ `<slug>` হলো অনুশীলনীর নাম, যেমন `hello-world`, আর `<language>` হলো ভাষার ট্র্যাক, যেমন `pharo-smalltalk`।

### রেসপন্স

#### 200

একটি সফল অনুরোধে JSON পেলোড-সহ একটি রেসপন্স পাঠানো হবে। JSON-এর ভিতরে থাকবে অনুশীলনীর তথ্য এবং একটি URL, যেখান থেকে অনুশীলনীর ফাইলগুলো ডাউনলোড করা যাবে।

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

ভাষার ট্র্যাকের নাম অস্পষ্ট, অথবা জমা দেওয়া অনুশীলনীর ফাইলগুলোতে কোনো পরিবর্তন হয়নি।

#### 403

ব্যবহারকারীর জন্য সলিউশনটি আনলক করা হয়নি, অথবা ব্যবহারকারী ভাষার ট্র্যাকটিতে জয়েন করেননি।

#### 404

ভাষার ট্র্যাক বা অনুশীলনীটি খুঁজে পাওয়া যায়নি।

## অনুশীলনী জমা দেওয়া

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### রেসপন্স

#### 201

সফলভাবে জমা দেওয়া হয়েছে।

#### 400

জমা দেওয়া কোনো ফাইল অনেক বড় (এক মেগাবাইটের বেশি), অথবা সলিউশনটি ডুপ্লিকেট।

#### 403

ব্যবহারকারীর পক্ষে সলিউশনটি অ্যাক্সেস করা সম্ভব নয়। সলিউশনের ইউজার ID আর বর্তমান ইউজার ID মিলছে না।

#### 404

সলিউশন ID খুঁজে পাওয়া যায়নি।
