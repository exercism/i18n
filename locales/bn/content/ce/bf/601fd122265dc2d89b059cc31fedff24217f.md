# পরিচিতি

Haxe-এ একটি `String` হলো এমন একটি অবজেক্ট, যা ইউনিকোড ক্যারেক্টারের একটি ক্রম (অক্ষর, সংখ্যা, যতিচিহ্ন ইত্যাদি) হিসেবে অপরিবর্তনীয় টেক্সট উপস্থাপন করে। একটি `String` ইনস্ট্যান্স তৈরি করতে ডাবল কোট ব্যবহার করা হয়:

```haxe
var fruit:String = "Apple";
```

স্ট্রিং নিয়ে কাজ করা হয় স্ট্রিংয়ের মেথড কল করে। একবার একটি স্ট্রিং তৈরি হয়ে গেলে তার মান আর কখনো বদলানো যায় না। যে মেথডগুলো দেখতে মনে হয় স্ট্রিং বদলাচ্ছে, তারা আসলে একটি নতুন স্ট্রিং রিটার্ন করে।

একাধিক স্ট্রিং একসাথে কনক্যাটেনেট (যোগ) করা যায়। এটি করার সবচেয়ে সহজ উপায় হলো `+` অপারেটর ব্যবহার করা।

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

সাধারণ যোগের চেয়ে জটিল যেকোনো স্ট্রিং ফরম্যাটিংয়ের জন্য স্ট্রিং ইন্টারপোলেশন ব্যবহার করাই ভালো। একটি স্ট্রিংয়ে ইন্টারপোলেশন ব্যবহার করতে সেটিকে সিঙ্গেল কোট (`'`) দিয়ে ঘিরে দিন। তারপর ডলার চিহ্ন (`$`) দিয়ে ইন্টারপোলেশন শুরু করতে পারেন:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
