# বিবরণ

পিথাগোরিয়ান ট্রিপলেট হলো তিনটি স্বাভাবিক সংখ্যার একটি সেট, {a, b, c}, যার জন্য

```text
a² + b² = c²
```

এবং যেখানে,

```text
a < b < c
```

উদাহরণস্বরূপ,

```text
3² + 4² = 5².
```

একটি ইনপুট ইন্টিজার N দেওয়া হলে, সেসব পিথাগোরিয়ান ট্রিপলেট খুঁজুন যেখানে `a + b + c = N`.

উদাহরণস্বরূপ, N = 1000 হলে, ঠিক একটি পিথাগোরিয়ান ট্রিপলেট আছে যার জন্য `a + b + c = 1000`: `{200, 375, 425}`.
