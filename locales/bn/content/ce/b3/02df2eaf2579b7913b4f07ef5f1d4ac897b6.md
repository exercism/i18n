# পরিচিতি

Go-তে একটি `string` হলো বাইটের একটি ইমিউটেবল সিকোয়েন্স, যা ক্যারেক্টার প্রকাশ করতেই হয়, তা নয়।

একটি স্ট্রিং লিটারেল ডাবল কোটের মধ্যে ডিফাইন করা হয়:

```go
const name = "Jane"
```

স্ট্রিংগুলো `+` অপারেটর দিয়ে কনক্যাটেনেট করা যায়:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

কিছু বিশেষ ক্যারেক্টারকে সামনে একটি ব্যাকস্ল্যাশ দিয়ে এস্কেপ করতে হয়, যেমন স্ট্রিংয়ে একটি ট্যাবের জন্য `\t` এবং একটি নতুন লাইনের জন্য `\n`।

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings` প্যাকেজে স্ট্রিং নিয়ে কাজ করার জন্য অনেক দরকারি ফাংশন আছে।
স্ট্রিং ফাংশন সম্পর্কে আরও তথ্যের জন্য [strings প্যাকেজের ডকুমেন্টেশন](https://pkg.go.dev/strings) দেখুন।
এখানে কিছু উদাহরণ দেওয়া হলো:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```

## বিশেষ ক্যারেক্টার

আগে বলা হয়েছে, কিছু বিশেষ ক্যারেক্টারকে সামনে একটি ব্যাকস্ল্যাশ দিয়ে এস্কেপ করতে হয়।
নিচে এই বিশেষ ক্যারেক্টারগুলো কী কী, তার আরও বিস্তারিত তালিকা দেওয়া হলো:

| মান | বিবরণ |
| ----- | -------------------- |
| `\a`  | সতর্কতা বা বেল |
| `\b`  | ব্যাকস্পেস |
| `\\`  | ব্যাকস্ল্যাশ |
| `\t`  | অনুভূমিক ট্যাব |
| `\n`  | লাইন ফিড বা নিউলাইন |
| `\f`  | ফর্ম ফিড |
| `\r`  | ক্যারেজ রিটার্ন |
| `\v`  | উল্লম্ব ট্যাব |
| `\'`  | সিঙ্গেল কোট |
| `\"`  | ডাবল কোট |

```go
fmt.Println("Joe\nWilliam\nJack\nAverell") 

// Output:
// Joe
// William
// Jack
// Averell
```

## র' স্ট্রিং লিটারেল

র' স্ট্রিং লিটারেল ডাবল কোটের বদলে ডিলিমিটার হিসেবে ব্যাকটিক (\`) ব্যবহার করে এবং এর ভেতরের সব ক্যারেক্টার আক্ষরিকভাবে ইন্টারপ্রেট করা হয়, অর্থাৎ ক্যারেক্টার বা নিউলাইন এস্কেপ করার দরকার নেই।

এটি একটি মাল্টিলাইন স্ট্রিংয়ের উদাহরণ:

```go
const daltons = `Joe
William
Jack
Averell`
```

এই স্ট্রিংটিতে একাধিক লাইন আছে।
আরও নির্দিষ্টভাবে বললে, এতে ৩টি `\n` আছে।
তবে, যেহেতু এটি একটি র' স্ট্রিং লিটারেল, তাই স্ট্রিংটিতে `\n` স্পষ্টভাবে বসানোর দরকার নেই।
নিউলাইনগুলো আক্ষরিকভাবে ইন্টারপ্রেট করা হবে।

এখানে র' স্ট্রিং লিটারেলের সঙ্গে সাধারণ স্ট্রিং লিটারেলের তুলনা করে আরও কিছু উদাহরণ দেওয়া হলো:

```go
`abc`
// same as "abc"

"\"" // regular string literal with 1 character: a double quote
// same as `"` a raw string literal with 1 character: a double quote

`\n
` // raw string literal with 3 character: a backslash, an 'n', and a newline
// same as "\\n\n"  a regular string literal with 3 characters: a backslash, an 'n', and a newline

"\t\n" // regular string literal with 2 characters: a tab and a newline
`\t\n`// raw string literal with 4 characters: two backslashes, a 't', and an 'n'
```
