# নির্দেশনার পরিশিষ্ট

## Prolog-এ তারিখ নিয়ে কাজ করা

তারিখ নিয়ে কাজ করার জন্য Prolog-এর বিল্ট-ইন সমর্থন [বেশ প্রাথমিক][built-in-dates-support]। আপনি শুধু Prolog-এ যা বিল্ট-ইন আছে তা দিয়েই এই অনুশীলনীটি সমাধান করতে পারেন, তবে তারিখ নিয়ে কাজ করার আরও অনেক সুবিধাজনক একটি উপায় হলো [date_time প্যাকেজ][date-time-package]।

### date_time প্যাকেজ ইনস্টল করা

আপনার ইনস্টল করা Swipl সংস্করণটি যদি বেশ হালনাগাদ হয়, তাহলে নিচের কমান্ডটি চালিয়ে প্যাকেজটি ইনস্টল করতে পারেন:

```bash
swipl pack install date_time
```

সেটি কাজ না করলে আপনি এটি চালাতে পারেন:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
আপনি যদি অনলাইন এডিটর ব্যবহার করেন, তাহলে নিজে হাতে কিছু ইনস্টল করার দরকার নেই।
~~~~

### date_time প্যাকেজ ব্যবহার করা

`date_time` প্যাকেজটি ব্যবহার করতে আপনার সলিউশন ফাইলের একদম উপরে নিচের কোডটি যোগ করুন:

```prolog
:- use_module(library(date_time)).
```
