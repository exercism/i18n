# নির্দেশাবলি

একটি অ্যামিউসমেন্ট পার্কের সাথে কাজ করতে গিয়ে উপস্থিতি ও রাইড পরিচালনার একটি সিস্টেম ডিজাইন করার জন্য আপনার হাতে একটি স্পেসিফিকেশন দেওয়া হয়েছে। আপনাকে Attendee (পার্কে ঘুরতে আসা ব্যক্তি) মডেল করার দায়িত্ব দেওয়া হয়েছে।

## 1. নতুন অ্যাটেনডি তৈরি করুন

`Attendee` ক্লাসের `Attendee#initialize` মেথডটি ইমপ্লিমেন্ট করুন; এটি একটি উচ্চতা (সেন্টিমিটারে) নেবে এবং সেটি একটি ইনস্ট্যান্স ভ্যারিয়েবলে সংরক্ষণ করবে।

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. অ্যাটেনডির উচ্চতা কত

`Attendee` ক্লাসের `Attendee#height` গেটারটি ইমপ্লিমেন্ট করুন; এটি ইনস্ট্যান্সের উচ্চতা রিটার্ন করবে।

```ruby
Attendee.new(106).height
# => 106
```

## 3. রাইড পাস আইডি কী

সব অ্যাটেনডি রাইড পাস কেনেননি, তবে তাদের পাস আছে কি নেই সেটি আমাদের জানা দরকার। `Attendee` ক্লাসের জন্য `Attendee#pass_id` গেটারটি ইমপ্লিমেন্ট করুন; এটি ইনস্ট্যান্সের pass_id রিটার্ন করবে, আর Attendee-র পাস না থাকলে `nil` রিটার্ন করবে।

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. লোকজনকে পাস কেনার সুযোগ দিন

ইনস্ট্যান্সের স্টেট পরিবর্তন করতে `Attendee#issue_pass!` ইমপ্লিমেন্ট করুন এবং পাস আইডি ইনস্ট্যান্স ভ্যারিয়েবলে আর্গুমেন্টটি সেট করুন। এটি পাস আইডি রিটার্ন করবে।

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. পাস বাতিল করুন

কিছু অতিথি অনিরাপদ আচরণ করে নিয়ম ভাঙেন, তাই পার্ক চায় প্রয়োজনে পাস বাতিল করতে পারতে। ইনস্ট্যান্সের স্টেট পরিবর্তন করতে `Attendee#revoke_pass!` ইমপ্লিমেন্ট করুন এবং পাস আইডি `nil` সেট করুন।

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
