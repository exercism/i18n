# ভূমিকা

## এনামারেশন

এখন পর্যন্ত আমরা মূলত সংখ্যা আর স্ট্রিং নিয়েই কাজ করেছি।
বাস্তব জগৎকে মডেল করতে আমরা চাইতে পারি, একটি ভ্যারিয়েবল যেন কেবল সীমিত সংখ্যক মানের যেকোনো একটি গ্রহণ করে।
আপনি হয়তো একটি আলাদা টাইপ চাইতে পারেন, যার কয়েকটি স্বতন্ত্র মান থাকবে আলাদা আলাদা নামের।
উদাহরণস্বরূপ, একটি স্কেটবোর্ড কারখানায় ডেকের উপাদান কেবল maple, bamboo বা plastic-এর মধ্যে একটি বেছে নেওয়ার সুযোগ থাকতে পারে।

ওই মানগুলো এনকোড করতে আপনি ইন্টিজার ব্যবহার করতে পারেন, তবে উপাদানের জন্য সিস্টেম থেকে কোনো অবৈধ মান আসছে কি না তা যাচাই করতে বাড়তি কোড লিখতে হবে।
সোর্স কোডের ওপর দিয়ে দেখতে গেলে ওই [_ম্যাজিক নাম্বারগুলোর_][magic numbers] অর্থ খুঁজে পাওয়া কঠিন, আর এগুলোতে ভুল হয়ে যাওয়ার ঝুঁকি থাকে।
`enumerations` ব্যবহার করে প্রকাশভঙ্গিময় কোড উৎসাহিত করা যায় এবং অনিচ্ছাকৃত তুলনার ভুল সীমিত করা যায়।

## ব্যবহারের উদাহরণ

এই ধরনের এনামারেশনের নির্দিষ্ট পরিভাষা হলো `scoped enumeration`।
নিচের স্নিপেটে দেখানো হয়েছে কীভাবে একটি `DeckMaterial` `enumeration` লিখতে হয়।
সংজ্ঞার শেষে `enum class` কিওয়ার্ড আর `;` খেয়াল করুন:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
এখন স্কেট শপের একটি দাম নির্ধারণের ফাংশন দেখুন এবং খেয়াল করুন, স্কোপ রেজলিউশন অপারেটর (`::`) কীভাবে `enumeration` থেকে একটি `enumerator` নির্দিষ্ট করছে:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## স্কোপিং

ভাবুন, চাকার উপাদানের জন্য আপনার আরেকটি `enumeration` আছে:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
যদিও চাকা আর ডেক দুটোই _plastic_ দিয়ে তৈরি হতে পারে, তবু এ দুটোকে গুলিয়ে ফেলার সুযোগ নেই।
এগুলো ভিন্ন ভিন্ন _টাইপ_: `DeckMaterial` plastic আর `WheelMaterial` plastic।
প্রতিটি `enumeration`-এর `enumerators` থাকবে তার নিজের স্কোপে, নিজের `namespace`-এ।
এ কারণেই এগুলোকে `scoped enumerations` বলা হয়।

## আনস্কোপড এনামারেশন
নামটা যখন `scoped`, আপনি হয়তো ভাবছেন নিশ্চয়ই _`unscoped`_ এনামারেশনও আছে, আর আপনি ঠিকই ভাবছেন।
`Unscoped enumerations` ক্রমশ কম জনপ্রিয় হয়ে উঠছে, কারণ এগুলো সবই একই গ্লোবাল নেমস্পেস শেয়ার করে।
এই শেয়ারিংয়ের কারণেই উপরের উদাহরণের মতো _plastic_-এর অনুরূপ `enumerators` নিয়ে দুটি `unscoped enumerations` থাকতে পারে না।

এছাড়া `unscoped enumerations` নিজে থেকেই ইন্টিজারে রূপান্তরিত হয়।
একটি চমকপ্রদ ফলাফলের জন্য নিচের উদাহরণটি দেখুন:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

আপনি যদি `scoped enumerations`-কে ইন্টিজারে রূপান্তর করতে চান, তাহলে `static_cast<int>` ব্যবহার করতে পারেন।

## সুইচ স্টেটমেন্ট

অন্য ভাষাগুলোর মতো C++-ও একটি `switch` স্টেটমেন্ট দেয়।
দীর্ঘ `if ... else if` স্টেটমেন্ট লেখার একটি ছোট উপায় হলো সুইচ স্টেটমেন্ট।
সুইচ বানাতে আমরা প্রথমে `switch` কিওয়ার্ডটি ব্যবহার করি, তারপরে একটি ইন্টিজার দিই।
এরপর `case` কিওয়ার্ড দিয়ে প্রতিটি শর্ত আলাদা করে ঘোষণা করি।
আমরা একটি `default` কেসও ঘোষণা করতে পারি, যা আগের কোনো `case` শর্ত মিল না গেলে চলবে।
প্রতিটি কেস `break` (বা `return`) স্টেটমেন্ট দিয়ে শেষ হওয়া উচিত।

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## ফল-থ্রু

সুইচ কনস্ট্রাক্ট নিয়ে একটি গুরুত্বপূর্ণ বিষয় হলো, কোড চলতেই থাকবে যতক্ষণ না কোনো `break` (বা `return`) স্টেটমেন্ট দিয়ে তা থামানো হয়।
এতে অপ্রত্যাশিত আচরণ হতে পারে।

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

এই ধারাবাহিকভাবে চলার বৈশিষ্ট্যের প্রধান ব্যবহার হলো এমন একটি স্টেটমেন্ট, যার একাধিক লেবেল থাকে।
সুইচের একাধিক ফলাফল একই কোডখণ্ডে নির্দেশ করতে পারে, যা নির্বাহ করা হবে।
এভাবে, উদাহরণস্বরূপ একটি বুকিং অ্যাপে, ২ ও ৩ মাপের গ্রুপের জন্য কল করা ফাংশন একই হতে পারে:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
