# ভূমিকা

Go-এর ফাংশন ও মেথড একাধিক মান রিটার্ন করতে পারে:

```go
func GetCard() (Card, error) { ... }
```

প্রতিটি রিটার্ন ভ্যালু অবশ্যই ক্রমানুসারে অ্যাসাইন করতে হবে এবং কমা দিয়ে আলাদা করতে হবে:

```go
card, err := GetCard()
```

অ্যাসাইনমেন্টের প্রতিটি অবস্থান একটি ভ্যারিয়েবল ডিক্লেয়ার করে।
যদি কোনো ডিক্লেয়ার করা ভ্যারিয়েবল কখনো ব্যবহার না হয়, তবে Go কম্পাইল করবে না।
ব্ল্যাংক আইডেন্টিফায়ার `_` একটি ভ্যারিয়েবল নামের জায়গা নেয় যাতে সেই রিটার্ন ভ্যালুটি বাদ দেওয়া যায়:

```go
card, _ := GetCard()
```

`error` একটি বিল্ট-ইন ইন্টারফেস।
একটি `nil` এরর মানে কোনো এরর হয়নি; যেকোনো নন-নিল মান মানে কিছু একটা ভুল হয়েছে।
প্রচলিত নিয়ম অনুসারে, যে ফাংশনগুলি ব্যর্থ হতে পারে সেগুলির শেষ মান হিসেবে একটি `error` রিটার্ন করা উচিত।
অন্য কোনো রিটার্ন ভ্যালু ব্যবহার করার আগে কলারকে এটি চেক করতে হবে:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
