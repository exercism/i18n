# পরিচিতি

## বুলিয়ান

Elixir বুলিয়ান টাইপ দিয়ে ট্রু ও ফলস মান প্রকাশ করে। এতে মাত্র দুটি মান থাকে: `true` এবং `false`। এই মানগুলো একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়:

```elixir
true_variable = true
false_variable = false
```

`and/2`, `or/2` এবং `not/1` অপারেটর ব্যবহার করে আমরা কঠোর বুলিয়ান এক্সপ্রেশন মূল্যায়ন করতে পারি।

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

বুলিয়ান মান রিটার্ন করে এমন একটি ফাংশন লেখার সময় ফাংশনের নামের শেষে একটি `?` দিয়ে শেষ করাই প্রচলিত রীতি। বুলিয়ান মান সংরক্ষণ করে এমন ভ্যারিয়েবলের ক্ষেত্রেও একই রীতি ব্যবহার করা যায়।

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
