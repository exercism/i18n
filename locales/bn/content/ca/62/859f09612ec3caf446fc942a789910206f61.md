# টেস্ট চালানো

SWI Prolog ইন্টার্যাক্টিভভাবে রান করা যায়, আবার কমান্ড লাইন থেকে সরাসরি চালানোও যায়।

## কমান্ড লাইন

কমান্ড লাইন থেকে টেস্ট চালাতে নিচের কমান্ডটি ব্যবহার করতে পারেন:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

আপনি যে অনুশীলনীটি করছেন তার নাম দিয়ে `<exercise>` প্রতিস্থাপন করুন।

## ইন্টার্যাক্টিভ

Prolog ইন্টার্যাক্টিভভাবে রান করতে প্রথমে এটি চালান:

```bash
swipl
```

Prolog কনসোল চালু হওয়ার পর আপনার ইমপ্লিমেন্টেশন লোড করুন এবং এই কমান্ড দিয়ে টেস্ট চালান:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

আপনি যে অনুশীলনীটি করছেন তার নাম দিয়ে `<exercise>` প্রতিস্থাপন করুন।

### পরিবর্তন রিলোড করা

উপরের ফাইলগুলো লোড হয়ে গেলে, আপনি যা যা পরিবর্তন করেছেন তা প্রয়োগ করতে এটি চালান:

```
?- make.
```

## স্কিপ করা টেস্ট

কোনো অনুশীলনী প্রথমে শুরু করলে শুধু প্রথম টেস্টটিই চলবে। বাকিগুলো `test` গোল-এ `condition(pending)` যোগ করে স্কিপ করা হয়েছে।
প্রথম টেস্টটি পাস হয়ে গেলে, `condition(pending)`-এর `pending` কে `true` করে পরের টেস্টটির স্কিপ বাতিল করুন।
সবগুলো টেস্ট চালু হয়ে পাস হওয়া পর্যন্ত প্রতিটি টেস্টের জন্য এই কাজটি পুনরাবৃত্তি করুন।

### কমান্ড লাইন

পেন্ডিং টেস্টগুলোও চালাতে চাইলে কমান্ডের শেষে `-- --all` আর্গুমেন্টটি যোগ করুন:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
