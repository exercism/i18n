# সম্পর্কে

কোনো শর্ত **ট্রু** না **ফলস**, তার উপর ভিত্তি করে কোড চালাতে শর্তসাপেক্ষ এক্সপ্রেশন ব্যবহার করা হয়। এসব এক্সপ্রেশন এভাবে লেখা হয়:

```haxe
if (condition) {
  expressions
};
```

শর্তের আউটপুট `Bool` টাইপের, তাই আউটপুট `true` হলে এক্সপ্রেশনগুলো চালানো হয়।

কখনও কখনও, শর্তটি আসলে `false` হলে আমরা চাই কোডের আরেকটি অংশ চালানো হোক। ঠিক সেখানেই `else` এক্সপ্রেশনটি কাজে আসে। শুরুর শর্ত `false` হলে `else` এক্সপ্রেশনগুলো চালায়। কিন্তু আমরা যদি একই শর্ত একাধিক সম্ভাবনার জন্য যাচাই করতে চাই? তখন আমরা `else if (condition)` ব্যবহার করি। এখানে একটি সম্পূর্ণ উদাহরণ:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
