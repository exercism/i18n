# পরিচিতি

## অ্যারে ও ভেক্টর

C++ একই টাইপের এলিমেন্ট একটি নির্দিষ্ট ক্রমে জমা রাখার জন্য বিভিন্ন কন্টেইনার সরবরাহ করে।
নির্দিষ্ট সাইজের কন্টেইনারের জন্য আছে `std::array`, আর ডায়নামিক রিসাইজিংয়ের সুবিধা নিয়ে আসে `std::vector`.

### তৈরি করা

অ্যারে বা ভেক্টর ডিক্লেয়ার করার সময় কোন টাইপের এলিমেন্ট ওই কন্টেইনারটি ধারণ করবে তা উল্লেখ করতে হয়।
অ্যারেগুলোর ক্ষেত্রে সাইজও দিতে হয়।
দুটি কন্টেইনার টাইপ কীভাবে ইনিশিয়ালাইজ করা হয়, তা দেখতে এই উদাহরণগুলো দেখুন:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

ভেক্টর সাধারণত বেশি জায়গা নেয়, কারণ ভবিষ্যতে আরও বাড়ার জন্য এরা মেমরি অ্যালোকেট করে।
আপনাকে সাইজ উল্লেখ করতে হয় না:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> দ্রষ্টব্য: টেমপ্লেট কনসেপ্টের পেছনের সঠিক কার্যপ্রণালী এখনই জানার দরকার নেই, সিলেবাস ট্রি-তে আরও নিচে এর জন্য আলাদা কনসেপ্ট থাকবে।

### এলিমেন্ট অ্যাক্সেস

ভেক্টর আর অ্যারে, দুটোই নিজেদের এলিমেন্ট অ্যাক্সেস করার জন্য একই ফাংশন ব্যবহার করে।
কন্টেইনারের প্রথম ও শেষ এলিমেন্ট পেতে আপনি মেম্বার ফাংশন `front` ও `back` ব্যবহার করতে পারেন।
নির্দিষ্ট এলিমেন্ট অ্যাক্সেস করার জন্য আছে `at` এবং `[]` অপারেটর।

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> দ্রষ্টব্য: আপনি যদি এমন কোনো পজিশন বেছে নেন যা আপনার কন্টেইনারের রেঞ্জে নেই, তাহলে `[]` আনডিফাইন্ড বিহেভিয়ার তৈরি করতে পারে।
> আর `at` ফাংশনটি একটি এক্সেপশন ছুড়ে দেবে, যা দীর্ঘমেয়াদে আপনার জীবন সহজ করে দিতে পারে।

### ভেক্টরের মডিফায়ার

যেহেতু `vector`-এর সাইজ নির্দিষ্ট নয়, তাই এলিমেন্ট যোগ করা বা সরিয়ে ফেলা সম্ভব।
এই কাজের জন্য দুটি কমন ফাংশন হলো `emplace_back` এবং `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### ক্যাপাসিটি

মেম্বার ফাংশন `empty` দিয়ে কন্টেইনার খালি কি না তা যাচাই করতে পারেন।
এলিমেন্টের সংখ্যা জানতে চাইলে `size` ব্যবহার করতে পারেন।
