# নির্দেশাবলি

_Instruments of Texas_-এ আপনার কাজ চালিয়ে যাওয়ার সময় RPN ক্যালকুলেটরের Elixir সংস্করণ নিয়ে কাজ এগিয়ে চলেছে। স্ট্যান্ডার্ড লাইব্রেরি যে জেনেরিক এররগুলো দেয়, তার চেয়ে বেশি নির্দিষ্ট এরর রেইজ করার সুবিধা আপনার টিম চায়। আপনি কিছু গবেষণা করছেন, তবে সিদ্ধান্ত নিয়েছেন যে _Exception Behaviour_ ইমপ্লিমেন্ট করে এমন দুটি নতুন এরর তৈরি করবেন।

## 1. শূন্য দিয়ে ভাগের এরর

শূন্য দিয়ে একটি সংখ্যা ভাগ করলে অনির্ধারিত ফলাফল আসে, আর টিমের সিদ্ধান্ত হলো এই ফলাফল একটি এরর দিয়ে প্রকাশ করাই সবচেয়ে ভালো।

`DivisionByZeroError` মডিউলটি এমনভাবে ইমপ্লিমেন্ট করুন যাতে এর এরর মেসেজ হয়: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. স্ট্যাক আন্ডারফ্লো ঘটলে এরর

RPN ক্যালকুলেটরগুলো যোগ করার আগে সংখ্যাগুলোর হিসাব রাখতে একটি _স্ট্যাক_ ব্যবহার করে। টিম এই _স্ট্যাক_-কে সংখ্যার একটি তালিকা (ইন্টিজার ও ফ্লোটিং-পয়েন্ট) দিয়ে প্রকাশ করে, যেমন: `[3, 4.0]`। প্রতিটি অপারেশনের নিজের হিসাব করতে স্ট্যাকে নির্দিষ্ট সংখ্যক সংখ্যা থাকা দরকার। স্ট্যাকে যথেষ্ট সংখ্যা না থাকলে তাকে স্ট্যাক আন্ডারফ্লো এরর বলা হয়। `StackUnderflowError` এক্সেপশনটি ইমপ্লিমেন্ট করুন, যা একটি ডিফল্ট মেসেজ এবং ঐচ্ছিক অতিরিক্ত কনটেক্সট দেয়

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. একটি ভাগ করার ফাংশন লিখুন

`divide/1` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি স্ট্যাক _(দুটি সংখ্যার একটি তালিকা)_ নেয় এবং:

- স্ট্যাকে যথেষ্ট সংখ্যা না থাকলে _স্ট্যাক আন্ডারফ্লো_ রেইজ করে
- ভাজক 0 হলে _শূন্য দিয়ে ভাগ_ রেইজ করে (মনে রাখবেন, সংখ্যার স্ট্যাকটি উল্টো ক্রমে রাখা থাকে)
- কোনো এরর রেইজ না হলে ভাগটি সম্পন্ন করে

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> মনে রাখবেন, তালিকার ক্রমটি উল্টো!
