# নির্দেশনার সংযোজন

## প্রজেক্ট স্ট্রাকচার

exercism-এর Clojure অনুশীলনীগুলো আপনার কোড কনফিগার ও রান করার জন্য [leiningen](http://leiningen.org/) ব্যবহার করে এবং [leiningen-এর স্ট্যান্ডার্ড ডিরেক্টরি স্ট্রাকচার](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout) ব্যবহার করে।

`test` ডিরেক্টরির ভেতরে `hello_world_test.clj` নামের একটি টেস্ট ফাইল পাবেন।
`src/hello_world.clj` ফাইলে আপনার কোড লিখুন। এতে `hello-world` নেমস্পেসটি ব্যবহার করা উচিত, যাতে টেস্টগুলো এটি খুঁজে নিতে পারে।

## টেস্ট রান করা

`lein test` কমান্ড দিয়ে টেস্টগুলো রান করুন এবং সেগুলো পাস করান:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

তারপর অনুশীলনীটি সাবমিট করুন এভাবে:

```
$ exercism submit src/hello_world.clj
```

আরও বিস্তারিত নির্দেশনা ও শেখার উপকরণের জন্য [exercism-এর clojure ভাষা পাতা](http://exercism.io/languages/clojure) দেখুন।
