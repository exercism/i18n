# সম্পর্কে

`use` ম্যাক্রোটি আমাদেরকে অন্য একটি মডিউলের দেওয়া কার্যকারিতা দিয়ে আমাদের মডিউল দ্রুত সম্প্রসারিত করার সুযোগ দেয়। আমরা যখন কোনো মডিউল `use` করি, তখন সেই মডিউল আমাদের মডিউলে কোড ইনজেক্ট করতে পারে, উদাহরণস্বরূপ এটি ফাংশন ডিফাইন করতে পারে, অন্য মডিউল `import` বা `alias` করতে পারে, কিংবা মডিউল অ্যাট্রিবিউট সেট করতে পারে।

আপনি যদি কখনো এখানে Exercism-এ কিছু Elixir অনুশীলনীর টেস্ট ফাইল দেখে থাকেন, তাহলে আপনি সম্ভবত লক্ষ্য করেছেন যে সেগুলোর সবকটিই `use ExUnit.Case` দিয়ে শুরু হয়। কোডের এই এক লাইনই টেস্ট মডিউলে `test` ও `assert` ম্যাক্রোগুলো উপলব্ধ করে তোলে।

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## `__using__/1` ম্যাক্রো

আপনি যখন কোনো মডিউল `use` করেন, তখন ঠিক কী ঘটে, তা নির্ধারিত হয় সেই মডিউলের `__using__/1` ম্যাক্রো দিয়ে। এটি একটি আর্গুমেন্ট নেয়, অপশনসহ একটি কিওয়ার্ড অ্যারে, এবং একটি [কোটেড এক্সপ্রেশন][concept-ast] রিটার্ন করে। `use` কল করার সময় এই কোটেড এক্সপ্রেশনের কোডটি আমাদের মডিউলে সন্নিবেশিত হয়।

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

`use` কল করার সময় অপশনগুলো দ্বিতীয় আর্গুমেন্ট হিসেবে দেওয়া যায়, যেমন `use ExUnit.Case, async: true`. স্পষ্টভাবে দেওয়া না হলে এগুলো ডিফল্টভাবে একটি খালি অ্যারে হয়।
