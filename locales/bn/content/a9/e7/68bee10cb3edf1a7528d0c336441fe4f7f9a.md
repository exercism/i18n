# পরিচিতি

[স্ট্রাকচার][structs-and-classes] (সাধারণত *স্ট্রাক্ট* বলা হয়) Swift প্রোগ্রামের প্রধান বিল্ডিং ব্লকগুলোর একটি।
স্ট্রাক্ট দিয়ে আপনি কাস্টম টাইপ তৈরি করতে পারেন, যা সম্পর্কিত প্রপার্টি (ডেটা) ও মেথড (আচরণ) একসাথে গুছিয়ে রাখে।
আসলে Swift-এর স্ট্যান্ডার্ড টাইপগুলো, যেমন `Int`, `Double`, `Bool`, `String`, `Array` এবং `Dictionary`, সবই স্ট্রাক্ট হিসেবে ইমপ্লিমেন্ট করা হয়েছে।

## স্ট্রাক্ট ডিফাইন করা

`struct` কিওয়ার্ড দিয়ে একটি স্ট্রাক্ট ডিফাইন করুন, তারপর টাইপের নাম আর সংজ্ঞাটি ধারণ করা দ্বিতীয় বন্ধনী লিখুন।
Swift-এর রীতি অনুযায়ী, স্ট্রাক্টের নামে `UpperCamelCase` ব্যবহার করা হয়:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## ইনস্ট্যান্স তৈরি করা

একটি স্ট্রাক্ট ডেফিনিশন আসলে একটি ব্লুপ্রিন্ট।
কোনো স্ট্রাক্টের *ইনস্ট্যান্স* তৈরি করতে, টাইপের নামের পরে বন্ধনী লিখে তার ইনিশিয়ালাইজার কল করুন:

```swift
var someStats = CharacterStats()
```

এটি ডেফিনিশনের ডিফল্ট প্রপার্টি মান দিয়ে পূর্ণ একটি ইনস্ট্যান্স তৈরি করে।

এছাড়াও, Swift স্ট্রাক্টের জন্য স্বয়ংক্রিয়ভাবে একটি **মেম্বারওয়াইজ ইনিশিয়ালাইজার** তৈরি করে, যা দিয়ে আপনি নাম ধরে প্রপার্টি ইনিশিয়ালাইজ করতে পারেন:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## প্রপার্টি অ্যাক্সেস ও পরিবর্তন করা

*ডট নোটেশন* ব্যবহার করে আপনি একটি ইনস্ট্যান্সের প্রপার্টি অ্যাক্সেস ও পরিবর্তন করেন:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

যেহেতু স্ট্রাক্ট ভ্যালু টাইপ, তাই একটি ইনস্ট্যান্সের প্রপার্টি পরিবর্তন করতে হলে ইনস্ট্যান্সটি নিজেই `var` দিয়ে ডিক্লেয়ার করতে হয়।
ইনস্ট্যান্সটি যদি `let` দিয়ে ডিক্লেয়ার করা হয়, তবে তার সব প্রপার্টি অপরিবর্তনীয় হয়ে যায়।
