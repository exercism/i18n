# সম্পর্কে

লুপ হলো একটি ব্যাচে এক বা একাধিক স্টেটমেন্ট বারবার কল করার একটি উপায়।
স্টেটমেন্টের একটি ব্যাচের প্রতিটি রানকে একটি ইটারেশন বলা হয়।

## while লুপ

একটি `while` লুপ স্টেটমেন্টের একটি ব্যাচ রান করে যতক্ষণ লুপের উপরে থাকা একটি বুলিয়ান এক্সপ্রেশন ট্রু থাকে।
বুলিয়ান এক্সপ্রেশনটি ফলস হলে লুপটি চলা বন্ধ করে এবং এক্সিকিউশন লুপের পরে কোডের পরবর্তী লাইনে এগিয়ে যায়।

শুরু থেকেই যদি বুলিয়ান এক্সপ্রেশনটি ফলস হিসেবে ইভ্যালুয়েট হয়, তাহলে `while` লুপটি একেবারেই রান করবে না এবং এক্সিকিউশন লুপের পরে কোডের পরবর্তী লাইনে এগিয়ে যাবে।

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

লুপ শেষ করার জন্য একটি শর্ত থাকা জরুরি; নাহলে এটি একটি অসীম লুপ হয়ে যায়, যা কোডের সব অগ্রগতি আটকে দেবে।
উপরের কোডে `i` থেকে `++` বাদ দিলে এটি একটি অসীম লুপ হয়ে যেত।

## do লুপ

একটি `do` লুপের বুলিয়ান এক্সপ্রেশন লুপের নিচের দিকে টেস্ট করা হয়।
একটি `do` লুপ সবসময় অন্তত একবার রান করবে, যেমনটি নিচের উদাহরণে দেখা যায়

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

একটি `while` লুপ দিয়ে এটি আরও ভার্বোজ হতো

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## for লুপ

প্রায়ই একটি লুপ একটি ভ্যারিয়েবল আপডেট করে এবং ভ্যারিয়েবলটি একটি নির্দিষ্ট মানে পৌঁছালে শেষ হয়।
একটি `for` লুপ হলো বন্ধনীর ভেতরে এক লাইনে এক বা একাধিক ভ্যারিয়েবল ইনিশিয়ালাইজ, আপডেট এবং টেস্ট করার একটি উপায়।
প্রথম অংশটি ভ্যারিয়েবল ইনিশিয়ালাইজ করার জন্য, দ্বিতীয় অংশটি ভ্যারিয়েবল টেস্ট করার জন্য, এবং তৃতীয় অংশটি ভ্যারিয়েবলের মান আপডেট করার জন্য।

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

এটি সমতুল্য `while` লুপের চেয়ে কম ভার্বোজ, তবুও এটি পড়ার উপযোগী।

`for` লুপের ইনিশিয়ালাইজিং ও আপডেটিং অংশগুলো শর্তের ভেতরে এক্সপ্রেশন আলাদা করতে কমা অপারেটর ব্যবহার করে একাধিক ভ্যারিয়েবল সামলাতে পারে।

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

এটি প্রিন্ট করবে

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

`for` লুপের কোনো অংশই ডিফাইন করা দরকার নেই।
একটি খালি টেস্টিং এক্সপ্রেশন ট্রু হিসেবে ইভ্যালুয়েট হয়, তাই একটি `for` লুপ দিয়ে এভাবে একটি অসীম লুপ ডিফাইন করা যেতে পারে

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

এটি `while` লুপের মতোই, কারণ এখানে `i` লুপের আগে ইনিশিয়ালাইজ করা হয় এবং লুপের ভেতরে ইনক্রিমেন্ট করা হয়।
এছাড়াও, `i` লুপের ভেতরে টেস্ট করা হয় এবং লুপটি `break` স্টেটমেন্ট দিয়ে শেষ হয়।

## break স্টেটমেন্ট

কখনও কখনও একটি লুপকে তার বুলিয়ান এক্সপ্রেশনে টেস্ট না করা কোনো বিশেষ শর্তে শেষ করতে হতে পারে।
`break` স্টেটমেন্ট লুপটি শেষ করে দেবে এবং এক্সিকিউশন লুপের পরে কোডের পরবর্তী লাইনে এগিয়ে যাবে।

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

এটি প্রিন্ট করবে

```
i is 0
j is 5
After the loop
```

## continue স্টেটমেন্ট

কখনও কখনও একটি লুপকে তার চলমান ইটারেশন শেষ না করেই পরের ইটারেশন শুরু করতে হতে পারে।
`continue` স্টেটমেন্ট চলমান ইটারেশনের এক্সিকিউশন থামিয়ে দেয় এবং পরের ইটারেশনের শুরুতে এক্সিকিউশন চালিয়ে যায়।

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

এটি প্রিন্ট করবে

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

যখন `i` ও `j` দুটোই `2` হয়, তখন এটি তাদের মান প্রিন্ট করে না।
