# ভূমিকা

Factor-এ একটি স্ট্রিং হলো ক্যারেক্টারের একটি সিকোয়েন্স। [`sequences`][sequences] ভোকাবুলারির বেশিরভাগ ওয়ার্ডই স্ট্রিংয়ের উপর কাজ করে, এবং তার সঙ্গে আছে [`splitting`][splitting], [`ascii`][ascii] ও অন্যান্য ভোকাবুলারির স্ট্রিং নিয়ে কাজ করার জন্য আলাদা ওয়ার্ডগুলোও।

## স্ট্রিং লিটারেল

স্ট্রিং লেখা হয় ডাবল কোটের ভেতরে। স্বাভাবিক এস্কেপগুলো সমর্থিত: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## দৈর্ঘ্য ও ইনডেক্সিং

যেহেতু একটি স্ট্রিং একটি সিকোয়েন্স, তাই [`sequences`][sequences] ভোকাবুলারির `length` ও `nth` ওয়ার্ড সরাসরি এর উপর কাজ করে।

`length` ক্যারেক্টারের সংখ্যা রিটার্ন করে:

```factor
"hello" length .    ! => 5
```

`nth` একটি ০-ভিত্তিক ইনডেক্স আর সিকোয়েন্স নেয়, এবং সেই অবস্থানের এলিমেন্ট রিটার্ন করে। স্ট্রিংয়ের ক্ষেত্রে এলিমেন্টটি হলো একটি *ক্যারেক্টার*, অর্থাৎ একটি কোড পয়েন্ট (একটি ইন্টিজার), এক ক্যারেক্টারের সাবস্ট্রিং নয়:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## ক্যারেক্টার থেকে আবার স্ট্রিংয়ে

একটি কোড পয়েন্টকে এক ক্যারেক্টারের স্ট্রিংয়ে বদলাতে [`strings`][strings] ভোকাবুলারির `1string ( char -- str )` ব্যবহার করুন। `CHAR:` হলো একটি লিটারেল কোড পয়েন্টের পার্সার-টাইম রূপ:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## স্প্লিটিং

[`splitting`][splitting] ভোকাবুলারি একটি স্ট্রিংকে টুকরোয় ভাগ করে।

`split1` সেপারেটরের *প্রথম* উপস্থিতিতে কাটে এবং দুই ভাগই রিটার্ন করে:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` সেপারেটর সেটের *যেকোনো* ক্যারেক্টারে কাটে, ফলে খালি টুকরোও তৈরি হতে পারে:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` ([`sequences`][sequences] ভোকাবুলারিতে) খালি টুকরোগুলো বাদ দেয়:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## একটি টুকরো বেছে নেওয়া

একবার একটি স্ট্রিং টুকরোর অ্যারেতে ভাগ হয়ে গেলে, `first`, `second`, `third` ও `fourth` ([`sequences`][sequences] ভোকাবুলারিতে) সেই অবস্থানের টুকরো রিটার্ন করে:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

আপনি যখন স্ট্যাকের উপর শুরুর সব টুকরো একসাথে চান, তখন `first2` ও `first3` এক ধাপে দুটি বা তিনটি খুলে দেয়:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

স্ট্রিংয়ের উপর সরাসরি `first` সাবস্ট্রিংয়ের বদলে প্রথম **ক্যারেক্টার** রিটার্ন করে, অর্থাৎ একটি কোড পয়েন্ট:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## ট্রিমিং

`[ blank? ] trim` ([`sequences`][sequences] ভোকাবুলারি থেকে, আর `blank?` [`ascii`][ascii] ভোকাবুলারি থেকে) শুরুর ও শেষের হোয়াইটস্পেস মুছে ফেলে:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## কেস রূপান্তর

`>lower` ও `>upper` ([`ascii`][ascii] ভোকাবুলারি থেকে) কেস বদলে দেওয়া একটি নতুন স্ট্রিং রিটার্ন করে:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## জোড়া লাগানো

[`sequences`][sequences] ভোকাবুলারির দুটি ওয়ার্ড স্ট্রিং জোড়া লাগায়:

`surround` একটি স্ট্রিংকে একটি প্রিফিক্স ও একটি সাফিক্স দিয়ে ঘিরে ফেলে:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` মাঝখানে একটি সেপারেটর দিয়ে দুটি স্ট্রিং জোড়া লাগায়:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
