# পরিচিতি

## টিউপল

একটি টিউপল হলো নামহীন কিন্তু ক্রম অনুসারে সাজানো মানের একটি _ইমিউটেবল_ সমষ্টি।
টিউপলে যেকোনো (বা একাধিক) ডেটা টাইপ রাখা যায়, এমনকি অন্য টিউপলও।

টিউপলকে `(` ও `)` অক্ষরের মাঝে কমা দিয়ে আলাদা করা মান হিসেবে লেখা হয়: `(<element_1>, ... , <element_n>)`।

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

শুধু একই দৈর্ঘ্য ও একই টাইপের (একই ক্রমে) টিউপলই তুলনা করা যায়।
টিউপলে কাঠামোগত সমতা থাকে, অর্থাৎ তাদের সব মান সমান হলেই _কেবল_ তারা সমান হয়।

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

টিউপল থেকে মান বের করার তিনটি উপায় আছে:

- `fst` ও `snd` ফাংশন
- টিউপল ডিকনস্ট্রাকশন
- প্যাটার্ন ম্যাচিং

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
