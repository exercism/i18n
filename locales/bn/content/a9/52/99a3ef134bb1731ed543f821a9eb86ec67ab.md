# ভূমিকা

`|>` অপারেটরটিকে বলা হয় পাইপ অপারেটর। এটি দিয়ে একটির পর একটি ফাংশন কল এভাবে জুড়ে দেওয়া যায়, যাতে আগের ফাংশন কল থেকে রিটার্ন করা মানটি পরের ফাংশন কলে পাঠানো হয়।

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

উপরের কোডটি নিচের কোডের সমতুল্য:

```gleam
string.append(string.uppercase("hello"), "?!")
```

পাইপ অপারেটর মানটি হয় ফাংশন কলে প্রথম আর্গুমেন্ট হিসেবে পাঠায়, নয়তো নতুন একটি কলে একমাত্র আর্গুমেন্ট হিসেবে পাঠায়; কোনটিতে টাইপটি সঠিক হবে সেটিই বেছে নেয়।

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

কখনও কখনও আমরা মানটি অন্য একটি অবস্থানে পাঠাতে চাই; সেক্ষেত্রে কোন জায়গায় মানটি বসানো হবে সেটি বোঝাতে `_` প্লেসহোল্ডার ব্যবহার করা যায়।

```gleam
100
|> some_function(1, _, 2)
```
