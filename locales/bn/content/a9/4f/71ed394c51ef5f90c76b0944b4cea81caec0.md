# ভূমিকা

`switch()` ফাংশনটি `if` ... `else if` পরীক্ষার একটি দীর্ঘ সিরিজের সংক্ষিপ্ত বিকল্প হতে পারে।
যে ভ্যারিয়েবলের উপর switch করা হচ্ছে সেটি সাধারণত একটি স্ট্রিং হয়, আর সেক্ষেত্রে সিলেক্টর থেকে কোটেশন চিহ্নগুলো বাদ দেওয়া যায়।

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

খেয়াল করুন, উপরের উদাহরণের `M`-এর মতো মানটি ফাঁকা রাখলেই কেবল অপশনগুলো ফল থ্রু করে।
অন্য কিছু ভাষার মতো এখানে `break` স্টেটমেন্ট যুক্ত করার দরকার নেই।

`character` টাইপের উপর switch করার সময় শেষ মানটি একটি ডিফল্ট হিসেবে কাজ করে, এখানে যেমন।
ইন্টিজার টাইপের ক্ষেত্রে কোনো ডিফল্ট দেওয়া যায় না।

## `dplyr`-এর ফাংশন

বেস R-এর `switch` বেশ সীমিত: এটি কেবল একটি একক ইনপুটের সাথে হুবহু মিল করতে পারে।
১৯৯৩ সালে R প্রথম প্রকাশিত হওয়ার সময় এটি যুক্তিসঙ্গতই মনে হয়েছিল, তবে আধুনিক ব্যবহারের জন্য এটির উন্নতি দরকার।

~~~~exercism/note
যেমনটি [`Conditionals`][concept-conditionals] কনসেপ্টে উল্লেখ করা হয়েছে, `tidyverse` প্যাকেজের সংগ্রহটি বেস R-এর কার্যকারিতার পরিপূরক (এবং কখনও কখনও প্রতিস্থাপন) হিসেবে কাজ করার জন্য তৈরি করা হয়েছে, পূর্ববর্তী সংস্করণের সাথে সামঞ্জস্য না ভেঙে।

আপনার কোডের শুরুতে `library(dplyr)` (একক প্যাকেজের জন্য) অথবা `library(tidyverse)` (পুরো সংগ্রহের জন্য) যোগ করে `dplyr` প্যাকেজটি স্কোপে আনা যায়।

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

`dplyr` লাইব্রেরি `switch`-এর সাথে সম্পর্কিত দুটি অতিরিক্ত ফাংশন দেয়।

### `recode_values` ও `replace_values` ফাংশন

এই দুটি সম্পর্কিত ফাংশন পুরনো মান থেকে নতুন মানে ভেক্টরাইজড, switch-এর মতো ম্যাপিং করার সুযোগ দেয়।

এদের মধ্যে মূল পার্থক্য হলো `recode_values()` সম্পূর্ণ নতুন একটি ভেক্টর তৈরি করে, আর `replace_values()` বিদ্যমান ভেক্টরের আংশিক পরিবর্তন করতে দেয়।

মিল এখনও হুবহু হতে হয়, তবে:

- বাম দিকের অপশনগুলো ভেক্টর হতে পারে, আর যেকোনো এলিমেন্ট মিললে ইনপুটটি মিলে যায়।
- বাম দিকের অপশন আর ডান দিকের ফলাফল `=`-এর বদলে টিল্ডা `~` দিয়ে যুক্ত করা হয়।
- সব ক্ষেত্রেই একটি ডিফল্ট নির্দিষ্ট করা যায়।

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when` ফাংশন

`case_when` `case_match`-এর সিনট্যাক্সকে আরও এক ধাপ এগিয়ে নেয়, কারণ এটি `~`-এর বাম দিকে যেকোনো লজিক্যাল এক্সপ্রেশন ব্যবহার করতে দেয়।

ইনপুট ভেক্টরটি (নিচের উদাহরণে `x`) আর্গুমেন্ট হিসেবে দেওয়া হয় না, এটি কেবল আগেই ডিফাইন করা থাকতে হয়।

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()` ফাংশনটিও `dplyr`-এর অংশ।
