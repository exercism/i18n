# পরিচিতি

Haxe-এ ইটারেটর দিয়ে `for` লুপ ব্যবহার করে একটি মানের উপর ইটারেট করা হয়। ইটারেটর দুই ধরনের:

- `Iterator`, যা একটি মানের উপর ইটারেট করে।
- `Iterable` ডেটা, যা দিয়ে একটি ডেটা টাইপের উপর ইটারেট করা সম্ভব হয়।

এই দুই ধারণাই `Iterator<T>` এবং `Iterable<T>` দিয়ে প্রকাশ করা হয়:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

এই টাইপগুলোর একটির সাথে ইউনিফাই করে এমন যেকোনো ক্লাসকে `for` লুপ ব্যবহার করে ইটারেট করা যায়। কোনো ক্লাস যদি `hasNext` আর `next` মেথড ডিফাইন করে, তবে সেটিকে একটি ইটারেটর ধরা হয়; আর যদি সেটি একটি `iterator` মেথড ডিফাইন করে, তবে সেটিকে একটি ইটারেবল টাইপ ধরা হয়:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

উপরের উদাহরণে, `MyStringIterator` ক্লাসটিকে একটি ইটারেটর হিসেবে ধরা হয়, কারণ এটি `hasNext` আর `next` দুটি মেথডই ইমপ্লিমেন্ট করে, ফলে এটি `Iterator<String>`-এর সাথে সামঞ্জস্যপূর্ণ হয়।

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

এখানে, `MyArrayWrap` ক্লাসটিকে একটি ইটারেবল ডেটা টাইপ ধরা হয়, কারণ এটি `Iterable<Array<T>>`-এর সাথে সামঞ্জস্যপূর্ণ।
