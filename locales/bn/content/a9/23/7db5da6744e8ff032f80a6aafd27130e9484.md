# ভূমিকা

## অ্যারে

Ruby-তে **অ্যারে** হলো যেকোনো অবজেক্টের সাজানো, ইন্টিজার-ইনডেক্সযুক্ত কালেকশন।
অ্যারের ইনডেক্স শুরু হয় `0` থেকে।
ঋণাত্মক ইনডেক্স অ্যারের শেষের সাপেক্ষে ধরা হয়। যেমন `-1` ইনডেক্স অ্যারের শেষ এলিমেন্টটি বোঝায়, `-2` বোঝায় শেষ থেকে দ্বিতীয় এলিমেন্টটি, এভাবে চলতে থাকে।

### অ্যারে তৈরি করা

অ্যারে সাধারণত `[]` নোটেশন দিয়ে তৈরি করা হয়।
এতে যেকোনো ভিন্ন ধরনের অবজেক্ট থাকতে পারে।

```ruby
array = [1, "two", 3.0]
```

### এলিমেন্ট রেফারেন্স

অ্যারের এলিমেন্টগুলো তাদের ইনডেক্স দিয়ে `#[]` মেথডের সাহায্যে পাওয়া যায়।
এটি নির্দিষ্ট ইনডেক্সের এলিমেন্ট রিটার্ন করে, অথবা শুরুর ইনডেক্স থেকে শুরু করে নির্দিষ্ট দৈর্ঘ্য পর্যন্ত চলা একটি সাবঅ্যারে রিটার্ন করে।
ঋণাত্মক ইনডেক্স অ্যারের শেষ থেকে পিছনের দিকে গণনা করে।

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### হেল্পার মেথড

অ্যারের উপর অনেক কাজের হেল্পার মেথড আছে।
এখানে আরও কমন কয়েকটি দেওয়া হলো:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## এনুমারেশন

কালেকশনের মধ্য দিয়ে ইটারেট করতে লুপ ব্যবহার না করে Ruby-তে আমরা এনুমারেশন ব্যবহার করি।

এনুমারেশন হলো একটি কালেকশনের (এক্ষেত্রে একটি অ্যারে) মধ্য দিয়ে একে একে এগিয়ে গিয়ে প্রতিটি অবজেক্টের উপর কিছু একটি কাজ করার প্রক্রিয়া। এনুমারেশন Ruby-র একটি মূল ধারণা এবং এটি সর্টিং, গ্রুপিং, ম্যাপিং, রিডিউসিংসহ আরও অনেক কাজে ব্যবহৃত হয়।

একটি অ্যারের প্রতিটি শব্দ প্রিন্ট করার এনুমারেশন দেখতে এমন হবে:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

এই উদাহরণে আমরা আমাদের অ্যারের উপর `.each` মেথড কল করেছি এবং একটি _ব্লক_ পাস করেছি, যা একটি প্যারামিটার (`word`) নেয় এবং তা প্রিন্ট করে।

Track-এর পরে আরও গভীরে গিয়ে আমরা _ব্লক_ নিয়ে আলোচনা করব, তবে আপাতত এগুলোকে এমন অ্যানোনিমাস ফাংশন হিসেবে ভাবুন যেগুলো শূন্য বা তার বেশি আর্গুমেন্ট নিতে পারে।
এগুলো উপরের `do...end` সিনট্যাক্স দিয়ে, অথবা নিচের `{}` সিনট্যাক্স দিয়ে ডিফাইন করা যায়।

ব্লক ব্যবহার করে এমন আরও কিছু অ্যারে মেথডের উদাহরণ এখানে দেওয়া হলো:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
