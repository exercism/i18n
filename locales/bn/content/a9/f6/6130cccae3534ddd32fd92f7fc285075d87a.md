# পরিচিতি

Elm হলো নির্ভরযোগ্য ওয়েব অ্যাপ্লিকেশন তৈরির জন্য একটি চমৎকার ভাষা।
এতে আছে বন্ধুত্বপূর্ণ এরর মেসেজ, দারুণ পারফরম্যান্স, ছোট আকারের অ্যাসেট, আর কোনো রানটাইম এক্সেপশন নেই।

Elm-এর সম্ভবত সবচেয়ে বিখ্যাত এবং সবচেয়ে বেশি অনুকরণ করা অংশটি হলো The Elm Architecture। এটি ওয়েব অ্যাপ্লিকেশন সাজানোর একটি সরল প্যাটার্ন, আর সব Elm ওয়েব অ্যাপ্লিকেশন এভাবেই লেখা হয়।

মূল ধারণাটি হলো, আপনার কোড গড়ে ওঠে আপনার অ্যাপ্লিকেশনের স্টেটের একটি `Model`, আপনার মডেল `update` করার একটি উপায়, আর আপনার মডেল `view` করার একটি উপায়কে ঘিরে।

`Model`-এ অ্যাপ্লিকেশনের স্টেট থাকে, অর্থাৎ অ্যাপ্লিকেশনের প্রয়োজনীয় সব ডেটা।
ধরুন একটি সাধারণ অ্যাপ্লিকেশন, যেখানে একটি টেক্সট বক্স আছে এবং সেই লেখার উল্টো রূপ দেখানো একটি লেখা আছে। তাহলে মডেলটি দেখতে নিচের মতো হবে।
আপনি এই উদাহরণটি [Elm Guide][elm-guide-text-fields]-এও দেখতে পারেন।

```elm
type alias Model =
  { text : String
  }
```

`update` হলো এমন একটি ফাংশন, যা কোনো পরিবর্তন ঘটলে (যেমন ব্যবহারকারী একটি বোতামে ক্লিক করলে) একটি `Msg` নিয়ে কল করা হয়।
এটি `Msg` আর বর্তমান `Model` নেয় এবং একটি নতুন `Model` রিটার্ন করে।

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` হলো এমন একটি ফাংশন, যা ব্রাউজারে ব্যবহারকারীকে দেখানোর জন্য HTML রিটার্ন করে।
এটি বর্তমান `Model` নেয় এবং একটি `Html Msg` রিটার্ন করে (Elm HTML প্রকাশ করতে যে টাইপ ব্যবহার করে)।

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
