# পরিচিতি

PHP-তে, একটি ভ্যারিয়েবলের সাথে বন্ধনী [`()`] প্রয়োগ করে সেটিকে ফাংশন হিসেবে কল করা যায়। PHP যখন ফাংশনটি কল করার চেষ্টা করে, তখন ভ্যারিয়েবলের মানের সঙ্গে একই নামের একটি ফাংশন খুঁজে দেখে।

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
