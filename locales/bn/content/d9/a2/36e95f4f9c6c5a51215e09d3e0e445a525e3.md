# ভূমিকা

Go-তে আপনি `for` আর একটি ইনডেক্স ব্যবহার করে `slice`-এর ওপর ইটারেশন করতে পারেন, অথবা `range` ব্যবহার করতে পারেন।
`range` দিয়ে আবার `map`-এর ওপরও ইটারেশন করা যায়।

প্রতিটি ইটারেশন দুটি মান রিটার্ন করে: ইনডেক্স/কী (key) আর সেই ইনডেক্স/কী (key)-এর জায়গায় থাকা এলিমেন্টের একটি কপি।

## একটি স্লাইসের ওপর ইটারেশন

একেবারে জলের মতো সহজ, স্লাইসের ওপর লুপ চলে, আর ক্রমও প্রত্যাশিত মতোই।

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## একটি ম্যাপের ওপর ইটারেশন

ম্যাপের ওপর ইটারেশন করলে নতুন একটি সমস্যা দেখা দেয়।
এখন ক্রমটি র্যান্ডম।

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
উপরের আউটপুটটি ভুল বলে মনে হতে পারে, কারণ ম্যাপটি ডিক্লেয়ার করার সময় প্রথম যে কী (key)/মান জোড়াটি লেখা হয়েছিল, অর্থাৎ `9 10`, সেটিই সবার আগে প্রিন্ট হবে, সবার শেষে নয়, এমনটাই স্বাভাবিকভাবে প্রত্যাশা করা যায়।
তবে ম্যাপে স্বভাবতই কোনো নির্দিষ্ট ক্রম থাকে না, তাই এর কোনো প্রথম বা শেষ কী (key)/মান জোড়াও নেই।
এই কারণে ম্যাপের এন্ট্রিগুলোর ওপর ইটারেশন করলে কোন এন্ট্রি কোন ক্রমে দেখা হবে তা র্যান্ডম, কোনো নির্দিষ্ট প্যাটার্ন মানে না।
এর মানে হলো, উপরের আউটপুটটি সম্ভব, তবে আপনি নিজে এটি রান করে দেখলে যা পাবেন তার থেকে সেটি আলাদা হতে পারে।
এই বিষয়ে আরও জানতে দেখুন [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause)।
~~~~

## কী (key) বা মান বাদ দিয়ে ইটারেশন

Go-তে ব্যবহার না করা ভ্যারিয়েবল থাকলে বিল্ডের সময় এরর হয়।
কখনও কখনও প্রথম উদাহরণের মতো আপনার শুধু মানটিই দরকার হয়:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

আপনি `i`-এর বদলে `_` বসাতে পারেন, যা কম্পাইলারকে জানায় যে আমরা ওই মানটি ব্যবহার করি না:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

আপনি যদি শুধু ইনডেক্সটি প্রিন্ট করতে চান, তাহলে `x`-এর বদলে `_` বসাতে পারেন, কিংবা ডিক্লারেশনটি একেবারে বাদ দিতে পারেন:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## নন-স্ট্রাক্ট টাইপ

আপনি আগে স্ট্রাক্ট টাইপ ডিফাইন করা দেখেছেন।
নন-স্ট্রাক্ট টাইপও ডিফাইন করা সম্ভব, যা আপনি কোনো বিল্ট-ইন টাইপ ডিক্লারেশনের অ্যালিয়াস হিসেবে ব্যবহার করতে পারেন; আর স্ট্রাক্ট টাইপের মতোই সেগুলোকে বাড়ানোর জন্য এগুলোর ওপর রিসিভার ফাংশনও ডিফাইন করতে পারেন।

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

অ্যারে আর ম্যাপ দিয়ে গঠিত নন-স্ট্রাক্ট টাইপও আপনি ডিফাইন করতে পারেন।

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
