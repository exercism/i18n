# পরিচিতি

একটি *জেনেরিক ওয়ার্ড* এমন একটি অপারেশন ঘোষণা করে, যার আর্গুমেন্টের ক্লাস অনুযায়ী ভিন্ন ভিন্ন ইমপ্লিমেন্টেশন থাকতে পারে। `M:` দিয়ে মেথড যোগ করা হয়।

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` ওয়ার্ডটি এবং তার স্ট্যাক ইফেক্ট ঘোষণা করে। `M:` নির্দিষ্ট একটি ক্লাসে একটি মেথড ডিফাইন করে। রানটাইমে Factor স্ট্যাকের একেবারে উপরের আর্গুমেন্টের ক্লাস দেখে ডিসপ্যাচ করে।

আপনি জেনেরিকটির কাছে জিজ্ঞেস করতে পারেন, কোন কোন ক্লাসের জন্য তার মেথড আছে, আর পরে মেথড যোগ করতে বা মুছে ফেলতেও পারেন। ইনহেরিটেন্সের জন্য আলাদা কোনো সিনট্যাক্স নেই: যেকোনো টাপল ক্লাসই স্বয়ংক্রিয়ভাবে তার উপর মেথড ডিফাইন করার যোগ্য।
