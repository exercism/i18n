# পরিচিতি

ভেক্টর হলো একমাত্রিক অ্যারে। এতে ভিন্ন ভিন্ন টাইপের এলিমেন্ট থাকতে পারে।

## ভেক্টর তৈরি করা

`vector` ফাংশনের মাধ্যমে, অথবা এর রিডার ফর্ম `#()` ব্যবহার করে ভেক্টর তৈরি করা যায়।

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

যেহেতু এগুলো অ্যারে, তাই `make-array` দিয়েও তৈরি করা যায়:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## ভেক্টর প্রেডিকেট

কোনো অবজেক্ট ভেক্টর কি না তা জানতে শুধু `vectorp` প্রেডিকেট ব্যবহার করুন।

## এলিমেন্ট অ্যাক্সেস করা

ভেক্টরের এলিমেন্ট অ্যাক্সেস করতে `aref` ব্যবহার করুন; ইনডেক্স শুরু হয় শূন্য থেকে:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
