# ইঙ্গিত

## সাধারণ

- `unparse` আছে [`prettyprint`][prettyprint]-এ; স্লাইস ভ্যারিয়েন্টগুলো আছে [`sequences`][sequences]-এ; আর মাল্টি-ইনপুট ক্লিভ পরিবারটি আছে [`combinators`][combinators]-এ।

## 1. একটি মান কোট করুন

- একটি শব্দই যথেষ্ট: `unparse`।

## 2. ফ্ল্যাগের ফ্রেমিং সরিয়ে ফেলুন

- প্রথমে `1 tail-slice` দিয়ে শুরুতে থাকা মার্কারটি সরিয়ে ফেলুন, তারপর `1 head-slice*` দিয়ে শেষে থাকা মার্কারটি সরিয়ে ফেলুন।

## 3. একটি ফ্ল্যাগ ভাগ করুন

- `head-slice` আর `tail-slice` দুটোরই স্ট্যাকে ফ্ল্যাগটি *এবং* হেডার লেন্থটি দরকার। সেটি হলো `[ head-slice ] [ tail-slice ] 2bi`.

## 4. দুটি রিডিং থেকে ট্রায়াঙ্গুলেট করুন

- তিনটি আলাদা কোটেশন, প্রত্যেকটি একই দুটি রিডিং নেয়: `[ - ] [ + 2 / ] [ / ] 2tri`.

## 5. তিনটি রিডিং সারসংক্ষেপ করুন

- তিনটি ইনপুটযুক্ত তিনটি কোটেশন: `3tri`। যোগ করার কোটেশনটি `[ + + ]`; গুণফলেরটি `[ * * ]`; সর্বোচ্চটিরটি `[ max max ]`।
