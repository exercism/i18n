# পরিচিতি

## ইনক্লুড

অন্য ফাইলের বিষয়বস্তু ইনক্লুড করতে C++ `include` ডিরেক্টিভ ব্যবহার করে।
এই ইনক্লুডগুলো ফাইলের একেবারে উপরে লিখতে হয়।
কম্পাইলের সময় ডিরেক্টিভযুক্ত লাইনটি সংশ্লিষ্ট ফাইলের বিষয়বস্তু দিয়ে প্রতিস্থাপিত হয়।
ইনক্লুডের পর নেমস্পেসগুলো মূল ফাইলে যেমন ছিল তেমনই থেকে যায়।

## স্ট্যান্ডার্ড লাইব্রেরি

স্ট্যান্ডার্ড লাইব্রেরিতে অনেক কমন ফাংশন, অ্যালগরিদম আর ডেটা স্ট্রাকচার আছে।
স্ট্যান্ডার্ড লাইব্রেরি `std` নেমস্পেস ব্যবহার করে।

এর একটি উদাহরণ হলো C-এর নিউমেরিকস লাইব্রেরি `cmath`।
এতে অনেক কমন গাণিতিক অপারেশন আছে।

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
স্ট্যান্ডার্ড লাইব্রেরি ডাবল কোট `"`-এর বদলে অ্যাঙ্গেল ব্র্যাকেট `<>` দিয়ে ইনক্লুড করা হয়।
পার্থক্যটা হলো অবস্থানে, অর্থাৎ কম্পাইলার সংশ্লিষ্ট ফাইলগুলো কোথায় খোঁজে।
অ্যাঙ্গেল ব্র্যাকেটের ক্ষেত্রে বর্তমান প্রজেক্টে খোঁজা বাদ দেওয়া হয়, আর খোঁজা সরাসরি সিস্টেমের ইনক্লুড ডিরেক্টরিতে শুরু হয়।
আপনি যদি লোকাল ফাইল ইনক্লুড করতে চান, তাহলে ডাবল কোট ব্যবহার করবেন: `#include "myfile"`
