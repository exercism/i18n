# ইনস্টলেশন

অনুশীলনগুলো করতে আপনার [Vim](http://www.vim.org) দরকার:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [সোর্স](#source)

## macOS

OS-এর সাথে ডিফল্টভাবেই Vim আসে, তবে সেটি আশ্চর্যরকম পুরনো একটি সংস্করণ।

সম্ভবত আপনি সফটওয়্যার ইনস্টল করতে [MacPorts](https://www.macports.org) বা [Homebrew](https://brew.sh) ব্যবহার করেন।

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

আপনি যদি GUI চান, তাহলে বদলে [MacVim](https://macvim-dev.github.io/macvim) দেখতে পারেন।

## Ubuntu / Debian

GUI সাপোর্ট-সহ পূর্ণাঙ্গ Vim (`gvim`) ইনস্টল করুন:

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

[Chocolatey](https://chocolatey.org) ব্যবহার করে:

```
C:\> choco install vim
```

অথবা সরাসরি [এখান থেকে](http://www.vim.org/download.php#pc) ডাউনলোড করে ইনস্টল করুন।

## সোর্স

আপনি যদি নিজে সর্বশেষ Vim কম্পাইল করতে চান, তাহলে [GitHub-এর অফিসিয়াল রিপোজিটরিটি](https://github.com/vim/vim) দেখুন।
