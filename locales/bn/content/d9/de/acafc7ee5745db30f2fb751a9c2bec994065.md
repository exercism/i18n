# ভূমিকা

## কনস্ট্যান্ট

Gleam-এ কনস্ট্যান্ট হলো মানকে নাম দেওয়ার একটি উপায়। এগুলো `const` কিওয়ার্ড দিয়ে ডিফাইন করা হয়।

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

`pub` কিওয়ার্ড দিয়ে ডিফাইন করা হলে মডিউল কনস্ট্যান্টগুলো অন্য মডিউল থেকে অ্যাক্সেস করা যায়, নাহলে সেগুলো যে মডিউলে ডিফাইন করা হয়েছে কেবল সেই মডিউলের ভেতর থেকেই অ্যাক্সেস করা যায়।

## অর্ডার

Gleam-এর স্ট্যান্ডার্ড লাইব্রেরির `gleam/order` মডিউলে রয়েছে `Order` টাইপ, যা মান তুলনা করতে ব্যবহৃত হয়।

`Order`-এর ডেফিনিশন দেখতে এমন:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

টাইপটির তিনটি ভ্যারিয়েন্ট আছে, যার প্রতিটি একটি মান ও আরেকটি মানের মধ্যকার সম্পর্ক বোঝাতে ব্যবহৃত হয়:

- `Gt` - মানটি অন্য মানটির চেয়ে _বড়_।
- `Eq` - মানটি অন্য মানটির _সমান_।
- `Lt` - মানটি অন্য মানটির চেয়ে _ছোট_।

কোনো ডেটা টাইপ যদি আকার অনুযায়ী তুলনা করা যায়, তাহলে এটি কমন যে মডিউলটি একটি `compare` ফাংশন ডিফাইন করে, যা একটি `Order` মান রিটার্ন করে। উদাহরণস্বরূপ, `gleam/float` ও `gleam/int` এমন `compare` ফাংশন ডিফাইন করে, যেগুলো যথাক্রমে ফ্লোট ও ইন্টিজারের ওপর কাজ করে।

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort`-এর মতো সাজানোর ফাংশনগুলো সাধারণত এমন একটি ফাংশন নেয়, যা একটি `Order` মান রিটার্ন করে, ফলে কলকারী ঠিক করতে পারে তালিকাটি কীভাবে সাজানো হবে।

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
