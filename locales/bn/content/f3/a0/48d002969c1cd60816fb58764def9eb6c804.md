# নির্দেশনা

কার্ল Exercism-এর ওয়েবসাইটে শেখার জন্য ভাষার একটি তালিকার হিসাব রাখতে চায়।
কার্লের নতুন ভাষা যোগ করতে, পুরোনো ভাষা মুছে ফেলতে এবং নির্দিষ্ট কিছু ভাষা তালিকায় আছে কি না তা যাচাই করতে পারা দরকার।
কার্ল যদি Java বা Kotlin শিখতে চায়, তাহলে সেটা হবে খুবই দারুণ ব্যাপার!

## 1. ভাষার তালিকাটি খালি কি না তা যাচাই করার জন্য একটি ফাংশন ডিফাইন করুন

কার্লের জানা দরকার তার ভাষার তালিকা কখনো খালি হয়ে যায় কি না, যাতে সে শেখার জন্য আরও ভাষা খুঁজে বের করতে পারে!
`isEmpty` নামে একটি মেথড ডিফাইন করুন, যা তালিকায় কোনো ভাষা না থাকলে `true` রিটার্ন করে।

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. তালিকায় একটি ভাষা যোগ করার জন্য একটি ফাংশন ডিফাইন করুন

কার্ল Kotlin আর Python শেখার জন্য খুব উৎসাহ নিয়ে অপেক্ষা করছে!
`addLanguage` নামে একটি মেথড ডিফাইন করে কার্লকে শুরু করতে সাহায্য করুন, যা সে যে ভাষাটি শিখতে চায় সেটি নেয় এবং তালিকায় যোগ করে।

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. তালিকা থেকে একটি ভাষা মুছে ফেলার জন্য একটি ফাংশন ডিফাইন করুন

কার্ল ঠিক করেছে, সে এখন Scala শিখতে চায় না।
`removeLanguage` নামে একটি মেথড ডিফাইন করে কার্লকে সেটি তালিকা থেকে মুছে ফেলতে সাহায্য করুন, যা সে যে ভাষাটি মুছে ফেলছে সেটি নেয় এবং তালিকা থেকে মুছে ফেলে।

```java
languageList.removeLanguage("Scala");
```

## 4. তালিকার প্রথম আইটেমটি রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

কার্ল তার তালিকায় যোগ করা প্রথম ভাষাটি (যেটি এখনো তালিকায় আছে) মনে রাখতে চায়।
`firstLanguage` নামে একটি মেথড ডিফাইন করুন, যা তালিকার প্রথম ভাষাটি রিটার্ন করে।

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. তালিকায় কতটি ভাষা আছে তা রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

কার্লের জানা দরকার, সে কতটি ভাষা শেখার চেষ্টা করছে।
`count` নামে একটি মেথড ডিফাইন করে কার্লকে উত্তরটি খুঁজে পেতে সাহায্য করুন, যা তালিকার ভাষার সংখ্যা রিটার্ন করে।

```java
int two = languageList.count(); // 2
```

## 6. কোনো ভাষা তালিকায় আছে কি না তা নির্ধারণ করার জন্য একটি ফাংশন ডিফাইন করুন

কার্ল মনে করার চেষ্টা করছে, সে Python না Ruby শিখতে চেয়েছিল।
`containsLanguage` নামে একটি মেথড ডিফাইন করুন, যা সে যে ভাষাটি সম্পর্কে জানতে চায় সেটি নেয়, যাতে কার্ল তা জানতে পারে!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. তালিকাটি উত্তেজনাকর কি না তা নির্ধারণ করার জন্য একটি ফাংশন ডিফাইন করুন

কার্ল যদি Java বা Kotlin শিখতে চায়, তাহলে সেটা খুবই উত্তেজনাকর ব্যাপার!
`isExciting` নামে একটি মেথড ডিফাইন করুন, যা কার্ল Java বা Kotlin শিখতে চাইলে true রিটার্ন করে।

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
