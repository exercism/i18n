# নির্দেশনা

এই অনুশীলনীতে আপনি একটি সাধারণ ইন্টিজার ক্যালকুলেটরের জন্য এরর হ্যান্ডলিং তৈরি করবেন।
ক্যালকুলেটরটির যোগ, গুণ ও ভাগ অপারেশন সমর্থন করা উচিত এবং ফলাফলটি একটি ফরম্যাট করা স্ট্রিং হিসেবে রিটার্ন করা উচিত।
এছাড়াও অবৈধ অপারেশন এবং শূন্য দিয়ে ভাগ করার ক্ষেত্রে এরর হ্যান্ডলিং বাস্তবায়ন করবেন।

লক্ষ্য হলো এমন একটি কার্যকর ক্যালকুলেটর তৈরি করা, যা নিচের ফরম্যাটে একটি স্ট্রিং রিটার্ন করে:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. ক্যালকুলেটরের অপারেশনগুলো বাস্তবায়ন করুন

এই কাজের মূল ফাংশনটি হবে `SimpleCalculator::calculate`, যা তিনটি আর্গুমেন্ট নেয়: দুটি ইন্টিজার এবং অপারেশন বোঝানো একটি `ByteArray`।
নিচের অপারেশনগুলো বাস্তবায়ন করুন:

- **যোগ**: `+` চিহ্ন দিয়ে
- **গুণ**: `*` চিহ্ন দিয়ে
- **ভাগ**: `/` চিহ্ন দিয়ে

## 2. অবৈধ অপারেশন সামলানো

যদি অপারেশন চিহ্নটি `+`, `*` বা `/` ছাড়া অন্য কিছু হয়, তাহলে ক্যালকুলেটরটি হয় প্যানিক করবে, নয়তো একটি এরর রিটার্ন করবে:

- যদি অপারেশনটি একটি খালি স্ট্রিং হয়, তাহলে `ByteArray` এরর মেসেজ `"Operation cannot be an empty string"` নিয়ে প্যানিক করুন।
- অন্য যেকোনো অবৈধ অপারেশনের জন্য `Result::Err("Operation is out of range")` রিটার্ন করুন।

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. শূন্য দিয়ে ভাগ করার সময় এরর সামলানো

`0` দিয়ে ভাগ করার চেষ্টা করলে ক্যালকুলেটরটির একটি এরর মেসেজ নিয়ে প্যানিক করা উচিত, যা বোঝাবে যে শূন্য দিয়ে ভাগ করা অনুমোদিত নয়।
রিটার্ন করা ফলাফলটি `'Division by zero is not allowed'` মানের একটি `felt252` ভ্যালু হওয়া উচিত।

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
