## 1. মিনিটে প্রত্যাশিত বেক সময় একটি কনস্ট্যান্ট হিসেবে ডিফাইন করুন

`EXPECTED_BAKE_TIME` [কনস্ট্যান্টটি][constants] ডিফাইন করুন, যা বোঝায় লাসাগনাটি ওভেনে কত মিনিট বেক হতে হবে।
আপনার রান্নার বই অনুযায়ী লাসাগনাটি ৪০ মিনিট ওভেনে থাকা উচিত:

```python
>>> print(EXPECTED_BAKE_TIME)
40
```

## 2. মিনিটে বাকি বেক সময় হিসাব করুন

`bake_time_remaining()` ফাংশনটি সম্পূর্ণ করুন। এটি আর্গুমেন্ট হিসেবে লাসাগনাটি এখন পর্যন্ত ওভেনে কত মিনিট ছিল তা নেয় এবং `EXPECTED_BAKE_TIME` কনস্ট্যান্টের ভিত্তিতে রিটার্ন করে লাসাগনাটিকে আর কত মিনিট বেক করতে হবে।

```python
>>> bake_time_remaining(30)
10
```

## 4. মিনিটে মোট অতিবাহিত সময় (প্রস্তুতি + বেকিং) হিসাব করুন

`elapsed_time_in_minutes()` ফাংশনটি ডিফাইন করুন, যা আর্গুমেন্ট হিসেবে দুটি প্যারামিটার নেয়:
