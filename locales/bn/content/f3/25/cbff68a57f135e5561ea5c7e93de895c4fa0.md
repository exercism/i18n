# ডামি

## `--argjson` অপশন

টেস্টগুলো `jq`-এর `--argjson n 1` অপশনটি ব্যবহার করে।
এটি `$n` নামে একটি jq ভ্যারিয়েবল তৈরি করে, যার মান _**সংখ্যা**_ `1`।

এর তুলনায় `--arg n 1` অপশনটি দেখুন, যেটি `$n` নামে একটি jq ভ্যারিয়েবল তৈরি করে, যার মান _**স্ট্রিং**_ `"1"`।

আপনার সলিউশনে n-তম মৌলিক সংখ্যাটি পেতে ইনপুট হিসেবে `$n` ব্যবহার করুন।

ম্যানুয়ালে [jq চালানো][man-invoke] দেখুন।

[man-invoke]: https://jqlang.org/manual/#invoking-jq
