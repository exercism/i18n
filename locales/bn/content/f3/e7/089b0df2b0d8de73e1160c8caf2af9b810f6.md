# নির্দেশনা

আপনার বন্ধু এইমাত্র একটি গুরুত্বপূর্ণ গোপন তথ্যসহ আপনাকে একটি বার্তা পাঠিয়েছেন।
অন্যরা যাতে সহজে এটি পড়তে না পারে, তাই পরপর কিছু বিট ম্যানিপুলেশন করে বার্তাটি এনক্রিপ্ট করা হয়েছে।
বার্তাটি ডিক্রিপ্ট করতে সাহায্য করার মেথডগুলো আপনাকে লিখতে হবে।

## 1. বিটগুলো আবার পিছিয়ে শিফট করুন

বার্তা ডিক্রিপ্ট করার প্রথম ধাপ হলো, বিটগুলো আবার ডানে শিফট করে এনক্রিপশনের সময় করা শিফটটি বাতিল করা।
ডিক্রিপশনের পরের ধাপগুলো ধরে নেবে যে বাঁ দিক থেকে 0 যোগ করা হয়েছে।

`Secrets.shiftBack` মেথডটি লিখুন, যা একটি value এবং কত ঘর শিফট করতে হবে সেই সংখ্যা নেয় এবং শিফটটি সম্পন্ন করে।

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. কিছু বিট সেট করুন

এরপর, কিছু বিট আছে যেগুলো 1-এ সেট করতে হবে।

`Secrets.setBits` মেথডটি লিখুন, যা একটি value ও একটি mask নেয় এবং value-এর বিটগুলো 1-এ সেট করার ফলাফল রিটার্ন করে।
mask-এ যে বিটটি 1, value-এর সেই বিটটিও 1-এ সেট হতে হবে।
বাকি সব বিট অপরিবর্তিত রাখতে হবে।

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. নির্দিষ্ট কিছু বিট উল্টে দিন

এনক্রিপশনের সময় কিছু বিট উল্টে দেওয়া হয়।
বার্তা ডিক্রিপ্ট করতে সেগুলো আবার উল্টে দিতে হবে।

`Secrets.flipBits` মেথডটি লিখুন, যা একটি value ও mask নেয়।
কোন বিটগুলো উল্টাতে হবে তা mask নির্দেশ করে।
mask-এ বিটটি যদি 1 হয়, তবে value-এর বিটটি উল্টে যায়।
বাকি সব বিট অপরিবর্তিত থাকে।

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. নির্দিষ্ট কিছু বিট ক্লিয়ার করুন

সবশেষে, কিছু বিট আছে যেগুলো সবসময় 0-এ ডিক্রিপ্ট হয়।

`Secrets.clearBits` মেথডটি লিখুন, যা একটি value ও একটি mask নেয়।
mask-এ যে বিটটি 1, `value`-এর সেই বিটগুলো 0-এ সেট করতে হবে।
বাকি সব বিট অপরিবর্তিত রাখতে হবে।

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
