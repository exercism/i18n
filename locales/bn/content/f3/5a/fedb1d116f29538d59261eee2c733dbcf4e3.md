# সম্পর্কে

একটি একক ক্যারেক্টার উপস্থাপন করতে Rust [char][char type] টাইপটি বাস্তবায়ন করে। একটি `char` লিটারেল একক কোটেশনের মধ্যে লেখা হয়, যেমন `'a'`।
প্রতিটি `char`-এর আকার চার বাইট এবং এটি একটি একক [ইউনিকোড স্কেলার ভ্যালু][unicode scalar] উপস্থাপন করে।

তবে [`char`][character type] সবসময় আমরা যা অক্ষর বলে ভাবি, তা নয়। কিছু ভাষা, যেমন হিন্দি, [ডায়াক্রিটিক্স][diacritics] ব্যবহার করে; এগুলো বিশেষ প্রতীক, যা যে ক্যারেক্টারের সাথে যুক্ত থাকে সেটিকে পরিবর্তন করে। Rust-এ ডায়াক্রিটিকটি আলাদা একটি `char` হলেও, আমরা সাধারণত ডায়াক্রিটিক আর যে ক্যারেক্টারটিকে এটি পরিবর্তন করে, তাদের একসাথে একটি অক্ষর হিসেবেই ভাবি।

একটি ক্যারেক্টার আর তার ডায়াক্রিটিককে একসাথে বলা হয় [গ্রাফিম ক্লাস্টার][grapheme cluster]। গ্রাফিম ক্লাস্টার প্রসেস করার জন্য বাহ্যিক ক্রেট ব্যবহার করা যায়, যেমন [unicode-segmentation][unicode-segmentation]।

উদাহরণ

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

প্রিন্ট করে

```rust
2
'u'
'\u{308}'
```

'\u{308}' হলো একটি `char` লিটারেল লেখার আরেকটি উপায়। `\u` বোঝায় এটি একটি ইউনিকোড `char`, যেখানে `{308}` হলো ওই ক্যারেক্টার বা ডায়াক্রিটিকের অনন্য ইউনিকোড নম্বর।
