# নির্দেশনা

এই অনুশীলনীতে আপনাকে এমন একটি এনক্রিপশন ডিভাইসের সফটওয়্যার লেখার দায়িত্ব দেওয়া হয়েছে, যা ডেটার উপর নানা রূপান্তর চালিয়ে কাজ করে। সহজ ফাংশনগুলো একসাথে জুড়ে জটিল ফাংশন নমনীয়ভাবে তৈরির একটি উপায় আপনার দরকার।

প্রতিটি টাস্কের জন্য এমন একটি অ্যানোনিমাস ফাংশন রিটার্ন করুন, যা কল করার স্কোপ থেকে কল করা যায়।

## 1. একটি যোগ করার ফাংশন তৈরি করুন

`secret_add` ইমপ্লিমেন্ট করুন। এটি এমন একটি ফাংশন রিটার্ন করবে, যা একটি আর্গুমেন্ট নেয় এবং তার সাথে `secret_add`-এ পাস করা আর্গুমেন্ট যোগ করে।

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. একটি বিয়োগ করার ফাংশন তৈরি করুন

`secret_subtract` ইমপ্লিমেন্ট করুন। এটি এমন একটি ফাংশন রিটার্ন করবে, যা একটি আর্গুমেন্ট নেয় এবং সেই আর্গুমেন্ট থেকে `secret_subtract`-এ পাস করা সিক্রেট বিয়োগ করে।

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. একটি গুণ করার ফাংশন তৈরি করুন

`secret_multiply` ইমপ্লিমেন্ট করুন। এটি এমন একটি ফাংশন রিটার্ন করবে, যা একটি আর্গুমেন্ট নেয় এবং `secret_multiply`-এ পাস করা সিক্রেট দিয়ে সেটিকে গুণ করে।

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. একটি ভাগ করার ফাংশন তৈরি করুন

`secret_divide` ইমপ্লিমেন্ট করুন। এটি এমন একটি ফাংশন রিটার্ন করবে, যা একটি আর্গুমেন্ট নেয় এবং `secret_divide`-এ পাস করা সিক্রেট দিয়ে সেটিকে ভাগ করে।

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. একটি ফাংশন কম্বাইনার তৈরি করুন

`secret_combine` ইমপ্লিমেন্ট করুন। এটি এমন একটি ফাংশন রিটার্ন করবে, যা একটি আর্গুমেন্ট নেয় এবং `secret_combine`-এ পাস করা দুটি ফাংশন ক্রমানুসারে তার উপর প্রয়োগ করে।

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
