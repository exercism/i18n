# ক্লাস স্ট্যাটিক কিওয়ার্ড

ক্লাস হলো PHP-তে কোড সাজানোর একটি একক, যা প্রায়শই কোনো জিনিস/সার্ভিস/প্রসিডিউরের একটি ইনস্ট্যান্সকে বোঝায়।
`static` ও `self` কিওয়ার্ড ব্যবহার করে প্রপার্টি এবং মেথড ক্লাসের সাপেক্ষে সব ইনস্ট্যান্সের জন্য (বা কোনো ইনস্ট্যান্স ছাড়াও) থাকতে পারে।

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## সীমাবদ্ধতা

static ক্লাস মেথড কেবল নিজের ক্লাসের অন্য static ক্লাস প্রপার্টি বা ক্লাস মেথড কল করতে পারে।
