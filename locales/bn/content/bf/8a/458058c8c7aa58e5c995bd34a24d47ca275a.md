# পরিচিতি

এখন পর্যন্ত আমরা দেখেছি, কোনো মেথডে পাঠানো আর্গুমেন্টগুলি অবস্থান অনুযায়ী মেথডের ঘোষিত প্যারামিটারগুলির সাথে মিলিয়ে নেওয়া হয়। এর একটি বিকল্প উপায় হলো, বিশেষ করে যখন কোনো রুটিন অনেকগুলি আর্গুমেন্ট নেয়, তখন কলকারী ঘোষিত প্যারামিটারের আইডেন্টিফায়ার উল্লেখ করে আর্গুমেন্ট মিলিয়ে দিতে পারেন।

নিচে সিনট্যাক্সটি দেখানো হলো:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
