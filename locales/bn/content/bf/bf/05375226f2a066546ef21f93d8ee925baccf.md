# পরিচিতি

একটি [`list`][list] হলো _সিকোয়েন্সে_ সাজানো আইটেমের একটি মিউটেবল কালেকশন।
 বেশিরভাগ কালেকশনের মতো (_দেখুন বিল্ট-ইন [`tuple`][tuple], [`dict`][dict] এবং [`set`][set]_), অ্যারে যেকোনো (বা একাধিক) ডেটা টাইপের রেফারেন্স ধরে রাখতে পারে, এমনকি অন্য অ্যারেরও।
 অ্যারে সম্পূর্ণ বা আংশিকভাবে কপি করা যায় [স্লাইস নোটেশন][slice notation] দিয়ে, বা `<list>.copy()` ব্যবহার করে।
 যেকোনো [সিকোয়েন্স][sequence type]-এর মতোই, `lists`-এর ভিতরের এলিমেন্টগুলো বাঁ দিক থেকে `0-based index` নম্বর দিয়ে, বা ডান দিক থেকে `-1-based index` নম্বর দিয়ে রেফার করা হয়।

অ্যারে [কমন][common sequence operations] এবং [মিউটেবল][mutable sequence operations] সিকোয়েন্স অপারেশন, দুটোই সাপোর্ট করে, যেমন `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` এবং `<list>.reverse()`।
 `for item in <list>` কনস্ট্রাক্ট ব্যবহার করে `list`-এর ভিতরের এলিমেন্টগুলো ইটারেট করা যায়।
 এলিমেন্টের ইনডেক্স এবং এলিমেন্টের মান, দুটোই দরকার হলে `for index, item in enumerate(<list>)` ব্যবহার করা যায়।

Python অ্যারে নিয়ে কাজ করার জন্য অনেক কাজের [অ্যারে মেথড][list-methods] দিয়ে থাকে।
 এর মধ্যে বাছাই করা কিছু `list methods` নিচে আলোচনা করা হয়েছে।


মনে রাখবেন, কোনো `list-method` দিয়ে একটি `list` নিয়ে কাজ করলে **আপনি পাস করা অ্যারেটিই বদলে দেন**।
 মূল `list`-টি মিউটেট করতে না চাইলে, স্লাইস বা `<list>.copy()` দিয়ে অন্তত তার একটি `shallow copy` তৈরি করতে হবে।


## আইটেম যোগ করা

কোনো অ্যারের শেষে বা "ডান দিকের প্রান্তে" একটি আইটেম যোগ করতে `<list>.append(<item>)` ব্যবহার করুন:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

_অ্যাপেন্ড_ করার বদলে `<list>.insert()` আপনাকে অ্যারের _একটি নির্দিষ্ট ইনডেক্সে_ আইটেমটি যোগ করার সুযোগ দেয়।
এটি ২টি প্যারামিটার নেয়:

1. যে `<index>`-এ আপনি আইটেমটি যোগ করতে চান।
2. যে `<item>` যোগ করতে হবে।

**নোট**: প্রদত্ত `index` যদি ০ হয়, তবে আইটেমটি `list`-এর শুরুতে ("বাম দিক") যোগ হবে।
 প্রদত্ত `index` যদি `list`-এর শেষ ইনডেক্সের চেয়ে বড় হয়, তবে আইটেমটি একেবারে শেষে যোগ হবে, অর্থাৎ `<list>.append(<item>)` ব্যবহার করার মতোই ফল পাওয়া যাবে।


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


`<list>.extend(<item>)` দিয়ে একটি অ্যারের সাথে অন্য একটি ইটারেবলের (যেমন `set`, `tuple`, `str`, বা `list`) এলিমেন্টগুলো একত্র করা যায়।
  ইটারেবলটি _আনপ্যাক_ করা হয় এবং এলিমেন্টগুলো ক্রমানুসারে অ্যাপেন্ড হয় (_এই অবস্থায় `<list>.append(<item>)` ব্যবহার করলে পুরো ইটারেবলটিই **একটি একক আইটেম** হিসেবে যোগ হতো।_)।


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## আইটেম মুছে ফেলা

অ্যারে থেকে একটি আইটেম মুছতে `<list>.remove(<item>)` ব্যবহার করুন, এবং যে আইটেমটি মুছতে চান সেটি আর্গুমেন্ট হিসেবে দিন।
 আইটেমটি `list`-এ না থাকলে `<list>.remove(<item>)` একটি `ValueError` থ্রো করবে।


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


অন্যভাবে, `<list>.pop(<index>)` মেথড ব্যবহার করলে একটি এলিমেন্ট সরানো **এবং** `return` করা, দুটোই হবে, যাতে সেটি ব্যবহার করা যায়।


`<list>.pop(<index>)` একটি ঐচ্ছিক প্যারামিটার নেয়: যে আইটেমটি সরানো ও রিটার্ন করা হবে তার `index`।
 (ঐচ্ছিক) `index` আর্গুমেন্টটি উল্লেখ না করলে `list`-এর শেষ এলিমেন্টটি সরানো ও রিটার্ন করা হবে।
 উল্লেখ করা `index` যদি শেষ আইটেমের `index`-এর চেয়ে বড় হয়, তবে একটি `IndexError` উত্থাপিত হয়।


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

`list.clear()` দিয়ে একটি `list` থেকে সব এলিমেন্ট মুছে ফেলা যায়। এটি কোনো প্যারামিটার নেয় না।

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## উল্টানো ও পুনর্বিন্যাস

`<list>.reverse()` মেথড এলিমেন্টগুলোর ক্রম **ইন-প্লেস** উল্টে দেয়।


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


[`<list>.sort()`][sort]-এর সাহায্যে একটি অ্যারে _**ইন-প্লেস**_ পুনর্বিন্যাস করা যায়।
ডিফল্ট সর্ট ক্রম বাঁ দিক থেকে _ঊর্ধ্বক্রমে_।
Python-এর ডকুমেন্টেশনে [সাজানোর আরও টিপস ও কৌশল][sorting how to] আছে।

~~~~exercism/note
 ২০০২ থেকে ২০২২ সাল পর্যন্ত Python অভ্যন্তরীণভাবে অ্যারে সাজাতে [`Timsort`][timsort] নামের একটি অ্যালগরিদম ব্যবহার করত, কিন্তু `Python 3.11` থেকে [`Powersort`][powersort]-এ বদলে যায়।

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

_অবরোহক্রমে_ সাজাতে চাইলে `reverse=True` আর্গুমেন্টটি দিন:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

মূল অ্যারে মিউটেট করা যেখানে কাম্য নয়, সেখানে বিল্ট-ইন [`sorted(<iterable>)`][sorted] ফাংশন ব্যবহার করে সাজানো একটি **কপি** পাওয়া যায়।


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## অ্যারেতে একটি আইটেম কতবার আছে

একটি অ্যারেতে কোনো এলিমেন্ট কতবার আছে তা `list.count(<item>)`-এর সাহায্যে হিসাব করা যায়।
 এটি যে `item` গুনতে হবে সেটি আর্গুমেন্ট হিসেবে নেয় এবং `list`-এ এলিমেন্টটি মোট কতবার আছে সেই সংখ্যা রিটার্ন করে।


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## আইটেমের ইনডেক্স খুঁজে বের করা

`<list>.index(<item>)` পাস করা কোনো আইটেমের _প্রথম উপস্থিতির_ `index` নম্বর রিটার্ন করে।
 কোনো উপস্থিতি না থাকলে একটি `ValueError` উত্থাপিত হয়।
 আইটেমের সঠিক অবস্থান জানার দরকার না থাকলে, একটি অ্যারে নির্দিষ্ট কোনো মান ধারণ করে কি না তা দেখতে বিল্ট-ইন `in` অপারেটর বেশি কার্যকর।


ইনডেক্সিং বাঁ দিক থেকে শূন্য-ভিত্তিক, তাই "প্রথম" আইটেমের অবস্থান `0`।
ইনডেক্সিং ডান দিক থেকেও কাজ করে, যা `-1` দিয়ে শুরু হয়।


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

`list`-এর নির্দিষ্ট অংশে খোঁজা সীমিত করতে `start` ও `end` ইনডেক্সও দেওয়া যায়:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
