# নির্দেশনা

ভবিষ্যতের জাদুকর এলিসের কিছু বেসিক বিষয় অনুশীলন করা দরকার। তার কাছে কার্ডের একটি স্ট্যাক আছে, যা নিয়ে সে কাজ করতে চায়।

বিষয়টি একটু সহজ করতে তিনি শুধু ১ থেকে ১০ পর্যন্ত কার্ড ব্যবহার করেন।

কার্ডের স্ট্যাকটি একটি `queue` দিয়ে প্রকাশ করা হয়, যেখানে স্ট্যাকের নিচের দিক থাকে কিউয়ের সামনে এবং স্ট্যাকের উপরের দিক থাকে কিউয়ের পিছনে।

## 1. স্ট্যাকের উপরে একটি কার্ড যোগ করুন

`insert_top` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের একটি কপি রিটার্ন করে, যেখানে দেওয়া নতুন কার্ডটি স্ট্যাকের উপরে যোগ করা হয়েছে।

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. স্ট্যাক থেকে উপরের কার্ডটি সরান

`remove_top_card` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের উপরের কার্ডটি সরিয়ে ফেলার পর স্ট্যাকের একটি কপি রিটার্ন করে। যদি দেওয়া স্ট্যাকটি খালি হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. স্ট্যাকের নিচে একটি কার্ড যোগ করুন

`insert_bottom` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের একটি কপি রিটার্ন করে, যেখানে দেওয়া নতুন কার্ডটি স্ট্যাকের নিচে যোগ করা হয়েছে।

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. স্ট্যাক থেকে নিচের কার্ডটি সরান

`remove_bottom_card` ফাংশনটি ইমপ্লিমেন্ট করুন, যা স্ট্যাকের নিচের কার্ডটি সরিয়ে ফেলার পর স্ট্যাকের একটি কপি রিটার্ন করে। যদি দেওয়া স্ট্যাকটি খালি হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. স্ট্যাকের আকার পরীক্ষা করুন

`check_size_of_stack` ফাংশনটি ইমপ্লিমেন্ট করুন, যা পরীক্ষা করে যে স্ট্যাকের আকার দেওয়া `stack_size`-এর সমান কি না।

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
