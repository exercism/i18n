# ভূমিকা

Python-এ, [একটি `enum`][enum-docs] হলো এমন একটি নামের সেট, যেগুলো ইউনিক `literal` বা `constant` মানের সাথে বাঁধা থাকে।
`Enum` ক্লাস থেকে ইনহেরিট বা সাবক্লাস করে `Enums` ডিফাইন করা হয়।
বিল্ট-ইন `enum` টাইপগুলো `enum` মডিউলে পাওয়া যায় এবং `from enum import Enum` দিয়ে `Enum` ক্লাসটি ইমপোর্ট করা যায়।


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

লক্ষ্য করুন, `enum` মেম্বারগুলোর মান যেকোনো ডেটা টাইপ হতে পারে, যেমন `str`, `tuple`, `float` ইত্যাদি।

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

`enum`-এ দুইটি মেম্বারকে একই মান অ্যাসাইন করলে, পরে অ্যাসাইন করা মেম্বারটি আগেরটির এলিয়াস হয়ে যায়। `enum`-এর দুইটি ভিন্ন মেম্বারের জন্য একই নাম ব্যবহার করা যায় না।

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

`enum`-এর মেম্বারগুলোর মধ্য দিয়ে ইটারেশন করা যায় সাধারণ `for member in` সিনট্যাক্স দিয়ে:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

[`is` (_আইডেন্টিটি অপারেটর_)][identity-keyword] বা `is not` দিয়ে `Enum` মেম্বারগুলো তুলনা করা যায়। `==` বা `!=` (_সমানতা অপারেটর_) একইভাবে কাজ করে:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

নির্দিষ্ট কোনো মানের জন্য `enum`-এর একটি মেম্বার অ্যাকসেস করতে `<EnumName>(<value>)` ব্যবহার করা যায়:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
