# পরিচিতি

বাইনারি ডিজিট শেষ পর্যন্ত সরাসরি আপনার CPU বা RAM-এর ট্রানজিস্টরের সাথে মিলে যায়, আর প্রতিটি ট্রানজিস্টর "চালু" না "বন্ধ" আছে সেটার সাথেও।

নিম্নস্তরের ম্যানিপুলেশন, যাকে অনানুষ্ঠানিকভাবে "বিট-টুইডলিং" বলা হয়, সিস্টেম ভাষাগুলোতে বিশেষভাবে গুরুত্বপূর্ণ।

Julia-র মতো হাই-লেভেল ভাষা সাধারণত এই বিশদগুলোর বেশিরভাগই আড়াল করে রাখে। তবে বেস ভাষাতেই বিট-স্তরের অপারেশনগুলোর পূর্ণ সেট পাওয়া যায়।

***নোট:*** REPL-এ মানুষের পড়ার মতো বাইনারি আউটপুট দেখতে নিচের প্রায় সব উদাহরণকেই একটি `bitstring()` ফাংশনে মুড়ে দিতে হবে। এতে চোখে বিশ্রী লাগে, তাই এই ফাংশনের বেশিরভাগ ব্যবহার এখান থেকে বাদ দেওয়া হয়েছে।

## বিট-শিফট অপারেশন

ইন্টিজার টাইপ, সাইনড বা আনসাইনড, ১ আর ০-এর একটি স্ট্রিং হিসেবে প্রকাশ করা যায়।

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

বিট-শিফট কেবল সবকিছু নির্দিষ্ট সংখ্যক অবস্থান বামে বা ডানে সরিয়ে দেয়। `UInt` টাইপে এক প্রান্ত থেকে কিছু বিট পড়ে যায়, আর অন্য প্রান্ত শূন্য দিয়ে ভরাট করা হয়:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

প্রতিটি বাম-শিফট মানটিকে দ্বিগুণ করে আর প্রতিটি ডান-শিফট এটিকে অর্ধেক করে (ট্রাঙ্কেশনের সাপেক্ষে)। দশমিক রূপে এটা আরও স্পষ্ট:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

এ ধরনের বিট-শিফট "প্রকৃত" অ্যারিথমেটিকের চেয়ে অনেক দ্রুত, তাই নিম্নস্তরের কোডিংয়ে এই কৌশলটি বেশ জনপ্রিয়।

সাইনড ইন্টিজারের বেলায় আমাদের একটু বেশি সতর্ক থাকতে হয়।

বাম শিফট তুলনামূলক সরল:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

তাই ধনাত্মক সাইনড ইন্টিজার বাম-শিফট করা আনসাইনড ইন্টিজারের মতোই।

ঋণাত্মক মান [টু'স কমপ্লিমেন্ট][2complement] আকারে সংরক্ষণ করা হয়, যার মানে বাঁদিকের বিটটি ১। বাম-শিফটে কোনো সমস্যা নেই, কিন্তু ডান-শিফট করার সময় বাঁদিকের বিটগুলো কী দিয়ে ভরাট করব?

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

`>>` অপারেটর অ্যারিথমেটিক শিফট করে, সাইন বিট অক্ষুণ্ণ রেখে।

`>>>` অপারেটর লজিক্যাল শিফট করে, শূন্য দিয়ে ভরাট করে যেন সংখ্যাটি আনসাইনড।

## বিটওয়াইজ লজিক

আগের একটি কনসেপ্টে আমরা দেখেছি যে `&&` (and), `||` (or) এবং `!` (not) অপারেটরগুলো বুলিয়ান মানের সাথে ব্যবহার করা হয়।

দুটি ইন্টিজারের বিট তুলনা করার জন্য সমতুল্য অপারেটর আছে: `&` (বিটওয়াইজ and), `|` (বিটওয়াইজ or) এবং `~` (টিল্ডি, বিটওয়াইজ not)।

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

এখানে `xor()` হলো এক্সক্লুসিভ-অর, যা একটি ফাংশন হিসেবে ব্যবহৃত হয়।

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
