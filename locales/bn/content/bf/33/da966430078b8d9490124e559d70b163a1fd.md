# ইঙ্গিত

## সাধারণ

- কলব্যাক ফাংশন হলো এমন ফাংশন, যেগুলোকে কল করা ফাংশনের কাছে আর্গুমেন্ট হিসেবে পাঠানো হয়।
- কলব্যাক ফাংশনগুলোকে কল করা ফাংশনের স্পেসিফিকেশন মেনে চলতে হবে।

## 1. সফল বার্তা দিয়ে নোটিফাই করা

- আপনার ফাংশনে ইমপোর্ট করা API ফাংশন `notify` ব্যবহার করুন।
- `notify`-কে একটি অবজেক্ট পাস করুন। এতে `message` নামের একটি প্রপার্টি থাকা উচিত। মেসেজ ভ্যালুটি কী হওয়া উচিত, সেটি ভেবে দেখুন।
- JSDoc টাইপ হিন্টে লক্ষ্য রাখুন, ফাংশনটির কোনো মান রিটার্ন করা উচিত নয়।

## 2. এরর বার্তা দিয়ে নোটিফাই করা

- আপনার ফাংশনে ইমপোর্ট করা API ফাংশন `notify` ব্যবহার করুন।
- `notify`-কে আরেকটি অবজেক্ট পাস করুন। এতে `message` নামের একটি প্রপার্টি থাকা উচিত। মেসেজ ভ্যালুটি আগেরটার থেকে আলাদা হওয়া উচিত।
- ফাংশন ডেফিনিশনের উপরে থাকা কমেন্টগুলো [JSDoc] লক্ষ্য করুন:
  - ফাংশনটির কোনো মান রিটার্ন করা উচিত নয়।

## 3. ফল কেনার জন্য অর্ডার দেওয়া

- আগেই ইমপোর্ট করা `order` ফাংশনটি ব্যবহার করুন।
- JSDoc টাইপ হিন্টে লক্ষ্য রাখুন, ফাংশনটি ৩টি আর্গুমেন্ট গ্রহণ করবে এবং কোনো মান রিটার্ন করবে না।
- আগে তৈরি করা কলব্যাকগুলোকে `order` ফাংশনের আর্গুমেন্ট হিসেবে পুনরায় ব্যবহার করুন।

## 4. আপনার কাজ রিফ্যাক্টর করে আরও সংক্ষিপ্ত ফাংশন বানানো

- আগের টাস্কগুলোর ফাংশনগুলো পুনরায় ব্যবহার করুন।
- JSDoc টাইপ হিন্টে লক্ষ্য রাখুন, ফাংশনটি ২টি আর্গুমেন্ট গ্রহণ করবে এবং কোনো মান রিটার্ন করবে না।
- অর্ডার দেওয়ার জন্য মুদির কাছে পাঠানো কোয়েরি বোঝায় এমন একটি অবজেক্টে আর্গুমেন্টগুলো একত্রিত করুন।
