# CLI

## সেটআপ

Purescript ইনস্টল করার সবচেয়ে সহজ উপায় হলো Node.js এবং NPM-এর মাধ্যমে।

আপনার কম্পিউটারে যদি Node.js আগে থেকেই ইনস্টল করা না থাকে, তবে আপনি এটি [Node.js ওয়েবসাইট][nodejs-website] থেকে ডাউনলোড করতে পারেন। Node.js চালু হয়ে গেলে, PureScript কম্পাইলার এবং Spago প্যাকেজ ম্যানেজার/বিল্ড টুল ইনস্টল করতে টার্মিনালে এই কমান্ডটি লিখুন।

```shell
npm install -g purescript spago
```

আরও তথ্য [PureScript রিপোজিটরিতে][purescript-repository] পাওয়া যাবে।

## প্রয়োজনীয়তা

অ্যাসাইনমেন্টের ডিপেন্ডেন্সি ইনস্টল করুন:

```shell
spago install
spago build
```

## টেস্ট স্যুট পাস করানো

টেস্টগুলো চালান এভাবে:

```shell
spago test
```

টেস্ট স্যুটগুলোতে প্রথমটি ছাড়া বাকি সব টেস্ট স্কিপ করা থাকে। এটি আপনাকে এক ধাপ করে অনুশীলনীটি সমাধান করতে উৎসাহিত করার জন্য।

একটি টেস্ট পাস হয়ে গেলে, আপনি `xit`-কে `it`-তে পরিবর্তন করে পরেরটি চালু করতে পারেন।

## সমাধান জমা দেওয়া

যখন কোনো টেস্ট স্কিপ করা থাকে না এবং সবগুলো পাস করে, তখন আপনি আপনার সমাধান এভাবে জমা দিতে পারেন:

```shell
exercism submit src/<NAME>.purs
```

## কাস্টম টেস্ট লেখা

আপনি যদি অতিরিক্ত কাস্টম টেস্ট লিখতে চান, তবে `test/Custom.purs` নামে একটি নতুন ফাইল তৈরি করুন এবং নতুন ফাইলটি আপনার সমাধানের সাথে জমা দিন:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
