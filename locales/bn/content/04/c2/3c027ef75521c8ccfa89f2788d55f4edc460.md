# ভূমিকা

## তুলনার অপারেটর

অন্য অনেক ভাষার মতোই R-এরও একগুচ্ছ অপারেটর আছে:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## ব্রাঞ্চিং

if-else-এর মূল রূপটি হলো:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

এক্ষেত্রে বুলিয়ানের চারপাশে প্রথম বন্ধনী `()` এবং বডির চারপাশে দ্বিতীয় বন্ধনী `{}`, দুটোই দিতে হবে।

সাধারণ একটি `if` স্টেটমেন্ট ছোট করেও লেখা যায়:

```R
if (x == 0) return("success")
```
