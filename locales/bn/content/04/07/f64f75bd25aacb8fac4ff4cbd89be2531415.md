# আমাকে উপেক্ষা করুন

## ইনপুট

আপনার স্ক্রিপ্টটি standard input (stdin) দিয়ে অ্যালফামেটিক ধাঁধাটি একটি একক স্ট্রিং হিসেবে পাবে। ধাঁধার স্ট্রিংটি এই ফরম্যাট অনুসরণ করে: `WORD1 + WORD2 + ... == RESULT`।

উদাহরণস্বরূপ:

```text
SEND + MORE == MONEY
```

## আউটপুট

যদি ধাঁধাটির কোনো সমাধান থাকে, তাহলে স্পেস দিয়ে আলাদা করা `LETTER=DIGIT` জোড়া সম্বলিত একটি একক লাইন প্রিন্ট করুন, যা বর্ণ অনুসারে বর্ণানুক্রমিকভাবে সাজানো।

উপরের উদাহরণটির জন্য আউটপুট হওয়া উচিত:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

যদি ধাঁধাটির একাধিক বৈধ সমাধান থাকে, তাহলে সেগুলোর যেকোনো একটি প্রিন্ট করলেই চলবে।

যদি ধাঁধাটির কোনো সমাধান না থাকে, তাহলে কিছুই প্রিন্ট করবেন না (একটি খালি লাইন)।
