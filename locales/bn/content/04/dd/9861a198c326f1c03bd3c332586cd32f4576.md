# সংখ্যা

`INT` একটি পূর্ণ সংখ্যা ধারণ করে। এই Sather-এ এটি ঠিক 32 বিট, তাই এটি -2147483648 থেকে 2147483647 পর্যন্ত গোনে।

```sather
   goals : INT is
      return 42;
   end;
```

## আর্গুমেন্ট

একটি রুটিন বন্ধনীর ভেতরে আর্গুমেন্ট নেয়, আর প্রতিটির একটি টাইপ থাকে:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

একই টাইপের আর্গুমেন্টগুলো একটি ডিক্লারেশনেই রাখা যায়, আর এটাই প্রচলিত ধরন:

```sather
   total(first, second : INT) : INT is
```

## পাটিগণিত

| অপারেটর | অর্থ |
| --- | --- |
| `+` | যোগ |
| `-` | বিয়োগ, আর ঋণাত্মক করা |
| `*` | গুণ |
| `/` | ভাগ, ভাগশেষ বাদ দিয়ে |
| `%` | ওই ভাগের ভাগশেষ |

দুটি `INT`-এর মাঝে `/` কখনোই ভগ্নাংশ তৈরি করে না:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

ভগ্নাংশ চাইলে `FLTD` লাগবে, যেটি পরে আসবে।

সাধারণ পাটিগণিতের মতোই গুণ ও ভাগ যোগ ও বিয়োগের চেয়ে বেশি অগ্রাধিকার পায়। অন্য কিছু চাইলে বন্ধনী দিয়ে গ্রুপ করতে হয়:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## INT-এর দরকারি রুটিনগুলো

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

স্ট্রিংয়ের সাথে পরিচয় হয়ে গেলে, `.str` দিয়েই একটি সংখ্যা বাক্যের অংশ হয়ে ওঠে।
