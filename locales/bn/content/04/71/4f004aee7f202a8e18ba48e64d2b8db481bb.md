# পরিচিতি

## ওপেক টাইপ

Gleam-এ ওপেক টাইপ হলো এমন কাস্টম টাইপ, যেখানে টাইপটি যে মডিউল ডিফাইন করে, কেবল সেই মডিউলই ওই টাইপের মান তৈরি করতে বা প্যাটার্ন ম্যাচ করতে পারে। নির্দিষ্ট একটি উপায়ে ব্যবহার হওয়া উচিত এমন টাইপ বানানোর জন্য এটি কাজে লাগে।

ওপেক টাইপ ডিফাইন করা হয় `opaque` কিওয়ার্ড দিয়ে।

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

এই `PositiveInt` টাইপটি ব্যবহার করা হয় এমন জায়গায়, যেখানে একটি int দরকার, কিন্তু সেটি শূন্য বা তার বেশি হতে হবে। সাধারণ Gleam `Int` এখানে ব্যবহার করা যেত না, কারণ সেগুলো ঋণাত্মকও হতে পারে।

এই টাইপটি যে মডিউল ডিফাইন করে, সেই মডিউল ভেতরের int মানটি পাওয়ার জন্য একটি ফাংশন ডিফাইন করতে পারে, আর `PositiveInt` টাইপ তৈরি করার জন্য আরেকটি ফাংশন, যা মানটি ধনাত্মক না হলে একটি এরর রিটার্ন করবে।

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

এই API দিয়ে অন্য মডিউলগুলো ঋণাত্মক মান দিয়ে একটি `PositiveInt` তৈরি করতে পারে না, তাই যে ফাংশনই একটি `PositiveInt` নেয়, সে নিশ্চিত থাকতে পারে যে মানটি ধনাত্মক।
