# :except দিয়ে ANSI ইমপোর্ট

নির্দেশনায় বলা হয়েছে, “আপনি অন্য গাড়ির রঙের জন্য সাপোর্ট যোগ করার পরিকল্পনা করছেন, তাই পুরো মডিউলটি ইমপোর্ট করতে চান”, তবে যে `color` ফাংশনটি সংঘর্ষ ঘটায় সেটি বাদ দিয়ে। এটি করতে `:except` অপশনটি এভাবে ব্যবহার করুন:

```elixir
import IO.ANSI, except: [color: 1]
```
