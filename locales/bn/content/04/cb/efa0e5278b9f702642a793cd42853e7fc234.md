# নির্দেশনার পরিশিষ্ট

## এক্সেপশন কাস্টমাইজ করা এবং রেইজ করা

কখনও কখনও আপনার কোডে এক্সেপশন দুটোই [কাস্টমাইজ](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) করা এবং [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) করা প্রয়োজন হয়। এমন করার সময়, এররটির উৎস কী তা বোঝাতে সবসময় একটি **অর্থবহ এরর মেসেজ** রাখা উচিত। এতে আপনার কোড আরও পাঠযোগ্য হয় এবং ডিবাগিংয়ে অনেক সাহায্য করে।

নতুন এক্সেপশন ক্লাসের মাধ্যমে কাস্টম এক্সেপশন তৈরি করা যায় (আরও বিস্তারিত জানতে [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) দেখুন), যেগুলো সাধারণত [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception)-এর সাবক্লাস হয়।

যেসব পরিস্থিতিতে আপনি জানেন যে এররটির উৎস নির্দিষ্ট কোনো এক্সেপশন টাইপের একটি ডেরিভেটিভ হবে, সেখানে _Exception_ ক্লাসের অধীনস্থ [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)-এর মধ্যে একটি থেকে ইনহেরিট করতে পারেন। এরর রেইজ করার সময়ও একটি অর্থবহ মেসেজ রাখা উচিত।

এই নির্দিষ্ট অনুশীলনীতে দুটি _কাস্টম এক্সেপশন_ তৈরি করতে হবে। একটি এক্সেপশন [রেইজ](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/"থ্রো" করতে হবে যখন আপনার সার্কুলার বাফার **ভর্তি**, আর একটি যখন তা **খালি**। টেস্ট পাস হবে কেবল তখনই, যখন আপনি যথাযথ এক্সেপশন কাস্টমাইজ করবেন, সেগুলো `raise` করবেন এবং যথাযথ এরর মেসেজ দেবেন।

একটি `built-in exception` কাস্টমাইজ করতে, ওই এক্সেপশন থেকে ইনহেরিট করা একটি `class` তৈরি করুন। মেসেজসহ কাস্টম এক্সেপশন রেইজ করার সময়, মেসেজটি `exception` টাইপের একটি আর্গুমেন্ট হিসেবে লিখুন:

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
