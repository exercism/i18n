# নির্দেশনা

আপনি একটি উপকূলীয় মালবাহী জাহাজের বোটসেইন। বিলজ (জাহাজের কাঠামোর সবচেয়ে নিচের কক্ষ) হলো সেখানে বর্জ্য পানি জমা হয়, আর প্রতি পালিতে বিলজের যন্ত্রপাতি খুলতে, চালাতে এবং গুছিয়ে তুলে রাখতে হয়। পাম্প চলাকালীন যা-ই ঘটুক, যন্ত্রপাতিকে *অবশ্যই* আবার তার গুছিয়ে রাখা অবস্থায় ফিরে যেতে হবে।

পরীক্ষাগুলো আপনাকে নতুন পাম্প পেতে `<test-pump>` দেয়। প্রতিটি পাম্পের একটি `opened>>` স্লট থাকে, যা খোলা থাকলে `t` এবং একবার ডিসপোজ করা হয়ে গেলে `f` দেখায়।

## 1. বিলজ খালি করুন

একটি একক পাম্প মুক্ত করার জন্য `drain-bilge` ডিফাইন করুন। একই পাম্পে দুবার `drain-bilge` কল করলে কোনো ক্ষতি হওয়া উচিত নয়, ফ্রেমওয়ার্কটি সেটি আপনার হয়ে সামলে নেয়।

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. পাম্প-আউট রুটিন

`pump-out` ডিফাইন করুন এমনভাবে যাতে এটি একটি পাম্প ও একটি কোয়োটেশন নেয়, কোয়োটেশনটি ব্যবহার করতে পারে সেজন্য পাম্পটি স্ট্যাকে তুলে দেয়, আর পরে পাম্পটি মুক্ত করে, *এমনকি কোয়োটেশনটি থ্রো করলেও*।

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. পুরো পালির রুটিন

`shift-routine` ডিফাইন করুন যা দুটি পাম্প ও একটি কোয়োটেশন নেয়। একটি ডেস্ট্রাক্টর স্কোপ খুলুন, *দুটি* পাম্পকেই শর্তহীন মুক্তির জন্য রেজিস্টার করুন, তারপর কোয়োটেশনটি কল করুন। কোয়োটেশনটি স্বাভাবিকভাবে শেষ হোক বা থ্রো করুক, শেষে দুটি পাম্পই মুক্ত হয়ে যায়।

কোয়োটেশনটি ইনপুট হিসেবে স্ট্যাকে দুটি পাম্পই পায়।

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. ঝুঁকিপূর্ণ পাম্প-আউট

কখনও কখনও একটি পাম্প ধার করা থাকে। আপনি সেটি কেবল তখনই বাদ দিতে চান যখন কিছু ভুল হয়ে যায়, নাহলে পরের পালির জন্য সেটি খোলা অবস্থায় রেখে যেতে হয়। `risky-pump-out` ডিফাইন করুন যা একটি পাম্প ও একটি কোয়োটেশন নেয়, পাম্পটিকে **কেবল ব্যর্থ হলে** মুক্তির জন্য রেজিস্টার করে, আর পাম্পটি স্ট্যাকে রেখেই কোয়োটেশনটি কল করে।

কোয়োটেশনটি সফল হলে পাম্পটি খোলা থাকে। কোয়োটেশনটি থ্রো করলে পাম্পটি মুক্ত হয়ে যায় এবং এক্সেপশনটি ছড়িয়ে পড়ে।

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. একটি কাস্টম ডিসপোজেবল: ভালভ

একেবারে নতুন একটি ডিসপোজেবল, একটি `valve`, দিয়ে টুলকিটটি পূর্ণ করুন। টাপলটি আপনার জন্য ঘোষণা করা আছে:

```factor
TUPLE: valve < disposable is-open ;
```

- `new-disposable` দিয়ে একটি নতুন ভালভ তৈরি করতে `<valve> ( -- valve )` ডিফাইন করুন, যেখানে `is-open` থাকবে `t`.
- `is-open`-কে `f`-এ ফ্লিপ করতে `M: valve dispose*` ইমপ্লিমেন্ট করুন।

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
