# নির্দেশনা

এই অনুশীলনীতে, আপনি আপনার স্থানীয় আর্কেড হলের সবচেয়ে জনপ্রিয় গেমের হাই স্কোর হিসাব রাখার একটি উপায় তৈরি করছেন।

## 1. একটি নতুন হাই স্কোর ম্যাপ ডিফাইন করুন

নতুন একটি হাই স্কোর ম্যাপ তৈরি করতে, `HighScore.new/0` ফাংশনটি ডিফাইন করুন, যা কোনো আর্গুমেন্ট নেয় না এবং হাই স্কোরের একটি নতুন, খালি ম্যাপ রিটার্ন করে।

```elixir
HighScore.new()
# => %{}
```

## 2. হাই স্কোর ম্যাপে প্লেয়ার যোগ করুন

হাই স্কোর ম্যাপে একজন প্লেয়ার যোগ করতে, `HighScore.add_player/3` ডিফাইন করুন, যা তিনটি আর্গুমেন্ট নেয় এমন একটি ফাংশন:

- প্রথম আর্গুমেন্টটি স্কোরের ম্যাপ।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে একজন প্লেয়ারের নাম।
- তৃতীয় আর্গুমেন্টটি ইন্টিজার হিসেবে স্কোর। আর্গুমেন্টটি অপশনাল। তৃতীয় আর্গুমেন্টটি 0 ডিফল্ট মান দিয়ে ইমপ্লিমেন্ট করুন।

ডিফল্ট প্রাথমিক স্কোরটি একটি মডিউল অ্যাট্রিবিউটে সংরক্ষণ করুন। এটি আবার দরকার হবে।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. স্কোর ম্যাপ থেকে প্লেয়ার সরান

হাই স্কোর ম্যাপ থেকে একজন প্লেয়ার সরাতে, `HighScore.remove_player/2` ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ম্যাপ।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে প্লেয়ারের নাম।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. একজন প্লেয়ারের স্কোর রিসেট করুন

একজন প্লেয়ারের স্কোর রিসেট করতে, `HighScore.reset_score/2` ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ম্যাপ।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে প্লেয়ারের নাম, যার স্কোর আপনি রিসেট করতে চান।

প্লেয়ারের কোনো স্কোর না থাকলেও ফাংশনটি কাজ করা উচিত।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. একজন প্লেয়ারের স্কোর আপডেট করুন

আগের স্কোরের সাথে যোগ করে একজন প্লেয়ারের স্কোর আপডেট করতে, `HighScore.update_score/3` ডিফাইন করুন, যা তিনটি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ম্যাপ।
- দ্বিতীয় আর্গুমেন্টটি স্ট্রিং হিসেবে প্লেয়ারের নাম, যার স্কোর আপনি আপডেট করতে চান।
- তৃতীয় আর্গুমেন্টটি সেই স্কোর, যা আপনি সংরক্ষিত হাই স্কোরের সাথে **যোগ** করতে চান।

প্লেয়ারের আগের কোনো স্কোর না থাকলেও ফাংশনটি কাজ করা উচিত। ধরে নিন আগের স্কোরটি 0।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. প্লেয়ারদের একটি অ্যারে পান

প্লেয়ারদের একটি অ্যারে পেতে, `HighScore.get_players/1` ডিফাইন করুন, যা একটি আর্গুমেন্ট নেয়:

- প্রথম আর্গুমেন্টটি স্কোরের ম্যাপ।

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
