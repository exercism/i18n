# সম্পর্কে

## সমতা

Elm টাইপগুলোকে সমতা অপারেটর `(==)` দিয়ে "একই হওয়া" যাচাই করা যায়।
অসমতা অপারেটরটি `(/=)` (অনেক ভাষার মতো `!=` নয়)।

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

তুলনা করা দুটি মানই একই টাইপের হতে হবে।
সমতা অপারেটরটি লিটারাল, টুপল, রেকর্ড ও কাস্টম টাইপে কাজ করে।
অপারেটরটি স্ট্রাকচারাল সমতা যাচাই করে, অর্থাৎ সমান মানগুলোর কনটেন্ট ও গভীর গঠন সমান হয়, টাইপ অ্যানোটেশন বা মেমোরিতে তাদের অবস্থান যাই হোক।

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

মনে রাখবেন, ফাংশন *কখনোই* তুলনা করবেন না, কারণ এতে প্রোগ্রামটি রানটাইমে ক্র্যাশ করবে।
এই সীমাবদ্ধতা সম্পর্কে আরও তথ্য [এখানে][equality-operator]।

## তুলনা

তুলনা অপারেটর `(<)`, `(<=)`, `(>)`, `(>=)` এবং `min`, `max`, `compare` ফাংশনগুলো `comparable` টাইপে কাজ করে।
`comparable` হলো একটি বিশেষ টাইপ, যা তুলনা করা যায় এমন সব বিল্ট-ইন টাইপকে একত্র করে: সংখ্যা, ক্যারেক্টার, স্ট্রিং, `comparable` জিনিসের অ্যারে, আর `comparable` জিনিসের টুপল।
ক্যারেক্টারগুলো তাদের [ইউনিকোড কোডপয়েন্ট][unicode-codepoint] অনুযায়ী তুলনা করা হয়।

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

সিকোয়েন্সজাতীয় টাইপ (স্ট্রিং, অ্যারে আর টুপল) [লেক্সিকোগ্রাফিক ক্রমে][lexicographic-order] তুলনা করা হয়।
সংক্ষেপে, সিকোয়েন্সের এলিমেন্টগুলো ক্রমানুসারে জোড়ায় জোড়ায় তুলনা করা হয়, যতক্ষণ না কোনো এলিমেন্ট ছোট হিসেবে পাওয়া যায় বা কোনো সিকোয়েন্স শেষ হয়।

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

রেকর্ড বা কাস্টম টাইপের মতো অন্য টাইপের মান সরাসরি তুলনা করা যায় না।

কিছু বিল্ট-ইন টাইপের কনটেন্ট `comparable` হতে হয়, যেমন `Set` বা `Dict`-এর কী (key), কারণ তাদের গঠন একটি অভ্যন্তরীণ ক্রমের উপর নির্ভর করে।
এর মানে হলো কাস্টম টাইপ `Set`-এ রাখা যায় না, যদিও কমিউনিটির বিকল্প আছে: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] আরও কিছু।

`comparable` মানের অ্যারে `List.sort` দিয়ে সাজানো যায়, আর `comparable` মানে ম্যাপ করা যায় এমন মানের অ্যারে `List.sortBy` দিয়ে সাজানো যায়।
আপনার যদি স্তরভিত্তিক সাজানো দরকার হয় (একটি বৈশিষ্ট্য দিয়ে সাজানো, আর সমতা হলে অন্য একটি দিয়ে ভাঙা), তাহলে টুপল বা অ্যারে `List.sortBy`-এর সাথে ব্যবহার করা যায় (অন্য [বিকল্পগুলোর][sort-by] মধ্যে), কারণ টুপল আর অ্যারে লেক্সিকোগ্রাফিক ক্রমে সাজানো হয়।


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

`compare` ফাংশনটি দুটি `comparable` মান নেয় আর একটি `Order` রিটার্ন করে।
`Order` হলো একটি টাইপ, যা একটিমাত্র অপারেশনে যাচাই করে একটি মান অন্য একটির চেয়ে বড় (`GT`), সমান (`EQ`) নাকি ছোট (`LT`)।

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

যেকোনো টাইপের জন্য তুলনা ফাংশন তৈরি করা যায় এবং ব্যবহার করা যায়, যেমন `List.sortWith` দিয়ে সাজানোর জন্য:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
