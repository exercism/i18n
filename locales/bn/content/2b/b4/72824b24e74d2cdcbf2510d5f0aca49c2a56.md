# নির্দেশনা সংযোজন

এই অনুশীলনীর একটি সম্ভাব্য সমাধান হল নিজের হাতে একটি মডুলার এক্সপোনেনশিয়েশন ফাংশন ইমপ্লিমেন্ট করা।
এটি সম্পর্কে আরও জানতে [নিচের পৃষ্ঠাটি](https://en.wikipedia.org/wiki/Modular_exponentiation) দেখুন।

## বোনাস পয়েন্টের জন্য

অনেক ইমপ্লিমেন্টেশন ইনপুটের পুরো ডোমেইনে কাজ করে না।
এর জন্য আরও কিছু ঐচ্ছিক টেস্ট দেওয়া আছে, যা নিশ্চিত করতে সাহায্য করে যে সব বৈধ ইনপুট বৈধ ফলাফলই দেয়।

বোনাস টেস্টগুলো চালাতে `#[ignore]` ফ্ল্যাগটি সরিয়ে ফেলুন এবং `big-primes` ফিচার দিয়ে টেস্টগুলো এভাবে চালান:

```bash
$ cargo test --features big-primes
```
