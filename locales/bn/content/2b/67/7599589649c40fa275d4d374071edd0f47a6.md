# নির্দেশাবলি

সংবাদপত্র কারখানার নতুন কোয়ালিটি ম্যানেজার এলেনা আপনাকে উৎপাদন কক্ষ নজরদারি করার জন্য একটি ছোট সফটওয়্যার লেখার অনুরোধ করেছেন।

## 1. একটি কাস্টম এরর ডিফাইন করুন

`ERROR:` পার্সিং শব্দটি দিয়ে একটি এরর টাপল ক্লাস `machine-error` ডিফাইন করুন। এতে কোনো স্লট লাগে না।

```factor
machine-error   ! throws a fresh machine-error
```

## 2. আর্দ্রতা যাচাই করুন

`check-humidity` ডিফাইন করুন। এটি স্ট্যাক থেকে একটি আর্দ্রতার রিডিং নেয় এবং রিডিংটি `70`-এর চেয়ে কঠোরভাবে বড় হলে `"humidity too high"` স্ট্রিংটি `throw` করে। অন্যথায় এটি কিছুই রিটার্ন করে না।

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. তাপমাত্রা যাচাই করুন

`check-temperature` ডিফাইন করুন। এটি একটি তাপমাত্রার রিডিং নেয় এবং রিডিংটি `500`-এর চেয়ে কঠোরভাবে বড় হলে `"temperature too high"` স্ট্রিংটি `throw` করে। অন্যথায় এটি কিছুই রিটার্ন করে না।

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. মেশিন নজরদারি করুন

`monitor` ডিফাইন করুন যেন এটি স্ট্যাক থেকে একটি আর্দ্রতা ও একটি তাপমাত্রা নিয়ে দুটি যাচাইই চালায়। যেকোনো একটি যাচাই `throw` করলে `monitor` তার বদলে একটি নতুন `machine-error` `throw` করবে। দুটিই পাস করলে `monitor` কিছুই রিটার্ন করে না।

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. এক ব্যাচ রিডিং নজরদারি করুন

`monitor-batch` ডিফাইন করুন যেন এটি `{ humidity temperature }` রিডিংয়ের একটি অ্যারে নিয়ে রিটার্ন করে তার মধ্যে কতগুলো ব্যর্থ হবে (অর্থাৎ কতগুলো `monitor`-কে `throw` করাবে)।

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
