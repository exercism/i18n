# ইনস্টলেশন

এই অনুশীলনীগুলো চালাতে আপনার যা লাগবে, তা হলো ইনস্টল করা [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) এবং [Java 8](https://java.com/en/download/)। CommandBox CLI Mac, Linux আর Windows-এ চলে, এবং ইনস্টলেশন গাইডটি এখানে পাবেন:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

আপনি যদি Mac-এ Homebrew ব্যবহারকারী হন, তাহলে CommandBox CLI সেটআপ করার একটি উদাহরণ হতে পারে:

```bash
brew install commandbox
```

CLI ইনস্টল হয়ে গেলে আপনি REPL নিয়ে খেলতে পারেন:

```bash
box repl
```

আপনি সরাসরি .cfm পেজ চালাতে পারেন:

```bash
box exec myTest.cfm
```

এমনকি আপনার হার্ড ড্রাইভের যেকোনো ডিরেক্টরিতে একটি ওয়েব সার্ভারও চালু করতে পারেন:

```bash
box server start
```

CommandBox-এ একটি ইন্টারঅ্যাকটিভ শেল আছে, যেখানে ট্যাব কমপ্লিশন আরও উন্নত এবং যা আরও দ্রুত চলে। শুধু কোনো আর্গুমেন্ট ছাড়া `box` বাইনারিটি রান করলেই আপনি সেটিতে ঢুকে পড়বেন।

```bash
box
```
