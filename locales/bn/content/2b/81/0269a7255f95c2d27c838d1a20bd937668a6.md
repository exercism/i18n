# সম্পর্কে

Lua সংখ্যার জন্য দুটি রূপ ব্যবহার করে: ৬৪-বিট ইন্টিজার সংখ্যা এবং ডাবল-প্রিসিশন ফ্লোটিং-পয়েন্ট সংখ্যা।

~~~exercism/note
5.3 সংস্করণের আগে, Lua সমস্ত সংখ্যা ডাবল-প্রিসিশন ফ্লোটিং-পয়েন্ট ফরম্যাটে উপস্থাপন করত।
~~~

সংখ্যাগুলি একটি ঐচ্ছিক দশমিক অংশ সহ, এবং একটি ঐচ্ছিক দশমিক সূচক সহ লেখা যেতে পারে।
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

দশমিক বিন্দু বা সূচক সহ একটি সংখ্যাকে ফ্লোট হিসাবে বিবেচনা করা হয় এবং তা ছাড়া একটি সংখ্যাকে ইন্টিজার হিসাবে বিবেচনা করা হয়, তবে উভয়েরই টাইপ 'number'।
```lua
type(1)         --> number
type(2.0)       --> number
```

যদি আমরা ফ্লোট এবং ইন্টিজারের মধ্যে পার্থক্য করতে চাই, তবে `math` মডিউলের `type` ফাংশন ব্যবহার করা যেতে পারে।
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## তুলনা

একই মানের ইন্টিজার এবং ফ্লোট সমান হিসেবে তুলনা করা হয়:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## পাটিগণিত

Lua সাধারণ পাটিগণিত অপারেটরগুলির সেট সমর্থন করে: যোগ, বিয়োগ, গুণ, ভাগ এবং ঋণাত্মককরণ। অতিরিক্তভাবে এটি ফ্লোর ডিভিশন, মডুলো এবং এক্সপোনেনশিয়েশন সমর্থন করে।

### যোগ, বিয়োগ, গুণ এবং ঋণাত্মককরণ

যদি উভয় অপারেন্ড ইন্টিজার হয় তবে অপারেশনের ফলাফল একটি ইন্টিজার। একই কথা ফ্লোটের ক্ষেত্রেও প্রযোজ্য।
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

যদি একটি অপারেন্ড ফ্লোট হয়, তবে বাকি ইন্টিজারগুলিও ফ্লোটে রূপান্তরিত হবে এবং অপারেশনের ফলাফল একটি ফ্লোট হবে।
```lua
1.0 + 2   --> 3.0
```

### ভাগ

ভাগ সর্বদা ফ্লোটের উপর কাজ করে এবং ফলাফল হিসাবে একটি ফ্লোট দেয়।
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

শূন্য দিয়ে ভাগ করলে `inf` বা `-inf` হবে। শূন্যকে শূন্য দিয়ে ভাগ করলে `-nan` হবে।
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### ফ্লোর ডিভিশন

যদি একটি ইন্টিজার ফলাফল প্রয়োজন হয়, তবে ফ্লোর ডিভিশন ব্যবহার করা যেতে পারে। ফ্লোর ডিভিশন সর্বদা ভাগফলকে ঋণাত্মক অসীমের দিকে রাউন্ড করে, সমস্ত অপারেন্ডের জন্য একটি পূর্ণসংখ্যা ফলাফল নিশ্চিত করে।

~~~exercism/note
5.3 সংস্করণের আগে, Lua-তে ফ্লোর ডিভিশনের জন্য কোনো পাটিগণিত অপারেটর ছিল না।
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

ফ্লোর ডিভিশন যোগ, বিয়োগ, গুণ এবং ঋণাত্মককরণ অপারেটরগুলির মতো একই নিয়ম অনুসরণ করে, যদি উভয় অপারেন্ড ইন্টিজার হয় তবে অপারেশনের ফলাফল একটি ইন্টিজার হয়, অন্যথায় ফলাফল একটি ফ্লোট হয়।

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

ফ্লোর ডিভিশন ব্যবহার করে শূন্য দিয়ে ভাগ করলে, Lua একটি এরর উত্থাপন করবে।
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### মডুলো

দুটি অপারেন্ডের ভাগের ভাগশেষ পেতে মডুলো ব্যবহার করা হয়।
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### এক্সপোনেনশিয়েশন

ভাগের মতো, এক্সপোনেনশিয়েশনও ফ্লোটের উপর কাজ করে এবং ফলাফল হিসাবে ফ্লোট দেয়।
```lua
10 ^ 2    --> 100.0
```

## প্রেসিডেন্স

সমস্ত অপারেশন [অপারেটর প্রেসিডেন্স](https://www.lua.org/manual/5.4/manual.html#3.4.8) অনুসারে মূল্যায়ন করা হয়। একটি এক্সপ্রেশনের প্রেসিডেন্স পরিবর্তন করতে বন্ধনী ব্যবহার করা যেতে পারে।

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## রাউন্ডিং

`math` মডিউল তিনটি রাউন্ডিং ফাংশন প্রদান করে: `floor` "নিচের দিকে" (ঋণাত্মক অসীমের দিকে) রাউন্ড করে, `ceil` "উপরের দিকে" (ধনাত্মক অসীমের দিকে) রাউন্ড করে এবং `modf` শূন্যের দিকে রাউন্ড করে।

### `math.floor`

`floor` ঋণাত্মক অসীমের দিকে রাউন্ড করে।
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` ধনাত্মক অসীমের দিকে রাউন্ড করে।
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` শূন্যের দিকে রাউন্ড করে। ফাংশনটি রাউন্ডেড মান এবং সংখ্যাটির ভগ্নাংশ অংশ রিটার্ন করে, যা সর্বদা একটি ফ্লোট।
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## রূপান্তর

যদি আমরা একটি ইন্টিজারকে ফ্লোটে রূপান্তর করতে চাই, তবে আমরা এটিতে `0.0` যোগ করতে পারি।
```lua
1 + 0.0         --> 1.0
```

যদি আমরা একটি ফ্লোটকে ইন্টিজারে রূপান্তর করতে চাই, তবে আমরা এটিকে শূন্যের সাথে বিটওয়াইজ OR করতে পারি বা `math` মডিউলের `tointeger` ফাংশন ব্যবহার করতে পারি।
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

যদি সংখ্যাটিকে ইন্টিজারে রূপান্তর করা না যায় তবে OR অপারেটর একটি এরর উত্থাপন করবে এবং `tointeger` ফাংশন `nil` রিটার্ন করবে।
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## হেক্সাডেসিমাল

অনেক অন্যান্য প্রোগ্রামিং ভাষার মতো, Lua `0x` দিয়ে প্রিফিক্স করে হেক্সাডেসিমাল সংখ্যা সমর্থন করে, কিন্তু অনেক অন্যান্য প্রোগ্রামিং ভাষার বিপরীতে, Lua ফ্লোটিং-পয়েন্ট হেক্সাডেসিমাল সংখ্যাও সমর্থন করে। তাদের একটি ভগ্নাংশ অংশ এবং একটি বাইনারি সূচক থাকতে পারে, যা 'p' বা 'P' দিয়ে প্রিফিক্স করা হয়।
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
