# নির্দেশাবলি

আপনি একটি প্রজেক্টে কাজ করছেন, যেটি ব্যবহারকারীদের অন্য ব্যবহারকারীদের সাথে শেয়ার করার জন্য সার্ভারে ফাইল আপলোড করার সুযোগ দেয়। একটি আপলোড তার [মিডিয়া টাইপ][mimetype]-এর সাথে মেলে কি না, তা যাচাই করার জন্য একটি ফাংশন লেখার দায়িত্ব আপনাকে দেওয়া হয়েছে। আপনি একটু খোঁজ নিয়ে জানতে পারেন যে একটি ফাইলের প্রথম কয়েকটি বাইট সাধারণত ওই ফাইল টাইপের জন্যই অনন্য, যা এটিকে এক ধরনের সিগনেচার দেয়।

রেফারেন্সের জন্য নিচের টেবিলটি দেখুন:

| ফাইল টাইপ | কমন এক্সটেনশন | মিডিয়া টাইপ | বাইনারি 'সিগনেচার' |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. একটি এক্সটেনশন পেলে প্রত্যাশিত মিডিয়া টাইপ রিটার্ন করুন

`type_from_extension/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি ফাইল এক্সটেনশন (স্ট্রিং) নেবে এবং মিডিয়া টাইপ (স্ট্রিং) রিটার্ন করবে, অথবা এক্সটেনশনটি প্রত্যাশিতগুলোর সাথে না মিললে nil রিটার্ন করবে।

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. একটি বাইনারি ফাইল পেলে প্রত্যাশিত মিডিয়া টাইপ রিটার্ন করুন

`type_from_binary/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি ফাইল (বাইনারি) নেবে এবং মিডিয়া টাইপ (স্ট্রিং) রিটার্ন করবে, অথবা ফাইলের সিগনেচার প্রত্যাশিতগুলোর সাথে না মিললে nil রিটার্ন করবে।

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

ফাইলটিকে বাইনারি হিসেবে পড়া নিয়ে চিন্তা করবেন না। ধরে নিন যে সেটি আপনার জন্য করা হয়েছে এবং টেস্টগুলো এটি একটি আর্গুমেন্ট হিসেবে দিয়েছে।

## 3. একটি এক্সটেনশন ও একটি বাইনারি ফাইল পেলে ফাইলটি প্রত্যাশিত টাইপের সাথে মেলে কি না যাচাই করুন

`verify/2` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি ফাইল (বাইনারি) এবং একটি এক্সটেনশন (স্ট্রিং) নেবে এবং একটি `:ok` অথবা `:error` টাপল রিটার্ন করবে।

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
