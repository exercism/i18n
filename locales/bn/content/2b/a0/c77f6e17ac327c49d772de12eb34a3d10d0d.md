# নির্দেশনা

এই অনুশীলনীতে আপনি কারখানার কর্মীদের জন্য নেম ব্যাজ প্রিন্ট করার কোড লিখবেন।
কর্মীদের একটি ID, নাম এবং ডিপার্টমেন্টের নাম থাকে।
কর্মীদের ব্যাজের লেবেল নিচের মতো ফরম্যাট করা হয়: `"[id] - name - DEPARTMENT"`.

## 1. একজন কর্মীর জন্য একটি ব্যাজ প্রিন্ট করুন

`print_name_badge` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি একটি ID, একটি নাম এবং একটি ডিপার্টমেন্ট নেবে।
এটি ব্যাজের লেবেল রিটার্ন করবে, যেখানে ডিপার্টমেন্টের নাম বড় হাতের অক্ষরে থাকবে।

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. একজন নতুন কর্মীর জন্য একটি ব্যাজ প্রিন্ট করুন

কম্পিউটার সিস্টেমের একটি অদ্ভুত কারণে, নতুন কর্মীদের কারখানায় কাজ শুরু করার সময় মাঝে মাঝে এখনও ID থাকে না।
যেহেতু ব্যাজ বাধ্যতামূলক, তাই তারা ID প্রিফিক্স ছাড়া একটি অস্থায়ী ব্যাজ পাবে।

`print_name_badge` ফাংশনটি বাড়িয়ে লিখুন। id না থাকলে, এটি ছাড়াই একটি ব্যাজ প্রিন্ট করবে।

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. মালিকের জন্য একটি ব্যাজ প্রিন্ট করুন

এমনকি কারখানার মালিককেও সব সময় ব্যাজ পরে থাকতে হয়।
তবে, মালিকের কোনো ডিপার্টমেন্ট থাকে না এবং কখনও থাকবে না: তিনি সব ডিপার্টমেন্টের ঊর্ধ্বে।
এক্ষেত্রে, লেবেলে ডিপার্টমেন্টের নামের বদলে `"OWNER"` প্রিন্ট করা উচিত।

`print_name_badge` ফাংশনটি বাড়িয়ে লিখুন। ডিপার্টমেন্ট `NULL` হলে ধরে নিন ব্যাজটি কোম্পানির মালিকের।

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

মনে রাখবেন, মালিক নিজেও একজন নতুন কর্মী হতে পারেন।

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. যে কর্মীদের ID নেই তাদের মোট বেতন হিসাব করুন

ID কতটা ভালোভাবে দেওয়া হচ্ছে তার একটি মোটামুটি মাপকাঠি হিসেবে, আপনি ID নেই এমন কর্মীদের সম্মিলিত বেতন দেখতে চান।
বেশি মানে অনেকেই অপেক্ষায়, অথবা সমস্যাটি সিনিয়র কর্মীদের প্রভাবিত করছে: দুটোই খারাপ।

`salaries_no_id` ফাংশনটি ইমপ্লিমেন্ট করুন, যা ID-এর একটি ভেক্টর এবং বেতনের একটি সংশ্লিষ্ট ভেক্টর নেয় এবং যাদের এখনও ID নেই তাদের বেতনের যোগফল রিটার্ন করে।
দুটি ভেক্টরের দৈর্ঘ্যই একই।

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_পরীক্ষা না করা একটি অতিরিক্ত শেখার জন্য:_ যদি ID নেই এমন কোনো কর্মী না থাকে, তাহলে যে "খালি ভেক্টর"টি আপনি যোগ করছেন সেটি কী?
