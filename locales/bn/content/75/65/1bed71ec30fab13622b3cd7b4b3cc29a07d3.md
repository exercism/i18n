# Entry API

ম্যাপ স্ট্রাকচারের ভেতরের উপাদান নাড়াচাড়া করার সবচেয়ে স্বাভাবিক উপায় সাধারণত Entry API। তবে Rust-এর ক্ষেত্রে এটি ব্যতিক্রমী: এটিকে কোনো ট্রেইটে আনুষ্ঠানিক রূপ দেওয়া হয়নি। এটি আসলে স্ট্যান্ডার্ড লাইব্রেরির ম্যাপ টাইপগুলোর উপর ইমপ্লিমেন্ট করা কিছু টাইপ ও মেথডের সমষ্টি।

মূলত, `map.entry()` মেথডটি একটি `enum` দেয়:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

এর কাজের সুবিধা আসে ওই এনামের উপর ইমপ্লিমেন্ট করা আরও কিছু মেথড থেকে। যেমন, আপনি যদি কোনো নির্দিষ্ট কী (key)-এর মান নিতে চান এবং প্রয়োজনে সেটি পরিবর্তনও করতে চান, আর মানের টাইপের ডিফল্ট মানটি আপনার কাজে লাগে, তাহলে শুধু এভাবে লিখলেই হয়:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

কাউন্টারের মতো কাজে এটি জীবন অনেক সহজ করে দেয়:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

টাইপের ডিফল্ট মানটি যদি আপনার কাজে না লাগে, তাহলে `or_insert` দিয়ে নিজের একটি ধ্রুবক ডিফল্ট দিতে পারেন, অথবা `or_insert_with` দিয়ে একটি মান হিসাব করে বের করতে পারেন।

কিছু ক্ষেত্রে, সম্ভাব্য ইনসার্টের আগে আপনি হয়তো কোনো বিদ্যমান মানের উপর একটি হিসাব করতে চাইবেন। সেসব ক্ষেত্রে `and_modify` এটির সুযোগ দেয়। তবে এভাবে ব্যবহার তুলনামূলক বিরল। ডিরেফারেন্স করার প্রয়োজন এড়াতে `and_modify` বেশি ব্যবহৃত হয়:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

মাঝে মাঝে Entry-টি সরাসরি ম্যাচ করা সুবিধাজনক। এটি করা বৈধ:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

আরও তথ্যের জন্য দেখুন [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) এবং [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html)।
