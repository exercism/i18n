# ম্যাচ এক্সপ্রেশন

একটি ম্যাচ এক্সপ্রেশন একটি মান ও একটি শর্ত মূল্যায়ন করে, যাতে মূল্যায়ন করার জন্য একটি এক্সপ্রেশন রিটার্ন করা যায়। টার্নারির মতোই, শর্তটি মিলে না গেলে রিটার্ন এক্সপ্রেশনটি মূল্যায়ন করা হয় না। শর্ত মেলাতে একটি আইডেন্টিটি (কঠোর সমতা বা `===`) যাচাই করা হয়।

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

সমতা [`==`] যাচাই করতে চাইলে শর্তটি অন্যভাবে সাজাতে পারেন:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

একটি ম্যাচ এক্সপ্রেশনে কোনো শর্ত মিলে না গেলে একটি `UnhandledMatchError` থ্রো করা হবে।
