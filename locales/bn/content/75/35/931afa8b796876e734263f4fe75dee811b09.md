# নির্দেশনা

যেকোনো দুটি অ্যারে `A` ও `B` দেওয়া থাকলে নির্ণয় করুন যে:

- অ্যারে `A` ও অ্যারে `B` সমান; অথবা
- অ্যারে `A`, অ্যারে `B` ধারণ করে (`A` হলো `B`-এর সুপার-অ্যারে); অথবা
- অ্যারে `B`, অ্যারে `A` ধারণ করে (`A` হলো `B`-এর উপ-অ্যারে); অথবা
- উপরের কোনোটিই সত্য নয়, অর্থাৎ অ্যারে `A` ও `B` অসমান

নির্দিষ্টভাবে বলতে গেলে, অ্যারে `A` ও অ্যারে `B` সমান হয় যদি দুটি অ্যারেতেই একই ক্রমে একই মান থাকে।
অ্যারে `A`, `B`-এর সুপার-অ্যারে হয় যদি `A`-তে `B`-এর সমান মানের একটি উপক্রম থাকে।
অ্যারে `A`, `B`-এর উপ-অ্যারে হয় যদি `B`-তে `A`-এর সমান মানের একটি উপক্রম থাকে।

উদাহরণ:

- যদি `A = []` ও `B = []` হয় (দুটি অ্যারেই খালি), তাহলে `A` ও `B` সমান
- যদি `A = [1, 2, 3]` ও `B = []` হয়, তাহলে `A` হলো `B`-এর সুপার-অ্যারে
- যদি `A = []` ও `B = [1, 2, 3]` হয়, তাহলে `A` হলো `B`-এর উপ-অ্যারে
- যদি `A = [1, 2, 3]` ও `B = [1, 2, 3, 4, 5]` হয়, তাহলে `A` হলো `B`-এর উপ-অ্যারে
- যদি `A = [3, 4, 5]` ও `B = [1, 2, 3, 4, 5]` হয়, তাহলে `A` হলো `B`-এর উপ-অ্যারে
- যদি `A = [3, 4]` ও `B = [1, 2, 3, 4, 5]` হয়, তাহলে `A` হলো `B`-এর উপ-অ্যারে
- যদি `A = [1, 2, 3]` ও `B = [1, 2, 3]` হয়, তাহলে `A` ও `B` সমান
- যদি `A = [1, 2, 3, 4, 5]` ও `B = [2, 3, 4]` হয়, তাহলে `A` হলো `B`-এর সুপার-অ্যারে
- যদি `A = [1, 2, 4]` ও `B = [1, 2, 3, 4, 5]` হয়, তাহলে `A` ও `B` অসমান
- যদি `A = [1, 2, 3]` ও `B = [1, 3, 2]` হয়, তাহলে `A` ও `B` অসমান
