# নির্দেশনা

কন্ডা এয়ারলাইনস প্রোগ্রামিং জগতের সবচেয়ে বড় এয়ারলাইন, দিনে ১০,০০০-এরও বেশি ফ্লাইট চলে!

এখন তারা হাতে করে সব সিট যাত্রীদের মধ্যে অ্যাসাইন করছেন; এটিকে স্বয়ংক্রিয় করতে হবে।

তারা _আপনাকে_ এমন একটি সফটওয়্যার তৈরি করতে বলেছে, যা যাত্রীদের সিট অ্যাসাইনমেন্ট স্বয়ংক্রিয় করবে।
তাদের চাওয়া, আপনার সফটওয়্যার হবে মেমরি সাশ্রয়ী ও পারফরম্যান্ট।

## 1. সিট লেটার জেনারেট করুন

কন্ডা তাদের বিমানের জন্য সিট লেটার জেনারেট করতে চায়।
একটি বিমান সারি সারি সিট দিয়ে তৈরি।
প্রতিটি সারিতে _৪টি সিট_ থাকে।
প্রতিটি সারির সিটগুলোর নাম সবসময় `A`, `B`, `C` এবং `D`।
সারির প্রথম সিটটি `A`, দ্বিতীয়টি `B`, এভাবেই চলতে থাকে।
`D`-তে পৌঁছানোর পর আবার `A` দিয়ে শুরু হবে।

এমন একটি ফাংশন `generate_seat_letters(<number>)` ইমপ্লিমেন্ট করুন, যা একটি `int` নেয় যাতে থাকে কতটি সিট লেটার জেনারেট করতে হবে।
এরপর ফাংশনটি সিট লেটারগুলোর একটি _ইটারেবল_ রিটার্ন করবে।

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. সিট জেনারেট করুন

কন্ডা এমন একটি সিস্টেম চায়, যা তাদের বিমানের জন্য নির্দিষ্ট সংখ্যক সিট জেনারেট করতে পারে।
প্রতিটি বিমানের প্রতিটি সারিতে _৪টি সিট_ থাকে।
সারিগুলো সংখ্যা দিয়ে চিহ্নিত হয়, `1` থেকে শুরু করে ক্রমশ বাড়তে থাকে।
সিটগুলো এভাবে সাজানো থাকবে: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

এখানে একটি উদাহরণ:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     সারি     |  5  | 21  |
| সিট লেটার |  A  |  D  |
|   ফলাফল   | 5A  | 21D |

যাত্রীদের কুসংস্কারের কারণে বহু এয়ারলাইন তাদের ফ্লাইটে _সারি_ নম্বর ১৩ রাখে না।
কন্ডা এয়ারলাইনসও এই রীতি মেনে চলে, তাই খেয়াল রাখুন, _সারি_ নম্বর ১৩-এর জন্য সিট জেনারেট করবেন _না_।

এমন একটি ফাংশন `generate_seats(<number>)` ইমপ্লিমেন্ট করুন, যা একটি `int` নেয় যাতে থাকে কতটি সিট জেনারেট করতে হবে।
এরপর ফাংশনটি প্রদত্ত সিটগুলোর একটি _ইটারেবল_ রিটার্ন করবে।

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. যাত্রীদের সিট অ্যাসাইন করুন

এখন যেহেতু সিট জেনারেট করার একটি ফাংশন আপনার কাছে আছে, এটি দিয়েই আপনি যাত্রীদের সিট অ্যাসাইন করতে পারেন।

এমন একটি ফাংশন `assign_seats(<passengers>)` ইমপ্লিমেন্ট করুন, যা যাত্রীদের নামের একটি `list` নেয়।
এরপর ফাংশনটি একটি _ডিকশনারি_ রিটার্ন করবে, যেখানে `passenger` থাকে _কী (key)_ হিসেবে এবং `seat_number` থাকে _মান_ হিসেবে।

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. টিকিট কোড

কন্ডা এয়ারলাইনস প্রতিটি টিকিটের জন্য একটি অনন্য কোড চায়।
যেহেতু তারা একটি বড় এয়ারলাইন, তাদের অনেক ফ্লাইট আছে।
এর মানে, একই সিট নম্বরের একাধিক ফ্লাইট থাকতে পারে।
তারা চায় আপনি এমন একটি সিস্টেম তৈরি করুন, যা একটি অনন্য টিকিট গঠন করে, আর সেই টিকিটটি _১২_ ক্যারেক্টার লম্বা একটি স্ট্রিং।

এই কোডটি শুরু হয় `assigned_seat` দিয়ে, আর তার পরেই থাকে `flight_id`।
কোডের বাকি অংশ `0s` দিয়ে ভরাট করা হয়।

এমন একটি ফাংশন `generate_codes(<seat_numbers>, <flight_id>)` ইমপ্লিমেন্ট করুন, যা `seat_numbers`-এর একটি `list` এবং ফ্লাইট নম্বরসহ একটি `string` নেয়।
এরপর ফাংশনটি একটি `generator` রিটার্ন করবে, যা একটি `ticket_number` দেয়।

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
