# অ্যারের পরিচিতি

Java-তে অ্যারে হলো একই টাইপের একাধিক মান একটি স্ট্রাকচারে সংরক্ষণ করার একটি উপায়। অন্য ডেটা স্ট্রাকচারের বিপরীতে, অ্যারে একবার তৈরি হয়ে গেলে এর আকার নির্দিষ্ট থাকে। ইনডেক্স ব্যবহার করে অ্যারের এলিমেন্টগুলো অ্যাসাইন করা যায় বা অ্যারে থেকে অ্যাক্সেস করা যায়। Java অ্যারে জিরো-বেজড ইনডেক্সিং ব্যবহার করে: প্রথম এলিমেন্টের ইনডেক্স 0, দ্বিতীয় এলিমেন্টের ইনডেক্স 1, ইত্যাদি।

এটি একটি অ্যারে ইনিশিয়ালাইজ করার স্ট্যান্ডার্ড সিনট্যাক্স:

```java
type[] variableName = new type[size];
```

`type` হলো অ্যারের এলিমেন্টগুলোর টাইপ, যা একটি প্রিমিটিভ টাইপ (যেমন `int`) অথবা একটি ক্লাস (যেমন `String`) হতে পারে।

`size` হলো এই অ্যারেতে থাকা এলিমেন্টের সংখ্যা (যা পরে পরিবর্তন করা যায় না)। অ্যারে তৈরি হওয়ার পর, এলিমেন্টগুলো তাদের ডিফল্ট মান দিয়ে ইনিশিয়ালাইজ করা হয় (সাধারণত `0`, `false` বা `null`)।

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

অ্যারে শর্টকাট নোটেশন ব্যবহার করেও ডিফাইন করা যায়, যা দিয়ে একই সাথে অ্যারে তৈরি করা এবং তার মান সেট করা যায়:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

যেহেতু কম্পাইলার এখন বলতে পারে অ্যারেতে কতগুলো এলিমেন্ট থাকবে, তাই দৈর্ঘ্য বাদ দেওয়া যায়।

বন্ধনীযুক্ত ইনডেক্স নোটেশন ব্যবহার করে অ্যারের এলিমেন্টগুলো অ্যাসাইন ও অ্যাক্সেস করা যায়:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

অ্যারের বৈধ ইনডেক্সের বাইরের কোনো ইনডেক্স অ্যাক্সেস করলে `IndexOutOfBoundsException` হয়।

অ্যারে ম্যানিপুলেট করা যায় হয় অ্যারে ইনস্ট্যান্সের মেথড বা প্রপার্টি কল করে, অথবা `Arrays` ক্লাসে ডিফাইন করা স্ট্যাটিক মেথড ব্যবহার করে (সাধারণত শুধু জেনেরিক কোডে ব্যবহৃত হয়)। `length` প্রপার্টি অ্যারের দৈর্ঘ্য ধারণ করে। এটি এভাবে অ্যাক্সেস করা যায়:

```java
int arrayLength = someArray.length;
```

Java আরও একটি সহায়ক ইউটিলিটি ক্লাস [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) দেয়, যেখানে অ্যারে-সম্পর্কিত অনেক কাজের মেথড আছে (যেমন `Arrays.equals`)।

Java [বহুমাত্রিক অ্যারে](https://www.programiz.com/java-programming/multidimensional-array) যেমন `int[][] arr = new int[3][4];` সমর্থন করে, যা খুব উপকারী হতে পারে।

অ্যারে আসলে একটি _কালেকশন_ হওয়ার কারণে, ইনডেক্স দিয়ে মান অ্যাক্সেস করার পাশাপাশি `for-each` লুপ ব্যবহার করে এর _সব_ মানের উপর ইটারেট করতে পারেন:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

কোন মানগুলোর উপর ইটারেট করবেন সেটির উপর আরও নিয়ন্ত্রণ চাইলে, একটি `for` লুপ ব্যবহার করা যায়:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
