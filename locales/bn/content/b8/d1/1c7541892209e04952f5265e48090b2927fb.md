# নির্দেশনার সংযোজন

## ইঙ্গিত

Sgf মডিউলটির নিচের সিগনেচার-সহ একটি parseSgf মডিউল এক্সপোর্ট করা উচিত:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

SgfTree আর SgfNode-এর নিচের ডেফিনিশনগুলো কপি করে রাখলে আপনার কাজে লাগতে পারে:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

parsec লাইব্রেরিটি Haskell Platform-এর অংশ। আপনার সুবিধার জন্য এটি ব্যবহার করুন।
