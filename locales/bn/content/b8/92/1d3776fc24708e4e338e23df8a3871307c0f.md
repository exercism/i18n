# পরিচিতি

## ট্রু এবং ফলস

রুবিতে ট্রু আর ফলস যৌক্তিক অবস্থা `true` এবং `false` দিয়ে প্রকাশ করা হয়। এগুলো একা লিটারেল হিসেবেও ব্যবহার করা যায়, আবার কোনো যৌক্তিক বা তুলনা মেথডের ফলাফল হিসেবেও।

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _ট্রুথি_ এবং _ফলসি_

`if` স্টেটমেন্ট বা অন্য বুলিয়ান প্রেক্ষাপটে অবজেক্ট মূল্যায়ন করার সময় `false` এবং `nil` ছাড়া বাকি সব অবজেক্টই _ট্রুথি_ হিসেবে গণ্য হয়।

## কন্ট্রোল ফ্লো

কন্ট্রোল ফ্লোর ক্ষেত্রে _ট্রুথি_ আর _ফলসি_ মূল্যায়ন বেশ কাজে লাগে। প্রোসিডিউরাল ভাষার মতো রুবিতেও `if`...`else` গঠন আছে, তবে এক্সপ্রেশনের মূল্যায়ন বদলাতে `if`-কে "গার্ডিং" স্টেটমেন্ট হিসেবে ব্যবহার করাই বেশি দেখা যায়।

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

কোড যাতে সহজে পড়া যায়, সেজন্য রুবি `unless` দেয়।
যেমন, `eat_desert if not too_full` না লিখে আমরা `eat_desert unless too_full`-ও লিখতে পারি।

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
