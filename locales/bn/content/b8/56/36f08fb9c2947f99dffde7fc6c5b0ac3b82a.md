# পরিচিতি

অনেক স্ট্যাটিকালি টাইপড ভাষার মতো C#-ও ইন্টিজার ধরে রাখার জন্য বেশ কিছু টাইপ দেয়, যার প্রতিটির নিজস্ব মান-পরিসর আছে। একদম নিচের দিকে `sbyte` টাইপের সর্বনিম্ন মান -128 আর সর্বোচ্চ মান 127. সব ইন্টিজার টাইপের মতোই এই মানগুলো `<type>.MinValue` আর `<type>.MaxValue` হিসেবে পাওয়া যায়। আর একদম উপরের দিকে `long` টাইপের সর্বনিম্ন মান -9,223,372,036,854,775,808 আর সর্বোচ্চ মান 9,223,372,036,854,775,807. এই দুইয়ের মাঝখানে আছে `short` আর `int` টাইপ।

পরিসর নির্ধারিত হয় সিস্টেম টাইপটির জন্য যে স্টোরেজ প্রস্থ বরাদ্দ করে তার দ্বারা। যেমন একটি `byte` ব্যবহার করে ৮ বিট, আর একটি `long` ব্যবহার করে ৬৪ বিট।

উপরের প্রতিটি টাইপের সঙ্গেই আছে একটি করে আনসাইনড সমতুল্য টাইপ: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` এবং `long`/`ulong`। সর্বক্ষেত্রেই মানের পরিসর 0 থেকে শুরু করে সাইনড টাইপের ঋণাত্মক সর্বোচ্চ মানকে 2 দিয়ে গুণ করে 1 যোগ করলে যা হয়, সেটি পর্যন্ত।

| টাইপ   | প্রস্থ  | সর্বনিম্ন                    | সর্বোচ্চ                     |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | ৮ বিট  | -128                       | +127                        |
| short  | ১৬ বিট | -32_768                    | +32_767                     |
| int    | ৩২ বিট | -2_147_483_648             | +2_147_483_647              |
| long   | ৬৪ বিট | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | ৮ বিট  | 0                          | +255                        |
| ushort | ১৬ বিট | 0                          | +65_535                     |
| uint   | ৩২ বিট | 0                          | +4_294_967_295              |
| ulong  | ৬৪ বিট | 0                          | +18_446_744_073_709_551_615 |

এক টাইপের একটি ভ্যারিয়েবল (বা এক্সপ্রেশন) সহজেই অন্য টাইপে রূপান্তর করা যায়। যেমন একটি অ্যাসাইনমেন্ট অপারেশনে, যদি যে মানটি অ্যাসাইন করা হচ্ছে তার টাইপ (lhs) নিশ্চিত করে যে মানটি যে টাইপে অ্যাসাইন করা হচ্ছে (rhs) তার পরিসরের মধ্যে পড়বে, তাহলে সেটি একটি সরল অ্যাসাইনমেন্ট:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

অন্যদিকে, যদি যে টাইপ থেকে মানটি অ্যাসাইন করা হচ্ছে তার পরিসর অ্যাসাইনি টাইপের মানের পরিসরের উপসেট না হয়, তাহলে ওই নির্দিষ্ট মানটি অ্যাসাইনি টাইপের পরিসরের মধ্যে থাকলেও একটি কাস্ট, অর্থাৎ `()` অপারেশন লাগে:

```csharp
short s = 42;
uint ui = (uint)s;
```

## বিট কনভার্সন

`BitConverter` ক্লাসটি ইন্টিজার টাইপকে বাইটের অ্যারেতে এবং বাইটের অ্যারে থেকে ইন্টিজার টাইপে রূপান্তর করার একটি সুবিধাজনক উপায় দেয়।
