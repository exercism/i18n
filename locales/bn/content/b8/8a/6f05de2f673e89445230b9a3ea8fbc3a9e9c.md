# পরিচিতি

[রেঞ্জ][range] দুটি মানের মধ্যবর্তী একটি ব্যবধান উপস্থাপন করে। `Int`, `String` ও `Character`-এর মতো টাইপের সাথে রেঞ্জের ব্যবহার কমন, যেমন সিকোয়েন্সের উপর ইটারেশন করা, কালেকশন স্লাইস করা, বা কোনো মান নির্ধারিত সীমার মধ্যে পড়ে কি না তা যাচাই করা।

Swift-এ দুটি প্রধান রেঞ্জ অপারেটর আছে:

- **ক্লোজড রেঞ্জ অপারেটর (`...`)**: শুরু ও শেষ, দুটি মানই অন্তর্ভুক্ত করে (`1...5`-এ 1, 2, 3, 4 ও 5 অন্তর্ভুক্ত)।
- **হাফ-ওপেন রেঞ্জ অপারেটর (`..<`)**: শুরুর মান অন্তর্ভুক্ত করে কিন্তু শেষের মান অন্তর্ভুক্ত করে না (`1..<5`-এ 1, 2, 3 ও 4 অন্তর্ভুক্ত)।

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
কোনো রেঞ্জ লিটারালের উপর সরাসরি মেথড কল করার সময়, রেঞ্জ এক্সপ্রেশনটি বন্ধনীর মধ্যে মুড়ে দিন, যাতে কম্পাইলার প্রথমে রেঞ্জটি ইভ্যালুয়েট করে:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```

## একটি রেঞ্জকে অ্যারেতে রূপান্তর

`Array(_:)` ইনিশিয়ালাইজার ব্যবহার করে সংখ্যার একটি রেঞ্জকে `Array`-এ রূপান্তর করা যায়:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## রেঞ্জ দিয়ে একটি অ্যারে স্লাইস করা

অ্যারের উপ-অংশ স্লাইস করতে রেঞ্জ ব্যবহার করা যায়:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## রেঞ্জের প্রপার্টি ও মেথড

রেঞ্জের কমন অপারেশনগুলোর মধ্যে রয়েছে:

| মেম্বার                  | বর্ণনা                                                | উদাহরণ                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | রেঞ্জে থাকা এলিমেন্টের সংখ্যা রিটার্ন করে                | `(1...5).count` রিটার্ন করে `5`          |
| [`contains(_:)`][contains] | রেঞ্জটি নির্দিষ্ট মানটি অন্তর্ভুক্ত করলে `true` রিটার্ন করে | `(1...5).contains(3)` রিটার্ন করে `true` |

## একতরফা রেঞ্জ

Swift একতরফা (আংশিক) রেঞ্জও সমর্থন করে, যেখানে আপনি শুরুর বা শেষের মান যেকোনো একটি বাদ দেন:

- `array[2...]`: ইনডেক্স 2 থেকে কালেকশনের শেষ পর্যন্ত।
- `array[...2]`: কালেকশনের শুরু থেকে ইনডেক্স 2 পর্যন্ত (2 সহ)।
- `array[..<2]`: কালেকশনের শুরু থেকে ইনডেক্স 2 পর্যন্ত (তবে 2 বাদ দিয়ে)।

## স্ট্রিং ও ক্যারেক্টার রেঞ্জ

`Comparable` মেনে চলে এমন ক্যারেক্টার বা স্ট্রিংয়ের মধ্যেও রেঞ্জ তৈরি করা যায়:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
