# ভূমিকা

## Julia-তে বুলিয়ান

ট্রু বা ফলস মান `Bool` টাইপ দিয়ে প্রকাশ করা হয়। এতে মাত্র দুটি মান থাকে: `true` আর `false`।

```julia-repl
julia> true
true

julia> false
false
```

## বুলিয়ান অপারেটর

Julia-তে তিনটি বুলিয়ান অপারেটর আছে।

`&&` হলো বুলিয়ান “এবং”। `&&`-এর *দুই* দিকের এক্সপ্রেশনই `true` হলে এর ফলাফল `true` হয়।

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` হলো বুলিয়ান “অথবা”। `||`-এর *যেকোনো* এক দিকের এক্সপ্রেশন `true` হলে এর ফলাফল `true` হয়।

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` হলো বুলিয়ান “নয়”। এটি `true` আর `false` মান পরস্পরের সঙ্গে বদলে দেয়।

```julia-repl
julia> !true
false

julia> !false
true
```

বড় ও আরও জটিল এক্সপ্রেশনের জন্য আপনার উদ্দেশ্য স্পষ্ট রাখতে বন্ধনী ব্যবহার করাই ভালো।

```julia-repl
julia> (true || false) && (false && true)
false
```
