# শর্তাধীনতা

Crystal-এ কন্ট্রোল এক্সপ্রেশন নামে পরিচিত জিনিস রয়েছে, এগুলো দিয়ে প্রোগ্রাম কীভাবে চলবে তা নিয়ন্ত্রণ করা হয় এবং এগুলো একটি ট্রুথি বা ফলসি মান নেয়।
কিছু অপারেটর আছে যেগুলো দিয়ে ট্রুথি বা ফলসি মান তৈরি করা যায়, এগুলোকে [সমতা ও তুলনা অপারেটর][equality-and-comparison] বলা হয়।

দুটি প্রধান কন্ট্রোল এক্সপ্রেশন আছে যেগুলো দিয়ে নিয়ন্ত্রণ করা হয় কোন কোডটি চলবে আর কোনটি চলবে না।
অর্থাৎ কোন নির্দিষ্ট শাখাটি চলবে তাও এগুলোই ঠিক করে।

এই দুটি হলো: `if` এবং `unless` এক্সপ্রেশন।

## তুলনা অপারেটর

তুলনা অপারেটর দিয়ে মানগুলো তুলনা করা হয় এবং একটি `true` বা `false` মান রিটার্ন করা হয়।
এই অপারেটরগুলো দিয়ে তুলনা করতে একই টাইপের দুটি মান লাগে।
মানগুলো একই টাইপের না হলে কম্পাইলার একটি এরর দেবে।
এখানে তুলনা অপারেটরগুলোর একটি তালিকা আর কখন সেগুলো `true` মান দেয় তার একটি উদাহরণ দেওয়া হলো:

| Method | Description           | Example |
| ------ | --------------------- | ------- |
| <      | less than             | 4 < 5   |
| <=     | less than or equal    | 4 <= 4  |
| >      | greater than          | 3 > 1   |
| >=     | greater than or equal | 2 >= 2  |

## সমতা অপারেটর

সমতা অপারেটর তুলনা অপারেটরের মতোই, তবে এগুলো দিয়ে পরীক্ষা করা হয় দুটি মান সমান কি না।

`==` অপারেটর পরীক্ষা করে দুটি মান সমান কি না, মানের টাইপসহ।
মান দুটি একই হলে এটি `true` রিটার্ন করে, নাহলে `false` রিটার্ন করে।
`==` অপারেটর যেকোনো টাইপের মানের সাথে যেকোনো টাইপের মান তুলনা করতে পারে।
`!=` একইভাবে কাজ করে, তবে মানগুলো অসমান হলে `true` আর সমান হলে `false` রিটার্ন করে।

## `if` স্টেটমেন্ট

[`if`][if] স্টেটমেন্ট দিয়ে পরীক্ষা করা হয় একটি নির্দিষ্ট শর্ত ট্রুথি কি ফলসি।
শর্তটি ট্রুথি হলে `if` স্টেটমেন্টের ভেতরের কোডটি চলবে।
একটি `if` স্টেটমেন্ট `end` কিওয়ার্ড দিয়ে শেষ হয়।

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## `unless` স্টেটমেন্ট

[`unless`][unless] স্টেটমেন্ট `if` স্টেটমেন্টের মতোই কাজ করে, তবে শর্তটি ফলসি হলে এটি `unless` স্টেটমেন্টের ভেতরের কোডটি চালায়।

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## `else` স্টেটমেন্ট

`else` স্টেটমেন্ট `if` ও `unless` স্টেটমেন্টের সাথে একসাথে ব্যবহার করা যায়।
`if` শাখা বা `unless` শাখা চালানো না হলে `else` স্টেটমেন্ট চালানো হবে।

~~~~exercism/warning
এমনকি `unless,`-এর সঙ্গেও একটি `else` শাখা ব্যবহার করা গেলেও, তা করতে নিরুৎসাহিত করা হয় কারণ এতে পড়ার সহজতা নষ্ট হয়।
বরং `else` শাখাসহ `if !condition` ব্যবহার করার পরামর্শ দেওয়া হয়।
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## "ক্যাসকেডিং-if" স্টেটমেন্ট

`elsif` স্টেটমেন্ট if স্টেটমেন্টের সাথে একসাথে ব্যবহার করা যায়।
if শাখাটি চালানো না হলে এবং `elsif` স্টেটমেন্টের শর্তটি ট্রুথি হলে `elsif` স্টেটমেন্ট চালানো হবে।
`elsif` স্টেটমেন্টগুলো একসাথে শৃঙ্খলাবদ্ধ করা যায় এবং প্রথম ট্রুথি শর্তটিই চালানো হবে।
if স্টেটমেন্টের শেষে একটি else স্টেটমেন্টও থাকতে পারে, যা তখনই চলবে যখন এর আগের কোনো স্টেটমেন্টই সত্য হয়নি।

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## শর্তের সাথে টাইপ

ভিন্ন টাইপের মান অ্যাসাইন করা হলে, ভ্যারিয়েবলটি দুটি টাইপই বহন করে।
এর কারণ, কম্পাইলার জানে না কোন শাখাটি চালানো হবে।
এই একাধিক অ্যাসাইনমেন্ট, যা ইউনিয়ন নামেও পরিচিত, পরের ধারণাগুলোতে ব্যাখ্যা করা হবে।
এটি নিচের উদাহরণে দেখা যায়:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```

## টার্নারি অপারেটর

Crystal-এ একটি টার্নারি অপারেটর আছে, যা এক লাইনের if-else স্টেটমেন্ট: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```
