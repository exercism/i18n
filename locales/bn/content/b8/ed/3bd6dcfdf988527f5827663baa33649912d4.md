# পরিচিতি

কখনও কখনও স্টেটসহ একটি অবজেক্ট তৈরি করার ওভারহেড আপনার দরকার হয় না।
এমন ক্ষেত্রে একটি `module` ব্যবহার করা যেতে পারে।

একটি মডিউল একটি ক্লাসের সঙ্গে অনেকটাই মিল (আসলে, অবজেক্ট হায়ারার্কিতে `Module` হল `Classes`-এর প্যারেন্ট)। মূল পার্থক্য হলো, ইন্সট্যান্স মেথড ব্যবহার না করে আমরা ক্লাস মেথড ব্যবহার করি।
ক্লাস মেথড `self.` দিয়ে শুরু হয় এবং সরাসরি একটি মডিউলের উপর কল করা হয়।

উদাহরণস্বরূপ:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
