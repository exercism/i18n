# রেঞ্জ

[রেঞ্জ][range] দুটি মানের মধ্যবর্তী একটি ব্যবধান বোঝায়।
রেঞ্জ সাপোর্ট করে এমন সবচেয়ে কমন টাইপগুলো হলো `Int`, `Char` এবং `String`.
এগুলো অনেক কাজে ব্যবহার করা যায়, যেমন দ্রুত একটি কালেকশন তৈরি করা, স্ট্রিং স্লাইস করা, কোনো মান রেঞ্জের মধ্যে আছে কি না তা যাচাই করা, এবং ইটারেশন।
এগুলো রেঞ্জ অপারেটর `..` বা `...` দিয়ে তৈরি করা হয় (যথাক্রমে অন্তর্ভুক্তিমূলক ও বর্জনমূলক)।

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

দুটি রেঞ্জ অপারেটর থাকার কারণ হলো এমন রেঞ্জ তৈরি করা, যা শেষ মানটিকে অন্তর্ভুক্ত করে বা বাদ দেয়, এবং এটি কাজে লাগে যখন, উদাহরণস্বরূপ, শূন্য-ভিত্তিক ইনডেক্স নিয়ে কাজ করা হয়।

`Range` ইনিশিয়ালাইজার দিয়েও রেঞ্জ তৈরি করা যায়।

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystal-এ রেঞ্জ অপারেটর `..` বা `...` দিয়ে রেঞ্জ তৈরি করার সময় যদি আপনি রেঞ্জের উপর কোনো মেথড কল করতে চান, তাহলে রেঞ্জটিকে বন্ধনীর মধ্যে রাখতে হবে।
কারণ অন্যথায় মেথডটি রেঞ্জ অপারেটরের দ্বিতীয় আর্গুমেন্টের উপর কল করা হবে।

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## সাবস্ট্রিং পাওয়া

একটি স্ট্রিং স্লাইস করতে চাইলে, সাবস্ট্রিং পেতে আপনি রেঞ্জ অপারেটর ব্যবহার করতে পারেন।
অর্থাৎ, সাবস্ট্রিংয়ের শুরুর ও শেষ ইনডেক্স দিয়ে একটি রেঞ্জ তৈরি করে।

স্ট্রিংয়ের শেষ থেকে সাবস্ট্রিং পেতে ঋণাত্মক ইনডেক্সও ব্যবহার করতে পারেন।

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

আরও কিছু সাবস্ট্রিং পাওয়ার জন্য আপনি ঋণাত্মক ইনডেক্স ব্যবহার করতে পারেন।

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## রেঞ্জের মেথড

রেঞ্জের সাথে কাজ করার জন্য রেঞ্জের কিছু মেথড আছে।
উদাহরণস্বরূপ, এই মেথডগুলো দিয়ে রেঞ্জের সব মানের যোগফল বের করা যায় বা রেঞ্জে কোনো মান আছে কি না তা যাচাই করা যায়।

| মেথড                    | বর্ণনা                                                                   | উদাহরণ                          |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | রেঞ্জের সব মানের যোগফল রিটার্ন করে                                      | `(1..5).sum # => 15`            |
| [`size`][size]          | রেঞ্জের আকার রিটার্ন করে                                                | `(1..5).size # => 5`            |
| [`includes?`][indludes] | রেঞ্জে প্রদত্ত মানটি থাকলে `true` রিটার্ন করে, অন্যথায় `false`          | `(1..5).includes?(3) # => true` |

## অন্তহীন ও শুরুবিহীন রেঞ্জ

একটি রেঞ্জ অন্তহীন বা শুরুবিহীন হতে পারে।
অন্তহীন বা শুরুবিহীন রেঞ্জের শুরু বা শেষ মান থাকে `nil`, তবে রেঞ্জ ডিফাইন করার সময় `nil` বাদ দেওয়া যায়।

শুরুবিহীন ও অন্তহীন রেঞ্জ কাজে লাগে যখন আপনি চান, উদাহরণস্বরূপ, স্ট্রিংয়ের শুরু থেকে বা শেষ পর্যন্ত স্লাইস করতে।

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
কোনো কালেকশনের উপর ব্যবহার করা না হলে, সতর্কতার সাথে ব্যবহার না করলে অন্তহীন রেঞ্জ একটি অন্তহীন সিকোয়েন্স তৈরি করতে পারে।
~~~~

## Char রেঞ্জ

রেঞ্জে Char ব্যবহার করা যায় এবং দুটি Char-এর মধ্যবর্তী Char-এর একটি ব্যবধান পেতে দেয়।
উদাহরণস্বরূপ, বর্ণমালা পেতে চাইলে এটি কাজে লাগতে পারে।

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## String রেঞ্জ

স্ট্রিংও রেঞ্জে ব্যবহার করা যায়, যা দিয়ে দুটি স্ট্রিংয়ের মধ্যবর্তী স্ট্রিংয়ের একটি ব্যবধান পাওয়া যায়।
তবে স্ট্রিং রেঞ্জে একাধিক ক্যারেক্টার ব্যবহার করলে এর আচরণ `Char`-এর থেকে সামান্য আলাদা।
আরও জটিল স্ট্রিং রেঞ্জ নিয়ে কাজ করলে এর আচরণ বিভ্রান্তিকর হয়ে উঠতে পারে, তাই সতর্ক থাকুন।

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
