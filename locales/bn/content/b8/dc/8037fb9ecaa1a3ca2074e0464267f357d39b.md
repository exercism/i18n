# স্টেটসহ ক্লাস

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| যেভাবে লেখা হয় | বাইরে থেকে পড়া যায় | বাইরে থেকে পরিবর্তন করা যায় |
| --- | --- | --- |
| `attr x : INT` | হ্যাঁ | হ্যাঁ |
| `readonly attr x : INT` | হ্যাঁ | না |
| `private attr x : INT` | না | না |

সাধারণত ডিফল্ট হিসেবে `readonly`-ই বেছে নেবেন। এটি যে কাউকে স্কোর দেখতে দেয়, আর
পরিবর্তন করতে হলে `home_goal`-এর মধ্য দিয়ে যেতে হবে বলে জোর দেয়, কারণ
স্কোরিংয়ের নিয়মগুলো ওখানেই থাকে।

## create and new

`new` এই ক্লাসের এমন একটি অবজেক্ট তৈরি করে যার প্রতিটি অ্যাট্রিবিউট খালি থাকে। এটি
কেবল ক্লাসের ভেতরেই ব্যবহার করা যায়।

`create` হলো একটি সাধারণ রুটিন, যার নাম নিয়ে সবাই একমত: `#C(args)` মানে হুবহু
`C::create(args)`। একটি ক্লাসে এমন কয়েকটি থাকতে পারে, যেগুলোকে তাদের আর্গুমেন্ট
দিয়ে আলাদা করা হয়, আর যেসব ক্লাসে একটিও নেই সেগুলোকে `#` দিয়ে তৈরি করাই যায় না।

## SAME

`SAME` বলতে বোঝায় যে ক্লাসে এটি লেখা হয়েছে সেটিকেই। `create`-এ এটি রিটার্ন টাইপ;
এটি আর্গুমেন্টেও কাজে আসে, আর এটিই একটি ইনহেরিটেড রুটিনকে যে ক্লাস থেকে এসেছে তার
বদলে যে ক্লাস ইনহেরিট করছে তার কথা বলায়।

## রিটার্ন টাইপ নেই এমন রুটিন

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

কোনো `:` নেই, কোনো টাইপও নেই। এমন রুটিনকে একটি স্টেটমেন্ট হিসেবে কল করা হয় এবং
এটি কোনো এক্সপ্রেশন হিসেবে থাকতে পারে না। এটি ইঙ্গিত দেয় যে কলটির মূল উদ্দেশ্য
হলো এটি যে পরিবর্তন করে সেটিই।

## self

একটি রুটিনের ভেতরে `self` হলো সেই অবজেক্ট, যার উপর এটি কল করা হয়েছিল। এটি খুব
কমই লেখা হয়, কারণ নিজে থেকে লেখা কোনো অ্যাট্রিবিউট বা রুটিন আগেই `self`-এর বোঝায়।
অবজেক্টটি যখন অন্য কোথাও পাঠাতে বা রিটার্ন করতে হয়, তখনই এটি দরকার হয়:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` এবং `out` — এগুলো সবই Sather নিজের জন্য
নিয়ে রাখা শব্দ, এগুলোর কোনোটিই নিজের নাম হিসেবে ব্যবহার করা যায় না।

## রেফারেন্স, মান নয়

একটি অবজেক্টে পৌঁছানো যায় একটি রেফারেন্সের মাধ্যমে। একই স্কোরবোর্ডের দুটি নাম
একই স্কোর দেখে:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

অন্য আচরণটি পেতে হলে পরে `immutable class` ব্যবহার করবেন।
