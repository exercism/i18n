# Factor ইনস্টল করা

Factor ট্র্যাকটি **Factor 0.101** ব্যবহার করে। আগের ভার্সনগুলো সমর্থিত নয়।

আপনি একটি [স্টেবল](#stable) বা [নাইটলি](#nightly) বিল্ড ইনস্টল করতে পারেন, অথবা [সোর্স থেকে বিল্ড করতে পারেন](#build-from-source)।

`factor -e='vm-version print'` চালিয়ে আপনার ইনস্টলেশন যাচাই করুন। এতে `0.101` বা তার চেয়ে বেশি প্রিন্ট হওয়া উচিত।

---
### স্টেবল

<https://factorcode.org#stable-release> "Stable release" সেকশনের অধীনে স্টেবল বাইনারি দেয়।

---
### নাইটলি

<https://factorcode.org#development-release> "Development release" সেকশনের অধীনে নাইটলি বাইনারি দেয়। এই বাইনারিগুলো git থেকে বিল্ড করা হয়, তবে কেবল যেসব বিল্ড পাস করে সেগুলোই দেখানো হয়।

---
### সোর্স থেকে বিল্ড করা

আপনি যদি একেবারে সর্বশেষটি চান, আর নাইটলিও আপনার কাছে পুরনো মনে হয়, তাহলে আপনার দরকার একটি আধুনিক C++ কম্পাইলার (GCC >=4.8 বা Clang >=3.5), `make`, এবং `curl`।

এই সাধারণ শর্তগুলো পূরণ হয়ে গেলে আপনি যা করতে পারেন:

1. `build` শেল স্ক্রিপ্টটি ডাউনলোড করুন: [Unix-জাতীয় / POSIX শেলের জন্য **এখানে**](https://raw.githubusercontent.com/factor/factor/master/build.sh) অথবা [Windows-এর জন্য **এখানে**](https://raw.githubusercontent.com/factor/factor/master/build.cmd)। Factor যে ডিরেক্টরিতে ইনস্টল করতে চান, সেখানে এটি রাখুন। কোডবেসসহ `factor` নামের একটি ডিরেক্টরি তৈরি হবে।

2. এটি `./build.sh install` এভাবে চালান, আর উইন্ডোজে `.\build.cmd install`। <sub>এটি Factor-এর `git` রিপোজিটরি ক্লোন করবে, বিল্ড করবে, এবং <https://factorcode.org> থেকে একটি Factor VM ইমেজ ডাউনলোড করবে। আপনার লিংক ও ঘড়ির গতির সাথে তাল মিলিয়ে এই প্রক্রিয়ায় ২ থেকে ২০ মিনিট লাগতে পারে।</sub>

3. এখন আপনি `factor` সাবডিরেক্টরির ভেতরে তৈরি হওয়া `factor` বা `factor.exe` বাইনারি চালাতে পারেন। সহায়তার জন্য `factor --help` চেষ্টা করে দেখুন। কমান্ড লাইন থেকেও ডকুমেন্টেশন দেখতে পারেন, অথবা GUI Listener-এ <kbd>F1</kbd> চাপতে পারেন, যাতে হেল্প ব্রাউজার খুলবে।

4. ভবিষ্যতে `factor` সাবডিরেক্টরির ভেতরের `build.sh` (উইন্ডোজে `build.cmd`) ব্যবহার করে git থেকে টেনে এনে জায়গায় বসেই রিবিল্ড করতে পারবেন, আর প্রয়োজন হলে নতুন VM ইমেজও ডাউনলোড করতে পারবেন।

ফাইল স্ট্রাকচার এখন এরকম দেখাতে পারে:

```
.
├── build.sh                   <- delete if you like
└── factor
    ├── basis
    ├── boot.unix-x86.64.image
    ├── build.cmd              <- use these from now on
    ├── build.sh               <-
    ├── core
    ├── extra
    ├── factor
    ├── Factor.app
    ├── factor.image
    ├── GNUmakefile
    ├── libfactor.a
    ├── libfactor-ffi-test.so
    ├── LICENSE.txt
    ├── misc
    ├── Nmakefile
    ├── README.md
    ├── unmaintained
    ├── vm
    └── work
```

আপনার আর টপ-লেভেলের `build` স্ক্রিপ্ট দরকার নেই, কারণ ভবিষ্যতে ডাউনলোড করা স্ক্রিপ্টটিই ব্যবহার করা উচিত।

### নিজে হাতে সোর্স থেকে বিল্ড করা (সুপারিশ করা হয় না)

[রিপোজিটরিটি](https://github.com/factor/factor) ক্লোন করুন এবং সেই ফোল্ডারে `make` ব্যবহার করুন।

কোনো টার্গেট নেই, এমন একটি এরর দিয়ে `make` যদি ব্যর্থ হয়, তাহলে `make factor` চেষ্টা করে দেখুন। আর আপনি যদি Makefile পড়তে পারেন, তাহলে `GNUmakefile`-এ আপনার প্ল্যাটফর্মের make টার্গেট খুঁজে বের করুন।

সেটাও যদি ব্যর্থ হয়, তাহলে এররটি লিখে [factor/factor](https://github.com/factor/factor)-এ একটি ইস্যু খুলুন। বন্ধুসুলভ ডেভেলপাররা সাহায্য করতে খুশিই হবেন।
