# পরিচিতি

## মূল বিষয়গুলো

C# একটি স্ট্যাটিক টাইপের ভাষা, অর্থাৎ কম্পাইল-টাইমেই প্রতিটি জিনিসের একটি টাইপ থাকে। কোনো নামে একটি মান বসানোকেই ভ্যারিয়েবল ডিফাইন করা বলা হয়। ভ্যারিয়েবল ডিফাইন করা যায় দুইভাবে: হয় স্পষ্টভাবে তার টাইপ উল্লেখ করে, নয়তো অ্যাসাইন করা মানের ভিত্তিতে C# কম্পাইলারকে তার টাইপ অনুমান করতে দিয়ে (একে _টাইপ ইনফারেন্স_ বলা হয়)। তাই নিচের দুটি ভ্যারিয়েবল ডেফিনিশন আসলে একই:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

ভ্যারিয়েবলের মান পরিবর্তন করা হয় `=` অপারেটরের মাধ্যমে। একবার ডিফাইন হয়ে গেলে ভ্যারিয়েবলের টাইপ আর কখনোই বদলানো যায় না।

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# একটি [অবজেক্ট-ওরিয়েন্টেড ভাষা][object-oriented-programming] এবং এতে সব ফাংশন একটি _ক্লাসের_ ভেতরে ডিফাইন করতে হয়। ক্লাস ডিফাইন করতে `class` কিওয়ার্ডটি ব্যবহার করা হয়। `new` কিওয়ার্ড ব্যবহার করে অবজেক্ট (বা _ইনস্ট্যান্স_) তৈরি করা হয়।

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

ক্লাসের ভেতরের ফাংশনকে _মেথড_ বলা হয়। প্রতিটি মেথডে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে। সব প্যারামিটারের টাইপ স্পষ্টভাবে উল্লেখ করতে হয়, প্যারামিটারের ক্ষেত্রে কোনো টাইপ ইনফারেন্স নেই। একইভাবে রিটার্ন টাইপও স্পষ্টভাবে উল্লেখ করতে হয়। `return` কিওয়ার্ড ব্যবহার করে মেথড থেকে মান রিটার্ন করা হয়। অন্য ফাইলের কোড থেকে কোনো মেথড কল করার সুযোগ দিতে হলে `public` অ্যাকসেস মডিফায়ার যোগ করতে হয়।

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

ইনস্ট্যান্সের উপর ডট (`.`) সিনট্যাক্স ব্যবহার করে মেথড কল করা হয়, যেখানে কোন মেথড কল করতে হবে তার নাম দিতে হয় এবং মেথডের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাঠাতে হয়। চাইলে আর্গুমেন্টে সংশ্লিষ্ট প্যারামিটারের নামও উল্লেখ করা যায়।

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C#-এ স্কোপ নির্ধারিত হয় `{` ও `}` অক্ষর দুটির মধ্যে।

C#-এ দুই ধরনের কমেন্ট লেখা যায়। এক লাইনের কমেন্টের আগে `//` বসে, আর একাধিক লাইনের কমেন্ট `/*` ও `*/`-এর মাঝে লেখা হয়।
