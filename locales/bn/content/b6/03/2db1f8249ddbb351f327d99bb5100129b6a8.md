# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার   | টাইপ    | বিবরণ                         |
| --------- | --------- | ------- | ----------------------------- |
| `$a0`     | ইনপুট     | অ্যাড্রেস | নাল-টার্মিনেটেড ডিজিট স্ট্রিং  |
| `$a1`     | ইনপুট     | ইন্টিজার | স্প্যান                       |
| `$v0`     | আউটপুট    | ইন্টিজার | সর্ববৃহৎ সিরিজ গুণফল          |
| `$t0-9`   | টেম্পোরারি | যেকোনো  | সাময়িক স্টোরেজের জন্য        |
