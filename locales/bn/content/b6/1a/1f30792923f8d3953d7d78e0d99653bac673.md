# নির্দেশনা

শহরে নতুন একটি কবিতা ক্লাব চালু হয়েছে, আর আপনি সেখানে যাওয়ার কথা ভাবছেন।
আগে কিছু ঘটনা ঘটেছে বলে ক্লাবের দরজায় ঢোকার একটি খুব নির্দিষ্ট নিয়ম আছে, যা ঢোকার চেষ্টা করার আগে আপনাকে ভালোভাবে শিখে নিতে হবে।

কবিতা ক্লাবে দুটি দরজা আছে, একটি সামনের আর একটি পিছনের, আর দুটিতেই পাহারাদার আছে।
ভিতরে ঢুকতে হলে আপনাকে দিনের পাসওয়ার্ড বের করতে হবে।

পাসওয়ার্ড সবসময় একটি কবিতার উপর ভিত্তি করে তৈরি হয় এবং দুটি ধাপে বের করা যায়।

1. পাহারাদার একবারে এক লাইন করে কবিতাটি আবৃত্তি করবেন, আর আপনাকে সেই লাইনের উপযুক্ত অক্ষর দিয়ে উত্তর দিতে হবে।
2. এরপর পাহারাদার আপনার দেওয়া সব অক্ষর একসাথে বলে দেবেন, আর আপনাকে সেগুলো একটি কাগজে নির্দিষ্ট একটি ফরম্যাটে লিখে রাখতে হবে।

প্রক্রিয়ার বিস্তারিত নির্ভর করে আপনি কোন দরজা দিয়ে ঢুকতে চাইছেন তার উপর।

## 1. একটি বাক্যের প্রথম অক্ষর বের করুন

সামনের দরজার পাসওয়ার্ডের অক্ষরগুলো নির্ধারণ করতে হলে, পাহারাদার আপনার কাছে যে লাইনটি আবৃত্তি করেন, তার প্রথম অক্ষর দিয়ে আপনাকে উত্তর দিতে হবে।

সুন্দর একটি পাসওয়ার্ড পেতে কবিতা ক্লাবের সদস্যরা _অ্যাক্রস্টিক_ কবিতা ব্যবহার করতে পছন্দ করেন।
এর মানে হল প্রতিটি বাক্যের প্রথম অক্ষর মিলে একটি শব্দ তৈরি হয়।
এখানে তাদের প্রিয় একজন লেখক Michael Lockwood-এর একটি উদাহরণ আছে।

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

তাই পাহারাদার যখন **Stands so high** আবৃত্তি করেন, আপনি উত্তর দেবেন **S**, আর পাহারাদার যখন **Huge hooves too** আবৃত্তি করেন, আপনি উত্তর দেবেন **H**।

`frontDoorResponse` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে কবিতার একটি লাইন নেয় এবং সেই লাইনের প্রথম অক্ষর রিটার্ন করে।

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. একটি শব্দ বড় হাতের অক্ষরে লিখুন

এখন আপনার কাছে সব সঠিক অক্ষর আছে, তাই সামনের দরজার পাসওয়ার্ড পেতে হলে শুধু শব্দটিকে সঠিকভাবে বড় হাতের অক্ষরে লিখতে হবে।

`frontDoorPassword` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি স্ট্রিং (১ নম্বর কাজে পাওয়া অক্ষরগুলো একসাথে) গ্রহণ করে এবং সেটিকে সঠিকভাবে বড় হাতের অক্ষরে লিখে রিটার্ন করে।

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. একটি বাক্যের শেষ অক্ষর বের করুন

পিছনের দরজার পাসওয়ার্ডের অক্ষরগুলো নির্ধারণ করতে হলে, পাহারাদার আপনার কাছে যে লাইনটি আবৃত্তি করেন, তার শেষ অক্ষর দিয়ে আপনাকে উত্তর দিতে হবে।

কবিতা ক্লাবের সদস্যরা সত্যিই বুদ্ধিমান।
আগে উল্লেখ করা কবিতাটি আবার _টেলেস্টিক_, যার মানে প্রতিটি বাক্যের শেষ অক্ষরও মিলে একটি শব্দ তৈরি করে:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

পাহারাদার যখন **Stands so high** আবৃত্তি করেন, আপনি উত্তর দেবেন **h**, আর পাহারাদার যখন **Huge hooves too** আবৃত্তি করেন, আপনি উত্তর দেবেন **o**।

লক্ষ্য করুন, পাহারাদার মাঝে মাঝে লাইনের শুরুতে বা শেষে শৈলীগত বিরতি (হোয়াইটস্পেস আকারে) দেন।
সঠিক অক্ষর বের করতে হলে ওই বিরতিগুলো আপনাকে উপেক্ষা করতে হবে।

`backDoorResponse` ফাংশনটি ইমপ্লিমেন্ট করুন, যা আর্গুমেন্ট হিসেবে কবিতার একটি লাইন নেয় এবং সেই লাইনের হোয়াইটস্পেস নয় এমন শেষ অক্ষরটি রিটার্ন করে।

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. ভদ্র হোন

পিছনের দরজা দিয়ে কবিতা ক্লাবে ঢুকতে হলে আপনাকে বাড়তি ভদ্রতা দেখাতে হবে।
তাই এবার পাসওয়ার্ড বের করতে, শব্দটিকে সঠিকভাবে বড় হাতের অক্ষরে লিখতে হবে এবং শেষে `', please'` যোগ করতে হবে।

`backDoorPassword` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি স্ট্রিং (৩ নম্বর কাজে পাওয়া অক্ষরগুলো একসাথে) গ্রহণ করে এবং বড় হাতের অক্ষরে লেখা পাসওয়ার্ডের ভদ্র সংস্করণটি রিটার্ন করে।

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
