# ইনস্টলেশন

আপনার সিস্টেমে Julia ইনস্টল করতে [Julia Language Downloads page](https://julialang.org/downloads/) পেজের নির্দেশনা অনুসরণ করুন।

~~~~exercism/caution
আপনার অপারেটিং সিস্টেমের প্যাকেজ ম্যানেজারের মাধ্যমে Julia ইনস্টল করা ঠিক নয়। ওই প্যাকেজগুলো আনুষ্ঠানিকভাবে রক্ষণাবেক্ষণ করা হয় না এবং সমস্যা তৈরি করতে পারে।
~~~~

লোকাল ইনস্টলেশনের জন্য অনেক এডিটর ও IDE-এর প্লাগইন পাওয়া যায়। [VS Code extension](https://github.com/julia-vscode/julia-vscode) সবচেয়ে জনপ্রিয়। GitHub-এ [JuliaEditorSupport](https://github.com/JuliaEditorSupport) অর্গানাইজেশনে অন্য এডিটরগুলোর জন্য ইন্টিগ্রেশন খুঁজে পাবেন।

আরও ইন্টার্যাক্টিভ পরিবেশ পছন্দ হলে আপনি Jupyter নোটবুকের সাথে [IJulia](https://github.com/JuliaLang/IJulia.jl) ব্যবহার করতে পারেন, অথবা Julia-তে সহজ রিঅ্যাক্টিভ নোটবুকের জন্য [Pluto.jl](https://github.com/fonsp/Pluto.jl) ব্যবহার করতে পারেন।

লোকাল ইনস্টলেশনের ঝামেলা ছাড়াই Julia শুরু করার একটি সহজ উপায় হলো [Nextjournal](https://nextjournal.com/), একটি নোটবুক-ভিত্তিক অনলাইন IDE। ব্রাউজার থেকেই সেখানে ঢুকতে, লগইন করতে এবং অনুশীলনী সমাধান শুরু করতে পারবেন। শুধু একটি অনলাইন REPL চাইলে [Repl.it](https://repl.it/languages/julia) ব্যবহার করতে পারেন।
