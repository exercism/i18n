# পরিচিতি

স্ট্রাক্ট হলো [ম্যাপ][exercism-maps]-এর উপর গড়ে ওঠা একটি এক্সটেনশন, যা কম্পাইল-টাইম চেক ও ডিফল্ট মান দেয়। স্ট্রাক্টের নামকরণ করা হয় যে মডিউলে এটি ডিফাইন করা হয় সেই মডিউলের নাম অনুসারে। স্ট্রাক্ট ডিফাইন করতে `defstruct` কনস্ট্রাক্টটি ব্যবহার করুন। সাধারণত মডিউল ডেফিনিশনের ঠিক পরেই এই কনস্ট্রাক্টটি বসানো হয়। `defstruct` হয় অ্যাটমের একটি অ্যারে (`nil` ডিফল্ট মানের জন্য) নেয়, নয়তো একটি কিওয়ার্ড লিস্ট (নির্দিষ্ট ডিফল্ট মানের জন্য)। ডিফল্ট মান নেই এমন ফিল্ডগুলোকে ডিফল্ট মান আছে এমন ফিল্ডের আগে থাকতে হবে।

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## ফিল্ড অ্যাক্সেস করা ও আপডেট করা

যেহেতু স্ট্রাক্টগুলো ম্যাপের উপরেই তৈরি, তাই মান পাওয়া ও সেগুলো নিয়ে কাজ করতে আমরা বেশিরভাগ ম্যাপ ফাংশনই ব্যবহার করতে পারি। স্ট্রাক্টের জন্য _Access Behaviour_ ইমপ্লিমেন্ট করা **হয় না**। বদলে স্ট্রাক্টের ফিল্ড অ্যাক্সেস করতে _স্ট্যাটিক অ্যাক্সেস অপারেটর_ `.` ব্যবহার করার পরামর্শ দেওয়া হয়।

- ফিল্ডের মান পাওয়া/ফেচ করা:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- ফিল্ডের মান আপডেট করা

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## প্যাটার্ন ম্যাচিং

স্ট্রাক্টের নামসহ বা নাম ছাড়াই প্যাটার্ন ম্যাচিংয়ে স্ট্রাক্ট ব্যবহার করা যায়।

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

প্যাটার্নে স্ট্রাক্টের নাম দিলে আপনি নিশ্চিত করতে পারেন যে বাম ও ডান দুই দিকেই একই টাইপের স্ট্রাক্ট রয়েছে।

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## ফিল্ডের মানের ইনিশিয়ালাইজেশন বাধ্যতামূলক করা

স্ট্রাক্ট তৈরি হওয়ার সময় ফিল্ডগুলোর মান ইনিশিয়ালাইজ হয় তা নিশ্চিত করতে আমরা ফিল্ড কী (key)গুলোর একটি অ্যারে দিয়ে `@enforce_keys` মডিউল অ্যাট্রিবিউট ব্যবহার করতে পারি। কোনো কী (key) তালিকায় না থাকলে তার মান `nil` হবে, উপরের উদাহরণে যেমনটি দেখা গেছে। বাধ্যতামূলক কোনো কী (key) ইনিশিয়ালাইজ না হলে একটি এরর রেইজ হয়।

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
