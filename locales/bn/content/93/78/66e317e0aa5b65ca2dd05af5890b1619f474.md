# মডুলো

মডুলো তুলনা Crystal-এ সম্পূর্ণ বৈধ, তবে ভাগের ভাগশেষ তুলনা করার আরও পাঠযোগ্য একটি উপায় হলো [`divisible_by?`][divisible_by] মেথডটি।
উদাহরণস্বরূপ:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
