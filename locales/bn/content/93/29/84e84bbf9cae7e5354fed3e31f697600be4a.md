# ভূমিকা

## অ্যারে

F#-এ একটি `list` হলো শূন্য বা ততোধিক মানের একটি ইমিউটেবল কালেকশন। একটি অ্যারের সব মানের টাইপ একই হতে হবে। যেহেতু অ্যারে ইমিউটেবল, একবার একটি অ্যারে তৈরি হয়ে গেলে তার মান আর কখনো বদলানো যায় না। যে ফাংশন/অপারেটরগুলো একটি অ্যারে পরিবর্তন করে বলে মনে হয় (যেমন একটি এলিমেন্ট যোগ করা), তারা আসলে একটি নতুন অ্যারে রিটার্ন করে।

অ্যারে এভাবে ডিফাইন করা যায়:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

একটি অ্যারেতে এলিমেন্ট যোগ করার সবচেয়ে কমন উপায় হলো `::` (কনস) অপারেটরের মাধ্যমে:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

একটি F# অ্যারের একটি _হেড_ (প্রথম এলিমেন্ট) এবং একটি _টেইল_ (প্রথম এলিমেন্টের পরের সবকিছু) থাকে। একটি অ্যারের টেইল নিজেই একটি অ্যারে।

অ্যারে হয় `List` মডিউলে ডিফাইন করা ফাংশন ও অপারেটর দিয়ে, অথবা ম্যানুয়ালি _list_ এবং _cons_ প্যাটার্ন দিয়ে প্যাটার্ন ম্যাচিং করে ম্যানিপুলেট করা হয়:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

প্যাটার্ন ম্যাচিংয়ের সময় আপনি একটি মান _ডিসকার্ড_ করতে পারেন; যখন কোনো নির্দিষ্ট কেসে একটি মানের প্রতি আপনার _আগ্রহ নেই_ (অর্থাৎ আপনি মানটি _ব্যবহার_ করবেন না), তখন এটি বোঝাতে আপনি একটি আন্ডারস্কোর (`'_'`) ব্যবহার করতে পারেন:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

একক `'_'` প্যাটার্ন ম্যাচিংয়ে সবসময় সবার _শেষে_ আসা উচিত; যে কোনো মান অন্য কোনো কেসের সাথে _মেলে না_, সেটি এই কেস দ্বারা হ্যান্ডেল করা হবে।
