# টাইপ অ্যাসারশন পরিচিতি

Go-তে ইন্টারফেস আন্ডারলাইং টাইপ নিয়ে অস্পষ্টতা তৈরি করতে পারে।
টাইপ অ্যাসারশনের সাহায্যে আমরা এই সিনট্যাক্স ব্যবহার করে ইন্টারফেস মানের আন্ডারলাইং কনক্রিট মান বের করতে পারি: `interfaceVariable.(concreteType)`।

উদাহরণস্বরূপ:

```go
var input interface{} = 12
number := input.(int)
```

দ্রষ্টব্য: ইন্টারফেস ভ্যারিয়েবলটিতে যদি কনক্রিট টাইপের কোনো মান না থাকে, তাহলে এটি একটি প্যানিক ঘটাবে।

টাইপ অ্যাসারশনের দুটি রিটার্ন ভ্যালুই কাজে লাগিয়ে আমরা পরীক্ষা করতে পারি, একটি ইন্টারফেস মানে নির্দিষ্ট কোনো কনক্রিট টাইপ আছে কি না: আন্ডারলাইং মান এবং একটি বুলিয়ান মান, যা জানায় অ্যাসারশনটি সফল হয়েছে কি না।
উদাহরণস্বরূপ:

```go
str, ok := input.(string) // no panic if input is not a string
```

`input`-এ যদি একটি `string` থাকে, তাহলে `str` হবে আন্ডারলাইং মান এবং `ok` হবে ট্রু।
`input`-এ যদি `string` না থাকে, তাহলে `str` হবে `string` টাইপের জিরো ভ্যালু (অর্থাৎ `""`, খালি স্ট্রিং) এবং `ok` হবে ফলস।
কোনো ক্ষেত্রেই প্যানিক ঘটে না।

## টাইপ সুইচ

একটি **টাইপ সুইচ** পরপর কয়েকটি টাইপ অ্যাসারশন করতে পারে।
এর সিনট্যাক্স টাইপ অ্যাসারশনের মতোই (`interfaceVariable.(concreteType)`), তবে `concreteType`-এর জায়গায় বসে `type` কিওয়ার্ডটি।
এখানে একটি উদাহরণ:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
