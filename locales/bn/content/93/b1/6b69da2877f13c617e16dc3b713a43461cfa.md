# ভূমিকা

## কলব্যাক ফাংশন

কলব্যাক ফাংশন হলো এমন ফাংশন যেগুলো আর্গুমেন্ট হিসেবে পাস করা হয়। এই প্রোগ্রামিং প্যাটার্নটি সিঙ্ক্রোনাস ও অ্যাসিনক্রোনাস উভয় প্রোগ্রামিংয়েই ফাংশন কলের একটি ক্রম তৈরি করে। একটি কলব্যাক ফাংশন লেখা একটি ফাংশন লেখার থেকে আলাদা কিছু নয়; তবে, কলব্যাক ফাংশনটিকে কলিং ফাংশন দ্বারা সংজ্ঞায়িত সিগনেচারের সাথে মিলতে হবে।

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

আপনি ফাংশন এক্সপ্রেশন হিসেবেও কলব্যাক লিখতে পারেন:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
