# টাইপ জাগলিং

টাইপ জাগলিংকে টাইপ কোয়ার্শন নামেও জানা যায়।
টাইপ জাগলিং হলো এমন একটি বিষয়, যখন একটি অপারেশন সম্পাদনের জন্য ভিন্ন টাইপের দুটি মানকে একই টাইপে কোয়ার্স করা হয়।

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

এক্সপ্রেশনটি মূল্যায়ন করা হলে, `*` অপারেটরের প্রত্যাশার সাথে মিল রাখতে স্ট্রিং মানটি অন্তর্নিহিতভাবে একটি `int`-এ রূপান্তরিত হয়।
কোন টাইপে কোয়ার্স করা হবে, সেই সিদ্ধান্ত PHP অপারেশনের নিয়ম অনুসারে নেয়, আর এই নিয়মগুলো অনেকটাই ভিন্ন হয়।

ফাংশন ও মেথড কল করার সময়েও টাইপ কোয়ার্শন ঘটে:

```php
strlen(12321);
# => 5
```

## টাইপ কাস্টিং

অন্তর্নিহিত কোয়ার্শনের উপর নির্ভর না করে, `C`-স্টাইলের টাইপ কাস্টিং ব্যবহার করে আমরা একটি মানকে নির্দিষ্ট একটি টাইপ হিসেবে মূল্যায়ন করতে জোর করে বাধ্য করতে পারি:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

এটি মানটিকে বন্ধনী `(...)`-তে উল্লেখ করা টাইপে রূপান্তর করবে।
লক্ষ্য টাইপ হিসেবে সব প্রিমিটিভ টাইপই ব্যবহার করা যায়: `bool`, `int`, `float`, `string`, `array`, `object`.

## কেবল সাময়িক রূপান্তর

টাইপ জাগলিং বা কাস্টিং একটি ভ্যারিয়েবলে সংরক্ষিত মানের টাইপ **পরিবর্তন করে না**।
কেবল অপারেশনের ইনপুটটিই রূপান্তরিত হয়।

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## তথ্যের ক্ষতি

কোনো মানকে অন্য একটি টাইপে কোয়ার্স করা হলে, সেই প্রক্রিয়ায় তথ্যের ক্ষতি হতে পারে:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

স্পষ্টভাবে হোক বা অন্তর্নিহিতভাবে, কাস্টিংয়ের উপর নির্ভর করা একটি বড় সিস্টেমে এরর তৈরি করতে পারে।

## `array` ও `object`-এ স্পষ্ট টাইপ কাস্টিং

মানকে `array` ও `object` টাইপেও কাস্ট করা যায়।
যদি কোনো মান, যা অ্যারে বা অবজেক্ট নয়, একটি `array`-তে কাস্ট করা হয়, তবে সেটি অ্যারের মধ্যে থাকা একটি একক এলিমেন্টে রূপান্তরিত হয়:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

একটি `object`-এ কাস্ট করা হলে, মানটি `scalar` নামের একটি পাবলিক প্রপার্টিতে সেট করা হয়:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` হলো PHP-তে বিল্ট-ইন একটি অ্যানোনিমাস ক্লাসের টাইপ।
