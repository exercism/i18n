# পরিচিতি

`null` মানটি কোনো মানের _অভাব_ বোঝাতে ব্যবহৃত হয়। একটি **নালেবল** টাইপ হলো এমন একটি টাইপ, যা একটি ভ্যারিয়েবলকে `null` মান নিতে দেয়। যেকোনো টাইপকে নালেবল করতে আমরা সেটিকে `Null<T>` দিয়ে মুড়ে দিই:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

কোনো মানের বর্তমান মান `null` কি না তা যাচাই করতে, সহজভাবে একটি `if` এক্সপ্রেশন ব্যবহার করুন:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
