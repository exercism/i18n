# সম্পর্কে

Perl একটি প্রোগ্রামিং ভাষা, যা ল্যারি ওয়াল তৈরি করেছেন এবং যা প্রথম প্রকাশিত হয় ১৯৮৭ সালে।

## প্যাকেজ ও মডিউল

একটি প্যাকেজ হলো কোডের একটি সংগ্রহ, যা প্রায়শই একই নামের একটি মডিউল ফাইলে রাখা হয় এবং সেই ফাইলের এক্সটেনশন হয় `.pm`. এরপর মডিউলটি অন্য একটি ফাইলে ইমপোর্ট করা যায়, সাধারণত `use` কিওয়ার্ড দিয়ে।

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## ভ্যারিয়েবল

স্কেলার (`$foo`), অ্যারে (`@bar`) এবং হ্যাশ (`%baz`) ভ্যারিয়েবল রয়েছে। সহজ রাখতে এখানে কেবল স্কেলার ভ্যারিয়েবল ব্যবহার করা হবে। একটি স্কেলার মান হতে পারে এদের যেকোনো একটি: একটি স্ট্রিং, একটি সংখ্যা, একটি বুলিয়ান, বা কোনো কিছুতে একটি [রেফারেন্স][perlreftut]। মান না থাকার অবস্থাকে বলা হয় `undef`.

কিওয়ার্ড `my` এবং `our` লেক্সিক্যাল স্কোপে একটি ভ্যারিয়েবল ডিক্লেয়ার করে, যেমন `my $foo;`. `our` ব্যবহার করলে ভ্যারিয়েবলটি একই নামের একটি প্যাকেজ ভ্যারিয়েবলের সাথেও সংযুক্ত হয়ে যায়। ভ্যারিয়েবল ডিক্লেয়ার করার আরও কিছু উপায় আছে, যা এখানে আলোচনা করা হবে না।

`=` অপারেটর দিয়ে আপনি একটি ভ্যারিয়েবলে মান অ্যাসাইন করতে পারেন, যেমন `$foo = 1;`; আবার ভ্যারিয়েবল ডিক্লেয়ার করার সময়েই সেটি করতে পারেন, যেমন `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## সাবরুটিন

`sub` কিওয়ার্ড একটি [সাবরুটিন][perlsub] ডিক্লেয়ার করে। `return` কিওয়ার্ড সাবরুটিনটি শেষ করে দেয় এবং নির্দিষ্ট মানগুলো ফেরত দেয়, আর কিছু দেওয়া না হলে একটি খালি অ্যারে ফেরত দেয়। আলাদা করে `return` না দিলে, ফেরত দেওয়া মান নির্ধারিত হয় ব্যবহৃত সাবরুটিনের কনটেক্সট (স্কেলার, অ্যারে, বা ভয়েড) এবং তার শেষ স্টেটমেন্ট দ্বারা।

```perl
sub hello () {
    return 'Hello, World!';
}
```

Perl-এর সাম্প্রতিক সংস্করণগুলোতে আপনি একটি [সিগনেচার][perlsubsig]-এ আনুষ্ঠানিক প্যারামিটার উল্লেখ করতে পারেন। প্যারামিটার তালিকায় স্কেলার, অ্যারে, বা হ্যাশ ভ্যারিয়েবল থাকতে পারে। খালি প্যারামিটার তালিকা মানে সাবরুটিনটি শূন্য আর্গুমেন্ট নেয়। Perl-এর পুরনো সংস্করণে বিশেষ ভ্যারিয়েবল `@_` থেকে আর্গুমেন্টগুলো নিতে হতো, যা এখানে আলোচনা করা হবে না।

## কমেন্ট
