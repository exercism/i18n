# ইমিউটেবল ক্লাস

একটি `SCOREBOARD` এমন একটি জিনিস যা বদলে যায়। একটি স্কোরবোর্ডের দুটি নাম একই স্কোর দেখে, কারণ বোর্ডটি একটিই, আর দুটি নামই তার দিকেই ইশারা করে।

বিয়ারিং সেরকম নয়। `350 degrees` অন্য কিছু হয়ে যায় না; এটি শুধু *যেমন আছে তেমনই*। সংখ্যাও এমনটাই আচরণ করে, স্ট্রিংও তাই, আর আপনার নিজের ক্লাসও তাই করতে পারে।

## immutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

দুটি শব্দই সব বদলে দেয়। ইমিউটেবল ক্লাসের একটি অবজেক্ট একটি **মান**, কোনো এক দিকে ইশারা করা বস্তু নয়:

- এটি অ্যাসাইন বা পাস করা হলে কপি হয়ে যায়, তাই অন্য কেউ আপনারটি বদলাতে পারে না;
- এটি কখনো void হতে পারে না;
- আর এর অ্যাট্রিবিউটগুলোতে অ্যাসাইন করা যায় না।

## আরেকটি তৈরি করে একটি বদলানো

যেহেতু `degrees := 90` অনুমোদিত নয়, `attr` দেয় অন্য কিছু: নতুন মানটি নিয়ে সেটি বদলিয়ে **একটি নতুন অবজেক্ট** ফিরিয়ে দেওয়া একটি রুটিন।

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

আসলটি অপরিবর্তিত থাকে। এটাই পুরো কৌশল, আর এভাবেই `create` লেখা হয়:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

এখানে কোনো `new` নেই। একটি ইমিউটেবল অবজেক্ট সবসময়ই থাকে, তাই `b : SAME` আগে থেকেই একটি অবজেক্ট, যার প্রতিটি অ্যাট্রিবিউট তার খালি মানে।

তাই যে রুটিন একটি বিয়ারিং "বদলায়", সেটি নতুন একটি ফিরিয়ে দেয়:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## তুলনা করা

মান তুলনা করা হয় তারা কী ধারণ করে তা দিয়ে, কোন অবজেক্ট তা দিয়ে নয়, তবে কীভাবে তা আপনাকে বলে দিতে হবে। `is_eq` লিখুন, তাহলে `=` সেটি ব্যবহার করবে:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

এটি ছাড়া দুটি বিয়ারিংয়ের উপর `=` কম্পাইল হবে না।

## কোনটি বেছে নেবেন

যখন জিনিসটির কোনো পরিচয় নেই এবং তার সম্পর্কে কোনো কিছুই যুক্তিসঙ্গতভাবে বদলাতে পারে না, তখন ইমিউটেবল ক্লাস ব্যবহার করুন: একটি বিয়ারিং, একটি বিন্দু, একটি তারিখ, একটি দৈর্ঘ্য। আর যখন জিনিসটি এমন একটি নির্দিষ্ট সত্তা যার উপর নানা ঘটনা ঘটে, তখন সাধারণ ক্লাস ব্যবহার করুন: একটি স্কোরবোর্ড, একটি হারনেস, একটি ফাইল।

আসল প্রশ্নটি হলো, "একই" বলতে "সমান" বোঝায়, নাকি "হুবহু ওই একটিই"।
