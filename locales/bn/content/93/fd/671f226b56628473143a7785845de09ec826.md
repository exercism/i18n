# নির্দেশাবলি

এই অনুশীলনীতে আপনি একটি গাড়ি কারখানার অ্যাসেম্বলি লাইনের উৎপাদন বিশ্লেষণ করার কোড লিখবেন। অ্যাসেম্বলি লাইনের গতি `0` (বন্ধ) থেকে `10` (সর্বোচ্চ) পর্যন্ত হতে পারে।

সবচেয়ে কম গতিতে (`1`) প্রতি ঘণ্টায় `221`টি গাড়ি তৈরি হয়। গতি বাড়ার সাথে সাথে উৎপাদন রৈখিকভাবে বাড়ে। তাই গতি `4` সেট করলে প্রতি ঘণ্টায় `4 * 221 = 884`টি গাড়ি তৈরি হওয়া উচিত। তবে বেশি গতিতে ত্রুটিপূর্ণ গাড়ি তৈরি হওয়ার সম্ভাবনা বেড়ে যায়, যেগুলোকে পরে বাদ দিতে হয়। নিচের টেবিলে দেখা যায় গতি কীভাবে সফলতার হারকে প্রভাবিত করে:

- `0`: 0% সফলতার হার।
- `1` থেকে `4`: 100% সফলতার হার।
- `5` থেকে `8`: 90% সফলতার হার।
- `9`: 80% সফলতার হার।
- `10`: 77% সফলতার হার।

আপনার তিনটি কাজ আছে।

## 1. সফলতার হার গণনা করুন

উৎপাদনের গতির ভিত্তিতে সফলতার হার গণনা করতে `successRate` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
successRate 6
// => 0.9
```

## 2. প্রতি ঘণ্টায় উৎপাদন হার গণনা করুন

সফলতার হার হিসাবে ধরে নিয়ে অ্যাসেম্বলি লাইনের প্রতি ঘণ্টায় উৎপাদন হার গণনা করতে `productionRatePerHour` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
productionRatePerHour 6
// => 1193.4
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `float`.

## 3. প্রতি মিনিটে উৎপাদিত কার্যকর গাড়ির সংখ্যা গণনা করুন

প্রতি মিনিটে কতটি কার্যকর গাড়ি তৈরি হয় তা গণনা করতে `workingItemsPerMinute` ফাংশনটি ইমপ্লিমেন্ট করুন:

```fsharp
workingItemsPerMinute 6
// => 19
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `int`.
