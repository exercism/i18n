# ইঙ্গিত

## 1. একজন কর্মীর জন্য ব্যাজ প্রিন্ট করুন

- বর্ণনামূলক স্ট্রিং তৈরি করতে [স্ট্রিং টেমপ্লেট][string-template] ব্যবহার করা যায়।
- স্ট্রিংকে বড় হাতের অক্ষরে রূপান্তর করার জন্য একটি [বিল্ট-ইন মেথড][to-upper-case] আছে।

## 2. একজন নতুন কর্মীর জন্য ব্যাজ প্রিন্ট করুন

- ব্যবহার করার আগে ID `null` কিনা তা যাচাই করা উচিত।
- একটি মান `null` কিনা তা যাচাই করতে আপনি একটি [সমানতা অপারেটর][kotlin-operators] ব্যবহার করতে পারেন।

## 3. মালিকের জন্য ব্যাজ প্রিন্ট করুন

- কোনো ভ্যারিয়েবল `null` হলে বিকল্প মান ব্যবহার করতে আপনি [এলভিস অপারেটর][elvis-operator] ব্যবহার করতে পারেন।
