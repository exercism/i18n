# সম্পর্কে

[`grouping`][grouping] এবং [`splitting`][splitting] থেকে পাওয়া চারটি ওয়ার্ড "একটি সিকোয়েন্সকে টুকরো টুকরো করা" ধরনের প্রায় প্রতিটি প্রয়োজন মিটিয়ে দেয়:

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| ওয়ার্ড              | প্রভাব                                                                  |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`, আলাদা আলাদা *n*-আকারের টুকরো                       |
| `clump`           | `( seq n -- clumps )`, ওভারল্যাপিং *n*-আকারের উইন্ডো                   |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`, quot সত্য হলে ভেঙে দেয়      |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`, *পাশাপাশি* জোড়ায় quot `f` হলে ভেঙে দেয় |

একটি দরকারি মানসিক মডেল:

- **`group` / `clump`** আকারের দিকে তাকায়; *n* প্যারামিটার ঠিক করে প্রতিটি উইন্ডো কত বড় হবে।
- **`split-when`** *একক এলিমেন্টের* দিকে তাকায়; প্রেডিকেট ঠিক করে প্রতিটি এলিমেন্ট "বিরতি" কি না।
- **`monotonic-split`** *জোড়ার* দিকে তাকায়; প্রেডিকেট ঠিক করে পাশাপাশি দুটি এলিমেন্ট একই ধারায় থাকবে কি না।
