# সম্পর্কে

C#-এ অ্যারে হলো প্রিমিটিভ মান বা স্ট্রাক্ট কিংবা ক্লাসের ইনস্ট্যান্সের কালেকশন। এগুলো বেস ক্লাস লাইব্রেরিতে [`List<T>`][lists-docs] হিসেবে ইমপ্লিমেন্ট করা হয়েছে, যেখানে `T` হলো অ্যারের আইটেমের টাইপ। API অ্যারে তৈরি ও ম্যানিপুলেট করার জন্য এক সমৃদ্ধ মেথড সেট প্রকাশ করে।

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

একটি কালেকশন ডেফিনিশনে সাধারণত অ্যাঙ্গেল ব্র্যাকেটের ভেতরে একটি প্লেসহোল্ডার থাকে, প্রচলিতভাবে প্রায়ই `T`। এটি কালেকশনের ব্যবহারকারীকে কালেকশনে কোন ধরনের আইটেম সংরক্ষণ করবেন তা নির্দিষ্ট করার সুযোগ দেয়।

[concept:csharp/arrays] এর বিপরীতে, অ্যারে নিজেদেরকে গতিশীলভাবে রিসাইজ করতে পারে।

## LINQ

যদিও `List<T>`-এর বিল্ট-ইন API সমৃদ্ধ (যেমন `ConvertAll`, `FindAll` ও `Foreach`-এর মতো ম্যাপিং ও ফিল্টার সহ) এবং এর [লুপিং সিনট্যাক্স][for-each] খুব স্পষ্ট, এবং এই API-এর সাথে আপনার অবশ্যই পরিচিত হওয়া দরকার, তবুও Language Integrated Query ([LINQ][linq]) অনেক কাজের জন্য উপলব্ধ, আরও শক্তিশালী ও বহুল ব্যবহৃত, এবং এর সুবিধা হলো এটি লাইব্রেরি কালেকশন, থার্ড-পার্টি কালেকশন এবং আপনার নিজের ক্লাসের মধ্যে একটি সামঞ্জস্যপূর্ণ ইন্টারফেস প্রদান করে।
