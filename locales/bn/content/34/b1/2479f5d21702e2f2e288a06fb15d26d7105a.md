# ভূমিকা

ইন্টিজারের উপর বিটওয়াইজ অপারেটরগুলো [`math.bitwise`][math.bitwise] মডিউলে থাকে:

```
bitand ( x y -- z )    ! AND
bitor  ( x y -- z )    ! OR
bitxor ( x y -- z )    ! XOR
bitnot ( x -- y )      ! NOT
shift  ( x n -- y )    ! left if n>0, right if n<0
```

```factor
USE: math.bitwise

12 10 bitand .    ! => 8
12 10 bitor .     ! => 14
1 4 shift .       ! => 16
16 -2 shift .     ! => 4
```

`even-parity?` এবং `odd-parity?` জানায় সেট বিটের সংখ্যা জোড় না বিজোড়:

```factor
USE: math.bitwise

5 even-parity? .    ! => t   (0b101 has two set bits)
5 odd-parity? .     ! => f
7 odd-parity? .     ! => t   (0b111 has three set bits)
```

একক বিটের জন্য সহায়ক ফাংশনও আছে: `bit?`, `set-bit`, `clear-bit`।

[math.bitwise]: https://docs.factorcode.org/content/vocab-math.bitwise.html
