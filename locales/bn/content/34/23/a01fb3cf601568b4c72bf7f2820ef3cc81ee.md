# টেস্ট

## টেস্ট চালানো
Haxe ট্র্যাকটি টেস্টিং ফ্রেমওয়ার্ক [Buddy](https://github.com/ciscoheat/buddy)-এর উপর নির্ভর করে।
এটি নিচের কমান্ড দিয়ে ইনস্টল করতে পারেন:

```bash
haxelib install buddy
```

টেস্ট চালাতে নিচের কমান্ডটি চালান:

```bash
haxe test.hxml
```

টেস্ট ফাইলে প্রতিটি `describe` ব্লক অনুশীলনীর টেস্টের একটি অংশ চিহ্নিত করে, আর প্রতিটি টেস্ট হলো একটি `it` বা `xit` ব্লক।
আপনি টেস্ট চালালে `it` ব্লকগুলো এক্সিকিউট হয়, কিন্তু `xit` ব্লকগুলো এমন টেস্ট, যেগুলো আপাতত চালানো হয় না।
আপনি যখন কোনো সলিউশন সাবমিট করেন, Exercism টেস্ট রানার সব `it` বা `xit` ব্লক চালায়।
লোকালি কাজ করার সময় ডিফল্টভাবে কেবল প্রথম টেস্টটি চালানো হয়।
অন্য টেস্টগুলো চালাতে হলে সংশ্লিষ্ট `xit` ব্লকগুলোকে `it` ব্লকে বদলে আবার `haxe test.hxml` চালান।


এছাড়া কিছু অনুশীলনীর ক্ষেত্রে haxelib দিয়ে অতিরিক্ত লাইব্রেরি ইনস্টল করার দরকার হতে পারে।
এমন হলে অনুশীলনীর নির্দেশনায় একটি নোট থাকবে।

## অনুশীলনী সমাধান করা

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
শুরু করার জন্য প্রতিটি অনুশীলনীর সঙ্গে একটি স্টাব ইমপ্লিমেন্টেশন ফাইল দেওয়া থাকে।
এই ফাইলটি আপনার সলিউশন গড়ে তোলার সূচনা বিন্দু হিসেবে ব্যবহার করতে পারেন।
এটি মুছে ফেলা বা পরিবর্তন করা ঠিক মনে হলে নিশ্চিন্তে তা করতে পারেন।
সলিউশনের দিকে এগোতে এগোতে একবারে একটি টেস্টে মনোযোগ দেওয়ার চেষ্টা করুন।
