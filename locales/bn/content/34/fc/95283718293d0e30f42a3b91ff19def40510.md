# নির্দেশনা

আপনি আগে যে স্টক ম্যানেজমেন্ট সিস্টেমটি তৈরি করেছিলেন, তার উপরেই কাজ চালিয়ে যাচ্ছেন। `OpenStruct` আর ব্লক শর্টকাট আবিষ্কার করার পর আপনি সিদ্ধান্ত নিয়েছেন কোডটি একটু রিফ্যাক্টর করবেন। আইটেমগুলো হ্যাশ হিসেবে সংরক্ষণ করার বদলে আপনি আপনার নতুন অর্জিত দক্ষতাগুলো কাজে লাগাবেন।

## 1. আইটেম রিট্রিভ করার সুযোগ দিন

আপনি স্টকে থাকা আইটেমের তালিকা রিট্রিভ করা চালিয়ে যেতে চান, তবে এবার সেগুলো এমন অবজেক্ট হওয়া উচিত, যেগুলোর উপর মেথড কল করা যাবে।

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. `item_names` রিফ্যাক্টর করুন

হ্যাশের বদলে আপনি যে নতুন ব্লক শর্টকাট শিখেছেন, তা ব্যবহার করতে `item_names` রিফ্যাক্টর করুন। মনে করিয়ে দেওয়ার জন্য, মেথডটি রিটার্ন করবে:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. `total_stock` রিফ্যাক্টর করুন

হ্যাশ রেফারেন্স করার বদলে OpenStruct-এর মেথড ব্যবহার করতে `total_stock` রিফ্যাক্টর করুন। মনে করিয়ে দেওয়ার জন্য, মেথডটি রিটার্ন করবে:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
