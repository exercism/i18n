# পরিচিতি

## Nil

Gleam-এ `Nil` হলো এমন একটি টাইপ, যার একটিই মান, যাকে-ও `Nil` বলা হয়। এটি অন্য ভাষার `void`-এর মতো, কারণ কোনো ফাংশনের রিটার্ন করার জন্য আর কোনো উপযুক্ত মান না থাকলে এটি ব্যবহার করা হয়।

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Gleam-এ মানগুলো অন্য কিছু ভাষার মতো "নিল-যোগ্য" বা "নাল-যোগ্য" নয়। কোনো মান কেবল তখনই `Nil` হতে পারে যখন তার টাইপ `Nil`, আর অন্য যেকোনো টাইপের মান কখনোই `Nil` হতে পারে না।

## IO

বেশিরভাগ প্রোগ্রামিং ভাষার মতোই Gleam-এও "সাইড এফেক্ট" আছে, তাই ফাংশনগুলো একটি মান রিটার্ন করার পাশাপাশি বাইরের জগতের অবস্থাও পড়তে ও বদলাতে পারে।

Gleam স্ট্যান্ডার্ড লাইব্রেরির `gleam/io` মডিউল কনসোলে স্ট্রিং প্রিন্ট করার ফাংশন দেয়।

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

অন্য প্যাকেজগুলো অন্য IO ফাংশনও দিতে পারে, যেমন `simplifile`, যা ফাইল পড়া ও লেখার ফাংশন দেয়।

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
