# ভূমিকা

Java-তে বুলিয়ান বোঝানো হয় `boolean` টাইপ দিয়ে, যার মান `true` অথবা `false` হতে পারে।

Java তিনটি বুলিয়ান অপারেটর সমর্থন করে:  

- `!` (NOT): বুলিয়ান মানটিকে উল্টে দেয়  
- `&&` (AND): দুটি বুলিয়ান নেয় এবং দুটোই ট্রু হলে ফলাফল ট্রু হয়  
- `||` (OR): দুটি বুলিয়ানের যেকোনো একটি ট্রু হলে ফলাফল ট্রু হয়  

## উদাহরণ

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
