# নির্দেশনা

এই অনুশীলনীতে আপনি একটি গাড়ির কারখানার অ্যাসেম্বলি লাইনের উৎপাদন বিশ্লেষণ করার কোড লিখবেন।
অ্যাসেম্বলি লাইনের গতি `0` (বন্ধ) থেকে `10` (সর্বোচ্চ) পর্যন্ত হতে পারে।

এর সর্বনিম্ন গতিতে (`1`), প্রতি ঘণ্টায় `221`টি গাড়ি উৎপাদিত হয়।
গতি বাড়ার সাথে সাথে উৎপাদন রৈখিকভাবে বাড়ে।
তাই গতি `4` নির্ধারণ করলে প্রতি ঘণ্টায় `4 * 221 = 884` গাড়ি উৎপাদিত হওয়া উচিত।
তবে বেশি গতিতে ত্রুটিপূর্ণ গাড়ি তৈরি হওয়ার সম্ভাবনা বেড়ে যায়, যেগুলোকে পরে বাদ দিতে হয়। 

আপনার সামনে তিনটি কাজ আছে।

## 1. সফলতার হার হিসাব করুন

নির্দিষ্ট একটি গতির জন্য ত্রুটি ছাড়া একটি আইটেম তৈরি হওয়ার অনুপাত হিসাব করতে (_static_) `AssemblyLine.SuccessRate()` মেথডটি ইমপ্লিমেন্ট করুন।
নিচের টেবিলটি দেখায় কীভাবে গতি সফলতার হারকে প্রভাবিত করে:

- `0`: ০% সফলতার হার।
- `1` থেকে `4`: ১০০% সফলতার হার।
- `5` থেকে `8`: ৯০% সফলতার হার।
- `9`: ৮০% সফলতার হার।
- `10`: ৭৭% সফলতার হার।

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. প্রতি ঘণ্টায় উৎপাদনের হার হিসাব করুন

অ্যাসেম্বলি লাইনের সফলতার হার বিবেচনায় নিয়ে প্রতি ঘণ্টায় তার উৎপাদনের হার হিসাব করতে (_static_) `AssemblyLine.ProductionRatePerHour()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `double`.

## 3. প্রতি মিনিটে উৎপাদিত কার্যকর আইটেমের সংখ্যা হিসাব করুন

প্রতি মিনিটে কতগুলো কার্যকর গাড়ি উৎপাদিত হয় তা হিসাব করতে (_static_) `AssemblyLine.WorkingItemsPerMinute()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

মনে রাখবেন, রিটার্ন করা মানটি একটি `int`.
