# নির্দেশনার সংযোজন

## IO প্রক্রিয়া

অন্য অনুশীলনীগুলোর থেকে আলাদা, `grep`-এর জন্য "বাইরের জগৎ"-এর সঙ্গে আন্তঃক্রিয়া করা প্রয়োজন: ফাইল পড়া, সিস্টেম এরর সামলানো আর `stdout`-এ প্রিন্ট করা।

Lean-এ সিস্টেমের সঙ্গে আন্তঃক্রিয়া সাধারণত [IO][io] মোনাডে করা হয়, যা একটি সীমাবদ্ধ পরিবেশে সাইড এফেক্ট ঘটতে দেয়, আর তাতে অন্য বেশিরভাগ ফাংশনের বিশুদ্ধ অবস্থা অক্ষত থাকে।

## আর্গুমেন্ট পড়া

Lean-এ একটি ফাইলকে স্ক্রিপ্ট হিসেবে চালানো যায়, হয় সরাসরি `lean --run` দিয়ে একটি স্বতন্ত্র স্ক্রিপ্ট হিসেবে, নয়তো `lake` ব্যবহার করে।

একটি Lean প্রজেক্টের প্রবেশবিন্দু একটিই, `main` নামের একটি ফাংশন, যা তার কাছে পাঠানো সব আর্গুমেন্টসহ একটি `List String` নেয়। এই অনুশীলনীতে `Grep.lean`-কে একটি এক্সিকিউটেবল হিসেবে চালানোর অনুকরণ করতে আর্গুমেন্ট একইভাবে পাঠানো হয়।

## ফাইল পড়া

ফাইল নিয়ে কাজ করার জন্য Lean `IO.FS` মোনাডে [ফাংশন][files] দেয়। যেমন, একটি নির্দিষ্ট পাথে থাকা ফাইলের বিষয়বস্তু একটি `String` হিসেবে পড়তে `IO.FS.readFile` ব্যবহার করা যায়।

## আউটপুট লেখা

মান রিটার্ন করার বদলে এই অনুশীলনীতে ফলাফল স্ট্যান্ডার্ড আউটপুট বা স্ট্যান্ডার্ড এররে লেখা প্রয়োজন। এ কাজের জন্য Lean-এ [ফাংশন][console] আছে।

## সিস্টেম এরর সামলানো

`Except`-এর এররগুলোর থেকে আলাদা, `IO`-এর এক্সেপশনগুলো আসলে রানটাইম এক্সেপশন। এগুলো সামলাতে আপনি `try`/`catch` ব্যবহার করতে পারেন:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
