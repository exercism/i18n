# পরিচিতি

Gleam-এ কনস্ট্যান্ট হলো মানের নাম দেওয়ার একটি উপায়। এগুলো `const` কিওয়ার্ড দিয়ে ডিফাইন করা হয়।

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

`pub` কিওয়ার্ড দিয়ে ডিফাইন করা হলে মডিউল কনস্ট্যান্টগুলো অন্য মডিউল থেকে অ্যাক্সেস করা যায়, অন্যথায় এগুলো কেবল যে মডিউলে ডিফাইন করা হয়েছে তার ভেতর থেকেই অ্যাক্সেস করা যায়।
