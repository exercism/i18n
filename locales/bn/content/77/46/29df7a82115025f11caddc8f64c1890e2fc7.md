# পরিচিতি

[ReScript][rescript-lang] দিয়ে লিখুন, JavaScript প্রকাশ করুন।
OCaml-এর মজবুত টাইপ সিস্টেমের ওপর গড়ে ওঠা এবং BuckleScript ও ReasonML-এর আধুনিক উত্তরসূরি ReScript, JavaScript ইকোসিস্টেমের ভেতরেই সম্পূর্ণ প্যাটার্ন ম্যাচিং আর কম্পাইল-টাইম নিশ্চয়তা দেয়।
যারা অ্যানোটেটেড JavaScript নয়, বরং সত্যিকারের টাইপ নিরাপত্তা চান, তাঁদের কাছে এর ফার্স্ট-ক্লাস React ইন্টিগ্রেশন এটিকে TypeScript-এর একটি আকর্ষণীয় বিকল্প করে তোলে।
কোনো `any` নেই, হঠাৎ করে আসা `undefined` নেই।

[rescript-lang]: https://rescript-lang.org
