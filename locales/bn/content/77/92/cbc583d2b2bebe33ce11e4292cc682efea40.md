# নির্দেশনা

আপনি একটি অনলাইন ফ্যাশন বুটিক চালান। আপনার বছরের বড় সেল আসছে, তাই ইনভেন্টরির হিসাব নিতে এবং সব ঠিকঠাক আছে কি না নিশ্চিত হতে কিছু ফাংশনালিটি তৈরি করতে চান।

ইনভেন্টরির একটি একক আইটেম প্রকাশ করা হয় একটি হ্যাশ দিয়ে, আর পুরো ইনভেন্টরি হলো এমন হ্যাশের একটি অ্যারে।

```ruby
[
  {
    name: "White Shirt",
    price: 40,
    quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}
  },
  { ... }
]
```

## 1. আইটেমগুলোর নামের একটি তালিকা রিটার্ন করুন

`BoutiqueInventory.item_names` ইমপ্লিমেন্ট করুন, যা আইটেমের নামগুলো বর্ণানুক্রমে সাজানো একটি তালিকা রিটার্ন করবে।

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

#=> ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 2. যেসব আইটেম সস্তা সেগুলো রিটার্ন করুন

`BoutiqueInventory.cheap` ইমপ্লিমেন্ট করুন, যা $30-এর কম দামের যেকোনো আইটেম রিটার্ন করবে।

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).cheap

# => [
#      {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
#      {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
#    ]
```

## 3. যেসব আইটেম স্টকে নেই সেগুলো রিটার্ন করুন

`BoutiqueInventory.out_of_stock` ইমপ্লিমেন্ট করুন, যা এমন সব আইটেম রিটার্ন করবে যেগুলোর কোনো স্টক নেই (যেখানে `quantity_by_size` খালি)।

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).out_of_stock

#=> [{price: 50.00, name: "Red Short Skirt", quantity_by_size: {}}]
```

## 4. একটি একক আইটেমের স্টক রিটার্ন করুন

নাম অনুসারে একটি আইটেমের স্টক রিটার্ন করতে `BoutiqueInventory.stock_for_item(name)` ইমপ্লিমেন্ট করুন:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).stock_for_item("Black Short Skirt")

#=> {s: 1, xl: 4}
```

## 5. মোট স্টক রিটার্ন করুন

আপনার স্টোররুমে থাকা মোট আইটেমের পরিমাণ হিসাব করতে `BoutiqueInventory.total_stock` ইমপ্লিমেন্ট করুন:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

#=> 36
```
