# ভূমিকা

## মৌলিক বিষয়

আমরা এখানে _ভাষাটিকে_ **AWK** এবং AWK প্রোগ্রাম ইন্টারপ্রেট করে এমন _এক্সিকিউটেবলটিকে_ **`awk`** বা **`gawk`** নামে ডাকব।

### প্যাটার্ন ও অ্যাকশন

একটি AWK প্রোগ্রাম তৈরি হয় **প্যাটার্ন-অ্যাকশন জোড়া** দিয়ে

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

একটি **প্যাটার্ন** ইনপুটের সাথে মেলানোর জন্য একটি রেগুলার এক্সপ্রেশন প্যাটার্ন হতে পারে।
এটি এমন যেকোনো এক্সপ্রেশনও হতে পারে যার ফলাফল ট্রু/ফলস মান হয়।

একটি **অ্যাকশন** হলো এক বা একাধিক AWK কমান্ড।
ঘিরে থাকা বন্ধনী দুটি অবশ্যই দিতে হবে।

প্যাটার্নের ফলাফল যদি _ট্রু_ হয়, তাহলে সংশ্লিষ্ট অ্যাকশনটি চালানো হয়।

### রেকর্ড ও ফিল্ড

AWK ইনপুটকে একের পর এক **রেকর্ড** হিসেবে পার্স করে।
প্রতিটি রেকর্ড শূন্য বা ততোধিক **ফিল্ড**-এ ভাগ করা হয়।

ডিফল্ট আচরণ হলো:

- "রেকর্ড সেপারেটর" হিসেবে নিউলাইন ব্যবহার করে ইনপুটকে রেকর্ডে ভাগ করা হয়, তাই প্রতিটি _লাইন_ হলো একটি রেকর্ড।
- "ফিল্ড সেপারেটর" হিসেবে হোয়াইটস্পেস ব্যবহার করে রেকর্ডটিকে ফিল্ডে ভাগ করা হয়, তাই প্রতিটি _শব্দ_ হলো একটি ফিল্ড।

### প্যাটার্ন ও অ্যাকশন, পরবর্তী অংশ

প্যাটার্ন বাদ দেওয়া যায়; সেক্ষেত্রে _প্রতিটি ইনপুট রেকর্ডের জন্য_ অ্যাকশনটি চালানো হয়।

অ্যাকশনও বাদ দেওয়া যায়; সেক্ষেত্রে ডিফল্ট অ্যাকশন হলো বর্তমান রেকর্ডটি প্রিন্ট করা।

#### বিশেষ প্যাটার্ন

এমন দুটি বিশেষ প্যাটার্ন আছে যেগুলো প্রায়ই ব্যবহার করা হয়।

- কোনো ইনপুট ব্যবহার হওয়ার আগে `BEGIN` সংশ্লিষ্ট অ্যাকশনটি চালায়।
- সমস্ত ইনপুট ব্যবহার হয়ে যাওয়ার পর `END` সংশ্লিষ্ট অ্যাকশনটি চালায়।

### ফিল্ড ভ্যারিয়েবল

ফিল্ডগুলো বোঝাতে আপনি `$1`, `$2`, `$3` ইত্যাদি ব্যবহার করেন।

বর্তমান রেকর্ডটি হলো `$0`।

এখানে আরও কিছু প্রায়ই ব্যবহৃত বিল্ট-ইন ভ্যারিয়েবল আছে।

#### ইনপুট পার্সিং নিয়ন্ত্রণ করে এমন বিল্ট-ইন ভ্যারিয়েবল

- `RS` হলো ইনপুট রেকর্ড সেপারেটর।
  আগেই বলা হয়েছে, এর ডিফল্ট মান একটি নিউলাইন।
- `FS` হলো ইনপুট ফিল্ড সেপারেটর।

এই ভ্যারিয়েবলগুলো প্রায়ই `BEGIN` অ্যাকশন ব্লকে সেট করা হয়।

#### তথ্য বহন করে এমন বিল্ট-ইন ভ্যারিয়েবল

প্রোগ্রাম চালানোর সময় AWK এই ভ্যারিয়েবলগুলো স্বয়ংক্রিয়ভাবে সেট করে।

- `NF` বর্তমান রেকর্ডে থাকা ফিল্ডের সংখ্যা সংরক্ষণ করে।
  - শেষ ফিল্ডের মান পেতে `$NF` ব্যবহার করুন।
- `NR` বর্তমান রেকর্ড নম্বর সংরক্ষণ করে।
  - একাধিক ইনপুট ফাইল প্রসেস করা হলে, `NR` এতক্ষণ প্রসেস করা মোট রেকর্ড সংখ্যা ধরে রাখবে।
- `FNR` বর্তমান ইনপুট ফাইলের বর্তমান রেকর্ড নম্বর সংরক্ষণ করে।
  - NR আর FNR-এর পার্থক্য বোঝাতে, এখানে একটি কমন AWK আইডিয়ম দেওয়া হলো।
    ```awk
    NR == FNR {action}
    ```
    এর অর্থ হলো "যদি জমে থাকা রেকর্ড নম্বর বর্তমান ফাইলের রেকর্ড নম্বরের সমান হয়।"
    এটি শুধু _প্রথম ইনপুট ফাইলের_ রেকর্ডের ক্ষেত্রেই ট্রু হতে পারে।

### ট্রুথিনেস

AWK-এ ট্রুথিনেসের ধারণাটি C-এর মতোই।

- সংখ্যা `0` হলো ফলস।
- অন্য যেকোনো সংখ্যা হলো ট্রু।

যেহেতু AWK একটি টেক্সট-প্রসেসিং ভাষা, তাই ট্রু/ফলস মান স্ট্রিং-এও প্রসারিত করা হয়েছে।

- খালি স্ট্রিং `""` হলো ফলস।
- যেকোনো অখালি স্ট্রিং হলো ট্রু।

### কমেন্ট

কমেন্ট শুরু হয় `#` ক্যারেক্টার দিয়ে এবং লাইনের শেষ পর্যন্ত বিস্তৃত থাকে।

### উদাহরণ

ইউনিক্স-সদৃশ সিস্টেমে `/etc/passwd` ফাইলে ব্যবহারকারীদের তথ্য থাকে।
প্রতিটি ব্যবহারকারী আলাদা লাইনে বর্ণিত থাকে, আর ফিল্ডগুলো কোলন দিয়ে আলাদা করা থাকে।

ইউজারনেমগুলো তালিকাভুক্ত করতে:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

খেয়াল করুন, `{print $1}` অ্যাকশনে কোনো প্যাটার্ন নেই, তাই এটি প্রতিটি রেকর্ডের জন্য চালানো হয়।

যদি আমরা আউটপুট শুধু সেইসব ব্যবহারকারীর মধ্যে সীমাবদ্ধ করতে চাই যারা লগইন শেল হিসেবে bash ব্যবহার করেন, তাহলে এভাবে করা যায়:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
