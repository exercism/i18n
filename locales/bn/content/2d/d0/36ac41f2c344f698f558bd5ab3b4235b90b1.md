# নির্দেশনা

আপনি একটি পাখি জরিপে সাহায্য করছেন। প্রতিদিন কেউ একটি আড়ালে বসে কী কী উড়ে যায় তা গোনে, আর সেই দিনের গণনাগুলো একটি অ্যারে হিসেবে ফিরে আসে।

পাঁচটি কাজই `BIRD_SURVEY` ক্লাসে থাকবে।

## 1. মোট

প্রতিটি দিনের গণনা যোগ করুন।

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

একেবারে দিন না থাকা জরিপে শূন্য পাখি গোনা হয়।

## 2. সেরা দিন

সবচেয়ে বড় গণনাটি রিটার্ন করুন। কোনো দিন না থাকলে উত্তর শূন্য।

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. ব্যস্ত দিনগুলো

কত দিনের গণনা একটি নির্দিষ্ট সংখ্যার বেশি ছিল?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

বেশি মানে সত্যিই বেশি: ঠিক ২-এর গণনা এখানে ধরা হয় না।

## 4. যাচাই করার আড়াল

জরিপের প্রথম দিনে আপনি একটি আড়াল যাচাই করেন, দ্বিতীয় দিনে দুটি, এভাবে চলতে থাকে। মোট কতবার আড়াল যাচাই করা হলো?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

এটাই ১ + ২ + ৩ + ৪।

## 5. প্রথম ব্যস্ত দিন

কোন দিনটি প্রথম যার গণনা একটি নির্দিষ্ট সংখ্যার বেশি ছিল? অ্যারের অবস্থানগুলোর মতোই দিনগুলো শূন্য থেকে গোনা হয়। কোনো দিনই এত ব্যস্ত না থাকলে উত্তর `-1`।

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
