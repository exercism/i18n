# সম্পর্কে

Swift-এ লুপ ও switch স্টেটমেন্টের এক্সিকিউশন ফ্লো বদলানোর জন্য কন্ট্রোল ট্রান্সফার স্টেটমেন্ট রয়েছে। `return` ছাড়াও Swift-এ আছে `continue`, `break`, লুপ লেবেল এবং `fallthrough`।

## Continue

`continue` স্টেটমেন্টটি লুপকে চলতি ইটারেশনের কাজ বন্ধ করে সঙ্গে সঙ্গে পরের ইটারেশন শুরু করতে বলে। `while` বা `repeat-while` লুপে এটি সরাসরি শর্ত পরীক্ষায় চলে যায়। `for-in` লুপে এটি সিকোয়েন্সের পরের এলিমেন্টে এগিয়ে যায়।

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break` স্টেটমেন্টটি পুরো একটি লুপ বা switch স্টেটমেন্ট থেকে সঙ্গে সঙ্গে বেরিয়ে যায়। এরপর এক্সিকিউশন লুপ বা switch-এর পরের প্রথম কোড লাইন থেকে আবার চলতে থাকে।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## লেবেলযুক্ত স্টেটমেন্ট

নেস্টেড লুপে কখনও আপনি চাইতে পারেন, `break` বা `continue` সবচেয়ে ভেতরের লুপে নয়, বরং বাইরের কোনো লুপে কাজ করুক। লুপের আগে একটি নাম ও একটি কোলন (`labelName:`) বসিয়ে লুপটিতে লেবেল দেওয়া যায়। এরপর সেই লেবেলটি `break` বা `continue`-কে দিয়ে দেওয়া যায়:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

Swift-এ `switch` স্টেটমেন্ট ডিফল্টভাবে পরের কেসে চলে যায় না; মিলে যাওয়া কেসের শেষেই এক্সিকিউশন স্বয়ংক্রিয়ভাবে থেমে যায়। আপনি যদি স্পষ্টভাবে চান যে, পরের কেসের প্যাটার্ন যাচাই না করেই এক্সিকিউশন তার ভেতরে চলতে থাকুক, তাহলে `fallthrough` কিওয়ার্ডটি ব্যবহার করুন:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
