# পরিচিতি

পুরো Julia ট্র্যাক জুড়ে আপনাকে আপনার সলিউশনকে ছোট ছোট লাইব্রেরির মতো ভাবতে হবে, অর্থাৎ আপনাকে ফাংশন, টাইপ ইত্যাদি ডিফাইন করতে হবে, যা পরে একটি টেস্ট স্যুটের বিরুদ্ধে রান করা হবে।
সেই কারণেই আমরা একেবারে প্রথম কনসেপ্ট হিসেবে নামযুক্ত ফাংশন নিয়ে আলোচনা করব।

Julia একটি ডাইনামিক, স্ট্রংলি টাইপড প্রোগ্রামিং ভাষা।
এর প্রোগ্রামিং স্টাইল মূলত ফাংশনাল, তবে Haskell-এর মতো ভাষার তুলনায় এতে আরও বেশি নমনীয়তা আছে।

## ভ্যারিয়েবল ও অ্যাসাইনমেন্ট

আগে থেকে কোনো ভ্যারিয়েবল ডিক্লেয়ার করার দরকার নেই।
শুধু একটি উপযুক্ত নামে একটি মান অ্যাসাইন করে দিলেই হয়:

```julia-repl
julia> myvar = 42  # an integer
42

julia> name = "Maria"  # strings are surrounded by double-quotes ""
"Maria"
```

## কনস্ট্যান্ট

যদি কোনো মান পুরো প্রোগ্রাম জুড়ে পাওয়া দরকার হয়, কিন্তু সেটি বদলানোর কথা না থাকে, তাহলে সেটিকে কনস্ট্যান্ট হিসেবে চিহ্নিত করাই ভালো।

কোনো অ্যাসাইনমেন্টের আগে `const` কিওয়ার্ড বসালে কম্পাইলার আরও দক্ষ কোড তৈরি করতে পারে, যা একটি ভ্যারিয়েবলের ক্ষেত্রে সম্ভব নয়।

কনস্ট্যান্ট কোডিংয়ের ভুল থেকে আপনাকে রক্ষা করতেও সাহায্য করে।
ভুলে `const` মানটি বদলাতে গেলে একটি ওয়ার্নিং দেখতে পাবেন:

```julia-repl
julia> const answer = 42
42

julia> answer = 24
WARNING: redefinition of constant Main.answer. This may fail, cause incorrect answers, or produce other errors.
24
```

মনে রাখবেন, একটি `const` কেবল যেকোনো ফাংশনের *বাইরে* ডিক্লেয়ার করা যায়।
এটি সাধারণত `*.jl` ফাইলের একেবারে উপরের দিকে, ফাংশন ডেফিনিশনের আগে থাকে।

## গাণিতিক অপারেটর

এগুলো অন্য অনেক ভাষার মতোই:

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division with floating-point result)
8 % 3  # 2 (remainder)
```

## ফাংশন

Julia-তে একটি নামযুক্ত ফাংশন ডিফাইন করার দুটি প্রচলিত উপায় আছে:

1. `function` কিওয়ার্ড ব্যবহার করে

    ```julia
    function muladd(x, y, z)
        x * y + z
    end
    ```

    পড়ার সুবিধার জন্য ৪ স্পেস ইন্ডেন্টেশন প্রচলিত রীতি, কিন্তু কম্পাইলার এটি উপেক্ষা করে।
    `end` কিওয়ার্ডটি অবশ্যই লাগবে।

    খেয়াল করুন, আমরা চাইলে `return x * y + z` লিখতেও পারতাম।
    তবে Julia-র ফাংশন সবসময় সর্বশেষ মূল্যায়িত এক্সপ্রেশনটিই রিটার্ন করে, তাই `return` কিওয়ার্ডটি ব্যবহার করা বাধ্যতামূলক নয়।
    অনেক প্রোগ্রামার তাদের উদ্দেশ্য আরও স্পষ্ট করতে এটি লেখা পছন্দ করেন।

2. "অ্যাসাইনমেন্ট ফর্ম" ব্যবহার করে

    ```julia
    muladd(x, y, z) = x * y + z
    ```

    সংক্ষিপ্ত, এক-এক্সপ্রেশনবিশিষ্ট ফাংশন বানানোর জন্য এটি সবচেয়ে বেশি ব্যবহৃত হয়।

    অ্যাসাইনমেন্ট ফর্মে `return` কিওয়ার্ড *কখনোই* ব্যবহার করা হয় না।

দুটি ফর্মই সমতুল্য এবং ঠিক একইভাবে ব্যবহৃত হয়, তাই যেটি পড়তে বেশি সুবিধাজনক বলে মনে হয়, সেটিই বেছে নিন।

কোনো ফাংশন কল করতে হলে তার নাম লিখে ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাঠাতে হয়:

```julia
# invoking a function
muladd(10, 5, 1)

# and of course you can invoke a function within the body of another function:
square_plus_one(x) = muladd(x, x, 1)
```

## নামকরণের রীতি

অনেক ভাষার মতোই, Julia-তে নাম (ভ্যারিয়েবল, ফাংশন এবং আরও অনেক কিছুর) একটি অক্ষর দিয়ে শুরু হতে হয়, তারপর অক্ষর, সংখ্যা ও আন্ডারস্কোরের যেকোনো সমন্বয় বসতে পারে।

প্রচলিত রীতি অনুযায়ী, ভ্যারিয়েবল, কনস্ট্যান্ট ও ফাংশনের নাম *ছোট হাতের অক্ষরে* লেখা হয় এবং আন্ডারস্কোর যতটা সম্ভব কম রাখা হয়।
