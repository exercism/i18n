# সম্পর্কে

[concept:csharp/resource-cleanup]() কোনো ক্লাসের কলারদের কাছে সংকেত দিতে `IDispose` ইন্টারফেস ব্যবহার করে যে এমন কিছু রিসোর্স বা প্রোগ্রাম-স্টেট আছে, যা ওই অবজেক্টটির আর প্রয়োজন না থাকলে সময়মতো ছেড়ে দিতে বা রিসেট করতে হয়। এই অনুশীলনীতে আমরা `using` কিওয়ার্ড দিয়ে কিছু সিনট্যাকটিক শুগার এনেছি, যা কোডকে কম কথা-বহুল করে এবং গুরুত্বপূর্ণ কল বাদ পড়ার সম্ভাবনা কমায়।

`using`-কে কিছু ক্ষেত্রে [`try/finally`][try-finally] এর বিকল্প হিসেবে দেখা যেতে পারে।

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

এই সিনট্যাক্সটির বদলে আসে আরও সংক্ষিপ্ত ও নিরাপদ রূপ:

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

লক্ষ্য করুন, এক লাইনের ব্লকের স্বাভাবিক নিয়ম মেনে একাধিক রিসোর্স সুবিধাজনকভাবে একসাথে জোড়া যায়:

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

C# 8-এ নিচের ভ্যারিয়েশনটি এসেছে, যেখানে `using` স্টেটমেন্টটি একটি ব্লকের শুরুতে বসে:

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

এটি দিয়ে আপনি একই ব্লকে একাধিক ডিসপোজেবল অবজেক্ট রাখতে পারেন এবং আরও স্বাভাবিকভাবে [`try/catch`][try-catch] সামলাতে পারেন:

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

`using` কিওয়ার্ড কীভাবে ব্যবহার করা যায় এবং কোন ধরনের টাইপের ইনস্ট্যান্সের সাথে, তার নিয়মগুলো [এখানে][using-statement] বিস্তারিত আছে।

## Java ডেভেলপারদের জন্য নোট

Java ডেভেলপাররা এটিকে Java 7-এ আসা [_automatic resource management_][automatic-resource-management] মেকানিজমের সমতুল্য হিসেবে চিনতে পারেন। দুটো বেশ একই রকম। Java-র সিনট্যাক্স, যা `try`-কে নতুনভাবে কাজে লাগায়, C#-এর `using`-এর চেয়ে বেশি স্বাভাবিকভাবে `catch` ব্লক যুক্ত করার সুবিধা দেয়।

## ভার্সনসমূহ

মনে রাখবেন, `using`-এর আরও নমনীয় ভার্সনটি, যেখানে এর নিজের কোনো সিনট্যাকটিক ব্লক থাকে না, C# 8-এ এসেছে; তাই আপনি যে কোডবেসে কাজ করছেন সেটি C# 8 বা তার পরের কোনো সংস্করণ ব্যবহার করছে কি না তা যাচাই করে নিতে হতে পারে।
