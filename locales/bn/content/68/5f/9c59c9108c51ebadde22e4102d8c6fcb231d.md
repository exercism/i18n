# নির্দেশনা

আপনার বন্ধু Linus একজন লোকোমোটিভ ইঞ্জিনিয়ার, যিনি শহরগুলোর মধ্যে মালবাহী ট্রেন চালান।
ট্রেন সামলানোয় তিনি দুর্দান্ত হলেও, লজিস্টিকস বা কম্পিউটার সামলানোয় ঠিক তেমন দুর্দান্ত নন।
ট্রেনের তথ্য গুছিয়ে রাখতে এবং রুট ডেটার ভুল সংশোধন করতে তিনি আপনার প্রোগ্রামিং সহায়তা নিতে চান।

~~~~exercism/note
এই অনুশীলনীটি স্লাইসিং, ইনডেক্সিং আর বিভিন্ন `hash` মেথড ব্যবহার করেও সহজে সমাধান করা যেত।
তবে নিচের প্রতিটি কাজ সমাধান করার সময় আমরা চাই আপনি প্যাকিং, আনপ্যাকিং আর মাল্টিপল অ্যাসাইনমেন্ট অনুশীলন করুন।
~~~~

## 1. সব ওয়াগনের একটি অ্যারে তৈরি করুন

আপনার বন্ধু প্রতিটি ওয়াগনের আইডেন্টিফায়ার (ID) হিসাব রাখছেন, কিন্তু সিস্টেমকে যে কোনো সময়ে কতগুলো ওয়াগন প্রসেস করতে হবে তা তিনি কখনোই নিশ্চিত নন।
এই ডেটাকে একটি একীভূত **অ্যারে**তে প্যাক করে রাখলে বাকি লজিস্টিকস প্রোগ্রামের জন্য কাজ অনেক সহজ হতো।

এমন একটি মেথড `generate_list_of_wagons()` বাস্তবায়ন করুন, যেটি ইচ্ছেমতো সংখ্যক ওয়াগন ID গ্রহণ করে।
প্রতিটি ID একটি ধনাত্মক ইন্টিজার হবে।
এরপর মেথডটি প্রদত্ত IDগুলোকে একটি একক **অ্যারে** হিসেবে `return` করবে।

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. ওয়াগনের অ্যারে ঠিক করুন

এই পর্যায়ে আপনি ডেটা এবং লজিস্টিকস প্রোগ্রামে এটি কীভাবে ব্যবহৃত হয় সে সম্পর্কে একটা ধারণা পেতে শুরু করেছেন।
ID সিস্টেম সবসময় লোকোমোটিভকে **1** আইডি দেয়, আর ট্রেনের বাকি ওয়াগনগুলোকে **1**-এর চেয়ে বড় এলোমেলোভাবে বেছে নেওয়া একটি ID দেয়।

আপনার বন্ধুকে ট্রেনে দুটি নতুন ওয়াগন জুড়তে হয়েছিল, কিন্তু সিস্টেম আপডেট করতে ভুলে গেছেন!
এখন ট্রেনের **অ্যারে**তে থাকা প্রথম দুটি ওয়াগনকে শেষে সরাতে হবে, নইলে সবকিছু এলোমেলো হয়ে যাবে।

ব্যাপারটা আরও জটিল করতে, আপনার বন্ধু সম্প্রতি একটি দ্বিতীয় **অ্যারে** খুঁজে পেয়েছেন, যাতে হারিয়ে যাওয়া ওয়াগন ID আছে বলে মনে হচ্ছে।
তিনি শুধু এটুকু মনে করতে পারছেন যে নতুন ওয়াগনগুলো সরানোর পর, এই দ্বিতীয় **অ্যারে**র IDগুলোকে নির্ধারিত লোকোমোটিভের ঠিক পরেই বসাতে হবে।

তাঁর ভুলগুলো সংশোধন করে এবং ডেটা একত্রিত করে দিলে Linus আপনার কাছে সত্যিই কৃতজ্ঞ থাকবেন।

এমন একটি মেথড `fix_list_of_wagons()` বাস্তবায়ন করুন, যেটি ওয়াগন ID ধারণ করা দুটি **অ্যারে** নেয়।
এটি প্রথম **অ্যারে**র প্রথম দুটি আইটেমকে শেষে সরিয়ে নেবে, এবং দ্বিতীয় **অ্যারে**র মানগুলো লোকোমোটিভ ID (**1**)-এর পিছনে (_অর্থাৎ ডান দিকে_) বসাবে।
এরপর মেথডটি পরিবর্তনগুলোসহ একটি **অ্যারে** `return` করবে।

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. অনুপস্থিত স্টপ যোগ করুন

এখন সব ওয়াগন ডেটা সঠিক, Linus চান আপনি সিস্টেমের রুটিং তথ্য আপডেট করুন।
একটি পরিবহন রুটে ট্রেন হয়তো মাল তুলতে বা নামাতে কয়েকটি আলাদা স্টেশনে থামতে পারে।
প্রতিটি যাত্রায় এই ধরনের মধ্যবর্তী ডেলিভারি পয়েন্টের সংখ্যা আলাদা হতে পারে।
আপনার বন্ধু চান আপনি সিস্টেমের রুটিং **হ্যাশ** আপডেট করুন, যাতে অনুপস্থিত বা অতিরিক্ত ডেলিভারি তথ্য যুক্ত হয়।

এমন একটি মেথড `add_missing_stops()` বাস্তবায়ন করুন, যেটি একটি রুটিং **হ্যাশ** এবং তারপর পরিবর্তনশীল সংখ্যক কিওয়ার্ড আর্গুমেন্ট গ্রহণ করে।
এই আর্গুমেন্টগুলো এক বা একাধিক স্টপ ধারণ করা একটি **হ্যাশ** আকারে হতে পারে, অথবা যেকোনো সংখ্যক `stop_<number>: "city"` কিওয়ার্ড জোড়া আকারে হতে পারে।
এরপর আপনার মেথডটি রুটিং **হ্যাশ** ফেরত দেবে, যাতে যোগ করা সব স্টপ ক্রমানুসারে ধারণ করা একটি বাড়তি **কী (key)** যুক্ত থাকবে।

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
স্টপগুলো সবসময় সঠিক ক্রমেই পাঠানো হবে, তাই সেগুলো সাজিয়ে ফেলার চিন্তা আপনার করতে হবে না।
~~~~

## 4. রুটিং তথ্য প্রসারিত করুন

Linus রুটিং প্রোগ্রাম নিয়ে কাজ করছেন এবং লক্ষ্য করেছেন যে কিছু রুটে গুরুত্বপূর্ণ কিছু বিবরণ অনুপস্থিত।
প্রাথমিক রুট তথ্য একটি **হ্যাশ** হিসেবে তৈরি করা হয়েছে, আর আপনার বন্ধু চান আপনি যা যা অনুপস্থিত থাকতে পারে তা দিয়ে ওই **হ্যাশ** আপডেট করুন।
সিস্টেমের প্রতিটি রুটে কিছুটা আলাদা বিবরণ দরকার হয়, তাই Linus সত্যিই একটি জেনেরিক সমাধান চান।

`extend_route_information()` নামের একটি মেথড বাস্তবায়ন করুন, যেটি দুটি **হ্যাশ** গ্রহণ করে।
প্রথম **হ্যাশ**-এ ট্রেন রুটটির উৎস ও গন্তব্য শহর থাকে।

দ্বিতীয় **হ্যাশ**-এ ট্রেনের গতি, দৈর্ঘ্য বা তাপমাত্রার মতো অন্যান্য রুটিং বিবরণ থাকে।
মেথডটি সব রুটিং তথ্যসহ একটি সমন্বিত **হ্যাশ** ফেরত দেবে।

~~~~exercism/note
দ্বিতীয় **হ্যাশ**-এ উদাহরণে দেখানো বৈশিষ্ট্যগুলোর চেয়ে ভিন্ন বা বেশি বৈশিষ্ট্য থাকতে পারে।
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
