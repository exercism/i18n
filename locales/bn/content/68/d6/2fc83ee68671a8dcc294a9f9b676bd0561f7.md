# ট্রেইট

একটি ট্রেইট এমন মেথডের একটি সেট নির্দিষ্ট করে, যা একটি টাইপ ইমপ্লিমেন্ট করতে পারে।
একাধিক টাইপের মধ্যে শেয়ার করা উচিত এমন মেথড ডিফাইন করার জন্য ট্রেইট দরকারি।
জেনেরিক টাইপের সাথে ট্রেইট ব্যবহার করলে, ডিফাইন করা মেথডগুলো কোনো নির্দিষ্ট টাইপে কল করা যায়, আবার অন্য ডেটা টাইপেও সেগুলো কল করা সম্ভব।
আরও বিমূর্তভাবে বললে, _ট্রেইট বাউন্ড_ ব্যবহার করে আমরা নির্দিষ্ট করতে পারি যে জেনেরিক টাইপটিকে অবশ্যই নির্দিষ্ট কিছু আচরণ শেয়ার করতে হবে।

> **নোট:** অন্য প্রোগ্রামিং ভাষায় যাকে ইন্টারফেস বলা হয়, ট্রেইটের বৈশিষ্ট্য অনেকটা সেরকমই, তবে কিছু পার্থক্য আছে।

## ট্রেইটের সংজ্ঞা

একটি ট্রেইট ডিফাইন করলে যে ফাংশন সিগনেচারগুলো দিয়ে একটি টাইপ ফলাফল পেতে প্রয়োজনীয় আচরণের সেট ইমপ্লিমেন্ট করে, সেগুলো চিহ্নিত করা যায়।
এই মেথডগুলোই একটি টাইপের আচরণ গঠন করে।
যদি ভিন্ন ভিন্ন টাইপে একই মেথড কল করা যায়, তবে বোঝা যায় জড়িত টাইপগুলোর আচরণও একই।

```rust
#[derive(Drop)]
pub struct NewsArticle {
    pub headline: ByteArray,
    pub location: ByteArray,
    pub author: ByteArray,
    pub content: ByteArray,
}

// A trait for NewsArticle struct type
pub trait Summary {
    fn summarize(self: @NewsArticle) -> ByteArray;
}
```

উপরের `Summary` ট্রেইটের সংজ্ঞা অনুযায়ী, `summarize` মেথড এমন একটি আচরণ, যা কেবল `NewsArticle` স্ট্রাক্ট টাইপেই কল করা যায়।
অন্য টাইপের ইনস্ট্যান্সে এটি কল করলে একটি কম্পাইলেশন এরর হয়।
`pub` কিওয়ার্ড দিয়ে ট্রেইট ডিক্লেয়ার করলে এই ক্রেটের ট্রেইটটি অন্য ক্রেটগুলোর জন্যও উন্মুক্ত হয়, যারা ট্রেইটটি ব্যবহার করতে চায়।
লক্ষ্য করুন, ট্রেইটে মেথড সিগনেচার ডিক্লেয়ার করার পরে আমরা একটি সেমিকোলন ব্যবহার করি।

জেনেরিক আর্গুমেন্ট দিয়ে একটি ট্রেইট ডিফাইন করা যায়, যার ফলে একটি ফাংশন যেকোনো ডেটা টাইপের আর্গুমেন্ট নিতে পারে।
এতে ফাংশন সিগনেচারে একধরনের নমনীয়তা আসে, ফলে সেগুলো বিভিন্ন ধরনের ডেটা টাইপ সামলাতে পারে।
নিচের `Summary` ট্রেইটের ক্ষেত্রে এটি যেকোনো ডেটা টাইপের জন্য কাজ করার মতো করে নতুন করে সাজানো হয়েছে, যাতে সেগুলোতে `summarize` মেথড কল করলে তা একটি ByteArray রিটার্ন করে।

```rust
// A trait for a generic type
pub trait Summary<T> {
    fn summarize(self: @T) -> ByteArray;
}
```

একটি ট্রেইটের বডিতে একাধিক মেথড থাকতে পারে; ডিক্লেয়ার করা প্রতিটি মেথড সিগনেচার এক লাইনের, যা সেমিকোলনে শেষ হয়।

## একটি টাইপে ট্রেইটের ইমপ্লিমেন্টেশন

একটি ট্রেইট গঠন করে এমন ফাংশন সিগনেচারগুলো ডিফাইন করার পর, কম্পাইলার নিশ্চিত করবে যে যে টাইপগুলো ট্রেইটটি গ্রহণ করে, সেগুলোর জন্য একটি ইমপ্লিমেন্টেশনও ডিফাইন করা হয়েছে।
নিচে আমরা একটি মিডিয়া `aggregator` লাইব্রেরি ক্রেট লিখেছি, যা `NewsArticle` ও `Tweet`-এর ইনস্ট্যান্স থেকে কিছু ডেটা সামারাইজ করে।
`NewsArticle` স্ট্রাক্টের ক্ষেত্রে আমরা `Summary` ট্রেইটের `summarize` মেথডের মান রিটার্ন করতে headline, author ও location ব্যবহার করব; আর `Tweet` স্ট্রাক্টের ক্ষেত্রে ব্যবহার করব username ও content, ধরে নিয়ে যে টুইটের কনটেন্টের ২৮০ ক্যারেক্টার সীমা আছে।

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray;
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {
        fn summarize(self: @NewsArticle) -> ByteArray {
            format!("{} by {} ({})", self.headline, self.author, self.location)
        }
    }

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    let tweet = Tweet {
        username: "EliBenSasson",
        content: "Crypto is full of short-term maximizing projects. \n @Starknet and @StarkWareLtd are about long-term vision maximization.",
        reply: false,
        retweet: false
    };

    println!("New article available! {}", news.summarize());
    println!("New tweet! {}", tweet.summarize());
}
```

## ডিফল্ট ইমপ্লিমেন্টেশন

কখনও কখনও একটি ট্রেইটের কিছু বা সব মেথডের জন্য একটি ডিফল্ট ইমপ্লিমেন্টেশন দিয়ে ট্রেইট ডিফাইন করা যায়।
এটি করা হয় যাতে প্রতিটি টাইপে সব মেথডের ইমপ্লিমেন্টেশন বাধ্যতামূলক করতে না হয় এবং কোড আরও পড়ার উপযোগী হয়।
কোনো নির্দিষ্ট টাইপে যদি ট্রেইটের কোনো মেথডের বিশেষ ইমপ্লিমেন্টেশন দরকার হয়, তবে সেটি ডিফল্ট ইমপ্লিমেন্টেশনটি ওভাররাইড করতে পারে।

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray {
            "(Read more...)"
        }
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {}

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    println!("New article available! {}", news.summarize()); // prints "New article available! (Read more...)"


    let tweet = Tweet {
        username: "Alice",
        content: "Cairo is fun and engaging.",
        reply: true,
        retweet: true,
    };
    println!("New tweet from {}", tweet.summarize()); // prints "New tweet from Alice: Cairo is fun and engaging."
}
```

## বাইরের ট্রেইট কীভাবে ব্যবহার ও পরিচালনা করা যায়

ট্রেইট ও ইমপ্লিমেন্টেশন বাইরের কোনো মডিউলে ডিফাইন করে অন্য মডিউলে ব্যবহার করা যায়, যতক্ষণ সেগুলো ঠিকভাবে ইমপোর্ট করা হয়।
ধরা যাক, আমাদের কাছে `ShapeGeometry` নামের একটি ট্রেইট আছে, যার `boundary` মেথডটি `Circle` ও `Rectangle` স্ট্রাক্ট দুটোতেই ইমপ্লিমেন্ট করতে হবে।
নিচে একটি উদাহরণ দেওয়া হলো, যেখানে দেখা যায় কীভাবে ট্রেইট ও ইমপ্লিমেন্টেশন বিভিন্ন মডিউলে ইমপোর্ট, পরিচালনা ও ব্যবহার করা হয়।

```rust
// Here T is an alias type which will be provided during implementation
pub trait ShapeGeometry<T> {
    fn boundary(self: T) -> u64;
    fn area(self: T) -> u64;
}

mod rectangle {
    // Importing ShapeGeometry is required to implement this trait for Rectangle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Rectangle {
        pub height: u64,
        pub width: u64,
    }

    // Implementation RectangleGeometry passes in <Rectangle>
    // to implement the trait for that type
    impl RectangleGeometry of ShapeGeometry<Rectangle> {
        fn boundary(self: Rectangle) -> u64 {
            2 * (self.height + self.width)
        }
        fn area(self: Rectangle) -> u64 {
            self.height * self.width
        }
    }
}

mod circle {
    // Importing ShapeGeometry is required to implement this trait for Circle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Circle {
        pub radius: u64
    }

    // Implementation CircleGeometry passes in <Circle>
    // to implement the imported trait for that type
    impl CircleGeometry of ShapeGeometry<Circle> {
        fn boundary(self: Circle) -> u64 {
            (2 * 314 * self.radius) / 100
        }
        fn area(self: Circle) -> u64 {
            (314 * self.radius * self.radius) / 100
        }
    }
}

use rectangle::Rectangle;
use circle::Circle;

fn main() {
    let rect = Rectangle { height: 5, width: 7 };
    println!("Rectangle area: {}", ShapeGeometry::area(rect)); //35
    println!("Rectangle boundary: {}", ShapeGeometry::boundary(rect)); //24

    let circ = Circle { radius: 5 };
    println!("Circle area: {}", ShapeGeometry::area(circ)); //78
    println!("Circle boundary: {}", ShapeGeometry::boundary(circ)); //31
}
```

`CircleGeometry` ও `RectangleGeometry` দুটোরই ইমপ্লিমেন্টেশনের ভিজিবিলিটি পাবলিক হওয়ার দরকার নেই, কারণ `ShapeGeometry` ট্রেইটটি পাবলিক করা হয়েছে এবং কম্পাইলারের সেটি সহজেই খুঁজে পাওয়া উচিত।

## Impl অ্যালিয়াস

ইমপোর্ট করার সময় `impl` কিওয়ার্ড ব্যবহার করে ইমপ্লিমেন্টেশনের অ্যালিয়াস তৈরি করা যায়।
কংক্রিট টাইপের জন্য জেনেরিক ইমপ্লিমেন্টেশন ইনস্ট্যানশিয়েট করার সময় এটি সহায়ক হয়।
চলুন, `One` ট্রেইট ইমপ্লিমেন্ট করে এমন সব টাইপের জন্য `Two` ট্রেইটের একটি সহজ ইমপ্লিমেন্টেশন ডিফাইন করি, যেখানে শুধু `One`-এর মানের দ্বিগুণ যোগ করে যোগফলটি রিটার্ন করা হয়।
এরপর আমরা শুধু `u8` ও `u128` টাইপের জন্য কাজ করে এমন `Two` ইমপ্লিমেন্টেশনটি প্রকাশ করতে পারি।

```rust
trait Two<T> {
    fn two() -> T;
}

mod one_based {
    pub impl TwoImpl<
        T, +Copy<T>, +Drop<T>, +Add<T>, impl One: core::num::traits::One<T>
    > of super::Two<T> {
        fn two() -> T {
            One::one() + One::one()
        }
    }
}

pub impl U8Two = one_based::TwoImpl<u8>;
pub impl U128Two = one_based::TwoImpl<u128>;
```

জেনেরিক ইমপ্লিমেন্টেশনটি একটি প্রাইভেট মডিউলে লেখা যায়, আর impl অ্যালিয়াস ব্যবহার করে আমরা এই দুটি কংক্রিট টাইপের জেনেরিক ইমপ্লিমেন্টেশন ইনস্ট্যানশিয়েট করতে পারি।
প্রাইভেট ও অপ্রকাশিত জেনেরিক ইমপ্লিমেন্টেশন ব্যবহারের সুবিধা হলো, এটি ফাইলগুলোর মধ্যে কোডের পুনরাবৃত্তি রোধ করে।
একইসাথে এতে পাবলিক API সহজ ও পরিচ্ছন্ন থাকে।
