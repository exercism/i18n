# ভূমিকা

*কম্বিনেটর* হলো উচ্চতর ক্রমের ওয়ার্ড, যেগুলো স্ট্যাক-শাফলিংয়ের কমন প্যাটার্নগুলোকে নাম দেওয়া রূপে ধরে রাখে। এগুলো ব্যবহার করলে আপনাকে অনেক কম `dup`, `swap`, `over`, `rot` লিখতে হয়।

```
keep   ( x quot: ( x -- y ) -- y x )         ! apply, preserve x
dip    ( x quot -- x )                        ! operate underneath
bi     ( x q1 q2 -- r1 r2 )                   ! two functions of one input
tri    ( x q1 q2 q3 -- r1 r2 r3 )             ! three functions of one input
cleave ( x { q1 q2 … } -- r1 r2 … )           ! n functions of one input
bi@    ( x y q -- r1 r2 )                     ! same function on two values
bi*    ( x y q1 q2 -- r1 r2 )                 ! different functions on two values
```

```factor
5 [ 2 * ] keep .s            ! 10  /  5
4 [ sq ] [ neg ] bi .s       ! 16  / -4
1 2 3 [ + ] dip .s           ! 3   /  3
3 4 [ sq ] bi@ .s            ! 9   / 16
```

`keep`, `dip`, `bi`, `bi@`, `bi*` আছে [`kernel`][kernel]-এ; `cleave` এবং দীর্ঘতর ভ্যারিয়েন্টগুলো আছে [`combinators`][combinators]-এ।
