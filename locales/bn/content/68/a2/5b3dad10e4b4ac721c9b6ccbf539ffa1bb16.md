# টেস্ট

MacOS/Linux-এ, অনুগ্রহ করে চালান:

```sh
$ chmod +x gradlew
```

এর সাহায্যে টেস্টগুলো চালান:

```sh
$ ./gradlew test
```

> আপনি Windows-এ থাকলে `gradlew.bat` ব্যবহার করুন

## স্কিপ করা টেস্ট

প্রথম টেস্ট (বা টেস্টগুলো) পাস হওয়ার পরে, অন্য টেস্টগুলোর আগে বসানো `@Ignore` অ্যানোটেশনগুলো কমেন্ট আউট করে বা মুছে ফেলে এগিয়ে যান।
