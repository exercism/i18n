# পরিচিতি

`call` হলো সর্বজনীন "এই কোটেশনটি এখনই চালান" প্রিমিটিভ। কম্পাইলার যখন কোটেশনটি আক্ষরিকভাবে দেখতে পায়, তখন সে এফেক্টটি অনুমান করতে পারে। কিন্তু কোটেশনটি যখন কোনো ভ্যারিয়েবল, অ্যারে বা প্যারামিটার থেকে আসে, তখন আপনাকে এফেক্টটি ডিক্লেয়ার করতে হবে:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

`call( a b -- c )` ডিক্লেয়ারেশনটি কম্পাইল হয়ে একটি রানটাইম চেকে পরিণত হয়, যা যাচাই করে যে কোটেশনটির সত্যিই ডিক্লেয়ার করা এফেক্ট আছে। মিসম্যাচ হলে নষ্ট স্ট্যাক স্টেটের বদলে একটি স্পষ্ট এরর পাওয়া যায়।

কোটেশনকে ডেটা হিসেবে ব্যবহার করা, অর্থাৎ সেগুলো পুশ করা, অ্যারেতে রাখা আর ওয়ার্ড থেকে রিটার্ন করা, কনক্যাটেনেটিভ কোডকে এত সংক্ষিপ্ত করে তোলে এমন একটি বিষয়। একটি "প্রোগ্রাম" সাধারণ সিকোয়েন্সও হতে পারে, আর এটি ইন্টারপ্রেট করার জন্য `each`-এর সঙ্গে `call` থাকলেই যথেষ্ট।
