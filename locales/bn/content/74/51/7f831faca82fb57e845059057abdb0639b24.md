# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ   | বিবরণ                                          |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | বাকেটগুলোর ধারণক্ষমতা সম্বলিত ওয়ার্ড অ্যারে      |
| `$a1`    | ইনপুট        | ইন্টিজার | শুরুর বাকেট (1 বা 2)                           |
| `$a2`    | ইনপুট        | ইন্টিজার | টার্গেট ভলিউম                                  |
| `$a3`    | ইনপুট/আউটপুট | অ্যাড্রেস | বাকেটের চূড়ান্ত বিষয়বস্তু সম্বলিত ওয়ার্ড অ্যারে |
| `$v0`    | আউটপুট       | ইন্টিজার | প্রয়োজনীয় অ্যাকশনের সংখ্যা, সম্ভব না হলে -1  |
| `$t0-9`  | অস্থায়ী     | যেকোনো  | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত                 |
