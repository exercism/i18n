# For লুপের পরিচিতি

[for লুপ](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) এমন একটি ব্যবস্থা দেয় যার মাধ্যমে যতক্ষণ না কোনো শর্ত পূরণ হয়, ততক্ষণ একগুচ্ছ স্টেটমেন্ট বারবার চালানো যায়। লুপটি চারটি অংশ নিয়ে গঠিত:

```java
for (initialization; test; update) {
    body;
}
```

`initialization` লুপের জন্য একটি প্রাথমিক অবস্থা নির্ধারণ করে এবং লুপের শুরুতে ঠিক একবার চালানো হয়। সাধারণত এটি টেস্ট এক্সপ্রেশন ও আপডেট স্টেটমেন্টে ব্যবহৃত একটি ভ্যারিয়েবল ঘোষণা করে এবং অ্যাসাইন করে। যেমন:

```java
int i = 1
```

`test` এক্সপ্রেশনটি পরীক্ষা করে লুপটি শেষ হওয়া উচিত কি না। এটি যদি `true`-তে মূল্যায়িত হয়, তবে লুপ বডি এবং তারপর আপডেট এক্সপ্রেশনটি চালানো হবে। এটি যদি `false`-তে মূল্যায়িত হয়, তবে লুপ বডি বা আপডেট স্টেটমেন্ট কোনোটিই চালানো হবে না এবং লুপের শেষ বন্ধনীর পরে এক্সিকিউশন আবার শুরু হয়। সাধারণত এটি ইনিশিয়ালাইজেশন ব্লকে অ্যাসাইন করা ভ্যারিয়েবলটি পরীক্ষা করে। যেমন:

```java
i <= 10
```

লুপ বডি চালানোর পরে, `update` এক্সপ্রেশনটি চালানো হয়। সাধারণত এটি লুপ ভ্যারিয়েবলকে কোনো মান দ্বারা ইনক্রিমেন্ট বা ডিক্রিমেন্ট করে। যেমন:

```java
i++
```

প্রথম চারটি বর্গ প্রিন্ট করা একটি `for` লুপ দেখতে এমন হবে:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

আউটপুট হবে:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

কোনো কালেকশনের প্রতিটি এলিমেন্টের মধ্য দিয়ে ইটারেট করলে `for-each` লুপটি বেশি পছন্দনীয়, তবে `for` লুপ দিয়েও এভাবে করা যায়:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for` লুপের `for-each` লুপের তুলনায় কিছু সুবিধা আছে:

- আপনি চাইলে যে ইনডেক্সে শুরু বা শেষ করতে পারেন।
- আপনি চাইলে যেকোনো (বুলিয়ান) টার্মিনেশন শর্ত ব্যবহার করতে পারেন।
- লুপ ভ্যারিয়েবলের ইনক্রিমেন্ট কাস্টমাইজ করে আপনি এলিমেন্টগুলো স্কিপ করতে পারেন।
- কাউন্ট ডাউন করে আপনি কালেকশনগুলো পিছন থেকে সামনে প্রসেস করতে পারেন।
- আপনি এমন পরিস্থিতিতেও `for` লুপ ব্যবহার করতে পারেন যেখানে কোনো কালেকশন নেই।
