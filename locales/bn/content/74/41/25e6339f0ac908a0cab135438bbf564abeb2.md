# নির্দেশাবলি

এই অনুশীলনীতে আপনি [Go খেলার নিয়মগুলো](https://matmoore.github.io/learngo/) প্রয়োগ করবেন। নিয়মগুলো তো আগেই লেখা আছে, আপনাকে শুধু সেগুলো প্রয়োগ করে Game আপডেট করতে হবে এবং যেকোনো এরর বা নিয়ম লঙ্ঘন সামলাতে হবে।

গেমটি এভাবে প্রকাশ করা হয়:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

গেমটিতে ৪টি নিয়ম আছে:

- প্রতিটি পয়েন্টে মাত্র একটি পাথর থাকতে পারে (`oneStonePerPointRule`)
- প্রতিপক্ষের পাথর ক্যাপচার করা যায়! (`captureRule`)
- যে পয়েন্টে পাথর রাখলে সেটি নিজেকেই ক্যাপচার করবে, সেখানে পাথর রাখা যায় না (`libertyRule`)
- একই পয়েন্ট দুবার ব্যবহার করা যায় না (`koRule`)

## 1. নিয়মগুলো প্রয়োগ করুন

`applyRules` ফাংশনের কোডটি লিখুন। এটি একটি প্রাথমিক `Game` আর নিয়মের একটি সেট নেয়, এবং নিয়মগুলো প্রয়োগ করা হয়ে গেলে নতুন `Game` রিটার্ন করে।

`oneStonePerPointRule`, `libertyRule` আর `koRule` — এদের সবাই নিয়ম লঙ্ঘন হচ্ছে কিনা পরীক্ষা করে, এবং একটি এরর রিটার্ন করতে পারে, তাই এদের রিটার্ন টাইপ `Result String Game`. এসব নিয়মের যেকোনোটি যদি ফেল করে, তাহলে আসল গেমটিই রিটার্ন করা উচিত, তবে `error` ফিল্ডে সংশ্লিষ্ট এররটি বসিয়ে।

`captureRule` কোনো লঙ্ঘন পরীক্ষা করে না, তাই এটি ফেল করতে পারে না (যদিও এটি বদলে যাওয়া একটি `Game` রিটার্ন করতে পারে), আর তাই এর রিটার্ন টাইপ `Game`.

সব নিয়ম যদি পাস করে, তাহলে নিয়মগুলো থেকে `Game`-এ যেসব পরিবর্তন এসেছে সেগুলো রাখা উচিত, আর প্লেয়ারটি বদলে দিতে হবে। এটি করার জন্য `changePlayer` ফাংশনটি দেওয়া আছে।

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
