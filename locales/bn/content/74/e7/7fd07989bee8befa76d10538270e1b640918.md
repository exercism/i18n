# HTTP-এর বিলিয়ন ডলার প্রশ্ন

## সমস্যার বিবৃতি

আপনাকে প্রদত্ত দেশের সেটে (দেশের সংখ্যা = `N`) নিট মূল্যের ভিত্তিতে শীর্ষ `x` জন বিলিয়নেয়ার খুঁজে বের করতে বলা হয়েছে। এটি বাস্তবায়ন করতে, আপনাকে এমন একটি API-এর অ্যাক্সেস দেওয়া হয়েছে যা দেশ অনুযায়ী বিলিয়নেয়ারদের বিবরণ রিটার্ন করে।

API-এ অ্যাক্সেস সহজ করতে, আপনি [`ims/billionairehub` ক্লায়েন্ট](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) কানেক্টর ব্যবহার করে দেশ অনুযায়ী বিলিয়নেয়ারদের বিবরণ রিটার্ন করে এমন API-এর সাথে সংযোগ করতে পারেন।

## সীমাবদ্ধতা

* 1 <= N <= 5
* 1 <= x <= 10

## টেস্ট এনভায়রনমেন্ট

* বিলিয়নেয়ার API-এর সাথে সংযোগ করার জন্য Client ID ও Client Secret আপনাকে `tests/Config.toml` ফাইলে দেওয়া হয়েছে। এগুলো দিয়ে আপনি ক্লায়েন্ট ইনিশিয়ালাইজ করতে পারেন।
* আপনার ইমপ্লিমেন্টেশন রান ও টেস্ট করতে `bal test` ব্যবহার করুন।

## ইঙ্গিত

* `ims/billionairehub` প্যাকেজের [ক্লায়েন্ট](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) ব্যবহার করে দেশ অনুযায়ী বিলিয়নেয়ার পাওয়ার API কল করা যায়। বিশেষভাবে আপনি `getBillionaires("<country>")` রিমোট মেথডটি ব্যবহার করতে পারেন।
* আপনি প্রথমে প্রতি দেশের সবচেয়ে ধনী ব্যক্তিদের খুঁজে বের করতে পারেন, তারপর সেগুলো একত্র করে শীর্ষ `x` জনকে বের করতে পারেন।
* ফিল্টারিং ও সর্টিংয়ের জন্য [কোয়েরি এক্সপ্রেশন](https://ballerina.io/learn/by-example/query-expressions/) সুবিধাজনক হবে
