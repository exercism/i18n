# ভূমিকা

একটি হায়ার-অর্ডার ফাংশন হলো এমন একটি ফাংশন, যা হয়:

- একটি ফাংশনকে আর্গুমেন্ট হিসেবে নেয়
- একটি ফাংশন রিটার্ন করে

একটি ফাংশন আর্গুমেন্ট হলো শুধু একটি সাধারণ আর্গুমেন্ট, যদিও সেটি এমন একটি যা আপনি কল করতে পারেন।

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
