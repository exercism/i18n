# PaySwitch - বেতন কনভার্টার

## সমস্যার বিবৃতি

**Insure Everyone** নামের একটি কোম্পানি তার কর্মচারীদের বিদেশি মুদ্রায় বেতন দিচ্ছে। কিন্তু আইনি বাধ্যবাধকতার কারণে বেতনটি স্থানীয় মুদ্রায় রূপান্তর করতে হয়। কোম্পানিটির কর্মচারীরা সারা বিশ্বে ছড়িয়ে আছেন।
Insure Everyone-এর HR বিভাগ প্রতিটি কর্মচারীর বেতন তার নিজ নিজ স্থানীয় মুদ্রায় রূপান্তর করার একটি প্রোগ্রাম বানাতে একজন দক্ষ ডেভেলপারের সাহায্য চাইছে। Insure Everyone বাইরের একটি API থেকে পাওয়া বিনিময় হারের ওপর নির্ভর করে।

বাইরের বিনিময় হার API-টি ব্যবহার করে আপনাকে এমন একটি ফাংশন লিখতে হবে, যা একটি `source currency`, `salary` (উৎস মুদ্রায়) এবং কর্মচারীর `local currency` নেবে এবং সেই বেতনটি স্থানীয় মুদ্রায় রিটার্ন করবে।

## সীমাবদ্ধতা

* 500 <= `salary` <= 10000
* `sourceCurrency` আর `targetCurrency` হলো [ISO মুদ্রা কোড (বর্ণভিত্তিক)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)। টেস্ট ইনপুটে ভুল মুদ্রা কোড থাকতে পারে।
* রিটার্ন করা হারের নির্ভুলতা `5` দশমিক স্থান পর্যন্ত যাচাই করা হবে।

## উদাহরণ

### উদাহরণ ১

#### ইনপুট:
* বেতন: 1000
* উৎস মুদ্রা: USD
* লক্ষ্য মুদ্রা: GBP

#### আউটপুট:

ধরে নিন, বাইরের মুদ্রা বিনিময় সেবাটি নিচের রূপান্তর হারের রেসপন্সটি দিয়েছে (বাদ দেওয়া হয়েছে):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

ফাংশনটিকে `735.84000` রিটার্ন করতে হবে
