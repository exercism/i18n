# নির্দেশনা

আপনি একজন আগ্রহী পাখি পর্যবেক্ষক, যিনি খেয়াল রাখেন আপনার বাগানে কত পাখি এসেছে। সাধারণত পাখি গোনার জন্য আপনি নোটবুকে দাগ কেটে হিসাব রাখেন, কিন্তু আপনার তথ্য নিয়ে আরও ভালোভাবে কাজ করার জন্য গত কয়েক সপ্তাহের পাখি গণনা আপনি ডিজিটাল করে ফেলেছেন।

## 1. এতদিনে আপনি মোট কতটি পাখি গুনেছেন তা নির্ণয় করুন

চলুন, সামগ্রিক চিত্র দেখে তথ্য বিশ্লেষণ শুরু করি। আপনি লগ রাখা শুরু করার পর থেকে মোট কতটি পাখি গুনেছেন তা বের করুন।

এমন একটি ফাংশন `TotalBirdCount` লিখুন, যা প্রতিদিনের পাখি গণনা সম্বলিত `int`-এর একটি স্লাইস নেয়। এটি আপনার গোনা মোট পাখির সংখ্যা রিটার্ন করবে।

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. নির্দিষ্ট একটি সপ্তাহে আসা পাখির সংখ্যা হিসাব করুন

এখন আপনার পাখি গণনার সংখ্যাগুলো সম্পর্কে মোটামুটি ধারণা হয়ে গেছে, তাই আপনি আরও সূক্ষ্ম বিশ্লেষণ করতে চান।

এমন একটি ফাংশন `BirdsInWeek` লিখুন, যা প্রতিদিনের পাখি গণনার একটি স্লাইস এবং একটি সপ্তাহ নম্বর নেয়।

এটি ওই নির্দিষ্ট সপ্তাহে আপনার গোনা মোট পাখির সংখ্যা রিটার্ন করে। ধরে নিতে পারেন, সপ্তাহগুলো সবসময় সম্পূর্ণভাবে হিসাব করা হয়।

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. গণনার একটি ভুল সংশোধন করুন

আপনি বুঝতে পারলেন যে যে সময়টা আপনি পাখিদের হিসাব রাখার চেষ্টা করছিলেন, সেই পুরো সময় বাগানের এক দূরের কোণে একটি পাখি লুকিয়ে ছিল।

আপনি বুঝতে পারলেন, এই পাখিটি সবসময় একদিন পরপর আপনার বাগানে সময় কাটাত।

ওই দিনগুলোর মাঝে এটি ঠিক কোথায় ছিল তা আপনি জানেন না, তবে নিশ্চিতভাবে আপনার বাগানে নয়।

আপনার পাখি পর্যবেক্ষকের অন্তর্দৃষ্টি আরও বলে, আপনার তালিকায় যে প্রথম দিনটির হিসাব আপনি রেখেছিলেন, সেদিন পাখিটি আপনার বাগানেই ছিল।

এই নতুন তথ্য অনুযায়ী, এমন একটি ফাংশন `FixBirdCountLog` লিখুন, যা প্রতিদিন গোনা পাখির একটি স্লাইস আর্গুমেন্ট হিসেবে নেয় এবং গণনার ভুলটি সংশোধন করে সেই স্লাইসটি রিটার্ন করে।

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
