# পরিচিতি

শূন্য বা তার বেশি এলিমেন্ট ধারণ করতে পারে এমন ডেটা স্ট্রাকচারকে _কালেকশন_ বলা হয়। **অ্যারে** এমন একটি কালেকশন, যার আকার/দৈর্ঘ্য নির্দিষ্ট এবং যার সব এলিমেন্ট অবশ্যই একই টাইপের হতে হয়। ইনডেক্স ব্যবহার করে অ্যারেতে এলিমেন্ট অ্যাসাইন করা যায়, আবার অ্যারে থেকে সেগুলো পাওয়াও যায়। C# অ্যারে শূন্য-ভিত্তিক, অর্থাৎ প্রথম এলিমেন্টের ইনডেক্স সবসময় শূন্য:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

শর্টকাট নোটেশন ব্যবহার করেও অ্যারে তৈরি করা যায়, যা দিয়ে একইসাথে অ্যারে বানানো ও তার মান সেট করা যায়। কম্পাইলার এখন বুঝতে পারে অ্যারেতে কতগুলো এলিমেন্ট থাকবে, তাই দৈর্ঘ্য বাদ দেওয়া যায়:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

অ্যারে ইনস্ট্যান্সের [মেথড][array-methods] বা [প্রপার্টি][array-properties] কল করে, কিংবা [`Array` ক্লাসে][array-class] ডিফাইন করা স্ট্যাটিক মেথড ব্যবহার করে অ্যারে নিয়ে কাজ করা যায়।

## ইটারেশন

অ্যারে আসলে একটি _কালেকশন_ও, অর্থাৎ [`foreach` লুপ][foreach-statement] ব্যবহার করে এর _সব_ মানের উপর ইটারেশন করা যায়:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

[`for` লুপ][for-statement] ব্যবহার করেও একটি অ্যারেতে ইটারেশন করা যায়:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

তবে সাধারণত নিচের কারণে `for` লুপের চেয়ে `foreach` লুপই ভালো:

- `foreach` লুপ _সব_ মানের উপর ইটারেশন করবে বলে নিশ্চিত থাকা যায়। `for` লুপে অফ-বাই-ওয়ান এররের মতো কারণে এলিমেন্ট বাদ পড়া সহজ।
- `foreach` লুপ বেশি _ডিক্লারেটিভ_, আপনার কোড কী করতে চায় সেটাই জানায়, অন্যদিকে `for` লুপ জানায় কীভাবে করতে চান।
- `foreach` লুপে ভুল হওয়ার সুযোগ নেই, অথচ `for` লুপে অফ-বাই-ওয়ান এরর হওয়া সহজ।
- `foreach` লুপ সব ধরনের কালেকশনেই কাজ করে, এমন কালেকশনেও যেগুলোতে এলিমেন্ট অ্যাক্সেস করতে ইনডেক্সার ব্যবহার সমর্থিত নয়।

`foreach` লুপ যে _সব_ মানের উপর ইটারেশন করবে তা নিশ্চিত করতে কম্পাইলার `foreach` লুপের ভিতরে কালেকশন আপডেট করতে দেয় না:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`foreach` লুপের চেয়ে `for` লুপের কিছু সুবিধাও আছে:

- আপনি যে ইনডেক্সে শুরু করতে বা থামতে চান, তা নিজেই ঠিক করতে পারেন।
- লুপ শেষ হওয়ার যেকোনো (বুলিয়ান) শর্তই ব্যবহার করতে পারেন।
- লুপ ভ্যারিয়েবলের ইনক্রিমেন্ট নিজের মতো সাজিয়ে এলিমেন্ট বাদ দিতে পারেন।
- উল্টো দিক থেকে গণনা করে কালেকশন পিছন থেকে সামনে প্রসেস করতে পারেন।
- কালেকশন ছাড়া অন্য পরিস্থিতিতেও `for` লুপ ব্যবহার করতে পারেন।

সম্পর্কিত বিষয়:

- জেনে রাখা ভালো, C# এ [মাল্টি-ডাইমেনশনাল অ্যারে][multi-dimensional-arrays] সমর্থিত, যেমন `int[,] arr = new int[10, 5]`, যা খুব কাজে লাগতে পারে।
- এটাও জেনে রাখা ভালো, `Array.CreateInstance` দিয়ে [`System.Array`][system-array-object] টাইপের অবজেক্ট ইনস্ট্যানশিয়েট করা যায়। এ ধরনের অবজেক্ট খুব একটা কাজে লাগে না, মূলত VB.NET কোডের সাথে ইন্টারঅপের জন্য। স্ট্যান্ডার্ড অ্যারের (`T[]`) সাথে এগুলো বিনিময়যোগ্য নয়। এগুলোর লোয়ার বাউন্ড শূন্য ছাড়া অন্য কিছুও হতে পারে।

উপরের দুটি বিষয়ই পরের একটি অনুশীলনীতে আরও বিস্তারিত আলোচনা করা হয়েছে।
