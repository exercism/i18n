# পরিচিতি

টেক্সট নিয়ে কাজ করা প্রোগ্রামিংয়ে একটি কমন কাজ। Swift, Foundation ফ্রেমওয়ার্কের সঙ্গে মিলে, স্ট্রিং পরীক্ষা করা, রূপান্তর করা এবং ম্যানিপুলেট করার জন্য অনেক সুবিধাজনক মেথড ও প্রপার্টি দেয়।

## `components(separatedBy:)` দিয়ে স্ট্রিং ভাগ করা

কোনো ডেলিমিটার অনুযায়ী একটি স্ট্রিংকে সাবস্ট্রিংয়ের অ্যারেতে ভাগ করতে `components(separatedBy:)` ব্যবহার করুন (এর জন্য Foundation ইমপোর্ট করা লাগে):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## `hasPrefix(_:)` ও `hasSuffix(_:)` দিয়ে প্রিফিক্স ও সাফিক্স পরীক্ষা করা

কোনো স্ট্রিং নির্দিষ্ট কিছু ক্যারেক্টারের ক্রম দিয়ে শুরু বা শেষ হয় কি না তা পরীক্ষা করতে `hasPrefix(_:)` ও `hasSuffix(_:)` ব্যবহার করুন:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## কেস পরিবর্তন করা

এই স্ট্যান্ডার্ড মেথড ও প্রপার্টিগুলো ব্যবহার করে আপনি একটি স্ট্রিংয়ের কেস বদলাতে পারেন:

- `lowercased()`: স্ট্রিংটির একটি ছোট হাতের অক্ষরের কপি রিটার্ন করে।
- `uppercased()`: স্ট্রিংটির একটি বড় হাতের অক্ষরের কপি রিটার্ন করে।
- `capitalized`: এমন একটি কপি রিটার্ন করে যেখানে প্রতিটি শব্দের প্রথম অক্ষর বড় হাতের হয় (Foundation থেকে)।

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## `replacingOccurrences(of:with:)` দিয়ে সাবস্ট্রিং রিপ্লেস করা

কোনো নির্দিষ্ট সাবস্ট্রিংয়ের সব উপস্থিতি অন্য একটি স্ট্রিং দিয়ে রিপ্লেস করতে `replacingOccurrences(of:with:)` ব্যবহার করুন (Foundation থেকে):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## `joined(separator:)` দিয়ে স্ট্রিং জোড়া লাগানো

`joined(separator:)` মেথডটি `[String]`-এর মতো স্ট্রিংয়ের কালেকশনের অন্তর্গত।
এটি একটি সেপারেটর ব্যবহার করে এলিমেন্টগুলোকে জোড়া লাগিয়ে একটি একক স্ট্রিং বানায়:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
