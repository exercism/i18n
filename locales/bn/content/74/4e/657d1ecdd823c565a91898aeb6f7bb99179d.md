# Instructions

এই অনুশীলনীতে আপনাকে ক্লাসিক গেম Pac-Man-এর কিছু নিয়ম C++ ফাংশনে অনুবাদ করতে হবে।

অনুবাদ করার জন্য আপনার কাছে চারটি নিয়ম আছে, যার সবকটিই গেমের স্টেটের সাথে সম্পর্কিত।

> আর্গুমেন্টগুলো কীভাবে তৈরি হচ্ছে তা নিয়ে চিন্তা করবেন না, শুধু কাঙ্ক্ষিত ফলাফল রিটার্ন করার জন্য আর্গুমেন্টগুলো একসাথে মেলানোর দিকে মনোযোগ দিন।

## 1. Pac-Man একটি ভূত খায় কি না তা ডিফাইন করুন

`can_eat_ghost` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man ভূতটি খেতে সক্ষম কি না তা একটি বুলিয়ান মান রিটার্ন করে। ফাংশনটি কেবল তখনই ট্রু রিটার্ন করবে যখন Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে এবং সে একটি ভূত স্পর্শ করছে।

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Pac-Man স্কোর করে কি না তা ডিফাইন করুন

`scored` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man একটি পাওয়ার পেলেট স্পর্শ করছে কি না_ এবং _Pac-Man একটি ডট স্পর্শ করছে কি না_) এবং Pac-Man স্কোর করেছে কি না তা একটি বুলিয়ান মান রিটার্ন করে। Pac-Man একটি পাওয়ার পেলেট বা একটি ডট স্পর্শ করলে ফাংশনটি ট্রু রিটার্ন করবে।

```cpp
scored(true, true);
// => true
```

## 3. Pac-Man হারে কি না তা ডিফাইন করুন

`lost` ফাংশনটি ডিফাইন করুন, যা দুটি আর্গুমেন্ট নেয় (_Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_ এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man হারে কি না তা একটি বুলিয়ান মান রিটার্ন করে। Pac-Man একটি ভূত স্পর্শ করলে এবং তার একটি পাওয়ার পেলেট সক্রিয় না থাকলে ফাংশনটি ট্রু রিটার্ন করবে।

```cpp
lost(false, true);
// => true
```

## 4. Pac-Man জেতে কি না তা ডিফাইন করুন

`won` ফাংশনটি ডিফাইন করুন, যা তিনটি আর্গুমেন্ট নেয় (_Pac-Man সব ডট খেয়ে ফেলেছে কি না_, _Pac-Man-এর একটি পাওয়ার পেলেট সক্রিয় আছে কি না_, এবং _Pac-Man একটি ভূত স্পর্শ করছে কি না_) এবং Pac-Man জেতে কি না তা একটি বুলিয়ান মান রিটার্ন করে। Pac-Man সব ডট খেয়ে ফেললে এবং ৩ নম্বর অংশে ডিফাইন করা আর্গুমেন্ট অনুযায়ী না হারলে ফাংশনটি ট্রু রিটার্ন করবে।

```cpp
won(false, true, false);
// => false
```
