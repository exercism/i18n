# নির্দেশাবলি

একটি [আর্মস্ট্রং সংখ্যা][armstrong-number] হলো এমন একটি সংখ্যা, যেটি তার নিজের অঙ্কগুলোর প্রত্যেকটিকে অঙ্কের সংখ্যার সমান ঘাতে উন্নীত করে যোগ করলে যে যোগফল পাওয়া যায়, তার সমান।

যেমন:

- 9 একটি আর্মস্ট্রং সংখ্যা, কারণ `9 = 9^1 = 9`
- 10 আর্মস্ট্রং সংখ্যা *নয়*, কারণ `10 != 1^2 + 0^2 = 1`
- 153 একটি আর্মস্ট্রং সংখ্যা, কারণ: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 আর্মস্ট্রং সংখ্যা *নয়*, কারণ: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

একটি সংখ্যা আর্মস্ট্রং সংখ্যা কি না, তা নির্ণয় করার জন্য কিছু Code লিখুন।
