# পরিচিতি

মনে করুন, একটি `jq` প্রোগ্রাম হলো _এক্সপ্রেশনের একটি পাইপলাইন_।
**ভ্যারিয়েবল অ্যাসাইনমেন্ট** এই নিয়মটি মেনে চলে: একটি _ভ্যারিয়েবল অ্যাসাইনমেন্ট_ হলো এমন একটি এক্সপ্রেশন, যেটি দেখতে এরকম:

```jq
... | expr as $varname | ...
```

## ফিল্টার ইনপুটই আউটপুট দেয়

_আইডেন্টিটি এক্সপ্রেশন_ `.`-এর মতোই, _ভ্যারিয়েবল অ্যাসাইনমেন্ট_-এর আউটপুটও তার ইনপুটের সমান। ভ্যারিয়েবলের মান সেট করা হলো একটি সাইড-ইফেক্ট।

উদাহরণ, যেখানে দেখা যায় অ্যাসাইনমেন্টের পরে `.` প্রথম ইনপুটটিরই সমান:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## ভ্যারিয়েবলের স্কোপ

ভ্যারিয়েবলের স্কোপ "লেক্সিকাল", অর্থাৎ পাইপলাইনের বাকি অংশজুড়ে ভ্যারিয়েবলটি স্কোপে থাকবে। ফাংশনের ভেতরে ডিফাইন করা ভ্যারিয়েবল (ফাংশন নিয়ে আমরা পরে আলোচনা করব) ফাংশনটির কাছে "লোকাল"।

## ভ্যারিয়েবলের নাম

ভ্যারিয়েবলের নাম অবশ্যই `$` দিয়ে শুরু হতে হবে।
নামের বাকি অংশটি একটি **আইডেন্টিফায়ার**: শুরু হয় একটি অক্ষর বা আন্ডারস্কোর দিয়ে, তারপর আসে অক্ষর, সংখ্যা বা আন্ডারস্কোর।

## ডিস্ট্রাকচারিং অ্যাসাইনমেন্ট

ম্যানুয়াল থেকে:

> একটি `as` এক্সপ্রেশন দিয়েই একাধিক ভ্যারিয়েবল ঘোষণা করা যায়, যদি এমন একটি প্যাটার্ন দেওয়া হয় যা _ইনপুটের গঠনের সাথে মেলে_ (এটিকেই "ডিস্ট্রাকচারিং" বলা হয়)।

উদাহরণ:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

_অবজেক্ট কী (key)_-এর সাথে ভ্যারিয়েবলের নাম মিলিয়ে নিলে একটি শর্টকাট পাওয়া যায়:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## কনস্ট্যান্ট

উপরের উদাহরণে দেখা গেছে, কনস্ট্যান্ট সংরক্ষণ করার জন্য ভ্যারিয়েবল সুবিধাজনক।
কোডে "ম্যাজিক নাম্বার" দেখানোর চেয়ে কনস্ট্যান্টকে একটি নাম দেওয়া ভালো।

## অনেক সময় ভ্যারিয়েবলের দরকারই হয় না

ভ্যারিয়েবল বাদ দিলে প্রায়ই কোড আরও সহজে পড়া যায়।

সংখ্যার একটি অ্যারের গড় বের করার কথা ভাবুন

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

এর তুলনায়

```jq
[2, 4, 8, 7] | add / length
```

এটি `jq`-এর সবচেয়ে শক্তিশালী দিকগুলোর একটি তুলে ধরে: একটি ফিল্টারের ইনপুট _প্রতিটি_ সাব-এক্সপ্রেশনকে দেওয়া হয়:

- ইনপুট অ্যারে `[2,4,8,7]` `add`-কে দেওয়া হয় (যা সব এলিমেন্টে `+` অপারেটর প্রয়োগ করে সংখ্যাগুলোর যোগফল বের করে)
- _সমান্তরালে_, `[2,4,8,7]` `length`-কেও দেওয়া হয়
- এই সাব-এক্সপ্রেশনগুলো সম্পন্ন হলে তাদের ফলাফল ভাগ করা হয়, ফলে ইনপুট অ্যারের সংখ্যাগুলোর গড় পাওয়া যায়।

## শেখার অনুশীলনীর জন্য আপনার দরকারি `jq` অপারেটর

### অল্টারনেটিভ অপারেটর: `//`

এক্সপ্রেশন `a // b` আউটপুট দেয় `b`, যদি `a` ফলস বা নাল হয়; নাহলে এটি `a` আউটপুট দেয়।
ভ্যারিয়েবল সেট করার প্রসঙ্গে এটি একটি ডিফল্ট মান দেওয়ার জন্য খুব সুবিধাজনক:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### অ্যারিথমেটিক অপারেটর

- `+`, `-`, `*` হলো স্বাভাবিক সংখ্যাগত যোগ, বিয়োগ ও গুণের অপারেটর।
