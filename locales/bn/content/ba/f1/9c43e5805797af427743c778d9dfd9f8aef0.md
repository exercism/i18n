# নির্দেশনা

আপনি আপনার স্কুলের নাটকের জন্য কিউগুলো ডাকছেন। স্টেজ ম্যানেজার চান স্ট্যান্ডার্ড লাইনগুলো লিখে রাখা হোক, যাতে যে কেউ ডেস্ক চালাতে পারে।

আপনার সামনে চারটি কাজ, সবগুলোই `STAGE_DIRECTIONS` ক্লাসে।

## 1. শুরু ঘোষণা করুন

যে লাইন দিয়ে শো শুরু হয়, সেটি রিটার্ন করুন।

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. বিরতি ঘোষণা করুন

বিরতির সময় যে লাইন ডাকা হয়, সেটি রিটার্ন করুন।

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. সমাপ্তি ঘোষণা করুন

যে লাইন দিয়ে শো শেষ হয়, সেটি রিটার্ন করুন।

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. শেষ কিউ ডাকুন

শেষ কিউটি শো শেষ করার লাইনটির মতোই। টেক্সটটি দ্বিতীয়বার লিখে না ফেলে, আপনি আগে যেই রুটিনটি লিখেছেন সেটিই কল করুন।

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
