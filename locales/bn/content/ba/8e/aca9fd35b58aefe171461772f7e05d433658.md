# টেস্ট রান করা

নির্দিষ্ট কোনো অনুশীলনীর টেস্ট রান করতে হলে, ফোল্ডারটিতে `cd` করে নিচের কমান্ডটি রান করুন:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

টেস্টগুলো TestBox নামের একটি লাইব্রেরি ব্যবহার করে, যা xUnit এবং BDD স্টাইলের টেস্টিং সাপোর্ট করে। সব টেস্ট স্যুট [BDD স্টাইলে](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) লেখা হবে, যেখানে ক্লোজার দিয়ে টেস্ট স্পেক ডিফাইন করা হয়। TestBox ইনস্টল করার নিয়ে আপনাকে ভাবতে হবে না। CLI টেস্ট রানার সেটি আপনার হয়ে সামলে নেবে। প্রথমবার রান করার সময় শুধু ইন্টারনেটে সংযুক্ত থাকলেই হবে। এ সম্পর্কে আরও জানতে পড়ুন:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
