# পরিচিতি

## ক্লাস

C#-এ অবজেক্ট-অরিয়েন্টেড প্রোগ্রামিংয়ের প্রাথমিক গঠনটি হলো _ক্লাস_, যা ডেটা (_ফিল্ড_) আর আচরণের (_মেথড_) সমন্বয়। একটি ক্লাসের ফিল্ড আর মেথডকে একসাথে তার _মেম্বার_ বলা হয়।

অ্যাক্সেস মডিফায়ারের মাধ্যমে মেম্বারগুলোতে অ্যাক্সেস সীমাবদ্ধ করা যায়; এর মধ্যে সবচেয়ে কমন দুটি হলো:

- `public`: যেকোনো কোড মেম্বারটি অ্যাক্সেস করতে পারে (কোনো নিষেধাজ্ঞা নেই)।
- `private`: শুধু একই ক্লাসের কোডই মেম্বারটি অ্যাক্সেস করতে পারে।

একটি ক্লাসকে ওই ক্লাসের ইনস্ট্যান্স তৈরির টেমপ্লেট হিসেবে ভাবতে পারেন। একটি ক্লাসের ইনস্ট্যান্স (যাকে _অবজেক্ট_-ও বলা হয়) তৈরি করতে `new` কিওয়ার্ডটি ব্যবহার করা হয়:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

প্রতিটি ফিল্ডের একটি টাইপ থাকে এবং ক্লাসের যেকোনো জায়গায় ফিল্ড ডিফাইন করা যায়।
পাবলিক ফিল্ড ডিফাইন করা হয় PascalCase-এ, আর প্রাইভেট ফিল্ড ডিফাইন করা হয় camelCase-এ এবং তার আগে একটি আন্ডারস্কোর `_` বসানো হয়:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

চাইলে একটি ফিল্ডে শুরুর মান বসিয়ে দেওয়া যায়। কোনো ফিল্ডে যদি শুরুর মান _না_ দেওয়া হয়, তাহলে তার টাইপের ডিফল্ট ভ্যালুটি সেট করা হয়। ডট নোটেশন ব্যবহার করে একটি ইনস্ট্যান্সের ফিল্ডের মান পড়া যায় এবং পরিবর্তন করা যায়।

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

সাধারণত কোনো মেথড কল করার সাইড এফেক্ট হিসেবে প্রাইভেট ফিল্ডগুলো আপডেট করা হয়। এমন মেথড সাধারণত কোনো মান রিটার্ন করে না, সেক্ষেত্রে রিটার্ন টাইপ `void` হওয়া উচিত:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
