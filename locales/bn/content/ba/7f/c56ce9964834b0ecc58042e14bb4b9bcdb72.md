# ভূমিকা

অনেক ভাষায় `null` বা `none`-এর মতো একটি উপায় থাকে, যা দিয়ে বোঝানো হয় যে কোনো মান আসলে নেই। যেহেতু R তৈরি করা হয়েছে প্রচুর পরিমাণ (প্রায়শই অগোছালো) ডেটা সামলানোর জন্য, তাই এতে শূন্যতার একাধিক রূপ রয়েছে।

মূল লক্ষ্য হলো, অনুপস্থিত বা সন্দেহজনক মান যেখানেই পাওয়া যাক সেগুলো চিহ্নিত করা, আর তারপর কোনো এক্সেপশন ছাড়াই কাজ চালিয়ে যাওয়া।

## NULL

কোনো মান সত্যিই না থাকলে সেটি `NULL` দিয়ে প্রকাশ করা হয়। সম্ভবত C বা Python যা করে, তার সঙ্গে এটিই সবচেয়ে কাছাকাছি।

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

অনেক ক্ষেত্রেই `NULL` মানগুলোকে সহজভাবে উপেক্ষা করা হয়:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

এমন পরিস্থিতির জন্য, যেখানে কোনো মান আছে কিন্তু সেটি কী তা আমরা জানি না, `NA` ব্যবহার করা হয়। যেমন রাস্তায় চলাচলকারী যানবাহন গোনার সময় মানব পর্যবেক্ষকরা অসুস্থ হয়ে পড়তে পারেন, কিংবা স্বয়ংক্রিয় সেন্সর নষ্ট হয়ে যেতে পারে, কিন্তু যান চলাচল তো চলতেই থাকে।

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

তাই `NA` হলো একটি প্লেসহোল্ডার, যা মানুষকে সতর্ক করে দেয় যে এটি কীভাবে সামলাতে হবে সে বিষয়ে তাদের সিদ্ধান্ত নিতে হবে।

## খালি ভেক্টর

আশ্চর্যজনক মনে হতে পারে, তবে খালি কি না তা যাচাই করার কোনো আদর্শ উপায় R-এ নেই, যদিও কিছু থার্ড-পার্টি প্যাকেজ `is.empty()`-এর মতো নিজস্ব ফাংশন তৈরি করেছে।

এমনকি একটি খালি ভেক্টর তৈরি করাও একেবারে সোজা ব্যাপার নয়।
আগের একটি অংশে আমরা দেখেছি, কোনো আর্গুমেন্ট ছাড়া `c()` একটি ভেক্টর নয়, বরং `NULL` রিটার্ন করে।

```R
is.vector(c())
#> [1] FALSE
```

`logical()` বা `integer()`-এর মতো ফাংশন একটি আর্গুমেন্ট নেয়, যা দিয়ে কাঙ্ক্ষিত দৈর্ঘ্য নির্দিষ্ট করা হয়, আর সেই দৈর্ঘ্য শূন্যও হতে পারে।

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

আমরা একটি ভেক্টর তৈরি করে তার সব এলিমেন্ট মুছে ফেলতেও পারি, যেমনটি [ভেক্টর ধারণা][concept-vectors] অংশে বর্ণনা করা হয়েছে।
এতে উপযুক্ত টাইপের একটি শূন্য দৈর্ঘ্যের ভেক্টর পাওয়া যায়।

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
