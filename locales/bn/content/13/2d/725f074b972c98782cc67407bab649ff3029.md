# ভূমিকা

## বিট ম্যানিপুলেশন

Java-তে `byte`, `short`, `int`, `long` বা `char`-এর বিট ম্যানিপুলেট করার অপারেটর রয়েছে।

### শিফট অপারেটর

বিট বামে শিফট করতে `<<` এবং ডানে শিফট করতে `>>` ব্যবহার করুন।

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

`<<` অপারেটর সবসময় ডান দিকের প্রান্তে 0 বসায়।
কিন্তু `>>` বামদিকের সবচেয়ে বামের বিটটির মতোই বিট বসায় (সংখ্যাটি ঋণাত্মক হলে 1, ধনাত্মক হলে 0)।

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

ডানে শিফট করার সময় 0 বসাতে হলে বদলে `>>>` ব্যবহার করুন।

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### বিটওয়াইজ অপারেশন

#### বিটওয়াইজ AND

বিটওয়াইজ AND (`&`) অপারেটর দুটি মান নেয় এবং প্রতিটি বিটে একটি AND করে।
এটি প্রথম মানের প্রতিটি বিট দ্বিতীয় মানের একই অবস্থানের বিটের সাথে তুলনা করে।
দুটিই 1 হলে ফলাফলের বিটটি 1 হয়।
অন্যথায়, ফলাফলের বিটটি 0 হয়।

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### বিটওয়াইজ OR

বিটওয়াইজ OR (`|`) অপারেটর দুটি মান নেয় এবং প্রতিটি বিটে একটি OR করে।
এটি প্রথম মানের প্রতিটি বিট দ্বিতীয় মানের একই অবস্থানের বিটের সাথে তুলনা করে।
যেকোনো একটি বিট 1 হলে ফলাফলের বিটটি 1 হয়।
অন্যথায়, এটি 0 হয়।

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### বিটওয়াইজ XOR

বিটওয়াইজ XOR অপারেটর (`^`) দুটি মানের উপর একটি বিটওয়াইজ XOR করে।
বিটওয়াইজ AND ও বিটওয়াইজ OR অপারেটরের মতোই, এটি প্রথম মানের প্রতিটি বিট দ্বিতীয় মানের একই অবস্থানের বিটের সাথে মিলিয়ে দেখে।
এদের মধ্যে কেবল একটি 1 হলে ফলাফলের বিটটি 1 হয়।
অন্যথায়, এটি 0 হয়।

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### বিটওয়াইজ NOT(`~`)

শেষে, বিটওয়াইজ NOT অপারেটর (`~`) প্রতিটি বিট উল্টে দেয়।
আগের অপারেটরগুলোর বিপরীতে, এটি একটি ইউনারি অপারেটর, যা কেবল একটি মানের উপর কাজ করে।

```java
~0b0110_0101;
// # => 0b1001_1010
```
