# ভ্যারিয়েবল পরিচিতি

## ভ্যারিয়েবল

_ভ্যারিয়েবল_ হলো ডেটা রাখার জায়গা।
Bash-এ দুই ধরনের ডেটা আছে: স্ট্রিং আর অ্যারে।
অ্যারে নিয়ে কথা হবে পরে।

আপনি এভাবে একটি ভ্যারিয়েবল অ্যাসাইন করেন
```bash
name="value"
```

~~~~exercism/note
**গুরুত্বপূর্ণ**: সমান চিহ্নের দুই পাশে _কোনো স্পেস থাকবে না_!

যখন স্পেস থাকে, যেমন এই উদাহরণে,

```bash
x = 10
```

bash তখন `=` আর `10` এই **দুটি আর্গুমেন্ট** নিয়ে `x` **কমান্ডটি** কল করবে!
~~~~

ভ্যারিয়েবলকে _প্যারামিটার_-ও বলা হয়।
এই লেখায় দুটি পরিভাষা একই অর্থে ব্যবহৃত হবে।

bash যে গুরুত্বপূর্ণ প্যারামিটারগুলো ব্যবহার করে বা সেট করে, সেগুলোর মধ্যে আছে:

* `PATH`: বাইরের কমান্ড খুঁজে বের করতে ব্যবহৃত কোলন দিয়ে আলাদা করা ডিরেক্টরির তালিকা।
* `IFS`: "ইন্টারনাল ফিল্ড সেপারেটর"।
   এটা কীভাবে ব্যবহার হয়, তা নিচে দেখব।
* `PWD`: আপনার বর্তমান ওয়ার্কিং ডিরেক্টরি।
   এর মান `pwd` কমান্ডের আউটপুটের সমান হবে।
* `RANDOM`: ০ থেকে ৩২৭৬৭-এর মধ্যে একটি সিউডো-র্যান্ডম ইন্টিজার।
* `BASH_VERSION`: চলমান bash-এর ভার্সন স্ট্রিং।

## ভ্যারিয়েবলের নাম

ভ্যারিয়েবলের নাম গঠিত হয় _বড় হাতের অক্ষর, ছোট হাতের অক্ষর, সংখ্যা আর আন্ডারস্কোর_ দিয়ে।
এটি সংখ্যা দিয়ে শুরু হতে পারে না।

## প্যারামিটার এক্সপ্যানশন

`$varname` সিনট্যাক্স দিয়ে আপনি একটি প্যারামিটারের মান পান।

```bash
x=10
echo "The value of x is $x"
```

ভ্যারিয়েবলের নাম যেন আশপাশের লেখার সাথে মিশে না যায়, সেজন্য নামটি বন্ধনীর ভেতরে রাখতে পারেন।
যেমন `10x10` স্ট্রিংটি প্রিন্ট করতে

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

কিছু [স্টাইল গাইড][google-style-guide] পড়ার সুবিধা ও ধারাবাহিকতার জন্য বেশিরভাগ ক্ষেত্রে বন্ধনী ব্যবহারের পরামর্শ দেয়।

## পজিশনাল প্যারামিটার

[কমান্ড আর আর্গুমেন্ট][cmds-args] পাঠে আমরা আলোচনা করেছি, কমান্ড আর্গুমেন্ট নিতে পারে।
Bash স্ক্রিপ্টও এর ব্যতিক্রম নয়।
bash-এর চলমান ইনস্ট্যান্সের আর্গুমেন্টগুলোকে _পজিশনাল প্যারামিটার_ বলা হয়।
এগুলোকে এই বিশেষ প্যারামিটার দিয়ে পাওয়া যায়:

* `$1`: প্রথম পজিশনাল প্যারামিটার
* `$2` ... `$9`: পরের প্যারামিটারগুলো
* `${10}` ...: দুই অঙ্কের সংখ্যায় বন্ধনী লাগে।
* `$0`: বর্তমান স্ক্রিপ্টের নাম।

শেল ফাংশনের আর্গুমেন্টও পজিশনাল প্যারামিটার, এগুলোও ঠিক এভাবেই ব্যবহৃত হয়।
ফাংশন নিয়ে আরও বিস্তারিত দেখব পরের কোনো পাঠে।

### বিশেষ পজিশনাল প্যারামিটার

কয়েকটি _বিশেষ প্যারামিটার_ আছে, যা পজিশনাল প্যারামিটার নিয়ে কাজ করতে সাহায্য করে।

* `$#` এক্সপ্যান্ড হয়ে পজিশনাল প্যারামিটারের _সংখ্যা_ দেয়।
* `"$@"` এক্সপ্যান্ড হয়ে সব পজিশনাল প্যারামিটারের তালিকা দেয়, প্রতিটি আলাদা শব্দ হিসেবে।
* `"$*"` এক্সপ্যান্ড হয়ে একটি মাত্র স্ট্রিং দেয়, যেখানে সব পজিশনাল প্যারামিটার একটি ক্যারেক্টার দিয়ে জোড়া লাগানো থাকে।
  * জোড়া লাগানোর ক্যারেক্টারটি হলো `$IFS` ভ্যারিয়েবলের _প্রথম ক্যারেক্টার_, যা ডিফল্টভাবে একটি স্পেস।

অন্য কমান্ডে পজিশনাল প্যারামিটার নিরাপদে কোটের ভেতরে রেখে পাঠানোর সবচেয়ে নিরাপদ উপায় হলো `"$@"`।
পজিশনাল প্যারামিটারগুলোর উপর লুপ চালাতেও আপনি এটি ব্যবহার করবেন:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

বাস্তবে `"$*"`-এর চেয়ে `"$@"` বেশি ব্যবহৃত হয়।

## কমান্ড সাবস্টিটিউশন

bash স্ক্রিপ্টে আপনি খুব প্রায়ই একটি কাজ করবেন: কোনো কমান্ডের আউটপুট ধরে সেটি একটি ভ্যারিয়েবলে রাখা।
এটি করতে আপনি ব্যবহার করবেন _কমান্ড সাবস্টিটিউশন_।

```bash
var=$(command)
```

যেমন একটি স্ট্রিংকে বড় হাতের অক্ষরে রূপান্তর করতে পারেন এভাবে:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## প্যারামিটার এক্সপ্যানশন নিয়ে আরও

ভ্যারিয়েবল আর স্ট্রিং নিয়ে কাজ করার জন্য bash-এ অনেক বিল্ট-ইন সুবিধা আছে, যাতে বাইরের কমান্ড ডাকতে না হয়।

* লেখাকে বড় হাতের অক্ষরে রূপান্তর।
  আগের অংশে দেখিয়েছিলাম কীভাবে `tr` দিয়ে লেখাকে বড় হাতের অক্ষরে রূপান্তর করা যায়।
  bash-এ এটি করতে:

  ```bash
  echo "${text^^}"
  ```

  একইভাবে, `${text,,}` মানটিকে ছোট হাতের অক্ষরে রূপান্তর করে।

* ভ্যারিয়েবল খালি থাকলে একটি ডিফল্ট মান সরবরাহ করা।

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* খোঁজা ও প্রতিস্থাপন।

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

আরও অনেক মজার প্যারামিটার এক্সপ্যানশন আছে: সাবস্ট্রিং বের করা, স্ট্রিংয়ের দৈর্ঘ্য পাওয়া, ডিফল্ট মান _অ্যাসাইন_ করা, মানের শুরু বা শেষ থেকে লেখা মুছে ফেলা, আরও কত কী।
এগুলো সম্পর্কে পড়ুন [ম্যানুয়ালে][param-exp]।
