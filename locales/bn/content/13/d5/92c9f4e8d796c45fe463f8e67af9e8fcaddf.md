# পরিচিতি

## হ্যাশ টেবিল

Common Lisp-এ হ্যাশ টেবিল হলো অ্যাসোসিয়েটিভ ডেটা সংরক্ষণের ডেটা স্ট্রাকচার। এগুলো কী (key)-কে মানের সাথে ম্যাপ করে, যেখানে কী (key) এবং মান দুটোই যেকোনো অবজেক্ট হতে পারে। অন্য ভাষায় এই ধারণাটিকে ম্যাপ, ডিকশনারি বা হ্যাশ বলা হতে পারে।

### হ্যাশ টেবিল তৈরি করা

`make-hash-table` ফাংশন দিয়ে হ্যাশ টেবিল তৈরি করা যায়।

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(খেয়াল করুন, হ্যাশ টেবিল প্রিন্ট হলে যা দেখা যায় তা ইমপ্লিমেন্টেশন-নির্ভর, তাই আপনার REPL-এ তা ভিন্নভাবে দেখা যেতে পারে।)

### কী (key) দিয়ে মান বের করা

হ্যাশ টেবিল থেকে কোনো কী (key) দিয়ে একটি মান পেতে আপনি `gethash` ফাংশন ব্যবহার করেন:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` [একাধিক মান][concept-multiple-values] রিটার্ন করে, যা আরেকটি ধারণায় ব্যাখ্যা করা হবে।

### মান যুক্ত করা

হ্যাশ টেবিলে একটি মান যুক্ত করতে আপনি `gethash`-এর সাথে `setf` এভাবে ব্যবহার করেন:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

এটি `*hash-table*` হ্যাশ টেবিলে `:foo` কী (key)-এর মান `:bar`-এ পরিবর্তন করবে। এটি মানটি রিটার্ন করে।

`setf`-এর ব্যবহার আরেকটি ধারণায় ব্যাখ্যা করা হবে।
