# নির্দেশনা

লেজার অ্যারে সক্রিয় করার আগে আপনাকে পূর্বাভাস দিতে হবে স্ফটিকগুলো ঠিক কোন ক্রমে আঘাত পাবে; স্ফটিকগুলো শনাক্ত করা হয় তাদের স্যাম্পল আইডি দিয়ে।

## উদাহরণ টেস্ট কেস

এই স্ফটিক অ্যারে কনফিগারেশনটি দেখুন:

```json
{
  "start": { "x": 0, "y": 0, "angle": 0 },
  "prisms": [
    { "id": 1, "x": 10, "y": 10, "angle": -90 },
    { "id": 2, "x": 10, "y": 0, "angle": 90 },
    { "id": 3, "x": 30, "y": 10, "angle": 45 },
    { "id": 4, "x": 20, "y": 0, "angle": 0 }
  ]
}
```

## কী ঘটছে

লেজারটি মূলবিন্দু `(0, 0)` থেকে যাত্রা শুরু করে এবং 0° কোণে ডানদিকে অনুভূমিকভাবে রশ্মি নিক্ষেপ করে। ধাপে ধাপে রশ্মির পথটি হলো:

**ধাপ ১**: রশ্মিটি x-অক্ষ বরাবর (y = 0) এগোতে এগোতে প্রথমে `(10, 0)` অবস্থানে **স্ফটিক #2**-এর উপর এসে পড়ে। এই স্ফটিকের প্রতিসরণ কোণ 90°, অর্থাৎ এটি রশ্মিটিকে তার বর্তমান পথের সঙ্গে লম্বভাবে বাঁকিয়ে দেয়। রশ্মিটি আগে 0° কোণে চলছিল, এখন সেটি 90° কোণে ঘুরে যায় (সোজা উপরের দিকে)।

**ধাপ ২**: এখন রশ্মিটি `(10, 0)` অবস্থান থেকে খাড়াভাবে উপরের দিকে এগোয় এবং `(10, 10)` অবস্থানে **স্ফটিক #1**-এর উপর এসে পড়ে। এই স্ফটিকের প্রতিসরণ কোণ -90°, যা রশ্মিটিকে তার বর্তমান দিকের সাপেক্ষে -90° বাঁকিয়ে দেয়। রশ্মিটি 90° কোণে চলছিল, তাই প্রতিসরণের পর সেটি এখন 0° কোণে (90° + (-90°) = 0°), আবার ডানদিকে অনুভূমিকভাবে এগোচ্ছে।

**ধাপ ৩**: `(10, 10)` অবস্থান থেকে রশ্মিটি অনুভূমিকভাবে এগোয় এবং `(30, 10)` অবস্থানে **স্ফটিক #3**-এর উপর এসে পড়ে। এই স্ফটিক রশ্মিটিকে 45° বাঁকিয়ে দেয়, ফলে তার দিক হয়ে যায় 45°। এরপর রশ্মিটি অ্যারের বাইরের শূন্যস্থানে চলে যায়।
