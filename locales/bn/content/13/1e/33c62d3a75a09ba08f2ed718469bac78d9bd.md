# ইনস্টলেশন

C ভাষার ট্র্যাকটি ব্যবহার করতে আপনার সিস্টেমে নিচের সফটওয়্যারগুলো ইনস্টল করা থাকা দরকার:

* একটি আধুনিক C কম্পাইলার
* Make বিল্ড টুল

Apple-এর Xcode IDE কম্পাইলার ও নেটিভ বিল্ড সিস্টেমকে একটি IDE (integrated development environment), অর্থাৎ একটি সমন্বিত ডেভেলপমেন্ট এনভায়রনমেন্টে একত্রিত করে।
Linux এনভায়রনমেন্টে সাধারণত কম্পাইলার ও নেটিভ বিল্ড সিস্টেম আলাদা কমান্ড-লাইন টুল হিসেবে পাওয়া যায়।

## Linux

কম্পাইলারের জন্য Linux ব্যবহারকারীদের gcc বা clang দরকার হবে, আর নেটিভ বিল্ডের জন্য দরকার হবে `make`। বেশিরভাগ ইউনিক্স সিস্টেমে Make আগে থেকেই ইনস্টল করা থাকে, তবে সম্ভবত আপনার প্যাকেজ ম্যানেজারের মাধ্যমেও এটি পাওয়া যায়। Debian ও Ubuntu ভিত্তিক ডিস্ট্রিবিউশনে যা কিছু দরকার তা না থাকলে `sudo apt-get install build-essential` দিয়ে ইনস্টল করা যাবে।

## MacOS

MacOS ব্যবহারকারীরা [Homebrew][] দিয়ে gcc বা clang ইনস্টল করতে পারেন, `brew install gcc` অথবা `brew install llvm` কমান্ডের মাধ্যমে।

## Windows

Windows 10 ব্যবহারকারীদের জন্য [Windows Subsystem for Linux][] ব্যবহার করে উপরের Linux-এর নির্দেশনা অনুসরণ করার পরামর্শ দেওয়া হয়।

আপনি যদি Windows-এর কোনো পুরনো সংস্করণ ব্যবহার করেন, অথবা আপনার জন্য WSL Bash উপলব্ধ না থাকে, তাহলে [MSYS][] বা [mingw-w64][] ব্যবহার করতে পারেন।

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
