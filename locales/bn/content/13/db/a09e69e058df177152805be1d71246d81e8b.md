# নির্দেশনা

আপনার নেটবল ক্লাবের প্রতিটি রাউন্ডের পর তার ল্যাডার হিসাব করে বের করতে হবে।

চারটি কাজই `NETBALL_LADDER` ক্লাসে থাকবে।

## 1. ল্যাডার পয়েন্ট

একটি জয়ের মূল্য ৪ পয়েন্ট, আর একটি ড্র-এর ২ পয়েন্ট। হারে কোনো পয়েন্ট নেই।

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. গোল পার্থক্য

নিজেদের করা গোল থেকে প্রতিপক্ষের করা গোল বিয়োগ করুন। এটি ঋণাত্মকও হতে পারে।

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. খেলা সম্পূর্ণ কোয়ার্টার

একটি কোয়ার্টার ১৫ মিনিট। কয়েক মিনিট দেওয়া হলে, সেটি কতটি সম্পূর্ণ কোয়ার্টার?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. কোয়ার্টারের ভেতরে কত মিনিট

একই সংখ্যক মিনিট দেওয়া হলে, চলতি কোয়ার্টারের কত মিনিট পার হয়েছে?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
