# নির্দেশনার সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                         |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | গুণনীয়ক ওয়ার্ডের অ্যারে         |
| `$a1`    | ইনপুট     | ইন্টিজার | গুণনীয়কের সংখ্যা               |
| `$a2`    | ইনপুট     | ইন্টিজার | সীমা                         |
| `$v0`    | আউটপুট    | ইন্টিজার | সীমার মধ্যে গুণিতকসমূহের যোগফল |
| `$t0-9`  | টেম্পোরারি | যেকোনো   | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত    |
