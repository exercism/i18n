# পরিচিতি

Factor-এ একটি স্ট্রিং হলো ক্যারেক্টারের একটি সিকোয়েন্স, যা সম্পূর্ণ [`sequences` প্রোটোকল][sequence-protocol] শেয়ার করে (`length`, `nth`, `head`, `tail`, `map`, `filter`, ইত্যাদি), আর এর নিজস্ব ডেডিকেটেড ভোকাবুলারিগুলোও আছে।

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

স্ট্রিং-সংক্রান্ত ওয়ার্ডগুলো বেশিরভাগই [`splitting`][splitting], [`ascii`][ascii] আর [`unicode`][unicode] ভোকাবুলারিতে থাকে:

| ওয়ার্ড         | ভোকাব         | কী কাজ করে                          |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | প্রথম যেটি আসে সেখানে কেটে ফেলে           |
| `split`      | [`splitting`][splitting]   | একটি সেটের যেকোনো ক্যারেক্টারে কেটে ফেলে         |
| `harvest`    | [`sequences`][sequences]   | স্প্লিটের ফলাফল থেকে খালি অংশ ফেলে দেয় |
| `replace`    | [`splitting`][splitting]   | একটি সাবস্ট্রিং প্রতিস্থাপন করে                |
| `surround`   | [`sequences`][sequences]   | প্রিফিক্স ও সাফিক্স দিয়ে মোড়ে         |
| `glue`       | [`sequences`][sequences]   | সেপারেটর দিয়ে দুটি স্ট্রিং জোড়া লাগায়     |
| `join`       | [`sequences`][sequences]   | সেপারেটর দিয়ে স্ট্রিংয়ের একটি অ্যারে জোড়া লাগায় |
| `>lower`     | [`ascii`][ascii]       | ছোট হাতের অক্ষরে রূপান্তর (ASCII)                     |
| `>upper`     | [`ascii`][ascii]       | বড় হাতের অক্ষরে রূপান্তর (ASCII)                     |
| `[ blank? ] trim` | [`sequences`][sequences] | শুরু ও শেষের হোয়াইটস্পেস সরিয়ে দেয় |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | শুরুর স্লট |
| `first2`, `first3`         | [`sequences`][sequences]   | শুরুর দুটি বা তিনটি স্লট আলাদা করে |
| `>string`    | [`strings`][strings]     | ক্যারেক্টারের একটি সিকোয়েন্সকে স্ট্রিংয়ে পরিণত করে |
| `1string`    | [`strings`][strings]     | একটি ক্যারেক্টারকে এক ক্যারেক্টারের স্ট্রিংয়ে মোড়ে |
| `CHAR: x`    | parser        | এক ক্যারেক্টারের লিটারেল (যেমন `CHAR: A` → `65`) |

সংখ্যা ↔ স্ট্রিং রাউন্ড-ট্রিপিংয়ের জন্য [`math.parser`][math.parser] `number>string` ও `string>number` দেয়। ফরম্যাট-স্ট্রিং আউটপুটের জন্য [`formatting`][formatting] `sprintf`সহ আরও কয়েকটি ওয়ার্ড দেয়।

ইউনিকোড-সচেতন কেস কনভার্সন বা ক্যারেক্টার ক্লাসিফিকেশনের জন্য [`unicode`][unicode] ভোকাবুলারির সংশ্লিষ্ট ওয়ার্ডগুলো ব্যবহার করুন।
