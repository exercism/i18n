# নির্দেশাবলি

উইজার্ডস অ্যান্ড ওয়ারিয়ার্স গেমের ধারা বজায় রেখে এবার সব কাজে ব্যবহারযোগ্য একটি ডাই রোল করার মেথড যোগ করার সময় এসেছে। এটি হবে ১ থেকে ১৮ পর্যন্ত সংখ্যাযুক্ত প্রচলিত ১৮-তাদের ডাই। খেলোয়াড়েরা একটি স্পেল স্ট্রেংথও তৈরি করে।

## 1. একজন _উইজার্ডস অ্যান্ড ওয়ারিয়ার্স_ খেলোয়াড়কে ডাই রোল করতে সক্ষম করুন।

`Player` ক্লাসে একটি `RollDie()` মেথড ইমপ্লিমেন্ট করুন।

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. খেলোয়াড়দের দরকার তাদের স্ট্রেংথ। স্পেল স্ট্রেংথ তৈরির একটি উপায় দিন

প্লেয়ার ক্লাসে একটি `GenerateSpellStrength()` মেথড ইমপ্লিমেন্ট করুন। স্পেল স্ট্রেংথ 0.0 থেকে 100.0-এর কম পর্যন্ত যেকোনো মান হতে পারে।

মনে রাখবেন, স্পেল স্ট্রেংথ অবশ্যই একটি বাস্তব সংখ্যা হতে হবে (ইন্টিজার নয়), যাতে দুই প্রতিপক্ষের স্ট্রেংথ তুলনা করার সময় ড্র হওয়ার সম্ভাবনা কমে।

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
