# সহায়তা

## Test চালানো

Factor ট্র্যাকটি **Factor 0.101** ব্যবহার করে। [এটি ইনস্টল করার](https://exercism.org/docs/tracks/factor/installation) পর, এই অনুশীলনীর ডিরেক্টরি থেকে চালান:

```
factor -roots=. -run=exercism-tools <exercise>
```

উদাহরণস্বরূপ, `hello-world` অনুশীলনীর ক্ষেত্রে:

```
factor -roots=. -run=exercism-tools hello-world
```

প্রতিটি অনুশীলনীর সঙ্গে ছোট একটি `exercism-tools` ভোকাবুলারি বান্ডল করা থাকে, যা Test রান পরিচালনা করে। প্রতিটি Test পাস হলে রানার 0 স্ট্যাটাস নিয়ে বেরিয়ে যায়, আর কোনো Test ফেল করলে 0 ছাড়া অন্য স্ট্যাটাস এবং ডায়াগনস্টিক আউটপুট নিয়ে বেরিয়ে যায়।

### বাদ দেওয়া Test

ডিফল্টভাবে কেবল প্রথম Test চলে। এর কার্যপদ্ধতিটি হলো Test ফাইলের `STOP-HERE` লাইনটি: পার্স করার সময় এটি Factor-এর লেক্সারকে তার নিচের সবকিছু উপেক্ষা করতে বলে, তাই রানার কেবল উপরের Test গুলোই দেখে। আপনার প্রথম Test পাস হয়ে গেলে আরও Test চালু করার দুটি উপায় আছে:

- **`STOP-HERE` লাইনটি মুছে ফেলুন**, যাতে বাকি সব Test একসঙ্গে চালু হয়।
- **`STOP-HERE` লাইনটি আরও নিচে সরিয়ে নিন**, যাতে একবারে একটি করে Test, বা একবারে একটি করে `TASK:` চালু হয়। কনসেপ্ট অনুশীলনীগুলো তাদের Test গুলোকে `TASK:` মার্কারের নিচে দলে ভাগ করে রাখে, তাই পরের `TASK:`-এর ঠিক আগে `STOP-HERE` সরিয়ে নেওয়া স্বাভাবিক একটি ধাপ।

সব Test পাস হলে বুঝবেন, আপনি অনুশীলনীটি সমাধান করে ফেলেছেন।

## আপনার সমাধান জমা দেওয়া

অনুশীলনীর ডিরেক্টরি থেকে:

```
exercism submit <exercise>/<exercise>.factor
```

উদাহরণস্বরূপ:

```
exercism submit hello-world/hello-world.factor
```

অনুশীলনীর `.meta/config.json` ফাইলে যদি একাধিক সমাধান ফাইলের নাম থাকে (কিছু কনসেপ্ট অনুশীলনী একটি সমাধানকে হেল্পার সাব-ভোকাবুলারিতে ভাগ করে রাখে), তাহলে আপনি যে প্রতিটি ফাইল সম্পাদনা করেছেন, সেটি `exercism submit`-কে দিতে হবে।

## অসম্পূর্ণ সমাধান জমা দেওয়া

Test ফেল করলেও আপনি সমাধান জমা দিতে পারেন। এতে আপনি দেখতে পাবেন, অন্যরা অনুশীলনীটির কাছে কীভাবে এগিয়েছে, আর এখন পর্যন্ত যা করেছেন তার জন্য মেন্টরের মতামত চাইতে পারবেন।

## আরও সহায়তা পাওয়া

- ট্র্যাক নিয়ে প্রশ্ন আর মতামতের জন্য [Exercism ফোরামের Factor ক্যাটাগরি](https://forum.exercism.org/c/programming/factor/) হলো সেরা জায়গা।
- [Exercism Discord](https://exercism.org/r/discord)-এ সাধারণ সহায়তার জন্য এবং প্রতিটি ট্র্যাকের জন্য আলাদা চ্যানেল আছে।
- Factor-এর অফিসিয়াল ডকুমেন্টেশন খুঁজে দেখা যায় এবং তা পূর্ণাঙ্গ। শুরু করার দুটি ভালো জায়গা:
  - [Factor হ্যান্ডবুক](https://docs.factorcode.org/content/article-handbook.html): রেফারেন্স-ধাঁচের, ভোকাবুলারি অনুসারে সাজানো।
  - [Factor কুকবুক](https://docs.factorcode.org/content/article-cookbook.html): বিষয় অনুসারে ছোট ছোট, ইডিওমাটিক উদাহরণ।
- Andrea Ferretti-র [Factor টিউটোরিয়াল](https://andreaferretti.github.io/factor-tutorial/) হলো ভাষা এবং ডেভেলপমেন্ট এনভায়রনমেন্টের একটি দ্রুত ও বন্ধুত্বপূর্ণ পরিচিতি।
