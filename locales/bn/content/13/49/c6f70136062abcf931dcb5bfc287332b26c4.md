# Bools

হাস্কেলে [`Bool`][bools] নামে একটি টাইপ আছে।
এটি `True` ও `False` নিয়ে গঠিত একটি এনুমারেশন।

## লজিক্যাল অপারেটর

হাস্কেলে তিনটি লজিক্যাল অপারেটর আছে (`not`, `||`, `&&`), যেগুলো Bool-গুলোকে একত্রিত করে ভিন্ন ভিন্ন মান দেয় এমন এক্সপ্রেশন তৈরি করে।

### অ্যান্ড(`&&`)

হাস্কেলে [_অ্যান্ড_ অপারেটর][and] `&&` দিয়ে প্রকাশ করা হয় এবং দুটি মানই `True` হলে এটি `True` রিটার্ন করে; অন্যথায় এটি `False` রিটার্ন করে।
_অ্যান্ড_ অপারেটর ব্যবহার করার সময় একটি Bool `&&`-এর ডান দিকে আর আরেকটি বাম দিকে বসানো হয়।

```haskell
True && True
-- -> True

True && False
-- -> False
```

### অর(`||`)

হাস্কেলে [_অর_ অপারেটর][or] `||` দিয়ে প্রকাশ করা হয় এবং প্রদত্ত মানগুলোর **অন্তত একটি** `True` হলে এটি `True` রিটার্ন করে। 
দুটি মানই `False` হলে এটি `False` রিটার্ন করে।
_অর_ অপারেটর ব্যবহার করার সময় একটি Bool `||`-এর ডান দিকে আর আরেকটি বাম দিকে রাখা উচিত।

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### নট(`not`)

হাস্কেলে _নট_ অপারেটর `not` দিয়ে প্রকাশ করা হয় এবং প্রদত্ত Bool-টি `False` হলে `True` রিটার্ন করে, আর `True` দিলে `False` রিটার্ন করে।
_নট_ অপারেটর ব্যবহার করার সময় অপারেটরের (`not`) পরে একটি Bool বসানো উচিত।

```haskell
not True
-- -> False

not False
-- -> True
```

## বন্ধনী ব্যবহার(`()`)

বুলিয়ান নিয়ে কাজ করার সময় আপনি বন্ধনী ব্যবহার করে ঠিক করতে পারেন কোন Bool আগে মূল্যায়ন করা হবে।
বন্ধনী কীভাবে ব্যবহার করা হয়েছে, তার উপর নির্ভর করে ফলাফল ভিন্ন হতে পারে।
হাস্কেলে বন্ধনীর ভেতরের অংশ আগে মূল্যায়ন করা হয়।

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

যেহেতু বন্ধনীর ভেতরের অংশ আগে মূল্যায়ন করা হয়, তাই নিচের উদাহরণে _নট_ অপারেটর বন্ধনীর ভেতরের এক্সপ্রেশনে প্রয়োগ হবে।

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```
