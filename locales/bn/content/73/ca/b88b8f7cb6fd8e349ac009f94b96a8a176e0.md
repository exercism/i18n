# নির্দেশনা

এই অনুশীলনীতে আপনি আপনার প্রিয় রান্নার বইয়ের একটি দুর্দান্ত লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার সামনে পাঁচটি কাজ রয়েছে, যার সবগুলোই লাসাগনা রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

`Lasagna.expected_minutes_in_oven/0` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং লাসাগনাটি ওভেনে কত মিনিট থাকা উচিত তা রিটার্ন করে। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় ৪০ মিনিট:

```elixir
Lasagna.expected_minutes_in_oven()
# => 40
```

## 2. ওভেনে আর কত মিনিট থাকতে হবে তা হিসাব করুন

`Lasagna.remaining_minutes_in_oven/1` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসাগনাটি আসলে কত মিনিট ধরে ওভেনে আছে তা নেয় এবং আগের কাজের ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে লাসাগনাটিকে আর কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```elixir
Lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`Lasagna.preparation_time_in_minutes/1` ফাংশনটি ডিফাইন করুন, যেটি আর্গুমেন্ট হিসেবে লাসাগনায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যা নেয় এবং লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```elixir
Lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`Lasagna.total_time_in_minutes/2` ফাংশনটি ডিফাইন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসাগনায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে আছে সেই সংখ্যা। ফাংশনটি রিটার্ন করবে লাসাগনা রান্নার কাজে আপনার মোট কত মিনিট লেগেছে, অর্থাৎ প্রস্তুতির সময় (মিনিটে) এবং এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```elixir
Lasagna.total_time_in_minutes(3, 20)
# => 26
```

## 5. লাসাগনা তৈরি হয়ে গেছে জানিয়ে একটি নোটিফিকেশন তৈরি করুন

`Lasagna.alarm/0` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং লাসাগনাটি খাওয়ার জন্য তৈরি হয়ে গেছে বোঝায় এমন একটি বার্তা রিটার্ন করে।

```elixir
Lasagna.alarm()
# => "Ding!"
```
