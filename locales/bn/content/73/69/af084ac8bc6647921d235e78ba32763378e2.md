# নির্দেশনা

আপনি জার্মানির মিউনিখে একটি বড় কোম্পানির সিস্টেম অ্যাডমিনিস্ট্রেটর হিসেবে কাজ করছেন। আপনার একটি দায়িত্ব হলো ইমেইল অ্যাকাউন্ট ব্যবস্থাপনা।

মানুষের কাছ থেকে আপনি অভিযোগ শুনছেন যে তারা মিস্টার মুলারকে ইমেইল লিখতে পারছেন না। আপনি দ্রুত বুঝতে পারেন যে কোম্পানির বেশিরভাগ মানুষ একটি পুরনো ইমেইল ক্লায়েন্ট ব্যবহার করেন, যা নন-ASCII ক্যারেক্টারের কারণে `müller@firma.de`-কে বৈধ ইমেইল হিসেবে চিনতে পারে না।

মানুষকে তাদের প্রিয় পুরনো ইমেইল ক্লায়েন্ট ছাড়তে বলাটা একটা হেরে যাওয়া লড়াই, তাই আপনি সিদ্ধান্ত নেন যে সব ইমেইল অ্যাকাউন্টের জন্য স্যানিটাইজড অ্যালিয়াস তৈরি করবেন।

## 1. ছোট হাতের অক্ষর ছাড়া বাকি সবকিছু সরিয়ে বিদ্যমান ইউজারনেম স্যানিটাইজ করুন

`sanitize/1` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি ইনপুট হিসেবে একটি ইউজারনেম চারলিস্ট নেবে এবং ছোট হাতের অক্ষর ছাড়া বাকি সব ক্যারেক্টার সরিয়ে ফেলা ইউজারনেমটি রিটার্ন করবে।

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. আন্ডারস্কোরের অনুমতি দিন

`sanitize/1` ফাংশনটি এক্সটেন্ড করুন। এটি ইউজারনেম থেকে আন্ডারস্কোর সরাবে না।

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. জার্মান ক্যারেক্টার প্রতিস্থাপন করুন

জার্মান বর্ণমালায় ৪টি নন-ASCII ক্যারেক্টার আছে, এবং প্রতিটিরই কমনভাবে স্বীকৃত ASCII বিকল্প রয়েছে।

| জার্মান ক্যারেক্টার | ASCII বিকল্প |
| ------------------ | ------------ |
| ä                  | ae           |
| ö                  | oe           |
| ü                  | ue           |
| ß                  | ss           |

`sanitize/1` ফাংশনটি এক্সটেন্ড করুন। এটি টেবিল অনুযায়ী জার্মান ক্যারেক্টার প্রতিস্থাপন করবে। আপনি নিশ্চিন্তে ধরে নিতে পারেন যে সব ইউজারনেম আগে থেকেই ছোট হাতের অক্ষরে লেখা।

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
