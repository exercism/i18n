# পরিচিতি

[Lua](https://lua.org) একটি সরল, তবুও শক্তিশালী, দক্ষ, হালকা ও এমবেডযোগ্য স্ক্রিপ্টিং ভাষা। ১৯৯৩ সাল থেকে ব্রাজিলের [PUC-RIO](https://www.puc-rio.br/)-তে Roberto Ierusalimschy, Waldemar Celes এবং Luiz Henrique de Figueiredo-র দল এটি ডিজাইন, বাস্তবায়ন ও রক্ষণাবেক্ষণ করে আসছে।

## মন্তব্য

Lua-তে এক-লাইনের মন্তব্য শুরু হয় `--` দিয়ে, আর বহু-লাইনের মন্তব্য শুরু হয় `--[[` দিয়ে ও শেষ হয় `]]` দিয়ে।
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## ভ্যারিয়েবল

Lua-তে তিন ধরনের ভ্যারিয়েবল আছে: গ্লোবাল ভ্যারিয়েবল, লোকাল ভ্যারিয়েবল এবং টেবিল ফিল্ড। ব্যাপারটি সহজ রাখতে এখানে কেবল লোকাল ভ্যারিয়েবলের কথা বলা হয়েছে। ডিফল্টভাবে সব ভ্যারিয়েবলই গ্লোবাল, তাই লোকাল ভ্যারিয়েবল ঘোষণা করার সময় `local` কিওয়ার্ড দিয়ে সেটি স্পষ্ট করে জানাতে হয়।
```lua
local x
```

`=` অপারেটর ব্যবহার করে একটি ভ্যারিয়েবলে মান অ্যাসাইন করা যায়।
```lua
local x = 1
```

একটি `local` ভ্যারিয়েবলের স্কোপ কেবল যে ব্লকে এটি ঘোষণা করা হয়েছে সেখানেই সীমাবদ্ধ। একটি ব্লক হতে পারে কোনো কন্ট্রোল স্ট্রাকচারের বডি, কোনো ফাংশনের বডি, অথবা যে ফাইল বা স্ট্রিং-এ ভ্যারিয়েবলটি ঘোষণা করা হয়েছে সেটি।
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## ফাংশন

একটি ফাংশন ঘোষণা করা হয় `function` কিওয়ার্ড দিয়ে, আর ভ্যারিয়েবলের মতোই এটি ডিফল্টভাবে গ্লোবাল। একটি ফাংশন ডেফিনিশনে থাকে একটি নাম, প্যারামিটারের একটি তালিকা এবং একটি বডি। `return` কিওয়ার্ডে পৌঁছালেই ফাংশনটি শেষ হয়ে যায় এবং তার পরে যে মানগুলো লেখা আছে সেগুলো রিটার্ন করে। `return` উল্লেখ না থাকলে ফাংশনটি `nil` রিটার্ন করবে।

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## টেবিল

Lua-তে ডেটা সাজানোর একমাত্র উপায় টেবিল, আর এটি খুবই শক্তিশালী। অ্যারে, সেট, অবজেক্ট, মডিউল এবং আরও অনেক কিছু প্রকাশ করতে এগুলো ব্যবহার করা হয়। মূলত Lua-র একটি টেবিল হলো একটি অ্যাসোসিয়েটিভ অ্যারে।
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

পরের অংশটির জন্য যা দরকার, এ তো কেবল তারই এক ঝলক। এই বিষয়ে আমরা পরে বিস্তারিতভাবে ফিরে আসব।

## মডিউল

একটি মডিউল হলো কোডের একটি সংগ্রহ, যা একটি `.lua` সোর্স ফাইলে রাখা থাকে। মডিউল যা কিছু এক্সপোর্ট করে, সবই একটি টেবিলে রাখা হয় এবং ফাইলের শেষে এই টেবিলটিই রিটার্ন করা হয়। তাই টেবিলটি মূলত একধরনের নেমস্পেস হিসেবে কাজ করে।
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

এরপর `require` ফাংশনের মাধ্যমে ওই মডিউলটি অন্য একটি ফাইলে লোড করা যায়, আর সেটি ওই টেবিলটি রিটার্ন করে।
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

`say.hello` দেখলে আমরা ভাবব "`say` মডিউলের `hello` ফাংশন"। কিন্তু আমরা জানি `say-hello.lua` একটি টেবিল রিটার্ন করে, আর টেবিলের অংশটি আবার দেখলে বোঝা যায়, Lua-তে এই এক্সপ্রেশনটির মানে হলো "`hello` স্ট্রিংটি কী (key) হিসেবে ব্যবহার করে `say` টেবিলে ইনডেক্স করা"।

মডিউল থেকে একটি টেবিল রিটার্ন করা ভালো অভ্যাস হলেও, ফাংশনের মতো অন্য যেকোনো টাইপও রিটার্ন করা যায়।

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
