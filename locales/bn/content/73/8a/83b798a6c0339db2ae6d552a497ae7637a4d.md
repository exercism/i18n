# ভূমিকা

মূলত দুই ধরনের লুপ থাকে:

1. একটি শর্ত পূরণ হওয়া পর্যন্ত লুপ চালানো।
2. একটি কালেকশনের এলিমেন্টগুলোর উপর লুপ চালানো।

R-এ দুটোই সম্ভব, যদিও প্রথমটি বেশি কমন হতে পারে।

## `while` ও `repeat`

যেসব সমস্যায় লুপটি কতবার ঘুরবে তা আগে থেকে জানা থাকে না, সেগুলোর জন্য R-এ রয়েছে শর্তসহ `while` লুপ, আর শর্তহীন `repeat` লুপ (`while (TRUE)`-এর সমতুল্য)।

মূল রূপটি বেশ সহজ:

```R
while (condition) {
  do_something()
}
```

এক্ষেত্রে প্রোগ্রামটি লুপে ঘুরতেই থাকবে, যতক্ষণ না `condition` আর `TRUE` থাকে।

লুপ থেকে আগেই বেরিয়ে আসার দুটি উপায় আছে:

- একটি `break` লুপটি থেকে বেরিয়ে আসে, আর লুপের শেষ `}`-এর পরের লাইন থেকে এক্সিকিউশন চলতে থাকে।
- একটি `return(x)` বর্তমান ফাংশনের এক্সিকিউশন থামিয়ে দেয় এবং রিটার্ন ভ্যালু `x` কলকারীর কাছে ফিরিয়ে দেয়।

এই সুবিধাগুলো থাকায় মাঝে মাঝে `repeat { ... }` দিয়ে একটি "অসীম" লুপ তৈরি করা সুবিধাজনক হতে পারে, আর তারপর লুপ বডির ভেতরে থামার শর্ত খুঁজে পেয়ে `break` বা `return` চালু করা যায়।

এই তিনটি ভ্যারিয়েন্ট সমতুল্য এবং প্রত্যেকটিই `x == 0.4444...` দিয়ে শেষ হয়

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## একটি ভেক্টরের উপর ইটারেশন করা

R-এ এটি অনেক সময় প্রয়োজন হয় না।
অন্য কনসেপ্টগুলোতে আলোচনা করা হয়েছে, অনেক ফাংশনই পুরো ভেক্টরের উপর কাজ করে।

তবে, সরাসরি লেখা লুপ কখনও কখনও এড়ানো যায় না।
এটি বিশেষভাবে সত্য যখন:

- লুপ বডির প্রিন্টিং বা ফাইল I/O-এর মতো সাইড ইফেক্ট থাকে।
- কোনো একটি মানদণ্ডে পৌঁছানো পর্যন্ত লুপ চলতে থাকে, আর কতবার ঘুরতে হবে তা আগে থেকে অনুমান করা যায় না।

লুপের শর্ত অবশ্যই বন্ধনীর ভেতরে থাকতে হবে।
ফাংশন বডির মতোই, এক লাইনের লুপ বডির ক্ষেত্রে দ্বিতীয় বন্ধনী `{}` ঐচ্ছিক (তবে প্রায়ই ব্যবহার করা হয়)।

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

যদি বর্তমান ইটারেশন কোনো শর্ত পূরণ করতে না পারে, তবে `next` দিয়ে সাথে সাথে পরের ইটারেশনে চলে যাওয়া যায়:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

সংখ্যাসূচক ইনডেক্স দরকার হলে `seq_along()` ব্যবহার করুন।

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)` ব্যবহার করা _সুপারিশ করা হয় না_, কারণ `length(v)` শূন্য হলে এটি সমস্যা তৈরি করতে পারে।
`1:0` রেঞ্জটি `c(1, 0)`-এর সমতুল্য, তাই লুপ বডি এক্সিকিউট হবে এবং সম্ভবত ব্যর্থ হবে।
`seq_along()` ফাংশনটি এই পরিস্থিতি সঠিকভাবে সামলানোর জন্যই তৈরি।
