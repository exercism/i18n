# সম্পর্কে

[সুইচ এক্সপ্রেশন][switch-expressions] [সুইচ স্টেটমেন্ট][switch-statements]-এর মতোই আচরণ করে, যেগুলো [concept:csharp/switch-statements]() অনুশীলনীতে আলোচনা করা হয়েছে। এগুলো এক ধরনের ডিসিশন টেবিল সমর্থন করে, যা ইনপুট শর্তগুলোকে অ্যাকশন বা মানের সাথে ম্যাপ করে।

সুইচ এক্সপ্রেশনের মূল ভিত্তি হলো _প্যাটার্ন ম্যাচিং_। কোডিং অনুশীলনীতে আমরা `const` প্যাটার্নের সাথে মান মিলিয়েছিলাম। এখানে `switch`-এর ইনপুট হলো একটি _রেঞ্জ এক্সপ্রেশন_, যা `const` মান এবং _কেস গার্ড_-এ ব্যবহৃত মানের সাথে মিলিয়ে দেখা হয়।

কেসগুলো (যেগুলোকে _সুইচ আর্ম_ বলা হয়) লেখার ক্রম অনুযায়ী মূল্যায়ন করা হয়, আর কোনো একটি মিল পাওয়া মাত্রই প্রক্রিয়াটি থেমে যায় এবং সংশ্লিষ্ট মানটি রিটার্ন করা হয়।

তালিকায় সবার শেষে থাকা `_` কেসটি মিল সম্পূর্ণ হওয়া নিশ্চিত করতে এবং সম্ভাব্য রান-টাইম এরর এড়াতে কাজে লাগে।

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

`switch`-এর একটি "আর্ম" নির্বাচিত হয়, যখন কোনো প্যাটার্ন রেঞ্জ ভ্যারিয়েবলের সাথে মেলে এবং কেস গার্ড সত্য হয়।

সুইচ এক্সপ্রেশন [টাইপ প্যাটার্ন][pattern-matching] ও রিকার্সিভ ম্যাচিংও সমর্থন করে।
