# পরিচিতি

যেখানে টাইপ ইমপ্লিসিটভাবে কাস্ট করা যায় না, সেখানে আপনাকে একটি এক্সপ্লিসিট কাস্ট অপারেটর ব্যবহার করতে হবে।
কাস্ট অপারেটর আসলে এর চেয়ে বেশি কিছু নয়, যে মানটি আপনি কাস্ট করতে চান তার আগে প্রথম বন্ধনীতে বসানো টার্গেট টাইপটি:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```
