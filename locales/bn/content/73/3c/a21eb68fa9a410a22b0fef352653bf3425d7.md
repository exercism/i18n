# টেস্ট

Exercism ওয়েবসাইটের অনলাইন এডিটর ব্যবহার করে অনুশীলনীগুলো সমাধান করতে পারেন।
অথবা, অনুশীলনীগুলো আপনার কম্পিউটারে ডাউনলোড করে স্থানীয়ভাবে সমাধান করে সেগুলো Exercism-এ জমা দিতে পারেন।
এই ডকুমেন্টের বাকি অংশে স্থানীয়ভাবে কাজ করার বিষয়ে বলা হয়েছে।

## Exercism CLI

অনুশীলনী ডাউনলোড ও জমা দিতে আপনার `exercism` কমান্ড-লাইন টুলটি লাগবে।
এটি ডাউনলোড ও কনফিগার করার নির্দেশনার জন্য [exercism cli ডকুমেন্টেশন][exercism-cli] দেখুন।

একটি অনুশীলনী ডাউনলোড করতে, এটি করুন:

```bash
exercism download --track 8th --exercise hello-world
```

এবং অনুশীলনীর ডিরেক্টরিতে যান:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

অথবা আপনি Windows-এ থাকলে:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

মনে রাখবেন, `exercism configure` কমান্ডটি ব্যবহার করে আপনার exercism ওয়ার্কস্পেস পেতে পারেন।

## স্থানীয়ভাবে টেস্ট করা

একটি অনুশীলনীর টেস্ট চালাতে, আপনাকে সঠিক অনুশীলনী ডিরেক্টরিতে থাকতে হবে।
তারপর এই কমান্ড দিয়ে টেস্ট চালু করুন:

```bash
8th -f test.8th
```

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করার অর্থ হলো তার সব টেস্ট পাস করানো।
ডিফল্টভাবে, আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) এক্সিকিউট হয়।
এটি ইচ্ছাকৃত, কারণ এটি আপনাকে কেবল সেই একটি টেস্ট পাস করানোর দিকে মনোযোগ দিতে দেয়।
এটি পাস হয়ে গেলে, `SKIP-REST-OF-TESTS` লাইনটি তার নিচে সরিয়ে আপনি পরের টেস্টটি সক্রিয় করতে পারেন।

### স্কিপ ওভাররাইড করা

`SKIP-REST-OF-TESTS` শব্দটির পরের টেস্টগুলোসহ সব টেস্ট চালাতে, আপনি `RUN_ALL_TESTS` এনভায়রনমেন্ট ভ্যারিয়েবলটির মান `true` সেট করতে পারেন।
কেবল টেস্ট চালানোর সময়ের জন্য এটি সেট করার একটি উপায় হলো (macOS ও Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## আপনার সমাধান জমা দিন

exercism টুল ব্যবহার করে আপনার সমাধান Exercism ওয়েবসাইটে আপলোড করতে:

```bash
exercism submit
```

মনে রাখবেন, সব টেস্ট পাস না করলেও আপনি আপনার কোড আপলোড করতে পারেন।
আপনি যদি আটকে যান এবং একজন মেন্টরের সাহায্য প্রয়োজন হয়, তাহলে এটি ভালো।
