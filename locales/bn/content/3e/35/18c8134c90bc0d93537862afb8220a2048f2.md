# ভূমিকা

একটি ইন্টারফেসকে একটি ক্লাসের সিগনেচার হিসেবে বোঝা যায়, কারণ এটি একটি ক্লাসের পাবলিক ফিল্ডগুলো বর্ণনা করে। একটি ক্লাস `implments` কিওয়ার্ড দিয়ে একটি `interface` _ইমপ্লিমেন্ট করে_।

এর সিনট্যাক্স একটি ক্লাসের সিনট্যাক্সের সাথে অনেকটাই মিল, শুধু এই পার্থক্য যে এখানে মেথডগুলো বডি ছাড়া সিগনেচার হিসেবে থাকে:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

একটি ইন্টারফেস থেকে ইমপ্লিমেন্ট করা ফিল্ডগুলোকে **অবশ্যই** সবসময় একই ভিজিবিলিটি মডিফায়ার ব্যবহার করতে হবে। উদাহরণস্বরূপ, কোনো ইন্টারফেসে `a` ভ্যারিয়েবলটি `public` হলে, তার ইমপ্লিমেন্টেশনেও `public` থাকতে হবে।
