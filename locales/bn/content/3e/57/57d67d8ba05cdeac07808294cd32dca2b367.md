# পরিচিতি

**ওয়ার্ড** হলো Factor-এ ফাংশনের নাম। `basics`-এর ডেটা স্ট্যাকের উপর ভিত্তি করে এই ধারণাটি আপনার নিজের ওয়ার্ড ডিফাইন করা নিয়ে: পাটিগণিত করা, নির্দিষ্ট মানের নাম দেওয়া, এবং অন্য ওয়ার্ড দিয়ে নতুন ওয়ার্ড গঠন করা।

একটি ডেফিনিশনে শুরুতে থাকে `:`, তারপর একটি স্ট্যাক ইফেক্ট, তারপর বডি, আর সবশেষে `;`. কম্পাইলার যাচাই করে যে বডিটি ঘোষিত ইফেক্টের সাথে মেলে:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

ইন্টিজার পাটিগণিতের ওয়ার্ড `+`, `-`, `*` প্রত্যেকটি দুটি সংখ্যা পপ করে আর ফলাফলটি পুশ করে। এগুলো থাকে `math` ভোকাবুলারিতে, তাই এগুলো ব্যবহার করা একটি ফাইলে `USING:` লাইনে `math` থাকা দরকার। স্ট্যাকের একেবারে উপরের মানটিই ডান দিকের অপারেন্ড:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` একটি নির্দিষ্ট মানের নাম দেয়। একটি কনস্ট্যান্ট নিজেই একটি ওয়ার্ড, এটিকে কল করলেই মানটি পুশ হয়:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

একটি ওয়ার্ডের বডি ইতিমধ্যে স্কোপে থাকা যেকোনো ওয়ার্ড কল করতে পারে, এমনকি একই ফাইলে আগে আপনি যেগুলো ডিফাইন করেছেন সেগুলোও:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

আউটপুটের শেষে একটি `?` থাকা হলো "একটি বুলিয়ান" বোঝানোর রীতি, আর ওয়ার্ড ও কনস্ট্যান্ট দুটোই `lowercase-kebab-case` ব্যবহার করে।
