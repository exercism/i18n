# ভূমিকা

C#-এ একটি `string` হলো এমন একটি অবজেক্ট যা ইউনিকোড ক্যারেক্টারের (অক্ষর, সংখ্যা, যতিচিহ্ন ইত্যাদি) একটি সিকোয়েন্স হিসেবে অপরিবর্তনীয় টেক্সট উপস্থাপন করে। একটি `string` ইনস্ট্যান্স ডিফাইন করতে ডাবল কোট ব্যবহার করা হয়:

```csharp
string fruit = "Apple";
```

স্ট্রিংয়ের মেথডগুলো কল করে স্ট্রিং নিয়ে কাজ করা হয়। একবার একটি স্ট্রিং তৈরি হয়ে গেলে তার মান আর কখনো পরিবর্তন করা যায় না। যে মেথডগুলো একটি স্ট্রিং পরিবর্তন করে বলে মনে হয়, তারা আসলে একটি নতুন স্ট্রিং রিটার্ন করে।

একাধিক স্ট্রিং একসাথে কনক্যাটেনেট (যোগ) করা যায়। এটি করার সবচেয়ে সহজ উপায় হলো `+` অপারেটর ব্যবহার করা।

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

সাধারণ কনক্যাটেনেশনের চেয়ে জটিল যেকোনো স্ট্রিং ফরম্যাটিংয়ের জন্য স্ট্রিং ইন্টারপোলেশনকেই প্রাধান্য দেওয়া হয়। একটি স্ট্রিংয়ে ইন্টারপোলেশন ব্যবহার করতে তার আগে ডলার (`$`) চিহ্ন বসান। তারপর আপনার স্ট্রিংয়ের ভেতরের যেকোনো ভ্যারিয়েবল অ্যাক্সেস করতে দ্বিতীয় বন্ধনী (`{}`) ব্যবহার করতে পারেন।

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
