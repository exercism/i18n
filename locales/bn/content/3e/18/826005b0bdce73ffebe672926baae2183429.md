# ভূমিকা

সম্পূর্ণ Julia ট্র্যাকেই আপনাকে আপনার সমাধানকে ছোট ছোট লাইব্রেরির মতো ভাবতে হবে, অর্থাৎ আপনাকে ফাংশন, টাইপ ইত্যাদি ডিফাইন করতে হবে, যেগুলো পরে একটি টেস্ট স্যুটের বিপরীতে রান করা হবে।
সেই কারণেই আমরা একেবারে প্রথম ধারণা হিসেবে নামযুক্ত ফাংশন নিয়ে আলোচনা করব।

Julia একটি ডাইনামিক, স্ট্রংলি টাইপড প্রোগ্রামিং ভাষা।
এর প্রোগ্রামিং স্টাইল মূলত ফাংশনাল, যদিও Haskell-এর মতো ভাষাগুলোর চেয়ে এতে বেশি নমনীয়তা আছে।

## ভ্যারিয়েবল ও অ্যাসাইনমেন্ট

আগে থেকে কোনো ভ্যারিয়েবল ডিক্লেয়ার করার দরকার নেই।
শুধু একটি উপযুক্ত নামে একটি মান অ্যাসাইন করুন:

```julia-repl
julia> myvar = 42  # an integer
42

julia> name = "Maria"  # strings are surrounded by double-quotes ""
"Maria"
```

## ধ্রুবক

কোনো মান যদি পুরো প্রোগ্রাম জুড়ে পাওয়া দরকার হয়, কিন্তু তা পরিবর্তন হবে বলে আশা করা না যায়, তাহলে সেটিকে ধ্রুবক হিসেবে চিহ্নিত করাই ভালো।

একটি অ্যাসাইনমেন্টের আগে `const` কিওয়ার্ড বসালে কম্পাইলার আরও দক্ষ কোড তৈরি করতে পারে, যা একটি ভ্যারিয়েবলের ক্ষেত্রে সম্ভব নয়।

ধ্রুবক কোড লেখার সময় এরর থেকেও আপনাকে রক্ষা করতে সাহায্য করে।
ভুলবশত `const` মানটি পরিবর্তন করার চেষ্টা করলে একটি ওয়ার্নিং দেখতে পাবেন:

```julia-repl
julia> const answer = 42
42

julia> answer = 24
WARNING: redefinition of constant Main.answer. This may fail, cause incorrect answers, or produce other errors.
24
```

মনে রাখবেন, কোনো `const` শুধু যেকোনো ফাংশনের *বাইরে* ডিক্লেয়ার করা যায়।
এটি সাধারণত `*.jl` ফাইলের একেবারে উপরের দিকে, ফাংশন ডেফিনিশনের আগে থাকে।

## গাণিতিক অপারেটর

এগুলো অন্য অনেক ভাষার মতোই:

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division with floating-point result)
8 % 3  # 2 (remainder)
```

## ফাংশন

Julia-তে নামযুক্ত ফাংশন ডিফাইন করার দুটি সাধারণ উপায় আছে:

1. `function` কিওয়ার্ড ব্যবহার করে

    ```julia
    function muladd(x, y, z)
        x * y + z
    end
    ```

     ৪ স্পেস দিয়ে ইনডেন্ট করা পড়ার সুবিধার জন্য প্রচলিত, তবে কম্পাইলার এটি উপেক্ষা করে।
    `end` কিওয়ার্ডটি অবশ্যই লাগবে।

    মনে রাখবেন, আমরা `return x * y + z` লিখতেও পারতাম।
    তবে Julia ফাংশন সবসময়ই শেষ এক্সপ্রেশনটি রিটার্ন করে, তাই `return` কিওয়ার্ডটি ঐচ্ছিক।
    অনেক প্রোগ্রামার নিজেদের উদ্দেশ্য আরও স্পষ্ট করতে এটি লেখা পছন্দ করেন।

2. "অ্যাসাইনমেন্ট রূপ" ব্যবহার করে

    ```julia
    muladd(x, y, z) = x * y + z
    ```

    সংক্ষিপ্ত, একক-এক্সপ্রেশন ফাংশন তৈরির জন্য এটি সবচেয়ে বেশি ব্যবহৃত হয়।

    অ্যাসাইনমেন্ট রূপে `return` কিওয়ার্ড *কখনোই* ব্যবহার করা হয় না।

দুটি রূপই সমতুল্য এবং ঠিক একইভাবে ব্যবহৃত হয়, তাই যেটি পড়তে বেশি সুবিধাজনক মনে হয় সেটিই বেছে নিন।

কোনো ফাংশন কল করতে হলে তার নাম লিখতে হয় এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাঠাতে হয়:

```julia
# invoking a function
muladd(10, 5, 1)

# and of course you can invoke a function within the body of another function:
square_plus_one(x) = muladd(x, x, 1)
```

## নামকরণের নিয়ম

অনেক ভাষার মতোই Julia-তে নাম (ভ্যারিয়েবল, ফাংশন এবং আরও অনেক কিছুর) অবশ্যই একটি অক্ষর দিয়ে শুরু হতে হবে, তারপর অক্ষর, অঙ্ক ও আন্ডারস্কোরের যেকোনো সমন্বয় আসতে পারে।

প্রচলিত নিয়ম অনুযায়ী, ভ্যারিয়েবল, ধ্রুবক ও ফাংশনের নাম *ছোট হাতের অক্ষরে* লেখা হয়, আর আন্ডারস্কোর যতটা যুক্তিসঙ্গত ততটাই কম রাখা হয়।
