# নির্দেশনা

এই অনুশীলনীতে আপনি একটি বিউটি সেলুনের অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন।

আপনার সামনে তিনটি কাজ, যেগুলোর প্রতিটিতেই অ্যাপয়েন্টমেন্টের তারিখ জড়িত থাকবে।

## 1. অ্যাপয়েন্টমেন্ট আগেই পেরিয়ে গেছে কি না দেখুন

`appointment_has_passed` সাবরুটিনটি ইমপ্লিমেন্ট করুন, যা একটি ডেট স্ট্রিং নেয় এবং দেখে যে অ্যাপয়েন্টমেন্টটি অতীতে কোথাও ছিল কি না:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

ডেট স্ট্রিংগুলো ISO 8601 ডেটটাইম ফরম্যাটে দেওয়া হবে: `YYYY-mm-ddTHH:MM:SS`

আপনাকে প্রাইভেট `_parse_datetime` সাবরুটিনটি ইমপ্লিমেন্ট করতে হবে।
আপনার জন্য কয়েকটি মডিউল প্রস্তাব করা হলো:

- [Time::Piece][time-piece] হলো পার্লের একটি কোর মডিউল।
- [DateTime::Tiny][datetime-tiny] CPAN থেকে পাওয়া যায়।

## 2. অ্যাপয়েন্টমেন্টটি বিকেলে কি না দেখুন

`is_afternoon_appointment` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি ডেট স্ট্রিং নেয় এবং দেখে যে অ্যাপয়েন্টমেন্টটি বিকেলে (>= 12:00 এবং < 18:00) কি না:

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. অ্যাপয়েন্টমেন্টের সময় ও তারিখ বর্ণনা করুন

`describe_appointment` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি ডেট স্ট্রিং নেয় এবং সেই তারিখ ও সময়ের একটি বর্ণনা রিটার্ন করে:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

খেয়াল করুন, ঘণ্টাটি 0-12 সীমার মধ্যে থাকে এবং এর আগে কোনো লিডিং শূন্য বা স্পেস থাকে না।
