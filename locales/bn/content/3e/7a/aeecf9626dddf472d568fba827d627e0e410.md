# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                                                        |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0`    | ইনপুট     | ইন্টিজার | বাহু a                                                                             |
| `$a1`    | ইনপুট     | ইন্টিজার | বাহু b                                                                             |
| `$a2`    | ইনপুট     | ইন্টিজার | বাহু c                                                                             |
| `$v0`    | আউটপুট     | ইন্টিজার | ত্রিভুজের ধরন (`0` = বিষমবাহু, `1` = সমদ্বিবাহু, `2` = সমবাহু, `3` = অবৈধ) |
| `$t0-9`  | অস্থায়ী | যেকোনো     | অস্থায়ী স্টোরেজের জন্য ব্যবহৃত                                                         |
