# অ্যারের পরিচিতি

Bash-এ দুই ধরনের প্যারামিটার থাকে: "স্কেলার" মান এবং অ্যারে। একটি স্কেলার মান স্ট্রিং বা সংখ্যা হতে পারে; এটি একটি মাত্র "জিনিস" বোঝায়।

বেশিরভাগ সময়েই আপনার ডেটা ধরে রাখতে স্কেলার মানই যথেষ্ট। কিন্তু কখনো কখনো আপনাকে স্কেলার মানের একটি তালিকা সংরক্ষণ করতে হয়। তখন আপনি একটি _অ্যারে_ ব্যবহার করবেন।

অ্যারে দুই ধরনের:

* সংখ্যাভিত্তিক ইনডেক্সের অ্যারে একটি ইন্টিজার কী (key)-এর সঙ্গে একটি স্ট্রিং মান যুক্ত করে।
  (অন্য ভাষায় এটিকে "list" বা "sequence" বলা হতে পারে।)
* অ্যাসোসিয়েটিভ অ্যারে একটি স্ট্রিং কী (key)-এর সঙ্গে একটি স্ট্রিং মান যুক্ত করে।
  (অন্য ভাষায় এটিকে "map" বা "dictionary" বলা হতে পারে।)

এই ডকুমেন্টের প্রথম কয়েকটি অংশে সংখ্যাভিত্তিক ইনডেক্সের অ্যারে নিয়ে আলোচনা করা হবে (এরপর থেকে এগুলোকে শুধু "অ্যারে" বলা হবে)।
অ্যাসোসিয়েটিভ অ্যারে নিয়ে বিস্তারিত থাকবে একেবারে শেষে।

~~~~exercism/caution
Bash অ্যারে _কেবল_ স্কেলার মানই সংরক্ষণ করতে পারে।
দ্বি-মাত্রিক অ্যারে (অ্যারের অ্যারে) তৈরি করার কোনো উপায় নেই।
~~~~

## একটি অ্যারে ভ্যারিয়েবল ডিক্লেয়ার ও ইনিশিয়ালাইজ করা

একটি ভ্যারিয়েবলে বন্ধনীর ভিতরে এলিমেন্টের একটি তালিকা (খালিও হতে পারে) অ্যাসাইন করে আপনি একটি অ্যারে ইনিশিয়ালাইজ করতে পারেন।

```bash
myarray=("one" "two" "three")
```

প্রতিটি ভ্যারিয়েবল অ্যাসাইনমেন্টের ক্ষেত্রেই যেমন হয়, এখানেও সমান চিহ্নের দুই পাশে কোনো স্পেস থাকা যাবে না।

খেয়াল করুন, এলিমেন্টগুলোর মাঝে কোনো কমা নেই; এটি হোয়াইটস্পেস দিয়ে আলাদা করা স্ট্রিংয়ের একটি তালিকা।

আসলে বন্ধনীর ভিতরে হোয়াইটস্পেসের পরিমাণ সম্পূর্ণ ইচ্ছাধীন।
নতুন লাইনও দেওয়া যায়; পড়ার সুবিধার জন্য যত খুশি ব্যবহার করুন।

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

এভাবে একটি অ্যারে ভ্যারিয়েবলে স্ট্রিংয়ের তালিকা অ্যাসাইন করলে প্রথম স্ট্রিংটি সংরক্ষিত হবে ০ নম্বর ইনডেক্সে, পরেরটি ১ নম্বর ইনডেক্সে, তার পরেরটি ২ নম্বর ইনডেক্সে, এভাবেই চলবে।

আপনার প্রয়োজনীয় ইনডেক্সগুলো নির্দিষ্ট করে একটি "স্পার্স অ্যারে" ইনিশিয়ালাইজ করাও সম্ভব।

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
আবার বলি: অ্যারের ইনডেক্সগুলো শূন্য-ভিত্তিক।
এই স্নিপেটটি "true" আউটপুট দেয়:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

কোনো ভ্যারিয়েবল যে একটি অ্যারে ধারণ করবে, তা নির্দিষ্ট করতে আপনি `declare` (বা ফাংশনের ভিতরে `local`) কমান্ডটি ব্যবহার করতে পারেন।

```bash
declare -a myarray
```

তবে ভ্যারিয়েবলটি ইনিশিয়ালাইজ করার জন্য শুধু একটি (হয়তো খালি) বন্ধনীবদ্ধ তালিকা অ্যাসাইন করাই বেশি প্রচলিত রীতি।

## অ্যারের এলিমেন্ট অ্যাক্সেস করা

উপরের নোটে যেমন দেখেছেন, একটি অ্যারের এলিমেন্ট অ্যাক্সেস করার সিনট্যাক্স হলো `${myarray[$index]}`।
ইনডেক্সটি দেওয়া হয় তৃতীয় বন্ধনীর ভিতরে।
আর দ্বিতীয় বন্ধনীগুলো অবশ্যই লাগবে।

~~~~exercism/note
সংখ্যাভিত্তিক ইনডেক্সের অ্যারের ক্ষেত্রে ইনডেক্সটি একটি অ্যারিথমেটিক এক্সপ্রেশন।
Bash ম্যানুয়ালে [বলা হয়েছে][arithmetic]:

> একটি অ্যারিথমেটিক এক্সপ্রেশনের ভিতরে শেল ভ্যারিয়েবলগুলোকে প্যারামিটার এক্সপ্যানশন সিনট্যাক্স ব্যবহার না করেই নাম দিয়ে রেফারেন্স করা যায়।

এর মানে হলো "সাধারণ" ভ্যারিয়েবল এক্সপ্যানশনের জন্য `$` লাগে না।
এভাবে এলিমেন্ট অ্যাক্সেস করতে পারেন, যা পড়তে একটু সহজ:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

অ্যারেতে দেওয়া ইনডেক্সটি না থাকলে এক্সপ্যানশনের ফলাফল হয় একটি খালি স্ট্রিং।

## অ্যারেতে অ্যাসাইন করা

অ্যারের কোনো নির্দিষ্ট এন্ট্রিতে অ্যাসাইন করতে এই সিনট্যাক্স ব্যবহার করুন:

```bash
myarray[10]="hello"
```

অ্যারেতে _অ্যাপেন্ড_ করতে `+=` কনক্যাটিনেটিং-অ্যাসাইনমেন্ট অপারেটর ব্যবহার করুন, আর বন্ধনী দিন:

```bash
myarray+=("new element 1" "new element 2")
```

## অ্যারের উপর ইটারেশন করা

সাধারণত আপনাকে একটি অ্যারের _মানগুলোর_ উপর ইটারেশন করতে হবে।
[লুপিং][looping] কনসেপ্টে দেখা একটি for লুপ ব্যবহার করুন:

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

অ্যারে এক্সপ্যান্ড করার বিশেষ সিনট্যাক্সটি খেয়াল করুন: `"${myarray[@]}"`
প্যারামিটার এক্সপ্যানশনের এই রূপটি অ্যারের মানগুলোকে আলাদা আলাদা শব্দ হিসেবে বসায়।
এটি অনেকটা এটির সমতুল্য:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

`"${myarray[@]}"` রূপটি স্পার্স অ্যারের সঙ্গেও কাজ করে, কেবল সংজ্ঞায়িত মানগুলোতেই এক্সপ্যান্ড হয়।

এই বিশেষ এক্সপ্যানশন, যেখানে ইনডেক্সটি একটি অ্যাম্পারস্যান্ড (`@`), কেবল ডাবল কোটের ভিতরেই বিশেষ।

#### আরও কিছু বিশেষ প্যারামিটার এক্সপ্যানশন

অ্যারের উপর ইটারেশন করার জন্য আমাদের আরও দু-একটি বিশেষ সিনট্যাক্স দরকার।
এগুলো ম্যানুয়ালের [শেল প্যারামিটার এক্সপ্যানশন][man-expn] অংশে বর্ণনা করা আছে।

একটি অ্যারের _দৈর্ঘ্য_ বের করতে `${#myarray[@]}` ব্যবহার করুন, নামের আগে একটি `#` দিয়ে।
অ্যারের "দৈর্ঘ্য" মানে তার ভিতরে থাকা এলিমেন্টের সংখ্যা।

একটি অ্যারের _ইনডেক্সগুলোর_ তালিকা বের করতে `"${!myarray[@]}"` ব্যবহার করুন, নামের আগে একটি `!` দিয়ে এবং এক্সপ্যানশনটি ডাবল কোটের ভিতরে রেখে।
সংখ্যাভিত্তিক ইনডেক্সের অ্যারের ক্ষেত্রে ইনডেক্সগুলো সংখ্যার ক্রমানুসারে এক্সপ্যান্ড হয়।

### অ্যারের ইনডেক্সগুলোর উপর ইটারেশন করা

কখনো কখনো মানের সঙ্গে ইনডেক্সও দরকার হয়।
এটি করার কয়েকটি উপায় আছে।

1. ইনডেক্সগুলো যখন অবিচ্ছিন্ন ধারা তৈরি করে, তখন আপনি একটি _অ্যারিথমেটিক_ for লুপ ব্যবহার করতে পারেন।

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   খেয়াল করুন `${#myarray[@]}` সিনট্যাক্সটি, অ্যারের নামের সামনে `#` অক্ষরটি আছে।
   যেহেতু অ্যারে শূন্য-ভিত্তিক ইনডেক্সিং ব্যবহার করে, তাই অ্যারের শেষ ইনডেক্সটি অ্যারের দৈর্ঘ্যের চেয়ে এক কম।

2. অ্যারেটি স্পার্স হলে আপনি এই রূপটি ব্যবহার করতে পারেন:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   খেয়াল করুন `${!myarray[@]}` সিনট্যাক্সটি, অ্যারের নামের সামনে `!` অক্ষরটি আছে।

## অ্যারে খতিয়ে দেখা

কোনো অ্যারের ভিতরের বিষয়বস্তু দেখতে চাইলে `declare` কমান্ডটি `-p` অপশনসহ ব্যবহার করুন:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

এটি শেলের ক্যানোনিকাল কোটিং দিয়ে বিষয়বস্তু আউটপুট করে।

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## অ্যাসোসিয়েটিভ অ্যারে

আবার বলি, অ্যাসোসিয়েটিভ অ্যারে ইনডেক্স হিসেবে সংখ্যা নয়, স্ট্রিং ব্যবহার করে।
উপরে লেখা সবকিছুই অ্যাসোসিয়েটিভ অ্যারের ক্ষেত্রে প্রযোজ্য, তবে সামান্য পার্থক্য নিয়ে।
সাধারণত আমরা "index" নয়, "key" শব্দটি ব্যবহার করি: অ্যাসোসিয়েটিভ অ্যারে কী (key)-এর সঙ্গে মান যুক্ত করে।

### অ্যাসোসিয়েটিভ অ্যারে ডিক্লেয়ার করা

অ্যারের মতো নয়, অ্যাসোসিয়েটিভ অ্যারে **অবশ্যই** ডিক্লেয়ার করতে হবে।
`declare`-এ `-A` অপশনটি ব্যবহার করুন (বা ফাংশনের ভিতরে `local`):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### অ্যাসোসিয়েটিভ অ্যারে ইনিশিয়ালাইজ করা

কী (key)-মানের জোড়াগুলো বন্ধনীবদ্ধ তালিকার ভিতরে উল্লেখ করা হয়:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

এটি আউটপুট দেয়:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
মনে রাখবেন, অ্যাসোসিয়েটিভ অ্যারে **ক্রমহীন**।
~~~~

ডিক্লেয়ার ও ইনিশিয়ালাইজেশন একই লাইনে করা যায়।

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

সাম্প্রতিক Bash সংস্করণে ইনিশিয়ালাইজেশনে একটি `(key value key value ...)` তালিকা ব্যবহার করা যায়।

```bash
declare -A mymap=(first foo second bar third baz)
```

### মান অ্যাক্সেস করা

এলিমেন্ট অ্যাক্সেস করতেও আগের মতোই একই সিনট্যাক্স ব্যবহার করা হয়: `${mymap[$key]}`।

অ্যাসোসিয়েটিভ অ্যারের কী (key) অ্যারিথমেটিক কনটেক্সটে মূল্যায়ন করা হয় না।
এখানে সাধারণ প্যারামিটার এক্সপ্যানশন সিনট্যাক্সই লাগে।

### অ্যাসোসিয়েটিভ অ্যারেতে অ্যাসাইন করা

অ্যাসাইনমেন্টেও আগের মতোই একই সিনট্যাক্স ব্যবহার করা হয়:

```bash
mymap[$key]="$value"
```

### ইটারেশন করা

ইটারেশন করতে আপনি `for value in "${mymap[@]}"` লুপ ব্যবহার করতে পারেন।
তবে সাধারণত মানের সঙ্গে কী (key)-ও দরকার হয়।

উপরে দেখা `"${!mymap[@]}"` সিনট্যাক্সটি ব্যবহার করুন।

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

এটি আউটপুট দেয়

```
second -> bar
first -> foo
third -> baz
```

আবার জোর দিয়ে বলি, কী (key)গুলোতে কোনো নির্দিষ্ট ক্রম নেই।
