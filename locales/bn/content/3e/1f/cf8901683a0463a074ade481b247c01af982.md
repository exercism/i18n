# নির্দেশনা

এই অনুশীলনীতে আপনি একজন বড় ক্রীড়াপ্রেমী, এবং NBA বাস্কেটবলের প্রতি আপনার নতুন করে টান অনুভব করছেন। NBA বাস্কেটবলে নতুন হওয়ায় আপনি NBA-এর ইতিহাস নিয়ে গভীরে যাচ্ছেন, দল, কোচ আর তাদের জয়-পরাজয়ের পরিসংখ্যান লিখে রাখছেন, এবং একে অন্যের সাথে মিলিয়ে দেখছেন।

যেহেতু এখনো আপনার কোনো প্রিয় দল নেই, তাই কোন নির্দিষ্ট দলকে সমর্থন করবেন সেটা বের করার জন্য আপনি একটি অ্যালগরিদমও বানাবেন।

আপনার নিজস্ব এই _root-for-a-team_ অ্যালগরিদম তৈরি করতে সাহায্য করবে সাতটি কাজ।

## 1. মডেল ডিফাইন করুন

নিচের দুটি ফিল্ডসহ `Coach` রেকর্ডটি ডিফাইন করুন:

- `name`: কোচের নাম, টাইপ `String`।
- `former_player`: কোচ আগে খেলোয়াড় ছিলেন কি না তা নির্দেশ করে, টাইপ `Bool`।

নিচের দুটি ফিল্ডসহ `Stats` রেকর্ডটি ডিফাইন করুন:

- `wins`: জয়ের সংখ্যা, টাইপ `Int`।
- `losses`: পরাজয়ের সংখ্যা, টাইপ `Int`।

নিচের তিনটি ফিল্ডসহ `Team` রেকর্ডটি ডিফাইন করুন:

- `name`: দলের নাম, টাইপ `String`।
- `coach`: দলের কোচ, টাইপ `Coach`।
- `stats`: দলের পরিসংখ্যান, টাইপ `Stats`।

## 2. একটি দলের কোচ তৈরি করুন

`create_coach` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে কোচের নাম ও তার পূর্বে খেলোয়াড় থাকার অবস্থা নেয় এবং `Coach` রেকর্ডটি রিটার্ন করে:

```gleam
create_coach("Larry Bird", True)
// -> Coach(name: "Larry Bird", former_player: True)
```

## 3. একটি দলের পরিসংখ্যান তৈরি করুন

`create_stats` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে জয়ের সংখ্যা ও পরাজয়ের সংখ্যা নেয় এবং `Stats` রেকর্ডটি রিটার্ন করে:

```gleam
create_stats(58, 24)
// -> Stats(wins: 58, losses: 24)
```

## 4. একটি দল তৈরি করুন

`create_team` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে দলের নাম, কোচ ও রেকর্ড নেয় এবং `Team` রেকর্ডটি রিটার্ন করে:

```gleam
let coach = create_coach("Larry Bird", True)
let stats = create_stats(58, 24)
create_team("Indiana Pacers", coach, stats)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Larry Bird", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 5. কোচ পরিবর্তন করুন

NBA-এর মালিকেরা অধৈর্য হন, আর আপনি দেখলেন যে খারাপ ফল করলে প্রায়ই কোচ বদলে দেওয়া হয়। `replace_coach` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে দল ও তার নতুন কোচ নেয় এবং নতুন কোচসহ দলটি রিটার্ন করে:

```gleam
let coach = create_coach("Larry Bird", True)
let record = create_stats(58, 24)
let team = create_team("Indiana Pacers", coach, record)

let new_coach = create_coach("Isiah Thomas", True)
replace_coach(team, new_coach)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Isiah Thomas", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 6. একই দল কি না তা যাচাই করুন

পরিসংখ্যান ঘাঁটতে ঘাঁটতে আপনি দল আর তাদের রেকর্ডের তালিকা রাখছেন। মাঝে মাঝে ভুল হয়ে যায় আর তালিকায় একই এন্ট্রি দুবার চলে আসে। `is_same_team` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি দল নেয় এবং দল দুটি একই হলে `True` রিটার্ন করে, নাহলে `False` রিটার্ন করে:

```gleam
let pacers_coach = create_coach("Larry Bird", True)
let pacers_stats = create_stats(58, 24)
let pacers_team = create_team("Indiana Pacers", pacers_coach, pacers_stats)

let lakers_coach = create_coach("Del Harris", False)
let lakers_stats = create_stats(61, 21)
let lakers_team = create_team("LA Lakers", lakers_coach, lakers_stats)

is_same_team(pacers_team, lakers_team)
// -> False
```

## 7. দলকে সমর্থন করা উচিত কি না তা যাচাই করুন

অনেক দল ও ম্যাচ দেখে আপনি একটি অ্যালগরিদম বের করেছেন। নিচের যেকোনো একটি ট্রু হলে আপনি ওই দলকে সমর্থন করেন:

- কোচের নাম "Gregg Popovich"
- কোচ আগে খেলোয়াড় ছিলেন
- দলের নাম "Chicago Bulls"
- দল ৬০ বা তার বেশি গেম জিতেছে
- দলের পরাজয় জয়ের চেয়ে বেশি

`root_for_team` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি দল নেয় এবং দলটিকে সমর্থন করা উচিত হলে `True` রিটার্ন করে, নাহলে `False` রিটার্ন করে:

```gleam
let spurs_coach = create_coach("Gregg Popovich", False)
let spurs_stats = create_stats(56, 26)
let spurs_team = create_team("San Antonio Spurs", spurs_coach, spurs_stats)
root_for_team(spurs_team)
// -> True
```
