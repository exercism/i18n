# নির্দেশনা

ভবিষ্যতের জাদুকর Elyse তার প্রশিক্ষণ চালিয়ে যাচ্ছে। তার জাদুর কৌশলগুলো দেখানোর জন্য তাকে কার্ডের কয়েকটি স্তূপ দেওয়া হবে।
কাজটা একটু সহজ করতে সে শুধু ১ থেকে ১০ নম্বরের কার্ডগুলোই ব্যবহার করে।

এই অনুশীলনীতে অ্যারের ভেতরের উপাদান বিশ্লেষণ করতে বিল্ট-ইন মেথড ব্যবহার করুন।

## 1. একটি কার্ডের অবস্থান খুঁজে বের করা

Elyse স্তূপে একটি কার্ডের অবস্থান (ইনডেক্স) জানতে চায়।

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. স্টূপে একটি কার্ড আছে কি না তা নির্ধারণ করা

Elyse জানতে চায় স্টূপে একটি কার্ড উপস্থিত আছে কি না, অর্থাৎ স্টূপে নির্দিষ্ট কোনো `number` আছে কি না।

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. প্রতিটি কার্ড জোড় সংখ্যা কি না তা নির্ধারণ করা

Elyse জানতে চায় প্রতিটি কার্ড জোড় সংখ্যা কি না, অর্থাৎ স্টূপের প্রতিটি সংখ্যা জোড় `number` কি না।

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. স্টূপে বিজোড় মানের কোনো কার্ড আছে কি না যাচাই করা

Elyse জানতে চায় স্টূপে কোনো বিজোড় সংখ্যা আছে কি না।

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. স্টূপ থেকে প্রথম বিজোড় কার্ডটি বের করা

Elyse প্রথম যে কার্ডটি বিজোড়, তার মান জানতে চায়।

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. প্রথম জোড় কার্ডটির অবস্থান নির্ধারণ করা

Elyse প্রথম যে কার্ডটি জোড়, তার অবস্থান জানতে চায়।

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
