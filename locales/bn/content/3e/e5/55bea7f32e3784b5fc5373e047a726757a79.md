# নির্দেশাবলি

আপনার শহরে পিৎজার স্লাইস বিক্রি করে এমন বেশ কয়েকটি দোকান আছে, আর আপনি এমন একটি ওয়েব অ্যাপ লিখতে চান যা দুটি আলাদা পিৎজা কনফিগারেশন তুলনা করে আপনাকে জানাবে কোনটি আপনাকে বড় স্লাইস দেবে।

## 1. এমন একটি ফাংশন লিখুন যা স্লাইসের আকার হিসাব করে এবং অবৈধ ইনপুটের জন্য nil রিটার্ন করে।

`sliceSize(diameter: Double?, slices: Int?) -> Double?` ফাংশনটি ইমপ্লিমেন্ট করুন, যা একটি পিৎজার ব্যাস ও প্রতি পিৎজায় স্লাইসের সংখ্যা পেলে একটি স্লাইসের ক্ষেত্রফল রিটার্ন করে।
ঋণাত্মক ব্যাস এবং ১-এর কম স্লাইস সংখ্যার জন্য `nil` রিটার্ন করুন, কারণ ঋণাত্মক ব্যাসের পিৎজা বলে কিছু নেই এবং একটি পিৎজাকে ১টিরও কম স্লাইসে ভাগ করার কোনো উপায় নেই।
যদি যেকোনো একটি প্যারামিটার `nil` হয়, তাহলেও `nil` রিটার্ন করুন

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. বড় স্লাইসটি নির্ধারণ করতে আপনার ওয়েব অ্যাপ্লিকেশন থেকে ইনপুট প্রসেস করুন।

আপনার ওয়েব অ্যাপ্লিকেশন আপনার `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String` ফাংশনে চারটি স্ট্রিং পাস করবে।
প্রথম ও দ্বিতীয় স্ট্রিংটি হলো যথাক্রমে প্রথম পিৎজার ব্যাস ও স্লাইসের সংখ্যা, আর তৃতীয় ও চতুর্থটি হলো যথাক্রমে দ্বিতীয় পিৎজার ব্যাস ও স্লাইসের সংখ্যা।

`biggestSlice` এমনভাবে ইমপ্লিমেন্ট করুন যাতে এটি প্রতিটি পিৎজার ব্যাস ও স্লাইসের সংখ্যাকে যথাক্রমে `Double` ও `Int` টাইপে রূপান্তর করার চেষ্টা করে।
যদি স্ট্রিং দুটি থেকে এই দুটি মানই পাওয়া যায়, তাহলে ক্ষেত্রফল হিসাব করার চেষ্টা করতে আপনার প্রথম ফাংশনটি ব্যবহার করুন, নাহলে ওই স্লাইসের ক্ষেত্রফল `nil`।
দুটি স্লাইসের ক্ষেত্রফল পাওয়া গেলে নিচের নিয়মগুলো ব্যবহার করে দুটি ক্ষেত্রফল তুলনা করুন:

1. যদি স্লাইস A-এর ক্ষেত্রফল একটি `Double` হয় আর স্লাইস B-এর `nil` হয়, তাহলে "Slice A is bigger" রিটার্ন করুন। উল্টোটা সত্য হলে "Slice B is bigger" রিটার্ন করুন।
2. যদি দুটি ক্ষেত্রফলই `Double` হয়, তাহলে কোন স্লাইসের ক্ষেত্রফল বেশি তা অনুযায়ী "Slice A is bigger" বা "Slice B is bigger" রিটার্ন করুন।
3. যদি দুটি ক্ষেত্রফলই `nil` হয়, অথবা দুটিই `Double` হয় এবং সমান হয়, তাহলে "Neither slice is bigger" রিটার্ন করুন।

~~~~exercism/note
ইনপুটের ফলে স্লাইসের ক্ষেত্রফল ০ হলেও স্লাইসটি বৈধ বলেই ধরা হয়, এবং `nil` ক্ষেত্রফলের স্লাইসের চেয়ে এটিকে বড় হিসেবে দেখা উচিত।
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
