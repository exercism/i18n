# টেস্ট

CLI টুল দিয়ে কোনো অনুশীলনী ডাউনলোড করলে আপনি অনুশীলনীর নামে একটি Uiua ফাইল আর একটি `tests.ua` ফাইল দেখতে পাবেন।
এই ফাইলে সব টেস্ট কেস থাকে, যেগুলো আপনি সলুশন আপলোড করলে টেস্ট রানার যেগুলো চালায় সেগুলোর সাথে মিলে যায়।
পরীক্ষা-নিরীক্ষার জন্য নির্দ্বিধায় আরও টেস্ট কেস যোগ করতে পারেন।
তবে টেস্ট বদলালেও অনলাইন টেস্ট রানারের প্রক্রিয়ায় কোনো প্রভাব পড়ে না।

## লোকাল টেস্টিং

কোনো অনুশীলনীর টেস্ট চালাতে হলে সেই অনুশীলনীর ডিরেক্টরিতে একটি টার্মিনাল খুলে `uiua test tests.ua` কমান্ডটি রান করুন।

উদাহরণস্বরূপ, সম্পাদনা না করা একটি `hello-world` অনুশীলনীর আউটপুট দেখতে এরকম হতে পারে:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

`Error` লাইনটি আপনার কোডের প্রকৃত আউটপুট দেখায়।
লাইন নম্বরটি `tests.ua`-তে প্রত্যাশিত ফলাফলের অবস্থান জানায়।
সঠিক সলুশনে আউটপুট আসে:

```bash
$ uiua test tests.ua
Test passed
```
