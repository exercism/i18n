# পরিচিতি

Elixir-এ স্ট্রিং ডাবল কোট দিয়ে ডিলিমিট করা হয়, এবং এগুলো UTF-8-এ এনকোড করা হয়:

```elixir
"Hi!"
```

`<>/2` অপারেটরটি ব্যবহার করে স্ট্রিং কনক্যাটেনেট করা যায়:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir-এ স্ট্রিং `#{}` সিনট্যাক্স ব্যবহার করে ইন্টারপোলেশন সমর্থন করে:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

কোনো স্ট্রিংয়ের ভেতরে একটি নিউলাইন ক্যারেক্টার বসাতে চাইলে `\n` ইস্কেপ কোডটি ব্যবহার করুন:

```elixir
"1\n2\n3\n"
```

অনেক নিউলাইন আছে এমন টেক্সট নিয়ে সহজে কাজ করতে চাইলে বদলে ট্রিপল-ডাবল-কোট হেরেডক সিনট্যাক্স ব্যবহার করুন:

```elixir
"""
1
2
3
"""
```

Elixir-এ স্ট্রিং নিয়ে কাজ করার জন্য `String` মডিউলে অনেক ফাংশন রয়েছে।
