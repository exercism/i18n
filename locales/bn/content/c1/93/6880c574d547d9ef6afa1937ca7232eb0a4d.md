# সম্পর্কে

একটি [হায়ার-অর্ডার ফাংশন](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) হলো এমন একটি ফাংশন যা:

- একটি ফাংশনকে আর্গুমেন্ট হিসেবে নেয়
- একটি ফাংশন রিটার্ন করে

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
