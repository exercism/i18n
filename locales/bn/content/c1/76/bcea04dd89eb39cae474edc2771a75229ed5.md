# নির্দেশনার সংযোজন

## ইমপ্লিমেন্টেশন

এই অনুশীলনীতে আপনি এমন একটি প্রসিডিউর ইমপ্লিমেন্ট করবেন, যা যে স্ট্রিংটি রিটার্ন করে সেটি অ্যালোকেট করার কথা। আর ওই স্ট্রিংটি ডিলোকেট করার দায়িত্ব প্রসিডিউরটির কলারের।

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
