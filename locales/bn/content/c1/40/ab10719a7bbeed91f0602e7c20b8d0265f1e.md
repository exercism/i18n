# পরিচিতি

## প্যাটার্ন ম্যাচিং

শর্তসাপেক্ষে লজিক চালানোর জন্য একটি `if/elif/else` এক্সপ্রেশন ব্যবহার করা যায়। শর্তসাপেক্ষে লজিক চালানোর আরও একটি, আরও শক্তিশালী উপায়ও F#-এ আছে: প্যাটার্ন ম্যাচিং। প্যাটার্ন ম্যাচিংয়ে একটি মানকে এক বা একাধিক _প্যাটার্ন_-এর সাথে মিলিয়ে পরীক্ষা করা যায়। এমন একটি প্যাটার্নের উদাহরণ হলো _কনস্ট্যান্ট প্যাটার্ন_, যা একটি মানকে একটি কনস্ট্যান্টের সাথে মেলায় (যেমন `1` বা `"hello"`)।

F#-এ প্যাটার্ন ম্যাচিং করা হয় `match` কিওয়ার্ডের মাধ্যমে:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

এটি অন্য ভাষার `switch` স্টেটমেন্টের মতো দেখালেও, অন্য প্যাটার্নগুলোও ব্যবহার করলে প্যাটার্ন ম্যাচিংয়ের আসল শক্তি ফুটে ওঠে। এর মধ্যে একটি হলো _ভ্যারিয়েবল প্যাটার্ন_, যা দিয়ে একটি মান ক্যাপচার করা যায়:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

কোনো কোনো ক্ষেত্রে আপনি একটি প্যাটার্নে একটি অতিরিক্ত শর্ত যোগ করতে চাইতে পারেন। একে _গার্ড_ (ক্লজ) বলা হয়, যা `when` কিওয়ার্ড ব্যবহার করে যোগ করা যায়:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

উপরের উদাহরণে, সম্ভাব্য সব ইনপুটের জন্যই মিলে যাওয়া প্যাটার্ন থাকবে না। কম্পাইলার এটি শনাক্ত করে একটি ওয়ার্নিং আউটপুট দেবে। একে _এক্সহসটিভ চেকিং_ বলা হয়। ওয়ার্নিংটি সমাধান করতে সব কেস সামলাতে হয়। এর জন্য _ওয়াইল্ডকার্ড প্যাটার্ন_ ব্যবহার করা যায়, যা যেকোনো মানের সাথে মেলে:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

প্যাটার্ন ম্যাচিং একটি মানকে উপর থেকে নিচে একেকটি প্যাটার্নের সাথে পরীক্ষা করে, যতক্ষণ না একটি মিলে যাওয়া প্যাটার্ন খুঁজে পায় এবং সেই প্যাটার্নের সাথে যুক্ত লজিক চালায়। প্যাটার্নের ক্রম গুরুত্বপূর্ণ!
