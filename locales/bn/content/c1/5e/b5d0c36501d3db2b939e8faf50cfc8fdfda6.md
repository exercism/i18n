# পরিচিতি

Common Lisp-এ সময়কে চারটি উপায়ে প্রকাশ করা হয়, যার মধ্যে দুটি নিয়ে এখানে আলোচনা করা হবে।

- ইউনিভার্সাল টাইম হলো একটি পরম সময়, যা `1900-01-01T00:00:00Z` থেকে অতিক্রান্ত সেকেন্ডের সংখ্যা বোঝানো একটি ইন্টিজার (অর্থাৎ UTC-তে ১৯০০ সালের ১ জানুয়ারির মধ্যরাত)।
- ডিকোডেড টাইম হলো ৯টি মানের একটি টাপল, যেগুলো একসাথে একটি নির্দিষ্ট ক্যালেন্ডার সময় প্রকাশ করে: সেকেন্ড, মিনিট, ঘণ্টা, মাসের দিন, মাস, বছর, সপ্তাহের দিন, DST ফ্ল্যাগ, টাইম জোন।
(নিচে বিস্তারিত আলোচনা করা হয়েছে।)

## ইউনিভার্সাল টাইম

বর্তমান ইউনিভার্সাল টাইম পেতে `get-universal-time` বা `get-decoded-time` ব্যবহার করা হয়।
প্রথমটি `1900-01-01T00:00Z` থেকে বর্তমান সেকেন্ড রিটার্ন করে, আর দ্বিতীয়টি একই ডেটা ডিকোডেড ফরম্যাটে রিটার্ন করে।

## ডিকোডেড টাইম

সময় নিয়ে কাজ করার মূল ফাংশন দুটি হলো `decode-universal-time` ও `encode-universal-time`।
প্রথমটি একটি ইউনিভার্সাল টাইম নেয় এবং [multiple-values][concept-multiple-values] হিসেবে একটি ডিকোডেড টাইম মান রিটার্ন করে, আর দ্বিতীয়টি আর্গুমেন্ট হিসেবে ডিকোডেড টাইম মানগুলো নেয় এবং একটি ইউনিভার্সাল টাইম রিটার্ন করে।

দুটিই ঐচ্ছিক একটি টাইম-জোন আর্গুমেন্ট নেয়।
টাইম-জোনের ফরম্যাট নিচে দেখুন।

একটি ডিকোডেড টাইম হলো কিছু মানের একটি সেট:

- *সেকেন্ড*: ০ থেকে ৫৯-এর মধ্যবর্তী একটি ইন্টিজার
- *মিনিট*: ০ থেকে ৫৯-এর মধ্যবর্তী একটি ইন্টিজার
- *ঘণ্টা*: ০ থেকে ২৩-এর মধ্যবর্তী একটি ইন্টিজার
- *মাসের দিন*: ১ থেকে ৩১-এর মধ্যবর্তী একটি ইন্টিজার (ঊর্ধ্বসীমা স্পষ্টতই মাস ও বছরের উপর নির্ভর করে)
- *মাস*: ১ থেকে ১২-এর মধ্যবর্তী একটি ইন্টিজার
- *বছর*: বছর নির্দেশ করে এমন একটি ইন্টিজার।
- *সপ্তাহের দিন*: ০ থেকে ৬-এর মধ্যবর্তী একটি ইন্টিজার। ০ মানে সোমবার, ১ মানে মঙ্গলবার ইত্যাদি ... ৬ মানে রবিবার।
- *ডেলাইট সেভিং টাইম ফ্ল্যাগ*: ট্রু মান বোঝায় DST বলবৎ আছে।
- *টাইমজোন*: UTC থেকে অফসেট বোঝানো, -২৪ থেকে ২৪-এর মধ্যবর্তী ঘণ্টার একটি সংখ্যা।
সংখ্যাটি একটি মূলদ সংখ্যা এবং অবশ্যই `1/3600`-এর গুণিতক হতে হবে

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
