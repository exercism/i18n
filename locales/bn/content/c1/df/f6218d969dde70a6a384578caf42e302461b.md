# নির্দেশাবলি

এই অনুশীলনীতে আপনি লগ-লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন নিচের ফরম্যাটে লেখা একটি স্ট্রিং: `"[<LVL>]: <MESSAGE>"`।

লগ লেভেলগুলো হলো:

- `TRC` (ট্রেস)
- `DBG` (ডিবাগ)
- `INF` (ইনফো)
- `WRN` (ওয়ার্নিং)
- `ERR` (এরর)
- `FTL` (ফেটাল)

আপনার সামনে তিনটি কাজ আছে।

## 1. লগ লেভেল পার্স করুন

উপরের লগ লেভেলগুলোর সাথে মিলে যায় এমন ছয়টি এলিমেন্টযুক্ত একটি `LogLevel` এনাম ডিফাইন করুন।

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

এরপর `LogLine.getLogLevel()` মেথড ইমপ্লিমেন্ট করুন, যা একটি লগ লাইনের পার্স করা লগ লেভেল রিটার্ন করে:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. অজানা লগ লেভেল সাপোর্ট করুন

দুর্ভাগ্যবশত, মাঝে মাঝে কিছু লগ লাইনে একটি অজানা লগ লেভেল থাকে।
এই লগ লাইনগুলো সুন্দরভাবে সামলানোর জন্য `LogLevel` এনামে একটি `UNKNOWN` এলিমেন্ট যোগ করুন, যা কোনো অজানা লগ লেভেল পার্স করার সময় রিটার্ন করা উচিত:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. লগ লাইনকে শর্ট ফরম্যাটে রূপান্তর করুন

একটি লগ লাইনের লগ লেভেল বেশ লম্বা।
লগ লাইন সংরক্ষণে প্রয়োজনীয় ডিস্ক স্পেস কমানোর জন্য একটি শর্ট ফরম্যাট তৈরি করা হয়েছে: `"[<ENCODED_LEVEL>]:<MESSAGE>"`।

এনকোড করা লগ লেভেল হলো একটি লগ লেভেলের সাথে একটি সংখ্যার সরল ম্যাপিং:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

`LogLine.getOutputForShortLog()` মেথড ইমপ্লিমেন্ট করুন, যা সংক্ষিপ্ত লগ লাইন ফরম্যাট আউটপুট দিতে পারে:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
