# নির্দেশনা সংযোজন

## ইনপুট ফরম্যাট

প্রতিটি ইনপুট তালিকা একটি নাল-টার্মিনেটেড স্ট্রিং হিসেবে প্রকাশ করা হয়, যেখানে প্রতিটি ইনপুটের শেষে থাকে একটি নিউলাইন ক্যারেক্টার।

একটি উদাহরণ হতে পারে `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বিবরণ                                                          |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | ইনপুট        | অ্যাড্রেস | প্রতিটি ইনপুটের পরে নিউলাইনসহ নাল-টার্মিনেটেড ইনপুট স্ট্রিং     |
| `$a1`    | ইনপুট/আউটপুট | অ্যাড্রেস | নাল-টার্মিনেটেড আউটপুট স্ট্রিং                                  |
| `$t0-9`  | টেম্পোরারি   | যেকোনো  | সাময়িক স্টোরেজের জন্য                                         |
