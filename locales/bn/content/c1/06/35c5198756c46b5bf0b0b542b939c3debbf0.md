# নির্দেশনার সংযোজন

## সর্টিং প্যাকেজ

এই অনুশীলনীতে আপনাকে একটি অ্যারে সর্ট করতে হবে, কিন্তু স্ট্যান্ডার্ড লাইব্রেরিতে এটি আগে থেকেই দেওয়া নেই। আপনি নিজেই একটি সর্টিং লাইব্রেরি লিখতে পারেন, তবে আরও ভালো উপায় হলো [sorts প্যাকেজ](https://github.com/diku-dk/sorts) ব্যবহার করা।

সলিউশন ডিরেক্টরিতে নিচের কমান্ডটি চালিয়ে আপনি আপনার সমাধানে এই প্যাকেজটি ব্যবহার করতে পারেন:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

এরপর, আপনার কাঙ্ক্ষিত [সর্টিং অ্যালগরিদম](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) এভাবে ইমপোর্ট করুন:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
