# নির্দেশনা

এই অনুশীলনীতে আপনি লগ-লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যা এভাবে ফরম্যাট করা থাকে: `"[<LEVEL>]: <MESSAGE>"`.

এখানে তিনটি ভিন্ন লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে; প্রতিটিতে একটি লগ লাইন দেওয়া হবে এবং সেটি নিয়ে আপনাকে কিছু একটা করতে বলা হবে।

## 1. লগ লাইন থেকে মেসেজ বের করুন

লগ লাইনের মেসেজ রিটার্ন করার জন্য `message` ফাংশনটি ইমপ্লিমেন্ট করুন:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

শুরুতে বা শেষে থাকা যেকোনো হোয়াইটস্পেস মুছে ফেলা উচিত:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. লগ লাইন থেকে লগ লেভেল বের করুন

লগ লাইনের লগ লেভেল রিটার্ন করার জন্য `log_level` ফাংশনটি ইমপ্লিমেন্ট করুন; লগ লেভেলটি ছোট হাতের অক্ষরে রিটার্ন করতে হবে:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. লগ লাইন নতুন করে ফরম্যাট করুন

লগ লাইনটি নতুন করে ফরম্যাট করার জন্য `reformat` ফাংশনটি ইমপ্লিমেন্ট করুন; এতে মেসেজটি আগে থাকবে আর তার পরে বন্ধনীর মধ্যে থাকবে লগ লেভেল:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
