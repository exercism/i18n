# কন্ট্রোল ফ্লো

`if` এক্সপ্রেশন আর লুপ Cairo-তে এক্সিকিউশনের ফ্লো নিয়ন্ত্রণ করে এভাবে:
`

- **`if` এক্সপ্রেশন** শর্তটি `true`-তে ইভ্যালুয়েট হয় কি না, তার ভিত্তিতে শর্তসাপেক্ষে কোড রান করে।
- **লুপ** (যেমন `loop`, `while` আর `for`) নির্দিষ্ট একটি শর্ত ট্রু থাকা পর্যন্ত, অথবা লুপ ভাঙার শর্ত পূরণ হওয়া পর্যন্ত বারবার কোড এক্সিকিউট করে।

Cairo-তে লজিক ও ইটারেশন বাস্তবায়নের জন্য এই কনস্ট্রাক্টগুলো মৌলিক।

## `if` এক্সপ্রেশন

Cairo-তে `if` এক্সপ্রেশন দিয়ে শর্তভিত্তিক লজিক অনুযায়ী এক্সিকিউশনের ফ্লো নিয়ন্ত্রণ করা যায়।
এগুলো এমন একটি গঠন অনুসরণ করে যেখানে একটি বুলিয়ান শর্ত `true` না `false`-তে ইভ্যালুয়েট হয়, তার উপর নির্ভর করে কোড এক্সিকিউট হয়।

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

এই উদাহরণটি Cairo-তে একটি সাধারণ `if` ব্লক দেখায়।
`temperature > 25` শর্তটি `true`-তে ইভ্যালুয়েট হলেই কেবল `"It's hot outside!"` বার্তাটি প্রিন্ট হয়।
শর্তটি `false` হলে কোনো কোড এক্সিকিউট হয় না, আর প্রোগ্রাম চলতে থাকে।

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

এই কোডটি রান করলে কনসোলে `"The number is less than 10."` প্রিন্ট হবে।

### `else if` দিয়ে একাধিক শর্ত সামলানো

`if` ও `else`-কে একটি `else if` এক্সপ্রেশনে মিলিয়ে আপনি একাধিক শর্ত ব্যবহার করতে পারেন।

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

এই কোডটি রান করলে কনসোলে `"Grade: B"` প্রিন্ট হবে।

### `let` স্টেটমেন্টে `if` ব্যবহার

Cairo-র `if` এক্সপ্রেশনটি একটি `let` স্টেটমেন্টের ডান দিকে ব্যবহার করে ফলাফলটি একটি ভ্যারিয়েবলে অ্যাসাইন করা যায়।

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## লুপ

লুপ একটি মৌলিক কনস্ট্রাক্ট, যা কোড ব্লক বারবার চালানোর সুযোগ দেয় এবং কাজগুলোকে দক্ষভাবে ও নিয়ন্ত্রিতভাবে এক্সিকিউট করতে সাহায্য করে।
লুপ কোনো সিকোয়েন্সের উপর ইটারেট করতে পারে, অথবা কোনো শর্তের ভিত্তিতে বারবার কোড এক্সিকিউট করতে পারে।
Cairo তিন ধরনের প্রধান লুপ দেয়:

- **loop**: একটি সাধারণ লুপ, যা স্পষ্টভাবে `break` স্টেটমেন্ট দিয়ে থামানো না হলে অনির্দিষ্টকাল ধরে চলতে থাকে।
- **while**: নির্দিষ্ট একটি শর্ত `true` থাকা পর্যন্ত এক্সিকিউট হতে থাকে।
  শর্তটি `false` হলে এটি থেমে যায়।
- **for**: কোনো কালেকশনের এলিমেন্টের উপর (যেমন অ্যারে) ইটারেট করে, প্রতিটি এলিমেন্টের জন্য কোড এক্সিকিউট করে।

### `loop` দিয়ে কোড বারবার চালানো

`loop` কিওয়ার্ডটি Cairo-কে একটি কোড ব্লক বারবার চালানোর নির্দেশ দেয়, চিরকাল ধরে, অথবা যতক্ষণ না আপনি স্পষ্টভাবে থামাতে বলেন।

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

এই কোডটি এক্সিকিউট করলে কনসোলে অনির্দিষ্টকাল ধরে `"again!"` প্রিন্ট হতে থাকবে, যতক্ষণ না প্রোগ্রামের গ্যাস ফুরায় বা আমরা নিজেরাই এটি থামাই।

> নোট: Cairo গ্যাস মিটার যুক্ত করে অনন্ত লুপসহ একটি প্রোগ্রাম রান করা থেকে আমাদের বিরত রাখে।
> গ্যাস মিটার হলো এমন একটি ব্যবস্থা, যা একটি প্রোগ্রামে করা যেতে পারে এমন গণনার পরিমাণ সীমিত করে।
> গ্যাস হলো পরিমাপের একটি একক, যা একটি ইন্সট্রাকশনের গণনার খরচ প্রকাশ করে।
> গ্যাস মিটার ফুরিয়ে গেলে প্রোগ্রামটি থেমে যাবে।

লুপ থেকে বেরিয়ে আসতে `break` কিওয়ার্ডটি লুপের ভেতরে বসান, যাতে প্রোগ্রামকে বোঝানো যায় কখন এটি এক্সিকিউট করা থামাতে হবে।

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

`continue` কিওয়ার্ডটি প্রোগ্রামকে লুপের পরবর্তী ইটারেশনে যেতে এবং এই ইটারেশনের বাকি কোড বাদ দিতে বলে।

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

এই প্রোগ্রামটি এক্সিকিউট করলে `i`-এর মান `5`-এর সমান হলে সেটি প্রিন্ট হবে না।

#### `loop` থেকে মান রিটার্ন করা

যে মানটি রিটার্ন করতে চান, সেটি `break` কিওয়ার্ডের পরে বসিয়ে আপনি একটি `loop` থেকে একটি মান রিটার্ন করতে পারেন।
এতে আপনি `loop` থেকে বেরিয়ে এসে বাকি কোডে একটি ফলাফল পাঠাতে পারেন।

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### `while` দিয়ে শর্তভিত্তিক লুপ

`while` একটি শর্ত `true` থাকা পর্যন্ত কোড রান করে, আর শর্তটি `false` হলে বেরিয়ে যায়।

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### `for` দিয়ে একটি কালেকশনের মধ্য দিয়ে লুপ

`for` একটি কালেকশনের প্রতিটি আইটেমের উপর ইটারেট করে, প্রতিটি আইটেমের জন্য কোড এক্সিকিউট করে।

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
