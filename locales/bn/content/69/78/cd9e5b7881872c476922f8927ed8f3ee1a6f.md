## Z3 ইনস্টল করা

### Python ডাউনলোড করুন (আগে ইনস্টল করা না থাকলে)

Python-এর সর্বশেষ ভার্সন [এখান থেকে](https://python.org) ডাউনলোড করা যাবে।

* ইনস্টল করার সময়, Python-কে PATH-এ যোগ করে এমন বক্সটি অবশ্যই সিলেক্ট করবেন

### Visual Studio ডাউনলোড করুন (আগে ইনস্টল করা না থাকলে)

Visual Studio-এর সর্বশেষ ভার্সন [এখান থেকে](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019) ডাউনলোড করা যাবে।

* ইনস্টল করার সময় অনুগ্রহ করে **Python Development** ওয়ার্কলোডটি সিলেক্ট করুন
* ডান দিকের সব ঐচ্ছিক Python ডেভেলপমেন্ট প্যাকেজ চেকবক্স সিলেক্ট করুন

ইনস্টলেশন শেষে Visual Studio খুলুন এবং আপনার প্রাথমিক পছন্দগুলো সেট আপ করুন।

### Git কমান্ড ইনস্টল করুন

Git ইনস্টল করার নির্দেশনা [এখানে](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) পাওয়া যাবে।

* আপনাকে [Git আপনার সিস্টেম ভ্যারিয়েবলে যোগ করতে হবে](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Z3 ক্লোন করুন

প্রজেক্টটি দেখতে [Z3 Github রিপোজিটরি](https://github.com/Z3Prover/z3)-তে যান।

আপনার কম্পিউটারে একটি টার্মিনাল খুলুন এবং Z3 রিপোজিটরি যেখানে ক্লোন করতে চান সেখানে যান (যেমন: C:\Z3)।

সেই লোকেশন থেকে রান করুন:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Visual Studio Command Prompt ব্যবহার করে Windows-এ Z3 বিল্ড করা

স্টার্ট মেনু থেকে **Developer Command Prompt for VS 2019** খুলুন।

যে ফোল্ডারে Z3 রিপোজিটরি ক্লোন করেছেন সেখানে যান (যেমন: C:\Z3)।

32-বিট বিল্ডের জন্য রান করুন:

```bash
python scripts/mk_make.py
```

64-বিট বিল্ডের জন্য রান করুন:

```bash
python scripts/mk_make.py -x
```

তারপর রান করুন:

```bash
cd build
pip install z3-solver
```



এখন আপনি Visual Studio খুলে তার Python বাইন্ডিং দিয়ে Z3 রান করতে পারবেন।


পরীক্ষা করার জন্য আপনি রান করতে পারেন:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

শেষ দুটি লাইন `sat` এবং `[y = 4, x = 2]` আউটপুট দেবে।
