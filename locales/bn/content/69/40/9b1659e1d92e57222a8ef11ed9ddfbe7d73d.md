# পরিচিতি

প্রপার্টির মতো, যেগুলো আপনার স্ট্রাক্ট ও ক্লাসে ডেটা সংরক্ষণ করে, আপনি _মেথড_-ও ডিফাইন করতে পারেন, যেগুলো আপনার স্ট্রাক্ট বা ক্লাসে ফাংশন সংরক্ষণ করে।

মেথড সাধারণ ফাংশনের মতোই ডিফাইন করা হয়, শুধু স্ট্রাক্ট বা ক্লাসের বডির ভেতরে। লক্ষ্য করুন, কোনো ফাংশন যদি স্ট্রাক্টের কোনো প্রপার্টির মান পরিবর্তন করে, তাহলে তার আগে অবশ্যই `mutating` কিওয়ার্ড থাকতে হবে। এছাড়া, কোনো মেথড যদি কোনো প্রপার্টি পরিবর্তন করতে পারে, তাহলে সেই প্রপার্টি `let` নয়, `var` দিয়ে ডিফাইন করতে হবে, ঠিক সাধারণ ভ্যারিয়েবলের মতোই।

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

এই মেথডগুলো প্রপার্টির মতোই ডট নোটেশন দিয়ে কল করা যায়।

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
