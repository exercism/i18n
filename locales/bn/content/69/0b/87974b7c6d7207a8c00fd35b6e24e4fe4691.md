# নির্দেশনার পরিশিষ্ট

## ওয়ার্ড

- `<bst> ( data-seq -- tree )`: `data-seq`-এর প্রতিটি এলিমেন্ট ক্রমানুসারে ইনসার্ট করে একটি ট্রি তৈরি করে।
- `sorted-data ( tree -- seq )`: ট্রির এলিমেন্টগুলো ঊর্ধ্বক্রমে রিটার্ন করে (ইন-অর্ডার ট্রাভার্সাল)।

## টাপল হায়ারার্কি

বাইনারি সার্চ ট্রির একটি নোড হয় *খালি*, নয়তো *ডেটা আর দুটি সাবট্রি নিয়ে গঠিত*। এটিকে একটি ছোট ইনহেরিট্যান্স হায়ারার্কি হিসেবে মডেল করুন:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` হলো অ্যাবস্ট্রাক্ট প্যারেন্ট; `leaf` হলো খালি ট্রির কেস; `branch` একটি মান আর দুটি `bst` চাইল্ড বহন করে (প্রতিটিই নিজে হয় একটি `leaf`, নয়তো একটি `branch`)।

## ক্রম নির্ধারণ

ডেটা তুলনা করুন `before=?` দিয়ে (`math.order` থেকে), যা সংখ্যা ও স্ট্রিং দুটোতেই কাজ করে। টেস্টে `"1"`, `"2"`, `"3"`-এর মতো স্ট্রিং ডেটা ব্যবহার করা হয়।
