# নির্দেশাবলি

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা Larry the Lisp Alien-কে লগ স্ট্রিং পার্স ও ফরম্যাট করতে সাহায্য করবে। এই লগ স্ট্রিংগুলো নানা সিস্টেম থেকে আসে এবং সেগুলো প্রসেস করা দরকার, যাতে তাদের মেসেজ একটি তথ্যসমৃদ্ধ মনিটরিং ডিসপ্লেতে দেখানো যায়।

লগ স্ট্রিংগুলো `"[<level>]: <message>"` ফরম্যাটে থাকে। লেভেলের মান নিচের যেকোনো একটি হবে: `info`, `warn`, বা `ohno`।

## 1. মেসেজ বের করুন

একটি ফাংশন `log-message` ডিফাইন করুন, যা একটি লগ স্ট্রিং নেবে এবং তার ভেতরে থাকা মেসেজটি রিটার্ন করবে।

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. সিভিয়ারিটি নির্ধারণ করুন

লগ স্ট্রিংয়ের লেভেলই তার সিভিয়ারিটি নির্ধারণ করে।

- `info` লেভেল মানে `:everything-ok` সিভিয়ারিটি
- `warn` লেভেল মানে `:getting-worried` সিভিয়ারিটি
- `ohno` লেভেল মানে `:run-for-cover` সিভিয়ারিটি

একটি ফাংশন `log-severity` ডিফাইন করুন, যা একটি লগ স্ট্রিং নেবে এবং সঠিক সিভিয়ারিটি রিটার্ন করবে।

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. বাস্তবতার খামখেয়ালিপনা সামলানো

দুর্ভাগ্যবশত কখনও কখনও লগ স্ট্রিংগুলো সবসময় সঠিকভাবে ফরম্যাট করা থাকে না। বিশেষ করে, লগ লেভেল উপরে বলা হয়েছে যেভাবে সব ছোট হাতের অক্ষরে নাও থাকতে পারে। এটি সামলাতে `log-severity`-তে পরিবর্তন আনুন।

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. লগের সিভিয়ারিটি অনুযায়ী লগ মেসেজ নতুন করে ফরম্যাট করা

সিভিয়ারিটি অনুযায়ী মেসেজটি আলাদা আলাদা ভাবে বদলাতে হবে:

- `:everything-ok` সিভিয়ারিটির ক্ষেত্রে মেসেজটি সব ছোট হাতের অক্ষরে বদলাতে হবে।
- `:getting-worried` সিভিয়ারিটির ক্ষেত্রে মেসেজের প্রতিটি শব্দের প্রথম অক্ষর বড় হাতের করতে হবে।
- `:run-for-cover` সিভিয়ারিটির ক্ষেত্রে মেসেজটি সব বড় হাতের অক্ষরে বদলাতে হবে।

একটি ফাংশন `log-format` ডিফাইন করুন, যা একটি লগ মেসেজ নেয় এবং সঠিকভাবে ফরম্যাট করা একটি মেসেজ রিটার্ন করে।

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
