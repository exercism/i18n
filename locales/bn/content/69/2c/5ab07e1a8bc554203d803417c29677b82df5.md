# ভূমিকা

## টাপল

Elixir-এ টাপল হলো একটি ডেটা স্ট্রাকচার, যা ডেটা সাজিয়ে রাখে এবং যেকোনো টাইপের নির্দিষ্ট সংখ্যক আইটেম ধারণ করে, তবে প্রতিটি এলিমেন্টের জন্য আলাদা কোনো নাম থাকে না। মেমরি থেকে পড়ার কাজ বেশি হয় এমন অপারেশনে Elixir-এ টাপল প্রায়ই ব্যবহৃত হয়, কারণ কোনো এলিমেন্ট পড়া একটি ধ্রুব সময়ের অপারেশন। এলিমেন্ট যদি চাহিদা অনুযায়ী যোগ বা বাদ করতে হয়, সেক্ষেত্রে সাধারণত টাপল ব্যবহার করা হয় না; কারণ বিদ্যমান টাপলটি পরিবর্তন না করে নতুন একটি টাপল তৈরি করা হয়, যার জন্য আগে থেকেই মেমরি বরাদ্দ করতে হয়।

বাস্তবে Elixir-এ টাপল তৈরি করা হয় দ্বিতীয় বন্ধনী দিয়ে। শূন্য-ভিত্তিক ইনডেক্সিং ব্যবহার করে `elem/2` ফাংশন দিয়ে টাপলের প্রতিটি এলিমেন্ট আলাদা আলাদাভাবে পড়া যায়:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### দলবদ্ধ তথ্য হিসেবে টাপল

বাস্তবে দলবদ্ধ তথ্য প্রকাশ করতে টাপল প্রায়ই ব্যবহার করা হয়।

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## প্যাটার্ন ম্যাচিং

Elixir-এর দৃঢ় ও ইডিয়ম্যাটিক কোডে প্যাটার্ন ম্যাচিংয়ের ব্যবহারই প্রধান। আপনার মনে থাকতে পারে, `=/2` আসলে অ্যাসাইনমেন্ট অপারেটর নয়, ম্যাচ অপারেটর হিসেবে বর্ণিত হয়। ম্যাচ অপারেটর ব্যবহার করলে, বাঁ দিকের প্যাটার্নটি ডান দিকের সাথে মিলে গেলে বাঁ দিকের যেসব ভ্যারিয়েবল থাকে সেগুলো বাইন্ড হয়ে যায়, এবং ডান দিকের মানটি রিটার্ন হয়। মিল না হলে একটি `MatchError` রেইজ হয়।

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

মনে রাখবেন, ম্যাচিং ঘটে ডান দিক থেকে বাম দিকে।

শেষ উদাহরণে, প্যাটার্ন ম্যাচে কোনো ভ্যারিয়েবলের দরকার না হলে `_` লিখে সেটি বাদ দেওয়া যায়। `_` দিয়ে শুরু হওয়া কোনো ভ্যারিয়েবলই রানটাইম ট্র্যাক করে না।

### নামযুক্ত ফাংশনে প্যাটার্ন ম্যাচিং

একাধিক ফাংশন ক্লজ তৈরি করার সময়ও প্যাটার্ন ম্যাচিং একটি দরকারি কৌশল। ফাংশনের আর্গুমেন্টেও প্যাটার্ন ম্যাচিং ব্যবহার করা যায়, যা ঠিক করে দেয় কোন ফাংশন ক্লজটি কল হবে: ফাইলের একেবারে উপরের ক্লজ থেকে শুরু করে নিচের দিকে যেতে যেতে যেটি প্রথমে মেলে, সেটিই। ভ্যারিয়েবল ফাংশন হেডে বাইন্ড করা যায় এবং ফাংশন বডিতে ব্যবহার করা যায়।

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
