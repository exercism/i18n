# পরিচিতি

[মডিউল অ্যাট্রিবিউট][module-attr]গুলো ["কনস্ট্যান্ট"][attr-as-const] এর মতোই ব্যবহার করা যায়, যেগুলো কম্পাইল-টাইমে মূল্যায়ন করা হয়।

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

তবে এগুলো কঠোরভাবে কনস্ট্যান্টের মতো আচরণ করে না, কারণ মডিউলে সেগুলো আবার ডিফাইন করে ওভাররাইট করা যায়:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```
