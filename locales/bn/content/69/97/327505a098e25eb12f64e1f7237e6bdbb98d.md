# নির্দেশনা

এই অনুশীলনীতে আপনি একটি লগ করা রিপোর্টের লাইনগুলো প্রসেস করবেন।
প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট নিচের মতো: `"[<LEVEL>]: <MESSAGE>"`।

এখানে তিনটি আলাদা লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে, যার প্রত্যেকটিতে একটি লগ লাইন দেওয়া হবে এবং আপনাকে সেটি নিয়ে কিছু করতে বলা হবে।

## 1. একটি লগ লাইন থেকে মেসেজ বের করুন

একটি লগ লাইনের মেসেজ রিটার্ন করতে `log_line::message` মেথডটি ইমপ্লিমেন্ট করুন:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. একটি লগ লাইন থেকে লগ লেভেল বের করুন

একটি লগ লাইনের লগ লেভেল রিটার্ন করতে `log_line::log_level` মেথডটি ইমপ্লিমেন্ট করুন, যা বড় হাতের অক্ষরে রিটার্ন করতে হবে:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. একটি লগ লাইন রিফরম্যাট করুন

`log_line::reformat` মেথডটি ইমপ্লিমেন্ট করুন, যা লগ লাইনটি রিফরম্যাট করে, মেসেজটি আগে রাখে আর তার পরে বন্ধনীর মধ্যে লগ লেভেলটি রাখে:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
