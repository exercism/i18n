# ইনস্টলেশন

Reason ইনস্টল করতে আপনার Node Package Manager (npm) দরকার হবে। [এখানে](https://www.npmjs.com/get-npm) দেওয়া নির্দেশাবলি অনুসরণ করুন।

npm হয়ে গেলে, এইভাবে Reason ইনস্টল করুন:
```
npm install -g bs-platform
```

Reason-এর জন্য অনেক এডিটরের ইন্টিগ্রেশন আছে, [এখানে](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors) দেখুন।

কিছু কমান্ড লাইন টুল (এর মধ্যে একটি REPL আছে, যা দিয়ে আপনি শেলের ভেতরে Reason এক্সপ্রেশন মূল্যায়ন করতে পারবেন) [এখানে](https://github.com/reasonml/reason-cli) পাবেন।
