# সম্পর্কে

[পেয়ার ও ডিক্ট][pairs-dicts] কনসেপ্টে Julia-এর ডিকশনারি টাইপের মূল বিষয়গুলো আলোচনা করা হয়েছে।

যেহেতু [`Dict`][dict] একটি গুরুত্বপূর্ণ এবং বহুল ব্যবহৃত কালেকশন টাইপ, তাই এগুলো নিয়ে কাজ করার জন্য অনেক ফাংশনও আছে।

## এন্ট্রি পাওয়া

একটি এন্ট্রি পাওয়ার সবচেয়ে সহজ উপায় হলো কী (key) দিয়ে (যেমনটি অনেক ভাষাতেই হয়)। তবে যে কী (key) নেই, সেটি চাইলে `KeyError` হয়।

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

এন্ট্রিটি রিট্রিভ করার চেষ্টা করার আগে আমরা কী (key) আছে কি না পরীক্ষা করে দেখতে পারতাম (`haskey(d, 4)` বা `4 ∈ keys(d)`-এর মতো কিছু দিয়ে), তবে অনুপস্থিত কী (key)-গুলোর জন্য শুধু একটি ডিফল্ট মান পেয়ে যাওয়াটাও কাজে লাগতে পারে।

এর জন্য আছে [`get()`][get] ফাংশন এবং তার মিউটেটিং ভ্যারিয়েন্ট [`get!()`][get-bang]। এদের পার্থক্য হলো, অনুপস্থিত কী (key)-টি `Dict`-এ যোগ হয় কি না।

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

আগের কনসেপ্টে আমরা দেখেছি, `delete!()` একটি এন্ট্রি তার কী (key) দিয়ে মুছে ফেলে। `pop!()` ফাংশন ব্যবহার করে মানটি রিট্রিভ করার সাথে এটিকে একসাথে করা যায়।

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## ইটারেশন

একটি `Dict`-এর উপর ইটারেশন করলে ডিফল্টভাবে `key => value` পেয়ার পাওয়া যায়। স্বাভাবিক `.first` ও `.second` নাম ব্যবহার করে এর অংশগুলো পাওয়া যায়।

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

অনেক সময় আমরা শুধু কী (key)-গুলো বা শুধু মানগুলো ব্যবহার করতে চাই, যা সহজ।

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## মার্জ করা

দুটি `Dict` একসাথে করা কাজে লাগতে পারে, তবে একাধিক ইনপুটে থাকা কী (key)-গুলো নিয়ে আমরা কী করতে চাই, তা স্পষ্ট থাকা দরকার।

[`merge()`][merge] ও [`merge!()`][merge-bang] ফাংশন যত খুশি সংখ্যক প্রদত্ত `Dict`-কে বাম থেকে ডানে ক্রমানুসারে একসাথে করে।

আগে থেকে থাকা কী (key)-গুলোর মান কেবল ওভাররাইট হয়ে যায়, তাই একেবারে ডানদিকের `Dict`-ই "জিতে যায়"।

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

[`mergewith()`][mergewith] ও [`mergewith!()`][mergewith-bang] ফাংশনে আমরা প্রথম আর্গুমেন্ট হিসেবে একটি ফাংশন দিতে পারি, যা ঠিক করে দেয় একই কী (key) বারবার এলে কীভাবে মার্জ হবে। যোগ করা তার একটি সহজ উদাহরণ।

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

মার্জ করার সময় দুটি ভেক্টর জোড়া লাগানো আরেকটি জনপ্রিয় কাজ। এর জন্য Julia [`vcat()`][vcat] ফাংশন ব্যবহার করে, যার কারণ [`Multi Dimensional Arrays`][multidim] কনসেপ্টে ব্যাখ্যা করা হয়েছে।

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

একাধিক [`Set`][sets]-এর ক্ষেত্রে সংশ্লিষ্ট মার্জ ফাংশনটি হলো [`union`][union]।

লক্ষ্য করুন, `mergewith` ফাংশনগুলো [হায়ার অর্ডার ফাংশন][hof] কীভাবে কাজে লাগে তার একটি ভালো উদাহরণ।
