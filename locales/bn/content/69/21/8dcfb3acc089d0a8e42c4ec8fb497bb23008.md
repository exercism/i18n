# পরিচিতি

## নেমস্পেস

কোড সংগঠিত করার একটি গুরুত্বপূর্ণ পদ্ধতি হলো নেমস্পেস ব্যবহার। দুটি ফাংশনের নাম একই হয়ে যেতে পারে, যা তাদের আলাদা আলাদা নেমস্পেসে রেখে সমাধান করা যায়। নেমস্পেস নেস্টেড হতে পারে, যা বড় কোডবেস সাজাতে সাহায্য করতে পারে। নেমস্পেসে অ্যাক্সেস করা হয় স্কোপ-রেজোলিউশন অপারেটর `::` দিয়ে।

নিচের উদাহরণে দুটি আলাদা `foo` ফাংশনের ব্যবহার দেখানো হয়েছে। নিজ নিজ নেমস্পেস প্রিফিক্স করে এদের একসাথে ব্যবহার করা হয়েছে।

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
