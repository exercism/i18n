# টেস্ট চালানো

টার্মিনাল থেকে অনুশীলনীর বেস ডিরেক্টরিতে চলে যান, তারপর নিচের কমান্ডটি দিয়ে টেস্টগুলো চালান:

```bash
$ gleam test
```

এটি `test` সাবফোল্ডারে থাকা টেস্ট ফাইলটি চালাবে, অর্থাৎ যে ফাইলের নামের শেষে `_test.gleam` থাকে.

## টেস্ট ফাংশন

টেস্টগুলো একটি [কাস্টম টেস্ট ফ্রেমওয়ার্ক](https://github.com/exercism/gleam-test-runner/tree/main/runner) ব্যবহার করে।
`test` ডিরেক্টরিতে থাকা যে কোনো পাবলিক ফাংশন, যার নামের শেষে `_test` থাকে, টেস্ট ফ্রেমওয়ার্কের কাছে একটি টেস্ট হিসেবে গণ্য হবে।

উদাহরণস্বরূপ:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
