# নির্দেশনা

আপনার বন্ধু এইমাত্র আপনাকে একটি গুরুত্বপূর্ণ গোপন বার্তা পাঠিয়েছেন।
অন্যরা যাতে তা সহজে পড়তে না পারে, তাই একের পর এক বিট ম্যানিপুলেশন করে বার্তাটি এনক্রিপ্ট করা হয়েছে।
বার্তাটি ডিক্রিপ্ট করতে সাহায্য করার ফাংশনগুলো আপনাকে লিখতে হবে।

## 1. বিটগুলো পিছনে শিফট করুন

বার্তাটি ডিক্রিপ্ট করার প্রথম ধাপ হলো এনক্রিপশনের সময় করা শিফটটি আগের অবস্থায় ফিরিয়ে আনা, অর্থাৎ বিটগুলোকে আবার ডানে শিফট করা।
ডিক্রিপশনের পরের ধাপগুলো ধরে নেয় যে বাম দিক থেকে 0 ঢোকানো হয়েছে।

`shift_back()` ফাংশনটি লিখুন, যা একটি মান এবং কত ঘর শিফট করতে হবে সেই সংখ্যা নেয় এবং শিফটটি সম্পন্ন করে।

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. কিছু বিট সেট করুন

এরপর, কিছু বিট আছে যেগুলোকে 1 সেট করতে হবে।

`set_bits()` ফাংশনটি লিখুন, যা একটি মান এবং একটি মাস্ক নেয় এবং value-এর বিটগুলোকে 1 সেট করার ফলাফল রিটার্ন করে।
`mask`-এর যে বিটটি 1, `value`-এর সেই বিটটি 1 সেট করা উচিত।
বাকি সব বিট অপরিবর্তিত রাখতে হবে।

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. নির্দিষ্ট বিট ফ্লিপ করুন

এনক্রিপশনের সময় কিছু বিট ফ্লিপ করা হয়।
বার্তাটি ডিক্রিপ্ট করতে সেগুলো আবার ফ্লিপ করতে হবে।

`flip_bits()` ফাংশনটি লিখুন, যা একটি মান এবং একটি মাস্ক নেয়।
মাস্কটি বলে দেয় value-এর কোন বিটগুলো ফ্লিপ করতে হবে।
`mask`-এ কোনো বিট 1 হলে, `value`-এর সেই বিটটি ফ্লিপ করা হয়।
অন্য সব বিট অপরিবর্তিত রাখা হয়।

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. নির্দিষ্ট বিট ক্লিয়ার করুন

সবশেষে, কিছু বিট আছে যেগুলো সবসময় 0-তে ডিক্রিপ্ট হয়।

`clear_bits()` ফাংশনটি লিখুন, যা একটি মান এবং একটি মাস্ক নেয়।
`mask`-এর যে বিটটি 1, `value`-এর সেই বিটটি 0 সেট করা উচিত।
অন্য সব বিট অপরিবর্তিত রাখা উচিত।

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
