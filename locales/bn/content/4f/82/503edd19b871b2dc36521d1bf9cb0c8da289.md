# ভূমিকা

পাইথনে লুপ করার দুটি উপায় আছে।
`while` লুপ _অনির্দিষ্ট_ (গণনাহীন) ইটারেশনের জন্য, আর `for` লুপ _নির্দিষ্ট_ (গণনাযোগ্য) ইটারেশনের জন্য।
`break`, `continue` এবং `else` কিওয়ার্ডগুলো লুপের আচরণ নিজের মতো সাজিয়ে নিতে সাহায্য করে।
`range(<length of sequence>)` এবং `enumerate(<iterable>)` ফাংশন লুপ গণনা ও ইনডেক্সিংয়ে সাহায্য করে।


`while` লুপে কতবার লুপ চলবে তা আগে থেকে নির্দিষ্ট করা থাকে না, আর `loop` এক্সপ্রেশন বা "পরীক্ষা"-এর মান যতক্ষণ `True` হয়, ততক্ষণ এটি চলতে থাকে।
লুপ এক্সপ্রেশনটির মান `False` হলে লুপটি শেষ হয়।

```python
while expression:
    set_of_statements
```

`for` লুপ যেকোনো সিকোয়েন্সের মানগুলোর মধ্য দিয়ে ঘুরে চলে, আর আর কোনো মান রিটার্ন না হলে এটি শেষ হয়।
কোনো ডেটা স্ট্রাকচার বা অন্য ইটারেবল না থাকলে লুপ চালানোর জন্য `range(<length of sequence>)` ফাংশন একটি `loop` কাউন্টার বা সিকোয়েন্স দেয়।

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
