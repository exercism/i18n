# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার     | টাইপ    | বিবরণ                                  |
| -------- | --------- | ------- | -------------------------------------- |
| `$a0`    | ইনপুট     | অ্যাড্রেস | বাইনারি ক্যারেক্টারের নাল-টার্মিনেটেড স্ট্রিং |
| `$v0`    | আউটপুট    | ইন্টিজার | ইনপুট স্ট্রিংয়ের দশমিক মান              |
| `$t0-9`  | টেম্পোরারি | যেকোনো   | অস্থায়ীভাবে সংরক্ষণের জন্য ব্যবহৃত          |
