# টেস্ট

প্রতিটি উদাহরণের জন্য নিচের সাধারণ ধাপগুলো অনুসরণ করতে হবে।

প্রথমে আপনি যে অনুশীলনীটি চর্চা করতে চান, তার ডিরেক্টরিতে চলে যান, এক্ষেত্রে `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

এরপর টেস্টগুলো রান করুন। `test` মেক টার্গেটটি `compile`-এর উপর নির্ভর করে, তাই `make test` রান করলে আপনার সোর্স কম্পাইল হয়ে যাবে, এবং তারপর টেস্টগুলো রান করা হবে।


```bash
$ make test
```

অভিনন্দন! আপনার টেস্টগুলো ফেল করছে!!!

এখন `README.md` পড়ে জেনে নিন, আপনার সব টেস্ট পাস করাতে কী কী করতে হবে।


টেস্ট যে প্রথম এররটি রিপোর্ট করেছে সেটি ঠিক করুন, তারপর আবার টেস্টগুলো রান করুন।

```bash
$ make test
```

এরপর আপনার সোর্স কোডে ফেল করা পরের টেস্টটি ঠিক করতে থাকুন এবং টেস্ট রান করতে থাকুন, যতক্ষণ না সব টেস্ট পাস করে।

সব টেস্ট পাস হয়ে গেলে `src` ডিরেক্টরিতে আপনার কোডটি শেষবারের মতো দেখে নিন, যাতে কোড নিয়ে আপনি সন্তুষ্ট কি না তা নিশ্চিত হতে পারেন, তারপর রিভিউয়ের জন্য সাবমিট করুন।

ফিডব্যাক নিন, সমাধান সংশোধন করুন, সাবমিট করুন, পরের অনুশীলনীটি চেষ্টা করুন, আর এভাবেই চলতে থাকুন যতক্ষণ না LFE-এর পরম জ্ঞান লাভ হয়।
