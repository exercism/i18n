# পরিচিতি

Go-তে ফাংশন হলো ফার্স্ট-ক্লাস মান।
এর মানে হলো, অন্য সব মান নিয়ে যা যা করা যায়, ফাংশন নিয়েও ঠিক তা-ই করা যায়: ফাংশনকে ভ্যারিয়েবলে অ্যাসাইন করা, অন্য ফাংশনে আর্গুমেন্ট হিসেবে পাঠানো, এমনকি অন্য ফাংশন থেকে ফাংশন রিটার্ন করা।

নিচে আমরা দুটি ফাংশন তৈরি করছি, `engGreeting` এবং `espGreeting`, এবং সেগুলোকে `greeting` ভ্যারিয়েবলে অ্যাসাইন করছি:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

ফাংশন মান ব্যবহার করে ফাংশনকে শুধু ডেটা দিয়েই নয়, বিহেভিয়ার দিয়েও প্যারামিটারাইজ করার সুযোগ মেলে।
নিচের উদাহরণে আমরা `greetingFunc` প্যারামিটারের মাধ্যমে `dialog` ফাংশনে বিহেভিয়ার পাঠাচ্ছি:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

ফাংশন টাইপের একটি আনইনিশিয়ালাইজড ভ্যারিয়েবলের মান `nil`.
তাই `nil` ফাংশন মান কল করলে প্যানিক হয়।

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

ফাংশন মানকে `nil`-এর সাথে তুলনা করা যায়।
এটি অপ্রয়োজনীয় প্রোগ্রাম প্যানিক এড়াতে কাজে লাগতে পারে।

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## ফাংশন টাইপ

Go-তে ফাংশন টাইপের কারণেই ফাংশন মান ব্যবহার করা সম্ভব।
একটি ফাংশন টাইপ এমন সব ফাংশনের সেট বোঝায়, যাদের প্যারামিটার টাইপের ক্রম এবং রেজাল্ট টাইপের ক্রম একই।
ফাংশন টাইপের উপরে ইউজার-ডিফাইনড টাইপ ঘোষণা করা যায়।
যেমন, আগের উদাহরণগুলোর `dialog` ফাংশনটি এভাবে আপডেট করা যায়:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## অ্যানোনিমাস ফাংশন

ফার্স্ট-ক্লাস ফাংশন সাপোর্টের কারণে পাওয়া আরেকটি শক্তিশালী টুল হলো অ্যানোনিমাস ফাংশন।
অ্যানোনিমাস ফাংশন ব্যবহারের জায়গাতেই ডিফাইন করা হয়, `func` কিওয়ার্ডের পরে কোনো নাম ছাড়াই।
এমন ফাংশন যে ফাংশনের ভেতরে থাকে, তার ভ্যারিয়েবলগুলোতে অ্যাক্সেস পায়।

উদাহরণস্বরূপ:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib` কল করলে `n1` এবং `n2` ভ্যারিয়েবল দুটি ঘোষণা হয়, আর একটি অ্যানোনিমাস ফাংশন রিটার্ন হয়, যেটি আবার প্রতিবার কল করা হলে এই ভ্যারিয়েবলগুলোর মান বদলে দেয়।
অ্যানোনিমাস ফাংশনটি N-তম বার কল করলে ০ থেকে শুরু হওয়া ফিবোনাচি সিকোয়েন্সের N-তম সংখ্যাটি রিটার্ন করে। ভেতরের অ্যানোনিমাস ফাংশনটি `fib` ফাংশনের লোকাল ভ্যারিয়েবলগুলো (`n1` এবং `n2`) অ্যাক্সেস পায়।
ফাংশন মান যাতে এক কল থেকে পরের কল পর্যন্ত স্টেট ধরে রাখতে পারে, তার একটি দারুণ উপায় এটি।
আমরা বলি, অ্যানোনিমাস ফাংশনটি `n1` এবং `n2` ভ্যারিয়েবলের একটি ক্লোজার।
[ক্লোজার][closure] প্রোগ্রামিংয়ে ব্যাপকভাবে ব্যবহৃত হয়, এবং অন্য ভাষাতেও এগুলোর সাপোর্ট দেখতে পাবেন।

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
