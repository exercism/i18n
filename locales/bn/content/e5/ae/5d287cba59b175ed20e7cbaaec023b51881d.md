# ভূমিকা

## সাধারণ সিনট্যাক্স

কিছু লজিক বারবার চালানোর জন্য সবচেয়ে বেশি ব্যবহৃত স্টেটমেন্টগুলোর একটি হলো for লুপ।
Go-তে এটি `for` কিওয়ার্ড, একটি হেডার এবং কোঁকড়া বন্ধনীর ভেতরে মোড়ানো লুপের বডি সম্বলিত একটি কোড ব্লক নিয়ে গঠিত।
হেডারটি সেমিকোলন `;` দিয়ে আলাদা করা ৩টি অংশ নিয়ে গঠিত: init, condition এবং post।

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init** অংশটি এমন কিছু কোড, যা লুপ শুরু হওয়ার আগে কেবল একবার রান করে।
- **condition** অংশটি অবশ্যই এমন একটি এক্সপ্রেশন হতে হবে যার ফলাফল একটি বুলিয়ান, এবং যা নিয়ন্ত্রণ করে লুপটি কখন থামবে।
  এই শর্তটি যতক্ষণ ট্রু-তে মূল্যায়িত হয়, ততক্ষণ লুপের ভেতরের কোড রান করবে।
  এক্সপ্রেশনটি ফলস-এ মূল্যায়িত হওয়ামাত্র লুপের আর কোনো ইটারেশন রান করবে না।
- **post** অংশটি এমন কিছু কোড, যা প্রতিটি ইটারেশনের শেষে রান করবে।

**লক্ষ্য করুন:** অন্য ভাষার মতো এখানে হেডারের তিনটি অংশকে ঘিরে প্রথম বন্ধনী `()` থাকে না।
আসলে এমন বন্ধনী বসানো একটি কম্পাইলেশন এরর।
তবে লুপের বডিকে ঘিরে থাকা দ্বিতীয় বন্ধনী `{ }` সবসময়ই প্রয়োজন।

## for লুপ: একটি উদাহরণ

সাধারণত init অংশটি একটি কাউন্টার ভ্যারিয়েবল তৈরি করে, condition অংশটি পরীক্ষা করে লুপটি চালিয়ে যাওয়া উচিত নাকি থামানো উচিত, আর post অংশটি সাধারণত প্রতিটি পুনরাবৃত্তির শেষে কাউন্টারটি ইনক্রিমেন্ট করে।

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

এই লুপটি `1` থেকে `9` পর্যন্ত সংখ্যাগুলো প্রিন্ট করবে (`9` সহ)।
উপরের উদাহরণে দেখানো হয়েছে, ধাপ নির্ধারণ করা হয় সাধারণত একটি ইনক্রিমেন্ট বা ডিক্রিমেন্ট স্টেটমেন্ট ব্যবহার করে।
