# টেস্ট

টেস্টগুলো এভাবে চালান:

```shell
npm run test
```

আপনি Jest কে "watch" মোডেও চালাতে পারেন, তখন কোড বা টেস্ট মডিউলে পরিবর্তন সেভ করলেই টেস্টগুলো স্বয়ংক্রিয়ভাবে আবার চলে:

```shell
npm run watch
```

## স্কিপ করা টেস্ট বোঝা

স্কিপ মেথড টেস্ট স্যুটকে একটি টেস্ট না চালানোর নির্দেশ দেয়। এই ফাংশনটি নিচের অ্যালিয়াসগুলো দিয়েও ব্যবহার করা যায়: `it.skip(name, fn)` বা `xit(name, fn)` বা `xtest(name, fn)`

- কেন এগুলো স্কিপ করা হয়?

ব্যবহারকারীরা যাতে একবারে একটি টেস্টে মনোযোগ দিতে পারেন এবং সমাধান এগিয়ে নেওয়ার সাথে সাথে একটি একটি করে সেগুলো চালু করতে পারেন, সেজন্য।

- কীভাবে এগুলো চালু করবেন?

`xtest` কে `test` এ পরিবর্তন করুন।

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
