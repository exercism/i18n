# ভূমিকা

একটি *রেগুলার এক্সপ্রেশন* (regex) হলো ছোট একটি প্যাটার্ন, যা বর্ণনা করে কিছু টেক্সট দেখতে কেমন হওয়া উচিত। নিজে একটি স্ট্রিং এক ক্যারেক্টার করে যাচাই করার বদলে আপনি একবারই যে আকারটি চান সেটি লিখে দেন, আর মেলানোর কাজটি Factor-কে করতে দেন। Factor-এর regex টুলগুলো থাকে [`regexp`][regexp] ভোকাবুলারিতে।

## একটি প্যাটার্ন লেখা

Factor-এ আপনি একটি regex লেখেন `R/ ` আর `/`-এর মাঝখানে:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

প্যাটার্নের বেশিরভাগ ক্যারেক্টার কেবল নিজেকেই বোঝায়, `R/ cat/` মেলে `cat` টেক্সটের সাথে। আসল শক্তি আসে কয়েকটি বিশেষ অংশ থেকে, যারা বোঝায় একেক *ধরনের* ক্যারেক্টার, বা সেগুলোর *কতগুলো*।

### ক্যারেক্টার ক্লাস: একটি সেট থেকে একটি ক্যারেক্টার

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

একটি ক্লাস মেলে ঠিক *একটি* ক্যারেক্টারের সাথে। `[A-Z]` মেলে `Q`-এর সাথে, কিন্তু `QQ`-এর সাথে নয়।

### কোয়ান্টিফায়ার: কতবার

কোনো অংশের *পরে* এদের একটি বসিয়ে বলুন সেটি কতবার পুনরাবৃত্তি হতে পারে:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

তাই `\d{4}` মানে পরপর চারটি সংখ্যা, আর `[A-Z]+` মানে এক বা একাধিক বড় হাতের অক্ষর। সব মিলিয়ে `R/ [A-Z]+-\d+/` বর্ণনা করে "এক বা একাধিক বড় হাতের অক্ষর, একটি ড্যাশ, তারপর এক বা একাধিক সংখ্যা", অর্থাৎ `SALE-2024`-এর মতো টেক্সট। এখানে `-` একটি সাধারণ ক্যারেক্টার: `[ ]`-এর বাইরে একটি ড্যাশ শুধু একটি ড্যাশের সাথে মেলে (ক্লাসের ভিতরে, যেমন `[A-Z]`-এ, এটি একটি রেঞ্জ বোঝায়)।

## পুরো একটি স্ট্রিং মেলানো

`matches?` উত্তর দেয় "এই *পুরো* স্ট্রিংটি কি প্যাটার্নের সাথে মেলে?" প্যাটার্নকে শুরু থেকে শেষ পর্যন্ত প্রতিটি ক্যারেক্টারের হিসাব দিতে হয়:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

যদিও `SALE-2024` রয়েছে `"GET SALE-2024"`-এর ভিতরে, `matches?` তবুও `f` বলে: বাড়তি ক্যারেক্টারগুলো স্ট্রিংয়েরই অংশ, আর তারা প্যাটার্নের সাথে মেলে না। যখন আপনার শুধু জানা দরকার প্যাটার্নটি *কোথাও* আছে কি না, তখন ব্যবহার করুন `re-contains?`; এটি ঠিক সেখানেই `t` রিটার্ন করে যেখানে `matches?` `f` রিটার্ন করেছিল:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## বড় টেক্সটের ভিতরে ম্যাচ খুঁজে বের করা

`re-contains?` শুধু বলে প্যাটার্নটি ভিতরে আছে কি না। পরের শব্দগুলো ভিতরে খুঁজে জানায় *কী* মিলেছে: `all-matching-subseqs` প্যাটার্ন যেসব জায়গায় মেলে সেগুলো স্ট্রিংয়ের একটি সিকোয়েন্স হিসেবে রিটার্ন করে, আর `count-matches` শুধু তাদের গুনে দেয়:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## ম্যাচ প্রতিস্থাপন করা

`re-replace` প্রতিটি ম্যাচকে প্রতিস্থাপন টেক্সটের একটি টুকরো দিয়ে বদলে দেয় এবং নতুন স্ট্রিংটি রিটার্ন করে:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

`regexp` ভোকাবুলারিতে জানার মতো আরও শব্দ আছে; বিস্তারিত জানতে লিংকগুলো দেখুন: [`first-match`][first-match] (শুধু প্রথম ম্যাচটি) আর [`re-split`][re-split] (প্যাটার্ন যেখানে যেখানে মেলে সেখানে স্ট্রিং ভাগ করে)।
