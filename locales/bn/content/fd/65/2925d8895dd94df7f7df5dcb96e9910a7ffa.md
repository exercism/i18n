# ভূমিকা

সবচেয়ে উপকারী সিকোয়েন্স ওয়ার্ডগুলো তাদের একটি ইনপুট হিসেবে একটি *কোয়োটেশন* নেয় এবং সেটি দিয়ে অপারেশন চালায়:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (এটিও `sequences`-এ আছে) একটি কোয়োটেশনকে সিকোয়েন্সের ওপর ম্যাপ করে এবং এক পাসেই ফলাফলগুলো যোগ করে। একই প্যাটার্নেই চলে `sort-by` ([`sorting`][sorting]-এ) এবং `minimum-by` / `maximum-by` (`sequences`-এ)।

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
