# টেস্ট

অনুশীলনীর ডিরেক্টরির ভেতর থেকে টেস্ট চালাতে এই কমান্ডটি রান করুন:

```sh
odin test .
```

টেস্ট করার সময় Odin আপনার কোড "ভেট" করতে পারে: অব্যবহৃত ইমপোর্ট আর ভ্যারিয়েবলের মতো বিষয়গুলো সে খুঁজে দেখতে পারে। টেস্টগুলো এভাবে রান করুন:

```sh
odin test . -vet
```

আরও অপশনের জন্য দেখুন `odin test -help`.
