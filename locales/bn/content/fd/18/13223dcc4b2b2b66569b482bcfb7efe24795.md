# নির্দেশনা সংযোজন

## এক্সেপশন কাস্টমাইজ করা ও রেইজ করা

কখনও কখনও আপনার কোডে এক্সেপশন [কাস্টমাইজ](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) করা এবং [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) করা, দুটোই প্রয়োজন হয়। এমনটা করলে আপনার সর্বদা একটি **অর্থবহ এরর মেসেজ** যোগ করা উচিত, যাতে বোঝা যায় এররটির উৎস কী। এতে আপনার কোড আরও পড়ার উপযোগী হয় এবং ডিবাগিংয়ে অনেক সাহায্য করে।

নতুন এক্সেপশন ক্লাসের মাধ্যমে কাস্টম এক্সেপশন তৈরি করা যায় (বিস্তারিত জানতে [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) দেখুন), যেগুলো সাধারণত [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception)-এর সাবক্লাস হয়।

যেসব ক্ষেত্রে আপনি জানেন যে এররটির উৎস কোনো নির্দিষ্ট এক্সেপশন টাইপের একটি রূপ হবে, সেখানে আপনি _Exception_ ক্লাসের অধীনস্থ [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)-এর একটি থেকে ইনহেরিট করতে বেছে নিতে পারেন। এররটি রেইজ করার সময়ও আপনার একটি অর্থবহ মেসেজ যোগ করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে স্ট্যাক যথেষ্ট পরিমাণে ভরাট না থাকলে [রেইজ](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/"থ্রো" করার জন্য একটি _কাস্টম এক্সেপশন_ তৈরি করা প্রয়োজন। টেস্টগুলো তখনই পাস করবে যখন আপনি একটি উপযুক্ত এক্সেপশন কাস্টমাইজ করবেন, সেই এক্সেপশনটি `raise` করবেন এবং উপযুক্ত এরর মেসেজ যোগ করবেন।


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

এছাড়াও, এই অনুশীলনীতে এরর মেসেজসহ বেশ কিছু `built-in exceptions` রেইজ করা প্রয়োজন।
মেসেজসহ একটি `built-in exception` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
