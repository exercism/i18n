# পরিচিতি

Common Lisp-এ একটি গ্লোবাল ফাংশন ডিফাইন করতে `defun` এক্সপ্রেশনটি ব্যবহার করা হয়।
এই এক্সপ্রেশনটি তার প্রথম আর্গুমেন্ট হিসেবে প্যারামিটারগুলোর একটি তালিকা নেয় (খালি তালিকা মানে ফাংশনটির কোনো প্যারামিটার নেই)।
এরপর আসে ঐচ্ছিক একটি ডকুমেন্টেশন স্ট্রিং (নিচে দেখুন), তারপর শূন্য বা তার বেশি এক্সপ্রেশন, যেগুলো মিলে ফাংশনটির "বডি" তৈরি করে।

ফাংশনে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে।

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

ফাংশন কল করা হয় এমন একটি এক্সপ্রেশন মূল্যায়ন করে, যেখানে ফাংশনটিকে নির্দেশকারী সিম্বলটি এক্সপ্রেশনটির প্রথম এলিমেন্ট এবং ফাংশনের আর্গুমেন্টগুলো (যদি থাকে) এক্সপ্রেশনটির বাকি আইটেম হিসেবে থাকে।

একটি ফাংশন যে মানে মূল্যায়িত হয়, সেটি হলো ফাংশন বডির মধ্যে সর্বশেষ যে এক্সপ্রেশনটি মূল্যায়িত হয়েছিল তার মান।
সব ফাংশনই একটি মানে মূল্যায়িত হয়।

```lisp
(add-nums 2 2) ;; => 4
```

ফাংশনে ঐচ্ছিকভাবে একটি ডকুমেন্টেশন স্ট্রিং-ও থাকতে পারে (যাকে 'ডকস্ট্রিং'ও বলা হয়)।
এটি দিলে তা আর্গুমেন্ট তালিকার পরে কিন্তু ফাংশনের বডির আগে আসে।
ডকুমেন্টেশন স্ট্রিংটি `documentation`-এর মাধ্যমে পাওয়া যায়।

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
