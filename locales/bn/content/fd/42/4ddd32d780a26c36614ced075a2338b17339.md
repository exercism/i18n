# নির্দেশনা

আপনি [Numberphile Youtube চ্যানেল](https://www.youtube.com/watch?v=PeUbRXnbmms)-এর একজন বড় ভক্ত এবং আপনি এইমাত্র _লুকাস সংখ্যা অনুক্রম_ সম্পর্কে একটি দুর্দান্ত ভিডিও দেখেছেন। আপনি Elixir ব্যবহার করে এই অনুক্রমটি তৈরি করতে চান।

আপনার ফাংশন ডিজাইন করার সময়, আপনি _লেজি ইভালুয়েশন_ ব্যবহার করতে চান, যাতে আপনি যত সংখ্যা চান জেনারেট করতে পারেন, কিন্তু কেবল তখনই যখন আপনার প্রয়োজন হয়। তাই আপনি একটি স্ট্রিম ব্যবহার করার সিদ্ধান্ত নেন।

## 1. ভুল আর্গুমেন্ট ধরুন

সিকোয়েন্সটি জেনারেট করতে যদি কোনও নন-ইন্টিজার বা ১-এর কম ইন্টিজার ব্যবহার করা হয়, তাহলে একটি এরর রেইজ করার জন্য একটি গার্ড ক্লজ যোগ করুন। প্রথম ধাপ হিসেবেই এটি করলে পরবর্তী ধাপগুলোতে অসীম রিকার্সন বাগ প্রতিরোধ করা যাবে।

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. বেস কেসগুলো জেনারেট করুন

আপনি জানেন যে এই অনুক্রমের দুটি প্রারম্ভিক সংখ্যা আছে যেগুলো একই নিয়ম অনুসরণ করে না। এই সংখ্যাগুলো রিটার্ন করার জন্য দুটি বেস কেস ক্লজ লিখুন:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. জেনারালাইজড কেস তৈরি করুন

২-এর চেয়ে বড় যেকোনো অনুক্রমের জন্য, আপনি জানেন যে পরবর্তী সংখ্যা পেতে আপনাকে আগের দুটি সংখ্যা যোগ করতে হবে এবং এভাবে চলতে থাকবে। জেনারালাইজড কেসটি লিখুন।

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
