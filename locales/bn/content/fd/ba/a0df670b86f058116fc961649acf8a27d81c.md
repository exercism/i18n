# নির্দেশনা

এই অনুশীলনীতে আপনি লগ-লাইন প্রসেস করবেন।

প্রতিটি লগ লাইন একটি স্ট্রিং, যার ফরম্যাট নিচের মতো: `"[<LEVEL>]: <MESSAGE>"`।

এখানে তিনটি ভিন্ন লগ লেভেল রয়েছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে, যার প্রতিটিতে একটি লগ লাইন নেওয়া হবে এবং সেটি নিয়ে আপনাকে কিছু একটা করতে বলা হবে।

## 1. একটি লগ লাইন থেকে মেসেজ বের করা

একটি লগ লাইনের মেসেজ রিটার্ন করার জন্য `message()` ফাংশনটি ইমপ্লিমেন্ট করুন:

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

শুরু বা শেষে থাকা যেকোনো হোয়াইট স্পেস মুছে ফেলতে হবে:

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. একটি লগ লাইন থেকে লগ লেভেল বের করা

একটি লগ লাইনের লগ লেভেল রিটার্ন করার জন্য `logLevel()` ফাংশনটি ইমপ্লিমেন্ট করুন; লেভেলটি ছোট হাতের অক্ষরে রিটার্ন করতে হবে:

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. একটি লগ লাইন রিফরম্যাট করা

লগ লাইনটি রিফরম্যাট করার জন্য `reformat()` ফাংশনটি ইমপ্লিমেন্ট করুন, যেখানে মেসেজটি সবার আগে থাকবে আর তার পরে বন্ধনীর ভেতরে লগ লেভেলটি থাকবে:

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
