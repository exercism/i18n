# পরিচিতি

*হিপ* হলো এমন একটি কালেকশন, যা সব সময় নিজের সবচেয়ে ছোট আইটেমটি জানে এবং আপনাকে সেটি দ্রুত সরিয়ে ফেলতে দেয়। *প্রায়োরিটি কিউ*-এর স্বাভাবিক ইমপ্লিমেন্টেশনই হলো হিপ। হিপগুলো [`heaps`][heaps] ভোকাবুলারিতে থাকে।

`<min-heap>` একটি খালি হিপ তৈরি করে, যার সবচেয়ে ছোট কী (key) সবার আগে বেরিয়ে আসে; `<max-heap>` হলো তার ঠিক উল্টো। প্রতিটি আইটেম হলো একটি *মান*, যা একটি *কী (key)* এর অধীনে রাখা হয়, আর সেই কী (key) ই হলো তার অগ্রাধিকার:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

হিপ *মিউটেবল*। `heap-push` এটিকে জায়গায় বসেই বদলে দেয়। `heap-peek` কিছু না সরিয়ে সামনের মান ও কী (key) রিটার্ন করে, `heap-pop` সেটি সরিয়ে ফেলে এবং রিটার্ন করে, আর `heap-pop-all` হিপটি অগ্রাধিকার অনুযায়ী `{ key value }` জোড়ার একটি অ্যাসোসিয়েশন লিস্টে খালি করে দেয়:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
