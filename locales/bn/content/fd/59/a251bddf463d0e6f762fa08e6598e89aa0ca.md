# নির্দেশনা

এই অনুশীলনীতে আপনি একটি গাড়ির কারখানার অ্যাসেম্বলি লাইনের উৎপাদন বিশ্লেষণ করার কোড লিখবেন। অ্যাসেম্বলি লাইনের গতি `0` (বন্ধ) থেকে `10` (সর্বোচ্চ) পর্যন্ত হতে পারে।

সর্বনিম্ন গতিতে (`1`) প্রতি ঘণ্টায় `221`টি গাড়ি উৎপাদিত হয়। গতি বাড়ার সাথে সাথে উৎপাদন রৈখিকভাবে বাড়ে। তাই গতি `4` হলে প্রতি ঘণ্টায় `4 * 221 = 884`টি গাড়ি উৎপাদিত হওয়া উচিত। তবে গতি বেশি হলে ত্রুটিপূর্ণ গাড়ি তৈরি হওয়ার সম্ভাবনা বেড়ে যায়, আর সেগুলোকে পরে বাদ দিতে হয়।

আপনার সামনে তিনটি কাজ আছে।

## 1. সফলতার হার গণনা করুন

নির্দিষ্ট কোনো গতিতে একটি আইটেম ত্রুটি ছাড়া তৈরি হওয়ার অনুপাত গণনা করতে `success_rate()` মেথডটি ইমপ্লিমেন্ট করুন। নিচের টেবিলটি দেখায় কীভাবে গতি সফলতার হারকে প্রভাবিত করে:

- `0`: ০% সফলতার হার।
- `1` থেকে `4`: ১০০% সফলতার হার।
- `5` থেকে `8`: ৯০% সফলতার হার।
- `9`: ৮০% সফলতার হার।
- `10`: ৭৭% সফলতার হার।

```R
success_rate(10)
# => 0.77
```

## 2. প্রতি ঘণ্টায় উৎপাদন হার গণনা করুন

অ্যাসেম্বলি লাইনের সফলতার হার বিবেচনায় নিয়ে প্রতি ঘণ্টায় তার উৎপাদন হার গণনা করতে `production_rate_per_hour()` মেথডটি ইমপ্লিমেন্ট করুন:

```R
production_rate_per_hour(6)
# => 1193.4
```

লক্ষ করবেন, এখানে রিটার্ন করা মানটি একটি `double`।

## 3. প্রতি মিনিটে উৎপাদিত কার্যকর আইটেমের সংখ্যা গণনা করুন

প্রতি মিনিটে কতগুলো কার্যকর গাড়ি তৈরি হয় তা গণনা করতে `working_items_per_minute()` মেথডটি ইমপ্লিমেন্ট করুন:

```R
working_items_per_minute(6)
# => 19
```

লক্ষ করবেন, রিটার্ন করা মানটি একটি ইন্টিজার: অসম্পূর্ণ আইটেম এতে ধরা হয় না।
