# ভূমিকা

Swift-এ এমন কিছু স্টেটমেন্ট আছে যা দিয়ে লুপের স্বাভাবিক কন্ট্রোল ফ্লো বদলানো যায়।
এগুলোকে বলা হয় কন্ট্রোল ট্রান্সফার স্টেটমেন্ট।
আপনি ইতিমধ্যেই `return` দেখেছেন; এই কনসেপ্টে আরও কয়েকটির সাথে পরিচয় হবে, যার মধ্যে আছে `continue`, `break` এবং লেবেল।
এই কনসেপ্টে আমরা `fallthrough` নিয়ে আলোচনা করব না, তবে [Swift বই][fallthrough]-তে এটি সম্পর্কে পড়তে পারেন।

## Continue

কখনও কখনও লুপের বর্তমান ইটারেশনের বাকি স্টেটমেন্টগুলো শেষ না করেই পরের ইটারেশনে চলে যাওয়া দরকার হয়।
এ কাজে `continue` কিওয়ার্ডটি ব্যবহার করা যায়।
`continue` কার্যকর হলে লুপটি লাফ দিয়ে পরের পরীক্ষায় চলে যায়: লুপের পরের ইটারেশনটি রান করা যাবে কি না তা দেখা হয়। while ও repeat-while লুপে এই পরীক্ষাটি `while` অংশটি, আর for-in লুপে সিকোয়েন্সে আরেকটি এলিমেন্ট আছে কি না সেটি।

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

break ব্যবহার করা হয় লুপ থেকে আগেভাগেই বেরিয়ে যেতে।
`break` কার্যকর হলে লুপটি সঙ্গে সঙ্গে শেষ হয়ে যায় এবং প্রোগ্রামটি লুপের পরের প্রথম স্টেটমেন্ট থেকে চলতে থাকে।

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## লেবেল

লুপগুলো নেস্টেড থাকলে কখনও কখনও এমন হয় যে, যে লুপের ভেতরে `break` বা `continue` ব্যবহার করা হচ্ছে, তার বাইরের লুপ থেকে বেরিয়ে যেতে বা সেটি আবার শুরু করতে চান।
এমন ক্ষেত্রে লেবেল ব্যবহার করে ঠিক কোন লুপ থেকে বেরোতে হবে বা কোনটি আবার শুরু করতে হবে তা নির্দিষ্ট করা যায়।
লুপ শুরু করা `while`, `repeat` বা `for`-এর আগে একটি নাম আর তারপর একটি কোলন বসিয়ে লুপে লেবেল দেওয়া যায়।

এভাবে লেবেল ব্যবহারের ফল দেখতে নিচের লুপটি দেখুন।

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
