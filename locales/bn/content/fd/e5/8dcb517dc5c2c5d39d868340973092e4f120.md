# পরিচিতি

Go-তে, একটি কনস্ট্যান্ট হলো একটি সরল, অপরিবর্তনীয় মান, যা `const` কিওয়ার্ড দিয়ে একটি নামে অ্যাসাইন করা হয়:

```go
const myWebsite = "Exercism"
```

এ ধরনের কনস্ট্যান্টগুলো আনটাইপড, কিন্তু যখন টাইপের প্রয়োজন হয়, তখন এদের সিনট্যাক্সের ভিত্তিতে একটি ডিফল্ট টাইপ দেওয়া হয়, যেমন যখন এগুলো কোনো মেথডে পাস করা হয়।
স্পষ্টভাবে একটি টাইপ যোগ করে টাইপড কনস্ট্যান্ট তৈরি করা যায়:

```go
const myWebsite string = "Exercism"
```

অন্য কিছু ভাষার মতো Go-তে এনাম নেই, তবে এনুমারেটেড কনস্ট্যান্ট তৈরির জন্য `iota` নামের একটি পূর্বঘোষিত আইডেন্টিফায়ার আছে।
একটি ব্লকে থাকা কনস্ট্যান্টগুলো অন্তর্নিহিতভাবে পুনরাবৃত্ত হয়:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
