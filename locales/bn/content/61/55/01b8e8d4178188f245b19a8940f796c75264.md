# Alias

[বিশেষ ফর্ম `alias`][alias] ব্যবহার করে বাইরের কোনো মডিউল যে নামে উল্লেখ করেন, সেই নাম ছোট করা বা বদলে ফেলা যায়। `:as` অপশন দিয়ে পছন্দমতো একটি নাম ঠিক করে দেওয়া যায়।

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

কোনো আর্গুমেন্ট ছাড়া ব্যবহার করলে এটি মডিউলের নামটি ছেঁটে কেবল তার শেষ অংশটুকু রেখে দেয়, যেমন

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

`{}` দিয়ে একাধিক অ্যালিয়াস একসাথে গ্রুপ করা যায়:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

সাধারণত অ্যালিয়াস মডিউল ডেফিনিশনের শুরুতে যোগ করা হয়, তবে যেকোনো জায়গাতেই যোগ করা যায়। এগুলোর লেক্সিকাল স্কোপ থাকে, অর্থাৎ কোনো ফাংশন ডেফিনিশনের ভেতরে যোগ করা অ্যালিয়াস অন্য একটি ফাংশনে পাওয়া যাবে না।

ব্যবহার না করা অ্যালিয়াস কম্পাইলার ওয়ার্নিং তৈরি করে।
