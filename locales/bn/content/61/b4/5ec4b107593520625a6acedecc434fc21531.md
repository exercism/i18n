# নির্দেশাবলি

এই অনুশীলনীতে আপনি একজন বন্ধুর সাথে একটি সংখ্যা অনুমান করার গেম খেলছেন।
নিয়মগুলো সহজ: আপনি গোপনে `1` থেকে `100`-এর মধ্যে একটি সংখ্যা বেছে নেন, আর আপনার বন্ধু আপনি কোন সংখ্যাটি বেছেছেন তা অনুমান করার চেষ্টা করে।
আপনার বন্ধুকে সাহায্য করার জন্য, আপনি যে সংখ্যাটি বেছেছেন (`42`) তার সাথে অনুমানটি কতটা কাছাকাছি ছিল তার উপর নির্ভর করে আপনি ভিন্নভাবে উত্তর দেন।
সম্ভাব্য বিভিন্ন ইনপুটের জন্য নিয়মগুলো এই রকম:

- অনুমানটি `42` হলে: "Correct"
- অনুমানটি `41` বা `43` হলে: "So close"
- অনুমানটি `41`-এর কম হলে: "Too low"
- অনুমানটি `43`-এর বেশি হলে: "Too high"

অনুমানগুলোর উত্তর তৈরি করতে আপনার সামনে চারটি কাজ রয়েছে।

## 1. সঠিক অনুমানের উত্তর দিন

সঠিক অনুমানের উত্তর দিতে `reply` ফাংশনটি ইমপ্লিমেন্ট করুন:

```haskell
reply 42
-- -> "Correct"
```

## 2. কাছাকাছি অনুমানের উত্তর দিন

কাছাকাছি অনুমানগুলোর উত্তর দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```haskell
reply 41
-- -> "So close"
```

## 3. খুব কম অনুমানের উত্তর দিন

খুব কম অনুমানগুলোর উত্তর দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```haskell
reply 25
-- -> "Too low"
```

## 4. খুব বেশি অনুমানের উত্তর দিন

খুব বেশি অনুমানগুলোর উত্তর দিতে `reply` ফাংশনটি পরিবর্তন করুন:

```haskell
reply 88
-- -> "Too high"
```
