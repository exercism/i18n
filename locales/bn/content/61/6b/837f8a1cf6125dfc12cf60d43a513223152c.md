# পরিচিতি

[স্ট্রাক্ট ও ক্লাসের মেম্বারের নানা ধরন][expression-bodied-members] এক্সপ্রেশন-বডিড মেম্বার সিনট্যাক্স ব্যবহার করতে পারে; এর প্রধান ব্যতিক্রম ফিল্ড। প্রথাগত ব্লক বা স্টেটমেন্টের চেয়ে এক্সপ্রেশন দিয়ে একটি মেম্বার ডিফাইন করলে প্রায়ই আরও সংক্ষিপ্ত ও পাঠযোগ্য কোড পাওয়া যায়।

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

এক্সপ্রেশন-বডিড মেম্বারে একাধিক স্টেটমেন্টের ব্লক থাকতে পারে না, তবে ফাংশনাল ব্যাকগ্রাউন্ড থেকে আসা পাঠকদের সাবধান করা দরকার: প্রথাগত একটি মেম্বার যা করতে পারে, এই মেম্বারগুলোর একটি দিয়েও তার সবই করা সম্ভব। এই "এক্সপ্রেশন" সাইড এফেক্ট তৈরি করা একটি অ্যাসাইনমেন্ট অপারেশন হতে পারে, আবার একটি মেথড ইনভোকেশনও হতে পারে, অর্থাৎ যেকোনো কিছুই সম্ভব।
