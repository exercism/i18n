# নির্দেশনা

_Instruments of Texas_-এ কাজ করার সময় আপনাকে C#-এ লেখা একটি পরীক্ষামূলক ক্যালকুলেটর নিয়ে কাজ করার দায়িত্ব দেওয়া হয়েছে। আপনি একটি টেস্ট হার্নেস তৈরি করছেন, যেটি দিয়ে ক্যালকুলেটরের বেশ কিছু ফাংশন যাচাই করবেন, শুরু হবে গুণ দিয়ে। দেখবেন, গুণের দুটি অপারেন্ড ঋণাত্মক হলে বিশেষ মনোযোগ দেওয়ার বিষয় আছে।

`Calculator` ক্লাসটি আপনার জন্য দেওয়া হয়েছে এবং এটি পরিবর্তন করা উচিত নয়।

## 1. ইউজার-ডিফাইন্ড এক্সেপশন `CalculationException`-এর ডেফিনিশন সম্পূর্ণ করুন

`CalculationException`-এর কনস্ট্রাক্টরের ডেফিনিশন সম্পূর্ণ করুন, যেটি ক্যালকুলেটর থেকে থ্রো হওয়া যেকোনো এক্সেপশন এবং এক্সেপশনটি থ্রো হওয়ার সময় প্রসেস হতে থাকা অপারেন্ডগুলো সংরক্ষণ (র্যাপ) করবে।

## 2. ক্যালকুলেটরে ওভারফ্লো পরিস্থিতি সামলান এবং কলারকে আরও সমৃদ্ধ তথ্য দিন

`CalculatorTestHarness.Multiply()` মেথডটি ইমপ্লিমেন্ট করুন, যেটি কনস্ট্রাক্টরে পাস করা `Calculator` ইনস্ট্যান্সের `Calculator.Multiply()` মেথড কল করবে এবং x ও y ইন্টিজার মান পাস করবে। `Calculator.Multiply()` মেথডে ওভারফ্লো ঘটলে এটি একটি `OverflowException` থ্রো করবে। এই এক্সেপশনটি `CalculatorTestHarness.Multiply()` মেথডে ধরে ফেলে একটি `CalculationException`-এ র্যাপ করা উচিত, আর যে x ও y মানগুলো পাস করা হচ্ছে সেগুলো এক্সেপশনের অপারেন্ড হিসেবে সংরক্ষণ করা উচিত। নতুন তৈরি হওয়া `CalculationException` অবজেক্টটি থ্রো করা উচিত। `Calculator.Multiply()` মেথড সফল হলে তার রিটার্ন করা মান উপেক্ষা করতে পারেন।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. বৈধ ইনপুটের জন্য গুণের অপারেশন পরীক্ষা করুন

`CalculatorTestHarness.TestMultiplication()` মেথডটি ইমপ্লিমেন্ট করুন, যেটি দুটি ইন্টিজার নেয় এবং `CalculatorTestHarness.Multiply()` মেথড কল করে। `"Multiply succeeded"` রিটার্ন হয়।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. ঋণাত্মক ইনপুটের জন্য গুণের অপারেশন পরীক্ষা করুন

`CalculatorTestHarness.TestMultiplication()` মেথডটি এমনভাবে পরিবর্তন করুন যাতে দুটি ইন্টিজার আর্গুমেন্টই ঋণাত্মক (শূন্যের কম) হলে `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` রিটার্ন হয়।

`<INNER_EXCEPTION_MESSAGE>` প্লেসহোল্ডারের জায়গায় `CalculationException`-এর ইনার এক্সেপশনের মেসেজ বসাতে হবে।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. ধনাত্মক ইনপুটের জন্য গুণের অপারেশন পরীক্ষা করুন

`CalculatorTestHarness.TestMultiplication()` মেথডটি এমনভাবে পরিবর্তন করুন যাতে ইন্টিজার আর্গুমেন্টগুলোর অন্তত একটি ঋণাত্মক না হলে `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` রিটার্ন হয়।

`<INNER_EXCEPTION_MESSAGE>` প্লেসহোল্ডারের জায়গায় `CalculationException`-এর ইনার এক্সেপশনের মেসেজ বসাতে হবে।

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
