# নির্দেশনা

মেরি টিভি সিরিজ _Star Trek: The Next Generation_-এর একজন বড় ভক্ত।
তিনি প্রায়ই কলম-কাগজে খেলা রোল-প্লেয়িং গেম খেলেন, যেখানে তিনি আর তাঁর বন্ধুরা _স্টারশিপ এন্টারপ্রাইজ_-এর ক্রু সেজে থাকে।
মেরির চরিত্রটি ক্যাপ্টেন পিকার্ড, অর্থাৎ তাঁকে ক্যাপ্টেনের লগটি রাখতে হয়।
গেমটির সৃজনশীল অংশটি তিনি দারুণ ভালোবাসেন, কিন্তু সঙ্গে সঙ্গে র‍্যান্ডম ডেটা বানানো তাঁর পছন্দ নয়।

ক্যাপ্টেনের লগে কমন যে ডেটাগুলো আসে, সেগুলোর জন্য র‍্যান্ডম জেনারেটর তৈরি করে মেরিকে সাহায্য করুন।

~~~~exercism/note
এই অনুশীলনীর স্টার্টার ইমপ্লিমেন্টেশন কনস্ট্রাক্টর আর্গুমেন্ট হিসেবে একটি `java.util.Random` ইনস্ট্যান্স নেয়।
এর ফলে অনুশীলনীর testগুলো আগে থেকে নির্ধারিত সিডসহ একটি ইনস্ট্যান্স পাঠাতে পারে, যার ফলে test-এর ফলাফল পূর্বানুমেয় হয়ে যায়।

তাই আপনার ইমপ্লিমেন্টেশনে প্রদত্ত `java.util.Random` ইনস্ট্যান্সটি ব্যবহার করা প্রত্যাশিত।
~~~~

## 1. একটি র‍্যান্ডম গ্রহ তৈরি করুন

ভ্রমণের পথে _স্টারশিপ এন্টারপ্রাইজ_ অনেক গ্রহের মুখোমুখি হয়।
Star Trek মহাবিশ্বের গ্রহগুলোকে তাদের বৈশিষ্ট্যের ভিত্তিতে ক্যাটাগরিতে ভাগ করা হয়েছে।
যেমন পৃথিবী একটি `M` ক্লাসের গ্রহ।
সম্ভাব্য সব গ্রহ-ক্লাস হলো: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` আর `Y`।

`randomPlanetClass()` মেথডটি ইমপ্লিমেন্ট করুন।
এটি র‍্যান্ডমভাবে গ্রহ-ক্লাসগুলোর যেকোনো একটি রিটার্ন করবে।

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. একটি র‍্যান্ডম স্টারশিপ রেজিস্ট্রি নম্বর তৈরি করুন

এন্টারপ্রাইজ (রেজিস্ট্রি নম্বর `NCC-1701`) একমাত্র স্টারশিপ নয় যা মহাকাশে ঘুরে বেড়ায়!
অন্য কোনো স্টারশিপের সঙ্গে এর সাক্ষাৎ হলে মেরিকে সেই স্টারশিপের রেজিস্ট্রি নম্বরটি লগ করতে হয়।

রেজিস্ট্রি নম্বরগুলো "NCC-" প্রিফিক্স দিয়ে শুরু হয়, এরপর `1000` থেকে `9999` পর্যন্ত (সহ) একটি সংখ্যা থাকে।

`randomShipRegistryNumber()` মেথডটি ইমপ্লিমেন্ট করুন, যা একটি র‍্যান্ডম স্টারশিপ রেজিস্ট্রি নম্বর রিটার্ন করে।

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. একটি র‍্যান্ডম স্টারডেট তৈরি করুন

তারিখ না থাকলে লগের আর কী কাজ?

স্টারডেট হলো একটি ফ্লোটিং পয়েন্ট সংখ্যা।
_The Next Generation_-এর প্রথম সিজনের _স্টারশিপ এন্টারপ্রাইজ_-এর অভিযানগুলো `41000.0` থেকে `42000.0` স্টারডেটের মধ্যে ঘটে।
এখানে "4" বলতে ২৪তম শতাব্দী বোঝায়, আর "1" বলতে প্রথম সিজন।

`randomStardate()` মেথডটি ইমপ্লিমেন্ট করুন, যা `41000.0` (সহ) থেকে `42000.0` (ব্যতীত) পর্যন্ত একটি ফ্লোটিং পয়েন্ট সংখ্যা রিটার্ন করে।

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
