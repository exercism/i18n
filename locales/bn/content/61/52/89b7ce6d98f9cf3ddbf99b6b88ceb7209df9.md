# পরিচিতি

## অ্যাট্রিবিউট

একটি [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) কোনো ডিক্লারেশন সাজিয়ে তার সঙ্গে মেটাডেটা যুক্ত করার একটি উপায় দেয়: একটি ক্লাস, একটি মেথড, একটি enum, একটি ফিল্ড, একটি প্রপার্টি কিংবা অন্য যেকোনো [সমর্থিত](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) ডিক্লারেশন।

`ClassAttribute` এবং `FieldAttribute` ব্যবহার করে ডিক্লারেশনের ঠিক আগের লাইনে অ্যাট্রিবিউট যোগ করে আপনি একটি অ্যাট্রিবিউট প্রয়োগ করতে পারেন:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

এই ডিক্লারেটিভ মেটাডেটা শুধু কোডের সঙ্গে বাড়তি কিছু কাঠামোবদ্ধ তথ্য যুক্ত করে, কোডের আচরণ বদলায় না। তবে কোডের অন্য অংশ এই মেটাডেটা ব্যবহার করে টার্গেটের আচরণ বদলায়, কিংবা তার কিছু কার্যকারিতা যোগ করে, বদলে দেয়, সরিয়ে দেয় বা সীমিত করে।

অনেক [পূর্বনির্ধারিত ও সংরক্ষিত অ্যাট্রিবিউট](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute) রয়েছে, যেমন: `Flags`, `Obsolete`, `Conditional` এবং `Experimental`. প্রতিটির নিজস্ব নির্দিষ্ট অর্থ আছে, যা C# ডকুমেন্টেশনে দেখে নেওয়া যায়। মনে রাখবেন, [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)-এর মতো একটি অ্যাট্রিবিউটের পুরো নাম `<Name>Attribute` রূপ নেয় (যেমন `FlagsAttribute`)।

## ফ্ল্যাগ enum

C#-এর [`enum` টাইপ](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) নামযুক্ত কনস্ট্যান্টের একটি নির্দিষ্ট সেট বোঝায় (একটি এনামারেশন)।

সাধারণত একটি `enum` সদস্য ওই নামযুক্ত কনস্ট্যান্টগুলোর মধ্যে ঠিক একটিকেই নির্দেশ করতে পারে। তবে মাঝে মাঝে একাধিক কনস্ট্যান্ট নির্দেশ করা কাজে লাগে। সেজন্য [`Flags` অ্যাট্রিবিউট](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) দিয়ে `enum` অ্যানোটেট করা যায়।

একটি ফ্ল্যাগ enum এভাবে ডিফাইন করা যায় (বাইনারি ইন্টিজার নোটেশন `0b` ব্যবহার করে):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

যে `PhoneFeatures` ইনস্ট্যান্সের মান `0b00000011`, তার `Call` _এবং_ `Text` দুটি ফ্ল্যাগই সেট করা থাকে।

ডিফল্টভাবে enum সদস্যের মানের জন্য `int` টাইপ ব্যবহার করা হয়। enum ডিক্লারেশনে টাইপ উল্লেখ করে ভিন্ন একটি ইন্টিজার টাইপ ব্যবহার করা যায়:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
