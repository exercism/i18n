# নির্দেশনা

নৃত্যদলটি তাদের বছরশেষের অনুষ্ঠানের হিসাব করছে: নৃত্যশিল্পীদের কতভাবে সাজানো যায়, আর প্রদর্শনের সময় বিভিন্ন পর্বের মধ্যে কীভাবে ভাগ হয়।

পাঁচটি কাজই `FORMATION_COUNT` ক্লাসে থাকবে।

## 1. কত রকমের সারিবদ্ধতা?

`n` জন নৃত্যশিল্পী থাকলে তাদের সারিবদ্ধ করার `n` ফ্যাক্টোরিয়াল সংখ্যক উপায় থাকে: সামনের জনের জন্য `n`টি পছন্দ, তারপর পরের জনের জন্য `n-1`টি, এভাবে চলতে থাকে। এটিকে একটি `INTI` হিসেবে রিটার্ন করুন। শূন্য জন নৃত্যশিল্পীর ক্ষেত্রে সারিবদ্ধতা ঠিক একটিই, আর সেটি খালি।

```sather
FORMATION_COUNT::line_ups(5)
-- => 120
FORMATION_COUNT::line_ups(20)
-- => 2432902008176640000
```

## 2. সংখ্যাটি লিখে দিন

একই সংখ্যাটি স্ট্রিং হিসেবে, তার প্রতিটি অঙ্ক সহ।

```sather
FORMATION_COUNT::line_ups_text(25)
-- => "15511210043330985984000000"
```

একটি `INT` ওই সংখ্যাটি ধারণ করতে পারে না, আর এটাই এই কাজের মূল লক্ষ্য।

## 3. একটি পর্বের ভাগ

`acts` সংখ্যক সমান পর্বের একটি অনুষ্ঠানে প্রতিটি পর্বের জন্য প্রদর্শনের সময়ের `1/acts` অংশ থাকে। এটিকে একটি `RAT` হিসেবে রিটার্ন করুন।

```sather
FORMATION_COUNT::share(3)
-- => 1/3
```

## 4. দুটি পর্ব একসঙ্গে

দুটি ভাগ যোগ করুন এবং মোট ফলটি নিখুঁতভাবে রিটার্ন করুন।

```sather
FORMATION_COUNT::combined(FORMATION_COUNT::share(2), FORMATION_COUNT::share(3))
-- => 5/6
```

## 5. এতে কি পুরো অনুষ্ঠান ভরে যায়?

একটি ভাগ ঠিক পুরো অনুষ্ঠানের সমান কি না, অর্থাৎ ঠিক এক কি না, সেই উত্তর দিন।

```sather
FORMATION_COUNT::covers_whole_show(#RAT(3, 3))
-- => true
FORMATION_COUNT::covers_whole_show(#RAT(2, 3))
-- => false
```
