# ইনস্টলেশন

Ceylon ইনস্টল করার সবচেয়ে সহজ উপায় হলো একেবারেই **ইনস্টল না** করা।
আমাদের [ওয়েব IDE](http://try.ceylon-lang.org/) ব্যবহার করে আপনি বেশিরভাগ অনুশীলনী সমাধান করতে পারবেন।

তবে চাইলে আপনি কমান্ড লাইন ডিস্ট্রিবিউশনও ইনস্টল করতে পারেন; এর সবচেয়ে সহজ উপায় [SDKMAN](http://sdkman.io/)।
তাই এটি এখনো ইনস্টল করা না থাকলে প্রথমে সেটাই ইনস্টল করুন, তারপর টার্মিনালে শুধু `sdk install ceylon` লিখুন।

OSX ব্যবহারকারীরা [Homebrew প্যাকেজ ম্যানেজার](http://mxcl.github.com/homebrew/) দিয়েও ইনস্টল করতে পারেন।

অন্য প্ল্যাটফর্মের জন্য, এবং Eclipse-এর একটি প্লাগইন Ceylon IDE-এর জন্য ইনস্টলেশন নির্দেশনা [অফিসিয়াল সাইটে](http://ceylon-lang.org/download/) পাওয়া যাবে।
