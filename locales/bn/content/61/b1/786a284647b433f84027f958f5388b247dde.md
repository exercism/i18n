# পরিচিতি

একটি _enum টাইপ_ হলো একটি বিশেষ ডেটা টাইপ, যা দিয়ে একটি ভ্যারিয়েবলকে আগে থেকে নির্ধারিত কিছু কনস্ট্যান্টের সেট বানানো যায়।
ভ্যারিয়েবলটিকে তার জন্য আগে থেকে নির্ধারিত করা মানগুলোর একটির সমান হতে হবে।
কমন উদাহরণের মধ্যে আছে কম্পাসের দিক (`NORTH`, `SOUTH`, `EAST` আর `WEST` মানগুলো) এবং সপ্তাহের বার।

যেহেতু এগুলো কনস্ট্যান্ট, তাই একটি enum টাইপের ফিল্ডগুলোর নাম বড় হাতের অক্ষরে লেখা হয়।

## একটি enum টাইপ ডিফাইন করা

Java প্রোগ্রামিং ভাষায় আপনি `enum` কিওয়ার্ড ব্যবহার করে একটি enum টাইপ ডিফাইন করেন।
উদাহরণস্বরূপ, সপ্তাহের বারের একটি enum টাইপ আপনি এভাবে লিখবেন:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

যখনই নির্দিষ্ট একটি কনস্ট্যান্ট-সেট প্রকাশ করতে হয়, তখনই আপনার enum টাইপ ব্যবহার করা উচিত।
এর মধ্যে পড়ে সৌরজগতের গ্রহগুলোর মতো স্বাভাবিক enum টাইপ, আর এমন ডেটা সেট যেখানে কম্পাইল টাইমেই সম্ভাব্য সব মান জানা থাকে, যেমন মেনুর অপশন, কমান্ড লাইন ফ্ল্যাগ ইত্যাদি।

## একটি enum টাইপ ব্যবহার করা

উপরে ডিফাইন করা `DayOfWeek` enum কীভাবে ব্যবহার করবেন, নিচের কোডটি তা দেখাচ্ছে:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## মেথড ও ফিল্ড যোগ করা

Java প্রোগ্রামিং ভাষার enum টাইপ অন্য ভাষার সমতুল্য জিনিসগুলোর চেয়ে অনেক বেশি শক্তিশালী।
`enum` ডিক্লেয়ারেশন একটি _ক্লাস_ ডিফাইন করে (যাকে _enum টাইপ_ বলা হয়)।
enum ক্লাসের বডিতে মেথড ও অন্যান্য ফিল্ড থাকতে পারে:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating` enum টাইপের একটি সদস্যের উপর `getNumberOfStars` মেথড কল করা:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
