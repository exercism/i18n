# নির্দেশাবলি

এই অনুশীলনীতে প্রোগ্রামিং ভাষার একটি অ্যারে নিয়ে কাজ করার জন্য আপনাকে কিছু ফাংশন ইমপ্লিমেন্ট করতে হবে।

## 1. খালি ভাষার অ্যারে রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`language_list` ফাংশনটি ডিফাইন করুন, যেটি কোনো আর্গুমেন্ট নেয় না এবং একটি খালি অ্যারে রিটার্ন করে।

```php
<?php

language_list();
// => []
```

## 2. যেকোনো সংখ্যক ভাষা থেকে একটি অ্যারে তৈরি করার জন্য ফাংশনটি পরিবর্তন করুন

`language_list` ফাংশনটি এমনভাবে পরিবর্তন করুন, যাতে এটি ভাষার (স্ট্রিং) একটি ভ্যারিয়াডিক আর্গুমেন্ট নেয়। এটি ভাষাগুলো নিয়ে গঠিত অ্যারেটি রিটার্ন করবে।

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. অ্যারেতে একটি ভাষা যোগ করার জন্য একটি ফাংশন ডিফাইন করুন

`add_to_language_list` ফাংশনটি ডিফাইন করুন, যেটি ২টি আর্গুমেন্ট নেয়: ভাষার একটি অ্যারে এবং নতুন ভাষাটি।

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. ভাষার অ্যারে থেকে একটি এলিমেন্ট সরানোর জন্য একটি ফাংশন ডিফাইন করুন

`prune_language_list` ফাংশনটি ডিফাইন করুন, যেটি ভাষার অ্যারে থেকে প্রথম ভাষাটি সরিয়ে দেয়।

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. অ্যারের প্রথম এলিমেন্ট পাওয়ার জন্য একটি ফাংশন ডিফাইন করুন

`current_language` ফাংশনটি ডিফাইন করুন, যেটি ১টি আর্গুমেন্ট (একটি _ভাষার অ্যারে_) নেয়। এটি অ্যারের প্রথম ভাষাটি রিটার্ন করবে। ধরে নিন অ্যারেতে সবসময় অন্তত একটি এলিমেন্ট থাকবে।

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. অ্যারে কতটি ভাষা আছে তা রিটার্ন করার জন্য একটি ফাংশন ডিফাইন করুন

`language_list_length` ফাংশনটি ডিফাইন করুন, যেটি ১টি আর্গুমেন্ট (একটি _ভাষার অ্যারে_) নেয়। এটি অ্যারেতে থাকা ভাষার সংখ্যা রিটার্ন করবে।

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
