# নির্দেশাবলির সংযোজন

## নিজের DSL তৈরি করুন

এই অনুশীলনীতে আপনি সম্পূর্ণ স্বাধীনভাবে আপনার স্বপ্নের গ্রাফ DSL ডিজাইন করতে পারেন।

হয়তো আপনি ট্যাগ ও রেকর্ডের তালিকার উপর ভিত্তি করে একটি DSL বানাতে চাইবেন, এই রকম:

```roc
my_graph =
    Graph.create([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

অথবা হয়তো আপনি ফাংশন কলে-র শিকলের উপর ভিত্তি করে একটি DSL বেশি পছন্দ করবেন, এই রকম:

```roc
my_graph =
    Graph.create()
        .with_title("My Graph")
        .add_node("a", Attr.create().with_color(Green))
        ...
```

আর নাও হতে পারে আপনার পরিকল্পনা একেবারেই ভিন্ন? তাহলে শুরু করে দিন! টেস্টগুলো শুধু কয়েকটি নির্দিষ্ট গ্রাফ তৈরি করতে বলে, সেগুলো আপনি কীভাবে বানাবেন তা সম্পূর্ণ আপনার নিজের ব্যাপার।

তবে হ্যাঁ, একটি DSL সাধারণত তখনই ভালো হয় যখন তা স্পষ্ট, সংক্ষিপ্ত এবং খুব একটা অবাক করে না (যেমন, `minus` ফাংশনটি বিয়োগ করার জন্য, দুটি নোডের মাঝে এজ বানানোর জন্য নয়, যেমনটা `node("a") - node("b")` এ হয়)।

মজা আরও বাড়াতে চাইলে আপনি ঐচ্ছিকভাবে একটি `to_dot` ফাংশন ইমপ্লিমেন্ট করার চেষ্টা করতে পারেন, যা আপনার গ্রাফকে DOT ফরম্যাটে রূপান্তর করে!
