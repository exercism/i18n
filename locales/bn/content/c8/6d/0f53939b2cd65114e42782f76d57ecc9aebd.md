# নির্দেশনা

জোশ একটি নতুন রোল-প্লেয়িং গেম নিয়ে কাজ করছেন এবং এর কয়েকটি মেকানিক্স তৈরি করতে আপনার সাহায্যের প্রয়োজন।

## 1. টাইপ ইউনিয়ন ডিফাইন করুন

`String` এবং `Missing` নিয়ে একটি টাইপ ইউনিয়ন ডিফাইন করুন, যার নাম `StringOrMissing` এবং যা পরে কোডে ব্যবহার করা যাবে।
`Int64` এবং `Nothing` নিয়ে একটি টাইপ ইউনিয়ন ডিফাইন করুন, যার নাম `IntOrNothing` এবং যা পরে কোডে ব্যবহার করা যাবে।

## 2. Player কম্পোজিট টাইপ ইমপ্লিমেন্ট করুন

Player কম্পোজিট টাইপে চারটি ফিল্ড থাকা উচিত, যার প্রতিটির একটি টাইপ অ্যানোটেশন ও একটি ডিফল্ট মান থাকবে:
- `name` হলো একটি `StringOrMissing`, যার ডিফল্ট মান `missing`
- `level` হলো একটি `Int64`, যার ডিফল্ট মান `0`
- `health` হলো একটি `Int64`, যার ডিফল্ট মান `100`
- `mana` হলো একটি `IntOrNothing`, যার ডিফল্ট মান `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. নিজের পরিচয় দিন

`introduce` ফাংশনটি ইমপ্লিমেন্ট করুন।

যে খেলোয়াড়েরা লুকিয়ে থাকে তারা নিজেদের নাম গোপন রাখতে পারেন, এবং তাদের পরিচয় দেওয়া হবে `"Mighty Magician"` হিসেবে।
অন্যথায়, খেলোয়াড়ের নাম দিয়েই তার পরিচয় দিন।

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. increment মেথডগুলো ইমপ্লিমেন্ট করুন

`increment` হেল্পার ফাংশনটির দুটি মেথড আছে, যার প্রতিটির ফাংশন সিগনেচার আলাদা।
সিগনেচার স্পষ্ট করতে প্রতিটির আর্গুমেন্টে একটি টাইপ অ্যানোটেশন দরকার।

নামের জন্য `increment` মেথডটি খেলোয়াড়ের `name` নেবে।
- যদি নাম `missing` হয়, তবে "The Great" টাইটেলটি রিটার্ন করুন।
- অন্যথায় নামের সঙ্গে " the Great" টাইটেলটি যোগ করা হয়।

এই `increment` মেথডটি নতুন নামটি রিটার্ন করে।

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

ম্যানার জন্য `increment` মেথডটি খেলোয়াড়ের `mana` নেবে।
- যদি খেলোয়াড়ের ম্যানা `missing` হয়, তবে `50` মানটি রিটার্ন করুন।
- অন্যথায় ম্যানা `100` বাড়ানো উচিত।

এই `increment` মেথডটি আপডেট হওয়া ম্যানা রিটার্ন করে।

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. title ফাংশনটি ইমপ্লিমেন্ট করুন

গেমের সর্বোচ্চ লেভেল হলো `42`। এই লেভেলে পৌঁছানো খেলোয়াড়দের কৃতিত্ব স্বীকৃতি দিতে তাদের নামের সঙ্গে একটি টাইটেল যুক্ত করা হয়। `title!` ফাংশনটি খেলোয়াড়ের নাম নিচের মতো আপডেট করে।

- যদি খেলোয়াড়ের লেভেল 42 হয়, তবে `increment` ফাংশন দিয়ে নামটি আপডেট করা হয়।
- অন্যথায় নামটি অপরিবর্তিত থাকে।

দুই ক্ষেত্রেই `title!` ফাংশনটি খেলোয়াড়ের নাম রিটার্ন করে।

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. revive ফাংশনটি ইমপ্লিমেন্ট করুন

`revive!` ফাংশনটির যাচাই করা উচিত যে খেলোয়াড়ের ক্যারেক্টারটি সত্যিই মৃত (তার হেলথ `0`-তে পৌঁছেছে)।

যদি খেলোয়াড়টি মৃত হয়:
- খেলোয়াড়কে `100` হেলথ নিয়ে আবার জীবিত করা উচিত।
- `increment` ফাংশন ব্যবহার করে খেলোয়াড়ের ম্যানা বাড়ানো উচিত।

যদি খেলোয়াড়টি জীবিত থাকে, তবে তার কিছুই হয় না।

`revive!` ফাংশনটির খেলোয়াড়কে রিটার্ন করা উচিত।

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
