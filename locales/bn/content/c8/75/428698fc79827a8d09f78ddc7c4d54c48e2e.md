# ভূমিকা

একটি ভেক্টর হলো এক-মাত্রিক অ্যারে।
এতে ভিন্ন ভিন্ন টাইপের এলিমেন্ট থাকতে পারে।

## ভেক্টর তৈরি করা

`vector` ফাংশন দিয়ে কিংবা এর রিডার ফর্ম `#()` ব্যবহার করে ভেক্টর তৈরি করা যায়।

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## এলিমেন্ট অ্যাক্সেস করা

ভেক্টরের এলিমেন্ট অ্যাক্সেস করতে `aref` ব্যবহার করুন। ইনডেক্সগুলো শূন্য থেকে শুরু হয়:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
