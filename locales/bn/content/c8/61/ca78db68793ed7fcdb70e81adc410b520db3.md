# পরিচিতি

F#-এ সংখ্যা নিয়ে কাজ করার সময় মূল দিকগুলোর একটি হলো ইন্টিজার (দশমিক বিন্দুর পরে কোনো ডিজিট নেই এমন সংখ্যা) এবং ফ্লোটিং-পয়েন্ট সংখ্যার (দশমিক বিন্দুর পরে শূন্য বা তার বেশি ডিজিট থাকে এমন সংখ্যা) মধ্যে পার্থক্য।

F#-এ সবচেয়ে বেশি ব্যবহৃত দুটি সংখ্যার টাইপ হলো `int` (একটি ৩২-বিট ইন্টিজার) এবং `float` (একটি ৬৪-বিট ফ্লোটিং-পয়েন্ট সংখ্যা)।

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

ইন্টিজার এবং ফ্লোটিং-পয়েন্ট সংখ্যা দুটোই `_` ক্যারেক্টারটিকে একটি _ডিজিট বিভাজক_ হিসেবে ব্যবহার করতে পারে, যা বড় সংখ্যা লেখার সময় কাজে আসে:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

পাটিগণিতের কাজ করা হয় স্ট্যান্ডার্ড [পাটিগণিত অপারেটর][arithmetic-operators] (`+`, `-`, `*` ইত্যাদি) দিয়ে। স্ট্যান্ডার্ড [তুলনা অপারেটর][comparison-operators] (`<`, `>=` ইত্যাদি) এবং সমানতা (`=`) ও অসমানতা (`<>`) অপারেটর দিয়ে সংখ্যা তুলনা করা যায়।

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

সংখ্যার টাইপগুলোর মধ্যে রূপান্তর করতে হলে বিল্ট-ইন [কনভার্সন অপারেটর][conversion-operators] ব্যবহার করতে হয়। এই অপারেটরগুলোর নাম রাখা হয় যে টাইপে রূপান্তর করা হবে সেটির নাম অনুসারে।

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

টাইপের মধ্যে রূপান্তর করার সময় সবসময় সতর্ক থাকুন। কোনো মান যদি টার্গেট টাইপে প্রকাশ করা সম্ভব না হয়, তাহলে মানটি _ওভারফ্লো_ হবে।
