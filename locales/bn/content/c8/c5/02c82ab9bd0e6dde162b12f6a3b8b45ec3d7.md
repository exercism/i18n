# If, Elseif, Else

`if`, `elseif` ও `else` দিয়ে গঠিত কন্ডিশনাল স্টেটমেন্ট প্রোগ্রামের কন্ট্রোল ফ্লোর একটি মৌলিক অংশ।
`if` স্টেটমেন্ট একটি এক্সপ্রেশন মূল্যায়ন করে, আর সেটি `true` হলে কোডের শাখাটি এক্সিকিউট করে।

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

এক্সপ্রেশনটি যদি কোনো বুলিয়ান মান না হয়, তাহলে মূল্যায়নটি মানটির "truthiness" বা "not falsiness" নির্ধারণ করে।
PHP-তে নিচের মানগুলো `false`-এর সমান বলে ধরা হয়:

- বুলিয়ান `false`
- ইন্টিজার `0`
- ফ্লোট `0.0` ও `-0.0`
- একটি খালি অ্যারে `[]`
- একটি খালি স্ট্রিং `""` বা একটি সাংখ্যিক স্ট্রিং `"0"`
- `null`

বাকি সব মান সত্য বলে ধরা হয়।

## একাধিক শর্তে সাড়া দেওয়া

একটি `if` স্টেটমেন্টের পরে `elseif` ও `else` ব্যবহার করে আপনি একাধিক শর্ত জুড়ে দিতে পারেন।

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

সত্য হিসেবে মূল্যায়িত হওয়া কেবল একটি কন্ডিশনাল স্টেটমেন্টই এক্সিকিউট হবে।
তাই একাধিক শর্ত সত্য হতে পারলে সেগুলো যে ক্রমে লেখা হয়েছে সেটি গুরুত্বপূর্ণ।

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
