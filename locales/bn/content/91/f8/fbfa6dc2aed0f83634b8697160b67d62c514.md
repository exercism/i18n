# পরিচিতি

ফ্লোটিং-পয়েন্ট নাম্বার হলো ভগ্নাংশ বা পূর্ণ সংখ্যা, যার মধ্যে একটি দশমিক বিন্দু থাকে (যেমন `3.14`, `-1.7`, `99.99`, `2048.0`)।

Common Lisp-এ ফ্লোট টাইপকে কয়েকটি সাবটাইপে ভাগ করা হয়েছে, যার প্রত্যেকটির নিজস্ব বৈশিষ্ট্য ও প্রিসিশন রয়েছে: short-float, single-float, double-float আর long-float।

short-float সাবটাইপ সাধারণত সবচেয়ে কম মেমোরি নেয় এবং চারটি সাবটাইপের মধ্যে সবচেয়ে কম প্রিসিশন দেয়। যেখানে মেমোরির ব্যবহার নিয়ে চিন্তা আছে কিন্তু কম প্রিসিশন চলতে পারে, এমন পরিস্থিতির জন্য এটি উপযুক্ত।

single-float সাবটাইপ মেমোরির ব্যবহার ও প্রিসিশনের মধ্যে ভারসাম্য বজায় রাখে। সাধারণ উদ্দেশ্যের ফ্লোটিং-পয়েন্ট হিসাবের জন্য এটি বহুল ব্যবহৃত হয়।

double-float সাবটাইপ single-float-এর তুলনায় বেশি প্রিসিশন দেয় এবং আরও নিখুঁত হিসাব দরকার হয় এমন অ্যাপ্লিকেশনের জন্য উপযুক্ত, যেমন বৈজ্ঞানিক গণনা ও সংখ্যাগত সিমুলেশন।

long-float সাবটাইপ চারটি সাবটাইপের মধ্যে সবচেয়ে বেশি প্রিসিশন দেয়, তবে অন্যগুলোর তুলনায় বেশি মেমোরি লাগতে পারে। অত্যন্ত নিখুঁত হিসাব দরকার হয় এমন বিশেষায়িত অ্যাপ্লিকেশনের জন্য সাধারণত এটি ব্যবহৃত হয়।

এই সাবটাইপগুলো Common Lisp প্রোগ্রামারদের সুবিধা দেয়, যাতে তারা নিজেদের নির্দিষ্ট অ্যাপ্লিকেশনের চাহিদা অনুযায়ী উপযুক্ত প্রিসিশন ও মেমোরি ব্যবহার বেছে নিতে পারেন।

সাধারণভাবে, আপনি যদি শুধু পূর্ণ সংখ্যা নিয়ে কাজ করেন, তাহলে ইন্টিজার ব্যবহার করাই ভালো, কারণ বহু হিসাবের পর ফ্লোটিং-পয়েন্ট নাম্বারের মতো প্রিসিশন হারানোর সমস্যা ইন্টিজারে হয় না।

## রেফারেন্স

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
