# নির্দেশাবলি

এলিস, হবু জাদুকর, তার প্রশিক্ষণ চালিয়ে যাচ্ছেন।
তার ট্রিক দেখানোর জন্য তাকে কার্ডের কয়েকটি ডেক দেওয়া হবে।
কাজটা একটু সহজ করতে তিনি শুধু ১ থেকে ১০ পর্যন্ত কার্ড ব্যবহার করেন।
প্রতিটি কার্ডের একটি করেই আছে তার কাছে, কার্ডের ডেকে কোনো ডুপ্লিকেট নেই।

এই অনুশীলনীতে একটি অ্যারের ভেতরের জিনিস বিশ্লেষণ করতে Julia-এর Base লাইব্রেরির মেথডগুলো ব্যবহার করুন।

## 1. একটি কার্ড ডেকে আছে কি না তা নির্ণয় করুন

এলিস জানতে চান ডেকে একটি নির্দিষ্ট কার্ড আছে কি না, অর্থাৎ ডেকে একটি নির্দিষ্ট সংখ্যা আছে কি না।

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. একটি কার্ডের অবস্থান খুঁজে বের করুন

এলিস ডেকে একটি কার্ডের অবস্থান (ইনডেক্স) জানতে চান।
ডেকে কার্ডটি না থাকলে `nothing` রিটার্ন করুন।

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. প্রতিটি কার্ড জোড় কি না তা নির্ণয় করুন

এলিস জানতে চান প্রতিটি কার্ড জোড় কি না, অর্থাৎ ডেকের প্রতিটি সংখ্যা জোড় কি না।

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. ডেকে কোনো বিজোড় মানের কার্ড আছে কি না যাচাই করুন

এলিস জানতে চান ডেকে কোনো বিজোড় সংখ্যা আছে কি না।

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. প্রথম জোড় কার্ডটির অবস্থান নির্ণয় করুন

এলিস প্রথম জোড় কার্ডটির অবস্থান জানতে চান।
ডেকে কোনো জোড় কার্ড না থাকলে `nothing` রিটার্ন করুন।

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. ডেক থেকে প্রথম বিজোড় কার্ডটি নিন

এলিস প্রথম বিজোড় কার্ডটির মান জানতে চান।
ডেকে কোনো বিজোড় কার্ড না থাকলে `nothing` রিটার্ন করুন।

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
