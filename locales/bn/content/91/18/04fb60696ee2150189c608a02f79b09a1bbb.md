# Instructions

আপনার কাজ হলো GPS কোঅর্ডিনেট পার্স করা।
প্রতিটি কোঅর্ডিনেট [ডেসিমেল ডিগ্রি ফরম্যাট](https://en.wikipedia.org/wiki/Decimal_degrees)-এর একটি ভ্যারিয়েন্টে লেখা হয়, যেখানে গোলার্ধগুলো স্পষ্টভাবে উল্লেখ থাকে:

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

প্রতিটি আলাদা কম্পোনেন্টের জন্য অনুমোদিত মানগুলো হলো:

- `<LATITUDE_DEGREES>`: 0..90 রেঞ্জের মধ্যে একটি ফ্লোটিং-পয়েন্ট সংখ্যা (উভয় প্রান্তসহ)
- `<LATITUDE_HEMISPHERE>`: `N` অথবা `S`
- `<LONGITUDE_DEGREES>`: 0..180 রেঞ্জের মধ্যে একটি ফ্লোটিং-পয়েন্ট সংখ্যা (উভয় প্রান্তসহ)
- `<LONGITUDE_HEMISPHERE>`: `E` অথবা `W`

উদাহরণস্বরূপ, `"48.8584 N, 2.2945 E"` পার্স করলে পাওয়া যায়:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

আপনার সামনে ১১টি টাস্ক আছে, যেখানে আপনি ধাপে ধাপে GPS কোঅর্ডিনেট পার্স করবেন।
আপনি ব্যবহার করবেন Prolog-এর [ডেফিনিট ক্লজ গ্রামার](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG) সাপোর্ট, যা স্ট্রাকচার্ড টেক্সট পার্স করার জন্য ডিজাইন করা হয়েছে।

````exercism/note
শুরু করার জন্য, স্টাব ফাইলে ইতিমধ্যেই [`dcg/basics` লাইব্রেরি](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) অন্তর্ভুক্ত করা আছে, এভাবে:

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. একটি কমা পার্স করুন

একটি কমা (`","`) পার্স করার জন্য `comma` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. একটি স্পেস পার্স করুন

একটি স্পেস (`" "`) পার্স করার জন্য `space` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. সব হোয়াইটস্পেস সাপোর্ট করুন (নিউলাইন ছাড়া)

নিউলাইন ছাড়া _সব_ হোয়াইটস্পেস পার্স করতে `space` রুলটি পরিবর্তন করুন:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. অক্ষাংশের গোলার্ধ পার্স করুন

অক্ষাংশের গোলার্ধ `"N"` অথবা `"S"` হতে পারে, যাকে `north` বা `south` অ্যাটমে পার্স করা উচিত।
অক্ষাংশের গোলার্ধ পার্স করার জন্য `latitude_hemisphere` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. দ্রাঘিমাংশের গোলার্ধ পার্স করুন

দ্রাঘিমাংশের গোলার্ধ `"E"` অথবা `"W"` হতে পারে, যাকে `east` বা `west` অ্যাটমে পার্স করা উচিত।
দ্রাঘিমাংশের গোলার্ধ পার্স করার জন্য `longitude_hemisphere` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. ডিগ্রি পার্স করুন

দ্রাঘিমাংশ বা অক্ষাংশের ডিগ্রিকে একটি ফ্লোটিং-পয়েন্ট সংখ্যা হিসেবে সংজ্ঞায়িত করা হয়।
ফ্লোটিং-পয়েন্ট সংখ্যা পার্স করার জন্য `degrees` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. অক্ষাংশের ডিগ্রি পার্স করুন

অক্ষাংশের ডিগ্রি শুধু ফ্লোটিং-পয়েন্ট সংখ্যা নয়, বরং 0..90 রেঞ্জের মধ্যে থাকা ফ্লোটিং-পয়েন্ট সংখ্যা (উভয় প্রান্তসহ)।
উপরের রেঞ্জ ব্যবহার করে অক্ষাংশের ডিগ্রি পার্স করার জন্য `latitude_degrees` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. দ্রাঘিমাংশের ডিগ্রি পার্স করুন

দ্রাঘিমাংশের ডিগ্রি শুধু ফ্লোটিং-পয়েন্ট সংখ্যা নয়, বরং 0..180 রেঞ্জের মধ্যে থাকা ফ্লোটিং-পয়েন্ট সংখ্যা (উভয় প্রান্তসহ)।
উপরের রেঞ্জ ব্যবহার করে দ্রাঘিমাংশের ডিগ্রি পার্স করার জন্য `longitude_degrees` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. অক্ষাংশ পার্স করুন

অক্ষাংশের দুটি অংশ থাকে: ডিগ্রি এবং গোলার্ধ, যেগুলো একটি স্পেস দিয়ে আলাদা করা থাকে।
একটি অক্ষাংশ পার্স করার জন্য `latitude` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. দ্রাঘিমাংশ পার্স করুন

অক্ষাংশের দুটি অংশ থাকে: ডিগ্রি এবং গোলার্ধ, যেগুলো একটি স্পেস দিয়ে আলাদা করা থাকে।
একটি অক্ষাংশ পার্স করার জন্য `latitude` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. কোঅর্ডিনেট পার্স করুন

কোঅর্ডিনেটের দুটি অংশ থাকে: অক্ষাংশ এবং দ্রাঘিমাংশ, যেগুলো একটি কমার পরে একটি স্পেস দিয়ে আলাদা করা থাকে।
অক্ষাংশ (ডিগ্রি ও গোলার্ধ) দুটোই পার্স করার জন্য `coordinate` রুলটি ইমপ্লিমেন্ট করুন:

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
