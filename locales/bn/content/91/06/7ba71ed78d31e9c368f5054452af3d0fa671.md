# নির্দেশনা

একদা এক খামখেয়ালি প্রোগ্রামার থাকতেন একটি অদ্ভুত বাড়িতে, যার জানালায় ছিল লোহার গ্রিল। একদিন তিনি একটি অনলাইন জব বোর্ড থেকে একটি পার্টি রোবট তৈরির কাজ নিলেন। রোবটটির কাজ ছিল মানুষকে স্বাগত জানানো এবং তাদের নিজ নিজ আসনে পৌঁছে দেওয়া। প্রথম সংস্করণটি ছিল খুবই টেকনিক্যাল, আর তাতে প্রোগ্রামারটির মানুষের সঙ্গে মেলামেশার অভাব স্পষ্ট ফুটে উঠেছিল। যার কিছুটা পরের সংস্করণেও ঢুকে পড়েছিল।

## 1. পার্টিতে নতুন অতিথিকে স্বাগত জানান

প্রদত্ত নামটি ব্যবহার করে একটি স্বাগত বার্তা রিটার্ন করার জন্য `Welcome` ফাংশনটি ইমপ্লিমেন্ট করুন:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. যার জন্মদিন আজ, তেমন নতুন অতিথিকে পার্টিতে স্বাগত জানান

ব্যক্তিটির প্রদত্ত নাম ও বয়স ব্যবহার করে একটি জন্মদিনের বার্তা রিটার্ন করার জন্য `HappyBirthday` ফাংশনটি ইমপ্লিমেন্ট করুন। দুর্ভাগ্যবশত প্রোগ্রামারটি একটু নিজের বড়াই করতে ভালোবাসেন, তাই প্রতিটি অতিথির জন্মদিন সম্পর্কে নিজের জ্ঞান রোবটকে দেখাতে হয়।

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. পথনির্দেশ দিন

পথনির্দেশ দেওয়ার জন্য `AssignTable` ফাংশনটি ইমপ্লিমেন্ট করুন। এটির ৫টি প্যারামিটার নেওয়া উচিত।

- যে নতুন অতিথিকে স্বাগত জানাতে হবে তার নাম (`string`)
- টেবিল নম্বর (`int`)
- পাশে বসার ব্যক্তির নাম (`string`)
- টেবিলটি কোথায় পাবেন তার দিক (`string`)
- টেবিলের দূরত্ব (`float64`)

ফলাফলের সঠিক ফরম্যাটটি নিচের উদাহরণে দেখা যাবে।

রোবট টেবিল নম্বরটি ৩ অঙ্কের ফরম্যাটে দেয়। সংখ্যাটি ৩ অঙ্কের কম হলে সেটি ৩ অঙ্কের হতে সামনে অতিরিক্ত শূন্য পায় (যেমন 3 থেকে 003 হয়)। রোবট টেবিলের দূরত্বও জানায়। ভাগ্যক্রমে তা মাত্র ১ অঙ্কের নির্ভুলতায় সীমাবদ্ধ।

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
