# পরিচিতি

একটি `SYMBOL:` কোনো মান *ধরে রাখে না*, এটি শুধুই একটি নাম। মানটি থাকে একটি নেমস্পেসে, আর নামটি দিয়ে সেই নেমস্পেসে ঢোকা যায়।

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

দুটি স্কোপ:

- **গ্লোবাল**: `set-global`, `get-global`, `change-global` দিয়ে লেখা ও পড়া হয়। মানগুলো প্রসেসটির পুরো জীবনকাল ধরে টিকে থাকে।
- **ডাইনামিক**: `set`, `get`, `change` দিয়ে লেখা ও পড়া হয়। বাইন্ডিংগুলো একটি `with-variable` ফর্ম চলার সময়টুকু টিকে থাকে, ফলে বাইরের কোড ভেতরের কোডের দেখা একটি মান "ইনজেক্ট" করতে পারে, মাঝখানের প্রতিটি সিগনেচার না বদলেই।

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` এবং `SYMBOLS:` ভোকাবুলারি লোড হওয়ার সময় সিম্বল ডিক্লেয়ার করে, ফলে সেগুলো ফাইল জুড়ে শেয়ারযোগ্য রেফারেন্স হয়ে ওঠে।
