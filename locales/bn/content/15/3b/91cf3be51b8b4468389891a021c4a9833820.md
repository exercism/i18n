# পরিচিতি

Python-এ তিন ধরনের বিল্ট-ইন সংখ্যা আছে: ইন্টিজার ([`int`][int]), ফ্লোটিং-পয়েন্ট ([`float`][float]), এবং কমপ্লেক্স ([`complex`][complex])।
স্ট্যান্ডার্ড লাইব্রেরি থেকে ইমপোর্ট করে ভগ্নাংশ ([`fractions.Fraction`][fractions]) এবং ডেসিমাল ([`decimal.Decimal`][decimals])-ও ব্যবহার করা যায়।

হেক্সাডেসিমাল ([_`hex()`_][hex]), অক্টাল ([_`oct()`_][oct]) এবং বাইনারি ([_`bin()`_][bin]) সংখ্যাসহ পূর্ণসংখ্যা, যেগুলো **দশমিক চিহ্ন ছাড়া** থাকে, সেগুলোও `ints` হিসেবে চিহ্নিত হয়:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

দশমিক বিন্দুযুক্ত সংখ্যা (ভগ্নাংশসহ বা ভগ্নাংশ ছাড়া) `floats` হিসেবে চিহ্নিত হয়:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## পাটিগণিত

Python এই বিভিন্ন ধরনের সংখ্যার মধ্যে পাটিগণিত পুরোপুরি সমর্থন করে, এবং বাইনারি পাটিগণিত অপারেটরগুলো (`+`, `-`, `*`, `/`, `//`, এবং `%`) ব্যবহার করলে ছোট পরিসরের সংখ্যাগুলোকে বড় পরিসরের সংখ্যাগুলোর সাথে মানানসই করতে রূপান্তর করে।

### যোগ ও বিয়োগ

যোগ ও বিয়োগ অপারেটর সাধারণ গণিতের মতোই কাজ করে।
যদি এক বা একাধিক অপারেন্ড `float` হয়, তবে বাকি `int`-গুলোও `float`-এ রূপান্তরিত হবে:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### গুণ

যোগ ও বিয়োগের মতোই, গুণও ছোট পরিসরের সংখ্যাগুলোকে বড় পরিসরের সংখ্যাগুলোর সাথে মানানসই করতে রূপান্তর করবে:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### ভাগ

ভাগ সর্বদা একটি `float` রিটার্ন করে, ফলাফল পূর্ণসংখ্যা হলেও:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### ফ্লোর ডিভিশন

যদি `int` ফলাফল দরকার হয়, তবে ফলাফল ছেঁটে ফেলতে ফ্লোর ডিভিশন ব্যবহার করতে পারেন।
ফ্লোর ডিভিশন `//` অপারেটর দিয়ে করা হয়:

```python
>>> 6//5
1

>>> 6//2
3
```

### মডুলো

মডুলো অপারেটর (`%`) দুটি অপারেন্ডের ভাগের ভাগশেষ রিটার্ন করে:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

5 % 3-কে অন্যভাবে দেখার উপায়:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## রাউন্ড

Python একটি বিল্ট-ইন ফাংশন [`round(number, <decimal_places>)`][round] দেয়, যার সাহায্যে একটি ফ্লোটিং-পয়েন্ট সংখ্যাকে নির্দিষ্ট সংখ্যক দশমিক স্থানে রাউন্ড করা যায়।
যদি দশমিক স্থানের সংখ্যা উল্লেখ না করা হয়, তবে সংখ্যাটি নিকটতম পূর্ণসংখ্যায় রাউন্ড হয় এবং একটি `int` রিটার্ন করে:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## প্রাধান্য ও বন্ধনী

Python-এ আপনি বন্ধনী দিয়ে এক্সপ্রেশন গোষ্ঠীবদ্ধ করতে পারেন।
অপারেশনের ডিফল্ট ক্রম অতিক্রম করতে চাইলে এটি কাজে লাগে।

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python অপারেটর প্রাধান্যের জন্য [PEMDAS][pemdas] নিয়ম অনুসরণ করে।
এর মানে `()`-এর ভেতরের হিসাবের প্রাধান্য সবচেয়ে বেশি, তারপর `**`, তারপর `*`, `/`, `//`, `%`, `+`, এবং `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## নির্ভুলতা ও উপস্থাপনা

Python-এ ইন্টিজারের [যেকোনো নির্ভুলতা][arbitrary-precision] থাকে, অর্থাৎ অঙ্কের সংখ্যা কেবল হোস্ট সিস্টেমের উপলব্ধ মেমোরি দিয়েই সীমিত।

ফ্লোটিং-পয়েন্ট সংখ্যা সাধারণত C-তে একটি `double` দিয়ে বাস্তবায়িত হয় (_১৫ দশমিক স্থানের নির্ভুলতা_), তবে হোস্ট সিস্টেম অনুযায়ী এর উপস্থাপনা ভিন্ন হয়।
কমপ্লেক্স সংখ্যার একটি `real` এবং একটি `imaginary` অংশ থাকে, যার দুটোই ফ্লোটিং-পয়েন্ট সংখ্যা দিয়ে উপস্থাপিত হয়।

প্রোগ্রামিং ভাষাগুলোতে ফ্লোটিং-পয়েন্ট পাটিগণিতের সমস্যা ও সীমাবদ্ধতা নিয়ে আরও বিস্তারিত আলোচনার জন্য দেখুন [0.30000000000000004.com][0.30000000000000004.com] এবং [The Python Tutorial][floating point math]।
