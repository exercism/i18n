# পরিচিতি

`fractions` মডিউলটি দিয়ে আমরা [`rational numbers`][rational] তৈরি করতে ও সেগুলো নিয়ে কাজ করতে পারি: এমন ভগ্নাংশ, যার লব একটি ইন্টিজার আর হরও একটি ইন্টিজার।
উদাহরণস্বরূপ, আসন্ন `float` মান `0.6666...` না রেখে আমরা `2/3` একটি নির্ভুল ভগ্নাংশ হিসেবে সংরক্ষণ করতে পারি।

`int`, `float` ও `complex` সংখ্যার বিপরীতে ভগ্নাংশের কোনো লিটারেল রূপ নেই।
তবে ফ্র্যাকশন কনস্ট্রাক্টরটি বেশ নমনীয়।

সবচেয়ে স্পষ্টতই, এটি আর্গুমেন্ট হিসেবে দুটি ইন্টিজার নিতে পারে।
সাধারণ গুণনীয়কগুলো স্বয়ংক্রিয়ভাবে বাদ যায়, ফলে ভগ্নাংশটি তার "সর্বনিম্ন রূপে" (_যে ক্ষুদ্রতম ইন্টিজারগুলো ভগ্নাংশটিকে নির্ভুলভাবে প্রকাশ করে_) রূপান্তরিত হয়:

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

ফ্র্যাকশন কনস্ট্রাক্টরটি একটি স্ট্রিং রূপও পার্স করতে পারে:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

ভগ্নাংশ `float` প্যারামিটার নিয়েও কাজ করতে পারে, তবে দশমিক মানটিকে ভেতরে বাইনারি হিসেবে প্রকাশ করার আসন্ন প্রকৃতির কারণে এতে সমস্যা দেখা দিতে পারে।
এই উপস্থাপন সমস্যাটি নিয়ে আরও জানতে দেখুন [0.30000000000000004][0.30000000000000004] ওয়েবসাইটটি, এবং Python ডকুমেন্টেশনের [Floating Point Arithmetic: Issues and Limitations ][fp-issues]।

ফ্র্যাকশনের সাথে ফ্লোট ব্যবহার করার সময় আরও নির্ভরযোগ্য ফলাফল পেতে আছে `<fraction>.limit_denominator()` মেথডটি।


## ভগ্নাংশ নিয়ে পাটিগণিত

অন্য সংখ্যাসূচক টাইপের মতোই [`arithmetic operators`][operators] `+ - * / **` ভগ্নাংশের সাথেও কাজ করবে।

ইন্টিজার ও অন্য `Fraction` মানগুলোও সমীকরণে থাকতে পারে, আর ফলাফল আসে একটি `Fraction` হিসেবে।
এক্সপ্রেশনে একটি `float` থাকলে আউটপুটও `float` হয়, ফলে নির্ভুলতা (সম্ভবত) কমে যেতে পারে:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Python-এর বিভিন্ন স্ট্যান্ডার্ড সংখ্যাসূচক ফাংশনও `int` ও `float` টাইপ নিয়ে কাজ করার সময় আপনি যে ফলাফল আশা করবেন, তা-ই দেয়:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
