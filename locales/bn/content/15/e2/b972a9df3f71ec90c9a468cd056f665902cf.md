# অ্যারে মেথড

অ্যারে হলো একটি কমন ডেটা স্ট্রাকচার, যার সাথে কাজ করা হয়। এজন্য অ্যারে নিয়ে কাজ করার জন্য অনেকগুলো মেথডের একটি সংগ্রহ রয়েছে। যার মধ্যে আছে সর্টিং, রিভার্সিং, ইনসার্টিং এবং আরও অনেক কিছু।

এর মধ্যে কিছু মেথড ডেস্ট্রাকটিভ, অর্থাৎ এগুলো মূল অ্যারেটি পরিবর্তন করে। আবার কিছু মেথড নন-ডেস্ট্রাকটিভ, অর্থাৎ এগুলো একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি পরিবর্তন করে না।

অ্যারে নিয়ে কাজ করার সময় সবচেয়ে কমন কিছু মেথড এখানে দেওয়া হলো:

## insert

কোনো অ্যারেতে একটি এলিমেন্ট ইনসার্ট করতে চাইলে আপনি [`insert`][insert] মেথডটি ব্যবহার করতে পারেন, যা আর্গুমেন্ট হিসেবে একটি ইনডেক্স এবং একটি এলিমেন্ট নেয়। নির্দিষ্ট ইনডেক্সে এলিমেন্টটি ইনসার্ট করা হবে, এবং অ্যারের বাকি অংশ ডানদিকে সরিয়ে দেওয়া হবে। ইনডেক্সটি সীমার বাইরে হলে একটি `IndexError` রেইজ হবে।

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

কোনো অ্যারে থেকে একটি নির্দিষ্ট এলিমেন্ট ডিলিট করতে চাইলে আপনি [`delete`][delete] মেথডটি ব্যবহার করতে পারেন, যা আর্গুমেন্ট হিসেবে একটি এলিমেন্ট নেয়। মেথডটি যে এলিমেন্টটি সরিয়ে ফেলা হয়েছে সেটি রিটার্ন করে। এলিমেন্টটি অ্যারেতে না থাকলে `nil` রিটার্ন হবে।

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

কোনো অ্যারের প্রথম বা শেষ এলিমেন্ট পেতে চাইলে আপনি [`first`][first] এবং [`last`][last] মেথড ব্যবহার করতে পারেন। এই মেথডগুলো একটি ঐচ্ছিক আর্গুমেন্ট নেয়, যা কতগুলো এলিমেন্ট রিটার্ন করবে তা নির্দিষ্ট করে। ইনডেক্স `0` বা `-1` ব্যবহার করা বা একটি রেঞ্জ ব্যবহার করার তুলনায় এগুলো পড়ার সহজতা বাড়াতে পারে। অ্যারেটি খালি হলে একটি `Enumerable::EmptyError` রেইজ হবে।

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

কোনো অ্যারে রিভার্স করতে চাইলে আপনি [`reverse`][reverse] মেথডটি ব্যবহার করতে পারেন, যা উল্টো ক্রমে এলিমেন্টসহ একটি নতুন অ্যারে রিটার্ন করে। লক্ষ্য রাখা জরুরি যে `reverse` একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি পরিবর্তন করে না। যদি আপনি মূল অ্যারেটি পরিবর্তন করতে চান, তাহলে মেথডের নামের শেষে একটি `!` যোগ করুন।

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

নিচের মেথডগুলো তখন কাজে আসে, যখন অ্যারেকে এক-মাত্রিক করা, `nil` এলিমেন্ট সরানো, ডুপ্লিকেট সরানো, কিংবা অ্যারের অ্যারে ট্রান্সপোজ করার মতো কাজ করতে হয়। `reverse`-এর মতো এগুলোও একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি পরিবর্তন করে না।

| Method | Description | example |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | এই অ্যারের একটি পুনরাবৃত্তিমূলক (recursive) এক-মাত্রিক রূপ দিয়ে নতুন একটি অ্যারে রিটার্ন করে। অর্থাৎ, অ্যারের প্রতিটি এলিমেন্টের ক্ষেত্রে তার ভেতরের এলিমেন্টগুলো বের করে নতুন অ্যারেতে আনে। | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | সব nil এলিমেন্ট বাদ দিয়ে self-এর একটি কপি রিটার্ন করে। | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | ধরে নেয় যে self একটি অ্যারের অ্যারে এবং সারি ও কলাম [ট্রান্সপোজ][transpose] করে। | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | self-এর ডুপ্লিকেট মানগুলো সরিয়ে একটি নতুন অ্যারে রিটার্ন করে। | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

অ্যারেতে অবজেক্ট যোগ করতে চাইলে অ্যাপেন্ড মেথড (`<<`) কাজে আসে। তবে দুটি অ্যারে একসাথে করতে চাইলে আপনি [`+`][concat] অপারেটরটি ব্যবহার করতে পারেন, যা দুটি অ্যারের এলিমেন্ট নিয়ে একটি নতুন অ্যারে রিটার্ন করে।

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

কোনো অ্যারেতে যদি আপনি আরেকটি অ্যারে অ্যাপেন্ড করেন, তাহলে অ্যারেটি একটি একক এলিমেন্ট হিসেবে যোগ হবে।

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

কোনো অ্যারে খালি কি না তা পরীক্ষা করতে আপনি [`empty?`][empty?] মেথডটি ব্যবহার করতে পারেন, যা অ্যারে খালি হলে `true` এবং অন্যথায় `false` রিটার্ন করে। অ্যারের দৈর্ঘ্য `0`-এর সাথে মিলিয়ে দেখার তুলনায় এটি পড়ার সহজতা বাড়ায়।

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

কোনো অ্যারেতে একটি এলিমেন্টের ইনডেক্স পেতে চাইলে আপনি [`index`][index] মেথডটি ব্যবহার করতে পারেন, যা আর্গুমেন্ট হিসেবে একটি এলিমেন্ট নেয়। এলিমেন্টটি অ্যারেতে না থাকলে `nil` রিটার্ন হবে।

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

কোনো অ্যারেতে কতগুলো এলিমেন্ট আছে তা জানতে চাইলে আপনি [`size`][size] মেথডটি ব্যবহার করতে পারেন।

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

কোনো এলিমেন্ট একটি অ্যারেতে কতবার আছে তা গণনা করতে চাইলে আপনি [`count`][count] মেথডটি ব্যবহার করতে পারেন।

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

কোনো অ্যারে সর্ট করতে চাইলে আপনি [`sort`][sort] মেথডটি ব্যবহার করতে পারেন, যা সাজানো এলিমেন্টসহ একটি নতুন অ্যারে রিটার্ন করে। `reverse`-এর মতো এই মেথডটিও একটি নতুন অ্যারে রিটার্ন করে এবং মূল অ্যারেটি পরিবর্তন করে না।

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
