# পরিচিতি

ফান্ডামেন্টালস কনসেপ্টে যেমন দেখেছেন, একটি AWK প্রোগ্রাম **প্যাটার্ন-অ্যাকশন জোড়া** দিয়ে গঠিত।

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## "প্যাটার্ন" বলতে আমরা কী বুঝি?

"প্যাটার্ন" হলো যেকোনো AWK এক্সপ্রেশন।
এক্সপ্রেশনের ফলাফলটি সত্য হিসেবে গণ্য হবে কি না, তা-ই নির্ধারণ করে অ্যাকশনটি চালানো হবে কি না।

## খালি প্যাটার্ন

প্যাটার্নটি বাদ দেওয়া যায়।
এক্ষেত্রে প্রতিটি রেকর্ডের জন্য অ্যাকশনটি চালানো হয়।

passwd ফাইলের সব ইউজারনেম আমরা প্রিন্ট করতে পারি।

```sh
awk -F: '{print $1}' /etc/passwd
```

## রেগুলার এক্সপ্রেশন

বুলিয়ান ফলাফল পেতে AWK স্ট্রিং ও রেগুলার এক্সপ্রেশনের তুলনা করতে পারে।

নির্দিষ্ট একটি ফিল্ড মেলাতে `~` রেগুলার-এক্সপ্রেশন-মেলানোর অপারেটরটি ব্যবহার করুন।
এই অপারেটরটি বাম দিকের অপারেন্ড হিসেবে একটি স্ট্রিং এবং ডান দিকের অপারেন্ড হিসেবে একটি রেগুলার এক্সপ্রেশন নেয়।
একটি রেগুলার এক্সপ্রেশন লিটারেল `/` স্ল্যাশের ভেতরে লেখা হয়।

passwd ফাইলে যেসব ইউজার bash দিয়ে লগ ইন করেন, তাদের খুঁজে বের করতে:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` হলো "রেগুলার এক্সপ্রেশন মেলে **না**" অপারেটর।

বর্তমান রেকর্ডের সাথে একটি রেগুলার এক্সপ্রেশন মেলাতে আপনি `$0 ~ /regex/` লিখতে পারেন।
এটি এতটাই কমন যে এর একটি সংক্ষিপ্ত রূপ আছে: আপনি `$0` আর `~` বাদ দিয়ে শুধু `/regex/` লিখতে পারেন

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
ওই AWK ওয়ান-লাইনারটির সাথে সমতুল্য grep কমান্ডটি মিলিয়ে দেখুন

```sh
grep 'regex' data.txt
```

সংক্ষিপ্ততা বিসর্জন না দিয়েই AWK আপনাকে একটি সম্পূর্ণ প্রোগ্রামিং ভাষা দেয়।
~~~~

GNU AWK-এর রেগুলার এক্সপ্রেশনের ধরন নিয়ে আমরা পরবর্তী কোনো কনসেপ্টে আরও আলোচনা করব।

## এক্সপ্রেশন

AWK-এর এক্সপ্রেশন (গাণিতিক, লজিক্যাল বা অন্য যেকোনো) প্যাটার্ন হিসেবে ব্যবহার করা যায়।

UID 1000 বা তার বেশি এমন সব ইউজার বের করতে:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

মনে রাখবেন, AWK-এর ফলস মানগুলো হলো সংখ্যা শূন্য আর খালি স্ট্রিং, আর অন্য সব সংখ্যা বা স্ট্রিং ট্রু।
যেকোনো এক্সপ্রেশন যা একটি সংখ্যা বা স্ট্রিং হিসেবে মূল্যায়িত হয়, সেটিকে প্যাটার্ন হিসেবে ব্যবহার করা যায়।

## ফাংশন

যেকোনো [বিল্ট-ইন][builtins] বা [ইউজার-ডিফাইনড][user-defined] ফাংশন একটি এক্সপ্রেশনে, আর তাই প্যাটার্নেও ব্যবহার করা যায়।
কয়েকটি উদাহরণ:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## ধ্রুবক প্যাটার্ন

AWK-এর একটি কমন রীতি হলো:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` হলো এমন একটি প্যাটার্ন যা সবসময় সত্য হিসেবে গণ্য হয়, আর এর সাথে যুক্ত কোনো অ্যাকশন নেই।
এর অর্থ "বর্তমান রেকর্ডটি প্রিন্ট করা"।
