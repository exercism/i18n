# সম্পর্কে

Elm-এ একটি [`Array`][array] হলো একই টাইপের শূন্য বা তার বেশি মানের একটি দ্রুতগতির অপরিবর্তনীয় সংগ্রহ। যেহেতু অ্যারে অপরিবর্তনীয়, একবার একটি অ্যারে তৈরি হয়ে গেলে তার মান আর কখনও বদলানো যায় না। অ্যারের জন্য কোনো লিটারাল সিনট্যাক্স নেই (লিস্টের জন্য যেমন আছে), তাই এর বদলে `Array.fromList` সিনট্যাক্স ব্যবহার করা হয়। যেমন, "a", "b" আর "c" সম্বলিত একটি `Array` সাধারণত `Array.fromList ["a", "b", "c"]` হিসেবে দেখানো হয়। কনসোল আউটপুটে, ডিবাগারে আর এ ধরনের অন্যান্য জায়গায় আপনি এটি দেখতে পাবেন।

`List` হলো একটি [ডিফল্ট ইমপোর্ট][default-imports], কিন্তু `Array` মডিউলটি স্পষ্টভাবে ইমপোর্ট করতে হয়, `import Array` বা অনুরূপ কিছু দিয়ে।

লিস্টের জন্য টাইপ অ্যানোটেশন এভাবে লেখা যায়

```elm
Array String --> an array of String
Array Int --> an array of Int
```

অ্যারে এভাবে তৈরি করা যায়:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

`Array.push` দিয়ে একটি অ্যারে-তে এলিমেন্ট যোগ করা হয়:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

`Array.append` দিয়ে অ্যারে জোড়া লাগানো হয়:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

`Array.get` দিয়ে অ্যারে থেকে একটি এলিমেন্ট পড়া হয়:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

`Array.set` দিয়ে অ্যারে-তে একটি এলিমেন্ট সেট করা হয়:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

অ্যারে নিয়ে কাজ করা হয় [`Array` মডিউল][array-module]-এ ডিফাইন করা ফাংশন দিয়ে।

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

কোনো ফাংশন বা অপারেটর যদি `Array` পরিবর্তন করছে বলে মনে হয় (যেমন একটি এলিমেন্ট যোগ করা), তাহলে আসলে সেটি একটি নতুন `Array` রিটার্ন করে। তবে পারফরম্যান্স সাধারণত সমস্যা হয় না, কারণ `Array`-এর ইমপ্লিমেন্টেশন অপ্রয়োজনীয় অ্যালোকেশন বা কপি প্রতিরোধ করে।
