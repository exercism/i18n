# রিপ্রেজেন্টার নরমালাইজেশন

[JavaScript রিপ্রেজেন্টার][github-javascript-representer] নিম্নলিখিত নরমালাইজেশনগুলো প্রয়োগ করে:

## কমেন্ট মুছে ফেলা

সব কমেন্ট মুছে ফেলা হয়।
নিচের উদাহরণগুলো সমতুল্য:

### কমেন্টসহ উদাহরণ

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### কমেন্ট ছাড়া উদাহরণ

```javascript
function hello() {
  return 'hi there';
}
```

## হোয়াইটস্পেস নরমালাইজ করা

কোড রিপ্রেজেন্ট করা হলে তার _ক্রম_ গুরুত্বপূর্ণ, কিন্তু তার ভৌত অবস্থান নয়।
এর মানে হলো হোয়াইটস্পেস নরমালাইজ করা হয়।
নিচের উদাহরণগুলো সমতুল্য:

### দুই স্পেস ইন্ডেন্টেশনের উদাহরণ

```javascript
function hello() {
  return 'hello world';
}
```

### চার স্পেস ইন্ডেন্টেশনের উদাহরণ

```javascript
function hello() {
  return 'hello world';
}
```

### মজার ইন্ডেন্টেশনের উদাহরণ

```javascript
function hello() {
  return 'hello world';
}
```

## আইডেন্টিফায়ার নরমালাইজ করা

আইডেন্টিফায়ারগুলো একটি প্লেসহোল্ডার মানে নরমালাইজ করা হয়।

### আগে

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### পরে

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
