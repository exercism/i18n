# পরিচিতি

এনুমারেশন হলো কোনো কালেকশনের (`Array`, `Hash` ইত্যাদি) ভেতর দিয়ে একে একে এগিয়ে যাওয়া এবং প্রতিটি অবজেক্টের উপর কোনো একটি কাজ করা।

এনুমারেশন রুবির একটি মূল ধারণা, এবং এটি সর্ট করা (`sort_by`), গ্রুপ করা (`group_by`), ম্যাপ করা (`map`), রিডিউস করা (`reduce`) সহ আরও অনেক কাজে ব্যবহৃত হয়।
সাধারণত লুপ ব্যবহার করার বদলে কালেকশনের ভেতর দিয়ে ইটারেট করার স্বাভাবিক উপায় হিসেবে আপনি সবচেয়ে বেশি এনুমারেশনই দেখতে পাবেন।

`map` ও `with_index` ব্যবহার করা একটি সহজ এনুমারেশন দেখতে এমন হয়:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
