# কমান্ড লাইনে টেস্ট করা

টেস্টগুলো এভাবে চালান:

```bash
scarb cairo-test
```

প্রথম টেস্টটি ছাড়া বাকি সব টেস্ট ইগনোর করা হয়েছে। প্রথম টেস্টটি পাস করানোর পর, `tests` ডিরেক্টরিতে থাকা টেস্টের সোর্স ফাইলটি খুলুন, পরের টেস্ট থেকে `#[ignore]` ফ্ল্যাগটি মুছে ফেলুন এবং টেস্টগুলো আবার পাস করান। প্রতিটি আলাদা টেস্ট হলো একটি ফাংশন, যার উপরে `#[test]` ফ্ল্যাগ থাকে। এভাবে চলতে থাকুন, যতক্ষণ না সব টেস্ট পাস হয়।

টেস্টের সোর্স ফাইল সম্পাদনা না করেই যদি _সব_ টেস্ট চালাতে চান, তবে ব্যবহার করুন:

```bash
scarb cairo-test --include-ignored
```

নির্দিষ্ট কোনো টেস্ট চালাতে, সেটি ইগনোর করা হোক বা না হোক, যেমন `some_test`, আপনি ব্যবহার করতে পারেন:

```bash
scarb cairo-test -f some_test
```

Cairo টেস্ট সম্পর্কে আরও জানতে অনলাইনের [টেস্ট ডকুমেন্টেশন][cairo-tests] দেখুন।

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
