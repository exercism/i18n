# নির্দেশনা

এই অনুশীলনীতে আপনি নিউ ইয়র্কের একটি বিউটি সেলুনের জন্য অ্যাপয়েন্টমেন্ট শিডিউলার নিয়ে কাজ করবেন। সেলুনটি ২০১২ সালের ১৫ সেপ্টেম্বর চালু হয়েছিল।

আপনার চারটি কাজ আছে, যার সবকটিতেই অ্যাপয়েন্টমেন্টের তারিখ জড়িত থাকবে। তারিখ ও সময় নিচের তিনটি ফরম্যাটের একটি ব্যবহার করবে:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
টেস্টগুলো স্বয়ংক্রিয়ভাবে কালচারটি `en-US` হিসেবে সেট করে দেবে, তাই আপনাকে নিজে কালচার সেট করতে বা উল্লেখ করতে হবে না।
~~~~

## 1. অ্যাপয়েন্টমেন্টের তারিখ পার্স করুন

`schedule` ফাংশনটি তৈরি করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখের টেক্সট রূপকে সংশ্লিষ্ট `DateTime` ফরম্যাটে পার্স করতে পারে:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. একটি অ্যাপয়েন্টমেন্ট ইতিমধ্যে পেরিয়ে গেছে কি না তা দেখুন

`hasPassed` ফাংশনটি তৈরি করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি অতীতে কোথাও ছিল কি না তা দেখে:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. অ্যাপয়েন্টমেন্টটি বিকেলে কি না তা দেখুন

`isAfternoonAppointment` ফাংশনটি তৈরি করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং অ্যাপয়েন্টমেন্টটি বিকেলে (>= 12:00 এবং < 18:00) কি না তা দেখে:

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. অ্যাপয়েন্টমেন্টের সময় ও তারিখ বর্ণনা করুন

`description` ফাংশনটি তৈরি করুন, যা একটি অ্যাপয়েন্টমেন্টের তারিখ নেয় এবং সেই তারিখ ও সময়ের একটি বর্ণনা রিটার্ন করে:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. অ্যানিভার্সারি তারিখ রিটার্ন করুন

`anniversaryDate` ফাংশনটি তৈরি করুন, যা চলতি বছরের অ্যানিভার্সারি তারিখ রিটার্ন করে, যেটি ১৫ সেপ্টেম্বর:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
