# পরিচিতি

C একটি স্ট্যাটিকালি টাইপড ভাষা, অর্থাৎ কম্পাইল হওয়ার সময়েই প্রতিটি জিনিসের একটি টাইপ থাকে।
একটি [ভ্যারিয়েবল][variable]-এর জন্য নাম বেছে নিয়ে তার টাইপ নির্ধারণ করাকেই ভ্যারিয়েবল ডিক্লেয়ার করা বলা হয়।

ভ্যারিয়েবল ডিক্লেয়ার করা হয় তার টাইপ স্পষ্টভাবে উল্লেখ করে।
ভ্যারিয়েবলের নামের ক্ষেত্রে [কিছু নিয়ম][name-rules] মানতে হয়, যেমন নাম শুরু হতে হবে কোনো অক্ষর বা আন্ডারস্কোর দিয়ে।
কিছু নাম ব্যবহার করা যায় না, কারণ সেগুলো [কিওয়ার্ডের][reserved-keywords] জন্য বা [অন্য কিছু আইডেন্টিফায়ারের][reserved-identifiers] জন্য সংরক্ষিত।

ভ্যারিয়েবলের মান নির্ধারণ বা হালনাগাদ করা হয় ভ্যারিয়েবল অ্যাসাইনমেন্টের মাধ্যমে।
মান নির্ধারণ করলে সেই ভ্যারিয়েবলটি ডিফাইন হয়ে যায়।
ভ্যারিয়েবল ডিফাইন করাকেই ইনিশিয়ালাইজেশন বলা হয়।

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

ভ্যারিয়েবলের মান [`=` সরল অ্যাসাইনমেন্ট অপারেটর][assignment-operator] ব্যবহার করে অ্যাসাইন ও হালনাগাদ করা যায়।
একবার ডিফাইন হয়ে গেলে ভ্যারিয়েবলের টাইপ আর কখনোই বদলানো যায় না।

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C একটি [ইম্পারেটিভ][imperative] [প্রসিডিউরাল][procedural] ভাষা।
সব ধরনের গণনা করা হয় একগুচ্ছ [স্টেটমেন্ট][statements]-এর মাধ্যমে, যেগুলো একটি [ফাংশন][function] বা একাধিক ফাংশনের অংশ।

প্রতিটি ফাংশনে শূন্য বা তার বেশি [প্যারামিটার][parameters] থাকতে পারে।
ফাংশন ডিফাইন করার সময় সব প্যারামিটার এবং রিটার্ন ভ্যালুর টাইপ স্পষ্টভাবে উল্লেখ করতে হয়।
ফাংশন থেকে মান রিটার্ন করা হয় [`return` কিওয়ার্ড][return-keyword] ব্যবহার করে।
ডিফল্টভাবে ফাংশনের [স্টোরেজ ক্লাস][storage_class] হয় এক্সটার্নাল, অর্থাৎ এটি প্রোগ্রামের পুরো জীবনকাল ধরে থাকে এবং ফাইলের বাইরে থেকেও দেখা যায়।
এটা আটকাতে `static` কিওয়ার্ড যোগ করে ইন্টার্নাল ভিজিবিলিটি নির্দিষ্ট করা যায়।

```c
static int add(int x, int y) {
  return x + y;
}
```

উপরের উদাহরণে `x` ও `y` ভ্যারিয়েবল দুটি কেবল ওই ফাংশনের ভেতরেই ব্যবহার করা যায়, অর্থাৎ এদের স্কোপ হলো ফাংশন স্কোপ।
[স্কোপ][scope] মানে হলো, একটি নামের (প্রোগ্রামের কোনো এলিমেন্টের) সঙ্গে যুক্ত মান কেবল সেই কোড "এলাকার" ভেতরেই ব্যবহার করা যায়, যেখানে সেটি ডিফাইন করা হয়েছে।
C-তে মূল কোড এলাকাগুলো হলো:

- ফাইল
- ফাংশন
- ব্লক (যেমন লুপ বা অন্য কোনো কনস্ট্রাক্টের ভেতরে)

ফাংশন কল করা হয় ফাংশনের নাম উল্লেখ করে এবং ফাংশনের প্রতিটি প্যারামিটারের জন্য আর্গুমেন্ট পাস করে।

```c
int sum = add(1, 2);
```

C দুই ধরনের [কমেন্ট][comments] সাপোর্ট করে।
একলাইন কমেন্টের আগে `//` বসে (C99 থেকে) এবং মাল্টিলাইন কমেন্ট `/*` ও `*/`-এর মাঝে লেখা হয়।
