# ভূমিকা

## রেগুলার এক্সপ্রেশন

**রেগুলার এক্সপ্রেশন** (রেজেক্স) হলো অক্ষরের এমন একটি ক্রম, যা টেক্সটে খোঁজার একটি প্যাটার্ন ঠিক করে দেয়।

রেগুলার এক্সপ্রেশনের সিনট্যাক্স শেখানো এই টপিকের পরিধির বাইরে।
আমরা রেজেক্স কাজে লাগাতে `jq` যে এক্সপ্রেশনগুলো দেয়, সেগুলোতেই মনোযোগ দেব।

### রেজেক্সের ধরন

ভিন্ন ভিন্ন টুল রেগুলার এক্সপ্রেশনের ভিন্ন ভিন্ন ভার্সন বাস্তবায়ন করে।
`jq` [Oniguruma][oniguruma] রেজেক্স লাইব্রেরিটি ব্যবহার করে, যা Perl v5.8-এর রেজেক্সের সাথে বেশিরভাগ ক্ষেত্রেই সামঞ্জস্যপূর্ণ।

`jq` যে নির্দিষ্ট সিনট্যাক্স ব্যবহার করে, তা [Oniguruma GitHub রিপোতে পাওয়া যাবে][onig-syntax]।

যেমন, ডিজিট ক্যারেক্টার ক্লাসটি (`\d`) লিখতে হবে `"\\d"` হিসেবে।

### রেজেক্স ফাংশন

`jq`-তে রেগুলার এক্সপ্রেশন [কয়েকটি ফিল্টারের মধ্যে সীমাবদ্ধ][jq-regex-funcs]।

#### সাধারণ ম্যাচিং

কোনো স্ট্রিং একটি প্যাটার্নের সাথে মেলে কি না জানতে হলে `test` ফিল্টারটি ব্যবহার করুন।

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

এই ফিল্টারটি একটি _বুলিয়ান_ ফলাফল আউটপুট দেয়।

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

#### ম্যাচ সম্পর্কে তথ্য

প্যাটার্নের সাথে আসলে যে সাবস্ট্রিংটি মিলেছে তা বের করতে হলে `match` ফিল্টারটি ব্যবহার করুন।

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

এই ফিল্টারটি আউটপুট দেয়:

- কোনো ম্যাচ না থাকলে কিছুই না, অথবা
- ম্যাচ থাকলে নানা প্রপার্টি-সহ একটি অবজেক্ট।

এই উদাহরণটি ব্যাকরেফ সিনট্যাক্স `\1` ব্যবহার করে পরপর থাকা দুটি একই স্বরবর্ণ খুঁজে দেখে।

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match` ফিল্টারটি _প্রতিটি_ ম্যাচের জন্য একটি অবজেক্ট রিটার্ন করে।
এই উদাহরণে সব স্বরবর্ণ খুঁজে বের করতে `"g"` ফ্ল্যাগটি কাজ করতে দেখা যায়।

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

#### ক্যাপচার করা সাবস্ট্রিং

`match` ফিল্টারের মতোই, `capture` ফিল্টারটি ম্যাচ থাকলে একটি অবজেক্ট রিটার্ন করে।

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

রিটার্ন করা অবজেক্টটি **নেমড ক্যাপচার**গুলোর একটি ম্যাপিং।

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

#### শুধু সাবস্ট্রিং

`scan` ফিল্টারটি `"g"` ফ্ল্যাগ-সহ `match`-এর মতোই।

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` সাবস্ট্রিংয়ের একটি _স্ট্রিম_ আউটপুট দেবে।

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

সাবস্ট্রিংগুলো ক্যাপচার করতে `[...]` অ্যারে কনস্ট্রাক্টরটি ব্যবহার করুন।

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

#### স্ট্রিং ভাগ করা

স্ট্রিংয়ের যে অংশগুলো আপনি **রাখতে** চান সেগুলো যদি জানা থাকে, তবে `match` বা `scan` ব্যবহার করুন।
আর যে অংশগুলো আপনি **বাদ দিতে** চান সেগুলো যদি জানা থাকে, তবে `split` ব্যবহার করুন।

```jq
STRING | split(REGEX; FLAGS)
```

~~~~exercism/caution
একটি মাত্র আর্গুমেন্ট নেওয়া `split` ফিল্টারটি তার আর্গুমেন্টকে একটি **ফিক্সড স্ট্রিং** হিসেবে ধরে।

`split`-এর সাথে রেজেক্স ব্যবহার করতে হলে আপনাকে **অবশ্যই** দ্বিতীয় আর্গুমেন্টটি দিতে হবে; খালি স্ট্রিং দিলেও চলবে।
~~~~

<!-- prettier-ignore-end -->

যেকোনো হোয়াইটস্পেসে একটি স্ট্রিং ভাগ করার একটি উদাহরণ।

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

#### প্রতিস্থাপন

`sub` ও `gsub` ফিল্টার ইনপুট স্ট্রিংটি রূপান্তর করতে পারে, ইনপুটের যে অংশগুলো মিলেছে সেগুলোকে একটি রিপ্লেসমেন্ট স্ট্রিং দিয়ে বদলে দিয়ে।

শুধু প্রথম ম্যাচটি বদলাতে `sub` ব্যবহার করুন।
সব ম্যাচ বদলাতে `gsub` ব্যবহার করুন।

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

রিপ্লেসমেন্ট টেক্সট মিলে যাওয়া সাবস্ট্রিংগুলোকে নির্দেশ করতে পারে; এজন্য নেমড ক্যাপচার ও [স্ট্রিং ইন্টারপোলেশন][jq-interp] ব্যবহার করুন।

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

### ফ্ল্যাগ

উপরের সব ফিল্টারে FLAGS হলো সাপোর্টেড ফ্ল্যাগগুলোর শূন্য বা ততোধিক নিয়ে গঠিত একটি স্ট্রিং।

- `g` - গ্লোবাল সার্চ (শুধু প্রথমটি নয়, সব ম্যাচ খুঁজে বের করে)
- `i` - কেস-ইনসেনসিটিভ সার্চ
- `m` - মাল্টি লাইন মোড ('.' নতুন লাইনেও ম্যাচ করবে)
- `n` - খালি ম্যাচ উপেক্ষা করে
- `p` - s ও m দুটি মোডই চালু থাকে
- `s` - সিঙ্গল লাইন মোড ('^' -> '\A', '$' -> '\Z')
- `l` - সবচেয়ে লম্বা সম্ভাব্য ম্যাচ খুঁজে বের করে
- `x` - এক্সটেন্ডেড রেজেক্স ফরম্যাট (হোয়াইটস্পেস ও কমেন্ট উপেক্ষা করে)

যেমন

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
