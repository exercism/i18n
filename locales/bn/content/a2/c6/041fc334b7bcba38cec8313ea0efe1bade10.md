# পরিচিতি

## ফাংশন

Common Lisp-এ একটি গ্লোবাল ফাংশন ডিফাইন করতে `defun` এক্সপ্রেশনটি ব্যবহার করা হয়।
এই এক্সপ্রেশনটি তার প্রথম আর্গুমেন্ট হিসেবে প্যারামিটারগুলোর একটি অ্যারে নেয় (খালি অ্যারে মানে ফাংশনটির কোনো প্যারামিটার নেই)।
এর পরে থাকে একটি ঐচ্ছিক ডকুমেন্টেশন স্ট্রিং (নিচে দেখুন), তারপর শূন্য বা ততোধিক এক্সপ্রেশন, যেগুলো মিলিয়ে ফাংশনটির "বডি" তৈরি হয়।

ফাংশনে শূন্য বা ততোধিক প্যারামিটার থাকতে পারে।

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

কোনো ফাংশন কল করা হয় এভাবে: একটি এক্সপ্রেশন মূল্যায়ন করা হয়, যেখানে ফাংশনটিকে নির্দেশ করা সিম্বলটি এক্সপ্রেশনের প্রথম এলিমেন্ট হিসেবে থাকে এবং ফাংশনের আর্গুমেন্টগুলো (যদি থাকে) এক্সপ্রেশনের বাকি আইটেম হিসেবে থাকে।

ফাংশন যে মানে মূল্যায়িত হয়, সেটি হলো ফাংশনের বডিতে মূল্যায়িত হওয়া শেষ এক্সপ্রেশনটির মান।
সব ফাংশনই একটি মানে মূল্যায়িত হয়।

```lisp
(add-nums 2 2) ;; => 4
```

ফাংশনে ঐচ্ছিকভাবে একটি ডকুমেন্টেশন স্ট্রিংও (যাকে 'ডকস্ট্রিং'ও বলা হয়) থাকতে পারে।
এটি থাকলে আর্গুমেন্টের অ্যারের পরে কিন্তু ফাংশনের বডির আগে বসে।
`documentation`-এর মাধ্যমে ডকুমেন্টেশন স্ট্রিংটি পাওয়া যায়।

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
