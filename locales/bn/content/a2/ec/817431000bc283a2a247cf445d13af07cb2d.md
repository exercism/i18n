# সম্পর্কে

PowerShell হলো মাইক্রোসফটের একটি ডাইনামিক ও ইমপ্লিসিটলি টাইপড (_তবে [স্ট্রং টাইপড][strong typed] ভ্যারিয়েবলও সমর্থন করে_) স্ক্রিপ্টিং ভাষা, যা মূলত টাস্ক অটোমেশন ও কনফিগারেশন ম্যানেজমেন্টে কাজ করে।

PowerShell ইমপারেটিভ, ফাংশনাল, অবজেক্ট-ওরিয়েন্টেড এবং এমনকি পাইপলাইন স্টাইলের প্রোগ্রামিংও সমর্থন করে।

PowerShell তৈরি হয়েছে .NET প্ল্যাটফর্মের উপরে এবং প্রথম প্রকাশিত হয় ২০০৬ সালে।
এটি সব আধুনিক Windows OS-এ ডিফল্টভাবে অন্তর্ভুক্ত, আর Mac ও Linux-এও ইনস্টল করা যায়।


## ভ্যারিয়েবল

PowerShell-এ ভ্যারিয়েবল ডিফাইন করার দুটি কমন উপায় আছে।

PowerShell-এ ভ্যারিয়েবলের নাম অবশ্যই `$` দিয়ে শুরু হতে হবে, এবং ভ্যারিয়েবলের নাম একটি মানের সাথে বাঁধতে অ্যাসাইনমেন্ট অপারেটর `=` ব্যবহার করতে হয়।

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

আপনি চাইলে ভ্যারিয়েবলের টাইপ স্পষ্টভাবেও উল্লেখ করতে পারেন, যদি আপনি নিশ্চিত করতে চান যে মানটি অবশ্যই একটি নির্দিষ্ট টাইপের হবে।
সম্ভব হলে PowerShell যথাসাধ্য চেষ্টা করবে মানটিকে এক টাইপ থেকে অন্য টাইপে রূপান্তর করতে।

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### কনস্ট্যান্ট

PowerShell-এ কনস্ট্যান্ট হলো এমন ভ্যারিয়েবল, যা ডিফাইন করার পর **পরিবর্তন** করা যায় না, **মুছে ফেলাও** যায় না।
এখান থেকেই ভ্যারিয়েবল ডিফাইন করার দ্বিতীয় উপায়টি আসে: `New-Variable` cmdlet ব্যবহার করা।

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## ফাংশন

PowerShell-এ ফাংশন ডিফাইন করা হয় `function` কিওয়ার্ড দিয়ে।
প্রতিটি ফাংশনে `()` বন্ধনীর ভেতরে শূন্য বা তার বেশি প্যারামিটার থাকতে পারে, তারপর থাকে ফাংশনের স্কোপ, যা `{` দিয়ে শুরু হয় এবং `}` দিয়ে শেষ হয়।

```powershell
function Greeting {
    return "Hello!"
}
```

`FuncName $Arg` সিনট্যাক্সে কল করার পর PowerShell-এ ফাংশন `return` কিওয়ার্ডের মাধ্যমে স্পষ্টভাবে মান রিটার্ন করতে পারে।

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## কমেন্ট

PowerShell-এ একক কমেন্ট শুরু হয় `#` দিয়ে, আর শেষ হয় লাইনটি যেখানে শেষ হয় সেখানে।
PowerShell-এ কমেন্ট ব্লক শুরু হয় `<#` দিয়ে এবং শেষ হয় `#>` দিয়ে।

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
