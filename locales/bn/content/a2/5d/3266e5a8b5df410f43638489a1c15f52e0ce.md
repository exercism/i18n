# টেস্ট

প্রতিটি অনুশীলনীতে একটি টেস্ট ফাইল থাকে।
`bats` প্রোগ্রাম দিয়ে টেস্টগুলো চালান।
```bash
bats test-hello-world.bats
```

`bats` ইনস্টল করা থাকতে হবে।
আপনার সিস্টেমের জন্য `bats` ইনস্টল করার নির্দেশনা পেতে [Bash ট্র্যাকের টেস্টিং][bash] পেজটি দেখুন।

### bats আসলে bash দিয়ে তৈরি

bats ফাইলটি একটি bash স্ক্রিপ্ট, যেখানে `bats` কমান্ডের চেনা কিছু বিশেষ ফাংশন থাকে।
আপনি এমন কিছু টেস্ট দেখবেন যেগুলো দেখতে এরকম
```sh
gawk -f some-exercise.awk <<< "some,input,here"
```
ওই `<<<` সিনট্যাক্সটি হলো bash-এর একটি [Here String][here-string]।
এটি ডান দিকের স্ট্রিংটি বাম দিকের প্রোগ্রামের স্ট্যান্ডার্ড ইনপুটে পাঠায়।
এটি ([প্রায়][so]) এর সমান
```sh
echo "some,input,here" | gawk -f some-exercise.awk
```

## assert ফাংশনগুলোর জন্য সহায়তা

টেস্টগুলো [bats-assert][bats-assert] লাইব্রেরির ফাংশন ব্যবহার করে।
বিভিন্ন `assert*` ফাংশনের সহায়তা সেখানে পাওয়া যাবে।

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করার অর্থ হলো তার সব টেস্ট পাস করানো।
ডিফল্টভাবে, আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) চলে।
এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।
এটি পাস হয়ে গেলে, অন্য টেস্টগুলোর আগে বসানো

    [[ $BATS_RUN_SKIPPED == true ]] || skip

অ্যানোটেশনগুলো কমেন্ট করে বা মুছে ফেলে আপনি পরের টেস্টটি চালু করতে পারেন।

## স্কিপ উপেক্ষা করা

`skip` অ্যানোটেশনযুক্ত টেস্টগুলোসহ সব টেস্ট চালাতে আপনি চালাতে পারেন:
```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

বারবার টাইপ কমাতে একটি র‍্যাপার ফাংশন ব্যবহার করা সুবিধাজনক হতে পারে: `bash`-এ আপনি এভাবে করতে পারেন:
```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```
তারপর শুধু এভাবে টেস্ট চালান:
```bash
bats
```

## ডিবাগিং আউটপুট

```exercism/caution
এটি লোকালে `bats` দিয়ে কাজ করে, কিন্তু Exercism অনলাইন এডিটরে **করে না**।
```

টেস্ট চালানোর সময় `bats` প্রত্যাশিত আউটপুটের সাথে তুলনা করার জন্য stdout ও stderr দুটোই ধরে রাখে।
আপনি যদি stdout বা stderr-এ ডিবাগ মেসেজ প্রিন্ট করেন, সেগুলো ধরে রাখা আউটপুটে যুক্ত হবে এবং টেস্ট ফেল করাতে পারে।

টেস্টের ফলাফলে প্রভাব না ফেলে ডিবাগ তথ্য প্রিন্ট করতে `bats` এই কাজের জন্য ফাইল ডেসক্রিপ্টর **3** দেয়।
`/dev/fd/3` ফাইলে যা কিছু প্রিন্ট করা হবে তা টেস্ট চালানোর সময় দেখানো হবে, কিন্তু অ্যাসারশনের জন্য ব্যবহৃত ধরে রাখা আউটপুটে যুক্ত হবে না।

উদাহরণ:

```awk
BEGIN {
    # This debug message will not interfere with test output comparison
    print "a debug message" > "/dev/fd/3"

    # Normal program output (this is what your tests will see and compare)
    print "Hello, World!"
}
```

চালানোর উদাহরণ:

```none
$ bats test-hello-world.bats
test-hello-world.bats
 ✓ Say Hi!
a debug message

1 test, 0 failures
```

এতে আপনি টেস্টে প্রভাব না ফেলেই সহায়ক ডিবাগ আউটপুট দেখতে পারেন।

আপনার কোডে 여러 জায়গায় এটি ব্যবহার করলে, বিস্তারিত অংশ একটি ফাংশনের ভেতরে লুকিয়ে রাখলে পড়ার সহজতা বাড়তে পারে:

```awk
BEGIN {
    debug("starting ...")
}

# do stuff here ...

END {
    debug("... finished")
}

function debug(msg) {print msg > "/dev/fd/3"}
```
