# ভূমিকা

## স্ট্রিং

Elm-এ টেক্সট উপস্থাপনার মূল ভিত্তি হলো ক্যারেক্টার ও স্ট্রিং। স্ট্রিংকে ক্যারেক্টারের অ্যারে হিসেবে ভাবা যায়, আর `List`-এর বেশিরভাগ ফাংশনেরই সমতুল্য ফাংশন `String` মডিউলে রয়েছে।

### ক্যারেক্টার

`Char` টাইপ একক কোটেশনে লেখা একটি একক ইউনিকোড ক্যারেক্টার বোঝায়, যেমন `'a'`। 
`Char` মডিউলে একটি ক্যারেক্টারের গুণাবলি পরীক্ষা করার জন্য প্রেডিকেট ফাংশন (`Char -> Bool`) আছে: `isUpper`, `isLower`, `isAlpha` এবং `isAlphaNum`
মডিউলটি আবার একটি ক্যারেক্টার রূপান্তর করার ফাংশনও দেয়: `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, আর `toCode` ও `fromCode` দিয়ে তার সংখ্যাসূচক ইউনিকোড মানে (`Int`) যাওয়া-আসার ফাংশন।

### স্ট্রিং

`String` টাইপ দক্ষ স্ট্রিং ম্যানিপুলেশনের জন্য একটি বিল্ট-ইন উপস্থাপনা দেয় এবং যেকোনো ইউনিকোড ক্যারেক্টারের ক্রম প্রকাশ করতে পারে, যেমন "this is an Elm string."। 
মাল্টি-লাইন স্ট্রিং তিনটি ডাবল কোট দিয়ে লেখা হয় এবং এতে এস্কেপ না করা কোট ও নিউলাইন থাকতে পারে।
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### স্ট্রিং ফাংশন

`String` মডিউলে নিচের টেবিলে সংক্ষেপে দেওয়া সব ফাংশন আছে। 
সবচেয়ে বেশি ব্যবহৃত কিছু ফাংশন:

`cons : Char -> String -> String` একটি স্ট্রিংয়ের শুরুতে একটি ক্যারেক্টার যোগ করে।
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` দুটি স্ট্রিং যুক্ত করে।
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` প্রদত্ত সেপারেটরে একটি স্ট্রিংকে স্ট্রিংয়ের অ্যারেতে ভাগ করে।
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` প্রদত্ত একটি সেপারেটর দিয়ে স্ট্রিংয়ের একটি অ্যারে সংযুক্ত করে।
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` প্রদত্ত একটি সাবস্ট্রিংয়ের সব উপস্থিতি প্রতিস্থাপন করে।
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` একটি স্ট্রিংয়ে ক্যারেক্টারের সংখ্যা রিটার্ন করে।
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` একটি স্ট্রিংকে `Just Int`-এ রূপান্তর করার চেষ্টা করে, আর ভুল ফরম্যাটের স্ট্রিংয়ের জন্য `Nothing` রিটার্ন করে।
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` দ্বিতীয় স্ট্রিংটিতে প্রথমটি আছে কিনা পরীক্ষা করে।
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` স্ট্রিংয়ের প্রতিটি `Char`-এ প্রদত্ত একটি ফাংশন প্রয়োগ করে।
খেয়াল করুন, দেওয়া ফাংশনটি অবশ্যই `Char` থেকে `Char`-এ একটি ম্যাপিং হতে হবে।
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
