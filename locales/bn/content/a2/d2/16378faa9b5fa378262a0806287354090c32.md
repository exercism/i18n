# পরিচিতি

`Enum` একটি অত্যন্ত কাজের মডিউল, যা এনুমারেবল নিয়ে কাজ করার জন্য একগুচ্ছ অ্যালগরিদম সরবরাহ করে। এটি দিয়ে করা যায়:

- সর্ট করা ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- ফিল্টার করা ([`filter/2`][enum-filter/2]),
- গ্রুপ করা ([`group_by/3`][enum-group_by/3]),
- গণনা করা ([`count/2`][enum-count/2])
- খোঁজা ([`find/3`][enum-find/3]),
- সর্বনিম্ন/সর্বোচ্চ মান খোঁজা ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- reduce করা ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

আরও অনেক কিছু! সম্পূর্ণ তালিকার জন্য [`Enum` মডিউলের ডকুমেন্টেশন][enum-functions] দেখুন।

## Enumerable

সাধারণভাবে, একটি _এনুমারেবল_ হলো এমন যেকোনো ডেটা যার উপর ইটারেট করা যায়, অর্থাৎ একটি কালেকশন। Elixir-এ, এনুমারেবল হলো এমন যেকোনো ডেটা টাইপ যা `Enumerable` [প্রোটোকল][exercism-protocols] ইমপ্লিমেন্ট করে। সেগুলো হলো:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

এগুলোর সবগুলো এখনো না জানলেও চিন্তার কিছু নেই।

যে কেউ নিজের কাস্টম ডেটা স্ট্রাকচারের জন্য `Enumerable` প্রোটোকল ইমপ্লিমেন্ট করতে পারে।

## Reduce

`Enum.reduce/2` দিয়ে আপনি পুরো এনুমারেবলটিকে একটি মাত্র মানে _reduce_ করতে পারেন। এটি করতে _অ্যাকুমুলেটর_ নামের একটি বিশেষ ভ্যারিয়েবল ব্যবহার করা হয়। অ্যাকুমুলেটর ইটারেশনগুলোর মাঝে রিডাকশনের মধ্যবর্তী অবস্থা বহন করে। এই কারণেই এটি এনুমারেবলের জন্য সবচেয়ে শক্তিশালী ফাংশনগুলোর একটি। আরও অনেক বিশেষায়িত ফাংশনের কাজ এই বেশি সাধারণ `reduce` দিয়েই করা যেত। যেমন...

সর্বোচ্চ মান খোঁজা:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

এমনকি ম্যাপিংও (তবে এর জন্য পরে ফলাফলটি উল্টে নিতে হয়):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## ম্যাপের উপর ম্যাপিং

- [`Map.new/2`][map-new] দিয়ে:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- [`Enum.into/3`][enum-into] দিয়ে:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- [`Enum.map/2`][enum-map] দিয়ে:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
