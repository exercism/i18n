# টেস্ট

অনুশীলনীর ডিরেক্টরিতে নিচের কমান্ডটি চালিয়ে আপনি টেস্টগুলো রান করতে পারেন:

```bash
dub test
```

## টেস্ট পাস করা

টেস্ট-ড্রিভেন ডেভেলপমেন্টের [তিনটি নিয়ম](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd) অনুসরণ করে প্রথম টেস্টটি কম্পাইল, লিংক ও পাস করান। কম্পাইলার এরর মেটাতে আর টেস্টটিকে ফেল করাতে যতটুকু দরকার, ঠিক ততটুকু স্ট্রাকচার বানান: নেমস্পেস, ফাংশন, ক্লাস ইত্যাদি ডিক্লেয়ার করে। তারপর টেস্টটি পাস করাতে যতটুকু দরকার, ঠিক ততটুকু কোড লিখুন। এটা হয়ে গেলে, নিচের লাইনটি পরের টেস্টের পরে সরিয়ে পরের টেস্টটি আনকমেন্ট করুন।

```D
static if (all_tests_enabled)
```

এতে কম্পাইল এরর হতে পারে, কারণ আপনি এখনো ডিক্লেয়ার বা ডিফাইন করেননি এমন নতুন কনস্ট্রাক্ট ব্যবহৃত হতে পারে। আবারও, ফেল করা টেস্ট পেতে কম্পাইল এররগুলো ন্যূনতমভাবে ঠিক করুন, তারপর টেস্টটি পাস করাতে কোড ন্যূনতমভাবে বদলান, পড়ার সুবিধা ও প্রকাশক্ষমতার জন্য আপনার ইমপ্লিমেন্টেশন রিফ্যাক্টর করুন, এবং তারপর পরের টেস্টে যান।

নিজের হাতে লো-লেভেল অ্যালগরিদম বা ফ্যাসিলিটি লেখার চেয়ে D-এর স্ট্যান্ডার্ড ফ্যাসিলিটিগুলো ব্যবহার করার চেষ্টা করুন।
