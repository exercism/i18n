# পরিচিতি

টাপল হলো নির্দিষ্ট সংখ্যক এবং যেকোনো টাইপের ডেটা একসাথে গোষ্ঠীবদ্ধ করার একটি হালকা উপায়।
টাপলের আলাদা কোনো নাম থাকে না; কোনো ডেটা স্ট্রাকচারের নাম দিলে সেটি হয়ে যায় একটি `struct`।
টাপলের ফিল্ডগুলোরও নাম থাকে না; সেগুলো ডিস্ট্রাকচারিং করে অথবা অবস্থান অনুযায়ী অ্যাক্সেস করা হয়।

## তৈরি করা

টাপল সবসময় একটি টাপল এক্সপ্রেশন দিয়েই তৈরি করা হয়:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

টাপলে যেকোনো সংখ্যক এলিমেন্ট থাকতে পারে।

## ডিস্ট্রাকচারিং করে অ্যাক্সেস করা

ডিস্ট্রাকচারিং করে টাপলের এলিমেন্টগুলো অ্যাক্সেস করা সম্ভব।
এর মানে হলো টাপলের প্রতিটি আলাদা এলিমেন্টকে ভ্যারিয়েবলের নাম দিয়ে অ্যাসাইন করা, আর এতে টাপলটি ব্যবহৃত হয়ে যায়।

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
