# নির্দেশনা

আপনি আপনার প্রিয় রান্নার বই থেকে একটি লাসাগনা রান্না করতে সাহায্য করার জন্য কিছু কোড লিখতে যাচ্ছেন।

আপনার পাঁচটি কাজ আছে, সবগুলোই আপনার রেসিপি রান্নার সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

লাসাগনাটি কত মিনিট ওভেনে থাকা উচিত তা দিয়ে `$Lasagna::ExpectedMinutesInOven` ভ্যারিয়েবলটি সেট করুন। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```perl
$Lasagna::ExpectedMinutesInOven
# => 40
```

## 2. ওভেনে বাকি থাকা সময় মিনিটে হিসাব করুন

`Lasagna::remaining_minutes_in_oven` সাবরুটিনটি পরিবর্তন করুন। এটি আর্গুমেন্ট হিসেবে লাসাগনাটি ইতিমধ্যে কত মিনিট ওভেনে রয়েছে তা নেয়, আর আগের কাজের ওভেনে প্রত্যাশিত সময় মিনিটের ভিত্তিতে লাসাগনাটিকে ওভেনে আরও কত মিনিট থাকতে হবে তা রিটার্ন করে।

```perl
Lasagna::remaining_minutes_in_oven(30)
# => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`Lasagna::preparation_time_in_minutes` সাবরুটিনটি পরিবর্তন করুন। এটি আর্গুমেন্ট হিসেবে আপনি লাসাগনায় কতটি স্তর যোগ করেছেন তার সংখ্যা নেয়, আর লাসাগনা প্রস্তুত করতে আপনার কত মিনিট লেগেছে তা রিটার্ন করে, ধরে নিয়ে যে প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```perl
Lasagna::preparation_time_in_minutes(2)
# => 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`Lasagna::total_time_in_minutes` সাবরুটিনটি পরিবর্তন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো আপনি লাসাগনায় কতটি স্তর যোগ করেছেন তার সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসাগনাটি কত মিনিট ধরে ওভেনে রয়েছে তার সংখ্যা।
সাবরুটিনটি রিটার্ন করবে লাসাগনা রান্না করতে আপনার মোট কত মিনিট লেগেছে, যা হলো প্রস্তুতির সময় মিনিটে আর এই মুহূর্তে লাসাগনাটি ওভেনে যত মিনিট কাটিয়েছে তার যোগফল।

```perl
Lasagna::total_time_in_minutes(3, 20)
# => 26
```

## 5. লাসাগনা তৈরি হয়ে গেছে জানিয়ে একটি নোটিফিকেশন তৈরি করুন

`Lasagna::oven_alarm` সাবরুটিনটি পরিবর্তন করুন। এটি কোনো আর্গুমেন্ট নেয় না, আর লাসাগনা খাওয়ার জন্য তৈরি হয়ে গেছে বোঝায় এমন একটি মেসেজ রিটার্ন করে।

```perl
Lasagna::oven_alarm()
# => "Ding!"
```
