# ভূমিকা

Clojure-এ একটি `string` হলো একটি Java স্ট্রিং, যা একটি অবজেক্ট এবং অপরিবর্তনীয় টেক্সটকে Unicode ক্যারেক্টারের (অক্ষর, অঙ্ক, যতিচিহ্ন ইত্যাদি) একটি সিকোয়েন্স হিসেবে উপস্থাপন করে।

`clojure.string` লাইব্রেরিটি স্ট্রিং ম্যানিপুলেশন ও প্রসেসিংয়ের অনেকগুলো স্ট্যান্ডার্ড ফাংশন দেয়। এছাড়াও, স্ট্রিং নিয়ে কাজ করার জন্য Java-এর সব প্রচলিত মেথড ইন্টারঅপের মাধ্যমে পাওয়া যায়।
