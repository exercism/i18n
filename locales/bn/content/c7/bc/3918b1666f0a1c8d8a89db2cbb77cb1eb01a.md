# পরিচিতি

জাভায় মেথড ওভারলোডিং এমন একটি ফিচার, যার সাহায্যে একটি ক্লাসে একই নামের একাধিক মেথড থাকতে পারে, যদি তাদের
প্যারামিটার তালিকা আলাদা হয়।
এটি কম্পাইল-টাইম (বা স্ট্যাটিক) পলিমরফিজমের সাথে সম্পর্কিত।
একই ধরনের কাজ করে কিন্তু ভিন্ন ইনপুট নেয়, এমন মেথড
তৈরি করার জন্য এই কনসেপ্টটি খুবই গুরুত্বপূর্ণ।

## কেন মেথড ওভারলোড করবেন?

মেথড ওভারলোডিং প্রোগ্রামের পাঠযোগ্যতা বাড়ায়।
ভিন্ন ভিন্ন মেথডকে একই নাম দেওয়া যায়, তবে
প্যারামিটার আলাদা হবে।
প্যারামিটারের সংখ্যা বা প্যারামিটারের টাইপের উপর নির্ভর করে সংশ্লিষ্ট মেথডটি কল করা হয়।

## কীভাবে মেথড ওভারলোড করবেন?

মেথড ওভারলোডিংয়ের মূল চাবিকাঠি হলো মেথডের সিগনেচার।
দুটি মেথডের সিগনেচার আলাদা হলে সেগুলোকে আলাদা মেথড ধরা হয়।
মেথড ওভারলোড করার দুটি উপায় আছে:

1. **প্যারামিটারের সংখ্যা আলাদা**: মেথডের নাম একই হতে পারে, কিন্তু প্যারামিটারের সংখ্যা আলাদা।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **প্যারামিটারের টাইপ আলাদা**: মেথডের নাম এবং প্যারামিটারের সংখ্যা একই হতে পারে, কিন্তু
   টাইপ আলাদা।

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## মনে রাখার বিষয়গুলো

- ওভারলোড করা মেথডের আর্গুমেন্ট তালিকা অবশ্যই বদলাতে হবে।
- ওভারলোড করা মেথডের রিটার্ন টাইপও বদলানো যায়, তবে শুধু রিটার্ন টাইপ বদলালেই সেটি মেথড
  ওভারলোডিং হিসেবে গণ্য হয় না।
- মেথড একই ক্লাসে বা একটি সাবক্লাসে ওভারলোড করা যায়।

এই কনসেপ্টে আমরা জাভায় মেথড ওভারলোডিংয়ের নানা উদাহরণ ও সূক্ষ্ম দিক দেখব।
