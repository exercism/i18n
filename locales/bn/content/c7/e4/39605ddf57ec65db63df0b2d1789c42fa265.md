# নির্দেশনা

আপনি আপনার প্রিয় রান্নার বই থেকে লাসানিয়া রান্না করতে সাহায্য করার জন্য কিছু কোড লিখবেন।

আপনার পাঁচটি কাজ আছে, সবগুলোই আপনার রেসিপি রান্নার সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

লাসানিয়াকে কত মিনিট ওভেনে থাকতে হবে তা দিয়ে `$EXPECTED-MINUTES-IN-OVEN` কনস্ট্যান্টটি সেট করুন। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় ৪০ মিনিট:

```raku
$EXPECTED-MINUTES-IN-OVEN
# => 40
```

## 2. ওভেনে বাকি সময় মিনিটে হিসাব করুন

`remaining-minutes-in-oven` সাবরুটিনটি পরিবর্তন করুন। এটি আর্গুমেন্ট হিসেবে লাসানিয়া কত মিনিট ধরে ওভেনে আছে সেই প্রকৃত সময়টি নেয়, আর আগের কাজে নির্ধারিত ওভেনে প্রত্যাশিত সময়ের ভিত্তিতে লাসানিয়াকে আরও কত মিনিট ওভেনে থাকতে হবে তা রিটার্ন করে।

```raku
remaining-minutes-in-oven(30)
# => 10
```

## 3. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparation-time-in-minutes` সাবরুটিনটি পরিবর্তন করুন। এটি আর্গুমেন্ট হিসেবে লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যাটি নেয়, আর প্রতিটি স্তর প্রস্তুত করতে ২ মিনিট লাগে ধরে নিয়ে লাসানিয়া প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন তা রিটার্ন করে।

```raku
preparation-time-in-minutes(2)
# => 4
```

## 4. মোট কাজের সময় মিনিটে হিসাব করুন

`total-time-in-minutes` সাবরুটিনটি পরিবর্তন করুন, যেটি দুটি আর্গুমেন্ট নেয়: প্রথম আর্গুমেন্টটি হলো লাসানিয়ায় আপনি কতগুলো স্তর যোগ করেছেন সেই সংখ্যা, আর দ্বিতীয় আর্গুমেন্টটি হলো লাসানিয়া কত মিনিট ধরে ওভেনে আছে সেই সংখ্যা।
সাবরুটিনটির রিটার্ন করা উচিত মোট কত মিনিট আপনি লাসানিয়া রান্নার কাজে ব্যয় করেছেন, যা হলো প্রস্তুতির সময় মিনিটে আর এই মুহূর্তে লাসানিয়া ওভেনে যত মিনিট কাটিয়েছে সেই সময়ের যোগফল।

```raku
total-time-in-minutes(3, 20)
# => 26
```

## 5. লাসানিয়া তৈরি হয়ে গেছে এমন একটি নোটিফিকেশন তৈরি করুন

`oven-alarm` সাবরুটিনটি পরিবর্তন করুন, যেটি কোনো আর্গুমেন্ট নেয় না, যাতে এটি লাসানিয়া খাওয়ার জন্য তৈরি হয়ে গেছে বোঝায় এমন একটি বার্তা রিটার্ন করে।

```raku
oven-alarm()
# => 'Ding!'
```
