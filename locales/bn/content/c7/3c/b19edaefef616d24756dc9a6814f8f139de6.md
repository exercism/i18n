## টাপল

[টাপল][tuple] দিয়ে আমরা সাধারণত একগুচ্ছ তথ্য একসাথে গুছিয়ে রাখি। অ্যারে থেকে এদের পার্থক্য হলো, এদের আকার নির্দিষ্ট এবং এরা ভিন্ন ভিন্ন ডেটা টাইপ ধরে রাখতে পারে।
টাপল তৈরি করা হয় বন্ধনী `()` দিয়ে, এবং এগুলো প্রায়ই কোনো ফাংশন থেকে একাধিক মান রিটার্ন করতে ব্যবহার করা হয়।

```haskell
tuple = (1, "abc", False)
```

এটা তখন কাজে লাগে, যেমন ধরুন আপনি 2D স্পেসে একটি স্থানাঙ্ক সংরক্ষণ করতে চান, তখন আপনি জানেন যে টাপলটিতে সবসময় দুটি এলিমেন্ট থাকবে, x আর y স্থানাঙ্ক।

```haskell
coordinate = (3, 4)
```

### এলিমেন্ট অ্যাক্সেস করা

প্রায়ই আপনি ছোট টাপল নিয়ে কাজ করেন, আর `fst` ও `snd` ফাংশন ব্যবহার করে এলিমেন্টগুলো অ্যাক্সেস করতে পারেন।

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## প্যাটার্ন ম্যাচিং

Haskell ফাংশন লেখার সময় আমরা [প্যাটার্ন ম্যাচিং][pattern-match-doc] ব্যবহার করে একটি [অ্যাসার্টিভ স্টাইল][assertive-style] অনুসরণ করতে পারি:
প্যাটার্ন ম্যাচিং হলো Haskell-এর একটি খুবই শক্তিশালী বৈশিষ্ট্য, যা দিয়ে আপনি ডেটা কনস্ট্রাক্টরের সাথে মিল করতে এবং ভেতরে থাকা মানের সাথে ভ্যারিয়েবল বাইন্ড করতে পারেন।
নাম থেকেই বোঝা যায়, আমরা আসলে মানকে প্যাটার্নের সাথে মেলাই, আর মানটি প্যাটার্নের সাথে মিলে গেলে আমরা প্যাটার্নের ভেতরের মানগুলোর সাথে ভ্যারিয়েবল বাইন্ড করতে পারি।
প্যাটার্ন ম্যাচিং মূলত এই কয়েকটি ধারণা দিয়ে গড়া: মান চেনা, ভ্যারিয়েবল বাইন্ড করা, আর মান ভেঙে ফেলা।

উদাহরণ হিসেবে এই ফাংশনটি ধরা যাক:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

এখানে আমাদের একটি ফাংশন `lucky` আছে, যা একটি `Int` নেয় আর একটি `String` রিটার্ন করে।
আমরা ফাংশনটির জন্য দুটি প্যাটার্ন ডিফাইন করেছি, একটি `7` সংখ্যাটার সাথে মেলে, আর অন্যটি অন্য যেকোনো সংখ্যার সাথে। নাম যা খুশি হতে পারে (যতক্ষণ তা Haskell-এর নামকরণের রীতি মেনে চলে), তবে এখানে আমরা `x` ব্যবহার করেছি।
সংখ্যাটি `7` হলে ফাংশনটি `"Lucky number seven!"` রিটার্ন করবে, নাহলে `"Sorry, you're out of luck, pal!"` রিটার্ন করবে।
এখানে যে বিষয়টা লক্ষ্য করা জরুরি, সেটা হলো প্যাটার্নগুলো উপর থেকে নিচে পরীক্ষা করা হয়। তাই আমরা যদি প্যাটার্ন দুটোর ক্রম উল্টে দিতাম, ফাংশনটি সবসময় `"Lucky number seven!"` রিটার্ন করত।

### অ্যারের প্যাটার্ন

খুবই কমন একটি প্যাটার্ন হলো অ্যারের সাথে মেলানো, অর্থাৎ অ্যারেটির হেড ও টেল নিয়ে নেওয়া।
এটা হয় কারণ অ্যারে আসলে একটি লিঙ্কড অ্যারে।
এখানে একটি ফাংশনের উদাহরণ দেওয়া হলো, যা একটি অ্যারের হেড ও টেল রিটার্ন করে:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

এখানে আমাদের দুটি প্যাটার্ন আছে, একটি খালি অ্যারের সাথে মেলে, আর অন্যটি অন্তত একটি এলিমেন্ট আছে এমন অ্যারের সাথে।
কারণ অ্যারেটি খালি হলে আমাদের সেটার জন্য একটি কেস রাখতে হয়, নাহলে আমরা একটি রানটাইম এরর পাব।
অ্যারেটি খালি না হলে আমরা অ্যারের হেডের সাথে `x` আর টেলের সাথে `xs` মেলাতে পারি।
এটা করা হয় `:` (cons) অপারেটরের সাহায্যে, যা একটি অ্যারের সামনে একটি এলিমেন্ট যোগ করতে ব্যবহৃত হয়।
কিন্তু প্যাটার্ন ম্যাচিংয়ে এটি আমাদের একটি অ্যারেকে তার হেড ও টেলে ভেঙে ফেলার সুযোগ দেয়, অর্থাৎ একভাবে উল্টো কাজ করে।

`xs` হলো অ্যারের টেলের জন্য একটি কমন নাম, এটা বোঝায় যে এটি একটি অ্যারে। কিন্তু আপনি যদি নেস্টেড অ্যারে নিয়ে কাজ করেন, তাহলে `xss` ব্যবহার করে বোঝাতে পারেন যে এটি অ্যারের একটি অ্যারে।

### টাপলের প্যাটার্ন

অ্যারের মতোই, আমরা টাপলের সাথেও মেলাতে পারি।
এখানে একটি ফাংশনের উদাহরণ দেওয়া হলো, যা একটি টাপল নেয় আর প্রথম ও দ্বিতীয় এলিমেন্ট রিটার্ন করে:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

এখানে আমাদের একটি প্যাটার্ন আছে যা দুটি এলিমেন্টের একটি টাপলের সাথে মেলে। প্রথম এলিমেন্টটি `x` নামে আর দ্বিতীয় এলিমেন্টটি `y` নামে বাইন্ড হয়।

### ওয়াইল্ডকার্ড প্যাটার্ন

কখনো কখনো আমরা একটি ভ্যারিয়েবলের মান নিয়ে মাথা ঘামাতে চাই না, শুধু প্যাটার্নটির সাথে মেলাতে চাই।
এখানেই ওয়াইল্ডকার্ড প্যাটার্ন কাজে আসে, এটা বোঝানো হয় আন্ডারস্কোর `_` দিয়ে।

এখানে একটি ফাংশনের উদাহরণ দেওয়া হলো, যা একটি অ্যারের প্রথম এলিমেন্ট রিটার্ন করে:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

এখানে আমরা বলছি যে অ্যারেটির টেল আমাদের দরকার নেই, তাই আমরা ওটা উপেক্ষা করতে ওয়াইল্ডকার্ড প্যাটার্ন ব্যবহার করি।

### টাইপ প্যাটার্ন

আমরা টাইপের সাথেও মেলাতে পারি, এটা করা হয় সেই টাইপের কনস্ট্রাক্টর ব্যবহার করে।
আমরা টাইপ থেকে মানও বের করতে পারি, যেমনটা টাপলের ক্ষেত্রে করেছিলাম।

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

প্রথম প্যাটার্নে আমরা `Guest` কনস্ট্রাক্টরের সাথে মেলাই, আর দ্বিতীয় প্যাটার্নে আমরা `User` কনস্ট্রাক্টরের সাথে মেলাই এবং ভেতরের মানটিকে `name` নামে বাইন্ড করি।
