## এডিটর

### ফ্রি/ওপেন সোর্স

- [VS Code](https://code.visualstudio.com)

  VS Code একটি ওপেন সোর্স কোড এডিটর। TypeScript সেটআপ করার তথ্য [এখানে](https://code.visualstudio.com/docs/languages/typescript) পাবেন। Microsoft একইসঙ্গে VS Code আর TypeScript রক্ষণাবেক্ষণ করে, তাই এই ভাষার সঙ্গে VS Code বেশ ভালোভাবে কাজ করে এবং TypeScript-এর জন্য এটি একটি জনপ্রিয় এডিটর; VS Code কোনো বাড়তি কনফিগারেশন ছাড়াই TS সাপোর্ট করে। আসলে VS Code লেখা হয়েছে TypeScript দিয়েই!

  VS Code আর TS নিয়ে একটি কমন সমস্যা হলো, আপনার এডিটর আর প্রজেক্টের ভার্সন আলাদা হলে VS Code সম্ভবত বিভ্রান্তিকর একটি এরর মেসেজ দেখাবে। এই এরর সামলানোর নির্দেশনা [এখানে](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### লাইসেন্সকৃত

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text একটি জনপ্রিয় কোড এডিটর, যা ইনস্টলযোগ্য প্লাগইনের মাধ্যমে বেশিরভাগ ভাষা সাপোর্ট করে। এটি চেষ্টা করে দেখার জন্য ফ্রি, তবে লাইসেন্স কেনার জন্য নিয়মিত অনুরোধ দেখতে পাবেন, যার দাম এখন \$70 USD।

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm একটি পূর্ণাঙ্গ JavaScript/TypeScript IDE (ইন্টিগ্রেটেড ডেভেলপমেন্ট এনভায়রনমেন্ট)। এটি কোনো বাড়তি কনফিগারেশন ছাড়াই TypeScript সাপোর্ট করে এবং এতে টেস্টিং, ডিবাগিং আর কোড অ্যানালাইসিস সমন্বিত আছে। ৩০ দিন ফ্রি চেষ্টা করা যায়, এরপর বার্ষিক লাইসেন্সের দাম প্রথম বছরে \$129 USD।
