# অ্যারে

PHP-তে অ্যারে হলো অর্ডারড ম্যাপ।
ম্যাপ হলো এমন একটি ডেটা স্ট্রাকচার, যা একটি কী (key)-এর সাথে একটি মান যুক্ত করে।
অ্যারে বহুমুখী, এবং এটিকে লিনিয়ার অ্যারে (`C` বা `Java`-এর মতো), অ্যারে [ভেক্টর], হ্যাশ টেবিল, ডিকশনারি, কালেকশন, স্ট্যাক বা কিউ হিসেবেও ব্যবহার করা যায়।

কী (key) ঐচ্ছিক, তবে উল্লেখ করা হলে সেটি অবশ্যই `int` অথবা `string` হতে হবে।
কোনো কী (key) না দিলে PHP ডিফল্টভাবে `0` থেকে শুরু করে ক্রমবর্ধমান ইন্টিজার কী (key) ব্যবহার করে।

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

একটি অ্যারে সব ধরনের মান সংরক্ষণ করতে পারে।
প্রতিটি মানের টাইপ ভিন্ন হতে পারে।

## অ্যারের ব্যবহার

অ্যারে লিটারাল হিসেবে ডিক্লেয়ার করা যায় (উপরের মতো কোডে লেখা), অথবা ফাংশনের মাধ্যমে তৈরি ও ম্যানিপুলেট করা যায়।
ইনডেক্স অপারেটর দিয়ে মান অ্যাক্সেস, অ্যাসাইন ও অ্যাপেন্ড করা যায়:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
