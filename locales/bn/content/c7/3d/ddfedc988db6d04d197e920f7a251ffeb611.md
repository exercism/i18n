Raku-তে কোড ব্লক প্রচুর পরিমাণে ব্যবহৃত হয়।
এগুলো ফাংশনের জন্য মৌলিক, তবে `grep` আর `map`-এর মতো টুলেও, `if`, `for`, `while` ও `given` স্টেটমেন্টের ব্লক হিসেবে, এমনকি অ্যারের সাবস্ক্রিপ্ট হিসেবেও।

## রুটিন

Raku-তে [`Subs`][type/Sub] এবং [`Methods`][type/Method] হলো [`Routines`][type/Routine]-এর টাইপ।

[`return`][control-return] কিওয়ার্ড ব্যবহার করে রুটিন যেকোনো সময় একটি রিটার্ন ভ্যালু নিয়ে শেষ হতে পারে, যা ফাংশন তৈরির জন্য দারুণ একটি হাতিয়ার।
কোনো `return` উল্লেখ না থাকলে রুটিনের শেষ স্টেটমেন্টটিই তার অন্তর্নিহিত রিটার্ন ভ্যালু হবে।

একটি রুটিনের কোড ব্লকের আগে প্রথম বন্ধনীর ভিতরে একটি [`Signature`][language/signatures] থাকতে পারে।

[`Routine`][type/Routine] হলো [`Block`][type/Block]-এর একটি সাবক্লাস।

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

মেথড নিয়ে ক্লাস ও অবজেক্ট সংক্রান্ত আলাদা একটি কনসেপ্টে আলোচনা করা হবে।

## ব্লক

একটি [`Block`][type/Block] হলো পুনরায় ব্যবহারযোগ্য একটি কোড অবজেক্ট, যা সাধারণত ল্যাম্বডা তৈরিতে ব্যবহৃত হয়।

ব্লকের শেষ স্টেটমেন্টটিই তার অন্তর্নিহিত রিটার্ন ভ্যালু।

কোড ব্লকের আগে `->` দিয়ে শুরু হওয়া একটি [`Signature`][language/signatures] থাকতে পারে।

[`Block`][type/Block] হলো [`Code`][type/Code]-এর একটি সাবক্লাস, যা Raku-তে সব কোড অবজেক্টের মূল বেস ক্লাস।

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## সিগনেচার

একটি [`Signature`][language/signatures] শূন্য বা তার বেশি [`Parameters`][type/Parameter] দিয়ে গঠিত, যেগুলো কমা দিয়ে আলাদা করা থাকে।

সিগনেচারের শেষে [রিটার্ন টাইপ অ্যারো][signatures-return-type-arrow] `-->` দিয়ে একটি রিটার্ন টাইপ উল্লেখ করা যায়।

কোনো `Block` কী কী আর্গুমেন্ট নেবে তা উল্লেখ করতে সিগনেচার ব্যবহার করা যায়।

এই কনসেপ্টে সিগনেচার সহজ রাখা হয়েছে: শুধু স্কেলার-সিগিলযুক্ত ভ্যারিয়েবলের পজিশনাল প্যারামিটার আর একটি রিটার্ন টাইপ ব্যবহার করা হয়েছে।
এগুলো নিয়ে অন্য কনসেপ্টে আরও বিস্তারিত আলোচনা করা হবে।

## মাল্টি-ডিসপ্যাচ

`multi` কিওয়ার্ড ব্যবহার করে Raku-তে একই নাম কিন্তু ভিন্ন সিগনেচারের একাধিক রুটিন লেখা যায়।
এই সুবিধাটিকে বলা হয় [মাল্টি-ডিসপ্যাচ][multi-dispatch]।
রুটিন নাম ধরে কল করা হলে রানটাইম এনভায়রনমেন্ট উপযুক্ত প্রার্থীটি নির্ধারণ করে সেটিই চালু করে।

টাইপ নিয়ে একটি কনসেপ্টে এটি আরও বিস্তারিতভাবে আলোচনা করা হবে।

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## হোয়াটএভারকোড

বেশিরভাগ অপারেটরের সঙ্গে [`Whatever`][type/Whatever] স্টার `*` একত্রে ব্যবহার করলে একটি [`WhateverCode`][type/WhateverCode] অবজেক্ট তৈরি হয়।
এতে আপনি আরও সহজ সিনট্যাক্সে ব্লক তৈরি করতে পারেন।

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
