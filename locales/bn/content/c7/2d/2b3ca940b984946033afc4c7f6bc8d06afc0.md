# নির্দেশনা সংযোজন

Python ট্র্যাকের ক্ষেত্রে এই অনুশীলনীতে আপনাকে একটি `SpaceAge` _ক্লাস_ (_[concept:python/classes]()_) তৈরি করতে বলা হয়েছে, যেখানে সৌরজগতের সব গ্রহের জন্য মেথড থাকবে।
মেথডগুলোর নামকরণে `on_<planet name>` রীতি অনুসরণ করতে হবে।

প্রতিটি মেথড বছর হিসেবে বয়স (_ওই গ্রহে_) `return` করবে, দুই দশমিক স্থান পর্যন্ত রাউন্ড করা:

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
