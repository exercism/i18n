# পরিচিতি

Elm-এর মতো খাঁটি ফাংশনাল ভাষায় একই আর্গুমেন্ট দিয়ে কল করা একটি ফাংশনকে সবসময় একই মান রিটার্ন করতে হয়। তাই `rand : Int` টাইপ সিগনেচারযুক্ত একটি ফাংশন কেবল (`rand = 4`)[xkcd-random] হিসেবেই ইমপ্লিমেন্ট করা যায়, যা থেকে র‍্যান্ডম ইন্টিজার তৈরি করার বিষয়ে ভালো কিছু আশা করা যায় না।

তাহলে Elm-এ আমরা কীভাবে র‍্যান্ডম মান তৈরি করি? আমরা সমস্যাটিকে দুই ভাগে ভাগ করি: প্রথমে `Random.Generator a` দিয়ে আমরা বোঝাই কোন মানটি তৈরি করতে চাই, তারপর একটি মান তৈরি করি।

মান তৈরি করার প্রথম উপায় হলো `initialSeed : Int -> Seed`-এর মাধ্যমে একটি `Random.Seed` তৈরি করা। `Seed` হলো একটি অস্বচ্ছ টাইপ, যা একটি ইন্টিজার ধারণ করে এবং সেই ইন্টিজারটিকে এমনভাবে রূপান্তর করতে জানে যা দেখতে র‍্যান্ডম মনে হবে (যাকে সিউডো-র‍্যান্ডম বলা হয়)। একবার `Seed` হাতে এলে আপনি সেটি দিয়ে `Generator a` ব্যবহার করে একটি মান তৈরি করতে পারেন। `Generator a`-ও একটি অস্বচ্ছ টাইপ, যা জানে কীভাবে সিডের ভেতরের ইন্টিজারটি ব্যবহার করে `a` টাইপের একটি সিউডো-র‍্যান্ডম মান এবং হালনাগাদ করা ইন্টিজারসহ একটি নতুন সিড তৈরি করতে হয়।

একটি মান তৈরি করতে আমরা `step : Generator a -> Seed -> ( a, Seed )` ব্যবহার করতে পারি, যা একটি মান এবং একটি নতুন সিড রিটার্ন করে, যেটি দিয়ে আমরা আরও মান তৈরি করতে পারি।

চলুন এই ফাংশনগুলো ব্যবহার করে একটি জেনারেটর থেকে `n`-টি র‍্যান্ডম মান বের করে আনি:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

মনে রাখবেন, এই ফাংশনগুলো সবই খাঁটি, তাই একই আর্গুমেন্ট দিয়ে দুবার কল করলে একই মান পাওয়া যাবে।

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

মান তৈরি করার দ্বিতীয় উপায় হলো `Random.generate : (a -> msg) -> Generator a -> Cmd msg` ব্যবহার করা, তবে এটি কেবল একটি Elm অ্যাপ্লিকেশনের ভেতরে করাই সম্ভব। সেক্ষেত্রে Elm-এর রানটাইম সিড তৈরি করতে `step`-এর পাশাপাশি বাইরের, খাঁটি নয় এমন রিসোর্সও ব্যবহার করতে পারে, আর একই ফাংশন দুবার কল করলে ভিন্ন ফলাফল আসবে।

এখন থেকে আমরা জেনারেটর নিয়েই আলোচনা করব।

`Random` মডিউল নির্দিষ্ট একটি সীমার মধ্যে ইন্টিজার ও ফ্লোট তৈরির জন্য দুটি মৌলিক জেনারেটর দেয়:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

সেই মানগুলোকে টাপল বা মানের অ্যারে হিসেবে একত্র করা যায়:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

(`elm-community/random-extra`)[random-extra] প্যাকেজটি নানা ধরনের ডেটা স্ট্রাকচারের জন্য আরও অনেক জেনারেটর দেয়: স্ট্রিং, তারিখ, ডিকশনারি, অ্যারে, সেট ইত্যাদি।

`Random.constant` ব্যবহার করে আমরা এমন জেনারেটর বানাতে পারি যা কেবল একটি মানই রিটার্ন করবে:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform` ব্যবহার করে আমরা দেওয়া এলিমেন্টগুলোর মধ্য থেকে সমান সম্ভাবনায় র‍্যান্ডমভাবে বেছে নিতে পারি:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` দুটি আর্গুমেন্ট (`Red` এবং `[Green, Blue]`) নেয়, যাতে বেছে নেওয়ার জন্য অন্তত একটি মান থাকা নিশ্চিত হয়, কারণ একটি একক অ্যারে খালি থাকতে পারে।

`Random.weighted` ব্যবহার করে আমরা সম্ভাবনাগুলো একটু বদলে দিতে পারি:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

মানগুলো যোগ করে ১০০ হতে হবে না, সেগুলো যেভাবেই হোক আবার নরমালাইজ হয়ে যাবে।

`Random.map` দিয়ে আমরা একটি জেনারেটরের ভেতরে পৌঁছাতে পারি:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

একাধিক জেনারেটর একত্র করতে আমরা `Random.map2` থেকে শুরু করে `Random.map5` পর্যন্ত ব্যবহার করতে পারি:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

আরও জটিল কাজের জন্য আছে `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, যা একটি জেনারেটরের তৈরি করা মান ব্যবহার করে আরেকটি জেনারেটর বানাতে পারে:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

মাঝে মাঝে একটি জেনারেটরকে নিজে নিজেকেই রিকার্সিভভাবে ডিফাইন করা কাজে লাগে। সেক্ষেত্রে কম্পাইলার যেন জেনারেটরটিকে অসীমভাবে আনরোল করতে না পারে, সেজন্য `Random.lazy` ব্যবহার করা লাগতে পারে।

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

এই উদাহরণটি একটু ভারী, তাই চলুন এটিকে ভেঙে দেখি।

`Peano` হলো একটি টাইপ, যা ধনাত্মক ইন্টিজার বোঝায়: `Zero` মানে ০, `Next(Zero)` মানে ১, `Next(Next(Zero))` মানে ২, ইত্যাদি। আমরা `peano` ডিফাইন করেছি যাতে এটি আমাদের একটি র‍্যান্ডম `Peano` সংখ্যা দেয়।

প্রথমেই মনে রাখবেন, `Random.lazy` লজিকের সাথে নতুন কিছু যোগ করে না, এটি কেবল কম্পাইলারকে `peano`-কে অনির্দিষ্টকালের জন্য `peano`-র ভেতরে লিখে ফেলা থেকে বিরত রাখে।

আমরা `Random.uniform` ব্যবহার করে শূন্য (৫০% সম্ভাবনায়) আর আরেকটি `Peano` সংখ্যার সাথে এক যোগ করা মান (৫০% সম্ভাবনায়) এর মধ্যে একটি বেছে নিই। তবে আগের উদাহরণের মতো নয়, এখানে `Random.uniform` মান (যেমন `Zero`) থেকে নয়, বরং জেনারেটর (যেমন `Random.constant Zero`) থেকে বেছে নিচ্ছে, কারণ আমরা `peano`-কে নিজেকেই ব্যবহার করতে চাই। এর মানে `Random.uniform` এমন একটি মান রিটার্ন করবে যার টাইপ `Generator (Generator Peano)`, যা আমাদের দরকার নয়।

জেনারেটরটিকে "ফ্ল্যাট" করতে আমরা এটিকে `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`-এ পাইপ করি, যেখানে আমরা চাই `b` হবে `Peano`। যেহেতু `Generator a` হলো `Generator (Generator Peano)`, তাই `a` অবশ্যই `Generator Peano` হবে, আর `(a -> Generator b)` ফাংশনটির টাইপ হবে `(Generator Peano -> Generator Peano)`। আমরা কিছুই বদলাতে চাই না, তাই `identity`-ই সঠিক পছন্দ।

সবশেষে, `peano` কী ধরনের সংখ্যা তৈরি করবে? আমরা জানি এটি ৫০% ক্ষেত্রে ০ তৈরি করবে, আর ৫০% ক্ষেত্রে নিজের আরেকবার ইটারেশনের সাথে এক যোগ করা মান তৈরি করবে। অর্থাৎ সংখ্যাগুলো হবে ০ (৫০% ক্ষেত্রে), ১ (২৫% ক্ষেত্রে), ২ (১২% ক্ষেত্রে), ৩ (৬% ক্ষেত্রে), ইত্যাদি। `peano` ইচ্ছেমতো বড় সংখ্যা তৈরি করতে পারে, তবে সম্ভাবনা সূচকীয় হারে কমতে থাকে।
