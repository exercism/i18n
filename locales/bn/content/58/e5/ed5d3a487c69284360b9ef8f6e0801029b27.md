Markdown ডকুমেন্টে আপনি নিজেই এই উইজেটগুলো রেন্ডার করতে চাইতে পারেন, যেমন কোনো ডকুমেন্টের শেষে বাড়তি পড়ার পরামর্শ দিতে বা কিছু শেখার জন্য ভালো অনুশীলনী সাজেস্ট করতে।

**নোট:** ইনলাইন টেক্সটের জন্য আপনি সাধারণ লিংকও ব্যবহার করতে পারেন, যেগুলোতে টুলটিপ যোগ হয়ে যাবে। আরও বিস্তারিত জানতে [ইন্টারনাল লিংকিং ডকুমেন্টেশন](/docs/building/markdown/internal-linking) দেখুন।

## ব্যবহার

Markdown ব্যবহার করা যায় এমন সব জায়গাতেই উইজেট ব্যবহার করা যায়, যেমন ডকুমেন্টেশন, অ্যাপ্রোচ এবং শিক্ষার্থী/মেন্টর আলোচনায়।

এগুলো নিচের ফরম্যাটে রেন্ডার হয়:

```md
[<type>:<id>]()
```

`<type>` আর `<id>` অংশগুলো পরিবর্তনশীল এবং কোন উইজেট ব্যবহার হচ্ছে তার উপর নির্ভর করে।

লিংক রেফারেন্স, অর্থাৎ `()`-এর ভেতরের অংশ, ওয়েবসাইট উপেক্ষা করে। রক্ষণাবেক্ষণের সুবিধার জন্য আপনি সেগুলোকে আপনার ইচ্ছেমতো যেকোনো জায়গায় নির্দেশ করাতে পারেন।

## অনুশীলনী উইজেট

লিংক ফরম্যাট: `[exercise:<track-slug>/<exercise-slug>]()`

### উদাহরণ

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## কনসেপ্ট উইজেট

লিংক ফরম্যাট: `[concept:<track-slug>/<concept-slug>]()`

### উদাহরণ

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## অ্যাপ্রোচ উইজেট

লিংক ফরম্যাট: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### উদাহরণ

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```
