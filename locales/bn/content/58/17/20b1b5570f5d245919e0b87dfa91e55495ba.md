# অপ্রত্যাশিত আবশ্যক প্যারামিটার

টেস্টগুলোতে `${'parameter.name'}` প্যারামিটারটি কখনো মান দিয়ে, আবার কখনো মান ছাড়া কল করা হয়, কিন্তু এটিকে _অপশনাল হিসেবে চিহ্নিত করা হয়নি_, যার মানে হলো টেস্টগুলো পাস করবে না। TypeScript-এ একটি প্যারামিটারকে `?` পোস্টফিক্স দিয়ে স্পষ্টভাবে অপশনাল হিসেবে চিহ্নিত করা যায়:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

অথবা, বিকল্পভাবে, একটি ডিফল্ট মান অ্যাসাইন করে:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
