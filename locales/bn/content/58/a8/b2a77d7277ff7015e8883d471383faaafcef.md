# ভূমিকা

Erlang বা JavaScript-এর মতো অন্য ভাষায় সংজ্ঞায়িত ডেটা টাইপ বোঝাতে এক্সটার্নাল টাইপ ব্যবহার করা যায়।

একটি এক্সটার্নাল ফাংশন ডিফাইন করতে একটি টাইপ ডিক্লেয়ার করুন কিন্তু কোনো কনস্ট্রাক্টর দেবেন না। এটিকে তখন অন্য যেকোনো টাইপের মতোই ব্যবহার করা যায়।

```gleam
pub type OrderedDictionary(element)
```
