# ভূমিকা

সাধারণভাবে প্রোগ্রামিংয়ের ক্ষেত্রে আপনি চাকা নতুন করে আবিষ্কার করতে চাইবেন না।
অনেক স্ট্যান্ডার্ড অ্যালগরিদমের জন্যই এমন কেউ থাকবেন, যিনি হয়তো আপনার কাজটা আগেই করে রেখেছেন।

## ইনক্লুড

অন্য ফাইলের কনটেন্ট ইনক্লুড করতে C++ `include` ডিরেক্টিভ ব্যবহার করে।
এই ইনক্লুডগুলো ফাইলের একেবারে উপরে লেখা উচিত।
কম্পাইলেশনের সময় ডিরেক্টিভসহ ওই লাইনটির জায়গায় সংশ্লিষ্ট ফাইলের কনটেন্ট বসে যায়।
ইনক্লুডের পর নেমস্পেসগুলো মূল ফাইলে যেমন ছিল ঠিক তেমনই থাকে।

## স্ট্যান্ডার্ড লাইব্রেরি

স্ট্যান্ডার্ড লাইব্রেরিতে অনেক কমন ফাংশন, অ্যালগরিদম আর ডেটা স্ট্রাকচার আছে।
স্ট্যান্ডার্ড লাইব্রেরি `std` নেমস্পেস ব্যবহার করে।

এর একটি উদাহরণ হলো C-এর নিউমেরিক লাইব্রেরি `cmath`।
এতে অনেক কমন গাণিতিক অপারেশন পাওয়া যায়।

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
স্ট্যান্ডার্ড লাইব্রেরি ডাবল কোট `"` -এর বদলে অ্যাঙ্গেলড ব্র্যাকেট `<>` দিয়ে ইনক্লুড করা হয়।
পার্থক্যটা খোঁজার জায়গায়, অর্থাৎ কম্পাইলার সংশ্লিষ্ট ফাইলগুলো কোথায় খুঁজবে তার মধ্যে।
অ্যাঙ্গেলড ব্র্যাকেটের বেলায় বর্তমান প্রজেক্টে খোঁজা বাদ দেওয়া হয়, আর সরাসরি সিস্টেমের include ডিরেক্টরিতে খোঁজা শুরু হয়।
আপনি যদি লোকাল ফাইল ইনক্লুড করতে চান, তাহলে ডাবল কোট ব্যবহার করবেন: `#include "myfile"`
