# নির্দেশাবলি

Ozan একটি নিখুঁত মিক্সটেপ তৈরি করছেন: প্রথমে ঠিক করছেন *কোন* গানগুলো বাছাই হবে, তারপর ঠিক করছেন সেগুলো *কোন ক্রমে* বাজবে। `mixtape-maker` শব্দভান্ডারে তাঁর এই পছন্দগুলোর পেছনে থাকা সমাবেশ ও বিন্যাসের সহায়ক ফাংশনগুলো আপনি তৈরি করবেন।

## 1. সমাবেশ গণনা করুন

`count-combinations` ডিফাইন করুন যাতে এটি রিটার্ন করে, ক্রম বিবেচনা না করে `n` থেকে `k` সংখ্যক জিনিস কত উপায়ে বাছাই করা যায় তার সংখ্যা।

```factor
5 2 count-combinations .
! => 10
```

## 2. বিন্যাস গণনা করুন

`count-permutations` ডিফাইন করুন যাতে এটি রিটার্ন করে, ক্রম গুরুত্বপূর্ণ হলে `n` থেকে `k` সংখ্যক জিনিস কত উপায়ে বাছাই করা যায় তার সংখ্যা।

```factor
5 2 count-permutations .
! => 20
```

## 3. সমাবেশের তালিকা তৈরি করুন

`list-combinations` ডিফাইন করুন যাতে এটি একটি সিকোয়েন্সের `k` সংখ্যক এলিমেন্টের সব সমাবেশ রিটার্ন করে।

```factor
{ 1 2 3 } 2 list-combinations .
! => { { 1 2 } { 1 3 } { 2 3 } }
```

## 4. বিন্যাসের তালিকা তৈরি করুন

`list-permutations` ডিফাইন করুন যাতে এটি একটি সিকোয়েন্সের সব বিন্যাস রিটার্ন করে।

```factor
{ 1 2 } list-permutations .
! => { { 1 2 } { 2 1 } }
```

## 5. যেসব সমাবেশের যোগফল একটি টার্গেটের সমান

`combinations-summing-to` ডিফাইন করুন যাতে এটি একটি সিকোয়েন্সের শুধু সেই `k`-সমাবেশগুলো রিটার্ন করে, যেগুলোর এলিমেন্টগুলোর যোগফল ঠিক `target` হয়।

```factor
{ 1 2 3 4 } 2 5 combinations-summing-to .
! => { { 1 4 } { 2 3 } }
```
