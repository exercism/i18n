# পরিচিতি

[গার্ড][guards] ব্যবহার করা হয় [প্যাটার্ন ম্যাচিংয়ের][exercism-pattern-matching] পরিপূরক হিসেবে। এটি আমরা পরের একটি কনসেপ্টে দেখব।
গার্ডের সাহায্যে আমরা ইনপুটের মানের উপর নির্ভর করে একটি ফাংশনের একাধিক ভিন্ন ইমপ্লিমেন্টেশন রাখতে পারি।
এর ফলে আরও জটিল চেক করা সম্ভব হয়।

একটি গার্ড স্টেটমেন্ট গঠিত হয় একটি পাইপ `|`, তারপর একটি বুলিয়ান এক্সপ্রেশন, আর শেষে একটি সমান চিহ্ন `=` ও ফাংশনের বডি দিয়ে।
একটি ফাংশনের জন্য একাধিক গার্ড স্টেটমেন্ট থাকতে পারে।
গার্ড স্টেটমেন্টগুলো উপর থেকে নিচে মূল্যায়ন করা হয়, আর সবার আগে যে স্টেটমেন্টটি `True` হয় সেটিই চালানো হয়।
একটি গার্ড স্টেটমেন্টে `otherwise` স্টেটমেন্টও রাখা যায়, যা আগের গার্ড স্টেটমেন্টগুলোর সাথে মেলে না এমন যেকোনো মানকে ধরে ফেলে।

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

আমরা নিজেদের একটি ফাংশনও ডিফাইন করে সেটি গার্ড স্টেটমেন্টের ভেতরে ব্যবহার করতে পারি।

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
