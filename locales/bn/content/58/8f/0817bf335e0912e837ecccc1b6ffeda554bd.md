# সম্পর্কে

[D](https://dlang.org) একটি সিস্টেমস প্রোগ্রামিং ভাষা, যার সিনট্যাক্স C-এর মতো এবং টাইপিং স্ট্যাটিক। এটি দক্ষতা, নিয়ন্ত্রণ ও মডেলিং ক্ষমতার সঙ্গে নিরাপত্তা এবং প্রোগ্রামারের উৎপাদনশীলতার মেলবন্ধন ঘটায়। D সংস্করণ ২ থেকে ভাষাটি মূলত [ওয়াল্টার ব্রাইট](https://en.wikipedia.org/wiki/Walter_Bright) এবং [আন্দ্রেই আলেকজান্দ্রেস্কু](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) তৈরি করেছিলেন।

D অনেক বিচিত্র ভাষার কম্পাইলার তৈরি করার কয়েক দশকের অভিজ্ঞতার ফসল, আর এতে রয়েছে অসংখ্য [অনন্য বৈশিষ্ট্য](http://dlang.org/overview.html):

- চমৎকার মডেলিং ক্ষমতার জন্য হাই লেভেল কনস্ট্রাক্ট
- উচ্চ পারফরম্যান্সের কম্পাইলড ভাষা
- স্ট্যাটিক টাইপিং
- C++-এর বিবর্তন (ভুলগুলো ছাড়া)
- অপারেটিং সিস্টেম API ও হার্ডওয়্যারের সঙ্গে সরাসরি ইন্টারফেস
- বিদ্যুৎগতির কম্পাইল টাইম
- মেমরি-সেফ প্রোগ্রামিংয়ের সুযোগ (SafeD)
- রক্ষণাবেক্ষণযোগ্য, সহজে বোঝা যায় এমন কোড।
- শেখার সময় কম লাগে (C-এর মতো সিনট্যাক্স, Java ও অন্যগুলোর অনুরূপ)
- C অ্যাপ্লিকেশন বাইনারি ইন্টারফেসের সঙ্গে সামঞ্জস্যপূর্ণ
- মাল্টি-প্যারাডাইম (ইমপারেটিভ, স্ট্রাকচার্ড, অবজেক্ট ওরিয়েন্টেড, জেনেরিক, ফাংশনাল প্রোগ্রামিংয়ের বিশুদ্ধতা এবং এমনকি অ্যাসেম্বলি)
- বিল্ট-ইন এরর প্রতিরোধ (কনট্র্যাক্ট, ইউনিট টেস্ট)

[D Language Foundation](https://dlang.org/foundation.html) হলো সেই সংস্থা, যা D ভাষার উন্নয়ন ও প্রসারে নিবেদিত।
