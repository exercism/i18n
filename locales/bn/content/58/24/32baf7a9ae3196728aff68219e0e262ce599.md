# স্ট্রিং

`String` ডেটা টাইপ হলো UTF-8 হিসেবে এনকোড করা ক্যারেক্টারের একটি রৈখিক ক্রম। টেক্সট ডেটা সংরক্ষণ করার জন্য এটি কাজে লাগে।

## একটি স্ট্রিং তৈরি করা

`String::new()` বা `String::from()` অ্যাসোসিয়েটেড ফাংশন ব্যবহার করে একটি স্ট্রিং তৈরি করা যায়। অনেক টাইপেরই একটি `to_string` মেথড থাকে, যা দিয়ে স্ট্রিং তৈরি করা যায়, যেমন কোনো সংখ্যা থেকে।

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### `format!` ম্যাক্রো

ছোট ছোট ডেটা টাইপ থেকে বড় একটি স্ট্রিং তৈরি করা কমন একটি কাজ, তাই Rust-এ একটি সংক্ষিপ্ত উপায়ও আছে, যা `to_string` কল করার বিস্তারিত এড়িয়ে যায়: `format!` ম্যাক্রো। উদাহরণস্বরূপ, উপরের কম্পোজিট স্ট্রিংটি তৈরি করার কাজটি আমরা এভাবে সহজ করতে পারি:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## স্ট্রিং স্লাইস

স্ট্রিংয়ের সাথে স্ট্রিং স্লাইসের ঘনিষ্ঠ সম্পর্ক রয়েছে। স্ট্রিং স্লাইস হলো পরিচিত আকারের মেমোরির একটি অঞ্চলের প্রতি অপরিবর্তনীয় রেফারেন্স, যেখানে UTF-8 হিসেবে এনকোড করা ক্যারেক্টারের একটি রৈখিক ক্রম থাকে। ডিরেফারেন্স (`&`) অপারেটর দিয়ে ধার করে যেকোনো স্ট্রিংকে স্ট্রিং স্লাইসে রূপান্তর করা যায়। আর স্ট্রিং স্লাইসকে স্ট্রিংয়ে রূপান্তর করতে `to_string()` মেথড বা `String::from` দুটোই উপযুক্ত।

Rust কোডে একটি স্ট্রিং লিটারাল ডাবল কোটের ভেতরে লেখা হয়। এই স্ট্রিং লিটারালগুলো সবসময়ই স্ট্রিং স্লাইস, কারণ এগুলো প্রোগ্রামের এক্সিকিউটেবলের ভেতরের একটি অপরিবর্তনীয় মেমোরি অঞ্চলকে নির্দেশ করে।

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## একটি স্ট্রিং পরিবর্তন করা

স্ট্রিংয়ের সাথে একটি ক্যারেক্টার কনক্যাট করতে `push` মেথডটি ব্যবহার করুন। স্ট্রিংয়ের সাথে একটি স্ট্রিং স্লাইস কনক্যাট করতে `push_str` মেথড বা `+` অপারেটর ব্যবহার করুন।

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## স্ট্রিংয়ের ক্যারেক্টার অ্যাক্সেস করা

Rust স্ট্রিংগুলো UTF-8 এনকোড করা, তাই আলাদা আলাদা ক্যারেক্টার সব একই আকারের হয় না। সেই কারণে `String` ডেটা টাইপে কোনো ইনডেক্সিং অপারেটর (`[]`) নেই। স্ট্রিংয়ের সব ক্যারেক্টার বা নির্দিষ্ট কোনো ক্যারেক্টার অ্যাক্সেস করতে `chars()` মেথড ব্যবহার করা যায়। এটি স্ট্রিংয়ের প্রতিটি ক্যারেক্টারের ওপর ক্রমানুসারে ইটারেট করে।

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

## আরও

স্ট্রিং একটি সমৃদ্ধ ডেটা টাইপ, যার চারপাশে অনেক মেথড ও ম্যাক্রো তৈরি হয়েছে। স্ট্রিং যে সব মেম্বার মেথড ও সুবিধা দেয়, সেগুলোর জন্য [স্ট্যান্ডার্ড লাইব্রেরির ডকুমেন্টেশন](https://doc.rust-lang.org/std/string/struct.String.html) দেখে নিন।
