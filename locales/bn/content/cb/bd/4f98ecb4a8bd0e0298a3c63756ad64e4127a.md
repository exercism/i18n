# Luhn: একটি কাস্টম trait ব্যবহার

এই অনুশীলনীটি করার আগে আপনার সম্ভবত মূল Luhn অনুশীলনী এবং এর পরবর্তী অনুশীলনী, "Luhn: From trait ব্যবহার" করা উচিত।

মূল Luhn অনুশীলনীটি পেতে, রান করুন।

```shell
exercism download --exercise=luhn --track=rust
```

"Luhn: From trait ব্যবহার" অনুশীলনীটি পেতে, রান করুন।

```shell
exercism download --exercise=luhn-from --track=rust
```

মূল Luhn অনুশীলনীতে আপনি শুধু স্ট্রিং ভ্যালিডেট করেছিলেন, কিন্তু Luhn অ্যালগরিদম ইন্টিজারের ক্ষেত্রেও প্রয়োগ করা যায়।

"Luhn: From trait ব্যবহার" অনুশীলনীতে আপনি একটি From trait ইমপ্লিমেন্ট করেছিলেন, যার জন্য আপনার একটি Luhn struct তৈরি করাও প্রয়োজন ছিল।

শুধু ভ্যালিডেশনটি করার জন্য একটি struct তৈরি করার বদলে, যদি আপনি প্রিমিটিভগুলো (অর্থাৎ, String, u8, ইত্যাদি) নিজেই ভ্যালিডেট করতেন?

এই অনুশীলনীতে আপনি একটি কাস্টম [trait](https://doc.rust-lang.org/book/ch10-02-traits.html) তৈরি করবেন এবং ইমপ্লিমেন্ট করবেন, যা ভ্যালিডেশনটি সম্পন্ন করে।
