# নির্দেশাবলি

একজন দাবা অনুরাগী হিসেবে আপনি গেমটির নিজের একটি সংস্করণ লিখতে চান।
হ্যাঁ, অনলাইনে ইতিমধ্যেই দাবার অনেক ইমপ্লিমেন্টেশন পাওয়া যেতে পারে, কিন্তু আপনারটি হবে অনন্য!

আপনি একটি দাবার বোর্ড ইমপ্লিমেন্ট করা দিয়ে শুরু করবেন।

দাবার গেমটি খেলা হবে আট ঘর চওড়া ও আট ঘর লম্বা একটি বোর্ডে।
ঘরগুলো একটি অক্ষর ও একটি সংখ্যা দিয়ে চিহ্নিত করা হয়।

## 1. র‍্যাঙ্ক ও ফাইল রেঞ্জ ডিফাইন করুন

গেমটিকে বোর্ডের র‍্যাঙ্কগুলো সংরক্ষণ করতে হবে।
র‍্যাঙ্কগুলো বোর্ডের সারি, এবং এগুলো ১ থেকে ৮ পর্যন্ত নম্বর দেওয়া হয়।

গেমটিকে বোর্ডের ফাইলগুলোও সংরক্ষণ করতে হবে।
ফাইলগুলো বোর্ডের কলাম, এবং এগুলো A থেকে H পর্যন্ত অক্ষর দিয়ে চিহ্নিত করা হয়।

`ranks` ও `files` কনস্ট্যান্ট ডিফাইন করুন, যেগুলো যথাক্রমে র‍্যাঙ্ক ও ফাইলের রেঞ্জ সংরক্ষণ করে।

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. ঘরটি বৈধ কিনা যাচাই করুন

গেমটিকে যাচাই করতে হবে একটি ঘর বৈধ কিনা।
র‍্যাঙ্ক ও ফাইল যদি র‍্যাঙ্ক ও ফাইলের রেঞ্জের মধ্যে থাকে, তবে ঘরটি বৈধ।

`isValidSquare(rank:file:)` মেথড ডিফাইন করুন, যা `rank` ও `file` আর্গুমেন্ট নেয়, যেখানে `rank`-এ র‍্যাঙ্কের একটি `Int` এবং `file`-এ ফাইলের একটি `String` থাকে।
র‍্যাঙ্ক ও ফাইল যদি র‍্যাঙ্ক ও ফাইলের রেঞ্জের মধ্যে থাকে, তবে মেথডটি `true` রিটার্ন করবে, অন্যথায় `false` রিটার্ন করবে।

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. সারি বের করুন

গেমটি বোর্ডের সব ঘর একটি একমাত্রিক অ্যারেতে সংরক্ষণ করবে।
ঘরগুলো র‍্যাঙ্ক ও ফাইল মিলিয়ে তৈরি একটি স্ট্রিং, যেমন "1A", "8B", "4G" ইত্যাদি।
একটি ঘরের সারি পেতে গেমটিকে ওই সারির প্রথম ঘরের ইনডেক্স হিসাব করতে হবে।

`getRow(rank:)` মেথড ডিফাইন করুন, যা `rank` আর্গুমেন্ট নেয়, যেখানে র‍্যাঙ্কের একটি `Int` থাকে।
মেথডটি স্ট্রিংয়ের একটি অ্যারে রিটার্ন করবে, যেগুলো সারির ঘরগুলো প্রকাশ করে।

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
