# নির্দেশনা

আপনি Paola's Prestigious Pizza-এর নতুন রেস্টুরেন্ট ম্যানেজার হিসেবে যোগ দিতে পেরে উচ্ছ্বসিত। এই জায়গাটি কীভাবে দক্ষতার সাথে চালাবেন, তা নিয়ে আপনার অনেক পরিকল্পনা আছে, আর সেজন্য আপনার কিছু ডেটা দরকার। প্রথমেই আপনাকে মেনুটি বিশ্লেষণ করতে হবে।

মেনুতে নানা ধরনের পিৎজা আছে। Paola আপনাকে একটি টেক্সট ফাইলে একটি তালিকা দিয়েছেন, যেখানে প্রতি লাইনে একটি করে পিৎজা আছে। প্রতিটি পিৎজা এন্ট্রিতে তিনটি অংশ থাকে: তার নাম, একটি ঐচ্ছিক নিরামিষ নির্দেশক, আর একটি দাম।

## 1. পিৎজার দাম পার্স করা

আপনি মেনুর প্রথম কয়েকটি লাইন দেখেন:

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

দাম দিয়েই শুরু করা ভালো হবে বলে মনে হচ্ছে।
সব দামই ইউরো মুদ্রার পূর্ণসংখ্যা।

দামগুলো পার্স করতে `priceParser` ইমপ্লিমেন্ট করুন।
যেহেতু সব দাম ইউরোতে, তাই মুদ্রাটি আলাদা করে মনে রাখার দরকার নেই, তবে সেটিও আপনাকে পার্স করতে হবে।

```elm
Parser.run priceParser "8€"
    --> Ok 8
Parser.run priceParser "8"
    --> Err [{ problem = ExpectingSymbol "€", col = 2, row = 1 }]
```

## 2. নিরামিষ নির্দেশক পার্স করা

আপনি আবার মেনুর দিকে তাকান:

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

নিরামিষ নির্দেশক `"(v)"`-ও বেশ সহজ, তাই এবার সেটিই করবেন বলে ঠিক করেন!

নির্দেশকটি পার্স করতে `vegetarianParser` ইমপ্লিমেন্ট করুন।
পার্সারটির একটি `Bool` রিটার্ন করা উচিত, নির্দেশকটি থাকলে `True` আর না থাকলে `False`।

```elm
Parser.run vegetarianParser "(v)"
    --> Ok True
Parser.run vegetarianParser ""
    --> Ok False
```

## 3. পিৎজা ও উপাদানের নাম পার্স করা

ঠিক আছে, এরপর কী?

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

উপাদান আর পিৎজার নামগুলো বেশ সহজ মনে হচ্ছে: এগুলো সবই একটি একটি করে শব্দ, যা বড় হাতের আর ছোট হাতের ASCII ক্যারেক্টার দিয়ে তৈরি।

নামগুলো পার্স করতে `wordParser` ইমপ্লিমেন্ট করুন।
সেই সঙ্গে, একরকম রাখার জন্য সব শব্দ ছোট হাতের করে ফেলুন।

```elm
Parser.run wordParser "REGINA"
    --> Ok "regina"
Parser.run wordParser "tomato"
    --> Ok "tomato"
Parser.run wordParser "(v)"
    --> Ok ""
Parser.run wordParser ""
    --> Ok ""
```

## 4. উপাদানের একটি তালিকা পার্স করা

উপাদান অবশ্য দলবদ্ধভাবে আসে:

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```
এগুলো আলাদা আলাদা শব্দ, যা কমা আর সম্ভবত স্পেস দিয়ে আলাদা করা।

উপাদানগুলো পার্স করতে `ingredientsParser` ইমপ্লিমেন্ট করুন।

```elm
Parser.run ingredientsParser "tomato, emmental"
    --> Ok ["tomato", "emmental"]
Parser.run ingredientsParser "tomato"
    --> Ok ["tomato"]
```

## 5. সম্পূর্ণ পিৎজা পার্স করা

এখন আপনার কাছে সব উপাদান আছে, এবার কিছু `Pizza` বানানোর সময়!

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

প্রথমে থাকে পিৎজার নাম, ঐচ্ছিক নিরামিষ নির্দেশক, একটি কোলন `':'`, উপাদানের তালিকা, একটি ড্যাশ `'-'` আর দাম, মাঝেমধ্যে সম্ভাব্য স্পেস সহ।

সম্পূর্ণ পিৎজা পার্স করতে `pizzaParser` ইমপ্লিমেন্ট করুন।

```elm
Parser.run pizzaParser "Regina: tomato, ham, mushrooms, cantal - 11€"
    --> Ok (Pizza "regina" False ["tomato", "ham", "mushrooms", "cantal"] 11)
```

## 6. সম্পূর্ণ মেনু পার্স করা

এবার পার্টির সময়!

টেক্সট ফাইলে নিউলাইন ক্যারেক্টার `'\n'` দিয়ে আলাদা করা সব পিৎজার একটি তালিকা পার্স করতে `menuParser` ইমপ্লিমেন্ট করুন।
পার্সারটি ফাইলের শেষ পর্যন্ত চালিয়ে আপনি যেন সব পিৎজা পান, তা নিশ্চিত করুন।

```elm
Parser.run menuParser "Regina: tomato, ham, mushrooms, cantal - 11€\nFormaggio (v): tomato, emmental - 8€"
    --> Ok [Pizza "regina" False ["tomato", "ham", "mushrooms", "cantal"] 11,
    --      Pizza "formaggio" True ["tomato", "emmental"] 8]
Parser.run menuParser "Regina: tomato, ham, mushrooms, cantal - 11€\[END]"
    --> Err [{ problem = ExpectingEnd, col = 1, row = 2 }]
```

## 7. একাধিক শব্দের উপাদানের নাম পার্স করা

ওহো, মনে হচ্ছে আপনি কিছু একটা মিস করেছেন।
মেনুর আরও নিচে কোথাও কিছু উপাদান এক শব্দের নয়:

```
...
Tonno: tomato sauce, tuna - 10€
Hawaii: tomato sauce, fresh pineapple, ham - 9€
...
```

`oneIngredientParser` ইমপ্লিমেন্ট করুন, যা বড় হাতের ও ছোট হাতের ASCII ক্যারেক্টার অথবা স্পেস `' '` গ্রহণ করবে।
সেই সঙ্গে `wordParser`-এ থাকা একটি ছোট খুঁত এড়ানোর সুযোগ নিন: খালি স্ট্রিংকে যেন বৈধ উপাদান হিসেবে ধরা না হয়, তা নিশ্চিত করুন এবং বদলে `Problem "empty string"` এমিট করুন।
আর সেই সঙ্গে, স্ট্রিংগুলো ছোট হাতের করা এবং দুই পাশের হোয়াইটস্পেস ক্যারেক্টার ট্রিম করা নিশ্চিত করুন।

```elm
Parser.run oneIngredientParser "Tomato Sauce"
    --> Ok "tomato sauce"
Parser.run oneIngredientParser "   tomato sauce     "
    --> Ok "tomato sauce"
Parser.run oneIngredientParser ""
    --> Err [{ problem = Problem "empty string", col = 1, row = 1 }]
```

পার্সারটি ডিফাইন করা হয়ে গেলে, এটি `ingredientsParser`-এ ব্যবহার করুন।
