# Instructions

এই অনুশীলনীতে আপনি একটি ব্যাংকের পরিচালনায় ব্যবহৃত কিছু কনস্ট্যান্ট তৈরি করবেন।

আপনার পাঁচটি কাজ আছে:

## 1. ঋণের নির্দিষ্ট সুদের হার প্রকাশ করা

5% (5/100) এর মান ধরে রাখতে `FixedInterestRate` নামে একটি আনটাইপড নাম্বারিক কনস্ট্যান্ট তৈরি করুন, তারপর সেটি রিটার্ন করার জন্য `GetFixedInterestRate` ফাংশনটি ইমপ্লিমেন্ট করুন:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. এক বছরে দিনের সংখ্যা প্রকাশ করা

365 মানটি ধরে রাখতে `int` টাইপের `DaysPerYear` কনস্ট্যান্ট তৈরি করুন, তারপর সেটি রিটার্ন করার জন্য `GetDaysPerYear` ফাংশনটি ইমপ্লিমেন্ট করুন:

```go
GetDaysPerYear()
// => 365
```

## 3. বছরের মাসগুলি প্রকাশ করা

একটি ব্লকে Go-এর এনুমারেটর ব্যবহার করে বছরের মাসগুলোর জন্য 1 থেকে 12 পর্যন্ত মান ধরে রাখতে বারোটি আনটাইপড নাম্বারিক কনস্ট্যান্ট তৈরি করুন।
এগুলোর নাম দিন `Jan`, `Feb`, `Mar` ইত্যাদি, তারপর নির্দিষ্ট একটি মাসের মান রিটার্ন করার জন্য `GetMonth` ফাংশনটি ইমপ্লিমেন্ট করুন:

```go
GetMonth(Jan)
// => 1
```

## 4. একটি অ্যাকাউন্ট নম্বর প্রকাশ করা

XF348IJ মানটি ধরে রাখতে `AccountNo` নামে একটি আনটাইপড স্ট্রিং কনস্ট্যান্ট তৈরি করুন, তারপর সেটি রিটার্ন করার জন্য `GetAccountNumber` ফাংশনটি ইমপ্লিমেন্ট করুন:

```go
GetAccountNumber()
// => "XF348IJ"
```
