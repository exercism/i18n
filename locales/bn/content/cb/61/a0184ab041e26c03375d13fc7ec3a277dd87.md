# পরিচিতি

Python একটি [ডাইনামিক ও স্ট্রংলি টাইপড][dynamic typing in python] প্রোগ্রামিং ভাষা।
এটি [ডাক টাইপিং][duck typing] ও [গ্র্যাজুয়াল টাইপিং][gradual typing] দুটোই ব্যবহার করে, [টাইপ হিন্ট][type hints]-এর মাধ্যমে।
Python কোডের পাঠযোগ্যতার উপর বিশেষ জোর দেয় এবং (_Haskell-এর মতো_) ফাংশন, মেথড ও ক্লাস ডেফিনিশন বোঝাতে [সিগনিফিক্যান্ট ইনডেন্টেশন][significant indentation] ব্যবহার করে।

Python তৈরি করেছিলেন Guido van Rossum, এবং এটি প্রথম প্রকাশিত হয় ১৯৯১ সালে।

ইম্পারেটিভ, ডিক্লারেটিভ (যেমন ফাংশনাল) এবং অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং _স্টাইল_ সবই সমর্থিত, তবে ভেতরে ভেতরে **[Python-এ সবকিছুই একটি অবজেক্ট][everythings an object]**।

Python ট্র্যাকের কনসেপ্টগুলোতে এগোনোর সময় এসবের মানে নিয়ে আমরা আরও গভীরে যাব।

এই প্রথম কনসেপ্টটি (`basics`) Python ভাষার ৪টি প্রধান বৈশিষ্ট্য পরিচয় করিয়ে দেয়:
1.  নাম অ্যাসাইনমেন্ট (_ভ্যারিয়েবল ও কনস্ট্যান্ট_),
2.  ফাংশন (_`def` কিওয়ার্ড ও `return` কিওয়ার্ড_),
3.  কমেন্ট, এবং
4.  ডকস্ট্রিং।

<br>

## নাম অ্যাসাইনমেন্ট (ভ্যারিয়েবল ও কনস্ট্যান্ট)

প্রোগ্রামাররা অ্যাসাইনমেন্ট `=` অপারেটরের সাহায্যে যেকোনো ধরনের অবজেক্টের সাথে [_নাম_][facts-and-myths-about-python-names] (যাদের _ভ্যারিয়েবল_ও বলা হয়) যুক্ত করতে পারেন: `<name> = <value>`।
একটি নাম তার জীবদ্দশায় ভিন্ন ভিন্ন মানে (ভিন্ন অবজেক্ট টাইপে) পুনরায় অ্যাসাইন (বা পুনরায় বাইন্ড) করা যায়:


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### কনস্ট্যান্ট

কনস্ট্যান্ট হলো এমন নাম, যা একটি প্রোগ্রামে একবারই অ্যাসাইন করার কথা। তবে Python পুনরায় অ্যাসাইন করা আটকায় না।
`SCREAMING_SNAKE_CASE` ব্যবহার করলে কোড পড়ছে যে কেউ বুঝতে পারে, নামটি **পুনরায় অ্যাসাইন করা উচিত নয়**, বা তার মান পরিবর্তন করা উচিত নয়।
কনস্ট্যান্ট সাধারণত [মডিউল][module] (ফাইল) স্তরে ডিফাইন করা উচিত, এবং এগুলো সাধারণত একটি প্রোগ্রামের সব ফাংশন ও ক্লাসের কাছেই দৃশ্যমান থাকে।



## ফাংশন

`def` কিওয়ার্ড একটি [ফাংশন ডেফিনিশন][function definition] শুরু করে।
প্রতিটি ফাংশনে `()` বন্ধনীর মধ্যে শূন্য বা তার বেশি আনুষ্ঠানিক [প্যারামিটার][parameters] থাকতে পারে, যার পরে থাকে একটি `:` কোলন।
ফাংশনের _বডি_-র স্টেটমেন্টগুলো `def`-এর পরের লাইন থেকে শুরু হয় এবং অবশ্যই _একটি ব্লকে ইনডেন্ট করতে হবে_।


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


ফাংশন [`return`][return] কিওয়ার্ডের মাধ্যমে _স্পষ্টভাবে_ একটি মান বা অবজেক্ট রিটার্ন করে:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


যে ফাংশনে `return`-এর পরে _স্পষ্ট_ কোনো এক্সপ্রেশন থাকে না, সেটি _অন্তর্নিহিতভাবে_ [`None`][none] অবজেক্ট রিটার্ন করে।
`None`-এর বিস্তারিত আলোচনা হবে পরের কোনো কনসেপ্টে।
এই অনুশীলনী ও ব্যাখ্যার উদ্দেশ্যে `None` হলো একটি প্লেসহোল্ডার, যা কিছুই না, বা null বোঝায়:


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

যে ফাংশনে `return` বাদ দেওয়া হয়, সেটিও _অন্তর্নিহিতভাবে_ [`None`][none] অবজেক্ট রিটার্ন করে।
এর মানে হলো, আপনি যদি কোনো ফাংশনে `return` ব্যবহার না করেন, Python আপনার হয়ে `None` অবজেক্টটি রিটার্ন করবে।

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## কমেন্ট

Python-এ [কমেন্ট][comments] শুরু হয় `#` দিয়ে, যা কোনো স্ট্রিংয়ের অংশ নয়, এবং লাইন শেষ হলেই কমেন্টও শেষ হয়।
অন্য অনেক প্রোগ্রামিং ভাষার মতো নয়, Python **মাল্টি-লাইন কমেন্ট চিহ্ন সমর্থন করে না**।
কমেন্ট ব্লকের প্রতিটি লাইনই `#` ক্যারেক্টার দিয়ে শুরু করতে হবে।


## ডকস্ট্রিং

ফাংশনের বডির প্রথম স্টেটমেন্টটি ঐচ্ছিকভাবে একটি [_ডকস্ট্রিং_][docstring] হতে পারে, যা ফাংশন বা অবজেক্টের উদ্দেশ্য সংক্ষেপে বলে দেয়।
[Sphinx][sphinx]-এর মতো স্বয়ংক্রিয় ডকুমেন্টেশন টুল ডকস্ট্রিং পড়ে, আর ফাংশন, মেথড বা ক্লাসের নামে বিশেষ অ্যাট্রিবিউট `.__doc__` কল করলে ডকস্ট্রিংটি রিটার্ন হয়।
ডকস্ট্রিংয়ের সাধারণ রীতিনীতি বর্ণিত আছে [PEP257][pep257]-এ, তবে প্রকল্প ও দলভেদে সঠিক ফরম্যাট আলাদা হয়।
ডকস্ট্রিং ডিক্লেয়ার করা হয় ট্রিপল ডাবল কোট (""") দিয়ে, কোড ব্লকের সমান স্তরে ইনডেন্ট করে:
