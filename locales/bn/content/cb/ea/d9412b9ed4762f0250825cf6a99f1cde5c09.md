# কনট্রাক্ট

একটি রুটিনের আর্গুমেন্ট আর রিটার্ন টাইপ বলে দেয় যে ভেতরে কেমন *ধরনের* জিনিস ঢোকে আর বাইরে কেমন জিনিস বেরোয়। তবে তারা বলতে পারে না যে কোনো ওজন অবশ্যই ধনাত্মক হতে হবে, কিংবা কোনো হার্নেস কখনো নিজের কাছে থাকা ধারণক্ষমতার চেয়ে বেশি অবশিষ্ট ধারণক্ষমতা রিপোর্ট করবে না।

এসব কথা বলে **কনট্রাক্ট**, রুটিনের নিজের হেডারেই, যেখানে যে-ই এটি পড়বে সে-ই সেগুলো দেখতে পাবে।

## pre

`pre` বলে দেয় রুটিনটি কল করা হলে কী সত্য থাকতে হবে। এটি রিটার্ন টাইপ আর `is`-এর মাঝখানে বসে।

```sather
   spare_capacity(load : INT) : INT
      pre load >= 0
   is
      return limit - load;
   end;
```

এটি **কলারের** প্রতি একটি দাবি: ঋণাত্মক কোনো load দিয়ে এটি কল করবেন না।

## post

`post` বলে দেয় রুটিনটি উত্তর দেওয়ার সময় কী সত্য হবে। এর ভেতরে `result` হলো যে মানটি রিটার্ন করা হচ্ছে।

```sather
   percent_used(load : INT) : INT
      pre load >= 0
      post result >= 0
   is
      return load * 100 / limit;
   end;
```

এটি কলারের প্রতি একটি প্রতিশ্রুতি। দুটোই থাকা একটি রুটিন আসলে এক ধরনের দর: আমাকে এটা দিন, আমি আপনাকে ওটা দেব।

বেশ কিছু শর্ত `and` দিয়ে জুড়ে যায়, যেমনটা যেকোনো বুলিয়ান করে:

```sather
      pre load >= 0 and load <= limit
```

## কনট্রাক্ট কোনো এক্সেপশন নয়

উত্থাপিত এক্সেপশন হলো এমন কিছুর জন্য যা ঘটতে পারে। আর ভাঙা কনট্রাক্ট মানে একটি **bug**: কেউ রুটিনটি ভুলভাবে কল করেছে, নয়তো রুটিনটি যা বলেছিল সেটি করেনি।

তাই ভাঙা কনট্রাক্ট এমন কিছু উত্থাপন করে না যা ধরা যায়। কনট্রাক্ট চেকিং চালু থাকলে প্রোগ্রামটি থেমে যায় আর প্রিন্ট করে কোন রুটিন, আর কোন শর্ত। আর বন্ধ থাকলে শর্তটি তো পরীক্ষাই করা হয় না, প্রোগ্রামটি চলতে থাকে; এরপর যা-ই এলোমেলো কিছু ঘটুক না কেন।

এই কারণেই কনট্রাক্ট হলো সঠিকতা নিয়ে একটি বিবৃতি, খারাপ ইনপুট সামলানোর কোনো উপায় নয়। খারাপ ইনপুট প্রত্যাশিত হলে সেটি পরীক্ষা করুন আর `raise` করুন। আর খারাপ ইনপুট যদি বোঝায় কলারটিই ভাঙা, তাহলে `pre` দিয়ে সেটাই বলে দিন।

## কনট্রাক্ট চেকিং চালু করা

এই Sather কম্পাইলারকে `-chk` দিলে কনট্রাক্ট চেক করে:

```
sacomp -chk mine.sa -main MAIN -o mine
```

এটি ছাড়া `pre` আর `post` হলো কেবল ডকুমেন্টেশন, যা কম্পাইলার পড়েছে আর মেনে নিয়েছে যে সেটি সঠিকভাবে লেখা, এর বেশি কিছু নয়। এই অনুশীলনীর টেস্টগুলো `-chk` ছাড়াই তৈরি, তাই সেগুলো আপনার হয়ে ভাঙা কনট্রাক্ট ধরতে পারবে না; তারা যাচাই করে যে রুটিনগুলো সঠিকভাবে ব্যবহার করলে ঠিকঠাক কাজ করে।
