# নির্দেশনা

এই অনুশীলনীতে আপনি একটি রিমোট কন্ট্রোলড গাড়ি নিয়ে খেলবেন, যেটি কেনার জন্য অবশেষে যথেষ্ট টাকা জমিয়েছেন।

গাড়িগুলো সম্পূর্ণ (১০০%) চার্জযুক্ত ব্যাটারি নিয়ে শুরু করে। রিমোট কন্ট্রোল দিয়ে প্রতিবার গাড়ি চালালে এটি ২০ মিটার পথ চলে এবং ব্যাটারির এক শতাংশ কমিয়ে দেয়।

রিমোট কন্ট্রোলড গাড়িটিতে একটি দারুণ LED ডিসপ্লে আছে যেটি দুই টুকরো তথ্য দেখায়:

- এটি মোট যত দূরত্ব চালিয়েছে, তা এভাবে দেখানো হয়: `"Driven <METERS> meters"`।
- ব্যাটারিতে অবশিষ্ট চার্জ, যা এভাবে দেখানো হয়: `"Battery at <PERCENTAGE>%"`।

যদি ব্যাটারি ০% থাকে, তাহলে আপনি আর গাড়ি চালাতে পারবেন না এবং ব্যাটারি ডিসপ্লেতে `"Battery empty"` দেখাবে।

আপনার ছয়টি টাস্ক আছে, যার প্রতিটি রিমোট কন্ট্রোলড গাড়ির ইনস্ট্যান্স নিয়ে কাজ করবে।

## 1. একটি একেবারে নতুন রিমোট কন্ট্রোলড গাড়ি কিনুন

একটি একেবারে নতুন রিমোট কন্ট্রোলড গাড়ির ইনস্ট্যান্স রিটার্ন করার জন্য (_static_) `JedliksToyCar.buy()` মেথডটি ইমপ্লিমেন্ট করুন:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. চালানো দূরত্ব প্রদর্শন করুন

LED ডিসপ্লেতে যেভাবে দেখানো হয় সেভাবে দূরত্ব রিটার্ন করার জন্য `JedliksToyCar.distanceDisplay()` মেথডটি ইমপ্লিমেন্ট করুন:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. ব্যাটারির শতাংশ প্রদর্শন করুন

LED ডিসপ্লেতে যেভাবে দেখানো হয় সেভাবে ব্যাটারির শতাংশ রিটার্ন করার জন্য `JedliksToyCar.batteryDisplay()` মেথডটি ইমপ্লিমেন্ট করুন:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. গাড়ি চালানোর সময় চালানো মিটারের সংখ্যা আপডেট করুন

`JedliksToyCar.drive()` মেথডটি ইমপ্লিমেন্ট করুন যা চালানো মিটারের সংখ্যা আপডেট করে:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. গাড়ি চালানোর সময় ব্যাটারির শতাংশ আপডেট করুন

ব্যাটারির শতাংশ আপডেট করার জন্য `JedliksToyCar.drive()` মেথডটি আপডেট করুন:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. ব্যাটারি শেষ হলে গাড়ি চালানো ঠেকান

ব্যাটারি শেষ হয়ে গেলে (০%-এ) চালানো দূরত্ব যাতে না বাড়ে এবং ব্যাটারির শতাংশ যাতে না কমে, সেভাবে `JedliksToyCar.drive()` মেথডটি আপডেট করুন:

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
