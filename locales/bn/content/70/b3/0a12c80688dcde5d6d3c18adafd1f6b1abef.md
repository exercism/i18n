# নির্দেশনা

এই অনুশীলনীতে আপনি লগ-লাইন প্রসেস করবেন।

প্রতিটি লগ-লাইন একটি স্ট্রিং, যার ফরম্যাট এরকম: `"[<LEVEL>]: <MESSAGE>"`।

তিনটি ভিন্ন লগ লেভেল আছে:

- `INFO`
- `WARNING`
- `ERROR`

আপনার সামনে তিনটি কাজ আছে, প্রতিটিতে একটি লগ-লাইন নিয়ে সেটি দিয়ে কিছু একটা করতে বলা হবে।

## 1. একটি লগ-লাইন থেকে মেসেজ বের করুন

লগ-লাইনের মেসেজ রিটার্ন করার জন্য `message` ফাংশনটি ইমপ্লিমেন্ট করুন:

```julia-repl
julia> message("[ERROR]: Invalid operation")
"Invalid operation"
```

শুরুতে বা শেষে থাকা যেকোনো হোয়াইট স্পেস সরিয়ে ফেলতে হবে:

```julia-repl
julia> message("[WARNING]:  Disk almost full\r\n")
"Disk almost full"
```

## 2. একটি লগ-লাইন থেকে লগ লেভেল বের করুন

লগ-লাইনের লগ লেভেল রিটার্ন করার জন্য `log_level` ফাংশনটি ইমপ্লিমেন্ট করুন, যেটি ছোট হাতের অক্ষরে রিটার্ন করতে হবে:

```julia-repl
julia> log_level("[ERROR]: Invalid operation")
"error"
```

## 3. একটি লগ-লাইন নতুন করে সাজান

লগ-লাইনটি নতুন করে সাজানোর জন্য `reformat` ফাংশনটি ইমপ্লিমেন্ট করুন, যেখানে মেসেজটি সবার আগে থাকবে আর তার পরে বন্ধনীর ভেতরে লগ লেভেলটি:

```julia-repl
julia> reformat("[INFO]: Operation completed")
"Operation completed (info)"
```

----

***নোট:***  এই অনুশীলনীর সব স্ট্রিং ইংরেজিতে আছে এবং ASCII ক্যারেক্টার সেটের মধ্যে সীমাবদ্ধ। পরবর্তী কনসেপ্টগুলোতে ইউনিকোড ক্যারেক্টার নিয়ে কাজ করার সুযোগ পাবেন।
