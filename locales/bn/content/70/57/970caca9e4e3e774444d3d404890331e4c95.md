# শেখা

Odin একটি সিস্টেমস প্রোগ্রামিং ভাষা।
C-এর মতো এখানেও প্রোগ্রামারকে মেমোরি নিজ হাতে সামলাতে হয়।
তবুও এটি বরং সহজ একটি ভাষা।

Odin শিখতে সাহায্য করার জন্য নিচের রিসোর্সগুলো রয়েছে:

ভাষাটির প্রথম স্বাদ নিতে:

* Odin-এর নির্মাতার উপস্থাপনায় [Introduction to Odin][video] দেখুন।
* ["Understanding the Odin Programming Language"][book] বইটির লেখকের লেখা [Introduction to Odin][intro] নিবন্ধটি পড়ুন।
* [ডেমো ফাইল][demo] মন দিয়ে দেখুন, যেখানে কোডে Odin-এর বিভিন্ন ধারণা দেখানো হয়েছে।

আরও গভীরে যেতে চাইলে:

* [Odin ভাষার ওভারভিউ][overview]।
* [অফিসিয়াল প্যাকেজগুলোর][packages] ডকুমেন্টেশন।
* ["Understanding the Odin Programming Language"][book] বইটি (ফ্রি নয়)।
* অফিসিয়াল ["Odin Examples"][examples] সংগ্রহ।
