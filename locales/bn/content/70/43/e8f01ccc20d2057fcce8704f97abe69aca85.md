# টেস্ট

বেশিরভাগ টেস্ট যাচাই করে যে, [result]-এ অ্যাসাইন করে বা [exit]-এ একটি মান পাস করে, আপনি প্রত্যাশিত মানটি রিটার্ন করেন।

কিছু টেস্ট যাচাই করে যে আপনি প্রত্যাশিত এক্সসেপশনটি [raise] করেন।

## টেস্ট চালানো

টেস্ট চালানোর জন্য `make` ইউটিলিটি একটি ডিপেন্ডেন্সি।

অনুশীলনীর ডিরেক্টরির ভেতরে থেকে কনসোল/টার্মিনালে টাইপ করুন:

```sh
make
```

আপনি যদি অনুশীলনীর সমাধান ফাইলটি একবারও না ধরেন, তাহলে এরকম একটি মেসেজ দেখতে পাবেন:

```
Please implement your solution.
```

তাই, সমাধান লেখা শুরু করার আগে এই লাইনটি মুছে ফেলুন।

ডিফল্টভাবে শুধু প্রথম টেস্টটিই চালানো হয়।

```text
TAP version 14
1..10
ok 1 - ...
```

সব টেস্ট চালাতে টাইপ করুন:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

সব টেস্ট পাস হয়ে গেলে অনুশীলনীটি আপনার শেষ, আর আপনি সমাধানটি সাবমিট করতে পারেন।

সংশ্লিষ্ট নম্বরটি পাস করে চালানোর জন্য একটি নির্দিষ্ট টেস্ট বেছে নেওয়া সম্ভব, উদাহরণস্বরূপ:

```sh
make test=2
```

তাহলে শুধু দ্বিতীয় টেস্টটিই চালানো হবে।
