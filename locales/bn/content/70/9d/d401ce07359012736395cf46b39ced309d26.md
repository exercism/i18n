# নির্দেশনা সংযোজন

## রেজিস্টার

| রেজিস্টার | ব্যবহার | টাইপ | বর্ণনা |
| -------- | --------- | ------- | -------------------------- |
| `$a0` | ইনপুট | অ্যাড্রেস | আইটেমের ওজনের অ্যারে |
| `$a1` | ইনপুট | অ্যাড্রেস | আইটেমের মানের অ্যারে |
| `$a2` | ইনপুট | ইন্টিজার | আইটেমের সংখ্যা |
| `$a3` | ইনপুট | ইন্টিজার | সর্বোচ্চ ওজন |
| `$v0` | আউটপুট | ইন্টিজার | সর্বোচ্চ মান |
| `$t0-9` | টেম্পোরারি | যেকোনো | টেম্পোরারি স্টোরেজের জন্য ব্যবহৃত |
