# ভূমিকা

## if এক্সপ্রেশন

`jq`-এর **শর্তসাপেক্ষ এক্সপ্রেশন** হলো `if A then B else C end`.

`if-then-else` হলো একটি ফিল্টার, `jq`-এর সব বিল্ট-ইন-এর মতোই: এটি একটি ইনপুট নেয় এবং একটি আউটপুট দেয়.

যদি `A` এক্সপ্রেশনটি একটি "ট্রুথি" মান তৈরি করে, তাহলে `if` ফিল্টারটি `B` মূল্যায়ন করে। অন্যথায় এটি `C` মূল্যায়ন করে।
`if` ফিল্টারের ইনপুটটি `B` বা `C`-তে পাঠানো হবে।

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else` ক্লজটি **ঐচ্ছিক**; নিচের দুটি স্টেটমেন্ট সমতুল্য।

```jq
if A then B else . end
if A then B end
```
~~~~

## নেস্টেড if স্টেটমেন্ট

আরও শর্ত `elif` দিয়ে যোগ করা যায়।

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

আপনার যতগুলো `elif` ক্লজ দরকার, ততগুলো ব্যবহার করুন।

## ট্রুথিনেস

`jq`-তে একমাত্র "ফলস" মানগুলো হলো: `false` এবং `null`.
বাকি সবকিছুই "ট্রু", এমনকি সংখ্যা শূন্য এবং খালি স্ট্রিং, অ্যারে ও অবজেক্টও।

## বুলিয়ান অপারেটর

**বুলিয়ান অপারেটর** `and` এবং `or` দিয়ে জটিল কোয়েরি তৈরি করা যায়।

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

নেগেট করতে `not` ব্যবহার করুন। এটি একটি **ফিল্টার**, কোনো অপারেটর নয়।

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## অল্টারনেটিভ অপারেটর

**অল্টারনেটিভ অপারেটর** দিয়ে আপনি একটি "ডিফল্ট" মান নির্দিষ্ট করতে পারেন, যদি কোনো এক্সপ্রেশন ফলস বা null হয়।

```jq
A // B

# This is identical to
if A then A else B end
```

উদাহরণস্বরূপ

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
