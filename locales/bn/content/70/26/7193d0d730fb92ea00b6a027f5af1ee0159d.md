# ভূমিকা

আমরা _প্রোগ্রামিং ভাষাটিকে_ **AWK** নামে ডাকব, আর AWK প্রোগ্রাম ইন্টারপ্রেট করে যে _এক্সিকিউটেবলটি_, তাকে **`awk`** বা **`gawk`** নামে ডাকব।

## প্যাটার্ন ও অ্যাকশন

একটি AWK প্রোগ্রাম **প্যাটার্ন-অ্যাকশন জোড়া** দিয়ে গঠিত

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

একটি **প্যাটার্ন** হতে পারে ইনপুটের সাথে মেলানোর জন্য একটি রেগুলার এক্সপ্রেশন প্যাটার্ন।
এটি এমন যেকোনো এক্সপ্রেশনও হতে পারে, যার ফলাফল ট্রু বা ফলস মান।

একটি **অ্যাকশন** হলো এক বা একাধিক AWK কমান্ড।
ঘিরে থাকা বন্ধনীগুলো অবশ্যই লাগবে।

প্যাটার্নের ফলাফল _ট্রু_ হলে সংশ্লিষ্ট অ্যাকশনটি মূল্যায়ন করা হয়।

## রেকর্ড ও ফিল্ড

AWK ইনপুটকে একের পর এক **রেকর্ড** হিসেবে পার্স করে।
প্রতিটি রেকর্ডকে শূন্য বা তার বেশি **ফিল্ডে** ভাগ করা হয়।

ডিফল্ট আচরণ হলো:

- নিউলাইনকে "রেকর্ড সেপারেটর" ধরে ইনপুটকে রেকর্ডে ভাগ করা, ফলে প্রতিটি _লাইন_ একটি রেকর্ড।
- হোয়াইটস্পেসকে "ফিল্ড সেপারেটর" ধরে রেকর্ডকে ফিল্ডে ভাগ করা, ফলে প্রতিটি _শব্দ_ একটি ফিল্ড।

## প্যাটার্ন ও অ্যাকশন, পরবর্তী অংশ

প্যাটার্ন বাদ দেওয়া যেতে পারে, সেক্ষেত্রে অ্যাকশনটি _প্রতিটি ইনপুট রেকর্ডের জন্য_ মূল্যায়ন করা হয়।

অ্যাকশন বাদ দেওয়া যেতে পারে, সেক্ষেত্রে ডিফল্ট অ্যাকশন হলো বর্তমান রেকর্ডটি প্রিন্ট করা।

### বিশেষ প্যাটার্ন

সাধারণত ব্যবহৃত দুটি বিশেষ প্যাটার্ন আছে।

- কোনো ইনপুট নেওয়ার আগেই `BEGIN` সংশ্লিষ্ট অ্যাকশনটি মূল্যায়ন করে।
- সব ইনপুট নেওয়া শেষ হলে `END` সংশ্লিষ্ট অ্যাকশনটি মূল্যায়ন করে।

## ফিল্ড ভ্যারিয়েবল

ফিল্ডগুলোকে আপনি `$1`, `$2`, `$3` ইত্যাদি দিয়ে বোঝান।

বর্তমান রেকর্ডটি হলো `$0`.

এখানে আরও কিছু বহুল ব্যবহৃত বিল্ট-ইন ভ্যারিয়েবল দেওয়া হলো।

### ইনপুট পার্সিং নিয়ন্ত্রণকারী বিল্ট-ইন ভ্যারিয়েবল

- `RS` হলো ইনপুট রেকর্ড সেপারেটর।
  যেমনটা বলা হয়েছে, এর ডিফল্ট মান একটি নিউলাইন।
- `FS` হলো ইনপুট ফিল্ড সেপারেটর।

এই ভ্যারিয়েবলগুলো সাধারণত `BEGIN` অ্যাকশন ব্লকে সেট করা হয়।

### তথ্য বহনকারী বিল্ট-ইন ভ্যারিয়েবল

প্রোগ্রাম চালানোর সময় AWK এই ভ্যারিয়েবলগুলো স্বয়ংক্রিয়ভাবে সেট করে।

- `NF` বর্তমান রেকর্ডের ফিল্ড সংখ্যা সংরক্ষণ করে।
  - শেষ ফিল্ডের মান পেতে `$NF` ব্যবহার করুন।
- `NR` বর্তমান রেকর্ড নম্বর সংরক্ষণ করে।
  - একাধিক ইনপুট ফাইল প্রসেস করা হলে `NR` এতক্ষণ প্রসেস করা মোট রেকর্ডের সংখ্যা ধরে রাখবে।
- `FNR` বর্তমান ইনপুট ফাইলের বর্তমান রেকর্ড নম্বর সংরক্ষণ করে।
  - NR আর FNR-এর পার্থক্য বোঝাতে, এখানে একটি কমন AWK ইডিয়ম দেওয়া হলো।
    ```awk
    NR == FNR {action}
    ```
    এর মানে হলো "জমা হওয়া রেকর্ড নম্বর যদি বর্তমান ফাইলের রেকর্ড নম্বরের সমান হয়।"
    এটি কেবল _প্রথম ইনপুট ফাইলের_ রেকর্ডের জন্যই সত্য হতে পারে।

## ট্রুথিনেস

AWK ঠিক C-এর মতো একই ট্রুথিনেস ধারণা ব্যবহার করে।

- `0` সংখ্যাটি ফলস।
- বাকি যেকোনো সংখ্যা ট্রু।

যেহেতু AWK একটি টেক্সট-প্রসেসিং ভাষা, তাই ট্রু-ফলস মান স্ট্রিং পর্যন্ত বিস্তৃত।

- একটি খালি স্ট্রিং `""` ফলস।
- যেকোনো অখালি স্ট্রিং ট্রু।

## কমেন্ট

কমেন্ট `#` ক্যারেক্টার দিয়ে শুরু হয় এবং লাইনের শেষ পর্যন্ত চলে।

## উদাহরণ

ইউনিক্স-সদৃশ সিস্টেমে `/etc/passwd`-এ ব্যবহারকারীদের তথ্য থাকে।
প্রতিটি ব্যবহারকারী আলাদা লাইনে বর্ণিত থাকে, যেখানে ফিল্ডগুলো কোলন দিয়ে আলাদা করা।

ইউজারনেমগুলো তালিকা করতে:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

খেয়াল করুন, `{print $1}` অ্যাকশনে কোনো প্যাটার্ন নেই, তাই এটি প্রতিটি রেকর্ডের জন্য চালানো হয়।

আউটপুট যদি কেবল সেই ব্যবহারকারীদের মধ্যে সীমাবদ্ধ রাখতে চাই, যারা লগইন শেল হিসেবে bash ব্যবহার করেন, তাহলে এভাবে করা যায়:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
