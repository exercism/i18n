# অ্যারে

PHP-তে অ্যারে হলো ক্রমবদ্ধ ম্যাপ (ordered map)।
ম্যাপ হলো এমন একটি ডেটা স্ট্রাকচার, যা একটি কী (key)-এর সঙ্গে একটি মান যুক্ত করে।
অ্যারে বহুমুখী, আর এটিকে `C` বা `Java`-র মতো লিনিয়ার অ্যারে, লিস্ট [ভেক্টর], হ্যাশ-টেবিল, ডিকশনারি, কালেকশন, স্ট্যাক বা কিউ হিসেবে ব্যবহার করা যায়।

কী (key) ঐচ্ছিক, তবে উল্লেখ করলে তা অবশ্যই একটি `int` বা একটি `string` হতে হবে।
কী (key) না দিলে PHP ডিফল্টভাবে `0` থেকে শুরু করে ক্রমবর্ধমান ইন্টিজার কী (key) ব্যবহার করে।

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

একটি অ্যারে সব ধরনের মান সংরক্ষণ করতে পারে।
প্রতিটি মানের টাইপ আলাদা হতে পারে।

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## অ্যারে ব্যবহার

অ্যারে লিটারাল হিসেবে ঘোষণা করা যায় (উপরের মতো কোডে লেখা), আবার ফাংশন দিয়ে তৈরি ও পরিচালনাও করা যায়।

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

ইনডেক্স অপারেটরের সাহায্যে মান অ্যাক্সেস করা, অ্যাসাইন করা আর যুক্ত করা যায়:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

foreach দিয়ে একটি অ্যারের ওপর ইটারেশন করুন:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
