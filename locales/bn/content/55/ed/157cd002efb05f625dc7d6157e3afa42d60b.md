# নির্দেশাবলি

প্যালার্মো বন্দরটি একটি ব্যস্ত সমুদ্রবন্দর, যেখানে অনেক জাহাজ আসা-যাওয়া করে।
অনেক দিন ধরে বন্দরে বর্তমানে থাকা জাহাজগুলোর হিসাব রাখার জন্য এখানে একটি ম্যানুয়াল সিস্টেম চলে আসছিল।
এই সিস্টেমে ভুল হওয়ার সম্ভাবনা খুব বেশি, তাই বন্দরের প্রধান এটি বদলে একটি কম্পিউটারভিত্তিক সিস্টেম বসানোর সিদ্ধান্ত নিয়েছেন।

নতুন সিস্টেমটি বাস্তবায়নের দায়িত্ব বন্দরের প্রধান আপনাকে দিয়েছেন।
সিস্টেমটিকে জাহাজের আইডেন্টিফায়ার সামলাতে হবে, পাশাপাশি গন্তব্যেরও।

## 1. বন্দরের আইডেন্টিফায়ার তৈরি করুন

প্রথমে আপনাকে প্যালার্মো বন্দরের আইডেন্টিফায়ার তৈরি করতে হবে।
আইডেন্টিফায়ারটি হলো বন্দরের নামের প্রথম চারটি অক্ষর, বড় হাতের অক্ষরে।

`Port::IDENTIFIER` কনস্ট্যান্টটিকে `:PALE` মানবিশিষ্ট একটি সিম্বল হিসেবে ডিফাইন করুন।

```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. অন্য বন্দরগুলোর আইডেন্টিফায়ার বের করুন

প্রোগ্রামটিকে অন্য বন্দরগুলোও সামলাতে হবে, তাই সেগুলোর জন্যও আপনাকে আইডেন্টিফায়ার তৈরি করতে হবে।
বন্দর কর্তৃপক্ষ সিস্টেমটি স্বয়ংক্রিয় করতে চায়, আর যেহেতু ভিন্ন ভিন্ন বন্দর ভিন্ন ভিন্ন নামকরণ রীতি ব্যবহার করে, তাই বন্দরের নাম থেকেই আইডেন্টিফায়ারগুলো তৈরি হওয়া উচিত।
আইডেন্টিফায়ারটি হলো বন্দরের নামের প্রথম চারটি অক্ষর, বড় হাতের অক্ষরে।

`Port.get_identifier` মেথডটিকে ডিফাইন করুন, যাতে এটি আর্গুমেন্ট হিসেবে একটি স্ট্রিং নেয় এবং ওই বন্দরের আইডেন্টিফায়ার একটি সিম্বল হিসেবে রিটার্ন করে।

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. কোন জাহাজ কোন টার্মিনালে ভিড়বে তা নির্ধারণ করুন

বন্দরটিতে দুটি টার্মিনাল আছে, আর কোন জাহাজ কোন টার্মিনালে ভিড়বে তা সিস্টেমটিকে নির্ধারণ করতে হবে।
টার্মিনাল নির্ধারিত হয় জাহাজের আইডেন্টিফায়ার দিয়ে।

আইডেন্টিফায়ারটি দুটি অংশে গঠিত: প্রথম অংশটি বড় হাতের ৩টি অক্ষর দিয়ে তৈরি, যা বলে জাহাজটি কোন পণ্য বহন করছে, আর তারপর ৩টি সংখ্যা, যা জাহাজটির অনন্য আইডেন্টিফায়ার।

জাহাজের আইডেন্টিফায়ারে যদি **OIL** বা **GAS** থাকে, তাহলে জাহাজটিকে টার্মিনাল **A**-তে ভিড়তে হবে।
অন্যথায় জাহাজটিকে টার্মিনাল **B**-তে ভিড়তে হবে।

`Port.get_terminal` মেথডটিকে ডিফাইন করুন, যাতে এটি আর্গুমেন্ট হিসেবে একটি সিম্বল নেয়, যা জাহাজটির আইডেন্টিফায়ার।
মেথডটি টার্মিনালটি একটি সিম্বল হিসেবে রিটার্ন করবে।

```ruby
Port.get_terminal(:OIL123)
# => :A
```
