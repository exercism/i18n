# পরিচিতি

## নেস্টেড টাইপ

C# টাইপ একটি ক্লাস বা স্ট্রাক্টের স্কোপের ভেতরে ডিফাইন করা যায়। এনক্লোজিং টাইপটি এক ধরনের নেমস্পেসের কাজ করে। ডট সিনট্যাক্স ব্যবহার করে এনক্লোজিং টাইপের মাধ্যমে টাইপটিতে অ্যাক্সেস করা যায়।

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

আপনি ইনার টাইপগুলোর জন্য অ্যাক্সেস লেভেল নির্ধারণ করতে পারেন।

এনক্লোজিং টাইপের প্রাইভেট মেম্বারগুলো ইনার টাইপের মেম্বারদের স্কোপে থাকে, কিন্তু উল্টোটা নয়।
