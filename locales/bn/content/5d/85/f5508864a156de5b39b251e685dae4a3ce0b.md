# পরিচিতি

মেথডের একটি প্যারামিটারকে একটি ডিফল্ট মান দিয়ে অপশনাল করে তোলা যায়। অপশনাল প্যারামিটারযুক্ত একটি মেথড কল করার সময় সেগুলোর জন্য মান পাস করা বাধ্যতামূলক নয়। কোনো অপশনাল প্যারামিটারের জন্য কোনো মান পাস না করা হলে তার ডিফল্ট মানটি ব্যবহৃত হবে।

অপশনাল প্যারামিটারগুলো _অবশ্যই_ প্যারামিটার তালিকার একেবারে শেষে থাকতে হবে; এগুলোর পরে নন-অপশনাল প্যারামিটার থাকতে পারে না।

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
