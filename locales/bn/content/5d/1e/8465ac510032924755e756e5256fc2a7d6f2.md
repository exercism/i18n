# ভূমিকা

PHP-তে কোভারিয়েন্স আর কন্ট্রাভারিয়েন্সের ধারণা গুরুত্বপূর্ণ, কারণ ক্লাস বা ইন্টারফেস এক্সটেন্ড করার সময় এই নিয়মগুলো যাতে মানা হয়, PHP তা বাধ্যতামূলকভাবে নিশ্চিত করে।

কোভারিয়েন্স দুইটি টাইপের মধ্যকার সম্পর্ক অটুট রাখে, আর কন্ট্রাভারিয়েন্স সেই সম্পর্ক উল্টে দেয়। সংক্ষেপে এর অর্থ হলো, ক্লাস এক্সটেন্ড করা বা ফাংশন ওভাররাইড করার সময় আপনি আপনার মেথডের প্যারামিটারের জন্য কম বা বেশি নির্দিষ্ট টাইপ অনুমোদন করতে পারেন, এবং মেথড থেকে কম বা বেশি নির্দিষ্ট টাইপ রিটার্ন করতে পারেন।

## উদাহরণ

নিচের ক্লাসটি ধরা যাক:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

ক্লাসটি এক্সটেন্ড করলে আমরা মূল ঘোষণার চেয়ে বেশি প্যারামিটার টাইপ অনুমোদন করতে পারি, কিন্তু মূল রিটার্ন টাইপ ছাড়া আর কিছু রিটার্ন করতে পারি না।

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

নিচের এক্সটেন্ড করা ক্লাসটি বৈধ নয়, কারণ অতিরিক্ত বা আরও বিস্তৃত টাইপ রিটার্ন করার অনুমতি নেই:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
