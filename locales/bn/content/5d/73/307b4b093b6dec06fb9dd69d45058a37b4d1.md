# ভূমিকা

## সময়

মানুষের পড়ার উপযোগী তারিখ ও সময় দেখানোর জন্য `Time` মডিউলটি ব্যবহার করা হয়।
যদিও `Time` দিয়ে সময় নাড়াচাড়া করা প্রযুক্তিগতভাবে সম্ভব, তবু এই কাজের জন্য Elm কমিউনিটির এমন কিছু প্যাকেজ আছে যেগুলো অনেক বেশি উপযুক্ত, যেমন [`justinmimbs/date`][date] বা [`CoderDennis/elm-time-format`][elm-time-format]।

### Posix

সময়কে প্রকাশ করা হয় `Posix` নামের অপেক টাইপ দিয়ে, যা Unix epoch time ধারণ করে, অর্থাৎ ১ জানুয়ারি ১৯৭০, UTC অনুসারে মধ্যরাত থেকে যত মিলিসেকেন্ড পেরিয়ে গেছে তার সংখ্যা।
একটি `Posix` হলো দ্ব্যর্থতাহীন একটি মান, যা টাইম জোন ভেদে বদলায় না, তাই সময় ধরে রাখার জন্য এটি ভালো একটি পছন্দ।
একটি Elm অ্যাপ্লিকেশনে `Posix` সময় সাধারণত বাইরের উৎস, যেমন ব্রাউজার, থেকে সরবরাহ করা হয়।

নিচের ফাংশনগুলো দিয়ে একটি `Posix` মানকে মিলিসেকেন্ডের সংখ্যায় রূপান্তর করা যায়, আবার উল্টোটাও করা যায়:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### টাইম জোন

আমাদের দৈনন্দিন জীবনে আমরা সাধারণত `Posix` পড়ি না, বরং স্থানীয় সময়ই পছন্দ করি, যা পৃথিবীতে আমাদের অবস্থান এবং স্থানীয় ডেলাইট সেভিং সংক্রান্ত নিয়মের উপর নির্ভর করে।
Elm-এ এই তথ্য এনকোড করা থাকে `Zone` নামের অপেক টাইপে, যা সাধারণত ব্রাউজার সরবরাহ করে।

এমন একটি বিশেষ `Zone` আছে যা সবসময় ব্যবহার করা যায়:

```elm
utc : Zone
```

### মানুষের পড়ার উপযোগী সময়

একটি `Posix` আর একটি `Zone` থাকলে, যেকোনো স্তরের বিস্তারিতসহ স্থানীয় সময় দেখানোর জন্য আমাদের কাছে যথেষ্ট তথ্য থাকে।
সে কাজে ব্যবহার করা যায় এমন ফাংশনগুলোর তালিকা এখানে:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

আপনি নিশ্চয়ই `Time`-এর আরও দুটি কাস্টম টাইপ লক্ষ্য করেছেন:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

এই কাস্টম টাইপগুলোকে মানুষের পড়ার উপযোগী মানে রূপান্তর করার কাজটি ব্যবহারকারীর উপরেই ছাড়া হয়েছে।
