# পরিচিতি

Ruby একটি ডাইনামিক [অবজেক্ট-ওরিয়েন্টেড ভাষা][object-oriented-programming]।
Ruby-তে সবকিছুই একটি [অবজেক্ট][object]।

Ruby-তে অবজেক্টকে নাম দেওয়ার দুটি প্রধান উপায় আছে: ভ্যারিয়েবল বা কনস্ট্যান্ট ব্যবহার করা।
ভ্যারিয়েবল সবসময় [স্নেক কেসে][snake-case] লেখা হয়।
একটি ভ্যারিয়েবল তার জীবদ্দশায় ভিন্ন ভিন্ন অবজেক্ট নির্দেশ করতে পারে।
উদাহরণস্বরূপ, `=` অপারেটর ব্যবহার করে `my_first_variable`-কে অনেকবার ডিফাইন ও রিডিফাইন করা যায়:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

অন্যদিকে কনস্ট্যান্ট একবারই অ্যাসাইন করার জন্য বোঝানো হয়েছে।
এগুলো অবশ্যই বড় হাতের অক্ষর দিয়ে শুরু হতে হবে এবং সাধারণত বড় হাতের অক্ষরে লেখা হয়, যেখানে শব্দগুলো আন্ডারস্কোর দিয়ে আলাদা করা থাকে।

উদাহরণস্বরূপ:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby ক্লাসে সাজানো থাকে।
`class` কিওয়ার্ডের পরে ক্লাসের নাম লিখে ক্লাস ডিফাইন করা হয়।
সাধারণত `.new` মেথড দিয়ে ক্লাস ইনস্ট্যানশিয়েট করে অবজেক্ট তৈরি করা হয়।

উদাহরণস্বরূপ:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

কার্যকারিতার এককগুলো মেথডে এনক্যাপসুলেট করা হয়, যা অন্য ভাষার _ফাংশন_-এর মতো।
একটি মেথডে ইচ্ছেমতো পজিশনাল আর্গুমেন্ট এবং/অথবা কিওয়ার্ড আর্গুমেন্ট দিয়ে ডিফাইন করা যায়, যেগুলো `:` সিনট্যাক্স দিয়ে ডিফাইন ও কল করা হয়।
মেথড হয় সর্বশেষ স্টেটমেন্টের ফলাফল অন্তর্নিহিতভাবে রিটার্ন করে, অথবা `return` কিওয়ার্ড দিয়ে স্পষ্টভাবে একটি অবজেক্ট রিটার্ন করতে পারে।
মেথড `.` সিনট্যাক্স দিয়ে কল করা হয়।

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
