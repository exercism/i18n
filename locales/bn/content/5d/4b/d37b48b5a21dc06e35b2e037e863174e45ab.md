# ভূমিকা

JavaScript-এর অ্যারে ডিস্ট্রাকচারিং সিনট্যাক্স হলো অ্যারে থেকে মান বের করে সেগুলোকে আলাদা আলাদা ভ্যারিয়েবলে অ্যাসাইন করার একটি সংক্ষিপ্ত উপায়।

এই উদাহরণে, `numberOfMoons` অ্যারের প্রতিটি মান তার সংশ্লিষ্ট গ্রহে অ্যাসাইন করা হয়েছে:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
