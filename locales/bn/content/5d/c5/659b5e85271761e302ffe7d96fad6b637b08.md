# পরিচিতি

কখনও কখনও একটি ফাংশন যখন অনেকগুলো আর্গুমেন্ট নেয়, তখন কোন ক্রমে সেগুলো দিতে হবে তা মনে রাখা কঠিন হয়ে পড়ে। পড়ার সুবিধার জন্য Gleam-এ আর্গুমেন্টের সাথে একটি নাম দিয়ে লেবেল করার সুবিধা আছে।

আর্গুমেন্টে লেবেল দিতে হলে আর্গুমেন্টের নামের আগে লেবেলের নামটি লিখুন, মাঝখানে একটি স্পেস দিয়ে।

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

লেবেলযুক্ত আর্গুমেন্ট আছে এমন কোনো ফাংশন কল করার সময় আর্গুমেন্টগুলো যেকোনো ক্রমে দেওয়া যায়। `replace`-এর এই প্রতিটি কলই সমতুল্য:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

লেবেল সবসময়ই ঐচ্ছিক। কোনো ফাংশনে লেবেলযুক্ত আর্গুমেন্ট থাকলেও লেবেল ছাড়াই সেটি কল করা যায়।

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
