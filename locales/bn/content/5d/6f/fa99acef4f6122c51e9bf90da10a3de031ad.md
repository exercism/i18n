# Test চালানো

## একটি অনুশীলনী ডাউনলোড করা

আপনি যে অনুশীলনীতে কাজ করতে চান, সেটি ডাউনলোড করতে [Exercism CLI][cli] ব্যবহার করুন।

```sh
exercism download --track=dart --exercise=hello-world
```

এরপর অনুশীলনীর ডিরেক্টরিতে চলে যান।

```sh
cd /path/to/exercism/dart/hello-world
```

## ডিপেন্ডেন্সি ইনস্টল করা

Test চালানোর আগে অনুশীলনীর ডিপেন্ডেন্সিগুলো ডাউনলোড করে নিন।

```sh
dart pub get
```

## Test চালানো

```sh
dart test
```

## Test-এর ফলাফল বোঝা

`dart test` ডিফল্টভাবে compact reporter ব্যবহার করে, যা এক লাইনে পাস, স্কিপ ও ফেল হওয়া Test-এর চলমান হিসাব দেখায়।

  Expected: <3>
    Actual: <0>

  package:matcher                    expect

To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'

- `+1`: ১টি Test পাস হয়েছে
- `~9`: ৯টি Test স্কিপ হয়েছে

## Test-গুলো একে একে করা

বেশিরভাগ অনুশীলনীতেই একাধিক Test থাকে, আর প্রথমটি ছাড়া বাকি সবগুলো ডিফল্টভাবে স্কিপ করা থাকে।

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

একে একে Test করতে করতে, প্রতিটি Test-এ `skip: true`-এর জায়গায় `skip: false` করে নিন।
অথবা ফাইলটি এডিট না করেই সব Test একবারে চালিয়ে দিন।

```sh
dart test --run-skipped
```

সাবমিট করার সময় অনলাইন test runner সব Test চালায়, স্কিপ করা Test-গুলোসহ।

## এরর "Could not find a command named frontend_server.dart.snapshot" সামলানো

ধরা যাক, একটি অনুশীলনী আপনি আগেই সমাধান করে সাবমিট করেছেন, আর কিছুদিন পর আবার সেটিতে ফিরে এসেছেন।
সেটি Test করার সময় আপনি এই এররটির মুখোমুখি হতে পারেন:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

এর [সমাধান][solution] হলো `pubspec.lock` ফাইলটি মুছে ফেলা।
তারপর আবার dart কমান্ডটি চালান।

[solution]: https://stackoverflow.com/q/79247335/7552
