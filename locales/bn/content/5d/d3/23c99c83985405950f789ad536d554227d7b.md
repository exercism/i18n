# পরিচিতি

SQL-এ একটি `SELECT` স্টেটমেন্টের সাহায্যে ডেটাবেজ থেকে ডেটা আনা যায়।
একটি `SELECT` স্টেটমেন্টের ফলাফল হলো একটি রেজাল্ট সেট।
রেজাল্ট সেটে মানগুলো সারি ও কলামে সাজানো থাকে।
প্রতিটি কলাম ডেটার একটি নির্দিষ্ট অ্যাট্রিবিউট।
প্রতিটি সারিতে প্রতিটি কলামের জন্য একটি মান থাকে।

এটা ভাবার একটি উপায় হলো, কলামগুলোর একটি সেট একটি ডেটা স্ট্রাকচারকে বোঝায়, যেখানে প্রতিটি কলাম ডেটা স্ট্রাকচারের একটি ফিল্ড, আর প্রতিটি সারি ডেটা স্ট্রাকচারের একটি ইনস্ট্যান্স।

`SELECT` স্টেটমেন্ট দিয়ে আপনি ঠিক করতে পারেন কোন ডেটা আনতে চান।
চাইলে আপনি আউটপুট ডেটা রূপান্তর, ফিল্টার এবং/অথবা তার আকার পরিবর্তনও করতে পারেন।

## মূল বিষয়গুলো

একটি সাধারণ `SELECT` স্টেটমেন্টের গঠনটি হলো এরকম:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM` ও `WHERE` ক্লজ দুটি ঐচ্ছিক।
যেমন, `SELECT "Hello, world.";` এর মতো একটি স্টেটমেন্ট পুরোপুরি বৈধ।

খেয়াল করুন, লাইন ভাঙা বাধ্যতামূলক নয়; `SELECT` স্টেটমেন্টের বিভিন্ন ক্লজ (অর্থাৎ অংশ) আলাদা করতে যেকোনো ফাঁকাই যথেষ্ট।
~~~~

`SELECT` কিওয়ার্ডের ঠিক পরেই থাকে সেই কলামগুলোর তালিকা, যেগুলো আপনি ফলাফলে চান।
`FROM` ক্লজ ডেটার উৎস নির্দেশ করে, যা সাধারণত ডেটাবেজের একটি টেবিল।
`WHERE` ক্লজ এক বা একাধিক শর্ত দিয়ে আউটপুট ডেটা ফিল্টার করে।

## WHERE ক্লজ দিয়ে ডেটা ফিল্টার করা

`WHERE` ক্লজ দিয়ে আপনি `SELECT` স্টেটমেন্টে আনা ডেটা ফিল্টার করতে পারেন।
যেমন, আমরা যদি শুধু Appliances চাই, তাহলে এভাবে করতে পারি:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

ফলাফল:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

অথবা ধরুন আমরা শুধু সেই ডেটা চাই যেখানে weight 2.0 থেকে 6.0-এর মধ্যে:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```
