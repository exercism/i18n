## নতুন AWK ধারণা

কিছু মজার GNU awk ভাষার বৈশিষ্ট্য ঝালিয়ে নিতে [`matrix` অনুশীলনীর নির্দেশনা][ex-matrix] দেখুন।

### ডায়নামিক ফাংশন কল

awk ফাংশন ফার্স্ট-ক্লাস অবজেক্ট নয়: অন্য কিছু ভাষায় যেভাবে করা যায়, সেভাবে এদের এক জায়গা থেকে আরেক জায়গায় পাঠানো যায় না।
তবে একটি ভ্যারিয়েবলে ফাংশনের _নাম_ (একটি স্ট্রিং) রাখা যায়, আর বিশেষ `@varname(args)` নোটেশন দিয়ে ফাংশনটি কল করা হয়।
একটি উদাহরণ:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
এ বিষয়ে [Indirect Function Calls][indirect]-এ বর্ণনা আছে।
এটি `gawk`-এর একটি এক্সটেনশন।
