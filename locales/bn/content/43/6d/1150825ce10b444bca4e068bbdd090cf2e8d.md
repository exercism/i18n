# সাধারণ

- [Partial application][partial-application] আর [`(|>)`][pipe-operator] দিয়ে সহজেই সুন্দর, চেইন করা code লেখা যায়, যখন ফাংশনের শেষ আর্গুমেন্ট হিসেবে মূল ডেটা স্ট্রাকচারটি থাকে। স্ট্যান্ডার্ড লাইব্রেরির সব কমন ফাংশনই এটা করে, যেমন `List.map`
- `attack` ফাংশনগুলোতে একটি [Let স্টেটমেন্ট][let] ব্যবহার করে Annalyn আর Kazak-এর জন্য সঠিক শক্তি দিয়ে `attackWithSword` আর `attachWithClaw` ফাংশন দুটিতে partial apply করা যায়।
