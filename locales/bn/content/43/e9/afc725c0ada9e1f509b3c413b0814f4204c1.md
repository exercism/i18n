# পরিচিতি

[_ভ্যারিয়েডিক প্যারামিটার_][variadic-parameters] ব্যবহার করে একটি ফাংশনের একটিমাত্র প্যারামিটারে নির্দিষ্ট কোনো টাইপের শূন্য বা তার বেশি মান গ্রহণ করা যায়। প্যারামিটারটির টাইপ অ্যানোটেশনের শেষে তিনটি ডট (`...`) যোগ করে আপনি একটি ভ্যারিয়েডিক প্যারামিটার ডিফাইন করেন।

ফাংশন বডির ভেতরে Swift এই মানগুলোকে নির্দিষ্ট টাইপের একটি অ্যারে হিসেবে ব্যবহারের সুযোগ দেয়:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
যদি কোনো ফাংশনে ভ্যারিয়েডিক প্যারামিটারের পরে আরও প্যারামিটার থাকে, তাহলে ভ্যারিয়েডিক প্যারামিটারের পরের প্রথম প্যারামিটারটির একটি স্পষ্ট আর্গুমেন্ট লেবেল **অবশ্যই** থাকতে হবে, যাতে Swift বুঝতে পারে ভ্যারিয়েডিক আর্গুমেন্টের তালিকা কোথায় শেষ হচ্ছে।
