# ইনস্টলেশন

## Godot Engine ইনস্টল করা

GDScript ট্র্যাকটি তৈরি হয়েছে [Godot Engine][godot-engine]-এর উপরে, যা Windows, Linux, macOS আর Android-এ চলে।
আপাতত, [নিজের কম্পিউটারে কাজ করার][working-locally] টেস্ট রানার চালাতে Linux দরকার।
এই ট্র্যাকটির জন্য Godot 4.0 বা তার চেয়ে নতুন ভার্সন দরকার।

ইনস্টলেশন শেষ করে টার্মিনালে এই কমান্ডটি চালিয়ে যাচাই করতে পারেন CLI ঠিকভাবে ইনস্টল হয়েছে কি না:

```bash
godot --version
```

## Exercism GDScript ট্র্যাকের টেস্ট রানার ইনস্টল করা

টেস্ট রানার ব্যবহার করতে [Godot সঠিকভাবে ইনস্টল][installation] থাকা দরকার।

Exercism-এর জন্য GDScript স্ক্রিপ্ট বিল্ড ও টেস্ট করতে Godot-কে CLI থেকে "headless" মোডে রান করা হবে।
এই নির্দেশনাগুলোর জন্য এখন Linux আর bash দরকার।

### ধাপ ১: টেস্ট রানারের সামগ্রিক অবকাঠামো ইনস্টল করা

টেস্টের জন্য প্রস্তুত হতে [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] ক্লোন করুন এবং এর বিষয়বস্তু `/opt/test-runner/`-এ নিয়ে যান:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### ধাপ ২: একক অনুশীলনীর টেস্ট রানার স্ক্রিপ্ট ডাউনলোড করা

ধরে নিচ্ছি আপনি `exercism` টুল সেটআপ করেছেন এবং অন্তত একটি GDScript অনুশীলনী ডাউনলোড করেছেন; তাহলে এটি অনুশীলনীগুলো রাখার জন্য আপনার ওয়ার্কস্পেসের নিচে একটি `gdscript` ফোল্ডার তৈরি করে থাকবে (`exercism configure` চালিয়ে এটি দেখতে পাবেন)।
এই ফোল্ডারে [টেস্ট রানারটি][test-local-gdscript-solution] সেভ করুন এবং ফাইলটি এক্সিকিউটেবল হিসেবে চিহ্নিত করুন।

## টেস্ট চালানো

ইনস্টলেশনের ধাপগুলো শেষ হলে, যেকোনো অনুশীলনীর ডিরেক্টরি থেকে শুরু করে (যেমন `~/exercism/gdscript/two-fer`) স্ক্রিপ্টটি (যা এক ধাপ উপরে, `../`-এ আছে) চালিয়ে সেই অনুশীলনীর আপনার লোকাল সমাধান টেস্ট করতে পারবেন:

```sh
../test-local-gdscript-solution.sh
```

## একটি IDE ব্যবহার করা

[Visual Studio Code][vscode]-এর মতো এডিটরে GDScript সিনট্যাক্স হাইলাইটিং পেতে [godot-tools][godot-tools]-এর মতো একটি এক্সটেনশন ইনস্টল করা এবং একটি চালু থাকা ডিবাগ সার্ভার দরকার।
নিজের এডিটরে কোনো প্রজেক্ট খোলা থাকলেই Godot এই ডিবাগ সার্ভার স্বয়ংক্রিয়ভাবে চালু করে এবং প্রজেক্টটি বা Godot নিজে বন্ধ না হওয়া পর্যন্ত এটি চালু রাখে।
