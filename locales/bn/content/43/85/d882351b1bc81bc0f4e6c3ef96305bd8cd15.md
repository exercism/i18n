# পরিচিতি

এক্সটেনশন মেথড দিয়ে নতুন কোনো ডেরাইভড টাইপ তৈরি না করে, রিকম্পাইল না করে, কিংবা মূল টাইপ অন্যভাবে পরিবর্তন না করেই বিদ্যমান টাইপে মেথড যোগ করা যায়। এগুলো স্ট্যাটিক মেথড হিসেবে ডিফাইন করা হয়, কিন্তু কল করা হয় ইনস্ট্যান্স মেথড সিনট্যাক্স ব্যবহার করে। এদের প্রথম প্যারামিটারের আগে `this` মডিফায়ার বসে, যা নির্দিষ্ট করে মেথডটি কোন টাইপের উপর কাজ করে; আর এগুলো নেমস্পেস লেভেলে স্কোপে আনা হয়।

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
