# টেস্ট

আপনার PATH-এ 8th বাইনারি থাকলে, কমান্ডটি লিখুন:

```bash
8th -f test.8th
```

PATH-এ 8th বাইনারি না থাকলে, Windows-এ লিখুন।

```cmd
\path\to\8th -f test.8th
```

Linux বা macOS:

```bash
/path/to/8th -f test.8th
```

## REPL-এ টেস্ট করা

test-words.8th লোড করে 8th চালু করুন:

```sh
8th -f test-words.8th
```

এতে একটি CLI সেশন শুরু হবে, যেখানে আপনার সমাধান ফাইলে কিছু কোড লেখার পর আপনি সেটি REPL-এ লোড করতে পারবেন।
উদাহরণস্বরূপ, "word-count" অনুশীলনীর জন্য আপনি লিখবেন:

```8th
"word-count.8th" f:include
```

আর আপনি টেস্টগুলো এভাবে চালাতে পারেন:

```sh
"word-count-tests.8th" f:include
```

অথবা আপনি ওই ফাইল থেকে একটি টেস্ট কপি করে পেস্ট করতে পারেন, বা নিজের একটি টেস্ট লিখতে পারেন।

## স্কিপ করা টেস্ট

একটি অনুশীলনী সমাধান করা মানে তার সব টেস্ট পাস করানো।
ডিফল্টভাবে, আপনি টেস্ট চালালে কেবল একটি টেস্ট (প্রথমটি) চালানো হয়।
এটি ইচ্ছাকৃত, কারণ এতে আপনি কেবল ওই একটি টেস্ট পাস করানোর দিকেই মনোযোগ দিতে পারেন।
এটি পাস হয়ে গেলে, `SKIP-REST-OF-TESTS` শব্দটি এর পরে সরিয়ে দিয়ে আপনি পরের টেস্টটি চালু করতে পারেন।

## স্কিপ ওভাররাইড করা

`SKIP-REST-OF-TESTS` শব্দটির পরে থাকা টেস্টগুলোসহ সব টেস্ট চালাতে, আপনি `RUN_ALL_TESTS` এনভায়রনমেন্ট ভ্যারিয়েবলটির মান `true` সেট করতে পারেন।
কেবল টেস্ট চালানোর সময়ের জন্য এটি সেট করার একটি উপায় হলো (macOS এবং Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
