# নির্দেশাবলি

এই অনুশীলনীতে আপনি আপনার এলাকার আর্কেড হলের সবচেয়ে জনপ্রিয় গেমটির হাই স্কোর হিসাব রাখার একটি উপায় তৈরি করবেন।

এখানে আপনার তৈরি করার জন্য ৭টি ফাংশন আছে, যেগুলোর সবগুলোই হাই স্কোরের ডেটার একটি ডিকশনারি রিটার্ন করা ও পরিবর্তন করার সাথে সম্পর্কিত।

## 1. একটি নতুন হাই স্কোর ডিকশনারি ডিফাইন করুন

এমন একটি ফাংশন `newScoreBoard()` তৈরি করুন যা কোনো প্যারামিটার নেয় না এবং একটি নতুন হাই স্কোর ডিকশনারি রিটার্ন করে, যেটি কী (key)-এর জন্য `String` টাইপের মান আর ভ্যালু হিসেবে `Int` টাইপের মান ব্যবহার করে।

## 2. হাই স্কোর ডিকশনারিতে খেলোয়াড় যোগ করুন

হাই স্কোর ডিকশনারিতে একজন খেলোয়াড় যোগ করতে `addPlayer(_:_:_:)` ডিফাইন করুন, যা একটি ফাংশন এবং ৩টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো স্কোরের ডিকশনারি। 
    এটি একটি in-out প্যারামিটার হওয়া উচিত।
- দ্বিতীয় প্যারামিটারটি হলো একজন খেলোয়াড়ের নাম, একটি স্ট্রিং হিসেবে।
- তৃতীয় প্যারামিটারটি হলো স্কোর, একটি ইন্টিজার হিসেবে। 
    প্যারামিটারটি অপশনাল; তৃতীয় প্যারামিটারটি ডিফল্ট মান 0 দিয়ে ইমপ্লিমেন্ট করুন।

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. স্কোর ডিকশনারি থেকে খেলোয়াড় সরান

হাই স্কোর ডিকশনারি থেকে একজন খেলোয়াড় সরাতে `removePlayer(_:_:)` ডিফাইন করুন, যা ২টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো স্কোরের ডিকশনারি। 
    এটি একটি in-out প্যারামিটার হওয়া উচিত।
- দ্বিতীয় প্যারামিটারটি হলো খেলোয়াড়ের নাম, একটি স্ট্রিং হিসেবে।

খেলোয়াড়টি ডিকশনারিতে থাকলে এই ফাংশনটি তাকে সরিয়ে দেবে, আর না থাকলে কিছুই করবে না।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. একজন খেলোয়াড়ের স্কোর রিসেট করুন

একজন খেলোয়াড়ের স্কোর রিসেট করতে `resetPlayer(_:_:)` ডিফাইন করুন, যা ২টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো স্কোরের ডিকশনারি।
    এটি একটি in-out প্যারামিটার হওয়া উচিত।
- দ্বিতীয় প্যারামিটারটি হলো খেলোয়াড়ের নাম, একটি স্ট্রিং হিসেবে, যার স্কোর আপনি রিসেট করতে চান।

ফাংশনটি খেলোয়াড়ের স্কোর 0 করে দেবে। 
খেলোয়াড়টি ডিকশনারিতে না থাকলে কিছুই হওয়া উচিত নয়।

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. একজন খেলোয়াড়ের স্কোর আপডেট করুন

আগের স্কোরের সাথে যোগ করে একজন খেলোয়াড়ের স্কোর আপডেট করতে `updateScore` ডিফাইন করুন, যা ৩টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো স্কোরের ডিকশনারি। এটি একটি in-out প্যারামিটার হওয়া উচিত।
- দ্বিতীয় প্যারামিটারটি হলো খেলোয়াড়ের নাম, একটি স্ট্রিং হিসেবে, যার স্কোর আপনি আপডেট করতে চান।
- তৃতীয় প্যারামিটারটি হলো সেই স্কোর, যা আপনি সংরক্ষিত হাই স্কোরের সাথে **যোগ** করতে চান।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. খেলোয়াড়ের নাম অনুযায়ী সাজানো স্কোরসহ খেলোয়াড়দের একটি অ্যারে পান

`orderByPlayers` ফাংশনটি ডিফাইন করুন, যা ১টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো স্কোরের ডিকশনারি।

ফাংশনটি `(String, Int)` টাপলের একটি অ্যারে রিটার্ন করবে, যেখানে থাকবে খেলোয়াড়েরা এবং তাদের হাই স্কোর, খেলোয়াড়ের নাম অনুযায়ী ঊর্ধ্বক্রমে সাজানো।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. খেলোয়াড়ের স্কোর অনুযায়ী অবরোহ ক্রমে সাজানো খেলোয়াড়দের একটি অ্যারে পান

স্কোর অনুযায়ী অবরোহ ক্রমে সাজানো খেলোয়াড়দের একটি অ্যারে পেতে `orderByScores` ডিফাইন করুন, যা ১টি প্যারামিটার নেয়:

- প্রথম প্যারামিটারটি হলো স্কোরের ডিকশনারি।

ফাংশনটি `(String, Int)` টাপলের একটি অ্যারে রিটার্ন করবে, যেখানে থাকবে খেলোয়াড়েরা এবং তাদের হাই স্কোর, খেলোয়াড়ের স্কোর অনুযায়ী অবরোহ ক্রমে সাজানো।

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
