# নির্দেশনা

আপনার কাছের একটি স্থানীয় স্কুলে খুব সক্রিয় একটি ছাত্র সংসদ আছে।
ছাত্র সংসদটি একজন সভাপতির মাধ্যমে পরিচালিত হয় এবং প্রতি ২ বছরে একবার নতুন সভাপতি নির্বাচনের জন্য নির্বাচন অনুষ্ঠিত হয়।
এ বছরের নির্বাচনে সিদ্ধান্ত হয়েছিল যে ভোট গণনার জন্য একটি নতুন ডিজিটাল সিস্টেম দরকার।

এই নতুন সিস্টেমটি তৈরি করতে স্কুলের আপনার সহায়তা দরকার।

## 1. একটি ভোট কাউন্টার তৈরি করুন

নতুন ভোটিং সিস্টেমের প্রথম যেসব জিনিস দরকার তার একটি হলো ভোট কাউন্টার।
এই কাউন্টারটি দিয়ে কোনো নির্দিষ্ট প্রার্থীর প্রাপ্ত ভোটের হিসাব রাখা যায়।

একটি ফাংশন `new_vote_counter` তৈরি করুন, যা একজন প্রার্থীর প্রাথমিক ভোটের সংখ্যা গ্রহণ করে এবং প্রদত্ত প্রাথমিক ভোটের সংখ্যা দিয়ে ইনিশিয়ালাইজ করা একটি `VoteCounter` স্ট্রাক্টের স্ন্যাপশট রিটার্ন করে।

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. একটি কাউন্টার থেকে ভোটের সংখ্যা বের করুন

এখন আপনার কাছে নতুন কাউন্টার তৈরির একটি উপায় আছে!
কিন্তু এখন আপনি বুঝতে পারছেন যে নতুন সিস্টেমের একটি কাউন্টার থেকে ভোটের সংখ্যা বের করারও একটি উপায় দরকার হবে।

একটি ফাংশন `vote_count` তৈরি করুন, যা একটি কাউন্টার (`@VoteCounter`) আর্গুমেন্ট হিসেবে নেবে এবং কাউন্টারের ভোটের সংখ্যা রিটার্ন করবে।

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. একটি কাউন্টারের ভোট বাড়ান

অবশেষে ভোট গণনার সময় এসেছে!
এখন আপনার একটি কাউন্টারের ভোট বাড়ানোর একটি উপায় দরকার।

একটি ফাংশন `increment_vote_count` তৈরি করুন, যা একটি কাউন্টার (`@VoteCounter`) এবং একটি ভোটের সংখ্যা আর্গুমেন্ট হিসেবে নেবে, এবং সেই সংখ্যক ভোট দিয়ে কাউন্টারটি বাড়াবে।

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. নির্বাচনের ফলাফল তৈরি করুন

সব ভোট এখন গণনা হয়ে গেছে, তাই পুরো স্কুলের জন্য ফলাফল ঘোষণার প্রস্তুতি নেওয়ার সময় এসেছে।
এজন্য আপনি খেয়াল করলেন যে শুধু ভোটের কাউন্টার থাকলেই যথেষ্ট নয়।
ভোটের সংখ্যাকে একজন নির্দিষ্ট প্রার্থীর সাথে সম্পর্কিত করার একটি উপায় থাকা দরকার।

একটি ফাংশন `new_election_result` তৈরি করুন, যা একজন প্রার্থীর নাম এবং তার ভোটের সংখ্যা গ্রহণ করে এবং একটি নতুন নির্বাচন ফলাফল রিটার্ন করে।

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

নির্বাচন ফলাফলের স্ট্রাক্টটি ইতিমধ্যে আপনার জন্য তৈরি করা হয়েছে এবং এটি এভাবে সংজ্ঞায়িত:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. ফলাফল ঘোষণা করুন

স্কুলকে নতুন সভাপতির কথা জানানোর সময় এসেছে!
স্কুলে থাকা ছোট ছোট ডিজিটাল মেসেজ বোর্ডে সভাপতির নাম ঘোষণা করা হবে।

বার্তাটিতে নতুন সভাপতির নাম এবং তার পাওয়া ভোট নিচের ফরম্যাটে দেখাতে হবে: `<candidate_name> (<votes>)`।
এমন একটি বার্তার উদাহরণ হলো: `"Peter (51)"`।

একটি ফাংশন `display_result` তৈরি করুন, যা একটি `@ElectionResult` আর্গুমেন্ট হিসেবে গ্রহণ করবে এবং দেখানোর জন্য বার্তাসহ একটি `ByteArray` রিটার্ন করবে।

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. ভোট পুনর্গণনা

চূড়ান্ত ফলাফল সঠিক ছিল কিনা নিশ্চিত করার জন্য ভোট আবার গণনা করা হয়েছিল।
পুনর্গণনায় দেখা গেল যে কিছু প্রার্থীর ভোটের সংখ্যায় এক ভোটের গরমিল ছিল।

একটি ফাংশন `decrement_votes_of_candidate` তৈরি করুন, যা চূড়ান্ত ফলাফল এবং এমন একজন প্রার্থীর নাম নেবে যার ভোটের সংখ্যা আপনি কমাবেন।
চূড়ান্ত ফলাফল দেওয়া হয় একটি `Felt252Dict<u32>` আকারে, যেখানে কী (key) হলো প্রার্থীদের নাম এবং মান হলো তাদের মোট ভোট।

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
