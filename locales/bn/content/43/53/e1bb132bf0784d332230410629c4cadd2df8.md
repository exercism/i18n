# নির্দেশাবলি

নিচের নিয়মগুলো মেনে ১ থেকে n পর্যন্ত সংখ্যাগুলো প্রিন্ট করুন:

1. সংখ্যাটি ৩-এর গুণিতক হলে "Fizz" প্রিন্ট করুন।
2. সংখ্যাটি ৫-এর গুণিতক হলে "Buzz" প্রিন্ট করুন।
3. সংখ্যাটি ৩ ও ৫ উভয়েরই গুণিতক হলে "Fizz Buzz" প্রিন্ট করুন।
4. সংখ্যাটি ৩ বা ৫-এর গুণিতক না হলে সংখ্যাটিই প্রিন্ট করুন।

আউটপুট হবে স্ট্রিংয়ের একটি ভেক্টর, যেমন, "1" "2" "Fizz" "4" "Buzz" ...
