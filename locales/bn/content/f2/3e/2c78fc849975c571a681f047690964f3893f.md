# Python ট্র্যাকের এই অনুশীলনীর নোট

`sum_of_multiples` ফাংশনের test ইনপুটগুলো সম্পর্কে আপনি নিচের বিষয়গুলো ধরে নিতে পারেন:

- সব ইনপুট সংখ্যাই **_অঋণাত্মক `int`_** (_অর্থাৎ শূন্যসহ স্বাভাবিক সংখ্যা_)।
- অবশ্যই গুণনীয়কগুলোর একটি `list` দিতে হবে, আর এর এলিমেন্টগুলো অনন্য এবং ঊর্ধ্বক্রমানুসারে সাজানো থাকে।
