# উপেক্ষা করুন

## jq-এর অতিরিক্ত কমান্ড লাইন অপশন

টেস্টগুলোতে `jq`-এর জন্য অতিরিক্ত কিছু অপশন দেখতে পাবেন।

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

এগুলো কী কী?

- `-s`

  এটি হলো "slurp" মোড।
  ইনপুটকে JSON অবজেক্টের স্ট্রিম হিসেবে না ধরে,
  পুরো ইনপুট একটি অ্যারেতে নিয়ে নেওয়া হয়।

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  "raw" স্ট্রিং (কোটেশন ছাড়া) আউটপুট দেওয়ার জন্য `-r` অপশনটি আপনি আগে দেখে থাকতে পারেন।
  এটি তার উল্টো।
  ইনপুটের প্রতিটি লাইনকে একটি স্ট্রিং হিসেবে ধরা হয়।

  দুটি উদাহরণ:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

এই দুটি অপশন একসাথে ব্যবহার করলে আপনি স্ট্রিংয়ের একটি অ্যারে _পাবেন না_:
বরং লাইন-শেষের নিউলাইনসহ পুরো ইনপুটটাই একটি একক স্ট্রিং হিসেবে পাবেন।

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

এটা সামলানোই এই অনুশীলনীর চ্যালেঞ্জের একটি অংশ।
