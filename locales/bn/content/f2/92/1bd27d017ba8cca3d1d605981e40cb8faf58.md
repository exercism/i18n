# সম্পর্কে

C++-এর শর্তাধীন গঠনগুলো অন্য ভাষার শর্তাধীন গঠনগুলোর মতোই।
যেকোনো শর্তাধীন অপারেশনের অন্তর্নিহিত টাইপ হলো `bool` টাইপ, যার মান `true` বা `false` হতে পারে।
বিভিন্ন শর্ত যাচাই করার জন্য শর্তাধীন গঠনগুলো প্রায়ই ফ্লো কন্ট্রোলের মাধ্যম হিসেবে ব্যবহৃত হয়।

একটি `if` স্টেটমেন্ট ব্যবহার করা যায়, যা অন্তর্নিহিত শর্তটি `true` হলে তার কোড চালায়, যেমন:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

একাধিক কেসের ক্ষেত্রে `else if` ও `else` স্টেটমেন্ট ব্যবহার করে অনেক `if` স্টেটমেন্ট একসাথে চেইন করা যায়।

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17 থেকে `if` স্টেটমেন্টে ছোট একটি ইনিশিয়ালাইজেশন স্টেটমেন্টও থাকতে পারে, যা `if` স্টেটমেন্টের জন্য এক বা একাধিক ভ্যারিয়েবল ইনিশিয়ালাইজ করতে ব্যবহার করা যায়।
যেমন:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> দ্রষ্টব্য: ইনিশিয়ালাইজেশনে তৈরি করা যেকোনো ভ্যারিয়েবল `if` স্টেটমেন্টের শেষ হওয়ার পরে অ্যাক্সেস করা যায় না।
