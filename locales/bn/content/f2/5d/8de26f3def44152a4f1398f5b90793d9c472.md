# পরিচিতি

একটি অ্যালজেব্রিক ডেটা টাইপ (ADT) নির্দিষ্ট সংখ্যক নামযুক্ত কেস বোঝায়।
ADT-এর প্রতিটি মান ঠিক একটি নামযুক্ত কেসের সাথে মিলে যায়।

ADT ডিফাইন করা হয় `data` কিওয়ার্ড দিয়ে, আর কেসগুলোকে পাইপ (`|`) ক্যারেক্টার দিয়ে আলাদা করা হয়।
কোনো কেসের সাথে যদি কোনো ডেটা যুক্ত না থাকে, তাহলে ADT-টি অনেকটা সেরকমই, যাকে অন্য ভাষাগুলো সাধারণত _এনুমারেশন_ (বা _এনাম_) বলে।

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

ADT-এর প্রতিটি কেসের সাথে ইচ্ছা হলে ডেটা যুক্ত থাকতে পারে, আর আলাদা আলাদা কেসে আলাদা টাইপের ডেটা থাকতে পারে।
কেসের সাথে ডেটা যুক্ত থাকলে একটি কনস্ট্রাক্টর লাগে।

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

নির্দিষ্ট কোনো কেসের জন্য মান তৈরি করা যায় তার নাম উল্লেখ করে (যেমন, `NInt 22`)।
কেসের নাম আসলে কনস্ট্রাক্টর ফাংশন, তাই যুক্ত ডেটা সাধারণ ফাংশন আর্গুমেন্টের মতোই পাস করা যায়।

ADT-এর _স্ট্রাকচারাল ইকুয়ালিটি_ থাকে, অর্থাৎ একই কেসের এবং একই (ঐচ্ছিক) ডেটাযুক্ত দুটি মান সমতুল্য।

ADT নিয়ে কাজ করতে `if/else` এক্সপ্রেশন ব্যবহার করা গেলেও, এর জন্য সুপারিশ করা হয় প্যাটার্ন ম্যাচিং, অর্থাৎ _কেস_ স্টেটমেন্ট ব্যবহার করা:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
