# নির্দেশনা

ভবিষ্যৎ জাদুকর এলিসের কিছু মৌলিক বিষয় অনুশীলন করা দরকার। তার কাছে কার্ডের একটি স্ট্যাক আছে, যা নিয়ে সে কার্সাজি করতে চায়।

কাজটা একটু সহজ করতে সে শুধু ১ থেকে ১০ নম্বরের কার্ডগুলোই ব্যবহার করে, তাই তার কার্ডের স্ট্যাককে সংখ্যার একটি অ্যারে দিয়ে প্রকাশ করা যায়। কোনো একটি কার্ডের অবস্থান অ্যারের ইনডেক্সের সাথে মিলে যায়। অর্থাৎ অবস্থান ০ মানে প্রথম কার্ড, অবস্থান ১ মানে দ্বিতীয় কার্ড, ইত্যাদি।

~~~~exercism/note
সব ফাংশনের উচিত কার্ডের অ্যারেটি হালনাগাদ করা এবং তারপর পরিবর্তিত অ্যারেটি রিটার্ন করা। এভাবে কাজ করার একটি কমন ধরনকে বলা হয় Builder pattern, যা দিয়ে সুন্দরভাবে একটার পর একটা ফাংশন জুড়ে দেওয়া যায়।
~~~~

## 1. স্ট্যাক থেকে একটি কার্ড বের করা

একটি কার্ড বাছতে প্রদত্ত স্ট্যাক থেকে `position` ইনডেক্সে থাকা কার্ডটি রিটার্ন করুন।

`getCard(at:from:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: `at`, অর্থাৎ স্ট্যাকে কার্ডটির অবস্থান, এবং `from`, অর্থাৎ কার্ডের স্ট্যাক। ফাংশনটি প্রদত্ত স্ট্যাক থেকে `index` অবস্থানের কার্ডটি রিটার্ন করবে।

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. স্ট্যাকে একটি কার্ড পরিবর্তন করা

একটু হাতের কৌশল দেখিয়ে `position` ইনডেক্সের কার্ডটি প্রদত্ত বিকল্প কার্ডের সাথে অদলবদল করুন।

`setCard(at:in:to)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা তিনটি আর্গুমেন্ট নেয়: `at`, অর্থাৎ স্ট্যাকে কার্ডটির অবস্থান, `in`, অর্থাৎ কার্ডের স্ট্যাক, এবং `to`, অর্থাৎ `index` অবস্থানের কার্ডটি বদলে দেওয়ার নতুন কার্ড। ফাংশনটি স্ট্যাকের একটি কপি রিটার্ন করবে, যেখানে `index` অবস্থানের কার্ডটি নতুন কার্ড দিয়ে বদলে দেওয়া হয়েছে। প্রদত্ত `index` যদি স্ট্যাকে বৈধ ইনডেক্স না হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. স্ট্যাকের উপরে একটি কার্ড ঢোকানো

স্ট্যাকের একেবারে উপরে একটি নতুন কার্ড ঢুকিয়ে একটি কার্ডকে হাজির করুন।

`insert(_:atTopOf:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: যে নতুন কার্ডটি ঢোকানো হবে, এবং কার্ডের স্ট্যাক। ফাংশনটি স্ট্যাকের একটি কপি রিটার্ন করবে, যেখানে প্রদত্ত নতুন কার্ডটি স্ট্যাকের উপরে যোগ করা হয়েছে।

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. স্ট্যাক থেকে একটি কার্ড সরানো

প্রদত্ত `position` থেকে কার্ডটি সরিয়ে একটি কার্ডকে উধাও করুন।

`removeCard(at:from:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: `at`, অর্থাৎ স্ট্যাকে কার্ডটির অবস্থান, এবং `from`, অর্থাৎ কার্ডের স্ট্যাক। ফাংশনটি স্ট্যাকের একটি কপি রিটার্ন করবে, যেখানে `index` অবস্থানের কার্ডটি সরিয়ে ফেলা হয়েছে। প্রদত্ত `index` যদি স্ট্যাকে বৈধ ইনডেক্স না হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. স্ট্যাকে একটি কার্ড ঢোকানো

প্রদত্ত `position` অবস্থানে স্ট্যাকে একটি নতুন কার্ড ঢুকিয়ে একটি কার্ডকে হাজির করুন।

`insert(_:at:from:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা তিনটি আর্গুমেন্ট নেয়: যে নতুন কার্ডটি ঢোকানো হবে, যে অবস্থানে নতুন কার্ডটি ঢোকানো উচিত, এবং কার্ডের স্ট্যাক। ফাংশনটি স্ট্যাকের একটি কপি রিটার্ন করবে, যেখানে প্রদত্ত নতুন কার্ডটি প্রদত্ত অবস্থানে যোগ করা হয়েছে। প্রদত্ত `index` যদি স্ট্যাকে বৈধ ইনডেক্স না হয়, তাহলে মূল স্ট্যাকটি অপরিবর্তিত অবস্থায় রিটার্ন করা উচিত।

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. স্ট্যাকের আকার যাচাই করা

স্ট্যাকের আকার `stackSize`-এর সমান কি না তা যাচাই করুন।

`checkSizeOfStack(_:_:)` ফাংশনটি ইমপ্লিমেন্ট করুন, যা দুটি আর্গুমেন্ট নেয়: `stack`, অর্থাৎ কার্ডের স্ট্যাক, এবং `stackSize`, অর্থাৎ স্ট্যাকের আকার। স্ট্যাকের আকার `stackSize`-এর সমান হলে ফাংশনটি `true` রিটার্ন করবে, অন্যথায় `false`।

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
