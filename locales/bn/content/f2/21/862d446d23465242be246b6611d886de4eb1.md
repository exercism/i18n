# পরিচিতি

Kotlin-এর `when` হলো কয়েকটি অপশনের মধ্যে একটি বেছে নেওয়ার জন্য একটি শর্তসাপেক্ষ এক্সপ্রেশন। এটি Java-এর `switch`-এর মতো, আর `if` ... `else if` ... `else`-এর একটি চেইনের চেয়ে বেশি নমনীয়।

`if`-এর মতোই `when`-কেও একটি এক্সপ্রেশন হিসেবে ব্যবহার করা যায়, যা একটি মান তৈরি করে।

## একটি মানের সাথে মেলানো

বন্ধনীর মধ্যে `when`-কে যে মানটির সাথে মিলতে হবে সেটি দিন। প্রতিটি ব্রাঞ্চ ওই মানটির সাথে তুলনা করে, যতক্ষণ না কোনো একটি মিলে যায়:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- প্রতিটি ব্রাঞ্চ লেখা হয় `pattern -> result` আকারে।
- ব্রাঞ্চগুলো উপর থেকে নিচে পরীক্ষা করা হয়, যতক্ষণ না একটি মিল পাওয়া যায়। শুধুমাত্র প্রথম ব্রাঞ্চটিই রান হয়।
- উপরে তালিকাভুক্ত নয় এমন যেকোনো মানের জন্য `else` ব্যবহার করুন (`if` চেইনের শেষ `else`-এর মতো)।

এটি [প্যাটার্ন ম্যাচিং][pattern-matching]-এর মতো। `pattern` হতে পারে সেই মান যার সাথে মিলতে হবে, অথবা টাইপ অনুযায়ী মেলাতে `is` ব্যবহার করুন:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

অথবা রেঞ্জ, কালেকশন, স্ট্রিং বা `contains` মেথড আছে এমন অন্য কিছুর মধ্যে এটি আছে কি না তা দেখতে `in` ব্যবহার করুন:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

`contains` [অপারেটর এক্সটেনশন ফাংশন][kotlin-operator-overloading] ডিফাইন করে অন্য অবজেক্টের সাথেও `in` ব্যবহার করতে পারেন। উদাহরণস্বরূপ, [Regex][kotlin-regex]-এর সাথে এটি ব্যবহার করা:

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

fun replace(input: String) {
    return when(input) {
        in Regex("""ani*""") -> println("animal")
        in Regex("""fru.*""") -> println("fruit")
        in Regex("""num.*""") -> println("number")
        else -> println("unknown")
    }
}
```

## গার্ড শর্ত

একটি মানের সাথে মেলানোর সময় প্যাটার্নের পরে একটি `if`-এ অতিরিক্ত শর্ত দেওয়া যায়। এই শর্তগুলোকে গার্ড শর্ত বলা হয়।

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

এমনকি `else if`-ও ব্যবহার করা যায়।

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## শর্তের সাথে মেলানো

বিকল্পভাবে, মানটি বাদ দেওয়া যায় এবং প্রতিটি ব্রাঞ্চে বুলিয়ান শর্ত বসানো যায়:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

আবারও, ব্রাঞ্চগুলো উপর থেকে নিচে পরীক্ষা করা হয় এবং শুধুমাত্র যে প্রথম ব্রাঞ্চের শর্ত `true` হয়, সেটিই রান হয়।

## এক্সপ্রেশন হিসেবে `when` ব্যবহার করা

যখন `when`-কে তার ফলাফলের জন্য ব্যবহার করা হয় (কোনো ভ্যারিয়েবলে অ্যাসাইন করা, ফাংশন থেকে রিটার্ন করা ইত্যাদি), তখন প্রতিটি সম্ভাব্য কেস কভার করতে হবে।

- মানের সাথে মেলানোর সময় `else` যোগ করুন, যদি না প্রতিটি সম্ভাব্য মান আগেই হ্যান্ডেল করা থাকে (যেমন একটি `Boolean` বা একটি `enum`-এর সব মান)।
- শর্তের সাথে মেলানোর সময় `else` ব্রাঞ্চ আবশ্যক, কারণ আপনার শর্তগুলো প্রতিটি কেস কভার করে কি না তা কম্পাইলার জানতে পারে না।

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
