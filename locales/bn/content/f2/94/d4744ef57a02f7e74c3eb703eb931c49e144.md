# নির্দেশাবলি

এই অনুশীলনীতে আপনি [ব্ল্যাকজ্যাক][blackjack]-এর কিছু নিয়ম বাস্তবায়ন করবেন, যেমন গেমটি কীভাবে খেলা হয় এবং কীভাবে স্কোর করা হয়।

**দ্রষ্টব্য**: এই অনুশীলনীতে, _`A`_ মানে টেকা, _`J`_ মানে জ্যাক, _`Q`_ মানে রানি এবং _`K`_ মানে রাজা।
জোকার বাদ দেওয়া হয়।
একটি [আদর্শ ফরাসি স্যুটের ৫২-কার্ডের ডেক][standard_deck] ধরে নেওয়া হয়, তবে বেশিরভাগ সংস্করণে খেলার জন্য একাধিক ডেক একসাথে শাফল করা হয়।

## 1. একটি কার্ডের মান নির্ণয় করুন

ব্ল্যাকজ্যাকে, একটি টেকার মূল্য ১ পয়েন্ট হবে নাকি ১১ পয়েন্ট, তা নির্ভর করে প্রতিটি খেলোয়াড়ের নিজের উপর (_সে বিষয়ে পরে আরও_)।
ফেস কার্ড (`J`, `Q`, `K`) ১০ পয়েন্টে গণনা করা হয় এবং অন্য যেকোনো কার্ডের মান তার "পিপ" (_সাংখ্যিক_) মান।

প্যারামিটার `card` সহ `value_of_card(<card>)` ফাংশনটি ডিফাইন করুন।
ফাংশনটি পাস করা কার্ড স্ট্রিংয়ের _সাংখ্যিক মান_ রিটার্ন করবে।
যেহেতু একটি টেকা একাধিক মান নিতে পারে (১ **বা** ১১), তাই আপাতত এই ফাংশনটি টেকা কার্ডের মান ১ হিসেবেই ধরে নেবে।
পরে, হাতে থাকা কার্ডের ভিত্তিতে টেকা কার্ডের মান নির্ণয় করার জন্য একটি ফাংশন বাস্তবায়ন করবেন।

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. কোন কার্ডের মান বেশি তা নির্ণয় করুন

`card_one` ও `card_two` প্যারামিটার সহ `higher_card(<card_one>, <card_two>)` ফাংশনটি ডিফাইন করুন।
স্কোরিংয়ের জন্য, `J`, `Q` বা `K`-এর মান ১০।
স্কোরিংয়ের জন্য কোন কার্ডের মান বেশি, তা ফাংশনটি রিটার্ন করবে।
দুই কার্ডের মান সমান হলে, দুটোই রিটার্ন করুন।
`return` স্টেটমেন্টে কমা ব্যবহার করে দুটি কার্ডই রিটার্ন করা যায়:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

একটি টেকা একাধিক মান নিতে পারে, তাই এই কাজের জন্য আমরা `A` কার্ডের মান ১ ধরে নেব।

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. একটি টেকার মান নির্ণয় করুন

আগেই বলা হয়েছে, একটি টেকার মূল্য _হয়_ ১, _নয়তো_ ১১ পয়েন্ট।
খেলোয়াড়রা ২১-এর স্কোরের যতটা সম্ভব কাছাকাছি পৌঁছানোর চেষ্টা করে, ২১-এর _উপরে_ না গিয়ে (_"বাস্ট" হয়ে যাওয়া_)।

টেকা কার্ড পাওয়ার _আগে_ হাতে থাকা একজোড়া কার্ড `card_one` ও `card_two` দিয়ে, অর্থাৎ এই প্যারামিটার দুটি সহ `value_of_ace(<card_one>, <card_two>)` ফাংশনটি ডিফাইন করুন।
আসন্ন টেকাটি ১ মান পাবে নাকি ১১ মান পাবে, তা আপনার ফাংশনকে সিদ্ধান্ত নিতে হবে এবং সেই মান রিটার্ন করতে হবে।
মনে রাখবেন: টেকাসহ হাতের মান যতটা সম্ভব বেশি হওয়া দরকার, তবে ২১-এর উপরে _না_ গিয়ে।

**ইঙ্গিত**: হাতে যদি ইতিমধ্যেই একটি টেকা থাকে, তাহলে আসন্ন টেকার মান হবে ১।

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. একটি "ন্যাচারাল" বা "ব্ল্যাকজ্যাক" হাত নির্ণয় করুন

কোনো খেলোয়াড়ের প্রথম দুই কার্ড হিসেবে একটি টেকা (`A`) আর একটি দশ-কার্ড (১০, `K`, `Q` বা `J`) পড়লে, তার স্কোর হয় ২১।
এটাকে **ব্ল্যাকজ্যাক** হাত বলা হয়।


`card_one` ও `card_two` প্যারামিটার সহ `is_blackjack(<card_one>, <card_two>)` ফাংশনটি ডিফাইন করুন, যেখানে এগুলো একজোড়া কার্ড।
দুই কার্ডের হাতটি **ব্ল্যাকজ্যাক** কি না তা নির্ণয় করুন, এবং সেটি হলে বুলিয়ান `True`, অন্যথায় `False` রিটার্ন করুন।

**দ্রষ্টব্য**: স্কোরের _হিসাব_ নানা ভাবে করা যায়।
তবে সম্ভব হলে, আমরা চাই আপনি হাতের মানগুলো _যোগ_ করার বদলে হাতে (_বা নির্দিষ্ট কোনো অবস্থানে_) একটি টেকা আর একটি দশ-কার্ড **_আছে_** কি না তা যাচাই করুন।

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. জোড়া ভাগ করা

হাতের প্রথম দুই কার্ডের মান একই হলে (_যেমন দুটি ছক্কা, বা একটি `Q` ও `K`_), খেলোয়াড় সেগুলোকে দুটি আলাদা হাত হিসেবে গণ্য করতে বেছে নিতে পারেন।
এটাকে "জোড়া ভাগ করা" বলা হয়।

`card_one` ও `card_two` প্যারামিটার সহ `can_split_pairs(<card_one>, <card_two>)` ফাংশনটি ডিফাইন করুন, যেখানে এগুলো একজোড়া কার্ড।
এই দুই কার্ডের হাতটি দুটি জোড়ায় ভাগ করা যায় কি না তা নির্ণয় করুন।
হাতটি ভাগ করা গেলে বুলিয়ান `True` রিটার্ন করুন, অন্যথায় `False` রিটার্ন করুন

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. ডাবল ডাউন

প্রথমে দেওয়া দুই কার্ডের মোট মান ৯, ১০ বা ১১ পয়েন্ট হলে, খেলোয়াড় নিজের মূল বাজির সমান একটি অতিরিক্ত বাজি রাখতে পারেন।
এটাকে "ডাবল ডাউন" বলা হয়।

`card_one` ও `card_two` প্যারামিটার সহ `can_double_down(<card_one>, <card_two>)` ফাংশনটি ডিফাইন করুন, যেখানে এগুলো একজোড়া কার্ড।
দুই কার্ডের হাতটি "ডাবল ডাউন" করা যায় কি না তা নির্ণয় করুন, এবং গেলে বুলিয়ান `True`, অন্যথায় `False` রিটার্ন করুন।

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
