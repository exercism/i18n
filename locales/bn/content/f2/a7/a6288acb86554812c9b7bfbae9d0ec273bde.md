# ভূমিকা

লুপের ইটারেশনের সংখ্যা যদি আগে থেকে জানা না থাকে, মানে "কোনো প্রেডিকেট আর ট্রু না থাকা পর্যন্ত চলতেই থাকুন", তখন Factor [`kernel`][kernel] থেকে `while` কম্বিনেটরটি ব্যবহার করে:

```
while ( pred body -- )
```

`pred` আর `body` দুটোই কোয়োটেশন, যারা ডেটা স্ট্যাকে কাজ করে। `while` প্রথমে `pred` কল করে। এটি যদি উপরে একটি ট্রুথি মান রেখে যায়, তাহলে `while` `body` রান করে এবং এই প্রক্রিয়াটি আবার পুনরাবৃত্তি করে। নাহলে `while` থেমে যায়। এক ইটারেশন থেকে পরের ইটারেশনে যে স্টেট চলে যায়, সেটি কলগুলোর মাঝে স্ট্যাকে থাকে (অথবা একাধিক স্টেট থাকলে নামযুক্ত লোকালে)।

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` হলো এর প্রতিসম রূপ: এটি *যতক্ষণ না* প্রেডিকেটটি ট্রুথি হয়, ততক্ষণ চলতে থাকে।
