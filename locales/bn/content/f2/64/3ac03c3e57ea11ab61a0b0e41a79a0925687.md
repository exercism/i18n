# ভূমিকা

কাস্টিং আর টাইপ কনভার্সন হলো একটি এক্সপ্রেশনকে এক ডেটা টাইপ থেকে আরেকটিতে বদলানোর দুটি ভিন্ন উপায়।

কাস্ট অপারেটর `(<type>)` দিয়ে একটি এক্সপ্রেশনকে অন্য একটি টাইপে কাস্ট করা যায়।

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

টাইপগুলো পরস্পর সামঞ্জস্যপূর্ণ না হলে একটি `InvalidCastException` ইনস্ট্যান্স থ্রো করা হয়। সংখ্যার ক্ষেত্রে এটি বোঝায় যে গ্রহণকারী টাইপটি কাস্ট করা মানটি ধারণ করতে পারে না। ক্লাসের ক্ষেত্রে টাইপ দুটির একটি অন্যটি থেকে ডিরাইভ করা থাকতে হবে (এটা স্ট্রাক্টের ক্ষেত্রেও সহজভাবে প্রযোজ্য)।

_কাস্টিং_-এর একটি বিকল্প হলো `is` অপারেটর দিয়ে _টাইপ কনভার্সন_। এটি সাধারণত রেফারেন্স ও নালেবল টাইপে প্রয়োগ করা হয়।

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

কোনো অবজেক্টের সঠিক টাইপ শনাক্ত করার প্রয়োজন হলে `is` হয়তো একটু বেশি উদার, কারণ এটি একটি ক্লাস এবং সেটি সরাসরি বা পরোক্ষভাবে যেসব ক্লাস ও ইন্টারফেস থেকে ডিরাইভ করা হয়েছে সেগুলোর জন্যও ট্রু রিটার্ন করবে। এই ক্ষেত্রে সমাধান হলো `typeof` আর `Object.GetType()`।

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
