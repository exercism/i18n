# নির্দেশাবলি

আপনি একজন উৎসাহী পাখি-পর্যবেক্ষক, যিনি হিসাব রাখেন আপনার বাগানে কত পাখি এসেছে। সাধারণত আপনি পাখি গোনার জন্য নোটবুকে হিসাব রাখেন, তবে আপনার ডেটা নিয়ে আরও ভালোভাবে কাজ করার জন্য গত কয়েক সপ্তাহের পাখি-গণনা আপনি ডিজিটাল করে ফেলেছেন।

## 1. এখন পর্যন্ত আপনার গোনা মোট পাখির সংখ্যা নির্ণয় করুন

চলুন সামগ্রিক একটা চিত্র নিয়ে ডেটা বিশ্লেষণ শুরু করি।
আপনি হিসাব রাখা শুরু করার পর থেকে মোট কত পাখি গুনেছেন, তা বের করুন।

এমন একটি ফাংশন `totalBirdCount` ইমপ্লিমেন্ট করুন যা `Int` টাইপের একটি অ্যারে নেয়, যেখানে প্রতিদিনের পাখি-গণনা থাকে।
এটি আপনার গোনা মোট পাখির সংখ্যা রিটার্ন করবে।

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. নির্দিষ্ট একটি সপ্তাহে বেড়াতে আসা পাখির সংখ্যা গণনা করুন

এখন আপনার পাখি-গণনার সংখ্যাগুলো সম্পর্কে মোটামুটি ধারণা হয়ে গেছে, তাই আপনি আরও সূক্ষ্ম বিশ্লেষণ করতে চান।

এমন একটি ফাংশন `birdsInWeek` ইমপ্লিমেন্ট করুন যা প্রতিদিনের পাখি-গণনার একটি অ্যারে এবং একটি সপ্তাহ নম্বর নেয়।

এটি ওই নির্দিষ্ট সপ্তাহে আপনার গোনা মোট পাখির সংখ্যা রিটার্ন করে।
আপনি ধরে নিতে পারেন যে সপ্তাহগুলো সবসময় সম্পূর্ণভাবে হিসাব করা হয়।

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. গণনার একটি ভুল ঠিক করুন

আপনি বুঝতে পারলেন যে পাখিদের হিসাব রাখার পুরো সময়টাতেই একটি পাখি বাগানের এক দূরের কোণে লুকিয়ে ছিল।

আপনি বের করলেন যে এই পাখিটি আপনার বাগানে একদিন অন্তর একদিন কাটাত।

ওই দিনগুলোর মাঝে এটি ঠিক কোথায় ছিল তা আপনি জানেন না, তবে নিশ্চিতভাবে আপনার বাগানে নয়।

আপনার পাখি-পর্যবেক্ষকের অন্তর্দৃষ্টিও বলে যে আপনার তালিকায় যে প্রথম দিনটির হিসাব রেখেছেন, সেদিন পাখিটি আপনার বাগানে ছিল।

এই নতুন তথ্য অনুযায়ী, এমন একটি ফাংশন `fixBirdCountLog` লিখুন যা আর্গুমেন্ট হিসেবে প্রতিদিন গোনা পাখির একটি অ্যারে নেয় এবং গণনার ভুল সংশোধন করে অ্যারেটি রিটার্ন করে।

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
