# নির্দেশাবলি

এই অনুশীলনীতে আপনি নানা ধরনের রিমোট কন্ট্রোলড গাড়ির মধ্যে রেস আয়োজন করবেন।
প্রতিটি গাড়ির নিজস্ব স্পিড ও ব্যাটারি ড্রেনের বৈশিষ্ট্য থাকে।

গাড়িগুলো শুরু করে পুরো (১০০%) ব্যাটারি নিয়ে।
রিমোট কন্ট্রোল দিয়ে যতবার আপনি গাড়িটি চালাবেন, ততবার এটি গাড়ির স্পিডের সমান মিটার এগিয়ে যায় এবং অবশিষ্ট ব্যাটারির শতাংশ তার ব্যাটারি ড্রেনের পরিমাণ কমিয়ে দেয়।

কোনো গাড়ির ব্যাটারি যদি তার ব্যাটারি ড্রেনের শতাংশের চেয়ে কম হয়, তাহলে আপনি আর সেই গাড়ি চালাতে পারবেন না।

প্রতিটি রেস ট্র্যাকের নিজস্ব দূরত্ব থাকে।
ব্যাটারি শেষ না করে গাড়িটি ট্র্যাক শেষ করতে পারে কি না, তা যাচাই করে গাড়িগুলোকে পরীক্ষা করা হয়।

## 1. একটি রিমোট কন্ট্রোলড গাড়ি তৈরি করুন

নিচের `int` টাইপের ফিল্ডগুলো নিয়ে একটি `Car` স্ট্রাক্ট ডিফাইন করুন:

- battery
- batteryDrain
- speed
- distance

`NewCar` নামের একটি ফাংশন ডিফাইন করে রিমোট কন্ট্রোলড গাড়ি তৈরি করা যাবে।
ফাংশনটি প্যারামিটার হিসেবে নেয় গাড়ির স্পিড (মিটারে) এবং ব্যাটারি ড্রেনের শতাংশ (দুটোই `int` টাইপের), আর রিটার্ন করে একটি `Car` ইনস্ট্যান্স:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. একটি রেস ট্র্যাক তৈরি করুন

integer টাইপের `distance` ফিল্ড নিয়ে `Track` নামে আরেকটি স্ট্রাক্ট টাইপ ডিফাইন করুন।
`NewTrack` নামের একটি ফাংশন ডিফাইন করে রেস ট্র্যাক তৈরি করা যাবে।
ফাংশনটি একমাত্র প্যারামিটার হিসেবে নেয় ট্র্যাকের দূরত্ব (মিটারে), যা `int` টাইপের:

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. গাড়ি ড্রাইভ করুন

`Drive` ফাংশনটি ইমপ্লিমেন্ট করুন, যা গাড়ির স্পিড অনুযায়ী অতিক্রান্ত মিটারের সংখ্যা হালনাগাদ করে এবং ব্যাটারি ড্রেন অনুযায়ী ব্যাটারি কমিয়ে দেয়।
আরেকবার চালানোর মতো যথেষ্ট ব্যাটারি না থাকলে গাড়িটি নড়বে না:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. একটি রিমোট কন্ট্রোলড গাড়ি রেস শেষ করতে পারবে কি না তা যাচাই করুন

রেস শেষ করতে হলে গাড়িটিকে রেসের দূরত্ব অতিক্রম করতে সক্ষম হতে হবে।
অর্থাৎ ফিনিশ লাইন পেরোনোর আগে তার ব্যাটারি শেষ হয়ে যাওয়া চলবে না।
`CanFinish` ফাংশনটি ইমপ্লিমেন্ট করুন, যা প্যারামিটার হিসেবে একটি `Car` ও একটি `Track` ইনস্ট্যান্স নেয় এবং গাড়িটি রেস শেষ করতে পারলে `true` রিটার্ন করে; নাহলে `false` রিটার্ন করে।

ধরে নিন, আপনি এখন রেসের শুরুর লাইনে আছেন এবং রেসের জন্য গাড়ির ইঞ্জিন চালু করছেন।
খেয়াল রাখুন, রেস শুরু করার সময় গাড়ির ব্যাটারি পুরোপুরি চার্জ করা নাও থাকতে পারে:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
