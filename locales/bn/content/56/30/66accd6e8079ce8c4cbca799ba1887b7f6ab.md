# নির্দেশনার সংযোজন

## `Print` স্ট্রিং মানে উদ্ধৃতি চিহ্ন বসায় না

এই অনুশীলনীতে সংখ্যাসূচক স্কোর নিয়ে কাজ করতে হয়।
#[a: 1]` and `#[a: "1"]` এক নয়:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

ডিবাগ করার সময় মানগুলো `print` করা একটি কমন অভ্যাস।
তবে আউটপুট স্ট্রিংয়ের চারপাশে উদ্ধৃতি চিহ্ন বসায় না।
তাই `"1"`-এর মতো একটি সংখ্যাসূচক স্ট্রিং প্রিন্ট করলে ইন্টিজার `1`-এর মতোই দেখায়।

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
এই অনুশীলনীর টেস্ট আউটপুটে আপনি হয়তো `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`-এর মতো একটি ফলাফল দেখতে পারেন।
তুলনা করা দুটি ডিকশনারি প্রিন্ট করলে একই রকম দেখায়।
তবে প্রথম ডিকশনারিতে থাকে সংখ্যাসূচক স্ট্রিং মান, আর দ্বিতীয়টিতে থাকে ইন্টিজার মান, তাই দুটি এক নয়। 
ডিবাগ করার সময় আপনার ডিকশনারিতে কী কী আছে তা যাচাই করতে `inspect` ব্যবহার করতে পারেন।

## `Express` স্ট্রিং মানে উদ্ধৃতি চিহ্ন বসায়

`express` একটি মানকে Arturo কোডে রূপান্তর করে এবং সেই কোড রূপটিকে প্রকাশ করা একটি স্ট্রিং রিটার্ন করে।
সেই ফলাফলে যেকোনো স্ট্রিং মান উদ্ধৃতি চিহ্নে মোড়া থাকবে।
ফলে `express "1"` রিটার্ন করবে `"1"`, `1` নয়।

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
