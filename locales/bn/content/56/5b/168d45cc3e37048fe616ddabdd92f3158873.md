# পরিচিতি

Go স্ট্যাটিক্যালি টাইপড, তাই প্রতিটি ভ্যারিয়েবলের টাইপ কম্পাইল টাইমেই জানা থাকে। একবার ঘোষণা করা হলে ভ্যারিয়েবলের টাইপ আর পরিবর্তন করা যায় না।

## একটি ভ্যারিয়েবল তৈরি করা

`var` স্টেটমেন্ট একটি নতুন ভ্যারিয়েবলের টাইপ ঘোষণা করতে পারে, তার মান সেট করতে পারে, অথবা দুটোই একসাথে করতে পারে:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

একটি ফাংশনের ভেতরে `:=` শর্ট অ্যাসাইনমেন্ট স্টেটমেন্টও ব্যবহার করা যায়।

```go
count := 1 // Type implictly declared, value explicitly set
```

Go-তে একটি ভ্যারিয়েবলের সবসময়ই একটি মান থাকে। ঘোষণার সময় কোনো মান সেট না করা হলে, ভ্যারিয়েবলের টাইপের ওপর ভিত্তি করে Go একটি মান দেয়, [যাকে জিরো ভ্যালু বলা হয়][zero-values]।

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## একটি ভ্যারিয়েবল আপডেট করা

একটি ফাংশনের ভেতরে `=` অ্যাসাইনমেন্ট অপারেটর একটি বিদ্যমান ভ্যারিয়েবলের জন্য নতুন মান সেট করতে পারে:

```go
count := 1
count = 2
```

নতুন মানটির টাইপ ভ্যারিয়েবলের টাইপের সমান হতে হবে:

```go
count := 1
count = false // compile error: a Boolean is not an int
```
