# ইনস্টলেশন

আপনার প্ল্যাটফর্মের জন্য সুপারিশকৃত ইনস্টলেশন নির্দেশনা পেতে, [Rust-এর অফিসিয়াল ওয়েবসাইটে][the official Rust website] যান।

শুধু টুলচেইন ইনস্টল করাই সবকিছু নয়! IDE সাপোর্ট প্রোডাক্টিভিটির বিশাল বুস্ট, যা বেশিরভাগ ডেভেলপার এখন আশা করেন। আপনি যদি Visual Studio Code ব্যবহার করেন, তাহলে এর [Rust সাপোর্টের ডকুমেন্টেশন][vscode] দেখুন। আমরা আন্তরিকভাবে সুপারিশ করি আপনি [clippy দিয়ে লিন্টিং][vscode-linting] চালু করুন!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
