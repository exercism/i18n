# পরিচিতি

## অপ্যাক টাইপ

### পরিচিতি

অপ্যাক টাইপ হলো Elm-এ এনক্যাপসুলেশনের একটি কৌশল।
কেউ কেউ এটাকে ইনফরমেশন হাইডিং বা ইমপ্লিমেন্টেশনের খুঁটিনাটি লুকিয়ে রাখা বলেও ডাকেন।
ভ্যালিডেশন প্রয়োগ করতেও এগুলো সাধারণত ব্যবহৃত হয়, [Parse, dont validate][parse-dont-validate] প্যাটার্ন ব্যবহার করে।
উদাহরণস্বরূপ, আপনার একটি `EmailAddress` অপ্যাক টাইপ থাকতে পারে, যেটি শুধু বৈধ ইমেইল ধারণ করতে পারে (একটি `String`-এর বিপরীতে, যেটি যেকোনো কিছু ধারণ করতে পারে)।

### অপ্যাক টাইপ তৈরি করা

[কাস্টম টাইপ][custom-types]-এর এক বা একাধিক *ভ্যারিয়েন্ট* থাকে, আর কম্পাইলার স্বয়ংক্রিয়ভাবে প্রতিটি *ভ্যারিয়েন্ট* তৈরির একটি ফাংশন বানিয়ে দেয়, *ভ্যারিয়েন্ট*-এর নাম ব্যবহার করে।
কাস্টম টাইপ তৈরির এটাই একমাত্র উপায়।
কম্পাইলার এই ভ্যারিয়েন্টগুলোর জন্য ডিস্ট্রাকচারিংয়েরও সুযোগ দেয়।

```elm
type Maybe a
    = Nothing --> Variant implies a 'Nothing' function, with type 'Maybe a', and destructuring of 'Nothing'
    | Just a  --> Variant implies a 'Just' function, with type 'a -> Maybe a', and destructuring of 'Just _'
```

ডিফল্টভাবে এসব কিছুই ফাইল বা মডিউলের ভেতরের বিষয়, আর কোনটা এক্সপোর্ট করবেন তা বেছে নিতে আমরা `exposing` কিওয়ার্ড ব্যবহার করি।
একটি অপ্যাক টাইপ তৈরি করতে, আপনি সহজভাবে *ভ্যারিয়েন্ট*গুলো এক্সপোর্ট না করার সিদ্ধান্ত নেন।

এটা করলে, প্রায় সবসময়ই কাস্টম ফাংশন এক্সপোজ করে *ভ্যারিয়েন্ট* তৈরি ও পাওয়ার আরেকটি উপায় আপনাকে দিতে হয়।
এই কাস্টম ফাংশনগুলো *ভ্যারিয়েন্ট* তৈরি ও পাওয়ার সময় কিছু লজিক প্রয়োগ করার সুযোগ দেয়।
এটি মডিউলের অভ্যন্তরীণ ইমপ্লিমেন্টেশনের খুঁটিনাটি লুকিয়ে রাখে, আর এর মানে হলো, এক্সপোজ করা ফাংশনগুলো একই থাকলে আপনি ইমপ্লিমেন্টেশনের খুঁটিনাটি যত খুশি বদলাতে পারেন।

### Parse, dont validate

অপ্যাক টাইপের সম্ভবত সবচেয়ে কমন ব্যবহার হলো [Parse, dont validate][parse-dont-validate] প্যাটার্ন ব্যবহার করে ভ্যালিডেশন প্রয়োগ করা।
এই প্যাটার্নে আপনি এমন একটি ফাংশন এক্সপোজ করেন, যা আপনার চাওয়ার চেয়ে কম স্ট্রাকচার বা টাইপ সেফটিসম্পন্ন একটি ইনপুট নেয়, যেমন একটি `String`, তারপর সেটিকে আরও বেশি স্ট্রাকচারযুক্ত একটি টাইপে পার্স করে, যেমন `EmailAddress`, হয় টাইপটি রিটার্ন করে, নয়তো একটি এরর রিটার্ন করে (সাধারণত `Maybe` বা `Result`)।

উদাহরণস্বরূপ, নিচের কোডে বাইরের মডিউলগুলোর জন্য `parseEmailAddress` ফাংশন ব্যবহার করে একটি `EmailAddress` টাইপ তৈরি করাই শুধু সম্ভব, তাই আপনি যখন `EmailAddress` টাইপ নিয়ে কাজ করেন, তখন নিশ্চিত থাকতে পারেন যে এটি বৈধ।

```elm
module EmailAddress exposing ( EmailAddress, parseEmailAddress, getEmailAddress )

-- The `EmailAddress` custom type has one variant, also called `EmailAddress`
-- When a custom type has one variant, it is idiomatic to use the same name for both.
type EmailAddress = 
  EmailAddress String

-- create an EmailAddress variant
parseEmailAddress: String -> Maybe EmailAddress
parseEmailAddress candidateEmailAddress =   
  if isValidEmailAddress candidateEmailAddress then
    Just (EmailAddress candidateEmailAddress)
  else
    Nothing

-- get an EmailAddress variant
getEmailAddress: EmailAddress -> String
getEmailAddress ( EmailAddress  emailAdress ) =
  emailAdress

isValidEmailAddress: String -> bool
-- ... 
```
