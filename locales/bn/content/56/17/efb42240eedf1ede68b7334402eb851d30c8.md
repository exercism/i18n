# নির্দেশনা

এই অনুশীলনীতে আপনি [গো গেমের নিয়মগুলো](https://matmoore.github.io/learngo/) প্রয়োগ করবেন। নিয়মগুলো আগে থেকেই লেখা আছে, আপনার শুধু সেগুলো প্রয়োগ করতে হবে যাতে Game আপডেট করা যায় এবং যেকোনো এরর বা নিয়ম লঙ্ঘন সামলানো যায়।

গেমটি এভাবে উপস্থাপন করা হয়েছে:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

গেমটিতে ৪টি নিয়ম আছে:

- প্রতিটি পয়েন্টে কেবল একটি পাথর থাকতে পারে।
- বিপক্ষের পাথর ক্যাপচার করা যায়।
- এমন জায়গায় পাথর রাখা যায় না যেখানে সেটি নিজেকেই ক্যাপচার করবে।
- একই পয়েন্ট দুইবার ব্যবহার করা যায় না।

## 1. নিয়মগুলো প্রয়োগ করুন

`apply_rules` ফাংশনটির ভেতরের অংশটি লিখুন, যেটি একটি প্রাথমিক `Game` ও নিয়মের একটি সেট নেয়, এবং নিয়মগুলো প্রয়োগ হওয়ার পর নতুন `Game` রিটার্ন করে।

নিয়মগুলোর মধ্যে তিনটি নিয়মই নিয়মের লঙ্ঘন খতিয়ে দেখে এবং একটি এরর রিটার্ন করতে পারে, তাই এদের রিটার্ন টাইপ `Result(Game, String)`। এই নিয়মগুলোর যেকোনোটি যদি ব্যর্থ হয়, তবে মূল গেমটি রিটার্ন করা উচিত, তবে `error` ফিল্ডটি সংশ্লিষ্ট এরর দিয়ে আপডেট করা অবস্থায়।

বাকি নিয়মটি লঙ্ঘন খতিয়ে দেখে না, তাই এটি ব্যর্থ হতে পারে না (যদিও এটি একটি পরিবর্তিত `Game` রিটার্ন করতে পারে), আর তাই এর রিটার্ন টাইপ `Game`।

সব নিয়ম যদি পাস করে, তবে নিয়মগুলো থেকে `Game`-এ হওয়া যেকোনো পরিবর্তন ধরে রাখা উচিত, এবং প্লেয়ারও পরিবর্তন করা উচিত।

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
