# পরিচিতি

## স্ট্রিং

স্ট্রিং হলো একগুচ্ছ ক্যারেক্টার, যা কোটেশন চিহ্ন দিয়ে ঘেরা থাকে।
সিঙ্গেল কোট ও ডাবল কোট, দুটোই সমর্থিত।

```php
<?php

$where = "Spain";
$what = 'rain';
```

### স্ট্রিংয়ের ভেতরে ভ্যারিয়েবলের মান বসানো

ডাবল কোটে লেখা স্ট্রিংয়ের ক্ষেত্রে, কোনো ভ্যারিয়েবল স্কোপে থাকা অবস্থায় সেটিকে রেফারেন্স করা হলে তার মানটি স্ট্রিংয়ের ভেতরে বসে যায়।

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### ক্যারেক্টার এনকোডিং সাপোর্ট

ঐতিহাসিকভাবে PHP-এর স্ট্রিং ফাংশনগুলো কেবল ASCII ক্যারেক্টার সমর্থন করত, আধুনিক Unicode এনকোডিং সমর্থন করত না।
প্রতিটি ASCII ক্যারেক্টারের আকার ১ বাইট, অথচ Unicode ক্যারেক্টার ১ থেকে ৪ বাইট পর্যন্ত লম্বা হতে পারে।
নিরাপদে Unicode স্ট্রিং নিয়ে কাজ করতে হলে, পুরোনো ফাংশনগুলোর [মাল্টিবাইট সংস্করণ][multi-byte-fns] দেখুন।

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
