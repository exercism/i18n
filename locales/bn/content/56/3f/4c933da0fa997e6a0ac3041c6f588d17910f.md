# ইনস্টলেশন

Windows বা Linux প্ল্যাটফর্মের জন্য Phix [অফিসিয়াল সাইট][Download] থেকে ডাউনলোড করা যায়।

ইনস্টলেশনের পরে ডিরেক্টরি বিন্যাসটি [ডকুমেন্টেশন][Installation]-এ দেওয়া বিন্যাসের সাথে মিলে যাওয়া উচিত।

'p -test' চালিয়ে পরীক্ষা করুন।

[Installation]: http://phix.x10.mx/docs/html/installation.htm
[Download]: http://phix.x10.mx/download.php
