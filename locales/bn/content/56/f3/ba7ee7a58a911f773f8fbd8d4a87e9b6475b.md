# ভূমিকা

Common Lisp প্রোগ্রামারকে "কমেন্ট" লেখার সুযোগ দেয়, যেগুলো কম্পিউটার উপেক্ষা করে। একলাইনের কমেন্ট শুরু হয় এক বা একাধিক সেমিকোলন (`;`) দিয়ে, আর মাঝে মাঝে আপনি নিচের মতো কিছু দেখতে পারেন:

```lisp
(code...) ; => value
```

এখানে কমেন্টটি দিয়ে বোঝানো হয়, ওই লাইনের কোড রান করার পর Common Lisp কী মান রিটার্ন করে।

একটি লাইনের শেষে ছোট কমেন্টের জন্য একটি সেমিকোলন, কোডের একটি অংশের উপরে বড় কমেন্টের জন্য দুটি, কোনো ফাংশনের মতো কিছু বর্ণনা করা লম্বা কমেন্টের জন্য তিনটি, আর সোর্স ফাইলের উপরে হেডারের মতো কমেন্টের জন্য চারটি সেমিকোলন ব্যবহার করাই প্রচলিত রীতি।
