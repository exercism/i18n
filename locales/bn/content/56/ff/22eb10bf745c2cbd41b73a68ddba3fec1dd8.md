# সম্পর্কে

অ্যারে হলো Factor-এর নির্দিষ্ট দৈর্ঘ্যের সিকোয়েন্স টাইপ: আপনি এলিমেন্ট বদলাতে পারেন, কিন্তু দৈর্ঘ্য বদলাতে পারেন না।
লিটারেল লেখা হয় `{ … }` দিয়ে, এলিমেন্টগুলোর মাঝে হোয়াইটস্পেস থাকে; `arrays` ভোকাবুলারি ছোট কিছু কনস্ট্রাক্টর যোগ করে, যেগুলো স্ট্যাক থেকে মান টেনে নেয়:

| ওয়ার্ড     | স্ট্যাক ইফেক্ট                      |
|----------|-------------------------------------|
| `1array` | `( a     -- { a } )`                |
| `2array` | `( a b   -- { a b } )`              |
| `3array` | `( a b c -- { a b c } )`            |
| `<array>`| `( n elt -- array )`, `elt`-এর `n`টি কপি |
| `array?` | `( obj   -- ? )`, টাইপ প্রেডিকেট   |

`sequences` থেকে আসা কয়েকটি [প্রোটোকল][sequence-protocol] ওয়ার্ড অ্যারের সাথে এত ঘন ঘন আসে যে সেগুলো একসাথে জেনে রাখা মূল্যবান:

| ওয়ার্ড      | স্ট্যাক ইফেক্ট                                        |
|-----------|-------------------------------------------------------|
| `concat`  | `( seqs -- seq )`, সিকোয়েন্সের সিকোয়েন্স ফ্ল্যাটেন করে |
| `join`    | `( seqs glue -- seq )`, একটি সেপারেটর দিয়ে ফ্ল্যাটেন করে |
| `reverse` | `( seq -- newseq )`                                   |
| `index`   | `( elt seq -- i/f )`, এলিমেন্টের ইনডেক্স, অথবা `f`    |
| `member?` | `( elt seq -- ? )`, মেম্বারশিপ টেস্ট                  |

```factor
USING: arrays sequences ;

3 4 2array .                       ! => { 3 4 }
{ { 1 2 } { 3 4 } } concat .       ! => { 1 2 3 4 }
{ 1 2 3 4 } reverse .              ! => { 4 3 2 1 }
"b" { "a" "b" "c" } index .        ! => 1
"b" { "a" "b" "c" } member? .      ! => t
```

[`sets`][sets] ভোকাবুলারির `all-unique?` আর `members`-ও যেকোনো সিকোয়েন্স গ্রহণ করে। এটি কাজে লাগে যখন অ্যারের এলিমেন্টগুলো থেকে ডুপ্লিকেট সরাতে হয়, বা আগে hash-set-এ রূপান্তর না করেই ডুপ্লিকেট আছে কি না যাচাই করতে হয়।
