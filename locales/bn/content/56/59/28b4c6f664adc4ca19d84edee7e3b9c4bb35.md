# ভ্যারিয়েডিক প্যারামিটার

Swift-এ [_ভ্যারিয়েডিক প্যারামিটার_][variadic-parameters] ব্যবহার করে একই টাইপের শূন্য বা তার বেশি মান একটি ফাংশনের একটি মাত্র প্যারামিটারে পাঠানো যায়। প্যারামিটারটির টাইপ অ্যানোটেশনের শেষে `...` যোগ করে এটি বোঝানো হয়।

এই মানগুলো স্বয়ংক্রিয়ভাবে একটি অ্যারেতে গুছিয়ে রাখা হয়, যার এলিমেন্টগুলোর টাইপ ভ্যারিয়েডিক প্যারামিটারটির টাইপের সমান।

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

খেয়াল করুন, ভ্যারিয়েডিক প্যারামিটার ব্যবহার করার সময় Swift-এর একটি সীমাবদ্ধতা আছে।
কোনো ফাংশনের ডেফিনিশনে যদি ভ্যারিয়েডিক প্যারামিটারের পরে আরও প্যারামিটার থাকে, তাহলে ভ্যারিয়েডিক প্যারামিটারের পরের প্রথম প্যারামিটারটির জন্য একটি আর্গুমেন্ট লেবেল থাকা _বাধ্যতামূলক_।
