# পরিচিতি

[অ্যারে][list] হলো Haskell-এর একটি মৌলিক ডেটা টাইপ, যা একগুচ্ছ মান ধরে রাখে।
অ্যারে _অপরিবর্তনীয়_, অর্থাৎ এগুলো পরিবর্তন করা যায় না।
অ্যারে পরিবর্তন করে এমন যেকোনো অপারেশন একটি নতুন অ্যারে রিটার্ন করে।
Prelude-এ এমন বেশ কিছু মেথড আছে, যেগুলো দিয়ে আপনি অ্যারে নিয়ে কাজ করতে পারেন।

Haskell-এ অ্যারে তৈরি হয় [লিংকড লিস্ট][linked-list-wiki] হিসেবে, পরস্পর সংলগ্ন মেমোরি লোকেশনের অ্যারে হিসেবে নয়।
তাই অ্যারের একটি এলিমেন্ট অ্যাক্সেস করতে অ্যারের দৈর্ঘ্যের ওপর নির্ভর করে লিনিয়ার টাইম লাগে।

অ্যারে লেখা যায় লিটারেল ফর্মে, হেড-টেইল নোটেশনে (যেখানে `cons` অপারেটর `:` ব্যবহার করা হয়), অথবা দুইয়ের মিশ্রণে:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

হেড-টেইল নোটেশন দিয়ে একটি অ্যারেতে আইটেম অ্যাপেন্ড করা যায়।

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

ইটারেশনের সময় একটি অ্যারেতে এলিমেন্ট অ্যাপেন্ড করাকে অ্যান্টি-প্যাটার্ন হিসেবে ধরা হয়।
একটি এলিমেন্ট অ্যাপেন্ড করতে হলে গোটা অ্যারের ভেতর দিয়ে হেঁটে গিয়ে শেষে এলিমেন্টটি যোগ করতে হয়; তাই প্রতিটি ইটারেশনে নতুন একটি এলিমেন্ট অ্যাপেন্ড করতে হলে প্রতিটি ইটারেশনে গোটা অ্যারেটির ভেতর দিয়ে হেঁটে যেতে হবে।

উল্টো করে নেওয়া অ্যারের সামনে একটি এলিমেন্ট প্রিপেন্ড করে, তারপর ফলাফলটি উল্টে দিয়ে আমরা একই ফলাফল পেতে পারি। প্রিপেন্ড একটি দ্রুত অপারেশন, এতে কনস্ট্যান্ট টাইম লাগে।

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

অ্যারের জন্য Prelude-এ বেশ কিছু কমন ফাংশন আছে:

- [`head`][head] অ্যারের _হেড_ রিটার্ন করে, অর্থাৎ অ্যারের _প্রথম_ আইটেমটি।
- [`tail`][tail] অ্যারের _টেল_ রিটার্ন করে, অর্থাৎ অ্যারে থেকে _প্রথম_ আইটেমটি _বাদ দিলে_ যা থাকে।
- [`length`][length] অ্যারেতে থাকা আইটেমের সংখ্যা রিটার্ন করে।
- [`elem`][elem] একটি বুলিয়ান মান রিটার্ন করে, যা জানায় আইটেমটি অ্যারেটির একটি এলিমেন্ট কি না।

এছাড়াও আছে [`Data.List` মডিউল][list]।

## অ্যারের টাইপ

Haskell-এ অ্যারে **সমজাতীয়**।
এর মানে অ্যারের সব এলিমেন্টের টাইপ একই।
একই অ্যারেতে ভিন্ন টাইপের এলিমেন্ট রাখতে গেলে আপনি একটি টাইপ এরর পাবেন।

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

একটি অ্যারের টাইপ অ্যানোটেশন হলো `[a]`, যেখানে a সেই টাইপটি, যা অ্যারেটিতে রাখা হয়, যেমন `String` বা `Int`।

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
