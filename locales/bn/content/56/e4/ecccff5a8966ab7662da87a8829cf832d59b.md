# ভূমিকা

একটি বুলিয়ান এক্সপ্রেশন হলো এক বা একাধিক মান সম্পর্কে করা একটি প্রশ্ন, যার উত্তর `true` বা `false` দিয়ে দেওয়া যায়।
একটি ট্রু এক্সপ্রেশন `1` রিটার্ন করে; একটি ফলস এক্সপ্রেশন `0` রিটার্ন করে।
এছাড়াও, সংখ্যাগুলোরও ট্রু/ফলস মান থাকে। শূন্য হলো `false`; অশূন্য হলো `true`।

পুরোনো C কোডে হয় সরাসরি বুলিয়ান মানের জন্য `int` টাইপ ব্যবহার করা হতো, নয়তো প্রোগ্রামার `TRUE` আর `FALSE`-এর মতো কনস্ট্যান্ট ডিফাইন করে `1` ও `0`-কে বুলিয়ান রূপে ম্যাপ করতেন।

C99 ভার্সনে `_Bool` টাইপটি যোগ করা হয়।
`stdbool.h` হেডার ফাইল তিনটি নতুন বুলিয়ান সিম্বল ডিফাইন করে: `bool`, `true` এবং `false`।
`true` ম্যাপ হয় `1`-এ, `false` ম্যাপ হয় `0`-এ, আর `bool` ম্যাপ হয় `_Bool`-এ।
তাই এখন প্রোগ্রামারদের সরাসরি `int` ব্যবহার করা বা নিজেদের মতো বুলিয়ান ম্যাপিং বানানোর দরকার নেই; তারা `stdbool.h` ইনক্লুড করলেই কোডে স্বয়ংক্রিয়ভাবে বুলিয়ান সিম্বল পেয়ে যান।

## তুলনা অপারেটর

C সাপোর্ট করে ছয়টি তুলনা অপারেটর: `==` (সমান), `!=` (সমান নয়), `>` (বড়), `<` (ছোট), `>=`(বড় বা সমান), `<=` (ছোট বা সমান)।
এই অপারেটরগুলি মানগুলোর মধ্যে সম্পর্ক তুলনা করে এবং সেগুলোকে বুলিয়ান মানে পরিণত করে।

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## বুলিয়ান অপারেটর

C সাপোর্ট করে তিনটি বুলিয়ান অপারেটর: `||` (অথবা), `&&` (এবং), আর `!` (নয়)।

`!` একটি অপারেন্ড নিয়ে ব্যবহার করা হয়।
এটি অপারেন্ডটির বুলিয়ান মান উল্টে দেয়।
যেমন, `0` হলো `false`, কিন্তু `!0` হলো `true`।

`||` আর `&&` দুটি অপারেন্ড নিয়ে ব্যবহার করা হয়।
ডান দিকের অপারেন্ডটি তখনই ইভ্যালুয়েট করা হয়, যখন বাম দিকের অপারেন্ড দিয়েই এক্সপ্রেশনের ফলাফল আগেই নির্ধারিত হয়ে যায় না।
অর্থাৎ, `||` তার ডান দিকের অপারেন্ডটি তখনই ইভ্যালুয়েট করে, যখন বাম দিকের অপারেন্ডটি `false` হয়।
`&&` তার ডান দিকের অপারেন্ডটি তখনই ইভ্যালুয়েট করে, যখন বাম দিকের অপারেন্ডটি `true` হয়।
