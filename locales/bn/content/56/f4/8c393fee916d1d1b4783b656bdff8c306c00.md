# নির্দেশনা

এই অনুশীলনীতে আপনি কারখানার কর্মীদের জন্য নামের ব্যাজ প্রিন্ট করার কোড লিখবেন। কর্মীদের একটি ID, একটি নাম ও ডিপার্টমেন্টের নাম থাকে। কর্মীদের ব্যাজের লেবেলগুলো নিচের ফরম্যাটে তৈরি হয়: `"[id] - name - DEPARTMENT"`.

## 1. একজন কর্মীর জন্য ব্যাজ প্রিন্ট করুন

`NameBadge.print/3` ফাংশনটি ইমপ্লিমেন্ট করুন। এটি প্যারামিটার হিসেবে একটি id, একটি নাম ও একটি ডিপার্টমেন্ট নেবে। এটি ব্যাজের লেবেলটি রিটার্ন করবে, যেখানে ডিপার্টমেন্টের নামটি থাকবে বড় হাতের অক্ষরে।

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. নতুন কর্মীর জন্য ব্যাজ প্রিন্ট করুন

কম্পিউটার সিস্টেমের একটি খুঁতের কারণে, নতুন কর্মীরা কারখানায় কাজ শুরু করার সময় মাঝে মাঝে তখনও কোনো ID পায় না। যেহেতু ব্যাজ বাধ্যতামূলক, তাই তারা ID প্রিফিক্স ছাড়া একটি সাময়িক ব্যাজ পাবে।

`NameBadge.print/3` ফাংশনটি এক্সটেন্ড করুন। id না থাকলে এটি id ছাড়াই একটি ব্যাজ প্রিন্ট করবে।

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. মালিকের জন্য ব্যাজ প্রিন্ট করুন

কারখানার মালিককেও সব সময় ব্যাজ পরে থাকতে হয়। তবে মালিকের কোনো ডিপার্টমেন্ট থাকে না। এক্ষেত্রে লেবেলে ডিপার্টমেন্টের নামের বদলে `"OWNER"` প্রিন্ট হবে।

`NameBadge.print/3` ফাংশনটি এক্সটেন্ড করুন। ডিপার্টমেন্ট না থাকলে ধরে নিন ব্যাজটি কোম্পানির মালিকের।

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

মনে রাখবেন, মালিক একইসাথে নতুন কর্মীও হতে পারেন।

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
