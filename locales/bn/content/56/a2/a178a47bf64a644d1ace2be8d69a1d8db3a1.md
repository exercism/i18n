# সম্পর্কে

Haxe-তে, এক্সেপশন হলো কোড চালানোর সময় ঘটে যাওয়া এরর নিরাপদে সামলানোর একটি উপায়। প্রতিটি এক্সেপশনে এররটি বর্ণনা করে এমন একটি বার্তা থাকা উচিত। `throw` কিওয়ার্ড ব্যবহার করে আমরা এক্সেপশন _থ্রো_ করতে পারি:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

কোনো এক্সেপশন থ্রো করা হলে কোড খুঁজে দেখে এররটি সামলানোর দায়িত্বে কোনো অংশ নির্ধারিত আছে কি না। যদি খুঁজে না পায়, তবে এটি এরর বার্তাটি দেখায় এবং একই সঙ্গে প্রোগ্রামের কার্যক্রমও থামিয়ে দেয়।

Haxe-তে এক্সেপশন সামলাতে আমরা `try-catch` ব্লক ব্যবহার করি। এই ব্লক স্টেটমেন্টে থাকে একটি `try` ব্লক আর এক বা তার বেশি `catch` ব্লক। `try` ব্লক কোডের একটি অংশ _চালানোর চেষ্টা_ করে, আর `catch` ব্লকটি অপেক্ষা করে, যাতে কোনো এক্সেপশন থ্রো হলে সেটি _ধরে_ ফেলা যায় এবং কার্যক্রম থেমে না যায়। `catch` ব্লক কোনো এক্সেপশন ধরতে পারলে ব্লকের ভেতরের সব কিছুও চালায়:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch` ব্লকের আর্গুমেন্টের টাইপ বাদ দিতে হবে।

এটা মনে রাখা জরুরি যে এক্সেপশন কেবল সেসব ক্ষেত্রেই ব্যবহার করা উচিত যেখানে ব্যতিক্রমী কিছু ঘটে, অর্থাৎ এমন কোনো এরর যা বিশেষভাবে সামলানো প্রয়োজন। প্রোগ্রামের কন্ট্রোল-ফ্লোর জন্য এটি ব্যবহার করা উচিত নয়, কারণ তা খারাপ ডিজাইন হিসেবে গণ্য হয়, যা প্রায়ই খারাপ পারফরম্যান্স আর রক্ষণাবেক্ষণযোগ্যতার দিকে ঠেলে দেয়।
