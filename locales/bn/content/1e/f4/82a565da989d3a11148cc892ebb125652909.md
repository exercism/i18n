# ভূমিকা

## ওভারফ্লো

কোনো গাণিতিক অপারেশন বা টাইপ কনভার্সনের মতো গণনার ফল যদি গ্রহণকারী টাইপের ধারণক্ষমতার চেয়ে বড় একটি মান হয়, তখন পাটিগণিতিক ওভারফ্লো ঘটে।

এমন পরিস্থিতিতে `int` ও `long` এবং তাদের unsigned প্রতিরূপের এক্সপ্রেশনগুলো নীরবে ঘুরে যায়।

`checked` কিওয়ার্ড ব্যবহার করে ইন্টিজার গণনার আচরণ পরিবর্তন করা যায়। `checked` ব্লকের ভেতরে ওভারফ্লো ঘটলে `OverflowException`-এর একটি ইনস্ট্যান্স থ্রো করা হয়।

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

`float` ও `double` টাইপের এক্সপ্রেশন ইনফিনিটি নামের একটি বিশেষ মান গ্রহণ করে।

`decimal` টাইপের এক্সপ্রেশন `OverflowException`-এর একটি ইনস্ট্যান্স থ্রো করে।
