# নির্দেশাবলি

Isaac's Asteroid Exploration Co.-এর ক্লেইমস ডিপার্টমেন্ট আপনাকে তাদের জমি দাবি সিস্টেমের পারফরম্যান্স উন্নত করার দায়িত্ব দিয়েছে।

যখনই কোনো অ্যাস্টেরয়েড আহরণের জন্য প্রস্তুত হয়, স্পেকুলেটরদের জমির একটি প্লটে নিজেদের দাবি স্টেক করার আমন্ত্রণ জানানো হয়।
অ্যাস্টেরয়েডের জমি ওভারল্যাপ না হওয়া আয়তাকার প্লটে ভাগ করা হয়েছে।
মাপ ভিন্ন ভিন্ন হলেও সবার বাহু স্থানাঙ্ক অক্ষের সমান্তরাল।
স্পেকুলেটররা স্থানাঙ্ক উল্লেখ করে জমির প্লটগুলোর একটি দাবি করে।

আপনার লক্ষ্য হলো জমির হিড়িক সামলানোর মতো একটি পারফরম্যান্ট সিস্টেম তৈরি করা, যে হিড়িকের কারণে আগে ওয়েবসাইট ক্র্যাশ করেছিল।

পরিমাপের একক ১০০ মিটার, তবে এই কাজগুলোতে এটি উপেক্ষা করা যায়।

## 1. একটি পয়েন্ট ডিফাইন করুন

`x` ও `y` স্থানাঙ্ক ধারণ করার জন্য একটি `struct` ডিফাইন করুন।
এগুলো বেশ ছোট অ-ঋণাত্মক ইন্টিজার, তাই `UInt16` টাইপ ব্যবহার করুন।

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. একটি Plot ডিফাইন করুন

যেহেতু সব প্লটই আয়তাকার হতে হবে এবং অনুভূমিক ও উল্লম্ব বাহু থাকতে হবে, তাই সেগুলো ডিফাইন করতে কেবল দুটি বিপরীত কোণা দরকার।

দুটি Coord স্ট্রাকট কনস্ট্রাক্টরে নিয়ে `Plot` স্ট্রাকটটি ইমপ্লিমেন্ট করুন।

`Plot` একটি কিওয়ার্ড স্ট্রাকট হবে, যার ফিল্ড হবে `bottom_left` ও `top_right`।

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. আপনার দাবি আগেই স্টেক করা হয়েছে কি না তা যাচাই করুন

এই দাবিগুলোর জন্য প্রতিযোগিতা আছে, তাই আপনার দাবি অনুমোদনের আগে রেজিস্টারে থাকা বিদ্যমান দাবিগুলোর সঙ্গে মিলিয়ে যাচাই করা হবে।

কোনো দাবি আগেই স্টেক করা হয়েছে কি না তা নির্ধারণ করতে `is_claim_staked()` ফাংশনটি ইমপ্লিমেন্ট করুন।

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. স্পেকুলেটররা কোণার স্থানাঙ্ক দিয়ে চিহ্নিত একটি প্লট উল্লেখ করে নিজেদের দাবি স্টেক করতে পারেন

একটি দাবি নিবন্ধন করার সুযোগ দিতে `stake_claim!()` মিউটেটিং ফাংশনটি ইমপ্লিমেন্ট করুন।

একই দাবি আগেই স্টেক করা থাকলে `false` রিটার্ন করুন।

নতুন দাবি সম্ভব হলে সেটি রেজিস্টারে যোগ করুন এবং `true` রিটার্ন করুন।

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. একটি প্লটের দীর্ঘতর বাহুর দৈর্ঘ্য বের করুন।

কোনো দাবির দীর্ঘতর বাহু (অনুভূমিক বা উল্লম্ব) বের করতে `get_longest_side()` ফাংশনটি ইমপ্লিমেন্ট করুন।

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. গবেষণার উদ্দেশ্যে সবচেয়ে দীর্ঘ বাহুযুক্ত দাবিকৃত প্লটটি খুঁজে বের করুন

সব নিবন্ধিত দাবি পরীক্ষা করে সবচেয়ে দীর্ঘ বাহুযুক্ত দাবিটি (বা দাবিগুলো) রিটার্ন করতে `get_claim_with_longest_side()` ফাংশনটি ইমপ্লিমেন্ট করুন।

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Plot (বা Plot-গুলো) একটি `Set` হিসেবে রিটার্ন করুন; সবচেয়ে দীর্ঘ প্লট একটিই হলে একটিমাত্র এলিমেন্ট, আর একই দৈর্ঘ্যের একাধিক প্লট থাকলে একাধিক এলিমেন্ট থাকবে।
