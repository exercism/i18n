# নির্দেশনা

এই অনুশীলনীতে আপনি কিছু কোড লিখবেন, যা আপনার প্রিয় রান্নার বই থেকে একটি চমৎকার লাসানিয়া রান্না করতে আপনাকে সাহায্য করবে।

আপনার সামনে তিনটি কাজ আছে, যেগুলোর সবই লাসানিয়া রান্নায় ব্যয় হওয়া সময়ের সাথে সম্পর্কিত।

## 1. ওভেনে প্রত্যাশিত সময় মিনিটে নির্ধারণ করুন

ওভেনে লাসানিয়াটি কত মিনিট থাকা উচিত তা যাচাই করার জন্য `expectedMinutesInOven` কনস্ট্যান্টটি ডিফাইন করুন। রান্নার বই অনুযায়ী, ওভেনে প্রত্যাশিত সময় মিনিটে ৪০:

```Haskell
expectedMinutesInOven
    --> 40
```

## 2. প্রস্তুতির সময় মিনিটে হিসাব করুন

`preparationTimeInMinutes` ফাংশনটি ডিফাইন করুন, যেটি প্যারামিটার হিসেবে লাসানিয়ায় আপনি যে সংখ্যক স্তর যোগ করেছেন তা নেয় এবং লাসানিয়া প্রস্তুত করতে আপনি কত মিনিট ব্যয় করেছেন তা রিটার্ন করে; ধরে নিন প্রতিটি স্তর প্রস্তুত করতে আপনার ২ মিনিট লাগে।

```Haskell
preparationTimeInMinutes 3
    --> 6
```

## 3. অতিবাহিত সময় মিনিটে হিসাব করুন

`elapsedTimeInMinutes` ফাংশনটি ডিফাইন করুন, যেটি দুটি প্যারামিটার নেয়: প্রথম প্যারামিটারটি হলো লাসানিয়ায় আপনি যে সংখ্যক স্তর যোগ করেছেন, আর দ্বিতীয় প্যারামিটারটি হলো লাসানিয়া কত মিনিট ধরে ওভেনে আছে। ফাংশনটি রিটার্ন করবে লাসানিয়া রান্না করতে আপনি কত মিনিট কাজ করেছেন, যা হলো প্রস্তুতির সময় মিনিটে এবং এই মুহূর্তে লাসানিয়া ওভেনে যে সময় মিনিটে ব্যয় করেছে তার যোগফল।

```Haskell
elapsedTimeInMinutes 3 20
    --> 26
```
