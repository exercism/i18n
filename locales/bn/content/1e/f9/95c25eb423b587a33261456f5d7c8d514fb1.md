# সম্পর্কে

সাধারণ ইংরেজির মতো পড়া যায় এমন কোড লিখুন।

Visual Basic একই .NET রানটাইমে চলে, যেটিতে C# এবং F# চলে।
আপনি LINQ, জেনেরিকস আর async/await পান, কিন্তু এর সিনট্যাক্স তৈরি হয়েছে পড়ার জন্য, ডিকোড করার জন্য নয়।

আপনি যদি ইতিমধ্যে C# বা F# জানেন, তাহলে .NET রানটাইম এবং লাইব্রেরিগুলো আপনার কাছে পরিচিত হবে।
আপনি যদি VB6, VBA বা VBScript জানেন, তাহলে সেই পরিচিত সিনট্যাক্সের পিছনে এখন আছে যুদ্ধে পোড় খাওয়া .NET রানটাইম।

মেলাতে হবে না কোনো দ্বিতীয় বন্ধনী, খুঁজতে হবে না কোনো সেমিকোলন।
