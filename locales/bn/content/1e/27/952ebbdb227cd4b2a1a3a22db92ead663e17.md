# রেফারেন্স ও স্ন্যাপশট

কোনো ফাংশনে একটি ভ্যারিয়েবল পাস করলে সাধারণত তার ওনারশিপ স্থানান্তরিত হয়ে যায়, ফলে মূল ভ্যারিয়েবলটি আর ব্যবহার করা যায় না। একই স্টেট একাধিকবার অ্যাক্সেস করতে হলে এটি বেশ ঝামেলার হতে পারে। কোনো মান ধ্বংস বা মুভ না করেই পাস করার জন্য Cairo-তে দুটি ফিচার আছে, যাদের নাম `references` এবং `snapshots`।

## স্ন্যাপশট

স্ন্যাপশট নির্দিষ্ট কোনো এক সময়ে একটি মানের অপরিবর্তনীয় ভিউ দেয়, যার ফলে আপনি ভ্যারিয়েবলটির ওনারশিপ ধরে রেখেই তার স্টেট অ্যাক্সেস করতে পারেন। ভ্যারিয়েবলটিতে যেকোনো পরিবর্তন একটি নতুন মেমোরি সেল তৈরি করে, আর স্ন্যাপশটের ভিউ অপরিবর্তিত থাকে।

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## ডিস্ন্যাপ অপারেটর

কোনো স্ন্যাপশটকে আবার একটি সাধারণ ভ্যারিয়েবলে রূপান্তর করতে আপনি ডিস্ন্যাপ অপারেটর `*` ব্যবহার করতে পারেন, যা `@` অপারেটরের বিপরীত হিসেবে কাজ করে। শুধু যেসব টাইপ `Copy` ট্রেইট ইমপ্লিমেন্ট করে, সেগুলোই ডিস্ন্যাপ করা যায়।

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## মিউটেবল রেফারেন্স

মিউটেবল রেফারেন্স ব্যবহার করে আপনি একটি ফাংশনে মিউটেবল মান পাস করতে পারেন এবং সেগুলো পরোক্ষভাবে ফিরে আসে, ফলে কলিং কনটেক্সটেই ওনারশিপ অটুট থাকে। `mut` কিওয়ার্ড দিয়ে ভ্যারিয়েবলটি মিউটেবল হিসেবে ঘোষণা করা থাকলে `ref` মডিফায়ার ব্যবহার করে এটি করা যায়।

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
