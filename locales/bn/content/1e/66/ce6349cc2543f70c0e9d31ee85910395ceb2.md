# নির্দেশনার পরিশিষ্ট

## রেজিস্টার

| রেজিস্টার | ব্যবহার      | টাইপ    | বর্ণনা                                  |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | ইনপুট        | ঠিকানা  | নাল ক্যারেক্টারে শেষ হওয়া ইনপুট স্ট্রিং  |
| `$a1`    | ইনপুট/আউটপুট | ঠিকানা  | নাল ক্যারেক্টারে শেষ হওয়া আউটপুট স্ট্রিং |
| `$t0-9`  | সাময়িক       | যেকোনো  | সাময়িক স্টোরেজের জন্য ব্যবহৃত           |
