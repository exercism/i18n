# ইঙ্গিত

## সাধারণ

- সব ক্লিনআপ ওয়ার্ড থাকে [`destructors`][destructors]-এ।
- `:>` এবং `::` (লোকালস) মাল্টি-পাম্প বডিগুলোকে পড়তে সহজ রাখে। আপনি যদি এগুলো ব্যবহার করতে চান, তবে `USING:`-এ `locals` যোগ করুন।

## 1. বিল্জ খালি করুন

- একটি ওয়ার্ড: `dispose`।

## 2. পাম্প-আউট রুটিন

- একটি ওয়ার্ড: `with-disposal`। ক্লোজিং `;`-এর পরে `inline` যোগ করুন, যাতে কম্পাইলার কোয়োটেশন আর্গুমেন্টের ভেতরটা দেখতে পারে: `: pump-out ( pump quot -- ) with-disposal ; inline`।

## 3. পুরো শিফটের রুটিন

- `with-destructors` দিয়ে স্কোপ খুলুন। তার ভেতরে প্রতিটি পাম্প `&dispose` দিয়ে রেজিস্টার করুন, তারপর কোয়োটেশনটি `call` করুন। লোকালস ব্যবহার করলে: `[ pump-a &dispose pump-b &dispose quot call ] with-destructors`।

## 4. ঝুঁকিপূর্ণ পাম্প-আউট

- টাস্ক ৩-এর মতোই, তবে একটিমাত্র পাম্পে `|dispose` (শুধু ব্যর্থতার ক্ষেত্রে) ব্যবহার করা হয়।

## 5. কাস্টম ডিসপোজেবল: ভালভ

- `TUPLE: valve < disposable is-open ;`। এখানে `<` `disposable`-কে এক্সটেন্ড করে, ফলে ফ্রেমওয়ার্কের মেশিনারি উত্তরাধিকারসূত্রে পাওয়া যায়।
- `<valve>` ব্যবহার করে `new-disposable` (সাধারণ `new` নয়), যাতে নতুন ভালভটি ফ্রেমওয়ার্কে রেজিস্টার হয়।
- `M: valve dispose*` হলো আপনার ক্লিনআপ হুক। স্ট্যাকে কিছু না রিটার্ন করা গুরুত্বপূর্ণ, কারণ `>>is-open` টিউপলটি উপরে রেখে যায়, তাই শেষে `drop` দিন।
