# নির্দেশনার পরিশিষ্ট

## `.to_string()`-এর জন্য Rust ট্রেইট

আপনাকে `Clock` স্ট্রাক্টের জন্যও `.to_string()` ইমপ্লিমেন্ট করতে হবে।
আমরা `Clock`-এর অবস্থা দেখানোর জন্য এটি ব্যবহার করব।
আপনি এটি সরাসরি ইমপ্লিমেন্ট করে করতে পারেন, অথবা [Display ট্রেইট][display-trait] ব্যবহার করে করতে পারেন।

সে ক্ষেত্রে বরং `Clock`-এর জন্য [Display ট্রেইট][display-trait] ইমপ্লিমেন্ট করে দেখুন।

ট্রেইট একেক টাইপের জন্য ফাংশনালিটি ইমপ্লিমেন্ট করার একটি সাধারণ উপায় দেয়।

আরও শেখার জন্য ভেবে দেখুন, `Clock` টাইপের জন্য `String::from` কীভাবে ইমপ্লিমেন্ট করা যায়।
এটি আসলে ইমপ্লিমেন্ট করা আপনার জন্য জরুরি নয়। গন্তব্য টাইপ `String` হলে সাধারণত `Display`-ই ভালো পছন্দ, তাই এটি `Display`-এর সাথে অপ্রয়োজনীয় পুনরাবৃত্তি মাত্র। তবে আপনার টুলকিটে কয়েকটি টাইপ কনভার্সন ট্রেইট থাকা কাজে লাগে।

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
