# ভূমিকা

R-এ আলাদা কোনো [সেট][wiki-set] টাইপ নেই, বরং ভেক্টরের উপর অনুরূপ অপারেশন করার জন্য বিভিন্ন ফাংশন ব্যবহার করে।

[`%in%`][ref-match] অপারেটরটি সেটের সদস্যতা পরীক্ষা করে।
এই ইনফিক্স অপারেটরটি `is.element()` ফাংশনের প্রতিশব্দ।

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

প্রাসঙ্গিক ফাংশনগুলো হলো:

- [`unique()`][ref-unique] ডুপ্লিকেট সরানোর জন্য।
- [`union()`][ref-sets] সেট একত্র করার জন্য (গাণিতিকভাবে, `A ∪ B`)।
- [`intersect()`][ref-sets] উভয় সেটের কমন এলিমেন্ট খুঁজে বের করার জন্য (`A ∩ B`)।
- [`setdiff()`][ref-sets] একটি সেট থেকে আরেকটি সেট বিয়োগ করার জন্য (`A - B`)।
- [`setequal`][ref-sets] ডুপ্লিকেট ও ক্রম উপেক্ষা করে সেটের সমতা পরীক্ষা করার জন্য।

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

প্রতিটি ক্ষেত্রে, ফাংশনটি একটি কপি রিটার্ন করে এবং আর্গুমেন্টগুলো অপরিবর্তিত রাখে।

## হ্যাশ টেবিল

উপরোক্ত ভেক্টর অপারেশনগুলো base R-এর অংশ।
এগুলো ছোট সমস্যার জন্য উপযোগী, কিন্তু বড় সেটের জন্য ধীর হয়ে যায়।

বিভিন্ন থার্ড-পার্টি প্যাকেজ [হ্যাশ টেবিল][wiki-hash] ইমপ্লিমেন্ট করে, কিছু প্রেক্ষাপটে পারফরম্যান্স উন্নত করতে।

উদাহরণস্বরূপ, [`hashtable`][ref-hashtable] প্যাকেজটি `hashmap` ও `hashset`-এর ইমপ্লিমেন্টেশন প্রদান করে, যেগুলো আরও ভালোভাবে স্কেল করে।
বেশিরভাগ এক্সটার্নাল প্যাকেজের মতো, এটি Exercism-এর মধ্যে পাওয়া যায় না, তবে বাস্তব-জগতের সমস্যার জন্য এটি খতিয়ে দেখার মতো।
