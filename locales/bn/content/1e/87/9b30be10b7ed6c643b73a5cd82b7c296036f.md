# নির্দেশাবলি

এই অনুশীলনীতে আপনি বিভিন্ন ধরনের রিমোট কন্ট্রোল গাড়ির মধ্যে রেস আয়োজন করবেন। প্রতিটি গাড়ির নিজস্ব গতি ও ব্যাটারি ড্রেনের বৈশিষ্ট্য থাকে।

গাড়িগুলো পূর্ণ (১০০%) ব্যাটারি নিয়ে শুরু করে। রিমোট কন্ট্রোল দিয়ে গাড়িটি চালানোর প্রতিবার সেটি গাড়ির গতির সমান মিটার অতিক্রম করে, আর তার ব্যাটারি ড্রেন অবশিষ্ট ব্যাটারির শতাংশ কমিয়ে দেয়।

কোনো গাড়ির ব্যাটারি যদি তার ব্যাটারি ড্রেনের শতাংশের চেয়ে কম হয়ে যায়, তাহলে আপনি আর সেই গাড়ি চালাতে পারবেন না।

প্রতিটি রেস ট্র্যাকের নিজস্ব দূরত্ব থাকে। ব্যাটারি শেষ না হয়ে গাড়িটি ট্র্যাক শেষ করতে পারে কি না, তা যাচাই করে গাড়িগুলোর পরীক্ষা করা হয়।

আপনার সামনে ছয়টি কাজ আছে, যার প্রতিটিতে রিমোট কন্ট্রোল গাড়ির ইন্সট্যান্স নিয়ে কাজ করতে হবে।

## 1. একটি রিমোট কন্ট্রোল গাড়ি তৈরি করা

`RemoteControlCar` ক্লাসের জন্য একটি কনস্ট্রাক্টর ডিফাইন করে রিমোট কন্ট্রোল গাড়ি তৈরি করার সুযোগ দিন, যেটি প্যারামিটার হিসেবে নেয় গাড়ির গতি (মিটারে) এবং ব্যাটারি ড্রেনের শতাংশ, দুটিই `int` টাইপের:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. একটি রেস ট্র্যাক তৈরি করা

`RaceTrack` ক্লাসের জন্য একটি কনস্ট্রাক্টর ডিফাইন করে রেস ট্র্যাক তৈরি করার সুযোগ দিন, যেটি একমাত্র প্যারামিটার হিসেবে নেয় ট্র্যাকের দূরত্ব (মিটারে), যা `int` টাইপের:

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. গাড়ি চালানো

`RemoteControlCar.Drive()` মেথডটি ইমপ্লিমেন্ট করুন, যা গাড়ির গতির ভিত্তিতে অতিক্রান্ত মিটারের সংখ্যা হালনাগাদ করে। এছাড়া `RemoteControlCar.DistanceDriven()` মেথডটি ইমপ্লিমেন্ট করুন, যা গাড়িটি কত মিটার অতিক্রম করেছে তা রিটার্ন করে:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. ব্যাটারি শেষ হয়ে গেছে কি না যাচাই করা

`RemoteControlCar.Drive()` মেথডটি হালনাগাদ করুন যাতে তা গাড়ির ব্যাটারি ড্রেনের ভিত্তিতে ব্যাটারি ড্রেন করে। এছাড়া `RemoteControlCar.BatteryDrained()` মেথডটি ইমপ্লিমেন্ট করুন, যা বলে দেয় ব্যাটারি ড্রেন হয়ে গেছে কি না:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. নাইট্রো রিমোট কন্ট্রোল গাড়ি তৈরি করা

সবচেয়ে বেশি বিক্রি হওয়া রিমোট কন্ট্রোল গাড়িটি হলো নাইট্রো, যার চমকপ্রদ সর্বোচ্চ গতি ৫০ মিটার এবং ব্যাটারি ড্রেন ৪%। এই ধরনের গাড়ি রিটার্ন করার জন্য (স্ট্যাটিক) `RemoteControlCar.Nitro()` মেথডটি ইমপ্লিমেন্ট করুন:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. একটি রিমোট কন্ট্রোল গাড়ি একটি রেস শেষ করতে পারে কি না যাচাই করা

একটি রেস ট্র্যাক শেষ করতে হলে গাড়িটিকে ট্র্যাকের দূরত্ব পথ চালাতে পারতে হবে। এর মানে ফিনিশ লাইন পার হওয়ার আগে তার ব্যাটারি ড্রেন হয়ে যাওয়া চলবে না। `RaceTrack.TryFinishTrack()` মেথডটি ইমপ্লিমেন্ট করুন, যেটি প্যারামিটার হিসেবে একটি `RemoteControlCar` ইন্সট্যান্স নেয় এবং গাড়িটি রেস ট্র্যাক শেষ করতে পারলে `true` রিটার্ন করে, অন্যথায় `false` রিটার্ন করে:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
