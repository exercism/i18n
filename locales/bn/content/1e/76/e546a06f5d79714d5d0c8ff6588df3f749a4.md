# নির্দেশাবলীর সংযোজন

## এক্সেপশন মেসেজ

কখনও কখনও [এক্সেপশন রেইজ করা](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) প্রয়োজন হয়। এটি করলে আপনি সর্বদা একটি **অর্থবহ এরর মেসেজ** যুক্ত করবেন, যাতে বোঝা যায় এররটির উৎস কী। এতে আপনার কোড আরও সহজে পড়া যায় এবং ডিবাগ করতে অনেক সুবিধা হয়। যেসব ক্ষেত্রে আপনি জানেন যে এররের উৎসটি একটি নির্দিষ্ট ধরনের হবে, সেসব ক্ষেত্রে আপনি [বিল্ট-ইন এরর টাইপগুলোর](https://docs.python.org/3/library/exceptions.html#base-classes) একটি রেইজ করা বেছে নিতে পারেন, তবে তবুও একটি অর্থবহ মেসেজ যুক্ত করা উচিত।

এই নির্দিষ্ট অনুশীলনীতে `slice()` ফাংশনে ইনপুট দেওয়া series এবং/অথবা length প্যারামিটার খালি বা সীমার বাইরে থাকলে `ValueError` "থ্রো" করতে আপনাকে [raise স্টেটমেন্ট](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) ব্যবহার করতে হবে। টেস্ট পাস হবে কেবল তখনই, যদি আপনি `raise` করেন এবং তার সঙ্গে একটি মেসেজও যুক্ত করেন।

একটি মেসেজসহ `ValueError` রেইজ করতে, মেসেজটি `exception` টাইপের আর্গুমেন্ট হিসেবে লিখুন:

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
