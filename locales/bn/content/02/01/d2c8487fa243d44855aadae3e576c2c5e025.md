# নির্দেশাবলি

**Chrono Realms**-এ Time Keepers প্রায়ই শুধু টাইমলাইনের ট্রি নয়, বরং **Chrono Chains** নিয়েও কাজ করেন, অর্থাৎ লিঙ্কড **TimeNodes**-এর সিকোয়েন্স, যেখানে প্রতিটি **TimeNode** সময়ের একটি নির্দিষ্ট মুহূর্ত নির্দেশ করে।
একটি **Chrono Chain** হলো ক্রমানুসারী মুহূর্তের একটি সরল পথ, যেখানে প্রতিটি **TimeNode** পরবর্তীটির সাথে সংযুক্ত থাকে।
এই **Chrono Chains** নির্দিষ্ট কিছু ইভেন্টের সিরিজের মধ্য দিয়ে ভ্রমণ করার সময় কাজে লাগে, কারণ এগুলো Time Keepers-কে একটি একক টাইমলাইন অনুসরণ করার সুযোগ দেয়।

তবে এই সম্ভাব্য দীর্ঘ **Chrono Chains** সামলাতে Time Keepers **স্মার্ট পয়েন্টার (Box<T>)** ব্যবহার করেন, যাতে অপ্রয়োজনীয় মেমরি ডুপ্লিকেশন বা ওভারফ্লো ছাড়াই নিরাপদে মুহূর্তের এই অ্যারেগুলো ব্যবস্থাপনা ও ট্রাভার্স করতে পারেন।
প্রতিটি **TimeNode** পরবর্তী নোডের একটি রেফারেন্স ধারণ করে, যা একটি রিকার্সিভ স্ট্রাকচার তৈরি করে।

শিক্ষানবিশ হিসেবে আপনার কাজ হলো স্মার্ট পয়েন্টার ব্যবহার করে একটি **Chrono Chain** কে রিকার্সিভ অ্যারে স্ট্রাকচার হিসেবে ইমপ্লিমেন্ট করা।

এই অনুশীলনীতে আপনি:

1. একটি রিকার্সিভ `ChronoChain` enum তৈরি করুন, যা মুহূর্তের একটি অ্যারে প্রতিনিধিত্ব করে।
2. রিকার্সিভ নোডগুলো সংরক্ষণ করতে `Box<T>` স্মার্ট পয়েন্টার ব্যবহার করুন।
3. `u32` মানের একটি অ্যারে থেকে একটি `ChronoChain` তৈরি করার একটি ফাংশন ইমপ্লিমেন্ট করুন।
4. `ChronoChain` ট্রাভার্স করে অ্যারেতে সংরক্ষিত মানগুলো যোগ করার একটি ফাংশন ইমপ্লিমেন্ট করুন।

## 1. রিকার্সিভ `ChronoChain` enum ডিফাইন করুন

দুটি ভ্যারিয়েন্ট সহ একটি রিকার্সিভ enum `ChronoChain` তৈরি করুন:

- `End`: অ্যারের শেষ নির্দেশ করে।
- `Link`: একটি `u32` মান এবং চেইনের পরবর্তী নোডের একটি বক্সড রেফারেন্স ধারণ করে।

## 2. ChronoChain তৈরির জন্য একটি ফাংশন তৈরি করুন

এমন একটি ফাংশন `ChronoChain::build` লিখুন যা `u32` মানের একটি অ্যারে নেয় এবং স্মার্ট পয়েন্টার ব্যবহার করে মানগুলো ক্রমানুসারে লিঙ্ক করে একটি `ChronoChain` রিটার্ন করে।

## 3. sum ফাংশনটি ইমপ্লিমেন্ট করুন

`ChronoChain` রিকার্সিভভাবে ট্রাভার্স করে সব নোডের মান যোগ করার জন্য একটি ফাংশন `ChronoChain::sum` লিখুন।

## ব্যবহারের উদাহরণ

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
