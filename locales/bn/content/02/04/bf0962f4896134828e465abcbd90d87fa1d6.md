# পরিচিতি

Gleam-এ ফার্স্ট ক্লাস ফাংশন আছে, অর্থাৎ ফাংশন হলো সাধারণ মান, যেগুলো ভ্যারিয়েবলে অ্যাসাইন করা যায়, আর্গুমেন্ট হিসেবে পাঠানো যায়, আর অন্য ফাংশন থেকে রিটার্ন করা যায়।

মডিউলে ডিফাইন করা একটি নামযুক্ত ফাংশনকে তার নাম দিয়েই রেফার করা যায়।

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam-এ অ্যানোনিমাস ফাংশনও আছে, যেগুলো অন্য ফাংশনের ভেতরে ডিফাইন করা হয়।

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

একটি ফাংশনের টাইপ লেখা হয় অ্যানোনিমাস ফাংশনের মতোই একই রকম সিনট্যাক্স ব্যবহার করে। যে ফাংশন একটি `Int` ও একটি `Float` নেয় আর একটি `Int` রিটার্ন করে, তার টাইপ লেখা হয় এভাবে:

```gleam
fn(Int, Float) -> Int
```

অ্যানোনিমাস ফাংশন ডিফাইন করার সময় যে ভ্যারিয়েবলগুলো স্কোপে ছিল, সেগুলো রেফার করতে পারে; এ কারণেই এরা _ক্লোজার_।

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_ফাংশন ক্যাপচার_ সিনট্যাক্স হলো এমন একটি সুবিধাজনক শর্টহ্যান্ড, যা দিয়ে অ্যানোনিমাস ফাংশন তৈরি করা যায়, যেগুলো একটি মাত্র আর্গুমেন্ট অন্য একটি ফাংশনে পাঠায়। এই দুটি এক্সপ্রেশন সমতুল্য:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
