# পরিচিতি

while লুপ দিয়ে আপনি যতক্ষণ একটি নির্দিষ্ট শর্ত পূরণ হয়, ততক্ষণ বারবার কোড চালাতে পারেন। এটি লেখা হয় `while` কিওয়ার্ড দিয়ে, তারপর প্রথম বন্ধনীর মধ্যে রাখা একটি শর্ত এবং দ্বিতীয় বন্ধনীর মধ্যে থাকা একটি কোড ব্লক দিয়ে, যেটিতে লুপের _বডি_ থাকে।

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript-এ do-while লুপও আছে। এখানে লুপের বডি চালানোর পরে শর্তটি যাচাই করা হয়। এটি তখন কাজে লাগে যখন শর্তটি বডির কোডের ফলাফলের উপর নির্ভর করে।

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

লুপের বডির ভিতরে আপনি `break` কিওয়ার্ড দিয়ে লুপটি সম্পূর্ণ বন্ধ করতে পারেন। এর বিপরীতে, `continue` কিওয়ার্ড কেবল বর্তমান ইটারেশনটি থামায় এবং পরেরটি দিয়ে চালিয়ে যায়। `continue` দিয়ে আপনি প্রায়ই লুপের বডির বড় অংশ একটি `if` স্টেটমেন্টে মুড়ে ফেলা এড়াতে পারেন।

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
