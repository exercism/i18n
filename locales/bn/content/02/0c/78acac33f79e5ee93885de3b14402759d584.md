# বিট ম্যানিপুলেশন

Crystal-এ বাইনারি স্তরে [`Int`][ints] ম্যানিপুলেট করার জন্য বিটওয়াইজ অপারেটর রয়েছে।

## শিফট অপারেটর

Crystal-এ বিটকে বামে (`<<`) বা ডানে (`>>`) সরানোর জন্য [শিফট অপারেটর][shift] রয়েছে।

### বামে শিফট(`<<`)

বামে শিফট অপারেটর (`<<`) বিটগুলোকে বামে সরায়।
শিফট করার মানটি বাম দিকে নির্দিষ্ট করা হয় এবং কত ঘর শিফট করতে হবে তার সংখ্যা ডান দিকে থাকে।

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

সংখ্যাটি ঋণাত্মক হলে এটি বদলে ডানে শিফট হবে।

```crystal
0b0010 << -1
# => 0b0001
```

### ডানে শিফট(`>>`)

ডানে শিফট অপারেটর (`>>`) বিটগুলোকে ডানে সরায়।
বামে শিফট অপারেটরের মতোই, শিফট করার মানটি বাম দিকে নির্দিষ্ট করা হয় এবং কত ঘর শিফট করতে হবে তার সংখ্যা ডান দিকে থাকে।

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

একইভাবে, সংখ্যাটি ঋণাত্মক হলে অপারেটরটি বামে শিফট করবে।

```crystal
0b0100 >> -1
# => 0b1000
```

## বাইনারি অপারেটর

Crystal-এ বিটওয়াইজ অপারেশন করার জন্য ৩টি [বাইনারি অপারেটর][binary] (`&`, `|`, `^`) এবং একটি `~` অপারেটর রয়েছে।

### বিটওয়াইজ AND(`&`)

বাইনারি AND অপারেটর (`&`) দুটি মানের উপর বিটওয়াইজ AND সম্পন্ন করে।
এটি প্রথম মানের প্রতিটি বিটকে দ্বিতীয় মানের একই অবস্থানের বিটের সাথে তুলনা করে।
দুটি বিটই ১ হলে ফলস্বরূপ বিটটি ১ সেট করা হয়।
অন্যথায়, এটি ০ সেট করা হয়।

```crystal
0b0011 & 0b1010
# => 0b0010
```

### বিটওয়াইজ OR(`|`)

বাইনারি OR অপারেটর (`|`) দুটি মানের উপর বিটওয়াইজ OR সম্পন্ন করে।
এটিও প্রথম মানের প্রতিটি বিটকে দ্বিতীয় মানের একই অবস্থানের বিটের সাথে তুলনা করে।
দুটির যেকোনো একটি বিট ১ হলে ফলস্বরূপ বিটটি ১ সেট করা হয়।
অন্যথায়, এটি ০ সেট করা হয়।

```crystal
0b0011 | 0b1010
# => 0b1011
```

### বিটওয়াইজ XOR(`^`)

বাইনারি XOR অপারেটর (`^`) বিটওয়াইজ XOR সম্পন্ন করে।
বিটওয়াইজ AND এবং বিটওয়াইজ OR অপারেটরের মতোই, এটি প্রথম মানের প্রতিটি বিটকে দ্বিতীয় মানের একই অবস্থানের বিটের সাথে তুলনা করে।
যদি তাদের _শুধু একটি_ ১ হয়, ফলস্বরূপ বিটটি ১ হয়।
অন্যথায়, এটি ০ হয়।

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### বিটওয়াইজ NOT(`~`)

সবশেষে, বিটওয়াইজ NOT অপারেটর (`~`) মানটির প্রতিটি বিট উল্টে দেয়।
অন্য বাইনারি অপারেটরগুলোর বিপরীতে, এটি একটি ইউনারি অপারেটর, যা কেবল ডান দিকের মানের উপর কাজ করে।

```crystal
~0b1110_0010
# => 0b0001_1101
```
