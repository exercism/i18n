# ইঙ্গিত
`Option` এমন একটি গণনা বোঝাতে ব্যবহৃত হয়, যার কোনো কাজের ফলাফল নাও থাকতে পারে
(যেমন কোনো এরর বা ভুল ইনপুটের কারণে)।
আপনি যদি `Option`-এর সাথে অপরিচিত হন, তাহলে [এই টিউটোরিয়ালটি](http://danielwestheide.com/blog/2012/12/19/the-neophytes-guide-to-scala-part-5-the-option-type.html) পড়ে দেখতে পারেন।
`Option` হলো তথাকথিত একটি [মোনাড](https://en.wikipedia.org/wiki/Monad_(functional_programming)), যা একটি "কম্পিউটেশনাল অ্যাসপেক্ট" সামলায়, এই ক্ষেত্রে একটি মান সম্ভবত অনুপস্থিত থাকা।
মোনাড সঠিকভাবে ব্যবহার করলে কোড খুব সংক্ষিপ্ত, তবুও সুন্দর
আর পাঠযোগ্য হতে পারে। ভুলভাবে ব্যবহার করলে সহজেই উল্টোটা হতে পারে।
আরও জানতে [এই ভিডিওটি](https://www.youtube.com/watch?v=Mw_Jnn_Y5iA) দেখুন।
## যে কমন বিপদগুলো এড়িয়ে চলা উচিত
`Option`-এর জন্য কয়েকটি সাধারণ নিয়ম আছে:
1. দরকার না থাকলে ব্যবহার করবেন না। এর বদলে
```scala
def add1(x: Int): Option[Int] = Some(x + 1)
```
বরং এভাবে লিখুন
```scala
def add1(x: Int): Int = x + 1
```
(এমন সাধারণ ফাংশন প্রয়োগ করার জন্য `Option.map` আছে,
তাই এগুলোকে `Option` দিয়ে জটিল করার দরকার নেই)।
2. সত্যিই দরকার না হলে "আনর্যাপ" করবেন না।
আপনার উদ্দেশ্য সাধনের জন্য প্রায়ই বিল্ট-ইন ফাংশন থাকে। সময়ের আগেই
আনর্যাপ করার লক্ষণ হলো `isDefined/isEmpty` বা প্যাটার্ন ম্যাচিং। এর বদলে
```scala
val x: Option[Int] = ...

if (x.isDefined) x.get + 1 else 0
// or
x match {
  case Some(n) => n + 1
  case None => 0
}
```
বরং এভাবে লিখুন
```scala
x map (_ + 1) getOrElse 0
```
3. মোনাড ফর-কম্প্রিহেনশনের ভেতরে ব্যবহার করা যায়, FTW।
একাধিক `Option` ইনস্ট্যান্স "কম্পোজ" করতে চাইলে এটি করাই বাঞ্ছনীয়। এর বদলে
```scala
val xo: Option[Int] = ...
val yo: Option[Int] = ...
val zo: Option[Int] = ...

xo.flatMap(x =>
  yo.flatMap(y =>
    zo.map(z =>
	  x + y + z)))
```
বরং এভাবে লিখুন
```scala
for {
  x <- xo
  y <- yo
  z <- zo
} yield x + y + z
```
