# ইঙ্গিত

## 1. সব ওয়াগনের একটি ভেক্টর তৈরি করুন

- `push!` দিয়ে একটি `Vector`-এ একটি ক্লাসিক for/while লুপ কাজ করবে।
- অন্যথায়, [`collect()`][collect] ফাংশনটি আরও সংক্ষিপ্ত হতে পারে।
- বিকল্পভাবে, ভেক্টর কনস্ট্রাক্টরের ভেতরে স্প্ল্যাটিং কাজ করে:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. ওয়াগনের ভেক্টরটি ঠিক করুন

- সামনের ওয়াগনগুলো ও ইঞ্জিনকে বাকি সবকিছু থেকে আলাদা করা সুবিধাজনক, যাতে সঠিক ক্রমে সেগুলো আবার জোড়া দেওয়া যায়।
- স্প্ল্যাটিংসহ মাল্টিপল অ্যাসাইনমেন্ট আপনার কাজে লাগতে পারে (ভূমিকা দেখুন)।

## 3. অনুপস্থিত স্টপ যোগ করুন

- মনে রাখবেন, এই ফাংশনটি ইনপুট পরিবর্তন করে না! একটি নতুন `Dict` তৈরি করুন।
- শুধু স্টপের নাম দরকার, স্টপ নম্বর নয়, তাই প্রতিটি জোড়াকে আলাদা করতে হবে।
- নামের ভেক্টর তৈরির একাধিক উপায় আছে:
  -  `push!()` দিয়ে একটি `Vector`-এ For/While লুপ।
  -  অ্যারে [কম্প্রিহেনশন][comprehensions]
  -  ভেক্টরের উপর একটি ফাংশন [`map()`][map] করা।
  -  একটি [অ্যানোনিমাস][anonymous] ফাংশনের [ব্রডকাস্টিং][broadcasting] সম্ভব:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. রাউটিং তথ্য বাড়ান

- স্লার্পিং করার পর, `more_route_information` একটি `Pairs()` কালেকশন হয়।
- [`merge()`][merge] ফাংশনটি দুই বা তার বেশি `Dict` একত্র করবে, তবে একটি `Pairs()` কালেকশনও গ্রহণ করবে।
  `Pairs()` কালেকশনটিকে স্পষ্টভাবে `Dict`-এ রূপান্তর করা সম্ভব, তবে দরকার নেই।
