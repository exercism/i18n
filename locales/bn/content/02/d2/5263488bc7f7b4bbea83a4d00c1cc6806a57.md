# সম্পর্কে

একটি [`switch` স্টেটমেন্ট][switch] ব্যবহার করে আপনি একটি মানকে একাধিক সম্ভাব্য মিলে যাওয়া মানের সাথে তুলনা করতে পারেন।
এটি একাধিক `else-if` স্টেটমেন্ট ব্যবহার করার চেয়ে সংক্ষিপ্ত কোড লিখতে সাহায্য করে।
একটি `switch` স্টেটমেন্ট শুরু হয় `switch` কিওয়ার্ড দিয়ে, তার পরে থাকে যে মানটির সাথে তুলনা করা হবে।
এরপর `case` কিওয়ার্ড দিয়ে কেসগুলো নির্ধারণ করতে পারেন, যার পরে থাকে যে মানের সাথে তুলনা করা হবে।
কোনো কেসই মিলে না গেলে ডিফল্ট কেস নির্ধারণ করতে ব্যবহার করা হয় `default` কিওয়ার্ড।
`else-if` স্টেটমেন্টের মতোই, `switch` স্টেটমেন্ট শুধু প্রথম মিলে যাওয়া কেসের সাথে সম্পর্কিত কোড ব্লকটিই চালায়।

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

নিচের উদাহরণটি দেখুন:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

এটির বদলে এভাবে লেখা যেতে পারে:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## বাইন্ডিং ও `where` স্টেটমেন্ট

`switch` স্টেটমেন্টে যে মানগুলোর সাথে মিল করা হয়, সেগুলোকে নামের সাথেও বাইন্ড করা যায়, আর সেই নামগুলো কেসের বডিতে ব্যবহার করা যায়।
নামগুলো `where` ক্লজেও ব্যবহার করা যায়; এগুলো এমন অতিরিক্ত বুলিয়ান এক্সপ্রেশন, যেগুলো কেসটি মেলাতে হলে `true` হতে হবে।

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
