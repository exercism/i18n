# লিপ-এর ধারণা

আমি প্রথম উদাহরণ সমাধানটি পছন্দ করি, কারণ এর সংক্ষিপ্ততা আইডিওম্যাটিক Rust-এ আমার দেখা ধরনটিকেই অনুসরণ করে। এছাড়া এটি ক্যানোনিকাল সমাধানে যুক্ত হওয়া ক্লোজার ধারণাটিও এড়িয়ে যায়।

## বের করে আনা ধারণা

### সাধারণ

- বুলিয়ান লজিক
  - বুলিয়ান
- এক্সপ্রেশন
  - Rust ফাংশনগুলো পরোক্ষভাবে এক্সপ্রেশন রিটার্ন করে
- অ্যারিথমেটিক
  - মডুলাস

### টাইপ

- আনসাইনড ইন্টিজার - `u64`
- বুলিয়ান - `bool`

## উদাহরণ অনুশীলনী ১

["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)-এর সমাধান

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## উদাহরণ অনুশীলনী ২

[ক্যানোনিকাল](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
