# ডেটাবেস পেমেন্ট ব্যাচ

## সমস্যার বিবৃতি

আপনাকে `Payment` টেবিলে এক ব্যাচ পেমেন্ট ডেটা ইনসার্ট করতে হবে। আপনার কাজ হলো প্রদত্ত ইনপুট JSON ফাইল থেকে পেমেন্ট ডেটা পড়া এবং JDBC ক্লায়েন্টের `batchExecute` অপারেশন ব্যবহার করে `Payment` টেবিলে পেমেন্ট ডেটা ইনসার্ট করা। নমুনা ইনপুট ফাইলটি `payments.json` নামে দেওয়া আছে।

ইনপুট JSON ফাইলের কনটেন্ট নিচের JSON স্কিমার উপর ভিত্তি করে তৈরি।

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

ডেটাবেসে আরেকটি কোয়েরি না পাঠিয়েই ব্যাচে ইনসার্ট করা পেমেন্ট ডেটার জন্য স্বয়ংক্রিয়ভাবে তৈরি হওয়া পেমেন্ট ID-গুলো আউটপুট হিসেবে রিটার্ন করতে হবে।

আপনি ধরে নিতে পারেন যে `payments.json` ফাইলে দেওয়া `employee_id`-গুলো বৈধ এবং সেগুলো আগে থেকেই `Employee` টেবিলে আছে।

## ডেটাবেসের বিবরণ

এই সমস্যার জন্য প্রদত্ত H2 ডেটাবেস ব্যবহার করুন।

> নমুনা ডেটাবেস ফাইলটি `gofigure.mv.db`, আর ডেটাবেসের নাম `gofigure`। এটি `db` ফোল্ডারের ভেতরে দেওয়া আছে।

নিচের টেবিলগুলো কিছু নমুনা ডেটাসহ ইতিমধ্যেই নমুনা H2 ডেটাবেসে আছে। কলামের নাম ও ডেটা টাইপ নিচে দেওয়া হলো।

**টেবিলের নাম** : `Employee`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `employee_id`     | ইন্টিজার, স্বয়ংক্রিয়ভাবে বাড়তে থাকা প্রাইমারি কী       |
| `name`            | স্ট্রিং        |
| `city`            | স্ট্রিং        |
| `department`      | স্ট্রিং        |
| `age`             | ইন্টিজার        |

**টেবিলের নাম**: `Payment`

| **কলাম:**      | টাইপ |
| -----------       | ----------- |
| `payment_id`      | ইন্টিজার, স্বয়ংক্রিয়ভাবে বাড়তে থাকা প্রাইমারি কী       |
| `date`            | ডেট        |
| `amount`          | ডেসিমাল        |
| `employee_id`     | ইন্টিজার        |
| `reason`          | স্ট্রিং        |

* ডেটাবেস ফাইলটি `gofigure.mv.db`. JDBC URL হিসেবে `jdbc:h2:file:/path/to/db/file` ব্যবহার করুন
* ইউজারনেম: `root`
* পাসওয়ার্ড: `root`

## সীমাবদ্ধতা

* কোয়েরি এবং Ballerina নমুনা যাচাই করতে `db` ফোল্ডারে দেওয়া H2 ডেটাবেস ফাইলটি ব্যবহার করুন
* আপনার Ballerina.toml-এ H2 ডেটাবেস ড্রাইভারকে প্ল্যাটফর্ম ডিপেন্ডেন্সি হিসেবে যোগ করতে Maven ডিপেন্ডেন্সি প্যারামস পদ্ধতি ব্যবহার করুন
* ডেটাবেসে আরেকটি কোয়েরি না পাঠিয়েই স্বয়ংক্রিয়ভাবে তৈরি হওয়া পেমেন্ট ID-গুলো খুঁজে বের করতে হবে।

## টেস্ট এনভায়রনমেন্ট

* আপনি `bal test` দিয়ে টেস্টগুলো রান করতে পারেন, আর এটি দেওয়া নমুনা DB-এর বিপরীতে টেস্ট চালাবে।

## ইঙ্গিত

* ডেটাবেস নিয়ে কাজ করতে [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) মডিউলটি ব্যবহার করুন
* JDBC ড্রাইভারকে ডিপেন্ডেন্সি হিসেবে যোগ করার ধাপগুলো জানতে [পূর্বশর্ত](https://lib.ballerina.io/ballerinax/java.jdbc/latest) অংশটি দেখুন
* JSON ইনপুট ফাইল পড়তে [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) ব্যবহার করুন
* টাইপ-সেফ উপায়ে ডেটা নিয়ে কাজ করতে JSON ভ্যালুগুলোকে অ্যাপ্লিকেশন-নির্দিষ্ট টাইপে রূপান্তর করুন। [ব্যবহারকারী-নির্ধারিত টাইপে রূপান্তর](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) উদাহরণটি দেখুন
* ডেটাবেস নিয়ে কাজ করতে [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) এবং [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) রিমোট মেথডটি ব্যবহার করুন
* [ব্যাচ এক্সিকিউট](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) উদাহরণটি দেখুন
