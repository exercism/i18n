# পরিচিতি

`case` ([`combinators`][combinators]-এ) কোনো মানের উপর ডিসপ্যাচ করে। এটি ক্লজের একটি অ্যালিস্ট ধরে ধরে এগোয় এবং প্রথম মিলে যাওয়া ক্লজটির বডি রান করে।

```
case ( obj assoc -- )
```

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

প্রতিটি ক্লজ হলো `{ value [ body ] }`। সমতা নির্ধারিত হয় `=` দিয়ে। মিলে যাওয়া ক্লজগুলো রান হয় ইনপুট মানটি *ইতিমধ্যেই খরচ হয়ে যাওয়া* অবস্থায়। শেষে থাকা একটি `[ body ]` (কোনো মান ছাড়া) হলো ডিফল্ট; এটি রান হয় ইনপুট *এখনও* স্ট্যাকে থাকা অবস্থায়, তাই বডিটা সাধারণত `drop` দিয়ে শুরু হয়।

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
