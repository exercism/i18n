# মেন্টরিং নোট

দুই ধরনের মেন্টরিং নোট আছে:

1. অনুশীলনী-ভিত্তিক নোট (ট্র্যাকের একটি নির্দিষ্ট অনুশীলনীর জন্য দেখানো হয়)
2. ট্র্যাক-ভিত্তিক নোট (ট্র্যাকের _সব_ অনুশীলনীর জন্য দেখানো হয়)

এই নোটগুলোর উদ্দেশ্য হলো:

- মেন্টরদের জন্য অনুশীলনী মেন্টরিং সহজতর করা
- সব মেন্টরের মধ্যে অনুশীলনী মেন্টরিং সামঞ্জস্যপূর্ণ রাখা

## মেন্টরিং নোটে কী থাকে?

অনুশীলনী-ভিত্তিক মেন্টরিং নোটে প্রায়ই থাকে:

- যুক্তিসঙ্গত সমাধানের উদাহরণ
- কমন পরামর্শ/বিপদ
- আলোচনার বিষয়

ট্র্যাক-ভিত্তিক মেন্টরিং নোটে প্রায়ই থাকে:

- কমন পরামর্শ/বিপদ (যা _সব_ অনুশীলনীতে প্রযোজ্য)
- দরকারি রিসোর্সের লিংক (যেমন একটি স্টাইল গাইড)

## মেন্টরিং নোট কীভাবে যোগ করবেন

মেন্টরিং নোট [website-copy রিপোতে][website-copy] নিম্নলিখিত ফাইল নামকরণের প্যাটার্ন ব্যবহার করে সংরক্ষণ করা হয়:

- অনুশীলনীর মেন্টরিং নোট: `tracks/<track-slug>/exercises/<exercise-slug>/mentoring.md`
- ট্র্যাকের মেন্টরিং নোট: `tracks/<track-slug>/mentoring.md`

মেন্টরিং নোট যোগ করতে, উপরের ফাইল নামকরণের প্যাটার্ন অনুযায়ী একটি ফাইল যোগ করার জন্য একটি PR সাবমিট করুন।

### মেন্টরিং নোট কেন ট্র্যাক রিপোতে নেই?

একটি ট্র্যাক রক্ষণাবেক্ষণ করা মেন্টরিং নোট লেখার থেকে বেশ আলাদা এবং এর জন্য ভিন্ন দক্ষতা দরকার।
তাই মেন্টরিং নোট লেখা ব্যক্তিরা এবং ট্র্যাক রক্ষণাবেক্ষণকারীরা একই ব্যক্তি হওয়াটা জরুরি নয়।

যদি আমরা মেন্টরিং নোটগুলো ট্র্যাকের রিপোতে সংরক্ষণ করতাম, তবে যেকোনো মেন্টরিং নোট PR মার্জ হওয়ার আগে রক্ষণাবেক্ষণকারীদের অনুমোদন দিতে হতো (অথবা অন্তত প্রতিটি মেন্টরিং নোট পরিবর্তনের জন্য তাদের জানানো হতো)।
মেন্টরিং নোট [website-copy রিপোতে][website-copy] সংরক্ষণ করলে আমরা যেসব সুবিধা পাই:

- ট্র্যাক রক্ষণাবেক্ষণকারীদের উপর বোঝা কমানো
- ট্র্যাক রক্ষণাবেক্ষণকারীদের থেকে আলাদা ব্যক্তিদের দিয়ে মেন্টরিং নোট পর্যালোচনা করানো (তারা একই হতে _পারেন_)
- মেন্টরিং নোটে দ্রুত ইটারেশনের সুযোগ দেওয়া (ট্র্যাক রক্ষণাবেক্ষণকারীরা PR মার্জ করার সময় প্রায়ই বেশ কঠোর হন)
