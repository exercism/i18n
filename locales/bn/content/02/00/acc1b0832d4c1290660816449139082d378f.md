# পরিচিতি

এলিক্সিরে টাপল হলো একটি ডেটা স্ট্রাকচার, যা ডেটা সাজিয়ে রাখে এবং যেকোনো টাইপের নির্দিষ্ট সংখ্যক আইটেম ধারণ করে, তবে প্রতিটি এলিমেন্টের জন্য আলাদা কোনো নাম থাকে না। এলিক্সিরে যেসব অপারেশনে মেমরি থেকে 많이 পড়তে হয়, সেখানে টাপল প্রায়ই ব্যবহার করা হয়, কারণ কোনো এলিমেন্ট পড়তে ধ্রুবক সময় লাগে। এলিমেন্ট যদি গতিশীলভাবে যোগ বা মুছে ফেলার প্রয়োজন হয়, তখন সাধারণত টাপল ব্যবহার করা হয় না, কারণ বিদ্যমান টাপল পরিবর্তন না করে নতুন একটি টাপল তৈরি করা হয়, যার জন্য আগে থেকেই মেমরি বরাদ্দ করতে হয়।

বাস্তবে এলিক্সিরে দ্বিতীয় বন্ধনী দিয়ে টাপল তৈরি করা হয়। টাপলের এলিমেন্টগুলো `elem/2` ফাংশন দিয়ে আলাদা আলাদাভাবে অ্যাক্সেস করা যায়, যেখানে 0 থেকে শুরু হওয়া ইনডেক্স ব্যবহার করা হয়:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## দলবদ্ধ তথ্য হিসেবে টাপল

বাস্তবে দলবদ্ধ তথ্য বোঝাতে প্রায়ই টাপল ব্যবহার করা হয়।

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
